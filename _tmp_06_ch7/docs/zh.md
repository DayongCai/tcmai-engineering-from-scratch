## 核心概念

### 中医：一致性评估的前提是先固定诊法条件

《素问·脉要精微论》强调「诊法常以平旦」，说的是诊断要在条件受控时进行。这句话在今天的含义是：**如果两位医生看同一个病人的时间、体位、问诊深度都不同，他们的不一致里混着测量误差，不能全算作判断差异**。评估系统与医生的一致性之前，先要评估医生彼此的一致性——后者是这套评估的噪声底。

### AI/工程：kappa 与它的陷阱

$$\kappa=\frac{p_o-p_e}{1-p_e}$$

$p_o$ 是观察一致率，$p_e$ 是「按各自边际分布随机猜」的期望一致率。kappa 的含义是「扣掉碰巧对上之后的一致程度」。

三个必须同时报告：$p_o$、$\kappa$、以及**边际分布**（各类占比）。因为当某一类占 90% 时，系统全判这一类就能拿到 0.9 的 $p_o$，而 $\kappa$ 可能接近 0——反过来，当两类各占 50% 且几乎全对时，$\kappa$ 也会被压得比直觉低。这就是著名的 kappa 悖论，替代方案是 PABAK 或 Gwet 的 AC1。

## BUILD IT：从零实现

```js
function kappa(matrix) {
  // matrix[i][j]：系统判 i、医生判 j 的例数
  const n = matrix.flat().reduce((a, b) => a + b, 0);
  const po = matrix.reduce((s, row, i) => s + row[i], 0) / n;
  const rowSum = matrix.map((r) => r.reduce((a, b) => a + b, 0) / n);
  const colSum = matrix[0].map((_, j) => matrix.reduce((s, r) => s + r[j], 0) / n);
  const pe = rowSum.reduce((s, r, i) => s + r * colSum[i], 0);
  return { po, pe, kappa: (po - pe) / (1 - pe) };
}
```

预期：一个「全判同一类」的退化矩阵 $p_o=0.857$ 但 $\kappa=0$，与一个均衡且几乎全对的矩阵（$\kappa\approx0.94$）形成对照——这正是答辩时最容易被问到的那一处。

## 代价与边界

- **一致不等于正确**。两位医生都判错时，系统跟着错会得高分；没有金标准，一致性只是「像人」，不是「对」。
- **kappa 对患病率敏感**。类别极不平衡时它会低得离谱，不能直接拿来与文献里的 0.8 比较。
- **样本量与类别数会改变可比性**。5 类 200 例与 2 类 2000 例的 kappa 不可直接对照。
- **它不告诉你错在哪**。必须同时给出混淆矩阵，否则无法看出系统是否把「肝阳上亢」全判成「肝火上炎」。

## 进阶思考

一致性评估最容易被当成「验收指标」：数字够了就上线。但一个只跟人类保持一致的模型，天花板就是人类的一致性水平——而人类彼此的一致性本身可能只有 0.6。先把噪声底测出来，再谈系统好不好。
