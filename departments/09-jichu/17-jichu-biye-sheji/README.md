## 三、本课与实例的关系

本系毕设实例的产物是「病理／病理生理／生理三套单元层（252 ＋ 216 ＋ 132 单元）」，三份案例：病理图像标注语料、九轴覆盖度诊断、正常值表可复现交付。
`毕设对接.md` 由脚本从实例现算生成，给出七项检查表状态、基准值与章节对位；答辩时必须能对上那七项。

1. 不写真实课题的数据、图表与结论；

3. 不写统计阈值与样本量取值；
4. 不替学生决定选题，只给判据。
