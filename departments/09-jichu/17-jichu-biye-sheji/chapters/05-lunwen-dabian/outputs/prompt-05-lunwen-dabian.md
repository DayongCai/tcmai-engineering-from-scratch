# 论文与答辩输在口径不一致，不输在口才 · 提示词

## 用途

给「论文与答辩输在口径不一致，不输在口才」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「引言不是背景综述，是把缺口收到一句话 → 方法要写成别人能重做的检索与评价 → 结果用规范的频率指标说话 → 图表与讨论：把分布与不确定一起呈现」这条链。

## 提示词

```
我在学《基础医学毕业设计与知识移交》第 5 章「论文与答辩输在口径不一致，不输在口才」，本章 7 节 / 3,248 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 引言最容易写成「某某病很常见、危害很大、因此研究很重要」的三段式，读完不知道你要填哪个缺口
   - 说「既有研究到哪一步」，靠的是证据定位而不是文献堆叠
   - 引言的边界要守住：不把关联写成因果，不把动物或体外结果直接推到人，不引用没读过的二次文献
   - 方法部分的功能不是「交代做过什么」，而是「让同行能重做一遍」
   - 系统评价的流程要按环节写：确定问题、制定方案、系统检索、筛选文献、评价质量、提取数据、综合分析、撰写报告
   - 质量评价写到偏倚风险：选择、实施、测量与判断、随访与缺失、报告五个方向，逐项给判断和依据
4. 指出本章写到类别就止步、不再给参数的地方。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章只讨论论文写作、结果呈现与答辩的方法学，不构成任何疾病诊断、治疗或用药建议；具体操作以现行规范与所在机构制度为准。
