# 第 5 章 · 论文与答辩输在口径不一致，不输在口才

> **MOTTO:** 「太上有立德，其次有立功，其次有立言」——《左传·襄公二十四年》
>
> **PROBLEM:** 答辩现场最伤人的问题往往只有一句：「你摘要里写患病率 12.3%，结果表里分母是 260 还是 320？」教学设定里一篇 8,000 字的论文，同一指标在摘要、结果、讨论里出现三次，三次分母都不同；评委不必追问方法，口径一乱，结论就自动失效。

**双根因定位:** 环境逼迫（答辩只有十几分钟，评委按摘要与图表抓要点，口径不一致会先于内容被看见；论文又要同时满足格式审查与学术规范，返修窗口很短） + 知识积累（写作课教的是结构模板，没教「指标—分母—来源」这条链，于是把不同来源的数字抄进同一段，自己也没意识到底数换了）

**教材出处:** 《流行病学》·第16章·16.1–16.2 与 第2章·2.1–2.2（本课为派生课，无独立教材；第 5 章十二个单元由循证医学的基本概念、系统评价的基本方法、疾病频率的测量指标、疾病的三间分布四节改写为论文写作与答辩流程）

## 一、引言不是背景综述，是把缺口收到一句话

引言最容易写成「某某病很常见、危害很大、因此研究很重要」的三段式，读完不知道你要填哪个缺口。有效的引言只做三件事：说清问题在人群中的分量，说清既有研究到哪一步、缺哪一块，说清你打算补哪一块。三件事各一段，最后一句落到本研究的目的上，读者就能顺着走下去。

说「既有研究到哪一步」，靠的是证据定位而不是文献堆叠。按研究设计归类，实验性研究对效果类问题的支持通常强于观察性研究；按证据体评价，还要看偏倚风险、研究间一致性、对目标人群的间接程度、结果精确程度与发表偏倚。引言里不需要展开分级细则，但要给读者一个判断：这个问题的现有证据是「已有稳定结论」，还是「方向互相打架」，还是「关键人群从未被覆盖」。三者的写法完全不同——第一种要说明为什么还值得做（比如人群不同、剂量不同），第二种要说明争议在哪，第三种要说明空白在哪。

引言的边界要守住：不把关联写成因果，不把动物或体外结果直接推到人，不引用没读过的二次文献。引用要落到可核查的原始出处，作者、期刊、年份、卷期页码要对得上；转引他人综述里的数字，要回去核原文，核不到就不用。这一条在答辩时最容易被抽查。

## 二、方法要写成别人能重做的检索与评价

方法部分的功能不是「交代做过什么」，而是「让同行能重做一遍」。文献检索尤其如此：检索词、检索字段、检索式、数据库与来源、时间范围、更新策略，六项缺一项，别人就复现不了你的检索。自由词与主题词要配着用，检索式的逻辑组合要写出来，不能只写「检索了中国知网和 PubMed」。

系统评价的流程要按环节写：确定问题、制定方案、系统检索、筛选文献、评价质量、提取数据、综合分析、撰写报告。方案是否事先制定，直接决定可信度——看到结果再改纳排标准，就是选择性报告。筛选要写两级：题录摘要初筛、全文核定，两级各由两名评价者独立完成，分歧如何解决、分歧多少，都要交代。灰色文献补没补、手工检索做没做，也要写，因为它关系到发表偏倚。

质量评价写到偏倚风险：选择、实施、测量与判断、随访与缺失、报告五个方向，逐项给判断和依据。观察性研究另加混杂控制、暴露与结局测量、对象选择。只给一个总分不算评价，因为读者看不出偏倚发生在哪一环。若纳入研究的偏倚风险普遍偏高，方法部分就要预先声明：结论只能谨慎表述。

方法写得实，结果才有位置。方法里承诺的分析，结果里要一项不落地出现；结果里多出来的分析，要说明是事后探索。两者对不上，评委一眼就能看出。

## 三、结果用规范的频率指标说话

结果部分的第一原则是口径一致。同一个指标，摘要、正文、图表只能用一套定义、一套分母、一套来源。常见指标要分清：发病率是新发病例数除以同期暴露人口数，衡量的是新发风险；发病密度是新发病例数除以合计人年，适合人群变动大的随访；患病率是现患病例数除以调查人口数，受病程长短影响，不能当发病风险用。死亡指标同样要分：死亡率的分母是人群，病死率的分母是病例，生存率要看随访起点与终点。

用一组教学设定的数据把口径走一遍：某人群 1,000 人随访一年，新发 20 例，发病率＝20/1000＝2.0%；若这 1,000 人合计贡献 2,000 人年，发病密度＝20/2000＝10/1000 人年；同一年调查时点现有病例 50 例，患病率＝50/1000＝5.0%。三个数都来自同一组设定，含义却不同，混用就是把风险、速率与存量搅在一起。这是教学示例，只演示算法。

指标还要与设计匹配。横断面研究能算患病率，算不了发病率；队列研究能算发病率与发病密度；病例对照研究一般只能算比值比，不能直接算发病率。把不能算的指标算出来，是结果部分最硬的内伤。

结果的呈现顺序按论证链走：先对象流程（进入多少、排除多少、失访多少），再基线特征，再主要结局，再次要结局与亚组，最后敏感性分析。每一张表都要能独立阅读：标题写清人群、暴露、结局、时间；表头标单位；合计对得上；效应量旁有置信区间。

## 四、图表与讨论：把分布与不确定一起呈现

描述人群、时间、地区三个维度的分布，是结果部分的常规动作，也是最容易做成流水账的地方。人群分布按年龄、性别、职业等特征看发病率或患病率的差异；时间分布看长期趋势、季节性、短期波动；地区分布看国家间、城乡间、区域间的差异。三间分布不是罗列，是找线索：哪个特征上的率明显偏离，哪个时点出现聚集，哪个地区持续偏高，这些才是讨论的入口。

图要选对类型：趋势用线图，构成用堆叠图或百分比条，地区差异用地图或排序条形图，生存用阶梯曲线。图题、坐标轴单位、图例缺一不可；截断坐标轴要标注，否则会放大差异。表与图不要重复同一批数据，正文也不要把表里的每个数字念一遍。

讨论部分按证据强度说话。自己的结果是关联，就写关联，不写因果；与既往研究一致，说清一致在哪、人群是否可比；不一致，先找方法学差异（对象、测量、随访、调整变量），再谈生物学解释。机制解释只能作为假设提出，不能当作已证实的通路。局限性要主动写：样本代表性、失访、残余混杂、测量误差、单中心，每一条都要说明可能把结论推向哪个方向。

结论段只回答引言提出的问题，不引入新结果，不作超出数据的推广。政策建议与临床应用建议要格外克制：本研究能支持的是「某人群中观察到某关联」，不是「应当如何处置」。

## 五、答辩：评委问的是边界，不是背稿

答辩的十五分钟，讲清楚三件事就够：为什么做、怎么做、做出了什么并且只能说到哪。幻灯片按论证链排，不按工作量排；每页一个主张，图大于字，方法页给出关键参数而不是全部步骤。

提问环节的问题大多落在边界上：样本够不够、对照合不合理、混杂控没控、指标口径是什么、结论能不能外推、与既往研究为什么不一致。回答的要领是先承认边界，再给依据：能答的给数字与出处，不能答的说清为什么不能答、后续怎么补。最忌讳两类回答：一类是把问题挡回去（「这是统计方法决定的」），一类是过度承诺（「这个结果可以直接用于临床」）。

答辩材料要与论文一致：幻灯片里的数字、图、结论，必须能在论文里找到对应段落。评委随手翻到一页对不上，后面所有解释都会被打折。提前做一次「口径核对」：把摘要、结果表、图、讨论里出现的每个指标列成一张表，逐个核对定义与分母，对不上的当场改。

## 代价与边界

把口径统一、把过程写全，论文会变长，写作周期会拉长；教学设定里，仅口径核对与图表重做通常要占两周。这个代价不能省，因为它是论文能被复核的唯一路径。另一个代价是克制：不写因果、不作过度推广，会让结论看起来「不够有力」，但答辩时被追问的破口也少。

边界要写死。第一，本章讨论论文写作与答辩的方法学，不构成任何疾病诊断、治疗或用药建议，论文结论不得直接作为临床处置依据。第二，观察性研究的关联不得表述为因果，系统评价的合并结果只适用于与纳入研究条件相近的情境。第三，派生课没有独立教材，本章不引具体期刊、作者、卷期或伦理批号；文中示例数字均为教学设定，只用于演示口径。

## 运行与验证

本章的正文与习题契约由脚本现算，可当场复核：

```bash
node code/main.js
```

脚本打印的是本章正文的规模、习题的阶段分布与接地情况；退出码为 0 表示各项契约满足，非 0 表示有不满足的项，输出里会逐条写明。


定稿前跑四步：

1. 指标台账：把全文出现的每个率、每个效应量列成一行，写清定义、分子、分母、来源，逐个核对三处（摘要、结果、讨论）是否一致。
2. 检索可复现：把检索式原样输入数据库，看命中数是否与论文所写相符；差得多，说明检索式或时间范围没写全。
3. 图表自检：遮住正文，只看表与图，能否读出人群、暴露、结局、时间与不确定性。
4. 模拟答辩：请一位没参与的同学按摘要提三个边界问题，答不上来的，就是论文里要补的段落。

再用教学设定复算三个指标：`20/1000=2.0%`、`20/2000=10/1000 人年`、`50/1000=5.0%`。三个数混用，口径就没统一。
