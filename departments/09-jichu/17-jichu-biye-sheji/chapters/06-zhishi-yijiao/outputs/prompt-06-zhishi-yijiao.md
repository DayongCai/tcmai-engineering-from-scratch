# 移交不是交钥匙，是把判断的依据一并交出去 · 提示词

## 用途

给「移交不是交钥匙，是把判断的依据一并交出去」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「交接前先把数据验一遍 → 伦理与数据合规：批件和授权随项目一起走 → 技术清单：每类技术都要写明能做什么、不能做什么 → 协议与观察：把「怎么做」写成「下一次怎么再做」」这条链。

## 边界

本章只讨论知识移交、实验协议编写与数据合规的方法学，不构成任何疾病诊断、治疗或用药建议；具体操作以现行规范与所在机构制度为准。
