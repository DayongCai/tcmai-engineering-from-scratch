# 方案经不起偏倚追问，伦理批件就过不了 · 提示词

## 用途

给「方案经不起偏倚追问，伦理批件就过不了」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「方案的第一页是问题与假设，不是流程 → 设计类型按目的与条件挑，不按高低排 → 偏倚要在设计里堵，统计补不回来 → 混杂要过三道关，控制分两个阶段」这条链。

## 边界

本章只讨论研究方案设计与偏倚控制的方法学，不构成任何疾病诊断、治疗或用药建议，也不对任何具体研究是否符合伦理作判断；具体操作以现行规范与所在机构制度为准。
