# 第 4 章 · 分析方法没有高级低级，只有配不配这批数据

> **MOTTO:** 「不以规矩，不能成方圆」——《孟子·离娄上》
>
> **PROBLEM:** 数据交上来是一张 300 行的表，缺失值散在十几列，暴露组与对照组基线差着一截；学生第一反应是「跑个多因素回归」，跑完发现某个变量系数方向与常识相反，却说不清是共线性、是缺失处理，还是分层没做——教学设定里这类返工平均要吃掉两周。

**双根因定位:** 环境逼迫（毕设的数据窗口只有一次，样本收完就封存，分析错了不能补采；答辩要的是能复算的表与图，不是「跑出来了」的一句话） + 知识积累（统计课按方法讲，没按「数据条件—方法—解释」串起来，于是把方法当工具挑，先选模型再找理由）

**教材出处:** 《流行病学》·第11章·11.1–11.4（本课为派生课，无独立教材；第 4 章十二个单元由数据管理与质量控制、常用分析方法的适用条件、分层与多因素分析思路、结果的呈现与报告四节改写为数据分析流程）

## 一、数据整理：把原始表变成能分析的表

分析从整理开始，不从模型开始。原始表通常是「一人一行、一题一列」的宽表，先要过五道工序：统一编码（把「男／男性／1」并成一类）、统一量纲（mg/L 与 g/L 不能混在一列）、处理缺失（标缺失、记原因，不拿 0 填）、识别异常值（超出生理可能范围的先回查原始记录，不能直接删）、做逻辑核查（年龄与出生日期对不上、随访日期早于入组日期的，逐条核）。

缺失值要分三类对待：完全随机缺失、随机缺失、非随机缺失。前两类可以用完整案例分析或多重填补，第三类只能靠敏感性分析看结论会不会翻。最忌讳的是默认「空白＝正常」，把没填的当成阴性，这会系统性地压低发生率。异常值同理：先判断是录入错误、测量错误，还是真实的极端个体；前两种回查改正，第三种保留并在报告中说明，不能为了让图好看而截尾。

整理完要留一张「变量字典」：每个变量的名称、含义、类型、单位、取值范围、缺失编码、来源条目。没有字典，三个月后自己也读不懂自己的表，更别说让别人复算。整理过程每一步都要留痕，改了什么、为什么改、谁改的，写在数据日志里。

## 二、质量控制与合规：数据也是有证据链的

数据质量控制的环节要前移。录入阶段用双人独立录入加比对，分歧回查原始表；录入后做逻辑核查与范围核查，把不可能的组合理出来；分析前再做一次分布核查，看有没有离谱的偏态与重复行。核查方法不复杂，难在坚持：每一批数据进来都过一遍，而不是最后一次性清洗。

核查要留下核查记录：查了什么、发现多少条、改了多少、剩多少未解决。这份记录在答辩时比任何解释都有说服力，因为它证明你知道数据哪里不干净，而不是假装干净。

数据安全与合规是同一件事的两面。涉个人信息的数据要脱敏，姓名、身份证号、联系方式与样本编号分开存放，分析表里只留编号；访问权限按角色给，谁能看原始表、谁能看分析表、谁能导出，事先写定；数据导出要登记，传输用加密渠道，本地不留散落的副本。涉及人体数据的研究，数据使用范围要与知情同意的授权一致，超出授权范围的使用，哪怕技术上做得到，也不能做。

共享与发表也有边界：能公开的是汇总结果与脱敏后的分析数据，不是原始可识别信息；合作方要用数据，走数据使用协议，写明用途、期限与销毁方式。数据合规不是给审查看的附件，它决定了这批数据将来还能不能被合法使用。

## 三、描述、比较、关联：三种问题，三套方法

描述性分析回答「是什么样」。连续变量看集中趋势与离散程度，正态用均数与标准差，偏态用中位数与四分位间距；分类变量看频数与构成比。描述要给出分母：说「阳性 30 例」没有意义，说「30/200，15.0%」才有意义。描述还要看分布形态，它决定了后面选哪种比较方法。

比较分析回答「两组有没有差别」。方法的选择取决于三件事：结局是连续还是分类，样本是独立还是配对，分布是否近似正态。连续独立、近似正态用 t 检验，偏态用秩和检验；分类用卡方检验，理论频数过小时改用精确检验；配对资料用配对检验。方法选错，P 值就没有解释力。

关联分析回答「因素与结局有多强的关系」。二分类结局常用相对危险度与比值比：相对危险度是两组发病风险之比，比值比是两组比值之比，二者在结局少见时接近，结局常见时不能互相替代。队列研究能直接算发病风险，病例对照研究一般只能算比值比，把比值比说成「风险增加几倍」是常见误读。生存资料用风险比，解释时要注意它随时间变化的前提。

可以拿一张教学示例的 2×2 表把口径走一遍：暴露组 20 例发病、80 例未发病，非暴露组 10 例发病、90 例未发病。暴露组风险 20/100＝0.20，非暴露组 10/100＝0.10，相对危险度 0.20/0.10＝2.00；比值比＝(20×90)/(80×10)＝2.25。同一组数据两个数不同，报告时必须说明用的是哪一个。这是教学示例，只演示算法，不代表任何真实研究。

## 四、分层、多因素与交互：控制混杂的三条路

分层分析是最透明的一条路：按潜在混杂因素取值切层，层内估计关联再合并。层内取值一致，混杂造不出组间差异。局限也明确：只能控制有限个变量，层数一多每层样本变薄；连续变量要先分类，切点会影响结果；变量多时层数爆炸，估不出稳定值。

多因素分析能同时处理多个变量，常用的是回归类模型。它的前提比分层多：样本量要够（每个自变量需要足够的事件数），变量间不能严重共线性，模型设定要与数据生成过程大致相符，缺失值要先处理。系数解释要看模型：线性模型看均值差，logistic 模型看比值比，Cox 模型看风险比；把 logistic 系数直接当风险差讲，是把「比值」读成了「概率」。

交互作用要看两个尺度。相加交互问的是「两因素同时存在时的效应，是否超过各自效应之和」；相乘交互问的是「效应比是否不等于两个效应比的乘积」。同一组数据在相加尺度上有交互，在相乘尺度上可能没有，反之亦然。判断交互不能只看 P 值，还要有专业依据与事先假设，否则就是在数据里钓鱼。

亚组分析是探索，不是结论。按性别、年龄、分期切亚组，样本一小，偶然性就大；切得越多，假阳性越多。亚组的发现只能写成「提示」，需要独立数据验证，不能直接写进结论当作定论。

## 五、结果呈现：把不确定一起报出来

结果呈现的要素，说到底是三样：效应量、不确定范围、分母。效应量回答「差多少」，置信区间回答「估得准不准」，分母回答「在多少人里」。只报 P 值是最常见的偷懒：P 小只说明「不太可能纯属偶然」，不说明效应大小，也不说明临床价值。

表与图要能独立阅读：标题写清人群、暴露、结局与时间；表头标单位；行列合计对得上；图的坐标轴从零开始还是截断要说明。同一张表里不混用不同口径的效应量，比值比与风险差混排，读者一定会误读。

常见误用有六类：把 P<0.05 当成「有效」；把关联写成因果；做了十次比较只报显著的那次；先看数据再定亚组；用基线检验的 P 值判断随机化是否成功（ baseline 差异应看临床意义与敏感性分析，而不是显著性检验）；把「无统计学意义」读成「没有差别」。每一类都能在答辩时被一句话问穿。

报告的完整性要求把过程写全：多少对象进入、多少排除、多少失访、缺失怎么处理、做了哪些敏感性分析、结论在哪一步可能翻。写得全，读者才能判断结论的边界；写得漂亮但缺过程，等于把判断权藏起来。

## 代价与边界

方法越复杂，解释成本越高：多因素模型能调整混杂，但模型设定错了会给出精确的错误；分层透明，却处理不了多变量；交互分析能发现问题，却极易过拟合。选择方法的依据应当是数据条件与研究问题，而不是「审稿人喜欢看复杂的」。样本量不足时，最诚实的选择是只做描述与简单比较，把复杂模型留到样本足够时。

边界也要写死。第一，本章讨论分析方法的选择与解释，不提供任何具体疾病的诊断阈值或治疗决策依据；统计显著不等于临床有效。第二，观察性数据调整后仍可能残余混杂，调整过的关联不得写成因果。第三，派生课没有独立教材，本章不引具体软件版本、论文数值或期刊结论；示例数字均为教学设定，只用于演示算法。

## 运行与验证

本章的正文与习题契约由脚本现算，可当场复核：

```bash
node code/main.js
```

脚本打印的是本章正文的规模、习题的阶段分布与接地情况；退出码为 0 表示各项契约满足，非 0 表示有不满足的项，输出里会逐条写明。


分析交付前跑一遍五问：

1. 变量字典齐不齐：每个变量有含义、类型、单位、缺失编码吗？
2. 分母写没写：每个率、每个构成比，分子分母各是多少？
3. 方法与数据配不配：结局类型、配对与否、分布形态，三条都对得上吗？
4. 混杂控制了几条路：分层做了什么、多因素放了哪些变量、为什么放这些？
5. 不确定性报没报：效应量旁边有没有置信区间，敏感性分析做了哪几项？

再用示例表复算一遍口径：`20/100=0.20`、`10/100=0.10`、`0.20/0.10=2.00`、`(20*90)/(80*10)=2.25`。四个数对不上，说明口径还没统一。
