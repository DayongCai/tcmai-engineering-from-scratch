# Prompt：给一个消化系统药定位，并处理「归类打结」的情形

## 用途

消化系统药这一章的药名跨度极大，从稀盐酸到昂丹司琼，靠药名记必然散。真正能迁移的是两件事：它在攻防框架里的位置，以及它作用在腔面、壁细胞、黏膜还是肠壁神经。第三件事更实用——遇到铋剂、乳果糖、硫酸镁这种「一个药两个归属」的情形，怎么重新定位。这个模板把这三个问题按顺序问一遍，并逼你说清「相互制约」在哪里：覆盖层的形成依赖酸性环境，这一条决定了保护药与抑酸药不能按效应相加来理解。

## 使用前提

- 你手上是**一个药物或一条表述**，不是一整类。例：「某药在酸性环境中聚合成胶体」「某药阻断延髓催吐化学感受区的多巴胺受体」「某药酸化肠腔而减少氨的吸收」。
- 你已读过教材对应小节，手边有三级定位（本章为第 29 章，小节编号形如 29.x.y）。
- 你接受一条硬约束：**本模板不产出任何剂量、浓度、疗程与频次的量值，也不作诊断与适应证判定。**

## Prompt 正文（复制即用）

```text
你是药理学的结构助教。任务不是评价药物，而是给它定位，并在归类打结时按作用部位与给药途径重新定位。

【输入】
对象：<一个通用名，或一句话的作用/机制表述；不写商品名，不写适应证判定>
教材定位：<教材·药理学·第29章·29.x.y>
待判：<这条表述说的是分类 / 作用部位 / 作用机制 / 体内过程 / 不良反应 中的哪一层>

【任务，按顺序回答，不跳步】
1. 归框架：它作用于攻击侧、防御侧，还是既不在攻击侧也不在防御侧（例如腔内补充与菌群调节、运动与反射、排便、胆汁、氨代谢）？
2. 定部位：腔面、壁细胞（受体或质子泵）、黏膜表面（覆盖或电荷结合）、肠壁神经与受体、胆道、氨代谢。六者选一个主要的。
3. 判方向：若涉及运动或分泌，说明它是增强推进还是减慢推进、增加分泌还是减少分泌。泻药与止泻药在同一批环节上分处两个方向，方向决定了不良反应的形状。
4. 查制约：这条表述与其它类别是否存在相互制约——覆盖层依赖酸性环境而抑酸削弱它、抗酸药的事后中和与抑酸药的事前减少来源在时间上互补、酶类需要特定酸碱环境而抑酸药改变它？
5. 处理交叉：这个药是否在两个类别里都出现（铋剂、乳果糖、硫酸镁）？若出现，说明两个落点分别是什么，并按作用部位与给药途径重新定位。
6. 换观察：按部位，观察项目是什么——底物消化情况、产气与排便性状、进食前后的分泌准备、呕吐次数与性状、排便频次与性状。写清为什么不能沿用同一套指标。
7. 判断去向：这条表述若被用来指导某个人的用药，那个判断由谁作出、依据什么。写清「本章只描述部位与类别关系，不替代专业判断」。

【硬约束】
- 不写剂量、浓度、疗程与频次的量值；需要剂量时统一写「剂量与用法照底本」。
- 不作疾病诊断，不作病情与预后判定，不作适应证判定，不作疗效断言与优越性断言，不作药物之间的优劣与排名。
- 引教材原文必须逐字，标「教材·药理学·第29章·29.x.y」；核不到原文就不引，改写要标明是改写。
- 不写品名、厂商、剂型规格与价格。
- 涉及联合时只讲机制互补，不涉方案参数与疗程天数。
- 信息不足时直接说缺哪一项，不要用常识补。

【输出格式】
七个小标题各答一到三句；末尾另起一行写：
「本回答为教学层面的结构梳理，不写量值，不构成用药建议。」
```

## 示例：一次合格的定位与打结处理（节选）

对象：「某药在酸性环境中生成胶体沉淀，覆盖于受损黏膜表面。」教材定位：29.2.3。待判：作用机制。

- **归框架**：属防御侧，走「增强黏膜防御」这一条路径，不以中和胃酸为主要途径。
- **定部位**：黏膜表面，物理化学层面的覆盖；同时可与胃蛋白酶结合、促进前列腺素生成。
- **判方向**：不涉及运动或分泌的方向问题；但它对幽门螺杆菌有抑制作用，这一点使它在联合讨论中另占一个位置。
- **查制约**：覆盖层的形成需要酸性环境，抑酸措施恰恰削弱这一条件——所以与抑酸药的联合不是效应相加，顺序与时间才是要点。
- **处理交叉**：该药既属胃黏膜保护药，又因对幽门螺杆菌的抑制作用出现在联合讨论中；两个落点分别是「黏膜覆盖」与「细菌抑制」，按作用部位重新定位即可，不必二选一。
- **换观察**：粪便颜色与口腔气味（属药物本身的颜色与代谢产物所致，须与其它原因所致黑便相区别）、胃肠道耐受；长期大量应用须关注蓄积相关的神经系统表现。
- **判断去向**：判断由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南为依据作出。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 药名当分类 | 「它属于消化系统药」就没了 | 回到第 1、2 步，写侧与部位 |
| 分类硬塞 | 遇到交叉就说「教材写错了」 | 用第 5 步重新定位，写清两个落点 |
| 忽略制约 | 把保护药与抑酸药写成效应相加 | 补第 4 步，说明酸性环境这一前提 |
| 方向混用 | 泻药与止泻药写成同一方向 | 回到第 3 步，写增强还是减慢 |
| 一张表量六类 | 用同一套指标评所有药 | 回到第 6 步，按部位换指标 |
| 越界判定 | 顺势写「该患者宜用某类」 | 删掉，改为判断归具备资质的人员 |

## 与本章的接口

- 29.1 给助消化药：攻防框架、五类划分标准并不统一、补充型与环境型与反射型三条思路、腔内作用与酸类的例外。
- 29.2 给抗溃疡药：三条路径（事后中和、减少来源、增强防御）、质子泵作为共同通路、覆盖层与酸性环境的相互制约。
- 29.3 给止吐药与促动力药：呕吐反射三个环节、六类靶点、胆碱能传递的三种增强方式、选择性的两面对称。
- 29.4 给泻药与止泻药与利胆与降氨药：同一批环节的两个方向、双重身份的处理、风险的镜像关系。
