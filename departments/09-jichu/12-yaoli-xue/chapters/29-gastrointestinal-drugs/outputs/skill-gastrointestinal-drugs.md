# Skill：消化系统药——两条坐标、三个方向、一处制约

## 何时用

- 读到「某药属于消化系统药」，需要说清它在攻防框架的哪一侧
- 遇到归类打结（铋剂、乳果糖、硫酸镁），需要按作用部位与给药途径重新定位
- 要解释「为什么保护药与抑酸药不能简单叠加」
- 要解释「为什么选择性高不等于更好」
- 遇到泻药与止泻药并列，需要说清它们为何不良反应呈镜像

## 核心判据（六问）

1. **哪一侧？** 攻击侧（酸与胃蛋白酶）、防御侧（黏液、碳酸氢盐、血流、上皮更新），还是既不在攻击侧也不在防御侧（腔内补充与菌群、运动与反射、排便、胆汁、氨代谢）。
2. **哪个部位？** 腔面、壁细胞（受体或质子泵）、黏膜表面（覆盖或电荷结合）、肠壁神经与受体、胆道、氨代谢。
3. **哪个方向？** 增强推进还是减慢推进，增加分泌还是减少分泌。方向决定不良反应的形状。
4. **有没有制约？** 覆盖层依赖酸性环境而抑酸削弱它；抗酸药事后中和与抑酸药事前减少来源在时间上互补；酶类的酸碱环境要求与抑酸药相反。
5. **交叉怎么处理？** 同一药物在两个类别里出现时，写清两个落点，按作用部位与给药途径重新定位，而不是二选一。
6. **判断交给谁？** 由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南决定。

## 执行步骤

```text
1. 收口：把待判对象压成一句「作用或机制」，删掉药名与用途
2. 定侧：攻击侧 / 防御侧 / 两者之外
3. 定部位：腔面 / 壁细胞 / 黏膜表面 / 肠壁神经 / 胆道 / 氨代谢
4. 定方向：增强还是减慢、增加还是减少
5. 查制约：酸性环境、酸碱环境、时间互补
6. 处理交叉：两个落点分别是什么，按什么重新定位
7. 换指标：按部位选观察项目，说明为什么不能沿用上一套
8. 定去向：谁判断、依什么、如何留痕
```

## 硬约束

- **不写剂量、浓度、疗程与频次的量值。** 需要剂量时统一写「剂量与用法照底本」。
- **不作疾病诊断，不作病情与预后判定，不作适应证判定，不作疗效与优越性断言，不作优劣与排名。**
- **引文逐字。** 标「教材·药理学·第29章·29.x.y」，核不到原文就不引；改写须标明是改写。
- **不写品名、厂商、剂型规格与价格。**
- **联合只讲机制互补。** 不涉方案参数与疗程天数；涉及幽门螺杆菌相关情形时同样如此。
- **不把选择性当优势。** 作用范围与不良反应谱同时收窄，评价须结合机制类别。

## 交付物

1. 一条定位：侧 → 部位 → 方向
2. 一条制约说明：这条作用在什么条件下被削弱或需要错开
3. 若遇交叉：两个落点各是什么，按什么重新定位
4. 一份观察清单：按部位选定的指标，以及不能沿用的理由
5. 一句边界句：本章只描述部位与类别关系，判断归属另行

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 药名当分类 | 说不清为何能联用、为何有风险 | 回到第 1、2 问 |
| 分类硬塞 | 交叉被当成教材错误 | 用第 5 问重新定位 |
| 忽略制约 | 把保护药与抑酸药写成效应相加 | 补第 4 问 |
| 方向混用 | 泻药与止泻药说成同一方向 | 回到第 3 问 |
| 选择性当优势 | 「选择性高所以更好」 | 改写为「范围与不良反应谱同时收窄」 |
| 把机制与用法分开 | 讲了机制却不提给药时机 | 机制叙述必须与用法相对应 |

## 边界

本 Skill 只处理「一个药物或一条表述 → 侧与部位」的定位与交叉处理，不涉及剂量、适应证与临床决策。本章内容为教学材料，不构成用药建议；任何涉及个体的用药评估须由具备资质的人员依现行法律法规与规范作出。
