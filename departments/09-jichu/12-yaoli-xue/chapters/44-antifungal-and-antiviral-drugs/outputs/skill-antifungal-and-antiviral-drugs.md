# Skill：抗真菌药与抗病毒药——选择性只剩一步之差

## 何时用

- 读到「某药选择性好 / 某药只对真菌有效 / 某药须空腹」，需要判断这句话的机制起点
- 要解释「为什么同一类药里，一个必须静脉、一个可以口服」
- 遇到「耐药了换另一个有没有用」，需要判断耐药断在靶点还是活化环节
- 要把不良反应转成观察项，却不确定按肾、血液、肝还是按输注过程
- 有人问「为什么这两类药的品种这么少」

## 核心判据（六问）

1. **选择性来自哪里？** 两个来源：结构差别（真菌有细胞壁、膜以麦角固醇为主；人体细胞没有细胞壁、膜以胆固醇为主）与活化差别（前药须经病原体独有的酶转化）。靶点相同也能有选择性，只要活化的门只对病原体开。
2. **靶点是哪一个？** 抗真菌四类：膜上麦角固醇、羊毛固醇去甲基化酶、葡聚糖合成酶、核酸合成（前药活化后）。抗病毒：逆转录酶、蛋白酶、整合酶、神经氨酸酶、病毒DNA聚合酶、脱壳环节、宿主导向。
3. **杀还是抑？** 由靶点位置决定：膜与壁的完整性被破坏，菌体短时间内失去生存条件；合成环节被抑制，菌体仍可凭既有成分维持一段时间。
4. **同类为什么不同用法？** 吸收条件（胃酸、食物、制剂形式）、分布去处（脑脊液、角质层、眼内）、代谢身份（唑类既是底物又是抑制药）。同类管不到剂型。
5. **相互作用的坐标在哪？** 酶诱导、酶抑制、排泄环节竞争、机制上的相互影响——四类，方向与主语要写清。
6. **观察项从哪里来？** 从靶点与体内过程反推：肾（尿量与电解质）、血液（血象）、肝（肝酶与胆红素相关指标）、输注过程、神经系统。

## 执行步骤

```text
1. 收口：把待判句子压成一句「机制、体内过程类别或观察要求」
2. 定来源：结构差别还是活化差别，二选一
3. 定靶点：四类抗真菌靶点 / 七类抗病毒环节，写清
4. 定杀抑：由靶点位置推出，不用强弱词
5. 查用法：吸收条件、分布去处、代谢身份，逐条对
6. 找相互作用：四类坐标，写方向与主语
7. 落观察：肾 / 血液 / 肝 / 输注 / 神经，按类别词
8. 定耐药：靶酶、外排、生物膜、活化缺失，并回答换药有没有用
```

## 硬约束

- **不写剂量、浓度、疗程、血浆药物水平与检验判定界限的量值。** 需要剂量时统一写「剂量与用法照底本」。
- **不作适应证判定，不作病情与预后判定，不作疗效断言与优越性断言，不作药物之间的优劣与等级排名。**
- **引文逐字。** 标「教材·药理学·第44章·44.x.y」，核不到原文就不引；改写须标明是改写。
- **不写品牌名称、生产企业、剂型规格与价格。**
- **表述取中间一档。** 说「有抑制作用」而不说「能解决感染」；说「较为常见」而不说「一定发生」；说「机制上配合」而不说「应当采用」。
- **不确定就写下来。** 标待核实，不用推测填空。

## 交付物

1. 五段拆解：选择性来源 → 靶点 → 杀或抑 → 体内过程 → 观察项
2. 一句来源判断：结构差别还是活化差别
3. 一句用法判断：这条表述受哪一环限制（胃酸、食物、分布、代谢身份）
4. 一句耐药判断：断在靶点、外排、生物膜还是活化缺失
5. 一句边界句：本章只描述机制与类别，判断归属另行

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 选择性当形容词 | 说不出来源 | 走第 2 步，结构差别还是活化差别 |
| 同类当同性质 | 「同一类药服法一样」 | 查吸收条件：同类之内差别可以很大 |
| 杀抑当强弱 | 「杀菌比抑菌好」 | 改为靶点位置的推论 |
| 相互作用只说「有」 | 无法核对 | 写明四类坐标与方向 |
| 耐药只说「耐药了」 | 不回答换药有没有用 | 断在活化环节的，换不依赖该环节的药才可能有用 |
| 偷给量值 | 顺手写疗程或监测区间 | 改为「剂量与用法照底本」 |

## 边界

本 Skill 只处理「一条表述 → 五段拆解」的判定，不涉及剂量、适应证与临床决策。本章内容为教学材料，不构成用药建议；任何涉及个体的用药评估须由具备资质的人员依现行法律法规与规范作出。
