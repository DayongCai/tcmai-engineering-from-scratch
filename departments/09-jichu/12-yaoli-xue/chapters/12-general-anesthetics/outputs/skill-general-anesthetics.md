# Skill：全身麻醉药——三句话、五个成分、两条通路

## 何时用

- 读到「某药麻醉作用强 / 苏醒快 / 循环稳定」，需要判断它覆盖了哪个成分
- 要解释「同样产生意识消失，为什么一个升血压、一个降血压」
- 遇到复合麻醉方案，需要判断哪几处是互补、哪几处是叠加
- 恢复期出现呼吸抑制或肌力恢复不全，需要顺着时程去找环节
- 有人问「MAC 是多少」，需要把问题放回「动态关系」而不是给一个数

## 核心判据（六问）

1. **哪一句？** 抑制是进行性的（深度可分级，风险同源）、成分是可分的（才有分工）、机制是网络的（单一受体解释不全）。三句话各管一件事，不要混用。
2. **哪个成分？** 意识消失与遗忘、镇痛、抑制不良反射、肌肉松弛、抑制应激反应。答不出成分，这条表述就没有落点。
3. **哪条通路？** 增强抑制性传递（γ-氨基丁酸 A 型受体、甘氨酸受体）还是抑制兴奋性传递（N-甲基-D-天冬氨酸受体）；吸入药另有多靶点清单。
4. **时程由什么决定？** 起效看分布，维持看清除，苏醒看再分布与代谢产物的活性；吸入药按肺泡分压、血/气分配系数、通气量、肺血流量四者定位。
5. **互补还是叠加？** 不同层面的同一过程被削弱是互补；同一层面的抑制被双重增强是叠加。前者支持减量，后者增加风险。
6. **判断交给谁？** 由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床规范决定。

## 执行步骤

```text
1. 收口：把待判句子压成一句「作用或性质」，删掉药名与用途
2. 定句：落在进行性 / 可分 / 网络三句中的哪一句
3. 定成分：五个成分里覆盖了哪几个，缺口由谁补
4. 定通路：增强抑制 / 抑制兴奋；多靶点的写「网络」，不简化
5. 定时程：分布 / 清除 / 再分布 / 代谢产物活性，选一个主要的
6. 定分工：与谁互补、与谁叠加，叠加属哪一种
7. 找风险：这条作用在哪一步变成风险（延髓、气道、分泌物、体温）
8. 落观察：多出哪一项、要不要分阶段；判断归具备资质的人员
```

## 硬约束

- **不写剂量、浓度、最低肺泡有效浓度、给药速度、目标值与维持时长的量值。** 需要剂量时统一写「剂量与用法照底本」。
- **不作适应证判定，不作病情与预后判定，不作疗效断言与优越性断言，不作等级排名。**
- **引文逐字。** 标「教材·药理学·第12章·12.x.y」，核不到原文就不引；改写须标明是改写。
- **不写品名、厂商、剂型规格与价格，不写仪器型号与品牌。**
- **数字会过期。** 凡「随条件移动」的量（最低肺泡有效浓度是最典型的），一律写关系不写数值。
- **不确定就写下来。** 标待核实，不用推测填空。

## 交付物

1. 一张成分—药物对应：这条表述覆盖哪一块，缺哪一块
2. 一处通路定位：增强抑制还是抑制兴奋，落到具体受体或通道
3. 一句时程口诀：起效 / 维持 / 苏醒各由什么决定
4. 一处叠加判断：互补还是双重增强，观察含义有何不同
5. 一句边界句：本章只描述作用与类别，判断归属另行

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 五合一 | 用「麻醉作用强」概括五个成分 | 逐成分说覆盖与缺口 |
| 单受体化 | 把网络机制写成单一受体 | 补多靶点层次 |
| 混淆叠加 | 把双重增强当互补，误以为安全 | 说明叠加类型 |
| 时程归错 | 把再分布说成代谢清除 | 按三句话逐一核对 |
| 偷给 MAC | 写出随条件移动的数值 | 改为关系描述，剂量照底本 |
| 记录漏项 | 只写「情况稳定」 | 拆成意识、呼吸、循环、体温、肌力 |

## 与相邻章节的接缝

- 第 11 章（局部麻醉药）：同样讲阻断传导，但靶点在单个通道、意识保持清醒；本章的靶点升到网络，意识消失成为主要表现。
- 第 13 章（镇静催眠药）：苯二氮䓬类与巴比妥类在复合麻醉中承担镇静成分，其别位调节机制在那一章写实。
- 第 18 章（镇痛药）：阿片类的 μ 受体机制与呼吸抑制，在本章只作为「镇痛成分」的承载者出现。
- 第 3 章（药动学）：本章的「分布—清除—再分布」在那一章有参数化写法，本章只用定性关系。

## 边界

本 Skill 只处理「一条表述 → 成分与通路的定位」，不涉及剂量、适应证与临床决策。本章内容为教学材料，不构成用药建议；麻醉的实施与气道管理一律由具备资质的人员按现行规范决定。
