# Skill：药效学——四级台阶与两套语言

## 何时用

- 读到「作用强 / 起效快 / 选择性高 / 安全范围大」，需要判断这句站在哪一级台阶
- 要解释「同一药物为什么在心脏抑制、在平滑肌收缩」
- 遇到「某药比某药好」的讨论，需要把比较拉回参数与条件
- 要判断一条效应属治疗作用还是副反应，却不确定依据是什么
- 写观察记录时，不确定该分几栏、指标选哪一层

## 核心判据（六问）

1. **哪一级？** 药物作用（分子事件）→ 药理效应（整体表现）→ 机制（受体或非受体）→ 参数（效能、效价强度、斜率、亲和力、内在活性）。层次不清，句子就既不像机制也不像观察。
2. **哪条途？** 受体途径（识别、转导、放大、表现）还是非受体途径（理化性质、酶、通道、转运体、核酸与蛋白合成、免疫调节与补充）。具体药物归属哪条途，按底本表述，不作跨类推定。
3. **哪个受体？** 族与亚型（M1–M5、N1 与 N2、α1 与 α2、β1–β3）。亚型分布既能解释治疗作用，也能预告无关效应——这是选择性相对性的来源。
4. **哪个参数？** 效能说上限，效价强度说剂量位置，斜率说敏感程度，亲和力说结合，内在活性说转导。五个词不能互相替代。
5. **治疗还是副反应？** 判据是用药目的，不是效应本身。同一效应在两种目的下可以分属两类，记录必须写明目的。
6. **判断交给谁？** 由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南决定。教材给判据，不给个案结论。

## 执行步骤

```text
1. 收口：把待判句子压成一句「性质或关系」，删掉药名与「优于」类比较
2. 分层：药物作用 / 药理效应，混淆处标出是哪半句
3. 归途：受体途径四步，或非受体途径七类，选一个主要的
4. 落受体：族与亚型，用分布解释句中的器官效应，并预告无关效应
5. 读参数：效能 / 效价强度 / 斜率 / 亲和力 / 内在活性，写明可比条件
6. 定性质：治疗作用三类，或不良反应七类，给出归类依据
7. 找指标：症状 / 体征 / 实验室 / 功能，写明与机制隔几环
8. 定去向：谁判断、依什么、如何留痕
```

## 硬约束

- **不写剂量、浓度、滴度、效价、半数有效量与血药浓度的量值。** 需要剂量时统一写「剂量与用法照底本」。
- **不作疾病诊断，不作病情与预后判定，不作适应证判定。**
- **不作疗效断言与优越性断言，不作药物之间的优劣与等级排名。** A 型与 B 型、完全与部分激动药、竞争性与非竞争性拮抗，都是机制分类，不是等级。
- **引文逐字。** 标「教材·药理学·第2章·2.x.y」，核不到原文就不引；改写须标明是改写。
- **结合不等于效应。** 亲和力高不等于作用强，占据率高不等于反应大——储备受体、阈值与信号放大都会打破直线关系。
- **机制未明就写未明。** 用「机制尚未完全阐明」，不用推测填空。

## 交付物

1. 一次分层：这句话说的是作用还是效应
2. 一条机制路径：受体四步或非受体七类中的哪一条
3. 一个受体亚型与它的分布解释
4. 一个参数与它的可比条件
5. 一句边界句：判断归具备资质的人员，教材不替代专业判断

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 作用与效应混写 | 分子事件与整体表现搅在一句里 | 分半句，各用各的语言 |
| 把亲和力当效力 | 「结合得牢所以作用强」 | 补内在活性，说明结合只是必要条件 |
| 曲线三读数混用 | 用位置说明上限 | 位置说剂量，高度说上限，斜率说敏感 |
| 分类当排序 | 「A 型轻，所以更安全」 | 分类只提示观察重点 |
| 受体名当结论 | 「作用于 β 受体所以安全」 | 补亚型与分布，预告无关效应 |
| 偷给量值 | 顺手写半数有效量 | 改为「剂量与用法照底本」 |
| 记录写评价 | 「效果不错」「明显好转」 | 改写为可测量的指标与中性描述 |

## 与相邻章节的接缝

- 第 1 章（绪论）：本章的「三个层次」在那里只是承诺，在这里兑现为受体与机制两节。
- 第 3 章（药动学）：本章的「效应滞后于血药浓度」在那一章成为药时曲线与房室模型的问题。
- 第 4 章（影响药物效应的因素）：本章的「条件性」在那里分成药物、机体、其他三组。
- 第 5 章起（传出神经）：受体亚型表在那里成为分类主纲，本章的亲和力与内在活性是它的语言基础。

## 边界

本 Skill 只处理「一条表述 → 四级台阶」的拆解，不涉及剂量、适应证与临床决策。本章内容为教学材料，不构成用药建议；任何涉及个体的用药评估须由具备资质的人员依现行法律法规与规范作出。
