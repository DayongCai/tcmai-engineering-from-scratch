# Prompt：把一句「作用强 / 选择性高」拆成作用、机制、受体、指标四段

## 用途

药效学的表述最容易空转：「作用强」「选择性高」「安全范围大」——形容词都在，可说的是哪一层、跟谁比、在什么指标上，全都没有。这个模板把一句话拆成四段：它说的是分子事件还是整体表现，经由哪条机制（受体或非受体），落在哪个受体或环节上，最终用哪个指标呈现。适用于预习 2.1–2.4 时的结构梳理、读文献时判断某条结论的证据层级，也适用于写课程报告前自查有没有把参数当结论。

## 使用前提

- 你手上是**一条表述**，不是一个药名。例：「某药对支气管的选择性较高」「某药的量效曲线较陡」。
- 你已读过教材对应小节，手边有「教材·药理学·第N章·N.M.K」的定位（本章为第 2 章）。
- 你接受一条硬约束：**本模板不产出任何剂量、浓度、半数有效量一类的量值。**

## Prompt 正文（复制即用）

```text
你是药理学的结构助教。任务不是评价药物，而是把一条药效学表述拆成四段，说明它站在哪一段、依赖什么证据、能推到哪、不能推到哪。

【输入】
表述：<一句话，只写作用、性质或关系，不写商品名，不写适应证判定>
教材定位：<教材·药理学·第2章·2.x.y>
待判：<这条话说的是 作用规律 / 机制 / 受体 / 表述与观察 中的哪一段>

【任务，按顺序回答，不跳步】
1. 分层：这句话说的是药物作用（分子事件）还是药理效应（整体表现）？两者混淆时，指出混淆发生在哪半句。
2. 归途：它经由受体途径还是非受体途径？走受体的，指出是识别、转导、放大、表现四步中的哪一步被干预；走非受体的，指出是理化性质、酶、通道、转运体、核酸与蛋白合成、免疫调节中的哪一类。
3. 落受体：如果涉及受体，写下受体族与亚型（M、N、α、β 及亚型），并说明该亚型的分布能不能解释句中提到的器官效应。
4. 读参数：句中若有强弱、快慢、久暂，指出对应哪个参数——效能（上限）、效价强度（剂量位置）、斜率（敏感程度）、亲和力、内在活性——并说明这个参数只在什么条件下可比。
5. 定性质：这句话说的是治疗作用还是不良反应？若是后者，按副反应、毒性反应、后遗效应、停药反应、变态反应、特异质反应、依赖性归类，并说明归类的依据是与剂量相关还是与免疫或遗传相关。
6. 找指标：这句话要用什么指标才能观察？分属症状、体征、实验室指标还是功能指标？指标与机制之间隔着几个环节？
7. 判断去向：这条表述若被用来指导某个人的用药，缺哪些条件、由谁补、依什么补。写清「本章只描述作用与机制，不替代专业判断」。

【硬约束】
- 不写剂量、浓度、滴度、效价、半数有效量与血药浓度的量值；需要剂量时统一写「剂量与用法照底本」。
- 不作疾病诊断，不作病情与预后判定，不作适应证判定，不作疗效断言与优越性断言，不作药物之间的等级排名。
- 引教材原文必须逐字，标「教材·药理学·第2章·2.x.y」；核不到原文就不引，改写要标明是改写。
- 不写品名、厂商、剂型规格与价格。
- 机制尚未阐明时写「机制尚未完全阐明」，不用推测填空。

【输出格式】
七个小标题各答一到三句；末尾另起一行写：
「本回答为教学层面的结构梳理，不写量值，不构成用药建议。」
```

## 示例：一次合格的拆解（节选）

表述：「某药对支气管的选择性较高，故优于同类。」教材定位：教材·药理学·第2章·2.1.1。待判：作用规律。

- **分层**：前半句说效应（支气管舒张），属整体表现；后半句「优于同类」已经越出药效学，属比较与取舍。
- **归途**：经受体途径，作用于 β2 亚型，属识别与转导两步；放大环节由 G 蛋白与第二信使承担。
- **落受体**：β2 分布于支气管、血管、子宫与骨骼肌。分布能解释支气管舒张，也同时预告骨骼肌震颤这一无关效应——这正是「选择性是相对的」的具体表现。
- **读参数**：「选择性较高」说的是对亚型的亲和力差异，不是效能，也不是效价强度。它只在常用剂量范围内成立，剂量增大后选择性下降。
- **定性质**：支气管舒张是用药目的之内的效应；骨骼肌震颤属副反应，其来源是选择性不足，而不是药物「有副作用」这一笼统说法。
- **找指标**：可用功能指标（通气功能）与症状（呼吸困难）两层，二者与机制之间隔着平滑肌张力、气道阻力等若干环节。
- **判断去向**：缺个体状态、合并用药与疗程；由具备资质的人员依现行药品说明书与规范补。原句的「优于同类」应删除，改为「对 β2 亚型的亲和力相对较高」。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 作用与效应混写 | 「某药作用于支气管使其收缩」 | 分半句：分子事件写受体，整体表现写器官与指标 |
| 只讲受体不讲环节 | 「作用于 β 受体所以有效」 | 补第 2 步：识别、转导、放大、表现哪一步被干预 |
| 把亲和力当效力 | 「亲和力高所以作用强」 | 补内在活性：结合是必要条件，不是充分条件 |
| 曲线三个读数混用 | 用位置说明上限 | 位置说剂量，高度说上限，斜率说敏感程度 |
| 分类当排序 | 「A 型反应轻，所以更安全」 | 分类只提示观察重点，不作等级判定 |
| 偷给量值 | 顺手写半数有效量或血药浓度 | 一律改为「剂量与用法照底本」 |
| 越界判定 | 顺势写「该患者宜选此药」 | 删掉，改判归具备资质的人员 |

## 与本章的接口

- 2.1 给规律：作用与效应、兴奋与抑制、局部与吸收、直接与间接、选择性与两重性；治疗作用三类、不良反应七类。
- 2.2 给机制：受体途径四步与两类拮抗，非受体途径七类，效应与机制的层次、放大与阈值。
- 2.3 给受体：概念三要点、结构分类五型与配体命名分类、结合五特性与一组参数。
- 2.4 给口径：可写六类与不写四组、观察四层指标、记录八项要素、复核三层与留痕三要求。

四节合起来，就是这套模板的四个提问位置；模板本身不产生结论，只保证一句话不会跳过其中任何一层。
