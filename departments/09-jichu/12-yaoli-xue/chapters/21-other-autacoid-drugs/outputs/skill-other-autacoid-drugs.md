# Skill：其他影响自体活性物质的药物——三步定位、四层位点、一个共用酶

## 何时用

- 读到「某药抗炎 / 止喘 / 止痛 / 扩血管」，需要判断它站在链条的哪一层
- 要解释「阻断同一个介质，为什么有的药起效快、有的只能长期控制」
- 要解释「同一物质为什么在血管上舒张、在子宫上收缩」
- 要解释「某药为什么会出现干咳或血管性水肿」
- 有人拿「抑制合成酶与阻断受体哪个好」来问，需要把问题换成「覆盖范围与选择性的权衡」

## 核心判据（七问）

1. **哪一层？** 生成（底物释放、合成酶）→ 释放（供体、稳定肥大细胞膜）→ 受体（亚型选择性拮抗或激动）→ 降解（降解酶抑制剂）。
2. **释放侧还是拮抗侧？** 减少生成或促其失活属释放侧，阻断受体属拮抗侧；两侧不互相替代。
3. **哪一个靶点？** 酶、受体亚型、转运体、可溶性鸟苷酸环化酶——靶点类型决定效应快慢与不良反应谱。
4. **哪条偶联通路？** Gq（收缩、分泌）、Gs（舒张、分泌）、Gi（负反馈）、通道型（快速兴奋）——通路决定方向。
5. **时程对不对？** 速发效应与长期控制效应分属不同机制；按即刻缓解的预期使用长期控制类药物，是最常见的判断错误。
6. **共用底物或共用酶吗？** 若是，结论只能写方向，并注明受酶表达、底物供应与氧化还原状态的限制。
7. **判断交给谁？** 由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南决定。

## 执行步骤

```text
1. 收口：把待判句子压成一句「性质或类别」，删掉药名与用途
2. 定层：生成 / 释放 / 受体 / 降解，四层定位
3. 分侧：释放侧还是拮抗侧；降解侧单列，它不属于前两者
4. 定靶点：酶、受体亚型、转运体或受体酶，写出具体名称
5. 核组织：该靶点在哪些组织表达，效应方向是否随亚型改变
6. 查时程：速发还是较慢；较慢者不能按即刻缓解使用
7. 查交互：共用底物、共用酶、同一信号通路的上下游叠加
8. 定去向：谁判断、依什么、如何留痕
```

## 四条主线的最小骨架

| 主线 | 关键环节 | 一眼判据 |
|---|---|---|
| 膜磷脂代谢物 | 磷脂酶 A2 → 环氧化酶 / 5-脂氧酶 → 受体 | 共用底物，故抑制一方可能改变另一方产物 |
| 白三烯 | 5-脂氧酶 → 半胱氨酰白三烯 → CysLT1 | 收缩持续较久且不被抗组胺药阻断 |
| 5-羟色胺 | 合成、储存、释放、再摄取、降解；七型受体 | 5-HT3 是通道型，其余为 G 蛋白偶联 |
| 多肽 | 肾素-血管紧张素与激肽释放酶-激肽 | ACE 即激肽酶 II，抑制它同时改两个系统 |
| 一氧化氮 | 生成、释放、受体酶、降解四层 | 供体不依赖内皮完整性；与降解层叠加属禁止合用 |

## 硬约束

- **不写剂量、浓度、滴度、效价、给药频次与疗程的量值。** 需要剂量时统一写「剂量与用法照底本」。
- **不作适应证判定，不作病情与预后判定，不作疗效断言与优越性断言，不作等级排名。**
- **方向不是幅度。** 共用底物与通路交互的结论只写趋势，教材明确写了不能据此推断所有品种。
- **类别替换不等于优劣。** 干咳换类、酶抑制换受体阻断，属机制层面的替代关系，教材不作高下判断。
- **引文逐字。** 标「教材·药理学·第21章·21.x.y」，核不到原文就不引；改写须标明是改写。

## 常见错误

- 把合成酶抑制剂与受体拮抗药都叫「拮抗药」：前者在生成层，后者在识别层，作用位点不同。
- 把「同一物质在不同组织方向相反」当成记错了：那是受体亚型分布的差异，如 EP1 收缩而 EP2 舒张。
- 把代谢特点当分类轴：前药与活性药同属一类，代谢特点应在体内过程一节叙述。
- 把「较少见」读成「没有」：不影响缓激肽代谢的一类干咳较少，但血管性水肿仍可发生。
