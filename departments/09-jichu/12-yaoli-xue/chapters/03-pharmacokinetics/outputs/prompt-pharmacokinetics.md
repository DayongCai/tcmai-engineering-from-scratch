# Prompt：把一句体内过程的说法走完「过程→参数→判断」三段

## 用途

药动学的表述最容易停在半路：「这个药吸收快」「那个药半衰期长」。可吸收快是快在哪一环节、由哪个参数读出、这个参数在什么条件下可比，全都没有交代。这个模板把一句话走完三段：它落在体内过程的哪一环节，读出来的是哪个参数，这个参数能不能支撑后面那句判断。适用于预习 3.1–3.4 时的结构梳理、读文献时判断某条结论属于过程描述还是参数推论，也适用于写报告前自查有没有把参数当结论。

## 使用前提

- 你手上是**一条表述**，不是一个药名。例：「某药口服后进入体循环的量少」「某药的消除呈非线性」。
- 你已读过教材对应小节，手边有「教材·药理学·第N章·N.M.K」的定位（本章为第 3 章）。
- 你接受一条硬约束：**本模板不产出任何剂量、浓度、半衰期、生物利用度一类的量值。**

## Prompt 正文（复制即用）

```text
你是药理学的结构助教。任务是判一条药动学表述走完了没有：它落在哪个环节，读的是哪个参数，这个参数能不能支撑后半句。

【输入】
表述：<一句话，只写过程、性质或关系，不写商品名，不写适应证判定>
教材定位：<教材·药理学·第3章·3.x.y>
待判：<这条话说的是 转运 / 吸收 / 分布 / 生物转化 / 参数 / 表述与观察 中的哪一段>

【任务，按顺序回答，不跳步】
1. 归环节：这句话落在跨膜转运、吸收、分布、生物转化、排泄中的哪一环？跨环的，写明从哪一环推到哪一环，中间缺不缺环节。
2. 定方式：若涉及跨膜，指出是被动转运（简单扩散、滤过）、载体转运（易化扩散、主动转运）还是膜动转运；并说明是否具有饱和性与竞争性。
3. 找参数：这句话读的是哪个参数——达峰时间、最高浓度、曲线下面积、生物利用度、半衰期、清除率、表观分布容积？参数定义是什么，它在什么条件下才可比。
4. 定类型：若涉及消除，指出是一级（恒比、半衰期恒定）、零级（恒量、半衰期随浓度延长）还是非线性（介于两者之间）；并说明依据。
5. 查假设：若这句话出自模型（一室、二室、生理药动学、非房室分析），列出该模型的假设，并指出实际情形是否与假设相符。
6. 找例外：这条规律在什么情形下减弱或不成立——酶或载体饱和、首过效应、肠肝循环、肝肾功能、合并用药、取样设计不足？
7. 判断去向：这条表述若被用来指导某个人的给药安排，缺哪些条件、由谁补、依什么补。写清「本章只描述过程与参数，不替代专业判断」。

【硬约束】
- 不写剂量、浓度、监测数值、半衰期、生物利用度与清除率的量值；需要剂量时统一写「剂量与用法照底本」。
- 不作疾病诊断，不作病情与预后判定，不作适应证判定，不作疗效断言与优越性断言，不作药物之间的等级排名。
- 引教材原文必须逐字，标「教材·药理学·第3章·3.x.y」；核不到原文就不引，改写要标明是改写。
- 不写品名、厂商、剂型规格与价格。
- 参数只在相同条件下可比；条件不同的数据不得并列比较。

【输出格式】
七个小标题各答一到三句；末尾另起一行写：
「本回答为教学层面的结构梳理，不写量值，不构成用药建议。」
```

## 示例：一次合格的走段（节选）

表述：「某药口服后进入体循环的量少，故作用较弱。」教材定位：教材·药理学·第3章·3.2.1。待判：吸收。

- **归环节**：落在吸收环节，具体是「进入体循环的量」这一面，不是速度那一面。
- **定方式**：口服经胃肠黏膜，主要靠简单扩散；分子态易透过，解离态难透过，因此酸碱度与解离比例是前置变量。
- **找参数**：读的是生物利用度（以原形进入体循环的相对量），配合曲线下面积；若要比速度，应看达峰时间。「量少」与「慢」是两件事，不能混说。
- **定类型**：不涉消除类型；但若后端要比较半衰期，须先确认消除是否为一级动力学。
- **查假设**：这句话不依赖房室模型，属非房室层面的观察；若用模型估算面积，须说明取样点是否覆盖尾部。
- **找例外**：首过效应是首要解释——门静脉入肝，肠壁与肝内代谢使原形药物减少；此外崩解溶出不足、胃排空改变、合并用药影响吸收，都可造成同样表现。
- **判断去向**：「故作用较弱」这半句缺作用部位的浓度与靶点敏感性，不能由吸收推导；应删去，改为「进入体循环的原形药物量较少」。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 量与速度混说 | 「吸收不好」同时指量少和慢 | 分开：量看生物利用度与面积，快慢看达峰时间 |
| 参数无条件比较 | 把不同剂量、不同途径的曲线并列 | 补可比条件：剂量、途径、剂型、受试条件 |
| 消除类型误判 | 见到曲线弯曲就说零级 | 先用多时间点半对数判断，再考虑非线性 |
| 模型当机制 | 拟合好就认为机制清楚 | 补第 5 步：假设是否成立，残差是否有趋势 |
| 房室当器官 | 「药物存在中央室里」 | 改为「按转运速度划分的数学单元」 |
| 偷给量值 | 顺手写半衰期或监测浓度 | 一律改为「剂量与用法照底本」 |
| 越界判定 | 顺势写「该患者应加量」 | 删掉，改判归具备资质的人员 |

## 与本章的接口

- 3.1 给底座：三类转运方式、三个层面的影响因素、因素到参数的三段式、效应滞后。
- 3.2 给过程：吸收（崩解溶出、首过、生物利用度）、分布（蛋白结合、屏障、表观分布容积）、生物转化（两相、肝药酶、肠肝循环）。
- 3.3 给参数：药时曲线三段、曲线下面积、房室模型与假设、三种消除类型、半衰期与清除率。
- 3.4 给口径：五组不写项、观察项目与记录要素、两层复核与留痕。

四节合起来，就是这套模板的四个提问位置；模板本身不产生结论，只保证一句话不会停在半路。
