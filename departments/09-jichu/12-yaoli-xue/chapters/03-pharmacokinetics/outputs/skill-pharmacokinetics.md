# Skill：药动学——一条曲线、两类模型、三种消除

## 何时用

- 读到「吸收快 / 分布广 / 消除慢」，需要判断这句话读的是哪个参数
- 要解释「同一药物同一剂量，为什么这次峰值高、那次峰值低」
- 遇到「曲线弯了就是零级」的说法，需要核对判断依据
- 有人把房室模型的结果直接当机制结论
- 要把观察整理成能复核的记录，却不确定该记哪些条件

## 核心判据（六问）

1. **哪一环？** 跨膜转运 → 吸收 → 分布 → 生物转化 → 排泄 → 参数。跨环的写明中间缺不缺环节。
2. **哪种转运？** 被动（简单扩散、滤过：不耗能、无饱和）／载体（易化扩散、主动转运：有饱和与竞争）／膜动（胞吞、胞吐）。这一条决定了后面会不会出现非线性。
3. **哪个参数？** 达峰时间与最高浓度说速度与综合结果，曲线下面积与生物利用度说进入体循环的量，半衰期说消除快慢，清除率说消除能力，表观分布容积说分布程度。七个词不能互相替代。
4. **哪种消除？** 一级（恒比、半衰期恒定）／零级（恒量、半衰期随浓度延长）／非线性（介于两者之间）。判断依据是多时间点的半对数曲线，不是单点观察。
5. **哪个假设？** 一室／二室／生理药动学／非房室分析，各有假设；假设不成立时拟合再好也不能用。
6. **判断交给谁？** 由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南决定。教材给规律，不给方案。

## 执行步骤

```text
1. 收口：把待判句子压成一句「过程或关系」，删掉药名与「故作用强/弱」类推论
2. 归环节：转运 / 吸收 / 分布 / 生物转化 / 排泄
3. 定方式：被动 / 载体 / 膜动；有无饱和与竞争
4. 找参数：这句话读的是哪一个，定义是什么
5. 写条件：剂量、途径、剂型、受试条件，缺哪项写哪项
6. 定类型：一级 / 零级 / 非线性，给出依据
7. 查假设：若用模型，列假设并核对实际
8. 找例外：饱和、首过、肠肝循环、肝肾功能、合并用药、取样不足
9. 定去向：谁判断、依什么、如何留痕
```

## 硬约束

- **不写剂量、浓度、监测数值、半衰期、生物利用度、清除率与分布容积的量值。** 需要剂量时统一写「剂量与用法照底本」。
- **不作疾病诊断，不作病情与预后判定，不作适应证判定。**
- **不作疗效断言与优越性断言，不作药物之间的优劣与等级排名。** 参数大小是描述，不是排序。
- **引文逐字。** 标「教材·药理学·第3章·3.x.y」，核不到原文就不引；改写须标明是改写。
- **参数只在相同条件下可比。** 剂量、途径、剂型、受试条件不同的曲线不得并列比较。
- **模型是工具。** 拟合良好不等于机制正确；输出须与实测数据并列呈现。
- **总论不套具体药。** 本章讲规律与参数，具体药物的体内过程在各论，不作跨类推定。

## 交付物

1. 一次归环节：这句话落在体内过程的哪一环
2. 一个转运方式或消除类型：并给出饱和与竞争的判断
3. 一个参数与它的可比条件
4. 一句假设核对：模型假设是否成立
5. 一句边界句：判断归具备资质的人员，教材不替代专业判断

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 量与速度混说 | 「吸收不好」含义不明 | 量看生物利用度与面积，快慢看达峰时间 |
| 无条件比较 | 把不同剂量的曲线并列 | 补齐剂量、途径、剂型、受试条件 |
| 消除类型误判 | 见曲线弯就说零级 | 用多时间点半对数判断，再考虑非线性 |
| 模型当机制 | 拟合好就以为机制清楚 | 核对假设与残差趋势 |
| 房室当器官 | 「药物存在中央室」 | 改为「按转运速度划分的数学单元」 |
| 分布容积当解剖容积 | 由容积推断某组织药量 | 补血流、屏障与亲和力三条 |
| 偷给量值 | 顺手写半衰期或监测浓度 | 改为「剂量与用法照底本」 |

## 与相邻章节的接缝

- 第 1 章（绪论）：本章的四个参数在那里只是被点名，在这里成为整套算法。
- 第 2 章（药效学）：本章的「效应滞后」在那一章成为效应室与量效关系的问题。
- 第 4 章（影响药物效应的因素）：本章的「个体差异」在那一章分成生理、病理、年龄与性别三组。
- 第 5 章起（各论）：具体药物的体内过程在那一层展开，本章只给判据。

## 边界

本 Skill 只处理「一条表述 → 三段走完」的判定，不涉及剂量、适应证与临床决策。本章内容为教学材料，不构成用药建议；任何涉及个体的用药评估须由具备资质的人员依现行法律法规与规范作出。
