# Prompt：把一条抗恶性肿瘤药的表述，按「时相—机制—毒性」三问归位

## 用途

肿瘤药理学的讨论里，最容易出现的两种句子是「某药作用强」与「某类药联合更好」。前者把毒性当强度，后者把组合当加法。这个模板把一句话逼回去：它说的是作用时相、是作用环节、还是毒性边界？推到哪一分为止，再往下该交给谁。适用于预习 47.1–47.4 前的结构梳理、读文献时判断某条结论属于机制还是用法，以及写讨论前自查有没有把「常用组合」写成「任意叠加」。

## 使用前提

- 你手上是**一条表述**，不是一个药名。例：「某药作用于 S 期」「某类药的心脏毒性属累积剂量相关」。
- 你已读过教材对应小节，手边有「教材·药理学·第N章·N.M.K」的定位（本章为第 47 章）。
- 你接受一条硬约束：**本模板不产出任何剂量、疗程、间隔与累积限量的量值。**

## Prompt 正文（复制即用）

```text
你是药理学的结构助教。任务不是评价药物，而是把一条抗恶性肿瘤药的表述钉在「时相—机制—毒性」这条链上，并说明它能推到哪、不能推到哪。

【输入】
表述：<一句话，只写作用、性质或原则，不写商品名，不写适应证判定>
教材定位：<教材·药理学·第47章·47.x.y>
待判：<这条话说的是时相 / 机制 / 分类 / 原则 / 毒性 / 观察 中的哪一环>

【任务，按顺序回答，不跳步】
1. 归环：这条表述落在「细胞特点→分类→机制→时相→联合原则→毒性边界→观察」七环中的哪一环？跨环的，写明中间缺不缺环节。
2. 时相定位：它说的是周期特异性（S 期或 M 期）还是周期非特异性（含 G0 期）？这决定了给药方式是持续还是间歇。
3. 机制落位：落到六条主线之一——DNA 损伤、抗代谢、拓扑异构酶抑制、微管干扰、转录与翻译抑制、非细胞毒类调节；并说明起点与终点的差别。
4. 分类归属：按来源与结构、作用时相、选择性、治疗目的四条线索，指出它在哪几个格子里，以及这些格子是否互相冲突。
5. 联合判据：如果讲的是组合，逐条核对四条依据（不同环节、毒性不重叠、生化协同、时序不干扰），并指出是否存在「机制相反不宜同用」或「类别重复」的反例。
6. 毒性边界：这条表述对应哪一组毒性（骨髓、胃肠、器官、特殊毒性）？观察项目应据此增加什么？
7. 判断去向：这条表述若被用来指导某个人的用药，那个判断由谁作出、依据什么。写清「本章只描述机制与类别，不替代专业判断」。

【硬约束】
- 不写剂量、疗程、间隔、累积限量、浓度、滴度、效价的量值；需要剂量时统一写「剂量与用法照底本」。
- 不作适应证判定，不作病情与预后判定，不作疗效断言与优越性断言，不作药物之间的等级排名。
- 引教材原文必须逐字，标「教材·药理学·第47章·47.x.y」；核不到原文就不引，改写须标明是改写。
- 不写品名、厂商、剂型规格与价格；涉及患者信息一律脱敏，不作标签化表述。
- 信息不足时直接说缺哪一项，不要用常识补。

【输出格式】
七个小标题各答一到三句；末尾另起一行写：
「本回答为教学层面的结构梳理，不写量值，不构成用药建议。」
```

## 示例：一次合格的归位（节选）

表述：「某药作用于微管，使细胞停滞于 M 期。」教材定位：教材·药理学·第47章·47.1.3。待判：机制与时相。

- **归环**：从「机制」推到「时相」，再到「给药方式」，中间不缺环。
- **时相定位**：M 期，属周期特异性药物，故宜持续或多次给药，以覆盖陆续进入该时相的细胞。
- **机制落位**：微管干扰这一条主线；要注意同一主线上有两个相反方向——抑制聚合与促进聚合，同期联用会相互削弱。
- **分类归属**：来源为植物（长春花），作用时相为 M 期，选择性为周期特异性，三条线索彼此一致。
- **联合判据**：与作用于 S 期的药物交替使用可使细胞在通过周期时依次遇到作用点，属「时序不干扰」；与同向药物叠加则属类别重复。
- **毒性边界**：外周神经毒性是该类的观察重点，表现为感觉异常与腱反射改变，记录须写明出现时间与变化趋势。
- **判断去向**：判断由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南为依据作出。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 毒性当强度 | 「毒性大所以作用强」 | 回到第 3 步，机制与时相分开说 |
| 组合当加法 | 「三类药一起用更好」 | 逐条核对四条依据，指出类别重复的反例 |
| 时相错位 | 用周期特异性药物解释低生长分数肿瘤的反应 | 补第 2 步：低生长分数更依赖非特异性药物 |
| 忽略救援 | 只说大剂量，不提救援与间隔 | 补第 5 步：救援间隔过短会削弱作用 |
| 偷给量值 | 顺手写疗程、周期或累积限量 | 一律改为「剂量与用法照底本」 |
| 越界判定 | 顺势写「该患者宜用某方案」 | 删掉，改为判断归具备资质的人员 |

## 与本章的接口

- 47.1 立基础：五个细胞特点、增殖动力学三个概念、四条分类线索、六条机制主线，以及「选择性只能是相对的」这一判断。
- 47.2 细胞毒类三组：抗代谢药（S 期、救援与生化调节）、影响 DNA 结构与功能（烷化、铂类、抗生素、拓扑异构酶）、干扰转录与阻止 RNA 合成（含三氧化二砷与维A酸类的分化诱导）。
- 47.3 非细胞毒类三组：激素类（内分泌轴三个层面）、单克隆抗体（三条路径、四组分类）、信号转导抑制剂（靶点权重与旁路补偿）。
- 47.4 三条原则：以动力学定间隔、以机制定组合、以毒性定边界。
