# Skill：抗恶性肿瘤药——三条原则，一张机制表

## 何时用

- 读到「某药作用强 / 某类药联合更好」，需要把这句话拉回时相或机制
- 要解释「为什么同类药不能叠、异类药也不能随便叠」
- 遇到低生长分数肿瘤对周期特异性药物反应有限，需要说清理由
- 要说明为什么「有效」与「有毒」在这类药上几乎是同一件事
- 要把毒性观察整理成能复核的记录，却不确定该按哪几组分类

## 核心判据（六问）

1. **哪一环？** 细胞特点 → 分类（来源与结构、作用时相、选择性、治疗目的）→ 机制（DNA 损伤、抗代谢、拓扑异构酶、微管、转录与翻译、非细胞毒类）→ 时相 → 联合原则 → 毒性边界 → 观察。
2. **哪个时相？** S 期、M 期，或含 G0 期的各期；时相决定持续给药还是间歇给药。
3. **哪条机制主线？** 起点不同、终点相近；起点决定与谁协同，终点解释毒性为何叠加。
4. **组合凭什么成立？** 四条依据：不同环节、毒性不重叠、生化协同、时序不干扰。反例有两类：机制相反（微管方向相反）、类别重复（同属烷化剂）。
5. **毒性属于哪一组？** 骨髓、胃肠、器官（心、肺、肾、神经、肝）、特殊（外渗、过敏、肿瘤溶解、生殖与远期）。
6. **判断交给谁？** 由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南决定。

## 执行步骤

```text
1. 收口：把待判句子压成一句「性质或作用」，删掉药名与用途
2. 定环：七环定位，跨环的写明中间环缺不缺
3. 定时相：S 期 / M 期 / 各期，据此定持续还是间歇
4. 落机制：六条主线选一，说明起点与终点
5. 查归属：四条分类线索，指出格子是否冲突
6. 核联合：四条依据逐条过，找机制相反或类别重复
7. 划边界：毒性组别与观察项目
8. 定去向：谁判断、依什么、如何留痕
```

## 硬约束

- **不写剂量、疗程、间隔、累积限量、浓度、滴度、效价的量值。** 需要剂量时统一写「剂量与用法照底本」。
- **不作适应证判定，不作病情与预后判定，不作疗效断言与优越性断言，不作等级排名。**
- **引文逐字。** 标「教材·药理学·第47章·47.x.y」，核不到原文就不引；改写须标明是改写。
- **不写品名、厂商、剂型规格与价格。**
- **不作标签化表述。** 涉及患者的叙述一律中性，不作道德评判，信息按伦理审查与知情同意的要求处理。
- **不确定就写下来。** 标待核实，不用推测填空。

## 交付物

1. 一条归位链：细胞特点 → 分类 → 机制 → 时相 → 联合 → 毒性
2. 一处机制定位：这条表述的起点在哪、终点在哪
3. 一条边界判断：对应的毒性组别与观察项目
4. 一句边界句：本章只描述机制与类别，判断归属另行

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 毒性当强度 | 用毒性大小推断作用强弱 | 机制与时相分开说，删掉强度排序 |
| 组合当加法 | 认为多一类药必然更好 | 四条依据逐条核对，指出类别重复 |
| 时相错位 | 用 S 期药物解释低生长分数肿瘤 | 补生长分数与 G0 期这一环 |
| 忽略救援 | 只讲大剂量，不提救援与间隔 | 补生化协同与间隔核对 |
| 靶点崇拜 | 「越新的靶点越好」 | 改为「越贴合该肿瘤的生长依赖越好」 |
| 偷给量值 | 疗程与累积限量无来源 | 改为「剂量与用法照底本」 |
| 越界判定 | 「该患者宜用某方案」 | 删掉，判断归具备资质的人员 |

## 与相邻章节的接缝

- 第 46 章（抗寄生虫药）：两章都讲比例性杀灭与联合，但那一章的联合依据是生活史阶段互补，本章是周期时相与通路互补。
- 第 45 章（抗结核病药及抗麻风病药）：同样以「联合不等于叠加」为纪律，但那一章的耐药来自菌群突变的自发出现，本章还多一条「凋亡缺陷导致多药耐药」。
- 第 48、49 章（免疫抑制药与免疫增强药）：本章的免疫检查点抑制剂与那两章共用免疫学基础，但评价口径不同——本章看靶点与毒性，那两章看环节与监测。
- 第 3 章（药动学）：本章的「分布与消除决定给药安排」在那一章有参数化写法，本章只用定性关系。

## 边界

本 Skill 只处理「一条表述 → 时相与机制」的判定，不涉及剂量、适应证与临床决策。本章内容为教学材料，不构成用药建议；任何涉及个体的用药评估须由具备资质的人员依现行法律法规与规范作出，并以现行药品说明书为依据。
