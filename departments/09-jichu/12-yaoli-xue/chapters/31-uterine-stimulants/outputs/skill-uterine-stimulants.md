# Skill：子宫兴奋药——一条谱系、三问归属、四维观察

## 何时用

- 读到「某药作用强、维持久、可用于加强宫缩」，需要判断这句话说的是机制还是方案
- 要解释「为什么同样加强宫缩，有的药能调整、有的药一用上就难拉回」
- 遇到配伍问题（与抑制药同用、与升压药同用），需要把冲突定位到环节而不是禁忌清单
- 要把给药期间的观察整理成能复核的记录，却不确定该分几栏
- 有人拿「哪一类子宫兴奋药更好」来问，需要把讨论拉回谱系

## 核心判据（七问）

1. **哪一组？** 垂体后叶激素类（多肽）／前列腺素类（二十碳不饱和脂肪酸衍生物）／麦角生物碱类（生物碱）／传统中药类。组别决定化学稳定性与给药途径。
2. **选择性高不高？** 高者子宫以外效应少，反应多与宫缩本身相关；低者还要顾及血管、消化道与中枢。选择性决定观察范围。
3. **宫体与宫颈同向吗？** 缩宫素：宫体兴奋、宫颈松弛；前列腺素：宫体兴奋、宫颈软化（双向）；麦角新碱：二者均兴奋。方向差异即用途差异。
4. **可逆吗？** 能靠调整给药较快逆转的，观察密度可前移；不易逆转的（麦角新碱剂量稍大时），观察项须提前设定、密度须提高。
5. **效应形态变了吗？** 节律性收缩与张力持续升高是两种状态，不是同一条曲线的两端；观察记「有没有舒张」，不记「强不强」。
6. **反方向是谁？** β2 激动药、镁盐、钙通道阻滞药、前列腺素合成酶抑制药；冲突落在胞内钙与收缩装置，不在「同类不同类」。
7. **判断交给谁？** 由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南决定。

## 执行步骤

```text
1. 收口：把待判句子压成一句「作用或性质」，删掉药名与用途
2. 归属：来源 → 作用部位 → 教材节序，三问是否彼此印证
3. 定选择性：子宫以外效应少 / 一并出现；推出观察范围
4. 定方向：宫体（兴奋/松弛）× 宫颈（兴奋/松弛/软化）
5. 定可逆：能否靠调整给药较快逆转；不能的，观察密度提高
6. 定形态：是节律性收缩还是张力持续升高；记舒张，不记强度
7. 落观察：子宫、母体、胎儿、局部四维中，这条表述要求多写哪一栏
8. 定去向：谁判断、依什么、如何留痕
```

## 硬约束

- **不写剂量、浓度、给药速度、疗程时长的量值。** 需要剂量时统一写「剂量与用法照底本」。
- **不作适应证判定，不作病情与预后判定，不作疗效断言与优越性断言，不作等级排名。**
- **引文逐字。** 标「教材·药理学·第31章·31.x.y」，核不到原文就不引；改写须标明是改写。
- **不写品名、厂商、剂型规格与价格。**
- **涉及妊娠与分娩的叙述只到类别与机制。** 不写个体评判，不作人群标签化；同一件事写成「某时点出现某现象」而不是「某人属于某类人」。
- **中药类不补结论。** 只写类别与配伍关系，配伍当独立变量，不与化学药物作优劣比较。
- **不确定就写下来。** 标待核实，不用推测填空。

## 交付物

1. 一条谱系定位：哪一组、选择性高或低、落在哪一端
2. 一处方向判定：宫体与宫颈各自的方向，是否同向
3. 一个可逆性判定：能否靠调整给药逆转，观察密度因此如何变
4. 一栏观察补充：四维中因此要多写什么
5. 一句边界句：本章只描述机制与类别，判断归属另行

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 谱系当排行 | 把「选择性低」说成「效果差」 | 改为「效应谱宽、可逆性差、观察密度高」 |
| 方向混同 | 把宫颈松弛与宫颈软化当同一件事 | 分写宫体与宫颈两个方向 |
| 形态混同 | 用「收缩更强」描述张力持续升高 | 改记为「舒张不完全」，记形态不记强度 |
| 抑制当禁忌 | 只说「不宜与某类同用」不说为什么 | 定位到胞内钙与收缩装置 |
| 越界写流程 | 把「需要加强宫缩的环节」写成处置步骤 | 删步骤，只留类别与机制 |
| 偷给量值 | 给药速度、频次、疗程无来源 | 改为「剂量与用法照底本」 |
| 记录写评价 | 「宫缩良好」代替所见 | 写频率、静息张力、主诉这类可观察项 |

## 与相邻章节的接缝

- 第 9 章（拟肾上腺素药）：利托君经 β2 受体与环磷酸腺苷通路松弛平滑肌，与那一章的受体分类共用一套语言。
- 第 22 章（作用于心血管离子通道的药物）：钙通道阻滞药减少钙内流的机制在那一章展开，本章只用到「方向一致」这一层。
- 第 21 章（其他自体活性物质）：前列腺素的生成、受体亚型与代谢在那一章更完整，本章只取子宫与宫颈两处效应。
- 第 32 章（抗贫血药）：产后出血与铁缺乏的衔接属临床表现，本章只写到「子宫收缩对肌层血管的压迫」这一机制环节。
- 第 4 章（影响药物效应的因素）：本章的激素环境、年龄与肝肾功能，在那一章被展开为一般框架。

## 边界

本 Skill 只处理「一条表述 → 谱系位置」的判定，不涉及剂量、适应证与临床决策。本章内容为教学材料，不构成用药建议；任何涉及个体的用药评估须由具备资质的人员依现行法律法规与规范作出。
