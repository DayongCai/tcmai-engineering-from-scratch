# Skill：绪论——一套读法，四问加一问

## 何时用

- 开课前想知道这门课到底在训练什么，而不只是要背多少药名
- 读到「某药作用强 / 起效快 / 维持久」，需要判断这句话站在哪一层、缺哪几个条件
- 遇到「这个药属于哪一类」的争论，需要把讨论从归类拉回判据
- 写课程报告前自查：有没有把参数写成结论、把分类写成取舍、把教材写成处方
- 有人拿「哪个药更好」来问，需要把问题还原成可比性

## 核心判据（五问）

1. **哪一面？** 药物改变机体（药效学）还是机体处置药物（药动学）？两者都涉及时，写明哪一面是主、哪一面是前提。只写一面的叙述，多半是没读完。
2. **哪一层？** 靶点（受体、酶、通道、转运体）→ 机制（信号转导、功能改变）→ 整体（药理作用、临床类别、不良反应类别）。层次不清，机制与效应就会被混为一谈。
3. **哪个参数、什么条件？** 强弱与久暂要落到具体参数：效价强度（剂量位置）、最大效应（上限）、半衰期（消除快慢）、生物利用度（进入体循环的份量与速度）、清除率（消除能力）、表观分布容积（分布倾向）。参数只在相同条件下可比，脱离条件谈强弱，谈的是别的东西。
4. **哪条分类轴？** 按系统、按结构、按用途。换一条轴，同一对象可能归到别处——这是观察角度不同，不是矛盾。分类是索引，不是围墙。
5. **判断交给谁？** 由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南决定。教材给判据，不给个案结论。

## 执行步骤

```text
1. 收口：把待判句子压成一句「性质或关系」，删掉药名、商品信息与用途结论
2. 分面：药效一侧 / 药动一侧 / 两者兼有（写明主次）
3. 定层：靶点 / 机制 / 整体；跨层的写明缺哪一环
4. 落参数：这句话依赖哪个参数，该参数的可比条件是什么
5. 查分类轴：换一条轴是否改变归属；改变则说明是角度差异
6. 定证据层级：经验记述 / 离体 / 在体 / 临床研究 / 上市后观察
7. 补条件：指标、途径、对象状态、合并用药，缺哪一项就写缺哪一项
8. 定去向：谁判断、依什么、如何留痕
9. 改写：保留机制与类别，删去量值、优劣、等级与绝对化表述
```

## 硬约束

- **不写剂量、浓度、滴度、效价与疗程的量值。** 需要剂量时统一写「剂量与用法照底本」。
- **不作疾病诊断，不作病情与预后判定，不作适应证判定。**
- **不作疗效断言与优越性断言，不作药物之间的优劣与等级排名。** 教材列出参数差别，是为了描述，不是为了排序。
- **引文逐字。** 标「教材·药理学·第1章·1.x.y」，核不到原文就不引；改写须标明是改写。
- **不写品名、厂商、剂型规格与价格。**
- **不确定就写下来。** 标待核实，不用常识填空。

## 交付物

1. 一次归位：这条表述落在哪一面、哪一层
2. 一个参数与它的可比条件
3. 一条分类轴与换轴后的归属
4. 一句证据层级的说明
5. 一句边界句：判断归具备资质的人员，教材不替代专业判断

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 把参数当结论 | 「效价强度高所以更好」 | 补可比条件，删去取舍结论 |
| 跨层直推 | 由离体曲线说临床起效快 | 补层次与证据层级两环 |
| 分类当围墙 | 「属于某类，所以只能用于某类情形」 | 换一条轴看归属，说明是角度差异 |
| 把沿革当结论 | 「古方有记载，所以有效」 | 回到验证：传统经验是起点，结论须经实验与临床研究 |
| 把新方法当证据 | 模型输出直接写进结论 | 加限定：结果须经实验验证 |
| 越界判定 | 顺势写「该患者宜用」 | 改为判断归具备资质的人员 |
| 记录当笔记 | 只写印象，不写条件与时点 | 按观察与记录要求补齐要素，缺口注明不详 |

## 与相邻章节的接缝

- 第 2 章（药效学）：本章的「三个层次」在那一章展开为受体途径与非受体途径、亲和力与内在活性、量效曲线的三个读数。
- 第 3 章（药动学）：本章列出的四个参数在那一章成为整套算法，并加上房室模型与消除类型。
- 第 4 章（影响药物效应的因素）：本章的「条件性」在那一章分成药物、机体、其他三组因素。
- 第 5 章起（各论）：每一章的具体药物，都是这套读法的应用实例；分类轴在传出神经系统一章被用到极致。

## 边界

本 Skill 只处理「一条表述 → 四个位置」的归位，不涉及剂量、适应证与临床决策。本章内容为教学材料，不构成用药建议；任何涉及个体的用药评估须由具备资质的人员依现行法律法规与规范作出。
