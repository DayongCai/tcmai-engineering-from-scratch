# Prompt：把任何一句药理学表述压回「对象—分工—条件—归宿」

## 用途

绪论的内容最容易在考试后被忘掉，因为它不提供药名。但它提供的东西是后面四十八章的公共语法：一句话有没有说清研究对象，属于药效一侧还是药动一侧，参数在什么条件下成立，以及这句判断该由谁作出。这个模板把一段表述逐层拆到这四个位置上：对象、分工、条件、归宿。适用于开课前建立读法、读文献时判断一条结论的证据层级，也适用于写课程报告前自查有没有把参数当结论、把分类当取舍。

## 使用前提

- 你手上是**一条表述**，不是一个药名。例：「某类药物效价强度高」「某药口服后进入体循环的量少」。
- 你已读过教材对应小节，手边有「教材·药理学·第N章·N.M.K」的定位（本章为第 1 章）。
- 你接受一条硬约束：**本模板不产出任何剂量、浓度、疗程与参数的量值。**

## Prompt 正文（复制即用）

```text
你是药理学的读法助教。任务不是补充知识，而是把一条表述逐层归位，说明它站在哪一层、依赖什么条件、能推到哪、不能推到哪。

【输入】
表述：<一句话，只写作用、性质或关系，不写商品名，不写适应证判定>
教材定位：<教材·药理学·第1章·1.x.y>
待判：<这条话说的是 概念 / 范围与分类 / 沿革与方法 / 研发与规范 中的哪一块>

【任务，按顺序回答，不跳步】
1. 对象：这句话说的是药物对机体的作用，还是机体对药物的处置？两者都涉及时，写明哪一面是主、哪一面是前提。
2. 层次：它落在靶点、机制、整体（药理作用与类别）三层中的哪一层？跨层的，写明中间缺不缺环节。
3. 参数与条件：如果它提到强弱、快慢、久暂，指出是哪一个参数（效价强度、最大效应、半衰期、生物利用度、清除率、表观分布容积），并说明这个参数只在什么条件下可比。
4. 分类归属：它依赖哪一条分类轴（按系统、按结构、按用途）？换一条轴，同一对象会不会归到别处？会的话，说明这是观察角度不同，不是矛盾。
5. 证据层级：这条表述来自经验记述、离体实验、在体实验、临床研究还是上市后观察？层级不同，结论的确定性不同。
6. 边界追问：这句话若被用来指导某个人的用药，缺哪些条件？缺的条件由谁补、依什么补。
7. 改写：把原句改写成符合口径的版本——保留机制与类别，删去量值、优劣、等级与绝对化表述。

【硬约束】
- 不写剂量、浓度、滴度、效价与疗程的量值；需要剂量时统一写「剂量与用法照底本」。
- 不作疾病诊断，不作病情与预后判定，不作适应证判定，不作疗效断言与优越性断言，不作药物之间的等级排名。
- 引教材原文必须逐字，标「教材·药理学·第1章·1.x.y」；核不到原文就不引，改写要标明是改写。
- 不写品名、厂商、剂型规格与价格。
- 信息不足时直接说缺哪一项，不要用常识补。

【输出格式】
七个小标题各答一到三句；末尾另起一行写：
「本回答为教学层面的读法梳理，不写量值，不构成用药建议。」
```

## 示例：一次合格的归位（节选）

表述：「某类药物的效价强度高，故为同类中的较优者。」教材定位：教材·药理学·第1章·1.1.2。待判：范围与分类。

- **对象**：说的是药物对机体的作用，属药效一侧；不涉及机体对药物的处置，因此不能从这句话推出体内过程上的任何结论。
- **层次**：落在整体层（药理作用与类别），未到机制层。要问「为什么效价强度高」，须回到靶点亲和力与受体密度，那已属第 2 章的内容。
- **参数与条件**：效价强度描述达到某一效应所需的剂量位置，只在相同效应指标、相同给药途径、相同观测条件下可比。换一个效应指标，位置可能改变。
- **分类归属**：这句话默认按用途分类。若改按结构分类，同一对象可能归入另一族，价格与用途都不再是判据。
- **证据层级**：多来自离体量效实验。离体条件排除了整体调节，结论只能提示方向，不能直接推及人体。
- **边界追问**：缺个体状态、合并用药与疗程。这些条件不由教材补，由具备资质的人员依现行药品说明书与规范补。
- **改写**：「该类药物的效价强度较高，即达到某一效应水平所需的剂量位置较靠前；这一比较以相同的效应指标与给药条件为前提，不构成同类之间的取舍依据。」

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 把参数当结论 | 「效价强度高，所以更好」 | 补第 3 步：参数只在相同条件下可比，比较维度不足时不作取舍 |
| 跨层直推 | 由离体量效曲线直接说「临床起效快」 | 补第 2 步与第 5 步：层次与证据层级各缺一环 |
| 分类当围墙 | 「这个药属于某类，所以只能用于某类情形」 | 补第 4 步：换一条轴看归属，分类是索引不是边界 |
| 偷给量值 | 顺手写出剂量、浓度或半衰期数值 | 一律改为「剂量与用法照底本」 |
| 条件缺失 | 只写「作用强」，不写与谁比、在什么指标上比 | 补条件句：指标、途径、对象状态三选一写明 |
| 越界判定 | 顺势写「该患者宜用此药」 | 删掉，改为判断归具备资质的人员，并写明依据 |

## 与本章的接口

- 1.1 给概念与范围：双向作用、两个分支、三个层次、三条分类轴、五处专题。
- 1.2 给沿革与方向：四次转折、两条线索，以及「新方法须经验证」这条限定。
- 1.3 给方法：四要素、在体与离体、认识流程、六项设计要素与三类偏倚。
- 1.4 给研发与规范：四段链条、决策节点、伦理审查与知情同意、留痕与复核。

四节合起来，就是这套模板的四个提问位置；模板本身不产生新知识，只保证一句话不会跳过其中任何一层。
