# Prompt：把一条人工合成抗菌药的表述拆成「靶点—选择性—耐药—部位」

## 用途

人工合成抗菌药这一章的四类药，最容易被误当成一个整体：都是合成的、都抗菌、都叫「沙星/磺胺/硝基」。但它们的靶点、选择性来源、耐药机制与作用部位几乎不可互换。这个模板要求把一句话拆成四步：打哪个靶点、选择性凭什么成立、耐药从哪条路来、药物到底到不到那个部位。适用于预习第 39 章 39.1–39.4、读药敏报告时判断「敏感」是否等于「可用」、以及写讨论前自查有没有把某一类的结论套到另一类上。

## 使用前提

- 你手上是**一条表述**，不是一个药名。例：「某类药对厌氧菌有效」「某药可用于尿路感染」。
- 你已读过对应小节，手边有「教材·药理学·第N章·N.M.K」级定位（本章为第 39 章）。
- 你接受三条硬约束：**不写具体剂量与浓度；不写判读界值与菌株标识；不作适应证判定。**

## Prompt 正文（复制即用）

```text
你是药理学的结构助教。任务不是评价药物，而是把一条人工合成抗菌药的表述拆成「靶点—选择性—耐药—部位」四步，说明它能推到哪、不能推到哪。

【输入】
表述：<一句话，只写作用、机制、性质或用途类别，不写商品名，不写适应证判定>
教材定位：<教材·药理学·第39章·39.x.y>
待判：<这条话说的是分类 / 作用与机制 / 体内过程 / 用途类别 / 不良反应类别 中的哪一环>

【任务，按顺序回答，不跳步】
1. 归类：属喹诺酮类、磺胺类与甲氧苄啶、硝咪唑类，还是硝基呋喃类？四类的划分依据各不相同（母核与分代 / 时间与用途 / 硝基与代数 / 吸收与部位），先说清这句话用的是哪一套。
2. 定靶点：拓扑异构酶（回旋酶与拓扑异构酶Ⅳ）、叶酸代谢（二氢蝶酸合酶与二氢叶酸还原酶）、还是硝基还原后的活性中间体？若为前药，必须写出「活化发生在病原体内」这一前提。
3. 选择性凭什么：酶的结构差异、代谢通路差异（细菌须自造叶酸而人可摄取）、还是氧化还原环境差异？三种来源对应三类不良反应方向，写清「作用与毒性同源」表现在哪。
4. 耐药走哪条路：靶点突变、外排增强、通透性下降、灭活或保护蛋白、活化酶失活？说明本类的耐药是「单点」还是「多靶点」性质，以及是否与其他类别交叉。
5. 到不到那个部位：吸收程度、血中与尿中水平的相对关系、组织分布与蛋白结合。凡「局部作用」的品种，必须写出它为何不能外推到全身。
6. 不良反应的同源解释：结晶尿、光敏、肌腱与软骨、QT 间期延长、双硫仑样反应、溶血——每一条要能指回作用机制或体内过程，而不是罗列症状。
7. 判断去向：说明「本章只描述分类、机制与类别，不替代专业判断」；具体决策由具备资质的人员依现行法律法规与规范、以现行药品说明书为依据作出。

【硬约束】
- 不写具体剂量、浓度、疗程与判读界值；不写菌株标识；需要剂量时统一写「剂量与用法照底本」。
- 不作疾病诊断，不作适应证判定，不作疗效断言与优越性断言，不作类别之间的优劣与等级排名。
- 引教材原文必须逐字，标「教材·药理学·第39章·39.x.y」；核不到原文就不引，改写须标明是改写。
- 不写品名、厂商、剂型规格与价格。
- 信息不足时直接说缺哪一项，不要用常识补。

【输出格式】
七个小标题各答一到三句；末尾另起一行写：
「本回答只作学习用途，不构成用药建议；剂量与用法照底本，具体决策由具备资质的人员依现行药品说明书与规范作出。」
```

## 一个走完的例子（脱敏合成）

表述：「这个药是合成的广谱抗菌药，所以和沙星类可以换着用。」走一遍：归类——「合成」只说明来源，不指向任何一类；「广谱」也不指向靶点，两句都空转；定靶点——未说明，追问；选择性——未说明，追问；耐药——若为硝基呋喃类，多靶点、耐药慢；若为喹诺酮类，单靶点、易筛选出敏感性下降的亚群，两者不可互换；到不到部位——呋喃妥因血中低、尿中高，沙星类组织分布广，互换会直接导致「用在该到的部位却到不了」；同源解释——呋喃妥因的肺与神经反应、沙星类的肌腱与 QT 问题，各自对应不同的机制；判断去向——「换着用」属适应证判定，退回。四步走完，一句「可以换着用」被拆成两套完全不同的机制与部位条件。

## 三条自查

1. 你的句子说的是「来源」还是「靶点」？只说「合成」「广谱」，等于没有信息。
2. 你的句子有没有把某一类的结论套到另一类？四类的划分依据都不同，套用必错。
3. 你的句子有没有出现剂量或界值？有，就改成「剂量与用法照底本」，或把数值挪进带 locator 的引文行。
