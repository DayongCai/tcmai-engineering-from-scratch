# Skill：四环素类与氯霉素类——两条起点不同、结论同构的链

## 何时用

- 读到「某类药影响牙齿与骨骼 / 某药吸收完全 / 某药对造血有影响」，需要判断这句话经过链条的哪几步
- 要解释「为什么同一类药里，一个必须随餐、一个必须空腹」
- 遇到「可逆的骨髓抑制」与「不可逆的再生障碍性贫血」并列，需要说清两者的剂量关系差别
- 要把「分布」直接转成观察项
- 有人问「为什么这两类结构不同却编在一章」

## 核心判据（六问）

1. **起点是什么？** 四环素类靠酚羟基与烯醇基与多价金属离子络合；氯霉素类靠高脂溶性与人工合成的硝基苯结构。起点不同，链不能混用。
2. **第一步落在吸收还是分布？** 同一起点常常落两处：络合既影响吸收（同服干扰），也影响分布（沉积于钙化组织）。
3. **药物到哪里？** 沉积于钙化组织、进入胎儿循环、中枢分布多（米诺环素）；氯霉素则广泛分布、能进脑脊液（无论脑膜有无炎症）、能过胎盘与乳汁。
4. **消除落在哪个器官？** 以肾排泄为主则看肾功能，以肝代谢为主则看肝功能，兼有两条途径则两者都看。
5. **风险怎么配对？** 可逆/不可逆、与剂量相关/无关——氯霉素的两个特殊风险正是按这两组配对立的。
6. **观察项从哪里来？** 从分布来（到哪里就看哪里）与从消除途径来（落在哪个器官就看那个器官）。不是凭经验加栏。

## 执行步骤

```text
1. 收口：把待判句子压成一句「结构性质、体内过程类别或不良反应类别」
2. 定起点：络合 / 穿透，二者不混
3. 补中段：起点推出的第一个体内过程后果（吸收或分布），不得跳到结论
4. 落部位：沉积、中枢、胎儿与乳汁，写清是哪一处
5. 定器官：肾排泄 / 肝代谢 / 双途径，决定看什么
6. 归类别：按教材的不良反应类别归档，归不进就标「本教材未列」
7. 回填机制：必须能回填到第 2 至 5 步中的某一步
8. 出观察项：分布到哪里、消除落在哪里，就写哪一栏
```

## 硬约束

- **不写剂量、浓度、疗程、血药浓度、药敏界值与参考区间的量值。** 需要剂量时统一写「剂量与用法照底本」。
- **不作适应证判定，不作病情与预后判定，不作疗效断言与优越性断言，不作两类之间的等级排名。**
- **引文逐字。** 标「教材·药理学·第43章·43.x.y」，核不到原文就不引；改写须标明是改写。
- **不写品名、厂商、剂型规格与价格。**
- **「到了」不等于「有效」。** 分布范围不等同于作用范围，还须看局部环境、组织结合与病原体位置。
- **不确定就写下来。** 标待核实，不用推测填空。

## 交付物

1. 一条链：结构起点 → 吸收或分布 → 部位 → 消除器官 → 不良反应类别
2. 一处跳步纠正：这条表述原来跳过了哪一步
3. 一句风险配对：可逆与不可逆、与剂量相关与无关
4. 一栏观察：分布与消除途径各给一条
5. 一句边界句：本章只描述机制与类别，判断归属另行

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 跳步 | 由络合直接说「不能同服」 | 补吸收这一步 |
| 起点混用 | 用四环素类的机制解释氯霉素 | 先写起点，两类分开推 |
| 分布当作用 | 「进得了脑脊液就能治中枢感染」 | 改为「分布—部位匹配」，不等同于作用 |
| 两类并列成一张表 | 机制与类别错配 | 按类分列，逐条回填机制 |
| 风险配对错 | 把两个特殊风险写成同一类 | 按可逆性、剂量关系两组分开 |
| 观察项凭经验 | 记录表臃肿或漏项 | 从分布与消除途径反推 |

## 与相邻章节的接缝

- 第 41 章（大环内酯类等）：氯霉素与大环内酯类、林可霉素类位点相邻，竞争同一区域；四环素类则在小亚基，不构成这一竞争。
- 第 42 章（氨基糖苷类）：同样作用于三十S亚基，但转运依赖呼吸链，与四环素类的质子梯度转运可作对照。
- 第 44 章（抗真菌药与抗病毒药）：氟胞嘧啶、阿昔洛韦的「须经病原体的酶活化」是本章「前药与选择性」思路的延伸。
- 第 3 章（药动学）：本章的吸收、分布、生物转化与排泄在那章有参数化写法，本章只用定性关系。

## 边界

本 Skill 只处理「一条表述 → 链条位置」的判定，不涉及剂量、适应证与临床决策。本章内容为教学材料，不构成用药建议；任何涉及个体的用药评估须由具备资质的人员依现行法律法规与规范作出。
