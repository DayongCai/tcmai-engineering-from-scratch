# Prompt：用一个「络合」或一个「穿透」，把一条表述推到底

## 用途

这一章的两类药，各自的因果链都由一个化学性质起步：四环素类靠母核上的酚羟基与烯醇基与多价金属离子络合，氯霉素类靠脂溶性高而穿透好。多数表述错误，都发生在链条的中段——由「络合」直接跳到「所以不能和牛奶同服」，却不说明这一步经过吸收；由「穿透好」直接跳到「所以能治脑膜炎」，却不说明这一步经过分布与部位匹配。这个模板要求把链条每一步都写出来，缺一步就标缺。

## 使用前提

- 你手上是**一条表述**，不是一个药名。例：「某类药影响牙齿与骨骼」「某药吸收完全、分布广」「某药对造血系统有影响」。
- 你已读过教材对应小节，手边有「教材·药理学·第N章·N.M.K」的定位（本章为第 43 章）。
- 你接受一条硬约束：**本模板不产出任何剂量、浓度、疗程与血药浓度的量值。**

## Prompt 正文（复制即用）

```text
你是药理学的结构助教。任务不是评价药物，而是把一条表述沿「结构—络合或穿透—吸收—分布—代谢与排泄—不良反应类别—观察项」推一遍，并指出链条断在哪一步。

【输入】
表述：<一句话，只写结构性质、体内过程类别或不良反应类别，不写商品名，不写适应证判定>
教材定位：<教材·药理学·第43章·43.x.y>
待判：<这条话说的是 结构 / 吸收 / 分布 / 代谢与排泄 / 不良反应类别 中的哪一环>

【任务，按顺序回答，不跳步】
1. 起点：这条表述的化学起点是什么？四环素类是氢化并四苯母核上的酚羟基与烯醇基（可与钙、镁、铝、铁等形成难溶络合物），氯霉素类是高脂溶性与人工合成的硝基苯结构。二者起点不同，后面的链也不同，不得混用。
2. 中段一步：由起点推出的第一个体内过程后果是什么？四环素类是吸收受食物与多价金属离子影响；氯霉素类是吸收迅速而完全。写出这一步，不要跳到结论。
3. 分布与部位：药物到哪里？四环素类沉积于钙化组织、可进入胎儿循环、米诺环素中枢分布较多；氯霉素类广泛分布、能进脑脊液（无论脑膜有无炎症）、能过胎盘、能进乳汁。指明这条表述对应哪一个部位。
4. 代谢与排泄：主要消除途径落在哪个器官？以肾排泄为主（四环素）还是以肝代谢为主（多西环素、氯霉素）？由此决定看肾功能还是肝功能。
5. 不良反应类别：把这条表述归入类别——胃肠道、二重感染、牙齿与骨骼、肝、肾、光敏、前庭（四环素类）；骨髓抑制、再生障碍性贫血、灰婴综合征、胃肠道、二重感染、过敏、视神经与周围神经、精神症状（氯霉素类）。归不进去的，标「本教材未列」。
6. 机制回填：这个不良反应类别的机制是什么？要能回填到第 2 至 4 步中的某一步（络合、沉积、线粒体核糖体受抑、肝内结合能力不足），回填不上的，说明这条表述缺机制支撑。
7. 观察项：按第 3 与第 4 步给观察重点——分布到哪里就观察哪里；主要消除途径落在哪个器官就看那个器官的功能状态。写成可记录的类别词，不写等级。
8. 判断去向：这条表述若被用来指导某个人的用药，那个判断由谁作出、依据什么。写清「本章只描述机制与类别，不替代专业判断」。

【硬约束】
- 不写剂量、浓度、疗程、血药浓度与药敏界值的量值；需要剂量时统一写「剂量与用法照底本」。
- 不作适应证判定，不作病情与预后判定，不作疗效断言与优越性断言，不作两类之间的等级排名。
- 引教材原文必须逐字，标「教材·药理学·第43章·43.x.y」；核不到原文就不引，改写要标明是改写。
- 不写品名、厂商、剂型规格与价格。
- 信息不足时直接说缺哪一项，不要用常识补。

【输出格式】
八个小标题各答一到三句；末尾另起一行写：
「本回答为教学层面的结构梳理，不写量值，不构成用药建议。」
```

## 示例：一次合格的推链（节选）

表述：「某类药会影响牙齿与骨骼。」教材定位：教材·药理学·第43章·43.1.3。待判：不良反应类别。

- **起点**：氢化并四苯母核上的酚羟基与烯醇基，可与钙形成难溶络合物。
- **中段一步**：这一步先落在吸收——同服含钙食物或药物使吸收减少；也落在分布——已进入体内的药物与钙化组织结合。两个后果，同一起点。
- **分布与部位**：沉积于骨骼与牙齿的钙化组织，与羟磷灰石中的钙结合而长期滞留；可透过胎盘进入胎儿循环，与胎儿钙化组织结合。
- **代谢与排泄**：与沉积无关，但解释滞留——储存部位血流少，释放慢。
- **不良反应类别**：牙齿与骨骼影响；妊娠期与婴幼儿期为观察重点。
- **机制回填**：回填到第 1 与第 2 步，链条完整。
- **观察项**：用药前询问并记录背景（妊娠期、婴幼儿期），用药后按类别观察；不设等级栏。
- **判断去向**：判断由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南为依据作出。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 跳步 | 由「络合」直接说「不能同服某食物」 | 补中间一步：吸收受干扰 |
| 起点混用 | 用四环素类的络合去解释氯霉素的分布 | 先写起点，两类分开推 |
| 分布当作用 | 「到了脑脊液所以能治中枢感染」 | 改为「分布—部位匹配」，并注明不等同于作用 |
| 两类并列成一张表 | 把不同机制的不良反应混排 | 按类分列，机制回填不得 |
| 机制缺位 | 只列不良反应，不写为什么 | 走第 6 步，回填不上就标缺 |
| 偷给量值 | 顺手写疗程或血药浓度 | 改为「剂量与用法照底本」 |

## 与本章的接口

- 43.1 讲四环素类：三个坐标、一条络合主线、三类耐药、八类不良反应。
- 43.2 讲氯霉素类：构型与活性、五十S 靶点、两个特殊风险（可逆与不可逆、与剂量相关与无关）。
- 43.3 收口径：七组不写项、两类药各自的观察清单、三层复核。
- 43.4 换坐标：吸收、分布、生物转化与排泄——同一件事的第二次叙述，用来做对照。
