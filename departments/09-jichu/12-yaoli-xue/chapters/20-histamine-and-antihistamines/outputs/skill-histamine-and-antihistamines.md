# Skill：组胺及抗组胺药——两个环节、四种亚型、两代分野

## 何时用

- 读到「某药抗过敏强 / 不犯困 / 作用持久」，需要判断这句话站在链的哪一环
- 要解释「阻断同一个 H1 受体，为什么有的犯困、有的不犯困」
- 要解释「抗组胺药为什么不影响胃酸，抑酸药为什么不影响支气管」
- 遇到「抗过敏药的止痒起效快，但对迟发相反应作用有限」这类边界问题
- 有人拿「第几代更好」来问，需要把讨论拉回受体谱与分布

## 核心判据（七问）

1. **哪一环？** 释放（免疫性 / 非免疫性 / 稳定肥大细胞膜）→ 受体亚型（H1 / H2 / H3 / H4）→ 受体占据（激动 / 竞争性拮抗 / 非竞争性拮抗）→ 中枢进入程度（脂溶性、解离度、外排转运体）。
2. **释放侧还是拮抗侧？** 减少释放影响「有多少组胺被放出来」，占据受体影响「放出来的组胺还能不能起作用」；两侧不互相替代。
3. **哪一型、哪条通路？** H1 走 Gq（效应快而短），H2 走 Gs（相对慢而持久），H3 与 H4 走 Gi；说得出偶联通路，才说得出效应方向。
4. **竞争性意味着什么？** 与组胺争夺同一位点，增加组胺可部分克服阻断；因此作用范围有限——对已释放的组胺有效，对释放过程无效，对迟发相反应作用有限。
5. **为什么进不了中枢？** 不用「第几代」当理由，用两条可查判据：脂溶性与解离度是否利于跨膜、是否为血脑屏障外排转运体的底物（P-糖蛋白在内皮腔面把药泵回血液）。
6. **时间差异从哪来？** 吸收（首过、食物、抗酸药结合）、分布（蛋白结合、组织亲和力、转运体）、代谢（有无活性代谢物、是否经同一酶系）、排泄（肾或胆道、功能状态）。
7. **判断交给谁？** 由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南决定。

## 执行步骤

```text
1. 收口：把待判句子压成一句「性质或类别」，删掉药名、用途与「最好」这类评价
2. 归环：四环定位，跨环的写明中间环缺不缺
3. 定侧：释放侧还是拮抗侧；拮抗侧再分竞争性与非竞争性
4. 定亚型：H1/H2/H3/H4 与 Gq/Gs/Gi 对齐，效应快慢由此推出
5. 查选择性：只阻断一型，还是兼及其他亚型与其他受体；不良反应类别随之宽窄
6. 查中枢：脂溶性、解离度、是否外排转运体底物三条里能答几条
7. 落体内过程：吸收 / 分布 / 代谢 / 排泄，指出这条表述的时间含义来自哪一环
8. 落观察：症状、体征、实验室类别、依从性四类中多出哪一栏，时点怎么设
9. 定去向：谁判断、依什么、如何留痕
```

## 典型判断对照

| 表述 | 归环 | 判据 |
|---|---|---|
| 某药减轻风团与瘙痒 | 受体占据（H1） | 竞争性阻断，抑制血管扩张与通透性增加 |
| 某药日间嗜睡少见 | 中枢进入程度 | 外排转运体底物，进入中枢的量有限 |
| 某药不影响胃酸 | 亚型选择性 | 对 H1 无作用即不影响血管与支气管；抑酸须落在 H2 |
| 某药与肝药酶抑制药合用风险增加 | 代谢 | 经同一酶系代谢，血中水平升高，复极延长风险增加 |
| 某药起效慢、维持长 | 吸收与代谢 | 吸收缓慢、活性代谢物仍具活性 |

## 硬约束

- **不写剂量、浓度、滴度、效价、给药频次与疗程的量值。** 需要剂量时统一写「剂量与用法照底本」。
- **不作适应证判定，不作病情与预后判定，不作疗效断言与优越性断言，不作等级排名。**
- **代际不是高低。** 第一代与第二代的差别在脂溶性、转运体与受体谱，教材只作类别归属。
- **引文逐字。** 标「教材·药理学·第20章·20.x.y」，核不到原文就不引；改写须标明是改写。
- **不写品名、厂商、剂型规格与价格**，药名一律用通用名。

## 常见错误

- 把「第几代」当成机制解释：代际是分类标签，机制是脂溶性与转运体。
- 把「抗过敏」当成一个作用：它至少分减少释放与阻断受体两种，位置不同。
- 把 H1 与 H2 的效应混在一张表里：H1 管血管、平滑肌与感觉神经末梢，H2 管胃酸与心脏的正性作用，两者在血管扩张上才是协同的。
- 把类别描述读成个体结论：「可见嗜睡」不是「此人会嗜睡」；这一条是本章三节写作规范的核心判据。
