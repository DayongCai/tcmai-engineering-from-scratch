# Skill：解热镇痛抗炎药与抗痛风药——两条线、六个环、一张分层表

## 何时用

- 读到「某药更安全 / 更有效 / 副作用更小」，需要拆成收益与代价两侧
- 要解释「同一药物为什么有三档用途」，且三档之间不能混
- 要解释「某药几乎不抗炎却仍是解热镇痛药」
- 遇到复方制剂，需要判断成分是否重复
- 遇到抗痛风药，需要判断它作用在生成、排泄、炎症还是尿液环境
- 要把不良反应整理成按环节归位的观察表，而不是背清单

## 核心判据（五问）

1. **哪条线？** 前列腺素线还是尿酸线。跨线的表述必须拆成两句分别判。
2. **哪一环？** 前列腺素线看同工型相对抑制；尿酸线看生成、排泄、炎症、尿液环境四环之一。
3. **成立条件是什么？** 抗血小板要「不可逆 + 无核」；抗炎要足够剂量；促排泄要肾功能尚可与尿量充足；秋水仙碱要结晶已沉积；碱化要尿液偏酸。写不出条件，用途就是空话。
4. **观察栏目怎么改？** 胃肠、肾、血液系统是前列腺素线常规；尿量、尿液性状、结石相关表现是促排泄药常规；肝功能与皮肤表现是抑制生成药常规。
5. **判断交给谁？** 由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南决定，并留痕。

## 执行步骤

```text
1. 收口：把待判句子压成一句「某一环被抑制 / 被改变」
2. 分线：前列腺素线 / 尿酸线，跨线的拆开
3. 定环：同工型选择性，或生成 / 排泄 / 炎症 / 尿液环境
4. 写条件：这一档用途凭什么成立
5. 推风险：收益的对侧是什么（黏膜 / 心血管 / 肝 / 肾 / 造血）
6. 落栏目：记录表因此多写什么
7. 查边界：疗效断言、优劣比较、绝对化、诊断与预后判定
8. 定去向：谁判断、依什么、如何留痕
```

## 硬约束

- **不写剂量、浓度、疗程与监测阈值的量值。** 需要剂量时统一写「剂量与用法照底本」。
- **不作适应证判定，不作病情与预后判定，不作疗效与优越性断言，不作等级排名。**
- **引文逐字。** 标「教材·药理学·第 17 章·N.M.K」，核不到原文就不引；改写须标明是改写。
- **不写品名、厂商、剂型规格与价格。**
- **复方必须逐成分列类别。** 只写制剂名等于放弃识别重复的唯一线索。
- **中药对照写到「方向对应」为止**，不写成替代方案，不作疗效断言。

## 交付物

1. 一条定位链：线 → 环 → 成立条件 → 用途类别 → 观察栏目
2. 一处收益与代价的对照：买到什么、付出什么
3. 一条观察切换说明：换了类别，观察项如何随之切换
4. 一句边界句：本章只写类别与机制，判断归属另行

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 把三档用途当强弱刻度 | 混档使用，机制上不成立 | 写出每档的成立条件 |
| 把选择性当安全 | 忽略心血管一侧的代价 | 补「收益伴随代价」与三处边界 |
| 由类别名推作用谱 | 把苯胺类当抗炎药 | 回到外周环氧合酶抑制强度 |
| 只记复方制剂名 | 成分重复导致叠加 | 逐成分列类别 |
| 把秋水仙碱当降尿酸药 | 急性期与间歇期定位错乱 | 回到「作用于反应而非量」 |
| 记录里写「反应轻微」 | 判断混入事实，复核无空间 | 只写所见，判断另设一栏 |

## 与相邻章节的接缝

- 第 18 章（镇痛药）：本类针对前列腺素介导的发热与轻中度疼痛，对锐痛与内脏绞痛作用有限；两类药在术后镇痛中按机制互补而非相互替代。
- 第 16 章（退行性疾病药）：水杨酸类与促尿酸排泄药的转运竞争，与那一章的转运体叙述同一思路。
- 第 20 章（组胺及抗组胺药）：抗炎与抗过敏都涉及自体活性物质，但作用点分别在环氧合酶与受体。
- 第 3 章（药动学）：本章四段体内过程在那一章有参数化写法，本章只用定性关系。

## 边界

本 Skill 只处理「一句表述 → 四格定位」的判定，不涉及剂量、适应证与临床决策。本章内容为教学材料，不构成用药建议；任何涉及个体的用药评估须由具备资质的人员依现行法律法规与规范作出，并对观察、记录与复核全程留痕。
