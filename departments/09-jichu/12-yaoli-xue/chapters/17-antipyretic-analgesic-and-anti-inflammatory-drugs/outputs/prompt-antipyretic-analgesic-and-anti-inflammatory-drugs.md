# Prompt 模板：解热镇痛抗炎药与抗痛风药的两条线判定

## 用途

拿到一段关于解热镇痛抗炎药或抗痛风药的表述，用这套模板判断它站在哪一条线上、落在哪一环上。适用于：读教材时自查有没有把「三类作用」读成同一效应的强弱刻度；判断某个复方制剂的成分是否被重复计入；把「某药更安全」这类说法拆成收益与代价两侧；把不良反应按环节归位，而不是背一张副作用清单。

模板不产出用药结论，只产出四个定位：线、环、成立条件、观察栏目。

## 用法

按顺序填四格，填不满就说明这句话还缺依据。

1. **哪条线？** 前列腺素线（解热、镇痛、抗炎）还是尿酸线（生成、排泄、结晶与炎症）？跨线的表述（如「某药既能止痛又能降尿酸」）一律拆成两句分别判。
2. **哪一环？** 前列腺素线上看它对两种同工型的相对抑制；尿酸线上看它作用在生成、排泄、炎症还是尿液环境。环定不准，用途与不良反应都推不出来。
3. **成立条件是什么？** 这一档用途需要什么条件才成立——不可逆加无核（抗血小板）、足够剂量（抗炎）、残存功能尚可且尿量充足（促排泄）、结晶已沉积（秋水仙碱）、尿液偏酸（碱化）。写不出条件，这一档用途就是空话。
4. **观察栏目怎么改？** 胃肠、肾、血液系统三方面是前列腺素线的常规；尿量、尿液性状与结石相关表现是促排泄药的常规；肝功能与皮肤表现是抑制生成药的常规。栏目随环节切换，不随药名罗列。

## 输出格式

```text
原句：……
线：前列腺素线 / 尿酸线
环：……（同工型选择性，或生成 / 排泄 / 炎症 / 尿液环境）
成立条件：……
观察栏目：……（新增或改写的栏目）
越界检查：是否含疗效断言 / 优劣比较 / 绝对化 / 诊断与预后判定
落点：剂量与用法照底本；判断归具备资质的人员
```

## 硬约束

- 不写剂量、浓度、疗程、监测阈值的量值；需要剂量时统一写「剂量与用法照底本」。
- 不作适应证判定，不作病情与预后判定，不作疗效与优越性断言，不作等级排名。
- 引文逐字，标「教材·药理学·第 17 章·N.M.K」；核不到原文就不引。
- 复方制剂必须逐成分列类别，不只写制剂名——成分重复是叠加过量最常见的原因。
- 中药与中成药只写药材名、方剂名、功效类别与配伍关系，不写含量与效价，不把配伍写成疗效结论。

## 一个反例

「这个复方里有解热成分，再吃一片退烧药没关系」——两处问题：只记制剂名而漏记成分，等于放弃了识别重复的唯一线索；「没关系」是安全性判断，越出了教材位阶。按模板改写为：「该复方含解热镇痛成分，类别为……；同种成分在不同复方中重复出现是叠加过量的常见原因；核对成分须逐项列出，是否合用由具备资质的人员判断。」
