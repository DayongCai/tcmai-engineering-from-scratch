# Skill：免疫抑制药——环节决定方向，方向决定观察

## 何时用

- 读到「这个药很强 / 这个药要小心肾」，需要把话拉回环节与机制
- 要解释「为什么抑制 T 细胞活化的药会出现肾毒性」
- 遇到同一药物在不同篇章有不同类别归属，需要说清这是叙述角度的差别
- 要说明感染与肿瘤风险为什么总是一起上升
- 要把观察整理成能复核的记录，却不确定该按几组反应分类

## 核心判据（六问）

1. **哪一环？** 识别与呈递 → 活化与克隆扩增 → 效应生成。越靠近起始，抑制范围越广，连带影响越明显。
2. **哪一类？** 钙调神经磷酸酶抑制剂类、抗增殖类、抗体类、糖皮质激素、其他（雷帕霉素靶蛋白抑制剂、来氟米特）。
3. **机制是什么？** 钙调神经磷酸酶与细胞因子转录、次黄嘌呤核苷酸脱氢酶、二氢叶酸还原酶、二氢乳清酸脱氢酶、烷化与交联、受体占据、细胞清除、G1 向 S 期推进。
4. **欠哪一组的账？** 八组：感染、骨髓与黏膜、肝肾、代谢内分泌、神经精神、过敏与输注、生殖发育、肿瘤风险。方向由环节与机制决定，不由药名决定。
5. **观察怎么安排？** 四类对象（机制指标、器官毒性、防御功能、用药过程）＋五个节点（基线、初期、调整后、维持期、停药或转换期）＋频次三条依据（体内过程、作用环节、个体条件）。
6. **判断交给谁？** 由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南决定。

## 执行步骤

```text
1. 收口：把待判句子压成一句「性质或作用」，删掉药名与用途
2. 归环：三阶段定位，说明抑制范围
3. 定类：五类之一；交叉归属的说明叙述角度
4. 落机制：八条机制选一，说明「细胞存活但不得活化」还是「细胞走向凋亡」
5. 定方向：八组反应里指出主要的一组，并说明为什么是它
6. 排观察：四类对象与五个节点，给出频次依据
7. 看关联：哪一组会与之相互放大
8. 定去向：谁判断、依什么、如何留痕
```

## 硬约束

- **不写剂量、疗程、血药浓度、参考区间、分级数值。** 需要剂量时统一写「剂量与用法照底本」。
- **不作适应证判定，不作病情与预后判定，不作疗效断言与优越性断言，不作等级排名。**
- **引文逐字。** 标「教材·药理学·第48章·48.x.y」，核不到原文就不引；改写须标明是改写。
- **不写品名、厂商、剂型规格与价格。**
- **中性表述。** 移植受者与长期治疗者一律按接受规范治疗的人群描述，不与其社会角色、生活方式相联系。
- **复核不重判。** 复核查形式与逻辑，实质判断归具备资质的人员。
- **不确定就写下来。** 标待核实，不用推测填空。

## 交付物

1. 一条归位链：环节 → 类别 → 机制 → 不良反应方向 → 观察
2. 一处方向判断：这条机制主要欠哪一组的账
3. 一条观察安排：对象、节点、频次依据
4. 一句边界句：本章只描述机制与类别，判断归属另行

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 强度当刻度 | 用「强弱」代替环节 | 改为「作用于哪一环、范围多广」 |
| 归错方向 | 把肾毒性归到免疫抑制本身 | 回到机制：肾血管收缩不经免疫机制 |
| 观察无由来 | 只写「注意监测」 | 补机制→方向→观察这条链 |
| 组间割裂 | 只看血象不看感染征象 | 补相互放大的关系 |
| 复核越界 | 复核者改写结论 | 复核只查形式与逻辑 |
| 偷给量值 | 浓度、参考区间无来源 | 改为「剂量与用法照底本」 |
| 标签化 | 把依从性写成个人品性 | 改为可观察、可记录的行为类别 |

## 与相邻章节的接缝

- 第 49 章（免疫增强药）：方向相反，同一篇内并列；本章以作用靶点与监测指标为主线，那一章以类别归属与作用环节为主线。
- 第 47 章（抗恶性肿瘤药）：环磷酰胺、甲氨蝶呤在两章都出现，角度不同——那一章看周期与时相，本章看淋巴细胞增殖与免疫应答。
- 第 45、46 章（抗结核与抗寄生虫药）：同属化学治疗思路，但选择性的来源不同：那两章靠病原体特有的酶系与生活史阶段，本章靠免疫细胞对特定通路的依赖。
- 第 3 章（药动学）：本章的「肝药酶底物、外排转运体底物」在那一章有参数化写法，本章只用到定性关系。

## 边界

本 Skill 只处理「一条表述 → 环节与方向」的判定，不涉及剂量、适应证与临床决策。本章内容为教学材料，不构成用药建议；任何涉及个体的用药评估须由具备资质的人员依现行法律法规与规范作出，并以现行药品说明书为依据。
