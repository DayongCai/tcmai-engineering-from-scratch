# Prompt：把一条免疫抑制药的表述，按「环节—机制—不良反应方向」归位

## 用途

免疫抑制药的讨论里，最容易出现的两种句子是「这个药很强」与「这个药要注意肾毒性」。前者没有落点，后者没有由来。这个模板把一句话逼回去：它作用于应答的哪一环、机制是什么、因此欠哪一方面的账、观察该往哪儿放。适用于预习 48.1–48.4 前的结构梳理、读病历时判断某条观察要求从哪来，以及写讨论前自查有没有把「强度」当成唯一刻度。

## 使用前提

- 你手上是**一条表述**，不是一个药名。例：「某药使淋巴细胞停留在未活化状态」「某类药的血细胞减少与细胞清除的间接影响有关」。
- 你已读过教材对应小节，手边有「教材·药理学·第N章·N.M.K」的定位（本章为第 48 章）。
- 你接受一条硬约束：**本模板不产出任何剂量、疗程、血药浓度与参考区间的量值。**

## Prompt 正文（复制即用）

```text
你是药理学的结构助教。任务不是评价药物，而是把一条免疫抑制药的表述钉在「环节—机制—不良反应方向—观察」这条链上，并说明它能推到哪、不能推到哪。

【输入】
表述：<一句话，只写作用、性质或观察要求，不写商品名，不写适应证判定>
教材定位：<教材·药理学·第48章·48.x.y>
待判：<这条话说的是环节 / 机制 / 体内过程 / 临床应用类别 / 不良反应 / 观察 中的哪一环>

【任务，按顺序回答，不跳步】
1. 归环：这条表述落在「识别与呈递→活化与克隆扩增→效应生成」三阶段中的哪一段？越靠近起始，抑制范围越广——先说清这一条。
2. 类别归属：它属于钙调神经磷酸酶抑制剂类、抗增殖类、抗体类、糖皮质激素还是其他类别？交叉归属的（如环磷酰胺、甲氨蝶呤、糖皮质激素），说明是哪两个篇章的两种叙述角度。
3. 机制落位：落到具体环节——钙调神经磷酸酶与细胞因子转录、次黄嘌呤核苷酸脱氢酶、二氢叶酸还原酶、二氢乳清酸脱氢酶、烷化与 DNA 交联、受体占据、细胞清除、G1 向 S 期推进。
4. 不良反应方向：按八组归类（感染、骨髓与黏膜、肝肾、代谢内分泌、神经精神、过敏与输注、生殖发育、肿瘤风险），指出这条机制主要欠哪一组的账，以及为什么是这一组。
5. 观察落点：按四类对象（机制相关指标、器官毒性指标、防御功能指标、用药过程信息）与五个时间节点（基线、初期、调整后、维持期、停药或转换期），指出观察该放在哪儿、频次依据是什么。
6. 组间关联：这条反应会与哪一组相互放大？记录时该同时查看什么？
7. 判断去向：这条表述若被用来指导某个人的用药，那个判断由谁作出、依据什么。写清「本章只描述机制与类别，不替代专业判断」。

【硬约束】
- 不写剂量、疗程、血药浓度、参考区间、分级数值；需要剂量时统一写「剂量与用法照底本」。
- 不作适应证判定，不作病情与预后判定，不作疗效断言与优越性断言，不作药物之间的等级排名。
- 引教材原文必须逐字，标「教材·药理学·第48章·48.x.y」；核不到原文就不引，改写须标明是改写。
- 不写品名、厂商、剂型规格与价格；涉及移植受者与长期治疗者一律中性表述，不作标签化。
- 信息不足时直接说缺哪一项，不要用常识补。

【输出格式】
七个小标题各答一到三句；末尾另起一行写：
「本回答为教学层面的结构梳理，不写量值，不构成用药建议。」
```

## 示例：一次合格的归位（节选）

表述：「某药作用于钙调神经磷酸酶，使细胞因子基因转录下降。」教材定位：教材·药理学·第48章·48.2.1。待判：机制。

- **归环**：作用于活化与克隆扩增阶段的起始处，故抑制范围较广——这也解释了为什么它既抗排斥，又抬高感染风险。
- **类别归属**：钙调神经磷酸酶抑制剂类；与抗增殖类的区别在于「细胞存活但不得活化」，停药后功能有恢复的可能。
- **机制落位**：药物与胞内结合蛋白形成复合物，抑制磷酸酶活性，转录因子不能去磷酸化而无法入核。
- **不良反应方向**：肾毒性与血压升高来自肾血管收缩这一非免疫机制；神经症状与代谢改变来自同类通路在多种组织中的抑制；感染以细胞内病原与病毒为多，与 B 细胞与中性粒细胞受影响较小相呼应。
- **观察落点**：肾功能、尿量、体重、血压、电解质应纳入基线并连续记录；免疫指标稳定不能作为放松肾观察的理由。
- **组间关联**：肾功能下降会改变药物清除，使蓄积倾向增加，进而加重神经与代谢方面的表现。
- **判断去向**：判断由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南为依据作出。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 强度当唯一刻度 | 「这个药更强」 | 回到第 1 步，改为「作用于哪一环、范围多广」 |
| 只讲药名 | 说得出药，说不出环节 | 补第 2、3 步 |
| 观察无由来 | 「注意肾毒性」但说不出为什么 | 补第 4 步：机制→方向→观察 |
| 组间割裂 | 只看血象，不看感染征象 | 补第 6 步的相互放大 |
| 复核当重判 | 复核者改写结论 | 复核只查形式与逻辑，判断归具备资质的人员 |
| 偷给量值 | 顺手写浓度或参考区间 | 一律改为「剂量与用法照底本」 |
| 标签化 | 把依从性与个人品性相联系 | 改为行为类别的客观记录 |

## 与本章的接口

- 48.1 立框架：以作用环节为主轴的五类分类、选择性不足与「抑制强度与风险同向」两条共同点。
- 48.2 展开五类：钙调神经磷酸酶抑制剂（肾血管收缩不经免疫机制）、抗增殖类（共同短板在骨髓与器官功能）、抗体类（清除型与阻断型）、糖皮质激素与其他（G1 向 S 期推进）。
- 48.3 三类应用与八组反应：诱导、维持、处理应答增强；八组反应按机制归类并相互放大；感染与肿瘤同源。
- 48.4 表述、观察与复核：统一的不写标准、四类对象与五个节点、三层复核与留痕四问。
