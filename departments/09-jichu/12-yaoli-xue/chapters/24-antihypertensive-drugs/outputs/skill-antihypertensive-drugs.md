# Skill：抗高血压药——三个要素、五类药、一道代偿题

## 何时用

- 读到「某药降压」，需要判断它动的是哪一个要素
- 要解释「利尿药为什么会降压，为什么作用要过一段时间才稳定」
- 要解释「为什么阻断 β 受体也能降压」「为什么血管扩张药单用会越用越不管用」
- 要解释「同是钙通道阻断药，为什么有的引起踝部水肿」
- 要解释「为什么强调平稳降压，而不是把血压压得越低越好」
- 有人拿「哪一类是首选」来问，需要把问题换成「哪个要素、哪一道代偿」

## 核心判据（七问）

1. **哪个要素？** 心排血量、外周血管阻力、循环血容量；或四条调节途径（交感、肾素-血管紧张素-醛固酮系统、内皮来源物质、肾脏排钠）。
2. **哪一类？** 利尿药、系统抑制药、钙通道阻断药、交感神经抑制药、血管扩张药；跨类者写明主要环节与次要环节。
3. **哪个靶点？** 转运体、转化酶、膜受体、核受体、钙通道、钾通道，或直接作用于血管平滑肌。
4. **有没有两个时相？** 利尿药的初期与长期机制不同；长期抑制之后受体与递质系统的敏感性会改变（撤药反跳即由此而来）。
5. **代偿是什么？** 反射性心率加快、钠水潴留、肾素释放、交感激活——代偿常与效应同源，补位要针对代偿那一环。
6. **覆盖得住吗？** 谷峰比判断间隔与作用持续时间是否匹配；给药时间决定峰效应覆盖哪个高峰、是否带来夜间过低的风险。
7. **判断交给谁？** 由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南决定。

## 执行步骤

```text
1. 收口：把待判句子压成一句「作用或环节」，删掉药名与「首选」这类评价
2. 定要素：心排血量 / 外周阻力 / 血容量 / 四条调节途径
3. 定类别：五类里归一类；跨类者注明主次
4. 定靶点：转运体、酶、膜受体、核受体、通道、平滑肌
5. 分时相：初期与长期是否一致；有无受体适应性改变
6. 查代偿：心率、钠水、肾素、交感——补的是哪一环
7. 查覆盖：谷峰比与给药时间两条判据
8. 落观察：症状 / 体征 / 实验室 / 时间关系，四组里选
```

## 五类药的最小骨架

| 类别 | 要素 | 机制要点 | 代偿与代价 |
|---|---|---|---|
| 利尿药 | 血容量 | 初期抑制钠氯共转运、缩减容量；长期以外周阻力下降为主 | 低钾、低钠、低镁、高尿酸、糖耐量与血脂变化，均与剂量相关 |
| 系统抑制药 | 神经内分泌 | 转化酶抑制（并影响缓激肽）、AT1 受体阻断、肾素抑制、醛固酮拮抗 | 干咳与血管性水肿只见于影响缓激肽者；共享高钾 |
| 钙通道阻断药 | 外周阻力 | 阻滞 L 型钙通道；二氢吡啶类偏血管、非二氢吡啶类偏心脏 | 反射性心率加快；踝部水肿源于静水压升高而非容量负荷 |
| 交感神经抑制药 | 心排血量与阻力 | 中枢 α2 与咪唑啉 1、神经节 N1、末梢递质耗竭、β 与 α1 受体阻断 | 撤药反跳、首剂现象、支气管痉挛 |
| 血管扩张药 | 外周阻力 | 直接舒张平滑肌（一氧化氮通路、钾通道开放） | 反射性心率加快与钠水潴留，故多与 β 阻断药及利尿药配合 |

## 硬约束

- **不写剂量、浓度、滴度、效价、给药频次与疗程的量值。** 需要剂量时统一写「剂量与用法照底本」。
- **不写血压数值、分层阈值与目标值。** 教材明确本章不列举这些数值，它们属现行指南与规范。
- **不作适应证判定，不作病情与预后判定，不作疗效断言与优越性断言，不作等级排名，不把分类写成用药顺序。**
- **代偿是机制，不是缺陷。** 反射性心率加快与钠水潴留是机体对血压下降的正常反应，理解它才能理解联合为什么这样配。
- **引文逐字。** 标「教材·药理学·第24章·24.x.y」，核不到原文就不引；改写须标明是改写。

## 常见错误

- 把「利尿」当成全部机制：长期降压靠的是外周阻力下降，不是尿量多少。
- 把「踝部水肿」当成容量负荷：机制是静水压升高，处理方向与利尿不同。
- 把「干咳少」读成「没有」：不影响缓激肽代谢的一类，血管性水肿仍可发生。
- 把「分层」当成终点：教材写明分层提供的是起点，并发症与耐受性才是改变方向的依据。
