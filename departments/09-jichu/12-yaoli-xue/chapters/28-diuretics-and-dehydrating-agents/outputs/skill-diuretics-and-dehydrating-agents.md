# Skill：利尿药与脱水药——四段、两侧、六项要素

## 何时用

- 读到「某药是高效利尿药」，需要判断这句话描述的是区间还是排名
- 要解释「为什么抑制了近曲小管，排钠幅度却有限」
- 要解释「为什么甘露醇口服只导泻、静脉才脱水」
- 要把一条含数值的描述改写成可复核的类别记录
- 遇到反跳、等渗尿、自由水这些词，需要说清它们各自属于哪一层

## 核心判据（六问）

1. **哪一侧？** 管腔侧（作用于转运体或酶，须先分泌入管腔）还是血管侧（靠渗透压梯度改变体液分布）。
2. **哪一段？** 近曲小管（钠氢交换与碳酸酐酶）、升支粗段（钠钾氯同向转运与钾再循环）、远曲小管前段（钠氯同向转运）、集合管（水通道与醛固酮受体与钠通道）。
3. **代偿多少？** 尿量增幅取决于该段的最大阻断比例与其后代偿程度，不取决于该段固有重吸收量。
4. **屏障在不在？** 脱水药的效应以屏障低通透性为前提；屏障受损时效应与风险同时改变。
5. **写成什么类别？** 尿量偏多与如常与偏少；体重上升与持平与下降；口渴无与轻度与明显；穿刺部位无异常与轻度肿胀与明显肿胀。不写数值。
6. **判断交给谁？** 由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南决定。

## 执行步骤

```text
1. 收口：把待判句子压成一句「作用或过程特点」，删掉药名与用途
2. 定侧：管腔侧 / 血管侧
3. 定段：近曲小管 / 升支粗段 / 远曲小管前段 / 集合管 / 血管与组织之间
4. 算代偿或算梯度：利尿药算其后节段代偿，脱水药算屏障通透性
5. 划边界：容量状态、剂量与部位扩展、反跳、屏障受损、口服与静脉分野
6. 换写法：四类观察项目 → 三级类别描述
7. 落记录：六项要素，区分主诉与体征
8. 定去向：谁判断、依什么、如何留痕
```

## 硬约束

- **不写剂量、浓度、出入量、体重变化、检验数值与参考区间。** 需要剂量时统一写「剂量与用法照底本」。
- **不作疾病诊断，不作病情与预后判定，不作适应证判定，不作疗效与优越性断言，不作优劣与等级排名。**
- **引文逐字。** 标「教材·药理学·第28章·28.x.y」，核不到原文就不引；改写须标明是改写。
- **不写品名、厂商、剂型规格与价格。**
- **不把分档当排名。** 高效、中效、低效只描述排钠幅度区间。
- **不把反跳当必然。** 反跳属过程特点，与给药速度、总量相关。

## 交付物

1. 一条定位：侧 → 段 → 转运体或梯度
2. 一条代偿或梯度判断：为什么排钠幅度是这个区间 / 为什么梯度能维持
3. 一份观察清单：四类项目各自用哪一级类别描述
4. 一条记录格式：六项要素齐备，主诉与体征分开
5. 一句边界句：本章只描述位置与类别关系，判断归属另行

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 用数值代替观察 | 记录无法复核，也越出口径 | 改为三级类别描述 |
| 分档当排名 | 由「高效」推出「更好」 | 回到第 3 问，写明只描述区间 |
| 混同两条途径 | 把口服甘露醇的导泻当脱水 | 写清局部效应与全身效应 |
| 忽略代偿 | 解释不了近曲小管抑制的限度 | 补第 3 问 |
| 只写药物一侧 | 忽略容量状态下的调节反应 | 补肾素与醛固酮系统的抵消 |
| 把复核写成长判断 | 复核者越权 | 复核只确认一致性与完备性 |

## 边界

本 Skill 只处理「一条表述 → 位置与记录写法」的定位，不涉及剂量、分级判定与临床决策。本章内容为教学材料，不构成用药建议；任何涉及个体的用药评估须由具备资质的人员依现行法律法规与规范作出。
