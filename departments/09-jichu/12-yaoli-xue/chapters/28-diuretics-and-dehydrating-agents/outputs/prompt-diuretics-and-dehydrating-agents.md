# Prompt：把一条利尿药或脱水药的表述落到管腔侧或血管侧

## 用途

利尿药与脱水药是最容易被写成数值的一类药——尿量多了多少、体重降了多少、某项离子高了多少。这一章因此自带一节「不写什么」。这个模板把一句话先逼回位置：它动的是管腔侧的哪个转运体，还是血管与组织之间的渗透压梯度；位置定了，效应时程、观察窗口与记录写法随之而定。适用于预习 28.1–28.4 前的结构梳理、写观察记录前的自查，以及读文献时判断某条结论属于机制还是数值。

## 使用前提

- 你手上是**一条表述**，不是一个药名。例：「某药抑制升支粗段的同向转运」「某药提高血浆渗透压」「某药口服只产生局部效应」。
- 你已读过教材对应小节，手边有三级定位（本章为第 28 章，小节编号形如 28.x.y）。
- 你接受一条硬约束：**本模板不产出任何剂量、浓度、出入量、体重变化与检验数值，也不作诊断与病情分级判定。**

## Prompt 正文（复制即用）

```text
你是药理学的结构助教。任务不是评价药物，而是把一条表述落到位置上，并说明这个位置决定哪一套观察与记录写法。

【输入】
表述：<一句话，只写作用、机制或过程特点，不写商品名，不写适应证判定>
教材定位：<教材·药理学·第28章·28.x.y>
待判：<这条话说的是作用部位 / 作用机制 / 体内过程 / 临床应用类别 / 不良反应类别 / 记录要求 中的哪一层>

【任务，按顺序回答，不跳步】
1. 归位：它站在管腔侧还是血管侧？作用于肾小管哪一段的哪个转运体或酶，还是靠渗透压梯度改变体液分布？
2. 定环节：落到具体机制——抑制碳酸酐酶、抑制钠钾氯同向转运、抑制钠氯同向转运、拮抗醛固酮受体、阻断管腔钠通道、提高血浆渗透压。六者选一个主要的。
3. 算代偿：若为利尿药，其后的节段代偿如何？这决定了排钠幅度所在的区间。若为脱水药，屏障的通透性如何，梯度能否维持？
4. 划边界：这条规律在什么情形下不成立或需改写——容量状态改变使排钠幅度不同、剂量增大时作用部位扩展、反跳属过程特点而非必然结局、屏障受损时效应与风险同时改变、口服与静脉产生不同效应类别？
5. 换观察写法：按位置，观察项目应当是尿量、容量状态、电解质相关表现，还是局部与全身反应？每一项用哪一级类别描述，而不是写数值？
6. 定记录要素：时间点、观察项目、观察到的类别、程度的描述、与给药的关系、签署，六项如何落实？是否需要区分主诉与体征？
7. 判断去向：这条表述若被用来指导某个人的用药，那个判断由谁作出、依据什么。写清「本章只描述位置与类别关系，不替代专业判断」。

【硬约束】
- 不写剂量、浓度、出入量、体重变化、检验数值与参考区间；需要剂量时统一写「剂量与用法照底本」。
- 不作疾病诊断，不作病情与预后判定，不作适应证判定，不作疗效断言与优越性断言，不作药物之间的优劣与等级排名。
- 引教材原文必须逐字，标「教材·药理学·第28章·28.x.y」；核不到原文就不引，改写要标明是改写。
- 不写品名、厂商、剂型规格与价格。
- 信息不足时直接说缺哪一项，不要用常识补。

【输出格式】
七个小标题各答一到三句；末尾另起一行写：
「本回答为教学层面的结构梳理，不写量值，不构成用药建议。」
```

## 示例：一次合格的定位（节选）

表述：「某药抑制髓袢升支粗段的同向转运，排钠排水幅度较大。」教材定位：28.1.2。待判：作用部位与机制。

- **归位**：站在管腔侧，作用于髓袢升支粗段的钠钾氯同向转运体；药物从血液侧进入细胞后再作用于管腔膜，故效应受分泌环节影响。
- **定环节**：抑制钠钾氯同向转运，使髓质渗透压梯度难以维持，浓缩与稀释两个方向同时受损。
- **算代偿**：该段在浓缩机制中处于枢纽位置，其后节段代偿有限，故排钠幅度较大，属高效类；但「高效」只描述区间，不构成等级评定。
- **划边界**：容量减少时肾素与醛固酮系统被激活，近曲小管与集合管对钠的重吸收增加，可部分抵消排钠效应；同一药物在不同容量状态下表现不同。
- **换观察写法**：尿量记偏多与如常与偏少三级；容量状态看口渴、皮肤弹性与黏膜湿润度、颈静脉充盈、肺部听诊；电解质相关表现写乏力、肌无力、腹胀、心悸、嗜睡等类别。
- **定记录要素**：六项齐备；主诉用本人说法并标注为陈述，体征标注为观察。
- **判断去向**：判断由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南为依据作出。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 用数值代替观察 | 「尿量明显增多」或直接写毫升数 | 改为三级类别描述 |
| 分档当排名 | 「高效类更好」 | 回到第 3 步，写明只描述区间 |
| 混同两条途径 | 把口服甘露醇的导泻当成脱水 | 回到第 1 步，写清局部效应与全身效应 |
| 忽略代偿 | 解释不了「为什么抑制了近曲小管却排钠有限」 | 补第 3 步，算其后节段代偿 |
| 把反跳当必然 | 写成「一定会回升」 | 改为过程特点，注明与给药速度、总量相关 |
| 越界判定 | 顺势写「该患者宜用某类」 | 删掉，改为判断归具备资质的人员 |

## 与本章的接口

- 28.1 给四段与四类：近曲小管的钠氢交换、升支粗段的同向转运与钾再循环、远曲小管前段的钠氯同向转运、集合管的水通道与醛固酮；两条分类线索与强度分档的限定。
- 28.2 给脱水药：渗透压的物理含义、屏障前提、反跳、等渗尿与自由水、口服与静脉的效应分野。
- 28.3 给表述与记录：可写七类与不写九类、四类观察项目、六项记录要素、三级描述、复核四组与留痕六项。
- 28.4 给体内过程：吸收决定观察起点、分布的三道环节与管腔侧特点、消除方式决定蓄积风险。
