# Prompt：把一条抗癫痫／抗惊厥药的表述拆成「环节—目的—观察—记录」

## 用途

这一类的表述最容易出两种偏差：一是写完机制就直接跳到用途（「故用于某类发作」），二是把「某药能止惊」当成「某药适合长期用」。这个模板把一句话压回四个位置：它落在哪个作用环节、服务于哪个目的、要求观察哪一组项目、最后该由谁判断。适用于预习 14.1–14.4 前的结构梳理、读文献时判断结论停在机制层还是用途层，以及写病例讨论前自查有没有把「需要监测」写成「监测到多少」。

## 使用前提

- 你手上是**一条表述**，不是一个药名。例：「某药减少病灶放电的扩散而不抑制病灶本身」「某药过量时先肌腱反射消失」。
- 你已读过教材对应小节，手边有「教材·药理学·第N章·N.M.K」的定位（本章为第 14 章）。
- 你接受一条硬约束：**本模板不产出任何剂量、血药浓度、监测范围与参考区间的量值。**

## Prompt 正文（复制即用）

```text
你是药理学的结构助教。任务不是评价抗癫痫药，而是把一条表述钉在「环节—目的—观察—记录」这条链上，并指出它推到哪一步为止。

【输入】
表述：<一句话，只写作用或性质，不写商品名，不写发作类型归属结论>
教材定位：<教材·药理学·第14章·14.x.y>
待判：<这条话说的是作用环节 / 用药目的 / 体内过程 / 观察项目 / 记录口径 中的哪一项>

【任务，按顺序回答，不跳步】
1. 目的归位：这条表述服务于长期预防发作，还是即时控制惊厥？两者的评价指标、给药途径权重与观察时间窗都不同，写明是哪一类，不要跨类外推。
2. 环节定位：落到四类环节中的哪一个——阻滞电压依赖性钠通道（与失活态结合、只压高频）、增强 γ-氨基丁酸介导的抑制、阻滞丘脑 T 型钙通道、多重机制？多环节的写明叠加的是哪几个。
3. 选择性说明：这条表述讲的「选择性」是从哪里来的？是高频放电优先、作用部位局限，还是作用环节单一？若表述里没有选择性，直接指出它可能被误读成全面抑制。
4. 体内过程拆解：按吸收（慢而不规则 / 载体依赖 / 几乎不吸收）、分布（蛋白结合与置换、血脑屏障）、消除（肝代谢饱和 / 自身诱导 / 原型肾排 / 活性代谢物）定位，并说明它决定的是起效、时程还是监测需要。
5. 观察项目：按六组（发作本身、意识与精神、生命体征、神经体征、皮肤黏膜、实验室类别）指出这条表述要求多出哪一组；若作用强烈，指出「最早出现的提示指标」是哪一项（如肌腱反射）。
6. 记录口径：写清这条表述进入记录时该写什么、不该写什么——写现象与时间，不写推断与命名；写「需要监测」，不写监测数值与参考范围。
7. 判断去向：这条表述若被用来指导某个人的用药，那个判断由谁作出、依据什么。写清「本章只描述作用与类别，不替代专业判断」。

【硬约束】
- 不写剂量、浓度、血药浓度、监测范围、参考区间与疗程量值；需要剂量时统一写「剂量与用法照底本」。
- 不作发作类型归属，不作诊断与预后判定，不作适应证判定，不作疗效断言与优越性断言，不作药物之间的等级排名。
- 引教材原文必须逐字，标「教材·药理学·第14章·14.x.y」；核不到原文就不引，改写要标明是改写。
- 不写品名、厂商、剂型规格与价格；不写试剂、仪器与实验动物的规格型号。
- 信息不足时直接说缺哪一项，不要用常识补。

【输出格式】
七个小标题各答一到三句；末尾另起一行写：
「本回答为教学层面的结构梳理，不写量值，不构成用药建议。」
```

## 示例：一次合格的拆解（节选）

表述：「某药减少病灶放电向周围扩散，而不明显影响病灶本身的放电。」教材定位：教材·药理学·第14章·14.1.2。待判：作用环节。

- **目的归位**：服务于长期预防发作；不能据此推「即时控制惊厥」，后者的评价指标是发作是否被终止。
- **环节定位**：钠通道阻滞——与失活态结合、延长失活时间、减少钠内流，抑制高频重复放电。
- **选择性说明**：选择性来自「高频优先」，不是来自对病灶的精准识别。这一点决定了表述要写成「限制扩散」，不能写成「消除病灶」。
- **体内过程拆解**：口服吸收慢而不规则、个体差异大，代谢具饱和性——故需要监测；这三条合起来决定了它不是「按剂量推算反应」的那类药。
- **观察项目**：以发作本身为主（形式、持续时间、发作后状态），辅以神经体征（共济失调、眼球震颤）与皮肤黏膜（皮疹）、实验室类别（血象）。
- **记录口径**：写「发作形式与时点」，不写「发作类型归属」；写「已按规范复查，结果由具备资质的人员判读」，不写数值。
- **判断去向**：判断由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南为依据作出。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 以机制代用途 | 写完钠通道就写「故用于某类发作」 | 回到第 1 步，说明用途类别与发作类型分类的对应 |
| 以类别代个体 | 把某类药的共性写成每个药都具备 | 补体内过程与个体差异 |
| 以观察代判断 | 记录里写「考虑」「提示」「符合」 | 改为现象与时间，判断另栏 |
| 跨目的外推 | 由「能止惊」推出「适合长期服用」 | 补第 1 步的两类目的 |
| 偷给数值 | 顺手写血药浓度或参考区间 | 一律改为「需要监测」＋「剂量与用法照底本」 |
| 漏观察组 | 只写发作，不写生命体征与皮肤黏膜 | 按第 5 步六组逐项核对 |

## 与本章的接口

- 14.1 给抗癫痫药：四类环节、两种分类、五类常用药的作用与不良反应、新药的机制拓展。
- 14.2 给抗惊厥药：四条分类轴、硫酸镁的顺序性、巴比妥类与苯二氮䓬类的作用部位差别。
- 14.3 给表述与观察：可写五类与不写九类、观察六组、记录四要素、复核三层与四查。
- 14.4 给体内过程：吸收的四类因素、分布的三个共性、消除的三类方式与三个相互作用方向。
