# Skill：抗癫痫药与抗惊厥药——同源、两用、一条对应

## 何时用

- 读到「某药对某类发作有效」，需要判断它停在机制层还是滑向了归属判断
- 要解释「同样是抗惊厥，为什么一个松肌肉、一个压意识」
- 遇到「需要监测」这类表述，要把它与「监测到多少」切开
- 要把观察整理成六组项目，却不确定该以哪一组为主
- 有人拿两类药互相替代来问，需要把「同源」与「同用」分开

## 核心判据（六问）

1. **哪个目的？** 长期预防发作，还是即时控制惊厥。目的决定评价指标、给药途径权重与观察时间窗。
2. **哪个环节？** 钠通道（与失活态结合、只压高频）、增强 γ-氨基丁酸介导的抑制、丘脑 T 型钙通道、多重机制。
3. **选择性从哪来？** 高频优先、作用部位局限（如神经肌肉接头）、还是环节单一。给不出，说明这条表述可能被读成全面抑制。
4. **哪个体内过程环节？** 吸收（慢而不规则 / 载体依赖 / 几乎不吸收）、分布（蛋白结合与置换、血脑屏障）、消除（饱和代谢 / 自身诱导 / 原型肾排 / 活性代谢物）。
5. **哪一组观察？** 发作本身、意识与精神、生命体征、神经体征、皮肤黏膜、实验室类别；作用强烈者还要定出「最早出现的提示指标」。
6. **判断交给谁？** 由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南决定。

## 执行步骤

```text
1. 收口：把待判句子压成一句「作用或性质」，删掉药名与用途结论
2. 定目的：长期预防 / 即时控制，检查有没有跨类外推
3. 定环节：四类机制之一或多重
4. 说选择性：高频优先 / 部位局限 / 环节单一
5. 拆体内过程：吸收、分布、消除各一句，落到起效、时程或监测
6. 定观察：六组中哪一组为主，最早提示指标是哪一项
7. 定记录：写现象与时间，不写命名与推断；写「需要监测」，不写数值
8. 定去向：谁判断、依什么、如何留痕
```

## 硬约束

- **不写剂量、浓度、血药浓度、监测范围、参考区间与疗程量值。** 需要剂量时统一写「剂量与用法照底本」。
- **不作发作类型归属，不作诊断与预后判定，不作适应证判定，不作疗效断言与优越性断言，不作等级排名。**
- **引文逐字。** 标「教材·药理学·第14章·14.x.y」，核不到原文就不引；改写须标明是改写。
- **不写品名、厂商、剂型规格与价格；不写试剂、仪器与实验动物的规格型号。**
- **切开「需要监测」与「监测到多少」。** 前者写透，后者不写；数值与参考范围属临床判断。
- **观察排序有机制依据。** 先写「最早出现的提示指标」，不按「最重要的指标」排。

## 交付物

1. 一处目的定位：长期预防还是即时控制
2. 一句环节与选择性：机制是什么、选择性从哪来
3. 一条体内过程线索：哪一环节决定起效、时程或监测
4. 一组观察补充：六组中以哪组为主，早期指标是哪一项
5. 一句边界句：本章只描述作用与类别，判断归属另行

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 以机制代用途 | 机制推演被当成选择依据 | 补用途类别与发作类型分类的对应 |
| 以类别代个体 | 共性被写成每个药的属性 | 补体内过程与个体差异 |
| 以观察代判断 | 记录里出现「考虑」「提示」 | 改为现象与时间 |
| 跨目的外推 | 由「能止惊」推出「适合长期用」 | 分两类目的写 |
| 偷给数值 | 血药浓度与参考区间无来源 | 改为「需要监测」＋「剂量照底本」 |
| 漏观察组 | 只写作发作，漏生命体征与皮肤黏膜 | 六组逐项核对 |

## 与相邻章节的接缝

- 第 13 章（镇静催眠药）：苯巴比妥与苯二氮䓬类在两章都出现，本章讲发作类型与长期预防，那一章讲剂量谱与别位调节。
- 第 12 章（全身麻醉药）：巴比妥类的静脉制剂在麻醉中用于诱导，本章的「剂量谱」在那一章是「深度可分级」。
- 第 3 章（药动学）：本章的饱和代谢、载体依赖与自身诱导，在那一章有参数化写法。
- 第 4 章（影响药物效应的因素）：本章的年龄、肝肾功能、合并用药三条，在那一章有一般框架。

## 边界

本 Skill 只处理「一条表述 → 环节与观察的定位」，不涉及剂量、发作类型归属与临床决策。本章内容为教学材料，不构成用药建议；任何涉及个体的用药评估须由具备资质的人员依现行法律法规与规范作出。
