# Skill：呼吸系统药——一条时间轴、两个方向、三个窄口

## 何时用

- 读到「某药扩张支气管、用于哮喘」，需要判断这句话说的是机制还是用途类别
- 要解释「为什么抗炎药不能当急救药」「为什么抗过敏药要提前用」
- 遇到「痰多能不能用镇咳药」这类问题，需要把冲突定位到具体环节而不是禁忌清单
- 要把用药后的观察整理成能复核的记录，却不确定该分几栏
- 有人拿「哪个平喘药更好」来问，需要把讨论拉回分工

## 核心判据（七问）

1. **哪一段时相？** 当下缓解（支气管扩张）／长期控制（抗炎）／发作前预防（抗过敏）。时相错了，机制讲得再细也是错位。
2. **哪条路？** β2 受体激动（提高环磷酸腺苷生成）、茶碱类（抑制磷酸二酯酶、阻断腺苷受体）、抗胆碱（降低环磷酸鸟苷）；三条路方向一致而环节相异，故不良反应谱不同。
3. **在不在平滑肌上？** 糖皮质激素的作用环节不在舒张平滑肌，而在炎症与受体敏感性；把两类当同类，就会把长期管理写成急救。
4. **反射弧的哪一段？** 镇咳按作用部位分中枢与外周；位置决定谱——可待因兼镇痛镇静并抑制腺体分泌，右美沙芬无镇痛，喷托维林兼外周与阿托品样作用。
5. **痰的三条线索在哪一条？** 增加分泌、降低黏度、增强清除；落点是纤毛与咳嗽，药改性状不改清除。
6. **哪个窄口？** 剂量窄（茶碱类有效量与中毒量接近）、时机窄（阻释药须在暴露之前）、权衡窄（镇咳抑制分泌与祛痰增加分泌方向相反）。
7. **判断交给谁？** 由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南决定。

## 执行步骤

```text
1. 收口：把待判句子压成一句「作用或性质」，删掉药名与用途
2. 定时相：当下 / 长期 / 之前，或退出时间轴（反射弧、痰液性状）
3. 定环节：三条路之一，或炎症与受体敏感性；镇咳定弧上位置；祛痰定三条线索
4. 找窄口：剂量窄 / 时机窄 / 权衡窄，三者都不属则标「无窄口」
5. 配不配：与哪一类同向、与哪一类反向，冲突落在哪个环节
6. 落观察：观察表多出哪一栏，要不要写明途径与时点
7. 找例外：途径、炎症与酸碱度、年龄与肝肾功能、合并用药
8. 定去向：谁判断、依什么、如何留痕
```

## 硬约束

- **不写剂量、浓度、装置类型与参数、疗程时长的量值。** 需要剂量时统一写「剂量与用法照底本」。
- **不作适应证判定，不作病情与预后判定，不作疗效断言与优越性断言，不作等级排名。**
- **引文逐字。** 标「教材·药理学·第30章·30.x.y」，核不到原文就不引；改写须标明是改写。
- **不写品名、厂商、剂型规格与价格。**
- **症状可以描述，诊断不能下。** 症状是药理作用的对应对象，症状组合不是诊断依据。
- **不确定就写下来。** 标待核实，不用推测填空。

## 交付物

1. 一条时相定位：当下 / 长期 / 之前，或说明它退出了时间轴
2. 一处环节落位：三条路之一，或炎症与受体敏感性
3. 一个窄口判定：剂量、时机、权衡，或明确「无窄口」
4. 一栏观察补充：记录表上因此要多写什么
5. 一句边界句：本章只描述机制与类别，判断归属另行

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 三节当三张清单 | 答不出「为什么这一类管这一段」 | 排成时间轴，先定时相 |
| 抗炎当急救 | 把起效慢的药放到发作当下 | 回到时相：控制炎症解决的是长期 |
| 机制混并 | 把 β2 激动药与茶碱当同类 | 一个提生成、一个减降解，环节相异 |
| 抑制当禁忌 | 只说「痰多不宜镇咳」不说为什么 | 指出两条机制方向相反 |
| 偷给量值 | 喷雾次数、装置参数无来源 | 改为「剂量与用法照底本」 |
| 记录写评价 | 「好转」「尚可」代替所见 | 写口干、心悸、咽部刺激这类可观察项 |
| 越界判定 | 「该患者宜用某药」 | 删掉，判断归具备资质的人员 |

## 边界

本 Skill 只处理「一条表述 → 时相与环节」的判定，不涉及剂量、适应证与临床决策。本章内容为教学材料，不构成用药建议；任何涉及个体的用药评估须由具备资质的人员依现行法律法规与规范作出。
