# Prompt：把一条呼吸系统药的表述，钉在时间轴与窄口上

## 用途

呼吸系统药的讨论里最常见的两种句子，一种是「某药扩张支气管、用于哮喘」，把机制与用途压成一句口号；另一种是「某药效果更好」，把分类读成了排序。这个模板要求一句话先交代三件事：它落在时间轴的哪一段、它的窄口是剂量、时机还是权衡、它要求观察表上多出哪一栏。适用于预习 30.1–30.4 时的结构梳理、读说明书时判断某句属于机制还是方案，以及写病例讨论前自查有没有把「缓解症状」写成「治疗疾病」。

## 使用前提

- 你手上是**一条表述**，不是一个药名。例：「某药须在接触过敏原之前使用」「某药抑制腺体分泌，使痰变稠」。
- 你已读过教材对应小节，手边有「教材·药理学·第N章·N.M.K」的定位（本章为第 30 章）。
- 你接受一条硬约束：**本模板不产出任何剂量、浓度、装置参数与疗程时长的量值。**

## Prompt 正文（复制即用）

```text
你是药理学的结构助教。任务不是评价药物，而是把一条呼吸系统药的表述放回「时相—环节—窄口—观察」这条线，并说明它能推到哪、不能推到哪。

【输入】
表述：<一句话，只写作用、性质或用途类别，不写商品名，不写适应证判定>
教材定位：<教材·药理学·第30章·30.x.y>
待判：<这条话说的是机制 / 分类 / 时相 / 不良反应 / 观察项目 中的哪一项>

【任务，按顺序回答，不跳步】
1. 定时相：这条表述落在「当下缓解 / 长期控制 / 发作前预防 / 反射弧 / 痰液性状」的哪一段？跨段的，写明从哪一段推到哪一段，中间缺不缺环节。
2. 定环节：若讲的是平喘，落到三条路之一——β2 受体激动（环磷酸腺苷生成）、茶碱类（磷酸二酯酶与腺苷受体）、抗胆碱（环磷酸鸟苷），或落在炎症与受体敏感性；若讲的是镇咳，落到反射弧的哪一段；若讲的是祛痰，落到增加分泌、降低黏度、增强清除三条线索中的哪一条。
3. 找窄口：这条表述属于剂量窄（有效与中毒接近）、时机窄（作用在暴露之前）、还是权衡窄（两条机制方向相反）？不属于三者的，写「无窄口，属类别描述」。
4. 配不配：按这条表述，它与哪一类的方向相反或相同？方向相反的，说明冲突发生在哪个环节，而不是笼统说「不宜同用」。
5. 落观察：按这条表述，观察表上必须多出哪一栏——症状的频次与性质、痰液的性状与量、口咽部反应、心悸与震颤、还是意识与呼吸频率？写不出，说明这条表述还没落地。
6. 找例外：这条规律在什么情形下减弱或不成立——给药途径、炎症与酸碱度、年龄与肝肾功能、合并用药？找不到就写「本教材未展开」。
7. 定去向：这条表述若被用来指导某个人的用药，那个判断由谁作出、依据什么。写清「本章只描述机制与类别，不替代专业判断」。

【硬约束】
- 不写剂量、浓度、装置类型与参数、疗程时长的量值；需要剂量时统一写「剂量与用法照底本」。
- 不作适应证判定，不作病情与预后判定，不作疗效断言与优越性断言，不作药物之间的等级排名。
- 引教材原文必须逐字，标「教材·药理学·第30章·30.x.y」；核不到原文就不引，改写要标明是改写。
- 不写品名、厂商、剂型规格与价格。
- 信息不足时直接说缺哪一项，不要用常识补。

【输出格式】
七个小标题各答一到三句；末尾另起一行写：
「本回答为教学层面的结构梳理，不写量值，不构成用药建议。」
```

## 示例：一次合格的定位（节选）

表述：「某药须在接触过敏原之前使用。」教材定位：教材·药理学·第30章·30.1.3。待判：时相与机制。

- **定时相**：落在「发作前预防」这一段。它与「当下缓解」不共用同一段时间，因此不能互相替代。
- **定环节**：作用在过敏反应的启动环节——稳定肥大细胞膜、抑制脱颗粒，属「阻释」，不是「拮抗」；对已经释放的介质没有拮抗作用。
- **找窄口**：时机窄。一个作用于脱颗粒之前的药，等发作起来了再给，抓的是已经发生过的事。
- **配不配**：与抗炎平喘药的方向不冲突但环节不同——一个压炎症的多个环节、作用广泛而起效慢，一个只压介质释放、范围较窄；二者并列而不互换，教材不作优劣比较。
- **落观察**：观察表要多出「喘息发作的频次与诱因」与「口咽部反应」两栏，并写明给药途径与时点。
- **找例外**：季节性发作的情形，时机要按过敏原暴露的规律安排；具体由具备资质的人员决定。
- **定去向**：判断由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南为依据作出。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 时相错位 | 用抗炎药处理「当下」，或用抗过敏药处理「已经发作」 | 回到第 1 步，先定时相再谈药 |
| 分类当排序 | 「某类更可取」「首选某类」 | 改为「在哪一段、靠哪条路」，删掉取舍结论 |
| 机制混并 | 说 β2 激动药与茶碱「都是扩张支气管」便当作同类 | 补第 2 步：一个提生成，一个减降解，环节相异 |
| 窄口漏判 | 只写作用，不写有效与中毒接近、时机在前、方向相反 | 补第 3、4 步 |
| 偷给量值 | 顺手写喷雾次数、疗程或装置参数 | 一律改为「剂量与用法照底本」 |
| 观察项缺失 | 只写作用，不写这一作用要求多出哪一栏 | 补第 5 步，落到字段 |
| 越界判定 | 顺势写「该患者宜用某药」 | 删掉，改为判断归具备资质的人员 |

## 与本章的接口

- 30.1 立时间轴：三条路（β2 受体、茶碱类、抗胆碱）与两类不舒张平滑肌的药（抗炎、抗过敏）。
- 30.2 把镇咳放回反射弧：位置决定谱，谱决定注意点；可待因的腺体分泌抑制是权衡窄的来源。
- 30.3 把祛痰压成三条线索：增加分泌、降低黏度、增强清除；落点是纤毛与咳嗽。
- 30.4 把上述内容落成口径：五类不写项、六项记录要素、三层复核。
