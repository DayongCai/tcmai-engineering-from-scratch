# Skill：抗肾上腺素药——三层亚型、两种结合、一条撤药纪律

## 何时用

- 读到「阻断 α／β 受体」，要判断削掉的是哪一层、剩下什么
- 要解释「同属 α 阻断，为什么三支药方向不同」——非选择性、α1 选择性、α2 选择性的对照
- 需要判断过量时「能不能被递质夺回」，以及撤药时「能不能骤停」
- 要处理首剂现象、体位性低血压、支气管敏感者的观察重点
- 拟观察表时，不确定血压该测几个体位、时点该按什么安排

## 核心判据（六问）

1. **阻断哪一层？** α1／α2／β1／β2／非选择性／兼 α1。亚型不明，方向可能相反。
2. **剩下的是什么？** α1：血管舒张、瞳孔缩小、前列腺与膀胱颈松弛；α2：负反馈解除、递质释放增多、交感张力升高；β1：心率与传导减慢、收缩力减弱、肾素释放减少；β2：支气管张力升高、糖代谢与钾分布受影响。
3. **结合可逆吗？** 竞争性可被递质夺回（曲线平行右移、最大效应不变）；非竞争性不可夺回（最大效应下降、作用持久、观察窗延长）。
4. **时程与撤药？** 短效／长效；有无内在拟交感活性。长期阻断致受体上调，骤停反跳，故逐渐减量。
5. **体内过程支持吗？** 首过效应决定口服可用性与剂量差别；脂溶性决定中枢症状多少；消除途径决定肝肾功能下降时是否蓄积。
6. **观察补哪几栏？** 血压（卧、立）、心率与心律（静息、节律）、呼吸、症状与体征。时点由时程决定，长期用药先设基线。

## 执行步骤

```text
1. 收口：把待判句子压成一句「某亚型被阻断后的某效应」
2. 定层：α1 / α2 / β1 / β2 / 非选择性
3. 摆剩余：写出该亚型所在器官与阻断后的净结果
4. 查可逆：竞争性 or 非竞争性 → 过量时有无「夺回」这条路
5. 查时程：首过、脂溶性、消除途径、上调与反跳
6. 落观察：卧立位血压、静息心率与节律、呼吸、症状；时点跟时程
7. 查例外：首剂现象、支气管敏感、肝肾功能下降、老年
8. 定边界：机制写足，剂量与判断阈值不写，判断归具备资质的人员
```

## 硬约束

- **不写剂量、浓度、减量幅度、血压与心率判断阈值的量值。** 需要时统一写「剂量与用法照底本」。
- **不作适应证判定、不作病情与预后判定、不作疗效与优劣断言、不作等级排名。**
- **引文逐字。** 标「教材·药理学·第10章 + 三级小节号」，核不到原文就不引。
- **不写品名、厂商、规格与价格，不写文书编号与联系电话。**
- **方向不是强弱。** α1 阻断与 α2 阻断方向相反是亚型决定的，不作排序。
- **不确定就标待核实。** 不用推测填空。

## 交付物

1. 一条层次判定：削掉哪一层亚型
2. 一张「亚型—器官—剩余效应」对照，只写相关几行
3. 一句结合性质判定：能否被递质夺回
4. 一句时程判定：首过、脂溶性、消除途径、上调与撤药反跳
5. 一栏观察补充 + 一句边界句

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 用「阻断 α 受体」概括全部效应 | 解释不了 α2 阻断为何升压 | 补亚型，写清方向 |
| 只记血压不记心率 | 「效应上的分离」被漏掉一半 | 两项并列，注明体位与状态 |
| 把首剂现象当成个体过敏 | 处理原则无从推出 | 回到血管扩张＋前负荷＋体位 |
| 过量时一律想「拮抗」 | 非竞争性结合夺不回来 | 先判结合性质 |
| 长期用药骤然停 | 受体上调致反跳 | 逐渐减量，撤药期即观察期 |
| 记录写「血压偏低」 | 判断混入事实，无法复核 | 写「立位较卧位下降」并注明体位 |

- 第 2 章（药效学）：亲和力与内在活性、竞争性与非竞争性拮抗、量效曲线的骨架在那一章更完整。
- 第 3 章（药动学）：首过效应、表观分布容积、半衰期在那一章有参数化写法，本章只用定性关系。

## 边界

本 Skill 只处理「一句表述 → 阻断层次 → 剩余效应 → 观察项」的判定，不涉及剂量、适应证与临床决策。本章内容为教学材料，不构成用药建议；任何涉及个体的用药评估，须由具备资质的人员依现行法律法规与规范、以现行药品说明书为依据作出。
