# Prompt：抗肾上腺素药的「阻断层次」判定器

## 用途

给一段关于抗肾上腺素药的表述，输出四样东西：它阻断哪一层（α1、α2、β1、β2、还是非选择性）；剩下的表现由什么决定；这条表述是竞争性还是非竞争性、能不能被递质夺回；以及它该配哪些观察项与时点。

三种场合最常用。其一，备课核对「为什么同属 α 阻断，三支药方向不同」——答案在亚型，不在强弱。其二，辨析过量与撤药两个时程问题——一个问「能不能逆转」，一个问「能不能骤停」。其三，拟观察表——血压必须测卧立位，时点必须跟时程走。

## 模板

```text
【待判表述】<一句话，去掉药名与程度词>

1. 阻断哪一层？
   α1 / α2 / β1 / β2 / α1+α2 / β1+β2 / 兼 α1
   → 削掉的位置不同，剩下的表现就不同

2. 剩下的是什么？
   α1 阻断：血管舒张、瞳孔缩小、前列腺与膀胱颈松弛
   α2 阻断：负反馈解除、递质释放增多、交感张力升高
   β1 阻断：心率与传导减慢、收缩力减弱、肾素释放减少
   β2 阻断：支气管张力升高、糖代谢与钾分布受影响
   → 表现是净结果，不是药物自身的属性

3. 结合性质？
   竞争性：可被提高递质浓度夺回，曲线平行右移、最大效应不变
   非竞争性：不可夺回，最大效应下降，作用持久、观察窗延长
   → 这一条决定过量时有没有「夺回」这条路

4. 时程与撤药？
   短效 / 长效；有无内在拟交感活性
   长期阻断 → 受体上调 → 骤停反跳 → 逐渐减量
   → 撤药期本身就是观察期

5. 体内过程支持这个说法吗？
   首过效应（决定口服能否用、剂量差别）
   脂溶性（决定中枢症状多少）
   消除途径（决定肝肾功能下降时是否蓄积）
   → 时程解释要落在这三条上

6. 观察补什么？
   血压（卧、立）、心率与心律（静息、节律）、呼吸、症状与体征
   → 时点由时程决定；长期用药先设基线

7. 边界句
   只写分类、机制、体内过程与效应类别；剂量与用法照底本；
   不作适应证判定，不作疗效断言，不构成用药建议。
```

## 用法要点

- **「阻断 α 受体」不是一条可用的表述。** 亚型不明，方向就可能相反；写到 α1 或 α2 才算落到位置。
- **效应上的分离要成对记录。** 血管被削、心脏被推，两个方向同时发生；只记一项，等于只记了一半。
- **首剂现象由机制推出。** 血管扩张＋前负荷下降＋体位，三条合起来才解释得通；处理原则也由这三条推出。
- **量值不写。** 剂量、减量幅度、判断阈值一律不填；需要时写「剂量与用法照底本」。

## 输出示例（骨架）

```text
待判：某药首次服用后出现眩晕与站立时血压下降
层次：α1 阻断（血管舒张为主），α2 负反馈保留
剩余：外周阻力下降、静脉回流减少 → 体位性低血压
结合性质：竞争性，可被递质部分夺回
时程与撤药：口服、首过明显；首剂效应集中在服药后短时间
体内过程：口服吸收好而首过明显，故口服剂量高于静脉所需
观察：卧位与立位血压、心率、眩晕出现与缓解时间、有无短暂意识改变
边界：写「立位较卧位下降」，不写「血压偏低」这类判断；剂量与用法照底本
```

## 不做什么

不判定某个人该不该用、不比较药物优劣、不推算剂量与减量节奏、不把首剂现象写成处置流程。涉个体的判断，由具备资质的人员依现行法律法规与规范、以现行药品说明书为依据作出。
