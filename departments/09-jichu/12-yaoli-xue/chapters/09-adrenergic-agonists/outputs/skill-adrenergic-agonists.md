# Skill：拟肾上腺素药——一张受体谱、一个剂量层次、一条观察纪律

## 何时用

- 读到「这支药升压／降压／强心／平喘」，要判断它在什么剂量、作用于哪一部位才成立
- 要把一支药的效应谱压成「受体 → 器官 → 表现」三列
- 需要解释为什么同一器官在不同剂量下方向相反（多巴胺的经典例子）
- 要判断一支药能不能口服、维持多久，需要一条结构判据
- 拟观察表时，要决定四组指标的频次与时点

## 核心判据（六问）

1. **依赖哪几类受体？** α1、α2、β1、β2、β3、多巴胺受体。受体谱越宽，效应越难分离，观察项越多。
2. **分布在哪？** 皮肤黏膜与内脏血管（α1）、骨骼肌血管（β2）、心肌（β1）、支气管与子宫（β2）、突触前与中枢（α2）、肾与肠系膜（多巴胺受体）。
3. **剂量在哪一段？** 小剂量偏 β（心脏兴奋、血管舒张），增量后 α1 占优（血管收缩）。不写剂量层次，句子就不完整。
4. **结构给了什么判据？** 有儿茶酚核 → 易被两种酶代谢、首过明显 → 口服无效、维持短；无儿茶酚核 → 可口服、维持长。
5. **反射改写了什么？** 血压升高可反射性减慢心率；缺少 α 效应时舒张压下降又可反射性加快心率。血压与心率必须分开记。
6. **观察补哪几栏？** 循环、局部、器官效应、主观感受。四组频次不同，时点必须与给药途径匹配。

## 执行步骤

```text
1. 收口：把待判句子压成一句「某受体被激动后的某效应」
2. 摆受体谱：列出该药激动哪几类受体，标出最宽与最窄的那一支
3. 对器官：写出受体在哪些器官，推出效应落点
4. 定层次：小剂量／增量后，效应方向是否改变
5. 查结构：有无儿茶酚核 → 给药途径与时程
6. 查反射：血压与心率之间是否互相改写
7. 落观察：四组指标 + 时点匹配 + 中性语言
8. 定边界：机制写足，剂量与判断阈值不写
```

## 硬约束

- **不写剂量、滴速、血压与心率的判断阈值的量值。** 需要时统一写「剂量与用法照底本」。
- **不作适应证判定、不作病情与预后判定、不作疗效与优劣断言、不作等级排名。**
- **引文逐字。** 标「教材·药理学·第9章 + 三级小节号」，核不到原文就不引。
- **不写品名、厂商、规格与价格。**
- **指标不等于判断。** 心率增快、血压下降都可能由药物以外的因素引起，记录只写所见与所测。
- **选择性是相对的。** 「β1 选择性」指常规剂量范围内的相对表现，增量后 β2 效应仍会出现。

## 交付物

1. 一张受体谱：哪几类受体、宽窄如何
2. 一张器官落点表：只写与待判句子相关的几行
3. 一句剂量层次判定：在哪一段，方向会不会变
4. 一条结构判据：能否口服、维持长短
5. 一栏观察补充 + 一句边界句

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 直接问「升压还是降压」 | 得到互相矛盾的答案 | 补剂量层次与作用部位两个条件 |
| 把两类受体效应对加 | 解释不了同一器官的方向反转 | 改为「相互制约后的综合结果」 |
| 用「专一」描述 β1 选择性 | 增量后的 β2 效应无法解释 | 改为「剂量范围内的相对表现」 |
| 把耐受当成药物失效 | 以加量对抗，越用越差 | 回到受体下调，重新评估方案 |
| 只记血压不记心率 | 反射性变化被读成药物直接作用 | 两项并列记录，注明体位与状态 |
| 记录写「循环改善」 | 判断混入事实，无法复核 | 改为具体指标与数值方向 |

## 边界

本 Skill 只处理「一句表述 → 受体谱 → 剂量层次 → 观察项」的判定，不涉及剂量、适应证与临床决策。本章内容为教学材料，不构成用药建议；任何涉及个体的用药评估，须由具备资质的人员依现行法律法规与规范、以现行药品说明书为依据作出。
