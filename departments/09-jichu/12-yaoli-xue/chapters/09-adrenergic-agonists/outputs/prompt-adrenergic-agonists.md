# Prompt：拟肾上腺素药的「受体谱 × 剂量层次」判定器

## 用途

给一段关于拟肾上腺素药的表述，输出四样东西：它依赖哪几类受体；这些受体分布在哪些器官；这条表述成立在什么剂量层次与给药途径下；以及它需要配哪些观察项。

三种场合最常用。其一，备课核对「为什么同一支药小剂量与大剂量面貌不同」——答案在受体选择顺序，不在「药性不稳」。其二，辨析「升压还是降压」这类问法——问法本身缺了两个条件：剂量与看哪一部位。其三，拟观察表——四组指标加时点匹配，才能把效应曲线写下来而不是只留一个截面。

## 模板

```text
【待判表述】<一句话，去掉药名与程度词>

1. 依赖哪几类受体？
   α1 / α2 / β1 / β2 / β3 / 多巴胺受体
   → 受体谱越宽，效应越难分离，观察项越多

2. 分布在哪？
   皮肤黏膜与内脏血管（α1）、骨骼肌血管（β2）、心肌（β1）、
   支气管与子宫（β2）、突触前与中枢（α2）、肾与肠系膜（多巴胺受体）
   → 同一器官两类受体并存时，方向由剂量层次决定

3. 剂量层次在哪一段？
   小剂量偏 β（心脏兴奋、血管舒张）／增量后 α1 占优（血管收缩）
   → 写明「在什么剂量、看哪一部位」，否则句子不完整

4. 给药途径与时程？
   儿茶酚胺类：口服无效，需注射；非儿茶酚胺类：可口服，维持较长
   → 途径决定时点，时点决定记录能不能反映过程

5. 效应能不能被反射改写？
   血压升高可反射性减慢心率；缺少 α 效应时舒张压下降又可反射性加快心率
   → 血压与心率必须分开记录，否则因果会被读反

6. 观察补什么？
   循环（心率、心律、收缩压、舒张压）、局部（穿刺部位）、
   器官效应（瞳孔、皮肤黏膜、尿量、呼吸）、主观感受
   → 四组频次不同：循环最频，主观感受按固定时点

7. 边界句
   只写受体类别、机制、体内过程与效应类别；剂量与用法照底本；
   不作适应证判定，不作疗效断言，不构成用药建议。
```

## 用法要点

- **不要问「升压还是降压」。** 正确问法是「在什么剂量、作用于哪一部位、当时的外周阻力如何」。缺条件的问法必然得到互相矛盾的答案。
- **受体谱宽窄决定观察项目多少。** 兼激动多巴胺受体者要看尿量与穿刺局部；β1 选择性者重点看心率、心律与心排出量的间接指标。
- **耐受不是失效。** 长期激动使受体数目下调，效应减弱；处理原则是不以加量对抗，而是重新评估方案。
- **量值不写。** 剂量、滴速、判断阈值一律不填；需要时写「剂量与用法照底本」。

## 输出示例（骨架）

```text
待判：某药静脉滴注后收缩压升高、舒张压下降、脉压增大
受体：β1（心肌）+ β2（骨骼肌血管），几乎无 α
分布：心脏与骨骼肌血管
剂量层次：常规范围内以 β 效应为主
途径：静脉滴注，起效快、消退快 → 观察需密集
反射：舒张压下降经反射使心率进一步加快，与 β1 直接作用叠加
观察：心率与心律、收缩压与舒张压、皮肤黏膜色泽、主观心悸
边界：不写「循环改善」这类判断；剂量与用法照底本
```

## 不做什么

不判定某个人该不该用、不比较药物优劣、不推算剂量与滴速、不把受体机制写成处置流程。涉个体的判断，由具备资质的人员依现行法律法规与规范、以现行药品说明书为依据作出。
