# Skill：三类抗生素——靶点决定范围，位点决定配伍

## 何时用

- 读到「某药对胞内病原体作用突出 / 某药只对革兰阳性菌有效」，需要判断这句话由靶点还是由到达决定
- 遇到「两类都作用于同一亚基，为何不宜同用」，需要区分位点竞争与交叉耐药
- 要解释「为什么骨与关节感染会提到某一类」，需要把分布与用途连起来
- 要把多肽类三个小组摆在一起而不排等级
- 要写观察表，却不确定该按品种加哪一栏

## 核心判据（六问）

1. **靶点在哪？** 核糖体的哪一个亚基，或核糖体之外（外膜脂质、细胞壁前体末端、合成载体）。靶点一换，范围随之换。
2. **位点与谁重叠？** 重叠意味着竞争（合用减弱）；位点相邻且共享甲基化，则意味着交叉耐药（一起失效）。两件事不可混说。
3. **谱到哪为止？** 阳性范围与阴性范围同时写出；阴性范围决定它不能用于哪些类别。
4. **谱由什么决定？** 靶点存在与否，还是到达（外膜通透性、转运），还是活化（前药须经病原体的酶转化）。
5. **配伍是哪一型？** 位点竞争、机制相容、不良反应叠加——三型的处理完全不同。
6. **观察多出哪一栏？** 腹泻的性质与频次、输注中的潮红与血压、尿量与尿的外观、血象与肝功能——按品种，不按类别。

## 执行步骤

```text
1. 收口：把待判句子压成一句「作用环节或谱的类别」
2. 定靶点：亚基 / 外膜 / 前体 / 载体，四选一
3. 查位点：与哪些类别重叠，后果是竞争还是交叉耐药
4. 画边界：阳性范围 + 阴性范围，一起写
5. 找原因：靶点、到达、活化，指出主因
6. 推配伍：竞争 / 相容 / 叠加，三型分开
7. 落观察：按品种与给药途径加栏
8. 定去向：谁判断、依什么、如何留痕
```

## 硬约束

- **不写剂量、浓度、配比、疗程与给药间隔的量值。** 需要剂量时统一写「剂量与用法照底本」。
- **不作适应证判定，不作病情与预后判定，不作疗效断言与优越性断言，不作类别或品种之间的等级排名。**
- **引文逐字。** 标「教材·药理学·第41章·41.x.y」，核不到原文就不引；改写须标明是改写。
- **不写品名、厂商、剂型规格与价格。**
- **「可替代」不等于「更好」。** 胸苷激酶缺陷的病毒对某药仍敏感，说明机制上绕开了，不说明强弱。
- **不确定就写下来。** 标待核实，不用推测填空。

## 交付物

1. 四格定位：靶点 / 位点 / 谱（含边界）/ 配伍型
2. 一句主因：谱的宽窄由靶点、到达还是活化决定
3. 一句配伍判断：竞争、相容还是叠加
4. 一栏观察补充：按品种落到字段
5. 一句边界句：本章只描述机制与类别，判断归属另行

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 同靶点当同类 | 以为同一亚基上的药可以互换 | 查位点：重叠即竞争，不是等效 |
| 谱窄当弱 | 「只对革兰阳性菌有效，不如广谱」 | 把原因归到靶点或到达，删掉「不如」 |
| 竞争与交叉耐药混说 | 敏感时的争位点与耐药时的共享甲基化写在一句 | 分开两段写 |
| 只写阳性范围 | 读者误以为全覆盖 | 每次补阴性范围 |
| 机制相容当联用推荐 | 由「不竞争」推出「应当合用」 | 改为「可先后作用于不同靶点，方案另定」 |
| 观察项通用化 | 三类药都写「注意观察」 | 按品种：腹泻、输注反应、尿、血象 |

## 与相邻章节的接缝

- 第 40 章（β-内酰胺类）：细胞壁活性药物使氨基糖苷类更易进入，是「机制相容」的典型；与本章的位点竞争恰成对照。
- 第 42 章（氨基糖苷类）：同样作用于核糖体，但亚基不同（三十S），故不构成位点竞争；两者都影响神经肌肉传递，属不良反应叠加。
- 第 43 章（四环素类与氯霉素类）：氯霉素与大环内酯类、林可霉素类位点相邻，通过屏障与菌种差异解释「同靶点不同谱」。
- 第 38 章（抗菌药物概论）：本章的「靶点决定范围」在那章是总则，本章是三组实例。

## 边界

本 Skill 只处理「一条表述 → 四格定位」的判定，不涉及剂量、适应证与临床决策。本章内容为教学材料，不构成用药建议；任何涉及个体的用药评估须由具备资质的人员依现行法律法规与规范作出。
