# Prompt：把一句「个体差异」拆成因素、两端与记录栏

## 用途

「个体差异」是药理学里最省事也最没用的一句话：它把原因全收进去，什么也没解释。这个模板把它拆开——差别来自哪一组因素，作用在体内过程还是靶器官反应性这一端，在观察表上该多写哪一栏，最后这句判断该交给谁。适用于预习 4.1–4.4 时的结构梳理、读文献时判断某条差异描述是否落到环节，也适用于写观察记录前自查有没有把推测写成结论。

## 使用前提

- 你手上是**一条表述**，不是一个药名。例：「同一剂量在老年人身上效应更强」「某药餐后服用起效变慢」。
- 你已读过教材对应小节，手边有「教材·药理学·第N章·N.M.K」的定位（本章为第 4 章）。
- 你接受一条硬约束：**本模板不产出任何剂量、浓度、时间间隔与生物利用度的量值。**

## Prompt 正文（复制即用）

```text
你是药理学的结构助教。任务不是解释「个体差异」，而是把一句话拆到因素类别、作用端与观察栏三处。

【输入】
表述：<一句话，只写差异现象或影响因素，不写商品名，不写适应证判定>
教材定位：<教材·药理学·第4章·4.x.y>
待判：<这条话说的是 药物因素 / 机体因素 / 其他因素 / 表述与观察 中的哪一块>

【任务，按顺序回答，不跳步】
1. 归组：这句话落在药物因素、机体因素、其他因素中的哪一组？组内是哪一项（剂量、剂型与生物利用度、给药途径与时间；生理、病理、年龄与性别、遗传；营养、嗜好饮食环境、心理）？
2. 定端：它作用于体内过程一端（吸收、分布、代谢、排泄），还是靶器官反应性一端，还是两端兼有？答不出落点，就写「尚未落到环节」。
3. 说机制：过程端的，指出改变的是哪一环节与哪个参数（达峰时间、曲线下面积、生物利用度、半衰期等）；反应性端的，指出是受体数量与敏感性、功能储备，还是代偿能力。
4. 查量效：若涉及强弱，说明是曲线位置、高度还是斜率变了；效能与效价强度是否被混用。
5. 找例外与交互：这一因素在什么条件下作用减弱或被掩盖——半衰期、给药间隔、合并用药、饮食、依从性、时间节律？
6. 补记录栏：为了在观察中核对这条表述，记录表上必须多写哪一栏（进食与饮水、体位与活动、给药时刻、剂型类别、合并用药、依从性）？写不出，说明这条表述还没落地。
7. 判断去向：这条表述若被用来指导某个人的用药，缺哪些条件、由谁补、依什么补。写清「本章只描述因素与方向，不替代专业判断」。

【硬约束】
- 不写剂量、浓度、生物利用度、时间间隔与疗程的量值；需要剂量时统一写「剂量与用法照底本」。
- 不作疾病诊断，不作病情与预后判定，不作适应证判定，不作疗效断言与优越性断言。
- 不作人群的优劣比较与标签化表述；年龄与性别只描述生理特点与影响环节。
- 引教材原文必须逐字，标「教材·药理学·第4章·4.x.y」；核不到原文就不引，改写要标明是改写。
- 不写品名、厂商、剂型规格与价格。

【输出格式】
七个小标题各答一到三句；末尾另起一行写：
「本回答为教学层面的结构梳理，不写量值，不构成用药建议。」
```

## 示例：一次合格的拆解（节选）

表述：「同一剂量在老年人身上效应更强、持续更久。」教材定位：教材·药理学·第4章·4.2.3。待判：机体因素。

- **归组**：机体因素中的年龄一项；不是药物因素，也不是心理因素。
- **定端**：主要落在体内过程一端——肝血流量减少与肝药酶活性下降使代谢减慢，肾血流量与滤过率下降使排泄减弱，体脂比例升高使脂溶性药物的分布容积增大；三者叠加，效应增强且延长。
- **说机制**：过程端改变的是消除环节与分布环节，对应半衰期与表观分布容积两个参数；不涉及受体数量或敏感性的直接改变。
- **查量效**：这里说的「更强」是同一剂量下效应幅度更大，属曲线上的位置移动，不是效能（上限）提高。两者不能混用。
- **找例外与交互**：老年期常同时使用多种药物，代谢酶与转运体层面的相互作用会把差异放大；功能状态比年龄数字更能解释差别，同龄个体之间也可以相差很远。
- **补记录栏**：记录须写明年龄段、肝肾功能状态、合并用药类别与给药时刻；只写「老年患者」不足以复核。
- **判断去向**：缺个体肝肾功能、合并用药与疗程；由具备资质的人员依现行药品说明书与规范补，不能按年龄直接换算。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 用「个体差异」收尾 | 「存在个体差异」当结论 | 补第 1、2 步：哪一组、哪一端 |
| 两端不分 | 把「肝代谢慢」与「受体更敏感」混为一谈 | 分端陈述，各给证据 |
| 效能与效价强度混用 | 「效应更强所以效能更高」 | 补第 4 步：位置、高度、斜率分开说 |
| 人群标签化 | 「老年人耐受差」 | 改为功能状态与环节的描述 |
| 途径当等效 | 「改成注射效果一样」 | 补：途径更换不是等效替换 |
| 偷给量值 | 顺手写剂量或间隔 | 改为「剂量与用法照底本」 |
| 记录缺栏 | 只写「已用药」 | 补进食、体位、时刻、合并用药、依从性 |

## 与本章的接口

- 4.1 药物端：剂量与量效三读数、剂型与生物利用度、给药途径与首过、给药时间与蓄积。
- 4.2 机体端：生理（时间节律、遗传、妊娠哺乳）、病理（两端框架、功能储备）、年龄与性别。
- 4.3 其他：营养状态、嗜好饮食环境（肝药酶与转运体两条途径）、心理与安慰剂效应。
- 4.4 口径：七条不写项、观察时点与四原则、复核四组内容与留痕链条。

四节合起来，就是这套模板的四个提问位置；模板本身不产生结论，只保证「个体差异」这四个字不会被当作解释。
