# Skill：影响药物效应的因素——三组、两端、一条记录链

## 何时用

- 读到「个体差异」「因人而异」「老年耐受差」，需要把话落到环节
- 要解释「同一剂量为什么这次效应强、那次弱」
- 遇到「换条给药途径效果一样吗」的问题
- 要判断某条差异描述属于过程端还是反应性端
- 写观察记录前，不确定该补哪几栏

## 核心判据（六问）

1. **哪一组？** 药物因素（剂量、剂型与生物利用度、给药途径与时间、配伍）／机体因素（生理、病理、年龄与性别、遗传）／其他（营养、嗜好饮食环境、心理与安慰剂）。
2. **哪一端？** 体内过程（吸收、分布、代谢、排泄）／靶器官反应性（受体数量与敏感性、功能储备、代偿能力）／两端兼有。答不出落点，「个体差异」就只是替换说法。
3. **哪个参数？** 过程端落到达峰时间、曲线下面积、生物利用度、半衰期、表观分布容积；反应性端落到受体与储备，不落到参数。
4. **曲线怎么动？** 位置（效价强度）、高度（效能）、斜率（敏感程度）三者分开说；「效应更强」通常是位置移动，不是上限提高。
5. **什么条件？** 半衰期、给药间隔、合并用药、饮食、依从性、时间节律，哪一项使这条规律减弱或被掩盖。
6. **判断交给谁？** 由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南决定。教材给方向，不给方案。

## 执行步骤

```text
1. 收口：把待判句子压成一句「现象或关系」，删掉药名与「故应加量/减量」类推论
2. 归组：药物 / 机体 / 其他，组内定位到具体项
3. 定端：过程端 / 反应性端 / 两端兼有
4. 落机制：哪一环节、哪个参数；反应性端的说清是受体、储备还是代偿
5. 查量效：位置、高度、斜率，效能与效价强度是否混用
6. 找例外：半衰期、间隔、合并用药、饮食、依从性、节律
7. 补记录：多写哪一栏——进食饮水、体位活动、给药时刻、剂型、合并用药、依从性
8. 定去向：谁判断、依什么、如何留痕
```

## 硬约束

- **不写剂量、浓度、生物利用度、时间间隔与疗程的量值。** 需要剂量时统一写「剂量与用法照底本」。
- **不作疾病诊断，不作病情与预后判定，不作适应证判定。**
- **不作疗效断言与优越性断言，不作药物之间的优劣与等级排名。**
- **不作人群的污名化与标签化。** 年龄与性别只描述生理特点与影响环节；统计上的群体差异不直接推及个体。
- **引文逐字。** 标「教材·药理学·第4章·4.x.y」，核不到原文就不引；改写须标明是改写。
- **剂型与途径只改到达，不改作用方式。** 途径更换不是等效替换，须重新观察与记录。
- **记录只写所见。** 判断另设一栏，注明依据与提出者。

## 交付物

1. 一次归组与定端：哪一组因素、哪一端
2. 一个环节与一个参数（或受体与储备）
3. 一条量效读法：位置、高度、斜率哪个动了
4. 一栏记录补充：因此要多写什么
5. 一句边界句：判断归具备资质的人员，教材不替代专业判断

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 「个体差异」当结论 | 什么也没解释 | 补归组与定端两步 |
| 两端不分 | 代谢慢与受体敏感混说 | 分端陈述，各给证据 |
| 效能当效价强度 | 「更强所以上限更高」 | 位置、高度、斜率分开 |
| 人群标签 | 「老年人耐受差」 | 改为功能状态与环节描述 |
| 途径当等效 | 「换注射一样」 | 补首过与吸收份量的差别 |
| 制剂当药理 | 「缓释片作用更强」 | 改为「到达过程改变」 |
| 记录写评价 | 「效果不错」「明显好转」 | 改为可测量的表现与时刻 |

## 与相邻章节的接缝

- 第 1 章（绪论）：本章的「条件性」在那里是阅读纪律，在这里分成三组具体因素。
- 第 2 章（药效学）：本章的量效三读数在那里是机制讨论，在这里成为归因工具。
- 第 3 章（药动学）：本章的过程端在那里有整套参数与模型，本章只取方向。
- 第 5 章起（各论）：每一章讲具体药物时，都要回答「哪些因素会改变它的效应」，用的是本章的框架。

## 边界

本 Skill 只处理「一条差异表述 → 因素组与两端」的归位，不涉及剂量、适应证与临床决策。本章内容为教学材料，不构成用药建议；任何涉及个体的用药评估须由具备资质的人员依现行法律法规与规范作出。
