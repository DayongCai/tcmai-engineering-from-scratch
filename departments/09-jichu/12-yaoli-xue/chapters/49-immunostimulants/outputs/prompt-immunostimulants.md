# Prompt：把一条免疫增强药的表述，按「环节—依赖条件—反应谱」归位

## 用途

免疫增强药的讨论里，最容易出现的两种句子是「提高免疫力」与「这个药能辅助抗感染」。前者既不是机制也不是结论，后者把辅助位置说成了独立作用。这个模板把一句话逼回去：它作用于应答的哪一环、是否需要抗原、效应是特异还是非特异、因此欠哪一方面的账。适用于预习 49.1–49.4 前的结构梳理、读文献时判断某条结论属于机制还是承诺，以及写讨论前自查有没有越过机制去保证结果。

## 使用前提

- 你手上是**一条表述**，不是一个药名。例：「某药促进巨噬细胞的吞噬功能」「某类药的作用依赖抗原同时给药」。
- 你已读过教材对应小节，手边有「教材·药理学·第N章·N.M.K」的定位（本章为第 49 章）。
- 你接受一条硬约束：**本模板不产出任何剂量、疗程、效价与含量的量值。**

## Prompt 正文（复制即用）

```text
你是药理学的结构助教。任务不是评价药物，而是把一条免疫增强药的表述钉在「环节—依赖条件—反应谱—观察」这条链上，并说明它能推到哪、不能推到哪。

【输入】
表述：<一句话，只写作用、性质或观察要求，不写商品名，不写适应证判定>
教材定位：<教材·药理学·第49章·49.x.y>
待判：<这条话说的是环节 / 来源 / 依赖条件 / 体内过程 / 临床应用类别 / 不良反应 / 观察 中的哪一环>

【任务，按顺序回答，不跳步】
1. 方向：这条表述属于「增强」还是「抑制」方向？与免疫抑制药的分界在哪一句上？
2. 归环：落在「抗原处理与呈递→淋巴细胞分化与增殖→效应细胞功能→细胞因子网络」四环中的哪一环？跨环的，写明中间缺不缺环节。
3. 依赖条件：这条作用是否需要抗原同时或预先存在？效应是特异性的还是非特异性的？这是佐剂与其他类别最本质的分界，也是判断「辅助位置」的依据。
4. 类别归属：六个板块之一（免疫佐剂、细胞因子、微生物来源、生物制品、化学合成、植物与中药来源）；交叉归属的（如卡介苗兼有佐剂与微生物来源两重身份），说明是两个视角而不是两次叙述。
5. 体内过程：这条作用的部位要求是什么（局部沉积与引流淋巴结、经注射进入血液、口服后分布于全身）？给药途径与作用部位是否匹配？
6. 反应谱：按来源与途径归类——菌体与蛋白类易发热、过敏与局部炎症；化学合成类多为胃肠道与皮肤表现；细胞因子类为流感样症状与器官功能影响；活菌制剂另有增殖风险。指出这条机制主要欠哪一组。
7. 表达边界：用三个问题自查——这句话是否对某个人作出了判定、是否对效果作出了承诺、是否指向了具体产品？任一为是，改用环节、方向、类别、趋势四个词重写。

【硬约束】
- 不写剂量、疗程、效价、单位、含量、浓度的量值；需要剂量时统一写「剂量与用法照底本」。
- 不作适应证判定，不作病情与预后判定，不作疗效断言与优越性断言，不作药物之间的等级排名。
- 引教材原文必须逐字，标「教材·药理学·第49章·49.x.y」；核不到原文就不引，改写须标明是改写。
- 不写品名、厂商、剂型规格与价格；不写疫苗产品名称与免疫程序参数。
- 对任何人群不作标签化描述；教学案例一律脱敏合成。
- 信息不足时直接说缺哪一项，不要用常识补。

【输出格式】
七个小标题各答一到三句；末尾另起一行写：
「本回答为教学层面的结构梳理，不写量值，不构成用药建议。」
```

## 示例：一次合格的归位（节选）

表述：「某类制剂与抗原同时使用，可增强针对该抗原的应答。」教材定位：教材·药理学·第49章·49.2.1。待判：依赖条件。

- **方向**：增强方向，但增强的是针对特定抗原的应答，不是整体防御水平。
- **归环**：作用于抗原处理与呈递环节——延长抗原在局部的滞留、促进呈递细胞摄取与成熟。
- **依赖条件**：必须与抗原同时或预先使用；脱离抗原只剩局部炎症与非特异性刺激，这是与其他类别最本质的分界。
- **类别归属**：免疫佐剂；若该制剂是菌体来源，则同时落在微生物来源这一板块，属两个视角而非重复。
- **体内过程**：给药后沉积于给药部位、随淋巴引流缓慢进入引流淋巴结、全身分布有限——这解释了为什么效应集中在引流区域，也解释了为什么局部反应常见而全身反应相对少见。
- **反应谱**：局部红肿、硬结、疼痛与引流淋巴结肿大为主；活菌制剂另有局部溃疡与播散风险。
- **表达边界**：可写「增强针对该抗原的应答」，不可写「提高免疫力」；后者既不对应环节，也不对应指标。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 「提高免疫力」 | 用一句口号代替环节 | 回到第 2 步，写清落在哪一环 |
| 佐剂当同义语 | 把佐剂与免疫增强药混用 | 补第 3 步：效应依赖抗原 |
| 辅助当主治 | 「用于治疗某病」 | 改为「处于综合处理的辅助位置」 |
| 网络当线性 | 用剂量推效应强弱 | 补第 5、6 步的网络调控与反应谱 |
| 单指标评价 | 用一个指标评价全部类别 | 按环节选指标 |
| 偷给量值 | 顺手写效价或单位 | 一律改为「剂量与用法照底本」 |
| 越过机制承诺 | 「能有效防治」 | 改为机制句，删掉结果承诺 |

## 与本章的接口

- 49.1 立框架：与免疫抑制药的方向对照、三条分类主线、六板块与三处常见偏差。
- 49.2 展开三块：佐剂（依赖抗原、局部滞留）、细胞因子（受体后信号、网络调控）、微生物来源与化学合成（模式识别受体与功能环节两条路）。
- 49.3 六类应用与反应谱：辅助位置的由来、按环节选指标、按来源与途径归类反应。
- 49.4 表述、观察与复核：三问判据、六组字段、三层复核与留痕四要素。
