# Skill：免疫增强药——方向、环节、依赖条件，三样先定

## 何时用

- 读到「提高免疫力 / 增强抵抗力」，需要把这句话换成环节与机制
- 要解释「佐剂为什么必须和抗原一起用」
- 遇到「辅助抗感染」「肿瘤辅助」这类表述，需要说清辅助位置的含义
- 要说明为什么细胞因子类起效慢、持续久，且剂量与效应不必然同向
- 要把观察整理成能复核的记录，尤其是局部反应与流感样反应的记录

## 核心判据（六问）

1. **方向？** 增强还是抑制；分界句是「恢复或放大已减弱的防御性应答」与「压低过强的病理性应答」。
2. **哪一环？** 抗原处理与呈递 → 淋巴细胞分化与增殖 → 效应细胞功能 → 细胞因子网络。
3. **要不要抗原？** 佐剂必须依赖抗原；细胞因子与化学合成类多不依赖；生物制品介于两者之间。这一条决定效应是特异还是非特异。
4. **哪个板块？** 免疫佐剂、细胞因子、微生物来源、生物制品、化学合成、植物与中药来源。交叉归属是两个视角，不是两套药理。
5. **反应谱怎么来？** 菌体与蛋白类易发热、过敏与局部炎症；化学合成类多为胃肠道与皮肤；细胞因子类为流感样症状与器官功能影响；活菌制剂另有增殖风险。
6. **判断交给谁？** 由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南决定。

## 执行步骤

```text
1. 收口：把待判句子压成一句「性质或作用」，删掉药名与用途
2. 定方向：增强或抑制，写出分界句
3. 归环：四环定位，跨环的写明缺不缺
4. 定依赖：要不要抗原、特异还是非特异
5. 落板块：六板块之一，交叉归属说明视角
6. 查体内过程：局部沉积 / 注射入血 / 口服分布，与作用部位是否匹配
7. 划反应谱：按来源与途径归类，指出观察要点
8. 过三问：是否判定个人、是否承诺效果、是否指向产品
```

## 硬约束

- **不写剂量、疗程、效价、单位、含量、浓度的量值。** 需要剂量时统一写「剂量与用法照底本」。
- **不作适应证判定，不作病情与预后判定，不作疗效断言与优越性断言，不作等级排名。**
- **引文逐字。** 标「教材·药理学·第49章·49.x.y」，核不到原文就不引；改写须标明是改写。
- **不用「提高免疫力」作结论。** 它既不对应环节，也不对应指标；教材把它列为最容易被写成夸大的表述。
- **中药类成分只写类别与机制方向。** 不写含量与效价，不写制剂规格，不作承诺式表述。
- **不标签化。** 不把免疫状态与人群身份对应；教学案例一律脱敏合成。
- **不确定就写下来。** 标待核实，不用推测填空。

## 交付物

1. 一条归位链：方向 → 环节 → 依赖条件 → 板块 → 反应谱
2. 一处依赖判断：这条作用要不要抗原、效应是否特异
3. 一组观察字段：局部、全身、实验室三层里该写哪几项
4. 一句边界句：本章只描述机制与类别，判断归属另行

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 「提高免疫力」 | 口号代替机制 | 改为环节＋方向＋类别 |
| 佐剂当同义语 | 忽略抗原依赖 | 补依赖条件这一环 |
| 辅助当主治 | 把辅助位置写成独立作用 | 改为「综合处理的一部分」 |
| 网络当线性 | 用剂量推效应强弱 | 补网络调控与三条用药思路 |
| 单指标评价 | 用一个指标评价全部类别 | 按环节选指标 |
| 漏记迟发反应 | 给药数日后出现的表现被忽略 | 记录写明给药时间与出现时间 |
| 偷给量值 | 效价与单位无来源 | 改为「剂量与用法照底本」 |

- 第 46 章（抗寄生虫药）：左旋咪唑在两章分别以驱虫药与免疫调节药出现，本章只提及免疫调节这一性质，不引申为临床应用。
- 第 47 章（抗恶性肿瘤药）：卡介苗的局部灌注、集落刺激因子的造血支持在两章都出现，角度不同——那一章看局部非特异性刺激与化疗后支持，本章看环节与类别。
- 第 3 章（药动学）：本章的「局部滞留、蛋白降解、口服吸收」在那一章有参数化写法，本章只用定性关系。

## 边界

本 Skill 只处理「一条表述 → 环节与依赖条件」的判定，不涉及剂量、适应证与临床决策。本章内容为教学材料，不构成用药建议；任何涉及个体的用药评估须由具备资质的人员依现行法律法规与规范作出，并以现行药品说明书为依据。
