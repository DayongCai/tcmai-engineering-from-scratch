# Skill：镇痛药——四段推演、三条线索、两种角色

## 何时用

- 读到「某药作用强 / 起效快 / 更安全」，需要判断这句话站在四段中的哪一段
- 要解释「为什么同一个药既镇痛又致便秘、缩瞳、呼吸抑制」
- 要解释「为什么患者安静了不等于疼痛缓解」
- 要解释「为什么部分激动药加量效应不增」
- 要判断某个合成类药物的观察重点：去看瞳孔、看呼吸、看胸壁、看心电，还是看惊厥倾向
- 要把依赖与戒断写进记录，却不想写成评价

## 核心判据（五问）

1. **哪一型受体、哪种方式？** μ、δ、κ、孤啡肽受体；完全激动、部分激动、拮抗。方式决定效应谱与有无平台。
2. **哪一组效应？** 中枢组、平滑肌组、心血管组。三组各对应一套观察项，混写就看不出归属。
3. **哪一类用途？** 急性剧痛、心源性哮喘辅助、麻醉组成、止泻、镇咳、依赖的替代与过渡。停在类别，不落到个体情形。
4. **观察权重怎么变？** 呼吸频率是共同项，但不同药另有主项：哌替啶看瞳孔与心率、芬太尼类看胸壁与心率、美沙酮看心电、曲马多看惊厥与五羟色胺能表现。
5. **判断交给谁？** 由具备资质的人员依现行法律法规与规范、以现行药品说明书与制度决定，并留痕。

## 执行步骤

```text
1. 收口：把待判句子压成一句「某受体被激动 / 被拮抗」
2. 定式：受体型别 + 完全/部分/拮抗 + 有无兼有其他成分
3. 分效：中枢 / 平滑肌 / 心血管三组归位
4. 归途：用途写到类别，不写具体情形
5. 定观：呼吸、意识、瞳孔、排尿、心电、惊厥倾向，写明权重
6. 查边界：疗效断言、优劣比较、绝对化、依赖人群标签化
7. 定去向：谁判断、依什么、如何留痕
```

## 硬约束

- **不写剂量、浓度、疗程的量值。** 需要剂量时统一写「剂量与用法照底本」。
- **不作适应证判定，不作病情与预后判定，不作疗效与优越性断言，不作等级排名。**
- **引文逐字。** 标「教材·药理学·第 18 章·N.M.K」，核不到原文就不引；改写须标明是改写。
- **不写品名、厂商、剂型规格与价格。**
- **依赖与戒断用中性口径。** 写适应性改变与停药表现，不写人格评价，不作人群标签化。
- **管理属性只写「受专门制度约束」**，不写处方流程与任何获取途径。
- **机制不确定的照教材写「可能涉及」**，不把假说当结论。

## 交付物

1. 一条四段链：受体与方式 → 效应组 → 用途类别 → 观察项目
2. 一处观察权重说明：这条表述让哪一项权重上升、哪一项下降
3. 一条耐受提示：哪些效应耐受快、哪些几乎不耐受
4. 一句边界句：本章只写类别与机制，判断归属另行

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 把镇静当镇痛 | 疼痛未评估却记为「已控制」 | 分开记录自述疼痛与行为表现 |
| 照吗啡经验找缩瞳 | 哌替啶效应过强被漏判 | 记住阿托品样作用使瞳孔散大 |
| 把「用了很久」当「效应不再出现」 | 漏记持续的缩瞳与便秘 | 记住耐受不平行 |
| 由脂溶性直推适应证 | 用理化性质替代个体判断 | 补效应组与观察项，判断归具备资质的人员 |
| 把部分激动药当「弱一点的完全激动药」 | 加量后不良反应升而效应不升 | 回到内在活性与平台现象 |
| 记录里写人格评价 | 标签化，复核无空间 | 改为适应性与停药表现的中性描述 |

## 与相邻章节的接缝

- 第 17 章（解热镇痛抗炎药）：本类对锐痛与内脏绞痛作用有限，那一类针对前列腺素介导的发热与轻中度疼痛；术后镇痛中两类按机制互补而非相互替代。
- 第 11 章（局部麻醉药）：同在「镇痛」名下，但一个在中枢受体，一个在神经传导的钠通道。
- 第 12 章（全身麻醉药）：本类不引起意识消失，这一条正是两章的分界；芬太尼类作为麻醉组成则是两章的接口。
- 第 15 章（抗精神失常药）：同一受体在不同通路被阻断/激动而呈现不同效应，两章用的是同一种分析方法。

## 边界

本 Skill 只处理「一句表述 → 四段定位」的判定，不涉及剂量、适应证与临床决策。本章内容为教学材料，不构成用药建议；任何涉及个体的用药评估须由具备资质的人员依现行法律法规与规范作出，并对观察、记录与复核全程留痕。
