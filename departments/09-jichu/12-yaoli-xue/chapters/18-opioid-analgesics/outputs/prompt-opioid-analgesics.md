# Prompt 模板：镇痛药的四段推演

## 用途

拿到一段关于阿片类或其他镇痛药的表述，用这套模板沿「受体—效应—用途—观察」四段把它走一遍，判断这句话站在哪一段、能推到哪、在哪一处越了界。适用于：读教材时自查有没有把「镇痛」读成「包治各种疼痛」；判断某个新药属于哪一组、观察重点该落在哪里；把「某药更安全」这类说法拆成效应谱与风险落点；在讨论中把「患者安静了」与「疼痛缓解了」分开。

模板不产出用药结论，只产出四个定位：受体与作用方式、效应组、用途类别、观察项目。

## 用法

按顺序填四格，填不满就说明这句话还缺依据。

1. **受体与方式**：作用于哪一型受体（μ、δ、κ、孤啡肽受体）？是完全激动、部分激动、还是拮抗？作用环节是否兼有其他成分（M 受体阻断、单胺再摄取抑制、多巴胺受体阻断）？方式不同，效应谱与平台现象都不同。
2. **效应组**：这句话说的是中枢组（镇痛、镇静、呼吸抑制、镇咳、缩瞳、恶心呕吐）、平滑肌组（便秘、胆道、泌尿、支气管、子宫）、还是心血管组（血管扩张、体位性低血压、颅内压升高）？三组各有各的观察项。
3. **用途类别**：写的是哪一类用途——急性剧痛、心源性哮喘辅助、麻醉组成、止泻、镇咳、依赖的替代与过渡？用途要停在类别，不写具体情形。
4. **观察项目**：呼吸频率与深度、意识水平、瞳孔、心率、排尿情况，哪几项因这条表述而权重上升？写不出权重变化，说明这句话还没落地。

## 输出格式

```text
原句：……
受体与方式：……（型别 + 完全/部分/拮抗 + 兼有成分）
效应组：中枢 / 平滑肌 / 心血管（写明具体效应）
用途类别：……（类别，不写个体情形）
观察项目：……（权重的增减）
越界检查：是否含疗效断言 / 优劣比较 / 绝对化 / 依赖人群标签化
落点：剂量与用法照底本；判断归具备资质的人员
```

## 硬约束

- 不写剂量、浓度、疗程的量值；需要剂量时统一写「剂量与用法照底本」。
- 不作适应证判定，不作病情与预后判定，不作疗效与优越性断言，不作等级排名。
- 引文逐字，标「教材·药理学·第 18 章·N.M.K」；核不到原文就不写。
- 依赖与戒断一律用中性口径：写适应性与停药表现，不写人格评价，不作人群标签化。
- 管理属性只写「受专门制度约束」，不写处方流程与任何获取途径。
- 机制不确定的（如某些其他镇痛药）照教材的「可能涉及」写，不把假说当结论。

## 一个反例

「患者用完药安静了，说明疼痛控制住了」——两处错：把镇静当镇痛；把单次观察当结论。按模板改写为：「给药后患者由坐立不安转为卧床安静，自述疼痛程度未作评估；镇静属可预期效应，不等于疼痛缓解；观察项目增设疼痛自述与呼吸频率、意识水平的定时记录。」
