# Prompt：把一条激素类药的表述，先定向、再定谱、后定轴

## 用途

肾上腺皮质激素类药的讨论最容易出现两种句子：一种是「某药抗炎作用强」，把活性谱与剂量混作一谈；另一种是「某药可以替代另一种」，把补充、刺激与抑制当成同一件事的三种做法。这个模板要求一句话先交代三件事：它属于三个方向中的哪一个、它的活性谱与时效落在哪一端、它与那条轴是什么关系。适用于预习 34.1–34.4 时的结构梳理、读说明书时判断某句讲的是作用环节还是个体方案，以及写讨论前自查有没有把「同源」写成「意外」。

## 使用前提

- 你手上是**一条表述**，不是一个药名。例：「某药对子宫颈无作用，但可致水钠潴留」不属本章；「某药需在肝内转化为活性形式」「某药的效应受皮质状态限制」属本章。
- 你已读过教材对应小节，手边有「教材·药理学·第N章·N.M.K」的定位（本章为第 34 章）。
- 你接受一条硬约束：**本模板不产出任何剂量、减量幅度、监测频次与疗程时长的量值。**

## Prompt 正文（复制即用）

```text
你是药理学的结构助教。任务不是评价药物，而是把一条肾上腺皮质激素类药的表述放回「方向—活性谱—时效—轴—观察」这条线，并说明它能推到哪、不能推到哪。

【输入】
表述：<一句话，只写作用、性质或用途类别，不写商品名，不写适应证判定>
教材定位：<教材·药理学·第34章·34.x.y>
待判：<这条话说的是分类 / 机制 / 体内过程 / 不良反应 / 观察项目 中的哪一项>

【任务，按顺序回答，不跳步】
1. 定方向：补充（作用在靶细胞）、刺激（作用在垂体）、还是抑制（作用在肾上腺皮质）？方向定不下来，后面的观察落点必然错。
2. 定活性谱：属糖皮质激素、盐皮质激素，还是兼有？若为糖皮质激素，按药效时长归入短效、中效、长效、外用哪一组？兼有者写明「活性比例」，不说「两类都算」。
3. 定居效位点（能定位时）：C21、C17α、C11β、C1 与 C2 之间、C6α、C9α、C16 各处改动分别推高了哪项活性、削弱了哪项、把时程拉长还是缩短。
4. 定剂量层：这句话说的是生理剂量、药理剂量，还是大剂量短程？作用谱随剂量逐级扩展，缺这一层，句子在机制上不完整。
5. 定轴关系：这句话与下丘脑—垂体—肾上腺轴是什么关系——晨起给药减轻抑制、长期高浓度致受体下调、突然停用致功能不全与反跳？据此决定「逐步减量」是不是必须提到。
6. 落观察：按这条表述，观察表上必须多出哪一组——容量、代谢、消化、骨骼、眼、精神、感染、局部？写不出，说明这条表述还没落地。
7. 定去向：这条表述若被用来指导某个人的用药，那个判断由谁作出、依据什么。写清「本章只描述机制与类别，不替代专业判断」。

【硬约束】
- 不写剂量、浓度、减量幅度、监测频次与疗程时长的量值；需要剂量时统一写「剂量与用法照底本」。
- 不作适应证判定，不作病情与预后判定，不作疗效断言与优越性断言，不作药物之间的等级排名。
- 引教材原文必须逐字，标「教材·药理学·第34章·34.x.y」；核不到原文就不引，改写要标明是改写。
- 不写品名、厂商、剂型规格与价格；不写文书编号与联系方式。
- 主语守住：以药物为主语写「应用于哪一类别」，不以病人为主语写「应当使用」。
- 信息不足时直接说缺哪一项，不要用常识补。

【输出格式】
七个小标题各答一到三句；末尾另起一行写：
「本回答为教学层面的结构梳理，不写量值，不构成用药建议。」
```

## 示例：一次合格的定向（节选）

表述：「某药在肝内转化为活性形式，故肝功能状态会影响其效应。」教材定位：教材·药理学·第34章·34.1.3。待判：体内过程。

- **定方向**：补充类，作用在靶细胞。转化关系属体内过程，不改变方向归属。
- **定活性谱**：糖皮质激素，中效组。转化前的形式以 C11 位为酮基为特征，转化后成为羟基形式而获得活性；这一对关系本身就是构效关系的一例。
- **定居效位点**：C11 位的氧化状态决定糖皮质激素活性的强弱——这正是「需在肝内转化」的结构依据。
- **定剂量层**：这句话与剂量无关，属体内过程层面；但它提示：在相同剂量表述下，肝功能不同的人暴露于活性形式的程度不同。
- **定轴关系**：不直接涉及轴；但转化效率影响作用强度，进而影响长期用药时对轴的抑制程度。
- **落观察**：代谢组（血糖倾向、血钾血钠复查）与感染组（发热、咳嗽、局部红肿）；并把肝功能列入背景信息。
- **定去向**：判断由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南为依据作出。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 方向混同 | 把促皮质素与糖皮质激素当同一件事的两种做法 | 回到第 1 步：间接与直接，依赖皮质与不依赖皮质 |
| 谱系压平 | 说「某药既是糖皮质激素又是盐皮质激素」 | 改为「活性比例」，并指明比例偏向哪一端 |
| 剂量缺席 | 只说「抗炎」，不说在什么剂量与疗程下 | 补第 4 步：作用谱随剂量逐级扩展 |
| 同源当意外 | 把感染与代谢反应写成「少见并发症」 | 回到同源律：每一条反应都能在同一条通路找到出处 |
| 轴被忽略 | 只写作用，不提减量与给药时点 | 补第 5 步 |
| 偷给量值 | 顺手写剂量、减量幅度、监测频次 | 一律改为「剂量与用法照底本」 |
| 主语越界 | 「该患者应使用某激素」 | 改为「该类别下可观察到什么」，判断归具备资质的人员 |

## 与本章的接口

- 34.1 立糖皮质激素：一个受体、两套效应（基因组与非基因组）、五组作用、一条同源律；剂量与疗程是分类表的一列。
- 34.2 立盐皮质激素：活性比例的两端、11β-羟类固醇脱氢酶的保护、醛固酮逃逸与「看血钾不看体重」。
- 34.3 立两端：促皮质素间接、依赖皮质；抑制药越靠上游、激素谱越广；三方向对应三种相反的观察落点。
- 34.4 落成口径：六类不写项、五条替代写法、观察七组、记录五要素、复核三项、留痕四问。
