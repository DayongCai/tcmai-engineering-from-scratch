# Skill：肾上腺皮质激素类药——三个方向、一条轴、一条同源律

## 何时用

- 读到「某药抗炎强 / 某药可替代某药」，需要判断这句话属于哪一层
- 要解释「为什么同一个药换个剂量，作用谱就变了」
- 遇到「为什么不能突然停药」「为什么晨起给药」这类问题，需要把答案落到轴与受体
- 要把长期用药的观察整理成能复核的记录，却不确定该按什么分组
- 有人拿「哪种激素更好」来问，需要把讨论拉回活性比例与方向

## 核心判据（七问）

1. **哪个方向？** 补充（靶细胞）／刺激（垂体）／抑制（肾上腺皮质）。方向决定观察落点是「过量与不足」还是「功能低下与应激能力」。
2. **哪条谱？** 糖皮质激素（短效、中效、长效、外用）／盐皮质激素／兼有。兼有者说「活性比例」，不说「两类都算」。
3. **哪个位点？** C21 位（与受体结合所必需，酯化改途径）、C17α 与 C11β（抗炎强弱）、C1 与 C2 之间双键（抗炎增强、水盐减弱）、C6α 甲基（脂溶性升高、盐活性下降）、C9α 氟与 C16 取代（抗炎增强、时程延长）。
4. **哪一层剂量？** 生理剂量补需要／药理剂量抗炎与免疫抑制／大剂量短程突出循环与细胞膜稳定。缺这一层，句子在机制上不完整。
5. **与轴什么关系？** 晨起给药使外源高峰与生理高峰重叠、对轴抑制较轻；长期高浓度致受体下调；突然停用致轴功能不全与反跳。故减量必须分批。
6. **同源在哪？** 抑制介质生成与细胞浸润→感染；促糖异生与促蛋白分解→血糖与负氮平衡；抑制成骨与增加尿钙→骨量下降。反应不是意外，是推论。
7. **判断交给谁？** 由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南决定。

## 执行步骤

```text
1. 收口：把待判句子压成一句「作用或性质」，删掉药名与用途
2. 定方向：补充 / 刺激 / 抑制，并写明作用点（靶细胞、垂体、皮质）
3. 定谱：糖 / 盐 / 兼有；糖再定时长组；兼有写比例
4. 定位点：有构效信息就落到具体位点，没有就标「未涉及构效」
5. 定剂量层：生理 / 药理 / 大剂量短程
6. 定轴：给药时点、受体下调、停药过渡，三者哪一项与这句话相关
7. 落观察：容量、代谢、消化、骨骼、眼、精神、感染、局部，八组中选相关项
8. 定去向：谁判断、依什么、如何留痕（时点、途径与剂量、表现、处理、签名复核）
```

## 硬约束

- **不写剂量、浓度、减量幅度、监测频次与疗程时长的量值。** 需要剂量时统一写「剂量与用法照底本」。
- **不作适应证判定，不作病情与预后判定，不作疗效断言与优越性断言，不作等级排名。**
- **引文逐字。** 标「教材·药理学·第34章·34.x.y」，核不到原文就不引；改写须标明是改写。
- **不写品名、厂商、剂型规格与价格；不写文书编号与联系方式。**
- **主语守住。** 以药物为主语写「应用于哪一类别」，不以病人为主语写「应当使用」。
- **不写减量步骤与时间表。** 只写「逐步减量、按规范评估」这一原则性表述。
- **不确定就写下来。** 标待核实，不用推测填空。

## 交付物

1. 一条方向定位：补充／刺激／抑制，附作用点
2. 一处活性谱落位：糖、盐或兼有（写比例），糖再定时长组
3. 一层剂量判定：生理／药理／大剂量短程
4. 一组观察补充：八组中因此要多写哪几项
5. 一句边界句：本章只描述机制与类别，判断归属另行

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 方向混同 | 把促皮质素当「另一种激素」 | 间接与直接，依赖皮质与不依赖皮质 |
| 谱系压平 | 「既是糖皮又是盐皮」 | 改为「活性比例」，指明偏向 |
| 剂量缺席 | 只说抗炎，不说剂量与疗程 | 补第 4 步 |
| 同源当意外 | 把感染与代谢反应写成少见并发症 | 回到同源律，逐条找出处 |
| 停药当小事 | 不写逐步减量与观察 | 补第 5 步：轴与受体两处依据 |
| 只看体重 | 用体重判断容量累积 | 改为「看血钾更能反映累积效应」 |
| 偷给量值 | 剂量、减量幅度、监测频次无来源 | 改为「剂量与用法照底本」 |
| 主语越界 | 「该患者应使用」 | 改为「该类别下可观察到什么」 |

## 与相邻章节的接缝

- 第 35 章（甲状腺激素与抗甲状腺药）：轴调节与负反馈的概念在两章共用，本章只讲肾上腺这一支。
- 第 36 章（抗高血糖药）：糖皮质激素升血糖的机制在那一章与降糖药的作用环节形成对照。
- 第 20 章（组胺与抗组胺药）：抗过敏作用与抗组胺的环节不同，本章只写到「介质释放与效应」这一层。
- 第 21 章（其他自体活性物质）：磷脂酶 A2 与前列腺素、白三烯的生成在那一章展开，本章只用到「介质生成受抑」。
- 第 4 章（影响药物效应的因素）：年龄、妊娠、肝肾功能对本章各药的影响，在那一章被展开为一般框架。

## 边界

本 Skill 只处理「一条表述 → 方向与谱」的判定，不涉及剂量、适应证与临床决策。本章内容为教学材料，不构成用药建议；任何涉及个体的用药评估须由具备资质的人员依现行法律法规与规范作出。
