# Skill：抗动脉粥样硬化药——四个侧面、一条事件链、一套窗口

## 何时用

- 读到「某药是抗动脉粥样硬化药」，需要说清它卡在事件链的哪一步
- 遇到「都能降脂所以归为一类」的说法，需要指出三类反例（普罗布考降 HDL、鱼油对总胆固醇影响小、藻多糖几乎不降脂）
- 要解释「为什么抗氧化药不能用血脂指标衡量」
- 遇到「多效性」这个词，需要分清机制解释与疗效断言
- 要判断两类药能否联用，需要回到位点而不是类别名

## 核心判据（六问）

1. **哪个侧面？** 调血脂药（脂蛋白水平与构成）、抗氧化药（氧化修饰）、多烯脂肪酸（脂肪酸组成）、保护血管内皮药（血管壁反应性）。
2. **哪个位点？** 胆固醇合成、肠道吸收、胆汁酸肠肝循环与转化、甘油三酯水解、脂肪组织脂解、脂质过氧化链式反应、膜脂质构成、内皮屏障与一氧化氮通路。八选一为主。
3. **链条完整吗？** 从位点到效应至少三步，缺环就标出来。例：抑制限速酶 → 肝内胆固醇减少 → 受体上调 → 血浆低密度脂蛋白被摄取增多。
4. **边界在哪？** 血脂表型不同导致方向不一致、效应时标与血脂变化不同步、剂量与效应不呈线性、食物与药品分属两个层面、多效性只是机制解释。
5. **该看哪张表？** 位点决定观察窗口：脂蛋白水平 / 氧化修饰相关环节 / 甘油三酯与出血倾向 / 出血表现与内皮功能相关环节。四张表不能混用。
6. **判断交给谁？** 由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南决定。

## 执行步骤

```text
1. 收口：把待判对象压成一句「作用或机制」，删掉药名与用途
2. 归侧面：四个侧面之一，跨侧面的写主次
3. 定位点：八类位点之一
4. 走链：三步以上，缺环标出
5. 划边界：表型差异、时标不同步、非线性、食物与药品、多效性
6. 换窗口：按位点换观察项目，并说明为什么不能沿用上一张表
7. 查相互作用：同一肝药酶、肠道转运、胆汁酸结合
8. 定去向：谁判断、依什么、如何留痕
```

## 硬约束

- **不写剂量、浓度、血脂目标值与疗程的量值。** 需要剂量时统一写「剂量与用法照底本」。
- **不作血脂异常的诊断与分级判定，不作适应证判定，不作疗效断言与优越性断言，不作优劣与排名。**
- **引文逐字。** 标「教材·药理学·第27章·27.x.y」，核不到原文就不引；改写须标明是改写。
- **不写品名、厂商、剂型规格与价格。**
- **不把位点相同当效果相同。** 同一类别内代谢途径、维持时间与相互作用谱差异明显。
- **不把反直觉现象当缺点。** 普罗布考降 LDL 同时降 HDL，属类别特征，不作优劣评价。

## 交付物

1. 一条定位链：侧面 → 位点 → 三步以上的机制链
2. 一份窗口清单：按位点应当换成的观察项目，以及不能沿用的理由
3. 一条边界说明：这条规律在什么情形下需要改写
4. 一条相互作用提示：是否落在同一代谢或转运环节
5. 一句边界句：本章只描述位点与类别关系，判断归属另行

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 都降脂所以一类 | 三类反例解释不通 | 回到第 1 问，按侧面归位 |
| 类别当位点 | 说不清为何能联用 | 回到第 2 问，写合成/吸收/转化排泄 |
| 链条跳步 | 机制变成口号 | 补中间环，缺环标出 |
| 多效性当好处 | 机制解释被读成疗效结论 | 改为「多条通路被改变」，并注明可核边界 |
| 一张表量四类 | 抗氧化药被用血脂评价 | 回到第 5 问，换窗口 |
| 类别推个体 | 由类别直接推疗程与用法 | 改写为「须逐个核对代谢途径与相互作用谱」 |

## 边界

本 Skill 只处理「一个药物或一条表述 → 位点与观察窗口」的定位，不涉及剂量、分级判定与临床决策。本章内容为教学材料，不构成用药建议；任何涉及个体的用药评估须由具备资质的人员依现行法律法规与规范作出。
