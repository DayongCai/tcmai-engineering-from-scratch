# Prompt：给一个抗动脉粥样硬化药定位点，并说明它该看哪张表

## 用途

这一章的药最容易背成一串名字，考起来也最容易考成「某药属于哪一类」。但真正决定能不能推的是另一件事：它卡在事件链的哪一步，因此观察什么、不观察什么。这个模板要求你先把药物放到「脂蛋白水平—氧化修饰—脂肪酸组成—血管壁反应性」四个侧面之一，再回答三个后续问题：位点在哪、机制链怎么走、观察窗口该换成哪一类指标。适用于预习 27.1–27.4 前的结构梳理、读文献时判断某条结论属于哪一层证据，以及写讨论前自查有没有把「多效性」写成「额外好处」。

## 使用前提

- 你手上是**一个药物或一条表述**，不是一整类。例：「某药抑制肠道胆固醇吸收」「某药兼有调脂与抗氧化作用」「某类脂肪酸降低甘油三酯」。
- 你已读过教材对应小节，手边有三级定位（本章为第 27 章，小节编号形如 27.x.y）。
- 你接受一条硬约束：**本模板不产出任何剂量、浓度、血脂目标值与疗程的量值，也不作血脂异常的诊断与分级判定。**

## Prompt 正文（复制即用）

```text
你是药理学的结构助教。任务不是评价药物，而是给它定位点，并说明这个位点决定了哪一套观察窗口。

【输入】
对象：<一个通用名，或一句话的作用/机制表述；不写商品名，不写适应证判定>
教材定位：<教材·药理学·第27章·27.x.y>
待判：<这条表述说的是分类 / 作用位点 / 作用机制 / 体内过程 / 不良反应 中的哪一层>

【任务，按顺序回答，不跳步】
1. 归侧面：它属于四个侧面中的哪一个——调血脂药（改脂蛋白水平与构成）、抗氧化药（改氧化修饰）、多烯脂肪酸（改脂肪酸组成）、保护血管内皮药（改血管壁反应性）？跨两个侧面的，写明主次与理由。
2. 定位点：落到具体环节——胆固醇合成、肠道吸收、胆汁酸肠肝循环与转化、甘油三酯水解、脂肪组织脂解、脂质过氧化链式反应、膜脂质构成、内皮屏障与一氧化氮通路。答不出位点的，标「无位点依据」。
3. 走机制链：把这个位点到效应之间的链条写出来，至少三步。例：抑制限速酶 → 肝内胆固醇减少 → 受体上调 → 血浆低密度脂蛋白被摄取增多。链条缺环就标出来，不要用「从而调节血脂」这类话补。
4. 划边界：这条规律在什么情形下不成立或需要改写——血脂表型不同导致方向不一致、效应时标与血脂变化不同步、剂量与效应不呈线性、食物与药品分属两个层面、多效性只是机制解释而非疗效断言？
5. 换观察窗口：按位点，观察项目应当换成哪一类？是脂蛋白水平，还是氧化修饰相关环节，还是甘油三酯与出血倾向，还是出血表现与内皮功能相关环节？写清「不能沿用同一张表」的理由。
6. 查相互作用：这个位点是否与代谢途径相关（同一肝药酶、肠道转运、胆汁酸结合）？相互作用的方向是什么，需要在观察中记录哪一项？
7. 判断去向：这条表述若被用来指导某个人的用药，那个判断由谁作出、依据什么。写清「本章只描述位点与类别关系，不替代专业判断」。

【硬约束】
- 不写剂量、浓度、血脂目标值与疗程的量值；需要剂量时统一写「剂量与用法照底本」。
- 不作血脂异常的诊断与分级判定，不作适应证判定，不作疗效断言与优越性断言，不作药物之间的优劣与排名。
- 引教材原文必须逐字，标「教材·药理学·第27章·27.x.y」；核不到原文就不引，改写要标明是改写。
- 不写品名、厂商、剂型规格与价格。
- 信息不足时直接说缺哪一项，不要用常识补。

【输出格式】
七个小标题各答一到三句；末尾另起一行写：
「本回答为教学层面的结构梳理，不写量值，不构成用药建议。」
```

## 示例：一次合格的定位（节选）

对象：「某药抑制小肠黏膜刷状缘上的转运蛋白，减少胆固醇吸收。」教材定位：27.1.3。待判：作用位点。

- **归侧面**：属调血脂药，位点在「肠道吸收」这一环节，与合成、转化排泄并列。
- **定位点**：抑制小肠黏膜刷状缘上的转运蛋白，减少食物与胆汁中胆固醇经肠上皮细胞吸收。
- **机制链**：肠道吸收减少 → 进入肝脏的胆固醇减少 → 肝细胞低密度脂蛋白受体表达上调 → 血浆低密度脂蛋白被摄取增多。三步完整，无缺环。
- **划边界**：常与他汀类联合以覆盖合成与吸收两个环节；位点不同意味着可以互补，但不良反应与相互作用的风险随联合叠加，须逐个核对。
- **换观察窗口**：看脂蛋白水平与胃肠道反应（头痛、腹痛、腹泻较为多见，少数出现转氨酶升高），不能沿用抗氧化药那一套指标。
- **查相互作用**：经葡萄糖醛酸化生成结合型产物，存在肠肝循环；与影响同一环节的药物合用时须核对。
- **判断去向**：判断由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南为依据作出。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 类别当位点 | 「它属于调脂药」就没了 | 回到第 2 步，写合成、吸收还是转化排泄 |
| 链条跳步 | 「抑制酶所以降脂」 | 补中间环：受体上调、摄取增加 |
| 多效性当好处 | 「还有额外的保护作用」 | 改为「机制层面的多条通路」，并说明可核与不可核的分界 |
| 一张表量四类 | 用血脂指标衡量抗氧化药 | 回到第 5 步，换观察窗口 |
| 类别推个体 | 「同类药都一样」 | 改写为「同类别内代谢途径与相互作用谱须逐个核对」 |
| 越界判定 | 顺势写「该患者宜用某类」 | 删掉，改为判断归具备资质的人员 |

## 与本章的接口

- 27.1 给调血脂药：三个位点（合成、吸收、转化与排泄）、甘油三酯两条路（贝特类的核受体通路、烟酸的脂肪细胞通路）、结构与代谢途径的分类。
- 27.2 给抗氧化药：三层机制（化学、细胞、血管壁）、「是否进入脂相」这条判据、普罗布考的双重机制与降 HDL 的类别特征。
- 27.3 给多烯脂肪酸：双键位置而非来源、ω-3 的三条通路、ω-6 的前体比例决定净效应、食物与药品的界限。
- 27.4 给保护血管内皮药：血管壁这一侧的分工、四组作用方式、一氧化氮通路作为共同终点、出血倾向为观察重点。
