# Skill：β-内酰胺类——一个环、三处差别、五条耐药线索

## 何时用

- 读到「某代头孢更强 / 某品种耐酶 / 某药广谱」，需要判断这句话站在链的哪一环
- 药敏报告说「耐药」，要说出断在产酶、靶位、通透、外排还是生物膜
- 要解释「为什么同一类里有的对革兰阳性球菌强、有的向革兰阴性杆菌延伸」
- 遇到复方制剂，需要判断抑制药到底补的是哪一个洞
- 要决定观察表上除过敏之外还要加哪一栏

## 核心判据（六问）

1. **环还在不在？** 四元 β-内酰胺环是活性的必需结构，开环即失活。讨论「失效」先问这一句。
2. **侧链改的是哪一件？** 对青霉素结合蛋白的亲和力、对 β-内酰胺酶的稳定性、透过细菌外膜的能力——三件只能取一二，问它取了哪一件、丢了哪一件。
3. **靶位是哪一族？** 青霉素结合蛋白是一族而不是一个；亲和谱越宽，细菌靠单一靶位突变逃避的机会越小。
4. **耐药断在哪一问？** 该菌是否产生可水解该药的酶、该药的靶位是否改变、药物能否到达作用部位。三问定位，才知道换药有没有意义。
5. **耐酶等不等于耐药？** 不等。耐酶只解决水解这一环，解决不了靶位改变、通透下降与外排。
6. **观察多出哪一栏？** 过敏为类内通用；凝血与双硫仑样反应跟含甲硫四氮唑基团的品种走；尿与中枢表现跟排泄途径和品种走。

## 执行步骤

```text
1. 收口：把待判句子压成一句「结构或性质」，删掉药名与用途
2. 归环：环 / 侧链 / 谱 / 耐药 / 观察，五环定位，跨环写明中间环
3. 找结构：母核（青霉烷、头孢烯、碳青霉烯、氧头孢烯、单环）与侧链（位阻、电荷、甲氧基、羟乙基）
4. 定靶点：讲「无效」时区分三种原因——亲和力不够、药到不了、靶位改了
5. 走三问：产酶 / 靶位 / 到达，指明这条表述能回答哪一问、不能回答哪两问
6. 落观察：过敏、凝血、尿、中枢，按品种与排泄途径分栏
7. 找例外：诱导型产酶、超广谱酶、靶位改变、生物膜、复方只补一个洞
8. 定去向：谁判断、依什么、如何留痕
```

## 硬约束

- **不写剂量、浓度、配比、疗程与给药间隔的量值。** 需要剂量时统一写「剂量与用法照底本」。
- **不作适应证判定，不作病情与预后判定，不作疗效断言与优越性断言，不作代际等级排名。**
- **引文逐字。** 标「教材·药理学·第40章·40.x.y」，核不到原文就不引；改写须标明是改写。
- **不写品名、厂商、剂型规格与价格。**
- **代际是坐标不是等级。** 三条曲线不平行，例外时有出现，不得按代际推断某一品种对某类菌的作用。
- **不确定就写下来。** 标待核实，不用推测填空。

## 交付物

1. 一条链：环 → 侧链三件事 → 抗菌谱 → 耐药表型 → 观察项
2. 一处定位：这条表述主要靠哪一件侧链功能成立
3. 一句耐药定位：断在产酶、靶位、通透、外排还是生物膜
4. 一栏观察补充：记录表上因此要多写什么
5. 一句边界句：本章只描述机制与类别，判断归属另行

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 坐标当等级 | 把「第三代」说成「更好」 | 改为性质描述，删掉取舍结论 |
| 耐酶当耐药 | 以为耐酶品种能对付所有耐药菌 | 走三问，指出它只回答产酶一问 |
| 广谱当全覆盖 | 忽略「不含铜绿假单胞菌」这类边界 | 每写一次「广谱」就配一句「不覆盖什么」 |
| 复方当新品种 | 把复方说成谱更宽的新药 | 复方只补酶水解这一环，谱随主药而定 |
| 观察项通用化 | 所有品种都只写「注意观察」 | 按品种的结构基团与排泄途径分栏 |
| 偷给量值 | 顺手写剂量、浓度或疗程 | 改为「剂量与用法照底本」 |
