# Prompt：把一条 β-内酰胺类的表述钉回「环—侧链—谱—耐药—观察」这条链

## 用途

β-内酰胺类的讨论里，最容易出现两种句子。一种是「某代头孢更强」，把坐标当成了等级；一种是「某药耐酶，所以对耐药菌有效」，把一条轴上的性质当成了另一条轴上的结论。这个模板把一句话逼回链上：它说的是环、是侧链、是谱、是耐药机制，还是观察项；能推到哪一步，再往下就该交给谁。适用于预习 40.1–40.4 前的结构梳理、读药敏报告时判断「耐药」断在哪一环，以及写讨论前自查有没有把「耐酶」写成「耐药」。

## 使用前提

- 你手上是**一条表述**，不是一个药名。例：「某品种耐酶，可用于产酶菌」「某代对革兰阴性菌作用增强」「某药要做皮试」。
- 你已读过教材对应小节，手边有「教材·药理学·第N章·N.M.K」的定位（本章为第 40 章）。
- 你接受一条硬约束：**本模板不产出任何剂量、浓度、配比、疗程的量值。**

## Prompt 正文（复制即用）

```text
你是药理学的结构助教。任务不是评价药物，而是把一条 β-内酰胺类的表述钉在这条链的某一环上，并说明它能推到哪、不能推到哪。

【输入】
表述：<一句话，只写结构、性质、抗菌谱类别或观察项，不写商品名，不写适应证判定>
教材定位：<教材·药理学·第40章·40.x.y>
待判：<这条话说的是 环与靶点 / 侧链三件事 / 抗菌谱 / 耐药机制 / 观察项 中的哪一环>

【任务，按顺序回答，不跳步】
1. 归环：这条表述落在「环—侧链三件事（亲和力、酶稳定性、外膜透过）—抗菌谱—耐药表型—观察项」五环中的哪一环？跨环的，写明从哪一环推到哪一环，中间缺不缺环节。
2. 结构依据：如果讲的是谱或稳定性，指出依据是母核（青霉烷、头孢烯、碳青霉烯、氧头孢烯、单环）还是侧链（位阻、电荷、甲氧基、羟乙基）；讲不出结构依据的，直接标「无结构依据」。
3. 靶点落位：这条表述涉及哪一族青霉素结合蛋白的亲和差异？如果它讲的是「某类菌无效」，回答是亲和力不够、还是药到不了（外膜通透性）、还是靶位改了。
4. 耐药定位：按三问核对——该菌是否产生可水解该药的酶、该药的靶位是否改变、药物能否到达作用部位。指明这条表述对应的是哪一问，以及它**不能**回答哪两问。
5. 观察项：按这条表述，观察表上必须多出哪一栏？是过敏史与皮试，是凝血相关指标与饮酒史（含甲硫四氮唑基团的品种），是尿量与尿常规（主要经肾排泄者），还是中枢神经系统表现？
6. 例外追问：这条规律在什么情形下减弱或不成立——诱导型产酶、超广谱酶、靶位改变、生物膜、复方只补一个洞？找不到就写「本教材未展开」。
7. 判断去向：这条表述若被用来指导某个人的用药，那个判断由谁作出、依据什么。写清「本章只描述机制与类别，不替代专业判断」。

【硬约束】
- 不写剂量、浓度、配比、疗程与给药间隔的量值；需要剂量时统一写「剂量与用法照底本」。
- 不作适应证判定，不作病情与预后判定，不作疗效断言与优越性断言，不作代际之间的等级排名。
- 引教材原文必须逐字，标「教材·药理学·第40章·40.x.y」；核不到原文就不引，改写要标明是改写。
- 不写品名、厂商、剂型规格与价格。
- 信息不足时直接说缺哪一项，不要用常识补。

【输出格式】
七个小标题各答一到三句；末尾另起一行写：
「本回答为教学层面的结构梳理，不写量值，不构成用药建议。」
```

## 示例：一次合格的归环（节选）

表述：「某品种耐酶，所以对产酶菌有效。」教材定位：教材·药理学·第40章·40.2.2。待判：耐药机制。

- **归环**：从「侧链」推到「耐药表型」再到「抗菌谱」，中间不缺环——侧链位阻使药物不易被青霉素酶水解，于是对产酶金黄色葡萄球菌有作用。
- **结构依据**：耐酶青霉素的侧链位阻；代价是对青霉素结合蛋白的亲和力下降，故抗菌作用弱于青霉素 G。
- **靶点落位**：仍是同一族青霉素结合蛋白，亲和力下降是「弱」，不是「无效」。
- **耐药定位**：只回答了第一问（产不产酶）。它不能回答靶位是否改变——对甲氧西林耐药金黄色葡萄球菌无效，正因为那一类菌改的是靶位，不是酶。
- **观察项**：过敏史与皮试、皮疹（此类品种皮疹较常见）、以及口服后的胃肠道反应；个别品种须看尿量与尿常规。
- **例外追问**：诱导型产酶可使「耐酶」随时间失效；复方只解决酶水解这一环，对靶位、通透、外排无针对性。
- **判断去向**：判断由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南为依据作出。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 坐标当等级 | 「第三代比第一代好」 | 回到第 1 步，把「更好」改成「在哪一环上有何性质」 |
| 耐酶当耐药 | 「耐酶所以什么耐药菌都能打」 | 走第 4 步三问，指出它只回答产酶一问 |
| 跨环直推 | 由「对酶稳定」直接说「用于某感染」 | 补中间环：谱的边界 → 病原学 → 判断归属 |
| 偷给量值 | 顺手写剂量、浓度或疗程 | 一律改为「剂量与用法照底本」 |
| 忘记靶位 | 只讲产酶，不讲靶位改变 | 补第 3、4 步：甲氧西林耐药菌改的是靶位 |
| 观察项缺失 | 只写作用，不写这一作用要求多出哪一栏 | 补第 5 步，落到字段 |

## 与本章的接口

- 40.1 立机制、耐药与分类：四元环、青霉素结合蛋白为一族、繁殖期杀菌、时间依赖性、五条耐药线索与三问。
- 40.2 与 40.3 走两遍链：青霉素类的四种改构目的，头孢菌素类的三项依据与三条曲线（含例外）。
- 40.4 检验边界：甲氧基、羟乙基、氧原子各换来什么，酶抑制药只补一个洞。
- 40.1.3 与 40.3.3 提供观察项：耐酸不等于耐酶、含甲硫四氮唑基团者的凝血与双硫仑样反应。
