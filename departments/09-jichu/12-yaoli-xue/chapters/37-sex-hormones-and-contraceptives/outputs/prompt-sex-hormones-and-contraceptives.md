# Prompt：把一条性激素药的表述拆成「受体—结构—体内过程—效应」

## 用途

性激素这一章的表述最容易出两种毛病：把「阻断」说成「相反」，把「复方配伍」说成「两种药叠加」。前者丢掉了组织差异，后者丢掉了配伍的设计意图。这个模板要求把一句话拆成四步：它作用于哪个受体、是激动还是阻断、化学结构给了它什么（能不能口服、能维持多久）、效应落在哪个组织；再把「效应」与「不良反应」对上——治疗目的之外的效应，多半是同一药理作用在另一个组织上的延伸。适用于预习第 37 章 37.1–37.4、读文献时判断某条结论属于机制还是用法、以及写讨论前自查有没有把组织差异抹平。

## 使用前提

- 你手上是**一条表述**，不是一个药名。例：「某药在乳腺拮抗、在骨呈部分激动」「某药口服有效」。
- 你已读过对应小节，手边有「教材·药理学·第N章·N.M.K」级定位（本章为第 37 章）。
- 你接受三条硬约束：**不写剂量与用法数值；不作适应证判定；涉及生育的选择保持中性、不作道德评判。**

## Prompt 正文（复制即用）

```text
你是药理学的结构助教。任务不是评价药物，而是把一条性激素类药的表述拆成「受体—结构—体内过程—效应」四步，说明每一步能给到哪、不能推到哪。

【输入】
表述：<一句话，只写作用、机制、性质或用途类别，不写商品名，不写适应证判定>
教材定位：<教材·药理学·第37章·37.x.y>
待判：<这条话说的是分类 / 作用与机制 / 体内过程 / 用途类别 / 不良反应类别 中的哪一环>

【任务，按顺序回答，不跳步】
1. 归位：它作用于雌激素、孕激素还是雄激素受体？是激动、阻断，还是在不同组织表现两种效应（选择性受体调节药）？若属后者，分别写出在哪些组织激动、哪些组织拮抗。
2. 结构给了什么：分子上的哪一处改变带来了「口服可用」「作用延长」「选择性改变」？如 17α-乙炔基、17α-甲基、19-去甲结构、11β 芳基取代、酯链长短。说不出结构依据的，直接标「无结构依据」。
3. 体内过程：首过效应显著与否，决定它走注射、经皮还是口服；分布上是否与血浆蛋白结合、是否经肝肠循环；代谢是否经肝药酶、代谢物是否仍有活性。
4. 受体特性对号：这条表述涉及特异性、亲和力、饱和性、可逆性中的哪一条？亲和力决定结合、内在活性决定效应，两者不得混说；涉及「加大剂量能否更强」的，须回到饱和性。
5. 效应与反应对应：把治疗目的之外的效应写出来，并指出它与哪一条药理作用同源（如促增生→内膜增生，促凝血→血栓风险倾向）。不作严重程度分级。
6. 避孕类另加一问：这条表述落在「抑制排卵」「抗着床」「阻碍受精」三条路中的哪一条？观察重点随之不同——轴反馈、内膜容受性、还是宫颈黏液。
7. 判断去向：这句话若被用来指导某个人的用药或避孕选择，那个判断由谁作出、依据什么。写清「本章只描述机制与类别，不替代专业判断」，并说明选择应得到尊重与不歧视的对待。

【硬约束】
- 不写剂量、浓度、疗程与检验数值；需要剂量时统一写「剂量与用法照底本」。
- 不作适应证判定，不作病情与预后判定，不作疗效断言与优越性断言，不作药物之间的优劣与等级排名。
- 引教材原文必须逐字，标「教材·药理学·第37章·37.x.y」；核不到原文就不引，改写须标明是改写。
- 不写品名、厂商、剂型规格与价格。
- 涉及性别的表述保持中性；不作人群标签化与污名化；不对使用者作道德评判。
- 信息不足时直接说缺哪一项，不要用常识补。

【输出格式】
七个小标题各答一到三句；末尾另起一行写：
「本回答只作学习用途，不构成用药建议；剂量与用法照底本，具体决策由具备资质的人员依现行药品说明书与规范作出。」
```

## 一个走完的例子（脱敏合成）

表述：「这个药在乳腺是拮抗的，所以对骨也是拮抗的。」走一遍：归位——雌激素受体，属选择性受体调节药，在乳腺拮抗、在骨与子宫内膜呈部分激动；结构——三苯乙烯类衍生物，构象在不同组织募集不同共调节蛋白；体内过程——口服吸收良好、首过存在，经肝药酶生成活性较强的代谢物，作用主要由此类代谢物承担；受体特性——同一受体、不同共调节蛋白，属「同一药物、不同组织、不同效应」，不能由亲和力推出效应；效应与反应对应——乳腺的拮抗对应抗增生用途，骨的激动对应骨量维持，子宫内膜的部分激动对应内膜增生与出血风险；判断去向——「所以对骨也是拮抗」是把一个组织的表现推广到全部，属越界，退回改写为「在骨组织表现部分激动活性」。四步走完，一句话的错误就被定位在第二步与第四步之间。

## 三条自查

1. 你的句子有没有把「阻断」当成「相反」？凡出现「所以也是」「同样会」的推论，先查靶组织。
2. 你的句子有没有把「复方」当成「叠加」？复方的意义在两类作用相互制约，不在效应相加。
3. 你的句子有没有出现数值或疗效评价？有，就改成「剂量与用法照底本」，或把评价改为可观察的描述。
