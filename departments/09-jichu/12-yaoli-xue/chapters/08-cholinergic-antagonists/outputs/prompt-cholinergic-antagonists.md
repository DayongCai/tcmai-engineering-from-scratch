# Prompt：抗胆碱药的「张力对比」判定器

## 用途

把一段关于抗胆碱药的表述交给这个模板，输出四样东西：它阻断的是哪一层受体（M、神经节 N、骨骼肌 N）；阻断之后剩下的表现由什么决定；这条表述的选择性成立到什么剂量范围；以及它该配哪些观察项。

三种场合用得上。其一，备课核对「为什么同样的阻断，表现差这么远」——答案在器官的支配优势，不在药物强弱。其二，辨析两类肌松药——一条分水岭决定过量时能不能拮抗，混淆这条分水岭是本章最常见的错误。其三，拟观察表——六组分列、基线与时点先行，记录才可复核。

## 模板

```text
【待判表述】<一句话，去掉药名与程度词>

1. 阻断哪一层？
   M 受体 / 自主神经节 N 受体 / 骨骼肌终板 N 受体
   → 层次决定效应谱，也决定要与哪一类药配合使用

2. 剩下的是什么？
   该器官哪一套自主神经占优势？
   交感占优（血管）→ 阻断后扩张、血压下降
   副交感占优（腺体、胃肠、膀胱、瞳孔）→ 阻断后分泌减少、蠕动减弱、瞳孔扩大
   → 表现是张力对比的结果，不是药物自身的属性

3. 选择性成立到哪一步？
   亚型分布（M1 抑酸、M3 平滑肌与腺体、M2 心率）
   剂量依赖（增量后选择性下降，出现其他亚型效应）
   → 写「相对选择性」，不写「专一」

4. 效应与状态有关吗？
   痉挛状态 vs 正常活动；低剂量 vs 高剂量
   → 阿托品对心率的方向随剂量反转；解痉作用对痉挛平滑肌更明显

5. 肌松这一侧：除极化还是竞争性？
   除极化：先激动再脱敏，胆碱酯酶抑制剂反使作用延长
   竞争性：占据不开放，胆碱酯酶抑制剂可逆转，且仅在残余肌松、自主呼吸部分恢复时考虑
   → 这一条决定过量时的处理方向

6. 观察补什么？
   腺体 / 眼 / 心血管 / 平滑肌与排泄 / 中枢与体温 / 骨骼肌
   → 六组分列；先记基线，再记时点；瞳孔同光线双侧对比，血压注明体位

7. 边界句
   只写分类、机制、体内过程与效应类别；剂量与用法照底本；
   不作适应证判定，不作疗效断言，不构成用药建议。
```

## 用法要点

- **「阻断」不等于「效应为零」。** 受体存在基础活性时，阻断本身也会带来可观察的变化；这也是为什么部分激动药与反向激动药要被单独提出。
- **教学引用不等于用药建议。** 写「照底本」「以现行说明书为准」是引用；写「应给予」「宜首选」是断言。两者性质不同，不能混用。
- **量值不写。** 剂量、浓度、输注速度不填；需要时写「剂量与用法照底本」。
- **引文逐字。** 标「教材·药理学·第8章 + 三级小节号」，核不到原文就不引。

## 输出示例（骨架）

```text
待判：某药用于术前以减少呼吸道分泌物
层次：M 受体阻断（腺体 M 受体为主）
剩余：腺体以副交感支配为主 → 分泌减少；同时可致口干、心率变化
选择性：相对，剂量增大后可出现中枢兴奋
状态相关：对痉挛平滑肌更明显，对正常活动影响较小
肌松侧：不涉及
观察：口干程度（相对基线）、瞳孔（同光线双侧）、心率与心律（安静状态、注明体位）、体温
边界：写「较前减少」，不写「分泌物正常」；剂量与用法照底本
```

## 不做什么

不判定某个人该不该用、不比较药物优劣、不推算剂量与疗程、不把肌松顺序写成操作步骤。涉个体的判断与操作，由具备资质的人员依现行法律法规与规范、以现行药品说明书为依据作出。
