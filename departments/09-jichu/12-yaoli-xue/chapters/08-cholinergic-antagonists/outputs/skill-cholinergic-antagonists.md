# Skill：抗胆碱药——两层受体、一条分水岭、一张观察表

## 何时用

- 读到「某药阻断胆碱受体」，要判断它阻断的是 M、神经节 N 还是骨骼肌 N，效应谱因此落在哪里
- 要解释「同样是阻断，为什么有的药只口干，有的药血压垮下来」
- 需要辨析阿托品在低剂量与高剂量上心率方向相反的现象
- 遇到「肌松药过量就打新斯的明」这类说法，需要判断它只对哪一类成立
- 要拟一份抗胆碱药用药后的观察表，却不确定该分几栏

## 核心判据（六问）

1. **阻断哪一层？** M 受体／自主神经节 N 受体／骨骼肌终板 N 受体。层次决定效应谱，也决定它要与哪类药配合。
2. **剩下的是什么？** 该器官哪一套自主神经占优势。血管以交感为主，阻断后扩张；腺体、胃肠、膀胱、瞳孔以副交感为主，阻断后分泌减少、蠕动减弱、瞳孔扩大。
3. **选择性到哪一步？** 亚型分布（M1 抑酸、M2 心率、M3 平滑肌与腺体）＋剂量依赖（增量后选择性下降）。写「相对」，不写「专一」。
4. **效应与状态有关吗？** 痉挛平滑肌与正常平滑肌不同；低剂量与高剂量的阿托品对心率方向相反。不写状态，就等于把条件句当成了全称句。
5. **肌松是除极化还是竞争性？** 前者先激动再脱敏，胆碱酯酶抑制剂反使作用延长；后者占据不开放，可被逆转，且仅在残余肌松、自主呼吸部分恢复时考虑。
6. **观察补哪几栏？** 腺体／眼／心血管／平滑肌与排泄／中枢与体温／骨骼肌。六组分列，先记基线，再记时点。

## 执行步骤

```text
1. 收口：把待判句子压成一句「阻断某层受体后的某效应」
2. 定层：M / 神经节 N / 终板 N
3. 摆张力：写出该器官的支配优势，推出剩下什么
4. 查亚型：M1 / M2 / M3 哪一条在起作用；剂量层次是否改变结论
5. 查状态：痉挛还是正常活动；低剂量还是高剂量
6. 分肌松：除极化 / 竞争性 → 决定能否拮抗、何时考虑
7. 落观察：六组项目 + 基线 + 条件（光线、体位、同一观察者）
8. 定句式：写「照底本」「以现行说明书为准」，不写「应给予」「宜首选」
```

## 硬约束

- **不写剂量、浓度、输注速度、肌松深度阈值的量值。** 需要时统一写「剂量与用法照底本」。
- **不作适应证判定、不作病情与预后判定、不作疗效与优劣断言、不作等级排名。**
- **引文逐字。** 标「教材·药理学·第8章 + 三级小节号」，核不到原文就不引。
- **不写品名、厂商、规格与价格，不写批准文号。**
- **肌松不等于麻醉。** 肌松程度与麻醉深度分开记录，不合并成一句「麻醉满意」。
- **不确定就标待核实。** 不用推测填空。

## 交付物

1. 一条层次判定：M / 神经节 N / 终板 N
2. 一张「支配优势—剩余效应」对照，只写与待判句子相关的器官
3. 一句选择性限定：亚型依据 + 剂量层次
4. 一条肌松分水岭判定（如涉及）：能否被胆碱酯酶抑制剂逆转
5. 一栏观察补充 + 一句句式纪律

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 把阻断说成「药物自身的效应」 | 解释不了器官间差异 | 改为「削掉一层张力，剩下的是支配优势」 |
| 用「专一」描述亚型选择性 | 超量时的全身效应无法解释 | 改为「相对选择性，剂量依赖」 |
| 忽略剂量层次谈心率 | 低剂量与高剂量的方向被混为一谈 | 补「M1 负反馈」与「M2 窦房结」两条 |
| 把解痉说成「让肠子停住」 | 与「对痉挛状态更明显」的限定冲突 | 改为「把过高的张力拉回来」 |
| 认为两类肌松药过量都能拮抗 | 处理方向反了 | 回到「先激动再脱敏」与「占据不开放」 |
| 记录只写「麻醉满意」 | 镇静与肌张力混在一起，无法复核 | 分别记录镇静水平与肌力 |

## 与相邻章节的接缝

- 第 6 章（拟胆碱药）：受体被激动后的效应，正好是本章效应的镜像；阿托品对抗 M 样作用是两章的接口。
- 第 7 章（有机磷酸酯类及复活药）：阿托品阻断 M 受体、复活药恢复酶活性，二者环节互补。
- 第 12 章（全身麻醉药）：本章反复强调「肌松不等于麻醉」，那一章讲的是中枢抑制这一侧。
- 第 2 章（药效学）：亲和力与内在活性、竞争性与非竞争性拮抗的定量骨架在那一章更完整。

## 边界

本 Skill 只处理「一句表述 → 阻断层次 → 剩余效应 → 观察项」的判定，不涉及剂量、适应证与围术期操作。本章内容为教学材料，不构成用药建议；任何涉及个体的用药评估，须由具备资质的人员依现行法律法规与规范、以现行药品说明书为依据作出。
