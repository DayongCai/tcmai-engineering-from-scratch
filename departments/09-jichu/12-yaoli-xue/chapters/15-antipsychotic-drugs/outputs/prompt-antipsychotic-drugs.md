# Prompt 模板：抗精神失常药的四条通路推演

## 用途

拿到一段关于抗精神失常药的表述（教材段落、讲义、产品资料、同事的判断），用这套模板把它拆到「哪一类受体、哪一条通路、哪一层观察」上，判断这句话能推到哪、不能推到哪。适用于：读教材时自查有没有把分类读成结论；写病历时判断某句描述是行为还是评价；被问到「哪个药更好」时把讨论拉回受体谱与类别。

模板的输出不是结论，是四个可核对的定位：通路、偏置、时间尺度、观察栏目。

## 用法

按顺序填四格，填不满就说明这句话还缺依据。

1. **通路**：这句话说的是哪一条多巴胺通路？中脑—皮质与中脑—边缘（症状群）、黑质—纹状体（运动）、结节—漏斗（内分泌），还是外周 α1 / M / H1 三条线之一？跨两条以上的，写明是一条还是几条。
2. **偏置**：这个分子在受体谱上是「宽」还是「窄」？宽则多余效应多（镇静、抗胆碱、体位性低血压）；窄则同一线上的不良反应放大（锥体外系）。写出偏置方向，不写强度排序。
3. **时间尺度**：这句话讲的是数小时内的直接效应，还是以周计的适应过程？抗精神病药的行为控制较快，抗抑郁药的症状群改善滞后，锂盐的起效以周计——三者的观察单元不同，混用就会误判。
4. **观察栏目**：这句话要求记录多写什么？症状群与日常功能、锥体外系四项、体位性血压的卧立对照、饮水量与尿量、还是心电图与体重？写不出栏目，说明这句话还没落地。

## 输出格式

```text
原句：……
通路：……（一条 / 多条，写明）
偏置：宽 / 窄，方向为……
时间尺度：直接效应 / 以周计的适应
观察栏目：……（新增或改写的栏目）
越界检查：是否含疗效断言 / 优劣比较 / 绝对化 / 标签化
落点：剂量与用法照底本；判断归具备资质的人员
```

## 硬约束

- 不写剂量、浓度、疗程的量值；需要剂量时统一写「剂量与用法照底本」。
- 不作适应证判定，不作疗效与优越性断言，不作等级排名。
- 引文逐字，标「教材·药理学·第 15 章·N.M.K」；核不到原文就不引。
- 描述行为，不评价人格；「拒绝服药」写为「对服药持保留态度」。
- 分类是起点，不是结论；任何「所以应该用某药」的推论都不在本模板的输出范围内。

## 一个反例

「某药镇静强，所以更适合这位患者」——三处越界：把亲和谱的特点当成适应证判定；把「强」当成优劣；没有给出观察栏目。按模板改写为：「该药 H1 受体阻断较明显，镇静与嗜睡属可预期效应；观察栏目增设日间思睡程度与夜间睡眠时长；是否适用由具备资质的人员判断。」改写后三处越界都收回到了机制与记录层面。
