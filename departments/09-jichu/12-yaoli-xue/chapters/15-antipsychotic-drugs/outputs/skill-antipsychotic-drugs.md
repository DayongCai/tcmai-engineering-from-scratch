# Skill：抗精神失常药——四条通路、一个偏置、两张清单

## 何时用

- 读到「某药作用强 / 镇静轻 / 更安全」，需要判断这句话站在受体谱的哪一格
- 要解释「为什么同一个分子既控制幻觉妄想又引起手抖」
- 要解释「为什么抗抑郁药要等数周才见效」，并据此安排观察单元
- 遇到锂盐的观察问题，不确定该看精神表现还是看饮水与尿量
- 有人问「这个患者该用哪个药」，需要把讨论拉回类别与机制
- 要把精神科观察整理成能复核的记录，却不确定该分几栏

## 核心判据（五问）

1. **哪条通路？** 中脑—皮质与中脑—边缘（症状群）、黑质—纹状体（运动）、结节—漏斗（内分泌），外加外周 α1 / M / H1。跨通路的要写明跨了几条。
2. **偏置朝哪边？** 受体谱宽则多余效应多（镇静、抗胆碱、体位性低血压）；谱窄则同一线上的不良反应放大（锥体外系）。写方向，不写强弱排序。
3. **时间尺度是哪一档？** 数小时内的直接效应，还是以周计的下游适应？抗精神病药的行为控制较快，抗抑郁药的症状群改善滞后，锂盐起效以周计。三档混用，观察必然误判。
4. **观察要多出哪一栏？** 症状群与日常功能、锥体外系四项、卧立血压对照、饮水量与尿量、体重与心电图。写不出栏目，说明这句话还没落地。
5. **判断交给谁？** 由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南决定，并留痕。

## 执行步骤

```text
1. 收口：把待判句子压成一句「某受体被阻断 / 未阻断」
2. 归路：四条通路定位，跨通路的写明中间环节
3. 定偏置：宽谱还是窄谱，方向写清
4. 定时标：直接效应 / 以周计的适应 / 以周计起效但机制在离子
5. 落栏目：记录表因此多写什么
6. 查边界：有无疗效断言、优劣比较、绝对化、人格评价
7. 定去向：谁判断、依什么、如何留痕
```

## 硬约束

- **不写剂量、浓度、疗程与监测数值。** 需要剂量时统一写「剂量与用法照底本」。
- **不作适应证判定，不作病情与预后判定，不作疗效与优越性断言，不作等级排名。**
- **引文逐字。** 标「教材·药理学·第 15 章·N.M.K」，核不到原文就不引；改写须标明是改写。
- **不写品名、厂商、剂型规格与价格，不写文书编号。**
- **描述行为，不评价人格。** 「言语增多、夜间睡眠需求减少」是行为；「脾气坏」是评价，不进记录。
- **不确定就写下来。** 标待核实，不用推测填空。

## 交付物

1. 一条定位链：受体 → 通路 → 效应 → 不良反应 → 观察栏目
2. 一处偏置说明：这个分子的受体谱是宽是窄，方向如何
3. 一条时间尺度：这句话属于哪一档，观察单元随之确定
4. 一句边界句：本章只写类别与机制，判断归属另行

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 把分类当结论 | 「某类药更好」 | 改为受体谱描述，删掉取舍 |
| 由镇静强直推适应证 | 用亲和谱替代个体判断 | 补「观察栏目 + 判断归具备资质的人员」 |
| 用单次观察判断疗效 | 抗抑郁药第一周就判无效 | 观察单元改为周，写明起效滞后的机制 |
| 锂盐只看精神表现 | 忽略钠平衡与肾排泄 | 增设饮水量、尿量与体重栏 |
| 治疗效应与直接效应混栏 | 把口干、嗜睡当疗效 | 分栏，并写明出现顺序 |
| 记录里写「药物所致」 | 判断混入事实，复核无空间 | 只写所见，判断另设一栏 |

## 与相邻章节的接缝

- 第 13 章（镇静催眠药）：抗焦虑药在那一章铺垫，本章不再展开；两章共用「镇静」这个词，但一个针对睡眠，一个针对症状群。
- 第 14 章（抗癫痫药与抗惊厥药）：丙戊酸钠与卡马西平的抗躁狂用途是机制延伸，读法在那一章；本章只写延伸后的定位。
- 第 16 章（中枢神经系统退行性疾病药）：苯海索在那一章是抗帕金森药，在本章是抗精神病药所致锥体外系反应的处理类别——同一药物两处出现，落点不同。
- 第 19 章（中枢兴奋药）：抗抑郁药不产生兴奋作用，也不改变正常人的情绪水平，两章的分界在此。

## 边界

本 Skill 只处理「一句表述 → 四格定位」的判定，不涉及剂量、适应证与临床决策。本章内容为教学材料，不构成用药建议；任何涉及个体的用药评估须由具备资质的人员依现行法律法规与规范作出，并对观察、记录与复核全程留痕。
