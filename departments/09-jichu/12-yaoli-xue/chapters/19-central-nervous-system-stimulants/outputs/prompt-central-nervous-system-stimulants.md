# Prompt 模板：中枢兴奋药的三级部位判定

## 用途

拿到一段关于中枢兴奋药的表述，用这套模板判断它站在三级部位的哪一级、走的是哪条机制路径、风险落在哪一端。适用于：读教材时自查有没有把分类当成解剖定位；判断某个药为什么会出现「过量反而抑制」；把「安全范围窄」这句评价拆成可核对的条件（剂量、速度、途径、蓄积）；在讨论中把「兴奋呼吸」与「纠正缺氧」分开。

模板不产出用药结论，只产出四个定位：部位、路径、安全边界、观察项目。

## 用法

按顺序填四格，填不满就说明这句话还缺依据。

1. **哪一级？** 皮质（意识、思维、注意、情感）、延髓（呼吸与心血管的基本中枢）、脊髓（反射与肌张力）。写明是常用量下的重心，不是作用范围的边界。
2. **哪条路径？** 增强兴奋性传递（腺苷受体阻断、磷酸二酯酶抑制、递质释放促进、呼吸中枢敏感性提高、转运体抑制）还是削弱抑制性传递（甘氨酸受体阻断、抑制性氨基酸受体阻断）。两条路径的剂量效应曲线陡缓不同，这是安全范围差异的根源。
3. **安全边界在哪？** 是治疗量与中毒量接近，是消除缓慢导致蓄积，是给药速度决定峰值，还是途径不同则剂量含义不同？四条各对应一种风险来源，写清是哪一条。
4. **观察项目怎么配？** 皮质层看意识、睡眠与进食；延髓层看呼吸频率与节律、通气量、心率、血压、肌张力与腱反射；脊髓层看肌张力、腱反射、肌群抽动范围与呼吸。呼吸频率是共同项，但权重与配套项不同。

## 输出格式

```text
原句：……
部位：皮质 / 延髓 / 脊髓（常用量下的重心）
路径：增强兴奋性传递 / 削弱抑制性传递（写明具体环节）
安全边界：剂量接近 / 蓄积 / 给药速度 / 途径差异（选主要一条）
观察项目：……（权重的增减）
越界检查：是否含疗效断言 / 优劣比较 / 绝对化 / 非治疗性使用的人群标签化
落点：剂量与用法照底本；判断归具备资质的人员
```

## 硬约束

- 不写剂量、浓度、疗程、极量的量值；需要剂量时统一写「剂量与用法照底本」。
- 不作适应证判定，不作病情与预后判定，不作疗效与优越性断言，不作等级排名。
- 引文逐字，标「教材·药理学·第 19 章·N.M.K」；核不到原文就不引。
- 非治疗性使用只写风险类别与管控原则，不写获取途径与使用方式，不对人群作评价。
- 「极量」不得表述为安全阈值；剂量不得跨途径套用。
- 机制不确定的照教材表述的强度写，不把提示当作结论。

## 一个反例

「呼吸不好就打一针呼吸兴奋药，先把呼吸提上来」——三处越界：跳过「环节是否在中枢」的判断；把提高驱动等同于改善通气；以症状代替适应证。按模板改写为：「该情形须先判断呼吸抑制的环节是否在中枢、是否预期可逆、通气支持是否到位；本类药只提高中枢驱动，不解除气道与肺的机械性障碍；用药后观察呼吸频率与节律、意识与肌张力；具体处置由具备资质的人员决定。」
