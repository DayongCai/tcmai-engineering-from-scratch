# Skill：中枢兴奋药——三级部位、两条路径、四句原则

## 何时用

- 读到「某药兴奋呼吸 / 提神 / 安全范围窄」，需要判断这句话站在哪一级、哪条路径
- 要解释「为什么剂量增大时作用部位会下移」
- 要解释「为什么过量反而出现呼吸抑制」
- 要解释「为什么削弱抑制比增强兴奋更危险」
- 要判断某个药能不能用在通气不足的情形，而不被「兴奋呼吸」四个字带走
- 要在记录里写清剂量、速度、途径与观察的关系，却不想写成方案

## 核心判据（五问）

1. **哪一级？** 皮质、延髓、脊髓。是常用量下的作用重心，不是作用范围的边界。
2. **哪条路径？** 增强兴奋性传递，还是削弱抑制性传递。前者曲线较平缓，后者在临界点附近陡升。
3. **安全边界在哪？** 治疗量与中毒量接近、消除缓慢易蓄积、给药速度决定峰值、途径不同则剂量含义不同。四条里选主要一条。
4. **观察怎么配？** 呼吸频率是共同项；皮质层加意识、睡眠、进食；延髓层加通气量、心率、血压、肌张力与腱反射；脊髓层加肌群抽动范围与呼吸状态。
5. **判断交给谁？** 由具备资质的人员依现行法律法规与规范、以现行药品说明书与制度决定，并留痕。

## 执行步骤

```text
1. 收口：把待判句子压成一句「某环节被增强 / 某抑制被削弱」
2. 定级：皮质 / 延髓 / 脊髓
3. 定路：增强兴奋性传递 / 削弱抑制性传递 + 具体环节
4. 定界：剂量接近 / 蓄积 / 速度 / 途径（选主要一条）
5. 配观：呼吸为共同项，另加该级的专属项
6. 查边界：疗效断言、优劣比较、绝对化、非治疗性使用的人群标签化
7. 定去向：谁判断、依什么、如何留痕
```

## 硬约束

- **不写剂量、浓度、疗程与极量的量值。** 需要剂量时统一写「剂量与用法照底本」。
- **不作适应证判定，不作病情与预后判定，不作疗效与优越性断言，不作等级排名。**
- **引文逐字。** 标「教材·药理学·第 19 章·N.M.K」，核不到原文就不引；改写须标明是改写。
- **不写品名、厂商、剂型规格与价格。**
- **「极量」不得表述为安全阈值**；剂量不得跨给药途径套用。
- **非治疗性使用只写风险类别与管控原则**，不写获取途径与使用方式，不对人群作评价。

## 交付物

1. 一条定位链：部位 → 路径 → 效应 → 中毒表现 → 观察项目
2. 一处安全边界说明：这条表述的风险来自剂量、蓄积、速度还是途径
3. 一条时间尺度：效应出现与消退的快慢，决定观察间隔
4. 一句边界句：本章只写类别与机制，判断归属另行

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 把分类当解剖定位 | 认为某药只作用于一个部位 | 补「常用量下的重心」与剂量迁移 |
| 把兴奋呼吸等同于纠正缺氧 | 气道不通时增加做功 | 回到三问：环节、可逆、支持是否到位 |
| 认为剂量越大效应越强 | 忽略双相效应与惊厥 | 写出剂量效应曲线的形状 |
| 把极量当安全阈值 | 低于极量也可能惊厥 | 补速度与个体差异两条 |
| 跨途径套用剂量 | 峰值与起效完全不同 | 换途径须重新核对说明书与规范 |
| 记录只写「较前好转」 | 无法复核，掩盖缺项 | 写呼吸频率、肌张力、腱反射的具体所见 |

## 与相邻章节的接缝

- 第 18 章（镇痛药）：阿片类降低呼吸中枢对二氧化碳的敏感性，本类提高其敏感性；两侧放在同一框架内，才说明本类的用途为何带时间窗与条件限制。
- 第 14 章（抗癫痫药与抗惊厥药）：本章中毒表现为惊厥，控制惊厥属那一章的类别；两章在「惊厥阈值」上相接。
- 第 15 章（抗精神失常药）：抗抑郁药不产生兴奋作用，也不改变正常人的情绪水平，两章的分界在此。
- 第 13 章（镇静催眠药）：巴比妥类与本类的功能抵消在本章被点明，但抵消不等于清除。

## 边界

本 Skill 只处理「一句表述 → 四格定位」的判定，不涉及剂量、适应证与临床决策。本章内容为教学材料，不构成用药建议；任何涉及个体的用药评估须由具备资质的人员依现行法律法规与规范作出，并对观察、记录与复核全程留痕。
