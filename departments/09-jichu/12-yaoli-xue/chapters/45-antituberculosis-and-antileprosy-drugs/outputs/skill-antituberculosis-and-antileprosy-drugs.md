# Skill：抗结核病药与抗麻风病药——两个前提、五个靶点、五项原则

## 何时用

- 读到「某药是主力 / 某方案是标准」，需要判断这句话说的是菌群、病灶、靶点还是原则
- 要解释「为什么要联合」「为什么不能见好就停」，而不是重复一句「规范要求」
- 遇到同一药物在不同病灶表现不一致，需要把原因落到血管、酸碱与穿透力上
- 要说明抗麻风病药为何以砜类为骨架、其余药各补哪个环节
- 要把用药观察整理成能复核的记录，却不确定该写哪五项

## 核心判据（六问）

1. **哪一环？** 菌群异质性（活跃 / 缓慢 / 休眠）→ 病灶环境（干酪样坏死 / 纤维化 / 空洞 / 细胞内 / 脑脊液）→ 靶点分工（细胞壁合成 / 转录 / 蛋白质合成 / 前药活化）→ 方案原则（早期 / 联合 / 适量 / 规律 / 全程）→ 体内过程（吸收 / 分布 / 消除）→ 观察记录。
2. **对哪段菌群？** 讲不出菌群指向的表述，多半是套话。
3. **进得了哪个隔间？** 脂溶性与分布决定能否进入细胞内与坏死组织；水溶性药物主要留在细胞外液。
4. **靶点是什么？** 细胞壁两处（分枝菌酸、阿拉伯半乳聚糖）、转录起始、酸性环境中的前药、核糖体翻译——四个位置对菌群状态的选择性不同。
5. **补的是哪个环节？** 联合的判据是机制、途径、毒性三类互补；同类重复只增毒性，不增覆盖面。
6. **判断交给谁？** 由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南决定。

## 执行步骤

```text
1. 收口：把待判句子压成一句「性质或作用」，删掉药名与用途
2. 归环：六环定位，跨环的写明中间环缺不缺
3. 定菌群：活跃 / 缓慢 / 休眠，三者选一为主
4. 定隔间：细胞内 / 细胞外液 / 坏死 / 空洞 / 纤维化 / 脑脊液
5. 落靶点：细胞壁、转录、翻译、前药活化，四选一
6. 查原则：对应五项原则的哪一条、联合的哪一条依据
7. 落观察：多出哪一栏，五项要素里哪项最易漏
8. 定去向：谁判断、依什么、如何留痕
```

## 硬约束

- **不写剂量、疗程、给药间隔、浓度、滴度、效价的量值。** 需要剂量时统一写「剂量与用法照底本」。
- **不作适应证判定，不作病情与预后判定，不作疗效断言与优越性断言，不作等级排名。**
- **引文逐字。** 标「教材·药理学·第45章·45.x.y」，核不到原文就不引；改写须标明是改写。
- **不写品名、厂商、剂型规格与价格。**
- **观察与判断分家。** 观察所得是材料，不是结论；判断另设一栏，由具备资质的人员填写。
- **不确定就写下来。** 标待核实，不用推测填空。

## 交付物

1. 一条归环链：菌群 → 病灶 → 靶点 → 原则 → 体内过程 → 观察
2. 一处菌群定位：这条表述主要对哪一段菌群成立
3. 一栏观察补充：记录表上因此要多写什么
4. 一句边界句：本章只描述机制与类别，判断归属另行

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 结论当理由 | 「必须联合」说了等于没说 | 补菌群异质性与病灶异质性两个前提 |
| 靶点当疗效 | 说得出抑制什么酶，推不出对哪段菌群有效 | 补菌群与隔间两问 |
| 把常用当最优 | 把「常用」写成「不可替代」 | 改为性质描述，删掉排序 |
| 偷给量值 | 疗程、间隔、剂量无来源 | 改为「剂量与用法照底本」 |
| 耐药归因于人 | 把漏服写成「不配合」 | 归因于暴露低谷这一机制，行为只作记录 |
| 记录写判断 | 「考虑药物过敏」混进观察栏 | 拆成两栏：所见一栏，判断一栏 |
| 麻风反应当毒性 | 把免疫现象写成药物不良反应 | 按两型分开叙述，处理归具备资质的人员 |

## 与相邻章节的接缝

- 第 44 章（抗真菌药与抗病毒药）：同属化学治疗，选择性来自病原体特有的酶系；本章的选择性来自菌群状态与病灶分布，两者不可互推。
- 第 40–43 章（抗菌药各论）：耐药的四条一般途径（降低摄取、增强外排、改变靶点、增强灭活）在本章同样成立，但本菌的耐药多源于染色体突变的自发出现与药物选择。
- 第 3 章（药动学）：本章的吸收、分布、消除三节在那一章有参数化写法，本章只用定性关系。
- 第 48、49 章（免疫抑制药与免疫增强药）：同属化学治疗篇之后的药物治疗，但评价口径不同——那两章以免疫环节为轴，本章以菌群与病灶为轴。

## 边界

本 Skill 只处理「一条表述 → 链上位置」的判定，不涉及剂量、适应证与临床决策。本章内容为教学材料，不构成用药建议；任何涉及个体的用药评估须由具备资质的人员依现行法律法规与规范作出，并以现行药品说明书为依据。
