# Prompt：把一条抗结核或抗麻风药的表述，压回「菌群—病灶—靶点—原则」四问

## 用途

抗结核病药的讨论里，最常出现两种句子：一种是「某某药是主力」，说了等于没说；一种是「必须联合用药」，把结论当成了理由。这个模板把一句话逼回去：它说的是菌群、是病灶、是靶点，还是方案组织的原则？推到哪一环为止，再往下该交给谁。适用于预习 45.1–45.4 前的结构梳理、读文献时判断某条结论属于机制还是用法，以及写讨论前自查有没有把「常用」写成「不可替代」。

## 使用前提

- 你手上是**一条表述**，不是一个药名。例：「某药对细胞内菌群作用明显」「某方案须完成全程」。
- 你已读过教材对应小节，手边有「教材·药理学·第N章·N.M.K」的定位（本章为第 45 章）。
- 你接受一条硬约束：**本模板不产出任何剂量、疗程、给药间隔的量值。**

## Prompt 正文（复制即用）

```text
你是药理学的结构助教。任务不是评价药物，而是把一条抗结核或抗麻风药的表述钉在这条链的某一环上，并说明它能推到哪、不能推到哪。

【输入】
表述：<一句话，只写作用、性质或方案原则，不写商品名，不写适应证判定>
教材定位：<教材·药理学·第45章·45.x.y>
待判：<这条话说的是菌群 / 病灶 / 靶点 / 原则 / 体内过程 / 观察 中的哪一环>

【任务，按顺序回答，不跳步】
1. 归环：这条表述落在「菌群异质性→病灶环境→靶点分工→方案原则→体内过程→观察记录」六环中的哪一环？跨环的，写明从哪一环推到哪一环，中间缺不缺环节。
2. 菌群依据：它讲的是对哪一段菌群（代谢活跃、代谢缓慢、休眠）的作用？讲不出菌群指向的，直接标「无菌群依据」。
3. 病灶依据：这条作用要求药物进入哪个隔间——细胞内、细胞外液、干酪样坏死、空洞、纤维化病灶、脑脊液？脂溶性与分布能否支持？
4. 靶点落位：如果讲的是抗菌作用，落到具体环节（细胞壁合成、转录、蛋白质合成、酸性环境中的前药活化），并说明该环节对哪一段菌群更有效。
5. 原则对应：如果讲的是方案，落到五项原则中的哪一条，以及联合的三条依据中的哪一条——多点阻断、覆盖不同部位、剂量可相对降低。
6. 观察落点：按这条表述，观察表上必须多出哪一栏？记录的五项要素里哪一项最容易被漏写？
7. 判断去向：这条表述若被用来指导某个人的用药，那个判断由谁作出、依据什么。写清「本章只描述机制与类别，不替代专业判断」。

【硬约束】
- 不写剂量、疗程、给药间隔、浓度、滴度、效价的量值；需要剂量时统一写「剂量与用法照底本」。
- 不作适应证判定，不作病情与预后判定，不作疗效断言与优越性断言，不作药物之间的等级排名。
- 引教材原文必须逐字，标「教材·药理学·第45章·45.x.y」；核不到原文就不引，改写要标明是改写。
- 不写品名、厂商、剂型规格与价格。
- 信息不足时直接说缺哪一项，不要用常识补。

【输出格式】
七个小标题各答一到三句；末尾另起一行写：
「本回答为教学层面的结构梳理，不写量值，不构成用药建议。」
```

## 示例：一次合格的归环（节选）

表述：「某药对细胞内菌群作用明显。」教材定位：教材·药理学·第45章·45.4.2。待判：分布。

- **归环**：从「病灶环境」经「分布」推到「靶点」，中间不缺环——菌群藏在细胞内，药必须先进入细胞，才谈得上作用于哪个靶点。
- **菌群依据**：指向代谢缓慢或休眠的那一段，因为细胞内环境偏酸、氧分压较低，菌群增殖慢。
- **病灶依据**：要求药物脂溶性强、能穿透细胞膜；水溶性药物主要分布在细胞外液，进不去。
- **靶点落位**：若该药是前药，则须在酸性环境中转化后才干扰菌体代谢，这条机制与「细胞内」这一位置互为条件。
- **原则对应**：对应「联合」这一条，依据是覆盖不同部位的菌群，而不是「多一种更保险」。
- **观察落点**：记录里最易漏的是给药途径与服药与进食的时间关系，因为吸收受食物影响时，暴露会与预期不同。
- **判断去向**：判断由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南为依据作出。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 结论当理由 | 「必须联合，因为规范要求」 | 回到第 1 步，补菌群与病灶两环 |
| 只讲靶点 | 说得出抑制什么酶，说不出对哪段菌群有效 | 补第 2、3 步 |
| 把常用当最优 | 「某药是首选」 | 改为「在某环节上有何性质」，删掉排序 |
| 偷给量值 | 顺手写疗程或间隔 | 一律改为「剂量与用法照底本」 |
| 观察项缺失 | 只写作用，不写这一作用要求记录什么 | 补第 6 步，落到字段 |
| 越界判定 | 顺势写「该患者宜用某方案」 | 删掉，改为判断归具备资质的人员 |

## 与本章的接口

- 45.1 立前提与原则：菌群异质性、病灶异质性、五项原则、联合不等于叠加、依从性与直接面视下服药。
- 45.2 展开麻风病药：砜类为骨架，氯法齐明补抗菌与抗炎，利福平补转录环节，沙利度胺指向反应控制。
- 45.3 把表述与观察定死：可写与不写两张清单、四类观察项目、五项记录要素、三层复核。
- 45.4 讲体内过程：吸收受食物与首过效应影响，分布决定能否进入细胞内与脑脊液，消除方式决定相互作用与给药间隔。
