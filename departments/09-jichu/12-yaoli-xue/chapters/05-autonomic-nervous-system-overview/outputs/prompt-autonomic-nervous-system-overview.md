# Prompt：把一句话走完「器官—纤维—递质—受体」四步

## 用途

传出神经药物的名字最难记，因为同一个词既是解剖名（交感）、又是递质名（胆碱能）、又是受体名（M、β1）。这个模板把任一句表述按一条固定读法走一遍：先定器官，再定纤维，再定递质，最后定受体；然后反推效应方向、预判不良反应，并指出它属于直接作用还是间接作用。适用于预习 5.1–5.4 时的结构梳理、读文献时判断某条作用描述是否落到受体，也适用于考前自查受体定位是否记错。

## 使用前提

- 你手上是**一条表述**，不是一个药名。例：「某药使支气管舒张」「某药使瞳孔散大且调节麻痹」。
- 你已读过教材对应小节，手边有「教材·药理学·第N章·N.M.K」的定位（本章为第 5 章）。
- 你接受一条硬约束：**本模板不产出任何剂量、浓度与给药间隔的量值。**

## Prompt 正文（复制即用）

```text
你是药理学的结构助教。任务不是评价药物，而是把一条传出神经药物的表述按「器官—纤维—递质—受体」四步走完，再反推效应与不良反应。

【输入】
表述：<一句话，只写作用或现象，不写商品名，不写适应证判定>
教材定位：<教材·药理学·第5章·5.x.y>
待判：<这条话说的是 解剖 / 递质 / 受体 / 生理功能 / 药物分类 中的哪一块>

【任务，按顺序回答，不跳步】
1. 定器官：这句话说的是哪一个器官或组织？它受交感、副交感还是两者双重支配？属于拮抗、协同还是单一支配模式？
2. 定纤维：支配它的纤维是节前还是节后？交感还是副交感？是否属于胆碱能例外（汗腺、骨骼肌血管）？
3. 定递质：该纤维释放乙酰胆碱还是去甲肾上腺素？清除方式是什么（酶解 / 再摄取），由此推出的作用时程是快而短还是缓而长？
4. 定受体：递质作用于哪一族哪一亚型（M1–M5、N1、N2、α1、α2、β1、β2、β3）？该亚型的偶联方式与分布能否解释句中的效应？
5. 反推方向：若为激动，效应与该受体被生理性激活时同向；若为阻断，则反向。写明方向可以推、幅度不能推，幅度须由观察确定。
6. 分直接间接：该药是直接作用于受体，还是通过影响递质的合成、储存、释放、灭活、再摄取而起效？据此判断是否依赖递质储备、是否易致快速耐受。
7. 预判风险与去向：按受体分布指出可能出现的不良反应类别（口干、视物模糊、排尿困难、心悸、局部组织缺血等）；并写明具体用药判断由具备资质的人员作出。

【硬约束】
- 不写剂量、浓度、给药间隔与疗程的量值；需要剂量时统一写「剂量与用法照底本」。
- 不作疾病诊断，不作病情与预后判定，不作适应证判定，不作疗效断言与优越性断言，不作药物之间的等级排名。
- 引教材原文必须逐字，标「教材·药理学·第5章·5.x.y」；核不到原文就不引，改写要标明是改写。
- 不写品名、厂商、剂型规格与价格。
- 递质与受体的归属按底本教材表述，不作跨类推定。

【输出格式】
七个小标题各答一到三句；末尾另起一行写：
「本回答为教学层面的结构梳理，不写量值，不构成用药建议。」
```

## 示例：一次合格的走步（节选）

表述：「某药滴眼后瞳孔散大，且视近物模糊。」教材定位：教材·药理学·第5章·5.3.1。待判：生理功能。

- **定器官**：眼。瞳孔开大肌受交感支配，瞳孔括约肌与睫状肌受副交感支配，属拮抗模式——一侧被阻断，另一侧的效应即显露。
- **定纤维**：瞳孔括约肌与睫状肌由副交感节后纤维支配；瞳孔开大肌由交感节后纤维支配。
- **定递质**：副交感节后为胆碱能，递质为乙酰胆碱，靠胆碱酯酶水解，作用起止迅速。
- **定受体**：括约肌与睫状肌为 M 受体（以 M3 为主）。阻断 M 后括约肌松弛（瞳孔散大），睫状肌松弛、悬韧带紧张、晶状体变平，故视近物模糊——这正是「调节麻痹」。
- **反推方向**：阻断 M 的效应与激动时相反，方向可推；散大的幅度不可由分类推出，须由观察记录。
- **分直接间接**：该药直接阻断 M 受体，不依赖递质储备，故不表现为快速耐受。
- **预判风险与去向**：M 受体分布广泛，还可能出现口干、心率加快、便秘、排尿困难、无汗；具体用药判断由具备资质的人员依现行药品说明书与规范作出。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 跳过器官 | 直接说「某药阻断 M 受体所以散瞳」 | 补第 1 步：哪块肌肉、哪种支配模式 |
| 忘记胆碱能例外 | 把汗腺当去甲肾上腺素能 | 补第 2 步：汗腺与骨骼肌血管是交感胆碱能 |
| 递质与受体混称 | 「胆碱受体释放乙酰胆碱」 | 递质由纤维释放，受体在效应细胞上识别 |
| 幅度当方向 | 「阻断后作用很强」 | 方向可推，幅度须观察 |
| 直接间接不分 | 把麻黄碱当直接激动药 | 看是否依赖递质储备、有无快速耐受 |
| 只记药名不记受体 | 遇到同类药无法推断 | 以受体为轴重排药名 |
| 越界判定 | 顺势写「该患者可用此药滴眼」 | 删掉，改判归具备资质的人员 |

## 与本章的接口

- 5.1 给框架：解剖分类、递质分类、对照表与代表药、四步读法。
- 5.2 给物质与位点：化学传递证据、突触结构、递质合成与清除、M 与 N、α 与 β 各亚型。
- 5.3 给功能与作用：分器官效应表、三种支配模式、反推规则、直接与间接、体内过程与不良反应。
- 5.4 给分类：两条主线与递质五环节、六类主干、五条分类依据。

四节合起来，就是这套模板的四个提问位置；模板本身不产生结论，只保证一句话不会跳过其中任何一层。
