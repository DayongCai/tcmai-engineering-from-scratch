# Skill：传出神经系统概论——三层框架、四步读法、六类主干

## 何时用

- 看到「某药使瞳孔散大」「某药舒张支气管」，要知道落在哪个受体上
- 分不清交感与副交感的节前节后、支配范围与递质归属
- 遇到「交感节后纤维为什么有的是胆碱能」这类交叉问题
- 要把一个药归入六类主干之一，却不确定以什么为主纲
- 读到「某药作用强 / 起效快」，需要判断它是直接作用还是间接作用

## 核心判据（六问）

1. **哪个器官？** 受交感、副交感还是双重支配？属拮抗、协同还是单一支配？— 模式决定「阻断一侧后会看到什么」。
2. **哪条纤维？** 节前还是节后、交感还是副交感；是否为胆碱能例外（汗腺、骨骼肌血管）。
3. **哪种递质？** 乙酰胆碱（酶解，起止迅速）还是去甲肾上腺素（再摄取，起止较缓）？清除方式决定作用时程。
4. **哪个受体？** M1–M5、N1、N2、α1、α2、β1、β2、β3。分布解释效应，偶联方式解释同一受体的器官差异。
5. **直接还是间接？** 直接作用于受体者不依赖递质储备；影响合成、储存、释放、灭活、再摄取者依赖储备，易致快速耐受。
6. **判断交给谁？** 由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南决定。

## 执行步骤

```text
1. 收口：把待判句子压成一句「器官 + 效应」，删掉药名与用途结论
2. 定器官与模式：拮抗 / 协同 / 单一支配
3. 定纤维：交感或副交感、节前或节后、有无胆碱能例外
4. 定递质与清除：酶解还是再摄取，推出时程特征
5. 定受体与亚型：分布 + 偶联，解释效应并预告无关效应
6. 反推方向：激动同向、阻断反向；方向可推、幅度须观察
7. 判方式：直接 / 间接；是否依赖储备、有无快速耐受
8. 预判风险：按受体分布列出不良反应类别
9. 定去向：谁判断、依什么、如何留痕
```

## 硬约束

- **不写剂量、浓度、给药间隔与疗程的量值。** 需要剂量时统一写「剂量与用法照底本」。
- **不作疾病诊断，不作病情与预后判定，不作适应证判定。**
- **不作疗效断言与优越性断言，不作药物之间的优劣与等级排名。** 分类只描述机制位置。
- **引文逐字。** 标「教材·药理学·第5章·5.x.y」，核不到原文就不引；改写须标明是改写。
- **递质与受体归属按底本。** 不把某一药物的归属跨类推定到同类其他药物。
- **选择性是相对的。** 剂量增大后作用谱扩大；「选择性高」须结合剂量与观察器官。
- **作用方式以证据判定。** 能被同受体拮抗药取消且不依赖末梢者为直接；依赖储备、去神经后消失者为间接。

## 交付物

1. 一次四步定位：器官 → 纤维 → 递质 → 受体
2. 一条支配模式判断：拮抗 / 协同 / 单一
3. 一个方向推演与幅度声明
4. 一句直接或间接的判断及其对耐受性的含义
5. 一句边界句：判断归具备资质的人员，教材不替代专业判断

## 典型误用

| 误用 | 表现 | 纠正 |
|---|---|---|
| 跳过器官 | 由受体直接跳到临床用途 | 先定器官与支配模式 |
| 忘记例外 | 把汗腺当去甲肾上腺素能 | 汗腺、骨骼肌血管为交感胆碱能 |
| 递质受体混称 | 「胆碱受体释放递质」 | 纤维释放递质，细胞上的受体识别它 |
| 幅度当方向 | 「阻断后作用很强」 | 方向可推，幅度须观察 |
| 直接间接不分 | 把麻黄碱当直接激动药 | 看储备依赖与快速耐受 |
| 分类当排序 | 「某类药更优」 | 分类只描述机制位置 |
| 只记药名 | 遇到同类药无从推断 | 以受体为轴重排药名 |

## 边界

本 Skill 只处理「一条表述 → 四步定位」的推演，不涉及剂量、适应证与临床决策。本章内容为教学材料，不构成用药建议；任何涉及个体的用药评估须由具备资质的人员依现行法律法规与规范作出。
