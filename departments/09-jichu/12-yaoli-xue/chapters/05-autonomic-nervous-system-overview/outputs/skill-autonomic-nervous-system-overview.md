# 以受体为主纲不是编排习惯，而是解剖、递质与临床应用共同给出的答案

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 没有被主题叙述点到的小节，在这里也必须有位置
- 引文是教材正文，不是经典
- 三层框架是压缩
- 受体亚型表是教学地图，不是处方依据
- 词频只描述写法
- 量值一律不给

## 边界

- **引文是教材正文，不是经典。** 卷首 MOTTO 取自经典，另标《书名·篇名》，与此条不冲突；本章正文引用格式为「教材·药理学·第N章·N.M.K」。教材举的药名用于说明分类位置，不构成对任何药物的评价。
- **三层框架是压缩。** 真实的传出神经解剖与受体药理学远为复杂，本章只留「解剖—递质—受体」这条主线；丢掉的是亚型分子结构、共传递的定量关系与中枢调控。
- **受体亚型表是教学地图，不是处方依据。** 分布与偶联的描述用于推演效应方向，不用于判断某个个体的反应。
- 本章为药理学教学材料，框架、分型与分类取自教材第 5 章，统计数字由 `code/main.js` 现算。
