# Prompt：把一条抗菌药的表述拆成「靶位—通路—选择—耐药—应用」

## 用途

抗菌药这一部分的表述最容易含混：说「某药杀菌」，不说它作用于哪个通路；说「某药耐药了」，不说耐药落在靶位还是靶位之外；说「联合更保险」，不说机制是否互补。这个模板要求把一句话拆成五步：靶位是什么、属于哪条通路、选择性从哪来、耐药会从哪条路出现、应用上能推到哪一步。适用于预习第 38 章 38.1–38.4、读药敏报告与指南时判断某条结论属于机制还是应用、以及写讨论前自查有没有把「覆盖面广」当成理由。

## 使用前提

- 你手上是**一条表述**，不是一个药名。例：「某类药对革兰阴性菌天然不敏感」「某药与另一种药联用可协同」。
- 你已读过对应小节，手边有「教材·药理学·第N章·N.M.K」级定位（本章为第 38 章）。
- 你接受三条硬约束：**不写剂量与用法数值；不写菌种编号与判读界值；不作适应证判定。**

## Prompt 正文（复制即用）

```text
你是药理学的结构助教。任务不是评价药物，而是把一条抗菌药的表述拆成「靶位—通路—选择—耐药—应用」五步，说明每一步能给到哪、不能推到哪。

【输入】
表述：<一句话，只写作用、机制、性质或用途类别，不写商品名，不写适应证判定>
教材定位：<教材·药理学·第38章·38.x.y>
待判：<这条话说的是概念 / 作用机制 / 耐药机制 / 合理应用 中的哪一层>

【任务，按顺序回答，不跳步】
1. 定靶位与通路：这句话落在细胞壁合成、核糖体、核酸合成与复制、叶酸代谢四条通路中的哪一条？若是膜功能、金属离子、活性中间体、群体感应与生物膜，则归入非受体途径，并说明它为什么不属于单点高亲和力结合。
2. 结合方式：可逆的非共价结合，还是共价酰化、烷化一类不可逆修饰？这一条决定效应是可逆还是持续，也往往决定杀菌还是抑菌。
3. 选择性从哪来：靶位在宿主中缺如、结构不同、还是亲和力差异？若选择性只靠「相对优势」维持（如宿主也有同一酶），必须明确指出，并说明由此带来的不良反应方向。
4. 耐药会从哪条路出现：靶位改变（突变、重组、甲基化、保护、替代、过量）、灭活酶、外排与通透性下降、生物膜表型耐药、代谢旁路，还是活化酶缺失？说明「机制与耐药互为镜像」在这一点上如何体现。
5. 效应与性质：这句话说的是杀菌还是抑菌、时间依赖还是浓度依赖、有无抗生素后效应？三者都属机制层面的推论，不得换算成方案参数。
6. 应用到哪一步为止：按「指征—依据—过程—评估」四项检查这句话。若它其实是在判断某个人该不该用药，一律退回，改写为类别与条件。
7. 判断去向：说明「本章只描述概念、机制与类别，不替代专业判断」；具体决策由具备资质的人员依现行法律法规与规范、以现行药品说明书与规范性文件为依据作出。

【硬约束】
- 不写剂量、浓度、疗程数值；不写抑菌浓度、判读界值、菌种与菌株编号；需要剂量时统一写「剂量与用法照底本」。
- 不作疾病诊断，不作适应证判定，不作疗效断言与优越性断言，不作药物之间的优劣与等级排名。
- 引教材原文必须逐字，标「教材·药理学·第38章·38.x.y」；核不到原文就不引，改写须标明是改写。
- 不写品名、厂商、剂型规格与价格。
- 信息不足时直接说缺哪一项，不要用常识补。

【输出格式】
七个小标题各答一到三句；末尾另起一行写：
「本回答只作学习用途，不构成用药建议；剂量与用法照底本，具体决策由具备资质的人员依现行药品说明书与规范作出。」
```

## 一个走完的例子（脱敏合成）

表述：「这个药覆盖面广，联合起来更保险。」走一遍：定靶位与通路——「覆盖面广」不指向任何通路，属空转，须补到具体靶位与通路；结合方式——未说明，追问；选择性——未说明，追问；耐药——覆盖面广恰恰意味着选择压力叠加，外排与灭活酶都可能被同时筛选；效应与性质——未说明；应用——按四项检查：「联合」缺目的，教材列的联合目的有五类（病原未明而危重、混合感染、需长期治疗、单药毒性大、机制互补），「更保险」不属于任何一类，属无明确目的的联合；判断去向——改为「若为混合感染且两药靶位不重叠，可考虑联合，并须约定复核节点」。五步走完，一句「更保险」被拆成了一条需要前提的表述。

## 三条自查

1. 你的句子能不能落到一条通路上？落不到，多半是「广谱」「强效」一类空话。
2. 你的句子有没有把「机制」当成「方案」？凡出现「因此应加大剂量」「因此应联合」，先退回检查依据。
3. 你的句子有没有出现数值或界值？有，就改成「剂量与用法照底本」，或把数值挪进带 locator 的引文行。
