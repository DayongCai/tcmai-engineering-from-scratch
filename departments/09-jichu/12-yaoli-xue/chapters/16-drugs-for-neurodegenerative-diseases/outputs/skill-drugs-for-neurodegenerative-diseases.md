# Skill：退行性疾病药——两道门槛、九个环节、一张观察表

## 何时用

- 读到「某药起效快 / 作用强 / 更适合早期」，需要判断这句话卡在哪一环
- 要解释「为什么要合用卡比多巴」「为什么苯海索对运动迟缓作用有限」
- 要解释「美金刚凭什么保留生理性传递」，而不滑向「亲和力越低越好」
- 要把「起效慢」这类模糊印象拆成可核对的时间尺度与观察单元
- 要把运动症状、非运动表现与不良反应整理成能复核的记录

## 核心判据（五问）

1. **哪一环？** 补充前体、抑制外周脱羧、抑制单胺氧化酶 B 型、促进释放、激动受体、抑制儿茶酚氧位甲基转移酶；抑制胆碱酯酶、激动 M 受体、拮抗 NMDA 受体。九环选一为主。
2. **过得了门吗？** 作用部位在中枢还是外周？靠脂溶性、靠转运体，还是靠主动转运？跨不过门槛的药，效应必然停在外周。
3. **效应谱对得上吗？** 由环节推效应，不由药名推。补前体对震颤作用相对有限；阻断 M 受体对运动迟缓作用有限；抑制胆碱酯酶依赖残存神经元；拮抗 NMDA 受体对应中重度阶段。
4. **时间尺度是哪一档？** 数日内的行为变化、以周计的症状群变化、以月计的沉积物改变。三档混用，观察必然误判。
5. **判断交给谁？** 由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南决定，并留痕。

## 执行步骤

```text
1. 收口：把待判句子压成一句「某环节被增强 / 被削弱」
2. 定环：九个环节里选一个，跨环的写明中间环缺不缺
3. 过门：中枢还是外周，过门方式写清
4. 推谱：由环节写效应，不写强弱
5. 定标：时间尺度 + 观察单元
6. 落栏：记录表因此多写什么
7. 查边界：疗效断言、优劣比较、绝对化、诊断与预后判定
8. 定去向：谁判断、依什么、如何留痕
```

## 硬约束

- **不写剂量、浓度、疗程与阶段分值的量值。** 需要剂量时统一写「剂量与用法照底本」。
- **不作适应证判定，不作病情与预后判定，不作疗效与优越性断言，不作等级排名。**
- **引文逐字。** 标「教材·药理学·第 16 章·N.M.K」，核不到原文就不引；改写须标明是改写。
- **不写品名、厂商、剂型规格与价格。**
- **研究阶段的内容不作既成结论。** 教材写「可能涉及」，就照「可能涉及」写。
- **中药来源只写来源与化学类别**，不引申为疗效论据，不与同类药比较。

## 交付物

1. 一条定位链：环节 → 门槛 → 效应 → 不良反应 → 观察项目
2. 一处门槛说明：这个药靠什么进入中枢，或为何进不去
3. 一条时间尺度：这句话属于哪一档，观察单元随之确定
4. 一句边界句：本章只写类别与机制，判断归属另行

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 把「补递质」当万能解释 | 解释不了为何某药对运动迟缓无效 | 补环节与门槛，写明效应偏向 |
| 由类别名推效应 | 把「中枢性抗胆碱药」当成全能抗帕金森药 | 回到 M 受体分布与纹状体环路 |
| 把亲和力高低当优劣 | 认为亲和力越低越安全 | 改为「是否保留生理性传递」 |
| 用单日观察判断疗效 | 以周计的效应被误判为无效 | 观察单元改为周，写明起效机制 |
| 记录不写给药时刻 | 剂末现象无法归因 | 增设给药时刻与间隔栏 |
| 三类运动并发症混写 | 复核时无法区分、无法纵向对照 | 剂末按时段、开关写转换、异动写部位 |

## 与相邻章节的接缝

- 第 15 章（抗精神失常药）：苯海索在那一章是抗精神病药所致锥体外系反应的处理类别，在本章是抗帕金森药；同一药物两处出现，落点不同。
- 第 13 章（镇静催眠药）：金刚烷胺的中枢作用与镇静药的观察项目有交叠，但前者看的是释放与受体阻断，后者看的是抑制性递质。
- 第 18 章（镇痛药）：美金刚与右美沙芬、金刚烷胺同作用于 NMDA 受体，合用时的中枢效应叠加在这一章被点明。
- 第 3 章（药动学）：本章的吸收、分布、生物转化与排泄四段，在那一章有参数化写法；本章只用定性关系。

## 边界

本 Skill 只处理「一句表述 → 四格定位」的判定，不涉及剂量、适应证与临床决策。本章内容为教学材料，不构成用药建议；任何涉及个体的用药评估须由具备资质的人员依现行法律法规与规范作出，并对观察、记录与复核全程留痕。
