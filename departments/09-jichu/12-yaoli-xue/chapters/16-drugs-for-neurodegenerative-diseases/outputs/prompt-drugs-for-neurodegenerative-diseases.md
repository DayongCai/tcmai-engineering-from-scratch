# Prompt 模板：退行性疾病药的两道门槛推演

## 用途

拿到一段关于抗帕金森病药或抗阿尔茨海默病药的表述，用这套模板判断它卡在哪一道门槛上：吸收进体循环、透过血脑屏障、还是到了受体之后信号转不出去。适用于：读教材时自查有没有把「补递质」当成万能解释；判断某个新药的作用环节与观察重点；把「起效慢」这类模糊印象拆成可核对的时间尺度；在讨论中被问到「为什么这个药要合用另一个」。

模板不产出用药结论，只产出四个定位：作用环节、门槛位置、效应谱、观察项目。

## 用法

按顺序填四格，填不满就说明这句话还缺依据。

1. **环节**：这句话说的是哪一环？补充前体、抑制外周脱羧、抑制单胺氧化酶、促进释放、激动受体、抑制儿茶酚氧位甲基转移酶、抑制胆碱酯酶、激动 M 受体、拮抗 NMDA 受体。九环选一为主。
2. **门槛**：这个环节要求药物到达哪里？中枢还是外周？若在中枢，它靠脂溶性、靠转运体，还是靠主动转运？跨不过门槛的药，其效应必然停在外周——卡比多巴就是标本。
3. **效应谱**：由环节推效应。补前体对应运动症状改善、对震颤作用相对有限；阻断 M 受体对应震颤与强直改善、对运动迟缓作用有限；抑制胆碱酯酶对应认知相关指标与部分行为症状；拮抗 NMDA 受体对应中重度阶段的表现。效应谱写不出来，说明环节没定准。
4. **观察项目**：对应新增或改写的栏目。运动症状与非运动表现分列；口干、排便、排尿、视物清晰度；胃肠道耐受性、心率、体重；步态、意识、睡眠。栏目由环节推出，不由药名罗列。

## 输出格式

```text
原句：……
环节：……（九环之一）
门槛：中枢 / 外周，过门方式为……
效应谱：……（可观察的效应，不写强弱排序）
观察项目：……（新增或改写的栏目）
时间尺度：数日内 / 以周计 / 以月计（并注明依据）
越界检查：是否含疗效断言 / 优劣比较 / 绝对化 / 诊断或预后判定
落点：剂量与用法照底本；判断归具备资质的人员
```

## 硬约束

- 不写剂量、浓度、疗程、阶段分值的量值；需要剂量时统一写「剂量与用法照底本」。
- 不作适应证判定，不作病情与预后判定，不作疗效与优越性断言，不作等级排名。
- 引文逐字，标「教材·药理学·第 16 章·N.M.K」；核不到原文就不引。
- 中药来源只写来源与化学类别，不引申为疗效论据，不与同类药比较。
- 从研究阶段的内容不作既成结论转述；教材标「可能涉及」的，就照「可能涉及」写。

## 一个反例

「左旋多巴效果最好，所以首选」——三处越界：把类别结论当个体结论；用「最好」作优劣断言；没有给出环节与门槛依据。按模板改写为：「左旋多巴为补充前体，进入中枢的量虽少却与症状改善程度相关，故外周脱羧抑制可提高其入脑比例；观察项目为运动症状与非运动表现分列，并写明给药时刻；是否选用由具备资质的人员判断。」改写后三处越界都收回到了机制与记录层面。
