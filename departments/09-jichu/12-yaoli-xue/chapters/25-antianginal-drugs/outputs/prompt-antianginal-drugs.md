# Prompt：把一条抗心绞痛药的表述钉到耗氧表的某一项上

## 用途

抗心绞痛药的讨论里最容易出现两种句子：一种是「某药是抗心绞痛的一线用药」，说了等于没说；一种是「某药扩张血管所以好用」，把一个环节当成了整条理由。这个模板把一句话逼回耗氧表：它改的是前负荷、后负荷，还是心率与收缩力；改的是耗氧一侧还是灌注一侧；推到哪一步为止、再往下该交给谁。适用于预习 25.1–25.4 前的结构梳理、读文献时判断某条结论属机制还是用法，以及写联合用药的讨论前自查有没有把「环节互补」写成「效果更好」。

## 使用前提

- 你手上是**一条表述**，不是一个药名。例：「某药以扩张容量血管为主」「某药在负荷状态下才显出效应」「某类药合用会叠加负性传导」。
- 你已读过教材对应小节，手边有三级定位（本章为第 25 章，小节编号形如 25.x.y）。
- 你接受一条硬约束：**本模板不产出任何剂量、浓度、给药间隔与疗程的量值。**

## Prompt 正文（复制即用）

```text
你是药理学的结构助教。任务不是评价药物，而是把一条抗心绞痛药的表述钉在耗氧表的某一项上，并说明它能推到哪、不能推到哪。

【输入】
表述：<一句话，只写作用、机制或用途类别，不写商品名，不写适应证判定>
教材定位：<教材·药理学·第25章·25.x.y>
待判：<这条话说的是耗氧一侧 / 灌注一侧 / 联合关系 / 观察要求 中的哪一类>

【任务，按顺序回答，不跳步】
1. 定位：这条表述改的是心肌耗氧的三项因素（心率、收缩力、心室壁张力）中的哪一项？还是改为增加缺血区灌注？跨两项的，写明主次。
2. 环节：落到具体路径——扩张容量血管降前负荷、扩张动脉降后负荷、抑制心脏做功降心率与收缩力、抑制心肌收缩与传导、改变能量代谢或离子流。五者选一个主要的。
3. 机制依据：如果它讲的是效应强弱或起效快慢，指出机制上的落点——一氧化氮与环磷酸鸟苷通路、受体竞争性拮抗、通道的状态依赖性与频率依赖性、首过效应与给药途径。讲不出落点的，直接标「无机制依据」。
4. 边界条件：这条规律在什么情形下减弱或不成立——耐受性、反射性心率增快、受体上调与停药反跳、剂量增大后选择性减弱、肝药酶相关的相互作用？找不到就写「本教材未展开」。
5. 联合关系：如果这条表述涉及两种药，判断它属于协同、相加还是相互抵消，依据是作用靶点与效应轴，而不是类别名称。同一类别内部的重复是否属于缺少增益的情形？
6. 观察要求：按这条表述，观察表上必须多出哪一栏？要不要同时记立位与卧位？要不要写明给药时点与合并用药？
7. 判断去向：这条表述若被用来指导某个人的用药，那个判断由谁作出、依据什么。写清「本章只描述机制与类别关系，不替代专业判断」。

【硬约束】
- 不写剂量、浓度、给药间隔、疗程与作用维持时长的量值；需要剂量时统一写「剂量与用法照底本」。
- 不作适应证判定，不作病情与预后判定，不作疗效断言与优越性断言，不作药物之间的等级排名。
- 引教材原文必须逐字，标「教材·药理学·第25章·25.x.y」；核不到原文就不引，改写要标明是改写。
- 不写品名、厂商、剂型规格与价格。
- 信息不足时直接说缺哪一项，不要用常识补。

【输出格式】
七个小标题各答一到三句；末尾另起一行写：
「本回答为教学层面的结构梳理，不写量值，不构成用药建议。」
```

## 示例：一次合格的定位（节选）

表述：「某药扩张容量血管，用于发作时的处理。」教材定位：25.1.2 与 25.1.3。待判：耗氧一侧。

- **定位**：改的是心室壁张力这一项，路径为前负荷下降；不涉及心率与收缩力的直接抑制。
- **环节**：扩张容量血管为主，剂量增大时动脉也扩张，后负荷随之减轻。
- **机制依据**：细胞内生物转化释出一氧化氮，激活鸟苷酸环化酶使环磷酸鸟苷增多，依赖该环核苷酸的蛋白激酶降低细胞内钙，肌球蛋白轻链磷酸化受抑。落点清楚。
- **边界条件**：连续给药使效应减弱，机制涉及巯基耗竭、神经激素系统激活、超氧阴离子增多与通路脱敏；反射性心率增快部分抵消耗氧下降；剂量偏大时另有高铁血红蛋白倾向与眼内压升高。
- **联合关系**：与 β 受体阻断药在心率环节一增一减，属协同；与磷酸二酯酶 5 抑制药属血管舒张过度方向的风险叠加。
- **观察要求**：心率与血压（含立位与卧位）、发作频次与持续时长、头痛与潮红等血管舒张相关表现；须写明给药时点。
- **判断去向**：判断由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南为依据作出。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 药名当答案 | 「某药是首选」 | 回到第 1 步，写它改的是哪一项 |
| 环节当整条理由 | 「扩张血管所以有效」 | 补第 2、3 步：扩的是静脉还是动脉，机制落在哪 |
| 忽略反射 | 只讲耗氧下降，不提心率增快 | 补第 4 步，说明抵消与灌注时间的变化 |
| 类别推个体 | 「二氢吡啶类都使心率增快」 | 改写为「治疗剂量下反射性增快较明显，剂量增大后选择性减弱」 |
| 组合当叠加 | 「两种同类药一起用更强」 | 回到第 5 步，判断是否落在同一环节 |
| 越界判定 | 顺势写「该患者宜用某类」 | 删掉，改为判断归具备资质的人员 |

## 与本章的接口

- 25.1 给硝酸酯类：两条主线、一氧化氮与环磷酸鸟苷通路、静脉强于动脉、耐受性与首过效应。
- 25.2 给受体学地基：特异性与可饱和性、竞争性拮抗、受体上调与停药反跳、亚型分布与选择性。
- 25.3 给钙通道阻断药：α1 亚基与结合位点、二氢吡啶类与非二氢吡啶类的方向差别、电压依赖性与频率依赖性、同一酶系相关的相互作用。
- 25.4 把前三节收成关系表：联用的三个目的、三种类别关系、两类风险方向、观察与复核的要求。
