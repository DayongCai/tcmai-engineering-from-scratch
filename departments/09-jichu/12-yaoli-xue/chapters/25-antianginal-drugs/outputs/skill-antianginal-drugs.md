# Skill：抗心绞痛药——一张耗氧表、两次分流、三种类别关系

## 何时用

- 读到「某药是抗心绞痛常用药」，需要判断这句话站在耗氧表的哪一项
- 要解释「同一类钙通道阻断药，为什么一个使心率增快、一个使心率减慢」
- 遇到耐受性问题（连续给药效应减弱），需要把机制与给药间歇的道理分开说
- 遇到联合用药的讨论，需要判断是协同、相加还是相互抵消
- 有人拿「哪一类更好」来问，需要把讨论拉回环节与类别

## 核心判据（六问）

1. **改哪一端？** 降低耗氧，还是增加缺血区灌注。两端混淆，后面的判断全错。
2. **改哪一项？** 耗氧三项——心率、收缩力、心室壁张力。前负荷与后负荷都通过室壁张力起作用，别把两者混成一句「扩血管」。
3. **机制落点在哪？** 一氧化氮与环磷酸鸟苷通路（硝酸酯类）、受体竞争性拮抗（β 阻断药）、通道的状态依赖性与频率依赖性（钙通道阻断药）、能量代谢或离子流（其他类）。给不出落点的表述多半是套话。
4. **边界条件是什么？** 耐受性、反射性心率增快、受体上调与停药反跳、剂量增大后选择性减弱、同一酶系相关的相互作用。五条里至少问一条。
5. **组合落在哪个环节？** 环节不同才互补；同一环节重复没有增益；效应方向相反属相互抵消，这种抵消在治疗意图上可能有利，在不良反应层面则要另算。
6. **判断交给谁？** 由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南决定。

## 执行步骤

```text
1. 收口：把待判句子压成一句「性质或作用」，删掉药名与用途
2. 定端：耗氧一侧还是灌注一侧
3. 定项：心率 / 收缩力 / 心室壁张力（前负荷或后负荷）
4. 找落点：一氧化氮通路 / 受体竞争 / 通道状态 / 代谢与离子流
5. 查边界：耐受性、反射、受体上调、选择性随剂量减弱、相互作用
6. 判组合：协同 / 相加 / 抵消；是否为同类重复
7. 落观察：多出哪一栏、要不要记立位与卧位、要不要写明给药时点
8. 定去向：谁判断、依什么、如何留痕
```

## 硬约束

- **不写剂量、浓度、给药间隔、疗程与作用维持时长的量值。** 需要剂量时统一写「剂量与用法照底本」。
- **不作适应证判定，不作病情与预后判定，不作疗效断言与优越性断言，不作等级排名。**
- **引文逐字。** 标「教材·药理学·第25章·25.x.y」，核不到原文就不引；改写须标明是改写。
- **不写品名、厂商、剂型规格与价格。**
- **不把分类当结论。** 同一类别内部差异明显，不能据类别直接推断个体药物的用法与疗程。
- **不确定就写下来。** 标待核实，不用推测填空。

## 交付物

1. 一条定位链：端 → 项 → 机制落点
2. 一条边界条件：这条规律在什么情形下减弱或不成立
3. 若涉及两种药：一句类别关系判断（协同 / 相加 / 抵消）
4. 一栏观察补充：记录表上因此要多写什么
5. 一句边界句：本章只描述机制与类别关系，判断归属另行

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 药名当答案 | 说不清为什么用、什么时候不该用 | 回到第 2、3 问，写端与项 |
| 扩血管一句带过 | 分不出静脉为主还是动脉为主 | 分开写前负荷与后负荷两条路径 |
| 忽略反射性增快 | 解释不了净效应为何不如预期 | 补第 4 问，写明抵消与灌注时间 |
| 类别推个体 | 把「二氢吡啶类使心率增快」当成无条件结论 | 改写为「治疗剂量下较明显，剂量增大后选择性减弱」 |
| 组合当叠加 | 认为同类药合用更强 | 判断是否落在同一环节，同类重复缺少增益 |
| 把互补当更优 | 由机制互补直接推出联用更好 | 补一句：净效应取决于剂量比例、时程与个体状态 |

## 与相邻章节的接缝

- 第 22 章（作用于心血管系统离子通道的药物）：本章的通道状态依赖性、频率依赖性在那一章有更完整的电生理语言。
- 第 23 章（治疗慢性心功能不全的药物）：本章的负性肌力作用与心功能状态的关系，在那一章被展开为血流动力学代价。
- 第 24 章（抗高血压药）：钙通道阻断药与 β 阻断药在那一章以血压为落点，本章以耗氧为落点，同一药在两章的位置不同。
- 第 26 章（抗心律失常药）：本章的「反射性心率增快」在那一章变成节律异常的诱因之一；钙通道阻断药的心脏效应在两章都要讲，但判据不同。

## 边界

本 Skill 只处理「一条表述 → 耗氧表位置」的判定，不涉及剂量、适应证与临床决策。本章内容为教学材料，不构成用药建议；任何涉及个体的用药评估须由具备资质的人员依现行法律法规与规范作出。
