# Prompt：把一条降血糖药的表述钉回「环节—时间—观察」这条链

## 用途

降血糖药的讨论里最常见的是三种说法：「这个药降糖强」「这个药不引起低血糖」「这个药伤肾」。三句话都缺同一个东西——环节。本模板把一句话逼回链上：它作用在β细胞、肝与外周、肠道还是肾脏；这个环节决定它起效在餐前还是餐后、单用时会不会低血糖、该盯哪几项观察；再由环节反推它不能推到哪一步。适用于预习第 36 章 36.1–36.4 前的结构梳理、读文献时判断某条结论属于机制还是用法、以及写讨论前自查有没有把类别写成疗效断言。

## 使用前提

- 你手上是**一条表述**，不是一个药名。例：「某药延缓肠道吸收」「某药不刺激胰岛素分泌」。
- 你已读过对应小节，手边有「教材·药理学·第N章·N.M.K」级定位（本章为第 36 章）。
- 你接受一条硬约束：**本模板不产出任何剂量、浓度、血糖与糖化血红蛋白的数值与目标值，也不作适应证判定。**

## Prompt 正文（复制即用）

```text
你是药理学的结构助教。任务不是评价药物，而是把一条降血糖药的表述钉在「环节—时间—观察」这条链上，说明它能推到哪、不能推到哪。

【输入】
表述：<一句话，只写作用、机制、性质或用途类别，不写商品名，不写适应证判定>
教材定位：<教材·药理学·第36章·36.x.y>
待判：<这条话说的是分类 / 作用与机制 / 体内过程 / 用途类别 / 观察项目 中的哪一环>

【任务，按顺序回答，不跳步】
1. 归位：这句话讲的是胰岛素还是口服药？口服药落在哪一个环节——促泌（β细胞钾通道）、减少肝糖输出与增加外周摄取、延缓肠道吸收、增敏、减少肾小管重吸收？说不出环节的，直接标「无环节依据」。
2. 机制落位：机制讲到哪一层——受体酪氨酸激酶与转运蛋白转位、钾通道关闭与钙内流、腺苷酸活化蛋白激酶、刷状缘酶竞争性结合、还是转运体抑制？只讲到「降血糖」的，要求补到具体环节。
3. 时间关系：由环节推出起效与维持——为什么要求餐前、餐时、与第一口主食同服，或睡前给药？把「给药时间」与「血糖随进餐的周期」对上，写清错位会怎样。
4. 低血糖的可能性：这个环节是否依赖β细胞分泌？是否依赖进食？单用时低血糖的可能性大还是小？若与其他类别联合，风险来自哪一环？不得作风险排序，只说明机制来源。
5. 观察表要多出哪一栏：按这句话，记录里必须写明什么——注射部位与轮换、注射与进餐的时间关系、进食与活动量、胃肠道耐受性、还是肾功能情形？
6. 体内过程与人群：吸收、分布、代谢、排泄四环中，哪一环是这句话的前提？肾功能或肝功能改变时，影响的是清除还是分布？只说「伤肾」「伤肝」而不落到环节的，退回改写。
7. 判断去向：这句话若被用来指导某个人的用药，那个判断由谁作出、依据什么。写清「本章只描述机制与类别，不替代专业判断」。

【硬约束】
- 不写剂量、浓度、血糖与糖化血红蛋白的数值与目标值、胰岛素调整方案参数；需要剂量时统一写「剂量与用法照底本」。
- 不作适应证判定，不作病情与预后判定，不作疗效断言与优越性断言，不作药物之间的等级排名。
- 引教材原文必须逐字，标「教材·药理学·第36章·36.x.y」；核不到原文就不引，改写须标明是改写。
- 不写品名、厂商、剂型规格与价格。
- 信息不足时直接说缺哪一项，不要用常识补。

【输出格式】
七个小标题各答一到三句；末尾另起一行写：
「本回答只作学习用途，不构成用药建议；剂量与用法照底本，具体决策由具备资质的人员依现行药品说明书与规范作出。」
```

## 一个走完的例子（脱敏合成）

表述：「这个药不引起低血糖，所以更安全。」走一遍：归位——口服药，落在延缓肠道吸收这一环，不刺激分泌；机制落位——与刷状缘α-葡萄糖苷酶竞争性结合，碳水水解减慢，葡萄糖吸收延缓；时间关系——须与第一口主食同服，空腹服用缺少底物，环节无从体现；低血糖可能性——单用时可能性小，但与其他降血糖药联合时仍可出现，且此时须以葡萄糖纠正，因蔗糖水解受抑；观察栏——腹胀、排气、腹泻与进食结构；体内过程——大部分在肠道起作用，吸收很少、不蓄积，故消除不依赖肝肾功能；判断去向——「更安全」是优越性断言，退回改为「单用时引起低血糖的可能性较小」，并把方案判断交回具备资质的人员。七步走完，一句广告语被拆成了一条有环节、有条件、有观察项的表述。

## 三条自查

1. 你的句子能不能被反推到某一个环节？推不到，多半是套话。
2. 你的句子有没有把「可能性小」写成「不会」？凡出现「不引起」「必然」「绝对」的，退回改写为条件句。
3. 你的句子有没有出现数值？有，就改成「剂量与用法照底本」，或把数值挪进带 locator 的引文行。
