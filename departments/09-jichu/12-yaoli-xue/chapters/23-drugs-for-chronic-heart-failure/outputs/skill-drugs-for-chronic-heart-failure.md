# Skill：治疗慢性心功能不全的药物——一个中心环节、六类药、两个尺度

## 何时用

- 读到「某药强心 / 某药减轻淤血 / 某药延缓重构」，需要判断它落在哪个环节
- 要解释「为什么起手会降低收缩力的药反而是长期治疗的重要类别」
- 要解释「同为增强收缩力，为什么一个增加耗氧、一个不增加」
- 要解释「同一个系统的三类药为什么都有高钾风险，而干咳只出现在其中一类」
- 要解释「某药效应为什么几周才显现」
- 有人拿「哪一类更好」来问，需要把问题换成「哪个环节、哪个尺度」

## 核心判据（七问）

1. **哪一层重构？** 心肌细胞（肥大与表型改变）、间质（纤维化与顺应性）、细胞数量（凋亡使收缩单位减少）。
2. **哪个环节？** 收缩力、容量（前负荷）、后负荷、神经内分泌激活——四者对应六类药。
3. **哪个靶点？** 离子泵、膜受体、核受体、酶、收缩装置；靶点类型决定效应快慢（膜受体以秒至分钟计，核受体以小时至日计）。
4. **哪个尺度？** 短期血流动力学，还是长期重构进程；两者不可互换，也不可用一个评价另一个。
5. **什么代价？** 反射性心率增快、钠水潴留、交感激活、受体上调或下调——代价常与效应来自同一机制。
6. **有没有时程错位？** 短期不利而长期有利（β 阻断药）、短期有利而长期无益（正性肌力药改善指标不等同改善过程）。
7. **判断交给谁？** 由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南决定。

## 执行步骤

```text
1. 收口：把待判句子压成一句「作用或环节」，删掉药名与「首选」这类评价
2. 定层面：细胞 / 间质 / 细胞数量，三层里落一层
3. 定环节：收缩力 / 容量 / 后负荷 / 神经内分泌
4. 定靶点：泵、膜受体、核受体、酶、收缩装置
5. 分尺度：短期指标还是长期过程；写出两个尺度各自的依据
6. 查代价：代偿反应是什么，是否与效应同源
7. 落观察：心率血压 / 体重水肿 / 电解质肾功能 / 症状与耐量，四组里选
8. 定去向：谁判断、依什么、如何留痕
```

## 六类药的最小骨架

| 类别 | 环节 | 靶点 | 需注意的机制点 |
|---|---|---|---|
| 强心苷类 | 收缩力 | 钠钾泵 | 泵抑制→胞内钠升→钠钙交换增强；舒张期延长故耗氧不增；中毒诱因是低钾低镁高钙与肾功能减退 |
| 非苷类正性肌力 | 收缩力 | β1 受体、磷酸二酯酶 III、肌钙蛋白 C | 静脉短期支持；血流动力学效应不等于长期改善 |
| 利尿药 | 容量 | 不同管段的转运体 | 减轻淤血，代价是电解质紊乱 |
| 系统抑制药 | 神经内分泌 | 转化酶、AT1 受体、醛固酮受体 | 三个层面；共享高钾，干咳只见于影响缓激肽的一类 |
| β 受体阻断药 | 神经内分泌 | β1 受体 | 短期负性肌力、长期受体回升；不可骤停 |
| 血管扩张药与钙通道阻断药 | 前后负荷 | 一氧化氮通路、L 型钙通道 | 反射性心率增快、耐受、首剂现象、负性肌力 |

## 硬约束

- **不写剂量、浓度、滴度、效价、给药频次与疗程的量值。** 需要剂量时统一写「剂量与用法照底本」。
- **不作适应证判定，不作病情与预后判定，不作疗效断言与优越性断言，不作等级排名，不把分类写成处方顺序。**
- **两个尺度不混用。** 用短期指标评价长期目标，或用长期收益掩盖短期代价，都是本章最典型的表述错误。
- **类别不是概率。** 「可见高钾」不是「会发生高钾」，也不给发生率与严重程度分级。
- **引文逐字。** 标「教材·药理学·第23章·23.x.y」，核不到原文就不引；改写须标明是改写。

## 常见错误

- 把「增强收缩力」当成唯一治疗目标：漏掉重构与神经内分泌这两层。
- 用短期效应否定长期价值：β 阻断药的「先抑制、后恢复」正是反例。
- 把三类系统抑制药当成可随意叠加：相邻环节叠加不增加机制覆盖，风险却增加。
- 把核受体药物的慢起效当成「作用弱」：受体类型决定时程，与强度不是一回事。
