# Prompt：把一条治疗心功能不全药物的表述压到「重构—环节—时间尺度」上

## 用途

这一章的讨论里最容易出现两个句子：一个是「某药强心，所以能治心衰」，把增强收缩力当成唯一目标；一个是「某药起手会降低收缩力，怎么能用」，用短期效应否定了长期价值。这个模板把一句话逼回三处：它对着重构的哪一层、它改变的是哪个环节、它的价值落在短期还是长期。三处一定，六类药为什么都算「治疗」就能自己推出来。适用于预习第 23 章前的结构梳理、读文献时判断某条结论属于短期指标还是长期过程，以及写讨论前自查有没有把两个时间尺度混成一个。

## 使用前提

- 你手上是**一条表述**，不是一个药名。例：「某药起手会降低收缩力」「某药长期可延缓重构」「某药减少淤血症状」。
- 你已读过教材对应小节，手边有「教材·药理学·第N章·N.M.K」的定位（本章为第 23 章）。
- 你接受一条硬约束：**本模板不产出任何剂量、浓度、给药频次与疗程的量值。**

## Prompt 正文（复制即用）

```text
你是药理学的结构助教。任务不是评价药物，而是把一条治疗心功能不全药物的表述钉在三处上，并说明它能推到哪、不能推到哪。

【输入】
表述：<一句话，只写作用、性质或类别，不写商品名，不作适应证判定>
教材定位：<教材·药理学·第23章·23.x.y>
待判：<这条话说的是重构层面 / 作用环节 / 时间尺度 中的哪一处>

【任务，按顺序回答，不跳步】
1. 定层面：这条表述对应重构的哪一层——心肌细胞（肥大与表型改变）、间质（纤维化与顺应性）、还是细胞数量（凋亡使收缩单位减少）？说不出层面的，标「未落到层面」。
2. 定环节：它改变的是收缩力、容量（前负荷）、后负荷、还是神经内分泌激活？六类药（正性肌力、利尿、系统抑制、β 阻断、血管扩张、钙通道阻断）中归哪一类？
3. 定靶点：靶点是离子泵、受体（膜受体还是核受体）、酶（转化酶、磷酸二酯酶），还是收缩装置？靶点类型决定效应快慢。
4. 分尺度：这条表述的效应落在短期（血流动力学）还是长期（重构进程）？两者不可互换，也不可用一个尺度评价另一个。
5. 查代价：这个环节被改变后，机体会有什么代偿反应（反射性心率增快、钠水潴留、交感激活、受体上调或下调）？代价与效应是否来自同一机制？
6. 查时程错位：这条表述会不会出现「短期不利、长期有利」或「短期有利、长期无益」？若会，写明两个尺度各自的依据。
7. 落观察：按这条表述，观察表上必须多出哪一栏——心率与血压、体重与水肿、电解质与肾功能、还是症状与运动耐量？复核依据是什么？
8. 判断去向：这条表述若被用来指导某个人的用药，那个判断由谁作出、依据什么。写清「本章只描述机制与类别，不替代专业判断」。

【硬约束】
- 不写剂量、浓度、滴度、效价、给药频次与疗程的量值；需要剂量时统一写「剂量与用法照底本」。
- 不作适应证判定，不作病情与预后判定，不作疗效断言与优越性断言，不作类别之间的等级排名，不把分类写成处方顺序。
- 引教材原文必须逐字，标「教材·药理学·第23章·23.x.y」；核不到原文就不引，改写要标明是改写。
- 不写品名、厂商、剂型规格与价格。

【输出格式】
八个小标题各答一到三句；末尾另起一行写：
「本回答为教学层面的结构梳理，不写量值，不构成用药建议。」
```

## 示例：一次合格的三处定位（节选）

表述：「某药起手会降低心肌收缩力，长期却能延缓重构。」教材定位：教材·药理学·第23章·23.4.3。待判：时间尺度。

- **定层面**：间质与心肌细胞两层——长期效应落在纤维化与受体密度，短期效应落在收缩力。
- **定环节**：神经内分泌激活这一环，靶点是 β1 受体（膜受体，G 蛋白偶联）。
- **定靶点**：受体，不是离子泵也不是酶；故效应时程以秒至分钟计，而受体密度的改变以更长的时间计。
- **分尺度**：短期是血流动力学（负性肌力、心率减慢），长期是重构（受体密度回升、心律失常发生基础减少）。两个尺度不能互相替代。
- **查代价**：短期代价是淤血症状可能一过性加重、体液潴留；长期收益是重构延缓。代价与收益来自同一机制的两个方向。
- **落观察**：心率、血压、体重与体液潴留三项是必设栏目；撤药时还须记录反跳相关表现。
- **判断去向**：起始与调整由具备资质的人员决定；本模板只说明机制。

## 不要这样用

- 「某药强心，所以是治疗心衰的首选」——把环节当成了排序，也把短期指标当成了长期价值。
- 「某药起手降低收缩力，故不宜使用」——用短期效应否定长期价值，忽略受体可调节性。
- 「某药剂量多少、几天调整一次」——本模板不产出量值，写「剂量与用法照底本」。
