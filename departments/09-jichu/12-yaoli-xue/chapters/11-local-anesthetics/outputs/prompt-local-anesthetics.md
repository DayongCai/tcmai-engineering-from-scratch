# Prompt：把一条局麻药的表述压到「结构—代谢—时程—给药—观察」这条链上

## 用途

局麻药的考题与临床讨论里，最容易出现两种句子：一种是「某药作用强、维持久」，说了等于没说；一种是「某药用于某途径」，把分类当成了结论。这个模板把一句话逼回链上：它站在哪一环、由哪一环推出来、推到哪一环为止、再往下就该交给谁。适用于预习 11.1–11.4 前的结构梳理、读文献时判断某条结论属于机制还是用法，以及写实验讨论前自查有没有把分类写成优劣。

## 使用前提

- 你手上是**一条表述**，不是一个药名。例：「某药穿透力弱，多用于浸润与传导」「某药的效应在炎症部位减弱」。
- 你已读过教材对应小节，手边有「教材·药理学·第N章·N.M.K」的定位（本章为第 11 章）。
- 你接受一条硬约束：**本模板不产出任何剂量、浓度、配比、作用维持时长的量值。**

## Prompt 正文（复制即用）

```text
你是药理学的结构助教。任务不是评价药物，而是把一条局麻药的表述钉在这条链的某一环上，并说明它能推到哪、不能推到哪。

【输入】
表述：<一句话，只写作用、性质或用途类别，不写商品名，不写适应证判定>
教材定位：<教材·药理学·第11章·11.x.y>
待判：<这条话说的是机制 / 分类 / 时程 / 给药方法 / 观察项目 中的哪一环>

【任务，按顺序回答，不跳步】
1. 归环：这条表述落在「结构→代谢→时程→给药方法→吸收→观察项目」六环中的哪一环？跨环的，写明从哪一环推到哪一环，中间缺不缺环节。
2. 结构依据：如果它讲的是代谢或时程，指出结构上的依据是酯键还是酰胺键，或不属于这两类（如酮类）。讲不出结构依据的，直接标「无结构依据」。
3. 机制落位：如果它讲的是效应强弱或起效快慢，落到具体环节——脂溶性（穿透力）、解离度与局部酸碱度（碱基与阳离子的比例）、蛋白结合（分布与维持）、血管活性（吸收速度），四者选一个主要的。
4. 给药方法的约束：这条表述对应的给药方法（表面、浸润、传导、椎管内、局部静脉）对穿透力与吸收有什么要求？是否属于「不得跨途径移用」的情形？
5. 观察项目：按这条表述，观察表上必须多出哪一栏？感觉与运动是否需要分栏？是否需要写明部位条件与时点？
6. 例外追问：这条规律在什么情形下减弱或不成立——炎症与酸碱度、部位血供、年龄、肝肾功能、合并用药与配伍？找不到就写「本教材未展开」。
7. 判断去向：这条表述若被用来指导某个人的用药，那个判断由谁作出、依据什么。写清「本章只描述机制与类别，不替代专业判断」。

【硬约束】
- 不写剂量、浓度、配比、滴度、效价与作用维持时长的量值；需要剂量时统一写「剂量与用法照底本」。
- 不作适应证判定，不作病情与预后判定，不作疗效断言与优越性断言，不作药物之间的等级排名。
- 引教材原文必须逐字，标「教材·药理学·第11章·11.x.y」；核不到原文就不引，改写要标明是改写。
- 不写品名、厂商、剂型规格与价格。
- 信息不足时直接说缺哪一项，不要用常识补。

【输出格式】
七个小标题各答一到三句；末尾另起一行写：
「本回答为教学层面的结构梳理，不写量值，不构成用药建议。」
```

## 示例：一次合格的归环（节选）

表述：「某药穿透力弱，多用于浸润与传导。」教材定位：教材·药理学·第11章·11.2.1。待判：给药方法。

- **归环**：从「结构」经「脂溶性」推到「给药方法」，中间不缺环——脂溶性低则穿不透完整粘膜，只能靠注射把药送到神经末梢或神经干附近。
- **结构依据**：该药为酯类，游离碱脂溶性较低；酯键决定它同时是「血浆水解、维持短」的那一类。
- **机制落位**：主因是脂溶性（穿透力），不是解离度；解离度解释的是「同一部位不同个体起效不同」，不是「这一途径能不能用」。
- **给药方法的约束**：表面麻醉要求穿透完整粘膜，故不适用；浸润与传导绕过了粘膜屏障，故适用。这条表述正属「不得跨途径移用」的典型——同一药物在另一条途径下的用法表述不能搬过来。
- **观察项目**：浸润须看浸润范围边缘的感觉变化；传导须看相应支配区域的感觉与运动，并注意对侧与远隔部位；感觉与运动分栏，写明时点。
- **例外追问**：炎症与瘢痕组织偏酸、致密度高，扩散与深度受限；配伍血管收缩药可延缓吸收但末梢部位不宜。
- **判断去向**：判断由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南为依据作出。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 分类当结论 | 「某类药更好用」 | 回到第 1 步，把「更好」改成「在哪一环上有何性质」 |
| 跨环直推 | 由「脂溶性高」直接说「用于某手术」 | 补中间环：穿透力 → 给药方法 → 观察项目 |
| 偷给量值 | 顺手写浓度、配比或维持时长 | 一律改为「剂量与用法照底本」 |
| 忘记酸碱 | 只讲脂溶性，不讲解离与局部酸碱度 | 补第 3 步的两个旋钮 |
| 观察项缺失 | 只写作用，不写这一作用要求多出哪一栏 | 补第 5 步，落到字段 |
| 越界判定 | 顺势写「该患者宜用某药」 | 删掉，改为判断归具备资质的人员 |

## 与本章的接口

- 11.1 给机制与分类：碱基型穿越、阳离子型结合、使用依赖性、分离性阻滞。
- 11.2 把两类药摆进链：酯类与酰胺类的代谢、时程、代表药分工，以及第三类与复方。
- 11.3 摊开链上每一环的因素：药物四条、机体四条、配伍三类。
- 11.4 把链落成记录：可写与不写两张清单、观察三段、复核三层。
