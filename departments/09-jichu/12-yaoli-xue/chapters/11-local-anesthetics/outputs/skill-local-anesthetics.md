# Skill：局部麻醉药——一条链、四个旋钮、两张清单

## 何时用

- 读到「某药作用强 / 维持久 / 穿透好」，需要判断这句话站在链的哪一环
- 要解释「同一药物同一部位，为什么这次起效慢、阻滞浅」
- 遇到配伍问题（是否加血管收缩药、是否碱化），需要把效应定位在血管而非神经
- 要把临床观察整理成能复核的记录，却不确定该分几栏
- 有人拿「哪个局麻药更好」来问，需要把讨论拉回分类与类别

## 核心判据（六问）

1. **哪一环？** 结构（酯键 / 酰胺键 / 酮类）→ 代谢（血浆水解 / 肝微粒体酶）→ 时程（维持与蓄积）→ 给药方法（表面 / 浸润 / 传导 / 椎管内 / 局部静脉）→ 吸收（部位、面积、配伍）→ 观察项目。
2. **结构给了什么判据？** 见到酯键推定血浆水解，见到酰胺键推定依赖肝脏。给不出结构依据的表述，多半是套话。
3. **哪个旋钮？** 脂溶性（穿透力与维持）、解离度与局部酸碱度（碱基与阳离子的比例）、蛋白结合（分布与维持）、血管活性（吸收速度）。四选一为主，不要四个一起说。
4. **顺序是预期还是判据？** 感觉先于运动、中枢先兴奋后抑制，都是预期，用来安排观察；不能拿来下判断。
5. **观察表要多出哪一栏？** 这条表述要求记录写明什么——部位条件、时点、感觉与运动分栏、还是配伍类别。写不出，说明这条表述还没落地。
6. **判断交给谁？** 由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南决定。

## 执行步骤

```text
1. 收口：把待判句子压成一句「性质或作用」，删掉药名与用途
2. 归环：六环定位，跨环的写明中间环缺不缺
3. 找标志：酯键 / 酰胺键 / 酮类，给不出就标「无结构依据」
4. 定旋钮：脂溶性 / 解离度 / 蛋白结合 / 血管活性，选一个主要的
5. 查途径：这条表述对应哪条给药方法，是否属「不得跨途径移用」
6. 落观察：多出哪一栏、要不要分感觉与运动、要不要写时点
7. 找例外：炎症与酸碱度、部位血供、年龄、肝肾功能、配伍与相互作用
8. 定去向：谁判断、依什么、如何留痕
```

## 硬约束

- **不写剂量、浓度、配比、滴度、效价与维持时长的量值。** 需要剂量时统一写「剂量与用法照底本」。
- **不作适应证判定，不作病情与预后判定，不作疗效断言与优越性断言，不作等级排名。**
- **引文逐字。** 标「教材·药理学·第11章·11.x.y」，核不到原文就不引；改写须标明是改写。
- **不写品名、厂商、剂型规格与价格。**
- **跨途径不搬用法。** 同一药物在不同途径下的用法表述不同，跨途径移用是本类最典型的表述错误。
- **不确定就写下来。** 标待核实，不用推测填空。

## 交付物

1. 一条归环链：结构 → 代谢 → 时程 → 给药方法 → 吸收 → 观察项目
2. 一处旋钮定位：这条表述主要靠哪个药物因素成立
3. 一栏观察补充：记录表上因此要多写什么
4. 一句边界句：本章只描述机制与类别，判断归属另行

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 分类当结论 | 把「某类药」说成「某类更优」 | 改为性质描述，删掉取舍结论 |
| 跨环直推 | 由脂溶性直接跳到手术选择 | 补穿透力 → 给药方法 → 观察 |
| 偷给量值 | 浓度、配比、维持时长无来源 | 改为「剂量与用法照底本」 |
| 只讲脂溶性 | 解释不了炎症部位效应减弱 | 补解离度与局部酸碱度 |
| 配伍归错环节 | 以为配伍改变了通道亲和力 | 定位在血管：改的是吸收，不是结合 |
| 记录不分栏 | 感觉与运动混写，看不出顺序 | 分栏并写明时点 |

## 与相邻章节的接缝

- 第 12 章（全身麻醉药）：同样讲「阻断传导」，但靶点从通道升到网络，意识消失成为主要表现；本章的「意识清醒」正是两章的分界。
- 第 5–10 章（传出神经系统）：局麻药的靶点是通道蛋白本身，不是胆碱受体或肾上腺素受体，配伍里的 α 受体环节则是两章的接口。
- 第 4 章（影响药物效应的因素）：本章的「机体与部位因素」在那一章被展开为年龄、肝肾功能、遗传与合并用药的一般框架。
- 第 3 章（药动学）：本章的「吸收—分布—代谢—排泄」四个词在那一章有参数化的写法，本章只用到定性关系。

## 边界

本 Skill 只处理「一条表述 → 链上位置」的判定，不涉及剂量、适应证与临床决策。本章内容为教学材料，不构成用药建议；任何涉及个体的用药评估须由具备资质的人员依现行法律法规与规范作出。
