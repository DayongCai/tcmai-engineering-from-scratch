# Prompt：把一条抗寄生虫药的表述，按「虫种—阶段—靶点—部位」四问归位

## 用途

抗寄生虫药的讨论里，最容易出现的两种句子是「某药是首选」与「某药对某虫有效」。前者把分类当结论，后者把作用谱当万能。这个模板把一句话逼回去：它说的是哪个虫种的哪一段、落在什么靶点上、药物能不能到达那个部位、推到哪一分为止。适用于预习 46.1–46.4 前的结构梳理、读文献时判断某条结论属于机制还是用法，以及写讨论前自查有没有把「作用谱宽」写成「可随意替换」。

## 使用前提

- 你手上是**一条表述**，不是一个药名。例：「某药对童虫作用明显」「某药吸收少，作用局限于肠腔」。
- 你已读过教材对应小节，手边有「教材·药理学·第N章·N.M.K」的定位（本章为第 46 章）。
- 你接受一条硬约束：**本模板不产出任何剂量、疗程与间歇参数的量值。**

## Prompt 正文（复制即用）

```text
你是药理学的结构助教。任务不是评价药物，而是把一条抗寄生虫药的表述钉在「虫种—阶段—靶点—部位」这条链上，并说明它能推到哪、不能推到哪。

【输入】
表述：<一句话，只写作用、性质或用途类别，不写商品名，不写适应证判定>
教材定位：<教材·药理学·第46章·46.x.y>
待判：<这条话说的是虫种 / 生活史阶段 / 靶点 / 体内过程 / 观察 中的哪一环>

【任务，按顺序回答，不跳步】
1. 归环：这条表述落在「生活史阶段→靶点→选择性→体内过程→观察记录」五环中的哪一环？跨环的，写明中间缺不缺环节。
2. 虫种与阶段：它说的是哪一种虫的哪一段（红内期 / 红外期 / 配子体；肠腔滋养体 / 组织滋养体 / 包囊；童虫 / 成虫；微丝蚴 / 成虫；线虫 / 绦虫）？讲不出阶段的，标「阶段不明」。
3. 靶点落位：落到具体环节——血红素聚合、过氧桥裂解、二氢叶酸还原酶、二氢蝶酸合成酶、核糖体、微管蛋白、烟碱型乙酰胆碱受体、氨基丁酸受体、线粒体氧化磷酸化、表膜钙通透性、谷氨酸门控氯离子通道，选一个主要的。
4. 部位可达性：这条作用要求药物到哪个部位（肠腔 / 肠壁 / 肝 / 细胞内 / 细胞外液 / 脑脊液 / 淋巴系统 / 泌尿生殖道）？吸收与分布能否支持？吸收少的药为什么只能留在肠腔？
5. 作用谱的边界：若该药对多种虫有效，说明宽窄由什么决定（表膜结构、钙稳态、靶点分布），并明确「作用谱宽不等于可随意替换」。
6. 观察落点：按这条表述，观察重点应该放在药物本身的反应，还是虫体死亡后释放抗原引起的反应？两者如何区分？
7. 判断去向：这条表述若被用来指导某个人的用药，那个判断由谁作出、依据什么。写清「本章只描述机制与类别，不替代专业判断」。

【硬约束】
- 不写剂量、疗程、间歇参数、浓度、滴度、效价的量值；需要剂量时统一写「剂量与用法照底本」。
- 不作适应证判定，不作病情与预后判定，不作疗效断言与优越性断言，不作药物之间的等级排名。
- 引教材原文必须逐字，标「教材·药理学·第46章·46.x.y」；核不到原文就不引，改写须标明是改写。
- 不写品名、厂商、剂型规格与价格；不对任何地区或人群作评价性描述。
- 信息不足时直接说缺哪一项，不要用常识补。

【输出格式】
七个小标题各答一到三句；末尾另起一行写：
「本回答为教学层面的结构梳理，不写量值，不构成用药建议。」
```

## 示例：一次合格的归位（节选）

表述：「某药对童虫作用明显，可用于减少童虫发育为成虫。」教材定位：教材·药理学·第46章·46.3.1。待判：生活史阶段。

- **归环**：从「阶段」经「靶点」推到「用药时机」，中间不缺环——阶段决定靶点能不能被活化，靶点决定时机。
- **虫种与阶段**：血吸虫的童虫期，不是成虫期；同一药物的这一用途与抗疟用途基于同一化学基础。
- **靶点落位**：过氧桥在血红素铁催化下裂解，产生自由基损伤虫体——与抗疟同一机制。
- **部位可达性**：童虫在迁行阶段，尚未定居于门静脉系统，药物须在血中达到有效暴露。
- **作用谱的边界**：作用谱宽由虫体表膜结构与钙稳态机制决定，不由给药途径决定。
- **观察落点**：注意区分药物本身反应与虫体死亡后释放抗原引起的反应，后者的程度与虫体负荷相关。
- **判断去向**：判断由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南为依据作出。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 作用谱当万能 | 「某药对多种虫有效，可替换」 | 回到第 2、5 步，写明阶段与宽窄的由来 |
| 只讲靶点 | 说得出抑制什么酶，说不出对哪一段虫有效 | 补阶段这一环 |
| 忽略部位 | 用吸收少的药解释组织内作用 | 补第 4 步：吸收少则作用局限在肠腔 |
| 把再感染当耐药 | 症状再现即判断敏感性下降 | 先复核用药史与依从性，再考虑敏感性下降 |
| 偷给量值 | 顺手写疗程或间歇 | 一律改为「剂量与用法照底本」 |
| 越界判定 | 顺势写「该地区宜用某方案」 | 删掉，改为判断归具备资质的人员 |

## 与本章的接口

- 46.1 立主线：选择性来自虫体特有的酶系与结构，敏感性差异来自生活史阶段性；四节框架与耐药的共同逻辑。
- 46.2 用分布解释部位：甲硝唑前药活化兼有两类作用，依米丁与氯喹偏组织内，二氯尼特与巴龙霉素偏肠腔；局部用药不能清除深部虫体。
- 46.3 讲三个靶点：表膜钙通透性与皮层损伤（含免疫参与）、过氧桥自由基、谷氨酸门控氯离子通道；并区分药物本身反应与虫体死亡反应。
- 46.4 落到靶点最分散的一组：微管蛋白、烟碱型乙酰胆碱受体、去极化与超极化、线粒体氧化磷酸化；并说明吸收程度决定作用部位。
