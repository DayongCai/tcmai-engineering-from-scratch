# Skill：抗寄生虫药——先认阶段，再认靶点，最后认部位

## 何时用

- 读到「某药是首选 / 某药对某虫有效」，需要判断这句话说的是阶段、靶点还是用途
- 要解释「为什么同一虫种要用两种药」，而不是重复一句「规范要求联合」
- 遇到「症状缓解后又出现」，需要先分清是再感染、治疗失败还是敏感性下降
- 要说明为什么吸收少的药只能作用于肠腔，而肝内蓄积的药能作用于肝
- 要把用药观察整理成能复核的记录，尤其是虫体死亡反应的记录

## 核心判据（六问）

1. **哪一环？** 生活史阶段（红内期 / 红外期 / 配子体；肠腔 / 组织 / 包囊；童虫 / 成虫；微丝蚴 / 成虫）→ 靶点（血红素聚合、过氧桥、二氢叶酸还原酶、二氢蝶酸合成酶、核糖体、微管蛋白、烟碱型乙酰胆碱受体、氨基丁酸受体、线粒体氧化磷酸化、表膜钙通透性、氯离子通道）→ 选择性 → 体内过程 → 观察。
2. **哪一段虫？** 讲不出阶段的表述，多半是把作用谱当成了结论。
3. **靶点是什么？** 同一环节可以有多条化学路径（氯喹抑制血红素聚合，奎宁与血红素形成加合物），故结构仍要看。
4. **到得了吗？** 吸收少的药留在肠腔；肝内蓄积的药作用于肝；分布广的药覆盖多个部位。作用部位由体内过程决定，不由剂量决定。
5. **是药物反应还是虫体死亡反应？** 两者的观察时点与记录内容不同，混写会把免疫现象记成毒性。
6. **判断交给谁？** 由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南决定。

## 执行步骤

```text
1. 收口：把待判句子压成一句「性质或作用」，删掉药名与用途
2. 定虫种与阶段：五组阶段里选一组
3. 落靶点：十一类靶点里选一个主要的，说明为何是这个
4. 查部位：吸收与分布能否把药送到该部位
5. 定作用谱边界：宽窄由什么决定，是否可替换
6. 分反应类型：药物本身 / 虫体死亡后释放抗原
7. 区分失败原因：疗程未完成、再感染、敏感性下降，按先易后难的顺序复核
8. 定去向：谁判断、依什么、如何留痕
```

## 硬约束

- **不写剂量、疗程、间歇参数、浓度、滴度、效价的量值。** 需要剂量时统一写「剂量与用法照底本」。
- **不作适应证判定，不作病情与预后判定，不作疗效断言与优越性断言，不作等级排名。**
- **引文逐字。** 标「教材·药理学·第46章·46.x.y」，核不到原文就不引；改写须标明是改写。
- **作用谱宽不等于可替换。** 教材对吡喹酮的表述是明证：宽窄由表膜结构与钙稳态决定，不由给药途径决定。
- **不对人群与地区作评价。** 群体防治只写组织流程与记录要求，不把感染状态与生活水平、职业或习惯相联系。
- **不确定就写下来。** 标待核实，不用推测填空。

## 交付物

1. 一条归位链：虫种与阶段 → 靶点 → 选择性 → 体内过程 → 观察
2. 一处阶段定位：这条表述只在哪一段成立
3. 一条部位判断：吸收与分布支持不支持这条作用
4. 一句边界句：本章只描述机制与类别，判断归属另行

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 作用谱当万能 | 把「对多种虫有效」写成「可替换」 | 写明阶段与宽窄的由来 |
| 只讲靶点 | 推不出对哪一段虫有效 | 补生活史阶段 |
| 忽略部位 | 用吸收少的药解释组织内作用 | 回到体内过程这一环 |
| 把免疫现象记成毒性 | 虫体死亡反应被写成药物过敏 | 分两类记录，注明出现时间与虫体负荷 |
| 把再感染当耐药 | 一再现症状就判断敏感性下降 | 先复核疗程、依从性与暴露 |
| 偷给量值 | 疗程与间歇无来源 | 改为「剂量与用法照底本」 |
| 标签化叙述 | 把感染与地区、职业相联系 | 改为中性表述，只写可观察事实 |

## 与相邻章节的接缝

- 第 45 章（抗结核病药及抗麻风病药）：同样以「病原体—药物—宿主」三方权衡，但那一章的异质性在菌群代谢状态，本章的异质性在生活史阶段。
- 第 40–44 章（抗菌药各论）：耐药四条途径（降低摄取、增强外排、改变靶点、增强灭活）在本章同构；差别在虫体靶点更分散、作用谱更窄。
- 第 3 章（药动学）：本章的「吸收决定作用部位」在那一章有参数化写法，本章只用定性关系。
- 第 47 章（抗恶性肿瘤药）：两章都讲「对数级杀灭」式的比例清除与联合，但本章的联合依据是阶段互补，那一章是周期与时相。

## 边界

本 Skill 只处理「一条表述 → 阶段与靶点」的判定，不涉及剂量、适应证与临床决策。本章内容为教学材料，不构成用药建议；任何涉及个体的用药评估须由具备资质的人员依现行法律法规与规范作出，并以现行药品说明书为依据。
