# Prompt：把一条抗贫血药的表述，放回「原料—辅酶—信号」三个层次

## 用途

抗贫血药的讨论里，最常见的两种句子是「某药补血」与「某药效果好」。前一种把三个层次压成一个动词，后一种把有条件的效应说成无条件的结论。这个模板要求一句话先交代三件事：它补的是哪一层、这一层的失败会表现成什么、它依赖哪些条件才成立。适用于预习 32.1–32.4 时的结构梳理、读文献时判断某条结论属于机制还是疗效、以及写讨论前自查有没有把「补了有效」写成「缺的就是它」。

## 使用前提

- 你手上是**一条表述**，不是一个药名。例：「某药须在接触过敏原前使用」不属本章；「某药在体内转化为另一活性形式」「某药的吸收依赖内因子」属本章。
- 你已读过教材对应小节，手边有「教材·药理学·第N章·N.M.K」的定位（本章为第 32 章）。
- 你接受一条硬约束：**本模板不产出任何剂量、浓度、检验数值与疗程时长的量值。**

## Prompt 正文（复制即用）

```text
你是药理学的结构助教。任务不是评价药物，而是把一条抗贫血药的表述放回「层次—环节—依赖—观察」这条线，并说明它能推到哪、不能推到哪。

【输入】
表述：<一句话，只写作用、性质或用途类别，不写商品名，不写适应证判定>
教材定位：<教材·药理学·第32章·32.x.y>
待判：<这条话说的是机制 / 分类 / 体内过程 / 不良反应 / 观察项目 中的哪一项>

【任务，按顺序回答，不跳步】
1. 定层次：这条表述补的是底物（铁）、辅酶（叶酸与维生素B12），还是调节信号（生长因子）？跨层的，写明从哪一层推到哪一层，中间缺不缺环节。
2. 定环节：若讲铁，落到血红素合成、铁硫簇组装、铁调素调控、还是吸收形态与还原；若讲叶酸与B12，落到脱氧胸苷酸合成、嘌呤环合成、甲硫氨酸循环、还是甲基丙二酰辅酶A的转化；若讲生长因子，落到受体通路、分化程序、还是铁利用。
3. 找交叉与独立：这条表述涉及叶酸与B12的交叉点（甲硫氨酸循环）还是各自的独立反应？涉及交叉的，写明「改善可能同时是掩盖」。
4. 定依赖：这条表述成立需要哪些前提——原料供给、内因子与回肠吸收、肾功能与产生部位、给药途径？前提缺一项，结论就不成立。
5. 落观察：按这条表述，观察表上必须多出哪一栏——耐受性与粪便颜色、神经系统表现、血压与血栓相关表现、还是骨痛与发热？写不出，说明这条表述还没落地。
6. 找不同步：这条表述的效应是即刻出现还是需要经过祖细胞增殖与分化的时间？恢复次序是否与其它系统同步？
7. 定去向：这条表述若被用来指导某个人的用药，那个判断由谁作出、依据什么。写清「本章只描述机制与类别，不替代专业判断」。

【硬约束】
- 不写剂量、浓度、检验数值与参考区间、疗程时长的量值；需要剂量时统一写「剂量与用法照底本」。
- 不作适应证判定，不作病情与预后判定，不作疗效断言与优越性断言，不作药物之间的等级排名。
- 引教材原文必须逐字，标「教材·药理学·第32章·32.x.y」；核不到原文就不引，改写要标明是改写。
- 不写品名、厂商、剂型规格与价格。
- 信息不足时直接说缺哪一项，不要用常识补。

【输出格式】
七个小标题各答一到三句；末尾另起一行写：
「本回答为教学层面的结构梳理，不写量值，不构成用药建议。」
```

## 示例：一次合格的归层（节选）

表述：「某药口服后在胃肠道被蛋白水解酶降解，故须经皮下或静脉给药。」教材定位：教材·药理学·第32章·32.3.3。待判：体内过程。

- **定层次**：第三层——造血细胞生长因子的调节信号。给药途径属体内过程，不改变层次归属。
- **定环节**：受体通路。它经受体二聚化与 Janus 激酶—信号转导与转录激活因子传递信号，推动红系祖细胞存活与分化，并抑制铁调素以增加铁的动员。
- **找交叉与独立**：不涉及叶酸与B12的交叉点；但涉及「底物依赖」——信号到位而原料不到位，效应仍受限。
- **定依赖**：依赖铁、叶酸与维生素B12的供给，依赖靶细胞上相应受体的表达，依赖给药途径（蛋白质类口服被降解，故须注射）。
- **落观察**：血压与血栓相关表现、注射部位反应；时点按祖细胞分化的时序安排，不以短期变化作结论。
- **找不同步**：时序性是本类的共同特点——从给药到外周血象改变要经过增殖与分化，不可能即时生效；因此「给药后立即复查」在机制上就没有意义。
- **定去向**：判断由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南为依据作出。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 三层压一层 | 「某药补血」当成机制 | 回到第 1 步，指明补的是原料、辅酶还是信号 |
| 交叉当替代 | 认为叶酸与B12可以互相替代 | 补第 3 步：交叉点解释掩盖，独立点解释差异 |
| 有效即缺乏 | 由「补了有效」反推「缺的就是它」 | 删掉反推，改为「机制上可能被掩盖」 |
| 依赖漏写 | 只写作用，不写原料、内因子、肾功能等前提 | 补第 4 步 |
| 偷给量值 | 顺手写元素铁计量、给药频次、检验数值 | 一律改为「剂量与用法照底本」 |
| 观察项缺失 | 只写作用，不写这一作用要求多出哪一栏 | 补第 5 步，落到字段 |
| 越界判定 | 「该患者应补铁」 | 删掉，判断归具备资质的人员 |

## 与本章的接口

- 32.1 立第一层：铁是底物，吸收三变量（胃酸、还原物质、转运蛋白）也是相互作用的发生部位；排铁途径有限，故过载是累积问题。
- 32.2 立第二层：叶酸是载体，B12 是两种辅酶；交叉点在甲硫氨酸循环，独立点在胸苷酸合成与甲基丙二酰辅酶A 转化。
- 32.3 立第三层：调节而非替代；受体通路、分化程序、铁利用三步；产生部位在肾，故应用类别与肾功能相关。
- 32.4 落成口径：五类不写项、三条改写规则、五要素记录、三层复核与留痕分层。
