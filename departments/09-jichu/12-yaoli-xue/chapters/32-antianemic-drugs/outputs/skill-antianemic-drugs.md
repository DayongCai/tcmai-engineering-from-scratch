# Skill：抗贫血药——三个层次、一条交叉、三处不同步

## 何时用

- 读到「某药补血 / 改善贫血」，需要判断这句话说的是哪一层
- 要解释「补了铁为什么血象不动」「补了叶酸为什么神经系统问题反而明显」
- 遇到「口服能不能替代注射」的问题，需要把答案落到吸收机制而不是习惯
- 要把补充期间的观察整理成能复核的记录，却不确定该按什么分项
- 有人拿「哪一类抗贫血药更好」来问，需要把讨论拉回层次与条件

## 核心判据（七问）

1. **哪一层？** 底物（铁）／辅酶（叶酸与维生素B12）／调节信号（造血细胞生长因子）。层次不同，失败点与观察方向都不同。
2. **哪个环节？** 铁：血红素合成（底物一侧，限速环节之一）、铁硫簇组装、铁调素调控、吸收形态与还原。叶酸：脱氧胸苷酸合成、嘌呤环合成、甲硫氨酸循环。B12：两种辅酶形式。生长因子：受体通路、分化程序、铁利用。
3. **交叉还是独立？** 交叉点在甲硫氨酸循环（叶酸陷阱的来源）；独立点在胸苷酸合成与甲基丙二酰辅酶A 的转化。交叉解释掩盖，独立解释差异。
4. **依赖什么？** 原料供给、内因子与回肠吸收、肾功能与产生部位、给药途径。前提缺一项，结论就不成立。
5. **同步吗？** 铁参与多种含铁蛋白，恢复次序不同步；生长因子有时序性，血象改变不可能即时出现；叶酸与B12的缺乏表现不完全重合。
6. **观察多哪一栏？** 铁：耐受性、粪便颜色（须与出血所致黑便区分）、依从性。叶酸与B12：血液系统以外与神经系统表现，并留意互相掩盖。生长因子：血压、血栓相关表现、骨痛与发热。
7. **判断交给谁？** 由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南决定。

## 执行步骤

```text
1. 收口：把待判句子压成一句「作用或性质」，删掉药名与用途
2. 归层：原料 / 辅酶 / 信号；跨层的写明中间环缺不缺
3. 落环节：按第 2 问给出具体反应或通路，不写「促进造血」这类笼统说法
4. 查交叉：涉及叶酸与B12的，写明「改善可能同时是掩盖」
5. 列依赖：原料、内因子、肾功能、途径，逐项标注成立与否
6. 排时序：即刻、经过分化程序、还是长期累积；据此定时点
7. 落观察：按层次分设观察项，写不出就说明这条表述还没落地
8. 定去向：谁判断、依什么、如何留痕
```

## 硬约束

- **不写剂量、浓度、检验数值与参考区间、疗程时长的量值。** 需要剂量时统一写「剂量与用法照底本」。
- **不作适应证判定，不作病情与预后判定，不作疗效断言与优越性断言，不作等级排名。**
- **引文逐字。** 标「教材·药理学·第32章·32.x.y」，核不到原文就不引；改写须标明是改写。
- **不写品名、厂商、剂型规格与价格。**
- **「补了有效」不等于「缺的就是它」。** 机制上存在掩盖的可能，判断归具备资质的人员。
- **中药补血类不补结论。** 只写类别与配伍关系，不与铁剂或维生素类作优劣比较。
- **不确定就写下来。** 标待核实，不用推测填空。

## 交付物

1. 一条归层链：原料 → 辅酶 → 信号，指明本句落在哪一层
2. 一处环节定位：具体反应、通路或转运环节
3. 一份依赖清单：成立所需的前提，缺哪一项
4. 一栏观察补充：记录表上因此要多写什么
5. 一句边界句：本章只描述机制与类别，判断归属另行

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 三层压一层 | 「补血」当成机制 | 指明补的是原料、辅酶还是信号 |
| 交叉当替代 | 认为叶酸与B12可互相替代 | 交叉解释掩盖，独立解释差异 |
| 有效即缺乏 | 由改善反推病因 | 删掉反推，改为「机制上可能被掩盖」 |
| 途径当偏好 | 把「不可随意替换」说成习惯问题 | 落到内因子与回肠吸收 |
| 限速当唯一 | 把「反应不足」直接读成「剂量不够」 | 补铁调素、铁硫簇等其它环节 |
| 偷给量值 | 元素铁计量、给药频次、检验数值无来源 | 改为「剂量与用法照底本」 |
| 记录写评价 | 「耐受良好」代替所见 | 写恶心、上腹不适、粪便颜色这类可观察项 |

## 与相邻章节的接缝

- 第 33 章（作用于凝血系统的药物）：慢性失血所致铁丢失与止血药的作用方向相反，本章只写到「铁丢失增多」这一类别。
- 第 34 章（肾上腺皮质激素类药）：糖皮质激素对血液与造血的影响（红细胞与中性粒细胞增多、淋巴细胞减少）在那一章按受体机制重述。
- 第 3 章（药动学）：本章的吸收三变量、肠肝循环与首过效应，在那一章有参数化的写法，本章只用到定性关系。
- 第 4 章（影响药物效应的因素）：年龄、妊娠与肝肾功能对本章各层的影响，在那一章被展开为一般框架。
- 第 30 章（呼吸系统药）：长期缺氧与红系造血的关系属机制衔接，本章不展开。

## 边界

本 Skill 只处理「一条表述 → 层次与环节」的判定，不涉及剂量、适应证与临床决策。本章内容为教学材料，不构成用药建议；任何涉及个体的用药评估须由具备资质的人员依现行法律法规与规范作出。
