# Skill：有机磷酸酯类与复活药——一条因果、三条时间线、三层边界

## 何时用

- 读到「这类化合物越拖越重」，要说明重在哪里（酶的水解极慢、老化不可逆），而不是归因于剂量
- 要解释「为什么复活药用得越晚越没用」，以及为什么它与阿托品不能互相替代
- 遇到「代谢即解毒」的直觉判断，需要检查是否存在代谢活化
- 要判断某类表现能不能用「递质蓄积程度」推算（迟发周围神经病变、中间期表现、局部刺激都不能）
- 写观察记录时，需要把六个系统的观察项与五项要素对齐

## 核心判据（六问）

1. **哪一环？** 酶被抑制／酶被复活／受体被阻断／递质被蓄积。环错，联合用药的理由必错。
2. **键还在不在？** 磷酰化酶水解极慢，恢复靠新酶合成；老化后肟基失去攻击位点。这是复活药的窗口。
3. **毒物还在不在吸收？** 仍在吸收 → 需反复给药应对新形成的酶；已清除而酶已老化 → 余地有限。
4. **效应落在哪些系统？** M 组（腺体、眼、呼吸、循环）、N 组（神经肌肉先颤动后无力、神经节、髓质）、中枢组（先兴奋后抑制）。组合要能被机制解释。
5. **转化是活化还是去毒？** 氧化脱硫是活化，酯酶水解是去毒，谷胱甘肽结合促排；三者并存，净结果依化合物与个体而定。
6. **药怎么进去的？** 经皮（慢而持续）、吸入（快）、消化道（首过，可能活化）；复活药注射为主、原形经肾快排。吸收与效应不同步。

## 执行步骤

```text
1. 收口：把待判句子压成一句「性质或作用」，删掉药名与程度词
2. 归环：酶抑制 / 酶复活 / 受体阻断 / 递质蓄积
3. 摆时间线：代谢清除、复活窗口、器官恢复，三条分开写
4. 查老化：取代基结构决定老化快慢；支链烷基者快
5. 归系统：M / N / 中枢；不能归入者标「需另行解释」
6. 查转化：活化与去毒是否并存；「转化 = 失活」是否成立
7. 落观察：六层项目 + 五项要素 + 相对时点表述
8. 定边界：机制写足，救治参数与剂量不写，判断归具备资质的人员
```

## 硬约束

- **不写剂量、浓度、接触量估算、观察间隔、疗程。** 需要剂量时统一写「剂量与用法照底本」。
- **不写救治参数。** 洗胃、给药顺序、拮抗方案均不进入正文；教材只到类别与系统受累。
- **不作诊断、不作病情与预后判定、不作疗效与优劣断言、不作人群标签化。**
- **引文逐字。** 标「教材·药理学·第7章 + 三级小节号」，核不到原文就不引。
- **顺序是倾向。** 「腺体最早、肌束颤动稍晚、循环呼吸在中后期」受接触途径与化合物性质影响，不作分期判据。
- **不写品名、厂商、规格与价格。**

## 交付物

1. 一条因果链：磷酰化 → 递质蓄积 → 受体激动 → 器官效应
2. 一张时间表：代谢清除、老化窗口、器官恢复三条线
3. 一份系统分组：M / N / 中枢各自的可观察项
4. 一句转化判定：这条通路在活化还是在去毒
5. 一句边界句：机制与类别写足，救治参数与剂量不写

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 把「不可逆」读成「永远好不了」 | 机制被读成临床判决 | 回到酶分子层面：恢复靠新酶合成 |
| 认为复活药晚给也一样 | 忽略老化这条硬边界 | 补「老化后肟基失去攻击位点」 |
| 把代谢一律当解毒 | 漏掉氧化脱硫的活化 | 写「转化不等于失活」 |
| 用递质蓄积程度推算迟发神经病变 | 机制错配，结论无依据 | 归入「不能由受体直接解释」的三类 |
| 记录只写「较重」「好转」 | 事实与判断混写，无法复核 | 改为描述性词语并注明时点 |
| 把接触量写进观察记录 | 估算需采样检测，超出职责 | 只写途径类别与接触情形 |

## 边界

本 Skill 只处理「一句表述 → 因果环 → 时间条件 → 可观察项」的判定，不涉及识别、分级与救治。本章内容为教学材料，不构成用药建议；任何涉及个体的评估与处置，须由具备资质的人员依现行法律法规与规范、以现行药品说明书为依据作出。
