# Prompt：有机磷酸酯类与复活药的「时间窗」判定器

## 用途

给一段关于有机磷酸酯类或胆碱酯酶复活药的表述，判定三件事：它落在因果链的哪一环（键的生成、键的脱落、还是受体层面的阻断）；它成立需要什么时间条件；它能不能被观察到，以及观察该记什么。

三种场合最常用。其一，备课时核对「为什么越拖越重」——答案在磷酰化酶的水解极慢与老化不可逆，而不在剂量。其二，讨论联合用药时区分环节——毒物作用于酶、复活药也作用于酶但方向相反、阿托品作用于受体，三者的覆盖范围不同，不能互相替代。其三，写观察记录时确定分层——六个系统对应两类受体加中枢，分层之后组合才有意义。

## 模板

```text
【待判表述】<一句话，去掉药名与情绪词>

1. 落在哪一环？
   酶（抑制）/ 酶（复活）/ 受体（阻断）/ 递质（释放与蓄积）
   → 环不对，后面对「为什么联合使用」的解释一定错位

2. 时间条件是什么？
   键还在不在？是否已老化？毒物是否仍在吸收？
   → 三条时间线要分开写：代谢清除的时间、复活窗口的时间、器官恢复的时间

3. 效应落在哪些系统？
   M 组：腺体 / 眼 / 呼吸 / 循环
   N 组：神经肌肉（先颤动后无力）/ 自主神经节 / 肾上腺髓质
   中枢组：先兴奋后抑制
   → 组合是否符合机制？不符合的，标「需另行解释」

4. 是否属于不能用受体解释的三类？
   迟发性周围神经病变 / 中间期表现 / 局部刺激
   → 这三类不得用「递质蓄积程度」去推算

5. 体内过程支持这个说法吗？
   经皮（慢而持续）/ 吸入（快）/ 消化道（首过，可能活化）
   复活药：注射为主，原形经肾快排
   → 吸收与效应不同步，记录必须写接触途径与两个时点

6. 观察补什么？
   六层项目 + 五项要素（时点、项目、表现类别、判断依据、记录者与复核者）
   → 时点写成相对位置，不写「后来」「之后」

7. 边界句
   只写机制与类别，不写救治参数与剂量；剂量与用法照底本；
   不作诊断与预后判定，不构成用药建议。
```

## 用法要点

- **「不可逆」不是临床判决。** 它指酶分子层面的转归；效应消退取决于新酶合成与器官储备。把这三个字读成「永远好不了」，是把机制读成了结论。
- **「转化」不等于「失活」。** 硫代磷酸酯需要氧化脱硫才活化，部分代谢物仍保留抑制能力；同一条通路可能既在制造活性物质，也在销毁它。
- **顺序是倾向，不是分期。** 腺体与瞳孔早、肌束颤动稍晚、循环呼吸在中后期成为主要矛盾——教材在每处都加了「受接触途径与化合物性质影响」的限定。
- **不写量值。** 剂量、浓度、接触量估算、观察间隔一律不填；接触量估算需采样与检测，属专业机构职责。

## 输出示例（骨架）

```text
待判：这类化合物中毒时腺体分泌增多出现得最早
环：酶（抑制）→ 递质蓄积 → M 受体
时间：键已生成、尚未老化；毒物可能仍在经皮吸收
系统：M 组（腺体），可伴眼与循环；N 组稍后
不可用受体解释者：暂不涉及
体内过程：经皮吸收起始缓慢而持续，表现滞后于接触时点
观察：腺体分泌（相对用药前）、瞳孔（同光线双侧对比）、心率、呼吸频率与节律；写明接触时点与首次观察时点
边界：写「较前增多」，不写「中毒程度」；剂量与用法照底本
```

## 不做什么

不判定某个人是否中毒、不给出救治顺序与剂量、不比较药物优劣、不推算接触量。识别、分级与处置由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南为依据作出。
