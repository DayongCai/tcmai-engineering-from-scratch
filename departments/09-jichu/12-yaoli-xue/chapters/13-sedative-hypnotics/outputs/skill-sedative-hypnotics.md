# Skill：镇静催眠药——一个剂量谱、两类别位调节、四个层面

## 何时用

- 读到「某药镇静 / 催眠 / 抗焦虑」，需要判断它落在剂量谱的哪一档
- 要解释「同一种受体，为什么两类药的安全范围不一样」
- 遇到「睡得更久但白天更困」这类主诉，需要把时长与结构分开
- 要在抗组胺药、褪黑素受体激动药、食欲素受体拮抗药之间作机制对照
- 有人问「能不能自己减半」，需要把问题放回反跳与依赖的观察，而不是给方案

## 核心判据（六问）

1. **哪一档？** 镇静、催眠、抗惊厥、麻醉、呼吸抑制——同一机制在不同剂量下的展开；档间无锐利分界，不给分界值。
2. **哪个位点、哪种调节？** A 型 γ-氨基丁酸受体的递质位点 / 苯二氮䓬位点（α 与 γ 交界）/ 通道本身；加开放频率（苯二氮䓬类）、延长开放时间（巴比妥类）、高浓度可不依赖递质（巴比妥类）。
3. **哪个层面？** 抑制性递质、昼夜节律（MT1/MT2）、觉醒驱动（OX1/OX2）、觉醒维持（组胺 H1）。层面决定作用谱宽窄。
4. **哪一段时程？** 起效看脂溶性与吸收，维持看代谢途径与活性代谢物，次日残留看消除快慢。
5. **作用还是用途？** 作用是可观察的生理效应，用途是某情形下的安排；两者混写就会滑向适应证判断。
6. **判断交给谁？** 由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南决定。

## 执行步骤

```text
1. 收口：把待判句子压成一句「作用或性质」，删掉药名与用途
2. 定档：剂量谱五档定位，检查有没有把两档说成一档
3. 定位点：递质位点 / 苯二氮䓬位点 / 通道本身；加频率还是加时长
4. 定层面：抑制性递质 / 节律 / 觉醒驱动 / 组胺
5. 定时程：吸收与脂溶性 / 代谢与活性产物 / 消除与次日残留
6. 拆作用与用途：把「可观察的效应」与「某情形的安排」分成两句
7. 找风险：呼吸抑制、共济失调、顺行性遗忘、反常反应、复杂睡眠行为、耐受与反跳
8. 落观察：入睡、夜醒、次日清醒、步态、异常行为；判断归具备资质的人员
```

## 硬约束

- **不写剂量、浓度、滴度、效价与维持时长的量值。** 需要剂量时统一写「剂量与用法照底本」——本章底本带剂量表，课程层一律不复述。
- **不作适应证判定，不作病情与预后判定，不作疗效断言与优越性断言，不作等级排名。**
- **引文逐字。** 标「教材·药理学·第13章·13.x.y」，核不到原文就不引；改写须标明是改写。
- **不写品名、厂商、剂型规格与价格；不写血药浓度监测的数值与参考区间。**
- **不标签化。** 依赖写成「可观察、可记录、可处理的状态」，不写贬义称谓，不作人群归类。
- **机制讲透，做法不写。** 耐受与依赖的机制可以写；减量、停药、替代的安排不写。

## 交付物

1. 一处档位定位：这条表述在第几档，有没有跨档混写
2. 一句位点—调节：加频率还是加时长，落在哪个位点
3. 一处层面判断：作用谱为什么宽或窄
4. 一栏观察补充：记录表上因此要多写什么
5. 一句边界句：本章只描述机制与类别，判断归属另行

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 两分法 | 镇静药与催眠药当两类 | 写成同一作用的两个档位 |
| 一个位点 | 停在「同一受体」 | 补位点与调节方式 |
| 层面混同 | 抗组胺药被当成「同类安眠药」 | 补四个层面的区别 |
| 时长当质量 | 只记睡眠时长 | 加记夜醒与次日清醒 |
| 抄剂量表 | 数值无来源、随版本过期 | 改为「剂量与用法照底本」 |
| 标签化 | 「这类人容易依赖」 | 改为观察项与时长记录 |
| 自行插值 | 由「剂量谱连续」推出「可减半」 | 改为判断归具备资质的人员 |

## 与相邻章节的接缝

- 第 12 章（全身麻醉药）：苯二氮䓬类与巴比妥类在复合麻醉中承担镇静成分，本章的别位调节机制正是那一章「为什么可以减量」的解释。
- 第 15 章（抗精神失常药）：同样经单胺与谷氨酸系统，但靶点层次与观察项目不同，本章的「层面决定作用谱」在那里可复用。
- 第 14 章（抗癫痫药）：巴比妥类与苯二氮䓬类在两章都出现，本章讲剂量谱，那一章讲发作类型与长期预防。
- 第 4 章（影响药物效应的因素）：本章的老年、肝功能、合并用药三条，在那一章有一般框架。

## 边界

本 Skill 只处理「一条表述 → 档位与层面的定位」，不涉及剂量、适应证与临床决策。本章内容为教学材料，不构成用药建议；任何涉及个体的用药评估须由具备资质的人员依现行法律法规与规范作出。
