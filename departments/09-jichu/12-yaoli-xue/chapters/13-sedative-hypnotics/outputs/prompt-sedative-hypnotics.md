# Prompt：把一条镇静催眠药的表述拆成「档位—位点—层面—时程—观察」

## 用途

这一章最容易出现的三句错话是：「镇静药和催眠药是两类」「某药只催眠、没有别的作用」「某药比另一类更安全」。三句话的毛病是同一个：把档位、位点与层面压成了一个形容词。这个模板把一句表述拆回四层，再落到观察字段上。适用于预习 13.1–13.4 前的结构梳理、读睡眠相关文献时判断结论落在哪一层，以及写讨论前自查有没有把「剂量谱连续」读成「可以自行插值」。

## 使用前提

- 你手上是**一条表述**，不是一个药名。例：「某药起效快、次日残留少见」「某药的困倦是疗效也是不良反应」。
- 你已读过教材对应小节，手边有「教材·药理学·第N章·N.M.K」的定位（本章为第 13 章）。
- 你接受一条硬约束：**本模板不产出任何剂量、浓度与作用维持时长的量值**——本章底本虽带剂量表，课程层一律写「剂量与用法照底本」。

## Prompt 正文（复制即用）

```text
你是药理学的结构助教。任务不是评价安眠药，而是把一条表述拆成档位、位点、层面与时程，并指出它推到哪一环为止。

【输入】
表述：<一句话，只写作用或性质，不写商品名，不写适应证判定>
教材定位：<教材·药理学·第13章·13.x.y>
待判：<这条话说的是档位 / 受体位点 / 靶点层面 / 体内过程 / 观察项目 中的哪一项>

【任务，按顺序回答，不跳步】
1. 档位归位：这条表述落在剂量谱的哪一档——镇静、催眠、抗惊厥、麻醉，还是呼吸抑制？是不是把两个档位说成了一件事？档位之间没有锐利分界，说明这一点，不要给出分界值。
2. 位点定位：它作用于 A 型 γ-氨基丁酸受体的哪个位置——递质位点、苯二氮䓬位点（α 与 γ 交界），还是不依赖递质的通道本身？调节方式是加开放频率、延长开放时间，还是两者兼有？
3. 层面判断：它属于抑制性递质、昼夜节律、觉醒驱动、觉醒维持（组胺）四个层面中的哪一个？不同层面的作用是「窄」还是「宽」，靠什么决定？
4. 时程拆解：起效看脂溶性与吸收、维持看代谢途径与活性代谢物、次日残留看消除快慢与剂量。指出这条表述的时程由哪一段决定。
5. 结构与用途分离：这条表述是在说作用（可观察的生理效应），还是在说用途（某情形下的安排）？若混在一起，拆开重写。
6. 风险同源：这条作用在哪一步变成不良反应——呼吸抑制、共济失调与跌倒、顺行性遗忘、反常反应、复杂睡眠行为、耐受与反跳？指出是哪一类。
7. 观察项目：按这条表述，观察表上必须多出哪一栏（入睡情况、夜间觉醒、次日清醒程度、步态与平衡、有无复杂睡眠行为）？记录要不要分时段？
8. 判断去向：这条表述若被用来指导某个人的用药，那个判断由谁作出、依据什么。写清「本章只描述机制与类别，不替代专业判断」。

【硬约束】
- 不写剂量、浓度、滴度、效价与作用维持时长的量值；需要剂量时统一写「剂量与用法照底本」。
- 不作适应证判定，不作病情与预后判定，不作疗效断言与优越性断言，不作药物之间的等级排名。
- 引教材原文必须逐字，标「教材·药理学·第13章·13.x.y」；核不到原文就不引，改写要标明是改写。
- 不写品名、厂商、剂型规格与价格；不写血药浓度监测的具体数值与参考区间。
- 不对用药人群作标签化表述；依赖写成「可观察、可记录、可处理的状态」。
- 信息不足时直接说缺哪一项，不要用常识补。

【输出格式】
八个小标题各答一到三句；末尾另起一行写：
「本回答为教学层面的结构梳理，不写量值，不构成用药建议。」
```

## 示例：一次合格的拆解（节选）

表述：「某药起效快、次日残留少见，但肝功能不好的人要当心。」教材定位：教材·药理学·第13章·13.4.3。待判：体内过程。

- **档位归位**：落在催眠这一档；这条表述没有涉及抗惊厥与麻醉，不要顺手外推。
- **位点定位**：作用于苯二氮䓬位点、偏 α1 亚基，加开放频率；故镇静催眠明显而抗焦虑与肌松弱。
- **层面判断**：抑制性递质层面，作用谱偏窄——这是它「只管入睡」的原因，也是它不带来广泛皮质抑制的原因。
- **时程拆解**：起效看吸收快、首过明显；维持看消除快（经肝细胞色素 P450 同工酶代谢）；次日残留少见来自消除快，不是来自剂量小。
- **结构与用途分离**：「起效快」是作用层面的性质，「用于入睡困难」是用途层面的安排，两者不能互换。
- **风险同源**：肝功能减退者清除减慢，次日残留与嗜睡的表现会回来；另一类需要盯的是复杂睡眠行为，当事人事后不能回忆，只能靠他人观察。
- **观察项目**：入睡所需时段、夜间觉醒与再次入睡、晨起清醒程度与日间困倦、步态与平衡、有无异常行为。
- **判断去向**：判断由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南为依据作出。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 两分法 | 把镇静与催眠当成两类药 | 回到第 1 步，写成同一作用的两个档位 |
| 一个位点 | 「都作用于同一个受体」就停住 | 补第 2 步：位点不同、调节方式不同 |
| 层面混同 | 把抗组胺药的困倦说成「同类药」 | 补第 3 步的四个层面 |
| 时程归错 | 把次日残留归因于剂量大 | 按第 4 步查消除途径 |
| 疗效外推 | 由「起效快」推出「适合所有人」 | 删掉，改为性质描述 |
| 偷给剂量 | 顺手抄剂量表 | 一律改为「剂量与用法照底本」 |
| 标签化 | 「这类人容易依赖」 | 改为「用药时长与个体条件相关，须观察与记录」 |

## 与本章的接口

- 13.1 给总图：剂量谱五档、A 型受体的亚基与位点、正向与反向别位调节。
- 13.2 给频率型：五条作用与亚型的对应、代谢途径与活性代谢物、氟马西尼的时程问题。
- 13.3 给时长型：结构决定脂溶性、剂量曲线更陡、酶诱导范围与反跳。
- 13.4 给四个层面：其他类的靶点差别如何变成观察项目的差别。
