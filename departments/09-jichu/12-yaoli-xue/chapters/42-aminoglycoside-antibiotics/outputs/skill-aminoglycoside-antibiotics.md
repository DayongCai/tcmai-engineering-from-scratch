# Skill：氨基糖苷类——三步转运、三处蓄积、三个窗口

## 何时用

- 读到「某药对厌氧菌无效 / 对肠球菌单用不够 / 与细胞壁活性药有协同」，需要判断卡在哪一步转运
- 要解释「为什么换一个耐酶的品种有用、换另一个没用」
- 遇到耳毒性、肾毒性、神经肌肉阻滞并列的段落，需要把它们收成同一个机制下的三种表现
- 要设计观察表，却不确定「什么时候看什么」
- 有人问「这类药要不要监测」，需要回答「要监测」而不给数值

## 核心判据（六问）

1. **结构给了什么？** 碱性化合物 → 带正电 → 水溶性强、脂溶性低 → 口服吸收极少、注射给药、分布限于细胞外液、原形肾排泄。四个临床事实都是同一个性质的后果。
2. **卡在第几步？** 静电吸附（不耗能）、能量依赖转运（靠呼吸链与膜电位）、胞内蓄积（正反馈）。厌氧菌缺驱动、链球菌与肠球菌通透性低、联合细胞壁活性药可降低门槛——三个现象，一个环节。
3. **时相是哪一边？** 静止期杀菌药，与繁殖期杀菌药互补；效应与体液中达到的水平相关，后效应较长，有首次接触效应。
4. **耐药断在哪一路？** 修饰酶改药物、靶位改变改靶子、摄取减少改通路。对策分别是结构改造、换靶位类别、提高局部水平或联合。
5. **毒性落在哪一处？** 内耳毛细胞、肾近曲小管、神经肌肉接头。前两处同源（线粒体核糖体受抑、溶酶体磷脂沉积），第三处另一条链（钙—乙酰胆碱—终板电位）。
6. **窗口放在哪一段？** 耳在疗程中后段，肾贯穿疗程，神经肌肉阻滞在给药后短时间内。窗口由蓄积速度与机制决定，不由习惯决定。

## 执行步骤

```text
1. 收口：把待判句子压成一句「性质、谱的类别或毒性类别」
2. 定性质：极性 → 给药方式与分布，先把结构后果说全
3. 找卡点：吸附 / 驱动 / 通透性，三选一
4. 画边界：需氧革兰阴性杆菌写到「是否覆盖铜绿假单胞菌、结核分枝杆菌」
5. 定时相：静止期、浓度依赖、长后效应、首次接触效应
6. 走三路：修饰酶 / 靶位 / 摄取，各配一条对策
7. 落毒性：耳、肾、接头，先写同源再写差别
8. 定窗口：中后段 / 贯穿 / 短时，说明理由
```

## 硬约束

- **不写剂量、浓度、配比、疗程与血浆药物水平的数值与判定区间。** 需要剂量时统一写「剂量与用法照底本」。
- **不作适应证判定，不作病情与预后判定，不作疗效断言与优越性断言，不作品种之间的等级排名。**
- **引文逐字。** 标「教材·药理学·第42章·42.x.y」，核不到原文就不引；改写须标明是改写。
- **不写品名、厂商、剂型规格与价格。**
- **「需要监测」可以写，数值不写。** 机制的蓄积可以说透，操作层面的区间归说明书与具备资质的人员。
- **不确定就写下来。** 标待核实，不用推测填空。

## 交付物

1. 一条六环链：结构 → 转运 → 谱 → 耐药 → 毒性 → 窗口
2. 一处卡点定位：吸附、驱动还是通透性
3. 一句耐药判断：三路之一，并配对策
4. 三个窗口：耳、肾、接头各在什么时候看
5. 一句边界句：本章只描述机制与类别，判断归属另行

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 把「进不去」说成「靶点不同」 | 误以为厌氧菌另有核糖体 | 回到转运：驱动缺失，靶点仍在 |
| 三处毒性并列 | 看不出同源，窗口也跟着乱 | 先写同源机制，再写部位与进展速度 |
| 协同当联用推荐 | 由机制协同推出方案 | 改为「时相互补，方案另定」 |
| 耐药三路混说 | 对策也就对不上 | 三路分写，各配一条对策 |
| 窗口错位 | 只在首次给药后查耳毒性 | 改到疗程中后段；肾贯穿疗程 |
| 监测写成数值 | 越界且不可复核 | 只写「需要监测」与判定归属 |

## 与相邻章节的接缝

- 第 40 章（β-内酰胺类）：细胞壁合成受阻使本类更易进入菌体，是协同的机制基础；两类不宜同瓶混合，属操作层面的限制。
- 第 41 章（大环内酯类等）：同样作用于核糖体但亚基不同，故不构成位点竞争；两者都影响神经肌肉传递，属不良反应叠加。
- 第 43 章（四环素类与氯霉素类）：同样作用于三十S亚基的是四环素类，但转运方式不同（不依赖呼吸链），可作对照。
- 第 38 章（抗菌药物概论）：本章的三条耐药通路在那章是总则，本章是它最完整的一次实例化。

## 边界

本 Skill 只处理「一条表述 → 六环位置」的判定，不涉及剂量、适应证与临床决策。本章内容为教学材料，不构成用药建议；任何涉及个体的用药评估须由具备资质的人员依现行法律法规与规范作出。
