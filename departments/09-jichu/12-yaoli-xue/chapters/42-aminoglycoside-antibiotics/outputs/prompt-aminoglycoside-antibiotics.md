# Prompt：把一条氨基糖苷类的表述，沿「结构—转运—谱—耐药—毒性—窗口」走一遍

## 用途

这一章的表述最容易两处走偏。一处是把「对厌氧菌无效」说成「靶点不对」，其实是进不去；一处是把「耳毒性、肾毒性、神经肌肉阻滞」并列成三件事，其实它们共用同一个机制，只是部位与时间不同。这个模板要求一条表述必须走完整条链：结构给出什么性质、转运卡在哪一步、谱因此到哪为止、耐药断在哪一环、毒性落在哪个部位、观察窗口因此放在什么时候。适用于预习 42.1–42.3、解释「为什么必须联合」、以及设计观察表时确定「什么时候看什么」。

## 使用前提

- 你手上是**一条表述**，不是一个药名。例：「某药对肠球菌单用不够」「某药与细胞壁活性药合用有协同」「某药耳毒性明显」。
- 你已读过教材对应小节，手边有「教材·药理学·第N章·N.M.K」的定位（本章为第 42 章）。
- 你接受一条硬约束：**本模板不产出任何剂量、浓度、配比、疗程与监测数值。**

## Prompt 正文（复制即用）

```text
你是药理学的结构助教。任务不是评价药物，而是把一条氨基糖苷类的表述沿「结构—转运—谱—耐药—毒性—窗口」走一遍，并说明每一环能推到哪、不能推到哪。

【输入】
表述：<一句话，只写性质、谱的类别、毒性类别或配伍关系，不写商品名，不写适应证判定>
教材定位：<教材·药理学·第42章·42.x.y>
待判：<这条话说的是 结构 / 转运 / 谱 / 耐药 / 毒性 / 观察窗口 中的哪一环>

【任务，按顺序回答，不跳步】
1. 结构给了什么：分子是碱性化合物，多个氨基解离带正电，故水溶性强、脂溶性低。由此直接推出给药方式与分布范围，不要跳过这一步。
2. 转运卡在哪：三步是静电吸附、能量依赖的跨膜转运、胞内蓄积。指出这条表述卡在哪一步——是吸附不足、驱动不足（厌氧菌），还是膜通透性低（链球菌与肠球菌）。
3. 谱的边界：阳性范围写到「需氧革兰阴性杆菌」这一层，并写明例外（是否覆盖铜绿假单胞菌、是否覆盖结核分枝杆菌）；阴性范围同样写出。
4. 时相与药效学：本类属静止期杀菌药，与繁殖期杀菌药时相互补；效应与体液中达到的水平相关、后效应较长、有首次接触效应。指出这条表述属于哪一条。
5. 耐药定位：走三问——修饰酶改药物、靶位改变改靶子、摄取减少改通路。指明这条表述对应哪一条，以及对策是什么（结构改造 / 换靶位类别 / 提高局部水平或联合）。
6. 毒性落位：耳（内耳毛细胞）、肾（近曲小管）、神经肌肉接头（钙—乙酰胆碱—终板电位），三处选一处，并说明共同点（蓄积性、与剂量相关、可叠加、可观察）。
7. 观察窗口：按第 6 步给窗口——耳在疗程中后段，肾贯穿疗程，神经肌肉阻滞在给药后短时间内。写清这一段为什么落在这里。
8. 判断去向：这条表述若被用来指导某个人的用药，那个判断由谁作出、依据什么。写清「本章只描述机制与类别，不替代专业判断」。

【硬约束】
- 不写剂量、浓度、配比、疗程与血浆药物水平的数值与判定区间；需要剂量时统一写「剂量与用法照底本」。
- 不作适应证判定，不作病情与预后判定，不作疗效断言与优越性断言，不作品种之间的等级排名。
- 引教材原文必须逐字，标「教材·药理学·第42章·42.x.y」；核不到原文就不引，改写要标明是改写。
- 不写品名、厂商、剂型规格与价格。
- 信息不足时直接说缺哪一项，不要用常识补。

【输出格式】
八个小标题各答一到三句；末尾另起一行写：
「本回答为教学层面的结构梳理，不写量值，不构成用药建议。」
```

## 示例：一次合格的走链（节选）

表述：「某药对肠球菌单用不够。」教材定位：教材·药理学·第42章·42.1.2。待判：转运。

- **结构**：碱性化合物，带正电，水溶性强、脂溶性低——所以只能注射，分布限于细胞外液。
- **转运**：卡在第二步。肠球菌的细胞膜通透性低，药物进不到胞质，核糖体上的靶点再敏感也没用。
- **谱的边界**：需氧革兰阴性杆菌为主；对肠球菌属、链球菌属单用作用有限；对厌氧菌无效（缺驱动）。
- **时相**：静止期杀菌药，故与抑制细胞壁合成的药物在时相上互补。
- **耐药定位**：这条表述讲的是天然不敏感，属「摄取」这一路，不是修饰酶也不是靶位。
- **毒性落位**：仍是三处——耳、肾、神经肌肉接头；「单用不够」不改变毒性谱。
- **观察窗口**：若联用，耳与肾的观察照旧，但神经肌肉阻滞需在给药后短时间内看，因为联合用药可能加重。
- **判断去向**：判断由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南为依据作出。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 把「进不去」说成「靶点不对」 | 「厌氧菌的核糖体不同」 | 回到第 2 步：驱动缺失，靶点仍在 |
| 三处毒性并列成三件事 | 耳、肾、接头各写一段互不相干 | 先写同源机制，再写部位与窗口的差别 |
| 协同当联用推荐 | 由「机制协同」推出「应当合用」 | 改为「机制上有互补，方案另定」 |
| 耐药三路混说 | 把修饰酶、靶位、摄取写成一句 | 分开写，并各配一条对策 |
| 窗口错位 | 只在首次给药后观察耳毒性 | 改到疗程中后段；肾贯穿疗程 |
| 偷给量值 | 顺手写监测数值或疗程 | 一律改为「剂量与用法照底本」 |

## 与本章的接口

- 42.1 立三条线索：结构（极性）、转运（三步与呼吸链）、耐药（三通路与对策）。
- 42.2 分品种：共同点先立（机制、转运、体内过程、四类不良反应），差别三点（谱的宽窄、对酶的稳定性、毒性侧重）。
- 42.3 落毒性：耳与肾同源不同部位，神经肌肉阻滞另成一条链，观察窗口因此分三种。
- 42.4 收口径：可写五类与不写五类，记录六要素与复核五问。
