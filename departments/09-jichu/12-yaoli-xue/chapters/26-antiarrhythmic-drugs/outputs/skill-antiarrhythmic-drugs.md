# Skill：抗心律失常药——四个环节、两个方向、一份同源清单

## 何时用

- 读到「某药治某类心律失常」，需要判断这句话绕过了哪一层机制
- 要解释「为什么抑制异常电活动的药会造出新的异常」
- 遇到「改善传导」与「减慢传导」并列出现，需要说清两者各自的前提
- 要解释「同一类药为什么对缺血组织作用更强」
- 讨论联合用药，需要判断叠加落在哪个效应轴上

## 核心判据（六问）

1. **靶点是什么？** 钠、钙、钾通道，β 受体、M 受体、α 受体、腺苷受体，或未分类的其它机制。答不出靶点，后面全是套话。
2. **改哪个环节？** 降低自律性、减少后除极与触发活动、改变传导性以消除折返、延长有效不应期。四个之中选主次，不要四个一起说。
3. **方向朝哪边？** 若涉及传导性：改善传导针对部分去极化组织里的单向阻滞；减慢传导针对可被转为双向阻滞的环路。两个方向都通向折返中断，前提不同。
4. **依赖哪条性质？** 状态依赖性决定对缺血或部分去极化组织的相对选择性；使用依赖性决定心率越快作用越突出。两条都同时解释了治疗作用与致心律失常作用。
5. **风险从哪来？** 复极过度延长、传导过度抑制、负性肌力、血压下降、心外器官影响。风险应当能从第 1 至 4 步推出来，推不出就是没想清。
6. **判断交给谁？** 由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南决定。

## 执行步骤

```text
1. 收口：把待判句子压成一句「性质或作用」，删掉药名与用途
2. 定靶：通道 / 受体 / 未分类机制
3. 定环：四个基本环节中选主次
4. 定方向：涉及传导性时，写清改善还是减慢，并写出前提
5. 查性质：状态依赖性、使用依赖性，落在哪一类组织上
6. 推风险：由靶点与环节向不良反应方向推一条，推不出就标「本教材未展开」
7. 判组合：是否落在同一环节、不良反应是否落在同一效应轴
8. 定去向：谁判断、依什么、如何留痕
```

## 硬约束

- **不写剂量、负荷量与维持量、血药浓度、心电与电生理参数的量值。** 需要剂量时统一写「剂量与用法照底本」。
- **不作节律异常的分型判定，不作适应证判定，不作病情与预后判定，不作疗效与优越性断言，不作优劣与排名。**
- **引文逐字。** 标「教材·药理学·第26章·26.x.y」，核不到原文就不引；改写须标明是改写。
- **不写品名、厂商、剂型规格与价格。**
- **不把「同源」写成「必然」。** 同源说的是机制上的同一条路径；是否显现取决于剂量、膜电位状态、电解质与个体条件。
- **不确定就写下来。** 标待核实，不用推测填空。

## 交付物

1. 一条拆解链：靶点 → 环节 → 方向或性质
2. 一条风险推导：从环节推到不良反应方向，并注明依据
3. 若涉及两种药：一句叠加判断（同环节 / 同效应轴 / 环节互补）
4. 一组观察补充：症状、体征、节律与心电、实验室、用药与依从，哪几类需要加密
5. 一句边界句：本章只描述机制与类别关系，判断归属另行

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 药名对病症 | 说不清作用位点与风险来源 | 回到第 1、2 问，写靶点与环节 |
| 方向混用 | 把改善传导与减慢传导混成一句 | 补第 3 问，写清各自前提 |
| 忽略状态依赖 | 解释不了「为什么对缺血组织更强」 | 补第 4 问，写失活态亲和力 |
| 只讲治疗 | 风险变成附加条款 | 从第 2 问往第 5 问推一条 |
| 选择性当绝对 | 「选择性药物没有某类不良反应」 | 改写为「选择性是程度，剂量增大时减弱」 |
| 把框架当流程 | 用四步直接裁断个案 | 四步是分析框架，处置归具备资质的人员 |

## 边界

本 Skill 只处理「一条表述 → 靶点与环节」的拆解，不涉及剂量、分型判定与临床决策。本章内容为教学材料，不构成用药建议；任何涉及个体的用药评估须由具备资质的人员依现行法律法规与规范作出。
