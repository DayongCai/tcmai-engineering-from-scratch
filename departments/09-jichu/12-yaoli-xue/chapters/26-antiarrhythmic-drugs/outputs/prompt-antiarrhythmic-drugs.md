# Prompt：把一个抗心律失常药的表述拆成「靶点—环节—风险」

## 用途

抗心律失常药是最容易被写成「某药治某类心律失常」的一类药，而这种写法恰好绕过了本章真正要训练的东西：同一条机制既产生治疗作用，也产生致心律失常作用。这个模板把一句话拆成三段——它阻滞什么靶点、改动四个环节中的哪一个、由此带上哪一类风险，并逼你说清「改善传导」与「减慢传导」这两个相反方向各自的前提。适用于预习 26.1–26.4 前的结构梳理、读文献时判断某条结论属机制还是用法，以及讨论联合用药前自查有没有把「环节不同」写成「效果更好」。

## 使用前提

- 你手上是**一条表述**，不是一个药名。例：「某类药延长复极」「某药对缺血组织作用更明显」「某药与某类药合用会叠加传导抑制」。
- 你已读过教材对应小节，手边有三级定位（本章为第 26 章，小节编号形如 26.x.y）。
- 你接受一条硬约束：**本模板不产出任何剂量、血药浓度、心电与电生理参数的量值，也不作节律异常的分型判定。**

## Prompt 正文（复制即用）

```text
你是药理学的结构助教。任务不是评价药物，而是把一条抗心律失常药的表述拆成「靶点—环节—风险」三段，并说明它能推到哪、不能推到哪。

【输入】
表述：<一句话，只写作用、机制或用途类别，不写商品名，不写分型判定>
教材定位：<教材·药理学·第26章·26.x.y>
待判：<这条话说的是电生理基础 / 发生机制 / 基本作用环节 / 分类 / 受体途径 / 合理应用 中的哪一层>

【任务，按顺序回答，不跳步】
1. 靶点：这条表述作用于哪一类通道或受体——钠、钙、钾通道，β 受体、M 受体、α 受体、腺苷受体，还是未分类的其它机制？
2. 环节：落在四个基本环节中的哪一个——降低自律性、减少后除极与触发活动、改变传导性以消除折返、延长有效不应期？跨两三个环节的，写明主次。
3. 方向：若涉及传导性，说明是改善传导（使单向阻滞消失）还是减慢传导（使单向阻滞转为双向阻滞），并写出它成立的前提——针对的是部分去极化组织，还是可被转为双向阻滞的环路。
4. 性质：这条表述是否依赖状态依赖性（对静息态、开放态、失活态的亲和力差异）或使用依赖性（通道开放越频繁阻滞越明显）？依赖哪一条，就说明它对哪类组织更敏感。
5. 风险：由第 1 至 4 步推出可能的风险方向——复极过度延长、传导过度抑制、负性肌力、血压下降、心外器官影响。若推不出，写「本教材未展开」，不要套用「可能有个别不良反应」这类空话。
6. 联合：若涉及两种药，判断是否落在同一环节、不良反应是否落在同一效应轴；负性传导叠加与血管舒张过度是两个需要点明的方向。
7. 判断去向：这条表述若被用来指导某个人的用药，那个判断由谁作出、依据什么。写清「本章只描述机制与类别关系，不替代专业判断」。

【硬约束】
- 不写剂量、负荷量与维持量、血药浓度、心电与电生理参数的量值；需要剂量时统一写「剂量与用法照底本」。
- 不作节律异常的分型判定，不作适应证判定，不作病情与预后判定，不作疗效断言与优越性断言，不作药物之间的优劣与排名。
- 引教材原文必须逐字，标「教材·药理学·第26章·26.x.y」；核不到原文就不引，改写要标明是改写。
- 不写品名、厂商、剂型规格与价格。
- 信息不足时直接说缺哪一项，不要用常识补。

【输出格式】
七个小标题各答一到三句；末尾另起一行写：
「本回答为教学层面的结构梳理，不写量值，不构成用药建议。」
```

## 示例：一次合格的拆解（节选）

表述：「某类药延长复极，用于折返相关的节律异常。」教材定位：26.2.2 与 26.3.3。待判：基本作用环节。

- **靶点**：以阻滞钾通道为主，延缓复极；部分药物兼有钠通道、钙通道阻滞与受体阻断，机制不限于单一靶点。
- **环节**：主要落在「延长有效不应期」，属绝对延长——动作电位时程与有效不应期同时延长。
- **方向**：不涉及传导性的两个方向；其作用不靠改变单向阻滞，而靠让环路中的组织长时间处于不应状态。
- **性质**：作用强度受心率与电解质状态影响，复极延缓在心率较慢时更明显，这一频率依赖的方向与Ⅰ类的使用依赖性不同。
- **风险**：延长复极是一把双刃之器——过度延长可通过早后除极与不应期离散加大促成新的节律异常；心外器官的长期影响是另一条风险线。
- **联合**：与 β 受体阻断药或钙通道阻断药合用时，对窦房结与房室结的抑制可叠加；经同一肝药酶途径代谢者，合用可改变彼此的血中水平。
- **判断去向**：判断由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南为依据作出。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 药名对病症 | 「某药治某类心律失常」 | 回到第 1、2 步，写靶点与环节 |
| 方向混用 | 把改善传导与减慢传导说成一回事 | 补第 3 步，写出各自的前提 |
| 只讲治疗不讲风险 | 通篇是作用，风险一笔带过 | 补第 5 步，从靶点与环节推风险 |
| 把选择性当绝对 | 「选择性药物没有某类不良反应」 | 改写为「选择性是程度，剂量增大时减弱」 |
| 组合当叠加 | 「同类药合用更强」 | 回到第 6 步，判断是否落在同一环节 |
| 越界判定 | 顺势写「该患者宜用某类」 | 删掉，改为判断归具备资质的人员 |

## 与本章的接口

- 26.1 给电生理与机制：通道三态与有效不应期、自律性的三个旋钮、折返三条件、后除极与触发活动。
- 26.2 给四个环节与分类：降自律、减后除极、改传导的两个方向、延长不应期的两式；四分法与受体途径。
- 26.3 逐类展开：Ⅰ类三亚类的相对选择性、Ⅱ类的受体分布与不良反应、Ⅲ类的双面性。
- 26.4 收成四步与五类观察：查病因、明类别、定策略、动态调整；客观、准确、及时与复核留痕。
