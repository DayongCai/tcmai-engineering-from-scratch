# Skill：拟胆碱药——两条路、三张表、一条边界

## 何时用

- 读到「这支药对眼有效 / 对骨骼肌特别有效」，要判断这句话是从哪条路推出的
- 要解释「同样是增强胆碱能效应，为什么一类药在神经受损的部位会失灵」
- 要把效应清单压成链条（缩瞳—房水回流—眼压下降；终板去极化—肌束颤动—肌松）
- 需要判断某支药为什么只能注射、为什么进不了中枢、为什么滴眼会有全身反应
- 有人拿「哪个拟胆碱药更强」来问，需要把讨论拉回受体谱与可分离性

## 核心判据（六问）

1. **哪条路？** 直接占受体（自己带钥匙），还是抑制胆碱酯酶（把已释放的钥匙留住）。后者有一道硬前提：递质还在释放、神经支配还在。
2. **哪类受体？** M、N 兼激动／M 选择性／N 选择性／不直接作用于受体。受体谱越宽，效应越难分离，治疗用途越难形成。
3. **效应能不能串成链？** 起点是哪一个受体被激动，中间是解剖或生理改变，终点是可观察的表现。串不成链的，只能算并列记忆项。
4. **时程由什么决定？** 胆碱酯酶水解、肝代谢、肾排泄。胆碱酯类不靠肝肾失活，这是本章的分界：多数药的时程由器官功能决定，它不是。
5. **药能到哪？** 电荷与脂溶性决定能否口服、能否入脑、能否透过角膜。季铵限细胞外液，叔胺可入中枢。
6. **观察补哪几栏？** M 组（腺体、眼、心血管、胃肠膀胱）、N 组（肌力与肌束颤动）、中枢组（意识与呼吸），再加基线、起效、峰值、恢复四个时点。

## 执行步骤

```text
1. 收口：把待判句子压成一句「性质或作用」，删掉药名与形容词
2. 分路：直接 / 间接；间接者先查「递质是否还在释放」这一前提
3. 归受体：M、N 兼 / M / N；写出该类受体的器官分布
4. 串链：受体 → 中间环节 → 可观察表现；串不通就标「并列项」
5. 定时程：水解 / 肝 / 肾；由此判断器官功能是否改变时程
6. 查途径：电荷与脂溶性 → 口服、入脑、透角膜；局部用药是否引起全身效应
7. 落观察：三组效应 + 四个时点 + 中性语言
8. 定去向：判断由具备资质的人员作出，过程留痕
```

## 硬约束

- **不写剂量、浓度、维持时长的量值。** 需要剂量时统一写「剂量与用法照底本」。
- **不作适应证判定，不作病情与预后判定，不作疗效断言，不作优劣排名。**
- **引文逐字。** 标「教材·药理学·第6章 + 三级小节号」，核不到原文就不引。
- **不写品名、厂商、剂型规格与价格。**
- **顺序是预期，不是判据。** 「先兴奋后抑制」「腺体最先显效」都属倾向，用来安排观察，不用来下结论。
- **不确定就标待核实。** 不用推测填空。

## 交付物

1. 一条路径判定：直接占受体，还是抑制酶；前提是否成立
2. 一张「受体—器官—效应」对应表，只写与待判句子相关的那几行
3. 一条可复述的链条：起点、中间环节、终点
4. 一句时程归因：水解、肝、肾，以及器官功能是否改变它
5. 一栏观察补充 + 一句边界句

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 把间接作用说成「亲和力高」 | 解释不了失神经部位为何无效 | 回到「依赖内源性递质释放」这一前提 |
| 三项眼效应并列背 | 答不出缩瞳为何能降眼压 | 串成链：缩瞳 → 前房角 → 房水回流 → 眼压 |
| 只谈受体不谈剂量层次 | 小剂量与增量的效应面貌混为一谈 | 补「小剂量 M 样为主，增量后 N 样显现」 |
| 把「作用强」当分类轴 | 三类药的差别被写成强弱排序 | 改为受体谱宽窄与可分离性 |
| 局部用药当全身无关 | 漏掉经鼻泪管的全身吸收 | 补吸收路径与压迫内眦的操作要点 |
| 记录写「瞳孔异常」 | 事实与判断混在一起，无法复核 | 改写「瞳孔较用药前缩小」并注明光线条件 |

## 与相邻章节的接缝

- 第 5 章（传出神经系统概论）：递质、受体、分类的总框架；本章是它在胆碱能一支上的展开。
- 第 7 章（有机磷酸酯类及复活药）：把「不可逆抑制」这条支线写足，并给出复活药这条反向路径。
- 第 8 章（抗胆碱药）：受体被阻断后的效应，正好是本章效应的镜像；阿托品对抗 M 样作用即两章的接口。
- 第 3 章（药动学）：本章的吸收、分布、转化、排泄四词在那一章有参数化写法，本章只用定性关系。

## 边界

本 Skill 只处理「一句表述 → 路径与受体 → 可观察项」的判定，不涉及剂量、适应证与临床决策。本章内容为教学材料，不构成用药建议；任何涉及个体的用药评估，须由具备资质的人员依现行法律法规与规范、以现行药品说明书为依据作出。
