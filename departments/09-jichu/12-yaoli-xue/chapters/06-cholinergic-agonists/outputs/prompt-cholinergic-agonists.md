# Prompt：拟胆碱药的「两条路」判定器

## 用途

把一段关于拟胆碱药的表述（教材摘录、课件句子、他人转述）交给这个模板，输出三样东西：这句话站在两条作用路径的哪一条上；它由受体分布与酶抑制程度能推出什么、推不出什么；它需要配哪几个观察项才算落地。

用于三种场合。其一，备课时核对一句话的成立条件——抗胆碱酯酶药的任何效应表述，都必须先过「递质还在不在释放」这一关。其二，读书时把效应清单压成链条——毛果芸香碱的三项眼效应是因果链，不是三个并列知识点，压不成链就说明还没读懂。其三，写观察记录时确定栏目——受体分几组，观察就分几栏；缺一栏，复核时就无法判断顺序。

## 模板

```text
【待判表述】<一句话，去掉药名与形容词，只留性质或作用>

1. 哪条路？
   直接作用（占受体） / 间接作用（抑制胆碱酯酶）
   → 若为间接：递质释放或神经支配是否完整？不完整则效应预期应当下调

2. 哪类受体？
   M、N 兼激动 / M 选择性 / N 选择性 / 不直接作用于受体
   → 该受体分布在哪些器官？这些器官就是效应与不良反应的落点

3. 效应能不能串成链？
   写出起点（哪一个受体被激动）→ 中间环节（解剖或生理改变）→ 终点（可观察的表现）
   → 串不成链的，标「并列记忆项」，不作机制解释

4. 时程由什么决定？
   水解（胆碱酯酶）/ 肝代谢 / 肾排泄 / 三者兼有
   → 由此判断器官功能状态会不会改变时程

5. 给药途径受什么限制？
   电荷与脂溶性 → 能否口服、能否入脑、能否透过角膜
   → 由此判断局部用药会不会引起全身效应

6. 观察要补哪几个栏目？
   M 组（腺体、眼、心血管、胃肠膀胱）/ N 组（肌力与肌束颤动）/ 中枢组（意识与呼吸）
   → 再加四个时点：基线、起效、峰值、恢复

7. 边界句
   本章只写分类、机制、体内过程与观察口径；剂量与用法照底本；
   不作适应证判定，不作疗效断言，不构成用药建议。
```

## 用法要点

- **先判路径，再判受体。** 顺序颠倒会把间接作用药的效应写成「受体亲和力高」的结果，这是本章最常见的误读。
- **「作用强」这个词在本章几乎不成立。** 三类直接作用药的差别在受体谱宽窄，两类抗胆碱酯酶药的差别在结合可逆性与分布；强弱不是分类轴。
- **量值一律不填。** 需要剂量时写「剂量与用法照底本」；需要时程时写「随药物、途径与个体状态移动」。
- **引文逐字。** 标「教材·药理学·第6章 + 三级小节号」，核不到原文就不引，改写须标明是改写。

## 输出示例（骨架）

```text
待判：某药滴眼可降低眼内压
路径：直接作用，M 受体激动
受体：瞳孔括约肌与睫状肌的 M 受体
链：括约肌收缩 → 虹膜根部向中心 → 前房角间隙扩大 → 房水回流增加 → 眼压下降
时程：局部给药，经角膜吸收；同时经鼻泪管入鼻咽，可致全身效应
观察：瞳孔大小（同光线、双侧对比）、视近与视远的清晰度、唾液与出汗、心率
边界：剂量与用法照底本；眼压变化写「较用药前」，不写「正常」
```

## 不做什么

不判定某个人该不该用这支药，不比较药物优劣，不推算剂量与疗程，不把教材的机制叙述转写为处置流程。涉个体的判断，由具备资质的人员依现行法律法规与规范、以现行药品说明书为依据作出。
