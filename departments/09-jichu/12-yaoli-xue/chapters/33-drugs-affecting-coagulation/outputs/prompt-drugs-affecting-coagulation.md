# Prompt：把一条抗栓药的表述，落到「哪一段—什么靶点—怎样监测」

## 用途

抗栓药的讨论里最容易出现的两种句子，一种是「某药抗凝强、起效快」，把靶点与强度混作一谈；另一种是「某药更安全」，把可逆性读成了风险等级。这个模板要求一句话先交代三件事：它作用在凝血与纤溶这条线的哪一段、靶点在哪个分子上、因此能用什么方式盯住。适用于预习 33.1–33.4 时的结构梳理、读监护记录时判断某项指标能不能反映某药的作用，以及写讨论前自查有没有把「机制差别」写成「优劣排序」。

## 使用前提

- 你手上是**一条表述**，不是一个药名。例：「某药不依赖抗凝血酶」「某药对已结合于纤维蛋白的凝血酶也有效」。
- 你已读过教材对应小节，手边有「教材·药理学·第N章·N.M.K」的定位（本章为第 33 章）。
- 你接受一条硬约束：**本模板不产出任何剂量、浓度、监测数值与疗程时长的量值。**

## Prompt 正文（复制即用）

```text
你是药理学的结构助教。任务不是评价药物，而是把一条抗栓药的表述放回「段—靶点—可逆性—监测—观察」这条线，并说明它能推到哪、不能推到哪。

【输入】
表述：<一句话，只写作用、性质或用途类别，不写商品名，不写适应证判定>
教材定位：<教材·药理学·第33章·33.x.y>
待判：<这条话说的是机制 / 分类 / 体内过程 / 不良反应 / 观察项目 中的哪一项>

【任务，按顺序回答，不跳步】
1. 定段落：这条表述落在「起始（血小板）/ 主体（纤维蛋白生成）/ 善后（已沉积的纤维蛋白）/ 回补（止血功能不足）」的哪一段？跨段的，写明从哪一段推到哪一段，中间缺不缺环节。
2. 定靶点：抗凝落到四类之一——增强抗凝血酶、直接结合凝血酶、抑制维生素 K 循环、抑制因子Ⅹa；溶栓落到对纤溶酶原的激活方式（复合物间接、直接裂解、纤维蛋白依赖）；抗血小板落到环氧化酶、P2Y12、糖蛋白Ⅱb 与Ⅲa、磷酸二酯酶；促凝落到辅因子、纤溶酶原结合位点、因子补充。
3. 定可逆：结合是否可逆？不可逆的，作用持续到什么时候（血小板更新、旧因子消耗）；可逆的，消退为何较快。可逆性决定时程，不决定「更安全」。
4. 定监测：这条表述对应的药，能否用常规的凝血功能指标盯住？不能的，说明监护方式为何要转向肾功能、合并用药核查与出血征象观察。
5. 落观察：按这条表述，观察表上必须多出哪一栏——穿刺点与导管部位、皮肤黏膜瘀斑、尿色与大便颜色、意识与肢体活动、还是注射局部？写不出，说明这条表述还没落地。
6. 找配伍：这条表述与哪一类方向相同、与哪一类方向相反？冲突落在哪个环节（同一受体、同一信号环节、还是改变体内过程），而不是笼统「不宜同用」。
7. 定去向：这条表述若被用来指导某个人的用药，那个判断由谁作出、依据什么。写清「本章只描述机制与类别，不替代专业判断」。

【硬约束】
- 不写剂量、浓度、监测数值与参考区间、疗程时长的量值；需要剂量时统一写「剂量与用法照底本」。
- 不作适应证判定，不作病情与预后判定，不作疗效断言与优越性断言，不作药物之间的等级排名。
- 引教材原文必须逐字，标「教材·药理学·第33章·33.x.y」；核不到原文就不引，改写要标明是改写。
- 不写品名、厂商、剂型规格与价格。
- 不写拮抗方案、剂量调整参数与处置步骤；凡涉及处置，写「由具备资质的人员依现行规范决定」。
- 信息不足时直接说缺哪一项，不要用常识补。

【输出格式】
七个小标题各答一到三句；末尾另起一行写：
「本回答为教学层面的结构梳理，不写量值，不构成用药建议。」
```

## 示例：一次合格的定位（节选）

表述：「某药与凝血酶结合后抑制其活性，对已结合于纤维蛋白的凝血酶也有效。」教材定位：教材·药理学·第33章·33.1.2。待判：机制与监测。

- **定段落**：主体段——纤维蛋白的生成。它不作用于起始环节的血小板，也不清除已沉积的纤维蛋白。
- **定靶点**：直接结合凝血酶，不依赖抗凝血酶。按结构可分多肽类与合成小分子，二者的结合位点与是否可逆不同。
- **定可逆**：水蛭素类同时占据催化位点与一处底物识别位点，形成稳定复合物；阿加曲班主要占据催化位点，结合可逆；比伐卢定结合后可被凝血酶缓慢水解，故作用短暂。可逆性决定消退快慢，进而决定它适合短时操作还是较长时程。
- **定监测**：不能。因为它绕开了抗凝血酶，建立在抗凝血酶之上的常规指标也就反映不了它的强度；评估转向肾功能状态、合并用药核查与出血征象。
- **落观察**：穿刺点与导管部位渗血、皮肤黏膜新发瘀斑、尿色与大便颜色；肾功能减退者的观察频次须提高。
- **找配伍**：与抗血小板药、溶栓药同向叠加（出血风险），与促凝药方向相反；冲突落在凝血酶这一环，而不是笼统「相互影响」。
- **定去向**：判断由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南为依据作出。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 段位错乱 | 把溶栓说成「更强的抗凝」 | 回到第 1 步：一个清已沉积的，一个减少新生成的 |
| 监测想当然 | 换了一类药，仍按原指标解读 | 补第 4 步：靶点换了，监测方式要跟着换 |
| 可逆当安全 | 「可逆所以更安全」 | 可逆决定时程，不决定风险等级 |
| 选择性当保证 | 「相对选择性所以不出血」 | 补一句：选择性是相对的，剂量增大仍可全身纤溶 |
| 偷给量值 | 顺手写监测数值、给药速度、疗程 | 一律改为「剂量与用法照底本」 |
| 越界写处置 | 直接写「应停药并加用拮抗剂」 | 删掉，改为判断归具备资质的人员 |
| 记录混时间线 | 溶栓与抗凝的起止写在一起 | 两条时间线分开，写明时刻与所见 |

## 与本章的接口

- 33.1 立抗凝四类：靶点决定能否被监测；肝素类借抗凝血酶，直接抑制药绕开它；华法林等旧因子消耗。
- 33.2 把溶栓摆上同一条线：作用对象是已沉积的纤维蛋白；纤溶酶不专一，故溶栓与出血同源。
- 33.3 讲起始环节的四靶点：环氧化酶、P2Y12、糖蛋白Ⅱb 与Ⅲa、磷酸二酯酶；可逆性决定恢复快慢。
- 33.4 讲回补：辅因子（维生素 K）、纤溶酶原结合位点（氨甲环酸）、因子补充（凝血因子制剂），三者机制不同，适用前提也不同。
