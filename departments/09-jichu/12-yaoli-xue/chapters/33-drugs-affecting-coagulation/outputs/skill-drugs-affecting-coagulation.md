# Skill：作用于凝血系统的药物——一条线四段、靶点定监测、可逆定时程

## 何时用

- 读到「某药抗凝强、起效快」，需要判断这句话说的是靶点还是强度
- 要解释「为什么换了一类抗凝药，原来的监测指标就不好用了」
- 遇到「某药更安全」的说法，需要把可逆性与风险等级分开
- 要把给药前后的观察整理成能复核的记录，尤其是溶栓与抗凝衔接的情形
- 有人拿「哪一类抗栓药更好」来问，需要把讨论拉回靶点与条件

## 核心判据（七问）

1. **哪一段？** 起始（血小板黏附与聚集）／主体（纤维蛋白生成）／善后（已沉积的纤维蛋白）／回补（止血功能不足）。段位错，后面全错。
2. **什么靶点？** 抗凝四类：增强抗凝血酶、直接结合凝血酶、抑制维生素 K 循环、抑制因子Ⅹa。溶栓：复合物间接激活、直接裂解、纤维蛋白依赖。抗血小板：环氧化酶、P2Y12、糖蛋白Ⅱb 与Ⅲa、磷酸二酯酶。促凝：辅因子、赖氨酸结合位点、因子补充。
3. **可逆吗？** 不可逆者作用持续至血小板更新或旧因子消耗；可逆者消退较快。可逆性决定时程，不决定安全性。
4. **盯得住吗？** 借用体内抑制系统（如抗凝血酶）的药，相关指标可反映其作用；绕开这条系统的药，常规指标反映不了，监护转向肾功能、合并用药核查与出血征象。
5. **同源风险在哪？** 溶栓的出血风险来自纤溶酶不专一；抗凝的出血风险来自凝血级联被整体压低；抗血小板的出血风险来自抑制程度叠加。风险与作用同源，故观察项由机制投影而来。
6. **配伍落哪个环节？** 同一受体或信号环节（相加或抵消）、同一器官的不同环节（叠加而不易察觉）、改变体内过程（时间进程改变）。三问之后再说「同用需注意」。
7. **判断交给谁？** 由具备资质的人员依现行法律法规与规范、以现行药品说明书与临床指南决定；拮抗方案与剂量调整参数不在本章。

## 执行步骤

```text
1. 收口：把待判句子压成一句「作用或性质」，删掉药名与用途
2. 定段：起始 / 主体 / 善后 / 回补
3. 定靶点：按第 2 问给出分子环节，不写「影响凝血功能」这类笼统说法
4. 定可逆：结合方式 → 时程 → 停药后恢复快慢
5. 定监测：能否用常规指标反映；不能的，说明监护转向什么
6. 落观察：穿刺点、黏膜、尿色与大便颜色、意识与肢体活动、注射局部
7. 查配伍：三问法定位冲突环节，不写成禁忌清单
8. 定去向：谁判断、依什么、如何留痕（两条时间线分开）
```

## 硬约束

- **不写剂量、浓度、监测数值与参考区间、疗程时长的量值。** 需要剂量时统一写「剂量与用法照底本」。
- **不作适应证判定，不作病情与预后判定，不作疗效断言与优越性断言，不作等级排名。**
- **引文逐字。** 标「教材·药理学·第33章·33.x.y」，核不到原文就不引；改写须标明是改写。
- **不写品名、厂商、剂型规格与价格。**
- **不写拮抗方案、剂量调整参数与处置步骤。** 凡涉及处置，写「由具备资质的人员依现行规范决定」。
- **可逆不等于安全，选择性不等于保证。** 两句都是教材的限定，转述时不得省略。
- **不确定就写下来。** 标待核实，不用推测填空。

## 交付物

1. 一条段位定位：起始／主体／善后／回补
2. 一处靶点落位：具体分子环节，而非「影响凝血」
3. 一个监测判定：能否被常规指标反映，不能时转向什么
4. 一栏观察补充：记录表上因此要多写什么，两条时间线如何分开
5. 一句边界句：本章只描述机制与类别，判断归属另行

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 溶栓当强抗凝 | 把「清除已沉积」说成「更强地阻止生成」 | 回到段位：一个清旧的，一个防新的 |
| 监测想当然 | 换类不换指标，误读「无异常」 | 靶点换了，监护方式要跟着换 |
| 可逆当安全 | 「可逆所以风险低」 | 可逆只决定时程与恢复快慢 |
| 选择性当保证 | 「相对选择性所以不出血」 | 补限定：剂量增大仍可全身纤溶 |
| 靶点当等级 | 按分类排出优劣 | 分类依据是靶点而非等级 |
| 越界写处置 | 写停药、换药、加拮抗剂 | 改为「由具备资质的人员依现行规范决定」 |
| 时间线混写 | 溶栓起止与抗凝开始写在一处 | 两条线分开，写明时刻与所见 |

## 边界

本 Skill 只处理「一条表述 → 段位与靶点」的判定，不涉及剂量、适应证、监测界值与临床处置。本章内容为教学材料，不构成用药建议；任何涉及个体的用药评估须由具备资质的人员依现行法律法规与规范作出。
