# 基因不是「一段编码」，是一套带开关的坐标系 · 提示词

## 用途

给「基因不是「一段编码」，是一套带开关的坐标系」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「从「一个基因一个蛋白」到「一个位点多种转录本」 → 三层组织：序列、染色质、拓扑 → 非编码区不是「填充」，是三种不同性质的元件 → 算例：一处变异落在哪一格，结论差多少」这条链。

## 提示词

```
我在学《医学遗传学》第 2 章「基因不是「一段编码」，是一套带开关的坐标系」，本章 5 节 / 2,608 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 其一，一个位点可以产生多种转录本
   - 变异是否致病，取决于它影响的是哪一种转录本
   - 其二，基因的边界是模糊的
   - 其三，非编码 RNA 也是产物
   - 不能说「变异在基因内所以重要」，也不能说「变异在基因外所以不重要」
   - 同一处变异在不同细胞里后果不同
4. 本章自陈的边界（不得越过）：
   - 本章的 3.2×10⁹ bp、编码区占比不到百分之二、20 个外显子与 3,000 bp 的编码长度，前者为**常引口径**，后者为**教学算例设定**，均非某个基因的实测值，也不作为判读阈值。
   - 「三层组织」是教学切分。实际是耦联的：序列决定甲基化位点，甲基化改变可及性，可及性改变拓扑；把三层当成三个独立模块，会在解释「同一序列、不同组织、不同结果」时失效。
   - 「四类判读方向」是启发式。真实判读需要人群频率、计算预测、功能实验、家系共分离等多条证据，本章不给任何判读规则、分级标准或阈值。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为医学遗传学的教学材料，用于建立「先定转录本、再定元件类别、最后定证据强度」的判读框架，不构成医学意见、诊断或治疗建议。文中结构描述与算例均为教学层面的概括与演示；具体操作以现行规范与所在机构制度为准。
