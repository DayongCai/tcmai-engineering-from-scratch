# 系谱不是「看图猜病」，是一台把家族史折成概率的机器

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 其一，男传男排除 X 连锁
- 其二，患病父亲的所有女儿均患病，则指向 X 连锁显性
- 其三，患病父亲的所有子女均不受累，且受累者的母亲均受累，则指向线粒体遗传
- 算例一（X 连锁隐性）
- 每多一个健康的儿子，分母加 1，分子的折半一次
- 算例二（外显不全）

## 边界

- 本章出现的 80%、1/100、F = 1/16 及由此推出的 1/3、1/5、1/9、1/15、1/1400 等，除 F 为**群体遗传学的标准系数**外，其余均为**教学设定与算例推导**，不代表任何真实疾病的外显率、携带率或人群风险，也不作为咨询结论的依据。
- 六种传递方式是分类框架，不是诊断工具。真实家系常同时呈现多种可能：外显不全、生殖腺嵌合、拟表型、非亲生关系、家系规模过小，任何一种都能让「看起来对」的方式失效。本章不给任何判别流程图或判定阈值。
- 「三条硬规则」的排除力以表型核实与亲子关系确认为前提；两者任一不成立，规则即失效。本章不涉及亲子鉴定的方法与程序。
- 本章为医学遗传学的教学材料，用于建立「先核信息、再定路径、最后算后验」的系谱分析框架，不构成医学意见、诊断、遗传咨询结论或治疗建议。文中算例均为教学演示，一切家系判读、风险告知与生育建议须由具备资质的执业人员依现行规范与所在机构制度作出。
