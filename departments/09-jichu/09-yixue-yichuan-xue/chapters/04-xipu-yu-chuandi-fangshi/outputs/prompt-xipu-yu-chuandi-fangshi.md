# 系谱不是「看图猜病」，是一台把家族史折成概率的机器 · 提示词

## 用途

给「系谱不是「看图猜病」，是一台把家族史折成概率的机器」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「六种传递方式的判别特征 → 三条硬规则：只有它们能「排除」 → 贝叶斯更新：每一个「正常」都在改动分母 → 近亲婚配：一个系数的算术」这条链。

## 边界

本章为医学遗传学的教学材料，用于建立「先核信息、再定路径、最后算后验」的系谱分析框架，不构成医学意见、诊断、遗传咨询结论或治疗建议。文中算例均为教学演示，一切家系判读、风险告知与生育建议须由具备资质的执业人员依现行规范与所在机构制度作出；具体操作以现行规范与所在机构制度为准。
