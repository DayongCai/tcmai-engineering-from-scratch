# 第 4 章 · 系谱不是「看图猜病」，是一台把家族史折成概率的机器

> **MOTTO:** 「男女同姓，其生不蕃。」——《左传·僖公二十三年》
>
> **PROBLEM:** 同一张系谱图，两个人读出两个结论：一人说「三代都有，肯定是显性」，另一人说「第二代那位其实没查过，只是家属说没事」。系谱的价值不在于它画了什么，而在于**每一个符号背后挂着一条可核实的条件**——谁确诊、谁只是被听说、谁已过风险年龄、谁的死因不明。数目设定：六种传递方式在系谱上的判别特征共有十余个，但真正具备「排除力」的只有三条；其余十余个只能「不排除」。用只能「不排除」的特征去下结论，是把一张概率图读成了一张判决书。

**双根因定位:** 环境逼迫（生育决策有时间窗，咨询必须在信息残缺时给出方向；而错误方向的代价是不可逆的——一次不必要的终止妊娠，或一次本可避免的患儿出生）+ 知识积累（判别特征 × 贝叶斯更新 × 近亲婚配的算术，三件合起来才能把「这家有病史」变成一个能拿来讨论的数字；缺任一件，只能给出「有一定风险」这种等于没说的话）

## 一、六种传递方式的判别特征

| 方式 | 代际连续 | 性别分布 | 关键特征 |
|---|---|---|---|
| 常染色体显性 | 每代可见（外显不全可跳代） | 两性相当 | 患者双亲至少一人患病（除非新发） |
| 常染色体隐性 | 常隔代 | 两性相当 | 双亲常无表型；近亲婚配显著增多 |
| X 连锁隐性 | 隔代 | 男性远多于女性 | **无男传男**；患者的舅父、外甥常受累 |
| X 连锁显性 | 每代可见 | 女性多于男性，女性常较轻 | **患病父亲的女儿全部患病，儿子全部不患病** |
| Y 连锁 | 每代可见 | 仅男性 | **父传子，全或无** |
| 线粒体 | 母系传递 | 两性均可受累 | **患病母亲的所有子女均可受累；患病父亲的子女均不受累** |

这张表最容易被误用的是第一行与第二行。「每代都有」被当成显性的充分条件——但一个隐性病在近亲婚配频繁的群体里、或在家系成员婚配对象恰好都是携带者的家系里，也可以每代都出现。反过来，「隔代」被当成隐性的充分条件——但外显不全的显性病同样隔代，且外显不全比多数人想的更常见。

## 二、三条硬规则：只有它们能「排除」

判别特征里，只有三条具备逻辑上的排除力，因为它们的违背无法用「偶然」解释：

**其一，男传男排除 X 连锁。** 父亲把 Y 传给儿子，X 只传给女儿。因此只要出现一次「父亲患病、儿子患病」，且能确认亲子关系，X 连锁（显性与隐性）即被排除。这一条在实践中的主要失效原因是亲子关系未核实，以及「父亲」的表型其实是拟表型。

**其二，患病父亲的所有女儿均患病，则指向 X 连锁显性。** 因为父亲唯一的 X 必然传给每一个女儿。若出现一个患病父亲有健康女儿，X 连锁显性被排除。这一条同样要求表型核实——「健康」可能只是「尚未到发病年龄」。

**其三，患病父亲的所有子女均不受累，且受累者的母亲均受累，则指向线粒体遗传。** 线粒体只经卵细胞传递。这一条的失效原因是异质性：携带低比例突变卵细胞的母亲，可能只传给孩子中的一部分。

其余特征都只能「支持」不能「排除」。这个区分在写法上有直接后果：报告里写「符合常染色体显性遗传」，与写「不排除常染色体显性遗传」，是两种强度完全不同的表述，前者需要家系证据支撑，后者只需要「没有反证」。

## 三、贝叶斯更新：每一个「正常」都在改动分母

系谱分析的核心动作，是把「某个亲属表型正常」这条信息，折进「他是携带者」的概率里。做法固定三步：先定先验，再列条件概率，最后归一化。

**算例一（X 连锁隐性）。** 一位女性的兄弟患 X 连锁隐性病，母亲必为携带者（有两个受累的 X 来源可能，此处设母亲为必然携带）。该女性为携带者的先验概率是 1/2。她已生育一个健康儿子，问她现在是携带者的概率：

```
P(携带) = 1/2，若携带，生健康儿子的概率 = 1/2
P(非携带) = 1/2，若非携带，生健康儿子的概率 = 1
后验 = (1/2 × 1/2) / (1/2 × 1/2 + 1/2 × 1) = 0.25 / 0.75 = 1/3
```

再生一个健康儿子，分子再乘 1/2：

```
后验 = (1/2 × 1/4) / (1/2 × 1/4 + 1/2 × 1) = 0.125 / 0.625 = 1/5
```

第三个健康儿子给出 1/9，第四个给 1/17。这串数（1/2、1/3、1/5、1/9、1/17）是遗传咨询里最有用的一串数，它把「越生越不像携带者」这件直觉写成了一条可复现的规则：**每多一个健康的儿子，分母加 1，分子的折半一次**。注意它永远不归零——这是概率，不是排除。

**算例二（外显不全）。** 某常染色体显性病，外显率 80%（教学设定），且表型多在成年早期出现。一位患病者的子女现已 40 岁、表型正常，问他将致病变异传给下一代的概率：

```
先验携带 = 1/2；若携带，未发病的概率 = 0.2
后验 = (0.5 × 0.2) / (0.5 × 0.2 + 0.5 × 1) = 0.1 / 0.6 = 1/6
其子代患病风险 = 1/6 × 1/2 × 0.8 = 1/15
```

从 1/2 降到 1/15，中间的杠杆是外显率与年龄。**外显率越低、观察到的年龄越大，「表型正常」这条信息越有分量**；反过来，如果这个人只有 15 岁，而该病的表型多在 30 岁后出现，那么「正常」几乎不提供信息，后验仍接近 1/2。所以贝叶斯更新必须带一个前提：**这条「正常」是在风险年龄之后观察到的**。漏掉这个前提，是咨询里最常见的一类计算错误。

## 四、近亲婚配：一个系数的算术

近亲婚配抬高隐性病风险，原因不是「血缘致病」，而是**共同祖先让双方更可能携带同一个拷贝**。用一个系数把这件事量化：子代从双亲获得「同一祖先同一等位基因的两个拷贝」的概率，记为 F。表兄妹婚配的子代，F = 1/16。

设某隐性病等位基因频率 q = 1/100（教学设定），则携带率约 1/50。子代患病风险：

```
随机婚配：q² = 1/10000
表兄妹婚配：q²(1 − F) + qF = 0.0001 × 0.9375 + 0.01 × 0.0625
         = 0.0000938 + 0.000625 ≈ 0.00072 ≈ 1/1400
```

比值约七倍。两点读法：

**其一，倍数是变数，不是常数。** 病越罕见，q 越小，近亲婚配的相对放大越明显——因为随机婚配的风险按 q² 缩小，而近亲部分按 q 缩小，两者缩小速度不同。这就是「罕见病更怕近亲」的算术来源。

**其二，绝对风险仍然很低。** 1/1400 是「仍然大概率生出健康孩子」。把七倍讲成「很危险」，与把 1/1400 讲成「没事」，是同一种错误的两面。**风险沟通必须同时给出相对值与绝对值**，否则听者只会抓住其中一个。

## 五、画图与读图的规矩

系谱图的价值取决于它有多「诚实」，因此有几条硬要求：

- **区分「确诊」与「听说」。** 符号旁应标注信息来源：经病历核实、家属陈述、未核实。三者混同，整张图的推断强度就被最高估的那一条决定了。
- **标注死亡年龄与死因。** 一个 30 岁「因意外去世、生前健康」的成员，与一个 70 岁「健康」的成员，对「是否已过风险年龄」的意义完全不同。
- **标注先证者。** 先证者是家系被发现的入口，它的选择本身会引入偏倚：从重症患者出发的家系，看起来总比从普查出发的家系更「重」。
- **不合并不同来源的家系。** 两个家系的图拼在一起，等于假定它们共享同一个变异，而这个假定通常没有证据。

还有一条常被忽略的：**系谱图会随信息更新而改**。第一次访谈画出的图，与三个月后拿到病历、核实了两位亲属诊断的图，可能给出不同的传递方式。把第一版图当成定稿，是把过程材料当成了结论。

## 代价与边界

- 本章出现的 80%、1/100、F = 1/16 及由此推出的 1/3、1/5、1/9、1/15、1/1400 等，除 F 为**群体遗传学的标准系数**外，其余均为**教学设定与算例推导**，不代表任何真实疾病的外显率、携带率或人群风险，也不作为咨询结论的依据。
- 六种传递方式是分类框架，不是诊断工具。真实家系常同时呈现多种可能：外显不全、生殖腺嵌合、拟表型、非亲生关系、家系规模过小，任何一种都能让「看起来对」的方式失效。本章不给任何判别流程图或判定阈值。
- 「三条硬规则」的排除力以表型核实与亲子关系确认为前提；两者任一不成立，规则即失效。本章不涉及亲子鉴定的方法与程序。
- 线粒体遗传的判别在异质性存在时显著弱化，本章只作类别说明，不涉及阈值、比例与临床判定。
- 本章不涉及任何具体疾病的诊断、治疗、产前诊断方案与用药；凡涉及判定与处置，须由具备资质的执业人员依现行规范与所在机构制度作出。
