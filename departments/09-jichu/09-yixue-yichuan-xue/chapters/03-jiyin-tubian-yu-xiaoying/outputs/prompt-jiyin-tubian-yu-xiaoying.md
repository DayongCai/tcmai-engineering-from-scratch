# 突变的后果不取决于它多大，取决于它落在哪一格、以及阅读框还在不在 · 提示词

## 用途

给「突变的后果不取决于它多大，取决于它落在哪一格、以及阅读框还在不在」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「变异的分类学：按什么分，就得到什么结论 → 密码子层面：四类后果，强弱差别很大 → 蛋白层面：四种功能机制，决定显性与隐性 → 修复：四条通路，四个盲区」这条链。
