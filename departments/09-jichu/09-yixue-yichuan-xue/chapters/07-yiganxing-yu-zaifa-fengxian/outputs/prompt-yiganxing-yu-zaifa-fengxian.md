# 再发风险不是一个数字，是一个随每条新信息改动的后验 · 提示词

## 用途

给「再发风险不是一个数字，是一个随每条新信息改动的后验」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三种口径：同一个词，三件事 → 一条完整的更新链：从 1/2 走到 1/11 → 检验不是答案，是又一次更新 → 染色体病的再发风险：两条完全不同的路」这条链。

## 提示词

```
我在学《医学遗传学》第 7 章「再发风险不是一个数字，是一个随每条新信息改动的后验」，本章 6 节 / 2,734 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 第一步，先验
   - 第二步，把「40 岁正常」折进去
   - 第三步，把「传给子代」折进去
   - 第四步，加入一次检测
   - 它们是同一个问题的四次回答，差别全在那几条新增信息
   - 「40 岁正常」这条信息的分量，取决于该病的表型是否真的已在 40 岁前出现
4. 本章自陈的边界（不得越过）：
   - 本章的 90%、99%、1/1000 及由此推出的 1/11、4.1%、0.045%、9% 等，全部为**教学设定与算例推导**，不代表任何真实疾病的外显率、检测性能或人群患病率；本章不给任何疾病的风险数字与筛查方案。
   - 贝叶斯更新链是简化：真实咨询还要处理生殖腺嵌合、拟表型、家系信息不可靠、多个变异同时存在等情形，任何一种都能让链条的某一环失真。
   - 「两条路径」是教学切分。真实情形中，年龄相关与结构重排可以并存；且部分三体来自父母一方的生殖腺嵌合，此时再发风险高于人群基线但远低于 1/2。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为医学遗传学的教学材料，用于建立「先验—更新—沟通」的风险分析框架，不构成医学意见、诊断、风险预测或治疗建议。文中一切算例均为教学演示；具体操作以现行规范与所在机构制度为准。
