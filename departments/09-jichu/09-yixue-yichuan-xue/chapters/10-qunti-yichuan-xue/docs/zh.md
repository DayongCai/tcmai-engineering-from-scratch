# 第 10 章 · 遗传平衡不是自然界的常态，是一把用来量「什么力在起作用」的尺子

> **MOTTO:** 「天之道，损有余而补不足。」——《老子·七十七章》
>
> **PROBLEM:** 「该病在人群中约占万分之一」，这句话背后藏着一个换算：如果这万分之一是纯合患者，那么致病等位基因的频率是百分之一，携带者约占五十分之一——**患者与携带者的比例约 1 比 200**。临床决策几乎全部建立在这个反比上：筛查找的是那 200 个人，不是那 1 个人。而这一切都建立在一个假定的平衡之上：随机婚配、无选择、无突变、群体足够大。真实人群四条全不满足。数目设定：哈代—温伯格平衡在真实群体里几乎从不严格成立，但它的偏离本身携带信息——**偏离的方向与幅度，指认出正在起作用的那一种力**（选择、漂变、迁移，还是近交）。

**双根因定位:** 环境逼迫（筛查策略、携带者频率、公共卫生预算都建立在群体频率上，而这些数字只能从「一群人」推出，不能从「一个人」推出；用错人群，所有下游换算全错）+ 知识积累（平衡的两条等式 × 五种扰动力 × X 连锁的特殊算法，三者合起来才能把一个表型频率翻成等位基因频率、再把等位基因频率翻成筛查方案；只背 p²+2pq+q²=1，遇到 X 连锁或近交群体就无从下手）

## 一、平衡的两条等式，与它成立的前提

设一对等位基因 A 与 a，频率分别为 p 与 q，p + q = 1。若配子随机结合，子代基因型频率为：

```
AA = p²    Aa = 2pq    aa = q²    （且 p² + 2pq + q² = 1）
```

这个结果只依赖一个条件：**配子是随机抽的**。它不依赖显隐性、不依赖基因在哪个染色体上（常染色体）、也不需要「遗传物质如何运作」的任何知识。正因为如此，它的适用范围很宽。

但要让它**代代保持不变**，还需要四条额外假定：群体足够大、随机婚配、无突变、无选择、无迁移。五条里少一条，频率就会移动。**平衡不是状态，是零假设**——它的价值在于：当我们观察到频率偏离时，可以反过来问「是哪一条假定不成立」。

## 二、三种用法：从表型倒推基因频率

**用法一：从隐性病患者频率开方。** 若某常染色体隐性病在人群中占 q²，则：

```
q² = 1/10000 → q = 1/100 → 2pq ≈ 2×0.99×0.01 ≈ 1/50
携带者 : 患者 = 2pq : q² = 2p/q ≈ 200 : 1
```

这个 200∶1 是群体遗传学里最常用的一个数。它有一个反直觉的推论：**病越罕见，携带者相对越多**。q = 1/1000 时，比值升到约 2000∶1。原因是患者按 q² 缩小，携带者按 q 缩小，前者缩得快得多。**这就是为什么罕见病反而更值得做携带者筛查**——要防的那一件事虽然罕见，但携带它的人并不罕见。

**用法二：从携带率反推。** 若已知携带率约 1/50，则 2pq ≈ 0.02，q ≈ 0.01，患者频率 q² ≈ 1/10000。反向推算在筛查方案设计里更常用，因为筛查直接测得的是携带率。

**用法三：X 连锁位点的特殊算法。** X 连锁的平衡与常染色体不同，因为男性只有一条 X：

```
男性患者频率 = q          （一条 X 即表现）
女性患者频率 = q²
女性携带者频率 = 2q
```

设 q = 1/1000（教学设定）：

```
男性患者 1/1000；女性携带者 2/1000 = 1/500；女性患者 1/10⁶
```

三个数差三个数量级。这条不对称解释了 X 连锁隐性病的全部临床表现：**患者几乎都是男性，女性多为携带者，女性患者罕见且常由「携带者母亲 + 患病父亲」或偏斜失活造成**。

## 三、五种扰动力：偏离指认什么

| 力 | 做什么 | 对频率的影响 | 临床上的痕迹 |
|---|---|---|---|
| 突变 | 引入新等位基因 | 极慢，每代极小 | 决定「新发病例」的来源 |
| 选择 | 差异繁殖 | 降低有害等位基因，但速率取决于其表现方式 | 显性病降得快，隐性病降得几乎看不见 |
| 迁移 | 群体间基因流 | 拉平群体间差异 | 隔离群体的频率常与周边不同 |
| 漂变 | 抽样误差 | 小群体里随机固定或丢失 | 隔离人群、奠基者效应 |
| 近交 | 提高纯合比例 | 不改变 q，但改变基因型比例 | 隐性病显著增多 |

五个力里，**选择与漂变的方向相反**：选择把有害等位基因往下压，漂变在小群体里可以把它随机推高。两者的角力解释了为什么某些隔离群体里某种罕见病「异常地多」——不是那里的人「基因不好」，而是奠基者只带去了有限的等位基因，此后漂变与有限的婚配范围把它放大了。**这类差异是群体史的产物，不含任何优劣判断，把频率差异写成人群属性是最常见的一种越界。**

## 四、为什么「清除致病等位基因」在群体层面不可能

这是本章最该记住的一条算术。设某隐性病的选择系数为 1（患者完全不生育，极端假定），等位基因频率 q 的每代变化约为：

```
Δq ≈ −s·q²/(1 − s·q²) ≈ −q²   （s = 1 时）
```

q = 1/100 时，每代下降约 1/10000 —— 要从 1/100 降到 1/200，需要约一百代。而且随着 q 变小，下降速度按平方递减：q 减半，速率降到四分之一。**这是一个典型的「越接近目标越慢」的过程，永远到不了零。**

平衡点由突变率维持：新突变不断补充被选择清除掉的部分。**突变—选择平衡**意味着，只要突变还在发生，这个等位基因就有稳定的「底噪」。这一条推翻了两个常见误解：

- 「把患者都治好，这个病就会消失」——不会。治疗改善的是患者的生存，若治疗使其恢复生育，反而**放松了选择**，q 会上升。
- 「筛查能把致病基因淘汰掉」——不会。筛查改变的是「哪些妊娠继续」，不是「变异是否产生」；而且对隐性病，被筛掉的是纯合子，携带者仍在传递。

## 五、小群体：漂变与近交是两个不同的东西

两者常被混为一谈，实际机制不同：

- **漂变**是频率的随机游走，改变的是 q 本身。小群体里，一个等位基因可能因为「恰好没传到下一代」而永久丢失，也可能因为「恰好传得多」而升到高位。
- **近交**不改变 q，只改变基因型比例：纯合子增多、杂合子减少。它让隐性病「显形」，但不让等位基因变多。

两者的关系是：**小群体同时具备漂变与近交**，所以既会频率异常，也会纯合偏多。这就是隔离群体里罕见隐性病聚集的双重原因。判断时应当分开说：频率异常指向漂变与奠基者效应；纯合偏多指向近交。

近交的程度用一个系数衡量：子代从双亲获得「同一祖先同一等位基因的两个拷贝」的概率。亲子、全同胞为 1/4，表兄妹为 1/16。隐性病风险随之按第四章的算式上升。

## 六、临床换算：从一个数字到一套策略

群体遗传学的落点是把频率变成决策。以携带者筛查为例，一条完整的链条是：

```
目标病的患者频率 → 等位基因频率 q → 携带率 2pq → 需筛查的人数 → 检出后的干预选项
```

每一环都有它的不确定性：患者频率来自特定人群、特定年代，可能已过时；q 的推算依赖平衡假定，而真实群体常有近交与分层；携带率在不同祖源人群间可以相差数倍。因此规范的做法是：**写明这套频率的来源人群与年代，并说明它在目标人群中的适用性未经本地验证**。把别处的频率直接搬到本地，是筛查方案设计里最常见的一次错误。

还有一个必须交代的算术：筛查的**阳性预测值**。携带率越低，检测的假阳性在阳性结果里占比越高。这就是为什么低患病率人群里的「广谱筛查」容易产出大量需要后续确认的阳性——**筛得越宽，确认的负担越重**，这是第十一章的核心权衡在群体层面的版本。

## 代价与边界

- 本章的 1/10000、1/100、1/50、200∶1、1/1000、1/500 等，除 200∶1 为**由公式推导的近似比值**外，其余均为**教学设定**，不代表任何真实疾病在真实人群中的频率；本章不给任何疾病的患病率、携带率与筛查阳性率。
- 哈代—温伯格平衡的五条假定在真实群体中几乎从不全部成立。本章把它作为零假设使用，不作为对真实群体的描述；凡引用平衡推算的频率，均须注明「基于平衡假定」。
- 「五种力」是分类框架。真实群体中五者同时作用，且相互耦合（如漂变可放大选择的差异）；把某一偏离单独归因于某一种力，需要额外的群体史证据。
- 突变—选择平衡的算式作了强简化（假定选择只作用于纯合子、无近交、无迁移）；真实的等位基因频率轨迹还受群体分层与遗传漂变影响。
- 本章不涉及任何筛查方案的设计、目标病种选择、成本效益评估与实施规范；不涉及任何诊断、治疗与预后判断。凡涉及群体筛查与个体判定，须由具备资质的执业人员与机构依现行规范与制度作出。
