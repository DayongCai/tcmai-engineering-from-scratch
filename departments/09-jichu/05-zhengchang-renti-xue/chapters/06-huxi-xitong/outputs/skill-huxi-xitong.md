# 呼吸不是把气吸进来，而是把胸腔的一次形变换成一次交换

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 4 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 无容量、无分压、无频率
- 负压是结构前提，不是治疗手段的描述
- 三套划分不可互换
- 调节只讲类别与通路

## 边界

- **无容量、无分压、无频率。** 底本 12 个单元、20,491 汉字，带容量、压力、频率单位的参数为 0 处。"通气量多少算够""血氧多少算低"一类问题，本章不作回答，交现行规范与机构制度。
- **负压是结构前提，不是治疗手段的描述。** 说明胸膜腔密闭与负压，只解释肺为何随胸廓扩张；由此推出任何引流、抽气或正压通气的做法，都超出本章范围。
- **三套划分不可互换。** 上／下呼吸道按部位与功能类别分，肺叶按表面裂隙分，肺小叶按结缔组织分隔分；把"叶"与"小叶"当成同一层级，是最常见的记混点。
- 本章为正常人体学教学材料，只描述呼吸系统的结构类别与功能关系，不构成医学意见、诊断、治疗或护理指导。
