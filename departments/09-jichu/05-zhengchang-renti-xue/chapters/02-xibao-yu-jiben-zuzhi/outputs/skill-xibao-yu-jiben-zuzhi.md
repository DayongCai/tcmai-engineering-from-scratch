# 四类基本组织不是分类摆件，而是功能的四个前置条件

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 4 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 这门课不提供量值
- 镜下判读的三条依据有边界
- 分类是描述工具，不是固定标签
- 再生能力的等级差不能反推个体预后

## 边界

- **这门课不提供量值。** 底本 12 个单元、20,273 汉字，带长度、角度、数量单位的结构参数为 0 处。细胞直径、纤维粗细、修复所需时间一概不给；凡涉及正常值区间与时限的问题，以现行规范与所在机构制度为准。
- **镜下判读的三条依据有边界。** 类别、排列、相邻关系能说明"这是什么组织"，不能说明"这个人的组织是否正常"；后者属专业判定，超出本课程范围。
- **分类是描述工具，不是固定标签。** 一处结构常同时具备多类特征（假复层看似多层而基部均达基膜、变移上皮随充盈改变层次），把分类当标签会在判读时出错。
- 本章为正常人体学教学材料，只描述正常细胞与基本组织的结构类别与功能关系，不构成医学意见、诊断、治疗或护理指导。
