# 两条回路、四道瓣膜、一套传导：心既是泵，也是路由

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 4 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 无管径、无压力、无心率
- 瓣膜与传导只讲结构顺序
- 毗邻关系不是风险提示
- 两条回路不可混着背

## 边界

- **无管径、无压力、无心率。** 底本 12 个单元、19,960 汉字，带管径、压力、频率单位的参数为 0 处。"血压多少算高""心率多少算快"一类问题，本章不作回答，交现行规范与机构制度。
- **瓣膜与传导只讲结构顺序。** 四道瓣膜的开闭时相、传导系统的速度与节律，都只到"位置与顺序"层面；据此判读任何心电或血流信息，属专业判定。
- **毗邻关系不是风险提示。** 传导系统与冠状血管分支的毗邻、脾与胃的相邻，都只作形态学描述，不引申为任何临床结论。
- 本章为正常人体学教学材料，只描述脉管系统的结构类别与功能关系，不构成医学意见、诊断、治疗或护理指导。
