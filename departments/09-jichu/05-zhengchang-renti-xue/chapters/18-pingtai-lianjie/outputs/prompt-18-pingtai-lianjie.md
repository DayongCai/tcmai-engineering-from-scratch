# 知识库的价值不在存了多少条，而在每条都写得出依据与边界 · 提示词

## 用途

给「知识库的价值不在存了多少条，而在每条都写得出依据与边界」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「21 行 × 11 列：只有两列是硬约束 → 合规两道：材料从哪儿来，人能不能被认出来 → 智能辅助：三类定位、四类提示、四条不替代 → 双交付物：把「要求」写成能被脚本核对的东西」这条链。

## 提示词

```
我在学《正常人体学》第 18 章「知识库的价值不在存了多少条，而在每条都写得出依据与边界」，本章 6 节 / 3,938 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 依据与边界约束为必填，缺一列即不得落库
   - 要的是可核，不是可查人
   - 同一个模板套到底，等于放弃了边界约束这一列的意义
   - 数据门禁 E1
   - 先核来源与伦理，再作最小必要的处理，再去标识化，再人工复核并留痕归档
   - （只处理教学所必需的信息，能范围更小、影响更轻就选更小更轻的）、
4. 本章自陈的边界（不得越过）：

   - **丢掉自由度。** 必填两列与四道门会挡住大量「先存进去再说」的冲动；代价是录入变慢，收益是任何一条都能被追问到底。
   - **合规不等于合规审查。** 本章写的是要求的类别与顺序，不替代伦理审查，也不替代机构与部门的审批；平台只作提示与留痕。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为正常人体学的知识组织与平台协同教学材料，只描述单元登记、数据合规与智能辅助边界的要求类别，不构成诊断、治疗或用药建议，也不构成法律与伦理审查意见；具体操作以现行规范与所在机构制度为准。
