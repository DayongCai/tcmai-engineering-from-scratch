# 颈部的问题不是结构多，而是筋膜把结构隔成了互不相通的层 · 提示词

## 用途

给「颈部的问题不是结构多，而是筋膜把结构隔成了互不相通的层」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「颈部是一条通道，四类筋膜决定通道怎么隔 → 颈前区四个三角：每个三角都是「三层皮 + 一个底」 → 胸锁乳突肌区与颈根部：一条斜角肌当轴 → 颈外侧区与颈部腧穴：把「浅深」和「前后内外」两套话合起来」这条链。
