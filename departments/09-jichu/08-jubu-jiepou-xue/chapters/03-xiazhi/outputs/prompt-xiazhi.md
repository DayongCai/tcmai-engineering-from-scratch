# 下肢的难点不在记血管，而在同一个区里叠着两套通道 · 提示词

## 用途

给「下肢的难点不在记血管，而在同一个区里叠着两套通道」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「分区不是切蛋糕，是按「承重」与「摆动」分工划出来的 → 股前内侧区：浅层一条静脉，深层两个通道 → 腘窝：菱形四角，浅中深三层，最深者贴骨 → 踝与足：支持带把通道收成管，足底三间隙给出最后答案」这条链。

## 边界

本章为局部解剖学的教学材料，只说明下肢各区结构与层次与毗邻的类别与关系，不构成诊断、治疗或操作指导；具体操作以现行规范与所在机构制度为准。
