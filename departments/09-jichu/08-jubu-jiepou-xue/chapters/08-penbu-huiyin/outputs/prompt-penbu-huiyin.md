# 骨盆下口靠两个膈封闭，会阴的层次得先说清从哪个方向数 · 提示词

## 用途

给「骨盆下口靠两个膈封闭，会阴的层次得先说清从哪个方向数」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「界限是界面：上口没有隔断，下口有两个膈 → 盆筋膜四个部位：腱弓是共同附着线 → 男女盆腔：以膀胱或子宫为中心的两套反折 → 会阴：一个菱形、两个三角、两个方向」这条链。

## 边界

本章为局部解剖学的教学材料，只说明盆部与会阴的结构、层次与界面关系，不构成诊断、治疗或操作指导；具体操作以现行规范与所在机构制度为准。
