# 头部的答案在「谁跟谁粘在一起」，不在五层的名字里

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 每一个转折都落在骨性隆起上
- （厚而致密，毛囊、皮脂腺与汗腺丰富，血供充分）
- （坚韧，前连额肌、后连枕肌，两侧渐薄并续于颞筋膜浅层）
- 先定位到窝，再按前后内外排序，孔与穿行结构成对出现
- 「瓣少 + 两端相通」
- 面神经主干与分支所在的平面

## 边界

- **五层的名字能背，粘滑的判断要练。** 本章把「粘—粘—粘—滑—粘」立为读法，但判断某一处到底是粘还是滑，必须到标本上用手指分离才能确认，文字只能给判据。
- **颅底只讲成对，不讲全貌。** 孔裂与穿行结构一一列出，但每一孔的骨质毗邻、与窦腔的关系都略去；求全会把一章写成颅底外科学。
- **面部间隙只到通连，不到转归。** 「通哪里」是形态学结论；液体积聚后走到哪里、引起什么，属个案判断，本章不写。
- 本章为局部解剖学的教学材料，只说明头部各区的结构与层次与毗邻的类别与关系，不构成诊断、治疗或操作指导。
