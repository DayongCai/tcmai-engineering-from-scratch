# 视频课不是"把正文念一遍"，是让每一段旁白都能指回一个判据 · 提示词

## 用途

给「视频课不是"把正文念一遍"，是让每一段旁白都能指回一个判据」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「一门课在平台里的四层形态 → 从正文到讲稿：有字不等于有旁白 → 从讲稿到成片：三段一步都不能跳 → 交付层：没有清单的成片等于不可发现」这条链。

## 提示词

```
我在学《流行病学》第 18 章「视频课不是"把正文念一遍"，是让每一段旁白都能指回一个判据」，本章 8 节 / 2,679 汉字，习题 7 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 习题与代码层
   - 只收"整门打齐"的课
   - 第一道，体积 × 时长判据
   - 第二道，讲稿与正文同源
   - 第三道，按门查整门
   - 不证明"这句话被念出来过"
4. 指出本章写到类别就止步、不再给参数的地方。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```
