# 筛检阳性只说明该进一步查，不说明已经患病

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 5 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 题记是古籍，取的是「早识别」的意思
- 全部数字都是教学设定
- 预测值不是个体患病概率
- 本章不给界值、不给筛检建议
- 偏倚只能减少，不能消除

## 边界

- **题记是古籍，取的是「早识别」的意思。** 《韩非子》讲扁鹊望诊，层层深入而病渐难治，与筛检「早期识别、及时复核」同构；但它是寓言，不是方法学文献，不能当作筛检依据引用。正文中标注「教材·第3章·N.M.K」的才是教材原文。
- **全部数字都是教学设定。** 真阳性 80／假阳性 90／假阴性 20／真阴性 810、灵敏度 80.0%、特异度 90.0%、阳性预测值 47.1% 与 7.5%、约登指数 0.70、似然比 8.0 与 0.22、1,000÷0.80=1,250，都是为演示四格表与预测值而设的合成数，可逐步复算，不代表任何真实试验、人群或方案。
- **预测值不是个体患病概率。** 47.1% 与 7.5% 是「在该人群、该流程、该参考标准下，阳性者中真患病的比例」，用于群体层面的流程设计；把它当作对某一个人的判断，是把群体统计量冒充个体判断，教材在 3.2.3 明确禁止。
- 本章为流行病学教学材料，现况调查、筛检评价与偏倚分类取自教材《流行病学》第 3 章与 `standards/liuxingbing-xue` 的机器可读层。文中所有数字均为教学设定的合成演算，用于演示四格表、预测值与样本量余量，不构成研究结论、不构成临床建议，也不代表任何真实试验或人群的表现。
