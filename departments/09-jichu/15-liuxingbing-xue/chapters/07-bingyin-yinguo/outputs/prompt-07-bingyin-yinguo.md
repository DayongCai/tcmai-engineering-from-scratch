# 因果要过五道关，关联只是第一道门 · 提示词

## 用途

给「因果要过五道关，关联只是第一道门」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「病因的意思比「致病因子」宽得多 → 三个模型各管一段距离 → 必要与充分都难找，于是有了组分病因 → 三类关联、五条准则、一条底线」这条链。
