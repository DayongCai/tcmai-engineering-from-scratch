# 科研实训与实验设计 缺口登记

## 一、无独立教材

本课是 sem910 实训课，六站材料**逐字取自**《流行病学》（研究设计、数据、偏倚、质控、循证）、《生物化学》（常用技术）、《组织学与胚胎学》（制片与观察）三本母本的实验方法章。
汉字**不与母本相加**。

## 二、不写参数（本课最硬的自我限制）

| 类型 | 处理 |
|---|---|
| 试剂浓度、配制比例 | 不写——写错会被直接照做 |
| 仪器型号与参数 | 不写——以机构设备为准 |
| 统计阈值、样本量取值 | 只写「为什么要做」，不写取值 |
| 具体分步操作动作 | 不写——必须面授与示教 |

## 四、六站之间的顺序不可换

六站按「安全 → 设计 → 操作 → 数据 → 解读 → 报告」排。**安全站在最前**不是排版偏好：任何一站出问题，第一件事都是回到安全与处置流程。

## 五、不做的事

1. 不提供可直接执行的实验方案；
2. 不引真实课题的数据、图表与结论；
3. 不替代伦理审查与生物安全备案。

## 六、第一章「安全与规范」缺正源（本条最要紧）

母本三门**都没有实验室安全专章**（《流行病学》只有现场调查质控，《生物化学》只有技术操作，《组织学与胚胎学》只有制片规范）。
因此第一章现有内容实质是「**技术操作规范**」，不是「**生物安全、化学品管理、废弃物处置、事故应急**」。

缺的四块：

| 缺什么 | 现状 | 补法 |
|---|---|---|
| 生物安全分级与个人防护 | 无 | 须以机构生物安全规程为源，或面授 |
| 危化品分类、存放与相容性 | 无 | 须以危化品管理规范为源 |
| 废弃物分类与处置 | 无 | 须以机构制度为源 |
| 事故应急（溅洒、刺伤、火情） | 无 | **必须面授与演练，文字教学不足以替代** |

在没有补到合资格来源之前，**这一章不应作为独立的安全培训材料使用**，只能作为「操作规范」的引子。

## 七、三辨 5.8× 的原因

三辨 准备与安全 232 / 设计与对照 806 / 记录与报告 1,335。安全类词如此之少，正是上面那条缺口的量化表现：
母本没有安全内容，所以派生课也说不出多少。**这个偏斜不是切分失误，是缺口本身**。
