# 规范的作用不是禁止动作，而是把不可逆的后果提前变成可核查的条款 · 提示词

## 用途

给「规范的作用不是禁止动作，而是把不可逆的后果提前变成可核查的条款」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「规范不是禁令清单，是把不可逆的后果前置 → 技术类别各有边界：越界往往不是「做错」，是「用错」 → 污染与对照：PCR 一节给出的通用范式 → 纸面上的规范：调查表、预调查与知情同意」这条链。

## 边界

本章为科研实训的教学材料，只说明技术类别、适用边界与规范的认识逻辑，不构成任何实验操作指导、合规结论或伦理审查意见；具体操作以现行规范与所在机构制度为准。
