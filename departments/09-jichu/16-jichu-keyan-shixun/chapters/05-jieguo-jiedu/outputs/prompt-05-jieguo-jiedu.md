# 解读结果靠的是机制判断，不是看偏离明不明显 · 提示词

## 用途

给「解读结果靠的是机制判断，不是看偏离明不明显」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「偏倚不是误差，它不会因为样本变大而消失 → 两类偏倚：一个在「谁进来了」，一个在「怎么说的」 → 混杂的三个条件：第三条最常被判错 → 交互：相加与相乘不是一回事，判断要两把尺」这条链。

## 边界

本章为科研实训的教学材料，只说明偏倚、混杂与交互作用的概念与判断条件，不构成统计咨询、研究结论或合规意见；具体操作以现行规范与所在机构制度为准。
