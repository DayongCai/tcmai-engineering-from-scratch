# 对照不是一个组，是给「反事实」找的一个可观察的替身 · 提示词

## 用途

给「对照不是一个组，是给「反事实」找的一个可观察的替身」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「研究问题不是「感兴趣的方向」，是五个要素齐全的一句话 → 假设要说成能被否定的样子 → 四种设计：对照在每一种里对应的是谁 → 样本量与方案：把「能回答」变成「可核查」」这条链。

## 提示词

```
我在学《科研实训与实验设计》第 2 章「对照不是一个组，是给「反事实」找的一个可观察的替身」，本章 6 节 / 4,473 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 笼统的关切不是研究问题
   - 两者之间的差距，就是结论外推时必须说明的界限
   - 。涉及暴露与结局在时间上的先后，以及研究是横断于某一时点还是纵向跨越一段时间
   - 比较或参照的情形
   - 核心要求是可检验性
   - 成对表述的目的，是让检验有明确的对象
4. 本章自陈的边界（不得越过）：
   - **对照讲清了「对应谁」，讲不了「够不够」。** 本章能说清每种设计的对照指向哪一群人，说不清某一具体研究的对照是否充分——那要看测量、样本与实施，属方案评审与同行评议的范围。
   - **不做优劣排序。** 横断面、病例对照、队列、实验各有相称的问题与条件；教材明确反对排序，本章照办。凡是「某设计更高级」的说法，都是把条件抽掉了。
   - **样本量只讲要素与关系。** 本章不给公式、不给数值，因为公式的代入需要效应量与变异度的具体估计，而这两者必须由研究者举证。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为科研实训的教学材料，只说明研究问题、假设、设计与样本量的要素与关系，不构成研究方案范本、统计咨询或伦理审查意见；具体操作以现行规范与所在机构制度为准。
