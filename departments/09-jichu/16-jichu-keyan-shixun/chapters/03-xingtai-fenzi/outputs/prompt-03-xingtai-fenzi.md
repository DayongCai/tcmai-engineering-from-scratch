# 你看到的从来不是组织本身，是处理过的那一片 · 提示词

## 用途

给「你看到的从来不是组织本身，是处理过的那一片」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「看到的永远是处理过的标本：形态学的第一句真话 → 从切片到三维：把平面还原成位置 → 分子侧的六个环节：每一步都在缩小可能性 → 转基因与基因打靶：伦理前置不是手续」这条链。

## 提示词

```
我在学《科研实训与实验设计》第 3 章「你看到的从来不是组织本身，是处理过的那一片」，本章 6 节 / 4,634 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 细胞、组织、器官、系统、机体整体
   - 四次不同的「预处理」
   - 每换一级，被保留下来的信息就换一批，被丢弃的信息也换一批
   - ：有的侧重轮廓与边界，有的侧重成分与分布，有的侧重空间层次
   - 每一次「显示」都是把一种化学性质翻译成一种可看的信号
   - 不把显示结果的强弱当作判定依据
4. 本章自陈的边界（不得越过）：
   - **制备决定所见。** 本章反复讲「处理过的材料」，代价是：具体的固定、包埋、染色条件一概不写。这不是遗漏，是体裁约束——条件属实验操作，须由具备资质的人员按规范设定。
   - **重建不是原样。** 三维重建依赖切片间距、对齐与分割规则，给的是「在给定设定下的三维」；把它当成结构的原貌，是本课程最需要防的一种误读。
   - **两侧的边界不一样。** 形态侧的边界是「正常形态」，分子侧的边界是「信息与遗传」，两套边界的依据不同（前者是参照系，后者是伦理与法规），不能互相替代。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为科研实训的教学材料，只说明形态观察与分子技术的类别、环节与边界，不构成实验操作指导、判读结论或伦理审查意见；具体操作以现行规范与所在机构制度为准。
