# 你看到的从来不是组织本身，是处理过的那一片

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 细胞、组织、器官、系统、机体整体
- 四次不同的「预处理」
- 每换一级，被保留下来的信息就换一批，被丢弃的信息也换一批
- ：有的侧重轮廓与边界，有的侧重成分与分布，有的侧重空间层次
- 每一次「显示」都是把一种化学性质翻译成一种可看的信号
- 不把显示结果的强弱当作判定依据

## 边界

- **制备决定所见。** 本章反复讲「处理过的材料」，代价是：具体的固定、包埋、染色条件一概不写。这不是遗漏，是体裁约束——条件属实验操作，须由具备资质的人员按规范设定。
- **重建不是原样。** 三维重建依赖切片间距、对齐与分割规则，给的是「在给定设定下的三维」；把它当成结构的原貌，是本课程最需要防的一种误读。
- **两侧的边界不一样。** 形态侧的边界是「正常形态」，分子侧的边界是「信息与遗传」，两套边界的依据不同（前者是参照系，后者是伦理与法规），不能互相替代。
- 本章为科研实训的教学材料，只说明形态观察与分子技术的类别、环节与边界，不构成实验操作指导、判读结论或伦理审查意见。
