# 报告不是把过程讲一遍，是把证据链交出来让人查 · 提示词

## 用途

给「报告不是把过程讲一遍，是把证据链交出来让人查」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「报告不是叙述，是一条可以被查的链 → 五类记录：证据链的五个环节 → 三个核查层：现场、逻辑、溯源 → 从实训报告到系统评价：证据分级的同一条逻辑」这条链。

## 提示词

```
我在学《科研实训与实验设计》第 6 章「报告不是把过程讲一遍，是把证据链交出来让人查」，本章 5 节 / 3,747 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 报告的全部说服力，来自链条的完整度，而不是结论的新鲜度
   - 能够辨认填写人与填写时间
   - 实施过程与方案的一致性
   - 没有修改记录的数据，等于宣称自己从未出错——这本身就是最不可信的陈述
   - （如实反映实际发生的情形）、
   - （不遗漏关键环节）、
4. 本章自陈的边界（不得越过）：
   - **链条讲清了，写作技巧没讲。** 本章不教怎么把报告写得好看，只教怎么让它可查。理由是：可查是底线，好看是加分；底线不立，加分无意义。
   - **五类记录在实训里常常做不全。** 课时有限时，最先被砍的往往是过程记录与版本记录。本章的立场是：可以简化形式（合并表单、缩短字段），但不能取消环节——取消一环，链条就断在那里。
   - **伦理审查是前置条件，不是手续。** 教材写明：凡以人为研究对象或需采集人的健康与其他个人信息的研究与调查，开始之前都应经伦理审查并获得批准；未经批准不得开展任何实质性采集活动。审查关注目的与社会价值、方案科学性、风险与受益的权衡、对象选择的公平性、知情同意的过程与内容、对弱势群体的保护；**受试者的权益与自主决定权优先于研究的科学价值**。以先开展后补办的方式处理，不符合要求。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为科研实训的教学材料，只说明记录留痕、数据核查与证据评价的要求与逻辑，不构成合规意见、伦理审查结论或统计咨询；具体操作以现行规范与所在机构制度为准。
