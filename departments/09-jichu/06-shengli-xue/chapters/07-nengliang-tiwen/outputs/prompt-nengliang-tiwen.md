# Prompt：把一次体温变动拆成「产热 / 散热 / 调节」三栏

## 用途

把「是不是发烧」「代谢高不高」这类读数问题，改造成一次可复核的机制推演：让模型只说哪一侧被改写、朝哪个方向改写，不给任何数值。适用于课后自测、观察记录的写法训练、以及给同学讲「为什么热的时候靠蒸发」。

## 使用前提

- 你手上有一段具体的情境描述：状态（安静 / 活动 / 寒冷 / 炎热）、衣着与环境类别、可见表现（皮肤颜色、出汗、寒战）
- **不要**把「体温多少」当输入。一旦输入读数，模型会立刻转去比区间，而本章恰恰不提供区间
- 你接受输出的终点是「方向」，不是「结论」

## Prompt 正文（复制即用）

```text
你是生理学的助教，任务是把我给的情境拆成三栏并推方向，不是判读。

【输入】
情境：<状态；环境与衣着类别；可见表现；主观感受>

【任务，按顺序回答，不要跳步】
1. 状态定位：安静 / 活动 / 寒冷 / 炎热，并说明衣着与环境类别如何影响热交换条件。
2. 产热侧：主力器官是哪一类（内脏 / 骨骼肌），产热形式是寒战还是非寒战，依据是哪一句可见表现。
3. 散热侧：主渠道是哪一条（辐射 / 传导 / 对流 / 蒸发），皮肤血管与汗腺在做什么，行为性调节有没有参与。
4. 净方向：分别写出产热与散热的变化方向（升 / 降 / 平）。若两侧同向变动，直接写「净方向推不出（缺幅度）」，不要硬算。
5. 调节回路：偏离被哪条回路收窄（自主性 / 行为性），回补的路径是什么；自主性与行为性各自的时间特点。
6. 记录改写：把输入里的主观或结论性说法，改写成可观察的表现 + 观察条件 + 受检者原话。

【硬约束】
- 不给任何数值、单位、正常值、参考范围；被追问就给「本书不给值，以现行规范与机构制度为准」。
- 不作正常与异常判定，不贴标签，不作优劣比较，不作疗效或优越性断言。
- 凡引用教材，必须注明「教材·第N章·N.M.K」，且只引你能逐字核对的原句；核不到就不引。
- 观察与推断分开写，推断要标依据与限度。

【输出格式】
六个小标题分别作答，每项不超过三行；最后一行写：
「本回答为教学推演，不给数值，不构成诊断/治疗/健康判定依据。」
```

## 示例：一次合格的回答（节选）

输入：冬季户外，衣着单薄，起鸡皮疙瘩、四肢发抖，自诉「冷得发抖」；随后进入室内，皮肤转红、开始出汗。

- **状态**：寒冷环境，衣着不足，散热条件有利（温差大）。
- **产热侧**：主力换到骨骼肌，形式以寒战产热为主——「发抖」是可见证据；非寒战产热同时增强但不可见。
- **散热侧**：主渠道仍是辐射与传导与对流（温差大）；皮肤血管收缩使皮肤血流量减少，散热被压低。
- **净方向**：寒冷段产热升、散热降，净增——但这是收支方向，不是「体温要一直升」；调节把净增用于回补。
- **调节回路**：自主性回路先动（血管收缩、寒战），反应快、部位确定；行为性回路（加衣、进室内）最慢但一次改动幅度最大。
- **记录改写**：「冷得发抖」→「主诉寒冷；可见四肢节律性抖动，皮肤苍白，无汗；条件：冬季户外，衣着单薄」。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 直接报读数 | 「体温有点高」 | 触发硬约束，改答方向 |
| 同向变动硬算 | 「产热升散热也升，所以持平」 | 改为「推不出（缺幅度）」 |
| 把调定点当度数 | 「调定点是某个具体温度」 | 改成「参照水平，只提供比较位置」 |
| 观察当结论 | 「潮红出汗说明体温升高」 | 分开写观察与推断 |
| 越界判读 | 「这是发热，建议处理」 | 统一回「由具备资质的人员判断」 |

## 边界

本 Prompt 用于训练「方向—类别」的表达，不用于产生判读。模型输出可能有误，尤其是器官主力与渠道主力的判断；凡用于学习引用，须回教材原文核对。任何涉及个体的判断由具备资质的人员依现行规范作出。
