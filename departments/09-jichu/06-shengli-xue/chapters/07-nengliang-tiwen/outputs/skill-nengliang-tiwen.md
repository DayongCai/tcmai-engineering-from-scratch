# Skill：能量代谢与体温：把「多少度」换成「哪一侧变了」

## 何时用

- 有人问「这算不算发烧」「代谢高不高」，而你要把问题从读数拉回机制
- 要给一段体温变动（寒战、出汗、皮肤潮红或苍白、活动后发热）找出「哪一侧被改写」
- 要在观察记录里把「看到的表现」与「推断的结论」分开写
- 要给同学解释「为什么高温时蒸发变成主力」这类只有方向、没有幅度的问题

## 三栏表（核心工具）

| 栏 | 内容类别 | 问句 |
|---|---|---|
| 产热侧 | 内脏（安静时为主，肝的代谢水平较高）/ 骨骼肌（活动时为主）/ 寒战产热 / 非寒战产热 | 这一侧是被什么改写的：活动、寒冷、激素状态？ |
| 散热侧 | 皮肤（主）+ 呼吸与排泄（辅）；辐射 / 传导 / 对流 / 蒸发；皮肤血管舒缩、汗腺、行为性调节 | 这一侧的主渠道换了吗：温差还在不在，汗有没有出？ |
| 调节环节 | 外周与中枢温度感受器 → 下丘脑整合 → 效应器官；自主性 vs 行为性；神经 vs 体液 | 偏离靠哪条回路收窄，快的那条还是幅度大的那条？ |

三栏填完，再回答「净方向」。**净方向推不出时，就写推不出**，不要用「大概升了点」补空。

## 执行步骤

```text
1. 先定状态：安静 / 活动 / 寒冷 / 炎热，以及衣着与环境类别
2. 填产热侧：主力是谁，形式是寒战还是非寒战
3. 填散热侧：主渠道是哪条，血管与汗腺在做什么
4. 写净方向：两侧同向变动时，标「推不出（缺幅度）」
5. 写调节：偏离被哪条回路收窄，回补的路径是什么
6. 落地到记录：把观察（皮肤颜色、出汗部位与程度、肌肉张力、原话）与推断分开
```

## 硬约束

- **不给值**：不写代谢率、体温、产热量、散热占比，也不写「正常范围」。本书不给值，这一类问题一律回到现行规范与机构。
- **不做正常与异常判定**：能说「散热侧被改写」，不能说「这是异常」。
- **观察与推断分栏**：记录里只写能直接描述的表现；推断另起一行并标明依据与限度。
- **主力换位优先于占比**：器官会换位、渠道会换位，占比不给——换位已经足够解释绝大多数现象。
- **同向变动拒绝硬算**：产热与散热同向变时，净方向必须判为「推不出」。

## 交付物

1. 一张三栏表（产热 / 散热 / 调节），每栏不超过三行
2. 一句净方向，或一句「推不出（缺幅度）」
3. 一段记录改写：把「发热」改成可观察的表现 + 条件 + 状态
4. 一处边界：本章结论不用于判定个体状态

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 把调定点当具体读数 | 以为教材暗示了某个度数 | 调定点是「比较的位置」，方向可用、幅度不给 |
| 高温时仍说「靠辐射散热」 | 方向推反 | 温差消失后辐射与传导失效，主力换到蒸发 |
| 把「产热升、散热降」读成「体温要升高」 | 得出越冷越热的荒谬结论 | 净增是收支方向，调节把净增用于回补，体温回到参照附近 |
| 同向变动硬算成「持平」 | 拿假设冒充事实 | 标「推不出」，并说明缺的是幅度 |
| 把观察记录当结论 | 练习纸当处方 | 观察与推断分写，不贴标签 |

## 边界

本 Skill 只处理「产热—散热—调节」的类别与方向关系，不涉及任何数值、正常值、诊断与治疗。任何涉及个体的判断须由具备资质的人员依现行规范作出。
