# shenjing-xitong

## 何时使用

- 读生理学第10章（神经系统）之前，想知道这一章到底写了什么、没写什么
- 手上的笔记或讲义里混着数值句（膜电位、阈值、频率、延搁），需要改写成关系句
- 要给神经系统的某一节定层级归属（细胞/组织/器官/系统），并说明为什么
- 复核一段引文的章号节号，确认它可逐字回查

## 不适用

- 需要正常值、参考值、分级标准的场景（本书不给值，必须另立数据层）
- 对个体作正常与异常判定、诊断、预后
- 药理学与外科处理
- 把词频密度当作重要性排序

## 步骤

1. **定章规模**：跑 `node code/main.js`，确认 4 节 12 小节 20,576 字，数值型 0，27 个数字全是列表序号。
2. **看两套口径**：三视角（代谢 22 / 机能 520 / 形态 160）与四层级（细胞 20 / 组织 0 / 器官 15 / 系统 122）。
3. **找密度差**：10.1 到 10.4 的密度逐节走低（58.1 → 44.7 → 41.4 → 23.8）；最密是 10.2.2 中枢抑制（73.6），最疏是 10.4.1 大脑皮层的生物电活动（5.8）。
4. **改写成关系句**：把每个「多少」换成「谁作用于谁、往哪个方向变、受什么限制」，五条常见转写见 docs 第五节。
5. **标层级**：能落到细胞就说细胞；落到系统就说系统；「组织」层按词表计 0，遇到神经节、神经束要注明是词表外写法。
6. **核引文**：引文写成 `教材·第N章·N.M.K`，逐字回查 `standards/shengli/底本.json`（或 units.json 的 body）。
7. **声明边界**：结尾明写「本书不给值」与「不构成诊断依据」。

## 输出模板

```text
【规模】4 节 12 小节 20,576 字 · 数值型 0
【口径】三视角 机能 520 / 形态 160 / 代谢 22；四层级 系统 122 / 细胞 20 / 器官 15 / 组织 0
【本节定位】10.x.y 标题 · 密度 x.x · 落在哪一层
【关系句】……（谁作用于谁、方向、限制条件）
【改写】原数值句 → 关系句
【出处】教材·第10章·N.M.K + 可回查引文
【边界】本书不给值；不作正常与异常判定
```

## 质量判据

- 输出的每一句都能回答「谁作用于谁、往哪个方向变」
- 没有出现「数字＋计量单位」，也没有出现正常值、参考值、分级标准
- 层级归属有依据，词表外写法被显式标注
- 引文与 locator 一致且逐字可查
- 结尾有边界声明，而不是「详见教材」

## 常见错误

1. **把密度当重要性**：10.4.1 密度最低，是因为通篇讲波形类别与记录条件，不是脑电不重要。
2. **把组织层 0 当内容缺席**：这是词表口径，神经节与神经束不进层级命中。
3. **自己补值**：缺值不是缺陷，是取舍；补进去的值会与书里的关系句对不上。
4. **用「底本」「原文」引书**：有教材底本的学科，引文就是教材正文，写成 `教材·第N章·N.M.K`。
5. **把抑制理解成活动停止**：抑制是让兴奋被限制在适当范围内的那一半机制，两者同时存在并相互制约。
