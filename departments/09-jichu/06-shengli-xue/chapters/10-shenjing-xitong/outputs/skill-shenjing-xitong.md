# 神经系统：全章最密的一节不是电，是抑制

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 机能是主轴
- 层级落在系统与细胞两端
- 「组织」层是 0
- 后两节不是写得少，是写得「不落在词表上」
- 最该逐句读的是抑制那一节
- 没有并进主题的小节，在这里也必须有位置

## 边界

- **边界声明：本书不给值。** 膜电位、阈电位、传导速度、突触延搁、放电频率、脑电波幅与节律，一个都不写；正常值与参考值也不写。这不是遗漏，是这本书的取舍：它只写类别与关系。任何需要正常值的场景（判读、分级、报告）都必须另立数据层，不能从这一章推。
- 「组织」命中 0 是**词表口径**，不是内容缺席。词表见 `scripts/build_shengli_text.py` 的 `VIEWS` / `LEVELS`；「神经节」「神经束」「皮质分层」这类写法不进层级命中。拿 0 去断言「本书不讲组织层」是过度解读。
- 密度高低**不是重要性排序**。10.4.1 密度最低，是因为它通篇在讲波形类别与记录条件，本就很少落在三视角与四层级的词上；这不等于脑电不重要。
- 本章内容用于教学，不构成诊疗或执业意见。
