# Prompt：把「因为有调节」拆成一条回路

## 用途

生理学里最容易被糊过去的答案是「因为有调节」。这个模板把这句话逼到回路上去：先定受控量，再找感受、传入、整合、传出、效应五个环节，最后判反馈类型与时点。适用于课堂讨论前的自检、写实验报告前的机制梳理，以及读后续各章（循环、呼吸、排泄、内分泌）时反复套用。

## 使用前提

- 你有一个具体的**现象**，而不是一个病名。例：「从卧位站起时没有出现头晕」「进食后消化活动提前启动」「分娩一旦发动就会持续到结束」。
- 你已经读过教材对应小节，手边有教材·第N章·N.M.K 的定位。
- 你接受一条硬约束：**本模板不产出任何数值**。

## Prompt 正文（复制即用）

```text
你是生理学的助教。任务不是解释「为什么」，而是把一个现象拆成一条可检查的调节回路。

【输入】
现象：<一句话描述，不带病名，不带判断>
教材定位：<教材·第N章·N.M.K>

【任务，按顺序回答，不跳步】
1. 受控量：被稳住的到底是哪一个条件？（例：某类物质的浓度、渗透压、酸碱度、温度、压力）
2. 调定点：这个条件的「适宜水平」在哪一侧？说明它存在、可被重设；不要给具体数值。
3. 感受环节：谁在感受偏离？感受的是「高了」还是「低了」，还是两者都感受？
4. 传入与整合：信号经哪条通路到中枢？中枢是整合点还是仅仅中继？
5. 传出与效应：指令经哪条通路传出，效应器做出什么动作，动作把受控量往哪个方向推？
6. 反馈判定：这是负反馈还是正反馈？依据是「把偏差改小」还是「把已开始的进程推向完成」。
7. 前馈检查：在这个现象里，有没有在干扰出现之前就启动的安排？如果有，依据的是什么信息？
8. 反查：如果环节 3 或环节 5 失效，现象会变成什么样？给出可观察的差别，不要给数值。

【硬约束】
- 不给任何数值、单位、正常值与参考范围。凡需要数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。也不要给百分比。
- 不作正常与异常的判定，不作诊断，不作疗效断言。
- 引教材原文必须逐字，并标「教材·第N章·N.M.K」；核不到就不引。
- 若现象描述不足以定受控量，直接说缺哪一项，不要猜。

【输出格式】
八个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的拆解（节选）

现象：从卧位站起时没有出现头晕。教材定位：教材·第1章·1.3.1。

- **受控量**：脑部的血液灌注条件（由压力与血管阻力共同决定的那一类条件）。
- **调定点**：灌注条件需要维持在「足够」的一侧；具体水平本书不给值。
- **感受**：循环系统内的压力感受装置感受「偏离适宜水平」，对升高与降低都敏感。
- **传入与整合**：信号传入中枢，中枢不是中继，而是把多路信息合成一个指令。
- **传出与效应**：指令经传出通路到达心脏与血管，心率与血管张力同时改变，把灌注条件往上推。
- **反馈判定**：负反馈——偏差被改小，条件回到适宜一侧。
- **前馈检查**：体位改变之前，肌肉活动与呼吸已经先有变化，这是前馈；依据的是「即将发生的动作」这一信息。
- **反查**：若感受环节失效，站起时不会出现及时的代偿，现象表现为「站起后不适」，而躺下后缓解——这是可观察的差别，不需要数值。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 用病名代替现象 | 「这是体位性低血压」 | 重填现象，只写可观察的动作与结果 |
| 受控量写成器官 | 「受控量是心脏」 | 改成「被稳住的条件」，器官是执行者不是受控量 |
| 把正反馈当更高级 | 「正反馈调节更强」 | 追问「它把进程推向完成还是把偏差改小」 |
| 偷给数值 | 「正常范围是……」 | 触发硬约束，改为「本书不给值」 |
| 跳过前馈 | 只答反馈 | 追问「干扰出现之前有没有提前安排」 |

## 边界

本模板训练的是「把调节写成回路」的表达能力，不产生临床判断。回路结构来自教材的类别与关系，参数不在本书范围内；任何涉及个体的评估须由具备资质的人员依现行规范作出。
