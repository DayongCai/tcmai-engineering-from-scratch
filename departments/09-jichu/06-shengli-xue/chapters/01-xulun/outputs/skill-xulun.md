# Skill：绪论——研究对象、三个水平与调节框架

## 何时用

- 有人（包括你自己）用一个「调节」把现象糊过去了，需要拆开
- 要在循环、呼吸、排泄、内分泌各章之间迁移同一套回路语言
- 要判断一段生理学叙述「越了几层」：把细胞层的话直接说成整体表现
- 遇到「正常值是多少」这类追问，需要一套一致的拒答口径

## 核心判据（四问）

1. **受控量是什么？** 被稳住的必须是「一个条件」，不是器官。答成器官，说明还在讲执行者。
2. **偏差往哪边改？** 改小是负反馈，推向完成是正反馈。答不出方向，说明回路没闭合。
3. **这件事发生在哪一层？** 细胞与分子 / 器官与系统 / 整体。跨层解释必须交代中间层，否则是跳跃。
4. **有没有前馈？** 在干扰出现之前就启动的安排，依据的是「对即将发生情况的判断」。有前馈而无反馈，系统会漂；有反馈而无前馈，系统总是慢一步。

## 执行步骤

```text
1. 抄现象，不抄病名：写「站起时没有不适」，不写「体位性低血压」
2. 定受控量：一个条件，一句话
3. 定调定点侧：只说在哪一侧、可被重设，不给数值
4. 走五环节：感受 → 传入 → 整合 → 传出 → 效应，逐环落到具体结构类别
5. 判反馈类型：负 / 正，并说出依据（改小偏差 / 推向完成）
6. 查前馈：干扰出现前有没有提前安排，依据什么信息
7. 反查断点：抽掉某一环，现象会怎样变（给可观察差别，不给数值）
```

## 硬约束

- **不给数值、单位、正常值、参考范围、百分比。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不判正常与异常。** 回路能说明「怎样被稳住」，不能说明「某人现在是否异常」。
- **引文逐字。** 标「教材·第N章·N.M.K」，核不到就不引；不许把教材里的学科对话当成古籍引文。
- **层次标注。** 每一条结论都要能回答「这在哪一层」，跨层必须补中间环节。

## 交付物

1. 一条回路（受控量 → 感受 → 整合 → 效应 → 回到受控量）
2. 一句类型判定：负反馈 / 正反馈 / 前馈参与
3. 一处断点假设：哪一环失效会怎样
4. 一处边界：本章不给值，数值须另立数据层

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 受控量写成器官 | 回路闭合不了，只剩「心脏在调节」 | 改成条件：压力、渗透压、温度、浓度 |
| 正反馈当「更强」 | 把一次性进程误当日常稳定机制 | 看它「改小偏差」还是「推向完成」 |
| 跨层直推 | 用单通道行为解释整体表现 | 补上器官与系统两层 |
| 用调节替代机制 | 五环节答不出三环 | 逐环落到结构类别 |
| 被追问就报数值 | 越出本书口径，且数值无来源 | 统一回「本书不给值，另立数据层」 |

## 与相邻章节的接缝

- 下一章（细胞的基本功能）：把「细胞层」讲实——跨膜转运、信号转导、电活动、收缩，是本章回路在细胞尺度的实现。
- 再下一章（血液）：把「内环境」讲实——血液是细胞外液里被运输的那一部分。
- 全书：本章的回路语言在循环（压力调节）、呼吸（气体与酸碱）、排泄（水盐平衡）、内分泌（轴系反馈）四章反复复用。

## 边界

本 Skill 只处理「现象 → 回路」的结构化表达，不涉及数值、判定与临床决策。任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
