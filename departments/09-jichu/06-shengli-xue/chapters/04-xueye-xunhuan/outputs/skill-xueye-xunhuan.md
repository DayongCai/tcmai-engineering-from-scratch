# Skill：血液循环：泵血·血管·调节·器官循环

## 何时用

- 看到一个循环现象（心音、脉搏、体位改变后的头晕、某器官供血随心动周期变化），要说出它改的是**压差**还是**阻力**
- 要把任一心动瞬间判断到时相，并说明此刻哪组瓣膜在动、容积往哪边走
- 要解释「为什么某一调节因素在这个器官升高血压、在那个器官降低阻力」
- 要把一批生理学事实整理成可对账的结构，而不是一串要背的结论

## 核心判据（三问）

1. **压差还是阻力？** 血液的方向只由压差决定，流量只由压差除以阻力决定。凡是调节，最终都落在两项之一：改泵造压差的能力，或改血管口径改阻力。说不清改的是哪一项，说明还停在背结论。
2. **哪个瓣膜在动？** 时相不看时间长短，看瓣膜启闭。但瓣膜状态只有三种组合而有四个时相——两个「关关」必须再用「收缩期还是舒张期」区分。容积方向是推论，不是输入。
3. **这个器官要解决什么问题？** 同一因素在不同器官可以方向相反：低氧使体循环血管舒张、使肺血管收缩，因为肺要的是通气与血流的匹配。方向由目的决定，不由刺激决定。

## 执行步骤

```text
1. 写下现象，不改写成病名（例：心室收缩时冠脉血流减少）
2. 定位到环节：改的是压差（灌注压）、阻力（口径）、还是泵的能力（收缩力/心率）
3. 定时相：房室瓣 / 动脉瓣 / 收缩期或舒张期 → 时相 → 容积方向（校验用）
4. 查结构：该血管壁里什么成分多（弹性、平滑肌、单层内皮、容量）→ 推出它管什么
5. 查时间尺度：这个调节是秒级（神经）、分到小时（体液）、连续局部（自身），还是长期（体液容量与肾）
6. 反查边界：这个机制在什么条件下失效（不应期的保护、自身调节的限度、负反馈的适应）
```

## 硬约束

- **不给值。** 不写压力、容积、时程、血流量的数值与单位，也不写正常值与参考值。需要数值的场合另立数据层，不从本章的类别推。
- **「形成条件」与「影响因素」不许混表。** 血液充盈、心脏射血、外周阻力、大动脉弹性是形成条件；每搏输出量、心率、外周阻力、弹性、循环血量与血管容积的匹配是影响因素。神经调节属于影响层面，不是形成条件。
- **容积方向必须由瓣膜状态推出。** 允许把「等容收缩期容积下降」写出来的模型是坏模型，必须报错。
- **薄层不等于不重要。** 词频低的层级可能只是因为那一版把它压在一节里讲（本章组织层就集中在微循环与组织液一节）。
- **数字必须能对账。** 单元数、字数、三视角与四层级的加总都要能由程序复算；对不上就报错，不写「约」。

## 交付物

1. 一张时相表：时相 / 房室瓣 / 动脉瓣 / 压力方向 / 容积方向
2. 一张血管表：区段 / 功能类别 / 结构依据
3. 一句对账：三视角加总与四层级加总各自等于分项之和
4. 一处边界：本章只到类别与方向，不给值，不构成诊断依据

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 把收缩期当成「一切都在工作」 | 推出「收缩期冠脉供血最多」的相反结论 | 冠脉被心肌挤压，供血主落在舒张期 |
| 只凭瓣膜状态定时相 | 等容收缩与等容舒张混为一谈 | 再加「收缩期还是舒张期」一维 |
| 把容积当独立输入 | 出现「等容而容积变化」的自相矛盾 | 容积方向由瓣膜状态推出并校验 |
| 用「低氧扩血管」套所有器官 | 肺循环方向判反 | 先问该器官要解决什么问题 |
| 把神经调节写成血压形成条件 | 范畴错误，后续推理全偏 | 形成四项与影响五项分表 |
| 用心率乘每搏当机制 | 只是恒等式，解释不了「过快反而减少」 | 走「心率快→舒张期短→充盈不足」这条链 |

## 边界

本 Skill 只处理「压差—阻力—时相」这一层的机制判断，不涉及任何数值、正常值或临床决策。任何关于个体状态的判断须由具备资质的医务人员作出。
