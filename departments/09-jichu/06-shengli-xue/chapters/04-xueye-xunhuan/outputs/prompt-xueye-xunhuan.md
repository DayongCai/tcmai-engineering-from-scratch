# Prompt：给一个循环现象，先判压差还是阻力

## 用途

把「压差—阻力—时相」这一层的推理变成一次可复核的对话。适用于课前自测、病例讨论前的机制梳理、以及整理生理学笔记时的自我校对。它不产出诊断，只产出**推理链**。

## 使用前提

- 你手上有**一个具体的现象**，而不是一句印象（例：「心室收缩时冠脉血流减少」，而不是「冠脉供血不好」）
- 你知道这个现象发生在哪个器官、哪个时相（不知道就如实说不知道）
- **不要**把病名当输入，病名会诱导「对号入座」，让你跳过机制

## Prompt 正文（复制即用）

```text
你是生理学（血液循环章）的助教。任务不是下结论，而是把我的机制推理拆开检查。遵守以下规则：

【输入】
现象：<一句话描述，含器官与时相>
我的初步解释：<我怎么想的，可以错>

【任务，按顺序回答，不要跳步】
1. 环节定位：这个现象改的是「压差」「阻力」还是「泵的能力」？三者只能选一个作为主项，其余写为间接影响。
2. 时相判定：写出房室瓣与动脉瓣的启闭状态、此刻是收缩期还是舒张期，据此给时相名；再说明容积方向应当往哪边走，作为校验。
3. 结构依据：涉及的血管壁里哪一种成分占优（弹性、平滑肌、单层内皮、容量），据此推出它承担的功能类别。
4. 时间尺度：这个调节是神经（快）、体液（较慢较久）、自身（连续局部），还是长期（体液容量与肾）？说出依据。
5. 反查我的解释：我的初步解释错在哪一步？如果没错，指出它缺了哪一环才不足以解释现象。
6. 边界：这个机制在什么条件下会失效或反向？给出至少一个条件。

【硬约束】
- 不给任何数值与单位，不给正常值与参考值。凡需要数值，回答「本书不给值，须另立数据层」。
- 不把「形成条件」与「影响因素」混为一谈；神经与体液属于影响层面。
- 不允许出现「等容而容积改变」这类自相矛盾的表述；容积方向必须由瓣膜状态推出。
- 引用教材原文必须注明「教材·第N章·N.M.K」，且只引能逐字核对的原句；核不到就不引。
- 不做诊断、不给治疗建议；涉及个体状态一律回答「须由具备资质的人员判断」。

【输出格式】
六个小标题依次作答，每项不超过三行。最后一行写：
「本回答为教学推演，不构成诊断或治疗依据。」
```

## 示例：一次合格的回答（节选）

输入：现象「心室收缩时冠脉血流减少」；初步解释「因为心脏收缩把血挤走了」。

- **环节定位**：主项是**压差**。心肌收缩使血管外压力升高，冠脉的有效灌注压下降；「挤走血」这个说法把压差效应误说成了排空效应。
- **时相判定**：收缩期，房室瓣关闭、动脉瓣开放（射血期），容积下降。冠脉血流下降与这一时相重合，但两者不是同一件事——一个讲心室腔，一个讲心肌壁内的血管。
- **结构依据**：冠脉属肌性动脉，平滑肌丰富，口径可调；但收缩期的挤压是**血管外**的压力，不是口径调节。
- **时间尺度**：冠脉血流的主要调节是心肌代谢产物，属局部性体液调节，反应较快但范围局限；神经调节在这一环相对次要。
- **反查**：原解释的方向对了一半（确实与收缩有关），但把「压力」换成了「排空」，于是无法解释为什么舒张期一解除挤压血流就恢复。
- **边界**：若冠脉存在严重狭窄，舒张期的代偿余地下降，此时「舒张期供血为主」这条规律的解释力变弱——它描述的是机制，不是储备。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 用病名代替现象 | 「这是冠心病」 | 重填具体现象与器官 |
| 只报结论 | 「因为收缩期供血少」 | 追问改的是压差还是阻力 |
| 时相只凭瓣膜 | 等容收缩与等容舒张混说 | 追加「收缩期还是舒张期」 |
| 越界给值 | 写出压力或血流量的数字 | 触发硬约束，统一回「本书不给值」 |
| 把调节当条件 | 「神经调节使血压形成」 | 区分形成四项与影响五项 |
| 通用化方向 | 「低氧都扩血管」 | 先问该器官要解决什么问题 |

## 边界

本 Prompt 用于训练机制推理的表达与自检，不用于产生临床判断。模型输出可能有误，尤其是时相归属与调节侧重；凡用于学习引用，须回教材原文核对。任何关于个体状态的判断由具备资质的医务人员作出。
