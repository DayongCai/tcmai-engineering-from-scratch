# Prompt：把血液问题拆成「三枚齿轮 + 一张判定表」

## 用途

血液这一章在临床语境里最容易被数字淹没：计数、浓度、时间、效价。这个模板把注意力从数字拉回结构：止血问「建网、限网、拆网哪一环出了问题」，输血问「供者抗原与受者抗体哪一对配上了」。适用于输血前的机制自检、出凝血问题的思路梳理，以及把血液章与循环章接起来。

## 使用前提

- 你手上是一个**机制问题**，不是一个化验数。例：「为什么这个人的出血不容易止」「为什么这两种血不能输」。
- 你已读过对应小节，能给出教材·第N章·N.M.K 的定位。
- 你接受硬约束：**本模板不产出任何数值**（计数、浓度、时间、效价一律不给）。

## Prompt 正文（复制即用）

```text
你是生理学的助教。任务不是解释一个数，而是把问题拆成结构：止血拆成三枚齿轮，输血拆成一张判定表。

【输入】
问题：<一句话，指向一个机制，不带化验数值>
教材定位：<教材·第N章·N.M.K>

【任务，按顺序回答，不跳步】
1. 归类：这个问题属于——组成与理化 / 血细胞 / 止血 / 血型与输血？
2. 结构：承担这一环的成分是哪一类（血浆蛋白的类别、血细胞的类别、凝血相关的物质类别、膜上的抗原类别）？
3. 齿轮定位（止血类必答）：建网、限网、拆网，问题落在哪一枚？另外两枚是否被牵连？
4. 方向与顺序：反应往哪个方向走、先后次序如何、哪一步是放大、哪一步是限速？
5. 判定（输血类必答）：供者抗原与受者抗体的配对关系是什么？配 / 不配，用布尔表述，不用效价。
6. 对照：把「同型」与「相容」分开说——同型只覆盖哪一层，相容还要核验哪一层？
7. 边界：这个问题里有哪些部分必须靠数值才能回答（计数、浓度、时间、效价）？列出并声明「本书不给值，需另立数据层」。

【硬约束】
- 不给数值、单位、正常值、参考范围、百分比，也不给「大约」「偏高偏低」这类依赖阈值的判断。
- 不作正常与异常的判定，不作诊断，不作输血或用药建议。
- 引教材原文必须逐字，标「教材·第N章·N.M.K」；核不到就不引。
- 若问题本身依赖一个数值阈值（例如「这个数算不算低」），直接说明「本书不给值，无法判定」，不要绕。

【输出格式】
七个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的拆解（节选）

问题：某人的出血不容易止住，可能是哪一环的问题？教材定位：教材·第3章·3.3.1。

- **归类**：止血。
- **结构**：血浆中的凝血相关物质、血管与血小板、以及纤维蛋白溶解系统的成分。
- **齿轮定位**：先在「建网」这一枚。若网建不起来，表现为持续渗血；若网建起来了却很快被拆，表现为「止住又出」。两者可观察的差别正是齿轮定位的依据。
- **方向与顺序**：凝血是级联——上游激活下游、一步放大一步，最终把可溶的纤维蛋白原变成不溶的纤维蛋白网。限速不在最后一步，而在放大链的入口。
- **牵连**：「限网」若失效，凝血不会停在受损部位，问题从「止不住」变成「不该凝的地方也凝」。同一症状的两个方向，靠齿轮分辨。
- **边界**：需要数值才能回答的是「缺到何种程度」「反应有多快」，本书不给值，需另立数据层并结合规范判读。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 一上来报数字 | 「血小板低了」 | 先答齿轮定位，数值留给数据层 |
| 凝集与凝固混用 | 「输血引起凝固反应」 | 输血反应是凝集（抗原抗体），止血是凝固（酶促级联） |
| 只答「凝血亢进 / 低下」 | 停在方向，不进齿轮 | 追问「建、限、拆哪一枚」 |
| 把同型当相容 | 「同型就一定安全」 | 分开说：同型覆盖 ABO，相容还要逐例核验 |
| 用效价代替判定 | 「效价很高所以不合」 | 判定是布尔：配对即不合 |

## 边界

本模板训练「机制拆解」的表达，不产生临床判断。齿轮划分与判定表是教学表达；计数、浓度、时间、效价一律不在本书范围内。任何输血、配血、抗凝或止血处置，须由具备资质的人员依现行规范与机构制度实施。
