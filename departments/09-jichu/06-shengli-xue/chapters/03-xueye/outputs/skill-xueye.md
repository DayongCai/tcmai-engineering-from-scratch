# Skill：血液——三枚齿轮与一张判定表

## 何时用

- 遇到「出血止不住」「不该凝的地方凝了」这类机制问题，需要定位环节
- 要回答「同型血为什么还要交叉配血」
- 要把血浆与血清、凝集与凝固、晶体与胶体这些成对概念分开
- 被追问计数、浓度、凝血时间、效价时，需要一致口径

## 核心判据（四问）

1. **落在哪一节？** 组成与理化 / 血细胞 / 止血 / 血型与输血。四节各管一件事，先归位再推理。
2. **哪一枚齿轮？** 建网（凝血）、限网（抗凝）、拆网（纤维蛋白溶解）。答不出齿轮，说明还停在「凝血功能好坏」这种笼统判断上。
3. **是集合差还是量差？** 血浆与血清、凝集与凝固，都是「成分或机制不同」，不是「多少不同」。误当量差就会去要数值。
4. **判定还是测量？** 血型相容是布尔判定（配 / 不配），效价才是测量。输血问题先用判定回答。

## 执行步骤

```text
1. 归类到四节之一
2. 止血类：定位齿轮（建 / 限 / 拆），并检查另外两枚是否被牵连
3. 写方向与顺序：级联的方向、放大点、限速点
4. 输血类：写抗原—抗体配对表，给配 / 不配
5. 分开「同型」与「相容」：同型覆盖哪一层，相容核验哪一层
6. 对照可观察差别：齿轮失灵时现象怎么变（渗血 / 扩散 / 留栓）
7. 列边界：哪些问题必须靠数值，声明另立数据层
```

## 硬约束

- **不给数值、单位、正常值、百分比。** 细胞计数、血红蛋白浓度、凝血时间、抗体效价一律不给。
- **不判正常与异常。** 「这个数算不算低」统一回「本书不给值，无法判定」。
- **不作输血与用药建议。** 输血、配血、抗凝处置由具备资质的人员依现行规范实施。
- **成对概念必须分开。** 凝集≠凝固、血浆≠血清、晶体渗透压≠胶体渗透压、同型≠相容。
- **引文逐字。** 标「教材·第N章·N.M.K」，核不到就不引。

## 交付物

1. 一次归位（四节之一）
2. 一次齿轮定位（止血类）或一张配对表（输血类）
3. 一组可观察差别（三枚齿轮失灵各自的表现）
4. 一处边界（哪些问题必须靠数值）

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 用「凝血功能差」代替齿轮 | 无法区分渗血与留栓 | 定位建 / 限 / 拆 |
| 凝集与凝固混用 | 输血反应被解释成止血 | 抗原抗体 vs 酶促级联 |
| 血浆当血清 | 成分差被抹掉，推理失去起点 | 差在纤维蛋白原 |
| 同型当相容 | 忽略 ABO 之外的血型系统 | 同型覆盖一层，相容逐例核验 |
| 被追问就报数值 | 越出本书口径且数值无来源 | 统一回「本书不给值」 |

## 边界

本 Skill 只处理「血液机制的结构化表达」，不涉及数值判读与临床处置。任何输血、配血、抗凝或止血决策，须由具备资质的人员依现行规范与机构制度作出。
