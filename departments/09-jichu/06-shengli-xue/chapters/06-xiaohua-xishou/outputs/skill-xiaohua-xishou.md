# Skill：消化和吸收：分泌·运动·吸收与调节

## 何时用

- 听到一句描述（「吃点东西就胀」「吃了油的就不舒服」「吃完就想上厕所」），要把它放回**分泌、运动、吸收**三段里的某一段
- 被问到「为什么脂肪排空最慢」「为什么胃不消化自己」「为什么吃肉不会立刻升血糖」这类**次序题与去向题**
- 要判断一个反应是局部反射、外来神经还是激素在起作用
- 要解释胆汁、胰液、胃液各自的「作用边界」

## 核心判据（四问）

1. **哪一段？** 分泌（消化液够不够、成分对不对）、运动（搅拌与推进是否配合）、吸收（面积、时间、运走是否到位）。三段互相供给，但缺的方式不同。
2. **谁先谁后？** 本章大量结论是次序：胃排空液体→糖类→蛋白质→脂肪；酶原激活肠激酶→胰蛋白酶→其余。次序答错，机制就反。
3. **走哪条路？** 吸收产物两条去向：糖、蛋白质、无机盐、水走血液（先过肝）；脂类与脂溶性维生素走淋巴（绕过肝）。途径两条：跨细胞与旁细胞。
4. **哪一层在调？** 局部反射（快、局限、可独立完成）、外来神经（调节内在神经系统的活动水平）、激素（较慢、较持久）。三层同时工作，但要能指认主项。

## 执行步骤

```text
1. 写下现象，不改写成病名（例：进食油腻后上腹不适）
2. 定段落：分泌 / 运动 / 吸收，只能选一个作为主项
3. 判次序：若涉及排空或激活，先排出次序，再看哪一环被拖慢
4. 判去向：若涉及吸收，先分血液还是淋巴，再谈后续代谢
5. 查调节层次：局部 / 外来神经 / 激素，并说明为什么主项是它
6. 反查边界：这个判断在什么条件下失效（黏膜完整性、括约肌功能、通路受阻）
```

## 硬约束

- **不给值。** 不写分泌量、排空时间、酶活性、浓度的数值与单位，也不写正常值。需要数值另立数据层。
- **两处方向陷阱必须标死。** 其一，交感对唾液是「促进但变黏稠」，不是抑制；其二，胆汁不含消化酶，作用是物理性的乳化与运载。
- **次序不可颠倒。** 胃排空脂肪最慢；胰蛋白酶原的激活必须由肠激酶起步。凡把脂肪写成最快、把胰蛋白酶写成「自己先活化」的，即为错误。
- **三层调节不许压成一层。** 外来神经只调节内在神经系统的活动水平，不直接支配每一个效应细胞；切断外来神经消化道不会停摆。
- **首过效应是去向的推论，不是独立知识点。** 先判血液还是淋巴，再谈是否先过肝。

## 交付物

1. 一句定段落：分泌 / 运动 / 吸收
2. 一条次序或一条去向：排空次序、激活次序、血液或淋巴
3. 一层调节：指出主项是局部、外来神经还是激素
4. 一处边界：这个判断在什么条件下失效

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 把「腹胀」一律归成「消化不好」 | 段落不清，无法定位 | 先分分泌/运动/吸收 |
| 认为交感抑制唾液分泌 | 方向反，后续推论全错 | 交感促进但变黏稠 |
| 认为胆汁靠酶消化脂肪 | 胆汁的作用被误解为化学性的 | 无酶，靠乳化与微胶粒 |
| 把慢波当动作电位 | 无法解释「节律固定而力度可变」 | 慢波定节拍，动作电位定力度 |
| 说外来神经直接支配每个效应细胞 | 忽略肠神经系统的独立性 | 只调活动水平 |
| 把脂肪排在排空次序的最前 | 与反馈性调节相反 | 脂肪最慢，小肠在踩刹车 |
| 用血糖变化解释所有吸收 | 忽略淋巴途径绕过肝 | 先判去向再谈代谢 |

## 边界

本 Skill 只处理消化三段的机制判断、次序与去向，不涉及任何数值、正常值或临床决策。任何关于个体状态的判断与进食、用药安排须由具备资质的医务人员作出。
