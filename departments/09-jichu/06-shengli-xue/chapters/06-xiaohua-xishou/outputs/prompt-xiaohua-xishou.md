# Prompt：把一句消化道描述翻译成三段机制

## 用途

把「分泌—运动—吸收」三段框架变成一次可复核的对话。适用于课前自测、问诊表述的机制翻译、以及整理消化生理笔记时的自我校对。它只产出推理链，不产出诊断。

## 使用前提

- 你手上有**一句具体的描述**，而不是一个病名（例：「进食油腻后上腹不适」，而不是「胆囊炎」）
- 你知道这句话发生在什么时间（进食前、进食中、餐后、空腹），不知道就如实说
- **不要**把病名或证型名当输入。它们会诱导「对号入座」，让你跳过段落定位

## Prompt 正文（复制即用）

```text
你是生理学（消化和吸收章）的助教。任务不是下结论，而是把我的机制推理拆开检查。遵守以下规则：

【输入】
描述：<一句话，含时间与情境>
我的初步解释：<我怎么想的，可以错>

【任务，按顺序回答，不要跳步】
1. 定段落：这句话落在分泌、运动、吸收的哪一段？只能选一个作为主项，其余写为继发影响，并说明为什么主项是它。
2. 判次序：若涉及排空或酶原激活，先写出正确的次序，再看描述里的现象是哪一环被拖慢或提前。
3. 判去向：若涉及吸收，先分「血液还是淋巴」，再谈是否先过肝。
4. 查调节层次：这个环节受局部反射、外来神经、激素中的哪一层主导？说明理由。外来神经只写「调节内在神经系统的活动水平」，不许写「直接支配每个效应细胞」。
5. 反查我的解释：错在哪一步？若没错，指出它缺哪一环才不足以解释现象。
6. 边界：这个判断在什么条件下会失效？至少给一个条件（黏膜完整性、括约肌功能、通路受阻等）。

【硬约束】
- 不给任何数值与单位，不给正常值与参考值。需要数值时回答「本书不给值，须另立数据层」。
- 胃排空的次序必须写成「液体 → 糖类 → 蛋白质 → 脂肪」；把脂肪写成最快即为错误，须重答。
- 胆汁不含消化酶，其作用是乳化与形成混合微胶粒；不许写成「胆汁靠酶消化脂肪」。
- 交感对唾液是促进分泌但使性状偏黏稠，不许写成抑制。
- 引用教材原文必须注明「教材·第N章·N.M.K」，且只引能逐字核对的原句；核不到就不引。
- 不做诊断、不给饮食或用药建议。

【输出格式】
六个小标题依次作答，每项不超过三行。最后一行写：
「本回答为教学推演，不构成诊断或治疗依据。」
```

## 示例：一次合格的回答（节选）

输入：描述「进食油腻食物后上腹饱胀、持续较久」；初步解释「消化不好，胃没力气」。

- **定段落**：主项是**运动**（排空），但启动原因是**分泌与肠段反馈**——脂类对十二指肠的刺激最强，经促胰液素与胆囊收缩素等途径抑制胃运动与排空。所以「胃没力气」把因果说反了：不是胃弱，是小肠在踩刹车。
- **判次序**：液体 → 糖类 → 蛋白质 → 脂肪。脂肪排在最后，正是这条反馈的结果，不是「脂肪难磨」这么简单。
- **判去向**：脂类吸收产物以淋巴途径为主（乳糜微粒经中央乳糜管），绕过肝直接入体循环。这与饱胀感无直接关系，但说明「油腻」这件事在吸收端也走了一条不同的路。
- **查调节层次**：主项是**激素**（促胰液素、胆囊收缩素），并叠加壁内神经丛的局部反射；外来神经参与但不是主项。
- **反查**：原解释的方向错在「胃弱」——现象是排空被抑制，抑制是主动的反馈，不是被动的不作为。
- **边界**：若括约肌功能或黏膜完整性受损，这条「反馈性抑制」的解释力下降，此时不能只谈生理性反馈。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 用病名代替描述 | 「这是胆囊炎」 | 重填具体描述与时间 |
| 段落不清 | 「消化不好」 | 先分分泌/运动/吸收 |
| 次序记反 | 「脂肪排空最快」 | 重排：液体→糖→蛋白→脂肪 |
| 把胆汁当酶 | 「胆汁分解脂肪」 | 无酶，靠乳化与微胶粒 |
| 把交感写成抑制唾液 | 「紧张就不分泌唾液」 | 促进但变黏稠 |
| 把三层调节压成一层 | 「神经控制一切」 | 局部/外来神经/激素分层 |
| 越界给值 | 写出分泌量或时间的数字 | 触发硬约束，统一回「本书不给值」 |

## 边界

本 Prompt 用于训练消化三段的机制推理与次序、去向判断，不用于产生临床判断。模型输出可能有误，尤其是段落归属与调节层次；凡用于学习引用，须回教材原文核对。任何关于个体状态的判断、饮食与用药安排，由具备资质的医务人员作出。
