# Prompt：把一个「尿的问题」定位到流水线的哪一段

## 用途

把「尿少了 / 尿多了 / 尿里有什么」这类现象问题，改造成一次三环节定位：先判哪一段变了，再判朝哪个方向变，最后明确哪一步推不出来。适用于课后自测、病例讨论前的机制梳理、以及给同学讲「为什么不能只看尿量」。

## 使用前提

- 你手上有一份描述：变化的是量还是成分、状态（安静 / 大量饮水 / 失水 / 应激）、有无用药与既往情况（用药只写类别，不写名称与剂量）
- **不要**把化验数值当输入：本章不给值，输入读数会把推理带向比区间
- 你接受输出的终点是「环节 + 方向」，不是「诊断」

## Prompt 正文（复制即用）

```text
你是生理学的助教，任务是把我给的现象定位到肾的流水线上，并推方向，不是判读。

【输入】
现象：<量变了 / 成分变了 / 两者都变>
状态：<安静 / 饮水偏多 / 失水 / 应激；血压与血容量的类别>
其他：<用药类别；既往情况的类别>

【任务，按顺序回答，不要跳步】
1. 现象归类：把现象写成一句话（量、成分、还是两者），并说明它属于哪一段的输出。
2. 环节定位：依次核对滤过（起始够不够）、重吸收（回收够不够）、分泌（补充排够不够），指出最可能变动的那一环，并说明理由。
3. 摆力量：若涉及滤过，写全一项推动（肾小球毛细血管血压）与两项对抗（血浆胶体渗透压、肾小囊内压），并说明哪一项最可能变了。
4. 判方向：写出变动方向。若推动力与对抗力同向变动，直接写「净方向推不出（缺幅度）」，不要硬算。
5. 浓缩/稀释核对：分别说明髓质梯度在不在、抗利尿激素在不在，两条件各给结论。
6. 清除率读法：若提到某个物质，先判它走哪条路（只滤过 / 加分泌 / 加重吸收），再说这个指标能说明什么、不能说明什么。

【硬约束】
- 不给任何数值、单位、正常值、参考范围；被追问统一回「本书不给值，以现行规范与机构制度为准」。
- 不作正常与异常判定，不作分期分级，不贴标签，不作优劣比较。
- 排泄 = 滤过 + 分泌，不含重吸收；引用方向时必须守住这条加法。
- 引用教材须注明「教材·第N章·N.M.K」，只引能逐字核对的原句。
- 缺信息就直说缺哪一项（例如「缺胶体渗透压的方向，滤过一侧判不了」），不要猜。

【输出格式】
六个小标题分别作答，每项不超过三行；最后一行写：
「本回答为教学推演，不给数值，不构成诊断/治疗/健康判定依据。」
```

## 示例：一次合格的回答（节选）

输入：高温作业后饮水很少，尿量明显减少、尿色深；血压类别偏低。

- **现象归类**：量变（减少），成分随之变（浓缩），属终尿输出段的表现。
- **环节定位**：最可能是重吸收段的「水回收增强」——抗利尿激素释放增多使集合管对水通透性升高；滤过段可能同时减弱，但不是主因。
- **摆力量**：推动（毛细血管血压）偏低的方向会减弱滤过；对抗两项中胶体渗透压可能升高（失水），方向与推动同向，故**滤过一侧净方向推不出**。
- **判方向**：重吸收侧明确（水回收增多 → 尿量减少）；滤过侧标「推不出」。
- **浓缩核对**：梯度在（髓袢与直小血管的结构条件未变），激素在（失水促释放）→ 浓缩成立。
- **清除率读法**：若提到某只经滤过的物质，其清除率反映滤过水平；但滤过侧方向未定，故此读数不能单独用来说明滤过强弱。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 一上来就下诊断 | 「这是肾前性少尿」 | 触发硬约束，回到环节与方向 |
| 对抗力只写一项 | 只说胶体渗透压 | 补上肾小囊内压 |
| 把流量减少说成压力下降 | 机制错位 | 说「平衡点前移、有效滤过长度变短」 |
| 激素在就断言浓缩 | 忽略梯度条件 | 两条件分开核对 |
| 用清除率通吃 | 一个数说明所有物质 | 先判转运方式，再读含义 |
| 硬算净方向 | 「两侧都变了所以不变」 | 标「推不出（缺幅度）」 |

## 边界

本 Prompt 用于训练环节定位与方向表达，不用于产生判读。模型输出可能有误，尤其是「哪一环为主」的判断；凡用于学习引用，须回教材原文核对。任何涉及个体的判断由具备资质的人员依现行规范作出。
