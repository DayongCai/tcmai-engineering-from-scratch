# Skill：肾脏的排泄功能——先定位环节，再谈方向

## 何时用

- 有人拿一个现象来问（尿少了、尿多了、尿里出现某种成分），而你要把它落到流水线的某一段
- 要判断「滤过会不会变」，需要把一项推动与两项对抗摆齐
- 要解释浓缩与稀释，而对方把「抗利尿激素多就浓」当成万能句
- 要给清除率定性：这个指标到底在说什么

## 三环节定位表（核心工具）

| 环节 | 转运方向 | 决定它的东西 | 变弱会怎样 |
|---|---|---|---|
| 滤过 | 血液 → 肾小囊 | 有效滤过压（血压 vs 胶体渗透压 + 囊内压）、滤过膜通透性与有效面积、肾血浆流量 | 超滤液减少，后续环节的原料变少 |
| 重吸收 | 小管液 → 血液 | 转运体的分布（选择性）与数量上限（有限性）、激素（醛固酮、抗利尿激素） | 有用物质随尿丢失，尿量相对增多 |
| 分泌 | 血液或上皮细胞 → 小管液 | 转运体、氢钠交换与钠钾交换的竞争、醛固酮 | 该排的排不出去，酸碱与水盐调节受压 |

记住加法：**排泄 = 滤过 + 分泌，不含重吸收**。方向记反一次，后面全反。

## 执行步骤

```text
1. 把现象写成一句话：量变了 / 成分变了 / 两者都变
2. 定位环节：先问「起始环节够不够」（滤过），再问「回收够不够」（重吸收），最后问「补充排够不够」（分泌）
3. 摆力量：滤过一侧必须写全一项推动与两项对抗，漏囊内压是最常见错
4. 判方向：单侧变动可定方向；两侧同向变动写「推不出（缺幅度）」
5. 浓缩/稀释：先问梯度在不在，再问激素在不在，两条件缺一不成立
6. 清除率定性：先问该物质走哪条路（只滤过 / 加分泌 / 加重吸收），再谈这个指标说明什么
```

## 硬约束

- **不给值**：不写滤过率、清除率、尿量、渗透压的数值与参考范围。本书不给值，一律回到现行规范与机构。
- **不作正常与异常判定**：能说「滤过减弱」，不能说「这是肾功能不全」。
- **对抗力必须写两项**：只写胶体渗透压就解释不了尿路受阻。
- **两条件分开判**：梯度是条件，激素是开关，混成一句会得出「激素在就一定浓缩」的错结论。
- **同向变动拒绝硬算**：标「推不出」，并说明缺的是幅度。

## 交付物

1. 一张三环节定位表（环节 / 方向 / 决定因素 / 变弱的后果）
2. 一句方向判断，或一句「推不出（缺幅度）」
3. 一句浓缩/稀释的条件核对（梯度、激素各在不在）
4. 一处边界：本章结论不用于个体状态的判定

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 把排泄当「尿里所有的东西」 | 被完全重吸收的物质被误算成排泄产物 | 排泄 = 滤过 + 分泌 |
| 对抗力只写胶体渗透压 | 尿路受阻影响滤过解释不了 | 加上肾小囊内压 |
| 把「流量少→滤过弱」记成压力变化 | 机制说不通 | 是平衡点前移、有效滤过长度变短 |
| 激素在就说一定浓缩 | 缺梯度时结论错 | 梯度与开关分开判 |
| 把清除率当通用指标 | 用一个数说明所有物质 | 先判物质的转运方式，再读含义 |
| 用「肾不好」代替环节定位 | 无法再往下推 | 落到滤过 / 重吸收 / 分泌 |

## 与相邻章节的接缝

- 上一章（能量代谢与体温）：代谢终产物要清除，本章是「出」的那一端。
- 上一章之前（血液循环）：肾血流来自体循环，血压与血量的变化经此传入本章。
- 下一章（内分泌）：抗利尿激素与醛固酮的来源与调节链，在下一章展开。
- 第 2 章（细胞的基本功能）：转运方式（主动、被动、胞吞）是本章重吸收一节的前置。

## 边界

本 Skill 只处理「环定位 + 方向判断」，不涉及数值、分期分级、诊断与治疗。任何涉及个体的判断须由具备资质的人员依现行规范作出。
