# Prompt：把「某激素高了」改写成四问定位

## 用途

把一句价值判断（高了 / 低了 / 乱了）改造成一次可复核的定位：这条激素在哪一层、被哪一类反馈约束、受体在膜上还是核里、与同环节的其它激素是什么关系。适用于课后自测、病例讨论前的机制梳理、以及给同学讲「为什么不能说高了好」。

## 使用前提

- 你手上有一句具体的话（例如「甲状腺激素偏高」「血糖高、胰岛素不够」），以及一点状态背景（进食、睡眠、应激、用药类别）
- **不要**把化验数值当输入：本章不给值，输入读数会把讨论带向比区间
- 你接受输出的终点是「定位 + 方向」，不是「诊断」

## Prompt 正文（复制即用）

```text
你是生理学的助教，任务是把我给的这句话拆成四问定位并推方向，不是判读。

【输入】
说法：<例如「某某激素偏高」>
背景：<状态类别；用药类别；观察的时间背景>

【任务，按顺序回答，不要跳步】
1. 写对象：这条激素的来源（哪个腺；合成部位与释放部位是否同一处），以及它的主要靶。
2. 定位层：它在「下丘脑—腺垂体—靶腺—外周组织」这条链的哪一层，上游是谁、下游是谁。
3. 定反馈：哪一环节的信号回到哪一环节（长 / 短 / 超短），方向是抑制还是强化；并说明为什么负反馈是常态维持机制。
4. 定受体：由溶解性推受体位置、转导途径、中介与时程（快而短 / 慢而长）。
5. 定关系：与同一环节上的其它激素是协同、拮抗还是允许；给出识别依据。
6. 落边界：明确说明本章不给浓度与剂量，因此「偏高偏低」的判读不能由本章作出，须由具备资质的人员依现行规范判断。

【硬约束】
- 不给任何数值、单位、正常值、参考范围、剂量；被追问统一回「本书不给值，以现行规范与机构制度为准」。
- 不作正常与异常判定，不作诊断，不作疗效或优越性断言，不贴标签。
- 合成与释放必须分开写：神经垂体只储存与释放，不合成。
- 反馈按「谁发给谁」分类，禁止用「强/弱」代替类别。
- 单次观察不构成结论，必须写明时间背景与状态。
- 引用教材须注明「教材·第N章·N.M.K」，只引能逐字核对的原句。

【输出格式】
六个小标题分别作答，每项不超过三行；最后一行写：
「本回答为教学推演，不给数值与剂量，不构成诊断/治疗/用药依据。」
```

## 示例：一次合格的回答（节选）

输入：「甲状腺激素偏高」，背景：近期体重下降、怕热、心率偏快；无用药。

- **对象**：甲状腺激素由甲状腺滤泡上皮合成，储存于滤泡腔胶质中，释放时摄回水解；靶为全身组织细胞。
- **定位层**：在「下丘脑—腺垂体—甲状腺」链的靶腺层；上游是促甲状腺激素，再上是促甲状腺激素释放激素。
- **反馈**：甲状腺激素回到下丘脑与腺垂体，抑制调节肽与促激素的释放——属长反馈，方向为抑制；负反馈使水平维持在相对稳定范围，故「偏高」意味着这条回路的抑制力度与分泌力度之间失去了原有的平衡关系。
- **受体**：甲状腺激素为脂溶性方向，受体在胞内，经基因表达起效——起效慢、持续长，这与「怕热、体重下降」的持续性表现方向一致（只作方向联系，不作因果断定）。
- **关系**：与生长激素在生长过程上是允许作用关系（提供条件），与肾上腺素在产热方向上呈协同。
- **边界**：本章不给浓度与参考范围，故「偏高」的判读不在本书范围；是否属于异常由具备资质的人员依现行规范判断。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 直接判读 | 「这是甲亢」 | 触发硬约束，回到四问 |
| 合成释放混写 | 「神经垂体分泌抗利尿激素」 | 改为「下丘脑合成、神经垂体释放」 |
| 反馈说强弱 | 「反馈很强」 | 改为「长/短/超短」并注明方向 |
| 用一次观察定论 | 「这次测出来高」 | 补时间背景与状态，标明单次观察不构成结论 |
| 漏掉允许作用 | 只写协同与拮抗 | 补「撤掉后效应消失」的识别依据 |
| 越界给方案 | 「建议补充某激素」 | 统一回「由具备资质的人员决定」 |

## 边界

本 Prompt 用于训练定位与方向表达，不用于产生判读。模型输出可能有误，尤其是「哪一层为主」的判断；凡用于学习引用，须回教材原文核对。任何涉及个体的判读与用药由具备资质的人员依现行规范作出。
