# Skill：内分泌——先定位，再谈方向

## 何时用

- 有人拿一句「某某激素高了 / 低了」来问，而你要把它变成可推理的问题
- 要判断某条激素在调节链的哪一层、受哪一类反馈约束
- 要解释为什么同一条激素在不同组织引起不同方向的反应
- 要给同学讲清「神经垂体只储存不合成」这类结构事实为什么重要

## 四问定位（核心工具）

| 问 | 可选的答案 | 答不出说明什么 |
|---|---|---|
| 哪一层？ | 下丘脑 / 腺垂体 / 靶腺 / 外周组织 | 还没上链条，只是在说一个名字 |
| 什么关系？ | 调节肽→促激素→靶腺激素→效应 | 说不清作用对象，方向无从谈起 |
| 哪类反馈？ | 长 / 短 / 超短（按谁发给谁） | 把反馈当「强弱」判，会导致归因错层 |
| 受体在哪？ | 膜受体（水溶性，信使放大，快而短）/ 胞内受体（脂溶性，改基因表达，慢而长） | 说不清受体，就没法解释时程与组织差异 |

四问答完，「高了低了」才第一次有了下文。

## 执行步骤

```text
1. 写对象：激素名称 + 来源（哪个腺、合成与释放是否同一部位）
2. 定位层：在链的哪一层，上游是谁、下游是谁
3. 定反馈：谁的信号回到谁，属长/短/超短，方向是抑制还是强化
4. 定受体：溶解性 → 受体位置 → 中介 → 时程
5. 定关系：与同一环节上的其它激素是协同、拮抗还是允许
6. 落边界：说明本章不给浓度与剂量，「高/低」的判读不在本书范围
```

## 硬约束

- **不给值**：不写浓度、剂量、参考范围、分泌曲线的幅度。**本书不给值**，一律回到现行规范与机构。
- **合成与释放分开写**：神经垂体只储存与释放；写成「分泌」即错。
- **反馈按回路分类**：长/短/超短由「谁发给谁」决定，与强弱无关。
- **允许作用单列**：撤掉后效应消失、补回后不产生效应，才是允许作用。
- **单次观察不作结论**：分泌有节律，任何描述必须带时间背景与状态。
- **不作诊断与疗效断言**：不写「提示某病」，不写「补充某激素会改善」。

## 交付物

1. 一张四问定位表（层 / 关系 / 反馈 / 受体）
2. 一句方向判断，或一句「本章不给值，无法判高低」
3. 一句相互作用说明（协同 / 拮抗 / 允许，并给识别依据）
4. 一处边界：结论不用于个体判读与用药

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 说「神经垂体分泌抗利尿激素」 | 结构来源错，后续推论全错 | 改为「下丘脑合成、神经垂体释放」 |
| 把反馈说成「强/弱」 | 归因错层 | 按「谁发给谁」判长/短/超短 |
| 用「量少」推断「作用小」 | 忽略放大特征 | 信号强度与效应不成简单比例 |
| 把允许作用当协同 | 多激素场合误判 | 撤掉试验识别 |
| 单次采血即下结论 | 忽略节律 | 写明时间背景与状态 |
| 越界给剂量 | 变成用药建议 | 统一回「由具备资质的人员决定」 |

- 第 7 章（能量代谢与体温）：非寒战产热与代谢水平受甲状腺激素与肾上腺素影响，两章在此接头。

## 边界

本 Skill 只处理「定位 + 方向 + 关系」，不涉及浓度、剂量、诊断与治疗。任何涉及个体的判读与用药须由具备资质的人员依现行规范作出。
