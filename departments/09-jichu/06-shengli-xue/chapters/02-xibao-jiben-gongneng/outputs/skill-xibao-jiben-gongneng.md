# Skill：细胞的基本功能——链、状态机与边界

## 何时用

- 细胞章的名词记不住，需要一条能挂住它们的链
- 要回答「某结构失效后哪一环失去输入」这类阻断假设题
- 要把「不应期」「兴奋性变化」这类时间现象写成可检查的离散结构
- 遇到「电位多少」「张力多大」的追问，需要一致口径

## 核心判据（四问）

1. **在哪一环？** 跨膜转运 / 信号转导 / 电活动 / 收缩。答不出环，说明还停在名词层。
2. **靠什么结构？** 膜的骨架、膜蛋白的类别、肌丝的排布、横管与终池的相邻关系。功能必须落到结构上。
3. **方向如何？** 顺梯度还是逆梯度、耗能还是不耗能、经不经膜蛋白。方向是类别问题，不是数值问题。
4. **状态怎么转移？** 静息 / 激活 / 失活，触发条件与先后顺序。状态机是本章唯一能完整写出的「时间结构」。

## 执行步骤

```text
1. 把问题钉到一条链上：物质 → 信息 → 电 → 力
2. 写出承担该环的结构类别（不给尺寸、不给数量）
3. 写方向：顺/逆、耗能/不耗能、经/不经膜蛋白
4. 写状态机：状态集 + 转移条件 + 顺序
5. 写下一环的输入：本环的输出是什么
6. 做阻断假设：抽掉一环，哪一环失去输入，现象如何变
7. 列边界：哪些问题必须靠数值，声明另立数据层
```

## 硬约束

- **不给数值、单位、正常值、百分比。** 电位幅度、时程、传导速度、张力、缩短速度一律不给；需要时回「另立数据层」。
- **不判正常与异常。** 链能说明机制，不能说明某人的检查结果是否异常。
- **分类要带依据。** 说「四类」必须说清两条轴；说「三类受体」必须说清结构差别。
- **引文逐字。** 标「教材·第N章·N.M.K」，核不到就不引。
- **重述要标注。** 「状态机」是本书的表达，教材未用此词，交付时要说明。

## 交付物

1. 一条链（四环，标明本问题落在哪一环）
2. 一台状态机（状态集、转移条件、顺序）
3. 一个阻断假设（哪一环失去输入、现象如何变）
4. 一处边界（哪些问题必须靠数值，本书不给）

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 从动作电位直接跳到收缩 | 中间三环丢失，遇阻断题即塌 | 补横管传导与钙释放 |
| 把状态机写成时间表 | 变成背时程，一改条件就错 | 只写状态与转移条件 |
| 分类当穷举 | 认为跨膜只有四类 | 加第三轴（是否成囊泡），并解释空格 |
| 用「更强刺激」代替机制 | 相对不应期与绝对不应期混淆 | 回到通道状态：失活 vs 部分恢复 |
| 被追问就报数值 | 越出本书口径且数值无来源 | 统一回「本书不给值」 |

## 与相邻章节的接缝

- 上一章（绪论）：稳态与调节是整体层的语言，本章是它在细胞尺度的实现。
- 下一章（血液）：血液把本章的跨膜与信号问题带到「细胞外液」这一层——红细胞的气体交换、血小板的激活，都是本章链条的复用。
- 后续（循环、呼吸、神经）：动作电位与耦联机制在心肌、平滑肌、神经元上反复出现，差别在结构而不在原理。

## 边界

本 Skill 只处理「细胞功能的链与状态」的结构化表达，不涉及数值、判定与临床决策。任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
