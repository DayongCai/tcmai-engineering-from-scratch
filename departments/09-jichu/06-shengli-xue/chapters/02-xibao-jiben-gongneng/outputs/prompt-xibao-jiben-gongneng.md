# Prompt：把「细胞功能」拆成一条链、一台状态机

## 用途

细胞这一层的知识最容易碎成一堆名词：单纯扩散、易化扩散、G蛋白、阈电位、横管、终池……这个模板逼你把它们挂到一条链上（物质→信息→电→力），再逼你把「时间上的变化」写成状态机而不是形容词。适用于复习细胞章、准备实验课提问、以及给后续循环与神经章做迁移。

## 使用前提

- 你手上有一个具体问题，而不是一整章。例：「某类通道被阻断后，这个细胞还能不能兴奋」「为什么这块肌肉在某个长度下更有力」。
- 你已读过对应小节，能给出教材·第N章·N.M.K 的定位。
- 你接受硬约束：**本模板不产出任何数值**（电位幅度、时程、张力、速度一律不给）。

## Prompt 正文（复制即用）

```text
你是生理学的助教。任务不是复述名词，而是把细胞功能整理成「一条链 + 一台状态机」。

【输入】
问题：<一句话，指向一个结构或一个环节>
教材定位：<教材·第N章·N.M.K>

【任务，按顺序回答，不跳步】
1. 定位：这个问题落在链的哪一环——跨膜转运 / 信号转导 / 电活动 / 收缩？
2. 结构：承担这一环的结构是哪一类（膜的骨架、膜蛋白的类别、肌丝的排布、横管与终池的相邻关系）？
3. 方向：物质或信号往哪边走？顺什么梯度、逆什么梯度、由谁供能？只说方向，不说快慢。
4. 状态：把这一环写成状态机——有哪些状态（静息 / 激活 / 失活等），哪些条件触发转移，转移的先后顺序如何？
5. 下一环：本环的输出变成下一环的什么输入？（例：电变化 → 钙释放 → 肌丝滑行）
6. 阻断假设：如果本环的某个结构失效，哪一环会失去输入？现象会怎样改变？给可观察差别，不给数值。
7. 边界：这个问题里有哪些部分必须靠数值才能回答？明确列出并声明「本书不给值，需另立数据层」。

【硬约束】
- 不给数值、单位、正常值、参考范围、百分比。也不要给「大约多少」。
- 不作正常与异常的判定，不作诊断，不作疗效断言。
- 引教材原文必须逐字，标「教材·第N章·N.M.K」；核不到就不引。
- 若问题的前提不成立（例如要求逆梯度又不耗能），直接指出前提不成立，不要顺着答。

【输出格式】
七个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的拆解（节选）

问题：某类通道被阻断后，这个细胞还能不能兴奋？教材定位：教材·第2章·2.3.2。

- **定位**：电活动这一环，具体在「兴奋的引起」这一步。
- **结构**：膜上承担去极化的通道类别；阻断意味着这一类通道不再随刺激开放。
- **方向**：正常情况下相关离子顺电化学梯度进入细胞，使膜去极化；阻断后这个方向的净移动消失。
- **状态**：通道三态——静息（可开放）、激活（开放）、失活（不可开放）。阻断相当于把「静息→激活」这一条转移切断，状态机停在静息。
- **下一环**：没有去极化，就没有后续的钙释放，收缩这一环失去输入。
- **阻断假设**：现象表现为「刺激存在而反应消失」；若只是部分阻断，则表现为「需要更强或更久的刺激才有反应」——这是可观察的差别，不需要数值。
- **边界**：需要数值才能回答的是「多强的刺激算够」「反应延迟多久」，本书不给值，需另立数据层。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 只报名词 | 「这是易化扩散」 | 追问「顺还是逆、耗不耗能、经不经蛋白」 |
| 链条断在中段 | 从动作电位直接跳到收缩 | 补上「横管传导 → 钙释放」两环 |
| 状态机写成时间表 | 「先这样，过一会儿那样」 | 改成状态与转移条件，不写时长 |
| 偷给数值 | 「电位约为……」 | 触发硬约束，改为「本书不给值」 |
| 把分类当穷举 | 认为跨膜只有四类 | 补第三轴（是否成囊泡），并指出空格为何为空 |

## 边界

本模板训练「结构—功能—状态」的表达，不产生临床判断。链与状态机的划分是教学表达，教材并未使用「状态机」一词；参数不在本书范围内，涉及个体的评估须由具备资质的人员依现行规范作出。
