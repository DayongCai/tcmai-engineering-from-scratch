# ganjue-qiguan

## 何时使用

- 读生理学第11章（感觉器官）之前，想知道这一章把视、听、前庭、嗅、味、皮肤写成了什么形状
- 手上有一张检查报告的栏目（视力、视野、听阈、屈光、色觉），需要改写成类别与关系的问法
- 要设计一张观察记录表，只装类别与条件、不装参数
- 复核一段引文的章号节号，确认它可逐字回查

## 不适用

- 验光、听力筛查、视野检查的判读与分级（本书不给值，必须另立数据层）
- 对个体作正常与异常判定、诊断、预后
- 矫正器具与药物的名称、型号与参数
- 把密度或声明次数当作内容质量排序

## 步骤

1. **定章规模**：跑 `node code/main.js`，确认 4 节 12 小节 20,527 字，数值型 0，27 个数字全是列表序号。
2. **看两套口径**：三视角（形态 186 / 机能 156 / 代谢 20）与四层级（细胞 105 / 器官 39 / 系统 27 / 组织 5）。
3. **找密度差**：视觉 32.9 最密、化学感觉与观察要求 20.8 最疏；同一视觉器官内，11.2.2 视网膜 52.2 最密、11.2.3 视觉现象 13.0 最疏。
4. **对四条特性**：适宜刺激、换能、编码、适应——每一条都要能在一段材料里指出来。
5. **改写栏目**：把「多少」换成「哪一类、往哪个方向、与什么相对」，六条常见转写见 docs 第五节。
6. **核引文**：写成 `教材·第N章·N.M.K`，逐字回查 units.json 的 body。
7. **声明边界**：结尾明写「本书不给值」与「不构成诊断依据」。

## 输出模板

```text
【规模】4 节 12 小节 20,527 字 · 数值型 0 · 声明 38 处
【口径】三视角 形态 186 / 机能 156 / 代谢 20；四层级 细胞 105 / 器官 39 / 系统 27 / 组织 5
【本节定位】11.x.y 标题 · 密度 x.x · 落在哪一层
【四条特性】适宜刺激 / 换能 / 编码 / 适应 各一句
【改写】原参数条 → 类别与关系条
【出处】教材·第11章·N.M.K + 可回查引文
【边界】本书不给值；不作正常与异常判定
```

## 质量判据

- 输出的每条都能回答「哪一类、往哪个方向、与什么相对」
- 没有出现「数字＋计量单位」，也没有正常值、参考值、分级标准
- 四条一般特性可逐条对上号，缺项被显式指出
- 层级归属有依据，视觉落在细胞、听觉落在细胞与器官
- 引文与 locator 一致且逐字可查
- 结尾有边界声明

## 常见错误

1. **把「感觉器官」读成「检查报告」**：本章 38 处不给值声明正是为了挡住这个读法。
2. **把视网膜的换能方向记反**：视杆细胞在光照下是超极化型，与一般感受器的去极化型相反。
3. **把听阈与最大可听阈混成一个门槛**：前者是刚能引起听觉的下界，后者是转为压迫感的上界，听域是两者之间的区间。
4. **把组织层 5 次当内容缺席**：味蕾与皮肤感受器的分布都在写，只是词表只认出 5 次。
5. **把密度当重要性**：11.4 最疏，是因为化学感觉的写法停在类别层。
