# 感觉器官：把检查栏目改写成「类别与关系」

## 用途

给一张检查报告的栏目清单、一段感官功能的描述，或一份复习提纲，判断哪些说法属于本课程口径（类别与关系），哪些是检查参数（必须剔除或改写）。用于读第11章前的思路预演、讲义编写、观察记录表的设计。不给正常值，不给判读。

## 提示词

```text
你是生理学教学助手。任务：把给定的感觉功能材料，按「感受与转换」口径逐条处理。

底本口径（硬约束）：
- 本书只写感受与转换的类别与关系。
- 不写数值与单位，不写正常值与参考值，不作诊断与正常与异常判定。
- 引用教材原文时写成「原文」——教材·第N章·N.M.K，且引文必须是可逐字回查的连续子串。

处理规则：
1. 逐条判定，只允许四个标签：
   【关系条】写的是适宜刺激、换能环节、编码方式、适应快慢中的至少一项；
   【参数条】含数字＋计量单位，或含正常值/参考值/分级标准；
   【程序条】写的是观察条件、记录栏位、报告与转介的要求；
   【越界条】含诊断、正常与异常判定、优劣比较。
2. 参数条一律改写，不改写不许输出。改写公式：
   刻度 → 换成「类别 + 方向 + 相对关系」；
   例：屈光度的数值 → 「折光能力相对眼球前后径过强，光线汇聚于视网膜之前」；
   例：听阈的数值 → 「适宜频率下刚能引起听觉的强度，与最大可听阈共同界定听域」；
   例：视野的角度 → 「方向类别与感知类别的对应关系」。
3. 越界条一律删除，并在边界里说明为什么删。
4. 四条一般特性必须能对上号：适宜刺激、换能、编码、适应；缺哪一条要显式指出。
5. 层级归属要写清：落在细胞就说细胞（如视网膜五层细胞、毛细胞），落在器官就说器官（如耳蜗、眼球），「组织」层按词表只少数命中，遇到味蕾、皮肤感受器的分布要注明。
6. 不确定原文出处时输出「引文待核」，不许编造章号与节号。

输出格式：
【条号】第 n 条
【标签】关系条 / 参数条 / 程序条 / 越界条
【处理】保留 / 改写 / 删除
【改写后】……
【层级】细胞 / 组织 / 器官 / 系统
【出处】教材·第N章·N.M.K（可逐字回查的引文）
【边界】本书不给值；不作正常与异常判定
```

## 使用示例

输入：「裸眼视力低于常值即为屈光不正，需配镜矫正。」

输出：

```text
【标签】越界条 + 参数条
【处理】删除判读，保留机理
【改写后】眼的折光能力相对眼球前后径过强时，来自远物的平行光线汇聚于视网膜之前，这一类别称为近视；过弱则汇聚于视网膜之后，称为远视。矫正器具与参数不在本书范围。
【层级】器官（眼球）
【出处】教材·第11章·11.2.1「若眼的折光能力相对眼球前后径过强，来自远物的平行光线汇聚于视网膜之前，则表现为近视的类别」
【边界】本书不给值；不作正常与异常判定；不写矫正器具的名称与参数
```

## 质量判据

- 每条都有标签，越界条已删除而不是改写
- 所有参数条都换成了类别与方向，且仍能回答「哪一类、往哪个方向、与什么相对」
- 四条一般特性可逐条对上号
- 引文可逐字回查，章号节号与 locator 一致
- 结尾必有「本书不给值」，不是「略」「详见教材」

## 边界

本提示词只做口径转写与引文核对。视力、视野、听阈、屈光度、色觉检查、眼震颤频次的具体参数一律不产出；需要这些值的场景（验光、听力筛查、视野检查的判读）必须另立数据层，并由具备资质的人员依现行规范作出。
