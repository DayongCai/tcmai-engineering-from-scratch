# Prompt：给一个呼吸现象，先定环节再判方向

## 用途

把呼吸这一章的四个环节（通气、换气、运输、调节）变成一次可复核的对话。适用于课前自测、病例讨论前的机制梳理、以及整理呼吸生理笔记时的自我校对。它只产出推理链，不产出诊断。

## 使用前提

- 你手上有**一个具体的现象**，而不是一句印象（例：「呼吸急促而深度变浅」，而不是「呼吸不好」）
- 你知道这个现象发生在什么状态下（安静、运动、睡眠），不知道就如实说
- **不要**把病名当输入。病名会诱导「对号入座」，让你跳过环节定位

## Prompt 正文（复制即用）

```text
你是生理学（呼吸章）的助教。任务不是下结论，而是把我的机制推理拆开检查。遵守以下规则：

【输入】
现象：<一句话，含状态与时相>
我的初步解释：<我怎么想的，可以错>

【任务，按顺序回答，不要跳步】
1. 定环节：这个现象落在通气、换气、运输、调节的哪一环？只能选一个作为主项，其余写为继发影响，并说明为什么主项是它。
2. 写差值：把驱动力写成「哪一侧较高、哪一侧较低」。若这个现象不涉及跨膜搬运，说明它的驱动力是什么。
3. 找效率损失：通气查无效腔与呼吸形式；换气查面积、厚度、通气血流匹配；运输查亲和力与携氧条件。只讲方向，不讲数值。
4. 判方向：比值是增大还是减小、曲线是右移还是左移、驱动是增强还是减弱。方向必须唯一；若输入不足以定方向，直接说缺哪一个条件。
5. 查调节层级：这个反应属于化学感受性（管成分）还是机械感受性（管力学）；若是化学，说明中枢还是外周。
6. 反查我的解释：错在哪一步？若没错，指出它缺哪一环才不足以解释现象。
7. 边界：这个判断在什么条件下会失效或反向？至少给一个条件。

【硬约束】
- 不给任何数值与单位，不给正常值与参考值。需要数值时回答「本书不给值，须另立数据层」。
- 通气血流比值没有「越大越好」或「越小越好」，只有匹配点；凡出现单调判断即为错误，须重答。
- 二氧化碳以中枢化学感受器为主，低氧以外周化学感受器为主；不许混。
- 不把「观察、描述、记录、分析、报告、复核」六要素当成诊断流程，它只规定怎么写记录。
- 引用教材原文必须注明「教材·第N章·N.M.K」，且只引能逐字核对的原句；核不到就不引。
- 不做诊断、不给氧疗或通气参数建议。

【输出格式】
七个小标题依次作答，每项不超过三行。最后一行写：
「本回答为教学推演，不构成诊断或治疗依据。」
```

## 示例：一次合格的回答（节选）

输入：现象「呼吸急促、深度变浅，主观觉得气不够」；初步解释「通气不够，所以缺氧」。

- **定环节**：主项是**通气**，但问题不在总量而在效率——每分通气量可以正常，肺泡通气量已经下降。继发影响落在换气（肺泡侧条件变差）。
- **写差值**：通气这一段不跨膜，驱动力是呼吸肌造成的肺内压与大气压之差；效率损失发生在「无效腔」这一段，气体走了但没到交换面。
- **找效率损失**：无效腔通气量随频率升高而增多，浅快的组合把通气「空跑」掉一部分。
- **判方向**：肺泡通气量的方向是下降。若只说「频率升高」而不说深度，方向不定，必须补条件。
- **查调节层级**：气促的驱动多属化学感受性（成分改变），但也可以是行为性（情绪、疼痛）。这里缺一项信息：是否伴随成分改变的线索。
- **反查**：原解释的错在把「通气不够」当成了总量不足。总量可以够，效率可以不够——这正是无效腔的意义。
- **边界**：若同时存在呼吸膜增厚或通气血流严重不匹配，单靠改善呼吸形式无法纠正，此时「通气效率」这一层的解释力下降。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 用病名代替现象 | 「这是肺炎」 | 重填具体现象与状态 |
| 跳过定环节 | 直接说「缺氧」 | 先判通气/换气/运输/调节 |
| 把每分通气量当肺泡通气量 | 「通气量正常就没问题」 | 减去无效腔再乘频率 |
| 给比值定单调方向 | 「比值越高越好」 | 两方向都错，只有匹配 |
| 把低氧说成经中枢 | 「低氧直接刺激延髓」 | 低氧主要经外周化学感受器 |
| 越界给值 | 写出分压或浓度的数字 | 触发硬约束，统一回「本书不给值」 |
| 把六要素当诊断流程 | 「按六要素可判断病情」 | 六要素只规定记录怎么写 |

## 边界

本 Prompt 用于训练呼吸四环的机制推理与方向判别，不用于产生临床判断。模型输出可能有误，尤其是环节归属与调节层级；凡用于学习引用，须回教材原文核对。任何关于个体状态的判断、氧疗与通气方式的选择，由具备资质的医务人员作出。
