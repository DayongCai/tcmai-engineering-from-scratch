# Skill：呼吸：通气·换气·气体运输·呼吸调节

## 何时用

- 看到一个呼吸现象（气促、发绀、呼吸节律改变、血氧下降），要判断它落在**通气、换气、运输、调节**哪一环
- 被问到「浅快呼吸为什么不好」「通气血流比值是不是越高越好」「低氧是怎么刺激呼吸的」这类**方向题**
- 要把呼吸机或氧疗的原理说清（正压通气改变胸膜腔内压、高浓度氧去掉低氧驱动）
- 要写一份能被复核的呼吸观察记录

## 核心判据（四问）

1. **哪一环？** 外呼吸（通气、换气）、运输、内呼吸。四环的驱动力不同：通气靠呼吸肌造成的压力差，换气靠分压差，运输靠循环，内呼吸靠分压差与代谢。
2. **差值够不够？** 一切「搬物质」的过程只看两侧差值。差值不足就换不动，与物质「重要不重要」无关——这是本章所有反直觉结论的来源。
3. **效率损失在哪里？** 通气的损失在无效腔（频率越高空跑越多）；换气的损失在面积、厚度、通气血流匹配（两个方向都错）；运输的损失在携氧条件与亲和力方向。
4. **谁在调、朝哪边调？** 二氧化碳主要经中枢、低氧主要经外周。方向答错，推论会整条反过来。

## 执行步骤

```text
1. 写下现象，不改写成病名（例：呼吸急促而深度变浅）
2. 定位环节：通气 / 换气 / 运输 / 调节，只能选一个作为主项
3. 算效率损失：通气查无效腔与频率；换气查面积、厚度、通气血流匹配；运输查亲和力与携氧条件
4. 判方向：比值增大还是减小、曲线右移还是左移、驱动增强还是减弱
5. 查调节：这个反应是化学感受性（成分）还是机械感受性（力学），中枢还是外周
6. 反查边界：这个判断在什么条件下失效（中枢被钝化、膜的条件改变、储备耗尽）
```

## 硬约束

- **不给值。** 不写分压、容积、通气量、浓度、比值的数值与单位，也不写正常值。需要数值的场合另立数据层。
- **方向必须唯一。** 输入合法就要给出唯一方向；输入不全（例如只给「频率升高」不说深度）必须拒答，不许含糊成「可能升高」。
- **通气血流比值没有单调方向。** 增大是无效腔样、减小是分流样，只有匹配点。凡在本条上说「越高越好/越低越好」，即为错误。
- **二氧化碳与低氧的分工不许混。** 二氧化碳以中枢为主，低氧以外周为主；把低氧写成「主要经中枢」是最常见的塌陷。
- **六要素是记录规范，不是诊断流程。** 观察、描述、记录、分析、报告、复核规定怎么写，不规定怎么判。

## 交付物

1. 一句定环：这个现象落在通气 / 换气 / 运输 / 调节的哪一环
2. 一条差值：把驱动力写成「哪一侧较高、哪一侧较低」
3. 一处效率损失：无效腔、面积厚度、匹配、亲和力中选一处，说明方向
4. 一处边界：这个判断在什么条件下会失效

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 把「呼吸困难」当环节判断 | 环节不清，处理方向全错 | 先分成通气/换气/运输/调节 |
| 认为平静呼气是主动的 | 弹性回缩力的双重身份理解反 | 平静呼气被动，用力呼气才主动 |
| 用每分通气量代替肺泡通气量 | 漏掉无效腔，浅快呼吸被判成「够」 | 减去无效腔后再乘频率 |
| 把通气血流比值当越大越好 | 无效腔样效应被当成好事 | 两方向都错，只有匹配 |
| 认为二氧化碳分压差小所以扩散慢 | 忽略溶解度，把推力当结果 | 分压差 × 溶解度 |
| 说低氧主要经中枢感受器 | 高浓度氧的风险推论全反 | 低氧主要经外周 |
| 用溶解形式解释运输主体 | 把「开关」当成「仓库」 | 溶解少而定性，结合多而定量 |

## 边界

本 Skill 只处理呼吸四环的机制判断与方向判别，不涉及任何数值、正常值或临床决策。任何关于个体状态的判断与氧疗、通气方式的选择须由具备资质的医务人员作出。
