# 酸碱紊乱的判据不是 pH 落没落在区间里，而是代偿有没有到位 · 提示词

## 用途

给「酸碱紊乱的判据不是 pH 落没落在区间里，而是代偿有没有到位」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「两套账：容量与浓度，先分清再算 → 水钠：渗透压是主变量，容量是另一个 → 钾：体内总量与血钾不是一回事 → 缓冲对：二十比一这个数是从 pH 与 pKa 算出来的」这条链。
