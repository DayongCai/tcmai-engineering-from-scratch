# 翻译的准确不靠一条规则，而靠两次校对与四次高能键的预付 · 提示词

## 用途

给「翻译的准确不靠一条规则，而靠两次校对与四次高能键的预付」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「密码表的三条设计：简并、无重叠、通用 → 两步校对：合成酶管「配对」，核糖体管「对号」 → 能量账：两次 ATP、两次 GTP → 核糖体是核酶：催化中心是 RNA」这条链。

## 边界

本章为生物化学的教学材料，用于建立「简并容错、两步校对、能量预付、合成后仍需加工」的判断框架，不构成医学意见、诊断或治疗建议。文中一切数量口径与折算均为教学层面的概括与演示；具体操作以现行规范与所在机构制度为准。
