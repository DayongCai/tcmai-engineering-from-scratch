# 分子技术的选择不看好坏，只看它那个致命假设你的样本能不能满足 · 提示词

## 用途

给「分子技术的选择不看好坏，只看它那个致命假设你的样本能不能满足」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「分离：三把尺子，三种偏见 → 印迹：把「分离」与「识别」拆成两步 → PCR：指数放大的代价是「必须知道两端」 → 测序：读长与通量的交换」这条链。

## 边界

本章为生物化学与分子生物学的教学材料，用于建立「按问题选技术、按假设验结论」的判断框架，不构成医学意见、诊断、检验判读或治疗建议。文中一切数量口径与技术描述均为教学层面的概括；具体操作以现行规范与所在机构制度为准。
