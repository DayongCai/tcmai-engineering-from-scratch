# 第 7 章 · 维生素本身不供能，它的价值在辅酶那一半

> **MOTTO:** 「圣人不治已病治未病，不治已乱治未乱。」——《素问·四气调神大论》
>
> **PROBLEM:** 十三种维生素、八种必需微量元素，日需要量在微克到毫克之间，合起来不到一克，却支撑着全部代谢途径的催化环节。缺其中任何一种，某一条途径就停在一个酶上，而表现出来的问题往往出现在离那个酶很远的器官——这个距离，正是本章要讲清楚的东西。

**双根因定位:** 环境逼迫（人体不能合成其中多数，必须从食物中获得；而代谢对辅因子的需求是刚性的，缺了没有替代品） + 知识积累（从「某食物能防某病」的经验观察，到把米糠浓缩物分离成硫胺素、把辅酶从酶上拆下来定性，方法把「营养素」变成了有结构的分子）

**教材出处:** 教材·第 7 章·7.1–7.4

## 一、水溶性维生素：B 族与辅酶的对照

水溶性维生素的主体是 B 族与维生素 C。B 族不是一种物质，是一组化学结构各异、但都作为辅酶前体参与代谢的小分子。把它们放在一起讲，唯一站得住的理由是功能：它们几乎都以辅酶或辅基的形式，挂在某个酶的活性中心旁边。

把这张对照表记住，比记住每种维生素的别名有用得多：

| 维生素 | 辅酶形式 | 参与的化学动作 |
|---|---|---|
| B1 硫胺素 | 焦磷酸硫胺素 | 脱羧、转酮 |
| B2 核黄素 | FMN、FAD | 递氢（两电子） |
| B3 烟酸、烟酰胺 | NAD⁺、NADP⁺ | 递氢（两电子，分步） |
| B5 泛酸 | 辅酶 A、酰基载体蛋白 | 携带酰基 |
| B6 吡哆醇等 | 磷酸吡哆醛 | 转氨、脱羧 |
| B7 生物素 | 羧化酶辅基 | 携带二氧化碳 |
| B9 叶酸 | 四氢叶酸 | 携带一碳单位 |
| B12 钴胺素 | 甲基钴胺素、腺苷钴胺素 | 甲基转移、分子内重排 |

这张表的每一行都能反向使用：看到「转氨酶」，想到磷酸吡哆醛；看到「羧化」，想到生物素；看到「一碳单位」，想到四氢叶酸。反向使用才是真的记住了，正向背只是认识名字。

维生素 C 是另一个类型。它是水溶性抗氧化剂，能直接清除水相中的自由基；它也是脯氨酸与赖氨酸羟化酶的辅因子，胶原蛋白的羟化需要它，羟化不足则三股螺旋不稳定——这一步把「维生素 C 缺乏」与「血管脆、伤口难愈」连了起来，机制是清楚的，不需要背症状。维生素 C 还能把三价铁还原为二价铁，促进铁的吸收，这一条常被忽略，却解释了为什么补铁时常配维生素 C。

## 二、脂溶性维生素：四个方向

维生素 A、D、E、K 都是脂溶性，吸收随脂类同行，经淋巴进入血液，因此任何影响脂类吸收的条件都会连带影响它们。

维生素 A 有三个活性形式：视黄醇、视黄醛、视黄酸。视黄醛与视蛋白结合成视紫红质，是暗视觉的光受体发色团，光一照构象改变，触发信号；这一条直接说明为什么缺乏会影响暗适应。视黄酸则进入细胞核，结合受体调控基因表达，参与上皮分化与胚胎发育。同一个分子的三种形式，走了两条完全不同的路：一条是光化学，一条是基因调控。

维生素 D 是类固醇衍生物，皮肤的七脱氢胆固醇经紫外线照射生成前体，再经肝与肾两次羟化，得到活性形式。它的作用是把钙磷的吸收与动员调到合适的水平：促进小肠吸收钙磷、促进骨矿化、在需要时与甲状旁腺激素配合动员骨钙。这条轴上任何一个环节出问题，表现都在骨，而不在皮肤或肾——这就是「远端表现」的典型。

维生素 E 是生育酚类，主要作用是抗氧化，保护膜脂中的多不饱和脂肪酸不被过氧化。它溶于膜内，与脂溶性自由基反应，自己变成自由基后由维生素 C 等还原再生。这个「E 在膜内、C 在水相、两者接力」的模型，是理解抗氧化体系分工的最小模型。

维生素 K 的功能与凝血因子的 γ-羧化有关：谷氨酸残基的 γ 位羧化后，能螯合钙离子，使凝血因子结合到膜磷脂表面。没有这一步，凝血因子的蛋白量可能是正常的，功能却不行。骨钙蛋白也依赖同样的修饰，所以维生素 K 的缺乏不只影响凝血。

## 三、微量元素：八种元素，三类角色

教材通常列出八种必需微量元素：铁、锌、铜、硒、碘、锰、钼、钴。它们的共同特点是需要量极小、但不可替代。

角色分三类。第一类是金属酶的活性中心，铁在血红蛋白与细胞色素里负责电子与氧的传递，锌在碳酸酐酶里负责活化水分子，铜在细胞色素氧化酶里传递电子，锰在线粒体的超氧化物歧化酶里参与清除自由基，钼在黄嘌呤氧化酶里参与含氮代谢。第二类是辅基的组成成分，钴是维生素 B12 的核心原子，没有钴就没有 B12，这是「微量元素—维生素」交叉的唯一一例。第三类是激素的组成成分，碘是甲状腺激素分子中的必需原子，缺碘则激素合成不足，反馈性地引起甲状腺组织增生——机制链条清晰，不需要背结论。

硒的作用值得单说。它是谷胱甘肽过氧化物酶的必需成分，该酶用还原型谷胱甘肽清除过氧化氢与脂质过氧化物。硒与维生素 E 都属抗氧化体系，但分工不同：E 在膜内终止链式反应，硒酶在水相分解已经生成的过氧化物。一个是刹车，一个是清扫。

## 四、脂溶性与水溶性的差别：四个维度

两类维生素的差别不止「溶于什么」，而是四条：吸收途径、运输方式、储存能力、过量风险。

吸收上，水溶性者直接经门静脉入肝，脂溶性者随乳糜微粒经淋巴入血，绕过肝脏首过。运输上，水溶性者多游离或与特定蛋白松散结合，脂溶性者需要载体蛋白或脂蛋白。储存上，脂溶性者可在肝与脂肪组织蓄积，水溶性者除 B12 外基本不储存，超出需要即随尿排出。过量风险上，正因为有储存，脂溶性者长期过量会蓄积；水溶性者虽排出快，但也不能无限量摄入。

这四条差别解释了一个常见的误解：水溶性维生素「多吃点没关系」。排出快不等于没有上限，只是中毒的门槛与机制不同。讲这一节时不写任何剂量，只讲差别在哪儿——剂量属于专业判断，不是教学能给的。

## 五、缺乏与过量：怎么定位

面对一个「某种维生素缺乏」的叙述，定位的方法是四步：先找该维生素的辅酶形式，再找依赖该辅酶的酶，再找该酶所在的途径，最后看这条途径停下来的后果落在哪个组织。

以 B1 为例：辅酶是焦磷酸硫胺素，依赖它的酶包括丙酮酸脱氢酶复合体与 α-酮戊二酸脱氢酶复合体，两条都在糖的有氧氧化上；这两个复合体一停，丙酮酸与 α-酮戊二酸堆积，能量供应下降，而神经组织对能量供应最敏感，所以表现先出现在神经与心脏。这条推理链不需要背症状，只需要知道酶在哪儿。

过量的判断同理反过来：某种维生素在体内有没有蓄积部位、蓄积后干扰哪条途径。脂溶性者蓄积在肝与脂肪，过量时首先受影响的是膜与肝；水溶性者经肾排出，过量时首先受影响的是肾的浓缩能力。

临床上的维生素缺乏很少是单一的。长期偏食、吸收不良、慢性消耗、特殊生理阶段，往往同时缺几种，因为它们的来源高度重叠。这个事实提醒人：把维生素当成一个个独立的营养素去补，容易漏；按「哪条途径缺辅酶」去想，才找得到全貌。

## 代价与边界

这张「维生素—辅酶」对照表好用，代价是它把维生素讲成了纯功能分子。实际上有些维生素还有非辅酶的作用：维生素 C 的抗氧化与羟化、维生素 A 的视觉与基因调控、维生素 D 的激素样作用，都不在「辅酶」这个框里。用一张表统摄全部，会把它们讲窄。

另一个代价是「缺什么补什么」的直觉被强化。真实的缺乏往往多因并存，单一补充未必解决问题；而过量的风险又恰恰来自这种直觉。教学能做的是把机制讲透，把剂量留白。

边界方面：本章只讲结构、辅酶对应与作用机制类别，不写任何剂量、浓度、参考值，不写制剂名称与品牌，不写补充建议。维生素与疾病的关系只作机制说明，不作诊断，不作正常与异常判定，不作预后判定，不作疗效断言，不作优劣比较。涉及个体营养状况的判断，由具备资质的人员依现行规范与机构制度作出；涉及人体样本与个人资料的内容，按敏感个人信息处理并保护隐私。
