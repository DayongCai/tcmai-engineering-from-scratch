# 碱基环能否被打开，决定了核苷酸代谢的两条终点与两套药理 · 提示词

## 用途

给「碱基环能否被打开，决定了核苷酸代谢的两条终点与两套药理」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「两条终点：一个留环，一个开环 → 从头合成：一个先借糖，一个先成环 → 抗代谢物：不是毒，是「长得像」 → 调节：反馈管住起点，协同管住比例」这条链。

## 边界

本章为生物化学的教学材料，用于建立「先看环能否打开、再看闸门在何处、最后看原料是否共用」的判断框架，不构成医学意见、诊断、检验判读或治疗建议。文中一切机制说明与数量口径均为教学层面的概括与演示；具体操作以现行规范与所在机构制度为准。
