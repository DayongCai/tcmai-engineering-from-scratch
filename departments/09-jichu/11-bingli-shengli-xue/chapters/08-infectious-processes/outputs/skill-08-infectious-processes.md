# Skill：感染过程——五问、一条界线与连续谱的末端

## 何时用

- 有人（包括你自己）用「有菌」「感染了」「炎症重了」把一段状态糊过去了，需要拆开
- 手上有一份培养报告或一张化验单，要先分清它答的是「有什么」还是「是不是它在起作用」
- 要判断一段叙述有没有把定植当感染、把感染当脓毒症、把「没发热」当排除依据
- 遇到「要不要紧」「到什么程度」这类追问，需要一套一致的拒答口径

## 核心判据（五问）

1. **哪一道防线被削？** 屏障（即时、广谱、无记忆）／固有免疫（拖延与局限）／适应性免疫（精准清除与记住）。再分「被器械突破」与「功能不足」。
2. **定植还是感染？** 两条判据：在表面繁殖还是在组织内；宿主有没有反应。只有培养阳性一律写「未给界线」。
3. **传播链哪一环没断？** 病原体、储存宿主、排出门户、传播途径、进入门户、易感宿主。院内看进入门户与传播途径的接缝。
4. **走到连续谱哪一级？** 局部 → 入血 → 全身炎症 → 器官功能障碍。位置，不是分级；感染不等于脓毒症。
5. **话停在哪一层？** 防线／界线／环节／谱位／判定。越到判定那层就是越界。

## 执行步骤

```text
1. 抄原话，不改写：把要拆的那句话原样放在第一行
2. 定防线：三道防线逐条写「被削 / 未提 / 不足以判断」
3. 划界线：位置与宿主反应两条判据各写一句；缺就写「未给」
4. 找断环：传播链六环逐一过，指出没断的那一环
5. 定谱位：局部 / 入血 / 全身炎症 / 器官功能障碍，四格选一；不判分级
6. 查越界：诊断、严重度、预后、疗效、处置建议——逐条标出
7. 中性改写：删掉判定成分，只留防线与过程，保留观察时点
8. 报边界：不写数值，不作诊断，不给预后判断
```

## 硬约束

- **不给数值、单位、正常值、参考区间、百分比、体温与化验界值。** 需要数值才能回答的追问，统一回：本书不给值，需另立数据层（另立来源与校验）。
- **不作诊断，不作严重度分级。** 脓毒症、脓毒性休克在本课程里只作类别使用，不展开分级标准。
- **培养阳性不是病因。** 必须结合部位、数量、炎性细胞与宿主状态；无菌部位与有菌部位的标本，解释力不同。
- **发热不是充分条件，不发热不是排除条件。** 老年、免疫抑制、严重营养不良者可以无发热，标志物也可不显著升高。

## 交付物

1. 一段五问拆解（防线 → 界线 → 环节 → 谱位 → 判定），缺层如实标缺
2. 一张三道防线对照：哪一道被削、哪一道未提
3. 一句界线判断：定植、感染，或「未给界线」
4. 一段中性改写：删掉判定成分后的版本，保留观察时点
5. 一处边界：本章不给值、不作诊断，数值须另立数据层

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 培养即病因 | 把定植与污染当成感染 | 四条件：部位、数量、炎性细胞、宿主状态 |
| 界线跳过 | 「有菌就是感染」 | 位置 + 宿主反应两条判据 |
| 感染=脓毒症 | 把过程当末端 | 脓毒症含器官功能障碍与反应失调 |
| 只看体温 | 漏掉灌注与器官功能的动态 | 观察重心：意识、尿量、皮肤、再充盈 |
| 把院内感染当新机制 | 记不住该防什么 | 三因叠加：屏障被破、生物膜、宿主防御下降 |
| 被追问就报界值 | 越出本书口径，且数值无来源 | 统一回：本书不给值，另立数据层 |

- 前一章（肿瘤）：本章 8.1 的第三道防线与第 7 章 7.8 的免疫监视是同一套能力的两个落点——一个对着肿瘤，一个对着病原体。
- 后一章（炎症与免疫）：本章的急性期反应、内皮活化与毛细血管渗漏在那里展开成血管反应、细胞反应与介质；两章共用补体与细胞因子这套语言。
- 与护理学的分工：本章给机制位置（防线、界线、谱位），操作与流程由规范与机构制度决定。本章不写操作细节。

## 边界

本 Skill 只处理「一句话 → 五问 → 中性表述」的结构化拆解，不涉及数值、判定与临床决策。分类框架取自 `standards/binglishengli/supplements/jiangyi.json` 第 8 章的类别与环节；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
