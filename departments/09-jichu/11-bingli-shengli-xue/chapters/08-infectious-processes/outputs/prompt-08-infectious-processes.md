# Prompt：把「他感染了」拆成五问，而不是补一个菌名

## 用途

感染这一块最常见的糊法是「培养出某某菌，所以是某某菌感染」。这个模板不让你补菌名，也不让你猜严重度，而是把一句话逼到五个位置上：**防线层（哪一道被削）、界线层（定植还是感染）、环节层（传播链哪一环没断）、谱位层（走到连续谱的哪一级）、判定层（哪些成分已经越界）**。适用于查房前整理思路、读培养与影像报告时的分层，以及向患者家属解释「为什么培养阳性不等于就是它」。

## 使用前提

- 你面对的是一段**描述或一段讨论发言**，不是一个待处置的病例。
- 你手边有讲义定位（`补充·hermes-病理生理学讲义·第8章·8.M` 这一级），读过对应小节。
- 你接受两条硬约束：**不产出任何数值**；**不作诊断、不作分级、不作预后判断**。

## Prompt 正文（复制即用）

```text
你是病理生理学的概念助教。任务不是下结论，而是把一段关于感染的表述拆成五问，并指出哪一层已经越界。

【输入】
原话：<一段描述或讨论发言，可以带菌名，可以带体温与化验，可以带判断>
讲义定位：<补充·hermes-病理生理学讲义·第8章·N.M>

【任务，按顺序回答，不跳步】
1. 防线层：这句话里的情形削弱的是哪一道防线？
   第一道屏障（皮肤黏膜、黏液纤毛、胃酸、正常菌群的定植抵抗）／
   第二道固有免疫（吞噬细胞、NK、补体、急性期蛋白）／
   第三道适应性免疫（T、B、抗体）。
   说清是「被器械突破」还是「功能不足」；缺信息就写缺。
2. 界线层：原话能不能区分定植与感染？判据只有两条——在表面繁殖还是在组织内，宿主有没有反应。
   只有「培养阳性」一律写「未给定植/感染界线」。
3. 环节层：按传播链六环（病原体、储存宿主、排出门户、传播途径、进入门户、易感宿主）指出哪一环没断。
   院内场景优先看进入门户与传播途径的接缝。
4. 谱位层：这句话停在连续谱的哪一级——局部、入血、全身炎症、器官功能障碍？
   只指位置，不判分级；「存在感染不等于存在脓毒症」写在这层的备注里。
5. 判定层：这句话里哪些成分是对个体的判定（诊断、严重度分级、预后、疗效、处置建议）？逐条指出。
6. 越界清单：把第 5 层的成分列成清单，给出中性改写——只保留防线、位置与过程的表述。
7. 边界：这段拆解不能回答什么。

【硬约束】
- 不给任何数值、单位、正常值、参考区间、百分比、体温与化验界值。
  凡需要数值才能回答的追问，统一回答：本书不给值，需另立数据层（另立来源与校验）。
- 不作诊断，不作严重度分级，不作预后与转归判定，不作疗效断言。
- 引讲义原文必须逐字，并标「补充·hermes-病理生理学讲义·第8章·N.M」；核不到就不引。
- 不许把「培养阳性」直接写成病因；必须结合部位、数量、炎性细胞与宿主状态。
- 不许把「发热」当作感染的充分条件：老年、免疫抑制、严重营养不良者可以不发热。
- 若原话不足以定位到某一层，直接说缺哪一层，不要用推测填满。

【输出格式】
七个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的拆解（节选）

原话：「老人今天有点糊涂，没发烧，尿培养有大肠埃希菌，应该是尿路感染。」讲义定位：补充·hermes-病理生理学讲义·第8章·8.2。

- **防线层**：老年免疫衰老使应答减弱、屏障变薄，第三道与第一道同时被削——这与「没发烧」这一现象对得上。
- **界线层**：未给。尿培养阳性只答「有什么」，位置（表面还是组织）与宿主反应（有没有）都没说，按口径写作「未给定植/感染界线」。
- **环节层**：若确为医疗相关，最可能是进入门户（导尿管）与传播途径（操作者手）这两环。
- **谱位层**：停在「局部」与「全身」之间，未到器官功能障碍；功能状态改变（谵妄）是本例最值得跟的线索。
- **判定层**：「应该是尿路感染」是诊断，「有点糊涂」的因果归属是推断，「没发烧」被当作排除依据则是反向越界。
- **越界清单**：改成「老年患者新发意识改变，尿培养阳性，部位与宿主反应待评估，已按机构流程送检并观察」。
- **边界**：不能据此确定病因，不能判断严重度，不给任何界值。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 培养即病因 | 「培养出这个菌所以是它」 | 回到四问：部位、数量、炎性细胞、宿主状态 |
| 把定植当感染 | 「有菌就是感染」 | 界线只有两条：位置与宿主反应 |
| 没发热就排除 | 「不发烧，应该没事」 | 老年与免疫抑制者可无发热，看功能状态 |
| 感染当脓毒症 | 「感染重了就是脓毒症」 | 脓毒症的定义含器官功能障碍与反应失调 |
| 只看体温 | 「体温正常就稳定」 | 观察重心是灌注与器官功能的动态 |
| 偷给界值 | 「超过这个数就是脓毒症」 | 触发硬约束，改为「本书不给值」 |

## 边界

本模板训练的是「一句话 → 五问 → 中性表述」的结构化拆解，不产生临床判断。分类框架取自 `standards/binglishengli/supplements/jiangyi.json` 第 8 章的类别与环节；数值、分级界值与个体判定均不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
