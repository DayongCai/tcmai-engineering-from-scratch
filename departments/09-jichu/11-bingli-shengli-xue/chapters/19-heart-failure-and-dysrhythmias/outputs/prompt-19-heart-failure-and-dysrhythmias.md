# Prompt：把「他一直挺稳定的」拆成一本代偿账

## 用途

心衰讨论里最常见的一句糊话是「他平时挺稳定的，这次不知道怎么就重了」。这句话把两件事合并了：**稳定的表象**与**储备的余额**。本模板不替任何人判断病情，只做一件事——把一段关于心衰过程的叙述，按「代偿 → 重构 → 失代偿」拆成三层，并逐条写出每一层付出的代价记在哪一栏。适用于病例讨论前的自检、护理交班的机制复述，以及读本章第二至五节时把「代偿」这个褒义词还原成中性词。

## 使用前提

- 输入是一段**机制叙述或讨论发言**，不是一份待判定的病历。
- 手边有讲义定位（`补充·hermes-病理生理学讲义·第19章·19.5` 这一级），读过对应小节。
- 接受两条硬约束：**不产出任何数值**；**不作诊断、不作分级、不作预后判定**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是判断病情轻重，而是把一段关于心衰过程的表述拆成三层，并把每一层的代价逐条记账。

【输入】
原话：<一段机制叙述、交班描述或讨论发言>
讲义定位：<补充·hermes-病理生理学讲义·第19章·N.M>

【任务，按顺序回答，不跳步】
1. 输出与需求的对比：这句话说的是「输出绝对不足」，还是「需求上升时供不上」？两者都属心衰，但推理路径不同。
2. 代偿层：句子里出现了哪几层代偿——即时的（Starling 换压力、心率换时间）、神经体液的（交感、RAAS、抗利尿激素与利钠肽）、结构的（向心性 / 离心性肥厚）？列出来，没提到的写「未提」。
3. 代价层：为每一层代偿各写一句代价，并指出这笔账记在哪个下游（淤血 / 缺血 / 后负荷 / 纤维化 / 顺应性 / 电不均一）。
4. 重构层：这句话有没有提到结构性改变？若有，归到心肌、间质、几何、电四层中的哪一层；若没有，写「未给重构」。
5. 失代偿层：这句话把加重归因于哪条路径——储备耗尽、代偿机制自身致病、诱因叠加？三条常并存，逐条标「有 / 无 / 未提」。
6. 越界清单：这句话里哪些成分是对个体的判定（诊断、分级、预后、疗效）？逐条指出，并给出只保留机制的中性改写。
7. 边界：这段拆解不能回答什么。

【硬约束】
- 不给任何数值、单位、正常值、阈值、百分比。凡需要数值才能回答的追问，统一回答「不给值，须另立数据层」。
- 不作诊断，不作心功能分级，不作预后与转归判定。
- 引讲义原文必须逐字，并标「补充·hermes-病理生理学讲义·第19章·N.M」；核不到就不引。
- 不把讲义标成「教材」。
- 原话不足以定位到某一层时，直接写缺哪一层，不用推测填满。

【输出格式】
七个小标题各答一到三句；第 3 项用一个「代偿 → 代价 → 记账处」的三列小表；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/治疗/用药依据。」
```

## 示例：一次合格的拆解（节选）

原话：「他平时挺稳定的，这次感冒之后喘得厉害，估计是感染把心脏拖垮了。」定位：`补充·hermes-病理生理学讲义·第19章·19.7`。

- **输出与需求**：说的是需求上升型——感染提高代谢需求，而输出没有相应提高；不是输出绝对值的问题。
- **代偿层**：未提。原话完全没有说靠什么维持了「稳定」。
- **代价层**：正因为没提代偿，代价也无从记。这一步必须写「未提」，不能替它补。
- **重构层**：未给重构。
- **失代偿层**：储备耗尽「未提」；代偿机制自身致病「未提」；诱因叠加「有」（感染）。
- **越界清单**：「拖垮了」是把结果写成判定；改成「在既有储备基础上叠加了新的负荷」。
- **边界**：不能据此判断任何人的病情走向；不给任何阈值。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 把「稳定」当成安全 | 「稳定期说明代偿成功」 | 代偿期是以持续透支换取表面稳定，必须同时写代价 |
| 只记益处不记账 | 把交感激活写成「身体的智慧」 | 每层代偿后面强制跟一句代价 |
| 用诱因替代机制 | 「感染引起心衰加重」 | 诱因只解释时点，机制要写储备已耗尽 |
| 症状方向当病情方向 | 「呼吸困难好转了，说明好转」 | 全心衰时肺淤血可看似减轻，须核对是哪一段链条变了 |
| 偷给数值 | 「射血分数低于某值就是心衰」 | 触发硬约束，改为「不给值，另立数据层」 |
| 把环节写成处置 | 「应该加用某类药物」 | 只写切在环的哪一段，药名与剂量不写 |

## 边界

本模板训练的是「过程 → 三层 → 代价账」的机制表达能力，不产生临床判断。机制框架取自《hermes-病理生理学讲义》第 19 章；数值与判定不在本课程范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
