# Skill：神经系统结构与功能——六层定位与两条线索

## 何时用

- 有人给出一组神经体征，却没说清病灶在哪一段通路
- 要判断一处「无力」是上运动神经元还是下运动神经元
- 要把意识障碍拆成觉醒与内容两个成分
- 要解释脱髓鞘为什么能在轴突未死时造成严重缺损（以及为什么周围神经再生优于中枢）
- 遇到「这算不算急症」「要不要做影像」这类追问，需要一致的拒答口径

## 核心判据（四问）

1. **走的是哪条轴？** 解剖轴（中枢 / 周围）与功能轴（躯体 / 自主）。两条轴交叉才有格，只答一条等于没定位。
2. **落在哪个层级？** 脊髓（节段反射与通道）／脑干（生命中枢、脑神经核、上行网状激活系统）／小脑（时序与平衡）／基底节（启动与抑制）／丘脑（感觉中转）／皮层（整合）。层级不是独裁，任一环受损都表现为运动异常，只是形式不同。
3. **上还是下？** 肌张力、腱反射、病理反射、肌萎缩、肌束颤动五栏逐条对。两栏同时成立（如肌萎缩叠加反射亢进）不是矛盾，而是上下同时受累的标志。
4. **时间怎么走？** 突发 / 数小时至数天 / 数月以上。部位与时间交叉，才形成病因假设。

## 执行步骤

```text
1. 抄原话，不改写：把要换算的那段描述原样放在第一行
2. 归轴：中枢 / 周围 × 躯体 / 自主，四格选一格
3. 定平面：六个层级逐一比对，不符的写「不符」，不硬套
4. 分上下：五栏对照表逐条填，缺项写「未给」
5. 拆意识：觉醒（脑干）与内容（皮层）分开描述，注意两者可分离
6. 定时间：三档选一档，并写出它提示的病因类别
7. 交叉与报边界：平面 × 时间出一到两个假设，只写成类别
```

## 硬约束

- **不给数值、单位、正常值、参考区间、百分比。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不作诊断，不作定位结论。** 六层定位图在本课程里是机制坐标，不是对某个人的结论。
- **引文逐字。** 标「补充·hermes-病理生理学讲义·第43章·43.M」；核不到就不引。讲义是本仓库原创教学正文，不许写成任何外文教材的译本。
- **层次必标。** 分子与离子、细胞、环路、系统四个层次的表述不混写；一句话里只装一个层次的内容。
- **不作处置建议。** 影像选择、用药、监测项目属临床决策，本 Skill 只给机制与判据。

## 交付物

1. 一段四问拆解（轴 → 层级 → 上下 → 时间），缺项如实标缺
2. 一张层级对照：六层逐条对上或标「不符」
3. 一句病因方向：平面 × 时间交叉后的一到两个类别假设
4. 一处边界：本章不给值、不作诊断，数值须另立数据层

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 用一个平面盖住全部 | 「这是脑梗」当成解释 | 六层逐一比对，把不符的写出来 |
| 跳过时间轴 | 只报部位，病因假设立不住 | 补上起病方式再交叉 |
| 把晚期信号当前兆 | 「瞳孔大，所以要脑疝了」 | Cushing 反应与瞳孔散大是代偿近极限的信号 |
| 上下混写 | 把肌萎缩加反射亢进当矛盾 | 逐栏标注，这正是两栏同时成立 |
| 名录化 | 十二对脑神经背完就算学会 | 名录只是取坐标的工具，不是目的 |
| 偷给数值 | 「瞳孔 5 毫米」 | 改为方向性表述，或回「本书不给值」 |

## 边界

本 Skill 只处理「一段体征描述 → 六个平面 → 两条线索」的结构化换算，不涉及数值、判定与临床决策。层级与通路取自《hermes-病理生理学讲义》第 43 章的表述；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
