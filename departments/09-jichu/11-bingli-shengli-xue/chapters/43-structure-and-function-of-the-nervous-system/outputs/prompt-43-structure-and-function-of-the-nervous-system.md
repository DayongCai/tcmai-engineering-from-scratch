# Prompt：把一组神经体征换算成一个解剖平面

## 用途

神经科最常见的一句含糊话是「患者有一侧无力」。这句话把六种可能压成了一种：皮层、内囊、脑干、脊髓前角、周围神经、神经肌肉接头，每一个平面截断的纤维不同，体征组合也不同。这个模板不让你背病名，而是把一组体征按层级与通路拆到具体平面，再用起病方式给一个病因方向。

适用于读病例摘要、写护理记录中的神经评估、做课前讨论，也适用于后面三章（急性脑功能障碍、慢性神经功能障碍、特殊感觉异常）的复盘：那三章讲的都是这张定位图上的局部放大。

## 使用前提

- 你手上是一段**体征描述**，不是一个待确诊的病例。
- 你读过讲义本章对应小节（`补充·hermes-病理生理学讲义·第43章·43.10` 这一级），能指出每条判断的出处。
- 你接受两条硬约束：**不产出任何数值**；**不作诊断、不作定位结论**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是给结论，而是把一段神经体征描述换算成解剖平面，再按起病方式给出病因方向。

【输入】
原话：<一段体征描述>
讲义定位：<补充·hermes-病理生理学讲义·第43章·43.M>

【任务，按顺序回答，不跳步】
1. 归轴：这条描述落在躯体部分还是自主部分？中枢还是周围？只归类，不写病名。
2. 定平面：按六个层级逐一比对——脊髓、脑干、小脑、基底节、丘脑、大脑皮层。对不上的写「不符」，能对上的说明理由（哪一组纤维被截断）。
3. 分上下：运动缺损属上运动神经元还是下运动神经元？按肌张力、腱反射、病理反射、肌萎缩、肌束颤动五栏逐条对。
4. 查意识与瞳孔：若涉及意识，拆成觉醒（脑干上行网状激活系统）与内容（大脑皮层）两个成分；若瞳孔异常，说明是哪一侧的动眼神经通路受压。
5. 定时间：突发 / 数小时至数天 / 数月以上，三档选一档，并说明它提示哪一类病因方向。
6. 交叉：把第 2 步的平面与第 5 步的时间交叉，写出 1 至 2 个病因假设；假设只写成类别，不写成诊断。
7. 边界：这段拆解不能回答什么。

【硬约束】
- 不给任何数值、单位、正常值、参考区间、百分比。凡需数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作定位结论，不作预后判定，不作疗效断言。
- 引讲义原文必须逐字，并标「补充·hermes-病理生理学讲义·第43章·43.M」；核不到就不引。
- 某一步缺证据就写「未给」，不要用推测填满。

【输出格式】
七个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的换算（节选）

原话：「老人突然说话含糊，右侧口角和右手不听使唤，两小时前还好好的。」讲义定位：补充·hermes-病理生理学讲义·第43章·43.10。

- **归轴**：躯体部分，中枢。
- **定平面**：小脑不符（无共济失调描述）；脊髓不符（面部受累排除脊髓以下）；脑干可疑（需眼球运动与瞳孔）；皮层与内囊均可解释对侧下面部与上肢，内囊型缺损通常更「齐全」，皮层型可能只损一部分。写「皮层 / 内囊，待第 4 步收紧」。
- **分上下**：描述里没有腱反射与肌张力，属「未给」，不能判上或下。
- **意识与瞳孔**：意识未描述，按「未给」处理；瞳孔未描述。
- **定时间**：突发，归「血管事件」这一档。
- **交叉**：突发 × 皮层或内囊，指向缺血性或出血性血管事件；不写具体病名。
- **边界**：不能由此判断病灶大小、可逆性与处置方式；数值一律不给。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 用一个平面盖住全部 | 「这是脑梗」 | 回到六个层级逐一比对，把不符的写出来 |
| 跳过时间轴 | 只报部位 | 补上起病方式，再交叉 |
| 把体征当结论 | 「瞳孔大，所以脑疝」 | 说明是同侧动眼神经受压这一环，再说明它是晚期信号 |
| 上下运动神经元混写 | 「反射亢进又有肌萎缩」当成矛盾 | 这正是两栏同时成立的组合，须逐栏标注 |
| 偷给数值 | 「瞳孔 5 毫米」 | 触发硬约束，改为方向性表述 |
| 越过机制给处置 | 「应当立即溶栓」 | 处置属临床决策，模板不产出 |

## 边界

本模板训练的是「归轴 → 定平面 → 分上下 → 定时间 → 交叉」的分层表达能力，不产生临床判断。层级与通路划分取自《hermes-病理生理学讲义》第 43 章的表述；数值与判定不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
