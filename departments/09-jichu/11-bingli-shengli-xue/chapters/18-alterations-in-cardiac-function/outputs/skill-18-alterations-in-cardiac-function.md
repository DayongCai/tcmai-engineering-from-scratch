# Skill：心脏功能异常——四类失衡、三个中介与一张网

## 何时用

- 一份记录里同时出现杂音、节律不齐、气促与水肿，需要找出主线
- 要区分压力负荷与容量负荷，以及它们对应的向心性 / 离心性肥厚
- 要解释为什么「去除初始病因」并不总能逆转病情
- 要判断某个表现是收缩侧还是舒张侧的问题
- 遇到「心功能几级」「狭窄多重」这类追问，需要一致的拒答口径

## 核心判据（四问）

1. **哪一类失衡？** 泵（收缩力下降 / 舒张充盈受限）、节律（形成 / 传导）、瓣膜（狭窄 / 关闭不全）、冠脉（供 < 需）。四类是定位工具，不是病名。
2. **走哪个中介？** 负荷（泵到瓣膜、泵到冠脉的转换器）、氧耗（泵到冠脉）、结构重塑（所有通路共同的固化器）。中介是四类之间互相转化的通道。
3. **压力还是容量？** 狭窄＝压力负荷→向心性肥厚→早期舒张功能受损；关闭不全＝容量负荷→离心性肥厚→早期收缩功能受损与心腔扩大。
4. **回路成立吗？** 只要写出两类以上失衡，就必须给出反向的一步，否则是把网络读成了链条。

## 执行步骤

```text
1. 抄记录，不改写：按症状 / 体征 / 结构 / 功能 / 电 / 生化分类
2. 归四类：每条表现落到泵 / 节律 / 瓣膜 / 冠脉，落不进去的标「未给」
3. 定主线：给理由（负荷方向、时序、结构证据），不给病名
4. 走中介：负荷 → 氧耗 → 结构重塑，逐段写转化
5. 画回程：第二类失衡如何加重第一类，至少一步
6. 排时序：损伤先行、症状后至，还是同时出现
7. 报边界：不给值、不分级、不写处置
```

## 硬约束

- **不给数值、单位、分级、分度、时间窗、百分比。** 需要数值才能回答的追问，统一回「本书不给值」。
- **不作诊断，不作分级。** 四类失衡是机制类别；确诊依赖结构与功能的客观评估。
- **引文逐字。** 标「补充·hermes-病理生理学讲义·第18章·N.M」；核不到就不引。
- **网络不许写成链条。** 惯性说明去因不等于逆转；可干预（如重构）说明惯性不是不可逆，两句一起读。
- **线索会沉默失效。** 老年人与糖尿病患者缺血可仅表现为气促或乏力而无疼痛，线索不出现不等于没有问题。

## 交付物

1. 一张四类归类表（含「未给」项）
2. 一句主线判断，附三条以内的理由
3. 一条中介路径（负荷 / 氧耗 / 结构重塑）
4. 一段回路（至少含反向一步）
5. 一句时序判断（损伤先行、症状后至 / 同时出现 / 未给）
6. 一句边界：不给值、不作诊断，数值须另立数据层

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 把四类当四个病 | 并存时无法定位 | 先归类，再画回路 |
| 混淆两类瓣膜失衡 | 把压力负荷与容量负荷当成一回事 | 负荷方向分开说，肥厚类型随之不同 |
| 单向链条 | 只写病因到结果 | 回路至少写一步反向 |
| 用症状时时点当病程起点 | 系统性低估病程 | 补上「损伤先行、症状后至」的时序 |
| 把重构当纯结局 | 忽略它是可干预环节 | 重构既是后果，也是着力点 |
| 被追问就报分级 | 越出本书口径，且数值无来源 | 统一回「本书不给值」 |

## 与相邻章节的接缝

- 上一章（心脏功能）：本章的四个因素在那里是正常生理，在这里变成四类失衡的机制来源。
- 第 19 章（心力衰竭与心律失常）：本章的泵失衡与节律失衡在那里合并成主线，本章的网络在那两章展开成自然史。
- 第 15 章（血流异常）：冠脉供-需失衡的后果（缺血、梗死）与那一章的梗死类型、时间窗共用一套语言。
- 第 16 章（血压异常）：瓣膜与泵的长期负荷最终落到血压与灌注那一侧，靶器官损害在那里收口。

## 边界

本 Skill 只处理「一份记录 → 四类失衡 → 网络」的结构化拆解，不涉及数值、分级与临床处置。机制框架取自《hermes-病理生理学讲义》第 18 章；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
