# Prompt：把一份复杂的心脏记录压回四类失衡，再顺着网络往回走

## 用途

心脏这一块最难的不是记病名，而是**在多个异常同时出现时找出主线**。同一份记录里可能既有杂音、又有节律不齐、还有气促与水肿，而四类失衡可以互为因果：泵衰竭抬高前负荷，前负荷拉高壁张力，壁张力加剧缺血，缺血又制造节律问题。这个模板让你先把记录压回四类失衡之一（或之几），再顺着负荷、氧耗、结构重塑三个中介往回走，看它是怎么被牵动、又牵动了谁。适用于读一份心脏相关记录、交接时复述机制、以及在讨论「为什么不只是某一个病」时给出结构。

## 使用前提

- 你面对的是一段**观察与记录**，不是一个待处理的病例。
- 你读过讲义对应节（`补充·hermes-病理生理学讲义·第18章·N.M`）。
- 你接受两条硬约束：**不引用、不换算任何数值与分级**；**不作诊断、不作分级、不写处置与用药**。

## Prompt 正文（复制即用）

```text
你是病理生理学助教。任务不是给诊断，而是把一段记录压回四类失衡，并顺着负荷、氧耗、结构重塑三个中介画出一小段网络。

【输入】
记录：<症状 / 体征 / 结构描述 / 功能描述 / 电活动 / 生化线索，允许带患者原话>
讲义定位：<补充·hermes-病理生理学讲义·第18章·N.M>

【任务，按顺序回答，不跳步】
1. 归类：把每条表现归入四类失衡之一——泵（收缩力下降 / 舒张充盈受限）、节律（形成 / 传导）、瓣膜（狭窄 / 关闭不全）、冠脉（供 < 需）。归不进去的写「未给」，不补猜。
2. 主线：哪一类最可能是主线？只写理由（负荷方向、时序、结构证据），不给病名。
3. 中介：沿负荷、氧耗、结构重塑三个中介，写出主线如何牵动第二类失衡；缺证据的环节写「未给」。
4. 反向：第二类失衡又如何回过头加重第一类？写成一到三步的回路，不许写成单向链条。
5. 时序：是「损伤先行、症状后至」，还是症状与损伤同时出现？原话没给时间就写「未给」。
6. 缺口：为了把主线定死，还差哪几项观察？只列观察项，不列检查项目与操作。
7. 边界：这段拆解不能回答什么。

【硬约束】
- 不给任何数值、单位、分级、分度、时间窗、百分比。凡需数值才能回答的追问，统一回答：「本书不给值」。
- 不作诊断，不作分级，不写药物、剂量、手术或器械之类的处置指令。
- 引讲义原文必须逐字，并标「补充·hermes-病理生理学讲义·第18章·N.M」；核不到就不引。
- 不许把四类失衡写成四个独立病种：只要写出两类以上，就必须给出它们之间的转化路径。

【输出格式】
七个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/处置依据。」
```

## 示例：一次合格的拆解（节选）

记录：「走几步就喘，夜里要垫高枕头；脚踝肿；听诊有杂音，脉搏忽快忽慢；年轻时查出过心脏结构问题。」讲义定位：补充·hermes-病理生理学讲义·第18章·18.1。

- **归类**：气促与端坐呼吸方向归泵（舒张充盈受限或收缩力下降，二者未分）；脚踝肿归泵（前负荷升高的后果）；杂音归瓣膜失衡（狭窄或关闭不全未分）；脉搏忽快忽慢归节律失衡。
- **主线**：瓣膜失衡更像起点——「年轻时查出过心脏结构问题」把时序前移，而瓣膜病变按讲义是同时提供压力或容量负荷、从起点推动循环的那一类。
- **中介**：瓣膜到泵走负荷这个中介（狭窄是压力负荷导致向心性肥厚，关闭不全是容量负荷导致离心性肥厚，两种路径的早期表现不同）；泵到节律走结构重塑这个中介（心腔扩大与纤维化改变传导路径）。
- **反向**：节律失衡使充盈时间不足、同步性丧失，泵功能进一步下降——回路成立。讲义的原话是网络一旦启动便有了自身的惯性。
- **时序**：属于损伤先行、症状后至：结构问题早年即存在，症状近年才出现。
- **缺口**：杂音的性质与部位、心腔是扩大还是肥厚、水肿是否对称，三项都缺，主线还定不死。
- **边界**：不能由此判断任何人的状态，不给分级；数值一律不给。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 把四类写成四个病 | 逐条罗列，不给转化路径 | 写两类以上必须写回路 |
| 用病名代替定位 | 「这是瓣膜病」 | 回到四类失衡与负荷方向 |
| 单向链条 | 只写瓣膜导致心衰，不写回程 | 回路至少要写出反向的一步 |
| 混淆两类瓣膜失衡 | 把狭窄与关闭不全当作同一回事 | 压力负荷与容量负荷分开说 |
| 忽略「症状后至」 | 用症状出现时间当病程起点 | 时序单独写，缺的标缺 |
| 偷给分级 | 「心功能几级」 | 触发硬约束，改为「本书不给值」 |

## 边界

本模板训练的是「一份记录 → 四类失衡 → 网络」的结构化拆解，不产生临床判断。机制框架取自《hermes-病理生理学讲义》第 18 章；分级、阈值与处置不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
