# Skill：血压异常——四个成分、三层调节与三个问题

## 何时用

- 有人拿一个读数来问「要不要紧」，需要一套不越界又能给出方向的回答口径
- 要区分收缩压升高为主与舒张压升高为主，并说出各自背后的机制
- 要判断一个「血压低」的说法指的是读数低还是灌注不足
- 要解释为什么慢性高血压一旦形成就倾向自我维持
- 遇到「多少算高」「降多少算达标」这类追问，需要一致的拒答口径

## 核心判据（四问）

1. **哪个成分？** 收缩压（每搏量与主动脉弹性）、舒张压（外周阻力与心率）、脉压（大动脉弹性）、平均动脉压（器官灌注的实际驱动压）。一个词底下两种机制时，先拆成分。
2. **哪层时间尺度？** 短期压力感受器反射（快但会适应）、中期肾素-血管紧张素-醛固酮（容量加阻力）、长期肾脏压力-利尿（设定点，曲线右移即慢性高血压）。
3. **哪条通路？** 容量（钠水潴留、前负荷）、阻力（交感、内皮、平滑肌增生）、结构（壁增厚、管腔缩小、血管稀少）。前两条可逆，第三条不可逆，这一条决定预后与可逆性。
4. **灌注够不够？** 意识、尿量、皮肤温度与颜色、毛细血管再充盈。血压是手段，灌注是目的。

## 执行步骤

```text
1. 抄读数与情境，不改写：体位、时间、状态、袖带、是否用药
2. 拆成分：这段话能落到四个成分里的哪几个，其余标「未给」
3. 第一问：数字可靠吗——袖带、姿势、手臂高度、静息、白大衣与隐蔽性
4. 第二问：急性还是慢性——急性看靶器官受累线索，慢性看心脑肾血管眼底五方向
5. 第三问：灌注够不够——意识、尿量、皮肤温度与颜色、毛细血管再充盈
6. 归通路：升高按容量 / 阻力 / 结构；降低按低血容量 / 心源 / 分布 / 梗阻
7. 报边界：不给值、不分级、不写处置
```

## 硬约束

- **不给数值、单位、界值、分级、百分比。** 需要数值才能回答的追问，统一回「本书不给值」。
- **不作诊断，不作分级。** 高血压分级、休克分期、靶器官损害分度都是机制类别，不是判定标准。
- **引文逐字。** 标「补充·hermes-病理生理学讲义·第16章·N.M」；核不到就不引。
- **三问的次序不许颠倒。** 先证伪读数，再定时间尺度，最后看灌注。颠倒一次，结论就建在沙上。
- **血压正常不等于灌注充分。** 分布性休克时心输出量可以正常甚至偏高，组织仍在灌注不足之中。

## 交付物

1. 一张成分表（四个成分中哪几个有信息，其余标「未给」）
2. 三问各一段（可靠吗 / 急性还是慢性 / 灌注够不够）
3. 一条通路归属（升高三条之一，降低四类之一，可并列）
4. 一张缺口清单（还差哪几项观察，只列观察项）
5. 一句边界：不给值、不作诊断，数值须另立数据层

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 直接答「高不高」 | 跳过三问，结论无依据 | 先证伪读数，再定时间尺度 |
| 拿读数当结论 | 「正常所以没事」 | 血压是手段，灌注是目的 |
| 把低血压当病 | 把灌注信号读成一个诊断 | 低血压是灌注不足的信号 |
| 忽略结构通路 | 以为压下去就算治好 | 功能与结构分开说，结构不可逆 |
| 一套标准套所有人 | 儿童、老年、妊娠、糖尿病全按成人线 | 标准跟着底板换 |
| 被追问就报界值 | 越出本书口径，且数值无来源 | 统一回「本书不给值」 |

## 边界

本 Skill 只处理「一个读数 → 三问 → 通路」的结构化拆解，不涉及数值、分级与临床处置。机制框架取自《hermes-病理生理学讲义》第 16 章；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
