# Prompt：把一个血压读数拆成三问，而不是回答「高不高」

## 用途

关于血压的绝大多数提问都落在同一个形状里：「这个数要不要紧？」本章的口径是不能直接回答这句——不是推脱，而是因为回答它需要三个前提，而这三个前提恰好是本章的全部内容：**这个数字可靠吗、这是急性还是慢性、灌注够不够**。这个模板把一句带着读数的追问，拆成这三问加一个成分表，让回答停在机制层而不越到判定层。适用于交接班时描述一位患者的血压状态、写观察记录之前的自检，以及读后续各章（休克、心力衰竭）时反复套用——那两章讲的都是同一个词在灌注那一侧的样子。

## 使用前提

- 你面对的是一段**观察与读数**，不是一个待处理的病例。
- 你读过讲义对应节（`补充·hermes-病理生理学讲义·第16章·N.M`），知道该节讲的是哪一层。
- 你接受两条硬约束：**不引用、不换算、不复述任何血压值与界值**；**不作诊断、不作分级、不写处置与用药**。

## Prompt 正文（复制即用）

```text
你是病理生理学助教。任务不是判断「高不高」，而是把一个血压读数拆成三问，并指出每一问缺什么信息。

【输入】
读数与情境：<谁、什么体位、什么时间、什么状态下测的；有无症状；是否用药；允许带患者原话>
讲义定位：<补充·hermes-病理生理学讲义·第16章·N.M>

【任务，按顺序回答，不跳步】
1. 成分：这段话涉及四个成分里的哪几个——收缩压（每搏量与主动脉弹性）、舒张压（外周阻力与心率）、脉压（大动脉弹性）、平均动脉压（器官灌注的实际驱动压）？只写成分与对应机制，不复述数值。
2. 第一问 数字可靠吗：袖带尺寸、姿势、手臂高度、是否静息、有无白大衣或隐蔽性高血压的可能。列出可疑处；没有可疑处就写「未见」。
3. 第二问 急性还是慢性：是突然出现还是长期存在？急性升高要看有无靶器官受累的线索（剧烈头痛、胸痛、呼吸困难、意识改变、视力改变、肢体无力或言语不清、少尿）；慢性升高要看靶器官评估的五个方向（心、脑、肾、血管、眼底）。
4. 第三问 灌注够不够：意识、尿量、皮肤温度与颜色、毛细血管再充盈。指出这三问的次序为什么不能颠倒。
5. 通路：若方向是升高，把它归到容量、阻力、结构三条通路中的哪一条（可并列）；若方向是降低，归到低血容量、心源、分布、梗阻四类中的哪一类。
6. 缺什么：为了把三问答完，还差哪几项观察？只列观察项，不列检查项目与操作。
7. 边界：这段拆解不能回答什么。

【硬约束】
- 不给任何数值、单位、界值、分级、百分比；不复述输入里的读数，也不换算。凡需数值才能回答的追问，统一回答：「本书不给值」。
- 不作诊断，不作分级，不写药物、剂量、给药时间之类的处置指令。
- 引讲义原文必须逐字，并标「补充·hermes-病理生理学讲义·第16章·N.M」；核不到就不引。
- 三个词不互换：血压是手段，灌注是目的；血压正常不等于没有灌注不足。

【输出格式】
七个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/处置依据。」
```

## 示例：一次合格的拆解（节选）

读数与情境：「上午门诊测的，坐着，袖带是诊室公用的，说有点紧；平时在家测都正常，没有不舒服。」讲义定位：补充·hermes-病理生理学讲义·第16章·16.7。

- **成分**：这段话只涉及一个时点的读数，无法分出收缩压与舒张压各自的机制，也拿不到脉压与平均动脉压。按讲义，平均动脉压才是器官灌注的实际驱动压，而它在这段描述里是缺的。
- **第一问 可靠吗**：可疑。袖带尺寸不合会使读数系统性偏高或偏低，叙述里「有点紧」正落在这个误差来源上；未说明静息时间与手臂高度，也未说明是否重复测量。
- **第二问 急性还是慢性**：更像慢性或假象——「平时在家测都正常」与本次读数方向不一致，这正是白大衣高血压与隐蔽性高血压需要区分的形状。指向靶器官受累的线索：未见。
- **第三问 灌注**：这段描述没有给意识、尿量、皮肤温度与颜色、毛细血管再充盈中的任何一项，所以灌注这一问「未给」。次序不能颠倒的理由就在这里：前两问没答完，第三问无从谈起。
- **通路**：方向尚未定，通路归不进去。若最终确认是升高，还要分容量、阻力、结构三条，其中结构一条决定它能否被逆转。
- **缺什么**：还差对侧手臂的重复测量、静息时长、袖带尺寸是否匹配、以及诊室外测量的记录。
- **边界**：不能由此判断任何人的状态，也不给界值与分级；数值一律不给。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 直接答「高不高」 | 「这个数偏高，要注意」 | 回到三问，先证伪读数 |
| 拿读数当结论 | 「血压正常，所以没事」 | 血压是手段，灌注是目的 |
| 跳过时间尺度 | 把慢性升高与急性升高混为一谈 | 第二问必须单独回答 |
| 只谈水平不谈时间 | 忽略靶器官损害是两个变量的乘积 | 补上持续时间与靶器官五方向 |
| 把降压当治因 | 「压下去就好了」 | 结构通路不可逆，功能与结构分开说 |
| 偷给界值 | 「超过多少算高」 | 触发硬约束，改为「本书不给值」 |

## 边界

本模板训练的是「一个读数 → 三问 → 通路」的结构化拆解，不产生临床判断。机制框架取自《hermes-病理生理学讲义》第 16 章；数值、分级与处置不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
