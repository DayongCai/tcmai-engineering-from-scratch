# Skill：遗传与发育性疾病——形状、变量、动作、语言

## 何时用

- 有人问「这病会不会传下去」「下一个孩子有没有事」
- 拿到一份筛查结果被当成确诊，或被当成「没事」
- 家系里出现「上代没有、这代有」或「一家人轻重悬殊」的情形
- 要说明为什么表型相似的畸形可以由完全不同的病因引起
- 需要一套既不越界也不含糊的风险沟通口径

## 核心判据（四问）

1. **形状是什么？** 垂直（代代有、男女相近）／水平（同代多人、上代无）／交叉（男性为主、无男传男、女儿全为携带者）／非经典（母系、亲本来源、连续分布、逐代加重）。形状判不出就写未定，不套比例。
2. **四个变量查了吗？** 外显率（携带者中实际出现表型的比例）／表现度（同一基因型在不同个体间的严重程度差异）／遗传异质性（不同基因可致相同表型）／新发突变。四条各自给证据或标缺。
3. **是筛查还是诊断？** 筛查把人群分成风险高低，结果是风险估计；诊断对一个人下结论，须经诊断性检测。两个动作不能混。
4. **语言是概率还是必然？** 用可能、风险升高、不能排除、需进一步确认；不用必然、一定、肯定。过度承诺与过度恐吓是同一个错误的两个方向。

## 执行步骤

```text
1. 抄原话，不改写：把家族描述或结果原样放在第一行
2. 画形状：三代结构、性别分布、有无男传男、父母是否受累
3. 查变量：外显率 / 表现度 / 异质性 / 新发，四条各写「有依据」或「未给」
4. 分动作：这是筛查结果还是诊断性检测？前者只作风险估计
5. 改语言：把结论改写成概率表述，删掉必然与肯定
6. 列可预防项：叶酸状态、血糖控制、避免已知致畸物、疫苗，只列类别
7. 报边界：不给数值、不作诊断、不给生育建议
```

## 硬约束

- **不给数值、复发风险、切割值、参考区间、百分比。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」，并把问题交回遗传咨询。
- **不作诊断，不作正常与异常判定。** 筛查阳性不等于诊断；意义未明的变异不作诊断依据；外显率不全与表现度差异必须说明。
- **非指令性。** 提供信息与支持，不替来访者做决定；不写「应该生」「不该生」这类话。
- **引文逐字。** 标「补充·hermes-病理生理学讲义·第6章·6.M」；核不到就不引。讲义是本仓库原创教学正文，不许写成任何外文教材的译本。
- **显性不等于重病。** 显性描述的是表现所需条件（杂合即可表现），不描述轻重；这条错读会连锁影响整张家系图的判读。

## 交付物

1. 一张三代家系结构描述：患者分布、性别、有无男传男、父母状态
2. 一句形状判断：垂直 / 水平 / 交叉 / 非经典之一，或「形状未定」
3. 一张四变量核对表：外显率、表现度、异质性、新发，各标有依据 / 未给
4. 一段概率表述：把必然改成可能，把准话改成待确认
5. 一处边界：不给数值、不作诊断、不给生育建议

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 比例先行 | 拿着「一半」「四分之一」套家系 | 先看形状，比例只在形状确定后才用 |
| 筛查当诊断 | 阳性即结论 | 筛查只给风险估计 |
| 显性当重病 | 判断严重程度出错 | 显性只讲表现条件 |
| 忽略外显率不全 | 「上代没有所以不是遗传」 | 外显率不全可造成跳代 |
| 表型反推病因 | 「长得像就是同一种病」 | 表型相似可由遗传或环境两条路造成 |
| 给生育建议 | 越界且违背非指令性 | 给信息与选项，决定权留在家庭 |

## 边界

本 Skill 只处理「家族描述 → 形状与变量 → 动作与语言」的结构化拆解，不涉及数值、诊断与生育决策，也不替代遗传咨询。框架取自《hermes-病理生理学讲义》第 6 章的表述；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
