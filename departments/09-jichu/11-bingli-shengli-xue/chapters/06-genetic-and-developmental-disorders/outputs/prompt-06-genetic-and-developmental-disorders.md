# Prompt：把「这病会不会传下去」拆成形状、变量、动作、语言四步

## 用途

家族里出现一个病，第一个问题总是同一个：会不会传下去。这个问题不能用「会」或「不会」回答，只能拆：先看家系的传递形状，再看四类变量（外显率、表现度、异质性、新发），然后分清筛查与诊断是两个动作，最后用概率而不是必然讲话。四步里任何一步省掉，答案就会变成一句越界的准话。

适用于家庭讨论的记录整理、遗传咨询的准备材料、写发育异常的机制说明；也适用于后面各章（肿瘤、先天畸形、代谢病）里凡是涉及家族与风险的地方。

## 使用前提

- 你手上是一段**家族描述或一份筛查结果**，不是一个待确诊的病例。
- 你读过讲义本章对应小节（`补充·hermes-病理生理学讲义·第6章·6.7` 这一级）。
- 你接受两条硬约束：**不产出任何数值与复发风险**；**不作诊断、不作对任何个体的判定**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是回答「会不会传」，而是把这个问题拆成四步，并说明哪一步证据不够。

【输入】
原话：<一段家族描述或一份筛查结果>
讲义定位：<补充·hermes-病理生理学讲义·第6章·6.M>

【任务，按顺序回答，不跳步】
1. 形状：把家系信息整理成三代结构——患者在哪几代、性别分布、有无男性到男性的传递、父母是否受累。据此判断形状属垂直、水平、交叉，还是四种非经典之一（线粒体 / 印记 / 多因子 / 动态突变）。形状判不出就写「形状未定」，不要套比例。
2. 变量：逐条检查四个变量——外显率是否不全、表现度是否差异大、是否为遗传异质性、是否可能为新发突变。每一条写明依据来自原话的哪一句，或写「未给」。
3. 动作：区分筛查与诊断。原话若是一份筛查结果，明确指出它给的是风险估计而不是诊断，须经诊断性检测确认；若已做诊断性检测，写明依据的类型。
4. 语言：把结论改写成概率表述——可能、风险升高、不能排除、需进一步确认。禁止出现必然、一定、肯定。
5. 可预防项：若涉及发育异常，列出讲义给的可预防因素类别（叶酸状态、血糖控制、避免已知致畸物、疫苗），只列类别，不给方案。
6. 越界清单：原话里哪些成分是对个体的判定（诊断、预后、生育建议）？逐条指出并给中性改写。
7. 边界：这段拆解不能回答什么，以及应当转给谁。

【硬约束】
- 不给任何数值、复发风险、切割值、参考区间、百分比。需要数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」，并把问题交回遗传咨询。
- 不作诊断，不作正常与异常判定；筛查阳性不等于诊断；意义未明的变异不作诊断依据。
- 不给生育建议。非指令性：提供信息与支持，不替来访者做决定。
- 引讲义原文必须逐字，并标「补充·hermes-病理生理学讲义·第6章·6.M」；核不到就不引。

【输出格式】
七个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的拆解（节选）

原话：「我外婆、我妈都有这个病，我是女儿，现在怀孕了，孩子会不会有？」讲义定位：补充·hermes-病理生理学讲义·第6章·6.2。

- **形状**：两代女性连续受累，符合垂直传递的样子；但缺男性成员的信息，无法判断是否存在男性到男性的传递，也无法排除非经典方式。写「形状倾向垂直，证据不全」。
- **变量**：外显率——两位受累者均表现，但家系小，不能据此判断外显率完全；表现度——原话未给轻重差异，写「未给」；遗传异质性——未给；新发突变——上代已有患者，可能性低但不能排除。四条里三条「未给」。
- **动作**：原话没有给任何检测结果。要区分两件事：携带者筛查给的是风险估计，诊断性检测才谈得上确认；两者都不能由家系描述替代。
- **语言**：可写「该家系的表现与某种垂直传递的方式相容，风险可能升高，需遗传咨询与相应检测进一步明确」；不写「孩子一定会」或「孩子一定不会」。
- **可预防项**：若最终指向神经管缺陷一类，讲义列的可预防因素类别包含叶酸状态、血糖控制、避免已知致畸物、疫苗；此处只列类别。
- **越界清单**：「孩子会不会有」被要求直接回答，属对个体的判定；改为概率表述，并把决定权交回家庭与咨询人员。
- **边界**：不能给出具体风险数值，不能判断该家系的遗传方式，也不能替代遗传咨询；数值与判定均须另立来源。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 用比例代替形状 | 「显性就是一半」 | 先看三代形状，比例只在形状确定后才有意义 |
| 把筛查当诊断 | 「筛查阳性，所以是」 | 筛查给风险估计，诊断须另做检测 |
| 把显性读成重病 | 「显性所以更严重」 | 显性只描述表现条件，不描述轻重 |
| 忽略外显率不全 | 「上代没有，所以不是遗传」 | 外显率不全可造成看似跳代 |
| 给生育建议 | 「建议不要生」 | 非指令性：给信息与选项，决定权在家庭 |
| 偷给数值 | 「四分之一概率」 | 改为概率层级表述，或回「本书不给值」 |

## 边界

本模板训练的是「形状 → 变量 → 动作 → 语言」的四步表达，不产生临床判断，也不替代遗传咨询。框架取自《hermes-病理生理学讲义》第 6 章的表述；数值、诊断与生育决策均不在本书范围内，须由具备资质的人员依现行规范作出。
