# Skill：骨骼肌肉功能异常——期、力学环境与三条打断路径

## 何时用

- 一段描述里出现骨折、肿胀、进行性加重的疼痛、窦道排脓或长期卧床，需要先推链再谈原因
- 要判断修复停在哪一期，以及当前的力学环境推出的是一期还是二期愈合
- 要把「养多久」「片子还没长好」这类说法换成可核对的进程判断
- 要在康复宣教里说明为什么固定方式决定活动范围
- 遇到「要不要手术」「要不要用抗菌手段」这类追问，需要一致的拒答与转介口径

## 核心判据（五问）

1. **哪一期？** 炎症与血肿期（清理与招募）、修复期（软骨痂转硬骨痂）、重塑期（编织骨转板层骨）。期定错，后面全错。
2. **哪种力学环境？** 相对稳定允许微动走二期愈合；绝对稳定走一期愈合。微动是双刃剑。
3. **哪一层被打断？** 局部（血供、感染、稳定、缺损、软组织嵌入）还是全身（年龄、营养、吸烟、血糖、药物、消耗）。
4. **有没有环？** 骨筋膜室的压力环、骨转移的肿瘤与骨环、钙与肾的环——环一旦形成，等观察就是等不可逆。
5. **可逆性还剩多少？** 早期可逆、部分可逆、不可逆，逐项标。

## 执行步骤

```text
1. 抄原话，不改写：把要推的那段放在第一行
2. 定受力：五种方式选一类；看软组织损伤与骨折位置是否一致
3. 定分期：血肿、软骨痂、硬骨痂、编织骨，四个标志物定位当前期
4. 定力学：相对稳定还是绝对稳定，推出一期或二期愈合
5. 拆层次：局部与全身两组因素逐条问，只写在不在
6. 查环：压力环、感染侧生物膜与死骨、肿瘤侧双向塑造、钙与肾
7. 标可逆：每项标早期可逆、部分可逆、不可逆
8. 中性改写：删掉判定与时限，保留进程、力学与观察项
9. 报边界：不给值、不给时限、不作预后判断、不写方案
```

## 硬约束

- **不给数值、单位、时长、分级、百分比。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不作诊断，不作正常与异常判定。** 三期、三种愈合不良、三条感染途径都是机制与时间序列的类别。
- **不写术式、药名、剂量与疗程。** 只写机制环节与力学类别。
- **不把「不痛了」当成「可以随意负重」。** 临床愈合同骨性愈合常不同步。
- **不把「还有脉搏」当成安全信号。** 脉搏消失是晚期征象。
- **不把感染当单纯药理问题。** 生物膜与死骨是药物与免疫都到不了的地方。
- **引文逐字。** 标「补充·hermes-病理生理学讲义·第50章·N.M」；核不到就不引。

## 交付物

1. 一段受力与软组织判断（看不见的损伤在哪）
2. 一句分期判断，附标志物依据
3. 一句力学环境判断，推出一期或二期愈合
4. 一张打断清单：局部与全身逐条在或不在
5. 一张可逆性表：早期可逆、部分可逆、不可逆
6. 一处边界：不给值、不给时限、不作预后判断、不写方案

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 用时长代替进程 | 「时间到了就好」 | 按期与力学环境判断 |
| 把固定越牢越好 | 忽略应力遮挡与生物性加固 | 力学环境与固定方式匹配 |
| 等脉搏消失 | 错过可逆窗口 | 早期信号是牵拉痛与感觉异常 |
| 感染只谈药理 | 忽略生物膜与死骨 | 先问两处药物到不了的地方 |
| 忽略废用 | 只治骨折不管制动 | 六类变化逐项过，肌力先于肌量 |
| 顺手给方案 | 越界 | 只写机制环节与力学类别 |

## 边界

本 Skill 只处理「一段描述 → 期 → 力学环境 → 打断层次 → 可逆性」的结构化推演，不涉及诊断、术式与用药决策。机制框架取自本仓库原创讲义第 50 章；任何涉及个体的评估与处置须由具备资质的人员依现行规范与机构制度作出。若出现进行性加重的剧痛、感觉异常、意识改变或开放伤口，请立即就医。
