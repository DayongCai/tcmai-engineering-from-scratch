# Prompt：把「骨折要养多久」改问成「哪一层被打断、力学环境如何」

## 用途

这一章的机制最后都落在三个判断上：修复走到哪一期、断端间的力学环境属于哪一种、打断发生在局部还是全身。这个模板不回答「要养多久」，只把一段骨折、感染或制动的描述推成这三个判断，并指出哪一步应该是可逆的、哪一步已经不可逆。适用于讨论课的机制推演、术后与康复宣教的机制自检，以及接到一份转科记录时先确认它描述的是愈合进程还是并发症。

## 使用前提

- 你面对的是一段**经过描述**（损伤方式、时间、固定方式、局部与全身表现），不是一个待判定的病例。
- 你手边有讲义定位（`补充·hermes-病理生理学讲义·第50章·50.4` 这一级），读过对应小节。
- 你接受三条硬约束：**不产出任何数值**；**不作诊断与判定**；**不写术式、药名与疗程**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是判断要养多久，而是把一段描述推成三个判断：修复期、力学环境、打断的层次；并指出可逆与不可逆的分界在哪。

【输入】
原话：<一段骨折、感染或制动的描述，可以带时间词与判断>
讲义定位：<补充·hermes-病理生理学讲义·第50章·N.M>

【任务，按顺序回答，不跳步】
1. 受力：直接、间接、扭转、牵拉还是重复应力？软组织损伤与骨折位置是否一致（这决定看不见的损伤在哪）。
2. 期：现在停在炎症与血肿期、修复期还是重塑期？依据是血肿、软骨痂、硬骨痂还是编织骨。
3. 力学环境：断端是相对稳定还是绝对稳定？由此推出的是一期愈合还是二期愈合？
4. 分离点：临床愈合同骨性愈合是否同步？若不，写明差在哪一侧。
5. 打断的层：局部（血供、感染、稳定、缺损、软组织嵌入）还是全身（年龄、营养、吸烟、血糖、药物、消耗）？逐条只说在不在。
6. 两个环：有无骨筋膜室压力环的线索（与损伤程度不相称的剧痛、被动牵拉痛、感觉异常）？有无感染侧的生物膜与死骨线索？
7. 废用侧：制动带来的六类变化里，哪几类已经在描述里出现；肌力与肌量哪一侧先变。
8. 可逆性：逐项标出早期可逆、部分可逆、不可逆。
9. 越界清单：原话里哪些成分是判定（愈合好坏、预后、能否负重）？逐条指出并给中性改写。
10. 边界：这段推演不能回答什么。

【硬约束】
- 不给任何数值、单位、时长、分级、百分比。凡需数值才能回答的追问（多久算愈合、多久算延迟），统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作正常与异常判定，不作预后判定，不作疗效断言。
- 不写术式、药名、剂量与疗程；只写机制环节与力学类别。
- 不把「不痛了」当成「可以随意负重」的依据。
- 引讲义原文必须逐字并标「补充·hermes-病理生理学讲义·第50章·N.M」；核不到就不引。

【输出格式】
十个小标题各答一到两句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的推链（节选）

原话：「小腿骨折打了石膏，六周了还肿，这两天越来越痛，脚趾发麻，家里人说再等等看。」讲义定位：补充·hermes-病理生理学讲义·第50章·50.6。

- **受力**：需先问清方式；若为间接暴力，骨折在受力点之外，软组织损伤相对轻——但这条与下面第 6 问冲突。
- **期**：处于炎症与血肿期向修复期过渡，软骨痂尚未形成；肿胀未退是这一期的正常方向，但与剧痛同时出现就改变性质。
- **力学环境**：石膏属相对稳定，走二期愈合方向，中间应有软骨痂。
- **分离点**：此时谈不上临床愈合，两者都未到；关键在于进程是否在推进。
- **打断的层**：外周环境改变（石膏）加上肿胀，属局部一侧；全身因素未给。
- **两个环**：越来越痛、被动牵拉痛、感觉异常三条同时出现，符合压力环的早期方向；这一项优先级最高，不是等待观察的信号。
- **废用侧**：制动已使肌肉蛋白合成下降，肌力先于肌量下降。
- **可逆性**：神经与肌肉的缺血改变在早期可逆，一旦进入坏死与纤维替代即不可逆。
- **越界清单**：「再等等看」是处置判断，改为「按流程复评神经血管状态并即时上报」。
- **边界**：不能判断任何人的具体病情与走向，也不给时限。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 用时间代替进程 | 「六周了该好了」 | 按期与力学环境判断，不看日历 |
| 只盯影像 | 「片子还没长好」 | 分清临床愈合同骨性愈合 |
| 等脉搏消失 | 「还有脉搏，先观察」 | 早期是牵拉痛与感觉异常 |
| 把感染当药理问题 | 「用足疗程就好」 | 先问生物膜与死骨在不在 |
| 忽略废用 | 只谈骨折不谈制动 | 六类变化逐项过，肌力先于肌量 |
| 顺手给方案 | 术式、药名、疗程 | 只写机制环节与力学类别 |

## 边界

本模板训练的是「一段描述 → 期 → 力学环境 → 打断层次 → 可逆性」的结构化推演，不产生临床判断。机制框架取自本仓库原创讲义第 50 章；数值、时限、分级与用药不在本书范围内，任何涉及个体的评估与处置须由具备资质的人员依现行规范作出。若出现进行性加重的剧痛、感觉异常或意识改变，应立即就医。
