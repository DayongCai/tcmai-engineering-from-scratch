# Skill：皮肤系统异常——五件组件的屏障与四条后果

## 何时用

- 一段描述里出现红斑、水疱、鳞屑或溃疡，需要先定层次再谈原因
- 要解释同是水疱，为什么有的一按就破、有的按不破
- 要把「保湿」与「抗炎」为什么必须同时做讲清，而不是当成两条并列医嘱
- 面对反复发作的湿疹，需要指出这是哪个闭环在自我维持
- 遇到「多久能好」「抹哪一种」这类追问，需要一致的拒答口径

## 核心判据（五问）

1. **破到哪一层？** 表皮（鳞屑、色素改变）、真皮（水疱、硬化、瘢痕）、皮下与更深（缓冲与保温丧失）。
2. **上皮储备还在不在？** 毛囊与汗腺在真皮内深埋；浅层部分真皮损伤靠它上皮化，全层损伤失去它。
3. **哪几维屏障同时失效？** 物理、化学、微生物、免疫——四维各有一组典型表现，缺几维写几维。
4. **四条后果走到哪一步？** 感染易感、经皮失水与体液丢失、免疫激活与炎症、体温调节与代谢。
5. **闭环的入口在哪？** 屏障差、抗原进入、炎症、屏障更差；炎症本身抑制脂质合成，这是入口。

## 执行步骤

```text
1. 抄原话，不改写：把要推的那段放在第一行
2. 定层次：表皮 / 真皮 / 皮下，只选一层作起点
3. 判储备：附属器在不在，能不能自行上皮化
4. 查四维：物理、化学、微生物、免疫各写一句依据
5. 推后果：四条各判「已出现 / 在路上 / 暂未见」
6. 找入口：写出闭环，并指出可切断的那一处
7. 中性改写：删掉判定成分，保留部位、分布与形态线索
8. 报边界：不给值、不作诊断、不写具体药物与浓度
```

## 硬约束

- **不给数值、单位、正常值、参考区间、百分比、浓度。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不作诊断，不作正常与异常判定。** 层次判断是机制定位；尼氏征、皮节分布、环形边缘只作线索类别。
- **不写具体药物与浓度。** 讲义明说本讲义不涉及具体药物与浓度；本 Skill 只写原则类别。
- **不写分级与分期界限。** 压疮分期、烧伤深度分度、肿瘤分期只在后续章节以层次与类别出现。
- **引文逐字。** 标`补充·hermes-病理生理学讲义·第52章·N.M`；核不到就不引。讲义是本仓库原创正文，不写成任何外文教材的译本。

## 交付物

1. 一句层次判断与一句储备判断
2. 一张四维屏障的失效清单（缺几维写几维）
3. 四条后果的状态（已出现 / 在路上 / 暂未见）
4. 一条闭环与环上的入口
5. 两到三处可切断的环节（只写类别）
6. 一张越界清单：判定成分的中性改写
7. 一处边界：不给值、不作诊断、不写药物与浓度

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 屏障当挡板 | 只说破了，漏掉四维 | 四维逐条判 |
| 病名代替层次 | 背得出病名却答不出机制 | 先答破到哪一层 |
| 单点干预 | 停药即复发 | 找闭环，两端同时处理 |
| 把保湿当越多越好 | 过度水合破坏屏障 | 恢复脂质比例与适度含水量 |
| 只看皮损 | 漏掉体温与失水 | 四条后果都要判 |
| 越过药物 | 直接给制剂与浓度 | 只写原则类别 |

## 与相邻章节的接缝

- 烧伤一章：本章的屏障四维与经皮失水是那一章四条全身反应的机制前提；「附属器是上皮储备」这条伏笔在那一章的深度类别里兑现。
- 炎症与免疫相关章节：本章的闭环是那一批章节在皮肤上的具体用例，同形反应是它在形态上的留痕。
- 骨骼肌肉功能异常：两章共用「层次决定表现」这条方法；一章看滑膜与软骨，一章看表皮与真皮。
- 护理实践：保湿、清洁、剪甲、防晒与随访可直接落到流程；诊断、处方与浓度属资质与规范一侧。

## 边界

本 Skill 只处理「层次 → 屏障 → 四路后果」的结构化推演，不涉及数值、判定与具体药物。层次与屏障类别取自本仓库原创讲义第 52 章；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
