# Prompt：把一处皮肤破损读成四路后果

## 用途

皮肤这一章的组织轴不是病名，而是结构层次与屏障功能的对应关系。这个模板不让你背皮损图谱，只让你对一段皮肤描述做三件事：先定损伤落在哪一层，再判哪几维屏障同时失守，最后把四条后果（感染、失水、炎症、体温）分别推下去。适用于换药前的机制自查、宣教材料写作前的自检，以及把「为什么保湿和抗炎要一起做」讲清。

## 使用前提

- 你面对的是一段**皮损描述**（部位与分布、形态与排列、边界、有无水疱、有无渗出），不是一份诊断。
- 你手边有讲义定位（`补充·hermes-病理生理学讲义·第52章·52.4` 这一级），读过对应小节。
- 你接受三条硬约束：**不产出任何数值**；**不作诊断与判定**；**不写具体药物与浓度**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是给结论，而是把一处皮肤破损读成层次、屏障与四条后果，并说明这段推演回答不了什么。

【输入】
原话：<一段皮损描述，可以带病名、可以带判断>
讲义定位：<补充·hermes-病理生理学讲义·第N章·N.M>

【任务，按顺序回答，不跳步】
1. 层次：损伤落在表皮、真皮、皮下，还是更深？只选一层作起点。
2. 储备：这一层还有没有上皮储备（毛囊与汗腺）？据此判断能不能自行上皮化。
3. 屏障：四维里哪几维同时失效——物理、化学、微生物、免疫？逐维写一句依据。
4. 后果：四条后果（感染易感、经皮失水、免疫激活、体温调节）哪些已经出现、哪些还在路上？只写类别。
5. 环路：若已进入炎症，指出这是哪个闭环（屏障—抗原—炎症—屏障），并写出环上的入口。
6. 可切断处：这条环路上哪两三处可被干预？只写环节类别，不写产品与浓度。
7. 越界清单：把原话里的判定成分逐条指出，给出中性改写。
8. 边界：这段推演不能回答什么。

【硬约束】
- 不给任何数值、单位、正常值、参考区间、百分比、浓度。凡需数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作正常与异常判定，不作疗效断言。
- 不写具体药物、浓度与制剂选择；只写屏障修复、感染监测、瘙痒与搔抓干预、防晒与随访这些原则类别。
- 引讲义原文必须逐字并标「补充·hermes-病理生理学讲义·第52章·N.M」；核不到就不引。

【输出格式】
八个小标题各答一到两句；第 1 问只许写一层；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的推演（节选）

原话：「两侧小腿前面一片红斑，边界清楚，上面有银白色皮屑，抓破的地方又长出新的一片。」讲义定位：补充·hermes-病理生理学讲义·第52章·52.10。

- **层次**：表皮为主（角化过度伴角化不全的层次），真皮乳头血管扩张参与。
- **储备**：表皮损伤，储备完好，可自行上皮化。
- **屏障**：化学维与免疫维同时失效；物理维尚可。
- **后果**：免疫激活已在环上；感染与失水暂未见，但要监测。
- **环路**：屏障差 → 抗原进入 → 炎症 → 屏障更差；入口是炎症对脂质合成的抑制。
- **可切断处**：屏障修复与炎症控制两处，另加打断搔抓；只写类别。
- **越界清单**：「就是癣」是判定，改为「分布与边界提示角质层内的浅表过程」。
- **边界**：不能判断任何人的状态，也不预测会不会泛发。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 病名先行 | 一开口就是某个病名 | 先答第 1 问的层次 |
| 只抗炎不修屏障 | 停药即复发 | 回到闭环：炎症抑制脂质合成 |
| 只保湿不控炎 | 越涂越痒 | 闭环两端都要处理 |
| 屏障当挡板 | 只说「破了」 | 按四维逐条判，缺哪维写哪维 |
| 越湿越好 | 长时间封闭浸渍 | 过度水合同样破坏屏障 |
| 越过药物 | 直接给制剂与浓度 | 只写原则类别，方案不在此侧 |

## 边界

本模板训练的是「层次 → 屏障 → 四路后果」的推演，不产生临床判断。层次与屏障类别取自本仓库原创讲义第 52 章（52.1–52.14）；数值、判定与具体药物均不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
