# Skill：肾脏功能——四环节定位与三组功能

## 何时用

- 有人用「肾功能不好」「肾衰」把一段状态糊过去了，需要落到具体环节
- 要解释同样一句「肾功能下降」为什么可以指四件不同的事（滤过、转运、浓缩、排出）
- 要判断某个药物效应落在哪一段：入球端、出球端、升支粗段，还是远端与集合管
- 要解释「肌酐正常但尿量、夜尿已经变了」这类看似矛盾的情形
- 遇到「属于第几期」「滤过率多少才算低」这类追问，需要一套一致的拒答口径

## 核心判据（五问）

1. **落在哪一环？** 滤过、重吸收与分泌、浓缩稀释、排出。四环的判据不同：滤过看四类因素，转运看两条途径与一个极限，浓缩看梯度与激素，排出看阻力位置。
2. **落在哪一组功能？** 排泄、内环境调节、内分泌。三组的后果分别是毒素蓄积、水电解质酸碱紊乱、贫血与骨病，不能用一个词打包。
3. **滤过这一环，落在四类因素的哪一类？** 膜的通透性与面积、净滤过压、肾血浆流量、膜两侧胶体渗透压差。说不出来就是没定位。
4. **浓缩这一环，是梯度还是激素？** 梯度问题在髓袢与直小血管；激素问题在集合管对激素的反应。两者方向不同。
5. **三个维度各是什么方向？** 尿量、尿成分、尿渗透压。量对应总账，成分对应选择性，渗透压对应浓缩能力。

## 执行步骤

```text
1. 抄原话，不改写：把结论句原样放在第一行
2. 去结论：只留可核对的观察项（尿量、夜尿、水肿、尿蛋白、比重方向、乏力、血压）
3. 落环节：四环选一环，说明为什么不是相邻那一环
4. 落功能组：排泄 / 调节 / 内分泌，缺线索写缺
5. 细分：滤过看四类因素；浓缩分梯度与激素；内分泌分四个产物
6. 问急慢：几小时还是数年，没给就写「无法判断急慢」
7. 查陷阱：血肌酐是否被肌肉量掩盖，是否在容量不足时用了影响滤过压的药物
8. 中性改写：删掉诊断、分期与处置成分
9. 报边界：不给值、不给分期、不作诊断
```

## 硬约束

- **不给数值、单位、正常值、参考区间、百分比、分期。** 统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不作诊断，不作正常与异常判定。** 「肾功能不好」在本 Skill 里只作待拆的结论，不用于给个体定性。
- **环节必答。** 说不清就写说不清，不许用「整体功能下降」把环节糊过去。
- **三组功能不许合并。** 贫血属内分泌组，水肿多属调节组，两者不能写成同一件事。
- **转运极限只讲有无饱和点。** 不给任何具体数值，讲义本身就明确不要求记数值。
- **引文逐字。** 标「补充·hermes-病理生理学讲义·第N章·N.M」；核不到就不引。

## 交付物

1. 一张观察项清单：去掉结论词之后剩下的可核对项
2. 一个环节落点：四环之一，附「为什么不是相邻环」
3. 一个功能组落点：排泄 / 调节 / 内分泌
4. 一条细分判断：滤过的四类因素、浓缩的梯度与激素、内分泌的四个产物
5. 一条急慢说明与一条陷阱提示（肌酐被掩盖、药物撤掉缓冲）
6. 一段中性改写：删掉诊断、分期与处置
7. 一处边界：本书不给值、不分期、不作诊断

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 用结论替代观察 | 「肾功能不好」 | 先列可核对的观察项 |
| 环节糊过去 | 「肾整体下降」 | 四环选一环并说明理由 |
| 用肌酐当滤过证据 | 老年人滤过下降被漏掉 | 补肌肉量与年龄，改用方向判断 |
| 梯度与激素不分 | 浓缩障碍被笼统处理 | 分梯度问题与激素反应问题 |
| 三组功能混写 | 贫血与水肿混为一谈 | 分组落位，缺线索写缺 |
| 忽略药物位置 | 「用药后变差，说不清」 | 问作用在入球端、出球端还是升支粗段 |
| 被追问就给分期 | 越出本书口径 | 统一回「本书不给值」 |

## 边界

本 Skill 只处理「一句结论 → 四环节 → 三组功能 → 三维度」的定位，不涉及数值、分期、判定与临床处置。框架取自本仓库原创《hermes-病理生理学讲义》第 26 章；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
