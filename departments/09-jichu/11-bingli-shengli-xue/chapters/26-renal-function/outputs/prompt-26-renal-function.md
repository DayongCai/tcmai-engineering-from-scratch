# Prompt：把一句「肾功能不好」拆到四环节与三组功能上

## 用途

「肾功能不好」是这门课里最省事、也最没用的一句话。它至少可以指四件不同的事：滤过不够、重吸收或分泌出错、浓缩稀释失灵、排出受阻；又可以落在三组不同的功能上：排泄、内环境调节、内分泌。本模板不让你换一个更准确的病名，而是把这句话逼到链上的某一环与某一组上。适用于讨论课、交班记录的自检，以及读第 28、29 章（肾功能不全、排尿功能）之前的定位练习。

## 使用前提

- 你面对的是一段**状态描述**（尿量、尿成分、水肿、乏力、化验方向），不是一个待确诊的病例。
- 你手边有讲义定位（`补充·hermes-病理生理学讲义·第26章·26.10` 这一级），读过对应小节。
- 你接受两条硬约束：**不产出任何数值、参考范围与分期**；**不作诊断、不作正常与异常的判定**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是判断肾好不好，而是把一句「肾功能不好」拆到四环节与三组功能上，并指出哪一步越界。

【输入】
原话：<一段描述，可以带结论，可以带化验方向>
讲义定位：<补充·hermes-病理生理学讲义·第N章·N.M>

【任务，按顺序回答，不跳步】
1. 去结论：把原话里的「肾功能不好」「肾衰」等结论词拿掉，只留可核对的观察项（尿量、夜尿、水肿、尿蛋白、尿比重方向、乏力、血压）。
2. 落环节：在滤过、重吸收与分泌、浓缩稀释、排出四个环节里选一环，并说明为什么不是相邻那一环。四环各有各的判据。
3. 落功能组：这句话落在排泄、内环境调节，还是内分泌？三组的后果不同，不许用一个词打包。
4. 若落在滤过：说出它落在决定滤过率的四类因素（膜的通透性与面积、净滤过压、肾血浆流量、膜两侧胶体渗透压差）中的哪一类。
5. 若落在浓缩：区分梯度问题（髓袢与直小血管）与激素问题（集合管对激素的反应），两者方向不同。
6. 若落在内分泌：分别问肾素、促红细胞生成素、活性维生素 D、前列腺素各有没有线索；缺的写缺。
7. 急性还是慢性：这一段给的是几小时的变化还是数年的变化？没给就写「无法判断急慢」。
8. 越界清单：指出原话里属于个体判定（诊断、分期、严重程度、处置）的成分，逐条给出中性改写。
9. 边界：这段拆解不能回答什么。

【硬约束】
- 不给任何数值、单位、正常值、参考区间、百分比、分期。凡需数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作正常与异常判定；不写药物、剂量与替代方案。
- 引讲义原文必须逐字，并标「补充·hermes-病理生理学讲义·第N章·N.M」；核不到就不引。
- 环节说不清就写说不清，不许用「肾整体功能下降」把环节糊过去。

【输出格式】
九个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的拆解（节选）

原话：「老人肾功能不好，肌酐还行，最近夜尿多、有点肿。」讲义定位：补充·hermes-病理生理学讲义·第26章·26.10。

- **去结论**：观察项是夜尿多、水肿、肌酐方向「还行」；结论词是「肾功能不好」，先摘掉。
- **落环节**：夜尿多指向浓缩稀释这一环，而不是滤过这一环——滤过下降通常先表现为滤过量减少，浓缩能力下降才表现为夜尿与多尿。
- **落功能组**：落在内环境调节（水与渗透压）这一组；排泄组没有给出线索。
- **滤过这一支**：肌酐「还行」不能作为滤过正常的证据。老年、消瘦、肌肉量少者肌酐生成少，滤过已明显下降而读数仍在参考范围内——这是讲义点名的陷阱。
- **浓缩这一支**：先分梯度与激素：髓袢与直小血管造成的梯度被稀释，与集合管对激素反应不足，两者方向不同；这一段没有给区分线索，写「待定」。
- **内分泌**：四项都没提到。乏力和水肿要与贫血、钠水潴留分开看，缺线索就写缺。
- **急慢**：只给了「最近」，无法判断是数日还是数年，写「无法判断急慢」。
- **越界清单**：「肾功能不好」是判定，改为「浓缩能力方向下降的线索存在，滤过能力尚无可靠线索」。
- **边界**：不能由此判断任何人的状态；数值与分期一律不给。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 用结论替代观察 | 「肾功能不好」 | 先列可核对的观察项 |
| 环节糊过去 | 「肾整体下降」 | 四环节选一环，说明为什么不是相邻环 |
| 用肌酐当滤过证据 | 「肌酐正常，滤过没问题」 | 补肌肉量与年龄，改用方向判断 |
| 梯度与激素不分 | 「浓缩不好」 | 分梯度问题与激素反应问题 |
| 三组功能混写 | 把贫血与水肿写成同一件事 | 排泄 / 调节 / 内分泌分组落位 |
| 忽略急慢 | 慢性表现按急性解释 | 先问时间尺度 |
| 偷给分期 | 「属于第几期」 | 触发硬约束，改为「本书不给值」 |

## 边界

本模板训练的是「一句结论 → 四环节 → 三组功能 → 越界改写」的拆解能力，不产生临床判断。框架取自本仓库原创《hermes-病理生理学讲义》第 26 章；数值、分期与判定不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
