# Skill：基因组结构、调控与组织分化——四层定位与一句结论

## 何时用

- 有人用「基因决定」「遗传的」这类话把讨论封住
- 检测未见致病变异，但表型与家族聚集解释不通，需要换一层问法
- 要说明为什么同一份基因组在不同细胞里读出不同结果
- 要判断一处组织损伤后会再生还是留瘢痕
- 遇到「这是不是遗传病」「基因查了没事是不是就没事」这类追问，需要一致的拒答口径

## 核心判据（四问）

1. **哪一层？** 序列层（变异、缺失、扩增）／读法层（转录效率、剪接方式、稳定性）／批注层（甲基化、组蛋白修饰、染色质重塑、非编码 RNA）／身份层（主控因子、表观锁定、微环境）。四层证据形态不同，不可互替。
2. **表观遗传的三个限定齐吗？** 不改序列、可稳定遗传、是表达状态改变。缺一条就不是表观遗传，而是突变或一时波动。
3. **读法怎么变？** 转录层看转录因子组合与增强子接触；转录后层看剪接、加帽加尾、稳定性、微小 RNA；两者不可合并成「表达异常」。
4. **更新类型是什么？** 持续分裂型（终生更新）／稳定型（损伤时被激活）／永久型（基本不再分裂）。这条决定修复结局是再生还是瘢痕。

## 执行步骤

```text
1. 抄原话，不改写：把要定位的那句话原样放在第一行
2. 定层：序列 / 读法 / 批注 / 身份，只选一层并说明理由
3. 核序列：有没有变异、缺失、扩增的证据？阴性也只算这一层的阴性
4. 核读法：转录效率、剪接方式、稳定性三者分开写
5. 核批注：四类机制逐条对，能对上几条写几条，缺的标缺
6. 核身份：主控因子 / 表观锁定 / 微环境；附更新类型
7. 报边界：不写数值，不作诊断，检出意义未明不作诊断依据
```

## 硬约束

- **不给数值、单位、频率、参考区间、百分比。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不作诊断，不作正常与异常判定。** 检出不等于解释：同一个变异在不同个体可有不同表现（外显率与表现度差异），意义未明的变异不得直接当作诊断依据。
- **引文逐字。** 标「补充·hermes-病理生理学讲义·第5章·5.M」；核不到就不引。讲义是本仓库原创教学正文，不许写成任何外文教材的译本。
- **层次必标。** 一句话里不许同时装序列与表达两层的内容；要对照两层时，先写清轴。
- **可纠正性只说层级。** 批注层理论上比序列层更易逆转，这是可能性判断，不是方案。

## 交付物

1. 一段四层定位（序列 / 读法 / 批注 / 身份），只落一层
2. 一张证据表：每层写「有证据」「阴性」「未给」三态之一
3. 一句更新类型判断：持续分裂 / 稳定 / 永久，并说明修复结局
4. 一处边界：本书不给值、不作诊断，数值须另立数据层

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 把阴性当排除 | 「没查到致病变异，所以不是遗传」 | 阴性只是序列层的结果 |
| 四层混写 | 「基因表达异常」一句到底 | 分四层，先定层再谈证据 |
| 把表观遗传当修饰清单 | 只会背甲基化与乙酰化 | 回到三限定：不改序列、可遗传、表达状态改变 |
| 把剪接当序列改变 | 「剪接突变所以序列变了」 | 剪接改的是产物，不是序列 |
| 检出即诊断 | 「检出变异就是这病」 | 意义未明的变异不作诊断依据 |
| 忽略更新类型 | 「会长回来的」 | 按三类更新策略判再生能力 |

## 边界

本 Skill 只处理「一句表述 → 四层定位 → 证据表」的结构化拆解，不涉及数值、判定与临床决策。层次划分取自《hermes-病理生理学讲义》第 5 章的表述；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
