# Prompt：把「这个基因有问题」拆成序列、读法、批注、身份四层

## 用途

「基因有问题」这句话可以指四件完全不同的事：序列变了、读法变了（转录与剪接）、批注变了（甲基化与组蛋白修饰）、身份变了（谱系与分化程序）。四层的证据形态不同，能被纠正的程度也不同。这个模板不让你找病因，而是把一句笼统的表述按四层定位，并说明证据停在哪一层。

适用于读基因检测结论、写机制说明、讨论「查不出变异但有家族聚集」这类情形，也适用于后面各章（肿瘤、遗传病、发育异常）的复盘。

## 使用前提

- 你手上是一句**关于基因或遗传的表述**，不是一个待确诊的病例。
- 你读过讲义本章对应小节（`补充·hermes-病理生理学讲义·第5章·5.5` 这一级）。
- 你接受两条硬约束：**不产出任何数值**；**不作诊断、不作正常与异常的判定**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是找病因，而是把一句笼统的表述按四个层次定位，并说明证据够不够。

【输入】
原话：<一句关于基因、遗传或表达的表述>
讲义定位：<补充·hermes-病理生理学讲义·第5章·5.M>

【任务，按顺序回答，不跳步】
1. 层次定位：这句话说的是序列层、读法层（转录 / 剪接 / 稳定性）、批注层（甲基化 / 组蛋白 / 重塑 / 非编码 RNA），还是身份层（谱系与分化程序）？只选一层，说明为什么不是另外三层。
2. 序列层核验：原话有没有给出序列层面的证据（变异、缺失、扩增）？没有就写「未给」。
3. 读法层核验：若涉及表达量或蛋白异构体，写出是转录效率、剪接方式、还是稳定性造成的；三者可区分，不要合并。
4. 批注层核验：若涉及「不改变序列的表达异常」，逐条对四类机制：甲基化、组蛋白修饰、染色质重塑、非编码 RNA。能对上几条写几条。
5. 身份层核验：若涉及分化或组织特性，说明是主控转录因子、表观锁定、还是微环境造成的；组织更新类型（持续分裂 / 稳定 / 永久）一并写出。
6. 可纠正性：按层次说明这类异常理论上能否被逆转（批注可改、序列难改），只说可能性层级，不给方案。
7. 边界：这段拆解不能回答什么。

【硬约束】
- 不给任何数值、单位、频率、参考区间、百分比。需要数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作正常与异常判定，不作预后判定；检出意义未明的变异不得直接当作诊断依据。
- 引讲义原文必须逐字，并标「补充·hermes-病理生理学讲义·第5章·5.M」；核不到就不引。
- 层次不明就写「层次未定」，不要用推测补齐。

【输出格式】
七个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的拆解（节选）

原话：「检测说没查到致病变异，但这个家里好几个人都有类似表现，所以可能是遗传的。」讲义定位：补充·hermes-病理生理学讲义·第5章·5.9。

- **层次定位**：这句话在序列层与批注层之间摇摆。「没查到致病变异」是序列层的阴性结果；「家里好几个人都有」是分布观察，不指层次。
- **序列层核验**：给了阴性结果，未给阳性证据；写「序列层证据为阴性，不等于排除」。
- **读法层核验**：未涉及表达量或异构体，写「未给」。
- **批注层核验**：若表型与表达异常相符，应逐条对甲基化、组蛋白修饰、染色质重塑、非编码 RNA；原话未给任何一条，写「未给」。
- **身份层核验**：未涉及分化或组织特性，写「未涉及」。
- **可纠正性**：批注层异常理论上比序列缺陷更易被逆转，但这只是可能性层级，不构成任何方案。
- **边界**：不能由此判断该家系属于哪一类遗传方式，也不能判断任何个体的状态。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 把阴性当排除 | 「没查到，所以不是遗传」 | 序列层阴性只说明这一层没证据 |
| 四层混成一层 | 「基因表达异常」一句到底 | 分序列、读法、批注、身份四层写 |
| 把剪接当序列 | 「剪接突变所以序列变了」 | 剪接改变产物，不改序列本身 |
| 把检出当诊断 | 「检出变异，所以是这个病」 | 意义未明的变异不作诊断依据 |
| 忽略细胞类型 | 「可再生」 | 按持续分裂 / 稳定 / 永久三类判断 |
| 偷给数值 | 「表达高了十倍」 | 改为方向性表述或回「本书不给值」 |

## 边界

本模板训练的是「一句话 → 四层 → 证据够不够」的定位能力，不产生临床判断。层次划分取自《hermes-病理生理学讲义》第 5 章的表述；数值与判定不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
