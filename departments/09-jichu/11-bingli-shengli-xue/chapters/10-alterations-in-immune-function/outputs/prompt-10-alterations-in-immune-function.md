# Prompt：把「免疫力太强／太弱」换成三条约束，再问「谁在识别、谁在执行」

## 用途

免疫这一块的糊法只有一个句式：「他免疫力太强／太弱」。这个模板不接受这个句式，而是把一句话逼成五步：**约束（三条里断哪一条）、配对（谁识别、谁执行）、时相（致敏、激发、速发、迟发）、耐受（中枢还是外周）、判定（哪些成分越界）**。适用于读免疫学报告时的分层、解释「为什么治疗是调节而不是增强」，以及判断一段叙述有没有把应答当成病。

## 使用前提

- 你面对的是一段**描述或一段讨论发言**，不是一个待处置的病例。
- 你手边有讲义定位（`补充·hermes-病理生理学讲义·第10章·10.M` 这一级），读过对应小节。
- 你接受两条硬约束：**不产出任何数值**；**不作诊断、不作分型判定、不作疗效判断**。

## Prompt 正文（复制即用）

```text
你是病理生理学的概念助教。任务不是判断病情，而是把一段关于「免疫力」的表述换成三条约束，并指出哪一层越界。

【输入】
原话：<一段描述或讨论发言，可以带抗体结果，可以带判断>
讲义定位：<补充·hermes-病理生理学讲义·第10章·N.M>

【任务，按顺序回答，不跳步】
1. 约束层：这句话说的是哪一条约束失效？
   识别正确（打错靶或用了不适当的效应机制）／强度适度（不足或过度）／及时关闭（抗原清除后没退出）。
   三条各写一句「失效 / 未提 / 不足以判断」，不补猜。
2. 配对层：若要追到机制，落在哪一对「识别者—执行者」上？
   IgE-肥大细胞／抗体-补体或吞噬（含受体刺激与阻断）／复合物-中性粒细胞／T 细胞-巨噬细胞或 CTL。
3. 时相层：这句话讲的是致敏还是激发？是速发相还是迟发相？
   迟发相与慢性化的关系（慢性过敏性炎症与气道高反应性）写在这一层。
4. 耐受层（若涉及自身免疫）：断的是中枢耐受还是外周耐受？
   并列可能的六条机制中与这句话相关的那一条（遗传易感、分子模拟、表位扩展、隐蔽抗原、旁路活化、Treg 不足）。
5. 判定层：这句话里哪些成分是对个体的判定（诊断、分型、严重度、疗效、处置建议）？逐条指出。
6. 越界清单：把第 5 层的成分列成清单，给出中性改写——只保留约束、配对与时相的表述。
7. 边界：这段拆解不能回答什么。

【硬约束】
- 不给任何数值、单位、正常值、参考区间、百分比、抗体滴度、补体水平、细胞计数。
  凡需要数值才能回答的追问，统一回答：本书不给值，需另立数据层（另立来源与校验）。
- 不作诊断，不作分型与严重度判定，不作疗效断言，不给处置建议。
- 引讲义原文必须逐字，并标「补充·hermes-病理生理学讲义·第10章·N.M」；核不到就不引。
- 不许写成「免疫力强／弱」；只写「哪条约束失效」。
- 不许把「抗体阳性」写成患病；应答与病之间隔着「造成组织损伤并出现临床表现」。
- 急症内容（如全身性过敏反应）只作类别提示，处置与流程由规范决定，不展开参数。
- 若原话不足以定位到某一层，直接说缺哪一层，不要用推测填满。

【输出格式】
七个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的拆解（节选）

原话：「他一吃虾就起风团，几分钟就起来了，是免疫力太强吧？」讲义定位：补充·hermes-病理生理学讲义·第10章·10.2。

- **约束层**：识别正确这一条失效（应答指向了无害的蛋白），强度与关闭两条未提。
- **配对层**：IgE 识别、肥大细胞执行——属四型里的第一对；「几分钟」这一描述与预存介质释放相符。
- **时相层**：原话讲的是激发阶段的速发相；迟发相未提，而它才是慢性过敏性炎症与气道高反应性的基础。
- **耐受层**：不涉及；本例不是对自身抗原的应答。
- **判定层**：「免疫力太强」是对个体状态的判定，「几分钟就起来」被当作强度证据属推断，「是……吧」把推断说成了结论。
- **中性改写**：改成「进食虾类后短时间内出现风团，已按机构流程评估与处理」——只留诱因、时相与流程位置。
- **边界**：不能判断严重度，不能预测下一次反应，不给任何界值。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 强／弱二分 | 「免疫力太强所以过敏」 | 换成三条约束：识别、强度、关闭 |
| 致敏当激发 | 「第一次吃就过敏」 | 致敏无症状，症状出现在再次接触 |
| 速发当全部 | 「过敏一会儿就好」 | 迟发相是慢性化的入口 |
| 抗体阳性即患病 | 「查到抗体就是自身免疫病」 | 应答与病之间隔着损伤与表现 |
| 调节当增强 | 「免疫调节就是补」 | 治疗是调节强度与方向，不是加量 |
| 偷给滴度 | 「这个滴度以上才算阳性」 | 触发硬约束，改为「本书不给值」 |

## 边界

本模板训练的是「一句话 → 三条约束 → 中性表述」的结构化拆解，不产生临床判断。分类框架取自 `standards/binglishengli/supplements/jiangyi.json` 第 10 章的类别与环节；数值、分型判定与个体判断均不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
