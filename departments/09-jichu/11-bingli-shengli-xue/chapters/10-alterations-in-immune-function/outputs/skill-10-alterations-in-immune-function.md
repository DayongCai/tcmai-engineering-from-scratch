# Skill：免疫功能异常——三条约束、四对判据与一个「谁在执行」

## 何时用

- 有人（包括你自己）用「免疫力太强」「抵抗力差」「补一补」把一段状态糊过去了，需要换成可检验的表述
- 手上有一份自身抗体或过敏原检测结果，要先分清它答的是「有应答」还是「有病」
- 要判断一段叙述有没有把四型混成一型、把迟发相当成速发相、把免疫抑制当成单向的好处
- 遇到「要不要增强免疫」「是不是过敏」这类追问，需要一套一致的拒答口径

## 核心判据（四问）

1. **哪条约束断了？** 识别正确（打错靶或用错效应机制）／强度适度（不足或过度）／及时关闭（抗原清除后没退出）。三条各写「失效 / 未提 / 不足以判断」。
2. **谁在识别、谁在执行？** IgE-肥大细胞／抗体-补体或吞噬（含受体刺激与阻断）／复合物-中性粒细胞／T 细胞-巨噬细胞或 CTL。这一问同时定速度、部位与检测结果。
3. **先说致敏还是激发？速发还是迟发？** 致敏无症状；迟发相（单核细胞浸润、肉芽肿）与慢性化相关。
4. **耐受断在哪一层？** 中枢（克隆删除不完整）／外周（无能、Treg、豁免部位、凋亡诱导）。六条机制里挑相关的一条，不铺开。

## 执行步骤

```text
1. 抄原话，不改写：把要拆的那句话原样放在第一行
2. 定约束：三条各写一句，缺的写「未提」
3. 配对：落到四对「识别—执行」中的一对
4. 定时相：致敏 / 激发；速发 / 迟发
5. 判耐受：涉及自身免疫时，指中枢或外周，再指一条机制
6. 查越界：诊断、分型、严重度、疗效、处置建议——逐条标出
7. 中性改写：删掉判定成分，只留约束与时相，保留观察时点
8. 报边界：不写数值，不作诊断，不给建议
```

## 硬约束

- **不给数值、单位、正常值、参考区间、百分比、抗体滴度、补体水平、细胞计数。** 需要数值才能回答的追问，统一回：本书不给值，需另立数据层（另立来源与校验）。
- **不许用「强／弱」。** 换成「哪条约束失效」；「调节」不等于「增强」。
- **抗体阳性不等于患病。** 应答与病之间隔着「造成组织损伤并出现临床表现」。
- **急症只作类别提示。** 全身性过敏反应的处置与流程由规范决定，本 Skill 不展开参数，也不给操作步骤。
- **免疫抑制是双刃剑。** 降低排斥的同时削弱抗感染与免疫监视，监测须同时覆盖排斥与感染两侧。
- **引文逐字。** 标「补充·hermes-病理生理学讲义·第10章·N.M」；核不到就不引。讲义是本仓库原创正文，不写成「教材」。

## 交付物

1. 一段四问拆解（约束 → 配对 → 时相 → 耐受），缺层如实标缺
2. 一句约束结论：三条里哪一条失效，另两条的状态
3. 一对配对判断：谁识别、谁执行
4. 一段中性改写：删掉判定成分后的版本，保留观察时点
5. 一处边界：本章不给值、不作诊断，数值须另立数据层

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 强／弱二分 | 把方向错误读成强度问题 | 三条约束逐条对，先判方向 |
| 致敏当激发 | 误以为首次接触就发病 | 致敏无症状，症状在再次接触 |
| 速发当全部 | 忽略慢性化入口 | 迟发相＝慢性过敏性炎症的基础 |
| 抗体即患病 | 把标志当诊断 | 应答与病之间隔着损伤与表现 |
| 四型当四病 | 背成四张互不相关的表 | 一句判据：谁识别、谁执行 |
| 抑制即获益 | 忽略感染与肿瘤风险 | 双刃剑：两侧同时监测 |
| 被追问就报滴度 | 越出本书口径，且数值无来源 | 统一回：本书不给值，另立数据层 |
