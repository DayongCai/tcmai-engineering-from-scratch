# Prompt：把一个「压力大」的叙述拆成一台回路

## 用途

病理生理学最容易被糊过去的一句话是「最近压力大，所以血压高、睡不好、老感冒」。这句话把三件事压成了一件：一个人处在什么应激时序上、回路哪一环出了问题、以及这套说法能证到哪一步。这个模板不让你补病名，而是把一段叙述按回路拆开，判断它属于三种失败方式里的哪一种，最后把表述收回到证据允许的范围内。

适用于读病史摘要、写机制说明、做课前讨论，也适用于后面各章的复盘：从第 20 章的休克到第 25 章的酸碱失衡，凡涉及「调节」的章节，都可以先用这台回路过一遍。

## 使用前提

- 你手上是一段**描述**——一段自述、一组体征或一段病程记录，不是一个待确诊的病例。
- 你读过讲义本章对应小节（`补充·hermes-病理生理学讲义·第2章·2.11` 这一级），能指出每条判断的出处。
- 你接受两条硬约束：**不产出任何数值**；**不作诊断、不作正常与异常的判定**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是给结论，而是把一段叙述拆成一台回路，并指出它停在哪一环。

【输入】
原话：<一段自述、一组体征或一段病程记录>
讲义定位：<补充·hermes-病理生理学讲义·第2章·2.M>

【任务，按顺序回答，不跳步】
1. 变量：这句话讲的是哪个被调变量？温度、血糖、血压、体液、睡眠，还是别的？只归类别。
2. 设定点：这个变量的目标值有没有被移动过？若有，说明它是适应性的上调，还是被固定下来。
3. 感受器与效应器：偏差是谁检测的、谁执行的？两端的反应是「偏差很大而纠正迟到」，还是「信号很强而反应很弱」？
4. 应激源：把它归到物理、化学、生物、心理社会、生活事件哪一类；再判断是外部事件，还是内在应激源（疼痛、发热、低血糖、缺氧、失眠）。
5. 时序：落在警觉期、抵抗期、衰竭期哪一段？还是已经在慢性化的累积里？
6. 失败方式：三种里选一种——设定点被移动、调节增益不足、效应器失效。选不出就写「证据不足」，不要硬套。
7. 证据限度：这句话能证到哪一步？把「导致」改成参与、增加、影响，并说明依据来自哪一层研究。
8. 边界：这段拆解不能回答什么。

【硬约束】
- 不给任何数值、单位、正常值、参考区间、百分比。凡需数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作正常与异常判定，不把异稳态负荷当诊断标签，不作预后判定。
- 引讲义原文必须逐字，并标「补充·hermes-病理生理学讲义·第2章·2.M」；核不到就不引。
- 某一环缺证据就写「未给」，不要用推测填满。

【输出格式】
八个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的拆解（节选）

原话：「这半年加班多，血压高了，晚上睡不踏实，还老感冒，是不是压力太大了？」讲义定位：补充·hermes-病理生理学讲义·第2章·2.3。

- **变量**：血压、睡眠、感染易感性三个变量同时在句中出现，属不同回路的输出，不能合成一个。
- **设定点**：句中没有给出目标值是否移动的证据；只能说「可能上调」，不能说「已经固定」。
- **感受器与效应器**：两项都没有描述，属未给。缺这两端，就无法判断是增益不足还是效应器失效。
- **应激源**：加班属心理社会性与生活事件两类交叉；若睡眠剥夺本身成立，它同时是内在应激源——这一点常被「最近有什么压力」这一问漏掉。
- **时序**：以「这半年」判断，已过警觉期，可能落在抵抗期，但不能由此推断衰竭。
- **失败方式**：证据不足。三种方式需要不同的证据：设定点上移要看长期偏离，增益不足要看纠正迟到，效应器失效要看信号与反应脱节。
- **证据限度**：只能说应激参与、增加风险、影响病程；不能说「压力导致了这些」。
- **边界**：不能推断器官受损程度、不能给处置顺序、不给任何数值。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 把应激当病因 | 「压力导致的」 | 改为参与、增加、影响三个动词 |
| 设定点当失灵 | 「调节坏了」 | 先问目标值有没有被移动 |
| 三种失败混为一谈 | 「就是失调」 | 按两句特征句逐条比对，选不出写证据不足 |
| 漏掉内在应激源 | 只问外部事件 | 补问疼痛、发热、低血糖、缺氧、失眠 |
| 负荷当诊断 | 「这是异稳态负荷高」 | 负荷是类别，判定需量表与资质 |
| 偷给数值 | 「高压到了一百五」 | 触发硬约束，改为方向性表述 |

## 边界

本模板训练的是「变量 → 设定点 → 两端 → 时序 → 失败方式 → 证据限度」的分层表达能力，不产生临床判断。回路与三种失败方式取自《hermes-病理生理学讲义》第 2 章的表述；数值与判定不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
