# Skill：稳态与应激——一台回路、三种失败方式

## 何时用

- 有人说「调节坏了」「失调了」，却说不清坏在哪一环
- 要把一段「压力大 + 若干症状」的自述拆成可以核对的机制
- 要区分应激反应、异稳态负荷与疾病三个层级
- 要判断某人的表现属设定点上移、增益不足还是效应器失效
- 遇到「这是不是压力造成的」这类追问，需要一致的表述口径

## 核心判据（四问）

1. **哪个变量？** 温度、血糖、血压、体液、睡眠，一次只谈一个；多个变量同时出现时分开写。
2. **设定点动过没有？** 没动过，看反馈与增益；动过，看它是适应性上调还是被固定下来。
3. **偏差与反应配不配？** 偏差很大而纠正迟到 → 增益不足；信号很强而反应很弱 → 效应器失效；反应正常而目标偏离 → 设定点上移。
4. **能证到哪一步？** 参与、增加、影响三个动词是上限；「导致」需要另一层证据。

## 执行步骤

```text
1. 抄原话，不改写：把要拆的那段话原样放在第一行
2. 定变量：一次一个，多个变量分开列
3. 查设定点：目标值是固定的、上调的，还是已被固定在高位
4. 查两端：感受器端与效应器端各一句，缺的写「未给」
5. 定应激源：五类中归一类，并补问内在应激源
6. 标时序：警觉期 / 抵抗期 / 衰竭期 / 慢性累积
7. 选失败方式：三种之一，选不出写「证据不足」
8. 收表述：改成参与、增加、影响，并注明证据层级
```

## 硬约束

- **不给数值、单位、正常值、参考区间、百分比。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不作诊断，不作正常与异常判定。** 异稳态负荷是类别，不是标签；它由一组指标与量表综合评估，本书只到类别层，不给分界值。
- **应激参与不等于应激致病。** 把相关性写成因果、把群体风险写成个体命运，都越过本章的证据限度。
- **引文逐字。** 标「补充·hermes-病理生理学讲义·第2章·2.M」；核不到就不引。讲义是本仓库原创教学正文，不许写成任何外文教材的译本。
- **层次必标。** 细胞、器官、系统、整体四个尺度的表述不混写；两轴的急性效应不直接当慢性的病因。
- **不作处置建议。** 减量、用药、监测项目属临床决策，本 Skill 只给机制与判据。

## 交付物

1. 一段回路拆解（变量 → 设定点 → 两端 → 时序），缺环如实标缺
2. 一句失败方式判断：三种之一，或写「证据不足」并说明缺哪条证据
3. 一张应激源归类：五类中一类，附内在应激源是否成立
4. 一句收束表述：参与、增加、影响三个动词，注明证据层级
5. 一处边界：本章不给值、不作诊断，负荷须另立数据层

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 稳态当不变 | 把波动读成异常 | 稳态是围绕设定点的波动 |
| 设定点当失灵 | 适应被误判为故障 | 先问目标值是否被移动 |
| 三种失败混为一谈 | 干预方向全错 | 按两句特征句逐条比对 |
| 负荷当诊断 | 类别变成标签 | 负荷只作类别，判定需量表与资质 |
| 急性当慢性 | 两轴的急性效应当成病因 | 分开写时程，再看累积 |
| 漏掉内在应激源 | 只问外部压力 | 补问疼痛、发热、低血糖、缺氧、失眠 |

## 与相邻章节的接缝

- 上一章（导论）：本章补上导论列为第四条规律却不展开的稳态失衡；导论给钩子，本章挂内容。

- 第 16 章（血压异常）：2.11 的「设定点被移动」是那一章解释持续性血压偏高的入口。
- 与心理学的分工：心理学讲评价与应对的行为层，本章讲评价之后的神经内分泌与免疫通路。

## 边界

本 Skill 只处理「一段叙述 → 一台回路 → 三种失败方式 → 一句收束表述」的结构化拆解，不涉及数值、判定与临床决策。回路与失败方式取自《hermes-病理生理学讲义》第 2 章的表述；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
