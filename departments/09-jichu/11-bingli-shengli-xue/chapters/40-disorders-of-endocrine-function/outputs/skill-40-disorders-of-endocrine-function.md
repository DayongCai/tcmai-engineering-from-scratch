# Skill：内分泌功能紊乱——四种型态、一张定位表与五种急症

## 何时用

- 一段描述里出现彼此方向矛盾的症状（怕冷却激素偏高、消瘦却食欲增加），需要先定型态
- 化验方向已经知道，但要判断病变在靶腺、垂体还是下丘脑
- 要解释为什么同一疾病在不同阶段方向相反
- 要评估一位长期用激素的患者在感染或手术时的风险
- 遇到「要不要紧」这类追问，需要一致的拒答口径

## 核心判据（五问）

1. **效应过强还是不足？** 四项型态：亢进、减退、抵抗、结构与异位分泌。
2. **几个腺体？** 单腺体、多腺体、综合征性——多腺体提示共同病因，常见为自身免疫。
3. **一对激素相称吗？** 靶腺激素与促激素反向说明反馈在工作；同向变动说明环路被打破。
4. **哪一格？** 原发（靶腺）、继发（垂体）、三发（下丘脑）、或终末效应一侧（抵抗）。
5. **有没有急症形态？** 意识改变加循环或呼吸不稳定，是需要立刻上报的组合。

## 执行步骤

```text
1. 抄原话，不改写：把要还原的那段放在第一行
2. 定型态：四类选一，抵抗单独标记（最易读反）
3. 定范围：单腺体 / 多腺体 / 综合征性
4. 读方向：只写升、降、相称、不相称
5. 落层级：四格表推断，落在「两个都高」时写清下一步靠什么分开
6. 排干扰：外源激素、采血时点、结合蛋白、急性应激
7. 标急症：有无意识改变与循环呼吸不稳定
8. 报边界：不给值、不作诊断、不写处置流程
```

## 硬约束

- **不给数值、单位、正常值、参考区间、百分比。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不作诊断，不作正常与异常判定。** 四种型态与四格表是机制坐标，不是给个体定性。
- **不写处置流程。** 急症只写识别方向与优先级；药物、剂量、操作步骤属临床决策。
- **不把方向当标签。** 同一疾病在不同阶段方向可以翻转，读的是当下这一对激素的关系。
- **引文逐字。** 标`补充·hermes-病理生理学讲义·第40章·N.M`；核不到就不引。讲义是本仓库原创正文，不写成任何外文教材的译本。

## 交付物

1. 一句型态判断与一句范围判断
2. 一句一对激素的方向判断（相称／不相称）
3. 一句层级落点，或一句“还差哪一步才能定”
4. 一张四类干扰排查表
5. 一行急症风险提示（有／无，有则写识别方向）
6. 一处边界：不给值、不作诊断、不写处置

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 病名先行 | 方向翻转时判反 | 先定型态与范围 |
| 抵抗读成亢进 | 结论与事实相反 | 看终末效应 |
| 单激素定位 | 层次错位 | 四格表成对读 |
| 忽略外源激素 | 漏掉一条独立病因 | 用药史单列一栏 |
| 把稳定当安全 | 漏掉应激时的风险 | 补一句“应激时会怎样” |
| 越过处置 | 越过教学边界 | 只写识别方向 |

## 边界

本 Skill 只处理「症状 → 型态 → 层级 → 边界」的结构化还原，不涉及数值、判定与临床决策。型态与定位类别取自本仓库原创讲义第 40 章（40.1–40.11）；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
