# Prompt：把一串症状还原成四种型态里的一格

## 用途

内分泌紊乱这一章的难点不在病名多，而在同一批症状可能来自相反的型态。这个模板不让你背综合征，只让你把一段描述还原成型态与层级两格，并指出还差哪一步才能定位置。适用于讨论课的机制推演、护理评估的结构化整理，以及读病程记录时确认每一句话落在哪一格。

## 使用前提

- 你面对的是一段**描述**（症状、体征、化验方向、用药史、手术史），不是一份诊断。
- 你手边有讲义定位（`补充·hermes-病理生理学讲义·第40章·40.5` 这一级），读过对应小节。
- 你接受三条硬约束：**不产出任何数值**；**不作诊断与判定**；**不给药物与剂量**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是给病名，而是把一段描述还原成型态与层级两格，并说明还差哪一步才能定位置。

【输入】
原话：<一段描述，可以带病名、可以带判断>
讲义定位：<补充·hermes-病理生理学讲义·第N章·N.M>

【任务，按顺序回答，不跳步】
1. 定型态：效应过强、效应不足、水平不低而效应不足（抵抗），还是结构与异位分泌？四类只选一类主型态。
2. 定范围：单腺体、多腺体，还是综合征性？
3. 读一对激素：靶腺激素与促激素的方向是反向、同向偏低，还是同向偏高？只写方向，不写数值。
4. 落层级：按四格表推断靶腺、垂体、下丘脑，或终末效应一侧。若落进「两个都高」那一格，说清接下来要靠什么分开。
5. 排干扰：外源激素、采血时点、结合蛋白、急性应激，逐条说有没有。
6. 找急症风险：这段描述里有无意识改变、循环或呼吸不稳定的线索？有就单列一行。
7. 越界清单：把原话里的判定成分逐条指出，给出中性改写。
8. 边界：这段推演不能回答什么。

【硬约束】
- 不给任何数值、单位、正常值、参考区间、百分比。凡需数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作正常与异常判定，不作预后判定，不作疗效断言。
- 不写处置流程：急症只写识别方向与优先级，不写用药、剂量与操作步骤。
- 引讲义原文必须逐字并标「补充·hermes-病理生理学讲义·第40章·N.M」；核不到就不引。

【输出格式】
八个小标题各答一到两句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的还原（节选）

原话：「她最近脸圆了、背厚了、皮肤薄容易淤青，说是用了很久的药。」讲义定位：补充·hermes-病理生理学讲义·第40章·40.8。

- **定型态**：效应过强，属皮质醇增多一侧。
- **定范围**：单腺体表现，但病因可能在腺体外。
- **读一对激素**：关键在于内源皮质醇与促激素是否同时被压低——若两者都低，说明来源在体外。
- **落层级**：外源激素这一格，不是肾上腺本身。
- **排干扰**：外源激素正是本例的主因，须先排除；急性应激会同时抬高多个轴，读的时候要避开应激窗。
- **急症风险**：长期外源激素抑制整条轴，减量过快或骤停有危象风险；这一点比当下的体型改变更要紧。
- **越界清单**：「用了很久的药」不带评价，可保留；「脸圆了」改为「面部脂肪重新分布」。
- **边界**：不判断任何个体的状态，也不给减量方案。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 病名先行 | 直接说「这是某某综合征」 | 先定型态与范围，再谈病名 |
| 把抵抗读成亢进 | 激素高就判效应过强 | 看终末效应，不看单点浓度 |
| 只读一个激素 | 不看促激素就定位 | 四格表要成对读 |
| 忽略外源 | 把用药史当背景 | 外源激素是亢进的一条独立路径 |
| 越过处置 | 直接写急症处理流程 | 只写识别方向与优先级 |
| 漏掉应激维 | 只看平时状态 | 脆弱性只在应激时显现 |

## 边界

本模板训练的是「症状 → 型态 → 层级 → 边界」的还原，不产生临床判断。型态与定位类别取自本仓库原创讲义第 40 章（40.1–40.11）；数值、判定与处置均不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
