# Skill：骨骼肌肉系统——六项功能、重建耦联与强度三要素

## 何时用

- 一段描述里出现骨量、骨折、关节疼痛、肌力下降或活动受限，需要先推维护链再谈原因
- 要判断一处骨病变落在耦联失衡的哪个方向
- 要把「补钙」「养养就好」这类说法换成机制层面的判断
- 要在康复或护理计划里说明负荷为什么是治疗的一部分
- 遇到「骨量够不够」「几级肌力」这类追问，需要一致的拒答口径

## 核心判据（五问）

1. **哪项功能？** 支撑保护、运动姿势、矿物储库、造血、产热代谢、内分泌——六项里碰到哪几项，就决定了连带损失在哪。
2. **哪一层？** 皮质骨、松质骨与骨小梁、关节软骨、滑膜、肌肉、神经控制。层定错，后面全错。
3. **哪个方向？** 形成下降加吸收上升；两者同降但吸收占优；局部吸收剧增；局部形成剧增。
4. **强度三要素？** 骨量、微结构、材料质量——三者处理方向不同，微结构的不可逆性最强。
5. **外力侧呢？** 骨折风险是强度与外力的乘积；平衡三联任一受损都抬高外力侧风险。

## 执行步骤

```text
1. 抄原话，不改写：把要推的那段放在第一行
2. 定功能：六项功能里碰到哪几项，连带损失写在哪
3. 定层：骨、软骨、滑膜、肌肉、神经，只选一层作起点
4. 推维护：骨看五相与三条主控通路；软骨看周期性负荷；肌肉看负荷与募集
5. 判方向：耦联失衡四个方向里选一个，写出依据
6. 拆强度：骨量、微结构、材料质量三项分别说
7. 补外力：平衡三联与跌倒线索，与强度并列写
8. 中性改写：删掉判定与分级，只留机制与负荷类别
9. 报边界：不给值、不分级、不作诊断与预后判断
```

## 硬约束

- **不给数值、单位、正常值、分级、度数、百分比。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不作诊断，不作正常与异常判定。** 六项功能与四种失衡方向都是机制类别，不是判定标准。
- **不给个体预测。** 强度与外力的乘法说明的是风险方向，不是某个人的结局。
- **不写药名、剂量与训练处方。** 只写机制环节与负荷类别。
- **不把软骨当可修组织。** 三无决定修复极限，写清楚营养方式与缺损替代。
- **引文逐字。** 标「补充·hermes-病理生理学讲义·第49章·N.M」；核不到就不引。

## 交付物

1. 一段功能落位（六项里哪几项，连带损失在哪）
2. 一句结构层判断，附依据
3. 一句耦联失衡方向，附依据
4. 强度三要素的拆分：骨量、微结构、材料质量
5. 外力侧的补充：平衡三联与跌倒线索
6. 一处边界：不给值、不分级、不作诊断与预后判断

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 把骨当死材料 | 认为补钙即可 | 先问负荷在不在，回到重建与耦联 |
| 混淆量与质量 | 骨量正常就认为没问题 | 拆成骨量、微结构、材料质量三项 |
| 只看骨不看外力 | 漏掉一半风险 | 强度与外力两条线并行 |
| 把软骨当可修 | 延误对结构改变的认识 | 三无决定修复极限 |
| 用分级代替描述 | 记录无法复评 | 改成抗重力、抗阻、对称三项描述 |
| 顺手给训练处方 | 越界 | 只写机制环节与负荷类别 |

## 与相邻章节的接缝

- 与第 50 章（创伤、感染与疾病）：本章的重建五相与耦联，是那一章骨折愈合三期的地基；本章的「三无软骨」解释了关节感染的破坏为何迅速。
- 与第 24、25 章（水电解质与酸碱）：骨的矿物储库身份，与钙磷平衡那两章直接相连。
- 与第 47 章（疼痛）：骨与关节的疼痛机制起点在转导与敏化；本章只给结构。
- 与第 2 章（稳态与应激）：制动带来的多系统退化，是异稳态那条思路在力学维度上的版本。

## 边界

本 Skill 只处理「一段描述 → 功能落位 → 维护机制 → 失衡方向 → 强度与外力」的结构化推演，不涉及诊断、分级与治疗决策。机制框架取自本仓库原创讲义第 49 章；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
