# Prompt：把「他骨头不好」推成一条重建链，而不是一句补钙

## 用途

骨骼肌肉这一章的机制最后都落在维护上：骨靠重建耦联更新，软骨靠周期性负荷换营养，强度靠微结构与外力共同决定。这个模板不让你判断「缺不缺钙」，只让你把一段关于骨、关节或肌力的描述推成维护链，判断它落在哪一层、朝哪个方向失衡。适用于讨论课的机制推演、康复与护理计划的机制自检，以及读一份影像或功能描述时先确认它说的是量、是微结构还是材料质量。

## 使用前提

- 你面对的是一段**结构或功能描述**（部位、负荷情况、活动能力、既往史线索），不是一个待判定的病例。
- 你手边有讲义定位（`补充·hermes-病理生理学讲义·第49章·49.4` 这一级），读过对应小节。
- 你接受三条硬约束：**不产出任何数值**；**不作诊断与判定**；**不给分级、不做个体预测**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是判断某个人骨量够不够，而是把一段描述推成一条维护链，指出失衡落在哪一层，并说明这段推演回答不了什么。

【输入】
原话：<一段骨、关节或肌力的描述，可以带判断>
讲义定位：<补充·hermes-病理生理学讲义·第49章·N.M>

【任务，按顺序回答，不跳步】
1. 六项功能：这句话碰到的是支撑保护、运动姿势、矿物储库、造血、产热代谢、内分泌里的哪几项？只写碰到的。
2. 结构层：说的是皮质骨、松质骨、骨小梁微结构、关节软骨、滑膜、肌肉，还是神经控制？只选一层作起点。
3. 维护机制：骨看重建五相与三条主控通路（RANKL 与 OPG 的比值、Wnt 与硬化素、甲状旁腺激素的时程特征）；软骨看周期性负荷与滑液扩散；肌肉看负荷与募集。
4. 方向：耦联失衡落在哪一个方向——形成下降加吸收上升、两者同降但吸收占优、局部吸收剧增、局部形成剧增？
5. 力学：这条链里负荷是被撤除了、还是被改变了形式（离心、冲击、制动）？
6. 强度三要素：描述指向骨量、微结构，还是材料质量？三者的处理方向不同。
7. 外力侧：有没有跌倒与平衡三联（视力、前庭、本体感觉）的线索？风险是强度与外力的乘积。
8. 越界清单：原话里哪些成分是判定（诊断、分级、预后）？逐条指出并给中性改写。
9. 边界：这段推演不能回答什么。

【硬约束】
- 不给任何数值、单位、正常值、分级、度数、百分比。凡需数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作正常与异常判定，不作预后判定，不作疗效断言。
- 不写药名、剂量与方案；只写机制环节与负荷类别。
- 引讲义原文必须逐字并标「补充·hermes-病理生理学讲义·第49章·N.M」；核不到就不引。

【输出格式】
九个小标题各答一到两句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的推链（节选）

原话：「老人骨折后卧床两个月，现在下地腿发软，家里人说多喝骨头汤补补。」讲义定位：补充·hermes-病理生理学讲义·第49章·49.4。

- **六项功能**：碰到支撑保护与运动姿势两项，另涉及矿物储库——卧床时骨吸收增强，钙从骨流向血。
- **结构层**：起点在骨（承重部位松质骨）与肌肉两侧，不在关节。
- **维护机制**：骨一侧负荷撤除使硬化素升高、Wnt 下调，形成下降而吸收相对占优；肌肉一侧蛋白合成下降、降解增强。
- **方向**：形成下降加吸收上升，属制动型的耦联失衡。
- **力学**：负荷被撤除而非改变形式；这正是「越不动越不能动」的机制起点。
- **强度三要素**：这条链同时动了骨量（丢失）与微结构（连接性受损），后者不可逆性更强。
- **外力侧**：腿发软提示肌力与本体感觉两侧都要评估；平衡三联任一受损都会抬高跌倒风险。
- **越界清单**：「多喝骨头汤补补」是处置建议而非机制，改为「按康复方案逐步加负荷，营养由具备资质者评估」。
- **边界**：不能判断任何人的骨量或骨折风险，也不能替代影像与功能评估。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 把骨当死材料 | 「补钙就行」 | 先问负荷在不在，回到重建与耦联 |
| 混淆量与质量 | 「骨量低所以骨折」 | 分骨量、微结构、材料质量三项说 |
| 只看骨不看外力 | 只谈增骨量不谈防跌倒 | 风险是强度与外力的乘积，两条线并行 |
| 把软骨当可修 | 「养养就好」 | 三无决定修复极限，改说负荷与营养方式 |
| 用分级代替描述 | 「肌力几级」 | 改成能否抗重力、能否抗阻力、是否对称 |
| 顺手给方案 | 补剂、剂量、训练处方 | 只写机制环节与负荷类别 |

## 边界

本模板训练的是「一段描述 → 六项功能 → 维护机制 → 失衡方向 → 强度与外力」的结构化推演，不产生临床判断。机制框架取自本仓库原创讲义第 49 章；数值、分级与用药不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
