# Prompt：把「血压还行」拆成三要素与一条环节链

## 用途

休克讨论里最容易被糊过去的一句是「血压还能撑住，先观察」。这句话把**压力**当成了**灌注**，把判断交给了下一次读数。本模板不判断谁在休克，只做一件事：把一段关于循环状态的叙述拆到三要素上，再指出它停在环节链的哪一段、还缺哪一段。适用于交班复述、病例讨论前的自检，以及读本章第七、八节时把「代偿」读成一种有代价的状态。

## 使用前提

- 输入是一段**机制叙述或交班描述**，不是一份待处置的病例。
- 手边有讲义定位（`补充·hermes-病理生理学讲义·第20章·20.3` 这一级），读过对应小节。
- 接受两条硬约束：**不产出任何数值**；**不作诊断、不作分期、不作处置建议**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是判断有没有休克，而是把一段循环相关的叙述拆到三要素上，并指出它停在环节链的哪一段。

【输入】
原话：<一段交班描述、机制叙述或讨论发言>
讲义定位：<补充·hermes-病理生理学讲义·第20章·N.M>

【任务，按顺序回答，不跳步】
1. 压力还是灌注：这句话用的是压力读数，还是灌注证据（意识、皮肤温度与色泽、尿量、毛细血管再充盈、乳酸倾向）？两者不可互为替代。
2. 三要素归位：容量、泵、张力与分布，哪一要素先失效？若同时有两项，按「先失效」排序，并说明依据。
3. 环节链位置：这句话停在链的哪一段——血量下降、灌注下降、氧输送不足、细胞代谢障碍、细胞结构损伤、器官功能受损、内环境紊乱？下一段是什么？
4. 微循环三段：痉挛、淤滞、微血栓，这句话对应哪一段？若无法判断，写「未给」。
5. 分期（只作机制位置）：代偿期（灌注不足而压力尚可）、进展期（压力与灌注同时下降）、难治期（压力可撑而细胞不能用）——落在哪一个组合上？
6. 越界清单：这句话里哪些成分是对个体的判定（诊断、分期、预后、处置）？逐条指出，并给出只保留机制的中性改写。
7. 边界：这段拆解不能回答什么。

【硬约束】
- 不给任何数值、单位、正常值、阈值、百分比。凡需要数值才能回答的追问，统一回答「不给值，须另立数据层」。
- 不作诊断，不作分期判定，不作处置建议；不写药名、剂量与滴速。
- 引讲义原文必须逐字，并标「补充·hermes-病理生理学讲义·第20章·N.M」；核不到就不引。
- 不把讲义标成「教材」。
- 原话不足以定位时写「未给」，不用推测填满。

【输出格式】
七个小标题各答一到三句；第 2 项用一个「要素 → 先失效的证据 → 对应动词」的三列小表；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/治疗/用药依据。」
```

## 示例：一次合格的拆解（节选）

原话：「他血压还行，手脚有点凉，尿少，先看看再说。」定位：`补充·hermes-病理生理学讲义·第20章·20.7`。

- **压力还是灌注**：这句话混用了两者——「血压还行」是压力读数，「手脚凉、尿少」是灌注证据。混用正是误判的起点。
- **三要素归位**：未给病因，无法定位哪一要素先失效；只能记「未给」。「手脚凉」提示外周血管收缩，「尿少」提示容量或肾灌注下降，两者都不能单独定要素。
- **环节链位置**：停在「组织灌注下降」这一段；氧输送与细胞代谢两段未给。
- **微循环三段**：外周收缩与尿少提示痉挛期方向，但没有微循环层面的证据，写「方向相符、证据不足」。
- **分期**：落在「灌注不足而压力尚可」这一组合上——这正是代偿期名字的由来，也是最佳窗口所在。
- **越界清单**：「先看看再说」是处置判断，不属于机制层；改成「按机制记录末端灌注证据的变化趋势」。
- **边界**：不能据此判断任何人的状态；不给任何阈值。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 血压当灌注 | 「血压正常，不像休克」 | 改列末端灌注证据，压力只作参考 |
| 三要素混写 | 「容量不足导致心功能下降」 | 先定哪一要素先失效，再谈传导 |
| 跳过细胞层 | 「恢复血压就好了」 | 链条后段有细胞与微循环损伤，须写明 |
| 分期当时间 | 「发病几小时属于某期」 | 分期按链的位置分，不按时间分 |
| 类型当标签 | 「他就是分布性休克」 | 只写哪一要素先失效 |
| 偷给阈值 | 「收缩压低于某值才算」 | 触发硬约束，改为「不给值，另立数据层」 |

## 边界

本模板训练的是「叙述 → 三要素 → 链位置」的机制拆解，不产生临床判断。机制框架取自《hermes-病理生理学讲义》第 20 章；数值、分期判定与处置不在本课程范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
