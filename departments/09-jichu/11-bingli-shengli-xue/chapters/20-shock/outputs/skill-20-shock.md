# Skill：休克的三要素归位与链位置判定

## 何时用

- 有人用「血压还行」「手脚有点凉」这类零散线索下结论，需要把线索归到要素与链段上
- 要在四类休克之间定位时，先问「哪一要素先失效」，而不是先贴类型名
- 要判断一段叙述有没有把「压力」当「灌注」、把「分期」当时间段
- 遇到「算不算休克」「到没到某期」这类追问，需要一致的拒答口径

## 核心判据（四问）

1. **是压力还是灌注？** 压力是驱动力之一；灌注要看意识、皮肤温度与色泽、尿量、毛细血管再充盈、乳酸倾向。
2. **哪一要素先失效？** 容量、泵、张力与分布（含梗阻）。先失效的那一个决定动词：补容量、强泵、调张力、解除梗阻。
3. **链走到哪一段？** 血量 → 灌注 → 氧输送 → 细胞代谢 → 细胞结构 → 器官 → 内环境。越靠前越可逆。
4. **微循环在哪一段？** 痉挛（血压可撑、组织已缺血）、淤滞（灌入多、流出少）、微血栓（无复流）。

## 执行步骤

```text
1. 抄原话，不改写
2. 分压力与灌注：把读数与末端证据分两栏记
3. 定要素：容量 / 泵 / 张力与分布 / 梗阻，先失效者排在前面
4. 定链段：这句话停在链的哪一段，下一段是什么
5. 定微循环段：痉挛 / 淤滞 / 微血栓 / 未给
6. 分期只作机制位置：三种组合，不按时间
7. 中性改写：删掉判定与处置成分
8. 报边界：不给值、不分期、不处置
```

## 硬约束

- **不给数值、单位、正常值、阈值、百分比。** 需要数值才能回答的追问，统一回「不给值，须另立数据层」。
- **不作诊断、不作分期判定、不作处置建议。** 代偿期与难治期是机制位置的名字，不是对某个人的分期。
- **引文逐字**，标 `补充·hermes-病理生理学讲义·第20章·N.M`；核不到就不引，不标「教材」。
- **不写药名、剂量与滴速。** 只写要素与环上的位置。
- **四类可以并存**，不要为了归类而抹掉第二要素。

## 交付物

1. 一段要素归位（容量 / 泵 / 张力与分布），先失效者在前
2. 一句链位置：停在哪一段、下一段是什么
3. 一句微循环段位：痉挛 / 淤滞 / 微血栓 / 未给
4. 一段中性改写：删掉判定与处置成分
5. 一处边界：不给值、不分期，数值须另立数据层

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 血压当灌注 | 「血压正常，不像休克」 | 列末端证据，压力只作参考 |
| 类型先行 | 先贴「分布性」再找证据 | 先定哪一要素先失效 |
| 分期按时间 | 「几小时属于某期」 | 按链的位置分 |
| 复苏即逆转 | 「血压回来就好了」 | 细胞与微循环损伤可能已成立 |
| 只处理一要素 | 三条入口开着只关一扇门 | 进展期须同时处理容量、泵、张力与病因 |
| 被追问就报阈值 | 「低于某值才算休克」 | 统一回「不给值，另立数据层」 |

## 边界

本 Skill 只处理「叙述 → 要素 → 链位置」的结构化拆解，不涉及数值、分期与处置。机制框架取自《hermes-病理生理学讲义》第 20 章；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
