# Prompt：把一份酸碱报告读成方向，而不是类型

## 用途

酸碱报告最容易被读成一次命名：先给一个类型名，再按名字去套处置。本模板反着来——先把四个变量放回方向，再按三步骨架走一遍，最后才允许出现类型名。适用于讨论课上读报告、交班前的自检，以及读第 24 章（水电解质）之后把「钾的分布」与「酸碱」合起来的场合。

## 使用前提

- 你面对的是一段**方向描述**（哪一项升、哪一项降、哪一项在正常范围），不是一份要处理的医嘱。
- 你手边有讲义定位（`补充·hermes-病理生理学讲义·第25章·25.11` 这一级），读过对应小节。
- 你接受两条硬约束：**不产出任何数值、阈值与公式**；**不作诊断、不作正常与异常的判定**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是给类型名，而是把一份酸碱描述读成方向，并指出哪一步越界。

【输入】
原话：<一份方向描述，可以带数值，可以带结论>
讲义定位：<补充·hermes-病理生理学讲义·第N章·N.M>

【任务，按顺序回答，不跳步】
1. 去数值：把原话里的数值全部替换成方向词（升高 / 降低 / 在描述范围内），并说明替换后有没有丢掉信息。
2. 看 pH 方向：酸血症、碱血症，或落在描述范围内。若是第三项，明确写下「pH 正常不等于无失衡」。
3. 找同向侧：碳酸氢根与二氧化碳分压，哪一项的变化方向与 pH 一致？它决定原发失衡是代谢性还是呼吸性。
4. 查对侧：对侧指标的变化方向与原发相反还是相同？相反为代偿中，相同为两个原发失衡并存——这一步只用方向，不比较幅度。
5. 若为代谢性酸中毒：阴离子间隙的方向是增大还是正常？增大指向固定酸蓄积，正常指向丢碱或排酸障碍。
6. 时间维度：这份描述是急性还是慢性？肾代偿有没有启动的时间？没有时间信息就写「无法判断急慢」。
7. 病史回指：呕吐、腹泻、利尿剂、胰岛素、镇静剂、机械通气、肾功能与肝功能，哪几项被提到？没提到的写没提到。
8. 越界清单：指出原话里属于个体判定（诊断、严重程度、处置、疗效）的成分，逐条给出中性改写。
9. 边界：这段判读不能回答什么。

【硬约束】
- 不给任何数值、单位、正常值、参考区间、百分比、阈值、预计代偿范围与公式。凡需数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作正常与异常判定；不写补碱、促通气或抑制通气的处置。
- 引讲义原文必须逐字，并标「补充·hermes-病理生理学讲义·第N章·N.M」；核不到就不引。
- 幅度比较不在本章范围内：只写「过小」「过大」的定性印象，并注明这是示意、不作为阈值。

【输出格式】
九个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的读法（节选）

原话：「pH 偏低，碳酸氢根低，二氧化碳分压也低，考虑代谢性酸中毒，已代偿。」讲义定位：补充·hermes-病理生理学讲义·第25章·25.11。

- **去数值**：原话只给了方向，替换后信息不丢；但缺「低了多快」这一维度。
- **看 pH 方向**：酸血症。
- **找同向侧**：碳酸氢根降低与 pH 同向，原发为代谢性酸中毒。
- **查对侧**：二氧化碳分压也降低，与原发（碳酸氢根降低）**同向**。代偿改变的方向永远与原发相反，所以这不是代偿，而是另一个原发失衡——同时存在呼吸性碱中毒。
- **间隙**：原话未给，写「缺」，并说明它决定固定酸蓄积还是丢碱。
- **时间维度**：未给，写「无法判断急慢」。
- **病史回指**：一项都没提到。脓毒症、水杨酸类、肝衰竭都可能造成这一组合，须回到临床。
- **越界清单**：「考虑代谢性酸中毒，已代偿」是判定，改为「代谢侧原发为酸中毒，呼吸侧另有原发，属混合型方向」。
- **边界**：不能据此决定任何处置；阈值与幅度一律不给。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 先命名后推理 | 一开口就是「代酸」 | 先走三步，再落名字 |
| 把同向当代偿 | 「二氧化碳低是代偿」 | 方向相反才是代偿，同向即混合 |
| pH 正常就收工 | 「大致正常」 | 补一句：pH 正常不等于无失衡 |
| 忽略急慢 | 用慢性标准读急性报告 | 先问肾代偿有没有时间启动 |
| 只读报告不问病史 | 「按报告处理」 | 报告永远不能脱离病史单独解读 |
| 偷给阈值 | 「低于多少算代偿」 | 触发硬约束，改为「本书不给值」 |

## 边界

本模板训练的是「方向 → 三步 → 混合判定 → 越界改写」的读法，不产生临床判断。框架取自本仓库原创《hermes-病理生理学讲义》第 25 章；数值、阈值、公式与判定不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
