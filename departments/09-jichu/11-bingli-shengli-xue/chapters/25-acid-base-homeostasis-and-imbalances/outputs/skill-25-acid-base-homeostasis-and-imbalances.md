# Skill：酸碱失衡——三步骨架与方向判据

## 何时用

- 有人拿着报告直接给出类型名（「代酸」「呼碱」），需要退回方向重走一遍
- pH 落在正常范围而两侧指标都异常，需要判断是「没有失衡」还是「两个失衡互相抵消」
- 两侧指标同向变化，需要区分「代偿」与「两个原发并存」
- 需要判断同一份报告在急性与慢性下判读是否不同
- 遇到「降到多少算代偿」「间隙多大算增大」这类追问，需要一套一致的拒答口径

## 核心判据（五问）

1. **pH 往哪边偏？** 酸血症、碱血症，或落在描述范围内。第三项必须补一句：pH 正常不等于无失衡。
2. **哪一侧与 pH 同向？** 碳酸氢根降低伴酸血症即代谢性酸中毒；二氧化碳分压升高伴酸血症即呼吸性酸中毒；依此类推。同向那一侧才是原发。
3. **对侧是反向还是同向？** 反向为代偿中；同向即两个原发失衡并存。这一步只看方向，不比较幅度。
4. **若是代谢性酸中毒，间隙朝哪边走？** 增大指向固定酸蓄积；正常指向碳酸氢根丢失或排酸障碍。
5. **时间够不够？** 肾代偿要数小时至数日才启动；急性与慢性的 pH 与碳酸氢根完全不同。没有时间信息就写「无法判断急慢」。

## 执行步骤

```text
1. 抄原话，不改写：把结论句原样放在第一行
2. 去数值：全部替换成方向词，并说明有没有丢信息
3. 定酸碱：pH 方向，或写下「pH 正常不等于无失衡」
4. 定原发：找与 pH 同向的那一侧指标
5. 查对侧：反向为代偿，同向为混合；只写方向，不写幅度
6. 分间隙：代谢性酸中毒必看间隙方向
7. 判急慢：肾代偿有没有时间启动
8. 回病史：呕吐、腹泻、利尿剂、胰岛素、镇静剂、通气、肝肾功能的线索
9. 中性改写：删掉类型名与处置，只留方向与原发判断
10. 报边界：不给阈值、不给公式、不作诊断
```

## 硬约束

- **不给数值、单位、正常值、参考区间、百分比、阈值、预计代偿范围与公式。** 统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不作诊断，不作正常与异常判定。** 四型在本 Skill 里只作机制类别的名字。
- **幅度只作定性印象。** 可以说「明显小于应有代偿」，同时注明这是示意、不作为阈值。
- **同向即混合。** 不许把同向变化写成「代偿良好」。
- **急慢必问。** 没有时间信息就写「无法判断急慢」，不默认按急性或慢性读。
- **引文逐字。** 标「补充·hermes-病理生理学讲义·第N章·N.M」；核不到就不引。

## 交付物

1. 一句 pH 方向，或在正常范围时的限定说明
2. 一条原发判断：哪一侧与 pH 同向
3. 一条代偿判断：对侧反向还是同向
4. 一条间隙判断（代谢性酸中毒时必写）
5. 一条急慢判断：肾代偿是否有时机
6. 一份病史回指：相关线索提到哪几项
7. 一段中性改写：删掉类型名与处置
8. 一处边界：不给阈值、不给公式、不作诊断

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 先命名后推理 | 混合型被读成单纯型 | 先走三步，再落名字 |
| 把同向当代偿 | 第二个原发失衡被漏掉 | 方向相反才是代偿 |
| pH 正常就收工 | 相互抵消的混合型被放过 | 补一句 pH 正常不等于无失衡 |
| 忽略急慢 | 急性报告按慢性标准读成混合型 | 先问肾代偿有没有时间启动 |
| 用幅度当判据 | 把「看起来差不多」写成「代偿适当」 | 只作定性印象并注明非阈值 |
| 只读报告不问病史 | 报告被当成结论 | 回到呕吐、利尿剂、通气、肝肾功能 |
| 被追问就报阈值 | 越出本书口径 | 统一回「本书不给值」 |

## 边界

本 Skill 只处理「一份描述 → 方向 → 原发 → 代偿 → 混合」的判读，不涉及数值、阈值、公式与临床处置。框架取自本仓库原创《hermes-病理生理学讲义》第 25 章；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
