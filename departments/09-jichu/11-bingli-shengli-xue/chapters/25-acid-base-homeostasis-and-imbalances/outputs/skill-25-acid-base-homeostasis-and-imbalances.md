# 酸碱平衡与失衡：三道防线与一条方向判据

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 不引代用底本
- 一组缓冲对同时挂在两个器官上
- 酸碱失衡能不能持续，往往不取决于它怎么开始，而取决于有没有一个维持它的环节
- 同一个 pH，两条路径，分岔点就在间隙
- 分类的名字本身就写着处理方向
- 这一句把本章与数据层的界线画死了

## 边界

- **引文只有一层，且是讲义。** 引用格式统一为`补充·hermes-病理生理学讲义·第N章·N.M`。讲义是本仓库原创的教学正文，不是任何外文教材的译本。本章不引代用底本——代用底本在这一章没有对应正文。
- **本章丢掉了什么：数值，而且是主动丢的。** 讲义第 25 章 5974 个非空白字里，数字加计量单位的命中为 0 处（`node code/main.js` 复算）。这不是疏漏：讲义明说判断代偿是否适当需要与预计代偿范围比对，而这依赖具体公式与数值，超出本章范围。本书照此收口——**方向可以教，阈值不能给。**
- **本章不给任何阈值、公式与预计代偿范围。** 四型、五组混合、五步顺序都只到方向层。凡追问降到多少算代偿、间隙多大算增大，一律回本章不给值、需另立数据层。
