# Prompt：把一句胃肠主诉反推到环节，而不是折成一句结论

## 用途

胃肠主诉只有六个词：腹胀、腹痛、腹泻、便秘、体重下降、贫血。这六个词不是六个诊断，而是六个指向环节的路标。这个模板不让你猜病名，只让你把一句主诉拆到四类功能里的某一环，并说清这一环缺什么、还能追问什么。适用于讨论课的机制推演、护理记录的症状归因、宣教材料写作前的自检。

## 使用前提

- 你面对的是一句**主诉或一段经过描述**，不是一份诊断。
- 你手边有讲义定位（`补充·hermes-病理生理学讲义·第35章·35.1` 这一级），读过对应小节。
- 你接受三条硬约束：**不产出任何数值**；**不作诊断与判定**；**不写治疗方案**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是给结论，而是把一句胃肠主诉反推到功能环节，指出这一环缺什么，并说明这段推演回答不了什么。

【输入】
原话：<一句主诉或一段经过描述，可以带病名、可以带判断>
讲义定位：<补充·hermes-病理生理学讲义·第N章·N.M>

【任务，按顺序回答，不跳步】
1. 定位段：症状提示病变在食管、胃、小肠、结肠，还是全消化道？只写段位，不定病名。
2. 归环节：四类功能（运动、分泌、消化与吸收、屏障与免疫）里，最可能是哪一环？若有两环同时可疑，写出两者的区别线索。
3. 三问：把 35.1 的三问逐个回答——推进太慢还是太快？分泌不足还是过多？面积不够还是酶不够？
4. 变量：若落在运动，指出是节律问题还是强度问题，是括约肌该开没开还是该关没关。
5. 传导：若落在吸收，按部位地图说清是哪一段（前段铁钙、回肠末端 B12 与胆盐、结肠水盐）。
6. 增益：症状负荷与可见损伤是否平行？若不平行，写下放大增益的可能来源。
7. 越界清单：把原话里的判定成分逐条指出，给出中性改写。
8. 边界：这段推演不能回答什么。

【硬约束】
- 不给任何数值、单位、正常值、参考区间、百分比。凡需数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作正常与异常判定，不作疗效断言。
- 不写治疗方案：药物、剂量、疗程、检查操作都不在本模板输出之内。
- 引讲义原文必须逐字并标「补充·hermes-病理生理学讲义·第35章·N.M」；核不到就不引。

【输出格式】
八个小标题各答一到两句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的反推（节选）

原话：「最近老是胀，吃点东西就饱，还总便秘。」讲义定位：补充·hermes-病理生理学讲义·第35章·35.3。

- **定位段**：症状偏上消化道，兼有下段排便问题，两处不必是同一处病变。
- **归环节**：运动为主，分泌次之；上段的饱胀指向排空，下段的排出困难指向括约肌协同。
- **三问**：推进偏慢（排空延迟）；分泌方向无法从这句话判断；面积与酶不像是主因。
- **变量**：节律与强度都无直接线索；关键是括约肌——该开时没开，才会出现排出困难，而不是简单的推进不足。
- **传导**：吸收线索缺如，暂不放在吸收环。
- **增益**：症状负荷可能高于可见损伤，需考虑内脏高敏感与中枢放大这一层。
- **越界清单**：「老是胀」是描述，可用；若原话说「就是消化不良」，那是判定，改为「进食后饱胀，排空可能延迟」。
- **边界**：不能判断任何人的状态，不给病因排序，不给检查与用药建议。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 主诉折成结论 | 腹胀直接写成消化不好 | 回到四类功能，指出哪一环 |
| 一个词收口两种机制 | 便秘一律当推进慢 | 分推进与括约肌两层 |
| 把刹车当故障 | 餐后排空慢就说动力差 | 认出十二指肠反馈是保护 |
| 只查酶不看介质 | 酶正常即判定分泌完好 | 回到酶量与溶媒体积的匹配 |
| 把相关当因果 | 通透性升高即当作病因 | 保留讲义那处限定 |
| 越到治疗 | 直接给抑酸或促动力 | 只写环节类别 |

## 边界

本模板训练的是「主诉 → 四步反推 → 环节判断」的结构化推演，不产生临床判断。功能类别取自本仓库原创讲义第 35 章（35.1–35.10）；数值、判定与治疗方案均不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
