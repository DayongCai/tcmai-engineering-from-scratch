# Skill：胃肠功能——四类功能、一条调控链与从症状反推环节

## 何时用

- 一句主诉里出现腹胀、腹痛、腹泻、便秘、体重下降或贫血，需要先落到环节再谈原因
- 要判断一处症状是推进问题、分泌问题、吸收问题，还是屏障问题
- 要解释为什么「推进弱」与「排不出」是两种机制
- 要把「骨瘦如柴但化验正常」一类矛盾读成环节问题，而不是体质问题
- 遇到多久算延迟、多少算偏低这类追问，需要一致的拒答口径

## 核心判据（五问）

1. **哪一段？** 食管、胃、小肠（前段／回肠末端）、结肠——段位决定可用的部位地图。
2. **哪一环？** 运动、分泌、消化与吸收、屏障与免疫；四环同链，选一环为主，另一环为次。
3. **哪个变量？** 运动看节律与强度、括约肌的开与合；分泌看酶量与溶媒体积是否匹配。
4. **哪一处地图？** 铁钙在前段、维生素 B12 与胆盐在回肠末端、水盐在结肠。
5. **增益多大？** 症状负荷与可见损伤是否平行；不平行则写放大增益，不写夸大。

## 执行步骤

```text
1. 抄原话，不改写：把要推的那句放在第一行
2. 定段位：上段、下段，或两段并存
3. 定主环：四类功能里选一环，写出理由与反证线索
4. 拆变量：运动拆节律与强度、括约肌；分泌拆酶与液体
5. 走地图：吸收类症状按部位逐段核对，按营养素逐个核，不看体重一项
6. 判增益：症状与损伤是否平行，列出放大来源
7. 中性改写：删掉判定成分，保留时间与方向线索
8. 报边界：不给值、不作诊断、不写方案
```

## 硬约束

- **不给数值、单位、正常值、参考区间、百分比。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不作诊断，不作正常与异常判定。** 四类功能只作功能类别；溢乳、腹胀、体重下降只作机制线索。
- **不写治疗方案。** 药物、剂量、疗程与检查操作属临床决策；本 Skill 只写环节类别。
- **不把相关当因果。** 通透性升高与多种疾病相关，讲义自己限定它不宜作独立病因，本 Skill 照此保留限定。
- **引文逐字。** 标`补充·hermes-病理生理学讲义·第35章·N.M`；核不到就不引。讲义是本仓库原创正文，不写成任何外文教材的译本。

## 交付物

1. 一句段位判断与一句环节判断（主环 + 次环）
2. 一张三问清单的逐条回答：快慢、多少、够不够
3. 一处变量拆解：节律／强度／括约肌，或酶／液体
4. 一张部位地图核对：按营养素逐个核，不只看体重
5. 一句增益判断与一处边界（不给值、不作诊断、不写方案）

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 主诉折成结论 | 环节丢失，只剩标签 | 回到四类功能定位 |
| 便秘一律当推进慢 | 括约肌协同失调被漏掉 | 分推进与排出两层 |
| 把保护当故障 | 餐后排空慢被读成动力差 | 认出十二指肠反馈 |
| 只查酶不看介质 | 分泌功能误判为完好 | 回酶量与溶媒体积的匹配 |
| 只看体重 | 选择性营养素缺乏被漏 | 按营养素逐个核 |
| 越到治疗 | 越过教学边界 | 只写环节类别 |

## 边界

本 Skill 只处理「主诉 → 四环定位 → 变量拆解」的结构化推演，不涉及数值、判定与临床决策。功能类别取自本仓库原创讲义第 35 章；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
