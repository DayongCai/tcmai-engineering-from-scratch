# Skill：细胞结构与功能——三条通路与两条判据

## 何时用

- 有人说「细胞损伤了」「组织坏死了」，却没有说清是哪一环先垮
- 要把一组散在体征（水肿、酸中毒、器官功能下降）串成一条机制链
- 要判断一处损伤还在可逆阶段还是已越过不可逆的界
- 要解释为什么某个药或某个毒物会影响分裂活跃的细胞（骨架动态平衡）
- 遇到「这算不算不可逆」「要不要紧」这类追问，需要一致的拒答口径

## 核心判据（四问）

1. **能量从哪儿断的？** 氧化磷酸化受阻（缺氧、线粒体损伤）／底物不足／泵与合成本身耗能过大。三条途径里只有糖酵解不需要氧，它是备用而不是替代。
2. **泵停了没有？** 钠钾泵是耗能大户，ATP 一降它先停。停后的方向固定：钠内流、钾外流、钙内流、水随钠进入。
3. **哪一处结构先坏？** 膜（离子梯度与酶的位置）／线粒体（产能与凋亡启动）／溶酶体（自身消化）／转运体（结构在而功能缺）／骨架与连接（抗牵拉与黏附）。
4. **可逆判据成立吗？** 膜完整性是否丧失，线粒体功能是否可恢复。两条判据任一成立即越过界；证据不足就写不足，不猜。

## 执行步骤

```text
1. 抄原话，不改写：把要拆的那句话原样放在第一行
2. 定起点：缺氧 / 缺血 / 物理 / 化学 / 生物 / 免疫 / 遗传 / 营养，只归类别
3. 断能量：说清 ATP 从哪一步下来，糖酵解顶上没有、代价是什么
4. 查泵：泵失活与否，离子与水的方向逐条写，不写幅度
5. 对结构：五类结构逐条比对，能对上几条写几条，缺的写「未涉及」
6. 判可逆：膜与线粒体两条判据各一句；判不了写「证据不足」
7. 报边界：不写数值，不作诊断，不给转归判断
```

## 硬约束

- **不给数值、单位、正常值、参考区间、百分比。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不作诊断，不作正常与异常判定。** 「可逆」与「不可逆」在本课程里是机制判据，不是对某个人的结论。
- **引文逐字。** 标「补充·hermes-病理生理学讲义·第3章·3.M」；核不到就不引。讲义是本仓库原创教学正文，不许写成任何外文教材的译本。
- **层次必标。** 分子与离子、细胞器、细胞、组织四个层次的表述不混写；一句话里只装一个层次的内容。
- **不作处置建议。** 恢复灌注、用药、监测项目属临床决策，本 Skill 只给机制与判据。

## 交付物

1. 一段三段拆解（能量 → 泵 → 结构），缺段如实标缺
2. 一张结构对照：膜、线粒体、溶酶体、转运体、骨架与连接，逐条对上或标未涉及
3. 一句可逆判断：两条判据各一句，或写「证据不足」
4. 一处边界：本章不给值、不作诊断，数值须另立数据层

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 病名替代机制 | 「这是缺血性损伤」当成解释 | 回到起点、能量、泵三段 |
| 跳过泵说水肿 | 链条断在中间 | 补上 ATP 下降与泵失活 |
| 把备用当替代 | 「糖酵解能供能，所以缺氧无碍」 | 糖酵解只顶一阵，代价是乳酸与酸负荷 |
| 结构清单化 | 五类结构逐条打勾就算分析完 | 要说明它们如何互相加重（钙激活酶→线粒体损伤） |
| 可逆当结论 | 「已经不可逆」 | 改为两条判据，缺证据写缺 |
| 偷给数值 | 「肿了一倍」 | 改为方向性表述，或回「本书不给值」 |

## 边界

本 Skill 只处理「一段损伤描述 → 三条通路 → 两条判据」的结构化拆解，不涉及数值、判定与临床决策。通路与判据取自《hermes-病理生理学讲义》第 3 章的表述；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
