# Prompt：把一组散在体征串成「能量—膜—钙」三条通路

## 用途

病理生理学最容易被糊过去的一句话是「缺氧导致细胞损伤」。这句话把三段过程压成了一段：能量怎么断、断了之后哪一环先垮、垮到什么程度算不可逆。这个模板不让你补病名，而是把一段体征描述按三条细胞通路拆开，并指出它停在哪一节——可逆、还是已越过膜的完整性。

适用于读病例摘要、写机制说明、做课前讨论，也适用于后面各章（坏死、凋亡、缺血-再灌注、休克）的复盘：那些章讲的都是这条链的延长线，链路不正，延长线就会歪。

## 使用前提

- 你手上是一段**机制描述或一组体征**，不是一个待确诊的病例。
- 你读过讲义本章对应小节（`补充·hermes-病理生理学讲义·第3章·3.2` 这一级），能指出每条判断的出处。
- 你接受两条硬约束：**不产出任何数值**；**不作诊断、不作正常与异常的判定**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是给结论，而是把一段关于细胞损伤的描述按三条通路拆开，并标出它停在哪一步。

【输入】
原话：<一段机制描述或一组体征>
讲义定位：<补充·hermes-病理生理学讲义·第3章·3.M>

【任务，按顺序回答，不跳步】
1. 起点：这句话说的初始条件是缺氧、缺血、毒物、免疫损伤、还是物理因素？只归类别，不写病名。
2. 能量段：ATP 是怎么下来的？指出是氧化磷酸化受阻、还是底物不足、还是线粒体本身受损；并说明糖酵解是否顶上、顶上的代价是什么。
3. 泵段：钠钾泵是否失活？若失活，写出离子与水的变化方向（钠内流、钾外流、钙内流、水随之进入），不写幅度。
4. 结构段：哪一处结构先出问题——膜、线粒体、溶酶体、转运体、还是骨架与连接？逐条对上，能对上几条写几条。
5. 可逆判据：膜完整性还在不在？线粒体功能可否恢复？两条判据各给一句判断，判不了就写「证据不足」。
6. 分岔：这条链会走向坏死、凋亡、还是仍可修复？说明判据，不作预测。
7. 边界：这段拆解不能回答什么。

【硬约束】
- 不给任何数值、单位、正常值、参考区间、百分比。凡需数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作正常与异常判定，不作预后判定，不作疗效断言。
- 引讲义原文必须逐字，并标「补充·hermes-病理生理学讲义·第3章·3.M」；核不到就不引。
- 某一段缺证据就写「未给」，不要用推测填满。

【输出格式】
七个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的拆解（节选）

原话：「组织缺血一段时间后，细胞肿了，代谢产物堆积，医生说已经不可逆了。」讲义定位：补充·hermes-病理生理学讲义·第3章·3.2。

- **起点**：缺血，属供血中断一类；比单纯缺氧多一层——废物清除与营养输送同时中断。
- **能量段**：氧化磷酸化受阻，ATP 下降；糖酵解顶上，产物转为乳酸，代价是酸负荷。
- **泵段**：钠钾泵失活，钠与水内流、钾外流、钙内流；细胞肿胀是这一段的直接后果。
- **结构段**：先对膜（离子梯度失控）、再对线粒体（通透性增高、细胞色素外漏）、再对溶酶体（酶漏出、自身消化）。三处可以同时成立。
- **可逆判据**：句中「已经不可逆」是判断，不是证据。要成立需要膜完整性丧失或线粒体功能不可恢复的迹象；原话没给，写「证据不足」。
- **分岔**：若膜仍完整，倾向可逆；若酶已漏出，倾向坏死。此处只列判据，不选边。
- **边界**：不能由此推断损伤范围、器官功能结局与处置方式；数值一律不给。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 用病名替代机制 | 「这是典型的缺血性损伤」 | 回到起点、能量、泵三段，只写过程 |
| 跳过泵直接说水肿 | 「缺血所以水肿」 | 补上 ATP 下降与泵失活这一环 |
| 把可逆当结论用 | 「已经不可逆了」 | 改为列出两条判据，缺证据就写缺 |
| 三条通路混成一条 | 把膜损伤与钙超载写成同一件事 | 分开写，再说明它们如何互相加重 |
| 偷给数值 | 「肿到原来的一倍半」 | 触发硬约束，改为方向性表述 |
| 越过机制给处置 | 「应当尽快恢复灌注」 | 处置属临床决策，模板不产出 |

## 边界

本模板训练的是「起点 → 能量 → 泵 → 结构 → 判据」的分层表达能力，不产生临床判断。通路划分取自《hermes-病理生理学讲义》第 3 章的机制表述；数值与判定不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
