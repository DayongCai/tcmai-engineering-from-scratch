# Prompt：把「喘得轻了」判成好转还是恶化

## 用途

阻塞性肺疾病的讨论里，有一句话最容易把人带错：「喘得轻了，应该好些了。」这句话把**症状的强度**当成了**气流的强度**。可事实上，声音与气流量是同向的：气流少到一定程度，哮鸣音会消失；呼吸肌累到一定程度，二氧化碳会「回到正常」。本模板不判断病情，只做一件事——把一句关于喘息的叙述拆到力学链上，并指出它落在链条的哪一段、哪个信号其实是恶化。适用于交班复述、急性发作的机制复盘，以及读本章第四、五节时练习「反常信号」的识别。

## 使用前提

- 输入是一段**床旁描述或机制叙述**，不是一份待处置的记录。
- 手边有讲义定位（`补充·hermes-病理生理学讲义·第22章·22.4` 这一级），读过对应小节。
- 接受两条硬约束：**不产出任何数值**；**不作诊断、不作分级、不作处置建议**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是判断病情轻重，而是把一句关于喘息的表述拆到力学链上，并指出其中哪些信号可能是反常的恶化信号。

【输入】
原话：<一段交班描述、机制叙述或讨论发言>
讲义定位：<补充·hermes-病理生理学讲义·第22章·N.M>

【任务，按顺序回答，不跳步】
1. 阻力还是回缩：这句话描述的是气道阻力升高（腔内、管壁、管壁外），还是弹性回缩力下降？两条轴各占多少，无法判断就写「未给」。
2. 链位置：呼气气流受限 → 气体陷闭 → 过度充气 → 呼吸功增加 → 呼吸肌疲劳 → 肺泡通气下降，这句话停在哪个箭头前后？
3. 反常信号核对：句子里有没有这三类信号——哮鸣音减弱或消失（气流不足以产生声音）、二氧化碳由低转正常或升高（过度通气撑不住了）、血氧尚可但意识变差（通气不足而氧合尚可）？逐条标「有 / 无 / 未提」。
4. 等压点：若涉及呼气费力或缩唇呼气，说明等压点是前移还是被推回，以及依据。
5. 机制类型：哮喘（炎症驱动、可逆程度）、慢阻肺（气道型与肺泡型比例）、支气管扩张（破坏与引流）——这句话更接近哪一类？不能定的写「未给」。
6. 越界清单：这句话里哪些成分是对个体的判定（诊断、分级、处置）？逐条指出，并给出只保留机制的中性改写。
7. 边界：这段拆解不能回答什么。

【硬约束】
- 不给任何数值、单位、正常值、阈值、百分比、氧浓度。凡需要数值才能回答的追问，统一回答「不给值，须另立数据层」。
- 不作诊断，不作严重度分级，不作处置建议；不写药名、剂量与装置参数。
- 引讲义原文必须逐字，并标「补充·hermes-病理生理学讲义·第22章·N.M」；核不到就不引。
- 不把讲义标成「教材」。
- 原话不足以定位时写「未给」，不用推测填满。

【输出格式】
七个小标题各答一到三句；第 3 项用「信号 → 常见误读 → 机制解释」的三列小表；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/治疗/用药依据。」
```

## 示例：一次合格的拆解（节选）

原话：「喘得比昨天轻了，哮鸣音也少了，人有点困，先不叫他。」定位：`补充·hermes-病理生理学讲义·第22章·22.4`。

- **阻力还是回缩**：哮鸣音提示气道阻力升高（管壁平滑肌与黏膜），回缩力一条未给。
- **链位置**：停在「呼吸功增加」与「呼吸肌疲劳」之间——喘得「轻」可能是做功方式变了，而不是负荷变小。
- **反常信号核对**：哮鸣音减少「有」——但原因未分：可能是痉挛缓解，也可能是气流不足以产生声音；二氧化碳方向「未提」；血氧与意识「有」——人困而血氧情况未给。
- **等压点**：未给，句子里没有呼气相的描述。
- **机制类型**：更接近哮喘急性发作（哮鸣音广泛），但慢阻肺急性加重不能排除，写「未给」。
- **越界清单**：「先不叫他」是处置判断；改成「按机制记录哮鸣音、呼吸功与意识的变化趋势」。
- **边界**：不能据此判断任何人的病情走向；不给任何阈值。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 声音当气流 | 「哮鸣音少了就是好转」 | 声音由气流产生，气流极低时声音与气流一起消失 |
| 正常值当安全 | 「二氧化碳回到正常了」 | 对过度通气者，回到正常意味着撑不住了 |
| 血氧当通气 | 「血氧好，通气没问题」 | 二氧化碳潴留可在血氧尚可时发生 |
| 桶状胸当体型 | 「他本来就胸廓大」 | 它是过度充气与膈肌低平的力学结果 |
| 病名先行 | 先定「这是哮喘」再找证据 | 先定阻力类型与链位置 |
| 偷给阈值 | 「一秒率低于某值就是阻塞」 | 触发硬约束，改为「不给值，另立数据层」 |

## 边界

本模板训练的是「叙述 → 力学链 → 反常信号」的识别能力，不产生临床判断。机制框架取自《hermes-病理生理学讲义》第 22 章；数值、分级判定与处置不在本课程范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
