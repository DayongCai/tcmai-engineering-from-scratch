# Skill：阻塞性肺疾病的力学链定位与反常信号识别

## 何时用

- 有人用「喘得轻了」「痰少了」概括病情变化，需要核对是不是反常信号
- 要在哮喘、慢阻肺、支气管扩张之间定位时，先问「阻力升高还是回缩力下降」
- 要解释某个康复动作（缩唇呼气、体位引流、哈气式咳嗽）为什么有效
- 遇到「算不算加重」「到没到某级」这类追问，需要一致的拒答口径

## 核心判据（四问）

1. **哪条轴？** 阻力升高（腔内、管壁、管壁外）还是回缩力下降。两条轴是一个正反馈环的两条边。
2. **链走到哪？** 气流受限 → 陷闭 → 过度充气 → 功增加 → 肌疲劳 → 肺泡通气下降。
3. **信号是正向还是反向？** 哮鸣音消失、二氧化碳由低转正常、血氧尚可而意识变差——三者都可能是恶化。
4. **等压点在哪？** 回缩力下降使其向小气道前移；缩唇呼气把它推回大气道。

## 执行步骤

```text
1. 抄原话，不改写
2. 定轴：阻力 / 回缩 / 两条并存 / 未给
3. 定链位：停在哪个箭头前后
4. 核反常信号：声音、二氧化碳方向、血氧与意识的组合
5. 定病类：哮喘 / 慢阻肺（气道型、肺泡型）/ 支气管扩张 / 未给
6. 中性改写：删掉判定与处置成分
7. 报边界：不给值、不分级，数值须另立数据层
```

## 硬约束

- **不给数值、单位、正常值、阈值、百分比、氧浓度。** 需要数值才能回答的追问，统一回「不给值，须另立数据层」。
- **不作诊断，不作严重度分级，不作处置建议。** 列表里的每一项在本课程里只作机制方向。
- **引文逐字**，标 `补充·hermes-病理生理学讲义·第22章·N.M`；核不到就不引，不标「教材」。
- **不把体征当结论。** 桶状胸是力学结果，杵状指是慢性改变，哮鸣音是气流的函数。
- **两类可并存。** 阻塞与限制叠加时，先看容积方向，再谈类型。

## 交付物

1. 一句轴定位：阻力 / 回缩 / 并存
2. 一句链位置：停在哪个箭头前后
3. 一张「信号 → 常见误读 → 机制解释」三列表
4. 一段中性改写：删掉判定与处置成分
5. 一处边界：不给值、不分级，数值须另立数据层

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 声音当气流 | 「哮鸣音少了是好转」 | 气流极低时声音与气流一起消失 |
| 正常值当安全 | 「二氧化碳正常了」 | 对过度通气者意味着撑不住 |
| 血氧替代通气 | 「血氧好就行」 | 二氧化碳潴留可在血氧尚可时发生 |
| 只写一条轴 | 解释不了为何恶化得这么快 | 阻力与回缩互相放大 |
| 病名先行 | 遇到不典型病例无从下手 | 先定阻力类型，再看下游 |
| 被追问就报阈值 | 越出口径 | 统一回「不给值，另立数据层」 |
