# Prompt：判断急性脑病患者「走到链的哪一步」

## 用途

急性脑病最容易被糊过去的一句话是「患者意识不好，考虑脑病」。这句话把六个可能压成一个：半暗带还在、水肿在涨、颅内压在升、移位已经开始、感染在扩散、还是继发损伤在演进。这个模板不让你补病名，而是把一段急性脑病的描述按共同通路拆开，并指出它停在哪一步、这一步上的干预点是什么。

适用于读急诊记录、写班次交班、做课前讨论，也适用于后面各章（休克、呼吸衰竭、肝性脑病）的复盘：那些章讲的都是「能量—灌注—水肿」这条链在别的器官上的版本。

## 使用前提

- 你手上是一段**急性脑病的描述**，不是一个待确诊的病例。
- 你读过讲义本章对应小节（`补充·hermes-病理生理学讲义·第44章·44.1` 这一级），能指出每条判断的出处。
- 你接受两条硬约束：**不产出任何数值**；**不作诊断、不给处置顺序**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是给结论，而是把一段急性脑病的描述按共同通路拆开，并标出它停在哪一步。

【输入】
原话：<一段急性脑病描述或一组体征>
讲义定位：<补充·hermes-病理生理学讲义·第44章·44.M>

【任务，按顺序回答，不跳步】
1. 入口：缺血、出血、感染、创伤，还是代谢性？只归类别，不写病名。
2. 能量段：能量衰竭是怎么发生的？找出泵失灵、细胞肿胀、谷氨酸释放、钙超载这一串里已经出现的那几环。
3. 水肿段：属细胞毒性、血管源性，还是间质性？依据是屏障完好与否、分布是灰质还是白质。三型可并存，说明以哪一型为主。
4. 压力段：代偿还在不在？把「容积增加而压力上升缓慢」与「陡峭段」分开；有无 Cushing 反应的成分（血压、心率、呼吸三项合看）。
5. 移位段：占位—移位—疝走到哪一步？瞳孔、眼位、运动反应各指向哪个结构。
6. 灌注段：灌注压的两个变量哪个在变？自动调节是否还成立？血压该往哪个方向看（只给方向，不给数值）。
7. 继发链：低血压、低氧、发热、高血糖、癫痫，哪几项在场？
8. 边界：这段拆解不能回答什么。

【硬约束】
- 不给任何数值、单位、正常值、参考区间、百分比。凡需数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作预后判定，不给处置顺序，不给药物与剂量。
- 引讲义原文必须逐字，并标「补充·hermes-病理生理学讲义·第44章·44.M」；核不到就不引。
- 某一段缺证据就写「未给」，不要用推测填满。

【输出格式】
八个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的拆解（节选）

原话：「患者两小时前突发右侧肢体无力，现在叫之能应但答非所问，瞳孔等大，呼吸深快。」讲义定位：补充·hermes-病理生理学讲义·第44章·44.2。

- **入口**：突发起病，归缺血或出血一类；「突发」这一档的鉴别价值最高。
- **能量段**：假设缺血，能量衰竭已启动；泵失灵与细胞肿胀是从能量到水肿的第一环，临床上表现为早期意识改变。
- **水肿段**：早期以细胞毒性水肿为主（屏障尚完好、灰质先受累）；若数小时后加重，须考虑血管源性水肿叠加。
- **压力段**：瞳孔等大提示尚未到钩回疝；代偿是否耗尽无法从描述判断，写「未给」。
- **移位段**：无瞳孔与眼位资料，写「未给」；答非所问提示皮层或语言区受累，不指向脑干。
- **灌注段**：只看方向——血压过低会扩大缺血，过高会加重水肿与出血；自动调节在严重损伤后常丧失。
- **继发链**：呼吸深快提示可能存在酸负荷或中枢性过度通气，须记录趋势。
- **边界**：不能判断病灶大小、可逆性与处置方式；数值一律不给。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 病名替代链条 | 「这是脑梗」当成分析完 | 回到入口、能量、水肿、压力四段 |
| 跳过水肿类型 | 「有水肿，脱水就好」 | 先判细胞毒性还是血管源性，方向错则干预无效 |
| 把 Cushing 反应当好消息 | 「血压高，灌注好」 | 三项合看，它是代偿近极限的晚期信号 |
| 单点值当结论 | 「颅压不高，所以没事」 | 改为趋势与多指标交叉 |
| 越界给处置 | 「应当立即降压」 | 只给方向与干预点，不给手段与数值 |
| 偷给数值 | 「瞳孔 5 毫米」 | 改为方向性表述，或回「本书不给值」 |

## 边界

本模板训练的是「入口 → 能量 → 水肿 → 压力 → 移位 → 灌注 → 继发链」的分层表达能力，不产生临床判断。通路与分型取自《hermes-病理生理学讲义》第 44 章的表述；数值与判定不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
