# Skill：脑功能急性疾病——一条链与四个干预点

## 何时用

- 有人给出「意识不好」「考虑脑病」这类笼统判断，却没说清这是哪一步
- 要在交班或记录里把急性脑病的机制链写清楚，而不是只写病名
- 要判断颅内压的代偿还在不在，以及 Cushing 反应意味着什么
- 要解释再灌注为什么不是无条件的好事
- 遇到「血压要控到多少」「多久之内必须处理」这类追问，需要一致的拒答口径

## 核心判据（四问）

1. **入口在哪？** 缺血（血栓／栓塞／低灌注）、出血（实质／蛛网膜下腔）、感染（脑膜／脑实质／脓肿）、创伤（原发／继发）。入口决定链的样子，不决定链的走法。
2. **水在哪里？** 细胞毒性（细胞内，灰质先，屏障相对完整）／血管源性（细胞外，白质先，屏障破坏）／间质性（室周，脑室液渗入）。判错类型，干预方向就错。
3. **压力到哪一段？** 代偿期（容积增加而压力上升缓慢）／陡峭段（再增极少容积即骤升）。Cushing 反应属晚期信号，不是早期警报。
4. **灌注还成立吗？** 灌注压约等于平均动脉压减颅内压；严重损伤后自动调节常丧失，故血压管理双向。趋势比单点值更重要。

## 执行步骤

```text
1. 抄原话，不改写：把要拆的那段描述原样放在第一行
2. 定入口：缺血 / 出血 / 感染 / 创伤，只归类别
3. 走能量段：泵失灵 → 细胞肿胀 → 去极化 → 谷氨酸 → 钙超载，标出已出现的那几环
4. 判水肿型：细胞内还是细胞外、灰质还是白质、屏障是否破坏；三型可并存，说明以哪型为主
5. 看压力段：代偿还是陡峭段；Cushing 三项合看
6. 查移位：占位 → 移位 → 疝，瞳孔与眼位指向哪个结构
7. 算方向：灌注压的两个变量哪个在变；只给方向，不给数值
8. 数继发链：低血压、低氧、发热、高血糖、癫痫，在场几项
```

## 硬约束

- **不给数值、单位、正常值、参考区间、百分比。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不作诊断，不给处置顺序。** 四个干预点是机制落点，不是临床路径；讲义明确不涉及具体药物与剂量，本 Skill 照此执行。
- **引文逐字。** 标「补充·hermes-病理生理学讲义·第44章·44.M」；核不到就不引。讲义是本仓库原创教学正文，不许写成任何外文教材的译本。
- **层次必标。** 离子与分子、细胞、器官、系统四个层次的表述不混写。
- **趋势优先。** 任何单点值都不构成结论；颅内压反映压力而非血流，影像反映结构而非功能，体征反映已发生的损害。

## 交付物

1. 一段八步拆解（入口 → 能量 → 水肿 → 压力 → 移位 → 灌注 → 继发链 → 边界），缺项标「未给」
2. 一句水肿分型判断与对应的干预方向（只写方向）
3. 一句压力段判断：代偿期、陡峭段，或证据不足
4. 一处边界：本章不给值、不给处置，数值须另立数据层

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 病名替代链条 | 「这是脑梗」当成解释 | 回到入口、能量、水肿、压力四段 |
| 水肿类型跳过 | 「有水肿就脱水」 | 细胞毒性水肿对脱水反应有限，方向先判 |
| 把晚期信号当前兆 | 「血压高是代偿好」 | Cushing 三项合看，属代偿近极限 |
| 再灌注无条件叫好 | 「通开就好」 | 权衡缺血范围与出血风险 |
| 单点值下结论 | 「颅压不高所以安全」 | 改为趋势与多指标交叉 |
| 偷给数值 | 「血压维持在一百二」 | 改为方向性表述，或回「本书不给值」 |

## 与相邻章节的接缝

- 第 43 章（神经系统结构与功能）：本章的六层定位图在那里立起来，本章只放大「突发」那一格。
- 第 45 章（慢性神经功能障碍）：本章的「数月以上」那一格在那里展开成变性、脱髓鞘与癫痫。
- 第 20 章（休克）：同一套「灌注压—自动调节」逻辑在全身循环上的版本。
- 与病理学的分工：病理学讲形态（梗死灶、出血灶、脑疝的压迹），本课程讲机制（为什么压力会在某个点突然失控）。

## 边界

本 Skill 只处理「一段急性脑病描述 → 共同通路 → 干预点」的结构化拆解，不涉及数值、判定与临床决策。通路与分型取自《hermes-病理生理学讲义》第 44 章的表述；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
