# Skill：男性生殖功能异常——六类归位、激素轴方向与不育三段

## 何时用

- 一段描述里出现「肿块」「不育」「勃起不好」「阴囊坠痛」「青春期不启动」这类词，需要先归位再谈原因
- 要判断一条叙述是不是从症状直接跳到了结论（跳过机制类别）
- 要区分激素「量」的不足与「作用」的不足，或要判断性腺功能减退的层次
- 要把不育的讨论从「一方的问题」拉回三段结构与双方评估
- 遇到「要不要紧」「是不是癌」这类追问，需要一套一致的拒答口径

## 核心判据（五问）

1. **哪一格？** 发育与结构／激素轴／配子生成／管道通畅性／腺体与肿瘤性／性功能。一格作起点，其余写交叉。
2. **方向朝哪？** 落在激素轴时，促性腺激素是高还是低——高指向腺体，低指向上游。只写「低」等于没分层。
3. **量还是用？** 激素水平落在区间内仍可能表型明显：受体缺陷在转导层，合成酶缺陷在转化层。
4. **哪一段？** 不育分前睾丸（指令）、睾丸（上皮）、后睾丸（输出）；三段各有一句特征，互为排除项。
5. **位置在哪？** 结构类看部位（移行带、外周带、腹膜后与腹股沟引流的差别），位置比体积更能解释症状。

## 执行步骤

```text
1. 抄原话，不改写：把要判的那句放在第一行
2. 归位：六类选一格作起点，写一句机制主线
3. 分层：激素轴写方向；不育写段位；结构写部位
4. 排除：用三段的特征句互排，不并列罗列
5. 路径：写下一步问什么类别，不写具体检查与取值
6. 中性改写：删掉判定成分，保留观察时点与体位、病程等情境
7. 报边界：不写数值，不作诊断与预后判断，不替代专科评估
```

## 硬约束

- **不给数值、单位、正常值、参考区间、百分比。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不作诊断，不作正常与异常判定。** 六类是机制类别，不是诊断类别；「雄激素低而指令高」是层次判断，不是对某个人的结论。
- **引文逐字。** 标`补充·hermes-病理生理学讲义·第31章·N.M`；核不到就不引。讲义是本仓库原创正文，不写成任何外文教材的译本。
- **不写处置。** 识别信号与转介时机属教学范围；用药、手术与操作细节不在此侧。
- **层次必标。** 同一句里不许同时装两个层面（局部形态与全身转运、激素水平与受体敏感性）。

## 交付物

1. 一段归位说明：六类里选了哪一格，为什么不是相邻那一格
2. 一句机制主线，一句段位或部位判断
3. 一张越界清单：原话里的判定成分与中性改写
4. 一条路径：下一步问什么类别、往哪个方向转介
5. 一处边界：不给值、不作诊断，数值须另立数据层

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 症状直跳结论 | 肿块先说癌、不育先说女方 | 先归位，再走该格路径 |
| 只写激素低 | 层次空缺，无法判断在腺体还是上游 | 补促性腺激素方向 |
| 水平正常就排除 | 漏掉受体与转化环节 | 记住激素异常不等于水平异常 |
| 两格并列当起点 | 评估路径不清 | 一格起点，其余写交叉 |
| 用体积替代症状 | 解释不了症状与体积不平行 | 回到位置：位置比体积更重要 |
| 单次数值定趋势 | 把数据层当类别层 | 用变化趋势判断，数值须另立来源 |

## 与相邻章节的接缝

- 上一章（男性生殖功能）：本章的六类归位，是把那一章的正常结构与激素轴当作参照系来用；缺了参照，所谓异常无从描述。
- 下一章（女性生殖功能）：同一套「轴—腺体—管道—功能」的骨架换成周期性版本，正反馈转换是两章最大的差别。
- 与性传播感染一章：本章只建立逆行扩散与炎症后遗症这条骨架，展开在那一章按共同机制统一讨论。
- 与护理实践：识别信号与转介时机可直接落到流程；判断与处置属资质与规范一侧。

## 边界

本 Skill 只处理「一句表现 → 六类归位 → 该类路径」的结构化拆解，不涉及数值、判定与临床决策。类别与机制取自本仓库原创讲义第 31 章；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
