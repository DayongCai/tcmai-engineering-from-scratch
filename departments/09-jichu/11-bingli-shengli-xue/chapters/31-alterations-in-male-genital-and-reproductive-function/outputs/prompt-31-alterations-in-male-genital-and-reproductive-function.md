# Prompt：把一句「他这儿不对」落到六个类别里的一格

## 用途

男性生殖功能异常这一章最容易出的错不是记错病名，而是**从症状直接跳到结论**：看到肿块先说「大概是癌」，看到不育先说「是女方的问题」，看到勃起不好先说「年纪到了」。这个模板不让你下结论，只让你做一件事——把一句关于表现的描述，落到六个机制类别里的一格，再走这一格自己的评估路径。适用于讨论课的病例摘要、写护理评估之前的自检，以及读后面性传播感染一章时的对照。

## 使用前提

- 你面对的是一段**表现描述**（症状、体征、检查线索），不是一份诊断。
- 你手边有讲义定位（`补充·hermes-病理生理学讲义·第31章·31.1` 这一级），读过对应小节。
- 你接受两条硬约束：**不产出任何数值**；**不作诊断、不作正常与异常判定、不作预后与疗效判断**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是给结论，而是把一段关于男性生殖系统表现的描述落到六个机制类别里的一格，并说明这一格的评估路径与边界。

【输入】
原话：<一段表现描述，可以带病名、可以带判断>
讲义定位：<补充·hermes-病理生理学讲义·第N章·N.M>

【任务，按顺序回答，不跳步】
1. 归位：这句话说的是哪一格？六个类别只能选一个作起点——发育与结构、激素轴、配子生成、管道通畅性、腺体与肿瘤性、性功能。若同时落在两格，写清起点与交叉关系，不要并列。
2. 机制：这一格的机制主线是什么？用一句机制句，不写病名堆叠。
3. 层次：若落在激素轴，写清促性腺激素的方向（高还是低），并说明这个方向指向哪一层（腺体还是上游）。
4. 段位：若落在配子生成或管道，写清是前睾丸、睾丸还是后睾丸，并给出这一段的特征句。
5. 位置：若落在结构或腺体，写清部位（例如移行带、外周带、阴囊与腹膜后引流的差别），说明位置如何解释症状。
6. 路径：这一格下一步要问什么、查什么类别？只写类别，不写具体检查项目与取值。
7. 越界清单：把原话里属于判定成分的词逐条指出（诊断、正常与异常、预后、疗效），并给出中性改写。
8. 边界：这段拆解不能回答什么。

【硬约束】
- 不给任何数值、单位、正常值、参考区间、百分比。凡需数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作正常与异常判定，不作预后判定，不作疗效断言。
- 引讲义原文必须逐字并标「补充·hermes-病理生理学讲义·第31章·N.M」；核不到就不引。
- 若原话不足以归位，直接写缺哪一层，不要用推测填满。

【输出格式】
八个小标题各答一到两句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的归位（节选）

原话：「他左边阴囊老是坠着疼，站久了更明显，估计是发炎了。」讲义定位：补充·hermes-病理生理学讲义·第31章·31.5。

- **归位**：起点是结构异常一格（局部淤血与温度环境改变），不是炎症一格；两者可交叉，但起点决定路径。
- **机制**：静脉回流受阻或瓣膜功能不全造成局部淤血、温度升高与氧化应激，损害是渐进的。
- **层次**：不涉激素轴，故不写指令方向。
- **段位**：若后续出现精液参数改变，再落到睾丸因素一段；此处不预设。
- **位置**：左侧静脉回流路径较长且角度特殊，故左侧更易受累——位置解释了好发侧。
- **路径**：下一步问病程与体位关系、问生育相关评估的类别，不问具体取值。
- **越界清单**：「估计是发炎了」是判定成分，改为「自述局部坠痛，与体位相关」。
- **边界**：不能由此判断任何人的状态，也不给严重程度。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 症状直跳结论 | 「肿块，多半是癌」 | 回到六类归位，先写机制主线 |
| 两格并列当起点 | 「既是结构又是激素」 | 选一格作起点，另一格写成交叉 |
| 把条件当病因 | 「熬夜所以不育」 | 条件写影响关系，不占病因位 |
| 用体积替代症状 | 「体积不大，问题不大」 | 回到位置：位置比体积更重要 |
| 偷给数值 | 「精子数低于某值就是不育」 | 触发硬约束，改为本书不给值 |
| 默认指向一方 | 「不育先查女方」 | 按机制写双方，双方同时评估 |

## 边界

本模板训练的是「表现 → 六类归位 → 该类路径」的表达，不产生临床判断。类别与机制取自本仓库原创讲义第 31 章（31.1–31.10）；数值与判定不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
