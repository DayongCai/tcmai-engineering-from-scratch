# Prompt：把一句「凝血不好」拆成三条线

## 用途

交班与病程记录里最常见的一句话是「凝血不好，注意出血」。这句话至少可以指三件不同的事，而三件事的观察重点与处理方向都不同。这个模板不补病名、不开化验单，而是把这句话压到三个位置上：**哪一条线（一期 / 二期 / 纤溶）、哪一端（出血 / 血栓）、形态对不对得上**。适用于病例讨论前的自检、凝血五项的组合读法训练，以及给同学解释「为什么化验提示出血却要防血栓」。

## 使用前提

- 你面对的是一句**判断或一段描述**，不是一个待处理的出血事件。
- 你手边有讲义定位（`补充·hermes-病理生理学讲义·第14章·14.5` 这一级），读过对应节。
- 你接受三条硬约束：**不产出任何数值与参考区间**；**不作诊断与分级**；**不写药物、剂量与输注阈值**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是给结论，而是把一句关于止血的说法拆到三条线上，并指出它的形态证据是否支持它的定位。

【输入】
原话：<一句判断或一段描述，可含化验方向>
讲义定位：<补充·hermes-病理生理学讲义·第N章·N.M>

【任务，按顺序回答，不跳步】
1. 定线：这句话说的是哪一条线——一期止血（血管 + 血小板）、二期凝血（因子级联）、还是纤溶？说出判断依据，而不是猜。
2. 定端：它落在出血端还是血栓端？若两端同时被提到，说明为什么可以并存（如肝病、DIC），不要强行二选一。
3. 对形态：把描述里的形态特征与线对应——皮肤黏膜、瘀点瘀斑、即刻出血、压之易止 属一期；深部血肿、关节腔、迟发出血、压之难止 属二期。对不上就写「形态与定位不符，需重看」。
4. 走机制：一期走「黏附 → 活化 → 聚集」；二期走「启动（组织因子）→ 放大（内源）→ 共同（凝血酶 → 纤维蛋白）」；纤溶走「纤溶酶原 → 纤溶酶 → 降解」。
5. 查指标组合：五项（血小板计数、凝血酶原时间、活化部分凝血活酶时间、纤维蛋白原、D-二聚体）各自管什么，缺哪项写缺哪项；指出哪一项最可能造成误读。
6. 并列排查：按血管壁、血小板数量、血小板功能、凝血因子四层逐一问「有没有证据」，没有就写没有。
7. 边界：这段话不能回答什么。

【硬约束】
- 不给任何数值、单位、参考区间、百分比、因子活性。凡需数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作分级，不给药物名称、剂量、疗程与输注阈值。
- 不用单一指标下结论：D-二聚体不定位、不定量；血小板低既可能造得少也可能耗得多。
- 引讲义原文必须逐字，并标「补充·hermes-病理生理学讲义·第N章·N.M」；核不到就不引。

【输出格式】
七个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的拆解（节选）

原话：「这个病人凝血不好，肝病晚期，注意出血。」讲义定位：补充·hermes-病理生理学讲义·第14章·14.7。

- **定线**：这句话没有指明哪一条线。肝病可同时影响三条：因子合成减少（二期）、血小板减少（一期）、纤溶亢进（第三条）。
- **定端**：只落在出血端，但机制上两端并存——促凝与抗凝物质同时减少，清场更积极。需要补一句「同时评估血栓风险」。
- **对形态**：原文没给形态。若为黏膜与消化道出血，偏二期与外源性通路；若为穿刺点渗血，偏消耗与纤溶。
- **走机制**：二期走启动与共同通路（多数因子在肝合成）；一期走数量（脾功能亢进与血小板生成减少）；纤溶走清除增强。
- **查指标组合**：五项都缺，无法定位；最可能误读的是凝血酶原时间——延长只说明外源性通路受影响，不说明只会出血。
- **并列排查**：血管壁（有无瘀点）、数量（有无血小板减少）、功能（有无尿毒症或用药）、因子（有无维生素 K 缺乏或消耗）——原文均未给，如实写缺。
- **边界**：不能判断严重程度，不能给输注或用药建议；数值一律不给。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 一句话一条线 | 「凝血不好就是因子不够」 | 三条线逐条问，缺证据写缺 |
| 只看出血端 | 肝病、DIC 只防出血 | 补上另一端，说明为何并存 |
| 形态与定位脱节 | 说是一期问题，却描述深部血肿 | 用形态反查定位，不符就重看 |
| 单指标下结论 | 「D-二聚体高，就是血栓」 | 回到不定位、不定量 |
| 低血小板一律当造得少 | 漏掉消耗性微血管病 | 问「低加上什么」：溶血、器官损害 |
| 偷给阈值 | 「低于多少就输血小板」 | 触发硬约束，改为「本书不给值」 |

## 边界

本模板训练的是「一句话 → 三条线 → 两端 → 形态对账」的拆解能力，不产生临床判断。框架取自《hermes-病理生理学讲义》第 14 章的三条线与 Virchow 三联；数值、分级与处置不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
