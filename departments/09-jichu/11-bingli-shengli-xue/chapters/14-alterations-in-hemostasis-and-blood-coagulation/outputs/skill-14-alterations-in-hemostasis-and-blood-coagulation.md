# Skill：止血与凝血——三条线定位与两端对账

## 何时用

- 交班说「凝血不好」，需要把它落成一条线、一端与一组形态证据
- 化验提示出血倾向，临床上却要考虑血栓（肝病、DIC、恶性肿瘤）
- 要用出血形态反查定位：黏膜／即刻／压之易止，还是深部／迟发／压之难止
- 要判断某个指标能不能单独用来诊断或排除血栓

## 核心判据（四问）

1. **哪一条线？** 一期止血（血管收缩 + 血小板黏附、活化、聚集）、二期凝血（因子级联 → 纤维蛋白网）、纤溶（纤溶酶原 → 纤溶酶 → 降解）。
2. **哪一端？** 出血（该堵的没堵住）还是血栓（不该堵的堵了）；两端可以并存，肝病与 DIC 是典型。
3. **形态对得上吗？** 黏膜、瘀点瘀斑、即刻出血、压之易止 → 一期；深部血肿、关节腔、迟发出血、压之难止 → 二期。对不上就重看定位。
4. **组合够吗？** 五项（血小板计数、凝血酶原时间、活化部分凝血活酶时间、纤维蛋白原、D-二聚体）各管一段；单指标不构成判断。

## 执行步骤

```text
1. 抄原话，不改写
2. 定线：一期 / 二期 / 纤溶，写依据
3. 定端：出血 / 血栓 / 并存，并存时说明四条同时改变的机制
4. 对形态：六特征对到线上，不符就标「需重看」
5. 走机制：黏附→活化→聚集；启动→放大→共同；纤溶酶原→纤溶酶
6. 查组合：五项各管什么，缺项写缺；指出最易误读的一项
7. 报边界：不给值、不分级、不写处置与阈值
```

## 硬约束

- **不给数值。** 血小板计数、凝血酶原时间、活化部分凝血活酶时间、纤维蛋白原、D-二聚体、因子活性一律不写；追问统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **单指标不下结论。** D-二聚体不定位、不定量；低血小板既可能造得少也可能耗得多；凝血酶原时间延长不等于只会出血。
- **两端可以并存。** 「出血」与「血栓」不是互斥标签，写的时候不许二选一。
- **不写药物与阈值。** 抗凝、抗血小板、维生素 K、输血与成分输注只作方向与类别。
- **引文逐字。** 标「补充·hermes-病理生理学讲义·第14章·N.M」；核不到就不引。

## 交付物

1. 一句定位：哪一条线、哪一端
2. 一张形态对账表：六特征 → 线 → 是否相符
3. 一段机制链：从起点到末端的箭头写法
4. 一份五项组合说明：各管什么、缺哪项
5. 一处边界：不给值、不单指标定论、不写处置

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 一句话一条线 | 漏掉并存的另一条 | 三条线逐条问，缺证据写缺 |
| 只防出血 | 肝病、DIC 漏掉血栓端 | 补上另一端与四条同时改变 |
| 形态与定位脱节 | 定位错了，观察重点也错了 | 用形态反查，不符就重看 |
| 单指标定论 | D-二聚体被当成血栓诊断 | 回到不定位、不定量 |
| 低血小板当造得少 | 漏掉消耗性微血管病 | 问「低加上什么」 |
| 见延长就补 | 消耗性路径上补因子可能加速消耗 | 先定机制，再谈方向 |

## 边界

本 Skill 只处理「一句判断 → 三条线 → 两端 → 形态对账」的结构化定位，不涉及诊断、分级与处置决策。框架取自《hermes-病理生理学讲义》第 14 章；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
