# Prompt：先判范式，再推损伤链

## 用途

风湿性疾病这一章的组织主线不是病名，而是两种机制的鉴别。这个模板不让你背病名表，只让你对一段关节描述做两件事：先判断它落在炎症范式还是力学-代谢范式，再把这条链推到它已经走到的环节，指出哪一环还可逆。适用于讨论课的病例推演、护理评估前的机制自查，以及把「这个关节为什么越治越僵」讲清。

## 使用前提

- 你面对的是一段**经过描述**（疼痛部位与对称性、晨僵特点、活动后变化、既往损伤与负荷史），不是一份诊断。
- 你手边有讲义定位（`补充·hermes-病理生理学讲义·第51章·51.1` 这一级），读过对应小节。
- 你接受三条硬约束：**不产出任何数值**；**不作诊断与判定**；**不承诺结局**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是给结论，而是先定范式，再把一段经过推成一条带可逆性阶梯的链，并说明这段推演回答不了什么。

【输入】
原话：<一段关节描述，可以带病名、可以带判断>
讲义定位：<补充·hermes-病理生理学讲义·第N章·N.M>

【任务，按顺序回答，不跳步】
1. 范式：炎症主导，还是力学-代谢主导？只给一个，并写出依据的两条时间线索（晨僵长短、活动后改善还是加重）。
2. 靶组织：滑膜与附着点，还是软骨与软骨下骨？这一步决定后面的破坏方式。
3. 链条：把损伤链写到当前环节为止，不超过七个箭头。
4. 可逆性：链上每一环标一个字母——可逆、部分可逆、不可逆。
5. 关节外：这种范式下要额外看哪几处（心血管、肺、眼、血液、骨），只写类别。
6. 可切断处：链上哪两三处可被干预？只写环节类别，不写药物与剂量。
7. 越界清单：把原话里的判定成分逐条指出，给出中性改写。
8. 边界：这段推演不能回答什么。

【硬约束】
- 不给任何数值、单位、正常值、参考区间、百分比。凡需数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作正常与异常判定，不作预后判定，不作疗效断言。
- 不写治疗方案：药物、剂量、疗程都不在本模板输出之内。
- 引讲义原文必须逐字并标「补充·hermes-病理生理学讲义·第51章·N.M」；核不到就不引。

【输出格式】
八个小标题各答一到两句；范式一行只许写一个答案；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的推链（节选）

原话：「早上手指僵得握不住，活动半小时才松开，两边手腕都肿。」讲义定位：补充·hermes-病理生理学讲义·第51章·51.4。

- **范式**：炎症主导。依据两条时间线索——晨僵长、活动后改善。
- **靶组织**：滑膜（对称性小关节、腕）。
- **链条**：滑膜炎 → 血管翳 → 软骨降解 → 边缘骨侵蚀 → 间隙狭窄 → 力学失衡。
- **可逆性**：可逆 → 部分可逆 → 不可逆 → 不可逆 → 不可逆 → 不可逆。
- **关节外**：心血管、肺、眼、血液、骨五处，只写类别。
- **可切断处**：炎症控制与关节保护两处，只写类别，方案不在此侧。
- **越界清单**：「握不住」是描述，可留；若原话带「就是类风湿」，改为「表现符合炎症主导型的分布与时间特点」。
- **边界**：不能判断任何人的状态，也不预测会不会出现畸形。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 病名先行 | 一开口就是某个病名 | 先答第 1 问的范式，只许一个答案 |
| 混用两套范式 | 同一段里既说侵蚀又说磨损 | 一段只用一套；对照时先写轴 |
| 只写急性期 | 停在肿胀与疼痛 | 推到链条当前环节，标可逆性 |
| 把标记当量表 | 用骨赘大小说病情轻重 | 骨赘是力学代偿标记，不是严重度量表 |
| 抗体当判决 | 抗体阳性就下结论 | 抗体是标志物：阳性加无症状不等于疾病 |
| 越到治疗 | 直接给药物与疗程 | 只写环节类别，方案不在此侧 |

## 边界

本模板训练的是「范式 → 链条 → 可逆性」的推演，不产生临床判断。机制与范式类别取自本仓库原创讲义第 51 章（51.1–51.12）；数值、判定与治疗方案均不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
