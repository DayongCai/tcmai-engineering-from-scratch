# Skill：风湿性疾病——两种范式、一条损伤链与全身代价

## 何时用

- 一段描述里出现关节肿痛、晨僵或活动后变化，需要先定范式再谈原因
- 要解释同一类关节肿为什么有的能完全消退、有的越治越僵
- 要把「关节病」读成系统性疾病，而不是只看关节
- 遇到影像与化验都干净却广泛疼痛的人，需要区分伤害性疼痛与中枢性疼痛
- 遇到「要不要紧」「会不会残」这类追问，需要一致的拒答口径

## 核心判据（五问）

1. **哪一套范式？** 炎症主导（滑膜与附着点、侵蚀性、全身表现明显、晨僵长而活动后改善），还是力学-代谢主导（软骨与软骨下骨、磨损与修复失衡、全身表现缺如、晨僵短而活动后加重）。
2. **靶组织是哪一层？** 滑膜、附着点、软骨、软骨下骨——决定破坏方式与影像方向。
3. **链走到第几环？** 滑膜炎、血管翳、软骨降解、骨侵蚀、间隙狭窄、力学失衡、畸形、功能丧失。
4. **哪一环还可逆？** 滑膜炎可逆；软骨降解仅早期部分可逆；骨侵蚀与畸形不可逆。
5. **关节外要看哪几处？** 心血管、肺、眼、血液、骨、皮肤，另加疲乏这一独立维度。

## 执行步骤

```text
1. 抄原话，不改写：把要推的那段放在第一行
2. 定范式：只给一个，写两条时间线索作依据
3. 定靶组织：滑膜与附着点 / 软骨与软骨下骨
4. 串链：不超过七个箭头，写到当前环节为止
5. 标可逆性：每一环标可逆、部分可逆或不可逆
6. 扩到关节外：列出这一范式要额外看的器官类别
7. 中性改写：删掉判定成分与评价性措辞，保留时间与部位线索
8. 报边界：不给值、不作诊断与预后判断、不写治疗方案
```

## 硬约束

- **不给数值、单位、正常值、参考区间、百分比。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不作诊断，不作正常与异常判定。** 范式是判断工具，不是诊断标准；抗体是标志物，阳性加无症状不等于疾病。
- **不写治疗方案。** 药物、剂量与疗程属临床决策；本 Skill 只写靶点与环节的类别。
- **不写分级与分期界限。** 影像分级、活动度评分、发作分期一律只写阶段与方向。
- **引文逐字。** 标`补充·hermes-病理生理学讲义·第51章·N.M`；核不到就不引。讲义是本仓库原创正文，不写成任何外文教材的译本。

## 交付物

1. 一句范式判断，附两条时间线索
2. 一句靶组织判断
3. 一条不超过七个箭头的链，每环标可逆性
4. 三到五处关节外要看的器官类别
5. 两到三处可切断的环节（只写类别）
6. 一张越界清单：判定成分的中性改写
7. 一处边界：不给值、不作诊断、不写方案

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 病名先行 | 跳过范式，检查方向错 | 先答范式，只许一个答案 |
| 混用两套范式 | 侵蚀与磨损同段出现 | 一段只用一套；对照时先写轴 |
| 把抗体当判决书 | 得出错误的确定性 | 抗体是标志物，拼图的一块 |
| 把骨赘当量表 | 用结构改变说病情轻重 | 骨赘是力学代偿标记 |
| 停在急性期 | 错过不可逆的窗口 | 推到链的当前环节，标阶梯 |
| 只看关节 | 漏掉心血管与眼部 | 全身病要覆盖关节外 |

## 与相邻章节的接缝

- 上一章（骨骼肌肉功能异常：创伤、感染与疾病）：那一章的骨与关节损伤是本章力学范式的一部分背景；本章把「磨损与修复失衡」推成一条范式。
- 皮肤系统异常与烧伤：三章共同使用「层次决定表现」这条方法；本章的层次是滑膜、附着点、软骨、骨，那两章的层次是表皮、真皮与三层带。
- 疼痛一章：中枢敏化与纤维肌痛那一节直接建立在疼痛机制上，是本章唯一一节「不在骨、关节或肌肉本身」的功能异常。
- 护理实践：评估六维与四支柱可直接落到流程；判断、治疗与告知策略属资质与规范一侧。

## 边界

本 Skill 只处理「范式 → 链条 → 可逆性」的结构化推演，不涉及数值、判定与临床决策。机制与范式类别取自本仓库原创讲义第 51 章；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
