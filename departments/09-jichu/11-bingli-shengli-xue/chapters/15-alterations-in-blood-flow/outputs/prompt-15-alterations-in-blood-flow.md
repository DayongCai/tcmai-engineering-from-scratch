# Prompt：把一条「不对劲的腿」拆成压差的方向，而不是先想病名

## 用途

血流异常这一章最容易被糊过去的一句话是「这条腿肿了」或「这个脚发凉」。这两个描述看上去都是「血液循环不好」，按本章的口径却是两个相反的方向：一个是灌不进去，一个是回不出来。方向一错，后面的动作全反——抬高还是平放、保暖还是降温、按摩还是制动，选哪个都能立刻看出代价。这个模板不让你补病名，只把一段观察逼到四个位置上：**方向、环节、条件、时间**，并说清每一个位置能说到什么程度。

适用于：床旁交接时描述一条肢体、读一份血管相关记录之前的自检、以及在后续各章（血压异常、心脏功能、休克）里反复套用——那些章讲的都是同一个压差在不同器官上的投影。

## 使用前提

- 你手上是一段**观察描述**（颜色、温度、肿胀、疼痛、脉搏），不是一个待确诊的病例。
- 你读过讲义对应节（`补充·hermes-病理生理学讲义·第15章·N.M` 这一级），知道该节讲的是哪一层。
- 你接受两条硬约束：**不产出任何数值**（腿围、温度、时长一律不给）；**不作诊断、不作分级、不写处置医嘱**。

## Prompt 正文（复制即用）

```text
你是病理生理学助教。任务不是给结论，而是把一段肢体观察拆成「方向—环节—条件—时间」四层，并指出哪一层还缺证据。

【输入】
观察描述：<颜色 / 温度 / 肿胀 / 疼痛与体位的关系 / 脉搏 / 毛细血管充盈，允许带患者原话>
讲义定位：<补充·hermes-病理生理学讲义·第15章·N.M>

【任务，按顺序回答，不跳步】
1. 方向：这段话更像压差变小（灌不进）还是回流受阻（回不去）？只写方向与理由，不写病名。若两侧都有迹象，说明各自依据哪一条观察。
2. 环节：沿四个环节归位——灌注压差、血管阻力（含管腔与外部压迫）、血液黏度、回流与淋巴。指出证据落在哪一环，缺的写「未给」。
3. 条件：列出决定后果的四个条件里的哪几项已有信息——阻塞部位与程度、侧支状态、组织耐受性、是否双重血供。缺项如实标缺，不补猜。
4. 时间：是刚发生还是长期存在？急性与慢性的后果方向不同（急性以肿胀发绀为主，慢性以纤维化与色素沉着为主）。原话没给时间就写「未给」。
5. 危险位点：这段话里有没有指向「危险不在症状所在处」的线索（例如腿肿背后的肺栓塞征兆）？有就写出来，没有就写「未见」。
6. 缺什么：为了把方向定死，还差哪一项观察？只列观察项，不列检查项目与操作。
7. 边界：这段拆解不能回答什么。

【硬约束】
- 不给任何数值、单位、腿围、温度读数、时间窗时长、百分比。凡需数值才能回答的追问，统一回答：「本书不给值」。
- 不作诊断，不作分级，不写药物、剂量、热敷或抬高之类的处置指令；只写「方向对应哪一类动作」，并说明依据来自讲义的哪一节。
- 引讲义原文必须逐字，并标「补充·hermes-病理生理学讲义·第15章·N.M」；核不到就不引。
- 不把「充血」「淤血」「缺血」三个词互换使用：它们的分界是毛细血管内压力的方向。

【输出格式】
七个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/处置依据。」
```

## 示例：一次合格的拆解（节选）

观察描述：「右小腿比左侧粗，皮肤发亮发紫，摸着比另一侧热，站起来更胀，走路不痛。」讲义定位：补充·hermes-病理生理学讲义·第15章·15.3。

- **方向**：压差没有变小，是回流受阻。依据三条：发紫而非苍白、皮温升高而非发凉、下垂加重而非抬高加重。
- **环节**：落在回流与淋巴这一环——静脉回流受阻使毛细血管内压力升高，液体外渗形成水肿。灌注压差与黏度两环「未给」。
- **条件**：四条里只有「部位」有信息（单侧、小腿）；侧支状态、组织耐受性、是否双重血供三项都缺。
- **时间**：原话只说「站起来更胀」，没有给起病时间，按口径写「未给」。
- **危险位点**：有。讲义明写深静脉血栓的真正危险不是腿肿，而是脱落造成肺动脉栓塞，且相当一部分可以没有明显症状——所以这段描述里「走路不痛」不构成安全信号。
- **缺什么**：还差对侧对比的温度与颜色、有无呼吸困难或胸痛、有无近期制动或手术史这三类观察。
- **边界**：不能由此判断任何人的状态，也不能给出抬高、压迫或活动方面的指令；数值一律不给。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 先给病名 | 「这是深静脉血栓」 | 回到方向与环节，病名属诊断层，不写 |
| 方向反了 | 见肿就抬高、见凉就热敷 | 先判压差方向，再谈动作类别 |
| 只写「循环不好」 | 把缺血与淤血并成一句 | 两者分界在毛细血管内压力，必须选一侧 |
| 拿症状位置当危险位置 | 「腿不痛就没事」 | 主动找远处征兆，症状位置不等于危险位置 |
| 偷给数值 | 「腿围差三厘米以上算异常」 | 触发硬约束，改为「本书不给值」 |
| 把代偿当获益 | 「红细胞多了携氧更好」 | 补上黏度与心脏负荷这一侧的代价 |

## 边界

本模板训练的是「一条肢体 → 方向 → 环节 → 条件 → 时间」的分层表达能力，不产生临床判断。机制框架取自《hermes-病理生理学讲义》第 15 章；数值、分级与处置不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
