# Skill：血流异常——压差方向、四套调节与时间窗

## 何时用

- 有人用「循环不好」「血供差」「有点肿」这类说法把一段灌注异常糊过去了，需要拆开
- 要在同一份材料上区分缺血与淤血，并且知道两者的体征方向为什么相反
- 要判断一个梗死范围的说法有没有交代侧支状态与组织耐受性
- 要解释「腿不痛却可能很危险」这类症状位置与危险位置不一致的情形
- 遇到「要不要抬高」「能不能热敷」这类动作层面的追问，需要一套一致的拒答与转述口径

## 核心判据（四问）

1. **压差往哪边偏？** 压差变小、供血不足 → 缺血，主要问题是缺氧与营养不足；回流受阻、毛细血管内压力升高 → 淤血，主要问题是水肿与出血。这一条决定颜色、温度、肿胀的方向。
2. **落在哪个环节？** 灌注压差、血管阻力（管腔狭窄、外部压迫、痉挛）、血液黏度、回流与淋巴。四个环节各自对应不同的病类，不能互相替代。
3. **四个条件齐了吗？** 阻塞部位与程度、侧支状态、组织耐受性、是否双重血供。梗死范围是这四条的函数，不是病名的属性。
4. **过没过阈值？** 自动调节的上下界、组织耐受性排序、时间窗。三个阈值都是方向性的临界条件，不是数值。

## 执行步骤

```text
1. 抄观察，不改写：颜色 / 温度 / 肿胀 / 疼痛与体位 / 脉搏 / 毛细血管充盈，原样列
2. 定方向：压差小（苍白发凉干瘪）还是回流受阻（发绀肿胀温度可升高）
3. 归环节：灌注压差 / 阻力 / 黏度 / 回流与淋巴，四选一并给证据
4. 查条件：四条逐一核对，缺项标缺，不补猜
5. 排时序：急性（肿胀发绀为主）还是慢性（纤维化、色素沉着、溃疡）
6. 找远处危险：症状所在处不等于危险所在处（腿肿背后的肺栓塞征兆）
7. 报边界：不给值、不分级、不写处置指令
```

## 硬约束

- **不给数值、单位、正常值、参考区间、百分比。** 需要数值才能回答的追问，统一回「本书不给值」。
- **不作诊断，不作分级。** 缺血四级（功能 / 可逆 / 梗死 / 坏疽）是机制类别，不是分级标准。
- **引文逐字。** 标「补充·hermes-病理生理学讲义·第15章·N.M」；核不到就不引。
- **三个词不互换。** 充血、淤血、缺血各自对应不同的压力方向与不同的后果，混用会让体征推不出来。
- **代偿与代价同源。** 红细胞增多、侧支开放、自动调节三处都同时写着好处与坏处，不能只写一半。

## 交付物

1. 一句方向判定（缺血 / 淤血 / 两者并存），附两到三条观察依据
2. 一张环节定位（四环节中落在哪一环，其余标「未给」）
3. 一张条件清单（四条齐了哪几项，缺哪几项）
4. 一句时序判断（急性 / 慢性 / 未给）
5. 一处远处危险提示（有则写，无则写「未见」）
6. 一句边界：不给值、不作诊断，数值须另立数据层

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 见肿就抬高 | 若是动脉缺血，抬高进一步降低灌注压 | 先定方向，再谈动作类别 |
| 见凉就热敷 | 提高组织代谢需求，加重缺氧 | 缺血侧只保暖，不给热源 |
| 只写「某动脉闭塞」 | 漏掉侧支状态，梗死范围无从解释 | 四条条件一起写 |
| 把腿肿当评估终点 | 漏掉肺动脉栓塞的远处征兆 | 症状位置不等于危险位置 |
| 把代偿当纯获益 | 忽略黏度上升带来的血栓与心脏负荷 | 代偿与代价并列写出 |
| 被追问就报时间窗 | 越出本书口径，且数值无来源 | 统一回「本书不给值」 |

## 与相邻章节的接缝

- 上一章（止血与凝血异常）：本章的血栓形成在那一侧被拆成凝血与抗凝的失衡；两章共用「红色血栓 / 白色血栓」这组词，但关注的后果不同。
- 下一章（血压异常）：本章的乘式（血压 ≈ 心输出量 × 外周阻力）在那里被展开成短期、中期、长期三层调节，本章只用它的一个方向。
- 第 17 章（心脏功能）：淤血的最常见起点是泵功能下降，本章只写到「回流受阻」这一层，泵的那一层留给第 17 章。
- 第 20 章（休克）：全身性低灌注在本章是缺血的第四类原因，在那一章成为主线。

## 边界

本 Skill 只处理「一段灌注异常 → 方向 → 环节 → 条件 → 时间」的结构化拆解，不涉及数值、分级与临床处置。机制框架取自《hermes-病理生理学讲义》第 15 章；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
