# Skill：肾内疾病——三问定位、漏与堵、沉默项

## 何时用

- 面对一组尿液、水肿、血压或影像线索，需要先给它们归位，而不是先给一个病名
- 要在「肾炎综合征」与「肾病综合征」之间做机制层面的分辨（同为水肿，来源相反）
- 要判断一句「肿得厉害」「肌酐不高」是不是越过了观察层
- 要检查一份病例摘要有没有漏掉两类沉默的恶化

## 核心判据（四问）

1. **哪一段结构？** 肾小球（滤过屏障，表现是蛋白尿、血尿、管型）／肾小管间质（重吸收与浓缩，表现是多尿、夜尿、比重低、电解质乱）／肾血管（灌注，表现是高血压、功能骤降、影像异常）。部位不决定机制，只缩小机制的范围。
2. **哪一条机制？** 免疫沉积、炎症破坏、缺血、梗阻、代谢损伤、药物性。同一部位只选一条主机制，第二条单列。
3. **急还是慢？** 看起病方式与可逆性，不看时间长短的数值。急的链条是细胞损伤与功能抑制、结构多完整；慢的链条是硬化与纤维化、不可逆。
4. **漏还是堵？** 漏 → 蛋白外漏、胶体渗透压下降、血管内缺水；堵 → 滤过面积减少、钠水排出减少、血管内水多。同是水肿，观察重点相反。

## 执行步骤

```text
1. 抄线索：把尿检、体征、影像的原始条目逐条列在左边，不改写
2. 归部位：每条线索挂到肾小球 / 小管间质 / 血管；挂不上的写「部位未定」并注明缺哪项
3. 定性质：在该部位上选一条主机制；两条以上分列，不合并
4. 定急缓：写「起病方式 + 可逆性」，不写时限数值
5. 判漏堵：给出容量方向（血管内缺水 / 血管内水多），据此改观察重点
6. 查沉默：肾功能下降而症状轻微？水肿掩盖血栓或感染？逐条列出该补的观察
7. 中性改写：删掉病名、轻重、预后、疗效四类判定，只留部位、机制、观察项
8. 报边界：不给值，不诊断，不写处置
```

## 硬约束

- **不给数值、单位、正常值、参考区间、百分比。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不作诊断，不作轻重与预后判定。** 三问是分类流程，不是诊断流程；八条观察线索是提示，不是判据。
- **引文逐字。** 标「补充·hermes-病理生理学讲义·第27章·27.M」；核不到就不引，不得标成「教材」。
- **一套轴只用一套。** 部位、病因、机制、急缓四套轴各自成立，一段话里不混。
- **不写处置。** 利尿、补白蛋白、转换酶抑制剂、导尿频次、替代治疗时机，只写机制与观察方向。

## 交付物

1. 一张线索归位表：线索 → 部位 → 机制 → 急缓
2. 一句容量方向判断：血管内缺水，还是血管内水多
3. 一份沉默项清单：两类沉默各有哪些观察要补
4. 一段中性改写：删掉四类判定后的版本
5. 一处边界：不给值、不诊断，数值须另立数据层

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 用病名替代部位 | 「这是肾病综合征」当成描述 | 回到部位层，病名留到机制清楚之后 |
| 漏堵不分 | 两种水肿用同一套观察 | 先写容量方向，再定观察重点 |
| 蛋白尿只当结果 | 漏掉它推动硬化这一层 | 补「标志 + 动力」两层 |
| 用肌酐筛小管间质病 | 漏诊电解质与酸碱紊乱 | 补浓缩功能、电解质、酸碱三项 |
| 单侧梗阻当无事 | 对侧代偿掩盖，延误 | 记住单侧可无症状，主动评估尿量 |
| 把水肿当全部 | 血栓被掩盖 | 沉默项与体重、出入量并列观察 |

## 边界

本 Skill 只处理「一组线索 → 部位 / 机制 / 急缓 → 中性表述」的结构化拆解，不涉及数值、判定与临床决策。分类与机制取自《hermes-病理生理学讲义》第 27 章；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
