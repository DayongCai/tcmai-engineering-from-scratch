# Prompt：把一例「肾不好」拆成部位、性质、急缓三问

## 用途

肾内疾病最容易糊过去的一句话是「这个病人肾不好」。这句话把三件事压成了一件：哪一段结构受损、是哪种机制在起作用、走到了急还是慢。本章的模板不让你补病名，而是把这句话逼到三个位置上，并检查每一层的表述有没有越界。

适用场合：写病例摘要之前的自检、读尿常规与影像报告时给表现归位、以及在「肾炎还是肾病」这类追问面前组织一次有依据的回答。

## 使用前提

- 你面对的是**一段状态描述或一组表现线索**，不是一份待确诊的病历。
- 你读过讲义第 27 章的对应小节，能给出 `补充·hermes-病理生理学讲义·第27章·27.M` 这一级的定位。
- 你接受两条硬约束：**不产出任何数值**；**不作诊断、不作正常与异常的判定**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是给病名，而是把一段「肾不好」的表述拆成三层，并指出哪一层已经越界。

【输入】
原话：<一段状态描述或一组表现线索>
讲义定位：<补充·hermes-病理生理学讲义·第27章·27.M>

【任务，按顺序回答，不跳步】
1. 部位层：这条线索指向肾小球、肾小管间质，还是肾血管？只写部位，不写病名。
   若线索不足以定部位，写「部位未定」，并说明缺哪一项（尿蛋白成分 / 红细胞管型 / 浓缩功能 / 影像）。
2. 性质层：在该部位上，机制属免疫沉积、炎症破坏、缺血、梗阻、代谢损伤，还是药物性？
   同一部位只选一条主机制；有第二条就单列，不合并成一句。
3. 急缓层：是数小时到数日的方向，还是数月到数年的方向？依据写「起病方式 + 可逆性」，不写具体时限数值。
4. 方向核对：这条线索属于「漏」还是「堵」？
   漏 → 蛋白外漏、胶体渗透压下降、血管内缺水；堵 → 滤过面积减少、钠水排出减少、血管内水多。
5. 沉默项清单：本例有没有两类沉默——肾功能下降而症状轻微、水肿掩盖血栓或感染？
   有就逐条列出该补的观察项，没有就写「未见」。
6. 越界清单：原话里哪些成分是对个体的判定（诊断、轻重、预后、疗效）？逐条摘出，给中性改写。
7. 边界：这段拆解不能回答什么。

【硬约束】
- 不给任何数值、单位、正常值、参考区间、百分比。凡需数值才能回答的追问，统一回：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作正常与异常判定，不作预后判定，不写处置方案与药物。
- 引讲义原文必须逐字，并标「补充·hermes-病理生理学讲义·第27章·27.M」；核不到就不引。
- 部位未定就写未定，不要用病名把空缺填满。

【输出格式】
七个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的拆解（节选）

原话：「患者眼睑浮肿、尿里有泡沫，估计是肾病，肿得厉害说明病重。」讲义定位：补充·hermes-病理生理学讲义·第27章·27.4。

- **部位层**：泡沫尿加眼睑与下垂部位水肿，指向肾小球；若要坐实，还需尿蛋白成分，缺这一项时写「部位倾向肾小球，待成分确认」。
- **性质层**：主机制按「滤过屏障孔径与电荷屏障失效」记，属免疫介导一类；不写具体病名。
- **急缓层**：描述里没有起病方式，只能写「急缓未定」，不猜。
- **方向核对**：属「漏」——蛋白外漏、胶体渗透压下降、水分外渗，所以是血管内缺水那一支，与「堵」那一支的观察重点相反。
- **沉默项清单**：有。肾病综合征的高凝状态常被水肿掩盖，须补单侧下肢肿胀、腰痛、血尿加重三项观察；不能因为「肿得厉害」就只盯水肿。
- **越界清单**：「估计是肾病」是对个体的病名判定，「肿得厉害说明病重」是轻重判定，两处都要摘掉，改成状态与观察项的陈述。
- **边界**：不能由此判断任何人的病情走向，也不给任何定量与处置。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 用病名替代部位 | 「这是肾病综合征」 | 回到部位层：肾小球 / 小管间质 / 血管 |
| 把「漏」与「堵」合并 | 「都是水肿，机制差不多」 | 分列两支，写出各自的容量方向 |
| 把蛋白尿只当结果 | 「蛋白尿是损伤的表现，治不治都一样」 | 补第二层：蛋白尿同时是推动硬化的动力 |
| 用单一指标筛小管间质病 | 「肌酐不高，所以没事」 | 补浓缩功能、电解质与酸碱三项 |
| 水肿遮住血栓 | 「先等消肿再说」 | 把沉默项单列，与体重、出入量并列 |
| 偷给数值 | 「蛋白尿超过某个量就是大量」 | 触发硬约束，改为「本书不给值」 |

## 边界

本模板训练的是「一句话 → 三层 → 中性表述」的拆解能力，不产生临床判断。分类与机制取自《hermes-病理生理学讲义》第 27 章；数值、处置与个体判定不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
