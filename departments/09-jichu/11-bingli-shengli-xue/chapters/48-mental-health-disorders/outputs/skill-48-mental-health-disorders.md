# Skill：精神心理健康障碍——五维描述、机制层级与去污名化的写法

## 何时用

- 一段描述里出现情绪、睡眠、兴趣或行为的改变，需要先描述再谈解释
- 要判断一句话是在描述状态还是在给定身份
- 要在护理记录、交班或宣教材料里写心理相关内容，又不想写成标签
- 遇到「是不是抑郁」「要不要吃药」这类追问，需要一致的拒答与转介口径
- 要把一个急性起病、日轻夜重的表现先按躯体问题查一遍

## 核心判据（五问）

1. **哪几维？** 症状群、时间、功能、危险性、资源——五维缺项就是后面要补的评估位，尤其别跳过功能。
2. **哪一层？** 分子与递质、环路、系统（应激轴、免疫、节律）。机制只能写到层，不能越到个人。
3. **是不是先排除过？** 急性起病、日轻夜重、注意受损、代谢异常、近期用药变动——有则先按躯体查。
4. **这句话落在人还是落在行为？** 描述行为与体验，用状态与类别，不用身份。
5. **此刻往哪一层干预？** 安全与环境、关系与心理教育、结构化心理干预、功能与康复、药物类别、专科转介。

## 执行步骤

```text
1. 抄原话，不改写：把要拆的那段放在第一行
2. 拆五维：症状群五项、时间、功能四项、危险性、资源，缺的写「未给」
3. 判层级：把可谈机制的部分写到分子、环路或系统层，不越界
4. 先排除：器质性线索逐条问，有则把排除写在最前
5. 查表述：逐句看是描述行为还是给定身份，标出越界处
6. 中性改写：删掉标签与评价，保留行为、时间、功能与观察时点
7. 定层级：按风险、功能损害领域、能否承受深谈三个问题选干预层
8. 报边界：不给值、不作诊断、不写药名与方案、不承诺结果
```

## 硬约束

- **不给数值、单位、量表分值与切点、百分比。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不作诊断，不作正常与异常判定。** 五个维度是描述工具，不是判定标准。
- **不写药名、剂量与方案。** 只写按递质系统分类的干预层级，处方与监测属具备资质者。
- **不身份化、不评价。** 写「近两周入睡困难、上班需家人催促」，不写「他是个抑郁的人」。
- **不把机制当借口，也不当宿命。** 阈值与缓冲、上行与下行两条路径，都指向可干预的资源侧。
- **不预测危险。** 只描述当下风险与所需支持；风险不明或升高时，安全与环境层永远第一。
- **引文逐字。** 标「补充·hermes-病理生理学讲义·第48章·N.M」；核不到就不引。

## 交付物

1. 一段五维描述（症状群、时间、功能、危险性、资源），缺项如实标缺
2. 一段机制层说明，标明落在分子、环路还是系统层
3. 一张排除清单：器质性线索逐条问过没有
4. 一段中性改写：只写行为与体验，加时间与功能
5. 一句干预层级判断，附三个判断问题的答案
6. 一处边界：不给值、不作诊断、不写方案、不承诺结果

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 标签代替描述 | 制造污名，且无法指导下一步 | 改为行为与体验，补时间与功能 |
| 机制还原 | 「都是脑子的问题」取消情境 | 机制写到层，情境与意义另写 |
| 跳过功能维度 | 无法判断是否需要干预 | 补四项功能受损程度 |
| 筛查当诊断 | 把概率当事实 | 筛查只提示是否需要进一步评估 |
| 先解释后排除 | 漏掉可逆的躯体原因 | 急性起病、日轻夜重先按躯体查 |
| 劝解当治疗 | 延误转介 | 只写层级位置与转介方向 |

## 边界

本 Skill 只处理「一段状态描述 → 五维 → 机制层 → 中性改写 → 干预层级」的结构化拆解，不涉及诊断、处方与危机处置决策。维度框架取自本仓库原创讲义第 48 章；任何涉及个体的评估与处置须由具备资质的人员依现行规范与机构制度作出。若涉及自伤或他伤风险，请立即联系当地急救与危机干预资源。
