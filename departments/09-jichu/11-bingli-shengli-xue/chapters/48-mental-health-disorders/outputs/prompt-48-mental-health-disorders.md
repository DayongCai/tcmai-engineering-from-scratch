# Prompt：把一段「他最近状态不好」拆成五维描述，而不是一个标签

## 用途

这一章最容易滑成两件事：给一个标签，或给一句劝解。这个模板两样都不给，只做一件事——把一段关于某人状态的表述拆成五组不依赖标签的维度，再指出哪几句已经越到身份层，最后改写为只写行为与体验的版本。适用于讨论课的状态描述、护理记录的措辞自检、以及接到一份转介材料时先确认它是在描述还是在定性。

## 使用前提

- 你面对的是一段**状态描述**（行为、体验、时间、功能），不是一个待判定的病例。
- 你手边有讲义定位（`补充·hermes-病理生理学讲义·第48章·48.2` 这一级），读过对应小节。
- 你接受三条硬约束：**不产出任何数值与量表分值**；**不作诊断与判定**；**不作身份化与评价性表述**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是判断当事人属于哪一类，而是把一段状态描述拆成五组维度，指出越界处，并给出只写行为与体验的改写。

【输入】
原话：<一段状态描述，可以带标签、可以带评价>
讲义定位：<补充·hermes-病理生理学讲义·第48章·N.M>

【任务，按顺序回答，不跳步】
1. 症状群：情绪基调、认知、知觉、意志与行为、生理五项各写一句；缺项写「未给」。
2. 时间：起病形式（骤然、亚急性、隐袭）、病程形态（单次、反复、持续、日间波动）、与生活事件的时间关系。
3. 功能：工作或学习、自我照护、家庭角色、人际关系四项的实际受损程度。
4. 危险性：有无自伤、他伤、自我忽视的线索。此项只作风险评估，不作诊断。
5. 资源：支持网络、经济与居住、既往应对方式、求助意愿。
6. 机制层：把可以谈到机制的部分写在该层——应激轴、睡眠与节律、环路、炎症，任一项都要说明它对应的是哪一层，不越到个人层。
7. 先排除：有无急性起病、日轻夜重、注意受损、代谢异常、近期用药变动等器质性线索？有则先写排除方向。
8. 越界清单：原话里哪些成分是身份化或评价性表述？逐条指出并改为行为与体验的写法。
9. 边界：这段拆解不能回答什么。

【硬约束】
- 不给任何数值、单位、量表分值与切点、百分比。凡需数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作正常与异常判定，不作预后判定，不作疗效断言。
- 不写药名、剂量与方案；只写按递质系统分类的干预层级。
- 只用状态与类别，不用身份；只描述行为与体验，不描述人。
- 引讲义原文必须逐字并标「补充·hermes-病理生理学讲义·第48章·N.M」；核不到就不引。

【输出格式】
九个小标题各答一到两句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的拆解（节选）

原话：「他是个抑郁的人，最近什么都不想干，估计是想太多。」讲义定位：补充·hermes-病理生理学讲义·第48章·48.2。

- **症状群**：情绪基调未给（只有评价，没有具体描述）；认知与知觉未给；意志与行为给了「不想干」一项；生理项未给。
- **时间**：未给。这是最该补的一格——起病形式与病程形态决定机制落在哪一段。
- **功能**：未给。按讲义的说法，这是判断是否需要干预最实用的维度，缺它无法定方向。
- **危险性**：未给，须补问。
- **资源**：未给（支持网络、经济、求助意愿全部空白）。
- **机制层**：只能说到「动力与奖赏回路方向可能参与」，不能推到个人层的原因。
- **先排除**：无明显器质性线索；若出现日轻夜重或注意受损，先把排除方向写在最前。
- **越界清单**：「他是个抑郁的人」是身份化表述，改为「近两周兴趣减退、上班需家人催促」；「估计是想太多」是归因与评价，删除。
- **边界**：不能判断任何人的状态，也不能替代评估与转介。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 用标签代替描述 | 「他是个抑郁的人」 | 改写为行为与体验，加时间与功能 |
| 用机制当借口 | 「都是脑子的问题，不用问情境」 | 机制只写到层，情境与意义另写 |
| 跳过功能维度 | 只写情绪词汇 | 补工作、自照护、家庭、人际四项 |
| 把筛查当诊断 | 「分值到了就是」 | 筛查只提示是否需要进一步评估 |
| 先解释后排除 | 直接给心理标签 | 先写器质性线索的排除方向 |
| 劝解当干预 | 「想开点就好了」 | 只写层级位置与转介方向 |

## 边界

本模板训练的是「一段状态描述 → 五维 → 机制层 → 中性改写」的结构化拆解，不产生临床判断。维度框架取自本仓库原创讲义第 48 章；数值、量表分值与用药不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
