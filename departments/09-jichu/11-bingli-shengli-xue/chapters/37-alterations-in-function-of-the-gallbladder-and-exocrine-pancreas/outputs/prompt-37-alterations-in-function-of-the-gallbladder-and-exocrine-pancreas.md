# Prompt：把一个胆胰症状读成「产生—排放—反流」三环节

## 用途

胆囊与胰腺的症状极少，却各自能对上五六个病：右上腹痛、黄疸、脂肪泻、体重下降。这个模板不让你猜病名，只让你把一句主诉放到三环节线上，再用位置与时限把它读成可比较的类别。适用于讨论课的机制推演、护理记录的归因、宣教材料写作前的自检。

## 使用前提

- 你面对的是一句**主诉或一段经过描述**，不是一份诊断。
- 你手边有讲义定位（`补充·hermes-病理生理学讲义·第37章·37.2` 这一级），读过对应小节。
- 你接受三条硬约束：**不产出任何数值**；**不作诊断与判定**；**不写治疗方案**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是给结论，而是把一个胆胰症状放到三环节线上，指出位置与时限，并说明这段推演回答不了什么。

【输入】
原话：<一句主诉或一段经过描述，可以带病名、可以带判断>
讲义定位：<补充·hermes-病理生理学讲义·第N章·N.M>

【任务，按顺序回答，不跳步】
1. 归系统：症状偏胆道、胰腺，还是两处都需考虑？只写系统，不定病名。
2. 定环节：产生、排放、反流三环节里落在哪一环？若在排放，指明是生成不足、排出受阻还是淤滞。
3. 定位置：若涉及结石，写在胆囊内、胆囊颈、胆总管，还是壶腹部？位置决定结局，逐处说一句。
4. 判时限：梗阻是间歇还是持续？间歇可缓解，持续则进入炎症阶段——这一步只看时间，不看强度。
5. 三道保险：若涉及胰腺，按三道保险逐一核对——酶原形式、细胞内隔离、腔内冲洗与抑制剂，指出哪一道失守。
6. 分后果：若已发生炎症，按四条线列：循环、钙、呼吸、凝血与心肌，各写一句方向性判断。
7. 越界清单：把原话里的判定成分逐条指出，给出中性改写。
8. 边界：这段推演不能回答什么。

【硬约束】
- 不给任何数值、单位、正常值、参考区间、百分比。凡需数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作正常与异常判定，不作疗效断言。
- 不写治疗方案：药物、剂量、疗程、内镜与手术都不在本模板输出之内。
- 引讲义原文必须逐字并标「补充·hermes-病理生理学讲义·第37章·N.M」；核不到就不引。

【输出格式】
八个小标题各答一到两句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的读法（节选）

原话：「吃完油腻的饭右上腹就痛，疼一阵会过去，说是胆结石。」讲义定位：补充·hermes-病理生理学讲义·第37章·37.4。

- **归系统**：胆道为主，未见胰腺线索。
- **定环节**：排放环节——结石暂时嵌顿，胆囊强烈收缩。
- **定位置**：按胆囊颈或胆管嵌顿处理；若在胆囊内可长期无症状，位置一变结局即变。
- **判时限**：疼痛能自行缓解，说明嵌顿是间歇性的；持续不缓解才进入炎症阶段。这一步只看时间。
- **三道保险**：不涉及胰腺，跳过；若出现向后背放射的持续痛，再回这一步。
- **分后果**：暂不涉及四条全身线，但需留一条观察：梗阻若合并感染，随时可能转为全身问题。
- **越界清单**：「说是胆结石」是转述的判断，改为「进食油腻后右上腹绞痛，可自行缓解」。
- **边界**：不能判断任何人的状态，不给病因排序，不给检查与用药建议。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 按痛感排轻重 | 痛得厉害就当作重 | 时限与位置的权重高于强度 |
| 结石当一种病 | 只说有结石 | 位置决定四种结局 |
| 只谈比例不谈三要素 | 过饱和即断结石 | 过饱和、成核、动力低下三者同时 |
| 把淤积当梗阻 | 一见淤积就找梗阻 | 分有梗阻与无梗阻两类 |
| 只看酶判轻重 | 酶高即重症 | 器官功能才是分水岭 |
| 越到治疗 | 直接给解痉或手术 | 只写机制与类别 |

## 边界

本模板训练的是「症状 → 三环节 → 位置与时限」的结构化推演，不产生临床判断。机制类别取自本仓库原创讲义第 37 章（37.1–37.11）；数值、判定与治疗方案均不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
