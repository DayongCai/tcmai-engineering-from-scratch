# Skill：胆囊与外分泌胰腺功能异常——三环节通则、三道保险与位置定位

## 何时用

- 一句主诉里出现右上腹痛、黄疸、脂肪泻或体重下降，需要先归环节再谈原因
- 要解释同一块结石为什么对应四种不同的病
- 要判断一处胆道梗阻该按时间紧迫处理，还是可以观察
- 要说明酶升高与病情轻重为什么不同步
- 遇到黄疸多少算高、酶高多少算重的追问，需要一致的拒答口径

## 核心判据（五问）

1. **哪一环？** 产生、排放、反流——凡有分泌、有储存、有排放的系统都适用这条线。
2. **哪一处位置？** 胆囊内、胆囊颈、胆总管、壶腹部；位置决定结局，不决定成分。
3. **是间歇还是持续？** 嵌顿能自行缓解则疼痛消退；持续则进入炎症阶段。时限优先于强度。
4. **三道保险哪一道失守？** 酶原形式、细胞内隔离、腔内冲洗与抑制剂；三道同时突破才在腺内自身消化。
5. **器官功能受累了吗？** 酶反映腺泡损伤的量，器官功能反映炎症放大的后果，两者不可互相替代。

## 执行步骤

```text
1. 抄原话，不改写：把要读的那句放在第一行
2. 定环节：产生、排放、反流里选一环，写明理由
3. 定位置：结石类按四处落位，逐处写一句结局
4. 判时限：间歇可缓解／持续进入炎症，只按时间不按强度
5. 核保险：涉及胰腺时逐道核对，指出失守的那一道
6. 列后果：循环、钙、呼吸、凝血与心肌四条线各一句
7. 中性改写：删掉判定成分，保留时间与位置线索
8. 报边界：不给值、不作诊断、不写方案
```

## 硬约束

- **不给数值、单位、正常值、参考区间、百分比。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不作诊断，不作正常与异常判定。** 三要素、三档黄疸、四条后果线都只作机制类别。
- **不写治疗方案。** 药物、剂量、疗程、内镜与手术属临床决策；本 Skill 只写机制与分类。
- **不把类别对照当诊断规则。** 结石多有痛且波动、胰头肿瘤多无痛且进行，这是类别对照，不能反过来用于判断任何个体。

## 交付物

1. 一句环节判断与一句位置判断
2. 一句时限判断（间歇／持续）及其后果方向
3. 一张三道保险核对表（涉及胰腺时）
4. 四条后果线的方向性判断（循环、钙、呼吸、凝血与心肌）
5. 一处边界（不给值、不作诊断、不写方案）

## 典型误用

| 误用 | 表现 | 纠正 |
|---|---|---|
| 按痛感排轻重 | 剧痛即重症 | 时限与位置的权重更高 |
| 结石当一种病 | 只说有结石 | 位置决定四种结局 |
| 过饱和即断结石 | 只看第一要素 | 三要素同时才成石 |
| 淤积一律找梗阻 | 忽略转运体障碍 | 分有梗阻与无梗阻 |
| 只看酶判轻重 | 酶高即重症 | 器官功能是分水岭 |
| 越到治疗 | 直接给解痉或手术 | 只写机制与类别 |
