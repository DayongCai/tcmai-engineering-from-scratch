# Prompt：把一处周期变化读成轴上的一个断点

## 用途

女性生殖功能这一章的机制，最后都要落在一个动作上：拿一处变化，判断它断在轴的哪一段。这一段可以很具体——卵泡池、两细胞流水线、反馈的方向、内膜的容受性、管道的通畅。这个模板不让你给病名，只让你给出断点、机制与它会长在哪一段表现上。适用于讨论课的机制推演、写护理评估之前的自检，以及读后面女性生殖功能异常一章时的对照。

## 使用前提

- 你面对的是一段**变化描述**（周期、经量、痛感、备孕经过），不是一份诊断。
- 你手边有讲义定位（`补充·hermes-病理生理学讲义·第32章·32.5` 这一级），读过对应小节。
- 你接受两条硬约束：**不产出任何数值**；**不作诊断、不作正常与异常判定**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是给结论，而是把一处周期或生殖相关的变化，读成这条轴上的一个断点，并说明这个断点会长出哪一段表现。

【输入】
原话：<一段变化描述，可以带病名、可以带判断>
讲义定位：<补充·hermes-病理生理学讲义·第N章·N.M>

【任务，按顺序回答，不跳步】
1. 断点：这句话的变化最可能断在哪一段？五段只能选一个作起点——卵泡池、两细胞流水线、反馈方向、内膜容受、管道通畅。若跨两段，写清起点与传导关系。
2. 机制：这一段的机制主线是什么？用一句机制句，不堆病名。
3. 方向：若断在反馈，写清是负反馈失位还是正反馈未转换；若断在两细胞，写清是原料不足还是转化不足。
4. 时序：这段变化与周期时相、与卵泡发育的跨周期时间差有没有关系？
5. 表现：按机制推出它会长在哪一段表现上（周期长度、经量、痛感、着床窗口），只写类别。
6. 该问什么：下一步问哪一类信息（时相、用药史、既往操作史），只写类别，不写具体检查与取值。
7. 越界清单：把原话里的判定成分逐条指出（诊断、正常与异常、预后、疗效），给出中性改写。
8. 边界：这段推演不能回答什么。

【硬约束】
- 不给任何数值、单位、正常值、参考区间、百分比。凡需数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作正常与异常判定，不作预后判定，不作疗效断言。
- 引讲义原文必须逐字并标「补充·hermes-病理生理学讲义·第32章·N.M」；核不到就不引。
- 若原话不足以定位断点，直接写缺哪一层，不要用推测填满。

【输出格式】
八个小标题各答一到两句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的定位（节选）

原话：「她这两个月月经来得勤，量也不稳，人还胖了些。」讲义定位：补充·hermes-病理生理学讲义·第32章·32.5。

- **断点**：起点在反馈方向这一段（正反馈未转换成排卵），卵巢与内膜是被动跟随。
- **机制**：排卵不能发生则无黄体、无孕酮，雌激素持续作用使内膜增殖而脱落不规律。
- **方向**：属正反馈未转换，而不是负反馈失位；负反馈失位会表现为促性腺激素升高。
- **时序**：卵泡发育跨数个周期，因此两个月的观察不足以判断储备，只说明当前这一段。
- **表现**：周期长度与经量的规律性丢失，属类别层描述，不落到具体天数。
- **该问什么**：问时相记录、用药史与体重变化的方向，不问单次数值。
- **越界清单**：「人还胖了些」是观察，可以留；「月经不调」若被当作诊断使用，改为「周期不规律」。
- **边界**：不能判断任何人的状态，也不给严重程度。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 现象当机制 | 「月经不调」直接当结论 | 先定断点，再写机制主句 |
| 只看升降 | 「雌激素低所以周期乱」 | 同时问幅度与时程，方向由两者组合决定 |
| 跳过时序 | 用单周期观察判断储备 | 回到跨周期的时间差 |
| 把内膜当原因 | 「内膜薄所以不着床」 | 容受性看比例与时程，不看厚度 |
| 偷给数值 | 「周期超过某天算异常」 | 触发硬约束，改为本书不给值 |
| 越到处置 | 直接给用药建议 | 处置不在此侧，交回规范与资质 |

## 边界

本模板训练的是「变化 → 断点 → 机制 → 该段表现」的推演，不产生临床判断。结构与机制取自本仓库原创讲义第 32 章（32.1–32.11）；数值与判定不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
