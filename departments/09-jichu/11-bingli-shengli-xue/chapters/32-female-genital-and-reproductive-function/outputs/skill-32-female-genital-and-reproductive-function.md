# Skill：女性生殖功能——断点定位、两细胞模型与正反馈开关

## 何时用

- 一段描述里出现周期不规律、经量改变、备孕不顺、泌乳或围绝经期相关变化，需要先定位断点再谈原因
- 要判断一处变化断在卵泡池、两细胞流水线、反馈方向、内膜容受还是管道通畅
- 要解释为什么同一种雌激素在两个时相上起相反作用
- 要把妊娠期的一处变化读成代偿，而不是病理现象
- 遇到「这样算不算异常」这类追问，需要一套一致的拒答口径

## 核心判据（五问）

1. **材料在后还是动力学在后？** 卵泡池只减不增，闭锁是主动过程；任何与年龄相关的衰退都从这里推。
2. **原料还是转化？** 卵泡膜细胞产雄激素、颗粒细胞芳香化；原料不足与转化不足的表型方向相反。
3. **幅度与时程各是什么？** 同一激素低水平短时程抑制、高水平持续兴奋；只看升降必错。
4. **读出器说什么？** 内膜是激素周期的读出器；容受性看雌孕激素比例与时程，不看厚度。
5. **是代偿还是病理？** 妊娠期变化的幅度接近病理，但机制上是可逆的代偿；先问为什么，再谈变了什么。

## 执行步骤

```text
1. 抄原话，不改写：把要判的那句放在第一行
2. 定位断点：五段选一段作起点，写传导关系
3. 写机制句：一句主句（原料/转化、抑制/兴奋、建设/改造），不堆病名
4. 校时序：与周期时相、与卵泡跨周期发育的时间差对齐
5. 推表现：只写类别（周期长度、经量、容受窗口），不写取值
6. 中性改写：删掉判定成分，保留时相与用药史、操作史这类情境
7. 报边界：不给值、不作诊断与预后判断
```

## 硬约束

- **不给数值、单位、正常值、参考区间、百分比。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不作诊断，不作正常与异常判定。** 生理与病理在本章只作状态类别；围绝经期、初潮后无排卵周期写成阶段特征，不写成结论。
- **引文逐字。** 标`补充·hermes-病理生理学讲义·第32章·N.M`；核不到就不引。讲义是本仓库原创正文，不写成任何外文教材的译本。
- **不写处置。** 机制与适应属教学范围；用药、手术与操作细节不在此侧。
- **层次必标。** 同一句里不许同时装两个层面（激素水平与受体敏感性、内膜厚度与容受性）。

## 交付物

1. 一句断点判断：五段里选了哪一段，为什么不是相邻那段
2. 一句机制主句，一句时序校准
3. 一张越界清单：原话里的判定成分与中性改写
4. 一条路径：下一步问哪一类信息
5. 一处边界：不给值、不作诊断，数值须另立数据层

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 现象当机制 | 周期不规律直接当结论 | 先定断点，再写机制主句 |
| 只看升降 | 解释不了正反馈转换 | 同时问幅度与时程 |
| 把闭锁当耗损 | 丢掉可干预的环节 | 记住闭锁是主动过程 |
| 内膜厚度替代容受性 | 解释不了着床失败 | 看比例与时程 |
| 单周期判断储备 | 结论悬空 | 回到跨周期的时间差 |
| 把代偿读成病理 | 妊娠期变化被误判 | 先问为什么，再谈变了什么 |

## 边界

本 Skill 只处理「一处变化 → 断点 → 机制 → 该段表现」的推演，不涉及数值、判定与临床决策。结构与机制取自本仓库原创讲义第 32 章；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
