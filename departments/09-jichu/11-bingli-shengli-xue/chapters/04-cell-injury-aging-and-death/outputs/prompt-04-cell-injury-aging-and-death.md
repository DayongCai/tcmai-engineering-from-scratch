# Prompt：把「细胞坏死了」拆成三问——过没过线、带不带炎症、是不是救回来那一下

## 用途

「细胞损伤」「组织坏死」这类说法在讨论里出现得太顺，顺到没人追问三件事：这条损伤过没过不可逆的线、越线之后是带炎症走还是安静走、以及这次加重是不是恢复灌注本身带来的。三问的顺序不能换——先判可逆，再分死法，最后才谈时间点。

适用于读损伤描述、写机制说明、复盘再灌注后的病情变化，也适用于后面各章（休克、心梗、移植、脓毒症）的机制讨论：那些章节讲的是这条线的延长线。

## 使用前提

- 你手上是一段**损伤描述或一组指标变化**，不是一个待确诊的病例。
- 你读过讲义本章对应小节（`补充·hermes-病理生理学讲义·第4章·4.4` 这一级）。
- 你接受两条硬约束：**不产出任何数值**；**不作诊断、不作正常与异常的判定**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是给结论，而是把一段损伤描述按三问拆开，并指出每一问的证据够不够。

【输入】
原话：<一段损伤描述或指标变化>
讲义定位：<补充·hermes-病理生理学讲义·第4章·4.M>

【任务，按顺序回答，不跳步】
1. 因素段：初始因素是缺氧、缺血、物理、化学、生物、免疫、遗传还是营养？写出它的主要作用环节，不写病名。
2. 过线判断：给出两条判据各自的状态——膜完整性在不在、线粒体功能可否恢复。每一条写明依据来自原话的哪一句；原话没给的写「证据不足」。
3. 死法分岔：若已越线，判断走向带不带炎症：膜破裂、内容物释放则归坏死一侧；膜完整、形成凋亡小体则归凋亡一侧；若为程序性且带炎症，写出属于哪一类（坏死性凋亡 / 焦亡 / 铁死亡 / 自噬依赖）。
4. 时间点：这次变化发生在缺血期、恢复灌注期，还是之后？若在恢复灌注期，逐条检查自由基爆发、钙超载、微血管无复流三条机制是否在原话里有对应。
5. 修复预期：按细胞类型判断再生能力（持续分裂型 / 稳定型 / 永久型），并说明修复结局是再生还是瘢痕；瘢痕的代价写一句。
6. 越界清单：原话里哪些成分是对个体的判定（诊断、预后、疗效）？逐条指出并给中性改写。
7. 边界：这段拆解不能回答什么。

【硬约束】
- 不给任何数值、单位、正常值、参考区间、百分比。需要数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作正常与异常判定，不作预后判定，不作疗效断言。
- 引讲义原文必须逐字，并标「补充·hermes-病理生理学讲义·第4章·4.M」；核不到就不引。
- 证据不足就写不足，不用推测填满；把推测写成判断是最常见的越界。

【输出格式】
七个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的拆解（节选）

原话：「缺血一段时间后细胞肿胀、酶升高，恢复血流后心功能反而更差，说明已经坏死了。」讲义定位：补充·hermes-病理生理学讲义·第4章·4.4。

- **因素段**：缺血，主要作用环节是 ATP 生成不足；它比单纯缺氧多断两样——废物清除与营养输送。
- **过线判断**：膜完整性——酶升高提示有酶漏出，可作为膜受损的线索，但不足以说明整块组织都不可逆；线粒体功能——原话未给，写「证据不足」。两条判据都没被坐实，所以「已经坏死了」这句判断证据不足。
- **死法分岔**：若后续出现膜破裂与炎症反应，倾向坏死一侧；若为膜完整、凋亡小体形成，则属凋亡。原话未给形态信息，写「待形态证据」。
- **时间点**：变化发生在恢复灌注期。三条机制逐条对：自由基爆发（原话无对应）、钙超载（无）、微血管无复流（「功能反而更差」与之相容，但需灌注层面的证据）。结论是只有第三条有相容性，不足以定论。
- **修复预期**：心肌属永久型细胞，再生能力几乎为零，结局是瘢痕替代；代价是收缩功能永久损失。
- **越界清单**：「说明已经坏死了」是诊断性判断，改为「现有材料不足以判断是否越线，需补充膜与线粒体层面的证据」。
- **边界**：不能由此推断损伤范围、功能结局与处置方式；数值一律不给。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 跳过判据直接定性 | 「已经不可逆」 | 两条判据各写一句，缺证据写缺 |
| 死法当评价 | 「凋亡是好的死法」 | 只写带不带炎症，不评价 |
| 把再灌注当原发病恶化 | 「病情加重了」 | 分时间点，逐条对三条机制 |
| 酶升高当结论 | 「酶高所以坏死」 | 酶漏出只说明膜受损，推断每一步都要标 |
| 忽略细胞类型 | 「会长回来的」 | 按持续分裂型 / 稳定型 / 永久型判再生能力 |
| 偷给数值 | 「酶高了好几倍」 | 改为方向性表述，或回「本书不给值」 |

## 边界

本模板训练的是「过线—分岔—时间点」的三问表达，不产生临床判断。判据与机制取自《hermes-病理生理学讲义》第 4 章的表述；数值与判定不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
