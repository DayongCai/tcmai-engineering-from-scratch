# Skill：细胞损伤、衰老与死亡——一条线、两种死法、一个例外

## 何时用

- 有人用「坏死了」「不可逆了」这类词跳过判断过程
- 要区分这次加重是原发病进展，还是恢复灌注本身带来的损伤
- 要说明为什么同样是细胞死亡，一种引起炎症、一种不引起
- 要判断一处损伤后组织会再生还是留瘢痕
- 遇到「这算不算不可逆」「还能不能修复」这类追问，需要一致的拒答口径

## 核心判据（四问）

1. **过没过线？** 膜完整性在不在；线粒体功能可否恢复。两条判据分别对应修复所需的「容器」与「能量」，任一失守即越过界。
2. **带不带炎症？** 膜破裂、内容物释放则归坏死；膜完整、形成凋亡小体则归凋亡。程序性但带炎症的一类（坏死性凋亡、焦亡、铁死亡、自噬依赖）另算。
3. **什么时间点？** 缺血期、恢复灌注期、还是之后。恢复灌注期要逐条对自由基爆发、钙超载、微血管无复流三条机制。
4. **修复靠什么？** 细胞类型决定再生能力：持续分裂型可再生，稳定型损伤时被激活，永久型基本不再分裂，只能由瘢痕替代。

## 执行步骤

```text
1. 抄原话，不改写：把要拆的那句话原样放在第一行
2. 定因素：缺氧 / 缺血 / 物理 / 化学 / 生物 / 免疫 / 遗传 / 营养，写出主要作用环节
3. 判过线：膜与线粒体两条各一句，标明依据来自哪一句原话或写「证据不足」
4. 分死法：先看膜破没破，再看是否程序性；带炎症的归入程序性坏死一类
5. 定时间：把变化放回缺血期 / 灌注期 / 之后，逐条对三条再灌注机制
6. 判修复：按细胞类型定再生能力，写明结局是再生还是瘢痕，并说一句瘢痕的代价
7. 报边界：不写数值，不作诊断，不给转归判断
```

## 硬约束

- **不给数值、单位、正常值、参考区间、百分比。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不作诊断，不作正常与异常判定。** 「可逆」与「不可逆」是机制判据，不是对某个人的结论；酶升高、细胞肿胀这类观察项只说明机制上的可能位置。
- **引文逐字。** 标「补充·hermes-病理生理学讲义·第4章·4.M」；核不到就不引。讲义是本仓库原创教学正文，不许写成任何外文教材的译本。
- **推断要标步。** 指标升高 → 酶漏出 → 膜受损 → 该处不可逆，是四步，不是一步；每一步都要单独给依据。
- **不评价死法。** 坏死与凋亡没有高低之分；把凋亡写成「好的死法」是把机制判断偷换成评价。

## 交付物

1. 一段三问拆解（过线 → 死法 → 时间点），缺证据处标「证据不足」
2. 一张两条判据的状态表：膜完整性、线粒体功能，各附依据或标缺
3. 一句修复预期：细胞类型 + 再生能力 + 结局（再生 / 瘢痕）
4. 一处边界：本书不给值、不作诊断，数值须另立数据层

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 越过判据直接定性 | 「已经不可逆」当解释用 | 两条判据各写一句，缺证据写缺 |
| 死法当评价 | 「凋亡是好事」 | 只写带不带炎症 |
| 把再灌注读成原发病恶化 | 机制错位，讨论失焦 | 分时间点，逐条对三条机制 |
| 忽略细胞类型 | 「会长回来」 | 按三类更新策略判再生能力 |
| 把代偿当纯粹的好事 | 化生、纤维化被写成恢复 | 补一句代价：原功能回不来 |
| 偷给数值 | 「肿了一倍」 | 改为方向性表述或回「本书不给值」 |

## 边界

本 Skill 只处理「一段损伤描述 → 三问 → 判据表」的结构化拆解，不涉及数值、判定与临床决策。判据与机制取自《hermes-病理生理学讲义》第 4 章的表述；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
