# Prompt：把一对激素读成一个位置

## 用途

内分泌这一章的机制最后都落在一对关系上：靶腺激素与它的促激素是否相称。这个模板不让你背腺体名与激素名，只让你把一段描述读成一个位置——靶腺、垂体还是下丘脑，并说明这一读法能推到哪一步、不能推到哪一步。适用于讨论课的机制推演、护理评估的结构化整理，以及读化验与病程记录时确认每一句话落在轴的哪一层。

## 使用前提

- 你面对的是一段**描述**（症状、化验方向、用药史），不是一份诊断。
- 你手边有讲义定位（`补充·hermes-病理生理学讲义·第39章·39.4` 这一级），读过对应小节。
- 你接受三条硬约束：**不产出任何数值**；**不作诊断与判定**；**不给药物与剂量**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是给结论，而是把一段描述读成一个轴上的位置，并说明这一读法回答不了什么。

【输入】
原话：<一段描述，可以带病名、可以带判断>
讲义定位：<补充·hermes-病理生理学讲义·第N章·N.M>

【任务，按顺序回答，不跳步】
1. 定轴：这段描述涉及哪一条三级轴——甲状腺、肾上腺、性腺、生长轴，还是不止一条？
2. 读相对关系：靶腺激素与促激素在方向上是大致反向、同向偏低，还是同向偏高？只写方向，不写数值。
3. 落位置：按三级轴的读法，病变更可能在上位、靶腺，还是终末效应一侧（抵抗）？
4. 查干扰：是否存在结合蛋白改变、采血时点、脉冲与节律、外源激素这四类干扰？逐条说有没有。
5. 找终末效应：哪个指标或体征反映的是功能的终末结果，而不是激素水平本身？
6. 越界清单：把原话里的判定成分逐条指出，给出中性改写。
7. 边界：这段推演不能回答什么。

【硬约束】
- 不给任何数值、单位、正常值、参考区间、百分比。凡需数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作正常与异常判定，不作预后判定，不作疗效断言。
- 不写治疗方案：药物、剂量、疗程都不在本模板输出之内。
- 引讲义原文必须逐字并标「补充·hermes-病理生理学讲义·第39章·N.M」；核不到就不引。

【输出格式】
七个小标题各答一到两句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的读法（节选）

原话：「他查出来甲状腺激素偏高，但人怕冷、乏力、反应慢。」讲义定位：补充·hermes-病理生理学讲义·第39章·39.8。

- **定轴**：甲状腺轴，单轴。
- **相对关系**：靶腺激素偏高；促激素的方向决定后面两步，必须先问清是同向偏高还是反向偏低。
- **落位置**：若促激素同向偏高或不相称，先考虑抵抗而不是亢进；若促激素反向偏低，才是靶腺自主分泌。
- **查干扰**：先排除结合蛋白升高（妊娠、雌激素、慢性肝病）与采血时点两类干扰，再看节律。
- **终末效应**：怕冷、乏力、反应慢属功能不足一侧，与激素偏高方向相反——这正是抵抗的典型组合。
- **越界清单**：「偏高」是化验方向，不是功能判断，改写为「测定值偏于参考方向，功能状态另评估」。
- **边界**：不能判断任何个体的状态，也不给治疗方案。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 箭头即结论 | 「高了就是亢进」 | 先读一对激素的相对关系 |
| 只看终末激素 | 不看促激素就定位 | 三级轴要成对读 |
| 忽略结合蛋白 | 把总浓度当功能 | 回到 39.6 的四种组合 |
| 忽略时点 | 单点采血下结论 | 节律与脉冲先于水平异常 |
| 越过治疗 | 直接给替代方案 | 只写机制类别，方案不在此侧 |
| 混用两个词 | 受体上下调说成激素上下调 | 措辞回到受体一层 |

## 边界

本模板训练的是「一对激素 → 一个位置 → 一条边界」的推演，不产生临床判断。机制类别取自本仓库原创讲义第 39 章（39.1–39.11）；数值、判定与治疗方案均不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
