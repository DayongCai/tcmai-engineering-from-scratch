# Skill：内分泌生理与下丘脑-垂体调控机制——两层整合、三级轴与五种读法

## 何时用

- 一段描述里出现「激素偏高／偏低」这类化验方向，需要先读成结构再谈意义
- 要判断一处异常在靶腺、垂体还是下丘脑，需要一条可推的次序
- 遇到「化验正常但有症状」，需要按五类情形逐条排查
- 要解释为什么长期用激素的人不能骤停，或为什么补了终末激素仍不见好
- 遇到「多少算正常」这类追问，需要一致的拒答口径

## 核心判据（五问）

1. **哪条轴？** 甲状腺（TRH–TSH–激素）、肾上腺（CRH–ACTH–皮质醇）、性腺（GnRH–LH/FSH–性激素）、生长轴（GHRH/生长抑素–GH–IGF-1）。
2. **一对激素的方向是否相称？** 反向（一升一降）说明反馈在工作；同向变动说明环路某处被打破。
3. **病变在哪一层？** 靶腺、垂体、下丘脑——越靠上，被牵连的环节越多。
4. **有没有四类干扰？** 结合蛋白、采血时点、脉冲与节律、外源激素。
5. **终末效应怎么说？** 代谢指标、生长速度、骨转换、生殖功能——比上位激素更接近功能状态。

```text
1. 抄原话，不改写：把要读的那段放在第一行
2. 定轴：一条还是多条，多轴受累本身就是定位线索
3. 读方向：只写升、降、相称、不相称，不写数值
4. 落层：靶腺 / 垂体 / 下丘脑 / 终末效应一侧（抵抗）
5. 排干扰：结合蛋白、时点、节律脉冲、外源激素，逐条过
6. 找终末物：指出哪一个指标反映的是结果而非水平
7. 中性改写：删掉判定成分，保留方向与时间线索
8. 报边界：不给值、不作诊断与预后判断、不写治疗方案
```

## 硬约束

- **不给数值、单位、正常值、参考区间、百分比。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不作诊断，不作正常与异常判定。** 激素水平只作机制描述；五类情形是读法的分类，不是给个体定性。
- **不写治疗方案。** 药物、剂量、疗程属临床决策；本 Skill 只写机制类别与评估层次。
- **不把抵抗读成亢进。** 激素高而终末效应不足时，先看抵抗；这是本章最常被跨过的一步。
- **引文逐字。** 标`补充·hermes-病理生理学讲义·第39章·N.M`；核不到就不引。讲义是本仓库原创正文，不写成任何外文教材的译本。

## 交付物

1. 一句定轴与一句方向判断（相称／不相称）
2. 一句落层判断：靶腺、垂体、下丘脑，或终末效应一侧
3. 一张四类干扰的排查表，逐条写有／无
4. 一处终末效应物的指认
5. 一张越界清单：判定成分的中性改写
6. 一处边界：不给值、不作诊断、不写方案

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 箭头即结论 | 把抵抗读成亢进 | 先读一对激素的相对关系 |
| 只看终末激素 | 定位错层 | 三级轴成对读 |
| 把总浓度当功能 | 妊娠与肝病被误判 | 回到结合蛋白四种组合 |
| 单点采血下结论 | 节律信息被抹平 | 时点与节律是结论的一部分 |
| 补了终末激素就放心 | 掩盖上位病变进展 | 多轴受累须一并评估 |
| 越过治疗 | 越过教学边界 | 只写机制类别 |
