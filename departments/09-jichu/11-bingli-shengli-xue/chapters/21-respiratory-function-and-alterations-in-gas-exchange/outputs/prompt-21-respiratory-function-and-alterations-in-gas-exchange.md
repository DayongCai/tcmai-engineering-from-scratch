# Prompt：把「血氧低」定位到四个环节上

## 用途

「血氧低，加点氧吧」是呼吸讨论里最常见的一步跳越：从表现直接跳到手段，中间跳过了机制定位。本模板不判断病情，只做一件事——把一句关于低氧的叙述拆到四个环节（通气、弥散、灌流、匹配）上，并给出氧与二氧化碳的方向组合，说明它指向哪一类机制。适用于查房前的机制复述、护理评估的结构化记录，以及读本章第八、九节时练习「用方向组合代替单点数值」。

## 使用前提

- 输入是一段**机制叙述或床旁描述**，不是一份待处置的报告。
- 手边有讲义定位（`补充·hermes-病理生理学讲义·第21章·21.8` 这一级），读过对应小节。
- 接受两条硬约束：**不产出任何数值**；**不作诊断、不作处置建议**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是决定要不要给氧，而是把一句关于低氧的表述定位到四个环节上，并说清它属于哪一类机制。

【输入】
原话：<一段床旁描述、机制叙述或讨论发言>
讲义定位：<补充·hermes-病理生理学讲义·第21章·N.M>

【任务，按顺序回答，不跳步】
1. 方向组合：这句话给的是「低氧伴二氧化碳升高（同向）」还是「低氧而二氧化碳不高或偏低（反向）」？两者是两条推理路径的入口。
2. 环节归位：通气、弥散、灌流、匹配，哪一环最可能先失衡？排出优先顺序并给理由，不合并成一句。
3. 机制类别：在吸入气氧分压降低、肺泡通气不足、弥散障碍、V/Q 失衡、分流五类中，这句话能支持哪几类？哪几类被这句话排除？
4. V/Q 方向：若涉及匹配，是升高（死腔样）还是降低（分流样）？有没有「完全无通气而仍有灌流」的真性分流成分？
5. 吸氧反应预期：按机制推测吸氧后改善是明显还是有限，并说明理由（只讲方向，不给数值）。
6. 越界清单：这句话里哪些成分是对个体的判定（诊断、分级、处置）？逐条指出，并给出只保留机制的中性改写。
7. 边界：这段拆解不能回答什么。

【硬约束】
- 不给任何数值、单位、正常值、阈值、百分比、氧浓度数值。凡需要数值才能回答的追问，统一回答「不给值，须另立数据层」。
- 不作诊断，不作呼吸衰竭分型判定，不作处置建议；不写药名与装置参数。
- 引讲义原文必须逐字，并标「补充·hermes-病理生理学讲义·第21章·N.M」；核不到就不引。
- 不把讲义标成「教材」。
- 原话不足以定位时写「未给」，不用推测填满。

【输出格式】
七个小标题各答一到三句；第 2 项用一个「环节 → 支持证据 → 反证」的三列小表；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/治疗/用药依据。」
```

## 示例：一次合格的拆解（节选）

原话：「他喘得厉害，血氧低，听诊有哮鸣音，先给氧看看。」定位：`补充·hermes-病理生理学讲义·第21章·21.8`。

- **方向组合**：只给了氧的方向，没给二氧化碳的方向——这是本次拆解最大的缺口。缺了它就无法区分「进气不足」与「交换/匹配障碍」。
- **环节归位**：哮鸣音提示气道阻力升高（通气环节），喘得厉害提示呼吸功增加；弥散与灌流两环没有证据。
- **机制类别**：可支持「肺泡通气不足」一类；V/Q 失衡也说得通（气道阻塞造成分流样效应）；其余三类未被支持，也未被排除。
- **V/Q 方向**：气道阻塞倾向「降低」方向，但「真性分流」无法从这句话判断，写「未给」。
- **吸氧反应预期**：若以 V/Q 失衡为主，改善应明显；若有真性分流成分，改善有限。原话不足以判断，只能给出两条分支。
- **越界清单**：「先给氧看看」是处置判断；改成「按机制记录氧与二氧化碳的方向组合及呼吸功的变化」。
- **边界**：不能据此判断任何人的状态；不给任何阈值。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 表现跳手段 | 「低氧就加氧」 | 先定位环节，再谈手段（泵 / 气 / 路） |
| 只看氧不看二氧化碳 | 只记「血氧低」 | 强制补上二氧化碳的方向 |
| 把弥散当常见原因 | 「低氧多半是弥散障碍」 | V/Q 失衡才是最常见的机制 |
| 混淆 V/Q 两个方向 | 「V/Q 异常」一句带过 | 分清升高（死腔样）与降低（分流样） |
| 用发绀当判据 | 「嘴唇不紫，不像低氧」 | 发绀受血红蛋白、色素与光照影响，不作可靠指标 |
| 偷给阈值 | 「低于某值要吸氧」 | 触发硬约束，改为「不给值，另立数据层」 |

## 边界

本模板训练的是「表现 → 四环节 → 机制类别」的定位能力，不产生临床判断。机制框架取自《hermes-病理生理学讲义》第 21 章；数值、分型判定与处置不在本课程范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
