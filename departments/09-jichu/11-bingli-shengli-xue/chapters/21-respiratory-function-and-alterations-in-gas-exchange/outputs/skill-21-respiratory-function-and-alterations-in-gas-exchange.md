# Skill：低氧血症的四环节定位与方向组合判据

## 何时用

- 有人用「血氧低」一句话概括呼吸问题，需要把它还原到环节上
- 要在五类低氧机制之间排序时，先看二氧化碳的方向，而不是先看氧的数值
- 要判断一段叙述有没有把「表现」直接跳到「手段」（低氧 → 加氧）
- 遇到「要不要吸氧」「吸氧能不能改善」这类追问，需要一致的机制口径

## 核心判据（四问）

1. **方向同向还是反向？** 低氧伴二氧化碳升高 → 先查进气（泵与路）；低氧而二氧化碳不高 → 先查膜、匹配与分流。
2. **哪一环节先失衡？** 通气（动力与阻力）、弥散（厚度、面积、时间）、灌流（压力、阻塞、血管床）、匹配（V/Q）。
3. **V/Q 往哪个方向偏？** 升高是死腔样（通气多、灌流少），降低是分流样（灌流多、通气少），全无通气而仍有灌流是真性分流。
4. **手段落在哪一字？** 泵（通气支持）、气（氧疗）、路（清除分泌物）。三者不能互替。

## 执行步骤

```text
1. 抄原话，不改写
2. 补方向：氧的方向与二氧化碳的方向，缺哪个标「未给」
3. 归环节：通气 / 弥散 / 灌流 / 匹配，排出优先顺序并给证据与反证
4. 分类别：五类机制里支持哪几类、排除哪几类
5. 定 V/Q：升高 / 降低 / 真性分流 / 未给
6. 推反应：吸氧改善明显或有限，只讲方向
7. 中性改写：删掉判定与处置成分
8. 报边界：不给值、不分型、不处置
```

## 硬约束

- **不给数值、单位、正常值、阈值、百分比、氧浓度。** 需要数值才能回答的追问，统一回「不给值，须另立数据层」。
- **不作诊断、不作呼吸衰竭分型判定、不作处置建议。** 低氧型与高碳酸型在本课程里只作机制方向。
- **引文逐字**，标 `补充·hermes-病理生理学讲义·第21章·N.M`；核不到就不引，不标「教材」。
- **不把发绀当判据。** 它受血红蛋白总量、皮肤色素与光照影响。
- **单帧不做结论。** 趋势与对活动的反应比单次读数更有价值。

## 交付物

1. 一句方向组合：同向还是反向，缺哪一向
2. 一张「环节 → 支持证据 → 反证」三列表
3. 一句 V/Q 方向与是否含真性分流
4. 一句吸氧反应预期（只讲方向）
5. 一处边界：不给值、不分型，数值须另立数据层

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 低氧即加氧 | 手段错位，掩盖机制 | 先定环节，再分泵 / 气 / 路 |
| 忽略二氧化碳 | 两条推理路径混成一条 | 强制补方向组合 |
| 把弥散当常见机制 | 归因偏差 | V/Q 失衡才是最常见 |
| V/Q 不分方向 | 治疗预期错 | 分清死腔样与分流样 |
| 镇静药当安眠 | 抑制呼吸中枢与咳嗽反射 | 对通气储备不足者是失代偿诱因 |
| 被追问就报阈值 | 越出口径 | 统一回「不给值，另立数据层」 |

## 边界

本 Skill 只处理「低氧 → 四环节 → 机制类别」的定位，不涉及数值、分型判定与处置。机制框架取自《hermes-病理生理学讲义》第 21 章；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
