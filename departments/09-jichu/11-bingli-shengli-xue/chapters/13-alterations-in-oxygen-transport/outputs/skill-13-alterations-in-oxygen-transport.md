# Skill：氧运输异常——链条定位与三步判读

## 何时用

- 一段描述里只有「气促、发绀、读数低」这类表现，需要指到链条上的某一段
- 有人用血氧读数或发绀替代指标判断
- 遇到「加了氧也不改善」的情形，需要解释为什么
- 要判断循环性与组织性缺氧这一对方向相反的类型

## 核心判据（四问）

1. **断在哪一段？** 摄取与交换（外呼吸）、携带与释放（血红蛋白）、输送（循环）、利用（细胞）。四段对应乏氧性、血液性、循环性、组织性。
2. **四项指标各自如何？** 分压管推动、容量管装得下多少、含量管实际装了多少、饱和度管装了几成。四项可以独立变化，任何一项都不能代表其余三项。
3. **顺序走了吗？** 先看动脉氧分压（降 → 乏氧性）；再看氧容量（降 → 血液性）；两者都正常时看动静脉氧差（增大 → 循环性，减小 → 组织性）。跳步必错。
4. **代偿与代价是什么？** 呼吸、循环、血液、组织细胞四层各自有收益，也各自有代价；器官受损的信号（意识、尿量、心律）在代偿之后才出现。

## 执行步骤

```text
1. 抄原文，不改写：把描述原样放在第一行
2. 画链：九个位置，标出原文涉及哪几段
3. 三问定位：分压 → 容量 → 氧差，缺项写「未给」，不推测
4. 细分亚类：乏氧性分三种（吸入气、外呼吸、分流）；血液性分三种（贫血、一氧化碳、高铁血红蛋白）
5. 查混合：两段是否同时受损，指标如何互相掩盖，给逐段排查顺序
6. 看代偿与器官：哪一层在代偿、代价是什么、器官是否已受损
7. 报边界：不给值、不分级、不写氧疗参数
```

## 硬约束

- **不给数值。** 氧分压、饱和度、含量、血红蛋白浓度、曲线移位幅度一律不写；追问统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **读数不等于含量，也不等于输送。** 贫血、一氧化碳、高铁血红蛋白三种情形下读数会假性正常，必须点明。
- **发绀是提示，不是分级。** 没有发绀不等于没有缺氧；发绀明显也不等于缺氧严重。
- **不写氧疗参数与处置流程。** 只写方向（有效 / 有限 / 无效 / 需针对病因），不给浓度、流量、时限与适应证界值。
- **引文逐字。** 标「补充·hermes-病理生理学讲义·第13章·N.M」；核不到就不引。

## 交付物

1. 一张链条定位图：九个位置，标出断点
2. 三步判读记录：分压 / 容量 / 氧差，各写结论或缺项
3. 一句亚类判断：在四型之内再往下落一层
4. 一份混合型说明：两段如何互相掩盖
5. 一处边界：不给值、不分级、不写处置参数

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 缺氧当状态 | 一律加氧 | 先定段，再谈方向 |
| 读数当含量 | 贫血被漏掉 | 分开饱和度与含量 |
| 发绀当分级 | 误判轻重 | 回到还原血红蛋白的绝对量 |
| 跳过第一步 | 乏氧性被判成循环性 | 按顺序缩小候选集 |
| 混合型硬套 | 只处理一段，另一段恶化 | 逐段排查，承认并存 |
| 分流加大流量 | 氧疗无效且延误 | 想到分流，改查结构原因 |

## 边界

本 Skill 只处理「一段描述 → 链条定位 → 三步判读 → 缺项」的结构化定位，不涉及诊断、分级与氧疗决策。框架取自《hermes-病理生理学讲义》第 13 章；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
