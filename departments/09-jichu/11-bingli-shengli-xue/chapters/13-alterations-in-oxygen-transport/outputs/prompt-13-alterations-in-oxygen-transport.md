# Prompt：给一组指标，指到链条上的某一段

## 用途

氧运输这一块最常见的错误不是记不住四型，而是把「缺氧」当成一个状态去处理：见到气促就加氧，见到读数正常就放心，见到发绀就紧张。这个模板把任何一段描述压回链条上的一个位置，并给出判读顺序：**分压 → 容量 → 氧差 → 代偿 → 器官**。适用于病例讨论前的自检、血气与血常规的读法训练，以及给同学解释「为什么读数正常人却不好」这类问题。

## 使用前提

- 你面对的是一段**描述**（症状、体征、检验方向的文字结论），不是一份待处理的急症。
- 你手边有讲义定位（`补充·hermes-病理生理学讲义·第13章·13.8` 这一级），读过对应节。
- 你接受三条硬约束：**不产出任何数值与阈值**；**不作诊断与分级**；**不写氧疗参数与处置流程**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是给结论，而是把一段描述定位到氧运输链条的四段之一，并说明为什么不是另外三段。

【输入】
原文：<一段描述，可含症状、体征、检验方向>
讲义定位：<补充·hermes-病理生理学讲义·第N章·N.M>

【任务，按顺序回答，不跳步】
1. 画链：把九个位置写出来（空气 → 肺泡 → 肺泡毛细血管膜 → 血浆 → 血红蛋白 → 循环 → 组织毛细血管 → 细胞 → 线粒体），标出原文提到的是哪几段。
2. 第一问·分压：动脉氧分压是降低还是正常？降低 → 乏氧性，进入第 3 步；正常 → 进入第 4 步。
3. 乏氧性细分：是吸入气氧分压降低、外呼吸功能障碍，还是静脉血分流入动脉？三者对氧疗的反应不同，必须分开说。
4. 第二问·容量：氧容量或血红蛋白是否降低？降低 → 血液性，继续问是数量减少（贫血）、一氧化碳，还是高铁血红蛋白。
5. 第三问·氧差：分压与容量都正常时，动静脉氧差是增大（循环性）还是减小、静脉端氧分压偏高（组织性）？
6. 混合型：两条段是否可能同时受损？若是，指出指标如何互相掩盖，并给出逐段排查的顺序。
7. 代偿与器官：代偿在哪一层（呼吸 / 循环 / 血液 / 组织细胞），代价是什么；器官是否已受损（脑 / 心 / 肺 / 肝肾 / 代谢）。
8. 边界：这段定位不能回答什么。

【硬约束】
- 不给任何数值、单位、阈值、参考区间、百分比、曲线移位幅度。凡需数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作分级，不写氧疗浓度、流量、时限与适应证界值。
- 引讲义原文必须逐字，并标「补充·hermes-病理生理学讲义·第N章·N.M」；核不到就不引。
- 不用发绀或血氧读数替代指标判断；说明它们各自能代表什么、不能代表什么。

【输出格式】
八个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的定位（节选）

原文：「活动后气促、心悸，口唇不紫，脉搏血氧读数正常。」讲义定位：补充·hermes-病理生理学讲义·第13章·13.5。

- **画链**：原文只给了表现与读数，没有给检验方向；链条上可能出问题的是携带段（血红蛋白）与输送段（心输出量）。
- **第一问·分压**：未给。若分压正常，可排除交换段；缺这一项就不能下结论，如实写缺。
- **第二问·容量**：未给血红蛋白，缺项。若容量降低而饱和度正常，指向血液性。
- **第三问·氧差**：未给，缺项。增大指向输送段，减小指向利用段。
- **混合型**：贫血合并心功能不全时，氧差增大的程度会被削弱，两项互相掩盖；排查顺序是先定有无容量下降，再看灌注证据。
- **代偿与器官**：活动后气促与心悸符合循环层代偿（心率增快、血流重分布），代价是心肌耗氧增加；器官受损证据（意识、尿量）未给。
- **边界**：不能判断是哪一型，也不能给任何处置；数值一律不给。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 见缺氧就加氧 | 「先吸氧再说」 | 先定段：血液性与组织性对氧疗基本无效 |
| 读数当含量 | 「饱和度正常，所以不缺」 | 回到容量与含量，贫血是典型反例 |
| 发绀当分级 | 「发绀明显，说明缺氧重」 | 发绀只反映还原血红蛋白的绝对量 |
| 跳过第一步 | 直接看氧差判循环性 | 按分压 → 容量 → 氧差的顺序缩小候选集 |
| 混合型硬套一类 | 找一个「最像」的型 | 按最可能的一段逐段排查，承认两段并存 |
| 偷给阈值 | 「饱和度低于多少就……」 | 触发硬约束，改为「本书不给值」 |

## 边界

本模板训练的是「描述 → 链条定位 → 判读顺序 → 缺项」的能力，不产生临床判断。框架取自《hermes-病理生理学讲义》第 13 章的链条四段与三步判读；数值、分级与氧疗参数不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
