# Skill：特殊感觉功能异常——形状定位与代偿

## 何时用

- 有人只说「看不清 / 听不清 / 晕 / 没味道」，没有给出任何形状信息
- 要把视野缺损、听力图形态、眼震方向换算成受累环节
- 要判断眩晕是否需要按中枢性对待
- 要解释耳鸣、噪声不耐受、怕黑这些「没有病灶」的症状
- 遇到「多少算低视力」「听力损失几分级」这类追问，需要一致的拒答口径

## 核心判据（四问）

1. **哪种感觉？** 视、听、前庭、嗅、味。主诉「吃东西没味道」时先分嗅觉与味觉——大部分味道来自嗅觉。
2. **缺成什么样？** 视野：单眼 / 双颞侧 / 同向性 / 象限性 / 黄斑回避。听力：气导与骨导谁下降、高频还是低频。前庭：眼震方向、是否被固视抑制。嗅味：单侧还是双侧、突发还是渐进。
3. **快还是慢？** 突发提示血管事件，数小时至数天提示炎症或感染，数月以上提示变性、压迫或慢性损伤。这条规则与第 43 章同一套。
4. **有没有代偿？** 耳鸣、噪声不耐受、怕黑、跨模态敏感都是中枢重组的痕迹。系统不承认没有输入，它会重新分配资源。

## 执行步骤

```text
1. 抄原话，不改写：把要换算的那段描述原样放在第一行
2. 定感觉：五种选一；嗅味主诉先分嗅觉与味觉
3. 取形状：按第 2 问的四组特征逐项填，缺项写「未给」
4. 定时间：突发 / 数天 / 数月，三档选一档
5. 查伴随：疼痛、耳鸣耳闷、复视、构音障碍、吞咽困难、共济失调
6. 落环节：按感受器 / 传入通路 / 皮层代表区三段比对，不匹配的写「不符」
7. 记代偿：有无中枢重组的痕迹
8. 报边界：不给值、不作最终定位结论、不给检查项目
```

## 硬约束

- **不给数值、单位、正常值、分级、参考区间、百分比。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不作诊断，不作外周或中枢的最终结论。** 两张鉴别表是机制层的方向判断，不是对某个人的定性。
- **引文逐字。** 标「补充·hermes-病理生理学讲义·第46章·46.M」；核不到就不引。讲义是本仓库原创教学正文，不许写成任何外文教材的译本。
- **形状优先于强度。** 眩晕的剧烈程度、视力下降的主观感受都不构成判据；判据在形态与伴随体征。
- **不作处置建议。** 检查选择、手术、助听验配属临床决策，本 Skill 只给定位推理。

## 交付物

1. 一段四问拆解（感觉 → 形状 → 时间 → 代偿），缺项标「未给」
2. 一句环节判断：感受器 / 通路 / 皮层，对不上的写「不符」
3. 一条安全线：有无需要按中枢性对待的伴随体征
4. 一处边界：本章不给值、不作最终结论，数值须另立数据层

## 典型误用

| 误用 | 表现 | 纠正 |
|---|---|---|
| 用动词替代形状 | 「他看不清」当成信息 | 追问单双眼、视野形态、疼痛、速度 |
| 强度当严重度 | 「晕得厉害所以重」 | 改看伴随神经体征与眼震特征 |
| 把行为当性格 | 「老人多疑」 | 先想高频听力损失导致的误解 |
| 把代偿当新病 | 「耳鸣是新出现的问题」 | 耳鸣多为输入减少后增益上调 |
| 青光眼看眼压一项 | 「眼压不高就没事」 | 眼压升高并非唯一机制，血管因素同样重要 |
| 偷给数值 | 「视力零点几」 | 改为方向性表述，或回「本书不给值」 |

## 与相邻章节的接缝

- 第 43 章（神经系统结构与功能）：三段骨架与「部位 × 时间」在那里立起来，本章把它用到五条具体通路。
- 第 45 章（慢性神经功能障碍）：嗅觉减退可作为变性病的前驱标志，两章在 46.8 交汇。
- 第 47 章（疼痛）：感觉通路与痛觉调制共用同一套传入与抑制机制。
- 与病理学的分工：病理学讲形态（白内障的晶状体混浊、视神经的萎缩），本课程讲机制（为什么这一段的缺损长成这个形状）。

## 边界

本 Skill 只处理「一段感觉症状描述 → 缺损形状 → 受累环节」的结构化换算，不涉及数值、判定与临床决策。通路与分型取自《hermes-病理生理学讲义》第 46 章的表述；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
