# Prompt：用缺损的形状反推受累环节

## 用途

感觉障碍最容易被糊过去的一句话是「他看不清 / 听不清 / 晕」。三个动词把五条通路压成三个词，落不到任何一段结构上。这个模板不让你补检查项目，而是先问「缺成什么样」：视野缺损的位置、听力损失的频率与气骨导关系、眼震的方向与固视抑制、眩晕的伴随体征、嗅觉减退的时程。形状给出来，受累环节就缩小到一段。

适用于读门诊记录、写护理评估、做课前讨论，也适用于第 43 章（神经系统结构与功能）的复盘：那一章讲通路的通用规则，这一章把规则用到五条具体通路上。

## 使用前提

- 你手上是一段**感觉症状的描述**，不是一个待确诊的病例。
- 你读过讲义本章对应小节（`补充·hermes-病理生理学讲义·第46章·46.1` 这一级），能指出每条判断的出处。
- 你接受两条硬约束：**不产出任何数值**；**不作诊断、不判定外周与中枢的最终结论**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是给结论，而是把一段感觉症状的描述按缺损的形状换算成受累环节。

【输入】
原话：<一段感觉症状描述>
讲义定位：<补充·hermes-病理生理学讲义·第46章·46.M>

【任务，按顺序回答，不跳步】
1. 哪一种感觉：视、听、前庭、嗅、味？若是「吃东西没味道」，先问是味觉还是嗅觉。
2. 形状：缺损的形态是什么？视野（单眼 / 双颞侧 / 同向性 / 象限性 / 黄斑回避）；听力（气导与骨导谁下降、高频还是低频）；前庭（眼震方向、是否被固视抑制）；嗅味（单侧还是双侧、突发还是渐进）。
3. 时间：突发、数小时至数天、数月以上。与第 43 章的「部位 × 时间」同一套规则。
4. 伴随：有无疼痛（眼球转动痛、耳痛、头痛）、有无神经体征（复视、构音障碍、吞咽困难、共济失调）、有无耳鸣耳闷。
5. 定位：按三段骨架（感受器 / 传入通路 / 皮层代表区）逐一比对，指出最可能的受阻环节；对不上的写「不符」。
6. 代偿：有无中枢重组的表现（耳鸣、噪声不耐受、怕黑、跨模态敏感）？
7. 边界：这段拆解不能回答什么。

【硬约束】
- 不给任何数值、单位、正常值、参考区间、百分比、分级。凡需数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作外周或中枢的最终结论，不给检查项目与处置建议。
- 引讲义原文必须逐字，并标「补充·hermes-病理生理学讲义·第46章·46.M」；核不到就不引。
- 某一步缺证据就写「未给」，不要用推测填满。

【输出格式】
七个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的换算（节选）

原话：「阿姨说最近看电视总觉得字幕看不清，眼睛不痛，是慢慢变差的；晚上出门更不敢走。」讲义定位：补充·hermes-病理生理学讲义·第46章·46.3。

- **哪一种**：视觉。
- **形状**：不是视野缺损而是「看清能力」下降；无痛、渐进、与照明相关（夜间更差），提示光学或晶状体环节，而非视神经或视交叉。
- **时间**：数月以上，属渐进档。
- **伴随**：无痛，无复视与神经体征；夜间加重提示对比敏感度与瞳孔因素。
- **定位**：按五层过——屈光不正（可解释）、白内障（可解释，渐进无痛）、青光眼（周边先受累，与主诉不符）、视网膜病变（需更多信息）、视神经病变（多伴疼痛或缺损形状），写「屈光与晶状体为主，其余未排除」。
- **代偿**：夜间不敢走提示对比敏感度下降叠加前庭与本体感觉的重新加权。
- **边界**：不能据此确定病因，也不能给出任何检查数值；需要现场检查才能收敛。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 用动词替代形状 | 「他看不清」 | 追问单双眼、视野形态、疼痛、速度 |
| 把强度当严重度 | 「晕得厉害所以严重」 | 改看伴随神经体征与眼震特征 |
| 把味觉当味觉 | 「吃东西没味道」直接查味蕾 | 先分嗅觉与味觉，大部分味道来自嗅觉 |
| 忽略代偿 | 只记录缺损，不问耳鸣与怕黑 | 补上中枢重组的表现 |
| 越界给检查 | 「先做磁共振」 | 只给定位推理，检查选择属临床决策 |
| 偷给数值 | 「视力零点几」 | 改为方向性表述，或回「本书不给值」 |

## 边界

本模板训练的是「感觉种类 → 形状 → 时间 → 伴随 → 定位 → 代偿」的分层表达能力，不产生临床判断。通路与分型取自《hermes-病理生理学讲义》第 46 章的表述；数值与判定不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
