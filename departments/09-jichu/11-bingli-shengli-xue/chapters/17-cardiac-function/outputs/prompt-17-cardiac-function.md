# Prompt：把一份心脏记录拆成四个因素与它们各自的代价

## 用途

关于心脏功能的提问多半长这样：「这个人心功能怎么样？」本章的口径是不能直接答——因为「心功能」在讲义里不是一件事，而是四件事：前负荷、后负荷、收缩力、心率。四件事可以同时异常，也可以互相掩盖（后负荷升高会压低每搏量，残余血量又抬高前负荷，前负荷再经 Starling 拉回一部分）。这个模板不让你给评价，只把一份记录拆成四个位置，并指出每一个位置上「改善」的代价是什么。适用于读一份心脏相关记录之前的自检、交接时的机制复述，以及读第 18 章（心脏功能异常）时反复套用。

## 使用前提

- 你面对的是一段**观察与记录**，不是一个待处理的病例。
- 你读过讲义对应节（`补充·hermes-病理生理学讲义·第17章·N.M`），知道该节讲的是哪一层。
- 你接受两条硬约束：**不引用、不换算任何数值**；**不作诊断、不作分级、不写处置与用药**。

## Prompt 正文（复制即用）

```text
你是病理生理学助教。任务不是评价心功能好坏，而是把一段记录拆成四个因素，并写出每个位置上「改善」的代价。

【输入】
记录：<症状 / 体征 / 结构描述 / 功能描述 / 电活动 / 生化线索，允许带患者原话>
讲义定位：<补充·hermes-病理生理学讲义·第17章·N.M>

【任务，按顺序回答，不跳步】
1. 结构：这段话涉及四腔、四瓣、传导系统中的哪一部分？结构改变会破坏三条对应关系中的哪一条（房室顺序、瓣膜单向、兴奋同步）？
2. 链条：若提到收缩或舒张，把它放回耦联链的哪一环——钙内流、钙致钙释放、肌钙蛋白与横桥、能量供应、力学耦联、钙回收（舒张）？缺的环写「未给」。
3. 四因素：把信息归到前负荷、后负荷、收缩力、心率四个位置上；归不进去的写「未给」，不补猜。
4. 代价：对每一个有信息的位置，写出「改善它会付出什么」——前负荷的室壁张力与淤血、后负荷降低时的灌注压、收缩力增强时的耗氧与储备、心率增快的充盈与供氧时间。
5. 平衡：这段话能不能判断供-需平衡往哪一侧破？供给侧（冠脉血流、血氧含量、舒张期长短）与需求侧（心率、收缩力、室壁张力）各写一句；缺的写「未给」。
6. 六方向：按症状、体征、结构、功能、电活动、生化六个方向列出已有信息与缺口，只列观察项，不列检查项目。
7. 边界：这段拆解不能回答什么。

【硬约束】
- 不给任何数值、单位、射血分数、压力、容积、百分比。凡需数值才能回答的追问，统一回答：「本书不给值」。
- 不作诊断，不作分级，不写药物、剂量、给药方式之类的处置指令。
- 引讲义原文必须逐字，并标「补充·hermes-病理生理学讲义·第17章·N.M」；核不到就不引。
- 不把四个因素写成四个独立开关：每写一条改善，必须同时写出代价。

【输出格式】
七个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/处置依据。」
```

## 示例：一次合格的拆解（节选）

记录：「走两层楼就喘，躺平更明显，脚踝有点肿；听诊有啰音；记录里写心腔比之前大。」讲义定位：补充·hermes-病理生理学讲义·第17章·17.4。

- **结构**：涉及心腔大小（结构方向）与肺部听诊（体征方向）。心腔扩大破坏的是三条对应里的第三条——同步性与几何效率：半径增大使同样腔内压需要更高壁张力。
- **链条**：这段话没有给收缩或舒张的直接指标，耦联链上的六环全部「未给」。只从「心腔扩大」推不出是钙的问题还是能量与结构的问题。
- **四因素**：前负荷有信息（躺平更明显、脚踝水肿提示充盈压升高方向）；收缩力「未给」（没有功能描述）；后负荷「未给」；心率「未给」。
- **代价**：若按前负荷方向去「改善」（比如进一步扩容），代价是室壁张力与耗氧上升、肺淤血加重，而收缩力未必随之上升——Starling 曲线的平台段与下降段就在这里。
- **平衡**：需求侧在活动时上升（走两层楼即喘），供给侧「未给」。无法判断破在哪一侧，只能写「供需两端信息不全」。
- **六方向**：有症状（活动耐量下降、端坐呼吸方向）、体征（啰音、水肿）、结构（心腔扩大）；缺功能、电活动、生化三项。
- **边界**：不能由此判断任何人的状态，也不给分级；数值一律不给。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 把四因素当四个开关 | 只说「收缩力差」就收尾 | 每写一条改善，补一条代价 |
| 直接评价好坏 | 「心功能很差」 | 回到四个位置，说明依据落在哪个位置 |
| 跳过链条 | 由「心腔大」直接推到「钙有问题」 | 链条上缺的环写「未给」 |
| 只谈需求不谈供给 | 「活动后不适＝需求太高」 | 供给侧也要写，缺的标缺 |
| 把代偿当治愈 | 「肥厚了，代偿良好」 | 肥厚同时增加耗氧、降低顺应性 |
| 偷给数值 | 「射血分数低于多少算差」 | 触发硬约束，改为「本书不给值」 |

## 边界

本模板训练的是「一份记录 → 四个因素 → 代价」的结构化拆解，不产生临床判断。机制框架取自《hermes-病理生理学讲义》第 17 章；数值、分级与处置不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
