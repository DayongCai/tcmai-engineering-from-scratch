# 心脏功能：四个旋钮与一条钙的链条

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；

## 核心判据

- 兴奋-收缩耦联
- 舒张也是一个耗能的主动过程
- 每搏量是一个由三个因素共同决定的量
- 每一个上游指标都要在终点被重新检验一次
- 同一条曲线，左半段是工具，右半段是陷阱
- 肥厚是代偿，也是新的负担

## 边界

- **引文只认讲义。** 本章引文格式统一为`补充·hermes-病理生理学讲义·第17章·N.M`，节号必须在 17.1–17.12 之间。讲义是本仓库原创的教学正文，不是任何外文教材的译本；本章不引代用底本。
- **本章丢掉了什么：数值。** 心脏功能是最容易被数字化的一章：射血分数、每搏量、心指数、压力、阻力，全都有标准取值。本章一个都不给，理由有三：其一，压力-容积环表达的是方向与形状，不需要刻度就能读出机制；其二，任何写进正文的界值都会随标准版本静默过期；其三，本章要练的是**从链条到因素、从因素到代价**的推演，数值不参与这条推演。需要数值的场景必须另立数据层，另立来源、版本与校验。
- **本章不写正常值，也不做换算。** 不写射血分数、每搏量、心指数、压力与阻力的任何取值，不把「四次方」「三分之一」这类关系式折算成绝对数。凡遇多少算低、低到多少算衰竭的追问，统一回「本书不给值」。
