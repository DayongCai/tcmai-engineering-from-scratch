# Skill：心脏功能——四个因素、一条链条与一张压力-容积环

## 何时用

- 有人问「心功能怎么样」，而你要把这个问题还原成四个可以分别定位的位置
- 要解释为什么「把某一个指标推到极限」在生理上走不通
- 要判断一段描述说的是收缩问题还是舒张问题，以及为什么两者的表现可以相似
- 要说明肥厚为什么既是代偿又是新的负担
- 遇到「射血分数多少算低」这类追问，需要一致的拒答口径

## 核心判据（四问）

1. **哪一环？** 结构（四腔 / 四瓣 / 传导）→ 功能（泵血 + 节律）；收缩走耦联链（钙内流 → 钙致钙释放 → 肌钙蛋白 → 横桥），舒张走钙回收（耗能）。
2. **哪个因素？** 前负荷（射血前装了多少）、后负荷（推出去要费多大力）、收缩力（独立于负荷的内在能力）、心率（乘数，且有峰值）。
3. **代价是什么？** 前负荷升高：室壁张力与耗氧上升、淤血风险；后负荷降低：器官灌注压下降；收缩力增强：耗氧与储备消耗；心率增快：充盈与冠脉灌注时间被压缩。
4. **供-需破在哪一侧？** 供给：冠脉血流、血氧含量、舒张期长短；需求：心率、收缩力、室壁张力。临床上常见的是两端同时恶化。

## 执行步骤

```text
1. 抄记录，不改写：症状 / 体征 / 结构 / 功能 / 电 / 生化，原样分类
2. 定结构：四腔、四瓣、传导，破坏了三条对应里的哪一条
3. 放链条：收缩或舒张落在耦联链的哪一环，缺的环标「未给」
4. 归因素：前负荷 / 后负荷 / 收缩力 / 心率，四选一或标缺
5. 写代价：每一条「改善」都配一条代价，不许只写收益
6. 判平衡：供给侧与需求侧各写一句，缺的标缺
7. 报边界：不给值、不分级、不写处置
```

## 硬约束

- **不给数值、单位、射血分数、压力、容积、百分比。** 需要数值才能回答的追问，统一回「本书不给值」。
- **不作诊断，不作分级。** 四类失衡（泵 / 节律 / 瓣膜 / 冠脉）是机制类别，不是诊断标准。
- **引文逐字。** 标「补充·hermes-病理生理学讲义·第17章·N.M」；核不到就不引。
- **不把因素写成开关。** 四个因素互相制约，任何一条改善都要附一条代价。
- **代偿与代价同源。** 肥厚、Starling 平台段、心率增快三处都同时写着好处与坏处。

## 交付物

1. 一张结构—功能对应表（三条对应里哪一条被破坏）
2. 一条链条定位（耦联链的哪一环，缺环标「未给」）
3. 一张四因素表（哪几个有信息，其余标缺）
4. 一张代价清单（每条改善配一条代价）
5. 一句供-需判断（破在哪一侧，或缺信息）
6. 一句边界：不给值、不作诊断，数值须另立数据层

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 把四因素当四个开关 | 只调一个，其余三个反噬 | 每写一条改善，补一条代价 |
| 把每搏量当心脏属性 | 忽略两个负荷的作用 | 每搏量由三个因素共同决定 |
| 只谈收缩不谈舒张 | 漏掉「射血不差却一动就喘」的病例 | 舒张是耗能的主动过程 |
| 把肥厚当纯代偿 | 忽略耗氧上升与顺应性下降 | 代偿与代价并列写出 |
| 缺血都归因于血管堵 | 漏掉贫血、低氧、舒张期过短 | 供需两端都查 |
| 被追问就报阈值 | 越出本书口径，且数值无来源 | 统一回「本书不给值」 |

## 与相邻章节的接缝

- 上一章（血压异常）：本章的后负荷在那一侧是外周阻力，两章共用同一个乘式。
- 下一章（心脏功能异常）：本章的四个因素在那里变成四类失衡——泵（收缩 / 舒张）、节律、瓣膜（压力 / 容量负荷）、冠脉（供-需）。
- 第 19 章（心力衰竭与心律失常）：本章的「损伤先行、症状后至」在那里成为自然史的主线。
- 第 15 章（血流异常）：冠脉的自主调节与那一章的自动调节是同一机制在不同血管床上的重演。

## 边界

本 Skill 只处理「一份记录 → 四个因素 → 代价」的结构化拆解，不涉及数值、分级与临床处置。机制框架取自《hermes-病理生理学讲义》第 17 章；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
