# Skill：糖尿病——一个不对称结构、三条环节与两类血管

## 何时用

- 一段描述里出现血糖异常的线索，需要先分清是急性失代偿还是慢性累积
- 要回答“为什么会突然垮”，需要数清当下有几个升糖激素在场
- 要解释同一诊断下治疗反应差异巨大，需要落到三环节里找主因
- 要评估低血糖风险，尤其是“从来没有低血糖症状”的人
- 遇到“血糖多少算好”这类追问，需要一致的拒答口径

## 核心判据（五问）

1. **不对称在不在场？** 四个以上升糖激素对一个降糖激素；应激时同时被推开。
2. **哪一环是主因？** β 细胞分泌缺陷、靶组织胰岛素抵抗、其他器官环节（肾小管重吸收、肠促胰素、脂肪组织炎症）。
3. **急性还是慢性？** 急性看酮体、脱水、意识与呼吸；慢性看眼、肾、神经、大血管。
4. **哪类血管？** 微血管以基底膜增厚与内皮功能障碍为主；大血管以动脉粥样硬化为主，机制不同不可合并。
5. **风险信号有没有失效？** 低血糖感知受损者预警缺失；足部感觉丧失使伤口不被发现。

## 执行步骤

```text
1. 抄原话，不改写：把要落位的那段放在第一行
2. 定方向：分泌缺陷为主 / 抵抗为背景 / 两者并存
3. 定环节：三环节里指出当下主因
4. 分急性慢性：先排除急性（酮体、脱水、意识、呼吸），再谈慢性
5. 分血管：微血管与大血管分开叙述
6. 数不对称：当下有哪几个升糖激素被激活
7. 中性改写：删掉判定成分，保留方向与时间线索
8. 报边界：不给值、不作诊断与预后判断、不写方案
```

## 硬约束

- **不给数值、单位、正常值、参考区间、百分比。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不作诊断，不作正常与异常判定。** 1 型与 2 型只作机制对照，不用于给个体分型。
- **不写治疗方案。** 药物、剂量、补液速率、监测频次属临床决策；本 Skill 只写识别方向与优先级。
- **不把“补上就好”当处理。** 一次低血糖是一次信号，处理之后必须查找原因。
- **引文逐字。** 标`补充·hermes-病理生理学讲义·第41章·N.M`；核不到就不引。讲义是本仓库原创正文，不写成任何外文教材的译本。

## 交付物

1. 一句类型方向的判断（不做分型结论）
2. 一句三环节的主因指认
3. 一句急性／慢性的分流判断
4. 一句血管类别的区分（涉及慢性时）
5. 一张诱因排查表：感染、中断、应激、妊娠、药物
6. 一处边界：不给值、不作诊断、不写方案

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 只谈血糖 | 漏掉酮体与脱水 | 先分急性与慢性 |
| 合并两类血管 | 机制讲错 | 微血管与大血管分开 |
| 把进展读成依从性问题 | 沟通对抗 | 进展是自然史的一部分 |
| 把蜜月期当痊愈 | 误判治疗失败 | 短暂恢复是残余细胞的喘息 |
| 把无预警当安全 | 漏掉最高风险者 | 感知受损是风险线索 |
| 越过方案 | 越过教学边界 | 只写识别方向 |

- 与内分泌生理一章：肾糖阈、结合蛋白与清除、妊娠期生理性抵抗，是本章多处机制的来源。

## 边界

本 Skill 只处理「描述 → 三环节 → 两类血管 → 边界」的落位，不涉及数值、判定与临床决策。机制类别取自本仓库原创讲义第 41 章（41.1–41.12）；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
