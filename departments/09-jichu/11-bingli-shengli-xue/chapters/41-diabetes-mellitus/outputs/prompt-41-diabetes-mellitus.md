# Prompt：把一次血糖失控推成三环节与两类血管

## 用途

糖尿病这一章的机制最后落在两个坐标上：三条环节（分泌缺陷、胰岛素抵抗、其他器官环节）与两类血管（微血管、大血管）。这个模板不让你背并发症清单，只让你把一段描述落到坐标上，并指出哪一环是当下的主因、哪一侧是长期的方向。适用于讨论课的机制推演、护理评估的整理，以及读病程记录时确认每一句话落在哪一条链上。

## 使用前提

- 你面对的是一段**描述**（症状、化验方向、用药与进食情况、病程长短），不是一份诊断。
- 你手边有讲义定位（`补充·hermes-病理生理学讲义·第41章·41.3` 这一级），读过对应小节。
- 你接受三条硬约束：**不产出任何数值**；**不作诊断与判定**；**不给药物与剂量**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是给方案，而是把一段描述落到三环节与两类血管的坐标上，并说明这次推演回答不了什么。

【输入】
原话：<一段描述，可以带病名、可以带判断>
讲义定位：<补充·hermes-病理生理学讲义·第N章·N.M>

【任务，按顺序回答，不跳步】
1. 定类型方向：以分泌缺陷为主、以抵抗为背景、还是两者并存？只写方向，不写数值，也不做分型结论。
2. 定环节：三环节里哪一环是当下主因——β 细胞分泌、靶组织抵抗，还是肾小管重吸收与肠促胰素等器官环节？
3. 读急性还是慢性：当下是急性失代偿方向（酮体、脱水、意识），还是慢性累积方向（眼、肾、神经、大血管）？
4. 分血管：若走慢性方向，是微血管还是大血管？两类机制不同，不能合并叙述。
5. 找诱因：感染、胰岛素中断、应激、妊娠、药物，逐条说有没有。
6. 查不对称：四个升糖激素里，当下有哪几个被激活？
7. 越界清单：把原话里的判定成分逐条指出，给出中性改写。
8. 边界：这段推演不能回答什么。

【硬约束】
- 不给任何数值、单位、正常值、参考区间、百分比。凡需数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作正常与异常判定，不作预后判定，不作疗效断言。
- 不写治疗方案：药物、剂量、补液速率与监测频次都不在本模板输出之内。
- 引讲义原文必须逐字并标「补充·hermes-病理生理学讲义·第41章·N.M」；核不到就不引。

【输出格式】
八个小标题各答一到两句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的落位（节选）

原话：「他有糖尿病好几年了，这次感冒后一直吐，人越来越困。」讲义定位：补充·hermes-病理生理学讲义·第41章·41.7。

- **类型方向**：以胰岛素不足为主，属急性失代偿方向。
- **定环节**：β 细胞分泌不足是主因；感染同时把四个升糖激素里的几个拉高。
- **急性还是慢性**：急性——呕吐、困倦、感染三者同时出现，是 DKA 与 HHS 的共同识别组合。
- **分血管**：本次不涉及，慢性方向另议。
- **找诱因**：感染是最常见的诱因；呕吐又加重脱水与进食不足。
- **查不对称**：感染激活肾上腺素与皮质醇，生长激素也升高，降糖一侧只剩外源补充。
- **越界清单**：「越来越困」改为「意识水平下降」，可保留描述、去掉推断。
- **边界**：不能判断是 DKA 还是 HHS（分界在酮体与渗透压方向），也不给补液与胰岛素方案。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 只谈血糖 | 把急症读成一个数字 | 看酮体与脱水的方向 |
| 合并两类血管 | 视网膜与冠脉一起说 | 微血管与大血管机制不同 |
| 把进展读成没管好 | 用依从性解释恶化 | 进展是自然史的一部分 |
| 漏掉不对称 | 只写胰岛素不足 | 数清当下有几个升糖激素在场 |
| 越过方案 | 直接写补液与剂量 | 只写识别方向与优先级 |
| 把蜜月期当痊愈 | 需求回升被误判为失败 | 短暂恢复是残余细胞的喘息 |

## 边界

本模板训练的是「描述 → 三环节 → 两类血管 → 边界」的落位，不产生临床判断。机制类别取自本仓库原创讲义第 41 章（41.1–41.12）；数值、判定与治疗方案均不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
