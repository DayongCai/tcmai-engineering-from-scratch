# Prompt：把「他炎症重、免疫力低」拆成两半，而不是给一句建议

## 用途

这一章最常见的糊法是一句话把两套系统混成一套：「炎症重说明免疫力低，得抗炎加增强免疫」。这个模板不让你开建议，而是把这句话逼成五步：**半区（在讲炎症还是免疫）、环节（四类落点）、记忆维度（有没有记忆）、因果方向（防御、误伤还是缺位）、判定层（哪些成分越界）**。适用于病例讨论前的自检、看到「炎症指标高」与「免疫指标低」并列出现时的分层，以及向患者解释「抗炎」与「调节免疫」不是一回事。

## 使用前提

- 你面对的是一段**描述或一段讨论发言**，不是一个待处置的病例。
- 你手边有讲义定位（`补充·hermes-病理生理学讲义·第9章·9.M` 这一级），读过对应小节。
- 你接受两条硬约束：**不产出任何数值**；**不作诊断、不作疗效判断**。

## Prompt 正文（复制即用）

```text
你是病理生理学的概念助教。任务不是给建议，而是把一段关于「炎症/免疫」的表述拆成两半，并指出哪一层越界。

【输入】
原话：<一段描述或讨论发言，可以带指标，可以带判断>
讲义定位：<补充·hermes-病理生理学讲义·第9章·N.M>

【任务，按顺序回答，不跳步】
1. 半区：这句话讲的是炎症（血管-细胞效应程序），还是免疫（识别与记忆的系统能力）？
   若一句话里两半都有，逐半标出，不许合并成「抵抗力」这种笼统说法。
2. 环节：落在哪一类？
   炎症侧：血管反应（扩张 / 通透性 / 淤滞）· 细胞反应（募集 / 吞噬）· 介质 · 形态类型 · 转归。
   免疫侧：固有（PAMP/DAMP）· 体液（抗体类别与效应）· 细胞（MHC 限制与 CTL）· 记忆。
   只指位置，不展开机制细节。
3. 记忆维度：这句话里的过程有没有记忆？炎症没有记忆（第二次烧伤不会更快），免疫有。
   用这一条复核第 1 步的分半是否正确。
4. 因果方向：免疫在这个过程里扮演什么角色——防御、误伤，还是缺位？
   三者位置不同，「炎症重」既可能是防御过度，也可能是免疫缺位后的替代反应。
5. 触发类型：是感染性还是无菌性？创伤、烧伤、缺血再灌注、化学刺激、结晶体、异物、自身免疫反应都属后者。
6. 判定层：这句话里哪些成分是对个体的判定（诊断、严重度、疗效、处置建议）？逐条指出。
7. 越界清单与中性改写：删掉判定成分，只保留半区、环节与过程的表述。
8. 边界：这段拆解不能回答什么。

【硬约束】
- 不给任何数值、单位、正常值、参考区间、百分比、细胞计数与抗体浓度。
  凡需要数值才能回答的追问，统一回答：本书不给值，需另立数据层（另立来源与校验）。
- 不作诊断，不作严重度分级，不作疗效断言，不给处置建议。
- 引讲义原文必须逐字，并标「补充·hermes-病理生理学讲义·第9章·N.M」；核不到就不引。
- 不许把「抗炎」写成「消灭炎症」：介质是同一套既防御又损伤的工具，抗炎是调节强度与时长。
- 不许把「免疫力低」当作炎症重的解释；先问原因（感染？损伤？免疫？），再问角色（防御、误伤、缺位）。
- 若原话不足以定位到某一层，直接说缺哪一层，不要用推测填满。

【输出格式】
八个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的拆解（节选）

原话：「伤口又红又肿，还有点发烧，说明炎症很重、抵抗力差，先消炎再补一补。」讲义定位：补充·hermes-病理生理学讲义·第9章·9.2。

- **半区**：前半句（红肿）是炎症侧，后半句（抵抗力差、补一补）是免疫侧；「炎症很重」把两半合成了一句。
- **环节**：红与热对应血管扩张后的血流增加，肿对应富含蛋白的液体渗出；发热属全身表现，机制在第 8 章，本章只回指。
- **记忆维度**：红肿是效应，没有记忆——第二次同样损伤不会因为「记住了」而更快，所以这里谈不到免疫记忆。
- **因果方向**：原话把「炎症重」直接归给「抵抗力差」，跳过了角色判断；炎症可由感染、损伤、免疫等多种原因触发，角色可能是防御、误伤或缺位。
- **触发类型**：伤口属可能合并感染的损伤，无菌性与感染性两条都要考虑，原话没有区分。
- **判定层**：「炎症很重」是严重度判定，「抵抗力差」是对个体状态的判定，「先消炎再补」是处置建议，三处都越界。
- **中性改写**：改成「伤口局部红肿伴体温升高，已按机构流程评估与处理」——只留观察所见与流程位置。
- **边界**：不能判断原因，不能判断严重度，不给任何界值。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 两半合一 | 「炎症重就是免疫低」 | 先分半区，再用记忆维度复核 |
| 抗炎=消灭 | 「把炎症压下去就好」 | 介质双重性：调节强度与时长 |
| 无菌性炎症漏掉 | 「没感染哪来的炎症」 | 创伤、缺血、结晶、异物都能起炎症 |
| 把渗出当漏出 | 「有积液就是炎症」 | 蛋白与细胞多寡决定方向 |
| 记忆张冠李戴 | 「炎症有记忆所以反复」 | 炎症无记忆，反复来自病因未除或慢性化 |
| 偷给界值 | 「超过这个数就是重度炎症」 | 触发硬约束，改为「本书不给值」 |

## 边界

本模板训练的是「一句话 → 两半 → 中性表述」的结构化拆解，不产生临床判断。分类框架取自 `standards/binglishengli/supplements/jiangyi.json` 第 9 章的类别与环节；数值、分型判定与个体判断均不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
