# Skill：炎症与免疫——分半、三条判据与一个交汇点

## 何时用

- 有人（包括你自己）用「发炎了」「抵抗力差」「消炎加补一补」把一段状态糊过去了，需要拆开
- 两个指标一高一低同时出现（炎症指标高、免疫指标低），要先确认它们是不是同一件事
- 要判断一段叙述有没有把无菌性炎症当感染、把渗出当漏出、把「抗炎」当「消灭炎症」
- 遇到「要不要抗炎」「是不是免疫低」这类追问，需要一套一致的拒答口径

## 核心判据（四问）

1. **哪一半？** 炎症＝血管-细胞效应程序（无记忆）；免疫＝识别与记忆的系统能力。一句话里两半都有时逐半标出，不许合并成「抵抗力」。
2. **哪一环？** 炎症侧：血管反应／细胞反应／介质／形态类型／转归。免疫侧：固有（PAMP、DAMP）／体液（抗体类别与效应）／细胞（MHC 限制与 CTL）／记忆。
3. **有没有记忆？** 炎症没有（第二次烧伤不会更快），免疫有。这一条用来复核第 1 问。
4. **什么角色？** 免疫在此是防御、误伤，还是缺位？「炎症重」既可能是防御过度，也可能是免疫缺位后的替代反应。

## 三条判据（本章的硬核）

```text
判据一 无菌性炎症  烧伤 / 痛风结晶 / 缺血再灌注 / 异物 → 无特异性抗原识别也能起炎症
判据二 无炎症的免疫 黏膜 IgA 中和 / 抗毒素抗体中和 / 某些耐受状态 → 免疫可不伴红肿热痛
判据三 记忆不对称  炎症无记忆，免疫有记忆 → 第二次接触的差异是可观察的判据
```

## 执行步骤

```text
1. 抄原话，不改写：把要拆的那句话原样放在第一行
2. 分半：逐半标出「炎症」与「免疫」，不许合并
3. 定环节：炎症侧五类、免疫侧四类，各指一处
4. 复核：用记忆维度再判一次两半是否分错
5. 判角色：防御 / 误伤 / 缺位；再分感染性与无菌性
6. 查越界：诊断、严重度、疗效、处置建议——逐条标出
7. 中性改写：删掉判定成分，只留半区与过程，保留观察时点
8. 报边界：不写数值，不作诊断，不给建议
```

## 硬约束

- **不给数值、单位、正常值、参考区间、百分比、细胞计数、抗体浓度。** 需要数值才能回答的追问，统一回：本书不给值，需另立数据层（另立来源与校验）。
- **不作诊断，不作分型与严重度判定。** 五型炎症与四种转归只作类别使用。
- **抗炎不是消灭炎症。** 介质是同一套既防御又损伤的工具；慢性炎症致病常因工具长期开启，所以调节强度与时长。
- **两词不互换。** 「炎症」与「免疫」在本课程里各指一套系统，混写即越界；共享成分（补体、细胞因子、巨噬细胞、肥大细胞）不构成同义。
- **引文逐字。** 标「补充·hermes-病理生理学讲义·第9章·N.M」；核不到就不引。讲义是本仓库原创正文，不写成「教材」。

## 交付物

1. 一段两半拆解（半区 → 环节 → 记忆 → 角色），缺层如实标缺
2. 一句分半结论：这句话讲的是炎症、免疫，还是两半混写
3. 一条判据复核：用三条判据里的哪一条支持这个分半
4. 一段中性改写：删掉判定成分后的版本，保留观察时点
5. 一处边界：本章不给值、不作诊断，数值须另立数据层

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 两半合一 | 「炎症重＝免疫低」 | 先分半，再用记忆维度复核 |
| 抗炎=清零 | 把防御程序当敌人 | 调节强度与时长，保留防御 |
| 无菌性炎症漏掉 | 「没感染哪来的炎症」 | 创伤、缺血、结晶、异物都能起炎症 |
| 渗出当漏出 | 判断积液方向反了 | 蛋白与细胞多寡决定方向，不是量 |
| 记忆张冠李戴 | 用免疫记忆解释炎症反复 | 反复来自病因未除或慢性化 |
| 被追问就报界值 | 越出本书口径，且数值无来源 | 统一回：本书不给值，另立数据层 |

## 与相邻章节的接缝

- 前一章（感染过程）：本章的急性期反应与内皮活化在那里已有铺垫；两章共用补体与细胞因子这套语言。
- 后一章（免疫功能异常）：本章 9.11 的「免疫驱动的炎症」是那一章的开场白——宿主对自身或对无害抗原发起攻击，炎症成为损伤的执行者。
- 与病理学的分工：病理学看形态类型（浆液、纤维蛋白、化脓、肉芽肿、溃疡），本课程看环节与判据。同一张切片，前者问「像什么」，后者问「哪一环在动」。

## 边界

本 Skill 只处理「一句话 → 两半 → 中性表述」的结构化拆解，不涉及数值、判定与临床决策。分类框架取自 `standards/binglishengli/supplements/jiangyi.json` 第 9 章的类别与环节；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
