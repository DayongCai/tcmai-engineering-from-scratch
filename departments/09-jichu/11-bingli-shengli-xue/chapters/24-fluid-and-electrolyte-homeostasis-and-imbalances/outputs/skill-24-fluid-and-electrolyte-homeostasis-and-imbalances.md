# Skill：水电解质失衡——两轴定位与三线查证

## 何时用

- 有人用「低钠」「水肿」「脱水」「容量不足」这类词直接给出结论，需要退回到观察
- 要判断眼前这个人的问题在容量这一侧还是渗透这一侧，还是两轴同时偏
- 要解释「为什么水肿的人还可能循环不足」，或「为什么血钠低不等于缺钠」
- 要解释「补了钾不见效」「补了钙不见效」这类反复出现的问题
- 遇到「要不要利尿」「要不要限水」「补多少」这类追问，需要一套一致的拒答口径

## 核心判据（五问）

1. **容量在哪一侧？** 不足 / 正常 / 过多。观察项：体重变化、出入量、颈静脉充盈、水肿、体位性血压与心率反应、皮肤黏膜。
2. **渗透在哪一侧？** 低渗 / 等渗 / 高渗。观察项：血钠方向、血浆渗透压方向、神经系统症状与出现速度。这是浓度判断，不是总量判断。
3. **落哪一格？** 两轴组合的五类机制类别，落一格并说明为什么不是相邻那格。
4. **第二条线索齐了吗？** 钾（分布与排出两条）、钙（总钙与离子钙两层）、镁（缺镁会拖住钾与钙）。三条都是独立线索，不能互相替代。
5. **速度写了吗？** 量与速度是两个独立变量；纠正速度本身是风险点，低钠与高钠两侧的危险方向相反。

## 执行步骤

```text
1. 抄原话，不改写：把结论句原样放在第一行
2. 分两类：观察（可核对）与结论（判断）分开列
3. 上容量轴：给方向，缺依据就写缺
4. 上渗透轴：给方向，并注明这是浓度判断
5. 落格：五类机制类别里选一格，说明为什么不是相邻格
6. 补三线：钾、钙、镁各问分布与排出，缺的写缺
7. 问循环：有无「总体多而循环不足」（水肿伴低钠、心衰、肝硬化、肾病综合征）
8. 写速度：多少与多快分开写
9. 中性改写：删掉处置与判定成分
10. 报边界：不写数值、不给速率、不作诊断
```

## 硬约束

- **不给数值、单位、正常值、参考区间、百分比、纠正速率。** 统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不作诊断，不作正常与异常判定。** 「低钠」「水肿」在本 Skill 里只作机制类别的名字，不用于给个体定性。
- **浓度与总量分开说。** 凡出现血钠，必须补一句它是浓度、不携带体内钠总量多少的信息。
- **两轴不许合并。** 只有一轴有依据时，另一轴写「待定」，不写「大致正常」。
- **速度单列。** 低钠与高钠两侧都要写纠正过快的风险，方向相反但都要写。
- **引文逐字。** 标「补充·hermes-病理生理学讲义·第N章·N.M」；核不到就不引。

## 交付物

1. 一张两类清单：观察项与结论项
2. 一个两轴落格：容量方向 × 渗透方向，附「为什么不是相邻格」
3. 一条有效循环血量判断：有无「总体多而循环不足」
4. 一份三线查证：钾 / 钙 / 镁各写分布与排出，缺项标缺
5. 一条速度说明：量与速度分开写
6. 一段中性改写：删掉处置与判定成分
7. 一处边界：本书不给值、不给速率、不作诊断

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 用结论替代观察 | 「低钠，限水」 | 先列观察，再谈方向 |
| 把浓度当容量 | 「血钠低说明缺钠」 | 补一句浓度不等于总量 |
| 一轴定全局 | 只看血钠就落格 | 两轴交叉，缺一轴写待定 |
| 水肿即利尿 | 循环不足者被进一步推向肾前性损伤 | 先问有效循环血量 |
| 低钾只补钾 | 补了不见效 | 查镁，低镁会拖住钾与钙 |
| 把速度当量 | 变化不大就判低风险 | 量与时相分开写 |
| 被追问就报速率 | 越出本书口径 | 统一回「本书不给值」 |

## 边界

本 Skill 只处理「一句结论 → 两轴定位 → 三线查证」的结构化拆解，不涉及数值、速率、判定与临床处置。框架取自本仓库原创《hermes-病理生理学讲义》第 24 章；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
