# Prompt：把一句「低钠」或「水肿」先放上两个轴

## 用途

水电解质讨论里最先出现的那句话，通常已经是一个结论：「低钠，先限水」「水肿，利尿」「脱水，补液」。三句话都跳过了定位。本模板不让你改结论，而是把结论退回到坐标上：容量在哪一侧、渗透在哪一侧、电解质有没有第二条线索。适用于交班记录的自检、讨论课的即时拆解，以及读第 25 章（酸碱）之前的热身——那一章的「方向判据」与本模板的「两轴定位」是同一套手艺。

## 使用前提

- 你面对的是一段**状态描述**（症状、体征、出入量、用药史），不是一个待处理的医嘱。
- 你手边有讲义定位（`补充·hermes-病理生理学讲义·第24章·24.13` 这一级），读过对应小节。
- 你接受两条硬约束：**不产出任何数值、单位、速率**；**不作诊断、不作正常与异常的判定**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是给处置，而是把一段关于水电解质状态的描述放上「容量 × 渗透」两个正交轴，并指出哪一步越界。

【输入】
原话：<一段描述，可以带结论，可以带数值>
讲义定位：<补充·hermes-病理生理学讲义·第N章·N.M>

【任务，按顺序回答，不跳步】
1. 拆结论：原话里哪些词是结论（低钠、脱水、水肿、容量不足），哪些是观察（体重变化、出入量、颈静脉充盈、黏膜、意识、尿量）。两类分开列。
2. 容量轴：把观察归到容量这一轴，给出方向（不足 / 正常 / 过多）与依据；依据不足就写不足，不补猜。
3. 渗透轴：把血钠方向与神经系统症状归到渗透这一轴，给出方向（低渗 / 等渗 / 高渗）与依据；并说明这是浓度判断，不是总量判断。
4. 落格：在两轴组成的五类机制类别里落一格，说明为什么不是相邻那一格。
5. 第二条线索：钾、钙、镁各自的分布与排出线索有没有被提到？缺哪条写缺。
6. 有效循环血量：这段描述里有没有「总体多而循环不足」的可能（水肿伴低钠、心衰、肝硬化、肾病综合征）？有就单列。
7. 速度：这段描述给的是「多少」还是「多快」？两者是否分开写了？
8. 越界清单：指出属于个体判定（诊断、严重程度、处置方向、疗效）的成分，逐条给出中性改写。
9. 边界：这段定位不能回答什么。

【硬约束】
- 不给任何数值、单位、正常值、参考区间、百分比、纠正速率。凡需数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作正常与异常判定；不写补液种类与剂量。
- 引讲义原文必须逐字，并标「补充·hermes-病理生理学讲义·第N章·N.M」；核不到就不引。
- 两轴说不清就写说不清，不许用「容量有点问题」把轴糊过去。

【输出格式】
九个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的拆解（节选）

原话：「患者水肿，血钠低，考虑容量过多，先利尿。」讲义定位：补充·hermes-病理生理学讲义·第24章·24.6。

- **拆结论**：结论是「容量过多」「先利尿」；观察只有「水肿」与「血钠低」两项，其余全是判断。
- **容量轴**：水肿提示总体钠水增多，但方向不能定——需要颈静脉充盈、体重变化、体位性血压与心率反应；这些都没给，写「容量方向待定」。
- **渗透轴**：血钠低指向低渗，属浓度判断；不能由此推体内钠总量少。
- **落格**：可能落在「容量过多 + 低渗」，但同样可能落在「容量不足 + 低渗」（有效循环血量不足时的稀释性低钠）。两格的处理方向相反，故必须先补容量线索。
- **第二条线索**：钾、钙、镁三条都没提。利尿剂使用者尤须补钾与镁的分布与排出线索。
- **有效循环血量**：这正是本例的关键——水肿伴低钠是典型的「总体多而循环不足」，单纯强力利尿会进一步激活 RAAS。
- **速度**：只给了「多少」的方向，没有「多快」。两者须分开写。
- **越界清单**：「考虑容量过多」「先利尿」都是处置判断，改为「容量方向待定，需补容量线索与有效循环血量判断」。
- **边界**：不能由此决定任何处置；数值与速率一律不给。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 用结论替代观察 | 「低钠，限水」 | 先列观察，再谈方向 |
| 把浓度当容量 | 「血钠低说明缺钠」 | 补一句：血钠是浓度，不携带总量信息 |
| 一轴定全局 | 只看血钠就落格 | 两轴交叉，缺一轴写缺 |
| 忽略有效循环血量 | 水肿即利尿 | 水肿伴低钠先问循环是否充足 |
| 把速度当量 | 「变化不大，问题不大」 | 量与时相分开写 |
| 偷给速率 | 「每小时不超过多少」 | 触发硬约束，改为「本书不给值」 |

## 边界

本模板训练的是「一句结论 → 两轴定位 → 第二条线索 → 越界改写」的拆解能力，不产生临床处置。框架取自本仓库原创《hermes-病理生理学讲义》第 24 章；数值、速率与判定不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
