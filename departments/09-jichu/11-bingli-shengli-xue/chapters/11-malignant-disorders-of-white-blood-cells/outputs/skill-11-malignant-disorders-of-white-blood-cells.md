# Skill：白细胞恶性肿瘤——三轴定位、四机制归位

## 何时用

- 一段血象、骨髓报告或病程记录里塞了三四个病名，讨论开始滑向「这到底是哪一种」
- 有人用「白细胞不高」「惰性」「慢性」当作排除某个方向的条件
- 要把贫血、感染、出血、淋巴结肿大四组表现写成一份评估，却担心拆成四个互不相干的条目
- 要判断一段叙述有没有把行为轴（惰性 / 侵袭性）与良恶轴（良性 / 恶性）混用

## 核心判据（四问）

1. **哪一系？** 髓系、淋系、浆细胞。谱系决定可用的表型标记，也决定疾病名称的前半段。
2. **停在哪一层？** 急性＝阻滞在很早的层级（以原始细胞为主、进展快）；慢性＝阻滞在较晚的层级（较成熟细胞仍能生成而数量失控）。成熟度是阻滞位置，不是严重程度。
3. **占了哪儿？** 骨髓为主、淋巴组织为主、浆细胞（骨髓内聚集 + 单克隆蛋白）。部位决定临床表现的重心。
4. **哪条机制在动？** 骨髓正常造血受抑、髓外浸润与占位、细胞因子释放、免疫功能异常。四条里能解释最多条表现的那一条就是主线。

## 执行步骤

```text
1. 抄原文，不改写：把描述原样放在第一行
2. 定三轴：谱系 / 成熟度 / 部位，各写一句，缺的写「未给」
3. 归机制：每条表现归到四条机制之一，归不进的单列，不硬塞
4. 找主线：能解释最多条机制的那一条，写成一句话；其余标为派生
5. 查反直觉点：白细胞不高、惰性、慢性、成熟——逐个说明为何不能当排除条件
6. 报缺项：缺哪一轴、缺哪条检查类别（血液学 / 骨髓 / 免疫表型 / 遗传分子 / 影像）
7. 报边界：不分型、不预后、不给治疗与参数、不给任何数值
```

## 硬约束

- **不给数值、单位、阈值、参考区间、百分比。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不作诊断，不作分型。** 讲义明写只到类别层面，精确分型依赖形态学、免疫表型、细胞遗传与分子检测的综合，属诊断学范围。
- **不写治疗方案与参数。** 治疗只作类别（化学治疗、靶向治疗、免疫治疗、放射治疗、移植），并发症只作机制推论。
- **引文逐字。** 标「补充·hermes-病理生理学讲义·第11章·N.M」；核不到就不引。讲义不是外文教材的译本，不许标成「教材」。
- **一个轴一句话。** 惰性 / 侵袭性 与 良性 / 恶性 不在一句里混用；「急性 / 慢性」不承担严重程度。

## 交付物

1. 三轴定位一句话（谱系 · 成熟度 · 部位），缺项标「未给」
2. 一张四机制归位表：表现 → 机制 → 是否主线
3. 一句主线陈述：哪条机制收住了最多表现
4. 一份反直觉点清单：哪几个词容易被当排除条件，为什么不行
5. 一处边界：不分型、不预后、不给值

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 病名先行 | 机制被病名带着走，只找该病的「典型」表现 | 先写机制，再写病名 |
| 计数当病情 | 白细胞不高就排除白血病方向 | 回到骨髓占位，三种计数方向都成立 |
| 四机制拆四病 | 一组表现给四个诊断 | 一元论收回一条主线 |
| 惰性当良性 | 把行为轴读成良恶轴 | 只用行为轴表述：增殖与凋亡之比慢 |
| 慢性当承诺 | 认为不会急变 | 慢性是当前阻滞位置，急变是再改变的结果 |
| 偷给阈值 | 说原始细胞超过多少比例才算 | 触发硬约束，改为「本书不给值」 |

## 边界

本 Skill 只处理「一段描述 → 三轴 → 四机制 → 缺项」的结构化还原，不涉及分型、预后与治疗决策。框架取自《hermes-病理生理学讲义》第 11 章的类别与机制；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
