# Prompt：把一份白细胞肿瘤的描述还原成「三轴 + 四机制」

## 用途

白细胞肿瘤这一块的名字密度极高，病例讨论里最常出现的失败不是记不住病名，而是被病名牵着走：一看到「淋巴瘤」就去找淋巴结，一看到「骨髓瘤」就只谈骨痛，结果把同一组机制拆成了互不相干的条目。这个模板不补病名、不做分型，而是把一段描述压回两个位置：**三个坐标轴**（哪一系、什么成熟度、占了哪儿）与**四条机制**（造血受抑、髓外浸润、细胞因子、免疫功能异常）。适用于病例讨论前的自检、血象与骨髓报告的读法训练，以及写护理评估时的机制归位。

## 使用前提

- 你面对的是一段**描述**（血象、骨髓报告的文字结论、病程记录），不是一份待确诊的病例。
- 你手边有讲义定位（`补充·hermes-病理生理学讲义·第11章·11.4` 这一级），读过对应节。
- 你接受三条硬约束：**不产出任何数值与阈值**；**不作诊断与分型**；**不写治疗方案与参数**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是给病名，而是把一段描述还原到三轴与四条机制上，并指出哪一处还缺。

【输入】
原文：<一段血象 / 骨髓报告 / 病程记录的描述，可带病名>
讲义定位：<补充·hermes-病理生理学讲义·第N章·N.M>

【任务，按顺序回答，不跳步】
1. 分轴：这段描述落在哪一系（髓系 / 淋系 / 浆细胞）？成熟度是急性还是慢性（以原始细胞为主，还是以较成熟细胞为主）？主要部位在骨髓、淋巴组织还是浆细胞？
2. 定机制：把描述里的每条表现归到四条机制之一——骨髓正常造血受抑、髓外浸润与占位、细胞因子释放、免疫功能异常。归不进去的，单独列出，不硬塞。
3. 找主线：四条机制里哪一条能解释最多条表现？用一句话写出这条主线，其余表现作为它的派生。
4. 查反直觉点：这段描述里有没有「白细胞不高」「长得慢」「慢性」这类容易被读成排除条件的词？逐个说明它们为什么不能当排除条件。
5. 缺项：描述里缺哪一轴、缺哪条机制？缺就写缺，不推测。
6. 边界：这段还原不能回答什么（分型、预后、治疗选择）。

【硬约束】
- 不给任何数值、单位、阈值、参考区间、百分比。凡需数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作分型判定，不作预后判断，不给治疗方案与剂量。
- 引讲义原文必须逐字，并标「补充·hermes-病理生理学讲义·第N章·N.M」；核不到就不引。
- 「惰性 / 侵袭性」与「良性 / 恶性」是两个轴，一段话里只用一个。

【输出格式】
六个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的还原（节选）

原文：「老年男性，乏力、体重下降，脾大，血象见成熟小淋巴细胞增多，淋巴结多发肿大。」讲义定位：补充·hermes-病理生理学讲义·第11章·11.5。

- **分轴**：淋系；成熟度偏慢性（以较成熟的小淋巴细胞为主，不是原始细胞为主）；部位以淋巴组织与脾为主，骨髓亦受累。
- **定机制**：乏力与体重下降归细胞因子释放；淋巴结与脾大归髓外浸润与占位；成熟淋巴细胞蓄积本身是克隆性增殖的直接结果，不属四条里的任何一条，单列。
- **找主线**：主线是「克隆性成熟小淋巴细胞在血、骨髓、淋巴结与脾中蓄积」，脾大与淋巴结肿大是它的派生，乏力与体重下降走细胞因子那条。
- **查反直觉点**：「成熟」不等于「良性」，也不等于「不会转急」；「慢性」描述的是当前的阻滞位置。
- **缺项**：缺免疫表型与遗传学信息，因此不能定谱系内的具体类别；缺免疫球蛋白水平，无法判断感染风险来自哪一侧。
- **边界**：不能回答分型、分期、预后与治疗选择；数值一律不给。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 用病名替代机制 | 「这是淋巴瘤，所以淋巴结大」 | 先写机制（髓外浸润与占位），再写病名 |
| 把计数当病情 | 「白细胞不高，先排除白血病」 | 回到骨髓占位这条主线，三种计数方向都成立 |
| 四条机制拆成四种病 | 贫血、感染、出血、淋巴结肿大各给一个诊断 | 用一元论收回一条主线，再点明共用起点 |
| 惰性读成良性 | 「惰性的，不用管」 | 换成行为轴的说法：增殖与凋亡之比慢，不等于无侵袭能力 |
| 偷给阈值 | 「原始细胞超过两成就……」 | 触发硬约束，改为「本书不给值」 |
| 把治疗写成处置 | 「应该马上化疗」 | 只写机制推论（如骨髓抑制期的次序），方案交回临床 |

## 边界

本模板训练的是「描述 → 三轴 → 四机制 → 缺项」的还原能力，不产生临床判断。分类框架取自《hermes-病理生理学讲义》第 11 章的类别与机制；数值、分型与治疗不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
