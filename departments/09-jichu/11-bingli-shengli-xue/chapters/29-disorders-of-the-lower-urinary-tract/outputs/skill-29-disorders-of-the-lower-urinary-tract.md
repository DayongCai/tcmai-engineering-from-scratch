# Skill：下尿路疾病——三组症状、三个环节、一条分界线

## 何时用

- 面对尿频、尿急、排尿费力、漏尿、尿不尽这类主诉，需要先归位再谈病名
- 要判断「还能尿出来」是否等于排空
- 要分辨四型尿失禁，避免把充盈性当急迫性
- 要在反复尿路感染里把注意力从用药转向结构

## 核心判据（四问）

1. **哪一段？** 上尿路（伤肾：腰痛、血尿、绞痛）还是下尿路（伤排尿：尿频、尿急、尿失禁、排尿费力）。唯一通路是下病上及：长期下尿路梗阻可经双侧上尿路积水累及肾功能。
2. **哪一组？** 储尿期（储不住）／排尿期（排不出）／排尿后（排不尽）。三组的组合本身就有方向：单纯储尿期多为膀胱或神经，储尿加排尿并存多见于出口梗阻继发逼尿肌改变，排尿后突出提示残余尿。
3. **哪个环节？** 神经（三级调控：外周三支、骶髓反射、脑桥与皮层抑制）／出口（阻力）／膀胱（收缩力与容量）。每个症状只挂一个主环节。
4. **两套开关哪一套坏了？** 储尿期应是膀胱松弛、出口关闭；排尿期应是膀胱收缩、出口开放。坏在哪一句，直接写出来。

## 执行步骤

```text
1. 抄主诉：症状原样列出，不改写、不合并
2. 分界：上尿路 / 下尿路；顺手核一次下病上及的风险
3. 分组：储尿期 / 排尿期 / 排尿后，逐条归属
4. 挂环节：神经 / 出口 / 膀胱；挂不上写未定并注明缺哪项评估
5. 核开关：两个状态里哪一个被破坏
6. 核不平行：症状响度与客观发现是否可能不一致；列出该补的客观项
7. 中性改写：删掉诊断、轻重、梗阻程度、预后四类判定
8. 报边界：不给值，不写处置
```

## 硬约束

- **不给数值、单位、参考值、百分比。** 残余尿、尿流率、导尿频次一律不给值；追问统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不作诊断，不作轻重与梗阻程度判定。** 三组症状是分类框架，不是诊断标准；症状响度与梗阻程度不平行这一条本身就否掉了以症状定轻重。
- **引文逐字。** 标「补充·hermes-病理生理学讲义·第29章·29.M」；核不到就不引，不得标成「教材」。
- **还能尿出来不等于排空。** 排尿后症状与残余尿要单独核。
- **不写处置。** 导尿、药物类别、手术选择、抗生素方案，只写机制与观察方向。

## 交付物

1. 一张归位表：主诉 → 分组 → 环节
2. 一句开关判断：储尿期还是排尿期的那一句被破坏
3. 一份客观项清单：为核对不平行该补哪些评估
4. 一段中性改写：删掉四类判定后的版本
5. 一处边界：不给值、不判轻重，数值须另立数据层

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 主诉直接变病名 | 「这是前列腺增生」 | 先分组，再挂环节 |
| 漏查排尿后症状 | 残余尿被忽略 | 补尿不尽感与客观评估 |
| 充盈性当急迫性 | 用药可能加重尿潴留 | 四型先分辨，再看方向 |
| 反复感染只换药 | 筛选耐药菌 | 找结构：梗阻、结石、反流、导管 |
| 只盯尿失禁 | 高压型神经源性膀胱伤上尿路 | 追膀胱内压方向与上尿路随访 |
| 报参考值 | 越界且无来源 | 统一回「本书不给值」 |

## 边界

本 Skill 只处理「一句主诉 → 三组症状 → 三个环节」的结构化拆解，不涉及数值、判定与临床决策。功能框架取自《hermes-病理生理学讲义》第 29 章；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
