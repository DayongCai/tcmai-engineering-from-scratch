# Skill：急性肾损伤与慢性肾脏病——一条主线、两条时间轴、代偿的代价

## 何时用

- 面对一段肾功能变化记录，需要先定急慢与部位，而不是先给病名或分期
- 要解释「为什么病因去掉了肾功能还在掉」——需要把代偿的代价讲出来
- 要判断一句「恢复了就没事」「没症状就稳定」是否越界
- 要在多系统后果里排出观察顺序，而不是平均用力

## 核心判据（四问）

1. **多快？** 数小时至数日（细胞损伤与功能抑制、结构多完整、可逆空间大）还是数月到数年（硬化与纤维化、不可逆、代偿空间逐步耗尽）。依据是起病方式与可逆性，不是时限数值。
2. **哪一段？** 肾前（灌注，尿浓而省）／肾性（实质，尿淡而费）／肾后（梗阻，解除后可速复）。三类可互转，功能性可转为器质性。
3. **代偿还剩多少？** 储备尚可／已在高流量高压力工况／已失代偿。写「代偿良好」时必须同时写代价：高滤过、蛋白尿、间质炎症。
4. **谁先致命？** 多系统后果按多快能致命排序，高钾居首；排序是观察顺序，不是评分。

## 执行步骤

```text
1. 抄记录：把时间点与观察项逐条列在左边，不改写
2. 定时间轴：写「起病方式 + 可逆性」，不写时限数值
3. 定部位：肾前 / 肾性 / 肾后；缺线索写未定，并注明缺哪项
4. 定代偿：三选一，写「良好」时必须补代价
5. 定方向：急性启动慢性，还是急性-on-慢性
6. 排顺序：多系统后果按致命速度排，最急的放第一
7. 中性改写：删掉诊断、分期、轻重、预后、疗效五类判定
8. 报边界：不给界值，不写处置
```

## 硬约束

- **不给数值、单位、正常值、分期界值、百分比。** 讲义明确不给任何分期界值；追问统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不作诊断，不作预后判定。** 「可逆」「不可逆」是机制属性，不是对个体的判断。
- **引文逐字。** 标「补充·hermes-病理生理学讲义·第28章·28.M」；核不到就不引，不得标成「教材」。
- **代偿不写成修复。** 代偿是顶住总量，代价写在每个剩余单位上。
- **不写处置。** 高钾处理、替代治疗时机与处方、用药调整，只写机制与观察方向。

## 交付物

1. 一张三层表：时间轴 → 部位 → 代偿状态
2. 一句方向判断：急性启动慢性，或急性-on-慢性
3. 一份排序清单：多系统后果按致命速度排列
4. 一段中性改写：删掉五类判定后的版本
5. 一处边界：不给界值、不作预后，数值须另立数据层

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 代偿写成修复 | 慢性化机制整段丢失 | 补高滤过与间质炎症的代价 |
| 急性慢性当成两病 | 互为因果解释不了 | 回到一条主线，两条时间轴 |
| 三类不分 | 检查方向乱 | 先定肾前 / 肾性 / 肾后 |
| 尿少才算危险 | 恢复期多尿被漏掉 | 记住恢复期是最易被忽视的危险期 |
| 等症状再查 | 延误（症状天然滞后） | 早期就看浓缩功能、夜尿、蛋白尿 |
| 报分期界值 | 越界且无来源 | 统一回「本书不给值」 |

## 边界

本 Skill 只处理「一段变化 → 三层 → 中性表述」的结构化拆解，不涉及数值、判定与临床决策。机制取自《hermes-病理生理学讲义》第 28 章；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
