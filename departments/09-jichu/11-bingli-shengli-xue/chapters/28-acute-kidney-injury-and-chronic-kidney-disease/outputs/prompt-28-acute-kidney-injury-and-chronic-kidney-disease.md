# Prompt：把一次「肾功能下降」拆成时间轴、部位与代偿状态

## 用途

「肾功能下降」这句话把三件事压成了一件：多快下降的、哪一段受损、代偿还剩多少。本章的模板不让你先给病名，而是把这句话逼到三个位置上，并检查叙述有没有把代偿写成好消息、把可逆写成结论。

适用场合：读一份肾功能变化记录、给一次急性事件归位、判断一句「恢复了就没事」是否成立。

## 使用前提

- 你面对的是**一段时间内的变化描述**（几条记录、几句观察），不是一份待确诊的病历。
- 你读过讲义第 28 章的对应小节，能给出 `补充·hermes-病理生理学讲义·第28章·28.M` 这一级定位。
- 你接受两条硬约束：**不产出任何数值与界值**；**不作诊断、不作预后判定**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是给病名，而是把一段「肾功能下降」的描述拆成三层，并指出哪一层越界。

【输入】
原话：<一段变化描述，可以带病名、可以带判断>
讲义定位：<补充·hermes-病理生理学讲义·第28章·28.M>

【任务，按顺序回答，不跳步】
1. 时间轴层：这段变化是数小时到数日的方向，还是数月到数年的方向？依据写「起病方式 + 是否可逆」，不写时限数值。
2. 部位层：属肾前（灌注）、肾性（实质）、肾后（梗阻）中的哪一类？
   若线索不足，写「部位未定」，并说明缺哪一项（容量状态 / 尿的浓淡方向 / 影像与排尿评估）。
3. 代偿层：残余单位的代偿还有多少空间？
   写三选一：储备尚可 / 已在高流量高压力工况 / 已失代偿。
   若写「代偿良好」，必须同时写出代价（高滤过、蛋白尿、间质炎症），不许只写好消息。
4. 因果核对：这一段是急性启动慢性，还是慢性上叠加急性（急性-on-慢性）？两条方向都没有就写「单向」。
5. 排序层：若出现多系统后果，按「多快能致命」排序，不按系统罗列；把最急的一栏放在第一句。
6. 越界清单：原话里哪些成分是判定（诊断、分期、轻重、预后、疗效）？逐条摘出，给中性改写。
7. 边界：这段拆解不能回答什么。

【硬约束】
- 不给任何数值、单位、正常值、分期界值、百分比。凡需数值的追问，统一回：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作正常与异常判定，不作预后判定，不写处置与用药。
- 引讲义原文必须逐字，并标「补充·hermes-病理生理学讲义·第28章·28.M」；核不到就不引。
- 「可逆」在文中是机制属性，不许写成对某个人的判断。

【输出格式】
七个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的拆解（节选）

原话：「他前两天脱水，肌酐高了一点，补液后降回来了，说明肾没事了。」讲义定位：补充·hermes-病理生理学讲义·第28章·28.3。

- **时间轴层**：数小时到数日，起病方式为容量不足，补液后可回落——方向上属可逆那一支，但不写成「已恢复」。
- **部位层**：脱水指向肾前性；讲义给的鉴别方向是肾前性者尿浓而省，若记录里有尿的浓淡，用它坐实部位；没有就写「部位倾向肾前，待尿的方向确认」。
- **代偿层**：不能写「代偿良好」。要写的是：此次为肾前性、结构多完整；但一次严重打击可使部分肾单位永久丧失，代偿的代价是把剩余单位推到高流量高压力工况。
- **因果核对**：单向（急性），未见慢性背景；若此人有慢性背景，则要按急性-on-慢性重写。
- **排序层**：本例未见多系统后果，写「未见」，不虚构分栏。
- **越界清单**：「说明肾没事了」是预后判定，摘掉；改成「本次变化方向可逆，后续观察项为尿量、体重与尿的浓淡方向」。
- **边界**：不能由此判断此人的长期走向，也不给任何界值与处置。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 把代偿写成好消息 | 「剩下的肾单位顶上来了」 | 补代价：高滤过、蛋白尿、间质炎症 |
| 用「恢复」替代「可逆」 | 「已经恢复正常」 | 写机制属性：结构多完整、方向可逆 |
| 三类不分 | 「就是肾功能不全」 | 先定肾前 / 肾性 / 肾后，缺线索就写未定 |
| 症状导向 | 「没症状，所以稳定」 | 补一句：症状在时间轴上天然滞后 |
| 八栏平均用力 | 逐系统罗列后果 | 按多快能致命排序，最急的放第一句 |
| 偷给界值 | 「到了某一期就该透析」 | 触发硬约束，改为本书不给值 |

## 边界

本模板训练的是「一段变化 → 三层 → 中性表述」的拆解能力，不产生临床判断。机制与排序取自《hermes-病理生理学讲义》第 28 章；界值、处置与个体判定不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
