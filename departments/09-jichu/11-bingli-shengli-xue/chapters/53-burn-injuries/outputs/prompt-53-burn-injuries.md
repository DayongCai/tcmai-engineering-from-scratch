# Prompt：把一处烧伤分成两层，再找出链上可干预的节点

## 用途

烧伤这一章的组织方式是两层加一条链：局部一层（三层带、深度、面积）与全身一层（渗漏、炎症、代谢、感染、器官），两层之间双向。这个模板不让你背分级表，只让你对一段烧伤经过做三件事：先定淤滞带保住了没有，再按时间把全身反应排开，最后在链上找出可干预的节点。适用于交班前的机制自查、护理计划的逻辑校核，以及把「为什么水肿不等于补够了」讲清。

## 使用前提

- 你面对的是一段**经过描述**（致伤源与接触情况、部位、创面外观、时间线、全身状态），不是一份诊断。
- 你手边有讲义定位（`补充·hermes-病理生理学讲义·第53章·53.2` 这一级），读过对应小节。
- 你接受三条硬约束：**不产出任何数值**；**不作诊断与判定**；**不给公式、剂量与速率**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是给结论，而是把一段烧伤经过分成局部与全身两层，再在链上指出可干预的节点，并说明这段推演回答不了什么。

【输入】
原话：<一段经过描述，可以带判断>
讲义定位：<补充·hermes-病理生理学讲义·第N章·N.M>

【任务，按顺序回答，不跳步】
1. 能量：热力、化学、电、其他？只选一类，并写出这一类的损伤特点（例如电烧伤体表轻而深部重）。
2. 三层带：凝固带、淤滞带、充血带各占什么位置？重点判淤滞带的转归条件。
3. 深度：按层次命名（表皮性、浅层部分真皮、深层部分真皮、全层、更深结构），只写类别，不写分度。
4. 储备：上皮储备还在不在？据此判能不能自行上皮化。
5. 全身四路：渗漏与容量、炎症与两次打击、代谢与分解、免疫与感染，逐路写一句，并标「已出现 / 在路上」。
6. 时相：现在处在渗漏期还是回收期？这一步决定复苏的方向，不写数值。
7. 可切断处：链上哪三处可被干预？只写节点类别（保温、灌注、镇痛、感染监测、营养、体位、心理支持）。
8. 边界：这段推演不能回答什么。

【硬约束】
- 不给任何数值、单位、正常值、面积百分比、深度分度、补液公式、剂量与速率。
  凡需数值才能回答的追问，统一回答：「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作正常与异常判定，不作预后预测。
- 不写药物、敷料种类与更换参数；只写目标与原则类别。
- 引讲义原文必须逐字并标「补充·hermes-病理生理学讲义·第53章·N.M」；核不到就不引。

【输出格式】
八个小标题各答一到两句；第 3 问只写层次类别；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的推演（节选）

原话：「右手掌被热油泼到，当时只红了，第二天起了几个水疱，基底发白发干，按下去不褪色，说疼得没那么厉害了。」讲义定位：补充·hermes-病理生理学讲义·第53章·53.3。

- **能量**：热力（热液），接触时间被油温延续。
- **三层带**：中心凝固带已定；周边淤滞带转归未定，是这一例的关键。
- **深度**：按层次记为深层部分真皮（基底干、按压不褪色、痛觉减退），须随时间修正。
- **储备**：残留附件还在，有上皮化可能，但瘢痕风险高。
- **全身四路**：渗漏在路上、炎症已启动、代谢应激开始、感染风险随创面存在。
- **时相**：仍在渗漏期，重点是灌注与保温，不写数值。
- **可切断处**：灌注、保温、感染监测三处，只写类别。
- **边界**：不能判断任何人的最终深度与结局，深度须系列评估。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 一次定深度 | 入院当天写死几度 | 回到三层带：淤滞带未定，系列评估 |
| 水肿当补够 | 看水肿判断容量 | 水肿是渗漏的证据，不是容量的证据 |
| 照公式补液 | 算完即输完 | 以灌注指标为终点，随时相调整 |
| 只看创面 | 漏掉气道与尿色 | 器官并发症要按四路同时看 |
| 过度降温 | 大面积冲洗致低体温 | 冷却与保温按面积取舍 |
| 越过分度 | 直接报百分比与剂量 | 只写层次类别与节点 |

## 边界

本模板训练的是「两层 → 时相 → 节点」的推演，不产生临床判断。层次与反应类别取自本仓库原创讲义第 53 章（53.1–53.13）；数值、判定、公式与方案均不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
