# Skill：烧伤——局部三道带、四路全身反应与一条把两者接起来的链

## 何时用

- 一段描述里出现烧伤创面，需要先判淤滞带保住了没有，再谈其他
- 要解释创面为什么会在伤后几天里自己变深
- 要把「水肿明显而容量不足」「体温既可能低也可能高」这两处反直觉讲清
- 要判断现在处在渗漏期还是回收期，以决定复苏方向（不写数值）
- 遇到「几度」「多少面积」「补多少」这类追问，需要一致的拒答口径

## 核心判据（五问）

1. **哪种能量？** 热力（温度与时间的组合）、化学（碱向深部穿透）、电（体表轻而深部重）、其他（放射、摩擦、冻伤）。
2. **三层带各在哪？** 凝固带不可逆、范围由能量决定；淤滞带可逆，是唯一可干预窗口；充血带多可自行恢复。
3. **深度按哪一层？** 表皮性、浅层部分真皮、深层部分真皮、全层、更深结构——按层次命名，不用分度。
4. **全身四路走到哪？** 渗漏与容量、炎症与两次打击、代谢与分解、免疫与感染；再叠加器官并发症。
5. **时相在哪一段？** 渗漏期需积极容量支持，回收期需主动减量——方向相反。

## 执行步骤

```text
1. 抄原话，不改写：把要推的那段放在第一行
2. 定能量：四类选一类，写出该类的损伤特点
3. 分三带：重点判淤滞带的转归条件（灌注、保温、感染、压迫）
4. 定深度：按层次命名，并声明须随时间修正
5. 判时相：渗漏期还是回收期，写方向不写数值
6. 排全身：四路各一句，标已出现或在路上
7. 找节点：保温、灌注、镇痛、感染监测、营养、体位、心理支持，各对链上一环
8. 报边界：不给值、不给分度、不给公式与剂量
```

## 硬约束

- **不给数值、单位、正常值、面积百分比、深度分度、补液公式、剂量与速率。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」；临床以所在机构的分诊标准与专科方案为准。
- **不作诊断，不作正常与异常判定。** 三层带是机制模型，不是判读工具；层次是客观的类别，不是分度。
- **不写药物、敷料种类与更换参数。** 讲义明说不提供公式、剂量与速率，也不涉材料种类。
- **不把一次评估当结论。** 深度判断在伤后早期不可靠，系列评估优于单次判断。
- **引文逐字。** 标`补充·hermes-病理生理学讲义·第53章·N.M`；核不到就不引。讲义是本仓库原创正文，不写成任何外文教材的译本。

## 交付物

1. 一句能量判断与一句三带判断（含淤滞带转归条件）
2. 一句深度判断（层次类别）与一句储备判断
3. 一句时相判断（渗漏期或回收期）
4. 四路全身反应各一句，标已出现或在路上
5. 三处可干预节点（只写类别）
6. 一张越界清单：把「几度」「多少」这类追问改成类别回答
7. 一处边界：不给值、不作诊断、不给方案

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 一次定深度 | 漏掉淤滞带的转归 | 系列评估优于单次判断 |
| 水肿当补够 | 延误复苏 | 水肿是渗漏的证据 |
| 照公式补液 | 回收期容量超负荷 | 以灌注指标为终点，随时相调整 |
| 只盯创面 | 漏掉气道与尿色 | 四路加器官同看 |
| 大面积冷却 | 诱发低体温 | 冷却与保温按面积取舍 |
| 体温当方向 | 低体温与感染混淆 | 双向偏离，须结合保温与感染两条线索 |

## 与相邻章节的接缝

- 皮肤系统异常：本章的渗漏与失水是那一章经皮失水的极端情形；「附属器是上皮储备」在深度类别里兑现为能否自行上皮化。
- 休克一章：本章休克属分布性加低容量性的混合类型，与失血性休克机制不同——丢失血浆成分而非全血，且发生在全身。
- 炎症与感染相关章节：两次打击与细菌移位是那一批章节在烧伤上的具体展开。
- 护理实践：保温、灌注、镇痛、感染监测、营养、体位与心理支持七项可直接落到流程；判断、处方与公式属资质与规范一侧。

## 边界

本 Skill 只处理「两层 → 时相 → 节点」的结构化推演，不涉及数值、判定与临床方案。层次与反应类别取自本仓库原创讲义第 53 章；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
