# Prompt：先分清是饿还是烧，再谈补什么

## 用途

代谢与营养这一章的难点不在营养素清单，而在两种方向相反的代谢模式：饥饿以降消耗、省蛋白为方向，应激以高代谢、持续分解为方向。这个模板不让你开食谱，只让你把一段描述落到模式上，再判断补充该快还是该慢。适用于讨论课的机制推演、营养风险筛查后的结构化整理，以及读病程记录时确认每一句话落在哪种模式里。

## 使用前提

- 你面对的是一段**描述**（进食情况、体重变化、病程与治疗经过），不是一份诊断或营养处方。
- 你手边有讲义定位（`补充·hermes-病理生理学讲义·第42章·42.6` 这一级），读过对应小节。
- 你接受三条硬约束：**不产出任何数值**；**不作诊断与判定**；**不给剂量与膳食方案**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是给食谱，而是把一段描述落到代谢模式上，并说明补充该快还是该慢。

【输入】
原话：<一段描述，可以带病名、可以带判断>
讲义定位：<补充·hermes-病理生理学讲义·第42章·N.M>

【任务，按顺序回答，不跳步】
1. 定模式：当下是饥饿型（降消耗、省蛋白）还是应激型（高代谢、持续分解）？两者并存时说明以哪一侧为主。
2. 读五项对照：代谢率方向、主要燃料、蛋白去留、血糖方向、营养支持效果，逐条只写方向。
3. 找转折点：若为饥饿型，燃料切换走到哪一步——糖原、糖异生，还是酮体？
4. 评风险：是否存在再喂养风险（长期摄入不足、体重显著下降、酒精使用障碍、长期禁食）？
5. 定节奏：补充应缓慢启动还是先控制原发病？只写方向，不写速度与剂量。
6. 查维度：体重变化的速度与幅度、功能指标、摄入与消化，三条各有没有线索？
7. 越界清单：把原话里的判定成分与评价性措辞逐条指出，给出中性改写。
8. 边界：这段推演不能回答什么。

【硬约束】
- 不给任何数值、单位、正常值、参考区间、百分比。凡需数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作营养状态的判定，不作预后判定。
- 不给膳食方案与补充剂量；只写模式、节奏与监测方向。
- 不作价值判断：不把体重变化归因于意志力，只写机制类别。
- 引讲义原文必须逐字并标「补充·hermes-病理生理学讲义·第42章·N.M」；核不到就不引。

【输出格式】
八个小标题各答一到两句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/营养处方。」
```

## 示例：一次合格的分流（节选）

原话：「他做完大手术第五天，人瘦了一圈，家里想赶紧给他补回来。」讲义定位：补充·hermes-病理生理学讲义·第42章·42.6。

- **定模式**：应激型为主，术后分解代谢占优。
- **五项对照**：代谢率升、燃料混合且糖异生显著、蛋白持续分解、血糖偏高方向、营养支持只有部分有效。
- **找转折点**：不适用——这不是燃料切换，而是强制分解。
- **评风险**：术后长期禁食或仅静脉输液者属再喂养风险人群，须在补充前评估电解质与容量。
- **定节奏**：先控制原发病（感染、疼痛、容量不足），补充循序渐进，不追求一次补足。
- **查维度**：体重看变化的速度与幅度；握力与行走能力是功能线索；记录实际摄入量。
- **越界清单**：「瘦了一圈」改为「体重较术前下降」，去掉推断，保留方向。
- **边界**：不给能量与蛋白的量，也不判断营养状态的分级。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 把两种模式混读 | 用补饥饿的办法对待应激 | 先读五项对照 |
| 追求一次补足 | 短期大量供能 | 缓慢启动、逐步增加 |
| 只看体重 | 忽略水肿与肌肉量 | 加功能指标与腰围 |
| 把肥胖归因于意志力 | 讨论失焦、护患对抗 | 只写机制类别 |
| 用单一比值定性 | 肌肉发达者被误判 | 结合腰围、功能与背景 |
| 越过方案 | 直接给食谱与剂量 | 只写模式与节奏 |

## 边界

本模板训练的是「描述 → 模式 → 节奏 → 边界」的分流，不产生临床判断与营养处方。机制与干预原则的类别取自本仓库原创讲义第 42 章（42.1–42.12）；数值、判定与膳食方案均不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
