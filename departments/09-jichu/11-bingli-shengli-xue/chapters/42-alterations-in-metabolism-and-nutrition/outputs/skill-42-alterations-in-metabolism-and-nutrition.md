# Skill：代谢与营养异常——一个调定点、两种代谢模式与一条再喂养链

## 何时用

- 一段描述里出现体重下降、进食减少或术后消瘦，需要先分清是缺还是烧
- 要判断“补得越快越好”这句话在当下情形里对不对
- 要解释为什么减重后容易反弹，需要一套不带评价的机制说法
- 要评估营养状态，却只有一个体重或一个比值可用
- 遇到“吃多少”“补多少”这类追问，需要一致的拒答口径

## 核心判据（五问）

1. **饥饿还是应激？** 代谢率方向、主要燃料、蛋白去留、血糖方向、营养支持效果，五项对照里至少三项一致才能定模式。
2. **燃料走到哪一步？** 糖原、糖异生，还是酮体——这一步决定了蛋白丢失的速度。
3. **有没有再喂养风险？** 长期摄入不足、体重显著下降、酒精使用障碍、长期禁食或仅静脉输液、老年与消耗性疾病。
4. **补充该快还是该慢？** 饥饿型缓慢启动、逐步增加；应激型先控制原发病，营养支持是辅助。
5. **评估够不够多维？** 体重看变化的速度与幅度，加功能指标、摄入与消化、社会心理。

## 执行步骤

```text
1. 抄原话，不改写：把要分流的描述放在第一行
2. 定模式：五项对照逐条写方向，不写数值
3. 找转折点：饥饿型要指出燃料切换的位置
4. 评风险：再喂养的高危情形逐条过
5. 定节奏：缓慢启动 or 先控制原发病
6. 查维度：变化速度、功能指标、摄入与消化
7. 中性改写：删掉评价性措辞，保留机制与时间线索
8. 报边界：不给值、不作判定、不开食谱
```

## 硬约束

- **不给数值、单位、正常值、参考区间、百分比。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不作诊断，不作营养状态的判定。** 两型营养不良与代谢综合征只作机制类别，不用于给个体定性。
- **不给膳食方案与剂量。** 热量、蛋白量、补充速率属个体化医疗决策；本 Skill 只写模式、节奏与监测方向。
- **不作价值判断。** 体重变化不归因于意志力；理由是机制上的，也是沟通上的。
- **引文逐字。** 标`补充·hermes-病理生理学讲义·第42章·N.M`；核不到就不引。讲义是本仓库原创正文，不写成任何外文教材的译本。

## 交付物

1. 一句模式判断（饥饿型／应激型／并存时以哪侧为主）
2. 一张五项对照表，逐条写方向
3. 一句转折点或一句“不是切换而是强制分解”
4. 一行再喂养风险提示（有／无，有则写高危情形）
5. 一句节奏判断（缓慢启动／先控制原发病）
6. 一处边界：不给值、不作判定、不开食谱

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 把两种模式混读 | 用补饥饿的办法对待应激 | 五项对照先分流 |
| 追求一次补足 | 触发再喂养综合征 | 缓慢启动、逐步增加 |
| 只补蛋白不问电解质 | 漏掉磷钾镁的细胞内转移 | 补充前先评估 |
| 只看体重 | 水肿与肌肉量被抹平 | 加功能与腰围 |
| 把肥胖归因于意志力 | 讨论失焦、护患对抗 | 只写机制类别 |
| 用单一比值定性 | 肌肉发达者被误判 | 结合多维评估 |

## 边界

本 Skill 只处理「描述 → 模式 → 节奏 → 边界」的分流，不涉及数值、判定与营养处方。机制与干预原则的类别取自本仓库原创讲义第 42 章（42.1–42.12）；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
