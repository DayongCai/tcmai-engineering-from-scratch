# Skill：限制性肺疾病——六位置定位与三栏账

## 何时用

- 有人用「气短」「肺不好」「片子没事但就是喘」把一段状态糊过去了，需要定位到具体位置
- 要判断眼前这个人是肺内限制还是肺外限制，从而决定该看弥散、看啰音，还是看呼吸形态与泵的力量
- 要给一段描述排出时序：呼吸困难、低氧、二氧化碳潴留谁先出现
- 遇到「血氧还行，要不要紧」「积液不多，问题大不大」这类追问，需要一套一致的判据
- 要在阻塞性与限制性之间切换解释框架，先确认自己在用哪一套

## 核心判据（五问）

1. **在哪一侧？** 肺内（实质、间质、肺泡腔）还是肺外（胸膜腔、胸廓、呼吸泵）。肺内常同时损害弥散，肺外早期肺本身正常。
2. **哪个位置？** 间质（壁变厚）、肺泡腔（腔被液体占）、胸膜腔（外压）、胸廓（壳不能动）、呼吸泵（没有力量把气吸进来）。相邻位置只差一层，说不清差别就是没定位。
3. **力学原因是什么？** 顺应性下降、外压、壳固定、泵无力——四种原因指向四种不同的干预方向。
4. **三栏账各记了什么？** 容积层（成比例减小、一秒率不低反高）、力学层（弹性功增加、死腔比例上升、呼吸肌疲劳）、交换层（弥散距离、低 V/Q 与分流）。
5. **时序对不对？** 呼吸困难最早，低氧其次，二氧化碳潴留最后（等泵衰竭）。若有人把顺序倒过来说，机制一定写错了。

## 执行步骤

```text
1. 抄原话，不改写：把要定位的那句话原样放在第一行
2. 分边：肺内 / 肺外，各写一条支持与一条反对的线索
3. 落点：六个位置里选一个，并说明为什么不是相邻那个
4. 写机制：顺应性、外压、壳、泵，四选一或组合
5. 算三栏：容积 / 力学 / 交换，缺栏写缺
6. 排时序：呼吸困难 → 低氧 → 二氧化碳潴留，附推断理由
7. 找急症：单向活瓣、快速增长的积液、泵的急性失效，命中就单列
8. 中性改写：删掉判定成分，只留位置、机制与可观察项
9. 报边界：不写数值，不作诊断，不给预后
```

## 硬约束

- **不给数值、单位、正常值、参考区间、百分比。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不作诊断，不作正常与异常判定。** 啰音、叩诊音、影像描述在本 Skill 里只作体征类别，不用于给个体定性。
- **引文逐字。** 标「补充·hermes-病理生理学讲义·第N章·N.M」；核不到就不引，也不许把它写成代用底本的出处。
- **位置必答。** 不许用「可能是肺的问题」把位置糊过去；说不清就写说不清。
- **速度与量分开。** 积液、水肿、泵的失效都要问「多快」，不只问「多少」。
- **三栏账不许合并。** 力学层的结论不能拿去解释交换层，反之亦然。

## 交付物

1. 一句分边结论：肺内还是肺外，附支持与反对各一条
2. 一个位置落点：六个位置之一，附「为什么不是相邻那个」一句
3. 一条机制说明：顺应性、外压、壳、泵
4. 一张三栏账：容积 / 力学 / 交换，缺栏标缺
5. 一条时序推断：三个信号的先后与理由
6. 一句急症提示：有无先要命后要肺的成分
7. 一段中性改写：删掉判定成分后的版本
8. 一处边界：本书不给值、不作诊断

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 用病名替代位置 | 把胸膜、胸廓、泵的问题塞进肺实质解释 | 先答肺内还是肺外，再答六个位置里的哪一个 |
| 把一秒率当万能指标 | 限制性疾病被读成「通气还行」 | 一秒率是比例，总量减小则比例升高 |
| 只看血氧不看通气 | 泵衰竭被漏到血氧下降才认出 | 补呼吸频率、潮气量趋势、咳嗽效力 |
| 把速度当量 | 「积液不多」被当成低风险 | 量与速度是两个独立变量 |
| 三栏账只写一栏 | 机制与后果脱节 | 容积、力学、交换各写一句 |
| 把讲义注成教材 | 读者分不清哪句有原文支撑 | 引文只标补充·hermes-病理生理学讲义·第23章·N.M |
| 被追问就报数值 | 越出本书口径，且数值无来源 | 统一回「本书不给值，另立数据层」 |

## 边界

本 Skill 只处理「一句描述 → 位置 → 机制 → 三栏账 → 时序」的定位，不涉及数值、判定与临床决策。分类与机制取自本仓库原创《hermes-病理生理学讲义》第 23 章；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
