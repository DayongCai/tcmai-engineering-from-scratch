# Prompt：把一句「气短」定位到六个位置之一

## 用途

限制性肺疾病最容易被糊过去的一句话是「他气短，可能是肺不好」。这句话把三件事混在了一起：位置（肺内还是肺外）、机制（顺应性、弥散、分流、泵）、后果（容积、力学、交换）。本模板不让你补病名，而是把一句描述逼到坐标上：先分边，再落点，最后才算账。适用于呼吸系统的讨论课、护理评估记录的自检，以及读第 24、25 章（水电解质、酸碱）之前的热身——那两章同样要求先定位再判断。

## 使用前提

- 你面对的是一段**状态描述**（症状、体征、病史线索），不是一个待确诊的病例。
- 你手边有讲义定位（`补充·hermes-病理生理学讲义·第23章·23.9` 这一级），读过对应小节。
- 你接受两条硬约束：**不产出任何数值与单位**；**不作诊断、不作正常与异常的判定**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是下结论，而是把一段关于呼吸困难的描述定位到「位置 × 后果」的坐标上，并指出哪一步越界。

【输入】
原话：<一段症状与体征描述，可以带病名，可以带判断>
讲义定位：<补充·hermes-病理生理学讲义·第N章·N.M>

【任务，按顺序回答，不跳步】
1. 分边：这段话指向肺内限制还是肺外限制？各写出支持与反对的一条线索。肺内看弥散下降、吸气末细密啰音、杵状指、影像间质改变；肺外看肺野清晰、通气受限、呼吸肌无力、胸廓形态。
2. 落点：在六个位置里选一个（间质、肺泡腔、胸膜腔、胸廓、呼吸泵、混合），并说明为什么不是相邻的那个位置。位置之间只差一层，说不清差别的就是没定位。
3. 机制：写下这一位置造成限制的力学原因（顺应性、外压、壳的固定、泵无力），再写它是否同时损害弥散或造成分流样效应。
4. 账目：按容积、力学、交换三栏各写一句，缺哪栏写缺哪栏。
5. 时序：按机制推断三个信号谁先出现——呼吸困难、低氧、二氧化碳潴留。给出推断理由，不引用数值。
6. 风险点：这段话里有没有「先要命、后要肺」的成分（如单向活瓣、快速增长的积液、泵的急性失效）？有就单列。
7. 越界清单：指出原话里属于个体判定（诊断、严重程度、预后、疗效）的成分，逐条给出中性改写。
8. 边界：这段定位不能回答什么。

【硬约束】
- 不给任何数值、单位、正常值、参考区间、百分比。凡需数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作正常与异常判定，不作预后判定。
- 引讲义原文必须逐字，并标「补充·hermes-病理生理学讲义·第N章·N.M」；核不到就不引。
- 位置说不清就写说不清，不要用「可能是肺的问题」这类话把位置糊过去。

【输出格式】
八个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的定位（节选）

原话：「他最近爬两层楼就喘，听诊没听到什么，片子也说肺上没什么事，血氧还行。」讲义定位：补充·hermes-病理生理学讲义·第23章·23.9。

- **分边**：支持肺外的是肺野清晰、无明显啰音、血氧尚可；反对肺内的是没有弥散下降的证据、没有杵状指。按讲义的分辨线索，先按肺外处理。
- **落点**：落在呼吸泵或胸廓，而不是间质。理由：间质病变会有吸气末细密啰音与影像改变，此处两者都缺；而活动后气短、呼吸变浅是泵与壳的典型表现。
- **机制**：泵无力使潮气量难以增大，频率代偿性加快，死腔比例上升，有效肺泡通气下降。
- **账目**：容积层可能成比例减小；力学层呼吸功上升；交换层早期低氧不明显，二氧化碳潴留晚于低氧出现——这里要写「交换层尚不能判断」，不补猜。
- **时序**：呼吸困难最先（呼吸功上升即出现），低氧其次，二氧化碳潴留最后（要等泵的储备耗尽）。
- **风险点**：有。血氧尚可不等于安全，泵的失代偿可以在血氧掉下来之前发生。
- **越界清单**：「没什么事」是对个体的判定，改为「现有描述未见肺内限制的体征线索，通气储备需继续观察」。
- **边界**：不能由此判断任何人的状态，也不能判断这次气短的走向；数值一律不给。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 用病名替代位置 | 「这是间质性肺病」 | 先答肺内还是肺外，再答六个位置里的哪一个 |
| 位置说不清就选肺内 | 「反正是肺的问题」 | 肺野清晰、无啰音、无杵状指时，先按肺外处理 |
| 只看血氧不看通气 | 「血氧还行，先观察」 | 补上呼吸频率、潮气量趋势、咳嗽效力三项 |
| 把速度当量 | 「积液不多，问题不大」 | 量与速度是两个独立变量，快速增长的更易致症状 |
| 三栏账只写一栏 | 只写「低氧」 | 容积、力学、交换各写一句，缺的写缺 |
| 偷给数值 | 「氧分压低于多少就要给氧」 | 触发硬约束，改为「本书不给值」 |

## 边界

本模板训练的是「一句描述 → 位置 → 机制 → 三栏账 → 时序」的定位能力，不产生临床判断。分类与机制取自本仓库原创《hermes-病理生理学讲义》第 23 章；数值与判定不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
