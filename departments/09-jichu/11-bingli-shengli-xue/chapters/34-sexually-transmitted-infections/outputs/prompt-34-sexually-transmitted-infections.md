# Prompt：把一次感染推成一条链，而不是列一张病原表

## 用途

性传播感染这一章的机制最后都落在一条链上：入口、扩散方向、炎症与修复、长期后果。这个模板不让你背病原表，只让你把一段描述推成一条链，并指出这条链在哪一步可以被切断。适用于讨论课的机制推演、宣教材料写作前的自检，以及读护理流程时确认每一步对着链上哪一处。

## 使用前提

- 你面对的是一段**经过描述**（症状、检查线索、接触或孕产史线索），不是一份诊断。
- 你手边有讲义定位（`补充·hermes-病理生理学讲义·第34章·34.2` 这一级），读过对应小节。
- 你接受三条硬约束：**不产出任何数值**；**不作诊断与判定**；**不作价值判断、不贴标签**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是给结论，而是把一段经过推成一条链，指出链上可切断的一处，并说明这段推演回答不了什么。

【输入】
原话：<一段经过描述，可以带病名、可以带判断>
讲义定位：<补充·hermes-病理生理学讲义·第N章·N.M>

【任务，按顺序回答，不跳步】
1. 入口：病原通过哪一类途径进入——直接穿透、经微损伤、细胞内寄生、表面定植？四类只选一类作起点。
2. 屏障：四层屏障里哪一层最可能被削弱（物理、化学、免疫、微生物）？激素状态在其中起什么作用？
3. 方向：扩散是上行、局部蔓延，还是淋巴与血行？若上行，写到哪一段为止。
4. 修复：炎症是急性可逆，还是已进入慢性与纤维化？管道、浆膜、腺体三处的后果分别是什么？
5. 链式：把上面四步连成一条短式，不超过六个箭头。
6. 可切断处：这条链上有哪两三处可被干预？只写环节类别，不写方案与药物。
7. 越界清单：把原话里的判定成分与评价性措辞逐条指出，给出中性改写。
8. 边界：这段推演不能回答什么。

【硬约束】
- 不给任何数值、单位、正常值、参考区间、百分比。凡需数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作正常与异常判定，不作预后判定，不作疗效断言。
- 不写治疗方案：药物、剂量、疗程都不在本模板输出之内。
- 不作价值判断、不使用标签化表述；凡涉及行为，只写与机制相关的类别。
- 引讲义原文必须逐字并标「补充·hermes-病理生理学讲义·第34章·N.M」；核不到就不引。

【输出格式】
八个小标题各答一到两句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的推链（节选）

原话：「她查出宫颈有感染，医生说问题不大，她也没太在意。」讲义定位：补充·hermes-病理生理学讲义·第34章·34.6。

- **入口**：起点按细胞内寄生处理（这类感染常轻微或无症状，且易转为慢性）。
- **屏障**：化学层与微生物层可能同时被削弱；激素状态决定化学层强度。
- **方向**：从宫颈向上行，写到输卵管为止。
- **修复**：关键在修复而非急性期——炎症持续则转向纤维化，管道器官的后果是狭窄或闭锁。
- **链式**：感染 → 上行 → 输卵管黏膜炎症 → 纤毛损伤与管腔狭窄 → 粘连 → 运输受阻。
- **可切断处**：入口（屏障类措施）、发现（筛查）、循环（伴侣同步处理）三处，只写类别。
- **越界清单**：「问题不大」是判定，改为「目前无症状，按流程随访」这类中性表述。
- **边界**：不能判断任何人的状态，也不给后果预测。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 症状即判断 | 「没症状就是没事」 | 回到机制：无症状仍具传染性 |
| 只写急性期 | 停在红肿渗出 | 推到修复：纤维化才是长期后果 |
| 病原表代替链 | 罗列一串病原名 | 四步一链，不超过六个箭头 |
| 混用两个词 | 感染与疾病随意互换 | 按 34.1 的取舍，统一用感染 |
| 越到治疗 | 直接给药物与疗程 | 只写环节类别，方案不在此侧 |
| 带评价的措辞 | 「不检点」一类表述 | 改为机制描述，删掉评价 |

## 边界

本模板训练的是「经过 → 四步一链 → 可切断处」的推演，不产生临床判断。机制与防控原则类别取自本仓库原创讲义第 34 章（34.1–34.11）；数值、判定与治疗方案均不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
