# Skill：性传播感染——四层屏障、上行链与六类防控

## 何时用

- 一段描述里出现分泌物、溃疡、盆腔痛或不孕线索，需要先推链再谈原因
- 要判断一处感染的后果为什么与初始症状不成比例
- 要把「没症状」这件事读成传播链上的一环，而不是安全信号
- 要在宣教或沟通材料里避开评价性表述，同时不丢失机制信息
- 遇到「要不要紧」「会不会传染」这类追问，需要一致的拒答口径

## 核心判据（五问）

1. **哪一层屏障先被削弱？** 物理（上皮类型）、化学（黏液与酸碱）、免疫（分泌型抗体，局部产生局部作用）、微生物（定植抵抗）。
2. **哪一类入口？** 直接穿透、经微损伤、细胞内寄生、表面定植——四类决定后面能不能被清除。
3. **向哪个方向扩散？** 上行（女性主路）、局部蔓延、淋巴与血行；男性以逆行为主。
4. **修复走到哪一步？** 急性可逆，还是已转纤维化；管道、浆膜、腺体三处后果不同。
5. **链上哪一处可切断？** 入口、发现、循环、清除、环境——只写环节类别，不写方案。

## 执行步骤

```text
1. 抄原话，不改写：把要推的那段放在第一行
2. 定入口：四类途径选一类作起点
3. 查屏障：四层里哪一层被削弱，激素状态在其中起什么作用
4. 定方向：上行写到哪一段为止
5. 推修复：急性可逆还是已转纤维化，按器官类型说后果
6. 串链：不超过六个箭头
7. 中性改写：删掉判定成分与评价性措辞，保留机制与时间线索
8. 报边界：不给值、不作诊断与预后判断、不写治疗方案
```

## 硬约束

- **不给数值、单位、正常值、参考区间、百分比。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不作诊断，不作正常与异常判定。** 感染只作状态类别；无症状感染是机制事实，不是对某个人的判断。
- **不写治疗方案。** 药物、剂量与疗程属临床决策；本 Skill 只写防控原则的类别。
- **不作价值判断、不贴标签。** 理由是机制上的：污名化会延迟就诊、抑制告知伴侣、降低筛查参与，直接削弱防控效果。

## 交付物

1. 一条不超过六个箭头的链：入口、扩散、修复、后果
2. 一句屏障判断与一句扩散方向判断
3. 两到三处可切断的环节（只写类别）
4. 一张越界清单：判定成分与评价性措辞的中性改写
5. 一处边界：不给值、不作诊断、不写方案

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 症状即判断 | 漏掉无症状感染者 | 回到机制：无症状仍具传染性 |
| 停在急性期 | 错过长期后果 | 推到修复与纤维化 |
| 病原表代替链 | 记不住也用不上 | 四步一链，六个箭头以内 |
| 混用感染与疾病 | 视野被缩小 | 按概念取舍统一用感染 |
| 越到治疗 | 越过教学边界 | 只写环节类别 |
| 带评价的措辞 | 削弱防控效果 | 改为中性机制描述 |

## 与相邻章节的接缝

- 上一章（女性生殖功能异常）：本章上行链的终点正是那一章不孕与异位妊娠的机制基础；输卵管粘连与狭窄在那一章是起点，在这一章是结局。
- 与男性生殖功能异常：男性以逆行扩散为主，终点多为附睾炎，接上那一章不育的后睾丸因素。
- 与炎症与免疫相关章节：本章的急性到纤维化链条是那一批章节的一个具体用例。
- 与护理实践：筛查、伴侣通知与沟通措辞可直接落到流程；判断、治疗与告知策略属资质与规范一侧。

## 边界

本 Skill 只处理「经过 → 四步链 → 可切断环节」的结构化推演，不涉及数值、判定与临床决策。机制与防控原则类别取自本仓库原创讲义第 34 章；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
