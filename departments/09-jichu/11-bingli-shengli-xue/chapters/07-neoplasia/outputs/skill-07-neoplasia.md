# Skill：肿瘤——约束清单、两把尺子与不判定的底线

## 何时用

- 有人（包括你自己）用「良性」「早期」「切了就好」这类说法把一段描述糊过去了，需要拆开
- 要在「形态学描述」（像不像）与「行为学描述」（停不停）之间迁移同一套语言时，先确认自己在用哪一层
- 要判断一段叙述有没有把分级当成分期、把标志物当成确诊、把「良性」读成「无害」
- 遇到「这算不算严重」「要不要紧」这类追问，需要一套一致的拒答口径

## 核心判据（四问）

1. **哪条约束被拆了？** 信号依赖、接触抑制与密度依赖、锚定依赖、凋亡清除、DNA 修复与检查点、端粒限制。六条逐条对，缺的写「未提」。
2. **自主性有没有证据？** 只有一条判据：不受正常调控，且去因仍在。形态与团块都不是判据。
3. **用的是哪把尺子？** 分化与异型性（分级，答「本身有多凶」）／原发灶与转移（分期，答「已经走到哪」）。两把尺子不许合并成「严重程度」。
4. **话停在哪一层？** 形态／基因／暴露／播散／全身／免疫／判定。越到判定那一层就是越界。

## 执行步骤

```text
1. 抄原话，不改写：把要拆的那句话原样放在第一行
2. 对六条约束：逐条写「拆了 / 没提 / 不足以判断」，不补猜
3. 找判据：是否给出「不受调控 + 去因仍在」的证据；没有就写「未给自主性证据」
4. 分尺子：分级归分级、分期归分期，各自写清答的是哪个问题
5. 归环节：基因（7.4）／暴露（7.5）／播散（7.6）／全身（7.7）／免疫（7.8）
6. 查越界：诊断、良恶性、分级、分期、预后、疗效——逐条标出
7. 中性改写：删掉判定成分，只留行为与环节，保留观察时点
8. 报边界：不写数值，不作诊断，不给预后判断
```

## 硬约束

- **不给数值、单位、正常值、参考区间、百分比、分级界值。** 需要数值才能回答的追问，统一回：本书不给值，需另立数据层（另立来源与校验）。
- **不作诊断，不作良恶性判定。** 「良性」在本课程里只作行为学类别（不浸润、不转移），不用于给任何个体定性。
- **「良性」不等于「无害」。** 行为学类别与后果是两个维度，位置可以单独决定后果。
- **确诊层只有病理。** 标志物用于监测与随访；正常不能排除、升高不等于患癌。
- **引文逐字。** 标「补充·hermes-病理生理学讲义·第7章·N.M」；核不到就不引。讲义是本仓库原创正文，不写成「教材」。

## 交付物

1. 一段四层拆解（约束 → 判据 → 范围 → 环节），缺层如实标缺
2. 一张六条约束的对照：拆了哪几条、哪几条未提
3. 一句尺子定位：这句话用的是分级尺还是分期尺，或两把都没用
4. 一段中性改写：删掉判定成分后的版本，保留观察时点
5. 一处边界：本章不给值、不作诊断，数值须另立数据层

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 用形态替代判据 | 「边界清楚所以良性」 | 回到自主性：不受调控、去因仍在 |
| 分级当分期 | 「分化差所以晚期」 | 凶与晚分写，两把尺子不换用 |
| 良性读成无害 | 「良性不用管」 | 行为学不等于后果学，位置单独起作用 |
| 标志物当确诊 | 「指标高基本确定」 | 确诊依赖病理，标志物只作监测与随访 |
| 把转移当晚期同义词 | 忽略「能不能走」这一层 | 转移是七步级联，是行为不是时点 |
| 被追问就报界值 | 越出本书口径，且数值无来源 | 统一回：本书不给值，另立数据层 |

- 后两章（第 9、10 章）：本章 7.8 的免疫编辑是那两章的接口——清除、平衡、逃逸三阶段；免疫逃逸与自身耐受共用一套检查点。
- 与病理学的分工：病理学讲形态判据（分化、异型性、基底膜），本课程讲「哪条约束被拆、哪一步能干预」。同一份切片，前者问「像什么」，后者问「停不停」。

## 边界

本 Skill 只处理「一句话 → 四层 → 中性表述」的结构化拆解，不涉及数值、判定与临床决策。分类框架取自 `standards/binglishengli/supplements/jiangyi.json` 第 7 章的类别与环节；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
