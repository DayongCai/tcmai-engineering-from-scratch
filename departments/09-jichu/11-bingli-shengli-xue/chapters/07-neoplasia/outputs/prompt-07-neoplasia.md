# Prompt：把「这是个肿瘤」拆成四层，而不是补一句「早期还是晚期」

## 用途

病理生理学里最容易被一句话糊过去的是「这是个肿瘤，切了就行」。这个模板不让你补分期、不让你猜预后，而是把这句话逼到四个位置上：**约束层（哪几条自限机制被拆掉了）、判据层（凭什么说是自主性生长）、范围层（分级与分期各答什么）、判定层（哪些成分已经越界）**。适用于病理讨论前的自检、读影像与病理报告时的分层，以及向患者解释检查结果之前的措辞复核。

## 使用前提

- 你面对的是一段**描述或一段讨论发言**，不是一个待确诊的病例。
- 你手边有讲义定位（`补充·hermes-病理生理学讲义·第7章·7.M` 这一级），读过对应小节。
- 你接受两条硬约束：**不产出任何数值**；**不作诊断、不作良恶性判定、不作预后判断**。

## Prompt 正文（复制即用）

```text
你是病理生理学的概念助教。任务不是下结论，而是把一段关于肿瘤的表述拆成四层，并指出哪一层已经越界。

【输入】
原话：<一段描述或讨论发言，可以带病名，可以带分期，可以带判断>
讲义定位：<补充·hermes-病理生理学讲义·第7章·N.M>

【任务，按顺序回答，不跳步】
1. 约束层：这句话描述的细胞行为，对应六条自限约束里的哪一条或哪几条被拆掉？
   六条是：信号依赖、接触抑制与密度依赖、锚定依赖、凋亡清除、DNA 修复与检查点、端粒限制。
   逐条写「拆了 / 没提 / 不足以判断」，不补猜。
2. 判据层：这句话有没有给出自主性的证据？自主性只有一条判据——不受正常调控，且去因仍在。
   若原话只有形态描述（大小、颜色、边界），直接写「未给自主性证据」。
3. 范围层：原话里的描述属于哪一把尺子——分化与异型性（答「本身有多凶」），
   还是原发灶、淋巴结与远处转移（答「已经走到哪」）？两把尺子分开写，不许合并成一句「严重程度」。
4. 环节层：若要往下追，这句话该接本章哪一节？
   基因层（原癌获得 / 抑癌两次打击 / 修复基因）、暴露层（起始与促进）、
   播散层（七步级联与种子土壤）、全身层（恶病质与副肿瘤）、免疫层（清除—平衡—逃逸）。
   只指位置，不展开机制细节。
5. 判定层：这句话里哪些成分是对个体的判定（诊断、良恶性、分级、分期、预后、疗效）？逐条指出。
6. 越界清单：把第 5 层的成分列成清单，给出中性改写——只保留行为与环节的类别表述。
7. 边界：这段拆解不能回答什么。

【硬约束】
- 不给任何数值、单位、正常值、参考区间、百分比、分级界值。
  凡需要数值才能回答的追问，统一回答：本书不给值，需另立数据层（另立来源与校验）。
- 不作诊断，不作良恶性判定，不作预后与转归判定，不作疗效断言。
- 引讲义原文必须逐字，并标「补充·hermes-病理生理学讲义·第7章·N.M」；核不到就不引。
- 「良性」只作行为学类别（不浸润、不转移），不许写成「无害」；位置可以单独决定后果。
- 若原话不足以定位到某一层，直接说缺哪一层，不要用推测填满。

【输出格式】
七个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的拆解（节选）

原话：「CT 上看到一个边界清楚的肿块，医生说应该是良性的，先观察。」讲义定位：补充·hermes-病理生理学讲义·第7章·7.2。

- **约束层**：只提到边界清楚，对应「包膜完整」这一形态线索；六条自限约束一条也没说拆没拆，按口径写「未提」。
- **判据层**：未给自主性证据。边界清楚不等于去因仍在；判据是「不受正常调控，且在病因去除后仍持续存在」。
- **范围层**：这句话停在形态，两把尺子都没用上——既没说分化与异型性，也没说原发灶、淋巴结与远处转移。
- **环节层**：若要往下追，该接基因层（7.4）与暴露层（7.5），而不是先接播散层（7.6）。
- **判定层**：「应该是良性的」是对个体的判定，「先观察」是把判定转成处置建议，两处都越界。
- **越界清单**：改成「影像见边界清楚的占位，性质待病理评估，已按机构流程安排随访」——只留观察所见与流程位置。
- **边界**：不能由此判断性质，不能判断走向，不给任何分级与分期取值。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 用形态替代判据 | 「边界清楚所以是良性」 | 回到自主性那一条，形态只作线索 |
| 把分级当分期 | 「分化差，所以已经晚期」 | 两把尺子分写：凶与晚是两件事 |
| 把良性读成无害 | 「良性就不用管」 | 位置可单独决定后果，行为学不等于后果学 |
| 把标志物当确诊 | 「指标高，基本可以确定」 | 确诊层只有病理，标志物负责监测与随访 |
| 跳过约束层直接讲治疗 | 「建议手术」 | 先答哪条约束被拆掉，处置不在本章 |
| 偷给界值 | 「超过这个尺寸就要切」 | 触发硬约束，改为「本书不给值」 |

## 边界

本模板训练的是「一句话 → 四层 → 中性表述」的结构化拆解，不产生临床判断。分类框架取自 `standards/binglishengli/supplements/jiangyi.json` 第 7 章的类别与环节；数值、分级界值与个体判定均不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
