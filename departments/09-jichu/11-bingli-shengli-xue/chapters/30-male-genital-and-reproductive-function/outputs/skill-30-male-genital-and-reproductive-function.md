# Skill：男性生殖功能——三件事、三层调控、两个身份

## 何时用

- 面对「生殖功能下降」这类笼统表述，需要先拆成配子、激素、性行为三件再谈
- 要解释「激素尚可而精液已下降」为什么可能
- 要判断一句「年纪大了」是不是把变量当解释
- 要把生殖系统的表现接到全身评估上（血管内皮、代谢、睡眠、吸烟）

## 核心判据（四问）

1. **哪一件事？** 配子（生精与精液）／激素（睾酮与促性腺激素）／性行为（勃起与射精）。三件事共用一套解剖，检查手段互不替代。
2. **哪一层？** 局部（旁分泌、血睾屏障、温度）／中枢（脉冲式指令、两条反馈）／神经血管（自主与躯体、一氧化氮通路）。每件事只挂一个主层次。
3. **两种驱动分开了吗？** 生精小管与间质细胞共用血供却受不同信号调控；激素正常不等于生精正常，反之亦然。
4. **时序对不对？** 胚胎期（结构异常为主）／青春期（启动，夜间脉冲先行）／成年（可逆波动）／中老年（差异极大，须列并行因素）。

## 执行步骤

```text
1. 抄原话：主诉或结果原样列出，不改写
2. 拆三件：配子 / 激素 / 性行为，逐条归属
3. 挂层次：局部 / 中枢 / 神经血管；挂不上写未定并注明缺哪项
4. 核两种驱动：是否把激素与生精当成一件事
5. 定时序：四期中哪一期；用年龄解释时必须列并行因素
6. 接整体：输出端四条路径（代谢、血管、神经、内分泌）与窗口价值
7. 中性改写：删掉诊断、生育力、轻重、预后四类判定
8. 报边界：不给值，不写处置，单次检测不孤立解读
```

## 硬约束

- **不给数值、单位、参考值、百分比。** 激素参考值、精液参数界值、时间常数一律不给；追问统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不作诊断，不作生育力与预后判定。** 原发性与继发性的推理骨架只作方向。
- **引文逐字。** 标「补充·hermes-病理生理学讲义·第30章·30.M」；核不到就不引，不得标成「教材」。
- **年龄不是解释。** 中老年段落的个体差异极大这一条否掉以年龄直接归因。
- **沟通即方法。** 生殖健康史的措辞与保密说明决定信息完整性，回避等于放弃早期发现全身疾病的入口。

## 交付物

1. 一张三件事 × 三层表：每件事挂一个主层次
2. 一句两种驱动的核对结果：激素与生精是否被混为一谈
3. 一份时序判断：四期中的哪一期，附并行因素
4. 一段中性改写：删掉四类判定后的版本
5. 一处边界：不给值、不判生育力，数值须另立数据层

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 三件事混成一件 | 检查方向乱 | 先拆配子 / 激素 / 性行为 |
| 激素正常推生精正常 | 漏掉支持细胞与局部因素 | 补两种驱动 |
| 只查局部 | 漏掉代谢与血管 | 接输出端四条路径 |
| 年龄当解释 | 掩盖可逆因素 | 列肥胖、代谢、睡眠、活动量 |
| 单次精液定结论 | 过度解读 | 写明个体差异与采集影响 |
| 跳过隐私沟通 | 信息不全，入口关闭 | 用中性语言并说明保密范围 |

## 边界

本 Skill 只处理「一句主诉 → 三件事 → 三层」的结构化拆解，不涉及数值、判定与临床决策。结构分工与调控层次取自《hermes-病理生理学讲义》第 30 章；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
