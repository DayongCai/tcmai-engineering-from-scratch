# Prompt：把一句「生殖功能下降」拆成三件事与三层调控

## 用途

男性生殖功能最容易被一句话糊过去：「他这方面不行了」。这句话把三件事压成了一件——配子、激素、性行为。本章的模板不让你补病名，而是把这句话逼到三件事与三层调控上，并检查有没有把局部问题写成全身结论、或把年龄当作解释。

适用场合：采集生殖健康史之后的结构化整理、读精液与激素结果时给异常归位、以及在「这是不是局部问题」这类追问面前组织一次有依据的回答。

## 使用前提

- 你面对的是**一段主诉或一组结果**，不是一份待确诊的病历。
- 你读过讲义第 30 章的对应小节，能给出 `补充·hermes-病理生理学讲义·第30章·30.M` 这一级定位。
- 你接受两条硬约束：**不产出任何数值与参考值**；**不作诊断、不作生育力判定**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是给病名，而是把一段生殖功能相关的描述拆成三件事与三层调控，并指出哪一层越界。

【输入】
原话：<一段主诉或一组结果描述>
讲义定位：<补充·hermes-病理生理学讲义·第30章·30.M>

【任务，按顺序回答，不跳步】
1. 三件事层：这句话说的是配子（生精与精液）、激素（睾酮与促性腺激素）、还是性行为（勃起与射精）？可多选，逐条写明。
2. 层次层：在每一件上，问题落在局部（旁分泌与温度）、中枢（脉冲式指令）、还是神经血管（自主与躯体）？
   每件事只挂一个主层次；挂不上写「层次未定」并注明缺哪项评估。
3. 两种驱动核对：若涉及激素与生精，检查是否把两者当成同一件事——生精小管与间质细胞共用血供却受不同信号调控。
4. 时序层：属胚胎期（结构异常为主）、青春期（启动）、成年（可逆波动）、还是中老年（差异极大）？
   若用年龄解释，必须同时列出肥胖、代谢、睡眠、活动量这几条并行因素。
5. 整体层：这条主诉有没有可能早于其他系统症状出现（血管内皮、代谢、睡眠、吸烟）？
   有就写「提示评估全身状态」，没有写「未见」。
6. 越界清单：原话里哪些成分是判定（诊断、生育力、轻重、预后）？逐条摘出，给中性改写。
7. 边界：这段拆解不能回答什么。

【硬约束】
- 不给任何数值、单位、参考值、百分比。凡需数值的追问，统一回：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作生育力判定，不作预后判定，不写处置与用药。
- 引讲义原文必须逐字，并标「补充·hermes-病理生理学讲义·第30章·30.M」；核不到就不引。
- 单次精液结果不孤立解读：个体差异大，且受近期发热、禁欲时间、采集方式影响。

【输出格式】
七个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的拆解（节选）

原话：「他激素查了没问题，就是精液质量差，可能是年纪大了。」讲义定位：补充·hermes-病理生理学讲义·第30章·30.2。

- **三件事层**：说的是配子（精液质量），激素被明确排除在异常之外；性行为未提及。
- **层次层**：配子这一件主层次在局部（支持细胞、血睾屏障、温度）与中枢（脉冲式 FSH 指令）之间；仅凭这两句无法定，写「层次未定，缺支持细胞功能与脉冲质量的评估」。
- **两种驱动核对**：不能因为激素正常就认定生精正常。睾丸同时是外分泌与内分泌器官，两者共用血供却受不同信号调控——这正是激素尚可而精液已下降的可能结构。
- **时序层**：若此人处中老年，讲义要求差异极大这一限定，并同时列肥胖、代谢、睡眠、活动量；不能简单归因于年龄。
- **整体层**：有。生殖功能是整体健康的输出端与窗口，代谢、血管、神经、内分泌四条路径都可影响，写「提示评估全身状态」。
- **越界清单**：「可能是年纪大了」是把变量当解释，且隐含预后判断；改成「年龄只是并行因素之一，待分层评估」。
- **边界**：不能由此判断生育力，也不给任何参考值与处置。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 三件事混成一件 | 「生殖功能差」 | 拆成配子 / 激素 / 性行为 |
| 激素正常推生精正常 | 「激素没事，精子也没事」 | 补两种驱动：不同细胞、不同信号 |
| 只查局部 | 不看代谢、血管、睡眠 | 补输出端四条路径 |
| 年龄当解释 | 「年纪大了都这样」 | 列并行因素，年龄只是其中之一 |
| 单次精液定结论 | 「一次不正常就是不育」 | 写明个体差异与采集影响 |
| 偷给参考值 | 「低于某个数就是少精」 | 触发硬约束，改为本书不给值 |

## 边界

本模板训练的是「一句主诉 → 三件事 → 三层调控」的拆解能力，不产生临床判断。结构分工与调控层次取自《hermes-病理生理学讲义》第 30 章；数值、处置与个体判定不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
