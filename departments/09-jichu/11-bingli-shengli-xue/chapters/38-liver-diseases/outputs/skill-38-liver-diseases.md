# Skill：肝脏疾病——四条主线、两条后果线与一个可逆窗口

## 何时用

- 一条线索（乏力、腹水、黄疸、意识改变、出血倾向）需要先归主线再谈原因
- 要解释为什么指标可以正常而功能已经受损
- 要从四条主线推出门脉高压或肝性脑病的机制
- 要判断当前纤维化处在可阻断阶段还是结节阶段
- 遇到白蛋白多少算低、氨多少算高的追问，需要一致的拒答口径

## 核心判据（五问）

1. **哪条主线？** 合成、解毒与生物转化、胆汁生成与排泄、门脉循环调节——四条是因。
2. **有储备吗？** 合成与解毒都有储备；指标正常只说明尚未耗尽，不说明没有损伤。
3. **哪条后果线？** 门脉高压（阻力乘流量）或肝性脑病（氨与炎症协同）——两条是果。
4. **分布如何？** 中央带为主想灌注，门管周围为主想药物与淤积。
5. **窗口还开着吗？** 早期纤维化可阻断甚至逆转；结节与结构扭曲阶段基本不可逆。

## 执行步骤

```text
1. 抄原话，不改写：把要接的那句放在第一行
2. 归主线：四条里选一至两条，各写一条证据
3. 查储备：说明指标可能滞后或在范围内，不能据此排除
4. 定后果线：门脉高压／肝性脑病，写出对应机制
5. 看分布：中央带或门管周围，推病因方向
6. 判窗口：可阻断／可逆转／已不可逆，只写阶段不写分级数值
7. 核诱因：涉及脑病时逐条核六项可逆负荷
8. 报边界：不给值、不作诊断、不写方案
```

## 硬约束

- **不给数值、单位、正常值、参考区间、百分比。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不作诊断，不作正常与异常判定。** 四条主线与两条后果线都只作机制类别；蜘蛛痣、腹水、嗜睡只作线索。
- **不写治疗方案。** 药物、剂量、疗程、穿刺、分流与移植属临床决策；本 Skill 只写机制与分类。
- **不把次序写成分级。** 「先找诱因」是机制层的次序，不是分级或时限规定。
- **引文逐字。** 标`补充·hermes-病理生理学讲义·第38章·N.M`；核不到就不引。讲义是本仓库原创正文，不写成任何外文教材的译本。

## 交付物

1. 一句主线判断（主副两条 + 各自证据）
2. 一句储备判断（为何指标不能排除）
3. 一句后果线判断与对应机制
4. 一句窗口判断（阶段，不含分级数值）
5. 一张脑病诱因核对表（涉及脑病时）与一处边界（不给值、不作诊断、不写方案）

## 典型误用

| 误用 | 表现 | 纠正 |
|---|---|---|
| 只盯一项指标 | 白蛋白正常即放心 | 回储备与半衰期 |
| 黄疸代替主线 | 用颜色下结论 | 按四条主线归位 |
| 门脉压力单因子 | 只想降流量 | 阻力乘流量 |
| 脑病跳过诱因 | 直接谈药 | 六项可逆负荷先核 |
| 肝肾综合征当肾病 | 直接护肾 | 结构正常而功能衰竭 |
| 越到治疗 | 直接给方案 | 只写机制与类别 |

## 边界

本 Skill 只处理「线索 → 四条主线 → 两条后果线」的结构化接线，不涉及数值、判定与临床决策。机制类别取自本仓库原创讲义第 38 章；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
