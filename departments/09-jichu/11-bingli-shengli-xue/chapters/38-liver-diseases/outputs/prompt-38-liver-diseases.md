# Prompt：把一条肝功能线索接回四条主线与两条后果线

## 用途

肝病的线索极稀：乏力、腹水、黄疸、意识改变、出血倾向、白蛋白偏低。这些词单独看都不指向肝，合起来才成一张图。这个模板不让你猜病名，只让你把一条线索接回四条功能主线，再推出它落在哪一条后果线上，并指出可逆窗口是否还开着。适用于讨论课的机制推演、护理评估的归因、宣教材料写作前的自检。

## 使用前提

- 你面对的是一条**线索或一段经过描述**，不是一份诊断。
- 你手边有讲义定位（`补充·hermes-病理生理学讲义·第38章·38.1` 这一级），读过对应小节。
- 你接受三条硬约束：**不产出任何数值**；**不作诊断与判定**；**不写治疗方案**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是给结论，而是把一条线索接回四条功能主线，指出它落到哪条后果线，并说明可逆窗口的状态。

【输入】
原话：<一条线索或一段经过描述，可以带病名、可以带判断>
讲义定位：<补充·hermes-病理生理学讲义·第N章·N.M>

【任务，按顺序回答，不跳步】
1. 归主线：合成、解毒与生物转化、胆汁生成与排泄、门脉循环调节四条主线里，这条线索指向哪一条？若两条同时，写出各自的证据。
2. 看储备：这条线索对应的功能是否有储备？若有，说明指标可能仍在范围之内，不能据此排除。
3. 定后果线：是否已落到门脉高压或肝性脑病？若已落，写出支撑的机制（阻力乘流量／氨与炎症协同）。
4. 分布：若已知病理分布，是中央带为主还是门管周围为主？据此推测病因方向。
5. 窗口：纤维化处在可阻断、可逆转的阶段，还是已进入结节与结构扭曲？只写阶段，不给分期数值。
6. 诱因：若涉及脑病，逐条核对可逆负荷：出血、感染、便秘、低钾性碱中毒、镇静药、脱水与过度利尿。
7. 越界清单：把原话里的判定成分逐条指出，给出中性改写。
8. 边界：这段推演不能回答什么。

【硬约束】
- 不给任何数值、单位、正常值、参考区间、百分比。凡需数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作正常与异常判定，不作预后判定，不作疗效断言。
- 不写治疗方案：药物、剂量、疗程、穿刺、分流与移植都不在本模板输出之内。
- 引讲义原文必须逐字并标「补充·hermes-病理生理学讲义·第38章·N.M」；核不到就不引。

【输出格式】
八个小标题各答一到两句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的接线（节选）

原话：「最近记性差、白天犯困，家里人说脾气变了；前阵子还黑便。」讲义定位：补充·hermes-病理生理学讲义·第38章·38.9。

- **归主线**：解毒与生物转化为主（氨的清除），门脉循环次之（门体分流使氨绕过肝）。
- **看储备**：解毒有余量，所以血氨可以在结构改变之后才升高；不能凭一次结果排除。
- **定后果线**：已落到肝性脑病——波动性的意识与行为改变是它的识别标志。
- **分布**：分布未知，暂不推病因方向，只留一条：若为中央带为主，先想灌注。
- **窗口**：若已出现门体分流与脑病，提示结构改变已积累；可逆窗口未必全关，但已在收窄。
- **诱因**：黑便这一条直接对上消化道出血——蛋白负荷加低灌注，是可去除的诱因之一。
- **越界清单**：「脾气变了」是描述，可用；若说「肝性脑病二期」那是判定与分级，改为「意识与行为有波动性改变」。
- **边界**：不能判断任何人的状态，不给分期与预后，不给处置建议。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 只盯一项指标 | 白蛋白正常即放心 | 回储备与半衰期两个特点 |
| 把黄疸当全部 | 用颜色代替四条主线 | 按主线逐条归位 |
| 门脉压力当单因子 | 只想降流量 | 阻力乘流量，两者都要动 |
| 脑病只想着加药 | 跳过诱因 | 六项可逆负荷先逐条核 |
| 把肝肾综合征当肾病 | 直接护肾 | 结构正常而功能衰竭，病灶不在肾 |
| 越到治疗 | 直接给方案 | 只写机制与类别 |

## 边界

本模板训练的是「线索 → 四条主线 → 两条后果线」的结构化接线，不产生临床判断。机制类别取自本仓库原创讲义第 38 章（38.1–38.12）；数值、判定与治疗方案均不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
