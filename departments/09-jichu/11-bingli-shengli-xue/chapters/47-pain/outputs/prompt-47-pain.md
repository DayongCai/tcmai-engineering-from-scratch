# Prompt：把一句「疼得厉害」推成四环节，而不是一个强度值

## 用途

疼痛这一章的机制最后都落在一条链上：转导、传导、整合、调控。这个模板不让你记录强度，只让你把一段关于疼痛的描述推成这条链，并判断增益是在哪一环被调高的。适用于讨论课的机制推演、护理记录里「疼痛」一栏的写法自检，以及读慢性疼痛病例时确认「检查没找到病灶」这句话到底意味着什么。

## 使用前提

- 你面对的是一段**经过描述**（部位、性质、时间、诱因、对功能的影响），不是一个待判定的病例。
- 你手边有讲义定位（`补充·hermes-病理生理学讲义·第47章·47.6` 这一级），读过对应小节。
- 你接受三条硬约束：**不产出任何数值**；**不作诊断与判定**；**不写药物与剂量**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是判断疼得多重，而是把一段疼痛描述推成四环节的链，指出增益可能被调高的位置，并说明这段推演回答不了什么。

【输入】
原话：<一段疼痛描述，可以带强度词、可以带判断>
讲义定位：<补充·hermes-病理生理学讲义·第47章·N.M>

【任务，按顺序回答，不跳步】
1. 定义层：这句话描述的是感觉-辨别、情绪-动机、认知、社会四维里的哪几维？缺哪几维就写缺哪几维。
2. 转导：起点属哪一类输入（机械、温度、化学）？有无炎症汤类的局部敏化线索（静息痛、局部压痛）？
3. 传导与整合：性质更像第一痛（尖锐、定位明确）还是第二痛（钝、弥散、带情绪色彩）？定位是否可能由汇聚-投射造成牵涉？
4. 调控：有无下行抑制被削弱的线索（失眠、焦虑、孤立）？有无「注意力转移时减轻」这类闸门证据？
5. 敏化层级：目前停在哪一级——外周、中枢、去抑制、结构重塑？说出判断依据。
6. 关系判断：伤害性输入与疼痛强度之间的关系是否仍然成立？成立写成立，削弱写削弱。
7. 记录单元：把这段描述改写成「疼痛—干预—再评估」可用的三段，只写观察，不写结论。
8. 越界清单：原话里哪些成分是判定（诊断名、严重程度、预后、疗效）？逐条指出并给中性改写。
9. 边界：这段推演不能回答什么。

【硬约束】
- 不给任何数值、单位、评分刻度、时长界值、百分比。凡需数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作正常与异常判定，不作预后判定，不作疗效断言。
- 不写药名、不给剂量与方案；只写机制靶点的类别。
- 不把「检查未见异常」写成「疼痛不成立」。
- 引讲义原文必须逐字并标「补充·hermes-病理生理学讲义·第47章·N.M」；核不到就不引。

【输出格式】
九个小标题各答一到两句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的推链（节选）

原话：「腰疼三年了，片子查了几次都说没问题，最近越躺越疼。」讲义定位：补充·hermes-病理生理学讲义·第47章·47.6。

- **定义层**：四维里出现了感觉-辨别（部位、性质）与认知（对检查结果的解释），情绪-动机与社会两维未给——这正是后续容易被漏掉的部分。
- **转导**：起点不明；无红肿热等局部炎症线索，静息痛反在卧床后加重，提示不是单纯外周敏化。
- **传导与整合**：定位模糊、范围弥散，更接近第二痛的性质；需考虑内脏或深部来源的汇聚-投射。
- **调控**：长期疼痛伴活动减少，下行抑制可能被削弱；卧床与孤立是同一方向的因素。
- **敏化层级**：停在去抑制与中枢敏化之间——依据是与损伤程度脱钩、活动回避与睡眠受影响。
- **关系判断**：削弱。强度已不能代表外周损伤程度，机制重心在中枢。
- **记录单元**：改写为「部位与性质—活动与卧床后的变化—干预后复评功能（行走、睡眠）」三段。
- **越界清单**：「片子没问题所以没事」是判定，改为「目前影像未见结构性解释，按流程随访并评估功能」。
- **边界**：不能判断任何人的病情走向，也不能给出治疗方案与强度刻度。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 把强度当病情 | 「疼得厉害，所以损伤重」 | 回到输入与强度的关系判断，慢性期这条关系已削弱 |
| 用检查阴性否定疼痛 | 「查不出原因，说明没事」 | 改为机制可能已转至中枢，只写当前检查的限度 |
| 跳过调控直接归因 | 「他太焦虑，所以疼」 | 下行抑制是生理功能，先写资源与睡眠，再谈情绪 |
| 把心因性放大当装病 | 「这是心理作用」 | 中性改写：中枢调制异常，症状真实 |
| 记录只有强度 | 「疼痛若干分」 | 改成「疼痛—干预—再评估」三段观察 |
| 顺手给方案 | 「加用某类镇痛药」 | 只写机制靶点类别，方案属临床决策 |

## 边界

本模板训练的是「描述 → 四环节 → 敏化层级 → 记录单元」的结构化推演，不产生临床判断。机制框架取自本仓库原创讲义第 47 章；数值、评分刻度与用药不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
