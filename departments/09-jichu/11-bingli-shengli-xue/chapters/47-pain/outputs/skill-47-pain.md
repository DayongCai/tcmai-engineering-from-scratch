# Skill：疼痛——四环节、敏化分层与记录闭环

## 何时用

- 一段描述里出现疼痛、麻木、烧灼感或「查不出原因」的痛，需要先推链再谈原因
- 要判断一处疼痛的强度与损伤程度是否还对得上，机制是否已转到中枢
- 要把「注意力转移时减轻」「越焦虑越重」这类现象读成下行调控的证据，而不是态度问题
- 要在护理记录里写疼痛，又不想写成只有一个强度数字
- 遇到「疼到几分算重」「要不要加量」这类追问，需要一致的拒答口径

## 核心判据（五问）

1. **哪几维？** 感觉-辨别、情绪-动机、认知、社会——四维缺项即是后面要补的评估位。
2. **哪一环？** 转导（伤害感受器与外周敏化）、传导（纤维类型与上行通路）、整合（疼痛矩阵）、调控（下行通路与闸门）。
3. **哪一级敏化？** 外周、中枢、去抑制、结构重塑；级别决定靶点，靶点决定方向。
4. **关系还成立吗？** 伤害性输入与疼痛强度之间的关系紧密还是削弱——这是急性与慢性的真正分界。
5. **记录成单元了吗？** 疼痛—干预—再评估三段齐全，孤立强度数字不作结论。

## 执行步骤

```text
1. 抄原话，不改写：把要推的那段放在第一行
2. 拆维度：四维各写一句，缺的写「未给」
3. 定环节：从转导到调控逐环对，缺环如实标缺
4. 定层级：四级敏化里判断当前停在哪一级，写出依据
5. 判关系：输入与强度的关系紧密还是削弱
6. 换记录：改写成观察—干预—再评估三段，只写观察
7. 中性改写：删掉判定成分与严重程度评价
8. 报边界：不给值、不作诊断与预后判断、不写方案
```

## 硬约束

- **不给数值、单位、评分刻度、时长界值、百分比。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不作诊断，不作正常与异常判定。** 疼痛在本课程里只作状态与机制类别。
- **不写药名与剂量。** 只写机制靶点的类别；用药决策属个体化医疗。
- **不把检查阴性当作疼痛不成立。** 机制可以从外周转到中枢，阴性只说明当前检查的限度。
- **不贴标签。** 心因性放大是机制描述，不是对当事人的评价。
- **引文逐字。** 标「补充·hermes-病理生理学讲义·第47章·N.M」；核不到就不引。

## 交付物

1. 一段四环节推演（转导 → 传导 → 整合 → 调控），缺环如实标缺
2. 一张四维对照：齐了哪几维、缺哪几维
3. 一句敏化层级判断，附依据
4. 一句关系判断：输入与强度的关系紧密还是削弱
5. 一段三段式记录改写（疼痛—干预—再评估）
6. 一处边界：不给值、不作诊断、不写方案

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 把强度当病情 | 慢性期强度已不代表损伤 | 改判关系，转向功能 |
| 检查阴性即否定 | 取消当事人体验 | 写机制可能已转至中枢 |
| 只写强度 | 记录无法复评 | 改成三段式记录单元 |
| 把调控读成心理作用 | 删掉整条下行通路 | 先写睡眠、情绪与资源，再谈抑制 |
| 心因性放大写成装病 | 污名化且判断错误 | 中性改写为中枢调制异常 |
| 顺手给镇痛方案 | 越界 | 只写机制靶点类别 |

## 边界

本 Skill 只处理「一段疼痛描述 → 四环节 → 敏化层级 → 记录单元」的结构化推演，不涉及数值、判定与临床决策。机制框架取自本仓库原创讲义第 47 章；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
