# Skill：HIV 感染——受体起点、耗竭路径与免疫缺口

## 何时用

- 一句关于 HIV 的说法同时混着传播、阶段、治疗与预后，需要拆层
- 有人把「病毒载量检测不到」直接读成「治愈」或「终身无忧」
- 要解释为什么机会性感染的清单长成这个样子，而不是靠背
- 要在沟通中避免人群标签与道德评价，同时不牺牲准确性

## 核心判据（五问）

1. **受体是谁？** CD4 加辅助受体（CCR5 或 CXCR4）决定可感染的细胞范围。靶细胞的主次是：CD4⁺ T 为主，单核巨噬、树突、小胶质为储存库。
2. **传播的前提满足吗？** 含病毒的体液进入血液或黏膜。三类途径（性接触、血液、母婴）都是这句的实例；日常接触不满足前提。
3. **在哪一段病程？** 急性期、临床潜伏期、症状期、艾滋病期——四者是未治疗自然史的分类，不是对个体的预测。潜伏期并非静息，而是持续低水平复制。
4. **缺口在哪一侧？** 细胞免疫削弱 → 胞内寄生或再活化的病原体。凡是病原体谱与缺口不同侧的叙述，机制上就接不上。
5. **抑制成功之后还剩什么？** 慢性免疫激活与炎症仍常高于一般人群，重心转向非艾滋病定义性疾病。

## 执行步骤

```text
1. 抄原话，不改写：把要拆的说法原样放在第一行
2. 定受体：写明靶细胞与储存库的分工
3. 定传播：能 / 不能两张清单，按「体液 + 入口」判
4. 定阶段：若用到阶段名，标注它是分类工具
5. 定缺口：由缺口推病原体谱，不用清单反推缺口
6. 查越界：诊断、分期、预后、停药、疗效断言，逐条指出并中性改写
7. 报边界：不给值、不给方案、不作个体判断
```

## 硬约束

- **不给数值。** 病毒载量、CD4 计数、窗口期、疗程、传播概率一律不写；追问统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **U=U 必须带前提。** 持续抑制是这句话成立的条件；单次检测结果不构成前提。
- **不作诊断与分期判定。** 阶段名是分类，不是结论。
- **不写药物与方案。** 只写机制与类别（逆转录酶、整合酶、蛋白酶、进入融合四个环节）。
- **语言即干预。** 用行为与暴露情境描述风险；不贴人群标签；不把感染与道德评价挂钩；保密与知情同意写进流程，而不是当附加条款。

## 交付物

1. 一张五层定位（受体 / 传播 / 阶段 / 缺口 / 抑制后）各一句
2. 一份越界清单与中性改写
3. 一句病原体谱判据：缺口 → 病原体类别，而不是清单
4. 一处边界：不给值、不作判定、不写方案

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 抑制当治愈 | 停药、放弃随访 | 区分血浆复制水平与细胞内前病毒储存库 |
| 潜伏当安全 | 误判传染性与进展 | 潜伏期持续低水平复制、CD4 缓慢下降 |
| 清单反推缺口 | 换一个病原体就失手 | 从「胞内寄生 / 再活化」这条判据出发 |
| 阶段名当预测 | 对个体下结论 | 四阶段是未治疗自然史的分类 |
| 用标签谈风险 | 歧视、延迟检测 | 改成行为与暴露情境 |
| 保密当可选项 | 披露失控、信任破裂 | 仅在必要诊疗范围内共享，未经同意不披露 |

## 边界

本 Skill 只处理「一句说法 → 五层定位 → 中性改写」的结构化拆解，不涉及诊断、分期、预后与治疗决策。框架取自《hermes-病理生理学讲义》第 12 章；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
