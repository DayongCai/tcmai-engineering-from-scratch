# Prompt：把一条 HIV 相关的说法拆成「受体 → 缺口 → 病原体谱」

## 用途

这一块的公众讨论密度极高，而大部分争论发生在两个不同的层面上：一个层面是「会不会传染」，另一个层面是「感染之后会怎样」。两层混在一起谈，就会出现「他看起来很健康，所以应该没事」这类结论。这个模板把任何一条说法拆到五个位置上：**受体与靶细胞、传播前提、阶段、免疫缺口、检测分工**，并指出说话人已经越到哪一层。适用于健康宣教备课、病例讨论前的口径统一，以及写护理沟通稿时的自检。

## 使用前提

- 你面对的是一句**说法**（患者的疑问、同学的判断、科普文章的结论），不是一个待诊的病例。
- 你手边有讲义定位（`补充·hermes-病理生理学讲义·第12章·12.5` 这一级），读过对应节。
- 你接受三条硬约束：**不给任何数值**（载量、计数、窗口期、疗程）；**不作诊断与分期判定**；**不写药物名称与方案**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是给结论，而是把一句关于 HIV 的说法拆到五个位置上，并指出它越界在哪一层。

【输入】
原话：<一句说法，可以是疑问、判断或科普结论>
讲义定位：<补充·hermes-病理生理学讲义·第N章·N.M>

【任务，按顺序回答，不跳步】
1. 受体层：这句话涉及的是哪一类细胞？先写受体（CD4 与辅助受体）决定靶细胞这一步，再写靶细胞的主次（CD4⁺ T 为主；单核巨噬、树突、小胶质为储存库）。
2. 传播层：这句话说的是「能不能传播」吗？若是，按前提归位——含病毒的体液进入血液或黏膜；并区分「能传播」与「不能传播」两张清单，不给概率。
3. 阶段层：这句话有没有用到急性期 / 潜伏期 / 症状期 / 艾滋病期？若有，说明它描述的是未治疗的自然史，不是对个体的预测。
4. 缺口层：这句话的结论依赖哪一侧免疫？细胞免疫削弱 → 胞内寄生与再活化类病原体；据此检查它给的病原体谱是否与缺口同侧。
5. 越界清单：这句话里哪些成分是判定（有没有感染、到哪一期、要不要治、能不能停）？逐条列出，并给中性改写。
6. 边界：这段拆解不能回答什么。

【硬约束】
- 不给任何数值、单位、阈值、窗口期天数、疗程长度、百分比。凡需数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作分期判定，不作预后判断，不给药物名称、剂量与方案。
- 说「测不到等于不传染」时必须带前提：持续抑制。前提被省略就不写这句。
- 引讲义原文必须逐字，并标「补充·hermes-病理生理学讲义·第N章·N.M」；核不到就不引。
- 用行为与暴露情境描述风险，不用人群标签；不把感染与道德评价挂钩。

【输出格式】
六个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的拆解（节选）

原话：「他病毒载量查不到了，那是不是就等于治好了，可以停药？」讲义定位：补充·hermes-病理生理学讲义·第12章·12.6。

- **受体层**：这句话没有涉及受体，但它隐含的前提是「病毒不复制了」。机制上要说清：病毒载量反映血浆中的复制水平，不反映细胞内的前病毒。
- **传播层**：载量持续检测不到对应的是传播风险极低（治疗即预防），但这需要「持续抑制」这个前提，而不是一次检测结果。
- **阶段层**：治疗成功会改变自然史的轨迹，四阶段不再按原样走；但阶段名仍然只是分类工具。
- **缺口层**：即使抑制成功，慢性免疫激活仍常高于一般人群——缺口从「机会性感染」转向「非艾滋病定义性疾病」。
- **越界清单**：「治好了」「可以停药」两处都是判定。中性改写：病毒复制被持续抑制，需按规范继续随访与治疗。
- **边界**：不能回答这位个体的具体方案与停药条件，那属临床处置；数值一律不给。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 把抑制当治愈 | 「载量测不到就是好了」 | 区分血浆复制水平与细胞内储存库 |
| 省略前提引用 U=U | 「测不到就不传染」单说 | 补上「持续抑制」这个前提 |
| 用人群标签谈风险 | 「某类人更容易」 | 改成行为与暴露情境的描述 |
| 阶段名当预测 | 「他在潜伏期，所以没事」 | 说明四阶段是未治疗的自然史分类 |
| 病原体谱脱离缺口 | 背一张机会性感染清单 | 回到「细胞免疫削弱 → 胞内寄生 / 再活化」这条判据 |
| 偷给数值 | 「CD4 低于某个数就要预防」 | 触发硬约束，改为「本书不给值」 |

## 边界

本模板训练的是「一句说法 → 五层定位 → 中性改写」的能力，不产生临床判断。框架取自《hermes-病理生理学讲义》第 12 章的受体、耗竭路径与免疫缺口；数值、分期与治疗不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
