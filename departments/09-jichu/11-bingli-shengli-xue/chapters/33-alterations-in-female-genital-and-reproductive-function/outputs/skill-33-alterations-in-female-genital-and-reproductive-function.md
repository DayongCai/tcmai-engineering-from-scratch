# Skill：女性生殖功能异常——五层排查、三源激素与因果环

## 何时用

- 一段描述里出现闭经、异常出血、痛经、脱垂、漏尿或妊娠相关问题，需要先定层次再谈原因
- 要判断一处出血来自轴、来自结构，还是来自全身凝血状态
- 要把一串同时出现的症状读成一个环（如雄激素过多伴代谢异常），而不是一张清单
- 要解释为什么体积不大却有症状，或为什么体积很大却症状轻微
- 遇到「这样算不算异常」这类追问，需要一套一致的拒答口径

## 核心判据（五问）

1. **哪一层？** 流出道、子宫、卵巢、垂体、下丘脑——从下游往上游排查，先排除最大类。
2. **哪一源？** 雄激素过多分卵巢源、肾上腺源、外周转化；三源对应三种入口。
3. **链还是环？** 单向下行写链，互相强化写环；环要指出可切入的那一环。
4. **位置还是体积？** 腔道器官的症状由位置决定：黏膜下的小病灶比浆膜下的大病灶更能说话。
5. **是共式还是具体机制？** 肿瘤先落共式（持续刺激、修复增殖、调控失效），再写这一种的具体起点。

## 执行步骤

```text
1. 抄原话，不改写：把要判的那句放在第一行
2. 排层：五层按下游到上游列出，标出最像断点的一层
3. 写判别特征：周期有无、激素方向、影像与病史线索，不写取值
4. 辨环：多系统并存时画环，指出可切入的一环
5. 定位置：结构类写部位，用位置解释症状
6. 中性改写：删掉判定成分，保留时相、孕产史、操作史
7. 报边界：不给值、不作诊断与预后判断、不作处置建议
```

## 硬约束

- **不给数值、单位、正常值、参考区间、百分比。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不作诊断，不作正常与异常判定。** 六类是评估路径，五层是排查次序，都不是对某个人的结论。
- **不写处置。** 终止妊娠、手术与用药一类决定不在本 Skill 输出范围；只写机制与评估次序。
- **引文逐字。** 标`补充·hermes-病理生理学讲义·第33章·N.M`；核不到就不引。讲义是本仓库原创正文，不写成任何外文教材的译本。
- **不贴标签。** 生殖与性相关的信息按中性表述处理，不评价、不推断行为。

## 交付物

1. 一张五层排序：哪几层被点到，断点落在哪一层
2. 一条判别特征与一句机制主句
3. 若为环：环的闭合处与可切入的一环
4. 一张越界清单：判定成分与中性改写
5. 一处边界：不给值、不作诊断、不作处置

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 直接给病名 | 层次缺失，无法评估 | 先排层，再定断点 |
| 从上游开始查 | 成本高、排除慢 | 从下游往上游 |
| 环读成清单 | 找不到干预点 | 写出互相强化的那一环 |
| 体积替代位置 | 解释不了症状与体积不平行 | 位置决定症状 |
| 出血只看轴 | 漏掉结构与凝血两组 | 四组机制逐组过一遍 |
| 越到处置 | 越过教学边界 | 处置交回规范与资质 |

## 边界

本 Skill 只处理「表现 → 五层排开 → 断点 → 机制」的结构化拆解，不涉及数值、判定与临床决策。机制与评估次序取自本仓库原创讲义第 33 章；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
