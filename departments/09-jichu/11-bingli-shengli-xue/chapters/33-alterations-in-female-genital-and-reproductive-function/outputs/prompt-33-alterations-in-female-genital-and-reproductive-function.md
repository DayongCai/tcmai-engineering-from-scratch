# Prompt：把一处闭经或出血按五层排开，而不是先给病名

## 用途

女性生殖功能异常这一章的机制最后都落在一个动作上：把一处表现按层排开，再从最下游往最上游走。这个模板不让你给病名，只让你交出三样东西：断点在哪一层、这一层的判别特征是什么、这一层之后该问什么。适用于讨论课的病例推演、写护理评估前的自检，以及把一处出血读到它该去的那一层。

## 使用前提

- 你面对的是一段**表现描述**（周期、经量、痛感、孕产史线索），不是一份诊断。
- 你手边有讲义定位（`补充·hermes-病理生理学讲义·第33章·33.2` 这一级），读过对应小节。
- 你接受两条硬约束：**不产出任何数值**；**不作诊断、不作正常与异常判定**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是给结论，而是把一处表现按层排开、定位断点，并说明这一层之后该问什么。

【输入】
原话：<一段表现描述，可以带病名、可以带判断>
讲义定位：<补充·hermes-病理生理学讲义·第N章·N.M>

【任务，按顺序回答，不跳步】
1. 排层：这句话涉及五层里的哪几层——流出道、子宫、卵巢、垂体、下丘脑？按从下游到上游的顺序写。
2. 定断点：哪一层最像断点？给一条判别特征（周期有无、激素方向、影像与病史线索），不写具体取值。
3. 机制：这一层的机制主线是什么？若是激素失衡，写清是三源里的哪一源（卵巢、肾上腺、外周转化）。
4. 是环还是链：若表现为多系统并存（如雄激素过多伴代谢异常），画出环，并指出哪一环可以切入。
5. 结构：若是结构或肿瘤，写清位置如何解释症状（位置而不是体积）。
6. 该问什么：下一步问哪一类信息，只写类别，不写检查项目与取值。
7. 越界清单：把原话里的判定成分逐条指出（诊断、正常与异常、预后、疗效），给出中性改写。
8. 边界：这段推演不能回答什么。

【硬约束】
- 不给任何数值、单位、正常值、参考区间、百分比。凡需数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作正常与异常判定，不作预后判定，不作疗效断言。
- 不作处置建议：终止妊娠、手术、用药一类决定不在本模板输出之内。
- 引讲义原文必须逐字并标「补充·hermes-病理生理学讲义·第33章·N.M」；核不到就不引。

【输出格式】
八个小标题各答一到两句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的排层（节选）

原话：「她半年没来月经了，最近老觉得肚子胀痛，人也没精神。」讲义定位：补充·hermes-病理生理学讲义·第33章·33.2。

- **排层**：五层都要点到，但顺序从下游往上：流出道、子宫、卵巢、垂体、下丘脑。
- **定断点**：周期性腹痛而无经血，先把流出道放在第一位——卵巢与激素周期可能正常，只是经血不能排出。
- **机制**：若流出道被排除，再看子宫内膜能否再生（激素正常而月经不来），最后才看激素方向。
- **是环还是链**：此处不构成环，按链处理；无多系统并存线索。
- **结构**：需要说明宫腔形态是否改变，位置与容积比大小更能解释症状。
- **该问什么**：问疼痛是否周期性、问既往宫腔操作史，不问单次数值。
- **越界清单**：「人也没精神」是观察，可留；若写成某诊断，改为中性描述。
- **边界**：不能判断任何人的状态，也不给严重程度。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 直接给病名 | 「这是多囊卵巢」 | 先排层、再定断点 |
| 顺序颠倒 | 一上来先查下丘脑 | 从下游往上，先排除最大类 |
| 症状当机制 | 「月经不调」当结论 | 写一条机制主句 |
| 把环读成清单 | 五个症状并列 | 写出互相强化的那一环 |
| 用体积替代位置 | 「肌瘤不大，问题不大」 | 回到位置决定症状 |
| 越到处置 | 直接建议用药或手术 | 处置不在此侧 |

## 边界

本模板训练的是「表现 → 五层排开 → 断点 → 该问什么」的推演，不产生临床判断。机制与评估次序取自本仓库原创讲义第 33 章（33.1–33.11）；数值与判定不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
