# Skill：慢性神经功能障碍——部位、储备与原发/继发分拣

## 何时用

- 有人用「病就是这样」解释一切坏转，却没有分清哪些是可干预的
- 要把记忆下降、步态改变、吞咽困难、情绪变化归到具体的环路与机制
- 要判断一位患者的症状波动是病程在走，还是诱因或并发症在拖
- 要区分中枢与周围脱髓鞘为什么体征相反
- 遇到「这算第几期」「还能撑多久」这类追问，需要一致的拒答口径

## 核心判据（四问）

1. **主线是哪条？** 变性（选择性死亡）／脱髓鞘（髓鞘受损、轴突相对保留）／癫痫（兴奋—抑制失衡）。三者可并存，先定主次。
2. **落在哪条环路？** 内侧颞叶与海马（记忆）、黑质与基底节（运动启动）、运动神经元（上下同时）、纹状体（不自主运动）、白质传导束（传导）。部位决定表现。
3. **储备还剩多少？** 慢性病的症状由「可代偿走向失代偿」决定，所以同一病不同阶段的差异常大于不同病之间的差异。
4. **这是原发还是继发？** 原发是受累环路的直接后果；继发是可干预的七类后果（运动、吞咽营养、呼吸、自主神经、感觉疼痛、认知情绪、社会心理）。

## 执行步骤

```text
1. 抄原话，不改写：把要拆的那段描述原样放在第一行
2. 定主线：变性 / 脱髓鞘 / 癫痫，说明以哪条为主
3. 排可逆：甲状腺功能减退、维生素缺乏、抑郁、药物不良反应、硬膜下血肿、正常压力脑积水
4. 归部位：把每条表现落到一处环路上，落不上的写「未定」
5. 分原发：逐条标注哪些是环路受损的直接后果
6. 拣继发：按七类过一遍，在场几条写几条，一条不漏
7. 找着力点：继发栏里可干预的条目，只写方向
8. 报边界：不给值、不分期、不预后
```

## 硬约束

- **不给数值、单位、正常值、量表分数、参考区间、百分比。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不作诊断，不作分期，不作预后判断。** 「储备耗尽」在本课程里是机制描述，不是对某个人的结论。
- **引文逐字。** 标「补充·hermes-病理生理学讲义·第45章·45.M」；核不到就不引。讲义是本仓库原创教学正文，不许写成任何外文教材的译本。
- **不把必要条件当充分条件。** 蛋白聚集是变性病的机制之一，不等于「有聚集就一定发病」；致痫灶也不等于总有发作。
- **不作处置建议。** 康复强度、进食方式、用药调整属临床与照护决策，本 Skill 只给机制与分类。

## 交付物

1. 一段两栏拆解：原发缺损 / 继发后果，逐条归位
2. 一句部位判断：每条表现落在哪条环路
3. 一份七类继发后果的在场清单（缺项写「无」而不是省略）
4. 一处边界：本章不给值、不分期，数值须另立数据层

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 用病程解释一切 | 可干预部分被放弃 | 拆成两栏，逐条归位 |
| 跳过可逆原因 | 把可治的当成不可治 | 先列六类可逆原因核查 |
| 病名替代部位 | 「这是帕金森病」当成解释 | 说明哪条环路失衡、净效应如何 |
| 把波动当进展 | 误判复发并加大干预 | 波动与复发分开：看持续时间与客观体征 |
| 上下运动神经元混写 | 把矛盾组合当错误 | 两栏同时成立正是 ALS 的标志 |
| 偷给数值 | 「评分多少分」 | 改为方向性表述，或回「本书不给值」 |

## 与相邻章节的接缝

- 第 43 章（神经系统结构与功能）：上下运动神经元对照表在那里立起来，本章用它做 ALS 与脱髓鞘的判别。
- 第 44 章（脑功能急性疾病）：急性期救回的人，出院后走的正是本章的路径；两章共用「水肿—压力—灌注」之外的另一套变量。
- 第 47 章（疼痛）：本章 45.2 的类朊蛋白播散与 45.8 的阈值调节，与中枢敏化共用同一套可塑性机制。
- 与病理学的分工：病理学讲形态（斑块、缠结、路易小体、脱髓鞘斑），本课程讲机制（为什么这些形态会带来这些体征）。

## 边界

本 Skill 只处理「一段功能变化描述 → 三条主线 → 两栏分拣」的结构化拆解，不涉及数值、判定与临床决策。主线与七类后果取自《hermes-病理生理学讲义》第 45 章的表述；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
