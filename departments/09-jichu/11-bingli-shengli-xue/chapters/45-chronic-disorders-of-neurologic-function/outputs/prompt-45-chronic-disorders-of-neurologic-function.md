# Prompt：把「越来越差」拆成原发缺损与继发后果

## 用途

慢性神经病最容易被糊过去的一句话是「病就是这样，慢慢会差」。这句话把两类完全不同的东西压成了一件：一类是神经元丢失带来的原发缺损，真的没有逆转办法；另一类是痉挛、误吸、体位性低血压、抑郁、照护者耗竭这些继发后果，多数可以干预。这个模板不让你补病名，而是把一段「越来越差」的描述拆成两栏，并指出哪一栏还有着力点。

适用于家庭照护沟通、护理计划讨论、长程随访复盘，也适用于第 44 章（急性脑病）出院后的接续：急性期救回来的人，后面走的正是这一章的路径。

## 使用前提

- 你手上是一段**功能变化的描述**，不是一个待确诊的病例。
- 你读过讲义本章对应小节（`补充·hermes-病理生理学讲义·第45章·45.10` 这一级），能指出每条判断的出处。
- 你接受两条硬约束：**不产出任何数值**；**不作诊断、不作预后判断**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是给结论，而是把一段「越来越差」的功能变化拆成原发缺损与继发后果两栏，并指出可干预的部分。

【输入】
原话：<一段功能变化描述>
讲义定位：<补充·hermes-病理生理学讲义·第45章·45.M>

【任务，按顺序回答，不跳步】
1. 定主线：属变性、脱髓鞘，还是癫痫？三者可以并存，说明以哪条为主。
2. 查可逆：有无甲状腺功能减退、维生素缺乏、抑郁、药物不良反应、硬膜下血肿、正常压力脑积水这类可逆原因的可能？只列类别，不下结论。
3. 归部位：缺损落在哪一处环路（记忆与默认网络 / 黑质与基底节 / 运动神经元 / 纹状体 / 白质传导束）？部位决定表现。
4. 分原发：这些表现里哪些是受累环路的直接后果？逐条标注。
5. 拣继发：按七类逐条过——运动、吞咽与营养、呼吸、自主神经、感觉与疼痛、认知与情绪、社会心理；在场几条，写几条。
6. 找着力点：继发栏里哪几条属可干预？只写方向，不写具体手段与强度。
7. 边界：这段拆解不能回答什么。

【硬约束】
- 不给任何数值、单位、正常值、参考区间、百分比、量表分数。凡需数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作分期，不作预后判断，不给药物与剂量。
- 引讲义原文必须逐字，并标「补充·hermes-病理生理学讲义·第45章·45.M」；核不到就不引。
- 某一段缺证据就写「未给」，不要用推测填满。

【输出格式】
七个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的拆解（节选）

原话：「老人这两年记性越来越差，最近不肯吃饭，走路拖着脚，夜里喊叫，家里人快撑不住了。」讲义定位：补充·hermes-病理生理学讲义·第45章·45.3。

- **主线**：以变性为主（情景记忆起病、逐渐累及），不排除血管性成分；癫痫与脱髓鞘无证据。
- **可逆**：须把甲状腺功能减退、维生素缺乏、抑郁、药物不良反应、硬膜下血肿、正常压力脑积水列出来核查——这是在给任何结论之前必须做的一步。
- **部位**：内侧颞叶与海马起病，逐渐累及语言、视空间与执行；符合变性沿解剖联系扩散的路径。
- **原发**：记忆与执行功能的下降是受累环路的直接后果，属原发栏。
- **继发**：不进食（吞咽与营养）、拖步（运动：痉挛或帕金森样）、夜间喊叫（认知与情绪、睡眠）、家属耗竭（社会心理）——四条都在继发栏。
- **着力点**：进食方式与体位、步态与跌倒预防、睡眠环境与诱因、照护者支持。只写方向，不写强度与具体手段。
- **边界**：不能由此确定病因、分期与预后；数值一律不给。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 一句「病就是这样」 | 把所有坏转都归给病程 | 拆成原发与继发两栏，逐条归位 |
| 跳过可逆原因 | 直接按变性解释一切 | 先把六类可逆原因列出来核查 |
| 病名替代部位 | 「这是阿尔茨海默病」当成解释 | 说明累及哪一处环路、为什么表现如此 |
| 继发后果漏项 | 只谈记忆，不谈吞咽与照护者 | 按七类逐条过，在场几条写几条 |
| 越界给方案 | 「每天走半小时」 | 只给方向，强度与方式属临床与照护决策 |
| 偷给数值 | 「评分二十分」 | 改为方向性表述，或回「本书不给值」 |

## 边界

本模板训练的是「主线 → 可逆 → 部位 → 原发 → 继发 → 着力点」的分层表达能力，不产生临床判断。三条主线与七类继发后果取自《hermes-病理生理学讲义》第 45 章的表述；数值与判定不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
