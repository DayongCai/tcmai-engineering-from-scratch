# Prompt：把一堆胃肠病名收进三类坐标

## 用途

胃肠病的名字多到记不完，但它们共用三根坐标轴：屏障、动力、吸收。这个模板不让你背清单，只让你把一个病（或一段描述）先落到坐标上，再用深度与分型把它压成可比较的类别。适用于讨论课的病例归位、护理交班时的机制说明、宣教材料写作前的自检。

## 使用前提

- 你面对的是一段**经过描述或一个病名**，不是一份诊断。
- 你手边有讲义定位（`补充·hermes-病理生理学讲义·第36章·36.1` 这一级），读过对应小节。
- 你接受三条硬约束：**不产出任何数值**；**不作诊断与判定**；**不写治疗方案**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是给结论，而是把一个病或一段描述收进三类坐标，指出深度与分型，并说明这段推演回答不了什么。

【输入】
原话：<一个病名或一段经过描述，可以带判断>
讲义定位：<补充·hermes-病理生理学讲义·第N章·N.M>

【任务，按顺序回答，不跳步】
1. 定位：上消化道还是下消化道？腔内、黏膜、壁内还是壁外？只写位置，不定病名。
2. 归轴：屏障破坏、动力异常、吸收障碍三类里落在哪一类？若同时落两类，写出两类的证据各一条。
3. 深度：若落在屏障，损伤到上皮层（糜烂渗血）、突破黏膜肌层（溃疡）、还是穿透浆膜（穿孔）？
4. 修复：当前处在炎症相、增殖相还是重塑相？若已多次复发，说明为何转向纤维化。
5. 分型：若主诉是腹泻或便秘，按四型／三层给出分型，并写出区分两者的那条判据。
6. 报警：症状模式是否成立？报警征象（出血、体重明显下降、贫血、夜间症状、新发症状的较大年龄）是否缺席？
7. 越界清单：把原话里的判定成分逐条指出，给出中性改写。
8. 边界：这段推演不能回答什么。

【硬约束】
- 不给任何数值、单位、正常值、参考区间、百分比。凡需数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作正常与异常判定，不作疗效断言。
- 不写治疗方案：药物、剂量、疗程、内镜与手术都不在本模板输出之内。
- 引讲义原文必须逐字并标「补充·hermes-病理生理学讲义·第36章·N.M」；核不到就不引。

【输出格式】
八个小标题各答一到两句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的归位（节选）

原话：「反复上腹痛，饭后加重，说是胃溃疡。」讲义定位：补充·hermes-病理生理学讲义·第36章·36.4。

- **定位**：上消化道，黏膜层为主，未见壁外线索。
- **归轴**：屏障破坏为主；若饭后加重还需考虑动力这一轴，但证据不足，暂列次轴。
- **深度**：按溃疡处理——缺损深达黏膜肌层；若只是糜烂，则后果限于渗血。
- **修复**：反复发作提示修复已多次启动，需警惕重塑相主导，即纤维化与狭窄方向。
- **分型**：主诉不含腹泻便秘，分型不适用。
- **报警**：出血、体重明显下降、贫血三项需逐条确认；缺一项则症状模式不足以支持功能性解释。
- **越界清单**：「说是胃溃疡」是转述的判断，改为「上腹痛，饭后加重，性质待明确」。
- **边界**：不能判断任何人的状态，不给病因排序，不给检查与用药建议。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 病名当结论 | 胃溃疡就是酸多 | 回两型机制：酸负荷与防御下降 |
| 跳过位置 | 直接谈病因 | 先定位再定机制 |
| 只看病名不看深度 | 糜烂与溃疡混谈 | 用深度对应三档后果 |
| 功能性当排除诊断 | 查不出就算功能性 | 症状模式 + 报警征象缺席，两者同时 |
| 腹泻不分型 | 一律止泻 | 按四型判据先分型 |
| 越到治疗 | 直接给抑酸或手术 | 只写机制与类别 |

## 边界

本模板训练的是「病名 → 三类坐标 → 深度与分型」的结构化归位，不产生临床判断。机制类别取自本仓库原创讲义第 36 章（36.1–36.12）；数值、判定与治疗方案均不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
