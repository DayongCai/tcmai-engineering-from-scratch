# Skill：胃肠疾病——三类机制、深度对应与四种分型

## 何时用

- 手里有一个病名或一段描述，需要先说清它落在哪一类机制上
- 要判断一处黏膜损伤的后果，而不只是给它一个名字
- 面对「腹泻」「便秘」这类词，需要先分型再谈方向
- 要解释为什么两个病的免疫机制相同而并发症完全不同
- 要把「查不出问题」读成症状模式与报警征象的组合，而不是一句排除

## 核心判据（五问）

1. **哪一段、哪一层？** 上／下消化道；腔内、黏膜、壁内、壁外。
2. **哪根轴？** 屏障破坏、动力异常、吸收障碍；可两轴并存，但要指出主次。
3. **多深？** 上皮层（糜烂渗血）、黏膜肌层（溃疡）、浆膜（穿孔）——深度定后果类别。
4. **修复到哪一相？** 炎症相、增殖相、重塑相；反复发作则转向纤维化。
5. **分到哪一型？** 腹泻四型（渗透、分泌、炎症、动力）／便秘三层（慢传输、排出障碍、继发）。

## 执行步骤

```text
1. 抄原话，不改写：把要归位的那句放在第一行
2. 定位置：段位与层次先写，不写病名
3. 定轴：三类里选主副，各写一条证据
4. 量深度：三档里选一档，写出对应的后果类别
5. 判修复：三相里定位，反复发作者说明纤维化的理由
6. 分型：腹泻／便秘按判据分型；分型先于处置
7. 查报警：症状模式成立＋报警征象缺席，两者同时才谈功能性
8. 报边界：不给值、不作诊断、不写方案
```

## 硬约束

- **不给数值、单位、正常值、参考区间、百分比。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不作诊断，不作正常与异常判定。** 三类机制只作类别；报警征象只作进一步评估的方向。
- **不写治疗方案。** 药物、剂量、疗程、内镜与手术属临床决策；本 Skill 只写机制与分类。
- **不把方向性判断当阈值。** 出血后血尿素氮升高只作方向，讲义自己否掉了阈值用法。
- **引文逐字。** 标`补充·hermes-病理生理学讲义·第36章·N.M`；核不到就不引。讲义是本仓库原创正文，不写成任何外文教材的译本。

## 交付物

1. 一句位置判断（段位 + 层次）与一句主轴判断（主副两轴 + 证据）
2. 一档深度判断，附对应的后果类别
3. 一相修复判断，反复发作者附纤维化理由
4. 一个分型结论与支撑它的那条判据
5. 一张报警征象核对表与一处边界（不给值、不作诊断、不写方案）

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 病名当结论 | 机制被跳过 | 回三类坐标归位 |
| 跳过位置 | 病因谈得悬空 | 先定位再定机制 |
| 糜烂溃疡混谈 | 后果判断失真 | 用深度三档 |
| 功能性当排除 | 器质病变被漏 | 症状模式 + 报警征象 |
| 腹泻不分型 | 处理方向可能反向 | 先分型 |
| 越到治疗 | 越过教学边界 | 只写机制与类别 |

## 边界

本 Skill 只处理「病名 → 三类坐标 → 深度与分型」的结构化归位，不涉及数值、判定与临床决策。机制类别取自本仓库原创讲义第 36 章；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
