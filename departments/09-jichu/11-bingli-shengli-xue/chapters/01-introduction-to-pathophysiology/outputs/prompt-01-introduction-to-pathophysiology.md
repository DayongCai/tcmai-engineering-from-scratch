# Prompt：把一句话拆成「状态 / 因素 / 环节 / 判定」四层

## 用途

病理生理学最容易被糊过去的一句话是「他这就是某某病」。这句话把四件事压成了一件：他现在处在什么状态、是什么因素在起作用、经过哪几个环节、以及对他个人作出了什么判定。这个模板不让你补病名，而是把一句话按这四层拆开，再按四问补上机制，最后指出哪一层已经越界。

适用于读病例摘要、写机制说明、做课前讨论，也适用于后面各章的复盘：从第 2 章的稳态到第 20 章的休克，凡是「一个表现对应一个结论」的写法，都可以先用这四层过一遍。

## 使用前提

- 你手上是一段**描述**——一句话、一组体征或一段病程记录，不是一个待确诊的病例。
- 你读过讲义本章对应小节（`补充·hermes-病理生理学讲义·第1章·1.2` 这一级），能指出每条判断的出处。
- 你接受两条硬约束：**不产出任何数值**；**不作诊断、不作正常与异常的判定**。

## Prompt 正文（复制即用）

```text
你是病理生理学的机制助教。任务不是给结论，而是把一句话拆成四层，并指出哪一层越界。

【输入】
原话：<一句话或一段描述>
讲义定位：<补充·hermes-病理生理学讲义·第1章·1.M>

【任务，按顺序回答，不跳步】
1. 状态层：这句话说的是健康、亚健康、疾病，还是病程中的某一阶段？只作位置描述，不给个体定性。
2. 因素层：句中出现的因素是病因、条件、诱因，还是危险因素？逐条按讲义的两个限定判断：是否必不可少、是否决定特异性。
3. 环节层：如果它是一条机制链，写出四段：病因 → 与机体相互作用（损伤与抗损伤）→ 功能代谢紊乱 → 临床表现。缺哪段就写缺。
4. 用时态：这句描述落在病程的哪个时点？代偿期、失代偿期，还是转归的哪一格？
5. 判定层：原话里有没有直接对个体下结论的句子？有就点出来，并说明它缺哪三样东西（标准、检查、资质）。
6. 四问复核：涉及哪条机制？在哪一层？方向如何？此刻处于病程哪个时点？
7. 边界：这段拆解不能回答什么。

【硬约束】
- 不给任何数值、单位、正常值、参考区间、百分比。凡需数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作正常与异常判定，不作预后判定，不作疗效断言。转归四格只描述位置，不预测走向。
- 引讲义原文必须逐字，并标「补充·hermes-病理生理学讲义·第1章·1.M」；核不到就不引。
- 某一层缺证据就写「未给」，不要用推测填满。

【输出格式】
七个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的拆解（节选）

原话：「老人受凉后咳嗽发热，这就是肺炎，得赶紧抗感染。」讲义定位：补充·hermes-病理生理学讲义·第1章·1.2。

- **状态层**：句中有病因作用与相应表现，位置在疾病一侧；但「这就是肺炎」是判定，不是状态描述。
- **因素层**：受凉是诱因——它促使疾病在病因作用下发生，本身不满足「必不可少」与「决定特异性」两条；病原体才是病因；年龄属条件，它削弱防御、改变反应性。
- **环节层**：病因进入后先与机体相互作用（损伤与抗损伤），再出现功能代谢紊乱（发热属这一类），最后才是可观察的表现（咳嗽、啰音）。原话跳过了第二、三段。
- **时态**：处在疾病早期，未到转归；代偿与失代偿尚未分开写。
- **判定层**：「这就是肺炎」与「得赶紧抗感染」两句都越界：前者缺标准与检查，后者属处置决策。
- **四问复核**：机制属感染性损伤一类；层次在器官与整体之间；方向是损伤占上风；时点在早期。
- **边界**：不能由此推断病原种类、严重程度与处置方式；数值一律不给。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 病名当状态 | 「这就是肺炎」 | 回到状态层，只写位置与阶段 |
| 条件当病因 | 「因为年纪大了所以得病」 | 按两个限定重判：年龄削弱防御，属条件 |
| 诱因当病因 | 「受凉引起的」 | 诱因只解释此刻被促成，不解释得哪一种 |
| 跳过环节层 | 「感染所以发热」 | 补上相互作用与功能代谢紊乱两段 |
| 判定混进描述 | 「情况不太好」 | 点出它缺标准、检查、资质三样 |
| 偷给数值 | 「烧到三十九度」 | 触发硬约束，改为方向性表述 |

## 边界

本模板训练的是「状态 → 因素 → 环节 → 判定」的分层表达能力，不产生临床判断。四层划分取自《hermes-病理生理学讲义》第 1 章的表述；数值与判定不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
