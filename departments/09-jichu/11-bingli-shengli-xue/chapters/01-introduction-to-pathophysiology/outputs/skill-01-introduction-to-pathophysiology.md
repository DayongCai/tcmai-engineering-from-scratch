# Skill：病理生理学导论——四层拆分与四问复核

## 何时用

- 有人用一句话下结论（「他这就是某某病」），你需要说清这句话落在哪一层
- 要把一组散在体征串成机制链，却不知道该补哪一段
- 要区分病因、条件、诱因与危险因素这四个常被混用的词
- 要判断一段描述是在讲过程、讲表现，还是在给个体定性
- 遇到「这算不算病」「要不要紧」这类追问，需要一致的拒答口径

## 核心判据（四问）

1. **涉及哪条机制？** 直接损伤还是间接机制；若属间接，落在免疫损伤、炎症介质、神经-体液调节紊乱、代谢障碍四路中的哪一路。
2. **在哪一层？** 分子、细胞、组织器官、整体；一句话里只装一层的内容。
3. **方向如何？** 损伤与抗损伤的力量对比指向哪边；注意抗损伤过度也会造成损害。
4. **此刻处于病程哪个时点？** 代偿期还是失代偿期；在转归的哪一格。四问不保证结论正确，但能挡掉大部分说得通却站不住的推理。

## 执行步骤

```text
1. 抄原话，不改写：把要拆的那句话原样放在第一行
2. 定状态：健康 / 亚健康 / 疾病 / 病程阶段，只作位置描述
3. 辨因素：按两个限定（必不可少、决定特异性）判病因；再判条件、诱因、危险因素
4. 补环节：病因 → 相互作用 → 功能代谢紊乱 → 临床表现，缺段写缺
5. 标时点：代偿期 / 失代偿期 / 转归四格之一
6. 查越界：原话有没有对个体下结论，缺哪三样（标准、检查、资质）
7. 报边界：不写数值，不作诊断，不给转归预测
```

## 硬约束

- **不给数值、单位、正常值、参考区间、百分比。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不作诊断，不作正常与异常判定。** 亚健康尤其如此：讲义写明它缺乏统一判定标准，宜作风险提示而非诊断标签。
- **引文逐字。** 标「补充·hermes-病理生理学讲义·第1章·1.M」；核不到就不引。讲义是本仓库原创教学正文，不许写成任何外文教材的译本。
- **层次必标。** 分子、细胞、器官、整体四个尺度的表述不混写；涌现关系要说明，不能把细胞层的改变直接推成整体结论。
- **不作处置建议。** 用药、检查、监测项目属临床决策，本 Skill 只给机制与判据。

## 交付物

1. 一段四层拆解（状态 → 因素 → 环节 → 判定），缺层如实标缺
2. 一张因素表：病因、条件、诱因、危险因素各一条，附判定理由
3. 一句时点判断：代偿期、失代偿期或转归四格之一
4. 一处边界：本章不给值、不作诊断，数值须另立数据层

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 病名替代状态 | 「这就是肺炎」被当成描述 | 回到状态层，只写位置与阶段 |
| 条件当病因 | 年龄、性别被写成病因 | 按两个限定重判，归入条件 |
| 诱因当病因 | 「受凉引起的」被当成因果 | 诱因只解释此刻被促成 |
| 跳过环节层 | 病因直接跳到表现 | 补相互作用与功能代谢紊乱两段 |
| 阶段当形容词 | 代偿期与失代偿期混为一谈 | 标出时点，按判据分开写 |
| 判定混进描述 | 「情况不太好」 | 点出缺标准、检查、资质三样 |

## 边界

本 Skill 只处理「一句描述 → 四层拆分 → 四问复核」的结构化表达，不涉及数值、判定与临床决策。四层与四问取自《hermes-病理生理学讲义》第 1 章的表述；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
