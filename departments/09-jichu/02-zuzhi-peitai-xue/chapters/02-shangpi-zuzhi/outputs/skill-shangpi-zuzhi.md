# 上皮的极性一看出，功能就已经说出一半

## 核心判据

- 上皮组织由排列紧密的细胞与少量细胞间质组成，细胞形态较规则，彼此借特化的连接结构结合，组织内不含血管，营养由深部结缔组织内的毛细血管经渗透提供
- 极性一旦确认，后面的事大半就定了
- 极性还决定了一个常见的观察错误：把切片上「朝上」的一面当成游离面
- 被覆上皮是上皮组织的主要类别，其特征可归为四条：细胞排列紧密、细胞间质少、有基膜、有极性
- 被覆上皮按细胞排列的层次分为单层与复层，按表层细胞的形态分为扁平、立方、柱状
- 单层上皮内部再分三类，判据同样是形态与位置而不是感觉：单层扁平上皮细胞扁、核多居中、相互嵌合成连续薄层，分布于心血管与淋巴管腔面者称内皮，分布于胸膜、腹膜、心包表面者称间皮，也见于肺泡壁与肾小体壁层；单层立方上皮细胞近似立方形、核圆而居中，分布于肾小管、部分腺的导管与甲状腺滤泡；单层柱状上皮细胞高柱状、核椭圆而偏基底，分布于胃、肠、胆囊、子宫的黏膜面，游离面常分化出微绒毛或纤毛，细胞之间常有杯状细胞

## 边界

- 只写类别与要点，不写操作参数。
- 本章所述上皮类别、细胞连接与腺的分类均为教学用的形态学说明，用于训练镜下辨认与描述，不构成诊断依据，不作正常与异常的临床判定，不作疾病与发育异常的判定。
