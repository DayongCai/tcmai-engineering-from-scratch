# 没有人看过自己的发生，胚胎学的时间线是拼接出来的 · 提示词

## 用途

给「没有人看过自己的发生，胚胎学的时间线是拼接出来的」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「发生与发育不是同义词 → 时间线是拼出来的，阶段是工具 → 四个研究取向：方法决定能问什么问题 → 三类方法各有边界」这条链。
