# 神经元的形态差异，是它在回路里位置不同的证据

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；

4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 神经组织由神经元与神经胶质细胞组成
- 神经元的胞体是代谢与营养中心，形态多样，可呈圆形、卵圆形、锥体形、梭形或多角形；核大而圆、多居中央，染色质以常染色质为主故着色浅，核仁清晰
- 本章最该背熟的不是这些名字，而是一条分布规律：尼氏体存在于胞体与树突，不进入轴突；轴丘处胞质内没有尼氏体
- 树突自胞体发出，呈树枝状反复分支，表面有细小突起称树突棘，是形成突触的主要部位；树突的胞质含尼氏体、微管、神经原纤维与线粒体，但缺乏高尔基复合体
- 神经元的分类有三套并行口径，互不排斥，同一个神经元可以在三套里各有一个名字
- 突触是神经元之间或神经元与效应细胞之间传递信息的特化结构

## 边界

- 只写类别与要点，不写操作参数。
