# 基质不是填充物，是细胞每天在读的一份说明书 · 提示词

## 用途

给「基质不是填充物，是细胞每天在读的一份说明书」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「四类大分子，四种力学任务 → 基底膜：极薄的一层，决定极性 → 力学信号怎么走进细胞核 → 基质是动态的：合成、降解、交联，以及三维与二维的差别」这条链。

## 边界

本章为医学细胞生物学的教学材料，用于建立「成分—力学—信号」的分析框架，不构成医学意见、诊断或治疗建议。文中病名只用于说明机制；具体操作以现行规范与所在机构制度为准。
