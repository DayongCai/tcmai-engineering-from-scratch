# 调控的答案不在「开或关」，在「多少、何时、在哪」

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 比较时间尺度
- 一个反应有多快，取决于它用了哪一层
- （组装在启动子上，所有基因共用）与
- 增强子可以远距离、方向无关地起作用
- 因子以组合方式工作
- 浓度本身就是信息

## 边界

- 本章的「数十种因子」「时间尺度」均为**常引口径**，用于比较不同调控层的快慢；本章不给任何转录速率、mRNA 半衰期、蛋白半衰期或拷贝数的具体数值。
- 「四层」是教学切分。实际调控是耦联的：转录与剪接共转录发生，翻译与 mRNA 降解竞争同一批转录本；把层与层当成独立模块，会在解释耦联现象时失效。
- 组合码与噪声模型多来自定量单细胞研究，结论仍在修正；本章只取已被多体系重复支持的部分。
- 本章为医学细胞生物学的教学材料，用于建立「分层—时序—分布」的分析框架，不构成医学意见、诊断或治疗建议。文中机制说明为教学层面的概括。
