# 调控的答案不在「开或关」，在「多少、何时、在哪」 · 提示词

## 用途

给「调控的答案不在「开或关」，在「多少、何时、在哪」」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「中心法则的修订版：五个可调点 → 转录层：组合码，而不是单一开关 → 染色质层：先决定「能不能碰到」 → 转录后与翻译层：放大与衰减的四个把手」这条链。

## 边界

本章为医学细胞生物学的教学材料，用于建立「分层—时序—分布」的分析框架，不构成医学意见、诊断或治疗建议。文中机制说明为教学层面的概括；具体操作以现行规范与所在机构制度为准。
