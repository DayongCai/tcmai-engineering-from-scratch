# 分化不是学会新本事，是把已有的本事关掉大部分 · 提示词

## 用途

给「分化不是学会新本事，是把已有的本事关掉大部分」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「潜能的层级与分化的三个判据 → 表观遗传锁定：关掉容易，打开难 → 干细胞：三种来源，一条有争议的路 → 位置信息与器官发生」这条链。


## 边界

本章为医学细胞生物学的教学材料，用于建立「潜能—锁定—位置」的分析框架，不构成医学意见、诊断或治疗建议。涉及人体胚胎、胎儿组织与人体样本的研究须以知情同意与伦理审查为前提；具体操作以现行规范与所在机构制度为准。
