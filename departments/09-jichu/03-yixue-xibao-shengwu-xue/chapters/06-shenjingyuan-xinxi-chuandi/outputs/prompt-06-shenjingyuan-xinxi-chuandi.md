# 信号不是一路跑到底，是每一小段都重新发一次 · 提示词

## 用途

给「信号不是一路跑到底，是每一小段都重新发一次」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「极性：一个细胞，三个功能区 → 静息电位：三条成因，一条判据 → 动作电位：正反馈、全或无、不应期 → 突触：把电变回化学，再把化学变回电」这条链。

## 边界

本章为医学细胞生物学的教学材料，用于建立「梯度—门控—突触」的分析框架，不构成医学意见、诊断或治疗建议。文中病名只用于说明机制；具体操作以现行规范与所在机构制度为准。
