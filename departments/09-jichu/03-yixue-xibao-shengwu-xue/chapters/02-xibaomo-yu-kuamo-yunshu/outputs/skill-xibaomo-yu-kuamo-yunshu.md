# 膜的本事不是「挡住」，是「让该过的过得快，让不该过的过得慢」

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 细胞对离子的不透，是电活动的前提
- 会不会饱和？要不要耗能？
- 饱和性是最实用的判据
- 不靠识别，靠尺寸与配位
- 其一是借势进门（次级主动运输）
- 同向（symport）与反向（antiport）

## 边界

- 本章的通透性排序与泵的化学计量（3 Na⁺ : 2 K⁺ : 1 ATP）为**常引口径**，取自通用教科书，不是本章的实测结果；不同细胞、不同亚型的数值会有差异，本章不给任何具体膜电位、电导或速率的数值。
- 「三类转运蛋白」是功能分类，不是结构分类。同一个蛋白家族可以既有通道型也有载体型成员（如某些通道兼有门控与饱和特征），分类的用途是建立判据，不是给蛋白贴标签。
- 上皮极性模型以小肠与肾小管为原型。其他上皮（如肺泡、脉络丛）的蛋白配置不同，不能照搬；本章不给任何跨上皮电位的正负与大小。
- 本章为医学细胞生物学的教学材料，用于建立「梯度—蛋白—方向」的分析框架，不构成医学意见、诊断或治疗建议。文中一切机制说明均为教学层面的概括，临床检验判读与处置须由具备资质的执业人员依现行规范与所在机构制度作出。
