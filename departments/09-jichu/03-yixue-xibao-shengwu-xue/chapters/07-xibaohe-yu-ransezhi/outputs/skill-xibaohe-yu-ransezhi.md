# 染色质不是打包好的档案，是一份随时被翻开的活页

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 核膜在分裂期会完全崩解，再在末期重建
- 信号序列 + 转运受体 + 梯度
- 方向不是靠「推」，是靠梯度两侧不同的化学状态
- 核孔的通透性本身是可调的
- 一级：核小体
- 二级：30 纳米纤维

## 边界

- 本章的 147 个碱基对、30 纳米纤维等均为**常引口径**；不同物种、不同细胞类型的核小体间距与折叠形态有差异，本章不给压缩比、核孔通量或端粒长度的具体数值。
- 三级折叠是模型。活细胞内的染色质是动态的、液态样的，许多「结构」是瞬时统计的结果，不宜当成固定的层级建筑。
- 拓扑关联域与相分离都是近十余年的研究前沿，结论仍在修正；本章只取已被多体系重复支持的部分，具体分子名单从略。
- 本章为医学细胞生物学的教学材料，用于建立「折叠—可及—表达」的分析框架，不构成医学意见、诊断或治疗建议。文中病名只用于说明机制。
