# 增殖、分化、衰老、死亡不是四件事，是同一个开关的四个位置 · 提示词

## 用途

给「增殖、分化、衰老、死亡不是四件事，是同一个开关的四个位置」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「周期不是四段路程，是三道闸 → 增殖要算两笔账：数量与保真 → 分化：不是丢掉基因，是锁住程序 → 衰老：三种计时器同时走」这条链。

## 边界

本章为医学细胞生物学的教学材料，用于建立「周期—分化—衰老—死亡」的统一判据，不构成医学意见、诊断或治疗建议。文中一切机制描述均为教学层面的概括；具体操作以现行规范与所在机构制度为准。
