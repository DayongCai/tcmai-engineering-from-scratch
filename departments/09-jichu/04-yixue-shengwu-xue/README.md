## 四、这门课的读法

16 章按「细胞结构（1–6）→ 增殖与工程（7–8）→ 遗传规律（9–13）→ 群体·临床·中医（14–16）」排，
每章要回答三问：

1. **结构在哪一层**（膜 / 细胞器 / 核 / 染色体 / 基因）；
2. **功能怎么从结构读出来**（运输、合成、周期、传递）；
3. **变异落在哪一步**（基因突变、染色体畸变、多基因易感）。

第 4–6 章（膜、质、核）是细胞线的三根柱子，第 10–13 章（基因、单基因、多基因、染色体）是遗传线的四根；
其余各章都挂在这七根上。
