# Skill：缺氧——氧运输链、五个指标与四型断点

## 何时用

- 有人（包括你自己）用一句「他缺氧」把判断糊过去了，需要拆开到链上
- 手上有几项血氧指标的方向，却分不清是低张性、血液性、循环性还是组织性
- 要解释「为什么同一个人不喘却缺氧」「为什么贫血很重却不发绀」这类反直觉现象
- 要判断氧疗在这件事上大概能做什么、不能做什么
- 遇到「这个值多少算缺氧」的追问，需要一套一致的拒答口径

## 核心判据（五问）

1. **断在哪一段？** 外呼吸、血液携氧、循环灌注、细胞利用——四段，答不出段就还在讲现象。
2. **分压与容量，哪个动了？** 分压动 = 外呼吸；容量动 = 载体。这是低张性与血液性唯一的关键分野。
3. **动静脉氧差往哪边走？** 增大 = 灌注不足（取不到只能多取）；缩小 = 用不了（血里留下更多）。
4. **代偿到了第几层？** 呼吸最快、循环紧随、血液较慢、细胞最慢。用时间尺度而不是用「程度」判断现况。
5. **这次定位能承担什么？** 只能承担机制与类别，不能承担正常与异常的判定。

## 执行步骤

```text
1. 立链：外呼吸 → 血液携氧 → 循环灌注 → 细胞利用
2. 归位：把每一项指标挂到它读的那一段
3. 定位：按联动方向定断点，并为另外三段各写一句排除理由
4. 签名：写成「某降 → 某降 → 某不变」的方向串
5. 代偿：按时间尺度排四层，指出哪层来得及
6. 边界：说明只到机制层，追问数值统一回「教材不给值，另立数据层」
7. 反查：抽掉一项指标，看会剩下什么歧义
```

## 硬约束

- **不给数值、单位、正常值、参考范围、百分比；不给氧解离曲线的坐标；不给氧疗的水平与时间参数。** 需要数值才能回答的追问，统一回「教材不给值，需另立数据层（另立来源与校验）」。
- **不判正常与异常。** 指标组合能说明「断在哪」，不能说明「某人现在算不算异常」。
- **不用外观替代指标。** 发绀取决于还原血红蛋白的绝对量，喘取决于通气驱动，两者都不能替代指标组合。
- **引文逐字。** 标「教材·第N章·N.M.K」，核不到就不引。

## 交付物

1. 一条链上的一个断点（四段之一，附三条排除理由）
2. 一组签名（方向串，不含数值）
3. 一层代偿判断（哪层来得及、依据是什么）
4. 一处边界（不给值，须另立数据层）

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 四型当四个病名背 | 换一个指标组合就套不上 | 记住四个断点位置，型名只是标签 |
| 只看单项指标 | 饱和度低就判低张性，漏掉血液性 | 五项方向一起看，看联动 |
| 用发绀定位 | 贫血者严重缺氧也不发绀 | 回到容量与含量 |
| 把代偿当无代价 | 忽略心脏负荷与血液黏度上升 | 代偿本身可能是负担 |
| 被追问就报阈值 | 越出本书口径，且阈值无来源 | 统一回「教材不给值」 |

## 与相邻章节的接缝

- 上一章（酸碱平衡紊乱）：缺氧时的无氧代谢增强会把酸性产物推上来，两章的代谢侧在这里相交。
- 下一章（发热）：发热使代谢率升高、耗氧需求增加，供与需的关系随之改变。
- 再下一章（应激）：应激的血流重新分布与心率改变，直接改写灌注这一段。
- 全书：本章的链在休克（灌注）、缺血-再灌注（利用与再损伤）、呼吸系统疾病（外呼吸）三处反复复用。

## 边界

本 Skill 只处理「指标方向 → 断点定位」的结构化表达，不涉及数值、判定与临床决策。任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
