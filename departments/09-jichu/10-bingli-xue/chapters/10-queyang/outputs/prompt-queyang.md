# Prompt：把「他缺氧」拆成链上的一个断点

## 用途

病理学里最容易被糊过去的判断是「他缺氧了」。这个模板把这句话逼到指标上去：先说清氧走到哪一段断的，再用五个指标的联动方向给出签名，最后说明这次定位能承担什么、不能承担什么。适用于课堂讨论前的自检、病例讨论的机制梳理，以及读 11 章（发热）、12 章（应激）时反复套用——那两章讲的都是「全身反应」，而全身反应几乎都会牵扯到供氧。

## 使用前提

- 你手上有的是**一组指标的方向**（升高、降低、相对稳定），而不是一个病名，也不是一个具体数值。例：「动脉端分压偏低、容量稳定、含量下降、动静脉氧差早期缩小」。
- 你已经读过教材·第10章对应小节，手边能指出 10.1.1 到 10.4.3 的定位。
- 你接受一条硬约束：**本模板不产出任何数值，也不产出诊断**。

## Prompt 正文（复制即用）

```text
你是病理学的助教。任务不是给出判断，而是把一个「缺氧」的说法拆成氧运输链上的一个断点。

【输入】
指标方向：<逐项写升高 / 降低 / 相对稳定，不写数值>
教材定位：<教材·第N章·N.M.K>

【任务，按顺序回答，不跳步】
1. 立链：把氧的行程写成四段——外呼吸、血液携氧、循环灌注、细胞利用。只写段名，不写任何数值。
2. 读数：把给出的指标各自归位到它读的是哪一段（分压读推力、容量读载体上限、饱和度读结合比例、含量读实际载量、动静脉氧差读组织取走多少）。
3. 定位断点：按指标联动方向判断断在哪一段，并说出「为什么不是另外三段」。三段各给一句排除理由。
4. 写签名：用「某项降 → 某项降 → 某项不变」的形式写出本型的指标签名，不用数值，不用箭头以外的符号。
5. 代偿：按时间尺度排出四层代偿（呼吸 / 循环 / 血液 / 细胞），并指出本次情境里哪一层来得及、哪一层来不及，依据是什么。
6. 边界：说明这次定位在机制层面成立，但不足以判定任何个体的正常与异常；若被追问具体数值或阈值，统一回答「教材不给值，需另立数据层」。
7. 反查：如果抽掉其中一项指标，还能不能定位？给出会剩下的歧义，不要用数值弥补。

【硬约束】
- 不给任何数值、单位、正常值、参考范围、百分比，也不给氧解离曲线的坐标与氧疗的水平与时间参数。
- 不作诊断，不作病情与预后判定，不作疗效断言。
- 引教材原文必须逐字，并标「教材·第N章·N.M.K」；核不到就不引。
- 指标方向不足以定位时，直接说缺哪几项，不要猜。

【输出格式】
七个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的拆解（节选）

指标方向：动脉端血氧分压稳定、血氧容量降低、血氧饱和度接近相对水平、血氧含量降低。教材定位：教材·第10章·10.2.2。

- **立链**：外呼吸 → 血液携氧 → 循环灌注 → 细胞利用。
- **读数**：分压读推力，容量读载体上限，饱和度读结合比例，含量读实际载量。
- **定位断点**：断在血液携氧。排除外呼吸——推力稳定说明进入与交换没问题；排除灌注——灌注不足会使静脉端氧张力下降而不是容量下降；排除利用——利用障碍会使静脉端氧张力偏高。三段各有一处对不上。
- **写签名**：容量降低 → 含量降低，分压稳定。
- **代偿**：呼吸层没有明显需要（推力未降），循环层可以增加输送，血液层的造血增强需要时间因而来不及，细胞层的适应更慢。本次情境里来得及的是循环层。
- **边界**：这是机制定位，不是诊断。追问数值统一回「教材不给值，需另立数据层」。
- **反查**：抽掉容量这一项，就只剩「含量降低」，而含量降低在低张性、血液性、循环性三型里都能出现，歧义无法消解——这说明容量是这组指标里不可省的一项。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 用病名代替断点 | 「这是贫血性缺氧」 | 改成断点：「断在血液携氧这一段」 |
| 只报一项指标 | 「饱和度低，所以是低张性」 | 补齐五项方向，单项不足以定位 |
| 用发绀代替指标 | 「口唇发绀，属于低张性」 | 发绀取决于还原血红蛋白的绝对量，不能替代指标组合 |
| 把代偿当治愈 | 「已经代偿了，所以没问题」 | 追问代价：心脏负荷、血液黏度 |
| 偷给数值 | 「分压低于某个值就是……」 | 触发硬约束，改为「教材不给值」 |

## 边界

本模板训练的是「把缺氧写成断点定位」的表达能力，不产生临床判断。链与签名来自教材的类别与关系，参数不在本书范围内；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
