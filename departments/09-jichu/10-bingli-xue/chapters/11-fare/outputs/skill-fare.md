# Skill：发热——调定点、四段机制链与三个时相

## 何时用

- 有人（包括你自己）用「发烧」两个字把机制糊过去了，需要拆到调定点上
- 要区分发热、过热与生理性体温升高——三种体温都高，处置方向完全不同
- 要解释「为什么先冷得发抖、后来热得掀被子」这类时相表现
- 要判断某个说法有没有把「出汗」当成退热的原因（因果倒置）
- 遇到「多少度算发热」的追问，需要一套一致的拒答口径

## 核心判据（五问）

1. **调定点动没动？** 动了才是发热；没动而体温高，是过热或生理性体温升高。这是全章唯一的分野。
2. **链走到第几段？** 激活物 → 产致热原细胞 → 内生致热原 → 中枢介质 → 调定点。答不出段，说明还停在「有致热原」的口号上。
3. **「调定点 − 实际体温」这个差是什么符号？** 正 = 上升期，近零 = 持续期，负 = 下降期。时相是差值，不是时长。
4. **表现与方向对得上吗？** 畏寒与皮肤苍白属「加产热、减散热」；皮肤发红与出汗属「散热恢复或加强」。对不上，说明时相判错了。
5. **说到哪里为止？** 到机制层。温度值、分级界线、降温参数、预后判断都不在本层。

## 执行步骤

```text
1. 分真伪：调定点动没动
2. 走链条：四段各写有 / 无 / 不明
3. 定两量：调定点方向 + 实际体温相对位置（只写方向）
4. 推时相：差值正负 → 上升 / 持续 / 下降
5. 对表现：逐条挂到产热与散热的方向上
6. 说全身：代谢率 + 五个物质侧面 + 各系统功能（只写方向）
7. 划边界：机制层成立，个体判定不成立
```

## 硬约束

- **不给数值、单位、正常值、参考范围、百分比；不给体温分级界线；不给降温或用药参数。** 追问统一回「教材不给值，需另立数据层（另立来源与校验）」。
- **不判正常与异常。** 能说清「设定值被重设了」，不能说明「这个人现在算不算异常」。
- **不把效应当原因。** 出汗是调定点回降的结果，寒战是差值为正的结果；因果方向颠倒会让处置方向也颠倒。
- **不用病名代替链条。** 「这是感染性发热」不是机制说明，只是病因类别的一个标签。
- **引文逐字。** 标「教材·第N章·N.M.K」，核不到就不引。

## 交付物

1. 一句分类判定（发热 / 过热 / 生理性体温升高，附调定点依据）
2. 一条四段链（每段标有 / 无 / 不明）
3. 一个时相判定 + 该时相的产热散热方向
4. 一处边界（不给值，须另立数据层）

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 体温高即发热 | 把过热当发热处置，方向反了 | 先问调定点动没动 |
| 时相当时间表 | 用药打断病程后判不出期 | 用差值推，不用时长推 |
| 出汗即退热原因 | 推导出「捂汗退烧」这类反向操作 | 出汗是调定点回降的结果 |
| 跳过产致热原细胞 | 链条断在第一段，后面接不上 | 四段逐段标有 / 无 / 不明 |
| 被追问就报界线 | 越出本书口径，且界线无来源 | 统一回「教材不给值」 |

## 与相邻章节的接缝

- 上一章（缺氧）：发热使代谢率升高、耗氧需求增加，氧的供与需在这里相交。
- 下一章（应激）：致热因素引起的整体反应里包含应激性调节，两章共用「调节网络被改写」这套语言。
- 与炎症：炎症局部的产物本身就是一类激活物，两章在启动段相接。
- 与酸碱平衡紊乱、水电解质紊乱：代谢率升高与出汗失水，是两条直接的机制通道。
- 全书：本章的「设定值 + 差值」方法可迁移到体温调节、渗透压调节、血糖调节等所有带调定点的系统。

## 边界

本 Skill 只处理「表现方向 → 调定点与链条」的结构化表达，不涉及数值、判定与临床决策。任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
