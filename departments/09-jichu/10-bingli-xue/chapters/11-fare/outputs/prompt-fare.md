# Prompt：把「他发烧了」拆成一条「设定值被重设」的链

## 用途

发热这一章最容易被糊过去的一句话是「他发烧了」。这个模板把它逼到调定点上：先分清是真发热还是体温高而调定点没动，再走完四段机制链，最后用「调定点 − 实际体温」这个差推出时相。适用于课堂讨论前的自检、病例讨论的机制梳理，以及读 12 章（应激）时对照——两章都以「调定点/调节网络被改写」为核心，方法可以迁移。

## 使用前提

- 你手上是**一组表现的方向**，不是一个病名，也不是一个温度读数。例：「起病时畏寒、寒战、皮肤苍白，随后皮肤转红、出汗」。
- 你已经读过教材·第11章对应小节，能指到 11.1.1 至 11.4.3 的定位。
- 你接受两条硬约束：**不产出任何数值**，**不产出任何判定**。

## Prompt 正文（复制即用）

```text
你是病理学的助教。任务不是判断「烧不烧」，而是把一个「发烧」的说法拆成一次调定点的重设。

【输入】
表现方向：<逐项写有 / 无、升高 / 降低 / 相对稳定，不写数值>
教材定位：<教材·第N章·N.M.K>

【任务，按顺序回答，不跳步】
1. 分真伪：先答调定点动没动。动 → 发热；未动而体温高 → 过热或生理性体温升高，并说出是哪一种、依据是什么。
2. 走链条：按四段写——激活物（什么类别）→ 产致热原细胞 → 内生致热原 → 中枢介质 → 调定点上移。每段只写"有 / 无 / 不明"，不写分子细节。
3. 定两量：说明此刻调定点在什么方向、实际体温相对它在什么位置。只写方向，不写数值。
4. 推时相：用「调定点 − 实际体温」的差推时相——差为正 → 上升期；近于零 → 持续期；为负 → 下降期。写出该时相的产热 / 散热方向。
5. 对表现：把输入里的表现逐条挂到该时相的方向上，解释「畏寒」与「皮肤苍白」为什么同时出现，「皮肤发红」与「出汗」为什么出现在另一期。
6. 说全身：代谢率与五个物质侧面（糖、脂肪、蛋白质、水电解质、维生素）各写方向；功能按系统写（中枢、循环、呼吸、消化、泌尿、防御），只写方向与类别。
7. 划边界：说明这一整套只在机制层成立，不足以判定任何个体的状态；被追问温度值、分级界线或降温参数时，统一回「教材不给值，需另立数据层」。

【硬约束】
- 不给任何数值、单位、正常值、参考范围、百分比；不给体温分级界线、不给降温或用药参数。
- 不作诊断，不作正常与异常判定，不作预后判定，不作疗效断言。
- 引教材原文必须逐字，并标「教材·第N章·N.M.K」；核不到就不引。
- 激活物或内生致热原的环节不明时，直接写「不明」，不要猜。

【输出格式】
七个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的拆解（节选）

表现方向：起病畏寒、寒战、皮肤苍白；随后皮肤转红、出汗增多、精神倦怠。教材定位：教材·第11章·11.2.1。

- **分真伪**：调定点上移 → 属发热。过热与生理性体温升高都要先排除，依据是调定点未动。
- **走链条**：激活物有（类别待按情境补），产致热原细胞被调动，内生致热原有，中枢介质变，调定点上移。
- **定两量**：调定点已在新高位；实际体温起初低于它，其后追上。
- **推时相**：前半段差为正 → 上升期（产热相对增加、散热相对减少）；后半段差近于零 → 持续期（高水平平衡）。
- **对表现**：畏寒与皮肤苍白是同一件事的两面——中枢判定「不够热」，于是骨骼肌节律性收缩（寒战）加产热、皮肤血管收缩减散热；皮肤转红与出汗是差近于零后散热恢复运作的表现。
- **说全身**：代谢率升高，糖与脂肪与蛋白质分解加强，经皮肤与呼吸失水增加；循环与呼吸加快，消化受抑，精神倦怠。
- **划边界**：机制层成立，个体判定不成立。追问温度值统一回「教材不给值，需另立数据层」。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 用体温高当定义 | 「体温高就是发热」 | 先答调定点动没动，再谈体温 |
| 把出汗当退热原因 | 「出了汗所以退烧了」 | 改成「调定点回降所以出汗」 |
| 链条跳段 | 从「有致热原」直接到「体温升高」 | 补齐产致热原细胞、内生致热原、中枢介质、调定点四段 |
| 时相当成时间表 | 「过了几个小时就进持续期」 | 用差值推时相，不用时长推 |
| 偷给数值 | 「超过多少度才算发热」 | 触发硬约束，改为「教材不给值」 |

## 边界

本模板训练的是「把发热写成一次设定值重设」的表达能力，不产生临床判断。链条与时相来自教材的类别与关系，温度、时程与处置参数不在本书范围内；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
