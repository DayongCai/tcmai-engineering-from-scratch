# Prompt：判断一个肿瘤的形态，先问「凭哪几面」

## 用途

病理学里最容易糊过去的答案是「这是恶性肿瘤」。这个模板把这句话逼到判据上去：先定起源组织与实质，再看分化与异型性，再看生长方式与扩散，最后把几面交叉起来说清「凭哪几面、哪一面不一致」。适用于读片讨论前的自检、写形态描述报告之前的梳理，以及读各器官肿瘤各论时反复套用。

## 使用前提

- 你面对的是一个**形态所见**，不是一个病名或一句结论。例：「一个边界清楚的结节，切面灰白、质韧」「一片细胞排列紊乱、核大小不一的组织」。
- 你手边有教材·第6章·N.M.K 的定位，读过对应小节。
- 你接受两条硬约束：**不产出任何数值**；**只谈形态与类别，不下诊断、不判分期与预后**。

## Prompt 正文（复制即用）

```text
你是病理学的读片助教。任务不是下结论，而是把所见写成一段可复核的描述，并说明这段描述支持什么、不支持什么。

【输入】
所见：<一段形态描述，不带病名，不带判断>
教材定位：<教材·第N章·N.M.K>

【任务，按顺序回答，不跳步】
1. 起源与实质：这个病变的实质属于哪一类组织来源（上皮 / 间叶 / 淋巴造血 / 神经 / 其他）？依据是形态的哪一处？
2. 间质与比例：间质由什么构成？实质与间质的比例如何影响质地、颜色与边界？
3. 组织结构异型性：细胞排列的层次与极向有无改变？腺体或上皮与间质的关系是否紊乱？
4. 细胞异型性：细胞大小形状是否一致？核的形态、核浆比例、染色质与核仁有无改变？有无核分裂象类别改变或病理性核分裂？
5. 分化推定：按上面的形态，分化偏高还是偏低？依据是「与起源组织接近还是偏离」，不给级别名称、不给数值。
6. 生长方式：膨胀性、浸润性还是外生性？包膜有无、是否完整？边界清楚还是不清？依据是哪一处形态？
7. 扩散线索：有无直接蔓延、淋巴道、血道、种植的表现？分别说明所见的依据。
8. 交叉判定：把上面几面列成一行，指出哪几面同向、哪一面不一致；说明「表现特殊、需综合理解」的情形该怎么表述。
9. 边界：这段描述不能回答什么（不判病因、不判分期与预后、不给数值、不给处理建议）。

【硬约束】
- 不给任何数值、单位、正常值、参考范围、百分比、分级与分期。凡需要数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作病情与预后判定，不作疗效断言，不作排名。
- 名称跟起源组织走：不以部位代替组织来源，不以形态特点代替组织来源；遇到习惯名称要说明它属例外。
- 引教材原文必须逐字，并标「教材·第N章·N.M.K」；核不到就不引。

【输出格式】
九个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的拆解（节选）

所见：一个边界清楚的结节，切面灰白、质韧，镜下细胞排列成束、核形态较一致，未见明显核分裂象类别改变；周围组织呈受压改变。教材定位：教材·第6章·6.2.1。

- **起源与实质**：实质呈束状排列的纤维样细胞，按形态归入间叶来源。
- **间质与比例**：间质较少，实质占优势，故质地偏韧、切面偏灰白。
- **组织结构异型性**：束状排列保留一定极向，未见腺体结构紊乱。
- **细胞异型性**：细胞与核形态较一致，单一性尚存，未见病理性核分裂。
- **分化推定**：与起源组织接近，分化偏高（不给级别名称）。
- **生长方式**：边界清楚、周围呈受压改变，符合膨胀性生长的形态；包膜是否完整需在描述中另写一句。
- **扩散线索**：所见范围内未见沿间隙延伸或脉管内肿瘤细胞团。
- **交叉判定**：分化、异型性、生长方式三面同向，指向「偏良性」的一组形态；但不能据此断言不复发——教材明写良性也不等于没有影响。
- **边界**：不能判断病因，不能给分期与预后，不给任何数值。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 用一个特征下结论 | 「有包膜所以是良性」 | 补齐分化、异型性、生长方式、扩散几面再交叉 |
| 异型性等于恶性 | 「异型性明显，肯定是恶性」 | 回到「形态比较 + 多项交叉」，异型性只是其中一面 |
| 名称推来源 | 「腺瘤长在腺体里」 | 名称跟实质走：腺瘤指实质呈腺样，不是部位 |
| 习惯名称按字面读 | 「黑素瘤是良性」 | 归入习惯名称一类，另说明其在分类框架中的位置 |
| 偷给分级分期 | 「属于中级」 | 触发硬约束，改为类别表述 |
| 把继发改变当原发 | 把出血区当成肿瘤本身的特点 | 原发与继发分开写，各自注明依据 |

## 边界

本模板训练的是「形态所见 → 多面交叉 → 可复核描述」的表达能力，不产生临床判断。分类与命名框架来自教材的类别与关系，数值、分级与分期不在本书范围内；任何涉及个体的评估须由具备资质的人员依现行规范作出。
