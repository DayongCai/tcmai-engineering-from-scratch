# Skill：肿瘤——克隆性、异型性与扩散的四面交叉

## 何时用

- 有人（包括你自己）用「这是恶性肿瘤」把一段形态所见糊过去了，需要拆开
- 要判断一段肿瘤描述有没有把「异型性」直接当成「恶性」来用
- 要在总论（肿瘤）与各器官肿瘤各论之间迁移同一套判据语言
- 遇到「有多大」「几期」「能活多久」这类追问，需要一套一致的拒答口径

## 核心判据（四问）

1. **实质来自哪一类组织？** 上皮 / 间叶 / 淋巴造血 / 神经 / 其他。名称跟实质走，不跟部位走。
2. **异型性在哪一面？** 组织结构面（层次、极向、腺体与间质关系）还是细胞面（形态、核、核分裂象类别）。两面必须分列。
3. **分化与异型性是否反变一致？** 分化高则异型性轻，分化低则显著；不一致时先查起源组织的结构认识是否到位。
4. **几面是否同向？** 分化、异型性、生长方式、扩散、复发倾向、对机体影响——同向才谈得上倾向性结论，不一致就写「表现特殊，需综合理解」。

## 执行步骤

```text
1. 抄所见，不抄病名：写「边界清楚的灰白结节」，不写「纤维瘤」
2. 定实质与间质：实质类别决定命名与行为，间质决定质地与血供
3. 分列两面异型性：组织结构面一句，细胞面一句
4. 推分化：与起源组织比「接近还是偏离」，不给级别名称与数值
5. 判生长方式：膨胀 / 浸润 / 外生；包膜有无与是否完整；边界清与不清
6. 查扩散线索：直接蔓延、淋巴道、血道、种植，各自说明依据
7. 交叉：把各面列成一行，标出同向与不一致
8. 报边界：不判病因、不判分期与预后、不给数值、不给处理建议
```

## 硬约束

- **不给数值、单位、正常值、参考范围、百分比、分级与分期。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不判诊断与预后。** 四面交叉能说明「形态支持什么」，不能说明「这个人会怎样」。
- **名称跟起源组织走。** 不以部位代替组织来源，不以形态特点代替组织来源；习惯名称（淋巴瘤、白血病、黑素瘤、精原细胞瘤）要单独标注为例外。
- **「多见于」保持原样。** 膨胀性多见于良性、浸润性多见于恶性——引用时不许改成「就是」。

## 交付物

1. 一段形态描述（部位 → 实质/间质 → 两面异型性 → 生长方式 → 扩散），所见与分析分离
2. 一句分化推定：偏高还是偏低，依据是哪一处形态
3. 一行交叉表：几面同向 / 哪一面不一致
4. 一处边界：本章不给值、不分期，数值与分期须另立数据层

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 异型性等于恶性 | 用一个形态特征回答一组问题 | 回到四面交叉，异型性只是其中一面 |
| 包膜等于良性 | 忽略部分良性可复发、部分恶性可有假包膜 | 包膜只是生长方式的标志之一 |
| 名称推来源 | 「腺瘤长在腺体里」 | 名称跟实质走：实质呈腺样才叫腺瘤 |
| 习惯名称按字面读 | 把黑素瘤、淋巴瘤当良性 | 归入习惯名称一类，另说明框架位置 |
| 继发当原发 | 把出血、坏死当成肿瘤本身特点 | 原发与继发分开描述，各注依据 |
| 被追问就报分期 | 越出本书口径，且无来源 | 统一回「本书不给值，另立数据层」 |

## 与相邻章节的接缝

- 上一章（炎症）：反应性增生与肿瘤性增生的分界（克隆性）是本章第一道判据；慢性炎症的长期刺激在本章病因学里再次出现。
- 下一章（水、电解质代谢紊乱）：肿瘤的全身影响（消耗、代谢改变）在那章只作背景，不展开。
- 各论（呼吸、消化、泌尿、生殖系统疾病）：本章的四问在每一个器官的肿瘤里都要重跑一遍，只是起源组织的类别变了。

## 边界

本 Skill 只处理「形态所见 → 四面交叉 → 可复核描述」的结构化表达，不涉及数值、分级、分期与临床决策。任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
