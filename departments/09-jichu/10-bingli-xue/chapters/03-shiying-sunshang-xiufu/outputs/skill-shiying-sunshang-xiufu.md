# Skill：适应、损伤与修复——三段形态与一条连续线

## 何时用

- 一段形态描述把适应、损伤、修复写成三块，彼此没有接续
- 要判断某处所见属于哪一类（萎缩/肥大/增生/化生、可逆/不可逆、再生/纤维性修复/创伤愈合）
- 遇到「可逆还是不可逆」的追问，需要一套不靠形态划线的答法
- 要按固定顺序写形态描述，使别人能复核

## 核心判据（四问）

1. **这一段在过程里的什么位置？** 适应（调整还在起作用）/ 损伤（调整被突破）/ 修复（重建）。答不出位置，类别就贴不上。
2. **判据是形态的还是过程的？** 可逆与不可逆之间没有单一形态界线，靠「解除后能否逐步恢复」这一过程判据。
3. **这是类别还是程度？** 「萎缩」「坏死」是类别；「轻度」「重度」「较大」是程度。程度不进正文。
4. **三段怎么排先后？** 依据是有害因素的作用强弱与持续、组织的再生潜力、缺损范围；排不出就写「依据不足」。

## 执行步骤

```text
1. 逐句归段：适应 / 损伤 / 修复，分不进去的单列「待归类」
2. 定类别：每段只写类别，删掉程度词
3. 分区描述：部位 → 层面 → 组织类别 → 细胞形态 → 排列关系 → 间质成分 → 界限关系
4. 写区分依据：哪一处像两类之间，依据是形态的还是过程的
5. 写接续：谁在前谁在后，依据是什么
6. 列待核实：解释不了的逐条写，不填推测
7. 边界自查：数值、尺寸、分级、时程、诊断与预后字样一律清除
```

## 硬约束

- **不写数值、单位、尺寸、数量、分级与分期与分度、时程与频次。** 需要数值的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不判正常与异常，不作诊断与病情与预后判定。** 形态能说明「像什么」，不能说明「算哪一类」的全部。
- **可逆线不在形态上。** 教材明写：没有单一的形态界线，区分要结合形态与成因与过程的连续关系。
- **引文逐字。** 标「教材·第N章·N.M.K」，核不到就不引。
- **敏感信息。** 涉人体标本与图像只写类别，不写可定位信息；脱敏与去标识化不得混称。

## 交付物

1. 一张归段表：三段的句子、类别、依据
2. 一段分区描述：按七项固定顺序写
3. 一句接续说明：三段谁在前谁在后
4. 一处待核实：缺的是哪一项观察

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 按节序写 | 一块组织写成三块 | 改按过程位置排 |
| 段内混类 | 一句话里两类并存 | 拆句逐段归位 |
| 形态划可逆线 | 用某个特征断言可恢复 | 改为待核实，注明依据不足 |
| 程度词代替类别 | 「轻度水肿」写满全篇 | 只留类别，程度删掉 |
| 漏掉间质 | 只写细胞，不写间质与界限 | 补齐七项顺序 |
| 结论先行 | 先写「符合某某改变」 | 删结论，只留描述与关系 |

## 与相邻章节的接缝

- 上一章（疾病概论）：给了原因与条件、局部与整体的框架；本章把「形态变化」落到具体类别。
- 下一章（局部血液循环障碍）：把本章的「损伤」展开到循环与液体层面，坏死与出血在此再次出现。
- 再下一章（炎症）：把本章的「修复」展开——肉芽组织与瘢痕在炎症的结局里反复出现。

## 边界

本 Skill 只处理「形态 → 类别 → 关系」的结构化表达，不涉及数值、判定与临床决策。任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
