# Prompt：把一块切片里的「适应 / 损伤 / 修复」分开写

## 用途

病理学最常出现的一种描述失败，是把一块组织写成三块：先说萎缩、再说坏死、再说肉芽组织，彼此之间没有关系。这个模板把三者按「过程里的位置」重新排一次：先分类别，再分区描述，最后写接续。适用于形态描述练习、读片记录与实习报告的结构梳理。

## 使用前提

- 你手上是**一块组织的观察所见**，而不是一个诊断结论。
- 你已经读过教材 3.1–3.3 的对应小节，手边有教材·第N章·N.M.K 的定位。
- 你接受一条硬约束：**本模板不产出任何数值、尺寸、分级与时程**。

## Prompt 正文（复制即用）

```text
你是病理学的形态描述助教。任务不是给出结论，而是把一块组织里的三种反应按过程位置分开写。

【输入】
观察所见：<一段原始描述，可以很乱，只写看见了什么>
观察层次：<大体 / 镜下，选一层为主>
教材定位：<教材·第N章·N.M.K>

【任务，按顺序回答，不跳步】
1. 分段归位：把所见逐句分到「适应 / 损伤 / 修复」三段里，分不进去的句子单列为「待归类」。
2. 类别判定：每段写明属于哪一类——萎缩 / 肥大 / 增生 / 化生；可逆 / 不可逆（坏死或凋亡）；再生 / 纤维性修复 / 创伤愈合。只写类别，不写程度。
3. 分区描述：按区域写形态，顺序固定为部位 → 层面 → 组织类别 → 细胞形态 → 排列关系 → 间质成分 → 界限关系。
4. 区分判据：对每一处「像是两类之间」的所见，写明你依据哪一条把它归入某一类，并说明这条依据是形态的还是过程的。
5. 接续关系：三段之间谁在前、谁在后，依据是什么（作用强弱与持续、组织的再生潜力、缺损范围）。
6. 待核实：哪几处所见解释不了，逐条列出，不填推测。
7. 边界自查：这段描述里有没有出现数值、尺寸、分级、时程，有没有出现诊断或预后字样？逐条标出并改写。

【硬约束】
- 不写数值、单位、尺寸、数量、分级与分期与分度、时程与频次。
- 不作诊断、不作病情与预后判定、不作正常与异常判定、不作疗效断言。
- 可逆与不可逆的区分要写明「依据是过程的还是形态的」——教材说没有单一的形态界线。
- 涉人体标本与图像只写类别，不写可定位信息；脱敏与去标识化不得混称。
- 引教材原文必须逐字，并标「教材·第N章·N.M.K」；核不到就不引。

【输出格式】
七个小标题各答一到三句，第 2 步用表格式短句列出；末尾另起一行写：
「本回答为教学描述推演，不写数值，不构成诊断或治疗或用药依据。」
```

## 示例：一次合格的整理（节选）

观察所见：某器官切面见一处界限较清的区域，该区细胞体积偏小、排列较密；邻近另有一片结构崩解、核显示不清的区域；两片之间及边缘见细颗粒状、湿润的组织。教材定位：教材·第3章·3.4.1。

| 步骤 | 结果 |
|---|---|
| 分段归位 | 「细胞体积偏小、排列较密」→ 适应；「结构崩解、核显示不清」→ 损伤；「细颗粒状、湿润的组织」→ 修复 |
| 类别判定 | 适应侧为萎缩类别；损伤侧为坏死类别（核的形态变化待进一步描述）；修复侧为肉芽组织类别 |
| 分区描述 | 三区分别按部位与层面与细胞排列与间质与界限七项写，界限关系单列 |
| 区分判据 | 萎缩与坏死的区分依据是「结构是否崩解」，属形态依据；可逆与不可逆的区分依据在这里不足，标为待核实 |
| 接续关系 | 损伤在前、修复在后；萎缩与损伤的先后不能由形态单独判定，写明依据不足 |
| 待核实 | 核的具体形态（固缩、碎裂、溶解）未描述；两区之间是否有过渡带未观察 |
| 边界自查 | 原稿「坏死面积较大」含尺寸推断，已删；「提示预后不佳」属越界，已删 |

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 按节序写 | 三段各写一段，互不相干 | 改按过程位置排，补接续 |
| 段内混类 | 一句话里既有萎缩又有坏死 | 拆句，逐句归一段 |
| 用形态划可逆线 | 「这个形态说明还能恢复」 | 改为「依据不足，待核实」 |
| 只写最明显处 | 其余区域从略 | 分区描述，每区都写 |
| 偷给程度 | 「轻度」「重度」 | 改为类别表述，删程度词 |
| 结论先行 | 先写「符合某某改变」 | 删结论，只留描述与关系 |

## 边界

本模板训练的是「把一块组织写成三段关系」的表达能力，不产生临床判断。类别框架来自教材的形态与关系，参数与阈值不在本书范围内；任何涉及个体的评估须由具备资质的人员依现行规范作出。
