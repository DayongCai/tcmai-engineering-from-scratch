# Skill：局部血液循环障碍——四段链与方向判别

## 何时用

- 有人（包括你自己）用「循环障碍」四个字把一处标本糊过去了，需要定位
- 要在充血 / 淤血 / 出血 / 血栓 / 栓塞 / 梗死之间做归类，且几类混在一起
- 要判断一段病理学叙述「越了几层」：把镜下的单处所见直接说成器官功能状态
- 遇到「这有多大 / 多重」这类追问，需要一套一致的拒答口径

## 核心判据（四问）

1. **血在哪一段出了偏差？** 多了、出不去、出来了、凝住了、被冲走了、供血断了。答成病名，说明还在背名词。
2. **方向对不对？** 充血只看两条：鲜红加温度升高指向动脉端；暗紫加温度降低指向静脉端。程度不是判据。
3. **上游与下游是什么？** 每一段都要能说出「谁提供了它的条件」与「它继续发展会变成哪一段」。答不出下游，说明链没接上。
4. **判据是哪一条？** 例如「血栓还在不在原地」分出机化与脱落；「组织致密还是疏松、有没有双重供血」分出白色与红色梗死。判据错，分类必错。

## 执行步骤

```text
1. 抄所见，不抄病名：写「切面暗紫、温度低、有血性液体渗出」，不写「淤血」
2. 定位到四段链中的一段，说出依据
3. 若为充血：用色泽与温度判方向，不用深浅判程度
4. 若为出血：按部位与机制两个维度各填一次，说明维度不互斥
5. 若为血栓：对应血管壁 / 血流 / 血液成分三族，并放回时间线（起始 / 体部 / 尾部 / 微循环）
6. 若为栓塞：先画血流方向，再定来源与停驻部位
7. 若为梗死：用组织密度 + 侧支状态 + 有无静脉回流受阻判类型，不用颜色深浅
8. 反查：抽掉某一条判据，结论会错在哪里（给可观察差别，不给数值）
```

## 硬约束

- **不给数值、单位、参考值、参考范围、百分比、分级分期。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不判正常与异常，不作诊断与预后判定。** 形态能说明与环节的对应，不能说明某人现在是否异常。
- **引文逐字。** 标「教材·第N章·N.M.K」，核不到就不引；不许把教材里的学科对话当成古籍引文。
- **层次标注。** 本章的观察单位是一个部位（器官与组织层）；把镜下所见直接说成器官功能状态，属跨层直推。

## 交付物

1. 一处定位：链的哪一段 + 依据
2. 一条方向判别（若为充血）或一对维度（若为出血）
3. 一条上下游接续：上游条件 + 下游去向 + 判据
4. 一处边界：本章不给值，数值须另立数据层

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 用病名代替所见 | 归类无从下手，只剩「血出了问题」 | 重填部位、色泽、温度、切面、镜下结构 |
| 用程度判方向 | 把淤血说成充血 | 换回方向指标：鲜红加温度升高 / 暗紫加温度降低 |
| 四类血栓当四种病 | 在标本面前失效 | 改成时间线上的位置与血流条件 |
| 只按颜色判梗死 | 把「血进不去」误当「出血多」 | 用组织密度 + 侧支 + 静脉回流三个条件 |
| 跳过判据 | 结论无法复核 | 每一段都说出判据是哪一条 |
| 被追问就报尺寸 | 越出本书口径，且数值无来源 | 统一回「本书不给值，另立数据层」 |

## 边界

本 Skill 只处理「形态所见 → 四段链」的结构化表达，不涉及数值、判定与临床决策。任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
