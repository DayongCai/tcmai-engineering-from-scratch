# Prompt：把一处循环障碍的标本放回四段链上

## 用途

病理学最容易被糊过去的答案是「这是循环障碍」。这个模板把一句结论逼到链上：先问血在哪一段出了偏差，再问这一段的上游是什么、下游是什么、判据是哪一条。适用于标本观察前的自检、病例讨论的机制梳理，以及读后续各章（炎症、修复、器官病理）时反复套用。

## 使用前提

- 你手上是**一处可观察的改变**，不是一个病名。例：「切面暗紫、温度低、有血性液体渗出」「管腔内灰白色质块与管壁相连」「器官内楔形病灶、色淡、边界清」。
- 你已经读过教材对应小节，手边有教材·第N章·N.M.K 的定位。
- 你接受一条硬约束：**本模板不产出任何数值**。

## Prompt 正文（复制即用）

```text
你是病理学的助教。任务不是给这处病灶命名，而是把它放回一条链上，说清它在链的哪一段。

【输入】
所见：<一句话描述肉眼与镜下所见，不带病名，不带判断>
教材定位：<教材·第N章·N.M.K>

【任务，按顺序回答，不跳步】
1. 定位：这处改变属于链的哪一段——血多了 / 血出不去 / 血出来了 / 血凝住了 / 凝块被冲走了 / 供血断了？给出依据。
2. 方向：如果是充血，判断是动脉性还是静脉性。依据是色泽与温度这两个方向指标，不是「红得厉不厉害」。
3. 维度：如果是出血，按部位（内 / 外）与机制（破裂性 / 漏出性）两个维度各填一次，说明维度之间不互斥。
4. 条件族：如果是血栓，把所见对应到血管壁、血流、血液成分三族里，指出它在时间线上的位置（起始 / 体部 / 尾部 / 微循环）。
5. 上游：这一段的上游是什么？谁提供了它的条件？
6. 下游：如果它继续发展，下一段是什么？判据是哪一条（例如「血栓还在不在原地」决定机化还是脱落）。
7. 反查：如果判据换成另一条（例如只按色泽深浅判梗死类型），结论会错在哪里？给出可观察的差别，不要给数值。
8. 边界：这处所见不能推出什么？说清形态描述与临床判断之间的界线。

【硬约束】
- 不给任何数值、单位、参考值与参考范围，不给尺寸、范围、数量的数值；也不给百分比与分级分期。
- 不作正常与异常的判定，不作诊断，不作病情与预后判定，不作疗效断言。
- 引教材原文必须逐字，并标「教材·第N章·N.M.K」；核不到就不引。
- 若所见不足以定位，直接说缺哪一项（部位 / 色泽 / 温度 / 切面 / 镜下结构），不要猜。

【输出格式】
八个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/治疗/用药依据。」
```

## 示例：一次合格的定位（节选）

所见：器官内楔形病灶，色泽较淡，边界较清，底朝表面、尖朝门部，周边有一圈充血出血带。教材定位：教材·第4章·4.4.2。

- **定位**：链的末段——供血断了之后的缺血性坏死。
- **方向**：不适用（不是充血，是供血中断）。
- **维度**：按病灶色泽与出血状态分为贫血性与出血性，本例归贫血性。
- **条件族**：不适用；缺血性坏死看的是原因（动脉阻塞、受压、静脉阻塞）与条件（吻合与侧支、组织耐受）。
- **上游**：动脉阻塞或持续痉挛；本例的楔形与器官的血管树分支形状对应。
- **下游**：炎性反应 → 肉芽组织自周边长入 → 瘢痕。
- **反查**：若只按「颜色深不深」判，会把「组织致密、血进不去」误当成「出血多」；正确判据是组织密度与侧支状态，加静脉回流是否受阻。
- **边界**：楔形与色淡只说明形态与供血环节的对应，不说明某个人现在的功能状态。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 用病名代替所见 | 「这是肺梗死」 | 重填所见，只写可观察的项目：部位、色泽、边界、形状、镜下结构 |
| 用程度代替方向 | 「红得很厉害，所以是动脉性充血」 | 换回方向指标：鲜红加温度升高 / 暗紫加温度降低 |
| 把四类血栓当四种病 | 「这是混合血栓病」 | 改成时间线上的位置：起始 / 体部 / 尾部 / 微循环 |
| 跳过判据 | 直接说「会机化」 | 追问判据：血栓还在不在原地、构成疏松还是致密 |
| 偷给数值 | 「病灶大约几厘米」 | 触发硬约束，改为类别语汇：范围局限 / 较广 |

## 边界

本模板训练的是「把形态放回链上」的表达能力，不产生临床判断。链的结构来自教材的类别与关系，尺寸、范围、时程等参数不在本书范围内；任何涉及个体的评估须由具备资质的人员依现行规范作出。
