# Skill：炎症——三要素配比、两套坐标与防御的两重性

## 何时用

- 有人（包括你自己）用「这是炎症」把一段形态所见糊过去了，需要拆开
- 要在总论（炎症）与各论（肺炎、肝炎、肾炎、脑膜炎）之间迁移同一套配比语言
- 要判断一段叙述有没有把「按局部变化分型」与「按病程分急慢」两套坐标混着用
- 遇到「体温多少算发热」「白细胞多少算升高」这类追问，需要一套一致的拒答口径

## 核心判据（四问）

1. **三要素各是什么配比？** 变质（伤）、渗出（援）、增生（补）三样在任何炎症里都有，类型划分看的是谁最突出，不是有没有。
2. **渗出物属什么性状类别？** 浆液性 / 纤维素性 / 化脓性 / 出血性 / 卡他性——这一层决定「渗出性炎」内部再分到哪一格。
3. **这是哪一套坐标？** 配比归型与病程归急慢是两套独立坐标，交叉后才完整；混着说必出错。
4. **防御的方向与限度说清了没有？** 方向是保护，强度有两重性：过度加重损伤，不足清不掉因子。

## 执行步骤

```text
1. 抄所见，不抄病名：写「黏膜表面覆着膜状物」，不写「纤维素性炎」
2. 定部位与层次：器官 → 组织层次（上皮/黏膜下/实质/间质/浆膜）
3. 走三要素：变质（实质 + 间质）→ 渗出（血管反应 + 液体 + 细胞）→ 增生（细胞类别 + 排列）
4. 判配比：谁最突出，依据是哪一处形态；另两样为何相对轻微
5. 归型：按局部变化归型；病程另起一句，注明是另一套坐标
6. 分离所见与分析：直接所见一段，联系分析一段，各自标明
7. 报边界：不判病因、不判病情与预后、不给数值
```

## 硬约束

- **不给数值、单位、正常值、参考范围、百分比。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不判正常与异常。** 配比能说明「长成什么样」，不能说明「这个人现在怎样」。
- **引文逐字。** 标「教材·第N章·N.M.K」，核不到就不引；不许把教材里的学科对话当成古籍引文。
- **部位必标。** 同一种形态在不同层次意义不同：表面上皮的坏死与实质器官的坏死不是一回事。

## 交付物

1. 一段形态描述（部位 → 三要素 → 配比 → 归型），所见与分析分离
2. 一句配比判定：谁最突出，依据是什么
3. 一句坐标声明：配比归型一句、病程一句，明确两套坐标
4. 一处边界：本章不给值，数值须另立数据层

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 三要素当三阶段 | 把并存的过程写成先后顺序 | 改成配比：同一时间窗内三样并存 |
| 细胞类别直推类型 | 「有中性粒细胞所以是化脓性」 | 回到渗出物性状与配比，细胞只作侧重提示 |
| 两套坐标混用 | 「变质性炎属于慢性炎症」 | 分开写，注明坐标不同 |
| 只写「红、肿、热、痛」 | 五字口诀替代形态描述 | 每一表现回到血管反应、渗出、组织变化 |
| 把防御写成绝对有利 | 忽略渗出物压迫、纤维增生、自身损伤 | 补上「防御作用有其限度」 |
| 被追问就报数值 | 越出本书口径，且数值无来源 | 统一回「本书不给值，另立数据层」 |

## 边界

本 Skill 只处理「形态所见 → 配比 → 归型」的结构化表达，不涉及数值、判定与临床决策。任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
