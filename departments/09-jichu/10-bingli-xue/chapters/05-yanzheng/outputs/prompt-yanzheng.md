# Prompt：把一张「有炎症」的切片写成可复核的描述

## 用途

病理学里最容易糊过去的答案是「这是炎症」。这个模板把这句话逼到三要素配比上去：先定部位与层次，再判变质、渗出、增生谁最突出，再按渗出物性状归型，最后说明这个结论的依据与边界。适用于课堂读片前的自检、写形态描述报告之前的梳理，以及读各论（肺炎、肝炎、肾炎）时反复套用。

## 使用前提

- 你面对的是一个**形态所见**，不是一个病名。例：「黏膜表面覆着一层膜状物」「肝细胞广泛肿胀、部分崩解」「局部有一团由上皮样细胞构成的结节」。
- 你手边有教材·第5章·N.M.K 的定位，读过对应小节。
- 你接受两条硬约束：**不产出任何数值**；**不给类型之外的判断**（不作诊断、不作良恶性或病情判定）。

## Prompt 正文（复制即用）

```text
你是病理学的读片助教。任务不是下结论，而是把所见写成一段可复核的形态描述，并说明它凭什么归到某一型。

【输入】
所见：<一段形态描述，不带病名，不带判断>
教材定位：<教材·第N章·N.M.K>

【任务，按顺序回答，不跳步】
1. 部位与层次：病变在哪个器官、哪一层（上皮 / 黏膜 / 黏膜下 / 实质 / 间质 / 浆膜）？
2. 变质：实质细胞有无水肿、脂肪变、坏死？间质有无纤维肿胀、溶解、基质液化？按类别说，不说程度分级。
3. 渗出：血管反应处在哪个环节（充血 / 血流减慢 / 白细胞附壁）？渗出物属什么性状类别（浆液性 / 纤维素性 / 化脓性 / 出血性 / 卡他性）？细胞成分以哪一类为主（中性粒细胞 / 单核与淋巴 / 嗜酸性粒细胞）？
4. 增生：有无纤维母细胞、内皮细胞、上皮细胞的增生？有无肉芽肿（上皮样细胞、多核巨细胞）？
5. 配比判定：三样里哪一样最突出？给出判断依据（哪一处形态支持「最突出」），并说明另两样为何相对轻微。
6. 归型：按局部变化归入哪一型；若还要按病程说，另起一句，明确这是另一套坐标。
7. 依据与所据分离：哪几句是直接所见，哪几句是依据形态作出的联系分析？分别标明。
8. 边界：这段描述不能回答什么（不判病因、不判良恶性、不判病情与预后、不给数值）。

【硬约束】
- 不给任何数值、单位、正常值、参考范围、百分比。凡需要数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作病情与预后判定，不作疗效断言，不作分级分期与排名。
- 引教材原文必须逐字，并标「教材·第N章·N.M.K」；核不到就不引。
- 若所见不足以定配比，直接说缺哪一项，不要猜。

【输出格式】
八个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的拆解（节选）

所见：黏膜表面覆着一层灰白色的膜状物，其下黏膜上皮有坏死脱落；黏膜下层可见血管扩张与较多中性粒细胞。教材定位：教材·第5章·5.3.2。

- **部位与层次**：黏膜层与黏膜下层，病变以表面为主。
- **变质**：表面上皮坏死脱落，属变质的表现，但范围限于表层。
- **渗出**：渗出物以纤维素为主，呈膜状附着；细胞成分以中性粒细胞为主，提示反应偏急性。
- **增生**：未见明显纤维母细胞或内皮细胞增生，也无肉芽肿。
- **配比判定**：渗出最突出——依据是「膜状附着物」这一形态本身，它只有纤维素性渗出才会形成；变质限于表层，增生缺如。
- **归型**：按局部变化归入渗出性炎（纤维素性）；按病程属急性表现，但这是另一套坐标，须另起一句说明。
- **依据与所据**：「膜状物」「上皮坏死」是直接所见；「提示反应偏急性」是由细胞类别作出的联系分析。
- **边界**：不能由此判断病原体类别，也不能判断病情走向；数值一律不给。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 用病名代替所见 | 「这是大叶性肺炎」 | 重填所见，只写可观察的形态与部位 |
| 把三要素当阶段 | 「先变质，再渗出，最后增生」 | 改成配比：同一时间窗内三样并存，谁最突出 |
| 两套坐标混用 | 「这是变质性炎，属于慢性炎症」 | 分开写：配比归型一句，病程一句，注明是两套坐标 |
| 用细胞类别直推类型 | 「有中性粒细胞所以是化脓性」 | 回到配比与渗出物性状，细胞类别只作侧重提示 |
| 偷给数值 | 「渗出液蛋白含量高于……」 | 触发硬约束，改为「本书不给值」 |
| 把分析写成所见 | 「因为血管扩张所以发红」混进描述段 | 分离：所见一段，联系分析一段，各自标明 |

## 边界

本模板训练的是「形态所见 → 配比 → 归型 → 可复核描述」的表达能力，不产生临床判断。分类框架来自教材的类别与关系，数值与判定不在本书范围内；任何涉及个体的评估须由具备资质的人员依现行规范作出。
