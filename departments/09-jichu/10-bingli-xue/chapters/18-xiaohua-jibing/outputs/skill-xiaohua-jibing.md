# Skill：消化系统疾病——三层结构、深度与修复结局

## 何时用

- 有人（包括你自己）用「有炎症」「有溃疡」把切片描述糊过去了，需要拆开
- 要在浅表性胃炎、萎缩性胃炎、消化性溃疡、病毒性肝炎、肝硬化、消化道肿瘤、肝功能衰竭之间迁移同一套层次语言
- 要判断一段描述「越了几层」：把黏膜缺损直接说成穿孔，把肝细胞坏死直接说成肝硬化
- 遇到「萎缩几度、坏死多少」这类追问，需要一套一致的拒答口径

## 核心判据（四问）

1. **在哪一层？** 黏膜层（上皮、固有层、黏膜肌层）/ 壁全层 / 肝小叶（肝细胞索、肝窦、门管区、中央静脉）。层不明，术语必错。
2. **深到哪？** 缺损穿透黏膜肌层没有？穿透是溃疡，未穿透是糜烂——这一问决定「愈合留不留瘢痕」。
3. **分布是什么？** 灶性、散在、弥漫、沿肝窦、沿门管区、沿坏死区、桥接状。分布词是形态词，不是分级词。
4. **靠什么修复？** 上皮再生 / 肉芽组织转瘢痕 / 肝细胞再生 / 纤维化。修复方式决定形态结局。

## 执行步骤

```text
1. 抄所见，不抄病名：写「缺损深达黏膜下层」，不写「胃溃疡」
2. 定层：黏膜层 / 壁全层 / 肝小叶
3. 定深度：是否穿透黏膜肌层
4. 定类别：从教材的类别表里挑（浅表、萎缩、溃疡、变性、坏死、炎性浸润、再生、纤维化、假小叶）
5. 定分布：用教材的分布词，不用「轻中重」
6. 定修复：上皮再生 / 肉芽→瘢痕 / 肝细胞再生 / 纤维化
7. 定结局：留不留瘢痕、改不改变管腔或肝结构（只说形态）
8. 定功能：屏障、分泌、消化、合成、解毒、凝血、胆汁排泄
9. 走六要素：观察 → 描述 → 记录 → 分析 → 报告 → 复核，复核留痕
```

## 硬约束

- **不给数值、单位、参考值、分级、分度、分期。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不判正常与异常。** 形态能说明「改成了什么样」，不能说明「这个人现在是否异常」。
- **引文逐字。** 标「教材·第N章·N.M.K」，核不到就不引；教材里的学科对话不是古籍引文。
- **病原与用药只写类别。** 不写菌种与毒株、不写药物名称与剂量。
- **化生不等于癌。** 肠上皮化生是适应性改变，只描述上皮表型转化，不作性质判定。
- **形态与功能可以脱节。** 肝性肾功能衰竭时肾脏可无明显结构病变；不可用形态反推功能，也不可用功能补形态。

## 交付物

1. 一条层次结论：层 + 深度
2. 一句分布描述：用教材的分布词
3. 一条修复结局：靠什么修复、留不留瘢痕
4. 一条功能后果：哪一项功能受影响
5. 一句边界：本章不给值，数值须另立数据层

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 病名代替所见 | 描述无法复核 | 重填层、深度、边缘、底部结构 |
| 糜烂当溃疡 | 修复结局判断错 | 先问是否穿透黏膜肌层 |
| 分布词当分级 | 「桥接状＝重度」 | 分布是空间描述，与程度分开写 |
| 化生当癌前 | 越出教材口径 | 只写「上皮表型转化」 |
| 纤维化起点混答 | 六型肝硬化分不开 | 先定起点：肝窦、门管区、中央区、坏死区、虫卵、沉积处 |
| 被追问就报数值 | 越出本书口径，且数值无来源 | 统一回「本书不给值，另立数据层」 |

## 边界

本 Skill 只处理「病变 → 层次与深度与修复」的结构化表达，不涉及数值、判定与临床决策。任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
