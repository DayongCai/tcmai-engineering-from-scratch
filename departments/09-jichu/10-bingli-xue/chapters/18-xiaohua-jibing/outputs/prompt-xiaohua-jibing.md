# Prompt：先定深度，再定形态，最后定修复结局

## 用途

消化系统的病变名目多、层次密，最容易滑成「有炎症」「有溃疡」这类空话。这个模板只做三件事：先把病变钉在某一层（黏膜层、壁全层、肝小叶），再判形态类别，最后说明这一层被破坏之后靠什么修复、会不会留瘢痕。适用于读片前的准备、病例讨论的结构化表达，以及把第 18 章四节（胃炎与溃疡、病毒性肝炎、肝硬化与肿瘤、肝功能衰竭）串成一条链复习。

## 使用前提

- 你手上是**一处病变或一张切片**，不是一句诊断。例：「黏膜缺损深达黏膜下层，底部见肉芽组织」「肝小叶内肝细胞索解离，见桥接状坏死带」。
- 你已读过教材对应小节，手边有「教材·第N章·N.M.K」的定位。
- 你接受一条硬约束：**本模板不产出任何数值、分级与分期**。

## Prompt 正文（复制即用）

```text
你是病理学的助教。任务不是给诊断，而是把一处消化系统的病变钉在层次上，再推它的修复结局。

【输入】
所见：<一句话描述，不带病名，不带判断>
教材定位：<教材·第N章·N.M.K>

【任务，按顺序回答，不跳步】
1. 定层：黏膜层 / 黏膜下层 / 肌层 / 浆膜 / 肝小叶（肝细胞索、肝窦、门管区、中央静脉）。层不明就停下来先问。
2. 定深度：缺损是否穿透黏膜肌层？（未穿透＝糜烂类；穿透＝溃疡类）
3. 定形态类别：从教材的类别表里挑一个（浅表性、萎缩性、溃疡、变性、坏死、炎性浸润、再生、纤维化、假小叶……），不造新词。
4. 定分布：灶性、散在、弥漫、沿肝窦、沿门管区、沿坏死区、桥接状——用教材的分布词。
5. 定修复：这一层的修复靠什么？（上皮再生 / 肉芽组织→瘢痕 / 肝细胞再生 / 纤维化）
6. 定结局：会不会留瘢痕？会不会改变管腔或肝结构？只说形态结局，不说预后。
7. 定功能后果：这一层的改变影响哪一项功能？（屏障、分泌、消化、合成、解毒、凝血、胆汁排泄）
8. 记录：按观察、描述、记录、分析、报告、复核六要素写一句可入档的描述，不给数值。

【硬约束】
- 不给任何数值、单位、参考值、分级与分期。凡需数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作正常与异常判定，不作预后判定，不作疗效断言。
- 病原只写类别，不写菌种与毒株；用药只写类别，不写名称与剂量。
- 引教材原文必须逐字，并标「教材·第N章·N.M.K」；核不到就不引。

【输出格式】
八个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的拆解（节选）

所见：胃窦黏膜一处圆形缺损，边缘整齐，底部由内向外见渗出物、坏死组织、肉芽组织与瘢痕组织。教材定位：教材·第18章·18.1.3。

- **定层**：黏膜层起，向下延伸至黏膜下层。
- **定深度**：穿透黏膜肌层——属溃疡类，不是糜烂。
- **定形态类别**：消化性溃疡（慢性溃疡性病变）。
- **定分布**：单发灶，边缘整齐，周围黏膜充血水肿。
- **定修复**：底部肉芽组织增生，外层瘢痕组织形成。
- **定结局**：愈合后局部留瘢痕；瘢痕收缩可改变周围黏膜形态，甚至引起管腔变形。
- **定功能后果**：黏膜屏障与分泌功能局部丧失；若侵蚀血管可出血，穿透管壁可穿孔。
- **记录**：胃窦黏膜见圆形缺损，深达黏膜下层，边缘整齐，底部呈渗出物、坏死组织、肉芽组织与瘢痕组织四层结构；观察与描述与复核环节齐备，材料来源与处理方式另记。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 用病名代替所见 | 「这是胃溃疡」 | 重填层、深度、边缘、底部四层 |
| 糜烂与溃疡混答 | 「黏膜破了就是溃疡」 | 先问是否穿透黏膜肌层 |
| 层次跳过 | 「肝有炎症」 | 落到肝小叶：肝细胞索、肝窦、门管区 |
| 分布词乱用 | 「点状坏死」说成程度 | 点状、碎片状、桥接状是空间分布，不是分级 |
| 把化生当癌前 | 「化生就是癌变」 | 化生是适应性改变，只描述形态转化 |
| 偷给分级 | 「中度萎缩」 | 触发硬约束，改为形态描述 |

## 边界

本模板训练的是「把病变钉在层次上并推修复结局」的表达能力，不产生临床判断。类别与关系来自教材，参数不在本书范围内；任何涉及个体的评估须由具备资质的人员依现行规范作出。
