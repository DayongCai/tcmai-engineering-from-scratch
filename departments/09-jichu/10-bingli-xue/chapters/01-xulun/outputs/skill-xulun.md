# Skill：绪论——研究对象、观察层次与描述边界

## 何时用

- 有人（包括你自己）用一句「符合某某改变」把形态描述糊过去了，需要拆开
- 要在总论各章（适应与损伤、循环障碍、炎症、肿瘤）之间迁移同一套形态描述语言
- 要判断一段叙述「越了几层」：把分子层的话直接说成大体表现
- 遇到「这到底是不是某病」这类追问，需要一套一致的边界口径

## 核心判据（四问）

1. **这是哪一层？** 大体 / 组织学 / 细胞与分子。答不出层次，描述就无法被别人核对。
2. **这一句是所见还是推断？** 所见以观察为限，推断属于联系。两句写在一句里，就是描述与判断混同。
3. **跟什么比的？** 没有对照的描述不是描述，是印象。对照必须是同一器官未受累区域或同类组织的常态类别。
4. **判断交给谁？** 结论由具备资质的人员依现行规范与机构制度作出，过程留痕。答成「我判断」，就越界了。

## 执行步骤

```text
1. 定层次：选一层为主，标明另一层只在何处起支撑作用
2. 定部位与分布：弥漫还是局限，界限清楚还是不清
3. 写所见：组织类别 → 细胞形态 → 排列关系 → 间质成分 → 界限关系
4. 作比较：对照写清，差异落在哪一项
5. 作联系：与成因或机制类别对应，写明是联系不是结论
6. 列待核实：解释不了的逐条写，不填推测
7. 定去向：谁判断、依什么、怎么留痕
```

## 硬约束

- **不写数值、单位、尺寸、数量、分级与分期与分度、时程与频次。** 需要数值的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不判正常与异常，不作诊断与病情与预后判定。** 描述能说明「这一类通常怎样」，不能说明「这一个是不是」。
- **引文逐字。** 标「教材·第N章·N.M.K」，核不到就不引；教材里的学科对话不是古籍引文。
- **层次标注。** 每条结论都要能回答「这在哪一层」，跨层必须补中间环节。
- **敏感信息。** 涉人体标本与图像只写类别，不写可定位信息；脱敏与去标识化不得混称。

## 交付物

1. 一条描述链：层次 → 部位与分布 → 所见 → 比较 → 联系
2. 一句边界句：本段只作类别描述，判断归属另行
3. 一处待核实事项：缺的是哪一项观察
4. 一处反查：抽掉某项所见，描述是否还成立

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 病名当观察 | 描述退化成标签 | 重写为类别与部位的观察 |
| 描述夹推断 | 所见与所推无法分开核对 | 拆句，各归其位 |
| 跨层直推 | 用分子所见代替形态结论 | 补组织层，写明支撑关系 |
| 无对照 | 只写「色泽不同」，不知与谁比 | 指定对照区域 |
| 偷给尺寸与分级 | 越出描述层，且数值无来源 | 改为类别表述，逐个替换 |
| 省掉复核 | 描述无法追溯 | 补报告去向与复核留痕 |

## 与相邻章节的接缝

- 第 2 章（疾病概论）：把本章的「类别」讲成过程——健康与疾病、原因与条件、经过与转归，都是类别关系。
- 第 3 章（适应、损伤与修复）：把本章的「形态描述」落到具体类别上，萎缩、化生、坏死、肉芽组织都是可描述的对象。
- 后续各章（循环障碍、炎症、肿瘤）：本章的层次与六要素在每一章复用，只是观察对象换掉。

## 边界

本 Skill 只处理「观察 → 可核对描述」的结构化表达，不涉及数值、判定与临床决策。任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
