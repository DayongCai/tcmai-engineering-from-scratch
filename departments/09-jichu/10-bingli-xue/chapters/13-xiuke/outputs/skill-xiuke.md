# Skill：休克——量、流、用三问与分期定位

## 何时用

- 有人（包括你自己）用「休克了」概括一个循环功能紊乱的情形，需要拆开
- 要判断一个情形落在缺血性缺氧期、淤血性缺氧期还是难治期，且**只允许**用前阻力与后阻力的相对关系作依据
- 要把细胞层（能量—离子泵—钙—溶酶体）与器官层（肾、肺、心、肝、消化道）的叙述接上同一条链
- 遇到「到什么程度算休克」这类追问，需要一套一致的拒答口径

## 核心判据（四问）

1. **量**：走的是哪条通道——血量减少、血管床容积改变、泵血能力下降，还是神经与张力？答成病名，说明还在背结论。
2. **流**：微循环的前阻力与后阻力各往哪边走？「进得少、出得通」是缺血；「进得多、流不出」是淤血；两者都麻痹是难治。
3. **用**：细胞这一层走到哪一环？能量不足 → 离子泵下降 → 钙分布改变 → 溶酶体酶释放。走到「成环」那一步，就是难治的细胞学基础。
4. **层**：这件事发生在器官层、细胞层还是整体层？跨层必须交代中间层，否则是跳跃。

## 执行步骤

```text
1. 抄情形，不抄病名：写「创伤后皮肤湿冷、尿量减少」，不写「失血性休克」
2. 定通道：血量 / 血管床 / 泵 / 神经张力，标出主次
3. 定阻力：前阻力往哪边、后阻力往哪边，据此定分期
4. 走细胞链：能量 → 离子泵 → 钙 → 溶酶体，指出当前环与是否成环
5. 串器官：最先受影响者 → 它反过来影响谁 → 整体
6. 压成一句：哪一期、哪一层、哪条通道为主（不给时限、不给分级）
7. 反查：抽掉「后阻力」这一半，结论是否只剩形容词
```

## 硬约束

- **不给数值、单位、正常值、参考范围、分级阈值、时限。** 需要数值的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不判正常与异常。** 分期能说明「往哪边走」，不能说明「某人现在算不算异常」。
- **不把类别名当等级。** 「难治期」是机制位置的名称，不是病情轻重评分。
- **引文逐字。** 标「教材·第N章·N.M.K」，核不到就不引；教材里的学科对话不是古籍引文。
- **处置归具备资质的人员。** 补液、用药、转介一律不写。

## 交付物

1. 一条三问答案：量（通道）、流（阻力方向）、用（细胞环）
2. 一句分期定位 + 一句器官连锁
3. 一处反查：抽掉关键环节后结论剩下什么
4. 一处边界：本章不给值，阈值须另立数据层

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 用病名代替通道 | 「失血性休克」四个字什么也没解释 | 改写成「循环血量减少 → 回心血量下降」 |
| 把淤血期写成缺血期 | 前阻力方向记反，三期全乱 | 记住「缺血是进得少、淤血是流不出」 |
| 分期挂时限 | 越出教材口径，且时限无来源 | 只写阻力与细胞状态，不写时长 |
| 把类别当评分 | 认识工具变成判定标准 | 类别编码，阈值外挂 |
| 只讲微循环不讲器官 | 漏掉「救回来还会坏」那一层 | 补上器官连锁与多器官障碍 |
