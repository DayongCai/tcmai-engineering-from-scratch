# Prompt：把「他为什么这次发病」拆成两个位置

## 用途

病理学的第一个门槛不是认病，而是分清「谁在起作用」与「什么在放大它」。这个模板把一次发生拆成原因与条件两个位置，再走一遍经过与转归，最后说清哪些环节超出本书范围。适用于概念课的讨论准备、个案式教学示例的分析，以及写病因学作业前的结构梳理。

## 使用前提

- 你手上有一个**发生过程**，而不是一个诊断。例：「同样接触某类生物性因素，这一位发病而另一位不发病」「某人的疲劳在作息改变后回落」。
- 你已经读过教材对应小节，手边有教材·第N章·N.M.K 的定位。
- 你接受一条硬约束：**本模板不产出任何数值、时限与分级**。

## Prompt 正文（复制即用）

```text
你是病理学的助教。任务不是给出诊断，而是把一个发生过程拆成原因与条件两个位置，再走一遍经过与转归的类别框架。

【输入】
过程描述：<一句话，只写发生了什么，不写病名，不写判断>
教材定位：<教材·第N章·N.M.K>

【任务，按顺序回答，不跳步】
1. 原因位置：能引起这一过程的因素属于哪一类？（生物性 / 理化性 / 营养性 / 遗传 / 免疫）说明它为什么是原因而不是条件。
2. 条件位置：哪些因素影响了这一作用的成效？（环境、年龄阶段、营养状况、调节能力、既往状态）逐条说明它改变的是敏感性还是机会。
3. 反事实检验：把原因拿掉，过程还会发生吗？把某个条件拿掉，过程会变成什么样？用「会不会发生」与「会不会更重」两种问法各答一次。
4. 规律定位：这一过程体现出哪几条基本规律？（条件性 / 阶段性 / 局部与整体相联系 / 双向推移 / 损伤与抗损伤对比 / 因果转化）
5. 机制层面：涉及细胞、组织、整体调节中的哪几层？写明是「同时在场」还是「依次展开」。
6. 经过归位：按阶段类别说明走到哪一段；只写阶段类别，不写时限。
7. 转归类别：属于恢复 / 部分恢复 / 迁延不愈 / 恶化中的哪一类，或者尚不能归类，写明缺什么信息。
8. 越界自查：这段分析里有没有出现病因归因、预后推断或对个体的裁断？逐条标出并改写。

【硬约束】
- 不写数值、单位、时限、频次、分级与分期与分度。
- 不作诊断、不作病情与预后判定、不作正常与异常判定、不作疗效断言。
- 不把相关当因果：两种情形同时出现，不等于固定因果。
- 涉感染、地域、人群与生活方式的内容一律中性表述，不作归因，不作标签化。
- 引教材原文必须逐字，并标「教材·第N章·N.M.K」；核不到就不引。

【输出格式】
八个小标题各答一到三句；末尾另起一行写：
「本回答为教学推演，不写数值，不构成诊断或治疗或用药依据。」
```

## 示例：一次合格的拆解（节选）

过程描述：同样接触某类生物性因素，一位出现明显变化，另一位没有。教材定位：教材·第2章·2.2.3。

- **原因位置**：该生物性因素属于原因类别——它决定过程「能不能发生」。拿掉它，过程通常不发生。
- **条件位置**：两位的差别落在调节能力、既往状态与营养状况上。这些条件改变的是机体对原因的敏感性与原因作用的机会。
- **反事实检验**：拿掉原因，两人都不发生；拿掉某一条件（例如调节能力受限这一项），发生的一方可能表现更明显——说明条件影响的是幅度，不是有无。
- **规律定位**：体现条件性、局部与整体相联系、损伤与抗损伤的对比。
- **机制层面**：细胞层与整体调节层同时在场，不是先后两段。
- **经过归位**：处在明显表现之前的阶段，只写阶段类别，不写时限。
- **转归类别**：尚不能归类——缺的是后续观察资料，写明而不猜。
- **越界自查**：原稿有一句「他就属于易感人群」，属于对个体的裁断，已改为「该个体的调节能力与既往状态属于条件类别」。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 条件当原因 | 「他因为熬夜所以发病」 | 追问：拿掉熬夜，过程还发生吗 |
| 单一归因 | 「就是那个因素造成的」 | 补条件位置，写明幅度受什么影响 |
| 把相关当因果 | 「两者同时出现，所以有因果关系」 | 改为「存在同时出现的联系，因果待核实」 |
| 阶段当判据 | 「已经到了某一期」 | 改为阶段类别，删掉推断 |
| 转归抢答 | 「预后应该不错」 | 改为「尚不能归类，缺什么信息」 |
| 标签化表述 | 「这类人群容易……」 | 改为条件类别的中性表述 |

## 边界

本模板训练的是「把发生拆成位置」的表达能力，不产生临床判断。位置框架来自教材的类别与关系，参数与阈值不在本书范围内；任何涉及个体的评估须由具备资质的人员依现行规范作出。
