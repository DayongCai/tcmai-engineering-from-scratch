# Skill：疾病概论——健康与疾病、原因与条件、经过与转归

## 何时用

- 有人用「因为体质差」把一次发病解释完了，需要拆开
- 要做病因学的作业或讨论，需要一套稳定的分析顺序
- 要把「阶段」与「转归」的框架用在描述上，而不越界当判据
- 遇到「这是不是亚健康」「预后怎么样」这类追问，需要一致的口径

## 核心判据（四问）

1. **拿掉它，过程还发生吗？** 拿掉就不发生的是原因；只改变幅度的是条件。这一问比任何定义都可靠。
2. **它改变的是敏感性还是机会？** 条件的两条作用路径，答不出就说明还没定位。
3. **现在是哪一段、往哪走？** 阶段只写类别，转归只写类别；带时限与程度的说法一律删。
4. **这一句是关系还是判断？** 关系可以写，判断交给具备资质的人员。

## 执行步骤

```text
1. 抄过程，不抄病名：写「接触后出现明显变化」，不写「某某病」
2. 定原因：归入生物性/理化性/营养性/遗传/免疫，说明为何不是条件
3. 定条件：逐条写明改的是敏感性还是机会
4. 反事实：拿掉原因会怎样，拿掉某个条件会怎样
5. 归规律：条件性、阶段性、局部与整体、双向推移、损伤与抗损伤、因果转化
6. 定机制层：细胞/组织/整体调节，写明同时在场还是依次展开
7. 归阶段与转归：只写类别，缺信息就写「尚不能归类，缺什么」
```

## 硬约束

- **不写数值、单位、时限、频次、分级与分期与分度。** 需要数值的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不判正常与异常，不作诊断与病情与预后判定。** 阶段与转归是框架，不是判据。
- **不把相关当因果。** 同时出现只是联系，因果要写「待核实」。
- **中性表述。** 涉感染、地域、人群与生活方式的内容不作归因、不贴标签。
- **引文逐字。** 标「教材·第N章·N.M.K」，核不到就不引。

## 交付物

1. 一张两位表：原因一栏、条件一栏，各自写明作用方式
2. 一次反事实检验：拿掉谁、结果变什么
3. 一条规律定位与一层机制定位
4. 一句边界句：阶段与转归只作类别说明，判断归属另有

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 条件当原因 | 归因错位，分析停在表面 | 用「拿掉还发生吗」重判 |
| 单一原因论 | 忽视幅度差异 | 补条件位置与作用方式 |
| 阶段当判据 | 把框架用成标准 | 删时限，只留阶段类别 |
| 转归抢答 | 越界作预后判定 | 改为「尚不能归类，缺什么」 |
| 亚健康当类型 | 把区间当独立类别 | 记住它是描述方式，不是分类 |
| 标签化表述 | 把疾病与人群简单对应 | 改为条件类别的中性表述 |

## 与相邻章节的接缝

- 上一章（绪论）：给了层次与描述框架；本章把「类别」用在过程上。
- 下一章（适应、损伤与修复）：把本章的「形态变化」落到具体类别——萎缩、化生、坏死、修复。
- 后续各章（循环障碍、炎症、肿瘤）：都在这套「原因—条件—机制—经过」的骨架上展开。

## 边界

本 Skill 只处理「发生 → 位置 → 类别」的结构化表达，不涉及数值、判定与临床决策。任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
