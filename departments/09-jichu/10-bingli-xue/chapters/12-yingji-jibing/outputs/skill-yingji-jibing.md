# Skill：应激与疾病——应激原、分期、机制网络与资源再分配

## 何时用

- 有人（包括你自己）用「压力大」「他应激了」把机制糊过去了，需要拆开
- 要判断某个情形到底算不算本章意义上的应激（三条判据不全就不是）
- 要解释「为什么长期扛着一种压力的人，换一种压力反而更脆弱」
- 要解释应激时消化、生殖为什么受抑，而心血管被优先保障
- 要处理「应激导致了这个病」这类说过头的说法，需要一套条件性的表述
- 遇到心理相关内容的追问，需要一套不贴标签、不作人格判定的口径

## 核心判据（五问）

1. **三条判据齐不齐？** 非特异性、神经内分泌主导、全身性。缺一条就不是本章的应激。
2. **入口是哪一类？** 外环境、内环境、心理社会。心理社会类的判定含认知评价，不能替他人断言。
3. **资源收支如何、倾向哪一期？** 警戒（支出骤增）、抵抗（接近平衡 + 选择性适应）、衰竭（支出大于补充）。分期是状态表，不是时间表。
4. **网络里哪条在跑？** 快通路（交感—肾上腺髓质）与持久通路（下丘脑—垂体—肾上腺皮质）不是替代而是互撑；再问细胞层与体液层有没有参与。
5. **投影到哪些系统？** 回到唯一原则——资源向生命重要器官倾斜，其余让路。心血管优先、消化与生殖让路、糖脂蛋白质分解加强、凝血倾向改变、水盐处理调整。

## 执行步骤

```text
1. 验判据：三条逐条标符合 / 不符合 / 不明
2. 找入口：三类应激原，心理社会类注明含认知评价
3. 定状态：倾向哪一期 + 依据（不写时长）
4. 看收支：抵抗期必查选择性适应
5. 走网络：两通路 + 细胞层 + 体液层，各标在跑 / 未明
6. 看投影：按资源再分配推导各系统，说明是原则的投影
7. 划边界：条件而非原因；不贴标签；不给数值
```

## 硬约束

- **不给数值、单位、正常值、参考范围、百分比；不给分期的时限与分级；不给量表分值。** 追问统一回「教材不给值，需另立数据层（另立来源与校验）」。
- **不贴标签，不作心理诊断与人格判定，不作等级判定与排名。** 对可能存在心理困扰的情形，唯一正确的动作是「由具备资质的人员评估，必要时报告与转介」。
- **不说因果，只说条件。** 应激通过功能与代谢的偏离间接参与疾病过程，常与其它条件共同起作用，同一刺激不同个体结果不同。
- **不把适应当全面变强。** 抵抗期的选择性适应意味着定向变强、其余变弱。
- **引文逐字。** 标「教材·第N章·N.M.K」，核不到就不引。

## 交付物

1. 一句判据结论（三条是否齐备）
2. 一个入口判定（三类应激原之一，心理社会类附认知评价说明）
3. 一期倾向 + 资源收支（抵抗期附选择性适应检查）
4. 一张投影表（各系统变化都挂在同一条再分配原则上）
5. 一处边界（条件性表述 + 不给值 + 不贴标签）

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 把日常「压力大」当应激 | 概念被稀释，判据失效 | 三条判据逐条验 |
| 分期按天数算 | 用药或事件打断后判不出期 | 用资源收支推，不用时长推 |
| 漏掉选择性适应 | 把「还扛得住」误读成「全面变强」 | 补一句「对其它刺激的余地变小」 |
| 各系统各说一套 | 五条互不相关的改变，记不住也用不上 | 回到资源再分配这一条原则 |
| 说「应激导致了病」 | 因果说过头，且不可检验 | 改成条件性、间接、多因素 |
| 给心理状态贴名字 | 污名化，且越出资质边界 | 只写类别与关系，建议转介 |

## 与相邻章节的接缝

- 上一章（发热）：致热因素引起的整体反应里包含应激性调节，两章共用「调节网络被改写」这套语言。
- 与缺氧：应激的血流重新分布与心率改变，直接改写「灌注」这一段；代谢动员又抬高耗氧需求。
- 与休克、弥散性血管内凝血：应激的凝血倾向改变与循环调整，是这两章的前置条件之一。
- 与炎症：应激的内分泌与免疫双向调节，参与炎症的全身反应。
- 全书：本章的「资源再分配」原则可迁移到休克（灌注重分配）、发热（代谢重分配）两章。

## 边界

本 Skill 只处理「表现方向 → 判据、分期与投影」的结构化表达，不涉及数值、判定与临床或心理决策。任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出；涉及心理状态的内容不作诊断、不作标签化表述。
