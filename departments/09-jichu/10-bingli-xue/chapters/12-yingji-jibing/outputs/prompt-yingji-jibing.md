# Prompt：把「压力大」拆成一次资源再分配

## 用途

应激这一章最容易被糊过去的一句话是「他压力大」。这个模板把它逼成一张调度表：先验判据（是不是应激）、再找入口（哪一类应激原）、再定状态（哪一期、资源收支如何）、再看网络（哪条通路在跑）、最后看投影（资源往哪边调、哪个系统在让路）。适用于课堂讨论前的自检、案例的机制梳理，以及读 10 章（缺氧）、11 章（发热）时对照——三章都属于全身性反应，判断方式可以互相迁移。

## 使用前提

- 你手上是**一组表现的方向**，不是一个标签，也不是一个量表分数。例：「近期睡眠变浅、食欲下降、心率偏快、注意力难以集中」。
- 你已经读过教材·第12章对应小节，能指到 12.1.1 至 12.4.3 的定位。
- 你接受两条硬约束：**不产出任何数值**，**不产出任何个体判定，也不贴任何标签**。

## Prompt 正文（复制即用）

```text
你是病理学的助教。任务不是判断「是不是压力大」，而是把一句「压力大」拆成一次统一的资源再分配。

【输入】
表现方向：<逐项写有 / 无、升高 / 降低 / 相对稳定，不写数值>
教材定位：<教材·第N章·N.M.K>

【任务，按顺序回答，不跳步】
1. 验判据：本章的应激有三个成分——非特异性、神经内分泌主导、全身性。逐条写「符合 / 不符合 / 不明」，三条不全就不要硬套应激。
2. 找入口：应激原属哪一类（外环境 / 内环境 / 心理社会）。心理社会类要说明判定含认知评价，因此不能替他人断言「这就是他的应激原」。
3. 定状态：倾向哪一期（警戒 / 抵抗 / 衰竭）。只写倾向与依据，不写「持续多久」，也不给任何时限。
4. 看收支：这一期的资源侧是支出骤增、平衡、还是支出大于补充？抵抗期要专门检查有没有选择性适应（定向变强、其余变弱）。
5. 走网络：快通路（交感—肾上腺髓质）与持久通路（下丘脑—垂体—肾上腺皮质）各写"在跑 / 未明"；再写细胞层（保护性蛋白质、细胞耐受）与体液层（急性期反应物质）有没有参与。
6. 看投影：按资源再分配原则推导各系统——灌注优先（心血管）、让路（消化、生殖）、动员要能量（糖脂蛋白质分解）、止血准备（血液）、水盐（泌尿）、双向两面（中枢与免疫）。每一条都要说明它是原则的投影，不是独立事实。
7. 划边界：应激是条件不是原因，作用间接、有条件和个体差异；不贴标签、不作心理诊断与人格判定；被追问数值、分期时限或量表分值时，统一回「教材不给值，需另立数据层」。

【硬约束】
- 不给任何数值、单位、正常值、参考范围、百分比；不给分期的时限与分级；不给量表分值。
- 不作诊断，不作正常与异常判定，不作心理诊断与人格判定，不作等级判定与排名。
- 引教材原文必须逐字，并标「教材·第N章·N.M.K」；核不到就不引。
- 三条判据不全时，直接写「不足以称为应激」，不要凑。

【输出格式】
七个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的拆解（节选）

表现方向：近期睡眠变浅、食欲下降、心率偏快、注意力难以集中，仍在正常工作。教材定位：教材·第12章·12.1.2。

- **验判据**：非特异性符合（不是某一器官的特异损伤）；神经内分泌主导符合（心率与睡眠同时被牵动）；全身性符合（消化与中枢同时变化）。三条齐。
- **找入口**：心理社会类为主，入口在认知评价；因此只能说「从他的描述看」，不能替他断言。
- **定状态**：倾向抵抗期——仍在维持日常功能，动员已趋稳定。不给时长。
- **看收支**：收支接近平衡；但要检查选择性适应：对当前这件事的耐受可能提高，对其它刺激的余地可能变小。这一点必须写出来，否则会把「还扛得住」误读成「全面变强」。
- **走网络**：快通路在跑（心率、警觉），持久通路未明（需更多线索）；细胞层与体液层未明。
- **看投影**：消化让路（食欲下降）、中枢调整（睡眠与注意）、心血管优先（心率偏快）。三条是同一条原则的投影，不是三个独立毛病。
- **划边界**：这是机制层的描述，不是判定。追问量表分值或分期时限，统一回「教材不给值」。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 用标签代替机制 | 「他有焦虑障碍」 | 退回判据与网络，标签不属于本层 |
| 把分期当时长 | 「已经两周了，属于抵抗期」 | 用资源收支推，不用时长推 |
| 漏掉选择性适应 | 只说「他适应了」 | 补一句「对其它刺激的余地变小了」 |
| 各系统各说一套 | 罗列五条互不相关的改变 | 回到资源再分配这一条原则 |
| 把条件说成原因 | 「他的病就是压力造成的」 | 改成条件性、间接、多因素 |
| 偷给数值 | 「皮质醇超过多少就是应激」 | 触发硬约束，改为「教材不给值」 |

## 边界

本模板训练的是「把应激写成一次资源再分配」的表达能力，不产生临床判断，也不产生心理判断。分期与机制来自教材的类别与关系，时限、量值与量表分不在本书范围内；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
