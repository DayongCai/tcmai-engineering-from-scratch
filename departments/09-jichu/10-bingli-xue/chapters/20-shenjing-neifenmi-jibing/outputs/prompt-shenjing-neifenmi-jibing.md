# Prompt：给一段神经或内分泌的形态描述装上三个刻度

## 用途

病理描述最常见的失败不是写错，而是**写不全**：只写「有渗出」，不写在哪、往哪扩、是弥漫还是局灶。这个模板给描述装上三个刻度——部位、性质、分布——并要求逐项对齐。适用于切片讨论、描述互评，以及读神经与内分泌各节时的自检。

## 使用前提

- 你手上有一段**具体的形态所见**，而不是一个病名或一个化验结论。
- 你已经读过教材对应小节，手边有教材·第N章·N.M.K 的定位。
- 你接受一条硬约束：**本模板不产出任何数值**。

## Prompt 正文（复制即用）

```text
你是病理学的助教。任务不是给出诊断，而是把一段形态描述按三个刻度补齐，并检查是否可被第二个人复核。

【输入】
形态所见：<一段客观描述，不带病名，不带判断>
教材定位：<教材·第N章·N.M.K>

【任务，按顺序回答，不跳步】
1. 部位刻度：病变落在哪一层？（脑膜 / 蛛网膜下腔 / 脑实质灰质 / 白质 / 脑血管壁 / 腺体 / 靶器官）
2. 性质刻度：渗出、变质、增生、硬化四类里，主是哪一类、次是哪一类？各自的细胞成分是什么？
3. 分布刻度：弥漫还是局灶？对称还是非对称？单侧还是双侧？
4. 层次：这是原发病变还是继发改变？若是继发，原发病变在哪一层？
5. 归属：按上述三项，它落在哪一个类别名下？说明依据的是哪一项形态（不是哪一个病名）。
6. 对照：同章有没有另一类别与它形态相近？两者的差别具体在哪一项刻度上？
7. 复核：把这段描述交给另一位观察者，他能据此指认同一处病变吗？若不能，缺哪一项？

【硬约束】
- 不给任何数值、单位、正常值、参考范围、百分比、分级与分期。
- 不作正常与异常的判定，不作诊断，不作预后与疗效断言。
- 引教材原文必须逐字，并标「教材·第N章·N.M.K」；核不到就不引。
- 若形态所见不足以定部位，直接说缺哪一项，不要猜。

【输出格式】
七个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的补齐（节选）

形态所见：蛛网膜下腔有大量中性粒细胞与纤维素，脑表面渗出物沿脑沟分布，脑实质浅层可见炎性细胞浸润。教材定位：教材·第20章·20.1.2。

- **部位**：脑膜与蛛网膜下腔为主，脑实质浅层为继发延伸。
- **性质**：以渗出为主（中性粒细胞、纤维素），增生性改变不明显。
- **分布**：弥漫，沿脑沟与脑池分布，脑底部与脑凸面有差异。
- **层次**：原发病变在脑膜；脑实质浅层的浸润是沿血管周围间隙延伸的继发改变。
- **归属**：化脓性脑膜脑炎类别；依据是「中性粒细胞 + 蛛网膜下腔」这一组合，而不是任何病名。
- **对照**：与病毒性脑炎的差别在部位刻度上——后者以脑实质为主、脑膜轻微；在性质刻度上以变质与增生为主。
- **复核**：可复核。任一位观察者按「蛛网膜下腔 + 中性粒细胞」都能指认同一处；若原描述只写「脑有炎症」，则不可复核。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 缺部位刻度 | 「脑组织有炎症」 | 追到层：脑膜、蛛网膜下腔、灰质、白质、血管壁 |
| 缺分布刻度 | 「有坏死灶」 | 补：弥漫还是局灶、对称还是单侧 |
| 用病名代替依据 | 「这是病毒性脑炎」 | 改为「以淋巴细胞血管套与噬神经细胞现象为据」 |
| 原发与继发混写 | 把脑疝写进脑膜炎的描述里 | 分层：先原发，后继发 |
| 偷给数值 | 「水肿程度三级」 | 触发硬约束，改为「脑回变平、脑沟变窄」 |

## 边界

本模板训练的是「把形态描述补齐到可复核」的表达能力，不产生诊断结论。三个刻度的划分来自教材的类别与关系，参数不在本书范围内；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
