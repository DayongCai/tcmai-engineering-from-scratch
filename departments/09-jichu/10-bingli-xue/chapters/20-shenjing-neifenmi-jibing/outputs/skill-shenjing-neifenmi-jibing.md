# Skill：常见神经及内分泌系统疾病——三个刻度与六要素

## 何时用

- 一段病理描述「看起来都对」，但换个人指不到同一处病变
- 要在化脓性与病毒性脑炎之间做类别对照，而不是各背一遍
- 要判断一段描述有没有把原发病变与并发症混在一层
- 遇到「这个病变重不重」这类追问，需要一套一致的拒答口径

## 核心判据（四问）

1. **部位在哪一层？** 脑膜、蛛网膜下腔、灰质、白质、血管壁、腺体、靶器官——答成「脑」或「甲状腺」，说明还没进镜。
2. **性质谁主谁次？** 渗出、变质、增生、硬化，四类里挑主次并说出细胞成分。
3. **分布怎么写？** 弥漫与局灶、对称与非对称、单侧与双侧，三对词至少答两对。
4. **原发还是继发？** 脑疝是继发，脑水肿是基础；管壁病变是因，脑组织病变是果。混层即失效。

## 执行步骤

```text
1. 抄形态，不抄病名：写「蛛网膜下腔有中性粒细胞」，不写「化脓性脑炎」
2. 定部位：一层结构，一句话
3. 定性质：四类里选主次，各配细胞成分
4. 定分布：弥漫/局灶、对称/非对称、单侧/双侧
5. 分层次：原发病变 → 继发改变，两层分写
6. 归类别：只依据形态组合，不依据病名或化验
7. 复核：交给第二个人，看他能否指认同一处；不能则补刻度
```

## 硬约束

- **不给数值、单位、参考值、百分比、分级与分期。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不判正常与异常。** 三个刻度能说明「病变在哪、什么样」，不能说明「某人现在怎么样」。
- **引文逐字。** 标「教材·第N章·N.M.K」，核不到就不引。
- **不用判定性词语。** 只写描述性词语；「符合某类别」可以，「诊断为某病」不行。

## 交付物

1. 一段三刻度齐全的描述（部位 / 性质 / 分布）
2. 一句层次判定：原发在哪一层，继发在哪一层
3. 一处对照：同章相近类别的差别落在哪一刻度
4. 一处边界：本章不给值，数值须另立数据层

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 缺部位刻度 | 描述无法复核，两个人指不到同一处 | 追到层与段 |
| 用病名代替依据 | 「这是病毒性脑炎」成了结论 | 改为形态组合的归属说明 |
| 原发继发混写 | 脑疝与脑膜炎写在同一句里 | 分层书写 |
| 类别名当知识 | 只记「化脓性」「病毒性」，丢了刻度 | 每个类别名后跟一组部位与形态 |
| 被追问就报数值 | 越出本书口径，且数值无来源 | 统一回「本书不给值，另立数据层」 |

## 边界

本 Skill 只处理「形态描述 → 三刻度」的结构化表达，不涉及数值、判定与临床决策。任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
