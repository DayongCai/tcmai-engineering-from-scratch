# Skill：常见传染病及寄生虫病——三维对照与签名形态

## 何时用

- 手上有两种以上形态相近的病变，需要说清「差在哪一列」而不是「综合不同」
- 复习时发现九种病各记各的，彼此没有接口
- 要把一段描述落到可指认的签名形态上（溃疡走向、假膜性状、结节分层）
- 遇到「这是什么菌引起的」这类追问，需要一套一致的拒答口径

## 核心判据（四列）

1. **部位列**：哪一个器官的哪一层？答成「肠道」「肺」，说明还没分层。
2. **基本病变列**：渗出、变质、增生、肉芽肿、溶解坏死，主次各是什么？
3. **特征形态列**：有没有签名？伤寒看溃疡长轴与肠管长轴的关系，痢疾看假膜与地图状边缘，阿米巴看口小底大，结核看结节分层与干酪样坏死，血吸虫看虫卵肉芽肿的三层。
4. **分布列**：弥漫还是灶性、连续还是跳跃、单侧还是双侧？

## 执行步骤

```text
1. 抄形态，不抄病名：写「溃疡长轴与肠管长轴平行」，不写「伤寒溃疡」
2. 填部位列：器官 + 层
3. 填基本病变列：五类里选主次
4. 填特征形态列：找出至少一个可指认的签名
5. 填分布列：弥漫/灶性、连续/跳跃
6. 定位差别：只指一列，说清差在哪
7. 反查：去掉签名后还能靠哪一列区分？都不能则说明描述缺项
```

## 硬约束

- **不给数值、单位、参考范围、百分比、分级与分期。**
- **不写菌种、毒株、毒力参数、药物名称与剂量。** 只写病原体类别。
- **不判正常与异常，不作诊断与预后断言。**
- **引文逐字。** 标「教材·第N章·N.M.K」，核不到就不引。
- **中性表述。** 不将疾病与地域、人群或生活方式挂接，不贴标签。

## 交付物

1. 一张四列对照表（部位 / 基本病变 / 特征形态 / 分布）
2. 一句差别定位：只指一列
3. 一句成因联系：这一列的差别与侵入部位、定居部位的关系
4. 一处边界：本章不给值、不写菌种，需要时另立数据层

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 只记病名与形容词 | 「椭圆形」「不规则」记混，指不到切片 | 改成走向、边缘、深度三项 |
| 三列混写 | 「肉芽肿性溃疡」把基本病变与形态揉在一起 | 分列填写 |
| 差别写成「综合不同」 | 无法复核，也无法教学 | 只指一列并说明差在哪 |
| 炎性强度当形态 | 「这个炎症更重」 | 改为渗出成分与坏死范围 |
| 追到菌种 | 越出病理学观察范围 | 只写病原体类别 |

## 与相邻章节的接缝

- 上一章（神经及内分泌）：同样的「三刻度」思路，只是刻度换成部位、性质、分布。
- 本章内部：结核病是参照系（三种基本病变 + 结核结节），伤寒与痢疾是标准对照（溃疡走向），其余六种各补一类破坏方式。
- 章末的方法要求（六要素）在 11 个单元里重复出现，适合当检查表用。

## 边界

本 Skill 只处理「多病变同表对照」的结构化表达，不涉及数值、菌种、药物与临床决策。任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
