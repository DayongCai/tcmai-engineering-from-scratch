# Prompt：把九种传染病压进一张三维对照表

## 用途

传染病与寄生虫病最容易学成「九份互不相干的笔记」。这个模板把它们压进同一张表：部位、基本病变、特征形态三列，每一列都要求给出可指认的证据。适用于切片鉴别、复习时的自测，以及写形态比较类作业前的结构梳理。

## 使用前提

- 你手上有**两种以上**待比较的病变，或一段需要归类的形态所见。
- 你已经读过教材对应小节，手边有教材·第N章·N.M.K 的定位。
- 你接受一条硬约束：**本模板不产出任何数值，也不写菌种与药物**。

## Prompt 正文（复制即用）

```text
你是病理学的助教。任务不是判断「这是什么病」，而是把若干病变压进同一张三维表，并说清每一格的证据。

【输入】
病变 A：<形态所见，不带病名>
病变 B：<形态所见，不带病名>
教材定位：<教材·第N章·N.M.K>

【任务，按顺序回答，不跳步】
1. 部位列：各自落在哪一个器官的哪一层？（肠壁黏膜 / 黏膜下层 / 肌层；肺泡 / 间质；肝小叶 / 门管区）
2. 基本病变列：渗出、变质、增生、肉芽肿、溶解坏死，各自的主次是什么？
3. 特征形态列：各自有没有可指认的「签名」？（溃疡的长轴方向与边缘形状、假膜的性状、结节的分层、虫卵肉芽肿的层次）
4. 分布列：弥漫还是灶性？连续还是跳跃？单侧还是双侧？
5. 差别定位：A 与 B 的差别落在哪一列？只写一列，不写「综合不同」。
6. 成因联系：这一列的差别与病原的侵入部位、定居部位有什么关系？
7. 反查：如果把第 3 列的签名去掉，还能靠哪一列区分？如果都不能，说明这份描述缺了什么？

【硬约束】
- 不给任何数值、单位、参考范围、百分比、分级与分期。
- 不写具体菌种与毒株名称，不写药物名称与剂量。
- 不作正常与异常的判定，不作诊断，不作预后与疗效断言。
- 引教材原文必须逐字，并标「教材·第N章·N.M.K」；核不到就不引。

【输出格式】
一张四列表（部位 / 基本病变 / 特征形态 / 分布），每格一句话；表下写一句「差别落在哪一列」；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的对照（节选）

病变 A：肠壁淋巴组织内见巨噬细胞聚集形成的小结节，周围淋巴细胞增多；黏膜面溃疡呈椭圆形，长轴与肠管长轴平行。病变 B：黏膜表层坏死，与纤维蛋白及炎细胞混成一片附着于表面，脱落后形成形状不规则、边缘不整齐的浅溃疡。教材定位：教材·第21章·21.2.3。

| 列 | 病变 A | 病变 B |
|---|---|---|
| 部位 | 肠壁淋巴组织，向黏膜与深部扩展 | 黏膜表层，向黏膜下层扩展 |
| 基本病变 | 肉芽肿性炎（伤寒小结） | 纤维素性炎与坏死性炎（假膜） |
| 特征形态 | 椭圆形溃疡，长轴与肠管长轴平行，边缘隆起 | 假膜可成片剥离，溃疡浅、边缘地图状 |
| 分布 | 沿肠管长轴分布，回肠末段最密 | 连续性分布，乙状结肠与直肠为主 |

**差别落在哪一列**：特征形态列——溃疡的走向与边缘形状。两者都是肠道的感染性病变，部位列也有差别（淋巴组织对黏膜表层），但最省力的判据是溃疡的走向。

**成因联系**：肠壁淋巴组织沿肠管长轴分布，故 A 的溃疡顺着长轴；B 的病变起于黏膜表层，坏死脱落不受淋巴组织走向约束，故形状不规则。

**反查**：去掉溃疡签名后，仍可靠「有没有假膜」「有没有伤寒小结」区分；若两者都缺，说明描述没有落到基本病变这一列。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 只写病名 | 「A 是伤寒，B 是痢疾」 | 每格填形态，不填病名 |
| 三列混成一列 | 「A 是肉芽肿性溃疡」 | 拆开：基本病变一列，特征形态一列 |
| 差别写成「综合不同」 | 「两者综合起来不一样」 | 只指一列，并说清这一列差在哪 |
| 把炎性强度当形态 | 「A 的炎症更重」 | 改为渗出成分与坏死范围 |
| 偷给数值或菌种 | 「培养出某某菌」 | 触发硬约束，回到形态类别 |

## 边界

本模板训练的是「多病变同表对照」的结构化表达，不产生诊断结论。三维划分来自教材的类别与关系，病原学与药物内容不在本书范围内；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
