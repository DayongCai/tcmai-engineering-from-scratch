# Prompt：用两把尺读一个水电解质紊乱

## 用途

病理生理学里最容易糊过去的答案是「他脱水了」。这个模板把这句话逼到两把尺上：先定容量往哪边走，再定渗透压往哪边走，再判水往哪边移、细胞是瘪还是胀，最后落到功能影响的侧别与类别的转化条件。适用于课堂讨论前的自检、写案例分析之前的梳理，以及读水肿、酸碱平衡紊乱两章时反复套用。

## 使用前提

- 你面对的是一个**状态描述**，不是一个诊断名。例：「呕吐后尿少、口渴明显」「大量饮清水后出现头痛与乏力」。
- 你手边有教材·第7章·N.M.K 的定位，读过对应小节。
- 你接受两条硬约束：**不产出任何数值**；**不给液体治疗方案**（不构成用药与处理依据）。

## Prompt 正文（复制即用）

```text
你是病理生理学的助教。任务不是判断病情，而是把一个状态拆成容量与渗透压两把尺上的位置。

【输入】
状态：<一句话描述，不带诊断名，不带判断>
教材定位：<教材·第N章·N.M.K>

【任务，按顺序回答，不跳步】
1. 丢了什么：水与钠的相对比例往哪边偏（水偏多 / 钠偏多 / 相近）？依据是描述里的哪一处？
2. 容量尺：细胞外液的总量是减少、增加还是改变不明显？它影响的是哪一类功能（循环 / 器官灌注）？
3. 渗透压尺：细胞外渗透压的变化方向是升高、降低还是改变不明显？
4. 水的移动：水从哪一侧移向哪一侧？哪一侧的细胞因此皱缩或肿胀？
5. 归类：按两把尺的组合落在哪一类（高渗性 / 低渗性 / 等渗性脱水；水潴留型 / 钠潴留型水过多；水中毒）？
6. 功能侧别：这个类别主要影响哪一侧的功能（神经表现 / 循环功能 / 器官功能）？只说侧别与类别，不说程度，不给数值。
7. 转化条件：如果再丢失或再补充的液体组成变了，类别会往哪一类转化？依据是什么？
8. 边界：这段分析不能回答什么（不给补液方案、不判病情与预后、不给数值）。

【硬约束】
- 不给任何数值、单位、正常值、参考范围、百分比。凡需要数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不给液体治疗方案、不给药物名称与用法、不作病情与预后判定。
- 原因不等于类别：同一原因可以落在不同类别，必须用水与钠的比例来说明。
- 引教材原文必须逐字，并标「教材·第N章·N.M.K」；核不到就不引。

【输出格式】
八个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的拆解（节选）

状态：持续呕吐后口渴明显、尿量减少。教材定位：教材·第7章·7.2.1。

- **丢了什么**：消化液里水与钠同时丢失，但就这个描述而言，口渴明显提示渗透压往升高一侧偏——只能说到这个程度。
- **容量尺**：尿量减少提示细胞外液总量减少，影响的是循环与器官灌注这一侧。
- **渗透压尺**：升高（依据是口渴这一表现，属间接线索，不是量）。
- **水的移动**：水从细胞内移向细胞外，细胞因此皱缩，以细胞内失水为主。
- **归类**：落在高渗性脱水一侧；若后续补充的是低渗液体，类别会向等渗或低渗方向移动。
- **功能侧别**：神经表现与口渴属这一类；循环功能受影响的程度要看容量一侧，不能由口渴推出。
- **转化条件**：丢失液与补充液的组成关系决定方向——这是教材写明的转化条件，不是经验推测。
- **边界**：不能给补液方案，不能判病情走向，不给任何数值。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 用病名代替状态 | 「这是低渗性脱水」 | 重填状态，只写可观察的表现 |
| 用一个症状定类别 | 「口渴所以是高渗」 | 口渴只对应渗透压一侧，容量一侧要另找线索 |
| 两把尺并成一把 | 「脱水就是容量少」 | 分别写容量与渗透压的变化方向 |
| 原因当类别 | 「呕吐所以是等渗性脱水」 | 回到水与钠的比例，原因不决定类别 |
| 直接给补液方案 | 「补等渗盐水」 | 触发硬约束：处理不属本章范围 |
| 偷给数值 | 「血钠低于……」 | 统一回「本书不给值，另立数据层」 |

## 边界

本模板训练的是「状态 → 两把尺 → 类别 → 转化条件」的结构化表达，不产生临床判断。分类框架来自教材的类别与关系，数值与处理方案不在本书范围内；任何涉及个体的评估与处理须由具备资质的人员依现行规范作出。
