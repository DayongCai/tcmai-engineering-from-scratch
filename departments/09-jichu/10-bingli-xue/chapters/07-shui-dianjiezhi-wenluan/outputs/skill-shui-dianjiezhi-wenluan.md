# Skill：水、电解质代谢紊乱——两把尺与四个环节

## 何时用

- 有人（包括你自己）用「他脱水了」把一段状态糊过去了，需要拆开
- 要判断一段叙述有没有把「容量」与「渗透压」并成一件事
- 要把水钠紊乱与钾、钙磷代谢障碍放在同一套方法里比较
- 遇到「血钠多少」「该补多少液体」这类追问，需要一套一致的拒答口径

## 核心判据（四问）

1. **水与钠的比例往哪边偏？** 水偏多 → 渗透压升高；钠偏多 → 渗透压降低；相近 → 以容量变化为主。原因不决定类别，比例才决定。
2. **容量往哪边走？** 细胞外液的总量减少还是增加。它管的是循环与器官灌注这一侧。
3. **渗透压往哪边走？** 升高还是降低。它管的是水在细胞内外的走向，因而决定细胞是皱缩还是肿胀。
4. **类别会往哪边转化？** 转化方向取决于丢失液与补充液的组成关系——这是教材写明的条件，不是经验推测。

## 执行步骤

```text
1. 抄状态，不抄诊断名：写「呕吐后口渴、尿少」，不写「高渗性脱水」
2. 判比例：水与钠谁相对丢得多（或谁相对潴留得多）
3. 走容量尺：细胞外液总量 → 循环功能侧
4. 走渗透压尺：渗透压方向 → 水的移动方向 → 细胞体积
5. 归类：两把尺的组合 → 高渗/低渗/等渗；水潴留型/钠潴留型；水中毒
6. 定功能侧别：神经表现 / 循环功能 / 器官功能，只说侧别与类别
7. 说转化：再丢或再补的组成变化会把类别推向哪一类
8. 报边界：不给数值、不给补液方案、不判病情与预后
```

## 硬约束

- **不给数值、单位、正常值、参考范围、百分比。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不给补液方案与药物用法。** 本章能说方向与类别，处理属临床范围。
- **不判正常与异常。** 两把尺能说明「落在哪一类」，不能说明「这个人现在怎样」。
- **原因不等于类别。** 同一原因（呕吐、腹泻、利尿）可以落在不同类别里，必须用比例说明。

## 交付物

1. 一段状态分析（比例 → 容量 → 渗透压 → 水的移动 → 归类）
2. 一句转化条件：补充液的组成如何改变类别
3. 一句功能侧别：这个类别主要影响哪一侧
4. 一处边界：本章不给值、不给方案

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 两把尺并成一把 | 「脱水就是容量少」 | 分别写容量与渗透压，二者可不同步 |
| 一个症状定类别 | 「口渴所以高渗」 | 口渴只对应渗透压一侧 |
| 原因当类别 | 「呕吐所以等渗」 | 回到水与钠的比例 |
| 电极质只看数值方向 | 只记「高钾低钾」不记环节 | 补上摄入、排出、细胞内外转移三个环节 |
| 把类别当标签 | 忘了可相互转化 | 写出转化的组成条件 |
| 被追问就给方案 | 越出本书口径 | 统一回「不给值、不给方案」 |

## 边界

本 Skill 只处理「状态 → 两把尺 → 类别 → 转化」的结构化表达，不涉及数值、处理方案与临床决策。任何涉及个体的评估与处理须由具备资质的人员依现行规范与机构制度作出。
