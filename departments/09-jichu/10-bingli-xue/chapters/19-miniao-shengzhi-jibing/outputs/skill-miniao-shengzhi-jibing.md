# Skill：泌尿及生殖系统疾病——部位轴与扩展方向

## 何时用

- 有人（包括你自己）用「肾脏的炎症」把一段切片描述糊过去了，需要拆开
- 要在肾小球肾炎、肾盂肾炎、肾功能衰竭三节之间迁移同一套部位语言
- 要判断一段描述「越了层」：把镜下的细胞改变直接说成临床表现
- 遇到「这个类型重不重」这类追问，需要一套一致的拒答口径

## 核心判据（四问）

1. **部位在哪一段？** 肾小球、肾小管、肾间质、肾盂黏膜、宫颈上皮、前列腺腺体——答成「肾脏」，说明还没进镜。
2. **成分谁主谁次？** 渗出、增生、变质、硬化，四类里挑出主次，并说出细胞成分。
3. **界线越没越？** 基底膜、包膜、黏膜肌层、肾小囊壁。越与不越，类型归属完全不同。
4. **方向朝哪走？** 由黏膜向间质（肾盂肾炎），还是由肾小球向外周（肾小球肾炎）。方向相反，这是最省力的鉴别。

## 执行步骤

```text
1. 抄形态，不抄病名：写「上皮侧有钉状突起」，不写「膜性肾病」
2. 定部位：一段管道 + 一层结构，一句话
3. 定成分：四类里选主次，各配一个细胞成分
4. 查边界：越过哪条界线，未越过哪条
5. 定方向：由内向外，还是由外向内
6. 定分布：弥漫 / 局灶 / 节段 / 双侧 / 单侧
7. 反查：把边界判断反过来，类型会不会变（给形态差别，不给数值）
```

## 硬约束

- **不给数值、单位、参考值、百分比、分级与分期。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不判正常与异常。** 部位轴能说明「病变在哪」，不能说明「某人现在怎么样」。
- **引文逐字。** 标「教材·第N章·N.M.K」，核不到就不引。
- **中性表述。** 生殖系统部分尤其如此：只写病变，不作归因、不作道德评判、不贴标签。

## 交付物

1. 一条部位链（段 → 层 → 成分 → 边界）
2. 一句方向判定：由黏膜向间质 / 由肾小球向外周
3. 一处反查：界线判断反转后类型如何变
4. 一处边界：本章不给值，数值须另立数据层

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 部位写成器官 | 描述停在「肾脏有病变」，无法分型 | 追到段与层 |
| 类型当病情等级 | 把「新月体型」读成「最重」 | 类型是形态聚类，教材不给分级 |
| 把趋同当同病 | 以为慢性肾衰是一种独立疾病 | 它是各种肾病的共同归宿 |
| 交界处当巧合 | 记不住鳞柱交界与移行区为何重要 | 两种组织相接处结构最复杂，病变常由此起始 |
| 被追问就报数值 | 越出本书口径，且数值无来源 | 统一回「本书不给值，另立数据层」 |

## 边界

本 Skill 只处理「形态所见 → 三问」的结构化表达，不涉及数值、判定与临床决策。任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
