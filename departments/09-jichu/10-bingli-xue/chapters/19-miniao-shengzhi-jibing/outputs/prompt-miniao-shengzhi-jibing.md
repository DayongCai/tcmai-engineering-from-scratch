# Prompt：把一张肾脏切片说清「部位—成分—方向」

## 用途

病理学里最容易被糊过去的回答是「这是肾脏的炎症」。这个模板把这句话逼到三个可核对的问题上：病变在**哪一段管道**、由**哪一类成分**构成、沿着**哪个方向**扩展。适用于形态描述训练、切片讨论前的自检，以及读泌尿与生殖系统各节时反复套用。

## 使用前提

- 你手上有一个**具体的形态所见**（镜下或大体），而不是一个病名。
- 你已经读过教材对应小节，手边有教材·第N章·N.M.K 的定位。
- 你接受一条硬约束：**本模板不产出任何数值**。

## Prompt 正文（复制即用）

```text
你是病理学的助教。任务不是给出诊断，而是把一组形态所见拆成「部位—成分—方向」三问。

【输入】
形态所见：<一段客观描述，不带病名，不带判断>
教材定位：<教材·第N章·N.M.K>

【任务，按顺序回答，不跳步】
1. 部位：病变落在哪一段管道、哪一层结构？（肾小球 / 肾小管 / 肾间质 / 肾盂黏膜 / 宫颈上皮 / 前列腺腺体……）
2. 成分：渗出、增生、变质、硬化四类里，哪一类是主，哪一类是次？各自的细胞成分是什么？
3. 边界：病变有没有越过某条界线？（基底膜、包膜、黏膜肌层、肾小囊壁）越过与未越过分别意味着什么类别？
4. 方向：从哪一端开始、往哪一端走？是「由黏膜向间质」还是「由肾小球向外周」？
5. 分布：弥漫、局灶、节段、双侧、单侧——用哪一个词最准确？
6. 对应：这组形态对应哪一类临床表现类别（不写数值、不写程度）？
7. 反查：如果把第 3 问的界线判断反过来，类型归属会变成什么？差在哪一处形态上？

【硬约束】
- 不给任何数值、单位、正常值、参考范围、百分比、分级与分期。
- 不作正常与异常的判定，不作诊断，不作预后与疗效断言。
- 引教材原文必须逐字，并标「教材·第N章·N.M.K」；核不到就不引。
- 若形态所见不足以定部位，直接说缺哪一项，不要猜。

【输出格式】
七个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的拆解（节选）

形态所见：肾小球细胞成分增多，毛细血管腔狭窄，基底膜增厚，上皮侧可见沉积物，足细胞突起融合。教材定位：教材·第19章·19.1.3。

- **部位**：肾小球，且落在毛细血管壁的上皮侧——不是系膜区，也不是内皮细胞下。
- **成分**：以增生与基底膜增厚为主，渗出成分不明显；足细胞突起融合是伴随改变。
- **边界**：病变局限在毛细血管壁内，未见新月体占据肾小囊腔，也未见间质浸润。
- **方向**：由毛细血管壁向外，属于「球内」的病变，不沿小管扩展。
- **分布**：弥漫性，不是节段性。
- **对应**：以尿液蛋白成分增多为主要表现的那一类临床资料。
- **反查**：若把「上皮侧沉积」改成「新月体占据肾小囊腔」，类型归属就落到新月体型，差别在有没有壁层上皮细胞增生与纤维蛋白沉积。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 用病名代替形态 | 「这是膜性肾病」 | 重填形态所见，只写部位、细胞、沉积位置 |
| 部位写成器官 | 「病变在肾脏」 | 追到段：肾小球、近曲小管、间质、肾盂黏膜 |
| 跳过边界 | 只说「有增生」 | 追问：越过基底膜没有？越过包膜没有？ |
| 方向写成时间 | 「先轻后重」 | 方向指空间扩展路径，不是病程 |
| 偷给数值 | 「蛋白三个加号」 | 触发硬约束，改为「以蛋白成分为主」 |

## 边界

本模板训练的是「把形态所见写成可核对的三问」的表达能力，不产生诊断结论。部位与成分的判断来自教材的类别与关系，参数不在本书范围内；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
