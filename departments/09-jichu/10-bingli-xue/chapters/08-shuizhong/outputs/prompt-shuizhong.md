# Prompt：把「水多了」拆成两本账

## 用途

病理学里最容易糊过去的一句话是「这是水肿」。这个模板把这句话逼到两本账上：先问液体是分配出了偏差，还是总量出了偏差，再问哪一条机制是主导、哪一条是跟随。适用于查体记录前的自检、病例讨论的机制梳理，以及读器官病理各章时反复套用。

## 使用前提

- 你手上是**一组可观察的表现**，不是一个诊断。例：「双下肢对称性凹陷性水肿，午后加重」「晨起眼睑浮肿，颜面无明显充血」「腹围增大伴双下肢水肿」。
- 你已经读过教材对应小节，手边有教材·第N章·N.M.K 的定位。
- 你接受一条硬约束：**本模板不产出任何数值**。

## Prompt 正文（复制即用）

```text
你是病理学的助教。任务不是给这组表现下诊断，而是把它拆到两条账上，并指出主导环节。

【输入】
表现：<一句话描述分布、性状与伴随表现，不带诊断，不带判断>
教材定位：<教材·第N章·N.M.K>

【任务，按顺序回答，不跳步】
1. 分账：这组表现主要落在「血管内外液体交换」还是「机体内外液体交换」上，还是两条同时？
2. 四条力量：如果涉及血管内外，逐条说静压、胶体渗透压、组织液一侧的渗透压、淋巴回流各自的方向与是否失衡。
3. 总闸门：如果涉及机体内外，说清是滤过下降、重吸收增强，还是两者并存；并说明钠水留滞是原发还是继发。
4. 主导与伴随：明确写「主导环节是……，伴随环节是……」。伴随环节若与主导混淆，说明会造成什么错误推论。
5. 分型：按主导环节归入心性 / 肾性 / 肝性 / 其他类别中的哪一类（可并列），并说出依据。
6. 分布解释：用主导环节解释为什么先出现在这个部位（与重力有关 / 与组织疏松有关 / 与体位无关），不要用「某某水肿的水会跑」这类说法。
7. 表现项：把分布、性状、伴随表现各写一项，只用类别语汇（有无凹陷、是否对称、部位与体位关系），不写程度。
8. 边界：这组表现不能推出什么？说清类别说明与临床判断之间的界线。

【硬约束】
- 不给任何数值、单位、参考值与参考范围，不给容量、浓度、程度的数值；也不给百分比与分度分级。
- 不作正常与异常的判定，不作诊断，不作病情与预后判定，不作疗效断言。
- 引教材原文必须逐字，并标「教材·第N章·N.M.K」；核不到就不引。
- 若表现不足以分账，直接说缺哪一项（分布 / 体位关系 / 凹陷性 / 伴随表现），不要猜。

【输出格式】
八个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/治疗/用药依据。」
```

## 示例：一次合格的拆解（节选）

表现：双下肢对称性凹陷性水肿，午后加重，伴颈静脉充盈。教材定位：教材·第8章·8.1.1。

- **分账**：两条账同时失衡，但起点在第一本账。
- **四条力量**：静压升高（静脉回流受阻）是主导；胶体渗透压未见主导证据；组织液一侧因滤过增多而静压上升，构成自我限制；淋巴回流相对不足，属伴随。
- **总闸门**：有效循环血量减少之后，钠水留滞为继发。
- **主导与伴随**：主导是毛细血管流体静压升高，伴随是钠水留滞。若把钠水留滞当主导，会误判为「肾的问题」。
- **分型**：按主导环节归入心性类别。
- **分布解释**：静压升高受重力支配，故下垂部位先显、午后加重；这与体位有关，不是「水往下走」这种说法。
- **表现项**：分布——双下肢对称；性状——凹陷性，皮肤紧张；伴随——颈静脉充盈。
- **边界**：这组表现只说明机制类别的组合，不说明心功能的分级，也不构成诊断。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 用诊断代替表现 | 「这是心衰」 | 重填分布、性状、伴随三项 |
| 两本账混成一本 | 「水多了就利尿」 | 先分账，再定主导与伴随 |
| 伴随当主导 | 「水肿都是肾的问题」 | 三类的伴随环节几乎相同，差别在主导 |
| 用程度代替类别 | 「凹陷很深，说明很重」 | 凹陷性只写有无与部位 |
| 偷给数值 | 「每天尿量多少」 | 触发硬约束，改为类别语汇 |

## 边界

本模板训练的是「把表现拆到两条账上」的表达能力，不产生临床判断。机制类别与表现类别的对应来自教材，容量、浓度、程度等参数不在本书范围内；任何涉及个体的评估须由具备资质的人员依现行规范作出。
