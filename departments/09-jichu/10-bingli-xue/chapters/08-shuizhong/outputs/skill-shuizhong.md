# Skill：水肿——两本账、四条力量与三类主导环节

## 何时用

- 有人（包括你自己）用「这是水肿」把一组表现糊过去了，需要拆开
- 要在心性 / 肾性 / 肝性之间归类，且几类同时在场、说不清主次
- 要判断一段叙述「越了几层」：把一处皮下水肿直接说成器官功能状态
- 遇到「有多重 / 每天多少」这类追问，需要一套一致的拒答口径

## 核心判据（四问）

1. **哪本账？** 血管内外的分配，还是机体内外的总量。答成「水多了」，说明两本账还没分开。
2. **哪条力量？** 静压、胶体渗透压、组织液一侧的渗透压、淋巴回流。答不出方向（推向组织间隙还是拉回血管），说明还在背名词。
3. **主导还是伴随？** 主导决定起始类别与分布特点，伴随影响发展与表现。三类的伴随环节几乎相同，差别全在主导。
4. **分布怎么解释？** 与重力相关 → 静压类；与组织疏松相关 → 胶渗或滤过类；与体位无关 → 通透性或淋巴回流类。解释不出来，说明主导环节还没定。

## 执行步骤

```text
1. 抄表现，不抄诊断：写「双下肢对称性凹陷性水肿，午后加重」，不写「心衰」
2. 分账：血管内外 / 机体内外 / 两者并存
3. 走四条力量：逐条写方向与是否失衡，指出哪一条是主导
4. 走总闸门：滤过下降 / 重吸收增强 / 钠水留滞是原发还是继发
5. 定主导与伴随，并写出「若把伴随当主导会错在哪」
6. 用主导环节解释分布，不用「水会往下走」这类说法
7. 写表现三项：分布、性状、伴随，全部用类别语汇，不写程度
8. 反查：抽掉主导环节，表现会怎样变（给可观察差别，不给数值）
```

## 硬约束

- **不给数值、单位、参考值、参考范围、百分比、分度分级。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不判正常与异常，不作诊断与预后判定。** 机制能说明「液体为什么积在这里」，不能说明某人现在是否危险。
- **引文逐字。** 标「教材·第N章·N.M.K」，核不到就不引；不许把教材里的学科对话当成古籍引文。
- **凹陷性只写有无与部位。** 它是类别（对应组织间隙液的蛋白含量），不是程度。

## 交付物

1. 一次分账：两本账各失衡在哪里
2. 一条主导环节 + 一条伴随环节，各附一句依据
3. 一条分布解释：主导环节 → 部位与体位的关系
4. 一处边界：本章不给值，容量与浓度须另立数据层

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 用诊断代替表现 | 拆解无从下手 | 重填分布、性状、伴随三项 |
| 两本账混成一本 | 只会说「利尿」，说不出为什么反复 | 先分账，再定主导 |
| 伴随当主导 | 「水肿都是肾的问题」 | 写出三类的伴随环节几乎相同 |
| 用程度代替类别 | 「凹陷深就是重」 | 凹陷性只写有无与部位 |
| 只写全局不写部位 | 分布解释无从落地 | 写明解剖位置、侧别、体位关系 |
| 被追问就报容量 | 越出本书口径，且数值无来源 | 统一回「本书不给值，另立数据层」 |

## 与相邻章节的接缝

- 第 4 章（局部血液循环障碍）：淤血是本章静压升高的常见来源，水肿常与淤血并存。
- 第 9 章（酸碱平衡紊乱）：钾的变动与酸碱状态互相牵连，两章共用「一条环节改动会带动另一条」的读法。
- 器官病理各章：脑水肿、肺水肿、腹水的表现与影响，反复复用本章的两本账与主导/伴随区分。

## 边界

本 Skill 只处理「表现 → 两本账 → 主导环节」的结构化表达，不涉及数值、判定与临床决策。任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
