# Prompt：把呼吸系统的病拆成「管道 / 海绵」两处，再顺着链条推到心

## 用途

呼吸系统的病变名目多、术语密，最容易滑成名词堆。这个模板只做两件事：先把病变归位到管道（气道）或海绵（肺泡与肺泡隔），再顺着「气道阻塞 → 肺泡壁破坏 → 血管床减少 → 右心负荷」这条链往下推一段。适用于读片前的准备、病例讨论的结构化表达，以及把第 17 章四节（慢阻肺、肺心病、肺炎与肿瘤、呼吸衰竭）串起来复习。

## 使用前提

- 你手上是**一处病变或一张切片**，不是一句诊断。例：「肺泡隔断裂，相邻肺泡腔融合」「细支气管管壁增厚，腔内充满脓性渗出物」。
- 你已读过教材对应小节，手边有「教材·第N章·N.M.K」的定位。
- 你接受一条硬约束：**本模板不产出任何数值、分级与分度**。

## Prompt 正文（复制即用）

```text
你是病理学的助教。任务不是给诊断，而是把一处呼吸系统的病变归位到结构上，并顺着链条推一段。

【输入】
所见：<一句话描述，不带病名，不带判断>
教材定位：<教材·第N章·N.M.K>

【任务，按顺序回答，不跳步】
1. 归位：病变在管道还是海绵？还是跨两者？（管道＝气管与支气管与细支气管；海绵＝肺泡与肺泡隔）
2. 层次：在黏膜、黏膜下层、管壁全层、肺泡腔、肺泡隔、间质中的哪一处？
3. 性质：属于哪一类？（炎症 / 渗出 / 增生 / 破坏 / 化生 / 肿瘤性生长）
4. 类别：从教材的类别表里挑一个（如脂纹式的列举：慢性支气管炎、肺气肿、大叶性、小叶性、间质性、中央型、周围型……），不造新词
5. 前一段与后一段：这个改变之前是什么，之后会变成什么？（如：气道阻塞 → 气体滞留 → 肺泡壁破坏）
6. 功能后果：走通气还是换气？若走换气，是通气血流比例失调、弥散障碍，还是肺内分流？
7. 是否跨器官：有没有走到血管床与右心？若有，写出四段链；若没有，明确说「本条不跨器官」
8. 记录：按观察、描述、记录、分析、报告、复核六要素写一句可入档的描述，不给数值

【硬约束】
- 不给任何数值、单位、参考值、分级与分度。凡需数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作正常与异常判定，不作预后判定，不作疗效断言。
- 病原只写类别，不写菌种与毒株；用药只写类别，不写名称与剂量。
- 引教材原文必须逐字，并标「教材·第N章·N.M.K」；核不到就不引。

【输出格式】
八个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的拆解（节选）

所见：肺泡隔多处断裂，相邻肺泡腔融合成较大的含气腔，肺泡隔变薄。教材定位：教材·第17章·17.1.2。

- **归位**：海绵（末梢肺组织），并跨管道——气道支撑随之减弱。
- **层次**：肺泡隔与肺泡腔。
- **性质**：破坏（肺泡壁结构丧失）伴扩张。
- **类别**：肺气肿；按部位与形态可归入腺泡中央型、全腺泡型、腺泡周围型或不规则型之一。
- **前后段**：前一段是气道阻塞导致呼气不畅与气体滞留；后一段是肺泡壁毛细血管床减少、肺循环阻力升高。
- **功能后果**：通气为主（呼气阻力增加、残气增多），换气亦受累（有效换气面积减少）。
- **跨器官**：跨。肺组织破坏 → 血管床减少 → 肺循环阻力升高 → 右心负荷加重。
- **记录**：末梢肺组织见肺泡腔扩张，肺泡隔断裂并变薄，相邻肺泡腔融合；观察与描述与复核环节齐备，材料来源与处理方式另记。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 用病名代替所见 | 「这是肺气肿」 | 重填所见：隔断在哪、腔有多大、壁有多薄 |
| 把管道与海绵混为一处 | 「肺部有炎症」 | 先归位，再写层次 |
| 定义少限定 | 「肺气肿就是肺扩张」 | 补「末梢」「永久性」「伴肺泡壁破坏」三个限定 |
| 链条只走一半 | 说到「肺泡壁破坏」就停 | 补血管床与右心两段 |
| 把类别当因果 | 「吸烟所以得病」 | 关系类描述，不作个体归因 |
| 偷给分级 | 「中度肺气肿」 | 触发硬约束，改为形态描述 |

## 边界

本模板训练的是「把病变归位并推一段链条」的表达能力，不产生临床判断。类别与关系来自教材，参数不在本书范围内；任何涉及个体的评估须由具备资质的人员依现行规范作出。
