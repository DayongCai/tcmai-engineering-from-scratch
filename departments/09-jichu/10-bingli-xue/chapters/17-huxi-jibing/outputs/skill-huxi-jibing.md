# Skill：呼吸系统疾病——管道、海绵与由肺及心的链条

## 何时用

- 有人（包括你自己）用「肺部有炎症」「肺气肿」把切片描述糊过去了，需要拆开
- 要在慢性支气管炎、肺气肿、慢阻肺、肺心病、三类肺炎、肺肿瘤、呼吸衰竭之间迁移同一套形态语言
- 要判断一段描述「越了几层」：把肺泡壁的破坏直接说成右心肥厚，中间两段被跳过
- 遇到「肺功能多少、狭窄几度」这类追问，需要一套一致的拒答口径

## 核心判据（四问）

1. **管道还是海绵？** 气管与支气管与细支气管是管道；肺泡与肺泡隔是海绵。跨两者的情形要单独说明（气道阻塞 → 肺泡壁破坏）。
2. **哪一层？** 黏膜、黏膜下层、管壁全层、肺泡腔、肺泡隔、间质。层不明，术语就会落错（把间质的纤维化写成肺泡腔渗出）。
3. **前一段与后一段是什么？** 序列答不出前后，说明只记住了病名（如只记住「肺气肿」，不知道前有气道阻塞、后有血管床减少）。
4. **走通气还是换气？** 通气看阻力与动力，换气看通气血流比例、弥散与分流。两条路可以并存，不能混答。

## 执行步骤

```text
1. 抄所见，不抄病名：写「肺泡隔断裂」，不写「肺气肿」
2. 归位：管道 / 海绵 / 跨两者
3. 定层次：黏膜、黏膜下层、管壁、肺泡腔、肺泡隔、间质
4. 定性质：炎症 / 渗出 / 增生 / 破坏 / 化生 / 肿瘤性生长
5. 套类别：从教材的类别表里挑，不造新词
6. 排序列：说出前一段与后一段
7. 落功能：通气（阻力、动力、顺应性）/ 换气（比例、弥散、分流）
8. 判跨器官：走没走到血管床与右心；走到就写四段链
9. 走六要素：观察 → 描述 → 记录 → 分析 → 报告 → 复核，复核留痕
```

## 硬约束

- **不给数值、单位、参考值、分级、分度、分期。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不判正常与异常。** 形态能说明「长成什么样」，不能说明「这个人现在是否异常」。
- **引文逐字。** 标「教材·第N章·N.M.K」，核不到就不引；教材里的学科对话不是古籍引文。
- **病原与用药只写类别。** 不写菌种与毒株、不写药物名称与剂量。
- **术语分列。** 大叶性写「肺泡腔弥漫纤维素性渗出」，小叶性写「细支气管为中心的化脓性炎」，间质性写「间质炎症与纤维化」；三者不能互换。

## 交付物

1. 一条归位结论：管道 / 海绵 / 跨两者 + 层次
2. 一句序列定位：前一段 / 本段 / 后一段
3. 一条功能判断：通气 / 换气 / 两者并存
4. 一条跨器官链（若成立）：肺泡壁 → 血管床 → 肺循环阻力 → 右心
5. 一句边界：本章不给值，数值须另立数据层

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 病名代替所见 | 描述无法复核 | 重填隔断、腔径、壁厚、渗出物类别 |
| 管道海绵混答 | 「肺部炎症」等于没说 | 先归位再定层次 |
| 定义少限定 | 把急性肺膨胀当肺气肿 | 补「末梢」「永久性」「伴肺泡壁破坏」 |
| 链条走一半 | 说到肺泡壁破坏就停 | 补血管床与右心两段 |
| 只答分级 | 「中度、重度」 | 改为形态描述，分级交数据层 |
| 三类肺炎术语互换 | 部位与功能对不上 | 按「肺泡腔 / 细支气管 / 间质」分列 |

## 与相邻章节的接缝

- 上一章（心血管系统疾病）：肺心病那一节是「右心负荷」的形态落点，与心力衰竭的代偿反应直接相接。
- 下一章（消化系统疾病）：同一套「管壁—腔面—器官」的写法迁移到胃肠与肝，溃疡与肝硬化是本章「破坏与修复」的延续。
- 全书：本章的「由肺及心」链条是全书少数跨器官链条之一，与泌尿系统的「肾—心」、消化系统的「肝—脑」可对照阅读。

## 边界

本 Skill 只处理「病变 → 归位与链条」的结构化表达，不涉及数值、判定与临床决策。任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
