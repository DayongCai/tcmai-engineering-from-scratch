# Skill：弥散性血管内凝血——时序四问

## 何时用

- 遇到一段「微血栓相关缺血 + 皮肤瘀斑 / 穿刺部位渗血」并存的描述，需要解释为什么不矛盾
- 要判断纤溶是原发还是继发（**本章的答案永远是继发**，但要能说出依据）
- 要把病因类别、影响因素、分期分型、功能代谢四个部分接成一条线
- 被追问「到什么程度算 DIC」「分期是第几天」时，需要一致口径

## 核心判据（四问）

1. **来源**：促凝物质从哪来——感染、组织损伤、产科、肿瘤、免疫、其它疾病？它是**启动**还是**促进**？
2. **途径**：组织因子途径（直接、可全身扩散）还是接触激活途径（与补体、激肽、纤溶交叉）？主线是哪一条？
3. **刹车**：抗凝受抑、纤溶时序紊乱、清除不足——三处里哪几处在起作用？答成「凝血太强了」等于没答。
4. **时序**：凝血激活为主 / 消耗为主 / 纤溶亢进为主？依据必须落在相反的临床表现上（血栓侧 vs 出血侧）。

## 执行步骤

```text
1. 抄情形，不抄病名：写「感染病程中出现瘀斑与穿刺部位渗血」
2. 定来源：六类里选，标出启动 or 促进
3. 定途径：组织因子 / 接触激活，指出交叉系统
4. 查刹车：抗凝 / 纤溶时序 / 清除，逐条说限制少了哪一环
5. 定时序：凝血在前、纤溶在后；给出「现在偏哪一侧」的依据
6. 加角度：按分型四角度看一遍（缓急、代偿、范围、侧重），与第 5 步分别登记
7. 找落点：出血 / 休克 / 器官功能 / 微血管病性溶血，补一条器官→整体的连锁
8. 表述检查：删掉一切判定性措辞（正常/异常、轻/中/重、时限、预后）
```

## 硬约束

- **不给数值、单位、正常值、参考范围、检验数值、分期时限、分级阈值。** 需要数值的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不把分期当分级。** 阶段名称是时间位置的标签，不是病情轻重评分。
- **不把并存当矛盾。** 血栓与出血并存是时序的必然，不是教材写错。
- **引文逐字。** 标「教材·第N章·N.M.K」，核不到就不引。
- **处置归具备资质的人员。** 抗凝、补充成分、转介一律不写。

## 交付物

1. 一条四问答案：来源（启动/促进）、途径（主线）、刹车（哪几处）、时序（偏哪一侧）
2. 一句分期位置 + 一句分型角度（两者分开写，不合并）
3. 一个表现落点 + 一条器官连锁
4. 一处边界：本章不给值，阈值须另立数据层

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 把纤溶当原发 | 整章讲反，血栓与出血无法解释 | 记住「继发性」三个字，纤溶在凝血下游 |
| 把「凝血强」当唯一解释 | 漏掉三处刹车，尤其清除与抗凝 | 逐条查刹车，答「限制少了哪一环」 |
| 分期挂时限 | 越出教材口径，时限无来源 | 只写功能状态的类别，不写天数 |
| 分型当等级 | 认识框架变成排序 | 分型是观察角度，四个角度并列 |
| 肝功能差 → 一定抗凝 | 得出相反结论 | 记住「双向失衡，净效应取决于丧失的类别与程度」 |

## 与相邻章节的接缝

- **第 13 章（休克）**：休克难治期的「微血栓形成、凝血与纤溶失衡」在本章展开；本章的休克落点又回到第 13 章。两章互为因果。
- **第 15 章（缺血-再灌注损伤）**：微血栓造成的缺血是再灌注损伤的前提条件之一，第 15 章从「恢复血流」那一端接上。
- **第 4 章（局部血液循环障碍）**：血栓形成的三要素（血流、血管壁、血液成分）在本章被拆成「高凝 + 淤滞 + 内皮损伤」，可直接复用。
