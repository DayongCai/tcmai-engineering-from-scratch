# Skill：酸碱平衡紊乱——三个环节、六个指标与四型判读

## 何时用

- 有人（包括你自己）用「这是酸中毒」把一组方向糊过去了，需要定位原发环节
- 要在四型之间归类，且两簇指标都偏、分不清是代偿还是混合
- 要判断一段叙述「越了几层」：把一项指标的数值当成结论，跳过方向与来源
- 遇到「代偿够不够 / 预计值多少」这类追问，需要一套一致的拒答口径

## 核心判据（四问）

1. **哪一簇先动？** 碳酸（呼吸因素）还是碳酸氢盐（代谢因素）。答成「酸碱度低」，说明还在读结果。
2. **方向是什么？** 每一簇都要说出升或降，不许写「异常」。
3. **代偿在哪一头？** 代偿必在原发的反方向：代谢性由呼吸补，呼吸性由肾补。找不到这一头，说明可能不是单纯型。
4. **酸碱度为什么在那里？** 用两头的变化解释它；解释不了，说明还有第三项在起作用。

## 执行步骤

```text
1. 抄方向，不抄病名：写「酸碱度朝下降方向变化」，不写「酸中毒」
2. 分簇：呼吸因素（二氧化碳分压）与代谢因素（碳酸氢盐 / 缓冲碱 / 碱剩余）
3. 定原发：看哪一簇的偏移与酸碱度同向、且位置更接近「先动」的一头
4. 定类型：原发环节 × 原发方向 → 四型之一
5. 定代偿：在另一头找反方向的变动
6. 判单纯/混合：两簇是否各自朝自己的原发方向偏离；区分同向叠加与反向抵消
7. 解释酸碱度：说明「看起来平静」不等于没有紊乱
8. 反查：只按酸碱度判读会错在哪里（给可观察差别，不做算术）
```

## 硬约束

- **不给数值、单位、参考值、参考范围、百分比、分级分期；不做代偿公式计算，不给预计值。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不判正常与异常，不作诊断与预后判定。** 方向能说明类别，不能说明某人现在是否危险。
- **引文逐字。** 标「教材·第N章·N.M.K」，核不到就不引；不许把教材里的学科对话当成古籍引文。
- **酸碱度不作来源判据。** 它只给方向，来源看两簇。

## 交付物

1. 一次分簇：呼吸因素与代谢因素各一项方向
2. 一条原发判定 + 一句依据
3. 一条代偿判定：方向是否与原发相反
4. 一处边界：本章不给值，代偿算式须另立数据层

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 用病名代替方向 | 判读无从下手 | 逐项写「某指标朝哪个方向变化」 |
| 用酸碱度定来源 | 把代谢性误判为呼吸性 | 酸碱度只给方向，来源看两簇 |
| 把代偿当第二个紊乱 | 单纯型误判为混合型 | 先查代偿方向是否与原发相反 |
| 把「接近稳定」当无事 | 漏掉反向抵消的混合型 | 先读分指标方向，再解释酸碱度 |
| 用「缓冲最快」收尾 | 误以为酸负荷已被消掉 | 缓冲只削峰，排出靠肺与肾 |
| 被追问就报数值 | 越出本书口径，且数值无来源 | 统一回「本书不给值，另立数据层」 |

## 边界

本 Skill 只处理「方向 → 类型 → 代偿」的结构化表达，不涉及数值、判定与临床决策。任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
