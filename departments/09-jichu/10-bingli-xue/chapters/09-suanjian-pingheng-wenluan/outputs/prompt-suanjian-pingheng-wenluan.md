# Prompt：把「偏酸偏碱」读成方向与原发环节

## 用途

酸碱这一章最容易被糊过去的答案是「这是酸中毒」。这个模板把这句话逼到两个维度上：原发变化在碳酸还是碳酸氢盐，原发方向是升还是降。适用于读血气资料前的自检、病例讨论的机制梳理，以及读电解质与器官病理时的判读练习。

## 使用前提

- 你手上有**一组方向**，不是一个数值。例：「酸碱度朝下降方向变化，二氧化碳分压朝升高方向变化，碳酸氢盐朝升高方向变化」。
- 你已经读过教材对应小节，手边有教材·第N章·N.M.K 的定位。
- 你接受一条硬约束：**本模板不产出任何数值，也不做算术**。

## Prompt 正文（复制即用）

```text
你是病理学的助教。任务不是给出病名，而是把一组方向读成「原发环节 + 原发方向 + 代偿方向」。

【输入】
方向组：<逐项写「某指标朝升高/下降方向变化」，不带数值，不带诊断>
教材定位：<教材·第N章·N.M.K>

【任务，按顺序回答，不跳步】
1. 分簇：把指标分成两簇——反映呼吸因素的（二氧化碳分压）与反映代谢因素的（碳酸氢盐、缓冲碱、碱剩余），并说明酸碱度只给方向不给来源。
2. 定原发：哪一簇的变化是原发的？依据是什么（例如酸碱度的偏移方向与哪一簇一致、哪一簇的偏移更接近「先动」的一头）。
3. 定类型：按「原发环节 × 原发方向」给出类型名（代谢性/呼吸性 × 酸中毒/碱中毒），并说出两个维度各是什么。
4. 定代偿：代偿应当出现在另一头，方向与原发相反。指出本组方向里是否出现了这个相反方向的变动。
5. 判单纯或混合：若两簇都朝「各自的原发方向」偏离而非一原发一代偿，说明可能是混合型；并区分「方向一致（叠加）」与「方向相反（抵消）」两种组合。
6. 解释酸碱度：用两头的变化解释酸碱度为什么在那里；特别说明「酸碱度看起来平静」不等于没有紊乱。
7. 反查：如果只按酸碱度一个指标判读，会在这组方向上错在哪里？给出可观察的差别，不做算术。
8. 边界：这组方向不能推出什么？说清机制说明与临床判断之间的界线。

【硬约束】
- 不给任何数值、单位、参考值与参考范围；不做代偿公式的计算，也不给「预计值」。
- 不作正常与异常的判定，不作诊断，不作病情与预后判定，不作疗效断言。
- 引教材原文必须逐字，并标「教材·第N章·N.M.K」；核不到就不引。
- 若方向组不足以定原发，直接说缺哪一项（哪一簇缺方向 / 是否有代偿方向的变动），不要猜。

【输出格式】
八个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/治疗/用药依据。」
```

## 示例：一次合格的读法（节选）

方向组：酸碱度朝下降方向变化，二氧化碳分压朝下降方向变化，碳酸氢盐朝下降方向变化。教材定位：教材·第9章·9.3.1。

- **分簇**：二氧化碳分压归呼吸因素；碳酸氢盐归代谢因素；酸碱度只说明偏酸。
- **定原发**：碳酸氢盐的原发减少——酸碱度与碳酸氢盐同向下降，二氧化碳分压的下降方向与原发相反，符合「代偿」的位置。
- **定类型**：代谢性酸中毒（原发环节＝碳酸氢盐，原发方向＝下降）。
- **定代偿**：呼吸侧代偿，通气增强使二氧化碳分压朝下降方向变，与本组一致。
- **判单纯或混合**：属单纯型——两簇不是各自朝自己的原发方向偏离，而是一原发一代偿。
- **解释酸碱度**：酸碱度下降的幅度被代偿部分减轻，但没有被消除。
- **反查**：只看酸碱度会误判为「呼吸性」，因为酸碱度本身不说明来源。
- **边界**：这组方向说明紊乱类别与代偿方向，不说明代偿是否充分，也不构成诊断。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 用病名代替方向 | 「这是代酸」 | 逐项写「某指标朝哪个方向变化」 |
| 用酸碱度定来源 | 「酸碱度低就是呼吸性」 | 酸碱度只给方向，来源看两簇 |
| 把代偿当第二个紊乱 | 见两簇都偏就判混合 | 先看代偿方向是否与原发相反 |
| 把「接近稳定」当无事 | 「酸碱度正常，排除紊乱」 | 先读分指标方向，再解释酸碱度 |
| 偷算代偿 | 「预计值应该是多少」 | 触发硬约束，改为方向与关系的说明 |

## 边界

本模板训练的是「把方向读成类型」的表达能力，不产生临床判断。调节环节与指标含义来自教材，数值、参照与代偿算式不在本书范围内；任何涉及个体的评估须由具备资质的人员依现行规范作出。
