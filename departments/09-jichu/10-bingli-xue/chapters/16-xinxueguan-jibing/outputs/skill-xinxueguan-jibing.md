# Skill：心血管系统疾病——位置、形态序列与后果

## 何时用

- 有人（包括你自己）用一个病名把标本描述糊过去了，需要拆开
- 要在动脉粥样硬化、冠心病、高血压病、风湿病、心内膜炎、心肌疾病、心力衰竭之间迁移同一套形态语言
- 要判断一段病理描述「越了几层」：把管壁的改变直接说成器官功能改变
- 遇到「狭窄多少、肥大到什么程度」这类追问，需要一套一致的拒答口径

## 核心判据（四问）

1. **在哪一层？** 内膜、内膜下、中膜、管壁全层；或心内膜、心肌、心外膜、瓣膜。答成「血管」说明还没定位。
2. **属于哪一类形态？** 脂纹 / 纤维斑块 / 粥样斑块 / 复合病变；变性 / 坏死 / 炎症 / 纤维化 / 肥大 / 扩张。类别答不出，说明只记住了病名。
3. **处在这一类的哪一段？** 序列的前一段是什么、后一段是什么。答不出前后，说明把序列读成了清单。
4. **后果落在哪个器官、走哪条关系？** 供血区域、血流方向、压力负荷、容量负荷。关系词缺一个，因果就是空的。

## 执行步骤

```text
1. 抄所见，不抄病名：写「内膜灰白色隆起」，不写「粥样硬化」
2. 定层次：一个解剖层次，一句话
3. 定类别：从教材的类别表里挑一个，不造新词
4. 写构成：按「中心—周边」或「表层—深层」写，不按记忆顺序写
5. 排序列：说出前一段与后一段，标出本病灶的位置
6. 看管腔或心腔：偏心 / 环状 / 扩张 / 相对缩小 / 局限性膨出
7. 落到后果：供血区域、血流方向、压力负荷、容量负荷，四选一说清
8. 做鉴别：与最易混的一类比「部位 + 附着 + 中心 + 周边」四项
9. 走六要素：观察 → 描述 → 记录 → 分析 → 报告 → 复核，复核留痕
```

## 硬约束

- **不给数值、单位、参考值、分级、分度、分期。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不判正常与异常。** 形态能说明「长成什么样」，不能说明「这个人现在是否异常」。
- **引文逐字。** 标「教材·第N章·N.M.K」，核不到就不引；教材里的学科对话不是古籍引文。
- **术语分列。** 心肌炎用「炎细胞浸润」，心肌病用「心肌细胞与间质的结构改变」；感染性心内膜炎用「松脆易落」，风湿性用「闭锁缘串珠样附着牢固」。混用即失当。

## 交付物

1. 一条三段式：位置 → 形态类别 → 器官后果
2. 一句序列定位：前一段 / 本段 / 后一段
3. 一处鉴别：与最易混类别在四项形态上的差别
4. 一句边界：本章不给值，数值须另立数据层

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 病名代替所见 | 描述无法复核 | 重填位置、颜色、隆起、切面 |
| 层次跳过 | 「血管堵了」无法对应心肌改变 | 先答层次，再答管腔 |
| 序列当清单 | 只会说「斑块」，说不出前后段 | 补前后两段与承接关系 |
| 把类别当因果 | 「血脂高所以长斑块」 | 危险因素只作归类，不作个体归因 |
| 术语混用 | 心肌炎与心肌病写成一类 | 按核心术语分列再比较 |
| 被追问就报数值 | 越出本书口径，且数值无来源 | 统一回「本书不给值，另立数据层」 |

## 与相邻章节的接缝

- 上一章（炎症与修复）：本章的「风湿小体」「肉芽组织」「瘢痕」都是那两章基本过程在心脏与血管上的具体表现。
- 下一章（呼吸系统疾病）：同一套「管壁—管腔—器官」的写法迁移到支气管与肺泡，肺淤血与肺水肿是本章心力衰竭的延续。
- 全书：本章的形态序列语言在呼吸（阻塞与实变）、消化（溃疡与肝硬化）、泌尿（肾小球病变）各章反复复用。

## 边界

本 Skill 只处理「病名 → 位置与形态与后果」的结构化表达，不涉及数值、判定与临床决策。任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
