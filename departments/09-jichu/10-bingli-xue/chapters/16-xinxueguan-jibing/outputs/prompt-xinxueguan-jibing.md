# Prompt：把一个心血管病名拆成「位置—形态—后果」

## 用途

病理学里最容易被糊过去的答案是病名。这个模板把病名逼回标本上：先定位病变在哪一层，再判定形态属于哪一类，最后把后果落到具体器官。适用于标本观察前的准备、切片描述的自检，以及把第 16 章四个话题（动脉粥样硬化与冠心病、高血压病、风湿病与心内膜炎、心力衰竭）串成一条链时的复习。

## 使用前提

- 你手上有一个**病变**或一个**器官**，而不是一句诊断结论。例：「主动脉内膜的一处灰白色隆起」「左心室前壁一片灰黄色灶」「二尖瓣闭锁缘的一串小赘生物」。
- 你已读过教材对应小节，手边有「教材·第N章·N.M.K」的定位。
- 你接受一条硬约束：**本模板不产出任何数值、分级与分度**。

## Prompt 正文（复制即用）

```text
你是病理学的助教。任务不是给诊断，而是把一个病变还原成「位置—形态—后果」三段式。

【输入】
病变或器官：<一句话描述所见，不带病名，不带判断>
教材定位：<教材·第N章·N.M.K>

【任务，按顺序回答，不跳步】
1. 层次：病变在哪一层？（内膜 / 内膜下 / 中膜 / 管壁全层 / 心内膜 / 心肌 / 心外膜 / 瓣膜）
2. 类别：形态属于哪一类？（脂纹 / 纤维斑块 / 粥样斑块 / 复合病变；或变性 / 坏死 / 炎症 / 纤维化 / 肥大 / 扩张）
3. 构成：这一类由什么构成？（纤维帽、坏死物、泡沫细胞、炎细胞、肉芽组织、胶原纤维……按「中心—周边」或「表层—深层」写）
4. 序列位置：它处在哪一段？（早期 / 中期 / 后期），前一段是什么，后一段是什么
5. 管腔或心腔：这个病变把管腔或心腔变成了什么形状？（偏心狭窄 / 环状狭窄 / 扩张 / 相对缩小 / 局限性膨出）
6. 后果：它让下游哪个器官或哪一层结构先出问题？用「供血区域」「血流方向」「压力负荷」「容量负荷」这类关系词说明
7. 鉴别：与最容易被混淆的那一类，差别落在哪一处形态？（部位 / 附着方式 / 中心成分 / 周边细胞）
8. 记录：按观察、描述、记录、分析、报告、复核六要素写一句可入档的描述，不给数值

【硬约束】
- 不给任何数值、单位、参考值、分级与分度。凡需数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作正常与异常判定，不作预后判定，不作疗效断言。
- 引教材原文必须逐字，并标「教材·第N章·N.M.K」；核不到就不引。
- 若所见不足以定层次，直接说缺哪一项，不要猜。

【输出格式】
八个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的拆解（节选）

所见：主动脉内膜一处灰白色隆起，切面见帽状结构，帽下为黄色糊状物。教材定位：教材·第16章·16.1.1。

- **层次**：内膜内，病灶主体位于内膜，帽下部分接近内膜下。
- **类别**：粥样斑块。
- **构成**：表层为纤维帽（胶原纤维与平滑肌细胞），深部为坏死物质与胆固醇结晶与钙盐。
- **序列位置**：处在纤维斑块之后、复合病变之前；前一段是纤维斑块，后一段是斑块内出血、破裂、血栓形成、钙化或动脉瘤形成。
- **管腔**：向腔内隆起，使管腔呈偏心性狭窄。
- **后果**：若发生在冠状动脉，供血区域的心肌先出现缺血性改变；若斑块破裂继发血栓，供血区域可出现梗死。
- **鉴别**：与脂纹的差别在有无纤维帽与深部坏死物；与复合病变的差别在斑块自身是否已发生出血、破裂或钙化。
- **记录**：主动脉内膜见灰白色隆起病灶，切面见表层纤维帽覆盖，帽下见黄色坏死物，管腔偏心性狭窄；观察与描述与复核环节齐备，材料来源与处理方式另记。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 用病名代替所见 | 「这是动脉粥样硬化」 | 重填所见：位置、颜色、隆起、切面 |
| 层次跳过 | 直接说「血管堵了」 | 先答在哪一层，再答管腔改变 |
| 把类别当因果 | 「因为血脂高所以长斑块」 | 改成危险因素归类，不作个体归因 |
| 序列只记一段 | 只会说「斑块」 | 补前后两段，说明承接关系 |
| 偷给分级 | 「狭窄三度」 | 触发硬约束，改为形态描述 |
| 术语混用 | 把心肌炎的「炎细胞浸润」写到心肌病上 | 按核心术语分列，再作比较 |

## 边界

本模板训练的是「把病名还原成形态」的表达能力，不产生临床判断。三段式的类别与关系来自教材，参数不在本书范围内；任何涉及个体的评估须由具备资质的人员依现行规范作出。
