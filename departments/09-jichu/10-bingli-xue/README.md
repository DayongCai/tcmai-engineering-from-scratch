病理学（Pathology）是基础医学院的核心学科，聚焦「形态 · 功能 · 病理 · 药理四条基线：中医概念落地前必须先有的正常与异常人体图景」中的一个完整知识域。

```text
病变形态→病理图像分类 / 病机演变→因果图
```

病理学 里的每一个传统概念，都被翻译成一个可计算、可验证的工程对象：

### 数值口径：教材再次 `valueLike = 0`（预判被实测否掉）

上一轮我预判「病理学教材大概不会零数值，正好演示带数值怎么写」。**实测否掉了**：21 章全量里「数字＋计量单位」**0 处**，603 个数字字符中 563 个是列表序号；「正常值」类词 193 次，其中 157 次在否定语境（教材自己声明「不写数值与单位，不作诊断与病情与预后判定」）。

所以口径按**两支**写，门里自动换档（详见 `standards/bingli/README.md`）：

- **A 支（本书走这支，教材 0 数值）**：正文零数值，只写类别与方向；需要值另立数据层。
- **B 支（预留，教材带数值时触发）**：数值只允许出现在带 `教材·第N章·N.M.K` 的引文行内，逐字原单位；禁止改写为「正常值/参考区间」、禁止换算与四舍五入、禁止用教材值对个体作判定。

门：`scripts/check_bingli_chapter.js` 与 `tests/test_bingli_chapters.js` 第 9 项都按 `底本.counts.valueLike` 分支判断，不是写在文档里的口头约定。
