# 炎症不是一种病，是三样变化的配比

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 同一时刻的三种成分
- 同一件事在链条里既是结果又是原因
- 记住名称而不记住配比，遇到没名字的情形就无从下手
- 常见搭配，不是必然对应
- 只用类别与关系描述，不作判定
- 炎症与修复是一体两面

## 边界

- **名字被抽走了，沟通会卡。** 教材不给类型名，可临床交接几乎全靠名字。学习者要自己完成「配比 → 名字」的翻译，而这一步本课不训练。
- **配比无法称重。** 「以渗出为主」是一句方向判断，说不出渗出占几成、变质占几成。想定量就得引入分级，一分级就回到凑分数。
- **全身与局部的对应被刻意放松。** 「对应但不固定」在认识上诚实，在写作上难用：它意味着任何从局部推全身的句子都要加限定，句子因此变长、变钝。
- 本章为疾病学基础的教学材料，只讲炎症三类变化的配比、划分轴与修复环节，不含炎症类型的诊断标准、程度分级与处置方案，不构成诊断或治疗建议，也不能替代现行规范、机构制度与具备资质人员的专业判断。
