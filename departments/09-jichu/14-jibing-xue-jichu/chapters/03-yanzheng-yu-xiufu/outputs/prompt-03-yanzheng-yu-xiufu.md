# 炎症不是一种病，是三样变化的配比 · 提示词

## 用途

给「炎症不是一种病，是三样变化的配比」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三样变化同时在场，比例才是判据 → 三条划分轴：病程、病变、部位 → 修复的三环节：清除、增生、重塑 → 全身账：局部配比决定全身反应的类别」这条链。

## 边界

本章为疾病学基础的教学材料，只讲炎症三类变化的配比、划分轴与修复环节，不含炎症类型的诊断标准、程度分级与处置方案，不构成诊断或治疗建议，也不能替代现行规范、机构制度与具备资质人员的专业判断；具体操作以现行规范与所在机构制度为准。
