# 第 5 章 · 水、电解质与酸碱是三笔账，混着算就全错

> **MOTTO:** 「饮入于胃，游溢精气，上输于脾，脾气散精，上归于肺，通调水道，下输膀胱，水精四布，五经并行。」——《黄帝内经·素问·经脉别论》
>
> **PROBLEM:** 本章 12 个单元、20,102 汉字，讲的是全身最需要「有数」的三件事；可全章 26 个阿拉伯数字逐个看，全是目标序号与要点序号，「阈值」与「剂量」各 0 次。真矛盾是：**一门讲失衡的课，一个可以用来比大小的量都不给；而学习者要判断的恰恰是「偏了多少」**。教材的回答是换问题——不问偏多少，先问偏在哪一维。

**双根因定位:** 环境逼迫（水电解质是唯一「说不清数值就等于没说」的领域，而课程明确不给数值，压力全落在分类上） + 知识积累（把容量、渗透、钠三笔账分开记，再把缓冲、呼吸、肾三条调节线按速度排开，失衡才不是一个笼统的「紊乱」）

**教材出处:** 教材·第5章·5.1–5.4（12 个单元，20,102 汉字）。本章的三维表与验收题为**教学设定**，用于课堂演练。

## 一、三个维度不能折叠：容量、渗透、钠水平

教材把水钠代谢紊乱按三个维度同时分类，而不是按一个维度分完再补充：

| 维度 | 三个方向 | 它问什么 |
|---|---|---|
| 容量 | 不足 / 正常 / 过多 | 血管内外的液体总量偏到哪边 |
| 渗透状态 | 低渗 / 等渗 / 高渗 | 液体相对于溶质的稀稠偏到哪边 |
| 钠水平 | 偏低 / 正常 / 偏高 | 钠的绝对量偏到哪边 |

三维不是同一件事的三种说法。容量不足可以是低渗、等渗或高渗；渗透状态改变时容量可以正常；钠水平偏高时容量也可以不足。**任意两维都能独立变化，所以两维之间的组合不能互相替代**。

这就是本章第一个、也是最大的错法：把「脱水」等同于「水少了」。脱水只是容量维的一个方向，水少了却可能同时是钠少了更多（低渗）、钠少了同样多（等渗），或钠相对不少（高渗）。三种情形在再分布方向上完全不同，写法也完全不同。

水过多一侧同样按维度拆：细胞外液容量过多与细胞内液容量过多是两个方向，钠的绝对量又分增多与不增多。四个方向两两组合，就有了四种描述——教材只要求把这四个方向写清，不要求给它们各配一个名字。

三个维度之所以必须分开，是因为**它们对应的调节机制不同**。容量靠压力与回流的环节，渗透靠水在细胞膜两侧的移动，钠水平靠摄入与排出的平衡。机制不同，能干预的入口就不同；把三维压成一维，入口也就只剩一个。

## 二、脱水三型：丢的不只是水，是水与钠的比例

脱水按丢失液体的类别与渗透状态的改变方向分成三型，三型的差别落在**水与钠谁丢得相对更多**：

- **高渗性脱水**：水的丢失相对居多，可经皮肤与呼吸道的不显性丢失。水少而钠相对不少，渗透状态偏向高渗，水由细胞内向细胞外移动，细胞因而收缩。
- **低渗性脱水**：钠的丢失相对居多，可经消化道丢失而同时补入不含钠的液体。钠少而水相对不少，渗透状态偏向低渗，水由细胞外向细胞内移动。
- **等渗性脱水**：水与钠按比例丢失，渗透状态的改变相对不明显，水的跨膜移动不占主导，细胞形态的改变相对较轻。教材对这一型有一句明确的提醒——重点在容量维度，不在渗透维度，描述时不宜把两维混在一句里。

三型的共同写法是「丢失类别 + 再分布方向」。只写丢失类别，等于只说了开头；只写再分布，等于只说了结果。两句合起来，才是一次可核对的描述。

教材没有给三型的判定条件，也没有给任何界值。这不是遗漏：一旦给出界值，三型就从「描述框架」变成「判定标准」，而判定标准属于临床规范的范围。课程能给的只有关系——**丢什么，水往哪边走**。

这里还有一个容易被跳过的时间因素。丢失是连续的，补入也是连续的，同一情形在不同时点可能落在不同型上。因此描述必须带时点，否则「高渗」与「低渗」可以在同一个人身上先后都成立，两份记录互相矛盾而各自都不错。

## 三、钾：四个端，三条调节速度

钾的紊乱按类别写，影响的入口有四个：摄入端、排出端、分布端、总量端。四个端不是并列的四条路，它们之间存在代偿关系——排出端的变化可以在一定程度上缓冲摄入端的波动；分布端的迅速调节可以在短时间内缓和总量端的偏移。

| 端 | 变化方向 | 与其余三端的关系 |
|---|---|---|
| 摄入端 | 多 / 少 | 排出端正常时可被缓冲 |
| 排出端 | 多 / 少 | 缓冲摄入端，也受容量状态影响 |
| 分布端 | 向细胞内 / 向细胞外移动 | 反应快，可短期掩盖总量变化 |
| 总量端 | 增多 / 减少 | 变化慢，决定长期方向 |

「分布端最快、总量端最慢」这一条是理解钾的关键。它意味着**一时的血钾水平不能代表体内的总量**：分布端的移动可以在总量没变的情况下让表面数字大幅偏移，也可以在总量已经改变时把表面数字维持在原处。教材对此的处理很谨慎，只写「影响因素类别」，不写任何含量、范围与参考值。

紊乱与功能变化的表述，教材限定在方向上：功能变化与紊乱的类别、发生的快慢、持续的时间相关，只写类别，不作判定。写「功能可能朝某方向变化」是对的，写「会出现某种表现」就越界了。

## 四、酸碱：先定原发环节，再看代偿方向

酸碱紊乱分四类：代谢性酸中毒、呼吸性酸中毒、代谢性碱中毒、呼吸性碱中毒。分类的切口是**原发环节落在哪一侧**——酸或碱的生成与排出出了偏差，属代谢一侧；通气与气体交换出了偏差，属呼吸一侧。

- **代谢性酸中毒**：起因分三类——酸的生成增多、酸的排出减少、碱的丢失增多。教材另给一个组合工具：按伴随的离子类别区分不同组合（阴离子间隙这个概念在此只作概念使用，不给数值）。代偿以**呼吸环节**为主，通过改变通气量实现。
- **呼吸性酸中毒**：起点在通气环节，分通气不足与气体交换障碍两类。按病程又分急性与慢性两个方向：急性以缓冲与呼吸为主，反应迅速而幅度有限；慢性以**肾环节**为主，需要一段时间才能充分展开。
- **碱中毒**：同样按原发环节分代谢与呼吸两侧，方向的推法与酸中毒对称。

四条调节线的速度顺序是全章唯一值得背的排序：

| 环节 | 速度 | 幅度 | 特点 |
|---|---|---|---|
| 缓冲系统 | 最快 | 有限 | 成对的酸与碱，分布于血液、组织间液与细胞内；不能从根本上清除多余的酸或碱 |
| 呼吸环节 | 次之 | 受气体交换条件限制 | 靠通气量调整酸的排出 |
| 肾环节 | 最慢 | 最持久 | 靠排酸与保碱，能对摄入与排出的不平衡作较充分的调整 |

三者「在时间尺度上相互衔接」，这句是本章的骨架。它解释了两件事：为什么急性期的描述总以缓冲与呼吸为主，为什么慢性期的描述必须把肾环节写进来。反过来，看到一份描述通篇只有缓冲与呼吸，就能判断它写的是一段较短的时间。

调节与结构功能的关系也被写成类别关系：肾环节的调节能力与有效循环血量、激素类别以及肾本身的功能状态有关。三个条件并列，说明「肾能调多少」不是一个固定值。这也是教材在最后一节设置判读边界的原因——调节能力的判断需要具备资质的人员结合完整信息作出。

## 五、代价与边界

这套写法的收益是把「紊乱」拆成可以逐项核对的维度；代价有三样：

- **没有刻度，就没有程度。** 三维能定位，不能定量。任何一句「失衡较重」在本课的语言里都写不出来，只能写成「偏向某一维、方向如何」。
- **组合的自由度太大。** 三维各自三个方向，组合数远超实际会遇到的情形，描述因此容易滑向「什么都能套」的空话。要收紧只能靠具体情形逐项落笔，而这一步最费时间。
- **时间尺度只有顺序，没有时点。** 「肾环节最慢」说了先后，说不出多久。所有关于「急性」「慢性」的判断因此都停在方向层面。

不适用的范围：失衡的判定与分度、补液与用药方案、钾与酸碱的处置、调节能力的评估，四类都不在本课范围。凡涉这四类，正确回答是以现行规范与机构制度为准，由具备资质的人员作出。

## 六、运行与验证

1. **三维定位。** 给四段描述，各填容量、渗透、钠水平三维的方向。通过标准：四段都不写成单一方向的「脱水」。
2. **两句话。** 给一个脱水情形，写「丢失类别」与「再分布方向」各一句。通过标准：两句都能独立成立，且不互相重复。
3. **配对代偿。** 把四类酸碱紊乱与主要代偿环节配对，并说明理由。通过标准：代谢一侧配呼吸、呼吸一侧配肾，理由落在「原发环节在哪一侧」。
4. **排时间。** 把缓冲、呼吸、肾三条线按速度排序，并各写一句「它解释了什么」。通过标准：三句分别对应急性期、过渡期、慢性期的描述差异。
