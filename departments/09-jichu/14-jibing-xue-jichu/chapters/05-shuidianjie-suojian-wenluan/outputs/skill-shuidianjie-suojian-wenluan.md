# 水、电解质与酸碱是三笔账，混着算就全错

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 任意两维都能独立变化，所以两维之间的组合不能互相替代
- 它们对应的调节机制不同
- 水与钠谁丢得相对更多
- 丢什么，水往哪边走
- 一时的血钾水平不能代表体内的总量
- 原发环节落在哪一侧

## 边界

- **没有刻度，就没有程度。** 三维能定位，不能定量。任何一句「失衡较重」在本课的语言里都写不出来，只能写成「偏向某一维、方向如何」。
- **组合的自由度太大。** 三维各自三个方向，组合数远超实际会遇到的情形，描述因此容易滑向「什么都能套」的空话。要收紧只能靠具体情形逐项落笔，而这一步最费时间。
- **时间尺度只有顺序，没有时点。** 「肾环节最慢」说了先后，说不出多久。所有关于「急性」「慢性」的判断因此都停在方向层面。
- 本章为疾病学基础的教学材料，只讲水钠、钾与酸碱紊乱的类别、维度与调节环节，不含检验取值、参考范围、分度界值与补液用药方案，不构成诊断或治疗建议，也不能替代现行规范、机构制度与具备资质人员的专业判断。
