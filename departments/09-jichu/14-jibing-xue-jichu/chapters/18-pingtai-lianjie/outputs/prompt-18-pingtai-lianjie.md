# 平台能不能用，取决于每条单元有没有「依据」和「边界」两列 · 提示词

## 用途

给「平台能不能用，取决于每条单元有没有「依据」和「边界」两列」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「单元的四段编码：让每条结论都能反查 → 两列硬约束：依据与边界 → 平台表与契约：表给人看，契约给机器判 → 病例与图像、智能辅助：两条不能越的线」这条链。

## 提示词

```
我在学《疾病学基础》第 18 章「平台能不能用，取决于每条单元有没有「依据」和「边界」两列」，本章 6 节 / 2,677 汉字，习题 7 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 表是索引，契约是规则
   - 单元化把连续论述切成了碎片
   - 边界列写多了，单元会「什么都不敢说」；写少了，等于没有边界
   - 表的唯一性要求与教材的表述弹性冲突
4. 本章自陈的边界（不得越过）：
   - **单元化把连续论述切成了碎片。** 每章 12 条，条与条之间的过渡在库里消失。检索到的是点，读到的是线，两者不能互相替代。用点代替线，是知识库最常见的误用。
   - **边界列写多了，单元会「什么都不敢说」；写少了，等于没有边界。** 这个度没有公式，只能靠同行复核与使用反馈慢慢调。
   - **表的唯一性要求与教材的表述弹性冲突。** 教材可以「一般地说」，字段必须给一个值。折中的办法是把弹性写进边界列，而不是塞进依据列——依据列一旦含糊，整条单元就废了。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为疾病学基础的教学材料，讲的是单元编码、依据与边界、平台映射与智能辅助的边界要求，不构成任何平台的技术规范或合规意见；具体操作以现行规范与所在机构制度为准。
