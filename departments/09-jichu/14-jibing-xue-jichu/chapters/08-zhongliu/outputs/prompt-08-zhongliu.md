# 良性与恶性的分界写在界面上，不写在体积上 · 提示词

## 用途

给「良性与恶性的分界写在界面上，不写在体积上」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「肿瘤是一个调控问题，不是一个肿块问题 → 实质与间质：两本必须分开记的账 → 生长方式与扩散路径是两件事 → 良恶之分：六条对照，全部是「多、常、较」」这条链。

## 提示词

```
我在学《疾病学基础》第 8 章「良性与恶性的分界写在界面上，不写在体积上」，本章 5 节 / 3,043 汉字，习题 7 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 教材·第8章·8.1–8.4（12 个单元）。本章的对照表与改写题为
   - 沟通效率掉了
   - 「倾向」容易被读成「承诺」
   - 不给安慰性结论
   - 改写结论句
4. 本章自陈的边界（不得越过）：
   - **沟通效率掉了。** 「几期」这个问句在本章的框架里没有对应答案。要把六条对照讲完，需要的时间远多于一个数字，而这个时间在门诊与病房都稀缺。这不是写法的问题，是「只写类别」这个表示本身的成本。
   - **「倾向」容易被读成「承诺」。** 六条对照都用「多」「常」，读者很容易把「多不转移」读成「不会转移」。教材的应对是每一格都保留程度词，代价是句子变长、读起来不再利落。
   - **不给安慰性结论。** 家属想要的是一个方向，本章能给的是「目前观察到的类别有哪些」。这在沟通上是实打实的劣势，必须承认，不能靠语气弥补。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为疾病学基础的教学材料，只讲肿瘤的形态、生长、扩散与影响类别，不含任何分级、分期、诊断标准与治疗方案，不构成诊疗建议，也不能替代现行规范、机构制度与具备资质人员的专业判断；具体操作以现行规范与所在机构制度为准。
