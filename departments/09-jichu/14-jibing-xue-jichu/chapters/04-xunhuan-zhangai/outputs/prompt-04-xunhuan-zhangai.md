# 循环障碍不是六种病，是血在管里走错了地方 · 提示词

## 用途

给「循环障碍不是六种病，是血在管里走错了地方」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「充血与出血：一字之差，方向相反 → 血栓形成：三个条件，缺一不成 → 栓塞与梗死：栓子走的是路，梗死看的是三件事 → 水肿：四个环节，任何一环都能开口」这条链。

## 边界

本章为疾病学基础的教学材料，只讲循环障碍六组现象的类别、方向与环节，不含诊断标准、程度分级与处置方案，不构成诊断或治疗建议，也不能替代现行规范、机构制度与具备资质人员的专业判断；具体操作以现行规范与所在机构制度为准。
