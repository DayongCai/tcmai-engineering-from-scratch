# 缺氧看断在哪一环，发热看调定点挪到哪

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 判据是「哪一环是起点」
- 能量生成方式改变
- 酸碱状态偏移
- 细胞内结构损伤
- 这个适应类别与「血液性缺氧」名称相近而环节不同，叙述时不得混称
- 调定点与体温的相对位置

## 边界

- **感受被删掉了，而学习者的入口正是感受。** 全章 0 次「寒战」，也没有「气短」「心悸」这类词。要让抽象框架落地，得由课堂自己补上这一步，而补得不好就会把感受当判据。
- **调定点不可观测。** 三期判据全靠一个读不出来的参照值。描述因此只能是「按模型推断的位置」，不能是观察所得的结论；这条界限在写作时必须每句都标。
- **分类不落到个体。** 四类缺氧能说清一条链断在哪，说不清这个人身上断了哪一处、断了多久。个体定位需要检查与判断，两者都不在本课。
- 本章为疾病学基础的教学材料，只讲缺氧四类的环节、细胞与系统变化的类别、发热的调定点关系与三期判据，不含诊断标准、程度分级、检查取值与处置方案，不构成诊断或治疗建议，也不能替代现行规范、机构制度与具备资质人员的专业判断。
