# 缺氧看断在哪一环，发热看调定点挪到哪 · 提示词

## 用途

给「缺氧看断在哪一环，发热看调定点挪到哪」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「四种缺氧：一条链上的四个断点 → 缺氧的影响：代偿与损伤用同一套反应 → 发热不是体温升高，是调定点先挪了 → 三期的判据：调定点与体温谁高」这条链。

## 边界

本章为疾病学基础的教学材料，只讲缺氧四类的环节、细胞与系统变化的类别、发热的调定点关系与三期判据，不含诊断标准、程度分级、检查取值与处置方案，不构成诊断或治疗建议，也不能替代现行规范、机构制度与具备资质人员的专业判断；具体操作以现行规范与所在机构制度为准。
