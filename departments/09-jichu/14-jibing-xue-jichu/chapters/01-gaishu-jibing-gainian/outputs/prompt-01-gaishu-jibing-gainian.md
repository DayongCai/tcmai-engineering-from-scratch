# 疾病不是一张名录，而是一组可以追问的关系 · 提示词

## 用途

给「疾病不是一张名录，而是一组可以追问的关系」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「健康与疾病：两类状态，一套观察维度 → 病因、条件、诱因：三格分开，讨论才有层次 → 三条一般规律：把过程读成链，而不是点 → 转归两类：恢复不是原样复现」这条链。

## 提示词

```
我在学《疾病学基础》第 1 章「疾病不是一张名录，而是一组可以追问的关系」，本章 5 节 / 3,192 汉字，习题 7 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 能写「调节能力下降」，不能写「处于某病前期」
   - 条件管「是否容易发生」，诱因管「是否在此刻发生」
   - 指机体对某类因素是否容易作出反应
   - 所依据的角度
   - 损伤与抗损伤
   - 局部与整体
4. 本章自陈的边界（不得越过）：
   - **判断权不在学习者手上。** 全章 8 次「诊断」全是否定式，学完能说清关系，说不出结论。缓解的办法是把两件事分开：说不出诊断是本课的设定，说不清关系才是失分点。前者不必焦虑，后者必须补。
   - **类别会钝化差异。** 「协调受破坏」这句话能装下从轻微失调到严重失衡的一切，写起来永远不错，也永远不具体。要找回差异只能靠六要素逐项落笔，而这一步最费时间。
   - **开篇的成本最高。** 近两万字没有一条可背的定义、没有一个可记的名字，前几小时的收益感接近于零。教材的对策是先给概念地图再填例子，但地图本身不产生成就感，这一点无法用写法弥补。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为疾病学基础的教学材料，只讲概念类别、关系与表述边界，不含诊断标准、检查取值与处置方案，不构成诊断或治疗建议，也不能替代现行规范、机构制度与具备资质人员的专业判断；具体操作以现行规范与所在机构制度为准。
