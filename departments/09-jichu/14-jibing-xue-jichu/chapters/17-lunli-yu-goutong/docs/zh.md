# 第 17 章 · 伦理不是附录条款，而是记录能不能摊开给当事人看的那条底线

> **MOTTO:** 「闭户塞牖，系之病者，数问其情，以从其意。」——《素问·移精变气论》
>
> **PROBLEM:** 教材第17章 12 个单元、20,173 字里，「去标识化」出现 80 次、「脱敏」36 次、「留痕」83 次，而这一章最常被当成背几条原则。真矛盾是**告知越完整，越可能把人吓退；讲得越简，同意越无效**——教材没有回避这个张力，它把分寸放在「讲清利害关系」上，而不是放在「讲多少」上。

**双根因定位:** 环境逼迫（门诊三分钟、家属在旁、敏感话题不便展开，讲全了时间不够，讲短了责任不清） + 知识积累（把告知拆成内容、方式、留痕三段，才知道「讲什么」和「怎么留证」是两件不同的事）

**教材出处:** 教材·第17章·17.1–17.4（12 个单元）。本章的告知清单与文本替换表为**教学设定**。

## 一、告知：四类内容、三种方式、一条前置

告知不是「把情况说一下」，它有可核对的内容清单。四类内容：病情与诊断的类别、拟采取措施的性质与目的、可预期的反应与风险、替代方案与不采取措施的后果。四类里最容易漏的是第四类——不采取措施会怎样。漏掉它，选择就只剩下一个选项，同意也就名存实亡。

方式有三：口头、书面、口头加书面。重要事项用口头加书面，原因不是形式主义，而是两种方式覆盖不同的失效：口头能即时澄清疑问，书面能事后复核。只口头，事后无凭；只书面，当事人常常没读懂就签了。

同意必须前置。措施之后补签的同意书，程序上不成立——它记录的不是同意，是事后追认。这一条在教材里写得毫不含糊。

最实用的有效性检验是复述：请当事人用自己的话讲一遍「接下来要做什么、可能有什么反应、还有别的选择吗」。复述得出来，才算讲清；复述不出来，签多少字都是空的。这个检验不需要额外工具，只需要多花一分钟。

告知还有一个常被忽略的对象问题：讲给谁听。当事人具备理解与决定能力时，告知对象是本人，家属在场不等于代替决定；当事人不具备时，按规范由其法定代理人或监护人参与，但仍应以当事人能理解的方式说明。学习者在这一步最容易犯的错，是把「家属说别告诉他」当成默认安排——这属于需要按规范处理的情形，不是可以自行决定的人情。

留痕要写的是过程，不是结果：讲了什么、谁讲的、什么时候、当事人问了什么、怎么答的。一张只有签名的纸，只能证明「签过」，不能证明「讲过」。留痕 83 次这个数字，说的就是这件事的权重。

## 二、隐私：去标识化与脱敏不是一回事

教材在这一点上给了一条硬要求：脱敏与去标识化不得混称。混称不是用词不严谨，它会直接导致错误判断——把可复原的数据当成不可复原的数据使用。

| 做法 | 可复原 | 是否仍属个人信息 | 适用场景 |
|---|---|---|---|
| 去标识化 | 可（有对照表即可复原） | 是，处理仍受限 | 内部分析、教学材料的受控使用 |
| 脱敏 | 不可 | 否（达到不可识别） | 对外发布、聚合统计、公开示例 |

敏感个人信息的处理原则是三条：最小必要、目的限定、可追溯。最小必要不是「少收集」，而是「只收集这一目的所需的那部分」；目的限定是「收的时候说清用途，不能挪作他用」；可追溯是「谁在什么权限下用过」。

有一条比定义更实用的判据：**稀有的情况＋时间＋地点，本身就是标识符**。一份病例摘要删掉了姓名，却保留了罕见的表现、精确的就诊年月与具体的机构，三者组合起来仍可能指向唯一的人。这就是为什么「裁掉姓名」从来不等于去标识化。

图像材料的风险更高。组织图像常带标本号、日期、机构标识，甚至拍摄设备的默认水印。「看不见脸」不等于去标识，这句话在图像场景里要重复一遍。

最小必要在材料使用上有个很实际的落点：教学需要的是一段病程的结构，不是某个人的全部资料。只取与教学目的相关的那几项，其余不取；取了的，用完按机构要求处理。多取的每一栏，都是将来可能泄露的一栏，而它对教学几乎没有增益。

## 三、不污名化：三条可操作的改写规则

中性表述不是「说话客气」，它有可执行的规则。

第一条，去形容词。「不配合的患者」改成「本次未按约定复诊的患者」。前者评价人，后者记录事。

第二条，去价值判断。「滥用」改成「未经评估使用」；「屡教不改」改成「多次偏离约定安排，原因待了解」。价值判断一旦进入记录，后面所有的照护都会被它带着走。

第三条，去群体标签。「某类人群都这样」改成「在该组观察中，某类表现的比例较高」。差异可以描述，但必须带来源与条件，不能写成「天生」「本性」。

人群差异的处理有一条底线：可以描述差异，不能据此区别对待。教材把这两件事分开写，是因为它们极易被混为一谈——「这个人群风险高」是描述，「所以对他们要另眼相看」是区别对待的起点。

最省事的自检是「家人测试」：把句子里的群体名换成自己的家人，读着不别扭，才算过关。「这个病人很难缠」换成「我父亲很难缠」，多数人立刻会改写。

中性表述在交接班上最能看出差别。「三床那个闹的」与「三床夜间多次按铃、主诉疼痛未缓解」，前者传出的是评价，后者传出的是可处理的信息。交接班传评价，下一班就会带着预设去接触人；改写的成本只有几秒钟，收益是整条照护链的判断不被污染。

## 四、不良事件报告：对事不对人

报告的价值不在记录谁做错了，而在让系统学到东西。教材把这一节放在最后，逻辑是：前面的告知、隐私、中性表述都做到，报告才有意义——否则报告会被当成告状。

渠道分三类：机构内的报告系统、向上级与监管部门的报告、涉及研究时的伦理委员会。渠道要在事前明确，事发时才找路径，等于没有路径。

时限也属于渠道的一部分。同一件事，报得早与报得晚，处理空间完全不同——早报还能补救，晚报只能解释。教材把「及时」写成要求，落地的做法是给每类事件定一个报告窗口，并把它写进交接内容。

原因分析的对象是流程与条件，不是个人品质。一份能用的报告要回答四件事：什么时间、什么环节、什么条件下发生、哪一步本来可以拦住。最后一问才是改进的入口——答不出它，报告就只是叙述了一次不幸。

非惩罚性不等于不追责。它把「主动报告」与「过失追责」分开处理：前者受保护，后者按规范处理。两者混在一起，结果是没人报告，系统失去学习能力，同类事件反复发生。

报告保护包括报告人信息的最小化与对报复性处理的禁止。这两条不写进制度，非惩罚性就只是一句口号。

## 五、代价与边界

- **完整告知与「不吓退」的张力消不掉，只能分配。** 一次讲不完就分两次：第一次讲性质与目的，第二次讲风险与替代。把最影响决策的部分放前面，是最不坏的折中。
- **留痕让沟通变得像办案。** 当事人看到你边问边记，可能更紧张、更少说。代价真实存在，缓解的办法是说明记录的目的——「记下来是为了下一次接着讲，不用你重复」。
- **去标识化的可逆性使它不能单独作为对外共享的依据。** 这一点常被忽略：内部受控使用可以，对外发布不行。把可逆数据当脱敏数据用，是本章最想拦住的一类错误。
- **边界**：本章不是法律意见，不替代伦理审查、机构制度与执业规范；具体条文以现行法规与机构规定为准。本章也不提供心理干预技术。

本章的正文与习题契约由脚本现算，可当场复核：

```bash
node code/main.js
```

脚本打印的是本章正文的规模、习题的阶段分布与接地情况；退出码为 0 表示各项契约满足，非 0 表示有不满足的项，输出里会逐条写明。


1. **告知复述。** 两人一组，A 讲 90 秒，B 用自己的话复述，A 判断漏了哪一类。通过标准：四类内容至少三类被复述到，且「不采取措施会怎样」不能漏。
2. **文本替换。** 给十二句含标签或价值判断的句子，逐句改写。通过标准：不出现群体标签与价值判断，且每句通过「家人测试」。
3. **标识符排查。** 给一份病例摘要，找出可能导致重新识别的组合。通过标准：至少指出「稀有情况＋时间＋地点」一类组合，并说明为何删名不够。
4. **报告改写。** 把「某某操作失误导致」改成可改进的表述。通过标准：落到环节与条件，不落到个人品质，并写出「哪一步本可以拦住」。
