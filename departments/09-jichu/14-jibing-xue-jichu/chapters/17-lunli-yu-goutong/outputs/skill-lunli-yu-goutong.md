# 伦理不是附录条款，而是记录能不能摊开给当事人看的那条底线

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 5 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 稀有的情况＋时间＋地点，本身就是标识符
- 完整告知与「不吓退」的张力消不掉，只能分配
- 留痕让沟通变得像办案
- 去标识化的可逆性使它不能单独作为对外共享的依据
- 标识符排查

## 边界

- **完整告知与「不吓退」的张力消不掉，只能分配。** 一次讲不完就分两次：第一次讲性质与目的，第二次讲风险与替代。把最影响决策的部分放前面，是最不坏的折中。
- **留痕让沟通变得像办案。** 当事人看到你边问边记，可能更紧张、更少说。代价真实存在，缓解的办法是说明记录的目的——「记下来是为了下一次接着讲，不用你重复」。
- **去标识化的可逆性使它不能单独作为对外共享的依据。** 这一点常被忽略：内部受控使用可以，对外发布不行。把可逆数据当脱敏数据用，是本章最想拦住的一类错误。
- 本章为疾病学基础的教学材料，讲的是告知、隐私、表述与报告的教学要求，不构成法律意见或伦理审查结论，也不能替代现行法规、机构制度、伦理委员会与具备资质人员的专业判断。
