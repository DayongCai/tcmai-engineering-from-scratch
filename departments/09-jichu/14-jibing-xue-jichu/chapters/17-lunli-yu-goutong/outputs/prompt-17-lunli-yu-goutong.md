# 伦理不是附录条款，而是记录能不能摊开给当事人看的那条底线 · 提示词

## 用途

给「伦理不是附录条款，而是记录能不能摊开给当事人看的那条底线」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「告知：四类内容、三种方式、一条前置 → 隐私：去标识化与脱敏不是一回事 → 不污名化：三条可操作的改写规则 → 不良事件报告：对事不对人」这条链。

## 提示词

```
我在学《疾病学基础》第 17 章「伦理不是附录条款，而是记录能不能摊开给当事人看的那条底线」，本章 5 节 / 2,645 汉字，习题 7 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 稀有的情况＋时间＋地点，本身就是标识符
   - 完整告知与「不吓退」的张力消不掉，只能分配
   - 留痕让沟通变得像办案
   - 去标识化的可逆性使它不能单独作为对外共享的依据
   - 标识符排查
4. 本章自陈的边界（不得越过）：
   - **完整告知与「不吓退」的张力消不掉，只能分配。** 一次讲不完就分两次：第一次讲性质与目的，第二次讲风险与替代。把最影响决策的部分放前面，是最不坏的折中。
   - **留痕让沟通变得像办案。** 当事人看到你边问边记，可能更紧张、更少说。代价真实存在，缓解的办法是说明记录的目的——「记下来是为了下一次接着讲，不用你重复」。
   - **去标识化的可逆性使它不能单独作为对外共享的依据。** 这一点常被忽略：内部受控使用可以，对外发布不行。把可逆数据当脱敏数据用，是本章最想拦住的一类错误。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为疾病学基础的教学材料，讲的是告知、隐私、表述与报告的教学要求，不构成法律意见或伦理审查结论，也不能替代现行法规、机构制度、伦理委员会与具备资质人员的专业判断；具体操作以现行规范与所在机构制度为准。
