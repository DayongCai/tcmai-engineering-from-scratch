# 预防的成败不在口号，而在「谁、在什么时点、做什么」

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 5 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 时点表把连续过程切成段

- 一级预防的收益最不可见
- 六十秒告知

## 边界

- **时点表把连续过程切成段。** 三级预防的分界在纸面上清楚，在个体身上常常模糊：「算早期还是已病」这个问题在临床上天天出现，本章的表格给不出答案，只能给判断的维度。
- **完整告知的成本很高。** 一次讲清四件事，按口语速度也要十几分钟，而门诊给不出这个时间。这是真实的资源约束，不是态度问题。折中的做法是把告知拆成两次：一次讲目的与流程，一次讲结果与下一步。
- **一级预防的收益最不可见。** 它不发生的事才是成果，因此在资源分配上永远争不过可见的三级预防。这个结构性劣势不是靠宣教能扭转的。
- 本章为疾病学基础的教学材料，只讲预防与康复的类别、时点与流程要求，不含具体筛查项目、训练参数与随访间隔，不构成诊疗或公共卫生建议，也不能替代现行规范、机构制度与具备资质人员的专业判断。
