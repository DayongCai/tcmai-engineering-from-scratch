# 预防的成败不在口号，而在「谁、在什么时点、做什么」 · 提示词

## 用途

给「预防的成败不在口号，而在「谁、在什么时点、做什么」」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三级预防不是三个名词，是三个时点 → 早期发现的三条途径与一条硬约束 → 康复：目标不是「恢复如初」 → 转介与随访：闭环的三个要素」这条链。

## 提示词

```
我在学《疾病学基础》第 16 章「预防的成败不在口号，而在「谁、在什么时点、做什么」」，本章 5 节 / 2,708 汉字，习题 7 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 教材·第16章·16.1–16.4（12 个单元）。本章的时点表与闭环检查为
   - 时点表把连续过程切成段
   - 完整告知的成本很高
   - 一级预防的收益最不可见
   - 六十秒告知
4. 本章自陈的边界（不得越过）：
   - **时点表把连续过程切成段。** 三级预防的分界在纸面上清楚，在个体身上常常模糊：「算早期还是已病」这个问题在临床上天天出现，本章的表格给不出答案，只能给判断的维度。
   - **完整告知的成本很高。** 一次讲清四件事，按口语速度也要十几分钟，而门诊给不出这个时间。这是真实的资源约束，不是态度问题。折中的做法是把告知拆成两次：一次讲目的与流程，一次讲结果与下一步。
   - **一级预防的收益最不可见。** 它不发生的事才是成果，因此在资源分配上永远争不过可见的三级预防。这个结构性劣势不是靠宣教能扭转的。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为疾病学基础的教学材料，只讲预防与康复的类别、时点与流程要求，不含具体筛查项目、训练参数与随访间隔，不构成诊疗或公共卫生建议，也不能替代现行规范、机构制度与具备资质人员的专业判断；具体操作以现行规范与所在机构制度为准。
