# 损伤与适应是同一件事的两头，判据在「还能不能回去」 · 提示词

## 用途

给「损伤与适应是同一件事的两头，判据在「还能不能回去」」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「可逆与不可逆：分界线画在「改变能不能回去」 → 适应四型：先改自己，再谈受损 → 两条死亡路径：靠三件事把坏死与凋亡分开 → 修复：再生能力分三档，肉芽长成瘢痕」这条链。

   - 损伤因素撤除后，形态可以回到原状

4. 本章自陈的边界（不得越过）：

   - **「可逆」二字给了虚假的安心。** 可逆只说明改变能回去，不说明回去需要多久、需要什么条件。教材对此只作方向说明，读者很容易把它读成「会自己好」。
