# 同一处病变有两本账：结构写一层，功能写一层，对不上才是常态 · 提示词

## 用途

给「同一处病变有两本账：结构写一层，功能写一层，对不上才是常态」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「黏膜缺损分两个层次，这一个层次差决定修复方式 → 溃疡：四个维度定类别，四层结构定描述 → 肝：结构一本账，功能一本账 → 肾：四个组成部分，三个功能，两条修复路径」这条链。

## 提示词

```
我在学《疾病学基础》第 11 章「同一处病变有两本账：结构写一层，功能写一层，对不上才是常态」，本章 5 节 / 3,048 汉字，习题 7 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 教材·第11章·11.1–11.4（12 个单元）。本章的层次对照表与演练题为
   - 句子变长了
   - 同步关系最容易被写成因果
   - 可逆与不可逆的分界不在本课
4. 本章自陈的边界（不得越过）：
   - **句子变长了。** 同一处病变要写结构、写功能、再写关系，三句起步。教材这一章类别密度高达每 21 字一次，读起来是吃力的——这不是文风问题，是表示方式的必然结果。
   - **同步关系最容易被写成因果。** 「结构改变与功能改变同时出现」是观察，写成「因此功能下降」就变成了结论。教材用四类关系（同步、不同步、先行、滞后）来挡这一滑坡，代价是每写一句都要标关系类型。
   - **可逆与不可逆的分界不在本课。** 教材只给类别名称与关系类型，区分依据由具备资质的人员按现行规范确定。这意味着学生学到的是一个框架，而不是一把可以自己用的尺子。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为疾病学基础的教学材料，只讲消化与泌尿系统病变的形态类别、功能类别及其关系类型，不含任何诊断标准、分级分期、检验参考值与治疗方案，不构成诊疗建议，也不能替代现行规范、机构制度与具备资质人员的专业判断；具体操作以现行规范与所在机构制度为准。
