# 骨质疏松的治疗，多半输在第二年

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 对药物的恐惧
- 费用与给药方式
- 医生没有强调
- 照护者缺位
- 基层能做的四件事
- 基层不该独立承担的三件事

## 边界

- 本章的随访框架是通用模板，具体间隔与项目须按现行指南与所在机构条件调整；本章不给固定的复查月份表。
- 依从性比例的表述只到定性（「常常不到一半」），不给精确百分比，因为不同人群、不同药物、不同随访方式下差异很大。
- 骨折联络服务的组织形式因机构而异，本章只给四个动作的顺序，不给编制与流程细节。
- 本章讨论骨质疏松的长期管理与随访，属教学材料，不构成诊疗或管理方案。筛查路径、用药调整与随访安排，应由具备资质的医师与所在机构依现行规范确定。
