# 分类看约束的方向，材料看它能撑多久

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的章首问题与「双根因定位」，确认这一章要回答的是什么；
2. 跑 `node code/main.js`，看现算的数：3204 汉字、6 节、2 张表、1 处引文（数字随正文变动，不手打）；
3. 用三个判断自查：分类的第一刀是约束的方向，不是解剖部位；材料按服役条件选，没有全面优胜：刚度换来重量与不可修改；修模避空不足是压疮最常见的技术原因，交付当天往往看不出来；
4. 用 `quiz.json` 的 8 道题自检，答不上就回到对应小节（第一节（力学三问）、第四节（材料四维度与服役寿命）、第五节（三条取模路径与避空））。

## 边界

只写类别与要点，不写材料牌号、角度、佩戴时长、压力数值与产品型号；不替代专业判断；
出现肢体麻木、皮肤破损、颜色改变、疼痛加剧或支具失效时，停用并即时就医。
