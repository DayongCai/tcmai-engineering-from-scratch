# 分类看约束的方向，材料看它能撑多久

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 8 道题自检，答不上就回到对应小节。

## 核心判据

- 它要不要动？
- 它限制哪个方向？
- 它的力从哪里来？
- 力的方向与大小能不能随关节位置变化而保持合适
- 静态渐进支具
- 贴合是动态的，不是静态的

## 边界

- **分类是工具，不是诊断。** 知道一副支具叫「腕手矫形器」不代表知道它该控什么方向；处方的核心是力学目的，不是名称。
- **材料没有最优，只有匹配。** 高刚度换来的是重量与不可修改，低刚度换来的是舒适与低约束；选择依据是病程阶段、使用场景与病人能否独立穿脱。
- **本章不写材料牌号、厚度、成形温度、佩戴时长与更换周期。** 这些属于制作与处方参数，各地区规范与产品说明不同，须由矫形师按所在机构规范执行，并由开方医师确认。
- 本章为支具分类与材料的教学材料，不构成处方或产品推荐。支具的选择、制作与更换须由具备资质的医师与矫形师依据诊断、肢体条件与使用场景决定。
