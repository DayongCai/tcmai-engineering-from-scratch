# 分类看约束的方向，材料看它能撑多久 · 提示词

## 用途

给「分类看约束的方向，材料看它能撑多久」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「分类的第一刀：不是部位，是约束的方向 → 静态、动态、静态渐进：三种力学思路 → 约束方向：单平面、双平面、三平面 → 材料：四个维度上的权衡，没有全面优胜」这条链。

## 边界

本章为支具分类与材料的教学材料，不构成处方或产品推荐。支具的选择、制作与更换须由具备资质的医师与矫形师依据诊断、肢体条件与使用场景决定；具体操作以现行规范与所在机构制度为准。
