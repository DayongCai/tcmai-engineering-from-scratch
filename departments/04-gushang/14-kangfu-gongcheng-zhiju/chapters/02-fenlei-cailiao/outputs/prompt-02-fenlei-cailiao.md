# 分类看约束的方向，材料看它能撑多久 · 提示词

## 用途

给「分类看约束的方向，材料看它能撑多久」这一章备课或自学时用的提示词。它不生成结论，只把本章的判断、可数的对象与边界摆出来，
让使用者自己走一遍这一章。

## 提示词

```
我在学《康复工程与支具学》第 2 章「分类看约束的方向，材料看它能撑多久」，本章 3204 汉字、6 节、2 张表。

请按以下顺序带我走：
1. 先给出本章的章首问题（谁、什么处境、卡在哪一步），并说明它为什么不能靠查名词解决；
2. 再列出本章要立的三个判断：
   · 分类的第一刀是约束的方向，不是解剖部位；
   · 材料按服役条件选，没有全面优胜：刚度换来重量与不可修改；
   · 修模避空不足是压疮最常见的技术原因，交付当天往往看不出来；
3. 然后按节逐条读出判据，重点在第一节（力学三问）、第四节（材料四维度与服役寿命）、第五节（三条取模路径与避空）；每条只写类别与要点，不给参数；
4. 最后给三条边界：哪些只能写到类别、哪些必须由具备资质的人员作出、哪些情况属停用并复诊的信号。

要求：不编造正文没有的数字；不写材料牌号、角度、佩戴时长、压力数值与产品型号；
不确定的地方直接说「本章未展开」。
```

## 边界

本提示词用于教学准备，不构成诊疗或处方意见；具体操作以现行规范与所在机构制度为准。
