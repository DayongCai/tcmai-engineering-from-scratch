# 脊柱支具靠三点力，不靠把躯干裹紧 · 提示词

## 用途

给「脊柱支具靠三点力，不靠把躯干裹紧」这一章备课或自学时用的提示词。它不生成结论，只把本章的判断、可数的对象与边界摆出来，
让使用者自己走一遍这一章。

## 提示词

```
我在学《康复工程与支具学》第 3 章「脊柱支具靠三点力，不靠把躯干裹紧」，本章 2913 汉字、6 节、1 张表。

请按以下顺序带我走：
1. 先给出本章的章首问题（谁、什么处境、卡在哪一步），并说明它为什么不能靠查名词解决；
2. 再列出本章要立的三个判断：
   · 三点力压侧弯，控旋转要四点力形成力偶；
   · 压力垫偏一个椎体，纠正的节段就错位；
   · 支具不能矫正结构性畸形，只能控制进展或限制活动；
3. 然后按节逐条读出判据，重点在第二节（压力垫、避空区与力系四可调量）、第四节（约束度三维与去支具化）、第五节（皮肤、呼吸与依从性）；每条只写类别与要点，不给参数；
4. 最后给三条边界：哪些只能写到类别、哪些必须由具备资质的人员作出、哪些情况属停用并复诊的信号。

要求：不编造正文没有的数字；不写材料牌号、角度、佩戴时长、压力数值与产品型号；
不确定的地方直接说「本章未展开」。
```

## 边界

本提示词用于教学准备，不构成诊疗或处方意见；具体操作以现行规范与所在机构制度为准。
