# 辅具的第一判据是使用者能不能自己用

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 8 道题自检，答不上就回到对应小节。

## 核心判据

- 它把一个人做不到的动作，变成做得到
- 跨的是什么？
- 处方要解的，是这个人当前能力与这个环境约束下的最优解，而不是参数上的最优
- 太灵活的会跌倒，太稳的会走不动
- 腋拐不能靠腋窝承重
- 胶头（防滑垫）是耗材

## 边界

- **辅具不能替代训练。** 用进废退在辅具使用上同样成立：过早、过度依赖轮椅会加速下肢功能衰退，而完全不用的跌倒风险同样真实。取舍要按功能潜力与风险评估。
- **尺寸错误的辅具比没有辅具更危险。** 座宽过大导致倾倒、拐杖过高导致代偿、坐垫失效导致压疮，都是「有辅具」造成的伤害。
- **弃用的原因几乎都能改。** 太重、进不了门、不好看、不会用、没人修——这些是设计、训练与服务问题，不是病人态度问题。
- 本章为助行器、轮椅与转移辅具的教学材料，不构成处方或适配意见。辅具的选择与尺寸须由康复治疗师或假肢矫形师按个体测量与居家环境评估确定。
