# 下肢支具先回答负重，再回答步态 · 提示词

## 用途

给「下肢支具先回答负重，再回答步态」这一章备课或自学时用的提示词。它不生成结论，只把本章的判断、可数的对象与边界摆出来，
让使用者自己走一遍这一章。

## 提示词

```
我在学《康复工程与支具学》第 5 章「下肢支具先回答负重，再回答步态」，本章 2945 汉字、6 节、1 张表。

请按以下顺序带我走：
1. 先给出本章的章首问题（谁、什么处境、卡在哪一步），并说明它为什么不能靠查名词解决；
2. 再列出本章要立的三个判断：
   · 先定承重、再定步态，最后才是材料与外观；
   · 踝的对线会改变膝的受力，足下垂支具是按膝的状态调整的一组东西；
   · 接受腔与坐骨承重座圈同理：能承重的部位加压，不能承重的部位避空；
3. 然后按节逐条读出判据，重点在第一节（两问与次序）、第二节（足下垂与踝的对线）、第四节（坐骨承重与鞋）与第五节（假肢三件事）；每条只写类别与要点，不给参数；
4. 最后给三条边界：哪些只能写到类别、哪些必须由具备资质的人员作出、哪些情况属停用并复诊的信号。

要求：不编造正文没有的数字；不写材料牌号、角度、佩戴时长、压力数值与产品型号；
不确定的地方直接说「本章未展开」。
```

## 边界

本提示词用于教学准备，不构成诊疗或处方意见；具体操作以现行规范与所在机构制度为准。
