# 下肢支具先回答负重，再回答步态

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 8 道题自检，答不上就回到对应小节。

## 核心判据

- 第一问：这条腿能不能承重？
- 第二问：这条腿能不能迈步？
- 先定承重，再定步态，最后才是材料与外观
- （把髋膝抬得很高，像跨门槛）与
- 踝关节的允许活动
- 壳体的覆盖范围

## 边界

- **负重状态是处方的第一参数，不能靠支具「补」。** 该免重的病人戴什么支具都不该负重，支具不能替代医嘱。
- **每增加一层约束，就增加一份能耗与依赖。** 长腿支具、锁定膝、坐骨承重座圈都能提高稳定，但都会降低步行效率与耐受性；方案要按「最小有效约束」设计。
- **足下垂支具的对线会改变膝的受力。** 不考虑膝的状态就配踝足矫形器，可能把一个膝过伸的病人推向更严重的过伸。
- 本章为下肢支具与假肢的教学材料，不构成诊断、处方或康复方案。负重时机、支具类型与假肢适配须由具备资质的医师与假肢矫形师决定。
