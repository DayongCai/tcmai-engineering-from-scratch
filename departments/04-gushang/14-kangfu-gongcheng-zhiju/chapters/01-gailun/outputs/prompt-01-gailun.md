# 支具不治病，它改变的是力的分配 · 提示词

## 用途

给「支具不治病，它改变的是力的分配」这一章备课或自学时用的提示词。它不生成结论，只把本章的判断、可数的对象与边界摆出来，
让使用者自己走一遍这一章。

## 提示词

```
我在学《康复工程与支具学》第 1 章「支具不治病，它改变的是力的分配」，本章 3349 汉字、6 节、2 张表。

请按以下顺序带我走：
1. 先给出本章的章首问题（谁、什么处境、卡在哪一步），并说明它为什么不能靠查名词解决；
2. 再列出本章要立的三个判断：
   · 支具的作用落在损伤层与活动层，不落在病理层；
   · 环形抱紧给的是摩擦与压缩，不是力矩；成角的控制来自三点压力差；
   · 约束度=允许多少活动、允许承受多少力、允许多久，方案要预设什么时候开始减量；
3. 然后按节逐条读出判据，重点在第一节（分层与四类产品）、第三节（三点固定的四个条件）、第五节（处方上「目的」与责任链四个签字）；每条只写类别与要点，不给参数；
4. 最后给三条边界：哪些只能写到类别、哪些必须由具备资质的人员作出、哪些情况属停用并复诊的信号。

要求：不编造正文没有的数字；不写材料牌号、角度、佩戴时长、压力数值与产品型号；
不确定的地方直接说「本章未展开」。
```

## 边界

本提示词用于教学准备，不构成诊疗或处方意见；具体操作以现行规范与所在机构制度为准。
