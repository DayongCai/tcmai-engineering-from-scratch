# 手部支具的目标是滑动，不是固定 · 提示词

## 用途

给「手部支具的目标是滑动，不是固定」这一章备课或自学时用的提示词。它不生成结论，只把本章的判断、可数的对象与边界摆出来，
让使用者自己走一遍这一章。

## 提示词

```
我在学《康复工程与支具学》第 4 章「手部支具的目标是滑动，不是固定」，本章 2987 汉字、6 节、1 张表。

请按以下顺序带我走：
1. 先给出本章的章首问题（谁、什么处境、卡在哪一步），并说明它为什么不能靠查名词解决；
2. 再列出本章要立的三个判断：
   · 手靠三套滑动界面工作，界面靠运动维持、不靠休息恢复；
   · 安全位取掌指屈、指间伸，因为两组侧副韧带最放松的方向相反；
   · 评价标准是主动活动度，不是固定牢靠；主动与被动差距扩大提示粘连；
3. 然后按节逐条读出判据，重点在第一节（三套界面）、第二节（功能位与安全位）、第五节（交付时的三项检查与水肿）；每条只写类别与要点，不给参数；
4. 最后给三条边界：哪些只能写到类别、哪些必须由具备资质的人员作出、哪些情况属停用并复诊的信号。

要求：不编造正文没有的数字；不写材料牌号、角度、佩戴时长、压力数值与产品型号；
不确定的地方直接说「本章未展开」。
```

## 边界

本提示词用于教学准备，不构成诊疗或处方意见；具体操作以现行规范与所在机构制度为准。
