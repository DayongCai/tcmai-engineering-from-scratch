# 适配好不好，皮肤先说话 · 提示词

## 用途

给「适配好不好，皮肤先说话」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「适配的三层判据 → 皮肤：最早、也最诚实的信号 → 记录：把「感觉」变成「可比」 → 随访：节奏由风险决定」这条链。

## 边界

本章为适配评估与随访的教学材料，不构成诊断或治疗意见。支具的适配、调整与停用须由具备资质的医师与矫形师判断；具体操作以现行规范与所在机构制度为准。
