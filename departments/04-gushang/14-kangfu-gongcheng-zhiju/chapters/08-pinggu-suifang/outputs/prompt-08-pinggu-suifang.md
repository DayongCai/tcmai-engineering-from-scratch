# 适配好不好，皮肤先说话 · 提示词

## 用途

给「适配好不好，皮肤先说话」这一章备课或自学时用的提示词。它不生成结论，只把本章的判断、可数的对象与边界摆出来，
让使用者自己走一遍这一章。

## 提示词

```
我在学《康复工程与支具学》第 8 章「适配好不好，皮肤先说话」，本章 2806 汉字、6 节、1 张表。

请按以下顺序带我走：
1. 先给出本章的章首问题（谁、什么处境、卡在哪一步），并说明它为什么不能靠查名词解决；
2. 再列出本章要立的三个判断：
   · 适配是过程不是事件：第三层耐受只能在真实生活里验证；
   · 剪切力比垂直压力更伤组织，松动比压紧更危险；
   · 依从要看行为与磨损痕迹，自报时长普遍偏高；
3. 然后按节逐条读出判据，重点在第一节（三层判据）、第二节（皮肤四信号）、第四节与第五节（风险分层随访、弃用五类与转诊链）；每条只写类别与要点，不给参数；
4. 最后给三条边界：哪些只能写到类别、哪些必须由具备资质的人员作出、哪些情况属停用并复诊的信号。

要求：不编造正文没有的数字；不写材料牌号、角度、佩戴时长、压力数值与产品型号；
不确定的地方直接说「本章未展开」。
```

## 边界

本提示词用于教学准备，不构成诊疗或处方意见；具体操作以现行规范与所在机构制度为准。
