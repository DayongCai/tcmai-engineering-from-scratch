# 片子回答「有没有」，不回答「痛不痛」 · 提示词

## 用途

给「片子回答「有没有」，不回答「痛不痛」」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「四种检查，各答一个不同的问题 → 读片的顺序：从大到小，从线到面 → 报告语言里的三个陷阱 → 影像与症状对不上时，信谁」这条链。

## 边界

本章讨论脊柱影像的适应证、读片顺序与报告解读，属教学材料，不构成诊疗意见。影像的判读与检查方案的选择，须由具备资质的医师结合病史、查体与既往片作出；具体操作以现行规范与所在机构制度为准。
