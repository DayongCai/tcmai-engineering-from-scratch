# 骨关节炎与类风湿的治疗方向是相反的

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 5 条核心判断见下）；
4. 用 `quiz.json` 的 8 道题自检，答不上就回到对应小节。

## 核心判据

- 两个方向的病不能用一套办法
- 影像分期不等于症状分级
- 本章不给药物名称、剂量与疗程，也不给各分级的阈值
- 中医的位置是症状、功能与体质，不是替代控制病情的药物
- 个案只作说明

## 边界

- **两个方向的病不能用一套办法。** 骨关节炎鼓励活动，炎性关节病活动期要先控炎；方向错了，越治越坏。
- **影像分期不等于症状分级。** 两套评估必须分开记录，否则无法判断治疗改变了什么。
- **本章不给药物名称、剂量与疗程，也不给各分级的阈值。** 这些须由风湿专科与骨科按规范决定；本章只到「识别与转向」。
- 本章讨论退行性与免疫性关节病的鉴别、评估与治疗方向，不构成诊疗方案。任何用药、外治与手术决策，须由执业医师依据具体病情、实验室与影像资料及所在机构规范作出。
