# 骨肿瘤的第一个动作是拍片，不是解释

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 5 条核心判断见下）；
4. 用 `quiz.json` 的 8 道题自检，答不上就回到对应小节。

## 核心判据

- 罕见病的判断不能靠概率，要靠规则
- 本章不给化疗方案、手术边界与生存数据，也不给活检技术细节
- 中医的位置是支持与症状控制，不是根治
- 影像不诊断
- 个案只作说明

## 边界

- **罕见病的判断不能靠概率，要靠规则。** 「这个年龄、这个部位、这种夜间痛就拍片」是一条规则，规则的价值在于它不依赖医生当天见过多少例。
- **本章不给化疗方案、手术边界与生存数据，也不给活检技术细节。** 这些属于肿瘤专科；本章只到「识别与转交」为止。
- **中医的位置是支持与症状控制，不是根治。** 这一条写得直白，因为含糊的表述会被理解成「还有一条路」。
- 本章讨论骨肿瘤的识别线索与转诊流程，不构成诊断或治疗建议。任何影像判读、活检、手术与药物治疗，须由具备相应资质的专科医师依据病理结果与所在机构规范作出。
