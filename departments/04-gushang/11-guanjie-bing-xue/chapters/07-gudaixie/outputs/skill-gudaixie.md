# 骨量的流失是安静的，骨折是它第一次说话

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 5 条核心判断见下）；
4. 用 `quiz.json` 的 8 道题自检，答不上就回到对应小节。

## 核心判据

- 骨密度是工具，不是结论
- 本章不给药物名称、剂量与疗程，也不给运动处方的时间与强度
- 补钙不是治疗的全部
- 痛风的管理是长期的
- 个案只作说明

## 边界

- **骨密度是工具，不是结论。** 同一个 T 值在不同年龄、不同部位、不同设备上的意义不同；诊断要与骨折史、风险因素合并判断。
- **本章不给药物名称、剂量与疗程，也不给运动处方的时间与强度。** 这些须由医师按骨密度、肾功能、骨折风险与合并用药决定。
- **补钙不是治疗的全部。** 只补钙不查继发因素、不评估跌倒风险、不用抗骨吸收或促骨形成药物，是这一科最常见的「看起来在治」。
- 本章讨论骨代谢性疾病的识辨、病机与评估框架，不构成诊疗方案。任何检查、用药与运动建议，须由执业医师依据骨密度、实验室结果与个体情况作出。
