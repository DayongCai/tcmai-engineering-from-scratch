# 骨结核最像的不是结核，是劳损

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 5 条核心判断见下）；
4. 用 `quiz.json` 的 8 道题自检，答不上就回到对应小节。

## 核心判据

- 慢病的判断要靠「无效即换路」
- 本章不给抗结核药物的名称、剂量与疗程，也不给手术指征的数值门槛
- 中医治疗的位置是扶正与化痰，不是抗病原
- 影像不能单独确诊
- 个案只作说明

## 边界

- **慢病的判断要靠「无效即换路」。** 按概率先治劳损是合理的，但必须约定复查时点；「理疗后轻松两天」不能算有效。
- **本章不给抗结核药物的名称、剂量与疗程，也不给手术指征的数值门槛。** 这些由结核专科与所在机构规范决定；写死的数字会被误当成「达到就可以停」。
- **中医治疗的位置是扶正与化痰，不是抗病原。** 阴证用温通、溃后用补益，这一方向判断错，比方剂选错更伤病人。
- 本章讨论骨与关节结核的识辨、病机与治疗次序，不构成诊疗方案。任何抗结核用药、手术与转诊决策，须由执业医师依据病原学结果、影像资料与所在机构规范作出。
