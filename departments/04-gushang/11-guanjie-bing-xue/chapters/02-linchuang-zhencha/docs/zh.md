# 第 2 章 · 关节病的体征长得很慢，判据必须写在流程里

> **MOTTO:** 「膝者筋之府，屈伸不能，行则偻附，筋将惫矣；骨者髓之府，不能久立，行则振掉，骨将惫矣。」——《素问·脉要精微论》
>
> **PROBLEM:** 一位 47 岁女性，双手晨僵 3 年，5 次门诊。每次查「抗链 O」与「血沉」，都写「正常」，诊断写「双腕腱鞘炎」，嘱少沾凉水。第 3 年拍片，双腕关节间隙已经消失。翻五次病历，没有一次写下晨僵多少分钟、有几个关节肿、握力多少、能不能握拳。指标查了十几次，判据一个也没留下——所以她一直在「观察」，观察了三年，观察掉了两只手腕。

**双根因定位:** 环境逼迫（门诊的时间预算按「主诉」分配，病人说膝疼就查膝，说手僵就查手；而关节病的诊断信息大部分藏在「别的地方」——对侧、晨僵、皮肤、眼睛、体重、用药史，问这些不产生即时回报，于是被省略）+ 知识积累（诊查章节按「望闻问切」与「视触动量」编排，条目齐全但彼此平行，学生学到的是一份检查清单，不是一条「先问什么、问到什么就转向」的分岔路；清单可以背，分岔路只能练）

## 一、问诊：时间轴比部位更早给出答案

关节痛的首诊，八成的人会先问「哪里疼」。这个问题的信息量最低，因为病人报的部位往往不是病灶部位：髋关节病变常诉膝痛，肩袖病变常诉上臂痛，腰椎小关节病变常诉臀部痛。真正能分开类别的是时间。

第一问，起病有多快。一夜之间肿起来、几小时内痛到不能碰，指向晶体或感染；几周之内逐渐加重，指向炎性；几年里慢慢进展、时轻时重，指向退变。这个问题的答案精确度要求不高，「一夜」「一个月」「好几年」三种回答已经足够分层。

第二问，早晨僵多久，活动之后是变轻还是变重。这是整个关节科性价比最高的一个问题。退行性关节病的晨僵通常短，起床活动片刻就松开；炎性关节病的晨僵长，往往超过半小时，活动后逐渐改善但整个上午都不利索；感染性病变没有这种「晨僵—活动缓解」的节律，它持续地痛，不动也痛。问这一句只要十秒，它能省掉一轮检查。

第三问，夜间痛不痛，会不会痛醒。白天活动时痛、休息后缓解，多数是机械性；夜间静息痛、痛醒、翻身痛，要想到炎症、感染、肿瘤与骨内压升高。儿童与青少年的夜间痛尤其要当心，这一条在后面的肿瘤章还会再出现。

第四问，是单关节还是多关节，对称不对称，从哪个关节开始。单关节急性发作，先想感染与晶体；对称性手足小关节起病，先想类风湿；不对称的下肢大关节加上腰背痛，先想脊柱关节炎；第一跖趾关节突然红肿，先想痛风。起病关节的「第一个」非常有价值，病人常常记得很清楚，只是没人问。

第五问，有没有关节以外的线索：发热、盗汗、消瘦、皮疹、眼红、口腔与外阴溃疡、腹泻、银屑病、反复尿路感染、近期关节腔注射、长期激素或抗凝药、糖尿病与免疫抑制状态。这些问题不是「全面查体」的形式主义，它们各自对应一条明确的转向：皮疹与眼红指向脊柱关节炎或系统性红斑狼疮，盗汗消瘦指向结核与肿瘤，近期注射与免疫抑制指向化脓性关节炎。

## 二、望诊与触诊：分清「骨性」与「滑膜性」

关节肿胀有两种，处理方式完全不同，靠手就能分开。

骨性肿大是硬的、边界清楚、压不下去，常伴畸形与骨赘感，见于退行性关节病的远端指间关节。滑膜性肿胀是软的、有波动、边界模糊，压之凹陷，常伴皮温升高，见于炎性、感染与晶体性关节病。摸到硬的，治疗方向是减负与力线；摸到软的，治疗方向是先弄清里面是什么液体。

皮温要用指背比，双侧对照，从远离关节处向关节移动。单侧皮温明显升高，配合肿胀与拒按，是抽液的指征，不是热敷的指征。

肌肉萎缩要量，不要看。股四头肌内侧头萎缩在膝关节病变里出现得很早，肉眼往往看不出，用软尺在大腿固定骨性标志上方量周径，两侧对比，比「看起来有点细」可靠得多。肌肉是关节的减震器，萎缩一旦发生，关节承受的峰值负荷立刻上升，疼痛加重，活动减少，萎缩更快——这个环要靠测量才能发现自己在转。

活动度要用同一把尺、同一个体位、同一句口令。膝关节屈伸、髋关节内外旋、肩关节前屈外展外旋、腕关节背伸掌屈，都是可以量到度数的。测量的意义不在绝对值，在于两次之间能不能比。

力线要站着看，不要躺着看。膝内翻、膝外翻、足弓塌陷、下肢不等长，躺着都看不出来。力线偏移意味着负荷分布改变，这是退变进展最重要的可控因素之一，也是「为什么她的右膝比左膝坏得快」这类问题的答案。

## 三、量化的最小集合：五件事，每次一样

关节病的特点是慢，慢病的质量取决于「能不能比」。所以诊查要留下一个最小的、可重复的集合。

一是疼痛。用同一张量表、同一个时间范围（例如「过去一周最痛时」），不要今天问「现在」明天问「一周平均」。

二是关节计数。记录压痛关节数与肿胀关节数，分开记。压痛反映主观疼痛，肿胀反映客观炎症，两者不同步的时候，肿胀那一栏更可信。

三是功能。握力（用手握式测力计或用血压计袖带法）、二十米步行时间、从椅子起身五次的时间、能否完成扣纽扣与拧瓶盖。这些项目不需要设备，却能在三个月后告诉医生「有没有变好」，而影像不会。

四是晨僵分钟数。让病人自己计时，写在就诊前三天。

五是全局判断。病人自己给「今天关节状况」打一个分，以及医生对疾病活动的整体评估。两个分数经常不一致，不一致本身就是信息。

影像与实验室是这五件事的补充，不是替代。X 线看结构：关节间隙、软骨下骨、骨赘、骨破坏、力线。超声看软组织：滑膜厚度、血流、积液、肌腱。磁共振看早期病变：骨髓水肿、软骨缺损、早期坏死、椎体与椎旁。实验室看炎症与免疫：血沉、C 反应蛋白、类风湿因子、抗环瓜氨酸肽抗体、血尿酸、HLA-B27。这些检查各自回答一个具体问题，先有问题再开检查，反过来做，就会得到一堆「轻度异常」而没有一个诊断。

## 四、中医四诊在这一科的落点

四诊不是四套并行的检查，是四个方向的观察，落到关节科有很具体的内容。

望：先望形态与姿态——站姿是否偏斜、步态是否避痛、脊柱有无侧弯与后凸、双膝是否内翻、手指有无尺偏与天鹅颈。再望局部——肿胀是弥漫还是局限、皮色是红是白、有无窦道与瘢痕、有无肌肉萎缩。再望舌——舌质淡胖多见于本虚，舌质紫暗或有瘀斑多见于瘀阻，舌苔白腻多见于寒湿，黄腻多见于湿热。舌象在关节病里不是装饰，它与炎症活动、体质、用药（激素、非甾体药对舌象的影响）都相关。

闻：关节病里「闻」的内容不多，但有一项不能漏——窦道或溃破处的气味。有臭味提示厌氧菌或混合感染，处理路径立刻不同。

问：除前述五问，中医还要问寒热、汗、饮食、二便、睡眠与情志。畏寒喜暖、得温痛减属寒；遇热加重、得凉则舒属热；汗出恶风、遇风加重属表虚；大便溏、腹胀、食少属脾虚；夜寐不安、心烦易怒，肝郁化火可以加重疼痛感受。这些问出来的是「证」，也常常问出来的是「这个人怎么过日子」——而后者往往决定治疗能不能落地。

切：脉诊之外，切诊在关节科有独立价值——局部皮温、肿胀的软硬、压痛点的位置与深浅、关节线的压痛、肌肉的张力与条索。按之痛在骨还是痛在筋，按之是拒按还是喜按，虚实的分界常常就在手指下。

四诊的结论必须与可测项对齐。说「湿热痹阻」，就要能指出皮温高、肿胀软、舌苔黄腻、血沉或 C 反应蛋白升高；说「肝肾亏虚」，就要能对上病程长、肌肉萎缩、骨量低、影像退变重。对不上，不是推翻中医，是提示辨证需要修正——这正是两套语言并用时最有用的一刻。

## 五、诊查的产出：一份下一个人能接手的记录

诊查的终点不是「诊断：骨痹」，是一份能让下一位医生在三十秒内接手的记录。它至少包含五段。

第一段，时间轴：起病时间、起病方式、病程中的起伏、治疗史与反应（用过什么、用了多久、有没有效、有没有停）。

第二段，分布：哪些关节、对称与否、哪一侧更重、有无关节外表现。

第三段，量化：疼痛分、肿胀与压痛关节数、晨僵分钟、功能项、力线描述。

第四段，危险排除：发热与感染史、结核接触与全身症状、夜间痛与肿块、体重变化、肿瘤史。这一段的写法应当是「已查/未查」，而不是留白。留白在下一个人眼里等于没问。

第五段，分层与下一步：把病人放进三层里——绿（明确良性、可门诊随访）、黄（诊断未定或治疗反应不佳，需在限定时间内复查或加做检查）、红（需当日转诊）。红层的触发条件写在纸上：关节红肿热痛伴发热、疑似化脓；脊柱痛伴下肢无力或二便障碍；夜间痛醒伴肿块；快速进展的关节破坏；儿童跛行伴发热。

这份记录的价值在于它把判断从「某位医生的记忆」变成「科室内可传递的东西」。关节病随访期长，一个病人五年里可能遇到十位医生，如果每个人都从零开始问，那么第五年得到的仍然是一份初诊记录。

## 代价与边界

- **量化不等于精确。** 疼痛分、握力、步行时间都有测量误差，单次差异没有意义，要看趋势；但「没有基线」比「基线不精确」糟糕得多。
- **检查不能代替问诊。** 关节病的诊断有相当大一部分由病史决定，实验室与影像负责确认与否决。先开单后问诊，得到的常是一份「轻度异常、建议随访」。
- **中医四诊不提供分期的数值。** 辨证给方向，影像与实验室给程度，两者不能互相顶替；本章不给任何分级的阈值，因为阈值随部位、年龄与设备而变。
- **分层是流程工具，不是免责声明。** 写「建议转诊」而不写触发条件，等于把判断交给病人自己。
- **个案只作说明。** 文中病例为合成示例，不含可定位的机构、人名与时间。

**免责声明:** 本章讨论关节病的诊查流程与记录要点，不构成诊断标准。任何检查项目、穿刺与转诊决策，须由执业医师依据具体病情与所在机构规范作出。
