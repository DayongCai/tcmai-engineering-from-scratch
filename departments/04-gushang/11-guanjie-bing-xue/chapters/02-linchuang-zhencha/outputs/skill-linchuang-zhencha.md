# 关节病的体征长得很慢，判据必须写在流程里

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 5 条核心判断见下）；
4. 用 `quiz.json` 的 8 道题自检，答不上就回到对应小节。

## 核心判据

- 量化不等于精确
- 检查不能代替问诊
- 中医四诊不提供分期的数值
- 分层是流程工具，不是免责声明
- 个案只作说明

## 边界

- **量化不等于精确。** 疼痛分、握力、步行时间都有测量误差，单次差异没有意义，要看趋势；但「没有基线」比「基线不精确」糟糕得多。
- **检查不能代替问诊。** 关节病的诊断有相当大一部分由病史决定，实验室与影像负责确认与否决。先开单后问诊，得到的常是一份「轻度异常、建议随访」。
- **中医四诊不提供分期的数值。** 辨证给方向，影像与实验室给程度，两者不能互相顶替；本章不给任何分级的阈值，因为阈值随部位、年龄与设备而变。
- 本章讨论关节病的诊查流程与记录要点，不构成诊断标准。任何检查项目、穿刺与转诊决策，须由执业医师依据具体病情与所在机构规范作出。
