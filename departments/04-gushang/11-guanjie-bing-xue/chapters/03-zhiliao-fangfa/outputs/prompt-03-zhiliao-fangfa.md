# 治疗不是选项的堆叠，是先分层、再分期、后选法 · 提示词

## 用途

给「治疗不是选项的堆叠，是先分层、再分期、后选法」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三层与三期：先决定「治哪一层」 → 内治：方从法出，法从证出，但别把内治当全部 → 外治：它作用在皮、筋、络，不在骨 → 关节镜与置换：适应证窄，边界清楚」这条链。

## 边界

本章讨论关节病治疗的层次、次序与边界，不构成治疗方案。任何用药、外治、注射与手术决策，须由执业医师依据具体病情、影像资料与所在机构规范作出；具体操作以现行规范与所在机构制度为准。
