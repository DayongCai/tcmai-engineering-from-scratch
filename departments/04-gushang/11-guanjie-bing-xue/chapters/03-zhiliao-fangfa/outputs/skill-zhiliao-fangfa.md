# 治疗不是选项的堆叠，是先分层、再分期、后选法

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 5 条核心判断见下）；
4. 用 `quiz.json` 的 8 道题自检，答不上就回到对应小节。

## 核心判据

- 方法越多，越需要次序
- 本章不写药物剂量、注射次数、手术参数与康复处方
- 中医外治的适应证有边界
- 手术是交换，不是升级
- 个案只作说明

## 边界

- **方法越多，越需要次序。** 本章给的是三层三期的框架，不是方法清单；没有次序的清单，落到临床就是十一项治疗与零个基线。
- **本章不写药物剂量、注射次数、手术参数与康复处方。** 这些数值必须结合体重、肝肾功能、合并用药、影像分期与所在机构规范，写死的数字会被当成标准照抄。
- **中医外治的适应证有边界。** 感染、结核、肿瘤部位，皮肤破损与感觉障碍区域，抗凝与凝血异常状态，都是边界之外；越界不是技法问题，是安全问题。
- 本章讨论关节病治疗的层次、次序与边界，不构成治疗方案。任何用药、外治、注射与手术决策，须由执业医师依据具体病情、影像资料与所在机构规范作出。
