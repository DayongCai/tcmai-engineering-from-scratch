## 四、辨清一件事：中医运动学 ≠ 康复训练

两者都讲「练」，但来源与判据不同：

| | 中医运动学 | 康复训练 |
|---|---|---|
| 来源 | 导引、气功、功法（三调） | 功能评定与训练处方 |
| 判据 | 功法规格与练功反应 | 肌力/活动度/平衡的量化改善 |
| 风险 | 练功偏差（意守过度、呼吸憋气） | 训练过量、跌倒 |

本课把两条线并置：第 1–4 章是导引侧，第 5–8 章是训练侧，**不把二者混成一锅**。
