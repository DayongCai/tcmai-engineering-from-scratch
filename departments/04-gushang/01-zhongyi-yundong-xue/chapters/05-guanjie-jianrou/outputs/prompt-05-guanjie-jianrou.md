# 柔韧不是拉得越开越好，是关节在该动的地方动、该稳的地方稳 · 提示词

## 用途

给「柔韧不是拉得越开越好，是关节在该动的地方动、该稳的地方稳」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「活动度由三样东西决定，缺一样都拉不开 → 「摸到脚尖」为什么不能代表髋的柔韧 → 三种牵伸，用在不同的时候 → 柔韧必须与稳定配对」这条链。

## 边界

本章讨论关节活动度与柔韧训练的原理与边界，不构成诊疗意见。具体牵伸方案、幅度与进度，以所在机构规范与具备资质人员的个体评估为准；具体操作以现行规范与所在机构制度为准。
