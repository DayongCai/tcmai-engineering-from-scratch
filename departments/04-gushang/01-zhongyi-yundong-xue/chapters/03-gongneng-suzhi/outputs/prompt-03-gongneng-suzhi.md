# 体能不是六项指标的并列，是一条有先后的链 · 提示词

## 用途

给「体能不是六项指标的并列，是一条有先后的链」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「六项素质与五脏：一张对不齐的表 → 要素之间有先后，顺序错了练的是代偿 → 年龄不是「该少动」的理由，是「换个动法」的依据 → 评估的最小集：三项，五个观察」这条链。

## 边界

本章讨论运动功能的构成与评估思路，不构成诊疗意见。具体测试方法、判读界值与训练安排，以所在机构规范与具备资质人员的评估为准；具体操作以现行规范与所在机构制度为准。
