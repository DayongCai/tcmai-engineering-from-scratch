# 体能不是六项指标的并列，是一条有先后的链

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 活动度 → 稳定 → 力量 → 耐力 → 平衡与协调 → 专项动作
- 看动作的终点在哪里先「卡住」
- 该有代偿的地方没有
- 「好走」「好趋」「好步」「好坐」不是意愿的变化，是能力结构的变化
- 青少年不宜过早做单一专项的大负荷
- 中年以后训练目标从「增长」转为「保住」

## 边界

- **本章不给任何及格线。** 握力、步速、单腿站立时长的参考值随年龄、性别、测量方法而变，且不同来源的界值差异很大。教学只讲「测什么、看什么」，具体判读以所在机构规范为准。
- **体测不能替代功能观察。** 一个人在测试环境里达标，在真实环境里（低光、湿滑、分心、负重）可能完全不达标。测试条件与出事条件不一致，是筛查漏诊的主因。
- **「综合评分」要慎用。** 若必须出总分，至少同时报出最低项，并注明总分不反映串联系统的真实强度。
- 本章讨论运动功能的构成与评估思路，不构成诊疗意见。具体测试方法、判读界值与训练安排，以所在机构规范与具备资质人员的评估为准。
