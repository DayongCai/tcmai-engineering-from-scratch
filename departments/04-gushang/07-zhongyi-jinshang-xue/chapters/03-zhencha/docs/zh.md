# 第 3 章 · 压痛点的位置，比疼了多久更有信息量

> **MOTTO:** 「一旦临证，机触于外，巧生于内，手随心转，法从手出。」——《医宗金鉴·正骨心法要旨》
>
> **PROBLEM:** 「腰骶部压痛」是一句不合格的记录：它没有位置、没有深度、没有诱发动作，第二个人拿着一张纸按不到同一个点上。一次筋伤诊查要取到哪几样证据才算够用——五样，还是五十样？

**双根因定位:** 环境逼迫（筋伤多数没有金标准：骨折有 X 线，前距腓韧带断没断最终要靠磁共振或直视，日常门诊拿不到；于是诊查的目标不是「确诊」，而是「把概率推到足以做决定的区间」）+ 知识积累（本章 5 单元 / 11,608 汉字，引书 9 部 22 次；五个单元分别是 L3 横突综合征、骨折的临床表现与检查、跟痛症、骨盆骨折、踝关节扭伤——五篇病种稿，却要拼出一套通用的取证方法）

**教材出处：**《中医筋伤学》第一章·第四节（诊断：临床表现、检查方法、并发症）；本章单元见 `standards/gushang-jinshang/units.json`。

## 一、四诊在筋伤里的分工

筋伤的四诊不是把内科四诊照搬，而是各有专属的取证任务。

**望诊看的是不对称。** 肿胀的范围与张力、瘀斑的位置与时间、肢体的成角与短缩、步态与负重意愿。腰背与踝部单元都写了同一条：肿胀严重者皮肤绷紧发亮、出现张力性水疱时，须警惕骨筋膜室综合征。望诊在这里不是描述，是报警阈值。望诊的另一半是看健侧——单侧病变的一切判断都以对侧为参照。

**闻诊在筋伤里只剩两件事：骨擦音与弹响。** 骨折的单元把骨擦音或骨擦感与畸形、异常活动并列为三项专有体征；反过来说，**没有骨擦音不等于没有骨折**：嵌插骨折与青枝骨折可以全无此征。闻诊不作常规追求，反复诱发骨擦音是加重损伤的动作。

**问诊问的是疼痛的时间结构，不是疼痛的分数。** 跟痛症给了最好的样板：晨起下床第一步或久坐后起步时剧痛，行走片刻减轻，长走久站又加重——这三句话合起来指向跖筋膜止点的退变，比任何疼痛评分都更能定位。第三腰椎横突综合征同样如此：弯腰、久坐、久站或劳累后加重，休息后减轻，晨起或静卧过久僵硬、活动后减轻。时间是免费的定位工具。

问诊还必须问三件与定位无关、与安全有关的事：夜间静息痛与消瘦、进行性麻木无力与大小便功能改变、发热与寒战。这三问不产生诊断，只产生「停」。

**切诊（摸）是筋伤诊查的主体。** 顺序是先轻后重、先健侧后患侧、先周围后中心：轻摸皮温与肿胀的边界，中摸肌张力与条索，重摸骨性标志与压痛点。摸到的三样东西要分开记：压痛（点）、条索或硬结（线）、肌痉挛（面）。三者混成一句「腰部压痛明显」，后面就无法复核。

## 二、三样可量、三样不可量

诊查里的量化，只有三样东西真正立得住。

**活动度。** 以中立位为零度，主动与被动分别记录，与健侧对比。教材给的是类别加方向的写法，如「腰椎活动度可轻度受限，以前屈与侧屈受限为主」；这是类别，不是角度。要写到角度，必须交代测量体位与量具，且前后对比用同一体位。绝对值受年龄、体型、配合程度影响，**差值才是判据**。

**肌力。** 通行按 0～5 级记录，0 级为无收缩，5 级为正常。它是序数：说明「能不能抗阻力、能不能抗重力、有没有收缩」，不说明「差了多少力量」。4 级与 5 级之间的差，不等于 0 级与 1 级之间的差；把分级相加求均值，在方法上不成立。

**周径与长度。** 这两项最容易做出假精确。皮尺的张力、骨性标志的选择、肢体的摆放，任何一项变了数就不可比。记录时必须把标志写进去（如「髌骨下缘上 10 cm」），否则第二次测量等于重新开始。

**不能量化的三样**：压痛的强度、条索的硬度、肿胀的手感。它们只能记成「部位 + 分级（无／轻／中／重）+ 诱发动作」。分级是序数，不加权、不求和、不当连续变量。

这一节要防的错误很具体：把四类证据当成同一种东西去打分、求平均。压痛可以定位，但没有单位；「L3 横突尖端深压痛」是一句可复核的话，「压痛 7 分」不是。给没有单位的东西硬配一个分数，看起来精确，实际只是把测量者的主观换了个包装。

## 三、特殊试验：改变概率，不给结论

特殊试验是用规定体位与规定方向的外力，把某一条结构的损伤从「可能」推向「较可能」的动作。几个常用试验可以拼成一张最小表：

| 试验 | 针对结构 | 阳性所见 |
|---|---|---|
| 踝前抽屉试验 | 前距腓韧带 | 跖屈位向前推足跟，前移较健侧增大并有凹痕感 |
| 内翻应力试验 | 外侧副韧带（跟腓韧带为主） | 内翻开口较健侧增大 |
| 外翻应力试验 | 三角韧带 | 外翻开口较健侧增大 |
| 小腿中段挤压试验 | 下胫腓联合 | 小腿中段挤压诱发踝前疼痛 |
| 直腿抬高试验 | 神经根／腘绳肌 | 一定角度内出现放射性痛 |
| 骨盆挤压分离试验 | 骨盆环 | 挤压或分离时骨盆环处疼痛 |
| 跖筋膜牵拉试验 | 跖筋膜 | 被动背伸足趾与踝诱发足底痛 |
| Thompson 试验 | 跟腱 | 挤压小腿肚无跖屈 |

读这张表要守三条规矩。第一，**双侧对比是试验的一部分**，不是补充；单侧做出来的「前移增大」没有分母。第二，**单项阳性只是概率移动**，踝部单元把前抽屉、内翻应力与双侧对比并写，只有多项同向才把结论推到「较可能」。第三，**阴性也要会读**：第三腰椎横突综合征「直腿抬高试验多为阴性或仅轻度受限，无神经根支配区的感觉、肌力与腱反射异常」——这个阴性排除的是根性受累，不是排除疼痛。

反过来，试验阳性也不等于诊断成立。踝部单元把骨性压痛、不能负重四步与拍片指征并写，用意是**用试验决定要不要拍片，而不是用试验代替拍片**。

## 四、危险信号是一票否决

以下任一条成立，诊查即到此为止，转影像、转诊，不再用手法试探：

- **全身**：发热寒战、消瘦、夜间静息痛（腰椎结核、腰大肌脓肿、转移瘤须列入鉴别）；面色苍白、口唇发绀、冷汗、脉搏细数、血压下降、尿量减少。
- **神经**：进行性麻木无力、腱反射改变、大小便功能异常。
- **血管**：足背动脉搏动减弱、足趾发凉、皮肤颜色改变。
- **软组织张力**：皮肤绷紧发亮、张力性水疱、被动牵拉痛。
- **骨盆**：疑有骨盆骨折者禁站立、行走、坐起或自行翻身，禁以手法反复按压骨盆环寻找痛点，禁在未固定骨盆的情况下搬动。
- **踝部**：内踝或外踝后缘与尖部骨性压痛、第五跖骨基底部或足舟骨压痛、伤后不能负重行走四步，应行 X 线检查。

这张表不是「注意事项」，是诊查流程的分支点。它一旦成立，后面的压痛定位、活动度、肌力都不再改变处置方向。这也是本章为什么把并发症放在第一节之后而不是文末附录：它不是诊查的后续，是诊查的第一个分叉。

教材把并发症单列一段，课程稿把它提到与体征同一层，两者的差别在次序而不在内容。次序的差别很实际：先查体征、后想并发症，人会顺着「像什么病」往下走；先过红旗，人会被拦在「不能做什么」之前。

## 五、六行记录

一次筋伤诊查的记录，六行写完，缺一行就是没查：

| 行 | 填什么 |
|---|---|
| 部位与侧别 | 具体到骨性标志与相对位置，不用「腰部」「踝部」了事 |
| 病程与分期 | 伤后时间、急性／缓解／恢复，与第 2 章分期口径一致 |
| 压痛 | 点、深度（浅／深）、诱发动作、有无放射及放射范围 |
| 活动度 | 主动、被动、健侧对比，受限方向优先写 |
| 神经血管 | 肌力分级、感觉、腱反射、末梢动脉搏动 |
| 试验与影像 | 做了哪几项、结果、是否已拍片及所见 |

判断一份记录合不合格，只有一个标准：第二个人拿着它，能不能把压痛按到同一个点上。「腰骶部压痛」不合格；「L3 横突尖端，深压约一横指，向臀后放射至大腿后侧、不过膝」合格——这一句里包含位置、深度、放射范围，而放射不过膝正是它与腰椎间盘突出症的分界。

这六行还有一个用处：它们是随访的比较基线。没有基线的「好多了」，在复诊时无法与前次对照；有了这六行，第二次只需在同一体位、同一标志上重测一遍。

## 代价与边界

1. **没有图。** 体表标志、试验体位、压痛点的解剖位置全靠文字描述，本章只能给「名称 + 相对位置」；看图须对教材，本课程与骨伤系其他课一样没有插图。
2. **没有阈值。** 压痛几公斤、活动度差几度算异常、肌力掉一级算不算阳性——课程单元与教材正文都只给类别与要点，本章不给数值。给了就是编。
3. **没有信度数据。** 压痛定位的观察者间一致性、量角器的测量误差、周径测量的重复性，本章只说「要报告」，不给系数。
4. **个案不进入正文。** 文中的例子是合成的说明性情形，不含可定位的机构、人名与时间地点。
5. **只覆盖五个病种单元。** 颈、肩、腰背、膝的系统诊查在第 5～8 章；本章借这五个单元说明「怎么取证据」，不代替各部位的诊查要点。
6. **「摸」的手感无法传递。** 什么算条索、什么算痉挛、多深算深压痛，文字只能描边界，不能给手感；这一层只能靠在带教下反复对照健侧获得。
