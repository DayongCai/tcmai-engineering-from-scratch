# 分期的尺子是肿、痛、活动度，不是日历

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 初期怕伤正，中期怕偏颇，后期怕留邪
- 后期仍有瘀者
- 初期而素体亏虚者
- 糖尿病患者
- 筋骨同伤者
- 以期为框架定治则的大方向，以证为落点定当下的方药

## 边界

- **时间窗是默认值，不是标准值。** 1～2 周、3～6 周、六周以后三个数字，用于给初学者一个起点；凡遇年老、体虚、糖尿病、失治日久、合并骨折者，一律按证调整，并在记录中写明调整理由。
- **只到方名，不到剂量。** 文中方名用于说明治则与分期的对应关系，不构成处方；剂量、煎服法、加减法与疗程不在本章范围。有出血倾向、正在使用抗凝药物或有活动性出血者，峻破之品尤须审慎。
- **不给疗效数据。** 本章不含任何研究数据、治愈率或疗程结论；「多数缓解」是方向性表述，不是统计结果。
- 本章为教学材料，不构成诊疗建议、诊断或治疗指导。文中治则、方名与时间窗只用于说明分期的逻辑，不构成用药依据。
