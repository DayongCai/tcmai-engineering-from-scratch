# 分期的尺子是肿、痛、活动度，不是日历 · 提示词

## 用途

给「分期的尺子是肿、痛、活动度，不是日历」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「五类病理：一条线由轻到重、由实到虚 → 由瘀到虚：一条主线 → 三期：默认时间窗与三条禁令 → 期不等于证」这条链。

## 边界

本章为教学材料，不构成诊疗建议、诊断或治疗指导。文中治则、方名与时间窗只用于说明分期的逻辑，不构成用药依据；具体操作以现行规范与所在机构制度为准。
