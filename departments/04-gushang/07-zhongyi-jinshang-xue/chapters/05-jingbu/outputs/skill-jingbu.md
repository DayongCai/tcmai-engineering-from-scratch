# 颈部的手法，先学会不做

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 反复落枕常是颈椎病的早期表现
- 神经根型颈椎病急性发作
- ，有明确外伤史且疼痛剧烈
- ，见儿童或青少年歪颈伴发热、咽痛，须行张口位 X 线或 CT
- ，见持续夜间痛、进行性加重、发热消瘦
- 椎动脉路径

## 边界

- **节号不补。** 教材颈部内容编在「第四章·躯干部筋伤」项下，本次只到章名，故按章引用，不补节号；这不是省略，是不编。
- **不写扳法细节。** 定位旋转扳法的操作步骤、角度与力度不在本章范围；本章只给禁忌、筛选与替代路径。
- **不给牵引参数。** 重量、角度、时间依个体与机构规范，本章不设统一数值。
- 本章为教学材料，不构成医学意见、诊断或治疗指导。颈部手法属高风险操作，须由具备执业资质的人员在排除禁忌、完成必要影像评估后依现行规范实施，具体参数以所在机构制度为准。凡见步态不稳、踩棉感、进行性麻木无力、二便功能障碍、眩晕伴复视或构音障碍者，立即停止一切手法并转诊。
