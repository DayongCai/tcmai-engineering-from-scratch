# 颈部的手法，先学会不做 · 提示词

## 用途

给「颈部的手法，先学会不做」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「落枕：一个症状名，不是诊断终点 → 扭挫伤：先证明没有骨折 → 颈椎病六型：分型的用处是禁忌 → 椎动脉与脊髓：两条路径，一条红线」这条链。

## 边界

本章为教学材料，不构成医学意见、诊断或治疗指导。颈部手法属高风险操作，须由具备执业资质的人员在排除禁忌、完成必要影像评估后依现行规范实施，具体参数以所在机构制度为准。凡见步态不稳、踩棉感、进行性麻木无力、二便功能障碍、眩晕伴复视或构音障碍者，立即停止一切手法并转诊；具体操作以现行规范与所在机构制度为准。
