# 小部位靠结构定位，不靠痛点定位

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 同一个病，可以按部位写，也可以按机制写
- 第一问，结构
- 第二问，加载
- 第三问，通道还是炎症
- 「麻」与「痛」的分野，大体就是通道与炎症的分野
- 分布本身就是一张地图，边缘比中心更有信息量

## 边界

- **没有图，也没有阈值。** 体表标志、试验体位全靠文字；超声看腱鞘厚度与神经横截面积、MRI 看滑膜与腱鞘，本章不写阈值，也不写分级。
- **不写按压手法与力度。** 腱鞘囊肿的按压、抽吸、切除三类处理各有适应证与复发问题，本章只作并列陈述，不写步骤、不承诺治愈——按压落在患者身上不可逆（皮下出血、疼痛加剧、囊壁再次闭合）。
- **电生理与手术指征不在本章。** 出现大鱼际萎缩、进行性感觉丧失、规范保守治疗无效，转诊；本章的责任是识别与转送，不是分级与决策。
- 本章为教学材料，不构成医学意见、诊断或治疗建议。肘、腕、手部的麻木、无力、肿物与活动受限，须由具备执业资质的人员依现行规范检查与处置。
