# 小部位靠结构定位，不靠痛点定位 · 提示词

## 用途

给「小部位靠结构定位，不靠痛点定位」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「把病名背后那根结构提到前面 → 三问：结构、加载、通道还是炎症 → 麻与木：性质本身有定位价值 → 最容易误判的那一个」这条链。

## 边界

本章为教学材料，不构成医学意见、诊断或治疗建议。肘、腕、手部的麻木、无力、肿物与活动受限，须由具备执业资质的人员依现行规范检查与处置；具体操作以现行规范与所在机构制度为准。
