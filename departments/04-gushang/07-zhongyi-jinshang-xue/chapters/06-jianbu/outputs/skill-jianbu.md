# 抬不起来的肩，先分关节囊还是肌腱

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 力量掉了没有
- 主动与被动活动均受限，且外旋受限出现最早、最明显
- 退变性部分撕裂以保守为主
- 急性全层撕裂、外伤后明显无力、年轻体力劳动者、巨大撕裂，转诊评估手术
- 肩峰下撞击综合征
- 撞击是「空间不够」，肩袖损伤是「肌腱坏了」

## 边界

- **「自限」这个说法不用。** 流行的说法是病程一至两年自限、不必积极治疗。本章不采此说：疼痛期过度锻炼会加重，僵硬期不干预会遗留外旋受限，糖尿病患者的病程更长。写法上写「多数可改善，部分遗留活动受限，需分期处理」。
- **撕裂的肌腱不做深部重手法。** 手法只用于周围软组织与关节囊，主力是渐进负荷训练；这条界线比手法技巧更重要。
- **疼痛弧与撞击试验只作筛查。** 这些体征敏感而不特异，阳性提示进一步查，阴性不能排除，确诊交给影像与力量评估。
- 本章为教学材料，不构成医学意见、诊断或治疗指导。肩部手法、固定与练功方案须由具备执业资质的人员依现行规范制定，具体参数以所在机构制度为准。急性外伤后明显无力、巨大撕裂、复位后仍不能主动抬臂者，应转诊评估，不以手法与练功替代。
