# 抬不起来的肩，先分关节囊还是肌腱 · 提示词

## 用途

给「抬不起来的肩，先分关节囊还是肌腱」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「四种病，一条由轻到重的排列 → 肩周炎：三期与三证 → 肩袖：一条肌腱的三种命运 → 撞击：一个间隙的狭窄；三者两条线分岔」这条链。

   - 主动与被动活动均受限，且外旋受限出现最早、最明显
   - 退变性部分撕裂以保守为主

   - 肩峰下撞击综合征

   - **疼痛弧与撞击试验只作筛查。** 这些体征敏感而不特异，阳性提示进一步查，阴性不能排除，确诊交给影像与力量评估。

## 边界

本章为教学材料，不构成医学意见、诊断或治疗指导。肩部手法、固定与练功方案须由具备执业资质的人员依现行规范制定，具体参数以所在机构制度为准。急性外伤后明显无力、巨大撕裂、复位后仍不能主动抬臂者，应转诊评估，不以手法与练功替代；具体操作以现行规范与所在机构制度为准。
