# 颈椎不是一段，是两段，风险也在两段之间分

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 上颈段（枕—寰—枢）
- 一次误差的后果是中枢性的
- 曲度是趋势指标，不是靶点
- 把曲度当疗效指标，等于用一个不会动的尺子量一次会动的变化
- 节段活动才是可操作的
- 评估的价值不在于找到问题，而在于把「可以做」与「不可以做」分开

## 边界

- **本章不写任何操作参数。** 上颈段的幅度上限、下颈段整复的角度与速度、牵引的重量与时间，一律不写；这些必须由当场的评估与机构规范决定。
- **分段的界线在临床上并不总是清晰。** C2/C3 之间的过渡节段、退变导致的节段融合，都会让「上段/下段」的划分变得模糊；此时按更保守的一段处理。
- **不宣称手法能治愈颈椎病。** 手法改善的是症状与活动度，不改变椎间盘突出的存在、不逆转骨质增生、不修复脊髓压迫。
- 本章为教学材料，不构成诊断、治疗或急救建议。文中分段原则与禁忌清单只用于建立判断框架。
