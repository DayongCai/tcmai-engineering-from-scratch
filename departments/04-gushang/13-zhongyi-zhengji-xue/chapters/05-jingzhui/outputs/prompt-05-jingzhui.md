# 颈椎整脊 · 提示词

## 用途

给「颈椎整脊」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「整脊源流与理论 → 脊柱解剖与生物力学 → 影像评估与适应证 → 整脊手法体系 → 颈椎整脊 → 胸腰椎整脊 → 骨盆与下肢力线 → 风险、禁忌与疗效评价」这条链。

## 提示词

```
我在学《中医整脊学》第 5 章「颈椎整脊」，本章 4 单元 / 11,695 汉字，
取自教材第 派生#5 章。

请按以下顺序带我走：
1. 先给本章要回答的问题，并说明它为什么不能直接套用上一章；
2. 再给三辨（脊柱力学／手法整复／评估与风险）在本章的实测分布，指出主导那一辨；
3. 然后按单元逐条读出「判据」——每条只写类别与要点，不给操作参数；
4. 最后给出三条边界：哪些内容只能写到类别、哪些必须由具备资质的人员作出、哪些情况按记录写：部位、病程、体征与影像、分型/分级、处理、随访报告。

要求：不编造教材没有的数字；引文写到《书名·篇名》级并标注是否本章原文篇名；
不确定的地方直接说「教材未展开」。
```

## 边界

本提示词用于教学准备，不构成诊疗或护理意见；具体操作以现行规范与所在机构制度为准。
