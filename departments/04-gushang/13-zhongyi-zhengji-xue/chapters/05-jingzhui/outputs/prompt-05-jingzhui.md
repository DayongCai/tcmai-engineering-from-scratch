# 颈椎不是一段，是两段，风险也在两段之间分 · 提示词

## 用途

给「颈椎不是一段，是两段，风险也在两段之间分」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「两套解剖，两套风险 → 序列看趋势，节段看活动 → 五类必须挡在门外的颈椎 → 层次的选择：上段低幅，下段择节」这条链。

## 提示词

```
我在学《中医整脊学》第 5 章「颈椎不是一段，是两段，风险也在两段之间分」，本章 6 节 / 3,071 汉字，习题 7 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 上颈段（枕—寰—枢）
   - 一次误差的后果是中枢性的
   - 曲度是趋势指标，不是靶点
   - 把曲度当疗效指标，等于用一个不会动的尺子量一次会动的变化
   - 节段活动才是可操作的
   - 评估的价值不在于找到问题，而在于把「可以做」与「不可以做」分开
4. 本章自陈的边界（不得越过）：
   - **本章不写任何操作参数。** 上颈段的幅度上限、下颈段整复的角度与速度、牵引的重量与时间，一律不写；这些必须由当场的评估与机构规范决定。
   - **分段的界线在临床上并不总是清晰。** C2/C3 之间的过渡节段、退变导致的节段融合，都会让「上段/下段」的划分变得模糊；此时按更保守的一段处理。
   - **不宣称手法能治愈颈椎病。** 手法改善的是症状与活动度，不改变椎间盘突出的存在、不逆转骨质增生、不修复脊髓压迫。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，不构成诊断、治疗或急救建议。文中分段原则与禁忌清单只用于建立判断框架；具体操作以现行规范与所在机构制度为准。
