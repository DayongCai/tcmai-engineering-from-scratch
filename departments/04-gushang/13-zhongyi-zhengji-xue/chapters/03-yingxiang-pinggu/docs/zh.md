# 第 3 章 · 影像的用法是排除禁忌，不是找病因

> **MOTTO:** 「必素知其体相，识其部位。」——《医宗金鉴·正骨心法要旨·手法总论》
>
> **PROBLEM:** 一张腰椎 MRI 报告上写着「L4/5 椎间盘突出，硬膜囊受压」，患者拿着它进门，认定自己「压到神经了」；而同一位患者，三年前的片子写着同样的话，那时他没有任何症状。这不是罕见情形，是常态：影像上的退变与突出在无症状人群中检出率很高，且随年龄上升。**如果影像是为了「找病因」，它给出的答案大半是错的；如果影像是为了「排除禁忌」，它给出的答案几乎总是对的。** 用错方向，影像就从安全工具变成了说服工具。

**双根因定位:** 环境逼迫（门诊时间短，片子是唯一能在几分钟内被双方共同看到的客观物；患者要一个「看得见的解释」，医生要一个「可交代的依据」，影像恰好同时满足这两点——于是它被推到了它不该在的位置） + 知识积累（正侧位、动力位、张口位各有各的适应证，CT 与 MRI 的分工明确，红旗清单可以背下来——这些合起来，才使「什么时候该拍、拍什么、拍完怎么看」成为可教的流程，而不是靠经验碰）

## 一、四种影像，各回答一个问题

影像不是越贵越好，是越对路越好。四种常用检查各有一个主问题：

| 检查 | 主要回答 | 不擅长的 |
|---|---|---|
| X 线 | 序列、曲度、椎体高度、骨赘、椎间隙、骨质大体情况 | 椎间盘、脊髓、神经根、早期骨破坏 |
| CT | 骨性细节：骨折线、椎弓根、钩椎关节、骨性椎管、钙化 | 软组织、脊髓信号、早期骨髓水肿 |
| MRI | 椎间盘、脊髓与神经根、椎管、感染与肿瘤、软组织 | 骨性细微结构、钙化、金属植入物附近 |
| 骨密度 | 骨量，用于评估手法与负荷的耐受 | 局部结构、病因 |

分工的临床含义很直接：**怀疑骨的问题用 X 线与 CT，怀疑软组织、神经与脊髓的问题用 MRI。** 想一次把两件事都看清，通常意味着两样都不够清楚。

有一项检查需要单独提醒：颈部血管超声。它在评估椎动脉的形态与血流上有价值，但把它当作「颈部手法前的常规筛查」，证据并不支持——转颈时血流的变化在无症状人群中同样可以出现，检查结果与是否会发生血管事件之间没有稳定的对应。**一项检查如果既不能排除、也不能预测，就不该被写成「做了就安全」。**

## 二、两个最常被省掉的体位

标准正侧位是基础，但有两类体位在整脊的语境里格外要紧，也格外容易被省。

**第一是动力位（过屈过伸位）。** 它回答的是「节段在负荷下会不会移动过多」。静态片上看不出不稳，动力位上可能出现椎体间的异常位移或成角。对计划做旋转、牵拉类操作的患者，这一项比正侧位更能说明问题。省掉它的理由通常是「怕麻烦」「怕多拍」，代价是把一个可以在片子上看到的风险，留到手上才发现。

**第二是张口位。** 它回答的是「寰枢关节是否对称、齿状突与侧块的关系是否正常」。上颈段是整条脊柱里旋转负荷最集中的地方，也是最不适合「先做了再看反应」的地方。儿童歪颈伴发热咽痛、类风湿患者出现颈痛、Down 综合征或软骨发育不全的患者，这一张片子不能省。

顺带说一句辐射：X 线与 CT 有电离辐射，不该作为「查一查放心」的常规项目；MRI 没有电离辐射，但有金属植入物、心脏起搏器、幽闭恐惧等禁忌。选择检查时，收益与代价要一起算，不能只算一边。

## 三、红旗：一张不许跳过的清单

红旗征的意义不是「诊断某个病」，是「在动手之前，把不该动手的情形挑出来」。以下几条，问诊时逐条过一遍，成本不到两分钟：

- **年龄与起病**：五十岁以上新发疼痛、无明确诱因；或任何年龄的夜间静息痛、痛醒。
- **全身症状**：发热、盗汗、不明原因体重下降、乏力。
- **肿瘤史**：任何恶性肿瘤病史，尤其乳腺、肺、前列腺、甲状腺、肾。
- **外伤**：跌倒、车祸、高处坠落，即使当时「只是扭了一下」。
- **神经症状的进展**：进行性麻木、无力、行走不稳、精细动作变差。
- **马尾相关**：鞍区麻木、大小便功能障碍、双下肢无力。
- **感染风险**：静脉用药史、免疫抑制、近期脊柱手术或穿刺、糖尿病控制不佳。
- **骨的质量**：高龄、长期糖皮质激素、已知骨质疏松或脆性骨折史。
- **先天与风湿**：Down 综合征、软骨发育不全、类风湿关节炎、强直性脊柱炎。

这张清单的共同点：**每一条指向的都不是「手法做得好不好」，而是「该不该做」。** 命中任何一条，处置不是「手法轻一点」，是「先完成评估，暂时不进入」。

需要说明的是，红旗的敏感度高、特异度低——绝大多数命中红旗的人并没有严重疾病。这不是清单的缺陷，是筛查的本性：它宁可多转一次诊，也不漏一个。把「转了没事」当成「清单没用」，是把筛查的逻辑搞反了。

## 四、片子与人对不上的三种情形

**第一种，片子有问题，人没症状。** 椎间盘膨出、突出、椎管狭窄、小关节退变，在无症状人群中都不少见，且随年龄增长而增多。看到片子上的突出，就认定它是疼痛的来源，是整脊最常见的归因错误。正确的问法是：这个影像发现，能不能解释患者此刻的症状分布、诱发方式与体征？

**第二种，人有症状，片子正常。** 影像正常不能排除机械性疼痛，也不能排除中枢敏化、肌筋膜问题与心理社会因素。反过来，也不能因为片子正常就断定「没事，只是筋的问题」——功能性的问题同样需要评估与处理。

**第三种，多节段都有问题，靶点选哪个。** 三个节段都突出，都狭窄，症状却只在一侧一条腿上。此时选靶靠的不是影像的严重程度，是体征：皮节分布、肌力、反射、神经张力试验、症状的诱发位相。诊断性阻滞在多学科条件下可以提供更强的定位信息。**影像给范围，体征给靶点。**

这三种情形合起来说明一件事：影像在整脊里的角色是「排除」与「划范围」，不是「定位病因」。把它当定位工具，会系统性地高估结构因素、低估功能因素。

## 五、准入四条件与「不进入」的写法

综合前面几节，本课把进入手法处理的条件写成四条，四条同时满足才进入：

1. **诊断落在机械性/功能性范围**：症状与负荷、体位、活动相关，有可复现的诱发与缓解方式。
2. **红旗全部阴性**：第三节清单逐条过完，无命中，或有命中但已由相应专科排除。
3. **影像与体征一致**：影像所见能解释症状分布与体征，或至少不矛盾。
4. **患者条件允许**：能配合、能沟通、知情同意，无出血倾向、无局部皮肤与软组织禁忌。

四条里任何一条不满足，写法不是「手法轻一点试试」，而是明确的「本次不进入，转诊/改路径」。「不进入」是一个需要写进病历的判断，不是一次含糊的推脱——它要写明是哪一条不满足、建议去哪里、什么时候复查。

这一节也是本课与「先做做看，不行再说」这一习惯的分界线。试探性治疗在骨折复位里有它的位置，在脊柱手法里没有：脊柱的试错成本是不对称的，做对了收益是几天的松快，做错了可能是一辈子的功能缺失。

## 六、影像不能替代的三件事

**第一件，触诊与功能测试。** 影像看的是形态，手法要处理的是运动。节段的活动度、终末感、肌肉张力、症状的诱发位相，都只能在人身上测。片子再清楚，也测不出「这一节转到某个角度时痛」。

**第二件，时间。** 一张三个月前的片子，不能代表今天的状态；一次外伤后的新症状，需要新的影像。影像有时效，超过时效的片子只能作参考，不能作依据。

**第三件，患者的叙述。** 什么时候疼、什么姿势疼、疼到哪里、有没有变化——这些信息在片子上没有，在问诊里有。影像能确认或否定一个假设，但它产生不了假设。**假设来自病史，影像只做裁判。**

把这三件事放在最后，是为了给整章定一个位置：影像很重要，但它是配角。整脊的主角始终是「这个人现在的运动与负荷」，影像只是确保这个主角没有隐藏的结构性危险。

## 代价与边界

- **本章不写影像判读的具体标准。** 各项测量的正常值、不稳的判定阈值、突出的分型，都需要影像科与专科医师的判断，本章只给分工与流程。
- **红旗清单不完整，也不能替代系统问诊。** 它是一张最低限度的筛网，不是全部；不同年龄、不同基础病的患者，需要补充相应的筛查项。
- **不做「影像正常即安全」的推论。** 影像正常只排除了一部分结构病变，不排除血管、感染早期、功能性等问题。
- **血管超声的局限要说清楚。** 它不构成颈部操作的安全保证，本章明确不把它写成术前常规。
- **不替代专业判断。** 凡影像提示破坏、感染、不稳、脊髓受压者，一律先由相应专科处理。
