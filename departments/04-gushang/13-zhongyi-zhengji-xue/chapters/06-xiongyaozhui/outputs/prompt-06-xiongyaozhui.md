# 胸腰段的手法失误，多半不是瘫，是折 · 提示词

## 用途

给「胸腰段的手法失误，多半不是瘫，是折」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「胸椎：被胸廓夹住的一段 → 腰椎：关节突决定了它本来就不该转那么多 → 非特异性腰痛：手法在证据里的位置 → 四条必须停的红线」这条链。

## 边界

本章为教学材料，不构成诊断、治疗或急救建议。文中分段原则与红线清单只用于建立判断框架；具体操作以现行规范与所在机构制度为准。
