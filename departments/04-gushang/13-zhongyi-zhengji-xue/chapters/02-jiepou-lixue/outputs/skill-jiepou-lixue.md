# 脊柱的稳定不是骨头撑住的，是三种组织在互相欠账

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 风险不是来自力量大小，是来自力线与已经不完整的结构之间的关系
- 手法还的是利息，训练还的是本金
- 这个替换很关键
- 但这类情形是少数，而且都有明确的排除条件
- 曲度是结果，不是原因
- 伪精确比模糊更危险，因为它让人以为可以照做

## 边界

- **本章不写手法参数，也不写诊断阈值。** 三柱的具体判定、中立区的量化、曲度的正常区间，都需要影像与专科评估，本章只给概念与方向。
- **生物力学的解释力有上限。** 它解释力学，不解释疼痛的全部——疼痛有外周敏化、中枢敏化、心理与社会因素，把这些都归到力学上是另一种还原论。
- **耦合运动的知识不可外推。** 体外数据与活体差异大，本章明确不以其作为操作方向的依据。
- 本章为教学材料，不构成诊断、治疗或急救建议。文中解剖与生物力学内容用于建立判断框架，不构成任何操作处方。
