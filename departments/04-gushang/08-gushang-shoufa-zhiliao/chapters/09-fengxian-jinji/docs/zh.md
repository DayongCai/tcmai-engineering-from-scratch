# 第 9 章 · 手法是主动加荷：先排危险，再谈手法

> **MOTTO:** 「元气素弱者，设手法再误，则万难挽回矣。此所以尤当审慎者也。」——《医宗金鉴·正骨心法要旨·手法总论》
>
> **PROBLEM:** 手法被古人列为正骨之首务，可同一段话里又写着「手法亦不可乱施」「设手法再误，则万难挽回矣」。禁忌于是常被读成一张清单，而它其实是三层：绝对禁忌九类、相对禁忌五类、一票否决红旗八条。三层的处置完全不同——一层停手、一层改方案、一层转诊、一层先诊断。混成一张表，就会出现两种相反的错：把相对禁忌当绝对，丢掉有效手段；把红旗当禁忌，只写「不宜手法」而不转诊。

**双根因定位:** 环境逼迫（一次手法的风险在几十秒内兑现，出事之后能做的只有补救，所以判断必须全部前置到动手之前） + 知识积累（把「尤当审慎」这个态度拆成有先后的筛子：红旗在前、绝对禁忌次之、相对禁忌再次——顺序由后果的不可逆程度与判错的代价共同决定，不由经验多少决定）

## 一、三层，三种处置

**绝对禁忌**：做了就必然或极可能造成不可逆损害，没有「调小一点、换个姿势」可以挽救。

| 类别 | 具体情形 | 误做的后果 |
|---|---|---|
| 骨折与脱位未处理 | 疑有或已证实的骨折端、未复位脱位、内固定不稳 | 移位、骨不连、内固定失效 |
| 感染 | 化脓性骨髓炎、化脓性关节炎、脊柱结核、椎间隙感染 | 感染扩散、脓毒症 |
| 肿瘤 | 原发骨肿瘤、骨转移、破坏性病变 | 病理骨折、脊髓压迫 |
| 脊髓与马尾受压 | 脊髓型颈椎病、胸椎管狭窄、马尾综合征 | 瘫痪、二便不可逆损害 |
| 进行性神经损害 | 肌力逐次下降、垂足、感觉平面上升 | 神经功能永久缺失 |
| 血管病变 | 动脉瘤、动脉闭塞、深静脉血栓、血管术后 | 破裂、栓塞、血栓脱落 |
| 出血倾向 | 凝血功能障碍、血小板减少、治疗量抗凝 | 深部血肿、硬膜外血肿 |
| 严重骨质疏松 | 长期激素、影像示骨小梁稀疏 | 医源性骨折、椎体压缩 |
| 妊娠 | 腰骶部与腹部手法、强力旋转类 | 流产、早产 |

这九类的共同点是：只需判断「有没有」，不需判断「程度」。凡需要掂量着来的，都不在这一层。

**相对禁忌**：风险真实存在，但可被条件改变。它不是「不能做」，是「不能照原方案做」。

| 情形 | 要改哪一格 | 改完还能做什么 |
|---|---|---|
| 急性期肿胀剧痛 | 时机 | 只做远端轻柔理筋与体位摆放，患处不动 |
| 高龄、体质虚弱、长期激素 | 力度与时长 | 以轻柔软组织手法为主，整复类不做 |
| 高血压未控制、心律失常 | 体位与强度 | 避免头低位与憋气发力，缩短单次时长 |
| 糖尿病 | 皮肤与力度 | 避开易损皮肤，力度减轻，事后查皮肤 |
| 月经期、饮酒后、空腹、疲劳 | 部位与时机 | 腰骶与下腹不做强刺激；改期 |

**一票否决红旗**不是「手法禁忌」，而是「必须先诊断」。禁忌问的是「我能不能做」，红旗问的是「我知不知道我在做什么」。

## 二、顺序：红旗在前，因为它的漏诊代价不可逆

「尤当审慎」是态度，态度不能执行。要执行，必须变成顺序：**红旗 → 绝对禁忌 → 相对禁忌 → 可做。**

顺序由两个量决定：后果的不可逆程度，与判错的代价。

**红旗放最前**，因为红旗对应的病（肿瘤、感染、马尾受压、血管损伤）漏诊的代价不可逆，而筛出的成本只是一句问话与一次转诊。这是「低概率、高代价」的情形，其中敏感度必须优先于特异度：宁可把十个不是肿瘤的人转去拍片，也不能漏掉一个——假阳性花的是钱，假阴性丢的是功能。

**绝对禁忌放第二**，因为它只需判断有没有，不需判断程度；凡需要「掂量着来」的，都归相对禁忌。

**相对禁忌放第三**，因为它要求把方案拆开逐格改。

这张表要背的不是病名，是**问法**：

| 红旗 | 最快能问出它的那句话 | 指向 | 当次处置 |
|---|---|---|---|
| 夜间静息痛、体重下降、肿瘤史 | 「晚上不动时疼不疼？最近瘦了吗？」 | 骨肿瘤、转移瘤 | 不做手法，转影像与专科 |
| 发热、局部红肿热、脊柱叩击痛 | 「有没有发烧？最近打过针吗？」 | 感染 | 不做手法，急诊或专科 |
| 鞍区麻木、二便无力或失禁 | 「大小便有没有变化？骑车麻不麻？」 | 马尾综合征 | 立即急诊，不等待 |
| 精细动作变差、走路踩棉感 | 「扣扣子、拿筷子还行吗？走路发飘吗？」 | 脊髓型颈椎病 | 不做颈部手法，转专科 |
| 眩晕、复视、构音不清、猝倒 | 「转头时晕不晕？看东西重影吗？」 | 椎动脉供血不足 | 不做颈部旋转类，转专科 |
| 远端苍白发凉、脉搏摸不到 | 「手（脚）比另一边凉吗？」 | 血管损伤、栓塞 | 立即急诊 |
| 进行性剧痛、被动牵拉痛 | 「越来越疼，还是好一点了？」 | 筋膜间隔区综合征 | 立即急诊，禁热敷禁按摩 |
| 外伤后畸形、异常活动 | 「受伤时听见响了吗？现在能自己动吗？」 | 骨折 | 制动、影像，不做手法 |

红旗的价值全在「在患者自述之前问出来」。患者不会主动说「我瘦了」「我骑车麻」——这两件事在他看来与腰痛无关。

## 三、相对禁忌的用法：逐格改，不整体降级

相对禁忌最容易犯的错，是**整体降级**：因为患者高龄，把所有手法都做轻。这个做法看似安全，实际把有效手段一起丢掉了。

正确的做法是只改与风险相关的那一格。高龄改力度不改部位；皮肤病改部位不改力度；抗凝改深度不改时长；疲劳改时机不改方案。一格一格地改，方案仍然成立；整体降级之后，方案已经不成其为方案——它变成了一次「什么都没做」的接触，而患者付了时间与费用。

这一条也是「相对」二字的真正含义：风险可以被条件改变，前提是你知道是哪个条件。

## 四、停手信号：手感先于仪器

停机信号往往先于任何仪器读数出现，且只在手下与眼前。

**组织突然变硬。** 本来在松的组织忽然顶住，说明保护性收缩启动或已到达骨性阻挡，此时加力只会加重。
**患者一声抽气、屏气、出汗。** 痛觉已越过阈值，继续即进入「越痛越重」的正反馈。
**指下脉搏变弱或消失。** 压迫或牵拉影响了血流，立即松手、改体位、复测。
**远端皮温下降、颜色变白或发绀。** 血管受累，按急症处理。
**患者主诉沿肢体放电、麻木。** 神经受牵拉，停止、摆中立位、复查感觉与肌力。

这五条不需要设备，也不需要经验丰富到「有手感」——它们是可观察的。把它们写进操作规范，比写「注意力度」有用。

## 五、四类意外：共用一套流程

意外不是禁忌，是「做了以后发生的事」，因此有流程。四类常见意外的现场处置共用同一模板：**识别 → 立即停止 → 现场处置 → 不改做什么 → 记录 → 转介 → 告知。** 最容易被忽略、最常出事的是「不改做什么」这一格。

**晕厥。** 面色苍白、出汗、眼前发黑、恶心、脉搏细速，多在首次治疗、空腹、紧张、疼痛刺激或体位骤变时发生。立即停止，平卧抬腿，松衣领、通风，测脉搏血压。**不改做什么**：不继续操作、不喂水、不扶起站立、不掐按颈部。意识不清、抽搐、脉搏摸不到或数分钟不缓解者呼叫急救。

**骨折。** 施术中突闻或触到闷响、剧痛、迅速肿胀、异常活动或畸形；老年人骨质疏松者风险最高，肋骨、椎体、肱骨近端与桡骨远端最常见。立即停止，制动患处。**不改做什么**：不试图把医源性骨折用手法「复回去」、不揉、不热敷、不贴膏药。

**神经血管损伤。** 神经侧见某一支配区麻木、刺痛、肌力下降（腕下垂、足下垂、拇指对掌无力），多在强力旋转、牵拉或长时间压迫后出现；血管侧见远端苍白发凉、脉搏减弱或消失、被动牵拉痛。立即停止，摆中立位，松开束缚，复测双侧脉搏与感觉肌力并记录。**不改做什么**：不热敷、不按摩、不抬高患肢（动脉供血不足时抬高加重缺血）、不观察等待。

**皮肤损伤。** 局部发红、灼热、表皮剥脱、瘀斑、水疱，多见于皮肤薄、糖尿病、长期激素、消瘦者，以及摩擦时间过长、介质不足、骨突处直接按压时。立即停止局部操作，清洁、保护。**不改做什么**：不在破损处继续做、不涂刺激性外用药、不覆盖不透气敷料。

## 六、告知：把「可能发生」说在发生之前

告知不是免责声明，它有三项实质内容。

**其一，说清预期反应与异常反应的界线。** 治疗后一两日内的酸胀、轻度疲惫属常见反应；剧痛、麻木加重、发热、二便变化不属于，须立即联系。界线不说，患者会把异常当正常。

**其二，说清替代方案与不做的后果。** 休息、药物、练功各有其位，把「不做也可以」说出来，选择才是真的选择。

**其三，说清复诊条件。** 直接列出：进行性麻木、肌力下降、夜间痛加重、发热。清单比叮嘱有效，因为它能被记住，也能被转述给家属。

需要明确一句：告知改变的是决策质量，不是责任归属。签了字不等于免责；把「已告知」当成风险的终点，是这一章最不该出现的理解。

## 七、代价与边界

- **不给发生率。** 椎动脉损伤、硬膜外血肿、医源性骨折各自的发生率，在不同人群、手法与操作者之间差着一个量级以上，本章一个数都不给。代价明确：读者拿到的是「能不能做」，不是「值不值得做」。
- **不给分级阈值。** 「严重骨质疏松」「进行性」都是定性判断，落到具体影像与体征属专科范围。
- **三层筛子只回答「该不该做」。** 它不回答「做了有多少收益」，也不替代患者的意愿与整体状况。
- **本章的流程不构成急救培训。** 现场处置的每一步都需要实际操作训练；读过流程不等于会做。
- **不替代专业判断。** 凡红旗成立、绝对禁忌存在、意外发生，一律停止手法，按记录写：部位、病程、体征与影像、分型、处理、随访与转介。

> **免责声明：** 本章为教学材料，不构成诊断、治疗或急救指导。文中禁忌分级、红旗问法与意外流程，只用于建立判断框架；一切检查与处置须由具备资质的执业人员依现行规范、临床路径与所在机构制度作出。出现意识改变、进行性神经症状、远端缺血或二便异常者，立即呼叫急救或转诊。
