# 腰腿痛有一半时间在做鉴别，鉴别没做完就不动手

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 这张表要背的不是病名，是「压痛在哪里、有没有放射」
- 这条「即刻缓解」是它最好的验证
- 松解与点按，不做整复
- 「只松不整」这四个字，把这一类从「腰痛都扳一下」的习惯里分出来
- 腰肌劳损的辨证三证要一并记
- 腰源（神经根性）

## 边界

- **本章不写手法参数。** 整复的角度与幅度、松解的时长与力度、疗程与频次，一律不写；凡教材没有给出的数值，本章不补。
- **六种病的划分是临床常用分类，不是全部。** 强直性脊柱炎、骶髂关节紊乱、髋关节来源的牵涉痛、内脏牵涉痛都在框架之外；遇到「不像」的腰痛，另立排查，不硬套。
- **「即刻缓解」是验证，不是承诺。** 它用于判断诊断是否正确，不用于向患者承诺疗效；一次不成即改判，是本条的用法。
- 本章为教学材料，不构成诊断、治疗或急救建议。文中病种鉴别、压痛定位与红旗筛查，只用于建立判断框架。
