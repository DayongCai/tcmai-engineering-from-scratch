# 颈肩的风险不在手上，在筛上 · 提示词

## 用途

给「颈肩的风险不在手上，在筛上」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三段解剖，一段风险 → 落枕：判据在「没有什么」 → 肩关节周围炎：三期决定手法强弱 → 肩袖损伤与肩峰撞击：鉴别先于手法」这条链。

```

正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

   - 要排除的五类
```

## 边界

本章为教学材料，不构成诊断、治疗或急救建议。文中病种判断、分期与禁忌，只用于建立判断框架；具体操作以现行规范与所在机构制度为准。
