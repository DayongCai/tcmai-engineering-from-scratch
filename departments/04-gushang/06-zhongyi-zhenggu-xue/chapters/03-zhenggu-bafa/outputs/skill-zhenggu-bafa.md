# 八法的次序比八法的名目重要

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 5 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 八法的价值在次序与停止条件，不在名目
- 「欲合先离」的前提是可控的牵引
- 力偶比单点力安全，但仍需骨质支持
- 本章不写手法角度、牵引重量与复位次数上限
- 文中的病例是合成示例

## 边界

- **八法的价值在次序与停止条件，不在名目。** 能背出八个字，与能用它做判断，是两件事。
- **「欲合先离」的前提是可控的牵引。** 没有麻醉、没有助手、没有对抗牵引的「拉一拉」，不叫离而复合，叫牵拉伤。
- **力偶比单点力安全，但仍需骨质支持。** 严重骨质疏松的骨，任何端挤都可能造成新的骨折，此时应降低目标，改换固定方式。
- 本章讨论正骨八法的功能分组、复位力学与停止指征，不构成诊疗方案。具体手法、固定与转诊决策，须由执业医师依据伤情、影像与所在机构规范作出。
