# 筋伤不是「没有骨折」，是另一类损伤

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 稳定性试验
- 「没骨折」是一个影像结论，不是一个治疗结论
- 「筋出槽」不能替代结构诊断
- 手法松开的是滑动度，不是力量
- 本章不写具体的固定方式、训练强度与疗程
- 个案为合成示例

## 边界

- **「没骨折」是一个影像结论，不是一个治疗结论。** 把前者当后者，是筋伤慢性化最主要的原因。
- **「筋出槽」不能替代结构诊断。** 没有触诊依据、没有功能对应、没有排除结构损伤，这个词就只是修辞。
- **手法松开的是滑动度，不是力量。** 粘连松解之后必须有主动训练巩固，否则松开的会重新粘上。
- 本章讨论筋伤的解剖含义、损伤机制与诊断方法，不构成诊疗方案。具体诊断、固定、手法与康复计划，须由执业医师依据体征、影像与所在机构规范作出。
