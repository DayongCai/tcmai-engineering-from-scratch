# 筋伤总论 · 提示词

## 用途

给「筋伤总论」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「绪论与理论基础 → 正骨手法概论 → 正骨八法与常用手法 → 骨折总论 → 上肢骨折 → 下肢骨折 → 躯干与骨盆骨折 → 关节脱位 → 筋伤总论 → 颈肩腰腿筋伤 → 四肢关节筋伤与小儿骨伤 → 骨病与康复」这条链。

## 提示词

```
我在学《中医正骨学》第 9 章「筋伤总论」，本章 5 单元 / 12,617 汉字，
取自教材第 10 章。

请按以下顺序带我走：
1. 先给本章要回答的问题，并说明它为什么不能直接套用上一章；
2. 再给三辨（正骨手法／固定与牵引／用药与康复）在本章的实测分布，指出主导那一辨；
3. 然后按单元逐条读出「判据」——每条只写类别与要点，不给操作参数；
4. 最后给出三条边界：哪些内容只能写到类别、哪些必须由具备资质的人员作出、哪些情况按记录写：部位、影像/体征、分类分型、处理、随访报告。

要求：不编造教材没有的数字；引文写到《书名·篇名》级并标注是否本章原文篇名；
不确定的地方直接说「教材未展开」。
```

## 边界

本提示词用于教学准备，不构成诊疗或护理意见；具体操作以现行规范与所在机构制度为准。
