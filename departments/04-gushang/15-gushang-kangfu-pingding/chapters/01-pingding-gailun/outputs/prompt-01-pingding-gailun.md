# 评定不是给功能打分，是把「他现在不能做什么」换成「下一步做什么」 · 提示词

## 用途

给「评定不是给功能打分，是把「他现在不能做什么」换成「下一步做什么」」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「评定的产出是一句话，不是一组数 → 三层结构：结构、功能、参与 → 同一件事，三层可以给出三个答案 → 频率与时点：评定是一条曲线，不是一个点」这条链。

## 提示词

```
我在学《骨伤康复评定》第 1 章「评定不是给功能打分，是把「他现在不能做什么」换成「下一步做什么」」，本章 7 节 / 2,950 汉字，习题 7 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 什么时候再看
   - 一次评定只能可靠地回答前两种；只有连续几次评定才能回答第三种
   - 上一层正常不能推出下一层正常，下一层异常也不能反推上一层有病
   - 先结构、再功能、后参与
   - 参与层的目标决定功能层要测什么，功能层的结果决定结构层能不能承受
   - 判据必须挂在目标上，不能挂在健侧的百分比上
4. 本章自陈的边界（不得越过）：
   - **本章不提供任何量表的具体条目、计分方法与判读阈值。** 三层结构是组织信息的框架，不是一套可以直接施测的工具；具体工具的选择与解释在后续各章分别讨论。
   - **三层之间没有换算关系。** 不存在「结构恢复七成等于功能恢复七成」这类对应；任何试图跨层折算的做法都会引入错误。
   - **时点与频率只给原则，不给日程表。** 具体间隔取决于损伤类型、手术方式、机构条件与随访可行性，本课不写「术后第几周复评」这类数值。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章讨论康复评定的目的、层次结构与组织原则，不构成诊断或治疗意见。具体评定项目、实施方法与结果解释，须由具备资质的人员依个体情况与现行规范作出；具体操作以现行规范与所在机构制度为准。
