# 骺板是一条时间线，不是一道缝

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 初级骨化中心
- 次级骨化中心
- 静止区（储备区）
- 成骨区（退变区）
- 旋转畸形几乎不塑形
- 骨折线经过了骺板的哪几层、是否累及骨骺与关节面

## 边界

- **本章的分型与机制是解剖学层面的，不是治疗指征。** 某一型要不要手术、要不要复位、复位到什么程度，取决于年龄、部位、移位方向、伴随损伤与随访条件，本章一概不给结论。
- **比例与时间点都是"常引口径"。** 各骺板对长度的贡献比例、骺板闭合的年龄顺序、男女差异的年数，不同教材与人群研究给出的数字不一致；本章只保留定性结论（膝周贡献最大、女性早于男性），不写具体数值，避免把一手数据说成二手。
- **骨龄判读不是本章能替代的。** 骨龄图谱有版本差异，判读者之间的差异也不小；涉及生长障碍、内分泌疾病或法医学用途时，须由专科按现行标准出具。
- 本章为儿童骨生长与骺板损伤的解剖学教学材料，不构成诊断、治疗或预后判断意见。儿童骨折与骺板损伤的处置须由具备资质的医师依据影像、年龄与随访条件决定。
