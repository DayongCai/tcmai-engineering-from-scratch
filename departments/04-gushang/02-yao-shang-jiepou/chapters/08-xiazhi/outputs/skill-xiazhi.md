# 下肢的力线一偏，整副骨架都要还债

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 8 道题自检，答不上就回到对应小节。

## 核心判据

- 限制胫骨相对股骨向前移位与过度内旋
- 限制向后移位
- 伸膝末端的锁扣
- 屈曲时的旋转自由度
- 距骨滑车前宽后窄
- 踝关节在背伸位最稳定，在跖屈位最不稳定

## 边界

- **本章给的是正常形态与力线关系，不是骨关节炎的分期或手术指征。** 力线偏移多少需要干预、截骨还是置换，取决于症状、年龄、关节间隙与活动需求，本章不给结论。
- **颈干角、前倾角、Q 角、力线偏角的数值都是常引口径。** 不同教材与测量方法给出的范围有差异；本章保留定性结论（颈干角使外展肌有力臂、前倾角使下肢自然外旋、Q 角女性偏大），不把数值当阈值用。
- **力矩演算是示意性的。** 它说明"力臂短则肌力需求大"这个关系，不能用来估算某个人的实际肌力或关节载荷。
- 本章为下肢解剖与力线的教学材料，不构成诊断或治疗意见。膝髋疼痛伴行走受限、下肢外形改变、跛行或外伤后不能负重者，应由具备资质的医师检查并完善影像与力线评估。
