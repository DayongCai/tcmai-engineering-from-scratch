# 摸得到的解剖，才是能在病人身上用的解剖

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 8 道题自检，答不上就回到对应小节。

## 核心判据

- 骨不会随体位与肿胀改变形状，肌会
- ，越胖的人标志越模糊，骨质疏松的病人棘突可能摸不清；二是
- 标志移位本身是体征
- 第七颈椎棘突
- 肩胛冈内侧端
- 髂嵴最高点连线

## 边界

- **本章的"平第几椎"全是常见值，不是定律。** 棘突长度、髂嵴高度、肩胛骨位置的个体差异都足以让定位偏移半个到一个节段；涉及有创操作时必须以影像核对，不能只靠触摸。
- **体表定位不能替代影像。** 它回答"大概在哪一层"，不回答"里面是什么"；病变的定性、范围与毗邻关系必须靠影像。
- **肥胖、水肿、瘢痕、畸形会显著降低定位可靠性。** 这些情况下应改用影像引导，而不是加大按压力度。
- 本章为体表标志与定位的教学材料，不构成诊断或治疗意见。任何有创操作（穿刺、注射、针刺、手法整复）的定位须由具备资质的人员在规范条件下完成，并结合影像核对。
