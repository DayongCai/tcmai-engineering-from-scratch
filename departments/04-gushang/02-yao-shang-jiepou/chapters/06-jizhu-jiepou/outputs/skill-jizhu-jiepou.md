# 脊柱的稳定是三根柱子的事，不是一块骨头的事

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 8 道题自检，答不上就回到对应小节。

## 核心判据

- 在后，由两侧椎弓根与椎板围成，与椎体后缘共同围出
- 只累及前柱的压缩骨折通常稳定，累及中柱则提示不稳定
- 为什么 L4/5 椎间盘突出，症状却在 L5 神经根分布区？
- 腰穿与麻醉的进针平面
- 脊髓节段与椎骨节段的对应不是一一对齐
- 马尾与脊髓的损伤表现不同

## 边界

- **本章给的是正常解剖与稳定性框架，不是骨折分型与治疗指征。** 具体某一处损伤要不要手术、要不要支具、卧床多久，须依据完整的评分系统、影像与神经状态判断。
- **三柱的分法有多套版本，柱的边界在不同教材里略有差异。** 本章采用通行的三柱划分，只取其"中柱受累提示不稳"的定性结论，不用它替代任何评分。
- **椎管矢状径的"狭窄"阈值是常引口径。** 不同人群、不同测量方法给出的界值不同，且影像上的狭窄与症状并不总是一致——"影像狭窄而无症状"很常见。
- 本章为脊柱解剖与稳定性的教学材料，不构成诊断或治疗意见。外伤后腰背痛伴翻身困难、下肢麻木无力、行走不稳或大小便功能改变者，须立即就医。
