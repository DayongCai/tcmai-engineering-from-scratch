# 神经和血管走的是空隙，不是路线

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 8 道题自检，答不上就回到对应小节。

## 核心判据

- 第一条：沿肌间隙与筋膜平面走
- 第二条：贴骨面走沟、穿管
- 第三条：狭窄处即弱点
- 腋神经与肱骨外科颈
- 桡神经与桡神经沟
- 正中神经与尺神经在肘部

## 边界

- **本章是解剖定位，不是损伤分级标准。** 肌力分级、感觉评定、电生理检查各有规范，本章只给解剖对应关系，判读须由专科完成。
- **神经血管的变异率不低。** 腋神经与四边孔的关系、腓总神经的分支平面、股动脉的分支型都有个体差异，术前评估以影像与术中探查为准，不能凭本章的"典型走行"下结论。
- **"位置浅"不等于"容易损伤"，"位置深"也不等于"安全"。** 深部血管损伤可能出血隐蔽而后果更重，浅部神经损伤可能只表现为麻木而被忽略；两者都需要主动检查而不是等待症状。
- 本章为神经与血管走行的解剖学教学材料，不构成诊断或治疗意见。外伤后出现肢体麻木、无力、发凉、苍白、被动牵拉痛，或骨折复位固定后症状加重，须立即就医评估血管神经状态。
