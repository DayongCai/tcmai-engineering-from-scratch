# 选题不是挑一个病种，是把一套复位方案压成一条别人能复算的命题 · 提示词

## 用途

给「选题不是挑一个病种，是把一套复位方案压成一条别人能复算的命题」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三条判据：骨伤版的可复现、可对照、可接手 → 四步降维：从一个病名到一条命题 → 三份能交出去的骨伤毕设产物 → 里程碑：四件必须交出去的东西」这条链。

## 提示词

```
我在学《骨伤毕业设计与知识移交》第 1 章「选题不是挑一个病种，是把一套复位方案压成一条别人能复算的命题」，本章 6 节 / 3,532 汉字，习题 7 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 你要归因的到底是哪一件

   - 这个判断错了会怎样

   - 能不能当场打开十条真实记录
   - 严判据会筛掉一部分本来能做完的题目
4. 指出本章写到类别就止步、不再给参数的地方。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，不构成医学意见、诊断或治疗建议，也不构成商业、合规或伦理意见；具体操作以现行规范与所在机构制度为准。
