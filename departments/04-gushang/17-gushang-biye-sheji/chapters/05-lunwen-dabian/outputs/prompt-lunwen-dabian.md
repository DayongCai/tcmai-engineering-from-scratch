# 论文不是把做过的事按时间讲一遍，是把「别人凭什么信你」按证据强度排好 · 提示词

## 用途

给「论文不是把做过的事按时间讲一遍，是把「别人凭什么信你」按证据强度排好」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「六段骨架：每一段都能用一句话检验 → 图表与数字：先让读者能核对，再让读者相信 → 答辩前先自评：七项检查 → 答辩：三类必答题与五分钟陈述」这条链。

## 提示词

```
我在学《骨伤毕业设计与知识移交》第 5 章「论文不是把做过的事按时间讲一遍，是把「别人凭什么信你」按证据强度排好」，本章 5 节 / 3,404 汉字，习题 7 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 图的顺序要跟论证顺序一致
   - 严格的结构与核对会拖慢写作
   - 自评七项不等于评审标准
   - 本章不给论文格式模板
   - 文中的检查表项名来自本系毕设口径
4. 指出本章写到类别就止步、不再给参数的地方。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，不构成医学意见、学术规范裁决或合规意见；具体操作以现行规范与所在机构制度为准。
