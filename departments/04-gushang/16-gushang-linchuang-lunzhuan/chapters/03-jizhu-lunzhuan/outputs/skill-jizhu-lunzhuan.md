# 脊柱轮转：最贵的错误，是把红旗征当成落枕

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 能写数字的不要写形容词
- 没有假设的检查无法被解读
- 先固定再搬动
- 平托、不折腰
- 交接说清「不能做什么」
- 本章不提供影像指征的具体阈值

## 边界

- **本章不提供影像指征的具体阈值**：何时做哪一项检查、多久复查，由上级医师与现行规范决定；本章只给「先问什么、按什么顺序」的框架。
- **不写机构流程**：绿色通道、会诊与转运的具体规定各院不同，进科后以本科室制度为准。
- **不替代神经定位判断**：本章教的是记录与筛查，不是定位诊断；分级与定位由具备资质的人员作出。
- 本章为教学材料，不构成医学意见、诊断或治疗指导。
