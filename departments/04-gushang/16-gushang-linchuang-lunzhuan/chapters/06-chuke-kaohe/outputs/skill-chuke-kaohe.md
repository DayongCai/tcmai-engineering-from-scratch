# 出科考核：考的不是背，是你能不能把一次接诊从头讲到尾

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 8 道题自检，答不上就回到对应小节。

## 核心判据

- 我认为是什么
- 先说结论，再说过程
- 情形 / 我的判断 / 实际结果 / 差别 / 改动
- 本章不给考核标准原文
- 权重为教学示例
- 不替代带教评价

## 边界

- **本章不给考核标准原文**：评分表、合格线、考核形式由各基地教学管理部门规定，本章只给结构与判据的逻辑。
- **权重为教学示例**：文中百分比用于说明维度构成，不构成任何机构的评分规则。
- **不替代带教评价**：出科结论由带教与考核小组作出，本章不提供自评结论。
- 本章为教学材料，不构成医学意见、诊断或处置指导。
