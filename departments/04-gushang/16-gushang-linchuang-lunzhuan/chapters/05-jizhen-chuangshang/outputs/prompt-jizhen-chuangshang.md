# 创伤轮转：第一课是分工，不是技术 · 提示词

## 用途

给「创伤轮转：第一课是分工，不是技术」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「接人：院前交接与到院十秒 → ABCDE：顺序不能换，也不能跳 → 四项现场技术：每一项都有「不做什么」 → 绿色通道与记录：谁有权启动、怎么喊、怎么留证」这条链。
