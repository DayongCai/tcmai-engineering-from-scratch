# 筋伤轮转：门槛不在手上，在禁忌筛查那三分钟

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 5 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 有没有人告诉过你不能按
- 会问、会看、会停
- 手法合格的标志是病人感受不到痛苦，而不是医者用了几成力
- 本章不提供手法参数
- 筛查表是通用逻辑，不是机构清单

## 边界

- **本章不提供手法参数**：力度分级、单次时长、疗程次数均以现行规范与所在科室要求为准；文中数字为教学建议，不构成操作标准。
- **筛查表是通用逻辑，不是机构清单**：各科室的禁忌条目会随设备、资质与病种结构变化，进科后必须以本科室版本为准。
- **不替代诊断**：筋伤的鉴别涉及感染、肿瘤、神经与血管问题，本章只讲「什么时候停、往哪里转」，不讲「怎么确诊」。
- 本章为教学材料，不构成医学意见、诊断或治疗指导。
