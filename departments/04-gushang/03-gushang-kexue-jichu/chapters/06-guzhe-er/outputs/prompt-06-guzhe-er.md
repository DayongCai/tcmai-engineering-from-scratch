# 下肢骨折先算血，再算骨 · 提示词

## 用途

给「下肢骨折先算血，再算骨」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「下肢的目标：负重、力线、长度 → 髋部：两种骨折，两套逻辑 → 股骨干与膝：失血、栓塞、关节面 → 小腿与踝：软组织决定方案」这条链。

## 边界

本章讨论下肢与躯干骨折的诊断治疗思路，不构成诊疗方案。任何复位、固定、手术、输血与康复决策，须由执业医师依据具体伤情、全身状况与所在机构规范作出；具体操作以现行规范与所在机构制度为准。
