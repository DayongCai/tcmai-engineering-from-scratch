# 影像回答哪里断了，查体回答他还能做什么，两者不能互相代替 · 提示词

## 用途

给「影像回答哪里断了，查体回答他还能做什么，两者不能互相代替」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三条信息线，各有各的盲区 → 机制问诊：五个必须问清的问题 → 查体三段：先排除，再定位，最后定量 → 影像：选它的理由是它会改变处理」这条链。


## 边界

本章讨论运动损伤的评估逻辑与影像选择原则，不构成诊断意见。任何影像检查的必要性、部位与判读，以及是否手术，均须由具备资质的人员依个体情况决定；具体操作以现行规范与所在机构制度为准。
