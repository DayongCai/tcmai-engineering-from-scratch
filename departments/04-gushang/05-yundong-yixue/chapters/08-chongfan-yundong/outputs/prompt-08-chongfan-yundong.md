# 能上场不是判据，能在这个强度下反复出现而不出问题才是 · 提示词

## 用途

给「能上场不是判据，能在这个强度下反复出现而不出问题才是」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「四层判据，缺一层就会漏一类风险 → 对称度：一个有用但会骗人的指标 → 心理准备：不是安慰，是一个可评估的变量 → 复发：回到旧负荷，但承受力没回到旧水平」这条链。

```
我在学《运动医学与损伤防护》第 8 章「能上场不是判据，能在这个强度下反复出现而不出问题才是」，本章 6 节 / 2,679 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：

3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章讨论重返运动的评估框架与复发预防原则，不构成诊疗意见或回归许可。是否回归、以何种强度回归，须由具备资质的人员依个体评估与现行规范作出；具体操作以现行规范与所在机构制度为准。
