# 病变不是病名，是几种基本变化的组合

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 边界

- **本章是征象语言，不是疾病诊断学。** 七种基本变化的价值在于让报告"说得清"，具体病种的诊断标准须由各论与病理承担。
- **征象与病理的对应不是一一映射。** 同一个征象可以由多种机制产生，同一个疾病在不同阶段可以呈现不同征象；本章的对应关系是倾向性的，不是判据表。
- **本章不给分型阈值与测量数值。** 破坏区的大小、移行带的宽度、骨膜反应的层数，都是相对描述；任何"超过多少毫米即为恶性"的说法都不成立。
- 本章为影像诊断学的教学材料，不构成诊断意见。任何影像征象的判读与疾病性质的判断，须由具备资质的医师结合病史、实验室检查、病理与随访作出。本章所引《灵枢·百病始生》"察其所痛，以知其应"，原论在据症候推求病所，与影像征象无直接关系，引用只为说明"由表现推机制"这一读片思路。
