# 病变不是病名，是几种基本变化的组合 · 提示词

## 用途

给「病变不是病名，是几种基本变化的组合」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「七种基本变化 → 破坏的边界，比破坏的大小更有信息 → 骨膜反应是时间的刻度 → 密度的两个方向」这条链。

## 边界

本章为影像诊断学的教学材料，不构成诊断意见。任何影像征象的判读与疾病性质的判断，须由具备资质的医师结合病史、实验室检查、病理与随访作出。本章所引《灵枢·百病始生》"察其所痛，以知其应"，原论在据症候推求病所，与影像征象无直接关系，引用只为说明"由表现推机制"这一读片思路；具体操作以现行规范与所在机构制度为准。
