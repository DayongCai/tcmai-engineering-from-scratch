# 感染与肿瘤在早期长得像，时间是最好的鉴别

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 临床怀疑骨感染而平片阴性时，不能等平片"长出来"，要直接做 MRI
- 骨皮质破坏与骨膜反应
- 骨膜下脓肿与软组织脓肿
- 跨越关节或骺板
- 硬化性骨髓炎
- 化脓性关节炎

## 边界

- **本章讲影像判据，不讲抗感染方案。** 抗生素的选择、疗程、手术清创的时机，须由感染科与骨科医师依病原学、药敏与病人状况决定。
- **感染的影像诊断不能替代病原学。** 血培养、穿刺培养、病理是确诊依据；影像的作用是定位、判断范围、评估并发症与随访。
- **MRI 的骨髓水肿极不特异。** 骨折、术后、肿瘤、放疗、骨关节炎都能产生水肿；把"水肿"当成"感染"是最常见的过度诊断。
- 本章为影像诊断学的教学材料，不构成诊断或治疗意见。感染与炎性疾病的诊断、用药与手术须由具备资质的医师依病原学、现行规范与所在机构制度作出。本章所引《素问·评热病论》"邪之所凑，其气必虚"，原论在正气不足则外邪易侵，引用只为提示"宿主状态决定感染的表现与转归"这一观察角度，与影像技术无关。
