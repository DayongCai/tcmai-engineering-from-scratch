# 第 1 章 · 先问要回答什么，再决定拍什么

> **MOTTO:** 「工欲善其事，必先利其器。」——《论语·卫灵公》
>
> **PROBLEM:** 一位 62 岁女性跌倒后右髋痛、不能负重。急诊右髋正位片报告"未见骨折"；次日加做 CT，报告仍写"未见明确骨折线"；第三日改做 MRI，股骨颈头下的一条细线才显出来。三天、三次检查、三种结论——不是设备不够好，是前两次都没有先回答一个问题：这个病人最可能是什么，哪一种检查能把它显出来。

**双根因定位:** 环境逼迫（临床留给影像的时间窗口极短，急诊要在几十分钟内回答"有没有骨折、要不要手术"，而体位、投照角度、窗宽窗位在开单与摆位那一刻就已决定了大半） + 知识积累（技术选择的判据不是"哪种设备先进"，而是每种成像的对比源与假阴性代价；这套判据只能靠一个个具体问题积累，背不下来）

## 一、四种影像，回答的是四类问题

影像技术之间的差别，不在"清晰度"，在"把什么变成可见的差别"。

X 线的对比源是组织对射线的衰减差。骨含钙、密度高、衰减多，与软组织天然差得远，所以它擅长回答"骨的整体形态、对线、皮质连不连续"；代价是把三维压成二维，前后结构叠在一起。CT 同样测衰减，但它把人切成层，重叠消失，还能用 CT 值把密度变成可测的数，于是擅长回答"骨块有几块、关节面塌了多少、椎体后壁破没破"；代价是辐射与软组织对比有限。MRI 测的是氢质子的弛豫，与密度无关，脂肪、水、骨髓、软骨、韧带、脊髓各有各的信号，所以擅长回答"骨髓有没有水肿、韧带断没断、脊髓受没受压"；代价是时间长、有禁忌、费用高。超声用声波，进不去骨，但能实时看表浅肌腱、积液、滑膜，还能让病人动起来看动态稳定性。还有常被忽略的第五类——核医学骨显像与 PET，它反映代谢与血流而非形态，敏感而不特异，骨扫描上一个浓聚灶可能是转移、可能是骨折、也可能是炎症，必须回到形态学影像去证实。它的位置是"筛"，不是"定"。

把这五类摆成一张问题表，选择就清楚了一半：

| 要回答的问题 | 首选 | 补充 |
|---|---|---|
| 有无骨折、对线与成角 | 正侧位平片 | CT（隐匿、关节内） |
| 关节面塌陷、骨块数目与位置 | CT 薄层 + 多平面重建 | 平片（整体对线） |
| 韧带、半月板、软骨、脊髓 | MRI | 超声（表浅肌腱、动态） |
| 骨髓水肿、早期感染、早期坏死 | MRI（压脂 / STIR） | 核医学（敏感不特异） |
| 全身有无多发病灶 | 骨显像 / PET | 分段平片或 MRI |
| 表浅积液、腱鞘、异物 | 超声 | MRI |

这张表是"问题—工具"的对应关系，不是操作规范。真正的选择还要加上第三节讲的代价。

## 二、开单之前的三问

**第一问：我要回答的是哪一个问题。**"查一下骨"不是问题。"跌倒后髋痛、不能负重，有无股骨颈骨折"才是问题——前者能拍出十张没有结论的片子，后者会直接指向髋关节正侧位，并在阴性时指向 CT 或 MRI。同理，"腰痛"与"腰痛伴左下肢放射痛、足背麻木"指向完全不同的检查：前者可能只需要平片排除结构性病变，后者需要 MRI 看椎间盘与神经根。问题的粒度决定了检查的粒度，也决定了报告的用处。

**第二问：这个检查阴性，我敢不敢就此排除。** 这是敏感性与假阴性代价的问题。股骨颈骨折在平片上的假阴性有实实在在的后果——漏诊意味着病人继续负重、骨折移位、股骨头血供进一步受损；所以"平片阴性而高度怀疑"时，下一步不是"观察两天再说"，而是 MRI 或 CT。反过来，一个慢性膝痛的年轻人，平片阴性基本可以接受，因为要排除的是骨性病变，软组织的问题本来就不在平片的能力范围内。同样一个"阴性"，价值完全不同。

**第三问：代价是什么。** 辐射、时间、费用、可及性、病人的配合能力都是代价。儿童的辐射敏感性高于成人，孕妇的盆腔检查需要权衡，幽闭恐惧、体内金属、心脏起搏器会直接排除 MRI，躁动或剧痛的病人做不完需要十几分钟不动的序列。把这些写在申请单上，比事后在报告末尾写一句"图像质量欠佳，建议复查"要负责得多。

## 三、平片：起点、基准与随访的尺子

平片在骨伤里一直没有被取代，原因有三：便宜、快、能反复。第三点常被低估——**平片是随访的基准**。骨折愈合是一个过程，判断"长了没有"靠的是同一部位、同一体位、同一投照条件下的前后比较。换一家医院、换一个角度、换一种曝光，比较就失去了意义。所以第一次拍片的体位与标记，实际上决定了此后几个月能不能判断愈合。

平片的几条硬要求：至少两个互相垂直的体位；必须包括骨折部位上下各一个关节，否则无法判断旋转与成角；左右标记必须在片内；曝光要能同时看清骨皮质与软组织轮廓，过曝则骨小梁纹理消失，欠曝则软组织一片黑；特殊部位加特殊体位——腕舟骨、跟骨、髌骨、肩关节、髂骨翼各有各的投照角度，用一张正位片去排除这些部位的骨折，等于给自己制造假阴性。

还有一条时间上的常识：**骨折线在伤后一两周内可能变得更清楚，而不是更模糊。** 断端骨质吸收、骨折线增宽，原本隐约的线就显出来了。这既解释了为什么临床怀疑骨折而首片阴性时复查有意义，也解释了为什么"首片正常"不能当作结论写进病历。

## 四、CT 与 MRI：把"看不见"变成"看得见"的两种代价

CT 的实质进步是去重叠与可定量。它对骨的价值集中在四类情形：关节内骨折（关节面有无台阶、塌陷多深）；粉碎骨折（骨块数目与空间位置）；脊柱与骨盆（椎体后壁、椎弓根、椎管内骨块、骶髂关节）；临床高度怀疑而平片阴性的隐匿骨折。三维重建适合看空间关系与手术设计，但它的表面形态受阈值设定影响，凡是"从三维图上量出来"的数，都要回到原始断层核对。

CT 的读片有一个必须养成的习惯：**同一组数据要看两套窗。** 骨窗看皮质与骨小梁，软组织窗看肌肉、血肿、关节囊与积液。只看骨窗，会漏掉椎管内的高密度血肿、关节内的积气与软组织肿胀；只看软组织窗，会把细如发丝的骨折线当成噪声。窗宽窗位的具体数值各机构不同，以所在机构规范为准；但"两套窗都看"不是参数问题，是习惯问题。

MRI 的价值在于它能看到别的技术看不到的组织：骨髓、软骨、韧带、半月板、脊髓、神经根、滑膜。骨伤中它最常用的三个场景是：临床怀疑骨折而平片与 CT 均阴性（看骨髓水肿）；关节内软组织损伤（韧带、半月板、盂唇、软骨）；脊柱损伤是否累及脊髓与韧带复合体。它的信号语言必须与序列绑定——同一个病灶在 T1 上暗、在压脂 T2 上亮，说的不是两件事，是"含水多"。骨髓水肿通常在伤后不久出现，可持续数周到数月；这个时间尺度决定了伤后很久才做的 MRI 可能只剩残余信号，不能据此判断"当时伤得很轻"。

MRI 的代价不只是钱和时间。体内有铁磁性植入物、心脏起搏器、某些动脉夹的病人不能进磁体间；幽闭恐惧、无法平卧、躁动的病人做不完序列；金属植入物周围会有伪影，把紧邻的骨与软组织糊掉。这些限制写在申请单上，比写在报告末尾有用得多。

## 五、报告是描述，不是判决

一张片子的价值链是：临床问题 → 申请单 → 投照或扫描 → 阅片 → 报告 → 临床决策。断在任何一环，后面的都白做。

申请单上最该写的不是"查骨折"，而是"跌倒后右髋痛、不能负重、查体患肢外旋短缩、平片阴性仍高度怀疑"。这句话直接告诉阅片者该重点看哪里、该不该建议下一步。反过来，报告上最该避免的是两句空话："未见明显异常"与"建议结合临床"。前者在没有说明检查限度时是误导——平片"未见异常"只意味着平片能看到的部分没看到异常；后者在没有给出具体建议时等于把问题原样退回。

一份可用的报告至少包含：检查部位与体位、图像质量是否满足诊断、主要阳性所见及其位置与范围、阴性但重要的所见（如"股骨颈皮质连续，未见骨折线"）、印象（按可能性排序）、以及明确的下一步建议（如"建议加做髋关节 MRI 以排除隐匿骨折"）。用词上，"皮质中断""成角""移位""关节面台阶"是可以被核对的事实；"严重""明显""少许"是不可核对的判断，能少用就少用，非用不可时补上依据。

## 代价与边界

- **本章讲技术选择的原则，不承担操作规范的功能。** 具体投照角度、扫描参数、剂量控制，以所在机构规范与现行指南为准。
- **问题表是按常见情形归纳的路径，不是绝对规则。** 同一问题在不同机构、不同设备、不同操作者条件下可能有不同的最优解，遇到冲突以当时的临床情境为准。
- **本章不给发生率，也不给敏感性与特异性的具体数值。** 这类数字高度依赖人群构成、设备与判读标准，转引容易失真；需要时查原始文献与本地数据，不要用二手数字做决策。
- **影像阴性不等于无病，影像阳性不等于病因。** 这个不对称是全书反复回到的底线，也是过度检查与过度治疗最常钻的空子。
- **检查的选择最终由临床医师与影像医师共同决定。** 本章不构成对任何具体病例的检查建议，也不涉及费用与医保政策。

**免责声明:** 本章为影像诊断学的教学材料，不构成诊断或治疗意见。检查的选择、实施与判读须由具备资质的医师依现行规范、临床路径与所在机构制度作出。本章所引《论语》"工欲善其事，必先利其器"原指做事先备其具，引用只为说明"先明确问题、再选择工具"这一顺序，与具体技术细节无关。
