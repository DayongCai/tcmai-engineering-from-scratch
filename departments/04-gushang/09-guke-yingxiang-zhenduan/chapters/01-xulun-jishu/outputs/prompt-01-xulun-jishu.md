# 先问要回答什么，再决定拍什么 · 提示词

## 用途

给「先问要回答什么，再决定拍什么」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「四种影像，回答的是四类问题 → 开单之前的三问 → 平片：起点、基准与随访的尺子 → CT 与 MRI：把"看不见"变成"看得见"的两种代价」这条链。

## 提示词

```
我在学《骨科影像诊断学》第 1 章「先问要回答什么，再决定拍什么」，本章 5 节 / 3,038 汉字，习题 7 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 第一问：我要回答的是哪一个问题
   - 第二问：这个检查阴性，我敢不敢就此排除
   - 第三问：代价是什么
   - 平片是随访的基准
   - 骨折线在伤后一两周内可能变得更清楚，而不是更模糊
   - 同一组数据要看两套窗
4. 本章自陈的边界（不得越过）：
   - **本章讲技术选择的原则，不承担操作规范的功能。** 具体投照角度、扫描参数、剂量控制，以所在机构规范与现行指南为准。
   - **问题表是按常见情形归纳的路径，不是绝对规则。** 同一问题在不同机构、不同设备、不同操作者条件下可能有不同的最优解，遇到冲突以当时的临床情境为准。
   - **本章不给发生率，也不给敏感性与特异性的具体数值。** 这类数字高度依赖人群构成、设备与判读标准，转引容易失真；需要时查原始文献与本地数据，不要用二手数字做决策。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为影像诊断学的教学材料，不构成诊断或治疗意见。检查的选择、实施与判读须由具备资质的医师依现行规范、临床路径与所在机构制度作出。本章所引《论语》"工欲善其事，必先利其器"原指做事先备其具，引用只为说明"先明确问题、再选择工具"这一顺序，与具体技术细节无关；具体操作以现行规范与所在机构制度为准。
