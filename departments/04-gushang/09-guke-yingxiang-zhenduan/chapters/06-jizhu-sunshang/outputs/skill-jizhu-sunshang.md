# 脊柱的片子，最危险的不是那条骨折线

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 为椎体前三分之二与前纵韧带
- 为椎体后三分之一、后纵韧带与椎间盘后部
- 程度轻不等于稳定，程度重也不必然不稳
- 椎弓根与椎板
- 椎管内骨块
- 椎体前缘线、后缘线与棘突连线

## 边界

- **本章讲判据，不讲手术决策。** 是否减压、是否融合、前路还是后路，须由脊柱外科医师依损伤类型、神经功能、合并伤与病人全身状况决定。
- **三柱与各分型是描述框架，不是阈值表。** 压缩比例、后凸角度、椎管内骨块的分级界值随学派与版本不同，本章不给数值，具体以现行标准与所在机构规范为准。
- **CT 与 MRI 各有盲区。** CT 看不到韧带、脊髓与血肿；MRI 对骨皮质与骨块的显示不如 CT，金属内固定附近伪影明显。两者不是替代关系，是互补关系。
- 本章为影像诊断学的教学材料，不构成诊断或治疗意见。脊柱与脊髓损伤的影像检查、判读与处理须由具备资质的医师依现行规范、创伤救治流程与所在机构制度作出。本章所引《素问·缪刺论》"有所堕坠，恶血留内"，原论在跌坠之后瘀血内停的病机与刺法，与影像技术无关，引用只为提示"外伤之后，看不见的腔内积血同样致命"这一观察角度。
