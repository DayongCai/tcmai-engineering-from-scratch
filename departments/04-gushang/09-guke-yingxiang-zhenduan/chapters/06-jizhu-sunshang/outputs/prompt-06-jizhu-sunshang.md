# 脊柱的片子，最危险的不是那条骨折线 · 提示词

## 用途

给「脊柱的片子，最危险的不是那条骨折线」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「先分稳定与不稳定，再谈压缩程度 → CT 骨窗的四个必看 → MRI 看三样东西 → 无骨折脱位型脊髓损伤」这条链。

## 边界

本章为影像诊断学的教学材料，不构成诊断或治疗意见。脊柱与脊髓损伤的影像检查、判读与处理须由具备资质的医师依现行规范、创伤救治流程与所在机构制度作出。本章所引《素问·缪刺论》"有所堕坠，恶血留内"，原论在跌坠之后瘀血内停的病机与刺法，与影像技术无关，引用只为提示"外伤之后，看不见的腔内积血同样致命"这一观察角度；具体操作以现行规范与所在机构制度为准。
