# 正常不是"没有异常"，是知道什么算正常 · 提示词

## 用途

给「正常不是"没有异常"，是知道什么算正常」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「先判读这张片，再判读这个骨 → 骨的三层与三个端 → 关节：间隙、面、囊与脂肪垫 → 脊柱的六条线」这条链。

## 提示词

```
我在学《骨科影像诊断学》第 2 章「正常不是"没有异常"，是知道什么算正常」，本章 6 节 / 2,772 汉字，习题 7 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - （致密白线）、
   - （网状纹理）、
   - 是关节面所在，边缘应当光滑连续，软骨下有一层致密带
   - 骨密度是相对的
   - 关节间隙不是软骨的影像
   - 居中成一列；两侧
4. 本章自陈的边界（不得越过）：
   - **本章给的是读片基准，不是解剖学教材。** 各部位的具体解剖关系、肌肉附着与血管神经走行，须另据解剖学与局解资料，本章只保留判读正常片时用得上的那部分。
   - **"正常"是统计意义上的多数形态，不是唯一形态。** 正常变异很多，本章列的是最常见的几类；遇到清单之外的形态，宁可写"不典型，建议对照与随访"，不要硬套。
   - **本章不给测量正常值。** 关节间隙宽度、椎体高度、皮质厚度都随部位、年龄、体型、投照条件变化，任何"正常值"都必须带条件说明；具体测量以所在机构规范与设备标定为准。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为影像诊断学的教学材料，不构成诊断意见。具体病例的判读须由具备资质的医师结合病史、查体与随访作出；具体操作以现行规范与所在机构制度为准。
