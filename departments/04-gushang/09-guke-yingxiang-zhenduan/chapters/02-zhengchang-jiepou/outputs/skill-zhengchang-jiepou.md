# 正常不是"没有异常"，是知道什么算正常

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- （致密白线）、
- （网状纹理）、
- 是关节面所在，边缘应当光滑连续，软骨下有一层致密带
- 骨密度是相对的
- 关节间隙不是软骨的影像
- 居中成一列；两侧

## 边界

- **本章给的是读片基准，不是解剖学教材。** 各部位的具体解剖关系、肌肉附着与血管神经走行，须另据解剖学与局解资料，本章只保留判读正常片时用得上的那部分。
- **"正常"是统计意义上的多数形态，不是唯一形态。** 正常变异很多，本章列的是最常见的几类；遇到清单之外的形态，宁可写"不典型，建议对照与随访"，不要硬套。
- **本章不给测量正常值。** 关节间隙宽度、椎体高度、皮质厚度都随部位、年龄、体型、投照条件变化，任何"正常值"都必须带条件说明；具体测量以所在机构规范与设备标定为准。
- 本章为影像诊断学的教学材料，不构成诊断意见。具体病例的判读须由具备资质的医师结合病史、查体与随访作出。
