# 骨折的片子，先看片子，再看骨头 · 提示词

## 用途

给「骨折的片子，先看片子，再看骨头」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「拍片的三条硬规矩 → 六步读片顺序 → 最容易漏的八处 → 脱位与半脱位：看关系，不看间隙」这条链。


## 边界

本章为影像诊断学的教学材料，不构成诊断或治疗意见。骨折与脱位的诊断、分型与处理须由具备资质的医师依现行规范与所在机构制度作出。本章所引《医宗金鉴·正骨心法要旨》"夫手法者，谓以两手安置所伤之筋骨，使仍复于旧也"，原论正骨手法的目的，引用只为说明"先判明筋骨的位置关系，才有复位的依据"这一顺序，与影像技术无关；具体操作以现行规范与所在机构制度为准。
