# 搬运不是把人抬走，是把断端抬走 · 提示词

## 用途

给「搬运不是把人抬走，是把断端抬走」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「先保己：现场安全是操作的第零步 → 固定：目的只有一个，让断端不再动 → 搬运：体位是治疗的一部分 → 卡困解救：先救人，还是先救腿」这条链。

## 提示词

```
我在学《创伤急救学》第 2 章「搬运不是把人抬走，是把断端抬走」，本章 6 节 / 2,955 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 会不会再出事
   - 人手不够时最正确的动作是等，而不是硬搬
   - 范围超过上下两个关节
   - 固定后必须复查末梢
   - 畸形不强行矫正
   - 可疑损伤部位
4. 本章自陈的边界（不得越过）：
   - **固定会掩盖伤情。** 夹板与敷料绑上之后，后续观察更难。所以固定前必须记录一次末梢状态，固定后再记录一次，两次都要写下来——不写，就等于没有基线。
   - **搬运永远有二次损伤的风险。** 目标是"把风险降到最低"，不是"零风险"。在火场、水中、坍塌现场，快速撤离的收益可能大于脊柱制动的收益，这个判断必须由现场负责人做出并说明理由。
   - **本章不给固定周数、不给夹板型号、不给止血带时限。** 临时固定是几十分钟到几小时的事，与治疗性固定的周数是两回事；具体参数以所在机构规范为准。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章讨论现场固定与搬运的原则与次序，属教学材料，不构成急救操作指南。实际固定、搬运、解救须由受过训练的人员按所在地区院前急救规范与接诊机构流程执行；具体操作以现行规范与所在机构制度为准。
