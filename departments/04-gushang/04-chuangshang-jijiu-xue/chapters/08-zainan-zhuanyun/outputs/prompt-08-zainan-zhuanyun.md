# 灾难现场最稀缺的不是技术，是"谁先走"的决定 · 提示词

## 用途

给「灾难现场最稀缺的不是技术，是"谁先走"的决定」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「灾难的医学定义：需求瞬间超过资源 → 检伤分类：把"谁最重"换成"谁最该先走" → 转运：不是越快越好，是分级与匹配 → 交接：灾难中最容易断裂的一环」这条链。

## 边界

本章讨论灾难救援中的检伤分类、转运与交接原则，属教学材料，不构成急救操作指南、伦理裁决或行政依据。实际救援须由受过训练的救援人员按所在地应急管理体系、院前急救规范与接诊机构流程执行；具体操作以现行规范与所在机构制度为准。
