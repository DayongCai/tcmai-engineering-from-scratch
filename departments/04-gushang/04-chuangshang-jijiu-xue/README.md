## 四、这门课的三条硬顺序

1. **ABCDE 的顺序不能换**：气道 → 呼吸 → 循环 → 意识 → 暴露；换一步就可能漏掉致命伤。
2. **疑似脊柱损伤：先固定，再搬动**。搬运姿势错，稳定骨折会变成不稳定。
3. **保肢优先于复位质量**：急救阶段的目标是止血、固定、转运，不是解剖复位。

每章要求写清：**受伤机制、生命体征、处置动作、时限、转运去向**——缺一项就无法复盘。
