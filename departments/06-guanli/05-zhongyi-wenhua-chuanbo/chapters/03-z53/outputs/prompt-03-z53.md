# 制度化救下的是编制与课表，不是可传播性 · 提示词

## 用途

给「制度化救下的是编制与课表，不是可传播性」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三次换载体，三次筛内容 → 汇通派的难题：用对方的词，说自己的事 → 论争的实质：定义权，不是疗效之争 → 制度化之后：标准语让传播提速，也让表达收窄」这条链。

## 提示词

```
我在学《中医文化传播学》第 3 章「制度化救下的是编制与课表，不是可传播性」，本章 5 节 / 2,726 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；

   - 本章不给运动式的评价

   - **本章不给运动式的评价。** 「汇通」「抗争」这类词自带立场，本章只描述动作与后果，不判定谁对谁错。
```
