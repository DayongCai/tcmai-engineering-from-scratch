# 典籍变不成资源，除非先被切成一格一格 · 提示词

## 用途

给「典籍变不成资源，除非先被切成一格一格」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三种「可查」，难度差着量级 → 分类是第一次解释，也是第一次删减 → 切分粒度：一条不到二十字的记载，为什么能改变一件事 → 异名同病与同名异病：标引真正的难点」这条链。

## 提示词

```
我在学《中医文化传播学》第 4 章「典籍变不成资源，除非先被切成一格一格」，本章 5 节 / 2,747 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 它短、它独立、它带主治关键词
   - 一条知识能否被后人用上，取决于它当年被切成了什么形状
   - 不存在一一对应的映射
   - 光学识别之误
   - 它们不报错
   - 切分是有损的
4. 本章自陈的边界（不得越过）：
   - **切分是有损的。** 把一段切成条，条与条之间的上下文就断了。结构化越彻底，越容易丢掉「这段话是在什么语境下说的」。补救的办法是保留原文定位，随时可回看整段。
   - **标引带立场。** 谁定类目，谁就在决定什么算一类。做标引的人要留下规则说明，让后来者能看出这套分类的前提。
   - **不追求完全对齐。** 古今病名之间做等号，是这类工作里最常见的错误。分层标注（同义／包含／存疑）比强行统一更可靠。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```
