# 能传走的是判据，不是神医 · 提示词

## 用途

给「能传走的是判据，不是神医」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「供给端的第一件事：署名本身就是传播装置 → 四种可传播的颗粒，四种不同的失真 → 问答体：《素问》八十一篇的排列，就是一份课程表 → 条列体：《伤寒论》二十二篇与《本草经》三百六十五味」这条链。

## 提示词

```
我在学《中医文化传播学》第 2 章「能传走的是判据，不是神医」，本章 6 节 / 2,816 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 署名不能当断代
   - 条列体的完整性是假象
   - 医案只能示理，不能示效
   - 人物叙事有上限
   - 本章不复述具体方药剂量
4. 本章自陈的边界（不得越过）：
   - **署名不能当断代。** 汉志七家医经里三家托名，托名书不是伪书，但不能用作年代证据。凡引「黄帝曰」，必须同时说明这是哪部书、大致成书于何时。
   - **条列体的完整性是假象。** 二十二篇、三百六十五味看着齐整，齐整的是编排，不是覆盖。数字的整齐容易让人误以为体系已经封闭。
   - **医案只能示理，不能示效。** 未经纳入标准筛选的个案，其价值在于展示一种思路如何落地，不在于证明这种思路优于别种。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，不构成医学意见、诊断或治疗指导；具体操作以现行规范与所在机构制度为准。
