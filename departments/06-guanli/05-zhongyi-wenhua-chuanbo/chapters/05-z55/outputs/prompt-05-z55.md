# 传播的底线不是说得动人，是说得住回查 · 提示词

## 用途

给「传播的底线不是说得动人，是说得住回查」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三类失真，三套判据 → 证据分层：四种材料，各证各的，不能互顶 → 个案为什么不能当疗效 → 能说到哪一层：把表述分成三级」这条链。

## 提示词

```
我在学《中医文化传播学》第 5 章「传播的底线不是说得动人，是说得住回查」，本章 5 节 / 2,740 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 都能通过一句准确的限定语被拦住
   - 专家共识与指南
   - 不是一条直线上的高低
   - 个案这种材料，在原理上无法区分这两种情况
   - 第一级：述而不评
   - 第二级：述而有限
4. 本章自陈的边界（不得越过）：
   - **限定语会降低传播效率。** 加了「在某某条件下」的句子，完播率一定不如斩钉截铁的句子。这是成本，必须认。省掉它的代价是读者按错的条件去用。
   - **三级表述不能混着用。** 一段文字里若同时出现「古书说」与「我建议」，读者会分不清哪句是文献、哪句是主张。要么分段，要么明确标注。
   - **证据分层不是排名。** 说「经典不是疗效证据」，不等于说经典无价值；它的价值在认识史与判据来源。反过来，有研究支持也不等于可以外推到所有人。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，不构成医学意见、诊断或治疗指导；具体操作以现行规范与所在机构制度为准。
