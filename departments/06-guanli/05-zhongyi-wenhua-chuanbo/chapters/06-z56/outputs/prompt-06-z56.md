# 把中医讲成奇迹，是最快也最贵的一种传播 · 提示词

## 用途

给「把中医讲成奇迹，是最快也最贵的一种传播」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「奇观叙事的三件套 → 可译性的三个硬点 → 四类典型误读 → 媒介的选择，就是条件的选择」这条链。
