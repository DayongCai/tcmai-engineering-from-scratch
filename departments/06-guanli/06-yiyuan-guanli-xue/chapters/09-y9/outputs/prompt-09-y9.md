# 中医院的难题不是多挂一块牌子，是让两套疗效判据互相承认 · 提示词

## 用途

给「中医院的难题不是多挂一块牌子，是让两套疗效判据互相承认」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「文化的三层：口号停在哪一层 → 医德医风：把准则变成可核查的行为 → 科室设置的双轨：同一个病，两个科 → 优势病种：从“能治”到“可重复”」这条链。

## 边界

本章为教学材料，讨论医院文化、医德医风与中医医院管理的结构问题，不构成诊疗意见、疗效评价结论或政策解读；具体操作以现行规范与所在机构制度为准。
