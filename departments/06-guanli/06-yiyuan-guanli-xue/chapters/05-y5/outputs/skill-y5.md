# 质量指标可以修饰，质量成本修饰不了

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- （人员、设备、制度、床位、资质）、
- （该做的做了没有、做得对不对）、
- 中医治疗的“结果”往往滞后且难以归因
- 什么时候必须启动、谁负责、记录在哪里
- 上级医师查房记录中是否出现了下级没有的判断
- 与会诊意见的

## 边界

- **本章不给指标阈值。** 死亡率、感染率、上报率、入径率的合理区间随级别、专科、病种差异极大，须以国家质量安全改进目标、专业质控指标与本院基线为准。
- **质量与成本的统一有条件。** “提高质量能降低成本”在某些环节成立（减少返工、缩短住院日），在另一些环节不成立（增加人力、增加筛查）。把前者当普遍规律，会导致对质量的投入被长期低估。
- **财务数据有口径陷阱。** 收入是否含财政补助、成本是否含分摊、人员支出是否含编外，三项口径不同，结论可以完全相反。
- 本章为教学材料，讨论医疗质量管理与医院财务管理的框架与指标逻辑，不构成审计意见、财务报告或质量认证结论。
