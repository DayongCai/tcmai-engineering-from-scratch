# 质量指标可以修饰，质量成本修饰不了 · 提示词

## 用途

给「质量指标可以修饰，质量成本修饰不了」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三层结构：结果好不等于质量好 → 核心制度：制度是触发条件，不是条目 → 上报率悖论：低上报是坏信号 → 临床路径：变异不是失败，是信息」这条链。

## 边界

本章为教学材料，讨论医疗质量管理与医院财务管理的框架与指标逻辑，不构成审计意见、财务报告或质量认证结论；具体操作以现行规范与所在机构制度为准。
