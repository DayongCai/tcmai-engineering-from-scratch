# 组织图画的不是权力，是签字与担责的错位 · 提示词

## 用途

给「组织图画的不是权力，是签字与担责的错位」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「四种结构，只有一种矛盾是你能承受的 → 双头指挥：护理垂直管理与科室属地管理 → 决策、执行、监督：三条线不能合成一条 → 人力：编制、岗位与配置的三本账」这条链。

## 边界

本章为教学材料，讨论医院组织结构、权责划分与人力资源管理的分析框架，不构成管理咨询意见或人事处理依据；具体操作以现行规范与所在机构制度为准。
