# 设备的账不在买贵了，在用坏了没人认 · 提示词

## 用途

给「设备的账不在买贵了，在用坏了没人认」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「六段生命周期，每一段都有一个失效点 → 效益分析：把“感觉有用”变成可核的数 → 建筑与流程：布局是最贵的制度 → 安全与后勤：外包不等于免责」这条链。

## 边界

本章为教学材料，讨论后勤保障、医学装备与科教管理的框架，不构成设备采购、工程建设、伦理审查或科研管理意见；具体操作以现行规范与所在机构制度为准。
