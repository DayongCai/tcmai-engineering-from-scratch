# 规范进不了诊室的那一步 · 提示词

## 用途

给「规范进不了诊室的那一步」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三层规范，效力递减而具体度递增 → 个体化与标准化：不是二选一 → 病历：唯一能自证的证据 → 知情同意：中医场景里的四个高风险点」这条链。

## 边界

本章为教学材料，讨论中医医疗行为规范与质量安全管理的制度结构，不构成医学意见、诊疗指导或法律意见。临床处置与争议处理须依现行规范、临床路径与所在机构制度，并由具备资格的人员承担；具体操作以现行规范与所在机构制度为准。
