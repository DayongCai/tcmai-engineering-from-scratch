# 技术跑在规则前面，救济跟在后面 · 提示词

## 用途

给「技术跑在规则前面，救济跟在后面」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「技术介入的三个档位 → 互联网中医：三个管辖问题 → 健康数据：敏感信息的三条红线 → 救济的四条路」这条链。

```

请按以下顺序带我走：

2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：

4. 本章自陈的边界（不得越过）：
```

## 边界

本章为教学材料，讨论新兴技术在中医药领域应用时的立法空白与权益救济结构，不构成法律意见、技术评估或医学意见。任何具体的合规、诉讼与临床决策，须依现行有效规范并由有权机关或具备资格的专业人员处理；具体操作以现行规范与所在机构制度为准。
