# 两条轨的准入：机构靠一张证，人员靠一条路 · 提示词

## 用途

给「两条轨的准入：机构靠一张证，人员靠一条路」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「机构准入：许可与备案两条轨 → 人员准入：四条路，四种能力画像 → 考核考什么，临床要什么 → 执业范围与地点：三个最容易被忽略的细节」这条链。

## 边界

本章为教学材料，讨论中医药机构与人员准入的制度结构，不构成法律意见或执业指导。具体的登记、备案、考核、执业范围认定，须依现行有效规范并由有权机关处理；具体操作以现行规范与所在机构制度为准。
