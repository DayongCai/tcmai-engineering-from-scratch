# 罚则写在纸上，执法站在门外 · 提示词

## 用途

给「罚则写在纸上，执法站在门外」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「从规范到处分，要过四道门 → 三支队伍与两个空档 → 查什么：证、人、药、记录 → 罚则的三种失效」这条链。

## 提示词

```
我在学《中医药政策与法规》第 2 章「罚则写在纸上，执法站在门外」，本章 5 节 / 3,119 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 把执法讲细，容易让人误以为「严罚就能治好」
   - 专项治理的成效容易被高估
   - 本章不引具体条文序号与法规全称
   - 文中数字除注明外均为演算设定
   - 本章讨论监管结构与责任分配，不是办案指引
4. 本章自陈的边界（不得越过）：
   - **把执法讲细，容易让人误以为「严罚就能治好」。** 罚则的作用边界在发现率与认定率。发现不了、认定不下的违法行为，罚则再重也不产生行为约束；反过来，发现率高、认定标准清楚的领域，即使罚则不重，行为也会收敛。监管能力是分母，罚则是分子。
   - **专项治理的成效容易被高估。** 专项期间查出的案件数上升，往往反映的是检查密度上升，不是违法率上升。用案件数评价监管成效，会诱导基层把力量放在容易成案的简单违法上，而不是放在后果最重的复杂违法上。
   - **本章不引具体条文序号与法规全称。** 处罚的种类、幅度与程序在修订中变化较快，且不同层级规范之间常有细化与衔接；凡涉及具体裁量，以现行有效文本与本地裁量基准为准。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，讨论中医药监督执法与行政责任的一般结构，不构成法律意见或办案指导。任何具体的处罚、复议、诉讼事项，须依现行有效规范并由有权机关或具备资格的专业人员处理；具体操作以现行规范与所在机构制度为准。
