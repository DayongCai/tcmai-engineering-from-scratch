# 第 4 章 · 效果评价的分水岭在视角：站错立场，同一措施会得出相反结论

> **MOTTO:** 「足国之道，节用裕民，而善臧其余。」——《荀子·富国》
>
> **PROBLEM:** 同一项「日间手术替代住院手术」的改进，医院算出来的结论是「不划算」：单例收入下降 3,200 元，床位空出来了但成本没降。医保基金算出来的结论是「很划算」：单例支付减少 3,200 元，且不需要新增床位。患者算出来的结论是「划算」：少请两天假，少花 600 元陪护。（以上为演算设定）三个结论都对，因为它们站在三个不同的立场上算账。报告如果只写一个，读者就无法判断它替谁作了决定。
>
> **双根因定位:** 环境逼迫（评价报告要交给一个具体的部门，于是自然地采用那个部门的账本；跨部门的账没人有动力去合）+ 知识积累（学过成本-效果分析的计算，没学过「视角决定成本范围」这条前置设定；视角选错，后面每一步都精确地错下去）

**教材出处:** 教材·第12章·1.2–4.3（配置原则与失衡、规划编制与实施、需要量测算、配置标准、资源整合、公平性与可及性测量）与第13章·1.2–4.3（人力供给与培养周期、薪酬与激励、流动与基层人力、配置效率）、第14章·1.2–4.3（改革路径、公立医院经济属性与补偿、分级诊疗、评价框架与挑战）；底本为《卫生经济学》，本章取 33 个单元、48,148 汉字，平均每单元约 1,459 字。

## 一、五步流程：先定视角，再算成本

经济学评价有五个相互衔接、实践中反复迭代的步骤：

1. **明确问题与视角。** 决策问题是什么、目标人群是谁、拟评价方案与对照方案各是什么、关心效果还是效用、时间跨度多长。同时必须确定视角。
2. **确定备选方案。** 方案必须相互替代、现实可行、有临床合理性；对照通常是现行标准做法。
3. **识别与测量成本。** 在既定视角下穷尽应计入的资源，再以自然单位计量、以价格估值。
4. **测量产出。** 按评价类型选效果、效用或货币收益。
5. **比较与决策。** 做增量分析，报告比值与不确定性。

第一步里最容易被跳过、后果最大的是**视角**。四种常见视角的成本范围完全不同：

| 视角 | 计入什么 | 典型用途 |
|---|---|---|
| 社会 | 无论由谁承担的全部资源消耗与产出，含患者负担与生产力损失 | 资源配置的总体判断 |
| 支付方（医保／财政） | 只计其实际支付的部分 | 目录准入、支付标准 |
| 机构 | 只计机构发生的成本 | 科室决策、成本控制 |
| 患者 | 个人承担的费用与获得的结果 | 负担与可及性 |

视角不同，同一项干预的评价结论可能不同，甚至方向相反。一项能显著减少患者误工的服务，在社会视角下会因生产力损失减少而显得更优；在支付方视角下，误工不进入账本，优势就消失了。**所以任何成本-效果结果，脱离视角就没有意义。** 本章默认以社会视角为基准，并视需要报告其他视角。

## 二、成本识别四类与两条原则

经济学意义上的成本是**机会成本**：这些资源被用于本方案后，所放弃的最佳替代用途的价值。这句话决定了识别的两条原则：

- **穷尽**：不遗漏应当计入的项目。
- **无重复**：不把同一项资源在两类成本中重复计算。

按与干预的关系，成本分四类：

| 类别 | 内容 | 常见漏项 |
|---|---|---|
| 直接医疗成本 | 药品、材料、检查检验、手术治疗、床位护理、康复随访、分摊的管理费用 | 处理并发症与不良事件的额外消耗 |
| 直接非医疗成本 | 交通、陪护、营养、住宿 | 家属误工以外的照护支出 |
| 间接成本 | 因病误工与早亡造成的产出损失 | 非正式照护的时间价值 |
| 无形成本 | 疼痛、焦虑、生活质量下降 | 通常难以货币化，宜单独描述 |

测量分两步：先以自然单位计量消耗量，再以价格换算为货币。这个分解的价值在于把「量」与「价」分开审：价格来源与年度口径要单独说明，敏感性分析也能分别调整量与价。

方法上有微观成本法（自下而上，逐项记录，精细但工作量大）与宏观成本法（自上而下，按床日、人次或收入比例分摊，简便但会掩盖差异）。方法的选择要说明理由，并对分摊假设做敏感性分析。

跨年度时还要贴现：把未来各期的成本与产出按贴现率折算为现值。设定一个算例：10 年后发生的 100 万元，按 5% 贴现率折现。

```text
现值 = 100 ÷ (1 + 0.05)^10
     = 100 ÷ 1.6289
     ≈ 61.4 万元
```

贴现率越高，未来收益的权重越低，对疫苗、筛查、慢病长期管理等收益滞后的项目尤其不利。取值必须明示依据，成本与产出是否用同一贴现率也要说明。

## 三、ICER：比值只说相对

成本-效果分析的核心是增量分析：比较拟评方案相对对照方案的增量成本与增量效果，而不是各自的总量或平均值。

```text
ICER = ΔC ÷ ΔE = (C₁ − C₀) ÷ (E₁ − E₀)
```

设定一个教学算例：新方案每例成本 12,000 元、效果 0.8 个健康单位；对照方案 5,000 元、0.5 个单位。

```text
ΔC = 12,000 − 5,000 = 7,000 元
ΔE = 0.8 − 0.5 = 0.3
ICER = 7,000 ÷ 0.3 ≈ 23,333 元／健康单位
```

这个数的含义是：相对对照方案，每多获得一个健康单位需多付 23,333 元。它有四个必须随附的条件——视角、对照方案、时间框架、贴现率。缺一项，这个数就不能被引用；脱离对照方案单独说「ICER 是 23,333」，等于说「比某个未说明的东西贵 23,333」。

阈值是另一个争议点。低于某阈值即认为「值得投入」，这个判断隐含了预算约束与价值取向，不是纯粹的技术结论。把阈值当作客观标准，会把一个分配问题包装成一个算术问题。

成本-效果分析也有明确局限：效果以具体健康单位度量，不同干预的单位不同（挽救的生命年、检出的病例数、避免的并发症数），单位之间没有换算基础。因此它适合同一健康目标下不同方案的比较，难以回答「资源该优先投向哪个病种」。

## 四、QALY 与效用：把质量折进时间

成本-效用分析用效用值把不同性质的健康结果压到同一尺度上。效用值置于 0 与 1 之间，0 对应死亡、1 对应完全健康；某些被评价为比死亡更差的状态可以取负值。

获取方式分直接测量与间接测量，结果不可混用。直接测量有三种：

- **直观类比标度（VAS）**：在 0–100 的刻度上标出偏好位置，简便，但更像主观评分，未必反映真实取舍。
- **时间权衡法（TTO）**：在「较差状态生存较长时间」与「完全健康生存较短时间」之间权衡，找到无差异点。
- **标准博弈法（SG）**：在确定的中等状态与有概率的完全健康／立即死亡之间权衡。

质量调整生命年（QALY）把生命的数量与质量合成一个指标：

```text
QALY = Σ (uᵢ × tᵢ)
```

设定算例：某状态效用值 0.7，持续 2 年，则 QALY = 0.7 × 2 = 1.4；另一方案完全健康 1.5 年，QALY = 1.0 × 1.5 = 1.5。后者更优，尽管前者活得更久。

QALY 的构造嵌入了一组价值假设：效用如何加权、不同人的 QALY 能否直接相加、一元 QALY 是否等值。因此 ICUR（增量成本效用比，单位为货币每 QALY）同样是比值型指标，必须连同假设与敏感性分析一起报告。

## 五、改革成效评价的三重挑战

把上面的方法用在真实政策上，会遇到三个绕不开的困难。

**数据可比性。** 改革在不同地区、不同时间以不同方式推进，统计口径与信息系统存在差异；政策实施前后，口径本身也可能调整。跨期比较前要做口径还原，并对变化作出说明。

**因果识别。** 改革不是随机分配的，试点地区与对照地区在财力、资源禀赋与治理能力上本就有系统差异；改革又常与其他政策同时发生。简单的前后比较或横向比较会高估或低估效应。准实验方法（双重差分、断点回归、倾向得分匹配）可以缓解，但依赖较强假设，结论要连同假设一起写。

**结果的多因性。** 健康结果与费用变化受人口结构、疾病谱、技术进步、经济水平、生活方式与多项政策共同影响。把某一指标的变化全部归给一项改革，是最常见的过度归因。

评价框架本身可以更稳一些：从可及性、费用、质量、效率四个维度设指标，每个指标注明口径与来源。可及性要区分地理可及与经济可及——看得见而负担不起，与负担得起而到不了，政策含义完全不同。费用要区分名义增长与实际增长。质量要看安全、有效、及时、以患者为中心与公平。效率要区分技术效率（给定投入下产出是否最大）与配置效率（资源是否流向回报最高的环节）。

## 六、代价与边界

- **评价本身消耗资源。** 一次规范的经济学评价需要成本数据、效果数据与建模，工作量往往超过被评价的干预本身。因此评价应聚焦于「决策真的有选择余地」的问题；没有备选方案的评价，只是记账。
- **效率证据不等于决策。** ICER 反映资源使用效率的相对高低，是否投入还取决于预算约束、价值取向与公平考量。把比值当作结论，是把决策责任推给算式。
- **不得以效率之名压缩法定权益。** 人力配置、排班与外包的调整，不能突破劳动报酬、休息休假、职业安全卫生与社会保险的底线。以「优化配置」为名的超负荷排班，既违背法律，也损害服务质量。
- **评价结果不得用于对机构与个人的简单排名。** 不同机构的业务规模、基础条件与发展阶段差异很大，排名会把结构性差异读成能力差异。
- 文中的 3,200 元、600 元、12,000／5,000 元、0.8／0.5 个单位、23,333 元与 5% 贴现率均为教学设定，用于演示增量分析与贴现的算法，不对应任何真实机构与真实价格。
