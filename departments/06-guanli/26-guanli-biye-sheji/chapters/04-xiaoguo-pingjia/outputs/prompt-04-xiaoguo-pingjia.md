# 效果评价的分水岭在视角：站错立场，同一措施会得出相反结论 · 提示词

## 用途

给「效果评价的分水岭在视角：站错立场，同一措施会得出相反结论」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「五步流程：先定视角，再算成本 → 成本识别四类与两条原则 → ICER：比值只说相对 → QALY 与效用：把质量折进时间」这条链。

正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 明确问题与视角
   - 确定备选方案
   - 识别与测量成本
   - 比较与决策

4. 本章自陈的边界（不得越过）：
   - **评价本身消耗资源。** 一次规范的经济学评价需要成本数据、效果数据与建模，工作量往往超过被评价的干预本身。因此评价应聚焦于「决策真的有选择余地」的问题；没有备选方案的评价，只是记账。

## 边界

本章讨论效果评价的视角设定、成本识别与增量分析方法，属管理教学方法内容，不构成诊疗意见、不构成投资或定价建议，也不构成对任何政策效果的认定。具体评价须依现行方法学规范执行，数据使用须符合授权与保密要求；具体操作以现行规范与所在机构制度为准。
