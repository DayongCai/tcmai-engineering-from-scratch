# 指标不写清分子与分母，后面每个分析都在自证 · 提示词

## 用途

给「指标不写清分子与分母，后面每个分析都在自证」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「二手数据的三道检验：口径、覆盖、可比 → 抽样：概率与非概率的分野 → 核查四法与异常值的双判据 → 频数分布：五步编表与三个特征」这条链。

## 提示词

```
我在学《管理毕业设计与知识移交》第 2 章「指标不写清分子与分母，后面每个分析都在自证」，本章 7 节 / 3,024 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 每个观察单位被抽中的概率是否已知或可计算
   - 用了就必须在方法部分写清它不能被用于推断
   - 样本量要在设计阶段估算，不能在数据到手后倒推
   - 依据专业知识判断某值是否可能（身高 17 厘米显然录错）
   - 选择哪个指标取决于分布形态，不能一律用均数
   - 数据与标题不符
4. 本章自陈的边界（不得越过）：
   - **口径统一要花时间，而且花在最不显眼的地方。** 一个指标的定义可能要拉着两三个科室对半天。省下这半天，代价是后续每一次比较都要重吵，或者更糟——没人吵，直接比。
   - **概率抽样的结论只能推回抽样框覆盖的总体。** 从一家医院抽的样本，推不到全省；从住院患者抽的样本，推不到全部患者。把范围说小不减分，说大一定被追问。
   - **异常值不都是错误。** 真实的极端值往往是最有信息量的观测（超长住院日、极端费用），删掉它等于删掉了问题本身。处置原则是：先核实、再判断、后记录，能保留就保留并单独说明。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章讨论毕业设计中的数据获取、指标定义、核查与图表规范，属管理教学方法内容，不构成诊疗意见、不构成统计咨询意见。涉及患者个人信息的数据，须依现行个人信息保护与伦理审查规定，在授权范围内、按最小必要原则使用；具体操作以现行规范与所在机构制度为准。
