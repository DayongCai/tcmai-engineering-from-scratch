# 选方法不是选结果好看的，是选资料允许的那一个 · 提示词

## 用途

给「选方法不是选结果好看的，是选资料允许的那一个」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「参数与非参数：三条判据 → 编秩的三条硬规则 → 相关与回归：r 与 b 的分工 → 相关不等于因果：四种来源与四条排除」这条链。

## 提示词

```
我在学《管理毕业设计与知识移交》第 3 章「选方法不是选结果好看的，是选资料允许的那一个」，本章 6 节 / 2,753 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 判据一：分布假定是否满足
   - 分析所依据的量
   - 判据二：变量的数据类型
   - 判据三：样本量
   - 先跑一种、不行再换
   - 规则一：混合编秩
4. 本章自陈的边界（不得越过）：
   - **换方法换不出结论。** 事先定方法、事后照报，是唯一站得住的流程。若确实发现前提不满足，正确做法是在方法部分说明「原计划用某方法，因某前提不满足改用某方法」，并同时报告两种结果。
   - **非参数方法不要求正态，但要求别的。** 它假设两组分布形状相似（成组比较时），并要求观测独立。看到「非参数」就以为「无假设」，是另一种误解。
   - **回归方程不能替代专业判断。** 一个统计上显著的回归系数，可能对应一个临床上毫无意义的变化幅度。效应量、置信区间与专业阈值三者要一起看。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章讨论统计方法的选择判据、编秩规则与相关回归的报告规范，属管理教学方法内容，不构成诊疗意见、不构成统计咨询意见。具体方法的选择与结果解释，以现行统计学教材、研究报告规范与所在院校要求为准；具体操作以现行规范与所在机构制度为准。
