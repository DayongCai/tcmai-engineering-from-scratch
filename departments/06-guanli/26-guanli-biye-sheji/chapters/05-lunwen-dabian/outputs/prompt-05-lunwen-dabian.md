# 答辩不是复述结论，而是当场交代结论的适用条件 · 提示词

## 用途

给「答辩不是复述结论，而是当场交代结论的适用条件」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「一段可用的论证，结构上像一条能执行的条文 → 事实判断与价值判断必须分开写 → 枚举与限定：把「等」字写实 → 答辩现场的五个追问与应答」这条链。

## 提示词

```
我在学《管理毕业设计与知识移交》第 5 章「答辩不是复述结论，而是当场交代结论的适用条件」，本章 6 节 / 2,861 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 条文结构与限定方式
   - 如果我的结论是错的，别人怎么知道？
   - 把「我观察到」写成「事实是」，把「我认为应该」写成「研究表明」
   - 实践的正当性、防护的最优化、个人剂量限值
   - 凡结论依赖一组条件，就把这组条件列全，不要用「等因素」收尾
   - 追问一：样本是怎么来的？
4. 本章自陈的边界（不得越过）：
   - **限定写多了会显得结论弱。** 这是真实的代价：一篇通篇「在……条件下」的论文，读起来不如一篇斩钉截铁的论文有气势。但评审的判断标准恰恰相反——限定准确，说明作者知道边界在哪；没有限定，说明作者还没想清楚。
   - **条文结构只是骨架，不能替代内容。** 把论证套进「命题—证据—边界」的模子，不会让一个没有数据的题目变得有数据。结构能防止遗漏，不能创造发现。
   - **本章不涉及具体法律适用。** 底本条文用于说明写作结构，不构成对食品安全、职业病防治、放射防护等具体事项的法律意见；相关判定以现行法律文本与主管部门规定为准。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章讨论毕业设计论文的论证结构、限定写法与答辩准备，属管理教学方法内容，不构成诊疗意见、不构成法律意见。文中引用的法律条文仅用于说明写作结构；具体操作以现行规范与所在机构制度为准。
