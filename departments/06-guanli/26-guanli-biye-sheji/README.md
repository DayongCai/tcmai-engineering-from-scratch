## 九、本系实例（替代指标）

> 本系不对外销售软件，「客户数 × 客单」不适用。改用**人力成本法**：工具节省的工时折成钱，再按分成定价。
> 这是「不适用」的正确解法——不是不算，是换一种算。跑 `python scripts/build_biye_altside.py` 可复算。

**产品**：统计口径对齐 ＋ 覆盖度双维报表（破立验证 ＋ 自动门禁）
**三个可交给学生的题目**：统计口径比对脚本、覆盖度双维报表、政策条文挂点库

### 第 2 项 · 客户数与使用人数

| 项 | 值 |
|---|---|
| 客群 / SAM | 中医类医院 / 6,498（S1） |
| 渗透带 / 成熟度 | 1.0%–10.0% ／ **0.15** |
| 客户数 | **54 家**（隐含渗透 0.831%） |
| 单位使用人数 | 1.5 人/机构（假设） |
| 依从率 | **80%**（假设） |
| 每例节省工时 | 72 小时/人/年（假设） |
| 时薪锚 | S18：119,465 元/年 ÷ 2000 工时 → **59.73 元/小时** |
| **每客户年节省价值** | **¥5,161** |

### 第 3 项 · 客单（按价值定价，而不是按成本加成）

| 项 | 值 |
|---|---|
| 定价路径 | 一次咨询包 3 万元（价值法不成立，改用人工交付定价） |
| 客单 | **¥30,000 / 年** |
| 客单占节省价值 | 38.75%（判定：带内） |

### 两种定价路径（本系的真问题）

| 路径 | 客单 | 回本 | 结论 |
|---|--:|--:|---|
| 价值分成 35% | ¥2,000 | 232.8 月 | 不成立：客单 1,000–2,000 元，覆盖不了产品化成本 |
| 一次咨询包 | ¥30,000 | 15.5 月 | 成立但不可复制：每家需现场咨询，人力交付为主 |

**结论**：管理工具省下的工时太少（每院年约 ¥5,161），按价值分成定价必然不成立；能成立的只有「一次咨询包」，而咨询包靠人力交付，不具复制性。**这门毕设的正确写法不是「做一个 SaaS」，而是「做一套可复用的口径 + 三次现场咨询的记录」。**
