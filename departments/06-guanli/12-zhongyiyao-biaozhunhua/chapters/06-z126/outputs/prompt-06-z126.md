# 走出国门的标准，先要学会翻译自己 · 提示词

## 用途

给「走出国门的标准，先要学会翻译自己」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「对接有三种模式，义务完全不同 → 翻译的四类难点，各有不同的解法 → 译名的三条判据 → 定义句的语法：一句话要经得起翻译」这条链。

## 提示词

```
我在学《中医药标准化》第 6 章「走出国门的标准，先要学会翻译自己」，本章 8 节 / 2,966 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 采纳：原样采用国际文件，本国标准与其在技术内容上一致，差异只允许出现在编辑性表述上
   - 三种模式的差别不在姿态，在法律与贸易后果：声明「采纳」就意味着要为该国文件的全部条款背书，将来出问题没有「这是别人写的」这条退路；声明「参照」则保留了自主空间，但也失去了互认的资格
   - 中医药术语的外译，不是语言问题，是概念问题
   - 译名之争常变成口味之争，其实可以落到三条判据上
   - 标准里的定义，最终要进外文文本
   - 第三，术语在句内首次出现时给上位概念
4. 本章自陈的边界（不得越过）：
   - 本章不引具体国际标准编号、发布年份与条款号；涉及国际组织与技术委员会的表述一律到「组织—文件类型」这一层，不落编号。
   - 音译有真实代价：学习成本抬高，传播速度放慢。判据是「误读后果是否涉及安全」，不是「哪个更好听」。
   - 对接的代价是双轨维护。国际码与国内码并行，意味着每次改版都要维护两张表、两次培训、两套校验；这笔钱必须事先算进预算，否则双轨会在第三年退化成「只维护国内那套」。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为标准国际化与术语翻译的教学讨论，不构成注册申报、进出口贸易或临床用药建议；具体操作以现行规范与所在机构制度为准。
