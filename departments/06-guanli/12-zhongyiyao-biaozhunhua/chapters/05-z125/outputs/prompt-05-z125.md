# 一张古方的标准，卡在「一两」是多少克 · 提示词

## 用途

给「一张古方的标准，卡在「一两」是多少克」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「标准化的对象是三件，不是一件 → 剂量：三重不确定，三条路线 → 炮制：方中的「半夏」到底是哪一种 → 煎服法：古方里最具体的一段，也最容易被跳过」这条链。

2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 名方的标准不是「一个组成表」
   - 常见做法是先定组成，再补炮制与煎服法，结果往往返工
   - 古方剂量的不确定来自三处
   - 三条路线不可能同时满足，标准必须择一，并写明依据
   - 也要承认一件事：标准只能锁一个值，而学界有两派
   - 古方写药名，常不写炮制；今人读方，必须补上这一层
4. 本章自陈的边界（不得越过）：

   - 择一有代价。标准选定一派折算，另一派的临床经验就被排除在标准之外；这不是否定，是标准文本的容量限制，须在编制说明里写明，让分歧可见。
   - 基准样品不等于疗效证据。它保证「批次之间一样」，不保证「这一批有效」；疗效评价是另一套方法，见第 8 章。

本章为名方标准化方法的教学讨论，不构成诊疗、处方、剂量或药品质量判定建议；具体操作以现行规范与所在机构制度为准。
