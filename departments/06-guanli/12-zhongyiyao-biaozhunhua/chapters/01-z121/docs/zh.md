# 第 1 章 · 标准化的第一刀，切在名词上

> **MOTTO:** 「名有固善，径易而不拂，谓之善名。」——《荀子·正名》
>
> **PROBLEM:** 一张中药处方，在医生工作站、药房发药、医保结算与省级上报四个环节各有一套药名：医生写「法半夏」，药房按「制半夏」发药，结算系统认「半夏（制）」，上报口径又回到「半夏」。四套名字背后是同一味药，但没有一套系统能证明它们是同一味药。演算一下：一所年门诊中药处方十八万张的中医院，平均每张十二味药，一年就是二百一十六万条处方明细；若每条明细人工核对一次名称，按每条八秒计，仅核对一项就是四千八百小时，约合两个半人的全年工时（按每人每年两千小时计）。核对不了的那部分，正是差错滋生的地方。

**双根因定位:** 环境逼迫（院内、药房、结算、上报四套词表各有各的维护方，谁先改，谁先在自己的报表上出现断裂，于是谁也不肯先改）+ 知识积累（本章底本二十二单元、三万一千余汉字，讲的是卫生信息管理的一般框架，术语条目的内部结构一句未及——这一章只能靠词表工程的通行做法补，不能靠教材转述）

## 一、术语条目不是词典条目

词典回答「这个词怎么用」，术语标准回答「这个概念只能这样叫」。差别落在可判定性上：词典可以并列三个义项，术语条目必须交出唯一所指。一条能用的中医术语条目通常要写全七项：条目编号、首选中文名、对应外文名、定义、许用同义词、禁用词、上位概念。七项里最容易被省略、也最不能省的是「禁用词」。没有禁用词，条目只是在推荐一个好名字，没有关掉坏名字的入口；而实际工作中，坏名字往往比好名字生命力更强，因为它活在旧病历、旧模板和师傅的口头里。

定义的写法有一条老规矩：属加种差，先归上位，再写差别。「饮片」不能定义成「加工过的药材」——「加工过」没有交代加工到哪一步、有没有改变药性，边界等于没画。写成「药材经净制、切制或炮炙后，直接用于调配或制剂的加工品」，线就出来了：净制算、切制算、炮炙算，提取物不算，配方颗粒也不算。定义的价值不在好看，而在能不能替人做判断：两个东西摆在面前，照定义能分出是不是。

还有一条硬约束：定义里不许出现被定义词，也不许出现它的同义词。这条看似迂腐，实际是筛掉循环定义的唯一办法。「证候是机体在疾病过程中某一阶段邪正关系的病理概括」是合格的；「证候即中医的证」不合格，它把问题原样退回给读者。

## 二、四种歧义，四种修法

| 歧义类型 | 现场例 | 该在哪一层修 |
|---|---|---|
| 同形异义（同名异物） | 「木通」兼指关木通与川木通 | 基原字段与品种码，名称层修不了 |
| 异形同义（一物多名） | 「消渴」「消瘅」「糖尿病」混用 | 首选词 + 同义词映射 |
| 上下位混用 | 「证」「症」「证候」当同义词 | 分层建模，禁止同级互替 |
| 粒度不一 | 「脾虚」「脾气虚」「脾胃虚弱」并用 | 锁死最小可判定单位 |

四类里最危险的是第一类。把「同名异物」当「异名同物」处理，等于在映射表里加一行别名，两味药就合成了一味——这不是术语学问题，是安全问题。木通是最常被举的例子：关木通与川木通长期混称，前者含马兜铃酸、后者不含，名称层面无法区分，只能靠基原字段与品种码把它们分开。贝母同理：川贝母与浙贝母功效方向不同，一个偏润、一个偏散，共用「贝母」二字时，任何基于名称的统计都会把两种用法混成一堆。

第二类「异形同义」看似无害，其实决定了能不能统计。消渴、消瘅、糖尿病三个词出现在同一批病历里，若不归并，病种分布就是三条互不相干的曲线；若粗暴归并，又会把中医病名与西医病名当成同一概念——它们的外延并不重合：中医的消渴包含一部分非糖尿病的高代谢状态，西医的糖尿病包含一部分无典型消渴表现的患者。正确做法不是合并，而是「首选词 + 双向映射 + 允许无对应」，映射关系必须能表达「部分重叠」这一档。

第三类是层级错误。「证」「症」「证候」在日常语言里常被当同义词，在模型里是三层：症是单个表现，证是若干表现的组合判断，证候是证的外延集合。三者同级互替，后果是所有按「证」统计的报表都在混着数症。第四类是粒度不统一，「脾虚」「脾气虚」「脾胃虚弱」同时使用，又没有规则说明谁包含谁。粒度问题靠映射解决不了，只能事先锁死最小可判定单位：一条记录只允许填到一个规定粒度，粗粒度用上位词，不许自造中间层。

## 三、术语表落成表结构，才算真的有了标准

术语标准最常见的失败形态是「发布了、装订了、没人用」。要让它进入系统，得把它落成三张表：概念表、同义词表、映射表。

```sql
CREATE TABLE term (
  term_id    TEXT PRIMARY KEY,   -- 概念号，不是名称
  pref_label TEXT NOT NULL,      -- 首选词，全局唯一
  definition TEXT NOT NULL,
  parent_id  TEXT REFERENCES term(term_id),
  status     TEXT CHECK (status IN ('现行','废止','草案'))
);

CREATE TABLE alias (
  term_id TEXT NOT NULL REFERENCES term(term_id),
  label   TEXT NOT NULL,
  kind    TEXT CHECK (kind IN ('许用','禁用','历史')),
  PRIMARY KEY (term_id, label)
);
```

三处细节值得停一下。第一，主键用概念号。名称会改，概念号不改；一旦拿名称做主键，改一次首选词就要改所有外键，实务中没人敢改，标准于是冻在原地。第二，同义词要带类型。许用的进下拉候选，禁用的进拦截规则，历史的只用于回溯旧数据——三类混在一张表里、不加类型字段，等于把「可以这样叫」和「不许这样叫」写成同一句话。第三，禁用词也要入库。很多单位只维护推荐词，结果系统拦不住任何东西；拦截靠反向查表：命中禁用词就提示首选词并记录原始输入。这一步比发一份 PDF 有用得多。

把这三张表接进录入端，才会出现真正的变化：医生敲「法夏」，系统补全为「法半夏」并留下原始输入；敲「关木通」，系统按基原字段要求补选品种。前者是体验，后者是安全。

## 四、三个检验，判一条定义合不合格

术语评审常流于「大家念一遍，没人反对就过」。有三个可操作的检验，能把争论落到具体句子上。

替换检验：把定义里的关键词换成同级概念，看定义是否还成立。若换成任何同级词都成立，说明它只写了上位、没写种差。「饮片是中药材的一种加工品」——换成「中成药」「提取物」也成立，故不合格。

反例检验：找三个「像但不是」的例子，看定义能否把它们排除。对「饮片」，反例是配方颗粒、超微粉、提取物；若排除不掉，就得补条件。

边界检验：找两个相邻概念，看定义是否在两者之间画出线。饮片与「中药材」的界线在「是否经净制、切制或炮炙」；饮片与「制剂」的界线在「是否直接用于调配」。画不出线的定义，在系统里就无法做互斥校验。

三个检验不解决学术分歧，但能把分歧压缩到一句话上——评审时争那一句，比争整段有效率。

## 五、术语管名，分类管位，两件事不能互相顶班

术语标准与分类标准常被当成一件事，其实是两件。术语回答「这个概念叫什么」，分类回答「这个概念放在哪个格子里」。术语不要求穷尽，分类必须互斥且穷尽；术语允许一个概念有多个许用名，分类必须给唯一归属。

混用有两种典型后果。一种是用分类层级当定义：「气虚证属于虚证类」——这是位置，不是含义，读者仍不知道什么算气虚。另一种是用术语表当分类表：同一概念有几个许用名时，不同科室按不同名字归类，同一批病案就分进了两个格子。正确关系是分层：术语层定名与义，分类层定唯一归属，两层之间用「概念—类目」映射连接，映射允许多对一，但不允许多对多而无约束。

中医药的术语还有一层特殊困难：古籍异名不能靠现代词表强行归一。《素问·痿论》里的「痿」与后世「痿证」外延不同，若按现行首选词一律改写，原文的层次就丢了。可行做法是「原文不动 + 标注现代对应」，把归一留在检索层，不改写文本。

## 六、条目从哪里来：三源合一，一条取舍

术语条目不会凭空长出来，实际来源只有三处：古籍与经典、现行教材、真实病历。三处的产出性格完全不同。

古籍给的是「有出处但外延古旧」的词。它的优势是每个词都能追到原文，劣势是同一个词在不同朝代指不同事。教材给的是「已经折中过的词」，通常已经做过一轮归一，边界清楚，但会丢掉流派差异。病历给的是「活着的词」，能反映真实叫法，缺点是错字、简写、方言混在一起，且分布极偏——十几味常用药能占掉大半条目，冷僻品种几年才出现一次。

工程上的取舍是：以教材条目为骨架，以古籍条目补义项与出处，以病历词频定优先级。落到数上，一所中医院三年的门诊病历，去重后的中药名通常在数千条量级，而能进首批术语表的只是其中高频的一小部分；先把这一小部分做扎实，比一次铺开上万条更有效。条目评审也不必全量开会：按「出现频次 × 涉及风险（毒性、配伍禁忌、基原混淆）」排序，前若干条逐条过，其余走批量抽检。这样安排的理由很实在——高频词的错误每天都在复制，低频词的错误一年也撞不上几次。

## 七、代价与边界

- 本章不引具体标准编号与发布年份；凡涉标准文本，一律以现行有效版本为准，本章只讨论条目结构与工程做法。
- 术语统一有真实成本。封闭首选词会挡住临床习惯叫法，医生为此多点三次下拉，就会绕开系统改用自由文本。对策是同义词「许用」而非一律禁用，把成本压在少数真危险的同形异义上。
- 术语表不解决真伪。它能保证「同一个名字指同一个概念」，不能保证「这批药材就是那个基原」；后者要靠基原鉴定与品种码，见第 3、4 章。
- 本章不评价任何具体术语标准文本的优劣，也不构成临床、药事或监管符合性建议。
