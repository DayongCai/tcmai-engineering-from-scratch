# 标准化的第一刀，切在名词上 · 提示词

## 用途

给「标准化的第一刀，切在名词上」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「术语条目不是词典条目 → 四种歧义，四种修法 → 术语表落成表结构，才算真的有了标准 → 三个检验，判一条定义合不合格」这条链。

## 提示词

```
我在学《中医药标准化》第 1 章「标准化的第一刀，切在名词上」，本章 6 节 / 3,061 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据请从小节标题与正文段落中自行提取，不要补充正文没有的内容；
4. 本章自陈的边界（不得越过）：
   - 本章不引具体标准编号与发布年份；凡涉标准文本，一律以现行有效版本为准，本章只讨论条目结构与工程做法。
   - 术语统一有真实成本。封闭首选词会挡住临床习惯叫法，医生为此多点三次下拉，就会绕开系统改用自由文本。对策是同义词「许用」而非一律禁用，把成本压在少数真危险的同形异义上。
   - 术语表不解决真伪。它能保证「同一个名字指同一个概念」，不能保证「这批药材就是那个基原」；后者要靠基原鉴定与品种码，见第 3、4 章。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为术语工程与词表设计的教学讨论，不构成诊疗、用药或标准符合性判定建议；具体操作以现行规范与所在机构制度为准。
