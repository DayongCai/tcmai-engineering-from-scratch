# 操作规范写在纸上，扎针的手不会自己变标准

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 若干 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 边界

- 本章不引具体技术操作标准的编号与年份；所举参数（深度、时长、样本量）用于说明写法，不作为临床执行依据。实际操作一律以现行发布的技术规范与机构规程为准。
- 可观察化有代价。把「得气」拆成代理指标，会让一部分真实有效的操作被判为「未达标」；把手法参数区间写窄，会挤压流派空间。这些代价要在编制说明里承认，不能假装没有。
- 结构化记录有代价。字段越多，医生填得越慢，绕过的动机越强。字段数量应当由「能不能用于判定」倒推，而不是由「想不想知道」正推。
- 本章为技术操作规范编写与流程嵌入的教学讨论，不构成具体操作指导、诊疗建议或合规意见。
