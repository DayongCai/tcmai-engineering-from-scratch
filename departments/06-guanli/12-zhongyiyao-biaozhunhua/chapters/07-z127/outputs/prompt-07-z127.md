# 操作规范写在纸上，扎针的手不会自己变标准 · 提示词

## 用途

给「操作规范写在纸上，扎针的手不会自己变标准」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「六要素：缺一件，规范就不可执行 → 可观察化：三级台阶，一级都别跳 → 规范进流程：三个嵌入点 → 培训解决「知道」，符合率靠闭环」这条链。

## 提示词

```
我在学《中医药标准化》第 7 章「操作规范写在纸上，扎针的手不会自己变标准」，本章 7 节 / 2,763 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 一套可执行的技术操作规范，通常要写全六件事
   - 适应症与禁忌：谁可以做、谁不能做
   - 体位与暴露：体位决定取穴的准确性，暴露范围决定消毒与安全
   - 手法参数：角度、深度、频率、时长、补泻操作
   - 疗程与间隔：几次为一疗程、间隔多久、最多几个疗程
   - 不良事件处置：晕针、断针、烫伤、出血、感染的处理步骤与上报路径
4. 本章自陈的边界（不得越过）：
   - 本章不引具体技术操作标准的编号与年份；所举参数（深度、时长、样本量）用于说明写法，不作为临床执行依据。实际操作一律以现行发布的技术规范与机构规程为准。
   - 可观察化有代价。把「得气」拆成代理指标，会让一部分真实有效的操作被判为「未达标」；把手法参数区间写窄，会挤压流派空间。这些代价要在编制说明里承认，不能假装没有。
   - 结构化记录有代价。字段越多，医生填得越慢，绕过的动机越强。字段数量应当由「能不能用于判定」倒推，而不是由「想不想知道」正推。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为技术操作规范编写与流程嵌入的教学讨论，不构成具体操作指导、诊疗建议或合规意见；具体操作以现行规范与所在机构制度为准。
