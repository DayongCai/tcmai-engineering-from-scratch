# 标准的分量，取决于它站在哪一层 · 提示词

## 用途

给「标准的分量，取决于它站在哪一层」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「五层结构，各有各的法理 → 制定流程七步，每一步都要交出东西 → 层级冲突的三种形态，修法各不相同 → 文本骨架：规范性附录与资料性附录不是一回事」这条链。

## 边界

本章为标准体系与制定程序的教学讨论，不构成标准化合规、监管符合性或临床用药建议；具体操作以现行规范与所在机构制度为准。
