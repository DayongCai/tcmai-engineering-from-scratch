# 标准的分量，取决于它站在哪一层

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 若干 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 边界

- 本章不引具体标准编号、发布年份与条款序号；凡涉层级与程序，一律以现行标准化法律法规与主管部门规定为准。
- 层级越多，一致性成本越高。五层体系的好处是覆盖不同尺度，坏处是同一件事被规定五次；「以最严者为准」只是权宜，真正的解法是每层只写自己该写的那一段。
- 加严有成本。限度每收紧一档，合格率就下降一档，被挡在门外的往往是小产区、小机构。加严必须有验证数据支撑，不能靠"更安全总是好的"这句话。
- 本章为标准体系与制定程序的教学讨论，不构成标准化合规、监管符合性或临床用药建议。
