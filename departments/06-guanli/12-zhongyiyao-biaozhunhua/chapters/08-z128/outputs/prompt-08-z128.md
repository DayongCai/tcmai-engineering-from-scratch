# 标准发出去不算完，要能算出它有没有用 · 提示词

## 用途

给「标准发出去不算完，要能算出它有没有用」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三个指标，先把分母说清 → 分母可以被操纵，这在评价里是常态 → 四种证据，强度递增，成本也递增 → 复审：三个问题，三种结论」这条链。

## 提示词

```
我在学《中医药标准化》第 8 章「标准发出去不算完，要能算出它有没有用」，本章 7 节 / 2,769 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 评价标准有没有用，绕不开三个指标
   - 覆盖率：分母是「应使用该标准的机构（或病例）数」，分子是「实际使用的」
   - 符合率：分母是「被抽查的记录数」，分子是「符合条款的记录数」
   - 有效率：分母是「符合条款的记录数」，分子是「达到预设结局的记录数」
   - 三个指标相乘不是科学公式，它只是把「乘法关系」这件事摆出来：覆盖再广，符合率低则无效；符合再高，无效则白做
   - 有效率的分母也有类似问题
4. 本章自陈的边界（不得越过）：
   - 本章不引具体标准编号、版本年份与监管条文序号；凡涉合规判定，一律以现行法律法规与主管部门规定为准，本章只讨论评价方法。
   - 指标可算不等于可信。三个指标的分母都可被合法地调整，报告必须同时披露分子、分母与口径变更，否则比率无法审计。
   - 评价有成本，且成本落在被评价方。每增加一张表，临床就少一分时间；评价项应当由「能改变决策」倒推，不能由「想知道」正推。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为标准实施评价与合规方法的教学讨论，不构成法律意见、监管符合性判定或绩效评价建议；具体操作以现行规范与所在机构制度为准。
