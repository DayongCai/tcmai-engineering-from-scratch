# 同意能力不是一张诊断书：谁有资格替谁决定 · 提示词

## 用途

给「同意能力不是一张诊断书：谁有资格替谁决定」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「同意的四个要件 → 决策能力：四项功能，不是一张诊断 → 代理决定的三个标准 → 代理人：谁有资格，以及代理的风险」这条链。

## 边界

本章为教学材料，讨论知情同意的要件、决策能力的功能性判断与代理决定的标准，不构成法律意见或临床建议。任何具体的能力认定、代理决定与同意瑕疵判断，须由具备资格的专业人员依现行规范作出；具体操作以现行规范与所在机构制度为准。
