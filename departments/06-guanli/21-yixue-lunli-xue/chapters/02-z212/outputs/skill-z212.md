# 四条原则不是四把尺：冲突时谁让位，凭什么

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 8 道题自检，答不上就回到对应小节。

## 核心判据

- 它是一份跨理论的最低共识，不是一套完整的伦理学
- 它常被误解为「不要冒险」，其实是
- 是同样情况同样对待
- 是按什么标准分配稀缺资源
- 第一种，具体化
- 第二种，平衡

## 边界

- **四原则的代价是它太容易被当成合规清单。** 一旦原则变成「逐条打勾」，它就不再是判断工具，而是免责工具。真正需要原则的场合，恰恰是打勾打不出来的场合。
- **平衡的代价是没有终局。** 每次冲突都要重新论证，无法一劳永逸。这是理论多元的必然成本；想要一劳永逸，只能靠权威，而权威在伦理上不产生正当性。
- **家庭参与的边界因地域、民族、家庭结构而异。** 本章给出的是分析框架，不是统一做法；具体到某个家庭，须看这个家庭的实际关系与患者的实际表达。
- 本章为教学材料，讨论生命伦理四原则的判据、冲突处理与本土落地问题，不构成法律意见或临床建议。任何具体的伦理判断、代理决定与资源分配事项，须结合情境由具备资格的专业人员依现行规范处理。
