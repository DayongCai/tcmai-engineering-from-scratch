# 专利审查不问方子灵不灵，只问它是不是新的、难想到的、做得出的 · 提示词

## 用途

给「专利审查不问方子灵不灵，只问它是不是新的、难想到的、做得出的」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三性各自卡在哪里 → 说明书要写到什么程度 → 权利要求怎么写：三层设权 → 从申请到授权：流程与三个关键节点」这条链。

## 提示词

```
我在学《中医药知识产权与成果转化》第 3 章「专利审查不问方子灵不灵，只问它是不是新的、难想到的、做得出的」，本章 6 节 / 3,255 汉字，习题 7 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 新颖性卡在「自己先说了」
   - 申请日之前不投稿、不报告、不上市
   - 创造性卡在「加减味算不算显而易见」
   - 预料不到的技术效果
   - 实用性卡在「做不出来、做不稳定」
   - 辨证论治的个体化恰恰与专利要求的可重复性相冲突
4. 本章自陈的边界（不得越过）：
   - **专利保护的是方案，不是疗效。** 一份写得再好、数据再全的申请，也不证明产品在临床上有效；反之，疗效确凿而公开不充分的申请照样被驳回。两者是两套评价体系，不能互相替代。
   - **二十年的期限与中药的研发周期严重错配。** 这是结构性的，不是起草技巧能解决的。能做的只有节奏设计与商业秘密配合。
   - **本章不给撰写模板，也不引条款。** 权利要求的措辞高度依赖具体技术方案与检索结果，模板化的写法在实务中通常有害；审查标准以现行规范与审查指南为准。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，讨论中药专利从申请到授权的一般逻辑与技术难点，不构成法律意见或代理意见；具体操作以现行规范与所在机构制度为准。
