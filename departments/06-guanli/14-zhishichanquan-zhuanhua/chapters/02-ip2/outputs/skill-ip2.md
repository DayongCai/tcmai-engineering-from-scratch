# 中药的知识产权不是一个筐，是五种互不替代的保护

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 没有保密措施，就没有商业秘密
- 分级与标识
- 处方会留痕
- 委托生产必然外泄
- 带教与进修是主要泄漏渠道
- 反向工程的边界要看清

## 边界

- **形态之间不能叠加在同一层。** 专利与商业秘密在同一个技术方案上互斥；商标护不住配方；著作权护不住医理。把「全都申请一遍」当作稳妥策略，只会增加成本与暴露面。
- **公开是不可逆的。** 专利申请文件一旦公布，即使最终驳回或无效，技术内容也已进入公有领域。这是选型时最需要冷静计算的一笔账。
- **传统知识这条路给不了排他。** 它能阻止他人不当取得权利、能带来惠益分享，但不能让持有人像专利权人那样禁止他人实施。把期望放在这上面，会在商业谈判中落空。
- 本章为教学材料，讨论中医药领域知识产权形态的类型与取舍逻辑，不构成法律意见或商业建议。
