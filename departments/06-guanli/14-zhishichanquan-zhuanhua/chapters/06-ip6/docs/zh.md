# 第 6 章 · 侵权判定不比两个方子像不像，比权利要求覆盖不覆盖

> **MOTTO:** 「法不阿贵，绳不挠曲。」——《韩非子·有度》
>
> **PROBLEM:** 一件中药组合物专利，权利要求写的是「药味 A 5–15 份、B 3–9 份、C 1–3 份」。被控产品把 C 换成功效相近的 D，配比全部落在范围内。这算不算侵权？答案不取决于两方「像不像」，取决于三件事：D 与 C 是否构成等同、专利权人在审查阶段有没有把 D 排除在外、被控产品能否用现有技术抗辩。这三个问题答得出来，才有资格谈赔偿；答不出来，谈的只是感觉。

**双根因定位:** 环境逼迫（专利权的边界由权利要求的文字确定，而文字永远比技术方案窄；凡文字没写到的，无论技术上多接近，都不在保护范围内） + 知识积累（中药复方的替代空间极大：换一味、改一量、换一种提取、改一种剂型，每一种替代都对应一条不同的判定规则，同一事实按不同规则走会得出相反结论）

## 一、侵权的两步：先字面，后等同

**第一步是全面覆盖。** 被控技术方案要落入权利要求的保护范围，必须包含权利要求中记载的**全部**技术特征。少一个，就不落入。这一条常与直觉相反：被控产品技术更复杂、效果更好，只要缺少一个必要特征，就不构成侵权；反过来，技术更简陋，只要把所有特征都做齐了，就构成侵权。判断的对象是特征的有无，不是水平的高低。

**第二步是等同。** 字面不落入时，看被控方案与权利要求中的某个特征是否以「基本相同的手段，实现基本相同的功能，达到基本相同的效果，且本领域技术人员无需创造性劳动即可联想到」的方式替换。中药场景最常见的等同争议就是换味：C 换成同性味、同功效的 D，量落在范围内。支持等同的理由是手段功能效果的实质一致；反对的理由通常是——本领域技术人员容易想到的替换，是否属于「无需创造性劳动」的判断，恰恰是争点。

等同不是无边的，有三条限制，缺一条都可能让主张落空：

- **禁止反悔。** 专利权人在审查或无效程序中，为获得授权或维持有效而作出的限缩性陈述、修改、放弃，不能在侵权诉讼中反悔，把已经放弃的内容再捞回来。所以审查档案（审查意见与答复）是侵权诉讼必读的材料，它决定了权利要求的真实边界。
- **捐献规则。** 说明书里写了、但没写进权利要求的方案，视为捐给公众，不能通过等同再拿回来。这条规则惩罚的是「写宽了兜不住、写窄了又想扩」的起草策略。
- **现有技术抗辩的挤压。** 若把某个替换解释为等同，会使权利要求覆盖到申请日前的现有技术，则该等同解释不能成立——专利不能通过等同把公有领域吞进去。

## 二、中药案件的四类特殊问题

**参数型权利要求的数值边界。** 中药组合物的核心特征往往是配比与含量。数值落入范围就是字面侵权，这一点没有争议；争议在边界之外——略高于上限、略低于下限，是否构成等同？判断要看该数值是否有实质性技术意义：如果说明书表明在 15 份以上效果骤降（例如毒性上升），那么 16 份不构成等同；如果数值只是常规取值范围，边界外的近似值可能被认定等同。

**用途限定。** 用途权利要求只在所限用途上排他。同一产品卖去做别的适应症，不落入。这使得用途专利的维权必须证明对方的**使用意图与实际用途**，而不是仅证明产品相同——举证难度明显高于产品专利。

**方法专利的延伸与举证。** 方法专利的保护及于使用该方法的行为，并通常延伸到依该方法直接获得的产品。难点在举证：别人的车间里怎么做，权利人看不到。制度上有一处缓和——涉及新产品制造方法的，举证责任可能转移，由被控方证明其使用的方法不同于专利方法。这是方法专利能否用起来的关键，也是撰写时应当争取落入「新产品」范畴的原因。

**工艺秘密与专利的分工。** 方法专利一旦公开，他人改用实质不同的工艺即可规避，而工艺的「实质不同」在中药上很容易做到（换溶剂、改温度、分步提取）。所以方法专利常需与产品专利配合：产品专利挡住成品，方法专利挡住特定的低成本路径。

举证的具体手段是实务活：公证购买、检测报告（成分、指纹图谱、特征指标）、鉴定意见、证据保全（诉前或诉中申请，针对生产现场、库存、账册）、现场检查（行政程序中的优势）。中药配方难以从成品完整反推，因此**证据保全的价值往往高于检测**。

## 三、抗辩清单：被控方手里的六张牌

被诉侵权不等于败诉，可用的抗辩有六类，各自的门槛不同。

| 抗辩 | 核心主张 | 门槛与要点 |
|---|---|---|
| 不落入 | 缺少必要技术特征，或替换不构成等同 | 逐特征比对，做特征对应表 |
| 现有技术抗辩 | 被控方案能从申请日前的现有技术直接得出 | 须是**一项**现有技术与被控方案的比对，不是拼凑 |
| 权利用尽 | 产品系权利人许可售出 | 仅及于该特定产品，不及于再造 |
| 先用权 | 申请日前已制造相同产品或使用相同方法 | 仅在原有范围内继续，不得扩张 |
| 科研实验例外 | 专为科学研究和实验而使用 | 不含商业目的的「研究」 |
| 无效宣告 | 权利要求不具备授权条件 | 釜底抽薪，但周期长，可与侵权程序并行 |

第六张牌最有效也最慢：权利被宣告无效，侵权之诉失去基础。实务上的常见节奏是——被诉后立即启动无效，同时申请中止侵权程序；能否中止，取决于无效理由的强度与是否需要等待结果。这条路上还有一种打法叫**自我无效**，即在起诉前自己先用最强证据攻一遍，能攻动就说明权利不稳，谈判筹码立减。

## 四、许可纠纷的五个高发点

侵权是「没买票就上车」，许可纠纷是「买了票坐过站」。后者在中药领域更常见，因为许可范围往往写得不细。

**超范围实施。** 超出约定的地域、期限、领域（治疗领域、剂型、适应症）、产量或销量。合同里若只写「在中国境内生产销售」，被许可方做出口就不在许可范围内；若只写「用于某适应症」，扩展到别的适应症就是超范围。

**许可类型冲突。** 独占许可之后又向第三方许可，或许可方自己继续实施。这类纠纷的根源是合同没把「独占」定义清楚——是否含许可方自己、是否含关联方、是否含分许可。

**提成基数与审计。** 按销售额还是按净销售额；是否扣除税费、退货、折扣；关联交易转移定价把利润挪走；审计权有没有约定、范围多大、费用谁承担。没有审计权的提成条款，在实务中接近于靠对方自觉。

**改进成果归属与回授。** 被许可方在实施中作出的改进，归谁？是否必须回授给许可方？回授是有偿还是无偿？改进后能否单独申请专利、申请后能否自己许可给别人？这一条在长期许可里几乎必然触发争议。

**终止后的过渡。** 合同终止时，库存能不能卖、卖多久；在研项目怎么处理；技术资料是否返还或销毁；客户能不能带走；保密义务是否延续。缺了过渡条款，一终止就是双输——被许可方的在研产品停摆，许可方的市场也空了。

## 五、救济与程序选择

**民事救济。** 主要形式是停止侵害、赔偿损失、消除影响。赔偿的计算有顺位：先按权利人的实际损失，实际损失难以确定的按侵权人的获利，两者都难以确定的参照许可使用费的合理倍数，仍无法确定的适用法定赔偿。这条顺位在实践中的意义是：**证据准备的方向决定赔偿的高低**——能证明自己损失（销量下降、价格侵蚀）的，走第一条；不能证明的，去查对方的账（获利）；连账都查不到的，只能落到法定赔偿，数额通常低于实际损失。

临时措施也值得重视：诉前或诉中的行为保全（临时禁令）与证据保全。申请有门槛——权利稳定性、侵权可能性、不采取措施会造成难以弥补的损害、提供担保。中药产品一旦铺货，晚一个月制止，损失就多一截，所以保全的时机比措辞重要。

**行政途径。** 专利侵权纠纷可以请求管理专利工作的部门处理（责令停止侵权，赔偿部分仍须诉讼）；假冒专利、商标侵权与混淆行为由市场监管部门查处；进出口环节可以走知识产权海关保护备案与扣留。行政程序快、成本低，但赔偿能力有限，通常作为配合手段而非主战场。

**刑事途径。** 假冒注册商标、侵犯商业秘密在达到门槛时构成犯罪。刑民交叉的策略要谨慎：刑事程序取证能力强，但一旦启动，民事和解的空间收窄；先刑后民还是并行，取决于目的是止损还是拿赔偿。

**程序选择的一般逻辑。** 侵权是法定之诉，只能诉讼或行政处理，不能仲裁；合同争议（许可费、超范围、改进归属）可以约定仲裁。所以一份好的许可合同，会把「侵权怎么处理」与「违约怎么处理」分开写，分别指定路径。

**跨境的一层。** 专利有地域性，出口目的国没有布局，在当地就不受保护；海关备案与展会保护是低成本手段，能挡住一部分侵权货物流通。中药出海前先看目的国的专利状态，比事后应诉便宜得多。

## 六、代价与边界

- **本章不给判例结论，也不评价任何具体案件。** 侵权判定的结果高度依赖权利要求的措辞、审查档案与证据，同类事实在不同案件中可能得出不同结论。
- **赔偿数额不作估计。** 计算顺位与举证方向是结构性的，具体数额须依证据与现行规范确定，任何通用数字都会误导。
- **等同原则是不确定的。** 它给权利人留了扩张空间，也给被控方留了抗辩空间，结果难以预测——这正是和解在专利纠纷中占比极高的原因。把希望寄托在「一定能赢」，通常不是好的诉讼策略。
- **权利的稳定性决定救济的实效。** 一件随时可能被无效的专利，即便侵权成立，也换不来多少赔偿；维权之前先做稳定性体检，是成本最低的一步。
- 本章不构成法律意见，也不构成诉讼或谈判建议。

**免责声明：** 本章为教学材料，讨论中医药知识产权的侵权判定、许可纠纷与救济途径的一般逻辑，不构成法律意见或诉讼建议；具体争议的处理，应由当事人委托具备资质的专业人士，依现行规范并结合完整证据判断。
