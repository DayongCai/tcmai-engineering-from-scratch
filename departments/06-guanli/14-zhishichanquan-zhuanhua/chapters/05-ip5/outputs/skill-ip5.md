# 新技术的麻烦不在能不能申请，在申请下来算谁的

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 落到具体数据处理
- 落到具体技术效果
- 落到具体应用环节
- 按商业秘密保护更现实
- 数据库的权利很薄
- 数据量大不等于证据强

## 边界

- **本章不给技术方案评价，也不判断任何具体模型的可专利性。** 这类判断高度依赖权利要求的具体写法与检索结果。
- **合规的判断以现行规范为准，且会变。** 数据、遗传资源、跨境流动的规则近年调整频繁，本章只给结构，不给条文；个案须核对最新要求。
- **「先做后补」在数据合规上通常行不通。** 数据一旦被超范围使用或出境，补救的空间极小；这与专利可以先申请后补强完全不同，须在项目立项时就前置。
- 本章为教学材料，讨论新兴技术与中医药知识产权交叉处的权属、数据合规与伦理边界，不构成法律意见或伦理审查结论。
