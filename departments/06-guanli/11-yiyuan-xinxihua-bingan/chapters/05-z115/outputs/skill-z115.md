# 数据质量与统计上报：同一个数，三个分母

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 3 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 转科病人算一次还是算两次
- 把抽出的错例逐条反馈到人和科室
- 不要试图把它们统一成一个数

## 边界

- 本章全部数值（床日、人数、错误率、金额）均为**演算设定**，用于演示算法关系，不是任何机构的实测数据；代入本院数据时须重新计算。
- 三个分母的差异源于口径而非错误。**不要试图把它们统一成一个数**——各口径服务于不同用途，强行统一会导致某一用途失真；正确做法是各自写清四件套并标注不可直接比较。
- 抽检错误率受抽样方法与判错标准影响很大，跨院比较前必须先比对这两项，否则比较无意义。
- 本章为医院统计与数据质量管理的教学讨论，不构成统计口径解释、上报要求或考核依据。
