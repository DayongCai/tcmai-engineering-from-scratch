# 数据质量与统计上报：同一个数，三个分母 · 提示词

## 用途

给「数据质量与统计上报：同一个数，三个分母」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「指标不是数，是四件套 → 三个分母：在院、出院、占用床日 → 三单一致与上传前的逻辑校验 → 抽检：抽样、判错标准与可复算的错误率」这条链。

## 提示词

```
我在学《医院信息化与病案管理》第 5 章「数据质量与统计上报：同一个数，三个分母」，本章 4 节 / 2,808 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 转科病人算一次还是算两次
   - 把抽出的错例逐条反馈到人和科室
   - 不要试图把它们统一成一个数
4. 本章自陈的边界（不得越过）：
   - 本章全部数值（床日、人数、错误率、金额）均为**演算设定**，用于演示算法关系，不是任何机构的实测数据；代入本院数据时须重新计算。
   - 三个分母的差异源于口径而非错误。**不要试图把它们统一成一个数**——各口径服务于不同用途，强行统一会导致某一用途失真；正确做法是各自写清四件套并标注不可直接比较。
   - 抽检错误率受抽样方法与判错标准影响很大，跨院比较前必须先比对这两项，否则比较无意义。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为医院统计与数据质量管理的教学讨论，不构成统计口径解释、上报要求或考核依据；具体操作以现行规范与所在机构制度为准。
