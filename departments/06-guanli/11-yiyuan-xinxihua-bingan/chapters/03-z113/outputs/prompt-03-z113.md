# 电子病历与临床信息系统：写得快不等于写得对，签了名才算写完 · 提示词

## 用途

给「电子病历与临床信息系统：写得快不等于写得对，签了名才算写完」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「时限：一张按小时排的清单 → 病程记录：频次是底线，内容才是证据 → 签名：谁签、签在哪儿、改过怎么留痕 → 知情同意书：五栏必填，一栏不能空」这条链。

## 边界

本章为电子病历与临床记录的教学讨论，不构成病历书写规范解释、法律意见或质控判定依据；具体操作以现行规范与所在机构制度为准。
