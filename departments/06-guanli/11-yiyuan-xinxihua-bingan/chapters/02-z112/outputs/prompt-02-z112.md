# 标准、编码与互操作：编码少一位，整组就匹配不上 · 提示词

## 用途

给「标准、编码与互操作：编码少一位，整组就匹配不上」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「标准分四层，混着谈就谈不出结论 → 编码的位数是匹配键，不是精度偏好 → 映射表：一对一、一对多，以及对不上的那一类 → 互操作：能传数据不等于能读懂数据」这条链。
