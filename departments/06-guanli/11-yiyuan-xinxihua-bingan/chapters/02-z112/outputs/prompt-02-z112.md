# 标准、编码与互操作 · 提示词

## 用途

给「标准、编码与互操作」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「系统 → 标准 → 病历 → 病案 → 质量」这条链。

## 提示词

```
我在学《医院信息化与病案》第 2 章「标准、编码与互操作」，正文见本章 `docs/zh.md`，关键数字由 `code/main.js` 从正文现算，
取自教材第 2 章。

请按以下顺序带我走：
1. 先给本章要回答的问题，并说明它为什么不能直接套用上一章；
2. 再按正文各小节给出判据，并指出本节最容易被误判的那一处；
3. 然后按正文小节逐条读出「判据」——每条只写类别与要点，不给操作参数；
4. 最后给出三条边界：哪些内容只能写到类别、哪些必须由具备资质的人员作出、哪些情况按记录写：对象与情境、依据的指标、与教材表述的差异报告。

要求：不编造教材没有的数字；引文写到《书名·篇名》级并标注是否本章原文篇名；
不确定的地方直接说「教材未展开」。
```

## 边界

本提示词用于教学准备，不构成诊疗或护理意见；具体操作以现行规范与所在机构制度为准。
