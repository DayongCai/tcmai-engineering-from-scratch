# 人才流动的问题不是流失率高，是内部流动比外部流动还慢 · 提示词

## 用途

给「人才流动的问题不是流失率高，是内部流动比外部流动还慢」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「流动的三个方向，判据不同 → 内部流动为什么更慢：四个卡点 → 配置优化的三个输入 → 流动的定价：调动成本与招聘成本」这条链。

## 边界

本章为教学材料，讨论医药人才流动规律与人力配置优化的分析框架，不构成人事处理依据、调配方案或管理咨询意见；具体操作以现行规范与所在机构制度为准。
