# 国际比较的用处不是判断谁更好，是看清同一工具换个约束就失效 · 提示词

## 用途

给「国际比较的用处不是判断谁更好，是看清同一工具换个约束就失效」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三种配置逻辑 → 两条培养路径 → 任务转移的三个条件 → 数字化的三种深度」这条链。

## 边界

本章为教学材料，讨论医药人力资源管理的国际比较方法与趋势判断，不构成政策建议、管理咨询意见或对任何国家、地区与机构的评价；具体操作以现行规范与所在机构制度为准。
