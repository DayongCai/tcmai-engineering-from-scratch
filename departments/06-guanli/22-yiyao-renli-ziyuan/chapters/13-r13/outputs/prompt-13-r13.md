# 传承断的不是名师，是「跟师」没有写进任何一张考核表 · 提示词

## 用途

给「传承断的不是名师，是「跟师」没有写进任何一张考核表」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三种知识，三种传法 → 师承的四个环节，缺一环就断 → 把传承写进岗位与考核 → 院校教育与师承的接缝」这条链。

```

正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
```

## 边界

本章为教学材料，讨论中医药人才传承机制与培养路径的分析框架，不构成人事处理依据、师承项目方案或教学管理意见；具体操作以现行规范与所在机构制度为准。
