# 绩效方案考的是可测量的部分，漏掉的会以别的方式回来

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 目标设定 → 过程辅导 → 考核评价 → 结果应用
- 具体到能被反馈
- 给每个易被博弈的指标配一个反向指标
- 指标一旦成为目标，就不再是好指标
- 分母的选择比分子更能决定行为
- 任何单一维度不应超过六成

## 边界

- **本章不给权重、系数与指标阈值。** 18%／12%／0.6 天、4.1%／6.3%、21%、62%、五三二结构，均为演示数量关系的合成设定，不对应真实机构；绩效工资总量、分配办法须依现行政策与本院制度确定。
- **指标没有最优解，只有取舍。** 每个指标都在"可测"与"可控副作用"之间做交换；配对指标能缓解博弈，不能消除。
- **职称制度随政策调整。** 本章只讨论评与聘的结构关系，不涉及具体评审条件与破格办法。
- 本章为教学材料，讨论绩效管理与考核指标设计的方法，不构成绩效方案、分配办法或管理咨询意见。
