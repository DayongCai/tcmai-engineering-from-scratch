# 留人不是加工资，是把"看不到成长"变成看得见的台阶 · 提示词

## 用途

给「留人不是加工资，是把"看不到成长"变成看得见的台阶」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三条通道，不是一条 → 梯队：先识别关键岗位，再谈后备 → 离职分析：先分可避免与不可避免 → 保留的组合：四件事一起做才有效」这条链。

## 边界

本章为教学材料，讨论职业发展通道、人才梯队与离职保留的分析框架，不构成人事处理依据、晋升方案或管理咨询意见；具体操作以现行规范与所在机构制度为准。
