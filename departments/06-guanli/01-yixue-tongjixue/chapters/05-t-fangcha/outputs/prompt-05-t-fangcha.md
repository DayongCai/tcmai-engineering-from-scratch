# 比较的不是两堆数，是差值除以它自己的抖动 · 提示词

## 用途

给「比较的不是两堆数，是差值除以它自己的抖动」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「所有 t 检验都是同一个形状 → 配对设计：把个体差异从分母里扣掉 → 方差分析：一次比较三组，靠的是变异分解 → 两两比较：3 次比较就是 3 次机会」这条链。

## 提示词

```
我在学《医学统计学》第 5 章「比较的不是两堆数，是差值除以它自己的抖动」，本章 6 节 / 2,725 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 如果两组（或前后）其实没有差别，这个差值会自己抖多大幅度
   - 标准误从哪里来，以及它被算错时会怎样
   - 同一批数据、同一个差值，两种算法差了近 200 倍的 p 值
   - 同一批人随机分到两种处理、交叉给药
   - 总变异 SST = 组间变异 SSB + 组内变异 SSW
   - 它是「总体检验」，只回答「三组中至少有两组不同」，不回答「哪两组不同」
4. 本章自陈的边界（不得越过）：
   - **t 与 F 都是「均值层面」的工具。** 它们回答「平均水平是否不同」，不回答「多少比例的人获益」。一个均数显著改善但分布双峰的治疗，可能对一半人有害——这时需要报有效率或分布，而不只是均数。
   - **配对省样本，但省不掉设计。** 前后对照无法排除自然病程、回归均值与安慰剂效应；能排除这些的是随机对照，代价是样本量更大。
   - **校正有代价。** 校正后不显著不等于没有效应，只等于「以现有样本量、在校正后的门槛下看不出来」。这一点必须写进局限性，否则读者会把「未校正出显著」误读为「无效」。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章讨论均值比较的方法与前提，属方法学内容，不构成疗效结论或临床建议；具体操作以现行规范与所在机构制度为准。
