# 样本的「率」是一团会呼吸的数 · 提示词

## 用途

给「样本的「率」是一团会呼吸的数」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「概率不是「可能」，是可以算的摆动幅度 → 均数的抽样分布：中心极限定理的实用含义 → 置信区间不说的那件事 → 20 例的「率」为什么几乎不可比」这条链。

## 提示词

```
我在学《医学统计学》第 3 章「样本的「率」是一团会呼吸的数」，本章 5 节 / 2,655 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 抽哪 20 个人
   - 约等于总体参数
   - n 变大，SE 按平方根缩小
   - 个体差异越大，SE 越大
   - 不论原分布长什么样，均数的分布在 n 足够大时近似正态
   - 样本量从 9 加到 36（四倍），区间宽度缩到 0.42 倍
4. 本章自陈的边界（不得越过）：
   - **区间比点估计诚实，但也更长。** 小样本研究会得到很宽的区间，宽到「没有结论」。这不是方法的缺陷，是数据的真实信息量；把宽区间藏起来只报点估计，等于把不确定性转嫁给读者。
   - **频率派的区间不是「参数的概率」。** 想要「参数有 80% 概率落在某区间」这种表述，需要贝叶斯框架与先验，那是另一套口径，不能混着用。
   - **置信水平是长期的，不是这一次的。** 95% 说的是重复抽样下的命中率；单次研究里它可能没命中，而你无法知道自己是不是那 5%。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章讨论抽样分布与区间估计的方法学，示例为教学演算，不构成研究结论或临床建议；具体操作以现行规范与所在机构制度为准。
