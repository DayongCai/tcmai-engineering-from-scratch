# 相关系数是斜率被两个标准差除过一遍 · 提示词

## 用途

给「相关系数是斜率被两个标准差除过一遍」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「r 的构造，决定了它的三种脾气 → r² 与斜率：两个数回答两个问题 → 相关不蕴含因果：三种替代解释 → 回归到均值：为什么「极端组」的第二次测量总在回归」这条链。

```

2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
```
