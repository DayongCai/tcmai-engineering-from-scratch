# 数据类型定错了，后面每个数字都跟着错 · 提示词

## 用途

给「数据类型定错了，后面每个数字都跟着错」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「统计在中医研究里只做四件事 → 四种尺度，四张不同的运算许可证 → 等级资料赋分：那段间距是从哪来的 → 四种类型错配，与它们各自的失效信号」这条链。

## 提示词

```
我在学《医学统计学》第 1 章「数据类型定错了，后面每个数字都跟着错」，本章 6 节 / 2,958 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 这个变量是什么尺度
   - 先定尺度，再定统计量
   - 零点是不是「什么都没有」
   - 用的时候要知道自己在假设什么
   - ——因为它只用次序，不用间距。这个对比说明的不是「赋分错了」，而是
   - 合并成二分类
4. 本章自陈的边界（不得越过）：
   - **尺度判定本身有争议。** 疼痛 0–10 分、生活质量量表总分，被广泛当作等距处理，理由是量表按等距思路设计；这是**约定**，不是测量学事实。用的时候要把这个约定写进方法，而不是当成前提不存在。
   - **二分类化常常是审稿要求，不是科学要求。** 期刊要「异常率」、要「有效率」，于是连续指标被切、等级指标被并。服从格式是可以的，但原始尺度的分析应当保留，否则读者无从判断结论是否依赖切点。
   - **本章只给判定规则，不给分析方案。** 具体研究该用哪种检验、样本量多大、如何控制混杂，取决于设计、结局与预注册的方案，不能从类型表直接读出。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章讨论统计变量的类型与尺度，属方法学教学内容，不构成研究方案、诊断或治疗建议；具体操作以现行规范与所在机构制度为准。
