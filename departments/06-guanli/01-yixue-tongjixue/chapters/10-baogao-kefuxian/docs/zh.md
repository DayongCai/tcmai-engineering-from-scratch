# 第 10 章 · 报告的价值，在于别人能照着重算一遍

> **MOTTO:** 「诊病不问其始，忧患饮食之失节，起居之过度，或伤于毒，不先言此，卒持寸口，何病能中，妄言作名，为粗所穷。」——《素问·征四失论》
>
> **PROBLEM:** 一项计划检出 0.6 个标准差的组间差异，双侧 α=0.05、把握度 0.8，算式给出每组 43.6 例，取整 44 例；若预计失访 20%，需 44/0.8=55 例/组。而多数论文只写「每组 30 例」，既不写预期效应，也不写把握度，更不写失访如何计入——读者无法判断这 30 例是算出来的，还是凑出来的。**样本量不写来源，等于整篇的精度无从核对。**

**双根因定位:** 环境逼迫（期刊字数有限、表格要好看、审稿意见要快速回复，报告规范总被排在最后）+ 知识积累（可复现不是态度问题，是一组可检查的物件：样本量算式、分析脚本、数据字典、软件版本、失访清单）

## 一、样本量：四个输入，一个算式，一处上调

样本量估算只需要四个输入，缺一个就算不出来：

1. **效应量**：临床上认为有意义的最小差异（不是「上次研究观察到的差异」——那会把上次的噪声当成目标）。
2. **α**：双侧还是单侧，取多少。
3. **把握度（1−β）**：通常 0.8 或 0.9。
4. **失访率**：预计有多少人中途退出。

两组均数比较的近似算式是 n/组 = 2(z_{1−α/2} + z_{1−β})² / d²，其中 d 是标准化差值（差值除以标准差）。代入 α=0.05、把握度 0.8，得 2×(1.96+0.8416)²/d² = 15.70/d²。

d=0.6 时，15.70/0.36=43.6 → 44 例/组；加上 20% 失访，44/0.8=55 例/组。这就是那 55 的来历。

三个常见的错误做法，都能在论文里认出来：

- **倒推**：研究做完了，用观察到的效应算样本量，写成「本研究样本量足够」。这是循环论证——观察到的效应本身带抽样误差，用它算出来的把握度必然虚高。
- **事后算把握度**：阴性结果出来后算「本研究的把握度是 0.35」，然后写「说明两组等效」。把握度低只说明没看清，不说明等效（第 4 章）。
- **不含失访**：按 44 例入组，最后 35 例完成，分析时按 35 例的把握度解释——真实把握度已经跌到 0.6 左右。

效应量的来源也要写清：来自文献（要给范围）、来自预试验（要说明例数）、还是来自最小临床重要差异（要有依据）。三者可信度不同，混着用会让样本量看起来「有根据」而实际是拍的。

## 二、一份报告该有的九件事

报告规范（RCT 用 CONSORT，观察性研究用 STROBE，系统评价用 PRISMA，诊断准确性用 STARD）条目很多，但落到中医临床研究，最常缺失的是下面九件。缺哪一件，读者就少一个核对点。

| 项 | 要写什么 | 常见缺失形式 |
|---|---|---|
| 对象与来源 | 哪个机构、哪段时间、什么人群 | 只写「本院门诊患者」 |
| 纳排标准 | 逐条列出，含证候判定依据 | 写「符合某证诊断标准」不写版本 |
| 设计与分配 | 随机方法、分配隐藏、盲法层级 | 写「随机分组」不写怎么随的 |
| 样本量 | 四个输入 + 算式 + 失访上调 | 只写例数 |
| 干预细节 | 方药组成、剂量、煎服法、疗程 | 写「某方加减」不写基础方 |
| 结局 | 主结局、次结局、测量时点与工具 | 主次不分，事后改主结局 |
| 统计方法 | 检验类型、单双侧、校正、软件与版本 | 写「用 SPSS 分析」 |
| 结果 | 效应量 + 95% CI + 精确 p 值 | 只报 p<0.05 |
| 失访与缺失 | 各组失访数、原因、处理方式 | 只写「无失访」 |

第九项最容易被含糊。失访不是「损耗」，它是**信息**：多少人、什么原因、与结局是否相关。若失访者病情更重（不来复诊）或更好（觉得没必要来），剩下的样本就偏了，而偏的方向可以猜。规范的写法是给出各组失访数与原因分布，并做一次「失访者全部按最差结局计」的敏感性分析。

## 三、可复现的最小集：五件物件

「可复现」不是一句承诺，是五件具体的东西：

1. **数据字典**：每个变量的名称、类型、单位、取值范围、缺失编码。缺这一件，别人拿到数据也不知道「疗效」这一列里 1 是有效还是无效。
2. **分析脚本**：从原始数据到最终表格的每一步，包括清洗规则（哪些值被判为异常、怎么改的）与统计模型设定。
3. **随机种子**：凡是涉及随机（随机分组、多重插补、交叉验证），都要记录种子；否则同一份数据重跑会得到不同的数。
4. **环境版本**：软件与包的版本。同一个检验在不同版本里默认参数可能不同（比如卡方是否默认连续性校正），结果会有细微差别。
5. **结果对账表**：论文里每个数字对应脚本的哪一行输出。这一件最能暴露「手改过的数」。

同一份数据两次算出不同结果，通常只有三种原因：随机过程没有固定种子；清洗规则没写清（这次删了 3 个异常值，上次删了 5 个）；软件默认参数不同。三种都不是「玄学」，都是可以写下来的东西。

交稿前还有一道最便宜的自查：**表内的加减要对得上**。三处最容易出问题。

**其一，n 之和。** 各分组的例数相加必须等于总例数；各时点的例数必须等于「入组 − 累计失访」；亚组之和必须等于全样本。任何一处不等，都要有脚注解释（比如「3 例证型记录缺失，未纳入分层」）。这一条最能揭出「分母悄悄换了」的问题。

**其二，百分比反算。** 报告 65.0% 且 n=60，反算应得 39 例；若表里写的是 38 例，两者必有一错。凡百分比保留一位小数，就应当能反算出整数例数；反算不出，说明分母不是那个数。

**其三，跨处一致。** 摘要写「有效率 66.7%，对照组 41.7%」，正文表里就必须是 40/60 与 25/60；改了一处忘改另一处，是投稿里最常见的自相矛盾。

| 核对项 | 检查方法 | 常见错处 |
|---|---|---|
| n 之和 | 分组相加 = 总数；入组 − 失访 = 分析数 | 分层后漏算缺失 |
| 百分比 | 由 n 反算例数 | 分母换了，率未重算 |
| 跨处一致 | 摘要、正文、表、图四处对齐 | 改数只改一处 |
| 单位 | 每个标目后括注单位 | 全文单位不统一 |

## 四、图表：三个最常见的失真点

报告里的图比表更容易骗人，因为图看起来更「客观」。三个失真点值得单独盯：

**其一，误差线没说是哪一种。** 均数±标准差、均数±标准误、95% 置信区间，三者宽度依次递减（n=20 时，标准误只有标准差的 0.22 倍）。图上只画一根短短的误差线而不注明含义，读者会默认它是标准差——于是以为数据很集中。规范做法是图注写明「误差线为 95% CI」或「为 SD」。

**其二，纵轴不从 0 开始。** 条图、直方图、百分条图的长度编码数值，纵轴必须从 0 起；截断会把 5% 的差异画成 3 倍。线图与散点图可以按数据范围定起点，但要标清刻度，且不能拉伸某一段。

**其三，生存曲线不附风险人数表。** KM 曲线在尾部风险集很小，曲线的一小段可能只由 2–3 人决定，此时曲线的「平稳」或「陡降」都没有意义。规范做法是在横轴下方附风险人数表（每个时点各组还剩多少人），并在风险集少于 5 人处截断。

表格一侧，三线表是基本要求：顶线、标目线、底线，不用竖线，不用斜线。数字对齐、位数一致、单位写在标目里、缺失用专门的符号而不用 0。这些看起来是排版细节，实际是**读者能否核对**的前提：位数不一致的表，读者没法一眼看出哪两个数该相减。

## 五、选择性报告：报告规范真正要挡的东西

报告规范的核心不是格式，是**让「实际做的」与「写出来的」对得上**。四类不对应最常见：

- **结局替换**：方案写主结局是症状总分，论文报单项积分（因为显著）。
- **时点替换**：方案写 8 周，论文报 4 周（因为 4 周显著）。
- **分析人群替换**：全分析集不显著，改报符合方案集。
- **模型替换**：试了五种模型，报最显著那一种。

这四类都无法从单篇论文内部识别，只能靠**方案与论文对读**。所以预注册（或至少是方案留档、统计计划签字）是可复现的前提条件，不是形式主义。中医研究里还有一个特殊点：证候判定与方药加减本身带主观性，若不预先写清判定依据与加减规则，事后无法复核「这个病人为什么算有效」。

可复现与隐私之间有边界。共享数据要先去标识化，注意出生日期、就诊时间、罕见病种与地域的组合识别风险；不能共享原始数据时，至少共享数据字典、分析脚本与汇总表，让「算的过程」可核对。凡用于教学或演示的合成数据，必须标注为合成，不能与真实研究数据混排。
本章可直接验证：`node code/main.js` 打印结构清点与判据清单（数字从 `docs/zh.md` 现算），`node --test code/main.test.js` 跑本章单测；两条命令只读正文与代码，不写任何文件。

## 六、代价与边界

- **规范不保证正确。** 一份完全符合 CONSORT 的论文，仍可能因为设计缺陷而结论错误。报告规范管「说清楚」，不管「做对」。
- **可复现有成本。** 写数据字典、留脚本、记版本，都要额外时间，且这些工作不会出现在摘要里。它是给同行的基础设施，不是给自己的加分项。
- **完全复现常常做不到。** 涉及个体化诊疗的研究，处方随证加减，干预本身难以完全标准化；这时应报告「可复现的部分」（纳排、结局定义、分析脚本）并说明「不可复现的部分」（个体化决策），而不是含糊过去。
- **本章数字为教学示意。** 0.6 个标准差、44 例与 55 例均为演示算式的结果，不对应任何真实试验；真实研究的样本量须依预注册方案、目标效应与失访预估确定，并经统计审核。

**免责声明：** 本章讨论统计报告规范与可复现要求，属方法学内容，不构成研究结论或临床建议；研究的实施、注册与数据共享须遵守伦理审查、知情同意与所在机构的数据管理规定。
