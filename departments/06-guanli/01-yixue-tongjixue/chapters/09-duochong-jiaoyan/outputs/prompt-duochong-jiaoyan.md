# 做了 20 个指标，「总有一个显著」是算术，不是运气 · 提示词

## 用途

给「做了 20 个指标，「总有一个显著」是算术，不是运气」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「多重性从哪来：比较次数，不是样本量 → 两种错误率：FWER 与 FDR → 三种实现：Bonferroni、Holm、BH → 校正救不了的四件事」这条链。

## 边界

本章讨论多重比较与假阳性控制的方法学，属教学与统计分析演练内容，不构成研究结论或临床建议；具体操作以现行规范与所在机构制度为准。
