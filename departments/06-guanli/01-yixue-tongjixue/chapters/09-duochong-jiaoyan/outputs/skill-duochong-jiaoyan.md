# duochong-jiaoyan

## 何时使用

- 研究方案讨论阶段，需要确定「比较几次、怎么校正」
- 稿件自查：m 是否漏算、α 是否事后调整
- 应答审稿人「你校正了吗」这类意见

## 不适用

- 单一比较且无亚组、无多时间点的研究（无需校正）
- 主结局未预注册、需要事后补校正的情形（校正无效，只能标注探索性）
- 贝叶斯/机器学习建模中的多重性问题（那是另一套框架）

## 步骤

1. **定目的**：确证 → FWER；探索 → FDR。
2. **数 m**：主结局 + 次要结局 + 亚组 + 时间点，逐项相加并列出。
3. **算门槛**：Bonferroni α/m；BH 逐位算 k/m·α 并给拒绝集。
4. **写表述**：确证写「显著」，探索写「值得进一步验证」。
5. **写局限**：校正可能抹掉真实效应；事后挑结局校正无效。

## 输出模板

```text
【方法】…
【m 与 α】m=…（构成：…）；α=…
【门槛与拒绝集】…
【表述】…
【局限】1) … 2) …
```

## 质量判据

- m 的构成逐项列出，可被读者复核
- 方法选择与「目的」一致
- 局限性包含「校正的代价」而非只有套话

> 本技能输出为统计方案辅助，不构成研究结论。
