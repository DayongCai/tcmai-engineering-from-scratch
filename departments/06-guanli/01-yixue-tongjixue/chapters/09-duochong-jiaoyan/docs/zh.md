# 第 9 章 · 做了 20 个指标，「总有一个显著」是算术，不是运气

> **MOTTO:** 「知其要者，一言而终，不知其要，流散无穷。」——《灵枢·九针十二原》
>
> **PROBLEM:** 一项证候研究测了 20 个指标，其中 1 个 p=0.03，写进摘要叫「具有统计学意义」。如果这 20 个指标其实全都无效，那么至少出现一个 p<0.05 的概率是 1−0.95²⁰=**64.15%**——大多数这样的研究都会「有发现」。这不是概率论的花招，是 20 次独立抽签的简单算术。审稿人问「你校正了吗」，问的其实是：你宣称的这个发现，是在多少次尝试里挑出来的？

**双根因定位:** 环境逼迫（毕业、晋升、结题都要「阳性结果」，于是指标越加越多、亚组越切越细）+ 知识积累（多重性有自己的错误率定义与校正算法，而这些算法只能约束「事先定好的比较集合」，管不了事后的挑选）

## 一、多重性从哪来：比较次数，不是样本量

单次检验在真实无效应时误判的概率是 α=0.05。做 k 次**独立**检验，一次都不误判的概率是 (1−α)^k，于是至少误判一次的概率是：

P = 1 − (1 − α)^k

k=3 时 14.3%，k=10 时 40.1%，k=20 时 64.2%，k=50 时 92.3%。这组数说明一件事：**只要比较够多，「显著」几乎是必然的。** 它不依赖样本量，也不依赖研究者的人品，只依赖 k。

中医研究里 k 的增长有四个常见来源，而且往往同时发生：

- **多指标**：一组症状积分、一组实验室指标、一组量表维度，加起来二三十个。
- **多时点**：治疗前、2 周、4 周、8 周、随访 3 个月，每个时点各测一遍。
- **多组别**：三个剂量组加一个对照组，两两比较 6 次。
- **多亚组**：按性别、年龄段、证型、病程、中心切分，十几层。

这四类比较并不是「同一个问题的重复测量」，它们各自都是独立的判断机会。**报告时把它们合起来数 k，才是诚实的 k。**

## 二、两种错误率：FWER 与 FDR

校正方法分成两族，区别在于「控制什么」。

**FWER（族错误率）**：整个比较族里**至少出现一次**假阳性的概率。控制 FWER 的方法保证：即使做了 20 次比较，全部比较里连一次假阳性都不出现的概率至少是 1−α。这是最严格的约束，适合**确证性研究**——你只打算宣称「有」，且这个「有」会被写进指南。

**FDR（错误发现率）**：在所有**被宣称的发现**里，假阳性所占的**比例**的期望。控制 FDR 在 5%，意味着「我宣称的 20 个发现里，平均约有 1 个是假的」。这是较宽松的约束，适合**探索性研究**——你要从上百个候选里筛出一批去做下一步验证，允许其中有一些被后续淘汰。

两者的差别可以用一句话记住：**FWER 问「我会不会说错」，FDR 问「我说对的那批里错了多少」。** 一项研究该用哪一种，取决于它处在证据链的哪一环，而不是取决于哪种方法能让结果更好看。

| 口径 | 控制对象 | 适用 | 代价 |
|---|---|---|---|
| FWER | 至少一次假阳性 | 确证性试验、主要终点 | 比较多时几乎全灭 |
| FDR | 假阳性占比 | 探索性筛选、组学、多指标初筛 | 允许少量假阳性进入下一轮 |

## 三、三种实现：Bonferroni、Holm、BH

用一组 10 个 p 值演示（升序）：0.001、0.008、0.021、0.039、0.041、0.062、0.110、0.190、0.350、0.620。

**Bonferroni**：门槛降到 α/m = 0.05/10 = 0.005。只有 0.001 通过，**保留 1 个**。简单、保守，比较数一多就几乎没有生还者。

**Holm（逐步降门槛）**：把 p 值升序排列，第 i 个与 α/(m−i+1) 比较。第一个 0.001 对 0.005，通过；第二个 0.008 对 0.00556，不通过，**立即停止**，其后一律不拒绝。结果同样是 1 个，但它比 Bonferroni 更容易留住多个真效应——当有 5 个真效应时，Holm 的把握度明显更高。

**Benjamini–Hochberg（BH）**：升序排列后，找最大的 k 使 p₍ₖ₎ ≤ (k/m)·α，则拒绝前 k 个。本例中：

| 秩 k | p₍ₖ₎ | (k/10)×0.05 | 是否满足 |
|--:|--:|--:|---|
| 1 | 0.001 | 0.005 | 是 |
| 2 | 0.008 | 0.010 | 是 |
| 3 | 0.021 | 0.015 | 否 |
| 4 | 0.039 | 0.020 | 否 |

最大满足的 k=2，于是**保留 2 个**：0.001 与 0.008。第三个 0.021 被放弃——注意它比 (3/10)×0.05=0.015 大，所以不满足；但它比 0.02 的「第 4 档门槛」也大，两处都不满足，结论一致。

三种方法给出「1 个」与「2 个」两种答案。这不是谁算错了，而是**它们回答的问题不同**：Bonferroni/Holm 说「这两个里至少有一个是假的概率不超过 5%」，BH 说「这两个里假阳性的期望比例不超过 5%」。写论文时必须说明用了哪种、为什么。

实现只在十几行。仓库里这一章的 `code/main.js` 给的就是这两条口径（`bonferroni` 与 `bh`），可以直接对照：

```js
function bh(pvalues, alpha = 0.05) {
  const m = pvalues.length;
  const idx = pvalues.map((p, i) => ({ p, i })).sort((a, b) => a.p - b.p);
  let k = 0;
  idx.forEach((x, rank) => { if (x.p <= ((rank + 1) / m) * alpha) k = rank + 1; });
  // 拒绝的是排序后的前 k 个，不是「所有 p ≤ k/m·α 的」——后者是常见实现错误
  return idx.slice(0, k).map((x) => x.i);
}
```

那段注释指的是一个真实存在的实现 bug：先算出 k、再用阈值筛全部 p 值，会把排序靠后但 p 值恰好很小的条目也拉进来，破坏 BH 的单调结构。**校正算法的正确性，靠的是「前 k 个」这个结构，不是阈值本身。**

## 四、校正救不了的四件事

校正只能约束「事先声明过的比较集合」。以下四件事，任何校正都无能为力。

**其一，事后挑指标。** 如果主结局是看完数据才选的，校正只是给挑选行为披了一件外衣。防止办法是预注册：方案里写定主结局、次要结局、分析人群与统计方法。

**其二，结局替换。** 方案写「症状总分」，论文报「某单项积分」，因为后者显著。这在校正框架里查不出来，只能靠方案与论文对读。

**其三，亚组挖掘。** 十几个亚组里挑出显著的那一个，报成「亚组分析提示某人群获益」。亚组结论只有在**交互作用检验**显著、且有生物学理由时才值得报告；单纯「这一层 p<0.05、那一层 p>0.05」不构成交互证据。

**其四，发表偏差。** 阴性结果不投稿、不发表，导致文献里的「显著」比例远高于真实比例。这不是一项研究内部的多重性，而是整个文献层的多重性，校正管不到。识别办法是漏斗图与 Egger 检验（Meta 分析层面），以及看是否有预注册、是否有阴性结果的登记。

校正是在「比较已经做完」之后打的补丁，所以更值得学的是两种在设计阶段就把多重性压下去的做法。

**固定序列检验（gatekeeping）。** 把结局按重要性排成一条链：主终点 → 第一层次要终点 → 第二层次要终点。只有当上一环显著时，下一环才检验，α 不必分摊给全部。逻辑是「你只在前面那个问题已答『是』时才问后面那个问题」，因此错误率不会被重复消耗。它要求顺序在方案里写定，事后调换顺序等于把 gate 拆了。

**拆成发现集与验证集。** 若手上有 300 例，与其在一批数据上测 20 个指标再做 BH，不如用 100 例做探索（不设显著性门槛，只看效应量与方向），把筛出的 3 个候选放到独立的 200 例上验证（门槛回到 0.05，不必校正）。**同一批数据既筛又验，再怎么校正也不可信**——筛选用的信息已经渗进了验证的样本里。这也是内部验证与外部验证的根本区别：前者只调整乐观程度，后者才是独立证据。

| 做法 | 多重性处理 | 代价 |
|---|---|---|
| 全指标 BH 校正 | 事后控制 FDR | 真效应可能被校正掉 |
| 固定序列 | 事前分层，α 不分摊 | 顺序必须预设，不能回改 |
| 发现集 + 验证集 | 验证集只验少数假设 | 需要更大总样本 |

## 五、发表偏差：为什么「小样本阳性」扎堆

发表偏差有一个可观察的印记：**小样本研究的效应量系统性偏大。** 原因很直接——小样本只有效应足够大时才能越过显著性门槛，效应小的那些做了也发不出来。于是文献里留下的是「小样本 + 大效应」的组合，而大样本研究给出的是更接近真实的、更小的效应。

这带来一个实务上的判断：看到「某小样本研究（n=30）报告效应量是后续大样本研究的 2–3 倍」，第一反应应当是发表偏差或选择性报告，而不是「那个中心的技术特别好」。同理，一项中医干预的 Meta 分析里，若漏斗图明显不对称、小样本研究集中在图的右下角，整体效应估计大概率被高估。

还有一层与本章直接相关：**探索性研究的多重性，会通过发表偏差被放大。** 一项测了 50 个指标的研究，即使做了 BH 校正、只报 3 个，这 3 个里仍可能有假阳性；如果这 3 个被后续研究反复引用而阴性重复不发表，文献就会固化一个不存在的效应。校正降低的是单篇论文内的错误率，降低不了文献层的。

## 六、代价与边界

- **校正会吃掉真效应。** 样本量不足时，真实的中等效应在 Bonferroni 下会掉出去。这是校正的正当代价，必须写进局限性，而不是悄悄改用不校正的口径。
- **BH 假定检验之间独立或正相关。** 指标高度相关时（同一量表的多个维度、同一证候的多个症状），FDR 控制会偏松；此时可用更保守的 BY 方法或先做降维。
- **「主结局只有一个」比任何校正都重要。** 一个预先声明的主结局加若干标注为探索性的次要结局，其可信度高于十个指标都做 BH 校正。
- **本章数字为教学示意。** 10 个 p 值、20 个指标与 64.15% 均为演示计算而设定，不对应任何真实研究；实际分析须在方案中写明比较族、校正方法与主结局。
