## 学习目标

- 说清「做 20 次独立检验、α=0.05，至少一次假阳性的概率约 64%」是怎么算出来的
- 实现 Bonferroni 与 Benjamini–Hochberg（BH）两种校正，并说明各自控制的是什么
- 判断一份结果表该用哪一种校正，并写出理由
- 指出校正**不能**挽救什么（比如事先没定主结局、事后挑指标）

## 核心概念

### 为什么要校正

《医学统计学·方差分析》一章在讲完两两比较后专门提醒：多组间反复比较会放大第一类错误。原因很简单：

$$P(\text{至少一次假阳性})=1-(1-\alpha)^m$$

$m=20$、$\alpha=0.05$ 时约 0.64。也就是说，**什么都不做的研究，二十个指标里几乎必然有一个「显著」**。

### 两种校正，控制的是不同的东西

- **Bonferroni**：$\alpha'=\alpha/m$，控制**族错误率（FWER）**——任意一次假阳性的概率。保守，指标多时几乎全灭。
- **BH（Benjamini–Hochberg）**：把 p 值升序排列，找到最大的 $k$ 使 $p_{(k)}\le \frac{k}{m}\alpha$，则前 $k$ 个拒绝。控制**错误发现率（FDR）**——被宣称的发现里假阳性的**比例**。探索性研究通常更合适。

关键区别：FWER 问「我有没有说错一次」，FDR 问「我说对的那批里错了多少比例」。前者适合确证性研究，后者适合筛选。

FWER 一侧还有一个比 Bonferroni 更聪明的做法：**Holm 逐步法**。把 p 值升序排列后，第一个与 $\alpha/m$ 比较，第二个与 $\alpha/(m-1)$ 比较，一旦某一步不显著就停止，之后的一律不拒绝。它同样控制 FWER，但在真有多个效应时比 Bonferroni 更容易留住结果。本课先实现 Bonferroni 与 BH 两条，是因为它们分别代表「最保守」与「按比例控制」两个极端，把这两个搞懂，中间的变体都是同一思路的调整。

## BUILD IT：从零实现

```js
function bh(pvalues, alpha = 0.05) {
  const idx = pvalues.map((p, i) => ({ p, i })).sort((a, b) => a.p - b.p);
  let k = 0;
  idx.forEach((x, rank) => { if (x.p <= ((rank + 1) / idx.length) * alpha) k = rank + 1; });
  return { k, rejected: idx.slice(0, k).map((x) => x.i) };  // 注意：拒绝的是"前 k 个"
}
```

## 验证

```bash
node code/main.js
node --test code/main.test.js
```

预期：给出的 10 个 p 值中，Bonferroni 只留下 1 个（p=0.001），BH 留下 2 个（0.001、0.008）——差异恰好说明两种口径的取舍。

## 代价与边界

- **校正救不了事后挑指标**。如果主结局是分析完才选的，任何校正都是装饰；预注册才是解药。
- **BH 假设检验之间独立或正相关**。指标高度相关时（同一证候的量表与症状积分），FDR 控制会偏松。
- **校正后不显著 ≠ 没有效应**。样本量不足时，真效应也会被校正掉，这叫「校正的代价」，必须写进局限性。
- **它不解决多重性之外的偏倚**：选择性报告、结局替换、分组不随机，校正一个都管不了。

> **免责声明：** 本章的代码与阈值用于教学与统计分析演练，不构成研究结论或临床建议；真实研究须按预注册方案与期刊统计要求执行。

## 练习

1. 把 α 从 0.05 改到 0.01，观察 BH 的拒绝集合如何变化，说明为什么 α 必须在分析前定。
2. 构造一组高度相关的 p 值（如 0.01、0.011、0.012…），观察 BH 的表现在哪里失效。
3. 若研究只有一个主结局与五个次要结局，你会怎么分配 α？写出方案与理由。

## 进阶思考

「做了很多比较」本身不是错，**不承认做了很多比较**才是错。校正方法的真正价值不是让结果变好看，而是逼研究者在动手之前就想清楚：我到底要回答几个问题。
