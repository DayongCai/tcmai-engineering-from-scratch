# 只报一个均数不叫描述，得报一对 · 提示词

## 用途

给「只报一个均数不叫描述，得报一对」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「一个分布有三个特征，缺一项就被误读 → 先看表，再选指标 → 偏态分布该报什么：中位数与四分位数间距 → 离散的三种口径，各回答不同的问题」这条链。

## 提示词

```
我在学《医学统计学》第 2 章「只报一个均数不叫描述，得报一对」，本章 5 节 / 2,590 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 均数与中位数差多少
   - 左尾被截断了
   - 看形状选指标，不看习惯选指标
   - 四分位数间距
   - 是标准差除以均数，用于比较
   - 的差异，标准误描述
4. 本章自陈的边界（不得越过）：
   - **描述性指标不承担推断。** 中位数 5.30 与均数 5.71 谁更能代表这批人，取决于你想描述的是「典型个体」还是「总体平均负担」；两种问法的答案不同，不是谁对谁错。
   - **稳健有代价。** 中位数与四分位数间距在正态资料上的效率低于均数与标准差；样本很小时（n<10），四分位数几乎由个别点决定，反而不稳。
   - **频数表与直方图的形态受组距支配。** 同一批数据换组距可以看起来单峰也可以看起来双峰。凡结论依赖形状的判断，都应给出组距并做敏感性检查。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```
