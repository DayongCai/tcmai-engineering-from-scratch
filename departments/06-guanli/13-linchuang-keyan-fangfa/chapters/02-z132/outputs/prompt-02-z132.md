# 设计不是越严格越好，是能答你那个问题的那个 · 提示词

## 用途

给「设计不是越严格越好，是能答你那个问题的那个」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三种设计各自回答什么问题 → 对照的四种形态，各有各的偏差 → 随机化怎么做才算数 → 单病例随机交叉：把 n=1 变成可检验」这条链。

## 提示词

```
我在学《临床科研方法学》第 2 章「设计不是越严格越好，是能答你那个问题的那个」，本章 5 节 / 2,772 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 随机对照试验
   - 真实世界研究
   - 单病例随机交叉
   - 安慰剂或假操作对照
   - 这 8 个百分点的差距全部来自时间漂移，与疗法无关
   - 其一，序列生成
4. 本章自陈的边界（不得越过）：
   - **没有「最好的设计」，只有「与问题匹配的设计」。** 把随机对照试验当唯一标准，会做出大量外部效度极低的研究；把真实世界当捷径，会做出大量混杂未控的相关性研究。两者都不构成证据链。
   - **设计一旦启动就改不动。** 入组开始后再改对照、改结局、改随机方法，都属于方案偏离，必须在报告中说明并做敏感性分析；改得越多，结论越弱。
   - **单病例设计不能替代群体证据。** 12 例的反应者比例可以支持「这类患者中可能存在反应亚型」，不能支持「该疗法有效」。它的价值在于提出更精确的假设，而不是结论。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章讨论研究设计与对照的选择，属方法学内容，不构成研究结论或临床建议；具体操作以现行规范与所在机构制度为准。
