# 回归不是「控制变量」，是把混杂摊在桌面上 · 提示词

## 用途

给「回归不是「控制变量」，是把混杂摊在桌面上」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「关联的三种读法 → 粗效应为什么会偏 → 回归在做什么 → 四个前提与它们被违反时的样子」这条链。

## 提示词

```
我在学《临床科研方法学》第 6 章「回归不是「控制变量」，是把混杂摊在桌面上」，本章 6 节 / 2,802 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 把第三种写成第一种是谦虚，把第一种写成第三种是失范
   - （样本波动，可用区间与重复研究排除）、
   - （第三个变量同时影响两者，靠设计与调整排除）、
   - 能在看数据之前判断方向，是评价一项观察性研究是否可信的重要线索
   - 在病情、年龄相同的患者之间
   - 必须报告粗效应与调整效应两个数
4. 本章自陈的边界（不得越过）：
   - **回归不能创造随机化。** 调整后的 OR=1.00 说明「在已测变量相同的患者中未见差异」，不说明「该方无效」——它也可能是「该方对所有人都一样，只是医师按病情分配」。
   - **调整过度与调整不足同样有害。** 把中介变量（如「服药依从性」若在暴露之后）放进模型，会抹掉真实效应；把结局的下游变量放进模型，会引入对撞偏倚。
   - **模型的选择应预设。** 主模型、协变量清单、敏感性分析方案都该在方案里写定。看完数据再挑模型，等于把结论写在数据之后。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章讨论关联分析与回归模型的解释边界，属方法学内容，不构成研究结论或临床建议；具体操作以现行规范与所在机构制度为准。
