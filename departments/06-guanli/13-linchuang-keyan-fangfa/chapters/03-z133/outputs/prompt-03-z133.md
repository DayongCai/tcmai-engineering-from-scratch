# 样本量不是越多越好，是够看清你要看的那点差 · 提示词

## 用途

给「样本量不是越多越好，是够看清你要看的那点差」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「抽样：便利样本推断不了总体 → 样本量的三个输入与一个公式 → 率与均数：两套算法 → 失访与不依从：分母要膨胀」这条链。

## 提示词

```
我在学《临床科研方法学》第 3 章「样本量不是越多越好，是够看清你要看的那点差」，本章 5 节 / 2,618 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 单纯随机抽样
   - 用便利样本算出率、再推断到全市，是中医临床研究里最常见的一处越界
   - 不报 ICC 与设计效应的整群研究，其样本量是虚的
   - δ（预期差值）
   - 临床认为有意义的最小差值
   - 最终可分析例数
4. 本章自陈的边界（不得越过）：
   - **样本量算得再准，也只是「按假设成立的前提」。** δ、σ 都是估计值，估偏了样本量就偏了。稳妥的做法是按 δ 的下限与 σ 的上限各算一次，取较大者，并在方案里说明取值依据。
   - **把握度 0.80 意味着两成机会漏掉真效应。** 这是被普遍接受的代价，不是保险。对确证性研究、对将要写进指南的结论，0.90 更合适。
   - **κ 不是万能的。** 它对边际分布敏感，患病率极低时即使一致率很高，κ 也会很低（κ 悖论）。报告时应同时给出一致率、κ 与具体的分歧条目。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章讨论抽样、样本量估算与测量一致性，属方法学内容，不构成研究结论或临床建议；具体操作以现行规范与所在机构制度为准。
