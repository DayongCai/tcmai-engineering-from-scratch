# 二十个指标里总有一个 p<0.05，这不是发现 · 提示词

## 用途

给「二十个指标里总有一个 p<0.05，这不是发现」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「多重性的算术 → 校正方法：三档强度 → 哪些「多重」必须校正 → 显著与可复现之间隔着把握度」这条链。

## 边界

本章讨论多重比较与可复现性，属方法学内容，不构成研究结论或临床建议；具体操作以现行规范与所在机构制度为准。
