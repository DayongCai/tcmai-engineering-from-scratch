# 结局选错，检验再对也答错了题 · 提示词

## 用途

给「结局选错，检验再对也答错了题」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「结局的三层：硬终点、替代终点、中间指标 → 替代终点要满足三个条件 → 主结局、次要结局与复合终点 → 量表：分数怎么变成结论」这条链。

## 提示词

```
我在学《临床科研方法学》第 5 章「结局选错，检验再对也答错了题」，本章 5 节 / 2,661 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 中医临床研究绝大多数主结局落在这一层
   - 干预显著影响该指标
   - 该指标显著影响硬终点
   - 干预对硬终点的效应，能被该指标的变化完全解释
   - 主结局只能有一个
   - 报告复合终点时必须列出各组分的事件数与效应
4. 本章自陈的边界（不得越过）：
   - **硬终点不是总能等到。** 罕见病、进展缓慢的疾病、经费有限的课题，只能用中间指标。此时正确的表述是「本研究以证候积分为主结局，未评估长期结局，结论限于症状层面」，而不是把中间指标的结果写成「疗效确切」。
   - **MCID 本身有估计误差。** 不同锚定方法算出的 MCID 可能相差一倍，报告时应说明来源与方法，并在讨论中给出区间。
   - **复合终点会掩盖异质性。** 它能提高效率，也会让「减少了住院」被读成「改善了预后」。使用它就要承担解释的透明义务。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章讨论结局指标的选择与统计检验的匹配，属方法学内容，不构成研究结论或临床建议；具体操作以现行规范与所在机构制度为准。
