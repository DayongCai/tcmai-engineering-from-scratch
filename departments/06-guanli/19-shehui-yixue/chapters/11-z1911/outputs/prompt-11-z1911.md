# 样本不是缩小版的人群 · 提示词

## 用途

给「样本不是缩小版的人群」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「抽样框：最常被跳过的一步 → 四种设计，四种方差代价 → 权重：三个动作，一个后果 → 无应答与测量误差：两个方向相反的问题」这条链。

## 提示词

```
我在学《社会医学》第 11 章「样本不是缩小版的人群」，本章 7 节 / 2,821 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 靠网格员维护，更新及时但边界模糊：租户登记不全，新楼盘可能还没纳入
   - 不精确有方向
   - 加权修不了它
   - 单纯随机抽样
   - 系统抽样（含按规模大小成比例抽样，PPS）
   - 事后分层（raking／post-stratification）
4. 本章自陈的边界（不得越过）：
   - **加权不能修补覆盖偏差。** 框外的人没有权重。判断一份调查能不能用，先问「框是什么、漏了谁」，而不是先问样本量。
   - **无应答调整依赖「相似」假定。** 应答者与不应答者相似这个前提几乎总是不完全成立，偏差方向可以推断，大小不能。
   - **设计效应是可算的，但常被忽略。** 整群设计的样本量不乘 deff，等于自己把精度砍掉一半。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章讨论调查设计与抽样的方法学，不构成统计调查的实施规范，也不构成任何调查结论的引用依据。具体抽样方案、权重构造与数据发布，以调查执行机构的原始技术报告与现行统计制度为准；具体操作以现行规范与所在机构制度为准。
