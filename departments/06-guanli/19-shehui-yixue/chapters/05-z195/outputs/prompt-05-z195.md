# 需要、需求与利用：三个词不是一回事 · 提示词

## 用途

给「需要、需求与利用：三个词不是一回事」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「四种「需要」，选错分母就选错政策 → 从需要到利用：一条会漏水的管道 → 可及性不是「有没有医院」 → 供方也会制造需求」这条链。

## 提示词

```
我在学《社会医学》第 5 章「需要、需求与利用：三个词不是一回事」，本章 8 节 / 3,453 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 规范性需要最大，感觉性需要最小，表达性需要居中，比较性需要最不稳定
   - （年龄、性别、教育、健康信念）、
   - （收入、医保、交通、是否有固定医生）、
   - 一是排队与拥挤并存
   - 二是转诊单向
   - 三是能力空心化
4. 本章自陈的边界（不得越过）：
   - **「满足需要」是无底承诺。** 需要由标准界定，标准可以无限提高；任何体系都无法满足全部规范性需要。政策必须明说优先级，而不是用「应保尽保」掩盖取舍。
   - **把利用量当需要量会系统性高估。** 利用量里含诱导需求与防御性医疗，用它推算需要，会得出「需要越来越多、资源永远不够」的结论，从而把管理问题误诊为投入问题。
   - **可及性的五维不能互相替代。** 提高报销比例（可负担性）不能弥补没有夜诊（可接受性）；建新院区（可得性）不能弥补没有全科医生（适切性）。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章讨论卫生服务需要、需求与利用的分析框架，不构成对任何机构或地区的绩效评价，也不构成诊疗意见。具体服务配置与支付政策，以现行制度与有权机关规定为准；具体操作以现行规范与所在机构制度为准。
