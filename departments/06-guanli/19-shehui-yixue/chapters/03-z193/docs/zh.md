# 第 3 章 · 公平不是平均：可避免的差异才叫不公平

> **MOTTO:** 「不患寡而患不均，不患贫而患不安。」——《论语·季氏》
>
> **PROBLEM:** 甲乙两县人均卫生支出都是 2,800 元，甲县的婴儿死亡率是乙县的 1.8 倍。钱一样多，结果不一样；把甲县的支出提到乙县的 1.5 倍，差距可能缩到 1.2 倍，但不会归零。卫生公平要处理的正是这个函数关系——投多少钱、缩多少差距、剩下的那部分由什么决定。它不是一个「人人享有」的口号，而是一道有系数的分配题。

**双根因定位:** 环境逼迫（资源永远不够，分配必然有取舍；取舍标准一旦不明说，就由权力与信息暗中决定，而权力与信息本身就分布不均）+ 知识积累（公平的知识本是「差异的度量—差异的可避免性—差异的机制—补偿原则」四段，教材常压缩成「公平与效率」一句口号；口号喊得响，一算就露馅）

## 一、三个词要先分开

**健康不平等**是描述：人群之间健康指标存在差异，这是个事实判断，不带褒贬。

**健康不公平**是规范判断：这些差异是可避免的、不公正的，并且是可以补救的。这三个词是关键门槛——如果差异由生物学差异或自由选择造成、且无法补救，就不叫不公平。

**健康 Inequity 与 Inequality 的混用**会造成两种相反的错。一种是把所有差异都叫不公平，于是所有资源都用于抹平差异，效率尽失；另一种是只承认「不可避免的差异」，于是把可避免的部分也说成命。判据只能逐条过：这个差异有没有干预手段？有手段而没做，就是不公平；没有手段，就是不平等。

世卫组织对健康不公平的经典定义把三个词并列：**可避免的、不公正的、可补救的**。三个词必须同时成立。缺一个，讨论就会滑向情绪。

## 二、三种公平观，对应三种政策

**平等主义**有两种形态。同等可及（equal access for equal need）要求同样的需要得到同样的服务；同等结果（equal outcome）要求健康指标本身趋同。前者可实现，后者几乎不可实现——因为健康的决定因素大部分在卫生系统之外。

**按需分配**区分横向与纵向。横向公平是同需同治：两个病情相同的人，不该因为收入不同而得到不同的治疗。纵向公平是不同需不同治：需要多的人应该得到更多。这两条在预算约束下会打架——多给重症患者，就少给轻症人群，后者的总数往往更大。

**可行能力**（森的框架）把公平定义为「实质自由」的平等：不是资源平均，而是每个人拥有的真实选择集相当。一个人有医保但住的地方没有医院，他的选择集并不比没医保的人大多少。这个视角的好处是把「可及性」纳入公平本身，而不只是当作效率问题。

三种公平观没有唯一正确的答案，选哪一种取决于价值判断。但选完之后必须一致：一边说按需分配，一边按人口平均拨款，就是两套逻辑混用。

## 三、怎么量：四个指标与一个陷阱

差异要被管理，先要被测量。常用四个指标，各有分工。

**极差与率比。** 取最富与最穷两个五分位，比较健康指标。它直观、好传播，缺点是只看两端，中间的变化被扔掉；而且对分组方式敏感，五分位与十分位会给出不同结论。

**集中指数。** 把人群按经济水平排序，画出健康的累积份额曲线，曲线与对角线的偏离程度×2 就是集中指数。它的优点是用了全体信息，能回答「差异是不是系统性的」：指数接近 0 表示健康在各经济层均匀分布，为负表示健康更集中在穷人身上。缺点是对健康指标的方向敏感——死亡率越低越好，患病率越低越好，方向搞反，结论就全反。

**斜率指数。** 用回归拟合各组的健康水平对组别秩次的关系，斜率表示「每降一个社会层级，健康差多少」。它保留单位，比集中指数更易解释。

**泰尔指数。** 最大的用处是可分解：总差异 = 组间差异 + 组内差异。这个分解能回答一个实际问题——「区域之间的差距」与「区域内部的差距」，哪一个占大头。如果组内占大头，那么把资源在区域间搬来搬去，效果有限。

举一个分解的示意（演算设定，非实测）：某省卫生资源分布的总泰尔指数为 0.11，其中地市之间贡献 0.04、地市内部贡献 0.07。含义很清楚：**跨市调资源的边际效果，只有市内调资源的一半左右。** 这类结论比一句「分布不均」有用得多，因为它指向了动作的层级。

陷阱主要有三个：一是分母偷换，把「就诊人次」当「患病人数」，算出来的公平其实是利用的公平；二是缺少年龄标化，老龄化程度不同的地区一比就失真；三是把统计上的不平等直接等同于不公平，跳过了「可避免性」的检验。

## 四、中间的大多数

梯度的存在使公平政策面临一个反直觉的选择。假设人群按风险分为五层，最穷层发病率 12%、次层 9%、中层 7%、次富 5%、最富 3%。如果只看率，最穷层是最该干预的；但如果看**可归因的病例数**，因为中间三层的人数远多于最穷层，它们贡献的病例总数可能是最穷层的数倍（此为构造示例，非实测）。

这解释了罗斯的预防悖论为何在公平议题上同样成立：以「缩小最穷与最富的差距」为唯一目标，可能只触及很小一部分人群负担；以「压低整个人群的暴露水平」为目标，反而让最穷层受益更多（因为他们的基线暴露最高）。两个目标并不冲突，但资源分配的顺序不同。

实践中的折中是「普遍主义加比例投入」（proportionate universalism）：服务对所有人开放，但投入按需要的程度递增。它既避免只做靶向项目造成的污名与漏出，也避免平均主义造成的梯度固化。

## 五、筹资的公平：谁付、付多少

卫生公平有两端：谁得到服务（服务公平），谁承担费用（筹资公平）。

筹资公平也分横纵。横向是同等支付能力的人承担同等负担；纵向是支付能力强者承担更高比例。判断标准常用「灾难性卫生支出」：家庭现金卫生支出占家庭消费（或可支付能力）超过某一比例，即视为灾难。世卫组织长期使用「自付费用超过家庭可支付能力 40%」这一口径，可持续发展目标监测则用「超过家庭消费 10%」的口径。两个口径不可混用，因为它们的分母与政策含义都不同。

一个示意（演算设定）：某家庭年消费 5 万元，其中食品等基本支出 2 万元，可支付能力约 3 万元；一次住院自付 1.2 万元，占可支付能力 40%，刚好触线；若按消费口径算则是 24%，早已越线。**同一个家庭，两个口径给出「刚好」与「严重」两种判断**。所以引用任何灾难性支出的比例，必须先问用的是哪个分母。

筹资结构里最影响公平的是自付比例。自付比例高，穷人要么不去看病（需要被压制），要么去了因病致贫（消费被挤压）；两种结果都不进入「利用率」的统计，于是数据看起来还不错。预付制（税收、社会保险）把风险从生病时转移到平时，是公平性更强的方式，代价是需要强制参保与征缴能力。

## 六、补偿原则怎么落到预算

公平的最后一步是钱怎么分。三条可操作的规则。

**第一，转移支付按需要而非按人口。** 按人口拨款隐含假设「人人需要相同」，实际上老龄化程度高、死亡率高、贫困率高的地区需要更多。需要指数通常由 65 岁以上人口占比、标准化死亡率、低保人数等构成，权重可以争论，但方向应当明确。

**第二，基层能力建设是前置补偿。** 把钱投在县医院与社区中心，比事后给穷人报销更早介入；但前置补偿见效慢，且容易被地方财政挪去填别的缺口，需要专项与绩效双约束。

**第三，补需方优于只补供方。** 直接补机构会稳定供给，但也可能固化低效；补需方（医保、救助、券）让居民用脚投票，能逼供方改善，代价是信息不对称下患者未必选得对。

补偿还有一个副作用要提前防：靶向补贴会带来污名，污名会降低使用率，最终使政策效果打折。设计上应尽量让受益资格自动认定（数据比对），而不是让人一次次去证明自己穷。

## 七、代价与边界

- **公平与效率的对立被夸大了，但并非不存在。** 在资源总量固定时，向低效地区倾斜确实会牺牲一部分产出；否认这一点会让政策失去可信度，承认它才能谈补偿。
- **没有社会经济变量，就量不出不公平。** 大量卫生统计只按地区与年龄分组，不采集收入与教育，导致不公平问题在数据层面「不存在」。这是最实际的障碍，比方法争论更紧要。
- **补偿可能制造新的不公平。** 按历史缺口分配会奖励过去投入不足的地区，惩罚提前改善的地区（棘轮效应）；设计时要看需要，而不是看缺口。
- **本章的泰尔指数分解、灾难性支出比例、分层发病率均为构造示例。** 它们只用于展示算法关系，不对应任何真实省份或家庭；不引具体调查的实测值。
- **公平的判断含价值成分。** 本章给出的是度量工具与判据，不替读者选定哪一种公平观；任何具体分配方案都须经公开讨论与法定程序。

**免责声明:** 本章讨论健康公平的度量与筹资分析，不构成对任何地区分配方案的评价，也不构成诊疗意见。具体筹资比例、补偿标准与考核办法，以现行制度与有权机关规定为准。
