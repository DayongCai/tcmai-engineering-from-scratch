# 支付方式是一根杠杆，撬动的是医生的手 · 提示词

## 用途

给「支付方式是一根杠杆，撬动的是医生的手」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「钱从三个口袋来，第四只口袋定行为 → 按项目付费：多做一项，多收一份 → 总额与病种：控费如何变成挑病人 → 集采降价的账要算到质量上」这条链。

2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 任何一种支付方式都会被「做透」，做到它的激励指向的极端
   - 第一处，省下的钱去哪了
   - 第二处，供应稳不稳
   - 第三处，质量有没有变

4. 本章自陈的边界（不得越过）：
   - **支付方式没有最优解，只有匹配。** 按项目适合急性期与技术复杂的病例，按病种适合诊断明确、路径成熟的病例，按人头适合长期健康管理。用一种方式覆盖所有服务，一定会把某类服务做坏。
   - **控费与质量天然张力。** 任何控费都会在某些环节压缩服务，问题在于压缩的是「不必要」还是「必要」。区分两者需要临床判断，而支付规则只认编码。
   - **风险调整无法做到完全公平。** 调整因子越多，编码负担越重，造假空间越大。粗调会推诿，细调会造假，这是两难。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。

## 边界

本章讨论卫生筹资与支付方式的管理逻辑，不构成诊疗意见，也不构成保险或投资建议。具体支付政策与报销待遇，以现行规定和经办机构解释为准；具体操作以现行规范与所在机构制度为准。
