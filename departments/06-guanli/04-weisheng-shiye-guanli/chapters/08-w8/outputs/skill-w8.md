# 并重写在方针里，落在编制与支付上

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 专门化带来边缘化
- 一体化带来稀释
- 商业保险为主
- 其一，口径不同
- 其二，人口结构不同
- 其三，购买力不同

## 边界

- **专门机构会强化部门视角。** 设了专门机构，中医药的事有人管了，但也容易与其他部门形成壁垒。协调机制能缓解，不能消除。
- **国际比较容易变成选择性引用。** 想论证「投入不足」，就引费用占比；想论证「效率不高」，就引可避免死亡。同一个国家的数据可以支撑相反的结论，比较必须同时给出反面证据。
- **移植的成功案例有幸存者偏差。** 被广泛引用的成功案例，往往是条件最齐备的那几个；失败的案例很少被写进教材。学经验时，也要学它的前提。
- 本章讨论卫生体制的国际比较与中医药管理，不构成诊疗意见，也不构成对任何国家制度优劣的最终判断。疾病诊治须由具备资质的医师依现行规范作出。
