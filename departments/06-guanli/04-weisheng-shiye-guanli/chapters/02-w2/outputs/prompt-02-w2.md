# 规划不能只写在纸上：资源配置是按规则分，不是按需要给 · 提示词

## 用途

给「规划不能只写在纸上：资源配置是按规则分，不是按需要给」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「政策落地时被改写了三次 → 需要量、需求、利用：三种算法三个数 → 床位是最容易被当成政绩的指标 → 人的配置是乘法，不是加法」这条链。

## 边界

本章讨论卫生资源配置的分析方法，不构成行政决策建议，也不构成诊疗意见。任何规划编制、床位核定与人力配置方案，须经主管部门按现行程序审定；具体操作以现行规范与所在机构制度为准。
