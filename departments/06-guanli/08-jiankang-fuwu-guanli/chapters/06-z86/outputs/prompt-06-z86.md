# 支付方式决定行为，比任何动员都硬 · 提示词

## 用途

给「支付方式决定行为，比任何动员都硬」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「谁付钱，谁定义“值得做” → 五种付费单元，五种行为 → 每一种支付都会长出自己的对策 → 健康管理为什么难付费」这条链。

## 边界

本章为教学材料，讨论健康服务支付方式与激励机制，不构成医疗、保险、投资或政策意见；具体操作以现行规范与所在机构制度为准。
