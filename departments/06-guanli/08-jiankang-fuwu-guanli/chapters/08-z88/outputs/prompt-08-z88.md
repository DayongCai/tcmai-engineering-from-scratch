# 协同不是开会，是把责任写进同一张流程单 · 提示词

## 用途

给「协同不是开会，是把责任写进同一张流程单」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「健康问题大多不在卫生部门手里 → 协同的三种机制与两种失败 → 应急的四段与一个真问题：谁指挥 → 平战结合的账怎么算」这条链。

## 边界

本章为教学材料，讨论健康服务的多部门协同与应急管理，不构成医疗、应急指挥、法律或政策意见；具体操作以现行规范与所在机构制度为准。
