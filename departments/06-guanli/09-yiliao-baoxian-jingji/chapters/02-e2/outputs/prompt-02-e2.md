# 医疗的需求是被供给方写出来的：「物多则贱」在这里失效 · 提示词

## 用途

给「医疗的需求是被供给方写出来的：「物多则贱」在这里失效」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「需求是派生的：要的不是胃镜，是「不再疼」 → 价格弹性为什么这么低：三重锁定 → 供给诱导需求：不是道德问题，是激励结构问题 → 供给的硬约束：床位、人、时间都不可储存」这条链。
