# 价格不是标价，是行为指令：换个支付方式，同一台手术会有两种做法 · 提示词

## 用途

给「价格不是标价，是行为指令：换个支付方式，同一台手术会有两种做法」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「价格的双重身份：补偿成本，还是发出信号 → 成本核算：平均成本定价会把自己推上死亡螺旋 → 四种支付方式的激励对照 → 每种支付方式都在它压住的地方长出新的规避」这条链。

## 边界

本章讨论价格、成本核算与支付方式的激励后果，属卫生经济学教学分析，不构成任何定价、支付标准或临床技术选择的建议；具体操作以现行规范与所在机构制度为准。
