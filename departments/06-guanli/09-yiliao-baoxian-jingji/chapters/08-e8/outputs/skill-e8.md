# 控费的最后一步不是省钱，是把钱从低价值处搬到高价值处

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 这就是「静态可支撑 5 年」与「动态 3 年见底」的差别
- 先调支付方式
- 加钱解决结构问题，钱一定被结构吞掉
- 智能审核的算术要说清
- 它优化的是「可检测性」，不是「价值」
- 分级诊疗的边界也要说清

## 边界

- **控费与质量是同一个约束下的两个目标，不是先后关系。** 先控费再补质量，等于先把水位降下来再修堤，中间那段时间的损失无法追回。
- **结余不是成绩。** 靠推诿、延迟服务、压缩必要治疗换来的结余，会在两三年后以再入院率、并发症率、患者自费上升的形式回来。看结余必须同时看质量指标。
- **中医的支付改革不能等「证型标准化完成」再做。** 分组可以先用粗颗粒（病种 + 主要证候要素），边做边细化。等标准完美的结果是永远不做，而按项目付费的扭曲每天都在发生。
- 本章讨论基金平衡、控费工具与中医支付的资源配置逻辑，属卫生经济学教学分析，不构成对任何地区医保政策、支付标准或考核指标的建议。
