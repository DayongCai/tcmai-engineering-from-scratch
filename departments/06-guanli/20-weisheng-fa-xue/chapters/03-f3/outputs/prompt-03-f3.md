# 规则不是写出来的，是审出来的 · 提示词

## 用途

给「规则不是写出来的，是审出来的」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「立法权限：三张清单 → 部门立法与试验型规范 → 法治不等于「有法可依」 → 应急状态下的规则生成」这条链。

## 提示词

```
我在学《卫生法学》第 3 章「规则不是写出来的，是审出来的」，本章 5 节 / 3,415 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 第一张，谁能立
   - 没有权限的机关，写出来的东西再合理也不是法
   - 第二张，立什么
   - 第三张，立多细
   - 价值与权限写在上层，技术与流程写在下层，二者之间留一道可检验的接口
   - 其一，把管理便利写进规则
4. 本章自陈的边界（不得越过）：
   - **讲立法技术容易变成「程序崇拜」。** 程序齐备不等于内容正当：一部经过完整程序制定的规范，仍可能把不合理的负担固定下来。程序的作用是让不同意见有机会进入记录，不是替实质判断背书。
   - **「法治」不能被窄化为「多发文件」。** 文件密度与治理效果没有正相关；规则过多会互相缠绕，执行者只能在冲突中选择性地适用，反而削弱了规则的权威。
   - **应急法治的三条底线是判断框架，不是审查标准。** 具体措施是否合法，仍须回到现行规范的具体授权与程序要求；本章给出的是提问顺序，不是结论。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，讨论卫生立法权限、规范生成过程与卫生法治的运行环节，不构成法律意见或政策建议。任何具体的规范制定、备案审查、应急措施与救济事项，须依现行有效规范并由有权机关或具备资格的专业人员处理；具体操作以现行规范与所在机构制度为准。
