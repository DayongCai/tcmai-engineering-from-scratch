# 一次准入要问四遍：卫生法的渊源不是书目，是顺位 · 提示词

## 用途

给「一次准入要问四遍：卫生法的渊源不是书目，是顺位」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「四层规范，四种语速 → 效力是一条依据链，不是一份排名 → 卫生法为什么必须分层 → 冲突：三条规则与一个陷阱」这条链。

```

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 效力与具体度成反比
   - 看到一句话，先问它在哪一层
   - 为什么下位规范里有内容
   - 下位规范不能给管理相对人增设上位规范没有的义务
   - 规范性文件不能作为处罚依据
   - 标准分强制与推荐
4. 本章自陈的边界（不得越过）：
   - **讲层级容易滑向「高位阶崇拜」。** 高位阶规范抽象，抽象意味着裁量，裁量意味着同一句话在不同地方可以有不同做法。层级解决的是「谁说了算」，解决不了「说得够不够清楚」。真正难办的案件，往往不是层级不清，而是同一层级里写得太粗。
   - **效力判断不能替代合法性判断。** 一条规定在正确的层级上，也可能内容不当；一条规定层级不高，也可能完全合法有效。顺位只解决冲突时的取舍，不解决规定本身好不好。
   - **依据链的追问有现实上限。** 越往上追，授权越概括；追到某一层，往往只能得到「由国务院规定」「由部门制定具体办法」这样的概括授权。此时能做的不是继续追问，而是检查下位规范有没有明显超出该授权的事项范围。
```

## 边界

本章为教学材料，讨论卫生法规范的层级结构、效力顺位与适用方法，不构成法律意见或行政决策建议。任何具体的准入、处罚、救济事项，须依现行有效规范并由有权机关或具备资格的专业人员处理；具体操作以现行规范与所在机构制度为准。
