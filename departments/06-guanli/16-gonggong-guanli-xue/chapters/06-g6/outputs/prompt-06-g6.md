# 决策的难处不是选对，是让人相信选得对 · 提示词

## 用途

给「决策的难处不是选对，是让人相信选得对」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「公共领导的三个额外约束 → 风格：从特质到情境，再到风险 → 决策的两条腿：科学性与民主性 → 失误的类型与责任的分配」这条链。

## 提示词

```
我在学《公共管理学》第 6 章「决策的难处不是选对，是让人相信选得对」，本章 5 节 / 2,658 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 向上级、向班子、向服务对象、向舆论同时交代。多头负责的难处不在「忙」，在
   - 在约束中制造可接受性
   - 行为与情境理论
   - 变革型与交易型
   - 把变革型领导理解成个人魅力
   - 科学性解决「判断对不对」
4. 本章自陈的边界（不得越过）：
   - **本章不评价任何具体领导者或决策。** 领导行为高度情境化，脱离具体条件评价既不公平也不准确。
   - **数字为演算设定。** 会签部门数、流转天数只用于说明程序与判断的分离，不对应任何真实方案或地区。
   - **科学与民主不是万能配方。** 两者都可能被形式化：专家论证可以是背书，公众参与可以是布景；判断标准是「异议有没有可能改变结论」。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，讨论公共领导与公共决策的一般原理，不构成对任何机构、领导者或具体决策的评价，也不构成行政建议；具体操作以现行规范与所在机构制度为准。
