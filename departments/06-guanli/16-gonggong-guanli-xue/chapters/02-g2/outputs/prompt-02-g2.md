# 每一代理论都在修上一代的偏 · 提示词

## 用途

给「每一代理论都在修上一代的偏」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「二分：一个有用但不成立的假设 → 官僚制：效率的极致，也是信息的漏斗 → 行为与决策：人不是完全理性的执行器 → 新公共管理：把公民当顾客的收益与代价」这条链。

## 边界

本章为教学材料，梳理公共管理理论的演进脉络与相互批评，不构成对任何国家、机构或改革方案的评价，也不构成政策建议；具体操作以现行规范与所在机构制度为准。
