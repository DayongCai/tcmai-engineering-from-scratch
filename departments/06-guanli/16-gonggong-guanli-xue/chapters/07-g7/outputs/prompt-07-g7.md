# 编制是硬的，激励是软的，人夹在中间 · 提示词

## 用途

给「编制是硬的，激励是软的，人夹在中间」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三个硬约束，决定了一切 → 入口：考试录用解决了什么，又牺牲了什么 → 考核、晋升与流动 → 薪酬、激励与职称」这条链。

## 边界

本章为教学材料，讨论公共部门人力资源管理的一般规律与制度约束，不构成对任何机构、岗位或个人的评价，也不构成人事管理建议；具体操作以现行规范与所在机构制度为准。
