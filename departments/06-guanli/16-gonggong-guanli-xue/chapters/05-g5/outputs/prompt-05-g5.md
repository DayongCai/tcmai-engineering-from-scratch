# 政策分析不是写文件，是把取舍摆上桌 · 提示词

## 用途

给「政策分析不是写文件，是把取舍摆上桌」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「政策是什么：权威性的分配 → 阶段论：有用的地图，危险的地形 → 三种分析工具，各自的适用面 → 决策模型：真实选择是怎么发生的」这条链。

## 提示词

```
我在学《公共管理学》第 5 章「政策分析不是写文件，是把取舍摆上桌」，本章 5 节 / 2,749 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - （给特定群体好处，成本由一般财政承担）、
   - （从一个群体转移给另一个群体，冲突最大）、
   - （限制行为，成本落在被规制者身上）、
   - 第一，不是线性的
   - 第二，不是有始有终的
   - 第三，忽略了执行者的位置
4. 本章自陈的边界（不得越过）：
   - **工具不替你做价值判断。** 成本收益、成本效果、多准则都只排序，不决定；谁承担代价、代价值不值，是政治问题。
   - **本章数字为演算设定。** 报告页数、成本与效果数值只用于说明工具的差异，不对应任何真实规划或地区。
   - **不评价具体政策方案。** 政策随形势调整，具体评价会迅速过期；方法可以长期使用。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，讨论公共政策分析的类型、工具与评估逻辑，不构成对任何政策、地区或机构的评价，也不构成决策建议。政策制定须依现行制度与法定程序进行；具体操作以现行规范与所在机构制度为准。
