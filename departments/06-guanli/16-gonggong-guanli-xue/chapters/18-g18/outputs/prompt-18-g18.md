# 智能系统能替代判断的搬运，替代不了判断的承担 · 提示词

## 用途

给「智能系统能替代判断的搬运，替代不了判断的承担」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「技术站在三个位置，位置决定责任 → 行政场景的四个前提 → 偏差有三种形态，各有各的来源 → 智能教学平台：能替什么，不能替什么」这条链。


本章为教学材料，讨论智能技术在公共管理与教学中的应用位置、前提条件与责任配置，不构成对任何系统、产品、机构或个人的评价，也不构成技术选型或合规意见；具体操作以现行规范与所在机构制度为准。
