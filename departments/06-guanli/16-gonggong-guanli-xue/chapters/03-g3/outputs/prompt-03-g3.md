# 组织图上是方块，运行中是接口 · 提示词

## 用途

给「组织图上是方块，运行中是接口」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「什么算公共组织：三个判据与四个类型 → 五种结构，五种病 → 条块：中国公共组织的真实运行轴 → 事业单位：一只脚在行政，一只脚在市场」这条链。

## 边界

本章为教学材料，讨论公共组织的结构、类型与运行机制，不构成对任何机构的评价或改革建议；具体操作以现行规范与所在机构制度为准。
