# 预算是用数字写成的政策 · 提示词

## 用途

给「预算是用数字写成的政策」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「支出为何只增不减，收入为何总不够用 → 预算的原则与类型 → 过程：为什么钱总在年底花完 → 政府间财政关系：事权、财权与转移支付」这条链。

## 边界

本章为教学材料，讨论公共财政与预算管理的一般原理，不构成对任何地区财政状况的评价，也不构成财政或投资建议；具体操作以现行规范与所在机构制度为准。
