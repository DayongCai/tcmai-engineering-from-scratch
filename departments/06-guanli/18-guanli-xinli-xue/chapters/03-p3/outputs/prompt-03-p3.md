# 每一种人性假设，都是一份事先写好的免责声明 · 提示词

## 用途

给「每一种人性假设，都是一份事先写好的免责声明」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「假设不是描述，是设计前提 → 三份经典假设，三种制度形态 → 复杂人、文化人、道德人：三种补丁 → 中国式人性观：三条主线与一个提醒」这条链。

## 边界

本章为教学材料，不构成人事管理、绩效分配或法律意见。涉及考核、奖惩与岗位设计的制度安排，须依现行劳动法律法规、行业规范与本机构章程，由具备相应资质的人员决定；具体操作以现行规范与所在机构制度为准。
