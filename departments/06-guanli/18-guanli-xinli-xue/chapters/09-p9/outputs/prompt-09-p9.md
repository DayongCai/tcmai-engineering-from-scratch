# 团队不是人凑齐就有战斗力，群体先生产出来的是一套规范 · 提示词

## 用途

给「团队不是人凑齐就有战斗力，群体先生产出来的是一套规范」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「群体结构的三根柱子：规范、角色、地位 → 凝聚力是双面的 → 从众、顺从、服从：三种不同程度的放弃 → 助长与懈怠：人多了，出力反而少」这条链。
