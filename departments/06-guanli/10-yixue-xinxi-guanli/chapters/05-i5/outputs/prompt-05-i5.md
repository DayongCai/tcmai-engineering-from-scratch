# 技术与资源检索：检索能力决定你能看见多少证据 · 提示词

## 用途

给「技术与资源检索：检索能力决定你能看见多少证据」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「检索式的四个变量 → 查全与查准：两个可以算的数 → 院内资源：先组织，再检索 → 技术选型：先划责任边界，再谈先进」这条链。

## 边界

本章为卫生信息技术与信息资源检索的教学讨论，不构成技术选型、检索策略或临床用药建议；具体操作以现行规范与所在机构制度为准。
