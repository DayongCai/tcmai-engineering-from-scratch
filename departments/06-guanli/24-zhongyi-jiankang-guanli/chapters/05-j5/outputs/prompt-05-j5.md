# 干预方案不是最优解，是这个人做得到的那一版 · 提示词

## 用途

给「干预方案不是最优解，是这个人做得到的那一版」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三因制宜是三条约束，不是三句口号 → 分层与强度：先决定投多少，再决定做什么 → 方案要素：五件东西，缺一件就会烂尾 → 依从性：换掉，而不是加上」这条链。

## 提示词

```
我在学《中医健康管理》第 5 章「干预方案不是最优解，是这个人做得到的那一版」，本章 6 节 / 2,883 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 档位越高，方案条目应当越少
   - 频次与总量
   - 用替换代替增加
   - 减少决策点
   - 一次只改一项，改稳了再加
   - 把支持者拉进来，但不要外包
4. 本章自陈的边界（不得越过）：
   - **可执行会牺牲一部分理论上的最优。** 一个只做一件事却做满一年的方案，收益通常高于一个做八件事却只做两周的方案。承认这一点，需要从业者放弃「方案要显专业」的心理需求。
   - **少即是多，但不能少到无意义。** 只留「多喝温水」这种零成本建议，等于没有干预。方案强度必须与分层匹配：一档可以极简，三档不能。
   - **依从性不能全归因于个人。** 把失败归为「不听话」，会掩盖方案设计、沟通方式与支付能力的问题。但反过来把一切归因于环境，也会让服务失去抓手——可执行的判断标准是：在现有条件下，下一个能被改动的具体环节是什么。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章讨论健康干预方案的设计原则、分层、要素与随访规则，不构成诊疗意见，也不构成任何具体干预处方。涉及疾病诊断、用药与治疗性操作，以现行诊疗规范与执业范围为准；具体操作以现行规范与所在机构制度为准。
