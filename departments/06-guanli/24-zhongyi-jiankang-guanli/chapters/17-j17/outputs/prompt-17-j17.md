# 数据能告诉你发生了什么，不能告诉你是不是你干的 · 提示词

## 用途

给「数据能告诉你发生了什么，不能告诉你是不是你干的」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「四个问题，四种证据 → 真实世界数据：四个偏差 → 效果口径：从中间指标到终点 → 转化：从方案到常规，从经验到可传」这条链。

## 提示词

```
我在学《中医健康管理》第 17 章「数据能告诉你发生了什么，不能告诉你是不是你干的」，本章 5 节 / 2,664 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 怎么做到的？
   - 把基线说清楚
   - 最小重要差异
   - （做了几次、做了哪些、完成率）、
   - （行为与状态的改变）、
   - 案例总结：经验怎么变成能传的东西
4. 本章自陈的边界（不得越过）：
   - **严谨的评价更慢、更贵、更不好看。** 加一个对照组、追一年失访、按基线分层，每一项都在增加成本、降低数字的漂亮程度。这是必须付的代价，否则得到的是一堆无法支撑决策的数字。
   - **真实世界数据不能替代对照研究。** 它可以做得很好，但它的天花板就是「相关」。把相关说成因果，是这一领域最常见的夸大方式。
   - **个案的价值在解释，不在证明。** 用个案证明疗效，无论个案多真实，都会系统性地高估效果。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章讨论中医健康管理的研究设计、证据评价与转化路径，不构成科研方法学指南或诊疗意见。涉及人体研究的伦理审查、数据使用与结果发表，以现行科研管理、伦理审查与个人信息保护的相关规定为准；具体操作以现行规范与所在机构制度为准。
