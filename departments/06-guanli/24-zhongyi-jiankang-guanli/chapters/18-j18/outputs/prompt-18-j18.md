# 平台的价值不在功能多，在换个人接手时口径不变 · 提示词

## 用途

给「平台的价值不在功能多，在换个人接手时口径不变」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「先统一三样东西，再谈功能 → 单元库与注释：让每句话都能回到出处 → 数据门禁：什么能进，什么只能看 → 智能辅助：在教学场景成立，在服务场景要退一步」这条链。

## 提示词

```
我在学《中医健康管理》第 18 章「平台的价值不在功能多，在换个人接手时口径不变」，本章 5 节 / 2,880 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 单位与量纲
   - 保存最小可引用的内容单元，每个单元有稳定的标识与出处（哪本书、哪一章、哪一节）
   - 解释不得扩张原文的适用范围
   - 学习与教学数据
   - 内容与知识数据
   - （只收集完成该目的所必需的部分）、
4. 本章自陈的边界（不得越过）：
   - **统一口径会牺牲一部分表达自由。** 术语定死之后，一些细腻的差异无法在字段里体现。缓解的办法是保留自由文本，并把自由文本排除在统计之外——各得其所，而不是强行统一到失真。
   - **平台会放大已有的问题。** 流程不清、责任不明、口径不一，在没有平台时只是局部摩擦，上了平台会变成系统性故障。所以上平台之前先理顺流程，而不是指望平台理顺流程。
   - **留痕与效率存在张力。** 每一次访问都记录、每一处修改都留版本，会让人觉得麻烦。这个代价必须付，因为不可追溯的服务在出事时无法自证。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章讨论课程平台在术语统一、内容溯源、数据门禁与教学评价上的设计原则，不构成技术方案或诊疗意见。涉及个人信息保护、数据安全与教学内容审核，以现行法律法规、行业规范与主管部门规定为准；具体操作以现行规范与所在机构制度为准。
