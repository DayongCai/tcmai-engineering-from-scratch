# 设备测的是信号，管理要的是判断，中间那一步没有自动化 · 提示词

## 用途

给「设备测的是信号，管理要的是判断，中间那一步没有自动化」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「数据链有四段，误差在第三段放大 → 监测数据能说什么，不能说什么 → 智能应用的三种角色 → 算法与数据风险：四种」这条链。

## 提示词

```
我在学《中医健康管理》第 16 章「设备测的是信号，管理要的是判断，中间那一步没有自动化」，本章 5 节 / 2,889 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 能说：相对自己的变化
   - 能说：趋势与节律
   - 不能说：诊断
   - 不能说：因果
   - 不能说：单点异常
   - 数据只覆盖被测量的那一部分
4. 本章自陈的边界（不得越过）：
   - **技术不会减少人力，只会改变人力的位置。** 采集自动化了，解释与动作仍然要人做，而且因为数据变多，这部分工作量是增加的。把技术当成减人的工具，是最常见的误判。
   - **数据越多，注意力越稀缺。** 一条预警的价值与预警总量成反比。控制预警量比提高算法精度更能改善实际效果。
   - **设备有生命周期，服务没有。** 设备两年一换，换的时候数据连续性会断。方案设计时就要考虑断档之后的接续，而不是等它发生。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章讨论数字技术在健康管理中的应用边界、数据解释与风险控制，不构成技术选型建议或诊疗意见。涉及个人信息保护、医疗器械管理与数据安全，以现行法律法规与主管部门规定为准；具体操作以现行规范与所在机构制度为准。
