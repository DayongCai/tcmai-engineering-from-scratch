# 课程表是一份资源分配文件，不是一个知识清单 · 提示词

## 用途

给「课程表是一份资源分配文件，不是一个知识清单」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「学时是零和的，先承认这一点 → 经典课的三种上法，以及「背」与「解」的先后 → 中西医课程的合流点只有一个：病床边 → 课程整合的四种做法与同一种失败」这条链。

## 提示词

```
我在学《中医教育学》第 3 章「课程表是一份资源分配文件，不是一个知识清单」，本章 6 节 / 3,170 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 先背骨架，后解释；背的不是全文，是能自动提取的结构
   - 西医负责排除与兜底，中医负责个体化处置
   - 以证为核心整合
   - 整合课没有主人
   - 同一形式连续使用超过一个学期，效果会衰减
   - 任何整合都会增加协调成本
4. 本章自陈的边界（不得越过）：
   - **任何整合都会增加协调成本。** 一门整合课的备课量是单门课的数倍，而课时费按学时算。不给协调人减其他工作量，整合就只能停在文件上。
   - **经典的通读必然被牺牲。** 五年制的总量装不下「通读四部经典 + 完整西医学 + 一年实习」。承认牺牲哪一部分，比声称「都兼顾」更有用；不同的牺牲方式培养出不同的人，这本身是办学定位问题，不是教学技术问题。
   - **背与解的顺序有例外。** 少数学生先理解后记忆反而更牢，但这是个体差异，不能作为课程设计的默认假设。课程设计要按多数人的认知路径来，个别差异靠辅导补。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章讨论课程组织方法，不构成医学建议。课程方案与学时分配的调整，须经院校教学委员会审定并履行相应程序；具体操作以现行规范与所在机构制度为准。
