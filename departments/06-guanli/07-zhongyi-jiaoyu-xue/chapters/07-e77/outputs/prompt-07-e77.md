# 认证保证的是底线，不是水平 · 提示词

## 用途

给「认证保证的是底线，不是水平」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三套标准，三件不同的事 → 标准化真正买到的是什么 → 代价：从「大纲」到「考点」的滑坡 → 中医特色的标准难题：能固定什么，不能固定什么」这条链。

## 边界

本章讨论教育标准与认证的一般方法，不构成对任何具体标准条文的解释。标准适用与认证结论，以主管部门正式文件为准；具体操作以现行规范与所在机构制度为准。
