# 考什么就学什么：选择题考不出会看病的人 · 提示词

## 用途

给「考什么就学什么：选择题考不出会看病的人」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三种考核，测的是三种不同的东西 → 病例题怎么出才算数 → 标准化病人与多站式考核：能移植什么，不能移植什么 → 形成性评价：把一次门诊变成一次教学」这条链。

2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 总学时与总经费固定时，学校会自然选择最便宜的那一种

   - 给干扰信息

4. 本章自陈的边界（不得越过）：
   - **提高考核真实性必然提高成本。** 一次床边考需要病人、考官、场地、时段，规模一大就办不动。现实的折中是分层抽考：全体笔试、抽样床边考、重点学生全考。抽样会带来公平争议，这必须有制度安排而不是靠解释。
   - **评分表会诱导「表演」。** 学生学会对着评分表做动作：问诊问全、话说得漂亮，判断却是空的。评分表越细，表演越容易。对冲的办法是保留一项不列评分点的整体判断，由考官独立给分。
   - **分数与能力只弱相关。** 高分学生多半知识结构好，但不等于是好医生；低分学生里有反应慢但手稳的。用分数排序分配资源，是制度上的必要，不是能力上的判断。

## 边界

本章讨论教学评价方法，不构成医学建议。考核方案、及格标准与成绩认定的调整，须经院校教学委员会审定并履行相应程序；具体操作以现行规范与所在机构制度为准。
