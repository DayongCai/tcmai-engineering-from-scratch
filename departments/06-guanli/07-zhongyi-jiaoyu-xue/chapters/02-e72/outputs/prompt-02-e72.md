# 学科强不等于学生会看病：这是两本账 · 提示词

## 用途

给「学科强不等于学生会看病：这是两本账」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「学科与专业，是两种不同的东西 → 四个层次的人才培养，各有各的判据 → 学科反哺教学：三条真路径，三条假路径 → 师资是学科与教学的接口，也是最细的瓶颈」这条链。

## 边界

本章讨论学科与教学的组织关系，不构成医学建议。任何考核指标与培养方案的调整，须经院校学术委员会与主管部门审定；具体操作以现行规范与所在机构制度为准。
