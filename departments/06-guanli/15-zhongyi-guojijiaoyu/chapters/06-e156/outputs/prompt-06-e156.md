# 学生记住的是比喻，用的是比喻 · 提示词

## 用途

给「学生记住的是比喻，用的是比喻」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「比喻的义务：讲完必须讲它何时失效 → 三类概念错位 → 教学次序：安全边界要前置 → 传播的三条边界」这条链。

## 提示词

```

正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；

   - 每给出一个比喻，紧接着给出它在什么情况下失效
   - 一个比喻是否合格，看它能不能被推翻

   - 它们描述的是同一个身体的不同层面，不是同一层面的两种说法

4. 指出本章写到类别就止步、不再给参数的地方。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，不构成医学意见、诊断或治疗建议。任何临床处置与教学中的操作训练，须依现行规范、执业范围与所在机构制度，由具备相应资质的人员实施；具体操作以现行规范与所在机构制度为准。
