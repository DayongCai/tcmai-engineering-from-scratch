# 名字定不下来，课就讲不下去 · 提示词

## 用途

给「名字定不下来，课就讲不下去」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三层标准，三种管辖 → 翻译的三种失配 → 不可译的部分怎么处理 → 标准落地的四道工程约束」这条链。

## 提示词

```
我在学《中医国际教育与传播》第 2 章「名字定不下来，课就讲不下去」，本章 4 节 / 2,763 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 第一层是术语标准，管「叫什么」
   - 第二层是分类标准，管「算不算病」
   - 第三层是产品与服务标准，管「合不合格」
   - 判据很简单：看到一个标准，先问它管的是名、是类、还是物
   - 第一种是一对多
   - 第二种是假朋友
4. 指出本章写到类别就止步、不再给参数的地方。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章内容用于教学，不构成诊疗或执业意见；具体操作以现行规范与所在机构制度为准。
