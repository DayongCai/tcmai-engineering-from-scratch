# 战略不是决定做什么，是决定不做什么 · 提示词

## 用途

给「战略不是决定做什么，是决定不做什么」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「战略只回答两个问题 → 外部分析：把"五力"翻译成医院语言 → 内部分析：优势要经得起四问 → 三种通用战略，在医院里的变形」这条链。

## 提示词

```
我在学《管理学基础》第 6 章「战略不是决定做什么，是决定不做什么」，本章 6 节 / 2,863 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 在哪里竞争？凭什么赢？
   - 定范围与增长方式（做深本地、还是向外扩张；是综合发展、还是专科突出）
   - 定每个业务单元怎么赢（脾胃病靠什么吸引患者，康复靠什么留住患者）
   - 职能战略才是真战略，因为它决定钱和人往哪走
   - ：区域内同级同类机构。要点不是"有几家"，而是
   - 上级医院把专家门诊开到你家门口
4. 本章自陈的边界（不得越过）：
   - **聚焦有政治成本。** 放弃某些方向意味着某些科室、某些人得不到资源，这在机构内部是真代价；本章只指出取舍的必要性，不提供摆平内部阻力的方案。
   - **门槛数值是演算设定。** 6,000 万元、750 万元、1,800 万元、八个与三个，均为演示"最低有效规模"的构造，不对应任何真实机构、真实评审标准或真实投入水平；实际门槛须以现行评审条件与区域规划为准。
   - **五力与通用战略是分析工具，不是处方。** 它们帮助定位问题，不产生答案；医院还受价格管制、公益约束与行政隶属关系约束，工具结论必须经过这三重过滤。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，讨论战略分析框架、通用战略与落地方法，不构成管理咨询意见、区域卫生规划建议或投资建议；具体操作以现行规范与所在机构制度为准。
