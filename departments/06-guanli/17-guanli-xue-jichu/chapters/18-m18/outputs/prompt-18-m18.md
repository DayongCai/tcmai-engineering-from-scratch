# 这门课真正的作业，是回去改一件你科室里的事 · 提示词

## 用途

给「这门课真正的作业，是回去改一件你科室里的事」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「这门课的结构：一条链，四个位面 → 读法：三遍 → 练法：把一个真实问题走完整条链 → 平台：数字现算，不手打」这条链。

```

正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
```

## 边界

本章为教学材料，讨论本课程的结构、学习方法与平台用法，不构成教学效果承诺、技术评估意见或管理咨询意见；具体操作以现行规范与所在机构制度为准。
