# 第 5 章 · 计划不是把目标写下来，是把目标拆到有人签字

> **MOTTO:** 「凡事豫则立，不豫则废。」——《礼记·中庸》
>
> **PROBLEM:** 某院年度工作计划 32 页、87 项任务，每项都有责任科室与完成时限。年底自评：完成 84 项，完成率 96.6%。同一份年报里，三个年初定下的核心指标却一条没动——平均住院日 8.6 天仍是 8.6 天，门诊满意度 86.4 分仍是 86.4 分，四级手术占比 21.3% 还降了 0.4 个百分点。**96.6% 的完成率与零进展同时成立，说明计划已经与目标脱钩。** 87 项任务里，能追到"谁签了字、按什么口径验收、没做到怎么办"的，不超过二十项；其余都是"开展了""推进了""组织了"。

**双根因定位:** 环境逼迫（年度考核按"任务完成率"取证，任务清单越细越容易做出高完成率，于是计划被写成了可勾选的清单而不是可验收的目标；同时外部检查项目逐年增加，任务只能加不能减） + 知识积累（计划的本质是把目标换算成责任与资源，而换算需要口径统一与优先级排序；多数机构没有这套换算的技术，只有"列任务—定期限—年底打分"三步，三步都绕开了换算）

## 一、计划有层次，层次错位是最常见的病

计划不是一个文件，是四个层次。**使命层**回答"我们为什么存在"——公立中医院的使命是提供可及的中医药服务，这一层不应年年改。**战略层**回答"未来三到五年靠什么赢"——重点专科、技术路线、区域定位。**年度计划**回答"今年做哪几件、做到什么程度"。**作业计划**回答"这个月这个班次谁做什么"。

四层之间是**换算**关系，不是并列关系。战略层选"以脾胃病与康复为双重点"，年度计划就必须回答：这两个方向今年各要新增多少门诊、多少床位、多少人才、多少设备，钱从哪来、从哪省。作业计划再把它落成排班与门诊单元。

层次错位的三种典型表现，都很好认。**上位空缺**：只有年度任务清单，没有战略选择，于是每个科室都要"全面发展"，资源被摊薄。**下位缺失**：有战略口号，没有年度分解，口号在文件里活三年，临床没感受。**同层混装**：把"加强学科建设"与"更换门诊叫号系统"写在同一张表上、同一个权重——前者是不可验收的方向，后者是可验收的动作，混在一起打分，结果是动作得分、方向失分。

## 二、目标分解是乘除，不是加减

这是计划工作里最容易做错的一步。

总目标分解到科室，常见做法是"按人头平摊"或"按去年基数加成"。两种做法都假设总目标是各部门目标的算术和，而现实中的关系更接近乘除：**全院的平均住院日不是各科室住院日的平均，而是各科室床日之和除以出院人数之和**；全院满意度不是各科满意度的简单平均，而是按各自的样本量加权。

口径搞错，分解就会失真，失真的分解会立刻被临床识别，然后被绕开。举例：某院把"平均住院日下降 1.2 天"按科室平摊，要求每个科室都降 1.2 天。外科从 9.8 降到 8.6 尚有可能，肿瘤内科从 12.4 降到 11.2 意味着把化疗周期压缩，这在临床上是错的。于是肿瘤内科选择"提高周转、分解住院"，指标好看了，患者负担重了——**不是科室不配合，是分解方式违背了指标的数学结构。**

正确做法是三步：**先算清全院指标的构成**（哪个科室贡献了多少床日、多少出院人次）；**再按贡献度分配责任**（贡献大的担得多，且要说明可压缩的空间在哪）；**最后允许科室提出"不可压缩"的说明并核减**，核减要留痕，因为它是下一次分解的依据。

## 三、可验收的目标长什么样

一个能进入计划的目标，要同时满足五条。缺任何一条，它都会在年底变成"开展了"。

| 要素 | 反例 | 合格写法 |
|---|---|---|
| 指标 | 提升服务能力 | 门诊满意度（第三方季度测评口径） |
| 基线 | 未写起点 | 2025 年 86.4 分 |
| 目标值 | 明显提升 | 89.0 分 |
| 时限与节点 | 年内 | 6 月底 87.5，12 月底 89.0 |
| 责任人与验收人 | 门诊部 | 责任：门诊部主任；验收：分管副院长 + 质控办 |

第五条最常被漏掉：**责任人与验收人必须是两个人。** 一个人既做又验，等于没有验收。医院里有一类指标常年不动，原因就在这里——牵头科室自己报数、自己评价、自己说完成了。

至于常被引用的 SMART 原则，要点在"可测量"与"有时限"，不在形式整齐。它常被误用成给每个目标硬凑五个字母：把不可测的目标（"提升中医特色"）硬写成"开展中医特色活动 12 次"，活动次数达标而特色没变。**SMART 是筛子，不是模具；过不了筛子的目标应当重新表述，不是改写成能过筛子的样子。**

还有一条比 SMART 更要紧的约束：**目标的数量本身就是一种资源配置。** 一份 87 项任务的计划，等于没有优先级；而执行者的注意力是有限资源，任务越多，每项分到的注意力越少，最后是靠"哪项催得紧"决定先做哪项。可操作的做法是强制排序：把任务分三档——**必须完成（不超过五项，与核心指标直接挂钩）、应当完成（有明确交付物）、可做可不做（列出但不分配资源）**。三档的比例大约 1∶3∶5，且必须完成的项要由院级会议逐项确认。**一份不写"可以不做"的计划，实际上把所有事都降级为"可以不做"。**

## 四、计划的方法：滚动、节点与预算

**滚动计划。** 年度计划一次做完十二个月，到第三个月就过期。滚动做法是：始终保留未来十二个月的完整计划，每季度（或每月）根据实际修订最近一期、顺延一期。代价是维护成本高，收益是计划不会在半年后变成历史文件。医院适用的是"年度定框架、季度滚动、月度调整"。

**里程碑与甘特。** 把任务拆成有交付物的节点，每个节点有日期与验收标准。甘特图的价值不在画得漂亮，在**把并行的依赖关系画出来**——新病房启用这件事，装修、设备进场、人员招聘、信息系统上线、医保编码申请五条线，任何一条晚两周，整体就晚两周。不画依赖，就会在最后一周发现还有一条线没动。

**PDCA 与预算。** PDCA（计划—执行—检查—处理）是节点管理的通用骨架，它的关键在 C 与 A 之间的连接：检查出来的偏差要能改到下一轮计划里，否则循环就断在 A。**预算则是计划最硬的形态**：任何一项计划，如果预算里没有对应的钱和人，它就只是意图。反过来，看一份预算就知道这家机构真正计划做什么——预算比文件诚实。

## 五、一次可复算的分解：1.2 天从哪来

看一个分解推演（演算设定，非实测）。

全院出院 24,000 例/年，平均住院日 8.6 天，占用床日 24,000 × 8.6 = 206,400 天。目标 7.4 天，占用床日降为 24,000 × 7.4 = 177,600 天，**全年释放 28,800 床日**。按目标住院日折算，这相当于新增收治能力 28,800 ÷ 7.4 ≈ 3,892 例/年，即收治能力提升约 16.2%（3,892 ÷ 24,000）。

接着把这 1.2 天拆成可追责的四段，四段之和必须等于 1.2：

| 环节 | 压缩量 | 责任 | 验收口径 |
|---|--:|---|---|
| 术前等待（检查预约与术前评估） | 0.50 天 | 医务科 + 手术室 | 入院至手术日的中位数 |
| 术后观察（出院标准执行） | 0.30 天 | 各手术科室 | 术后住院日的 P75 |
| 检查预约排队 | 0.25 天 | 医技科室 | 预约至完成的中位时长 |
| 出院结算与带药 | 0.15 天 | 住院处 + 药房 | 医嘱下达到离院的时长 |

0.50 + 0.30 + 0.25 + 0.15 = 1.20，账对得上。这一步做完，计划才从"全院降 1.2 天"变成四件具体的事：谁去改预约规则、谁去定出院标准、谁去把结算窗口前移。**没有这一步，1.2 天就只是一个会，不是一个计划。**

## 六、代价与边界

- **本章不主张计划越细越好。** 计划颗粒度过细会锁死现场判断，尤其在临床场景；一节里给出的五要素是"可验收"的最低要求，不是表格模板。
- **数值均为演算设定。** 87 项任务、96.6% 完成率、24,000 例出院、8.6 与 7.4 天、四段压缩量，都是为演示"分解要对得上账"而构造，不对应真实机构；实际指标须以本院统计口径与卫生行政部门口径为准。
- **指标之间存在替代关系。** 缩短住院日可能推高再入院率与门诊负担，本章的分解只处理"怎么把目标拆到人"，不处理"该不该设这个目标"；后者属战略判断，见第六章。
- **计划不能替代应变。** 计划的价值在于把资源与责任提前排好，使意外发生时还有余量可调；把计划当成不可变更的承诺，会在第一次冲击时全盘失效。
