# 计划不是把目标写下来，是把目标拆到有人签字 · 提示词

## 用途

给「计划不是把目标写下来，是把目标拆到有人签字」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「计划有层次，层次错位是最常见的病 → 目标分解是乘除，不是加减 → 可验收的目标长什么样 → 计划的方法：滚动、节点与预算」这条链。

## 提示词

```
我在学《管理学基础》第 5 章「计划不是把目标写下来，是把目标拆到有人签字」，本章 5 节 / 2,593 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 回答"未来三到五年靠什么赢"——重点专科、技术路线、区域定位
   - 回答"今年做哪几件、做到什么程度"
   - ：只有年度任务清单，没有战略选择，于是每个科室都要"全面发展"，资源被摊薄
   - ：有战略口号，没有年度分解，口号在文件里活三年，临床没感受
   - 全院的平均住院日不是各科室住院日的平均，而是各科室床日之和除以出院人数之和
   - 不是科室不配合，是分解方式违背了指标的数学结构
4. 本章自陈的边界（不得越过）：
   - **本章不主张计划越细越好。** 计划颗粒度过细会锁死现场判断，尤其在临床场景；一节里给出的五要素是"可验收"的最低要求，不是表格模板。
   - **数值均为演算设定。** 87 项任务、96.6% 完成率、24,000 例出院、8.6 与 7.4 天、四段压缩量，都是为演示"分解要对得上账"而构造，不对应真实机构；实际指标须以本院统计口径与卫生行政部门口径为准。
   - **指标之间存在替代关系。** 缩短住院日可能推高再入院率与门诊负担，本章的分解只处理"怎么把目标拆到人"，不处理"该不该设这个目标"；后者属战略判断，见第六章。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，讨论计划的层次、目标分解方法与节点管理，不构成管理咨询意见或绩效考核方案；具体操作以现行规范与所在机构制度为准。
