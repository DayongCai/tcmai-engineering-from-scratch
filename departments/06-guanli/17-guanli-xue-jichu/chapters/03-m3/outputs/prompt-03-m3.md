# 原理用来排除错误做法，方法才用来动手 · 提示词

## 用途

给「原理用来排除错误做法，方法才用来动手」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「四条基本原理，各有各的战场 → 原理与制度的差别：制度可以抄，原理不能 → 五种管理方法，各自的失效条件 → 一次可复算的改进：把收益算出来」这条链。

## 边界

本章为教学材料，讨论管理的基本原理与常用方法，不构成管理咨询意见、质量控制方案或绩效设计依据；具体操作以现行规范与所在机构制度为准。
