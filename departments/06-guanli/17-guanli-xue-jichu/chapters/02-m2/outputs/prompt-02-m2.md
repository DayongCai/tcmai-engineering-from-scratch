# 每一种"最优解"都是它那个年代的应急方案 · 提示词

## 用途

给「每一种"最优解"都是它那个年代的应急方案」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三次转向，各自回答一个不同的问题 → 从"唯一最优"到"视情况而定"：权变的收益与代价 → 理论丛林：学派为什么打不完 → 读任何一个理论，问三句话」这条链。

## 提示词

```
我在学《管理学基础》第 2 章「每一种"最优解"都是它那个年代的应急方案」，本章 5 节 / 3,436 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 它们认为组织的核心问题是什么
   - 第一次转向：效率
   - 生产过程可以被测量，测量结果可以被用来改进
   - 第二次转向：秩序
   - 规模扩大后如何让成千上万人的行动可预期

   - **本章不给"哪种理论更好"的结论。** 理论的有效性取决于条件，而条件要现地判断；本章只提供判断条件的三个问句，不提供答案。
   - **思想史的年份与主张以通行版本为准。** 泰勒一九一一年、法约尔一九一六年、韦伯的官僚制论述、霍桑实验一九二四至一九三二年、孔茨一九六一年、伯恩斯与斯托克一九六一年、伍德沃德一九六五年、劳伦斯与洛希一九六七年，均为通行纪年；不同版本与译本在个别年份上有出入，引用时应回原书核对。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，梳理管理理论的形成脉络与适用条件，不构成管理咨询意见或制度设计依据；具体操作以现行规范与所在机构制度为准。
