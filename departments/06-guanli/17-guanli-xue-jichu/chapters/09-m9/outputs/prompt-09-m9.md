# 人力不是成本项，是唯一会自己决定出多少力的资源 · 提示词

## 用途

给「人力不是成本项，是唯一会自己决定出多少力的资源」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三本账：编制、岗位与配比 → 工作分析：一切人力工作的地基 → 选人：先定标准，再定方法 → 育人与留人：培训的转化率才是问题」这条链。

## 边界

本章为教学材料，讨论人力资源管理的分析框架与激励理论，不构成人事处理依据、薪酬设计方案或管理咨询意见；具体操作以现行规范与所在机构制度为准。
