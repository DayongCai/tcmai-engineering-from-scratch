# 第 1 章 · 管理不是把事做完，是让同样的力气换出不同的结果

> **MOTTO:** 「兼足天下之道在明分。」——《荀子·富国》
>
> **PROBLEM:** 一家县级中医院去年门诊 48.6 万人次，比三年前增长 31%。同一个三年里，医师人均日接诊从 52 人次升到 68 人次，平均候诊时间从 28 分钟拉长到 46 分钟，门诊满意度从 91.2 分掉到 86.4 分，投诉件数增长 42%。院长在年终总结里写"业务量创历史新高"，医务科在另一份报告里写"人力已达极限"。两份文件都真，用的都是准确的数，指向的却是相反的结论。**业务量不是管理成绩，把投入换成产出的那一步才是。** 而这一步，恰好是"管理"这个词唯一不可让渡的内容。

**双根因定位:** 环境逼迫（医保支付方式改革与分级诊疗把医院从"多做多得"推到"做对才得"，服务量的增长不再自动等于可支配收入的增长，任何一处流程浪费都直接冲减结余；同时患者可择院，等待时间与体验成了可被比较的竞争变量） + 知识积累（管理作为可传授的知识，直到二十世纪才把"效率"从工匠经验里分离出来，形成可测量、可比较、可复制的判据；在此之前，做得好只能解释为"这个人能干"）

## 一、两个必须分开的词：效果与效率

管理学的全部讨论都建立在一个二分上，而这个二分在日常语言里几乎总是被混用。

**效果（effectiveness）**问的是目标达成程度：该做的事做成了没有。**效率（efficiency）**问的是投入产出比：用多少资源换来的。德鲁克把这两件事分别叫做"做正确的事"与"把事情做正确"，并明确指出后者不能补救前者——把一件不该做的事做得极好，只是加快了浪费的速度。

回到那家医院。门诊量增长 31%，从"服务人次"这个目标看是效果提升；但人均日接诊从 52 升到 68、候诊从 28 分钟拉到 46 分钟，说明单位时间内的产出虽然上去了，患者为获得服务付出的等待成本也上去了，效率的实际变化取决于你把等待算进谁的账。同一个数，在院长那里是政绩，在患者那里是代价，在医师那里是负荷。**管理者要做的第一件事，是把这三本账分开记。**

两者的改进手段是相反的，这也是必须分开的现实理由：

| | 效果 | 效率 |
|---|---|---|
| 关注 | 方向、目标人群、做什么 | 流程、等待、返工、单位成本 |
| 改善手段 | 重新选择病种结构、技术路线、服务边界 | 消除等待、减少重复、压缩非增值环节 |
| 判错的后果 | 做得越多偏得越远 | 越省越僵，把必要的冗余也砍掉 |
| 医院里的典型问句 | 这个病种我们该不该做 | 这台手术的平均周转为什么是 3.2 天 |

一句话判据：**方向错了，效率越高亏得越快。** 这是管理学里最便宜的一条经验，也是被违反得最多的一条。

## 二、五项职能不是五个科室

法约尔在一九一六年把管理的职能拆成计划、组织、指挥、协调、控制五项；后来的教材把它改写为决策、计划、组织、领导、控制、创新。名称变过几轮，内核没变：**职能是动作，不是部门。**

这个区分在机构里最容易被抹掉。医院设了质控办、运营管理部、绩效办、院办，看上去五项职能都有人管，于是科主任很容易认为"管理是职能部门的事，我只管看病"。结果就是：目标由院里下、标准由职能部门定、考核由绩效办算，而**病区的目标怎么落到每个医师头上、标准与本专科实际差在哪里、考核结果怎么反馈成下一年的改进**——这三件没有任何部门能替他做，因为它们必须发生在具体的人与具体的病人之间。

链条是有顺序的：决策定方向，计划把方向变成可考核的节点，组织把节点分给人，领导让人愿意做，控制检查做完没有、偏差在哪里。前一环答不上来，后一环就只能照着文件执行而不知道为什么。一家医院最常见的失效不是某一环做得差，而是**链条断在第二环**：院里有战略、科室有指标，中间那层"今年到底先做哪三件事、由谁负责、什么时候验收"是空的。空的一层不会自己长出来，它只能由人补。

## 三、管理者做什么：十种角色与三种技能

明茨伯格在一九七三年出版的《管理工作的本质》里做了一件当时很少有人做的事：他跟着管理者记录他们实际在做什么，而不是问他们认为自己应该做什么。结论是十种角色，归为三类。

**人际关系类**：挂名首脑（作为组织代表履行礼仪与法律义务）、领导者（激励与指导下属）、联络者（维护外部关系网络）。**信息类**：监听者（收集内外信息）、传播者（把信息传给内部）、发言人（对外发布）。**决策类**：企业家（发起变革、寻找机会）、混乱驾驭者（处理冲突与危机）、资源分配者（决定钱、人、时间投向谁）、谈判者（代表组织磋商）。

卡茨给出的技能三分更直白：技术技能、人际技能、概念技能。三者的配比随层级变化——基层管理者七成靠技术技能立身，高层管理者七成靠概念技能判断方向，人际技能则在每一层都是门槛而非加分项。这解释了一个常见错位：**把最好的外科医生提成科主任，往往同时损失了一名好医生和得到了一名差管理者**，因为提拔依据的是技术技能，岗位要求的却是概念技能与人际技能。

明茨伯格还有一条观察比十角色更值得记住：管理者的工作日是碎片化的。活动持续时间以分钟计，口头沟通占大头，打断频繁，连续思考的时间极少。这与"管理者坐在办公室里谋划战略"的想象相反。对读者的实操含义是：**如果你的一天被会议与临时事务填满，那不是你意志力的问题，而是岗位设计没有给判断留出结构位置。** 解决办法不是早起两小时，而是把判断类工作固化成节律——周例会解决横跨科室的冲突，月度复盘看偏差，季度评审动目标。让"思考"在日程上占一个不可挪动的格子，否则它永远排在所有急事之后。

## 四、管理学为什么不精确，以及不精确有什么用

管理学被归入软科学，它的结论形态是条件性命题："在什么条件下，采取什么做法，可能产生什么结果。"它不是定律。

不精确有三个来源。**变量太多**：一次管理变革同时受结构、人员、技术、政策、市场影响，无法像实验室那样隔离单一变量。**人的反身性**：被观察者知道自己被观察就会改变行为，霍桑实验本身就有这个麻烦；问卷里的社会期许偏差会让答案偏离真实态度。**因果难辨**：管理水平高的机构绩效好，既可能是管理促进了绩效，也可能是绩效好的机构才有资源改善管理——这在统计上叫内生性，在管理现场叫"说不清是谁成就了谁"。

但不精确不等于靠感觉。一门不精确的学科，它的知识形态是排除法：**它告诉你哪些做法在哪些条件下会失败，以及失败通常从哪一步开始。** 临床指南也不保证每个患者见效，但它把"不该做的事"划得很清楚；管理知识的第一用途同样是划界。学完一章管理理论，合格的收获不是"我知道该怎么管了"，而是"我知道在这个条件下，这种做法会在哪一步崩"。

## 五、在中医药机构里，管理的第一性问题

一般原理落到中医机构，会撞上三个具体的第一性问题。

**其一，服务的时间结构是尖的。** 针灸、推拿、熏蒸、穴位贴敷多集中在上午，患者也偏好上午来。如果按日均门诊量配置人力，上午必然排队、下午必然闲置，两者都不经济。这不是排班技巧问题，而是**产能的时间分布与需求的时间分布不匹配**，属于管理学里最经典的产能管理问题：要么错峰（预约分时、下午优惠、把部分治疗改为下午续做），要么扩容峰值（半日制医师、弹性班），要么改变需求（把复诊患者导到下午）。三条路都要付代价，没有免费的。

**其二，疗效难标准化，但流程可以。** 辨证论治的个体化是中医的核心价值，也是最难标准化的一段。但一个诊疗过程并不全是辨证：四诊信息的记录格式、处方审核的规则、煎药与配送的时限、复诊提醒的触发条件，这些都是可以标准化、可以测量、可以追责的环节。**把不可标准化的部分完整留给医师，把可标准化的部分坚决交给流程**，是中医机构管理的主要空间。反过来做——用统一模板去规范辨证——既压不住质量，又伤掉专业尊严。

**其三，双重目标是结构性的，不是口号。** 公益性要求覆盖基本医疗、可及、价格可承受；运营可持续要求收支平衡、有结余投入发展。任何一个指标单独最大化都会毁掉另一个：只讲公益，设备不更新、人才留不住；只讲运营，轻症患者被过度收治、疑难重症被推走。管理在这里的任务不是"兼顾"，而是**在具体的决策点上说清楚这一次让哪一边**，并把让出去的代价记账。说不清的地方，就是下一次纠纷的源头。

## 六、代价与边界

- **本章不给配比与指标的数值。** 床护比、医护比、人均日接诊量、候诊时限，随医院级别、地区、专科结构、支付方式与评审周期变化，须以现行规范和本院核定文件为准。正文里的 48.6 万人次、52 与 68 人次、28 与 46 分钟，是为一组对比而设的合成示例，不对应任何真实机构。
- **效果与效率的二分有失灵区。** 在公共卫生、急救、传染病防控这类场景，"效率"不能直接折算，因为公平与可及性本身就是目标而非约束。把二分硬套到公共卫生上，会得出"减少低收益服务"这种在伦理上站不住的结论。
- **管理学不替代医学判断。** 本章讨论的是组织如何配置资源与责任，任何一条都不能用来推翻临床指征、诊疗规范或药事管理规定；两者冲突时，专业规范优先。
- **"应该"不等于"已经"。** 本章描述的是职能应当如何衔接、角色应当如何配比，不保证任何一家机构已经做到。把规范文本当成现实描述，是管理类写作最普遍的误读，也是管理者最容易犯的自欺。

**免责声明：** 本章为教学材料，讨论管理的本质、职能与管理者的角色技能，不构成管理咨询意见、人事处理依据或绩效分配方案；涉及机构设置、岗位职责、人员配置与考核分配的具体事项，应依现行法律法规、行业规范与所在机构章程办理，并由具备相应权限的机构决定。
