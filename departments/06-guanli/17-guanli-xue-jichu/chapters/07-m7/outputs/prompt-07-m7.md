# 组织图上的每一根线，都要有人能被叫来问 · 提示词

## 用途

给「组织图上的每一根线，都要有人能被叫来问」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「幅度与层级：一条可算的硬约束 → 部门化：按什么切，就得到什么行为 → 职权：直线、参谋，以及授权的四个动作 → 协调机制：六种，按复杂度递进」这条链。

```

正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。
```

## 边界

本章为教学材料，讨论组织结构、职权配置与协调机制的分析框架，不构成管理咨询意见或机构设置方案；具体操作以现行规范与所在机构制度为准。
