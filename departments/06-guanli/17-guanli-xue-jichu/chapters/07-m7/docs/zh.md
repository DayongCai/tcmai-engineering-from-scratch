# 第 7 章 · 组织图上的每一根线，都要有人能被叫来问

> **MOTTO:** 「（人）力不若牛，走不若马，而牛马为用，何也？曰：人能群，彼不能群也。」——《荀子·王制》
>
> **PROBLEM:** 某院有 8 名院领导、31 个临床科室、14 个职能科室。一名副院长分管 11 个科室，一周开 6 个会，仍说不清其中 3 个科室的日常到底向谁汇报；一份采购文件要过 7 个签字，问到第 5 个签字人"你签的是什么"，回答是"前面都签了"。护理部每周向病区直接下达 3 条以上业务指令，而这些指令不经过科主任。**组织图画得很完整，但图上的线有三种不同的含义——指挥线、参谋线、协调线——画的时候没有区分，跑起来就全靠人记。** 组织的实际形态不是那张图，是"出事时第一个被叫去问的人是谁"。

**双根因定位:** 环境逼迫（医院同时受专业分工与行政科层两套逻辑约束，每一处权责都必须能追溯到岗位与文件；等级评审、绩效考核、医保监管都按"谁签字谁负责"追溯，线路不清就直接表现为追责困难） + 知识积累（组织的核心问题是分工之后如何协调，而协调靠机制不靠善意；机构往往只设计了分工（科室、岗位），没有设计协调（跨部门的规则、接口人、升级路径），于是协调只能靠开会与私人关系维持）

## 一、幅度与层级：一条可算的硬约束

管理幅度是一名管理者直接有效指挥的下属数量，层级是由幅度推导出的结果。二者是倒数关系：**给定总人数，幅度越大层级越少，幅度越小层级越多。**

人们常以为幅度可以随意放大，格兰丘纳斯在一九三三年给出了一个反对意见：管理者要处理的关系不止是"与每个下属的一对一关系"，还包括下属之间的交叉关系与组合关系。按下式计，直接关系 n 条、交叉关系 n(n−1) 条、组合关系 n(2^(n−1)−1) 条：

- n = 4 时，关系总数 = 4 + 12 + 28 = **44**
- n = 8 时，关系总数 = 8 + 56 + 1,016 = **1,080**

下属从 4 人增到 8 人，人数翻一倍，需处理的关系数增至约 24.5 倍。这就是"多加几个人"在管理上从来不是线性成本的原因。

幅度该多大，取决于四个条件：**工作的相似性**（同质工作幅度可大）、**下属的成熟度**（能力强、经验足可大）、**任务的不确定性**（例外多则幅度必须小）、**沟通技术的支撑**（有信息系统与标准流程可适度放大）。医院里门诊与病房的幅度差异就来自第一条与第三条：门诊流程高度同质，一名护士长可带二十余人；ICU 的例外密集，一名组长带六到八人已是上限。

层级带来两个必然代价：**信息衰减**与**决策延迟**。每过一层，信息被概括一次、语气被调整一次；每过一层，审批多一次往返。**层级不是问题，层级没有被设计成"只处理例外"才是问题**——如果每一层都在复核下一层的常规事务，层级就成了纯粹的延迟。

## 二、部门化：按什么切，就得到什么行为

分工的第一刀是"按什么划分部门"。常见五种切法，各产生不同的部门视角，也各产生不同的盲区。

**按职能**（医务、护理、药学、财务、后勤）：专业能力集中，规模经济明显；盲区是**没有人对完整流程负责**——一个患者从入院到出院经过六个部门，每个部门都只对自己那一段负责。

**按产品/服务**（内科、外科、妇科、儿科）：结果责任清楚，反应快；盲区是**职能重复**，每个科室都要有自己的辅助人员，规模不经济。

**按地区**（分院、院区）：贴近患者，响应快；盲区是标准不统一，同一家医院两个院区两种做法。

**按患者群**（老年、儿童、慢病、肿瘤）：需求导向，体验好；盲区是与既有科室交叉，一个患者同时属于三个群。

**按流程/时段**（门诊、急诊、住院、手术、日间）：流程效率高；盲区是接口处最容易掉病人，交接班与转科是差错高发点。

医院的实际形态是**混合部门化**：临床按产品（科室），支持按职能（医务、护理、药学），服务按流程（门诊、住院、手术）。混合本身没错，错在**没有人负责接口**。接口的责任必须显式指定——这就是为什么越来越多医院设"患者服务中心""入院准备中心""出院随访中心"：它们不新增业务，只填接口。

## 三、职权：直线、参谋，以及授权的四个动作

职权是组织里最容易被含糊处理的东西。三种线必须分开画。

**直线职权**：对下属有直接指挥权，能下命令、能考核。院长—科主任—主治医师这条线是直线。

**参谋职权**：提供专业建议与标准，不直接指挥。医务科、质控办、院感科对临床的多数行为属此类。参谋的困境是**有责无权**：发现问题只能通报，通报没有牙齿。

**职能职权**：参谋被授予在特定事项上的指挥权（如院感科对隔离措施的强制执行权）。这是对参谋困境的制度性解法，但必须**限定事项范围**，否则就退化成多头指挥。

职权之外还有权力。 French 与 Raven 在一九五九年区分了五种权力来源：**强制权**（能惩罚）、**奖赏权**（能给好处）、**法定权**（位置赋予）、**专家权**（懂）、**参照权**（被认同、被敬重）。医院里最有效的往往不是前三种而是后两种：一位老专家没有行政职务，但他说的话比文件管用，这是专家权与参照权在起作用。这也解释了为什么"空降"的管理者常常推不动——法定权到位了，专家权与参照权还没建立。

**授权**是职权配置的核心动作，它常被误解为"把活分出去"。授权有四个动作，缺一个就会变成"授责不授权"或"授权不授责"：

1. **明确任务与期望结果**：做什么、做到什么程度、什么时候要。
2. **授予相匹配的权限**：能调动哪些资源、能批多少钱、能定哪些事。权限与任务不匹配，任务必然完不成。
3. **约定汇报节点与例外升级路径**：什么情况自己定、什么情况必须报。这一步最常被省略，结果是下属不敢定、上级不知道。
4. **保留最终责任**：授权不授责，出了事仍是授权者的责任。这一条不是道德要求，是组织逻辑——如果责任可以随授权转移，就没有人需要对授权本身负责。

与此相对的是**集权与分权**的程度问题。判断该集权还是分权，有一组实用问题：这件事的频率高不高（高频宜分权，低频宜集权）、后果可逆不可逆（不可逆宜集权）、信息在哪一端（信息在一线宜分权）、是否涉及统一标准（涉及则集权定标准、分权执行）。医院的通行做法是"标准集权、执行分权"：诊疗规范、药事目录、绩效规则全院统一，具体排班、门诊单元、患者沟通由科室定。

## 四、协调机制：六种，按复杂度递进

分工产生协调需求。明茨伯格把协调机制分为六种，它们的可靠性与成本依次上升：

| 机制 | 靠什么 | 适用 | 代价 |
|---|---|---|---|
| 相互调整 | 面对面沟通 | 小团队、非例行 | 规模一大就失效 |
| 直接监督 | 一个人统一指挥 | 中小单元 | 受幅度限制 |
| 工作过程标准化 | 规定动作顺序 | 流程稳定 | 僵化，例外无处安放 |
| 产出标准化 | 规定结果指标 | 结果可测 | 指标替代 |
| 技能标准化 | 统一训练与资质 | 专业工作 | 培养周期长 |
| 规范标准化 | 共享价值观 | 高度自主的团队 | 建立慢，易空转 |

关键判据是：**机制要与任务的复杂度和不确定性匹配**。用工作过程标准化去做需要判断的事（比如规定辨证必须按某个模板），会把专业判断压成形式；用相互调整去管一个两百人的科室，会开不完的会。医院最缺的通常是中间三种——过程、产出、技能标准化都有基础，但**跨科室的接口没有标准化**，只能靠相互调整（开会）来协调，这就是会议多的结构性原因。

## 五、新形态：项目制、平台化、网络化、团队化

近二十年的组织创新，共同方向是**在科层之外增加横向的连接方式**，而不是取消科层。

**矩阵与项目制。** 胸痛中心、卒中中心、创伤中心、多学科诊疗团队、专病中心，本质都是矩阵。收益是打破科室壁垒，把患者路径拉直；代价是双重汇报。矩阵要跑得动，必须事先写清三件事：**项目负责人有没有考核权重、成员的工时怎么算、项目结束后人回哪里**。这三件不写，矩阵就只是一张写着"协作"的图。

**平台化。** 把共用的能力（检验、影像、病理、消毒供应、日间手术、随访）做成平台，业务单元按需调用。收益是规模经济与专业化；代价是平台成为瓶颈时全院一起等，因此平台必须公布服务时限与优先级规则。区域检验中心、影像中心、消毒供应中心都是这个逻辑。

**网络化。** 医联体、专科联盟、远程协作，用协议与信息系统替代产权扩张。收益是服务半径扩大而资本投入小；代价是控制力弱，质量一致性难保证。网络化能不能成立，取决于**转诊规则、责任划分与利益分配**三件事是否写清楚。

**团队化。** 自我管理团队、护理单元小组、质量改进小组。收益是响应快、归属感强；代价是团队边界与个人考核的冲突——团队奖励若无个人维度，会搭便车；只有个人维度，会拆掉协作。

这些形态有一个共同的成本常被低估：**每一层横向结构都在增加协调节点，而协调节点的数量增长快于业务量增长。** 中小机构把矩阵铺满，结果是会议翻倍、决策减半。判断该不该引入一种新形态，只需回答一个问题：**这个新结构解决了哪一个具体的接口问题，如果撤掉它，那个接口会坏在哪里。**

## 六、代价与边界

- **结构解决不了所有协调问题。** 任何结构都有协调成本，横向化程度越高成本越高；本章主张"把接口写清楚"，不主张"把结构复杂化"。
- **本章不给幅度、层级、人员配比的具体数值。** 4 人与 8 人的关系数（44 与 1,080）是按格兰丘纳斯公式的演算，用于说明非线性增长，不代表任何机构应采用的幅度；实际幅度须结合任务性质、人员能力与支撑系统确定。
- **五种权力来源不构成使用建议。** 强制权与奖赏权的使用受法律法规与职业道德约束，在医疗场景中尤其不得用于影响临床判断。
- **案例为合成说明。** 8 名院领导、31 个临床科室、7 个签字、每周 3 条护理指令，均为演示权责错位而构造，不含可定位的真实机构与人员。

**免责声明：** 本章为教学材料，讨论组织结构、职权配置与协调机制的分析框架，不构成管理咨询意见或机构设置方案；涉及科室设置、岗位职责、干部任免与权限划分的具体事项，应依现行法律法规、党内法规与所在机构章程办理，并由具备相应权限的机构决定。
