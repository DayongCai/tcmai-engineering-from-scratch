# 信息化不是把纸搬到屏幕上，是让决策在数据到达的地方发生 · 提示词

## 用途

给「信息化不是把纸搬到屏幕上，是让决策在数据到达的地方发生」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「数据、信息、知识：三层不是一个东西 → 系统谱系：用哪一层解决哪一层的问题 → 数字化三段：门槛不在技术，在权限 → 架构与治理：谁对数据负责」这条链。

## 边界

本章为教学材料，讨论管理信息系统的层次、数字化路径与数据治理，不构成技术方案、采购建议或合规意见；具体操作以现行规范与所在机构制度为准。
