# 变革死在半路，文化活在细节 · 提示词

## 用途

给「变革死在半路，文化活在细节」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「阻力不是觉悟问题 → 解冻、变革、再冻结：最难的是解冻 → 变革失败的三笔账 → 文化：三个层次，只有最下面那层是真的」这条链。

## 边界

本章为教学材料，讨论组织变革的动力、阻力与组织文化的分析框架，不构成管理咨询意见或改革实施方案；具体操作以现行规范与所在机构制度为准。
