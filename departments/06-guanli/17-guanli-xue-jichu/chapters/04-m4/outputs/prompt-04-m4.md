# 决策不是选最好的，是在信息不够时选一个能交代的 · 提示词

## 用途

给「决策不是选最好的，是在信息不够时选一个能交代的」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「完全理性是一个反事实前提 → 决策有程序，程序的第一步最容易错 → 群体决策：不是人多就对 → 三类偏差，决策者最该防的」这条链。

## 提示词

```
我在学《管理学基础》第 4 章「决策不是选最好的，是在信息不够时选一个能交代的」，本章 5 节 / 2,849 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 的（bounded rationality）。限制来自三处
   - ：备选方案列不全，后果预测不准，很多后果在决策时根本想不到
   - ：人一次只能处理少量变量，超过就靠经验捷径（启发式）简化，而捷径会系统性出错
   - 先定一条可接受的门槛，遇到第一个跨过门槛的方案就停下来
   - 第一步，发现问题
   - 现状与标准之间的差距，且这个差距有可追的责任主体
4. 本章自陈的边界（不得越过）：
   - **有限理性不是不作为的借口。** "信息不全所以没法决策"与"信息不全所以先定门槛、先设复查点、先做小规模试点"是两件事，前者是逃避，后者是方法。
   - **本章的金额与概率均为演算设定。** 1,200 万元、22 与 9.4 人次、500 元收费、8 年折旧、256 个工作日、0.3/0.5/0.2 的概率分布，都是为演示可复算关系而设定，不对应任何真实机构、真实设备或真实价格；实际测算须以现行价格政策、医保结算标准与本院财务数据为准。
   - **群体决策的制度要求高于技术讨论。** 重大事项决策、重要干部任免、重大项目安排、大额资金使用须走集体决策程序并留痕，这是制度约束，不因本章对群体决策缺陷的分析而改变；本章的修法（先写后议、指定反方、记录异议）是在制度框架内的质量改进，不是替代。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，讨论决策的有限理性、程序与常见偏差，不构成投资建议、采购建议或管理咨询意见；具体操作以现行规范与所在机构制度为准。
