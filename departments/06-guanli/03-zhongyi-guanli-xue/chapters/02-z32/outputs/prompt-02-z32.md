# 规划一家中医机构，真正要决定的是关掉哪些科室 · 提示词

## 用途

给「规划一家中医机构，真正要决定的是关掉哪些科室」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「定位三问，先于任何科室表 → 科室的四种角色，四种管法 → 从门诊量到调剂能力：一条必须算完的链 → 计划的三种失败模式」这条链。

## 边界

本章为教学材料，不构成医疗机构设置审批、医保定点或投资决策意见。科室设置、床位核定与执业登记须依《医疗机构管理条例》及属地卫生健康行政部门的规定办理；具体操作以现行规范与所在机构制度为准。
