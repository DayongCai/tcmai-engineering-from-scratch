# 实践报告的可信度来自能被重跑，不来自写得厚 · 提示词

## 用途

给「实践报告的可信度来自能被重跑，不来自写得厚」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「报告的第一性要求：别人按你写的能重跑一遍 → 数据文件：编码、缺失与版本 → 从软件输出到表格：五条转换规则 → 四类误读，必须在答辩前自查一遍」这条链。

## 提示词

```
我在学《管理实习与实践》第 6 章「实践报告的可信度来自能被重跑，不来自写得厚」，本章 6 节 / 2,854 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 读者会不会去验证
   - 从原始数据到最终结论的每一步都可查明
   - 原始数据、分析脚本、运行日志
   - 原始数据以观测为单位保存，汇总结果另行生成
   - 有规则的再组织
   - 结果不得手工修饰
4. 本章自陈的边界（不得越过）：
   - **可重复是有成本的，而且成本前置。** 整理脚本、写日志、留版本，会占掉整个项目 15%–25% 的时间，且全在开头。省掉它，代价出现在被质疑的那一刻，往往已经无法补救。
   - **智能工具改变不了责任归属。** 它可以辅助整理、提示异常、生成候选结果，但方法的取舍、变量的选择、结论的表述必须由研究者作出。一旦结果写进报告，责任在研究者与所在单位，不在工具。凡由工具生成的结果，采用前都要核验方法适用条件、参数设置与中间结果。
   - **可重复不等于可推广。** 一份能被重跑的报告，证明的是「过程无误」，不是「结论普遍成立」。把两者混为一谈，是另一种形式的过度解读。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章讨论实践报告的数据组织、结果呈现与答辩准备，属管理教学方法内容，不构成诊疗意见、不构成统计咨询意见，也不构成学术不端行为的认定标准。涉及真实数据的研究与报告，须依现行科研诚信规范、伦理审查要求与数据保护规定办理；具体操作以现行规范与所在机构制度为准。
