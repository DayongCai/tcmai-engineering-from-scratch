# 政策落地调研要查的不是「有没有发文」，而是钱、人、编哪一条断了 · 提示词

## 用途

给「政策落地调研要查的不是「有没有发文」，而是钱、人、编哪一条断了」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三层文本先分清：法律、行政法规与规范性文件 → 政策工具四类，落地的接口只有四个 → 调研设计：把「落地」翻译成可观测的量 → 执行偏差有名字：最后一公里与街头官僚」这条链。

## 提示词

```
我在学《管理实习与实践》第 4 章「政策落地调研要查的不是「有没有发文」，而是钱、人、编哪一条断了」，本章 6 节 / 3,399 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 强制型、激励型、信息型、能力建设型
   - 只发文件不动资源，等于只用信息型工具去完成一件需要四种工具的事
   - 钱从哪出、人从哪来、编在哪里、考核考什么
   - 把政策条款切到可执行的最小单位
   - 为每条找到承载体
   - 设定判据与证据等级
4. 本章自陈的边界（不得越过）：
   - **调研不是监督，不能替代监督检查。** 调研能描述状态、提出假设，不能认定违法、不能作出处理。把调研结论写成处理意见，是越权。
   - **因果识别很难，别把前后比较当效果。** 政策往往与其他变化同时发生，试点地区与对照地区在财力、资源禀赋与治理能力上本就有系统差异。双重差分、断点回归、倾向得分匹配可以缓解，但都依赖较强假设，结论要连同假设一起写。
   - **文号与条款必须逐条核对原文。** 政策文本修订频繁（例如传染病防治法已于 2025 年第二次修订），引用旧版本会得出已经失效的结论。凡是记不清的条款号，宁可不写编号，也不要估一个。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章讨论中医药政策落地调研的文本分层、工具识别与证据分级方法，属管理教学方法内容，不构成诊疗意见、不构成法律意见，也不构成对任何地区政策执行情况的评价。政策条款、文号与指标口径以现行有效文本为准；具体操作以现行规范与所在机构制度为准。
