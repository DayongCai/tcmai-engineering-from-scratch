# 信息科实习的成品是一份口径字典，不是一张好看的报表 · 提示词

## 用途

给「信息科实习的成品是一份口径字典，不是一张好看的报表」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「病案管「记录」，信息科管「从记录里取数」 → 指标必须能拆成分子、分母与来源 → 检索与知识组织：查得到不等于找得准 → 报表与驾驶舱：把结论放在第一屏」这条链。

4. 本章自陈的边界（不得越过）：
   - **口径统一是有成本的，而且成本落在最不方便的地方。** 建字典要拉着业务、统计、信息三方逐条对，一个指标可能要吵半小时。省下这个半小时，代价是此后每一次跨科室比较都要重吵一遍。
   - **字典只能管「已定义的指标」。** 大量管理问题是临时提出的，没有现成指标；这时正确的做法是先定义再取数，而不是拿一个近似的指标顶上去。用近似指标回答问题，比不回答更危险。

## 边界

本章讨论病案与信息科实习中的指标口径、检索方法与报表规范，属管理教学方法内容，不构成诊疗意见、不构成信息公开或数据合规的法律意见。实际取数、对外报送与数据共享，须依现行统计制度、个人信息保护规定与本院授权流程办理；具体操作以现行规范与所在机构制度为准。
