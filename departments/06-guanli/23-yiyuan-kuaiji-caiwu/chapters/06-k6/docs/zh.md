# 第 6 章 · 家底分两半：借来的与攒下的，混着看就会把负债能力当实力

> **MOTTO:** 「生之有时，而用之亡度，则物力必屈。」——《汉书·食货志》
>
> **PROBLEM:** 某院净资产 74,400 万元，看上去家底厚实。但把结构摊开：非流动资产 84,000 万元减去非流动负债 5,600 万元，还有 78,400 万元要靠净资产支撑，而净资产只有 74,400 万元——**差出的 4,000 万元，实际上是用流动负债（应付账款、预收医疗款）垫在设备与房子上的。** 这就是第 4 章流动比率 0.90 的账内解释：不是欠得多，是长期资产占用了短期资金。一家医院的"实力"，要看净资产里有多少能变成现金，而不是看净资产总额有多大。

**双根因定位:** 环境逼迫（医院不得分配结余、不得发行股票，扩张只能靠财政投入、自身积累与借款三条路；三条路的成本与约束完全不同）+ 知识积累（净资产是"资产减负债"的余数，不是"保险柜里的钱"；不理解这一点，就会把账面净资产当成可支配财力）

## 一、负债：先分有息与无息

医院的负债按流动性分为流动与非流动，但管理上更该按"有没有利息"分。

**无息负债**是运营自然形成的：应付账款（欠供应商）、应付职工薪酬（欠职工）、预收医疗款（住院预交金，欠患者服务）、应交税费。它们没有资金成本，但有刚性——欠供应商太久会断供，欠职工太久会出事，预收医疗款是必须履行的服务义务。

**有息负债**是主动融资形成的：短期借款、长期借款。它有明确的成本与到期日，是真正需要"还本付息"的部分。

这个划分的意义在于：**资产负债率把两类负债混在一起，会掩盖真实风险。** 一家医院负债率 38%，若其中九成是无息负债，风险很小；若一半是有息负债，压力就完全不同。所以分析时至少要再加一个"带息负债率"。

还有一层结构要看：**期限匹配。** 短期负债（一年内到期）应当由流动资产偿还，长期负债应当对应长期资产。医院常见的失衡是"短贷长投"——用一年期的借款去买十年寿命的设备，设备还没开始产生足够的现金流，借款已经到期，只能借新还旧。这类操作在报表上不违规，在资金链上很脆弱。判断方法就是第 4 章算过的那个配对：非流动资产是否小于"非流动负债 + 净资产"。小于，说明长期资产由长期资金支撑；大于，说明有短期资金被长期占用。

本章的算例（演算设定）沿用第 4 章的口径：负债 45,600 万元 = 流动 40,000 + 非流动 5,600。其中带息负债设为 12,000 万元（短期借款 8,000 + 长期借款 4,000），带息负债率 12,000 ÷ 120,000 = 10.0%。

## 二、四个负债科目的实务要点

**应付账款**：按发票与验收单入账，不以付款为准。月末要对"货到票未到"做暂估入账，否则成本与负债同时少计。暂估是负债核算里最容易被漏的一步，也是最容易在审计中被指出的。

**应付职工薪酬**：含工资、绩效、社会保险、住房公积金等。医院的人员经费占业务支出比重通常在 35%—40%，这个科目余额大是正常的，但要注意"计提了没发"与"发了没计提"两个方向的差错。

**预收医疗款**：住院预交金。它在会计上是负债，在管理上是"未来要提供的服务"。**预交金余额越大，说明在院患者越多或预交标准越高，而不是收入越高。** 把它当收入看，是外行最常犯的错。

**应交税费**：医院虽享受部分税收优惠，但代扣代缴的个人所得税、以及非医疗服务的增值税仍需处理。这一块边界由税务机关认定，财务人员不作税务判定（第 2 章的原则）。

## 三、净资产六个科目：谁能动，谁不能动

净资产是重点，因为它是"家底"的会计表达。政府会计制度下，医院净资产分六个科目：

| 科目 | 来源 | 可否用于日常支出 |
|---|---|---|
| 累计盈余 | 历年结余滚存、无偿调拨等 | 可以（但受资金形态约束） |
| 专用基金 | 按规定提取的职工福利基金、医疗风险基金 | 只能按指定用途 |
| 本期盈余 | 当年尚未结转的结余 | 年末结转 |
| 本期盈余分配 | 结余分配的过渡科目 | 年末结平 |
| 无偿调拨净资产 | 无偿调入/调出资产 | 不可分配 |
| 权益法调整 | 长期股权投资权益法核算 | 不可分配 |

关键在"专用基金"与"无偿调拨净资产"两项。**专用基金是"锁定的净资产"**：账上有钱，但只能用于职工福利或医疗风险赔付。**无偿调拨净资产是"没花钱得到的东西"**：家底增加了，但既不能分配也不能变现（多数是房屋、设备）。

两项提取的算例（演算设定）：

- 职工福利基金：按结余 1,800 万元提取 40%，即 720 万元。分录为借 本期盈余分配／贷 专用基金，**净资产总额不变，可动用部分减少 720 万元**。
- 医疗风险基金：按医疗收入 83,000 万元的 2‰ 提取，即 166 万元。同样只改变结构，不改变总额。

第 5 章讲过折旧年限的操纵，这里是另一个同类问题：**提取比例是政策参数，不是管理工具。** 用它调节结余，会让"可动用财力"这个指标彻底失效。

## 四、净资产不等于可动用资金：一个结构性算例

这是本章最重要的一张表（演算设定，与第 4 章勾稽一致）：

| 项目 | 金额（万元） |
|---|---:|
| 资产总额 | 120,000 |
| 其中：流动资产 | 36,000 |
| 　　　非流动资产 | 84,000 |
| 负债总额 | 45,600 |
| 其中：流动负债 | 40,000 |
| 　　　非流动负债 | 5,600 |
| 净资产 | 74,400 |

现在做一次"资金配对"：非流动资产 84,000 万元，应由长期资金（非流动负债 + 净资产）支撑。长期资金合计 5,600 + 74,400 = 80,000 万元，比 84,000 万元少 4,000 万元。**这 4,000 万元，就是流动负债被挪去买了设备的部分。**

反过来看流动资产：36,000 万元的流动资产，对应 40,000 万元的流动负债，缺口同样是 4,000 万元。两个缺口相等，不是巧合——它是同一个失衡的两种说法。

这个失衡的直接后果是：**医院必须持续用新收到的钱去填旧账。** 只要业务量不下降、结算不断流，它就能一直转；一旦医保结算延迟一个月，或者业务量骤降，链条立刻绷紧。这不是"负债率过高"能描述的风险，是"期限错配"的风险。

管理上的应对只有三条：**其一，控制资本性支出的节奏**，不让设备采购超过长期资金的能力；**其二，缩短应收周期**，把压在医保结算上的钱要回来；**其三，保留现金缓冲**，把可动用资金维持在流动负债的一定比例以上。三条都不是财务部门单独能做的，第一条要院长办公会决定，第二条要医保办配合。

还有一个容易被忽略的推论：**净资产增加不等于可动用资金增加。** 一台无偿调入的设备会让净资产增加几百万元，但现金一分没多。所以看一家医院的财力，应当看"货币资金 + 可快速变现的应收"与"流动负债 + 已承诺的资本性支出"之比，而不是看净资产。前者是支付能力，后者只是账面余数。

## 五、债务风险的三条线

判断医院债务是否安全，用三个指标交叉看（演算设定）：

| 指标 | 算式 | 数值 | 判断 |
|---|---|---:|---|
| 资产负债率 | 45,600 ÷ 120,000 | 38.0% | 中等 |
| 带息负债率 | 12,000 ÷ 120,000 | 10.0% | 低 |
| 偿债备付率 | (盈余 1,800 + 折旧 6,100) ÷ 年还本付息 3,200 | 2.47 | 尚可 |

三条线的读法不同。**资产负债率看长期结构**，超过 50% 就要警惕，但医院之间可比性差（财政投入多的医院天然低）。**带息负债率看真实融资压力**，这一项才和利息支出直接相关。**偿债备付率看现金流覆盖能力**，分母是当年要还的本息，分子是"盈余 + 折旧"这种准现金。2.47 意味着现金流是还本付息的 2.47 倍，尚有余地；低于 1.2 就要靠借新还旧。

还有一个常被忽略的约束：**医院借债要履行审批程序，且不得用于经常性支出。** 借来的钱买设备、盖楼可以，发工资不行。这条规定的经济含义是：债务必须形成能产生收入流的资产，否则就是用未来的收入补今天的窟窿。

## 六、代价与边界

- **净资产为正是底线，不是目标。** 一家净资产持续为正但现金流断裂的医院并不少见；反过来，净资产为负但在财政支持下正常运行的医院也存在（多见于承担大量公共卫生任务的机构）。单看净资产，两个方向都会误判。
- **专用基金提多了会削弱当期可用财力。** 提取比例在政策区间内由单位确定，取上限意味着更稳健也更紧；这是一个真实的取舍，没有标准答案。
- **本章的负债结构为演算设定。** 45,600、40,000、5,600、12,000、74,400 等数为便于复算而设，与第 4 章保持勾稽；不对应任何真实机构的报表。实际债务分析须以审计报告、借款合同与还本付息计划为准。
- **不提供融资建议。** 本章只讲债务的结构与风险判据，不评价任何具体融资方式、不推荐借款方案、不涉及利率判断；实际筹资决策须依主管部门规定与法定审批程序。

**免责声明：** 本章讨论医院负债与净资产的核算与管理，属会计学与财务管理教学内容，不构成融资建议、信用评价或对任何机构偿债能力的认定；实际核算与管理须依现行政府会计制度、医院财务制度及主管部门规定执行。
