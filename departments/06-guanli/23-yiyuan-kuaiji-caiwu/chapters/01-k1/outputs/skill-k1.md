# 医院没有利润，只有结余：把医院当企业算，第一页就错了

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 第一，评价指标不能用利润率
- 第二，亏损必须分成两类
- 第三，规模不是目标
- 筹集 → 使用 → 耗费 → 回收 → 分配
- 凡是两个体系不一致的地方，都是理解医院财务的入口
- 财务会计回答：家底有多厚、这一年是盈是亏

## 边界

- **结余为负不等于经营失败，结余为正也不等于办得好。** 前者可能来自政策性定价，后者可能来自压缩了必要的投入（设备不修、培训不办、人手不足）。单看结余这一个数，两个方向都会误判。
- **双体系增加核算成本，这是已知代价。** 平行记账要求每一笔涉及资金收付的业务同时判断两套要素，对人员能力与信息系统都有要求。制度选择它，是因为"家底"与"预算执行"这两个问题都无法用一套账同时答好；代价是效率，收益是信息完整。
- **本章四个口径的拆法只适用于教学演示。** 真实的现金流调节还要处理应付账款变动、存货变动、财政项目拨款、借款收支等项，实际编制须依现行政府会计制度与本单位核算办法逐项勾稽，不能直接套用本章的四行表。
- 本章讨论医院会计与财务管理的分析框架，属管理学与会计学教学内容，不构成对任何机构的财务评价、审计意见或政策建议。
