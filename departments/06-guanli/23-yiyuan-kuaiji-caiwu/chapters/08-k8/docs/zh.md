# 第 8 章 · 成本核算的本质是分摊：每一次分摊都是一次归因假设

> **MOTTO:** 「以九式均节财用。」——《周礼·天官·大宰》
>
> **PROBLEM:** 某院行政后勤成本 2,400 万元要摊到临床科室。按人员比例摊，内科分得间接成本 2,098 万元；按收入比例摊，内科分得 1,786 万元。**同一批数据，两种分摊，内科的总成本差 312 万元，相差 8.7%。** 这 312 万元足以让一个科室从"结余"变成"亏损"，也足以让院长在会上做出完全相反的判断。所以成本核算的第一个问题不是"怎么算得更准"，而是"用了什么假设，这个假设站不站得住"。

**双根因定位:** 环境逼迫（医疗服务价格由目录决定、支付标准由医保决定，医院唯一能自主改变的是成本；而成本要管，必须先能算到科室、项目、病种三个层级）+ 知识积累（间接成本没有唯一正确的分摊方法，只有"与成本动因相关性更强"的方法；不写明动因，成本数字就只是分摊者的一次投票）

## 一、三个核算对象，三个用途

医院成本核算有三个层级，各有各的用途，不能互相替代。

**科室成本**：回答"哪个科室消耗了多少资源"。用途是科室运营分析与内部资源配置。它是基础层，项目成本与病种成本都要从它出发。

**项目成本**：回答"做一次某个医疗服务项目要花多少"。用途是价格测算、项目盈亏分析与新增项目定价。它的难点是把科室成本拆到单个项目。

**病种成本**：回答"治一个某病种要花多少"。用途是支付方式下的盈亏分析（DRG/DIP）、临床路径优化。它的难点是病例的归并与路径的标准化。

三者的关系是包含：科室成本 ⊃ 项目成本（按项目工作量分） ⊃ 病种成本（按病种的路径组合）。层级越往下，假设越多，误差越大。**所以对外报告用科室层，对内决策才用到病种层，且必须标注假设。**

## 二、科室成本：三级分摊的完整算例

医院科室分四类：临床服务类、医疗技术类、医疗辅助类、行政后勤类。分摊按"行政后勤 → 医疗辅助 → 医疗技术 → 临床服务"的顺序逐级往下，叫三级分摊。

设某院某月四类科室成本如下（演算设定）：

| 科室类别 | 直接成本（万元） | 分摊基数 |
|---|---:|---|
| 行政后勤 | 2,400 | 按向各类科室提供服务的人员数 |
| 医疗辅助 | 1,800 | 按服务量 |
| 医疗技术 | 3,600 | 按工作量 |
| 临床服务 | 9,000 | 最终承担全部间接成本 |

**一级分摊**：行政后勤 2,400 万元按人员数比例 2:3:5 分给医辅、医技、临床，得 480、720、1,200。

**二级分摊**：医疗辅助成本变为 1,800 + 480 = 2,280 万元，按服务量比例 3:7 分给医技、临床，得 684、1,596。

**三级分摊**：医疗技术成本变为 3,600 + 720 + 684 = 5,004 万元，全部转入临床。

**临床服务总成本** = 9,000 + 1,200 + 1,596 + 5,004 = **16,800 万元**。

复算链条：2,400 = 480 + 720 + 1,200；2,280 = 1,800 + 480；2,280 = 684 + 1,596；5,004 = 3,600 + 720 + 684；16,800 = 9,000 + 1,200 + 1,596 + 5,004。五式全部闭合，说明分摊没有遗漏也没有重复。

这套方法的三个技术要点：

**其一，顺序不能乱。** 必须从行政后勤开始，因为它不接收其他科室的分摊。若先分医技，医技的成本里就缺了行政后勤那一份，后面全部失真。

**其二，基数要与动因相关。** 行政后勤按人员数（因为它的服务对象是人），医辅按服务量（因为它的产出是被服务的次数），医技按工作量（因为它的产出是检查检验的项次）。用收入做基数最省事，但收入受价格影响，价格高的科室会被多摊——这是把价格差异错当成资源消耗差异。

**其三，分摊是单向的。** 不允许"临床再分回医技"这种回摊，否则会形成循环，算不出来。

## 三、分摊基数的敏感性：312 万元从哪来

同一个临床科室，换个基数就换个结果（演算设定）：

| 分摊基数 | 内科占比 | 分得间接成本（万元） | 内科总成本（万元） |
|---|---:|---:|---:|
| 按人员数 | 26.9% | 2,098 | 3,898 |
| 按收入 | 22.9% | 1,786 | 3,586 |
| 差额 | 4.0 个百分点 | **312** | 312（8.7%） |

复算：7,800 × 26.9% = 2,098.2；7,800 × 22.9% = 1,786.2；差 312.0；312 ÷ 3,586 = 8.7%。

这张表要传达的判断是：**分摊基数不是技术细节，是结论本身。** 内科人员多、收入相对低（内科以药物治疗为主，项目单价低于外科手术），按人员摊会吃亏，按收入摊会占便宜。选哪个，取决于你要回答什么问题：

- 要评价"科室占用了多少人力资源"→ 按人员。
- 要评价"科室对间接服务的消耗"→ 按服务量或工作量。
- 要评价"科室的创收效率"→ 根本不该用分摊后的全成本，应该用直接成本加可控成本。

**所以规范的做法是：分摊方法一经确定，年度内不得变更；确需变更，须留档说明理由与影响。** 否则每年的科室排名都在变，而变的不是业绩，是算法。

## 四、项目成本：三种方法，一个共同难题

项目成本要解决的问题是：一个科室的成本，怎么分到它做的几十上百个收费项目上。

**成本当量法**：以某个代表项目为 1 个成本当量，其他项目按其资源消耗折算当量数，再按当量总数分摊。优点是简单，缺点是需要预先测定当量系数，系数一错全错。

**作业成本法**：把科室作业分解为若干作业（如接诊、检查、出报告），按作业动因分配。优点是准确，缺点是需要采集作业数据，工作量大。医院通常在检验、影像等标准化程度高的科室使用。

**比例系数法**：按收入比例或工作量比例直接分摊。最省事，也最不可靠——它把价格差异带进了成本。

一个必须说清的共同难题：**项目成本里的"项目"是收费项目，不是临床操作。** 一次静脉输液可能对应三个收费项目（穿刺、输液、材料），也可能对应一个打包项目。项目口径不同，算出来的单位成本不可比。所以做项目成本之前，先对齐收费目录版本。

## 五、病种成本：历史成本与临床路径

病种成本有两条路。

**历史成本法**：回溯既往病历，把每个病例的实际消耗归集起来，求平均。优点是反映真实，缺点是受历史行为影响——如果过去的诊疗本身不合理，算出来的"标准成本"就是不合理的标准。

**临床路径法**：按标准诊疗路径，把路径上的项目按项目成本累加。优点是反映应然，缺点是路径之外的变异（并发症、合并症）没有位置，而变异恰恰是成本超支的主要来源。

实务中的做法是两者结合：以路径法确定基准，以历史成本法校正变异。**只报一个数而不说方法，等于没报。**

病种成本最重要的用途不是"算清楚花了多少"，是**与支付标准对照**（第 9 章）：支付 12,800 元、成本 13,500 元，亏 700 元；这 700 元是路径问题、耗材问题还是病例结构问题，才是管理的起点。

## 六、数据从哪来：三个源头的对账

成本核算的精度，最终取决于数据能不能对上。医院的成本数据来自三个系统，各管一段：

| 来源 | 内容 | 关键字段 |
|---|---|---|
| 财务系统 | 总账费用、明细科目、辅助核算 | 科目、部门、项目 |
| 业务系统（HIS） | 收入、工作量、收费项目、人次床日 | 科室、项目、执行时间 |
| 物资与人事系统 | 领用、库存、工时、排班 | 科室、品种、人员 |

三源之间必然有差。最常见的是**科室口径差**：财务的科室按核算单元设，HIS 的科室按开单与执行分设，人事按编制科室设。同一个"心内科"，三个系统里可能是三个不同的编码集合。不先建一张科室对照表，分摊就无从谈起——这是成本核算项目里工作量最大、也最不显眼的一步。

第二常见的是**项目口径差**：收费项目有版本，价格调整后旧版本仍在使用，历史数据混着两个版本的成本与收入。做项目成本时必须锁定同一版本，否则单位成本会莫名其妙地上下跳。

第三是**时间口径差**：财务按月结账，HIS 按自然日，物资按领用单日期。月末最后两天的领用常常落在两个期间。规范做法是设定统一的月结时点，并对跨期单据做明确的归属规则。

三源对上之后，还要做一次反向校验：**科室成本合计应当等于总账的相关费用合计。** 若不等，差额通常来自未分配的共同费用（如全院性的水电、房屋折旧）或未纳入核算的科室。这个校验每月做一次，比年底查一次有用得多。

## 七、代价与边界

- **分摊必然带有任意性，这是方法的内在代价。** 任何分摊都是把共同成本强行切开，切法可以选择，切开的事实不可消除。所以成本报表的第一行应该写清分摊方法与基数，而不是把结果当客观事实发布。
- **成本数据不能直接用于绩效分配。** 全成本含折旧与分摊的行政后勤费用，科室无法控制这部分。用全成本考核科室，等于让科室为院长的投资决策负责。绩效应当用可控成本与工作量。
- **病种成本对编码质量高度依赖。** 病案首页的主要诊断与手术操作填错，病种归组就错，成本跟着错。这是成本核算与病案管理的接口，也是很多医院算不准病种成本的真正原因。
- **本章全部数字为演算设定。** 2,400、1,800、3,600、9,000、16,800、2,098、1,786、312 等数为便于复算而设，比例 2:3:5、3:7、26.9%、22.9% 亦为设定值；不对应任何真实机构的成本报表。实际核算须依《医院成本核算规范》与本单位核算办法执行。
