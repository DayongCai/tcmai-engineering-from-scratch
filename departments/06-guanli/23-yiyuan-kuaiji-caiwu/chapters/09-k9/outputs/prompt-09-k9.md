# 多做不一定多赚：支付标准固定之后，成本—量—本全反过来了 · 提示词

## 用途

给「多做不一定多赚：支付标准固定之后，成本—量—本全反过来了」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三种分类，三种用途 → 成本—量—本：三个算式足够 → 把 12,800 与 13,500 拆开看 → 扭亏的两条路：算一遍就知道该走哪条」这条链。

## 提示词

```
我在学《医院会计与财务管理》第 9 章「多做不一定多赚：支付标准固定之后，成本—量—本全反过来了」，本章 7 节 / 2,757 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 按性态分：固定成本与变动成本
   - 按可控性分：可控成本与不可控成本
   - 按归属分：直接成本与间接成本
   - 固定不等于不可控
   - 变动不等于可控
   - 单位边际贡献 = 单位收入 − 单位变动成本
4. 本章自陈的边界（不得越过）：
   - **固定成本与变动成本的划分依赖时间尺度。** 一年内视为固定的成本（人员、房屋），三年内可能变成可变的（合同到期、人员流动）。所以保本点每年要重算，不能拿旧数用三年。
   - **量本利分析假设支付标准单一、病种同质。** 实际病例的病情轻重不同（同一 DRG 组内也有差异），用平均值做决策会低估重症病例的亏损。规范做法是按组内分层看，而不是只看组均值。
   - **"多做少亏"不构成扩产理由。** 它只在产能有余、且不挤占其他更高边际贡献业务时成立。把这条结论直接用于鼓励冲量，是把短期决策当长期战略，方向错了。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章讨论医院成本分析与成本管控的方法，属管理会计教学内容，不构成价格谈判依据、绩效方案或临床决策建议；具体操作以现行规范与所在机构制度为准。
