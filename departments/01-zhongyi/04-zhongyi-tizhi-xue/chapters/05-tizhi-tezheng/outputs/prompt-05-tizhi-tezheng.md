# 五步转数

## 用途

问卷到向量最容易错在第一步与第四步：**条目跨域、跨域相加**。

## 步骤

### 1. 条目

一题一域，检查是否跨域

### 2. 编码

统一 1–5 级

### 3. 缺失

缺失记为未测，不填最低分

### 4. 聚合

域内标准化后再合成，按关键域加权

## 判据速查：五步的检查点

| 步 | 自查一句 |
|---|---|
| 条目 | 这一题是否同时问了两个域？ |
| 编码 | 全部题是否都是 1–5 级？ |
| 缺失 | 缺失是否被误填成最低分？ |
| 聚合 | 是否先域内标准化再加总？ |
| 合成 | 是否输出了主质与兼夹两栏？ |

五问自查看似琐碎，却是「可重复」的唯一入口——任一步错，后面的统计都不可信。

## 输出

① 四域分数；② 关键域；③ 主质与兼夹；④ 已知偏倚（偏向功能域）。

## 边界

- 数字一律由 `code/main.js` 读 `standards/tizhi/units.json` 与 `体质库.json` 现算，不手写；
- 不给方药剂量、不给量表条目；
