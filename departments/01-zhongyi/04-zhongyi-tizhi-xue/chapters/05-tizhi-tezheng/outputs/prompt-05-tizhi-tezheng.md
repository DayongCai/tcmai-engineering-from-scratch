# 量表算出来的不是一分数，是四组分数 · 提示词

## 用途

给「量表算出来的不是一分数，是四组分数」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「五步转数：从一张答卷到一组向量 → 四域各自的编码：同一现象，四种形状 → 缺失与未测：三种处理，三种后果 → 合成与加权：关键域优先，兼夹保留【教学设定】」这条链。

## 提示词

```

正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
```
