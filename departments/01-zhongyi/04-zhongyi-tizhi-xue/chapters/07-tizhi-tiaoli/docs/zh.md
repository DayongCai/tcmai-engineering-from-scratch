# 第 7 章 · 体质调理与治未病：以平为期

> **MOTTO:** 「形不足者，温之以气；精不足者，补之以味」——教材·第7章·7.1（《素问·阴阳应象大论》）

> **PROBLEM:** 体质调理最容易变成「养生建议清单」：这个质吃这个、那个质练那个。教材的落点不同：**调养的目标是「平」，方法是「以偏纠偏」，而纠偏的力度由偏颇程度决定**。

## 一、九质的调养主线

| 质 | 调养主线 | 忌 |
|---|---|---|
| 平和 | 维持：饮食有节、起居有常 | 过度进补 |
| 气虚 | 益气健脾 | 耗气、过劳 |
| 阳虚 | 温阳散寒 | 生冷、久处寒湿 |
| 阴虚 | 滋阴润燥 | 辛燥、熬夜 |
| 痰湿 | 健脾化湿 | 肥甘、久坐 |
| 湿热 | 清热利湿 | 辛辣、酒醴 |
| 血瘀 | 活血化瘀 | 久坐、受寒 |
| 气郁 | 疏肝解郁 | 情志抑郁、久思 |
| 特禀 | 益气固表、避过敏原 | 接触致敏物 |

**「忌」一列比「宜」一列更重要**：体质调理的收益多半来自「去掉持续刺激」，而不是「加上补品」。

## 二、三条共同原则

1. **以平为期**：目标是回到平和，不是把某一项推到极致；
2. **缓图为法**：体质改变以年计，短期猛补猛泻都不可取；
3. **三辨合一**：辨体、辨病、辨证同时进行——只辨体会漏掉当下的急症，只辨证会忽略长期倾向。

## 三、治未病的三个落点

| 落点 | 内容 |
|---|---|
| 未病先防 | 按体质倾向调整生活方式 |
| 既病防变 | 体质决定传变方向，提前拦截 |
| 瘥后防复 | 病后按体质调养，减少复发 |

## 四、本章的方法学限制

调养效果的评价需要长期随访，本课程没有这类数据。因此本章**只给原则与主线，不给疗效承诺**——这也是本课程与「养生科普」的分界。

## 代价与边界

1. 本章不给方药与剂量；
2. 调养建议须个体化，不可按质照抄；
3. **免责声明：** 教学整理，不构成诊疗建议；有明确疾病者须先治病。

## 五、九质调养的三条通用动作

| 动作 | 内容 | 为什么通用 |
|---|---|---|
| 饮食有节 | 定时、定量、少生冷肥甘 | 直接作用于脾胃，是九质共同上游 |
| 起居有常 | 规律作息、防过劳 | 睡眠与劳逸影响所有质 |
| 情志舒畅 | 减少久思久郁 | 气郁是多个质的加重因素 |

三条都不针对某一质，却对每一质都有效——**这是「以平为期」的具体含义：先把共同上游修好，再谈纠偏。**

## 六、调养与治疗的分工

| 情形 | 谁主导 |
|---|---|
| 有明显疾病 | 治疗为主，调养为辅 |
| 无明确疾病但有偏颇 | 调养为主 |
| 病后恢复期 | 调养为主，防复发 |

三行的分界是「有没有病」，不是「偏颇重不重」。**把调养当治疗、把治疗当调养，是两个方向的错误。**

## 七、为什么本章不给数字

体质的改变以年计，评价需要长期随访；本课程没有随访数据，因此不给「调理几周见效」这类数字。**不给数字，是不想给假精度。**
