# 纠偏力度

## 用途

调养的目标是「平」，不是把某一项推到极致。**「忌」比「宜」更重要。**

## 步骤

### 1. 定主质

主质与偏颇程度（轻／中／重）

### 2. 选主线

按九质表选调养主线

### 3. 列忌项

去掉持续刺激（收益多来自这一列）

### 4. 三辨合一

辨体＋辨病＋辨证，缺一不可

## 判据速查：三条通用动作与九质主线的接法

| 层 | 内容 |
|---|---|
| 通用层 | 饮食有节、起居有常、情志舒畅（对九质都有效） |
| 主线层 | 按主质选一条调养主线（益气／温阳／滋阴／化湿／清热／活血／解郁／固表／维持） |
| 忌项层 | 去掉持续刺激（生冷、肥甘、辛辣、久坐、久思、致敏物） |
| 复评层 | 一年一次复判，用变化量而非绝对值 |

四层从通用到个体，**先修共同上游，再谈纠偏**——这是「以平为期」的执行顺序。

## 输出

① 主质与程度；② 调养主线；③ 忌项；④ 三辨合一方案与复评时点。
