# 三条关系定位

## 用途

三条关系的证据强度不同：同证异质强、同质异证中、传变弱。**先定位，再标证据等级。**

## 步骤

### 1. 判关系

当前是「一证多质」「一质多证」还是「质定传变」

### 2. 找证据

跨课证候？一质多证？还是有纵向数据

### 3. 标等级

强／中／弱

### 4. 定侧重

同证异质者重在调整治法权重；传变问题重在拦截

## 输出

① 关系类型；② 证据等级；③ 处理侧重。

## 边界

- 数字一律由 `code/main.js` 读 `standards/tizhi/units.json` 与 `体质库.json` 现算，不手写；
- 不给方药剂量、不给量表条目；
