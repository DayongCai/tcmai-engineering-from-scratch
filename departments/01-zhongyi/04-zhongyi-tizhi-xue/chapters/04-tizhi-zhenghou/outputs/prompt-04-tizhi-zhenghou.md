# 同一个证可以长在不同底子上，处理要分两步走 · 提示词

## 用途

给「同一个证可以长在不同底子上，处理要分两步走」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「两种混淆各有方向，纠正方法也不同 → 同证异质：一个证名，三种底子 → 同质异证：一种底子，三个病程 → 两步时序与调护边界：先治证，后调质【教学设定】」这条链。

## 提示词

```
我在学《中医体质学》第 4 章「同一个证可以长在不同底子上，处理要分两步走」，本章 5 节 / 3,065 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 参考件状态
   - 判据一句话：证是「现在发生了什么」，质是「为什么这个人容易这样发生」
   - 证名给出「做什么」，底子给出「和什么一起做、不能做什么」
   - 每一段的处理目标不同
   - 「不成立」的四条
   - 证未立而先调质
4. 本章自陈的边界（不得越过）：
   - **两步时序是简化模型。** 真实病程中治证与调质常常重叠，尤其慢性病；本章要求分阶段，是为了让动作有主次，不是要求机械等待。
   - **对照表只覆盖常见组合。** 九质与百余证候的组合远多于表中所列，表中给的是判据形式（证名定动作、底子定约束），不是穷举清单。
   - **跨科数据只能提示，不能定论。** 10 个证候跨两科，说明这些证名在两科都被使用，不说明两科的病人相同。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学整理，不构成诊疗建议；具体操作以现行规范与所在机构制度为准。
