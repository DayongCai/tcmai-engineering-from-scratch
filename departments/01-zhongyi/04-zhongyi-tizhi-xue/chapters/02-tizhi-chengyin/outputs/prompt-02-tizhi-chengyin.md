# 底板＋漂移

## 用途

先天定底板（易感方向），后天定漂移（当前偏颇）。**调养的空间全在漂移这一段。**

## 步骤

### 1. 定底板

父母禀赋、胎孕、禀赋不耐

### 2. 列变量

年龄、性别、地域、饮食情志

### 3. 判漂移

哪个变量在推动当前偏颇

### 4. 定可调

哪些可改、哪些只能顺应

## 判据速查：底板与漂移的四问

| 问 | 落到 |
|---|---|
| 父母体质如何、孕期有无异常 | 底板 |
| 近十年体重、饮食、作息如何变 | 漂移 |
| 现在最突出的是形态、功能还是心理 | 当前偏颇所在域 |
| 哪一项是自己能改的 | 调养的抓手 |

四问走完，底板与漂移就分开了，调养也有了具体抓手。

## 输出

① 底板；② 漂移变量与方向；③ 当前体质；④ 可调项与不可调项。

## 边界

- 数字一律由 `code/main.js` 读 `standards/tizhi/units.json` 与 `体质库.json` 现算，不手写；
- 不给方药剂量、不给量表条目；
