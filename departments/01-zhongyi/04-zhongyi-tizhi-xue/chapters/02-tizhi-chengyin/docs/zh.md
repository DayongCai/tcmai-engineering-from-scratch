# 第 2 章 · 底板改不了，漂移的方向可以选

> **MOTTO:** 「人之始生，以母为基，以父为楯」——《灵枢·天年》
>
> **PROBLEM:** 老年常见的气虚、阳虚、阴虚、痰湿、血瘀五质，在本库合计 17+7+18+9+16 = 67 个证候，占 132 证的 51%。数字看着像「人老了必然偏颇」，但证候库里没有年龄字段——这 67 个证候不是从老年人身上采来的，而是从三个科的教材里数出来的。于是问题变成：既然「年龄导致漂移」这一层在本库无法分层验证，那关于形成的论述，哪些能写、哪些只能写方向？

**双根因定位:** 环境逼迫（同一个人在不同年龄、不同季节、不同作息下会被判成不同体质，若不区分「底板」与「漂移」，每次辨识都会推翻上一次）+ 知识积累（先天禀赋这一层在病证文本里几乎不留痕，本库记录的是已病状态，因此形成论只能靠条理组织，不能靠数据支撑）。

**参考件状态:** 本课程无足本参考件，不引页码版次。底本 13 个单元中涉及形成论的仅 2 个单元，且其中关于后天因素的表述来自老年病学的通行归纳，属参照层而非本课程自有证据。本章数字取自 `standards/zhenghou/证候库.json` 与 `standards/tizhi/体质库.json`，可按类目复算。

## 一、底板：三条几乎不可改的记录

底板指一个人出生时带下来的部分。它不可改，但可以记录，而记录的意义在于——当一个人的辨识结果与同龄同环境者明显不同时，底板是第一个要查的解释项。

| 底板项 | 问什么 | 记录形式 | 解释力 |
|---|---|---|---|
| 父母体质与病史 | 父母是否长期畏寒、易过敏、体胖、情绪易郁；父母有无慢性病 | 定性描述 + 是否双方同向 | 双方同向时解释力最强，单方同向只能算线索 |
| 胎产情况 | 足月与否、出生体重、喂养方式、幼年是否反复感染 | 类别词，不追细节 | 与特禀质、气虚质的判定相关 |
| 幼年病史 | 幼年是否反复感冒、是否有哮喘与湿疹、是否有长期食欲不振 | 计次 + 年龄区间 | 与特禀质、气虚质、痰湿质相关 |

采集底板有三条纪律。**第一，只问能记住的，不追问精确数值。** 父母的具体体重、幼年的具体用药，回忆误差极大，追问只会得到编造的答案；改成「偏胖／中等／偏瘦」这类分档，可靠性反而更高。**第二，底板项不得单独成为判定依据。** 父母双方都畏寒，本人却无任何寒象，此时底板只能作为「需要留意」的记录，不能直接判阳虚质。**第三，底板记录一次即可，不必每次复评重问。** 复评要问的是漂移项，重复追问底板会让被辨识者觉得「上次说的白说了」。

底板的临床价值不在于预测，而在于**解释差异**。两个同龄、同地域、同职业的人，一个判气虚、一个判平和，若前者底板项有明显线索（幼年反复感染、出生体重偏低），这个差异就有了可交代的来源；若两者底板项完全相同而结果不同，则要怀疑施测过程而非体质本身。

## 二、漂移的五个推手

漂移指底板之上、随时间与环境改变的部分。它决定了同一个人的体质为什么会变，也决定了调理动作应该作用在哪一层。

| 推手 | 漂移方向 | 可观察信号 | 可改程度 |
|---|---|---|---|
| 年龄 | 向气虚、阳虚、阴虚、痰湿、血瘀集中，且常两三相兼 | 体力恢复变慢、畏寒加重、口干与便干并存、体重与腹围上升 | 不可改，只能顺应对策 |
| 饮食 | 肥甘厚味助痰湿与湿热；生冷助阳虚与痰湿；长期偏嗜助单一偏向 | 舌苔厚腻、口黏、口苦、大便黏滞、食欲波动 | 高度可改，改变后数周内可见信号变化 |
| 情志 | 长期压抑助气郁；气郁日久化火可转湿热 | 善太息、胸胁胀满、入睡困难、情绪与症状同步波动 | 可改，但需要时间与外部支持 |
| 地域与气候 | 东南湿热多，西北燥寒多；久居空调环境可现「假寒」 | 症状随季节与迁徙变化；换环境后减轻 | 部分可改（居住与工作环境） |
| 劳逸与睡眠 | 过劳助气虚，久坐助血瘀与痰湿，长期熬夜助阴虚与湿热 | 休息后能否恢复、久坐后下肢沉重、熬夜后口干 | 高度可改 |

这五项里，**只有「年龄」是单向不可逆的**，其余四项都可以在数周至数月内看到信号变化。这带来一条实用的排序原则：辨识出一个偏颇之后，先看它能不能被可改项解释；能被解释的，先改可改项再复评；只有当可改项都已调整而偏颇仍在，才把它当作稳定倾向来调养。这个顺序可以避免把「最近三个月加班太多」误判成终身气虚。

关于地域还有一点要提醒：**迁徙会制造假象。** 北方人迁到南方，初期多见湿热信号，这可能是环境适应而非体质改变；反过来，南方人迁到北方出现口干、鼻干、便干，也可能是环境所致。判据是时间：与环境变化同步出现、又在适应后减轻的，记为环境反应；持续两年以上不随环境改善的，才进入体质判定。

## 三、年龄这一项，本库只能给方向

把「老年多见五质」写成结论之前，必须先看数据能不能支撑分层。本库的结构是：132 个证候，来自外科 325 个单元、儿科 250 个单元、妇科 325 个单元的扫描，共 900 个单元；每个证候带病名、科属、方剂，**不带年龄**。

因此以下三句话的可靠性完全不同：

1. 「老年常见气虚、阳虚、阴虚、痰湿、血瘀五质」——这是参照层的通行归纳，可写，但必须标注来源为参照而非本库；
2. 「这五质合计 67 证、占 132 证的 51%」——这是本库可复算的事实，可写；
3. 「老年人中这五质占 51%」——这是把「教材里占 51%」换成「人身上占 51%」，不成立，不可写。

第 3 句的错误形式在教学中反复出现：**分母从「证候」悄悄换成了「人」。** 识别方法是追问一句「这个百分比的分母是什么」。若答不出分母，这个数字就不能用。

能做的是另一件事：**用本库看兼夹的结构。** 兼夹指一个人同时满足两质以上的判据。本库中各质覆盖的病名数除以证候数，可以得到一个粗略的「扩散度」：湿热质 41/37 ≈ 1.1，阴虚质 29/18 ≈ 1.6，气虚质 19/17 ≈ 1.1，血瘀质 29/16 ≈ 1.8，气郁质 14/7 = 2.0。扩散度高说明该质的证候在病名上分布更散，往往伴随与其他证候的并存；扩散度低说明该质的证候集中在少数病名上。这个比值不能证明兼夹，但能提示哪些质更需要主动排查兼夹——血瘀质与气郁质排在前面，与「老年常两三相兼」的通行说法方向一致。

## 四、成组判据：把「不可改」与「可改」分开记【教学设定】

以下判据为教学设定，用于课堂练习统一口径；实际使用以所在机构制度与医师判断为准。

| 判据 | 内容 | 不成立的情形 |
|---|---|---|
| 归属 | 每条支持项都要标注它属于底板还是漂移 | 未标注归属即视为不可用 |
| 解释顺序 | 先排漂移项（近半年饮食、作息、情志、环境变化），再谈底板 | 跳过漂移直接归因底板 |
| 时程 | 漂移项引起的信号，须与变化同步出现且持续两月以上才计入判定 | 变化发生不足两月，或早于变化出现 |
| 底板限制 | 底板项不能单独支持判定，须有至少一域现症证据 | 只有父母体质与幼年病史，无现症 |
| 复评 | 漂移项调整后须复评；底板项不因复评改变 | 复评时重问底板并改动结论 |

**「不成立」的典型形态有三种：** 一是把季节反应记成体质（每年入夏口黏、入秋即消，这是季节信号不是体质漂移）；二是把一段生活事件记成体质（丧亲后半年情绪低落，属应激反应，须满半年且脱离事件后仍在才进入判定）；三是把药物作用记成体质（服用某些药物后口干、便秘，停药即消，不判阴虚）。

## 五、纵向档案、四种失效模式与本章考核

形成论落到操作上，就是一份纵向档案。字段设计要能回答一个问题：**这次和上次比，变的是哪一域，变化能否被某个推手解释。**

| 字段 | 取值形式 | 用途 |
|---|---|---|
| 首次辨识日期 | 年月日 | 纵向比较的起点 |
| 底板三项 | 父母／胎产／幼年，各一句定性 | 解释个体差异，不参与每次判定 |
| 本次漂移事件 | 列举近半年饮食、作息、情志、环境、劳逸变化 | 归因的第一顺位 |
| 四域分档 | 形态／功能／心理／易感各一档 | 看清变的是哪一域 |
| 与上次的差值 | 逐域写「升／平／降」，不写总分 | 总分同向抵消会掩盖真实变化 |
| 推手归因 | 从五个推手中选一至两个，写明证据 | 决定调理动作落在哪一层 |
| 复评时点 | 按性质定：季节转换／事件结束后／年度体检 | 保证档案连续 |
| 未解释项 | 有变化但找不到推手的，单列 | 累积三条以上应转医师评估 |

「未解释项」这一栏最容易被省略，却最有用。它是「体检式辨识」与「诊疗式辨识」的分界：连续多次出现无法用推手解释的变化，往往提示存在未被发现的疾病，此时体质档案应当转为就医线索，而不是继续调养。

**四种失效模式如下。**

**失效模式一：把体质当病名。** 在档案里写「禀赋不足病」或在告知时把底板说成「天生的病」。底板是解释项，不是诊断。

**失效模式二：单一特征定体质。** 见到腹围上升即判痰湿，而忽略舌苔、口黏、大便性状；腹围上升也可能只是近期活动量下降。

**失效模式三：标签化与歧视。** 用「先天不足」评价一个人的能力、性格或前途，或在招生、用工场景引用底板记录。底板记录仅用于调养参照。

**失效模式四：因体质判断而延误就医。** 把持续两月的体重下降、食欲减退、夜间盗汗一律解释为「阴虚漂移」。这类信号属于必须就医的情形，体质档案只能作为旁证附上。

**考核项（本章）：**

1. 用 17、7、18、9、16 五个数算出老年常见五质合计占比，并指出该数字的分母是什么；
2. 写出「老年人中五质占 51%」为何不成立，指出被替换的分母；
3. 为一个「入夏口黏、入秋即消」的就诊者判断是否构成体质漂移，写出理由；
4. 列出底板三项与漂移五项，各举一条不能单独成判据的例子；
5. 填一份纵向档案，八字段齐备，含至少一条「未解释项」的处置意见。

## 代价与边界

1. **本节的形成论只有方向，没有速率。** 底本不含年龄、地域、职业字段，任何「多少岁会漂移到什么程度」的表述都超出证据范围，本章一律不给。
2. **五推手的划分是教学简化。** 真实生活中饮食、作息、情志互相纠缠，一项改变往往带动另外两项；归因时要求写出证据，就是为了避免把纠缠当成单因。
3. **参照层的归纳不能当本库结论。** 「老年多见五质」来自老年病学的通行表述，本章引用时已标注为参照；读者若要用它做人群推断，须另找带年龄分层的资料。
4. **扩散度比值只是提示。** 病名数除以证候数受教材编写密度影响，不能读成兼夹率，更不能读成发病风险。
5. **免责声明：** 本章为教学整理，不构成诊疗建议；形成因素的判断与调养方案须由医师结合病史确定，出现新发或加重的症状应先就医。
