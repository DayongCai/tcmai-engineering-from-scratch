# 第 2 章 · 体质的形成：底板与漂移

> **MOTTO:** 「先天之强者不可恃，恃则并失其强矣」——教材·第2章·2.2（《景岳全书·传忠录·先天后天论》）
>
> **PROBLEM:** 「体质是天生的」与「体质可以调」两句话都对，但学生常把它们当成互斥。教材的写法是分层：**先天定底板，后天定漂移方向。** 底板决定「易感哪一类」，漂移决定「现在偏到哪一边」。
>
> **双根因定位:** 环境逼迫（同一个「痰湿质」在青年与老年身上的表现与风险完全不同）+ 知识积累（本章 2 单元，三辨主**先天禀赋 9**——全课程唯一以禀赋居首的章）

**教材出处:** 派生底本 + 老年病学 3.4.1（老年体质五种常见质与兼夹）。本章数字由 `code/main.js` 现算。

## 一、先天：三个来源

| 来源 | 内容 | 表现 |
|---|---|---|
| 父母禀赋 | 精血强弱 | 素体强弱、易感倾向 |
| 胎孕调养 | 孕期营养与情志 | 先天不足、过敏倾向 |
| 禀赋不耐 | 特异体质 | 特禀质 |

## 二、后天：四个变量

| 变量 | 方向 | 例 |
|---|---|---|
| 年龄 | 由实转虚、由单转兼 | 老年多气虚、阳虚、阴虚、痰湿、血瘀，常两三种兼夹 |
| 性别 | 女子多血、男子多气 | 女子易血虚、气郁；男子易痰湿、湿热 |
| 地域 | 东南湿热、西北燥寒 | 湿热质在南方更多见 |
| 饮食情志 | 肥甘助湿热、生冷伤阳、久郁成气郁 | 最可控的一环 |

**「老年多兼夹」这一条来自老年病学原文**：老年单纯平和质较少，常见者集中在气虚、阳虚、阴虚、痰湿、血瘀五种，且常以两三种兼夹出现——这解释了为什么本课程的体质判定必须支持「复合」。

## 三、底板与漂移的关系

```text
先天禀赋（底板）→ 决定易感方向
      ↓
后天因素（漂移）→ 决定当前偏颇
      ↓
体质（当前状态）＝ 底板 + 累积漂移
```

一句话：**底板不能改，漂移可以改。** 调养的全部空间在「漂移」这一段。

## 四、本章的方法学限制

先天禀赋在证候层几乎不可见——证候记录的是「已病」，而禀赋是「未病」。因此：

1. 本章关于禀赋的论述**以条理为主、数字从略**（三辨主禀赋 9，而全课程仅本章以此居首）；
2. 「哪个质更易感哪种病」这类问题，需要纵向队列，横向数据只能看共现（第 6 章展开）。

## 代价与边界

1. 本章不给「体质遗传度」类数字，因为派生底本无此数据；
2. 年龄与性别的影响是群体规律，不能推及个人；
3. **免责声明：** 教学整理，不构成诊疗建议。

## 五、四个后天变量的可操作化

| 变量 | 可观察到什么 | 可改变吗 |
|---|---|---|
| 年龄 | 质的兼夹数、虚象的比例 | 不可改，只能顺应 |
| 性别 | 女子血虚与气郁比例高，男子痰湿湿热比例高 | 不可改 |
| 地域 | 气候与饮食结构 | 部分可改（迁居、饮食） |
| 饮食情志 | 每日可观察的行为 | **完全可改** |

这张表回答了一个常见问题：「我的体质是不是天生的、改不了？」——**底板不可改，四个变量里有两个完全可改、一个部分可改**，所以体质调理不是空话。

## 六、与老年病学第 3 章的关系

老年病学 3.4.1（2,286 汉字）给了两点本课程直接引用的事实：

1. **老年单纯平和质较少**，常见者集中在气虚、阳虚、阴虚、痰湿、血瘀五质；
2. **常以两三种兼夹出现**（气虚兼痰湿、阳虚兼血瘀、阴虚兼气郁）。

这两点决定了本课程的判定必须支持复合（第 3 章），也决定了调养必须排主次（第 7 章）。**老年人群是体质学最重要的应用场景，它的规律反过来塑造了本课程的方法。**
