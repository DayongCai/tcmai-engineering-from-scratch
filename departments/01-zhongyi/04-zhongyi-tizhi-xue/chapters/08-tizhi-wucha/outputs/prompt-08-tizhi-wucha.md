# 同一个人测出两个体质，先查尺子再查人 · 提示词

## 用途

给「同一个人测出两个体质，先查尺子再查人」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三种误差：同一个人、不同施测者、同一工具 → 重测怎么做：条件比间隔更重要 → 一致性怎么读：三个数各自有盲区 → 判定线附近：给不确定留一个位置【教学设定】」这条链。

```

正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
```

本章为教学整理，不构成诊疗建议；具体操作以现行规范与所在机构制度为准。
