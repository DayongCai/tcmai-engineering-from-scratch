# 第 3 章 · 判定要靠两条同向证据，不能靠一条扎眼的特征

> **MOTTO:** 「凡五人者，其态不同，其筋骨气血各不等」——《灵枢·通天》
>
> **PROBLEM:** 九质在本库的证候数极不均衡：湿热质 37、阴虚质 18，两质合计 55 个证候，占 132 证的 41.7%；而痰湿质 9、阳虚质 7，两质合计仅 16 证。如果量表设计成「每质一题、答是即成立」，那么凡与热、与干相关的回答都会被吸收进前面两个大质，后面两个小质几乎不可能被选中。判定表要解决的不是「问得准不准」，而是「问完之后，小质还有没有机会被看见」。

**双根因定位:** 环境逼迫（辨识必须在有限时间内完成，条目越多越难落地，于是条目被迫压缩到「一质一题」）+ 知识积累（九种体质的定义清楚，但每个质的支持项、反证项与临界情形没有统一口径，施测者只能凭印象把握宽严）。

**参考件状态:** 本课程无足本参考件，不引页码版次。底本 13 个单元只给出九质的名称与四域描述，不含条目库与判定线；本章的条目设计、分档与临界规则均为教学设定，须与所在机构的量表规范核对后使用。文中的证候数与病名数取自 `standards/zhenghou/证候库.json`，可复算。

## 一、九质的判定要点：每一质都要有支持项、反证项与临界项

判定不是「像不像」，而是「支持项够不够、反证项排不排得掉」。下表把九质拆成三列：关键域（判定时权重最高的一域）、支持项（出现即加分）、反证项（出现即须重新考虑）。

| 体质 | 关键域 | 支持项 | 反证项 | 临界项（须追查后定） |
|---|---|---|---|---|
| 平和质 | 无（四域皆中） | 睡眠、食欲、体力、情绪长期稳定，患病少 | 任一项长期偏离 | 自评「很好」但体重或睡眠近期明显变化 |
| 气虚质 | 功能 | 疲乏、气短、自汗、易感冒、舌淡脉弱 | 明显畏寒肢冷（提示阳虚）、口苦苔黄（提示湿热） | 疲乏伴情绪低落（气郁与气虚并存） |
| 阳虚质 | 功能 | 畏寒肢冷、喜热饮、便溏、夜尿清长、舌淡胖脉沉迟 | 手足心热、盗汗、舌红少苔（提示阴虚） | 畏寒仅限手足、躯干不觉冷（可能为环境或气郁） |
| 阴虚质 | 功能 | 手足心热、口燥咽干、盗汗、便干、舌红少苔脉细数 | 畏寒、便溏、舌淡胖（提示阳虚） | 口干但饮水多而仍干（须排查其他原因） |
| 痰湿质 | 形态 | 形体肥胖、腹部松软、口黏、苔白腻、脉滑 | 形体消瘦、舌红少苔（提示阴虚）、苔黄腻口苦（提示湿热） | 肥胖但食欲差、便溏（脾虚与痰湿并存） |
| 湿热质 | 形态与功能并重 | 面垢油光、口苦口干、易生疮疡、苔黄腻、脉滑数 | 畏寒、便溏、苔白（提示阳虚或痰湿） | 仅有面部油腻而无苔象与口苦（不足以成立） |
| 血瘀质 | 形态 | 肤色晦暗、口唇暗淡、易有瘀斑、舌暗有瘀点、脉涩 | 面色红润、舌淡红无瘀点 | 瘀斑仅见于外伤部位（须排除外伤） |
| 气郁质 | 心理 | 情绪低落、胸胁胀满、善太息、脉弦 | 情绪高涨、语声洪亮、无胸胁苦满 | 情绪低落继发于明确事件且未满半年 |
| 特禀质 | 易感 | 明确过敏诱因、易感外邪、禀赋不耐 | 无明确诱因的「易感冒」（可能为气虚） | 过敏仅在特定季节（须区分季节性与常年性） |

这张表的用法是**先看关键域，再看反证项，最后看临界项**。顺序不能颠倒：先看支持项会让施测者只找符合自己第一印象的证据（确认偏误），先看反证项则等于先做排除，结论稳得多。

## 二、题目怎么写：可观察、带频次、一题一域

一道好的条目要满足三个条件，缺一条就会污染结果。

**条件一：可观察。** 「你觉得自己虚吗」不可观察，因为「虚」是结论而不是现象；「上三层楼是否气短」可观察。条目要描述具体情境与具体反应，把判断留给计分规则，不留给被问者。

**条件二：带频次或程度。** 「是否口干」只有两个答案，会把「偶尔」与「每天」压成同一档；改成「口干出现的频次：从不／偶尔／经常／几乎每天」，同一现象才有分辨力。

**条件三：一题一域。** 「怕冷且容易疲劳」把功能域的两个方向混在一题，答「是」时无法知道是怕冷还是疲劳。一题一域是量表设计里最容易违反也最致命的一条，因为它在填写时毫无异样，只在计分后才暴露。

| 反面写法 | 问题 | 改法 |
|---|---|---|
| 你体质偏虚吗 | 用结论当题目 | 近半年是否常感疲乏、休息后不易恢复 |
| 是否怕冷或怕热 | 两个方向混一题 | 拆成两题：畏寒部位与程度；手足心热与程度 |
| 是否容易生病 | 无频次、无诱因 | 近一年感冒几次，是否每次都在受凉后 |
| 是否心情不好 | 一时状态与长期基调不分 | 近半年情绪低落的持续时间与是否善太息 |

**计分的第一步不是相加，而是域内标准化。**

四个域的原始形式不同：形态是描述或测量值，功能是频次，心理是自评，易感是计次。**直接相加在数学上无意义**，因为一个「肥胖」与一个「每天口干」不在同一量纲上。

| 域 | 原始形式 | 标准化做法 | 注意事项 |
|---|---|---|---|
| 形态 | 分档（偏瘦／适中／偏胖）+ 舌象描述 | 转为四级序数 | 舌象由施测者记录，不采自评 |
| 功能 | 频次（从不／偶尔／经常／几乎每天） | 直接映射四级 | 同一域内条目方向须一致，反向条目先翻转 |
| 心理 | 自评四级 | 反向题翻转后计分 | 翻转是最常漏的一步，漏了会互相抵消 |
| 易感 | 计次（近一年）+ 诱因 | 分档后映射四级 | 无诱因的计次不能直接当特禀证据 |

缺失的处理只有一条规则：**缺失记为「未测」，不记为零分，也不记为最低分。** 若某域缺失条目超过该域条目数的一半，该域整体记为未测，判定时按「域数不足」处理，不给结论。把缺失填成最低分，等于把「没问」当成「没有」，这是量表类工具最常见的数据污染。

## 三、成组判据与「不成立」条件【教学设定】

以下为教学设定，用于课堂练习与考核；临床判定以所在机构量表规范与医师判断为准。

| 判据 | 内容 | 不成立的情形 |
|---|---|---|
| 域数 | 至少两域同向支持 | 仅一域支持；或两域方向相反 |
| 关键域 | 该质的关键域必须支持 | 关键域中立（未达阈值）或反向 |
| 反证 | 无该质的反证项 | 出现任一反证项，须先解释再判 |
| 时程 | 支持项持续半年以上 | 与近期事件同步，或不足半年 |
| 排除 | 已排除急性病、药物、妊娠、术后、时差 | 未排除，或排除记录缺失 |
| 并列 | 两质同时满足则记为并列 | 为求简洁强行择一 |

**「不成立」的六种典型形态**，每一种都要在练习中遇到过，否则判定会流于形式：

1. **只有一条扎眼特征。** 体型偏胖但舌苔不腻、无口黏、大便正常——不成立痰湿。
2. **关键域不支持。** 情绪长期低落但无胸胁胀满、无善太息、脉不弦——气郁待定，不成立。
3. **被近期急性病解释。** 感冒后两周内的疲乏与自汗，不足以判气虚。
4. **被药物解释。** 服某些药物后口干、便秘，停药即消，不判阴虚。
5. **被一时状态解释。** 连续熬夜一周后的口干与手足心热，须待作息恢复后复评。
6. **被单一检查值解释。** 体重指数偏高但形体结实、舌脉无异常，不能仅凭数值判痰湿。

## 四、记录字段：让判定可以被第二个人复核

| 字段 | 取值形式 | 用途 |
|---|---|---|
| 量表名称与版本 | 名称 + 版本号 | 换版本后分数不可直接比 |
| 条目应答原始值 | 逐题记录，不记总分 | 复核时要能追到具体条目 |
| 各域得分 | 四域各一值 + 是否含未测项 | 判定看域，不看总分 |
| 关键域判定 | 支持／中立／反向 | 关键域反向即一票否决 |
| 主质、兼夹、待定 | 主质一、兼夹零至二、待定若干 | 「待定」必须允许出现 |
| 排除项 | 急性病、用药、妊娠、术后、时差 | 缺此栏的判定不予复核 |
| 判定人与复核人 | 两人姓名缩写 | 双人复核可显著降低宽严漂移 |
| 复核结论 | 一致／修正／退回 | 记录分歧本身就是质量数据 |

## 五、四种失效模式与本章考核

**失效模式一：把体质当病名。** 量表输出「某某质」后直接在文书里写成诊断，甚至据此开具体治疗方案。量表输出的是倾向判断，须由医师结合四诊确认。

**失效模式二：单一特征定体质。** 一条高分条目即定质，尤其常见于体型与情绪两项。防法是强制两域同向，并强制填写反证项。

**失效模式三：标签化与歧视。** 把量表结果用于招生、用工、保险核保或人际评价。量表是调养参照，不具资格判定效力。

**失效模式四：因判定而延误就医。** 把持续存在的异常（体重下降、夜间盗汗、便血、持续低热）算作「某质的常态」，从而推迟检查。量表不能替代检查，这一点须写在量表首页。

**考核项（本章）：**

1. 用 37、18、9、7 四个数与 132 复算，说明「一质一题」为何会挤压小质；
2. 为痰湿质写两条可观察条目，各带四级频次，且不跨域；
3. 给出一份含一个未测域的量表结果，判定应如何处理；
4. 列出「不成立」的六种形态，每种配一个具体病案片段的判读；
5. 填一份判定记录，八字段齐备，并写出至少一条反证项。

## 代价与边界

1. **条目与阈值均为教学设定。** 本章不给常模、不给切点、不给权重数值，因为这些必须由量表研制方与所在机构确定；课堂练习用的是相对比较，不是可对外引用的标准。
2. **九质的边界本身有交叠。** 气虚与阳虚的界在「有无寒象」，但在临界情形下这条界会失效；本章的处理是允许「待定」，而不是强行归类。
3. **判定一致性依赖培训。** 同一份答卷由不同施测者判读，宽严差异可能大于被辨识者本身的差异；双人复核与版本记录是唯一可控的手段。
4. **量表不能替代四诊。** 自评条目只能覆盖被辨识者能感知的部分，舌象、脉象、形态须由施测者记录，二者不可互相替代。
