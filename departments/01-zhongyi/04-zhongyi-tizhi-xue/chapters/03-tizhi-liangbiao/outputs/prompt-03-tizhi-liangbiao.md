# 判定要靠两条同向证据，不能靠一条扎眼的特征 · 提示词

## 用途

给「判定要靠两条同向证据，不能靠一条扎眼的特征」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「九质的判定要点：每一质都要有支持项、反证项与临界项 → 题目怎么写：可观察、带频次、一题一域 → 成组判据与「不成立」条件【教学设定】 → 记录字段：让判定可以被第二个人复核」这条链。

```

正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：

2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
```
