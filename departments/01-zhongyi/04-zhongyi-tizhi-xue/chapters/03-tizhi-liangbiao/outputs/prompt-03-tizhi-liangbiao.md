# 四域定质

## 用途

每个质都有「最关键的域」。**先查关键域，再用其余三域佐证**——这是可复核的判定方式。

## 步骤

### 1. 记四域

形态／功能／心理／易感各一条

### 2. 找关键域

按第 3 章表确定该质的关键域得分

### 3. 定主质

关键域支持且另有 ≥1 域佐证

### 4. 定兼夹

2–3 个质并存时排主次

## 判据速查：四域各一句提问

| 域 | 提问 |
|---|---|
| 形态 | 「这两年体重与腰腹有什么变化？舌苔厚不厚？」 |
| 功能 | 「爬三层楼气短吗？怕冷还是怕热？大便成形吗？」 |
| 心理 | 「最近心情怎么样？常叹气吗？」 |
| 易感 | 「一年感冒几次？有没有明确的过敏？」 |

四问之后再查关键域，主质就出来了；其余三域作佐证，不作主证。

## 输出

① 四域记录；② 关键域与得分；③ 主质；④ 兼夹与主次。

## 边界

- 数字一律由 `code/main.js` 读 `standards/tizhi/units.json` 与 `体质库.json` 现算，不手写；
- 不给方药剂量、不给量表条目；
