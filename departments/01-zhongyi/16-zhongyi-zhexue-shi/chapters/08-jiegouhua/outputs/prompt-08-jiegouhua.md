# 三能三不能

## 用途

**能检索、能对照、能追问；不能判归属、不能评高下、不能推人群。**

## 步骤

### 1. 分类命题

检索／对照／追问，还是归属／高下／人群

### 2. 定证据

命中数、语料、Top 篇是否齐

### 3. 改写

不能做的命题改成能做的说法

### 4. 标限制

词频 ≠ 地位

## 判据速查

| 项 | 数字 |
|---|---|
| 内经语料 | 162 篇 / 490,232 汉字 |
| 临床语料 | 2,792 条（伤寒 1,760 + 金匮 402 + 温病 630） |
| 气的分布 | 10,855 / 1,520（双高） |
| 阴阳分布 | 9,797 / 1,370（双高） |
| 道 与 五行 | 1,479 / 30 与 129 / 0（论说词） |

## 输出

① 命题类型；② 可否用本课程证据；③ 替代说法；④ 限制说明。

## 边界

- 数字一律由 `code/main.js` 读 `standards/zhexue/` 现算，不手写；
- 词频只说明分布，不说明地位；单字噪声须一并报；
