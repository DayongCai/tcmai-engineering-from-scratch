# 三问定序

## 用途

三条规则考的是**次序**，不是知识量。次序错了，知识再多也用不出来。

## 步骤

### 1. 问常变

这是常局还是变局

### 2. 问顺逆

正治还是反治

### 3. 问标本

谁先谁后

### 4. 给次序

写出一二三与理由

## 判据速查

| 项 | 数字 |
|---|---|
| 内经语料 | 162 篇 / 490,232 汉字 |
| 临床语料 | 2,792 条（伤寒 1,760 + 金匮 402 + 温病 630） |
| 气的分布 | 10,855 / 1,520（双高） |
| 阴阳分布 | 9,797 / 1,370（双高） |
| 道 与 五行 | 1,479 / 30 与 129 / 0（论说词） |

## 输出

① 常/变；② 正治/反治；③ 标本先后；④ 次序依据与失败模式。
