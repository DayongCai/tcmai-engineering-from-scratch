# 分类还是生成

## 用途

五行以词罕见（129→0），以关系无处不在。**用名与用功能，是两件事。**

## 步骤

### 1. 定读法

分类（归类）／生成（生克传变）

### 2. 找句式

母病及子／子病犯母／相乘／相侮

### 3. 判价值

能否推出临床判断（归类不能，生成能）

### 4. 防误判

不要以词频否定思想

## 判据速查

| 项 | 数字 |
|---|---|
| 内经语料 | 162 篇 / 490,232 汉字 |
| 临床语料 | 2,792 条（伤寒 1,760 + 金匮 402 + 温病 630） |
| 气的分布 | 10,855 / 1,520（双高） |
| 阴阳分布 | 9,797 / 1,370（双高） |
| 道 与 五行 | 1,479 / 30 与 129 / 0（论说词） |

## 输出

① 读法；② 对应句式；③ 能否推判断；④ 与阴阳的分工。
