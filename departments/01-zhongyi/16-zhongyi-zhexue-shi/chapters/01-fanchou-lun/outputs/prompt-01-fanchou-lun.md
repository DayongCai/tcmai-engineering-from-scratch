# 范畴三件

## 用途

哲学史最怕变成背名词。**每个范畴结论必须报三件：命中数、语料、Top 篇**，否则不可复核。

## 步骤

### 1. 定范畴

该词是否可同名检索、是否在两个以上层面使用

### 2. 查命中

内经 490,232 汉字 / 临床 2,792 条

### 3. 看分布

Top 篇在哪：集中还是均分

### 4. 定类型

论说词（内经高临床低）／操作词（双高）

## 判据速查

| 项 | 数字 |
|---|---|
| 内经语料 | 162 篇 / 490,232 汉字 |
| 临床语料 | 2,792 条（伤寒 1,760 + 金匮 402 + 温病 630） |
| 气的分布 | 10,855 / 1,520（双高） |
| 阴阳分布 | 9,797 / 1,370（双高） |
| 道 与 五行 | 1,479 / 30 与 129 / 0（论说词） |

## 输出

① 范畴；② 命中与语料；③ Top 篇；④ 论说或操作；⑤ 推断限制。
