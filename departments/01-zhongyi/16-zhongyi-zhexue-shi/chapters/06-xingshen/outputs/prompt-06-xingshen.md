# 双向链

## 用途

**形为神之宅，神为形之主。** 两句话必须一起用，单用一句就走偏。

## 步骤

### 1. 定方向

形→神 / 神→形 / 并见

### 2. 定侧重

治形为主、治神为主或互治

### 3. 找依据

纳食、睡眠、脉象等可观察项

### 4. 防越界

不以神代形，不漏器质病

## 判据速查

| 项 | 数字 |
|---|---|
| 内经语料 | 162 篇 / 490,232 汉字 |
| 临床语料 | 2,792 条（伤寒 1,760 + 金匮 402 + 温病 630） |
| 气的分布 | 10,855 / 1,520（双高） |
| 阴阳分布 | 9,797 / 1,370（双高） |
| 道 与 五行 | 1,479 / 30 与 129 / 0（论说词） |

## 输出

① 方向；② 治疗侧重；③ 可观察依据；④ 越界风险。
