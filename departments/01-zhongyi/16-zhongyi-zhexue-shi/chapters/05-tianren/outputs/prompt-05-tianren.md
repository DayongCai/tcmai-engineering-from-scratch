# 天人相应是以天地为参数的关系模型，不是养生口号 · 提示词

## 用途

给「天人相应是以天地为参数的关系模型，不是养生口号」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三个参数：时、地、人 → 参数怎样进入诊断与治法 → 模型的边界：能解释季节，不能解释个体 → 被误用时的表现与可判断的标志」这条链。

```
我在学《中医哲学史》第 5 章「天人相应是以天地为参数的关系模型，不是养生口号」，本章 5 节 / 2,842 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
```
