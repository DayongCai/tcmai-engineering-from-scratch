# 三参数

## 用途

天人模型是三因制宜的来源。**落地的是「时」，不是「天地」。**

## 步骤

### 1. 时

季节、节气、昼夜

### 2. 地

燥湿寒温、海拔

### 3. 人

年龄、体质、情志

### 4. 边界

群体规律不能直接作个体预测

## 判据速查

| 项 | 数字 |
|---|---|
| 内经语料 | 162 篇 / 490,232 汉字 |
| 临床语料 | 2,792 条（伤寒 1,760 + 金匮 402 + 温病 630） |
| 气的分布 | 10,855 / 1,520（双高） |
| 阴阳分布 | 9,797 / 1,370（双高） |
| 道 与 五行 | 1,479 / 30 与 129 / 0（论说词） |

## 输出

① 三参数；② 各自改变什么；③ 模型边界；④ 需体质/辨证补足处。
