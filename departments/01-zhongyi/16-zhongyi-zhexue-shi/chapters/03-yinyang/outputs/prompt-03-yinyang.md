# 关系检验

## 用途

阴阳是关系不是物质。**凡是能量化的是气，凡是只能论关系的是阴阳。**

## 步骤

### 1. 定转义

现象 / 范畴 / 工具

### 2. 定两端

这一处的阴与阳各指什么（两端必须都说得出）

### 3. 查可否量化

能否称重、能否计数（不能则是阴阳）

### 4. 防误用

是否只讲对立忘了互根

## 判据速查

| 项 | 数字 |
|---|---|
| 内经语料 | 162 篇 / 490,232 汉字 |
| 临床语料 | 2,792 条（伤寒 1,760 + 金匮 402 + 温病 630） |
| 气的分布 | 10,855 / 1,520（双高） |
| 阴阳分布 | 9,797 / 1,370（双高） |
| 道 与 五行 | 1,479 / 30 与 129 / 0（论说词） |

## 输出

① 转义阶段；② 两端所指；③ 可否量化；④ 常见误用提示。
