# 气是内容，道是形式，两个本体词不能互换 · 提示词

## 用途

给「气是内容，道是形式，两个本体词不能互换」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「气的三义：质料、动力、中介 → 道不是另一种气 → 从本体到动作：四个「气」字对应四个动词 → 被误用时的表现与可判断的标志」这条链。

## 提示词

```
我在学《中医哲学史》第 2 章「气是内容，道是形式，两个本体词不能互换」，本章 6 节 / 3,012 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 「气」不是一个可以被单独定义的名词，而是一个随上下文改变重心的词
   - 你能指着一个东西说「这就是道」时，你指的通常已经是气，不是道
   - 气是内容，道是形式；气回答「有什么」，道回答「按什么次序」
   - 本体词的价值，就在于它逼你先把「不够、不通、反上、陷下」分开，再谈用什么
   - 把「气」当成万能主语
   - 一个不能被证伪的判断，在临床上也不能被使用
4. 本章自陈的边界（不得越过）：
   - 本章只处理气与道在本库文本中的用法，不涉及先秦诸子对「道」的完整讨论；那需要原书，本课程不代为转述。
   - 「气」的单字统计噪声很大，合成词（气机、气化、血气、邪气）与单字必须分开计，否则会高估其独立性。
   - 三义的划分是教学用的分析框架，文本中三义常在同一句里重叠；本章不主张古人先有这三个定义再使用。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```
