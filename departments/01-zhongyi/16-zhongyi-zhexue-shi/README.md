## 一、这门课的做法：范畴史，不是年表

中医哲学史最容易上成两样东西：人物年表，或观点罗列。两者都不能回答一个具体问题——**这些词在文本里到底占多大分量？**

本课程只做能复算的那一种：把 12 个哲学范畴当可检索词，在**本库已有的经典全文**里统计分布。

| 写法 | 可复核性 | 本课程 |
|---|---|---|
| 编年 / 学派 / 观点罗列 | 低（需原著与史料） | 否 |
| **范畴分布（词频与 Top 篇）** | **高（可现算）** | **是** |

## 四、三条最值得记住的读数

1. **头尾差 84 倍**（气 10,855 vs 五行 129）——这不是「五行不重要」，而是「五行很少作为一个词出现」；
2. **「五行」在 2,792 条临床经典里 0 命中**，但「肝病传脾，当先实脾」「肝气犯胃」遍地都是——**以词罕见、以关系无处不在**；
3. **道 1,479 → 临床 30**——哲学词与医学词的分野最清楚的样本。落地的是「时」（四时 1,807 → 527），不是「天地」（3,695 → 143）。

## 五、四个层面（全书结论）

| 层 | 范畴 | 性质 |
|---|---|---|
| 本体 | 气 / 道 | 气双高、道论说 |
| 关系 | 天地 / 阴阳 / 五行 / 四时 | 阴阳双高、五行词稀 |
| 方法 | 常变 / 顺逆 / 标本 / 权衡 | 顺逆与标本真正落地（各约两成） |
| 心身 | 形神 / 志意 | 密度中低，但进入操作 |

## 六、口径

- **三辨＝范畴 / 文本依据 / 医学转用**（单元首位：文本依据 4、医学转用 4、范畴 2）；
- **四位面＝本体 / 关系 / 方法 / 心身**（单元首位：关系 4、本体 2、心身 2、方法 1）；
- 10 个派生单元、8 章，`locator` 以「派生·第N章·」开头。

## 七、三条不能做的事（与各家学说同一标准）

| 不能做 | 原因 |
|---|---|
| 判定学派归属 | 词面命中不含思想归属 |
| 评价思想高下 | 分布说明频率，不说明对错 |
| 推断人群观念 | 文本密度 ≠ 社会观念 |
