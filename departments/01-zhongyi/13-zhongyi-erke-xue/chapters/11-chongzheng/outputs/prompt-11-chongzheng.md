# 虫证三问：夜间、痛性与同病者

## 用途

两种虫证，靠三个问题就能定位；两型急症靠第二问的「痛性」抓出来。

## 第一问：症状在夜间还是白天

- **夜间肛周瘙痒、夜寐不安** → 蛲虫病（夜间可见白色线头样小虫）；
- 白天脐周隐痛、时作时止、纳差消瘦 → 蛔虫病。

## 第二问：痛的性质（决定是否急症）

| 痛 | 指向 | 处置 |
|---|---|---|
| 脐周隐痛、时作时止 | 虫积肠道 | 驱虫（使君子散类） |
| 突发脘腹**绞痛＋四肢厥冷** | **蛔厥**（钻入胆道） | 立即就医（乌梅丸方向，不自行驱虫） |
| 腹痛阵作＋**腹部条索状包块＋呕吐＋便闭** | **虫瘕**（成团梗阻） | 立即就医（外科范畴） |

## 第三问：家庭与集体有无同病者

有 → 蛲虫可能性大，须**全家同治＋衣裤被褥煮沸消毒**，否则再感染。

## 治疗三条实务（蛲虫）

内服＋外洗（百部、苦楝皮煎汤熏洗肛周）＋环境消毒；缺任一条都会「治好又犯」。

## 输出格式

```text
虫种方向：蛔/蛲
证型：虫积肠道 / 蛔厥 / 虫瘕 / 蛲虫
治疗要点：驱虫 · 外洗 · 同治 · 消毒
转诊：<无 / 蛔厥 / 虫瘕>
```
