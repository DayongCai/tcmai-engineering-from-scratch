# 生长三问 + 两条时限

## 用途

把「长得够不够、吃得对不对」变成可记录的三问，再加两条有时限的动作（辅食、接种）。

## 第一问：量了没有

- 体重、身高（身长）、头围、胸围；
- 测量条件：**晨起空腹、排尿后称重**；**立正、去鞋帽量身长/身高**；
- 上次测量时间与数值（没有上一次就没有趋势）。

## 第二问：放在曲线的哪里、趋势如何

| 判读 | 含义 |
|---|---|
| 低于同年龄同性别均值 2 个标准差以下 | 警惕营养不良、慢性消耗病、内分泌疾病 |
| 体重增长缓慢而身高正常 | 近期摄入不足 |
| 体重与身高均落后 | 慢性疾病或内分泌因素 |
| 仅单次偏低、曲线平行 | 多为个体差异，随访 |

## 第三问：单项还是多项落后

- 只体重落后 → 先查喂养与近期疾病；
- 只身高落后 → 查慢性病、内分泌、遗传（结合父母身高）；
- 大运动/精细/语言单项落后 → 随访＋多领域评估（里程碑是筛查，不是诊断）。

## 时限一：辅食

4–6 个月开始（纯母乳可满 6 个月；**最早不早于 4、最晚不晚于 8**）。五原则：由少到多、由稀到稠、由细到粗、由一种到多种（**新食物观察 3–5 天**）、循序渐进；患病期间暂缓添加。

## 时限二：接种

按免疫程序表对月龄：出生（乙肝1＋卡介苗）、1 月（乙肝2）、2 月（脊灰1）、3 月（脊灰2＋百白破1）、4 月（脊灰3＋百白破2）、5 月（百白破3）、6 月（乙肝3＋流脑A1）、8 月（麻腮风1＋乙脑1）、18 月（百白破4＋麻腮风2）、2 岁（乙脑2）、3 岁（流脑AC1）、4 岁（脊灰4）、6 岁（白破＋流脑AC2）。**接种证入托入学必查**。

## 输出格式

```text
测量：体重…／身高…／头围…（日期）
曲线：第…百分位，趋势…
偏离类型：体重慢/身高慢/两者/单项发育
下一步：观察随访 / 喂养指导 / 转诊（依据）
时限：辅食（是/否/何时）｜接种（漏种项）
```

## 边界

不做个体化营养处方、不给接种禁忌判断；异常须转儿童保健或专科。
