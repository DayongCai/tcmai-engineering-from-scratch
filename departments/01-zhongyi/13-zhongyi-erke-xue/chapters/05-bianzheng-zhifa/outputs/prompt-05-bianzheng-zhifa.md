# 选尺三步：先问用哪一套辨证

## 用途

三套辨证不是三选一，而是三个适用区间。本单用三步决定「先拿哪把尺」，再进入具体辨证。

## 第一步：外感还是内伤

| 起病 | 主线索 | 首选框架 |
|---|---|---|
| 急、有接触史/受凉史、发热为主 | 发热恶寒、咽红、疹、咳 | **卫气营血**（＋三焦定位） |
| 缓、与喂养/体质/久病相关 | 纳差、便溏、消瘦、生长迟 | **脏腑辨证**（钱乙五脏） |
| 任何情况 | 阴阳表里寒热虚实 | **八纲**（总纲，先立） |

## 第二步：现在在哪一段

- 卫气营血四段对照（ch05 表）：卫/气/营/血；
- 儿科修正：**不必拘泥循序**——卫气同病、气营两燔、气血两燔、逆传心包都常见；故「见微知著、先证而治」；
- 主线是**透邪外达**：卫分辛凉透表；入营透热转气；疹出不畅须透疹，**忌早用苦寒冰伏**。

## 第三步：该用哪一法、禁区在哪

| 法 | 禁区 |
|---|---|
| 疏风解表 | 发汗不宜太过；表虚自汗者改益气固表 |
| 清热解毒 | 苦寒中病即止，勿伤脾、勿冰伏 |
| 健脾运脾 | 「脾健不在补，贵在运」 |
| 平肝息风 | 虫类药有毒，用量从严、不可久服 |
| 宣肺化痰 | 见咳止咳不可取，先辨痰之寒热 |

## 红线（不在辨证层面处理）

- 惊厥持续 >5 分钟或反复发作 → 急诊；
- 斑疹紫黑、出血不止 → 转诊；
- 神昏谵语＋高热 → 警惕逆传心包。

## 输出格式

```text
框架：八纲（…）＋ <卫气营血 / 脏腑>
段位：<卫/气/营/血 或 某脏某证>
治法与代表方：<不含剂量>
禁区/红线：…
```

## 边界

本单只做框架选择与治法方向，不给方药剂量、不给加减；临床用药由医师依现行规范开具。
