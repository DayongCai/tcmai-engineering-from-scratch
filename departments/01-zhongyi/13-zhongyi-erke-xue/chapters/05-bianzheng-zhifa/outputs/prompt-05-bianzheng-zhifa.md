# 三套辨证不是三个答案：一套定位、一套分期、一条用药律 · 提示词

## 用途

给「三套辨证不是三个答案：一套定位、一套分期、一条用药律」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三套辨证各管一件事 → 把四诊的证据组织成「一组」 → 一条用药律：轻清灵动，以及它的四条边界 → 记录与失效模式」这条链。

## 提示词

```
我在学《中医儿科学》第 5 章「三套辨证不是三个答案：一套定位、一套分期、一条用药律」，本章 5 节 / 2,804 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 回答的问题不同
   - 八纲给性质，不给部位
   - 脏腑给部位，不给阶段
   - 卫气营血给阶段，不替代脏腑细目
   - 串联而不是并列
   - 最重要的一组反常
4. 本章自陈的边界（不得越过）：
   - **本章不含方药剂量、疗程与具体处方**：教材给的折算比例只说明「随年龄移动」，本书照录事实、不给数值；一切处方由医师依现行规范决定。
   - **三套辨证的排序不是教条**：时行病（第 10 章）以卫气营血、三焦为主轴，脏腑辨证为辅；脾系、肾系慢病（第 7、9 章）以脏腑为主轴。用错主轴，会把一个五日病程讲成一个月的调理。
   - **「真热假寒」这类反常必须靠时间顺序识别**，不能靠单次体征。凡体征与病史方向相反，先信病史的时间顺序。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

不构成诊疗建议，不能替代医师面诊；具体操作以现行规范与所在机构制度为准。
