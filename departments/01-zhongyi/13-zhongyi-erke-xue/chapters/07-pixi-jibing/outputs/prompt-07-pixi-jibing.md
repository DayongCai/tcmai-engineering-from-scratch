# 管道定位五问：症状在哪一格

## 用途

脾系九证按「入口→受纳→运化→出口＋气机」排列。本单先定位，再分虚实，最后判该「运」还是该「补」。

## 第一问：在哪一格

| 主症 | 格位 | 病证 |
|---|---|---|
| 口腔白屑 | 入口 | 鹅口疮 |
| 口腔溃疡、灼痛流涎 | 入口 | 口疮 |
| 长期不想吃 | 受纳 | 厌食 |
| 吃了不化、脘胀嗳腐、大便酸臭 | 运化 | 积滞 |
| 消瘦、面黄发枯、精神差 | 运化（慢性） | 疳证 |
| 便次增多、粪质稀薄或水样 | 出口·下（泻） | 泄泻 |
| 便干难下或间隔延长 | 出口·下（秘） | 便秘 |
| 乳食由口吐出 | 气机上逆 | 呕吐 |
| 胃脘以下、耻骨以上痛 | 气机不通 | 腹痛 |

## 第二问：急性还是慢性

急性（数日）：伤食泻、湿热泻、风寒泻、伤食呕吐、乳食积滞腹痛；
慢性（数周～数月）：脾虚泻、脾肾阳虚泻、厌食、积滞日久、疳证、气虚便秘。

## 第三问：虚实三分（脾系特有）

- **能食不能化** → 积滞（实）；
- **不想吃** → 厌食（虚实夹杂）；
- **吃了也不长** → 疳证（虚，气液耗伤）。

## 第四问：两条红线

1. **脱水**：前囟/目眶凹陷、皮肤干燥、尿少、精神萎软 → 泄泻变证（气阴两伤），急诊补液；四肢厥冷、脉微欲绝 → 阴竭阳脱，急诊。
2. **急腹症**：腹痛剧烈拒按、发热呕吐、腹部包块 → 转诊，不做「脾虚腹痛」解释。

## 第五问：该运还是该补

| 情形 | 取法 |
|---|---|
| 湿滞、食积 | 先运（不换金正气散、保和丸类） |
| 脾虚不运 | 运脾为主、补脾寓于运（「脾健不在补，贵在运」） |
| 干疳、气血大虚 | 方可峻补（八珍汤类），且须先顾脾胃 |

## 输出格式

```text
格位：入口/受纳/运化/出口/气机 → 病证候选
急慢：…
虚实：能食不能化 / 不想吃 / 吃了不长
红线：<无 / 脱水 / 急腹症>
取法：运 / 消 / 补（先运后补）
```

## 边界

只做定位与方向，不给剂量；脱水与急腹症不在本单范围内处理。
