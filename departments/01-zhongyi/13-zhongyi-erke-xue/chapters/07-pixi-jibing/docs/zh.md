# 第 7 章 · 脾系疾病：九证沿一条管道排开

> **MOTTO:** 「湿胜则濡泄」——教材·第7章·7.3.1（《素问·阴阳应象大论》）
>
> **PROBLEM:** 九个病证看起来互不相干：口腔白屑、口疮、拉肚子、不吃饭、肚子胀、消瘦、呕吐、肚子痛、便秘。学生按病名背，背完仍不知道为什么它们在同一章。真正的关系在**空间**：它们沿着「入口 → 运化 → 出口」这一条管道排列，加上一个上下方向的「气机」（呕与痛）。位置不同，判据就不同。
>
> **双根因定位:** 环境逼迫（同一件事——喂养——在管道的不同位置表现为完全不同的症状：入口是口疮、中间是厌食与积滞、出口是泄泻与便秘）+ 知识积累（本章 45 单元、33,152 字，是全书最长一章；**证候表现 381、脾胃系 1,121** 双居首位；**引书 36 部 99 次，全课程最高**）

**教材出处:** 教材·第 7 章（7.1 鹅口疮、7.2 口疮、7.3 泄泻、7.4 厌食、7.5 积滞、7.6 疳证、7.7 呕吐、7.8 腹痛、7.9 便秘，共 9 病证 45 单元）。本章数字由 `code/main.js` 读 `standards/erke/units.json` 现算。

## 一、九证的位置图

| 位置上 | 病证 | 一句话判据 |
|---|---|---|
| 入口·口腔 | 鹅口疮 | 口腔舌上满布**白屑，状如鹅口**（又名雪口） |
| 入口·口腔 | 口疮 | 唇颊上腭齿龈舌面**淡黄或灰白小溃疡**，灼痛流涎拒食 |
| 受纳 | 厌食 | **较长时期**食欲不振、见食不贪、食量减少 |
| 运化 | 积滞 | 内伤乳食、**积而不化**：不思乳食、脘腹胀满、嗳腐吞酸、大便酸臭 |
| 运化（慢性） | 疳证 | 脾胃受损、气液耗伤：**形体消瘦、面黄发枯**、精神萎靡或烦躁 |
| 出口·下 | 泄泻 | 大便次数增多、**粪质稀薄或如水样** |
| 出口·下 | 便秘 | 大便干燥坚硬、排出困难，或**间隔延长** |
| 气机上逆 | 呕吐 | 胃失和降、气逆于上，乳食由胃经口吐出 |
| 气机不通 | 腹痛 | 胃脘以下、耻骨毛际以上疼痛 |

这条图解决一个实际问题：**同一个孩子可以同时占两格**（疳证常兼泄泻、积滞常兼腹痛）。教材把它们分列，是为了让每一格有独立的判据；临证要按「主症在哪一格」定主次。

## 二、泄泻：六型 + 两个变证（本章最重）

教材 7.3 是本章最长的一节。病因分内外：外感风寒湿热、内伤乳食，病位在脾胃，**湿是核心**（「湿胜则濡泄」）。

| 证型 | 要点 | 代表方 |
|---|---|---|
| 湿热泻 | 泻下急迫、色黄褐、气味臭秽、苔黄腻 | 葛根黄芩黄连汤（《伤寒论》） |
| 风寒泻 | 泻下清稀、泡沫多、肠鸣腹痛、兼表证 | 藿香正气散（《太平惠民和剂局方》） |
| 伤食泻 | 大便酸臭、夹不消化物、脘腹胀满、嗳腐 | 保和丸（《丹溪心法》） |
| 脾虚泻 | 久泻不止、食后即泻、色淡不臭、面黄神疲 | 参苓白术散（《太平惠民和剂局方》） |
| 脾肾阳虚泻 | 久泻不止、完谷不化、形寒肢冷、脉沉细 | 附子理中汤（《太平惠民和剂局方》）合四神丸（《治证准绳》） |

**两个变证，是儿科的生死线**：

| 变证 | 表现 | 方 |
|---|---|---|
| **气阴两伤** | 泻下无度、精神萎软、目眶与前囟凹陷、皮肤干燥、口渴引饮、尿少 | 人参乌梅汤（《温病条辨》） |
| **阴竭阳脱** | 面色苍白、四肢厥冷、汗出不止、脉微欲绝 | 生脉散（《医学启源》）合参附龙牡救逆汤 |

「前囟凹陷」这四个字把第 2 章的常数接了上来：**摸前囟就是读脱水**。教材 4.1.3 另给了「水样便量多如米泔须防重度脱水」的同一条逻辑。

## 三、厌食 → 积滞 → 疳证：一条三级台阶

这三证是同一件事的三个深度，教材把它拆成三节，正好逐级加深：

| 台阶 | 病证 | 核心 | 证型与方 |
|---|---|---|---|
| ① 不想吃 | 厌食 | 脾胃不和、纳运失健，**病在「欲」** | 脾失健运 → 不换金正气散（《太平惠民和剂局方》）；脾胃气虚 → 异功散（《小儿药证直诀》）；（教材同节另列脾胃阴虚） |
| ② 吃了不化 | 积滞 | 乳食停聚中脘、**气滞不行**，病在「化」 | 乳食内积 → 消乳丸（《证治准绳》）合保和丸；积滞化热 → 枳实导滞丸（《内外伤辨惑论》）；脾虚夹积 → 健脾丸（《证治准绳》） |
| ③ 化了也不长 | 疳证 | 脾胃受损、**气液耗伤**，病在「养」 | 疳气 → 资生健脾丸（《先醒斋医学广笔记》）；疳积 → 肥儿丸（《医宗金鉴》）；干疳 → 八珍汤（《正体类要》） |

### 疳证的三期与三个兼证

教材 7.6 把疳证按轻重分三期：**疳气（初期，形瘦但精神尚可）→ 疳积（中期，腹大肢瘦、毛发枯黄）→ 干疳（后期，极度消瘦、精神萎靡）**。疳证的古称把它抬得很高——「痧、痘、惊、疳」为儿科四大要证。

兼证三个，各有专方：

| 兼证 | 表现 | 方 |
|---|---|---|
| 眼疳 | 两目干涩、畏光、夜盲 | 石斛夜光丸（《原机启微》） |
| 口疳 | 口舌生疮、糜烂 | 泻心导赤散（《小儿药证直诀》）合知柏地黄丸（《医宗金鉴》） |
| 疳肿胀 | 下肢浮肿、按之凹陷 | 五苓散（《伤寒论》）合五皮饮（《中藏经》） |

## 四、口疮与鹅口疮：入口处的两种白

这两证位置相同、样子不同，判据就在「形态」：

| | 鹅口疮 | 口疮 |
|---|---|---|
| 形态 | **白屑**如鹅口、似雪片，可擦去（教材同节） | **溃疡**：淡黄或灰白小溃疡，周围红 |
| 疼痛 | 一般不剧 | 灼热疼痛、流涎拒食 |
| 证型与方 | 心脾积热 → 清热泻脾散（《医宗金鉴》）；虚火上浮 → 知柏地黄丸（加肉桂少量引火归元） | 风热乘脾 → 银翘散合凉膈散；心火上炎 → 泻心导赤散；虚火上浮 → 知柏地黄丸 |

「加肉桂少量引火归元」这一笔值得单独记住：**虚火上浮时用少量温热药把火引回去**，与实火直折是两条相反的思路。

## 五、呕吐与腹痛：气机的两个方向

| 病证 | 证型与方 |
|---|---|
| 呕吐 | 伤食 → 保和丸；胃热 → 黄连温胆汤（《六因条辨》）；脾胃虚寒 → 丁萸理中汤（《医宗金鉴》）；肝气犯胃 → 解肝煎（《景岳全书》） |
| 腹痛 | 腹部中寒 → 养脏散（《医宗金鉴》）；乳食积滞 → 保和丸合木香槟榔丸（《儒门事亲》）；胃肠热结 → 大承气汤（《伤寒论》）；气滞血瘀 → 少腹逐瘀汤（《医林改错》）；脾胃虚寒 → 小建中汤（《伤寒论》）合理中丸 |

腹痛一节有一条必须记住的边界（教材 7.8 同节口径）：**先排除急腹症**——腹痛剧烈、拒按、伴发热呕吐或腹部包块者，不在「脾系杂病」范围内处理。这与第 9 章（肠痈）是同一条防线。

## 六、便秘：四个方向，不是「都吃泻药」

| 证型 | 病机 | 方 |
|---|---|---|
| 食积便秘 | 乳食积滞、传导失常 | 枳实导滞丸（《内外伤辨惑论》） |
| 燥热便秘 | 肠燥津亏、燥热内结 | 麻子仁丸（《伤寒论》） |
| 气滞便秘 | 气机郁滞、传导无力 | 六磨汤（《证治准绳》） |
| 气虚便秘 | 气虚推动无力（便不干但难下） | 黄芪汤（《金匮翼》） |

最后一行是本节的要点：**气虚便秘的特点是「便不干硬、但努挣难下」**，用泻药会越泻越虚。教材把它单列一型，正是为了区分「干燥」与「无力」。

## 七、本章的一句话总纲

教材 5.2.2 的那六个字在本章兑现了三次：**「脾健不在补，贵在运」**。

- 厌食不先补，先运（不换金正气散化湿运脾）；
- 积滞不先补，先消（保和丸、消乳丸）；
- 疳证虽虚，也先运后补（资生健脾丸以运为主，干疳才用八珍汤峻补）。

这条顺序解释了本章为何 9 个病证里有 7 个的首选方都是「运」与「消」而不是「补」——**儿科最常见的错误是见纳差就补**，本章几乎每一节都在纠这个错。

## 代价与边界

1. **本章方名与证型只作对账**，不含剂量与加减；儿童剂量须按年龄体重折算并由医师确定（第 6 章 §七 有教材的折算比例，仅作核对）。
2. **泄泻的两个变证是急症**：气阴两伤（前囟凹陷、尿少、皮肤干燥）与阴竭阳脱（四肢厥冷、脉微欲绝）须立即就医并补液，不在家庭调理范围。
3. **腹痛先排急腹症**：剧痛拒按、发热呕吐、腹部包块 → 转诊，不做「脾虚腹痛」的解释。
4. **疳证是慢性营养障碍**，教材把它与喂养不当、慢性疾病并列；本书不给食谱与营养素剂量。
5. **引书 36 部 99 次不等于读了 36 部**：密度高是因为每格证型都要落到具体方书。

本章为教学整理与文献梳理，**免责声明：** 不构成诊疗建议，不能替代医师面诊；儿童用药、补液与急症处置须由具备资质的医师执行。
