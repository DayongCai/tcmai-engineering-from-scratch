# 四句话对账：一条生理特点 → 一条临床推论

## 用途

教材把儿科特点压成四句话。背下来没用，能用才有用。本单要求每句话必须配一条**床边可验证**的推论，并指出它在哪一章被具体化。

## 对账表

| 特点 | 它解释的临床现象 | 它约束的用药/照护 | 具体化在哪章 |
|---|---|---|---|
| 脏腑娇嫩，形气未充（稚阴稚阳） | 感邪易伤津、正气易溃；易虚易实、易寒易热 | 清热勿过苦寒、温补勿过辛燥；剂量宜轻、中病即止；浓煎少量频服 | 5.2.1 用药特点 |
| 生机蓬勃，发育迅速（纯阳） | 感邪后易化热化火，热病最多 | 「纯阳」非盛阳：不可据此攻下 | 5.1.2 卫气营血 |
| 发病容易，传变迅速 | 肺脾肾三脏不足：外邪首犯肺、乳食即伤脾、肾虚则生长迟 | 治未传：卫分即顾气分 | 6–9 章各系病证 |
| 脏器清灵，易趋康复 | 药力直达、见效快 | 前提是「确得其本」：辨证一错，打偏也快 | 每章「辨证论治」 |

## 三个必查的常数（读完这四条要能顺手对上）

1. 前囟：1.5–2 cm，12–18 月闭；**凹陷＝脱水，饱满＝颅压增高**；
2. 收缩压 ≈ 80＋年龄×2；舒张压 ≈ 收缩压的 2/3；
3. 脉率：新生儿 120–140 → 学龄期 70–90（「脉数」先对年龄）。

## 输出格式

```text
年龄/月龄：…
当前偏离：<哪一项、偏离多少、趋势>
受哪一脏不足影响：肺/脾/心肝/肾（附依据）
预判传变方向：<母子相传 / 乘侮 / 脏腑同病>
该做的动作：<观察 / 指导 / 转诊>
```

## 边界

只做特点与现象的对应与传变预判，不给诊断与方药；常数以教材为准，不替代生长曲线评估。
