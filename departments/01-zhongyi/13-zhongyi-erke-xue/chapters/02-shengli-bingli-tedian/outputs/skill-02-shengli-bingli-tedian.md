# 四句话对账 · 可装载技能

## 何时装载

- 拿到一个儿科病例，需要判断「这个年龄该看哪一层」；
- 需要预判传变方向（会不会从肺传到脾、从气传到营）；
- 教学场景：把特点背成推论。

## 四句话 → 四条推论

| 特点 | 推论 |
|---|---|
| 脏腑娇嫩，形气未充 | 易伤津、易正溃 → 清热勿过苦寒、温补勿过辛燥、中病即止 |
| 生机蓬勃，发育迅速 | 化热快 → 但「纯阳非盛阳」，不可攻下 |
| 发病容易，传变迅速 | 肺脾肾三脏不足 → 治未传（卫分顾气分、肺病顾脾） |
| 脏器清灵，易趋康复 | 见效快，但前提是「确得其本」 |

## 三个常数（必查）

前囟 1.5–2 cm、12–18 月闭（凹陷＝脱水／饱满＝颅压高）；收缩压≈80＋年龄×2；脉率先对年龄（新生儿 120–140 → 学龄 70–90）。

## 传变预判

母子相传（培土生金／子盗母气）· 乘侮（肝木乘脾＝抑木扶土；木火刑金）· 脏腑同病（心肝同病）。

## 硬规则

1. 常数以教材为准，不自行换算。
2. 预判只给方向，不给方药。
3. 出现第 4 章红线（囟填、颈强、脉微欲绝）时停止预判，直接转诊。

## 边界

本技能做特点对应与传变预判，不产诊断。教材依据：第 2 章 2.1–2.4。
