# 急症三步 + 数字化三问

## 用途

儿科急症只有一件事要做对：**在几分钟内判断「能不能等」**。本单把它拆成三步（危重征象 → 转运条件 → 到院交什么），再追加三问，把这条判据写成可计算、可复核的字段——这是本章「急症 + 数字化」两个主题的接缝处。

## 一、急症三步（先救命）

### 第一步：有没有危重征象

| 病类 | 危重征象 |
|---|---|
| 高热惊厥 | 持续 >5 分钟／24h 内反复／局灶性／年龄 <6 月或 >5 岁／发作后瘫痪·颈强·喷射性呕吐／意识障碍·面色青灰·呼吸节律异常 |
| 哮喘持续 | 三凹征、端坐呼吸、说话断续、发绀、心率显著增快、**哮鸣音突然减弱或消失** |
| 重度脱水 | 前囟与目眶凹陷、皮肤弹性差、尿少、精神萎靡、四肢厥冷 |
| 急性中毒/意外 | 明确接触史＋意识或呼吸改变 |

### 第二步：转运条件

保持呼吸道通畅、防窒息、防误吸；抽搐者侧卧、清除口鼻分泌物；不强行按压肢体；记录发作时间与用药。

### 第三步：到院交什么

起病时间线、发作次数与每次时长、发热与用药史、进食与尿量、既往史与接种史、已做处理。

## 二、数字化三问（把判据变成可算）

1. **能不能写成字段**：形态→枚举＋参照图（面赤/面青/面黄/面白）；触觉→二分＋操作说明（前囟凹陷/饱满）；数量→数值＋单位；主观→原文＋标签。
2. **对齐哪个编码**：病名与证候名相区分（泄泻 vs 湿热泻），对齐 ICD-11 TM1 与 GB/T 16751.2。
3. **谁复核**：急症、隐私、外治操作三类必须人工即时复核；所有输出带「教学整理·不构成诊疗建议」。

## 输出格式

```text
危重征象：<无 / 命中第 N 类>
转运要点：…
到院信息：…
字段化建议：<可字段项 / 保留原文项>
复核：<谁＋边界>
```
