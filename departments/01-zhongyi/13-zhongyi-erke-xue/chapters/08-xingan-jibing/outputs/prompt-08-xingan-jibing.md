# 神风四问：先定时间尺度，再辨虚实

## 用途

心肝系的六个病证共处「神—风」轴，但处理路径由**时间尺度**决定：秒（惊厥）、夜（夜啼）、年（多动/抽动）。本单四问把这条轴走完，并单列红线。

## 第一问：落在神还是风

| 表现 | 轴位 |
|---|---|
| 啼哭、烦躁、惊惕、汗出、神思涣散 | **神（心）** |
| 抽搐、抽动、震颤、项强、目窜 | **风（肝）** |
| 皮肤瘀点瘀斑（压之不褪色） | **血（心主血）** |

## 第二问：时间尺度（决定路径）

| 尺度 | 病证方向 | 处理基调 |
|---|---|---|
| 秒—分 | 惊风（急惊/慢惊） | 急诊优先，查病因 |
| 每夜、白日如常 | 夜啼 | 调护＋分型 |
| 安静时/寐中 | 汗证 | 先排除生理性 |
| 数日—数周 | 紫癜 | 辨虚实，查内脏受累 |
| 年（持续、随情绪波动） | 多动障碍 / 抽动障碍 | 调治为主，专科评估 |

## 第三问：虚实寒热

- 惊风：急惊属实热（起病急、抽搐有力、高热神昏）；慢惊属虚寒（起病缓、抽搐无力、形神疲惫）。
- 汗证：肺卫不固/营卫失调/气阴两虚（虚）vs 脾胃湿热（实）。
- 紫癜：风热伤络、血热妄行（实）vs 气不摄血、阴虚火旺（虚）。
- 多动/抽动：肝肾阴虚、心脾两虚、脾虚痰聚（虚）vs 痰火内扰、肝亢风动（实）。

## 第四问：红线

1. 惊厥 >5 分钟、反复发作、间歇期意识不清、瞳孔不等大 → 立即急诊，途中保气道；
2. 紫癜伴剧烈腹痛、黑便、尿血、头痛呕吐 → 立即就医；
3. 婴幼儿用含朱砂成药（硫化汞）→ 不用，或以磁石、珍珠母代；
4. 白天也闹、全身情况差的「夜啼」→ 不是夜啼，另查。

## 输出格式

```text
轴位：神/风/血
时间尺度：秒/夜/年
虚实寒热：…
证型与代表方（不含剂量）：…
红线：<无 / 命中第 N 条>
```
