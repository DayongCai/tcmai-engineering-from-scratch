# 第 8 章 · 心肝系疾病：一条「神—风」轴，两种时间尺度

> **MOTTO:** 「急惊合凉泻，慢惊合温补」——教材·第8章·8.6.1（《小儿药证直诀》）
>
> **PROBLEM:** 六个病证分成两组，但学生看不出分组依据：夜啼、汗证、紫癜、多动、抽动、惊风。其实它们共处一条轴——**神（心）与风（肝）**，而这两者在儿科的特点都是「有余」：心常有余故易惊、易啼、易躁；肝常有余故易动、易抽。真正难的是**时间尺度**：同一组症状，几秒钟的抽（惊厥）与几年的动（抽动障碍）是完全不同的处理路径。
>
> **双根因定位:** 环境逼迫（家长描述的「抽了一下」可能是高热惊厥、癫痫、低钙、抽动障碍，四者处理完全不同）+ 知识积累（本章 30 单元、25,051 字，**证候表现 315、心肝系 507** 双居首位；引书 33 部 55 次——神经精神类病证的古籍用语最杂，须逐条对）

**教材出处:** 教材·第 8 章（8.1 夜啼、8.2 汗证、8.3 紫癜、8.4 注意力缺陷多动障碍、8.5 抽动障碍、8.6 惊风，共 6 病证 30 单元）。本章数字由 `code/main.js` 读 `standards/erke/units.json` 现算。

## 一、六个病证的两个坐标

| 病证 | 主在何脏 | 时间尺度 | 一句话判据 |
|---|---|---|---|
| 夜啼 | 心（兼脾、惊） | 每夜定时、白日如常 | **入夜哭、白天好**，多见于 6 个月内 |
| 汗证 | 心（汗为心液） | 安静时／寐中 | 安静状态汗出过多、湿透衣被，伴神疲面黄 |
| 紫癜 | 心（主血） | 数日至数周 | **瘀点瘀斑、压之不褪色**，常伴鼻衄齿衄 |
| 多动障碍 | 心肝（兼脾肾） | 年 | 注意力不集中＋活动过多＋冲动任性 |
| 抽动障碍 | 肝 | 年 | 不自主、反复、快速、刻板的抽动或发声 |
| 惊风 | 肝（心包） | **秒—分** | 抽搐＋神昏；分急惊（实热）与慢惊（虚寒） |

用这张表可以把家长的描述归类：**「抽了一下」→ 先问持续多久**（秒级＝惊风范畴，年级＝抽动障碍）。

## 二、夜啼：三种夜，三种治法

教材 8.1 把《诸病源候论》「小儿夜啼者，脏冷故也」作为源头，但今天的分型已扩为三：

| 证型 | 特点 | 代表方 |
|---|---|---|
| 脾寒气滞 | 哭声低弱、曲腰、腹喜温按、四肢欠温 | 匀气散（《医宗金鉴》） |
| 心经积热 | 哭声洪亮、烦躁、面赤、舌尖红 | 导赤散（《小儿药证直诀》） |
| 惊恐伤神 | 猝然惊啼、面色青、惊惕不安 | 朱砂安神丸（《内外伤辨惑论》） |

关键在**「白日如常」**这一条：白天也闹、全身情况差的，不属夜啼，要考虑其他疾病。

## 三、汗证：先分生理与病理，再辨四型

教材 8.2 先划界：小儿新陈代谢旺盛，**活动后或入睡初时头颈微汗属生理**；只有在**安静时或寐中汗出过多、湿透衣被**，并伴精神疲倦、面色萎黄等，才是病证。这一条能挡掉大量「家长觉得孩子出汗多」的焦虑。

四型与方：

| 证型 | 特点 | 代表方 |
|---|---|---|
| 肺卫不固 | 自汗为主、易感冒、面色少华 | 玉屏风散（《丹溪心法》）合牡蛎散（《太平惠民和剂局方》） |
| 营卫失调 | 汗出畏风、遍身湿润、时寒时热 | 黄芪桂枝五物汤（《金匮要略》） |
| 气阴两虚 | 盗汗为主、心烦、手足心热 | 生脉散（《医学启源》） |
| 脾胃湿热 | 汗出黏腻、口臭、苔黄腻 | 泻黄散（《小儿药证直诀》） |

最后一型容易被漏：**汗黏、有味、苔腻**是湿热，用固表止汗会越治越闷。

## 四、紫癜：压之不褪色是它的门

教材 8.3 的判别核心是一个动作：**压之不褪色**（血液溢于皮肤黏膜之下，而非充血）。病因分两类：外感风热与血热妄行（实），气不摄血与阴虚火旺（虚）。

| 证型 | 特点 | 代表方 |
|---|---|---|
| 风热伤络 | 起病急、紫癜鲜红、伴发热咽红 | 银翘散（《温病条辨》） |
| 血热妄行 | 紫癜密集色深、鼻衄齿衄、舌红绛 | 犀角地黄汤（《备急千金要方》） |
| 气不摄血 | 反复发作、色淡、面黄神疲、纳差 | 归脾汤（《济生方》） |
| 阴虚火旺 | 紫癜时发时止、五心烦热、舌红少苔 | 大补阴丸（《丹溪心法》）合知柏地黄丸（《医宗金鉴》） |

红线（教材同节口径）：**紫癜伴剧烈腹痛、黑便、尿血、头痛呕吐**——提示内脏受累，须立即就医；本章不给处理方案。

## 五、多动与抽动：两个「年」级病证，辨的是同一条阴阳轴

### 多动障碍（8.4）

教材引《素问·阴阳应象大论》「阴静阳躁」立病机：**阴阳失调、动静失制**。

| 证型 | 特点 | 代表方 |
|---|---|---|
| 肝肾阴虚 | 多动难静、急躁、五心烦热、舌红少苔 | 杞菊地黄丸（《医级》） |
| 心脾两虚 | 神思涣散、多动而不暴躁、纳差面黄 | 归脾汤合甘麦大枣汤（《金匮要略》） |
| 痰火内扰 | 烦躁多动、胸闷、苔黄腻 | 黄连温胆汤（《六因条辨》） |

### 抽动障碍（8.5）

教材引《素问·至真要大论》「诸风掉眩，皆属于肝」立病机：**肝风内动**，兼痰、兼虚。

| 证型 | 特点 | 代表方 |
|---|---|---|
| 肝亢风动 | 抽动频繁有力、烦躁易怒、脉弦 | 天麻钩藤饮（《杂病证治新义》） |
| 痰火扰神 | 抽动伴喉中发声、秽语、苔黄腻 | 黄连温胆汤 |
| 脾虚痰聚 | 抽动无力、时轻时重、纳差面黄 | 六君子汤（《医学正传》）合涤痰汤（《奇效良方》） |
| 阴虚风动 | 抽动日久、形体消瘦、舌红少苔 | 大定风珠（《温病条辨》） |

两病的共同点：**病程以年计、症状随情绪与疲劳波动、治疗靠「调」不靠「镇」**。这与惊风形成鲜明对照。

## 六、惊风：全章的急症入口

### 急与慢的分界（教材 8.6.1 引钱乙）

> 「急惊合凉泻，慢惊合温补」——《小儿药证直诀》

| | 急惊风 | 慢惊风 |
|---|---|---|
| 起病 | 急暴 | 缓慢 |
| 抽搐 | 有力、频繁 | 无力、时抽时止 |
| 神志 | 高热神昏 | 形神疲惫 |
| 性质 | 属实属热 | 属虚属寒 |
| 治则 | 凉泻（清热、豁痰、镇惊、息风） | 温补（温运脾阳、温补脾肾、育阴潜阳） |

### 惊风八候（教材给的八个字，用来判断病势）

| 字 | 表现 |
|---|---|
| 搐 | 肘臂伸缩 |
| 搦 | 十指开合 |
| 掣 | 肩头相扑 |
| 颤 | 手足动摇 |
| 反 | 身仰向后 |
| 引 | 手若开弓 |
| 窜 | 目直似怒 |
| 视 | 睛露不活 |

### 证型与方

| 分期 | 证型 | 代表方 |
|---|---|---|
| 急惊 | 风热动风（高热惊厥初起，冬春多见） | 银翘散 |
| | 气营两燔 | 清瘟败毒饮（《疫疹一得》） |
| | 湿热疫毒（夏秋、中毒性痢疾类） | 黄连解毒汤合白头翁汤（《伤寒论》） |
| | 惊恐惊风（骤闻异声、跌仆惊吓） | 琥珀抱龙丸（《活幼心书》）——**方中朱砂含硫化汞，婴幼儿慎用，常去之或以磁石、珍珠母代** |
| 慢惊 | 脾虚肝亢 | 缓肝理脾汤（《医宗金鉴》） |
| | 脾肾阳衰 | 固真汤（《活幼心书》） |
| | 阴虚风动 | 大定风珠（《温病条辨》） |

### 危候与操作（本章最该背的一段）

教材 8.6.3 写得很具体：

1. **惊厥持续超过 5 分钟仍不缓解**，或反复发作、**间歇期意识不清**；
2. 伴**高热持续不退、剧烈呕吐、呼吸节律不整、瞳孔不等大** → 提示惊厥持续状态或颅内病变；
3. 处理：**立即转诊急诊，转运途中保持呼吸道通畅，防止窒息**；
4. 发作期可**急刺人中、合谷、十宣**以开窍止痉，配合降温止痉；内服煎剂难以喂服时可**鼻饲、针剂或灌肠**给药；
5. **任何惊厥发作均须积极查找病因**（颅内感染、电解质紊乱等），缓解后系统检查。

「任何惊厥都要查病因」这一句，是本章与「抽动障碍」最根本的分界：前者是症状，必须找原因；后者是慢病，重在调理。

## 七、本章的剂量与用药警示

教材在本章提到两处必须留痕的警示：

1. **朱砂（含硫化汞）婴幼儿慎用**——琥珀抱龙丸常去朱砂或以磁石、珍珠母代之；
2. **惊风用药须中病即止，温热与寒凉之品均不可过剂**，以免损伤阴阳。

## 代价与边界

1. **本章多为神经精神类病证**，教材的辨证分型用于方向判断；抽动障碍与多动障碍的诊断须由专科完成，本书不给量表与药物方案。
2. **惊风是急症入口**：惊厥 >5 分钟、反复发作、间歇期意识不清、瞳孔不等大 → 立即急诊，本章只给识别与转运要点。
3. **紫癜须辨内脏受累**：腹痛、黑便、尿血、头痛呕吐 → 就医，不在本章处理。
4. **汗证先排除生理性出汗**，否则会把正常孩子治成病人。
5. **含汞、含重金属的成药（朱砂等）不用于婴幼儿**，教材已明示，本书照录。

本章为教学整理与文献梳理，**免责声明：** 不构成诊疗建议，不能替代医师面诊；惊厥、紫癜与神经精神类疾病须由具备资质的医师诊治。
