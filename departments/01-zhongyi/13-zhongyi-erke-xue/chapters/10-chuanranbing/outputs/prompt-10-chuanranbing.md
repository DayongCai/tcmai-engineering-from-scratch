# 出疹四问：把八证压到一张时间表

## 用途

八个时行病的第一句话都是「发热、出疹」。本单不问病名，只问四件事，四问下来病名自现。

## 第一问：发热第几天出疹

| 关系 | 指向 |
|---|---|
| 发热 3–4 天后出疹，**疹出热更高** | 麻疹 |
| 发热 1–2 天出疹，疹轻热轻 | 风疹 |
| **热退疹出** | 幼儿急疹 |
| 发热 1–2 天出疹，**疹出热不退** | 丹痧 |
| 发热同时或稍后出疹，**疱疹分批** | 水痘 |

## 第二问：疹从哪儿起、往哪儿走

- 麻疹：耳后发际→面颈→躯干→四肢（按序）；
- 水痘：躯干多、四肢少（**向心性**）；
- 手足口：手、足、口腔、臀部；
- 风疹：面颈→躯干四肢，一日出齐。

## 第三问：特殊体征（一票判据）

| 体征 | 病 |
|---|---|
| 口腔麻疹黏膜斑、目赤畏光 | 麻疹 |
| 耳后、枕后淋巴结肿大 | 风疹 |
| 一般情况好而高热 | 幼儿急疹 |
| 咽喉肿痛糜烂、疹后大片脱屑 | 丹痧 |
| 同一部位斑疹＋丘疹＋疱疹＋结痂 | 水痘 |
| 以耳垂为中心的腮部漫肿 | 痄腮 |
| 阵发性痉咳＋鸡鸣样回声 | 顿咳 |

## 第四问：退疹后留什么

色素沉着＋糠麸样脱屑（麻疹）；无痕迹（风疹、幼儿急疹）；大片脱屑无色素沉着（丹痧）；不留瘢痕（水痘）。

## 附加两条（比辨证更硬）

1. **隔离与报告**：按各病规定期限隔离；手足口病等属法定报告传染病。
2. **重症红线**：手足口持续高热、精神差、肢体抖动、呼吸心率增快；麻疹疹出不透＋气促鼻煽；痄腮头痛呕吐抽搐或睾丸肿痛；顿咳小婴儿窒息。

## 输出格式

```text
热疹关系：…
分布：…
特殊体征：…
退疹后：…
病证候选：…
隔离/报告：…
红线：<无 / 命中>
```
