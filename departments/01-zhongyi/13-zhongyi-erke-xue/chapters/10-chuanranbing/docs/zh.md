# 第 10 章 · 传染病：一张「发热—出疹」时间表

> **MOTTO:** 「麻为阳毒，以透为顺」——教材·第10章·10.1.1（《麻科活人全书》）
>
> **PROBLEM:** 八个时行病的第一句话几乎都是「发热、出疹」。学生记不住谁是谁，是因为按病名背；教材的判据其实排在一张**时间表**上：发热第几天出疹、疹从哪儿起、退疹后留下什么。谁把这张表画出来，谁就不会混。
>
> **双根因定位:** 环境逼迫（同一季节、同一托幼机构里同时流行数种出疹病；隔离与报告要求各不同）+ 知识积累（本章 40 单元、29,002 字，**证候表现 400** 居三辨首位、肺系 291 居四位面首位；**数值 187 处，全课程最高**——潜伏期、隔离期、接种月龄都写成了可核的数）

## 一、四疹鉴别表（本章第一张该背的表）

| | 麻疹 | 风疹 | 幼儿急疹 | 丹痧 |
|---|---|---|---|---|
| 好发年龄 | 6 个月–5 岁 | 5 岁以下 | **6–18 个月**（1 岁内最多） | 学龄前与学龄期 |
| 发热与出疹的关系 | 发热 3–4 天后出疹，**疹出热更高** | 发热 1–2 天出疹，疹轻热轻 | **热退疹出**（高热 3–5 天，退热时出疹） | 发热 1–2 天出疹，**疹出热不退** |
| 皮疹形态 | 红色斑丘疹，**按序布发**（耳后发际→面颈→躯干→四肢） | 淡红色斑丘疹，细小如沙 | 玫瑰色细小斑丘疹，一日出齐 | 鲜红色，弥漫细密，**压之褪色** |
| 特殊体征 | **口腔麻疹黏膜斑**、目赤畏光、流泪 | **耳后、枕后淋巴结肿大** | 一般情况好（高热而精神尚可） | **咽喉肿痛糜烂**、杨梅舌类表现、疹后脱屑 |
| 退疹后 | 色素沉着＋糠麸样脱屑 | 无色素沉着、无脱屑 | 无 | **脱屑明显**（大片状），无色素沉着 |
| 教材的一句话 | 「麻为阳毒，以透为顺」 | 「一日出齐，三日退净」 | 又称奶麻、假麻 | 又称烂喉痧 |

这张表有四列可用一句话记住：**麻疹是「先热后疹、疹出更热」，风疹是「疹轻热轻」，幼儿急疹是「热退疹出」，丹痧是「咽烂疹密」**。

## 二、麻疹：三期的任务是「透」

教材 10.1 把麻疹分三期，每期一个治法方向：

| 期 | 表现 | 治法与方 |
|---|---|---|
| 疹前期（初热期） | 发热、咳嗽、流涕、目赤畏光、**麻疹黏膜斑** | 辛凉透表 → 宣毒发表汤（《医宗金鉴》） |
| 出疹期 | 按序布疹、疹色红活 | 清热解毒、**透疹达邪** → 清解透表汤（经验方） |
| 疹回期（恢复期） | 疹退、脱屑、色素沉着、阴伤 | 养阴生津 → 沙参麦冬汤（《温病条辨》） |

**逆证（邪毒闭肺）**：疹出不透、高热咳喘、鼻煽 → 麻杏石甘汤合葶苈大枣泻肺汤。这是麻疹最危险的一格，本质是「透不出来，邪往里闭」。

教材把「以透为顺」放在最前面，因此有一条用药禁忌贯穿全章：**疹未透时忌早用苦寒冰伏**（与第 5 章「透邪外达」是同一条原则）。

## 三、风疹与幼儿急疹：两个「轻」病，各有其重

- **风疹**（10.2）：疹细小、出没快（「一日出齐，三日退净」），伴**耳后枕后淋巴结肿大**。它的严重性不在患儿，而在**孕妇**——妊娠早期感染可致先天性风疹综合征（流产、死胎、多发畸形）。教材明确写进概述，这是本章最重要的一条公共卫生提示。
- **幼儿急疹**（10.3）：**突然高热 3–5 天，热退疹出**；高热虽甚但精神尚可。方用银翘散，重证用清瘟败毒饮。它的辨识价值在于**「热退疹出」四个字可以省掉大量不必要的抗生素**。

## 四、水痘与手足口：两套疱疹的分布学

| | 水痘 | 手足口病 |
|---|---|---|
| 形态 | 斑丘疹→疱疹→结痂**分批出现**，皮薄如水泡、疱液清亮 | 斑丘疹、疱疹，口腔疱疹破后成溃疡 |
| 分布 | **向心性**（躯干多、四肢少） | **手、足、口腔、臀部** |
| 好发 | 6 个月–3 岁，托幼易流行 | 学龄前，**3 岁以下最多**，夏秋多见 |
| 方 | 银翘散合六一散；重证清胃解毒汤 | 甘露消毒丹（《温热经纬》）；重证清瘟败毒饮 |
| 风险 | 一般预后好、不留瘢痕；新生儿、免疫缺陷者重 | **少数重症可并发脑炎、脑膜炎、神经源性肺水肿、循环衰竭**（2008 年 5 月起纳入法定丙类传染病） |

「四世同堂」这四个字在水痘这一节有具体所指：**同一部位同时可见斑疹、丘疹、疱疹、结痂**——这是水痘最可靠的一眼判据。

## 五、痄腮与顿咳：两个「以特征命名」的病

### 痄腮（10.5）

教材引《外科正宗·痄腮》：

> 「痄腮乃风热湿痰所生，有冬温后天时不正，感发传染者，多两腮肿痛，初发寒热」——《外科正宗·痄腮》

判据是**以耳垂为中心的腮部漫肿**（不是颌下淋巴结）。证型与方：邪犯少阳 → 柴胡葛根汤（《外科正宗》）；热毒壅盛 → 普济消毒饮（《东垣试效方》）；**毒窜睾腹**（睾丸肿痛或腹痛）→ 龙胆泻肝汤；**邪陷心肝**（头痛呕吐、抽搐）→ 清瘟败毒饮合羚角钩藤汤。

后两型就是它的两个并发症：**睾丸炎**与**脑膜脑炎**。

### 顿咳（10.7）

判据三件：**阵发性痉挛性咳嗽**、**咳后鸡鸣样吸气性吼声**、**病程 2–3 个月**（故名百日咳）。教材引《素问·咳论》两句立病机：「五脏六腑皆令人咳，非独肺也」与「聚于胃，关于肺」——后者解释了痉咳时**呕吐与痰浊**的关系。

证型与方：初咳期 → 三拗汤加味；痉咳期 → 桑白皮汤合葶苈大枣泻肺汤；恢复期 → 人参五味子汤（《幼幼集成》）／沙参麦冬汤。

## 六、丹痧：唯一「咽部先出问题」的出疹病

教材 10.8 的临床特征是四件：**发热、咽喉肿痛糜烂、全身鲜红色皮疹、疹后脱屑**。它引《金匮要略》「阳毒之为病，面赤斑斑如锦文，咽喉痛，唾脓血」为源，清代陈耕道《疫痧草》为专著。

| 期 | 方 |
|---|---|
| 邪侵肺卫（初起） | 解肌透痧汤（《喉痧症治概要》） |
| 毒炽气营 | 凉营清气汤（《喉痧症治概要》） |
| 疹后阴伤 | 沙参麦冬汤 |

与麻疹的分界很清楚：**丹痧从咽开始（咽痛糜烂），麻疹从眼鼻开始（目赤畏光、流涕）**。

## 七、本章的共同骨架：隔离、报告、接种

教材每一节都写了三件事，它们不出现在辨证里，但决定疾病会不会传下去：

1. **隔离**：呼吸道隔离至规定期限（各病不同，教材各节分列）；
2. **报告**：手足口病等属法定报告传染病，须按传染病管理要求报告；
3. **接种**：麻疹、风疹（麻腮风）、乙脑、流脑等有免疫规划疫苗（第 3 章 3.3.1 的程序表）——第 3 章那张表解释了本章「为什么现在少见」。

## 代价与边界

1. **本章的辨证用于识别与分期方向**，抗病毒、抗感染、补液、隔离期限均须按现行传染病管理规范执行。
2. **四疹鉴别表是筛查工具**：不典型病例须实验室确诊（抗体、核酸），不得仅凭皮疹定诊。
3. **手足口病重症信号优先**：持续高热、精神差、肢体抖动、呼吸心率增快 → 立即就医（可并发神经源性肺水肿）。
4. **痄腮的睾丸炎与脑膜脑炎是并发症红线**；**麻疹的邪毒闭肺是危候**；**顿咳在小婴儿可致窒息**。
5. **风疹的重点人群是孕妇**：育龄期与妊娠早期筛查的意义大于治疗。

本章为教学整理与文献梳理，**免责声明：** 不构成诊疗建议，不能替代医师面诊；传染病须按法规报告与隔离，疫苗接种须按当地接种门诊程序执行。
