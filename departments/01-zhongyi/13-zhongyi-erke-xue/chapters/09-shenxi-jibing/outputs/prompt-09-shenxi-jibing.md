# 水尿长三问：先归类，再对界值

## 用途

肾系六证分三件事：水、尿、长。本单先归类，再对界值（3 岁、8/9 岁、月龄里程碑），最后看四个危象指标。

## 第一问：是哪一类

| 主诉 | 类别 | 病证方向 |
|---|---|---|
| 眼睑/下肢浮肿、尿少、血尿、泡沫尿 | 水 | 急性肾炎（水肿）/ 肾病综合征 |
| 小便次数多、急迫 | 尿·频 | 尿频 |
| 睡中遗尿、醒后方觉 | 尿·遗 | 遗尿（须 ≥3 岁） |
| 立行齿发语迟 / 头项口手足肌肉软 | 长·迟 | 五迟五软 |
| 女 <8 岁、男 <9 岁出现第二性征 | 长·早 | 性早熟 |

## 第二问：分段或界值

- 水肿分段：肺（起于眼睑、上半身）→ 脾（四肢、腹）→ 肾（下肢、全身伴尿少）；
- 遗尿界值：**3 岁**；
- 性早熟界值：**女 8 岁 / 男 9 岁**；
- 五迟五软：对第 3 章里程碑表（大运动、精细、语言）。

## 第三问：四个危象指标（每次都要看）

| 指标 | 危险信号 |
|---|---|
| 血压 | 显著升高＋头痛呕吐 → 邪陷心肝（高血压脑病） |
| 尿量 | 明显减少甚至无尿 → 水毒内闭（急性肾损伤） |
| 呼吸 | 气促、端坐、粉红色泡沫痰 → 水凌心肺（心衰/肺水肿） |
| 神志 | 嗜睡、抽搐、意识不清 → 急诊 |

## 第四问：证型与方向（不含剂量）

- 肾炎：风水相搏（麻黄连翘赤小豆汤）／湿热内侵（五味消毒饮合五苓散）／脾虚湿困（参苓白术散合玉屏风散）＋三危象；
- 肾病：肺脾气虚／脾虚湿困／脾肾阳虚／肝肾阴虚／气阴两虚（后两型常对应激素阶段）；
- 尿频：湿热下注（八正散）／脾肾气虚（缩泉丸合参苓白术散）；
- 遗尿：肾气不足（菟丝子散）／肺脾气虚（补中益气汤合缩泉丸）／肝经湿热（龙胆泻肝汤）／心肾失交（交泰丸合导赤散）；
- 五迟五软：肝肾亏损／心脾两虚／痰瘀阻滞；
- 性早熟：阴虚火旺（知柏地黄丸）／肝郁化火（丹栀逍遥散）。

## 输出格式

```text
类别：水/尿频/尿遗/长迟/长早
分段或界值：…
证型与代表方（不含剂量）：…
危象四看：血压…／尿量…／呼吸…／神志…
```
