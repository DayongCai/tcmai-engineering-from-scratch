# 第 4 章 · 儿科四诊概要：脉靠不住的时候，看什么

> **MOTTO:** 「脉既难凭，必资外证」——教材·第4章·4.1.1（《小儿药证直诀·原序》）
>
> **PROBLEM:** 儿科的就诊现场是这样的：孩子哭、家长急、脉按不住、问诊得到的是转述。教材把这条路一眼说穿——「脉既难凭，必资外证」。于是问题变成：**外证里哪些能在三分钟内看清、且能分辨？** 这不是「望诊更重要」的态度问题，而是一套按可靠性排序的操作顺序。
>
> **双根因定位:** 环境逼迫（信息源是「家长的记忆＋孩子的表现」，两者都不稳定）+ 知识积累（本章 5 单元、8,365 字，三辨重心在**证候表现 151**——全章都在写「看见什么算什么」；引书 14 部 20 次，几乎每条判据都有出处）

**教材出处:** 教材·第 4 章（4.1 望诊、4.2 闻问切诊，共 2 节 5 单元）。本章数字由 `code/main.js` 读 `standards/erke/units.json` 现算。

## 一、为什么是望诊：三句原话

教材 4.1.1 用三句经典把「望诊为首」立住：

1. **「脉既难凭，必资外证」**——《小儿药证直诀·原序》。理由是小儿寸口短小、就诊啼哭躁动；
2. **「望而知之谓之神，闻而知之谓之圣，问而知之谓之工，切脉而知之谓之巧」**——《难经·六十一难》。这句话在成人科是排序，在儿科是**现实约束**；
3. 教材同时给了望诊的六项清单：**望神色、望形态、审苗窍、辨斑疹、察二便、看指纹**，其中**望神色居首**。

## 二、望神色与望形态

- **望神**：观察精神意识、目光眼神、表情动态与反应灵敏程度。**两目有神、精神振作、表情自然、反应灵敏、哭声洪亮**为「得神」；反之（教材同节续列）为失神之象。
- **望形态**：形体强弱、胖瘦、姿态动静。教材把「囟填／囟陷」「颈项强直」这类体态异常放在按诊里讲（4.2.2），说明**望与按是连着用的**：看见异常要上手确认。

## 三、审苗窍：五脏开窍于面

> 「视其外应，以知其内脏，则知所病矣」——《灵枢·本脏》（教材 4.1.2 引）

苗窍指目、鼻、口、舌、耳。教材把「目」写得最细，并直引钱乙的目内证辨五脏：

> 「赤者，心热，导赤散主之。淡红者，心虚热，生犀散主之。青者，肝热，泻青丸主之。浅淡者补之。黄者，脾热，泻黄散主之。无精光者，肾虚，地黄丸主之」——《小儿药证直诀·目内证》

这段的价值在于**它是「一望定脏」的最短路径**：颜色→脏→方，三步到位。教材另给几条目诊要点：目赤多泪＝肝经风热；白睛红赤＝肺肝热盛；目胞浮肿＝风水相搏；**目睛斜视、窜视＝肝风内动**；**目珠凝视无神＝惊风先兆**；目眦红赤糜烂＝心火或湿热上炎。

## 四、察二便：一条被低估的判据

> 「魄门亦为五脏使，水谷不得久藏」——《素问·五脏别论》（教材 4.1.3 引）

教材给的大便判读表（原值要点）：

| 大便 | 指向 |
|---|---|
| 初生 24 小时内暗绿色黏稠（胎便） | 正常 |
| 母乳喂养：金黄色糊状、日行数次 | 正常 |
| 人工喂养：淡黄色、质较干硬 | 正常 |
| 干结如羊屎、数日一行 | 肠燥津亏或食积化热 |
| 稀溏、色淡不臭 | 脾虚不运（「脾健不在补，贵在运」） |
| 酸臭、夹不消化食物 | 伤食积滞 |
| 泡沫多、矢气频频 | 乳食停滞或感受风寒 |
| 色黄如蛋花汤样、水样多沫 | 湿热或风寒之泄泻 |
| **夹黏液脓血、里急后重** | 湿热痢疾，**须隔离并及早诊治** |
| **色黑如柏油样** | 胃肠出血（远血） |

最后两行是红线。教材还补了一条脱水警告：**量多、水样如米泔**须防重度脱水。

## 五、看指纹：儿科独有的一门「脉」

教材 4.1.3 把指纹诊法讲得最完整，值得逐条记住。

### 源流与适用范围

> 「指纹之法起于宋人钱仲阳，以食指分为三关：寅曰风关，卯曰气关，辰曰命关。其诀谓风轻、气重、命危」——《幼幼集成·指纹析义》

**适用 3 岁以内**，作为脉诊的补充（3 岁以上寸口可切，应以脉诊为主）。

### 操作（照做即可）

孩子面向光，家长抱坐；医者左手拇、食二指轻握其食指末端，右手拇指**自命关向风关**轻推数次使指纹显露，再察浮沉、色泽、淡滞与所达部位。**须在小儿安静时、自然光下进行**，用力推按过久或哭闹挣扎都会造成假象。

### 四条判据（本段是全章最该背下来的）

> 「但当以浮沉分表里，红紫辨寒热，淡滞定虚实」——《幼幼集成·指纹析义》

教材把它扩成四诀：

| 诀 | 观察 | 判读 |
|---|---|---|
| **浮沉分表里** | 推之易见／难显 | 浮＝病在表（外感初起）；沉＝病在里 |
| **红紫辨寒热** | 纹色 | 鲜红＝外感风寒；紫红＝里热炽盛；淡红＝虚寒；青紫＝惊风、疼痛或血瘀；深紫而滞＝热毒内闭 |
| **淡滞定虚实** | 粗细与流畅度 | 淡而细、推之流畅＝虚（气血不足）；暗而粗、推之滞涩＝实（痰食瘀热） |
| **三关测轻重** | 所达部位 | 仅风关＝初起轻浅；达气关＝较重；透命关＝危笃；**透关射甲（直透指端）＝危重**，警惕惊风、闭证 |

教材的三条安全条款：**不可单凭指纹断病**（体质、气温、手法都会影响）；**有假象须排除**；**青紫透关射指＋高热神昏抽搐＝惊风危候，应急转急诊**。

## 六、闻诊：哭声与咳声各有语法

教材 4.2.1 把「听」拆成可分辨的几类：

| 声音 | 判读 |
|---|---|
| 哭声洪亮、泪涕俱出，哺乳安睡即止 | 健康 |
| 哭声绵长、吮乳急切 | 饥饿 |
| 哭声尖锐、时作时止 | 疼痛或惊恐 |
| 哭声低微、呻吟断续、绵软无力 | 虚证、重证（疳证、久泻、正气衰败） |
| 哭声忽高忽低、烦躁不宁，夜间尤甚 | 夜啼（辨心经积热／脾寒腹痛／惊恐伤神） |
| **剧烈阵发性哭闹、屈腰蜷缩、面色苍白、呕吐** | **警惕肠套叠等急腹症，急诊** |
| 咳声轻扬、鼻塞流涕 | 外感 |

最后两行仍是红线：一句哭声能把「夜啼」和「急腹症」分开，这是闻诊最实用的一格。

## 七、问诊与切诊：十问歌 + 儿科的五个追加项

### 问诊

教材 4.2.2 先引十问歌：

> 「一问寒热二问汗，三问头身四问便，五问饮食六问胸，七聋八渴俱当辨，九问旧病十问因，再兼服药参机变」——《医学实在易·问证》

并引它的儿科版收尾：**「再添片语告儿科，天花麻疹全占验」**——这一句就是「麻疹类疾病必须问接种与接触史」的古文表述。

教材给的儿科追加项（这是本章和成人的分界）：**年龄与月龄**（年龄是问诊之首务，不同年龄病谱不同）、**喂养与乳食**、**睡眠**、**二便**、**预防接种**；问诊对象是家长、保育人员与较大儿童本人，**避免暗示性提问**。

### 切诊

- **一指定三关**：小儿寸口短小，以一指同时按察寸、关、尺；
- **先对年龄再看脉率**：新生儿 120–140、婴儿 110–130、幼儿 100–120、学龄前期 80–100、学龄期 70–90 次/分；
- **脉纲**：浮沉迟数＋有力无力（浮主表、沉主里、迟主寒、数主热、有力为实、无力为虚）；
- 钱乙的小儿脉法：

> 「脉乱不治，气不和弦急，伤食沉缓，虚惊促急，风浮，冷沉细」——《小儿药证直诀·小儿脉法》

最后一句古训「脉乱不治」值得单独记住：**脉象杂乱无章是危候**，不是「信息量大」。

### 按诊：从囟门到腹部

教材 4.2.2 的按诊清单里有四条急症线索：

| 按诊所见 | 提示 |
|---|---|
| 前囟饱满隆起、按之紧张（囟填） | 热盛或颅内压增高 |
| 前囟凹陷、按之柔软（囟陷） | 津液大伤 |
| 颈项强直、按之抵抗 | 惊风或脑系感染，**急诊** |
| 淋巴结肿大如串珠、质硬、推之不动 | 警惕结核或肿瘤，**转专科** |
| 腹部喜按为虚、拒按为实；右下腹固定压痛＋反跳痛 | 警惕肠痈 |
| 心悸胸闷、脉律不齐或脉微欲绝 | 警惕病毒性心肌炎，**急诊** |

## 代价与边界

1. **指纹与脉象都是「辅助判断」**，教材明令「不可单凭」；本章四条判据必须与神色、舌象、症状合参。
2. **操作会制造假象**：推按过久、哭闹、强光或昏暗环境都会改变色泽判断——这不是理论问题，是手法问题。
3. **本章不作诊断结论**：所有红线只给「转诊」方向，不给处理方案。
4. **十问歌是框架不是清单**：儿科的追加项（喂养、睡眠、二便、接种）比补齐十问更重要。

本章为教学整理与文献梳理，**免责声明：** 不构成诊疗建议，不能替代医师面诊；出现本章标红的任何一条，须立即就医。
