# 第 6 章 · 肺系疾病：一条由表入里的纵线，五个停靠点

> **MOTTO:** 「伤于风者，上先受之」——教材·第6章·6.1.1（《素问·太阴阳明论》）
>
> **PROBLEM:** 五个病证（感冒、咳嗽、肺炎喘嗽、哮喘、反复呼吸道感染）在门诊的第一句话几乎一样：「咳嗽、发热」。学生背得下五个定义，却分不清**什么时候它还是感冒、什么时候已经该按肺炎喘嗽处理**。教材把它们排在同一章并非按病名，而是按**肺气被闭的深度**排的。
>
> **双根因定位:** 环境逼迫（同一患儿 48 小时内可以从流涕进展到鼻煽——肺系的病程尺度以「天」计）+ 知识积累（本章 25 单元、28,479 字，**证候表现 406、肺系 946** 双居首位；引书 27 部 60 次，每一格证型都有方名可对）

**教材出处:** 教材·第 6 章（6.1 感冒、6.2 咳嗽、6.3 肺炎喘嗽、6.4 哮喘、6.5 反复呼吸道感染，共 5 病证 25 单元）。本章数字由 `code/main.js` 读 `standards/erke/units.json` 现算。

## 一、五个病证，排成一条纵线

| 病证 | 病位深浅 | 一句话判据 | 病程尺度 |
|---|---|---|---|
| 感冒 | 肺卫（表） | 发热恶寒＋鼻塞流涕喷嚏，**无气促鼻煽** | 数日 |
| 咳嗽 | 肺（宣肃失常） | 以咳为主，可分外感／内伤 | 数日至数周 |
| 肺炎喘嗽 | 肺（**气闭**） | **热、咳、痰、喘、煽**五字并见 | 以天计，可变证 |
| 哮喘 | 肺（**夙根**伏痰） | 反复发作、喉间哮鸣、**呼气延长**、夜间加重 | 数年，发作/缓解交替 |
| 反复呼吸道感染 | 肺脾肾（**正虚**） | 单位时间内感染次数超标 | 以年计 |

这条纵线的用法：**不要把「咳嗽」当诊断终点**。咳嗽升级为气促＋鼻煽，是肺炎喘嗽；反复发作伴哮鸣，是哮喘；一年反复超次数，是反复呼吸道感染。教材在第 6.2.5 按语里把这条线写明：外感咳嗽治疗不彻可发展为肺炎喘嗽；咳嗽反复发作可演变为哮喘与反复呼吸道感染。

## 二、感冒：三夹是它的签名

教材 6.1.1 直接把小儿感冒与成人感冒的差别点出来：**易夹痰、夹滞、夹惊**。

| 兼夹 | 表现 | 处理（6.1.3） |
|---|---|---|
| 夹痰 | 咳嗽加剧、喉间痰鸣 | 解表方加宣肺化痰（前胡、杏仁、桔梗、浙贝母、陈皮、半夏） |
| 夹滞 | 脘腹胀满、纳呆、口臭、便溏或便秘 | 加消食导滞（焦山楂、焦神曲、炒麦芽、鸡内金、莱菔子） |
| 夹惊 | 惊惕、烦躁、夜卧不宁，甚则抽搐 | 加镇惊熄风（钩藤、蝉蜕、僵蚕、地龙），可合小儿回春丹 |

四型与主方（教材 6.1.3）：

| 证型 | 主症要点 | 代表方 |
|---|---|---|
| 风寒感冒 | 发热恶寒、无汗、清涕、咽不红、苔薄白、脉浮紧、**指纹浮红** | 荆防败毒散（《摄生众妙方》） |
| 风热感冒 | 发热重、有汗或少汗、口渴咽痛、浊涕、痰黄稠、咽红肿、脉浮数、**指纹浮紫** | 银翘散（《温病条辨》） |
| 暑邪感冒 | 夏季、身热无汗或少汗、头痛如裹、胸闷脘痞、呕泻、苔腻、脉濡数 | 新加香薷饮（《温病条辨》） |
| 时邪感冒 | 起病急骤、壮热烦躁、咽痛、**有流行性** | 银翘散合普济消毒饮（《东垣试效方》） |

用药分寸（教材 6.1.3 原文口径）：小儿为纯阳之体，感邪易从热化，故解表之中**兼顾清热**；但「不可过用辛温燥烈（耗伤阴津）、亦不可过用苦寒（冰伏邪气、损伤脾阳）」。

教材还给了儿科剂量折算（见 §四），这是本章唯一可直接用于**核对**的数量口径。

## 三、咳嗽：治咳必先治痰，治痰当顾脾胃

教材 6.2.5 的按语是本章最值得先读的一段：**「治咳必先治痰，治痰当顾脾胃」**——因为「脾为生痰之源，肺为贮痰之器」，无论外感内伤之咳，痰都是绕不过去的一环。

首辨外感／内伤（6.2.3）：

| | 外感咳嗽 | 内伤咳嗽 |
|---|---|---|
| 起病 | 急 | 缓 |
| 病程 | 短 | 较长 |
| 表证 | 有（发热恶寒、鼻塞流涕、喷嚏） | 多无 |
| 病性 | 属实 | 虚实夹杂 |
| 伴症 | — | 痰多、乏力、纳呆、汗出 |

六型与主方：

| 证型 | 痰与咳 | 代表方 |
|---|---|---|
| 风寒咳嗽 | 咳声重浊、痰白清稀、清涕、咽不红 | 杏苏散（《温病条辨》） |
| 风热咳嗽 | 咳声高扬、痰黄黏稠、浊涕、咽红 | 桑菊饮（《温病条辨》） |
| 痰热咳嗽 | 痰黄稠量多、咳声洪亮、面赤唇红、苔黄腻 | 清金化痰汤（《统旨方》） |
| 痰湿咳嗽 | 痰白稀量多、咳声重浊、纳呆、苔白腻 | 二陈汤（《太平惠民和剂局方》）合三子养亲汤（《韩氏医通》） |
| 肺气虚 | 咳声低微无力、痰白清稀、自汗易感 | 六君子汤（《医学正传》） |
| 肺阴虚 | 干咳少痰、痰黏难咯、午后潮热 | 沙参麦冬汤（《温病条辨》） |

两条禁忌（教材 6.2.5）：**外感咳嗽忌过早敛肺**（闭门留寇、邪气内伏）；**内伤咳嗽忌过用辛散**（耗气伤阴）。

## 四、肺炎喘嗽：全章最重的一节

### 五字征与「开闭第一」

教材 6.3.1 的临床特征是「**发热、咳嗽、气促、鼻煽**」，重者「张口抬肩、呼吸困难、口唇发绀」；6.3.5 按语把病机核心定为**肺气闭郁**，因此**「开闭为治疗第一要法」**——宣肺、肃肺、泻肺、通腑，都是为了开其闭。

### 常证六型

| 证型 | 要点 | 代表方 |
|---|---|---|
| 风寒闭肺 | 发热恶寒、咳喘痰清、苔薄白 | 华盖散（《太平惠民和剂局方》） |
| 风热闭肺 | 发热恶风、咳痰黄、咽红 | 银翘散合麻杏石甘汤（《伤寒论》） |
| 痰热闭肺 | 壮热烦躁、喉间痰鸣、气促鼻煽、苔黄腻 | 五虎汤（《证治汇补》）合葶苈大枣泻肺汤（《金匮要略》） |
| 毒热闭肺 | 高热持续、咳喘剧烈、烦躁口渴、舌绛苔黄燥 | 黄连解毒汤（《外台秘要》）合三拗汤 |
| 阴虚肺热 | 低热盗汗、干咳少痰 | 沙参麦冬汤 |
| 肺脾气虚 | 低热起伏、咳嗽无力、纳呆便溏 | 人参五味子汤（《幼幼集成》） |

### 变证：这一节决定生死

教材 6.3.3 把变证单列，因为「常证与变证之间并无截然界限」：

- **心阳虚衰**：喘促加重、面色苍白、四肢厥冷、汗出不止、脉微欲绝 → 参附龙牡救逆汤（教材注明：附子有毒，须先煎 30–60 分钟，3 岁以内每剂 3–6 g，中病即止）；病情凶险，须与西药强心、利尿、血管活性药配合。
- **邪陷厥阴**（热陷心肝）：高热神昏、抽搐 → 属急惊风范畴（见第 8 章）。

红线的操作化写法（教材同节）：**痰鸣如拽锯、喘促不安、口唇发绀明显 → 警惕变证，中西医结合积极救治，必要时吸痰、吸氧**。

## 五、哮喘：发时治标，平时治本

教材 6.4.1 引《景岳全书·喘促》定其性质：

> 「喘有夙根，遇寒即发，或遇劳即发者，亦名哮喘」——《景岳全书·喘促》

「夙根」是什么？6.4.2 答得明确：**痰饮内伏于肺**，其成因是肺脾肾三脏失调——肺不足则卫外不固、脾不足则湿聚成痰、肾不足则水液气化失常。诱因以**感受外邪**最常见，其次过敏原、饮食、情志、劳倦、剧烈运动。

| 分期 | 证型 | 代表方 |
|---|---|---|
| 发作期 | 寒性哮喘（痰白清稀泡沫、形寒肢冷、苔白滑） | 射干麻黄汤（《金匮要略》） |
| | 热性哮喘（痰黄黏稠、面赤口渴、苔黄腻） | 定喘汤（《摄生众妙方》） |
| | 外寒内热（表寒＋里热并见） | 大青龙汤（《伤寒论》） |
| | 肺实肾虚（喘促持续、动则尤甚、呼多吸少） | 苏子降气汤合都气丸 |
| 缓解期 | 肺脾气虚 | 玉屏风散（《丹溪心法》）合人参五味子汤 |
| | 脾肾阳虚 | 金匮肾气丸（《金匮要略》） |
| | 肺肾阴虚 | 麦味地黄丸（《医级》） |

教材 6.4.5 点出临床上最常见的错误：**「见喘止即停药」**——许多家长如此，导致反复发作，「此为大忌」。缓解期调理正是中医的优势所在。

红线：**哮喘持续状态经初步处理不能缓解，须立即转诊**（吸氧、雾化、静脉用药）。

## 六、反复呼吸道感染：把「反复」变成一个数

教材 6.5.1 给了可核对的诊断标准（教材原值）：

| 年龄 | 上呼吸道感染 | 下呼吸道感染 |
|---|---|---|
| 0–2 岁 | 每年 ≥7 次 | 每年 ≥3 次 |
| 3–5 岁 | 每年 ≥6 次 | 每年 ≥2 次 |
| 6–12 岁 | 每年 ≥5 次 | 每年 ≥2 次 |

附加条件：**两次感染间隔至少 7 天以上**，且**排除免疫缺陷等器质性疾病**。

这条标准的价值在于：它把一个模糊的「老是感冒」变成可数的门槛，同时把「排除器质病」写进前置条件——**先排除，再谈调理**。

分期辨治（6.5.3）：

| 期 | 病机 | 治法 | 代表方 |
|---|---|---|---|
| 急性期 | 邪实为主（正气本虚） | 祛邪为先，**兼顾护正**，中病即止 | 参照感冒，如黄芪桂枝五物汤（《金匮要略》） |
| 迁延期 | 正虚邪恋 | **扶正祛邪并施** | 玉屏风散合四君子汤（《太平惠民和剂局方》） |
| 恢复期 | 正虚为主 | 固本（肺脾气虚／营卫失调／肾虚骨弱） | 补肾地黄丸（《医宗金鉴》）等 |

6.5.5 按语把本病总纲写成一句：**「其本在正虚，其标在邪侵」**，正虚以肺脾肾为主；并明确两条禁忌：忌「见咳止咳、见热退热」的头痛医头；忌「急性期过用苦寒、恢复期忽视调理」。

## 七、本章的剂量口径（教材原值，仅作核对用）

教材 6.1.3 给的儿童剂量折算：

| 年龄 | 相当于成人剂量 |
|---|---|
| 3 岁以内 | 1/4～1/3 |
| 3–6 岁 | 1/3～1/2 |
| 6–12 岁 | 1/2～2/3 |
| 12 岁以上 | 可接近成人量 |

教材同时注明「临证尚须结合体质酌定」，且多味药另给更小的上限（如麻黄 3 岁以内每剂 3–5 g、细辛 1–2 g、香薷 3–6 g、附子 3–6 g 且先煎 30–60 分钟）。**本书不复述具体处方剂量，只保留这条折算比例作为「剂量随年龄移动」的证据**——真正开方须由医师依现行规范执行。

## 代价与边界

1. **本章的方名与证型用于对账，不用于开方**：剂量、加减、煎法均须由医师依现行规范决定；本书只抄了教材的**比例**与**上限警示**，不抄处方。
2. **红线优先于辨证**：气促鼻煽＋发绀、痰鸣如拽锯、四肢厥冷脉微欲绝、哮喘持续状态、抽搐神昏——立即转诊/急诊，不在本章范围内处理。
3. **「反复呼吸道感染」必须先排除器质病**（免疫缺陷、先心病、营养不良、佝偻病、贫血），教材把它写在诊断标准里，不是可选项。
4. **哮喘以「控制」为目标**：教材明确缓解期调理是优势，但同时承认发作期需支气管扩张剂等急救处理；不要用中药替代急救。

本章为教学整理与文献梳理，**免责声明：** 不构成诊疗建议，不能替代医师面诊；儿童用药剂量与急症处置须由具备资质的医师执行。
