# 肺系五问：先分深度，再辨寒热

## 用途

五个肺系病证的第一句话都是「咳嗽发热」。本单按**闭塞深度**分流：先判断有没有气闭（决定是不是肺炎），再判断急慢（决定是不是哮喘/反复感染），最后才辨寒热痰。

## 第一问：有没有气促、鼻煽（一票分流）

| 观察 | 判定 |
|---|---|
| 只有发热、鼻塞流涕、喷嚏、咳嗽，**呼吸平顺** | 感冒／咳嗽 |
| **气促＋鼻煽**，或张口抬肩、口唇发绀 | **肺炎喘嗽**（按急重证处理） |
| 呼气延长、喉间哮鸣、夜间加重、反复发作 | 哮喘 |

三岁以下计数呼吸：新生儿 40–45、婴儿 30–40、幼儿 25–30、学龄前 20–25 次/分（教材原值，见第 2 章）。

## 第二问：急性还是反复

- 一次病程、数日～数周：感冒／咳嗽／肺炎；
- 反复发作、发作间期如常：哮喘；
- 一年内上/下呼吸道感染次数超标（0–2 岁 7/3、3–5 岁 6/2、6–12 岁 5/2，间隔 ≥7 天，已排除器质病）：反复呼吸道感染。

## 第三问：痰之色质与咽部（辨寒热）

| 线索 | 寒 | 热 |
|---|---|---|
| 痰 | 白、清稀、泡沫 | 黄、黏稠 |
| 涕 | 清 | 浊 |
| 咽 | 不红 | 红／肿痛 |
| 舌／指纹 | 淡红、苔薄白、指纹浮红 | 红、苔薄黄、指纹浮紫 |

## 第四问：兼夹（感冒的签名）

夹痰（喉间痰鸣）→ 加宣肺化痰；夹滞（脘胀、纳呆、口臭、便溏）→ 加消食导滞；夹惊（惊惕、烦躁、抽搐史）→ 加镇惊熄风。

## 第五问：红线

1. 痰鸣如拽锯＋喘促不安＋发绀明显 → 肺炎变证，急诊；
2. 四肢厥冷、汗出不止、脉微欲绝 → 心阳虚衰，急诊；
3. 哮喘持续状态、初步处理不缓解 → 转诊；
4. 高热＋神昏抽搐 → 急惊风（见第 8 章）。

## 输出格式

```text
深度：感冒/咳嗽/肺炎喘嗽/哮喘/反复感染（依据）
急慢：…
寒热：…
兼夹：…
红线：<无 / 命中第 N 条>
```

## 边界

只做分流与证型方向，不给剂量与加减；红线命中即转诊。
