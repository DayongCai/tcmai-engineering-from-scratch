# 第 12 章 · 「动静结合」要拆成负荷、时相、监测三个可执行变量

> **MOTTO:** 「吹呴呼吸，吐故纳新，熊经鸟申」——《庄子·刻意》
>
> **PROBLEM:** 「动静结合」被写进几乎每一份骨病康复医嘱，也因此几乎没有约束力——患者听成「适当活动」，医生写成本意正确的空话。可执行的说法必须回答三个问题：动多少（负荷）、什么时候动（时相）、看什么决定加减（监测）。三个变量不写清，康复就退化成「多走走」与「少动动」的拉锯。

**双根因定位:** 环境逼迫（骨病康复周期长，患者依从性随疼痛波动，医嘱越模糊越容易被自行解释）+ 知识积累（导引与练功传统重「法」而轻「量」，讲究动作要领与意念，对负荷与时相缺少可传递的参数，进入现代康复语境后无法对接）

## 一、三个变量，一个也不能省

**负荷。**指力的大小与重复次数，也包括体重的承载比例。同样是膝关节训练，坐位伸膝与深蹲的负荷差几个量级。骨病患者的负荷要同时满足两个条件：足以刺激骨与肌肉，又不至于突破病灶的承受能力。前者决定「有没有效果」，后者决定「安不安全」。

**时相。** 指在病程的哪一段做什么。急性期、恢复期、维持期的目标不同：急性期是保住邻近关节与肌肉，恢复期是恢复活动度与力量，维持期是重建负重能力与平衡。把维持期的方案用在急性期，等于在伤口上做体能训练。

**监测。** 指用什么指标决定加量、减量或停止。可用的是疼痛（性质与持续时间）、肿胀、活动度、肌力、步态、以及次日的反应。**「次日反应」是康复中最实用的监测点**：训练后当晚与次日的疼痛、肿胀若超过原有水平，说明负荷过大；若在一天内回落，说明可以维持或小幅增加。

三个变量的关系是：时相决定负荷的上限，监测决定负荷能否上调。只写负荷不写时相，是冒险；只写时相不写监测，是放任。

负荷可以用三档描述，避免在没有数字的情况下无从下手：**轻**，指肌肉做等长收缩或在无阻力下完成关节活动，患者不觉疲劳；**中**，指对抗自身肢体重量的活动或轻阻力，做完有轻微酸胀、次日消退；**重**，指对抗外加阻力或单腿承载全部体重，做完有明显疲劳感。三档不需要设备就能区分，也能在病历里被下一位医生读懂。骨病的常规路径是从轻起步，在监测通过后升一档，而不是一上来就中或重。对于骨质疏松、骨坏死、术后早期的患者，档位的上限由病灶的力学条件决定，不由患者的意愿决定。

时相上还有一个容易被忽视的点：**一天之内的顺序**。先做活动度、再做力量、最后做负重与平衡，是同一天内的常规次序；反过来（先负重再活动度）会让已经疲劳的关节在僵硬状态下承受负荷，训练后的疼痛更难归因。这条次序看起来琐碎，却是「次日反应」能否被正确解读的前提——顺序颠倒了，第二天痛了，你分不清是负荷过大还是次序错了。（底本 第12章·第1节）

## 二、采集项：活动度、肌力、疼痛、步态与依从性

| 组 | 采集项 | 判读要点 |
|---|---|---|
| 活动度 | 各方向角度，与健侧对比 | 写度数，不写「活动可」 |
| 肌力 | 徒手肌力 0–5 级，按肌群分别记录 | 分级是结构性描述，用于随访对比 |
| 疼痛 | 部位、性质、与活动的关系、静息时是否痛、0–10 评分 | 性质变化比数值更重要 |
| 肿胀 | 周径测量（固定标志点）、皮温、浮髌 | 周径必须写测量点位置 |
| 步态 | 步幅、步速、是否需要辅助、跛行程度 | 可用「能连续行走的距离类别」记录 |
| 日常活动 | 进食、穿衣、如厕、转移、行走、上下楼等自理项目的完成情况 | 按项目逐条记录，不写「生活自理」一句 |
| 支具与辅具 | 种类、佩戴场景、适配情况、皮肤 | 辅具是负荷的调节器 |
| 依从性 | 家庭训练的执行情况、中断原因、家属能否复述要点 | 依从性低时先改方案，不要先归因于患者 |

自理项目这一栏要逐条写。写成「生活能自理」看起来省事，实际上把最有信息量的部分抹掉了——能穿衣但不能如厕，与能如厕但不能上下楼，康复重点完全不同。

疼痛评分用 0 到 10 的数字量表即可，但要同时记录性质（钝痛、刺痛、酸胀、牵拉感）。数字回答「多痛」，性质回答「为什么痛」；只记数字，复评时会发现分数相同而病情已变。

## 三、阶段判据与「必须停止训练」的红线

| 期 | 目标 | 负荷原则 | 进入下一期的条件 |
|---|---|---|---|
| 急性期 | 保护病灶、维持邻近关节与肌肉 | 等长收缩为主，不负重或部分负重，避免剪切与旋转 | 肿胀与静息痛消退，活动时不引起明显疼痛 |
| 恢复期 | 恢复活动度与力量 | 主动活动度训练，渐进抗阻，负荷小幅递增 | 活动度接近健侧，肌力达到可支撑日常活动的水平 |
| 维持期 | 重建负重与平衡 | 负重训练、平衡与步态训练、功能性动作 | 长期维持，不再以「期」为界 |

红线四条，触线即停训并复评（教学设定，实际以机构制度与专科会诊为准）：

1. **训练中出现新的神经症状**——麻木、无力、放射痛向下肢扩散、二便异常。立即停止，制动，转诊。
2. **关节在训练后肿胀明显增加且次日不消**——减量或暂停，复评。持续加量会走向滑膜炎与关节破坏。
3. **固定期内的疼痛性质改变**——由活动痛转为静息痛或夜间痛，停训复评，警惕感染、血栓与病灶进展。
4. **跌倒后出现新的局部压痛或不能负重**——先拍片排除骨折，不按「扭了一下」处理。骨质疏松者的跌倒不能靠观察。

另有两条边界属于「不该做」的范畴：急性炎症期不做抗阻训练；关节明显积液时不做大范围活动度训练，先处理积液。

## 四、支具与数字化工具：适配边界与三条纪律

康复工程解决的是「力怎么传」的问题。支具与矫形器的适配四要素与上一章相同：对线、压力分布、关节轴心、皮肤。假肢的适配还多一项——残端的形态与体积会随消肿与肌肉变化而变，因此接受腔需要随复评调整，一次做好并不意味着长期合适。

数字化工具在这一层的定位要写清，否则很容易从「辅助」滑向「替代」：

**骨密度与影像的人工智能评估**可以辅助质控、提示可疑病灶、提高阅片一致性；**手术导航**可以提高置钉与截骨的精度；**三维打印**可以做术前模型、截骨导板与定制植入物。这些工具的共同点是：它们改善的是「精度与效率」，不改变「判断与责任」。

三条纪律：

1. **AI 结果必须由医师复核后方可用于临床**。提示可疑不等于诊断，提示阴性不免除阅片责任。
2. **AI 不改变转诊红线**。上一章与本章列出的红线，不因某项检查「AI 判为低风险」而降级。红线的依据是病程与体征，不是算法输出。
3. **数据与知情**。影像与骨密度数据涉及个人信息，采集、存储、用于模型训练都需脱敏、知情同意与伦理审查；植入物的材料与结构须可溯源。

对教学而言，还有一条附加纪律：数字化平台给出的「病—证—法—方—边界」推荐，只能作为检索与提示，不能作为考核的答案标准。考核要考的是判断依据，不是系统输出。

## 五、记录字段、失效模式与考核

| 字段 | 写法要求 |
|---|---|
| 分期 | 急性期／恢复期／维持期，写进入该期的依据 |
| 负荷 | 动作、组次类别、负重比例、辅助具 |
| 时相 | 每日安排的时段与训练顺序（先活动度后力量） |
| 监测 | 看哪几项、由谁看、什么情况下减量或停 |
| 活动度与肌力 | 角度与级别，注明与上次对比 |
| 支具与辅具 | 类型、场景、适配检查、皮肤情况 |
| 数字化结果 | 工具名称、提示内容、复核人、是否改变处置 |
| 家庭执行 | 家属能否复述要点、复述中出错的地方 |

四条失效模式：

- **把骨病当劳损**：以「多活动活动就好了」替代分期方案，急性期加量导致肿胀加重。对策是分期与负荷同时写，急性期不给负重训练。
- **外治禁忌漏查**：在关节积液明显时做大范围活动度训练，或以热敷加训练同时进行，渗出增加。
- **延误手术时机**：把「康复没效果」当成需要继续加练，而实际是结构问题已经需要手术评估。对策是设「康复一定阶段无改善即复评」的节点。
- **固定过久、训练过少**：怕痛而长期制动，肌力与骨量双降，形成「越不动越痛、越痛越不动」的循环。对策是把等长收缩写进固定期医嘱，并以次日反应作为加量的开关。

考核项三项：给三份不同分期的病例，写出该期的负荷原则与监测指标；指出哪一份触了停训红线、第一个动作是什么；给一份「适当活动、避免负重、定期复查」的康复医嘱，改写为含负荷、时相、监测三要素的可执行版本。
