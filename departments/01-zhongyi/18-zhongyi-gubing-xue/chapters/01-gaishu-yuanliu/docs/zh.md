# 第 1 章 · 骨病学的门槛不在辨证，而在先把「病」从「伤」里择出来

> **MOTTO:** 「肾气热，则腰脊不举，骨枯而髓减，发为骨痿」——《素问·痿论》
>
> **PROBLEM:** 一次跌倒可以同时给出两个结论：一处骨折，或者一个早已被病灶掏空的椎体塌陷。前一个结论只需复位与固定，后一个结论若也按前者处理，病灶就留在体内继续扩大。本章把这一步拆成四栏采集、三组判据、三条红线：四栏没填完，不允许开第一张外敷方。

**双根因定位:** 环境逼迫（「伤」与「病」常在同一具身体上并存，病理性骨折就是二者的交叠产物，临床上无法靠回避来分开）+ 知识积累（骨病学的语言来自《内经》的痹、痿、骨空三论，讲的是「骨枯髓减」；骨折筋伤的语言来自复位与力学，两套语言不同源，混用必然在边界上出错）

## 一、边界不在分类表上，在因果链上

骨伤与骨病的分别，通常被讲成一张四行对照表：起因、时间、影像、治法。这张表有用，但它只是结果。真正的分别在前一步——**外力在因果链上的位置不同**。

骨折筋伤里，外力是唯一充分的原因：有多大的力，就有多重的伤；把力去掉、把骨对回去，链条就断了。骨病里，外力最多是诱因，真正的原因是骨本身已经不正常：感染在蚀骨、肿瘤在破骨、代谢在减骨量、缺血在断血供、退变在磨关节、畸形在错力线。同样一次跌倒，落在正常的骨上未必有事，落在被病灶掏空的骨上就是骨折。所以骨病的治疗起点不是「怎么复位」，而是「这块骨为什么坏」。

这个差别落到三处，才成为可以操作的分界：

| 维度 | 骨伤（骨折·脱位·筋伤） | 骨病 |
|---|---|---|
| 起病时点 | 有明确时点，能说清哪一天 | 常无时点，只能说「近来」「这半年」 |
| 影像语义 | 骨折线、移位、关节对位关系 | 骨质破坏、硬化、骨膜反应、间隙变窄、密度改变 |
| 治疗主轴 | 复位—固定—练功，终点是骨愈合 | 定性—分期—边界，终点是保住骨与关节的功能 |

第三条最容易被误解。有人以为骨病学是「不动刀的学科」，恰好相反：底本第4章专设手术适应证与时机一节，说明骨病学从不排除手术，它只是坚持「先定性，再决定动不动、什么时候动」。定性错了，刀开得再漂亮也是错的方向。

源流的意义也在这里。从《内经》以「肾主骨」定病位、以「骨枯髓减」定病机，到《诸病源候论》把骨疽、骨痨等病名系统化，到唐宋金元以三因学说分开外因内因、以脾胃为本解释化源不足，再到明清与近现代的内外治并举、确立影像与手术的边界——四个节点讲的不是年表，而是同一个观念逐步成形：**骨的病，先要说清它在哪一层坏，才谈得上怎么治。**（底本 第1章·第2节）

## 二、采集项：四栏，缺一栏就不算问完

| 栏 | 采集项 | 判读要点 |
|---|---|---|
| 时点与外力 | 受伤时点、外力大小与方向、伤后能否继续负重、有无二次跌倒 | 高能量外力与损伤相称 → 偏伤；平地跌倒、翻身、咳嗽后即骨折 → 偏病，必须往下查 |
| 全身 | 午后或夜间发热、盗汗、消瘦、乏力、近期疔疮与咽喉牙齿耳部感染灶、结核病史与接触史 | 任一项阳性，感染与结核的可能上升一个量级，影像必须加断层 |
| 局部 | 夜间痛（能否痛醒）、肿胀性质（红热肿痛或不红不热）、肿块（质地、边界、活动度、是否变大）、窦道与渗液、邻近关节活动度 | 静息痛与夜间痛是「病」的强信号；不红不热的肿物要想到冷脓肿 |
| 骨本身 | 既往骨折史（尤其低能量骨折）、糖皮质激素使用史、饮酒史、身高较年轻时下降多少、绝经与年龄、家族史、长期制动史 | 这一栏决定骨的质量，它不会出现在主诉里，只能主动问 |

四栏里最容易被跳过的是第四栏，因为它不影响本次疼痛，只影响判断。但骨质疏松、骨软化、长期激素使用这几件事，恰恰是把「伤」的解释推翻的那一类信息。

「填不出」与「没有」必须分开写：前者写「不详」，在复评时补；后者写「无」。把「没问」记成「无」，是后面所有误判的源头。

影像的底线是正侧位两张。只拍正位等于没拍——椎体压缩、骨的膨胀性破坏、关节间隙的改变，多数要在侧位或断层上才看得清。平片之后是否加断层，由前三栏决定：有夜间痛、有肿块、有全身症状、平片可疑而临床不符，四条任一成立，就加 CT（看骨破坏范围、死骨、骨皮质是否中断）与 MRI（看髓内水肿、软组织、椎管与神经）。判读影像时不要只看报告结论，要看到图上的征象与它对应的是哪一栏。

## 三、成组判据与三条红线

单项症状没有诊断力，成组才有。把四栏答案归成三组：

| 组 | 成立条件 | 处置方向 |
|---|---|---|
| 偏伤 | 高能量时点 + 影像与外力相称 + 无夜间静息痛 + 无全身症状 | 按伤处理，但复诊时必须重问夜间痛与全身症状 |
| 偏病 | 低能量骨折、夜间静息痛、不红不热的肿物、窦道、消耗症状，任一项成立 | 补齐第四栏，加断层，暂不做手法与外治 |
| 伤叠病 | 有明确外伤史，同时满足「偏病」任一项 | 两套流程都走：先制动，再定性 |

三条红线，触线即转，不在门诊继续试：

1. **低能量骨折 + 影像见骨质破坏**——疑似病理性骨折。不做闭合复位，不反复手法「摸一摸对不对位」，先制动、护住、转专科。反复手法会把病灶从骨内推到软组织。
2. **发热 + 局部红热肿痛 + 患肢拒动**——疑似化脓性感染。局部不做热敷、熏洗、推拿、膏药，转急诊。热与手法是给感染开路。
3. **肿块 + 夜间痛 + 生长快 + 皮温高或浅静脉怒张**——疑似恶性骨肿瘤。不在肿块上做任何外治、不做穿刺、不做按摩，直接转骨肿瘤专科，由专科决定活检的部位与入路。

这三条属教学设定，用于训练「什么时候必须停手」；实际执行以所在机构制度与专科会诊为准。红线写在这里的价值，是让「转诊」成为一个有触发条件的动作，而不是一句礼貌的托辞。

## 四、外治与固定：先划禁区，再谈手法

定性未完成之前，允许使用的外治只有两种：制动（支具、夹板、卧床）与冷敷（用于急性肿胀）。热敷、熏洗、热熨、膏药、推拿、牵引，全部暂缓。理由不是保守，而是这几类操作分别会把感染推向深部与全身、把肿瘤细胞推入血窦、把尚未定性的骨质破坏变成移位。

定性完成之后，外治仍要受三条约束：皮肤完整性（破损、窦道、渗出者不做贴敷与熏洗）、感觉与血运（麻木、皮温低、毛细血管充盈慢者不做加压包扎与热疗）、全身状态（发热、消耗、凝血异常者先处理全身）。三条中任何一条不过，外治只能退回到制动。

固定的停与不停，判据是「痛与负重」，不是日历。骨病的固定常要跨过「不痛」这个点继续一段，因为痛消不等于骨强；反过来，固定过久也要付代价：肌肉萎缩、关节挛缩、废用性骨量丢失，对骨质疏松者尤甚。因此固定一开始就要写清三件事——目的（防移位、防塌陷、防畸形加重）、复评节点（哪一类时点复评）、解除条件（影像与负重能力达到什么程度）。三条缺一条，固定就会滑向「一直戴着」。

出现下列任一情况，停外治并复评：局部皮温升高或红肿范围扩大、疼痛由活动痛转为静息痛、出现新的麻木或无力、固定远端出现压痕水疱或肤色改变。

## 五、记录字段、失效模式与考核

一份能复核的骨病门诊记录，至少要有八个字段：

| 字段 | 写法要求 |
|---|---|
| 起病时点与外力 | 能精确到日就写日；无时点写「无明确时点」 |
| 夜间痛 | 有／无，性质（钝痛、刺痛、痛醒） |
| 全身症状 | 发热、盗汗、消瘦三项逐项记，不合并写「一般情况可」 |
| 局部体征 | 肿胀性质、肿块三径、皮温、活动度、窦道 |
| 影像 | 部位、序列（正位／侧位／CT／MRI）、关键征象、加断层的理由 |
| 实验室 | 血常规、红细胞沉降率、C 反应蛋白、碱性磷酸酶，注明是否已查 |
| 已做处置 | 外治与固定的种类、起止、反应 |
| 分流结论 | 伤／病／伤叠病，附依据（落在哪一栏、哪一条） |

四条失效模式，每条都对应前面某一栏的缺失：

- **把骨病当劳损**：只问「哪里痛、多久了」，不问夜里是否痛醒、不问体重与盗汗。对策是把夜间痛与全身症状做成必填项，不填不签字。
- **外治禁忌漏查**：没问发热就上热敷，没看皮肤就贴膏药。对策是外治前过一遍三条约束（皮肤、感觉血运、全身状态）。
- **延误手术时机**：把「再观察」当成结论，而不是当成一个有期限的动作。对策是每次写「观察」，必须同时写复评节点与转诊条件。
- **固定过久**：以「不痛了」为唯一解除标准，或干脆不设标准。对策是固定医嘱里写目的、节点、条件三件事。

考核项三项，缺一不合格：给三张病例卡，按四栏填采集表；对每张卡给出分流结论并指出依据落在哪一栏；指出其中至少一张卡触了哪条红线，以及触线后的第一个动作是什么。

## 代价与边界

1. 本章只处理分流，不给任何病种的具体方案，病种内容在第 5 至 11 章。
2. 四栏与三组判据是教学用的简化，真实病例常有跨组表现；判据用来防漏项，不用来代替判断。
3. 三条红线是「必须停手并转诊」的下限，不是手术适应证的全部；手术与否由专科按分期与全身状态决定。
