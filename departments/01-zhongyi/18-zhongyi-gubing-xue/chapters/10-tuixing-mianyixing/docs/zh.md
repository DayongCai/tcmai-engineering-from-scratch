# 第 10 章 · 痹的时间感不止一种：越动越痛，越歇越僵

> **MOTTO:** 「风寒湿三气杂至，合而为痹也」——《素问·痹论》
>
> **PROBLEM:** 三个都以「关节痛」为主诉的患者，如果只问「哪里痛、多久了」，会被归成一类。真正能分开他们的是时间：一个越走越痛、歇一会儿就好；一个早晨僵得握不住拳、活动开了才松；一个半夜痛醒、起床活动反而轻；还有一个是突发突止、间歇期完全如常。这四条时间曲线，比任何单一症状都更能指向不同的病。

**双根因定位:** 环境逼迫（关节痛是最常见的主诉之一，门诊节奏下容易在「痹证」这个大类里就地处理，不再细分）+ 知识积累（痹证的传统分类以病因与部位为主——风、寒、湿、行痹、着痹，而这几类病的关键差别在时间的形态，需要另立一套观察维度）

## 一、四条时间曲线

**机械性时间（骨关节炎）。** 负重关节在活动后疼痛加重，休息后缓解；晨起僵硬短暂，活动几下即松。疼痛与负荷成正比——走平路尚可，上下楼、蹲起时明显。受累多在膝、髋、远端指间关节，影像见间隙变窄、软骨下硬化、骨赘形成，力线常有内翻或外翻。它的本质是「用得越多，磨得越快」。

**炎症性时间（类风湿关节炎）。** 越歇越僵，越动越松。晨僵明显且持续较久，需要一段时间的活动才能缓解；夜间痛与全身乏力常见。受累多为对称性小关节——近端指间、掌指、腕，肿胀呈梭形，晚期可见尺偏、天鹅颈、纽扣花等畸形，并可有眼、肺、皮肤等关节外表现。

**轴性炎症时间（强直性脊柱炎）。** 炎性腰背痛的特征是：夜间痛、晨僵、活动后改善、休息不缓解。起病多在青年，自骶髂关节向上累及脊柱，晚期出现竹节样改变与活动度全面下降，髋关节受累时致残明显，可伴眼炎。

**发作性时间（痛风性关节炎）。** 突发、夜间为多、红肿热痛剧烈，常在短时间内达到高峰，间歇期可完全如常。好发于第一跖趾关节，可有痛风石，破溃后排出白色物质。诱因常与饮酒、高嘌呤饮食、脱水、某些利尿药物相关。

四条曲线放在一起，就构成一张「时间问诊表」。它不需要任何设备，只需要把「什么时候痛、什么时候松」问清。这也是本章把「痹」的讨论从病因学拉回观察学的原因：风寒湿三气讲的是外因，而患者能准确回答的是时间。（底本 第10章·第1节）

## 二、采集项：晨僵、关节计数、力线、抗体与尿酸

| 组 | 采集项 | 判读要点 |
|---|---|---|
| 时间 | 晨僵（有无、持续类别）、疼痛与活动的关系、夜间是否痛醒、发作是否突发突止 | 时间曲线是分型的第一依据 |
| 关节分布 | 单／寡／多关节，对称与否，受累部位（负重关节、小关节、中轴） | 对称性小关节指向炎症性，负重关节指向机械性 |
| 局部体征 | 肿胀性质（骨性膨大或软组织肿胀）、压痛、皮温、活动度、畸形 | 骨性膨大是骨赘，软组织肿胀是滑膜 |
| 中轴 | 枕墙距、指地距、Schober 试验、胸廓扩张度、骶髂关节压痛 | 四项量化，用于随访对比 |
| 关节外 | 眼红眼痛、皮下结节、皮疹、口腔溃疡、发热 | 关节外表现常先于关节症状 |
| 实验室 | 类风湿因子、抗环瓜氨酸肽抗体、HLA-B27、尿酸、红细胞沉降率、C 反应蛋白 | 抗体阳性支持诊断，阴性不能排除 |
| 影像 | 间隙变窄、骨赘、软骨下囊变、穿凿样破坏、骶髂关节改变、竹节样变 | 不同病的影像语言不同，不能只写「退变」 |

晨僵时长要用类别词记录（短／较长／很长），不追求精确分钟，因为患者的回忆精度有限；重要的是「活动后缓解还是加重」这一方向。方向错了，后面的判断全错。

中轴的四项量化看起来繁琐，但它们是强直性脊柱炎随访中唯一可比的指标。枕墙距从两厘米变成八厘米，比患者说「脖子更僵了」有分量得多。

四项的测法要一致才有可比性。枕墙距：立正靠墙，足跟贴墙，测枕骨粗隆与墙的距离；指地距：双膝伸直前屈，测指尖与地面的距离；Schober 试验：以髂后上棘连线中点为标记，向上量十厘米，前屈后测两点间距离的变化；胸廓扩张度：测第四肋间水平的最大吸气与呼气胸围差。四项都要求同一体位、同一标记点、同一测量者，否则变化可能来自测量而非病情。关节外的表现同样要问：眼红眼痛（前葡萄膜炎）、皮肤银屑样改变、反复腹泻（肠道炎症），这些常先于关节症状出现，也常被分别就诊于不同科室。

## 三、成组判据与四条红线

| 组 | 成立条件 |
|---|---|
| 骨关节炎 | 负重关节 + 活动后痛、休息缓解 + 晨僵短 + 影像见间隙变窄与骨赘 |
| 类风湿 | 对称性小关节 + 晨僵较长 + 软组织肿胀 + 抗体阳性或炎症指标升高 |
| 强直性脊柱炎 | 青年 + 炎性腰背痛四项特征 + 骶髂关节改变 + HLA-B27 可阳性 |
| 痛风 | 突发单关节红肿热痛 + 高尿酸 + 典型部位或痛风石 + 间歇期如常 |

四条红线（教学设定，实际以机构制度与专科会诊为准）：

1. **单关节红肿热痛伴发热**——先排除感染性关节炎，做穿刺。按痛风处理而实际是感染，关节软骨会被溶掉；反过来按感染处理而实际是痛风，也只是多做了检查。两者的代价不对称。
2. **中轴病伴神经症状**——颈痛或背痛合并肢体麻木无力、步态改变，立即制动转诊。强直的脊柱像一段融合的骨柱，脆性高，轻微外力即可造成骨折。
3. **多关节快速进展的破坏**——短期内外观与功能明显恶化，转风湿专科，不在门诊以「痹证」长期调治。
4. **痛风石破溃**——按创面处理并转诊，不自行挤压。挤出的物质会污染周围皮肤，窦道难愈。

四组判据之外，还要承认一种常见的状态：**重叠与未分化**。同一个人可以既有骨关节炎的负重关节退变，又有类风湿的对称性小关节受累；也可以只有几周的关节肿痛、抗体与影像都不典型。此时写「痹证」是对的，但不足以指导处置。可执行的做法是写三行：目前支持哪一组、缺哪一项、观察多久复评。把「未分化」写清楚，比强行归入某一组更负责——归类错了，后续所有的治疗方向都会跟着错。

## 四、外治与固定：活动期禁热，类风湿禁重手法

外治的选择在两个维度上分叉：病的类别与所处的期。

**骨关节炎的慢性期**适合温热类外治——熏洗、热熨、敷贴，目的是缓解肌肉痉挛、改善局部循环。但这只适用于没有急性肿胀的时期；关节明显肿胀发热时，热敷会加重渗出。

**类风湿的活动期与痛风急性期**禁用温热。类风湿活动期滑膜充血，热使渗出增加；痛风急性期的红肿热痛本就是炎症高峰，热敷会延长发作。这两个时期可用的是制动、冷敷与药物，不是外治。

**手法**在类风湿上是明确的禁区：骨质疏松与颈椎不稳同时存在，扳法、旋转手法可能造成骨折或椎动脉问题；在强直上同样禁用暴力扳法与踩跷，融合的脊柱没有缓冲。骨关节炎的轻手法松解可以用，但以「操作后次日不加重」为界。

**固定与支具**的用处常被低估。膝关节的内翻或外翻可以通过矫形支具部分卸载内侧或外侧间室的压力；类风湿的手腕可以用休息位支具减少畸形进展；强直的胸腰段支具在骨折风险高时可短期使用。支具的共同边界是：**它替代不了肌力**。佩戴时间过长，肌肉进一步萎缩，卸载效果被抵消。所以支具医嘱要写适配要点、佩戴场景（行走／劳动／夜间）、以及停用与减量的条件。

停做指征：关节肿胀与皮温在治疗后上升、疼痛由活动痛转为静息痛、出现新的关节畸形或交锁、支具压迫处皮肤破损。

## 五、记录字段、失效模式与考核

| 字段 | 写法要求 |
|---|---|
| 时间曲线 | 晨僵类别、活动后加重或缓解、夜间痛、发作形式 |
| 关节计数 | 受累关节数与对称性，列出具体关节 |
| 中轴四项 | 枕墙距、指地距、Schober、胸廓扩张度，各写数值 |
| 实验室 | 抗体、HLA-B27、尿酸、沉降率、C 反应蛋白，注明是否已查 |
| 影像 | 部位、序列、关键征象（间隙、骨赘、破坏、骶髂、竹节） |
| 外治 | 种类、适用期（活动期／慢性期）、皮肤反应 |
| 支具 | 类型、佩戴场景、减量条件 |

四条失效模式：

- **把骨病当劳损**：把炎性腰背痛当腰肌劳损、把类风湿的晨僵当「受凉」。对策是把时间曲线做成必填项。
- **外治禁忌漏查**：在痛风急性期与类风湿活动期上热敷，发作延长后归因于「病重了」。对策是按期选择外治，活动期只用制动与冷敷。
- **延误手术时机**：关节破坏到无法行走仍以保守治疗维持。对策是把力线严重异常与关节间隙消失写成转诊触发词。
- **固定过久**：长期佩戴支具而不做肌力训练，卸载效果被肌萎缩抵消。对策是支具与训练同开，支具写减量条件。

考核项三项：给三份病例的时间描述，判断属哪条曲线并说明依据；指出其中哪一份触线、触哪一条；给一份「关节痛，予热敷加推拿」的处理，指出在活动期病例上错在哪里。
