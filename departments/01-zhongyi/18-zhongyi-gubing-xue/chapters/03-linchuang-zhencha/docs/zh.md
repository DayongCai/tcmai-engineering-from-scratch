# 第 3 章 · 临床诊查：影像不是辅助，是判据

> **MOTTO:** 「一旦临证，机触于外，巧生于内，手随心转，法从手出」——教材·第3章·3.3.1（《医宗金鉴·正骨心法要旨》）
>
> **PROBLEM:** 骨病的查体与内科不同：内科靠问与切，骨科必须靠「摸 + 量 + 看片」。学生常把影像当「确认手段」，实际它是**判据本身**——很多骨病的诊断标准就是某一条影像征象（骨膜反应、死骨、间隙变窄、T 值）。
>
> **双根因定位:** 环境逼迫（骨病早期症状轻微、体征模糊，必须靠影像与实验室定案）+ 知识积累（本章 7 单元 11,037 汉字，三辨主**证候表现 215**；**数值 62 处，为全书最高**——诊查章是全书量化最密的一章）

**教材出处:** 同上。本章数字由 `code/main.js` 现算。

## 一、四诊在骨科的改写

| 诊 | 骨科要点 |
|---|---|
| 望 | 形体、步态、姿势、局部肿胀与畸形、舌象 |
| 闻 | 关节弹响、骨擦音（骨折）、气味（窦道） |
| 问 | 疼痛性质（夜间痛／静息痛／活动痛）、起病缓急、家族史、用药史（激素） |
| 切 | 脉象、按诊（压痛、皮温、波动感、肿块活动度） |

**问诊里最值钱的一项是「夜间痛」**：夜间静息痛是肿瘤与感染的共同信号，也是把「劳损」与「骨病」分开的第一刀。

## 二、查体的三组特殊试验

| 部位 | 试验 | 意义 |
|---|---|---|
| 脊柱 | 直腿抬高、压颈（Spurling）、拾物 | 神经根受压 |
| 髋 | 屈髋内旋、「4」字试验 | 髋关节病变（含股骨头坏死） |
| 膝 | 浮髌、麦氏征、内外翻应力 | 积液与半月板／韧带 |

## 三、影像：四种手段各问什么

| 手段 | 回答的问题 | 局限 |
|---|---|---|
| X 线 | 骨质破坏、骨膜反应、死骨、间隙 | 早期破坏不显（常需 2 周以上） |
| CT | 骨皮质细节、死骨、钙化 | 软组织分辨差 |
| MRI | 骨髓水肿、软组织侵犯、早期坏死 | 费用高、金属植入物受限 |
| 骨密度 DXA | 骨量（T 值） | 只测骨量不测结构 |

**教材在此处的一条实用提醒：急性骨髓炎早期 X 线可为阴性，不能凭阴性排除。**

## 四、实验室四项

| 项 | 提示 |
|---|---|
| 血常规 + CRP + 血沉 | 感染活动度 |
| 碱性磷酸酶 | 成骨活跃（骨肉瘤、Paget 病、骨折愈合） |
| 血钙磷 + 25(OH)D | 代谢性骨病 |
| 病理活检 | 肿瘤定性的**金标准** |

## 五、七单元逐条读

**3.1.1 全身症状**　发热、消瘦、贫血、乏力。教材强调这些症状的「诊断意义」而非「描述意义」：消瘦＋夜间痛＋年轻，首先要想到骨肿瘤；低热＋盗汗＋背痛，首先要想到脊柱结核。

**3.1.2 局部症状与体征**　疼痛（夜间痛／静息痛）、肿胀与肿块、畸形、功能障碍、皮肤与血管神经体征。这一节给的排序是「痛—肿—畸—障」，临床上多数骨病按此顺序出现。

**3.2.1 望闻问切在骨病的应用**　四诊的骨科化。最有价值的是问诊清单：疼痛性质、起病时间、诱因、家族史、激素与饮酒史（股骨头坏死的两大危险因素）。

**3.3.1 脊柱检查**　活动度、压痛、神经体征与特殊试验。这一节的判据是「有无神经受累」——一旦出现，处理级别立刻上升。

**3.3.2 四肢关节检查**　肩肘腕、髋膝踝的活动度与肌力分级。肌力分级（0–5 级）是本章少见的标准化量表，值得记住。

**3.4.1 影像学检查**　X 线／CT／MRI／ECT／DXA。教材在此处标注「现代认识」，说明这部分是新增内容，也是本书与古籍距离最远的一节。

**3.4.2 实验室与病理检查**　血常规、血沉、CRP、碱性磷酸酶、肿瘤标志物与病理活检。**活检是肿瘤定性的金标准**，这句话在本章出现得很硬。

## 六、三条常见误判

- **X 线阴性就排除骨髓炎**：早期可阴性，须结合临床与 MRI。
- **把夜间痛当劳损**：夜间静息痛是骨肿瘤与感染的共同信号，须影像。
- **只做影像不做实验室**：感染活动度、成骨活性、钙磷代谢都只能靠实验室。
