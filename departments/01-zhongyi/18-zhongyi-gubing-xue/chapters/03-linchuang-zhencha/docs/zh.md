# 第 3 章 · 影像不是辅助检查，它是分型与边界的判据

> **MOTTO:** 「骨者，髓之府，不能久立，行则振掉，骨将惫矣」——《素问·脉要精微论》
>
> **PROBLEM:** 「辅助检查」这四个字害人。它让人以为影像只是给已定的诊断补个证据，于是先辨证、后拍片，把片当成签字画押。骨病的实际顺序相反：良性还是恶性、塌陷前还是塌陷后、结核还是化脓，都由影像定；定不下来，后面的内治外治全是空转。本章给出六组采集项、四组成组判据与三样必须自己核对的材料：正侧位片、必要的断层、既往片对比。

**双根因定位:** 环境逼迫（门诊时间被主诉切碎，医生先接住最响的那个症状——痛，影像就退成了事后验证）+ 知识积累（中医骨病学的诊查传统以望闻问切为主干，影像进入判据体系是近现代的事，教材把它编在一节里，学生容易把它读成「补充材料」而不是「判据」）

## 一、四种影像各回答一个不同的问题

把影像当成「清晰度的阶梯」是常见的误解：以为磁共振比 CT 清楚，CT 比平片清楚，于是有了高级设备就不看平片。实际上它们回答的是四个不同的问题，互相不能替代。

| 手段 | 回答的问题 | 关键征象 |
|---|---|---|
| X 线平片 | 骨的形态与密度是否正常 | 骨折线、骨质破坏、硬化边、骨膜反应、间隙变窄、椎体高度、力线 |
| CT | 骨皮质是否中断、破坏范围、有无死骨 | 皮质断裂、死骨、窦道、椎弓与附件的破坏、钙化 |
| MRI | 髓内与软组织有没有病变、椎管与神经是否受压 | 髓内水肿信号、软组织肿块、椎间盘与椎体信号、脊髓受压、积液 |
| 核素与骨密度 | 代谢活跃度与骨量 | 浓聚灶、骨密度值、脆性骨折风险分层 |

「影像不是辅助」有两层意思。第一层是分型靠它：良性肿瘤边界清楚、有硬化边，恶性边界不清、伴骨膜反应；股骨头坏死塌陷前与塌陷后的处理完全不同；结核破坏椎间隙、化脓更常累及椎体与椎旁。第二层是边界靠它：能不能保肢、能不能保髋、要不要立即制动、固定多久，都是影像给的答案，不是症状给的。

因此读片要做三个动作，缺一个就等于没读：**自己看片，不看报告结论**（报告是别人的判断，你要的是征象）；**按序列比**（正位对侧位，本次对既往）；**把征象写回临床那一栏**（这个破坏对应哪个体征，这个水肿对应哪个夜间痛）。只念报告，等于把判断权交出去。（底本 第3章·第4节）

## 二、采集项：六组清单

| 组 | 采集项 |
|---|---|
| 全身 | 体温（午后与夜间各测一次）、体重变化、贫血貌、食欲、乏力、近期感染灶 |
| 局部 | 疼痛的部位与性质、是否夜间痛醒、与负重的关系、肿胀性质、肿块三径、皮温、浅静脉、窦道与渗液、肤色 |
| 脊柱 | 视诊生理曲度与侧弯后凸；触诊棘突压痛与叩击痛；活动度前屈后伸侧屈旋转；神经检查感觉平面、肌力（0–5 级）、反射、病理征；特殊试验直腿抬高、压颈、拾物 |
| 四肢关节 | 力线、肿胀（浮髌）、压痛、主动与被动活动度（与健侧对比）、肌力、肢体长度与周径、特殊试验（4 字试验、Thomas 征、Trendelenburg 征） |
| 影像 | 部位、序列、关键征象、与既往片对比、加断层的理由 |
| 实验室与病理 | 血常规、红细胞沉降率、C 反应蛋白、碱性磷酸酶、尿酸、类风湿因子与抗环瓜氨酸肽抗体、HLA-B27、血钙磷、穿刺液与培养、活检 |

脊柱这一组最容易被压缩成「腰背痛，活动可」。而脊柱结核与脊柱肿瘤的早期，恰恰只有叩击痛、夜间痛与一个不明显的神经体征，等到「活动明显受限」时，椎体往往已经塌陷。所以脊柱的采集必须逐项写，不能合并成一句。

四肢关节这一组的关键是**对比**：活动度要与健侧比，周径要与健侧比，肌力要与健侧比。单侧的数值没有意义，「屈曲 100 度」这句话在不知道健侧是 130 度时无法判断。

实验室与病理这一组要点是分工：红细胞沉降率与 C 反应蛋白指向炎症的活动度，碱性磷酸酶指向成骨活动，尿酸与抗体指向代谢与免疫，培养与活检指向病原与性质。活检不在门诊做，由专科按影像定位取，取错位置比不取更糟。

六组的采集顺序也有讲究：**先神经、再局部、最后影像**。神经检查必须在任何手法与牵引之前完成，因为手法之后出现的麻木无力，分不清是病灶本身进展还是操作所致，责任与处置都会陷进争论。影像放在最后，不是因为它次要，而是因为前五组的答案决定拍什么、拍几个序列——先拍片再看病人，最容易拍出一堆与问题无关的图像，然后拿报告去凑诊断。

## 三、成组判据与三条红线

四组判据，每组要求「症状 + 体征 + 实验室或影像」三项同时成立，缺一项只能写「疑似」：

| 组 | 成立条件 |
|---|---|
| 感染组 | 发热或近期感染灶 + 局部红热肿痛与拒动 + 红细胞沉降率或 C 反应蛋白升高 + 影像见破坏或积液 |
| 结核组 | 低热盗汗消瘦 + 慢性腰背痛伴叩击痛 + 红细胞沉降率升高 + 影像见椎间隙变窄或椎旁脓肿 |
| 肿瘤组 | 夜间痛 + 肿块 + 影像见边界不清的破坏伴骨膜反应 + 碱性磷酸酶可升高 |
| 退变免疫组 | 晨僵 + 对称或多关节受累 + 抗体阳性或尿酸升高 + 影像见间隙变窄、骨赘或穿凿样破坏 |

三条红线，触线即停手（教学设定，实际执行以机构制度与专科会诊为准）：

1. **神经功能进行性下降**——肌力下降、感觉平面上升、二便功能障碍，任一项成立即立即制动、急诊转诊，不做手法、不做牵引、不做任何「试一试」的复位。
2. **影像见骨皮质中断伴软组织肿块**——疑似恶性，不穿刺、不按摩、不贴敷，转骨肿瘤专科，由专科决定活检的部位与入路。
3. **关节穿刺抽出脓液**——不向关节内注入任何药物、不做热敷与熏洗，急诊评估引流。关节软骨在脓液里泡着的时间，就是它被破坏的时间。

写了「疑似」之后必须跟三样东西，否则「疑似」等于「不管」：一是补什么检查、二是多久之内完成、三是出现什么情况直接来急诊。三样缺一样，「疑似」就在病历里变成了一个不承担责任的词。四组判据的用处也在这里——它不给出诊断，它给出「还差哪一项」，而差的那一项通常就是下一步该做的检查。

## 四、外治与固定：读片之前不动手

手法前必须有三样东西：正侧位片、必要的断层、与既往片的对比。三样缺一样，不做手法。这不是形式，而是因为手法能造成三种不可逆：把感染推向深部、把肿瘤推入血窦、把骨质疏松的椎体压塌。

手法的绝对禁忌列在这里：感染、结核、肿瘤、重度骨质疏松、脊髓或马尾受压、凝血功能异常、局部皮肤破损。相对禁忌是急性肿胀期与剧烈疼痛期——此时手法既做不进去，也容易加重。

固定的边界写在「复评」上。固定之后每个复评节点查五件事：皮温、肤色、感觉、末梢活动度、疼痛性质的变化。任何一项恶化，拆固定复评，不解释为「正常反应」。固定的解除条件要同时有影像与功能两条：影像上骨愈合或病灶稳定，功能上能负重且无痛。只有其中一条，不算达到解除条件。

停外治的判据四条：皮肤水疱或破溃、疼痛明显加剧、出现发热、红肿范围扩大。四条与第 1 章一致，因为外治禁忌不随病种改变，只随禁忌证改变。

## 五、记录字段、失效模式与考核

| 字段 | 写法要求 |
|---|---|
| 主诉四要素 | 部位、性质、程度、时间，各一个词，不写「腰痛多年」 |
| 体征分组 | 按脊柱组或四肢组逐项，神经检查五项单列 |
| 神经检查 | 感觉平面、肌力（写明级别）、反射、病理征、二便，五项缺一不写「神经未见异常」 |
| 影像 | 部位、序列、征象、对比、加断层的理由 |
| 判据组 | 归属哪一组、三项条件是否齐、结论写「确诊」或「疑似」 |
| 处置 | 外治与固定的种类、强度、复评节点、停的条件 |
| 转诊 | 是否触线、触哪一条、转往哪个专科 |

五条失效模式，每条都能在病历里找到痕迹：

- **只拍正位**：椎体压缩、膨胀性破坏、关节间隙改变看不出来，漏诊从这里开始。对策是正侧位为底线，侧位不可省。
- **不问神经症状**：把「能走」当成神经功能正常，漏掉早期的括约肌障碍与感觉平面。对策是神经五项做成必填。
- **把报告当结论**：报告写「骨质增生」，就按退变治，不再看图；而图上同时有一个边界不清的破坏区。对策是自己看片、按序列比。
- **活动度写得含糊**：写「活动可」而不写度数，复评时无法比较。对策是与健侧比、写度数。
- **固定后不查末梢**：石膏或支具下出现麻木、肤色改变未及时发现。对策是复评五件事写进固定医嘱。

考核项三项：给两份影像描述与配套体征，写出归属哪一组判据、还缺哪一项；指出其中一份是否触线、触哪一条、第一个动作是什么；给一份写了「神经未见异常」的病历，指出它缺哪五项中的哪几项。
