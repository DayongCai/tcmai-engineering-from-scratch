# 影像不是辅助检查，它是分型与边界的判据 · 提示词

## 用途

给「影像不是辅助检查，它是分型与边界的判据」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「四种影像各回答一个不同的问题 → 采集项：六组清单 → 成组判据与三条红线 → 外治与固定：读片之前不动手」这条链。

正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

## 边界

本章为教学整理，不构成诊疗建议，不能替代医师面诊、影像判读与病理诊断；具体操作以现行规范与所在机构制度为准。
