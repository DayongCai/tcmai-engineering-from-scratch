# 四诊＋三项

## 用途

骨科的影像不是「确认手段」，是判据本身。本单把诊查写成四层清单，其中**夜间痛**与**活检**是两个最硬的节点。

## 步骤

### 1. 四诊

望形体步态／闻弹响气味／问疼痛性质与用药史／切脉与按诊（夜间静息痛最先问）

### 2. 特殊试验

脊柱（直腿抬高、压颈）／髋（4 字、屈髋内旋）／膝（浮髌、麦氏）

### 3. 影像四问

X 线看骨与膜／CT 看皮质与死骨／MRI 看骨髓与软组织／DXA 看骨量（早期 X 线可阴性）

### 4. 实验室

血常规＋CRP＋血沉／碱性磷酸酶／钙磷＋25(OH)D／病理活检（活检是肿瘤金标准）

## 输出

① 主诉性质（尤其夜间痛）；② 查体阳性项；③ 影像选择及理由；④ 实验室项；⑤ 是否需活检。
