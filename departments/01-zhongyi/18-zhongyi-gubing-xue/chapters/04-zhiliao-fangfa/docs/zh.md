# 第 4 章 · 五条路各有各的禁区，选路之前先算边界

> **MOTTO:** 「手随心转，法从手出」——《医宗金鉴·正骨心法要旨》
>
> **PROBLEM:** 治疗方法的教材最容易读成菜单：内治、外治、手法、固定牵引、手术、练功，六样都列上，学生就以为可以自由组合。真实约束是反过来的——每一条路都有一组「不能走」的条件，先排除掉不能走的，剩下的那条才是选项。本章把五条路的禁区排成一张表，并给出选路前必须填满的三栏。

**双根因定位:** 环境逼迫（骨病病程长、见效慢，患者与医者都倾向于「多上几样」，把并用当成加强）+ 知识积累（外治与手法在骨伤科传统里是强项，这份自信迁移到骨病时，容易忽略骨病特有的禁忌——感染、肿瘤、骨质疏松，这三种在骨折筋伤里不是主要矛盾）

## 一、五条路的分工，与它们各自怎么失效

| 路 | 主要作用 | 典型失效方式 |
|---|---|---|
| 内治 | 分期论治：按急性、慢性、恢复三期调整攻补 | 只辨证不分期，急性期用补、慢性期用攻，方向反了 |
| 外治 | 敷贴、涂搽、熏洗、热熨、理疗，作用于局部 | 不看皮肤与全身状态，把热疗用在化脓期与肿瘤局部 |
| 手法与固定牵引 | 手法松解粘连、理筋通络、改善活动度；固定与牵引制动、防移位、防塌陷、纠正挛缩 | 手法用在感染、结核、肿瘤、重度骨质疏松上，把病灶推开；固定没有解除条件，滑向「一直戴着」 |
| 手术 | 引流、病灶清除、切除重建、关节置换 | 两个方向的错：该转不转，或把手术当成最后一招而错过窗口 |
| 练功与康复 | 动静结合，保住肌力与活动度 | 痛就完全不动，或反之，不痛就过度负重 |

这五条路里，第三条实际上装着两个动作——手法与固定牵引，一个主动加力、一个被动限制，方向相反却同属一条路，因为它们在临床上是成对出现的：先松解再固定，或先固定再练功。

这张表要读出两层意思。第一层，五条路不是并列的选项，而是有先后：性质未定之前，只有制动是安全的；性质定了，才轮到内治与外治；分期清楚了，才谈手术时机；全程都要有练功，否则治好了病、废掉了关节。

第二层，每条路的失效方式都指向同一个毛病——**把「可以用」当成「应该用」**。化脓性骨髓炎急性期用热敷，不是因为它有一点道理，而是因为「外治是骨伤科的强项」这句话被不加限定地搬了过来。（底本 第4章·第2节）

## 二、选路之前：三栏必须填满

| 栏 | 内容 | 它决定什么 |
|---|---|---|
| 分期栏 | 感染分急性与慢性；结核分活动与稳定；肿瘤分良性、恶性、瘤样；坏死分塌陷前与塌陷后；退变分早期与晚期 | 决定主法：急性以祛邪为主，慢性以扶正兼祛邪，塌陷后以重建为主 |
| 性质栏 | 影像三征 + 实验室 + 必要时病理 | 决定能不能动手：感染与肿瘤不做手法，恶性不做局部外治 |
| 全身栏 | 体温、体重、贫血、肝肾功能、凝血、血糖、年龄、依从性与家庭支持 | 决定强度与能不能手术：全身条件不允许时，先处理全身 |

三栏里最常被漏的是第三栏。同样是股骨头坏死，一个能配合免负重、能定期复查的人，与一个独居、依从性差、还在饮酒的人，治疗选择完全不同——不是病不同，是条件不同。

选路的顺序可以固定成三句问话：**这块骨坏在哪一层（性质）？坏到第几步（分期）？这个人扛不扛得住（全身）？**三句答完，可选的路自然只剩一两条。

## 三、外治与固定：动作边界与停做指征

外治的四条通用禁忌，与病种无关，只与禁忌证有关：皮肤不完整（破损、窦道、渗出、皮疹）、感觉与血运差（麻木、皮温低、毛细血管充盈慢）、全身有热（发热、感染活动）、出血倾向（凝血异常、抗凝用药）。四条逐一核对，任一条不过，外治降级为制动。

热疗另有两处绝对禁区：**化脓性感染的急性期**与**恶性肿瘤的局部**。前者热促扩散，把骨膜下脓肿推进软组织与血流；后者局部加热增加血流，理论上利于肿瘤细胞播散。结核活动期同样不用温热，以免病灶活跃。

敷贴与熏洗的边界不写在日历上，写在皮肤上：以皮肤反应为界——出现潮红加重、瘙痒、水疱即停，不因为「还没到时间」而继续。面积也要控制，一次不超过一个关节的范围，理由是皮肤吸收与全身反应都随面积上升。

手法的边界写在「次日」：以操作后次日症状不加重为界。次日疼痛加剧或活动度下降，说明力度过头，降一级或停做。手法绝不追求「一次到位」，尤其在骨质疏松与长期激素使用者身上，一次重手法可能就是一次压缩骨折。

固定的边界写在三件事上：目的（防移位、防塌陷、防畸形加重，三者只选一个为主的）、复评节点、解除条件（影像与功能两条同时达到）。固定期内必须安排肌肉等长收缩与邻近关节活动，理由是制动本身会造成骨量丢失与肌肉萎缩，而骨病患者原本就常处于这一风险的边缘。

牵引的边界写在神经体征上：牵引过程中出现新的麻木、无力、放射痛加重，立即减重或停止，不解释为「正常反应」。

停做指征五条，任一出现即停外治并复评：皮肤水疱或破溃、疼痛明显加剧、出现发热、红肿范围扩大、固定远端麻木或肤色改变。

最后要说的是并用顺序。临床上常见「内治加外治加手法加固定」一起上的处方，看起来周全，实际上把判断稀释了：一旦出现不良反应，无法归因到哪一条路。可执行的做法是给并用排一个顺序与主次——**同一时间只允许一条路是新加的**，其余保持不动；新加的那条路在复评节点上单独评估，有效则保留，无效或加重则撤掉。这样每次复评只回答一个问题，责任与效果都能落地。顺序上的一般规律是：先制动控制风险，再内治调整全身，然后外治与手法处理局部，最后以练功收尾；手术不在这个序列里排队，它按红线单独触发。

## 四、红线：什么时候必须交给手术

这一组判据的作用，是把「转手术」从态度问题变成条件问题。以下五条成立，即应转专科评估，不在门诊继续保守（教学设定，实际以机构制度与专科会诊为准）：

1. **化脓性感染伴全身中毒**——高热不退、意识改变、血压下降。此时第一位是切开引流与全身支持，内治与外治都不是主角。
2. **关节穿刺抽出脓液**——关节软骨在脓液中的每一段时间都在被溶解，需急诊引流冲洗。
3. **脊髓或马尾受压**——肌力进行性下降、感觉平面上升、二便功能障碍。立即制动、急诊，任何手法与牵引都是禁忌。
4. **恶性骨肿瘤的疑似征象**——夜间痛、肿块、影像见边界不清的破坏伴骨膜反应。不做局部外治、不做穿刺、不做按摩，限期转骨肿瘤专科。
5. **骨坏死已塌陷、关节结构破坏、力线严重异常**——保守治疗无法逆转结构改变，需评估重建。

与这五条相对的，是三种不该转却被转走的情形：良性肿瘤与瘤样病变可以随访观察；骨质疏松的骨量减少阶段以生活方式与药物管理为主；退变性关节病的早期以力线与肌力训练为主。**红线是下限，不是全部；把不该转的转走，与该转的不转，代价一样。**

还有一段常被忽略的边界：围手术期。骨病的手术不是「切完就好」，术前要控制感染灶与全身状况，术后要处理疼痛、肿胀、制动带来的肌肉萎缩与血栓风险。中医药在这一段的位置是辅助——改善全身状态、减轻术后肿胀与疼痛、帮助恢复胃肠功能；但它不能替代抗感染、抗凝与康复训练这三件硬事。把围手术期写成「中药调理为主」，等于把风险留给患者。

## 五、记录字段、失效模式与考核

| 字段 | 写法要求 |
|---|---|
| 三栏结论 | 分期、性质、全身，各写一句，各带证据 |
| 选路 | 主选哪一条、辅选哪一条、排除其余的理由各一句 |
| 外治 | 种类、部位、面积、强度、皮肤反应、停的条件 |
| 手法 | 力度级别、操作后次日的反应记录 |
| 固定 | 目的、复评节点、解除条件三件事 |
| 练功 | 动作、频次类别、负重限制 |
| 复评 | 看什么、什么情况提前来、什么情况直接急诊 |

四条失效模式，与本章的四个小节一一对应：

- **把骨病当劳损**：按软组织劳损开外治与手法，未做性质栏。对策是三栏不填不选路。
- **外治禁忌漏查**：发热患者上热敷、皮肤破损处贴膏药。对策是四条禁忌逐条核对并记录结果。
- **延误手术时机**：把「再保守看看」当成结论，不设期限与复评条件。对策是每次保守治疗都写复评节点与转诊条件。
- **固定过久**：以「不痛」为唯一解除标准，或未设标准。对策是固定医嘱写目的、节点、条件，且固定期同步肌肉维持。

考核项三项：给三个病例，写出三栏结论并选路，说明为何排除其余各条；指出其中一个病例触了哪条红线、第一个动作是什么；给一份「外治加手法加固定」全上的病历，指出其中至少两处越界。

## 代价与边界

1. 本章讲选路的框架，不给具体方药、手法操作细节与手术术式，这些分别在第 5 至 11 章与专科培训中完成。
2. 五条路的划分沿用教材的组织方式，实际治疗常需并用，但并用的前提是每条路各自都不越界。
3. 红线五条是教学设定的下限判据，不构成手术适应证的全部；手术决策由专科按分期、全身状态与患者意愿共同作出。
