# 第 7 章 · 良恶之分看边界与生长方式，不看肿块大小

> **MOTTO:** 「骨瘤者，形色紫黑，坚硬如石，推之不移」——《医宗金鉴·外科心法要诀》
>
> **PROBLEM:** 一个直径两厘米、边界清楚、多年不变的骨性突起，多数是良性；一个直径一厘米、边界模糊、近期变大的破坏区，可能是恶性。体积在良恶判断里几乎不占权重，权重在边界、皮质、骨膜与生长速度。本章要求把评估从「摸起来有多大」转到「边界清不清、皮质断没断、骨膜有没有反应」。

**双根因定位:** 环境逼迫（患者最先注意的是「长了个包」，医患沟通的第一句话就是大小，评估被这个第一印象锚定）+ 知识积累（中医典籍以「骨瘤」统称骨部肿物，寒热虚实的分辨与良恶的生物学行为不是同一套语言，混用会把「阴证」当成「良性」的同义词）

## 一、四个判据比「大小」有用

良性与恶性的分别，落在骨的反应方式上，而不是落在体积上。四条判据的权重从高到低：

| 判据 | 良性倾向 | 恶性倾向 |
|---|---|---|
| 边界 | 清楚，常有硬化边 | 模糊，与正常骨之间无过渡带 |
| 骨皮质 | 完整，可膨胀但连续 | 中断，被破坏穿透 |
| 骨膜反应 | 无，或厚实连续 | 葱皮样、Codman 三角、日光放射状 |
| 生长方式 | 缓慢，多年变化不大 | 快，与既往片对比可见明显进展 |

软组织肿块是第五条：良性一般没有，恶性常见，且边界不清。疼痛的性质是第六条：良性多无痛或仅活动后不适，恶性常有夜间痛与静息痛，普通止痛手段难以缓解。

年龄与部位构成第一层筛查，它的作用是缩小范围，不是下诊断：青少年长骨干骺端（骨肉瘤、骨软骨瘤）、骨骺闭合前后的骨骺端（骨巨细胞瘤）、儿童骨干与干骺端（尤文肉瘤、嗜酸性肉芽肿）、中老年脊柱与骨盆（骨髓瘤、转移性肿瘤）。中老年人发现骨破坏，第一件事是问原发肿瘤史——乳腺、肺、前列腺、肾、甲状腺都是常见来源。

还有一类必须单列：瘤样病变（骨囊肿、骨纤维结构不良、嗜酸性肉芽肿）。它们不是真性肿瘤，但会造成骨质破坏与病理性骨折，处理原则是「防折、随访、必要时手术」，不是「切掉」。

**中间性**也要留一个位置：骨巨细胞瘤有局部侵袭性，可以复发，少数可转移。把它当良性放任，与把它当恶性过度，都是错的。

三类容易混淆的「同像」要单独提出来。第一类是**骨转移瘤与原发性骨肿瘤**：中老年的脊柱破坏，多为转移，处理的方向是找原发灶与控制病灶，而不是按原发骨肿瘤去做大范围切除。第二类是**瘤样病变与真性肿瘤**：骨囊肿、骨纤维结构不良、嗜酸性肉芽肿都可以表现为破坏区，但它们的自然史是「可能自愈或稳定」，处理是防折与随访，不是切除。第三类是**感染与肿瘤**：两者的早期都可以只有疼痛与影像上的破坏，区别在于感染有发热与炎症指标升高、肿瘤有软组织肿块与骨膜反应；判断不清时先做感染的相关检查，因为感染的时间成本更高。

把这三类分开，是为了避免一个更常见的错误：把所有「骨破坏」都往肿瘤上想，或者都往感染上想。分类的价值不在于给病命名，而在于决定下一步查什么、能不能动手、以及要不要转诊。（底本 第7章·第1节）

## 二、采集项：六组，重点是三径与旧片

| 组 | 采集项 | 判读要点 |
|---|---|---|
| 基本信息 | 年龄、性别、职业、既往肿瘤史与家族史 | 年龄是缩小范围的第一把筛子 |
| 疼痛 | 夜间痛、静息痛、是否痛醒、与活动的关系、对普通止痛手段的反应 | 夜间痛是恶性倾向的强信号 |
| 肿块 | 长、宽、高三径（用尺量并记录），质地、边界、活动度、皮温、浅静脉、有无搏动、与深部是否固定 | 「推之不移」提示与骨固定，是古籍已经抓住的征象 |
| 生长速度 | 与既往照片、既往记录、患者自述的衣物松紧对比 | 速度比大小重要 |
| 影像 | 边界、皮质中断、骨膜反应、软组织肿块、基质钙化；必要时 CT 看皮质与死骨、MRI 看髓内范围与软组织 | 五项逐项写，不写「见骨质破坏」一句了事 |
| 实验室 | 碱性磷酸酶、血钙、血常规、红细胞沉降率、蛋白电泳与免疫固定电泳（怀疑骨髓瘤时） | 碱性磷酸酶升高提示成骨活动活跃 |

肿块三径必须用尺量并写数值，不能用「鸡蛋大」「拳头大」。理由是随访时无法比较——「鸡蛋大」过了三个月还是「鸡蛋大」，而实际上已经从三厘米变成五厘米。有条件的应同时留照片，标尺入镜。

旧片对比是本章最容易被跳过、也最能改变结论的一步。一个「边界清楚」的病灶，若与两年前的片子相比明显扩大且边界变模糊，性质判断就要改写。因此采集项里应有一行：**有无既往影像、是否已调取对比**。

## 三、成组判据与四条红线

| 组 | 成立条件 |
|---|---|
| 良性倾向 | 边界清楚有硬化边 + 皮质完整 + 无骨膜反应 + 无软组织肿块 + 生长缓慢 |
| 恶性倾向 | 边界模糊 + 皮质中断 + 骨膜反应 + 软组织肿块 + 夜间痛，五项中三项以上 |
| 中间性 | 边界尚清但皮质变薄或膨胀明显 + 局部侵袭表现 + 有复发史 |
| 瘤样病变 | 年龄与部位符合 + 囊性改变或纤维替代 + 无软组织肿块 + 常以病理骨折首现 |

四条红线，触线即转，不做任何局部处置（教学设定，实际以机构制度与专科会诊为准）：

1. **夜间痛 + 肿块 + 皮质中断**——疑似恶性。不穿刺、不按摩、不贴敷、不热敷，直接转骨肿瘤专科。活检的部位与入路由专科规划，随手一针可能污染将来保肢要用的通道。
2. **青少年膝关节周围持续疼痛**——不按「生长痛」观察。生长痛多为双侧、夜间发作、次日如常；单侧、持续、渐重、伴压痛的，必须拍片。
3. **中老年脊柱破坏伴体重下降**——不按骨质疏松治疗，先查原发灶。把转移瘤当骨质疏松治，会一直治到病理骨折。
4. **瘤样病变已发生病理骨折**——制动、转专科，不反复手法复位。囊性病灶的骨折端反复搬动，既不复位也不愈合。

## 四、外治与固定：肿块上的三条禁令

骨肿瘤的局部外治有三条禁令，理由各不相同：

**禁热敷。**局部加热使血流增加，对恶性病灶不利；同时热敷会掩盖皮温变化的观察。

**禁按摩与推拿。**机械挤压可能使肿瘤细胞进入破裂的血管与周围软组织，也可能直接把薄化的皮质压断。患者常因「按一按舒服些」而自行按摩，这句话要写进交代事项。

**禁贴敷与自行穿刺。**贴敷造成皮肤改变，影响后续手术的皮肤条件与切口设计；穿刺更是直接污染活检通道。任何取样都必须由专科在规划好的位置完成。

固定的边界要按目的写。对病理骨折风险高的病灶（皮质破坏范围大、负重骨），固定是「防折」，范围要跨过病灶上下各一个关节，避免应力集中在病灶处；对已发生病理骨折者，固定是「维持对位与减痛」，需与专科的手术计划衔接，不宜自行长期维持。固定期内禁止负重，负重时机由影像的骨愈合或病灶稳定决定，不由疼痛决定。

停做指征：疼痛加剧或由活动痛转为静息痛、肿块在短期内明显增大、出现新的麻木无力、固定远端肤色与感觉改变。

## 五、记录字段、失效模式与考核

| 字段 | 写法要求 |
|---|---|
| 肿块三径 | 三个数值加单位，注明测量部位与体位；有条件留照片 |
| 疼痛节律 | 夜间痛有／无、是否痛醒、与负重的关系 |
| 影像五征 | 边界、皮质、骨膜反应、软组织肿块、基质钙化，逐项写 |
| 旧片对比 | 有无既往片、是否已对比、变化描述 |
| 倾向判断 | 良性／中间性／恶性／瘤样，四者选一并写依据条数 |
| 处置 | 是否转诊、转往何处、转诊前做了什么（制动／禁止事项） |
| 交代事项 | 不按摩、不热敷、不贴敷、不自行穿刺，四项逐一交代并记录 |

四条失效模式：

- **把骨病当劳损**：青少年膝周痛按生长痛、运动损伤处理；中老年背痛按劳损处理。对策是单侧、持续、夜间痛三项成立即拍片。
- **外治禁忌漏查**：在肿块上贴膏药、做热敷、做推拿。对策是把三条禁令写进交代事项并留痕。
- **延误手术时机**：把恶性倾向的病灶按良性「随访观察」，观察期一过，分期已变。对策是随访必须有期限与转诊条件，且恶性倾向不进入随访通道。
- **固定过久**：病理骨折后长期制动，肌肉萎缩、关节僵硬，等到能手术时全身条件反而更差。对策是固定与专科计划衔接，固定期同步非制动关节的活动。

考核项三项：给四份影像与体征描述，判断倾向并写出依据条数；指出其中哪一份触线、触哪一条；给一份写了「肿块约鸡蛋大，建议随访」的记录，指出它在字段与判断上各缺什么。
