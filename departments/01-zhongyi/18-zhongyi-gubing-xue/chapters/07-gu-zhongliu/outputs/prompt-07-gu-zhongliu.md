# 良恶先行

## 用途

骨肿瘤里最危险的一类错误是**拿阴阳当良恶**。本单的次序固定：良恶印象 → 是否必须病理 → 才谈证型与攻补。

## 步骤

### 1. 判良恶印象

生长速度／疼痛（夜间）／骨膜反应／软组织肿块／全身与碱性磷酸酶（印象≠诊断）

### 2. 定病理

边界不清、夜间痛、骨膜反应异常者须活检（病理是金标准）

### 3. 辨证型

阴证／阳证；痰瘀毒聚与正虚（阴阳只管用药，不管切不切）

### 4. 定切入点

扶正祛邪为辅、攻毒须监护、不替代手术边界

## 输出

① 良恶印象与依据；② 病理必要性；③ 证型与攻补比例；④ 中医切入点与边界。

## 边界

- 数字一律由 `code/main.js` 读 `standards/gubing/units.json` 现算，不手写；
- 不给药物剂量、不给手术技术参数；
- **免责声明：** 本单为教学整理，不构成诊疗建议，不能替代医师面诊与影像判断。
