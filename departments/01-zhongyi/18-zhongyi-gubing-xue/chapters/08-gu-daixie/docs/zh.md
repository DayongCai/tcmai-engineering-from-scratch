# 第 8 章 · 骨量是一本账，看余额也要看已经发生的支出

> **MOTTO:** 「肾者主水，受五藏六府之精而藏之」——《素问·上古天真论》
>
> **PROBLEM:** 两个骨密度数值完全相同的患者，一个从未骨折，一个已经因为平地跌倒断过腕骨与椎体，处理并不相同。只盯数值会把后者当成前者。骨量要按账本读：收入（营养与力学刺激）、支出（年龄、绝经、药物、制动）、余额（骨密度）、以及已经发生的支出（脆性骨折）。四项缺一，判断就会偏。

**双根因定位:** 环境逼迫（骨量减少本身没有症状，患者只有在骨折后才就诊，而骨折又常被当作一次意外单独处理，账本从未被翻开）+ 知识积累（「肾主骨」在本病的解释力最强，也最容易停在「补肾」这一步，把可测的钙磷、维生素 D、骨转换指标与力学负荷挡在门外）

## 一、账本的四个栏目

**收入。** 峰值骨量在青年期达到顶点，此后只能维持、难以增加。收入来自两处：原料（钙、蛋白质、维生素 D 与日照）与力学刺激（负重与抗阻运动）。原料不足或刺激不足，收入就低。

**支出。** 年龄增长、女性绝经后的骨量加速丢失、长期糖皮质激素、甲状旁腺功能异常、慢性肾病、胃肠手术后吸收不良、长期制动、烟酒。支出项目里，制动最容易被忽略——卧床与长期不负重，骨量下降的速度远快于多数人的预期。

**余额。** 以双能 X 线吸收法测定，取腰椎、髋部、前臂等部位，用 T 值表示与年轻同性别人群峰值的差距：不低于 −1.0 为正常，介于 −2.5 与 −1.0 之间为骨量减少，不高于 −2.5 为骨质疏松。（数值判据属教材口径，实际报告以所在机构标准为准。）

**已发生的支出。** 脆性骨折——从站立高度或更低处跌倒即发生的骨折。这一栏的意义是：**同样一个 T 值，合并脆性骨折就是严重骨质疏松，处理强度不同**。一次脆性骨折之后，再次骨折的风险显著上升，所以骨折本身是一个必须被记账的事件，而不是一次孤立的意外。

佝偻病与骨软化走的是同一条账本，但错在「原料」这一栏：矿化的原料不足，类骨质不能正常钙化。儿童表现为佝偻病，成人表现为骨软化——前者在骨骺板，后者在骨基质，机制同源。

体征要认得出来，因为这两类病的实验室改变可能很轻微。佝偻病看四处：方颅（额骨与顶骨隆起）、肋骨串珠（肋骨与软骨交界处膨大，触诊可及一排结节）、腕部增宽（桡尺骨远端膨大如手镯）、下肢弯曲（负重后出现 O 形或 X 形）；此外还有前囟闭合延迟、出牙晚、肌张力低、腹部膨隆。骨软化看三处：弥漫性骨痛（以腰背与骨盆为主，按压有痛）、肌无力（起立与上楼费力，步态摇摆）、假骨折线（影像上呈横行带状透亮区，常见于肋骨、骨盆与股骨颈）。把「O 形腿」一律当成缺钙、把「腰背痛加肌无力」一律当成劳损，是这两类病最常见的漏诊方式。（底本 第8章·第1节）

（本段体征属教材口径，个体差异大，判读以专科检查为准。）

## 二、采集项：身高、跌倒史、骨密度、继发因素

| 组 | 采集项 | 判读要点 |
|---|---|---|
| 体态 | 身高（与年轻时对比，下降多少）、体重、脊柱后凸、驼背 | 身高下降是椎体压缩的间接证据，比「背有点弯」可靠 |
| 疼痛 | 腰背痛的性质、是否与体位改变相关、有无突发加重 | 突发的剧烈背痛要想到新发压缩骨折 |
| 骨折史 | 部位、时间、外力大小（是否站立高度以下） | 低能量即骨折，是账本上的红字 |
| 跌倒史 | 次数、地点、时间、原因（视力、平衡、药物、地面、照明） | 跌倒是骨折的直接通路，可干预 |
| 危险因素 | 绝经年龄、糖皮质激素使用、烟酒、咖啡、制动、胃肠手术、肾病、甲状旁腺疾病、家族史 | 继发因素不查，补得再多也留不住 |
| 骨密度 | 设备、部位、T 值，注明是否同一设备复查 | 不同设备、不同部位的数值不可直接比较 |
| 实验室 | 血钙磷、碱性磷酸酶、25 羟维生素 D、甲状旁腺激素、肝肾功能、骨转换标志物 | 低磷伴骨痛肌无力，要想到骨软化 |
| 影像 | 平片看压缩骨折、假骨折线与骨皮质厚度；椎体骨折的形态学评估 | 假骨折线（Looser 带）是骨软化的重要征象 |

跌倒史这一栏常被写成「否认跌倒」，追问之后才发现是「摔过一次没当回事」。问法要具体：近一年有没有摔倒、滑倒、被绊、从凳子上下来时腿软。老年人常把这类事件归为「不小心」，不认为与病有关。

复查的方法学也要写进记录，否则数值再精确也不可比。骨密度随访应在同一设备、同一部位进行，因为不同设备的校准与不同部位的骨量变化速度不同；腰椎有严重退变、骨质增生或椎体压缩时，腰椎的测量值会被抬高，此时应参考髋部或前臂。这类细节决定了「数值没变」到底是病情稳定，还是测量部位选错了。

## 三、成组判据与四条红线

| 组 | 成立条件 |
|---|---|
| 骨质疏松 | T 值不高于 −2.5，或骨量减少合并脆性骨折 |
| 严重骨质疏松 | T 值不高于 −2.5 且已有脆性骨折 |
| 佝偻病 | 儿童 + 方颅、肋骨串珠、腕部增宽等体征 + 碱性磷酸酶升高 + 影像见骨骺板增宽与干骺端毛刷样改变 |
| 骨软化 | 成人 + 骨痛与肌无力 + 假骨折线 + 低磷或低钙 + 维生素 D 缺乏 |

四条红线（教学设定，实际以机构制度与专科会诊为准）：

1. **脆性骨折**——不能只处理骨折。同一次就诊内必须评估骨量、跌倒风险与继发因素，并转专科。漏掉这一步，下一次骨折只是时间问题。
2. **骨痛 + 肌无力 + 低磷**——查骨软化，不按骨质疏松只补钙。原料错在哪里没查清，补钙可能加重异常。
3. **脊柱压缩骨折伴神经症状**——制动、转诊。禁手法、禁牵引、禁让患者「起来活动活动试试」。
4. **存在继发因素**（长期激素、甲状旁腺异常、慢性肾病、可疑肿瘤）——先查因，再谈补。继发性骨质疏松的处理与原发性不同。

## 四、外治与固定：重手法是禁区，支具宜短不宜长

骨质疏松者的外治禁区比一般人宽：**禁用重手法**（按压、踩跷、暴力扳法），理由是压缩骨折与肋骨骨折常发生在一次「松解」之后；**慎用牵引**，尤其是长期牵引，卧床本身就是骨量的支出项；**慎用拔罐与刮痧**于脊柱区，皮下出血与负压对薄弱的骨与皮肤都不利。相对安全的是温热类外治用于缓解肌肉痉挛，但要控制温度与时间，因为老年人的皮肤对热不敏感，烫伤常在不知不觉中发生。

固定在这一章有个反直觉的结论：**支具宜短不宜长**。急性压缩骨折的支具目的是止痛与早期活动，疼痛控制后应逐步撤除；长期佩戴支具会加重椎旁肌萎缩，肌肉一弱，椎体的负荷反而更多落在骨上。因此支具医嘱要写三件事：目的（止痛、允许早期下地）、复评节点、撤除条件（疼痛控制、能在无支具下完成坐起与短距离行走）。

卧床同样要设上限。长期卧床带来的骨量下降、肌力下降、肺部感染与血栓风险，往往超过它「保护脊柱」的收益。处置原则是：**止痛优先于制动，活动优先于卧床**，在疼痛可控的前提下尽早坐起、站立、行走。

康复的三条主线：负重运动（步行、低强度抗阻）、平衡与步态训练（减少跌倒）、环境改造（照明、扶手、防滑、去除门槛与地毯）。第三条最容易被写成「注意防跌倒」四个字，实际上它是最能落地的一条——扶手装在哪个位置、夜灯放在哪里，都是可以逐项核对的。

停做指征：出现新发剧烈背痛、身高在短期内继续下降、支具压迫处皮肤发红不消、训练后疼痛持续到次日。

## 五、记录字段、失效模式与考核

| 字段 | 写法要求 |
|---|---|
| 身高 | 现值与年轻时对比，写下降幅度 |
| 骨密度 | 设备、部位、T 值，注明是否与上次同设备 |
| 骨折史 | 部位、时间、外力（是否低能量） |
| 跌倒史 | 近一年次数、地点、原因归类 |
| 继发因素 | 逐项写有／无，阳性者写下一步 |
| 处置 | 支具目的与撤除条件、运动处方、环境改造项 |
| 复评 | 何时复查骨密度、看什么、什么情况提前来 |

四条失效模式：

- **把骨病当劳损**：突发背痛按腰肌劳损处理，不拍片、不问身高变化，漏掉压缩骨折。对策是背痛 + 身高下降 + 低能量跌倒史三者任一，即拍片。
- **外治禁忌漏查**：对高龄者做重手法「松解」，造成肋骨或椎体骨折。对策是骨密度与年龄任一提示风险，手法降级为轻手法或不做。
- **延误手术时机**：压缩骨折不稳定或伴神经症状仍保守观察。对策是把神经症状与不稳定写成转诊触发词。
- **固定过久**：长期支具加卧床，肌力与骨量双降，撤除后立即跌倒。对策是支具写撤除条件，卧床设上限，同步负重训练。

考核项三项：给三份病例，按账本四栏填表并判断属原发还是继发；指出哪一份触线、触哪一条；给一份「骨密度偏低，建议补钙、多晒太阳」的处理，指出它漏了哪两栏、应补什么。
