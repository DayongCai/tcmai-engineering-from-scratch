# 第 11 章 · 畸形的窗口只开一次：骨在长，机会不等人

> **MOTTO:** 「骨为干，脉为营，筋为刚，肉为墙」——《灵枢·经脉》
>
> **PROBLEM:** 一个六个月大的髋关节发育不良，靠支具就可能复位；一个两岁才发现同样的问题，多数要走手术，而且术后仍有残余畸形的风险。病没变，变的是骨的可塑性与关节的塑形能力。本章排了五张时间表、四条红线，并要求记录里多一个字段——发现时的月龄或年龄，因为它是判断机会还剩多少的唯一依据。

**双根因定位:** 环境逼迫（婴幼儿不会主诉，畸形又没有疼痛，家属与初诊者都倾向「长大就好了」，观察本身成了最常见的处置）+ 知识积累（中医对小儿筋骨畸形多以「先天禀赋不足、肝肾亏虚」立论，论治重在内服与调护，而矫形的关键变量——月龄与生长板状态——不在传统辨证的框架里）

## 一、为什么这几类病的时间表不一样

时间表取决于两件事：**生长板是否还在，以及塑形能力还剩多少**。

髋关节发育不良的时间表最陡。出生后数月内，髋臼与股骨头的塑形能力最强，此时用支具把股骨头维持在髋臼内，髋臼会顺着股骨头长；随着月龄增加，软组织挛缩加重、髋臼浅平定形，复位越来越难，最终需要手术。所以「早」这个字在这里不是态度，是生理条件。

先天性肌性斜颈的时间表稍缓但同样有限。生后早期胸锁乳突肌内可触及梭形肿块，多数会逐渐消散而遗留挛缩；若头颈长期偏向一侧，面部会在持续的应力下出现不对称，这种不对称一旦形成，即使颈部活动恢复正常也难以完全逆转。干预越早，面部对称性的保全越好。

马蹄内翻足的时间表取决于畸形是姿势性的还是结构性的。姿势性的（柔软、可被动矫正）以手法与支具为主；结构性的需要按序矫正，且不可用蛮力——婴儿的足部软组织娇嫩，一次暴力的扳正就可能造成医源性的僵硬与畸形加重。

脊柱侧凸的时间表跟着生长高峰走。青春期生长加速期是侧凸进展最快的阶段，也是支具能发挥作用的阶段；生长基本结束后，支具的作用消失，剩下的选择是观察或手术。判断进展，靠的是角度测量的连续对比，不是「看起来弯了没有」。

骨软骨病的时间表跟着骨骺的血液供应走。骨骺在生长活跃期最脆弱，反复的牵拉与应力造成缺血与坏死，处理的核心是减负与时间，让骨骺在低压力的环境中完成修复。

五张时间表合起来说明一件事：**畸形类疾病的主要变量不是药，是时间。**

时间表也解释了为什么筛查比治疗更划算。髋关节的筛查放在新生儿期与婴儿期，成本是查体与一次超声；漏过去之后，成本是支具失败、手术、以及残余畸形带来的长期随访。斜颈的筛查放在生后早期，成本是摸一次胸锁乳突肌；漏过去之后，成本是面部不对称与斜视的代偿。脊柱的筛查放在生长高峰前，成本是 Adam 前屈试验加一次站立位片；漏过去之后，成本是角度进展到需要手术的范围。三处都遵循同一条经济学：**早一步的成本是检查，晚一步的成本是手术加余生。**（底本 第11章·第1节）

## 二、采集项：月龄、皮纹、特殊试验、角度

| 组 | 采集项 | 判读要点 |
|---|---|---|
| 时间 | 发现时的月龄或年龄、发现方式（筛查／家属注意／跛行后） | 这一个字段决定窗口还剩多少 |
| 产前与产时 | 臀位产、产伤、羊水过少、多胎、襁褓方式 | 「蜡烛包」式的伸直并拢包裹是髋脱位的危险因素 |
| 发育 | 独坐、独走的月龄，与同龄对比 | 运动里程碑延迟要一并评估 |
| 髋 | 臀纹与皮纹是否对称、双下肢长度（Galeazzi）、外展范围、Ortolani 与 Barlow 试验、行走后步态 | 单侧外展受限是敏感体征；双侧脱位呈鸭步 |
| 颈 | 头是否向患侧倾斜、下颌是否旋向健侧、胸锁乳突肌有无肿块、颈部旋转与侧屈范围、面部是否不对称 | 面部不对称提示已有时日，需尽快处理 |
| 足 | 前足内收、后足内翻、踝背屈范围、足跟能否着地、负重时足印 | 柔软可矫正与僵硬不可矫正，处理完全不同 |
| 脊柱 | Adam 前屈试验、双肩与肩胛高度、腰线与乳房对称性、骨盆倾斜、Cobb 角 | 角度连续测量比单次外观描述有用 |
| 影像 | 髋：六月龄内首选超声，骨化核出现后摄骨盆平片（髋臼指数、Shenton 线）；脊柱：站立位全长片测 Cobb 角；足：负重位片 | 检查方式跟着年龄走，不能一套用到底 |

这一组里，Ortolani 与 Barlow 是两个方向的动作：一个把脱出的股骨头复位回来（感受弹响与滑入），一个把可脱位的股骨头推出（感受不稳）。两者都要求放松与手法轻柔，哭闹挣扎时结果不可靠，应安抚后复查。写记录时要写「阳性／阴性／不配合」，不能只写「查体未见异常」。

Cobb 角的测量要点是找到上端椎与下端椎，取各自终板最倾斜的一条线作垂线相交。它在不同测量者之间有误差，因此随访要尽量由同一人或同一流程测量，并在记录里注明测量体位（站立位还是卧位）。

## 三、成组判据与四条红线

| 组 | 成立条件 |
|---|---|
| 先天性肌性斜颈 | 生后胸锁乳突肌肿块或挛缩 + 头向患侧倾、下颌旋向健侧 + 颈部旋转或侧屈受限 |
| 髋关节发育不良 | 臀纹不对称 + 外展受限 + Ortolani 或 Barlow 阳性；行走后为跛行 + Galeazzi 征阳性 + 影像异常 |
| 马蹄内翻足 | 前足内收 + 后足内翻 + 踝背屈受限，三者同时存在 |
| 脊柱侧凸 | Adam 前屈试验阳性 + 站立位片 Cobb 角超出可接受范围 |
| 骨软骨病 | 特定部位（股骨头骨骺、胫骨结节、跟骨、月骨等）的负重痛与局部压痛 + 影像见骨骺改变 |

四条红线（教学设定，实际以机构制度与专科会诊为准）：

1. **六月龄内髋关节筛查异常**——立即转专科，不进入「再观察几个月」的通道。支具的窗口在这一段，错过就要换一整套方案。
2. **侧凸伴神经体征**（腹壁反射不对称、下肢肌力或感觉异常、足畸形、步态异常）——转专科并进一步查脊髓。这类侧凸不是姿势问题。
3. **马蹄内翻足不可强行扳正**——尤其不可由家属自行用力扳。婴儿足部的软组织损伤后形成僵硬，比原来的畸形更难处理。
4. **斜颈已出现面部不对称**——尽快转专科评估，不再单纯依靠家庭按摩。

## 四、外治与固定：支具的适配与按摩的力度

支具是这一章的主要外治手段，它的效果取决于四件事，缺一件就等于没戴：**对线正确**（力的方向对准需要矫正的轴）、**压力分布均匀**（压红集中在一处说明受力点错了）、**关节轴心对齐**（支具的关节要落在解剖关节的位置）、**佩戴依从**（家属能否坚持，取决于是否讲清了目的与如何观察皮肤）。

支具的边界写在皮肤与血运上：每次取下检查受压部位，出现持续不退的红斑、水疱、肤色改变，立即调整或停用。婴儿的皮肤薄，压疮进展快，这一条不能打折。

按摩与被动牵伸只适用于斜颈这类软组织问题，要点有三：方向明确（头向健侧侧屈、下颌旋向患侧）、力度轻（以婴儿不哭闹抗拒为度）、次数分散（少量多次优于一次长时间）。**力度这一项没有可用的数字，只有观察指标**：做完之后婴儿情绪平稳、局部皮肤不红、次日活动范围不缩小，说明力度合适；出现哭闹加剧、皮肤发红或活动范围变小，说明过头了。

固定的停与减，按病种写：髋关节支具以复位稳定与超声或影像改善为减量依据；脊柱支具以生长阶段与角度进展为依据，生长结束后不再以支具为主要手段；足部矫形支具在畸形矫正后仍需维持一段时间以巩固，减量的条件由复查决定。

停做指征：皮肤压红不消或破溃、肢体肤色与温度改变、婴儿持续哭闹无法安抚、复查见复位丢失或角度进展。

## 五、记录字段、失效模式与考核

| 字段 | 写法要求 |
|---|---|
| 发现时月龄 | 具体月龄或年龄，加发现方式 |
| 危险因素 | 臀位、产伤、襁褓方式、家族史，逐项写 |
| 专科试验 | Ortolani、Barlow、Galeazzi、Adam，写阳性／阴性／不配合 |
| 角度 | 髋臼指数、Cobb 角、踝背屈角度，写数值与体位 |
| 支具 | 型号、对线、佩戴场景、皮肤检查结果、减量条件 |
| 家庭执行 | 按摩方向与力度描述、家属是否能复述、下次复查时间 |
| 转诊 | 是否触线、触哪一条、转往何处 |

四条失效模式：

- **把畸形当「长大就好」**：髋脱位与斜颈被观察至月龄偏大，窗口关闭。对策是「发现时月龄」成为必填字段，且六月龄内异常直接转诊。
- **外治禁忌漏查**：家属自行用力扳足、按摩力度过大，造成医源性损伤。对策是把「不可强行扳正」写进交代事项，并教家属用观察指标判断力度。
- **延误手术时机**：侧凸角度进展而仍以支具与体操维持。对策是把角度进展与神经体征写成转诊触发词。
- **固定过久**：支具长期佩戴导致肌萎缩、依从性下降、皮肤问题，最终被迫中断。对策是支具写减量条件，并在佩戴期安排非固定部位的活动。

考核项三项：给三份婴幼儿或青少年的体征描述，写出归属与依据；指出哪一份必须立即转诊、为什么观察会误事；给一份「建议继续观察，半年来复查」的记录，指出它缺了哪个字段、在什么情况下这个建议是错的。

1. 本章讲窗口与边界，不给支具型号参数、手法操作细节与手术方式，具体由小儿骨科与康复专科执行。
2. 月龄与角度的分界是教材与专科共识的口径，不同机构的具体标准可能不同，以所在机构为准。
