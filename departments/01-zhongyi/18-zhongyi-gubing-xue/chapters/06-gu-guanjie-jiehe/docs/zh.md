# 第 6 章 · 骨与关节结核：冷脓肿与截瘫之间

> **MOTTO:** 「骨痹不已，复感于邪，内舍于肾」——教材·第6章·6.1.1（《素问·痹论》）
>
> **PROBLEM:** 骨结核起病隐袭，最容易被当成「腰肌劳损」或「关节炎」。它的两个结局都很重：寒性脓肿破溃成窦道、脊柱结核压迫脊髓致截瘫。学生的问题不是不会辨证，而是**不会把「低热、盗汗、消瘦 + 局部痛」这组信号串起来**。

## 一、三个别名与一个共同点

| 名 | 用法 |
|---|---|
| 骨痨 | 强调虚损（阴虚火旺为本） |
| 流痰 | 强调痰浊流注（寒性脓肿） |
| 骨与关节结核 | 现代病名 |

共同点：**本虚标实**——阴虚为本，痰浊与瘀为标。教材的辨证骨架正是这条：阴虚火旺、阳虚、气血两虚三证，都在「本虚」上加一层「标实」。

## 二、信号组合（本章最实用的一张表）

| 信号 | 提示 |
|---|---|
| 低热、盗汗、消瘦、乏力 | 结核中毒症状 |
| 局部隐痛、夜间加重、休息不减 | 病灶活动 |
| 寒性脓肿（不红不热，波动感） | 流痰已成 |
| 脊柱后凸、活动受限 | 椎体破坏 |
| 下肢无力、二便障碍 | **脊髓受压 → 紧急** |

最后一行是红线：**截瘫前兆一旦出现，任何辨证都要让位于减压。**

## 三、三证与治法

| 证 | 主症 | 治法方向 |
|---|---|---|
| 阴虚火旺 | 潮热盗汗、舌红少苔、脉细数 | 滋阴降火、托毒 |
| 阳虚（寒痰凝滞） | 形寒、脓肿不红不热 | 温阳散寒、化痰通滞 |
| 气血两虚 | 面色㿠白、乏力气短 | 益气养血、托里生肌 |

## 四、三单元逐条读

**6.1.1 骨与关节结核概论**（2,785 汉字）　概述（流痰／骨痨）、病因病机（阴虚火旺／正虚邪恋）、辨证论治、预防调护、按语。按语给出两条红线：**截瘫与寒性脓肿**——前者紧急减压，后者穿刺或切开须防窦道。

**6.2.1 脊柱结核**（2,719 汉字）　教材把脊柱单列，因为它是骨结核最好发的部位（约占一半）。病机以肾虚骨痨为主；按语给出「截瘫／后凸畸形手术指征」——后凸角度进行性加重也是手术指征之一。

**6.3.1 髋膝关节结核**（2,740 汉字）　髋、膝是第二好发部位。按语强调「关节功能保护」：结核治疗的目标不只是病灶清除，还有保住活动度。

## 五、三条常见误判

- **把低热盗汗当「体虚」调理**：结核中毒症状被当作一般虚损，延误诊断。
- **寒性脓肿当普通脓肿切开**：不红不热的脓肿切开易成窦道，须先明确性质。
- **只看局部不看全身**：骨结核是全身病的局部表现，抗结核治疗是主线，中药是协同。

## 代价与边界
