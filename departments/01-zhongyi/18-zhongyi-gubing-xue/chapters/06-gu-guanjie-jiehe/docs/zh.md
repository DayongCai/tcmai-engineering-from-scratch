# 第 6 章 · 冷脓肿不热，截瘫不可逆，中间那段就是诊断的窗口

> **MOTTO:** 「大骨枯槁，大肉陷下」——《素问·玉机真藏论》
>
> **PROBLEM:** 结核性炎症渗出少、红热不显，脓肿可以在离病灶很远的部位被摸到——大腿根部的包块，来源可能是腰椎。正因为「不热」，它被当成劳损的时间最长；而一旦出现截瘫，脊髓的损伤往往已经不可逆。本章用全身五项、神经五项与三条红线建立一条时间意识：在不热与不可逆之间，只有一段窗口。

**双根因定位:** 环境逼迫（慢性腰背痛在人群里极常见，绝大多数确实是劳损，于是「先按劳损治一治」成为默认路径，结核被这条路径吞掉）+ 知识积累（本病在中医典籍中以「骨痨」「流痰」立名，痨与痰都指向「虚」与「缓」，这份「缓」的印象削弱了对神经功能恶化的警觉）

## 一、冷脓肿为什么「冷」，截瘫为什么不可逆

结核性炎症以增生与干酪样坏死为主，渗出相对少，局部红、热、肿都不明显，触之可有波动而皮色如常，故称冷脓肿。它的危险在于会**沿筋膜间隙流注**：腰椎病灶的脓可沿腰大肌下行至髂窝、大腿根部，在远离脊柱的地方形成一个包块。患者主诉「大腿根有个包」，医生若只查大腿，就永远找不到椎体上的破坏。

截瘫的发生有四条路径：脓液与坏死组织突入椎管、死骨或塌陷的椎体后缘压迫脊髓、结核性肉芽组织与硬膜外脓肿、以及后凸畸形造成的慢性牵张。前两条来得快，后两条来得慢。共同点是——**压迫早期可逆，压迫久了不可逆**。这决定了处置的紧迫性：不是等「确诊了再说」，而是一旦出现神经体征的变化，就按急症处理。

于是本章的核心矛盾可以写成一句话：冷脓肿的「不热」使人迟缓，截瘫的「不可逆」要求迅速，两者之间只剩一段不长的时间窗。窗口里能做三件事：问出全身症状、查神经五项、拍对影像。（底本 第6章·第2节）

## 二、采集项：全身五项、神经五项、影像三处

| 组 | 采集项 | 判读要点 |
|---|---|---|
| 全身 | 午后低热、盗汗、消瘦、乏力、食欲；结核病史与接触史；既往肺或淋巴结结核 | 五项中两项以上阳性，结核的可能上升一个量级 |
| 脊柱局部 | 慢性腰背钝痛（劳累后加重、休息减轻）、夜间痛、棘突叩击痛、拾物试验、后凸与侧弯 | 叩击痛定位价值高于患者自述的「一片都痛」 |
| 神经五项 | 感觉平面、肌力（0–5 级）、腱反射、病理征、二便功能 | 每次复诊都查，五项缺一不写「神经未见异常」 |
| 四肢关节 | 跛行、关节肿胀（浮髌）、主动与被动活动度、大腿或小腿周径 | 单关节慢性肿痛伴肌肉萎缩，要想到关节结核 |
| 影像 | 平片看椎体破坏、椎间隙变窄或消失、椎旁脓肿阴影、后凸角；CT 看死骨与附件；MRI 看椎管内、硬膜外、脊髓受压与跳跃病灶 | 平片早期可阴性；有神经症状者必须有 MRI |
| 实验室 | 红细胞沉降率、C 反应蛋白、结核菌素试验或干扰素释放试验、涂片与培养、必要时病理 | 沉降率用于判断活动度与治疗反应，不用于定位 |

影像这一组要特别注意两件事。第一，**椎间隙变窄是脊柱结核的重要征象**，它与多数脊柱肿瘤的鉴别点正在此处：肿瘤多破坏椎体而保留间隙，结核则常同时累及相邻椎体与间隙。第二，**跳跃病灶**——脊柱结核可以同时累及不相邻的多个椎体，只拍病变最痛的那一段会漏。因此 MRI 应覆盖全脊柱或至少包含跳跃可能涉及的节段。

髋与膝的结核另有一套观察重点。髋关节结核早期表现为跛行与髋部痛，患儿常把疼痛说成膝部痛（闭孔神经牵涉），检查可见髋关节各方向活动受限，尤其外展与外旋；晚期出现屈曲内收畸形与肢体短缩。膝关节结核以单关节慢性肿胀为主，浮髌阳性，股四头肌萎缩出现得早而明显——「肿胀加萎缩」这个组合，比单纯的关节肿胀更值得警惕。两处的共同点是：**功能保护与病灶控制必须同时进行**，一味制动会让关节僵在畸形位，一味活动又会加重破坏，所以制动的体位要放在功能位（髋略屈、膝略屈），并在制动期内做肌肉等长收缩。

与化脓性关节炎的鉴别要点是时间与温度：结核起病缓、低热、皮温不高、沉降率升高而白细胞多不显著；化脓起病急、高热、局部红热明显、白细胞与 C 反应蛋白显著升高。两者的处理方向不同，把结核当化脓做切开，窦道难愈；把化脓当结核慢慢调，关节毁得快。

## 三、成组判据与三条红线

| 组 | 成立条件 |
|---|---|
| 脊柱结核 | 低热盗汗消瘦中两项 + 慢性背痛伴叩击痛 + 沉降率升高 + 影像见椎间隙变窄或椎旁脓肿 |
| 髋膝结核 | 单关节慢性肿痛 + 肌肉萎缩 + 沉降率升高 + 影像见关节间隙变窄与骨质破坏 |
| 截瘫前期 | 上述任一组成立 + 肌力下降或感觉平面上升或二便改变 + MRI 见硬膜外压迫 |

三条红线（教学设定，实际以机构制度与专科会诊为准）：

1. **神经功能进行性下降**——立即制动、急诊转诊。禁手法、禁牵引、禁任何「试一试复位」。已经受压的脊髓经不起第二次挤压。
2. **后凸角进行性增大或椎体明显塌陷**——转专科评估稳定与矫形，不在门诊以支具「先撑着看」。
3. **冷脓肿将破或已破**（皮肤发亮、波动明显、有窦道形成）——不在门诊自行穿刺或切开排脓。穿刺通道与切口位置要由专科按后续手术规划决定，随手一针可能污染将来要用的入路。

另有两条常被忽略的边界：抗结核治疗必须规范、不自行停药，中途停药是复发与耐药的主要来源；窦道形成后按慢性窦道处理，不用封闭性敷料覆盖。

## 四、外治与固定：禁温热、禁重手法，制动的起与止

外治在本章的禁区比上一章更宽：**一切温热禁用**（热敷、熏洗、热熨、理疗），理由是温热使病灶局部活跃、血流增加，不利于稳定；**一切重手法禁用**，理由与感染相同，且脊柱结核常伴骨质破坏，手法可直接造成塌陷或脊髓损伤；**牵引禁用**于脊柱不稳或有神经症状者。拔罐、刮痧这类造成局部负压与皮下出血的操作，同样不用于病灶区。

允许的外治只有制动。制动的方式按部位分：脊柱结核以硬板床与支具为主，颈椎用颈托或头颈胸支具，胸腰段用胸腰骶支具；髋关节结核以皮牵引或支具限制负重；膝关节结核以支具制动。制动的目的是减少负重与剪切，防止椎体进一步塌陷与后凸加重。

制动的起止要写清。起始条件：确诊或高度疑似、有神经症状、影像见明显破坏或不稳。复评节点：每一类时点复评时查四件事——体温、疼痛性质、神经五项、后凸角。解除条件：全身症状消失、沉降率回落至稳定、影像见病灶稳定或骨性融合，三者同时具备才逐步下地，且下地初期仍在支具保护下。

固定过久在这里的代价是三重的：骨质疏松加重（长期卧床）、压疮与坠积性肺炎（尤其截瘫患者）、关节挛缩。因此卧床期必须同步做三件事：轴线翻身、四肢被动与主动活动、深呼吸与有效咳嗽。这三件事不做，固定本身就会成为新的病因。

停做指征：出现新的麻木无力、皮肤压疮或支具压痕不消、体温反复、后凸明显加重。

## 五、记录字段、失效模式与考核

| 字段 | 写法要求 |
|---|---|
| 结核五项 | 低热、盗汗、消瘦、乏力、接触史，逐项写有／无 |
| 神经五项 | 感觉平面、肌力级别、反射、病理征、二便，逐次记录并与上次对比 |
| 后凸角 | 每次复评记录数值与测量体位 |
| 影像 | 序列、椎间隙、椎旁脓肿、椎管内情况、有无跳跃病灶 |
| 冷脓肿 | 部位、大小、波动感、皮肤情况、是否已破 |
| 制动 | 方式、起止、复评节点、解除条件 |
| 依从性 | 抗结核用药是否规律、有无自行停药 |

四条失效模式：

- **把骨病当劳损**：慢性腰痛按腰肌劳损处理，不问盗汗与体重，不查叩击痛与神经。对策是把结核五项与神经五项做成必填。
- **外治禁忌漏查**：腰背痛直接上热敷与推拿，把稳定期推向活动期，甚至造成塌陷。对策是疑似结核一律不做温热与手法。
- **延误手术时机**：把截瘫早期的肌力下降解释为「卧床太久没力气」，错过减压窗口。对策是神经五项每次量化并对比。
- **固定过久**：以「不痛」为解除标准，长期卧床后骨量、肌力、肺功能一起下降。对策是制动医嘱写清复评节点与解除条件，并同步三项卧床期训练。

考核项三项：给三份病例，写出是否属结核、依据哪几项；指出其中一份的神经体征变化提示什么、第一个动作是什么；给一份「热敷加推拿加卧床」的处理，指出越界之处并改写。
