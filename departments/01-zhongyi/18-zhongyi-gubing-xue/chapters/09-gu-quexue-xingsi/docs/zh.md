# 第 9 章 · 塌陷是一条单行道，围塌陷期是唯一的岔口

> **MOTTO:** 「虚邪之入于身也深，久留而内著，内伤骨为骨蚀」——《灵枢·刺节真邪》
>
> **PROBLEM:** 股骨头坏死最贵的错误不是治不好，而是治得晚。症状轻、平片正常的那一段叫围塌陷期，此时软骨下骨尚完整，干预可以改变病程；一旦出现新月征与塌陷，结构改变不可逆，治疗目标就从「保髋」变成「重建」。本章给出四段刻度与四条红线，把「什么时候必须做磁共振」写成硬判据，因为这一步决定了后面全部选项。

**双根因定位:** 环境逼迫（本病好发于青壮年，主诉是腹股沟或臀部隐痛，与腰椎间盘突出、髋关节滑膜炎高度重叠，最省事的路径是先按常见病处理）+ 知识积累（「骨蚀」之名提示病在骨，但病变的血供机制要求把影像提前到症状之初，而传统诊法以症候为先，这一先后顺序需要重新训练）

## 一、从缺血到塌陷：一条可以标出刻度的线

股骨头的血供被切断或受损，骨细胞与骨髓成分死亡，修复反应随之启动；但修复的速度赶不上坏死范围扩大的速度，软骨下骨的力学支撑逐步下降，最终发生软骨下骨折与塌陷，继而继发骨关节炎。这条线可以标出四个刻度：

| 阶段 | 症状 | 平片 | 磁共振 |
|---|---|---|---|
| 早期（围塌陷期） | 轻微，负重后隐痛，可无跛行 | 常无异常 | 已可见坏死灶与水肿信号 |
| 塌陷前 | 疼痛持续，活动度受限 | 密度不均、硬化带 | 坏死范围清楚，可见双线征 |
| 塌陷期 | 疼痛明显，跛行，外展内旋受限 | 新月征、软骨下骨折、股骨头变扁 | 骨髓水肿广泛 |
| 塌陷后 | 疼痛与功能障碍固定 | 塌陷、关节间隙变窄、骨赘 | 继发退变表现 |

四个刻度里只有前两个是可逆的窗口。**围塌陷期概念的临床价值，就在于把干预的起点从「影像见到塌陷」提前到「影像见到坏死」。**这一步能否做到，取决于是否在症状之初就安排磁共振，而不是等平片出现异常。平片阴性不能排除——平片看的是骨小梁的密度变化，早期坏死在密度上还看不出来。

同一病理过程在儿童与青少年身上表现不同：胫骨结节骨骺炎（运动后膝下疼痛、胫骨结节处隆起压痛）、跟骨骨骺炎（足跟痛、跑跳后加重）、月骨坏死（腕背痛、握力下降）。它们的共同点是骨骺或短骨的血供相对薄弱，反复的牵拉与应力成为诱因，故处理的核心是**减负与时间**，而不是加大治疗强度。

磁共振上看到的「骨髓水肿」并不等于坏死，这一点决定了下判断的分寸。水肿可见于暂时性骨质疏松、应力反应、感染、肿瘤与创伤后改变；坏死的特征性表现是坏死灶本身（常有边界清楚的信号异常区与双线征）。因此磁共振报告写「骨髓水肿」时，不能直接读成「坏死」，要看有没有坏死灶、范围与部位是否符合股骨头的负重区。判据不清时的处置是短期复查影像并结合病史（激素、酒精、创伤），而不是先按坏死启动一整套治疗。

这也是本章反复强调「病史先行」的原因：影像给出的是形态，病史给出的是原因，两者对上才成为诊断。（底本 第9章·第1节）

## 二、采集项：三问病史、四个体征、一套影像

| 组 | 采集项 | 判读要点 |
|---|---|---|
| 用药史 | 糖皮质激素的种类、用药原因、使用时间与累积情况 | 激素性坏死常双侧，一侧确诊必查对侧 |
| 饮酒史 | 饮酒种类、频次、年限 | 「应酬多」不是量化，要问到频次与年限 |
| 创伤史 | 股骨颈骨折、髋关节脱位、髋部手术 | 创伤性者血供重建慢，需长期随访 |
| 其他 | 减压病、镰状细胞贫血、放射治疗、脂代谢异常 | 少见但改变处理路径 |
| 疼痛 | 部位（腹股沟深部、臀部）、是否向大腿前内侧或膝部放射、负重与休息的关系、夜间痛 | 以膝痛首诊者最易漏，实为髋部牵涉痛 |
| 体征 | 跛行、外展与外旋、内旋受限、肌萎缩、肢体长度 | 内旋受限出现较早，是敏感的体征 |
| 特殊试验 | 4 字试验、Thomas 征、滚动试验 | 阳性提示髋关节内病变，不指向具体病因 |
| 影像 | 平片（正位加侧位，看新月征与塌陷）、磁共振（坏死灶、双线征、水肿范围）、CT（软骨下骨折） | 有症状而平片阴性者，磁共振是必做项 |

「一侧确诊必查对侧」这句话要写进流程。激素性与酒精性坏死双侧受累并不少见，而对侧在早期往往没有症状；等到有症状时，另一侧可能已进入塌陷期。这不是过度检查，是把窗口用满。

量化饮酒史同样重要。「喝酒多」这类描述无法进入判断，需要问到频次与年限；同理，激素要问到用药原因——红斑狼疮、肾病综合征、器官移植后的长期用药，与前次短期冲击治疗，风险评估不同。

## 三、成组判据与四条红线

| 组 | 成立条件 |
|---|---|
| 高度疑似 | 激素或酒精或创伤史 + 腹股沟深部痛或内旋受限 + 平片正常或可疑 |
| 确诊 | 磁共振见坏死灶（或平片已见硬化带、新月征、塌陷） |
| 骨骺炎 | 青少年 + 特定部位（胫骨结节、跟骨、月骨）的局部压痛与负重痛 + 影像见骨骺改变 |

四条红线（教学设定，实际以机构制度与专科会诊为准）：

1. **腹股沟痛 + 激素史，平片正常**——必须做磁共振，不按「髋关节滑膜炎」观察。这一条是本章最核心的一条，因为它决定了是否还有保髋的机会。
2. **新月征或软骨下骨折**——转专科评估保髋手术，不再单纯观察与对症。结构的连续性一旦中断，保守治疗无法把它接回去。
3. **已塌陷且关节间隙变窄**——评估重建，不长期以保守治疗维持。此时的「再等等」只会让功能进一步丧失、手术难度上升。
4. **一侧确诊**——查对侧，无论有无症状。

## 四、外治与固定：免负重是主线，深部重手法是禁区

外治在本病的定位是缓解症状，不是改变病程。可以用的：温热类外治缓解髋周肌肉痉挛、轻手法松解阔筋膜与臀肌的紧张、局部敷贴缓解疼痛。禁区有三条：**深部重手法与暴力扳法**（髋关节内的病变经不起外力，且骨质疏松背景下有骨折风险）、**长期牵引**（卧床本身加速骨量丢失与肌萎缩）、**以「活血」为名的高强度局部刺激**（皮肤反应与疼痛加剧会掩盖病情变化的判断）。

免负重是这一章真正的治疗主线。方式有三：双拐（患侧完全不负重）、单拐（对侧持拐，部分减负）、支具（限制活动范围与负重）。三种方式的选择取决于分期与患者条件，但共同点是**必须量化**——拐要撑到什么程度、每天走多远、什么动作禁止（跑、跳、深蹲、盘腿、长时间站立）。只写「减少负重」，患者会理解为「少走几步」。

免负重的代价是肌萎缩，因此必须同步训练：等长收缩（股四头肌、臀中肌）、非负重关节活动（固定自行车、水中行走）、上肢与核心力量。训练与免负重是同一条医嘱的两半，缺一半就会在解除负重时出现新的问题——肌肉撑不住，关节负荷反而更大。

双拐与单拐的选择也有一条判据：病灶在单侧、需要把患侧负重降到最低的，用双拐；疼痛可控、只需减轻部分负荷的，用对侧单拐。用错侧是常见错误——拐杖应持在健侧，行走时与患侧同时落地，才能把重心移向健侧、减轻患髋的负荷。拐的高度以站立时手柄位于腕横纹附近为宜，过高会使肩部代偿、过低会造成躯干侧倾。这些细节没有一项需要设备，但每一项都直接影响减压效果。

停做指征：疼痛由负重痛转为静息痛、活动度进一步下降、出现交锁或弹响、训练后疼痛持续到次日。

## 五、记录字段、失效模式与考核

| 字段 | 写法要求 |
|---|---|
| 病史三问 | 激素（种类、原因、时间）、饮酒（频次、年限）、创伤，逐项量化 |
| 疼痛定位 | 腹股沟／臀部／向膝放射，写清与负重的关系 |
| 活动度 | 屈、伸、外展、内旋、外旋，与健侧对比并写度数 |
| 专科试验 | 4 字试验、Thomas 征，阳性／阴性 |
| 影像 | 平片与磁共振的序列、坏死部位与范围、有无新月征、是否查对侧 |
| 分期 | 围塌陷期／塌陷前／塌陷期／塌陷后，四者选一 |
| 负重方案 | 方式、程度、禁止动作清单 |
| 训练 | 动作、频次类别、进展条件 |

四条失效模式：

- **把骨病当劳损**：腹股沟痛按髋周肌肉劳损、膝痛按膝关节病处理，从未想到髋。对策是把「腹股沟深部痛 + 内旋受限」作为触发磁共振的组合。
- **外治禁忌漏查**：以重手法「松解」髋周，疼痛暂时缓解、病程照旧推进，患者以为在好转。对策是明确外治只缓解症状，分期判断不依赖症状缓解。
- **延误手术时机**：已见新月征仍继续保守，等塌陷后再评估。对策是把新月征写成转诊触发词。
- **固定过久**：长期拄拐完全不负重，肌肉萎缩到无法脱离辅助，解除负重即疼痛复发。对策是免负重与训练同时开、同时评。

考核项三项：给三份病例，写出分期与依据；指出其中哪一份必须做磁共振、为什么平片正常也不能排除；给一份「减少负重、口服活血药、观察」的处理，指出它缺了哪两项关键动作。
