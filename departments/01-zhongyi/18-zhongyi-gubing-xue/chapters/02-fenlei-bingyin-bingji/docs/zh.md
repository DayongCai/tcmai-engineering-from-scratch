# 第 2 章 · 「肾主骨」要落到三条可测的轴上，否则它只是一个结论

> **MOTTO:** 「肾者水也，而生于骨，肾不生则髓不能满」——《素问·逆调论》
>
> **PROBLEM:** 同一句「肝肾亏虚、痰瘀互结」，可以写进骨结核、骨肿瘤、骨关节炎三份完全不同的病历。写得出，是因为病机语言没有绑定证据。本章要求：每写一个病机判断，必须同时指出它落在哪一条轴上、证据是哪几项；三轴与两组证据填不满，病机结论不成立。

**双根因定位:** 环境逼迫（骨病的病因常常查不出来，临床上只能退回到「本虚标实」这类总纲，退得多了，总纲就代替了诊断）+ 知识积累（《内经》以「肾主骨」定病位，是一句高度压缩的判断，历代注家各有引申，若不把它拆成可观察的层次，学习者只能背原句而无法用它做鉴别）

## 一、分类轴不是背名称，它决定下一步查什么

骨病的分类有两根轴，各有各的用处，混着用就会背得很熟却不会用。

**病因轴**分六类：感染（化脓性骨髓炎、化脓性关节炎、骨与关节结核）、肿瘤（良性、恶性、瘤样病变）、代谢（骨质疏松、佝偻病、骨软化）、缺血（股骨头坏死、骨骺炎、月骨坏死）、退变与免疫（骨关节炎、类风湿、强直性脊柱炎、痛风）、畸形（斜颈、髋脱位、马蹄内翻足、脊柱侧凸）。这一轴的价值在于：**每一类对应一组不同的检查。**感染查血常规、红细胞沉降率、C 反应蛋白与穿刺培养；肿瘤查影像三征与活检；代谢查骨密度、血钙磷与碱性磷酸酶；缺血查磁共振；退变与免疫查抗体、力线与关节计数。

**部位与性质轴**分两组：按部位分脊柱、关节、四肢；按性质分良性、恶性、瘤样。部位轴决定「怎么查」——脊柱病必须查神经体征，四肢关节病必须查活动度与力线；性质轴决定「能不能动手」——良性可观察，瘤样病变需随访，恶性不在门诊做任何处置。

两根轴都分类正确，仍可能治错，因为分类不等于机制。把骨结核按化脓性感染治、把痛风性关节炎按感染治、把骨肉瘤的夜间痛按瘀血治，这三类错误都发生在「病名对了，机制反了」的时候。所以分类之后必须再走一步：这个病坏在哪一层。（底本 第2章·第1节）

## 二、把「肾主骨」拆成三条可测的轴

「肾主骨」是一句结论。要让它成为诊断工具，得拆成三条能被观察的轴，每条轴上有自己的症状、体征与影像：

**第一条，血供轴。** 肾精生髓，髓养骨，髓要靠血送达。这条轴上坏掉的是「送达」：激素、酒精、创伤、减压病都会切断股骨头的滋养血管，骨细胞在缺血中死亡，修复跟不上，于是塌陷。可观察的落点是：夜间静息痛、腹股沟深部痛、磁共振上的髓内信号改变、激素与饮酒史。股骨头坏死之所以叫「骨蚀」，正因为它先是供血的事，然后才是骨的事。

**第二条，物质轴。** 肾主水，主藏精，精生髓。这条轴上坏掉的是「原料」：钙磷代谢、维生素 D 的转化、骨基质的矿化。可观察的落点是：骨密度、身高较年轻时下降的幅度、脆性骨折史、血钙磷与碱性磷酸酶、日照与饮食结构。骨质疏松、佝偻病、骨软化都在这条轴上，它们的共同后果是骨量减少与骨结构变脆，中医统称「骨痿」并不牵强——痿是失养不用，不是被打断。

**第三条，负载与修复轴。** 肝主筋、脾主肌肉，筋骨肉三者共同承担负载。这条轴上坏掉的是「受力与修复的匹配」：力线不正、肌肉无力、体重过大、长期制动，都会让正常的负载变成异常应力，软骨磨损、骨骺受牵拉、畸形加重。可观察的落点是：步态、肌力分级、关节活动度、力线、跌倒史与制动史。

三条轴的意义在于：**凡说「肾虚」，必须能指出是血供、物质、负载三者中的哪一条出了证据。**指不出来，「肾虚」就只是一个结论，不能作为用药与固定的依据。反过来，三条轴可以相互加重：骨量低的人跌倒后骨折，制动又让骨量更低，这是骨痿最常见的恶性循环。

## 三、病因采集与成组判据

外因与内因，都要转成问诊与体检项，否则永远是两句空话。

| 类别 | 采集项 |
|---|---|
| 外因·六淫 | 居住环境潮湿与否、受凉后是否加重、疼痛与天气变化的关系、有无长期冷库或水下作业 |
| 外因·外伤劳损 | 职业与负重方式、重复性动作、既往扭伤与骨折、运动量近期是否骤变 |
| 外因·邪毒 | 近期疔疮、咽喉肿痛、龋齿、中耳炎、泌尿系感染、皮肤破损与手术史 |
| 内因·禀赋 | 家族中同类病、先天畸形、出生时臀位或产伤、发育里程碑 |
| 内因·肝肾 | 年龄、绝经年龄、生育次数、久病与长期用药（尤其糖皮质激素）、饮酒 |
| 内因·饮食劳倦 | 日照时间、奶类与豆制品摄入、是否严格素食、作息与夜班、体重变化 |
| 内因·情志 | 长期焦虑与失眠、病前重大生活事件（只作背景，不作病因结论） |

病机要分三层写，三层各有各的证据：气血津液层（气滞血瘀、气虚血亏、痰饮内生）、脏腑经络层（肾肝脾的虚实、经络阻滞的部位）、筋骨层（骨枯髓减、痰瘀毒聚）。三层不是并列的三个选项，而是从全身到局部的递进：气血是运行的载体，脏腑是化生的源头，筋骨是受损的终点。写病机时三层都要有，且每层只写一句，不堆形容词。

成组判据只做一件事：把「虚」与「实」从印象变成勾选。

| 组 | 证据项（勾选） |
|---|---|
| 虚 | 病程长、隐痛喜按、遇劳加重、形寒肢冷或潮热盗汗、舌淡或红少苔、脉沉细或细数、骨密度低、肌力下降、体重下降 |
| 实 | 痛有定处拒按、夜间加重、肿胀或肿块、皮温改变、舌暗有瘀斑、脉涩或滑数、影像见骨质破坏或明显增生、窦道渗液 |

两组并存，是本虚标实，骨病的大多数属此类；只有虚而无实，先排除器质性疾病再谈纯虚；只有实而无虚，先排除感染与肿瘤再谈纯实。

三条红线，触线即改方向（教学设定，实际以机构制度与专科会诊为准）：

1. **纯实证而病因未明**——有发热、消瘦、影像见骨质破坏，不做峻补，先查因。补住症状会把病灶藏起来。
2. **纯虚证而进行性加重**——夜间痛加重、体重持续下降、对症调补无反应，不继续按「虚劳」调，加影像与实验室。
3. **痰瘀互结的判断只建立在触诊上**——摸到硬块就写痰瘀，没有影像，判断不成立。肿块的性质由影像与病理定，不由手感定。

## 四、外治与固定的强度边界

病机不同，外治的强度就不同，这一条在临床上比选方更常出错。

虚证的外治宜温、宜缓、宜小面积：温熨、轻手法、短时敷贴，观察皮肤反应。虚证不宜大面积发泡、不宜重手法弹拨、不宜长时间牵引——虚证的骨本来就弱，外力一大就是新的损伤。

实证（瘀、痰、毒）的外治可以用活血化瘀类，但有四条禁忌必须逐条问：有无出血倾向与抗凝用药、皮肤是否完整、有无发热、局部皮温是否升高。四条任一不过，外治降级为制动。

停的判据写死四条：皮肤出现水疱或破溃、疼痛较原有程度明显加剧、出现发热、局部红肿范围扩大。任一条出现，停外治、复评、记录。

固定这一层，虚证与实证的代价不同。实证固定是「限制活动以保护修复」，虚证固定是「用进废退的加速器」——骨量低、肌力差的人一旦长期固定，肌肉萎缩与骨量丢失会同时发生，拆除固定后反而更容易跌倒。所以虚证的固定必须同日安排等长收缩与邻近关节活动，原则是**不动关节动肌肉，不负重也用力**。固定的解除条件要写影像与负重能力两条，不能只写「不痛」。

## 五、记录字段、失效模式与考核

| 字段 | 写法要求 |
|---|---|
| 三轴归类 | 病因轴（六类之一）、部位轴、性质轴，各写一个 |
| 轴上的证据 | 血供／物质／负载三条轴，各写「有证据／无证据／未查」，不得留空 |
| 虚实勾选 | 虚组与实组各勾选至少两项，或注明「不足两项」 |
| 病机三层 | 气血津液、脏腑经络、筋骨三层各一句，每句带证据 |
| 外治强度与禁忌 | 强度级别、四条禁忌逐条核对结果 |
| 固定方案 | 目的、复评节点、解除条件三件事 |
| 复评 | 下次复评看什么、什么情况提前来 |

四条失效模式：

- **把「肾虚」当诊断终点**：写了肾虚就开补，不写落在哪条轴、证据是什么。对策是「轴上的证据」一栏不填不许下病机。
- **只辨证不查因**：把骨肉瘤的夜间痛辨成瘀血阻络、把结核的低热辨成阴虚发热。对策是纯实证与纯虚证都要过红线。
- **病机套模板**：每个病都写「肝肾亏虚、痰瘀互结」，读者看不出这个病和那个病的分别。对策是三层各一句、每句带证据，写不出证据的那一层就删掉。
- **固定期不做肌肉维持**：虚证患者固定一段时间后肌力与骨量双降，拆固定即跌倒。对策是把等长收缩写进固定医嘱，与固定同时开始。

考核项三项：给四个病例，写出三轴归类与每条轴上的证据；对每个病例勾选虚实两组证据并给出本虚标实的层次；指出其中一个病例的病机判断为何不成立、缺的是哪一项证据。

## 代价与边界

1. 六类病因与三条轴是教学用的组织方式，不是严格的疾病分类学；同一疾病可跨类，如骨巨细胞瘤既属肿瘤也具侵袭性。
2. 「虚」「实」两组证据是本章自设的教学判据，用于训练勾选习惯，不等同于任何一家学派的辨证标准。
3. 三条轴只覆盖骨病的主要机制，遗传性骨病、药物性骨损害等另有专门路径，不在本章范围内。
