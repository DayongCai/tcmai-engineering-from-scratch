# 第 5 章 · 化脓的病，要先问脓积在哪一层

> **MOTTO:** 「大热不止，热胜则肉腐，肉腐则为脓」——《灵枢·痈疽》
>
> **PROBLEM:** 同一个「热毒炽盛」，在骨髓腔里、在骨膜下、在关节腔里，后果是三件不同的事：死骨、软组织脓肿与窦道、关节软骨溶解。三者的处理不同，判断的依据不是热势高低，而是脓的位置。本章要求把「脓在哪一层」写成一条必答的记录项，答不出来就不算完成诊断。

**双根因定位:** 环境逼迫（这类病起病急、进展快，接诊时最响的信号是体温与剧痛，位置这一层常被跳过）+ 知识积累（中医对本病的认识从「附骨痈」「附骨疽」的病名入手，痈与疽的分别本身是层次判断，但后世教材把重点放在证型上，层次这一层反而淡了）

## 一、三个层次，三种结局

化脓性感染在骨内起步，走哪条路，决定了留下什么后遗症。

**骨髓腔与骨膜下。** 感染多起于长骨干骺端，此处血运丰富、血流缓慢，病原容易滞留。脓在骨膜下积聚，把骨膜掀起，骨皮质因此失去来自骨膜的血供，一段皮质变成死骨。脓若穿破骨膜进入软组织，形成脓肿，再穿破皮肤即成窦道；窦道反复排脓、时闭时开，就是慢性骨髓炎的样子。所以慢性骨髓炎的核心不是「反复感染」，而是**死骨与窦道并存**——死骨不去，窦道不愈。

**关节腔。** 干骺端的感染可以越过邻近关节，也可以由外伤、穿刺、手术直接带入。脓性渗出物中的蛋白溶解酶会分解软骨基质，软骨一旦溶解不能再生，结局是关节间隙变窄、纤维性强直或骨性强直。这就是化脓性关节炎与化脓性骨髓炎的分野：前者毁的是关节，后者毁的是骨干。

**软组织。** 脓若停留在软组织内而未穿破皮肤，表现为局部肿胀、波动感、皮温升高而皮色可不红——这一层最容易被当成「扭伤后血肿」。儿童的患肢拒动、假性瘫痪，往往就是这一层的表现。

因此「脓在哪一层」这一问，实际在问三件事：血供是否已断（决定药物能否到达）、有无需要引流的腔隙（决定要不要手术）、以及哪一处结构将被永久破坏（决定复评时看什么）。（底本 第5章·第1节）

## 二、采集项：体温、四征、压痛最重处、穿刺、影像的时间差

| 组 | 采集项 | 判读要点 |
|---|---|---|
| 全身 | 体温（按班次测并画曲线）、寒战、精神与意识、食欲与呕吐、尿量 | 体温曲线的形态比单次最高值有用；寒战提示菌血症 |
| 局部四征 | 红、肿、热、痛，加患肢拒动 | 深部感染可以「红不明显而压痛极重」，四征不全不能排除 |
| 压痛最重处 | 定位到骨端还是关节、有无波动感 | 压痛最重处通常在干骺端；波动感提示脓已到软组织 |
| 关节 | 肿胀、浮髌、主动与被动活动度、拒动程度 | 关节被动活动即剧痛，是关节内感染的强信号 |
| 穿刺 | 部位、抽出物性状（脓性／浑浊／血性）、送涂片与培养 | 穿刺是分层最直接的手段，抽到脓即定层 |
| 影像 | 平片、CT、MRI，注明距起病的时间 | 平片早期常无异常，破坏多在起病一段时间后才显现；MRI 可较早显示髓内水肿与骨膜反应 |
| 实验室 | 白细胞与中性粒细胞、红细胞沉降率、C 反应蛋白、血培养 | 炎症指标用于判断活动度与治疗反应，不用于定位 |

这张表里最需要反复讲的是影像那一行。**「片子正常」不能排除本病**，因为平片看到的是骨的反应，而骨的反应需要时间；起病初期，髓内已经水肿、脓已经积聚，平片却可能一片干净。这就是为什么在儿童高热、患肢拒动、干骺端压痛极重的情况下，不能凭一张正常平片写下「观察」。

穿刺是分层的关键动作，但有三条纪律：避开将要手术的切口线路、避开血管神经走行、抽出物必须同时送涂片与培养。抽不到脓不等于没有脓——针尖可能停在脓腔之外，此时应结合 MRI 判断，而不是宣布排除。

儿童与成人的表现差别要写在采集项旁边。儿童的骨膜厚、血运丰富，脓容易被局限在骨膜下，全身反应重而局部体征相对不明显，患肢拒动往往是最早的信号；成人骨膜薄，脓更容易穿破进入软组织，局部肿胀与窦道出现得早，而全身反应可以很轻。同一本病，一个是「全身重、局部轻」，一个是「局部重、全身轻」，采集的侧重因此不同：儿童盯体温与拒动，成人盯肿块与窦道。

## 三、成组判据与「必须手术」的红线

三组判据，每组要求全身、局部、实验室或影像三方同时具备：

| 组 | 成立条件 |
|---|---|
| 急性骨髓炎 | 高热寒战 + 干骺端深压痛与患肢拒动 + 白细胞与 C 反应蛋白升高 + 穿刺见脓或 MRI 见髓内水肿 |
| 慢性骨髓炎 | 窦道反复排脓 + 局部反复红肿 + 影像见死骨与包壳形成 |
| 化脓性关节炎 | 关节肿胀积液 + 被动活动即剧痛 + 穿刺见脓性液 + 全身中毒表现 |

四条红线，触线即转，不在门诊继续观察（教学设定，实际以机构制度与专科会诊为准）：

1. **高热 + 意识改变或血压下降**——疑似脓毒症。急诊处理，第一位是全身支持与感染源控制，不是调整方药。
2. **关节穿刺抽出脓液**——急诊引流冲洗。关节软骨被溶解的过程不可逆，拖延的代价直接写在关节间隙上。
3. **儿童干骺端压痛 + 拒动 + 发热**——按急性骨髓炎处理并转诊，不按「生长痛」「扭伤」「滑膜炎」观察。这一条是本章最常见的漏诊入口。
4. **窦道 + 影像见死骨**——转专科评估手术。死骨是感染的载体，不取出则窦道不可能真正愈合，反复换药只是把时间拉长。

四条之外的两种「不该急」也要写清：慢性骨髓炎的稳定期，窦道闭合、无全身症状者，可以按计划评估而非急诊；化脓性关节炎引流后的恢复期，关节肿胀会持续一段时间，不等于感染未控，判断要看体温、疼痛性质与炎症指标的走向。

## 四、外治与固定：化脓期禁热，制动不等于长期石膏

外治在这一章只有一句话最重要：**化脓期禁用一切温热**。热敷、熏洗、热熨、理疗、拔罐，全部禁用，理由是热使局部血流增加、组织张力上升，把骨膜下或关节内的脓推向软组织与血流。膏药与推拿同样禁用——前者封闭皮肤、妨碍引流与观察，后者可以直接压破骨膜下的脓腔。

允许使用的外治只有两种：制动与冷敷。制动用夹板、支具或皮牵引，目的是减轻疼痛、防止病理性骨折与畸形；冷敷用于急性肿胀，以减轻张力，不作治疗手段宣传。

固定的边界要写清三件事。目的：本期固定是「减痛与防折」，不是「等骨愈合」，因此不需要长到骨愈合的程度。复评节点：体温、局部四征、疼痛性质、炎症指标，四项一起看。解除条件：全身症状控制、局部红热消退、疼痛由静息痛转为活动痛、影像上无进行性破坏。四条同时具备才逐步解除，解除后立即开始关节活动度训练。

固定过久在这里的代价格外具体：关节僵硬、肌肉萎缩、废用性骨量丢失，儿童还有骨骺受压的风险。所以「等它彻底好」这句话在化脓性骨髓炎里是错的——彻底好的标志是功能恢复，不是固定到期。

慢性期的外治另有一套边界：祛腐生肌类的敷料可以用，但窦道引流不畅时不用封闭性敷料；换药时记录窦道的深度、方向、分泌物的性状与气味，这些是判断引流是否充分的依据。

停做指征：皮肤破溃流脓（转引流评估）、固定远端麻木或肤色改变、体温反复、局部红肿范围扩大。

## 五、记录字段、失效模式与考核

| 字段 | 写法要求 |
|---|---|
| 脓的层次 | 骨髓腔／骨膜下／软组织／关节腔，四者选一并写依据 |
| 体温 | 曲线形态与最高值，注明测量班次 |
| 局部四征 | 红、肿、热、痛逐项，加拒动与波动感 |
| 压痛定位 | 干骺端或关节，左右与具体部位 |
| 穿刺 | 部位、性状、是否送涂片与培养 |
| 影像 | 序列、距起病时间、关键征象；写明「平片阴性不排除」 |
| 外治与固定 | 种类、起止、皮肤反应、解除条件 |
| 转诊判断 | 是否触线、触哪一条、转往何处 |

四条失效模式：

- **把骨病当劳损**：儿童拒动被记成「扭伤后不愿走」，成人深部压痛被记成「肌肉拉伤」。对策是压痛定位到骨端、并把体温列为必填。
- **外治禁忌漏查**：发热未问就上热敷，把骨膜下脓肿推进软组织。对策是外治前四条禁忌逐条核对，化脓期一律不用温热。
- **延误手术时机**：窦道与死骨并存仍反复换药，或关节积脓仍以口服药观察。对策是把「死骨」「关节积脓」写成触发转诊的关键词。
- **固定过久**：以「不痛了再说」为解除标准，关节僵硬后再花更长时间康复。对策是固定医嘱写目的、节点、解除条件，并同步非感染关节的活动。

考核项三项：给三份病例，写出脓的层次与依据；指出其中哪一份触线、触哪一条、第一个动作是什么；给一份「热敷加推拿加口服药」的处理，指出越界之处并改写为合规处置。

## 代价与边界

1. 本章讲分层与边界，不给具体方药与用药方案，具体证治在第 4 章的内治框架与专科教材中完成。
2. 分层判断在多数情况下可由穿刺与影像确定，但深部病灶、儿童与免疫低下者的表现常不典型，此时应按「疑似」处理并转诊，而不是等待典型化。
3. 四条红线是教学设定的下限判据，不构成手术适应证的全部；引流方式与时机由专科决定。
4. **免责声明：** 本章为教学整理，不构成诊疗建议，不能替代医师面诊、影像判读与专科会诊。
