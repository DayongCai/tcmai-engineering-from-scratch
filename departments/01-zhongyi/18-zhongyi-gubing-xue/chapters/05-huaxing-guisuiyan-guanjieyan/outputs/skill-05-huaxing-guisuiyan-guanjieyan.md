# 化脓的病，要先问脓积在哪一层

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 8 道题自检，答不上就回到对应小节。

## 核心判据

- 骨髓腔与骨膜下
- 死骨与窦道并存
- 「片子正常」不能排除本病
- 高热 + 意识改变或血压下降
- 关节穿刺抽出脓液
- 儿童干骺端压痛 + 拒动 + 发热

## 边界

- 本章讲分层与边界，不给具体方药与用药方案，具体证治在第 4 章的内治框架与专科教材中完成。
- 分层判断在多数情况下可由穿刺与影像确定，但深部病灶、儿童与免疫低下者的表现常不典型，此时应按「疑似」处理并转诊，而不是等待典型化。
- 四条红线是教学设定的下限判据，不构成手术适应证的全部；引流方式与时机由专科决定。
- 本章为教学整理，不构成诊疗建议，不能替代医师面诊、影像判读与专科会诊。
