## 一、学科定位

中医外科学研究中**发生于体表及某些内在脏腑**的外科疾病，理论核心是整体观念与辨证论治：病位在体表，病因却常根于脏腑气血阴阳的失调。

本课程把它拆成三件可训练的事：

1. **归科与边界**（第 1 章）——一个体表病灶凭什么归外科、什么时候该转走；
2. **判据**（第 2–3 章）——病名按什么取、深浅在哪一层、阴阳与脓的窗口怎么判；
3. **手段**（第 4 章 + 各论）——消托补的时间轴，外治与切开的时机与指征。

## 四、章节契约（每章必须满足）

```text
chapters/NN-<slug>/
├── docs/zh.md      # MOTTO / PROBLEM / 环境逼迫 / 知识积累 + 经典引文（《书·篇》级）
│                   # + 「代价与边界」 + 免责声明 + 验证段（章内相对命令）
├── code/main.js    # 读 standards/waike/units.json 现算本章规模与词频，退出码 0
├── code/main.test.js # node --test，≥5 项断言，锁规模/重心/引书/数值
├── quiz.json       # 恰好 6 题 = 1 pre + 3 check + 2 post
└── outputs/        # prompt-<slug>.md（H1 + ## 用途）+ skill-<slug>.md（frontmatter name=基准名）
```

**写作口径（本学科特有）**

- 三辨＝**病因 / 病机 / 局部表现**；四位面＝**皮肤 / 筋肉 / 脏腑 / 全身**（不是病理学的细胞-组织-器官-系统，那套与教材语言错位）；
- 数字一律由 `code/main.js` 从单元层现算，正文不手打；
- 手术与外治只写**时机、指征、禁忌**，不写剂量与操作步骤；
- 每章必须有「代价与边界」——只报喜不报忧的章节不算写完（L3 门会拦）。
