> **MOTTO:** 「营气不从，逆于肉理，乃生痈肿」——《素问·生气通天论》
>

## 一、范围不是按「病」划的，是按「有没有看得见的病灶」划的

《周礼·天官》设疡医一职，所掌为「肿疡、溃疡、金疡、折疡」。四类里，肿疡是未溃之肿，溃疡是已溃之疮，金疡是金刃所伤，折疡是骨折筋伤。后两类今天已归创伤与骨伤，前两类仍是外科的主体。这条线索很要紧：外科的边界从来不是按脏腑、按病种划的，而是按两件事划的——**病灶在体表可见、治疗要动手**。

教材现行七大类是这条线索的现代版本：疮疡、乳房疾病、瘿瘤岩、皮肤病、肛门直肠疾病、泌尿男性疾病、周围血管疾病；七类之外另列烧伤、冻疮、毒蛇咬伤、破伤风、肠痈等。七类之间有明确的西医对照，这是临床沟通的基础，也是转诊语言的来源：

| 类别 | 代表病证 | 西医对照 |
|---|---|---|
| 疮疡 | 疖、疔、痈、有头疽、丹毒、走黄、内陷、瘰疬、流注、附骨疽 | 毛囊炎与脓肿、急性淋巴结炎、脓毒症、骨与关节感染 |
| 乳房 | 乳痈、乳癖、乳岩、乳衄、粉刺性乳痈 | 急性乳腺炎、乳腺增生病、乳腺癌、导管内乳头状瘤 |
| 瘿瘤岩 | 气瘿、肉瘿、石瘿、血瘤、肉瘤、失荣、肾岩 | 甲状腺肿、甲状腺腺瘤、甲状腺癌、血管瘤、恶性肿瘤 |
| 皮肤 | 蛇串疮、湿疮、瘾疹、白疕、油风、粉刺、酒齄鼻、药毒、疥疮 | 带状疱疹、湿疹、荨麻疹、银屑病、斑秃、痤疮 |
| 肛门直肠 | 内痔、外痔、混合痔、肛痈、肛漏、肛裂、脱肛、锁肛痔 | 痔、肛周脓肿、肛瘘、肛裂、直肠脱垂、直肠癌 |
| 泌尿男性 | 子痈、精浊、精癃、血精、阳痿、不育、水疝 | 附睾炎、前列腺炎、良性前列腺增生、鞘膜积液 |
| 周围血管 | 臁疮、脱疽、股肿、青蛇毒、筋瘤 | 静脉性溃疡、动脉硬化性闭塞与糖尿病足、深静脉血栓、浅静脉炎、静脉曲张 |

这张表要读出三层意思。第一层，**归口决定路径**：乳岩归外科，不等于进门就开刀，而是先进病理；肠痈归外科，不等于进门就手术，而是先看有没有腹膜刺激征；股肿归周围血管，不等于只做外敷，而是先排除肺栓塞。第二层，**边界是互补而非对立**：与内科的分界在「有无局部病灶、是否以外治为主」，与西医外科的分界在「手术是手段之一，且要讲适应证」。第三层，**交叉病按主要矛盾归口**：丹毒既在疮疡又在皮肤，脱疽既在周围血管又常是糖尿病足，教材的处理是按当下最危险的那一面归口，不是按书本目录归口。

## 二、入口评估：局部七项、全身五项

外科的第一次接触，动作顺序是视、问、触，触诊放最后且要轻——先按压会让红肿变形，也会改变患者对疼痛的描述。要看的局部项目固定为七项，缺一项就会在后面某一步付代价：

| 项 | 怎么看 | 读什么 |
|---|---|---|
| 部位 | 分区记录：头面颈项、胸腹胁肋、腰背、上肢、下肢、二阴 | 决定归经与风险（头面感染易向深部蔓延，下肢多湿热，二阴多涉及肛肠泌尿） |
| 形态 | 高突、平塌、漫肿、凹陷、翻花、菜花状 | 高突根脚收束多为阳证浅位；平塌散漫多为阴证深位；翻花要想到岩 |
| 大小与边界 | 以标尺量长、宽、高；看边界清不清、根脚收束与否 | 边界清楚者易局限，边界不清者易扩散；尺寸是复诊比较的唯一硬指标 |
| 色泽 | 鲜红、暗红、紫黑、皮色不变、苍白 | 鲜红灼热属热毒；不变或苍白属寒凝或虚；紫黑提示血瘀或坏死 |
| 温度 | 以手背对比健侧，同高同压 | 灼热与不热是阴阳最省力的一项判据 |
| 质地与活动度 | 软、韧、硬；推之移与不移；与基底、皮肤是否粘连 | 硬而推之不移、与基底粘连，是恶变可疑的核心组合 |
| 压痛与波动 | 由轻到重，周围向中心；有无按之应指 | 应指＝脓成；痛如鸡啄＝脓熟将溃 |

全身五项则是把局部放回人身上：发热与寒战、神志与精神、饮食与二便、舌象、脉象。再加两项常被漏掉但极有价值的：近期体重变化、夜间痛是否加重。这两项不指向某一个证型，指向的是「这个病灶可能不是感染」。

局部七项与全身五项合起来，才构成一次完整的入口评估。只写「红肿热痛」四个字，等于七项里只做了一项半。

## 三、成组判据：单项不可判，三组才能立论

外科判据的用法不是「对号入座」，是成组比对。三组判据各有各的用途，不能互相替代：

**归口组**——部位、形态、病程三者合看。同是红肿，长在颈侧、三天、边界清，归疮疡里的颈痈；长在乳房、两个月、边界不清、随情绪消长，归乳房疾病的乳癖；长在足趾、半年、皮色紫暗发凉，归周围血管的脱疽。三者缺一，归口就会漂。

**阴阳组**——色泽、温度、肿势、疼痛性质、脓液稠稀五项合看，落阳证、阴证或半阴半阳。教材给的是九项对照，实际操作里最省时的是温度与肿势两项，最容易骗人的是色泽一项（照片、灯光、肤色差异都会改写判断）。

**风险组**——局部形态加全身五项，判断是否已经越出「外科门诊」的边界。

由此得到三条红线。写法上有个规矩：每条红线必须能被一个实习生在床旁用三项以内的事实触发，否则它只是口号。以下为教学设定，实际执行以所在机构制度为准。

1. **恶变可疑线**：质地坚硬、推之不移、与基底粘连，或表面翻花、溃后渗血腥臭，或伴夜间痛加重与体重下降。触发后停一切刺激性外治，转病理与影像，不按痈疽消托补处理。
2. **全身中毒线**：高热寒战、神志改变（烦躁、谵语、嗜睡），同时疮顶忽然平塌、肿势向周围漫散、边界消失。这是走黄与内陷的形态，转急诊，不在门诊换药观察。
3. **脏器并发症线**：腹痛拒按并出现腹膜刺激征（肠痈）、尿闭与下腹胀痛（精癃）、单侧下肢肿胀同时胸痛气促（股肿）。三条都指向「先救命、再治病」。

## 四、第一次外治只做三件事，以及四种停手条件

总论章最容易写成著作提要，实际上它要交付的是一个可执行的开场动作。第一次接触，外治只做三件：**清洁、覆盖、制动抬高**。清洁用等渗冲洗，覆盖用不粘连敷料，下肢病灶抬高。不开刀、不挤压、不上腐蚀性药物——理由不是保守，是因为在归口与风险未定时，任何刺激都可能把「可局限的感染」推成「扩散的感染」，也可能把「岩」按「痈」处理。

停手条件要写成可观察的事实，不写成感觉：

- 诊断未定、尤其恶变可疑未排除时，停一切刺激性外治，只做保护性覆盖；
- 红肿越过皮肤上画的标记线，停敷贴，改为重新评估（不是加药）；
- 疼痛由胀痛转为跳痛、触诊出现波动感，停观望，准备切开引流；
- 敷贴后出现水疱、瘙痒向周围扩散，停该药，按接触性皮炎处理并记录。

记录字段固定为八列加两列：部位、大小（长×宽×高）、形态、色泽、温度、质地与活动度、压痛与波动、脓（有无、色、质、味）；外加标记线（画在皮肤上的边界与日期）、全身项（体温、精神、饮食）。画线这一步常被省略，代价是复诊时只能说「好像小了一点」。画了线，边界每天可复测，变化可读、可对照、可交接。

## 五、四种失效模式与五项考核

失效模式比正确路径更值得先记，因为它们都是「看起来在做外科」：

**以病名代替判断。** 一句「这是个痈」，就跳过了归口、阴阳、风险三组判据。病名是结论，不是依据；先有依据再落病名，顺序反了就是背书的姿势。

**以流派偏好代替辨证。** 学《外科全生集》就一律温通，学《外科正宗》就一律寒凉。三派各有边界：全生派长于阴疽，正宗派长于阳证与刀针，心得派长于温病思路救危证。偏好一旦固定，判据就退化成口号。

**把岩当痈。** 坚硬、不移、翻花的肿块按痈去消、去托、去补，最坏的后果不是无效，是延迟病理。这条失效的链条通常是：按炎症处理 → 短期似有缓解 → 复诊时已错过窗口。

**入口漏项。** 只写「红肿热痛」，不写大小、边界、活动度。三个月后回看，谁也无法判断是好转还是进展。

对应的五项考核，每项都要求动手而不是复述：

1. 给一张病灶照片加三句话病史，限时填完八列字段，缺项即为不合格；
2. 说出七类归口各自的至少两条依据，并指出一个交叉病该按什么归口；
3. 写出三条红线各自的三项触发事实；
4. 说出第一次外治的三件事与四种停手条件；
5. 举出「把岩当痈」的完整后果链，不少于三步，并指出在哪一步可以截断。

## 六、代价与边界

1. **七类划分本身有交叉**。丹毒、脱疽、肠痈都能同时落在两类里，归口只能按主要矛盾，不能求一个干净的分类。教材目录是教学秩序，不是疾病的真实边界。
2. **源流叙述极易变成人名年表**。本章只取「范围与判据怎么变」这一条线索：《周礼》给四类，《外科精要》把内因与脾胃摆进来，《外科正宗》把刀针与托法做成体系，《外科全生集》以阴阳立纲，《疡科心得集》把温病思路引入外科。著作本身的提要留到专门章节，本章不做堆叠。
3. **红线不是诊断**。三条红线只回答「要不要马上转」，不回答「是什么病」。把红线当诊断用，会制造另一种延误。
4. **入口评估依赖条件**。光线、角度、标尺、拍摄距离不固定，「色泽」「大小」就不可比；下乡与远程随访尤其如此，这一点在第 13 章会具体展开。
5. **本章不含任何病证的治疗方案**。出现具体用药与外治处方，都属于后面各章的范围，且必须由医师面诊决定。
