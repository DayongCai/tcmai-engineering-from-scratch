# 归科五问 · 可装载技能

## 何时装载

- 拿到一个体表病灶（疮、肿、斑、瘘、痛、溃口），需要判断「这是不是外科的事」；
- 需要在辨证之前先说清「有没有外治指征」「现在该不该转走」；
- 教学场景：让学生练习把描述与判断分开。

## 输入

至少提供：**部位**、**形态**（红肿/平塌、有脓/无脓、边界）、**病程**（起病几天、有无发热）、**既往**（消渴、脾虚、术后、外伤）。

缺项不猜：缺哪一项就在输出的「该补的检查」里写清。

## 五问（顺序固定）

1. **位**：体表可观察，还是内部需影像？
2. **形**：阳证（红肿高突、灼热、边界清）还是阴证（平塌漫肿、不热、边界不清）？成脓否？
3. **可外治否**：已成脓 → 切开引流指征；未成脓 → 外敷/熏洗/挂线指征。
4. **内因**：脏腑气血阴阳哪一层失调？正虚能否托毒？
5. **急缓**：走黄、内陷、扩散征象（高热、神昏、肿势迅速蔓延、疼痛剧增）。

## 输出模板

```text
归科：<外科 / 内科 / 两科共管>
依据：位—…；形—…；外治—…；内因—…；急缓—…
该补的检查：<缺项>
不该做什么：<例如未成脓不宜切开；阴证不宜纯用寒凉>
```

## 判定规则（可执行）

| 条件 | 结论 |
|---|---|
| 第 5 问命中任一项 | 归科一栏写「急症·外科急诊」，输出止于转诊建议，不再推演方药 |
| 第 2 问「无脓」且第 3 问无外治指征 | 内治为主，第 4 问的结论决定消法与托法的取向 |
| 第 2 问「已成脓」 | 外治为主（切开引流），内治为辅（托毒/补虚） |
| 第 1 问「需影像/内镜」 | 不属本章能力范围，标注「需专科评估」 |
| 五问里有 ≥2 项缺失 | 输出「不足以定归科」，只给补检查清单 |

## 反例（必须拒绝的三种输出）

1. 只给病名不给依据（「这是痈」——五问一项没答）；
2. 越过第 5 问直接开方；
3. 把「有外治手段」当成「必须手术」，或反过来用内治拖延已成脓的病灶。

## 边界

本技能只做**归科与急缓**判断，不产诊断、不给剂量、不替代面诊。任何涉及切开、引流、挂线的操作，必须由具备资质的医师在面诊后决定。教材依据：第 1 章 1.1.2（与内科、与西医外科的边界）与 1.4.1（病证单元学习法）。
