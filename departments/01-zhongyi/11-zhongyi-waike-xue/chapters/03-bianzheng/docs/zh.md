# 第 3 章 · 辨证：外科的判据长在「看得见的地方」

> **MOTTO:** 「善诊者，察色按脉，先别阴阳」——《素问·阴阳应象大论》
>
> **PROBLEM:** 本章 7 个单元分成三块：阴阳 2 个（3.1.1、3.1.2）、部位与经络 2 个（3.2.1、3.2.2）、局部 3 个（3.3.1–3.3.3）。阴阳一节给的是九项对照表，九项乘两列共十八格；但对「现在切不切」这个决定真正起作用的只有两格——脓之稠稀、溃后收口。十八格背完却抓不住这两格，辨证就停在形容词层面。
>
> **双根因定位:** 环境逼迫（外科的病灶是露在外面的，患者与家属都看得见、都会问「这是什么」，判断必须能被指认、能被复述，不能停留在「我觉得像虚证」）+ 知识积累（判据一路细分：《疡医大全》把「先审阴阳」立为纲领，《疡科心得集》按上中下三部分配病因，教材再把局部拆成肿、痛、脓、痒、麻木、溃疡、出血七项，每一项都要分型）

**教材出处:** 教材·第 3 章（3.1 阴阳辨证、3.2 部位与经络辨证、3.3 局部辨证，共 3 节 7 单元）。

## 一、阴阳：十八格的表，重心在两格

教材不主张背「阳证＝红」，而是给一张九项对照表，让判断落在可比的项上：

| 对照项 | 阳证 | 阴证 |
|---|---|---|
| 起病与病程 | 急、短 | 缓、长 |
| 病位深浅 | 皮肉浅表 | 筋骨、脏腑 |
| 局部色泽与温度 | 鲜红、灼热烫手 | 不变或苍白、不热或微热 |
| 肿势形态 | 高突、根脚收束、境界清 | 平塌漫肿、根脚散漫、境界不清 |
| 疼痛性质 | 剧烈、得冷则舒 | 隐痛酸痛、得温则适 |
| 脓液 | 稠厚、色黄白、略带腥味 | 稀薄、色白或污浊 |
| 溃后 | 易脓易溃易敛 | 难脓难溃难敛 |
| 全身 | 发热、口渴、便秘溲赤 | 不热或畏寒、便溏 |
| 舌脉 | 舌红苔黄、脉数有力 | 舌淡苔白、脉细弱 |

这张表最有用的一列是「溃后」。**易脓易溃易敛**不只描述当下，它预测病程：脓能成、能溃、能收，说明气血还够用；难脓难溃难敛，说明后面要走的托与补会比预期长。临床排班、换药频次、家属沟通的预期，都该按这一列来定。

阴阳辨证最容易漏的一格是**阳中伏阴**：阳证后期气血耗伤，局部红肿渐减而漫肿不消，脓水转清稀。此时若继续一味寒凉攻伐，就把「余毒未清」按「热毒炽盛」治了。这一格的价值是提醒：红肿退了不等于痊愈，方向可能已经从清热转到托补。

还有一处必须提前声明：**局部红而脉沉细无力、精神委靡者，不可遽断为阳证**。局部与全身不一致时，以全身为重，这是阴阳辨证里唯一一条优先级规则。

## 二、部位与经络：先定「哪一块」，再定「哪条经」

部位辨证给的是病因倾向，《疡科心得集》的三句话是原始出处：

- 上部（头面、颈项、上肢）多属风温风热，风性上行；
- 中部（胸腹、胁肋、乳房）多属气郁火郁，气火俱发于中；
- 下部（腰以下、下肢、二阴）多属湿火湿热，湿性下趋。

| 部位 | 病因倾向 | 常见病 | 用药方向 |
|---|---|---|---|
| 上部 | 风温、风热 | 颜面丹毒、痄腮、颈痈、风热疮、油风早期 | 疏风清热，轻清上扬，佐升提引经 |
| 中部 | 气郁、火郁 | 乳癖、乳痈气郁化火、瘿瘤、腋痈 | 疏肝理气、解郁散结、清泻肝火 |
| 下部 | 湿火、湿热 | 臁疮、脱疽、肛肠病、子痈 | 清热利湿，佐以升提 |

教材在表后特意加了反例：上部也有火毒炽盛者，颜面疔疮来势迅猛、肿势散漫，非单纯风热可比，当以清热解毒为主，不可一味疏风发散。这一句把部位辨证从公式拉回参考——部位给的是概率，不是结论。

经络辨证解决两个问题：**归经**与**引经**。归经看循行：前额面颊属阳明，头侧耳周属少阳，后枕项背属太阳；乳头属肝、乳房属胃；颈侧属少阳肝胆；下肢内侧属三阴、外侧属三阳；肛门属大肠与督脉。引经看药向：太阳用羌活、阳明用白芷升麻葛根、少阳用柴胡、厥阴用吴茱萸川芎、下肢用牛膝独活。

两件事合起来的用法是：**先据部位定脏腑，再据经络选方向**。乳痈从肝胃，瘰疬从肝胆，脱疽从下肢三阴——这些结论都不是背出来的，是循行推出来的。

## 三、局部七征：每一项都要分型，不能只描述

局部辨证是本章的主体，教材把征象拆成七项，每项都要求「分型＋判读」两步：

| 征象 | 分型 | 判读要点 |
|---|---|---|
| 肿 | 成因：火、寒、风、湿、痰、气、瘀血、郁结；形态：高突／平塌／漫肿 | 形态定阴阳与深浅，成因定消法方向。肿高而软者发于肌肉，肿下而坚者发于筋脉，肿平而肉色不变者毒附于骨 |
| 痛 | 性质：刺痛、灼痛、裂痛、钝痛、酸痛、胀痛、绞痛、啄痛、掣痛；时间：卒发／绵绵、昼／夜 | 啄痛（痛如鸡啄）是脓熟信号；夜间痛甚多属阴证、血瘀或骨痨深脓 |
| 脓 | 有无（应指与否）、稠稀、色、味 | 稠黄有腥为气血尚充；清稀污浊为正虚毒深 |
| 痒 | 风、湿、热、虫、血虚 | 风痒走窜、湿痒滋水、热痒焮红、虫痒夜甚、血虚痒干燥脱屑。溃后作痒而脓将尽，是毒尽痒生，属佳象 |
| 麻木 | 气血不荣、寒凝血脉、痰瘀阻络 | 麻木范围扩大为病进；伴冷痛皮色紫暗多为寒凝血瘀，见于脱疽 |
| 溃疡 | 色泽、肉芽、边界、收口 | 肉芽红活、脓稠、渐收口为顺；紫暗、灰白水肿、脓清、翻花为逆 |
| 出血 | 血管破裂、血热妄行、气不摄血 | 动脉血鲜红喷涌、静脉血暗红持续；量多不止或岩性溃疡渗血腥臭，须急症评估 |

七项里最容易被写成形容词的是「肿」和「痛」。教材的写法是逼着分型：同样是痛，刺痛指瘀血，灼痛指火毒，胀痛指气滞，啄痛指脓成。分型一落，治法方向就跟着定了，不需要再讨论。

七项里最需要提前设红线的是「溃疡」与「出血」：**疮面翻花如菜花、坚硬如石、渗血腥臭**，不走提脓祛腐的路，走病理活检的路；**出血量大、色鲜红持续不止**，不走换药的路，走急诊止血的路。这两条不属于辨证技巧，属于边界。

## 四、辨脓：四条方法，一条决定性的手感

教材把辨脓放在枢纽位置，理由是它直接决定动作：脓未成宜消，脓已成宜托、宜切。

四条方法：**按之应指**（波动感）、**疮顶软陷**、**皮色转亮**、**痛如鸡啄**。四条不必全备，但按之应指的权重最高——它是唯一一个「手放上去就能得到二值答案」的判据。

外治的边界由此划出三档，每一档对应一个动作和一句停手条件：

- **脓未成**：箍围消肿，不切。停手条件：肿势不消反增、疼痛由胀转跳，说明已越过这一档。
- **脓已成未溃**：托毒透脓，适时切开。停手条件：切开后仍痛不减、发热不退，说明引流不畅或脓未净，要复查而不是加药。
- **脓已溃**：提脓祛腐，腐去生肌。停手条件：腐已脱而新肉不生、疮口久不收，转去查全身（气血、血糖、营养）而不是反复换祛腐药。

这条边界有一个必须写明的代价：**应指依赖手感与经验，深部脓肿靠体表触诊并不可靠**。附骨疽、肠痈、深部流注都属于这一类，须借影像确认。把「摸不到波动」当「没有脓」，是本章最贵的一次误判。

## 五、成组判据、记录字段、四种失效与五项考核

单项判据不成论，成组才有结论。三组用法：

**阴阳组**：色泽＋温度＋肿势＋痛＋脓，五项里至少三项同向，才落阳证或阴证；两项对三项，落半阴半阳，按消补兼施处理。

**部位组**：部位＋病程＋诱因，定归经与病因倾向，给用药方向。

**窗口组**：脓＋溃疡形态＋出血，定「现在能不能动手」。

记录字段固定八列，缺一列复诊就无法比较：部位与归经、大小（长×宽×高）、形态与边界、色泽与温度、疼痛性质与时间、脓（有无、稠稀、色、味）、溃疡（肉芽色泽、脓腐、边界、收口趋势）、出血（有无、色、量、方式）。再加两列：标记线与日期、全身项与舌脉。

四种失效模式：

**以红代阳。** 只凭皮色定阴阳，忽略温度、肿势、脉象。肤色差异、灯光、拍摄角度都能改写「红」的判断，单一色泽不足为据。

**把啄痛当一般的痛。** 痛如鸡啄是脓熟信号，漏掉它就漏掉了切开窗口，后面所有换药都是在错误的阶段做正确的事。

**辨脓只辨有无，不辨成色。** 有脓不等于正气够用。脓稀如污水而按顺证处理，托补的方向就反了。

**把逆证当难治的顺证。** 疮面紫暗、脓清、久不收口，被解释为「体质差、慢慢来」，于是反复换药数月，直到翻花才做病理。

五项考核：

1. 默出九项阴阳对照，并用「溃后」一列说明它为何能预测病程；
2. 举一个阳中伏阴的例子，写出方向该怎么转、依据是哪两项；
3. 就三个病位（颜面疔疮、乳癖、臁疮）分别说出部位倾向、归经与引经方向；
4. 说出辨脓四条方法，并说明为什么深部脓肿不能只靠应指；
5. 给一段疮面描述，判定顺逆并写出下一步动作与停手条件。

## 六、代价与边界

1. **阴阳二分的盲区在半阴半阳**。教材用「阳中伏阴」提示，但真正的判读靠动态观察：换药时的色泽、脓质、肿势变化，一次判断不能定终身。
2. **部位辨证是概率不是定律**。上部多风热，但颜面疔疮走的是火毒；下部多湿热，但脱疽的寒凝证要温阳。反例比正例更需要记住。
3. **局部判据依赖暴露与光线**。皮色在照片、不同光源、不同肤色下差异很大。数字化随访必须固定光照、角度、标尺与拍摄距离，否则「鲜红」「漫肿」不可比，这一点在第 13 章具体展开。
4. **辨证不等于诊断**。本章给的是征象判读框架，不含任何疾病的诊断标准；危重征象（肿势散漫、神昏、出血不止、疮面翻花）须立即转诊或转急症处理。
5. **本章只写到治法方向**。「清热」「托毒」「补益」到此为止；方名、配伍与用药分量属各论与处方范畴，由医师面诊决定。
