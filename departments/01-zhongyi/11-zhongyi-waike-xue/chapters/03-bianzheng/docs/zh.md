# 第 3 章 · 辨证：外科的判据长在「看得见的地方」

> **MOTTO:** 「疡科之证，在上部者，俱属风温风热，风性上行故也」——教材·第3章·3.2.1（《疡科心得集》）
>
> **PROBLEM:** 学生能背「红肿热痛为阳证」，可面对一个真实的疮面，却说不清该先看哪一项、看到什么程度算「成脓」、什么算「逆证」。于是辨证退化成形容词对号：红＝热、痛＝实。真正要判断的是**三件事**——阴阳（方向）、部位（归经与风险）、脓与溃疡（可外治的窗口）。
>
> **双根因定位:** 环境逼迫（外科纠纷里高频出现的一句是「当时以为只是发炎」——把成脓判成未成脓、把逆证判成顺证）+ 知识积累（本章 7 个单元、9,388 字里三辨重心压在**局部表现**（144 次），远高于病因；这说明教材把外科辨证的判据明确放在可观察的局部，而不是靠推算内因）

**教材出处:** 教材·第 3 章（3.1 阴阳辨证、3.2 部位与经络辨证、3.3 局部辨证：肿痛脓、痒麻木、溃疡出血，共 3 节 7 单元）。

## 一、阴阳：不是两堆症状，而是一套对照表

教材不让学生背「阳证＝红」，而是给一张**九项对照表**：发病缓急、病位浅深、局部色泽温度、肿势形态、疼痛性质、脓液稠稀、溃后收口、全身症状、舌脉。

| 对照项 | 阳证 | 阴证 |
|---|---|---|
| 起病 | 急、病程短 | 缓、病程长 |
| 病位 | 皮肉浅表 | 深在筋骨、脏腑 |
| 局部 | 皮色鲜红、灼热烫手 | 皮色不变或苍白、不热或微热 |
| 肿势 | 高突、根脚收束、境界清 | 平塌漫肿、根脚散漫、境界不清 |
| 疼痛 | 剧烈、得冷则舒 | 隐痛、酸痛、得温则适 |
| 脓液 | 稠厚、色黄白、略带腥味 | 稀薄、色白或污浊 |
| 溃后 | 易脓易溃易敛 | 难脓难溃难敛 |
| 全身 | 发热、口渴、便秘溲赤 | 不发热或畏寒、便溏 |
| 舌脉 | 舌红苔黄、脉数有力 | 舌淡苔白、脉细弱 |

这张表最实用的一列是「溃后」：**易脓易溃易敛**是阳证的完整表述——它不仅描述当下，还预测病程。反过来，阴证的「难脓难溃难敛」提示需要更长的托补周期。

## 二、阳中伏阴：辨证最容易漏的一格

教材在阳证一节末尾补了一句关键的例外：阳证后期气血耗伤，局部红肿渐减而漫肿不消，即**阳中伏阴**，不可一味寒凉攻伐。

这一句的价值是防「一条道走到黑」：红肿退了不等于痊愈，若漫肿不退、脓水清稀，方向已经从「清热」转到「托补」。

## 三、部位辨证：上中下三部的病因偏好

《疡科心得集》的三段话，是外科部位辨证的原始出处：

> 「疡科之证，在上部者，俱属风温风热，风性上行故也」——《疡科心得集》

> 「在中部者，多属气郁火郁」——《疡科心得集》

> 「在下部者，多属湿火湿热，湿性下趋故也」——《疡科心得集》

| 部位 | 病因偏好 | 常见病 | 用药倾向 |
|---|---|---|---|
| 上部（头面颈项上肢） | 风温、风热 | 颜面丹毒、痄腮、颈痈、风热疮 | 疏风清热、轻清上扬（荆防、蝉蜕、僵蚕；引经用升麻、葛根、川芎） |
| 中部（胸腹胁肋乳房） | 气郁、火郁 | 乳癖、胁痛、缠腰火丹 | 疏肝解郁、清火（柴胡、郁金、香附） |
| 下部（腰以下、下肢、二阴） | 湿火、湿热 | 臁疮、脱疽、肛肠病 | 清热利湿、佐以升提（四妙、萆薢、防己） |

教材还特意加了反例：上部也有火毒炽盛者（颜面疔疮来势迅猛、肿势散漫），「非单纯风热可比，当以清热解毒为主，不可一味疏风发散」。这句话把部位辨证从「公式」拉回「参考」。

## 四、经络辨证：把局部接到归经与引经

部位辨证给的是**病因倾向**，经络辨证给的是**归经与用药引经**。教材 3.2.2 把它写成两件事：一是十二经与外科病位的对应（乳＝胃经与肝经、肛肠＝督脉与膀胱经、下肢内侧＝三阴经），二是引经药的选用（太阳用羌活、阳明用白芷葛根、少阳用柴胡、厥阴用川芎吴茱萸）。

学这一节的目的不是背穴，而是回答一个具体问题：**这个病灶该从哪条经下手**。

## 五、局部辨证：肿、痛、脓、痒、麻木、溃疡、出血

教材在这一节把外科的「痒」追到经典，用的仍是那句总纲：

> 「诸痛痒疮，皆属于心」——《素问·至真要大论》

这句在辨证里的作用是提醒：痒与痛同属「局部感受」，可以归经入脏，不能只当皮表小症。教材用 3 个单元把局部征象拆成七项，每项都要求「分型 + 判读」：

| 征象 | 要分几型 | 判读要点 |
|---|---|---|
| 肿 | 按成因（热、寒、痰、瘀、虚）与形态（高突、平塌、漫肿） | 形态决定阴阳，成因决定消法方向 |
| 痛 | 按性质（胀痛、刺痛、灼痛、隐痛、跳痛）与时间（持续、阵发、夜间加重） | 「痛如鸡啄」＝脓熟信号 |
| 脓 | 按有无（应指与否）、稠稀、色味 | 稠黄有腥＝气血尚充；清稀污浊＝正虚 |
| 痒 | 风、湿、热、虫、血虚 | 痒的病因谱最宽，须与全身证合看 |
| 麻木 | 气血不荣、毒邪阻络 | 麻木区扩大＝毒邪深入或气血更虚 |
| 溃疡 | 形态（色泽、肉芽、边界、收口） | 顺证：肉芽红活、脓稠、渐收口；逆证：紫暗、脓清、不收口 |
| 出血 | 血管破裂、湿毒化火 | 出血量大或色鲜红持续＝需急症评估 |

**「按之应指」与「痛如鸡啄」是本章最硬的两个判据**：它们把「成脓」从一个模糊判断变成两个可复述的触觉与痛觉指标——这两个指标也正是第 4 章「切开时机」的直接依据。

## 六、辨脓：外科辨证的分水岭

教材把辨脓写成整章的枢纽：脓未成则宜消，脓已成则宜托、宜切。辨脓的方法在教材里有四条（按之应指、疮顶软陷、皮色转亮、痛如鸡啄），四条不必全备，但**「按之应指」最具决定性**。

这条判据的代价也要写清楚：应指判断依赖手感与经验，深部脓肿（如附骨疽、肠痈）靠体表触诊并不可靠，需影像确认。教材在相应各论里补了这一点。

## 代价与边界

1. **阴阳二分有盲区**：半阴半阳证大量存在，教材用「阳中伏阴」提示，但真正的判读仍靠动态观察（换药时的变化），一次判断不能定终身。
2. **局部判据依赖暴露与光线**：皮色在照片、不同光线下差异很大；数字化随访（第 13 章）必须固定光照与角度，否则「皮色鲜红」不可比。
3. **辨证不等于诊断**：本章给的是征象判读框架，不含任何疾病的诊断标准；危重征象（肿势散漫、神昏、出血不止）须立即转急症处理。

**免责声明：** 本章为教学整理，**不构成诊疗建议，不能替代医师面诊**；任何切开与用药决定须由医师面诊后作出。
