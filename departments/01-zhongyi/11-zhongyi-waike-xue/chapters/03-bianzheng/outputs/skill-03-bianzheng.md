# 三步辨证单 · 可装载技能

## 何时装载

- 有一份局部征象记录（部位、皮色、肿势、疼痛、按之应指、有无溃口），要给出结构化辨证结论；
- 要判断「现在能不能切」「该消还是该托」；
- 教学场景：训练学生按固定顺序辨证，避免形容词对号。

## 输入

部位、病程（几天）、皮色与温度、肿势形态与边界、疼痛性质、按之有无应指、有无溃口与脓液性状、全身反应（发热、口渴、便秘）、舌脉。

## 三步与判定

**① 位面**：皮肤 / 皮肉之间 / 筋骨 / 脏腑。筋骨与脏腑层一律提示「需影像或专科评估」。

**② 阴阳**（九项对照）：
- ≥6 项同侧 → 阳证或阴证；
- 3–5 项混杂 → 半阴半阳，标注「需动态观察」；
- 阳证后期「红肿减、漫肿不消、脓水清稀」→ 阳中伏阴，方向转托补。

**③ 窗口**：
- 高突 + 皮色亮 + 应指 + 痛如鸡啄 → 脓熟（可切窗口）；
- 红肿热痛但无应指 → 未成脓（只宜消）；
- 溃后肉芽红活、脓稠、渐收口 → 顺证；
- 溃后紫暗、脓清、不收口 → 逆证（托补 + 查残腔）。

## 输出模板

```text
位面：… ｜依据：…
阴阳：… ｜条目：…
窗口：… ｜下一步：…
缺失项：…
不该做什么：…
```

## 判定优先级

1. 危重征象（肿势迅速散漫、神昏、出血不止）＞ 一切辨证 → 直接建议急症处理，停止推演；
2. 位面为筋骨/脏腑 → 先建议影像，不输出「可切」结论；
3. 缺「按之应指」这一项 → 不得判「脓熟」。

## 反例

1. 只写「红肿热痛，属阳证」而不给九项条目；
2. 未见应指就建议切开；
3. 溃后不收口只加寒凉，不问正虚与残腔。

## 边界

本技能做结构化辨证记录，不产诊断、不给方药与操作。教材依据：第 3 章 3.1（阴阳）、3.2（部位与经络）、3.3（局部征象）。
