# 三步辨证单：位面 → 阴阳 → 脓/溃疡窗口

## 用途

拿到一个外科病灶的观察记录，按固定三步把它读成一组可核对的结构化结论：**在哪一层（位面）· 属阴属阳（方向）· 到了哪一格（窗口）**。三步的顺序不可换：位面错了，阴阳判得再细也会落到错的方向上。

## 第一步：位面

| 位面 | 判据（看什么） | 风险含义 |
|---|---|---|
| 皮肤 | 皮色、边界、有无鳞屑渗液、浅表淋巴 | 扩散快但多可外治 |
| 皮肉之间 | 肿势高突或平塌、根脚收束或散漫 | 成脓与否决定手段 |
| 筋骨 | 深在、按之深痛、活动受限、久不敛口 | 需影像，忌盲切 |
| 脏腑 | 腹部、乳房深部、二阴深部；伴全身反应 | 多需专科评估 |

输出一句：`位面：<层>｜依据：<看得见的证据>`

## 第二步：阴阳（九项对照）

按教材 3.1.2 的九项逐条对：起病缓急、病位浅深、局部色泽温度、肿势形态、疼痛性质、脓液稠稀、溃后收口、全身症状、舌脉。

- 九项里 ≥6 项指向同一侧 → 判为阳证或阴证；
- 3–5 项混杂 → 判为**半阴半阳**，注明「需动态观察」；
- 阳证后期出现「红肿减而漫肿不消、脓水清稀」→ 记**阳中伏阴**，方向转托补。

输出一句：`阴阳：<阳证/阴证/半阴半阳/阳中伏阴>｜条目：<指向的项>`

## 第三步：窗口（脓与溃疡）

| 判据 | 结论 |
|---|---|
| 肿势高突 + 皮色转亮 + 按之应指 + 痛如鸡啄 | 脓熟 → 可切窗口 |
| 有红肿热痛但按之不软、无应指 | 未成脓 → 只宜消，不宜切 |
| 已溃，肉芽红活、脓稠、渐收口 | 顺证 → 提脓祛腐、生肌收口 |
| 已溃，紫暗、脓清稀、不收口 | 逆证 → 托补为主，查正虚与深部残腔 |

输出一句：`窗口：<未成脓/脓熟/溃后顺证/溃后逆证>｜下一步方向：<消/切/托/补>`

## 汇总输出

```text
位面：…
阴阳：…
窗口：…
缺失项：<哪一步缺证据>
不该做什么：<例：未应指不宜切开；阳中伏阴不宜纯寒凉>
```

任何一步缺证据，就在「缺失项」里写清，**不得用推测补齐**。

## 边界

本单用于教学与临床记录的结构化，不产生诊断、不给方药与操作；切开与用药须由医师面诊决定。危重征象（肿势迅速散漫、神昏、出血不止）不适用本单，直接按急症处理。
