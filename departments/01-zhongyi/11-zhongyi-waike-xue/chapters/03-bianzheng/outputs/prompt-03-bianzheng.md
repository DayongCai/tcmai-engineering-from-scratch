# 辨证：外科的判据长在「看得见的地方」 · 提示词

## 用途

给「辨证：外科的判据长在「看得见的地方」」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「阴阳：十八格的表，重心在两格 → 部位与经络：先定「哪一块」，再定「哪条经」 → 局部七征：每一项都要分型，不能只描述 → 辨脓：四条方法，一条决定性的手感」这条链。

```

正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 易脓易溃易敛
   - 局部红而脉沉细无力、精神委靡者，不可遽断为阳证
```
