# 第 7 章 · 瘿、瘤、岩：一条「质地轴」，八个病证

> **MOTTO:** 「坚硬不可移者，名曰石瘿」——教材·第7章·7.4.1（《三因极一病证方论·瘿瘤证治》）
>
> **PROBLEM:** 学生能背「气瘿弥漫、肉瘿如丸、石瘿如石」，但面对一个颈前肿块答不出最关键的一件事：**这个块该不该马上做病理**。八个病证被分成三类（瘿、瘤、岩），真正的分野不在名称，而在**质地与活动度**这两个可触摸的判据上；摸不出这一层，就会把石瘿放在「观察」里。
>
> **双根因定位:** 环境逼迫（颈前肿块与体表肿块最常被「先观察三个月」，而石瘿、失荣、肾岩三类都属「一经发现立即转诊」）+ 知识积累（本章 40 个单元、25,320 字里局部表现 257 次居首，全身只有 48 次——说明癌类病证的判据仍写在局部：硬、不平、不移；四位面没有一极独占，正是因为这八个病横跨颈前、体表与全身淋巴结）

**教材出处:** 教材·第 7 章（7.1 气瘿、7.2 肉瘿、7.3 瘿痈、7.4 石瘿、7.5 血瘤、7.6 肉瘤、7.7 失荣、7.8 肾岩，共 8 病证 40 单元）。本章数字由 `code/main.js` 读 `standards/waike/units.json` 现算。

## 一、三类八证：先分类，再谈辨证

| 类 | 病证 | 位面 | 一句话判据 |
|---|---|---|---|
| **瘿**（颈前） | 气瘿 | 甲状腺弥漫 | 结喉两侧弥漫肿大、质软、随吞咽上下、随喜怒消长 |
| | 肉瘿 | 甲状腺结节 | 单发圆形、柔韧如肉团、边界清、随吞咽活动 |
| | 瘿痈 | 甲状腺（炎症） | 结块色红灼热、压痛明显、起病急、可伴发热 |
| | 石瘿 | 甲状腺（恶性） | **坚硬如石、高低不平、推之不移** |
| **瘤**（体表良性） | 血瘤 | 血络丛集 | 鲜红或暗紫、柔软如海绵、压之褪色、擦破血流不止 |
| | 肉瘤 | 皮里膜外脂肪 | 软似棉、皮色不变、边界清、生长缓（＝脂肪瘤） |
| **岩**（恶性） | 失荣 | 颈部淋巴结 | 耳前后坚硬肿块、融合成团、固定不移、溃如翻花 |
| | 肾岩 | 阴茎 | 龟头结节坚硬、溃后翻花、特异恶臭 |

三类的处置节奏完全不同：**瘿以辨良恶为枢纽，瘤以辨性质防恶变为枢纽，岩以立即转诊为枢纽**。

## 二、质地轴：从气瘿到石瘿，同一条线上四个刻度

教材把四种瘿写成四个质地档，这条轴比任何定义都好用：

| 档 | 质地 | 边界 | 活动 | 对应 |
|---|---|---|---|---|
| 1 | 质软不痛、弥漫 | 边缘不清 | 随吞咽上下 | 气瘿 |
| 2 | 柔韧、圆、如肉团 | 边界清楚 | 可随吞咽活动 | 肉瘿 |
| 3 | 较硬、压痛明显 | 局限 | 活动、触痛重 | 瘿痈 |
| 4 | **坚硬如石、高低不平** | 不清、侵及周围 | **推之不移、吞咽时活动度小** | 石瘿 |

教材对石瘿的诊断要点还补了两条：**存在多年的颈前肿块短期内迅速增大、变硬**，以及**颈部淋巴结肿大、声音嘶哑、呼吸吞咽困难等压迫症状**。前者是「良转恶」的信号，后者是「已侵及周围」的信号。

## 三、石瘿：本章的第一个红线

石瘿的辨证论治里有一句与诊断并列的要求：**甲状腺细针穿刺细胞学检查可基本确诊**；B 超见低回声、边缘不规则、侵及甲状腺外、血流紊乱、微小钙化、淋巴结门结构消失等征象有助诊断。

本课程不复制具体影像判据的阈值，但保留教材的判断结构：**先看质地与活动度 → 再看影像 → 最后靠穿刺（或病理）定性质**。三步的顺序不能倒：先做病理再摸，是资源浪费；只摸不做病理，是延误。

## 四、失荣与肾岩：两个「一经发现即转诊」

- **失荣**：颈部或耳前后坚硬肿块，初起单发可活动，继而**融合成团、固定不移、生长较快**；溃后渗流血水、状如翻花；**须全面检查寻找原发灶**，病理活检明确诊断。教材红线：多属恶性肿瘤颈淋巴结转移，一经发现立即转诊肿瘤专科。
- **肾岩**：阴茎头、冠状沟、包皮内板出现丘疹、结节、菜花状或疣状肿物，逐渐增大、痒痛不休、溃后渗流血水、有特异恶臭；**以手术治疗为主**，确诊后按恶性肿瘤处理。

两节的共同点：**它们不是「辨证论治」的对象，而是「识别—转诊」的对象**。教材把辨证论治的内容写成了诊断与鉴别，而不是方药，这个写法本身就是态度。

## 五、瘤的两个样本：血瘤与肉瘤

- **血瘤**：《外科正宗·瘿瘤论》的描述是「微紫微红，软硬间杂，皮肤隐隐，缠若红丝，**擦破血流，禁之不住**」——四句里最后一句是重点：出血难止是它最危险的特征。辨证纲领：辨色泽（鲜红多属心火、暗紫多属瘀血）、辨部位（头面多心火上炎、下肢多湿热下注）。
- **肉瘤**：软似棉、边界清、皮色不变、生长缓慢（＝脂肪瘤）。教材特意提醒：**西医的「肉瘤」指软组织恶性肿瘤（脂肪肉瘤、纤维肉瘤），与本病本质不同**，不可混淆。这一句是全章最容易错的名词陷阱。

## 六、三条鉴别线，比背八个定义划算

| 鉴别 | 判据 |
|---|---|
| 气瘿 / 肉瘿 | 弥漫多发、边界欠清 vs 单发、圆、边界清、质地柔韧 |
| 瘿痈 / 石瘿 | 起病急、红肿热痛、压痛明显、可伴发热 vs 起病缓、坚硬不平、无痛、推之不移 |
| 失荣 / 瘰疬 | 坚硬固定、融合成团、溃如翻花、多见于中老年 vs 质地较软、溃后成瘘、伴低热盗汗、多见于青少年 |

三条线都用同一组变量：**起病缓急 + 质地 + 活动度 + 有无红肿热痛**。

## 代价与边界

1. **本章的误判代价集中在「等」**：石瘿、失荣、肾岩三类都写着「立即转诊」，等三个月可能就是分期改变。
2. **瘿病的检查不可替代**：气瘿与肉瘿的鉴别靠 B 超与甲状腺功能，靠手感只能给出倾向；教材给的扫描与功能描述属诊断层，本课程不复制阈值。
3. **名词陷阱**：肉瘤（脂肪瘤）≠ 西医肉瘤（恶性肿瘤）；血瘤（血管瘤/血管畸形）的外治（如硬化、激光）在教材中属慎重之举，**不可自行处理**——擦破血流不止是它的特征。
4. **本章不含方药剂量与手术方案**：辨证论治给出的是分型与治法方向，具体方药见教材原文，手术与穿刺由专科决定。

**免责声明：** 本章为教学整理与文献梳理，**不构成诊疗建议，不能替代医师面诊**；颈前与体表肿块的性质必须靠影像与病理确定。
