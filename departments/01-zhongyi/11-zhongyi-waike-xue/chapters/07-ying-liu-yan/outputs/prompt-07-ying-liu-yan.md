# 肿块四问：瘿、瘤、岩的性质判定与红线

## 用途

颈部或体表的肿块，用四问定性质与红线：**位置与来源 · 质地与活动度 · 生长速度与压迫征象 · 该不该立刻病理**。本章八个病证的差别几乎全在第二问上，而第四问决定「还谈不谈辨证」。

## 第一问：位置与来源

| 位置 | 可能来源 |
|---|---|
| 结喉两侧（甲状腺） | 瘿病四类（气瘿/肉瘿/瘿痈/石瘿） |
| 耳前、耳后、颈侧（淋巴结） | 失荣、瘰疬、颈痈 |
| 皮下、皮里膜外 | 肉瘤、脂瘤、囊肿 |
| 血络丛集处 | 血瘤 |
| 阴茎 | 肾岩 |

## 第二问：质地与活动度（核心）

| 档 | 质地 | 边界 | 活动 | 提示 |
|---|---|---|---|---|
| 1 | 质软、弥漫 | 不清 | 随吞咽上下 | 气瘿 |
| 2 | 柔韧、圆、如肉团 | 清 | 随吞咽活动 | 肉瘿 |
| 3 | 较硬、压痛明显 | 局限 | 活动、触痛重 | 瘿痈 |
| 4 | **坚硬、高低不平** | 不清、侵及周围 | **推之不移** | 石瘿 |
| — | 软似棉、皮色不变 | 清 | 可移动 | 肉瘤（脂肪瘤） |
| — | 柔软如海绵、压之褪色 | 可不清 | — | 血瘤 |

## 第三问：生长速度与压迫征象

- 存在多年后**短期迅速增大、变硬** → 良转恶信号；
- 声音嘶哑、呼吸/吞咽困难、头颈疼痛 → 已侵及周围；
- 颈部多个肿块**融合成团、固定** → 失荣可能，需寻找原发灶；
- 溃后渗流血水、状如翻花、特异恶臭 → 恶性溃破（失荣/肾岩）。

## 第四问：该不该立刻病理

**命中任一即转诊，不做辨证论治：**

- 质地档 4（坚硬、不平、推之不移）；
- 短期迅速增大变硬；
- 压迫症状（声嘶、吞咽/呼吸困难）；
- 颈淋巴结肿大固定或融合成团；
- 影像提示可疑（低回声、边缘不规则、微小钙化、淋巴结门结构消失等，以报告为准）。

## 输出格式

```text
分类：<瘿/瘤/岩> ｜病证候选：…
质地档：<1–4 或 良性瘤>
红线：无 ／ 有（<项>）→ 立即转诊病理
下一步：<观察随访 / 专科评估 / 转诊>
缺证据：…
```

## 边界

只做分类、质地判档与红线筛查，不给方药剂量与手术方案。血瘤禁自行处理（擦破血流不止）；甲状腺与淋巴结性质须靠超声与穿刺/病理确定。
