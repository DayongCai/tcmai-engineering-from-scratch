# 肿块四问 · 可装载技能

## 何时装载

- 颈部或体表摸到肿块，需要判定属于瘿、瘤还是岩；
- 要判断「能不能先观察」以及「何时必须做病理」；
- 教学场景：训练学生用质地与活动度而不是病名排序。

## 输入

位置、大小、质地（软/柔韧/硬）、边界、活动度（可移/推之不移/随吞咽）、有无压痛、皮肤与颜色、生长速度、病程、压迫症状（声嘶、吞咽呼吸困难）、淋巴结情况、影像与穿刺结果。

## 判定规则

| 条件 | 结论 |
|---|---|
| 坚硬 + 高低不平 + 推之不移 | 质地档 4 → 红线，立即转诊病理（石瘿类） |
| 短期迅速增大变硬（原有多年的肿块） | 良转恶信号 → 转诊 |
| 声嘶 / 吞咽或呼吸困难 / 颈淋巴结固定成团 | 已侵及周围 → 转诊并寻找原发灶 |
| 柔韧圆形、边界清、随吞咽活动 | 肉瘿类 → 超声＋功能评估 |
| 弥漫质软、随喜怒消长 | 气瘿类 → 超声＋功能评估，观察随访 |
| 红肿热痛、压痛明显、起病急 | 瘿痈类 → 炎症评估（血沉、摄碘率） |
| 软似棉、皮色不变、可移动 | 肉瘤（脂肪瘤）→ 观察，短期内增大变硬需病理 |
| 鲜红/暗紫、海绵状、压之褪色 | 血瘤 → 禁自行处理（擦破血流不止），专科评估 |

## 输出模板

```text
分类：瘿 / 瘤 / 岩 ｜ 病证候选：…
质地档：…
红线：无／有（项）→ 立即转诊
下一步 …
缺证据 …
```

## 反例

1. 见颈前肿块一律按气瘿观察（漏石瘿）；
2. 用「肉瘤」当软组织恶性肿瘤（名词混淆）；
3. 自行挑破或挤压血瘤。

## 边界

本技能做分类与红线筛查，不产诊断、不给方药与手术方案。甲状腺与淋巴结性质必须靠超声与穿刺/病理；教材依据：第 7 章 7.1–7.8。
