# 第 2 章 · 命名与病因病机：一个病名里藏着三层判据

> **MOTTO:** 「痈疽原是火毒生，经络阻隔气血凝」——《医宗金鉴·外科心法要诀》
>
> **PROBLEM:** 本章 7 个单元，命名与术语占 2 个（2.1.1、2.1.2），病因占 3 个（2.2.1–2.2.3），病机占 2 个（2.3.1、2.3.2）——2＋3＋2 正好是 7。这个配比说明教材的判断：病因分得比病机细，因为病因决定「问什么」，病机决定「怎么解释」。而命名的真正难点在量界：教材以痈的范围约「六至九厘米」、有头疽「超过九厘米」为分界。两个数字把「痈」与「有头疽」从形容词之争，变成了可量的判据。
>
> **双根因定位:** 环境逼迫（同一片红肿，长在颈侧叫颈痈、长在腋下叫腋痈、长在委中附近叫委中毒，病名承担了部位信息；不先解码病名，就没法归口，也没法选引经药）+ 知识积累（命名从「以形状比附」走到「审因定名」，术语层层叠加：疡→疮疡→肿疡／溃疡，每加一层就绑定一个治疗阶段，最终把「消、托、补」的时间轴钉在了词义上）

**教材出处:** 教材·第 2 章（2.1 命名与术语、2.2 病因、2.3 病机，共 3 节 7 单元）。

## 一、病名是一个压缩包：部位、形态、病因三层

中医外科的病名不是标签，是压缩过的判断。教材列出的命名法有五路，五路对应五种解码方式：

| 命名依据 | 例 | 解码出什么 |
|---|---|---|
| 部位 | 颈痈、腋痈、脐痈、委中毒、胯腹痈、锁喉痈、肠痈、乳痈、子痈、肾岩 | 病位与归经。乳痈在乳房，乳头属肝、乳房属胃，所以从肝胃论治；肾岩在阴茎，属肝肾 |
| 特征 | 流注、流痰、丹毒、蝼蛄疖、蛇头疔、红丝疔、瓜藤缠 | 病机形态。流注是脓毒走注无定处，流痰是脓稀如痰、流注骨节，丹毒是色如涂丹 |
| 病因 | 暑疖、疫疔、漆疮、虫咬皮炎、毒蛇咬伤 | 直接给出起点，问诊可顺着查暴露史 |
| 形态 | 蛇头疔、蛇眼疔、蛇腹疔、托盘疔、鹅掌风、蛇串疮、乳岩 | 皮损的形与分布，是复诊比较的锚点 |
| 颜色与病程 | 丹毒、白疕、青蛇毒；急性者多阳证，慢性者多阴证 | 色泽与时间，两者合看能预判转归 |

解码的价值在于三件事同时被读出来：**病位**（决定归经与风险）、**病性**（决定阴阳与消托补）、**病势**（决定是观望还是动手）。只记住名字而读不出这三层，病名就退化成一个读音。

要特别警惕一类错误：把病名当结论。病名是解码之后落的标签，先有部位、形态、病程三项事实，才有资格落名字。反过来用名字去套事实，是背书而不是诊断。

## 二、术语的四级台阶，与「痈／疽」的量界

教材把基本术语排成四级台阶，每一级对应一个治疗阶段：

**疡**——最宽，泛指一切外科疾病。《周礼》设疡医，掌肿疡、溃疡、金疡、折疡，后世因称外科为疡科。

**疮疡**——狭义指体表化脓性感染的总称（疖、疔、痈、有头疽、丹毒、流注等），广义可泛指一切体表外科疾患。国家标准《中医临床诊疗术语》取狭义，临床也应以狭义为主。

**肿疡**——体表尚未溃破的肿块，含未成脓与已成脓未溃两种。特征只有一个：肿起有形、皮肤未破。

**溃疡**——已溃破的疮面，脓水外泄、疮口未敛者。臁疮、褥疮、糖尿病足溃疡都归这一级。

四级台阶的用处，是把治法钉在阶段上：肿疡期以消为主，脓成不溃以托为主，溃疡期以提脓祛腐、生肌收口为主，气血虚者以补为主。所以「消、托、补」不是三个并列选项，是四个词义台阶推出来的时间轴。

再往下是六个极易混淆的具体名目，教材用可量的边界把它们分开：

| 名 | 病变层次与形态 | 量界与转归 |
|---|---|---|
| 疖 | 单个毛囊及其周围，肿势局限，范围小 | 易消易敛，反复发作者称疖病 |
| 疔 | 形小而根深，肿硬如钉，麻痒或剧痛 | 易走黄，头面与手足部尤须警惕 |
| 痈 | 皮肉之间，光软无头，红肿热痛 | 教材以六至九厘米为范围，易肿易脓易溃易敛 |
| 有头疽 | 初起即有粟粒样脓头，向深部与周围扩散，溃后状如蜂窝 | 教材以超过九厘米为界，好发于项背皮肤厚韧处，易内陷 |
| 丹毒 | 皮肤突然红赤如涂丹，边界清楚，按之褪色 | 反复发作可致下肢淋巴水肿 |
| 疮 | 泛指溃破之疮面；狭义指皮肤浅表溃破 | 与「疡」的广义用法要分清 |

这张表真正要记的不是六个定义，是两条界线：**痈与有头疽的分界在范围与脓头**，**疖与痈的分界在毛囊数与肿势**。界线一模糊，切开时机、切口方向、是否需住院的判断就跟着模糊。

## 三、病因采集：六个问题，加一条红线

教材把病因分五路：外感六淫、特殊之毒、情志内伤、饮食不节与劳逸过度、外来伤害，再加作为继发性病因的痰饮与瘀血。落到问诊上，是六个必问：

1. **起病与季节**——骤起者多风热、疫毒；暑令多发者想到暑疖、暑湿流注；秋令干燥脱屑者想到燥邪。
2. **部位与诱因**——上部多风温风热，中部多气郁火郁，下部多湿火湿热；有无虫咬、漆触、金刃竹木刺伤。
3. **饮食与酒**——过食辛辣炙煿、膏粱厚味者，湿热火毒内生，《素问·生气通天论》所谓「膏粱之变，足生大疔」即指此路。
4. **情志与睡眠**——郁怒伤肝、忧思伤脾，痰气互结则生瘿瘤瘰疬；乳癖、乳岩、失荣多与此相关，且随情志波动而进退。
5. **劳逸与房室**——劳力耗气则卫外不固，劳神耗血则托毒无力，房劳耗精则虚火炼痰。
6. **既往与用药**——糖尿病、长期激素或免疫抑制、既往放疗史，都会改写「同样的红肿」的风险等级。

六问之外有一条红线，属于**特殊之毒**这一路，触发即转诊，不在门诊观察：

- **深窄伤口＋牙关紧、肌肉痉挛**：想到破伤风，尽早清创并按规范做预防处置，发病即转急诊；
- **犬咬伤**：清创并按规范全程处置，不存侥幸；
- **蛇咬伤**：辨神经毒、血循毒、混合毒三型，制动、低位、尽快转有抗蛇毒血清的机构；
- **伤口剧痛、皮色灰暗、恶臭、按之有捻发音**：想到烂疔（气性坏疽），紧急外科处理，不换药观望。

这四条的共同点是：它们的病程以小时计，不以日计。凡是「以小时计」的病，问诊的第一任务不是辨证型，是识别它。

## 四、病机三条链：从气血凝滞到内陷

病机在本章被压成两条主链和一条转归链，链条清楚了，治法就不用背。

**第一条链：气血凝滞 → 经络阻塞 → 脏腑失调。** 各种病因作用于人体，第一步都是让气血运行失常。「通则不痛，痛则不通」，肿是气血瘀滞有形，痛是气血不通之象。凝滞日久郁而化热，热盛肉腐，血肉腐败而成脓，于是由肿疡转溃疡。经络是气血的通道，也是邪毒传变的路径：乳痈从肝胃论，瘰疬从肝胆论，脱疽从下肢三阴论，依据都在经络循行。脏腑失调则是链条的末端，也是病根所在——「外之证必根于内」这句话，讲的就是这条链的方向。

**第二条链：正邪交争 → 脓的成色 → 顺逆判断。** 疮疡的发生以正虚为前提、邪实为条件。初起邪盛正未衰，宜消；成脓期正邪交争最烈，宜托；溃后邪去正复，宜补。脓是这条链上最诚实的指标：**脓稠厚、色黄白、略带腥味，是气血充实；脓稀薄、色败气秽，是气血亏虚、毒邪深重**。所以辨脓不只是辨有没有脓，是辨正气还剩多少。

**转归链：正不胜邪 → 毒不外达 → 内攻脏腑。** 疔疮走黄与有头疽内陷都走这条路：疮顶忽然平塌、肿势漫散、边界消失，同时高热、神昏、烦躁。到这里，病机讨论结束，处置只剩一件事——转急诊，中西医结合抢救。

三条链合起来给出一个操作结论：**外治的边界由脓决定**。脓未成，不切，切了是伤气血；脓已成而不溃，要托要切，不切则毒内攻；脓已溃而引流不畅，要扩创要引流，不引流则腐不去、新不生。这条边界比任何一张方剂表都更常被违反。

## 五、记录字段、四种失效与五项考核

病名与病因这两节，落成记录是六个字段加一条时间轴：

- 病名（含部位定语，如「颈痈」而非「痈」）；
- 命名依据（按部位／形态／病因／颜色／病程，写明用了哪一路）；
- 病位层次（皮、肉、筋、骨、脏腑）；
- 病因线索（六问的答案，逐条写「有／无／不详」）；
- 阶段（肿疡／脓成未溃／溃疡）；
- 经络归经与引经药方向（只写方向，不写具体方）。

时间轴则写三行：起病日、脓成日（或预计）、溃破日。三行一填，「消托补」该走到哪一步就不需要再讨论。

四种失效模式，都是本章内容被误用的方式：

**名实混淆。** 同一个「痈」字，在颈叫颈痈、在乳叫乳痈，病位不同、归经不同、风险不同。只写「痈」，等于把三层信息丢了两层。

**以古名套今病。** 中医病名与西医病名不是一一对应，一个中医病名可涵盖多种现代疾病。教材要求做对照，不是要求做等号。

**病因问一半。** 只问寒热、不问饮食情志与暴露史，六淫之外的四处病因全部漏掉，于是「反复发作的疖病」永远找不到真正的原因。

**病机当结论。** 「气血凝滞」是解释框架，不是处置方案。写了四个字就开方，等于跳过了阶段判断与脓的判断。

五项考核：

1. 给出五个病名（颈痈、委中毒、蛇头疔、流痰、瓜藤缠），逐个写出它用的是哪一路命名、解码出哪三层信息；
2. 说出疡、疮疡、肿疡、溃疡四级术语各对应哪个治疗阶段；
3. 用范围与脓头两项，说清痈与有头疽的分界，以及这个分界对切开时机的意义；
4. 就一则「足部深窄刺伤后牙关发紧」的病史，写出问诊六问的答案要点与触发的红线；
5. 用「脓的成色」解释顺证与逆证，并指出外治该在哪个节点改变动作。

## 六、代价与边界

1. **命名法本身不严密。** 五路命名并存，同一个病可能同时符合两三路（丹毒既按颜色又按形态），教材不作统一，是因为历史层积无法回溯清理。学习时要接受「一名多据」，但记录时必须写明用了哪一路。
2. **量界是教材口径，不是绝对标准。** 「六至九厘米」「超过九厘米」用于教学分界，实际判断还要看部位、皮肤厚薄、糖尿病等基础病。数字不能单独作决定。
3. **病因推演有过度的风险。** 把每一个疮疡都追到情志或饮食，会造出一套无法验证的因果。教材的写法是「常见」「多与」，不是「必然」。
4. **病机解释不能替代病理。** 坚硬不移的肿块用「痰瘀互结」解释得通，但不能因此不做病理。解释力强，恰是这类框架最危险的地方。
5. **方药的分量与煎服不在本章范围**。引文只到书名与篇名；具体用药须由医师面诊后处方。
