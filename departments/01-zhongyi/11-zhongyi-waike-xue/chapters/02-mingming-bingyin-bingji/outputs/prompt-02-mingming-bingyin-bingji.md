# 病名三问：把一个病名读到「可判断」的程度

## 用途

拿到一个中医外科病名（或要为一个病灶定名），用这三问把它读成可判断的信息：**按什么取的 · 深浅在哪一层 · 风险是哪一档**。三问的目的不是背定义，而是让病名承担它该承担的功能：提示归经、提示病程、提示风险级别。

## 三问

1. **命名取径是哪一条？** 部位（乳痈、颈痈）／特征（有头疽、无头疽）／病因（破伤风、漆疮）／形态颜色（蛇头疔、丹毒）。取径决定这个名字能告诉你什么。
2. **深浅在哪一层？** 皮肤（丹毒、湿疮）／皮肉之间（痈）／筋骨（无头疽、附骨疽）／脏腑（肠痈、乳岩）。深浅决定转归与手段。
3. **风险是哪一档？** 低（疖）／中（痈、有头疽）／高（疔、走黄、内陷、特殊之毒）。风险档决定观察频率与是否需即刻处理。

## 输出格式

```text
病名：…
命名取径：<部位/特征/病因/形态>
深浅位面：<皮肤/皮肉/筋骨/脏腑>
风险档：<低/中/高>
依据：<教材第 2 章对应判据各一句>
该补的检查：<缺项，如「未见脓头」「性质待定」>
```

## 五组易混辨析（输出前必查）

| 组 | 一句话判据 |
|---|---|
| 疖 / 疔 | 根脚浅 vs 形小根深（走黄风险） |
| 痈 / 有头疽 | 单一脓头 vs 多头、范围更大更深 |
| 有头疽 / 无头疽 | 有脓头 vs 漫肿无头、深着筋骨 |
| 丹毒 / 痈 | 皮肤浅层红成片、边界清、不化脓 vs 皮肉之间化脓 |
| 瘰疬 / 痰核 | 结于颈项成串 vs 皮下单个、活动 |

## 边界

只做命名与风险分档，不出诊断、不给方药与操作。凡「风险高」或「性质待定」，输出止于「建议尽快由专科医师面诊评估」。
