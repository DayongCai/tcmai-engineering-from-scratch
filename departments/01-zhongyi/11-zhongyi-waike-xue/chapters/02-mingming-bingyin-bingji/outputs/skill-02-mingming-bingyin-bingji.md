# 病名三问 · 可装载技能

## 何时装载

- 要在病历或交班记录里写一个中医外科病名；
- 要判断「这个名字提示的是轻症还是危症」；
- 教学场景：训练学生把病名与病机、深浅、风险连起来。

## 输入

病名（或待定名的局部描述）：部位、形态、有无脓头、病程、全身反应。

## 三步

1. **取径**：部位 / 特征 / 病因 / 形态颜色。名字里通常能读出 1–2 条。
2. **位面**：皮肤 / 皮肉之间 / 筋骨 / 脏腑。位面来自解剖深度，不来自名字。
3. **风险**：低 / 中 / 高。判据是「走黄、内陷、特殊之毒」三类事件的可能性。

## 判定规则（可执行）

| 条件 | 输出 |
|---|---|
| 名字含「疔」或为特殊之毒所致 | 风险＝高；提示忌挤压、尽快面诊 |
| 无脓头而漫肿平塌、病程长 | 位面＝筋骨或更深；风险＝中高；提示阴证可能 |
| 红成片、边界清、不化脓 | 位面＝皮肤浅层（丹毒类）；风险＝中（需注意扩散） |
| 病名与形态不符（如「疖」却多头成片） | 输出「名实不符，建议改称并复评」 |
| 关键项缺失（有无脓头、部位不清） | 输出「不足以定名」，只给补问清单 |

## 反例（必须拒绝）

1. 只写病名不写取径与位面；
2. 把「疖」当「疔」处理过度，或把「疔」当「疖」处理不足；
3. 见「疽」就一律按阴证温补（有头疽多属阳证）。

## 边界

本技能只做命名与风险分档，不产诊断、不给方药与操作。教材依据：第 2 章 2.1（命名与术语）、2.2（病因）、2.3（病机）。
