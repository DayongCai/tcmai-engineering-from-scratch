# 疮疡四问 · 可装载技能

## 何时装载

- 拿到一个红肿的包、溃口或多发脓肿的记录，要定位病证范围；
- 要判断「现在能不能切」「脓到了哪一格」；
- 要筛查走黄与内陷（这是疮疡唯一必须先排除的事）。

## 输入

部位、大小与范围、有无脓头与数目、皮色与温度、按之是否应指、疼痛性质、病程（几天）、全身反应（发热、寒战、神志、尿量）、既往（消渴、正虚、老年）。

## 四问

1. **位面**：皮肤 / 皮肉之间 / 深部肌肉 / 骨与关节 / 淋巴结。
2. **病证**：用「深浅 + 起病缓急 + 脓的性状」三件事定位（疖/疔/痈/有头疽/丹毒/瘰疬/流注/附骨疽/流痰）。
3. **脓**：未成脓 / 已成脓 / 溃后顺证 / 溃后逆证。
4. **危候**：走黄与内陷筛查（见下表）。

## 危候筛查表（命中任一即转急症）

| 类别 | 征象 |
|---|---|
| 局部 | 疮顶黑陷无脓、肿势散漫、皮色暗红或紫滞 |
| 全身 | 寒战高热（≥39℃）、头痛剧烈、烦躁不安、恶心呕吐、口渴引饮 |
| 恶化 | 神昏谵语、痉厥抽搐、皮肤瘀斑、尿少；或体温不升、四肢厥冷、脉微欲绝 |

内陷三型：**火陷**（初起，邪盛）、**干陷**（溃脓期，正虚）、**虚陷**（收口期，脾肾阳衰）。

## 输出模板

```text
位面：… ｜病证候选：…
脓：… ｜下一步：…
危候：无 ／ 有（<项>）→ 转急症
缺证据：…
```

## 硬规则

1. 危候命中 → 只输出「按急症处理」，不得继续给治法建议。
2. 未应指不得建议切开（疖/疔尤忌早期切开与挤压）。
3. 颈项肿块质硬固定、逐渐增大 → 先排除恶性（失荣），不得按瘰疬处理。
4. 脓出初稠后稀、久不收口（附骨疽/流痰）→ 提示死骨或残腔，需影像。
5. 不输出剂量与操作步骤。

## 反例

1. 把疔当疖挤压（走黄）；
2. 把有头疽的「平塌」当好转（内陷）；
3. 见包块就按瘰疬论治（漏恶性）。

## 边界

本技能做定位、分格与危候筛查，不产诊断、不给方药与操作。教材依据：第 5 章（5.1–5.10 十病证的五段结构与按语）。
