# 疮疡四问：位面 → 病证 → 脓 → 危候

## 用途

拿到一个疮疡描述的记录（红肿的包、溃口、脓、发热），用四问把它读成可判断的结构：**在哪一层 · 落在哪个病证 · 脓到了哪一格 · 有没有危候**。四问的顺序不能换——危候筛查必须放在最后一遍，因为它一旦命中，前三问的推演全部作废。

## 第一问：位面

| 位面 | 判据 | 病证范围 |
|---|---|---|
| 皮肤（毛囊） | 局限、根脚浅、有脓头或结块 | 疖、丹毒（浅层淋巴） |
| 皮肉之间 | 结块较大、红肿灼痛、易向周围扩散 | 痈、有头疽 |
| 深部肌肉 | 漫肿无头、一处将愈他处又起 | 流注 |
| 骨与关节 | 疼痛彻骨、附筋着骨、活动受限 | 附骨疽、流痰 |
| 淋巴结 | 结核如串珠、皮色不变 | 瘰疬 |

## 第二问：病证（含鉴别三件事）

用**深浅 + 起病缓急 + 脓的性状**三件事定位，而不是靠背病名：

- 根浅范围小、出脓即愈 → 疖
- 形小根深如钉、肿势小而病重 → 疔
- 单一脓头、易溃易敛、范围较大 → 痈
- 多个蜂窝状脓头、范围大、易内陷 → 有头疽
- 皮肤鲜红成片、边界清、不化脓 → 丹毒
- 起病缓、脓稀夹败絮样物、发于骨关节 → 流痰

## 第三问：脓

| 状态 | 判据 | 下一步 |
|---|---|---|
| 未成脓 | 按之坚硬、痛无应指 | 消（禁止切开） |
| 已成脓 | 按之软陷应指（必要时穿刺确认） | 托 + 切开引流 |
| 溃后顺证 | 脓出黄稠、肿消痛减、疮面渐敛 | 提脓祛腐、生肌收口 |
| 溃后逆证 | 脓稀灰暗、肿势不消、久不收口 | 托补 + 查残腔/死骨 |

## 第四问：危候（走黄与内陷）

**命中任一 → 停止推演，按急症处理：**

- 局部：疮顶黑陷无脓、肿势散漫、皮色暗红或紫滞；
- 全身：寒战高热（39℃ 以上）、头痛剧烈、烦躁不安、恶心呕吐；
- 恶化：神昏谵语、痉厥抽搐、皮肤瘀斑、尿少，或体温不升、四肢厥冷、脉微欲绝。

## 输出格式

```text
位面：… ｜病证候选：…（依据：深浅/缓急/脓）
脓：… ｜下一步：…
危候：无 ／ 有（<命中的项>）→ 转急症
缺证据：…
```

## 边界

只做定位、分格与危候筛查，不出诊断、不给方药与操作。任何切开与用药须由医师面诊决定；危候命中时本单只输出转诊建议。
