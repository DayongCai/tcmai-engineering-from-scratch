# 疮疡：十个病证，同一套五段模板 · 提示词

## 用途

给「疮疡：十个病证，同一套五段模板」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「十个病证排成三层：浅、深、危 → 四个「红肿」的分界：疖、疔、痈、有头疽 → 丹毒与危层：颜色看得见，红线也看得见 → 四个「深部」：起病快慢与脓质是分水岭」这条链。
