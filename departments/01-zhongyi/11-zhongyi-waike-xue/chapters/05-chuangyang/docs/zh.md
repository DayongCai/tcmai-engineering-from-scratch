# 第 5 章 · 疮疡：十个病证，同一套五段模板

> **MOTTO:** 「疖是生于肌肤浅表部位、以局部红肿热痛为主要表现的急性化脓性疾病，其特点是肿势局限、根脚浅、范围小，出脓即愈」——教材·第5章·5.1.1（《中医外科学·第5章》）
>
> **PROBLEM:** 学生把十个病证的「概述」都背下来了，却答不出一个更硬的问题：为什么同样的红肿热痛，疖出脓即愈，疔却能走黄死人，有头疽会内陷，附骨疽要烂到骨头？如果十个病证各背一遍，脑子会变成十个孤岛；真正要抓的是**同一套五段模板里，哪一项变了**。
>
> **双根因定位:** 环境逼迫（疮疡是外科门诊量最大的一类，误判的代价集中在两处：把疔当疖挤压，把有头疽的「平塌」当好转）+ 知识积累（本章 50 个单元、31,002 字，结构极整齐：**10 个病证 × 5 段**（概述／病因病机／辨证论治／预防调护／按语），说明教材刻意用同一模板承载不同深浅的疾病；而词频重心落在**病机**（455）与**全身**（259）而非局部，说明疮疡章真正的难点是「何以成脓」与「何时走黄内陷」）

**教材出处:** 教材·第 5 章（5.1–5.10，10 个病证，共 50 单元）。本章数字由 `code/main.js` 读 `standards/waike/units.json` 现算。

## 一、十个病证与位面：从皮肤排到骨头

本章十病证不是并列的十个病，而是**按深浅排开的一条线**：

| 病证 | 位面 | 一句话判据（教材口径） |
|---|---|---|
| 疖 | 皮肤（毛囊） | 肿势局限、根脚浅、范围小，出脓即愈 |
| 疔 | 皮肤深层至皮肉 | 形小根深、坚硬如钉、易于走黄 |
| 痈 | 皮肉之间 | 结块范围较大、红肿灼痛、易向深部与周围扩散 |
| 有头疽 | 皮肉至筋骨 | 多个粟粒样脓头、范围大、易内陷 |
| 丹毒 | 皮肤浅层（淋巴） | 皮肤鲜红成片、边界清楚、一般不化脓 |
| 走黄与内陷 | 全身（危候） | 疮顶黑陷无脓 + 全身中毒症状 |
| 瘰疬 | 颈部（淋巴结） | 结核如串珠、皮色不变、溃后脓稀夹败絮样物 |
| 流注 | 肌肉深处（多发） | 漫肿无头、一处将愈他处又起 |
| 附骨疽 | 骨 | 疼痛彻骨、附筋着骨、可排死骨 |
| 流痰 | 骨与关节 | 起病缓、不红不热、脓稀夹败絮样物 |

这条线的用处：**先定位面，再定病名**。同一个「红肿的包」，在皮肤层是疖，在皮肉之间是痈，深到骨是附骨疽——位面错了，病名必错，处置也随之错（该切的没切、该转的没转）。

## 二、五段模板：同一结构，五处判据

教材给每个病证都用五段，但五段里填的东西不同。把十病证横向对齐，才看得出「模板相同、判据不同」：

| 段 | 这段回答什么 | 交叉看时最该盯的一格 |
|---|---|---|
| 概述 | 这是哪个病、与西医什么病对应 | **深浅**（决定风险量级） |
| 病因病机 | 为什么会这样 | 是「火毒蕴结」还是「痰凝／正虚」（决定消、托还是补） |
| 辨证论治 | 现在分几型、怎么处理 | **分型数**与**方**（同一病证内部分型越多，说明它跨的证型越宽） |
| 预防调护 | 怎么防复发、怎么护 | 忌挤压、忌膏粱厚味、忌情绪（三忌覆盖大半） |
| 按语 | 这一病证的「一句话总结」 | 教材在这里放的是**临床上最容易错的那一点** |

「按语」这一段常被学生跳过，但它恰恰是教材作者留的判据。读十个病证的按语，等于读十句「别这样」。

## 三、辨脓：贯穿十病证的同一个动作

从疖到附骨疽，教材在每一病证的「辨证论治」里都要辨脓，判据也一致：

| 状态 | 局部 | 处理方向 |
|---|---|---|
| 脓未成 | 按之坚硬、痛无应指 | 消（不可切） |
| 脓已成 | 按之软陷应指（或透光试验阳性、必要时穿刺） | 托 + 切开引流 |
| 溃后顺证 | 脓出黄稠、肿消痛减、疮面渐敛 | 提脓祛腐、生肌收口 |
| 溃后逆证 | 脓水稀薄灰暗、肿势不消、久不收口 | 托补 + 查残腔与死骨 |

痈的「按之中软应指」、疔的「脓出黄稠为顺」、有头疽的「脓出黄稠、肿消痛减为顺；脓水稀薄灰暗、肿势不消为逆」、附骨疽的「脓出初稠后稀、可排死骨」——**同一套判据，按位面调语气**。

## 四、两个危候：走黄与内陷

这是全章唯一以「危候」立项的一节，也是本章最该背熟的一节：

- **走黄**：疔疮毒邪走散，多见于邪盛之体。局部见**疮顶黑陷无脓、肿势散漫、皮色暗红或紫滞**，全身见寒战高热（可达 39℃ 以上）、头痛剧烈、烦躁不安、恶心呕吐。
- **内陷**：有头疽毒邪内攻，分三型——**火陷**（邪盛之体，多见于初起）、**干陷**（溃脓期正虚）、**虚陷**（收口期脾肾阳衰）。
- 进展到**神昏谵语、痉厥抽搐、皮肤瘀斑、尿少，甚则体温不升、四肢厥冷、脉微欲绝**，即阴阳离决之象。

教材的处理口径只有一句但很硬：**一经确诊，立即抢救，不可片刻延误**。这一节因此不属「辨证练习」，属「识别后立刻转」。

## 五、易混四组：教材把鉴别写在同一句里

| 组 | 辨点 |
|---|---|
| 疖 / 疔 | 根浅范围小、出脓即愈 vs 根深如钉、肿势虽小而病重 |
| 痈 / 有头疽 | 单一脓头、易溃易敛 vs 多个蜂窝状脓头、范围大、易内陷 |
| 疖 / 痈 / 脂瘤染毒 | 疖根浅；痈范围较大；脂瘤染毒中心可及囊性感（原有包块） |
| 流痰 / 附骨疽 / 流注 | 流痰起病缓、脓稀夹败絮样物、发于骨关节；附骨疽起病急、疼痛彻骨、脓黄稠；流注发于肌肉深处、与骨无关、多发 |

四组的共同结构是**深浅 + 起病缓急 + 脓的性状**三件事。背病名不如背这三件事。

## 六、五个病证的「按语」在说什么

教材在按语里放的是最容易错的那一点，摘五条：

- **疖**：面部危险三角区者忌挤压——毒邪可循血流上行；
- **疔**：忌早期切开与挤压，防走黄；
- **有头疽**：辨虚实与顺逆，警惕内陷（尤其老年消渴患者）；
- **瘰疬**：颈项肿块质硬固定、逐渐增大者，须先排除恶性（失荣）；
- **附骨疽**：X 线可示骨质破坏与死骨，脓出初稠后稀、久不收口要考虑死骨未除。

五条按语里，三条是「别做什么」，两条是「该查什么」。这就是按语的分量。

## 代价与边界

1. **本章十病证的方药与操作细节，本章只给方向不给剂量**：消、托、补与切开引流的时机在第 4 章，具体方药在各病证的教材原文；本课程不复制剂量。
2. **疮疡最危险的不是「治不好」，而是「看轻了」**：疔被当疖挤压、有头疽的平塌被当好转、附骨疽的死骨未除——三种误判都在教材里写明了，但都要靠人去看。
3. **危候优先**：凡出现走黄内陷征象（疮顶黑陷、肿势散漫、寒战高热、神昏），本章所有辨证推演立即作废，直接按急症处理。

**免责声明：** 本章为教学整理与文献梳理，**不构成诊疗建议，不能替代医师面诊**；任何疮疡的切开、引流、用药须由具备资质的医师面诊后决定。
