# 血管两问：动脉还是静脉 → 到了哪一期

## 用途

下肢的「肿、痛、凉、烂」在下肢血管病里方向相反。两个动作就能先分侧：**摸足背动脉搏动**、**量双侧周径**。分错侧，后面所有处理都会反向。

## 第一问：动脉侧还是静脉侧

| 侧 | 阳性所见 | 病证 |
|---|---|---|
| 动脉（缺血） | 足背动脉搏动减弱/消失、发凉、苍白、汗毛脱落、趾甲增厚、间歇性跛行、静息痛 | 脱疽 |
| 静脉（阻塞/高压） | 搏动正常、静脉显露或曲张、肿胀、色素沉着、条索状硬结 | 筋瘤、青蛇毒、股肿、臁疮 |

## 第二问：到了哪一期／哪一并发症

**动脉侧三期的二期：** 静息痛（夜间抱膝）、肌肉萎缩、趾甲增厚、搏动消失；三期则坏死变黑、可脱落。

**静脉侧按病证分：**

| 病证 | 判据 | 危险 |
|---|---|---|
| 筋瘤 | 迂曲如蚯蚓、站立明显、抬高减轻 | 溃疡、出血 |
| 青蛇毒 | 沿浅静脉条索状红肿硬结 | 蔓延 |
| 股肿 | 突然粗肿、皮温高、浅静脉扩张、**Homans 征阳性**、周径增粗 | **肺栓塞** |
| 臁疮 | 小腿下 1/3 慢性溃疡、久不敛、色素沉着 | 久不愈 |

## 红线

1. **股肿**：疑似即制动、禁按揉、尽快超声＋专科抗凝评估（血栓脱落可致命）。
2. **脱疽三期**：坏死不消退需外科处理，勿无限期保守。

## 四个「别做」

| 别做 | 机制 |
|---|---|
| 给脱疽肢体加温泡脚 | 代谢需求↑而供血不变 |
| 给脱疽肢体加压（弹力袜、紧绑） | 进一步减少动脉灌注 |
| 按揉、热敷股肿患肢 | 血栓脱落风险 |
| 把丹毒当青蛇毒只做局部 | 丹毒是感染，需系统抗感染 |

## 输出格式

```text
侧别：动脉 / 静脉（依据：足背动脉…／周径…）
病证候选：… ｜ 期或并发症：…
红线：无 ／ 有（肺栓塞风险／坏死）→ 处置
下一步：超声（动脉血流／静脉血栓／瓣膜功能）
```

## 边界

只做分侧、分期与红线筛查，不给方药、不给抗凝与手术方案。股肿与脱疽的处置须由专科决定。
