# 血管两问 · 可装载技能

## 何时装载

- 下肢肿、痛、凉、溃疡、静脉曲张；
- 需要判断「能不能热敷/加压/按揉」；
- 教学场景：训练学生先摸动脉再谈辨证。

## 输入

症状（凉/痛/肿/烂）、病程与诱因、跛行距离、静息痛、足背动脉搏动、双侧周径差、皮肤颜色与温度、静脉曲张、Homans 征、既往血栓史。

## 判定

| 条件 | 结论 |
|---|---|
| 足背动脉消失 + 静息痛/坏死 | 脱疽（动脉侧），三期判定；禁加温、禁加压 |
| 突然单侧粗肿 + Homans 征 + 周径差 | 股肿（深静脉血栓）→ 制动、超声、专科抗凝；禁按揉 |
| 沿静脉条索状红肿 | 青蛇毒（浅静脉炎）；与丹毒鉴别（大片、边界清） |
| 迂曲如蚯蚓、抬高减轻 | 筋瘤（静脉曲张）→ 瓣膜功能试验 |
| 小腿下 1/3 久不敛溃疡 + 色素沉着 | 臁疮 → 改善回流为主 |

## 硬规则

1. 侧别未定不做外治（热敷/加压/按摩）。
2. 股肿疑似 → 先制动与超声，不做手法。
3. 脱疽三期坏死不消退 → 外科评估，不作无限期保守。
4. 不输出剂量、抗凝方案与手术方式。

## 反例

1. 把脱疽当「老寒腿」泡脚；
2. 把股肿当肌肉拉伤按摩；
3. 把丹毒当青蛇毒只外敷。

## 边界

本技能做分侧、分期与红线筛查，不给方药与操作。教材依据：第 11 章 11.1–11.5。
