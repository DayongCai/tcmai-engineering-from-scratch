# 数字化四问：字段 → 编码 → 图谱 → 复核

## 用途

把一段中医外科知识（或一条临床判据）转成可被检索、可被统计、可被复核的形式。四问的顺序不可换：字段没定义就编码，会把脏数据锁进标准里。

## 第一问：这条判据能被写成字段吗

| 判据类型 | 字段化方式 | 例 |
|---|---|---|
| 形态（可观察） | 枚举 + 参照照片 | 疮面色泽：红活／灰暗／苍白 |
| 触觉（可操作） | 二分 + 操作说明 | 按之应指：是／否（须写明「按哪里、怎么按」） |
| 数量（可测量） | 数值 + 单位 + 方法 | 周径差（cm，同一水平位） |
| 时间（可判断） | 区间 + 阈值说明 | 潜伏期（天）、病程（月） |
| 主观（不可直接字段化） | 保留原文 + 标签 | 「心中懊憹」→ 标签「神志-体感」，原文并存 |

**规则**：不可字段化的，一律保留原文，不做「翻译」。丢质感比丢精度更糟。

## 第二问：对齐哪个编码

- 病名 → ICD-11 传统医学章节（TM1）／GB/T 16751.2；
- 证候 → TM1 证候编码（本课程的做法是保留教材证名为主键，编码作附属）；
- 方药与外治 → 各自的术语表（方名、药名、外治技术名）。

对齐的结果必须能回指原文，否则宁可不对齐。

## 第三问：属于哪类实体与哪条边

六类实体：病／证／法／方／药／外治（＋经络部位）。
一条完整路径：`病 —(有证)→ 证 —(治法)→ 法 —(选方)→ 方 —(组成)→ 药`，外治另挂 `病 —(外治)→ 外治技术`。

**检查方法**：画出这一支，指出哪一段是空的（有证无法？有法无方？）。

## 第四问：谁复核

| 输出类型 | 复核要求 |
|---|---|
| 急危重症相关（走黄内陷、重症药毒、扭转、尿潴留、胆管炎、蛇伤、破伤风） | 必须人工即时复核；不得以模型建议替代处置 |
| 男科与隐私相关 | 人工复核 + 沟通边界 |
| 外治与操作（切开、挂线、引流） | 人工复核；操作由有资质者执行 |
| 教学与检索类 | 需标注「教学整理·不构成诊疗建议」 |

## 输出格式

```text
字段：<可字段化项> ＋ <保留原文项>
编码：<ICD-11 TM1 / GB/T 16751.2 落点，或「暂不对齐」>
图谱三元组：<实体 - 关系 - 实体>（并指出空支）
复核：<谁复核 + 边界声明>
```

## 边界

本单只做「表示方法」的建议，不产出诊断、不产出编码的最终值、不替代编码员与医师的确认。
