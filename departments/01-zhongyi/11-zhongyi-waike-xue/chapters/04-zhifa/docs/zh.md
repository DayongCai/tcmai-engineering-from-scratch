# 第 4 章 · 治法：消、托、补不是三个选项，是一条时间轴

> **MOTTO:** 「汗之则疮已」——《素问·五常政大论》
>
> **PROBLEM:** 本章 12,765 字，是第 1–4 章里最长的一章（四章依次为 7,720、9,185、9,388、12,765），7 个单元分成内治 2 个、外治 3 个、调护与围手术期 2 个。这个配比说明一件常被忽略的事：教材把一半以上的篇幅给了「怎么动手」，而不是「用什么方」。原因很实际——内治三法的边界只有一句话能说清（脓未成可消、脓成不可消），外治的边界却要用几十个动作与禁忌去划。

## 一、三法是一条时间轴，节点由脓决定

消、托、补常被背成三个并列选项，实际上它们各自只对应一段时间，分界点只有一个：**脓成没成**。

| 阶段 | 局部事实 | 法 | 做什么 | 越界的后果 |
|---|---|---|---|---|
| 肿疡初起，脓未成 | 肿硬、无波动、痛以胀为主 | 消 | 审因消散：热毒清解、寒凝温通、气滞行气、痰凝化痰、瘀血活血 | 用托法过早，等于催一个还没熟的脓 |
| 脓成未溃，或溃而脓出不畅 | 按之应指、疮顶软陷、皮色转亮、痛如鸡啄 | 托 | 透托（毒盛正未衰）或补托（正虚毒盛） | 继续用消法，脓毒不得外泄，反致内攻 |
| 溃后脓泄，疮口未敛 | 脓稠渐少、肉芽红活 | 补 | 益气养血、滋阴助阳，助生肌收口 | 一味攻伐，气血更虚，疮口久不敛 |

时间轴上有三处最常见的错位，教材都点了名：

**其一，脓已成而仍用消法。** 这是最危险的一种。消法的本意是「使毒邪消散于无形」，脓已成则无形可散，只剩有形之脓，必须给出路。继续消，等于把毒关在里头。

**其二，消法用药过用寒凉。** 寒凉冰伏气血，肿硬反而难消，脾胃素虚与年老体弱者尤其如此。教材的措辞是「药宜轻清，量宜适中，不可过剂」——过剂则正气先伤。

**其三，正虚邪恋者一味攻伐。** 疮疡发于消渴、虚劳之人，须消补兼施或先扶正后消散。攻伐不停，正虚更甚，托无可托。

## 二、内治法则：九法各有各的「证」，不各有各的「病」

教材在内治三大法之下展开九条常用法则，用法是按证不按病：

| 法则 | 对应证 | 典型场景 |
|---|---|---|
| 清热解毒 | 热毒蕴结 | 疖、疔、痈、有头疽初期，丹毒、红丝疔 |
| 清热利湿 | 湿热交结、下注 | 臁疮、下肢丹毒、湿疮、缠腰火丹 |
| 凉血活血 | 热入营血、血热瘀滞 | 丹毒重症、红丝疔、血热型白疕、岩肿热毒瘀结 |
| 行气活血 | 气滞血瘀 | 乳癖、瘿瘤、脱疽、股肿、跌打损伤 |
| 化痰散结 | 痰凝 | 瘰疬、流痰、乳癖、肉瘿 |
| 温经散寒 | 寒凝 | 阴疽、脱疽寒凝证、附骨疽初起 |
| 祛风止痒 | 风邪 | 瘾疹、风热疮、皮肤瘙痒 |
| 养阴生津 | 阴虚津伤 | 烧伤后期、岩肿放疗后、慢性溃疡 |
| 通里攻下 | 腑实 | 肠痈初起、阳证疮疡兼便秘 |

九法里最容易被误用的是前两条：把「清热解毒」当外科万应之法，凡红肿一律清解。教材对这条给了明确的刹车——**苦寒之品易伤脾胃，中病即止，不可久服，脾胃虚寒者慎用**。这句话不是客套，它决定了后面很多事的边界：一个脾胃虚寒的下肢溃疡患者，长期清热利湿，疮面会越换越淡。

还有一条必须写进处置流程：**热毒炽盛、肿势迅猛者，须防走黄与内陷；见高热神昏、烦躁不安，立即转急诊中西医结合抢救**。内治在这一步不再是主角，抢救是主角。

## 三、外治药物：四种剂型，各有各的「什么时候停」

外治药物是外科的主体手段，教材按剂型分了四组，每组都有明确的适应证与停用条件：

**膏药**（古称薄贴）。按药性分温凉：清凉者用于阳证各期，温热者用于阴证未溃，提脓祛腐者用于疔痈脓成未溃。停用条件写得很硬：贴后出现丘疹、水疱、瘙痒，立即揭去，改油膏或其他剂型。含铅的膏药不可长期大面积贴敷，孕妇与肝肾功能不全者慎用。

**油膏**（软膏）。质软、不含铅、刺激小，宜于溃疡疮面、颜面与关节活动处。阳证薄摊，阴证稍厚；糜烂渗液者慎用，以免阻遏渗液。含汞砷的提脓祛腐制剂，只可少量局部使用，禁大面积、禁长期、禁用于头面黏膜与大血管神经邻近部位——这条边界不是保守，是防吸收中毒。

**箍围药**（敷贴）。药末调糊，敷于患处四周，箍集围聚、收束疮毒。阳证用寒凉，半阴半阳用平和，阴证用温热。用法的要点是「敷四周、留中心」：中心留空便于观察与后续切开，四周收束使肿势局限。停用条件：肿势越过所敷范围、或皮肤出现刺激反应。

**掺药与药线**。掺药直接作用于疮面，提脓祛腐与生肌收口分两个阶段用；药线插入疮口或瘘管，起引流与祛腐双重作用。三条边界：插入深度以达疮底为度，不可过深伤好肉；脓腐渐尽时逐步减短直至撤除，不可久插；含汞药线按少量、局部、短期使用。

四组剂型合起来有一条共同的停手逻辑：**外治的每一次更换，都要回答「这次换的理由是什么」**。理由只有四类——脓的性质变了、疮面的色泽与肉芽变了、出现过敏或刺激、阶段变了。答不出理由，就是在做机械换药。

## 四、切开与引流：五条原则、四条禁忌、一张记录

切开排脓是外科最不可替代的动作，教材把原则写成了五条，每条都对应一个具体的坏结果：

1. **低位切开**——选脓腔最低位，让脓顺势流出。切在高位，脓液潴留，形成袋脓。
2. **循经直切，避开大血管、神经与重要脏器**——切口方向顺着组织与经络走行，避免损伤。
3. **乳房部以乳头为中心作放射状切口**——免伤乳络，否则形成乳漏。
4. **关节区作横切口或弧形切口**——防瘢痕挛缩影响关节功能。
5. **面部切口小而浅，肛周作放射状切口**——前者为美观与功能，后者为引流与括约肌保护。

切口的大小与深浅也各有边界：**大小以脓液畅出为度，深浅以达脓腔为度，不可过深伤及正常组织**。这两句是切开的度量尺，写着「够用就好」。

四条禁忌必须背成条件反射：**脓未成者不切**（徒伤气血、反增其痛）；**血瘤与岩肿不切**（大出血或扩散转移）；**出血性疾病与严重凝血功能障碍者不切**；**正气极虚者先扶正再切**。第四条容易被误解为「等一等」，实际意思是「同时进行，先给支撑」。

切开只是开始，引流才是过程。引流的三条判据写在引流物的变化上：由稠转稀、由多转少、色由黄转淡，是脓毒渐尽之象；反之，引流不畅而脓液潴留，须调整引流方式而不是加药；脓腔变浅则逐步剪短引流物，直至撤除。深部脓腔配合垫棉加压，使空腔壁相贴而闭合。

记录字段固定为八列：切口位置与方向、切口长度与深度、脓液（量、色、质、味）、引流物种类与深度、引流物性状变化、疮周皮肤（红肿范围、标记线）、疼痛与体温、下次换药要观察的一项。第八列最容易被省，它恰恰是把换药从「照做」变成「有假设」的那一列。

## 五、调护、红线与四种失效

调护在外科不是附属品。教材给的三分治、七分养，落成三件事：**情志**（瘿瘤、乳癖、乳岩多随情志进退）、**饮食**（阳证忌辛热助火，阴证宜适当温补，消渴者控制血糖，瘙痒者忌动风发物）、**起居**（患处制动、抬高患肢、戒烟——吸烟使血管收缩，脱疽与臁疮尤忌）。围手术期则把中医的位置说清了：术前扶正、术后调养，与加速康复的理念相通，但不替代外科规范。

四条红线，触发即转，不在门诊处理：

- 高热寒战、烦躁谵妄、疮顶陷黑无脓——走黄与内陷；
- 腹痛拒按、腹膜刺激征——肠痈穿孔；
- 胆石症合并高热、黄疸、神志改变——急性胆管炎；
- 股肿（下肢深静脉血栓）突发胸痛气促——肺栓塞；精癃突然尿闭——急性尿潴留。

四种失效模式，全都发生在「动作已经做了」之后：

**消托错位。** 脓已成仍消，或脓未成先托。前者致内攻，后者催熟无用之脓。

**切开不彻底。** 切口偏小、位置偏高、方向错误，脓出不畅，反复换药数月，最后形成窦道。教材对此的判断很直接：引流不畅则脓毒潴留，疮口难敛，甚则旁窜深溃。

**外治替代评估。** 用不断更换敷料来回应「肿势在扩大」。换药是动作，不是判断；肿势扩大要先重新评估归口与风险。

**调护空转。** 嘱咐了「清淡饮食、保持心情舒畅」，却没有具体到「戒烟」「控制血糖」「抬高患肢」这些可核查的项。不可核查的医嘱等于没有医嘱。

五项考核：

1. 用「脓成与否」这一个节点，把消、托、补三法各自的时间段与越界后果说清；
2. 给出三个场景（丹毒重症、阴疽初起、臁疮渗液），分别说出该用哪条内治法则、哪条边界不能越；
3. 说出四种外药剂型各一个停用条件，并解释含汞砷制剂的三条禁令；
4. 就一个乳房脓肿，写出切口位置、方向、大小深浅的判据，以及四条禁忌里哪一条最需要先排除；
5. 写出一份切开引流的八列记录，第八列填一个可验证的观察项。

## 六、代价与边界

1. **三法的时间轴有灰色地带。** 半阴半阳证、正虚邪恋证都横跨两个阶段，教材用「消补兼施」「托补并行」处理，实际靠动态观察调整，不能靠一次判断定全程。
2. **九法的分证不等于分方。** 同一个患者常同时具备两三条法则的适应证，合方与取舍靠医师判断，本章只给方向，不给配伍与分量。
3. **外治的禁忌比适应证更重要。** 含铅、含汞砷制剂的限制，血瘤与岩肿禁切，出血性疾病禁切——这些条件的共同点是：违反一次，后果不可逆。
4. **切开是技术，也是判断。** 五条原则能背，手感不能背。低位、够大、方向对，这三件事在模型与尸体上练不出来，只能在带教下反复做。
5. **本章只到动作与方向**。具体处方、分量与用药时长均不在本章范围，须由医师面诊后决定；文中红线为教学设定，实际执行以所在机构制度为准。
