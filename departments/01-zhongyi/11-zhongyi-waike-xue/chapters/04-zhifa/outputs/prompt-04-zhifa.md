# 三法定位单：把当前病例放到「消 / 托 / 补 / 切」的哪一格

## 用途

消、托、补不是三个可挑选的选项，而是一条时间轴上的三个格。这张单子用四个问题，把当前病例定位到唯一的格子上，并同时给出**这一格的禁忌**。定位错了，用药再准也是错时期。

## 四问（按顺序）

1. **成脓了吗？** 肿势高突、皮色转亮、按之应指、痛如鸡啄 → 脓熟；有红肿热痛但无应指 → 未成脓；已有溃口 → 已溃。
2. **正虚吗？** 脉细弱、脓水清稀、疮顶平塌、久不成脓、面色少华 → 正虚；脉数有力、脓稠、肿势高突 → 正不虚。
3. **位面在哪一层？** 皮肤 / 皮肉之间 / 筋骨 / 脏腑（决定外治方式与补的落点）。
4. **有没有该急症处理的征象？** 肿势迅速散漫、神昏、出血不止 → 停止定位，直接建议急症处理。

## 定位表

| 成脓 | 正虚 | 格 | 法与手段 | 禁忌 |
|---|---|---|---|---|
| 未成脓 | —（阴阳决定方向） | **消** | 清热解毒／疏风／化痰／活血／温通；外敷箍围（阳证寒凉、阴证温通） | 成脓后仍消＝把脓逼深 |
| 脓熟 | 不虚 | **切** | 切开排脓 + 引流；内治清热和营 | 脓未成切之则徒伤气血；切口位置与深浅须面诊定 |
| 脓熟 | 虚 | **托 + 切** | 透托（透脓散）或补托（托里消毒散），脓熟后仍须切开引流 | 只托不切＝脓毒内攻 |
| 已溃·顺证 | 不虚 | **提脓祛腐 / 生肌收口** | 换药 + 引流保持通畅 | 引流不畅则疮口难敛 |
| 已溃·逆证 | 虚 | **补** | 补气／补血／双补／滋阴温阳；按位面选落点 | 只补不清则余毒留连 |

## 输出格式

```text
定位：<消 / 切 / 托+切 / 提脓祛腐·生肌 / 补>
依据：成脓—…；正虚—…；位面—…
禁忌：<本格不该做的一件事>
缺证据：<哪一问没答案>
```

## 边界

只做治法定位与禁忌提示，**不给方药剂量、不给切开操作步骤**。脓熟与切开时机必须由医师面诊确认；本单不得替代临床决定。
