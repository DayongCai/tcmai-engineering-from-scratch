# 肛肠四查：血、痛、脱、脓 → 齿线 → 指检 → 红线

## 用途

把「肛门不适」的主诉读成可判断结构：**主诉归位（血／痛／脱／脓）· 齿线与分度 · 指检与镜检 · 红线（锁肛痔）**。第三查是本章的关键——八个病证的鉴别几乎全部依赖指检与肛门镜，跳过它就只能靠猜。

## 第一查：主诉归位

| 主诉 | 首先想到 | 关键追问 |
|---|---|---|
| 便血（鲜红、不痛） | 内痔 | 有无排便习惯改变、便条变细 |
| 便血＋肛门剧痛（周期性） | 肛裂 | 便后疼痛持续多久、是否怕痛忍便 |
| 肛门肿痛、发热 | 肛痈 | 深部者局部体征可不明显（坠胀、里急后重、排尿困难） |
| 反复流脓、瘙痒 | 肛漏 | 外口几个、有无分支、既往有无肛痈 |
| 肿物脱出 | 内痔脱出／脱肛 | 分颗还是环形、能否回纳 |
| 便血＋里急后重＋便条变细（40 岁以上） | **锁肛痔（红线）** | 立即指检＋肠镜 |

## 第二查：齿线与分度

- 齿线以上（黏膜、不敏感）→ 内痔；齿线以下（皮肤、敏感）→ 外痔；上下相连 → 混合痔。
- 内痔四度：Ⅰ 不脱出／Ⅱ 脱出可自行回纳／Ⅲ 需手托回／Ⅳ 不能回纳或立即脱出。
- 脱肛三度：便后自行回纳／需手托／咳嗽行走即脱出。嵌顿（不能回纳、紫暗、糜烂）＝急症。

## 第三查：指检与镜检（不可省）

1. 直肠指检：触肿块（质硬、不平、活动差→警惕恶性）、压痛与波动感（深部脓肿）、内口（肛漏）、括约肌张力；
2. 肛门镜：齿线上黏膜隆起、痔核分颗、裂口位置（后正中多见）；
3. 必要时：肠镜＋活检（确诊锁肛痔）、超声／MRI（复杂肛漏的管道走行）。

## 第四查：红线

**40 岁以上 + 排便习惯改变 + 便血（或便条变细、里急后重）→ 立即肠镜＋活检，不按痔处理。**

## 输出格式

```text
主诉归位：血／痛／脱／脓
病证候选：… ｜ 度或单纯/复杂：…
指检与镜检：做了／未做（缺什么）
红线：无 ／ 有（锁肛痔可疑）→ 肠镜＋活检
```

## 边界

只做主诉归位、分度与红线筛查，不给方药与术式。凡红线命中或嵌顿，输出止于转诊建议。
