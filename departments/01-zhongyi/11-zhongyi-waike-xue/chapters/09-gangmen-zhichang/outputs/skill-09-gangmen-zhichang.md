# 肛肠四查 · 可装载技能

## 何时装载

- 遇到便血、肛门疼痛、脱出或流脓的主诉；
- 需要判断是痔、裂、痈、漏、脱肛还是必须排恶性；
- 教学场景：训练学生先做指检再下结论。

## 输入

主诉类别、便血性状（鲜红/暗红、滴/射/附于表面）、疼痛性质与时限、脱出物形态（分颗/环形、可否回纳）、分泌物、排便习惯改变、年龄、既往肛痈史。

## 四查与规则

1. **主诉归位**：血（内痔/肛裂/锁肛痔）、痛（肛裂/肛痈/血栓性外痔）、脱（内痔/脱肛）、脓（肛痈/肛漏）。
2. **齿线与分度**：内痔四度、脱肛三度、肛漏单纯/复杂。
3. **指检与镜检**：未做则输出「不足以定性」，并列出该做的检查。
4. **红线**：40 岁以上＋排便习惯改变＋便血/便条变细/里急后重 → 肠镜＋活检。

## 硬规则

| 条件 | 输出 |
|---|---|
| 红线命中 | 立即肠镜＋活检，停止按痔处理 |
| 嵌顿（不能回纳、紫暗、糜烂） | 急症处理（复位/手术评估） |
| 深部脓肿（局部体征不明显、坠胀、里急后重、排尿困难） | 指检＋超声，勿按「痔痛」处理 |
| 反复不愈、形态不典型 | 查原发病（克罗恩、结核、血液病），必要时活检 |
| 肛漏多外口/分支 | 标「复杂」，需 MRI/腔内超声定走行 |

## 反例

1. 便血就给痔疮栓（漏锁肛痔）；
2. 肛门痛就按肛裂（漏深部脓肿）；
3. 挂线/手术适应证未经专科确认就承诺疗效。

## 边界

本技能做归位、分度与红线筛查，不给方药与术式。教材依据：第 9 章 9.1–9.8（锁肛痔红线见 9.8.3）。
