# 皮损三读 · 可装载技能

## 何时装载

- 遇到「痒、起疹子」的主诉，需要定位到具体病证；
- 需要判断「急性还是慢性」「湿热还是血虚血瘀」；
- 需要先排除两条红线：重症药毒、疥疮（传染）。

## 输入

皮损类型与形态、分布（单侧/对称/部位）、颜色、有无渗出与鳞屑、有无苔藓化、瘙痒性质与时间（夜间是否加重）、病程与分期、用药史、接触与家族/集体发病史、黏膜与全身症状。

## 三读

1. **形态**：先用一票判据定病（单侧带状→蛇串疮；骤起骤退→瘾疹；薄膜现象＋点状出血→白疕；用药史→药毒；隧道＋夜间剧痒→疥疮）。
2. **分期**：进行期（鲜红、新疹、渗出）→湿热/血热；静止期（色淡、鳞屑）→脾虚/血虚风燥；退行期（肥厚、暗红）→血虚风燥/血瘀。
3. **病因**：按痒的性质对风/湿/热/虫/血虚。

## 红线与优先级

| 条件 | 处置 |
|---|---|
| 尼氏征阳性、表皮大片剥脱、黏膜糜烂、高热 | 重症药毒 → 停可疑药 + 急症处理 + 转诊，暂停辨证 |
| 夜间剧痒 + 接触传染史 + 隧道 | 疥疮 → 同住者同治 + 镜检确认 |
| 皮损骤然泛发、色泽鲜艳、有明确用药史 | 先按药毒处理并停可疑药 |

## 输出模板

```text
形态：… → 病证候选：…
分期：… → 病因轴：…
红线：无／有（项）
缺证据：…
下一步：…
```

## 反例

1. 只按「痒」给消风散，不读形态；
2. 把疥疮当湿疮治（不同治同住者，反复复发）；
3. 药毒仍按湿热论治而不停药。

## 边界

本技能做结构与红线判断，不给方药、外用强度与疗程，不替代面诊。教材依据：第 8 章 8.1–8.9（含 8.8 重症药毒、8.9 疥疮传染两项硬条件）。
