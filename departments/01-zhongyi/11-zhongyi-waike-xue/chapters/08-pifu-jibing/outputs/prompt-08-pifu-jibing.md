# 皮损三读：形态 → 分期 → 病因

## 用途

一份皮肤科主诉（痒、起疹），用三步读成可判断结构：**读形态（皮损类型＋分布）· 读分期（进行／静止／退行）· 读病因（风／湿／热／虫／血虚）**。顺序不可换——形态读错，分期与病因都会跟着错。

## 第一读：形态（一票判据在这里）

| 判据 | 指向 |
|---|---|
| 成簇水疱 + 单侧带状、不过正中线 | 蛇串疮 |
| 风团、骤起骤退、退后不留痕迹、发无定处 | 瘾疹 |
| 红斑＋多层银白鳞屑，**薄膜现象＋点状出血** | 白疕 |
| 明显用药史 + 皮疹骤然泛发、色泽鲜艳 | 药毒 |
| 指缝/腕屈/下腹丘疹水疱 + **隧道** + 接触传染史 | 疥疮 |
| 多形性皮损 + 对称 + 渗出倾向 + 反复 | 湿疮 |
| 圆形脱发区、头皮光滑、无瘢痕 | 油风 |
| 粉刺/丘疹/脓疱 + 颜面胸背 + 青年 | 粉刺 |
| 面中部红斑、毛细血管扩张、脓疱、鼻赘 | 酒齄鼻 |

## 第二读：分期

| 期 | 皮损 | 病因轴 |
|---|---|---|
| 进行期/急性 | 色鲜红、新疹不断、渗出明显 | 湿热 / 血热 |
| 静止期/亚急性 | 色淡、鳞屑、结痂 | 脾虚湿蕴 / 血虚风燥 |
| 退行期/慢性 | 肥厚、苔藓样变、色暗 | 血虚风燥 / 血瘀 |

## 第三读：病因（痒的五个来源）

| 痒的性质 | 病因 | 对应 |
|---|---|---|
| 游走不定、遇风加重 | 风 | 瘾疹 |
| 渗液缠绵、遇湿加重 | 湿 | 湿疮 |
| 灼热、遇热加重 | 热 | 蛇串疮、酒齄鼻 |
| **夜间剧痒** | 虫 | 疥疮（追问传染史） |
| 干燥脱屑、久病或老年 | 血虚 | 白疕静止期、油风 |

## 红线（优先于一切辨证）

1. **重症药毒**：全身弥漫红斑、水疱大疱、**尼氏征阳性**、表皮松解剥脱，或口腔/眼/外生殖器黏膜糜烂，伴高热烦躁 → 立即停可疑药、按急症处理并转诊。
2. **疥疮**：同住者与接触者必须同治，否则复发；需疥虫镜检支持。

## 输出格式

```text
形态：<主皮损＋分布> → 病证候选：…
分期：<进行/静止/退行> → 病因轴：…
红线：无 ／ 有（重症药毒/疥疮）→ 处置优先
缺证据：…
下一步：…
```

## 边界

只做形态—分期—病因的结构化读法与红线筛查，不给方药与外用药强度、不替代面诊。皮损描述须固定光照与部位，便于前后可比。
