# 急症六问 · 可装载技能

## 何时装载

- 外伤、毒伤、急腹症的主诉；
- 需要判断「能不能观察」；
- 教学场景：训练学生先判时限再谈辨证。

## 输入

受伤/咬伤时间与方式、部位、面积与深度、局部进展、意识与呼吸、体温与循环、腹痛起始与范围、黄疸、既往病史与免疫史。

## 判定表

| 条件 | 结论 |
|---|---|
| 烧伤：面积大、深Ⅱ度以上、头面/会阴/关节、吸入性损伤 | 立即急诊 |
| 蛇伤：眼睑下垂、复视、吞咽困难、气促、发绀 | 立即急诊（神经毒） |
| 蛇伤：瘀斑血疱、出血不止 | 急诊（血循毒），监测凝血 |
| 破伤风：张口困难、苦笑面容、角弓反张、喉痉挛 | 立即急诊 |
| 肠痈：右下腹固定压痛＋反跳痛/肌紧张 | 外科急会诊 |
| 胆石症：痛＋热＋黄（＋神志改变/低血压） | 急诊（胆管炎） |
| 冻疮：紫暗、水疱溃烂、坏死 | 专科处理 |

## 硬规则

1. 时限命中 → 停止辨证，只输出转诊建议。
2. 烧伤「不痛」不代表性轻，Ⅲ度痛觉消失。
3. 蛇伤局部轻不代表轻，风毒型以全身为主。
4. 不输出液体量、抗毒血清剂量、手术指征。

## 反例

1. 蛇伤「先观察一夜」；
2. 肠痈先按胃痛服药；
3. 烧伤按面积小就居家处理而忽略吸入性损伤。

## 边界

本技能做分类与时限判定，不含急救操作与药物。教材依据：第 12 章 12.1–12.6。
