# 急症六问：什么伤／什么毒 → 量 → 全身 → 时限

## 用途

本章六证（冻疮、烧伤、毒蛇咬伤、破伤风、肠痈、胆石症）没有共同病机，但有共同结构：**先量、再判全身、最后看时限**。这张单子的唯一目的是尽早识别「必须立刻转急诊」的那一档。

## 第一问：什么伤／什么毒

| 类别 | 病证 | 关键病史 |
|---|---|---|
| 伤 | 冻疮 | 寒冷暴露时长、部位（手足耳廓面颊） |
| 伤 | 烧伤 | 热源（火焰/热液/化学/电/放射）、时间、密闭空间（吸入性损伤） |
| 毒 | 毒蛇咬伤 | 蛇形、咬伤时间、局部进展速度 |
| 感染 | 破伤风 | 外伤史、伤口深窄污染、潜伏期 |
| 急腹症 | 肠痈 | 腹痛起始部位与转移、时限 |
| 急腹症 | 胆石症 | 右上腹痛放射、发热、黄疸、既往结石史 |

## 第二问：量

- 烧伤：面积（新九分法／手掌法≈1%）＋深度（Ⅰ／浅Ⅱ／深Ⅱ／Ⅲ）＋部位（头面、手足、会阴、关节）＋吸入性损伤；
- 蛇伤：毒型（火毒／风毒／风火毒）；
- 破伤风：潜伏期长短、抽搐频率；
- 肠痈：腹痛范围、反跳痛与肌紧张；
- 胆石症：痛＋热＋黄是否并见。

## 第三问：全身反应（本章重心）

发热、意识、呼吸（气促、发绀、吞咽困难）、循环（脉细、四肢冷）、尿量。

## 第四问：时限判定（命中即转急诊）

| 条件 | 判定 |
|---|---|
| 烧伤面积大／深Ⅱ度以上／头面或吸入性损伤 | 立即急诊（休克、气道风险） |
| 蛇伤出现眼睑下垂、复视、吞咽困难、气促 | 立即急诊（呼吸麻痹） |
| 破伤风潜伏期短、抽搐频繁、喉痉挛 | 立即急诊（窒息） |
| 腹痛范围扩大＋反跳痛＋肌紧张；或痛热黄并见 | 立即外科评估（穿孔／胆管炎） |
| 冻疮出现紫暗、水疱溃烂、坏死 | 专科处理（深部坏死） |

## 输出格式

```text
类别：伤／毒／感染／急腹症 ｜ 病证候选：…
量：…
全身反应：…
时限：<安全观察 ／ 立即转诊（依据）>
```

## 边界

只做分类、量与时限判定，不含急救操作、药物剂量与手术指征。凡命中时限即输出「立即就医」，不做进一步辨证。
