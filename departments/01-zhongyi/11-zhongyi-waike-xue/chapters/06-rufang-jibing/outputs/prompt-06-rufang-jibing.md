# 乳房五问：先定性质，再谈辨证

## 用途

乳房肿块与乳头溢液的门诊记录，用五问把它读成可判断的结构：**位置与来源 · 性质 · 消长规律 · 危险征象 · 该不该转诊**。五问里第四、五问是「一票否决」：命中即停止辨证，转诊。

## 第一问：位置与来源

- 位于乳房哪个象限？乳晕区还是外周？
- 是腺体肿块、囊性、还是乳腺外（皮下/胸壁）？
- 溢液是单孔还是多孔？挤乳晕区能否诱发？

## 第二问：性质（四类）

| 性质 | 判据 |
|---|---|
| 急性化脓（乳痈） | 红肿热痛、乳汁排出不畅、可伴发热；分未成脓／已成脓／溃后 |
| 非哺乳期慢性炎（粉刺性乳痈） | 非哺乳期、乳晕部肿块、粉刺样/油脂样溢液、反复发作、可成瘘 |
| 良性增生（乳癖） | 胀痛＋肿块，双侧多发、质中、边界不清但活动好、随月经与情绪消长 |
| 乳头溢血（乳衄） | 单孔或多孔血性/浆液血性溢液，常无肿块，乳晕区可及小结节 |

## 第三问：消长规律（决定病机落点）

| 规律 | 病机 | 治法方向 |
|---|---|---|
| 随喜怒消长 | 肝郁气滞、痰凝 | 疏肝解郁、化痰散结（忌峻猛破气破血） |
| 随月经周期消长 | 冲任失调 | 调摄冲任（补益肝肾、整理阴阳） |
| 不随任何因素变化、持续增大 | 不支持良性增生 | 转第二→第五问 |

## 第四问：危险征象（恶变警示）

- 肿块短期内迅速增大、质地变硬、表面不光滑；
- 与皮肤或深部组织粘连、固定不移；
- 乳头溢血、乳头回缩；
- 皮肤橘皮样变、酒窝征；
- 腋窝淋巴结肿大。

**命中任一项 → 进入第五问，不再按乳癖/乳痈处理。**

## 第五问：该不该转诊

教材红线：上述任一项命中，**立即转诊做病理（金标准），不可延误**。影像（彩超/钼靶/MRI）用于发现与分级，不替代病理。

## 输出格式

```text
性质：<急性化脓/慢性炎/良性增生/溢血>
病机落点：<肝郁/冲任/胃热/肝火/脾虚>
危险征象：无 ／ 有（<项>）
结论：<按性质分期处理 ／ 立即转诊病理>
缺证据：<如「未做彩超」「溢液未做涂片」>
```

## 边界

只做性质判定、病机落点与转诊阈值判断，不给方药剂量、不给手术方案。乳岩的四条转诊条件一旦命中，输出止于转诊建议。
