# 男科四筛：归位 → 三条红线 → 一个动作 → 检查清单

## 用途

把男科主诉读成可判断结构：**系统归位 → 排三条红线 → 关键体检动作 → 该做的检查**。男科的风险集中在「先按炎症治两周」，所以第二筛必须先做。

## 第一筛：系统归位

| 系统 | 病证 | 主诉特征 |
|---|---|---|
| 腺体与感染 | 子痈 | 睾丸/附睾肿痛（急性红肿热痛；慢性硬结坠胀） |
| | 精浊 | 尿频尿急尿痛＋尿道滴白＋会阴少腹腰骶坠痛 |
| | 血精 | 精液带血，可伴射精痛 |
| 排尿 | 精癃 | 50 岁以上、进行性排尿困难、夜尿增多 |
| 生殖 | 阳痿 | 勃起不能/不坚/不久 > 3 个月 |
| | 不育症 | 同居一年未避孕未孕、女方正常、精液异常 |
| 阴囊积液 | 水疝 | 阴囊无痛无热、囊性、透光试验阳性 |

## 第二筛：三条红线

1. **睾丸扭转**：青少年突发睾丸剧痛、**托起阴囊疼痛反加重**、精索增粗缩短 → 立即超声＋泌尿外科急诊（6 小时窗口）。
2. **急性尿潴留**：小便完全不通、小腹胀满膨隆、疼痛难忍 → 急症导尿/泌尿外科。
3. **睾丸肿瘤**：睾丸**硬、重、持续增大**、透光阴性 → 尽早转泌尿外科（禁穿刺、禁按炎症观察）。

## 第三筛：一个动作定分歧

- 托起阴囊：疼痛减轻 → 附睾炎（子痈）；疼痛加重 → 扭转。
- 透光试验：阳性 → 水疝；阴性＋硬重 → 肿瘤；阴性＋可还纳＋冲击感 → 狐疝。

## 第四筛：检查清单

| 病证 | 必查 |
|---|---|
| 子痈 | 血常规、尿常规、彩色多普勒超声（血流） |
| 精浊 | 直肠指检＋前列腺液（白细胞、卵磷脂小体） |
| 精癃 | 直肠指检＋超声（体积、残余尿） |
| 血精 | 精液常规、前列腺液、经直肠超声 |
| 阳痿 | IIEF-5、性激素、夜间勃起监测、海绵体多普勒 |
| 不育症 | 精液分析、性激素、生殖道感染、必要时遗传学；**女方同步检查** |
| 水疝 | 透光试验、超声、必要时穿刺 |

## 输出格式

```text
系统归位：…
红线：无 ／ 有（扭转/尿潴留/肿瘤）→ 急诊或转诊
关键动作结果：托阴囊…／透光…
下一步检查：…
```

## 边界

只做归位、红线筛查与检查清单，不给方药与剂量、不做检查判读。三条红线命中即转诊。
