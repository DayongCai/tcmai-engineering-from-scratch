# 第 10 章 · 泌尿男性疾病：三个系统，三条不可错过的红线

> **MOTTO:** 「凡男子阳痿不起，多由命门火衰，精气虚冷，或以七情劳倦，损伤生阳之气」——教材·第10章·10.5.1（《景岳全书》）
>
> **PROBLEM:** 这一章的七个病证分属三套完全不同的系统：腺体与感染（子痈、精浊、血精）、排尿（精癃）、生殖（阳痿、不育症）、以及阴囊内的一包水（水疝）。学生常把它们当成「一串男科病」一起背，于是丢掉三件真正救命的事——**睾丸扭转**（6 小时内不处理就坏死）、**急性尿潴留**（尿不出就是急症）、**睾丸肿瘤**（硬、重、透光阴性）。
>
> **双根因定位:** 环境逼迫（男科门诊最大的风险是「先按炎症治两周」：把扭转当附睾炎、把肿瘤当鞘膜积液）+ 知识积累（本章 35 个单元、26,896 字里，病因 300 次居三辨首位、脏腑 139 次居四位面首位——七个病证的病机几乎都落在肾、肝、脾与精室、膀胱，而鉴别靠的是**体检动作与影像**，不是症状描述）

**教材出处:** 教材·第 10 章（10.1 子痈、10.2 精浊、10.3 精癃、10.4 血精、10.5 阳痿、10.6 不育症、10.7 水疝，共 7 病证 35 单元）。本章数字由 `code/main.js` 读 `standards/waike/units.json` 现算。

## 一、三套系统，七個病证的归位

| 系统 | 病证 | 一句话判据 |
|---|---|---|
| 腺体与感染 | 子痈 | 睾丸或附睾肿痛；急性红肿热痛、慢性硬结坠胀（＝急慢性附睾炎/睾丸炎） |
| | 精浊 | 尿频尿急尿痛＋尿道滴白＋会阴少腹坠胀（＝慢性前列腺炎） |
| | 血精 | 精液带血，可伴射精痛（＝精囊炎/前列腺炎所致） |
| 排尿 | 精癃 | 50 岁以上、进行性排尿困难、夜尿增多（＝前列腺增生） |
| 生殖 | 阳痿 | 不能勃起或勃起不坚不久，病程 >3 个月（＝勃起功能障碍） |
| | 不育症 | 同居一年以上未避孕未孕、女方正常、精液分析异常 |
| 阴囊内积液 | 水疝 | 阴囊无痛无热、囊性肿物、**透光试验阳性**（＝鞘膜积液） |

三套系统的治法语言也不同：腺体以清利湿热、活血化瘀为主；排尿以补肾（或清利）＋化气行水为主；生殖以补肾填精、疏肝解郁为主。合在一起背，就会用错语言。

## 二、红线一：睾丸扭转 vs 子痈，只差一个动作

教材在子痈的鉴别里给了一个几乎「一摸就分」的判据：

> 睾丸扭转，多见于青少年，**突发睾丸剧痛，托起阴囊疼痛不减轻反加重**，精索增粗缩短；彩色多普勒超声示患侧睾丸血流信号减少或消失。

而急性子痈的典型是**托起阴囊疼痛减轻**（附睾炎的特征性体征）。于是「托起阴囊后疼痛是加重还是减轻」这一动作，就把「6 小时内要手术的急症」和「抗感染＋中药的炎症」分开了。

教材同时把这条写成红线：**青少年突发睾丸剧痛，先排扭转，再做其他考虑。**

## 三、红线二：精癃的急性尿潴留

精癃（前列腺增生）的辨证分虚实：湿热下注、气滞血瘀属实（起病较急、尿路刺激征或小腹胀痛明显）；肾阳衰微、中气下陷属虚（病程日久、排尿无力、神疲畏寒）。

但教材在辨证纲领之后，紧接着写了「急症识别红线」：**若小便完全不通、小腹胀满膨隆、疼痛难忍，为急性尿潴留**——这一条优先于任何分型。因为「癃」（点滴而出）与「闭」（小便不通）在教材里是同一病证的两端，闭属急症。

诊断层面还有两项固定动作：**直肠指检**（前列腺增大、中央沟变浅或消失）＋**超声**（体积增大、残余尿量增多）。残余尿是「排不干净」的客观证据，比主诉可靠。

## 四、红线三：水疝的鉴别里藏着肿瘤

水疝（鞘膜积液）的判据很干脆：阴囊无痛无热、皮色正常、囊性肿物、**透光试验阳性**、穿刺抽得淡黄色清亮液体。

教材给的三个鉴别恰好是三类不同性质的病：

| 鉴别 | 判据 | 性质 |
|---|---|---|
| 狐疝（腹股沟疝） | 肿物可还纳、咳嗽有冲击感、**透光阴性**、可闻肠鸣 | 需外科 |
| **睾丸肿瘤** | 睾丸**质地坚硬、沉重、持续增大**、透光阴性 | 需尽早转泌尿外科 |
| 子痈 | 阴囊红肿热痛明显 | 炎症 |

于是「透光试验」成了这一章最便宜的一次分诊：阳性＝水；阴性＋硬重＝要想到肿瘤。

## 五、精浊与血精：两套「说不清」的病，靠检查定

- **精浊**（慢性前列腺炎）：症状谱极宽（尿路刺激、滴白、会阴少腹腰骶坠痛），辨证首辨虚实——急性发作、苔黄腻脉滑数属湿热实证；日久、隐痛、腰膝酸软属虚（阴虚火旺／肾阳虚损）；痛处固定如刺、舌紫暗属瘀。
  客观依据是**直肠指检＋前列腺液检查**（白细胞增多、卵磷脂小体减少）。
- **血精**：精液带血，多见于青壮年，常反复发作。教材特意写了一句临床态度：患者多因「见血」而紧张焦虑，**临证当耐心解释、消除顾虑**。辨证首辨虚实（湿热／阴虚火旺／瘀血），检查靠精液常规、前列腺液与经直肠超声。

这两个病的共同点：**主诉模糊、焦虑重、检查才是判据**。所以本章把它们放在「腺体与感染」一组，而不是「肾病」一组。

## 六、阳痿与不育：从「补肾」转到「查因」

- **阳痿**：教材的诊断要点已经把重心从「肾虚」挪到了**评估**——病史（起病缓急、有无晨勃与夜间勃起、环境与夫妻关系）、IIEF-5 问卷、性激素、夜间勃起监测、海绵体多普勒超声。这一串检查的用处是分清「心理性」「血管性」「内分泌性」。辨证分虚实：肾阳不足、心脾两虚属虚；肝郁气滞、湿热下注、惊恐伤肾属实。
教材把不育的根源追到「天癸」，用的是《内经》的原文：

> 「丈夫八岁，肾气实，发长齿更；二八，肾气盛，天癸至，精气溢泻，阴阳和，故能有子」——《素问·上古天真论》

这句给了不育辨证的时间轴：肾气盛衰与天癸至竭决定生育能力，所以年龄与「肾气」是同一件事的两面。

- **不育症**：诊断三条件（同居一年以上未避孕、女方生育能力正常、男方精液分析异常），教材还写了**夫妇同治**——女方须同步检查。辨证从肾精亏虚立论，兼湿热血瘀肝郁。

两节的共同转向很值得注意：**先分类（器质/心理、男方/女方），再辨证**。这与全书的「先辨病后辨证」是同一条原则。

## 代价与边界

1. **三条红线优先于辨证**：青少年突发睾丸剧痛（扭转）、小便完全不通（尿潴留）、睾丸硬重且透光阴性（肿瘤）——命中即转诊，不做分型推演。
2. **本章不含方药剂量与检查阈值**：精液分析、性激素、IIEF-5 的具体判读以报告与专科医师为准；教材给的是「要查什么」，不是「多少算异常」。
3. **隐私与沟通**：男科问诊涉及性生活史与生育史，教材在多处提示「耐心解释、消除顾虑」；采集病史的方式本身就是治疗的一部分。
4. **不育是夫妇问题**：只查男方或只查女方都会得出错误结论，教材明确要求同步检查。

本章为教学整理与文献梳理，**不构成诊疗建议，不能替代医师面诊**；男科疾病的诊断依赖体检、影像与实验室检查，须由专科医师完成。
