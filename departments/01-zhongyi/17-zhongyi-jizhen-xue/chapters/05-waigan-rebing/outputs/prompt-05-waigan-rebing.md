# 热不是敌人，热伤到的那个器官才是 · 提示词

## 用途

给「热不是敌人，热伤到的那个器官才是」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「四道门：从症状走到人群 → 卫气营血不是四个格子，是四段斜坡 → 判据与升级路径 → 动作与时限」这条链。

本章为教学整理，不构成诊疗建议。持续高热伴意识改变、出血点、尿少，请立即就医；具体操作以现行规范与所在机构制度为准。
