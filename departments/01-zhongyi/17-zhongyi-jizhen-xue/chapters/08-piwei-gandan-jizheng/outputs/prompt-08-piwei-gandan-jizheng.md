# 红线先行

## 用途

吐泻与腹痛最容易把「需要外科」的病人留在内科。**红线之内不谈证型。** 本章三项全书第一（汉字、数值、引书），密度最高。

## 步骤

### 1. 过红线

腹膜刺激征／转移性右下腹痛／上腹剧痛放射至背 → 外科

### 2. 过公卫红线

剧烈吐泻疑霍乱 → 隔离＋补液（隔离即治疗环节）

### 3. 评脱水

口渴、尿少、皮肤弹性、血压（补液先于辨证）

### 4. 辨证型

寒湿／湿热／食滞；急黄看「速度」；胆道看 Charcot 三联

## 输出

① 红线命中项；② 脱水程度；③ 证型；④ 处置与转诊。

## 边界

- 数字一律由 `code/main.js` 读 `standards/jizhen/units.json` 现算，不手写；
- 不给药物剂量、不给监护参数（属急诊医学与重症医学规范）；
