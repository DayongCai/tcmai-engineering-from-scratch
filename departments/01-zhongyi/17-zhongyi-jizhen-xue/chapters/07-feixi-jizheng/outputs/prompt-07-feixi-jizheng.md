# 喘三级

## 用途

喘的判据不在「喘不喘」，在**能不能平卧、能不能说完整句**。三级一旦到「喘脱」，辨证让位于固脱。

## 步骤

### 1. 定级

声高气粗呼出为快＝实；声低气怯吸入为快＝虚；鼻煽汗出肢冷脉浮大无根＝脱

### 2. 判持续

常规处理无效、说话断续、发绀＝持续状态（「持续」＝升级）

### 3. 定处置

实：宣肺泻实；虚：补肺纳肾；脱：固脱为先

### 4. 标红线

大咳血：一次＞100 mL 或 24h＞500 mL → 转诊

## 输出

① 喘级；② 是否持续状态；③ 处置方向；④ 红线与转诊。
