# 闭脱二分

## 用途

急症的病机不在「虚在哪」，而在「往哪一步恶化」。四条主轴是阶梯：邪盛 → 气机逆乱 → 脱 → 离决。**闭脱二分是所有后续判断的前置。**

## 步骤

### 1. 分闭脱

牙关紧闭、两手握固、脉沉实＝闭；目合口开、手撒肢冷、脉微欲绝＝脱（用反即危）

### 2. 定邪正

邪盛为主？正衰为主？二者并重？（决定攻补次序）

### 3. 选体系

外感热病→卫气营血；心脑→脏腑；血证→气血津液；中毒创伤→病因＋脏腑

### 4. 定方向

闭：开窍；脱：固脱；并见：先固脱后开窍（不给剂量）

## 输出

① 闭／脱／并见；② 邪正主次；③ 辨证体系；④ 救治方向（开窍／固脱／双管）。
