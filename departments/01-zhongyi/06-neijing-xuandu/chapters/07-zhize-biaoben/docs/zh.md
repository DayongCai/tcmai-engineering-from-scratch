# 第 7 章 · 治则是排序问题，不是选方问题

> **MOTTO:** 「知标本者，万举万当，不知标本，是谓妄行」——《素问·标本病传论》
>
> **PROBLEM:** 「急则治标，缓则治本」这八个字人人会说，但没人告诉你什么算「急」。于是临床上出现两种相反的错误：一种是把所有的「标」都放着不管，只管本，病人发热、腹满、二便不通还在慢慢调理；另一种是见症治症，追着标跑，本一直没动。原文其实给了判定条件——中满、小大不利——只是那些条件散在《标本病传论》的一大段里，被概括成口号之后就丢了。数也可以现算：本章四篇教材本 5,346 字、全文 10,084 字，覆盖 53.0%；原文一长串「先……后……」里，例外只有两类。

**双根因定位:** 环境逼迫（门诊时间有限，必须当场决定先治哪一头；顺序错了，后面的方再好也追不回来） + 知识积累（治则在原文里是三层：排序规则（标本）、方向规则（正治反治）、失效后的再判断（求其属）。教材通常只讲第一层的口号与第二层的名词，第三层几乎不讲，而它恰恰是最像现代临床思维的一层）

## 一、标本：把「治什么」换成「先治什么」

《标本病传论》开篇不问「何病何治」，而问「病有标本，刺有逆从，奈何」。回答的第一句就把标本定义成了可互换的求解方向：

「有其在标而求之于标，有其在本而求之于本，有其在本而求之于标，有其在标而求之于本」（《素问·标本病传论》）。

四种组合不是四个位置，而是四种**求解路径**：它承认「治标」也能治本，「治本」也可能绕道治标。标本不是「重要的」与「次要的」之分，是「先动哪一端」之分。

所以本章讲排序，不讲选方。方是排序之后的产物；排序错了，方越对越坏事——该先通腑的病人，你给他补中益气，方没错，时机全错。

原文接下来说的是一长串「先……后……」。这些条款不必逐条背，抽出方向即可：

- 先病而后逆者治其本；先逆而后病者治其本；
- 先寒而后生病者治其本；先病而后生寒者治其本；
- 先热而后生病者治其本；先病而后泄者治其本；先泄而后生他病者治其本。

十余条里，绝大多数结论都是「治其本」，说明默认方向很明确。真正有信息量的是例外，而例外只有两类。

> 「先热而后生中满者治其标」——《素问·标本病传论》

> 「小大不利治其标，小大利治其本」——《素问·标本病传论》

两个例外指向同一类情况：**中满**与**二便不通**。前者是气机中焦闭塞，后者是出路断绝。二者共同的性质是「不通」——不是病得重，而是通路断了。通路一断，后面所有的治疗都送不到地方，所以必须先通。

于是「急则治标」这句话就有了条件，不再是一句感觉：

| 判定 | 条件 | 处置 |
|---|---|---|
| 默认 | 有明确因果先后 | 先治其本 |
| 例外一 | 中满（中焦闭塞） | 先治其标 |
| 例外二 | 小大不利（二便不通） | 先治其标 |

这是本章最实用的产出：**「急」不是一个形容词，是一组可枚举的征象**。临床上遇到不确定，先问三件事——有没有中满、二便通不通、是虚是实。前两问定例外，第三问定方向。

同一篇里还有两条相反的默认，值得单列：

> 「病发而有余，本而标之，先治其本，后治其标；病发而不足，标而本之，先治其标，后治其本」——《素问·标本病传论》

有余先治本（去其因），不足先治标（扶其正、救其急）。这是攻补次序的原文依据，也说明「虚实」这一维是排序的前置条件——虚实判错，顺序整个反过来。第五章说过十九条只给了归属一维，这里是同一个道理：**任何单一维度的治则都不能自足**。

最后一条总纲：「间者并行，甚者独行」——《素问·标本病传论》。病轻而缓，标本可以同时治；病重而急，只能专治一头，不能分兵。这句话是给「多管齐下」设的限制：病重时面面俱到，等于哪一面都没到。

## 二、正治与反治：不是反着治

方向规则在《至真要大论》，一句话给完：

> 「寒者热之，热者寒之，微者逆之，甚者从之」——《素问·至真要大论》

前两句是正治（逆其病性而治），后两句才是关键：**病势轻微时逆治，病势深重时从治**。为什么重了反而要顺？**因为重病往往拒药**——你给他热药，他格拒不受，甚至加重。此时要**先顺其表象**、入其门，**再逆其本质**。

> 「逆者正治，从者反治」——《素问·至真要大论》

反治具体有四条：

> 「热因寒用，寒因热用，塞因塞用，通因通用」——《素问·至真要大论》

四条各对应一种「表象与本质相反」的情形：真寒假热、真热假寒、脾虚中满（以补治满）、积滞下利（以泻治利）。

原文对反治的限定极严，紧接着的两句是全篇最要紧的注解：「必伏其所主，而先其所因，其始则同，其终则异」。**开始看起来与病象同向，最终结果与病象反向**——「同」是手段，「异」是目的。只学了「同」的半句，反治就变成了「以寒治寒」的胡来。

这里必须说清一处最常见的误用：**反治不是「反常治法」的通行证**。它的门槛是「甚」——病势深重且拒药；轻证用它，是把简单问题做成复杂问题。

## 三、判据：求其属、条件依赖与四种失效

### 求其属：当治疗本身成为诊断

治则里最像现代临床思维的一段，是「治之不效怎么办」。

> 「诸寒之而热者取之阴，热之而寒者取之阳，所谓求其属也」——《素问·至真要大论》

用寒药治热，热不退——这不是热太盛，是「取之阴」，即阴不足所致的虚热，当滋阴而非清热。用热药治寒，寒不去——是阳不足，当补阳而非散寒。

这一条的真正价值不在给出两个治法，而在给出一条方法论：**治疗反应是诊断信息**。**按常规方向治而不效**，说明你的**归属判断错了**；错误的方向本身告诉你正确的方向在哪。「以药测证」四个字，源头就在这里。

前提是「按常规方向治过，且剂量与疗程足够」。这一条被滥用得也很厉害：一剂不效就换方向，那不是求其属，那是没有方向。原文的语境是「方士用之，尚未能十全」，说的是常规治法在多数情况下有效、少数情况下不效——**它是例外处理，不是首选**。

### 一病五法：条件依赖

最后一层是方法本身的选择。《异法方宜论》开篇就问了一个尖锐的问题：

「医之治病也，一病而治各不同，皆愈，何也？」（《素问·异法方宜论》）——同一个病，五种治法，都治好了，凭什么？

回答是「地势使然也」：东方鱼盐之地，病多痈疡，治宜砭石；西方水土刚强，病生于内，治宜毒药；北方风寒冰冽，脏寒生满，治宜灸焫；南方雾露所聚，病多挛痹，治宜微针；中央地平以湿，食杂不劳，病多痿厥寒热，治宜导引按蹻。

结论只有一句：「故圣人杂合以治，各得其所宜」（《素问·异法方宜论》）。这段话常被读成「因地制宜」的泛泛之谈，其实它论证的是一件更硬的事：**同一疾病，在不同条件下，最优方法可以不同，而且都成立**。这让「多方法并存」有了合法性——不是「都能治」，而是「各自在自己的条件下都能治」。

现代用法很直接：读一篇疗效研究，先看它的人群条件，再看结论。一种疗法在 A 人群有效，不构成在 B 人群有效。

### 两档判据与四种失效

| 档 | 成立条件 | 能拿它做什么 | 不能拿它做什么 |
|---|---|---|---|
| **依据** | 有篇名、有原文、条件可枚举（中满、小大不利、有余不足、甚者从之） | 决定先治哪一头；决定逆治还是从治；决定用哪一种方法 | 不能当处方，不能给剂量，不能替代虚实判断 |
| **参照** | 属枚举之外的急症、属后世的发挥与流派口号、属条件未写清的经验 | 提示还可以往哪里找条件；作教学举例 | 不能写「原文规定」，不能当通用路径 |

| 失效模式 | 本章的具体样子 | 拦法 |
|---|---|---|
| **以注代经** | 把「急则治标」这八字口号当原文，其实原文给的是中满与小大不利两条枚举 | 引口号必回到两条枚举 |
| **断章取义** | 单取「甚者从之」，跳过「其始则同，其终则异」，把从治读成跟着病象走 | 引从治必带「终则异」 |
| **版本混用** | 教材本《至真要大论》只有 2,421 字（全文 7,018），治则段落之外的推演不在教材上 | 引治则一律以全文为准 |
| **望文生义** | 把「反治」读成「反着治」、「标本」读成「重要与次要」 | 先定「反治＝顺其表象」、「标本＝先后两端」 |

## 四、读法与记录：把排序写成可查的次序

1. **先判两端**：这一病哪是本、哪是标，写出因果先后，写不出就先别排。
2. **查两条例外**：中满、小大不利，中一条就先治标。
3. **定虚实**：有余先本、不足先标，虚实不明则次序无意义。
4. **定逆从**：轻则逆、甚则从，用从治必须能说出「终则异」的那一步。
5. **留退路**：常规方向治而不效，回头改归属，而不是换一个方向硬试。
6. **落记录**：按下面七项填，缺项即视为未核。

| 字段 | 填什么 | 为什么必须记 |
|---|---|---|
| 本 | 本病与依据 | 排序的起点 |
| 标 | 标病与依据 | 排序的对照端 |
| 例外 | 中满 / 小大不利 / 无 | 决定是否先治标 |
| 虚实 | 有余 / 不足 / 未辨 | 决定先本还是先标 |
| 逆从 | 逆治 / 从治（须有拒药证据） | 从治门槛极高，须留证 |
| 判定 | 依据 / 参照（参照写原因） | 决定能否进论证 |

**考核项（三条）**：一、任给一个病例，须写出本、标与因果先后，并指出是否触到两条例外。二、任给一处「用从治」的决定，须给出拒药证据与「终则异」的落点，缺一即判越界。三、任给一次「治之不效」，须说明该改的是归属还是剂量，并说出理由。

## 代价与边界

- **本章的治则是排序工具，不是处方集。** 全文没有给出任何一首方、一个剂量。把「先治其本」直接翻译成某个方，跳过了辨证与剂量两层。
- **「急」的条件是枚举，不是全部。** 原文给的例外只到中满与小大不利；临床上还有大量急症在原文的枚举之外。用本章的条件去判所有急症，会漏。
- **反治的门槛很高。** 「甚者从之」不是「病重就用反治」，而是「病重且拒药」。把反治当常规手段，是把例外当默认。
- **求其属不适用于初诊。** 它的前提是常规方向已经治过且无效；首诊就用「以药测证」，等于放弃了常规路径。
- **异法方宜的条件依赖不等于相对主义。** 它说的是「各自条件下都成立」，不是「怎么治都行」。条件没写清，就不能叫成立。
