# 治则是排序问题，不是选方问题 · 提示词

## 用途

给「治则是排序问题，不是选方问题」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「标本把「治什么」换成「先治什么」 → 默认治本与两类例外 → 正治与反治：不是反着治 → 求其属：当治疗本身成为诊断」这条链。

## 提示词

```
我在学《内经选读》第 7 章「治则是排序问题，不是选方问题」，本章 6 节 / 2,940 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 「急」不是一个形容词，是一组可枚举的征象
   - 任何单一维度的治则都不能自足
   - 病势轻微时逆治，病势深重时从治
   - 开始看起来与病象同向，最终结果与病象反向
   - 反治不是「反常治法」的通行证
   - 治疗反应是诊断信息
4. 本章自陈的边界（不得越过）：
   - **本章的治则是排序工具，不是处方集。** 全文没有给出任何一首方、一个剂量。把「先治其本」直接翻译成某个方，跳过了辨证与剂量两层。
   - **「急」的条件是枚举，不是全部。** 原文给的例外只到中满与小大不利；临床上还有大量急症（大出血、剧痛、神昏）在原文的枚举之外。用本章的条件去判所有急症，会漏。
   - **反治的门槛很高。** 「甚者从之」不是「病重就用反治」，而是「病重且拒药」。把反治当常规手段，是把例外当默认。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章内容用于教学，不构成诊疗或执业意见；具体操作以现行规范与所在机构制度为准。
