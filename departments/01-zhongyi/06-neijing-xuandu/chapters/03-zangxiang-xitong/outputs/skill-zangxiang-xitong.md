# zangxiang-xitong

## 何时使用

- 把藏象条文建成结构化表（教材对照、知识库）
- 校核某脏的「其华」「其充」是否为原文所有
- 发现两个版本（如《太素》）用字不同，需要保留证据

## 不适用

- 临床辨证（藏象讲关联，不构成诊断）
- 需要跨篇整合的藏象学说综述（本章只取一篇）
- 原文句式残缺、无法判定字段时（应标「无法判定」）

## 步骤

1. **剥夹注**：识别「《…》作…」「别本作」「一作」，剥离并存档。
2. **抽五元组**：本 / 华 / 充 / 阴阳位 / 通于；缺则 null。
3. **标不规则**：合称句、替代表述（至阴之类）逐一注明。
4. **留候选**：一句含两脏或跨句时，列候选不合并。
5. **写边界**：说明五元组是整理格式。

## 输出模板

```text
【抽取】脏｜本｜华｜充｜阴阳位｜通于｜不规则
【夹注】…
【无法判定】…
【边界】…
```

## 质量判据

- 夹注一条不丢
- 不规则项被标出，而不是被表格抹平
- 没有把关联写成因果

> 本技能输出为文献结构化辅助，不构成诊断依据。
