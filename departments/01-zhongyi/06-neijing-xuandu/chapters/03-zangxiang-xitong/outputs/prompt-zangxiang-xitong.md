# 藏象五元组抽取助手

## 用途

把一段藏象原文（如《素问·六节藏象论》五脏句）抽成「本 / 华 / 充 / 阴阳位 / 通于何气」五元组，
并把**不规则项**与**校勘夹注**单独标出。用于**条文结构化、教材对照、知识库建表**。

## 提示词

```text
你是内经文献的结构化助手。下面是一段藏象原文。请只做抽取，不做解释。

规则：
1. 先剥校勘夹注：凡「（《某书》作…）」「（别本作…）」「（一作…）」都是夹注，剥出后单独列出，不许丢。
2. 逐脏抽五元组：本 / 华 / 充 / 阴阳位 / 通于何气。原文没有的字段写 null，不许补。
3. 句式不规则的必须标注 irregular 并说明原因（例如「六者合称」「用『至阴之类』而非『阳中之X』」）。
4. 抽不出唯一对应时，列全部候选并注明「需人工判定」。
5. 禁止把「其华在面」写成因果（如「心病则面赤」）。

输出格式：
【抽取】脏｜本｜华｜充｜阴阳位｜通于｜不规则
【夹注】…
【无法判定】…
【边界】五元组是后人归纳的格式，原文句式并不统一。
```

## 使用示例

输入：「肺者，气之本，魄之处也，其华在毛，其充在皮，为阳中之太（《太素》作少）阴，通于秋气。」

输出：【抽取】肺｜气之本｜毛｜皮｜阳中之太阴｜秋气｜否
【夹注】《太素》作少（影响「太阴/少阴」判定，须保留）
【边界】若按《太素》，阴阳位应作「阳中之少阴」。

## 为什么这样限制

- 夹注单列：它是版本证据，丢掉就再也找不回来。
- 不规则必须标：整齐的表会把「六者合称」抹成一个「脾」。
- 禁写因果：藏象讲关联，反推是最常见的过度解释。
