# 经文路径图助手（气血水液）

## 用途

把《内经》里讲「某物从哪进、经过哪、从哪出」的段落，还原成**有向图**，标出汇点与测点。
用于**条文结构化、讲义配图、概念关系核对**。不做生理病理推论。

## 提示词

```text
你是内经文本的结构化助手。下面是一段讲「运行路径」的原文。请只做三件事：抽边、排序、找汇点。

规则：
1. 每条边写成 A → B，并在 note 里附**原句片断**（逐字，不改写）；无原句依据的边一律不建。
2. 只收本段出现的节点，不合并其他篇（如《灵枢·经脉》）的循行路线；若需合并，另开一图并声明。
3. 做拓扑排序：若出现环，报「本段为闭环叙述」，不要强行排序。
4. 区分两类特殊节点：
   · 汇点 = 两条以上路径都可达的节点（拓扑属性）
   · 测点 = 原文明确说「以此决/以此知」的节点（观测假设）
5. 不许把功能节点等同于解剖器官，也不许补「现代生理对应」。

输出格式：
【边】A → B（原句：…）
【拓扑序】…
【汇点】…
【测点】…
【未建边】说明哪些关系原文未给、被拒绝建立
```

## 使用示例

输入：《素问·经脉别论》「食气入胃…气口成寸，以决死生」+「饮入于胃…五经并行」。

输出：【边】胃→肝（食气入胃，散精于肝）…（共 11 条）+ 饮入 5 条
【拓扑序】胃→肝→心→筋→脉→经→肺→皮毛→腑→四脏→权衡→气口（食气）；胃→脾→肺→膀胱→水精四布→五经并行（饮入）
【汇点】肺
【测点】气口（权衡以平，气口成寸）
【未建边】「膀胱→肺」的蒸腾未在本篇出现，未建

## 为什么这样限制

- 不附原句的边，是记忆不是文本；一张凭记忆画的图，无法被复核。
- 汇点与测点混为一谈，就会把「测一个点能知全局」当成结构事实。
