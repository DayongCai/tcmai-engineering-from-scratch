# jingmai-bielun

## 何时使用

- 讲义要把「食气/饮入/营卫」这类运行叙述画成图
- 核对某个「某脏主某」的说法是否在本篇有路径依据
- 需要区分「结构上的必经点」与「原文指定的观测点」

## 不适用

- 经络循行的完整路线（《灵枢·经脉》，另一套文本）
- 生理功能与现代解剖的对应
- 诊断与治疗

## 步骤

1. **抽边**：A → B + 原句片断；无原句不建边。
2. **限定节点**：只收本篇出现的节点，不跨篇合并。
3. **拓扑排序**：有环即报「闭环叙述」，不强行排序。
4. **标汇点**：多条路径可达的交集。
5. **标测点**：原文说「以此决/以此知」的节点，单列。
6. **列未建边**：明确拒绝建立的关系，防止后人误以为是原文所有。

## 输出模板

```text
【边】A → B（原句：…）
【拓扑序】…
【汇点】…【测点】…【未建边】…
```

## 质量判据

- 每条边有原句
- 没有跨篇合并
- 汇点与测点分开
- 未建边有交代

> 本技能只做文本结构分析，不构成诊疗依据。
