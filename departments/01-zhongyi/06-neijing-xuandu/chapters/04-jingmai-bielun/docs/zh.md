# 第 4 章 · 气血走的是环，不是河：一条被写死的路线

> **MOTTO:** 「饮入于胃，遊溢精气，上输于脾，脾气散精，上归于肺，通调水道，下输膀胱」——《素问·经脉别论》
>
> **PROBLEM:** 你说「气血运行全身」，被追问「怎么走的、从哪起、到哪归」，多数人只能画出心→血管→全身的箭头。可《内经》给的是一张有节点、有顺序、有汇合点的环形路线图：营气从肺出发，走完十二经回到肺；水饮从胃出发，经脾、肺、膀胱，最后「水精四布，五经并行」。这两条路线不是同一个环，也不是同一条河——把它们画成一条单向的河，后面所有关于「循经」「传变」的说法都失去落点。

**双根因定位:** 环境逼迫（针灸、推拿、方药三条路都要回答「作用在哪一段」，说不清走行就说不清为什么取这个穴、为什么先治这个脏） + 知识积累（循环在原文里至少有三套写法：食气入胃的输布路线、饮入于胃的水液路线、营气的十二经环。三套的起点、终点、节点都不同，混成一套就全乱）

## 一、两条入路：食与饮

《经脉别论》把「进入身体的东西」分成两类处理，两条路线写得很细：

**食气入胃**：散精于肝 → 淫气于筋 → 浊气归心 → 淫精于脉 → 脉气流经 → 经气归于肺 → 肺朝百脉 → 输精于皮毛 → 毛脉合精 → 行气于腑 → 腑精神明 → 留于四脏 → 气归于权衡 → 权衡以平 → 气口成寸，以决死生。

**饮入于胃**：遊溢精气 → 上输于脾 → 脾气散精 → 上归于肺 → 通调水道 → 下输膀胱 → 水精四布 → 五经并行。

两条路线的结构其实不一样：

| | 起点 | 关键中转 | 终点 | 落点 |
|---|---|---|---|---|
| 食气 | 胃 | 肝、心、脉 | 皮毛、四脏 | 气口成寸（诊） |
| 饮 | 胃 | 脾、肺 | 膀胱、五经 | 水精四布（布散） |

食气那条路最后落在「气口成寸，以决死生」——**它把循环的终点接在了诊脉的位置上**。这是全书最要紧的一次接续：气口之所以能候五脏，不是因为那儿有什么特殊，而是因为所有食气之精最终要经过这里、在这里形成一个可读的「权衡」。这个论证方式很现代：它先给出一条通路，再把观测点放在通路的汇合处。

饮那条路则落在「水精四布，五经并行」——布散，不是回流。两条路合起来才完整：一条管精微的输布与归拢，一条管水液的分布与排出。

顺带说一句「生病起于过用」：同篇前段说饮食饱甚汗出于胃、持重远行汗出于肾、摇体劳苦汗出于脾，结论是「故春秋冬夏，四时阴阳，生病起于过用，此为常也」（《素问·经脉别论》）。这句话把「过用」写成了病因学的一般原理，比任何具体的「某邪伤某脏」都更宽——它是本章两条路线的共同前提：路线本身没错，超载才出错。

## 二、肺朝百脉：一个所有通路都要过的节点

「肺朝百脉」四个字，是全书最明确的一处「全体脉都朝会于一处」的表述：

> 「脉气流经，经气归于肺，肺朝百脉，输精于皮毛」——《素问·经脉别论》

「朝」是朝会，不是流经。它给的是一个拓扑事实：所有脉最终要回到肺这里过一次。要留意的是，原文在这里只给了这句陈述，并没有交代理由；「肺主气、气为血之帅」是后世的解释，说得通，但不是这篇的话。

现代生理里有一个结构上的巧合：体循环的各个器官是并联的，唯独肺循环是串联的，全部心输出量每循环一次都要过肺。原文当然不知道心输出量，但它猜到了一个拓扑特征：**存在一个所有通路都必须经过的节点**。这个节点在工程上极其重要——它是唯一的单点，也是最好的观测位与最脆的失效位。

区别也要说清：原文的理由是「气」，生理学的理由是气体交换与滤过。拓扑相同，机制不同。承认这一层，才能既用它的结构，又不冒充它的解释。

## 三、营气的十二经环：顺序是可核的

《灵枢·营气》给了一条完整闭环，起点与终点都在肺：

> 「营气之道，内谷为宝。谷入于胃，乃传之肺，流溢于中，布散于外，精专者行于经隧，常营无已，终而复始」——《灵枢·营气》

接着是次序：肺 → 手阳明（大肠）→ 足阳明（胃）→ 足太阴（脾）→ 手少阴（心）→ 手太阳（小肠）→ 足太阳（膀胱）→ 足少阴（肾）→ 心主（心包）→ 手少阳（三焦）→ 足少阳（胆）→ 足厥阴（肝）→ 复出太阴（肺）。

这是一条**可逐条比对**的文本事实：十二经的顺序在这里就已排定，后世的「十二经流注」直接沿用。要注意的是它没有说时辰——「某时某经当令」是后人加的推演，原文只给顺序与「终而复始」，没给时刻表。把后世的子午流注当成《内经》原文，是这一章最常见的越界。

另外两条补充通路也在本章的篇目里：

- **经别**（《灵枢·经别》）给的是表里两经之间的「别行」通路，六组「一合」到「六合」，解决的是「阳经与阴经怎么接上」；
- **骨空论**（《素问·骨空论》）给任、督、冲三脉的起止与病候：「任脉为病，男子内结、七疝；女子带下、瘕聚」「冲脉为病，逆气里急」「督脉为病，脊强反折」。

三者合起来，才是本章所说的「循环」：一条主环（营气）、六条联络（经别）、三条纵轴（任督冲）。

## 四、是动与所生：症状挂在脉上

《灵枢·经脉》开篇一句把全篇的野心说尽了：

> 「经脉者，所以能决死生、处百病、调虚实，不可不通」——《灵枢·经脉》

每一条经脉都写两段清单：「是动则病……」与「是主某所生病者……」。以肺经为例：是动则病肺胀满、膨膨而喘咳、缺盆中痛，甚则交两手而瞀，此为臂厥；所生病者则是咳、上气、喘、渴、烦心、胸满、臑臂内前廉痛、厥、掌中热。

两段的分工，原文没有明说，后世争了很久。《难经》专门讨论过「是动」与「所生」的分别，一种较通行的读法是：**「是动」是经脉本身受邪而动的即时反应，「所生」是本经所属脏腑病变沿经反映出来的一组症状**。前者偏「经」，后者偏「脏」。

这个区分在实践中很有用：它把「按经取穴」与「按脏用药」分成了两条决策路径。同一组症状，判为「是动」就从经脉入手（循经取穴、局部处理），判为「所生」就从脏腑入手（治其本脏）。分错了，手段就用错了层次。

教材本《经脉》是节选：3,644 字对全文 4,479 字，删去约 835 字。删的是哪一段，读者要自己核——这正是第一章说的那个陷阱：**你记住的「原文」，可能在一个被剪过的版本里**。

## 五、当成图来看：能算什么，不能算什么

把这一章的文本当图来处理，是可以真做的：

- 节点：十二经、奇经、脏腑；
- 有向边：营气次序、经别的六合、表里配合；
- 中心节点：肺（朝百脉）、气口（决死生）；
- 可算指标：入度出度、环长、割点（去掉它图就断）。

这些指标不需要相信经络存在就能算，而且算出来能回答一些实际问题：如果「肺朝百脉」成立，肺就是全图唯一的必经点，任何「绕过肺」的传变路径都该被质疑。

不能做的也很清楚：

1. **不能当血流动力学。** 原文没有压力、阻力、流量、管径这些量，也没有「心泵」的概念（「心主血脉」不等于心脏泵血）。把它按流体力学建模，等于给文本加它没有的变量。
2. **不能把经络当一套独立管道。** 《经脉》篇的循行描述与血管走行大面积重合，「脉」这个词在原文里既指可见的血管，也指不可见的通路，这层歧义原文自己没消解。承认歧义，比替它选一个答案诚实。
3. **不能由「环」推出「周期」。** 「终而复始」说的是走完一圈再走一圈，没有给一圈多久。后世的各种「一圈几刻」「一昼夜五十营」是另一套推演，出自别的篇与别的时代。

一句话：这一章给的是**拓扑**，不是**物理**。拓扑可以算，物理不能替它编。

## 代价与边界

- **本章不裁定经络的实体性。** 「经络有没有独立结构」是争论了一个世纪的问题，本章只处理文本说了什么、能推出什么。把文本分析当成实体证明，或反之，都是越界。
- **「肺朝百脉」的拓扑类比只到结构为止。** 我用了「必经点」这个词，是为了说明它在图上的位置，不是宣称原文预见了肺循环。类比能帮理解，不能当证据。
- **营气次序 ≠ 子午流注。** 原文给顺序，没给时辰。把两者混为一谈，是本章最想拦住的一处误读。
- **是动/所生的区分是后世的读法。** 原文两段并列而未加界定，本章采用的「经/脏」分法是较通行的一种解释，不排除他说；引用时应标明这是解释而非原文。
- **《经脉》是节选篇。** 教材本比全文少约 835 字，此处任何「原文如此」的判断都以全文为准，读者须自行核对。
