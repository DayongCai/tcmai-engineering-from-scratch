# 第 4 章 · 经脉别论：两条路径、一个汇点、一个测点

> **MOTTO:** 「食气入胃，散精于肝，淫气于筋。」——《素问·经脉别论》
>
> **PROBLEM:** 你能背「脾胃为后天之本」，但说不清「气从口进去，走到哪儿、从哪里出去」。让你画一张循环图，你画成闭环——原文其实给的是**两条单向路径**，而且只在两个地方汇合。

## 学习目标

- 逐句把「食气」与「饮入」两条路径还原成有向图，指出各自的终点
- 说出「肺朝百脉」在图里的位置：它不是一个器官，是一个**汇点**
- 解释「气口成寸，以决死生」在工程上意味着什么：把全身状态压缩到一个测点
- 用拓扑排序证明两条路径无环，并说明这与「循环」叙事的差别

## 核心概念

### 路径一：食气（固体饮食的精微）

> 食气入胃，散精于肝，淫气于筋。食气入胃，浊气归心，淫精于脉。脉气流经，经气归于肺，肺朝百脉，输精于皮毛。毛脉合精，行气于腑，腑精神明，留于四脏，气归于权衡。权衡以平，气口成寸，以决死生。——《素问·经脉别论》

拆成边：

```
胃 → 肝 → 筋          （散精、淫气）
胃 → 心 → 脉          （浊气归心、淫精于脉）
脉 → 经 → 肺          （脉气流经，经气归于肺）
肺 → 皮毛             （肺朝百脉，输精于皮毛）
皮毛/脉 → 腑 → 四脏    （毛脉合精，行气于腑，留于四脏）
四脏 → 权衡 → 气口     （气归于权衡，气口成寸）
```

注意「肺朝百脉」这句常被讲成「肺主管全身血脉」，但在这一段的语法里，它是**脉→经→肺**这条边的终点：所有脉气都要经过肺，再从肺输到皮毛。

### 路径二：饮入（水液）

> 饮入于胃，游溢精气，上输于脾，脾气散精，上归于肺，通调水道，下输膀胱，水精四布，五经并行，合于四时五脏阴阳，揆度以为常也。——《素问·经脉别论》

```
胃 → 脾 → 肺 → 膀胱 → 水精四布 → 五经并行
```

两条路径的**唯一公共节点是肺**（食气：经→肺；饮入：脾→肺）。这就是「肺为水之上源」的原文依据——不是比喻，是图上的一个属性：肺是两条路径的必经点。

### 汇点与测点，不是一回事

- **汇点（肺）**：两条路径在此合并，之后分成「皮毛」与「水道」两路输出。
- **测点（气口）**：原文最后落到「气归于权衡，权衡以平，气口成寸，以决死生」。这是把全身状态**压缩到一个可触的读数点**。

工程上这是两件不同的事：汇点是网络拓扑属性，测点是一个**观测假设**——假设气口这一处的状态足以推断全局。本章只做图，不评判这个假设；但要标出来，因为它是后世「独取寸口」的理论起点，也是它的全部风险所在。

### 「生病起于过用」

同一篇还有一句常被单独引用的话：

> 生病起于过用，此为常也。——《素问·经脉别论》

它在这段语境里紧跟「饮食饱甚、汗出于胃；惊而夺精，汗出于心；持重远行，汗出于肾……」等一串「过用则某脏之液外泄」的列举。也就是说，「过用」不是泛泛的「过度」，而是**有具体出口的**：每一种过用，都有一个对应的「汗出于某处」。

## 代价与边界

- **图是文本图，不是解剖图**。「肝」「心」「肺」在这里是功能节点，不能与器官血管一一对应。
- **边只取本篇原句**，不掺后世「经络循行」的完整路线（那在《灵枢·经脉》，是另一套文本）。
- **无环 ≠ 生理闭环**。原文这里是「入口→出口」的流向叙述；真正的循环叙事要靠心脉与经络篇合并，本章不做这个合并。
- **测点假设未被验证**。「气口决死生」是原文主张，本章只标注它是假设，不提供任何验证数据。
- 「过用」的具体对应（汗出于某脏）本章未建表——那需要逐条核对，留作练习。

## 进阶思考

「肺朝百脉」四个字，被引用得比它所在的整段多得多。单独引用时它像一句宣言；放回段落，它只是一条边的方向说明——**经典的力量常常来自上下文，而不是金句**。
