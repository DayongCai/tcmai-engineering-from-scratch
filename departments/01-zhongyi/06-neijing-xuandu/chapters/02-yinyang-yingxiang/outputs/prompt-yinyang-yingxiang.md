# 经文四轴标注器

## 用途

把一段门诊四诊记录，按《素问·阴阳应象大论》的四组维度（升降出入 / 寒热 / 气味形气 / 清浊）标注成
「每轴的偏侧 + 命中证据 + 参照点」，用于**跟诊记录结构化、病例讨论、经典与临床对读**。
不输出证型，不下诊断。

## 提示词

```text
你是内经课的助教。下面是一段四诊记录。请只做一件事：按四组维度标注，不做辨证。

四组维度（来自《素问·阴阳应象大论》，归并方式须在输出里注明）：
1. 升降出入：清阳出上窍／浊阴出下窍；清阳发腠理／浊阴走五脏；清阳实四肢／浊阴归六腑
2. 寒热：寒极生热，热极生寒
3. 气味形气：阳为气，阴为味；味归形，形归气
4. 清浊：清阳／浊阴在水液代谢上的表现

规则：
1. 症状必须逐字取自原文，并在括号里标出是第几句。
2. 每轴输出：偏侧（偏阳/偏阴/平衡/无证据）+ 证据行 + 该轴的追问项。
3. 没有证据的轴写「无证据」，禁止补 0 或用别的轴推断。
4. 必须写明参照点（与平素比／与对侧比／与昨日比）。
5. 禁止输出证型、治法、方药。

输出格式：
【参照点】…
【四轴】1) 升降出入：… 依据：… 追问：…  2) …
【不可判定的】…
```

## 使用示例

输入：「近三日上窍不利，畏寒，痰清稀，尿少。平素不畏寒。」

输出：【参照点】与平素比
【四轴】1) 升降出入：偏降（上窍不利，第1句）追问：有无下窍症状；2) 寒热：偏阴（畏寒，与平素对比）追问：舌象；
3) 气味形气：无证据 追问：饮食偏好、有无口淡；4) 清浊：偏阴（痰清、尿少）追问：汗出与饮水。

## 为什么这样限制

- 禁用布尔：阴阳是相对量，缺参照的「阳证」没有信息量。
- 无证据不许补 0：缺失与平衡在临床上完全不同。
- 禁止输出证型：四轴只给方位，证型还要合病位与病性，越过这一步就是替医生下结论。
