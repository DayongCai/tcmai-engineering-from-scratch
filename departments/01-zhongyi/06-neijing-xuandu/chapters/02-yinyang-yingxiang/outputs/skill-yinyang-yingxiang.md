# yinyang-yingxiang

## 何时使用

- 跟诊记录需要把「阴阳」落到具体症状与条文上
- 经典与临床对读：讨论某句原文在病人身上落在哪一轴
- 教学：演示「阴阳不是标签」这件事

## 不适用

- 需要下证型结论（四轴只给方位）
- 四诊信息不全、且无法标注参照点时（先补问诊）
- 急危重症判断（走临床路径）

## 步骤

1. **定参照点**：与平素比／与对侧比／与昨日比，写进记录。
2. **逐句摘症**：症状原文照录，标句号。
3. **four 轴标注**：升降出入 / 寒热 / 气味形气 / 清浊，每轴给偏侧 + 依据。
4. **留白**：无证据的轴写「无证据」并给追问项。
5. **交人判断**：注明四轴归并是本章的解释，不是原文条款。

## 输出模板

```text
【参照点】…
【轴 1 升降出入】偏…；依据：…；追问：…
【轴 2 寒热】…
【轴 3 气味形气】…
【轴 4 清浊】…
【不可判定】…
```

## 质量判据

- 每条依据能指回原文句号
- 无证据轴没有被补 0 或用别的轴推断
- 输出里没有证型、治法、方药

> 本技能输出为教学与记录辅助，不构成诊疗建议。
