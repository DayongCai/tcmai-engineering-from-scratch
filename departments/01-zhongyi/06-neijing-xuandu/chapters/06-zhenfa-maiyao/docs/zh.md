# 第 6 章 · 诊法是先定条件再读信号，不是「摸一下就知道」

> **MOTTO:** 「诊法常以平旦，阴气未动，阳气未散，饮食未进，经脉未盛，络脉调匀，气血未乱，故乃可诊有过之脉」——《素问·脉要精微论》
>
> **PROBLEM:** 脉诊被讲成「指下的感觉」，学生练三个月，还是说不出所以然。问题往往不在手指，在条件：同一个人饭后、走路后、刚吵完架，脉都不一样；不定条件就比脉，等于拿三个不同状态下的读数互相比较。原文第一句就把条件写死了，还给足了六条理由，逐条对应一个干扰源。这一句常被当背景带过，实际上它是全篇的方法论前提；丢掉它，后面所有「某脉主某病」都失去意义。

**双根因定位:** 环境逼迫（门诊要在几分钟内给出方向，不可能每次都等到理想条件；条件不理想时仍须判断，这就要求知道偏离了多少） + 知识积累（诊法在原文里是三层：采样条件、多通道互证、分级判读模板。「参伍」与「三段式」这两层比任何具体脉名都重要，而它们最容易被跳过）

## 一、平旦：一个被写死的采样条件

原文列的六条，逐条都有对应的干扰源：

| 原文条件 | 排除了什么干扰 |
|---|---|
| 阴气未动 | 夜间的收藏状态尚未被活动打断 |
| 阳气未散 | 阳气未因起居劳作而外散 |
| 饮食未进 | 食气未入胃，脉不受谷气冲击 |
| 经脉未盛 | 气血未被食物与活动充满 |
| 络脉调匀 | 外周循环处于基线 |
| 气血未乱 | 情绪与劳倦未介入 |

这六条合起来只做一件事：**把变量按住，只留病变这一个变数**。这个逻辑和现代检查前的要求同构——抽血要空腹、量血压要静坐五分钟、心电图要静息平卧。

关键在「常以」两个字。**平旦是基准条件，不是必要条件**。原文说「常以平旦」，没说「非平旦不可诊」。这一字之差决定了它能不能进临床：如果它是必要条件，门诊就永远不能诊脉；如果它是基准，那么偏离基准就是一种可记录的信息。

于是可操作的做法出来了：**记下偏离量**。饭后几小时、活动后多久、昨夜睡了几小时、来时情绪如何。这些不是废话，它们是让两次诊脉可比较的协变量。少了它们，你手里的「脉弦」既可能是病，也可能是刚爬了四层楼。

同篇还有一句同样重要：「持脉有道，虚静为保」（《素问·脉要精微论》）。虚静讲的不只是病人的状态，也是医者的状态——手要稳、心要静。这句常被当成修养话，其实是操作要求：手感的分辨率依赖施诊者自身的稳定。

## 二、参伍与胃气：互证与三级判读

### 参伍：四个通道互证

采到信号之后，《脉要精微论》给的下一步不是「以脉定病」，而是交叉验证：

「切脉动静而视精明，察五色，观五脏有余不足，六腑强弱，形之盛衰，以此参伍，决死生之分。」（《素问·脉要精微论》）

「参伍」是错互比验：脉、目之精明、五色、藏府强弱、形之盛衰五个来源各自独立采集，再互相印证。

要点不在「五个都看」，而在**不一致本身是信息**。「征其脉小，色不夺者，新病也；征其脉不夺，其色夺者，此久病也」（《素问·脉要精微论》）。脉已虚而色未败，是新病；脉尚未败而色已夺，是久病。也就是说，**两个通道的时间常数不同**：脉反应快，色退得慢。利用这个差，可以推断病程的新久。

这是全书里最接近多模态时序推断的一段。

### 胃气：把「有胃气」变成一个三段式

《平人气象论》先给「平人」一个可数的定义，再给判读模板：

> 「人一呼脉再动，一吸脉亦再动，呼吸定息，脉五动，闰以太息，命曰平人」——《素问·平人气象论》

一呼两动、一吸两动，加上呼吸之间的定息，一共五动；这与「以不病调病人」的平息法配套，是全篇唯一一处给出数字的地方。往下才是三段式。以春脉为例：

- 春胃微弦曰平；
- 弦多胃少曰肝病；
- 但弦无胃曰死。

一个模板，三级判读。四时各一条：春弦、夏钩、长夏软弱、秋毛、冬石，每一条都套这个三段式。三个关键词是全篇的技术核心：

| 词 | 含义 | 判读后果 |
|---|---|---|
| 微 | 脏气略现，胃气为主 | 平（正常） |
| 多……少 | 脏气偏盛，胃气被压 | 病（该脏病） |
| 但……无 | 只见脏气，胃气已绝 | 死（危候） |

「胃气」在这里不是某种物质，是**脉的柔和度与从容度**——也就是「不偏不亢」这个性质。原文用「人无胃气曰逆，逆者死」（《素问·平人气象论》）把它定为底线指标：任何脉，只要失去从容，就已在危险区。

这套三段式的价值在于它可分级、可复述、可教学。学生说不清「脉弦不弦」，但可以说清「是微弦、弦多胃少，还是但弦无胃」。**把连续的指下感觉离散成三档**，是让脉诊可讨论的第一步——比直接追求波形量化更现实，因为波形量化至今仍没有公认的「弦」的定义，而三档判读至少能保证**两个人说的是同一件事**。

## 三、判据：色诊表与经终清单，各自能用到哪

### 色诊的部位表与它的问题

《灵枢·五色》给了两张表，一张是面部的部位划分，一张是五色主病。

部位表以鼻（明堂）为中心：阙（眉间）、庭（颜额）、蕃（颊侧）、蔽（耳门）；再细分到「庭者，首面也；阙上者，咽喉也；阙中者，肺也；下极者，心也；直下者，肝也……」一路排到「巨屈者，膝膑也」，共二十余个部位。五色主病只有一句，极简：「青黑为痛，黄赤为热，白为寒，是谓五官」（《灵枢·五色》）。

这张表有三个问题，读时必须自己标出来：**一是划分极细，判读无标准**——二十多个部位之间的界线靠什么定？「直下者肝」的「直下」是几寸？原文没给度量，后世各家画的图并不一致。**二是断言极强，随访无据**——「赤色出两颧，大如拇指」与「必卒死」绑定，原文没给随访数据。**三是映射没有解剖依据**——面部某区对应某脏是观察加推演，不是发育或神经支配。

那它还能干什么？**当假设生成器**。「青黑为痛」可以转成一条可检验的命题：面色青黑的病人，疼痛主诉的比例是否更高？这类研究有人做，结论不一，但至少命题是清楚的。反过来，把它**当筛查工具**（「面见青色，必有痛症」）就是越界——假阳性会高到无法使用。

### 经终：一份终末期清单

《诊要经终论》的后半是一份清单，十二条经脉各写一段终末表现。以太阳为例：

「太阳之脉，其终也，戴眼、反折、瘛瘲，其色白，绝汗乃出，出则死矣。」（《素问·诊要经终论》）

戴眼（两眼上视不能转动）、反折（角弓反张）、瘛瘲（抽搐）、绝汗（汗出如珠不流）——这四个征象凑在一起，是极重危候。

这份清单的功能是**识别不可逆的终末期**。它承认了一件事：诊法不只回答「是什么病」，也回答「还能不能治」。同篇还有一句更硬的：「凡刺胸腹者，必避五脏」（《素问·诊要经终论》）。诊与治的安全线在这两段里连成一体：知道什么不能治，也知道什么不能碰。

风险在于这类断言脱离上下文就成了预后宣判。「其终也」有明确的前置——是经脉之气已终，不是随便一个抽搐；三个征象同时出现，才够得上。把其中任何一个单独拿出来说「必死」，是把清单当成了标签。

### 两档判据与四种失效

| 档 | 成立条件 | 能拿它做什么 | 不能拿它做什么 |
|---|---|---|---|
| **依据** | 有篇名、有原文、条件被写明（平旦六条、平息五动、三段式、参伍五源） | 作采样条件的清单；作互证的对照表；作分级判读的模板 | 不能当病名，不能由一档直接推到方 |
| **参照** | 属无度量的部位划分、属无随访的强断言、属比喻性的脉名 | 作假设生成的来源；作教学设计的分档 | 不能当筛查阈值，不能当预后宣判 |

|---|---|---|
| **以注代经** | 把后世「某脉主某病」的脉诀当《脉要精微论》原文，其实原文给的是条件与互证 | 引文只认 `units.json` 的 `body`，脉诀另记 |

## 四、读法与记录：把条件写在读数前面

1. **先记条件**：时辰、进食、活动、睡眠、情绪五项，缺一项这次读数就只能当参考。
2. **再取信号**：脉、色、形、藏府强弱至少两条通道，单通道不下结论。
3. **比通道**：不一致先问差在哪、差的方向说明什么（脉快色慢＝新病）。
4. **分三档**：把连续的指感离散成平、病、危三档，用同一套词，别人才能复核。
5. **标性质**：部位表与强断言标「参照」，条件与三段式标「依据」。
6. **落记录**：按下面七项填，缺项即视为未核。

| 字段 | 填什么 | 为什么必须记 |
|---|---|---|
| 条件 | 平旦 / 非平旦（偏离量） | 决定读数可否横向比较 |
| 通道 | 脉 / 色 / 形 / 藏府强弱 | 单通道不能定论 |
| 互证 | 一致 / 不一致（差在哪） | 不一致才是信息 |
| 分档 | 平 / 病 / 危 | 决定判读的落点 |
| 脉名 | 弦 / 钩 / 毛 / 石（比喻） | 标明是比喻，非量值 |
| 出处等级 | 经文 / 脉诀 / 后世图 | 决定证据等级 |
| 判定 | 依据 / 参照（参照写原因） | 决定能否进论证 |

**考核项（三条）**：一、任给一次诊脉记录，须指出它还缺哪几项条件，缺项会导致什么误判。二、任给一组脉色不一致的病例，须说出它支持新病还是久病，理由是哪两个通道的时间常数不同。三、任给一句「某色主某病」，须判它是假设还是筛查标准，并说出越界的那一步。

## 代价与边界

- **本章不提供脉象标准。** 「弦」「钩」「毛」「石」在原文里是比喻，没有给出可测量的定义；本章只讲判读结构，不给任何波形、压力或频率的数值门槛。
- **平旦是理想条件，不能苛求。** 门诊做不到，也不必做到；要做的是记录偏离。把「非平旦不诊」当规矩，是把基准当成了门槛。
- **色诊部位表不作诊断依据。** 二十余部位的划分无度量、无一致性标准，本章只把它当假设生成的来源，并明确其强断言缺乏随访证据。
- **经终清单不是预后工具。** 它是识别终末期的征象组合，须多个征象同时出现；单征象推「必死」是滥用。
