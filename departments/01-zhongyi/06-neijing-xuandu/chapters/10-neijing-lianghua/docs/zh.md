# 第 10 章 · 量化能测《内经》的什么，测不出什么

> **MOTTO:** 「不知年之所加，气之盛衰，虚实之所起，不可以为工矣」——《素问·六节藏象论》
>
> **PROBLEM:** 一说「用数据研究《内经》」，最常见的产出是一张词频表：气 3,012 次、阴阳 284 次、五脏 253 次，于是结论写「气是《内经》的核心概念」。这类结论有数据、有表格、有百分比，却什么也没证明——气出现得多，是因为它是通用构词成分（气穴、气街、邪气、真气、谷气、宗气），不因为它重要。更糟的是同一套方法得出的反例：全书「治未病」只出现 3 次。这两个数相差千倍，而两者的重要性没有千倍之差。频率与重要性之间没有单调关系，这就是本章要划的那条线。

**双根因定位:** 环境逼迫（教材与讲稿都需要数字来支撑论断，而「很多」「大量」「核心」这类词一经追问就崩；给数字是唯一能站住的办法） + 知识积累（文本可测的量其实很少：篇数、字数、段数、词次、版本差异。每一项都有口径，口径错了数字就假；而大部分「量化研究」的毛病不在算法，在口径没交代）

## 一、先把可测的量列清楚

对仓内全文语料（只统计「原文」块，不含译文与按语；汉字数去标点），能稳定算出的量有这些：

| 量 | 值 | 口径 |
|---|--:|---|
| 篇数 | 162 | 素问 81 + 灵枢 81 |
| 原文汉字 | 155,206 | 素问 88,940 / 灵枢 66,266 |
| 原文段数 | 3,147 | 素问 1,887 / 灵枢 1,260 |
| 篇均汉字 | 958 | 素问 1,098 / 灵枢 818 |
| 篇均段数 | 19.4 | 素问 23.3 / 灵枢 15.6 |
| 字/段 | 49.3 | 素问 47.1 / 灵枢 52.6 |
| 篇长中位数 | 696.5 | 162 篇排序取中 |
| 最长篇 | 9,314 | 素问·六元正纪大论（197 段） |
| 最短篇 | 146 | 灵枢·背俞（2 段） |

这张表本身没什么可辩的，唯一要强调的是第三列：**口径**。「只统计原文块」这一条决定了所有数字——把译文与按语算进去，字数会翻倍；把校勘夹注算进去，字/段会上升。口径不写在数字旁边，数字就不可复算；一旦不可复算，它就不是证据，是装饰。

这也是本课从第一章起就在做的事：任何关于文本的说法，都要能被一个人用同一份语料重算出来。

## 二、分布与词频：两种最常被误用的统计

### 篇长分布：是长尾，不是平均

篇均 958 字，中位数 696.5 字——**均值高于中位**，说明**分布右偏**：少数超长篇**把均值拉高了**。拉得多高？

- 最长的《六元正纪大论》9,314 字，占全书 6.0%；
- 最短的《背俞》146 字，两者相差 **63.8 倍**；
- 运气七篇合计 28,049 字，占全书 **18.1%**，而这七篇只占篇数的 4.3%（7/162）。

所以「平均一篇九百多字」这句话，对大多数篇都不成立。任何按篇聚合的统计（词频、主题、相似度）都会被这种长尾扭曲：一篇《六元正纪》的权重相当于六十多篇《背俞》。

这条分布有一个直接的操作后果：**做检索时按段切分，不要按篇切分**。3,147 段、段均 49.3 字，粒度均匀得多；按篇切，长尾篇会独占地压过其它所有篇，检索结果永远先出那几篇。

### 词频的三个陷阱

**陷阱一：通用词被当成概念。** 「气」3,012 次。拆开看，它出现在气穴、气街、邪气、真气、谷气、宗气、血气、气化、气机……里。这些不是同一个概念的 3,012 次出现，而是几十个复合词共用一个字。直接计数，得到的是「这个字有多常用」，不是「这个概念有多重要」。

**陷阱二：异形同指被漏算。** 「五脏」253 次，「五藏」只有 14 次。按字面看，「脏」是主流用字；可篇名偏偏用「藏」——《五藏生成》《五藏别论》，以及《灵枢》的《本藏》。也就是说，**全书用字不统一**：正文多作「脏」，篇名仍作「藏」。词频法会把同一个所指拆成两个低频项。

**陷阱三：稀少不等于不重要。** 「治未病」全书 3 次，按任何频次门槛都进不了「核心概念」，可它是中医最广为传诵的一句话。「气」3,012 次，也很难说它比「治未病」重要 1,004 倍。

三个陷阱指向同一个结论：**词频只能用于检索排序，不能用于概念权重**。用它做索引，很好；用它下判断，必错。

这里有一个干净的自证例子。「皆属于」全书出现 26 次——看起来可以推出「本书有 26 条病机规则」。实际拆开：19 次构成《至真要大论》的病机十九条，5 次在《五藏生成》讲「诸脉者皆属于目、诸髓者皆属于脑」这一串，1 次在《痿论》讲「皆属于带脉」，1 次在《本输》讲「大肠、小肠，皆属于胃」。**同一个词，26 次，只有 19 次是病机规则**。计数得到 26，条目只有 19；把计数当条目，**多出来的 7 条全是假的**。

## 三、判据：节选本会让引文失真

本章的 5 篇，教材本 7,445 字对全文 12,367 字，覆盖 60.2%，节选 1 篇。

那 1 篇是《至真要大论》：教材本 2,421 字，全文 7,018 字，相似度 0.191。任何以「《至真要大论》说……」开头的句子，都有相当概率来自一个被剪过的版本。

但反过来也要防一种误判：**相似度低不等于教材删了内容**。本章之外有个现成的反例——《五运行大论》教材本 2,869 字，全文字数 1,666 字，教材本比全文还长。原因是教材本含注释与通读文字，而全文本只抽「原文」块。所以**相似度低有两个成因：删节，或者加注**。只归因于删节，会得出「教材丢了内容」这种错误结论。

可操作的做法只有一条，而且要机械地执行：**引用前先在该篇全文里逐字搜**。搜不到，就是没读到（或者标错了篇名）；搜到了，再看上下文是否被剪、是否被注文混入。这一步不需要理解医理，只需要文本，所以它一定能做到。

### 两档判据与四种失效

| 档 | 成立条件 | 能拿它做什么 | 不能拿它做什么 |
|---|---|---|---|
| **依据** | 口径写明、可复算（篇数、字数、段数、逐字命中数、覆盖率） | 定位；对齐版本；核对引文 | 不能推概念权重，不能推疗效，不能推年代 |
| **参照** | 词频排序、相似度阈值、按篇聚合的主题判断 | 做检索排序；提示哪里可能有节选 | 不能当结论，不能当权重，不能当分型依据 |

| 失效模式 | 本章的具体样子 | 拦法 |
|---|---|---|
| **以注代经** | 统计时把译文与按语算进正文，字数翻倍还自称原文统计 | 口径写进表头：只统计原文块 |
| **断章取义** | 用「气」3,012 次直接说「气是核心概念」，不看它是几十个复合词共用一字 | 词次必附拆分样例 |
| **版本混用** | 拿教材本字数当全文字数，或把相似度低一律读成删节 | 字数与相似度两列并看，标注版本 |
| **望文生义** | 把「皆属于」26 次当成 26 条规则，把「五脏/五藏」当成两个概念 | 计数先做同指合并，再定条目 |

## 四、读法与记录：让每个数都带口径

1. **先写口径**：语料是哪份、含不含译文与按语、汉字怎么计。口径先写，数字后出。
2. **再算基数**：篇数、字数、段数，三样先核对，与 `chapter-map.json` 对得上再往下做。
3. **按段不按篇**：检索与统计的单位定在段，避免长尾篇独占。
4. **同指合并**：脏/藏、遊/游这类异形先合并，再计词次；合并规则要写出来。
5. **核引文**：任何一句进结论之前，先在该篇全文逐字搜，标明命不命中。
6. **落记录**：按下面七项填，缺项即视为未核。

把本章收成两张清单。**能做的三件事**：定位（给定一句引文，返回它在哪一篇、哪一段、是否逐字命中，可被第三方检验）；对齐（给定一章篇目，算出教材本与全文各自的字数、相似度，标出哪几篇是节选、哪几篇教材本更长）；复算（任何「占比」「频次」「篇均」的结论，都应能被一份脚本重跑出同一个数）。

| 字段 | 填什么 | 为什么必须记 |
|---|---|---|
| 口径 | 语料、含否译文与按语、汉字计法 | 换口径数字全变 |
| 基数 | 篇数 / 字数 / 段数 | 一切比例的分母 |
| 单位 | 段 / 篇 | 决定长尾是否独占 |
| 合并规则 | 异形同指的处理（脏/藏……） | 决定词次真假 |
| 引文核验 | 逐字命中 / 未命中 | 决定能不能引 |
| 版本 | 教材本 / 全文 + 相似度 | 决定剪口在哪 |
| 判定 | 依据 / 参照（参照写原因） | 决定能否进结论 |

**考核项（三条）**：一、任给一个词次，须说出它的口径与是否做过同指合并，并给出至少两个复合词样例。二、任给一处「相似度低」，须判它是删节还是加注，并说出判据。三、任给一个占比结论，须能在一份脚本里重跑出同一个数，重跑不出即判不合格。

## 代价与边界

- **本章所有数字都依赖同一份语料与同一套口径。** 换语料（刻本、校本）、换口径（含译文、含夹注），数字全变。凡引用本章数字，须连同口径一起引。
- **词频不是语义。** 本章只说明词频法的失败之处，不给任何「概念权重」的替代方案——那个方案需要人工判断，而人工判断不可复算，必须单独论证。
- **「节选」的判定基于相似度阈值。** 0.9 这条线是工程约定，不是学术判断；教材本加注导致的低相似度会被误判为节选，读者须自己核。
- **本章不评价七篇、遗篇的年代与真伪。** 那些是文献学问题，统计方法无法回答。
- **不能判定哪一句更可信。** 文本统计不含校勘、年代、真伪判断；它能告诉你这句话在哪，不能告诉你这句话该不该信。
- **量化不构成临床依据。** 「某概念出现次数多」不能推出「某治法有效」；从文本统计到临床结论之间，隔着一整套证据链。

> **免责声明：** 本章为教学材料，全部数字由脚本对仓内语料实测得出，口径已随文标注，可直接复核。本章不构成诊断标准、治疗方案或研究结论；临床与研究决策须依具体病情与现行规范作出。
