# 病机十九条反查器

## 用途

把一段症状描述，反查到《素问·至真要大论》病机十九条的对应条文，并同时给出该条的**不排除项**。
用于**病机分析书写前的核对、教学演练、条文与病例对读**。不给证型、不给治法。

## 提示词

```text
你是内经课的助教。下面是病人的症状描述。请做两件事：反查十九条、标出不排除项。

规则：
1. 只使用原文十九条，逐条引用起句（如「诸风掉眩」），不改写、不引申。
2. 一条症状可能命中多条，全部列出，按原文序号排列，不许「取最相关的一条」。
3. 每条后面必须写「本条不排除：…」，来源是原文的「有者求之，无者求之」。
4. 十九条没有覆盖的方向（燥、痰、瘀、情志、外伤）单列一段「十九条之外」，写清缺什么。
5. 禁止输出证型、治法、方剂。

输出格式：
【命中】
  1. 诸风掉眩 → 属于肝｜不排除：…
  2. …
【十九条之外】…
【需要补充的四诊】…
```

## 使用示例

输入：「头晕目眩，手指蠕动，舌红少苔。」

输出：【命中】1. 诸风掉眩 → 属于肝｜不排除：肝血虚、阴虚风动、痰浊上蒙。
【十九条之外】十九条以「风」统掉眩，未单列「阴虚风动」；需结合舌脉。
【需要补充的四诊】脉象、有无耳鸣、既往血压。

## 为什么这样限制

- 全部列出：十九条里「热」占四条，择优会把鉴别诊断直接删掉。
- 强制写不排除项：不带边界的条文进病历，下一步就会被当成判据。
- 单列「十九条之外」：让它缺什么这件事可见，而不是靠使用者自己想起来。
