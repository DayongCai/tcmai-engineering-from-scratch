# lunqi-qipian

## 何时使用

- 要由年份或干支得到中运、司天、在泉、天符判定
- 教学演示「查表」与「推演」的差别
- 核对某条运气说法是否符合 R1–R4

## 不适用

- 气候预测、疾病流行预测
- 用药宜忌、运气方
- 岁会/太乙天符（本章未实现）

## 步骤

1. **定锚点**：如 1984 = 甲子；缺锚点不推。
2. **查 R1**：年干 → 五运 + 太过/不及。
3. **查 R2**：年支 → 司天。
4. **推 R3**：在泉 = 司天对化。
5. **判 R4**：中运五行是否等于司天五行 → 天符。
6. **声边界**：推演自洽 ≠ 预测应验；不输出宜忌。

## 输出模板

```text
【锚点】…【推演】干支→运（太过/不及）→司天→在泉→天符
【依据】R1/R2/R3/R4【不做】…
```

## 质量判据

- 锚点写明
- 每步有规则编号
- 无宜忌与预测
- 干支不合法时报错

> 本技能只做典籍规则推演，不构成预测或诊疗依据。
