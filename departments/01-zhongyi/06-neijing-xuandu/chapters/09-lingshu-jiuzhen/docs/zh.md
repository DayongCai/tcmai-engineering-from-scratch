# 第 9 章 · 九针是一套器材规格表，玄的那一半它管不了

> **MOTTO:** 「小针之要，易陈而难入。粗守形，上守神」——《灵枢·九针十二原》
>
> **PROBLEM:** 讲九针有两条路，都走偏了。一条把它讲成象数：一法天、二法地、三法人，讲得很玄，学生听完仍不知道九根针各有多长。另一条只背规格：一寸六分、三寸半、七寸，背完还是不知道为什么要九种。这两处恰好是本章六篇里最像「清单」、最容易被跳过的段落。真正能落地的部分也在两处——《九针十二原》的规格表与《官针》的失配判据：后者给的是四种损害，两两对称，可分「深度」与「力度」两个维度。

**双根因定位:** 环境逼迫（针具是针法的物质前提：用什么针决定了能做什么手法、能取什么部位，用错针的后果原文写得很具体） + 知识积累（九针在原文里是三层：器材（名、长、形、用）、匹配（病与针的对应与失配后果）、判断（守形与守神的分别）。只学第一层，针法就成了背规格）

## 一、规格表：名、长、形、用

《九针十二原》把九根针一次列完，格式统一——名字、长度、形状、用途：

| 序 | 名 | 长 | 形 | 用 |
|--:|---|---|---|---|
| 1 | 镵针 | 一寸六分 | 头大末锐 | 泻阳气 |
| 2 | 员针 | 一寸六分 | 针如卵形 | 揩摩分间，泻分气，不伤肌肉 |
| 3 | 鍉针 | 三寸半 | 锋如黍粟之锐 | 按脉，勿陷，以致其气 |
| 4 | 锋针 | 一寸六分 | 刃三隅 | 发痼疾 |
| 5 | 铍针 | 四寸，广二分半 | 末如剑锋 | 取大脓 |
| 6 | 员利针 | 一寸六分 | 且员且锐，中身微大 | 取暴气 |
| 7 | 毫针 | 三寸六分 | 尖如蚊虻喙 | 静以徐往，微以久留，取痛痹 |
| 8 | 长针 | 七寸 | 锋利身薄 | 取远痹 |
| 9 | 大针 | 四寸 | 尖如梃，其锋微员 | 泻机关之水 |

这张表最值得说的是它的**跨度**：最短一寸六分，最长七寸，相差四倍多；最细是毫针（蚊虻之喙），最粗是铍针（末如剑锋）。这不是九个等级，是**九种功能专用器械**——按病灶深浅（皮、分肉、脉、筋、骨）、内容物性质（脓、水、血、痹）来分工。

关于长度，必须提醒一句：古今尺度不同，寸的长度随朝代变化，本章不做换算。**能直接用的是相对比例**（四倍多的跨度、毫针与铍针的粗细之别），这些都**跟尺子无关**。要换算成厘米，须先确定所用的是哪一朝哪一尺，否则算出来的数是假的。

## 二、官针：把病情配到针上

有了规格，就要配对。《官针》开篇第一句是判断句，不是赞美：

「凡刺之要，官针最妙。九针之宜，各有所为，长短大小，各有所施。不得其用，病弗能移。」（《灵枢·官针》）

接着给出四种失配的后果，一条一格，非常干净：

| 失配 | 后果 |
|---|---|
| 疾浅针深 | 内伤良肉，皮肤为痈 |
| 病深针浅 | 病气不泻，反为大脓 |
| 病小针大 | 气泻太甚，疾必为害 |
| 病大针小 | 气不泄泻，亦复为败 |

这四格是本章最实用的部分。它不说「**要选对针**」这种空话，它说**选错的四种损害**：浅病深刺会伤好肉，深病浅刺会把病邪逼成脓，小病用大针会泻过头，大病用小针则泻不动。四格两两对称，本质上是「深度」与「力度」两个维度上的**过与不及**。

同篇还有三套刺法分类，各有名目与适应证：九刺应九变、十二节应十二经、五刺应五脏。三套的分法不同——按病变性质、按经脉、按五脏——说明《内经》的刺法分类并非一套统一体系，而是不同来源的三种整理。

这里必须说清一件事：**今天临床上常规使用的只有毫针一类**，其余八种多已不用，或转成了别的器械（铍针演为外科刀，锋针演为三棱针，镵针演为皮肤针）。把九针说成「九种都在用」，是给读者一个不存在的现状。它们的价值在于说明「针具是按用途分化的」这个原则。

## 三、判据：注释层、停止规则与安全边界

### 小针解：文本内的注释层

《灵枢》第三篇《小针解》很特殊：它逐句解释第一篇《九针十二原》的开头。原文说「小针之要，易陈而难入。粗守形，上守神」，小针解就一句一句拆：

「所谓易陈者，易言也。难入者，难着于人也。粗守形者，守刺法也。上守神者，守人之血气有余不足，可补泻也。」（《灵枢·小针解》）

这段解释把两个模糊的词钉住了：**形 = 刺法**（进针、深浅、徐疾、提插等技术动作）；**神 = 血气有余不足**（该补该泻的判断）。也就是说，「粗工守形、上工守神」不是在褒贬境界，而是在区分两层能力。这是全书最早的一处**操作与判断分离**的表述，而且它出自文本内部。

这一层也提醒一件事：**经文与解文要分开引**。《小针解》的解释未必是《九针十二原》的原意，它是后人对同一文本的再理解。引用时说清「这是小针解的解释」，比说「《内经》认为」准确得多。

### 得气：一个停止规则

规格与匹配都能说清，剩下的那一半说不清：什么叫「得气」。

《九针十二原》的描述是一串比喻：「刺之要，气至而有效，效之信，若风之吹云，明乎若见苍天」。而停止条件极其干脆：「刺之而气不至，无问其数；刺之而气至，乃去之，勿复针」。

**得气在这里是一个停止规则**：气至则止，不至则继续（不问次数）。作为规则，它完全可执行；作为指标，它至今没有公认的客观定义——后世总结为酸、麻、重、胀，但不同人、不同部位、不同手法的报告差异很大。

所以要分开说：**可执行的部分**是把得气当停止条件与手法反馈，有则止、无则调整深浅与手法，这一层今天仍在使用；**不可宣称的部分**是说「测到了气」，任何把得气量化到某个物理量的说法，都需要先给出定义与重复性，而这两样目前都没有。

「守神」的另一半是注意力。《九针十二原》说「神在秋毫，属意病者，审视血脉者，刺之无殆」——注意力要放在病人身上，不在针上。这是针刺安全的第一条：多数针刺意外不是因为手法错，是因为注意力离开了病人。

### 安全边界：一份带后果分级的清单

本章最有现实价值的部分，是散在几篇里的安全条款。《诊要经终论》说「凡刺胸腹者，必避五脏」（《素问·诊要经终论》），接着给出中脏的后果：中心者环死，中脾者五日死，中肾者七日死，中肺者五日死。《九针十二原》另有一组：「针太深则邪气反沉，病益」；「取五脉者死，取三脉者恇」。

把这两处合起来看，它其实是一份**不良事件清单**，而且分了级：轻则病益（加重），中则恇（虚弱不复），重则死。它给的规避原则只有一条——避开重要脏器所在的区域，控制深度。

要注意的是：具体的死期数字（五日、七日、环死）不可核，也没有随访依据。可以信的是原则（避脏器、控深度、看反应），不能信的是时刻表。**把原则与时刻表分开，是读这一类条文的基本功**。

### 两档判据与四种失效

| 档 | 成立条件 | 能拿它做什么 | 不能拿它做什么 |
|---|---|---|---|
| **依据** | 有篇名、有原文、是规格或规则（九针名长形用、四失配、气至乃去、避五脏） | 选针具；定停止条件；定安全边界 | 不能当现行器材清单，不能给寸与厘米的换算 |
| **参照** | 属宇宙论配属（一法天二法地）、属注文解释（小针解）、属后世得气描述 | 理解编者的分类意图；帮助记忆 | 不能当测量标准，不能当技术规范 |

| 失效模式 | 本章的具体样子 | 拦法 |
|---|---|---|
| **以注代经** | 把《小针解》的解释当《九针十二原》原意，把《九针论》的一法天二法地当规格依据 | 经与解分引，注文另记 |
| **断章取义** | 只取「中脾者五日死」，不取「必避五脏」这条原则 | 引后果必引规避原则 |
| **版本混用** | 本章两篇节选（《九针论》0.825、《刺节真邪》0.647），按教材措辞去全文搜会落空 | 引文以全文为准，剪口标出 |
| **望文生义** | 把「守神」读成玄虚境界，把「气至」读成某种可测的物理量 | 先取文本内的定义（小针解），再定词义 |

## 四、读法与记录：把器材读到能给规格

1. **先读表**：九针的名、长、形、用四列逐条读，读完能说出「哪种针做什么」。
2. **只比相对量**：跨度、粗细、锐钝，不换算朝代尺。
3. **配病**：按深浅与内容物选针，再看四种失配的后果，确认没有过与不及。
4. **定停止**：气至则止、不至则调，不把次数当指标。
5. **划安全线**：胸腹避五脏、控制深度、注意力留在病人身上。
6. **落记录**：按下面七项填，缺项即视为未核。

| 字段 | 填什么 | 为什么必须记 |
|---|---|---|
| 针名 | 镵 / 员 / 鍉 / 锋 / 铍 / 员利 / 毫 / 长 / 大 | 决定用途 |
| 长与形 | 原文的寸与形状描述 | 换算须先定尺，故只记原文 |
| 用途 | 泻阳气 / 取大脓 / 取痛痹…… | 选针的唯一依据 |
| 失配判断 | 深 / 浅 / 大 / 小 四种中哪一种 | 决定放弃这一支针 |
| 停止条件 | 气至 / 未至（如何调整） | 防过度操作 |
| 安全边界 | 部位 / 深度 / 注意力 | 针刺意外的第一道闸 |
| 判定 | 依据 / 参照（参照写原因） | 决定能否当规范 |

**考核项（三条）**：一、任给一根针，须说出它的长度区间归属（一寸六分档、三寸档、四寸档、七寸）与用途。二、任给一次失配（如病深针浅），须说出后果与它在「深度/力度」哪一维上过或不及。三、任给一条「某处刺之必死」，须把它拆成原则与时刻表两部分，并说明哪一部分可用。

## 代价与边界

- **本章不给尺寸换算。** 寸的长度随朝代变化，不先定尺就换算，得到的数是假的。可用的是相对比例与形状描述。
- **九针不是现行器材清单。** 今天常规只用毫针一类，其余多为历史形制或已演变为他器。把九针讲成「九种都在用」，是失实。
- **「九针应天地之数」不作本章论据。** 《九针论》确有「一以法天、二以法地」的配属，那是宇宙论包装；本章只用它的规格与用途。
- **得气无可核指标。** 本章只把它当停止规则与手法反馈，不宣称任何客观测量；读者若见「得气量化」之说，应要求其给出定义与重复性。
- **死期数字不可信，原则可信。** 「中脾者五日死」一类是定性命中，无随访依据；「避五脏、控深度」是与解剖危险区一致的原则。
- **《针解》是《素问》的篇。** 本章篇目里有它，说明「九针」不是《灵枢》的专利；引用时书名不能写成《灵枢》。
