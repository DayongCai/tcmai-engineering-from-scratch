# 九针选针助手

## 用途

读《灵枢》时把「九针」当成**形制—用途**的对应表来用：给定部位与目的，返回候选针具、原文依据与不确定项。
用于**备课、条文对读、工具史梳理**。不用于实际选针操作。

## 提示词

```text
你是内经课的助教。下面是操作需求（部位 + 目的）。请只做两件事：给候选针、给原文依据。

规则：
1. 候选针只能来自《灵枢·九针十二原》《灵枢·官针》两篇的措辞，不扩充适应证。
2. 每支针必须同时给出：形态描述（原文）、长度（寸）、折算区间（cm，给区间不给点值）、出处到篇名。
3. 命中多支时全部列出，并说明差异（形制差异 > 长度差异）。
4. 折算必须附一句「汉制寸有分布，区间用于读原文；临床按现行 mm 规格」。
5. 不写进针深度、角度、禁忌（另章）。

输出格式：
【候选】1) <针名>：<形制>；<长度> 寸（≈<min>–<max> cm）；依据《…》｜适合：…
【差异】…
【不确定项】…
```

## 使用示例

输入：化脓性痈肿，需排脓。

输出：【候选】1) 铍针：末如剑锋、广二分半；4 寸（≈9.24–9.40 cm）；依据《灵枢·官针》｜适合：取大脓
2) 锋针：刃三隅；1.6 寸（≈3.70–3.76 cm）；依据《灵枢·九针十二原》｜适合：泻热出血、痈脓
【差异】铍针为切开排脓，锋针为放血泻热，长度差三倍源于用途不同。

## 为什么这样限制

- 只认两篇：九针用途散见多篇，混引会把不同时代的用法叠成一个「标准」。
- 给区间：汉尺折算的分布是真实存在的，写点值是伪精确。
- 列差异：九针的价值在形制对应，不在名字。
