# lingshu-jiuzhen

## 何时使用

- 读到「九针」时要把名字落回形制与用途
- 备课：对比某两支针（如锋针 vs 铍针）的差异
- 工具史梳理：某一类操作（放血、排脓、深刺）对应哪支针

## 不适用

- 实际选针与操作（临床按现行 mm 规格与规范）
- 需要刺法禁忌、进针深度（另章：腧穴学·危险穴位）
- 九针之外的刺法（五刺、九刺、十二节刺）

## 步骤

1. **定目的**：泻热出血 / 排脓 / 摩分间 / 深刺 / 泻水。
2. **查表**：九针各条形制 + 长度 + 用途（来源《九针十二原》《官针》）。
3. **给区间**：寸 × [2.31, 2.35] cm。
4. **列差异**：多候选时先讲形制差异，再讲长度。
5. **标不确定**：折算区间、原文归纳性、适应证未展开。

## 输出模板

```text
【候选】1) <针>：<形制>；<寸>（≈<min>–<max> cm）；《…》｜…
【差异】…
【不确定项】…
【提醒】区间用于读原文；临床按现行规格。
```

## 质量判据

- 每支针都有形制描述与出处
- 折算写成区间
- 没有把「主某病」写成适应证

> 本技能输出为教学辅助，不构成针具选择或操作建议。
