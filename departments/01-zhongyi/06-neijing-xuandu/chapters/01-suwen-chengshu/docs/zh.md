# 第 1 章 · 162 篇不是一部书，是一部丛书的合订本

> **MOTTO:** 「令可传于后世，必明为之法」——《灵枢·九针十二原》
>
> **PROBLEM:** 你在论文或讲稿里写「《内经》认为……」时，被追问一句「哪一篇？原文怎么说的？教材里有还是全文里有？」就答不上来。可复算的底数是这样的：162 篇、原文 155,206 字，而教学用的选读本只有 136,032 字——两者相差 19,174 字，占全文 12.4%。这意味着你从教材上背下来的「原文」，每八句里可能有一句在全文里根本不是那个样子。于是那句「内经云」既不能核，也不能辩。

**双根因定位:** 环境逼迫（中医的论证习惯是「引经据典」，一句没有出处的经典等于没有依据；而审稿、答辩、临床带教三个场合都会当场追问篇名） + 知识积累（《内经》不是一本书，是 162 篇不同来源文本的合订；不先建立「篇—段—原文/注」三级定位，读得再多也是散的）

## 一、两个入口可以现算：体量与篇名

### 体量：论与术分家

仓内全文语料（`standards/materials/neijing-quanwen`）按「原文」块逐段统计，得：

| | 篇数 | 原文汉字 | 篇均汉字 | 原文段数 | 篇均段数 | 字/段 |
|---|--:|--:|--:|--:|--:|--:|
| 素问 | 81 | 88,940 | 1,098 | 1,887 | 23.3 | 47.1 |
| 灵枢 | 81 | 66,266 | 818 | 1,260 | 15.6 | 52.6 |
| 合计 | 162 | 155,206 | 958 | 3,147 | 19.4 | 49.3 |

两个数字值得停一下。第一，**素问篇均比灵枢长 34%**（1,098 / 818）。这不是排版，是体裁：素问多论（阴阳、藏象、运气、治则），一篇要展开一条推理链；灵枢多术（九针、经脉、骨度、刺法），一篇是一组操作条目。第二，**段落的切分方向相反**：素问一篇 23.3 段、灵枢一篇 15.6 段，但灵枢每段更长（52.6 字对 47.1 字）。也就是说，灵枢的条目在电子整理时被合并成了较长的规程段，而素问的问答被切得更碎。这两个数字都不是体裁本身，而是**体裁加上切分规则**的结果——统计结构时，切分规则必须一起交代。

篇长分布是长尾的，不是钟形：中位数 696.5 字，最短的《灵枢·背俞》只有 146 字 2 段，最长的《素问·六元正纪大论》9,314 字 197 段——**相差 63 倍**。任何「平均一篇」的说法都会失真：你读十篇短的，抵不上一篇《六元正纪》。

### 篇名：作者自标的主题标签

《内经》每一篇都有篇名，且篇名与内容大体相扣：上古天真论讲养生与肾气盛衰、阴阳应象大论讲阴阳与五行映射、至真要大论讲六气与治则、九针十二原讲针具与十二原穴。这不是后人加的目录，而是文本自带的主题标签，所以篇名可以作为**语义归类依据**的第一层，也可以当「一级对象」来编目。

但它只能当标签，不能当编号。**不同整理本的编次并不一致**，「第 5 篇」这种说法必须绑定版本；要指认位置，写成「素问第 5 篇·阴阳应象大论」这种复合形式，别用裸序号。裸序号在跨版本引用时会静默指错篇，而错指不会报错。

篇名还暴露另一个事实：162 篇不是一人一时之作。篇间体例不一（通篇问答、纯条目、夹韵语口诀三种并存），重复与矛盾并存。同一句「阴阳者，天地之道也」在《阴阳应象大论》出现，《天元纪大论》几乎原样复现，只是主语换成了「五运阴阳」——这不是抄袭，是同一学派的共用句式在两个传承链上各留了一份。

还有一层麻烦：**同一篇有两个名字**。教材本用今字（本脏、五脏生成、五脏别论），全文本仍作古字（本藏、五藏生成、五藏别论）；遗篇在教材本里带「遗篇·」前缀，在全文里没有。这类差异必须逐条列表，本仓的做法是建一张异名表一条一条写死；不能靠模糊匹配——模糊匹配会把《本藏》判到别的篇，把整篇静默算成 0 字，而 0 不会报错，只会让你的覆盖率凭空少一块。

## 二、教材本与全文：一句话可能不在教材里

本课有两套底本，各管一段：

- **教材选读本**（`standards/neijing-xuandu`）：31 个篇类、162 篇、136,032 字，是教学用的通读注释本；
- **全文**（`standards/materials/neijing-quanwen`）：162 篇、155,206 字，是逐字引用的裁判。

二者分工用一句话说清：**教材本是教学的通读注释本，负责注释、篇导读与编排；全文是逐字引用的裁判**。判断一句话能不能引，只认后者。

两者不是同一文本。本章的四篇里，三篇基本等同全文（相似度 0.949–0.983），《至真要大论》却是**节选**：教材本 2,421 字，全文 7,018 字，相似度 0.191。也就是说，教材这一篇与全文的相似度只有 0.191，字数只及 34.5%（2,421 / 7,018），删掉的主要是六气胜复与方制君臣的大段推演。

这个差异不是瑕疵，是选读本的职责。但它产生一个陷阱：**你从教材上记住的「原文」，可能是一个被剪过的句子**，而剪口处不留痕迹。本章四篇合计，教材本 6,789 字对全文 11,557 字，覆盖 58.7%——四篇里有近一半的文字不在教材上。

另外，教材本的每一篇里还分了「原文」与「注释」两类块。**注释不是原文**：把注文当经文引，是这一行最常见的硬错。引用时写清是经文还是注，是本课的底线。

## 三、判据：哪一句能当依据，哪一句只能当参照

### 三项核对必须在动笔前做完

拿任何一句「内经说」去用，先核三件事，缺一件就不许写进稿子：

1. **篇名核对**：这句在哪一篇？给出素问/灵枢 + 篇名 + 篇序，三样齐。篇名对不上全书篇目表的，直接判为记错。
2. **版本核对**：这句在教材本、全文里各是什么形态？教材本缺、全文有的段落只能说明教材略去，不能当教材引；版本不同而字句有异的，按你要引的那一版写，并注明版本。
3. **字句核对**：把这句去掉标点后在该篇全文里逐字搜。搜不到就是改过字、串过篇或者根本是转述；节引用「……」断开可以，改字不可以。

### 两档判据

| 档 | 成立条件 | 能拿它做什么 | 不能拿它做什么 |
|---|---|---|---|
| **依据** | 篇名可定位、全文逐字命中、上下文完整（剪口之外）、是经文而非注文 | 作为论证的前提引用；作为操作规范的出处；作为反驳别人的证据 | 不能跨篇拼句，不能把两篇的句子并成一句「内经认为」 |
| **参照** | 命中但有剪口、属注文与通读、属后人推演、或只有转述而无原句 | 说明某一学派的说法倾向；提示可以往哪篇去找 | 不能当定义、不能当操作依据、不能写「原文明确规定」 |

划档的分界线只有一条：**能不能给出一串连续的字，让别人在同版本里搜到并读出同一个意思**。能，是依据；只能给出大意，是参照。四类常见写法的问题可以直接对照：

| 写法 | 问题 |
|---|---|
| 「内经云：精神内守，病安从来」 | 无篇名，不可定位 |
| 「上古天真论说……」 | 无书名；同名篇在其他典籍里也可能存在 |
| 「《素问》讲恬淡虚无」 | 无篇名，无法核 |
| 「《素问·上古天真论》认为养生很重要」 | 有出处但无原文，是转述不是引用 |

第四种最常见，也最容易被自己骗过去：转述听起来像引用，但它把「我认为」伪装成了「原文说」。

### 四种失效模式

| 失效模式 | 表现 | 拦法 |
|---|---|---|
| **以注代经** | 把教材「注释」「通读」块的话当经文引，字数还很好看 | 引文必须落在 `units.json` 的 `body` 里，`notes`/`tongdu` 一律不算 |
| **断章取义** | 单取「壮火食气」，读成火邪致病；放回《阴阳应象大论》的气味讨论，它讲的是药食气味的厚薄 | 引用必须带上下文一句，段级定位不能省 |
| **版本混用** | 前半句抄教材本、后半句抄全文，拼出一句两版都没有的话 | 一条引文只允许一个版本，跨版差异单列 |
| **望文生义** | 用现代词义解古字，如把「走」读成步行、「写」读成书写 | 疑难字先查该篇注文与异文，再定词义 |

## 四、读法与记录：从选文到引用的六个动作

1. **定篇**：按主题在 162 篇里定位，先查篇名表，再读篇首三段确认主题相符。
2. **取版**：明确这一条引教材本还是全文；教材本只作教学导读，引用落到全文。
3. **切片**：按段取，不按句取。段的边界决定上下文，句的边界只管停顿。
4. **验字**：去标点后在该篇全文里逐字搜，命中的记「依据」，不命中的记「参照」并写明原因。
5. **标级**：在记录里写清依据/参照，参照项不许出现在论证的前提位置。
6. **留痕**：字数、版本、相似度一并记下，让别人能拿同一份语料复算出同一个数。

前五步是判断，第六步是让它可被检验。**可复算是引用能被别人检验的前提**；至于这句话在临床上对不对，是后面九章的事。

记录字段固定为八项，缺项即视为未核：

| 字段 | 填什么 | 为什么必须记 |
|---|---|---|
| 引文 | 去标点后的连续汉字 | 供逐字检索 |
| 书名·篇名 | 素问/灵枢 + 篇名 | 定位到篇，防止串篇 |
| 篇序 | 素问第 N 篇 / 灵枢第 N 篇 | 版本不同则序不同，须与版同记 |
| 版本 | 教材本 / 全文 | 决定字句形态 |
| 字数 | 该篇教材本字数 / 全文字数 | 判断是否节选、剪口在哪 |
| 命中 | 逐字命中 / 未命中 | 依据与参照的分界 |
| 上下文 | 前后各一句的首尾 | 断章取义的唯一拦截 |
| 判定 | 依据 / 参照（参照须写原因） | 决定能不能进论证 |

**考核项（三条，逐条可判对错）**：一、任给一句本章引文，须能说出书名、篇名、篇序，并当场在全文里搜到；说不出或搜不到，判不合格。二、任给一章的篇目，须能算出教材本与全文的字数与覆盖率，并与本仓 `chapter-map.json` 的数一致。三、任给一条「内经认为」，须能判它是依据还是参照，并说出判定的那一条理由。

## 代价与边界

- **字数口径依赖清洗规则。** 本章所有字数按「去掉标点与空白后的汉字数」计，含异体字、不含篇名与校勘夹注。换口径数字会变，所以每个数字都标了来源文件。
- **162 篇不等于 162 个作者。** 本章只做结构与量的描述，不做作者判定、不做成书年代的裁断。七篇大论是否为后补、遗篇是否可信，是学术史问题，本章不裁。
- **本仓用的是电子整理本，不是校勘底本。** 异体字、通假字、错简都可能与刻本不同。一切引文以所用底本为准，本章不承担校勘职能。
- **篇均数字不能判优劣。** 灵枢篇短是体裁所致，不是内容单薄；拿篇均字数当重要性是典型的指标误用。
- **「全文」也只是这份语料里的全文。** 它比教材本全，但不等于传世善本全貌；两者都缺的段落，本仓不补。
- **记录表不解决义理分歧。** 八项字段只能保证引文可核，不能保证理解正确；同一句在依据档上仍可能被两位注家读出相反的意思。
