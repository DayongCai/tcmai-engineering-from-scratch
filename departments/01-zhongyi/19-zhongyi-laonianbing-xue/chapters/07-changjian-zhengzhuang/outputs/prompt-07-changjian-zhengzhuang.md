# 七症状归并

## 用途

七个「说不清」的主诉常同源。**先把红旗排掉，再找共同上游**，比一症状一方有效得多。

## 步骤

### 1. 列症状

晕／不寐／便秘／排尿／汗出／纳差消瘦／疼痛

### 2. 排红旗

体重骤降、新发剧痛、停止排气（任一命中先转诊）

### 3. 找上游

多为脾虚、痰瘀

### 4. 定治法

健脾为主，兼顾化痰、活血、安神（不给剂量）

## 判据速查：七个症状的「一句话上游」

| 症状 | 最常见上游 | 第一排查 |
|---|---|---|
| 眩晕 | 痰（脾虚生痰）＋肝阳 | 血压、颈椎、耳源 |
| 不寐 | 心神失养＋脾胃不和 | 睡眠卫生、情绪、药物 |
| 便秘 | 气虚推动无力、津亏肠燥 | 饮食活动、药物性 |
| 排尿异常 | 肾与膀胱气化、前列腺 | 前列腺、盆底、感染 |
| 汗出异常 | 气阴两虚、卫表不固 | 自主神经、结核、甲亢 |
| 纳差与消瘦 | 脾虚、恶性消耗 | **体重下降速度** |
| 疼痛 | 瘀与寒、久病入络 | 部位性质、骨折风险 |

七个症状里有六个的上游落在脾与肾——这就是本章「脾胃肝胆」居首（350）的原因，也是「合看而非分治」的依据。

## 输出

① 症状清单；② 红旗排查；③ 共同病机；④ 治法方向。
