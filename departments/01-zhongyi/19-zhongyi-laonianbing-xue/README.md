## 一、学科定位

老年病学研究的是**生了病的人**，不是病人身上的病。它与内科学的分界有三条：

| 维度 | 内科学 | 老年病学 |
|---|---|---|
| 组织方式 | 按病分章 | 按人（老年特点）分章 |
| 目标 | 治愈或控制疾病 | 维持功能、减少失能 |
| 用药 | 按病给药 | 多重用药审查、小剂量起始 |
| 评价 | 指标达标 | 功能与生活质量 |

老年病的三个临床特点：**多病共存与虚实夹杂、症状不典型与变化迅速、病情缠绵与康复缓慢。**

## 二、计算约定（本学科与内科不同）

底本结构化脚本 `scripts/build_laonian_text.py`（12 章 → 77 单元，一小节一单元），口径实测后确定：

**三辨＝病因 / 病机 / 证候表现**，第三项取老年特有的可观察项：步态、跌倒、认知、纳食、二便、睡眠、体重、乏力。
实测（186,163 汉字）按单元首位：病机 **55** / 证候表现 14 / 病因 8——**病机居首**，因为老年病章讲的多是「为什么老人不同」。

**四位面＝脏腑系统（心脑 / 肺系 / 脾胃肝胆 / 肾与骨关节）**，四条候选实测：

| 候选 | 实测 | 结论 |
|---|---|---|
| **A 脏腑系统** | 2,386 / 1,378 / 3,304 / 2,018（max/min **2.4×**） | **采用**：与教材 08–11 章一一对应 |
| B 虚损四分 | 569 / 458 / 374 / 387（**1.5×**） | 不作四位面：分布极均说明「虚」是全书底色、不分章，改作**横向观察轴**写进各章 |
| C 病邪四分 | 933 / 888 / 580 / 163（5.7×，毒过稀） | 弃用 |
| D 形神四分 | 1,180 / 1,510 / 3,657 / 999（3.7×，脏腑单极） | 弃用 |

四套候选的实测数字全留 `standards/laonian/axis-probe.json`。

## 三、中医 → AI 桥梁

- **共病网络**：多病共存（第 12 章）可建为诊断—用药—风险的二部图；
- **综合评分**：老年综合评估（CGA，第 5 章）的五个域（功能／认知／营养／跌倒／用药）可结构化；
- **功能端点**：步速、握力、起立试验是「虚」的可测替代（第 11 章「肾虚证据四取法」）；
- **风险红线**：四条心血管红线、三条消化红线、三条症状红旗可作规则层。

## 五、五条实测发现（写进正文）

1. **病机居首 12 章全占**：三辨首位全是病机（55/77 单元），说明本课程讲的是「老人的机制」而非「病的识别」——与四门临床课（多以证候表现居首）形成对照；
2. **虚损四分 1.5×**：气虚 569 / 血虚 458 / 阴虚 374 / 阳虚 387，几乎均匀——「虚」是全书底色，只作横向观察轴；
3. **脾胃肝胆在 5 章居首**（02/03/04/06/07/10/12），历代养老著作的落点（饮食、脾胃）在教材里延续至今；
4. **数值 906 全库最高**：第 10 章 384、第 7 章 270、第 9 章 214——老年病写得多的是「岁／天／次／克」这类可数项；
5. **引书两极**：第 4 章 80 次（最高）与第 11 章 1 部 1 次（最少）并存——肾系骨关节六病以功能与专科处理为主，教材没有硬凑古籍依据。
