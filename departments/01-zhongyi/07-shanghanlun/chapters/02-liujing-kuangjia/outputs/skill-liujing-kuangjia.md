# liujing-kuangjia

## 何时使用

- 写讲义/教材前，确认六经各自在底本里有没有正文
- 有人引用「某经提纲」时，核对是否为原文
- 教材与底本对不上，需要把差异定位到「缺篇 / 错配 / 异文」

## 不适用

- 辨证分型（本技能只做文本核对）
- 跨书汇总（底本之外一律不引）
- 方证推演

## 步骤

1. **定底本**：确认 JSON/文本来源与篇数，记录底本标识。
2. **逐经检索提纲条**：逐字，不做同义扩展。
3. **跑标志方**：每经 1–3 个代表方/关键句，命中数为 0 即证据。
4. **判状态**：ok / weak / MIA。
5. **留痕**：MIA 必须写出「已检索什么、命中多少」，供下一手复核。

## 输出模板

```text
【经名】状态：ok | weak | MIA
  提纲条：<原文>（篇 N）/ 检索不到
  规模：N 条 / M 篇
  标志方：A×n、B×m
  线索：…
```

## 质量判据

- 六行都有状态，没有空白格
- MIA 的经没有任何替代引文
- 异文与版本差异保留

> 本技能只做文本结构核对，不构成辨证论治指导。
