# 六经辨证的框架：五条提纲，一条失踪 · 提示词

## 用途

给「六经辨证的框架：五条提纲，一条失踪」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「五条提纲，逐字与落点 → 少阴：目录里有，正文没有 → 判据：提纲条是入口，不是全部 → 读法与引用动作」这条链。
