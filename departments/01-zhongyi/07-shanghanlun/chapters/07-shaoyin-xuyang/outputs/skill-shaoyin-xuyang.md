# shaoyin-xuyang

## 何时使用

- 读到少阴条文，要判断它讲的是预后还是方证
- 教学演示「少阴看手足」的判据落在哪几条
- 需要区分「死证」与「不治」「难治」三类语气

## 不适用

- 预后估计（生存期、概率）
- 处方与剂量
- 把外源条文当作底本原文引用

## 步骤

1. **声明数据边界**：底本缺此篇；只用外源·搜狐2019（45 条）。
2. **看结论词**：死 / 不治 / 难治。
3. **看判据词**：必自愈 → 欲解；可治/不死 → 可治；欲愈、欲解时。
4. **未命中 → 未判定**，不猜。
5. **写判据**：逐字，不替换成解释。

## 输出模板

```text
【条】外源·搜狐2019 第 N 条
【类别】…
【判据】…（逐字）
【不发散】…
```

## 质量判据

- 类别有结论词或判据词支撑
- 判据逐字可回原文
- 未判定的没被硬归
- 条号标「外源」

> 本技能只做条文预后分类，不构成诊疗依据。
