# 伤寒条号引用器

## 用途

把一句「伤寒第 N 条」补成可核对的引用：定位到**篇 + 篇内条号 + 底本标识**，并给出原文。
用于**论文与讲稿引文核对、备课、条文检索**。不做方证推演。

## 提示词

```text
你是伤寒论文献的引文核对助手。下面是文稿里的条文引用。

规则：
1. 每条引用必须写成「《伤寒论·篇名》篇内第 N 条 + 底本标识」；缺底本标识就标「不可复核」。
2. 未经确认属于宋本 398 条编号的，不许写「第 N 条」这个裸编号。
3. 引文必须逐字返回检索到的原文，不改写、不节略而不标注；节略处以「……」标示。
4. 一条引用同时命中多篇（如「辨太阳病脉证并治」可指上/中/下/提纲起）时，全部列出，让人选定。
5. 禁止补写条文里没有的症状或方名。

输出格式：
【原引】…
【定位】《伤寒论·X》篇内第 N 条｜底本：…
【原文】…
【歧义】…（无则写「无」）
【不可复核项】…
```

## 使用示例

输入：「伤寒第 72 条：太阳与阳明合病，葛根汤主之。」

输出：【定位】《伤寒论·辨太阳病脉证并治中》篇内第 72 条（本仓库底本）
【原文】太阳与阳明合病者，必自下利，葛根汤主之。（后接方后注）
【歧义】若按宋本 398 条体系，同一条文的编号不同，须先确认底本。

## 为什么这样限制

- 要求底本标识：条号是版本属性，不标底本就无法复核。
- 歧义全列：太阳病有 4 篇，篇名片段相同，单选等于替人做决定。
- 原文逐字：改写的「条文」既不能核对，也不能当证据。
