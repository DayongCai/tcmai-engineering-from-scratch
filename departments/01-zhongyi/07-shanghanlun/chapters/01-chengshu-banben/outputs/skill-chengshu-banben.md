# chengshu-banben

## 何时使用

- 文稿里出现「伤寒第 N 条」，需要确认底本与篇次
- 备课检索条文原文（含方后注）
- 发现同一句在两本书里编号不同，需要留下版本说明

## 不适用

- 需要方证推演或剂量折算（另章）
- 只记得条文大意、没有任何原文词句时（此时应写「不可复核」）
- 需要宋本 398 条与底本的逐条映射（本仓库未建该映射表）

## 步骤

1. **取原文特征词**（如「太阳与阳明合病」），不要用编号当唯一线索。
2. **检索篇**：命中多篇则全列（太阳病有上/中/下/提纲起四篇）。
3. **定条号**：篇内连续编号；同时记 declared 与 actual 条数是否一致。
4. **标底本**：写明识别古籍刻本 version 与三级对象编号。
5. **逐字返原文**，节略处标「……」；方后注单列。

## 输出模板

```text
【定位】《伤寒论·X》篇内第 N 条｜底本：…
【原文】…
【方后注】…（无则写「无」）
【歧义】…
```

## 质量判据

- 每条引用都带底本标识
- 没有裸编号（「第 35 条」这种）
- 原文与方后注分开，节略有标记

> 本技能输出为文献核对辅助，不构成诊疗建议。
