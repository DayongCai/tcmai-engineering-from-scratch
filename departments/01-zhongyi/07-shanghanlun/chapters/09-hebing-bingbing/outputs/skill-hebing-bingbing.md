# hebing-bingbing

## 何时使用

- 病历或带教讨论里出现「合病」「并病」，需要把依据讲清楚
- 条文对照：同一合病不同主症为何用不同方
- 教学：演示「并列 vs 叠加」的时间结构差异

## 不适用

- 预测传变方向与转归（需要病程数据，条文关键词不够）
- 条文只以「二阳」「三阳」指代、且无其它线索时（应保留「未标经」）
- 方药剂量与加减（另章）

## 步骤

1. **找依据词**：有无「未罢」「复」「转属」等先后词 → 并病；纯并列 → 合病。
2. **列经名**：只列出现过的六经名；不足写「未标经」。
3. **摘主症**：逐字引用，未描述项单列。
4. **引原方**：条文有方照录；无方写「原文无方」。
5. **标出处**：篇名 + 篇内条号 + 底本标识。

## 输出模板

```text
【定性】…｜依据词：…
【定经】… + …
【主症】…｜未描述：…
【方】…
【出处】《伤寒论·X》篇内第 N 条（底本：…）
```

## 质量判据

- 定性有依据词，不是凭感觉
- 没有补写条文里没有的经名或症状
- 出处到篇、到条、带底本

> 本技能输出为教学与讨论辅助，不构成诊疗建议。
