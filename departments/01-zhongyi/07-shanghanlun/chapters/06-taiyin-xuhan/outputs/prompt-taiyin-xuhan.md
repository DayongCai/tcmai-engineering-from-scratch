# 太阴病：一条提纲撑起的一章，理中丸不在这一篇 · 提示词

## 用途

给「太阴病：一条提纲撑起的一章，理中丸不在这一篇」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「底本里的太阴，被切成三块 → 一条提纲，两个版本 → 教材链条断在哪一环 → 读法与引用动作」这条链。

## 提示词

```
我在学《伤寒论》第 6 章「太阴病：一条提纲撑起的一章，理中丸不在这一篇」，本章 4 节 / 2,886 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 能用的太阴条文只有 1 条提纲
   - 你无法只凭这两个电子文本判断哪个更早
   - 「太阴—理中丸」这条链，是靠跨篇拼合与后世补充成立的，不是太阴篇内部的原文
   - 、时腹自痛；阳明是腹满
4. 本章自陈的边界（不得越过）：
   - 本章不重建太阴篇。缺口如实留在表里，不用其他篇的条文填补——填补会让「太阴篇只有一条提纲」这个事实消失，而那个事实正是本章要讲的。
   - 跨篇引用不是错，但不标篇名是错。把霍乱篇、差后劳复篇的方写成太阴篇的方，损失的是可复核性，而不是准确性。
   - 一条提纲不足以支持辨证。任何「太阴虚寒证」的完整证候描述都超出本章证据；本章能给的只有入口条件与一句禁令。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

条文与条数引自 `standards/shanghan/底本.json`（识典古籍刻本电子整理本，太阴篇残缺，缺口标注即为结论的一部分，可复算）；具体操作以现行规范与所在机构制度为准。
