# jueyin-hanre

## 何时使用

- 引用某经条文，需要确认它是否真在该篇
- 某篇条文数异常少，怀疑残缺或混编
- 教材主方在底本里查不到，需要给出可复核的说法

## 不适用

- 补佚（本技能只标缺口）
- 厥阴病的完整辨证（底本证据不足）
- 方剂剂量与加减

## 步骤

1. **取提纲**：逐字，先归类「症状 / 误治后果」。
2. **归一**：异体字（𤍠 等）先归一再计数，并写明。
3. **两列计数**：篇内 / 全库，逐词标注「底本无此条 / 仅篇外 / 篇内可用」。
4. **混入检查**：本篇内出现的其他经病名计数。
5. **写口径**：条数反映底本状态，不反映病证权重。

## 输出模板

```text
【提纲】…
【分布】词｜篇内｜全库｜标记
【混入】…
【口径】…
```

## 质量判据

- 两列都在
- 「仅篇外」都带篇号
- 没有把缺口写成「本篇云」
- 异体归一有说明

> 本技能只做文本核对，不构成辨证处方建议。
