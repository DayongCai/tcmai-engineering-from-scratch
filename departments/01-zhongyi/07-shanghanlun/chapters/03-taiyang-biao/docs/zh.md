# 第 3 章 · 太阳病表证：有汗与无汗之外，还有 129 条「发热」被写成了异体字

> **MOTTO:** 「太阳病，头痛发热，身疼恶风，无汗而喘者，麻黄汤主之。」——《伤寒论·辨太阳病脉证并治中》
>
> **PROBLEM:** 你想统计「发热」在全书出现多少次，用检索工具一查——39 条。可正文里明明到处都是发热。你漏掉的那 124 条，写的是「发𤍠」：𤍠 是一个不在 GB2312 里的异体字。

## 学习目标

## 核心概念

### 两条分支的原文条件

> 太阳病，发热汗出恶风，脉缓者，名为中风。——《伤寒论·辨太阳病脉证并治》（篇 4）
>
> 太阳中风，阳浮而阴弱。阳浮者，热自发，阴弱者汗自出，啬啬恶寒，淅淅恶风，翕翕发热，鼻鸣干呕者，桂枝汤主之。——《伤寒论·辨太阳病脉证并治》（篇 4，方一）
>
> 太阳病，头痛发热，身疼恶风，无汗而喘者，麻黄汤主之。——《伤寒论·辨太阳病脉证并治中》（篇 5）

三条放在一起，「有汗 / 无汗」是分水岭，「脉缓 / 脉浮紧」是佐证，「喘 / 干呕」是旁证。注意桂枝汤条的自我解释：**阳浮者热自发，阴弱者汗自出**——原文自己在给机制，这是《伤寒论》里少见的「条文带注释」写法。

### 实测规模（本章全部数字可复算）

| 指标 | 实测 |
|---|--:|
| 太阳病域条文 | **566 条 / 4 篇** |
| 「桂枝汤」出现 | **134 条** |
| 「麻黄汤」出现 | **44 条** |
| 「汗出」 | **224 条** |
| 「无汗」 | **38 条** |
| 「恶寒」 | **107 条** |
| 「发热」（正体） | **39 条** |
| 「发𤍠」（异体） | **129 条** |
| 归一后「发热」 | **163 条**（129 + 39 − 5 条两形并存） |

最后两行的意义：**不归一化，检索「发热」会漏 124 条（43%）**。这不是排版问题，是检索层的正确性问题——你的症状索引会静默丢掉三分之二的证据。

### 桂枝汤 134 条说明了什么

桂枝汤出现 134 次，麻黄汤 44 次，比例约 3:1。但这不是「桂枝汤更重要」的证明——桂枝汤大量出现在**禁忌、误治、变证**的条文里（「桂枝汤不中与之」「先与桂枝汤」之类），出现频次高恰恰因为它是基准方，被反复当作对照。用频次当权重，会把「被反复否定」读成「最常用」。

## 代价与边界

- **归一化表是手工的，不完整**。本章只收 𤍠→热 一组并附实测影响；其他异体（如「蚘/蛔」「欬/咳」）未纳入，检索结果仍可能漏。
- **「脉缓」不是心率慢**。原文语境指脉势缓纵，本章代码只做字符串匹配，**不解析脉象含义**。
- **表证判定器只覆盖两条经典分支**。太阳病 566 条里大量是变证、坏病、结胸、痞证，本章不处理；把它当「太阳病分类器」会错。
- **频次不是权重**（见上）。
- 判定器输出「不排除项」而非单一结论，因为原文本身允许合病（见第 9 章）。

## 进阶思考

中医文本的检索难点不在分词，而在**字形**。一个异体字能让 129 条证据消失，而这 129 条恰恰是「发热」最密集的部分——数据工程里最贵的错误，通常不是算法错，是字符没对齐。
