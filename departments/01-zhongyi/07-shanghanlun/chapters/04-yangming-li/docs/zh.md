# 第 4 章 · 阳明病里实证：三承气不是三档火力，是三道门槛

> **MOTTO:** 「阳明病，脉迟，汗出不恶寒，身重短气，腹满潮热，大便硬，大承气汤主之。若腹大满不通者，与小承气汤。」——《伤寒论·辨阳明病脉证并治》（篇 8）
>
> **PROBLEM:** 你把三承气当成「轻—中—重」三档，病人腹满潮热就往上加码。但原文这两句是**同一基础证的两个分支**：都是腹满潮热，一个大便硬用大承气，一个腹大满不通改用小承气——加码方向在这里是反的。
>
> **双根因定位:** 环境逼迫(临床要选方) + 知识积累(逐条条件表 × 异文标注 = 能说明「凭什么这一档」)

## 核心概念

### 阳明提纲与它的夹注

> 阳明之为病，胃家实，一作寒是也。——《伤寒论·辨阳明病脉证并治》（篇 9）

「胃家实」三字是全篇入口。夹注「一作寒是也」提示另有版本作「胃家寒」——这直接把提纲的判据反转。本章按主流读法取「胃家实」，但**保留夹注**，因为删掉它会假装版本一致。

### 一条原文，两个分支

> 阳明病，脉迟，汗出不恶寒，身重短气，腹满潮热，大便硬，大承气汤主之。若腹大满不通者，与小承气汤。——（篇 8）

拆开看条件：

| 条件（原文词） | 大承气支 | 小承气支 |
|---|:--:|:--:|
| 脉迟、汗出不恶寒 | ✓ | ✓ |
| 身重短气、腹满潮热 | ✓ | ✓ |
| 大便硬 | ✓ | —（腹大满不通） |
| 腹大满不通 | — | ✓ |

**大便硬**是燥屎成形的标志，故用大承气直下；**腹大满不通**是气机壅塞为主，燥屎未必坚，故小承气轻下。所以「更重的症状用更轻的方」并不矛盾——两个分支的目标不同：一个攻燥屎，一个通壅气。

### 异文会改方

> 发汗后，恶寒者，虚故也。不恶寒但热者，实也，当和胃气，与调胃承气汤。方三十三玉函云：与小承气汤。——（篇 5）

同一处，《玉函》给的是小承气。底本把两个说法并列保留了。这件事对工程的启示很直接：**方名不是铁值，是带版本的值**。任何「条文→方」的映射表都必须留一个 `variant` 字段，否则你在做的是一个静默二选一。

## BUILD IT：从零实现

```js
// code/main.js
grade(signs)   // 输入 {潮热,谵语,手足濈然汗出,腹满,不大便,大便硬,燥屎,腹大满不通}
               // 输出 {tier: 大承气|小承气|调胃承气|不足以定档, hit[], missing[], notExcluded[]}
```

判定规则（全部来自原文词）：

1. 大便硬 + 潮热 + 腹满 → `大承气汤`
2. 腹大满不通 + 潮热（无大便硬）→ `小承气汤`
3. 但热不恶寒、无腹满硬满 → `调胃承气汤`（和胃气）
4. 其余 → `不足以定档`，并列出还缺哪些条件

## 代价与边界

- **只覆盖三承气的原文条件**，阳明病另有白虎汤、茵陈蒿汤、栀子豉汤等大量分支，本章不涉及。
- **「痞满燥实」是后世归纳**，原文用词是腹满、大便硬、潮热、谵语；本章的映射标明了对应词，未把归纳当原文。
- **判定器不处理虚实夹杂**（如「脉迟」在此为邪结而非虚寒），也不判断患者能否承受攻下。
- **异文保留不取舍**：`variant` 字段只记录，不自动选择；选哪一版是文献学判断，不由代码代劳。
- 攻下类方剂有明确禁忌与风险，本章代码仅作文本规则演示。

## 进阶思考

三承气的教学图常画成一条上升的箭头，而原文给的是一棵分叉树。把树压成箭头，学生就会记住「越重越猛」这个错的方向——这正是「读原文」与「读归纳」的差别。
