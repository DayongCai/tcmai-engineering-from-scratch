# 第 7 章 · 病因不是一份清单，而是一台从症状倒推的反向机器

> **MOTTO:** 「邪之所凑，其气必虚。」——《素问·评热病论》
>
> **PROBLEM:** 六淫 6 类、七情 7 类、病理产物 3 类（痰饮、瘀血、结石），单这三组就是 16 个病因名；而一次门诊能稳定采集到的体征，通常只有十几条。16 个候选对着十几条证据，反推必然不唯一。教材·第7章·7.1.1 给了方法名——辨证求因，却没给「几条证据才够指向一个因」的门槛。

**双根因定位:** 环境逼迫（病案里写「受凉后咳嗽，属风寒」，被问「受凉的人多了，为什么只有他咳」时答不出正气的部分） + 知识积累（把病因读成需要四条判据才点亮的候选，而不是见到一个症状就贴一个标签）

**教材出处:** 教材·第7章·7.1（分类与认识方法）、7.2（六淫）、7.3（疠气）、7.4（七情）、7.5（饮食劳逸）、7.6（病理产物）；发病原理见 7.1.2。本章的四条判据与时序表为**教学设定**。

> **规模：** 6 节（内容小节，不含「代价与边界」）/ 6 条核心判断（见 `quiz.json`）。

## 一、定义与采集项：三类病因，两种求因方向

教材·第7章·7.1.1 把病因分成三类，这个分法的用处是决定「往哪里找」：外感病因（六淫、疠气）源于自然界，多从外侵入；内伤病因（七情、饮食、劳逸）源于机体内部失调；病理产物性病因（痰饮、瘀血、结石）由其他病因导致，形成后又成为新的致病因素。第三类的特殊之处在于它是**二手的**：痰是水液代谢失常的结果，同时又是新的致病因素，记录时必须写清这是原始因还是继发因，否则病机链会从中间开始讲。

教材·第7章·7.1.2 给了发病的两句话：「正气存内，邪不可干」与「邪之所凑，其气必虚」。这两句合起来是一个双条件模型：邪气是条件，正气是依据。所以求因有两个方向——**向外找邪**（季节、气候、环境、接触史）与**向内找正**（体质、劳倦、情志、宿疾）。只做一个方向的记录，一定缺一半。

病机的写法有现成样板。教材·第9章·9.1.1 举病机十九条为例，其中「诸风掉眩，皆属于肝」与「诸湿肿满，皆属于脾」两条，结构完全一样：先列一组症状（掉眩、肿满），再给一个归属（肝、脾），中间没有任何形容词。这个写法值得照抄，因为它把可观察项放在了前面，把结论放在了后面，读者可以逐项核对。十九条的价值不在条数，而在示范了这种句法。

采集六项，每项都要落到可核的时间或部位上：

| 采集项 | 记什么 | 为什么必须有 | 核验动作 |
|---|---|---|---|
| 起病方式 | 骤起 / 渐起 | 骤起多外感，渐起多内伤，这是最粗的筛 | 问「第一天什么样」 |
| 时序 | 起因、加重、缓解三个时点 | 因果要求因在前 | 三点写在同一行 |
| 季节气候 | 发病时的时令与异常气候 | 六淫与季节强相关 | 查当时当地气象记录 |
| 部位 | 症状落在何处、是否游走 | 风善行、湿趋下，靠部位分辨 | 让病人指，不让他描述 |
| 诱因 | 受凉、饮食、情志、劳倦 | 诱因常被误当病因 | 逐项问，不合并 |
| 素体 | 平素怕冷/怕热、易汗/无汗 | 决定「从化」方向 | 问一年四季的常态 |

六项里最容易被漏的是最后一项。同受寒邪，素体阳虚者从寒化，素体阳盛者从热化——教材·第7章·7.1.2 讲发病时强调正气，讲的就是这件事。没有素体这一栏，两个吃了同一顿饭、吹了同一阵风的人，你无法解释为什么一个病了一个没病。

## 二、成组判据与「不成立」的四种情形

**病因判据**四条，缺一条只能记「疑似」（**教学设定**）：**时序**（因在前、病在后）、**部位**（症状分布与该邪的侵袭部位相符）、**性质**（症状性质与该邪的特性相符）、**排他**（没有另一个因解释得更好）。四条里最常被跳过的是第一条与第四条。

六淫的性质要能背成「一句话＋一个反例」，否则判据用不起来：风善行数变（病位游走、起病急）、寒凝滞收引（痛处固定、筋脉拘急）、暑炎热升散而耗气伤津（高热、多汗、乏力）、湿重浊黏滞而趋下（头身困重、病程缠绵、下部为甚）、燥干涩伤津（口鼻干、皮肤裂）、火炎上燔灼（上部症状、耗津、动血）。教材·第7章·7.2 把这六条逐节展开，每一节都给了性质与致病特点两栏，这个结构本身就是判据表。

「不成立」四条：

1. **只看单个症状。** 见痛就判寒、见痒就判风。痛有胀痛、刺痛、冷痛、隐痛，寒只对应其中一类；单症状定向是把特性句当成了万能钥匙。
2. **把诱因当病因。** 「吃了火锅所以上火」——火锅是诱因，火是病机结果。教材·第7章·7.5.1 讲饮食致病时，落点是「过食辛辣助火」，讲的是性质，不是某一顿饭。
3. **把病理产物当原始病因。** 痰饮、瘀血既是结果又是因，写「痰湿致病」时必须回答「痰从何来」。跳过这一问，病机链就断在中间。
4. **疠气混入六淫。** 疠气是一类具有强烈传染性的外感病邪，其特点是发病急骤、传染性强、一气一病、症状相似（教材·第7章·7.3.1）；六淫则一气多病、症状多样。混在一起写，会漏掉「需要报告与隔离」这一层。

## 三、落到临床：三个动作与三条边界

**动作一，画时序表。** 三列：起因、加重、缓解，每列写时间与当时的情形。因果判断的全部力量都在「因在前」这三个字上；时序写不出来，后面三条判据都是猜。

**动作二，每个候选写「哪条特性对上了」。** 候选病因可以并列两三个，但每个后面必须跟一句特性对应——「湿：头身困重、苔腻、下肢为甚」。写不出对应的候选，删掉；写得出却排他的理由说不清，标「疑似」。

**动作三，病机写成三层，不写病名。** 邪正（虚实）→ 阴阳（寒热）→ 气血津液（在哪一层失常）。教材·第9章·9.1.1 把病机分基本病机与具体病机两层，基本病机正是邪正盛衰、阴阳失调、气血津液失常这三组；具体到某脏某腑，是第二层。三层写完，病名往往自己就出来了，不必先猜病名再倒填病机。

三条边界：

- **病因推断不是病原学诊断。** 「感受风寒」是中医的病因判断，不指向任何一种病原体；需要病原学结论时，走检验，两者并列记，不互相替代。
- **疠气要报。** 一旦判为疠气，防疫动作优先于辨证讨论；这一条不属理论推演，属公共卫生义务。
- **不做预后判断。** 病因与病机写清即可，转归要看邪正消长与治疗反应，不在本章给结论。

还要给「病因」与「病机」划一条界线，否则写记录时两者会混成一句。病因回答「是什么让它发生的」，病机回答「发生之后体内怎么变的」。同一件事可以同时出现在两栏：受寒是病因，寒凝导致气滞是病机；但在记录里必须分栏写，因为两者的证据不同——前者要时序，后者要部位与性质的变化。教材·第9章·9.1.1 把病机定义为疾病发生、发展、变化的机理，这一定义本身就把它放在了病因的下游。

## 四、记录字段与四类失效

| 字段 | 取值示例 | 说明 |
|---|---|---|
| 起病 | 三日前进食生冷后骤起 | 时间＋诱因 |
| 时序 | 起因 3 日前 / 加重昨夜 / 未缓解 | 三点齐全 |
| 候选因 | 寒（外感）、食积（内伤） | 可并列 |
| 特性对应 | 寒：冷痛、得温减、苔白 | 每个候选都要写 |
| 素体 | 平素畏寒、手足不温 | 决定从化 |
| 原始/继发 | 原始：寒；继发：痰 | 病理产物必标 |
| 排他 | 无发热恶风，故不取风 | 必填 |
| 结论 | 寒邪犯胃，疑似 | 疑似与确定分开 |

四类失效：

- **把理论当结论。** 「寒主收引」是性质，不是「抽筋就是寒」。抽筋还可能是血虚、津伤；性质句给的是方向，判据给的是这一次的证据。
- **泛化。** 六淫被用成六个筐，什么症状都能塞进去：乏力是湿、烦躁是火、怕冷是寒、游走是风。筐越多，判断越少。
- **背诵代替判断。** 背得出「风为百病之长」，却说不出这位病人的哪个症状是「善行」、哪个是「数变」。两个词对应两条可观察项，说不出就是没掌握。
- **以辞害意。** 「百病多由痰作祟」被读成「查不出原因的都有痰」，于是把一切疑难都归痰。原句讲的是痰致病广泛、变幻多端，是范围描述，不是兜底条款。

## 五、考核项：五道要落笔的题

1. **填一张时序表。** 通过标准：三点齐全，每点带时间与情形；缺一点即不通过。
2. **给一个病例列三个候选因并排他。** 通过标准：每个候选写出特性对应；排他理由必须指向另一候选的缺失项。
3. **区分原始因与继发因。** 通过标准：写出「痰/瘀从何而来」，不把病理产物直接当起点。
4. **判断是否属疠气。** 通过标准：必须用「一气一病、症状相似、传染性强」三条对照，并说明防疫动作。
5. **把一条病机写成三层。** 通过标准：邪正、阴阳、气血津液三层俱在，且不出现具体病名。

## 六、外源补录：病机十九条（教材只引两句）

教材 9.1.1.2 只引「诸风掉眩，皆属于肝」「诸湿肿满，皆属于脾」两句，却说「十九条」。这两句是十九条里的第一与第四条，不是全部。下表按《素问·至真要大论》顺序补全，出处统一标为**外源·笈成·黃帝內經素問 至真要大論篇第七十四**（繁体底本，简体为通行写法）。

**为什么必须补全**：病因病机一章的判据是「由症推机」，而十九条是这套推法的骨架。只给两条，学生手里等于只有两个格子；十九条齐了，才能看出「同一组症状可以归到不同脏」——这正是后面「不成立」四种情形的来源。

**补全之后的边界**：十九条是分类骨架，不是诊断标准。条文中「皆属于」是归属方向的判断，不是「一定属于」；实际病例常一条对多脏，报告里要写明依据的是哪一条、以及为什么排除相邻的那一条。

## 七、代价与边界

- **丢掉确定性。** 四条判据跑完，很多病例仍只能写「疑似」。这是反推本身的性质：从结果推原因永远是多对一，承认疑似比给一个漂亮答案更接近实情。
- **丢掉病名层。** 本章只到病机三层，不给病名。病名要综合病程、体质、治疗反应，超出病因病机的范围。
- **16 个病因名里，一半没有独立可观察项。** 七情尤其如此：喜、怒、思、悲、恐的强度无法直接测量，只能靠行为与自述。这一层的缺口，记录里应当注明，不许用「情绪不畅」四个字盖过去。
- **正气的部分最薄。** 「正气存内」是原理，可操作的是它下属的体质与劳倦项；把正气写成一个总评分，是把原理当指标用。
