# 第 1 章 · 阴阳不是两个筐，而是一条能反向追问的偏向轴

> **MOTTO:** 「阴阳者，天地之道也，万物之纲纪，变化之父母，生杀之本始，神明之府也。」——《素问·阴阳应象大论》
>
> **PROBLEM:** 教材·第2章·2.2.3 处理阴阳在人体上的分布，只给出 5 组结构对偶：上下、表里、背腹、脏腑、兴奋与抑制。5 组对偶都是「整体对整体」的判断，可你第一次独立接诊遇到的是畏寒、口渴、脉数同时出现的人——三项体征分指两侧，5 组对偶一条也用不上。真问题不是「阴阳是什么」，而是**体征互相打架时，这句话还能不能说，凭什么说**。

**双根因定位:** 环境逼迫（带教老师只问一句「你凭什么是阳虚」，你只能把症状再复述一遍，说不出哪一项证据更重） + 知识积累（把阴阳从两个名词改读成一条带权重、可被反证推翻的轴，判断才第一次有依据）

**教材出处:** 教材·第2章·2.2（2.2.1 属性与归类、2.2.2 消长与转化、2.2.3 在医学中的应用）。本章的六项采集项、权重顺序与判据表均为**教学设定**，用于课堂演练，不是教材给出的分类标准。

> **规模：** 5 节（内容小节，不含「代价与边界」）/ 6 条核心判断（见 `quiz.json`）。

## 一、定义与采集项：把「阴阳」拆成六项可记的东西

教材·第2章·2.2.1 的定义只有一句：「阴阳是对自然界相互关联的某些事物或现象对立双方属性的概括」。这句话里最容易被读丢的是「相互关联」和「某些」两个限定：它说的不是万物分两类，而是**在一组已被认为互相关联的现象里，指出对立的两侧**。所以判阴阳的第一步不是分类，是先确认这组现象属不属于同一个对照面。手足温度和今天的情绪不在同一个对照面上；手足温度与畏寒喜暖在。

第二步才是采集。下面六项是本章要求逐项落笔的采集项，每一项都要能回答「凭这一项判阴阳，理由是什么」：

| 采集项 | 记什么 | 为什么它能进这条轴 | 核验动作 |
|---|---|---|---|
| 寒热喜恶 | 怕冷还是怕热、喜温喜凉、加衣减衣 | 教材·第2章·2.2.1 把寒热制衡当作对立制约的典型，它是最稳定的自我报告项 | 追问部位（手足/背腹/全身）与时间（晨轻暮重） |
| 渴与饮 | 渴不渴、想喝冷喝热、饮多饮少 | 热盛伤津则渴喜冷，津停不化则渴不欲饮，方向相反 | 问「想喝」而非「喝了多少」，后者受习惯干扰 |
| 二便 | 小便清长或短赤、大便溏或结 | 教材·第2章·2.2.3 把二便归入可观察的外在征象 | 记颜色、次数、排便感受三项 |
| 脉 | 至数、形态、沉浮 | 「察色按脉，先别阴阳」把脉列为判阴阳的入口 | 左右对比，记一次不成，记两次取同 |
| 舌 | 舌质颜色、舌苔厚薄润燥 | 舌象变化慢，适合做长期偏向的旁证 | 自然光下看，不隔夜补记 |
| 精神体力 | 倦怠还是烦躁、欲寐还是易怒 | 阳主动、阴主静，此项常与寒热同向 | 问「一天里最没力气是几点」 |

采集之后是核验，三条硬要求：一是每项都要有**部位**，不能只写「畏寒」；二是每项都要有**条件**，比如「饮热水后缓解」；三是每项都要有**时长**，「三天」和「三年」不是同一条证据。缺其中任意一条，这一项记为「未采集」，不许改记为「无异常」——这是本章最容易被跳过的一步，也是后面所有误判的源头。

## 二、成组判据与「不成立」的四种情形

单项体征不能定向，这是本章的核心判据。教材·第2章·2.2.2 讲「重阴必阳，重阳必阴」，讲的正是量变到极处才转向；反过来说，没到极处的单项证据本来就不该被当成结论。据此给出成组判据（**教学设定**，课堂演练用）：

- **可判**：同一方向上有 3 项及以上，且没有一项反向的强证据。此时可以写「偏阴」或「偏阳」，并列出参与判断的项。
- **并见**：2 项同向、1 项反向，或两侧各有 2 项。此时不合并、不折中，写成「寒热并见，两轴分列」，把两侧各自列清。
- **不判**：只有 1 项，或关键项（寒热喜恶）缺失。只记录，不给结论。
- **权重顺序**（教学设定）：寒热喜恶 ＞ 渴饮 ＞ 二便 ＞ 脉 ＞ 舌 ＞ 精神体力。理由是前四项是病人自己报告的持续状态，后两项是检查者一次性的读数；一次读数压不过一段持续状态。换一批病人、换一个科室，这个顺序应当重排——它是可讨论的教学约定，不是教材口径。

判据之所以要写成「不成立条件」，是因为只给正面标准时，任何人都能凑出三条支持自己的证据。四种情形一旦出现，前面的判断即作废：

1. **单项定阴阳。** 「脉数就是热」不成立：数脉在失血、惊恐、虚损里都会出现，方向并不唯一。
2. **并见被读成矛盾并被抹掉一侧。** 畏寒与口渴同时存在时，删掉其中一项，剩下的判断看起来更干净，也更假。
3. **舌脉与问诊冲突时只留顺手的。** 这是选择性取证，不是辨证。冲突本身是信息，应当写进记录。
4. **把「没问」当「没有」。** 缺项不是阴性证据。未采集与阴性必须分开记，否则判断的证据条数是虚的。

每写一个判断，后面必须跟一句作废条件：「若出现 X，此判断作废」。这句话不是形式，它是让判断可被反驳的唯一入口；写不出作废条件的判断，说明判据还没成形。

## 三、落到临床：三个动作与三条边界

**动作一，分栏记录。** 把寒热、渴饮、二便、脉、舌、精神六项分行写，不许合并成「寒热错杂」四个字。合并之后，你失去了回头检查的能力——两周后复诊，你无法判断是体征变了还是你当时记漏了。

**动作二，每个判断写一条最强反证。** 判「偏阳」时，写出最不支持它的一项（例如「但手足不温」）。这一条要写在结论旁边，不是写在备注里。

**动作三，用证据条数报不确定度。** 报「3 项同向」，不报「感觉八成是」。条数是可复核的，感觉不是；而且条数会逼你去补采集，感觉只会让你提早收工。

三条边界必须同时写进记录：

- **阴阳只判偏向，不定病名。** 它回答「这一组体征整体偏哪一侧」，不回答「这是什么病」。把偏向直接写成病名，是越过了八纲其余六纲的位置。
- **不替代表里、寒热、虚实各自的判据。** 阴阳是这六纲的汇总视角，不是省掉六纲的捷径。教材·第2章·2.2.3 说「阴病治阳，阳病治阴」，前提是已经辨明病在阴在阳，而不是先套一句治则。
- **真假寒热时明确弃判。** 阴盛格阳可见身热反欲近衣、面赤而足冷，此时的方向证据是被格拒出来的假象，强行二分只会得到一半正确的答案。此时输出两条轴并写「不可判」，比给一个错结论更负责。

## 四、记录字段与四类失效

记录用固定字段，字段名固定，取值才可比。下面这套字段是本章的最小集，缺项留空并注明原因，不许默认为正常：

| 字段 | 取值示例 | 备注 |
|---|---|---|
| 主诉 | 畏寒三月，加重一周 | 一句话，不超过二十字 |
| 寒热 | 手足冷，加衣不减，晨轻暮重 | 部位＋条件＋时间，三项齐 |
| 渴饮 | 渴喜热饮，量少 | 方向（冷/热）与量分开记 |
| 二便 | 小便清长，大便成形偏溏 | 颜色、次数、感受 |
| 脉 | 沉细，两尺尤弱 | 至数、形态、沉浮 |
| 舌 | 淡，苔薄白润 | 质与苔分开 |
| 证据条数 | 3 项偏阴，1 项反向 | 反向项要写出是哪一项 |
| 结论 | 偏阴（不确定：有口渴） | 不确定项必须写出 |
| 作废条件 | 若口渴转为喜冷、脉转数，判断作废 | 每次都要写 |
| 弃判理由 | — | 弃判时写，不弃判留空 |

四类失效，都是这套字段跑久了一定会出现的：

- **把理论当结论。** 「阳虚则寒」是规则，不是诊断。规则只说明阳虚会有寒象，不说明有寒象就是阳虚；诊断要落到那三四条体征上。教材写的是前者，记录里要写的是后者。
- **阴阳泛化。** 万物皆可分阴阳这句话是对的，但它不能反过来用：见到任何一对概念就套阴阳，遇到局部病变（一个关节、一颗牙）立刻失灵，因为局部没有「整体偏向」可言。
- **背诵代替判断。** 能背「善诊者，察色按脉，先别阴阳」，却写不出这一次按脉得到什么。背诵的量与判断的质量无关，考场上能骗过自己，床边骗不过。
- **以辞害意。** 「重阴必阳」的前提是「物极」，把「阴久了必转阳」当成规律读，就抽掉了条件，也抽掉了它作为判据的用处——它本来提醒你观察转折点，而不是让你预言转折。

## 五、考核项：五道要写出依据的题

1. **填一张六项采集表。** 用一段两分钟的问诊录音，填满六项字段，每项带部位、条件、时长。通过标准：六项无空缺，或空缺处写明未采集原因；不出现「无异常」代替「没问」。
2. **三个病案判偏向轴。** 分别给出一致型、并见型、缺项型各一例。通过标准：每例写出证据条数、反向项、作废条件；并见型不得合并成单一结论。
3. **找出一例应当弃判的病例。** 通过标准：说出弃判属于四类中的哪一类（并见、缺项、真假寒热、单项）。
4. **复述「重阴必阳」的成立条件。** 通过标准：必须点出「极」与「条件」两件事，只背原句不给分。
5. **一句话反驳「阴阳就是二分法」。** 通过标准：必须落在互根或转化中的一条上（例如「二分法的两类互斥，阴阳的两侧互藏且可转」），只说「不是二分」不算。

## 六、代价与边界

这套判据换来的是可复核，代价是丢掉三样东西，且这三样不是实现没写好，是「一条轴」这个表示本身带不动的：

- **转化是过程，判据是快照。** 阴阳消长讲的是量变积累到转折，本章的判据只给某一时刻的偏向，无法表达「正在转」。要表达转折，得连续记录同一组字段，比较两次之间的位移。
- **互藏表达不了。** 「阴中有阳、阳中有阴」说的是两侧互相包含；一条轴的两端只有位置，没有结构。所以本章的判断永远不能说「纯阴」或「纯阳」。
- **强度被压成有/无。** 畏寒三分与畏寒十分在记录里都是「畏寒」一条证据。要保留强度，得给每项加等级，但等级一旦相加就又回到「凑分数」，本章刻意不做。

不适用范围也要写清：寒热错杂、真假寒热、局部病变三类不适用本章的单一偏向判据；儿科与失语患者因自我报告项缺失，只能使用可观察项，且必须在记录里注明缺失，不许当作阴性。
