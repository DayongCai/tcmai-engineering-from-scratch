## 核心概念

### 中医：阴阳

阴阳是对相互对立又相互依存的两类属性的抽象概括。《素问·阴阳应象大论》把它抬到「万物之纲纪」的位置。关键在于它是**关系性**的，不是分类标签：没有孤立的「阴」，只有相对某参照的「偏阴」。

临床落地时，八纲里的阴阳是**总纲**——表里、寒热、虚实六纲都可以归到阴阳下。所以本章不是要判「属于哪种证」，而是判「这一组体征整体上偏向哪一侧，偏多少」。

### AI / 工程：逻辑回归

给定特征向量 $\mathbf{x}$，先做一次线性打分：

$$z = \mathbf{w}^\top\mathbf{x} + b$$

再用 sigmoid 把实数压到 $(0,1)$：

$$p = \sigma(z) = \frac{1}{1+e^{-z}}$$

以交叉熵为损失 $L = -[y\log p + (1-y)\log(1-p)]$ 时，梯度有一个非常干净的形式：

$$\frac{\partial L}{\partial \mathbf{w}} = (p - y)\,\mathbf{x}$$

这意味着每个权重的更新方向，就是「预测偏差 × 该特征取值」。**权重会自己长成对特征重要性的解释** —— 这正是阴阳判别需要的「说得清理由」。

### 对应关系

| 中医概念 | AI / 工程概念 | 桥梁（为什么可以这样翻译） |
|---------|--------------|--------------------------|
| 阴阳 | 二分类的两个类别 | 对立两端的划分，与二分类的标签空间一一对应 [**B 级**] |
| 偏阴偏阳的**程度** | sigmoid 输出的连续概率 | 虚证不是「非阴即阳」，而是偏向程度不同；连续输出保留了强度 [**B 级**] |
| 阴阳互根互用 | 两类的概率之和为 1 | 这一条是**约束**，恰好对应 $p + (1-p) = 1$ [**A 级**] |
| 阴阳转化 | 状态转移 / 阈值翻转 | 「重阴必阳」是**动态过程**；本章的单次分类模型**拿不到**这一层，需在后续章节用状态机补 |
| 阴阳 = 二进制 0/1 | —— | ❌ **D 级误用**。二进制位互斥且可交换，阴阳互根、可转化、带强度。用位运算处理阴阳会丢掉全部动态语义 |

## BUILD IT：从零实现

只用 Node.js 标准库。三件事必须自己写：sigmoid、交叉熵、梯度下降。

```javascript
// 1. sigmoid —— 注意数值稳定写法：z 很负时 e^{-z} 会溢出
function sigmoid(z) {
  if (z >= 0) { const e = Math.exp(-z); return 1 / (1 + e); }
  const e = Math.exp(z); return e / (1 + e);
}

// 2. 交叉熵 + 梯度（一次算完）
function lossAndGrad(w, b, X, y) {
  let loss = 0;
  const gw = [0, 0, 0];
  let gb = 0;
  for (let i = 0; i < X.length; i += 1) {
    const z = dot(w, X[i]) + b;
    const p = sigmoid(z);
    const eps = 1e-9;
    loss += -(y[i] * Math.log(p + eps) + (1 - y[i]) * Math.log(1 - p + eps));
    const d = p - y[i];              // ← 梯度就是 (预测 − 真实)
    for (let j = 0; j < w.length; j += 1) gw[j] += d * X[i][j];
    gb += d;
  }
  return { loss: loss / X.length, gw: gw.map((g) => g / X.length), gb: gb / X.length };
}

// 3. 梯度下降
for (let step = 0; step < 4000; step += 1) {
  const { gw, gb } = lossAndGrad(w, b, X, y);
  for (let j = 0; j < w.length; j += 1) w[j] -= lr * gw[j];
  b -= lr * gb;
}
```

跑起来：

```bash
node code/main.js
```

## USE IT：框架调用

框架做的事和上面完全一样，只是把「手写三次循环」封成了 `fit`。本课用同一个梯度公式做一次 10 批的**小批量**训练，验证手写版本与批量版本的解在同一量级。

关键对照：如果两种实现给出的权重**符号相反**，那一定是特征标准化或学习率出了问题，不是「模型玄学」。
