# 阴阳倾向结构化判别

## 何时使用

当你需要把一段非结构化的四诊描述，落到「偏阴 / 偏阳 / 无法判断」这一个输出上，并且
**必须能说明理由**时。

不适用：需要给出证型诊断、需要处方、需要在真实患者身上做临床决策 —— 本技能只做结构化与非判断性归因。

## 输入契约

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `畏寒程度` | 0..1 | 否 | 0 = 无 / 1 = 畏寒肢冷显著 |
| `口渴程度` | 0..1 | 否 | 0 = 口不渴或喜热饮 / 1 = 大渴喜冷饮 |
| `脉数` | 0..1 | 否 | 0 = 迟 / 1 = 数 |
| `原文` | string | 否 | 医师原始描述，用于补齐缺失项 |

**缺失项必须显式记为缺失，不得填 0 或填均值。**

## 步骤

1. **抽取**：从 `原文` 中抽取三项体征。抽不出来就标缺失，不要猜。
2. **检查**：若缺失项 ≥ 2，直接输出 `无法判断`，并说明缺哪几项。
3. **打分**：$z = -7.60 \times \text{畏寒} + 5.19 \times \text{口渴} + 5.85 \times \text{脉数} - 2.10$，$p = \sigma(z)$。
   （系数取自第 1 章教学样例，**不具备临床效力**，仅用于演示流程。）
4. **归因**：逐项报告「该项取值 × 该项系数 = 对 $z$ 的贡献」，按贡献绝对值排序。
5. **判定**：
   - $p \ge 0.70$ → `偏阳`
   - $p \le 0.30$ → `偏阴`
   - 否则 → `无法判断（倾向不明显）`
6. **拒答检查**：$p \in (0.30, 0.70)$ 或任一关键项缺失 → 输出 `无法判断` + 需要补充的信息。

## 输出契约

```json
{
  "verdict": "偏阴 | 偏阳 | 无法判断",
  "p_yang": 0.0,
  "evidence": [{ "feature": "畏寒", "value": 0.9, "contribution": -6.84 }],
  "missing": [],
  "confidence_note": "一句话说明这个判定的可靠性边界",
  "disclaimer": "本输出为结构化辅助，不构成临床诊疗建议。"
}
```

## 硬约束

- 输出**必须**包含 `evidence`，且每项都能回指到输入或原文。无理由的判定一律视为无效输出。
- 输出**必须**包含 `disclaimer`。
- 不允许输出方剂、剂量、治则 —— 那不是本技能的职责。
- 当判定为 `无法判断` 时，**必须**在 `missing` 或 `confidence_note` 里写清「还需要问什么」。

## 验证清单

- [ ] 三项体征全缺失时，输出 `无法判断` 且 `missing` 列出三项
- [ ] `p = 0.68` 的病例输出 `无法判断`，而不是 `偏阳`
- [ ] `evidence` 的贡献值与系数符号一致（畏寒为负贡献）
- [ ] 任何输出路径都带 `disclaimer`
