# 第 5 章 · 气血津液给的是方向，不是配额，所以它不能当化验单读

> **MOTTO:** 「人之血气精神者，所以奉生而周于性命者也。」——《灵枢·本藏》
>
> **PROBLEM:** 精、气、血、津液、神五个物质，两两之间共 10 对关系（从 5 个里取 2 个）；教材·第4章·4.6 只给了 2 对正文——气与血、气与津液。剩下 8 对里，「精血同源」只在 4.1.2 顺带一句，「神与血」只在 4.3.2 有一句「血脉和利，精神乃居」。10 对关系只写 2 对，你背下的那张关系图有一大半是没有正文的空边。

**双根因定位:** 环境逼迫（病人说「我气虚」，你只能回一句「补补气」，说不出气在哪一环节虚、虚到什么程度） + 知识积累（把五个物质读成五种「有方向的流量」而不是五种「有配额的存量」，判断就从形容词变成可记录的项）

**教材出处:** 教材·第4章·4.1（精）、4.2（气）、4.3（血）、4.4（津液）、4.5（神）、4.6（关系）。本章的五栏采集法与方向记号为**教学设定**；教材给方向与性质，不给系数。

## 一、定义与采集项：五个物质各自的判定特征

五个物质的定义在教材里分得很散，先把各自的落脚点摘出来，才谈得上采：

- **精**：教材·第4章·4.1.1 说是构成人体和维持生命活动的最基本物质，先天之精禀受于父母、藏于肾，后天之精源于水谷、由脾胃运化生成。落点在**生长、发育、生殖**这条时间线上。
- **气**：教材·第4章·4.2.1 说「气的运动称为气机，基本形式为升、降、出、入」。落点在**动**，不在量。
- **血**：教材·第4章·4.3.1 引「中焦受气取汁，变化而赤是谓血」，落点在**色与行**：能变赤、能在脉中循行。
- **津液**：教材·第4章·4.4.2 分清稀与稠厚两种，清稀者布于体表孔窍主滋润，稠厚者布于关节脏腑主濡养。落点在**润与停**。
- **神**：教材·第4章·4.5.1 分广义与狭义，广义是生命活动的主宰及其外在征象，狭义指精神、意识、思维。落点在**反应**。

采集表按「判定特征」而不是按「名词」列，因为名词可以背，特征不能：

| 物质 | 判定特征 | 可观察项 | 常见替代写法 |
|---|---|---|---|
| 精 | 生长、发育、生殖的时间线 | 齿、发、骨、生殖功能的变化速度 | 「肾虚」 |
| 气 | 升降出入的顺畅与否 | 呼吸、嗳气、矢气、倦怠、声音 | 「气虚」 |
| 血 | 色与行 | 面色、唇甲、舌质、脉的充盈 | 「血虚」 |
| 津液 | 润与停 | 口干、皮肤、二便、痰、水肿 | 「湿气重」 |
| 神 | 反应 | 目光、语言、应答、睡眠 | 「心神不宁」 |

最右一列是必须禁掉的写法：它们把判断直接写成结论，中间的证据被吞掉了。采集的要求是先把中间项写出来——气要写「呼吸浅、语声低、饭后腹胀」，不能只写「气虚」。

四类气还要分开采，因为生成与分布不同：元气根于肾，宗气聚于胸中，营气行于脉中，卫气行于脉外（教材·第4章·4.2.1）。落到采集上，元气看生长与生殖的时间线，宗气看呼吸与语声的强弱，营气看脉的充盈与色泽，卫气看恶风与汗出。把四者合写成「气不足」，等于把四个不同部位的证据压成一个词，后面的判断再无法复核——这也是临床最常发生的一次信息丢失。

## 二、成组判据与「不成立」的四种情形

**单项判据**按各自特征来（**教学设定**）：气看动（升降出入有无一处不畅）、血看色与行（色淡且脉细为偏少，色紫且痛有定处为偏滞）、津液看润与停（干与肿可以同时存在）、精看时间线（变化的速度比绝对值有意义）、神看反应（对外界应答的快慢与一致）。

**关系判据**只有方向，没有系数。教材·第4章·4.6.1 给了三条：气能生血、气能行血、气能摄血；反向一条：血为气母，载气、养气。4.6.2 同样给三条：气能生津、气能行津、气能摄津；反向两条：津液能生气、能载气。把这些写成箭头，就是本章关系图的全部分量：

- 气 → 血（生、行、摄），血 → 气（载、养）
- 气 → 津液（生、行、摄），津液 → 气（生、载）
- 精 ↔ 血（精血同源，双向），精 → 气（化气），气 → 精（生精）

双向边要特别小心。精血同源写成双向，是因为精能化血、血能化精，两条都成立；但双向不等于等强——失血之后补血见效快、补精见效慢，方向相同而快慢不同。记录里遇到双向边，应当分别写两次证据，不能因为一个方向有征象就默认另一个方向也成立。同理，气→津液的三条（生、行、摄）各有自己的观察点：生看津液是否充足，行看输布是否均匀，摄看有无无故流失，三者不能互相顶替。

「不成立」四条：

1. **没有中间项就断言。** 「气虚」必须有至少两条可观察项支撑，否则它只是一个态度。
2. **把气当单一实体。** 元气、宗气、营气、卫气四者的生成与分布不同，混成一句「气不足」会丢掉「哪一处不足」。教材·第4章·4.2.1 分述四者，正是为了防止这种合并。
3. **血虚等于贫血。** 血虚是功能层的判断（色、行、养），贫血是检验层的指标。两者可以同时成立，也可以只有一个成立；把等式写死，会在化验正常时否定病人的真实不适，也会在化验异常时误判为血虚。
4. **津液等于水。** 津液讲的是有润养作用的那部分体液及其输布，喝水多不等于津液足——水停不化时，喝得越多，肿得越明显。

## 三、落到临床：三个动作与三条边界

**动作一，五栏分记。** 精、气、血、津液、神各占一栏，每栏只填可观察项。分栏的好处是能看出「同一个人身上几栏同时出问题」——这在临床上很常见，而合并成一句「气血两虚」就看不出来了。

**动作二，每条关系写方向。** 写「气能行血」，不写「气血互相影响」。方向写出来，才能被反驳：如果一个人气虚而血行不见迟滞，那条方向在这个病例上就没有证据，应当如实记为「未显现」。

**动作三，只记可观察项。** 舌、脉、面色、二便、汗、精神、声音，七项足够支撑一张表。不可观察的（如「气机不畅」这种总称）只能作为结论栏的用词，不能作为证据栏的条目。

汗与二便是津液最容易被漏掉的两条证据。汗多而口渴、尿少，指向津液耗损；汗出而口不渴、身重，指向水停不化。二便同理：便干而小便短赤，与便溏而小便清长，方向相反。这两组对照不需要任何仪器，只需要在记录里把「渴不渴」与「汗多少」分开写——合成一句「有点脱水」，两组证据就都没了。

三条边界：

- **不做定量。** 教材通篇没有给出任何一项的系数，本章也不造。任何「气虚三分、血虚两分」的相加，都是把方向图当成了计量表。
- **不替代检验。** 血与津液的判断不能替代血常规、电解质这类检查；两者回答的是不同层面的问题，冲突时应当并列记录，而不是用一个否掉另一个。
- **神只描述。** 神志相关的判断停在行为描述层（应答、目光、睡眠、语言），不给分值，也不据此推断器质病变。

## 四、记录字段与四类失效

| 字段 | 取值示例 | 说明 |
|---|---|---|
| 物质 | 气 / 血 | 一栏一个 |
| 可观察项 | 语声低、饭后腹胀、呼吸浅 | 至少两条 |
| 方向 | 气→血（行） | 关系必须带箭头 |
| 证据状态 | 有征象 / 未显现 / 冲突 | 三态，不许只写「有」 |
| 合并结论 | 气血两虚（暂定） | 合并必须列出被合并的各栏 |
| 作废条件 | 若脉转洪大，改判 | 必填 |

四类失效：

- **把理论当结论。** 「气能生血」是方向，不是「补气就能治血虚」的处方。方向说明的是可能的路径，走不走得通要看这一例的证据。
- **泛化。** 「气」被用来解释一切：乏力是气虚、胀是气滞、闷是气郁、喘是气逆——四个词覆盖了所有不适，也就等于没有判断。判据要求可观察项，正是为了把覆盖面收窄。
- **背诵代替判断。** 背得出「气为血帅、血为气母」，却在病人面前分不清是气不摄血还是血热妄行。两句口诀给的是方向，鉴别要靠出血的颜色、病程与伴随项。
- **以辞害意。** 「气主煦之，血主濡之」被读成「气是热、血是水」，于是把温煦理解成体温、把濡养理解成补水；原意说的是功能属性，读成物质属性就把两个系统压成了一个。

## 五、考核项：五道要落到表上的题

1. **填五栏采集表。** 通过标准：每栏至少两条可观察项，无一条写成结论词。
2. **给三条关系标方向。** 通过标准：箭头方向正确，且每条注明教材·第4章的节号。
3. **判一例「血虚」是否成立。** 通过标准：必须引用色与行两类证据；化验正常不构成否证，化验异常不构成证明。
4. **区分气滞与气逆。** 通过标准：一个说运行不畅（胀、闷），一个说上升太过（呕、咳、嗳），不得互换。
5. **写出「津液不足」与「水湿内停」并存的记录。** 通过标准：两条同时写，且指出这正是「津液不等于水」的临床长相。

## 六、代价与边界

- **丢掉数量感。** 五栏表能说清「哪一栏、哪个方向」，说不清「差多少」。这是本章刻意的取舍：在没有系数的前提下给数量，等于编数。
- **合并会掩盖并存。** 「气血两虚」这类合并结论读起来顺，但它压缩了两栏各自的证据。字段里要求列出被合并的各栏，就是为了保留回溯路径。
- **8 对关系没有正文。** 精与气、神与精、神与津液这些边，教材只有零星一句。本章把它们写成箭头，但箭头只是方向，不是论证；真正的补写要等后续在每条边上找到独立征象。
- **神这一栏最薄。** 它只有行为描述，没有可比的量。承认这一点，比给它编一个评分标准要诚实；也不该借量表之名，给它造一个看起来可比的量级。
