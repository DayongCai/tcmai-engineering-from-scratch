# 治则不是八个字的目录，是八条各带「何时不能用」的判据 · 提示词

## 用途

给「治则不是八个字的目录，是八条各带「何时不能用」的判据」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「定义与采集项：三层结构，四项采集 → 成组判据与「不成立」的四种情形 → 落到临床：三个动作与三条边界 → 记录字段与四类失效」这条链。

## 提示词

```
我在学《中医基础理论》第 8 章「治则不是八个字的目录，是八条各带「何时不能用」的判据」，本章 7 节 / 3,276 汉字，习题 6 道。
教材规模：教材第 10 章，合计 3,544 汉字。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 在最上（未病先防、既病防变、瘥后防复，10.1）
   - 居中（治病求本与正治反治、调整阴阳、扶正祛邪、三因制宜，10.2）
   - 只写法不写证
   - 把反治当正治
   - 把三因制宜当免责条款
   - 把八法当八门互斥的功课
4. 本章自陈的边界（不得越过）：
   - **丢掉方药层。** 没有方药，治法只有方向，读者会问「那到底怎么治」。这个问题的答案在下一门课，不在本章；硬塞进来，会变成没有依据的处方集。
   - **八法覆盖不全。** 八法是粗分类，真实治法远比八个多（如固涩、安神、开窍）。用八法当全目录，会漏掉整类治法；本章把它当方向坐标，不当清单。
   - **禁忌依赖病机判断。** 禁忌写得对不对，取决于证辨得准不准。证错了，禁忌也会跟着错——这一层风险无法用格式弥补。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为中医基础理论的教学与文献研读，治则治法的表述引自教材所述传统理论；具体操作以现行规范与所在机构制度为准。
