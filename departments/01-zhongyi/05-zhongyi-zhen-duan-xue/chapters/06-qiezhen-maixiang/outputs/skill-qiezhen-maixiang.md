# qiezhen-maixiang

## 何时使用

- 要按教材建 28 脉索引、脉名对照表或抽认卡
- 需要解释「28 脉」为什么在段标题里只数得出 27 个
- 要把「标题 vs 正文」做成可复现的核对，而不是靠记忆

## 数据边界

```text
教材：standards/zhenduan/ 教材 JSON · sha256 051d830a627c04cfd6e684f76537c19c691b63590fe3c0ca6bd3efa3ab9c5355
章：第5章 切诊（2 节 6 小节 14 段 2,030 字）
节：5.1 脉诊 1,545 字（4 小节 10 段）· 5.2 按诊 485 字（2 小节 4 段）
引用格式：教材·第5章·5.1.2.1
```

## 硬约束

1. 引用只写「教材·第5章·5.1.2.1」，不加别的称法。
2. 5.1.2.1 段标题是 **15** 个单字脉名，不是 14 个。
3. 5.1.2.2 段标题按顿号切 8 片段；「长短短脉」去重后只得长、短，「短」是重复字样。
4. 标题唯一脉名 **27**；正文 **28**；差 **1**，缺的是「缓」。
5. 不拿通行 28 脉名表补标题，也不替教材判定「缓」算不算病脉。

## 已核事实

| 项 | 值 |
|---|---|
| 规模 | 2,030 字 = 全书 9.1% |
| 脉诊 / 按诊 | 1,545（76.1%）/ 485（23.9%） |
| 5.1.2.1 段标题 | 15 名单字脉名 |
| 5.1.2.2 段标题 | 8 片段 → 12 名（重复：短） |
| 标题合计 / 正文合计 | 27 / 28 |
| 差值 | 1（缓，仅见 5.1.2.2 正文） |

## 使用方法

```bash
node code/main.js               # 现算两节字数与两种切分
node --test code/main.test.js   # 8 项断言（含教材原文核对与引用口径）
```

## 不适用

- 脉象判读、凭脉辨证、健康评估
- 跨教材的脉名比对与统一
- 按诊量化标准（教材未给）
