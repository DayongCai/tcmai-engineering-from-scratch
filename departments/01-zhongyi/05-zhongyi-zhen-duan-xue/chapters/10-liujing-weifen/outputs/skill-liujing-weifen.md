# liujing-weifen

## 何时使用

- 病例讨论前，需要把一份发热病历同时放到三套坐标上看
- 教学演示：让学生看清「太阳 / 卫分 / 上焦肺卫」为什么指同一段表证却不等价
- 跟诊记录整理，需要一份「每一列的依据在哪」的对照表

## 不适用

- 需要给统一分期、单一结论时（本技能明确拒绝合并）
- 需要脏腑辨证定位时（那是脏腑辨证的事，属教材第八章，不是阶段问题）
- 记录只有体温、没有舌质/斑疹/神志时（三列都判不实，只该写证据不足）
- 需要方药时（本技能不输出治法方药）

## 步骤

1. **锁记录**：按句编号，所有证据必须能指回句子。
2. **三列并行**：六经列（6 阶段）、卫气营血列（4 层）、三焦列（3 部位），各写各的。
3. **各用各的判据**：六经看寒热与经腑，卫气营血看热型 + 神志 + 斑疹 + 舌质，三焦看病位 + 热型。
4. **标重叠**：太阳≈卫分≈上焦肺卫、阳明≈气分≈中焦胃、少阴≈下焦肾，重叠处注明「重叠 ≠ 等价」。
5. **单列传变**：六经 5 式（循经/越经/直中/合病/并病）、卫气营血 2（顺/逆）、三焦 2 支（顺/逆）——条数与支数分开写。
6. **拒绝合并**：不输出「综合分期」，不给「属于第几期」的判定。

## 输出模板

```text
【六经列】阶段：<太阳…厥阴> / 证据：<症状>（第N句）… / 缺：… / 传变可能：…
【卫气营血列】层次：<卫分…血分> / 证据：… / 缺：… / 传变可能：…
【三焦列】部位：<上焦|中焦|下焦> / 证据：… / 缺：… / 传变可能：…
【重叠与分歧】…
【不合并声明】三列各自成立/不成立，不做统一分期
【必须追问】…
```

## 质量判据

- 三列都有明确落点或明确写「证据不足」，不许留空
- 没有一列借用另一列的证据（如用斑疹定六经即判失败）
- 重叠点至少写出一处，并写明为什么重叠不等于等价
- 传变条目数与支数分开报（8 条 / 9 支），不混用
- 全文不出现「属于第 X 期」这类合并分期表述

> 本技能输出为教学材料，不构成诊疗建议；病期与病位判断须由执业中医师作出。
