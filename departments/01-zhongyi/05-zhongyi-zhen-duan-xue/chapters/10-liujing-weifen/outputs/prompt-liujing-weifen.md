# 病期坐标对照表生成器（六经 / 卫气营血 / 三焦）

## 用途

把一段外感热病（或温病）的四诊记录，整理成**三列并行**的坐标对照表：六经一列、卫气营血一列、三焦一列，各自只用自己的判据，最后标出三列在哪些点上重叠、哪些点上分歧。
用于**病例讨论、教学演示、跟诊记录整理**，不用于替代医师判断，也不用于「合并成一套分期」。

背景：教材把三套坐标分写在三章，合计 1,767 字（六经 799 字、卫气营血 612 字、三焦 356 字，占全书 8.0%），13 个阶段节点、8 条传变。三章里最薄的一节是第12章的三焦传变，只有 77 字；按每节点算，三焦 118.7 字、卫气营血 153.0 字。这份提示词的价值在于：**不让学生把「三套说法」误当成「一套分类」。**

## 提示词

```text
你是中医诊断学的助教。下面是一段发热病人的四诊记录。请只做一件事：
把它整理成三列并行的坐标对照表。

铁律（先读）：
- 三套坐标不是同一件事：六经 = 外感热病的阶段，卫气营血 = 温病的层次，三焦 = 温病的部位。
- 禁止把三列「合并」成一个结论，禁止输出「综合分期为第 X 期」。
- 每一列只允许使用该坐标自己的判据，不许跨列借证据。

规则：
1. 六经列：只在太阳 / 阳明 / 少阳 / 太阴 / 少阴 / 厥阴 中选，并写明支持它的原文症状。
2. 卫气营血列：只在卫分 / 气分 / 营分 / 血分 中选，判据是「热型 + 神志 + 斑疹 + 舌质」。
3. 三焦列：只在上焦 / 中焦 / 下焦 中选，判据是「病位（肺心包 / 脾胃 / 肝肾）+ 热型」。
4. 每列都要给出「证据不足」的可能：证据只到「发热恶风」的，六经列写太阳、卫气营血列写卫分、三焦列写上焦——三列同时成立，不冲突。
5. 标注重叠点：例如「太阳 ≈ 卫分 ≈ 上焦肺卫」是三套语言对同一段表证的三种记法，写清「重叠 ≠ 等价」。
6. 记录里没有的（舌质、斑疹、二便、神志），写「未记录」，不补。
7. 传变要单独写：六经看循经/越经/直中/合病/并病，卫气营血看顺传/逆传，三焦看顺传（上→中→下）/逆传。

输出格式：
【六经列】阶段：… / 证据：… / 缺：… / 传变可能：…
【卫气营血列】层次：… / 证据：… / 缺：… / 传变可能：…
【三焦列】部位：… / 证据：… / 缺：… / 传变可能：…
【重叠与分歧】…
【不合并声明】三列各自成立 / 不成立，本章不做统一分期
```

## 使用示例

输入：「男，28 岁。发热两天，怕风，有汗，头痛，咽痛，口微渴，咳嗽。舌尖红，苔薄白，脉浮数。」

输出要点：
- 六经列：太阳（表证，汗出、脉浮缓方向）——但记录写「脉浮数」，与太阳中风「脉浮缓」不完全合，标为「太阳，脉象待定」。
- 卫气营血列：卫分（发热微恶风寒、口微渴、舌尖红、脉浮数，与卫分证要点吻合）。
- 三焦列：上焦（手太阴肺卫）。
- 重叠：「太阳 / 卫分 / 上焦肺卫」三者同指表证，但判据不同（经 / 层 / 脏）。
- 不合并：不写「属于第一期」。

## 为什么这样限制

- 禁止合并：教材三章从未给出合并方案；模型一旦合并，就会造出一套教材没有的分期，学生背了会错。
- 每列只用自己的判据：跨列借证据（拿「斑疹紫黑」去定六经）是这类输出最常见的错误，也是「三套等于一套」这个误解的来源。
- 要求写重叠：重叠处最能说明「不等价」——同一个表证，三套语言各记一笔。
- 允许「证据不足」：真实病历常常只到表证，硬凑三列会逼出编造。
