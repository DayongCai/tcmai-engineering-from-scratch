# bagang-bianzheng

## 何时使用

- 要画「八纲辨证分型表」「八纲 16 型」的图或文档
- 需要说清 8 纲、13 个证候、16 格三者之间的关系
- 要给「教材举例覆盖几格」一个可复现的答案

## 数据边界

```text
教材：standards/zhenduan/ 教材 JSON · sha256 051d830a627c04cfd6e684f76537c19c691b63590fe3c0ca6bd3efa3ab9c5355
章：第6章 八纲辨证（5 节 10 小节 20 段 1,823 字）
节：6.1 412 · 6.2 408 · 6.3 385 · 6.4 332 · 6.5 286
引用格式：教材·第6章·6.4.1.1（只写教材章·节号）
```

## 硬约束

1. 四对轴：表里 / 寒热 / 虚实 / 阴阳 → 4 × 2 = **8 纲**。
2. 点名证候 **13** 个，不多不少（含半表半里证、阴虚证、阳虚证、亡阴证、亡阳证）。
3. 阴阳**不是独立轴**：教材写「阴证：里虚寒证的总称」「阳证：表实热证的总称」→ 有效网格 2³ = 8 格。
4. 2⁴ = 16 只是乘法上界；半表半里使表里成三值，上界进一步成为 12 格（3×2×2）。
5. 四轴全定且被点名的组合只有 2 格：里·寒·虚（阴证）、表·热·实（阳证）。
6. 「上热下寒」用上下（部位）轴，不落八纲网格；不代补未举例的格。

## 已核事实

| 项 | 值 |
|---|---|
| 规模 | 1,823 字 = 全书 8.2% |
| 结构 | 5 节 10 小节 20 段（每节 2 小节 4 段） |
| 字数分布 | 412 / 408 / 385 / 332 / 286（逐节递减） |
| 8 纲 | 表、里、寒、热、虚、实、阴、阳 |
| 点名证候 | 13 个 |
| 空间 | 16（上界）/ 12（三值表里）/ 8（有效） |
| 点名覆盖 | 2 格 = 有效 25% / 朴素 12.5% |

## 使用方法

```bash
node code/main.js               # 五节字数、8 纲、13 证候、16/12/8 格、覆盖 2 格
node --test code/main.test.js   # 8 项断言（含教材原文核对与引用口径）
```

## 不适用

- 辨证诊断、给具体患者定八纲
- 补齐 16 型的证候名与治法
- 寒热真假 / 虚实真假的判别（教材无阈值）
