# 第 2 章 · 望诊：2,812 字里 1,249 字在舌上

> **MOTTO:** 「视其外应，以知其内脏，则知所病矣」——《灵枢·本脏》
>
> **PROBLEM:** 望诊 2,812 字，舌诊独占 1,249 字（44.4%），全身望诊 680、局部望诊 488、排出物与小儿指纹 395。剩下 1,563 字要交代 20 余处观察点，平均每处不到 80 字。这就意味着：望诊的**清单**比望诊的**文字**细——照书背记不住顺序，只能靠一张按部位排的表。

**双根因定位:** 环境逼迫（门诊里「伸舌头」几乎等于望诊全部，其余望法一闪而过，漏掉的部位没人补） + 知识积累（四节字数分布与部位清单已清点完，足以把「整体—局部—舌—排出物」排成一条固定路线）

**本章口径：** 教材·第2章（2,812 字）。望神、望色、形体姿态、局部、舌、排出物、小儿指纹七块，按先整体后局部、先静态后动态的顺序重排为一条采集路线；舌诊只给接口，细节归第 3 章。

## 一、采集：一条固定路线，五段二十余处

望诊最容易漏的不是难看的部位，是**顺序不定**。同一病人两次望诊看出不同结果，多半不是病情变了，是路线变了。本章固定「整体 → 头面五官 → 躯干四肢皮肤 → 舌 → 排出物」五段【教学设定】，条件允许时加第六段小儿指纹。

| 段 | 部位 | 看什么 | 判据方向 | 教材位置 |
|--:|---|---|---|---|
| 1 | 神 | 目、色、精神、言语、体态 | 得神／少神／失神／假神／神乱 | 2.1.1 |
| 1 | 色 | 色（青赤黄白黑）+ 泽（荣／枯） | 五色主病，泽夭定善恶 | 2.1.2 |
| 1 | 形 | 强弱、胖瘦、形盛／形衰 | 内脏坚实与否 | 2.1.3 |
| 1 | 态 | 动静、卧姿、异常动作 | 阴阳寒热虚实 | 2.1.3 |
| 2 | 头面 | 头形、囟门、面肿、腮肿 | 虚实、水湿 | 2.2.1 |
| 2 | 头发 | 疏密、荣枯、有无成穗 | 精血盛衰 | 2.2.1 |
| 2 | 目 | 目赤、目黄、目眦淡白、目窠浮肿 | 热、黄疸、血虚、水肿 | 2.2.1 |
| 2 | 耳鼻口唇齿龈咽喉 | 干枯、流脓、涕之清稠、唇色、龈色、乳蛾 | 肾精、湿热、寒热、血虚、热毒 | 2.2.1 |
| 3 | 颈项胸腹腰背 | 瘿瘤、瘰疬、胸廓、腹部膨隆、青筋、脊柱 | 气滞痰凝、水停、血瘀 | 2.2.2 |
| 3 | 四肢 | 抽搐、蠕动、痿废、关节肿大 | 动风、虚风、痿证、痹证 | 2.2.2 |
| 3 | 皮肤 | 斑、疹、水疱、疮疡 | 热入营血、风热、湿热、阴阳证 | 2.2.2 |

采集条件三条，缺一条该次望诊就要降级记录：**自然光**（避免色温偏红或偏青的灯）、**一臂距离**（先整体后局部，不贴脸）、**体位自然**（卧姿与坐姿的腹部形态不同，须注明）。这三条教材只在舌诊里写了「光线充足」，其余部位没写，属本课程补的采集条件。

## 二、成组判据：每一类要凑齐几项才算数

望诊的判据天生是成组的，教材也是成组给的：教材·第2章·2.1.1 把得神写成四项并列表述——「望神是观察人体生命活动整体外在表现以判断脏腑精气盛衰的方法。得神（有神）：两目灵活、明亮有神，面色荣润，精神充沛」。照这个写法，判据就该按组记，不按词记。

| 判据组 | 必须同时成立 | 缺项时的处置 |
|---|---|---|
| 得神 | 目（灵活有神）· 色（荣润）· 神（充沛）· 语（清晰）四项 | 缺一项记「少神待察」，不记「得神」 |
| 假神 | 「久病重病」+「突然转佳」+「面赤如妆」或「言语不休」 | 只有一项不作假神，但要写「动态异常，须复查」 |
| 五色主病 | 色（哪一色）+ 泽（荣／枯） | 只记色，判据不成立——无法分善恶 |
| 局部异常 | 部位 + 形态 + 色泽 三要素 | 缺一记「未采」，不记「无异常」 |
| 小儿指纹 | 关位（风／气／命）+ 四项观察中至少两项 | 只写颜色不写关位，判据不成立 |

不成立条件要写在采集单背面，因为它们是当场就要处理的：

| 情形 | 为什么不成立 | 处置 |
|---|---|---|
| 灯光下看面色 | 色温改变红与苍白的分界 | 自然光下重看 |
| 化妆、涂口红、染发 | 面色与唇色被覆盖 | 卸妆后重看，或注明「受妆容影响」 |
| 刚进食、饮酒、剧烈运动 | 面色泛红、唇色加深 | 静息后再看 |
| 小儿哭闹 | 面红、目赤为生理性 | 安静后重看 |
| 只看一张照片 | 色差与白平衡不可控 | 照片只作留档，不作判据唯一来源 |

## 四、动作与边界：什么时候必须转

| 触发 | 时限 | 动作 |
|---|---|---|
| 假神（重病中突然精神转佳、面赤如妆） | 即刻 | 上报，按危重流程启动 |
| 循衣摸床、撮空理线 | 即刻 | 同上 |
| 斑疹紫黑成片、融合 | 即刻 | 同上 |
| 目窠内陷、皮肤弹性丧失 | 即刻 | 同上 |
| 小儿指纹透关射甲 | 即刻 | 同上 |
| 口眼歪斜、半身不遂新发 | 当班内 | 走卒中流程，不留在门诊观察 |
| 单处异常但无全身征象 | 复诊时 | 记「待察」，下次同部位对比 |

**五条失效模式**，每条都对应一个可检查的记录缺陷：

1. **以单一征象定证**：面赤即判热。面赤如妆、身热反欲盖衣被，是戴阳，方向相反。
2. **四诊不同步**：上午看舌、下午诊脉，两段资料拼成一个证。靠第 1 章第 1 列（采集时间）识别。
3. **只记结论不记所见**：写「面色无华」而不写「面色淡白、唇色淡」，复核者无法判断依据。
4. **被字数重心带走**：舌占 44.4%，于是「望诊」退化成「看舌」，头面、皮肤、排出物常年空白。
5. **以照片代替当场**：白平衡一偏，淡白与苍白就换了位。

## 五、代价与边界

- 教材给的是**描述性词汇**（「两目灵活」「面色荣润」），没有色卡、没有分级。本章把它们排成字段，不等于它们已经可量化；要量化必须外接色卡或图像设备，且需另立采集规范。
- 五色主病是**多对多的映射**：一色主数病，一病见数色。把「青＝寒」当等式用，就会漏掉青亦主痛、主瘀、主惊风。
- 望诊的判据受光线、妆容、设备影响，本章只列了必须记录的条件，没有给「标准光环境」的技术参数——那属于设备与场地规范，不是教材内容。
- 本章不给任何人的面色、舌象下判断；文中所有「主某证」都是教材口径的转述。

## 六、考核项

1. 默写五段路线与每段的部位，漏一段扣一格；说明为什么把舌放在第 4 段而不是第 1 段。
2. 给一句「面色红赤，属热证」，指出它缺哪一维（泽），并写出两种方向相反的补充情形。
3. 判断下列记录哪一条**不成立**：①「灯光下舌红苔黄」；②「小儿哭闹时面红目赤」；③「自然光下、静息十分钟，面色淡白、唇色淡」；④「照片示面色萎黄」。
4. 把「得神」的四项判据写全，并说明缺一项时应该记什么、为什么不能记「得神」。
5. 列出三个必须即刻上报的望诊征象，说明它们共同的特征（提示什么）。
6. 说明「形瘦」为什么必须补「能食／食少」，这两句分别指向什么。

## 教材小节：逐条落位

教材第 2 章共 7 个小节。这一节把它们逐一落位：每个小节一段，说清这一节在问什么、答案落在哪一层、与相邻小节是什么关系。**没有被主题叙述点到的小节，在这里也必须有位置。**

#### 2.1.1 望神

望神看的是「生命活动的整体外在表现」，落点在两目、面色、精神、反应与言语五项。教材给五态：得神、少神、失神、假神、神乱。要点是假神为什么必须单列——它不是「神气较好」，而是重病之人突然转佳的一过性伪信号，与整体病情相反，属「假象」类。这一节因此成为全书第一处「见到好表现先问是不是假」的判据。

#### 2.1.2 望色

先立常色（微黄红润有光泽，有主色与客色之分），再讲病色；病色以「有胃气」（明润含蓄）为善、「无胃气」（晦暗暴露）为凶。分类轴有两条：五色（青赤黄白黑）主病与色泽的善恶。要点是这两条轴不能混用——五色回答「主什么病」，善恶回答「病情向哪边走」，同一个色可以善也可以凶，混了就判不出轻重。

#### 2.1.3 望形体与姿态

形体看强弱：形盛（骨骼粗大、胸廓宽厚、肌肉充实）与形衰（形瘦骨立、皮肤干枯）。教材还给四组组合判断：胖而能食、胖而食少、瘦而能食、瘦而食少，各对应不同的气血状态。姿态看动静与体位。要点是把「形」与「食」配对读——单看胖瘦分不出虚实，配上食欲这一项才能落到证候方向上。

#### 2.2.1 头面五官望诊

按部位逐一给判据：头形与囟门（高凸为实、凹陷为虚）、面肿（阳水与阴水之分）、腮肿、头发（荣枯辨精血）、目（赤红肿属肝火、目黄属黄疸等）、耳、鼻、口唇与齿龈、咽喉。要点是「部位 + 表现」两栏一起记：同一种表现落在不同部位，所属脏腑不同——这就是局部望诊最容易被记混的地方。

#### 2.2.2 躯体四肢与皮肤望诊

按部位推进：颈项（瘿瘤属气滞痰凝、瘰疬属痰火凝结）、胸腹（桶状胸、鸡胸龟背、鼓胀、青筋暴露）、腰背、四肢（肿胀、枯萎、拘急）、皮肤（色泽、形态、斑疹、水疱、疮疡）。要点是每一处都给出「形态 + 病机方向」的固定搭配，读者要能把这份清单还原成一句可复述的判断，而不是背一堆名词。

#### 2.4.1 望排出物

分四类：痰涎、呕吐物、大便、小便，各自按性状给判据（如痰清稀为寒痰、黄稠为热痰、少而黏为燥痰、白滑量多为湿痰）。要点是排出物是「内邪外现」最直接的一路——它不经过体表修饰，所以性状判据比面色之类的间接征象更硬；但也正因如此，教材只给类别对应，不给程度分级。

#### 2.4.2 望小儿指纹

指纹是小儿食指掌侧前缘的浅表络脉，适用于三岁以内。分三关：风关、气关、命关；观察内容包括浮沉、色泽、长短与形状，判读趋势是「由风关向命关延伸则病进」。要点是适用范围写在最前——超过三岁指纹不显，这一诊就失效；这是本课程里少见的「有明确适用边界」的诊法，边界与判据同等重要。
