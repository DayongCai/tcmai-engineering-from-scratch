# 问诊：标题写「十问歌」，实际只列了八节 · 提示词

## 用途

给「问诊：标题写「十问歌」，实际只列了八节」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「采集：三段式加八节，歌诀与节次并表 → 成组判据：每一问都要问成一组 → 记录字段：时间轴与「未问」都要有位置 → 动作与边界：问出来的危险信号」这条链。

## 提示词

```
我在学《中医诊断学》第 5 章「问诊：标题写「十问歌」，实际只列了八节」，本章 6 节 / 3,291 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - （并进既往史）、
   - 四条失效模式
   - 以单一征象定证
   - 只记结论不记所见

4. 本章自陈的边界（不得越过）：
   - 八节与歌诀十问的差集（旧病、病因）是本课程的对表结果，教材并未声明「十问歌只落实了八节」；引用时应写「教材 4.2 列八节」，不要写成「教材承认少两问」。
   - 问诊的效力受患者表达能力、记忆偏差、隐瞒意愿影响，本章只给了提问方式与记录字段，没有给任何信度系数——那需要独立研究，不是教材内容。
   - 本章不涉治法方药，所有「主某证」都是教材 4.2 的口径转述，不作为处方依据。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为问诊采集顺序与记录字段的教学整理，不构成诊断、辨证或治疗建议，不作为诊疗依据。问诊与辨证须由执业中医师完成；具体操作以现行规范与所在机构制度为准。
