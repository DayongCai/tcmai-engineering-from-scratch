# 第 5 章 · 问诊：标题写「十问歌」，实际只列了八节

> **MOTTO:** 「诊病不问其始，忧患饮食之失节，起居之过度，或伤于毒，不先言此，卒持寸口，何病能中」——《素问·征四失论》
>
> **PROBLEM:** 教材·第4章·4.2 挂着「十问歌」的名，实际只有 **8** 个小节：寒热、汗、疼痛、头身胸腹耳目、睡眠、饮食口味、二便、经带与小儿。歌诀十问里的「旧病」与「病因」，在教材里没有独立小节——它们被并进了 4.1.2 的既往史与诱因。于是两种问法各缺一块：照歌诀问会漏节，照小节问会漏「因」。要问全，只能并表。

**双根因定位:** 环境逼迫（问诊几乎占接诊时间的一半，但没人给你一张「问到哪算问全」的清单，问多问少全凭习惯） + 知识积累（4.2 的八节与 4.1 的两节已经清点完，歌诀十问与教材八节的差集也能算出来，足以拼成一张覆盖两者的问诊单）

**本章口径：** 教材·第4章（2,281 字）：4.1 意义方法与一般情况（439 字）、4.2 问现在症（1,842 字）。本章只做问诊的采集顺序、成组判据与记录字段，不涉治法。

## 一、采集：三段式加八节，歌诀与节次并表

问诊的骨架是主诉 → 现病史 → 既往与生活史三段（教材·第4章·4.1.2），血肉是 4.2 的八节。两套并行不悖，但要合并成一张表才不会漏：

| 段 | 内容 | 教材位置 | 必填 |
|---|---|---|---|
| 一般情况 | 姓名、性别、年龄、职业、婚否、籍贯、住址、就诊日期 | 4.1.2 | 是 |
| 主诉 | 最感痛苦的症状／体征 + 持续时间（原话） | 4.1.2 | 是 |
| 现病史 | 起病情况 → 病变经过 → 诊治经过 → 现在症状 | 4.1.2 | 是 |
| 既往史 | 曾患病、与现病可能相关的旧疾 | 4.1.2 | 是 |
| 个人生活史 | 居住、饮食嗜好、烟酒、情志、劳逸、婚育 | 4.1.2 | 是 |
| 家族史 | 直系亲属的遗传病、传染病 | 4.1.2 | 是 |

| 节 | 问什么 | 教材位置 |
|--:|---|---|
| 1 | 寒热：恶寒发热、但寒不热、但热不寒、寒热往来 | 4.2.1 |
| 2 | 汗：表证有汗无汗；里证自汗、盗汗、绝汗、战汗；头汗、半身汗 | 4.2.2 |
| 3 | 疼痛：性质 10 种 × 部位 7 处 | 4.2.3 |
| 4 | 头身胸腹与耳目：头晕、胸闷、胁胀、脘痞、耳鸣耳聋、目痛目痒 | 4.2.4 |
| 5 | 睡眠：不易入睡、睡后易醒、彻夜不眠、嗜睡 | 4.2.5 |
| 6 | 饮食口味：口渴与饮水、食欲食量、口淡口苦口甜口酸口咸 | 4.2.6 |
| 7 | 二便：便次、性状、排便感；尿量、尿次、排尿感 | 4.2.7 |
| 8 | 经带与小儿：期、量、色、质、痛经时点；带下量色质味 | 4.2.8 |

歌诀补的两格，在表外单列：**旧病**（并进既往史）、**病因与诱因**（并进现病史的「起病情况」）。这两格不补，八节就只是八个孤立的问答，串不成一条病程。教材·第4章·4.1.1 对问诊的定义也支持这个读法：「问诊是医生通过对患者或陪诊者进行有目的的询问，以了解病情的方法」——有目的，指的是围着主诉展开，不是把八节平铺一遍。

## 二、成组判据：每一问都要问成一组

问诊最大的浪费是「问了，但只问了一维」。教材给的每一项都是多分节的，问的时候必须成组问完：

| 条目 | 必须问全的维度 | 缺项后果 |
|---|---|---|
| 疼痛 | 部位 · 性质 · 程度 · 时间（昼／夜） · 诱因 · 缓解因素 | 只问「哪疼」，无法分气滞与血瘀 |
| 寒热 | 恶寒与发热的先后、轻重、时间 | 只问「怕冷吗」，分不出表里 |
| 汗 | 有无 · 时点（昼／夜／战栗后） · 部位（全身／头／半身） · 温凉 | 只问「出汗吗」，分不出自汗与盗汗 |
| 口渴 | 渴与不渴 · 喜冷喜热 · 饮多饮少 · 欲咽不咽 | 只问「渴吗」，漏「但欲漱水不欲咽」 |
| 二便 | 次数 · 性状 · 颜色 · 排便感 · 伴随 | 只问「大便正常吗」，正常二字什么都装 |
| 睡眠 | 入睡 · 易醒 · 多梦 · 嗜睡 · 时点 | 只问「睡得好吗」，答「还行」即终止 |

「不成立」条件集中在提问方式上，与内容无关：

| 情形 | 为什么不成立 | 处置 |
|---|---|---|
| 用「是不是」「对不对」提问 | 诱导作答，主诉被改写 | 改开放式提问重问 |
| 把患者用词直接换成术语 | 「胃不舒服」被写成「脘痞」，含义已变 | 原话入记录，术语另列 |
| 只听家属、不问本人 | 自觉症状被转述过滤 | 能问本人必须问本人 |
| 前后矛盾未复核 | 两段病史拼成一个证 | 当场复核，矛盾处标注 |
| 小儿不问家长、不问喂养接种 | 无替代信息源 | 补齐家长陈述 |

## 三、记录字段：时间轴与「未问」都要有位置

| # | 字段 | 取值 | 说明 |
|--:|---|---|---|
| 1 | 主诉原文 | 患者原话 + 持续时间 | 不改写 |
| 2 | 起病 | 时间 + 缓急 + 诱因 | 缓急用「骤起／渐起」 |
| 3 | 演变 | 时间轴：何时加重、何时缓解 | 一行一个节点 |
| 4 | 诊治经过 | 做过什么、反应如何 | 不写具体方药剂量 |
| 5 | 现在症 | 按八节分组记 | 见上表 |
| 6 | 既往史 | 病名 + 时间 | 与现病可能相关者优先 |
| 7 | 生活史 | 饮食、烟酒、情志、劳逸 | 有则必填 |
| 8 | 家族史 | 有／无 + 病名 | 有则必填 |
| 9 | 未问项 | 项名 + 原因 | 不得留空 |
| 10 | 所见／所判 | 两栏 | 同第 1 章 |

第 3 列是问诊独有的：其它三诊是**截面**，问诊是**时间轴**。一条病程如果只记「现症」，等于把演变过程压成一个点，后面判断病势进退就没有依据了。

## 四、动作与边界：问出来的危险信号

| 触发 | 时限 | 动作 |
|---|---|---|
| 胸痛彻背、痛引肩背伴汗出 | 即刻 | 按急症流程处置，不继续门诊问诊 |
| 突发一侧肢体无力、言语不清 | 即刻 | 走卒中流程 |
| 大量呕血、便血、咳血 | 即刻 | 同上 |
| 绝汗（大汗淋漓、汗冷肢厥） | 即刻 | 同上 |
| 持续加重的体重下降伴发热 | 当班内 | 安排进一步检查，记「待查」 |
| 病史前后矛盾且影响判断 | 当场 | 复核并标注，不带矛盾出结论 |

**四条失效模式**：

1. **以单一征象定证**——「怕冷」即判阳虚，不问是否恶寒发热并见（表证）、是否但寒不热（里寒）。
2. **四诊不同步**——问诊在上午、望切在下午，问出来的「现在症」已经不是现在的了。
3. **只记结论不记所见**——写「纳差、乏力、脾虚」，把三个结论当三条所见，复核无从下手。
4. **把「未问」写成「无」**——与闻诊同病。患者说「都正常」，记录写「二便正常」，实际从未逐项问过。

## 五、代价与边界

- 八节与歌诀十问的差集（旧病、病因）是本课程的对表结果，教材并未声明「十问歌只落实了八节」；引用时应写「教材 4.2 列八节」，不要写成「教材承认少两问」。
- 问诊的效力受患者表达能力、记忆偏差、隐瞒意愿影响，本章只给了提问方式与记录字段，没有给任何信度系数——那需要独立研究，不是教材内容。
- 本章不涉治法方药，所有「主某证」都是教材 4.2 的口径转述，不作为处方依据。
- 「必填」是按教学场景设定的最小集；实际病历的必填项以所在机构规范为准。

## 教材小节：逐条落位

教材第 4 章共 10 个小节。这一节把它们逐一落位：每个小节一段，说清这一节在问什么、答案落在哪一层、与相邻小节是什么关系。**没有被主题叙述点到的小节，在这里也必须有位置。**

#### 4.1.1 问诊的意义与方法

意义一句：「问而知之谓之工」，是四诊中获取资料最重要、最全面的手段。方法分注意事项与技巧：环境与态度、避免暗示与诱导、危重抓主症先问后治、对隐瞒者耐心引导再以望闻切核实；技巧是先问主诉、围绕主诉展开、按十问歌顺序逐项问。要点是「避免暗示性提问」这一条，它是问诊与套话的分界。

#### 4.1.2 问一般情况与现病史

三个块：一般情况（姓名性别年龄职业婚否籍贯住址等）、主诉（最感痛苦的症状或体征加持续时间）、现病史（发生、发展、诊疗全过程）。要点是主诉的写法约束——症状加时间，不加诊断、不加推测；这条约束决定了后面病案书写的规范，也决定了主诉能否被复核。主诉不写诊断，是为了让后面的辨证不被前一句结论牵着走——先记录事实，再作推理。

#### 4.2.1 问寒热

十问歌之首。基本组合有四种：恶寒发热并见（表证）、但寒不热（里寒或阳虚）、但热不寒（里热，再按潮热、壮热、低热分层）、寒热往来（半表半里）。要点是这一节给的是「组合判断」而不是单症状判断——单有恶寒不能定表，必须看它是否与发热并见，这是问诊八节共同的读法。

#### 4.2.2 问汗

两条线：表证辨汗之有无（表实无汗、表虚有汗），里证辨汗的形态（自汗、盗汗、绝汗、战汗、黄汗）。要点是「有汗无汗」在表证里是分型的判据，不是程度差别——表实与表虚是两个证，不是同一证的两档。这一条与后面八纲的表里虚实直接接上，是问诊里最典型的二值判据。

#### 4.2.3 问疼痛

按性质分九类：胀痛（气滞）、刺痛（血瘀）、走窜痛（气滞风邪）、冷痛（寒）、灼痛（热）、重痛（湿）、酸痛（湿或肾虚）、隐痛（虚）、绞痛（寒凝气滞）。再按部位分：头痛、胸痛、胁痛、胃脘痛、腹痛、腰痛、四肢痛。要点是性质与部位两栏都要问，只问一处会漏掉「同一性质不同部位」的鉴别。

#### 4.2.4 问头身胸腹与耳目

逐项给判据：头晕（肝阳上亢、痰湿内阻、气血亏虚、肾精不足四类）、胸闷（心气不足、痰浊阻肺）、胁胀（肝气郁结）、脘腹与腰背、耳鸣耳聋（虚实之分）、目（视物昏花、目赤）。要点是本节用「同一症状的四类归属」示范辨证思维：症状只有一个，归属要由伴随表现决定。

#### 4.2.5 问睡眠

失眠按入睡与维持分层：不易入睡（心肾不交）、睡后易醒（心脾两虚）、彻夜不眠（心胆气虚或痰火扰心）、多梦（肝血不足或痰热内扰）。嗜睡分痰湿困脾与饭后困倦等。要点是把「失眠」拆成三个时点，因为不同时点对应不同脏腑——不拆就只能笼统说「心神不宁」，等于没辨。

#### 4.2.6 问饮食口味

口渴与饮水按五种组合分：不渴、渴欲饮、渴喜冷饮、渴喜热饮、渴不欲饮、但欲漱水不欲咽，各对应津伤、里热、寒或痰饮、湿阻或瘀血。食欲与食量按增减与偏嗜分。要点是「但欲漱水不欲咽」被单列——它是瘀血的典型征象，与「渴不欲饮」不同，混在一起就把瘀血读成了湿阻。

#### 4.2.7 问二便

大便看次数、性状、排便感：便溏（脾虚湿盛）、五更泄（脾肾阳虚）、便秘分实热与气虚、里急后重（湿热痢疾）、排便不爽（湿热或肝郁）。小便看量、色、次数与感觉。要点是「排便感」这一栏最易漏——次数与性状正常而排便感异常，仍属病象，漏了这一栏就漏掉一类证。

#### 4.2.8 问经带与小儿

月经按四栏：期（先期热或气虚、后期寒或血虚、先后无定期肝郁或肾虚）、量、色质、痛经（经前胀痛属气滞、经后隐痛属血虚）。带下按量色质味分。小儿问诊另有重点（喂养、发育、预防接种）。要点是妇人问诊单列，因为期量色质四栏是联动的——只问期不问量，判断会落空。
