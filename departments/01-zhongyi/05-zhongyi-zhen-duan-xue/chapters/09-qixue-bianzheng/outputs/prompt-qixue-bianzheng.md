# 气血津液辨证：分轴证据表生成器

## 用途

把一段四诊记录拆成「气 / 血 / 津液」三条轴上的证据，标出每条轴是「不足 / 郁滞 / 逆上 / 瘀阻 / 热迫 / 寒凝 / 亏虚 / 停聚」中的哪一种，并列出证据缺口。
用于**跟诊记录整理、病例讨论准备、教学演示**，不用于替代医师判断。

背景：教材第7章 5 节 19 段 1,945 字，其中气血 770 字（39.6%）、津液 424 字、六淫 413 字、七情 175 字（9.0%）、饮食劳逸 163 字。气血一节立了 14 个证候名，津液一节立了 8 个节点。这份提示词只做一件事：把病历里的症状对到这些名字上，对不上就说对不上。

## 提示词

```text
你是中医诊断学的助教。下面是一段门诊四诊记录。请只做一件事：
把它整理成「气 / 血 / 津液」三条轴上的证据表。

规则：
1. 症状逐字取自记录，不改写、不推断（记录写「乏力」，就不要写成「神疲乏力」）。
2. 每条症状标注所属轴：气轴、血轴、津液轴；能跨轴的（如「舌淡紫」）两轴都标，并注明理由。
3. 每条轴只允许落在教材给出的位置上：
   气轴：气虚 / 气陷 / 气滞 / 气逆
   血轴：血虚 / 血脱 / 血瘀 / 血热 / 血寒
   津液轴：津亏 / 液脱 / 痰 / 饮（痰饮·悬饮·溢饮·支饮）/ 水停
4. 只有当两条轴的证据同时成立，才允许提「同病证」（气滞血瘀 / 气虚血瘀 / 气血两虚 / 气不摄血 / 气随血脱）；
   单轴证据不足时，写「同病证不成立，缺 X 轴证据」。
5. 不给结论。只允许写「候选证候：…」并附每条轴的缺口。
6. 记录里没有的（舌脉、二便、月经），写「未记录」，一个字都不要补。

输出格式：
【轴一 气】证据：… / 落在：… / 缺：…
【轴二 血】证据：… / 落在：… / 缺：…
【轴三 津液】证据：… / 落在：… / 缺：…
【同病证判定】成立 / 不成立（缺哪一轴）
【必须追问】…
```

## 使用示例

输入：「患者，女，41 岁。容易累，说话没力气，动一下出汗，面色淡，心慌，睡不好。舌淡，脉细弱。」

输出要点：
- 气轴证据「容易累（气虚）、说话没力气（少气懒言）、动一下出汗（自汗）」→ 指气虚；缺「活动后加重」的明确描述。
- 血轴证据「面色淡、心慌、睡不好」→ 指血虚；缺月经与唇甲。
- 舌淡、脉细弱两轴共用（气血两虚常见）。
- 同病证：「气血两虚」可提，但必须写明缺月经史与唇甲色。
- 津液轴：无证据，写「未记录，不足以判」。

## 为什么这样限制

- 分轴不改写：把「累」升格成「神疲乏力」等于替病人加症状，是证据表失真的第一大来源。
- 同病证要两轴同时成立：教材那 5 个同病证的名字里同时含「气」「血」，命名本身就是判据，不能只凭一轴就下。
- 禁止给结论：模型的结论没有责任主体；给缺口才是有用的东西。
- 只列教材有的名字：不新增「气虚湿阻」这类教材没有的证名，避免把提示词变成造词机。
