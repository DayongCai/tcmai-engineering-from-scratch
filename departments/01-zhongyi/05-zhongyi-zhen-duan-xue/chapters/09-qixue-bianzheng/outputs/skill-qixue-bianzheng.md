# qixue-bianzheng

## 何时使用

- 跟诊后整理病例，需要一份「这条证据属于哪一轴、依据在哪」的记录
- 病例讨论前，要把零散症状对齐到教材第7章的 14 个气血证与 8 个津液节点
- 教学演示：让学生看清同一个病人为什么会在气轴与血轴上各落一个位置

## 不适用

- 需要下诊断结论时（本技能只出证据表与缺口）
- 需要脏腑定位时（那是脏腑辨证，第8章，不是三轴问题）
- 记录靠含糊转述、无法逐字引用时
- 只有单一症状、没有任何舌脉时（三轴都判不了，只该写「证据不足」）

## 步骤

1. **锁记录**：按句子编号，后续每条症状都要能指回句号。
2. **分三轴**：气轴（气虚/气陷/气滞/气逆）、血轴（血虚/血脱/血瘀/血热/血寒）、津液轴（津亏/液脱/痰/饮/水停）。
3. **逐条落位**：一条症状落一轴；跨轴的（舌淡紫、脉细弱）两轴都标并写理由。
4. **判同病**：只在两轴证据同时成立时才提同病证；否则明写缺哪一轴。
5. **写缺口**：把缺口翻译成下一次问诊要问的具体问题（月经、唇甲、二便、饮水量）。
6. **不越界**：不新增教材没有的证名，不把证候写成诊断。

## 输出模板

```text
【轴一 气】证据：<症状>（第N句）… / 落在：<气虚|气陷|气滞|气逆> / 缺：…
【轴二 血】证据：… / 落在：<血虚|血脱|血瘀|血热|血寒> / 缺：…
【轴三 津液】证据：… / 落在：<津亏|液脱|痰|饮|水停> / 缺：…
【同病证】成立 / 不成立（缺 <轴> 证据）
【必须追问】
1. …
```

## 质量判据

- 每条症状都能在记录第 N 句找到原话（否则是编的）
- 三轴都有明确结论：要么落位，要么写「证据不足」，不许留空
- 提到同病证时，必须同时列出气轴与血轴的证据，缺一条即判不成立
- 缺口清单至少 2 条，且都是下一次问诊能问到的具体问题
- 不出现教材第7章之外的证候名

> 本技能输出为教学材料，不构成诊疗建议；辨证结论须由执业中医师作出。
