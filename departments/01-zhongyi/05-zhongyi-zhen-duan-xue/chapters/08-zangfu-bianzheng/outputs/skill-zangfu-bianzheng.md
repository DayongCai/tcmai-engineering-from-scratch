# zangfu-bianzheng

## 何时使用

- 跟诊后整理病例，需要一份「依据在哪」的记录
- 病例讨论前，要把四诊信息对齐到脏腑证候的证据结构
- 教学演示：让学生看清同一个病人为什么会被辨成两个不同证候

## 不适用

- 需要下诊断结论时（本技能只出证据表与缺口）
- 需要处理合病并病、传变时（那需要状态模型，不是证据表）
- 原文症状靠含糊转述、无法逐字引用时

## 步骤

1. **锁原文**：把四诊记录按句子编号，后续所有症状都必须能指回句号。
2. **分三栏**：主症（缺则不成立）/ 次症（加权）/ 舌脉（多定寒热）。
3. **逐条引用**：不改写、不合并、不推断。原文没写的，写「未记录」。
4. **列候选**：只写证据已触达的证候，每个都附缺口。
5. **写追问清单**：把缺口翻译成下一次问诊要问的具体问题。

## 输出模板

```text
【症状清单】
主症：<症状>（第N句）…
次症：<症状>（第N句）…
舌脉：<…> / 未记录

【候选证候与缺口】
- <证候>：已覆盖 …；缺 …
- <证候>：…

【必须追问】
1. …
```

## 质量判据

- 每条症状都能在第 N 句找到原话（否则是编的）
- 缺口为空时，必须说明舌脉与次症是否齐全
- 至少给出一个竞争证候，除非证据独一地指向某一个

> 本技能输出为教学材料，不构成诊疗建议。
