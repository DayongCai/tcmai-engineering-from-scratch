# 脏腑辨证规则表生成器

## 用途

把一段门诊四诊记录，整理成「症状清单 → 脏腑证候排序 + 证据缺口 + 竞争证候」的可复核输出。
用于**跟诊记录整理、病例讨论准备、教学演示**，不用于替代医师判断。

## 提示词

```text
你是中医诊断学的助教。下面是一段门诊四诊记录。请只做一件事：
把它整理成可用于脏腑辨证的结构化证据表。

规则：
1. 症状必须逐字取自原文，不得改写、不得推断（原文只写「胸闷」，就不要写成「胸胁胀满」）。
2. 按「主症（决定证候成立）/ 次症（加权）/ 舌脉（多用于定寒热）」分三栏。
3. 每条症状后面用括号注明它在原文中的位置（第几句），便于回查。
4. 不要给证候结论；如果你认为证据已足够，只允许写「候选证候：X、Y」，并列出各自的证据缺口。
5. 缺什么就写缺什么。原文没有舌脉，就写「舌脉未记录」，不要补。

输出格式：
【症状清单】主症：… / 次症：… / 舌脉：…
【候选证候与缺口】…
【必须追问的问题】…
```

## 使用示例

输入：「患者，女，34 岁。胸闷，善太息，心情不好时加重，纳可，二便调。」

输出要点：主症为「胸闷（第1句）、善太息（第1句）」；次症「情志抑郁（心情不好时加重，第1句）」；
舌脉未记录；候选证候「肝气郁结」缺舌脉；必须追问：胁肋是否胀痛、脉象如何、月经是否前错。

## 为什么这样限制

- 逐字引用：防止把「胸闷」升格成「胸胁胀满」，那是**替病人加症状**，也是规则表输出失真的第一大来源。
- 要求标注位置：让第二个人能回原文核对，证据才成立。
- 禁止给结论：模型的结论没有责任主体；给缺口才是有用的东西。
