# zhenduan-wucha

## 何时使用

- 要分析「一次辨证错在哪」，需要按来源分类而不是凭感觉归因
- 有人向你要「误诊率 / 准确率 / 一致性」的数字，需要说明教材给不了
- 要核对「假象到底有几个」「脉症从舍有没有操作规则」这类说法

## 数据来源

`standards/zhenduan/底本.json`：教材·第13章（1,307 字）+ 教材·第14章·14.3（462 字）= 1,769 字，占全书 8.0%。

## 硬约束

1. 引用写「教材·第13章·13.1.1」「教材·第14章·14.3.2」。
2. 四条来源必须有节号：13.1.1.2 / 2.1.1.2 + 6.2.2 + 6.3.2 / 5.1.4.1 / 14.3.2。
3. 假象是 **5 个**：假神 + 真寒假热/真热假寒 + 真实假虚/真虚假实；假神属望神，不属八纲真假。
4. 5.1.4.1 只有 108 字，**没有优先级规则**，不许写成算法。
5. 14.3.2 只有 **175 字**，只点了真寒假热、真实假虚两个假象 + 血瘀兼证遗漏。
6. 14.3.2 第二段在教材文本中断在「方可进」，**照原样标注，不补写**。
7. **不得输出任何概率**：全书 0 个百分比数值。
8. 「教材要求报告敏感度/特异度」≠「教材给出数值」，两句必须分开。
9. 四诊字数不是诊断权重（闻诊 855 字 = 3.8%，只说明编写薄、留痕难）。

## 已核事实

| 项 | 值 |
|---|---|
| 正文规模 | 1,769 字 = 8.0%（第13章 1,307 + 14.3 462） |
| 四诊最薄 | 闻诊 855 字 = 3.8%，是望诊的 30.4% |
| 假象 | 5 个（假神 / 真寒·真热 / 真实·真虚） |
| 脉症从舍 | 5.1.4.1，108 字，两判据各一例 |
| AI 误判 | 14.3.2，175 字，3 案例 + 双轨复核 |
| 误差率 | 0 个百分比数值；仅 4 个指标名称无数值 |

## 不适用

- 误差率、误诊率、模型评测指标的任何估计
- 具体病人的诊断、治法、用药建议
