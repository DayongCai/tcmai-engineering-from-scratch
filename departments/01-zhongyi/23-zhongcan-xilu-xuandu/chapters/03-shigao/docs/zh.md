# 第 3 章 · 石膏：被误读的不是剂量，是三个动作

> **MOTTO:** 「夫石膏之质甚重，七八钱不过一大撮耳。」——《医学衷中参西录·二、药物·1．石膏解》
>
> **PROBLEM:** 讲张锡纯的石膏，几乎所有人第一句都是「他敢用到八两」。这句话传了一百年，结果是两头落空：不敢用的人记住了一个吓人的数字，从此绕开石膏；敢用的人记住了数字，照着抓八两、一次煎服，出了事就说「张锡纯之法不灵」。两边都漏掉了原文里真正的操作。他反对的从来不是小剂量，是两件事：把石膏煅了用，和一次把一剂喝完。剂量只是这两个动作之后的自然结果。把结果当方法，等于把药方当药。

**双根因定位:** 环境逼迫（清末药肆习惯把石膏煅过再卖，因为煅过易碎、易煎出、卖相好；一个开业医如果照药肆给的煅石膏开方，用量越大错得越远，他必须在书里把这个默认值推翻）+ 知识积累（读方书的人记住的是「石膏大寒」「石膏用量」，而不是「生用、轧细、多煎、分服」这一串操作条件；条件一丢，同一味药就从「逐热外出」变成「寒凉伤中」）

## 一、他的靶子是「煅」，不是「少」

石膏解开篇先立药性：「其性凉而能散，有透表解肌之力，为清阳明胃腑实热之圣药。」接着立刻转到用法上的第一处分歧：

> 「石膏医者多误认为大寒而煅用之，则宣散之性变为收敛（点豆腐者必煅用，取其能收敛也），以治外感有实热者，竟将其痰火敛住，凝结不散，用至一两即足伤人，是变金丹为鸩毒也。」——《医学衷中参西录·二、药物·1．石膏解》（外源·笈成）
注意这句话里的因果：伤人的不是石膏，是「煅」。而且他给了一个日常类比——点豆腐要用煅石膏，取的就是收敛凝固之性。同一个「收敛」，用来点豆腐是本事，用来治外感实热就是把痰火封在里。这不是抽象的寒热之争，是一句可以当场验证的话。

更麻烦的是误用之后的归因错误，他把这一层也点破了：

> 「迨至误用煅石膏偾事，流俗之见，不知其咎在煅不在石膏，转谓石膏煅用之其猛烈犹足伤人，而不煅者更可知矣。于是一倡百和，遂视用石膏为畏途。」——《医学衷中参西录·二、药物·1．石膏解》（外源·笈成）
于是形成恶性循环：煅石膏出事 → 归罪石膏 → 不敢用 → 偶尔用也只敢七八钱 → 药不胜病 → 无效 → 更不敢用。他在这个循环里插了一刀，用的是「七八钱不过一大撮」这句话：不是嫌剂量小，是指出**在错误的前提下，小剂量只是让失败变得更慢**。

所以这一章的第一个判据是：**谈石膏剂量之前，先确认拿到的是生石膏。** 他还给了鉴别法，今天仍可用：买整块明亮的，自己看着轧细；煎成后「石膏凝结药壶之底，倾之不出者，必系煅石膏，其药汤即断不可服」。这是把不可见的药材质地，转成一个可观察的现象。

## 二、生用的根据：一层该弃的解释，一层该留的操作

他给「生用」找的根据是化学：「石膏之所以善治寒温者，原恃其原质中之硫养轻也。若煅之，其硫养轻皆飞去，所余之钙经煅即变质。」今天知道石膏主要是含水硫酸钙，煅烧后失去结晶水成为熟石膏（半水硫酸钙），「硫养轻」这个成分判断是错的。

但错了解释，不等于操作错了。把这一段拆成两层看：

| 层 | 内容 | 今天的状态 |
|---|---|---|
| 解释层 | 硫养轻飞去、钙变质，故煅者收敛 | 成分判断错误；「煅后收敛」的现象描述与熟石膏的实际性质大体相容，但理由完全不同 |
| 操作层 | 生用内服、不煅、整块自轧细、煎透 | 仍成立；矿物药不轧细确实煎不透 |
| 边界层 | 煅者只可外用（敷金疮出血） | 仍成立，且与现代外用习惯一致 |

他在同一篇里写了自己的外用经验：「愚尝用煅石膏细末，敷金疮出血者甚效。盖多年壁上石灰，善止金疮出血，石膏经煅与石灰相近，益见煅石膏之不可内服也。」外用有效、内服不可，这个分工他讲得很清楚。

这就是读这本书要练的第一种手艺：**当解释和操作捆在一起时，把它们解开，分别判断。** 解释错了，操作可能还对；操作对了，也不能反过来给错解释背书。

## 三、多煎徐服：他自己叫「以小心行其放胆」

第二处被漏掉的操作在煎服法。先看他怎么定剂量：

> 「是以愚用生石膏以治外感实热，轻证亦必至两许；若实热炽盛，又恒重用至四五两，或七八两，或单用，或与他药同用，必煎汤三四茶杯，分四五次徐徐温饮下，热退不必尽剂。」——《医学衷中参西录·二、药物·1．石膏解》（外源·笈成）
一句话里有四个条件：生用、两许到七八两、煎成三四茶杯、分四五次温饮。第四个字「分」最要紧。他给了三条理由：

1. **免病家疑惧。** 一大碗浓药端上来，家属先怕三分；分成几次，心理门槛低。
2. **药力常在上焦、中焦。** 少量频服，药力维持在胃与胸膈，不至于一次冲下。
3. **寒凉不至下侵致滑泻。** 这是生理层面的：一次大量寒凉入胃，肠道蠕动骤增，容易滑泻。

反面案例写得极狠。仙露汤下记一人素吸鸦片，冬月伤寒，烦躁无汗，脉关前洪滑、两尺无力。他开仙露汤，特别嘱咐「徐徐饮下，一次只饮药一口，防其寒凉侵下焦也」。病家不听，「竟顿饮之，遂致滑泻数次，多带冷沫。上焦益觉烦躁，鼻如烟熏，面如火炙」，关前脉比原来大一倍，数至七至，已成戴阳之证。后面用人参、童便、玄参、生地、知母，折腾半夜才救回来。

他的总结只有一句，但分量很重：

> 「审是，则凡药宜作数次服者，慎勿顿服也。盖愚自临证以来，无论内伤、外感，凡遇险证，皆煎一大剂，分多次服下。此以小心行其放胆，乃万全之策，非孤注之一掷也。」——《医学衷中参西录·一、医方·（二十五）治伤寒温病同用方·1．仙露汤》（外源·笈成）
「以小心行其放胆」六个字，是本章的题眼。胆子大的是剂量，心细的是分服。后人只学了前一半。

## 四、剂量不是自变量

把上面的内容压成一张表，可以看到剂量实际上被三个条件牵着走：

| 条件 | 变化 | 剂量随之 |
|---|---|---|
| 生 / 煅 | 煅者内服即伤人 | 煅者无论多少都不可内服 |
| 单用 / 配人参 | 「热实脉虚者」用白虎加人参汤 | 石膏仍重，但加人参托住正气；他明说「以人参佐石膏亦必能退热」 |
| 煎服法 | 三四茶杯、分四五次、热退不必尽剂 | 总量可以大，单次入胃量必须小 |
| 代粳米 | 以生山药代粳米（白虎加人参以山药代粳米汤） | 护胃，使寒凉不至伤中 |

所以「张锡纯用石膏到八两」这句话本身没有信息量——它缺了生煅、缺了配伍、缺了分服、缺了是否代粳米。四个条件补上，八两才是八两；补不上，八两就只是一个数字。

反过来也一样：他并不是一味求大。治产后温病轻证，他「恒重用玄参一两，或至二两」，因为「石膏、玄参，《神农本草经》皆明言其治产乳，至知母条下则未尝言之，不敢师心自用也」。同样是清热，他选玄参不选知母，理由是本草有据。这是一处很有意思的自限：他对剂量的胆量，建立在「本草有明文」的基础上，不是建立在「我用过没事」上。

## 五、他把石膏推到了多远

石膏解是全书写得最长的一篇药解，覆盖的场景远超「外感实热」四个字。下面这些都能在原篇里逐条对到：

- **外感实热**——白虎汤、仙露汤一路，主力场景。
- **产后温病**——「果系产后温病，心中燥热，舌苔黄厚，脉象洪实，寒凉亦在所不忌」，但须以山药代粳米、玄参代知母。
- **痢疾挟热**——「痢证身热不休，服一切清火之药，而热仍不休者」，用通变白虎加人参汤。
- **疟疾兼阳明实热**——大剂白虎汤加柴胡。
- **内伤伏热**——痔疮三十年，因伤寒热入阳明用大剂白虎汤而「痔疮竟由此除根」；幼童每年患眼疾六七次，因瘟疹重用石膏而「从此不再反复」。
- **中毒**——吞砒石，生石膏细末二两凉水送下，再用半斤煮汤。
- **与西药并用**——「石膏之性，又最宜与西药阿斯匹林并用」，理由讲得很实：石膏清热之力大而发表之力轻，阿司匹林「最善达表」，两者「相助为理」。

读这些「意外之效」要注意写法。他自己交代得很清楚：「夫劳疾至年近七旬，本属不治之证，而事出无心，竟以重用石膏治愈之。」「事出无心」四个字是诚实——这些是回顾性的观察，不是设计出来的疗效。把它们当经验线索可以，当疗效证据不行。

另有一篇《论用药以胜病为主不拘分量之多少》，常被拿来给「大剂量」撑腰。但那一篇的性质要看清：他先给论点——「所服之药病当之，非人当之也」，然后举的全是**别人的**案子：明李士材治阳极似阴用生石膏三斤，清江涵暾《笔花医镜》治时疫发斑共用十四斤，吴鞠通治一人每剂用半斤、服至三月。这三例是文献收集，用来证明「药不胜病则不效」这个一般命题；他自己的案子另列在后。把别人的极端剂量当成他的常规，是二次误读。

## 六、代价与边界

- **解释不可引用，操作可以。** 「硫养轻」是错的，「生用、轧细、分服」是对的。教学上必须分开讲，否则学生要么全信要么全弃。
- **大剂量不等于安全。** 石膏毒性低是事实，但「毒性低」不等于「无后果」：大量含钙入胃、长期服用、与某些药物同用，都有需要评估的地方。本书没有这方面的数据，本章也不替它补。
- **「热退不必尽剂」不是「见热就用」。** 他的前提是「外感实热」且脉证相符；表里俱寒、脉虚无力、脾胃素弱而滑泻者，用石膏是另一回事。他自己在产后、痢疾、疟疾各处都加了一层层限定，这些限定比剂量重要。
- **剂量不可照搬。** 原文的两、钱为清末衡制（一斤十六两），与现代克数不是同一个单位体系；本课不做换算，也不建议按字面折克。
- **统计口径。** 本章所引的 176 个医方条目中，含生石膏者 36 条；这是按本仓 `standards/zhongcan-xilu/units.json` 的 534 单元现算的文本统计（药名出现，不等于该方以石膏为君）；它是结构数字，不是疗效数字。

**免责声明：** 本章为文本阅读与用法分析，讨论《医学衷中参西录》石膏条的药性判断、炮制取舍与煎服方法，不构成诊疗或用药建议。石膏为处方药，大剂量使用须由执业医师依据具体病情决定；文中所引剂量属 1909 年原文语境，不可自行照方服用。
