# 脑充血与脑贫血：参西最深的一处，也是证名最先失效的一处

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 西学提供事实，中学提供动力与方向
- 脉 + 症状同时出现
- 卒中与短暂性脑缺血发作的警示信号
- 先有方，后有失败，再补三味
- 第一层，诊断
- 第二层，疗效

## 边界

- **1909 年无法区分脑出血与脑梗死。** 没有影像，床边不能分；而今天的治疗方向相反（缺血可溶栓取栓，出血须止血降压），这是本章最不能跨越的界线。任何「引血下行」的思路在未明确诊断前都是危险的。
- **「脑充血」「脑贫血」不是现行诊断名。** 本章讨论的是这两个概念在 1909 年的构造方式与判断依据，不能写进现代病历。
- **血压读数不可作为诊断依据。** 单次测量受多种因素影响；高血压的诊断须规范测量与多次评估。
- 本章为文本与学术史阅读，讨论「脑充血」「脑贫血」两证的构造、鉴别与方剂分工，不构成诊疗建议。突发头痛、眩晕、口眼歪斜、言语不清、肢体无力者须立即就医。
