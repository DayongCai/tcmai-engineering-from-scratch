# 大气下陷：先有临床，后有名字

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 同一个词在《内经》里有两个所指，取哪一个要看上下文，不能一律
- （一）与寒饮结胸
- （二）与气逆作喘
- （三）与中气下陷
- （四）与气郁
- 开破药后加重，是这个证最好的反证

## 边界

- **证名不可作为诊断结论。** 「大气下陷」是 1909 年的功能性描述，用于组织判据与处方，不能写进现代病历的诊断栏，也不能据此排除器质性疾病。
- **经典依据是重构，不是原文。** 他取《灵枢·五色》「大气入于脏腑者，不病而卒死」来证成「下陷」，这一步是推理而非训诂，读者应知道其性质。本章因此只引他的原话，不代他宣称《内经》本有此义。
- **升麻、柴胡、桔梗有明确禁忌。** 他在吐衄章里反复交代这类升提药「最忌」，只在确知宗气下陷时才用，且「四十余年，仅遇赵姓一人」。把它当成常规补气方，方向就错了。
- 本章为文本与学术史阅读，讨论「大气下陷」这一证名的形成过程、鉴别判据与方剂结构，不构成诊疗建议。文中所引方药与剂量属 1909 年原文语境，现代临床使用须由执业医师依现行规范判断。
