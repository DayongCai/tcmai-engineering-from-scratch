# 第 7 章 · 吐衄不是三条路，是一个主轴加四个岔口

> **MOTTO:** 「无论其证之或虚或实，或凉或热，治之者，皆当以降胃之品为主。」——《医学衷中参西录·三、医论·67．论吐血衄血之原因及治法》
>
> **PROBLEM:** 「寒降、温降、清降是三条路」这句话，把这一章讲成了三选一。原文《论吐血衄血之原因及治法》里列的是七个方，而且开宗明义只有一句话：不管虚实寒热，都要以降胃为主。也就是说，主轴只有一个，「三」是后人把七个方归并出来的结果——归并的过程丢掉了一件事：他后来发现「因热」不是一个原因，而是三个（胃热、肝火、冲气）。三方版本与七方版本的差别，不是方多寡，是分岔的维度不一样。

**双根因定位:** 环境逼迫（大吐血、衄血不止在 1909 年是床边急症，没有内镜、没有介入、没有输血；能用的只有口服药与少量外治法，因此每一张方都必须在「一剂下去能不能止」这个尺度上成立，方与方之间的差别被迫做得极细）+ 知识积累（教材按方名归类，寒降对温降，整齐好看；但方名记的是药性，不是病因，一旦按药性分类，肝火与冲气这两个岔口就被压进了「热」里面，临床上一遇到「脉弦长有力但不是胃热」的病人就无从下手）

## 一、主轴：为什么所有方都重用赭石

这一章的起点不是方，是一句生理判断：

> 「盖胃腑以熟腐水谷，传送饮食为职，其中气化，原以息息下行为顺。乃有时不下行而上逆，胃中之血亦恒随之上逆。其上逆之极，可将胃壁之膜排挤破裂，而成呕血之证；或循阳明之经络上行，而成衄血之证。」——《医学衷中参西录·三、医论·67．论吐血衄血之原因及治法》（外源·笈成）
这段话里有三个环节，每一环都能单独检查：胃气本以下行为顺 → 上逆则血随气升 → 上逆之极可使胃壁之膜破裂。第三个环节是他自己的推想（没有解剖依据），前两个是《内经》的旧说。

但结论很清楚：**出血的部位在上，动力在逆，所以治法是降，不是止。** 他把《金匮》泻心汤的道理讲了一遍来支持这一点：大黄直入阳明以降逆上之热，黄芩清肺金使清肃之气下行以助胃降，黄连清心火使元阳潜伏以保少阴真液，「是泻之实所以补之也」。

七方共用赭石，用量从六钱到一两，理由在《论胃气不降治法》里已经给全了（见第 4 章六条特长）。用在血证上，最关键的是第六条：**「性非寒凉开破，分毫不伤气分」**。一个正在失血的人，气分本来就虚，用寒凉药强行止血会伤中，用破气药会耗气，只有一味「降而不伤」的药才能既止血又不添新病。

## 二、七个方，六个岔口

把七方的主治原文排成一张表，分岔的逻辑就出来了：

| 方 | 主治原文（节） | 岔口 | 判断依据 |
|---|---|---|---|
| 平胃寒降汤 | 「脉象洪滑重按甚实」 | 胃热 | 脉洪滑 + 重按实 |
| 健胃温降汤 | 「脉象虚濡迟弱，饮食停滞胃口，不能下行」 | 胃凉 | 脉虚濡迟弱 |
| 泻肝降胃汤 | 「左脉弦长有力，或肋下胀满作疼，或频作呃逆」 | 肝火 | **左脉**弦长 + 胁胀 + 呃逆 |
| 镇冲降胃汤 | 「右脉弦长有力，时觉有气起在下焦，上冲胃腑」 | 冲气 | **右脉**弦长 + 气自下焦上冲 |
| 滋阴清降汤 | 「失血过多，阴分亏损，不能潜阳而作热」 | 阴虚 | 失血多 + 虚热 |
| 保元清降汤 | 「血脱气亦随脱，言语若不接续，动则作喘」 | 气随血脱 | 言语不接续 |
| 保元寒降汤 | 同上，「喘促咳逆，心中烦热，其脉上盛下虚」 | 气随血脱兼热 | 上盛下虚 |

六个岔口，不是两个。而四个「实」的岔口，靠的是**脉的左右分部**加体感定位：

- 左脉弦长有力、胁下胀满、频频呃逆 → 肝火。左候肝，胁是肝的部位。
- 右脉弦长有力、自觉有气自下焦上冲 → 冲气。他的解释是「冲气上冲之由，恒与肝气有关系」，所以镇冲方里用龙骨、牡蛎「不但取其能敛冲，且又能镇肝」。
- 脉洪滑重按甚实、无左右之分 → 胃热。
- 脉虚濡迟弱、饮食停滞 → 胃凉。

这四条里，前两条最容易混。都是弦长有力，都是气逆，都用赭石，但一个加芍药、石决明、龙胆草、青黛（泻肝），一个加山药、龙骨、牡蛎（镇冲）。**混用的后果不是无效，是反效**——泻肝药多寒凉，用在冲气上冲而中气不足的人身上，冲气未必降，胃先受不了。

## 三、为什么「三」这个说法会出现

两处文本可以对照。医方篇（七）治吐衄方共十一首：寒降汤、温降汤、清降汤、保元寒降汤、保元清降汤、秘红丹、二鲜饮、三鲜饮、化血丹、补络补管汤、化瘀理膈丹。医论 67 列七方：平胃寒降汤、健胃温降汤、泻肝降胃汤、镇冲降胃汤、滋阴清降汤、保元清降汤、保元寒降汤。

同一个作者，两处编排不同。差别在哪：

- 寒降汤 → 拆成平胃寒降汤（胃热）与泻肝降胃汤（肝火）、镇冲降胃汤（冲气）。方名从「寒」改成「平胃」，从药性命名改成病位命名。
- 温降汤 → 改名健胃温降汤，分量略调。
- 清降汤 → 改名滋阴清降汤，并明说「此方即清降汤，加龙骨、牡蛎、地黄、三七也」。

这个改写本身就是知识增量。**早期他按药性分（寒、温、清），后来按病因分（胃热、胃凉、肝火、冲气、阴虚、气脱）。** 教材停在早期版本，把三个药性名当成三条路，恰好错过了他修正自己的那一步。

所以本章的建议是：读这一章先读医论的七方，再回头看医方的十一方。七方是整理后的骨架，十一方是方剂的细节与加减（秘红丹的肉桂与大黄同用、二鲜饮的藕与茅根、补络补管汤的龙骨牡蛎萸肉三七），两者互补而不重复。

## 四、两条禁忌比七个方更重要

**第一条：忌用凉药与炭药强止。**

> 「吐衄之证，忌重用凉药及药炭强止其血。因吐衄之时，血不归经，遽止以凉药及药炭，则经络瘀塞，血止之后，转成血痹虚劳之证。是以方中加生地黄一两，即加三七之善止血兼善化瘀血者以辅之也。」——《医学衷中参西录·三、医论·67．论吐血衄血之原因及治法》（外源·笈成）
这条与第 6 章直接接上：血止住了但瘀在经络，下一步就是虚劳。所以他的方里几乎都有三七——止血兼化瘀，血止而瘀不存。他对十灰散的评价也在这里：「以药炭止血，原为吐衄者所甚忌，犹幸其杂有大黄炭……为差强人意耳。」

**第二条：忌升提，但留一个极窄的例外。**

> 「吐衄证最忌黄耆、升、柴、桔梗诸药，恐其能助气上升血亦随之上升也。若确知病系宗气下陷，可以放胆用之，然必佐以龙骨、牡蛎，以固血之本源，始无血随气升之虞也。」——《医学衷中参西录·三、医论·67．论吐血衄血之原因及治法》（外源·笈成）
然后是那句分量极重的话：「吐衄证之因宗气下陷者极少，愚临证四十余年，仅遇赵姓一人，再四斟酌，投以升陷汤加龙骨、牡蛎治愈，然此方实不可轻试也。」

四十年，一例。他把这个例外写进书里，同时标出「不可轻试」。这是把概率当成知识的一部分——比只写「可用」或只写「禁用」都难。

## 五、一个反例：柴胡二钱

医论 67 末尾记了一案，值得整段读，因为它同时演示了辨证、急救与善后：

> 「近津沽有张姓，年过三旬，患吐血证，医者方中有柴胡二钱，服后遂大吐不止。仓猝迎愚诊视，其脉弦长有力，心中发热，知系胃气因热不降也。所携药囊中，有生赭石细末约两余，俾急用水送服强半。候约十二分钟，觉心中和平，又送服其余，其吐顿止。继用平胃寒降汤调之，全愈。」——《医学衷中参西录·三、医论·67．论吐血衄血之原因及治法》（外源·笈成）
三个动作，三种时间尺度：

1. **辨证**——脉弦长有力 + 心中发热 → 胃热。注意这里没有用左右分部，因为「心中发热」已经把热的位置说清了。
2. **急救**——随身药囊里的赭石细末，先服大半，等十二分钟，观察「心中和平」再服余下。这是分服原则（第 3 章）在急症上的应用：不是一次灌完，是看着反应给药。
3. **善后**——吐止之后用平胃寒降汤，把病因清掉，不是止了就走。

他的总结：「同一吐血证也，有时用柴胡而愈，有时用柴胡几至误人性命，审证时岂可不细心哉。」这句话的锋芒指向的不是柴胡，是「按症状套药」的习惯——柴胡能升，升在气陷的人是救命的，升在气逆的人是催命的，药没变，方向变了。

## 六、代价与边界

- **吐衄是急症。** 大量呕血、咯血在现代医学里是急诊情形，内镜、介入、输血、手术是主力手段；本章讨论的是 1909 年的口服方案与其判断逻辑，不能作为眼下的处置依据。出现大量出血应立即呼叫急救。
- **「忌炭药」要分场景。** 他反对的是「以药炭强行止住而不化瘀」这一思路，指向的是血止后成瘀的后果；这与现代局部止血材料、内镜下止血不是同一件事，不可简单比附。
- **「倒经」先查器质病。** 他治妇女经期吐衄用四物汤去川芎加牛膝、赭石，这是当时的思路；今天遇到经期咯血、鼻衄，首先要排除子宫内膜异位症等器质性疾病。
- **七方与十一方的数目要对上版本。** 本章所引「治吐衄方十一首」指医方篇（七）的十一个单元，「七方」指医论 67 所列，二者不矛盾，但引用时必须说明是哪一个版本，否则会被当成前后不一致。
- **剂量不换算。** 原文两、钱为清末衡制，本课不做克数折算；三七、赭石的冲服法（研细末送服）与其汤剂用法不同，不可互换。

**免责声明：** 本章为文本阅读与方证结构分析，讨论吐衄证的降胃主轴、六类岔口与两条禁忌，不构成诊疗建议。吐血、咯血、衄血不止属急症，须立即就医；文中所引方药与剂量属 1909 年原文语境，不可自行照服。
