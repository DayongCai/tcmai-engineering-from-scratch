## 边界

- 只代表一部书，不代表 1840–1949 全部医家；
- 「参西」是 1909 年的解释层（化合、脑筋、血管），不替代辨证，也不当病理学结论引用；
- 剂量是清末衡制，本课不做克数换算；
- 医案为作者自报，无对照随访，只能作判断过程读。
