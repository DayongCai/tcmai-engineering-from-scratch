# 一百三十三段禁忌不是清单，是一张「禁什么—中了什么症—用什么解」的三栏表 · 提示词

## 用途

给「一百三十三段禁忌不是清单，是一张「禁什么—中了什么症—用什么解」的三栏表」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「规模与来源：1 条 · 0 方 · 2357 字 → 段级核对表 → 判据分层：附篇只有「三栏」，没有判据层 → 读法与引用动作」这条链。

## 提示词

```
我在学《金匮要略》第 23 章「一百三十三段禁忌不是清单，是一张「禁什么—中了什么症—用什么解」的三栏表」，本章 7 节 / 4,891 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 表 1 · 三个层次上的计量单位
   - 两个本子的收文并不相同
   - 凡引附篇，先说清用的是哪一本
   - 出方条 0、无方条 1、方条比 0.00
   - 方名在正文里，方表是空的
   - 把它读成「本篇没有方」，就会连带把 20 首解毒方一起丢掉
4. 本章自陈的边界（不得越过）：
   - **1 条是存储单位，133 段是行文单位，20 首方是内容单位。** 三者不可互换，也不该相等。
   - **两本字数差 511 字**，是三篇附篇里最大的一处；引用须注明本子。
   - **三栏相加 134 ≠ 133**，因为有 1 段被两栏各数一次；这是「可重叠不相加」的具体含义。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```
