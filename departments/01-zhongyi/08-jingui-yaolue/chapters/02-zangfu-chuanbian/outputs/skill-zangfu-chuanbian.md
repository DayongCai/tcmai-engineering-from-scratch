# zangfu-chuanbian

## 何时使用

- 要判「先治什么、后治什么」：表里同病、痼疾加卒病、脏病欲攻
- 要判「该不该提前补」：见肝之病当先实脾的三个出口（实脾 / 勿补 / 不补）
- 要查望闻判据：面部五色、语声、呼吸的定位与预后
- 要核「三因」「五邪」这类分类主张是否跨轴

## 数据来源

`standards/jingui/底本.json` 篇 1（外源·笈成·金匮要略方论 第1篇·第1–17条）；
复算：`node code/main.js`；断言：`node --test code/main.test.js`（19 项）。

## 硬约束

1. 引文一律取 `zhHans` 栏逐字；本技能配套代码用 `quoted(tiao, phrase)` 在运行时回源比对（47 处）。
2. 传变链只明说「肝→脾」一条，其余四条由 1.1 后半段逐句抽出、按五行相克成环——引用时说「推演」，不说「原文附图」。
3. 本篇方数按「有方文的方」计，为 0；1.17 的猪苓汤是规则举例，不是本篇方证。
4. 三因（3 类）与五邪（5 名 / 5 法度）是两套轴，同名 0，不得互相翻译。
5. 「急则治标、缓则治本」是后世概括，不是原文用语；1.14 先救里而里属本，正是它的反例。
6. 1.14 与 1.15 在「痼疾+卒病+里急」并见时撞车，原文无判据，标「未定」。

## 用法

```js
const { chuanbian, zhiweibing, sanyin, classifyCause, wuxie, lookup, order, suode, verifyQuotes } = require('./code/main.js');

chuanbian().chain                 // ['肝','脾','肾','心','肺']
zhiweibing({ zang: '肝', xu: true, season: '四季' }).act   // '勿补'
sanyin().n                        // 3
classifyCause('风')               // null —— 风不在三因轴上
wuxie().paired                    // 0
lookup('不治').length             // 3
order(['痼疾', '卒病']).map(s => s.what)                   // ['卒病','痼疾']
suode({ kind: '在脏' }).tiao       // '1.17'
verifyQuotes().bad                // []
```

## 不适用

- 具体方证、剂量、煎服法（本篇 0 方）
- 校勘（外源非校本；1.3 异文存于源数据 `notes`）
- 把克序当传变预测算法：真实传变有乘侮、直中、伏气
- 依据本技能处方：判据与次序不等于诊断与用药
