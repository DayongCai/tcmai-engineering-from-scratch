# nueb-zhongfeng

## 何时使用

- 要判一条疟病条文属于哪一型，或核「瘅疟 vs 温疟」的分界
- 要统计第 4 篇的节律词（一日发／十五日／当月尽解／未发前／临发时等）
- 要判中风条文的病位层（在络／在经／入腑／入脏），或核「中经络／中脏腑」这类二分说法
- 要判历节条文的成因、方证分界，或核「第 5 篇有几个方」

## 数据来源

`standards/jingui/底本.json`（外源·笈成，sha256 见该目录 README）；
复算：`node code/main.js`；单测：`node --test code/main.test.js`。

## 硬约束

1. 只认原文点名的名号：疟母／瘅疟／温疟／牝疟。4.1 是脉法总纲，**不归型**。
2. 归型只看主文（第一条空行之前），**不看方后注**——4.5 方后注有「温疟加蜀漆半分」，看整条会把牝疟误判成温疟。
3. 方只计 `formulas[]` 非空者：第 5 篇 10 条只有 2 方；侯氏黑散、风引汤、防己地黄汤、头风摩散、矾石汤及附方段诸方不入方数。
4. 四层是病位深度，不是轻重分级；原文未给预后排序，也不等于后世「中经络／中脏腑」二分。
5. 中风／历节的分界（5.1–5.3 / 5.4–5.10）是按文义切的，原文无小标题，须标注为本章归纳。
6. 「间日」在本篇 0 次出现，不得写成本篇分类。

## 判据速查

| 型／层 | 判据原文 |
|---|---|
| 疟母 | 久疟不差，结为症瘕（以月计病程） |
| 瘅疟 | 阴气孤绝、阳气独发；但热不寒，消铄脱肉 |
| 温疟 | 脉如平，身无寒但热，骨节疼烦，时呕 |
| 牝疟 | 疟多寒 |
| 在络 | 肌肤不仁 |
| 在经 | 即重不胜 |
| 入腑 | 即不识人 |
| 入脏 | 舌即难言，口吐涎 |

## 不适用

- 处方、剂量、煎服法（乌头汤含川乌且用蜜煎）
- 疗效判断与预后推定
- 校勘（外源非校本）
