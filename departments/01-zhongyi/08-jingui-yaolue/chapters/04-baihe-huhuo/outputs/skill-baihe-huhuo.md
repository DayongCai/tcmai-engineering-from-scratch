# baihe-huhuo

## 何时使用

- 要把一段证候描述归到 百合病 / 狐惑 / 阴阳毒 之一，并说明排除路径
- 讲稿或教材里出现「三病都是神志病」「咽喉痛就是阴阳毒」这类把共有症当鉴别点的说法
- 要核「本篇多少条、多少方、方条比为什么是全书第二（0.80，第一是篇 9 的 1.00）」
- 要判断某个古代病名能被映射到什么程度（而不是能不能映射）

## 数据来源

`standards/jingui/底本.json` 篇 `no: 3`（外源·笈成，sha256 见 `standards/jingui/README.md`）。
单条核字：`python scripts/build_jingui_text.py --tiao 3.1`；
复算：`node code/main.js`；断言：`node --test code/main.test.js`。

## 硬约束

1. 归类按**段界**（3.1–3.9 / 3.10–3.13 / 3.14–3.15），不按关键字。第 11、12、13 条条文里没有「狐惑」二字，关键字法会漏。
2. 引文必须逐字取自 `zhHans`；条号写「第3篇·第M条」，不得写「宋本第 N 条」或「底本」。
3. 「12 方」= 有方文者。第 15 条的升麻鳖甲汤去雄黄、蜀椒是提名无方文，单列不并入；若并入则本篇 13 方、方条比 0.87。**报数必须带口径。**
4. 鉴别只用**字面可判定**的词（蚀于阴／斑斑如锦纹／目不得闭／身痛如被杖…）。「湿热」「气阴两虚」不得作为矩阵依据。
5. 共有症不得当判据用。见下方「已核事实」表。

## 归类流程

1. 前后阴蚀烂 → 狐惑，停。
2. 发斑 / 面青 / 身痛如被杖 / 唾脓血 → 阴阳毒；再用面赤斑斑（阳）vs 面目青（阴）定阴阳。
3. 目不得闭 → 狐惑（成脓看目赤如鸠眼、目四眦黑）。
4. 只剩神志 + 饮食 + 假寒热 + 口苦尿赤 → 百合病（须见「欲……不能……」句式）。
5. 只有共有症 → 输出「证据不足」，点名缺哪一项独占点。

## 不适用

- 方证判断、处方、剂量、煎服法
- 雄黄加热的安全边界（砷化物）——须回原文与药典
- 把古代病名直接等同于某个现代诊断
