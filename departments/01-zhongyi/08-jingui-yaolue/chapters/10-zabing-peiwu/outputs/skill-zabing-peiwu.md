# zabing-peiwu

## 何时使用

- 要报「金匮某味药用了几方 / 哪些药对最常见 / 方子平均几味药」这类数字
- 教材或讲稿出现「经方多在 2–15 味」「君臣佐使分明」「甘草为君」这类说法，需要核口径
- 要在别的数据集上复用本章的清洗规则与统计管线（`code/main.js` 的 `cleanHerb` / `herbPairs` / `junProxy`）

## 数据来源

`standards/jingui/底本.json`（外源·笈成·金匱要略方論，sha256 见该目录 README）；
复算：`node code/main.js`；断言：`node --test code/main.test.js`。

## 硬约束

1. **分母是 165，不是 174。** 174 = 165 有方文 + 9 互见方（`refOnly: true`，药味为空）。空药味会拉低平均药味、稀释药对共现、虚增「不可判」。174 也不是「全书方数」——条文提名的方未立项。
2. **药名先清洗再统计。** 原样去重 165 味，清洗后 154 味；728 次出现不变。不清洗会把「甘草」「甘草如指大」算成两味药，排名随之失真（附子 16→18、枳实 12→13、甘草 67→68、半夏 29→30）。
3. **清洗只合并写法，不做异名归并。** 薯蓣/山药、黄耆/黄芪、蜀椒/川椒、牡丹/牡丹皮、栝蒌根/栝蒌实仍分列。
4. **只剥尾不剥头。** 剥首字会把干姜并入姜、干地黄并入地黄。剂量串剥空必须回退（否则「百合」被「百 + 合」吃掉）。
5. **君臣佐使只能给代理指标。** 金匮 402 条无一处标注；本章代理 = 方内同族剂量最大者，覆盖率 45/165 = 27.3%。引用必写「按剂量代理」。
6. **剂量三族不可通约。** 重量（两/斤/分/铢）、容量（升/合/斗）、计数（枚/个）族内归一，族间不折算——不发明「一升≈十两」。
7. **错位方退出规模与君臣分析（v1 历史，v2 已归零）。** v1 有 3 方药名格错位（橘皮竹茹汤、越婢加术汤、百合洗方），规模只能算 154 = 157 − 3；v2 拆列后橘皮竹茹汤归位六味、越婢加术汤改判互见方，错位判定 0 方，165 方全量可判。残留：百合洗方 的煎法句被拆成 7 个短格，仍被当成 7 味计入 728，且无「右N味」自述、不进自校验。

## 复用要点

- `selfCountCheck()` 是这套管线的看门狗：拿原文「右N味」反查解析器，解析错时它会自己叫（v1 曾 129/139，v2 底本拆列后 148/148）。
- `herbPairs(min)` 的计数单位是「方」，一方内两味药各多次只算一次共现；门槛建议取 5%（165 → 8 方）。
- `junProxy()` 输出五种状态（unique / tie / equal / mixed / noDose），**状态分布本身就是结论**，别只报可判部分。

## 不适用

- 方证判断、处方、剂量安全（本章只做文本统计）
- 把「君臣佐使」当原书字段引用
- 用未清洗的 165 味下排名结论
- 拿 22 方妇人篇的百分比当结论（4 方 = 18 个百分点）
