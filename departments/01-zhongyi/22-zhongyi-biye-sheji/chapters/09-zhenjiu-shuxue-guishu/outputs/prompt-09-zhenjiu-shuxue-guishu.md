# 一案八件

## 用途

把「腧穴多经归属冲突表——ISO 针灸标准的落地校验」做成可复跑、可验算、假设可披露的一次毕设。只写能被第三人复核的项，并标明哪些是假设。

**命题：** 同一个穴名在几部教材里归经不一致的有多少？冲突能否收敛到一张表？

## 步骤

### 1. 写命题

同一个穴名在几部教材里归经不一致的有多少？冲突能否收敛到一张表？

### 2. 锚数据

无现成数据；可用口径＝每穴一行（穴名／归经／出处），冲突＝同穴多经

### 3. 做方法

① 建穴-经表；② 按穴名分组；③ 输出多经穴清单与出处

### 4. 做评价

基线＝单教材（无冲突）；消融＝多教材合并；失效＝同名异穴被合并

### 5. 定客户数

SAM 200 × 中位渗透 8.0% → 采用 16

### 6. 验客单

无营收锚：仅作内部一致性检查（同类案例客单差异不超过 5 倍）

### 7. 算预算

建设 ¥87,400／获客 ¥3,000／回本 45.2 月

### 8. 判渠道

不做：个人无使用场景

### 9. 写缺口

多教材文本未入库，本案例第一步是补源，不是计算

## 判据速查

| 项 | 本章要求 |
|---|---|
| 案例类型 | 方法层 |
| 数据规模 | 无现成数据；可用口径＝每穴一行（穴名／归经／出处），冲突＝同穴多经 |
| 客群 / SAM | 药企与器械 / 200 |
| 客户数（采用） | 16（隐含渗透 8.0%）|
| 客单 / 回本 | ¥24,000 / 45.2 月 |

## 输出

命题三件式 + 数据锚点 + 基线／消融／失效 + B 端四件 + 客户数与客单判据 + C 端判定 + 合并账 + 缺口。

## 边界

- 缺口须原样写进开题：多教材文本未入库，本案例第一步是补源，不是计算；
- 客户数须写成 SAM×渗透率，不得直接拍数；客单须给营收／IT 预算占比；
- 工时三段为「假设·未实测」，不得去标签；
