# 第 9 章 · 补源之前，冲突率只能是零比零

> **MOTTO:** 「必通十二经络之所终始」——《灵枢·本输》
>
> **PROBLEM:** 本章可现算的底数只有两个：已入库的多教材文本 0 部、可建穴-经行数 0 行。冲突判定的最小结构是一穴一行、每部教材一列，所以在补源完成前，冲突率的分母就是 0。任何写出来的百分比都是拿 0 除以 0 得来的假数——这是本案例最常见的伪结果。
>
> **双根因定位:** 环境逼迫（针灸器械、教学设备与标准落地都要求穴名与归经能对上）+ 知识积累（知识树 schema 与词表工具已在库，缺的只是多教材文本这一层）

## 一、命题与数据锚点：先承认没有数据

本章的命题是：**同一个穴名在几部教材里归经不一致的有多少，冲突能否收敛到一张表**。这句话的后半句才是工作量所在——不一致本身不稀奇，能把不一致做成一张可核的表，才叫交付。

现状必须写在最前面：

| 项 | 状态 | 数 |
|---|---|---|
| 多教材文本入库 | 未完成 | 0 部 |
| 穴-经表 | 未建 | 0 行 |
| 冲突清单 | 未建 | 0 条 |
| 知识树 schema | 已入库 | 可用 |
| 可算的冲突率 | 分母为 0 | 不可算 |

把「不可算」写成「0%」是这一章最容易犯的错。0% 读起来像「没有冲突」，实际意思是「没查过」。评审看到 0%，会以为工作已经做完；看到 0/0，才知道这是待办。两种写法差一个词，结论差一个阶段。

为什么会有归经冲突？常见的有三类：**同名异穴**（两个不同位置的穴共用一名，归经自然不同）、**归经分歧**（同一穴在不同教材里归到不同经）、**口径差异**（有的书按经脉归，有的按部位归）。三类的处置不同：同名异穴要先拆，归经分歧要并列，口径差异要在表里标出，不能混成一句「存在冲突」。

所以本章的产出不是一个比例，而是**一张能容纳分歧的表**。表的价值在于：每一行都有出处，每一条冲突都能被第二个人复核。比例要等表建起来之后才算，而且算出来也只是「这批教材之间的冲突」，不是「针灸学界的冲突」。

还有一层现实约束：本章的可算范围取决于能拿到几部教材。一部书只有一种归经，冲突率必然是 0——不是因为没有冲突，而是因为没有第二个说法。所以补源数量直接决定这一章有没有内容：两部书能判「分歧」，三部书才能判「哪一种说法是少数」。开题时若只能拿到一部，应改做「穴名规范化」而不是「冲突表」，这是命题层面的调整，不是执行层面的凑合。

这也是为什么本章把「补源」写进标题。毕设里有一类题目，数据不在学生手里，需要去要、去借、去核对；这类题目的正确写法是先交付补源过程，再交付分析结果。把补源过程写成附录，比硬凑一个百分比诚实得多，也更容易被评委接受。

## 二、分阶段交付物与分工

| 节点 | 时点 | 必交物 | 责任人 | 签收人 |
|---|---|---|---|---|
| 开题 | 第 1–4 周 | 补源清单（书目、版本、获取方式）、穴-经表字段、冲突判定规则 | 学生 | 开题小组 |
| 中期 | 第 8 周 | 至少一部教材的穴-经表 v1、出处列、冲突初判 | 学生 | 导师 |
| 预答辩 | 第 12 周 | 多教材合并表、冲突清单、未覆盖穴清单 | 学生 | 预答辩组 |
| 答辩 | 第 16 周 | 穴-经表、冲突清单、出处列、复跑记录 | 学生 | 答辩委员会 |

开题的关键是**补源清单**，不是表结构。清单要写清每部教材的书名、版本、获取方式与可切分程度；写不出获取方式的，就等于没有这部书。往届常犯的错是先设计一张漂亮的表，到中期才发现只有一部书能入库，表空着。

补源还有一条硬规矩：**先登记来源，再落条文**。登记至少三项：书名版本、来源渠道、文件校验值。校验值的作用不是防伪，是防「同一部书两个版本混着用」——同一穴名在两版里归经不同，若不登记版本，冲突会被误判成学术分歧，实际是版本差异。

分工上，书目与版本由导师确认，切分与建表由学生做，校验值由教学秘书登记。三方各管一段，答辩时谁都能说清自己签的是哪一步。若只有学生一人，至少要让导师在补源清单上签一次字，避免中期换书。

中期只要求一部教材建成表，看起来少，实际是刻意的：一部书的表能把字段、出处、冲突判定全部跑通，第二部书只是重复。反过来，一开始就并行三部，字段还没定，三张表口径不一，合并时等于重做。

预答辩要交的是**合并表与冲突清单**，不是叙述。合并表按穴名分组，组内每部书一行；冲突清单只列组内有分歧的穴。两张表的关系要说清：合并表是全集，冲突清单是子集，子集的每一条都能在全集里找到对应行。这个关系说不清，读者就无法判断冲突清单是否漏项。

答辩阶段的复现包四件照旧，但本章的「数据」这一件比较特殊：它包含教材文本本身。教材有版权，不能整本随包交付，处置办法是交付**字段化的穴-经表与校验值**，不交付原文；他人复跑时用同版本书自行重建。这一条要写在 README 第一段，避免被误认为资料不全。

## 三、判据与评分维度【教学设定】

方法层判据四条：

| 判据 | 合格线 | 检查方式 |
|---|---|---|
| 行可数 | 穴-经表行数可打印 | 跑一次看输出 |
| 出处可查 | 每行有书与版本 | 抽三行回查 |
| 冲突可判 | 冲突类型有标签 | 清单有列 |
| 零不伪装 | 未建部分写「未建」不写 0% | 全文检索「0%」 |

评分维度（教学设定）：

| 维度 | 权重 | 不合格 | 合格 | 优秀 |
|---|--:|---|---|---|
| 命题可判 | 15% | 只说「整理归经」 | 有冲突判定规则 | 预写冲突类型 |
| 补源可核 | 25% | 书目说不清 | 一部书已入库 | 版本与校验值齐 |
| 表可复跑 | 20% | 表是手填的 | 脚本可重建 | 换书可扩 |
| 评价完整 | 20% | 无冲突清单 | 冲突有标签 | 三类冲突分开报 |
| 边界与移交 | 20% | 不写未覆盖 | 写未覆盖清单 | 附复跑记录 |

「零不伪装」这一条要单独说。它不是一个技术判据，是一个写作纪律：凡是分母为 0 的地方，一律写「未建」「不可算」，不写百分比。这条纪律在评分里体现为「边界与移交」那一项，扣分理由是「把待办写成了结论」。

评分在预答辩前自评一次，主要查一件事：表里有没有一行是「凭记忆填的」。凭记忆填的行通常有两个特征：出处只写书名不写版本，归经只有一个值没有分歧。查到就删，宁可表短，不要表假。

评分时还要看「换书可扩」这一项。做法很简单：问作者「再给你一部书，多久能并进表里」。答「半天」并说清步骤的，说明表结构是通的；答「要重做」的，说明字段是为这一部书定制的。前者可以移交，后者只能自用。这一问比看表本身更能判断可复现性。

## 四、记录字段与复算口径

穴-经台账建议七列：

| 列 | 填什么 | 例 |
|---|---|---|
| 穴名 | 规范名 | 合谷 |
| 归经 | 该书所归之经 | 手阳明大肠经 |
| 出处 | 书名·版本 | 教材甲·第二版 |
| 部位 | 该书记载的部位 | 手背第一、二掌骨间 |
| 冲突 | 是／否／待判 | 是 |
| 冲突类型 | 同名异穴／归经分歧／口径差异 | 归经分歧 |
| 校验值 | 该书的文件校验值 | 前八位 |

「部位」这一列是判冲突的关键。同名异穴与归经分歧的区别，往往就在部位上：部位相同而归经不同，是归经分歧；部位不同而穴名相同，是同名异穴。没有部位列，两类冲突只能靠印象分，分错了整张表就不可信。

复算口径两条：行数 ＝ 穴数 × 入库书数（去重后按穴计）；冲突率 ＝ 冲突穴数 ÷ 可判穴数。第二条在可判穴数为 0 时不计算，写「不可算」。这两条要写进脚本注释，不能只写在论文里，否则换人接手就会重新定义。

台账的更新节奏与补源同步：每入库一部书，就追加一列而不是重排。追加列的好处是历史可追——哪一部书带来了新的冲突，一眼能看出来。若重排，旧列的顺序变了，前面写的分析段落就得全部改；追加列则只需在文末补一句「新增乙书后，冲突穴增加几条」。

## 五、失效模式与考核项

| 失效 | 表现 | 拦截 |
|---|---|---|
| 零当结论 | 未建部分写 0% | 全文检索百分比 |
| 同名异穴被并 | 两个穴合成一行 | 部位列必填 |
| 版本混用 | 两版当一版 | 校验值登记 |
| 记忆填表 | 出处只有书名 | 抽三行回查 |
| 冲突率越界 | 报成学界冲突率 | 只报本批教材 |

第五条最容易被忽略。本章算出的冲突率，只说明「这几部教材之间不一致」，不说明「针灸学界有多大分歧」。后者需要更大范围的教材与标准比对，不是一章能回答的。论文里写成「本批 N 部教材中，可判穴的冲突占比为 X」，读者一看就知道范围；写成「腧穴归经冲突率 X」，就把样本说成了总体。

答辩时的一个常见追问是「你的表能直接给临床用吗」。答案是不能，也不必能。这张表的价值在于把分歧显性化，供教材编写与标准讨论参考；临床取穴要结合具体病人的情况，不是查表能解决的。主动说清这一点，比含糊地说「有参考价值」更能守住边界。

八条考核项：

- [ ] 能报出「入库 0 部、可建 0 行」的现状；
- [ ] 能解释为何 0/0 不能写成 0%；
- [ ] 能列出补源清单的三项登记内容；
- [ ] 能说出三类冲突的判别依据；
- [ ] 能交出一部教材的穴-经表；
- [ ] 能抽三行回查出处；
- [ ] 能列出未覆盖的穴；
- [ ] 能说明冲突率的适用范围。

## 代价与边界

1. 多教材文本未入库，本案例第一步是补源，不是计算；补源完成前，一切比例都不可报；
2. 穴-经表以教材口径为准，与任何标准文件的穴名表可能不一致，差异须单列；
3. 三类冲突的判别含人工判断，边界个案须在表里保留原始出处，不得只留结论；
4. 商业侧按本库实例：针灸器械与教学设备客群 200 家、取带中位 8% 对应 16 家、客单 24,000 元，三年收入 480,000 元，回本 45.2 个月——超出三年窗口，说明该产品更适合做标准配套而非独立售卖；
5. **免责声明：** 本章为教学与毕设指导用，不构成诊疗建议、标准解释、商业承诺或法律意见；穴-经表不得用于临床取穴的最终依据。
