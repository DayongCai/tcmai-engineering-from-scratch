# 一案八件

## 用途

把「方剂-药味对账——饮片集采时代的配伍可核账本」做成可复跑、可验算、假设可披露的一次毕设。只写能被第三人复核的项，并标明哪些是假设。

**命题：** 方剂里出现的药味，有多少不在中药学词表内？补词表能把覆盖率提到多少？

## 步骤

### 1. 写命题

方剂里出现的药味，有多少不在中药学词表内？补词表能把覆盖率提到多少？

### 2. 锚数据

114 方 / 836 个药位 / 246 味；不在词表 86 味

### 3. 做方法

① 取 notInZhongyaoLexicon 清单；② 人工判别「别名／新药／解析噪声」三类；③ 补别名后重算覆盖率

### 4. 做评价

基线＝原覆盖率；消融＝只补别名（不补新药）；失效＝把解析噪声当新药计入

### 5. 定客户数

SAM 200 × 中位渗透 8.0% → 采用 16

### 6. 验客单

无营收锚：仅作内部一致性检查（同类案例客单差异不超过 5 倍）

### 7. 算预算

建设 ¥67,400／获客 ¥3,000／回本 18.8 月

### 8. 判渠道

不做：个人无法使用配伍对账

### 9. 写缺口

18 方只有 4 味药角色完整（withRoles4），角色层数据不足，不能做配伍角色分析

## 判据速查

| 项 | 本章要求 |
|---|---|
| 案例类型 | 方法层 |
| 数据规模 | 114 方 / 836 个药位 / 246 味；不在词表 86 味 |
| 客群 / SAM | 药企与器械 / 200 |
| 客户数（采用） | 16（隐含渗透 8.0%）|
| 客单 / 回本 | ¥45,000 / 18.8 月 |

## 输出

命题三件式 + 数据锚点 + 基线／消融／失效 + B 端四件 + 客户数与客单判据 + C 端判定 + 合并账 + 缺口。

## 边界

- 缺口须原样写进开题：18 方只有 4 味药角色完整（withRoles4），角色层数据不足，不能做配伍角色分析；
- 客户数须写成 SAM×渗透率，不得直接拍数；客单须给营收／IT 预算占比；
- 工时三段为「假设·未实测」，不得去标签；
