# 一案八件

## 用途

把「证候词典即服务——900 单元派生的 132 证基层辨证底座」做成可复跑、可验算、假设可披露的一次毕设。只写能被第三人复核的项，并标明哪些是假设。

**命题：** 同一批 900 个临床单元，用两套族归并规则跑，能否稳定落在同一数量级？

## 步骤

### 1. 写命题

同一批 900 个临床单元，用两套族归并规则跑，能否稳定落在同一数量级？

### 2. 锚数据

外科 325 ＋ 儿科 250 ＋ 妇科 325 = 900 单元 → 132 证 / 14 族 / 208 次病证覆盖

### 3. 做方法

① 用 build_zhenghou_layer.py 抽证名与代表方；② 族归并顺序改为「病位优先」重跑；③ 比对两次的证数与族分布

### 4. 做评价

基线＝人工按章节挑证名（3 章抽样）；消融＝族顺序互换；失效＝「其他」族占比从 8.3% 升到何值

### 5. 定客户数

SAM 42,000 × 中位渗透 1.55% → 采用 651

### 6. 验客单

客单占客户年营收 0.2%（IT 预算区间 15,000–60,000 元/年）——落在合理带内

### 7. 算预算

建设 ¥87,400／获客 ¥9,900／回本 5.9 月

### 8. 判渠道

可做 个人体质—证候自测（只给测量结果与就医建议，不给诊断与处方）

### 9. 写缺口

跨课证候最多两门共有，10 个；没有一门三课共有——这条限制必须在论文里写清

## 判据速查

| 项 | 本章要求 |
|---|---|
| 案例类型 | 数据层 |
| 数据规模 | 外科 325 ＋ 儿科 250 ＋ 妇科 325 = 900 单元 → 132 证 / 14 族 / 208 次病证覆盖 |
| 客群 / SAM | 基层中医馆 / 42,000 |
| 客户数（采用） | 651（隐含渗透 1.55%）|
| 客单 / 回本 | ¥6,000 / 5.9 月 |

## 输出

命题三件式 + 数据锚点 + 基线／消融／失效 + B 端四件 + 客户数与客单判据 + C 端判定 + 合并账 + 缺口。

## 边界

- 缺口须原样写进开题：跨课证候最多两门共有，10 个；没有一门三课共有——这条限制必须在论文里写清；
- 客户数须写成 SAM×渗透率，不得直接拍数；客单须给营收／IT 预算占比；
- 工时三段为「假设·未实测」，不得去标签；
