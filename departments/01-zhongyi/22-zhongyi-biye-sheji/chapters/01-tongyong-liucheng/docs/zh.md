# 第 1 章 · 通用流程与基本要求

> **MOTTO:** 「必审问其所始病，与今之所方病」——教材·第1章·1.1（《素问·三部九候论》）
>
> **PROBLEM:** 毕设的三类失败：**没人能重跑**（工程）、**没人愿意买**（定位）、**以为能卖给个人却越线**（合规）。本章把三件事定死，并把「假设」与「数据」分开记账。
>
> **双根因定位:** 环境逼迫（答辩要证据、市场要付费方、监管要边界）+ 知识积累（本库底本层与门禁链已构成整套样板）

**教材出处:** 派生底本。数字由 `code/main.js` 与 `standards/biye/` 六份 JSON 现算。

## 一、四段流程

| 段 | 做什么 | 不合格的样子 |
|---|---|---|
| 选题 | 对象＋对照＋失败形态 | 「中医治疗失眠的探讨」 |
| 证据 | 数据路径、规模、可核方式 | 「查阅相关文献若干」 |
| 实现 | 管线可跑、参数外置 | 结果只在截图里 |
| 评价 | 基线／消融／失效 | 只报「效果良好」 |

## 二、三件必报

| 件 | 定义 | 为什么强制 |
|---|---|---|
| 基线 | 不做处理时的结果 | 没有基线，改进无法度量 |
| 消融 | 去掉你的方法后 | 说不清哪一步起作用 |
| 失效 | 方法不成立的情形 | 说明边界没摸到 |

## 三、市场四件 ＋ 渠道判定

| 件 | 合格 | 不合格 |
|---|---|---|
| 服务对象 | 谁、哪件每周重做的事 | 「面向广大患者」 |
| 服务内容 | 四件交付物 | 「提供咨询服务」 |
| 预算 | 建设＋获客＋运维＋回本 | 「预计盈利」 |
| AI 创新点 | 没有它这一步为何做不成 | 「接入大模型提效」 |
| **渠道判定** | C 端做不做，都要给理由与合规结论 | 「顺便做个 App」 |

## 四、C 端：能做测量，不能做诊断

| 辅助决策还是处理测量 | S12（2021 年第 47 号） | 辅助决策→三类；非辅助决策→二类 |

| 是否给诊断处方 | S15 | 不得对首诊开展互联网诊疗 |

## 六、客户数怎么来的（本轮新增）

客户数不再手设，而由 **SAM × 渗透带中位** 推出，并报隐含渗透率：

| 客群 | SAM | 来源 | 合理带 |
|---|---|--:|---|
| 基层中医馆 | 42,000 | S2 | 0.1%–3% |
| 中医类诊所 | 100,885 | S1 | 0.1%–3% |
| 中医类医院 | 6,498 | S1 | 1%–10% |
| 院校 | 60 | 估计 | 5%–40% |
| 药企与器械 | 200 | 估计 | 1%–15% |

**校验结果**：合理 **24** 案、偏高 **0** 案、偏低 **3** 案、无客单锚 16 案。修正后有 14 案的客户数被 SAM 上限压了下来（如院校 150 → 14）。

## 七、客单怎么验

客单与客户年营收／IT 预算挂钩（S16：三级医院 IT 预算占总预算 1%–2%；S17：中医类医院总收入 5,910.5 亿 ÷ 6,498 家 ≈ 9,100 万/家）：

| 客群 | 年营收锚 | 客单占营收 | 判定 |
|---|--:|--:|---|
| 中医类医院 | ≈ 9,100 万 | 0.03%–0.66% | 在 IT 预算带内 |
| 中医类门诊部 | ≈ 311 万 | 0.2%–1.9% | 在带内 |
| 基层中医馆 | ≈ 300 万（估计） | 0.2%–2% | 在带内 |

**32 案里 16 案无营收锚**（院校、药企、诊所部分）——这些只做内部一致性检查，不假装有锚。

## 八、成本口径：不做单一单价

| 类型 | 单价 | 粗口径折算单位成本 | 差距 |
|---|--:|---|--:|
| 单元 | 60 | 97.1–1456.7 | **15.0×** |
| 条 | 0.6 | 24.1–416.0 | **17.3×** |
| 字段 | 12 | 76.1–662.1 | **8.7×** |

同一单价、单位成本差 8.7–17.3 倍，因为设计与校验是固定投入。**细口径 ¥727,356（16/27 可计）／粗口径 ¥1,318,400，差 -44.8%**——细口径作敏感性，粗口径作计费。

**工时三段**当前按假设比例拆（设计 40%／校验 35%／返工 25%），台账 45 行（15 案）标「假设·未实测」，33 行待建、3 行无隐性成本。校验器 `check_biye_timelog.py` 拒绝 0 与半填；有真实工时后替换即可重算。

## 九、B／C 合并账：分摊是报表，增量才是决策

| 合计（27 案，三年） | 数值 |
|---|--:|
| 共同成本 | ¥2,199,800 |
| B 三年收入 | ¥41,116,000 |
| C 三年收入 | ¥2,547,057 |
| B 净贡献 | ¥38,228,600 |
| C 增量净 | ¥169,857 |
| **合并净** | **¥38,398,457** |
| C 增量正 / 负 / 不做 | 7 / 4 / 16 |

`合并净 = B净（未摊）+ C增量净 − 共同成本`，三种分摊规则下合并净相同（脚本逐案断言）。
