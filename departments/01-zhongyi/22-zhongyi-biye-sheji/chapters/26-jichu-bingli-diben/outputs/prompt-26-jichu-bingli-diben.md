# 一案八件

## 用途

把「病理 252 单元底本——基础医学的课程数字化底座」做成可复跑、可验算、假设可披露的一次毕设。只写能被第三人复核的项，并标明哪些是假设。

**命题：** 全库最大的单个底本层，其单元切分与章节门禁能否被别的课直接复用？

## 步骤

### 1. 写命题

全库最大的单个底本层，其单元切分与章节门禁能否被别的课直接复用？

### 2. 锚数据

bingli 252 单元 / 428,867 汉字 / 数值 0

### 3. 做方法

① 复用切分规则；② 跑门禁；③ 记录复用失败的位置

### 4. 做评价

基线＝原课（已建 10 章）；消融＝换课复用；失效＝切分粒度与该课章节数不匹配

### 5. 定客户数

SAM 60 × 中位渗透 22.5% → 采用 14

### 6. 验客单

无营收锚：仅作内部一致性检查（同类案例客单差异不超过 5 倍）

### 7. 算预算

建设 ¥107,400／获客 ¥3,000／回本 41.4 月

### 8. 判渠道

不做：个人不订阅底本层

### 9. 写缺口

教材版本差异未处理，换版需重建

## 判据速查

| 项 | 本章要求 |
|---|---|
| 案例类型 | 数据层 |
| 数据规模 | bingli 252 单元 / 428,867 汉字 / 数值 0 |
| 客群 / SAM | 院校 / 60 |
| 客户数（采用） | 14（隐含渗透 23.333%）|
| 客单 / 回本 | ¥32,000 / 41.4 月 |

## 输出

命题三件式 + 数据锚点 + 基线／消融／失效 + B 端四件 + 客户数与客单判据 + C 端判定 + 合并账 + 缺口。

## 边界

- 缺口须原样写进开题：教材版本差异未处理，换版需重建；
- 客户数须写成 SAM×渗透率，不得直接拍数；客单须给营收／IT 预算占比；
- 工时三段为「假设·未实测」，不得去标签；
