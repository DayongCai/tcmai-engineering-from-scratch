# 一案八件

## 用途

把「287 味药性味归经 API——给四诊仪与 HIS 补一张结构化药表」做成可复跑、可验算、假设可披露的一次毕设。只写能被第三人复核的项，并标明哪些是假设。

**命题：** 同一份说明书文本，严格解析与宽松解析的「未解析条数」差多少？

## 步骤

### 1. 写命题

同一份说明书文本，严格解析与宽松解析的「未解析条数」差多少？

### 2. 锚数据

287 味；带气 287、带味 285、带归经 284；未解析 0

### 3. 做方法

① 记下 parseRule；② 把规则改成「允许缺项」重跑；③ 统计三字段的缺口从 0 变成多少

### 4. 做评价

基线＝严格规则（未解析 0）；消融＝缺项容忍；失效＝宽松后是否把「归经：无」误计为有

### 5. 定客户数

SAM 200 × 中位渗透 8.0% → 采用 16

### 6. 验客单

无营收锚：仅作内部一致性检查（同类案例客单差异不超过 5 倍）

### 7. 算预算

建设 ¥87,400／获客 ¥3,000／回本 36.2 月

### 8. 判渠道

不做：C 端买不到「API」，药名查询已有免费替代

### 9. 写缺口

287 味只是词表口径，不是《中药学》教材全量；教材全量另需建底本

## 判据速查

| 项 | 本章要求 |
|---|---|
| 案例类型 | 数据层 |
| 数据规模 | 287 味；带气 287、带味 285、带归经 284；未解析 0 |
| 客群 / SAM | 药企与器械 / 200 |
| 客户数（采用） | 16（隐含渗透 8.0%）|
| 客单 / 回本 | ¥30,000 / 36.2 月 |

## 输出

命题三件式 + 数据锚点 + 基线／消融／失效 + B 端四件 + 客户数与客单判据 + C 端判定 + 合并账 + 缺口。

## 边界

- 缺口须原样写进开题：287 味只是词表口径，不是《中药学》教材全量；教材全量另需建底本；
- 客户数须写成 SAM×渗透率，不得直接拍数；客单须给营收／IT 预算占比；
- 工时三段为「假设·未实测」，不得去标签；
