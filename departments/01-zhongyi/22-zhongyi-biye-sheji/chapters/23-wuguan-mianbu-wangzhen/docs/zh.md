## 九、AI 时代创新点

字段化让图像模型有明确标签体系，减少「望神」这类整体判断被误当分类标签

| 传统做法 | 本案例的做法 | 为什么在 AI 时代才成立 |
|---|---|---|
| 靠专家经验与个人笔记 | 词表／字段／门禁可复算 | 大模型能生成，但只有可核的词表能拦住编造 |
| 交付一份 PDF 报告 | 交付脚本与门槛 | 评审方会用 AI 交叉验证 |
| 按人天定价 | 按「可用数据＋可复跑」定价 | 数据资产可复用，边际成本随客户数下降 |

## 十一、B／C 合并账与成本分摊

| 共同成本（底本建设） | ¥87,400 |
| B 增量成本（获客＋运维） | ¥23,000 |
| B 三年收入 | ¥560,000 |
| C 三年收入 | ¥794,010 |
| C 增量成本（获客×3＋合规） | ¥630,000 |
| **C 增量净** | **¥164,010** |
| **合并净** | **¥613,610** |
| 判定 | **加 C** |

| 规则 | C 分摊 | B 净 | C 净 | 合并 |
|---|--:|--:|--:|--:|
| 收入比例 | ¥51,253 | ¥500,853 | ¥112,757 | ¥613,610 |
| 等分 | ¥43,700 | ¥493,300 | ¥120,310 | ¥613,610 |
| 增量法 | ¥0 | ¥449,600 | ¥164,010 | ¥613,610 |

**最后一列相同，就是恒等式的可视证明**：`合并净 = B净（未摊）+ C增量净 − 共同成本`，与分摊规则无关。

## 十四、三处最常见的退步

- **只写意义不写对象**：说不出「谁每周都要用」，等于没有定位；
- **客户数直接拍**：必须写成 SAM × 渗透率，并给渗透带；
- **把假设当数据**：工时三段与客单都是假设，须标注来源，不得去掉标签。
