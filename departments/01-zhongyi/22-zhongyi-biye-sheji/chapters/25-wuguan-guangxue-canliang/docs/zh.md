# 第 25 章 · 留空与写「无」，在报表里是两件事

> **MOTTO:** 「目者，宗脉之所聚也」——《灵枢·口问》
>
> **PROBLEM:** 光学参数表要求缺项显式写「无」，不允许留空。可复算的判据是「受影响行数 ÷ 总行数」：留空版被下游按 0 处理时，有多少行的均值、分档或排序会变。同一批参数，两种填法，结论不同——这不是格式问题，是数据问题。
>
> **双根因定位:** 环境逼迫（眼科数据报表要能被下游直接计算，不能让读取方猜）＋ 知识积累（缺项显式的口径已在库，参数表结构可直接套用）

## 一、命题与数据锚点：留空不是「没有值」，是「不知道」

本章的命题是：**参数报表里「本项无数据」与「留空」混用会带来什么后果**。答案不止是「看起来不规范」，而是下游计算会给出不同的数：留空被当成 0，均值、分档、排序都会偏。

结构摆清：

| 项 | 状态 | 说明 |
|---|---|---|
| 真实光学数据 | 本库无 | 属院内数据 |
| 参数表结构 | 待建 | 本章定义 |
| 两种填法 | 留空／显式无 | 对照 |
| 下游计算 | 均值／分档／排序 | 受影响项 |
| 受影响行数 | 待统计 | 判据分子 |
| 合规口径 | 缺项显式 | 已在库 |

「留空」在语义上是歧义的：它可能是「没有测」，也可能是「测了但没有」，还可能是「忘了填」。三种含义对下游影响不同，而报表本身不区分。显式写「无」至少消掉了「忘了填」这一种，剩下的两种靠备注区分。

为什么留空会被当成 0？因为多数表格工具与脚本在求和、求均值时，把空单元格当缺失跳过，而在做减法或分档时又当 0 处理。两种行为混在同一张表里，结果就不可预期。作者若只在一处验证，就发现不了另一处的问题。

受影响行数这个判据，要这样算：把同一批参数按两种填法各算一遍，逐行比均值、分档、排序，凡结果不同的是受影响行。行数越多，说明这张表对填法越敏感，越需要统一口径。

真实光学数据本库没有，这一条要写在开题。本章交付的是表结构与填法规范，不是一批实测参数。若读者以为「参数表」里已经填了真实数据，会高估这一章的完成度。

## 二、分阶段交付物与分工

| 节点 | 时点 | 必交物 | 责任人 | 签收人 |
|---|---|---|---|---|
| 开题 | 第 1–4 周 | 参数表字段、缺项标记规则、下游计算清单 | 学生 | 开题小组 |
| 中期 | 第 8 周 | 两版填法样例、下游计算脚本、受影响行初算 | 学生 | 导师 |
| 预答辩 | 第 12 周 | 两版对照表、受影响行数、填表说明 | 学生 | 预答辩组 |
| 答辩 | 第 16 周 | 参数表、对照表、说明、复跑记录 | 学生 | 答辩委员会 |

开题要定「缺项」的三种标记：未测、无此项、不适用。「未测」表示应测未测，「无此项」表示该设备或该检查不产生此参数，「不适用」表示该受检者不需要此项。三种混成一个「无」，下游仍会误判。

分工上，字段与标记规则由导师确认，样例与脚本由学生做，下游影响核验由同学完成。第三项为什么独立？因为作者容易只验自己关心的那一项计算，漏掉分档与排序；换个人按清单逐项验，才查得全。

中期两版都要做。只做显式无的一版，无法证明留空有问题；两版并列，受影响行数才有依据。这个对照是本 chapter 的方法核心，不能省。

预答辩要交填表说明。说明里写清三种标记的用法，并各举一例。没有例子，填写者仍会按习惯留空；有了例子，留空就成了明确的违规。

### 下游计算先列清单

下游有哪些计算，要在开题时列全。常见的至少四类：求均值、分档、排序、同比。四类对缺项的敏感度不同：均值最敏感（空被跳过或被当 0 差很多），排序次之（缺项排末位还是排除），同比最复杂（基期缺项时算不出来）。

清单列全之后，逐项验一次两版填法的差别。验完会发现，有些计算其实不受影响；把这些写出来，反而增加可信度——说明作者不是笼统地说「有影响」，而是知道影响在哪。

清单还有一个用处：它是填表说明的依据。说明里可以写「本表用于均值与分档，不用于同比」，把用途限定住，减少误用。

## 三、判据与评分维度【教学设定】

移交层判据四条：

| 判据 | 合格线 | 检查方式 |
|---|---|---|
| 标记可分 | 三种缺项各有标记 | 表里可读 |
| 两版可算 | 留空与显式无各算一遍 | 脚本可跑 |
| 影响可数 | 受影响行数可复算 | 抽一行核 |
| 说明可用 | 填表说明有例子 | 读说明 |

评分维度（教学设定）：

| 维度 | 权重 | 不合格 | 合格 | 优秀 |
|---|--:|---|---|---|
| 命题可判 | 15% | 只说「规范填表」 | 有受影响行数 | 预写三种标记 |
| 表结构 | 25% | 字段不明 | 标记可读 | 用途已限定 |
| 对照完整 | 30% | 只做一版 | 两版都算 | 影响按计算分类 |
| 边界与移交 | 15% | 暗示有真实数据 | 声明无实测 | 附复跑记录 |
| 评价完整 | 15% | 不报影响 | 报行数 | 说明可操作 |

「对照完整」占 30%，因为这一章的说服力全在「同一批数、两种填法、结果不同」。只做一版，等于只交了一张表；两版并列并算出差异，才叫分析。

「边界与移交」看一句声明：是否写明「本章无真实光学数据」。写明，读者知道这是规范与模板；不写，容易被当成一份实测报表。

## 四、记录字段与复算口径

参数台账建议八列：

| 列 | 填什么 | 例 |
|---|---|---|
| 受检号 | 脱敏编号 | E-007 |
| 参数 | 参数名 | 某光学参数 |
| 值 | 数值 | 待填 |
| 单位 | 单位 | 待填 |
| 缺项标记 | 未测／无此项／不适用 | 未测 |
| 留空版结果 | 下游算出 | 待算 |
| 显式版结果 | 下游算出 | 待算 |
| 是否受影响 | 是／否 | 是 |

「单位」这一列必须与值同表。只填数值不填单位，跨机构合并时会出错；单位不同还会导致排序错乱。本章把单位设为必填，缺单位视同缺项。

复算口径三条：受影响行数 ＝ 两版结果不同的行数；影响率 ＝ 受影响行数 ÷ 总行数；均值 ＝ 有效值之和 ÷ 有效值个数（有效值不含缺项）。三条都要写进脚本，缺项规则写进注释。

## 五、失效模式与考核项

| 失效 | 表现 | 拦截 |
|---|---|---|
| 留空当 0 | 均值偏低仍照算 | 缺项显式 |
| 三种缺项混一 | 无法区分原因 | 三种标记 |
| 单位缺失 | 合并排序错乱 | 单位必填 |
| 只验一种计算 | 漏掉分档与排序 | 下游清单 |
| 冒充实测 | 模板说成数据 | 声明无实测 |

第一条与第五条是本章的两条红线。第一条关乎数据质量：留空被当 0，均值会系统性偏移，而这种偏移不会报错，最难发现。第五条关乎学术诚实：模板不是数据，把模板说成实测，等于用一份空表支撑结论。

八条考核项：

- [ ] 能说出留空与「无」的语义差别；
- [ ] 能列出三种缺项标记；
- [ ] 能列出至少四类下游计算；
- [ ] 能跑出两版填法并算受影响行数；
- [ ] 能举一行说明均值为何偏移；
- [ ] 能说明单位为何必填；
- [ ] 能交出填表说明与例子；
- [ ] 能声明本章无真实光学数据。

说明文档要写清表能干什么、不能干什么。能干的是「记录参数、支持下限上限比对」；不能干的是「替代设备读数、替代验光结论」。两句话写在表头，使用者不会误用。

跨机构合并时，缺项标记要先统一。甲机构用「无此项」、乙机构用「NA」，合并后脚本认不出，缺项会被当成有值。处置办法是在合并脚本里先做一次标记映射，映射表随包交付。

缺项统计要单独出一张表，不能混进参数表。混在一起，读者看到的是一张有很多空格的表，看不出缺了多少、缺在哪类参数。单独统计，才能回答「哪类参数最常缺」这个有用的问题。

还有一条经验：把「缺项原因」做成限定几个选项，不要让填写者自由写。自由写的结果是几十种说法，无法统计；限定选项（未测、无此项、不适用）虽然损失一点细节，但换来可用性。细节可以放备注，选项必须收敛。

最后一条给答辩准备：把「缺项怎么处理」做成一张一页纸的对照，左边写填法，右边写算法怎么读。评审若问「你怎么保证下游不出错」，把这张纸递过去，比解释十分钟清楚。这张纸也是移交包里最实用的一页。

### 两种填法的差值怎么算

算差值不要只看均值。均值之外，至少还要看三处：分档的人数、排序的前三位、缺失率本身。四处都算一遍，才知道影响是全方位的还是只集中在均值。

写论文时把四处列成一张小表，比一段话描述清楚。表格里两列（留空版、显式版）、四行（均值、分档、排序、缺失率），一眼能看出哪一处变化最大。

### 缺项标记会改变分母

显式写「无」之后，分母要相应调整：均值只按有值条目算，缺失率单独列出。若不调整分母，显式版会把「无」算进总数，均值反而偏低。这个细节最容易被忽略，而它恰好会让结论反过来。

所以填法与算法必须一起改。只改填法不改算法，等于换了个说法继续错；只改算法不改填法，脚本无从判断哪些是缺项。
