# 一案八件

## 用途

把「光学参数缺项写法——眼科数据报表的合规底线」做成可复跑、可验算、假设可披露的一次毕设。只写能被第三人复核的项，并标明哪些是假设。

**命题：** 参数报表里「本项无数据」与「留空」混用会带来什么后果？

## 步骤

### 1. 写命题

参数报表里「本项无数据」与「留空」混用会带来什么后果？

### 2. 锚数据

无现成光学数据；口径＝缺项必须显式写「无」，不允许留空

### 3. 做方法

① 设计参数表；② 两版填法（留空／显式无）；③ 统计下游计算受影响的行数

### 4. 做评价

基线＝留空；消融＝显式无；失效＝留空被下游按 0 处理导致平均值偏移

### 5. 定客户数

SAM 100,885 × 中位渗透 1.55% → 采用 120

### 6. 验客单

无营收锚：仅作内部一致性检查（同类案例客单差异不超过 5 倍）

### 7. 算预算

建设 ¥67,400／获客 ¥18,000／回本 14.2 月

### 8. 判渠道

可做 视力与用眼记录（自测趋势，不替代验光）

### 9. 写缺口

真实验光数据属院内数据，本案例只有模板与口径

## 判据速查

| 项 | 本章要求 |
|---|---|
| 案例类型 | 移交层 |
| 数据规模 | 无现成光学数据；口径＝缺项必须显式写「无」，不允许留空 |
| 客群 / SAM | 中医类诊所 / 100,885 |
| 客户数（采用） | 120（隐含渗透 0.119%）|
| 客单 / 回本 | ¥12,000 / 14.2 月 |

## 输出

命题三件式 + 数据锚点 + 基线／消融／失效 + B 端四件 + 客户数与客单判据 + C 端判定 + 合并账 + 缺口。

## 边界

- 缺口须原样写进开题：真实验光数据属院内数据，本案例只有模板与口径；
- 客户数须写成 SAM×渗透率，不得直接拍数；客单须给营收／IT 预算占比；
- 工时三段为「假设·未实测」，不得去标签；
