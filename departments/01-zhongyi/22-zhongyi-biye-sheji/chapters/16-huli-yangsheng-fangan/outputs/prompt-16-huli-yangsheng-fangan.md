# 一案八件

## 用途

把「养生方案检查单——治未病的「忌」清单产品」做成可复跑、可验算、假设可披露的一次毕设。只写能被第三人复核的项，并标明哪些是假设。

**命题：** 养生方案里「忌」比「宜」重要——能否用检查单把这条落成可核项？

## 步骤

### 1. 写命题

养生方案里「忌」比「宜」重要——能否用检查单把这条落成可核项？

### 2. 锚数据

口径来源：体质学第 7 章「以平为期，忌比宜重要」；证候 132 证可作对象池

### 3. 做方法

① 列忌／宜两栏；② 每条写可观察判据；③ 检查单逐项勾选并记录依据

### 4. 做评价

基线＝只写宜；消融＝忌宜并列；失效＝把「忌」写成模糊劝告（如「少食生冷」无量化）

### 5. 定客户数

SAM 42,000 × 中位渗透 1.55% → 采用 400

### 6. 验客单

客单占客户年营收 0.233%（IT 预算区间 15,000–60,000 元/年）——落在合理带内

### 7. 算预算

建设 ¥67,400／获客 ¥6,000／回本 6.3 月

### 8. 判渠道

可做 养生「忌」清单订阅（按体质出忌宜清单＋打卡）

### 9. 写缺口

养生效果的长期随访数据本库没有，只能做方案可执行性，不做疗效结论

## 判据速查

| 项 | 本章要求 |
|---|---|
| 案例类型 | 移交层 |
| 数据规模 | 口径来源：体质学第 7 章「以平为期，忌比宜重要」；证候 132 证可作对象池 |
| 客群 / SAM | 基层中医馆 / 42,000 |
| 客户数（采用） | 400（隐含渗透 0.952%）|
| 客单 / 回本 | ¥7,000 / 6.3 月 |

## 输出

命题三件式 + 数据锚点 + 基线／消融／失效 + B 端四件 + 客户数与客单判据 + C 端判定 + 合并账 + 缺口。

## 边界

- 缺口须原样写进开题：养生效果的长期随访数据本库没有，只能做方案可执行性，不做疗效结论；
- 客户数须写成 SAM×渗透率，不得直接拍数；客单须给营收／IT 预算占比；
- 工时三段为「假设·未实测」，不得去标签；
