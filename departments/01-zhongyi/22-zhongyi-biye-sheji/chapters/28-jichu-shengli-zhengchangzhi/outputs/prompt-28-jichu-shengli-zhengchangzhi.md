# 一案八件

## 用途

把「生理正常值表——可复现的参考区间交付」做成可复跑、可验算、假设可披露的一次毕设。只写能被第三人复核的项，并标明哪些是假设。

**命题：** 正常值表移交时，单位与参考区间必须写到什么程度才算可复现？

## 步骤

### 1. 写命题

正常值表移交时，单位与参考区间必须写到什么程度才算可复现？

### 2. 锚数据

shengli 132 单元 / 228,672 汉字 / 数值 0

### 3. 做方法

① 抽正常值条目；② 补单位与区间；③ 检查跨章同一指标是否一致

### 4. 做评价

基线＝只抄数值；消融＝带单位与区间；失效＝同一指标两章单位不同（如 mmol/L 与 mg/dL）

### 5. 定客户数

SAM 6,498 × 中位渗透 5.5% → 采用 90

### 6. 验客单

客单占客户年营收 0.02%（IT 预算区间 910,000–1,820,000 元/年）——落在合理带内

### 7. 算预算

建设 ¥87,400／获客 ¥15,000／回本 13.7 月

### 8. 判渠道

可做 化验单解读订阅（只做参考区间解释，不给诊断）

### 9. 写缺口

参考区间的实验室差异本库未收，表中只反映教材口径

## 判据速查

| 项 | 本章要求 |
|---|---|
| 案例类型 | 移交层 |
| 数据规模 | shengli 132 单元 / 228,672 汉字 / 数值 0 |
| 客群 / SAM | 中医类医院 / 6,498 |
| 客户数（采用） | 90（隐含渗透 1.385%）|
| 客单 / 回本 | ¥18,000 / 13.7 月 |

## 输出

命题三件式 + 数据锚点 + 基线／消融／失效 + B 端四件 + 客户数与客单判据 + C 端判定 + 合并账 + 缺口。

## 边界

- 缺口须原样写进开题：参考区间的实验室差异本库未收，表中只反映教材口径；
- 客户数须写成 SAM×渗透率，不得直接拍数；客单须给营收／IT 预算占比；
- 工时三段为「假设·未实测」，不得去标签；
