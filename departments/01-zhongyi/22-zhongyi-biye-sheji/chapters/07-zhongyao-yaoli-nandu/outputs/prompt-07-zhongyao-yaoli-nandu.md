# 一案八件

## 用途

把「药理 97 万字难度图谱——教培与继续教育的选题引擎」做成可复跑、可验算、假设可披露的一次毕设。只写能被第三人复核的项，并标明哪些是假设。

**命题：** 用「字数 × 数值密度」能否预测哪些小节最难学？预测在哪些小节失效？

## 步骤

### 1. 写命题

用「字数 × 数值密度」能否预测哪些小节最难学？预测在哪些小节失效？

### 2. 锚数据

49 章 / 196 节 / 588 小节 / 7,455 段 / 971,179 汉字 / 数值 421

### 3. 做方法

① 以字数与数值密度排序；② 取前 10 与后 10 小节人工判难；③ 记录不一致的小节

### 4. 做评价

基线＝字数排序；消融＝字数×数值；失效＝纯理论小节（数值 0）被误判为最容易

### 5. 定客户数

SAM 60 × 中位渗透 22.5% → 采用 14

### 6. 验客单

无营收锚：仅作内部一致性检查（同类案例客单差异不超过 5 倍）

### 7. 算预算

建设 ¥87,400／获客 ¥3,000／回本 60.3 月

### 8. 判渠道

可做 药理难点精讲订阅（按章节付费）

### 9. 写缺口

「难」的定义依赖人工判断，本库只提供可量化代理，不能替代教学经验

## 判据速查

| 项 | 本章要求 |
|---|---|
| 案例类型 | 移交层 |
| 数据规模 | 49 章 / 196 节 / 588 小节 / 7,455 段 / 971,179 汉字 / 数值 421 |
| 客群 / SAM | 院校 / 60 |
| 客户数（采用） | 14（隐含渗透 23.333%）|
| 客单 / 回本 | ¥18,000 / 60.3 月 |

## 输出

命题三件式 + 数据锚点 + 基线／消融／失效 + B 端四件 + 客户数与客单判据 + C 端判定 + 合并账 + 缺口。

## 边界

- 缺口须原样写进开题：「难」的定义依赖人工判断，本库只提供可量化代理，不能替代教学经验；
- 客户数须写成 SAM×渗透率，不得直接拍数；客单须给营收／IT 预算占比；
- 工时三段为「假设·未实测」，不得去标签；
- **免责声明：** 教学用，不构成诊疗建议、商业承诺或法律意见。
