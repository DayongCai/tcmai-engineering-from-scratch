# 一案八件

## 用途

把「康复评定可复现包——社区康复的量表合规盒」做成可复跑、可验算、假设可披露的一次毕设。只写能被第三人复核的项，并标明哪些是假设。

**命题：** 把一套康复评定做成可复现包，最少需要哪些文件才能让别人重跑？

## 步骤

### 1. 写命题

把一套康复评定做成可复现包，最少需要哪些文件才能让别人重跑？

### 2. 锚数据

无现成量表；可复现包口径＝数据＋脚本＋门禁＋README 四件

### 3. 做方法

① 定义量表字段；② 写评分脚本；③ 加门禁（字段完整性、分数范围、缺项显式化）

### 4. 做评价

基线＝手工评分；消融＝脚本评分；失效＝缺项被默认填 0 导致分数虚高

### 5. 定客户数

SAM 42,000 × 中位渗透 1.55% → 采用 300

### 6. 验客单

客单占客户年营收 0.267%（IT 预算区间 15,000–60,000 元/年）——落在合理带内

### 7. 算预算

建设 ¥87,400／获客 ¥4,500／回本 9.2 月

### 8. 判渠道

可做 居家康复自评（量表自填＋趋势记录，不替代评估）

### 9. 写缺口

量表本身需自建并经信度检验，本库不提供信度数据

## 判据速查

| 项 | 本章要求 |
|---|---|
| 案例类型 | 移交层 |
| 数据规模 | 无现成量表；可复现包口径＝数据＋脚本＋门禁＋README 四件 |
| 客群 / SAM | 基层中医馆 / 42,000 |
| 客户数（采用） | 300（隐含渗透 0.714%）|
| 客单 / 回本 | ¥8,000 / 9.2 月 |

## 输出

命题三件式 + 数据锚点 + 基线／消融／失效 + B 端四件 + 客户数与客单判据 + C 端判定 + 合并账 + 缺口。

## 边界

- 缺口须原样写进开题：量表本身需自建并经信度检验，本库不提供信度数据；
- 客户数须写成 SAM×渗透率，不得直接拍数；客单须给营收／IT 预算占比；
- 工时三段为「假设·未实测」，不得去标签；
