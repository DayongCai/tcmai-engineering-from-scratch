## 十一、B／C 合并账与成本分摊

| 共同成本（底本建设） | ¥87,400 |
| B 增量成本（获客＋运维） | ¥24,500 |
| B 三年收入 | ¥2,880,000 |
| C 三年收入 | ¥158,604 |
| C 增量成本（获客×3＋合规） | ¥120,000 |
| **C 增量净** | **¥38,604** |
| **合并净** | **¥2,806,704** |
| 判定 | **加 C** |

| 规则 | C 分摊 | B 净 | C 净 | 合并 |
|---|--:|--:|--:|--:|
| 收入比例 | ¥4,562 | ¥2,772,662 | ¥34,042 | ¥2,806,704 |
| 等分 | ¥43,700 | ¥2,811,800 | ¥-5,096 | ¥2,806,704 |
| 增量法 | ¥0 | ¥2,768,100 | ¥38,604 | ¥2,806,704 |

**最后一列相同，就是恒等式的可视证明**：`合并净 = B净（未摊）+ C增量净 − 共同成本`，与分摊规则无关。

## 十四、三处最常见的退步

- **只写意义不写对象**：说不出「谁每周都要用」，等于没有定位；
- **客户数直接拍**：必须写成 SAM × 渗透率，并给渗透带；
- **把假设当数据**：工时三段与客单都是假设，须标注来源，不得去掉标签。
