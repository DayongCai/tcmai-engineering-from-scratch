# 第 10 章 · 挂点覆盖率的分母没建起来之前，分子毫无意义

> **MOTTO:** 「令可传于后世，必明为之法」——《灵枢·九针十二原》
>
> **PROBLEM:** 知识树五级骨架已入库、条文层 0 条，覆盖率 ＝ 已挂条数 ÷ 条文总数 ＝ 0 ÷ 0。开题报告里若写「覆盖率可达 85%」，那个 85% 没有分母可依，只能是估的。本章要求先把分母建起来，再谈覆盖率；在此之前，一律写「不可算」。
>
> **双根因定位:** 环境逼迫（知识图谱团队与教材数字出版方都需要条文级的挂点，而不是只有骨架）+ 知识积累（五级骨架 schema 已在库，挂点规则可直接按层级定义）

## 一、命题与数据锚点：骨架有了，条文还没有

本章的命题是：**按五级骨架给针灸条文挂点，覆盖率能到多少，哪些条文挂不上**。句子里最容易被跳过的是「条文」两个字——骨架是空的，条文是要一条条进来并挂上去的。跳过它，整章就变成了「设计一套分类法」，而设计分类法不是毕设的工作量所在。

现状摆清：

| 项 | 状态 | 说明 |
|---|---|---|
| 五级骨架 schema | 已入库 | 层级与字段已定义 |
| 条文层 | 未建 | 0 条 |
| 挂点表 | 未建 | 0 行 |
| 覆盖率 | 分母为 0 | 不可算 |
| 未挂清单 | 未建 | 待条文入库后产出 |

0 ÷ 0 这件事必须讲透。它不是「覆盖率为零」，也不是「全部覆盖」，而是**还没有可算的对象**。三种写法在答辩场上后果完全不同：写「0%」会被问「为什么一条都挂不上」，写「100%」会被要求当场演示，写「不可算」则会被问「那你打算怎么建分母」——只有最后一种问法指向真正的工作。

条文层怎么建，要写清三步：选书、切条、编号。选书决定范围，切条决定粒度，编号决定可引用性。三步里最容易糊的是切条：一条条文可能是一句、一段或一节，粒度不同，条数能差好几倍。粒度口径必须在开题时定死，例如「以句为单位，含完整证治者为一条」。

骨架与条文的关系也要说清。五级骨架是**挂点的坐标系**，不是条文本身。条文挂上去，等于给每条条文一个坐标；坐标的价值在于能被检索与聚合，不在于分类是否正确。这个区分很重要：本章不评价骨架分得好不好，只检验条文能不能按它挂上。

## 二、分阶段交付物与分工

| 节点 | 时点 | 必交物 | 责任人 | 签收人 |
|---|---|---|---|---|
| 开题 | 第 1–4 周 | 五级骨架读解说明、切条粒度口径、条文来源清单 | 学生 | 开题小组 |
| 中期 | 第 8 周 | 首批条文表（含编号）、人工挂点抽样、挂点规则 v1 | 学生 | 导师 |
| 预答辩 | 第 12 周 | 自动挂点表、未挂条文清单、错挂案例 | 学生 | 预答辩组 |
| 答辩 | 第 16 周 | 挂点表、未挂清单、挂点规则、复跑记录 | 学生 | 答辩委员会 |

开题的关键是**切条粒度**，不是骨架。骨架已经现成，读一遍就能讲；切条粒度要自己定，而且定完就不能改。定法建议从抽样开始：先切二十条，看看一条的平均长度与信息量，再定「一句一条」还是「一段一条」。抽二十条的成本很低，却能避免中期的返工。

分工上，骨架读解与切条粒度由导师确认，条文切分与编号由学生做，挂点抽检由同学独立完成。抽检为什么不能自己做？因为挂点这件事很容易「自己觉得对」——同一条条文，作者知道它讲的是刺法，就顺手挂到刺法下，而读者可能认为它讲的是穴位。独立抽检能把这种默认知识暴露出来。

中期只要求首批条文与人工抽样挂点。人工挂点是基线的来源：没有人工挂点的二十条做对照，后面说「自动挂点准」就没有参照物。抽样的二十条要覆盖五个层级，不能全挂在最下层——全在最下层，等于只验了一条路径。

## 三、判据与评分维度【教学设定】

移交层判据四条：

| 判据 | 合格线 | 检查方式 |
|---|---|---|
| 条文可数 | 条文表行数可打印 | 跑一次看输出 |
| 编号唯一 | 每条一个号，无重复 | 去重后行数不变 |
| 挂点可查 | 每条有路径与层级 | 抽五条回查 |
| 未挂有清单 | 挂不上的逐条列出 | 清单可数 |

评分维度（教学设定）：

| 维度 | 权重 | 不合格 | 合格 | 优秀 |
|---|--:|---|---|---|
| 命题可判 | 15% | 只设计分类法 | 有覆盖率口径 | 预写挂不上类型 |
| 数据可核 | 25% | 条文数说不清 | 表可打印 | 粒度口径写死 |
| 挂点可复跑 | 20% | 手工逐条点 | 规则可重跑 | 错挂可归因 |
| 评价完整 | 20% | 无人工对照 | 抽样二十条 | 自动／人工差可读 |
| 移交可用 | 20% | 只交表 | 表＋规则 | 附复跑记录 |

评分里「挂点可复跑」这一项，看的是规则能不能重跑，而不是结果对不对。规则重跑指的是：给定同一批条文与同一套关键词，第二次跑出来的挂点表与第一次一致。若两次不一致，说明规则里掺了随机或人工微调，那就不叫规则。

「评价完整」这一项看人工对照的覆盖面。二十条抽样的分布要写清楚：五个层级各几条。若某一层一条都没有，这一层的挂点准确率就是未知的，不能并用总体准确率掩盖。评分时抽到这种表，按「未覆盖」处理，不按「合格」处理。

## 四、记录字段与复算口径

条文挂点台账建议八列：

| 列 | 填什么 | 例 |
|---|---|---|
| 条文号 | 书内唯一编号 | 甲乙经·0231 |
| 书名 | 出处 | 针灸甲乙经 |
| 篇名 | 所在篇 | 卷三 |
| 条文 | 条文原文或首句 | （首句） |
| 挂点路径 | 五级路径 | 经络／手太阴／… |
| 层级 | 挂到第几级 | 4 |
| 挂点方式 | 人工／自动 | 自动 |
| 状态 | 已挂／未挂／待判 | 已挂 |

「挂点方式」这一列决定了后面能不能算消融差。人工挂点与自动挂点混在一张表里，若不标方式，两条路径的结果就没法对照；标了方式，才能算出「自动挂点相对人工挂点，错在哪几层」。

复算口径两条：覆盖率 ＝ 已挂条数 ÷ 条文总数；错挂率 ＝ 错挂条数 ÷ 已挂条数。两条都要求分母不为 0，分母为 0 时写「不可算」。这两条要写在脚本里，与台账同源导出，避免正文与附录两套数。

## 五、失效模式与考核项

| 失效 | 表现 | 拦截 |
|---|---|---|
| 先报覆盖率 | 条文未建就写 85% | 分母为 0 写不可算 |
| 自动挂点错级 | 同义不同级被硬挂 | 抽五条回查层级 |
| 未挂清单缺失 | 只报挂上的 | 未挂逐条列 |
| 粒度漂移 | 前二十条按句、后面按段 | 口径写死 |
| 骨架当结论 | 说「分类体系已建成」 | 只报挂点结果 |

第一条是本章的红线。**覆盖率暂不可算，这一点必须写进开题，不能先报一个数**。先报数最常见的理由是「让开题报告好看一点」，代价是中期无法交差：条文建起来之后，真实覆盖率与开题报的数对不上，作者只能改口径，而改口径比一开始就写「不可算」难解释得多。

第二条要展开。自动挂点最典型的错误是「同义不同级」：条文里出现「刺」，规则把它挂到「刺法」这一层，而条文实际讲的是「某穴的刺法」，应该挂在穴位层。这类错误不会让覆盖率下降，反而会让覆盖率虚高——挂是挂上了，挂错了。所以本章要求错挂率与覆盖率同时报，只报覆盖率的表不算完成。

八条考核项：

- [ ] 能报出「骨架已入库、条文 0 条」的现状；
- [ ] 能解释 0 ÷ 0 为什么不能写成 0% 或 100%；
- [ ] 能说出切条粒度口径；
- [ ] 能交出首批条文表与唯一编号；
- [ ] 能抽出五条回查挂点路径与层级；
- [ ] 能列出未挂条文与原因；
- [ ] 能报错挂率并归到层级；
- [ ] 能说明为何先建分母再谈覆盖率。

### 骨架与条文谁先动

一个常见的顺序错误是先改骨架、再等条文。理由是「骨架不合理，条文挂上去也白挂」。这话在长期项目里成立，在毕设里不成立：骨架一改，前面的挂点全部作废，而条文一条都还没进来，等于用两周时间改了个空架子。

正确顺序是先用现有骨架挂二十条，看它在哪里卡。卡点会告诉你骨架的问题是真问题还是想象出来的问题。多数情况下，真正卡住的只有一两个分支，改这两处即可，不必重做整套。

先挂二十条还有一个好处：它让「骨架」从概念变成可检验的对象。评审问「这套骨架合不合理」，你可以拿出二十条挂点结果说「这三条挂不上，原因如下」，比空谈分类原则有说服力。

### 覆盖率报出来之后要配什么

覆盖率一旦可算，就要同时报「未挂条数」与「未挂原因分布」。只报覆盖率，读者会以为没挂上的都是失败；配上原因，才知道有些条文本来就不该挂。

原因分布通常呈长尾：多数未挂集中在两三类（如跨分支、无对应分支），其余零散。把前两类写清，长尾可以合并成「其他」并注明条数，不必逐条解释。

覆盖率还要注明分母版本。条文层若增删，分母变，覆盖率不可比。写成「本版条文 N 条，覆盖 X%」，读者才知道这个数对应哪一版。

## 代价与边界

1. 条文层未建，覆盖率暂不可算；本章的交付重心是建分母与挂点规则，不是报一个比例；
2. 五级骨架的层级定义为该课既有约定，换一套骨架，挂点结果会变，历史百分比不可沿用；
3. 自动挂点依赖关键词，遇到同义不同级的条文会错挂，错挂率须与覆盖率同时报；
4. 商业侧按本库实例：知识图谱团队与教材数字出版方客群 60 家、取带中位 22.5% 对应 14 家、客单 20,000 元，三年收入 360,000 元，回本 54.2 个月——超出三年窗口，说明该产品适合做项目制交付，不适合订阅制；
5. **免责声明：** 本章为教学与毕设指导用，不构成诊疗建议、标准解释、商业承诺或法律意见；挂点结果不得作为临床取穴或教材编写的依据。
