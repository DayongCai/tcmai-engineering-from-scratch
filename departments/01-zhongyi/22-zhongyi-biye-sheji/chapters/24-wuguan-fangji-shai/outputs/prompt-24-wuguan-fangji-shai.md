# 一案八件

## 用途

把「114 方五官筛——专科中成药的选品依据」做成可复跑、可验算、假设可披露的一次毕设。只写能被第三人复核的项，并标明哪些是假设。

**命题：** 按「方中出现五官专药」筛方，与按「教材主治」筛方，结果差多少？

## 步骤

### 1. 写命题

按「方中出现五官专药」筛方，与按「教材主治」筛方，结果差多少？

### 2. 锚数据

114 方 / 246 味 / 86 味不在中药词表

### 3. 做方法

① 定义五官专药表；② 两条路径各筛一遍；③ 比对交集与差集

### 4. 做评价

基线＝主治筛选；消融＝专药筛选；失效＝专药表太窄导致漏掉经典方

### 5. 定客户数

SAM 200 × 中位渗透 8.0% → 采用 16

### 6. 验客单

无营收锚：仅作内部一致性检查（同类案例客单差异不超过 5 倍）

### 7. 算预算

建设 ¥67,400／获客 ¥3,000／回本 33.8 月

### 8. 判渠道

不做：个人不买选品报告

### 9. 写缺口

五官病名与方剂主治的对应关系需自建，本库无现成映射

## 判据速查

| 项 | 本章要求 |
|---|---|
| 案例类型 | 方法层 |
| 数据规模 | 114 方 / 246 味 / 86 味不在中药词表 |
| 客群 / SAM | 药企与器械 / 200 |
| 客户数（采用） | 16（隐含渗透 8.0%）|
| 客单 / 回本 | ¥25,000 / 33.8 月 |

## 输出

命题三件式 + 数据锚点 + 基线／消融／失效 + B 端四件 + 客户数与客单判据 + C 端判定 + 合并账 + 缺口。

## 边界

- 缺口须原样写进开题：五官病名与方剂主治的对应关系需自建，本库无现成映射；
- 客户数须写成 SAM×渗透率，不得直接拍数；客单须给营收／IT 预算占比；
- 工时三段为「假设·未实测」，不得去标签；
