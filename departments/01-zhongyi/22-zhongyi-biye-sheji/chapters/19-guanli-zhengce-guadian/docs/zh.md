# 第 19 章 · 条文没登记来源，挂上去也是无出处

> **MOTTO:** 「法者，天下之程式也，万事之仪表也」——《管子·明法解》
>
> **PROBLEM:** 政策文本 0 条入库、挂点覆盖率 ＝ 0 ÷ 0；而补源登记至少三项：发文机关、文号、文件校验值。可复算的判据是「已登记文书数 ÷ 计划纳入数」。未登记就落条文，等于每一句引文都没有出处，检索得再准也无法核。
>
> **双根因定位:** 环境逼迫（医院合规岗与管理部门要能按条查政策，而不是靠记忆与转发）+ 知识积累（五级骨架 schema 已在库，挂点规则可直接套用）

## 一、命题与数据锚点：先立登记，再谈挂点

本章的命题是：**政策条文按五级骨架挂点，哪些条款挂不上，挂不上说明什么**。命题看似关于分类，实际第一道关是补源：没有原文，就没有条文；没有登记，就没有出处。

现状与登记字段摆清：

| 项 | 状态 | 说明 |
|---|---|---|
| 五级骨架 | 已入库 | 层级可读 |
| 政策全文 | 0 条 | 需外部补源 |
| 已登记文书 | 0 份 | 待建 |
| 登记字段 | 至少 3 项 | 机关／文号／校验值 |
| 覆盖率 | 0 ÷ 0 | 不可算 |
| 未挂清单 | 待建 | 挂点后产出 |

登记三项各有作用。发文机关解决「谁定的」，文号解决「哪一份」，校验值解决「是不是同一版」。三者缺一，条文就可能在两年后变成「某文件说过」，而无法回查。政策类资料的麻烦正在于此：文件会被修订、废止、替换，若不记校验值，读者拿到的可能是旧版。

所以本章的顺序是**先登记、再落条文、最后挂点**。三步不能颠倒。常见做法是先抓条文、后补登记，结果条文抓了一堆，来源记不清，最后只能整批丢弃重来。宁可慢一步，不要返工一遍。

挂不上这件事要正面处理。政策条文里有大量「监督管理」「组织实施」类条款，它们不属于诊疗、也不属于药事，硬挂进某个分支会让知识树失真。正确做法是保留「未挂」这一类，并在报告里说明未挂的原因。未挂清单不是失败清单，是边界清单。

覆盖率在此前不可报。0 ÷ 0 既不是 0% 也不是 100%，是「还没有可算的对象」。这一条与第 10 章同理，但本章更严：不仅条文未建，连原文都未入。开题时若写「覆盖率可达八成」，等于承诺了一件没有分母的事。

## 二、分阶段交付物与分工

| 节点 | 时点 | 必交物 | 责任人 | 签收人 |
|---|---|---|---|---|
| 开题 | 第 1–4 周 | 纳入清单（文件名／机关／文号）、登记模板、挂点规则 | 学生 | 开题小组 |
| 中期 | 第 8 周 | 已登记文书不少于计划半数、首批条文表、校验值 | 学生 | 导师 |
| 预答辩 | 第 12 周 | 挂点表、未挂清单、挂点规则说明 | 学生 | 预答辩组 |
| 答辩 | 第 16 周 | 登记表、条文表、挂点表、未挂清单、复跑记录 | 学生 | 答辩委员会 |

开题要交纳入清单，而不是「打算找一些政策」。清单里每份文件写清名称、发文机关、文号、获取渠道。写不出获取渠道的，等于没有这份文件，不能进清单。清单规模不必大，十份以内即可，关键是每份都能拿到全文。

分工上，文件选取由导师确认，登记与切条由学生做，校验值由教学秘书复核。校验值为什么要复核？因为它是最容易被跳过的字段：复制一个文件、改个名字，校验值就不同了。复核一次，能拦住「同名不同版」这类错误。

中期要交的是「已登记不少于计划半数」。这个要求看起来是进度指标，实际是风险控制：登记做完一半，就能看出补源是否可行；若一半都拿不到，剩下的一半大概率也拿不到，应及时缩小范围而不是硬撑。

预答辩要交未挂清单。清单里每条写清：条文首句、拟挂层级、未挂原因。原因分三类：骨架无对应分支、条文跨多分支、条文属程序性规定。三类处置不同，不能混成「挂不上」三个字。

### 登记表长什么样

登记表建议五列：文件名、发文机关、文号、发布日期、校验值。五列之外可加「获取渠道」与「备注」，但前五列必填。缺任何一列，这份文件就不算登记完成。

填表时最容易出错的是文号。政策文号有固定格式（机关简称＋年份＋序号），手抄容易漏字或多字。处置办法是照抄原文，不做任何规范化；规范化留给后续处理，登记阶段只求与原文件一致。

校验值建议取前八位即可，够用且便于人工比对。全值太长，写在表里反而没人看；前八位足以区分同名不同版，也能在复核时快速对上。

## 三、判据与评分维度【教学设定】

移交层判据四条：

| 判据 | 合格线 | 检查方式 |
|---|---|---|
| 登记可查 | 每份文件五列齐全 | 抽三份核 |
| 条文可溯 | 每条有文书与文号 | 抽五条回查 |
| 挂点可读 | 每条有路径与层级 | 抽五条看 |
| 未挂有因 | 每条有原因分类 | 清单可数 |

评分维度（教学设定）：

| 维度 | 权重 | 不合格 | 合格 | 优秀 |
|---|--:|---|---|---|
| 命题可判 | 15% | 只说「建政策库」 | 有登记判据 | 预写未挂类型 |
| 补源可核 | 25% | 文件说不清 | 五列齐全 | 校验值可复核 |
| 挂点可复跑 | 20% | 手工逐条点 | 规则可重跑 | 错挂可归因 |
| 评价完整 | 15% | 不报未挂 | 未挂有分类 | 边界可读 |
| 移交可用 | 25% | 只交条文 | 表＋规则 | 附登记与复跑 |

「补源可核」与「移交可用」各占 25%，因为这一章的两件实体产出就是登记表与挂点表。前者证明来源可靠，后者证明分类可用。两件都齐，才算交付；只有一件，只能算半成品。

评分时通常抽三份文件核校验值、抽五条条文回查文号。抽得动，说明表是真的；抽不动，说明表是编的。这个动作很土，但它是唯一能区分「做过」与「看起来做过」的办法。

## 四、记录字段与复算口径

条文台账建议八列：

| 列 | 填什么 | 例 |
|---|---|---|
| 文书号 | 登记表序号 | D-003 |
| 条文号 | 文内条序 | 第十二条 |
| 条文首句 | 前二十字 | （首句） |
| 挂点路径 | 五级路径 | 机构／人员／… |
| 层级 | 第几级 | 3 |
| 挂点方式 | 人工／规则 | 人工 |
| 状态 | 已挂／未挂 | 已挂 |
| 未挂原因 | 三类之一 | 跨多分支 |

「文书号」而不是「文件名」，是为了与登记表对齐。文件名可能重复（同名文件不同年份），文书号是本章赋的唯一编号，回查时不会有歧义。

复算口径两条：登记完成率 ＝ 已登记份数 ÷ 纳入清单份数；挂点率 ＝ 已挂条数 ÷ 条文总数。第二条在条文总数为 0 时不计算，写「不可算」。

## 五、失效模式与考核项

| 失效 | 表现 | 拦截 |
|---|---|---|
| 无登记落条 | 引文查不到出处 | 登记先行 |
| 同名不同版 | 两条引文对不上 | 校验值登记 |
| 硬挂程序条款 | 监督条款挂进诊疗 | 保留未挂类 |
| 覆盖率虚报 | 0/0 写成百分比 | 写不可算 |
| 条文断章 | 只取半句 | 保留首句与条序 |

第三条要展开。程序性条款（如「各级主管部门应当加强领导」）不属于任何业务分支，硬挂会让知识树出现一个「什么都装」的分支，久而久之失去区分力。保留未挂，等于承认骨架的边界；硬挂，等于把边界藏起来。

第五条也值得说。政策条文常以「款」为单位，一句里可能包含两个规范。只取半句，挂点就会偏向其中一半。处置办法是切到「条」为止，不切到「句」；一条一挂，长条可标「跨多分支」，不强拆。

八条考核项：

- [ ] 能报出「原文 0 条、覆盖率不可算」的现状；
- [ ] 能说出登记三项各解决什么问题；
- [ ] 能交出不少于计划半数的登记表；
- [ ] 能抽三份核校验值；
- [ ] 能说出三类未挂原因；
- [ ] 能抽五条回查文号与条序；
- [ ] 能说明为何不硬挂程序条款；
- [ ] 能说明补源前不报覆盖率。

登记表还要解决一个现实问题：同一份文件可能有多个发布渠道（官网、公报、转载）。三处的文本可能一字不差，也可能有细微差异。处置办法是选一个权威渠道作为「正本」，其余只作参考，并在备注里写清正本渠道。这样校验值只需记一次，复核时也不会拿转载版去对正本。

选正本的原则很简单：发布机关的官方渠道优先，其次是国家层面的公报，最后才是转载。原则写进登记模板的说明，后续补源的人就不必每次重新判断。

### 政策库最怕的是「过期还对得上」

政策文件会修订、废止、被新文件替代。库里的条文若不同步，会出现一种很难发现的错误：条文与挂点都对得上，但它引的是一份已经失效的文件。检索时看不出问题，使用者照着做才发现依据没了。

防这种错误的办法是给每份文书加「状态」列：现行、修订、废止。状态不是一次填完的，要定期核。核的频率不必高，一学期一次即可；但必须有，否则库会慢慢变成历史档案。

状态一变，挂点表也要跟着标。已废止文件下的条文保留，但标注「仅作历史参考」，不再参与「现行有效条文」的统计。这个区分让库既保留沿革，又不误导当下使用。
