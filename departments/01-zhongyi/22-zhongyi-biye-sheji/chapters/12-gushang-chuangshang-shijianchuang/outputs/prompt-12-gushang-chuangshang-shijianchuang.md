# 教材不给时点，就别替它编一个 · 提示词

## 用途

给「教材不给时点，就别替它编一个」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「命题与数据锚点：先查教材有没有，再谈要求多少 → 分阶段交付物与分工 → 判据与评分维度【教学设定】 → 记录字段与复算口径」这条链。

## 提示词

```
我在学《中医毕业设计与知识移交》第 12 章「教材不给时点，就别替它编一个」，本章 5 节 / 2,906 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 急救教材里真正带「时间窗」的条目有多少，哪些病只有操作没有时点
   - 分类而非取舍
   - 不计入窗口但保留标记
   - 教材里写过的表述
4. 本章自陈的边界（不得越过）：
   - 教材对部分病种确实不给时点（交给指南），本案例只能报「教材有没有」，不能报「指南要求多少」；
   - 中文时间表述本身模糊，「数日」在不同病种下含义不同，本章只分类不解释；
   - 48 单元、151,733 字是当前切分口径，换版本或换粒度，条目数会变；

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学与毕设指导用，不构成诊疗建议、急救规范解释、商业承诺或法律意见；具体操作以现行规范与所在机构制度为准。
