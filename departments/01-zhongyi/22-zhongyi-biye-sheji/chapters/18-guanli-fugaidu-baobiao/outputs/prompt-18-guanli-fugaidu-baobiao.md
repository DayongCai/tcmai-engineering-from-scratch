# 一案八件

## 用途

把「覆盖度双维报表——院校学科建设的诊断仪」做成可复跑、可验算、假设可披露的一次毕设。只写能被第三人复核的项，并标明哪些是假设。

**命题：** 覆盖率报表用「已建章节／目标章节」一个指标够不够？哪一维会误导？

## 步骤

### 1. 写命题

覆盖率报表用「已建章节／目标章节」一个指标够不够？哪一维会误导？

### 2. 锚数据

全库已建 405 章 / 目标 2,115（口径取 audit 输出）；中医系 208 章、基础医学院 134 章

### 3. 做方法

① 按院系算覆盖率；② 加入「有底本层的学科数」一维；③ 比对两维排序差异

### 4. 做评价

基线＝单一覆盖率；消融＝双维；失效＝章节多的系看起来「完成度高」但底本为 0

### 5. 定客户数

SAM 60 × 中位渗透 22.5% → 采用 14

### 6. 验客单

无营收锚：仅作内部一致性检查（同类案例客单差异不超过 5 倍）

### 7. 算预算

建设 ¥67,400／获客 ¥3,000／回本 38.4 月

### 8. 判渠道

不做：个人不订阅覆盖率报表

### 9. 写缺口

目标章节数本身是排课期估算，不是评估标准

## 判据速查

| 项 | 本章要求 |
|---|---|
| 案例类型 | 方法层 |
| 数据规模 | 全库已建 405 章 / 目标 2,115（口径取 audit 输出）；中医系 208 章、基础医学院 134 章 |
| 客群 / SAM | 院校 / 60 |
| 客户数（采用） | 14（隐含渗透 23.333%）|
| 客单 / 回本 | ¥22,000 / 38.4 月 |

## 输出

命题三件式 + 数据锚点 + 基线／消融／失效 + B 端四件 + 客户数与客单判据 + C 端判定 + 合并账 + 缺口。

## 边界

- 缺口须原样写进开题：目标章节数本身是排课期估算，不是评估标准；
- 客户数须写成 SAM×渗透率，不得直接拍数；客单须给营收／IT 预算占比；
- 工时三段为「假设·未实测」，不得去标签；
