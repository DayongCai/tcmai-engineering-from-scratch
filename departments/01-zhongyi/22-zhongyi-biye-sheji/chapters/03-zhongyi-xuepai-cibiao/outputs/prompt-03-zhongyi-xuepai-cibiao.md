# 一词命中一千四百次，证的是字频不是学派 · 提示词

## 用途

给「一词命中一千四百次，证的是字频不是学派」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「命题与数据锚点：命中次数量的是字，不是主张 → 分阶段交付物：四个节点各交什么 → 判据、评分维度与考核项【教学设定】 → 记录字段与失效模式」这条链。

```

正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
```
