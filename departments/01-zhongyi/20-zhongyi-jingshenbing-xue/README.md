## 一、学科定位

中医精神病学研究的是**神**——神志、情感、行为、认知。它与其它临床课最根本的差别在判据来源：

| 维度 | 内科／外科 | 精神病学 |
|---|---|---|
| 判据 | 化验、影像、体征 | **精神检查**（看、听、问） |
| 量表 | 辅助 | **可辅助参考**（教材明写） |
| 首务 | 辨证 | **安全评估**（自伤／伤人） |
| 疗程 | 以周月计 | 以年计，重维持与康复 |

## 二、计算约定

底本结构化脚本 `scripts/build_jingshen_text.py`（12 章 → 48 单元），口径实测后确定：

**三辨＝病因 / 病机 / 证候表现**，第三项取精神检查可观察项（神志、意识、言语、行为、情绪、幻觉、妄想、自知力、睡眠、纳食）。
实测（154,254 汉字）按单元首位：**病因 40** / 证候表现 8 / 病机 0——**病因占绝对多数**，本课程讲的是「什么在致病」。

**四位面＝症状群四分（神志意识 / 情感情绪 / 行为言语 / 认知睡眠）**，即精神检查的四个域。四条候选实测：

| 候选 | 实测 | 结论 |
|---|---|---|
| **B 症状群四分** | 634 / 651 / 470 / 547（max/min **1.4×**） | **采用**：分布最均，且与精神检查四域同构 |
| A 病类四分（癫/狂/郁/痫） | 622 / 691 / 1,381 / 410（3.4×） | 弃用：郁单极（27/48 单元） |
| C 脏腑四分 | 2,000 / 684 / 492 / 2,427（4.9×） | 弃用：心肾单极 |
| D 病程四分 | 117 / 85 / 111 / 84（计数仅 397） | 弃用：覆盖过稀 |

四套候选实测全留 `standards/jingshen/axis-probe.json`。

## 三、中医 → AI 桥梁

- **多标签分类**：一段精神检查记录 → 四域标签（第 4 章），天然适合多标签任务；
- **状态机**：癫↔狂互转、痫证发作期／休止期、痴呆／谵妄的慢急二分，都是离散状态；
- **风险模型**：自杀风险四层（第 7 章）可落成规则＋特征；
- **边界约束**：第 12 章「主导／辅／监测／特殊人群」是 agent 的权限约束素材。

## 五、五条实测发现（写进正文）

1. **病因居首 11 / 12 章**：唯一例外是第 4 章（诊断，证候表现 278）——**总论讲病因，诊断章讲识别**，这个翻转本身就是课程结构；
2. **第 3 章病因 882，占该章三辨的 71%**：一整个章在讲「什么在致病」；
3. **四位面与精神检查四域同构**：这不是巧合，教材的精神检查与症状描述本来就是按四个域组织的；
4. **引书两极**：癫狂 25 部 42 次（古籍最丰）↔ 治疗 3 部 5 次、痴呆谵妄 3 部 4 次（以现代内容为主）；
5. **每章都带安全条款**：第 5 章（监护与依从）、第 6 章（狂证伤人）、第 7 章（自杀风险）、第 10 章（谵妄查因）、第 11 章（戒断）——精神科的第一性原则是安全。
