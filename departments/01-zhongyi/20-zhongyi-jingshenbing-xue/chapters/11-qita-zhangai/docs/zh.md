# 第 11 章 · 酒、儿童、产妇：三类人各有不能照搬的方

> **MOTTO:** 「妇人脏躁，喜悲伤欲哭，象如神灵所作，数欠伸，甘麦大枣汤主之。」——《金匮要略·妇人杂病脉证并治》
>
> **PROBLEM:** 本章三类人群合计十二个证型：酒依赖四证、儿童两病五证、围产期三证。但真正决定成败的不是这十二个证型，而是一份十条的「禁止照搬」清单——酒依赖三条、儿童三条、围产期四条。比例是 12 比 10。证型选错还有回旋余地，禁忌犯了往往不可逆：给酒依赖者用药酒送服、给多动患儿用含朱砂的成药、给哺乳期产妇用峻猛破血之品，三件事都能在几分钟内做成，后果却要用很久来承担。
>
> **双根因定位:** 环境逼迫（三类人的「自主决定权」各不相同：酒依赖者有渴求而自制力受损，儿童由监护人决定，围产期要同时顾两个人，同一张方子在不同人身上权限不同）+ 知识积累（底本第 11 章四节按「酒依赖—酒精所致障碍—儿童—围产期」排列，本章把三节里散落的禁忌抽出来排成一张表）

## 一、三类人差在哪三处

| 类 | 体质特点 | 决策主体 | 处方约束的核心 |
|---|---|---|---|
| 酒依赖 | 酒湿困脾、湿热内蕴、久则痰瘀与肾虚 | 患者本人，但渴求削弱自控 | 一切含乙醇的送服方式都必须排除 |
| 儿童 | 脏腑娇嫩、肝常有余、脾常不足、肾常虚 | 监护人 | 剂量按年龄体重折算，重镇有毒之品摒弃 |
| 围产期 | 产后多虚多瘀；妊娠期阴血下聚养胎 | 产妇，涉胎儿与婴儿 | 药简量轻、短程，避回乳与破血 |

三行里最有操作价值的是第三列。它把「辨证论治」这件正确的事，压缩成一个可以在开方前逐条核对的动作。

酒依赖的病变重心在脾胃与心肝。酒性辛热而质湿，少饮和血行气，痛饮则伤神耗血、损胃亡精、生痰动火。所以它的演变是一条链：早期酒湿困脾（脘痞、口黏、苔腻），中期湿热痰浊扰心（烦躁、易激、失眠），晚期痰瘀互结、肾虚髓亏（健忘、迟钝、人格改变）。治随链走：分消→清化→化痰→化瘀→扶正。

儿童的关键在五脏的有余不足：肝常有余故易动风，心常有余故神不守舍，脾常不足故易生痰，肾常虚故水不涵木。多动多责之心肾不交与心神不宁，抽动多责之肝风与痰火。这个分法比记病名有用。

围产期的关键在「多虚多瘀」四个字：分娩耗气伤血，阴血骤亏则心失所养、肝失濡润；胞宫瘀血留滞、恶露不畅则气机更郁。所以产后抑郁的方，既要补，又要通，且补不得壅、通不得猛。

## 二、观察项：三类各有各的问法

| 类 | 必问项 | 记录字段 |
|---|---|---|
| 酒依赖 | 饮酒史 | 起始年龄、日饮酒种类与量、晨起即饮有无、最长戒断多久 |
| 酒依赖 | 失控证据 | 是否隐瞒酒量、是否以酒代饭、有无因酒外伤或误工 |
| 酒依赖 | 戒断史 | 有无手抖汗出、有无抽搐、有无震颤谵妄史（决定能否门诊戒断） |
| 酒依赖 | 共病 | 情绪、睡眠、有无以酒解愁而掩盖抑郁 |
| 儿童 | 两地观察 | 学校（上课专注、作业完成）与家庭（作业时长、入睡）分开记 |
| 儿童 | 起病与波动 | 抽动在紧张、疲劳、兴奋时是否加重，专注与睡眠时是否减轻 |
| 儿童 | 共病 | 有无强迫、焦虑、对立违抗、自伤 |
| 儿童 | 环境 | 管教方式、父母冲突、学业负担、屏幕时间 |
| 围产期 | 时间与程度 | 起病于产后第几日；持续多久（短暂波动与持续两周以上要分开） |
| 围产期 | 母婴关系 | 对婴儿是过度担忧、回避，还是厌恶接触 |
| 围产期 | 危险念头 | 有无自杀观念、有无伤害婴儿的意念（必须直接问） |
| 围产期 | 躯体排查 | 甲状腺功能、血常规（贫血）、感染 |

酒依赖第 3 项是全章最关键的一问。「有没有戒断抽搐史、有没有过一次震颤谵妄」——有，就不能门诊戒断，必须住院。这一问决定处置层级，比辨证更早。

围产期第 3 项要直接问，而且要问两件事：想不想伤害自己，想不想伤害孩子。第二件很多医生不敢问，但它恰恰是最需要问的——问出来才能防，问不出来只能等。

## 三、十二个证型与十条禁忌

**酒依赖四证**：酒湿困脾（脘痞恶心、口黏、苔白腻、脉濡缓）治以分消酒湿、温中健脾，葛花解酲汤；湿热蕴结（口苦、目黄溲黄、苔黄腻、脉滑数）治以清热化湿和中，黄连温胆汤合葛花解酲汤；心脾两虚（神疲、心悸健忘、食少便溏、舌淡脉细弱）治以健脾养心，归脾汤；痰瘀互结（呆钝、时烦躁、肢麻震颤、舌暗苔腻、脉弦涩）治以化痰活血开窍，癫狂梦醒汤。

**儿童五证**：多动之肾阴不足肝阳偏旺（五心烦热、舌红少苔、脉细数）治以滋阴潜阳、宁神益智，六味地黄丸加减；多动之心脾两虚（神思涣散而不暴躁、倦怠纳差、舌淡脉缓弱）治以健脾养心，归脾汤；多动之痰火内扰（烦躁冲动、痰多口苦、苔黄腻、脉滑数）治以清化痰热，黄连温胆汤；抽动之肝风内动（眨眼耸肩、烦躁易怒、舌红苔薄黄）治以平肝息风，天麻钩藤饮；抽动之阴虚风动（日久形瘦、五心烦热、舌红少苔）治以滋阴柔肝息风，六味地黄丸合芍药甘草汤。

**围产期三证**：心脾两虚、心神失养（欲哭、心悸失眠、食少便溏、舌淡脉细弱）治以补益心脾、养血安神，归脾汤合甘麦大枣汤；肝郁气滞兼瘀血内阻（抑郁寡欢、胸胁乳房胀满、恶露不净色暗有块、舌暗脉弦涩）治以疏肝解郁、活血化瘀，逍遥散合生化汤；阴血亏虚、虚热内扰（烦热盗汗、口干、舌红少苔、脉细数）治以滋阴清热安神，百合地黄汤合甘麦大枣汤。

**十条禁忌**——开方前逐条核对：

| 类 | 禁／慎 | 理由 |
|---|---|---|
| 酒依赖 | 服药期间绝对禁酒；忌以药酒、醪糟送服；避免含乙醇的口服制剂 | 加重肝损，或诱发戒断 |
| 酒依赖 | 不带药让患者自行骤停断饮 | 骤停是戒断抽搐与震颤谵妄最常见诱因 |
| 酒依赖 | 肝损害者慎用苦寒败胃与破血伤肝之品 | 需定期复查肝功能 |
| 儿童 | 含朱砂、雄黄之剂与金石重坠之品（如朱砂安神丸、磁朱丸类）一律禁用或慎用 | 重金属蓄积损伤稚体 |
| 儿童 | 虫类药（全蝎、蜈蚣等）小量、短程、中病即止 | 辛温走窜、性猛有毒 |
| 儿童 | 剂量按年龄与体重折算，药味精简 | 脏腑娇嫩，不耐峻药 |
| 围产期 | 峻猛活血破血之品（三棱、莪术、水蛭等）不用 | 产后出血风险 |
| 围产期 | 峻下逐水之品不用 | 伤正，损津液 |
| 围产期 | 含朱砂、雄黄等毒性或重金属成分之药不用 | 可经乳汁影响婴儿 |
| 围产期 | 含大剂量麦芽之剂慎用 | 有回乳之虞 |

**三条红线：**

1. **震颤谵妄**——断饮后出现意识模糊、定向障碍、鲜明恐怖的幻视幻触、粗大震颤、发热、心动过速、大汗，属精神科与内科共同处理的急危重症，须立即转诊，以补液、纠正电解质、补充维生素 B1、苯二氮䓬类替代递减等规范处置为主。**不得仅予汤药观察。**
2. **自杀与伤婴**——产妇出现自杀观念或行为、明显伤害婴儿的意念，或幻觉妄想、言语行为紊乱等产后精神病表现，须立即护送精神科急诊，专人看护，确保母婴双方安全。
3. **儿童冲动自伤、抽动致自伤，或严重共病情绪障碍、强迫症状**——请儿童精神科评估，必要时住院。

**以上分档与转诊条件为【教学设定】，用于课堂推演；实际处置以所在机构制度与专科会诊为准。**

## 四、干预动作与停止条件

**酒依赖。** 第一要务是彻底戒酒，药物只做分消酒湿、健脾和胃、清化湿热、化痰安神、补益心肾。戒酒须在医师指导下有计划地进行，重症一律住院戒断——既往有戒断抽搐或震颤谵妄史者、年老体弱者、合并严重躯体疾病或妊娠者，均属住院指征。恢复期以六君子汤合生脉散健脾益气、养阴和胃，配酸枣仁、远志、茯神安神。心理侧用动机访谈，尊重、非评判，与患者商定戒酒目标，切忌说教与强制断饮。

**儿童。** 治疗目标是改善核心症状、减轻共病损害、保护学习与人际功能，不是「快速安静」。汤剂浓缩取汁、少量多次温服，与进食间隔半小时以上，苦味重者可加饴糖矫味。针灸取百会、四神聪、神门、内关、足三里、太冲、风池，配合耳穴与行为干预。家庭侧三件事：不因抽动打骂呵斥、不当面数落；保证睡眠、控制屏幕时间；主动与学校沟通，形成家庭—学校—医院协同。

**围产期。** 三证三方（见上）。筛查可在产前检查、产后访视与产后检查时用相应量表初筛，阳性者转精神科评估，同时排查甲状腺功能与血常规。情志调护与家庭支持不可省：分担夜间照护、多倾听少指责、帮助恢复规律作息。

**停止条件**：

- 酒依赖者服药期间饮酒、或出现震颤谵妄征象——停止门诊处理，转急诊；
- 酒依赖者肝功能异常加重——停用苦寒与破血之品，复查肝功能；
- 儿童服药后出现过敏、明显食欲减退或嗜睡——减量或停药并复诊；
- 哺乳期确需抗抑郁西药者，须由精神科与产科、儿科共同权衡并告知产妇，不可自行服药或擅自停药；
- 产妇出现自杀或伤婴意念——停止一切非急救流程。

### 四种把这件事做坏的固定方式

**把神志病当思想问题。** 酒依赖上是「意志不坚定」，儿童上是「家长没管好」，围产期上是「矫情、月子里想太多」。三句话的共同后果，是把可干预的状态推到无人干预。

**用酒送药。** 药酒、醪糟、含乙醇的口服制剂——都属同一类错误，且往往由「这也是中药」的善意发起。

**照搬成人方。** 把成人剂量按比例缩小就给儿童，或把平时的活血方直接给产妇。判据：处方前有没有逐条走过那十条禁忌。

**漏问伤婴意念。** 只问「有没有想不开」，不问「有没有想过伤害孩子」。后者是围产期特有的风险，不问就永远不会被报告。

## 代价与边界

- 十二证是主要证型，不是全部；三类人群虚实夹杂者多，方药须随证化裁。
- 方名只作示例，**不给剂量、不给煎服法、不给疗程**；儿童剂量折算与围产期用药尤须由医师按规范决定。
- 酒依赖、注意缺陷多动障碍、抽动障碍、围产期抑郁均为现代诊断，须由精神科或相应专科医师依规范作出；中医病证与之是「对应」而非等同。
- 本章不提供患病率、复发率、疗效数字；凡涉比例须回原始研究，不得据以作个体判断。
- 震颤谵妄、韦尼克脑病、柯萨可夫综合征等属现代医学诊断与处置范畴，本章只作识别提示，不提供急救方案。
- 量表（如产后抑郁筛查工具、戒断评估工具）结果仅可辅助参考，须人工复核。
- 引文只到「书名·篇名」，不引页码、不引版次。
