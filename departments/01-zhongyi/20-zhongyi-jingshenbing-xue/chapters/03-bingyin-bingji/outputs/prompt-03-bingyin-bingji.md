# 七情不是「想不开」，是气机停在了某个方向 · 提示词

## 用途

给「七情不是「想不开」，是气机停在了某个方向」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「病因有先后：情志为始，痰瘀为中，禀赋为底 → 观察项：把一句情绪话译成六格之一 → 成组判据：虚实先分，痰火与痰气再分 → 干预动作与停止条件」这条链。

## 边界

本章为教学整理，不构成诊疗建议。出现意识改变、中毒或外伤后新发精神症状、躁动伤人、自伤自杀意念、木僵拒食者，须立即就医或转精神科急诊；具体操作以现行规范与所在机构制度为准。
