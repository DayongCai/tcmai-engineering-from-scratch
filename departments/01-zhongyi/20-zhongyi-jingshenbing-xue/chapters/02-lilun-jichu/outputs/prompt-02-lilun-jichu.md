# 三层归属

## 用途

脑是载体，心是枢纽，五脏是分工。**三层都给答案，不是三选一。**

## 步骤

### 1. 物质层

脑（髓海）是否受累

### 2. 功能层

心（神明）是否失守

### 3. 分工层

归到神／魂／魄／意／志中的哪一个

### 4. 形神

形病致神病，还是神病致形病

## 判据速查：五神对应的常见症状

| 神 | 常见症状 |
|---|---|
| 神（心） | 健忘、失眠、神志恍惚 |
| 魂（肝） | 多梦、易惊、幻觉 |
| 魄（肺） | 感觉异常、悲忧善哭 |
| 意（脾） | 思虑过度、注意力差 |
| 志（肾） | 意志减退、恐惧、记忆衰退 |

按这五格问一遍，症状就有了归属，辨证也有了下手处。

## 输出

① 三层归属；② 形神方向；③ 可用的治法落点。
