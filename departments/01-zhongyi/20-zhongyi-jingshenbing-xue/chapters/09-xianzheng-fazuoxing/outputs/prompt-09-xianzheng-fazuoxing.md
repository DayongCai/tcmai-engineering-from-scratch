# 发作的那几分钟，决定后面所有的用药纪律 · 提示词

## 用途

给「发作的那几分钟，决定后面所有的用药纪律」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「痫证的三要与五因 → 发作记录：一张表决定后面所有的判断 → 五个证型，与一条不可协商的时间线 → 现场六步与用药纪律」这条链。

## 边界

本章为教学整理，不构成诊疗建议。发作持续不止、反复发作而意识不恢复、发作中受伤、首次发作、妊娠期发作，均须立即呼叫急救或转神经科、急诊；具体操作以现行规范与所在机构制度为准。
