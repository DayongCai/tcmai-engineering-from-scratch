## 四、这门课的读法

读医学史最容易犯两个错：**用现代概念倒推古代**（把「辨证论治」当成自古如此的体系）、**把传说当史实**（三皇五帝、神农尝百草）。
本课的处理：

1. 人物与著作按**可考的成书年代**排，传说部分标注「传说」并说明其史学功能；
2. 制度沿革（太医署、医政、教育）单列，因为制度决定了知识怎么传；
3. 疾病与诊疗只写教材所述，**不用现代病名反推古代证候**。
