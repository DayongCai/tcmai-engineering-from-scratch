# 争鸣不是意见多：一个新说要能被反驳，还得交出一条转化规则 · 提示词

## 用途

给「争鸣不是意见多：一个新说要能被反驳，还得交出一条转化规则」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「建制先于争鸣：统一教材反而造出了争论 → 一个新说的两个条件 → 四家的对手各是谁 → 宋慈与专科：另一条不靠争鸣的线」这条链。

## 提示词

```
我在学《中国医学史》第 5 章「争鸣不是意见多：一个新说要能被反驳，还得交出一条转化规则」，本章 5 节 / 2,887 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 「什么是对的」被写成了文本
   - 没有定本，就没有异说；异说只是各说各话
   - 条件一：这个立场必须可以被反驳
   - 条件二：它必须交出一条转化规则
   - 一个可反驳的命题 + 一条从现象推到治法的规则
   - 标签可以背，对手不能背
4. 本章自陈的边界（不得越过）：
   - 本章所引四家主张依底本的概括，四家原书本章未引原文；凡「主寒凉」「主攻邪」一类表述，属后世医史的通行概括，非原书语句。
   - 本章不给四家生卒年与著作卷数。凡底本未载者本章不补，凡底本所载者引用时须注明「底本所述」。
   - 本章不判定四家主张的对错。学派分歧多数是适用域之争，判定对错需要临床证据，本章不提供。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为中国医学史宋金元部分的教学整理，医家主张与著作性质均转自课程底本，未核对四家原书；具体操作以现行规范与所在机构制度为准。
