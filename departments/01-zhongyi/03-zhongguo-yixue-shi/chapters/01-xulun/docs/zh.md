# 第 1 章 · 医学史不是年表：分期方案一换，同一批材料就讲出不同的故事

> **MOTTO:** 「方技者，皆生生之具，王官之一守也」——《汉书·艺文志》
>
> **PROBLEM:** 底本给出两套分期：一套按社会形态分五段（原始、奴隶、封建、半殖民地半封建、社会主义），一套按学术自身脉络分九段（起源、先秦、秦汉、魏晋南北朝、隋唐、宋金元、明清、近代、当代）。本课程只有八章。八章无法同时对齐五段与九段，也就是说，每一章的边界都是取舍的结果，不是历史本身的分界。本章要回答的是：既然边界是人为的，凭什么说这个分法比另一个分法好。

**双根因定位:** 环境逼迫（一部通史要在一学期内讲完数千年，必须切段；而切段一旦做出，后面所有的人物、著作、事件都按段归位，段错则全篇错）+ 知识积累（中国医学既有随王朝更替而变的制度面，也有不随王朝更替而变的学术面；两套节奏不同步，分期问题才真实存在）

**底本：** `standards/zhongguo-yixue-shi/units.json`（8 内容章 / 51 单元 / 94,294 汉字）；本章取第 1 章 3 个单元、5,344 汉字。

## 一、两套分期对不上，八章只能选一条线

分期是社会形态与学术脉络两条线的妥协，而两条线的节点并不重合。

社会形态那条线以生产关系变革为界：原始社会医药萌芽，与采集渔猎相伴；奴隶社会（夏、商、西周）医事活动渐趋专门化，医与巫逐渐分离，《周礼》所载医师掌医之政令，并见食医、疾医、疡医、兽医的分科雏形；封建社会绵延两千余年，是体系形成、发展、成熟与集大成的时期；鸦片战争后进入半殖民地半封建社会，西医大规模传入；此后是社会主义社会。五段，每一段的界线都由政治史给出。

学术脉络那条线以理论建构与临床进步为界：起源、先秦、秦汉、魏晋南北朝、隋唐、宋金元、明清、近代、当代。九段，每一段的界线由医学自身的变化给出。

两条线在秦汉、隋唐、明清几处大致重合，在魏晋南北朝与宋金元两处则不合。魏晋南北朝在政治史上是一个分裂动荡期，在学术史上却是专科文献大量涌现的时期——《脉经》《针灸甲乙经》《肘后备急方》《本草经集注》相继问世。若按社会形态讲，这一段只能写成「动荡中的发展」；若按学术脉络讲，它是「专科化与文献整理」的起点。**同一个三百年，两种讲法的重心完全不同。**

本课程的八章取的是学术脉络那条线，并在两处作了合并：把「起源」与「先秦」的一部分并成一章，把「近代」与「当代」并成一章。合并的理由不是历史，是课时。

这就带出第一条判据：**任何分期都要说明它是按什么分的，以及为此丢掉了什么。** 按学术脉络分，丢掉的是制度与社会条件——同一时期为什么恰恰出现这批书，靠分期答不出来；按社会形态分，丢掉的是学术自身的节奏——为什么分裂时代反而出专科书，也答不出来。承认丢掉的部分，比声称分法客观更有用。

## 二、史料分四级，级别决定它能证明什么

医史的材料不是一个平面。按可靠性可以分四级，每一级能支撑的结论不同。

第一级是**一手文献**：当时的著作、当时的记录。医籍原文、正史的《方技传》与《艺文志》、诏令、碑刻、方志，都属这一级。底本说文献研究法包括目录、版本、校勘、训诂四门，加辑佚与辨伪，落点都在这一级——「医家生卒、著作年代、学术史实等，均须有明确的文献依据，做到言必有据、信而有征」。

第二级是**出土材料**：马王堆帛书《五十二病方》《足臂十一脉灸经》，张家山汉简《脉书》《引书》，武威汉代医简，殷墟甲骨卜辞中的疾首、疾腹。这一级的特点是**未经后人改动**，因此对「当时实际水平」最有说服力；局限是残断、无编者、无年代自述，断代要靠考古层位与字体。

第三级是**转述**：后人书里记载的前代之事。皇甫谧记扁鹊，王冰述师传，李时珍考药名源流，都属这一级。转述可能准确，也可能走样；判据是能否找到更早的源头。

第四级是**传说**：神农尝百草、岐伯问答、长桑君授禁方。这一级不能当史实用，但可以做另一件事——说明当时人如何理解医学的来源。

四级之间不是高下之分，是**用途之分**。第一级能证「有什么」，第二级能证「实际做到什么」，第三级能证「后人怎么理解」，第四级能证「当时人怎么想象」。用错级别，结论就悬空：拿传说证「商代已有本草」，是第四级当第一级用；拿甲骨卜辞证「商代医学理论成熟」，是第二级当第三级用，过度解释。

底本特别强调出土与传世的互证：马王堆帛书所载十一脉系统与《灵枢·经脉》十二脉系统可以对照，这种对照能看出经脉学说从十一到十二的演进——这是第二级与第一级互证产生的结论，任何单独一级都给不出。

## 三、叙事与考证的分界：一句话凭什么进史

写医学史最常犯的错，是把叙事当考证。两者的区别可以用一句话检验：**这句话的证据在哪里，谁在什么时代以什么形式记下它。**

叙事的句子长这样：「扁鹊是战国时期最著名的医学家，精通望闻问切，能起死回生。」句句都像结论，但没有一句能指向证据。考证的句子长这样：「《史记·扁鹊仓公列传》记扁鹊望齐桓侯之色而知病，同书记其治虢太子『尸蹶』，以厉针砥石、熨胁服药而苏；传末又记其『过邯郸，闻贵妇人，即为带下医』，随俗为变。」

第二种句子有两个特征：一，每个判断都挂在具体的篇上；二，它不回避材料本身的性质——同一篇里既有诊籍式的操作记载，也有「忽然不见，殆非人也」的神异情节。

底本对「病入膏肓」「六气致病」这类著名故事的处理值得注意：它把这些记载放进「先秦阶段」的学术脉络里，说明它们反映了当时对疾病的认识水平，而不是把它们当作某位医家的个人事迹来渲染。这是史学的写法：**故事的价值在于它透露的观念，不在于它是否真发生过。**

由此得出第二章要用的判据：一句医学史的话要进正文，必须能回答三问——出处在哪一篇、这条材料属哪一级、它能证明什么。三问有一问答不出，这句话就只能放进「传说」或「待考」。

## 四、记录字段与三种失效

写一条医史判断，记录格式如下：

```
医史条目卡（一事一条）
① 事件：（一句，含时代、主体、行为）
② 出处：（书名·篇名；版本或整理本）
③ 史料级别：（一手／出土／转述／传说）
④ 年代依据：（纪年出处；无明确纪年须写「据某推」）
⑤ 旁证：（第二条独立材料；无则写「孤证」）
⑥ 可证与不可证：（一句各一）
```

④与⑤是这张卡的关键。④栏要求写出年代依据，是因为医史里最含糊的正是年代：一个人的生卒多不可考，一部书的成书多跨数十年，一个制度的起始往往只见于后世追述。写「据某推」比写一个精确年号更诚实。⑤栏要求第二条独立材料，是因为孤证在医史里极常见——某医家的事迹往往只有一篇传，某部书只有一条著录。

三种失效模式可以定点排除。

**以传说代史实。**「神农尝百草，一日而遇七十毒」被写成「神农发现了七十种有毒药物」。判据：这条材料属第四级吗？属，就只能写「传说反映了先民以身试药的记忆」，不能写具体数字与具体人名。

**年代不清。**《黄帝内经》非一时一人之作，若写成「某年成书」，就把一个跨数百年的编纂过程压成了一个点。底本对《内经》成书的处理是「通过考辨其语言文字、天文历法、职官制度等文献内证，结合先秦两汉的学术背景加以推断」——这是正确写法：给依据，不给假精确。判据：这个年代是材料自带的，还是你推出来的？推出来的，必须写「推」。

**以今评古。** 说某一时代的医学「落后」「不科学」，用今天的标准去评古代的实践。判据：这个评价用的是哪个时代的标准？用今标准评古实践，得到的只是今人的态度，不是历史判断。底本在「不做的事」里明确列了这一条：不作医学价值判断（某朝代医学「先进／落后」）。

## 五、考核项

1. 分别按社会形态与学术脉络为「魏晋南北朝」写一句分期说明，指出两套说法各自丢掉了什么。
2. 说明本课程八章相对底本九段的合并处，并指出合并的依据是历史还是课时。
3. 给下列四条材料各标级别并说明它能证明什么：甲骨卜辞疾首、马王堆帛书《五十二病方》、《史记·扁鹊仓公列传》、神农尝百草。
4. 把「扁鹊是战国时期最著名的医学家，能起死回生」改写成一句可核的考证句，须含出处与史料级别。
5. 说明《黄帝内经》成书年代为何不宜写成精确年份，并给出底本所用的推断依据类型。
6. 指出下列哪一条属「以今评古」：某朝代医书多述鬼神，故其医学不科学。

评分只看：③④⑤三栏是否填实，⑥栏是否写出「不可证」的一面。只写结论不写级别的，按未考处理。

## 代价与边界

1. 本章的分期说明取学术脉络一条线，并按课时合并两处；这不是唯一正确的分法，社会形态分法在同一批材料上同样成立，只是重心不同。
2. 本章不给任何医家生卒年与著作成书年的判定。凡底本未明确纪年者，本章不推；凡底本所载者，引用时须注明「底本所述」。
3. 传说层材料本章只作观念史用，不作事实用；这不等于否定传说所反映的早期经验，两件事必须分开。
4. 本章不评价各时代医学的高下。医学史的任务是说明它如何发生，不是给它排座次。
5. 本章不涉及诊疗判断与方药。史学的结论只关于过去，不构成任何现实建议。
