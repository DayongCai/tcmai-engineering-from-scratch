# 第 2 章 · 起源不是某个人的发明：四类证据各只答得上一半

> **MOTTO:** 「其病皆为痈疡，其治宜砭石」——《素问·异法方宜论》
>
> **PROBLEM:** 本章底本 3 个单元、4,968 汉字，标为【原文】的引文块 18 处，全部出自《淮南子》《韩非子》《吕氏春秋》《说文解字》《山海经》《世本》《周礼》《素问》等后世追述之作，没有一处出自医药起源的当时。也就是说，讲「医药怎么起源」这段历史，可用的文字材料全是几百年乃至上千年后的追记。真正能直接对应起源时期的，只有考古实物与民族学调查两类。本章要回答的是：在这种材料结构下，能写什么、不能写什么。

**双根因定位:** 环境逼迫（「神农尝百草」人人会说，说起来像史实，而它其实是战国的追述；不把这条界线划清，整章就退化成神话故事）+ 知识积累（考古学提供了实物与层位，民族学提供了类比模型，文献学提供了观念记录；三类材料的能力边界不同，互证才成立，互相替代就出错）

**底本：** `standards/zhongguo-yixue-shi/units.json`（本章取第 2 章 3 个单元、4,968 汉字）。

## 一、四类证据，四种不同的回答

底本开篇即把材料结构说清楚了：考察医药起源，「主要依据考古发掘的实物资料、民族学调查材料以及先秦文献中的传说记载，通过多学科的综合研究加以推断」。三类材料，加上制度类的文献，共四种回答能力。

考古实物回答「有什么、什么时候有」。新石器时代遗址出土砭石、骨针、陶针，形制与后世针具相近；山顶洞人遗址出土骨针，说明已能缝制兽皮衣物；周口店北京人遗址的灰烬层说明已能使用并保存火种。这些物件的年代由地层与共存关系给出，不依赖任何文字。

民族学调查回答「可能是怎么发生的」。考察近现代仍处于较原始发展阶段的民族，看他们如何辨认草药、如何处理创伤，可以推想远古经验积累的一般过程。这一类的力量在**类比**，限度也在类比：类比能提出可能，不能证明曾经。

文献追述回答「后人怎么理解起源」。《淮南子·修务训》「神农……尝百草之滋味，水泉之甘苦，令民知所辟就。当此之时，一日而遇七十毒」；《韩非子·五蠹》「民食果蓏蚌蛤，腥臊恶臭而伤害腹胃，民多疾病。有圣人作，钻燧取火以化腥臊」；《吕氏春秋·古乐》「民气郁阏而滞着，筋骨瑟缩不达，故作为舞以宣导之」。三条都是战国人的话，讲的是远古，写的是战国的关切。

制度文献回答「什么时候开始有分工」。《周礼·天官》「医师掌医之政令，聚毒药以共医事」，下设食医、疾医、疡医、兽医，并建立岁终考核、据治愈情况定俸禄的制度。

四种回答不能互相顶替。用《淮南子》证「神农确有其人」，是把第三类当第一类；用骨针证「当时已有针灸理论」，是把第一类当第三类，过度解释。底本的态度很稳：它把「神农尝百草」明确标为传说，同时说「传说之中含有合理的内核」——把药物发现归之于亲身尝试、反复试验，与劳动实践说的基本精神吻合。**传说在这里的用处，是提供一个可解释的模型，不是提供事实。**

## 二、考古给年代，文献给观念：两条线不重合

底本列了诸种起源说，其中「劳动实践说」最通行，理由是它得到考古学与民族学材料的支持。其余诸说各有依据，也各有局限。

「医源于巫」说的依据是文献：《说文解字》释「巫」为「祝也。女能事无形，以舞降神者也」，《吕氏春秋·勿躬》有「巫彭作医，巫咸作筮」，《山海经·海内西经》记巫彭、巫抵、巫阳等「皆操不死之药以距之」。这些记载都带神话色彩。底本的处理方式是：不把「医源于巫」当成起源的唯一定论，而把它理解为**历史阶段性**——在医学尚未独立的阶段，医事确曾与巫术长期结合，巫师往往兼为最早的医者。它反映的是「医巫不分」这个状态，不是「医药知识由巫术凭空产生」。

「医源于酒」说的依据是双重的：文献有《世本》「仪狄始作酒醪，变五味」，考古有贾湖遗址陶器内壁的酒类遗存与大汶口、龙山文化的大量酒器；文字上，《说文解字》释「醫」为「治病工也。从殹从酉」，并说「酒所以治病也」。三条材料互相补位：考古证「有酒」，文字证「醫与酒相关」，文献证「后人如此解释」。这与「医源于巫」只有文献一条支撑，可靠度不在一个层级。

讲这一段最该学的是**排序**：先给考古能做到的（有酒器、有砭石、有火塘），再给文献说了什么（仪狄、神农、巫彭），最后给推断（所以起源是多源的）。倒过来讲，先给推断再找材料，就变成了用材料凑结论。

底本最后一句可以当成本章的判据：「医药起源非止一途，劳动实践、巫术宗教、酒与针砭诸说从不同侧面揭示了早期医药的多重源头，传说与考古互证，方能接近历史真相。」「接近」两个字用得准确——它没说「还原」。

## 三、卜辞与《周礼》：最早的制度，与它的释读风险

商代这一段，材料性质突然变硬了：甲骨卜辞是当时的文字，不是后人的追述。底本把它的价值说得很清楚——「是研究商代医药活动最可靠的文字史料」。

卜辞能给的东西很具体。病名多冠以「疾」字，按部位分：疾首、疾目、疾耳、疾齿、疾腹、疾足、疾肘、疾身；「疾齿」之「龋」象虫蛀牙齿之形，是关于龋齿的早期文字记载；另有蛊、疟、风等病名，以及关于疾年、雨疾的占卜。医疗活动方面，卜辞常见「御疾」「禳疾」一类祈求之辞，反映医巫不分的状态；同时也有用药、针刺、按摩的痕迹。卫生方面，卜辞有沐、浴、洗、沫等字，帚、洒等字说明居室洒扫为日常之务。

但卜辞有一条硬限制，底本专门点了出来：**释读历来存在分歧，学者对若干字形的考释意见不一，引用时当以经过考释的通行释文为据。** 这句话的分量在于它承认了「一手材料也要经一道解释」。甲骨文不是拿来就能读的，每一个字的认读都是研究结论；不同学者的释读不同，同一片卜辞可以读出不同的病名。所以引用卜辞，实际上引用的是「某家的释文」，不是「甲骨本身」。

《周礼》这一段则是另一种材料问题。它记的是制度：「医师掌医之政令，聚毒药以共医事」，下设疾医、疡医、兽医分科主治，岁终考核、据治愈情况定俸禄，底本称这是「我国最早的医事制度记载」。《周礼》的成书年代本身有争议，它所述制度有多少是西周的实况、有多少是战国的理想，学界看法不一。因此写这一段要留一分余地：**它可以证「至晚在《周礼》成书的时代，人们已经如此设想医事分工」，不宜直接证「西周已实行此制」。**

三类材料的能力差别，到这里就很清楚了：卜辞证「当时有什么」，但受释读限制；《周礼》证「有这样一种制度设计」，但受成书年代限制；传说证「后人如何想象」。三者混用，任何一条都会出错。

## 四、记录字段与三种失效

写早期医学的条目，记录格式如下：

```
早期医史条目卡（一事一条）
① 事项：（时代 + 主体 + 行为，一句）
② 材料类型：（考古实物／民族学类比／当时文字／后世追述／制度文献）
③ 出处：（书名·篇名，或遗址·器物；释文须注家）
④ 年代依据：（地层、共存器物、字体，或文献纪年；无则写「推」）
⑤ 能证：（一句，限定在材料类型的能力内）
⑥ 不能证：（一句，写明越界的方向）
```

②③两栏配套使用。同一件事常有两类材料：酒有考古（陶器残留）与文献（《世本》），写卡时两栏都要填，④栏分别给年代依据。⑤⑥是这张卡的用处：它逼你把「能证」缩到材料允许的范围内。

三种失效模式因此可以定点排除。

**以传说代史实。** 把「一日而遇七十毒」写成统计，「七十」被当成确数；把「巫彭作医」写成「巫彭创立了医学」。判据：这条材料属「后世追述」吗？属，⑤栏就只能写「反映战国人对医药起源的理解」。

**年代不清。** 把考古年代与文献年代混成一个：「神农时代」「黄帝时代」是最典型的混法——它们既是传说人物，又被当作纪年单位。判据：这个年代是器物地层给的，还是文献追记给的？后者只能写成「传说中」。底本讲《黄帝内经》成书时用的办法是「考辨其语言文字、天文历法、职官制度等文献内证」，这是给推断依据，不给假精确，可作范本。

**以今评古。** 说卜辞「只记部位不记病理，说明商代医学很原始」，或说「御疾、禳疾是迷信，毫无价值」。两种说法都用今天的学科标准去裁量古代材料。判据：这个评价是否假定了一种「应该有的样子」？有，就是把今人的分类当成了历史的标尺。底本的处理是描述性的：巫术与经验并存，「正是早期医药活动的基本面貌」。

评分只看：②③是否配套、⑤⑥是否划出边界。把传说与考古写在同一条⑤栏里的，按未考处理。
