# 第 2 章 · 用字关系分不清，训释就只是猜：通假、古今、异体、讹字各是一条证据

> **MOTTO:** 「名定而实辨，道行而志通」——《荀子·正名》
>
> **PROBLEM:** 本章底本 11 个单元、23,483 汉字，标为【原文】的引文块 36 处，出现书名 97 种。36 处引文里，同一个概念被写成不同的字：藏与脏、府与腑、写与泻、支与肢、蚤与早、被与披、内与纳。这些字若一律按「错字」处理，原文就被改坏了；若一律按「本字」处理，句子又读不通。36 块引文里究竟哪几处是借字、哪几处是后造本字、哪几处是抄刻之误，是本章要给出的分辨程序。

**双根因定位:** 环境逼迫（医经成书于先秦两汉，传世之本多存古字，读者手上却是一部用现代规范字排印的通行本，古字已被改写或径改，看不出原貌）+ 知识积累（清代考据学把用字关系分成通假、古今、异体、讹字四类，并各配一套证明条件；这套分类不是术语游戏，而是四种不同的证据要求）

## 一、四类关系，四张不同的证据单

初学者最容易把「这个字看着不对」统统归为通假。四类关系的性质完全不同，证明方式也不同。

| 关系 | 性质 | 借字与本字有无意义关联 | 证明要求 |
|---|---|---|---|
| 通假 | 共时书写借用，本有其字而不用 | 无 | 本字可考、声音可通、文义可安 |
| 古今字 | 历时造字分化，先造为古、后造为今 | 有，音义相承 | 指明分化所分担的义项 |
| 异体字 | 同一时期的不同写法 | 音义全同 | 可互换而不改义 |
| 讹字 | 传写刊刻之误 | 无，属无心之失 | 须出校改正并说明依据 |

通假以声音为枢纽。底本举「蚤」通「早」，出自《史记·扁鹊仓公列传》「使圣人预知微，能使良医得蚤从事，则疾可已，身可活也」；蚤本义跳蚤，借为早，蚤、早上古同属幽部。「被」通「披」，《素问·四气调神大论》「被发缓形」，被、披同属歌部。「卒」通「猝」，《素问·玉机真脏论》「其卒发者，不必治于传」，卒、猝同属物部。「内」通「纳」，《伤寒论》小建中汤方「内饴，更上微火消解」，诸方「内诸药」皆是加入之义，不可误读为内外之内。「居」通「倨」，《素问·平人气象论》「前曲后居，如操带钩」。「僻」通「避」，《灵枢·本神》「僻邪不至」，而同书《素问·上古天真论》「虚邪贼风，避之有时」正用本字——这一对本字与借字并见于两部经典，是通假最硬的证据形态。

古今字则相反，古字与今字之间有字源与意义的相承。《素问·五脏别论》一句话里并用了三个古字：「所谓五藏者，藏精气而不写也」「六府者，传化物而不藏」「藏」本是收藏，「府」本是府库，「写」本是倾注；后来各加意符，造出脏、腑、泻三字分担其义。同类还有支与肢（「四支皆禀气于胃」）、亦与腋、要与腰、俞与腧。段玉裁《说文解字注》说「古今无定时，周为古则汉为今，汉为古则晋宋为今」，这句话点明古今字是相对的时间关系，不是绝对的新旧。

判据因此很干脆：**看两字之间有无字源与意义的相承。** 有，是古今字，处理办法是注明「古字某，今字某，分担某义」；无，才考虑通假；音义全同而只是写法不同，是异体，不必改字；形近音近而义不可通、且仅见于某一传本，才判为讹字。

四类之中，通假最容易被滥用。底本给出的三道门槛值得原样记住：本字可考、声音可通、文义可安，三者缺一不可。凡文义本来可通而强立通假之说，是把读者自己的不懂，写成古人的借字。

## 二、词义的三条移动路线，与一类不能拆的词

用字关系解决「写成什么字」，词义问题解决「这个字在这里是哪个义」。后者有三条常见路线。

词义扩大：由专指变为泛指。词义缩小：由泛指变为专指，「臭」古义泛指气味，《素问·金匮真言论》「其臭焦」，读 xiù，指焦气；今义专指秽气。「丈夫」古义泛指成年男子，《素问·上古天真论》「丈夫八岁，肾气实」，今义专指妻之夫。词义转移：所指对象整体换掉，「涕」古指眼泪，「汤」在医籍中指汤剂，「亡」古义为丧失——《伤寒论》「若亡血、亡津液」，即失血、失津液，与今义「死亡」不同。

三类之中，缩小与转移最容易骗过人，因为句子照样通顺。判据只有一条：**这个义域是变宽了、变窄了，还是换了一个对象？** 说得出来，才叫辨明了古今；说不出来，就只是把今义读了一遍。

还有一类词不能按字面拆：「利害」「缓急」「得失」这类偏义复词，两个语素中只有一个承担实义。医籍中「虚实」「标本」「寒热」多数情形下两义并立，不能类推为偏义；判断依据是上下文是否只允许一侧成立。这一步若做错，后面所有的辨证都建在拆错的词上，而且错得不显眼——因为古汉语的偏义复词与并列复合词在字面上完全一样。

## 三、训诂三法各证到哪一层

形训、声训、义训不是三种可以随便挑的工具，它们各自能证到的深度不同。

形训依字形求义，靠的是《说文》一系的字形分析。「灸，灼也。从火，久声」——从火，故与火灼有关；「藥，治病艸。从艸，乐声」——从艸，故本草之字多从艸。形训的长处是能追到本义，短处是只对形声、会意的理据清楚的字有效；隶变之后字形多已失据，硬拆字形就是「望形生训」。

声训依声音求义，靠的是同音近音的线索，王念孙《广雅疏证》是范本。它的长处是能打通通假与同源，短处是容易泛滥——凡音近皆可牵合，最后什么都能证成。防滥的办法仍是那三道门槛。

义训依上下文与同义聚合求义，靠的是《尔雅》一系的义类与本书前后文互证。《释诂》「初、哉、首、基、肇、祖、元、胎、俶、落、权舆，始也」即是以通语释古语。义训的长处是最贴近具体文句，短处是不能独立证明本义，只能证明「在这一句里作此解」。

三法的正确用法是分工而不是竞争：**形训定本义，声训通借字与语源，义训定句中之义。** 底本引段逸山「训诂有据」、王育林「以《说文》《尔雅》为根柢，旁参《广雅》及清儒注疏」，讲的正是这个次序：先有字形与本义的根，再谈声音的通，最后落到句中的安。

## 四、一次辨字的记录字段，与校勘四法

辨字要留下可复核的东西，格式如下：

```
辨字记录（一字一条）
① 字头与所在句：（照录，附书名·篇名）
② 初步归类：通假 / 古今 / 异体 / 讹字 / 避讳
③ 声音依据：（古韵部或双声叠韵；无异则填「不适用」）
④ 意义依据：（本字义、借字本义、句中义三栏对齐）
⑤ 版本依据：（宋本、成注本、通行本异文；无异则填「诸本同」）
⑥ 结论与代价：（采何读，若采借义则原文义损失了什么）
```

⑤是这一章的关键，也是底本反复强调的一层。通假之迹常留在版本异文里：宋本与成无己《注解伤寒论》在「已发热／未发热」「淅淅恶风」等处有异文，正可参证。避讳字更是版本证据：汉避文帝刘恒讳，「恒山」改「常山」，而《神农本草经》原名恒山；唐代避代宗李豫讳，薯蓣改称薯药，宋代又避英宗赵曙讳改称山药，沿用至今；清避圣祖玄烨讳，玄参作元参、玄胡索作元胡索；宋本《伤寒论》避钦宗赵桓讳，「丸」多作「圆」，故有「乌梅圆」。这些不是错字，是**有意的改字**，读时必须还原，还原之后又可反过来用于断代。

断代这一步最忌孤证。底本说得很清楚：避讳断代须参以字体、刻工、纸质，不可单凭一讳字即下定论。理由也简单——避讳有时代性与地域性，某本避而某本不避，同一时代的不同刻坊做法并不一致。

版本比对的方法，底本引陈垣《校勘学释例》四法：对校（以祖本、别本对读）、本校（以本书前后文互证）、他校（以他书所引校本书，如以《脉经》所引校《伤寒论》，以《太素》《甲乙经》校《素问》）、理校（据文理医理推断）。四法不是并列的四条路，而是有四层可靠性：对校最实，本校次之，他校又次之，理校最险。理校之所以险，因为它只依赖读者的判断，而判断恰恰是最容易出错的一环；底本的例子是唐王冰据师藏本补入七篇大论、宋林亿等作新校正，这两件事都不是理校能独立完成的，背后都有本子。

## 五、考核项

1. 为「蚤／早」「被／披」「内／纳」各写一条辨字记录，②③④⑤四项不得空缺；其中「内」须说明若读为内外之内，方中哪一句会讲不通。
2. 说明「藏—脏」「府—腑」「写—泻」三组属古今字而非通假的理由，并指出其分化所分担的义项。
3. 给出「常山」「山药」「元参」「乌梅圆」四个名称各自的避讳来源，并说明还原后原文用字是什么。
4. 判断下列哪一条属孤证立说：某本避一讳字，遂定其为某朝刻本。给出补证的两条途径。
5. 用形训、声训、义训各解释一字，并说明三法各自证到了哪一层、哪一层它证不到。
6. 取《伤寒论》一条，以宋本与成注本对校，列出异文，判断是非并写明所用的是四法中的哪一法。

评分标准与上一章一致：能回查者为合格，结论漂亮而报不出篇名、韵部或版本的，作未辨处理。

## 代价与边界

1. 本章所引古韵部（幽、歌、物等）依底本所述，未逐字复核音韵学专书；韵部归属在学者间有异说，本章取其常见者。
2. 避讳例证的年代与讳主依底本，未核历代避讳专书；避讳有地域与刻坊差异，本章不给「一讳定年」的操作。
3. 底本只给出异文之「有」，未给出异文之「全」，本章所列宋本与成注本异文仅为示例，不构成校勘记。
4. 本章不处理俗字与简体规范问题：俗字约定俗成，可酌存原貌；简化字与古籍用字不是一一对应，排印本的改字不属校勘对象。
5. 本章不给方药与病证判断。字词辨明只解决「这句话在说什么」，不解决「这个病该怎么治」。
