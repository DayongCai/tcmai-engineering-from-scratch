# 用字关系分不清，训释就只是猜：通假、古今、异体、讹字各是一条证据 · 提示词

## 用途

给「用字关系分不清，训释就只是猜：通假、古今、异体、讹字各是一条证据」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「四类关系，四张不同的证据单 → 词义的三条移动路线，与一类不能拆的词 → 训诂三法各证到哪一层 → 一次辨字的记录字段，与校勘四法」这条链。
