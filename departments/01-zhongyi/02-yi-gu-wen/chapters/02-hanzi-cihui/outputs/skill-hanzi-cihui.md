# 用字关系分不清，训释就只是猜：通假、古今、异体、讹字各是一条证据

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 3 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 看两字之间有无字源与意义的相承
- 这个义域是变宽了、变窄了，还是换了一个对象？
- 形训定本义，声训通借字与语源，义训定句中之义

## 边界

- 本章所引古韵部（幽、歌、物等）依底本所述，未逐字复核音韵学专书；韵部归属在学者间有异说，本章取其常见者。
- 避讳例证的年代与讳主依底本，未核历代避讳专书；避讳有地域与刻坊差异，本章不给「一讳定年」的操作。
- 底本只给出异文之「有」，未给出异文之「全」，本章所列宋本与成注本异文仅为示例，不构成校勘记。
- 本章为医古文用字与词义的教学整理，音韵、避讳、版本诸项均转述自课程底本，未逐条核对原书与拓本。
