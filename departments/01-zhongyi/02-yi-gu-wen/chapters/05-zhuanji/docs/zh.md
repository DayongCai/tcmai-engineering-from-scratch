# 第 5 章 · 读传不是读故事：姓、字、籍贯、师承、著作各是一条待核的证据

> **MOTTO:** 「使圣人预知微，能使良医得蚤从事，则疾可已，身可活也」——《史记·扁鹊仓公列传》
>
> **PROBLEM:** 本章底本 6 个单元、20,029 汉字，出现书名 113 种——是全书八章里引用面最宽的一章。113 种书里真正属于传记本身的只有《史记》《三国志》《晋书》《旧唐书》等数种，其余全是注家、方志、书目与后世医书。这个比例说明一件事：一篇传记里的每一句「某地人」「受业于某」，都要靠传外的书来核。本章要回答的是，一篇医家传记里到底有哪几个字段可以核、怎么核、核不到时怎么写。

**双根因定位:** 环境逼迫（医家传记是读医籍时最常被引用的材料，一句「某家出于某派」往往整段立论都靠它，而传记本身是史笔与传闻的混合物）+ 知识积累（正史医家传自《史记·扁鹊仓公列传》始，到《晋书》《旧唐书》形成体例：里居、家世、师承、仕履、著作、卒葬依次排布，字段固定，正因固定才可核）

## 一、传记要读的六个字段

正史列传的体例不是随意行文，它有一套固定的信息顺序。读医家传，先把六个字段抽出来，再谈文采。

| 字段 | 传中位置 | 可核对象 | 常见缺损 |
|---|---|---|---|
| 姓、氏、名、字、号 | 开篇 | 姓氏书、同期传记 | 名与字互乙，号与室名混 |
| 籍贯、里居 | 开篇 | 地理总志、方志 | 郡县沿革变动，古今地名不对应 |
| 家世、出后 | 开篇 | 同期史传、谱牒 | 过继、出嗣记载不一 |
| 师承 | 学医段落 | 师之传记、书目 | 只记「受业于某」，无第二证 |
| 仕履、征辟 | 中段 | 职官表、诏令 | 辞不应征与实曾赴任混淆 |
| 著作 | 末段或散见 | 书目、序跋 | 传不载而书目有，或传载而书亡 |

以《史记·扁鹊仓公列传》为例：开篇「扁鹊者，勃海郡郑人也，姓秦氏，名越人。少时为人舍长」，五个字段里一次给了四个——籍贯、姓、名、早年职业，字与号不载。「舍客长桑君过，扁鹊独奇之，常谨遇之」「出入十余年，乃呼扁鹊私坐」，这是师承字段，但师承的对象是一个「忽然不见，殆非人也」的人。太仓公一段则是另一种排布：「太仓公者，齐太仓长，临菑人也，姓淳于氏，名意。少而喜医方术。高后八年，更受师同郡元里公乘阳庆」，官职、籍贯、姓、名、性情、师承依次列出，还带了师之年岁与传授内容——「庆年七十余，无子，使意尽去其故方，更悉以禁方予之，传黄帝、扁鹊之脉书」。

这一段的字段密度值得注意：**它把「授受方式」也写成了字段。**「尽去其故方」四字，说明汉初医家授受是整批替换而非累加；「受之三年，为人治病，决死生多验」，说明学制与验证方式；「诊籍」二十五则载于本传下文，格式含姓名、里居、病名、脉证、治法、预后，是现存最早的医案。读传时若只记住「淳于意是名医」，这些字段就全丢了。

《晋书·皇甫谧传》则是另一种样本：开篇「皇甫谧，字士安，幼名静，安定朝那人，汉太尉嵩之曾孙也。出后叔父，徙居新安」，字、幼名、籍贯、家世、出后五项齐全，唯独不载生年——生年须靠他处推。传中「年二十，不好学，游荡无度」给了一个年龄锚点，「久婴笃疾，躯半不仁，右脚偏小，十有九载」又给了一个病程锚点，这两个数字比生卒年更能定他的处境。**传记里的年龄与病程，常常比生卒年可靠**，因为它们是传文自述，不是后人推算。

## 二、一个「郑」字牵出一串注：异文是传记的第一道关

「扁鹊者，勃海郡郑人也」——这个「郑」字有问题。裴骃《史记集解》引徐广曰「郑当作鄚」，张守节《史记正义》亦谓「郑」为「鄚」之讹，鄚为河间鄚县。多数注家从之。底本据此在正文里保留了「郑」而在讲析里给出辨正，这个处理方式本身就是教学：**原文照录，异文出注，不径改。**

同类问题还有一处：「扁鹊过齐，齐桓侯客之」。底本指出，一说即田齐桓公午，而《韩非子·喻老》载此事作「蔡桓侯」。人物异文，历来有讨论。两处异文合起来给了一条方法：传记的专名（地名、人名）是最容易在传抄中被「规范化」的部分——抄手看见不熟悉的「鄚」，顺手写成熟悉的「郑」；看见「齐桓侯」与史不合，改作「蔡桓侯」。所以读传遇到专名与常识不合，第一反应不是「史家有误」，而是「这里可能有异文」。

异文的手续仍是上一章说的四步，只是在传记里第三步要加一层：**以他书所引校本书**。《韩非子》与《史记》记同一事而人物不同，这是典型的他校材料；《史记》三家注本身也是他校材料，因为注家所见本与今本未必相同。

还有一类异文不涉及专名，只涉及字形。《晋书》本传「出后叔父」，百衲本作「出嗣」；「教有所阙」的「阙」，通「缺」。这类差异对理解影响不大，但对判定版本早晚有用——底本把它列在「通假与古今字」项下，提示读者：传记的用字本身也是证据。

## 三、把神异情节降一级：传说不是不能读，是不能当史料

《扁鹊传》最惹眼的部分是学医经过：长桑君「出其怀中药」，「饮是以上池之水，三十日当知物矣」，「忽然不见，殆非人也」；扁鹊饮药三十日，「视见垣一方人」，「以此视病，尽见五藏症结，特以诊脉为名耳」。这一段在任何时代读都觉得离奇。

底本的处理很值得学：它先指出「此系采录民间传说，当注意其文献性质」，再把这一层与扁鹊的理性主张对观——同一个人，传说里靠神药透视脏腑，传记里却说「信巫不信医，六不治也」。两处并置，医学与巫术决裂的轨迹就出来了。**传说在这里的功能不是提供事实，而是提供一个可对照的坐标。**

同类处理还有《说文》「醫，治病工也。从毉，从酉」，「毉」从巫——巫医同源是文字层留下的痕迹。这条材料比任何传说都硬，因为它是字形，不是叙事。用它去解释传说的来源，比用传说去证明医学起源可靠得多。

判据因此可以写成一句：**凡传记中的神异情节，只能用来解释「当时人如何想象医」，不能用来证明「当时医如何操作」。** 操作层要看诊籍、方书、脉证记载，那些是有格式、可复算的东西。

## 四、记录字段与三种失效

读传要留下可核的痕迹，格式如下：

```
传记字段卡（一人一卡）
① 出处：（书名·篇名；所据版本）
② 姓名字号：（分栏填，缺者写「传不载」）
③ 籍贯：（原文地名 + 今地 + 沿革疑点）
④ 师承：（师名、授受方式、学制、验证方式）
⑤ 仕履与征辟：（官职、辞就、诏令次数）
⑥ 著作：（传载 / 书目载 / 存佚，三者分列）
⑦ 传说层：（标出神异情节，注明「不作史实用」）
⑧ 异文：（专名与字形的异文，各注出处）
```

②⑥⑦三栏是这张卡的关键。②栏要求「缺者写传不载」，是为了防止把后人的补撰当成原文——医家传记最常见的添补就是字与号。⑥栏要求三者分列，是因为「传载而书亡」与「传不载而书目有」是两种完全不同的证据状态：前者说明著作曾存在，后者说明传记不全。⑦栏是把传说降级的动作，写在卡上，就不会在写文章时被顺手引用成事实。

三种失效模式都能在这张卡上定点排除。

**以传说代史实。** 把「视见垣一方人」当成扁鹊确有特异功能，或反过来据此否定扁鹊其人的存在。两种做法都把传说层当成了事实层。判据：这条材料是否只出现在一种性质的文本里？只出现在传记的学医段落而不见于诊籍、方书，就是传说层。

**孤证立说。** 一处「受业于某」就断定某派源流；一条「郑当作鄚」就推翻全部地理记载。判据：这个结论是否只依赖一条材料？是，就只能写成「一说」。

**以今律古。** 底本给了一个很细的例子：「望见桓侯而退走」，「走」古义为奔跑，今义为行走；通行教材或作「望桓侯而还走」，「还」通「旋」，旋即、立即。两说并可通。若按今义读「退走」为「退下走开」，齐桓侯「使人问其故」的紧张感就没了——他问的是「你为什么转身就跑」。一个字读错，整段的气氛与病理判断一起变。

## 五、考核项

1. 为《史记·扁鹊仓公列传》扁鹊开篇一段填一张字段卡，②栏五项逐项注明「传载」或「传不载」。
2. 说明「勃海郡郑人」的「郑」为何当作「鄚」，写出两条注家依据，并指出这属于四法中的哪一法。
3. 比较「齐桓侯」与《韩非子·喻老》「蔡桓侯」，说明这类人物异文说明了什么，并给出处理办法。
4. 从《晋书·皇甫谧传》中找出两个可替代生卒年的年龄或病程锚点，说明它们为何比生卒年可靠。
5. 指出「视见垣一方人」在字段卡⑦栏应如何标注，并说明它能证明什么、不能证明什么。
6. 说明「退走」与「还走」两读的差别，并指出若取今义「走开」，会丢失哪一层信息。

评分只看：②栏是否敢写「传不载」，⑦栏是否把传说降级。把传说与诊籍混在一栏叙述的，按未读处理。
