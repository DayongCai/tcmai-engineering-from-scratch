# 读传不是读故事：姓、字、籍贯、师承、著作各是一条待核的证据 · 提示词

## 用途

给「读传不是读故事：姓、字、籍贯、师承、著作各是一条待核的证据」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「传记要读的六个字段 → 一个「郑」字牵出一串注：异文是传记的第一道关 → 把神异情节降一级：传说不是不能读，是不能当史料 → 记录字段与三种失效」这条链。

## 提示词

```
我在学《医古文》第 5 章「读传不是读故事：姓、字、籍贯、师承、著作各是一条待核的证据」，本章 5 节 / 2,976 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 它把「授受方式」也写成了字段
   - 传记里的年龄与病程，常常比生卒年可靠
   - 原文照录，异文出注，不径改
   - 以他书所引校本书
   - 传说在这里的功能不是提供事实，而是提供一个可对照的坐标
   - 以传说代史实
4. 本章自陈的边界（不得越过）：
   - 本章所引传记文字转自底本，底本以中华书局点校本为据；本章未核原书，异文（郑／鄚、齐桓侯／蔡桓侯、出后／出嗣）依底本所述，属转述层。
   - 本章不给医家生卒年与著作卷数的判定。凡底本未载者，本章不推；凡底本载者，引用时须注明「底本所述」。
   - 传记文学手法（对话写人、排比收束）本章只作提示，不作文学分析；读传的目的在取字段，不在评文。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为医古文传记文选的教学整理，传文、注家异文与医案格式均转自课程底本，未逐条核对原书；具体操作以现行规范与所在机构制度为准。
