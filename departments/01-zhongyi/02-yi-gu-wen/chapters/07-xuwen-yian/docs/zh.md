# 第 7 章 · 序文讲书怎么来的，医案讲人怎么决断：两种文体各有一份必答清单

> **MOTTO:** 「医经者，原人血脉经络骨髓阴阳表里，以起百病之本，死生之分」——《汉书·艺文志》
>
> **PROBLEM:** 本章底本 6 个单元、20,769 汉字，出现书名 138 种——全书最多的一章。138 种书里，序文类与医案类各占一半，而这两类文体的读法几乎相反：序文谈的是一部书如何成书，重「缘起」；医案谈的是一个病人如何被判断，重「决断」。同一段文字，按序文读会问「作者想说什么」，按医案读会问「他凭什么这么定」。底本给出的《本草纲目》序自述「岁历三十稔，书考八百余家，稿凡三易」，三个数字全是成书过程；《寓意草》一案则先记脉证、次断病因、再析病机，全是判断过程。本章要回答的是：这两种文体各自必须回答哪几个问题，答不出时该怎么标注。

**双根因定位:** 环境逼迫（序文与医案是医籍中最常被摘引的两类文字，而它们恰恰是最容易脱离体例被读的两类：序文的称誉被当成评价，医案的自述被当成疗效）+ 知识积累（序文体自汉魏以来形成固定的著作缘起叙述，医案体至明清除喻昌「议病式」而立定程式，两者都有可指认的体例，正因有体例才可核）

## 一、序文：一部书的六个必答项

序文的职责是交代一部书为什么会有。底本所载王世贞《本草纲目》序，把六个必答项答得极完整。

其一，**作者是谁、凭什么作序**。序中先以「望龙光，知古剑；觇宝气，辨明珠」起兴，说萍实、商羊这类奇物「非天明莫洞」，由此推出识奇书须有识者——这是为自己作序立资格。这一段是修辞，不是事实，读序时要分得开。

其二，**来访与授受的情状**。「楚蕲阳李君东璧，一日过予弇山园谒予，留饮数日」，三句写见面；「睟然貌也，癯然身也，津津然谭议也」三句写人，貌、形、言各一面。这类细节是序文的体温，也是判断序文可靠性的依据：作者确实见过人、读过书，还是只凭传闻。

其三，**成书过程与工时**。李时珍自述「岁历三十稔，书考八百余家，稿凡三易」，三个数字是全序最硬的部分——三十年、八百余家、三易其稿。数字之所以硬，因为它们可以与他书互证，也可以被后人质疑。

其四，**修订的具体动作**。「复者芟之，阙者缉之，讹者绳之」三个短句，删重、补缺、正误，正是校勘三件事。紧接着给出量的交代：「旧本一千五百一十八种，今增药三百七十四种，分为一十六部」。旧本一千五百一十八种所指，底本说明是宋唐慎微《证类本草》所载之数；这一层交代很重要，因为「增三百七十四种」只有在知道基数的情况才有意义。

其五，**体例**。「每药标正名为纲，附释名为目」是「纲目」之名的由来；「次以集解、辨疑、正误，详其土产形状也；次以气味、主治、附方，著其体用也」，两句话把全书栏目说尽。读序文最该记的就是这一段，因为它把一部大书的结构压缩成了可核的几行。

其六，**刊刻与流传的愿望**。「兹集也，藏之深山石室无当，盍锲之，以共天下后世」——「盍」是何不，一句劝刻的话收束全篇。序文写到刊刻，才算完成它的功能：序不是评论，它是**使书得以流传的手续**。

六项之外，序文还有一种常见的附加内容：价值判断。「博而不繁，详而有要，综核究竟，直窥渊海」是定评；「实性理之精微，格物之通典，帝王之秘箓，臣民之重宝」是推许。这些话读的时候要知道它们是**序作者的评语**，不是书的属性。底本在讲析里特意把它们与「细读原书、评骘有据」联系起来，意思是：评语之所以可信，是因为前面有体例的逐项交代；没有那一段，评语就只是客套。

《串雅》序是另一种类型：赵学敏为一部民间走方医的方书作序，重点不在体例而在**为被轻视者正名**。读这类序，第六项（刊刻流传）往往变成第一项（为什么要刻这部书），六项的次序可以变，项不能缺。

## 二、医案：从「议病式」到一份可核的案

医案的体例到明末才真正定形。底本指出，喻昌《寓意草》卷首有《与门人定议病式》一篇，为医案书写立定程式：先记年月、地名、年龄、形色、嗜好，次述病状、脉象，再论病名、病因、病机，终定治法方药并预测预后。这五段就是医案的骨架。

看《寓意草》所载金道宾一案如何落这个骨架。第一段记脉：「左尺脉和平，右尺脉如控弦，如贯索，上冲甚锐」——不是笼统说「脉弦」，而是分左右尺、给比喻、指方向。第二段断病因：「是病枝叶未有害，本实先拨，必得之醉而使内也」，先引《诗经·大雅·荡》立断，病人答「诚有之」，病因遂定。第三段辨病机：「人身之阴阳，相抱而不脱，是以百年有常。故阳欲上脱，阴下吸之，不能脱也；阴欲下脱，阳上吸之，不能脱也」，这是把「真阳上脱」放进一个阴阳互吸的模型里讲。第四段定治法：「治法要在寻其罅漏而缄固之」，并提出「引用」之法——上脱者七分阳药、三分阴药而夜服，从阴引阳。

四段之后还有一层，是这一案最见功力的地方：**鉴别**。上脱与下脱的证候被分列：上脱者妄见妄闻、身轻汗多；下脱者不见不闻、身重青紫。同是「脱」，方向相反，治法相反。医案的教学价值大半在这一层——它给的不是一个结论，是一个分岔口。

由此可以给医案立一条判据：**一份可核的医案，必须能回答「凭什么」。** 凭脉（哪一部、什么象）、凭症（哪一症为主）、凭病史（何因而起）、凭鉴别（排除了什么）。四者缺一，案子就只剩故事。

底本对疗效的处理也值得学：它指出案中「服之果获大效」一类，是作者自述，属医案文献记载，宜作文献史料理解，不可径视为今之临床证据。这句话把医案的两个层次分开了——**文本层**（作者写了什么）与**证据层**（这个写法能支持什么结论）。读医案读到「果获大效」，先问它有没有对照组、有没有随访、有没有他人记录；三问皆无，它就只是文本层的材料。

## 三、文体与纪年：庚寅是哪一年，古方一升是多少

底本另有两单元讲文体与文化常识，这两块看着是背景，实则是读序文与医案的必备工具。

文体先要认得出。序、论、传、记、书、疏各有其职能：序交代成书，论立主张，传记人物，记叙事，书是书信，疏是上呈之文。《本草纲目》序落款「时万历岁庚寅春上元日，弇州山人、凤洲王世贞拜撰」——年号加干支加月日加别号加「拜撰」，一套完整的署款格式。**署款本身就是证据**：它给出作序的时间（万历庚寅即万历十八年）、作者的身份（弇州山人、凤洲都是王世贞的号）、文体功能（拜撰是作序的谦称）。

干支纪年要会换算。年号加干支是双重定位：年号给出朝代与某帝在位第几年，干支给出六十年一轮的位置。两者对上，年份才定得死；只给干支（如「岁在庚寅」），就必须靠上下文或他书系年。这一条对读医籍序跋极实用：序跋往往只写干支，不写年号。

还有一层是称谓与避讳。序文中「李君东璧」称字不称名，是敬称；医案中「金道宾之诊」直呼其名，因为案是内部记录。称谓的差别透露文体：对外称字，对内称名。避讳则已在上文讲过，读清刻本遇「元参」「元胡」须还原。

度量衡则是本章必须划界的地方。古方中的两、升、方寸匕、钱匕，各代标准不同，折算须专门考证，且同一名称在不同时代所指不一。**本章不做折算，也不给任何换算比例。** 理由有二：其一，折算涉及考古实物与度量衡专史，非文本训读所能定；其二，折算一旦进入实用，就从「读懂古书」越界成了「照古方用药」。这条界限必须自己守住。

## 四、记录字段与三种失效

序文与医案共用一张卡，只是栏目的权重不同：

```
序跋·医案卡（一篇一案各一张）
① 文体与署款：（序／跋／案／论；年号＋干支＋月日＋署名）
② 对象：（所序之书 / 所诊之人；名称照录）
③ 过程字段：（序：工时、考书数、稿次数、增删数；案：脉、症、因、鉴别）
④ 体例或程式：（序：栏目结构；案：议病式五段）
⑤ 自述与评语：（分出哪句是作者自述、哪句是序作者的评语）
⑥ 可核程度：（可与他书互证／仅此一见／作者自述无旁证）
⑦ 不做的事：（如折算古方剂量、判定疗效）
```

③是这份卡的核心。序文的③要填数字，医案的③要填判断依据；两者都不许填形容词。⑤与⑥是配套的：把自述与评语分开，才谈得上可核程度。⑦一栏看着奇怪，其实是这份卡最实用的一栏——它要求填卡的人当场写下自己**不打算做什么**，从而避免越界。

三种失效模式因此可以定点排除。

**以传说代史实（此处表现为以自述代证据）。** 序文说「书考八百余家」，就把这部书当成「参考了八百种书」的定论；医案说「果获大效」，就把这一个案子当成疗效证据。判据：这条陈述的发出者是谁？是作者自述，还是第三方记录？自述只能作自述用。

**孤证立说。** 据一篇序的评语断定一部书的学术地位；据一则医案断定某法的有效率。判据：这个结论是否只依赖一条材料？是，就只能写「某序称」「某案载」。

**训释脱离上下文。** 摘「博而不繁，详而有要」作评价，而不看它评的是体例那一段；摘「寻其罅漏而缄固之」作治法，而不看它前面的阴阳互吸模型。判据：把摘句放回原段，它还是那个意思吗？

## 五、考核项

1. 为《本草纲目》序填一张卡，③栏四项数字（工时、考书数、稿次数、增删数）逐项照录原文，不得改写成概数。
2. 说明该序⑥栏所记「旧本一千五百一十八种」的基数所指，并解释为什么「增三百七十四种」必须与基数同引。
3. 为《寓意草》金道宾一案填卡，③栏须分列脉、症、因、鉴别四项，并指出「上脱」与「下脱」的鉴别点各是什么。
4. 说明「服之果获大效」在⑤⑥两栏应如何标注，并指出它能支持什么结论、不能支持什么结论。
5. 就「时万历岁庚寅春上元日，弇州山人、凤洲王世贞拜撰」一句，指出年号纪年与干支纪年各提供了什么信息、二者为何必须并用。
6. 说明本章为何不做古方度量衡折算，并写出两条理由。

评分只看：③栏是否只有可核项，⑤栏是否分出评语，⑦栏是否写出不做什么。
