# 第 3 章 · 语法不是贴标签：它是给歧义句定出唯一读法的手续

> **MOTTO:** 「夫设情有宅，置言有位」——《文心雕龙·章句》
>
> **PROBLEM:** 本章底本 6 个单元、13,302 汉字，其中没有一处【原文】块，全部例证以行内引文出现。这意味着同一句「春伤于风」既可读成「春天被风邪所伤」，也可读成「春天在风上受伤」；「未之闻也」既可读成「没有听说他」，也可以被初读者读成「未来的听闻」。底本给不出页码，读者只能靠句式自己判定。本章要回答的是：判断句、被动句、前置与省略，各靠哪一条可复核的判据定读法；定不下来时，该承认定不下来。

**双根因定位:** 环境逼迫（医经句子常主语省略、标志词缺省，而一句读错就直接改掉病位与病性——「伤于寒」与「伤寒」是两种句子，治法不同）+ 知识积累（古汉语的句式标志是一套有条件的系统：疑问代词、否定副词、「之／是」标记，各有其触发条件，条件不成立就不能套用）

## 一、判断句：五种形式，一条判据

底本列判断句五式：一为「……者，……也」，主语后「者」提顿、谓语后「也」煞尾，如《素问·阴阳应象大论》「阴阳者，天地之道也，万物之纲纪」；二为「……，……也」，只用「也」，如《素问·金匮真言论》「夫精者，身之本也」；三为「……者，……」或「……者也」，如《灵枢·本藏》「五藏者，所以藏精神血气魂魄者也」；四为无标志，主谓直接连用；五为副词或动词配合判断，「乃」「即」「则」「皆」「为」「非」皆是，《素问·热论》「今夫热病者，皆伤寒之类也」以「皆」总括，王冰《黄帝内经素问注·序》「《素问》即其经之九卷也」以「即」表判断，《伤寒论》「此为坏病」以「为」表判断，否定判断用「非」，如《史记·扁鹊仓公列传》「越人非能生死人也」。

五式看着繁，判据只有一条：**能否在主语与谓语之间补出「是」而不改原意。** 能补，就是判断句；补上之后句子变形，就不是。这条判据的好处是可当场验，不必先记五式名称。

但这条判据有一个必须同时施加的限制：「是」在先秦两汉多作指示代词。《伤寒论·序》「危若冰谷，至于是也」的「是」指「这种境地」，不是判断词；若见「是」就译「是」，句子立刻变成病句。这条限制不是细节，它是判断句教学里最容易出事的地方——底本特意点出「是」作判断词乃后起之变，等于提醒读者：判断句的标志是句式，不是某个字。

还有一个容易混的层次：「非」与「不」分工不同。「非」否定名词性谓语（「非常人也」），「不」否定动词、形容词谓语（「不治」）。混用会把「不是」写成「不」，句意从否定身份变成否定行为。

## 二、被动句：「于」字最险，施受关系说了算

底本列被动五式。「于」字式：动词后用「于」引出施动者，《素问·生气通天论》「春伤于风，邪气留连，乃为洞泄」，《素问·热论》「人之伤于寒也，则为病热」。「见」字式：动词前加「见」，《伤寒论·序》「明堂阙庭，尽不见察」；「见……于……」式则施动者由「于」引出。「为」字式与「为……所……」式，后世医案「为病所困」「为药所误」即沿此。「被」字式，《伤寒论》「若被下者，小便不利」「若被火者，微发黄色」。最后一式是意念被动，无标志，全凭文意，《灵枢·九针十二原》「言不可治者，未得其术也」即谓病不能被治好。

五式中「于」字式最险，因为「于」同时是处所、对象、比较的介词。底本给的对照极清楚：「春伤于风」是「于」引出施动者，主语「人」为受动者，属被动；「始于皮肤」的「于皮肤」表处所，主语「虚邪」为施动者，不是被动。同一虚词，两种结构，区别不在字面而在施受。

于是判据必须是两步，不能一步：**先看有无标志词，再看主语与动词的施受关系。** 只看标志词，会把所有「于」都读成被动；只看施受关系，则会漏掉「见」「为所」这类明确标志。两步都过，才定被动。

还有一条细则可用作交叉验证：「见」用于被动时后面不再带宾语；「见」后带宾语（如「见病」）多为「看见」的动词义。这条细则的价值在于它是**形式**判据，不依赖对文意的猜测——当文意两可时，形式判据更可靠。

## 三、语序与省略：前置有三条件，补足有上限

宾语前置不是修辞自由，它有三个触发条件，条件之外不能前置。

其一，疑问句中疑问代词作宾语。《大医精诚》「何以得其幽微」即「以何」；《素问·上古天真论》「精神内守，病安从来」，「安」作介词「从」的宾语前置；《伤寒论·序》「皮之不存，毛将安附焉」，「安」作动词「附」的宾语前置。其二，否定句中代词作宾语。《伤寒论·序》「下此以往，未之闻也」即「未闻之」；《素问·生气通天论》「虽有大风苛毒，弗之能害」即「弗能害之」。其三，以「之」「是」为标志。《素问·四气调神大论》「此之谓也」即「谓此」；《伤寒论·序》「孜孜汲汲，惟名利是务」即「惟务名利」。

三个条件给了一个反向判据：**不符合条件而读不通的句子，不要用「前置」去救它。** 前置是有条件的语法现象，不是万能的补丁；把任何读不通的句子都说成「宾语前置」，等于取消了语法。

定语后置同理。《史记·扁鹊仓公列传》「问中庶子喜方者」即「喜方之中庶子」，《华佗传》「立吐蛇一枚」即「一枚蛇」，《伤寒论》桂枝汤方「大枣十二枚」是数量词后置。辨「者」的两用是这一节的关键：判断句的「者」在主语后提顿，后置定语的「者」在中心语后、定语后。位置不同，功能不同。

省略七类中，最影响句读的是主语承前省与介词宾语省。《伤寒论》「太阳病，头痛，发热，汗出，恶风，桂枝汤主之」，末句前省主语「此证」；不知这一省，就会把「恶风」与「桂枝汤」连读。《伤寒论》「少少与饮之」，「与」后省宾语「之」；「以水七升，微火煮取三升」，「微火」前省介词「以」。

但补足有上限。底本说得明白：**省略以不害意为度**，能据承前、蒙后、对话确定的补出；上下文无可据者不可强补，以免臆改经文。这条上限比任何一条补足技巧都重要，因为补足是读者的动作，动作越界就变成了改写。

虚词这一层与语序、省略是同一件事的两面。底本把否定副词分成两组：不、弗与勿、毋。不、弗否定的是动作本身（「不治」即未治、不能治），勿、毋否定的是意愿与禁止（「勿使被毒药」是不让、别让）；未、莫则带时间与范围（「未之闻」是迄今没有，「莫知之」是无人）。「之」「其」「者」「所」四字的分工更直接：「之」作结构助词时可取消句子独立性，「其」多表领属或推测，「者」为提顿或后置定语的标志，「所」与动词合成名词性短语。这些分工不是要背的清单，而是判断时的**形式信号**：一段白文里出现「未」「莫」，前面又有一个代词，宾语前置的条件就齐了；出现「者」而其后无谓语，就要先问它是提顿还是后置标志。虚词读错，句式判断随之错，且错在根上——补足、还原语序都无从谈起。

## 四、一次析句的记录格式与三种失效

语法分析要留下可复核的痕迹，格式如下：

```
析句记录（一句一条）
① 原句：（照录，附书名·篇名）
② 待决问题：（判断／被动／前置／省略／虚词归属，只填一项）
③ 候选读法：（写出两种以上，含各自的译文）
④ 判据：（用哪一条：补「是」／施受关系／前置三条件／「者」的位置）
⑤ 反证：（若取另一读法，哪一处会讲不通）
⑥ 结论与置信：（定 / 存疑，存疑须写缺口在哪）
```

⑤与⑥是这份记录的价值所在。语法判断最怕的不是判错，而是**判错却当成确定**。凡两读皆通而无法用形式判据分开的句子，正确做法是记「存疑」，并在注里写明缺哪一类材料才能定——底本对「是」的处理就是这个态度的示范：它不说「是」一定不是判断词，而说先秦两汉「多作」指示代词，「是」作判断词乃后起之变。

三种失效模式因此可以定点排除。

**以今律古。** 见「是」即译「是」，见「被」即译「被」（「余欲勿使被毒药」的「被」是动词「遭受」，不是被动标志），见「于」即断被动。判据：这个虚词在同期文献中是否已有该用法？没有，就是今义投射。

**孤证立说。** 拿一个例句的读法去概括全部同类句式。判据：换一位作者、换一部书，这个句式是否仍成立？《素问》的判断句与《伤寒论》序的判断句语气不同，不能互推。

**训释脱离上下文。** 省略补足时凭印象补一个主语，补完句子通顺了，却与原篇的主语不一致。判据：补出的成分能否在本篇找到出处？找不到，就不能补。

## 五、考核项

1. 给「阴阳者，天地之道也」「此为坏病」「越人非能生死人也」三句各写一条析句记录，④栏须填「补出『是』」并写出译文。
2. 说明「春伤于风」与「始于皮肤」两句的「于」为何一为被动、一为处所，并指出判据落在施受关系的哪一侧。
3. 给「未之闻也」「惟名利是务」「病安从来」三句各还原语序，并说明各自触发的是哪一条件。
4. 指出「中庶子喜方者」与「扁鹊者，勃海郡郑人也」两处「者」的功能差别，依据是位置还是意义。
5. 为「太阳病，头痛，发热，汗出，恶风，桂枝汤主之」补出省略成分，并说明补足的依据是承前还是蒙后；若依据不足，须写明为何不补。
6. 举一例说明「不」与「非」的分工，并指出混用后句子错在哪一层。

评分只看两件：④栏的判据是否可当场复核，⑥栏是否敢写「存疑」。全判为「定」而无反证的记录，按未做处理。

## 代价与边界

1. 本章例句全部转自底本的行内引文，底本未给版本与页码；同一句在不同传本中虚词或有出入，本章不据以作版本判断。
2. 本章只讲医籍中高频出现的句式，不覆盖古汉语语法全貌；诗词语法、骈偶句法不在范围内。
3. 「存疑」是本章允许并鼓励的结论，但不是免责牌：凡能以形式判据定下的句子，仍须定，不得一律标存疑。
4. 省略补足以「不害意」为上限，本章不给「尽量补全」的做法；补得越多，改写原文的风险越大。
5. 本章不涉及方药与治法。句式判定只影响「这句话在说什么」，不构成任何临床判断。
