# 医论读的是论证，不是警句：一句名言脱离上下文就不能引用 · 提示词

## 用途

给「医论读的是论证，不是警句：一句名言脱离上下文就不能引用」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「说理文的骨架：现状、病因、后果、对策 → 引用一个动作，要交代四件事 → 注家异说怎么排：一条「佩」字的教训 → 记录字段与三种失效」这条链。

## 提示词

```
我在学《医古文》第 6 章「医论读的是论证，不是警句：一句名言脱离上下文就不能引用」，本章 6 节 / 3,106 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 这一段是全序唯一带数的地方，也是唯一可以核的地方
   - 字义的授权来源
   - 我用它证什么
   - 用摘句代替论证
   - 只要一句注需要你再解释一遍才能成立，它就已经是疑点了
   - 训释脱离上下文
4. 本章自陈的边界（不得越过）：
   - 本章所引经文与注文转自底本；底本以明顾从德影宋刻王冰注本、宋本《伤寒论》为据，本章未核原书，属转述层。
   - 本章不给《伤寒论》条文的病机解释与方药用法。「伤寒十居其七」是序文自述，不是发病率统计，不可作流行病学数据使用。
   - 注家异说本章只取「佩」一例作示范，其余异说未遍举；凡底本未收的注家，本章不代为立说。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为医古文医经医论的教学整理，经文、序文与注文均转自课程底本，未逐条核对原书传本；具体操作以现行规范与所在机构制度为准。
