# 第 6 章 · 医论读的是论证，不是警句：一句名言脱离上下文就不能引用

> **MOTTO:** 「勤求古训，博采众方」——《伤寒论·序》
>
> **PROBLEM:** 本章底本 5 个单元、20,502 汉字，标为【原文】的引文块 35 处、行内引例 21 条，出现书名 52 种。35 块原文里，被后人反复摘引的警句不足十句，其余都是论证的中间环节。摘句的成本极低，验句的成本极高——「勤求古训，博采众方」八个字人人会引，可它前面一句是「感往昔之沦丧，伤横夭之莫救」，后面一句是「撰用《素问》《九卷》《八十一难》」。摘掉前后，这句就成了「要多读书」，而原意是「因宗族死丧而著书」。本章要回答的是：一段医论要读到什么程度，才算有资格引用它。

**双根因定位:** 环境逼迫（医论的说服力来自论证链，而读者往往只需要一句结论；摘句在传播上永远胜过读全篇，代价是结论脱离了它成立的条件）+ 知识积累（《素问》《灵枢》《难经》《伤寒论》各有其成书层次与注家系统，同一段文字在王冰、林亿、马莳、张介宾笔下可以有不同读法，异说不排清就无法引用）

## 一、说理文的骨架：现状、病因、后果、对策

《伤寒论·序》是医论中最完整的样本，四段推进，每一段都可指认。

第一段立现状。开篇「余每览越人入虢之诊，望齐侯之色，未尝不慨然叹其才秀也」，以两个典故起兴，随即转向反面：「怪当今居世之士，曾不留神医药，精究方术」。「曾」读 zēng，竟然，表出乎意料——底本特意注明此字不可释为「曾经」，因为全段的批判语气就压在这个副词上。

第二段陈病因。病因不是外邪，是价值排序错了：「但竞逐荣势，企踵权豪，孜孜汲汲，惟名利是务；崇饰其末，忽弃其本，欲华其外而悴其内」。四句两层，「末」指名利，「本」指身体；「华」「悴」是使动，使外表华美、使内里憔悴。紧接着一句比喻收束：「皮之不存，毛将安附焉？」

第三段推后果。「卒然遭邪风之气，婴非常之疾，患及祸至，而方震栗；降志屈节，钦望巫祝，告穷归天，束手受败」——从遭邪、婴疾、震栗，到求巫、归天、受败，六个动作一气贯下，是一整条失败的因果链。这段的分量在「钦望巫祝」四字：它与《史记》「信巫不信医，六不治也」是同一个批判方向，只是仲景写在序里，司马迁写在传里。

第四段给对策，也是全序的枢纽：「余宗族素多，向余二百。建安纪年以来，犹未十稔，其死亡者，三分有二，伤寒十居其七。感往昔之沦丧，伤横夭之莫救，乃勤求古训，博采众方」。宗族二百余、十年间死亡三分之二、伤寒居其七——三个数字是著书的直接动因。**这一段是全序唯一带数的地方，也是唯一可以核的地方**；前两段的批判是价值判断，这一段的死亡比例是经验陈述。

读到这里才看得出「勤求古训，博采众方」的性质：它不是治学格言，是**对策**。它的上一句是死丧，下一句是「撰用《素问》《九卷》《八十一难》《阴阳大论》《胎胪药录》，并平脉辨证」。把这三句连起来读，「博采众方」的意思就不是「多看书」，而是「按这五部书的路子重编一部」。

四段之外还有一段自勉：「孔子云：生而知之者上，学则亚之。多闻博识，知之次也。余宿尚方术，请事斯语。」引孔子语定位自己，是汉人文章的通例；「请事斯语」把前面所有的批判转成了自勉，语气为之一收。

四段结构给了一条可操作的读法：**读一段医论，先把它的现状、病因、后果、对策四段找出来；找不出的那一段，往往就是作者没说清的地方。**《大医精诚》同理：它以「博极医源，精勤不倦」立标准，以「今以至精至微之事，求之于至粗至浅之思」陈病因，以「世有愚者，读方三年，便谓天下无病可治」写后果，以「誓愿普救含灵之苦」给对策。骨架一致，语气不同——序是愤，诚是誓。

## 二、引用一个动作，要交代四件事

「勤求古训」这四个字在本章底本里出现不止一次，每一次的上下文都不同。这说明引用的第一件事不是抄原文，而是交代它在原书里的位置。

一条合格的引用要交代四件事：

其一，**出处到篇**。《伤寒论·序》与《伤寒论》是两回事：前者是作者自述，后者是正文条文。引「伤寒十居其七」而不说是序，读者会以为这是临床统计；说是序，读者才知道这是作者自述的家族丧亡。

其二，**上下文**。「上以疗君亲之疾，下以救贫贱之厄，中以保身长全」三句，若只引中间一句，就成了「学医为了救人」；三句连读才看得出它的结构是忠孝与自保并列，反映的是汉代士人的医学价值观。

其三，**注家**。「不时御神」的「时」，王冰注「时，善也」；不从这条注，「不时」就读成「不按时」，整句变成「不按时调摄精神」，与原意（不善于调摄精神）有距离。注家不是装饰，它是**字义的授权来源**。

其四，**我用它证什么**。同一句「恬惔虚无，真气从之，精神内守，病安从来」，可以用来证「养生重在心性」，也可以用来证「正气存内，邪不可干的思想源头」。两种用法都成立，但要说清是哪一种，否则读者无法判断这句是否支持了你的论点。

四件事缺任何一件，引用就退化成摘句。摘句不是错，错在**用摘句代替论证**。

## 三、注家异说怎么排：一条「佩」字的教训

《素问·四气调神大论》「道者，圣人行之，愚者佩之」。王冰注训「佩」为「佩服」，于是「行之」是实行、「佩之」是佩服，两句的文意不类——圣人实行，愚者佩服，佩服为什么是贬义？

杨上善《太素》此句「佩」作「背」。林亿等新校正引以相证，佩通倍，倍通背，义为违背。改读之后，两句对文见义：圣人实行它，愚者违背它。文意立刻成立。

这条异说的处理值得拆开看。第一步，发现文意不类——这是「疑点」。第二步，查异文——《太素》作「背」。第三步，用声音通训诂——佩、倍、背，一声之转。第四步，验文意——与「圣人行之」对文，成立。

四步里最容易被跳过的是第一步。王冰的注不是错的离谱，它只是让句子变得「勉强通」；而「勉强通」正是疑点最常出现的形态。**只要一句注需要你再解释一遍才能成立，它就已经是疑点了。**

注家异说的排序也有规矩。底本给出的态度是：以通行教材与权威注本为据，异说并存者表述克制，取其通行，注明出处，不作无据之翻案。这不是保守，是成本计算——翻案要付出四步的全部成本，而读者多数只需要知道「通行读法是什么、另有异说」。反过来，若确有异文与声音两重证据（如「佩」字例），不指出反而是失职。

## 四、记录字段与三种失效

读一段医论，记录格式如下：

```
医论读记（一段一条）
① 出处与层次：（书名·篇名；是正文、序、注、还是附录）
② 四段定位：（现状／病因／后果／对策，各摘一句）
③ 关键字的注：（字 + 注家 + 注文；无注须写「无注」）
④ 异说：（异文或异注 + 出处 + 采何说 + 理由）
⑤ 我引它证什么：（一句，须能与②对上）
⑥ 不能证什么：（一句，写清这句的适用边界）
```

⑤⑥两栏是这条记录的用途所在。⑤要求「与②对上」，是为了防止拿对策段的句子去证明现状段的判断。⑥要求写出边界，是因为医论里绝大多数句子都是有条件的：《素问·四气调神大论》「春夏养阳，秋冬养阴」是在四时框架下说的，脱开四时去讲「养阳」，就把一句有条件的话变成了无条件口号。

三种失效模式因此可以定点排除。

**以今律古。**「知道」在《素问·上古天真论》「其知道者」中是动宾结构，懂得养生之道，不是今义「知晓」；「曾」是竟然，不是曾经；「给」读 jǐ，口才敏捷（「务在口给」），不是给予。判据：这个义项在同期文献中是否有用例？没有，就是今义投射。

**孤证立说。** 以一条注家之说推翻通行读法；以一处的「时，善也」推广到全书所有的「时」。判据：这条注是否只此一见？是，就只能写成「王冰注此句作某」。

**训释脱离上下文。** 摘「勤求古训，博采众方」而不带前后句，把对策读成格言；摘「恬惔虚无」而不带「虚邪贼风，避之有时」，把内养读成全部。判据：把摘出的句子放回原段，它的意思变了没有？变了，就说明摘句时丢了条件。

## 五、考核项

1. 为《伤寒论·序》作四段定位，②栏四句各摘一句原文，并指出哪一段是唯一带数的段落。
2. 说明「曾不留神医药」的「曾」为何不可释为「曾经」，并给出若误释会造成什么后果。
3. 就「愚者佩之」写一条异说记录，④栏须写出异文出处、声音依据、采何说；并说明王冰注为何构成「疑点」而不只是「错误」。
4. 为「上以疗君亲之疾，下以救贫贱之厄，中以保身长全」写一条引用记录，⑤⑥两栏不得空缺。
5. 说明「春夏养阳，秋冬养阴」的适用边界，并指出脱开四时框架引用它会丢失什么。
6. 指出下列哪一条属孤证立说：据王冰一处注文断定《素问》全书「时」皆训「善」。

评分只看：③④两栏是否指出注家与出处，⑥栏是否写出边界。只摘警句不记上下文的，按未读处理。
