# 第 8 章 · 检索不是回答：词频给出的是候选，不是结论

> **MOTTO:** 「方以类聚，物以群分」——《周易·系辞上》
>
> **PROBLEM:** 本章底本只有 2 个单元、5,169 汉字，是八章里最薄的一章——不到第 2 章（23,483 汉字）的四分之一，占全书 47 个单元里的 2 个、131,298 汉字里的约百分之四。薄的原因不在题目小，而在这一章讲的东西大多不在纸本里：数据库、语料库、知识图谱都是近年才有的工具，底本只能给出「可辅助参考」的操作口径。于是本章的问题变成：当工具比材料多的时候，一个人凭什么判断检索结果可信？

**双根因定位:** 环境逼迫（一次全文检索能在数秒内返回上千条命中，而判断哪一条可用所需的时间远多于检索本身；工具把「找到」的成本降到了近零，把「判断」的成本留在了原处）+ 知识积累（古籍数字化的三级——影像、文本、知识——各有其失真方式：扫描会漏页，识别会错字，标注会错分词，一层一层叠上去，最上层的结论离原书最远）

## 一、数字化的三级，失真各有其形

底本把医籍数字化分为三级，这个分法比任何工具清单都有用，因为每一级的失真方式不同。

第一级是图像数字化：逐页扫描或拍照，存为影像。它的价值是存真，善本化身千百；它的缺陷是漏页、模糊、装订遮挡，而这些缺陷在读影像时看得见——看得见的缺陷不危险。

第二级是文本数字化：经识别或人工录入，把影像转为可检索文字。它的价值是可检索；它的缺陷是**看不见的错字**。形近字误识（日／曰、己／已、淅／浙）在屏幕上与正确的字长得一样，读者不会怀疑。这一级的失真最危险，因为它伪装成原文。

第三级是知识数字化：在文本之上标注、切分、建库，形成语料库与知识库。它的缺陷再叠一层：分词错、实体标错、关系抽错。而上层的错误不会自我暴露——你查「桂枝汤」，它给你一百条，你无法从结果本身看出其中三条其实是「桂枝」与「汤」两个词被错并。

三级的关系可以这样记：**越往上层，越好用，越不可核。** 底本因此反复强调「数字化只是载体之变，而非学问之变」，并给出一个具体例证：同一部《素问》，全元起注本、王冰次注本与宋林亿等新校正本之间文字颇有差异，今通行者多以明顾从德影宋刻本为底本。**版本不统一，数据就不可比**——这句话是本章所有操作的前提。

## 二、一次检索要报三个数

检索不是提问，是抽样。既然抽样，就要报抽样框与样本量。本课程要求一次检索报三个数。

其一，**召回**。用这一组检索词，在同一语料里能捞到多少条？底本举的例子最能说明问题：《史记·扁鹊仓公列传》「能使良医得蚤从事」的「蚤」通「早」，若语料库没有通假字映射表，检索「早」就捞不到这一条。也就是说，**召回率的上限由异体字、通假字、古今字的处理方式决定**，而不由检索词是否聪明决定。报召回，等于承认「我没捞到的可能更多」。

其二，**精确**。返回的一百条里，有几条真的是你要的？虚词是最典型的噪声源：「之」「也」频次极高而与医理无涉，底本明说须先过滤停用词。不退掉噪声就报数，报出来的「高频」只是排版特征。

其三，**版本**。这批评分数据出自哪个本子？底本指出，词频统计易受底本异文、文本长短、篇章分合的影响。同一部书，篇章分合不同，「篇均词频」立刻变形；底本不同，「某字出现几次」直接不可比。

三个数报齐，检索才算有交代。只报「命中 N 条」的，是把抽样当普查。

## 三、语料库的三种失败：分词、通假、异文

底本指出医古文语料库标注的三个特殊困难，恰好对应三种失败。

**分词。** 文言没有词界，切分须依赖训诂判断。这不是技术问题而是学问问题：「阴阳」「营卫」「标本」是词还是词组，取决于你按什么标准切；标准不同，词频就不同。底本说得很直：「切分与标注须由通训诂者为之。」凡标注者不通训诂，建出来的库只能做字频，不能做词频。

**通假与古今字。** 上一章讲过「蚤」通「早」、「藏」为「脏」之古字。语料库若不做映射，同一概念被拆成两个检索项，统计结果系统性偏低。补的办法是建映射表，而映射表本身是研究成果，不是技术配置——**每一条映射都要有训诂依据**。

**异文。** 同一段文字在不同传本中不同（「教下」与「教也，下皆为之」），若混本入库，检索结果会把两个本子的字混在一起数。底本因此要求：选本须择善本，识别后须逐字校对，最后经抽检复核，方为可用。

三种失败有一个共同点：**它们都不报错。** 分词错了，库照样返回结果；映射缺了，库照样返回结果；异文混了，库照样返回结果。所以判断只能靠人：看它的选本说明、看它的标注规范、看它有没有出校记。三者都没有的库，只能当索引用，不能当数据用。

知识图谱把标注再推一步：以节点表示实体、以边表示关系。医籍图谱常用的实体是医籍、医家、方剂、药物、证候、经络腧穴，常用的关系是「著」「载」「治」「用」「师承」，于是有「张仲景—著—《伤寒杂病论》」「《伤寒论》—载—桂枝汤」「桂枝汤—治—太阳中风证」「李杲—师承—张元素」这样的三元组。底本说它像一张地图：初学者可借它一眼看懂总关联，查某方出处、某药所载，一索即得。但地图不是地形——文言兼类词多、主语常省略，实体与关系的自动抽取极难，须逐条人工把关；一条关系抽错，整片邻域都跟着错。底本引王军教授团队的主张作标准：每个实体、每条关系都要能回溯到原文出处与版本，做到典籍可溯、文本可证。这条标准与前面几章讲的训诂考据是同一条，只是换了一个介质。

## 四、记录字段与三种失效

数字人文的操作要留痕，格式如下：

```
检索记录（一次检索一条）
① 问题：（一句话，须是可被否证的）
② 语料与版本：（库名 + 底本 + 收录范围）
③ 检索式：（词 + 异体/通假映射 + 停用词处理）
④ 三个数：（召回估计 / 精确抽检 n 条中 m 条可用 / 版本是否统一）
⑤ 结果：（数量 + 分布，不给结论）
⑥ 回原文核：（抽 2—3 条回原书影像或权威整理本核对，记差异）
⑦ 能支持什么：（一句，且须与①对应）
```

①要求「可被否证」，是这一章最要紧的一条。可被否证的问题长这样：「《伤寒论》中『桂枝』与『芍药』在同一方中共同出现的条数，是否多于『桂枝』与『麻黄』？」不可否证的问题长这样：「桂枝汤是不是最重要的方？」后者无论检索出什么数都能圆回去，所以检索对它毫无意义。

④的三个数是上一节的落地。⑥是本章的底线动作：任何一条结果，抽两三条回原书核，核不上就说明这一批数据有问题。**回核不是可选项，它是数字人文与「搜一下」的分界线。**

⑦与①对应，是对「结论越界」的防范。

三种失效模式在这个框架下可定点排除。

**以今律古（此处表现为以现代语料习惯读古文本）。** 用现代汉语的分词标准切文言，用现代的词频直觉判断重要性。判据：这个切分在古注中有依据吗？没有，就是今人的切法。

**孤证立说。** 一次检索的一批结果就当作定论；一个库的数据就当作全部材料。判据：换一个库、换一个底本，结论是否还成立？

**训释脱离上下文。** 拿着词频分布去解释词义；拿着共现网络去证明因果。底本的两句话可以当判据用：频次高低不等于词义确定，统计相关不等于因果成立。

## 五、考核项

1. 说明图像、文本、知识三级数字化各自的失真方式，并指出哪一级的失真最容易被读者忽略、为什么。
2. 就「《素问》某字出现次数」这一问，写出④栏三个数应如何报，并说明为什么必须先统一底本。
3. 举一例说明语料库不做通假映射会造成什么后果，并给出补映射时所需的训诂依据。
4. 把「桂枝汤是不是最重要的方」改写成一个可否证的问题，并写出改写后的检索式要点。
5. 说明「抽 2—3 条回原文核」这一动作能发现哪两类错误，不能发现哪一类。
6. 指出下列哪一条违反「统计相关不等于因果成立」：某药与某证共现次数最多，故该药治该证最有效。

评分只看：①是否可被否证，④是否报齐三个数，⑥是否真的回核。

## 代价与边界

1. 本章所引数据库名称、收录范围与平台功能均转自底本，未逐一实测；各库的收录数与底本版本可能已有变化，引用时须核当前说明。
2. 本章不给任何具体数据库的操作步骤与检索语法。工具界面变动快，写成步骤的教程很快失效；本章只给判断口径。
3. 知识图谱的实体与关系抽取依赖人工校验，本章不主张用自动抽取结果直接立论；底本引「典籍可溯、文本可证」之旨，落点仍在原文与版本。
4. 本章不评价任何一部工具书的优劣，也不推荐替代品；选本的标准是「有没有交代底本与标注规范」，不是「好不好用」。
5. 本章不涉及诊疗判断。检索与统计只处理「文本里有什么」，不处理「病人该怎么治」。
