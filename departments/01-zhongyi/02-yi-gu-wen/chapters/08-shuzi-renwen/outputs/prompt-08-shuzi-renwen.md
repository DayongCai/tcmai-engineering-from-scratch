# 检索不是回答：词频给出的是候选，不是结论 · 提示词

## 用途

给「检索不是回答：词频给出的是候选，不是结论」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「数字化的三级，失真各有其形 → 一次检索要报三个数 → 语料库的三种失败：分词、通假、异文 → 记录字段与三种失效」这条链。

```

正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
```
