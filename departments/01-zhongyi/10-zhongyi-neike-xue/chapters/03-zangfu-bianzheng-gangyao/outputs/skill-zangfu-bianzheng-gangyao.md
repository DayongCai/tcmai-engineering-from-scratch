# Skill：脏腑辨证纲要与内科治则——模板、纲与两个补丁

## 何时用

- 读到一个证型，要问它由哪一条脏腑功能失常推出来
- 面对一系几十个证型记不住，需要用三四条功能把它们串起来
- 要判断某一系的纲为什么是「宣降」而不是「补泻」，或反之
- 遇到纲的例外（如「肾无实证」却有湿热淋证）
- 读到各论某病证的病因病机，需要回推它的功能依据

## 核心判据（六问）

1. **这一系的功能有哪几条？** 每条要写到「管什么、往哪个方向」。只写「主气」是不够的，要写「吸清呼浊、主一身之气」。
2. **失常之后出现什么？** 写成因果链：某功能失常 → 某类症状。写不成因果链的，说明功能还没写实。
3. **这个证归哪条功能？** 每个证都要能指回一条功能。指不回的，要么改归别系，要么标「模板装不下」。
4. **纲属于哪一型？** 六型：恢复一个功能（宣降）/ 判虚实再补泻 / 一对相反运动（升降）/ 体用并调 / 以补为主 / 气血同调。型由核心矛盾决定，不由习惯决定。
5. **纲有没有例外？** 有例外的纲才是真纲。肾的例外是湿热淋证与实证水肿；肺的例外表现为用药上的反向约束（忌苦寒冰伏、忌辛散太过）。
6. **分寸是性质还是数量？** 轻清灵动、平和权衡、甘温、甘凉、补而不腻——这些都是性质。凡出现数量，一律回到「剂量与用法照底本」。

## 执行步骤

```text
1. 定位：位置、开窍、在体、在志、在液、表里，一句带过
2. 功能：两到三条，写到方向与对象
3. 失常：每条功能写因果链
4. 归证：证型归到功能上，指不回的单列
5. 定型：判断纲属于六型中的哪一型，写理由
6. 找例外：例外条件 + 例外时改用哪个方向
7. 分寸：用药性质与禁忌，不写数量
8. 反查：抽掉一条功能，哪些证失去依据
```

## 硬约束

- **不写剂量、用法与疗程的量值。** 需要剂量时统一写「剂量与用法照底本」。
- **不作诊断，不作证候判定，不作病情与预后判定，不作疗效与优越性断言。**
- **证名照教材**，不自创证名，不把两个证名合成一个新名。
- **引文逐字。** 标「教材·中医内科学·第N章·M.K」，核不到原文就不引。
- **纲不当教条。** 凡写纲，必须同时写例外或写「本教材未见例外」。
- **不确定就写下来。** 标待核实，不用推测填空。

## 交付物

1. 一份四步模板：功能 → 失常 → 证候 → 治法
2. 一句定型判断：这一系的纲属于哪一型，理由是什么
3. 一处例外：纲在什么条件下不适用
4. 一处反查：抽掉某条功能后失去依据的证

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 跳过功能背证型 | 证型之间毫无联系 | 先写功能，再归证 |
| 功能写虚 | 「主疏泄」四字了事 | 补「管什么、往哪个方向」 |
| 纲当口号 | 「以宣降为纲」不作解释 | 补六型判断与理由 |
| 纲无例外 | 遇到实证仍温补 | 补例外条件 |
| 跨系硬塞 | 把痰湿证硬归肺 | 标跨系，写清两系各占哪一半 |
| 分寸写成数量 | 「用量宜轻」写成具体数 | 改为性质，剂量照底本 |

## 边界

本 Skill 只处理「一系病证 → 可复用模板」的结构表达，不涉及剂量、诊断结论与临床决策。本章内容为教学材料，不构成诊断与用药依据；任何涉及个体的诊治评估须由具备资质的人员依现行法律法规与规范作出。
