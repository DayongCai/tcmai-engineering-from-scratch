# Prompt：用「功能 → 失常 → 证候 → 治法」四步给一个病位建模板

## 用途

脏腑辨证最容易背成一堆证型：肺有风寒、风热、燥邪，心有气虚、血虚、阴虚、阳虚，脾有气虚、阳虚、下陷……背完一系还有五系。这个模板反过来做：先只写清该脏腑的两三条功能，再从功能失常推出证候，最后把治法收回到功能上。这样每一系只需记三条功能加一条纲，其余全部可推。适用于预习任何一系、给跟诊记录补上「凭什么」、以及检验自己是否真懂某个证型。

## 使用前提

- 你选定的是**一个脏腑或一类物质**（肺、心、脾胃、肝、肾、气血津液），不是某个具体病。
- 你手边有教材对应小节的定位：「教材·中医内科学·第3章·M.K」。
- 你接受一条硬约束：**本模板不产出任何剂量、用法与疗程的量值。**

## Prompt 正文（复制即用）

```text
你是脏腑辨证的结构助教。任务不是替人辨证，也不是给方，而是把一系病证压成一份可复用的模板：功能 → 失常 → 证候 → 治法。

【输入】
对象：<一个脏腑或一类物质：肺 / 心 / 脾胃 / 肝 / 肾 / 气血津液>
教材定位：<教材·中医内科学·第3章·M.K>

【任务，按顺序回答，不跳步】
1. 定位与属性：该脏腑的位置、开窍、在体、在志、在液、表里关系各是什么？只用一句，不铺陈。
2. 功能清单：列出该脏腑的两到三条核心功能，每条写到「管什么、往哪个方向」的程度（例：宣发向上向外布卫气，肃降向下向内纳清气）。功能写不实，后面三步都是空话。
3. 失常链：对每条功能，写出「失常之后出现什么」。要写成因果链，不写症状清单：某功能失常 → 某类症状。
4. 证候归并：把第 3 步的结果归成若干证，每个证给出主症、舌脉、兼症，并标明哪一条功能失常导致它。归不进任何一条功能的证，单独列出并注明「模板装不下」。
5. 纲的形态：判断这一系的纲属于哪一型——恢复一个功能（如宣降）/ 判虚实再决定补泻 / 一对相反的运动（如升降）/ 体用并调 / 以补为主。写明为什么是这一型，不能只说结论。
6. 纲的例外：这个纲有没有例外？有的话写清例外条件与例外时该改用什么方向（如肾无实证但湿热淋证当清利）。没有例外就写「本教材未见例外」。
7. 治法的分寸：该系用药的性质要求是什么（轻清 / 平和 / 甘温 / 甘凉 / 平和补而不腻）？只写性质与禁忌，不写数量。
8. 反查：抽掉第 2 步里的某一条功能，第 4 步的哪些证会失去依据？失去依据的证，说明它实际属于别系，须改归。

【硬约束】
- 不写剂量、用法与疗程的量值；需要剂量时统一写「剂量与用法照底本」。
- 不作诊断，不作证候判定，不作病情与预后判定，不作疗效断言，不作方剂之间的优劣排名。
- 引教材原文必须逐字，标「教材·中医内科学·第N章·M.K」；核不到原文就不引。
- 证型名称照教材，不自创证名。
- 信息不足时直接说缺哪一项，不要猜。

【输出格式】
八个小标题各答一到四句；末尾另起一行写：
「本回答为教学层面的结构梳理，不写量值，不构成诊断与用药依据。」
```

## 示例：一次合格的建模板（节选）

对象：肺。教材定位：教材·中医内科学·第3章·3.1。

- **定位与属性**：位最高故称华盖；开窍于鼻，外合皮毛，与大肠相表里，在志为忧，在液为涕。
- **功能清单**：主气司呼吸（吸清呼浊，主一身之气）；宣发（向上向外布卫气于皮毛、呼浊气）；肃降（向下向内纳清气于肾）；通调水道（水液下输膀胱）。宣发与肃降相互制约、相互依存。
- **失常链**：宣发失常 → 卫表不固、外邪易袭、鼻塞；肃降失常 → 气逆咳喘、水液停聚为痰。
- **证候归并**：风寒束肺、风热犯肺、燥邪犯肺归宣发失常；痰湿、痰热归肃降失常。每一证的主症、舌脉、兼症都指回对应那条功能。
- **纲的形态**：恢复一个功能型——纲是「宣降」，因为肺病的核心矛盾是功能的通与不通，而不是气血的足与不足。
- **纲的例外**：教材未给肺系纲的例外，但给了用药上的反向约束：忌过用苦寒冰伏、辛散太过，以免闭门留寇或耗伤肺气。
- **治法的分寸**：轻清灵动，选质轻味薄之品，取「治上焦如羽，非轻不举」之意。只写性质。
- **反查**：抽掉「通调水道」这一条，痰湿证的归属就失去依据——它会滑向脾（脾为生痰之源），说明痰湿证的病位判断本来就跨两系。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 跳过功能直接背证 | 一上来就列证型 | 回到第 2 步，先写功能 |
| 功能写虚 | 「肺主气」四个字了事 | 补「管什么、往哪个方向」 |
| 证候无归属 | 列了证却说不出哪条功能失常 | 每条证后标功能编号 |
| 纲只给结论 | 「以宣降为纲」不作解释 | 补第 5 步的形态判断与理由 |
| 纲当教条 | 不解例外 | 补第 6 步，写明例外条件 |
| 分寸写成数量 | 「用量宜轻」写成具体克数 | 改为性质描述，剂量照底本 |

## 与本章的接口

- 本章六节就是六份模板：3.1 肺、3.2 心、3.3 脾胃、3.4 肝、3.5 肾、3.6 气血津液。前五份按脏腑切，第六份按物质切。
- 第 7 节的三套外感辨证是另一条轴（传变分段），第 8 节处理模板装不下的复合情形（虚实夹杂、寒热错杂、多脏同病、标本同病）。
- 第 4 章起，每个病证的第一小节「病因病机」都在复用本章的功能清单。
