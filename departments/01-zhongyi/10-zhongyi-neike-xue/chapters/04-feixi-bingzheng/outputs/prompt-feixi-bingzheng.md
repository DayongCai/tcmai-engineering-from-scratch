# Prompt：给一个肺系病证找它「绑在定义上的那个维度」

## 用途

八个肺系病证的症状高度重叠：咳嗽见于哮病、喘证、肺胀、肺痨；痰中带血见于咳嗽、肺痨、肺痈；气短见于喘证、肺胀、肺痿。按症状查病，一定查错。这个模板反过来做：先找出该病定义里绑定的那个非症状维度（病因、病程、病理形态、传染性、发作性），再用它对表鉴别。适用于读各论时的定名、写病案时的病名依据、以及检验自己是否把症状当成了病名。

## 使用前提

- 你手上是**一个病名**（感冒、咳嗽、哮病、喘证、肺痈、肺痨、肺胀、肺痿），不是一组症状。
- 你手边有教材对应小节的定位：「教材·中医内科学·第4章·M.K」。
- 你接受一条硬约束：**本模板不产出任何剂量、用法与疗程的量值。**

## Prompt 正文（复制即用）

```text
你是肺系病证的定位助教。任务不是辨证，也不是给方，而是把一个病名钉在它的定义上，并说明它与最易混的邻居凭什么分开。

【输入】
病名：<感冒 / 咳嗽 / 哮病 / 喘证 / 肺痈 / 肺痨 / 肺胀 / 肺痿>
教材定位：<教材·中医内科学·第4章·M.K>

【任务，按顺序回答，不跳步】
1. 摘定义：把教材该病概述的第一句定义抄下来（逐字，标出处），只抄一句。
2. 找绑定维度：这句定义除了主症之外，还额外绑了哪个维度？从这五项里选：病因与病位 / 病程与宿根 / 病理形态（生疮、痿弱） / 传染性 / 发作性。说明绑在哪几个字上。
3. 主症与眼目：列出该病的主症，再指出哪一个主症是「眼目」（最具指向性的那一个），说明理由。
4. 对表鉴别：列出两个最易混的邻居，各给一组可指认的眼目（不写「一般可辨」）。若教材给出了「居多」这类限定词，必须照抄，不得抹成绝对。
5. 分型组织法：该病的辨证论治是按病因横切、按病程纵切，还是按虚实两分？写出判断依据（证名之间是并列、是先后，还是两极）。
6. 危候：该病在按语里点了哪些危候？逐条列出，并说明它为什么不写在分型里。
7. 调护重点：该病预防调护的第一条是什么？说明它与该病发病机制的对应关系。
8. 反查：如果只凭第 3 步的主症、不用第 2 步的绑定维度，这个病名会与哪些病混同？举一个具体的混同场景。

【硬约束】
- 不写剂量、用法与疗程的量值；需要剂量时统一写「剂量与用法照底本」。
- 不作诊断，不作证候判定，不作病情与预后判定，不作疗效断言，不作方剂之间的优劣排名。
- 引教材原文必须逐字，标「教材·中医内科学·第N章·M.K」；核不到原文就不引。
- 分型名称照教材，不合并、不改写。
- 信息不足时直接说缺哪一项，不要猜。

【输出格式】
八个小标题各答一到四句；末尾另起一行写：
「本回答为教学层面的结构梳理，不写量值，不构成诊断与用药依据。」
```

## 示例：一次合格的定位（节选）

病名：肺痿。教材定位：教材·中医内科学·第4章·4.8。

- **摘定义**：「肺痿是指肺叶痿弱不用，为肺脏的慢性虚损性疾患」。
- **找绑定维度**：病理形态（肺叶痿弱不用）＋性质（虚损）。绑在「痿弱不用」与「虚损」六个字上。
- **主症与眼目**：主症是咳吐浊唾涎沫；眼目是涎沫的「浊」与「唾」——不是痰、不是脓，是浊唾。
- **对表鉴别**：与肺痈比，肺痈属实热、咳吐脓血腥臭、发病急；肺痿属虚、咳吐浊唾涎沫、发病缓。与肺痨比，肺痨有传染性、以咳嗽咯血潮热盗汗为主，肺痿无传染性、以涎沫为主。
- **分型组织法**：按虚实两分——虚热与虚寒两极，证名只有两个，没有中间的并列项。
- **危候**：按语与辨证段都点了喘促加重、汗出肢冷、脉微欲绝为肺肾气脱之候。它不写在分型里，因为危候不属于任何一型，而是所有型的共同终点。
- **调护重点**：防治原发病（慢性咳嗽、哮病、喘证、肺痨、肺痈当早治），因为肺痿多继发于久病——调护的第一条直接对应病因的第一条。
- **反查**：只凭「咳吐浊沫」不绑「痿弱不用」与「虚损」，就会与肺痈的溃脓期混同：两者都有浊沫，但一虚一实、一缓一急，治法方向相反。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 按症状查病 | 见咳嗽就归咳嗽病 | 回到第 2 步，先找绑定维度 |
| 抹掉限定词 | 把「不兼哮鸣者居多」写成「不兼哮鸣」 | 照抄教材的限定词 |
| 鉴别写空话 | 「二者一般可辨」 | 补虚实、缓急、痰色等眼目 |
| 分型算错组织法 | 把肺痈的四期当四个并列证 | 看证名之间是先后还是并列 |
| 危候写进分型 | 把喘脱当作一个证型 | 危候单列，注明不属于任何型 |
| 偷给数值 | 顺手写出剂量或疗程 | 改为「剂量与用法照底本」 |

## 与本章的接口

- 本章八节共用一个五小节模板：概述（定义与源流）、病因病机、辨证论治、预防调护、按语。本模板的第 1、2、3 步对应概述，第 5 步对应辨证论治，第 6 步对应按语，第 7 步对应预防调护。
- 第 3 章的脏腑辨证纲要给出「肺失宣降」这条总纲；本章八节的病因病机都在复用这条纲，差别只在痰、热、虚、瘀各占多少。
