# Skill：肺系病证——定义、分型组织法与鉴别网

## 何时用

- 读到一个肺系病名，要问它凭什么独立成病、与邻居怎么分
- 症状重叠时（咳嗽见于多病、痰中带血见于多病），需要一条不靠症状的判据
- 要判断某病的辨证论治是按病因横切、按病程纵切，还是按虚实两分
- 读到按语里的危候，要问它为什么不在分型里
- 需要有依据地说明「这不是我随手定的，是教材的定义如此」

## 核心判据（六问）

1. **定义绑了什么？** 除主症之外的维度只有五种：病因与病位（感冒）、病程与宿根（哮病、肺胀）、病理形态（肺痈生疮、肺痿痿弱）、传染性（肺痨）、发作性（哮病）。绑不出维度的病名，说明定义还没读进去。
2. **眼目是哪一症？** 主症可以有几个，眼目只有一个——最具指向性的那一个。肺痿的眼目是涎沫的「浊」，不是「咳」。
3. **邻居是谁？** 每个病至少两个最易混的邻居，各给一组可指认的眼目。教材的限定词（「居多」「多属」）必须照抄，不得抹成绝对。
4. **分型怎么组织？** 三种：按病因横切（感冒、咳嗽）、按病程纵切（肺痈四期、肺痨四台阶、肺胀发作与缓解）、按虚实两分（喘证、哮病、肺痿）。判据是证名之间是并列、先后，还是两极。
5. **危候在哪？** 都在按语。危候不属于任何一型，它是所有型的共同终点——所以不能写成证型。
6. **调护第一条是什么？** 它必须与该病发病机制的第一条对应：哮病避诱因（诱因是触发点）、肺胀戒烟（烟是最重要病因）、肺痈排痰（脓痰是关键）、肺痨防传染（传染是定义性特征）。

## 执行步骤

```text
1. 抄定义：概述第一句，逐字，标出处
2. 找维度：五项里选，指出绑在哪几个字上
3. 定眼目：主症列出，圈出唯一眼目
4. 对表：两个邻居 + 两组眼目 + 照抄限定词
5. 判组织法：横切 / 纵切 / 两分，给依据
6. 列危候：按语里的危候逐条抄，注明不属任何型
7. 对机制：调护第一条 ↔ 病因第一条
8. 反查：抽掉维度，会与谁混同，给一个具体场景
```

## 硬约束

- **不写剂量、用法与疗程的量值。** 需要剂量时统一写「剂量与用法照底本」。
- **不作诊断，不作证候判定，不作病情与预后判定，不作疗效与优越性断言。**
- **证名照教材**，不合并两个证、不改写证名、不把四期当四个证。
- **引文逐字。** 标「教材·中医内科学·第N章·M.K」，核不到原文就不引；改写须标明是改写。
- **限定词照抄。** 「居多」「多属」「多见」不得删。
- **危候单列。** 喘脱、大咯血、神昏等只提示及时就医，不给处理建议。

## 交付物

1. 一句定义 + 一个绑定维度
2. 一组鉴别：两个邻居、两组眼目
3. 一句组织法判断：横切 / 纵切 / 两分，附依据
4. 一处反查：抽掉维度后会与谁混同的具体场景

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 按症状查病 | 见咳归咳、见痰归痈 | 先找定义绑定的维度 |
| 眼目选错 | 把「咳」当肺痿的眼目 | 眼目要最具指向性 |
| 抹掉限定词 | 「居多」写成「一定」 | 照抄教材措辞 |
| 期证混用 | 把肺痈四期当四个并列证 | 看证名之间是先后还是并列 |
| 危候入型 | 把喘脱写成证型 | 危候单列，注明不属任何型 |
| 偷给数值 | 顺手写出剂量 | 改为「剂量与用法照底本」 |

- 第 3 章（脏腑辨证纲要与内科治则）：给「肺失宣降」这条总纲与宣降为纲的用药分寸；本章八节的病因病机都在复用它。
- 第 5 章起（心系、脾胃系…）：同一套五小节模板与同一套鉴别方法，换掉病名与眼目即可复用。

## 边界

本 Skill 只处理「病名 → 定义绑定的维度 → 鉴别眼目」的结构表达，不涉及剂量、诊断结论与临床决策。本章内容为教学材料，不构成诊断与用药依据；任何涉及个体的诊治评估须由具备资质的人员依现行法律法规与规范作出。
