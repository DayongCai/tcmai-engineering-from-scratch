# Skill：辨证论治思路与方法——辨、治、调三段

## 何时用

- 拿到一份四诊资料，要把「症状→病名→证候→治法→方」这条路走通
- 跟诊记录写完只有结论没有判据，需要回填「凭什么」
- 遇到主症与兼症分不清、病名与证名混着写的情况
- 同一个病在不同阶段出现不同证，需要说明为什么会变
- 有人问「先治标还是先治本」，需要一条可指认的判据

## 核心判据（六问）

1. **主症是哪一条？** 须同时满足「感受最明显」「最突出」「对诊断最有价值」。三条缺一，就只能算突出症状，不能算主症。
2. **主病是什么？** 由主症定病名；同时说出同一主症还可能属哪些病、拿什么分开。说不出来，说明定位还没做。
3. **病位在哪？** 按脏腑功能与经络循行定位，写出用的是哪一条功能依据。病位可变（肝火犯肺、脾虚生痰皆令人咳），故须分清主次。
4. **病性是什么？** 六淫加气滞、血瘀、痰饮、食积、气血阴阳虚实。主症、舌脉、兼症权重不同，不能等量相加。
5. **先治标还是先治本？** 判据是危急程度，不是因果层级。标本随病程转化，每次复诊重判。
6. **判断交给谁？** 结论由具备资质的人员依四诊合参与现行规范作出。

## 执行步骤

```text
第一段 辨
1. 收口：把四诊资料压成一句主诉，标出缺项
2. 定主症：三条判据逐条核，缺哪条写哪条
3. 定主病：给出病名，并列出需排除的相邻病与眼目
4. 定病位：脏腑功能依据写实，不写「有关」
5. 定病性：主症 / 舌脉 / 兼症分权重
6. 辨标本：本与标各是什么，先治哪一头，判据写危急程度

第二段 治
7. 立治则：五条治则里指出主约束，其余如何同时成立
8. 定治法：八法里选方向，写出该法的禁忌与度
9. 组方：君臣佐使各治什么，方证对应的依据是什么，不写药量

第三段 调
10. 起居情志：每条要点后面写依据
11. 饮食：写性质与忌口，不写份量频次
12. 随访：目的、方式、监测变化、先兆征象
```

## 硬约束

- **不写剂量、用法与疗程的量值。** 需要剂量时统一写「剂量与用法照底本」。
- **不作诊断，不作证候判定，不作病情与预后判定，不作疗效与优越性断言。**
- **引文逐字。** 标「教材·中医内科学·第N章·N.M」，核不到原文就不引；改写须标明是改写。
- **层次标注。** 每句话要说清它在病、证、症哪一层，跨层须补中间环节。
- **危重征象单列。** 喘脱、大出血、神昏等只提示及时就医，不给处理建议。
- **不确定就写下来。** 标待核实，不用推测填空。

## 交付物

1. 一条三段链：辨（主症→主病→病位→病性→标本）→ 治（治则→治法→方）→ 调（起居→饮食→随访）
2. 每段至少一条判据：凭什么这样定
3. 一处鉴别：最易混的相邻病证与可指认的眼目
4. 一处待核实：缺的是哪一项资料

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 主症凭印象 | 抓到的是最响的症状 | 三条判据逐条核 |
| 病证混写 | 「风寒咳嗽证」当病名 | 病名与证名分行 |
| 病位含糊 | 「与肺脾有关」 | 写明脏腑功能依据 |
| 标本凭因果 | 「本是根，故先治本」 | 改判危急程度 |
| 治法无禁忌 | 只写方向不写度 | 补禁忌与中病即止 |
| 调护写成清单 | 只有做法没有依据 | 每条后面写依据 |

## 与相邻章节的接缝

- 第 1 章（绪论）：给的是定位坐标（归属、来路、读法）；本章把它变成一条可执行的工序。
- 第 3 章（脏腑辨证纲要与内科治则）：把「定病位」拆成五脏系统的生理、证候与辨治要点，并补六经、卫气营血、三焦三套辨证的分工。
- 第 4 章起（各论）：每个病证都是这条流水线的一次完整走法，差别只在病名与分型。

## 边界

本 Skill 只处理「四诊资料 → 可复核的三段链」的表达，不涉及剂量、诊断结论与临床决策。本章内容为教学材料，不构成诊断与用药依据；任何涉及个体的诊治评估须由具备资质的人员依现行法律法规与规范作出。
