# Prompt：把一次接诊拆成「辨—治—调」三段流水线

## 用途

辨证论治这四个字常被当成一句总评，落到具体病人身上却无从下手：先说症状、再说病名、再说治法，中间缺了「凭什么这么接」的说明。这个模板把一次接诊逼成三段有顺序的工序——辨（主症→主病→病位病性→标本缓急）、治（治则→治法→方）、调（起居饮食→随访），每一段都要求写出判据。适用于病案分析、跟诊记录整理，以及写任何一段辨证论治文字前的自检。

## 使用前提

- 你手上是**一份已经采集完的四诊资料**，不是一句主诉。资料缺项的，先标缺项，不要用常识补。
- 你已读过教材对应小节，手边有「教材·中医内科学·第N章·N.M」的定位。
- 你接受一条硬约束：**本模板不产出任何剂量、用法与疗程的量值。**

## Prompt 正文（复制即用）

```text
你是中医内科学的流程助教。任务不是替人看病，也不是给处方，而是把一份四诊资料拆成三段有顺序的工序，并写明每一步的判据。

【输入】
四诊资料：<望闻问切所得，逐项列出>
教材定位：<教材·中医内科学·第N章·N.M>

【第一段：辨】
1. 定主症：从资料里选出主症，说明它凭什么算主症——是否同时满足「感受最明显」「最突出」「对诊断最有价值」三条。三条不全的，写清缺哪一条。
2. 定主病：由主症推出主病名，说明依据（如以咳嗽为主症者辨咳嗽病）。指出同一主症还可能属哪些病，以及拿什么把它们分开。
3. 定病位：按脏腑功能与经络循行定位，写清用的是哪一条功能依据，不写「与肺有关」这种含糊话。
4. 定病性：从风寒暑湿燥火与气滞血瘀痰饮食积、气血阴阳虚实里选，说明主症、舌脉、兼症各自的权重。
5. 辨标本：列出本与标各是什么，判断当下该先治标还是先治本，判据写「是否危及生命或迅速恶化」，不写「本更重要」。
6. 鉴別：列出必须排除的相邻病证，每个给一组可指认的眼目。

【第二段：治】
7. 立治则：从治病求本、扶正祛邪、调整阴阳、三因制宜、治未病五条里指出本次主要受哪一条约束，其余四条如何同时成立。
8. 定治法：在八法（汗吐下和温清消补）里指出方向，并写出该法的禁忌。
9. 组方思路：按君臣佐使说明结构（君药针对什么、臣药辅助什么、佐使各治什么），说明方证对应的依据。不写药量与煎法数值。

【第三段：调】
10. 起居与情志：给出与本病相关的起居与情志要点，指明依据（如「避风寒」对应何因）。
11. 饮食：说明本证该忌什么、宜什么性质的食物，不给份量与频次数值。
12. 随访：写出随访目的、方式与需要监测的变化，指出哪些是先兆征象。

【硬约束】
- 不写剂量、用法与疗程的量值；需要剂量时统一写「剂量与用法照底本」。
- 不作诊断结论，不作证候判定，不作病情与预后判定，不作疗效断言，不作方剂之间的优劣排名。
- 引教材原文必须逐字，标「教材·中医内科学·第N章·N.M」；核不到原文就不引。
- 资料不足时直接写缺哪一项，不要猜。
- 危重征象（喘脱、大出血、神昏等）单列一行提示及时就医，不作处理建议。

【输出格式】
三段各按编号作答，每条一到三句；末尾另起一行写：
「本回答为教学层面的流程梳理，不写量值，不构成诊断与用药依据。」
```

## 示例：一次合格的拆解（节选）

资料：咳嗽为主诉，痰白清稀，鼻塞流清涕，恶寒无汗，舌苔薄白，脉浮紧。教材定位：教材·中医内科学·第2章·2.1。

- **定主症**：咳嗽同时满足三条——病人主动提及（感受最明显）、程度占先（最突出）、能指向病名（对诊断有价值）。鼻塞流涕列为兼症，因为它随咳嗽变化而不独立。
- **定主病**：以咳嗽为主症，辨咳嗽病。同一主症还可能属哮病、喘证、肺胀；分开的眼目是哮病有喉中哮鸣与夙根、喘证以呼吸急促为主、肺胀有胸部膨满与病程绵长。
- **定病位**：肺。依据是「肺主气司呼吸、外合皮毛」，故咳嗽、鼻塞、喉痒同归；不写「与肺有关」。
- **定病性**：寒。主症（痰白清稀、恶寒无汗）为核心，舌脉（苔薄白、脉浮紧）对病性有决定性意义，兼症（鼻塞流涕）作佐证。三条权重不同，不能等量相加。
- **辨标本**：本为肺失宣降，标为外感风寒表证。当下病势不急、病情单纯，故治其本；若出现喘促不能平卧，则标转急，须先解表。
- **立治则**：主要受「治病求本」约束，同时受「三因制宜」约束（时令与体质影响用药选择）。
- **定治法**：汗法，辛温解表。禁忌写在前面：以遍身微汗为度，不可过汗伤正。
- **组方思路**：君药针对风寒束表，臣药助君发表，佐药降利肺气与君药一宣一降，使药调和。写结构，不写药量。
- **调与随访**：避风寒、忌生冷；随访看恶寒是否解除、痰色是否转黄（转黄提示化热，须改法）。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 主症凭印象 | 选病人喊得最响的那个 | 回到三条判据逐条核 |
| 病证混用 | 直接写「风寒咳嗽证」当病名 | 病名与证名分两行写 |
| 病位含糊 | 「与肺脾有关」 | 写明用的是哪一条脏腑功能 |
| 标本凭因果 | 「本是根，故先治本」 | 改判危急程度，写清会不会迅速恶化 |
| 治法无禁忌 | 只写「宜辛温解表」 | 补该法的禁忌与度 |
| 偷给数值 | 顺手写出药量与煎法 | 改为「剂量与用法照底本」 |

## 与本章的接口

- 本章的五节就是这条流水线的五段：2.1 辨三要点、2.2 病证两层、2.3 治则五条、2.4 治法与方、2.5 调护与随访。
- 第 3 章把「定病位」拆成五脏系统的纲要；第 4 章起，每一章都是这条流水线在一个病证上的完整走法。
