# Skill：绪论——学科界定、范围、源流与读法

## 何时用

- 读到一个新病名，需要先判断它归哪一门、为什么不归另一门
- 要在总论三章（绪论、辨证论治思路、脏腑辨证纲要）之间迁移同一套定位方式
- 有人拿病名当证名，或拿症状当证候，需要把讨论拉回层次
- 遇到「这两个病怎么分」的问题，需要一组可指认的鉴别眼目
- 读到某条治法，要问它的来路与适用边界

## 核心判据（五问）

1. **归哪一门？** 肺系、心系、脾胃系、肝胆系、肾系、气血津液、肢体经络。判据是病位与病性，不是病名的字面。答不出归属，说明病位还没找到。
2. **来路是什么？** 六经出自《伤寒论》，卫气营血出自叶天士，三焦出自吴鞠通，脾胃学说出自李杲，活血化瘀一路有王清任。知道来路，才知道这条说法当初是为解决什么问题提出的。
3. **在哪一层？** 病是全程，证是阶段，症是当下表现。三层不许互换：拿证当病，会漏掉全程规律；拿症当证，会把兼症当病机。
4. **按什么顺序读？** 概念与源流 → 病因病机 → 辨证分型 → 治法方药 → 预防调护 → 按语。六段是固定体例，跳过任何一段都会在读下一段时补不回来。
5. **边界在哪？** 与相邻对象怎么分开。要一组可指认的眼目（虚实、缓急、痰色、病程），不要「一般可辨」这类空话。判断最终归具备资质的人员。

## 执行步骤

```text
1. 收口：把待定位的对象压成一个病名或一条治法，删掉症状清单
2. 归门：按病位与病性选一门，写明判据；归不进就写归不进
3. 溯来路：找出处（书名或医家），找不到标「出处待核实」
4. 定层：病 / 证 / 症，选一层为主，说明换层会错在哪
5. 排读序：按六段体例标出这一条最容易跳过的一环
6. 找鉴别：配一组最易混的对象，写可指认的眼目
7. 定去向：谁判断、依什么、如何留痕
8. 反查：抽掉病位判据，归属是否还成立；不成立即为待补
```

## 硬约束

- **不写剂量、用法与疗程的量值。** 需要剂量时统一写「剂量与用法照底本」。
- **不作诊断，不作证候判定，不作病情与预后判定，不作疗效与优越性断言，不作等级排名。**
- **引文逐字。** 标「教材·中医内科学·第N章·N.M」，核不到原文就不引；改写须标明是改写。
- **不写商品名、厂商、剂型规格与价格。**
- **层次标注。** 每条结论都要能回答「这在病、证、症哪一层」，跨层必须补中间环节。
- **不确定就写下来。** 标待核实，不用推测填空。

## 交付物

1. 一条定位链：归属 → 来路 → 层次 → 读序 → 鉴别 → 去向
2. 一句边界句：本段只描述病机与治法，判断归属另行
3. 一处待核实事项：缺的是病位判据、出处，还是鉴别眼目
4. 一处反查：抽掉某项判据，归属是否还成立

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 见字归类 | 见「肺」字就归肺系 | 用病位与病性作判据 |
| 病证混用 | 拿证名当病名 | 回到第三问，写清层次 |
| 出处含糊 | 「古人早有论述」 | 补书名或标待核实 |
| 鉴别写空 | 「二者一般可辨」 | 补虚实、缓急、痰色等眼目 |
| 越界判定 | 顺势给出诊断 | 改写为「判断归具备资质的人员」 |
| 偷给数值 | 顺手写出剂量 | 改为「剂量与用法照底本」 |

## 与相邻章节的接缝

- 第 2 章（辨证论治思路与方法）：把本章的「读序」拆成抓主症、辨病位病性、辨标本缓急，把「判断」拆成病名、证候与病证结合。
- 第 3 章（脏腑辨证纲要与内科治则）：把本章的「归属」拆成五脏系统的生理、证候与辨治要点，并补上六经、卫气营血、三焦三套辨证的分工。
- 第 4 章起（各论）：本章的五问在每一个病证上复用，只是结论换掉。

## 边界

本 Skill 只处理「病证或治法 → 可核对位置」的表达，不涉及剂量、诊断与临床决策。本章内容为教学材料，不构成诊断与用药依据；任何涉及个体的诊治评估须由具备资质的人员依现行法律法规与规范作出。
