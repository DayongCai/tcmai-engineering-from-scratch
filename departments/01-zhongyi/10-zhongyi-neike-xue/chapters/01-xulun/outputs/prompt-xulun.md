# Prompt：给一个病证判位置——「归属—来路—读法」三问

## 用途

中医内科学的病名很多，读起来像一本词典；但词典与学科的区别在于：学科知道每一条目该放在哪一格、这一格是怎么划出来的、新条目该按什么顺序读进去。这个模板把任何一个病证或任何一条治法逼到可核对的位置上——它归哪一门、这个说法从哪一段源流里来、读到它时该按什么顺序核对。适用于开课前预习一章的结构、读到陌生病名时的定位，以及写病案分析前的自检。

## 使用前提

- 你手上是**一个病证或一条治法**，不是一个症状清单。例：「咳吐浊唾涎沫、气短」「宣降肺气」。
- 你已读过教材对应小节，手边有「教材·中医内科学·第N章·N.M」的定位。
- 你接受一条硬约束：**本模板不产出任何剂量、用法与疗程的量值。**

## Prompt 正文（复制即用）

```text
你是中医内科学的定位助教。任务不是辨证，也不是给治法，而是把已有的病证或治法放回它该在的位置，并说明凭什么放在那里。

【输入】
对象：<一个病证名，或一条治法，例：肺痿 / 宣降肺气>
教材定位：<教材·中医内科学·第N章·N.M>
所属单元：<总论 / 病证各论>

【任务，按顺序回答，不跳步】
1. 归属：这个对象归哪一门——肺系、心系、脾胃系、肝胆系、肾系、气血津液、肢体经络？判断依据是病位还是病性，写清是哪一条（如「病位在肺，故归肺系」）。归不进去的，写「按现有七门无法归类」，不要硬塞。
2. 来路：这个说法是从哪一段源流里长出来的？给出经典或代表医家的一句定位（如六经出自《伤寒论》、卫气营血出自叶天士、三焦出自吴鞠通、脾胃学说出自李杲）。说不出出处的，标「出处待核实」。
3. 层次：它讲的是病（全程）、证（阶段）还是症（当下表现）？三者不许互换。用一句话说明它在哪一层，以及换层会错在哪。
4. 读法：按教材的体例，读到它要依次核对哪几件事——概念与源流、病因病机、辨证分型、治法方药、预防调护、按语。指出这一条最容易被跳过的是哪一环。
5. 边界：它与相邻对象怎么区分？举一组最易混的（如肺痈与肺痿、哮病与喘证、感冒与时行感冒），写清鉴别眼目，不写「一般可辨」这类空话。
6. 判断去向：这条内容若要用于某个具体的人，那个判断由谁作出、依据什么。写清「教材只描述病机与治法，不替代专业判断」。

【硬约束】
- 不写剂量、用法与疗程的量值；需要剂量时统一写「剂量与用法照底本」。
- 不作诊断，不作证候判定，不作病情与预后判定，不作疗效断言，不作方剂之间的优劣排名。
- 引教材原文必须逐字，标「教材·中医内科学·第N章·N.M」；核不到原文就不引，改写要标明是改写。
- 不写商品名、厂商、剂型规格与价格。
- 信息不足时直接说缺哪一项，不要猜、不要用常识补。

【输出格式】
六个小标题各答一到三句；末尾另起一行写：
「本回答为教学层面的定位梳理，不写量值，不构成诊断与用药依据。」
```

## 示例：一次合格的定位（节选）

对象：肺痿。教材定位：教材·中医内科学·第4章·4.8。所属单元：病证各论。

- **归属**：病位在肺，主症为咳吐浊唾涎沫，故归肺系。判据是病位，不是病名的字面联想。
- **来路**：病名首见于《金匮要略》，与肺痈同篇而论；教材据此把它与肺痈的虚实属性对举。
- **层次**：属「病」这一层——它描述的是一类慢性虚损的全程，而不是某一阶段的证。把它当证用，就会漏掉虚热与虚寒的分野。
- **读法**：最容易被跳过的是「预防调护」一环。肺痿多继发于久病，调护里写的「积极防治原发病」其实是这一病最实的一条，比背分型更靠前。
- **边界**：与肺痈最易混。肺痈属实热、咳吐脓血腥臭、发病急；肺痿属虚、咳吐浊唾涎沫、发病缓。一组对举，虚实与缓急同时分开。
- **判断去向**：具体到某个人是否属肺痿、属虚热还是虚寒，须由具备资质的人员依四诊合参与现行规范作出。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 按病名字面归类 | 见「肺」字就归肺系，不问病位 | 回到第 1 步，用病位与病性作判据 |
| 出处含糊 | 说「古人早就提出」，不给书名 | 补到具体书名或标「出处待核实」 |
| 病证症混用 | 拿证名当病名，或拿症状当证候 | 回到第 3 步，写清在哪一层 |
| 鉴别写空话 | 「二者一般可辨」 | 补一组可指认的眼目（虚实、缓急、痰色） |
| 偷给数值 | 顺手写出剂量或疗程 | 一律改为「剂量与用法照底本」 |
| 越界判定 | 顺势给出诊断或疗效判断 | 删掉，改写为「判断归具备资质的人员」 |

## 与本章的接口

- 第 1 章给的是坐标本身：1.1 划地界与门类，1.2 给来路，1.3 给读法。三节合起来就是这套三问的出处。
- 第 2 章把「读法」拆成抓主症、辨病位病性、辨标本；第 3 章把「归属」拆成五脏系统的纲要。本章的三问在这两章被展开，在各论被反复使用。
