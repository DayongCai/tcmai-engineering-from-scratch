# Skill：肾系病证——水、溺、精三条通道

## 何时用

- 读到一句「浮肿」「小便不利」「不举」「滑精」，需要判断它落在哪条通道
- 要在淋证、癃闭、关格之间分辨，三病是一条溺道上的三个段位
- 遇到「为什么同一个人先淋证、后水肿、再关格」的传变问题
- 有人把阳痿一律当肾虚补，需要一把先定脏腑再辨虚实的尺子
- 需要判断水肿该攻还是该补，以及「通」到底指什么

## 核心判据（六问）

1. **哪条通道？** 水道（水泛肌肤）、溺道（尿涩、尿闭、尿闭伴呕）、精道（不举、不固）。
2. **哪个段位？** 溺道三问：能尿而不畅（淋）→ 尿不出（癃闭）→ 尿不出且呕（关格）。段位决定预后等级。
3. **哪个大类？** 水肿分阳水阴水；淋证分六淋（热、石、血、气、膏、劳）；遗精分有梦无梦；阳痿先定脏腑（肾、心脾、肝）再辨虚实。
4. **证格与相邻证的分界在哪？** 如阳水湿热壅盛与阴水瘀水互结、气淋虚证与劳淋、君相火旺与湿热下注。
5. **通还是补，分寸在哪？** 水肿不可一味峻下逐水，当以调补脾肾为本；癃闭以通为用，而通法非仅利尿一途；淋证实证忌早用补益。
6. **传变看哪一步？** 淋证日久可致水肿、癃闭、关格；水肿久延可致关格。凡见溺道症状加重，须回头查水道。

## 执行步骤

```text
1. 收口：把条文压成一句主症 + 病程 + 兼症 + 诱因
2. 定通道：水 / 溺 / 精
3. 定段位：溺道三问逐一否掉，直到落定
4. 定大类：阳水阴水 / 六淋 / 有梦无梦 / 脏腑定位
5. 落证格：证名 + 支持症状 + 与相邻证的分界
6. 定治法：只写治法方向与代表方名，不写用量
7. 定分寸：抄下本篇按语里那句「度」
8. 查传变：这一步会不会走到下一段？何时该拦
```

## 硬约束

- **不写剂量、用法与疗程的量值。** 需要剂量时统一写「剂量与用法照底本」。
- **不作诊断，不作病情与预后判定，不作疗效断言，不作方剂优劣比较。**
- **引文逐字。** 标「教材·中医内科学·第N章·N.M.K」，核不到原文就不引；改写须标明是改写。
- **急症前置。** 尿量骤减或无尿、呕恶不止、水肿伴喘促不能平卧、神昏抽搐，先写立即就医。
- **「通」不等于利尿。** 宣肺、理气、活血、温升、温阳皆所以通；只知利尿，遇气不化水者愈利愈伤。
- **不确定就写下来。** 标待核实，不用推测填空。

## 交付物

1. 一条拆解链：通道 → 段位 → 大类 → 证格 → 治法 → 分寸
2. 一句边界句：本段只作结构梳理，判断归属另行
3. 一处相邻证的分界说明
4. 一处反查：病位沿通道前移一段，第一动作会变成什么

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 通道不分 | 水肿与遗精同法论治 | 先定通道，再谈证 |
| 段位不判 | 淋与癃闭混称「小便不利」 | 三问逐一否掉 |
| 一律补肾 | 阳痿湿热证误用温补，愈补愈炽 | 先定脏腑，再辨虚实 |
| 只知利尿 | 气不化水者愈利愈虚 | 通法六路，随证选用 |
| 峻下逐水 | 水肿正气受伤 | 不可一味峻下，缓图其功 |
| 漏掉传变 | 淋证只治当下，不防癃闭关格 | 定段位时同时看下一段 |

## 与相邻章节的接缝

- 第 7 章（肝系）：鼓胀的腹水与水肿的皮水在体征上分开，肝肾同源在阴虚水停处接续。
- 第 5 章（心系）：水肿的水气凌心与心衰的阳虚水泛同源，喘促不能平卧是两章的交界。
- 第 6 章（脾胃）：土不制水是本章脾词频仅次于肾的原因，泄泻的「利小便以实大便」与本章水道相通。
- 第 3 章（脏腑辨证纲要）：本章的「先定脏腑再辨虚实」在那里被写成脏腑兼证的规范问法。
