# Prompt：把一条肾系病证条文拆成「通道—段位—大类—证格—通补分寸」

## 用途

肾系只有六个病，主诉却分布在皮肤、尿道、生殖三处，最容易被当成互不相干的毛病。这个模板把一条条文逼到可核对的位置上——病在哪条通道、在这条道的哪一段、属哪个大类（阳水阴水、六淋、有梦无梦）、落到哪一格、通与补的分寸在哪。适用于预习一篇前的结构梳理、跟诊后复盘一个由淋转癃的病例，以及写医案讨论前的自检。

## 使用前提

- 你手上是**一条条文或一个病例**，不是一个症状词。
- 你已读过教材对应小节，手边有「教材·中医内科学·第N章·N.M.K」的定位。
- 你接受一条硬约束：**本模板不产出任何剂量、用法与疗程的量值。**

## Prompt 正文（复制即用）

```text
你是中医内科学的结构助教。任务不是下诊断，也不是开方，而是把一条已有的辨治条文拆成六个可追问的位置。

【输入】
条文或病例：<一句话主症 + 病程 + 兼症 + 诱因，不写化验值与影像分级>
教材定位：<教材·中医内科学·第N章·N.M.K>
所属病证：<病名>

【任务，按顺序回答，不跳步】
1. 通道归位：落在水道（水泛肌肤、按之凹陷）、溺道（小便频数涩痛、点滴不出、尿闭伴呕）、还是精道（不举、不固）？
2. 段位判定：溺道尤须问三句——能尿而不畅（淋）、尿不出（癃闭）、尿不出且呕（关格）。这一步决定预后判断的等级。
3. 大类分辨：水肿分阳水阴水（起病急缓、肿势走向、皮肤色泽、按之能否即复）；淋证分六淋（热石血气膏劳）；遗精分有梦无梦；阳痿先定脏腑再辨虚实。
4. 证格落位：在教材本篇证型表里落到具体一格，写出证名、支持症状、以及与最易混的那一证的分界（如阳水湿热壅盛与阴水瘀水互结、气淋虚证与劳淋）。
5. 治法与方：只写治法方向与代表方名，不写药味用量、不写煎服法。加减须说明针对哪一个兼症。
6. 通补分寸：这一证该通还是该补？教材本篇按语里对应的那句「度」是什么（如不可一味峻下逐水；通法非仅利尿一途；实证忌早用补益）？
7. 反查：如果病位沿通道前移一段（淋→癃→关格），治法的第一件事会变成什么？说明六病之间常是段位之差。

【硬约束】
- 不写剂量、用法、疗程与任何剂量的量值；需要剂量时统一写「剂量与用法照底本」。
- 不作诊断，不作病情与预后判定，不作疗效断言，不作方剂优劣比较。
- 尿量骤减或无尿、呕恶不止、水肿伴喘促不能平卧、神昏抽搐者，先写「立即就医」，再谈辨证。
- 引教材原文必须逐字，标「教材·中医内科学·第N章·N.M.K」；核不到原文就不引，改写须标明是改写。
- 信息不足时直接说缺哪一项，不要猜、不要用常识补。

【输出格式】
七个小标题各答一到三句；末尾另起一行写：
「本回答为教学层面的结构梳理，不写量值，不构成诊疗建议。」
```

## 示例：一次合格的拆解（节选）

条文：小便频数短涩，灼热刺痛，溺色黄赤，少腹拘急胀痛，口苦，舌质红，苔黄腻，脉滑数。定位：教材·中医内科学·第8章·8.2.3。病证：淋证。

- **通道归位**：溺道。有尿而涩痛，非点滴不出，故不到癃闭那一段。
- **段位判定**：淋证段。三问逐一否掉：无「点滴而出」，无「尿闭伴呕」，故不属癃闭与关格。
- **大类分辨**：六淋之中属热淋——灼热刺痛、溺色黄赤、苔黄腻是湿热之象，无砂石、无血块、无脂浊、无遇劳即发。
- **证格落位**：热淋（实证）。与血淋之别在于尿色是否深红夹块；与膏淋之别在于是否混浊如米泔；与气淋实证之别在于是否以少腹胀满、尿后余沥为主。
- **治法与方**：清热利湿通淋；代表方为八正散加减。若兼口苦呕恶，教材另加和胃之品——加减对兼症。
- **通补分寸**：本篇大法是实则清利、虚则补益，且明写「实证忌早用补益，以免助邪留寇」。本证属纯实，宜清宜利，不补。
- **反查**：若病位前移一段，尿由涩痛变为点滴而出，则治法第一件事从「清利」转为「通阳化气或宣肺通窍」——同一条通道，段位不同，第一动作就不同。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 通道不分 | 把遗精与水肿当同类病 | 回到第 1 步，先定通道 |
| 段位不判 | 淋与癃闭混称「小便不利」 | 回到第 2 步，三问逐一否掉 |
| 阴阳水不辨 | 水肿一律利水 | 补起病缓急、肿势走向、按之能否即复 |
| 六淋不分 | 见溺痛即用清热 | 先辨属哪一淋，再定清、排、止、行、分、补 |
| 峻下无度 | 水肿一路攻逐 | 抄下按语：不可一味峻下逐水 |
| 偷给量值 | 顺手写药味用量 | 改为「剂量与用法照底本」 |

## 与本章的接口

- 第 8 章给的是这套拆法本身：8.1.1 与 8.2.1 与 8.3.1 给三个定义句，8.2.5 给「淋证日久可致水肿、癃闭、关格」的传变线，8.1.5 与 8.3.5 给通补的分寸。
- 第 5、6、7 章可套用同一模板：换掉通道词（心系换成神脉气机、脾胃换成升降通道、肝系换成气血水风），六问不变。
