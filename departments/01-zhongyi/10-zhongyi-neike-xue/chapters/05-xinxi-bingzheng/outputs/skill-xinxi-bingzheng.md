# Skill：心系病证——九病一条轴，从心神到心脉

## 何时用

- 读到一句「心悸」「胸痹」「心衰」的表述，需要判断它落在神、脉还是气机
- 要在心悸、不寐、健忘、痴呆、癫狂之间分辨，五病主症都含「神明不安」
- 有人把证型表当成病名清单，需要一条轴把它们串起来
- 遇到「同一个方为什么治三个病」的疑问（如归脾汤见于心悸、不寐、健忘）
- 需要把急症的处置放在辨证之前（厥证、痫病持续发作、心衰喘脱）

## 核心判据（六问）

1. **落点在神、脉还是气机？** 神：自觉、不能自主（悸、烦、忘、呆、癫狂）；脉：胸膺疼痛、喘肿（胸痹、心衰）；气机：卒倒、抽搐（痫病、厥证）。落点决定后面全部问法。
2. **病程在哪一段？** 新病多实、久病多虚；发作期与休止期治法相反（痫病）；急性期与恢复期侧重相反（中风）。本篇若写明分期，按教材分期。
3. **本虚在哪一脏？** 心之气、血、阴、阳四端，或脾（生化之源）、肾（气化之根）、肝（气机之逆）。不写「正虚」二字了事。
4. **标实在哪一路？** 痰、瘀、水、火、气滞、寒凝。心系九病里痰的覆盖面最广（八病有痰证），但痰生于气郁与脾虚。
5. **证格与相邻证的分界在哪？** 落到具体一证，并写出与最易混的那一证的区别点（如心虚胆怯与心血不足、心肾不交与心火亢盛）。
6. **处方之外还差哪一半？** 诱因回避、活动量、情志、急救处置。急症先写「立即就医」，再论辨证。

## 执行步骤

```text
1. 收口：把条文压成一句主症 + 病程 + 兼症
2. 归位：神 / 脉 / 气机，选一为主，另两项只写兼夹
3. 定位病程：新久、发作缓解、急性恢复
4. 分标本：本虚落到一脏一端，标实落到一路
5. 落证格：证名 + 支持症状 + 与相邻证的区别点
6. 定治法：只写治法方向与代表方名，不写用量
7. 补调护：首条诱因回避 + 必须就医的情形
8. 反查：抽掉标实后证是否改变；改变即为虚实夹杂
```

## 硬约束

- **不写剂量、用法与疗程的量值。** 需要剂量时统一写「剂量与用法照底本」。
- **不作诊断，不作病情与预后判定，不作疗效断言，不作方剂优劣比较。**
- **引文逐字。** 标「教材·中医内科学·第N章·N.M.K」，核不到原文就不引；改写须标明是改写。
- **急症前置。** 胸痛持续不缓解、喘促不能平卧、卒然昏倒、抽搐不止，先写立即就医。
- **归类依据与治脏分开。** 归在心系不等于从心治（痫病按语通篇不言心）。
- **不确定就写下来。** 标待核实，不用推测填空。

## 交付物

1. 一条拆解链：落点 → 病程 → 标本 → 证格 → 治法 → 调护
2. 一句边界句：本段只作结构梳理，判断归属另行
3. 一处相邻证的分界说明
4. 一处反查：抽掉标实后证是否成立

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 病名当证名 | 只会说「他是心悸」 | 落到具体证格并写出分界 |
| 标本含糊 | 「正虚邪实」掩盖了治法的取舍 | 本虚落脏、标实落路 |
| 分期丢失 | 痫病不分发作休止，一张方到底 | 按教材分期重写治法 |
| 频次当权重 | 见「痰」最多就一味化痰 | 回到痰的来路：气郁与脾虚 |
| 一号通治 | 见归脾汤治三病便套用 | 先辨三处病机是否同源 |
| 偷给量值 | 顺手写药味用量 | 改为「剂量与用法照底本」 |

## 与相邻章节的接缝

- 第 3 章（脏腑辨证纲要）：本章的「本虚在哪一脏」在那里被写成脏腑辨证的规范问法。
- 第 6 章（脾胃系）：痰之源在脾，本章反复出现的「健脾以杜生痰之源」在那里展开为升降治法。
- 第 7 章（肝系）：气机之逆与肝风，痫病与厥证的风、火、痰三路在那里写实。
- 第 8 章（肾系）：水从肾主，心衰与水肿的「水」在那里落到阳水阴水之分。

## 边界

本 Skill 只处理「条文 → 可核对结构」的表达，不涉及剂量、诊断与临床决策。本章内容为教学材料，不构成诊疗建议；任何涉及个体的辨治评估须由具备资质的人员依现行法律法规与规范作出。急症请立即就医。
