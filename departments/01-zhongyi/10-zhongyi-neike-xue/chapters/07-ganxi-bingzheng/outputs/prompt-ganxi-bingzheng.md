# Prompt：把一条肝系病证条文拆成「层次—来源—外感内伤—证格—攻补」

## 用途

肝系九病的部位散得很开：胁、目、腹、头、肢、颈。同一个病机在不同部位长出不同病名，读起来像九门课。这个模板把一条条文逼到可核对的位置上——它落在气、血、水、风哪一层，是本层之病还是上一层传下来的，外感还是内伤，落到哪一格，攻与补的分寸在哪。适用于预习一篇前的结构梳理、跟诊后复盘一个迁延病例的传变路径，以及写医案讨论前的自检。

## 使用前提

- 你手上是**一条条文或一个病例**，不是一个部位词。
- 你已读过教材对应小节，手边有「教材·中医内科学·第N章·N.M.K」的定位。
- 你接受一条硬约束：**本模板不产出任何剂量、用法与疗程的量值。**

## Prompt 正文（复制即用）

```text
你是中医内科学的结构助教。任务不是下诊断，也不是开方，而是把一条已有的辨治条文拆成六个可追问的位置。

【输入】
条文或病例：<一句话主症 + 病程 + 兼症 + 诱因，不写化验值与影像分级>
教材定位：<教材·中医内科学·第N章·N.M.K>
所属病证：<病名>

【任务，按顺序回答，不跳步】
1. 层次归位：落在气（胀痛走窜、随情志起伏）、血（刺痛固定、有形结块）、水（胀大、脉络显露、小便不利）还是风（眩晕、抽搐、猝倒、肢体动摇）？跨层时写明哪一层为主、哪一层为兼。
2. 来源追索：是本层原发，还是上一层传下来？气滞→血瘀→水停是一条链；阴虚→阳亢→化风是另一条链。两条链不许混说。
3. 外感内伤：有无表证、起病急缓、病程长短。外感以风为先导（风寒、风热、风湿），内伤分肝阳、血虚、痰浊、肾虚、瘀血五路。
4. 证格落位：在教材本篇证型表里落到具体一格，写出证名、支持症状、以及与最易混的那一证的分界（如肝阳上亢与痰湿中阻、闭证与脱证）。
5. 治法与方：只写治法方向与代表方名，不写药味用量、不写煎服法。加减须说明针对哪一个兼症。
6. 攻补分寸：这一证该攻还是该补？教材本篇按语里对应的那句「度」是什么（如攻不可过、衰其大半而止；闭证宜开、脱证宜固；中病即止）？
7. 反查：如果把第 1 步的层次降一层（血→气、水→血），这个证会变成哪个病？说明九病之间常是层次之差，不是本质之差。

【硬约束】
- 不写剂量、用法、疗程与任何剂量的量值；需要剂量时统一写「剂量与用法照底本」。
- 不作诊断，不作病情与预后判定，不作疗效断言，不作方剂优劣比较。
- 突发剧烈头痛、猝然昏仆、半身不遂、呕血黑便、腹大胀满伴神昏少尿者，先写「立即就医」，再谈辨证。
- 引教材原文必须逐字，标「教材·中医内科学·第N章·N.M.K」；核不到原文就不引，改写须标明是改写。
- 信息不足时直接说缺哪一项，不要猜、不要用常识补。

【输出格式】
七个小标题各答一到三句；末尾另起一行写：
「本回答为教学层面的结构梳理，不写量值，不构成诊疗建议。」
```

## 示例：一次合格的拆解（节选）

条文：腹部胀大如鼓，皮色苍黄，脉络显露，胁下痞块，小便短少，舌质紫暗，脉细涩。定位：教材·中医内科学·第7章·7.4.3。病证：鼓胀。

- **层次归位**：以水层为主（腹大、小便短少），兼血层（胁下痞块、舌紫暗、脉络显露）。水与血同病，是鼓胀的常态。
- **来源追索**：不是原发。教材把「黄疸、积聚久延」写进病因，故此例当追问前病：先有胁痛或黄疸，后有腹大，属沿「用」的链条逐层加深。
- **外感内伤**：内伤为主。无表证、病程长、有痞块，属肝脾肾同病。
- **证格落位**：瘀结水停证。与阴虚水停之别在于舌象（紫暗与舌红少苔）；与阳虚水盛之别在于有无畏寒肢冷与脉沉迟。
- **治法与方**：活血化瘀、行气利水；代表方为调营饮加减。若兼脾虚纳呆，教材另加健脾之品——加减对兼症。
- **攻补分寸**：本篇总纲是虚实为纲、攻补兼施，按语的度是攻不可过、衰其大半而止。此例有痞块而正气未大衰，可攻，但不可一路攻下。
- **反查**：若把血层抽掉（无痞块、无舌紫），只剩腹大与小便不利，则近于水湿困脾证，病名仍是鼓胀——层次之差，不是病名之差。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 一句话套九病 | 九病都说成「肝气不舒」 | 回到第 1 步，分层 |
| 链条混说 | 把「气滞→血瘀→水停」与「阴虚→阳亢→化风」混成一条 | 两条链分开写，不许接错 |
| 外感内伤不分 | 头痛不问有无表证就开平肝方 | 回到第 3 步，先定内外 |
| 闭脱不辨 | 中风见神昏即用开窍 | 先辨闭与脱，闭宜开、脱宜固 |
| 攻伐无度 | 鼓胀积聚一路攻下 | 抄下按语的分寸句：衰其大半而止 |
| 偷给量值 | 顺手写药味用量 | 改为「剂量与用法照底本」 |

## 与本章的接口

- 第 7 章给的是这套拆法本身：7.1.1 给经络所过，7.3.1 给气血两分的定义，7.6.5 给「阳亢化风致中风」的预防线，7.7.3 给三刀切法，7.4.5 与 7.7.8 给攻补与闭脱的分寸。
- 第 5、6、8 章可套用同一模板：换掉层次词（心系换成神脉气机、脾胃换成升降通道、肾系换成水精溺），六问不变。
