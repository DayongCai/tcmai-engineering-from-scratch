# Skill：肝系病证——气血水风四层，与一个例外

## 何时用

- 读到一句「胁痛」「头晕」「腹大」「口眼歪斜」，需要判断它落在四层中的哪一层
- 要在头痛、眩晕、中风之间分辨，三病部位相同而深浅不同
- 有人把九病都说成「肝气不舒」，需要一把有层次的尺子
- 遇到「为什么同一个方治三个病」的疑问（如天麻钩藤饮见于头痛、眩晕、中风）
- 要判断一个迁延病例是原发还是上一层传下来的（黄疸→积聚→鼓胀）

## 核心判据（六问）

1. **落在哪一层？** 气（胀痛走窜、随情志起伏）、血（刺痛固定、有形结块）、水（胀大、脉络显露、小便不利）、风（眩晕、抽搐、猝倒、肢体动摇）。
2. **是本层之病还是上一层传来？** 两条链不许混：「气滞→血瘀→水停」走的是肝之用；「阴虚→阳亢→化风」走的是肝之体。
3. **外感还是内伤？** 外感以风为先导（风寒、风热、风湿）；内伤五路（肝阳、血虚、痰浊、肾虚、瘀血）。疟疾是例外：以特感病邪为主因。
4. **证格与相邻证的分界在哪？** 如肝阳上亢与痰湿中阻、闭证与脱证、阴虚水停与阳虚水盛。
5. **攻还是补，分寸在哪？** 总纲是攻不可过、衰其大半而止；中风闭宜开、脱宜固；黄疸苦寒中病即止。
6. **预防关口在哪？** 眩晕的肝阳上亢要防其化风致中风——关口在眩晕，不在中风。

## 执行步骤

```text
1. 收口：把条文压成一句主症 + 病程 + 兼症 + 诱因
2. 分层：气 / 血 / 水 / 风，一主一兼
3. 追来源：本层原发，或上一层传来（气→血→水；阴虚→阳亢→风）
4. 定内外：有无表证、起病急缓、病程长短
5. 落证格：证名 + 支持症状 + 与相邻证的分界
6. 定治法：只写治法方向与代表方名，不写用量
7. 定分寸：抄下本篇按语里那句「度」
8. 定关口：这一病进展到哪一步就该拦（如眩晕→中风）
```

## 硬约束

- **不写剂量、用法与疗程的量值。** 需要剂量时统一写「剂量与用法照底本」。
- **不作诊断，不作病情与预后判定，不作疗效断言，不作方剂优劣比较。**
- **引文逐字。** 标「教材·中医内科学·第N章·N.M.K」，核不到原文就不引；改写须标明是改写。
- **急症前置。** 猝然昏仆、半身不遂、剧烈头痛、呕血黑便、腹大胀满伴神昏少尿，先写立即就医。
- **两刀不可省。** 中风先分中经络中脏腑（有无神志改变），再分闭与脱；闭脱倒置即危。
- **承认例外。** 疟疾归肝系靠经脉相表里，病机不在肝；强行归入四层反而失真。

## 交付物

1. 一条拆解链：层次 → 来源 → 内外 → 证格 → 治法 → 分寸
2. 一句边界句：本段只作结构梳理，判断归属另行
3. 一处相邻证的分界说明
4. 一处反查：把层次降一层，会变成哪个病

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 一句话套九病 | 九病皆「肝气不舒」 | 分层，一主一兼 |
| 链条接错 | 把气滞血瘀与水停接成阴虚化风 | 两条链分开 |
| 内外不分 | 头痛不问表证即平肝 | 先定外感内伤 |
| 闭脱倒置 | 神昏即开窍，脱证愈脱 | 先辨闭与脱 |
| 攻伐无度 | 鼓胀积聚一路攻下 | 衰其大半而止 |
| 关口错位 | 等中风发作才防 | 关口前移到眩晕 |

## 与相邻章节的接缝

- 第 5 章（心系）：中风与厥证都以卒然昏仆为主症，鉴别点在有无偏瘫失语与抽搐吐涎。
- 第 6 章（脾胃）：木旺乘土是本章脾词频仅次于肝的原因，鼓胀的腹大与痞满的痞塞在那里分开。
- 第 3 章（脏腑辨证纲要）：本章的「落在哪一层」在那里被写成脏腑兼证与传变的规范问法。
- 第 8 章（肾系）：水不涵木、肝肾同源，鼓胀的肝肾阴虚与水肿的肾阳衰微在那里接续。
