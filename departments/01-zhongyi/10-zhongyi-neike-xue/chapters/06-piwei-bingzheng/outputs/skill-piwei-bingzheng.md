# Skill：脾胃系病证——一条通道上的九个卡点

## 何时用

- 读到一句「胃胀」「吃了就泻」「排便不畅」，需要判断它卡在通道的哪一段
- 要在胃痛、痞满、呕吐、噎膈、呃逆之间分辨，五病都在入口段且症状上逆
- 有人把九个病当成九个独立毛病，需要一条线把它们排成位置
- 遇到「为什么同一个方治四个病」的疑问（如保和丸见于胃痛、痞满、呕吐、泄泻）
- 需要先排心系急症再谈胃病（胃脘痛与真心痛部位重合）

## 核心判据（六问）

1. **症状朝上还是朝下？** 朝上者病在入口（噎膈、痞满、胃痛、呕吐、呃逆）；朝下者病在出口（泄泻、痢疾、便秘）；腹痛横跨中段，按大腹、小腹、少腹定位。
2. **卡在哪一段？** 受纳、腐熟、传导三段。部位即定位：小腹多属膀胱与胞宫，少腹多属肝经。
3. **病性是寒是热、是虚是实？** 痞满、呕吐必辨寒热（苔白腻与苔黄腻）；泄泻、痢疾必辨新久（暴忌收涩，久忌攻伐）。
4. **病因是食、是气、是湿、是虚？** 九篇病因第一句几乎都含饮食，故「食」是覆盖面最广的一路；肝气犯中焦可落在三个不同位置，长出三个病名。
5. **证格与相邻证的分界在哪？** 如胃中寒冷与脾胃阳虚、痰湿中阻与湿热阻胃、气秘与气虚秘。
6. **攻还是补，分寸在哪？** 总纲是攻不伤正、补不碍滞；暴痢忌收涩忌补益；老年虚秘宜润下缓图。

## 执行步骤

```text
1. 收口：把条文压成一句主症 + 病程 + 兼症 + 诱因
2. 定方向：朝上 / 朝下 / 居中（腹痛按三腹定位）
3. 定卡点：受纳 / 腐熟 / 传导
4. 定病性：寒热、虚实、新久（泄泻痢疾必分暴久）
5. 落证格：证名 + 支持症状 + 与相邻证的分界
6. 定治法：只写治法方向与代表方名，不写用量
7. 定分寸：抄下本篇按语里那句「度」，写明攻补的边界
8. 安全线：胃脘痛先排心系急症；腹痛剧烈先排急腹症
```

## 硬约束

- **不写剂量、用法与疗程的量值。** 需要剂量时统一写「剂量与用法照底本」。
- **不作诊断，不作病情与预后判定，不作疗效断言，不作方剂优劣比较。**
- **引文逐字。** 标「教材·中医内科学·第N章·N.M.K」，核不到原文就不引；改写须标明是改写。
- **安全线前置。** 胃脘痛排除心系急症；腹痛剧烈、持续呕吐、停止排便排气、下痢脓血伴高热，先写立即就医。
- **位置不等于本质。** 归在脾胃系是归类，不等于九病同源；同一病名在暴久两端治法可完全相反。
- **不确定就写下来。** 标待核实，不用推测填空。

## 交付物

1. 一条拆解链：方向 → 卡点 → 病性 → 证格 → 治法 → 分寸
2. 一句边界句：本段只作结构梳理，判断归属另行
3. 一处相邻证的分界说明
4. 一处反查：把卡点挪到通道另一端，会变成哪个病

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 只报症状 | 「他胃胀」，无卡点无证格 | 定位到通道一段再落证 |
| 寒热不辨 | 痞满呕吐一律「胃气不和」 | 补苔象与喜恶 |
| 新久不分 | 暴痢用收涩、久泻用攻伐 | 先定病程，再定方向 |
| 通治套方 | 见食滞便用保和丸 | 先辨到具体一证 |
| 补泻失度 | 虚秘峻下、虚痞峻消 | 抄下按语的分寸句 |
| 漏安全线 | 胃脘痛不排心痛 | 分诊写在辨证之前 |
