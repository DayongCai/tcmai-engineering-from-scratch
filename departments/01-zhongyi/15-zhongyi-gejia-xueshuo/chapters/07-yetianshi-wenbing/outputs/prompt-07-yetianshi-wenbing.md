# 定位而非分型

## 用途

四层是**位置**，不是证型。位置决定能不能透、该不该清、要不要凉血。

## 步骤

### 1. 定位

卫 / 气 / 营 / 血

### 2. 定动作

透 / 清 / 凉 / 散（卫与营都要「透」）

### 3. 判传变

顺传逐层 vs 逆传（卫直入营）

### 4. 对读六经

两套坐标可并用

## 判据速查

| 项 | 一句话 |
|---|---|
| 语料 | 伤寒 1,760 条 / 金匮 402 条 / 温病 630 条（合计 2,792） |
| 命中 | 只是词面分布，不是学派归属 |
| 归属 | 需原书与师承，本库不提供 |
| 结论 | 只说分布与关联，不说高下 |

## 输出

① 层次；② 治法动作；③ 顺逆传；④ 与六经的对读提示。
