# 定位而非分型 · 可装载技能

## 何时装载

- 需要先定邪在哪一层，再定透／清／凉／散；
- 教学场景：用对账替代背诵；
- 复核场景：检查一句学派主张是否被当成了原文。

## 步骤

1. **定位** —— 卫 / 气 / 营 / 血
2. **定动作** —— 透 / 清 / 凉 / 散（卫与营都要「透」）
3. **判传变** —— 顺传逐层 vs 逆传（卫直入营）
4. **对读六经** —— 两套坐标可并用

## 输出格式

① 层次；② 治法动作；③ 顺逆传；④ 与六经的对读提示。

## 边界

- 不引未收原书，不作归属判定；
- 数字须能回溯到 `standards/gejia/` 或本章 `code/main.js`；
