# 主张的可核性

## 用途

学派的主张不是不能核，而是要分清**可核的部分**（概念在文本中的分布）与**不可核的部分**（归属与师承）。

## 步骤

### 1. 拆主张

把一句主张拆成 2–3 个可检索的概念词

### 2. 定检索

在伤寒 1,760 / 金匮 402 / 温病 630 里检索

### 3. 读结果

命中条数只说明分布，不说明归属（词表噪声要一并报）

### 4. 标等级

可核 / 部分可核 / 后世转述

## 判据速查

| 项 | 一句话 |
|---|---|
| 语料 | 伤寒 1,760 条 / 金匮 402 条 / 温病 630 条（合计 2,792） |
| 命中 | 只是词面分布，不是学派归属 |
| 归属 | 需原书与师承，本库不提供 |
| 结论 | 只说分布与关联，不说高下 |

## 输出

① 主张拆分；② 检索词；③ 命中分布；④ 证据等级与噪声说明。
