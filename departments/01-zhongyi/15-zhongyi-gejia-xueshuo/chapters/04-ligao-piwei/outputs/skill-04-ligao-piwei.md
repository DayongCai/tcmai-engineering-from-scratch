# 内伤发热：给一个已有 60 条记载的老问题造一套 0 命中的新词

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 没有受寒、没有表证、脉不浮、却持续发热，而且越用发散越坏
- 给这个热指定一个新的来源
- 它把发热的来源从「外」搬到了「内」
- （胃气虚，60 条），但没有给出一个
- 问题越老，命名越值钱
- 命中 0 的词，标出的是新增问题的位置

## 边界

- **李杲的原书（《脾胃论》《内外伤辨惑论》等）本库未收全文，本章不引其原文。**「阴火」的三步链按学术史通行描述整理，属转述层；本章对该链的拆解（位而非质、方向而非温度）是对通行描述的再表述，不是原文的逐句解释。
- **68 与 60 的对照依赖词表选择。**若把「胃气」并入李杲词表，命中会从 68 升到 128，占比从 2.4% 升到 4.6%，八派中的位次也会变。本章刻意不并入，因为「胃气」是底本原有的词，并入等于把底本的功算在学派头上——这一步在方法上必须守住。
- **证候库的 23 证与 12 方，是教材整理的挂接关系，不是历史传播的实证。**它说明当代证候学吸收了这套分类，不说明金元之际的实际流传广度。
- 本章为学术史与文本统计的教学整理，命中数可由本库 `standards/{shanghan,jingui,wenbing}/底本.json` 与 `standards/zhenghou/证候库.json` 复算。
