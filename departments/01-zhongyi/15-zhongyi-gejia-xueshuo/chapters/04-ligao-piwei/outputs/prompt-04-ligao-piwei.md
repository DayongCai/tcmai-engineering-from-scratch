# 内伤发热：给一个已有 60 条记载的老问题造一套 0 命中的新词 · 提示词

## 用途

给「内伤发热：给一个已有 60 条记载的老问题造一套 0 命中的新词」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「问题：发热被一种解释垄断 → 换词不换题：60 条的存量与 6 条的新词 → 阴火成立的三个条件，与四种失效 → 可教性：这套框架为什么能传下来」这条链。

## 提示词

```
我在学《中医各家学说》第 4 章「内伤发热：给一个已有 60 条记载的老问题造一套 0 命中的新词」，本章 5 节 / 3,280 汉字，习题 7 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 没有受寒、没有表证、脉不浮、却持续发热，而且越用发散越坏
   - 给这个热指定一个新的来源
   - 它把发热的来源从「外」搬到了「内」
   - （胃气虚，60 条），但没有给出一个
   - 问题越老，命名越值钱
   - 命中 0 的词，标出的是新增问题的位置
4. 本章自陈的边界（不得越过）：
   - **李杲的原书（《脾胃论》《内外伤辨惑论》等）本库未收全文，本章不引其原文。**「阴火」的三步链按学术史通行描述整理，属转述层；本章对该链的拆解（位而非质、方向而非温度）是对通行描述的再表述，不是原文的逐句解释。

   - **证候库的 23 证与 12 方，是教材整理的挂接关系，不是历史传播的实证。**它说明当代证候学吸收了这套分类，不说明金元之际的实际流传广度。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```
