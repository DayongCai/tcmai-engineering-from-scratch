# 三问对账

## 用途

学各家学说的终点是判断力：**哪些分歧是真的，哪些只是词不同，哪些能算、哪些不能算。**

## 步骤

### 1. 填表

主张／命中／关联证候／跨课

### 2. 列分歧

攻vs补、阳有余vs阳不足、伤寒vs温病

### 3. 给解释

病种不同？理论冲突？词义差异？（顺序：先标词义，再判断）

### 4. 标边界

结构化不能判定归属与高下

## 判据速查

| 项 | 一句话 |
|---|---|
| 语料 | 伤寒 1,760 条 / 金匮 402 条 / 温病 630 条（合计 2,792） |
| 命中 | 只是词面分布，不是学派归属 |
| 归属 | 需原书与师承，本库不提供 |
| 结论 | 只说分布与关联，不说高下 |

## 输出

① 对账表；② 分歧清单与解释类型；③ 证据等级；④ 不能算的部分。

## 边界

- 数字一律由 `code/main.js` 读 `standards/gejia/` 现算，不手写；
- 不引各派原书（本库未收），只引可检索的经典条文；
- **免责声明：** 本单为教学整理，不构成诊疗建议。
