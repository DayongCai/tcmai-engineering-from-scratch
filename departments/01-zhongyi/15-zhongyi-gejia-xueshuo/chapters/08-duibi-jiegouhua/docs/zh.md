# 第 8 章 · 三个排序三个答案：一张表能算出三件事，算不出两件事

> **MOTTO:** 「儒之门户分于宋，医之门户分于金元。」——《四库全书总目·医家类》
>
> **PROBLEM:** 把八派放进同一张表，量三个数：词表在 2,792 条里的命中、在 132 证里的覆盖、代表作在 364 条方源记录里的占位。三个排序各各不同。词频第一是张从正（1,476 条），他在方源里是 0；方源第一是张景岳（22 方），他的词频是 7 条、八派最末。三个量两两求秩相关：词频与证候 ρ = 0.190，词频与方源 ρ = −0.357，证候与方源 ρ = **−0.714**。最后一对是负的——一个学派覆盖的证越多，它的书被方书采用得越少。
>
> **双根因定位:** 环境逼迫（八派各自在不同地域、不同病种上成立，本无高下之分；但教材必须排序，排序就必须选一个量，而任何单一的量都会把另外两面压平）+ 知识积累（本库已有 2,792 条条文、132 证 14 族、364 条带出处的方源，三个量第一次能并排算出三个不同的答案，从而把「谁最重要」这个伪问题暴露出来）

## 一、一张 8×6 的矩阵，三个排序，三个 ρ

三个量的排序，抄下来并排看：

|--:|---|---|---|

同一个张景岳，词频第八、方源第一。同一个张从正，词频第一、方源并列最末。**任何一列，都能支撑一个「最重要」的结论；三列一起看，这个结论就不成立了。**

在同一张矩阵上，把三个量两两求秩相关，得三个 ρ——它们各自的分量要往下细说。

| 一对 | ρ | 直读 |
|---|--:|---|
| 词频 ↔ 证候 | 0.190 | 几乎无关 |
| 词频 ↔ 方源 | −0.357 | 弱负相关 |
| 证候 ↔ 方源 | **−0.714** | 强负相关 |

先说样本量，这是读这张表之前必须知道的：**n = 8。**八个样本的秩相关极不稳定，任何一个学派的数值变一下，ρ 就可能大幅移动。n = 8、双侧 0.05 的临界值约 0.738，所以 −0.714 虽然接近，仍未过线。**本章的所有 ρ 都只能作为否定性证据使用**——它们足以说「词频不能代表影响」，不足以说「证候与方源真的反向」。这条界限必须写死，否则本章就变成了用弱统计造强结论。

在这个限制下，三个 ρ 各自还能说一件确定的事：

**第一个 ρ = 0.190 否掉了「词频 = 重要性」。**这是第 1 章的主结论，此处得到第三个量的旁证。

**第二个 ρ = −0.357 稍弱地否掉了「词频 = 后世采用」。**方向是负的：词用得多，反而不太被方书采用。原因不神秘——词频高的学派（张从正、叶天士、王清任）用的都是高频基本字（汗、气、血），高频字不产生专有方名。

**第三个 ρ = −0.714 提出了一个有意思的问题**：覆盖广与方源多，为什么反向？

## 二、覆盖越宽，留下的方越少

先看两端。

一端是张锡纯：43 证（32.6%，八派最高），方源 0。另一端是李杲与王清任：各 23 证（17.4%，并列最低），方源 19 与 21（第二、第三高）。张景岳居中偏窄（34 证）而方源最高（22）。

这个反向关系有一个纯粹机械的解释，值得说清，因为它同时也是方法论警告。

**证候覆盖是按病机族机械归类的。**本库的归属规则是：一个学派挂接若干「族」，族的证数相加即覆盖数。张锡纯挂气虚（14）+ 阴虚（13）+ 血瘀（16）三族，覆盖 43 证；李杲挂气虚（14）+ 痰湿（9），覆盖 23 证。**族越宽，覆盖越大，与该学派实际处理过多少种病无关。**张锡纯的 43 证里，绝大多数不是他治过的证，而是他所属的三个族碰巧很大。

**方源占位是按具体方剂追溯的。**364 条方源记录里，每一条都指名一本书。王清任的 21 条来自《医林改错》的血府逐瘀汤、通窍活血汤一类；李杲的 19 条来自补中益气汤、升阳益胃汤一类。这些方有明确出处、可被反复采用，因此计数扎实。

于是两个量的差别就出来了：**覆盖量的是「分类的宽度」，方源量的是「工具的密度」。**一个学派可以占很宽的分类面而一个方也不留（张锡纯），也可以只占一个窄角而留下成批可复用的方（王清任）。宽度与密度不是同一件事，甚至在样本里是反向的。

这一点对学习者极实用。当有人问「哪一派最重要」，正确的回答不是给一个名字，而是反问「按哪个量」。**按分类宽度，答案是张锡纯；按方剂可用性，答案是张景岳；按文本密度，答案是张从正。三个都是真的，三个都不回答「哪一派更对」。**

## 三、八派的分歧，其实只有三个问题

矩阵把八派摊平之后，会看到一件在逐章阅读时看不到的事：八个人吵的其实只有三个问题。

**问题一：热从哪里来。**

| 回答 | 学派 | 关键词 |
|---|---|---|
| 从邪化来 | 刘完素 | 六气皆从火化 |
| 从气陷来 | 李杲 | 阴火 |
| 从阴亏来 | 朱震亨 | 相火妄动 |
| 从阳浮来 | 张景岳 | 虚阳外越 |
| 从层位来 | 叶天士 | 卫气营血 |

五种回答，不是五个理论，是**同一个问题的五个候选归因**。它们可以并存，因为它们各自指向不同的病人类型；它们不能互相证伪，因为在当时的条件下无法判定归因的真假。

**问题二：虚在何处。**

| 回答 | 学派 |
|---|---|
| 在中焦（气陷） | 李杲 |
| 在阴（水不足） | 朱震亨 |
| 在阳与阴两处（二维） | 张景岳 |
| 在气（大气下陷） | 张锡纯 |

**问题三：邪该攻还是该留。**

| 回答 | 学派 | 条件 |
|---|---|---|
| 攻，三法该尽 | 张从正 | 有邪即攻 |
| 攻，但先辨膜原 | 吴又可 | 邪伏夹层，透而后攻 |
| 不留邪，也不妄攻 | 叶天士 | 按层定动作，顺序不可乱 |
| 攻其瘀，不攻其正 | 王清任 | 血瘀为实，逐之即安 |

三个问题，八派，十五种回答。**学派的数量远多于问题的数量**——这是本章最想让人记住的一句话。因为问题只有三个，所以任何一个病人都可能同时被三套回答命中；因为回答有十五种，所以任何两个医生都可能在同一张床上给出不同的方，而各自都能自圆其说。

## 四、能算的三件，算不出的两件，与一张检查单

**能算的三件事。**

**其一，词的年龄。**一个词在 2,792 条里命中多少，近似地标出它出生的年代。命门 1 条、相火 0 条、阴火 0 条、升阳 0 条——四个 0 与 1，标出的是四个明代前后才成形的问题。

**其二，族的覆盖。**一个学派挂接哪几个病机族，覆盖多少证，是可以机械算出的分类宽度。它回答「这套分类能装下多少种病人」，不回答「这套分类治得好多少种病人」。

**其三，方源的占位。**364 条带出处的方源记录，能算出一个学派留下了多少可复用的工具。这是三个量里最接近「实际影响」的一个，因为它数的是别人真的用了什么。

**算不出的两件事。**

**其一，思想归属。**词面命中不能判定归属，这是第 1 章就立下的规矩。一个含「火」字的条文，可能是在描述火邪，也可能是在否定火邪；一个含「相火」的条文，可能出自丹溪，也可能出自批评丹溪的人。**检索给出的是位置，不是立场。**

**其二，高下。**数据只能显示分布，不能显示对错。三个 ρ 都是横向的比较，没有一个是纵向的评价。任何以「覆盖 43 证所以最高明」或「方源 22 所以最实用」的论断，都把分布读成了价值。

**由此得到一张检查单，五行，用来审任何一篇讲学派的文字：**

1. 它有没有说出这派要解决的那个问题？（没有 = 标签）
2. 它用的是哪个量？词频、覆盖、方源，还是三个混着用？（混用 = 排序不可信）
3. 它有没有给出这派的失效场景？（没有 = 宣传）
4. 它有没有把某一派的一句话当全派共识？（有 = 可用该派原文反驳）
5. 它有没有把学派关系讲成替代关系？（有 = 与「并存」的事实冲突）

五条全过，这篇文章可以读；中一条，就要回去查原文。

## 代价与边界

- **三个量的口径都在本章写明，可复算，但都只在「本库」内成立。**词频基于 2,792 条（伤寒 1,760 · 金匮 402 · 温病 630）；覆盖基于 132 证 14 族；方源基于 364 条带出处的记录（370 条方条中 6 条未标出处，未计入）。换一套语料，三个数都会变，结论可能反向。
- **n = 8，三个 ρ 全部只能作否定性证据。**n = 8 时双侧 0.05 的临界值约 0.738，本章最大的 |ρ| = 0.714 未过线。因此「证候与方源反向」只能作为**待检验的观察**提出，不能作为结论使用。凡引用本章 ρ 值而不带样本量者，即为误用。
- **族归属是机械挂接，不是历史考证。**一个学派挂接哪几族，由本库构建脚本按病机关键词指定；张锡纯覆盖 43 证，是因为气虚、阴虚、血瘀三族恰好都大，不是因为他处理过这 43 证。本章第三节已就此作出解释，读者不应把 43 当作他的临床广度。
- **方源统计偏向「有专名的方」。**一个学派若只留下治法原则而无专方（叶天士的多数条文即如此），在方源里就会接近 0。叶天士的 2 条来自《温热经纬》（王孟英所编，含叶案），属间接归属。0 与 2 在这里都不代表「无影响」，只代表「无专名方被方书收录」。
- **八派之中，王清任与张锡纯在本课程没有独立章节。**他们在本章出现，是作为矩阵的完整性与两个极值（方源 21 / 覆盖 43）而出现；其学说的内部结构不在本课程范围，读者不应据本章的几行字形成对他们的整体判断。
- **本章不给方药与用量，也不给任何学派的处方建议。**表中出现的方名仅为标明方源，不构成用药指引；凡涉具体方药、用量、煎服与用药时长，须依执业医师判断。
- **本章不评断任何一派的对错，也不排序。**三个量给出三个排序，正是为了说明「排序」这个动作本身没有唯一解。本课程的立场是：**先问用哪个量，再谈谁更重要。**

## 进阶思考

这门课从「学派不是标签」开始，到「排序没有唯一解」结束，中间八个人。如果只带走一句话，应当是这一句：**学派提供的是一组候选归因，不是一组答案。**

候选归因的价值，在于它让医生在第一次判断失败时有第二条路可走。刘完素给了「化火」，李杲给了「气陷」，朱震亨给了「阴亏」，张景岳给了「阳浮」——四个候选摆在那里，一个发热的病人被清之不应时，医生不会无话可说，而是有四句话可以依次追问。这就是学术史的实际用处：**它不是知识，是备选方案的库存。**

而库存要能用，必须知道每件的适用条件与失效方式。这正是本课程每一章都写「代价与边界」、都列「判据」的原因。没有边界的学说，用起来与标语无异。

最后回到那张表。三个排序、三个 ρ、十五种回答、三个问题。数字能做的事到此为止：它告诉你分布，告诉你错位，告诉你哪个量在测什么。它不能告诉你这个病人该用哪一派——那要靠四诊，靠对具体人的观察，靠对判断失误的及时回头。**学问的尽头是病人，不是矩阵。**
