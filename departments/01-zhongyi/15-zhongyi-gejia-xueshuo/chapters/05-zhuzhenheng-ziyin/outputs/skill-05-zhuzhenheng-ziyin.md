# 相火论把「火」从病邪改写成身体的常驻设施

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 两人都承认热，都反对滥用温燥，分歧只在「热的来源」
- 把身体需要的那一点火也灭掉
- 阴不足而阳失所制
- 相对于阴的供给，阳显得有余
- 它不是临床文本里的词，是理论文本里的词
- 「阴虚」这个词在汉代还没成为一个独立的诊断类别

## 边界

- **朱震亨的原书（《格致余论》《丹溪心法》等）本库未收全文，本章不引其原文。**「阳有余阴不足」「相火妄动」等表述按学术史通行概括引用，属转述层；三状态表（常／妄／衰）是本章为教学清晰而作的整理，其中「衰」一格在丹溪本人著作中的分量远小于前两格，主要经张景岳接续而成，这一层归属必须写明，否则就是替古人添话。
- **「相火」在 2,792 条中 0 命中，不等于这个概念无据。**它的文本依据在《素问》运气七篇（本库《素问》选读中 6 处），不在仲景三部。用三部经典去否证它，是选错了底本；用运气七篇去证明它，也只是证明了范畴的存在，证明不了临床有效性。
- **189 倍这个比值只是两个比例的商，不是因果强度。**0.14% 与 26.5% 分母不同（一个是 2,792 条，一个是 132 证），相除得到的数没有统计含义。它的用处只有一个：说明「文本命中」与「框架覆盖」在这门课里必须分开看。
- 本章为学术史与文本统计的教学整理，命中数可由本库 `standards/{shanghan,jingui,wenbing}/底本.json`、`standards/neijing-xuandu/底本.json` 与 `standards/zhenghou/证候库.json` 复算。
