## 一、这门课教什么

不是背八个人名，而是回答三个问题：**同一件事可以有几种讲法？分歧在哪几个点上？哪些主张能被今天的数据支持或削弱？**

八派：刘完素（火热）／张从正（攻邪）／李杲（补土）／朱震亨（滋阴）／张景岳（温补）／叶天士（温病）／王清任（活血）／张锡纯（汇通）。

## 二、底本为什么是派生的

`F:/textbooks/` 下**没有**《中医各家学说》工作簿，各派原书（《素问玄机原病式》《儒门事亲》《脾胃论》《格致余论》《景岳全书》《温热论》《医林改错》《医学衷中参西录》）本库也未收。

因此本课程**不虚构原文**，只做词面统计：

## 四、口径

- **三辨＝学术主张 / 文本依据 / 后世影响**（单元首位：文本依据 6、学术主张 3）；
- **四位面＝理论 / 方药 / 病机 / 传承**（单元首位：病机 6、理论 4）；
- 10 个派生单元、8 章，`locator` 以「派生·第N章·」开头。

## 五、中医 → AI 桥梁

- **文本相似度**：同一概念在不同语料中的分布差异，可作学派相似度矩阵；
- **图网络**：师承与引用关系（本库缺数据，须补原书与史料）；
- **正反对读**：朱震亨 vs 张景岳这类「同一坐标两侧」的分歧，适合做对照检索；
- **证据分级**：原文 / 词面统计 / 教材概括 / 个人推断四层，可直接落成答案的置信度标签。

## 七、四条自我限制（写进正文）

1. **不引原书**：各派代表作本库未收，只引可检索的经典条文；
2. **词面统计 ≠ 归属判定**：同一「火」字可能出自不同语境；
3. **无谱系数据**：师承与门人关系需原书与史料，本章相关论述为条理性说明；
4. **不评价高下**：数据能显示分布，不能显示对错。
