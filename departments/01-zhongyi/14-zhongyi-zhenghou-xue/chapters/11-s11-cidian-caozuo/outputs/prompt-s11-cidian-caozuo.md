# 编码不是给书加编号，是给每一条候装一个唯一把手 · 提示词

## 用途

给「编码不是给书加编号，是给每一条候装一个唯一把手」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三码一树：编码的四段 → 检索的六种式子与入库判据【教学设定】 → 统计口径三条 → 记录字段与失效模式」这条链。

## 提示词

```
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学与工程用途的证候结构重建，不构成诊疗建议。任何证候判定都必须由执业中医师结合四诊完成；具体操作以现行规范与所在机构制度为准。
