# 第 27 章 · 证—法—方对接：从候到治则到方症的索引

> **MOTTO:** 「气有多少，病有盛衰，治有缓急，方有大小」——《素问·至真要大论》
>
> **PROBLEM:** 第 10 章讲到「治法方向」就停了，后面没有路。学生拿着证名与候名，仍然不知道下一步该往哪看；而书里每条候都印着【治则】与【方症】，只是从来没人把它接成索引。
>
> **双根因定位:** 环境逼迫（1860 条候带【方症】、1858 条带【治则】，不接起来就只是一堆原文）＋知识积累（本库已有候→证→门的四级码，缺的只是把法、方挂到同一条码上）

> **概论原文**（`概论·第九节·二`）：「证是病因+病位的临床诊断形式，由于病因多错杂相兼，所以在求因之后，必须进一步审察其错杂情况，如风不仅有内外之分，外风与其他病因相错，又有风寒、风热、风湿、风燥、风暑、风火、风痰的不同；内风有风阳与虚风……」

**辞典定位：** 补篇 · 对应概论第四节 证的结构、第十节 证的论治 · 2 单元 · 12 门 / 45 类 / 291 证 / 1866 候 · 方症索引 1563 / 1860

**母本出处:** 《中医证候学》第一章 病证概论 第四节 证的结构、第十节 证的论治。原文层 `standards/zhenghou-cidian/正文-概论.json`（OCR 逐字，校勘见其 `校勘` 字段）；单元层 `standards/zhenghou/units.json`（51 单元）。本章数字由 `code/main.js` 现算。

**经典锚点:** 《素问·至真要大论》 —— 「气有多少，病有盛衰，治有缓急，方有大小」：法随病机而设，方随法之缓急而分。

## 一、三层怎么接：候是键，法是首句，方是落点

这一层只做一件事：**把「候 → 法 → 方」接成一条可查的线**，并说清它不是什么。三层的取法各有判据，判据写不出来，接上的东西就不可核。

- **候**：`M01-L01-Z01-H001 卫气失宣候`（四级码，唯一）。它是唯一的索引键——候名会重、会省字，码不会。
- **法**：该候【治则】字段的首句，逐字取，不改写。首句里的引文、候名复述一并保留，只加标记，不删。
- **方**：该候【方症】字段里的方名，锚点是「X症：」或方剂后缀（汤／散／丸／丹／饮／膏／煎／锭／片）。

三条判据对应三个「不许」：

**不许改写法句。** 把「卫气失宣候，系风寒初袭皮毛肌表……」缩成「辛温解表」，读起来干净，却已经不是书上的话了。索引层的价值在逐字可回核，改写一次就断了回核的路。首句过长时只做标记（含候名复述、含引文），不做删节。

**不许按后缀硬切方名。** 方名只认「X症：」前的 2–12 字，再叠加后缀白名单作二次确认。仅凭「汤」字切，会把「汤剂」「汤液」切进来；仅凭锚点切，会把「（1）《肘后方》方」这类编号开头切成一串无意义的字。

**不许把多首方合成一首。** 同一条候下常并列数方，书里是按「轻证／重证」「某书方／另一书方」分列的；合成一首，分层就消失了，读者再也看不出书在这里做了取舍。

所以这一层给的不是「标准答案」，而是「这一候在书上对应哪些方」——**对接关系，不是处方**。

**方为什么不设级码。** 四级树是 门 → 类 → 证 → 候，每一级都是「包含关系」：一个门含若干类，一个类含若干证，一个证含若干候。方不是包含关系里的下一级——同一首方出现在不同门、不同候下是常态（桂枝汤既在风门，也在其他门的候里）。若给方设第五级码，就会逼着每首方认一个上级，从而把跨门复用的事实压掉。所以方在本层是**属性**（候的一个字段值），不是**层级**。同理，法也不设码：法句是原文，码是可枚举的东西，把不定长的句子编码只会得到一个又一个同义码。

这个区分有实用后果：按候码可以唯一定位一条候，按方名只能得到一个**候选集**——用方名检索，得到的是一组候，必须逐条回看治则才能确定是不是同一法。

## 二、口径与实测：1563 / 1860 是怎么算的

| 项 | 数 | 口径 |
|---|--:|---|
| 有【方症】字段 | 1860 / 1864 | 分母是候级清单条数 |
| 取到方名 | **1563** | 锚点＋后缀双确认 |
| 取不到 | **297** | 多为「（1）《某书》方」式开头 |
| 含多首方 | **790** | 一候列数方 |
| 方名种类 | **1132** | 去重后的方名数 |

1563 + 297 = 1860，加总对齐；1132 种方名在 1563 次取到里反复出现，平均每方 1.38 次——**这说明方名是一套小词表，而不是一人一方的开放集合**。词表小，索引才立得住；但词表小也意味着「同名异方」的风险，所以本层只记方名，不记出处书目，书目留给原页。

占全书的比要按口径说清：1860 / 1864 是**字段覆盖率**（有没有这个字段），1563 / 1860 是**抽取成功率**（有字段能不能取到名）。两个分母不同，混着算会得出一个既不是覆盖率也不是成功率的数。

方名频次最高的几个（小柴胡汤 15、龙胆泻肝汤 12、犀角地黄汤 11、补中益气汤 10、乌梅丸 9、附子理中汤 9、当归四逆汤 9）说明的是「哪些方被反复当作某类候的落点」，**不是「这些方最常用」**——频次来自辞典的编写分布，不来自临床使用分布。

**法句有三种形态，记录时必须分开标：** 一是**纯治法句**（如「治宜益气固脱」），法意直给；二是**含引句**（首句里先引《内经》或前贤语再落治法），法意要读到第二层；三是**含候名复述句**（开头先把候名与病因再述一遍，治法在后半句），这是书里最常见的形态。三种都按「逐字取首句」处理，区别只在标记：不标，检索时会把引文当法，把复述当重复。一条候的法句若三种形态都不属（首句只是一句病情描述），记「无法句」，不硬凑。

## 三、一候多方是常态：790 / 1860 附数方

790 / 1860 的候附有多首方。这不是编排冗余，是母本的写法：同一条候，书里常按轻重分层、按来源分列。索引层若只留第一首，就把「书在这一候上有分歧、有分层」这件事抹掉了。

**方症字段本身分四段，本层只取前两段：** 方名（第一段）、症（第二段，随方列出的证象）、分列编号（第三段，如（1）（2）各附出处书目）、药味组成（第四段，逐味与用量）。取到第二段为止，是这一层的硬边界——第三段只用来判「这是第几首方」，第四段完全不取。所以本层的产物里不会出现药味，也不会出现用量；任何在这条线上加内容的行为，都会把索引变成处方。

> 第十节：「证的论治，以证的内容为依据，以证的称谓为标帜……凡立法、选方、遣药，均不得脱离此标帜。」

「标帜」二字是这一层的枢纽：证名仍是标帜（第 10 章），法随病机而变，方只是该法在书上的**历史落点之一**。把三者混成一句「某证用某方」，就把这一层又读回了死记——死记的是方，丢掉的是「为什么是这一法」。

第四节把「方症」定义为「方名＋证象」的对应体，同一段里举的例子是「麻黄汤证」。**注意这个定义只到对应体，不含剂量、加减、禁忌**——本层严格停在这条线上，越过去就是处方，而不是索引。

第十节还有一层常被漏掉的提醒：实际情形里「病因、病位超过了证的命名的两个」，对证施治时必须兼顾那些没写进证名的兼位。落到索引层，就是**法句只记主导，兼位要另记**——一条候的治则首句往往只写主导方向（如「消除肺卫的风寒」），而兼治（如「兼以宣泄卫气」）在同段后半或后句里。本层不做合并，只把兼治另标一段；合并会把「书在这里做了兼顾」这个信息抹掉，而它恰恰是证名与治法之间最容易被忽略的落差。

## 四、记录字段与失效模式

**记录字段六项**：

| 字段 | 填法 | 反例 |
|---|---|---|
| 候码 | 四级码，唯一 | 只写候名 |
| 法句 | 首句逐字，附「含引／含候名」标记 | 缩写成四字治法 |
| 方名 | 「X症：」前 2–12 字，取不到记 null | 硬造一个近似的方名 |
| 方数 | 该候方名个数 | 只记第一首 |
| 索引状态 | 取到／取不到／待核 | 一律写「已接」 |
| 出处 | 正文文件＋册 | 只写「据方症」 |

**五种失效模式**：

1. **编号开头取不到名。** 「（1）《肘后方》方：……」这类写法，锚点前没有中文方名，只能记 null——297 条多属此类。补名的唯一合法路径是回原页人工读，不许按方剂学常识猜。
2. **方名跨行被截。** 方名与「症：」分处两行时，前段只剩半名；本层按白名单拒收半名，宁可记 null。
3. **同名异方被合并。** 「理中汤」与「理中丸」按方名归并会把剂型差抹掉；本层只按字面归并，剂型差异在比对时单列。
4. **法句含引文。** 首句引《内经》或前贤语时，「法」看起来像一段议论；记录时标「含引」，检索时单独看待。
5. **一候多方的顺序被当优先级。** 书里的排列多按轻重或来源，不是推荐次序；索引层不排序，任何排序都是外加的。

还有两条不许做的动作：**不许以方名反推证名**（「小柴胡汤治少阳」不等于「见小柴胡汤即少阳证」，方向不能倒），**不许把索引当处方**（剂量、加减、禁忌都不在其中）。

## 五、代价与边界

本层不给剂量、煎服法、加减与疗程；不替代《方剂学》的主治归经，也不构成用药建议。处方由具备资质者依规范开具。

写厚这一章的代价写在这里：概论只有 2.7 万字，它是**总论**，讲的是规则不是病例；把它当全部证候学来学，会得到一套干净但干旱的框架。所以每章的实测表都把读者指回辞典正文层（1866 条候的原书释义）——**规则在概论，材料在辞典，两者不能互相替代**。

边界还有一层：**297 条记 null 不是缺陷，是这一层守住了不编造这条线。** 一份 84% 成功率的索引，比一份 100% 完整但有一成方名是猜的索引更有用——因为前者可以逐条回核，后者不能。
