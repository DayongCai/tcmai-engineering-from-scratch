# 第 12 章 · 一条病案走完六步，才算把辞典用了一次

> **MOTTO:** 「病为本，工为标。」——《素问·汤液醪醴论》
>
> **PROBLEM:** 前十章各自成立，一到真实病例就散：求因与定位混着做，证名与治法对不上，写出来的病案别人复核不了。散的原因不抽象——1866 条候里，最大的一个证（脾胃湿热证，L12-Z13）下就有 35 条候，中位数只有 5 条；在一个 35 条候的证里不按步骤走，随手挑一条，命中率不到三十分之一。
>
> **双根因定位:** 环境逼迫（病案要能被别人复核、要被编码进入数据库，任何一步跳过的记录都无法复核）＋知识积累（前十一章给了判据、编码与规则，缺的是一条把它们连起来的工序；工序不立，规则就只是条文）

> **概论原文**（`概论·第九节`）：「为了临床识证的需要，历代医家通过千百年来的经验总结，归纳了各种证的具有特异性的表象，即包括症象、脉象、舌象的各自特征，以及其相互组合的特点，作为识证的标帜，给证的诊断带来了一定的便利条件，大体上有：（……」

**辞典定位：** 综合实操 · 六步（病·因·位·证·候·治）· 1866 候 / 291 证 / 72 证象格 / 21 位 / 1563 方症 / 261 危候

**母本出处:** 综合运用《中医证候学》第一章 病证概论 第一至十节，并参 `standards/zhenghou-cidian/结构.json`、`方症索引.json`、`危候判据.json` 的计数。

## 一、六步与每步的采集项

工序是六步，顺序不能换。换序的典型是「先想方，再找证」，那不叫辨证，叫给方找理由。

**第一步，主诉与病。** 采集起病时间、病程、既往、体质、用药史。产出：一句病名加一句病程，写在首行作背景。判据：这一句能不能说清「从何时起、按什么节奏走」。

**第二步，求因。** 从十五类里取一条主因。采集该因的特性象：动、收引、炎上、重着、干涩、黏蒙、清稀、壅腐、扰动、不足。产出：一条主因，零到一条兼因。判据：主因的证据能不能成组，且至少一条来自舌或脉。

**第三步，定位。** 从 21 格里取一格主位。采集脏之外应：皮毛鼻、肌肉口、筋目、骨髓耳二阴、血脉舌。产出：一个 Z 码，零到一格兼位。判据：该位有没有独有的特异象。

**第四步，合证。** 因＋位合成证名，回指到唯一码。产出：门-类-证三段码。判据：码能不能唯一回指，证名与主证是否相符。

**第五步，查候。** 在证下比对候，定病层与病态。产出：一条主候，零到两条附候。判据：层是否在证位之内，态是否由因所致，候名是否在该证的候表里。

**第六步，立法。** 由层与态出方向，由显性加隐性定范围，最后到方症索引核对。产出：方向一句、范围一句、方症一条（可缺）。判据：方向能不能从层态推出，范围是否覆盖隐性清单。

六步之外还有一道闸：**危候判据**。1864 条候里命中 261 条，其中厥脱 26、陷逆 37、脱绝 17 为明确档。任何一步若出现脉骤变、神志变、四肢温凉骤变，先过这道闸，再回工序。

## 二、六步的完成判据与「不成立」【教学设定】

| 步 | 完成需 | 不成立 |
|---|---|---|
| 病 | 起病＋病程＋走向 | 只有病名 |
| 因 | 主因一条，成组含舌脉 | 两因并列、或单症定因 |
| 位 | 主位一格，有特异象 | 位过宽、或以症状部位定位 |
| 证 | 可回指唯一码，与主证相符 | 回指两条、或证名与主证不符 |
| 候 | 层在证位内、态由因所致 | 候名不在该证候表、或层态错配 |
| 法 | 方向由层态推出、范围覆盖隐性 | 由类名推方向、或漏隐性因位 |

五条「不成立」：

**一、跳步。** 从主诉直接到证名。跳过的因与位没有记录，别人无法复核；复核不了，病案就不是病案，是结论。

**二、回填。** 先有结论再补证据。回填的特征是证据条数与结论的强度不匹配：结论写「湿热内蕴」，证据只有一条苔腻。

**三、一名多码。** 证名回指到两条码。辞典只有一处（L05-Z13），但记录里常见——写「脾胃虚寒」可能指脾胃阳虚，也可能指脾胃气虚，两者码不同。

**四、候名自造。** 写的候名不在该证的候表里。脾胃湿热证 35 条候里没有「湿热中阻候」，自造一个，统计时就归不进去。

**五、法与证脱节。** 证是湿热，法写温燥；或证在气分，法用血分药。脱节多半是第六步没回看第四步。

## 三、动作：一例到底

下面这条病例从主诉走到方症，六步各留记录。

**主诉与病。** 脘痞反复三月，食后加重，伴口苦、大便黏滞不爽。起病缓，无发热，无消瘦。病：痞满（背景），病程三月，走向缠绵。

**求因。** 象组：脘痞、口苦、大便黏、苔黄腻、脉濡数、身重。对性：重着（湿）＋炎上（热）。成组：湿象三条（脘痞、便黏、苔腻）、热象两条（口苦、脉数），均含舌脉。排他：燥的反证（苔干）不在场；寒的反证（得温减）不在场。主因：湿；兼因：热。

**定位。** 外应：脘痞属脾胃，口苦属胆胃，胁胀属肝。候选：Z13 脾胃、Z15 胆胃、Z20 肝胆。特异象：Z13 的脘痞便溏、苔腻；Z15 的口苦目眩；Z20 的胁胀脉弦。本条脘痞为主、口苦为次、无目眩、胁胀不显。主位：Z13 脾胃；兼位：无（口苦归兼因之象，不单立位）。

**合证。** 湿＋脾胃＝脾胃湿热证，回指 M04-L12-Z13，唯一。校验：该证 35 条候，是全书最大的一个证；证名与主证（脘痞、苔黄腻）相符。

**查候。** 该证候表里与本条最合的是「清气郁蒸候」：主证脘痞、苔黄腻，副证口苦、身重，脉濡数。层为清气，在脾胃证位之内；态为郁蒸，由湿热郁遏所致。附候记「胃气失和候」（食后加重、嗳气），不并列为主。

**立法。** 层在清气，态为郁蒸，方向为「清化宣展」，范围覆盖湿（显性）、热（兼因）、脾胃（主位）；隐性清单两条：一是「湿重伤阳」（母本语），二是「炉烟虽熄，恐灰中有火」所指的伏热（用药史：前医曾用寒凉两剂，痞未减而便更黏）。方症索引里该候可取的方不止一首，选方以覆盖范围为准，不以方名熟悉为准。

**闸门检查。** 无脉骤变、无神志变、四肢温凉正常，不过危候闸。

这条病例的价值不在结论，在每一步都留下了可被反驳的记录：因有象组与反证，位有候选与排除，证有回指码，候有层态与候表核对，法有方向与范围。任何一步被反驳，后面都要重做——这才是工序的意义。

**边界三条。** 其一，六步只到「法定方向、方定范围」，具体用药与服法不在本章。其二，六步不替代四诊，缺一项（如脉）时只能记「待补」，不能推断。其三，六步不判预后；病势顺逆与危候要另走第 5 章与第 26 章两套判据。

## 四、记录字段与失效模式

| 字段 | 记什么 | 本例 |
|---|---|---|
| 病（背景） | 病名＋病程＋走向 | 痞满，三月，缠绵 |
| 象组 | 症、脉、舌分组 | 脘痞、口苦、便黏、苔黄腻、脉濡数 |
| 主因／兼因 | 各一条 | 湿／热 |
| 主位／兼位 | Z 码 | Z13／无 |
| 证 | 位＋因＋证 | 脾胃湿热证 |
| 码 | M-L-Z | M04-L12-Z13 |
| 主候／附候 | 层＋态 | 清气郁蒸候／胃气失和候 |
| 隐性清单 | 来源＋证据 | 湿重伤阳（痞久）；伏热（用药史） |
| 方向／范围 | 一句各一 | 清化宣展／湿·热·脾胃 |
| 方症 | 方名（可缺） | 该候方症，按范围选 |

四种失效模式，各自对应一步：

**以病代证。** 写「慢性胃炎，湿热中阻」。病灶在第一步与第四步：病名占位，证名无 Z 码。

**以症代候。** 写「苔黄腻，湿热」。病灶在第二步与第五步：单症定因，且无层无态。

**证名串联。** 写「脾胃湿热兼肝郁气滞」。病灶在第三步与第四步：两个位、两个因并列，违反两因两位。

**术语混用。** 写「湿热蕴结中焦，宜清热燥湿，用某方加减」。病灶在第五步与第六步：把病机（蕴结）、治法（清热燥湿）、方（某方）三层混成一句，层与态没有分开写。

## 五、代价与边界

第一层代价是**工序比结论慢**。六步走完，一条病案要写十行以上；临床上多数记录只有三行。慢的收益是可复核，代价是时间。本章不掩饰这个交易：在需要复核的场合（教学、科研、会诊、留档），六步是底线；在只需要处置的场合，可以压缩，但要记住压缩的是记录，不是判断。

第二层代价是**候的选择在最大证上最难**。脾胃湿热证 35 条候，是全书最大的一个证；中位数只有 5 条。同一个证里，候数从 2 到 35，差十七倍。候越多，判据越细，选错的概率越高；候越少，判据越粗，漏掉的可能越多。工序能保证「按层态选」，不能保证「选得对」——后者要靠对 35 条候逐条读过。

第三层代价是**隐性清单的边界模糊**。本例列了两条隐性因位，都有一条证据；若把四个来源推到底，还能列出更多（体质、季节、情志）。本章用「一条证据」作门槛，只是把清单压到可执行的规模，不保证不漏。漏掉的隐性因位，往往在复诊时才暴露。

第四层边界是**本章只到内治的方向与范围**。方药的具体选择与服法，都不在本章；针灸、外治、调护也不在。辞典能提供的是诊断与方向，不是处方。把本章当处方用，是把地图当路走。

还有一层要交代：**复诊是同一工序再走一遍，不是打补丁。** 复诊时主诉会变，象组会变，主因与主位都可能换；若不重走六步，只在原证上加减，就会把「变化」记成「兼夹」。正确的做法是把上一次的记录与这一次的记录并排：同一栏位逐项比，变了哪一栏，就在那一栏写清为什么变。母本讲传变「定向但无定体」，落到记录上就是两句话：方向可以延续，证名不能照抄。

工序的最后一道是交接。一条病案要交给别人复核，至少要给出三样：可回指的码、每一步的证据、每一步的排除理由。三样齐，复核者可以逐条反驳；三样缺一，复核者只能凭印象同意或不同意。辞典的 291 证、1866 候本身不保证判断正确，它们保证的是——只要按工序写，判断就是可以被检验的。

1. 写出六步的顺序与每步的产出，说明为什么顺序不能换。
2. 复算 35÷2 与 35÷5，说明最大证与中位证的候数差，对选候意味着什么。
3. 用六步走一遍「脘痞、口苦、便黏、苔黄腻、脉濡数」，写出每步的记录。
4. 指出「湿热蕴结中焦，宜清热燥湿，用某方加减」这句话混了哪三层，并拆开重写。
5. 说明危候闸在六步中的位置，以及触发它的三个信号。
