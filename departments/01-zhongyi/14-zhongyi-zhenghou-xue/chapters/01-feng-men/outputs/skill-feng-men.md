# feng-men

## 何时用

需要把一段中医四诊描述，或一个既有证候名，落到《中医证候学》风门的编码上时。

## 输入

| 输入 | 形态 | 例 |
|---|---|---|
| 四诊描述 | 自由文本 | 恶寒重、无汗、头身痛、脉浮紧 |
| 既有证候名 | 字符串 | 肺卫风寒证 |
| 全码 | 字符串 | M01-L01

## 步骤

1. 读 `standards/zhenghou-cidian/结构.json`，取 `men` 中 `code == "M01"` 的子树。
2. 判据词过滤：不能用「动」说清的，直接返回「不属于本门」。
3. 位匹配：把描述里的部位/层次映射到 `语素-位.json` 的证位（22）或候位（62）。
4. 性匹配：选类（L01、L02、L03、L04）。
5. 态匹配：从 `语素-态.json` 的 108 态里选，禁止新造。
6. 输出全码 `M01-Lnn-Zmm[-Hnnn]` 与一句治法动作。

## 输出

```text
门 M01｜类 Lnn ｜证 MM01-Lnn-Zmm ｜候 -Hnnn ｜态 xxx｜治法动作 xxx
```

## 边界

只做编码与检索，不做诊断；**不构成诊疗建议**。词表外的说法一律返回「无法归码」，不许模糊匹配。
