# 第 7 章 · 内生九因没有季节可依，只能靠病机形态认

> **MOTTO:** 「百病生于气也。」——《素问·举痛论》
>
> **PROBLEM:** 第九节·一 的后九目共 3,409 汉字（火 550、气 328、瘀 325、痰 626、饮 409、水 338、食 386、虫 223、虚 224），对应七门共 1,170 候（火 313、气 98、瘀 126、痰 159、饮 103、食 64、虚 307），占 1866 候的 62.7%。比值差得悬殊：食＋虫 609 字只挂 64 候（9.5 字/候），虚 224 字却挂 307 候（0.7 字/候）——最省的因，条目最多。
>
> **双根因定位:** 环境逼迫（内伤杂病的病因不从天时来，没有季节表可查，只能从证象反推，且反推的方向与六淫相反——先见形态，后推因素）＋知识积累（概论把九目逐条写定，火与热、水与饮、虫与食的合并规则也已给定，使判据表可以直接落地）

> **概论原文**（`概论·第九节·一`）：「尽管证是处于动态演变的过程中，只要有相应的特征出现，即可认定病因的存在。」

**辞典定位：** 辨证求因（下）· 九因（火·气·瘀·痰·饮·水·食·虫·虚）· 3,409 汉字 / 7 门 / 1,170 候（62.7%）

**母本出处:** 《中医证候学》第一章 病证概论 第九节·一（辨证求因，火至虚九目）。字数取自 `standards/zhenghou/units.json`，候数取自 `standards/zhenghou-cidian/结构.json`。

## 一、九因的形态与采集项

六淫可以问天时，内生九因没有天时可问。母本的办法是**先立形态**：每一因都有一种可观察的「坏法」，采集从坏法入手，不从原因入手。

**火，性炎上而耗气伤津。** 采集项是上炎与消耗：面赤目赤、心烦、口苦、咽痛、出血、疮疡、舌红、脉数。与热的区别在程度与部位：热多指外感之热，火多指内生之热，且火常见于局部（目、口、咽、齿）。

**气，性郁滞而升降失司。** 采集项是郁与逆：胸胁胀满、嗳气、太息、情绪相关、症状随情绪起伏、脉弦。气病的关键是「胀而不痛」或「痛而走窜」，与瘀的「痛有定处」相对。

**瘀，性滞涩而固定。** 采集项是定处与色暗：痛有定处、拒按、夜甚、面色黧黑、唇甲青紫、舌紫或有瘀点、脉涩。瘀的判据最硬，因为「定处、拒按、夜甚」三条可以互相独立验证。

**痰，性黏滞而随处可到。** 采集项是黏与蒙：咳痰黏稠、胸闷、恶心、眩晕、喉中异物感、舌苔腻、脉滑。痰的特点是「无定处」，与瘀的「定处」正是两面。

**饮，性清稀而停聚。** 采集项是清稀与停聚：咳痰清稀、背冷、肠鸣、振水音、苔白滑、脉弦。饮与痰的分界在稠稀：稠者为痰，稀者为饮。

**水，性泛溢而肿。** 采集项是肿与小便不利：浮肿、按之凹陷、腹胀大、小便短少、苔白滑。水与饮的分界在「聚」与「泛」：停于局部者为饮，泛于肌肤者为水。

**食，性壅塞而腐。** 采集项是壅与腐：脘腹胀满、嗳腐吞酸、厌食、大便臭秽或夹不化之物、舌苔厚腻。食的判据靠「嗳腐」与「大便夹不化之物」两条，比「腹胀」可靠。

**虫，性扰动而耗。** 采集项是扰动与耗：脐周痛、时作时止、面黄、嗜食异物、睡中磨牙、大便见虫。虫的条目最少（3 证 14 候），判据依赖两条硬证据：见虫，或典型的时作时止腹痛。

**虚，性不足而失用。** 采集项是不足与失用：气短乏力、面色淡、脉细弱、舌淡。虚分四类——气、血、阴、阳，各有其象。虚是九因里唯一条目多于文字的一因：307 候对 224 字。

**九因的判据强度天然不同。** 瘀有三条可独立验证的硬指标（定处、拒按、夜甚），食有两条（嗳腐、不化之物），虫有一条（见虫）。痰、饮、水三者靠稠稀与聚泛分辨，指标偏软；气靠「与情绪相关」这一条，也偏软；虚靠脉与舌，介于软硬之间。所以九因的误判集中在气、痰、饮三者，而不是瘀与食。

## 二、成组判据与「不成立」条件【教学设定】

| 因 | 成立需（成组） | 不成立（反证） |
|---|---|---|
| 火 | 上炎象＋舌红脉数＋局部灼痛或出血 | 畏寒、脉迟、苔白滑 |
| 气 | 胀满或走窜痛＋随情绪起伏＋脉弦 | 定处拒按（瘀）、器质肿块 |
| 瘀 | 定处＋拒按＋夜甚（三条取二） | 痛处游走、按之则舒 |
| 痰 | 黏＋蒙＋苔腻脉滑 | 痰清稀（饮）、无苔腻 |
| 饮 | 清稀＋停聚＋苔白滑 | 痰稠、口干舌燥 |
| 水 | 肿＋按之凹陷＋小便不利 | 肿而按之即起（气肿） |
| 食 | 嗳腐或不化之物＋苔厚腻 | 无嗳腐、大便正常 |
| 虫 | 见虫，或时作时止的脐周痛 | 持续定处痛 |
| 虚 | 不足象＋脉细弱或舌淡＋病程久 | 脉实、舌红苔厚（多属实） |

五条「不成立」：

**一、以症代因。** 见胀就写气，见痰就写痰。胀可以是食积、可以是水停；痰可以是饮、可以是湿。单症定因在九因里比六淫更危险，因为九因的症状重叠度更高。

**二、因果倒置。** 因为用了活血药有效，就写「瘀」。疗效不是判据，母本只把方症当对应物，不当证据。

**三、合并不当。** 把水写成饮，把虫写成食。母本在门层做了合并：水并入饮（M10），虫并入食（M11）。合并是目录的便利，不是判据的等同；记录里要写清水或虫，不能只写合并后的门名。

**四、虚实混写。** 写「痰热内盛，兼气阴两虚」而不分主次。虚与实并存时，必须判哪一边是当下主导：脉有力而苔厚，实为主；脉细弱而苔薄，虚为主。

**五、痰饮不分。** 见咳痰就写痰。痰稠、饮稀，这是母本给的第一分界；第二条是位：痰无处不到，饮多停于胸胁、胃肠。

## 三、动作与边界：从形态反推

**第一步，找形态。** 九因各有坏法，先把材料归到形态上：是炎上、是郁滞、是固定、是黏蒙、是清稀停聚、是泛溢、是壅腐、是扰动、是不足。形态对不上任何一条，说明材料不够或病因在六淫那一半。

**第二步，分稠稀与聚泛。** 这一对对照能一次分开痰、饮、水三因。稠＝痰，稀而聚＝饮，稀而泛＝水。三者的位也不同：痰无定处，饮停局部，水泛肌肤。

**第三步，验硬指标。** 瘀与食靠硬指标确认：定处、拒按、夜甚；嗳腐、不化之物。硬指标在场，不必再找旁证；硬指标不在场，旁证再多也只能进候选。

**第四步，判虚实主次。** 虚与实并存时，用脉力与舌苔两项判主次：脉有力、苔厚腻，实为主，虚为兼；脉细弱、苔薄少，虚为主，实为兼。主次决定命名的先后。

**第五步，定主兼并写合并前的原名。** 主因进证名，兼因进兼夹栏；水、虫要写原名，不写合并后的门名。合并只用于编码，不用于诊断表述。

**边界三条。** 其一，本章只求因，不定位；九因落到哪个位，在第 8 章。其二，本章不处理六淫，风寒暑湿燥火在第 6 章。其三，本章不判危候；虚到脱、瘀到闭，都要转交危候判据，在第 26 章。

虚的四类要按一个固定顺序判，顺序错了会互相冒充。先判**气虚**：气短、乏力、动则加重、脉弱，这是最外层；再判**阳虚**：气虚之象加畏寒肢冷、便溏、舌淡胖，阳虚必含气虚；再判**血虚**：面色淡、唇甲淡、心悸、脉细，血虚可与气虚并存，也可单独成立；最后判**阴虚**：形瘦、五心烦热、盗汗、舌红少苔、脉细数，阴虚与阳虚是两极，不会同时成立。四类的顺序是「气→阳→血→阴」，因为阳虚含气虚、阴虚不含阳虚，先判两极容易把中间的层次跳过。四类各自落到五脏，就有了虚门的 44 证：气虚 12 证、血虚 4 证、阴虚 14 证、阳虚 14 证——四类之中，血虚的证最少，只有 4 个，说明血虚的位分化最不细，判起来也最容易含混。

## 四、记录字段与失效模式

| 字段 | 记什么 | 例 |
|---|---|---|
| 形态 | 九种坏法之一 | 固定 |
| 硬指标 | 逐条写有／无 | 定处：有；拒按：有；夜甚：有 |
| 稠稀聚泛 | 痰／饮／水 | —（不适用） |
| 主因 | 一条 | 瘀 |
| 兼因 | 在场但不命名 | 气虚 |
| 原名 | 水、虫须写原名 | — |
| 虚实主次 | 实主虚兼／虚主实兼 | 实主虚兼 |

四种失效模式：

**以病代证。** 写「冠心病，心血瘀阻」。病名占位，证只有因没有位；「心血瘀阻」的位是心与血，但未按 21 格写出组合。

**以症代候。** 写「胸痛，属瘀」。胸痛可以是瘀、是气、是痰、是阳虚；单症定因，且没有层态。

**证名串联。** 写「痰瘀互结兼气滞」。三个因串联，主次全无；正确写法是主因一条，其余进兼夹栏并注证据强弱。

**术语混用。** 把「痰」当「湿」，把「饮」当「水」，把「火」当「热」，把「虚」当「气虚」。虚是四类的总名，气虚只是其中一类；用总名代替分类，治法就落不到具体。

## 五、代价与边界

第一层代价是**九因的判据软硬不均**。瘀与食有硬指标，气、痰、饮只有软指标。软指标的通病是可被叙述塑造：同一组症状，换一个问法，可以问出「胀」也可以问出「痛」。所以九因的误判不在瘀与食，而在气、痰、饮；这三因的记录必须写明采集方式，否则无法复核。

第二层代价是**合并规则留下的缝**。水并入饮、虫并入食，编码上省了两个门，诊断上少了两个名。合并之后，「饮」要同时承担停聚与泛溢两种形态，「食」要同时承担壅塞与扰动两种形态。读者若只看门名，会把两种形态当成一种。

第三层代价是**虚的过度概括**。虚只有 224 字，却挂 307 候，占全书的 16.4%；虚门一门就有 44 证，比火门以外的任何门都多。字数少、条目多，意味着概论的文字只给了原则，具体判据要靠 44 证逐条去读。把「虚」当成一个判据用，等于用一条原则处理 307 条候。

第四层边界是**内生与外感的交叉**。九因里没有一条是纯粹内生的：火可以由外热引动，痰可以由外湿凝聚，瘀可以由外伤所致。本章按「内生」归类，是按判据的形态归，不是按成因归。用成因去套，会把大量外因所致的痰瘀火排除在九因之外。
