# 病是全程、证是阶段、候是当下的一步，三级混称一次就丢一层 · 提示词

## 用途

给「病是全程、证是阶段、候是当下的一步，三级混称一次就丢一层」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三级各自回答一个问题 → 成组判据与「不成立」条件【教学设定】 → 动作与边界：一条病案的拆法 → 记录字段与失效模式」这条链。

## 提示词

```
我在学《中医证候学》第 1 章「病是全程、证是阶段、候是当下的一步，三级混称一次就丢一层」，本章 5 节 / 3,091 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 一条母本原例可以把三级一次摆开
   - 是病位，取自 21 个病位组合里的 Z01
   - 是病层，比「肺卫」更细一层——肺卫是证的位，卫气是候的位
   - 一、以病名代证
   - 二、以证名代候
   - 三、一个证名塞两个阶段
4. 指出本章写到类别就止步、不再给参数的地方。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学与工程用途的证候结构重建，不构成诊疗建议。任何证候判定都必须由执业中医师结合四诊完成；具体操作以现行规范与所在机构制度为准。
