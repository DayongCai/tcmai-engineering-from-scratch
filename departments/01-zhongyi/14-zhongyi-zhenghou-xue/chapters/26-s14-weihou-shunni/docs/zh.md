## 一、危候与顺逆

本层先划清一件事：**词面判据不等于临床判据**。它回答的是「这一候的名字与治法里有没有危象语义」，
不回答「这个病人现在危不危险」。这个区分必须写在标题里，否则最容易被误用。

词面判据由三条线索拼成：

1. **候名态根**：名字里带「厥脱 / 厥逆 / 亡阳 / 亡阴 / 虚脱 / 气脱 / 血脱 / 液脱 / 陷逆 / 内陷 / 闭脱」的候。
2. **治则用语**：治则中出现「救逆 / 固脱 / 回阳 / 开窍 / 醒神 / 急下 / 益气固脱 / 凉血解毒 / 透热转气 / 急存阴」等。
3. **口语危象表**：`口语别名.json` 里的 17 条百姓说法（昏倒、不省人事、冷汗淋漓、大汗如油、脉微欲绝、气息奄奄…），
   分别归到三档——**厥脱 / 脱绝 / 陷逆**。

实测结果（`危候判据.json`）：候名命中的 **80 条**（厥脱 26 · 脱绝 17 · 陷逆 37），
只命中治则用语的 **181 条**（列为「候选」，不判危候），两条线索同时命中的 **42 条**。
80 与 181 的差，就是这个方法诚实的地方：**只靠治法词会把普通候也算成危候**，所以它们停在候选，等人工复核。

顺逆的判断在概论里是另一条线：**由阳入阴多恶，由阴出阳多顺**；「阳病见阴，病必危殆；阴病见阳，虽困无害」。
这条线不看字面，看的是证的走向——它与词面判据互补：字面判「当下像不像危」，走向判「在往好还是往坏走」。

## 二、概论原文（本章锚点）

**`概论·第八节`**

> 证的传变，是疾病演变过程的具体体现，是疾病定向演变的普遍规律。张仲景《伤寒论》伤寒传变说形成“六经传变”的学说，至明代吴又可论瘟疫则有“九传”之说，清代温病诸家倡导“三焦”传变说和“卫气营血”传变说等。然而均是以病位传变为基础的，至清代俞根初《通俗伤寒论》则从病因、病机演变论述传变。俞根初日：“伤寒一证传变颇多，不越乎水化、火化、水火合化三端。从火化者，多少阳相火证、阳明燥实证、阴风热证；从水化者，多阳明水结证、太阴寒湿证、少阴虚寒证；从水火合化者，多太阴湿热证、少阴、厥阴寒热错杂证。”至此始得传变全貌。

## 四、误判清单

**误判一：把候名带「闭」的都当危候。** 「经脉闭塞」是病机描述，不是危象；所以本层把只命中字面的条目一律保留依据、交人工核。
**误判二：用词面判据替代临床判断。** 词面判据只用于检索与教学；病人危不危要看四诊与生命体征。
**误判三：把「逆」当恶化。** 逆传是走向判断，不是程度判断；里邪出表也可能伴危象。

## 五、代价与边界

本层不做生死判断、不给处置时限、不给急救流程；急诊处置按机构规范。危候清单仅供检索与教学复核，删条必须写理由。

写厚这一章的代价写在这里：概论只有 2.7 万字，它是**总论**，讲的是规则不是病例；把它当全部证候学来学，会得到一套干净但干旱的框架。所以每章的实测表都把读者指回辞典正文层（1866 条候的原书释义）——**规则在概论，材料在辞典，两者不能互相替代**。
