# 第 26 章 · 危候与顺逆：词面判据能做与不能做的事

> **MOTTO:** 「凡厥者，阴阳气不相顺接，便为厥」——《伤寒论·辨厥阴病脉证并治》
>
> **PROBLEM:** 「危候」在教材里往往只给一句「病情危重」，没有判据。于是两种做法都不对：一种凭印象说重，一种干脆不写。
>
> **双根因定位:** 环境逼迫（1866 条候里必然有一批带危象语义的，临床与教学都要能把它们挑出来）＋知识积累（候名尾部态根、治则用语、口语危象表三样都在库里，可以做成词面判据并逐条标依据）

> **概论原文**（`概论·第八节·三`）：「可以从现代医学的病理损害转化为致病因素等去理解，但又不全是这样，亦有两种过程。」

**辞典定位：** 补篇 · 对应概论第八节 证的传变、第十节 证的论治 · 5 单元 · 12 门 / 45 类 / 291 证 / 1866 候 · 危候判据 261 条

**母本出处:** 《中医证候学》第一章 病证概论 第八节 证的传变、第十节 证的论治。原文层 `standards/zhenghou-cidian/正文-概论.json`（OCR 逐字，校勘见其 `校勘` 字段）；单元层 `standards/zhenghou/units.json`（51 单元）。本章数字由 `code/main.js` 现算。

**经典锚点:** 《素问·玉版论要》 —— 「上为逆，下为从」——顺逆是一对方向词，不是一对程度词；危候判据取的是「有没有危象语义」，顺逆判的是「在往哪边走」。

## 一、两条判据，两个方向

本层先划清一件事：**词面判据不等于临床判据**。它回答的是「这一候的名字与治法里有没有危象语义」，不回答「这个病人现在危不危险」。这个区分必须写在标题里，否则最容易被误用——误用的代价是有人拿一份检索清单当分诊标准。

词面判据由三条线索拼成，每条都要能指出「依据是哪个字」：

1. **候名态根**：名字里带「厥脱／厥逆／亡阳／亡阴／虚脱／气脱／血脱／液脱／陷逆／内陷／闭脱」的候。这一路最硬，因为态根是书自己给的分类词。
2. **治则用语**：治则中出现「救逆／固脱／回阳／开窍／醒神／急下／益气固脱／凉血解毒／透热转气／急存阴」等 15 个提示词。这一路最软，因为它只说明「这一候的处置方向重」，不说明当下危。
3. **口语危象表**：`口语别名.json` 里的 17 条百姓说法（昏倒、不省人事、冷汗淋漓、大汗如油、脉微欲绝、气息奄奄……），分别归到三档。

三档的语义边界要分清，不能互相顶替：

- **厥脱**：阴阳气不相顺接，以厥冷、昏倒、呼之不应为主——判的是「接不上」；
- **脱绝**：气血津液外脱，以冷汗淋漓、大汗如油、脉微欲绝为主——判的是「守不住」；
- **陷逆**：病邪内陷、气机逆乱，以抽搐不止、口吐白沫、意识不清为主——判的是「往里走、往上冲」。

走完这三条线索要按固定次第，不能跳步：**先看候名态根定档，再看治则用语补证据，最后用口语表对读**。次序颠倒的后果是档位被治法牵着走——先看治法，几乎每条重候都会显得危急，档就失了分辨力。口语表放在最后，是因为它只用来对读医患两套说法，不用来定档。

**一条候在清单里只能占一档。** 两档同时命中的，按「候名态根优先于治则用语」定档，并在记录里写明「档间竞争」，不许两边都记——两边都记，统计就重复了。

顺逆是另一条线，方向与危候正交：**由阳入阴多恶，由阴出阳多顺**；「阳病见阴，病必危殆；阴病见阳，虽困无害」。这条线不看字面，看的是证的走向。它与词面判据互补：字面判「当下像不像危」，走向判「在往好还是往坏走」。两者可以同时成立——里邪出表是顺，途中仍可伴危象；也可以同时不成立——字面干净而走向已坏，这正是词面判据的盲区。

走向判据要有落脚处，概论把它落在传变上：六经、九传、三焦、卫气营血诸说「均是以病位传变为基础」，而病因层面的演变「归纳起来不外有3种过程：火化、水化、水火合化」。**火化者多阳证、水化者多阴证、水火合化者多寒热错杂**——一个候从火化转水化，是走向在变；同一候名下的危象，也可能因为火水之变而换档。所以判顺逆时先问两句：这一候从哪一端来、往哪一端去。只问「名字里有没有危字」，答不了这两句。

## 二、口径：261 怎么分成 80 与 181

实测（`危候判据.json`，分母是 1864 条候）：

| 项 | 数 | 说明 |
|---|--:|---|
| 候名命中 | **80** | 厥脱 26 · 脱绝 17 · 陷逆 37 |
| 只命中治则用语 | **181** | 列为「候选」，不判危候 |
| 两路同时命中 | **42** | 80 与 181 的交集 |
| 合计入清单 | **261** | 80 + 181 |

80 与 181 的差，就是这个方法诚实的地方：**只靠治法词会把普通候也算成危候**（清热解毒出现在大量普通候的治则里），所以它们停在候选，等人工复核。反过来说，只靠候名会漏——有些危候的态根写得克制，危象只出现在治则里。

这里有一条口径必须讲死：**261 是「带危象语义的候」，不是「危候发生率」，也不是「危候总数」。** 分子分母都只在本库的候级清单内成立；换成别家的辞典，两个数都不成立。同理，80 与 181 之间那 42 条交集不能重复计入，261 已经在生成时去重。

分母也要说清：本层取 **1864**，是候级清单的条数；`结构.json` 里的 **1866** 是候实例数，两者不是同一口径，不得互相换算。差的那两条不进清单，是因为它们没有可拆的候级正文字段——不是被筛掉，也不是判成不危。凡是把 261 直接除以 1866 得出占比的写法，都同时踩了两个口径的错，本层不这么做。

## 三、复核：80 条逐条回原页

**80 条已逐条回原页核过**（`危候判据-复核.json`，`scripts/verify_weihou_pages.py`）：

| 项 | 结果 |
|---|---|
| 候名在印张页的 OCR 原文命中 | **80 / 80** |
| 另有治则用语同页或后两页佐证的「双证」 | **42** |
| 依据只有候名的「仅名」（本就没有治则线索，不算缺陷） | **38** |
| 未命中 / 仅治法 | **0** |
| 按册分布 | 上 22 · 中 24 · 下 34 |
| 目录页可交叉核（上册书签页可用） | 22 条，**全部对齐**（偏差 0） |

42 与 38 相加正是 80：双证的和仅名的，各占一半略强与略弱。这个分解比「80/80 全中」更有信息量——它告诉你证据强度是分层的。

复核的口径三条，缺一条这次核就白做：**其一，「命中」指候名连写在原页 OCR 中出现**，允许换行处断开，不允许只对上前两字；**其二，「双证」的窗口是同页或后两页**，再往后就不算佐证，因为中间已换候；**其三，「仅名」不降级**——那些候在原书里本就没有治则句，仅名即是它们能达到的最高证据等级，记成「待补」反而是错的。

中、下两册的目录书签目标页在扫描件里已失效（`PDF登记.json` 记着），所以那 58 条只能核「候名在印张页」，不能核「目录页 ↔ 正文页」。**这一条限制必须说出口，不能拿 80/80 当成「全链核过」**：能核的是「这个候名确实出现在原书这一页」，不能核的是「这一页正是目录指向的那一页」。

## 四、记录字段与失效模式

**记录字段六项**：

| 字段 | 填法 | 反例 |
|---|---|---|
| 候码 | 四级码，唯一 | 只写候名 |
| 命中路径 | 名／法／双 | 只写「命中」 |
| 档位 | 厥脱／脱绝／陷逆，唯一 | 两档并记 |
| 依据字 | 逐字引出 | 写「语义相近」 |
| 原页 | 印张＋册 | 只写册 |
| 复核状态 | 双证／仅名／待核 | 一律写「已核」 |

**五种失效模式**，每一种都能在上面的分流里指到位置：

1. **同形异义。** 「经脉闭塞」是病机描述，不是危象；字面带「闭」的一律保留依据、交人工核，不直接入档。
2. **治法词泛化。** 「清热解毒」「活血化瘀」在普通候的治则里也常见；只命中治法的一律停在候选。
3. **候名裁短。** 单字「厥」可能指厥证（手足厥冷的一类证）而非厥脱；单字不入档，须有组合词。
4. **跨页截断。** 治则与候名分属两页时，单页核会判「未命中」；本层允许「同页或后两页」，但要在记录里写明跨页。
5. **目录书签失效。** 中、下两册的目录页对不上，58 条只能核候名；把它记成「全链已核」是最容易犯的一处虚报。

还有两条不许做的动作：**不许用词面判据替代临床判断**（病人危不危要看四诊与生命体征），**不许把「逆」读成恶化**（逆传是走向判断，不是程度判断；里邪出表也可能伴危象）。

**清单的三条维护纪律**：其一，**删条要写理由**，理由须指向原页或另一条判据，不许写「感觉不像」；其二，**改档要留旧档**，档位变更记「前档→后档」与依据字，一次改档不能抹掉原来的判定；其三，**新增条目必须带依据字**，没有依据字的条目不进清单——这三条不是流程洁癖，而是让 261 这个数在任何时点都能被重建。缺一条，清单就只成了一份意见。

## 五、代价与边界

本层不做生死判断、不给处置时限、不给急救流程；急诊处置按机构规范。危候清单仅供检索与教学复核，删条必须写理由。

写厚这一章的代价写在这里：概论只有 2.7 万字，它是**总论**，讲的是规则不是病例；把它当全部证候学来学，会得到一套干净但干旱的框架。所以每章的实测表都把读者指回辞典正文层（1866 条候的原书释义）——**规则在概论，材料在辞典，两者不能互相替代**。

边界还有一层：**80 条是「名字里有危象」的下界，不是「临床上会危」的上界。** 一条候没进清单，不等于它不危险——可能是名字写得克制，也可能是治则句被 OCR 截断。清单的用法是「提示去看」，不是「保证不漏」。同理，261 这个数只在本库口径内可复算；离开这份候级清单，它只是三个数字的加法，不是一条可引用的结论。
