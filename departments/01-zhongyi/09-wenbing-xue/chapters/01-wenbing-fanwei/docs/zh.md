# 第 1 章 · 温病不是「另一类伤寒」，是一套换了入口的病

> **MOTTO:** 「凡病温者，始于上焦，在手太隂。」——《温病条辨·上焦篇》第二条（外源·笈成·溫病條辨 上焦篇·第二条）
>
> **PROBLEM:** 教材把温病讲成一串病名：风温、温热、温疫、温毒、暑温、湿温、秋燥、冬温、温疟。学生背得下九个名字，却答不出「温病与伤寒差的到底是哪一步」。差的不是病名，是**入口与方向**：寒邪从毛窍入、自下而上、始足太阳；温邪从口鼻入、自上而下、始手太阴。病名可以背，坐标不能背——它决定第一张方子开桂枝汤还是银翘散。
>
> **双根因定位:** 环境逼迫（温病学在本仓库没有教材底本，唯一可引的是外源三书；不复算就只剩背病名）+ 知识积累（三书 630 条 × 原病篇 19 条引文溯源 = 知道「九种」这份名单在篇内怎么落地，也知道哪些标题其实不在名单里）

## 核心概念

### 一、原病篇 19 条：先把《内经》拆成可回查的 19 条

《温病条辨·原病篇》不写治法，只做一件事：把《内经》里跟温病有关的句子逐条摘出，再加自注。19 条里 **14 条明标篇名，5 条承上条而无篇名，共 13 个不同篇名**（《热论篇》重出两次）：

| 条 | 所引篇名 | 条 | 所引篇名 |
|---|---|---|---|
| 一 | 六元正纪大论 | 十一–十五 | （承上《刺热篇》，无篇名） |
| 二 | 隂阳应象大论 | 十六 | 热论篇（重出） |
| 三 | 金匮真言论 | 十七 | 刺法论 |
| 四 | 热论篇 | 十八 | 玉板论要 |
| 五 | 刺志论 | 十九 | 平人气象论 |
| 六 | 生气通天论 | | |
| 七 | 论疾诊尺篇 | | |
| 八 | 热病篇 | | |
| 九 | 评热病论 | | |
| 十 | 刺热篇 | | |

两个最常被引的源头都在这里。第二条：「《隂阳应象大论》曰：喜怒不节，寒暑过度，生乃不固。故重隂必阳，重阳必隂，故曰：冬伤于寒，春必病温。」第三条：「《金匮真言论》曰：夫精者身之本也，故藏于精者，春不病温。」——一条讲**邪从外来**，一条讲**正能拒邪**，吴鞠通把这两句并置，是要说明温病的发生既看时气，也看人本身藏不藏精。第四条则直接切开温与暑：「凡病伤寒而成温者，先夏至日者为病温；后夏至日者为病暑，暑当与汗出，勿止。」

这一篇的工程价值不在义理，在**结构**：19 条 = 19 个可核对的引文槽位。任何人说「《内经》说温病如何」，都能落回某一号，不必凭记忆。

### 二、九种温病：名单是原文给的，篇内分布不是

「九种」出自上焦篇第一条：「温病者：有风温、有温热、有温疫、有温毒、有暑温、有湿温、有秋燥、有冬温、有温疟。」数一遍是 9 个，但**背书上的九个名字与看篇目结构是两件事**。上焦篇实际只有 7 节，标题覆盖这 9 种的方式极不均匀：

| 节标题 | 条 | 方 |
|---|--:|--:|
| 风温、温热、温疫、温毒、冬温 | 21（一–二一） | 24 |
| 暑温 | 13（二二–三四） | 12 |
| 伏暑 | 8（三五–四二） | 5 |
| 湿温、寒湿 | 7（四三–四九） | 8 |
| 温疟 | 4（五十–五三） | 5 |
| 秋燥 | 5（五四–五八） | 5 |
| 补秋燥胜气论 | 22（条号自「一」重起） | 6 |

首节一节担了五种（风温、温热、温疫、温毒、冬温），共 21 条 24 方，占上焦篇 80 条的 26%、65 方的 37%。反过来，**标题里有、九种名单里没有**的病名有三个：伏暑、寒湿、补秋燥胜气论。伏暑 8 条 5 方，是一个成型的小节；寒湿与湿温合节；补秋燥胜气论 22 条自成一篇。

所以「九种」是大纲，不是分类学。上焦篇 80 条 65 方是实际展开，两者的差集就是教材最容易漏掉的地方：**背九个名字的人，永远找不到伏暑**。

### 三、寒与温：四个维度，一句话定死

上焦篇第二条正文只有 12 个字，边界全在自注里：

> 「伤寒由毛窍而入，自下而上。始足太阳。」「温病由口鼻而入，自上而下，鼻通于肺，始手太隂。」（外源·笈成·溫病條辨 上焦篇·第二条）

拆成四维，两侧对称得近乎刻意：

| 维度 | 伤寒 | 温病 |
|---|---|---|
| 入口 | 毛窍 | 口鼻 |
| 方向 | 自下而上 | 自上而下 |
| 首犯 | 足太阳（膀胱，寒水之腑） | 手太阴（肺，鼻通于肺） |
| 治法 | 仲景六经次传为祖法 | 河间三焦定论 |

吴鞠通给「为什么是太阳/太阴」的理由是**同气相求**：太阳膀胱属水，寒即水之气，故寒先犯太阳；太阴属金，温为火之气，火克金，故温先犯太阴。这套解释可争论，但它的**可操作性**不容置疑——入口与方向一确定，「首犯何经」就不再靠猜，而是从邪的性质推出来。

边界到此为止也就够了。它不回答「温病有几个阶段」（那是第 2、3 章），只回答「第一步落在哪」。

### 四、吴鞠通的批评：三个人，三种偏

原病篇第二条自注把「以伤寒法治温病」这条线索摊开，先点名一长串宋元名家：

> 「如庞安常之《卒病论》，朱肱之《活人书》，韩祇和之《微旨》，王实之《证治》，刘守真之《伤寒医鉴》、《伤寒直格》，张子和之《伤寒心镜》等书，非以治伤寒之法治温病，即将温暑认作伤寒」（外源·笈成·溫病條辨 原病篇·第二条）

然后集中处理三家，且各给一个不同的错法（王叔和一条在上焦篇第一条自注，吴、喻两家在原病篇第二条自注）：

| 对象 | 错在哪 | 原文 |
|---|---|---|
| 王叔和 | 有证无治法，混编入《伤寒例》 | 「但叔和不能别立治法，而叙于《伤寒例》中，实属蒙混」（上焦篇·第一条自注） |
| 吴又可 | 认得寒温二字，却不认伏气 | 「实能识得寒温二字……又不明伏气为病之理」（原病篇·第二条自注） |
| 喻嘉言 | 立了治法，却仍在伤寒圈内 | 「虽有分析，中篇亦混入伤寒少隂、厥隂证，出方亦不能外辛温发表、辛热温里，为害实甚」（原病篇·第二条自注） |

在條辨全书自注里，这几个名字的出现频次是：叔和 8 次、又可 19 次、嘉言 5 次、喻氏 14 次、景岳 5 次。又可被提得最多，不是因为他错得最多，而是因为他是**唯一被部分肯定**的对手——反对一个说得清的人，比反对一个说不清的人更费力。

第五条的短注最见态度：「此伤寒暑之辨也。经语分明如此，奈何世人悉以治寒法治温暑哉！」一句话把「经已说明，是人没读」的判断讲完。这一章读到这里，才明白吴鞠通写原病篇的用意：**先把责任推回文本**，再谈自己的三焦。

### 五、首四条，是一份判定流程

上焦篇前四条不是四个知识点，是四步：

1. **第一条｜列名单**：九种温病，先把「温病」这个词的外延钉住。
2. **第二条｜定坐标**：「凡病温者，始于上焦，在手太隂。」——一切温病共用的起点。
3. **第三条｜给脉证**：「太隂之为病，脉不缓不紧而动数，或两寸独大，尺肤热，头痛，微恶风寒，身热自汗，口渴，或不渴，而咳，午后热甚者，名曰温病。」注意这里的辨法：**不缓不紧**排除太阳中风与伤寒，**动数**、**两寸独大**、**尺肤热**、**午后热甚**四点把温病从「像伤寒」里挑出来。
4. **第四条｜分流**：「太隂风温、温热、温疫、冬温，初起恶风寒者，桂枝汤主之；但热不恶寒而渴者，辛凉平剂银翘散主之。温毒、暑温、湿温、温疟，不在此例。」一条之内两方，判据只有一个：**恶不恶风寒**。

第四条是全章的技术核心：它不是「温病用银翘散」，而是「温病初起仍可能恶风寒，此时用桂枝汤」。吴鞠通在自注里把话说明白了——「既恶风寒，明是温自内发，风寒从外搏，成内热外寒之证，故仍旧用桂枝辛温解肌法」。**边界不是靠病名划的，是靠当下这一层的证划的。**

三个设计决定，都是「不这样写就会骗自己」：

- **名单不手抄。** `jiuZhong()` 用 `/温病者[：:]([^。]+)。/` 从第一条原文现切。手抄一份常量，早晚与原文分家，而分家时没有任何报错。

- **引文定位失败要炸。** `boundary()` 用正则从第二条自注里抓那两句，抓不到就 `throw`。原文一改字，本章立刻失败——而不是继续输出一句已经不在底本里的话。

## 代价与边界

- **外源不是校勘本。** 引文只保证「等于笈成留档页面的字」，不宣称等于任何刻本原文。要作校本须另立校勘工程。
- **简体栏保留异体「隂」。** `底本.json` 的 `zhHans` 逐字转换，未把「隂」归并为「阴」。本章引文照抄，所以正文出现「太隂」而非「太阴」——这是照抄的痕迹，不是错字。要做正字规范，应另立一层，不能改引文。
- **条号非通行体系，且篇内不唯一。** 凡例 14 条全标「一」；补秋燥胜气论 22 条只有 8 个号码（条号自「一」重起）。**引用必须带篇名**，只写「第N条」在條辨里指不到唯一一条。
- **「九种」不是完备分类。** 它是上焦篇首条给的大纲；篇内实有伏暑、寒湿、补秋燥胜气论三个不在名单内的标题。凡说「温病分九种」，须补一句「大纲九种，篇内另有展开」。
- **243 方只是條辨一家。** 《溫熱論》37 条、《溫疫論》303 段一方不载。不能据 243 当温病学方剂总量，也不能据本章做方剂统计。
- **原病篇只标篇名，不标书名。** 19 条引文里没有一条写明出自《素问》还是《灵枢》，因此本章不做经书归属判断，也不据以校勘。
- **不能据本章处方。** 桂枝汤与银翘散的剂量、煎服法、禁忌须回原文与药典，由执业医师判断。

## 练习

1. 上焦篇首节一节担五种温病、24 方，占全篇方的 37%。这个密度说明吴鞠通把什么当「主战场」？
2. 第四条同条给两方，判据只有「恶不恶风寒」。为什么这条判据比「病名」更可靠？用第三条的脉证说明。

## 进阶思考

把「入口—方向—首犯—治法」四维写成表，是本章唯一真正可迁移的东西。它不依赖任何一家注家的解释，只依赖两条原文里的八个短句；而只要这四维成立，「温病该不该用桂枝汤」这种争论就会自动降级为一个更小的问题：**此刻这一层，恶不恶风寒**。温病学的其余九章，都是在这个坐标上继续切分。
