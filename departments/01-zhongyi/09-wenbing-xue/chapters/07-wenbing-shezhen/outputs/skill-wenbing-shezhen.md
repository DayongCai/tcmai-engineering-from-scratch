# wenbing-shezhen

## 何时使用

- 要从温病条文中抽舌象并按苔色/苔质/舌体归类
- 要判斑与疹，或读「出后转归」
- 要读条文里的预后档位（可治/难治/凶/死）

## 数据来源

`standards/wenbing/底本.json`（溫熱論 37 条 + 溫病條辨 290 条）；
复算：`python scripts/build_wenbing_text.py --check`；统计：`node code/main.js`。

## 硬约束

1. **词表固定 27 词**（苔色 6 / 苔质 11 / 舌体 10）；词表外一律「词表外」，不新增。
2. 只认字面：不把「舌淡」并入「舌色淡」；繁简已归一（乾/干），但不做同义归并。
3. 斑疹六维：形态 / 所属 / 色与脏腑 / 多少 / 兼见 / 出后转归；缺维不填。
4. 「斑属血者恒多、疹属气者不少」是概率判断，**不得反推**。
5. 预后四档只认：可治 / 难治 / 凶 / 死；命中必须给句内证据。

## 不适用

- 处方、剂量、煎服法
- 用舌象单独定病或判断温病整体预后（样本是带预后词的条文，不是全库）
