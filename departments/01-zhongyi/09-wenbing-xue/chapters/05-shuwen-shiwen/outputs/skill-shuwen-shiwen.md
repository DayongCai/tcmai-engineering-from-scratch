# shuwen-shiwen

## 何时使用

- 判一条暑季条文偏暑温还是偏湿温
- 需要给出可核验的症状词出现率对比（而不是「凭感觉像」）
- 遇到「湿温口渴用甘寒」这类治法错位时要指出来

## 数据来源

`standards/wenbing/底本.json`（暑温/伏暑/湿温/寒湿九篇 132 条）；
复算：`python scripts/build_wenbing_text.py --check`；统计：`node code/main.js`。

## 硬约束

1. 先病名、再症状词；**季节不是判据**（32 条暑温里只有 1 条提「长夏」）。
2. 口渴差值是最硬的判据：暑 43.8% vs 湿 3%；面赤湿温 0 条。
3. 湿温必须点三禁：汗之则神昏耳聋 · 下之则洞泄 · 润之则病深不解。
4. 三焦落点要报：中焦 62 条里 57 条属湿，湿温重心在脾胃。
5. 条号漢数字、每篇重起 → 引用带篇名，标「外源·笈成」。

## 已核事实

| 项 | 值 |
|---|---|
| 九篇 | 132 条 · 135 方（109 + 26 互见） |
| 暑 / 湿 | 32 条 / 100 条 |
| 三焦 | 上焦 28 · 中焦 62 · 下焦 42 |
| 中焦湿占比 | 57/62 |
| 口渴 | 暑 43.8% · 湿 3% |
| 面赤 | 暑 ≥4 条 · 湿 0 条 |
| 治法组 | 清气泄热 9 · 疏表透邪 6 · 益气养阴 4（另有 2 组） |

## 不适用

- 处方、剂量、煎服法
- 用现代气候经验改写原书的时间轴
