# 咳与喘在书上分两节，在病人身上常是一件事的两头

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 第一问：咳与喘，谁为主
- 第二问：痰的色、质、量
- 第三问：有无报警征象
- 可观察学习目标
- 两套入口，先定一个
- 上报；首次评估

## 边界

- 本章不给方药剂量与疗程，不给雾化或吸入药物的具体方案；所有治疗以带教医师与所在机构制度为准。
- 「按痰分」「按虚实分」是教学上的入口归并，不是教材原文的分类学。两套表在临床会交叉，交叉处的取舍应写明理由，而不是强行二选一。
- 报警征象只列方向（咯血、消瘦、声嘶、固定部位胸痛），不含任何量化阈值；是否转诊由接诊医师结合机构流程决定。
- 本章为教学整理，不构成诊疗建议。轮转期间的任何临床处置，须在有资质医师指导下进行。
