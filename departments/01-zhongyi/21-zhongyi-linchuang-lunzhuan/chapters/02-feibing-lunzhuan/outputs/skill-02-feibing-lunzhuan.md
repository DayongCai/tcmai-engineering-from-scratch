# 咳喘哮三分 · 可装载技能

## 何时装载

- 需要先分病，再分证，再报方；
- 轮转交接、出科考核、病例复盘；
- 复核场景：检查一份轮转要求是否报了病数、动作数、代表方与数值判据。

## 步骤

1. **分病** —— 有痰无声／有声无痰／喉中痰鸣
2. **查跨科** —— 该病在儿科、急诊、老年科的侧重
3. **分证** —— 外感与内伤两条入口
4. **报方** —— 代表方与是否合方

## 输出格式

① 病名；② 三病分界；③ 证型与方；④ 跨科定义差。

## 边界

- 病名只取教材的「节」；教材未给的数值不补；
- 缺口（如脾胃科数值 0、脑病科证候库 0）须显式写出，不隐藏；
- **免责声明：** 本技能为教学用，不构成诊疗建议。
