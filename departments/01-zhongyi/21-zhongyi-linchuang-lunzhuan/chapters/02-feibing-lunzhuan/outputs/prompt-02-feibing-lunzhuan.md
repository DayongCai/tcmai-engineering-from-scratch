# 咳喘哮三分

## 用途

**肺病科最容易见咳止咳。** 先用三个问题把咳、喘、哮分开，再谈证与方。

本单只做一件事：把轮转要求写成可对账的表——病名来自教材的「节」，动作来自教材的 5 个小节，考核证据来自「辨证论治」小节与代表方。写不出数字的地方，写「无」。

## 步骤

### 1. 分病

有痰无声／有声无痰／喉中痰鸣

### 2. 查跨科

该病在儿科、急诊、老年科的侧重

### 3. 分证

外感与内伤两条入口

### 4. 报方

代表方与是否合方

## 判据速查

| 项 | 数字 |
|---|---|
| 五科病数 | 38（心病 9／肺病 8／脾胃 9／肾病 6／脑病 6） |
| 必做动作 | 190 项（每病 5 小节） |
| 辨证论治小节 | 37 个 |
| 代表方（去重） | 179 首 |
| 证候库同名证 | 17 个 |
| 数值判据 | 12 处（脾胃 0、脑病 2） |
| 跨科病 | 23 个 |

## 输出

① 病名；② 三病分界；③ 证型与方；④ 跨科定义差。

## 边界

- 数字一律由 `code/main.js` 读 `standards/lunzhuan/` 现算，不手写；
- 病名一篇不增不删；教材未给的数值不补；
