# 第 2 章 · 咳与喘在书上分两节，在病人身上常是一件事的两头

> **MOTTO:** 「五脏六腑皆令人咳，非独肺也。」——《素问·咳论》
>
> **PROBLEM:** 肺病科病单 8 病、必做动作 40 项，轮转学时 18，一病五项动作、两个学时略多。可门诊里同一个病人，上午被写成「咳嗽」，下午被写成「喘证」是常事——两个病名的分界不在症状轻重，而在「动则气促、能否平卧」这一句问不问得到。问不到，两套证型表都要各查一遍，两个学时全耗在来回翻表上。
>
> **双根因定位:** 环境逼迫（呼吸道症状随季节与气温集中，接诊高峰与教学进度不同步，最忙的时候正是最该学的时候）+ 知识积累（咳嗽七证按「痰」分入口，喘证八证按「虚实」分入口，两套表的第一个岔路口不同，混用则辨证必然漂移）

> 本章无参考电子件，不引页码、不引版次、不给剂量与疗程。证型与方名属教学归类，用药以所在机构制度与带教医师意见为准。

## 一、入科三问

肺病科的三问，问的是同一个症状在两条路上的位置。

**第一问：咳与喘，谁为主。** 咳嗽是肺气上逆出声，喘是呼吸困难、气息迫促。判别只用一个动作：让病人走几步、上一层楼，看是否气促加重、是否要停下来。走不动、要停下喘气，主症就是喘，不是咳。

**第二问：痰的色、质、量。** 色分白黄，质分稀稠，量分多少。三样要分开记，不能合成一句「痰多」。色偏黄、质稠、量多，与色白、质稀、量少，指向的证型相反；只记「有痰」，等于什么都没记。

**第三问：有无报警征象。** 咯血、进行性消瘦、声嘶、久治不愈的单侧胸痛，属须转专科排查的情形，不在本科按「咳嗽」继续调治。这一问的作用是把「常见的」与「必须排除的」分开——前者靠辨证，后者靠流程。

**可观察学习目标：**

| # | 目标 | 可观察动作 |
|--:|---|---|
| 1 | 分清咳与喘 | 让病人走几步后，说出主症归属及判断依据 |
| 2 | 痰的三要素 | 接诊记录里色、质、量三项分列，不合并 |
| 3 | 两套入口不混 | 说清咳嗽按痰分、喘证按虚实分的理由 |
| 4 | 报得出证型 | 不查资料说出咳嗽七证、喘证实喘五证与虚喘三证 |
| 5 | 报警征象 | 说出四条须转诊的征象并说明理由 |

## 二、判据：达标与不达标两列【教学设定】

本表为教学分档，不作为质控依据；各机构病历规范高于本表。

**两套入口，先定一个。** 咳嗽按「痰」分入口，喘证按「虚实」分入口——这是本科最容易被忽略的一条结构。下表把两套表并置，用于训练「先选表、再查证」：

| 入口 | 证型 | 主症抓手 | 治法方向 |
|---|---|---|---|
| 咳嗽·痰白稀 | 风寒袭肺 | 咳声重浊、痰白稀、鼻塞流清涕 | 疏风散寒、宣肺止咳 |
| 咳嗽·痰黄稠 | 风热犯肺 | 咳痰黄稠、咽痛、口渴 | 疏风清热、宣肺止咳 |
| 咳嗽·痰少难咯 | 风燥伤肺 | 干咳连声、喉痒、痰黏成丝 | 疏风清肺、润燥止咳 |
| 咳嗽·痰多易咯 | 痰湿蕴肺 | 痰多色白、晨起为甚、胸闷脘痞 | 燥湿化痰、理气止咳 |
| 咳嗽·痰黄量多 | 痰热郁肺 | 痰黄稠厚、面赤、苔黄腻 | 清热肃肺、豁痰止咳 |
| 咳嗽·随情绪而发 | 肝火犯肺 | 咳时面赤、胁痛、症状随情绪起伏 | 清肺泻肝、顺气降火 |
| 咳嗽·久咳痰少 | 肺阴亏耗 | 干咳少痰、午后潮热、舌红少苔 | 滋阴润肺、化痰止咳 |
| 喘·实 | 风寒壅肺 | 喘息气粗、遇冷即发、痰白 | 宣肺散寒 |
| 喘·实 | 表寒肺热 | 喘而烦闷、痰黄、恶寒发热并见 | 解表清里、化痰平喘 |
| 喘·实 | 痰热郁肺 | 喘咳气涌、痰黄稠、胸中烦热 | 清热化痰、宣肺平喘 |
| 喘·实 | 痰浊阻肺 | 喘而胸满、痰多黏腻、苔白厚 | 祛痰降逆、宣肺平喘 |
| 喘·实 | 肺气郁痹 | 每因情志而发、咽中如窒、息促 | 开郁降气平喘 |
| 喘·虚 | 肺气虚耗 | 喘促短气、声低、自汗畏风 | 补肺益气 |
| 喘·虚 | 肾虚不纳 | 动则喘甚、腰膝酸软、呼多吸少 | 补肾纳气 |
| 喘·虚 | 正虚喘脱 | 喘逆加剧、汗出肢冷、脉浮大无根 | 扶阳固脱、镇摄元气 |

十五行里，前七行走「痰」，后八行走「虚实」。训练方式：给一段主诉，先要求说出「用哪张表」，再说证型。选错表，后面全错。

| 环节 | 达标 | 不达标 |
|---|---|---|
| 起病与病程 | 写明起病急缓、持续久暂、有无季节性反复 | 只写「咳嗽多日」 |
| 痰 | 色、质、量、是否易咯四项分记 | 一句「痰多色白」带过 |
| 喘的判定 | 写明活动后气促程度、能否平卧、夜间是否憋醒 | 把「气短」与「喘」混用 |
| 听诊 | 记录呼吸音、有无干湿啰音及部位 | 只写「双肺呼吸音清」而不听 |
| 辨证 | 病名＋证型，标明入口（按痰／按虚实） | 咳嗽套喘证表，或反之 |
| 治法 | 一句话，与证型同向（如「疏风清肺、润燥止咳」） | 治法写成「止咳化痰」这类对症词 |
| 交代 | 复诊指征、加重信号、转诊方向 | 只说「按时吃药」 |

「喘的判定」这一行是本科最容易失分的地方。把「气短」写成「喘」，会把一个虚证写成实证；把「喘」写成「气短」，会把一个需要即刻处理的状态留在门诊。

## 三、交接四段与时限

| 段 | 写什么 | 时限 |
|---|---|---|
| 现状 | 呼吸频率趋势、痰量与痰色变化、能否平卧、本班内加重或缓解 | 交班前完成书面 |
| 背景 | 吸烟史、职业粉尘接触、既往喘病史与类似发作、在吸药物名称 | 入科首日补齐 |
| 评估 | 病名＋证型＋轻重分层（可门诊随访／需留观复评／须即刻处理） | 每班复评一次 |
| 待办 | 复评听诊、影像与检验回报后的处置、转诊方向、已告知内容 | 交班口头过一遍并复述确认 |

时限仍用类别词：出现呼吸困难加重、口唇发绀、不能平卧，**即刻**上报；首次评估**当班内**完成；书面记录**交班前**完成；病情不稳者**每班复评**，稳定者按复诊间隔。呼吸道病人夜间常加重，交接时要把「夜里怎么样」当成一个独立问题问，不并入白天的情况。

一段能用的交接：

> **现状：** 5 床，昨夜咳三次，痰黄稠、量中等，可平卧，未喘；今晨听诊右下肺湿啰音。**背景：** 吸烟多年，既往无喘病史，在吸药物一种。**评估：** 咳嗽，痰热郁肺；分层为需复评。**待办：** 复评痰色与听诊；若走平路即气促或夜里憋醒，即刻上报；戒烟与复诊指征已交代，病人复述无误。

「未喘」两个字要单独写出来，不能省。它是对第一问的当班复核，也是接班人判断「要不要按喘证重新评估」的唯一依据。

## 四、记录字段

| 字段 | 写法 | 常见错法 |
|---|---|---|
| 主诉 | 咳／喘＋时限＋加重因素 | 「咳嗽咳痰」四个字了事 |
| 现病史 | 起病、演变、诱因（冷空气、异味、活动）、已用处理 | 漏问诱因 |
| 既往与用药 | 吸烟史（有无、年限）、在吸药物名称、过敏史 | 吸烟史写成「偶吸」 |
| 痰 | 色、质、量、易咯与否 | 与咳嗽合并成一句 |
| 听诊 | 呼吸音、啰音性质与部位 | 「未闻及明显异常」照抄 |
| 舌脉 | 舌质舌苔、脉象两位 | 只记脉不记舌 |
| 辨证与治法 | 病名＋证型＋治法，入口写明 | 证型与痰象矛盾 |
| 方 | 方名＋出处＋加减依据 | 只写「止咳方」 |
| 交代 | 复诊指征、加重信号、转诊方向 | 只说「不好再来」 |

第九格在肺病科尤其重要：咳嗽病人最常犯的错是「忍到不能忍才来」。交代里必须有一句可复述的加重信号（如「走平路也气促」「夜里憋醒」），否则复诊时已错过窗口。

本科最常见的记录断裂是「同一个病人、两份记录」：上午门诊写咳嗽，下午急诊写喘证，两份互不提及。判据上这算两次不达标——没有任何一份写清了主症归属与另一症的关系。修正的办法不在事后补写，而在接诊时把「是否有喘」写进现病史第一行。

## 五、失效模式与考核项

1. **只跑不动手。** 跟着查房听了一周肺音，自己一次也没独立听过。听诊是手上的功夫，判据是当班内独立完成听诊并写下部位与性质。
2. **把看当会。** 看带教三句话问出痰的色质，就以为自己也会问。换一个只会说「有痰」的老人，问不出三要素，就是不会。
3. **记流水不记判断。** 记录里写「上午门诊、下午查房、雾化一次」，却没有「痰黄质稠、属痰热郁肺」这样的判断。流水越多，越显得没看见。
4. **以痰色定寒热。** 只看黄白就下寒热结论，不问质地与易咯程度。黄而稀与黄而稠不是一回事，前者未必是热。
5. **喘证不分虚实。** 见喘即平喘，不问动则气促还是静息亦喘。虚喘用攻法，是本科最需要防的方向性错误。
6. **把并见当两病。** 咳喘并见时分成两份记录，一份治咳、一份治喘，两套治法互相牵制。并见应写在一份记录里，主症在前，兼症随后。

**考核项：**

| # | 考核项 | 形式 | 通过判据 |
|--:|---|---|---|
| 1 | 咳喘分界 | 口试，给两段主诉 | 两段均判对，各给一条依据 |
| 2 | 痰三要素 | 床边接诊 | 记录中色质量分列，无合并 |
| 3 | 证型复述 | 闭卷口述 | 咳嗽七证、喘证八证名称无误 |
| 4 | 独立接诊 | 带教旁观 | 九字段齐全，入口标注正确 |
| 5 | 转诊判断 | 病例讨论 | 四条报警征象说清，并给出处置方向 |

第 1、4 两项权重最高：第 1 项考的是入口选择，第 4 项考的是能不能独立完成一次接诊。入口选错，证型背得再熟，也只是把错答案说得更流利。
