# 第 3 章 · 胃痞与泄泻同属脾胃，升降反作时只能先救一头

> **MOTTO:** 「清气在下，则生飧泄；浊气在上，则生䐜胀。」——《素问·阴阳应象大论》
>
> **PROBLEM:** 脾胃病科病单 9 病、必做动作 45 项，轮转学时 18。胃痞与泄泻是一对：一个气滞于上，一个气陷于下，教材各占一节。可门诊里「上痞下泄」并见的病人极多，同一份病历里两个病名同时成立；18 学时辨 9 病，逐个背证型一定来不及——得先抓住「升降」这一根轴。
>
> **双根因定位:** 环境逼迫（脾胃病主诉琐碎、复诊密集，问诊窗口被切得很碎，很少有整段的问诊时间）+ 知识积累（胃痞六证按虚实两组、泄泻六证按暴久两组，两组的判别点都落在「食与便的关系」这一层，不问这一层，两套证型表都挂不上）

> 本章无参考电子件，不引页码、不引版次、不给剂量与疗程。证型与方名属教学归类，用药以所在机构制度与带教医师意见为准。

## 一、入科三问

**第一问：主症在上还是在下。** 痞、胀、嗳气、恶心呕吐，在上；便次增多、便质稀溏、腹痛即泻，在下。两者并见时要追问哪个先起：先痞后泄，多从气滞起而及脾运；先泄后痞，多从脾虚起而致气滞。先后顺序不同，治法的主次就不同。

**第二问：食与便是什么关系。** 这一问是本科的分水岭。食后胀甚、嗳腐厌食，是食滞；空腹亦胀、得食稍安，是虚痞；食后即泻、完谷不化，是脾不运化；情绪紧张即泻、泻后痛减，是肝气乘脾。四种关系对应四个方向，问不出来就只能在虚实之间猜。

**第三问：有无报警征象。** 进行性消瘦、便血或黑便、吞咽不利、持续呕吐不能进食，属须转专科排查的情形，不在本科按「胃痞」「泄泻」继续调治。这一问不是辨证，是划界。

**三问的顺序不能颠倒。** 先定上下（主症在哪个方向），再定食便关系（虚实与脏腑），最后划界（能不能留在本科）。颠倒过来的常见后果是：一上来就辨寒热，把虚痞当食滞攻下，泻得更重。

**痞与泄并见时，先救一头。** 上痞下泄同时成立，治法不能平摊：痞甚而食入即胀者，先理气消痞；泄甚而一日数次者，先健脾止泻；待一头缓解，再议另一头。平摊的后果是两边的药互相抵消——理气药多则泄更甚，收涩药多则痞更满。带教时要问一句「今天哪个更难受」，这一句就是主次的依据，也是治法先后的依据。

**可观察学习目标：**

| # | 目标 | 可观察动作 |
|--:|---|---|
| 1 | 定上下 | 听一段主诉，说出主症在上、在下或并见，并说出先后 |
| 2 | 问食便 | 用不超过三个问题问出「食与便的关系」属于哪一类 |
| 3 | 报得出证型 | 不查资料说出胃痞六证、泄泻六证 |
| 4 | 分得清痞与痛 | 说清「按之柔软」与「拒按」的区别及其意义 |
| 5 | 写得成记录 | 独立完成一份九字段接诊记录，饮食与排便史分列 |

## 二、判据：达标与不达标两列【教学设定】

本表为教学分档，不替代所在机构的病历规范与质控要求。

**先把十二个证型挂到抓手上。** 胃痞按虚实两组、泄泻按暴久两组，每一证都要有一条能反推回来的主症：

| 病 | 证型 | 主症抓手 | 治法方向 |
|---|---|---|---|
| 胃痞 | 饮食内停 | 脘腹痞满、嗳腐吞酸、厌食、苔厚腻 | 消食和胃 |
| 胃痞 | 痰湿中阻 | 痞满而身重、口黏、苔白厚腻 | 除湿化痰、理气宽中 |
| 胃痞 | 湿热阻胃 | 痞满、口苦口黏、苔黄腻 | 清热化湿、和胃消痞 |
| 胃痞 | 肝胃不和 | 痞满连及两胁、嗳气频、随情绪起伏 | 疏肝解郁、和胃消痞 |
| 胃痞 | 脾胃虚弱 | 痞满时减、喜按、食少便溏 | 补气健脾、升清降浊 |
| 胃痞 | 胃阴不足 | 痞满而饥不欲食、舌红少津 | 养阴益胃、调中消痞 |
| 泄泻 | 寒湿内盛 | 泻下清稀、腹痛肠鸣、苔白腻 | 芳香化湿、解表散寒 |
| 泄泻 | 湿热伤中 | 泻下急迫、色黄褐、肛门灼热 | 清热利湿、分利止泻 |
| 泄泻 | 食滞肠胃 | 泻下臭如败卵、嗳腐、泻后痛减 | 消食导滞 |
| 泄泻 | 脾胃虚弱 | 大便时溏时泻、食后即泻、面黄乏力 | 健脾益气、化湿止泻 |
| 泄泻 | 肾阳虚衰 | 黎明前泻、完谷不化、腰膝酸冷 | 温肾健脾、固涩止泻 |
| 泄泻 | 肝气乘脾 | 情绪紧张即泻、胸胁胀闷、泻后痛不减 | 抑肝扶脾 |

十二行里，「脾胃虚弱」在两张表中都出现，抓手不同：作痞时看「喜按、痞满时减」，作泻时看「食后即泻、时溏时泻」。同一个证名在两病中的落点不同，这正是本章要练的回头路。

| 环节 | 达标 | 不达标 |
|---|---|---|
| 问诊 | 饮食、排便、体重三项都问到；排便问次数、性状、与进食的关系 | 只记「胃不舒服」「拉肚子」 |
| 腹诊 | 写明部位、喜按或拒按、有无痞块 | 只写「腹软」 |
| 舌脉 | 舌质舌苔分记，脉象两位（如濡缓、弦细） | 一律「舌淡苔白」 |
| 辨证 | 病名＋证型，指出抓手（一条主症或一个食便关系） | 只给病名，或证型与抓手矛盾 |
| 治法 | 一句话，与证型同向 | 治法写成「健脾和胃」万能句 |
| 选方 | 方名＋出处＋加减依据 | 只写「中药调理」 |
| 交代 | 饮食宜忌、复诊指征、报警信号 | 只说「注意饮食」 |

「治法」一行最容易滑过去：「健脾和胃」四个字在十二个证型里几乎都能套，套得住就等于没辨。达标要求是治法能反推出证型——写「温肾健脾、固涩止泻」的人，一定辨到了肾阳虚衰。

## 三、交接四段与时限

| 段 | 写什么 | 时限 |
|---|---|---|
| 现状 | 本班进食量、排便次数与性状、腹痛与腹胀变化 | 交班前完成书面 |
| 背景 | 饮食偏嗜、既往胃肠病史与检查、在服药物名称、体重变化 | 入科首日补齐 |
| 评估 | 病名＋证型＋分层（可门诊调治／需留观复评／须转专科） | 每班复评一次 |
| 待办 | 复评腹部体征、待回报的检查、饮食交代内容、转诊方向 | 交班口头过一遍并复述 |

时限用类别词：出现便血、持续呕吐、明显脱水征象，**即刻**上报；首次评估**当班内**完成；书面记录**交班前**完成；腹泻病人**每班复评**排便次数与性状，稳定者按复诊间隔。脾胃病的变化常以「次数」与「性状」体现，交接时要把这两个数报出来，不能只说「好一些」。

一段能用的交接：

> **现状：** 12 床，今晨至今排便四次，稀水样，腹痛泻后减，进食半量，无发热。**背景：** 慢性胃炎史，近日进食生冷，在服药物两种。**评估：** 泄泻，寒湿内盛为主，兼脾虚；分层为需复评。**待办：** 夜班复评排便次数与性状；若出现便血或呕吐不止，即刻上报并转专科；饮食已交代忌生冷，病人复述无误。

## 四、记录字段

| 字段 | 写法 | 常见错法 |
|---|---|---|
| 主诉 | 部位或症状＋时限 | 「胃肠不好多年」 |
| 饮食与排便史 | 进食情况、排便次数、性状、与进食的关系 | 只写「大便不成形」 |
| 腹诊 | 部位、喜按拒按、有无痞块、肠鸣 | 缺腹诊一项 |
| 舌脉 | 舌质舌苔、脉象两位 | 舌脉合并成一句 |
| 辨证 | 病名＋证型＋抓手 | 证型与抓手不符 |
| 治法 | 一句话，可反推证型 | 万能治法 |
| 方 | 方名＋出处＋加减依据 | 只写「随症加减」 |
| 交代 | 饮食宜忌、复诊指征、报警信号 | 「注意饮食」四个字 |
| 体重与报警 | 近期体重变化、有无便血消瘦 | 不问体重 |

第九格在脾胃病科不是可选：消瘦与便血是本科最有价值的两个信号，问不到就等于把需要转诊的病人留在了门诊。记录里要写「已问、无」或「已问、有，见现病史」，不能空着不说。

填一格试写：交代栏写「若出现黑便、呕血、吃不下东西，当日就诊；平时忌生冷、定时进食」——病人能复述才算完成。写「注意饮食」，等于把判断留在了自己心里。

记录写完要能回答一个问题：换一个没参与接诊的医生读这份记录，能不能复述你的判断？答不上来，就还没写完。

## 五、失效模式与考核项

1. **只跑不动手。** 跟着查房听了一周「胃脘不适」，自己没做过一次腹诊。腹诊是手感，判据是当班内独立完成并按部位、喜按拒按写下结论。
2. **把看当会。** 看带教两句话问出食便关系，换一个只答「吃不下」的老人就问不出来。会问的标志是：三个问题之内拿到可用信息。
3. **记流水不记判断。** 记录写「上午查房、下午复诊、调整处方」，却没有一句「痞满喜按、属脾胃虚弱」。流水可以补，判断补不回来。
4. **见泻止泻。** 不问暴久、不辨虚实，一律收涩。暴泻多实，收涩即闭门留寇；久泻多虚，清利则更伤脾阳。
5. **把痞写成痛。** 痞是自觉痞塞不通而按之柔软，痛是拒按。写成「胃痛」会把一个气滞证写成形质病，后面的检查与转诊判断全部跟着错。

**考核项：**

| # | 考核项 | 形式 | 通过判据 |
|--:|---|---|---|
| 1 | 上下与先后 | 口试，给两段主诉 | 两段均判对，说出先后及意义 |
| 2 | 食便关系 | 床边接诊 | 三个问题内问出四类中的一类 |
| 3 | 证型复述 | 闭卷口述 | 胃痞六证、泄泻六证名称无误 |
| 4 | 独立接诊 | 带教旁观 | 九字段齐全，腹诊不缺项 |
| 5 | 转诊判断 | 病例讨论 | 四条报警征象与处置方向说清 |

第 2、4 两项是本科的核心：一个考问得出来，一个考写得下来。两项都过，才说明这套判据被真正用上了。
