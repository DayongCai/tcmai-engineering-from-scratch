# 重叠症状四分

## 用途

**脾胃科症状重叠最重。** 数值判据 0，考核只能问辨证依据。

本单只做一件事：把轮转要求写成可对账的表——病名来自教材的「节」，动作来自教材的 5 个小节，考核证据来自「辨证论治」小节与代表方。写不出数字的地方，写「无」。

## 步骤

### 1. 四分

痛在胃／胀在脘／痛在腹／泻在肠

### 2. 定虚实

虚实夹杂最常见

### 3. 报方

45 首代表方中择一

### 4. 改考核

无量化项时改问辨证依据

## 判据速查

| 项 | 数字 |
|---|---|
| 五科病数 | 38（心病 9／肺病 8／脾胃 9／肾病 6／脑病 6） |
| 必做动作 | 190 项（每病 5 小节） |
| 辨证论治小节 | 37 个 |
| 代表方（去重） | 179 首 |
| 证候库同名证 | 17 个 |
| 数值判据 | 12 处（脾胃 0、脑病 2） |
| 跨科病 | 23 个 |

## 输出

① 病名；② 与相邻病的分界；③ 证型与方；④ 无量化项的考核改法。

## 边界

- 数字一律由 `code/main.js` 读 `standards/lunzhuan/` 现算，不手写；
- 病名一篇不增不删；教材未给的数值不补；
- **免责声明：** 本单为教学整理，不构成诊疗建议；轮转须在有资质医师指导下进行。
