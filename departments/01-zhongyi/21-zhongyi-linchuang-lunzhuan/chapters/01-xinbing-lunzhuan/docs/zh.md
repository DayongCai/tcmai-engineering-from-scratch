# 第 1 章 · 心病科的第一道分水岭是「胸痹」还是「心悸」

> **MOTTO:** 「夫脉当取太过不及，阳微阴弦，即胸痹而痛，所以然者，责其极虚也。」——《金匮要略·胸痹心痛短气病脉证治》
>
> **PROBLEM:** 108 学时均摊到 6 个轮转单元，每科 18 学时；心病科病单 9 病、必做动作 45 项，一病五项动作、两学时。两学时里要跑完问诊、查体、辨证、治法、交代转归五步，靠背九个病名一定来不及——必须先分清「痛」与「悸」两条主干。
>
> **双根因定位:** 环境逼迫（接诊窗口按当班算，不按学时算，病人不会等你学完再来）+ 知识积累（胸痹七证、心悸六证的分证依据要能当场报出，且两病同属心而定位不同：一在脉道，一在心神）

> 本章无参考电子件，不引页码、不引版次、不给剂量与疗程。文中证型与方名属教学归类，实际用药以所在机构制度与带教医师意见为准。

## 一、入科三问

入科第一天不问「你想学什么」，先问三件事，答案决定这五周里你怎么看病人。

**第一问：主诉落在「痛」还是「悸」。** 胸痹以胸膺部闷痛、憋闷、压迫感为主，痛可放射；心悸以心中悸动、不能自主为主，病人常说「心里发空」「跳一下停一下」。两病同属心，但一个辨脉道通不通，一个辨心神安不安。问错这一步，后面的证型表再熟也用不上。

**第二问：并见时谁主谁次。** 「痛而悸」在门诊很常见。要追问一句「今天来，是因为痛得厉害，还是因为心跳得慌」——主病决定先查哪一套证型，兼病只作加减的依据。主次不分，就会出现治法自相矛盾：一边要通，一边要补。

**第三问：本科处理到哪一步。** 胸痛持续不缓解、汗出肢冷、脉微欲绝、动辄气促不能平卧，属必须即刻由院内急诊路径接手的征象，不留在本科观察、不用「先吃点药看看」拖延。这一问的答案要能脱口而出，因为它决定的是时间，不是知识。

**可观察学习目标**（入科首日由带教与学生共同勾选，写在轮转手册首页）：

| # | 目标 | 可观察动作 |
|--:|---|---|
| 1 | 分得清两病 | 拿到主诉，即刻说出「痛」「悸」或「并见」，并给出一条理由 |
| 2 | 报得出证型 | 不查资料说出胸痹七证、心悸六证的名称 |
| 3 | 对得上主症 | 任给一条主症，能反推所属证型并说出鉴别点 |
| 4 | 说得出转诊 | 说清本科三条即刻转诊指征，不加「大概」「可能」 |
| 5 | 写得成记录 | 独立完成一份九字段接诊记录，不经解释即可被他人读懂 |

这五条都是可观察的：能不能说出、能不能反推、能不能写下来，均由带教当场判定，不看自我评价。

**三问的顺序不是随意的。** 先分病，再定主次，最后划边界：分病决定用哪一套证型表，定主次决定加减方向，划边界决定这次接诊在本科结束还是在急诊结束。三步全做完才算一次接诊；只做第一步，那是分诊。

## 二、判据：达标与不达标两列【教学设定】

下表为教学用分档标准，不是行业规范，也不替代所在机构的病历与质控制度。

**先看坐标，再看判据。** 两病的证型不是背下来就完事，要能挂在一条主症上反推回来。下表只给「主症抓手」与治法方向，训练的是从症到证的回头路：

| 病 | 证型 | 主症抓手 | 治法方向 |
|---|---|---|---|
| 胸痹 | 心血瘀阻 | 痛如针刺、痛处固定、入夜尤甚 | 活血化瘀、通脉止痛 |
| 胸痹 | 气滞心胸 | 胀痛走窜、嗳气或情绪诱发 | 疏肝理气、活血通络 |
| 胸痹 | 痰浊闭阻 | 闷重如窒、痰多体胖、苔厚腻 | 通阳泄浊、豁痰宣痹 |
| 胸痹 | 寒凝心脉 | 卒然心痛、遇寒加重、手足不温 | 辛温通阳、开痹散寒 |
| 胸痹 | 气阴两虚 | 隐痛时作、心悸气短、动则汗出 | 益气养阴、活血通脉 |
| 胸痹 | 心肾阴虚 | 隐痛、心烦、腰膝酸软 | 滋阴清火、养心和络 |
| 胸痹 | 心肾阳虚 | 闷痛、畏寒、下肢浮肿、脉沉微 | 温补阳气、振奋心阳 |
| 心悸 | 心虚胆怯 | 善惊易恐、稍惊即发 | 镇惊定志、养心安神 |
| 心悸 | 心血不足 | 心悸而面色无华、倦怠乏力 | 补血养心、益气安神 |
| 心悸 | 阴虚火旺 | 心悸易惊、五心烦热、舌红少津 | 滋阴清火、养心安神 |
| 心悸 | 心阳不振 | 心悸不安、胸闷气短、畏寒肢冷 | 温补心阳、安神定悸 |
| 心悸 | 水饮凌心 | 心悸眩晕、胸脘痞满、下肢浮肿 | 振奋心阳、化气行水 |
| 心悸 | 瘀阻心脉 | 心悸胸闷、痛如针刺、舌紫暗 | 活血化瘀、理气通络 |

十三个证型，训练方式是随机报一条主症，要求在表里反推证型并说出治法方向。推不回去，说明这一证还没记住；推得回却对不上病人的其余表现，说明鉴别点没抓住。

**再看一份接诊的判据。**

| 环节 | 达标 | 不达标 |
|---|---|---|
| 问诊 | 痛：诱因、性质、放射部位、持续时间四要素齐全；悸：发作诱因、持续久暂、伴否黑蒙晕厥 | 只写「胸闷不舒」「心慌」，无诱因、无时限 |
| 舌脉 | 舌质与舌苔分记，脉象至少两位并置（如沉细、弦滑、结代） | 只写「舌淡脉弱」，或照抄上一次记录 |
| 辨证 | 病名与证型同时给出，证型能对上一条主症 | 只给病名不给证型；证型与主症互相矛盾 |
| 治法 | 一句话，与证型同向（如「通阳泄浊、豁痰宣痹」） | 把方名当治法写 |
| 选方 | 方名加出处，说明加减依据 | 只写「中药汤剂调理」 |
| 交代 | 三类信息齐备：复诊指征、危险信号、转诊方向 | 只说「不舒服再来」 |
| 记录 | 判断栏有结论，依据栏有可回查的症舌脉 | 通篇是时间与动作，找不到一句判断 |

七行里只要「辨证」与「记录」两行不达标，这一份接诊就算没完成——其余各行都可以事后补，这两行补不回来。

## 三、交接四段与时限

心病科交接按四段写，缺一段就不算交清。四段的顺序固定：先说现在的状态，再说他的底子，然后给判断，最后交代要做什么。

| 段 | 写什么 | 时限 |
|---|---|---|
| 现状 | 当前主诉、生命体征趋势、本班内的变化（加重、缓解、用药后反应） | 交班前完成书面 |
| 背景 | 既往病、在服药物名称、过敏史、既往同类发作 | 入科首日补齐，其后随诊更新 |
| 评估 | 病名＋证型＋风险分层（可留观／需复评／须即刻转） | 每班复评一次 |
| 待办 | 复评项目、复查时点、转诊方向、已向病人交代的内容 | 交班时口头过一遍，接班者复述确认 |

时限只用类别词，不写具体钟点：危险信号**即刻**上报；首次评估**当班内**完成；书面记录**交班前**完成；再评估**每班一次**，病情变化时随时。把「多久」写成固定分钟数，一旦超出就变成走过场的借口；写成类别词，判据落在「有没有做」上。

一段能用的交接，写在纸上不过十行，四段必须分明：

> **现状：** 3 床，胸痛两次，均在活动后，休息可缓，脉沉细，本班未再汗出。**背景：** 冠心病史，在服药物三种，否认过敏。**评估：** 胸痹，寒凝心脉为主，兼气虚；分层为需复评。**待办：** 夜班复评脉象与胸痛次数；若静息亦痛或伴冷汗，即刻走急诊路径；已告知病人与家属，复述无误。

十行里没有一句是形容词。「痛两次」「均在活动后」「未再汗出」是可回查的事实；「需复评」是判断；「若静息亦痛即走急诊」是可执行的待办。三者混在一起写，交接才有用。

## 四、记录字段：九个格子，一个不能空

接诊记录的价值不在「经过了什么」，在「判断是什么」。九个字段按顺序填，缺项即退回。

| 字段 | 写法 | 常见错法 |
|---|---|---|
| 主诉 | 部位＋性质＋时限，一句话 | 抄病人原话不加整理 |
| 现病史 | 起病、演变、加重与缓解因素、已用处理 | 只写「反复发作多年」 |
| 既往与用药 | 病名、在服药物名称、过敏史 | 写「否认药物过敏」而不问 |
| 舌象 | 舌质、舌形、舌苔分记 | 与脉象合成一句套话 |
| 脉象 | 至少两位，注明取脉部位 | 一律「脉弦」 |
| 辨证 | 病名＋证型，附一条主症依据 | 证型与主症不符 |
| 治法 | 一句话，与证型同向 | 治法栏抄方名 |
| 方 | 方名＋出处＋加减理由 | 只写「随症加减」 |
| 交代 | 复诊指征、危险信号、转诊方向 | 只写「不适随诊」 |

第九格最容易被当成客套。它的实际用法是：把「什么情况下必须马上回来」写成病人能复述的一句话，并在记录里注明已告知、已复述。这一格空着，前面八格做得再漂亮，责任链也是断的。

## 五、失效模式与考核项

**四种最常见的失效，每一种都能在带教记录里找到痕迹：**

1. **只跑不动手。** 跟着查房跑得勤，回到示教室却写不出一份完整记录。跑动产生的是印象，动手产生的才是能力；判据是当班结束时你交了几份记录。
2. **把看当会。** 看带教做一次胸痹辨证，就认为自己也「会了」。检验方式只有一个：换一个同证不同人的病人，自己独立辨一次，看结论是否仍对得上。
3. **记流水不记判断。** 记录写满「上午查房、下午复查」，却找不到一句「此属阴寒内盛、治当辛温通阳」。流水可以补，判断补不了——它在你写的时候就已经决定了你看没看见。
4. **见痛止痛、见悸安神。** 把症状当病机，直接对症状下方。胸痹的「痛」有寒凝、有痰浊、有血瘀，同一个止痛方向用错证型就是加重。

**考核项：**

| # | 考核项 | 形式 | 通过判据 |
|--:|---|---|---|
| 1 | 两病分界 | 口试，给三条主诉 | 三条全对，且各给一条理由 |
| 2 | 证型复述 | 闭卷，限时口述 | 胸痹七证、心悸六证名称无误 |
| 3 | 独立接诊 | 带教旁观，学生主问 | 九字段齐全，「辨证」「记录」两行达标 |
| 4 | 交接演练 | 与接班者对接一次 | 四段齐全，接班者能复述待办 |
| 5 | 病例复盘 | 书面一页 | 写出一个判断错误及其依据缺口 |

五项里第 3、5 两项权重最高：它们考的是能不能独立完成一次判断，而不是记住多少名目。

## 代价与边界

1. 本章只给接诊骨架与判据，不给具体方药剂量与疗程；证型的临床取舍必须由带教医师在病人身上确定。
2. 七证、六证是教材归类，实际病人常两证并见或介于两证之间。判据表要求「证型能对上一条主症」，对不上的情形应当写成「兼证待辨」，而不是强行归入某一证。
3. 风险分层用的是描述性征象（持续不缓解、汗出肢冷、脉微、不能平卧），不是量化评分；任何评分表的使用都以所在机构现行制度为准。
