# 第 4 章 · 水肿与淋证都关于水，虚实一分治法就分道

> **MOTTO:** 「诸淋者，由肾虚而膀胱热故也。」——《诸病源候论·淋病诸候》
>
> **PROBLEM:** 肾病科病单 6 病、必做动作 30 项，轮转学时 18，折算一病三学时——每病分到的时间是心病科的一倍半。可 6 病里水肿、淋证、癃闭、关格四病共用「小便不利」这一条主诉：同一句「小便不好」，可能是水道不通、可能是气化不行、可能是浊毒内闭。分错一层，处置方向正好相反；三学时够辨清一个病，不够把四病都过一遍。
>
> **双根因定位:** 环境逼迫（四病共用一条主诉，病人开口的第一句话几乎不提供鉴别信息，全靠追问）+ 知识积累（水肿分阳水阴水两纲共七证，淋证分六淋，判别点集中在「量、色、痛、砂石、中断」五个字上，不把这五个字问全，两套表都挂不上）

> 本章无参考电子件，不引页码、不引版次、不给剂量与疗程。证型与方名属教学归类，用药以所在机构制度与带教医师意见为准。

## 一、入科三问

**第一问：肿从何处起、按之如何。** 眼睑先肿、来势急、多兼表证，属阳水一路；下肢先肿、来势缓、按之凹陷难复，属阴水一路。这一问决定的是先表还是先里、先攻还是先补，方向错了，后面越辨越远。

**第二问：小便怎么样。** 五个字问全：量（多少、昼夜差）、色（清、黄、赤、浑浊）、痛（涩痛、灼痛、不痛）、砂石（有无排出、尿时中断）、血（全程血尿还是终末血尿）。五字不问全，六淋就分不开——热淋在「痛」，石淋在「砂石与中断」，血淋在「血」，气淋在「涩而腹满」，膏淋在「浑浊如脂」，劳淋在「遇劳即发」。

**第三问：有无浊毒内闭的征象。** 少尿甚至无尿、呕恶不食、口中尿味、神识昏蒙，属须即刻转诊处理的情形，不在本科按「水肿」慢慢调。这一问排在最前也不为过——它决定的是处置的时间顺序，不是辨证的精细程度。

**三问的顺序有讲究。** 先部位与起势（定阴阳），再小便五字（定六淋或水肿的证），最后划界（有没有浊毒内闭）。颠倒顺序的典型后果是：一上来就辨六淋，把一个少尿的水肿病人按「淋证」清了半天水道，而真正要处理的是浊毒。

**四病同源不同层。** 水肿是水停于肌肤，淋证是湿注于下焦，癃闭是尿路闭塞不通，关格是浊毒内闭而上犯清窍。四者可以依次演进：淋证日久可致癃闭，癃闭不通则成关格。轮转要练的是判断病人此刻停在哪一层——停在水停，按水肿辨；停在尿闭，先通后辨；停在浊毒，先保命再辨证。层判断错，辨证再细也是白辨。

**可观察学习目标：**

| # | 目标 | 可观察动作 |
|--:|---|---|
| 1 | 定阴阳 | 问出肿起部位与起势，说出阳水或阴水及依据 |
| 2 | 小便五字 | 接诊记录里量、色、痛、砂石、血五项分列 |
| 3 | 报得出证型 | 不查资料说出水肿七证、淋证六证 |
| 4 | 认得出危象 | 说出四条浊毒内闭征象与即刻转诊要求 |
| 5 | 写得成记录 | 独立完成一份九字段接诊记录，出入量单列 |

## 二、判据：达标与不达标两列【教学设定】

本表为教学分档，不替代所在机构的病历规范与质控要求；分级一律用描述词，不用阈值。

**先把十三个证型挂到抓手上：**

| 病 | 证型 | 主症抓手 | 治法方向 |
|---|---|---|---|
| 水肿 | 风水相搏 | 眼睑先肿、来势急、兼恶风发热 | 疏风清热、宣肺行水 |
| 水肿 | 湿毒浸淫 | 肿兼疮毒、发热、小便短赤 | 宣肺解毒、利湿消肿 |
| 水肿 | 水湿浸渍 | 全身水肿、按之凹陷、身重困倦 | 健脾化湿、通阳利水 |
| 水肿 | 湿热壅盛 | 遍身浮肿、皮色光亮、烦热口渴 | 分利湿热 |
| 水肿 | 脾阳虚衰 | 下肢为甚、按之凹陷难复、纳减便溏 | 健脾温阳、利水消肿 |
| 水肿 | 肾阳衰微 | 水肿反复、腰以下为甚、畏寒肢冷 | 温肾助阳、化气行水 |
| 水肿 | 瘀水互结 | 水肿日久、面色晦暗、舌紫暗 | 活血祛瘀、化气行水 |
| 淋证 | 热淋 | 小便灼痛、尿频尿急、色黄 | 清热利湿通淋 |
| 淋证 | 石淋 | 尿中砂石、尿时中断、腰腹绞痛 | 清热利湿、排石通淋 |
| 淋证 | 血淋 | 尿中带血、涩痛 | 清热通淋、凉血止血 |
| 淋证 | 气淋 | 少腹胀满、小便涩滞、余沥不尽 | 理气疏导、通淋利尿 |
| 淋证 | 膏淋 | 尿液浑浊如脂、尿道涩痛 | 清热利湿、分清泄浊 |
| 淋证 | 劳淋 | 遇劳即发、小便淋沥不已、腰酸 | 健脾益肾 |

十三行里，水肿七证按「阳水四、阴水三」排，淋证六证按「痛、砂石、血、气、浊、劳」六个抓手排。训练方式是：给一句「小便不好」，要求在表里找出至少三个候选证型，再用追问排除到剩一个。

| 环节 | 达标 | 不达标 |
|---|---|---|
| 问诊 | 起病部位与起势、诱因（外感、疮毒、劳累）写明 | 只写「浮肿多日」 |
| 小便记录 | 量、色、痛、砂石、血五项分列 | 一句「小便正常」带过 |
| 查体 | 浮肿部位与按之凹陷程度用描述词记录；肾区叩击痛 | 只写「双下肢水肿」 |
| 舌脉 | 舌质舌苔分记，脉象两位（如沉细、濡滑） | 一律「舌淡脉沉」 |
| 辨证 | 病名＋证型＋抓手，阴阳或六淋的归属写明 | 只写「水肿」「淋证」不落证型 |
| 治法 | 一句话，与证型同向 | 一律「利水渗湿」 |
| 交代 | 复诊指征、危象信号、转诊方向、饮水与饮食要点 | 只说「少喝水」 |

「小便记录」与「查体」两行是本科的命门。五项小便不记全，六淋永远分不开；凹陷程度只写「水肿」不写描述，复评时无从比较。

## 三、交接四段与时限

| 段 | 写什么 | 时限 |
|---|---|---|
| 现状 | 本班出入量、体重趋势、浮肿部位与凹陷程度变化、小便性状 | 交班前完成书面 |
| 背景 | 既往肾病史与检查、近期感染或疮毒、在服药物名称、过敏史 | 入科首日补齐 |
| 评估 | 病名＋证型＋分层（可门诊调治／需留观复评／须即刻转） | 每班复评一次 |
| 待办 | 复评尿量与浮肿、待回报的检验、转诊方向、已交代的饮水与饮食要求 | 交班口头过一遍并复述 |

时限只用类别词：少尿、呕恶、神识改变等浊毒征象**即刻**上报；首次评估**当班内**完成；书面记录**交班前**完成；浮肿与尿量**每班复评**，稳定者按复诊间隔。肾病科的交接最忌只报「水肿同前」——「同前」不是事实，是省事。

一段能用的交接：

> **现状：** 7 床，本班尿量偏少，双下肢凹陷性浮肿，按之复起缓慢，体重较昨日上升，无呕恶、神识清。**背景：** 慢性肾病史，近日咽痛，在服药物三种。**评估：** 水肿，脾阳虚衰为主，兼风邪未清；分层为需复评。**待办：** 夜班复评尿量与浮肿；若尿量进一步减少或出现呕恶，即刻上报并转诊；饮水与盐的交代已复述。

## 四、记录字段

| 字段 | 写法 | 常见错法 |
|---|---|---|
| 主诉 | 症状＋部位＋时限 | 「肾不好」 |
| 起病与诱因 | 起病缓急、有无外感、疮毒、劳累 | 只写「无明显诱因」 |
| 出入量与体重 | 本班入量、出量、体重趋势 | 只记「尿少」 |
| 浮肿 | 部位、按之凹陷程度（描述词）、对称与否 | 「水肿++」而无描述 |
| 小便性状 | 量、色、痛、砂石、血 | 合并成「小便如常」 |
| 舌脉 | 舌质舌苔、脉象两位 | 抄上一份记录 |
| 辨证 | 病名＋证型＋阴阳或六淋归属 | 不落证型 |
| 治法与方 | 治法一句、方名加出处、加减依据 | 只写「利尿方」 |
| 交代 | 复诊指征、危象信号、转诊方向、饮水饮食要点 | 只写「不适随诊」 |

第九格在肾病科要写得比别科更具体：哪些变化意味着必须马上回来（尿量明显减少、呕恶不食、神志改变），要写成病人能复述的话。这句话写不出来，等于把风险留给了下一次复诊。

填一格试写：交代栏写「若一天尿量明显比平时少、吃不下还恶心、人发困叫不醒，当日就诊；平时按交代控制饮水与盐」——病人能复述，才算交代完成。写「注意饮食」，等于把判断留在自己心里。

## 五、失效模式与考核项

1. **只跑不动手。** 跟着查房看了一周浮肿，自己没按过一次、没记过一次出入量。判据是当班内独立完成一次浮肿查体与一张出入量记录。
2. **把看当会。** 看带教问出五项小便，就以为会问。换一个只答「尿不多」的病人，问不出色、痛、砂石，就是不会。
3. **记流水不记判断。** 记录里写「上午查房、下午复诊、记出入量」，却没有「阳水，风水相搏」这样的判断。流水越细，越显得没看见。
4. **以「水肿」统称不辨阴阳。** 阴阳不分，则先攻先补无从定，方随证转也无从谈起。
5. **见淋即清利。** 六淋里劳淋、气淋本属虚与滞，一律清利会伤正气；石淋不问砂石与中断，清利再久也排不出。
6. **把「同前」当事实。** 交接只写「水肿同前」「尿量同前」，复评时无从比较。同前不是观察，是省略。

**考核项：**

| # | 考核项 | 形式 | 通过判据 |
|--:|---|---|---|
| 1 | 阴阳分纲 | 口试，给两段主诉 | 两段均判对，说出部位与起势依据 |
| 2 | 小便五字 | 床边接诊 | 记录中五项分列，无合并 |
| 3 | 证型复述 | 闭卷口述 | 水肿七证、淋证六证名称无误 |
| 4 | 危象识别 | 病例讨论 | 四条浊毒征象与即刻转诊要求说清 |
| 5 | 独立接诊 | 带教旁观 | 九字段齐全，出入量与浮肿不缺项 |

## 代价与边界

1. 本章不给方药剂量与疗程，不给饮水量与食盐的具体数值；一切治疗与调护以带教医师和所在机构制度为准。
2. 七证与六证是教学归并，实际病人常阳水阴水互转、六淋相兼。判据要求「证型能对上一条抓手」，对不上应写「兼证待辨」。
3. 浮肿程度一律用描述词（按之凹陷、复起快慢、对称与否），不给分级切点；分级量表若机构有现行版本，以机构版本为准。
