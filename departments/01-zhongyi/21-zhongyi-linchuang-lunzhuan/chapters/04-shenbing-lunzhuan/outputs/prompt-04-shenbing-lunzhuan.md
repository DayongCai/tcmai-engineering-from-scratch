# 水液链

## 用途

**水肿、癃闭、关格是一条链，不是三个并列病。** 阶段错，转诊时点就错。

本单只做一件事：把轮转要求写成可对账的表——病名来自教材的「节」，动作来自教材的 5 个小节，考核证据来自「辨证论治」小节与代表方。写不出数字的地方，写「无」。

## 步骤

### 1. 定阶段

水停／尿闭／上下不通

### 2. 分证

阴水阳水、六淋、虚实夹杂

### 3. 报方

30 首代表方

### 4. 判转诊

关格须立即转诊

## 判据速查

| 项 | 数字 |
|---|---|
| 五科病数 | 38（心病 9／肺病 8／脾胃 9／肾病 6／脑病 6） |
| 必做动作 | 190 项（每病 5 小节） |
| 辨证论治小节 | 37 个 |
| 代表方（去重） | 179 首 |
| 证候库同名证 | 17 个 |
| 数值判据 | 12 处（脾胃 0、脑病 2） |
| 跨科病 | 23 个 |

## 输出

① 阶段；② 证型与方；③ 危急判定；④ 转诊时点。

## 边界

- 数字一律由 `code/main.js` 读 `standards/lunzhuan/` 现算，不手写；
- 病名一篇不增不删；教材未给的数值不补；
- **免责声明：** 本单为教学整理，不构成诊疗建议；轮转须在有资质医师指导下进行。
