# 跨章取病

## 用途

**教材没有脑病章。** 6 病跨肝系与心系取，取法公开在 METHOD.json。

本单只做一件事：把轮转要求写成可对账的表——病名来自教材的「节」，动作来自教材的 5 个小节，考核证据来自「辨证论治」小节与代表方。写不出数字的地方，写「无」。

## 步骤

### 1. 定归属

该病为何归脑病科

### 2. 报原章

教材原章与节号

### 3. 分界

与相似病（眩晕 vs 头晕、中风 vs 厥证）

### 4. 标缺口

证候库 0 命中须显式说明

## 判据速查

| 项 | 数字 |
|---|---|
| 五科病数 | 38（心病 9／肺病 8／脾胃 9／肾病 6／脑病 6） |
| 必做动作 | 190 项（每病 5 小节） |
| 辨证论治小节 | 37 个 |
| 代表方（去重） | 179 首 |
| 证候库同名证 | 17 个 |
| 数值判据 | 12 处（脾胃 0、脑病 2） |
| 跨科病 | 23 个 |

## 输出

① 病名；② 原章；③ 归本科理由；④ 与相似病的分界。

## 边界

- 数字一律由 `code/main.js` 读 `standards/lunzhuan/` 现算，不手写；
- 病名一篇不增不删；教材未给的数值不补；
- **免责声明：** 本单为教学整理，不构成诊疗建议；轮转须在有资质医师指导下进行。
