# 跨章取病 · 可装载技能

## 何时装载

- 需要说明一个病为何归本科，并给出原章位置；
- 轮转交接、出科考核、病例复盘；
- 复核场景：检查一份轮转要求是否报了病数、动作数、代表方与数值判据。

## 步骤

1. **定归属** —— 该病为何归脑病科
2. **报原章** —— 教材原章与节号
3. **分界** —— 与相似病（眩晕 vs 头晕、中风 vs 厥证）
4. **标缺口** —— 证候库 0 命中须显式说明

## 输出格式

① 病名；② 原章；③ 归本科理由；④ 与相似病的分界。

## 边界

- 病名只取教材的「节」；教材未给的数值不补；
- 缺口（如脾胃科数值 0、脑病科证候库 0）须显式写出，不隐藏；
- **免责声明：** 本技能为教学用，不构成诊疗建议。
