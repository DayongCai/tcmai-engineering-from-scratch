# 第 5 章 · 脑病科轮转：眩晕与中风的辨证接诊

> **MOTTO:** 「头者精明之府」——教材·第5章·5.1（《素问·脉要精微论》）
>
> **PROBLEM:** 教材里没有「脑病科」这一章。中医内科按脏腑分章，脑病科按病种收人，两者对不齐——这是全部六章里唯一需要跨章取病的一科，也是最能说明「轮转不等于照章念」的一科。
>
> **双根因定位:** 环境逼迫（眩晕与中风是轮转必见的病，且中风有时间窗）+ 知识积累（本章 1 单元；跨肝系与心系取 6 病 24,964 汉字，辨证论治小节 5 个，代表方 23 首）

**教材出处:** 派生底本。本章数字由 `code/main.js` 现算。

## 一、跨章取病：本章的成立方式

| 病 | 教材所在章 | 为何归脑病科 |
|---|---|---|
| 头痛 | 肝系病证（7.5） | 以头部为病位 |
| 眩晕 | 肝系病证（7.6） | 以头目为病位 |
| 中风 | 肝系病证（7.7） | 脑病核心 |
| 痫病 | 心系病证（5.8） | 神识异常 |
| 痴呆 | 心系病证（5.6） | 认知功能 |
| 厥证 | 心系病证（5.9） | 神识暴失 |

**6 病，横跨两章，24,964 汉字。** 这个取法写在 `standards/lunzhuan/METHOD.json` 里，可复核、可改。

## 二、必须做操作（30 项）

| 动作 | 脑病科的具体落点 |
|---|---|
| 概述 | 眩晕与头晕、中风与厥证的分界 |
| 病因病机 | 风、火、痰、虚、瘀五端；中风在脑 |
| 辨证论治 | 中风须先辨中经络／中脏腑 |
| 预防调护 | 中风的时间窗与二级预防 |
| 按语 | 「见晕止晕」；中风误作眩晕 |

## 三、出科考核证据：一条必须要说的空缺

| 证据 | 数量 |
|---|--:|
| 辨证论治小节 | 5 |
| 代表方（去重） | 23 |
| 证候库同名证 | **0** |
| 数值判据 | 2 |

**证候库同名证 0 是本课程最该公开的一处空缺**：证候库（132 证）是从外科、儿科、妇科三门的 900 个单元里派生的，内科病名不在其中，所以脑病科的证名一个也对不上。

这不是「脑病科没有证」，而是**两个层的语料来源不同**。补救办法有两条：① 用内科自己的「辨证论治」小节作证名来源（本章 5 个单元）；② 把证候库扩到内科后再对齐。本章选第一条，并把第二条写成待办。

## 四、为什么这一章最短

24,964 汉字，五科里字数最少（心病 35,350、肺病 38,900、脾胃 38,439、肾病 26,217）。原因很实在：**教材没有为脑病单列一章**，取病只能从两章里挑，挑完就不是完整章。

**字数少不等于要求低**：中风是本科最重的时间窗病，轮转要求里「按语」一项（误作眩晕）比任何字数都重要。

## 五、跨科校验

6 病中 3 个跨课（最多 2 门）：眩晕、中风、厥证在急诊与老年病学里都讲。

| 病 | 跨课含义 |
|---|---|
| 中风 | 急诊优先，内科接续 |
| 眩晕 | 老年病学高频 |
| 厥证 | 急诊首诊 |

## 代价与边界

1. 本章不给中风的时间窗数值（属急诊学第 6 章）；
2. 证候库 0 命中是层的缺口，不是病的缺口，已在正文与 `METHOD.json` 标注；
3. **免责声明：** 教学整理，不构成诊疗建议；中风须立即急诊。
