# 第 5 章 · 眩晕与中风共用一套风证坐标，差在一个时间窗

> **MOTTO:** 「诸风掉眩，皆属于肝。」——《素问·至真要大论》
>
> **PROBLEM:** 脑病科病单 6 病、必做动作 30 项，轮转学时 18。眩晕与中风共用一套「风」的坐标，差别在时间窗：眩晕是风动而未中，中风是风动而已中。同一个「头晕」主诉，走错一条路就是两个结局——按眩晕慢慢调治的卒中病人，错过的不是一剂方，是可干预的那段时间。
>
> **双根因定位:** 环境逼迫（卒中病人到诊时多已被家属观察多时，「最后看起来正常的时间」只能靠回溯，而这一句决定走哪条流程）+ 知识积累（眩晕五证按肝、痰、瘀、虚、精分，中风要分中经络与中脏腑、闭与脱两途；两套入口不同，混用就会把「已中」辨成「未中」）

> 本章无参考电子件，不引页码、不引版次、不给剂量与疗程。证型与方名属教学归类，用药以所在机构制度与带教医师意见为准。

## 一、入科三问

**第一问：突发还是渐进。** 突发的头晕伴神经功能缺损，走卒中流程；反复发作、与体位、情绪、劳累相关的头晕，走眩晕一路。这一问不是问病程长短，是问「有没有一个明确的起点」——有起点，就有时间窗；没有起点，才谈得上慢慢辨。

**第二问：三症有没有。** 口舌歪斜、一侧肢体无力、言语不利，三者出现任一，即刻启动院内卒中流程，不等辨证、不等检查、不留在门诊观察。这一问要背到条件反射的程度，因为它的价值全在速度上。

**第三问：既往与用药。** 高血压、房颤、既往卒中或短暂发作、在服药物名称，是判断风险与复发方向的底子。三问的顺序同样固定：先定有没有时间窗，再定是哪一途，最后补底子。

**「最后看起来正常的时间」是本章最重要的一个字段。** 家属常说「早上还好好的」「吃完饭就不对了」，这两句都不能直接用。要追问到具体事件：「最后一次看见他正常走路是什么时候」「有没有人跟他通过电话」。这个时点写不清，后面的路径判断就没有依据。

**可观察学习目标：**

| # | 目标 | 可观察动作 |
|--:|---|---|
| 1 | 定时间窗 | 问出「最后正常时间」，写成一句可引用的话 |
| 2 | 认三症 | 三条神经体征逐一查、逐一记，不合并 |
| 3 | 报得出证型 | 不查资料说出眩晕五证、中风中经络三证与中脏腑闭脱 |
| 4 | 分闭脱 | 给一段表现，说出闭证或脱证及依据 |
| 5 | 写得成记录 | 独立完成一份九字段记录，起病时间单列 |

## 二、判据：达标与不达标两列【教学设定】

本表为教学分档，不替代所在机构的卒中流程与病历规范；流程判断一律以机构现行制度为准。

**先挂证型，再谈判据：**

| 病 | 分期或证型 | 主症抓手 | 治法方向 |
|---|---|---|---|
| 眩晕 | 肝阳上亢 | 眩晕耳鸣、头胀痛、遇烦劳加重、脉弦 | 平肝潜阳、清火息风 |
| 眩晕 | 痰湿中阻 | 头重如裹、胸闷恶心、苔白腻 | 化痰祛湿、健脾和胃 |
| 眩晕 | 瘀血阻窍 | 眩晕头痛、痛处固定、舌紫暗 | 祛瘀生新、通窍活血 |
| 眩晕 | 气血亏虚 | 眩晕动则加剧、面色白、神疲 | 补益气血、调养心脾 |
| 眩晕 | 肾精不足 | 眩晕日久、腰膝酸软、耳鸣如蝉 | 滋养肝肾、益精填髓 |
| 中风·中经络 | 风痰入络 | 肌肤不仁、手足麻木、口舌歪斜 | 祛风化痰通络 |
| 中风·中经络 | 风阳上扰 | 平素头晕头痛、突发歪斜、舌红苔黄 | 平肝潜阳、活血通络 |
| 中风·中经络 | 阴虚风动 | 平素腰酸耳鸣、突发歪斜、舌红少苔 | 滋阴潜阳、息风通络 |
| 中风·中脏腑 | 闭证·痰热腑实 | 神昏、腹胀便秘、苔黄腻 | 通腑泄热、息风化痰 |
| 中风·中脏腑 | 闭证·痰火瘀闭 | 神昏、躁扰不宁、面赤身热 | 息风清火、豁痰开窍 |
| 中风·中脏腑 | 闭证·痰浊瘀闭 | 神昏、静卧不烦、面白唇暗、苔白腻 | 化痰息风、宣郁开窍 |
| 中风·中脏腑 | 脱证 | 神昏、目合口开、肢冷、脉微欲绝 | 回阳救阴、益气固脱 |

十二行里，眩晕五证看的是「兼症」——耳鸣、胸闷、痛处、乏力、腰酸各指一路；中风看的是「层次」——先分中经络与中脏腑，中脏腑再分闭与脱。层次错了，证型再准也没有意义。

| 环节 | 达标 | 不达标 |
|---|---|---|
| 起病 | 写明起病形式（突发／渐进）与最后正常时间 | 只写「头晕多日」「今晨发作」 |
| 神经体征 | 口舌、肢体力量、言语三项逐一查记，注明左右 | 只写「无明显阳性体征」 |
| 舌脉 | 舌质舌苔分记，脉象两位（如弦滑、沉细） | 一律「舌红脉弦」 |
| 辨证 | 病名＋分期（中经络／中脏腑）＋证型 | 只写「中风」不分期 |
| 闭脱 | 明确写出闭或脱，附一条依据 | 只写「神昏，待查」 |
| 治法与方 | 治法一句、方名加出处、加减依据 | 只写「活血化瘀」 |
| 交代 | 复发信号、康复介入方向、复诊与转诊 | 只说「注意休息」 |

「闭脱」一行是本科的生死线：闭证宜开，脱证宜固，两者方向相反。没写清楚，接班的人只能重新判断一次，而时间已经过去了。

## 三、交接四段与时限

| 段 | 写什么 | 时限 |
|---|---|---|
| 现状 | 意识、三项神经体征、血压趋势、本班内变化 | 交班前完成书面 |
| 背景 | 起病时间与最后正常时间、既往卒中与房颤史、在服药物名称 | 入科首日补齐，卒中病人当班内补齐 |
| 评估 | 病名＋分期＋闭脱＋分层（可留观／需复评／须即刻处理） | 每班复评一次 |
| 待办 | 复评神经体征、影像与检验回报后的处置、康复介入时点、转诊方向 | 交班口头过一遍并复述 |

时限用类别词：三症任一出现或意识转差，**即刻**启动院内流程；首次评估**当班内**完成；书面记录**交班前**完成；病情不稳者**每班复评**神经体征。脑病科的交接里，「肢体力量比上一班好还是差」必须写成比较句，不能只写「肌力尚可」。

一段能用的交接：

> **现状：** 9 床，神清，右侧肢体无力较昨日下午相仿，言语略涩，无新发口舌歪斜；血压趋势平稳。**背景：** 昨日上午发病，最后正常时间为昨晨起床时；高血压史，在服药物两种。**评估：** 中风，中经络，风阳上扰；分层为需复评。**待办：** 夜班复评三项体征；若意识转差或出现新发歪斜，即刻上报；康复介入已联系，家属复述复发信号无误。

「相仿」两个字是本科最需要练的写法，但它必须补足三样：与什么相仿（上一班）、哪一项相仿（右侧肢体）、其余两项如何（言语略涩、无新发歪斜）。三样缺一，接班的人就得重新查一遍，交接的时间就白花了。

## 四、记录字段

| 字段 | 写法 | 常见错法 |
|---|---|---|
| 主诉 | 症状＋起病形式 | 「头晕不适」 |
| 起病时间 | 起病时点＋最后正常时间＋目击者 | 只写「今日」 |
| 神经体征 | 口舌、肢体、言语三项分列，注明左右 | 三项合并成一句 |
| 既往与用药 | 高血压、房颤、既往卒中、在服药物名称 | 漏问房颤 |
| 舌脉 | 舌质舌苔、脉象两位 | 抄前一份 |
| 辨证与分期 | 病名＋中经络／中脏腑＋证型＋闭脱 | 分期缺项 |
| 治法 | 一句话，与分期同向 | 一律「平肝息风」 |
| 方 | 方名＋出处＋加减依据 | 只写「中药治疗」 |
| 交代 | 复发信号、康复方向、复诊与转诊 | 「不适随诊」 |

第九格在脑病科要写成两句：一句是「什么情况立刻来」（新发歪斜、言语不清、意识改变），一句是「接下来怎么练」（康复介入的方向）。只写前一句，病人回家后仍不知道能做什么。

填一格试写：交代栏写「若再出现口角歪斜、一侧手脚抬不起来、说话含糊，立刻来，不要等复诊；平时按康复安排练站立与步行」——两句都能复述，才算交代完成。

## 五、失效模式与考核项

1. **只跑不动手。** 跟着查房看了一周神经体征，自己没查过一次肢体力量。判据是当班内独立完成三项体征检查并写下左右与程度。
2. **把看当会。** 看带教两句问出起病时间，换一个说不清的家属就问不下去。会问的标志是：能问出「最后正常时间」并写成一个时点。
3. **记流水不记判断。** 记录写「上午查房、下午复查、陪同检查」，却没有「中经络，风阳上扰」这样的判断。流水越长，越看不出判断。
4. **眩晕一律当虚。** 见眩晕即补气血，漏掉肝阳上亢与痰湿中阻，也漏掉以眩晕起病的卒中。
5. **先辨证型，后辨闭脱。** 顺序颠倒，会在一个脱证病人身上讨论痰热，方向从一开始就错。
6. **把「肌力尚可」当描述。** 无比较、无左右、无程度，等于什么都没写；复评时无从判断进退。

**考核项：**

| # | 考核项 | 形式 | 通过判据 |
|--:|---|---|---|
| 1 | 时间窗 | 口试，给一段家属叙述 | 问出最后正常时间并写成时点 |
| 2 | 三症查体 | 床边，带教旁观 | 三项分列，左右与程度写明 |
| 3 | 证型复述 | 闭卷口述 | 眩晕五证、中风分期与闭脱无误 |
| 4 | 闭脱判断 | 病例讨论 | 判断正确并给出依据 |
| 5 | 独立接诊 | 带教旁观 | 九字段齐全，起病时间单列 |

第 1、4 两项权重最高：一个决定走哪条路，一个决定先救什么。两项都过，其余各项才有意义。

第 2 项常被当成形式，其实它是本科所有判断的地基：三项体征写不写左右、写不写程度，直接决定下一班能不能做比较。教学上只要把一份写清左右的记录与一份「肌力尚可」的记录并排给学生看，差别不用讲，他自己就能认出来。
