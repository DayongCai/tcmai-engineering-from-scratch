# 妊娠病三问：分组、红线、用药纪律

## 用途

妊娠期的每一次判断都要同时回答两个问题：**这个症状属于哪一组**（决定辨证方向）与**能不能等**（决定是否急诊）。本单用三问把两者一次做完——分组、红线、用药纪律。

## 第一问：属哪一组

| 组 | 病证 |
|---|---|
| 胎气上逆 | 妊娠恶阻（食入即吐；重症气阴两虚属急症） |
| 胎系不固 | 妊娠腹痛、胎漏与胎动不安、堕胎小产、滑胎、胎萎不长 |
| 母体并发症 | 肿胀、眩晕、痫证、小便淋痛、小便不通、身痒、贫血 |
| 例外 | **异位妊娠**（必须破瘀） |

## 第二问：红线（先排除，再辨证）

1. **异位妊娠四联征**：停经＋腹痛＋阴道流血＋休克；约 20%–30% 无停经史；
2. **腹胀满痛＋阴道出血增多** → 堕胎小产；
3. **肿胀→眩晕→抽搐** → 痫证（急症）；
4. **食入即吐＋消瘦＋尿少** → 妊娠剧吐致酸中毒（急症）。

## 第三问：用药纪律

- 妊娠禁忌药原则上不用；确有病邪依「**有故无殒**」，但须诊断明确、监护到位、与西医结合（三棱莪术治异位妊娠即此例）；
- 安胎不离补肾（系胎）与健脾（载胎）；治母即安胎（癥瘕伤胎者用桂枝茯苓丸合寿胎丸）；
- 不因怀孕停止必要检查（B 超、血 β-hCG）。

## 输出格式

```text
分组：胎气上逆 / 胎系不固 / 母体并发症 / 异位妊娠
红线：<无 / 命中第 N 条>
证型与方（不含剂量）：…
急症判断：<可门诊 / 立即就医>
```
