# 六法选一 + 按周期换挡

## 用途

妇科治疗有两层：**选哪一法**（横）与**现在该用哪一档**（纵）。只做对第一层，效果常常不好。

## 横向：六法

| 证 | 法 | 锚点方 |
|---|---|---|
| 肾气虚/阳虚/阴虚 | 补肾滋肾 | 寿胎丸、归肾丸、左归/右归类 |
| 肝气郁结 | 疏肝养肝 | 逍遥散 |
| 脾气虚（不摄血） | 健脾和胃 | 归脾汤 |
| 气血两虚 / 血瘀 | 补气养血 / 活血化瘀 | 八珍汤 / 桃红四物汤 |
| 气滞 / 血热 | 理气行滞 / 清热凉血 | 加味乌药汤、金铃子散 / 清热固经类 |
| 寒凝血瘀 / 痰湿 | 温经散寒 / 利湿除痰 | 温经汤 |

## 纵向：调周四档

| 段 | 治法 | 方向 |
|---|---|---|
| 经后期（5–13 日） | 滋肾填精、养血益阴 | **养** |
| 经间期（约 14 日） | 活血化瘀、温阳理气 | **化** |
| 经前期（15–28 日） | 温肾助阳、理气调经 | **温** |
| 行经期（1–4 日） | 活血调经、引血下行 | **通** |

## 禁区

补肾勿一味温燥；疏肝勿过用香燥；健脾勿壅补；活血须辨虚实与时机（经期、妊娠慎破血）；清热勿过苦寒。

## 输出

```text
横向：治法…
纵向：周期第 N 天 → 养/化/温/通
禁区：…
```
