# 闭／崩／经行：三路分流

## 用途

第 8 章 14 个病证看似杂乱，其实只有三路：**血没了、止不住、每次经期固定犯**。先分流，再辨证。

## 第一路：闭经

- 门槛：年逾 16 周岁月经未潮／周期建立后中断 6 个月以上／按月行经后又停闭 3 个周期以上；
- **先排除不必治的**：妊娠、哺乳期、绝经前后、初潮后 1 年内暂闭；
- 现代分流：妊娠试验、甲状腺、泌乳素、卵巢功能、宫腔因素；
- 证型：气血虚弱（人参养荣汤）／肾气亏损（加减苁蓉菟丝子丸）／阴虚血燥（加减一阴煎）／气滞血瘀（血府逐瘀汤）／痰湿阻滞（苍附导痰丸）。

## 第二路：崩漏

- 定义：经血非时暴下不止（崩中）或淋漓不尽（漏下），两者可互相转化；
- 三法次序：**塞流 → 澄源 → 复旧**；
- 证型：脾虚（固本止崩汤）／肾气虚（加减苁蓉菟丝子丸）／肾阴虚（左归丸合二至丸）／肾阳虚（右归丸）／血热（清热固经汤）／血瘀（逐瘀止崩汤）；
- **红线**：大量出血＋头晕心悸＋面色苍白＋冷汗 → 立即就医。

## 第三路：经行诸证十二种

判据三件：**每逢经期或经前**、**经净自止**、**周期性反复**。

| 病证 | 落点 | 方 |
|---|---|---|
| 乳房胀痛 | 肝郁／肝肾阴虚 | 逍遥散／一贯煎 |
| 发热 | 阴虚／气虚／血瘀 | 蒿芩地丹四物汤／补中益气汤／血府逐瘀汤加丹皮 |
| 头痛 | 肝火／血瘀／血虚／痰湿 | 羚角钩藤汤／通窍活血汤／八珍汤／半夏白术天麻汤 |
| 身痛 | 血虚／寒湿 | 当归补血汤／趁痛散 |
| 泄泻 | 脾虚／肾虚 | 参苓白术散／健固汤合四神丸 |
| 吐衄 | 肝火／阴虚 | 清肝引经汤／顺经汤（引血下行） |
| 口糜 | 阴虚／胃热 | 知柏地黄丸／凉膈散 |
| 风疹块 | 血虚／风热 | 当归饮子／四物消风饮 |
| 眩晕 | 血虚／阳亢／痰湿 | 归脾汤／天麻钩藤饮／半夏白术天麻汤 |
| 浮肿 | 脾肾阳虚／气滞血瘀 | 五皮散／天仙藤散 |
| 情志异常 | 肝郁／痰火 | 逍遥散／生铁落饮 |
| 经断前后诸证 | 肾阴虚／肾阳虚／阴阳两虚 | 左归丸／右归丸／二仙汤合二至丸 |

## 输出格式

```text
分流：闭经 / 崩漏 / 经行某证
依据：门槛与三件判据
证型与方（不含剂量）：…
红线：<无 / 出血量大 / 需排查器质病>
```
