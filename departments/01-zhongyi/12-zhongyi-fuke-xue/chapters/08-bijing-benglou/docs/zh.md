# 第 8 章 · 月经病（二）：闭经、崩漏与十二个「经行」病

> **MOTTO:** 「阴虚阳搏谓之崩」——教材·第8章·8.2.1（《素问·阴阳别论》）
>

## 一、闭经：五型，先排「不需要治的闭经」

教材 8.1 的定义要背全：**年逾 16 周岁月经尚未来潮**（原发性），或**周期已建立后又中断 6 个月以上**，或**按月行经后又停闭 3 个周期以上**（继发性）。

**但教材同时列出不必当病治的情形**：妊娠期、哺乳期、绝经前后的停闭，少女初潮后 1 年以内暂闭不行——这一句是本章最重要的「排除条款」，能挡掉大量误治。

| 证型 | 治法 | 代表方 |
|---|---|---|
| 气血虚弱 | 补气养血调经 | 人参养荣汤（《局方》） |
| 肾气亏损 | 补肾益气，调理冲任 | 加减苁蓉菟丝子丸（《中医妇科治疗学》） |
| 阴虚血燥 | 养阴清热调经 | 加减一阴煎（《景岳全书》） |
| 气滞血瘀 | 理气活血，祛瘀通经 | 血府逐瘀汤（《医林改错》） |
| 痰湿阻滞 | 燥湿化痰，活血通经 | 苍附导痰丸（《叶氏女科证治》） |

闭经的现代分流（教材同节）：**先查妊娠、甲状腺、泌乳素、卵巢功能与宫腔因素**，再谈辨证。原因不明就「活血通经」是最常见的错误。

## 二、崩漏：六型，与三条治崩大法

教材 8.2 的定义：**经血非时暴下不止（崩中）或淋漓不尽（漏下）**；两者常相互转化——「血崩日久、气血耗伤可转为漏下，久漏不止、病情加重亦可突然暴崩」。教材把它列为**妇科疑难危急重症**。

| 证型 | 治法 | 代表方 |
|---|---|---|
| 脾虚 | 补气摄血，固冲止崩 | 固本止崩汤（《傅青主女科》） |
| 肾气虚 | 补肾益气，固冲止血 | 加减苁蓉菟丝子丸 |
| 肾阴虚 | 滋肾益阴，固冲止血 | 左归丸合二至丸 |
| 肾阳虚 | 温肾固冲，止血调经 | 右归丸（《景岳全书》） |
| 血热 | 清热凉血，固冲止血 | 清热固经汤 |
| 血瘀 | 活血化瘀，固冲止血 | 逐瘀止崩汤 |

三句治崩要点（教材同节按语口径）：**塞流（止血）→ 澄源（求因治本）→ 复旧（调理善后）**，次序不可颠倒——先止血，再找原因，最后恢复周期。

红线：**大量出血伴头晕、心悸、面色苍白、冷汗** → 立即就医（第 4 章 4.1.2 的「阴血暴脱」危候）。

## 三、十二个「经行×」：一条机制，十二个靶点

教材 8.3–8.13 与 8.14 共 13 节（含经断前后诸证）。它们全部符合一个格式：**每逢经期或经前出现 → 经净自止 → 周期性反复**。

共同机制（教材各节概述反复表述）：经行之际**阴血下注冲任**，气血相对不足；素体某处不足或某处郁滞者，此时暴露出来。

| 病证 | 病机落点 | 证型（治法） | 代表方 |
|---|---|---|---|
| 经行乳房胀痛 | 肝郁（乳头属肝、乳房属胃） | 肝气郁结；肝肾阴虚 | 逍遥散；一贯煎 |
| 经行发热 | 气血失调、营卫不和 | 阴虚、气虚、血瘀 | 蒿芩地丹四物汤；补中益气汤；血府逐瘀汤加丹皮 |
| 经行头痛 | 气血不足／肝火／血瘀／痰湿 | 四型对应四法 | 羚角钩藤汤；通窍活血汤；八珍汤；半夏白术天麻汤 |
| 经行身痛 | 血虚不荣／寒湿阻络 | 血虚；血瘀寒凝 | 当归补血汤；趁痛散 |
| 经行泄泻 | 脾虚（「经前泄水」）／肾阳虚 | 脾虚；肾虚 | 参苓白术散；健固汤合四神丸 |
| 经行吐衄 | 血热气逆（「倒经」） | 肝经郁火；肺肾阴虚 | 清肝引经汤；顺经汤 |
| 经行口糜 | 心胃火／阴虚火旺 | 阴虚火旺；胃热 | 知柏地黄丸；凉膈散 |
| 经行风疹块 | 血虚生风／风热 | 血虚；风热 | 当归饮子；四物消风饮 |
| 经行眩晕 | 血虚／阴虚阳亢／痰湿 | 三型 | 归脾汤；天麻钩藤饮；半夏白术天麻汤 |
| 经行浮肿 | 脾肾阳虚／气滞血瘀 | 两型 | 五皮散；天仙藤散 |
| 经行情志异常 | 肝郁／痰火 | 两型 | 逍遥散；生铁落饮 |
| 经断前后诸证 | 肾气衰、阴阳失调 | 肾阴虚／肾阳虚／阴阳两虚 | 左归丸；右归丸；二仙汤合二至丸 |

### 三个最值得单独记的点

1. **经行吐衄＝「倒经」**：血以下行为顺，上行为逆；教材给的两个方（清肝引经汤、顺经汤）都带「引血下行」四个字——治法是**引**，不是单纯清。
2. **经行泄泻责之脾肾**：教材引《傅青主女科》「经前泄水」责脾气之虚；故治泻不在肠而在脾肾。
3. **经断前后诸证的三型是阴阳坐标**：肾阴虚（左归丸）→ 肾阳虚（右归丸）→ 阴阳两虚（二仙汤合二至丸）。这一节与第 6 章 6.3.2 的绝经期保健首尾相接。

## 四、本章与第 7 章的分工

| | 第 7 章 | 第 8 章 |
|---|---|---|
| 管什么 | **周期、量、时间、时点、疼痛**的形状 | **不出血（闭经）／止不住血（崩漏）／每逢经期的固定症状** |
| 判据 | 期量色质四栏 | 时间的「有无」与「周期性」 |
| 危险度 | 多为慢性、可调 | 崩漏属危急重症 |

这条分界对临床很实用：**先问「血是多了还是没了，还是每次来都犯同一个症状」**——一句话就能分流到两章。

## 代价与边界

1. **本章方名只作方向**，不含剂量；崩漏的止血与输血、清宫等处置须由医院完成。
2. **闭经必须先查原因**（妊娠、内分泌、宫腔），不可直接活血通经。
3. **经行诸证以「经净自止、周期性发作」为界**：不随周期消失的同一症状，应查器质病。
4. **围绝经期异常出血须排查内膜病变**（第 12 章杂病同此）。

本章为教学整理与文献梳理，**免责声明：** 不构成诊疗建议，不能替代医师面诊；崩漏与异常出血须立即就医。
