# 第 8 章 · 两个大病在「血」，十二个小病在「周期与全身」

> **MOTTO:** 「阴虚阳搏谓之崩。」——《素问·阴阳别论》（教材·第 8 章·8.2.1 引）
>
> **PROBLEM:** 本章 70 单元 43,274 汉字里，「病机」391 次、「证候表现」378 次、而「病因」257 次，是三组最均衡的一章；四个观察面出现一个反常：**肾 157、肝脾 125、冲任 81、胞宫 30**——胞宫全章最低。复算：按 `units.json` 第 8 章各单元 `prose` 与 `views`／`levels` 词表计数。原因不难看出：闭经与崩漏的病位在血与冲任，而十二个「经行」病（乳胀、发热、头痛、身痛、泄泻、吐衄、口糜、风疹、眩晕、浮肿、情志异常、经断前后）大多是**全身表现**，胞宫在其中只作背景。所以本章的结构不是「一个病位一条线」，而是「两个血病＋一条共同模板」。（三组＝病机／病因／证候表现；四个观察面＝肾／肝脾／冲任／胞宫）
>
> **双根因定位:** 环境逼迫（同一种出血，青春期多肾虚、育龄期多血热与血瘀、绝经过渡期多脾虚与肾虚，年龄换了判据也换）＋知识积累（闭经的「血枯／血隔」、崩漏的「塞流／澄源／复旧」、十二个经行病的「周期相关、经净自止」三条原则分散在《素问》《金匮要略》《景岳全书·妇人规》与教材十四节里）

**教材出处:** 教材·第 8 章（8.1 闭经、8.2 崩漏、8.3–8.14 经行乳房胀痛、发热、头痛、身痛、泄泻、吐衄、口糜、风疹块、眩晕、浮肿、情志异常、经断前后诸证。14 病各 5 单元，共 70 单元 43,274 汉字）。

## 一、两个大病：闭经与崩漏

**闭经的门槛有三条，缺一不立：** 年逾 16 周岁月经尚未来潮（原发性）；月经周期已建立后又中断 6 个月以上；或按月行经后又停闭 3 个周期以上（继发性）。同时要先把四类**生理性停经**划出去：妊娠期、哺乳期、绝经前后，以及初潮后 1 年内的暂闭。教材还补了一句常被忽略的例外——「个别妇女终身不潮而能受孕者」，不作病论。

闭经的辨治框架来自《景岳全书·妇人规》的**血枯与血隔**：血枯者当补养阴血，血隔者宜疏利冲任。这一对把闭经的所有证型压成两类——虚（肾虚、气血虚弱、阴虚血燥）与实（气滞血瘀、痰湿阻滞）。治则因此只有一句：**虚者补而通之，实者泻而通之。** 教材特别警告：不可一见闭经即投破血通经之品，以免愈攻愈虚；实证攻伐亦当中病即止。

闭经要排的四件事，顺序不能乱：**妊娠**（育龄期必做妊娠试验与超声）→ **药物与手术史**（避孕药、镇静药；人流与宫腔操作后闭经要想到宫腔粘连）→ **病变环节**（下丘脑、垂体、卵巢、子宫四级，靠性激素与超声定位）→ **生殖道畸形**（原发性闭经伴周期性下腹痛者）。前两件在诊室就能做，后两件决定要不要转。

**崩漏是同一个出血的两种形态：** 暴下不止为崩中，淋漓不尽为漏下。二者常互相转化——血崩日久气血耗伤可转为漏，久漏不止也可突然暴崩，所以教材把它们合称而不分开治。病机一句话：《景岳全书·妇人规》说「崩漏不止，经乱之甚者也」，其本在肾、其标在冲任。

崩漏的治法是一套**时序**，不是三张方：**塞流**（暴崩之际固气摄血、止血防脱，急则治标）、**澄源**（血势缓或血止后审因论治：脾虚补气摄血、肾虚补肾固冲、血热清热凉血、血瘀化瘀止血）、**复旧**（血止之后固本培元、恢复周期）。三法不可截然分割，但顺序不能倒——**先止血，再找因，最后修周期**；反过来做，等于在漏水的屋里讨论装修。

崩漏按年龄换判据：青春期多肾虚，育龄期多血热与血瘀，绝经过渡期多脾虚与肾虚。这不是学术偏好——同一套四栏在三年龄段指向不同病因：**绝经过渡期反复出血，第一位要排内膜病变。**

## 二、十二个「经行」病：一条共同模板

十二个病名各不相同，判据却是同一条：**症状随月经周期反复发作，经净后自止。** 教材在每一病的概述里都写了这半句，它是这组病的定义性特征，也是与「恰好赶上经期的别的病」的分界线。凡不符合「周期性发作＋经净自止」的，一律不按经行病论治。

| 病 | 主证（虚实两分） | 治法方向 |
|---|---|---|
| 经行乳房胀痛 | 经前胀甚于痛、痛不可触衣、随情绪增减（肝郁）／经后隐痛、乳房柔软（肝肾亏虚） | 疏肝理气／滋养肝肾 |
| 经行发热 | 经前午后潮热、五心烦热（阴虚）／经行经后热势不扬、动则汗出（气血虚）／经前发热伴腹痛拒按、色紫暗有块（瘀热） | 调气血、和营卫 |
| 经行头痛 | 经前胀痛掣痛拒按（肝火、血瘀）／经后隐痛空痛喜按（血虚）／头重如裹（痰湿） | 清热平肝／活血通络／养血 |
| 经行身痛 | 经后隐痛麻木、按之舒适（血虚）／经前剧痛有定处、得热减（血瘀） | 养血柔筋／活血通络 |
| 经行泄泻 | 溏薄完谷不化、脘腹胀满（脾虚）／黎明前泻、泻后则安、畏寒（肾虚） | 健脾化湿／温肾固肠 |
| 经行吐衄 | 量多色鲜红、口苦易怒（肝经郁火）／量少色红、潮热颧红（肺肾阴虚） | 清降逆火、引血下行 |
| 经行口糜 | 溃疡色淡灰白、疼痛轻（阴虚火旺）／色红痛剧、口臭便秘（胃热） | 滋阴降火／清胃泄热 |
| 经行风疹块 | 色淡苍白、夜间痒甚、面色无华（血虚）／色红灼热、遇热加重（风热） | 养血祛风／疏风清热 |
| 经行眩晕 | 经后眩晕、劳累加重（血虚）／经前头胀痛、心烦（阴虚阳亢）／头重如蒙、胸闷泛恶（脾虚夹痰） | 补血／滋阴潜阳／化痰 |
| 经行浮肿 | 按之凹陷、畏寒便溏（脾肾阳虚）／随情志增减、经行不畅（气滞血瘀） | 温肾健脾／理气活血 |
| 经行情志异常 | 烦躁易怒、胸胁胀满（肝郁）／狂躁、语无伦次、口苦而黏（痰火）／悲伤欲哭、恍惚（心血不足） | 疏肝／豁痰清心／养心安神 |
| 经断前后诸证 | 烘热汗出、五心烦热（肾阴虚）／畏寒肢冷、面浮肢肿（肾阳虚）／寒热错杂（阴阳俱虚） | 滋肾／温肾／调阴阳 |

读这张表要读出三件事。**其一，虚实的分界线几乎都在「经前还是经后」与「喜按还是拒按」上。** 经前发作、拒按、痛势剧者多实；经后发作、喜按、隐痛者多虚。这条规律贯穿十二个病，比逐个背证型省力。

**其二，病位可以从「症状落在哪一窍」反推。** 乳房属胃、乳头属肝；头为诸阳之会，前额属阳明、两侧属少阳、巅顶属厥阴、后头属太阳；口为脾窍、舌为心苗；皮肤属肺而赖营血。教材在每一病都写了这一句，它的用处是**引经**——同一味药在不同经络的病里加与不加，差别在此。

**其三，经断前后诸证不按「经净自止」判。** 它看年龄（45～55 岁）与一组症状，且必须**先排甲状腺、心血管、精神疾病与肿瘤**。教材把鉴别写在辨证之前，这一顺序值得照搬。

## 三、成组判据与必转红线【教学设定】

单条症状不定证，成组才定。下表为本章教学设定。

| 判为 | 成立需 | 不成立 |
|---|---|---|
| 血枯（闭经之虚） | 经量渐少而闭＋面色萎黄／腰膝酸软＋舌淡脉细 | 骤然停闭而无虚象 |
| 血隔（闭经之实） | 骤然停闭＋小腹胀痛拒按＋舌紫黯脉沉涩 | 只有闭经无胀痛 |
| 脾虚崩漏 | 量多色淡质稀＋神疲气短＋舌淡胖脉缓弱 | 只有量多 |
| 血热崩漏 | 色深红质稠＋口渴心烦＋舌红脉数 | 只有色红 |
| 血瘀崩漏 | 色紫暗有块＋小腹疼痛拒按 | 只有血块 |

**必转红线【教学设定】**——识别即转，止血与抢救先于辨证：

1. 暴崩下血、面白、冷汗、四肢厥逆、脉微欲绝（气随血脱）——立即急救并转急诊。
2. 出血量多致头晕心悸、血红蛋白明显下降。
3. 绝经过渡期反复出血、经期延长淋漓不净（须排内膜病变）。
4. 育龄期闭经未排妊娠；停经后腹痛＋流血（异位妊娠）。
5. 人流或宫腔操作后闭经（宫腔粘连）。
6. 原发闭经伴周期性下腹痛、性征发育异常（生殖道畸形）。
7. 经行情志异常出现自伤或伤人倾向——需安全监护与精神科会诊。
8. 经断前后症状伴甲状腺、心血管异常指征者，先查因。

第八条不是「急」，而是「不能只当更年期」。

## 四、调治动作、记录字段与失效模式

动作分三层。**第一层是时序**：出血类先塞流后澄源再复旧；闭经类先排因再补或通。**第二层是换判据**：闭经用血枯／血隔，崩漏用年龄，十二个经行病用「经前实、经后虚」。**第三层是调周**：无论哪一类，血止或经通之后都要回到四段——经后期滋肾填精、经间期补肾促排、经前期温肾助阳、行经期活血调经。

三条约束值得单记：崩漏「止血须审因，不可一味固涩，以免留瘀」；闭经「不可一见闭经即投破血通经」；经行吐衄「不可见血止血而妄投止涩」。三条说的是同一件事——**见血止血与见闭即通，是本章最贵的两个直觉。**

七栏记录，「周期相关性」单列一栏，因为它是十二病的定义性判据：

| 字段 | 记什么 | 例 |
|---|---|---|
| 周期相关性 | 是否随周期反复、经净是否自止 | 连续三个周期，经净即止 |
| 主症与时机 | 症状＋落在经前／经期／经后 | 头痛，经前 3 天起 |
| 两栏 | 量、色质（出血类必记） | 量多；色紫暗有块 |
| 兼症 | 痛的性质、情志、二便、寒热 | 小腹拒按、块下痛减 |
| 证型与年龄判据 | 虚／实＋年龄段 | 血瘀（育龄期） |
| 红线筛查 | 八条逐条打勾 | 妊娠试验阴性，余阴性 |
| 转诊 | 转与不转 | 不转 |

**四种失效模式。**

**一、把生理当病理。** 初潮后 1 年内暂闭、哺乳期闭经、绝经前后停经、偶发一次经期头痛——教材都写在「不作病论」里。误治的代价是给生理过程用药。

**二、周期不分期。** 崩漏的塞流只在出血期成立，血止后仍塞流就是留瘀；闭经的攻伐只在实证成立，经通后仍攻就是耗血。经行病更是如此：经前治实、经后治虚，方向相反。

**三、以调经代替查因。** 本章的四个陷阱：宫腔粘连（闭经）、内膜病变（绝经过渡期出血）、生殖道畸形（原发闭经）、甲状腺与精神疾病（经断前后、情志异常）。它们都能被「调经」改善一点，于是被反复调经。

**四、延误转诊。** 气随血脱、异位妊娠、内膜病变三类最贵。教材对气随血脱写得很直接：急予固脱救逆，并立即转急诊，采取输血、补液、止血及诊断性刮宫等中西医结合抢救，「不可延误」。

## 五、代价与边界

**第一层，三法（塞流、澄源、复旧）在实际执行中常被压平成「一个方吃到底」。** 原因是三法共享一组固涩药，方子看起来相似；差别在时机与配伍。**同名同方而时机不同，效果相反**，这是本章最难教的一点。

**第二层，十二个经行病的模板会诱使「套模板」。** 「经前实、经后虚」覆盖大多数，但经行情志异常的痰火、经行吐衄的阴虚火旺都不完全服从；模板是起点，不是结论。

**第三层，胞宫计数最低提示了本章的视野缺口。** 十二病大多落在全身，若只读本章，会以为妇科病可以脱离胞宫谈。其实这些症状的根仍在轴上，只是表现不在胞宫。

**第四层边界，本章不含带下、胎产、癥瘕。** 崩漏与癥瘕的鉴别、闭经与不孕的关系，分别在第 9、10、12 章；本章只到「转诊」与「排因」为止。

本章为教学整理，**免责声明：** 不构成诊疗建议，不能替代医师面诊；异常出血与闭经须先排除妊娠及器质性病变，急症请立即就医。
