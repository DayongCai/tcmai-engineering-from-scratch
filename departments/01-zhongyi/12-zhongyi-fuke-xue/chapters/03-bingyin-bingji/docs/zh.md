# 第 3 章 · 妇科病因不是一张清单，是四个入口接三条通路

> **MOTTO:** 「血气者，喜温而恶寒，寒则泣而不能流，温则消而去之。」——《素问·调经论》（教材·第 3 章·3.1.1 引）
>
> **PROBLEM:** 本章 7 单元 11,099 汉字里，「病机」253 次、「病因」131 次，比值 1.9∶1；四个观察面计 冲任 113、胞宫 60、肾 49、肝脾 34——**冲任居首，全课程唯一**。复算：按 `units.json` 第 3 章各单元 `prose` 与 `views`／`levels` 词表逐词计数。这组数说明：本章名义上写「病因病机」，重心却在病机，且落在冲任。因为妇科病机不是「邪气进来打坏了什么」，是「四个入口各自把气血推到同一个瓶颈」。（三组＝病机／病因／证候表现；四个观察面＝肾／肝脾／冲任／胞宫）
>
> **双根因定位:** 环境逼迫（同一个「寒」，客于冲任是痛经、伤及脾阳是泄泻、与湿相合是带下，入口相同而通路不同，处理也不同）＋知识积累（脏腑、气血、冲任督带三套术语分节写就，读时必须并成一条链，否则「肾虚」与「冲任不固」会被当成两个病）

**教材出处:** 教材·第 3 章（3.1 病因、3.2 病机，2 节 7 单元 11,099 汉字）。

## 一、四个入口、三条通路：病机的坐标

### 入口一：淫邪——寒、热、湿各有各的走法

| 邪 | 主要来路 | 落点与所见，兼判据 |
|---|---|---|
| 寒 | 经期产褥冒雨涉水、久居阴冷、贪凉饮冷；素体阳虚 | 客冲任则血凝：后期、过少、痛经、闭经、癥瘕、不孕；产后受寒则腹痛、身痛、恶露不下。实寒拒按得热痛减，虚寒喜温喜按，脉沉紧或沉迟 |
| 热 | 温邪疫毒、暑热、辛辣温燥；阳盛、五志化火、阴虚 | 扰冲任则迫血妄行：先期、过多、经期延长、崩漏、经间期出血；灼胎元则胎漏；热毒蕴结则产后发热、盆腔炎、阴疮。实热舌红苔黄脉数有力，虚热五心烦热舌红少苔 |
| 湿 | 居处潮湿、冒雨、水中作业；脾失健运、肾阳不化 | 伤任带则带下多、阴痒、经行浮肿、子肿；聚痰阻冲任则闭经、不孕、癥瘕；困脾则经行泄泻、恶阻。重浊黏滞、缠绵反复 |

血得温则行，得寒则凝，故寒最常见。热易伤阴，而经行产后阴血本亏，清热必兼护阴。湿随兼邪转化为寒湿、湿热、痰湿——**这就是它缠绵难愈的原因**；治湿必先健脾。

### 入口二：情志——怒、思、恐各伤一脏

**怒伤肝。** 肝主疏泄、藏血、司血海。郁怒则气结，冲任失调：先后无定期、痛经、闭经、经前乳胀、癥瘕、不孕；化火迫血：先期、过多、崩漏、经行吐衄；横逆犯脾：经行泄泻、腹胀；气逆于上：经行头痛、脏躁。此类病证随情绪增减——**郁则重、舒则轻**，这是它的可验证特征。

**思伤脾、恐伤肾。** 思则气结于中，化源不足：过少、闭经、不孕；暗耗心血则为心脾两虚：经行失眠、脏躁。恐则气下，肾气不固：崩漏、胎漏、阴挺。《素问·举痛论》：「**百病生于气也**」——情志致病的机窍全在气机。

### 入口三：生活所伤——房劳、饮食、劳逸、损伤

- **房劳多产**：耗肾精、伤冲任，见后期、过少、闭经、崩漏、不孕、滑胎、阴挺。教材点明现代对应：多次人流、刮宫损伤内膜基底层，致宫腔粘连与继发不孕。
- **饮食四失**：生冷伤脾阳、血凝（后期、过少、痛经）；辛辣助热动血（先期、过多、崩漏）；肥甘生湿热痰浊（带下、闭经、不孕、癥瘕）；饥饱失常或过度节食则化源乏（后期、过少、闭经）。
- **劳逸两失**：劳力耗气、统摄无权（过多、经期延长、胎漏）；安逸气血壅滞（痛经、闭经、癥瘕、恶露不下）。
- **跌仆与手术**：孕期跌仆扰动胎元（胎漏、胎动不安）；非孕期瘀血内停、血不归经（崩漏、经期延长、痛经）；宫腔操作伤胞宫胞络（过少、闭经、粘连、不孕）。瘀血之证，色紫黯有块、块下痛减、脉涩。

### 入口四：体质与禀赋——内因，也是判据

体质的用处是「预判走向」，不是「下诊断」。教材六类：阳虚易感寒（后期、痛经）、阴虚易感热（先期、绝经前后诸证）、气虚冲任不固（胎漏、阴挺）、血虚血海空虚（过少、缺乳）、血瘀（痛经、癥瘕）、痰湿（多肥，带下、闭经）。年龄期亦改体质：青春期肾气未充、育龄期情志易郁、围绝经期阴阳失调。

禀赋不足则天癸迟至、冲任虚衰（初潮迟、闭经、子宫发育不良）。**先天畸形必须单列**：处女膜闭锁、阴道横隔、子宫发育不全、双子宫，可致经血潴留、原发性闭经、不孕——这类不是调经的对象，是矫治的对象。

### 通路一：脏腑——肾为主，肝为枢，脾为源

- **肾**以虚为主：气虚则冲任不固（过多、崩漏、胎漏、滑胎）；阳虚则胞宫失温（后期、闭经、宫寒不孕、带下清冷）；阴虚则血海空虚或虚火内扰（过少、闭经、绝经前后诸证）。补气、温阳、滋阴，须阴中求阳、阳中求阴。
- **肝**四路：郁则气滞（先后无定期、经前乳胀）；火则迫血（过多、崩漏、吐衄）；阴虚阳亢、肝风内动（经行眩晕、子痫）；湿热下注（带下、阴痒）。用药宜轻灵，忌刚燥克伐。
- **脾**四路：统摄无权（过多、崩漏、胎漏、恶露不绝）；中气下陷（阴挺）；湿注任带（带下、浮肿）；湿聚成痰（闭经、不孕、癥瘕）。
- **心**三路：心脾两虚（经行失眠、脏躁）；心火、心肾不交（经行口疮、绝经前后诸证）；心血瘀阻（经行胸痛）。《素问·评热病论》「月事不来者，胞脉闭也……心气不得下通」，是从心论治闭经的原文依据。

### 通路二：气血——四端气病、四端血病，加一种急症

**气病四端**：气虚（冲任不固）、气滞（郁则血滞）、气逆（怒则气上：吐衄、恶阻）、气陷（阴挺、崩漏、带下）。**血病四端**：血虚（血海空虚）、血瘀（血不归经或不通则痛）、血热（迫血妄行）、血寒（血凝不行）。

气血同病三种常见、一种危急：气血两虚、气滞血瘀、气虚血瘀之外，是**气随血脱**——崩漏或产后大出血，血去气脱，症见突然晕厥、面白、汗出肢冷、脉微欲绝，即产后血晕之危候，须立即益气固脱并转急诊。《灵枢·五音五味》「妇人之生，有余于气，不足于血」是这条通路的生理前提。

### 通路三：冲任督带——四条通路合成一个瓶颈

冲为血海、任主胞胎，二脉皆起于胞中。冲任损伤四端：**不固**（气虚或肾虚：过多、胎漏、滑胎）、**虚衰**（房劳多产、久病：过少、闭经、不孕）、**阻滞**（寒、气、痰、瘀：痛经、癥瘕）、**伏热**（肝郁化火或阴虚：崩漏、吐衄）。

督脉总督诸阳，虚则胞宫失温（后期、宫寒不孕、腰脊酸冷）；带脉束诸经，失约则带下多、阴挺、胎漏。胞宫胞络损伤分直接（跌仆、房劳、孕产过频、手术）与间接（脏腑气血失常累及）两路。

三条通路串联：**脏腑功能失常 → 气血失调 → 冲任损伤 → 胞宫失养或失约。** 这就是本章「冲任」113 次排第一的原因——它是前两条通路的汇合处。

## 二、问诊与检查项：先定位入口，再定位通路

【教学设定】病因问诊的价值不在「问出几个邪」，而在**确定入口与通路的对应**。同一句话在不同入口下指向不同通路，故先问入口：

1. **起病与诱因。** 受寒、情志、房劳、饮食、外伤还是术后？起病有时间点，多能指到一个入口。
2. **加重与缓解条件。** 得温则减（寒）、随情绪波动（气）、劳累后重（虚）、按压加重（实）——比症状本身更能定性。
3. **病程与复发。** 缠绵反复多属湿或痰；与周期同步多属气或血；逐月加重须先排器质。
4. **体质、既往与舌脉。** 畏寒还是怕热、易怒还是多思、形体肥瘦、产育与宫腔操作史；带下量色质味与舌脉用于通路定位。

【教学设定】检查项按「入口—通路」的最小组合开：疑虚看血红蛋白与超声；疑湿或热看带下性状与血象；疑瘀看超声与内膜；疑畸形须妇科检查与影像，必要时遗传学检查。

## 三、成组判据与必转红线【教学设定】

单个症状不定病机，成组才定。下表为本章教学设定：每行一条「入口—通路—病性」三元组，缺一元不成立。

| 判为 | 入口证据 | 通路证据 | 病性 |
|---|---|---|---|
| 寒凝血瘀 | 受寒史、得温痛减 | 冲任阻滞，色紫黯有块 | 实寒 |
| 阳虚内寒 | 素体畏寒、腰膝冷 | 肾阳不足，带下清冷 | 虚寒 |
| 肝郁气滞 | 情志诱因、随情绪增减 | 肝失疏泄，经前乳胀 | 气滞兼瘀 |
| 湿热下注 | 嗜食肥甘、居处潮湿 | 任带受损，带下黄稠秽臭 | 实 |
| 肾气不固 | 房劳多产、腰酸 | 冲任不固，量多或胎漏 | 虚 |

**必转红线【教学设定】**——识别即转，止血与支持先于辨证：

1. 大出血后晕厥、面白、汗出肢冷、脉微欲绝（气随血脱／产后血晕）——立即急救并转诊。
2. 出血多致头晕心悸、血红蛋白明显下降。
3. 高热寒战伴下腹剧痛、带下臭秽。
4. 妊娠期跌仆或撞击后腹痛、阴道流血。
5. 宫腔操作后发热、腹痛、闭经伴周期性下腹痛。
6. 原发性闭经＋周期性下腹痛＋性征发育异常（生殖道畸形）。
7. 育龄期停经伴一侧下腹剧痛（异位妊娠）。
8. 绝经后出血。

八条与第 1、2 章同构：**不是「重证」，是「换了处理体系」。**

## 四、调治动作、记录字段与失效模式

病机定了，动作只剩三段：**去入口、断通路、调轴位。** 去入口是移走可移除的病因（避寒、调情志、节房劳、改饮食）；断通路是按三元组选法（寒则温经散寒、热则清热凉血、湿则健脾化湿、郁则疏肝、虚则补益、瘀则活血）；调轴位是回到肾肝脾与冲任。顺序上，**治病求因在前，调理冲任在后**。

七栏记录，把「入口—通路—病性」压成一行，因为它是全表的判据骨架：

| 字段 | 记什么 | 例 |
|---|---|---|
| 入口 | 淫邪／情志／生活／体质 | 淫邪：寒 |
| 通路 | 脏腑／气血／冲任督带 | 冲任（阻滞） |
| 病性 | 寒热虚实 | 实寒兼瘀 |
| 段位与轴位 | 周期第几段／产后第几天；取哪一环 | 行经第 1 天；冲任 |
| 红线筛查 | 八条逐条打勾 | 全阴性 |
| 转诊 | 转与不转 | 不转 |

**四种失效模式。**

**一、把生理当病理。** 阳虚畏寒不等于「宫寒」，痰湿易胖不等于「痰湿阻滞」。教材把体质写在病因里，是让你知道「容易往哪走」，不是下诊断。检查办法：问「有没有成组的三元组」。

**二、周期不分期。** 同一条通路在四段表现不同：气滞在经前最显，血虚在经后最显，寒凝在行经期最痛，湿热在经间期最重。不分期就把「经前疏肝」做成「经后疏肝」。

**三、以调经代替查因。** 三个最容易踩的坑：把宫腔粘连当血瘀、把生殖道畸形当闭经、把内分泌问题当肾虚。共同点是「调经也能见效一点」，于是被反复调经。检查办法：初诊必答「这个入口能不能被移走」。

**四、延误转诊。** 气随血脱最贵：它要求先止血固脱、同时转诊，而不是先辨气虚还是血热。顺序错，辨证再准也无用。

## 五、代价与边界

**第一层，「四个入口」是穷举，不是排序。** 教材并列四者，读起来像四选一；临床上常叠加：产后受寒又郁怒又劳倦的人，四个入口全开。并列结构给你的是「都要问」，不是「只选一个」。

**第二层，「三条通路」是串联模型，会掩盖并联。** 癥瘕、不孕、畸形这类有明确器质基础的，通路只是表象。串联模型越顺，越容易把器质读成功能。

**第三层边界，冲任居首是本章的写法，不是全书的写法。** 各章重心不同，把本章权重当全科权重，会把辨证做成「什么都往冲任上挂」。本章不含治法方药——治法在第 5 章，病证在第 7 至 12 章。

本章为教学整理，**免责声明：** 不构成诊疗建议，不能替代医师面诊；出血、感染、妊娠相关情况须立即就医。
