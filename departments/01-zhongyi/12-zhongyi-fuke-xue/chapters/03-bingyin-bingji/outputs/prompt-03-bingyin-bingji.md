# 四入口三通路：病因走到哪条路

## 用途

妇科病因与内科同名单不同权重。本单强制写出「入口 → 通路 → 典型表现」，避免只写一个「寒凝血瘀」了事。

## 入口一：四类

| 入口 | 妇科特点 | 追问 |
|---|---|---|
| 淫邪 | **寒为第一**（血得温则行，得寒则凝），分内外寒 | 有无经期涉水、贪凉、久居湿地；是否素体畏寒 |
| 情志 | 数伤于血＋多思善虑，怒伤肝最重 | 情绪、压力、经前烦躁是否相关 |
| 生活所伤 | **房劳多产**（含人工流产） | 孕产次数、房事、手术史 |
| 体质 | 决定「同因异证」 | 阳虚／阴虚／气虚／气郁 |

## 通路二：三条

| 通路 | 表现 |
|---|---|
| 脏腑 | 肾（腰膝酸软、头晕耳鸣、小便频数）／肝（胀痛游走、叹息）／脾（纳差、便溏、乏力） |
| 气血 | 气虚（量多色淡、气短）／气滞（胀痛、乳胀）／血瘀（刺痛、色暗有块）／血热（色深红、心烦） |
| 冲任督带 | 不固（量多、崩漏、胎漏）／虚衰（后期、量少、闭经）／瘀阻（痛经、癥瘕）／寒凝或热盛 |

## 输出

```text
入口：淫邪(寒) / 情志 / 房劳多产 / 体质
通路：脏腑(肾肝脾) / 气血 / 冲任督带
典型表现：…
对应证型方向：…
```
