# 六字定位：块、痛、孕、痒、脱、情

## 用途

杂病六证不属于经带胎产，判据也不同——先按一个字定位，再辨证型。

| 字 | 病证 | 首要问题 |
|---|---|---|
| 块 | 癥瘕 | 有形固定（癥）还是聚散无常（瘕）？增长快不快？ |
| 痛 | 妇人腹痛 | 是否随周期（随周期归第 7 章痛经）？是否急腹症？ |
| 孕 | 不孕症 | 夫妇同查了吗？排卵/输卵管/宫腔有无问题？ |
| 痒 | 阴痒 | 查过病原吗？ |
| 脱 | 阴挺 | 分度如何？重度是否需手术？ |
| 情 | 脏躁 | 是否需精神心理协作？ |

## 证型与方（不含剂量）

- 癥瘕：气滞血瘀（香棱丸）／痰湿瘀结（开郁二陈汤）／湿热瘀阻（银甲丸）／肾虚血瘀（补肾祛瘀方）；
- 妇人腹痛：肾虚血瘀（补肾祛瘀方）／湿热瘀阻（银甲丸）／气滞血瘀（膈下逐瘀汤）／寒湿凝滞（少腹逐瘀汤）；
- 不孕：肾气虚（毓麟珠）／肾阳虚（温胞饮）／肾阴虚（养精种玉汤）／肝郁（开郁种玉汤）／瘀滞胞宫（少腹逐瘀汤）／痰湿（启宫丸）；
- 阴痒：湿热下注（龙胆泻肝汤）／肝肾阴虚（知柏地黄汤）；
- 阴挺：气虚下陷（补中益气汤）／肾虚（大补元煎）；
- 脏躁：心血不足（甘麦大枣汤）／阴虚火旺／肝郁（百合地黄汤合甘麦大枣汤）。

## 红线

癥块增长快、质硬、消瘦、异常出血 → 转专科排除恶性；急腹痛 → 先排除蒂扭转、黄体破裂、急性盆腔炎。

## 输出格式

```text
定位：块/痛/孕/痒/脱/情
证型与方（不含剂量）：…
须先做的检查或转诊：…
```
