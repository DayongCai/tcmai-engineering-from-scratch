# 保健的核心不是「做什么」，是每个阶段「不许做什么」 · 提示词

## 用途

给「保健的核心不是「做什么」，是每个阶段「不许做什么」」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「五个阶段与各自的「别做什么」 → 每一阶段要记录什么 → 成组判据与必转红线【教学设定】 → 调护动作与失效模式」这条链。

## 提示词

```
我在学《中医妇科学》第 6 章「保健的核心不是「做什么」，是每个阶段「不许做什么」」，本章 6 节 / 3,018 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 禁忌之所以成立，是因为它对着一个具体的生理状态
   - 其一，只记能自测的
   - 其二，记「变化」不记「状态」
   - 其三，异常项单列
   - 判断「这还在生理范围内，还是该就医了」
   - 必转红线【教学设定】
4. 指出本章写到类别就止步、不再给参数的地方。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

不构成诊疗建议，不能替代医师面诊；具体操作以现行规范与所在机构制度为准。
