# 阶段—机制—禁令

## 用途

保健建议若只给禁令，患者记不住也不执行。本单要求每条建议先说清「此期身体如何」，再说「所以禁什么」。

## 五阶段

| 阶段 | 身体状态 | 三条最要紧的禁令 |
|---|---|---|
| 经期 | 血室正开、泻而不藏、气血相对不足 | 忌寒凉生冷／忌涉水冷水浴与房事／忌剧烈运动与大怒 |
| 孕期早期 | 胎元初结、根基未固 | 忌提重物与剧烈运动／忌长途颠簸／慎用药与房事（不必绝对卧床） |
| 孕期中晚期 | 胎儿渐长、负担日重 | 忌久立久坐／忌弯腰负重／适度散步 |
| 产褥期（6–8 周） | 百脉空虚、腠理疏松、多虚多瘀 | **避风寒**、汗出擦干／不宜绝对卧床／居室通风 |
| 哺乳期 | 血化为乳、气血与肝气决定乳量 | 乳头清洁防皲裂与乳痈／内衣不束胸／哺乳前热敷按摩 |
| 绝经期 | 肾气衰、天癸竭、冲任虚、阴阳失调 | 调情志／适劳逸／定期检查（异常出血须排查） |

## 输出

```text
阶段：…
身体状态：…
三条禁令：1…2…3…
违反后果：<对应病证>
```
