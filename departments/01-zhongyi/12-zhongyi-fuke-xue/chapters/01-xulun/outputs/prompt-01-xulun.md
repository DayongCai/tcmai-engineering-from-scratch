# 一个病名归轴：五类 → 轴位 → 年龄 → 判据

## 用途

妇科病名多，初学者容易背名字而不见结构。本单用四步把任意病名放回结构里：**先分类，再定轴位，再看年龄，最后确认判据是哪几项**。

## 第一步：属五类中的哪一类

| 类 | 例 |
|---|---|
| 月经病 | 先期、后期、先后无定期、过多、过少、经期延长、经间期出血、崩漏、闭经、痛经、绝经前后诸证 |
| 带下病 | 带下量多、色质气味异常 |
| 妊娠病 | 恶阻、胎漏、胎动不安、滑胎、妊娠肿胀 |
| 产后病 | 产后发热、恶露不绝、缺乳、产后身痛 |
| 妇科杂病 | 癥瘕、不孕、阴挺、脏躁 |

## 第二步：落在轴的哪一环

肾（精与天癸）→ 冲任（血海与胞胎）→ 胞宫（藏泻）。再补肝脾：肝主疏泄（气机）、脾主生血与统摄。

问法：「这个病，是源不足（肾）、路不通（肝郁气滞）、血不足（脾）、还是执行环节失常（冲任／胞宫）？」

## 第三步：年龄阶段该从哪一脏论

| 期 | 主导 | 常见病 |
|---|---|---|
| 青春期 | 肾 | 初潮延迟、稀发、闭经、痛经 |
| 育龄期 | 肝（兼脾） | 先后无定期、经前乳胀、不孕、癥瘕 |
| 绝经期 | 脾（兼肾） | 绝经前后诸证、带下异常 |

## 第四步：判据是期量色质中的哪几项

期（节律）、量（多少）、色（寒热）、质（瘀滞）。带着下则加量色质味；带产后则加虚瘀与二便。

## 输出格式

```text
病名：… ｜ 五类中的：…
轴位：肾 / 肝脾 / 冲任 / 胞宫（依据）
年龄期主导脏：…
判据要素：期·量·色·质（勾选）
```
