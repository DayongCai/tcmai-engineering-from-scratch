# 虚瘀定位：两个动作，十个出口

## 用途

产后病十个病证共用一条轴（多虚多瘀）。本单用两个床边动作先定偏虚偏瘀，再落到具体出口——不这样做，就会按病名各开一张方，越治越乱。

## 第一步：两个床边动作

| 动作 | 判读 |
|---|---|
| 察小腹痛与不痛 | 隐痛喜按＝虚；刺痛拒按、恶露量少色黯有块＝瘀 |
| 察大便通与不通 | 便秘多因血虚津亏 |

## 第二步：定「偏虚／偏瘀」

总纲：产后**多虚多瘀**；原则是**不可因虚概补、不可因瘀概攻**。

## 第三步：落到十个出口

| 出口 | 虚 | 瘀／实 |
|---|---|---|
| 发热 | 血虚（补中益气汤） | 感染邪毒（五味消毒饮合失笑散）／血瘀（生化汤） |
| 腹痛 | 血虚（肠宁汤） | 血瘀（生化汤） |
| 恶露不绝 | 气虚（补中益气汤）／阴虚血热（保阴煎） | 血瘀（生化汤） |
| 身痛 | 血虚（黄芪桂枝五物汤）／肾虚（养荣壮肾汤） | 风寒湿（独活寄生汤）／血瘀（身痛逐瘀汤） |
| 自汗盗汗 | 气虚（黄芪汤）／阴虚（生脉散） | — |
| 缺乳 | 气血虚弱（通乳丹） | 肝郁（下乳涌泉散） |
| 乳汁自出 | 气虚（补中益气汤） | 肝经郁热（丹栀逍遥散） |
| 情志异常 | 心血不足（归脾汤） | 肝郁（逍遥散） |
| 小便不通 | 气虚（补气通脬饮）／肾虚（济生肾气丸） | 气滞（木通散） |
| 大便难 | 血虚（润肠丸）／气虚（八珍汤加味） | — |

## 第四步：红线

高热＋恶露臭秽＋下腹压痛（产褥感染）｜大出血｜意识异常 → 立即就医。

## 输出格式

```text
定位：偏虚 / 偏瘀（依据两个动作）
出口：十证之一
证型与方（不含剂量）：…
红线：<无 / 命中>
```
