# 第 11 章 · 产后的所有病，都从「多虚多瘀」这一条轴上分出去

> **MOTTO:** 「新产妇人有三病：一者病痉，二者病郁冒，三者大便难。」——《金匮要略·妇人产后病脉证并治》（教材·第 11 章·11.1.1 引）
>
> **PROBLEM:** 本章 50 单元 26,983 汉字里，「病机」211 次、「证候表现」172 次、「病因」144 次；四个观察面则是全书最「平」的一章：肾 31、肝脾 31、胞宫 26、冲任 21，四轴相差不到一半。复算：按 `units.json` 第 11 章各单元 `prose` 与 `views`／`levels` 词表计数。四轴均摊说明一件事：**产后病不由某一个脏腑主导，而由一种共同的体质状态主导**——虚与瘀同时在场。所以本章的骨架不是脏腑，是一个轴心加十个出口；每个出口的判据都要回答同一个问题：这一症是偏虚，还是偏瘀。（三组＝病机／病因／证候表现；四个观察面＝肾／肝脾／冲任／胞宫）
>
> **双根因定位:** 环境逼迫（同一个「产后发热」，感染邪毒要急清急下、血虚要养血、血瘀要化瘀，三者的处置方向彼此排斥，而症状只写「发热」）＋知识积累（三病、三冲、三审三套旧框架分别出自《金匮要略》《医宗金鉴》与教材，各管一段，不并起来就无法覆盖从产房到产褥末的全过程）

**教材出处:** 教材·第 11 章（11.1 产后发热、11.2 产后腹痛、11.3 产后恶露不绝、11.4 产后身痛、11.5 产后自汗盗汗、11.6 缺乳、11.7 乳汁自出、11.8 产后情志异常、11.9 产后小便不通、11.10 产后大便难。10 病各 5 单元，共 50 单元 26,983 汉字）。

## 一、一条轴与三个旧框架

产后的体质状态只有六个字：**多虚多瘀。** 虚来自分娩耗气伤血（气随血耗、百脉空虚、腠理疏松），瘀来自胞宫复旧过程中余血浊液的排出不畅（败血留滞）。二者不是先后关系，是**同时在场**——所以教材给的治则是「勿拘于产后，亦勿忘于产后」：不可因虚而概用补益，也不可因瘀而概用攻逐。

围绕这条轴，教材并置了三个旧框架，各管一段：

- **三病**（《金匮要略》）：病痉、病郁冒、大便难。它管的是**新产之初**三种因亡血伤津而起的急变。
- **三冲**：败血上冲。它管的是**瘀的走向**——瘀不下行而上逆，冲心、冲肺、冲胃，各有危候。
- **三审**（《医宗金鉴》）：先审小腹痛与不痛，以征恶露之有无；次审大便通与不通，以征津液之盛衰；再审乳汁行与不行，以征胃气之充馁。它管的是**当下**——用三个可观察项把虚实瘀定位。

三个框架的次序不能颠倒：三病看急、三冲看危、三审看常。**急与危先过，常后辨。**

## 二、十个出口

十个病名各占一个出口，判据都落在「虚／瘀」的偏向与「病位」上。

| 病 | 判据要点 | 病机偏向 |
|---|---|---|
| 产后发热 | 产褥期内发热持续或突发高热寒战 | 四因：感染邪毒（最凶险）、外感、血虚、血瘀；兼因食滞、蒸乳 |
| 产后腹痛 | 小腹疼痛，拒按或喜按 | 血瘀（拒按、恶露少色黯）／血虚（喜按、恶露淡） |
| 产后恶露不绝 | 血性恶露持续 10 日以上仍淋漓不断 | 气虚为本，血热与血瘀为标 |
| 产后身痛 | 肢体关节酸痛麻木 | 血虚失养／血瘀阻滞／外感 |
| 产后自汗盗汗 | 汗出过多，不能自止 | 气虚卫外不固／阴虚内热 |
| 缺乳 | 乳汁甚少或全无 | 气血虚弱（化源不足）／肝郁气滞（乳络不畅） |
| 乳汁自出 | 乳汁不经吮吸而自出 | 气虚不摄／肝经郁热 |
| 产后情志异常 | 情绪低落、烦躁、悲伤欲哭，甚则恍惚 | 心血不足／肝郁／痰火 |
| 产后小便不通 | 产后 6～8 小时膀胱充盈而不能自行排尿 | 膀胱气化不利：气虚、肾虚、气滞（或瘀） |
| 产后大便难 | 大便艰涩，数日不解 | 血虚津亏／气虚推动无力 |

三处需要特别记住的「分界句」。

**产后发热的分界最要紧：** 新产后一二日因阴血骤虚、阳气易浮而见轻微发热，**不作病论**。这一句把生理性发热挡在诊断之外，也决定了「产后发热」的第一问是「第几天」。四因之中教材明确「感染邪毒最为凶险」——可致热入营血、内陷心包，见高热神昏、斑疹隐隐之危候。

**恶露不绝的分界是一个天数与一个总量：** 血性恶露约 3～4 日转浆液性，浆液性约 2 周排尽，白色约 3 周干净，总量约 250～500 毫升（教材原值）；血性恶露**持续 10 日以上**仍淋漓不断，才叫恶露不绝。教材另加一句判断：恶露量多、色质异常并伴发热腹痛者，须警惕宫内残留与产褥感染，甚者可发展为晚期产后出血。

**小便不通的分界是一个时间窗：** 产后 6～8 小时膀胱充盈而不能自行排尿即属本病；而预防的动作在更早——指导产妇产后 4～6 小时内主动排尿。教材把预防写在治疗之前，因为膀胱过度充盈可致逼尿肌损伤，日久可致排尿功能障碍。

## 三、成组判据与必转红线【教学设定】

单条症状不定证，成组才定。下表为本章教学设定。

| 判为 | 成立需 | 不成立 |
|---|---|---|
| 感染邪毒（发热） | 高热寒战＋下腹压痛＋恶露臭秽 | 只有发热 |
| 血虚发热 | 低热＋面白心悸＋舌淡脉细 | 只有发热而恶露臭 |
| 血瘀发热 | 发热＋恶露少色黯有块＋小腹刺痛 | 只有发热 |
| 血瘀腹痛 | 小腹刺痛拒按＋恶露量少色黯有块＋块下痛减 | 只有腹痛 |
| 血虚腹痛 | 小腹隐痛喜按＋恶露淡＋面白 | 只有腹痛 |
| 气虚恶露不绝 | 量多色淡质稀＋神疲气短＋舌淡 | 只有淋漓不断 |
| 气血虚弱缺乳 | 乳汁清稀＋乳房柔软无胀感＋面白 | 只有乳汁少（须先核婴儿体重与尿量） |
| 肝郁缺乳 | 乳汁不行＋乳房胀痛＋情志不遂 | 只有乳汁少 |

缺乳那一行值得单说：教材要求**先观察婴儿体重增长与排尿次数**，判断乳汁是否真正不足，避免把生理性偏少当缺乳过度干预。这是全书少见的「先验证主诉」的判据。

**必转红线【教学设定】**——识别即转，抢救与转诊先于辨证：

1. 产后大量出血、血色鲜红，伴头晕心慌、面白、冷汗、脉微欲绝（血脱气亡）。
2. 高热寒战、下腹剧痛、恶露臭秽（产褥感染重症，防内陷心包）。
3. 产后晕厥、神昏、斑疹隐隐（热入营血或败血冲心）。
4. 恶露量多不止或干净后复又大出血（晚期产后出血）。
5. 产后 6～8 小时不能排尿且小腹胀急（尿潴留，须及时导尿）。
6. 乳房红肿热痛迅速扩大伴高热（乳痈）。
7. 产后情绪异常持续不缓解，或出现伤害自己与婴儿的念头。
8. 产后发热伴一侧下肢肿痛（须排血栓）。

第 1、3 条是「三病」「三冲」在现代的落点；第 8 条教材未列，但它与「产后早期活动可预防下肢血栓」一句互为表里，属同一风险的另一面。

## 四、调治动作、记录字段与失效模式

动作只有两句话：**虚者补之，瘀者行之，而补不留瘀、行不伤正。** 落到十个出口上，是两组方向的配比问题：偏虚者以补为主、佐以行（如恶露不绝用补气摄血，佐化瘀）；偏瘀者以行为主、佐以扶（如腹痛血瘀用生化汤类，佐养血）。教材给的旧戒「勿拘于产后，亦勿忘于产后」，说的就是这个配比——**它不是折中，是要求每一次都重新算一次比例。**

三条边界要背下来：产时产后失血多者，攻逐之品须减；恶露未净者，固涩之品须慎（留瘀）；哺乳期用药须权衡对婴儿的影响（第 6 章已列禁用四类）。

七栏记录，「第几天」放第一栏，因为产后发热、恶露、排尿三件都按天数判：

| 字段 | 记什么 | 例 |
|---|---|---|
| 产后第几天 | 分娩日期与天数；分娩方式 | 产后第 8 天，顺产 |
| 主症 | 发热（度数与起伏）／腹痛／恶露／汗／乳／二便 | 低热，午后为甚 |
| 恶露 | 量、色、质、味 | 量少、色黯、有块、无臭 |
| 三审 | 腹痛与否、大便通否、乳汁行否 | 小腹隐痛喜按；便干；乳汁清稀 |
| 偏虚偏瘀 | 虚／瘀／并见＋病位 | 血虚为主，兼瘀 |
| 红线筛查 | 八条逐条打勾 | 全阴性 |
| 转诊与停药 | 转与不转；停的条件 | 不转；热退即减清解 |

**四种失效模式。**

**一、把生理当病理。** 新产后一二日轻微发热、褥汗、恶露由血性转浆液再转白、产后数日情绪低落——四件都是生理，教材都写了「不作病论」。误治的代价在产后被放大：产妇本已虚，多余的药都是负担。

**二、周期不分期。** 产后的「期」是天数：新产之初看三病，产褥中期看恶露与发热，产褥末期看复旧与哺乳。同一个活血，产后第 2 天用是「化瘀生新」，恶露已净后用就是「耗血」。

**三、以调经代替查因。** 在产后这条改写成「以调补代替查因」：把宫内残留当恶露不绝、把产褥感染当血瘀发热、把尿潴留当气虚不化。三者都能被调补暂时缓解，代价是延迟了该做的超声与导尿。

**四、延误转诊。** 八条红线里第 1、2、3、4 条属于「分钟级」——产后出血与感染性休克的时间窗很短，教材对血脱气亡的处置写得极简：立即抢救并转诊。

## 五、代价与边界

**第一层，「多虚多瘀」是万能解释，也是万能借口。** 任何产后不适都能被这四个字覆盖，于是真正的感染、出血、抑郁被解释掉。教材把三病、三冲单列，正是给这四个字划出「急与危」的边界。

**第二层，十个出口的判据高度依赖「量、色、质、味」，而这四项在产后极难标准化。** 恶露的「量多」没有刻度，「臭秽」受卫生条件影响，故教材反复要求结合超声与血象。**四栏在产后是筛查，不是结论。**

**第三层，哺乳期用药的边界会削弱治法。** 四类禁用加上「权衡对婴儿的影响」，使清热、化瘀、攻下的力度都要打折；力度一降，见效就慢，而「勿拘于产后」又要求不能一味保守。**这是本章最需要逐案权衡的地方，也是最不该给统一答案的地方。**

**第四层边界，本章不含妊娠与不孕。** 堕胎小产后的调养虽同属产后范畴，但孕期本身的病在第 10 章；产后抑郁与情志异常在第 12 章脏躁处另有论述。本章只到产褥期结束为止。

本章为教学整理，**免责声明：** 不构成诊疗建议，不能替代医师面诊；产后出血、发热与排尿困难须立即就医，用药尤须考虑哺乳因素，由具备资质的医师决定。
