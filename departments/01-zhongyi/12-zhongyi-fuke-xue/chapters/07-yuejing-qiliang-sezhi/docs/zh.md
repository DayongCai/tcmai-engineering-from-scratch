# 第 7 章 · 月经病（一）：期、量、时间的三种异常

> **MOTTO:** 「经水不利，少腹满痛」——教材·第7章·7.7.1（《金匮要略·妇人杂病脉证并治》）
>
> **PROBLEM:** 本章八个病证，学生背得下名字，却常在同一张处方上犯错：**先期与过多同治、后期与过少同治**。教材的区分其实极清楚——先期/后期管「节律」，过多/过少管「量」，经期延长管「行经时间」，经间期出血管「时点」，痛经管「疼痛」。五个维度各管一件事，互相可以并存（先期＋过多、后期＋过少），也可以单独出现。
>
> **双根因定位:** 环境逼迫（同一个「月经不调」的主诉，可能落在五个维度中的任意一个，问错一栏就辨错证）+ 知识积累（本章 40 单元、31,433 字，**证候表现 494** 居三辨首位、**胞宫 112** 居四位面首位——它是全课程唯一「胞宫」居首的理论章，因为期量色质最终都落在胞宫的藏泻上；引书 24 部 69 次）

**教材出处:** 教材·第 7 章（7.1 先期、7.2 后期、7.3 先后无定期、7.4 过多、7.5 过少、7.6 经期延长、7.7 痛经、7.8 经间期出血，共 8 病证 40 单元）。本章数字由 `code/main.js` 读 `standards/fuke/units.json` 现算。

## 一、先分清维度，再辨证型

| 维度 | 病证 | 门槛（教材原值） |
|---|---|---|
| 节律 | 月经先期 | 提前 **7 天以上**，连续 **两个周期以上** |
| | 月经后期 | 延后 **7 天以上**，连续 **两个周期以上**；可至 3–5 个月一行 |
| | 先后无定期 | 时提前时延后 **7 天以上**，连续 **三个周期以上** |
| 量 | 月经过多 | 每次经量 **超过 80 mL**，周期与经期基本正常 |
| | 月经过少 | 每次经量 **少于 20 mL**，或点滴即净，或经期不足 2 天 |
| 时间 | 经期延长 | 行经时间 **超过 7 天**，甚或淋漓半月方净 |
| 时点 | 经间期出血 | 两次月经之间（氤氲之时）周期性少量出血，多持续 1–3 天 |
| 疼痛 | 痛经 | 经期或经行前后周期性小腹疼痛，或痛引腰骶，甚则剧痛昏厥 |

三个低频数字值得单独记（教材原值）：**80 mL / 20 mL / 7 天**——它们把「感觉多／少」变成可核的门槛。另外教材对每个病名都加了一句「偶见一次或提前三五日、无其他不适者，不作病论」，这是**排除波动**的统一口径。

## 二、先期（5 型）：气虚、肾虚、血热（三源）、肝郁化热

| 证型 | 治法 | 代表方 |
|---|---|---|
| 脾气虚（不摄血） | 补脾益气，摄血调经 | 补中益气汤（《脾胃论》） |
| 肾气虚 | 补肾益气，固冲调经 | 固阴煎（《景岳全书》） |
| 阳盛血热 | 清热凉血，固冲调经 | 清经散（《傅青主女科》） |
| 肝郁化热 | 疏肝解郁，清热调经 | 丹栀逍遥散（《内科摘要》） |
| 阴虚血热 | 养阴清热，凉血调经 | 两地汤（《傅青主女科》） |

记忆锚点：**先期的虚证在「不固」（气不摄），实证在「迫血」（热）。** 三种热要分清来源：素体阳盛（清经散）、情绪化火（丹栀逍遥散）、阴亏生热（两地汤）。

## 三、后期（6 型）：源不足 vs 路不通

| 证型 | 治法 | 代表方 |
|---|---|---|
| 肾虚（精亏） | 补肾益精，养血调经 | 归肾丸（《景岳全书》） |
| 血虚 | 补血养营，益气调经 | 滋血汤（《证治准绳》）；亦可人参养荣汤（《局方》） |
| 虚寒 | 温经扶阳，养血调经 | 温经汤（《金匮要略》）；亦可艾附暖宫丸（《仁斋直指方》） |
| 实寒（寒凝） | 温经散寒，活血调经 | 温经汤（《妇人大全良方》） |
| 气滞 | 理气行滞，活血调经 | 乌药汤（《济阴纲目》） |
| 痰湿 | 燥湿化痰，活血调经 | 苍附导痰丸（《叶天士女科诊治秘方》） |

**两个温经汤必须分清**（这是本章最常见的混淆）：《金匮》温经汤治**虚寒**（血色淡、腹冷喜温、脉沉迟），《妇人良方》温经汤治**实寒凝滞**（色暗有块、腹痛拒按、脉沉紧）。

## 四、先后无定期（3 型）与经期延长（3 型）

| 病证 | 证型 | 治法 | 方 |
|---|---|---|---|
| 先后无定期 | 肝郁 | 疏肝解郁，和血调经 | 逍遥散（《局方》） |
| | 肾虚 | 补肾益气，调理冲任 | 固阴煎 |
| | 肝郁肾虚 | 疏肝补肾，调理冲任 | 定经汤（《傅青主女科》） |
| 经期延长 | 气虚 | 益气摄血，固冲调经 | 举元煎（《景岳全书》） |
| | 阴虚血热 | 滋阴清热，凉血调经 | 两地汤合二至丸 |
| | 血瘀 | 活血化瘀，固冲调经 | 桃红四物汤合失笑散 |

先后无定期的第三型「肝郁肾虚」值得注意：教材把它单列，方用**定经汤**——因为临床上长期压力＋年龄增长常两因并存，只疏肝或只补肾都不效。

## 五、过多（3 型）与过少（4 型）

| 病证 | 证型 | 治法 | 方 |
|---|---|---|---|
| 过多 | 气虚 | 补气摄血，固冲调经 | 举元煎 |
| | 血热 | 清热凉血，固冲止血 | 保阴煎（《景岳全书》） |
| | 血瘀 | 活血化瘀，固冲止血 | 失笑散（《局方》） |
| 过少 | 肾虚 | 补肾益精，养血调经 | 归肾丸 |
| | 血虚 | 养血益气调经 | 滋血汤 |
| | 血瘀 | 活血化瘀调经 | 桃红四物汤（《医宗金鉴》） |
| | 痰湿 | 燥湿化痰，理气调经 | 苍附导痰丸 |

**过量与过少的「血瘀」是本章最反直觉的一对**：同样是血瘀，量多者用**失笑散**（化瘀以止血），量少者用**桃红四物汤**（化瘀以通经）。方向相反，理由相同——瘀不去则血不归经。

教材另给了一条进程判断：**后期与过少并见，日久可发展为闭经**；**过多与经期延长并见须结合辨治**。这两句把本章与第 8 章（闭经、崩漏）连了起来。

## 六、痛经（5 型）与经间期出血（3 型）

| 病证 | 证型 | 治法 | 方 |
|---|---|---|---|
| 痛经 | 气滞血瘀 | 行气活血，祛瘀止痛 | 膈下逐瘀汤（《医林改错》） |
| | 寒凝血瘀 | 温经散寒，化瘀止痛 | 少腹逐瘀汤（《医林改错》） |
| | 湿热瘀阻 | 清热除湿，化瘀止痛 | 清热调血汤（《古今医鉴》） |
| | 气血虚弱 | 益气养血，调经止痛 | 圣愈汤（《医宗金鉴》） |
| | 肾气亏损 | 补肾填精，养血止痛 | 调肝汤（《傅青主女科》） |
| 经间期出血 | 肾阴虚 | 滋肾养阴，清热止血 | 两地汤合二至丸 |
| | 湿热 | 清热利湿，凉血止血 | 清肝止淋汤（《傅青主女科》） |
| | 血瘀 | 化瘀止血 | 逐瘀止血汤（《傅青主女科》） |

痛经的辨证有两个床边问题：**痛在经前还是经后**（经前多实、经后多虚）、**喜按还是拒按**（喜按多虚、拒按多实）。教材把「剧痛昏厥」写进定义，是提醒：痛经也可以是需要排除器质性病变的症状（第 12 章杂病有对照）。

## 代价与边界

1. **本章只有方向与方名**，不含剂量与加减；经量门槛（80/20 mL）为教材原值，用于判断而非精确测量。
2. **痛经须排除器质性病变**：进行性加重、非经期也痛、伴不孕者，须查子宫内膜异位症等（第 12 章）。
3. **经间期出血须与排卵期生理性出血区分**：量少、1–3 天、偶发者未必是病。
4. **围绝经期与青春期不用同一套解释**：前者多肾气衰，后者多肾气未充（第 1 章年龄轴）。

本章为教学整理与文献梳理，**免责声明：** 不构成诊疗建议，不能替代医师面诊；异常子宫出血须由具备资质的医师诊治。
