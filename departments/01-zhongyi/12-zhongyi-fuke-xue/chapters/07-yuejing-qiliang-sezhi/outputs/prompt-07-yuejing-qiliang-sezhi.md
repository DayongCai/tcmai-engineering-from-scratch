# 五维定位：先问是哪一栏

## 用途

八个月经病（先期、后期、先后无定期、过多、过少、经期延长、痛经、经间期出血）分属五个维度。本单强制先定位维度，再辨证型——**维度错，证型必然错**。

## 五维与门槛

| 维度 | 病证 | 门槛 |
|---|---|---|
| 节律 | 先期／后期／先后无定期 | 提前或延后 **7 天以上**、连续 **2 个周期**（先后不定为 3 个周期） |
| 量 | 过多／过少 | **> 80 mL** / **< 20 mL** |
| 时间 | 经期延长 | 行经 **> 7 天** |
| 时点 | 经间期出血 | 两次月经之间，1–3 天 |
| 疼痛 | 痛经 | 经期或前后周期性小腹疼痛 |

未过门槛（偶发一次、三五日之差、无不适）→ **不作病论**。

## 该维度下的证型候选

| 维度 | 常见证型（方） |
|---|---|
| 先期 | 脾气虚（补中益气汤）／肾气虚（固阴煎）／阳盛血热（清经散）／肝郁化热（丹栀逍遥散）／阴虚血热（两地汤） |
| 后期 | 肾虚（归肾丸）／血虚（滋血汤）／虚寒（《金匮》温经汤）／实寒（《妇人良方》温经汤）／气滞（乌药汤）／痰湿（苍附导痰丸） |
| 先后无定期 | 肝郁（逍遥散）／肾虚（固阴煎）／肝郁肾虚（定经汤） |
| 过多 | 气虚（举元煎）／血热（保阴煎）／血瘀（失笑散） |
| 过少 | 肾虚（归肾丸）／血虚（滋血汤）／血瘀（桃红四物汤）／痰湿（苍附导痰丸） |
| 经期延长 | 气虚（举元煎）／阴虚血热（两地汤合二至丸）／血瘀（桃红四物汤合失笑散） |
| 痛经 | 气滞血瘀（膈下逐瘀汤）／寒凝血瘀（少腹逐瘀汤）／湿热瘀阻（清热调血汤）／气血虚弱（圣愈汤）／肾气亏损（调肝汤） |
| 经间期出血 | 肾阴虚（两地汤合二至丸）／湿热（清肝止淋汤）／血瘀（逐瘀止血汤） |

## 输出格式

```text
维度：节律/量/时间/时点/疼痛
过门槛：是/否（数值）
证型与方（不含剂量）：…
需排除：器质病变 / 妊娠 / 生理波动
```
