## 三、三辨与四位面（实测）

| 三辨 | 词频 | 四位面（疗法类别） | 词频 |
|---|--:|---|--:|
| **情志病因** | **3,474** | 情志相胜 | 197 |
| **心理诊断** | **447** | 认知与行为 | 381 |
| **心理治疗** | **1,099** | 气功与导引 | 143 |
|  |  | 针药与其他 | 144 |

三辨极差 **7.8×**；四位面极差 **2.7×**。

三辨 7.8× 是词表失真：本教材把「情志」当高频术语用（七情、五志、情志病、情志护理都计入），3,474 不能读成「病因占七成」。真正有信息量的是四位面：按疗法类别（2.7×）——认知与行为 381 / 情志相胜 197 / 针药 144 / 气功 143，四类接近，说明这本教材对中医疗法与现代心理疗法是并列介绍的。病证轴（B，6.6×）不取：癫狂痫只有 87 次，取了会把课写成「郁证与不寐 + 附赠」。
