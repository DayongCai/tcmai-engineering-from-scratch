# 心身疾病的干预，一半在治法，一半在把不确定说清 · 提示词

## 用途

给「心身疾病的干预，一半在治法，一半在把不确定说清」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「先把范围划清：心身疾病不等于「查不出病」 → 四条干预路径，各有强弱项 → 三档干预强度与三条会诊红线【教学设定】 → 调护的落点：四时、老人、小儿、病后」这条链。

## 边界

本章为教学材料，所述范围、路径与分档用于训练判断与交接，不构成医学意见、诊断或治疗建议；具体操作以现行规范与所在机构制度为准。
