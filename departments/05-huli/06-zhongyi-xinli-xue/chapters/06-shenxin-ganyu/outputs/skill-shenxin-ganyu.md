# 心身疾病的干预，一半在治法，一半在把不确定说清

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 参考件状态
- 一头，不能把「查不出病」等同于心身疾病
- 另一头，不能把「有器质病变」排除在心身之外
- 心身疾病不是排除性诊断，而是「两条线同时在」的诊断
- 先易后难、先短后长
- 静养与导引的关键不是功法，是「低门槛 + 固定时点」

## 边界

- 只写类别与要点，不写操作参数。
- 本章为教学材料，所述范围、路径与分档用于训练判断与交接，不构成医学意见、诊断或治疗建议。
