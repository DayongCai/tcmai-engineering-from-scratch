# 要证明一个干预有效，先得说清它跟什么比 · 提示词

## 用途

给「要证明一个干预有效，先得说清它跟什么比」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「四个问题，缺一个结论就不成立 → 五种设计，各自能回答什么 → 三档可信度：读一篇研究时怎么下判断【教学设定】 → 偏倚与报告字段」这条链。

## 提示词

```
我在学《中医心理学》第 8 章「要证明一个干预有效，先得说清它跟什么比」，本章 6 节 / 3,071 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 参考件状态
   - 「有效」永远是一个比较级
   - 对照的作用，就是让「无」也能被看见
   - 单组前后对照是所有设计里最常用、也最容易被高估的一种
   - 随机对照的代价是外推性
   - 中医与心理类干预还有四个特殊困难
4. 指出本章写到类别就止步、不再给参数的地方。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，所述设计要素、判断分组与报告字段用于训练阅读与设计能力，不构成医学意见、研究方案或统计建议；具体操作以现行规范与所在机构制度为准。
