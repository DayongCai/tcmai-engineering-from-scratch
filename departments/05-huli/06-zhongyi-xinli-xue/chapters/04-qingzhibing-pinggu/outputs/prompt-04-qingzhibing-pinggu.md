# 评估的功夫在提问，不在结论 · 提示词

## 用途

给「评估的功夫在提问，不在结论」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「四个入口，各有一条证据链 → 问情的六个技术动作 → 证据的三组状态与量表的位置【教学设定】 → 评估本身也是干预，边界同时成立」这条链。

## 边界

本章为教学材料，所述采集项、提问技术与分组方法用于训练评估能力，不构成医学意见、心理诊断或治疗建议；具体操作以现行规范与所在机构制度为准。
