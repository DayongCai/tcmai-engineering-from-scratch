# 中医心理学的第一道判断，是分清形与神各自的证据 · 提示词

## 用途

给「中医心理学的第一道判断，是分清形与神各自的证据」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「学科边界由三个动作划出，不由一段定义划出 → 采集项：形六项、神六项，每一项都要能被第二个人复核 → 成组判据：四档回答的是「先动哪一头」，不是严重度【教学设定】 → 干预动作与停、转的边界」这条链。

## 边界

本章为教学材料，所述观察项、分档与交接字段用于训练识别与判断，不构成医学意见、心理诊断或治疗建议；具体操作以现行规范与所在机构制度为准。
