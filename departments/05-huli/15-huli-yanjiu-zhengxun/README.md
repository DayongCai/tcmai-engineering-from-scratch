**三处覆盖不到的地方，已在对应章节正文中明写，不拿报告规范冒充方法学。**

## 六、代价与边界

- 本课**不编研究案例**：不写「某研究纳入了 N 例」，也不给任何具体的效应量与 P 值
- **不给公式推导与数值示例**：避免出现可被误当成结果的数字
- 证据 ≠ 处方：分级结论只说明「能信几分」，不说明「该怎么做」
- 伦理部分只讲准备与自查，审查结论以伦理委员会意见为准

**免责声明：** 本课正文用于教学与研究训练，不构成诊疗、护理、法律或投资意见；临床与管理处置以现行规范、院内制度与伦理委员会意见为准。
