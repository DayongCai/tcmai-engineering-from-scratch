# 质性研究不是聊天，是把重复说的话听成结构 · 提示词

## 用途

给「质性研究不是聊天，是把重复说的话听成结构」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「访谈要问出的是说法的边界，不是答案 → 抽样与饱和的判据 → 从码到主题的三步与留痕 → 动作、时限与记录字段」这条链。

## 提示词

```
我在学《护理研究与循证护理》第 3 章「质性研究不是聊天，是把重复说的话听成结构」，本章 6 节 / 3,381 汉字，习题 7 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 参考件说明
   - 一是追问具体事件，不追评价
   - 二是追问反例
   - 三是追问用词
   - 第一步，开放编码
   - 第二步，归并与比较
4. 指出本章写到类别就止步、不再给参数的地方。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

本章为教学材料，不构成医学意见、诊断或护理指导；具体操作以现行规范与所在机构制度为准。
