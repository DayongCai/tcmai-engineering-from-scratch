# 好选题不是灵感，是把一句抱怨压成一个能算的缺口 · 提示词

## 用途

给「好选题不是灵感，是把一句抱怨压成一个能算的缺口」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「抱怨和缺口之间隔着一张四槽位表 → 每个槽位要写到什么颗粒度 → 三条判据决定这个题能不能开 → 动作、时限与记录字段」这条链。

```

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```
