# 伦理审查不是盖章，是替不能到场的人提问 · 提示词

## 用途

给「伦理审查不是盖章，是替不能到场的人提问」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「审查问的是四个问题 → 同意书要写到什么颗粒度 → 弱势人群与免除知情的边界 → 动作、时限与记录字段」这条链。

## 提示词

```
我在学《护理研究与循证护理》第 8 章「伦理审查不是盖章，是替不能到场的人提问」，本章 5 节 / 3,434 汉字，习题 7 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 参考件说明
   - 第一件，风险是否已最小化
   - 第二件，风险与预期受益的比例是否合理
   - 第三件，知情同意是否真实、完整、自愿
   - 第四件，受试者的选择是否公正
   - 免除知情同意
4. 指出本章写到类别就止步、不再给参数的地方。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，不构成医学意见、诊断或护理指导；具体操作以现行规范与所在机构制度为准。
