# 第 8 章 · 伦理审查不是盖章，是替不能到场的人提问

> **MOTTO:** 「人命至重，有贵千金。」——《备急千金要方·大医精诚》。审查桌上坐着的是研究者与委员，真正该被代表的人不在场；审查的全部功夫，就是替他把话问出来。
>
> **PROBLEM:** 一份 18 页的方案送审，首轮反馈 11 条：知情同意 5 条，风险与受益 3 条，隐私与数据 2 条，弱势人群 1 条。5 + 3 + 2 + 1 = 11。逐条回溯，11 条里有 7 条指向同一处：同意书把可能的不适写成「可能会有轻微不适」，没有交代是什么不适、持续多久、出现后怎么处理。再看方案全文，涉及风险描述的只有 2 段，合计 3 句话；而涉及研究意义的段落有 5 段，合计 11 句。18 页里，研究者花了近两页说明这件事值得做，用了三句话说明受试者可能承受什么。这个比例本身就是审查意见的来源。
>
> **双根因定位:** 环境逼迫（方案要在申报截止前完成，审查被排在最后一步，此时研究设计已定、干预已排、数据表已印，任何涉及风险与同意方式的修改都意味着重做前面的工作，于是修改只能停在措辞层面）+ 知识积累（审查被理解成「填表与签字」，而不是「用四组问题去检验研究对人做了什么」；不知道审查问的是哪四件事，就只会照着上一份方案改格式）。

**参考件说明：** 本课程无足本参考件，不引页码、不引版次。以下框架依循涉及人的研究伦理审查的通行原则写成；具体要件、文书格式与审查程序以现行法规与所在机构伦理委员会的规程为准，本章不作替代。

## 一、审查问的是四个问题

无论文书格式如何变化，审查要回答的始终是四件事。四件事里任何一件答不上来，方案就不该通过。

**第一件，风险是否已最小化。** 不是问「有没有风险」（任何研究都有），而是问「在能达到研究目的的前提下，风险是不是已经降到最低」。这一问会直接改变设计：能用手册与培训替代的侵入性操作，能缩短的访视次数，能减少的采血量，能避免的安慰剂。最小化是一条行动要求，不是一句声明。

**第二件，风险与预期受益的比例是否合理。** 受益可以是针对受试者本人的，也可以是针对未来人群与知识的。当受益只落在后者时，风险的可接受门槛要提高。这一问最容易被含糊过去的方式是把「研究的意义」写得很大，而对风险的描述只有一句。

**第三件，知情同意是否真实、完整、自愿。** 真实指信息准确，完整指该说的都说了，自愿指没有胁迫与不当诱导。三者中「自愿」最难保证，因为它取决于关系：护患关系、师生关系、上下级关系，都可能让「拒绝」变得很难说出口。

**第四件，受试者的选择是否公正。** 负担与受益是否在人群间分配得当。只招容易招的人（比如本病房、本班次能接触到的患者），而受益落在别人身上，是选择不公正的典型形态。

四问的顺序有讲究。先问风险最小化，再问比例，再问同意，最后问选择——因为前三问的答案会改变第四问的对象。反过来做，会变成「先定人群，再补理由」。

## 二、同意书要写到什么颗粒度

同意书不是法律文书，是一份让普通人能做出决定说明。颗粒度不够，签字就只是签字。

| 项目 | 不合格写法 | 合格写法 |
|---|---|---|
| 研究目的 | 探讨某某的临床意义 | 想知道某做法能否让某类人在某段时间内少出现某种情况 |
| 会被做什么 | 接受常规护理及额外评估 | 逐项列出：做什么、谁做、多久一次、每次多久、总共几次 |
| 可能的不适 | 可能会有轻微不适 | 具体是什么感觉、大概持续多久、出现后怎么处理、什么时候要报告 |
| 替代方案 | 无 | 不参加也能得到的照护是什么，与参加相比差在哪 |
| 退出 | 可随时退出 | 怎么退、向谁说、退出后已收集的数据怎么处理 |
| 隐私 | 资料将保密 | 谁知道、存哪、存多久、发表时如何避免被认出 |
| 补偿与费用 | 无额外费用 | 有无补偿、因研究增加的交通或时间成本如何对待 |
| 联系方式 | 一个电话 | 研究相关问谁、权益受损找谁（两个不同的渠道） |

这张表里最容易空着的是「替代方案」与「退出后数据怎么处理」两行。前者空着，受试者会以为不参加就没有照护；后者空着，受试者以为退出就能把已给的数据要回去。两种误解都会影响决定的真实性。

同意书的完备程度可以按缺项数分档送审（教学设定）：八项全实、且每项的表述能被一位非医学背景的读者在十分钟内说清，判为齐备，直接进审查；缺一至两项但属补充即可的（如联系方式只写了一个渠道），判为待补，补齐后再送；缺三项以上，或缺的是「可能的不适」「替代方案」「退出后处理」这三项之一，判为需重写——这三项缺任何一项，同意就已经不成立了，补措辞没有意义。

同意过程还要留痕。签字之外，应记录：谁做的说明、在什么场合、给了多长时间考虑、有没有家属在场、受试者提了哪些问题。只有签名没有过程的同意，事后无法证明它是知情的。

## 三、弱势人群与免除知情的边界

**弱势**不是指「可怜」，指「自愿同意的能力被削弱」。常见情形有三类：一是决策能力受损（认知障碍、意识改变、急性痛苦中）；二是关系从属（学生、下属、本院职工、本科室患者）；三是处境脆弱（经济困难、无固定居所、缺乏照护者）。

对这三类，做法不同。决策能力受损者，需要法定代理人同意并尽可能取得本人 assent，且研究风险须与本人可能获得的直接受益相称。关系从属者，招募与同意应由不参与其照护的人执行，且必须明确写出「拒绝不影响照护」以及这句话由谁、在什么场合说。处境脆弱者，要额外说明补偿不会构成不当诱导——补偿应针对时间与花费，不与风险程度挂钩。

**免除知情同意**只在极窄的情形下成立，通常需要同时满足：研究风险不大于最小风险、免除不会对受试者权益产生不利影响、不豁免则研究无法实施或实施不可行、事后会提供适当信息。四条里缺一条，就不能免。把「回顾性病历研究」默认为可免，是常见的越界——病历研究同样可能涉及隐私风险与再识别风险。

**匿名化**也要说清。删去姓名与床号不等于匿名，因为日期、罕见诊断、居住地、事件组合都可能指向唯一的人。质性材料的原话尤其危险，一句话的用词习惯就可能被同科室的人认出。

## 四、动作、时限与记录字段

审查不是一次会议，它有前、中、后三段，每段都有明确的交付。

| 环节 | 角色 | 时限 | 交付物 |
|---|---|---|---|
| 预审自查 | 主研 | 送审前 10 个工作日 | 四问逐条自查表＋同意书逐项核对 |
| 材料准备 | 主研 | 送审前 5 个工作日 | 方案、同意书、招募材料、工具、数据管理说明 |
| 送审 | 主研 | 按委员会受理周期 | 受理回执与编号 |
| 答复意见 | 主研 | 收到意见后 10 个工作日内 | 逐条答复表：改了什么、改在哪一页哪一段 |
| 方案修订 | 主研 | 答复同时 | 修订版方案＋修订说明（改动处标出） |
| 批准后启动 | 主研 | 取得批件后 | 批件号、有效期、批准的同意书版本号 |
| 过程报告 | 主研 | 按批件要求 | 进展、偏离、不良事件、方案修改申请 |
| 结题报告 | 主研 | 研究结束后按委员会要求 | 完成情况、实际入组数、发表计划 |

「答复意见」这一环的关键是逐条对应。写「已按要求修改」而不指明改在哪一段，等于没答复；委员会无法核验，只能再问一遍。

记录字段（审查与执行登记表）：

| 列名 | 填什么 | 用途 |
|---|---|---|
| 批件号与有效期 | 编号、起止日期 | 合规的基础凭据 |
| 批准版本 | 方案版本号＋同意书版本号 | 防止用错版本施测 |
| 四问自查结论 | 逐条：做了什么、还差什么 | 送审前的硬检查 |
| 风险清单 | 逐项：是什么、多久、怎么处理 | 同意书的直接来源 |
| 受益说明 | 对本人／对未来，分别写 | 判断比例是否合理 |
| 同意过程记录 | 说明人、场合、考虑时间、在场者 | 证明知情的真实性 |
| 弱势情形与对策 | 属于哪类、采取了什么额外措施 | 判断选择是否公正 |
| 偏离与不良事件 | 时间、内容、处理、上报 | 过程监管 |
| 方案修改记录 | 改了什么、何时获批 | 版本一致性 |
| 数据保存与销毁 | 存放位置、期限、责任人 | 隐私承诺的落地 |

## 五、失效模式与考核

**一是同意书通篇「轻微」。** 所有风险都写成「轻微」「少见」「一般可耐受」，没有一个具体描述。受试者签了字，却不知道自己在同意什么。这是最普遍的一处，也是最少被追责的一处。

**二是同意在治疗前五分钟完成。** 患者刚入院、刚被告知诊断、家属还没到，护士拿着表格请签字。此时的「自愿」几乎不存在，而记录上看不出任何异常。

**三是本院职工与学生当受试者。** 招募方便，成本低，但拒绝的代价是可见的。补救措施不是加一句「自愿参加」，而是让招募与同意完全脱离其直接上级。

**四是回顾性研究默认免知情。** 直接从病历里取数据，不做任何告知。病历数据包含的隐私风险不低于问卷，再识别风险往往更高。

**五是偏离不报。** 入组比方案多了几例、访视晚了两周、同意书用了旧版，这些都被当成小事不报。偏离不报的后果是批件与实际执行脱节，一旦出事，前面所有合规记录都会失效。

**六是把审查当一次性门槛。** 批件拿到就再不回看，方案改了不申请，年度报告拖着不交。审查是持续的过程，不是入场券。

考核看五件事：一，四问是否逐条有书面结论；二，同意书八个项目是否逐项写实，特别是替代方案与退出后数据处理；三，弱势情形是否识别并写了具体对策；四，是否有审批版本号与实际使用版本的一致性核对；五，偏离与不良事件是否有上报记录。五项全有，这一章算过。

## 六、代价与边界

第一，审查不能替代研究者的伦理判断。委员会看的是文书与程序，看不到你在病房里的每一次取舍；真正的伦理发生在你决定要不要多问一句、要不要多抽一管的时候。

第二，本章的参考件不足。本课程没有伦理审查要件的原文，本章依通行原则写成，具体要件（申请材料清单、审查程序、跟踪审查频次、免知情同意的具体条件）以现行法规与所在机构伦理委员会的规程为准；本章任何表述都不能作为「已符合法规」的依据。

第三，程序合规不等于伦理上成立。一份格式完美、逐条答复、批件齐全的方案，仍可能在做一件不应当做的事。程序的价值是让这类问题有机会被提出，不是保证它一定被提出。

第四，审查有时间成本，这个成本是必要的。为了让方案更快通过而把风险描述写得含糊，短期省下的时间会在出事时以更大的代价还回来。
