# 中医技术轮转的门槛是辨证用技，不是把手法练熟 · 提示词

## 用途

给「中医技术轮转的门槛是辨证用技，不是把手法练熟」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「施术前必须答出的三个问题 → 四类常用技术：适应证与禁忌的结构 → 操作记录与反应观察 → 出科考核项：把「会做」与「会用」分开考」这条链。

## 边界

本章为教学材料，所述评估三问、适应证禁忌结构与记录六项用于训练辨证用技的判断与表达，不构成医学意见、诊断或治疗建议；具体操作以现行规范与所在机构制度为准。
