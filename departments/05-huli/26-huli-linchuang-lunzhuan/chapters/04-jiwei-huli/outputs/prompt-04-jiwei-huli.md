# 急危重症轮转先学排序：谁先看，比看得多快更重要 · 提示词

## 用途

给「急危重症轮转先学排序：谁先看，比看得多快更重要」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「分诊的四级与各自的判据 → 优先级：五个必须立刻看到的信号 → 团队与呼叫：谁能叫、叫谁、说什么 → 记录与交接：急诊的记录是给下一个班用的」这条链。

## 边界

本章为教学材料，所述分级结构、信号识别与呼叫格式用于训练急诊的判断与配合，不构成医学意见、诊断或急救指导；具体操作以现行规范与所在机构制度为准。
