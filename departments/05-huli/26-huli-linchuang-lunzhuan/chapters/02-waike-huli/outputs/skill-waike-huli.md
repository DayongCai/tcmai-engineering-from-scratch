# 外科轮转的核心在术前那一天与术后那几个窗口

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 本章无对应参考电子件
- 术前段结束时，你必须能说出这位病人术前的生活能力水平
- 你是核对的人，不是决定的人
- 疼痛是贯穿四窗的一条线，也是最容易被写坏的一条
- 手术室与病房之间、班次之间、出院与社区之间
- 观察项要与措施对应

## 边界

- 只写类别与要点，不写操作参数。
- 本章为教学材料，所述三段划分、核对清单与观察窗口用于训练围手术期的判断与表达，不构成医学意见、诊断或护理指导。
