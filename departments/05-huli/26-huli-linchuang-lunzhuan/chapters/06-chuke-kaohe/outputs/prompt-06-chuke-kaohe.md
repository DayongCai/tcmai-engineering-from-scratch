# 出科考的是一例能不能讲透，不是做过多少项 · 提示词

## 用途

给「出科考的是一例能不能讲透，不是做过多少项」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「出科考的三层：会做、会看、会讲 → 个案复盘：六栏格式 → 评价维度与不合格的判据 → 六站之间：迁移比积累更重要」这条链。

## 提示词

```
我在学《护理临床轮转》第 6 章「出科考的是一例能不能讲透，不是做过多少项」，本章 5 节 / 2,978 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 本章无对应参考电子件
   - 把「换个做法」写成「若再遇到同类情形，我会先做 X，因为 Y，代价是 Z」
   - 不合格的判据可以给
   - 本章不给合格线，也不建议用总分掩盖单项不合格
   - 第一种，方法的迁移
   - 第二种，判据的迁移
4. 指出本章写到类别就止步、不再给参数的地方。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，所述三层能力、复盘六栏与不合格判据用于训练判断表达与自我反思，不构成医学意见、诊断或考核裁定；具体操作以现行规范与所在机构制度为准。
