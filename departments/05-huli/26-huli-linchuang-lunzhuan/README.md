> 章链：入科准备 → 专科执行 → 观察记录 → 出科考核与复盘

## 一、这门课是什么，不是什么

**是**：一章一个轮转站的**入口**——进这个科之前要知道它在管什么、要盯什么、要会什么、出科考什么。

**不是**：不是各科护理的缩写版，也不是操作手册。具体病例处置、各科操作细节、排班与考勤都不在本课，
那些属于院内带教与教务管理，本库不越过它们。

**它是派生课**：本库没有《护理临床轮转》母本（这类课通常由各校自编实习手册，无统一教材）。
本课由五门专科护理课的 13 个「概述 / 评估 / 考核」单元派生，`locator` 一律「派生·」，`source` 记「父课:父课行号」。

## 二、必须说清的一条：框架是新增的

实测父课底本里：

| 词 | 命中 |
|---|--:|
| 轮转 | **1** |
| 出科 | **0** |
| 带教 | 16 |

**「轮转」「出科」几乎不出现**——父课讲的是各科护理，不讲轮转这件事本身。
所以本课的章节骨架（六个站、四个环节）是本轮引入的组织方式，不是底本原话；这一点与 `03-健康评估` 的四域框架同类，已在 `meta.json#底本.note` 登记。

## 三、三辨与四位面（实测）

| 三辨 | 词频 | 四位面（专科站位） | 词频 |
|---|--:|---|--:|
| **临床执行** | **2,896** | 急危重症 | 419 |
| **考核复盘** | **787** | 内科 | 375 |
| **轮转准备** | **191** | 外科 | 343 |
| | | 妇儿 | 164 |

三辨极差 **15.2×**：临床执行 2,896 是轮转准备 191 的 15.2 倍。
**这说明父课全是「怎么做」，几乎没有「怎么准备」**——而入科准备恰恰是轮转最容易被浪费掉的一段。
本课因此把准备单独立章（第 1、2 章的第一单元），并在每章开头写明「进科要回答的三个问题」。

四位面取**专科站位**（2.6×，四类都有值）：急危重症 419 / 内科 375 / 外科 343 / 妇儿 164。
环节轴（3.1×）与能力轴（3.4×）作为辅助读数写在每章正文里，不作分章依据。

## 五、代价与边界

- 不写具体病例的处置过程、不写各科操作细节（**底本不提供，也不该由本课提供**）
- 不写排班、考勤、轮转时长与考核评分（属教务与院内制度）
- 出科考核章只讲「考什么维度、怎么复盘」，**不给分值**

**免责声明：** 本课正文用于教学与轮转前预习，不构成诊疗、护理或法律意见；临床处置以现行规范、院内制度与带教老师判断为准。

## 七、一处门禁修正（本轮顺带做的）

`scripts/scaffold_sem910.js` 原来把 `chapters.json` 的 status 一律写死 `⬚`，`--check` 又要求整份文件字节相同。
后果是：**第 9/10 学期的课一旦开始写正文，`npm run check` 必红**——所以此前 18 门 sem910 课全是空的。

现在改成：**章节名与顺序**来自 `data/new-subjects-chapters.json`（不许手改）；**状态与产物路径**由磁盘现算
（`chapters/<slug>/docs/zh.md` 存在即 🚧 并补 `docs`/`code` 两栏，否则 ⬚）；`--check` 只对账「名字与顺序」。
本课是第一个走通这条路的 sem910 课。
