## 一、这门课在链条上负责哪一步

护理系的课按「对象—场景」分工。中医护理技术负责的是：评估与选法 → 施术前准备 → 施术与观察 → 评价与推广。

系内技术操作密度最高（40.9/万字），是「手上功夫」课的代表。

## 三、三辨与四位面（实测）

| 三辨 | 词频 | 四位面（操作环节） | 词频 |
|---|--:|---|--:|
| **技术操作** | **3,094** | 前准备 | 1,900 |
| **适应证禁忌** | **1,490** | 实施 | 1,052 |
| **操作后观察** | **5,401** | 观察处置 | 4,876 |
|  |  | 记录评价 | 3,544 |

三辨极差 **3.6×**；四位面极差 **4.6×**。

三辨里最大的不是「技术操作」而是「操作后观察」（5,401 vs 3,094，1.7×）：这本教材把技术写成「做完要盯什么」，不是「手法怎么做」。四位面按操作环节组织（4.6×，观察处置 4,876 是实施 1,052 的 4.6 倍），部位轴（C，4.0×）虽有值但与本课主题无关——本课按技术名组织，不按部位组织。技术类别轴（A，5.8×）不能取：艾灸只有 24 次，取了会把全书写成「穴位贴敷 + 附赠艾灸」。

## 五、代价与边界

- 不写具体灸量、留罐时间、刮痧力度等操作参数
- 不承诺疗效，不写「根治／有效率」
- 涉及破损皮肤、出血倾向、孕妇等禁忌情形一律先说明不适用
