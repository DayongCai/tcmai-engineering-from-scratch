# 第 10 章 · 这一章不动手，所以更没有「做到位」这回事

> **MOTTO:** 「气血冲和，万病不生，一有怫郁，诸病生焉。」——《丹溪心法·六郁》
>
> **PROBLEM:** 本章单单元 19,913 汉字，「观察」122 次、「记录」131 次、「报告」72 次，而「核对」0 次、「皮肤」0 次、「中止」1 次、「评估」7 次、「告知」17 次、「同意」14 次。这是全课唯一一章完全不涉及皮肤、器具、体表操作的内容：没有可看的伤口，没有可量的温度，也就没有「做没做到位」这一说。教材把力气放在观察与报告上（122 与 72），说明这一章的技术性全部集中在「看见什么、说给谁听」。复算：`python scripts/huli_jishu_chapter_stats.py 10`
>
> **双根因定位:** 环境逼迫（情志护理没有操作台、没有起止时点，它发生在交接班的两分钟、输液的半小时、出院前的走廊里；正因为没有边界，它最容易被当成「顺便聊聊」，也最容易在聊的过程中越界）+ 知识积累（教材把情志疏导、情志相胜、陪伴与支持、五音、导引、作息节律并置，最后用「不作心理诊断与判定」「由具备资质的人员指导」收口；这个收口是对的，但它把「哪些话能说、哪些话必须交给别人说」这一层留给了学生自己判断）

## 一、没有操作台的技术，靠三件事成立

前面九章的技术都有一组变量：温度、压力、浓度、面积。本章没有。它只有三件事：**在场、看见、转出去。**

**在场**指的是人在、心也在。陪伴的价值不在说了什么，而在「没有走开」。教材把「陪伴与支持」单列一节，说明它本身就是一个独立的措施，不是其他措施的前奏。

**看见**指的是把情绪状态变成可记录的事实：表情、语速、活动量、睡眠、食欲、与人交往的意愿。这一层最难，因为情绪是主观的，而记录要求客观。

**转出去**指的是识别出超出护理范围的情形，交给具备资质的人员。教材 72 次「报告」、多处「转介与配合」，说的都是这一件事。

三件事合起来构成本章的判断：**情志护理的上限是「陪伴 + 观察 + 转介」，下限是「不添乱」。** 上限做不到，是能力问题；下限破了，是伤害。

## 二、接触之前：五个判断，一个「不做」

本章教材里「核对」出现 0 次，但接触前的判断一样不能少。五项：

**一是当前情绪状态与强度。** 是低落、焦虑、愤怒、恐惧，还是平静；强度是「能谈」还是「谈不下去」。判断依据是可观察的行为，不是患者说的「我没事」。

**二是危机信号。** 有无表达活着没意思、有无自伤自杀的言语或行为、有无拒绝进食饮水、有无极度激越或木僵。**这一项必须在任何「疏导」之前完成。** 出现危机信号，处置不是谈话，是**立即报告、不离开、按机构流程转介**。

**三是精神科诊断与用药。** 有无已知诊断、正在服用什么、近期有无调整。这一项不是让护士去判断病情，而是让护士知道「这个人的情绪变化可能有医学背景」，不把症状当成「想不开」。

**四是意愿。** 愿不愿意谈、愿不愿意有人在旁边。不愿谈的人，陪着坐一会儿也是照护；追问「你为什么不说」，是把照护变成压力。教材在这一章反复讲尊重与不作判定，落点就在这里。

**五是环境。** 有没有遮挡、有没有旁人、谈话会不会被第三人听见。情绪的表达需要安全感，走廊里、电梯口、多人病房的床边，都不是谈话的地方。

五项之后有一个明确的「不做」：**不做心理诊断，不做人格评价，不做因果推断。** 「患者属于焦虑型人格」「他这是想太多」「因为家里不管他，所以抑郁」——这三句话都不在本课的职责范围内，写进记录更是越界。

## 三、三个动作的具体做法

**观察，看四组可记录的行为。**

第一组，表情与姿态：面部表情是否与话题相符、目光接触、坐姿是前倾还是回避、有无不安的小动作。第二组，言语：语速、音量、是否反复说同一件事、是否长时间沉默。第三组，活动：下床活动的次数、是否整日卧床、是否拒绝原本愿意做的事。第四组，生理：入睡困难或早醒、食欲与进食量、有无原因不明的疼痛与乏力。

四组都写成描述，不写成标签。「今晨起未进食，卧床未起，与其交谈时目光回避，回答以单字为主」——这是观察。「患者情绪低落」——这是判断，且没有信息量。

**倾听，守三条纪律。**

不评判：不说「这有什么好难过的」「你想开点」。不追问：不在对方停下来的地方继续挖，尤其不追问家庭矛盾与既往创伤的细节。不承诺：不说「一定会好」「我保证不告诉别人」——后者尤其危险，因为危机情形下的报告是必须的。

可说的是三句：我在；你可以慢慢说；这件事我会和负责的医生一起看怎么办。三句话的共同点是**不解决、不评价、不隐瞒**。

**转介，认四条线。**

出现危机信号（自伤自杀言语或行为、极端激越、木僵、拒绝进食饮水）；情绪状态明显影响治疗配合与基本生活；出现与现实不符的信念或感知；家属无法照护、存在安全风险。四条任一出现，动作是**报告 + 不离开 + 按流程转介**，并在记录中写明报告对象、时点与回应。

## 四、五音、导引与情志相胜：可以配合，不可自施

教材讲了五音类方法与导引类方法，也讲了情志相胜的思想。这三样在本课里的位置是**配合性措施**，不是治疗手段。

**五音**是按声音与曲调的特性分类，用于营造环境、辅助放松。执行要点有三：音量与环境适配、患者意愿（不喜欢就换或停）、不作为治疗宣称。写记录时写「播放某类音乐，患者表示放松」，不写「以某音调某脏」。

**导引**是形体与呼吸的配合，本章只取其「调息安神」的一面，具体动作与强度放在下一章。要点是：不在情绪激动时要求患者「跟着做深呼吸」，那常常适得其反；先陪着，等情绪落下来，再谈活动。

**情志相胜**讲的是一种情志对另一种情志的制约关系。它是理论层面的认识，不是可自行操作的处方——用什么、用多少、对谁用，属专业判断。护士能做的是：理解这套思路，配合已确定的方案，观察反应，报告变化。

三样合起来的纪律只有一条：**凡带「治疗」意味的表述，一律不出自护士之口。** 教材在这一章连着写了「不作心理诊断与判定」「不作疗效断言」「由具备资质的人员指导」三句，正是这条纪律的三个侧面。

## 五、记录字段与五种失效模式

**记录字段（七项）**：接触的时间、地点、在场人员；患者当时的可观察状态（表情、言语、活动、生理四组）；患者原话（关键句照录，不作概括）；本次所做的（陪伴、倾听、环境调整、配合性措施）；危机信号的排查结论（有/无，依据）；报告与转介（对象、时点、回应）；后续安排与交代。

其中「患者原话」一项是本章最有价值的字段。「患者说『晚上躺着就想哭，不敢跟家里讲』」——这句话后面的人能读出很多；「患者情绪低落」什么也读不出。

**失效模式一：把安慰当治疗。** 「聊了半小时，患者笑了」被记成「情绪改善」。笑是当下的社交反应，不是状态改变。记录只写所见，不写结论。

**失效模式二：越界做心理疏导。** 追问创伤细节、给出人生建议、解释患者的家庭关系。这些动作超出了训练范围，且可能造成二次伤害。

**失效模式三：漏掉危机信号。** 患者用玩笑的口吻说「活着没意思」，被当成玩笑。凡出现这类表达，一律按危机信号处理：问清、不离开、报告。宁可过度反应，不可漏。

**失效模式四：把情绪变化归因于技术。** 「做完艾灸后患者情绪好多了」——这类因果在单次观察里无法成立，写进记录会误导后续判断。可写的是「施灸后患者诉放松，与之交谈时语速放缓」，两件事并列，不连因果。

**失效模式五：承诺保密。** 「你放心说，我不告诉别人」。危机情形下的报告是职责，承诺保密会把自己逼进两难，也会让患者在被报告后感到被背叛。

## 六、代价与边界

**丢掉了什么。** 本章不写任何一种心理干预技术的操作步骤，不写情志相胜的具体配法，也不写五音的曲目与时长。代价是它不能替代心理护理的专门训练；收益是它把边界画在了最容易越界的地方——话说到哪里为止。教材的用词分布是旁证：122 次「观察」、72 次「报告」，对 0 次「核对」、0 次「皮肤」；这一章的技术性全在「看」与「报」。

**数字的边界。** 「观察 122」「记录 131」「报告 72」「核对 0」「皮肤 0」「中止 1」「评估 7」「告知 17」「同意 14」为底本原文的字符串计数，出现即计。「核对 0 次」不表示本章无需前置判断，而是教材未使用该词；本节的五项判断即为此补出。

**参数的边界。** 谈话时长、频次、五音的音量与时长、导引的动作与次数，一概不给数值。五项判断与四条转介线为本课教学设定。涉及心理评估、诊断与干预，一律由具备资质的人员进行。

**责任的边界。** 本章不构成心理治疗或咨询建议，不评价任何干预的效果。出现自伤自杀风险、精神症状加重、拒绝基本照护，立即报告、不离开、按机构流程转介并留痕；不得自行处置，不得承诺保密。
