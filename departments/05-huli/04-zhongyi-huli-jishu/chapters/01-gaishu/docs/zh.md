# 第 1 章 · 「适宜」指的是资源可及，不是风险低

> **MOTTO:** 「其治宜导引按跷。」——《黄帝内经·素问·异法方宜论》
>
> **PROBLEM:** 本章合两单元共 40,020 汉字，其中「规范」388 次、「记录」231 次、「观察」141 次，而「皮肤」0 次、「中止」0 次、「不适用」仅 1 次。也就是说，概述层把全部力气花在「按规范做」上，对「什么情况不能做」几乎整段留白；而后面各章的「不适用」一路上涨到单章二十余次、四十余次。复算：`python scripts/huli_jishu_chapter_stats.py 1`
>
> **双根因定位:** 环境逼迫（这类技术的入场门槛低——器具便宜、场地随意、一次操作以分钟计，因此它天然被安排在病房走廊、社区活动室、家庭卧室里做；门槛低意味着没有第二道防线，护士本人就是那道防线）+ 知识积累（教材用「简、便、验、廉、广」五个字概括特点，这五个字读起来像宣传语，实际上每一个字都在描述一种特定的风险来源，教材没有把特点和风险对上号）

## 一、先把「适宜」两个字拆开

教材给这类技术下的定义里，「适宜」有两层意思：一是适合在护理实践中推广，二是适合当时的资源条件。两层都指向**可及性**，没有一层指向**安全性**。这是本章要立的第一个判断：一门技术之所以被列入「适宜」，是因为它便宜、好学、不依赖大型设备，不是因为它做不出事。

这个区别在临床上很具体。一台监护仪坏了，报警会响；一根艾条、一个火罐、一块刮板不会报警，它们的风险全靠操作者术前那几分钟的判断。教材的写法也印证了这一点：全章 388 次「规范」，说的是「你要按规范做」，而不是「规范会替你挡住风险」。规范是底线，判断是护士自己的事。

由此可以推出本章的第二个判断：**护士在这类技术里的角色是筛选者与观察者，不是决策者。** 教材反复出现的一句边界是「由具备资质的人员辨识」「不作证型判定」「不作疗效断言」。这三句话不是免责套话，它们划定了操作密度的起点——凡是需要判断「这个人是什么证、该不该治、治到什么程度」的环节，都不在这门课的操作范围内；凡是需要判断「这个人此刻能不能承受、做的时候有没有变化、做完要不要报」的环节，全部在这门课里。

技术链因此可以写成四段：**评估与选法 → 施术前准备 → 施术与观察 → 评价与记录**。四段之间是承接关系，前一段的输出是后一段的输入。链条上任何一段松动，后面的判断就失去依据。本章要做的，是把这条链上的判据讲清楚，让后面十三章各自有落点。

## 二、术前核对：禁忌排在适应证前面

教材的章节顺序容易给人一个错觉：先讲适应证，再讲不适用范围。真实的核对顺序必须反过来——**先排禁忌，再看适应证**。原因是两类错误的代价不对称：漏掉一个适应证，最多是这次不做、换个方法；漏掉一个禁忌，可能是一次不可逆的皮肤损伤。

按「人的状态」而不是「病的名字」来排，禁忌可以归成三档。这三档的界线和处置是本课的教学设定，用于训练判断顺序，不替代任何规范条文：

| 档 | 情形 | 处置 |
|---|---|---|
| 甲：不可做 | 施术局部皮肤破损、溃疡、感染、皮疹、烧伤瘢痕、植皮区；不能准确表达灼痛或压痛的人（意识障碍、镇静状态、失语、严重认知障碍、局部感觉减退）；未取得知情同意 | 不做，记录原因，报告，改换方法或改期 |
| 乙：调条件后做 | 空腹、过饱、酒后、剧烈运动后、极度疲劳、情绪激动；局部有轻微潮红或压痕但皮肤完整；正在使用抗凝药物；妊娠期腰骶与腹部 | 先处理条件（进食、休息、平复），再由具备资质的人员确认，缩小范围、加密观察 |
| 丙：可做 | 局部皮肤完整、感觉正常、能自主表达、已告知并同意、条件适宜 | 按规范实施，按本节观察时点看 |

三档里最容易出事的是乙档，因为它看起来「差不多能做」。乙档的处置有一条硬要求：**条件的处理必须留下痕迹**。「患者进食后实施」「患者休息后情绪平稳，复测血压回落后实施」——这样写，下一位护士才知道当时为什么可以做；只写「已处理」，等于什么都没写。

还有一条经常被漏掉的核对项：**这次不做什么。** 计划施灸而因局部皮损取消、准备拔罐而因患者空腹改期，这类「未实施」必须记录原因与去向。只记做了的，会让接班的人以为已经做过，或者以为评估过而没问题。

## 三、四类技术的作用路径不同，观察的落点也不同

教材把技术按作用方式分成若干类。分类的教学价值不在于背名称，而在于**知道每一类的「变量」是什么、失控时先坏在哪里**。护理上真正要控的从来不是「手法像不像」，而是这几个变量：

| 类别 | 核心变量 | 失控先坏在哪 | 术中看什么 |
|---|---|---|---|
| 温热类（灸、热熨、熏洗） | 热源与皮肤的距离、单次持续时间、累计面积 | 皮肤：潮红 → 深红 → 水疱 → 破溃 | 颜色、患者主诉的灼痛、有无不出声但身体绷紧 |
| 负压与机械类（拔罐、刮痧、按压） | 负压或压力强度、作用时长、作用面积 | 皮下：瘀斑范围、皮肤完整性 | 罐内隆起程度与颜色、刮拭处皮肤反应、疼痛性质 |
| 经皮给药类（贴敷、外敷、药浴） | 药物类别、接触面积、皮肤屏障状态 | 局部过敏与水疱，少数全身反应 | 敷处瘙痒、红疹、边界是否超出贴敷范围 |
| 穴位刺激类（耳穴埋豆、揿针） | 刺激强度、留置时长、局部清洁 | 耳廓或穴区红肿、感染 | 局部温度与压痛、有无渗液 |
| 饮食情志类（药膳、情志调摄、导引） | 食性与体质的匹配、活动量与耐受 | 消化反应、头晕气短、情绪波动 | 进食后腹胀腹泻、活动中面色与呼吸、情绪变化 |

这张表有一个共同结构：**每一类都有一个「量」，也都有一个「最先坏掉的器官」。** 温热的量是热，先坏在皮肤；负压的量是压力，先坏在皮下；给药的量是接触，先坏在屏障；刺激的量是强度，先坏在局部；饮食与运动的量是耐受，先坏在全身反应。把「量—靶器官」这一对记住，观察就有了焦点，而不是笼统地「多看看」。

## 四、记录字段与三种失效模式

**记录字段（七项）**：术式与部位侧别；术前基线（皮肤完整性、感觉、局部颜色，含阴性所见）；禁忌核对结论（甲/乙/丙三档中落在哪一档，乙档写明条件如何处置）；参数执行口径（写「依规范执行」，具体数值按机构记录要求）；术中与术后的观察所见（按上表的落点写）；异常与处置；报告对象、时点与回应。

**失效模式一：把「特点」当成「优点」。** 「简、便、验、廉、广」被读成「所以安全」。真实的对应关系是：简 → 步骤少、容易被跳过；便 → 随处可做、环境不受控；验 → 依赖个人经验、难以复制；廉 → 用物可重复使用、清洁消毒容易松；广 → 受众广、非专业人员也在做。五个字每一个都在提示一处薄弱点。

**失效模式二：用适应证反推禁忌。** 「这个证适合灸」不等于「这个人可以灸」。适应证说的是证，禁忌说的是人——皮肤、感觉、时机、意愿。核对顺序反了，就会拿证型去压过局部皮损。

**失效模式三：把「没出事」当成「做对了」。** 一次顺利不构成任何证据。这类技术的反应有延迟性，水疱、迟发灼痛、瘀斑扩大常在离开操作间之后出现，当场没反应不等于安全。

**考核项：**

| 序号 | 考核项 | 合格线 |
|---|---|---|
| 1 | 说出「适宜」的两层含义，并说明它为什么不指安全性 | 两层都说全，能举一个反例 |
| 2 | 对给定案例判定落在甲/乙/丙哪一档并说明处置 | 判定正确，甲档处置为「不做并报告」 |
| 3 | 说出五类技术各自的核心变量与最先受损的部位 | 五对全对 |
| 4 | 复述技术链四段，指出其中属于护士职责的环节 | 四段顺序正确，职责边界不越界 |
| 5 | 写出一次「未实施」的完整记录 | 含原因、去向、报告对象 |
| 6 | 复算本章术语计数并解释「中止 0 次」的含义 | `python scripts/huli_jishu_chapter_stats.py 1` |

## 五、代价与边界

**丢掉了什么。** 本章不写任何一种技术的具体做法，也不写「什么证配什么穴」。代价是这一章不能用来学操作；收益是它给出了一条后面十三章共用的判断顺序——先排禁忌，再看适应证，最后才谈手法。教材的结构与此一致：概述层 388 次「规范」对 0 次「皮肤」、0 次「中止」，说明它自觉地把风险细节留给了各论。

**数字的边界。** 「规范 388 次」「记录 231 次」「观察 141 次」「皮肤 0 次」「中止 0 次」「不适用 1 次」均为底本原文的字符串计数，出现即计，不做同义词合并。计数只说明教材在这一层的用词分布，不构成对教材质量的评价。

**参数的边界。** 本章不给温度、时长、剂量、疗程的任何数值。三档判据的界线与处置是本课的教学设定，用于训练核对顺序；真实执行以现行规范、机构制度与医嘱为准，两者冲突时以规范为准。
本章可直接验证：`node code/main.js` 打印结构清点与判据清单（数字从 `docs/zh.md` 现算），`node --test code/main.test.js` 跑本章单测；两条命令只读正文与代码，不写任何文件。

**责任的边界。** 本章为教学材料，不构成操作指导，不评价疗效。适宜技术须由受训并具备资质的人员在合规场所实施；出现烫伤、水疱、破皮、晕灸晕罐，一律停止、报告、按机构流程处置并留痕。
