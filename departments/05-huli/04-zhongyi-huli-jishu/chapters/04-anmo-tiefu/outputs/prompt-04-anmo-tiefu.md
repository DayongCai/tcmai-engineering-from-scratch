# 轻手法不是低风险，是低信号 · 提示词

## 用途

给「轻手法不是低风险，是低信号」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「合章的理由，与不该合的地方 → 按压：三个变量与四类不适用 → 贴敷：贴什么、贴多大、留多久 → 两套记录字段」这条链。

## 边界

本章为教学整理，依据底本第 5 章（教材·第5章·5.1.2）编写，不构成操作指导、疗效承诺或替代医疗建议。文中的三档判据与观察时点为本课教学设定。读者不得据本章为他人进行按压或贴敷操作，尤其不得自行配制贴敷药物；具体操作以现行规范与所在机构制度为准。
