## 核心概念

### 中医：护理技术的疗效怎么算

艾灸、拔罐、穴位贴敷这类技术，教材给的疗效描述多是「症状改善」「有效率高」。《医学入门》讲「药之不及，针之不到，必须灸之」，讲的是适应证选择，不是疗效大小。护理要回答的是**这个病人这次改善了多少**，所以必须落到同一量表的两次测量上。

护理常用量表：疼痛 NRS（0–10）、睡眠 PSQI、焦虑 SAS、中医症状积分。选择原则是一致的：**同一病人、同一量表、同一时间窗、同一个评估者**（或至少记录评估者）。

### AI/工程：效应量与 MCID

配对差值的效应量用 Cohen's $d_z$：

$$d_z=\frac{\bar{x}_{\text{后}}-\bar{x}_{\text{前}}}{s_{\text{差}}}$$

经验读数：0.2 小、0.5 中、0.8 大。但**效应量大不等于病人受益**：NRS 从 6 分降到 5 分，$d_z$ 可能很可观，而 MCID 通常要求至少降 2 分。所以报告必须并排给三个数：均值差、$d_z$、是否达到 MCID。

还有一个容易被忽略的环节是**基线**。同一位病人，入院时 NRS 8 分与出院前 3 分，若把「干预前」定在入院那天，测到的其实是住院期间全部处理（包括药物与休息）的合力。护理记录要能说清「这一次技术」的作用，就必须把测量点贴近操作：操作前 30 分钟、操作后固定时点，而不是笼统写「治疗前 / 治疗后」。基线定在哪里，等于决定了这份数据回答的是哪个问题。

## BUILD IT：从零实现

```js
function effect(pre, post, mcid) {
  const diff = post.map((v, i) => v - pre[i]);
  const mean = avg(diff);
  const sd = stdev(diff);
  return { mean: +mean.toFixed(2), dz: +(mean / sd).toFixed(2), reached: mean <= -mcid };
}
```

预期：一组 NRS 从 6/7/5/6/7 降到 4/3/2/4/3，均值差 −3.4、$d_z$ 约 −1.9，达到 MCID=2 的判定；另一组只降 0.8 分，即使 $d_z$ 不小也判「未达 MCID」。

## 代价与边界

- **单组前后对比不能证明是艾灸起效**。病程自然波动、安慰效应、同期用药改变都在里面；没有对照，只能叫「变化」，不能叫「疗效」。
- **评估者不盲**。护士知道谁做了艾灸，量表打分容易偏高，这是护理研究里最常见的偏倚。
- **MCID 本身是人群平均值**。同一个 2 分，对慢性痛病人可能无感，对术后病人可能很重要。
- **样本极小**时 $d_z$ 极不稳定，五个人的效应量不足以支撑任何结论。

> **免责声明：** 本章的量表与阈值用于教学与护理记录规范演练，不构成诊疗建议；实际护理方案须由责任护士与医师依据病情确定，症状恶化须立即报告。

## 进阶思考

护理疗效评价最容易被简化成「有效率 90%」这种数字。问一句「90% 是怎么算的」，往往就露出破绽：没有量表、没有阈值、没有基线。把这三样补齐，比多发一篇总结更有价值。
