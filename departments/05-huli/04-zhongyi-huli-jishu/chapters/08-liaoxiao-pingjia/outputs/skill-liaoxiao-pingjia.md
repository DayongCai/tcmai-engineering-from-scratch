# liaoxiao-pingjia

## 何时使用

- 交班记录里要写清「这次艾灸改善了没有、改善多少」
- 护理查房需要一份能被护士长复算的疗效数据
- 科室做小样本护理观察，需要先统一记录口径

## 不适用

- 需要证明因果效应的研究（必须有对照与盲法，本技能不做研究设计）
- 无法使用量表、只能凭感受描述的情形（此时应记录「未测量」而不是编一个数）
- 危急重症的病情判断（走临床路径，不用疗效记录单）

## 步骤

1. **固定量表**：NRS / PSQI / SAS / 中医症状积分，选一个并在整组内不变。
2. **固定时间窗**：干预前、干预后多久（如三次后 24 h），写进记录。
3. **标明评估者**：谁测的、是否知晓干预。
4. **算三个数**：均值差、配对 dz（n−1）、是否达 MCID。
5. **写「不能推断」**：无对照、不盲、样本量、同期用药。

## 输出模板

```text
【记录】量表 … ；时间点 … ；评估者 …
【数值】均值差 … ；dz … ；MCID … → 达到 / 未达
【表述】本组 N 例由 … 降至 …
【不能推断】1) … 2) …
```

## 质量判据

- 三个数齐全且同量纲
- 没有出现「有效率」「显著有效」这类未经设计的结论
- 「不能推断」至少两条，且都不是套话

> 本技能输出为护理记录辅助，不构成诊疗建议。
