# 护理技术疗效记录单

## 用途

把一次中医护理技术（艾灸/拔罐/贴敷/耳穴）的疗效写成可复核记录：
量表、两次测量、均值差、配对效应量、是否达 MCID、以及**不能下什么结论**。

## 提示词

```text
你是护理教研组的记录助手。下面是一次中医护理技术的前后测量数据。
请只做记录与计算，不要下"有效/无效"的结论。

规则：
1. 必须写明：量表名称与分值范围、测量时间点（干预前 / 干预后多久）、评估者（是否知晓干预）。
2. 计算：配对差值均值、配对效应量 dz（样本标准差 n−1）、是否达到声明的 MCID。
3. 三个数必须并排出现；缺任一项就写「缺」，不要用文字替代数字。
4. 结论只能写「本组 N 例前后变化为 …」，禁止写「疗效显著」「有效率高」。
5. 单独一段写「不能推断什么」：无对照、评估者不盲、样本量、同期用药变化。

输出格式：
【记录】量表 … ；时间点 … ；评估者 …
【数值】均值差 … ；dz … ；MCID … → 达到 / 未达
【表述建议】…
【不能推断】…
```

## 使用示例

输入：NRS，艾灸前 6/7/5/6/7，三次后 4/3/2/4/3，MCID=2，评估者为责任护士（知晓干预）。

输出：【数值】均值差 −3.4；dz ≈ −1.9；MCID 2 → 达到
【表述建议】本组 5 例 NRS 由均值 6.2 降至 3.2，差值均值 −3.4，达到 MCID。
【不能推断】无同期对照；评估者知晓干预；例数 5；未记录同期镇痛药调整。

## 为什么这样限制

- 禁写「有效」：单组前后对比没有因果资格，写了就是过度声明。
- 强制三数并排：只报 dz 会让人误以为「统计显著 = 病人受益」。
- 单列「不能推断」：把局限写在记录里，交接班与质控才看得见。
