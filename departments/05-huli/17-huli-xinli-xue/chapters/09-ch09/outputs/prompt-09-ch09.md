# 长期照护里最耗人的不是病，是每次复诊都要重新解释自己 · 提示词

## 用途

给「长期照护里最耗人的不是病，是每次复诊都要重新解释自己」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三个阶段：反应随病程变形 → 家庭负担与照护者支持 → 支持方式的选择 → 分档、告知配合与时限」这条链。

## 边界

本章为教学材料，所述阶段划分、支持方式与随访时限用于训练长期照护中的心理支持，不构成医学意见、诊断或治疗建议；具体操作以现行规范与所在机构制度为准。
