# 患者记住的不是宣教重点，而是被对待的方式 · 提示词

## 用途

给「患者记住的不是宣教重点，而是被对待的方式」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「感觉与知觉：进入大脑的第一道闸 → 注意与记忆：信息为什么丢 → 思维与语言：抽象的话落不了地 → 情绪、意志与行为：依从的心理学」这条链。

## 提示词

```
我在学《护理心理学》第 2 章「患者记住的不是宣教重点，而是被对待的方式」，本章 5 节 / 2,912 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 参考件状态

   - 知觉层面最关键的是「解释框架」

   - 其二，给「做什么」，不给「为什么」的大段论证
4. 指出本章写到类别就止步、不再给参数的地方。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，所述注意与记忆规律、沟通句式与复评时限用于训练信息传达，不构成医学意见或治疗建议；具体操作以现行规范与所在机构制度为准。
