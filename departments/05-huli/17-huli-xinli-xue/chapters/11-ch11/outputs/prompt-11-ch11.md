# 临终照护最难的，是把「还能做什么」说到最后一刻 · 提示词

## 用途

给「临终照护最难的，是把「还能做什么」说到最后一刻」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「老年期：认知与情绪的观察要点 → 孤独与失落：支持的对象是关系，不是情绪 → 临终：四个阶段与「还能做什么」 → 尊重自决与分档时限」这条链。

## 边界

本章为教学材料，所述观察要点、沟通动作与分档时限用于训练老年与临终患者的心理支持，不构成医学意见、诊断或治疗建议；具体操作以现行规范与所在机构制度为准。
