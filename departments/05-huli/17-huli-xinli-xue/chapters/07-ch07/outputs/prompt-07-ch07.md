# 危机靠问出来，不靠看出来 · 提示词

## 用途

给「危机靠问出来，不靠看出来」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三类信号：情绪、言语、行为 → 求助表达：两种形式与回应的边界 → 风险评估：直接问的四句话 → 安全照护、陪伴与报告转介」这条链。

## 提示词

```
我在学《护理心理学》第 7 章「危机靠问出来，不靠看出来」，本章 6 节 / 3,129 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 参考件状态
   - 「突然平静」这一条要单独强调
   - 行为信号的价值在于它不需要患者配合
   - 接住试探，不追问动机
   - 第一句：「最近有没有觉得，活着没什么意思？」
   - 第二句：「有没有想过不想活了？」
4. 指出本章写到类别就止步、不再给参数的地方。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，所述识别信号、询问句式与处置时限用于训练危机识别与转介，不构成医学意见、心理诊断或治疗建议；具体操作以现行规范与所在机构制度为准。
