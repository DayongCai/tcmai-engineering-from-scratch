## 一、这门课在链条上负责哪一步

护理系里唯一「以人的心理状态为对象」的课，与 `06-中医心理学`（辨证视角）、`23-精神科护理学`（障碍视角）、`03-健康评估` 第 3 章（评估工具）共同构成心理线的四门。本课负责**非障碍人群的常规心理护理**——病人、家属、护士自己，这三个对象都不在精神科的诊断框架里。

## 五、代价与边界

- 不写具体心理量表分值、分级界值与诊断标准（量表工具见 `03-健康评估` 第 3 章的外源层）

- 涉及自伤、自杀等危机情形一律指向即时处置与转介，不在本课处理

**免责声明：** 本课正文用于教学与训练，不构成诊疗、护理或法律意见；临床处置以现行规范、院内制度与主治医师判断为准。
