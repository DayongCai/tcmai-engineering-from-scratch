# 第 7 章 · 焦虑病人的"我没事"，多数时候是"我说不出来"而不是"真的没事"

> **MOTTO:** 「气血冲和，万病不生，一有怫郁，诸病生焉」——《丹溪心法·六郁》
>
> **PROBLEM:** 一次惊恐发作的就诊路径通常是：急诊挂号、心电图、抽血、留观、结论"未见异常"、回家，全程约 4 小时；其中用于询问"发作的时候你最怕会发生什么"的时间，往往是 0 分钟。4 小时与 0 分钟的差，就是躯体排查与心理评估之间的那段空白——而复发就藏在这段空白里。【演算设定，非实测】

**双根因定位:** 环境逼迫（焦虑最先以躯体形式出现：心悸、胸闷、气短、手抖、濒死感，这套表现天然把病人送进综合医院的急诊与心内科，而不是精神科；反复检查得到的"未见异常"既不解释症状也不减轻恐惧，反而加深"查不出来，是不是更严重"的循环）+ 知识积累（焦虑谱系从"神经衰弱"一类笼统说法中分离出来，惊恐、社交焦虑、广泛性焦虑、创伤后反应被识别为机制与干预各不相同的类型，护理不再能用"放松点"一句话覆盖）

**本章说明：** 本科目无参考电子件，不引页码、不引版次、不给剂量与疗程。本章不写诊断标准与药物方案，只写观察、判断与配合。

## 一、焦虑的三个层次与对应的护理动作

焦虑不是一个"情绪强度"，它是三层同时运转的系统：**生理唤醒**（心跳加快、呼吸变浅、出汗、肌肉紧张）、**认知担忧**（预感灾难、反复推演、无法停止的"万一"）、**回避行为**（不去人多的地方、不坐电梯、不单独出门、反复确认）。

这三层对应三种完全不同的护理动作。对生理唤醒，有效的是降低唤醒的具体技术：放慢呼吸、延长呼气、把注意力放到脚底与椅面的接触、用冷水洗脸。对认知担忧，有效的是把"万一"变成可检验的具体句子（"万一我晕倒"→"上次晕倒过吗？当时发生了什么？"）。对回避行为，有效的是分级暴露：把回避的场景拆成若干级，从最轻的一级开始，逐级停留到焦虑下降。

三层里最容易被漏掉的是回避。因为回避让人看起来"好了"——不去超市就不发作，不坐电梯就不心慌。护理记录如果只记"发作次数为零"，就会把一个正在缩小的生活圈记成稳定。正确的记录方式是把"活动范围"当成指标：这一周去过哪些地方、独自出门几次、有没有因为害怕而中途返回。

还有一层需要单独说明：焦虑常与抑郁共存。当一个人既有明显的焦虑又有无望感时，风险不是相加而是相乘——焦虑提供行动的驱力，无望提供行动的理由。遇到这种组合，评估的重点要立刻转向自杀风险。

家庭在焦虑的维持中扮演双重角色。一方面，家属的安抚是最有效的即时镇痛剂；另一方面，反复的安抚会形成"我一不安，就有人来保证"的循环，症状因此被无意中强化。护理能做的是给家属一套替代动作：不急着保证，先问"你现在最怕的是什么"，再一起做一次呼吸练习，最后把"下次发作先做这三步"写下来。这套动作把家属从"安慰提供者"变成"技术陪伴者"，既减轻家属的无力感，也切断保证的循环。

## 二、观察项

| 观察项 | 具体问法与看法 | 判读要点 |
|---|---|---|
| 发作特征 | 起病多快、持续多久、当时在做什么、有无濒死感或失控感 | 突然起病、十分钟内达峰、伴强烈濒死感，是惊恐的典型轮廓 |
| 躯体鉴别 | 胸痛性质、是否与活动相关、有无放射、有无晕厥、有无心悸伴出汗 | 新发、与活动相关、伴晕厥或大汗，先按躯体急症处理 |
| 过度换气 | 呼吸频率、口周与手指麻木、手足抽搐 | 麻木与抽搐提示呼吸性碱中毒，处理方向是放慢呼吸而非加氧 |
| 回避范围 | 最近一周去过的场所、独自出门次数、有无中途折返 | 用"次数与范围"记，不用"焦虑明显"记 |
| 担忧内容 | 具体怕什么、多久想一次、能否被打断 | 泛化的"什么都担心"与特定的"怕失控"干预路径不同 |
| 创伤相关 | 有无反复闯入的画面、噩梦、惊跳反应、对相关场所的回避 | 三群症状（再体验、回避、警觉增高）同时存在时，不主动追问细节 |
| 物质因素 | 咖啡、浓茶、能量饮料、减肥产品、酒精使用 | 大量摄入可模拟或加重焦虑，须写进评估 |

关于创伤相关反应，有一条专业上很硬的规则：**不为了"了解情况"而让病人复述创伤细节**。护理需要知道的是触发线索、当下的应对方式与安全状况，而不是事件的全过程。反复复述会造成二次创伤，也会让护士在没有准备的情况下承接超出能力的内容。需要结构化处理时，转介给受训的治疗者。

## 三、判据分档与动作时限

| 档 | 判据 | 谁在多长时间内做什么 | 升级条件 |
|---|---|---|---|
| 观察档 | 有焦虑体验但能自述、能自行缓解；日常活动基本维持 | 每班接触并记录；教会一项降唤醒技术并确认会用 | 出现明显回避或发作频次上升 |
| 干预档 | 发作频繁影响进食睡眠；或出现明显回避；或反复就诊要求检查 | 当班内完成一次结构化评估；与医师沟通躯体排查结果；30 分钟内实施一次降唤醒干预；每 2 小时记录 | 出现无望感、自伤念头或物质滥用 |
| 应急档 | 发作伴濒死感、过度换气致手足抽搐；或焦虑合并明确自杀意念；或急性应激下出现冲动 | 立即就地处置（体位、呼吸、安全环境）；同步医师；不间断陪护 | 意识改变、抽搐、胸痛不缓解 |

【教学设定】上表为训练用分档，真实阈值依院内制度与临床判断。

"反复就诊要求检查"这一条需要特别处理。它既是症状，也是对医疗系统的消耗。护理的可行做法不是拒绝，而是**把检查的边界说清楚并给一个替代承诺**："今天的检查结果出来后，如果还是正常，我们一起想办法处理这种害怕，而不是再查一遍。"这句话之所以有效，是因为它回应了真实需求（怕被漏掉），同时把路径从"再查"转向"处理焦虑"。

## 四、护理干预的四个可教动作

第一，**放慢呼气**。吸气短、呼气长，比"深呼吸"更有效；"深呼吸"对已经过度换气的人常常适得其反。教的时候要示范并一起做，不要只说。

第二，**接地**。五感定向：说出看到的五样东西、听到的四种声音、摸到的三种触感。这个方法的价值在于把注意力从内部的灾难预演拉回外部现实，而且不需要任何器材。

第三，**把担忧写成句子**。让病人把"万一"写成一句完整的话，再一起找反证。写下来比说出来更容易发现逻辑跳跃。

第四，**分级任务**。把回避的场景排成队，每周完成一级，完成即记录。护理的角色是陪同与记录，不是替他完成。

这四件事都有一个共同前提：**先建立"发作是可以被理解的"这个解释**。很多病人最恐惧的不是症状本身，是"我是不是要疯了""是不是心脏病"。给出一个能自洽的解释（身体在错误的时间拉响了警报，警报本身不会造成伤害），比任何技术都先起效。

不同人群的焦虑面貌差别很大，这一点常被忽略。青少年的焦虑常表现为躯体不适、拒学、易怒，而不是"担心"；老年人的焦虑常表现为反复就诊、对身体细微变化的过度关注、夜间不安；男性的焦虑常表现为饮酒、易怒、工作过度。护理如果只用"你焦虑吗"去问，三类人都会答"没有"。更可行的问法是行为式的：最近有没有因为害怕而放弃过什么事、有没有反复去查同一件事、晚上躺着的时候脑子在做什么。

## 五、记录与失效模式

记录字段：**时间、触发情境、躯体表现、认知内容（原话）、回避行为、已用技术、缓解所需时间、下次复评**。

| 失效 | 现场表现 | 后果 | 纠正 |
|---|---|---|---|
| 过度保证 | 反复说"没事的、别怕" | 短期安抚、长期强化依赖与检查循环 | 给解释与技术，不给无限次保证 |
| 把躯体症状当"想太多" | "查了都正常，你就是焦虑" | 病人感到被否定，转向别处反复就诊 | 先承认症状真实，再区分来源 |
| 二次创伤式追问 | 要求详述创伤全过程 | 症状加重、脱落 | 只问触发、应对与安全 |
| 记录只写"焦虑" | 无情境、无行为、无时长 | 无法判断变化 | 按六字段记录 |
| 忽视物质因素 | 不问咖啡、酒精、减肥产品 | 误判为病情加重 | 评估必含物质使用 |

**考核：** 三项。其一，惊恐与躯体急症的鉴别要点能否说出四条；其二，能否示范四种降唤醒技术并说明各自的失效条件；其三，回避的记录写法（活动范围与次数）是否准确。

## 六、代价与边界

第一，**降唤醒技术不是万能的**。它能降低当下的痛苦，但不能替代对焦虑背后冲突的处理；长期改善仍需要结构化心理干预与必要时的药物治疗。

第二，**"不追问创伤"可能让护士觉得没帮上忙**。这个感受是真实的，但专业边界更重要：承接超出训练范围的内容，对双方都有风险。

第三，**本章不含诊断标准、量表阈值与用药方案**。所有判断以现行规范与具备资质人员的评估为准。

第四，**焦虑的护理容易"说不清成果"**。它的效果体现在活动范围扩大、就诊次数下降、发作后恢复变快这些不显眼的指标上，需要靠记录把它们显影，否则会被误认为"没做什么"。

**免责声明：** 本章为教学材料，不构成医学意见、诊断或治疗指导；一切评估与处置以现行规范、医嘱与所在机构制度为准。
