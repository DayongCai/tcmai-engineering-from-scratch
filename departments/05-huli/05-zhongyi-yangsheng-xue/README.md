## 三、三辨与四位面（实测）

| 三辨 | 词频 | 四位面（时令与人群） | 词频 |
|---|--:|---|--:|
| **养生原则** | **315** | 四季 | 922 |
| **养生方法** | **2,912** | 昼夜 | 585 |
| **时令与人群** | **1,614** | 年龄 | 338 |
|  |  | 体质与性别 | 746 |

三辨极差 **9.2×**；四位面极差 **2.7×**。

三辨 9.2× 是「方法」压倒「原则」（2,912 vs 315）：养生书写得最多的是「怎么做」，最少的是「凭什么」。这个比值不能当结构用——它只说明教材偏实践。四位面取时令与人群（2.7×）：四季 922 / 体质 746 / 昼夜 585 / 年龄 338，四类都有值且对应「什么时候、什么人」两个必须回答的问题。方法层轴（C，9.3×）与方法轴（A，3.8×）都是「方法」的再切分，取哪个都只是把 2,912 换个方式分堆。
