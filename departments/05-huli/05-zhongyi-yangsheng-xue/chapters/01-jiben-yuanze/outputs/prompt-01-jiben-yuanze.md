# 养生的第一判断不是做什么，而是此刻该顺着什么 · 提示词

## 用途

给「养生的第一判断不是做什么，而是此刻该顺着什么」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「天人相应在判断什么 → 四项评估：每次判断先看这四栏 → 判据与分档：顺、偏、逆 → 动作、边界与记录」这条链。
