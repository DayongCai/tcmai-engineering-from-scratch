## 三、逐单元读

### 5.1.1 神与情志活动

一、神的概念与广狭二义 神，是中医对人体生命活动最高层次功能及其外在征象的概括。中医论神，有广狭二义。广义之神，指人体生命活力的整体表现，即所谓生机、生命力，藏于脏腑经络气血之中，外显为面色荣润、目光有神、言语清晰、应答灵敏、动作协调、呼吸匀调、脉象和缓有力。故「能形与神俱，而尽终其天年」（素问·上古天真论），把形神相俱、神气不散视为健康长寿的基本标志。狭义之神，指精神、意识、思维、情感、知觉、记忆、意志等心理活动的总称，包括神、魂、魄、意、志五神与喜、怒、忧、思、悲、恐、惊七情，是中医学认识情志病、神志病的理论基础。精神养生所养之神，兼取二义，而以狭义之神为操作重点。 二、神的化生与物质基础 神的生成，源于先天之精，长养于后天水谷精气。「故生之来谓之精，两精相搏谓之神」（灵枢·本神），说明神由父母生殖之精相合而成，是生命活动最初的表现形式。「五味入口，藏于肠胃，味有所藏，以养五气，气和而生，津液相成，神乃自生」（素问·六节藏象论），说明后天饮食所化生的水谷精气，是神不断得到充养的物质来源。「血者，神气也」（灵枢·营卫生会），指出血是神活动的直接载体。故精充、气足、血旺则神旺；精亏、气虚、血少则神衰。养生所见之精神饱满或神疲乏力、心神不宁，多可由精气血之盛衰解释。饮食有节、起居有常、节欲保精，是养神的物质前提，单纯的心理调节不能替代精气血的充养。 三、神与五脏的关系 神分属五脏，而以心为主宰。「心者，君主之官也，神明出焉」（素问·灵兰秘典论）；「五脏所藏：心藏神，肺藏魄，肝藏魂，脾藏意，肾藏志」（素问·宣明五气）。五神各有所属，心神统摄诸神，故养神之要在养心，使心有所主、神有所归，则五脏气机安和。情志活动亦分属五脏，肝主谋虑、胆主决断、膻中主喜乐，五脏气血调和是情绪平稳的内在条件。 四、神在养生中的地位 神为形之主，形为神之宅。神安则形健，神扰则形伤，神去则形亡。故「恬淡虚无，真气从之，精神内守，病安从来」（素问·上古天真论），把精神内守列为养生第一要义。

### 5.1.2 情志与健康

一、情志致病的概念与条件 情志致病，又称内伤七情，指情志活动失调成为致病因素，直接损伤脏腑气血而发病。情志本为正常生理反应，并不必然致病。其致病与否，取决于四方面条件：一是刺激强度过大，如暴怒、骤惊、大悲；二是持续时间过长，如长期忧思、久郁不解；三是个体耐受与调节能力，与体质、年龄、既往经历相关；四是情志性质与脏腑虚实状态是否相合，虚者易受，实者易郁。 二、情志致病的基本机理 其一，直接伤及内脏。「怒伤肝」（素问·阴阳应象大论）；「心怵惕思虑则伤神，神伤则恐惧自失」（灵枢·本神），说明情志过极可循五脏所属而伤其精气。其二，扰乱脏腑气机。「百病生于气也，怒则气上，喜则气缓，悲则气消，恐则气下，惊则气乱，思则气结」（素问·举痛论），为情志致病气机紊乱之总纲。其三，先动于心而波及五脏。「悲哀愁忧则心动，心动则五脏六腑皆摇」（灵枢·口问）。其四，耗伤精气、化火生痰、瘀阻络脉，形成气滞—痰凝—血瘀的病理演变。其五，影响病情转归，久病之人情志不遂，常致病情反复、康复延迟。 三、情志致病的临床特点 与六淫外感相比，情志致病具有以下特点：发病多无外邪表证，起病缓而病程长；病位以心、肝、脾为多，常多脏同病；症状多兼情志异常与躯体不适，如胸闷太息、纳呆腹胀、失眠心悸、月经不调；病情随情绪波动而起伏，得情志之舒则减，遇情志之扰则增；易反复发作，难求速愈。故调养之要在解结顺气、和志安神，而非单纯用药。 四、情志致病的现代认识 现代认识：情志致病与应激反应研究有相通之处。心理社会应激可激活下丘脑—垂体—肾上腺轴与交感神经系统，引起皮质醇、儿茶酚胺水平变化，进而影响血压心率、胃肠动力与分泌、免疫监视功能与睡眠结构；长期应激与功能性胃肠病、原发性高血压、冠心病、紧张性头痛、失眠、焦虑抑郁状态等存在相关性。传统「七情内伤」着眼的是气机与脏腑的整体失调，现代研究着眼具体通路与指标，二者可互相参照，但现代认识不改经典原义。

### 5.2.1 清静养神

一、清静养神的内涵 清静养神，指通过减少外界纷扰与内心躁动，使神气内守、真气从之，是精神养生诸法之首务。「恬淡虚无，真气从之，精神内守，病安从来」（素问·上古天真论），为清静养神之总纲。恬淡，谓心境安静、少所贪求；虚无，谓不凝滞于物、不为外境所役；精神内守，谓神不外驰、意不逐境。三者相因为用，非断灭思虑、离世独居之谓。 二、经典依据与理论阐释 其一，少欲则气不乱。「志闲而少欲，心安而不惧，形劳而不倦」（素问·上古天真论），指出欲望有节、心境安定，则形体虽劳而不致困倦。其二，清静则外邪难侵。「清静则肉腠闭拒，虽有大风苛毒，弗之能害」（素问·生气通天论），说明心神清静则卫外固密。其三，静则神藏。「阴气者，静则神藏，躁则消亡」（素问·痹论），躁动耗神，安静养神。其四，养心之要在于主静。朱丹溪《格致余论》谓「儒者立教曰：正心、收心、养心，皆所以防此火之动于妄也」，其意在于以静制动，防情志之火妄动。曹庭栋《老老恒言》亦以养静为一身摄生之首务。 三、具体做法 1. 减少欲求与外扰：梳理自身欲望与比较之心，明确能力边界，不求事事周全；每日留出不少于30分钟的信息静默时段，关闭非必要通知，避免睡前过度刷屏。 2. 建立安宁节律：起居有常，尽量固定入睡与起床时间，子时前入睡；饮食有节，食时专心，不边食边议烦杂之事。 3. 设置静息功课：每日晨起或午后静坐、闭目养神10至20分钟；闭目，默数呼吸，不刻意控制，不走神即可，杂念起时轻轻拉回。 4. 环境清静：居室整洁简净、光线柔和、通风良好；工作与休息区域尽量分开，不在卧床处置办公与纷争之事。 5. 遇事缓应：遇烦扰之事先暂离现场数分钟，缓言缓行，待气平再作应答与决策。 四、适用人群与注意事项 本法适用于各类人群，尤宜于思虑繁多、情绪易波动、入睡困难、从事高负荷脑力工作者及老年人。注意事项：恬淡虚无不等于消极避世，亦非取消正常社会交往与责任；性格内向、情绪低落者不宜过度独处，应增加户外活动与亲友往来；静息功课不可挤压必要睡眠与进餐时间；已确诊焦虑、抑郁等精神心理疾病者，静坐等放松方法仅为辅助，不能替代规范诊疗（就医提示）。

### 5.2.2 调摄情志

一、节制七情的含义 情志为人之常，不可绝，亦不可纵。节制七情，指在承认情志正常性的前提下，使情志反应有度、发而有节、过而不留，既不压抑自苦，亦不暴发伤人。「和喜怒而安居处」（灵枢·本神），以「和」字统摄情志调摄，是节制七情的基本准则。《千金要方·养性》所列戒条，如莫忧思、莫大怒、莫悲愁、莫大惧，勿汲汲于所欲、勿涓涓怀忿恨，皆言情志之过当戒。《寿世保元·摄养》以薄滋味、省思虑、节嗜欲、戒喜怒为摄养之要，亦见其义。 二、情志管理的四步法 1. 觉察：识别情绪的名称与强度，可用0至10分自评；同时觉察躯体信号，如胸闷、面热、手紧、胃部不适。练习方法：每日情绪日记，记录事件、想法、情绪、反应、结果五栏。 2. 接纳：承认情绪有其缘由，不急于评判「不该有」；告诉自己情绪是信息而非命令，可在不压抑的情况下暂缓行动。 3. 表达：以「我」为主语陈述感受与需要，避免指责式表达；对可信之人倾诉，或以书写、绘画、运动等方式表达。 4. 调节：采取具体措施降低唤起水平，如缓行、深呼吸、离开现场、规律作息；事后再作理性回顾与问题解决。 三、具体做法 （一）即时缓解 1. 暂停六秒：感到情绪骤起时，先不发言、不动作，缓慢呼气6次，再决定如何应对。 2. 转换注意：将注意力移向具体事物，如观察窗外景物、整理桌面、缓步走动5至10分钟。 3. 躯体放松：肩颈与下颌放松，双手搓热后浴面、按揉太阳穴与内关穴各1分钟。 （二）长期调摄 1. 节律保障：固定睡眠时间，成年人一般保证7至8小时；避免长期熬夜，熬夜易致烦躁易怒。 2. 运动疏解：每周进行150分钟以上中等强度有氧运动，如快走、慢跑、八段锦、太极拳；以运动后微汗、精神舒展为度。 3. 减少诱因：限制浓茶、咖啡、酒精；减少无谓的争执场合与过量信息摄入；高风险时段（如极疲劳、极饥饿时）不议敏感之事。 4. 建立支持：与家人同事保持稳定往来，培养不少于一项长期兴趣；遇重大生活事件时主动寻求支持。 5. 认知调整：区分可控与不可控之事，对不可控者接受，对可控者行动；降低完美主义与过度责任感。

### 5.2.3 修德养性与怡情养神

一、仁者寿的含义 「仁者寿」是中国传统文化关于道德修养与健康长寿关系的经典命题。「知者乐水，仁者乐山；知者动，仁者静；知者乐，仁者寿」（论语·雍也），指出仁德之人内心安静、与人为善，故多得其寿。《礼记·中庸》亦谓大德必得其寿。中医养生学吸收这一思想，形成修德养性、以德润身的养生传统。所谓修德，指修养仁爱、宽厚、诚信、知足、感恩、节制等品性，其要不在外在形式，而在心地平和、不欺不贪、与人无怨。 二、经典依据与理论阐释 孙思邈在《千金要方·养性》中明确指出：「夫养性者，欲所习以成性，性自为善，不习无不利也。性既自善，内外百病皆悉不生，祸乱灾害亦无由作，此养性之大经也」。所谓养性，重在养成善性，性善则情志多和，情志和则脏腑气机调畅、气血冲和，此为修德所以能养生的道理所在。反之，心地刻薄、贪求无度、常怀怨怒者，情志易于过激，气机易于郁滞，虽服补药亦难奏功。故修德为精神养生之本，情志调摄为修德之用。 三、修德养生的具体做法 1. 存仁爱之心：待人接物以善意先之，遇分歧留有余地；主动关心家人与邻里，参与力所能及的助人活动。实践方式：每周做一件力所能及的小善事，如探望长者、指导后学、参与志愿服务，量力而行，不勉强、不图报。 2. 养宽厚之量：遇冒犯时先了解原委，不轻易断定恶意；运用宽容练习，回想一件耿耿于怀之事，写下对方可能的处境与动机，尝试以更宽的解释替代原有判断，每周一次，每次15分钟。 3. 守诚信之节：言行一致，不欺己、不欺人；减少需要掩饰之事，则内心少愧少懼，自然气定神闲。 4. 知足与感恩：每日睡前记录三件值得感念之事，可具体到饮食、天气、他人帮助；减少横向比较与攀比消费，将精力转向自身可控的成长与关系。 5. 守本分之责：尽家庭与社会之责而不越界，不揽取非分之利；处事尽力而为、结果顺其自然，减少执念与怨尤。 6. 与人为善、以和为贵：家庭之内和睦为先，遇争执以解决问题为目标而非争胜负；职业场合不搞倾轧，减少敌意与猜忌。 四、适用人群与注意事项 本法适用于各年龄段、各种体质人群，尤宜于性格刚急、易怒好争、贪求较多、人际关系紧张者。

### 5.3.1 不同人群的精神养生

一、青少年的身心特点 青少年处于生长发育的旺盛时期，中医学认为此时肾气渐充、天癸至而精气溢泻，形与神均未稳定。《素问·上古天真论》论女子二七、男子二八之候，指出此期冲任二脉通盛、月事以时下、精气溢泻，为生命节律变化的重要阶段。情志方面，青少年心气偏盛、肝气易动，情绪反应快而强度大，喜、怒、忧、思转换迅速；自我意识增强而调节能力尚弱，故易见烦躁、郁闷、委屈、冲动。现代认识：青春期神经内分泌变化与情绪波动、睡眠相位后移有相关性，情绪调节能力随前额叶发育而逐步成熟。常见的压力来源包括学业竞争、升学考试、同伴关系、亲子沟通、网络信息与自我形象关注。 二、精神养生要点 1. 睡眠为先：每日保证8至10小时睡眠，尽量在23时前入睡，周末不过度补觉；睡前1小时不使用手机与电脑，卧室保持安静黑暗。睡眠充足则情绪稳定，熬夜易致烦躁易怒、注意力下降。 2. 运动疏肝：每日中高强度运动不少于60分钟，或每周累计300分钟以上，如跑步、球类、游泳、跳绳、武术、瑜伽等，以微汗、心情舒畅为度；运动是青少年疏解郁气最有效的方式之一。 3. 用眼用脑有节：近距离用眼每20分钟远眺20秒以上，每40至50分钟起身活动；不在卧床暗环境下长时间看书或屏幕，注意阅读姿势与光线。 4. 情绪表达：鼓励以言语向父母、老师或朋友表达；养成写日记或写随笔的习惯，每日10至15分钟；通过音乐、绘画、体育、社团活动表达与转化情绪。 5. 网络节制：每日娱乐性屏幕使用时间宜有明确约定（如不超过1至2小时），不在睡前、餐时沉浸式使用；避免熬夜刷短视频与游戏，避免以网络比较加重焦虑。 6. 家庭与学校配合：家长宜多倾听、少责骂，关注过程而非仅看分数；不体罚、不羞辱、不与人攀比；重视同伴关系的困难与校园人际压力。 7. 学业压力调适：采用番茄工作法等分段学习；将大任务拆解为小目标；考试前适度运动与呼吸放松，不靠咖啡因与熬夜强撑。 三、常见偏颇与调养 1. 郁怒烦躁：多见于学业受挫、亲子冲突之时，宜疏肝解郁，方法见第5.3.2.1段。 2. 忧思焦虑：见于考试前后，宜规律作息、有氧运动与呼吸放松，方法见第5.3.2.2段。

### 5.3.2 常见情志失调的调养

一、病机与表现 郁怒烦躁，属中医情志失调之常见类型，其病机多以肝失疏泄为核心。郁，指情志不遂而气机郁滞，见情绪低落、胸胁胀满、善太息、咽中如有物阻；怒，指肝气升发太过，见性情急躁、易怒、面红目赤、口苦、头痛眩晕；烦躁，指心神不安而气火内扰，见心神不宁、坐卧不安、多梦易醒。若郁久化火，则见肝火上炎之候，如失眠多梦、目赤、耳鸣、便秘、小便黄；若肝气横逆犯脾，则兼见脘腹胀满、纳差、肠鸣泄泻；女子可见月经不调、经前乳胀、痛经。体质方面，此型多见于气郁质、阴虚质、湿热质及血瘀质者，亦常见于素体阳盛而生活节律紊乱之人。 二、调养方法 1. 情志调摄：先缓后理。情绪骤起时采用暂停六秒法，缓慢呼气6次再作应答。日常采用疏泄宣泄之法，向可信之人倾诉，或以书写、运动、歌唱等方式使郁气得舒；运用移情易性，借琴棋书画、花木园艺转移郁结之心；改变绝对化与过度苛责的思维习惯，区分可控与不可控之事。详见第5.2.2.1、第5.2.2.2段。 2. 起居调摄：固定入睡与起床时间，成年人以7至8小时为度；尽量在23时前入睡，避免熬夜，因夜间不眠最易化火伤阴而增烦躁；每工作40至50分钟起身活动5至10分钟，避免久坐气滞。 3. 饮食调养：以清淡、富含蔬菜与全谷为原则，定时定量，避免过饥过饱。可用（辅助）：玫瑰花、菊花、佛手、陈皮、决明子、百合等泡水代茶，每次用量宜小；多食绿叶蔬菜、豆类、菌类与新鲜水果。忌：辛辣煎炸、肥甘厚味、过量饮酒、浓茶与咖啡、夜间进食刺激性食物。注意：上述食材属药食同源或日常食用之品，仅在辨证适宜时辅助使用，不宜长期大剂量服用；孕妇、哺乳期妇女、儿童及慢病服药者须咨询医师后使用（就医提示）。 4. 运动调养：宜快走、慢跑、游泳、球类、八段锦、太极拳等，每周5次、每次30至45分钟，以微汗、气机舒展为度；八段锦中攒拳怒目增气力一式尤合疏肝之用。注意：情绪激动、血压偏高时不宜立即剧烈运动，宜先缓行与拉伸；中高强度运动前宜评估心肺功能。

*单元规模：3,569 汉字；出处 `教材·第5章·5.3.2`；本单元数值类命中 26。*

### 5.3.3 四时精神养生

一、春夏养神的总则 春夏为阳气生发、隆盛之时，人体的神志活动亦应顺应生长之机而舒展条达。「春三月，此谓发陈，天地俱生，万物以荣，夜卧早起，广步于庭，被发缓形，以使志生」（素问·四气调神大论），指出春季宜宽缓形体、舒展志意，使情志随春气而生发。又「夏三月，此谓蕃秀，天地气交，万物华实，夜卧早起，无厌于日，使志无怒，使华英成秀」（素问·四气调神大论），指出夏季宜使志无怒、心情开朗，使神气与夏气之盛相应。要言之，春夏养神重在「使志生」「使志无怒」，即疏其郁、畅其志、戒其怒。 二、春季养神要点 1. 情志：春应肝，肝喜条达而恶抑郁，故春季宜舒展情怀、忌郁怒压抑。遇事多以沟通化解，不宜强忍积怨；可结伴踏青、赏花、郊游、放风筝，使情志得舒。切忌连日闭门独居、郁思不已。 2. 起居：夜卧早起，晨起后可于庭院或公园缓步10至30分钟，衣着宜宽松舒适，不束身束缚；春季气候多变，宜随气温增减衣被，防倒春寒。 3. 运动：宜缓和舒展之运动，如散步、慢跑、太极拳、八段锦、六字诀中嘘字诀，每次30分钟左右；不宜骤然进行大强度运动。 4. 饮食与茶饮（辅助）：宜清淡甘润，多食时令绿叶蔬菜、豆芽、荠菜、春笋等；可用（辅助）玫瑰花、菊花、佛手片泡水代茶，每次用量宜小。忌过食酸涩、油腻与过量饮酒；阴虚火旺者不宜久服温燥之品。 5. 穴位保健（可辅助参考）：按揉太冲、太溪、内关、风池等穴，每穴1至2分钟。 6. 常见偏颇：春季易见烦躁易怒、失眠、眩晕、情绪波动，属肝气升发过旺或肝血不足之候，调养见第5.3.2.1段；过敏体质者情绪受躯体不适牵动，宜兼顾原发疾病规范治疗（就医提示）。 三、夏季养神要点 1. 情志：夏应心，心主神明，暑热易扰心神而致烦躁易怒、心神不宁。故夏季尤须使志无怒、心境平和，遇事缓应、不与人争；可于清晨或傍晚静坐、读书、听舒缓音乐，每次20至30分钟。 2. 起居：夜卧早起，午间安排20至30分钟小憩（以11时至13时为佳），以养心气；避免在正午高温时段长时间户外劳作与剧烈运动；居室通风，空调温度不宜过低，避免冷风直吹。

*单元规模：2,529 汉字；出处 `教材·第5章·5.3.3`；本单元数值类命中 10。*
