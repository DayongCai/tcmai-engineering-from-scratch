# 第 3 章 · 吃什么由体质和当下状态定，不由食物排行榜定

> **MOTTO:** 「善养性者，先饥而食，先渴而饮」——《备急千金要方·养性》
>
> **PROBLEM:** 配膳要背的条目，取决于从哪一头记。从体质记：9 种体质 × 宜与忌 2 档 = 18 条，加四季各 1 条时令修正 = 22 条。从食物记：常用食材上百种，每种再分寒热温凉、再分四季宜忌，条目数翻数倍且互相冲突。22 与数百，是两种完全不同的记忆负担，也是两种完全不同的出错方式。本章选前一头。【演算设定，非实测】

**双根因定位:** 环境逼迫（人一天至少三次面对「这一餐吃什么」，一天三次、一年千余次，判断必须轻到能在餐桌前完成，否则一定退回习惯与口味）+ 知识积累（食性、五味、归经、体质、食忌、药食同源目录分属不同体系，同一味食物在不同文献里评价不一，若不排出「先看什么」的次序，学得越多越不敢吃）

**本章说明：** 本章不引页码、不给剂量与疗程，不写「某方治某病」。所举食材只作性味与方向的示例，具体用法依个人情况与现行规范。

## 一、判断单位是「这一餐对这个人」

饮食养生最容易走偏的地方，是把「某食物好」当成结论。食物没有绝对的好坏，只有合不合适：姜对阳虚受寒的人是温中，对阴虚火旺的人是助火；绿豆对湿热的人是清利，对脾虚便溏的人是滑肠；梨对秋燥干咳的人是润，对痰湿咳嗽的人是助湿。

所以饮食养生的判断单位不是食物，也不是营养素，而是「**这一餐、这个人、这个状态下，合不合适**」。三个变量里，食物最容易查，人最难判，状态最容易漏。

「人」这一头，用体质做粗分。体质是长期稳定的倾向，决定了大方向：阳虚者整体偏温，阴虚者整体偏润，痰湿者整体偏燥湿。方向定错，具体吃什么都救不回来。

「状态」这一头，用当下的脾胃功能与病证做修正。同样是阳虚，平时可以温补，正在腹泻、发热、口疮时就不能补；同样是阴虚，平时润燥，痰多胸闷时就要先化痰。这就是为什么本章的表只给方向，不给固定食谱。

还有一条底座：**脾胃为后天之本**。饮食养生的所有收益，都要经过脾胃运化才能兑现。脾胃一伤，补品变成负担，食疗变成腹胀。所以任何配膳方案的第一条都不是「加什么」，而是「别让脾胃超载」：定时、定量、不夜食、不过食生冷。

## 二、四项评估：下筷之前看什么

| 评估项 | 看什么 | 常见误判 |
|---|---|---|
| 饥饱 | 是真饿还是到点了；上一餐到这一餐间隔多久；有没有「不饿也吃」的加餐 | 把嘴馋、无聊、焦虑当成饿 |
| 寒热 | 平时怕冷还是怕热；手足温凉；吃生冷后是否腹胀腹泻；吃辛辣后是否口干口疮 | 只看天气，不看本人反应 |
| 口味 | 近期偏嗜酸、甜、咸、辣、油中的哪一种；是否越吃越重 | 把「想吃」当成「身体需要」 |
| 食后反应 | 餐后腹胀、反酸、嗳气、困倦、排便变化、皮肤反应 | 只记「好吃不好吃」，不记身体的账 |

四项里最有信息量的是「食后反应」，也最容易被忽略。一个人对某类食物的真实态度，不写在营养表里，写在他餐后两小时的身体里。把这一栏记两周，比做任何体质问卷都准。

还有一层「谨和五味」的老话需要落地。《素问·五脏生成》讲五味偏嗜之害：多食咸则脉凝泣而变色，多食苦则皮槁而毛拔，多食辛则筋急而爪枯，多食酸则肉胝而唇揭，多食甘则骨痛而发落。这段话的意思不是某种味道有毒，而是**长期单向偏嗜会把饮食结构压成一条线**：口重的人盐与酱菜占了大半餐桌，喜甜的人主食之外再加甜饮与点心，蔬果与蛋白的位置被挤掉。判断偏嗜，看的是「一周里有多少种食物」而不是「咸不咸」，因为结构单一比某一种味道更伤人。

## 三、判据与分档：九种体质的配膳方向

下表只给方向与坑，不给食谱。判断时先按体质定大方向，再按当下状态（发热、腹泻、口疮、痰多、失眠）做临时修正。

| 体质 | 主要表现 | 配膳方向 | 最容易踩的坑 |
|---|---|---|---|
| 平和 | 食欲睡眠二便均正常，寒热耐受好 | 均衡、定时、不过偏，五谷为养、五菜为充 | 因为「没毛病」而长期外卖、夜食 |
| 气虚 | 易疲乏、气短、动则汗出、易感冒 | 益气健脾：小米、山药、大枣、鸡肉、扁豆 | 过度节食减重，把乏力当「排毒」 |
| 阳虚 | 畏寒、手足不温、喜热饮、便溏 | 温阳：姜、羊肉、桂圆、韭菜，温热熟食为主 | 一边温补一边冰饮、久待空调 |
| 阴虚 | 口干咽燥、手足心热、盗汗、便干 | 滋阴润燥：百合、银耳、梨、鸭肉、桑葚 | 用辛辣烧烤「开胃」，越吃越干 |
| 痰湿 | 形体偏胖、身重、苔腻、易困倦 | 健脾化湿：薏米、赤小豆、冬瓜、白萝卜 | 用水果代餐，甜饮不断 |
| 湿热 | 面油、口苦口臭、易生疮、便黏 | 清热利湿：绿豆、冬瓜、苦瓜、芹菜 | 用「祛湿茶」长期替代正常饮水 |
| 血瘀 | 面色晦暗、痛有定处、舌下脉络明显 | 活血行滞：山楂、黑木耳、玫瑰花、少量黄酒入膳 | 过食寒凉、久坐不动，只靠食物 |
| 气郁 | 情绪低落、胸胁胀、善太息、咽中如有物 | 疏肝理气：佛手、陈皮、玫瑰花、萝卜、柑橘 | 借酒解郁、情绪性暴食 |
| 特禀 | 明确过敏原、易起皮疹、鼻痒喷嚏 | 回避已知致敏物，饮食清淡稳定 | 把「发物」清单无限扩大，吃到营养不良 |

【教学设定】三档的分界靠三个可核事实：有没有正在治疗的病证、偏颇是否伴功能下降、食后反应是否已经影响日常。三者占其一按方向微调，占其二先减负担，占其三只作配合。

第三档最容易被越过——不少人一边服药一边自行加「食疗方」，两套方案互相干扰，反应出现时谁也说不清来源。

## 四、动作、边界与记录

动作只有三条。

**第一条，先减后加。** 先减夜食、减甜饮、减油炸、减酒，等减法稳定下来再谈「加什么」。减法做过一轮，脾胃的负担降下来，加法才接得住。

**第二条，一次只动一餐。** 从最容易控制的那一餐入手（多数人是早餐），把它固定成「有主食、有蛋白、有蔬菜」的结构，其余两餐不动。改一餐能坚持一个月，比改三餐坚持三天有用。

**第三条，遇到这几种情况停。** 发热、急性吐泻、急性腹痛、消化道出血、术后恢复期、孕期出现异常症状，一律停止一切「调理」类饮食，改为清淡易消化并就医。正在服药的慢病人群，加任何药食同源之品前先问医师，避免相互影响。

食忌要分三类记，不要混成一锅「忌口」：

| 类别 | 依据 | 举例 |
|---|---|---|
| 病证食忌 | 现有病证与治疗方案 | 消渴控糖、脾胃病忌生冷油腻、痛风限高嘌呤、肾病按医嘱限盐与蛋白 |
| 特殊人群食忌 | 生理阶段 | 孕产期忌酒与生食、婴幼儿不加盐糖与整粒坚果、老年人忌过烫与过硬 |
| 药食界限 | 药食同源目录 | 目录内可按日常食用量用于膳食；目录外属药品，须遵医嘱，不作日常食疗 |

记录字段六项：日期与餐次、吃了什么（大致分量，不用称重）、餐前饥饱与寒热感、餐后两小时反应、当日排便、下次调整一条。六项写满两周，体质方向基本能看出来。

失效模式四种：

| 失效 | 现场表现 | 后果 | 拦截 |
|---|---|---|---|
| 把食疗当治疗 | 停降压、降糖药，改吃「降三高」食物 | 指标失控，并发症风险上升 | 已有病证者，食疗只作配合，用药调整由医师决定 |
| 体质误判 | 怕冷即判阳虚，口干即判阴虚，只看一条 | 方向反了，越调越偏 | 体质判断至少两类证据，并与当季常见反应区分 |
| 单味长期大量 | 听说薏米祛湿就天天吃、听说绿豆好就顿顿喝 | 单一性偏，伤脾胃或加重虚寒 | 任何食材都不长期单用，一周内轮换 |
| 「发物」扩大化 | 把鱼虾蛋奶全列为发物，一概不吃 | 蛋白摄入不足，老年人肌肉流失 | 只回避本人明确过敏或明确诱发的食物 |

## 五、考核与带教

考核看三件事：给出一个「怕冷、便溏、喜热饮」的人和一个「口干、盗汗、便干」的人，能否各自说出方向与三条禁忌；给出一个正在服降糖药、想用「苦瓜降糖」替代部分主食的人，能否指出错在哪里、正确做法是什么；给出一份三日饮食记录，能否找出最该先减的那一项。

带教的关键是让学生先写「食后反应」，再写「吃了什么」。顺序反过来，记录就变成菜单，没有判断价值。

## 六、代价与边界

第一，**体质分型是粗分**。九种体质是教学与筛查用的框架，实际多为兼夹，且随季节与病程变化；分型不准时，以食后反应为准。

第二，**食性之说有经验成分**。四气五味的描述来自长期观察，不能等同于成分分析；同一食物在不同文献中评价不一，遇到冲突时按本人反应与传统主流口径处理，不迷信单一名目。

第三，**「先减后加」会让人失望**。多数人想要的是「吃什么能补」，得到的答案是「先别吃什么」。这个次序不能反过来，因为负担未减时的加法，通常只增加症状。

第四，**本章不含剂量与疗程**。药膳用量、膏方、药酒、保健品的具体用法均不在本章范围，依现行规范与所在机构制度执行；孕产、儿童、老年与肝肾功能不全者的饮食方案，须由专业人员个别拟定。
