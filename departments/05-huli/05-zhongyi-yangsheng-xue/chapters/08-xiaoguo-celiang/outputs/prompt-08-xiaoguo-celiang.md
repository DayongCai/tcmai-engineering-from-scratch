# 养生有没有效，要看同一把尺子量了两次 · 提示词

## 用途

给「养生有没有效，要看同一把尺子量了两次」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「测量的对象是「变化」，不是「状态」 → 四类指标：各自测什么、各自骗人在哪 → 判据与分档：改善、稳定、恶化 → 动作与边界：怎么把测量做实」这条链。
