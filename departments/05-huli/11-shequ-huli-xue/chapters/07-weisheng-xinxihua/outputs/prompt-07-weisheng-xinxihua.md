# 系统能替你提醒，替不了你判断；电话能替你呼救，替不了你先动手 · 提示词

## 用途

给「系统能替你提醒，替不了你判断；电话能替你呼救，替不了你先动手」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「数据：先可信，再自动 → 急救：先识别，再呼救，再处置 → 记录字段 → 三种失效」这条链。

## 提示词

```
我在学《社区护理学》第 7 章「系统能替你提醒，替不了你判断；电话能替你呼救，替不了你先动手」，本章 5 节 / 2,801 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 数据质量的四条判据
   - 权限与最小必要
   - 远程服务的适用与不适用
   - 需要用手或眼睛确认的事，远程做不了
   - 智能辅助的边界
   - 以现场所见为准，就地核实，改字段，留痕，回头查一次同批人
4. 指出本章写到类别就止步、不再给参数的地方。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，不构成诊疗、急救操作或信息安全的技术意见。所述判据、顺序与记录要求用于训练流程意识；具体操作以现行规范与所在机构制度为准。
