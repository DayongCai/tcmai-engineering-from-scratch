# 照护失能老人，先算清「哪几件事他做不了」，再谈人力 · 提示词

## 用途

给「照护失能老人，先算清「哪几件事他做不了」，再谈人力」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「分层与「三种介入」 → 观察什么：五个最容易出事的地方 → 记录字段与尊严 → 三种失效」这条链。

## 边界

本章为教学材料，不构成诊疗、康复或照护等级的建议。所述分层、观察项与介入档位用于训练判断与记录；具体操作以现行规范与所在机构制度为准。
