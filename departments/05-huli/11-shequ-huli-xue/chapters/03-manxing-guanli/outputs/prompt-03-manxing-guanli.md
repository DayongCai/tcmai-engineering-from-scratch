# 慢病管理的产出不是「随访次数」，是「他自己能处理的那几步」 · 提示词

## 用途

给「慢病管理的产出不是「随访次数」，是「他自己能处理的那几步」」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「把「管理」重新定义：谁能做决定，就管到谁 → 分层、随访内容与转介条件 → 自我管理支持：教三步，不教一套 → 记录字段」这条链。

## 边界

本章为教学材料，不构成诊疗或用药建议。所述分层、随访内容与教学步骤用于训练组织与记录；具体操作以现行规范与所在机构制度为准。
