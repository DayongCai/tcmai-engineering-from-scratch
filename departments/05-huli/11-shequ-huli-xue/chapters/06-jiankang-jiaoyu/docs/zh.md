# 第 6 章 · 健康教育的产出不是「讲了几场」，是「他回去改了哪一步」

> **MOTTO:** 「其知道者，法于阴阳，和于术数，食饮有节，起居有常，不妄作劳，故能形与神俱，而尽终其天年，度百岁乃去。」——《素问·上古天真论》
>
> **PROBLEM:** 社区每年办很多场讲座：摆桌子、挂横幅、发手册、拍照、记人数。年底统计，场次与人数都很可观，而居民的盐罐、油壶、烟盒、药盒没有变化。原因不在讲得不好，在于设计时定的是「讲什么」，而不是「他今天回去改哪一步」。前者可以用场次衡量，后者只能用行为衡量——衡量方式决定了设计方式。

**双根因定位:** 环境逼迫（集体宣教是唯一能在有限人力下覆盖大量人群的形式，而它的信息传递是单向的、平均的，对每个人的「卡点」都不精准） + 知识积累（把「知道—相信—能做—做了」拆成四段，并承认每一段的失败原因不同，使教育从「讲清道理」变成「拆掉执行障碍」）

## 一、四段链条：知道不等于做到

《素问·上古天真论》列的那串「法于阴阳，和于术数，食饮有节，起居有常，不妄作劳」，二十二个字里没有一句是讲道理的，全是行为。古人早看清了：健康靠的是行为，而行为靠的是条件。

四段链条，每段的失败长得不一样：

**知道。** 缺信息，或信息被噪音淹没。失败表现是「没听说过」「记成别的了」。
**相信。** 信息与他的经验冲突。失败表现是「我邻居这么吃一辈子也没事」「医生自己还抽烟」。
**能做。** 环境不允许。失败表现是「知道该少放盐，但一家人一起吃，做淡了没人吃」。
**做了并能维持。** 缺反馈与支持。失败表现是「试了两周，没感觉，就放下了」。

四段之中，社区教育最常只做第一段，然后把第二三四段的失败归因于「居民不配合」。更有效的做法是**从第四段倒推**：先问他现在实际怎么做，再问他为什么这么做，再找一个「改起来最省力的一步」。这一步通常不是最重要的一步，是最容易做到的一步。

倒推还有一个副作用值得注意：找到的「一步」往往是**器物与流程**，而不是知识。一个人不是不知道少吃盐，是家里的勺子大、一家人口味重、他做饭时没空分两份。真正管用的干预常常是换一个勺子、买一个分格餐盘、把菜分成两份再调味——这些不是教育，是提供工具。分清「缺知识」与「缺条件」，是设计的第一步，也是最多人跳过的一步。

## 二、设计：一个目标、三次接触、一个动作

| 要素 | 具体要求 | 常见反例 |
|---|---|---|
| 目标 | 一次教育只定一个行为目标，可观察、可复述 | 「提高健康素养」「普及慢病知识」 |
| 对象 | 按「卡点」分组，不按诊断分组 | 把初诊者与十年老病号放同一场 |
| 内容 | 只讲与那一步直接相关的三条信息 | 从病因讲到并发症，讲满四十分钟 |
| 形式 | 按识字、听力、时间、场所、语言选 | 一律用统一课件＋纸质手册 |
| 动作 | 现场演练一次，对方做一遍 | 只讲不练，或只由讲授者示范 |
| 支持 | 约定下一次谁来看、看什么 | 讲完即结束，无后续 |
| 评价 | 行为、复述、到场三类指标 | 只统计场次与人数 |

**一个目标。** 「这一个月，把家里的盐勺换成小的」比「低盐饮食」有效，因为前者可以当场完成并核对。目标要小到能在两周内看到结果，大到值得做——太小的目标（「今天少喝一口汤」）没有意义，太大的目标（「戒烟」）让人直接放弃。折中的做法是把大目标切成第一刀：「这周先把早上那支烟推迟到早饭后」。

**三次接触。** 一次讲、一次练、一次回看。三次不必是同一种形式：讲可以在活动室，练可以在他家厨房，回看可以是一个电话。少了「练」与「回看」，教育就停在知道那一段。

**一个动作。** 每场活动必须有一个当场完成的动作：换勺、量一次血压并读出来、把药按日分格、演练一次低血糖时该吃什么。动作完成的当场反馈，是四段链条里唯一能同时解决「能做」与「做了」的环节。

形式与载体按条件选，不按潮流选。识字率低的群体用图与实物演示；听力下降者用大字与近距离；白天要上班的人用傍晚或周末；不愿公开露面的人用入户或一对一。方言与用语同样重要：一句本地话的解释，胜过三页标准表述。

选择时还要算一笔时间账【教学设定】。居民愿意为一件事投入的时间通常在十几分钟内，超过这个长度，注意力会转向手机与门口。所以「二十分钟讲完、五分钟做完、留一个电话」的结构，往往比一小时的系统授课更有效。系统知识可以印在纸上让他带走，现场只做那一步。

## 三、评价：三类指标，一个禁区

**行为指标**：目标行为有没有发生、发生了多久。这是唯一能说明教育有效的指标，也最难收集，通常靠随访时看实物（盐勺、药盒、烟盒）而不是靠问。

**复述指标**：对方能不能用他自己的话讲出三条。复述正确是最低成本的效果检验，也是「知道」那一段唯一可靠的验证。

**到场与完成指标**：通知到的人来了多少、来的里面完成了动作的有多少、没来的是谁。第三项最容易被忽略，而它决定了下一轮该找谁。

一个禁区：**不承诺效果。** 「听了这堂课就能控制好血压」是不能说的话。原因有两层：一是教育只是众多因素之一；二是承诺一旦落空，损失的是下一次的信任。可以说的是范围与条件：「按这三步做，多数人能把每天的量降下来；两周后我们来看看你的实际情况」。

评价还要避开一个陷阱：**用热闹代替效果。** 现场反应好、提问多、掌声响，只能说明讲得生动，不能说明他回去会改。反过来，一场安静的活动可能效果很好，因为每个人都在动手做。判断标准永远是三个月后那几个具体动作还在不在。

## 四、记录字段与隐私

教育记录要能支持「这个人在哪一段卡住」。

**对象与分组依据**（按什么卡点分的组）；**目标行为**（一句话）；**本次形式与时长**；**讲的三条信息**（列出来，不写「讲解了相关知识」）；**当场动作与完成情况**；**复述内容**（引原话）；**下一步与责任人**（谁在什么时候回看什么）；**未到场者与原因**（这一栏最常空着）。

隐私在集体活动中最容易失守，三个场景：**点名**（当众说「某某血糖高，大家要注意」）、**个案举例**（用本社区真实的人当例子）、**拍照发群**（含人脸与姓名的照片）。三条对策：分组用编号或序号、举例一律改到不可识别、拍照先征得同意并避开面部与姓名。

还有一条容易被忽略：**不歧视与不强迫。** 教育不是改造，参与者有退出的自由。对不愿改变的人，反复劝说会把人推得更远；可行的做法是保留联系、降低门槛、等他准备好的时候再来。

## 五、三种失效与考核项

**其一，把教育当形式。** 表现是「已完成健康教育一次，发放资料若干」。这是活动记录，不是教育记录。判断办法还是那句：这条记录能不能让另一个人接着做？不能，就是形式。

**其二，隐私泄露与标签化。** 「糖尿病病人组」「高血压组」这类称呼一进记录，人就被简化成病。更严重的是在公开场合按病分组排队、按病贴标识。改写方向是按需求分组、只在必要的范围内使用诊断信息。

**其三，责任边界不清。** 两条越界：承诺疗效、代替医生给方案（「你这个药可以停」）。两条反向越界：明知对方理解错误而不纠正、明知存在风险而不提示转介。教育的边界很清楚：可以讲清事实与做法，不能替人做医疗决定。

**考核项五条：** 一、把一个空泛目标改写成可观察的行为目标。二、为一位居民设计三次接触，写明每次的形式与内容。三、现场做一次复述检验，记录原话并判断是否合格。四、写出一次活动的七项记录字段。五、说明集体活动中三条隐私对策，各举一个反例。

## 代价与边界

**第一，小目标见效慢。** 「换盐勺」听上去琐碎，一年下来可能只是几克之差；而它的价值在于让人第一次成功。成功经验比知识更能带来下一次改变。这个道理讲给管理者听往往不被接受，因为它的成果无法写进总结。

**第二，精准化需要成本。** 按卡点分组、一对一入户、方言讲解，都比大课贵。可行的折中是「大课筛人＋小课做事」：大课负责让需要的人出现，小课与入户负责让他做成一件事。

**第三，教育不能替代服务。** 一个人不做，可能不是不懂，而是没有条件（买不起、走不动、没人陪）。在这种情况下再做十次教育都是无效的，该做的是转介与资源对接。

边界四条：不承诺效果；不替代诊疗与处方；不评价个人生活方式的好坏，只谈具体风险与可行选择；不对群体作标签化描述。涉及心理危机、成瘾、家庭暴力等情形，按流程转介，不在教育场景中处理。还有一条常被忽略的边界：不把教育当成「已经尽到责任」的证据——讲过不等于解决，缺少条件的人需要的是转介与资源对接。
