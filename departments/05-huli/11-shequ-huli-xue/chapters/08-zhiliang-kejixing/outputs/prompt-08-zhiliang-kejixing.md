# 可及性不是「有没有服务」，是「他能不能用得上」 · 提示词

## 用途

给「可及性不是「有没有服务」，是「他能不能用得上」」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「质量三层：结构、过程、结果 → 口径：没有口径的指标不是指标 → 可及性四维：把人挡在门外的四种方式 → 公平、报告与改进」这条链。

## 边界

本章为教学材料，不构成质量管理、法律或政策意见。所述维度、口径与改进方法用于训练识别与表达；具体操作以现行规范与所在机构制度为准。
