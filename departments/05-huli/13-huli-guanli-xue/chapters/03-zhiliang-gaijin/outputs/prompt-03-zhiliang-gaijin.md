# 指标没有分母与口径，就只是一个数字 · 提示词

## 用途

给「指标没有分母与口径，就只是一个数字」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「质量可以分解，不能概括 → 指标的四要素：分子、分母、口径、时点 → 改进循环：每一步都要交出东西 → 数据质量：五个维度决定指标能不能用」这条链。

## 提示词

```
我在学《护理管理学》第 3 章「指标没有分母与口径，就只是一个数字」，本章 5 节 / 3,195 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - （该做的动作有没有按规范做——评估、核对、告知、记录）、
   - 这就是「指标无分母」失效的完整形态：数字是真的，结论是假的
   - 其一是不可比较性说明
   - 其二是指标分类
   - 计划（P）：把问题写成一句可核对的话
   - 执行（D）：限定范围与时限
4. 指出本章写到类别就止步、不再给参数的地方。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，所述指标框架、改进循环与数据要求用于训练质量判断与记录习惯，不构成医学意见、质量裁定或对任何机构的评价；具体操作以现行规范与所在机构制度为准。
