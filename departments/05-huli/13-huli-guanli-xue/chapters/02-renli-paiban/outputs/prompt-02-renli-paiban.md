# 排班的公平要写成规则，才经得起追问 · 提示词

## 用途

给「排班的公平要写成规则，才经得起追问」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「人力需求：先算工作量，再谈人头 → 排班：三个原则与一张能查的表 → 公平性：把「我觉得不公」变成可查的数 → 培训与带教：从需求到效果的四段」这条链。

## 边界

本章为教学材料，所述原则、字段与算例用于训练管理判断，不构成医学意见、用工意见或对任何机构排班安排的评价；具体操作以现行规范与所在机构制度为准。
