# 复苏的成败不在手法漂亮，而在中断的那几十秒 · 提示词

## 用途

给「复苏的成败不在手法漂亮，而在中断的那几十秒」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「几十秒的去向：质量由停手时间决定 → 判据与升级路径【教学设定】 → 动作与时限：分钟档上谁做什么 → 记录字段：时间轴九列」这条链。

```

正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。
```

## 边界

本章为教学材料，不构成诊断或急救指导。一切复苏操作须由受过培训的人员依现行规范与设备说明执行；具体操作以现行规范与所在机构制度为准。
