# 意识下降先当急症处理，别急着给它贴标签 · 提示词

## 用途

给「意识下降先当急症处理，别急着给它贴标签」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「意识是结果，不是原因 → 判据与升级路径【教学设定】 → 动作与时限：分钟档上谁做什么 → 记录字段：时间轴八列」这条链。

## 提示词

```
我在学《急危重症护理学》第 8 章「意识下降先当急症处理，别急着给它贴标签」，本章 6 节 / 3,185 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 先保气道与呼吸，再查血糖，再查循环与氧合，最后才做神经定位
   - 其一，「他是老年痴呆，一直都糊涂」
   - 其二，「他睡着了」
   - 第一层，三个维度，两分钟内完成
   - 分项记的价值在于：同一个人可能睁眼正常而语言混乱，这种组合本身就指向特定方向
   - 第二层，两项旁证，五分钟内完成
4. 本章自陈的边界（不得越过）：
   - **本章不给镇静药物名称、剂量与疗程，也不给降颅压措施的具体参数。** 这些是医师依病因、影像与病情作出的决定。
   - **评分工具是筛子，不是诊断。** 同一分数可由完全不同的原因造成；把分数当成病因判断，会把一个代谢性问题送去做神经影像。
   - **「降一分即报」的代价是呼叫量增加。** 大量呼叫里会有相当比例最终无事。这个代价是可接受的，因为反向错误不可逆；但要用「一次报清四项」来降低无效呼叫的比例。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，不构成诊断或治疗建议。一切检查、用药与气道处置须由具备资质的执业人员依现行规范与所在机构制度作出。凡见意识较前下降、瞳孔不等大、新发抽搐、抽搐超过五分钟或抽后意识不恢复者，立即呼救并按应急流程处置，不做等待观察。本章不给药物剂量、不给评分工具的原始条目分值、不给结局数据；具体操作以现行规范与所在机构制度为准。
