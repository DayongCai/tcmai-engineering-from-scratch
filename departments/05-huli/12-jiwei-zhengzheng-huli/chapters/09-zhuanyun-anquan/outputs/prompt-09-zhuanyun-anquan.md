# 转运是一次可控的病情恶化，不是一段路程 · 提示词

## 用途

给「转运是一次可控的病情恶化，不是一段路程」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三个易损段：移动、途中、交接 → 判据与升级路径【教学设定】 → 动作与时限：出发前十分钟与途中五分钟 → 记录字段：转运单十列」这条链。

## 边界

本章为教学材料，不构成诊断或治疗建议。一切转运决策与途中处置须由具备资质的执业人员依现行规范与所在机构制度作出。凡见途中意识下降、血氧持续下降、活动性出血、设备失效无法维持支持者，立即就近停靠并呼救，不强行抵达目的地。本章不给药物剂量、不给转运时限标准、不给结局数据；具体操作以现行规范与所在机构制度为准。
