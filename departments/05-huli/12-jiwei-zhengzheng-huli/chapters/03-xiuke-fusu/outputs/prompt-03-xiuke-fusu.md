# 休克先看灌注够不够，再问血压低不低 · 提示词

## 用途

给「休克先看灌注够不够，再问血压低不低」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「血压是最后一个投降的参数 → 判据与升级路径【教学设定】 → 动作与时限：分钟档上谁做什么 → 记录字段：时间轴八列」这条链。

## 边界

本章为教学材料，不构成诊断或治疗建议。一切补液、用药与处置须由具备资质的执业人员依现行规范与所在机构制度作出。凡见意识改变伴皮肤湿冷、尿量锐减、血压较基础值明显下降、或皮疹伴声嘶与呼吸困难者，立即启动应急流程并呼救，不做等待观察。本章不给药物剂量、不给输液速度、不给结局数据；具体操作以现行规范与所在机构制度为准。
