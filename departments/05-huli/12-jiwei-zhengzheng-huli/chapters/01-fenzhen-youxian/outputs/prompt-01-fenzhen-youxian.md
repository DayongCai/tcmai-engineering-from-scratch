# 分诊不是排队，是把有限的注意力按分钟重新分配 · 提示词

## 用途

给「分诊不是排队，是把有限的注意力按分钟重新分配」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「门口那一分钟：先归类，再分层看 → 判据与升级路径【教学设定】 → 动作与时限：分钟档上谁做什么 → 记录字段：时间轴七列」这条链。

## 提示词

```
我在学《急危重症护理学》第 1 章「分诊不是排队，是把有限的注意力按分钟重新分配」，本章 5 节 / 3,435 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 其一，把分诊当成挂号排序
   - 其二，把分诊当成量体温、测血压
   - 其三，把分诊当成一次性动作
   - 第一层，三十秒，只问三件事：气道通不通、有没有在大量出血、叫得应不应
   - 第二层，两分钟，看五项生命体征加三项附加
   - 第三层，五分钟，只看趋势线索：尿量、皮肤灌注、毛细血管再充盈、呼吸费力程度
4. 本章自陈的边界（不得越过）：
   - **分级标准是统计出来的，不是生理定律。** 同一个人两次分诊得到不同级别，不一定是谁错了；但必须有再评估留痕。要求「每次分级都一致」，等于逼人抄前一次的结果。
   - **快与准不能同时最大化。** 本章选「先红线、后精细」：宁可让十个黄级多等十分钟，也不让一个红级多等一分钟。这个选择的代价是黄级病人的体验与投诉，要在告知环节补回来，不能靠加快分诊解决。
   - **直觉条款给的是升级权，不是处置权。** 觉得不对可以升级、可以要求复核，但不能据此自行用药、自行决定去向。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，不构成诊断或治疗建议。一切分诊、检查、处置与转运，须由具备资质的执业人员依现行规范与所在机构制度作出。凡见意识迅速下降、呼吸困难不能成句、活动性大出血、抽搐持续不止者，按最高优先级启动应急流程，不做等待观察。本章不给药物剂量、不给疗程、不给抢救结局数据；具体操作以现行规范与所在机构制度为准。
