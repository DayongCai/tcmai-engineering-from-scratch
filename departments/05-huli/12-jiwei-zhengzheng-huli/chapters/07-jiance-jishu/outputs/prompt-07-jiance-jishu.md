# 监护仪给的是数，护士要给的是趋势 · 提示词

## 用途

给「监护仪给的是数，护士要给的是趋势」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「数、趋势与阈值：三者不能互相替代 → 判据与升级路径【教学设定】 → 动作与时限：技术配合的分寸 → 记录字段：趋势表与报警日志」这条链。

## 提示词

```
我在学《急危重症护理学》第 7 章「监护仪给的是数，护士要给的是趋势」，本章 5 节 / 2,924 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 数回答「此刻是多少」
   - 趋势回答「往哪走」
   - 这正是最该报的时刻——不是越过阈值的时候，是斜率改变的时候
   - 阈值回答「什么时候必须动手」
   - 监护仪测的是它以为的东西
   - 当读数与病人表现不一致时，先信病人，再查设备
4. 本章自陈的边界（不得越过）：
   - **本章不给报警阈值、不给通气与净化参数、不给药物剂量。** 参数随设备、病种与机构预案变化；抄一个数值进教材，就是把可能过时的设定教成标准。
   - **连续监测的代价是过度诊断。** 测得越密，越容易抓到无意义的波动，进而引发不必要的干预。取舍是：只对「有趋势意义」的波动反应，单次抖动先复查。
   - **本章不给任何设备的分辨率与误差数值。** 这些是厂商参数，写错比不写更糟。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，不构成诊断或治疗建议。一切监测、置管与设备操作须由受过培训的人员依厂商说明、现行规范与所在机构制度执行。凡见趋势性恶化、报警反复、或读数与病人表现明显不符者，先评估病人再排查设备，同时报告上级。本章不给参数、不给剂量、不给结局数据；具体操作以现行规范与所在机构制度为准。
