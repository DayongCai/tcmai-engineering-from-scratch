# 健康评估

**03-jiankang-pinggu** · 护理学院 · 8 章 · 8 单元 · 145,170 汉字 · 派生课

> 锚点：**个体在生理、心理、社会、环境生态四个适应域上，相对自己的「从容长寿」目标，都处于最合适状态。**

## 一、这门课的判据（重构后的骨架）

本课不再按「问诊 → 查体 → 辅助检查」组织，而按**四个适应域**组织，每域一章：

| 域 | 这个域在问什么 | 父课词频 |
|---|---|--:|
| 生理适应 | 身体还能不能维持稳态 | **720** |
| 社会适应 | 角色、参与和支持还在不在 | 424 |
| 心理适应 | 尊严、自主与情绪还撑不撑得住 | 308 |
| 环境生态适应 | 所在场所是否还容许他这样活 | 259 |

四域极差 **2.8×**。

**「最合适」不等于「最高」**：功能练到极限，往往同时压缩了休息、社交与安全的余量。本课找的是**稳态区间**，不是峰值。

**四域是并联的，不能相加**：任何一域掉出合适区间，其余三域的代偿会在数月内被耗尽。所以整合判断只做一件事——找短板、看代偿还能撑多久、优先修短板。

## 二、必须说清的三件事

**1.「从容长寿」这套框架是本轮引入的，不是父课原话。**
实测：`从容长寿` 0 次、`长寿` 0 次、`最合适` 0 次、`适应` 14 次。
父课写的是「评估要点」与「护理要求」；把它们重组到四域上，属框架层新增，已登记在 `meta.json#底本.note`。

**2. 本课仍是派生课，本库无《健康评估》母本。**
8 章对应四门护理课的 8 个评估类单元，`locator` 一律「派生·」：

| 父课 | 取用 |
|---|---|
| 内科护理学 | 第 3 章评估与病情观察 · 第 5 章常见症状 · 第 17 章质量与风险 |
| 基础护理学 | 第 3 章患者安全与权益 · 第 4 章生命体征 · 第 14 章考核评价 |
| 老年护理学 | 第 4 章老年综合评估基础 |
| 外科护理学 | 第 4 章外科护理评估与记录 |

**3. 四块内容不编**：问诊技术、体格检查手法、实验室判读、心电图判读——底本无对应单元。
**另有两域证据偏薄**：心理域（父课写在「权益」里，无独立心理评估单元）、环境生态域（词频最低 259、无专用单元）。
这两章原按「四域判据 + 清单」组织；**本轮已按 `补源约定.md` 补入外源工具**（GDS／Mini-Cog／CDC 居家清单／Hendrich II，共 18 条逐字校勘），
见下文「五·补、外源层」。仍未补的是心理域的**尊严与自主**——这两项没有量表，只能靠观察与访谈，不用外源硬填。

## 五、代价与边界

- 不写问诊话术、查体手法、实验室参考区间、心电图判读标准（**无底本，不编**）

**校勘踩到的两个坑**（都已写进约定第五节）：

1. **弯直引号**：PDF 里是 `Alzheimer’s`、`you’re`，按直引号抄逐字比对就失败——引号必须与原文一致；
2. **多栏版面**：CDC 那份是三栏，整页提取会把左右栏交错成一行（「Are there papers…」后面直接接右栏），
   所以校勘改用**双通道提取**（整页 + 三分栏各提一次，任一命中即算可查）。

**负例验证**：塞入一条伪造条文（「GDS is a 42-item scale…」）→ 脚本判 `unverified`；删掉 → 回到 18/18。
