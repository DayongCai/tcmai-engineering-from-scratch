# 四域整合判断与量表的使用

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的「一、这一章的问题」，确认要回答的是什么；
2. 跑 `node code/main.js`，看本章的规模、三辨与适应能力四域分布（数字由 `standards/jiankang-pinggu/units.json` 现算）；
3. 按「三、逐单元读」的单元顺序，逐个说出判据类别；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应单元。

## 边界

只写类别与要点，不写操作参数；不替代专业判断；异常按现行护理记录与报告制度及院内流程报告。
