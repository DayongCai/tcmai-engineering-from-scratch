## 二·补、适应能力四域与「最合适状态」

**本章单元的四域读数：** 生理适应 0 ｜ 心理适应 10 ｜ 社会适应 41 ｜ 环境生态适应 4
### 四域共用的判据：什么叫「最合适」

本课把健康定义为：**个体在生理、心理、社会、环境生态四个适应域上，相对自己的「从容长寿」目标，都处于最合适状态。**

四句话各有约束，缺一句就变形：

- **「相对个体」**——不是相对人群均值。同龄人能爬五层楼，他爬两层就够用，那么两层就是合适；把均值当标准，评估就变成了排名。
- **「从容」**——不是「活着」，是「不必长期硬撑」。靠意志顶住的日常、靠家人代劳的日常，都不算从容。
- **「长寿」**——是时间维度。任何只在当下成立的「合适」，若要以明年的功能为代价，就不是合适（例如靠过量镇静换来的安静）。
- **「四域都」**——不是平均分高就行。四域是并联的：任何一域掉出合适区间，其余三域的代偿会在数月内被耗尽。

**「最合适」不等于「最高」。** 这是本课最容易读错的一句：功能练到极限，往往同时意味着休息、社交与安全的余量被压缩。评估要找的是**稳态区间**，不是峰值。

一条实测提醒：**「从容长寿」「最合适」「长寿」在父课底本里出现 0、0、0 次，「适应」只有 14 次。**
这套框架是本轮引入的评估锚点，不是父课原话——父课写的是「评估要点」与「护理要求」，本课把它重新组织到四域上，属于框架层的新增，已在 README 与 `meta.json` 登记。

### 整合判断：四域不能相加

四域各自打分再求和，是本课明确反对的做法。原因是四域是**并联**的，不是可替代的：

- 一域归零，其余三域再高也不构成「最合适」（失能卧床者社会域评分再高，也换不回自主如厕）。
- 四域之间存在**代偿**关系，但代偿有期限：社会支持可以短期替代生理功能，环境改造可以长期补偿功能缺陷，心理韧性可以延缓失代偿——三者都会耗尽。

因此整合判断的顺序是固定的：

1. **找短板**：四域里最接近「不合适」的那一域，决定整体结论。
2. **看代偿**：短板靠什么在撑、还能撑多久。
3. **定干预**：优先修短板或扩大代偿，而不是继续抬高已经合格的那一域。
4. **回头验**：干预后重测短板域，其余三域一并复评——抬高峰值不算改善。

量表在本课中的位置就是第 1 步的工具：它把「感觉不太行」变成可比较的数，**用于排序，不用于定论**。
