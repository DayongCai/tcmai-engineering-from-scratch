# 情绪可以问出来，尊严和自主只能被让出来 · 提示词

## 用途

给「情绪可以问出来，尊严和自主只能被让出来」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三条线：情绪、认知、意愿 → 采集项与判据 → 记录字段：原话、来源、条件 → 三种失效」这条链。

## 边界

本章为教学材料，不构成心理诊断或治疗建议。所述采集项与分档方向用于训练访谈与记录；具体操作以现行规范与所在机构制度为准。
