# 生命体征的价值不在读数，而在它与本人基线之间的那段距离

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 同时反映心率与节律，速率之外要看强弱与规整；节律不规整比速率偏出更需要立刻报告
- 受体位、肢体、袖带与情绪影响极大，单次偏高更可能是条件问题
- 在末梢循环差、指甲油、手指温度低时失真，读它必须同时读灌注
- 体位与肢体
- ＝落在本人基线与同条件参考之内，且与本次症状不相矛盾
- ＝偏出但可由已知条件解释（活动后、情绪后、用药后），需在条件恢复后复测

## 边界

- 只写类别与要点，不写操作参数。
- 本章为教学材料，不构成诊断或治疗建议。所述参数、准备要求与分档方向用于训练测量与记录习惯。
