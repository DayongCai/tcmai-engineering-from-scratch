## 二·补、适应能力四域与「最合适状态」

**本章单元的四域读数：** 生理适应 71 ｜ 心理适应 39 ｜ 社会适应 45 ｜ 环境生态适应 25
### 四域共用的判据：什么叫「最合适」

本课把健康定义为：**个体在生理、心理、社会、环境生态四个适应域上，相对自己的「从容长寿」目标，都处于最合适状态。**

四句话各有约束，缺一句就变形：

- **「相对个体」**——不是相对人群均值。同龄人能爬五层楼，他爬两层就够用，那么两层就是合适；把均值当标准，评估就变成了排名。
- **「从容」**——不是「活着」，是「不必长期硬撑」。靠意志顶住的日常、靠家人代劳的日常，都不算从容。
- **「长寿」**——是时间维度。任何只在当下成立的「合适」，若要以明年的功能为代价，就不是合适（例如靠过量镇静换来的安静）。
- **「四域都」**——不是平均分高就行。四域是并联的：任何一域掉出合适区间，其余三域的代偿会在数月内被耗尽。

**「最合适」不等于「最高」。** 这是本课最容易读错的一句：功能练到极限，往往同时意味着休息、社交与安全的余量被压缩。评估要找的是**稳态区间**，不是峰值。

一条实测提醒：**「从容长寿」「最合适」「长寿」在父课底本里出现 0、0、0 次，「适应」只有 14 次。**
这套框架是本轮引入的评估锚点，不是父课原话——父课写的是「评估要点」与「护理要求」，本课把它重新组织到四域上，属于框架层的新增，已在 README 与 `meta.json` 登记。

## 三、逐单元读

### 1.1 1.1 四域适应框架与「从容长寿」基线

1．能说出内科护理评估的内容类别与观察维度，理解其在护理程序中的位置与作用。 2．能区分资料的主观来源与客观来源类别，并说明核实与交叉印证的基本要求。 3．能列举呼吸、循环、消化、泌尿、神经与内分泌等系统功能方面的观察要点类别。 4．能说明评估记录应包含的要素与留痕要求，理解客观描述与主观评判的差别。 5．能描述实验室与辅助检查护理配合中评估、告知、核对与观察的要素及其顺序。 6．能理解护理记录合规与个人信息保护的基本要求，并说清脱敏与去标识化的区别。 7．能建立以评估为基、以照护为要的整体护理思维，并初步明确护理的责任边界。 内科护理评估（nursing assessment）是护理程序（nursing process）的起始环节，也是后续诊断性思考、照护计划、实施与评价的共同基础。评估不等同于疾病诊断（disease diagnosis），其目的在于系统收集与患者健康状况相关的资料，形成对健康问题与照护需求的整体认识，为护理判断提供依据。凡涉及评分、分级与风险判定的内容，本章一律不写量表名称与分值，不写截断值，也不作评定结论，具体判断与结论由具备资质的人员作出。 从内容维度看，内科护理评估通常涵盖若干类别。其一是健康史与现病史类别，包括本次健康问题的发生、演变与就诊经过，以及既往健康状况、住院与手术经历、家族健康情况等线索。其二是症状与体征类别，即患者主诉的不适与照护者可观察到的表现，强调以患者自述为主、以客观所见为辅。其三是功能状态与自理能力类别，包括进食、排泄、活动、睡眠、沟通与日常自理等方面的受限情形。其四是心理与社会支持类别，包括情绪反应、应对方式、家庭与照护者支持、照护环境等。其五是生活方式与环境类别，包括饮食类别、活动习惯、烟酒等嗜好的有无、居住与工作环境等。其六是用药与过敏相关类别，只记录既往用药经历、有无不良反应与过敏线索，不书写具体药物名称与用量。
