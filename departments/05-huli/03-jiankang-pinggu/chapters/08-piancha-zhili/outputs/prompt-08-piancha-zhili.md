# 偏差不在仪器上，在「这次只看这一次」的习惯里 · 提示词

## 用途

给「偏差不在仪器上，在「这次只看这一次」的习惯里」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「六类偏差，各有各的识别法（分类为【教学设定】的归纳，不是分类学） → 过度检查：三种动机，三种对策 → 质量治理：指标、报告、改进 → 三种失效」这条链。

## 边界

本章为教学材料，不构成质量管理、法律或责任认定的意见。所述偏差类型与治理方法用于训练识别与改进思路；具体操作以现行规范与所在机构制度为准。
