# 记录是写给下一个人的，沟通是留给这个人的 · 提示词

## 用途

给「记录是写给下一个人的，沟通是留给这个人的」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「记录的三条硬要求 → 沟通：对谁说，说多少 → 把沟通写进记录 → 三种失效」这条链。

## 边界

本章为教学材料，不构成诊断、告知或法律意见。所述记录结构与沟通规则用于训练职业习惯；具体操作以现行规范与所在机构制度为准。
