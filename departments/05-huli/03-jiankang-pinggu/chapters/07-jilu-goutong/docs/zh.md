## 二·补、适应能力四域与「最合适状态」

**本章单元的四域读数：** 生理适应 200 ｜ 心理适应 59 ｜ 社会适应 29 ｜ 环境生态适应 39
### 四域共用的判据：什么叫「最合适」

本课把健康定义为：**个体在生理、心理、社会、环境生态四个适应域上，相对自己的「从容长寿」目标，都处于最合适状态。**

四句话各有约束，缺一句就变形：

- **「相对个体」**——不是相对人群均值。同龄人能爬五层楼，他爬两层就够用，那么两层就是合适；把均值当标准，评估就变成了排名。
- **「从容」**——不是「活着」，是「不必长期硬撑」。靠意志顶住的日常、靠家人代劳的日常，都不算从容。
- **「长寿」**——是时间维度。任何只在当下成立的「合适」，若要以明年的功能为代价，就不是合适（例如靠过量镇静换来的安静）。
- **「四域都」**——不是平均分高就行。四域是并联的：任何一域掉出合适区间，其余三域的代偿会在数月内被耗尽。

**「最合适」不等于「最高」。** 这是本课最容易读错的一句：功能练到极限，往往同时意味着休息、社交与安全的余量被压缩。评估要找的是**稳态区间**，不是峰值。

一条实测提醒：**「从容长寿」「最合适」「长寿」在父课底本里出现 0、0、0 次，「适应」只有 14 次。**
这套框架是本轮引入的评估锚点，不是父课原话——父课写的是「评估要点」与「护理要求」，本课把它重新组织到四域上，属于框架层的新增，已在 README 与 `meta.json` 登记。

### 记录：漏记一域 = 漏判一域

四域判断能否传递，全靠记录。记录的最低要求是**四域齐全**，而不是「异常项写清」：

| 域 | 必须留下的一条 |
|---|---|
| 生理适应 | 至少一组生命体征 + 一般状态描述 |
| 心理适应 | 尊严/自主/情绪三项中，哪一项有变化 |
| 社会适应 | 角色与参与的实际状态（不是「家属关心」） |
| 环境生态适应 | 所在场所的具体障碍或风险 |

**只写异常项会制造系统性偏差**：下一班只看到「血压偏高」，就默认其余三域无问题。四域记录的价值正在于「没有变化」也要写——它证明这一域被看过。

沟通同理：交班讲的是「哪一域是短板、靠什么在撑」，不是罗列数值。

### 7.1 7.1 评估结果的记录与沟通

一、能说明内科常见症状护理在内科护理中的定位与意义，理解症状护理是整体护理与病情观察的重要环节。 二、能概述发热、疼痛、咳嗽咳痰、呼吸困难、水肿与意识障碍六类常见症状的现象类别与常见伴随表现。 三、能依据观察要点类别，对上述症状开展有重点的病情观察并规范记录，把握观察的连续性与动态性。 四、能列举各类症状的照护类别与要求，说明照护措施的原则、宜忌与安全边界。 五、能识别需要及时报告与转介的异常情形，正确履行报告与转介职责，做到不延误、不遗漏。 六、能运用「评估、告知、禁忌、观察、报告、记录」六要素，描述常见症状护理的闭环要求，理解不得事后追认的原则。 七、能理解症状护理中的责任边界，认识症状护理不替代内科护理判断与专业责任，涉病因与处理的判断由具备资质的人员作出。 内科常见症状（common medical symptoms）是指在内科各类疾病过程中反复出现、并能被患者直接感知或由照护者观察到的身体异常现象。它们常在病因尚未明确之时先行出现，是患者就诊与住院的重要原因，也是护理病情观察的第一手线索。症状护理的重点，不在于判定疾病的名称与性质，也不在于给出治疗处理意见，而在于通过系统的观察、恰当的照护以及及时的报告与转介，为后续由具备资质的人员作出的判断与处理提供真实、连续、完整的依据。因此，本章所写内容均为观察要点类别、照护类别与报告要求；凡涉及病因分析、检查判读、用药与处置，一律不作疾病诊断，统一写明由具备资质的人员作出或确定。 发热（fever）是本章首先讨论的症状，指机体在致热因素作用下出现、以体温调节中枢功能改变为特征的一类临床表现。护理对发热的观察不写任何体温数值、分级界值与评分，只按要点类别展开。第一类是热程与热型类别：关注起病缓急、持续时间长短以及热势起伏的形态，如稽留、弛张、间歇、回归、波状等热型类别，并记录退热是骤退还是渐退。第二类是伴随症状类别：如畏寒与寒战、出汗与无汗、口渴与食欲改变、乏力与全身酸痛、头痛与周身不适等；这些伴随表现常提示不同的病因方向，但方向的判断仍由具备资质的人员作出。
