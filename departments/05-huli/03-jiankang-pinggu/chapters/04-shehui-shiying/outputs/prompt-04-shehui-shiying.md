# 支持不是「有人陪」，是「出事时谁能在今晚到场」 · 提示词

## 用途

给「支持不是「有人陪」，是「出事时谁能在今晚到场」」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「角色：先知道他原来是干什么的 → 采集项与判据 → 记录字段：一张图加三个数 → 三种失效」这条链。

```

正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，不构成法律、社会救助或照护级别的个别建议。所述采集项与分档方向用于训练访谈与记录；具体操作以现行规范与所在机构制度为准。
