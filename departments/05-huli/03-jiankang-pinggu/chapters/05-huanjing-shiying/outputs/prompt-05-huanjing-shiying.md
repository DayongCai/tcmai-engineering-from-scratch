# 环境不是背景，它决定了一件小事要做几步 · 提示词

## 用途

给「环境不是背景，它决定了一件小事要做几步」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三条线：场所、季节、可达性 → 采集项与判据 → 入户的动作：走一遍、看一遍、问一遍 → 记录字段：路径、清单、三个量」这条链。

## 提示词

```
我在学《健康评估》第 5 章「环境不是背景，它决定了一件小事要做几步」，本章 5 节 / 2,903 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 进别人的地界，先问他的规矩
   - 这件事要做几步
   - 可达性用三个量算，不用「方便不方便」评
   - 步骤数与是否需要他人
   - 「索性不做了」的清单，就是环境造成的功能损失清单
   - 发现即时危险
4. 指出本章写到类别就止步、不再给参数的地方。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，不构成住房改造、消防安全或照护安置的专业意见。所述采集项与判据方向用于训练入户观察与记录；具体操作以现行规范与所在机构制度为准。
