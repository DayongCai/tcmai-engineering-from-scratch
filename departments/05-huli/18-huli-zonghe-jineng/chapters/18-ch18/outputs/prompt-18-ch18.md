# 平台不替人做判断，它只让判断可追溯 · 提示词

## 用途

给「平台不替人做判断，它只让判断可追溯」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「平台做的三件事，与它不做的一件事 → 技能单元：两级编码与必填的两列 → 四道门：命中即阻断 → 留痕、复核与四类失效」这条链。

## 提示词

```
我在学《护理综合技能》第 18 章「平台不替人做判断，它只让判断可追溯」，本章 5 节 / 3,491 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 本章引证口径
   - 它只处理文本的结构与位置，不处理内容的对错
   - 采纳与否由人工复核决定
   - 仿真负责呈现，提示负责定位，人负责负责
   - 的，它说清「凭什么」；边界列是
   - 不写文号、不写条款序号、不写发布年份
4. 指出本章写到类别就止步、不再给参数的地方。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，不构成医学意见、诊断或护理指导；具体操作以现行规范与所在机构制度为准。
