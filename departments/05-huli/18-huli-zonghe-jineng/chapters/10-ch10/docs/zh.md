# 第 10 章 · 急救配合的评价标准是让位是否及时，不是动作是否好看

> **MOTTO:** 「天覆地载，万物悉备，莫贵于人」——《素问·宝命全形论》
>
> **PROBLEM:** 本章 12 段、19,949 汉字。段题含「观察」的 3 段，「记录」「报告」「转介」各 1 段，讲现场安全与配合的 4 段。12 段里承担「记什么」的只有 1 段（配合中的观察与记录），而复苏配合的全部可复盘性都压在这 1 段上；同时有 1 段专门写「实施与判断由具备资质的人员完成」，却没有一段写「配合错位长什么样」——而错位是配合里唯一会自己发生的事。

**双根因定位:** 环境逼迫——急救现场的时间以秒计，任何需要「想一想」的动作都会被跳过，所以现场接受的只有已经变成条件反射的动作；而条件反射练的是自己的动作，不是自己与别人之间的衔接。知识积累——教材把现场安全、观察要点、启动流程、分工、记录分列成五组要求，五组各自都对，但都把「配合」当成一种态度而不是一组可以被观察的行为，于是学员学到的是一句「要配合好」。

## 一、配合是一种可以被观察的行为

「配合好」这句话没法评分，因为它不指向任何具体动作。可以被观察的配合只有四种，每一种都对应一个具体的让：

| 让 | 具体动作 | 反向动作（错位） |
|---|---|---|
| 让位 | 站到不遮挡的位置，把操作空间让出来 | 站在操作者与被救者之间 |
| 让物 | 物品放在一步之内，按需递出 | 把三件一起递上去 |
| 让路 | 通道与器械车不占抢救动线 | 器械车停在通道上 |
| 让权 | 自己不决定技术方案，只报告与执行 | 替操作者调整设备 |

四种让的共同点：它们都是**减法**。配合做得好的标志不是助手多做了几件事，而是操作者少中断了几次。所以评价一次配合，看的是**中断次数**与**中断时长**，不是助手手上的动作数。

这个判据把「配合」从态度问题变成了测量问题，也解释了本章为什么把记录放在那么重的位置：中断次数只有在记录里才数得出来，不记，配合就永远只能凭印象评价。

## 二、现场安全与呼救：三步，不许跳

急救现场的第一步永远不是救人，是让自己能救。三步按顺序，跳步等于制造第二个需要被救的人：

1. **看环境**：有无持续的危险源（电、火、坠落物、交通、气体）。有，先脱离再评估，不脱离不接近。
2. **定人数**：一个人能做什么、需要几个人、谁去呼救。分不清人数就开始，是现场最常见的失序。
3. **呼救并回告**：呼救的内容必须包含三件事——**在哪里、什么情况、需要什么**；呼救之后必须回告「已呼救、预计到达」，否则现场会重复呼救或以为无人呼救。

第三项「回告」是最缺的一环。呼救本身是发出，回告才是闭环；没有回告，现场所有人都处在「不知道有没有人来」的状态，而这个状态会让人做出两种极端选择：自己硬做，或者放弃。

呼救的对象与渠道按所在机构制度与现场条件确定，本章只写要求：**渠道明确、内容三要素齐全、有回告**。三条之中缺回告，视为未完成呼救。

这三步同时就是操作前的三项核对：防护是否到位、呼救是否已有回告、分工是否说清。三项有一项没答，不进入下一步。

## 三、意识与呼吸的观察，与启动流程的判据

观察在本章占 3 段，落到操作上是四个维度，每一维只回答一个问题：

| 维度 | 问题 | 结论形态 |
|---|---|---|
| 反应 | 对呼唤与轻触有无反应 | 「有反应」「无反应」 |
| 呼吸 | 有无正常呼吸、有无异常声响 | 「有正常呼吸」「无呼吸」「有异常呼吸」 |
| 循环征象 | 有无可触及的搏动征象（按规范要求的方法） | 「有」「无」「不确定」 |
| 其他 | 有无可见的出血、呕吐物、分泌物 | 「有，位置在……」 |

四维里第三个允许「不确定」这个结论，这是它与其他三维的不同之处。允许「不确定」的理由是：不确定时必须按最不利情形处置并立即报告，而不是反复确认。反复确认在生产上是严谨，在急救现场是延误。

启动流程的判据只有一句：**无反应且无正常呼吸，即启动**。这一句之所以写得这么短，是因为现场没有时间做鉴别；鉴别是接手者的事，启动是发现者的事。

启动之后的时间窗【教学设定】，各位置的动作有先后：

| 秒档 | 谁 | 做什么 |
|---|---|---|
| 0–10 | 发现者 | 判断反应与呼吸，呼救并回告 |
| 10–30 | 发现者 | 摆放体位、开放气道、准备器具 |
| 30–60 | 发现者与接手者 | 交接现状（四维结论），让出位置 |
| 60 起 | 接手者主导 | 配合轮换，每次轮换中断不超过规范要求的时限 |
| 全程 | 记录者 | 秒级记录，不参与搬动 |

第三档的「交接现状」是一个极容易被略过的动作：发现者往旁边一站，接手者直接开始。缺了这 10 秒，接手者要从零判断一遍，而判断所需的信息发现者刚刚已经得到。交接的四句话是：**无反应、无正常呼吸、已呼救、已开始多久**。

## 四、配合记录与四类失效

复苏配合的记录必须是秒级，理由不是精确，而是**轮换**：轮换是复苏中唯一一件定期发生、且每次都带来质量下降的事，只有秒级记录才能看出轮换间隔是否稳定、每次中断多长。

记录八列：

| 列 | 内容 | 缺了会怎样 |
|---|---|---|
| 时刻 | 时:分:秒，全部事件 | 无法计算中断与轮换间隔 |
| 位置 | 谁在什么位置（按压、气道、通路、记录、巡回） | 无法复盘错位 |
| 事件 | 开始、轮换、给药配合、除颤配合、转送 | 无法重建时间轴 |
| 中断 | 起止秒数与原因 | 无法判断质量下降的来源 |
| 观察 | 四维结论的变化 | 无法判断反应 |
| 报告 | 向谁报告、时刻、答复 | 责任链断裂 |
| 交接 | 交给谁、四句话是否说完 | 接手者重复判断 |
| 去向 | 转送目的地与途中支持 | 途中无准备 |

第四列「中断」是这张表的核心。它把「配合得好不好」变成两个可以直接读出来的数：中断了几次、每次几秒。任何一次配合的复盘，只要看这两列，就能定位问题发生在哪一段。

四类失效模式：

- **让位失败**：站错位置，操作者被迫绕行或侧身。前兆是操作者的手开始绕开助手。拦截：站位固定为惯用手侧后方一步之内，开场即定。
- **递多**：预判后一次递出多件，占用无菌面或视野。前兆是操作者手上出现当前不需要的物品。拦截：预判准备、按需递出。
- **呼救无回告**：呼救了但无人确认，现场重复呼救。前兆是多人同时在呼救。拦截：呼救后必须回告，回告内容进记录。
- **记录位被抽走**：记录者被叫去搬动或递物。前兆是时间轴出现一段空白。拦截：记录位不参与搬动，人力不足时宁可减别的位。

第四类在真实场景里发生得最多，理由永远充分（「就一会儿」）。它的代价不是当场出错，而是事后无人能重建那几分钟，而复盘、改进、责任界定全部依赖那几分钟。

## 五、考核项

1. **四种让**：看一段配合演示，逐项判断四种让是否成立，指出至少一处错位。
2. **三步现场安全**：给一个现场情境，说出三步各自的判断与动作，第三项必须包含回告。
3. **四维观察**：给三个情境，说出四维结论，其中必须有一次使用「不确定」并说明立即报告。
4. **启动判据**：用一句话说出启动条件，并说明为何不在现场做鉴别。
5. **交接四句**：完成一次交接，四句齐全，缺一句即不通过。
6. **秒级记录**：给一段流程，填八列，中断起止必须到秒。
7. **轮换配合**：完成三次轮换，考核者记录每次中断秒数，出现超时即记重。
8. **失效归因**：四段场景对应四类失效，其中「记录位被抽走」必须说明代价落在哪一步。

第 7 项与第 8 项是主考项：一项测「轮换时手会不会停」，一项测「会不会为了眼前的事牺牲可复盘性」。

## 六、代价与边界

第一个代价是**让位要求助手保持「闲」**。四种让都是减法，减法在旁人看来就是没在干活。抢救现场最容易被指责的正是这一点：站着不动的人。承认这个代价的方式是把岗位写清——站在那个位置的人，其职责就是不让操作者中断，而不是多做几件事。

第二个代价是**秒级记录需要专职的人，而人常常不够**。两人配置下排不出记录位。可接受的最小妥协是由巡回兼任记录，但必须在记录中标明「兼任」与兼任期间的空档，让复盘知道哪一段的秒数是估的。标明估算，比伪造精确要好。

第三个代价是**「不确定」这个结论会被误用**。允许写「不确定」，前提是紧接着按最不利情形处置并报告；如果「不确定」变成了不做处置的借口，这个结论就该被取消。所以本章把它与「立即报告」写成一句话，两者不可拆开。
