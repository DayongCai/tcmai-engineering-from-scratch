# 规范不是流程的长度，是每个断点都有人接 · 提示词

## 用途

给「规范不是流程的长度，是每个断点都有人接」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「流程的长度不等于规范的密度 → 操作前的六类核对与一次三数清点 → 核对方式的选择与五个必须停的核对点 → 感控要求的三个落点与四类失效」这条链。

## 边界

本章为教学材料，不构成医学意见、诊断或护理指导；具体操作以现行规范与所在机构制度为准。
