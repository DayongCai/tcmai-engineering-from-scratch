# 安全的第一道防线不是谨慎，是可核对的重复 · 提示词

## 用途

给「安全的第一道防线不是谨慎，是可核对的重复」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「谨慎是一种态度，重复才是一种保障 → 三处再核对：身份的、部位的、意愿的 → 告知的四要素与拒绝的三条路径 → 隐私的三个暴露面与四类失效」这条链。
