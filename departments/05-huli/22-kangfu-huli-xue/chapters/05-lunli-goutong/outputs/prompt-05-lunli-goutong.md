# 同意不是签个字，是让他知道可以说不 · 提示词

## 用途

给「同意不是签个字，是让他知道可以说不」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「四条原则落到床边，各是什么动作 → 告知要说五件事，「听懂」要验一次 → 拒绝与撤回：记什么、不做什么、谁该知道 → 与表达受限者的沟通：辅助方式的边界」这条链。
