# 可塑性有前提，不是一句安慰话 · 提示词

## 用途

给「可塑性有前提，不是一句安慰话」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「功能的三层与残疾的三层，说的是同一件事的两面 → 可塑性的三个前提：用进、任务特异、时机 → 分期是一把刻度尺：偏瘫六期与护理重点 → 运动学习：练的是任务，不是次数」这条链。
