# 质量不是不出事，是把出事的方式提前写下来 · 提示词

## 用途

给「质量不是不出事，是把出事的方式提前写下来」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「指标的四要素：少一个就不可比 → 常见风险与高危环节 → 不良事件：分类、上报、非惩罚 → 原因分析与改进：两个够用的工具」这条链。

## 提示词

```
我在学《康复护理学》第 17 章「质量不是不出事，是把出事的方式提前写下来」，本章 5 节 / 2,909 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - （算的是什么）、
   - （分子是什么人群的什么事件）、
   - （在哪个范围、哪段时间里算）、
   - 报告例数不等于发生例数
   - 高危环节提示
   - 第三步非惩罚
4. 指出本章写到类别就止步、不再给参数的地方。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，不构成管理规范或法律意见；具体操作以现行规范与所在机构制度为准。
