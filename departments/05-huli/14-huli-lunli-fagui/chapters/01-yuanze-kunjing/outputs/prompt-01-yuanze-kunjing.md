# 四个原则不是四句口号，是四种能被追问的动作 · 提示词

## 用途

给「四个原则不是四句口号，是四种能被追问的动作」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「原则要能被追问：四原则各自的落点 → 三种理论各自回答什么问题 → 困境的结构：不是「难选」，是「两种对」 → 决策程序：五步，每一步都要留下东西」这条链。

## 提示词

```
我在学《护理伦理与法规》第 1 章「四个原则不是四句口号，是四种能被追问的动作」，本章 5 节 / 3,283 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 要回答哪些问题
   - 的落点是三项
   - （说清楚做什么、为什么、还有什么选择、可能有什么影响）、
   - （在理解的基础上由本人作出决定）、
   - 决定能力的判断不属于护理人员的独立职责
   - （在动作之前，而不是之后）、
4. 指出本章写到类别就止步、不再给参数的地方。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，所述原则、冲突类型与决策步骤用于训练伦理判断与记录习惯，不构成医学意见、法律意见或对任何个案的处理结论；具体操作以现行规范与所在机构制度为准。
