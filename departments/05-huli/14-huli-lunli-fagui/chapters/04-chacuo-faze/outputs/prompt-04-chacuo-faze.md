# 报告的自由度，决定差错的可见度 · 提示词

## 用途

给「报告的自由度，决定差错的可见度」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「报告的四个要求：及时、如实、完整、留痕 → 报告之后：分级处理与公正文化 → 团队协作：职责边界与越界代行 → 特殊人群：不作标签化，支持而不是代替」这条链。

## 边界

本章为教学材料，所述报告要求、分级思路与协作边界用于训练判断与记录习惯，不构成医学意见、法律意见或对任何事件的责任认定；具体操作以现行规范与所在机构制度为准。
