# 规范不是捆住动作的条文，是划出可被信任的范围 · 提示词

## 用途

给「规范不是捆住动作的条文，是划出可被信任的范围」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「信任：护患关系的伦理基础不是「态度好」 → 执业范围：能做什么，由三件事决定 → 教学与带教：学生的动作也是患者的风险 → 伦理质量：把「氛围」变成可观察的东西」这条链。

## 边界

本章为教学材料，所述原则、边界与判断要求用于训练执业判断与记录习惯，不构成医学意见、法律意见或合规结论；具体操作以现行规范与所在机构制度为准。
