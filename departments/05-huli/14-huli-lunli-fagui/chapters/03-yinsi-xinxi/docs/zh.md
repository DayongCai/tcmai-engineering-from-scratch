## 三、逐单元读

### 6.1.2 信息隐私类别

1. 说出隐私的主要类别，理解各类别在护理情境中的伦理意义与相互关系。 2. 说明身体隐私的保护要求与在照护操作中落实的方式。 3. 描述信息隐私的构成，理解健康信息按敏感个人信息处理的缘由。 4. 理解保密义务的类别与范围，说明保密例外的判断要求与程序。 5. 明确团队内共享信息的边界，理解目的限定与最小必要的要求。 6. 掌握去标识化与留痕的基本要求，说明脱敏与去标识化不得混称的口径。 7. 形成在信息共享中尊重、告知与同意、报告与改进的伦理意识。 隐私是护理伦理的重要范畴，其类别与关系是本章讨论的起点。就护理情境而言，隐私可大致区分为身体隐私、信息隐私以及空间与场所隐私三类。三者并非彼此孤立，而是相互交织：一次照护操作既可能触及身体隐私，也会生成并被记录为信息隐私，还可能发生在涉及空间隐私的场所之中；理解这些类别与关系，是提出恰当伦理要求的前提。 身体隐私类别，指与个人身体、生理状况及身体形象相关的隐私范畴。在护理工作中，更衣、沐浴、擦洗、导尿、伤口换药、体位变换等操作，都可能使护理对象处于身体暴露的状态。此类情境中的伦理议题，集中在暴露的必要程度、操作的可见范围以及当事人意愿是否得到尊重等方面。 对身体隐私的保护，首先体现为尊重的态度与相应的操作习惯。进入照护前应先作说明并征询意愿；操作时保持专注，不以与照护无关的话题谈论当事人的身体特征与外观。任何与照护无关的观看、议论或传播，都不属于护理工作的范围。 最小暴露是身体隐私保护的基本要求。护理人员在操作中只暴露完成操作所必需的部位，其余部分及时以被服或隔帘遮盖；操作间歇与结束时，尽快为当事人整理衣被。暴露范围的把握以操作需要为限，不以方便或习惯为由加以扩大。 环境准备同样属于身体隐私保护的一部分。条件允许时，宜使用屏风或床帘，关闭门窗，减少与操作无关的人员在场；在多人病房中，避免在公共视野内进行涉及身体暴露的操作。上述做法属于常规伦理要求与操作规范，具体以现行规范与机构制度为准。 告知与同意应前置于涉及身体隐私的操作。

### 13.1.2 公正原则类别

1. 说明护理科研伦理的基本要求与原则类别及其相互关系 2. 描述研究告知与知情同意与自愿参与的伦理要求 3. 归纳公正原则类别在研究参与者选取中的具体要求 4. 辨识隐私保护与数据合规中的最小必要与去标识化要求 5. 列举伦理审查的范围与材料与意见落实的要求类别 6. 运用中性表述分析常见科研伦理议题的分析要求与程序 7. 形成以现行规范与机构制度为准的科研伦理意识 护理科研伦理是护理伦理在科学研究活动中的延伸，其要求围绕研究参与者权益保护与科学诚信展开。本章只写伦理要求与原则与议题类别，不作道德评判与个案裁断。研究活动由具备资质的人员按现行规范与机构制度组织实施，护理人员在其中承担相应的伦理责任，并在职责范围内完成相应工作。 尊重原则类别是护理科研伦理的基础类别之一，要求在立项、实施与总结各环节尊重研究参与者的人格与自主意愿，承认其对是否参与以及如何参与享有决定权。尊重原则类别与受益原则类别互为支撑，形成不可分割的关系，二者共同构成科研伦理的底层要求。 受益原则类别要求研究活动对研究参与者与社会具有可预期的价值，风险与受益的权衡须在实施前完成并形成书面记录。风险管理以最小化为要求，不作获益承诺，不作疗效断言，也不作优越性断言，相关伦理判断由具备资质的人员依现行规范作出。本章不作疾病诊断，亦不替代规范诊疗与用药。 尊重原则类别与受益原则类别的关系体现在具体议题的处理要求上。当研究活动涉及研究参与者的时间、精力与个人信息时，尊重原则类别要求充分告知，受益原则类别要求权衡风险与受益，二者共同指向对研究参与者权益的保护要求。 科研伦理议题的分析遵循既定程序，按议题识别与陈述、知情同意与自愿、多方沟通与协商、报告与转介、记录与复核的顺序推进。程序中的各环节均以伦理要求为依据，不作道德评判与个案裁断，相关结论由具备资质的人员作出。 在伦理议题分析中，伦理要求与原则类别是判断的起点。类别划分使研究者能够识别议题所属范围，关系梳理则帮助研究者理解各项要求之间的优先次序与相互制约。任何类别的适用均以现行规范与机构制度为准。
