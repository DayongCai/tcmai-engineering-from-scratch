# 签字只是同意的痕迹，同意是一个被听懂的过程 · 提示词

## 用途

给「签字只是同意的痕迹，同意是一个被听懂的过程」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「五个要件：缺一个就不是同意 → 告知：说什么、怎么说、什么时候说 → 自愿：拒绝与同意要被同等对待 → 生命起始的议题：只写类别，不作裁断」这条链。

## 提示词

```
我在学《护理伦理与法规》第 2 章「签字只是同意的痕迹，同意是一个被听懂的过程」，本章 5 节 / 3,230 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 没有确认理解的告知，只是「已经说过」
   - 本人具备理解信息、权衡利弊、表达选择的能力
   - 对方能不能用自己的话把「为什么做、还有什么选择、可能有什么不舒服」复述出来
   - 其一，不用术语替代解释
   - 其二，分段说，不一次说完
   - 其三，允许沉默与追问
4. 指出本章写到类别就止步、不再给参数的地方。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，所述要件、告知内容与记录要求用于训练沟通与记录习惯，不构成医学意见、法律意见或对任何个案的处理结论；具体操作以现行规范与所在机构制度为准。
