# 第 11 章 · 术前准备的每一件事，都是为术后那一次观察留基线

> **MOTTO:** 「凡刺之法，先必本于神」——《黄帝内经·灵枢·本神》
>
> **PROBLEM:** 本章底本 19,911 汉字、112 个实质段；段内含「记录」的 89 段（83.9%）、含「核对」的 40 段（35.0%）、含「告知」的 37 段（34.5%），而含「评估」的只有 2 段（2.0%）。记录与核对写得极厚，而「术前这一次的状态是什么样」——术后所有比较的基准——几乎没有独立的位置。

**双根因定位:** 环境逼迫——围手术期的节奏由手术排程决定，准备工作被切成一段段待办事项，每完成一项就打勾，打勾的节奏把「状态描述」挤成了「已完成」；知识积累——教材按术前、术中配合、术后三段时间书写，每段时间各自的关注点不同，读者容易把术前理解成「把事情做完」，而术前真正不可替代的产出是「把状态记下来」。

**本章引证口径：** 教材·第 12 章·12.1.2（皮肤与肠道准备的要求类别）；段数与关键词命中按 `standards/jichu-huli/units.json` 现算（实质段＝以换行分隔、≥35 汉字者；占比＝命中段汉字／实质段汉字合计）；带【教学设定】的分钟档为课堂演练口径；全章不写禁食禁饮的小时数、皮肤准备的用药与参数、麻醉与镇痛方案，不写发生率，不引页码。

**引用粒度：** 只到「第 12 章·第 1 节」（12.1.2）级，不引页码、不引版次；节号为底本单元编号的中段，目号为该节内的条目序号。

## 一、术前的产出不是「做完了」，是「记下来了」

术前准备按内容分三类，每一类除了完成动作，还要留下一个可用于比较的描述。

| 类 | 完成动作 | 必须留下的描述 |
|---|---|---|
| 身体准备 | 皮肤清洁、肠道准备、饰品与义齿处理、通路建立 | 部位与范围、皮肤现况、完成时刻 |
| 信息准备 | 核查、标识、同意与告知、既往情况确认 | 谁核的、核了什么、有无不一致 |
| 状态准备 | 生命体征与一般状况、疼痛、活动能力、情绪 | 术前这一次的基线，逐项写数值或描述 |

第三类是本章的重点，也是最容易被做成「正常」的一类。术前的状态描述之所以关键，是因为术后所有异常判断都拿它作对照：术前就有的轻微咳嗽、术前就有的下背不适、术前就偏快的心率，如果不写下来，术后出现同样的表现就会被当成新的变化，追查方向随之偏掉。

由此得到本章第一条判断：**术前准备的成品是一份基线，不是一串勾**。勾只能证明动作发生过，基线才能证明变化发生过。

基线还有一处常被忽略的用法：**它决定了术后第一次观察该问什么**。术前有咳嗽的人，术后要问咳嗽与痰；术前不能平卧的人，术后要看耐受；术前就焦虑的人，术后的表现不能用「情绪稳定」一句带过。术前的基线写得越具体，术后的第一次观察就越有方向。反过来，术前只写「一般情况可」的班次，术后的第一次观察只能从头问一遍。

## 二、操作前的评估与核对

| 项 | 要确认的 | 判据 |
|---|---|---|
| 身份与项目 | 对象、部位或侧别、拟行项目 | 三者在同一句话里说得完整 |
| 依据与标识 | 依据可查、标识与部位一致、标识未被移动 | 标识位置与依据一致，标记清楚 |
| 身体准备 | 皮肤范围与现况、肠道准备完成情况、通路 | 每一项都能说出完成时刻 |
| 既往与用药 | 过敏史、长期使用的物品、既往手术与反应 | 能复述最近一次的相关反应 |
| 状态基线 | 生命体征、疼痛、活动、情绪、睡眠 | 五项都有可比较的记录 |
| 退路 | 术前出现变化的处置路径与联系人 | 知道找谁、怎么找 |

第四项「既往与用药」在核对里常被当成一次问诊，实际要落到「最近一次的相关反应」上。对象说「以前用过没事」，这句话本身不是信息；「上次是什么时候、当时有没有不适」才是。

第五项的五项基线要写明具体内容，不能写「一般情况可」。这一句在病历里最常见，也最无用——它无法与术后的任何表现作比较。

## 三、术后观察与配合的步骤

以下为课堂训练口径【教学设定】，时长按教学需要设定，观察频次与处置以现行规范与机构制度为准。

| 段 | 时间档 | 做什么 | 通过判据 |
|---|---|---|---|
| 接收 | 5 分钟 | 与手术方交接：项目、经过、管路、用药、特殊情况 | 接收方复述三项以上 |
| 就位 | 3 分钟 | 体位、保暖、管路安置、床档、呼叫器在手 | 管路无牵拉，呼叫器可取到 |
| 首次观察 | 接收后立即 | 意识、呼吸、颜色、伤口与敷料、管路、疼痛 | 六项各自与术前基线成对比较 |
| 观察间隔 | 按【教学设定】 | 按间隔复看，重点看变化项 | 每次都有时刻与比较结果 |
| 报告 | 变化即报 | 变化的类别、幅度、时刻、已做动作 | 接收人明确 |
| 记录 | 当次完成 | 见下表 | 记录可复现本次观察 |

第三段「首次观察」的六项顺序不是随意的：意识与呼吸在前，因为它们变化最快；伤口与管路在后，因为它们需要暴露与操作。把需要动手的项放在前面，会让最需要快速判断的项被推后。

第六项的记录要写「与术前基线比较」，而不是只写现值。只写现值，读记录的人必须自己回去翻术前记录；而翻不到的时候，比较就默认成立。

## 四、时限、责任人与记录字段

| 事项 | 时限口径 | 责任人 | 记录字段 |
|---|---|---|---|
| 术前基线 | 术前当次完成，不引用旧记录 | 术前班执行者 | 五项基线、完成时刻 |
| 核查 | 按机构规定的时点执行，逐项 | 执行者＋第二人 | 核查项、双方签名、时刻 |
| 交接 | 术后接收时当面完成 | 手术方与接收方 | 见下表 |
| 观察 | 按【教学设定】间隔，变化时加密 | 当班执行者 | 时刻、六项、比较 |
| 报告 | 变化即报 | 发现者 | 变化内容、幅度、接收人 |
| 记录 | 当次完成，不跨班补写 | 执行者 | 全部字段 |

| 记录列 | 内容 |
|---|---|
| 时刻 | 接收、首次观察、各次观察、报告 |
| 基线对照 | 术前五项基线的现值与差值 |
| 伤口与敷料 | 位置、渗液量级与性质、敷料完整性 |
| 管路 | 条数、位置、固定、通畅、引流性状 |
| 疼痛 | 部位、性质、程度（对象自述口径）、缓解因素 |
| 活动与饮食 | 体位耐受、首次活动、进食情况 |
| 报告与交代 | 报告对象、接收人、交代内容 |

第四列的「条数」要写数字。术后管路是最容易在交接中丢失信息的对象：一条引流被记成两条，或两条只记了一条，后续所有观察都会算错基数。

第五列「疼痛」的记法要按对象自述，不按观察者的判断。写「疼痛可忍」是观察者的判断，写「自述为持续性胀痛，翻身时加重，评分 4 分（自述）」是对象的表述。两者的区别在术后第一天的判断上尤其明显：前者无法比较，后者能看出趋势。同时要记缓解与加重因素，因为它们是下一步处置的依据，也是判断「是不是新出现的问题」的线索。

## 五、失效模式与考核项

- **核查走过场**：核查表全部打勾而无人真正比对。前兆是所有项同一时刻完成。拦截：核查分时点，双方各自记时。
- **术前基线缺失**：只写「一般情况可」，术后无可对照。前兆是术前记录无具体项。拦截：五项基线为必填。
- **禁食交代不到位**：只交代「不要吃」，未交代为什么、未确认对象理解。前兆是对象能复述「不能吃」但说不出原因。拦截：交代后请对象复述。
- **管路信息丢失**：交接未逐条核对，条数与位置记错。前兆是交接记录只写「管路通畅」。拦截：条数与位置逐条写。
- **首次观察推迟**：接收后先安置物品再看人，把观察排到最后。前兆是接收与首次观察的时刻相隔较久。拦截：观察先于整理。
- **疼痛被当成必然**：把术后疼痛一律视为正常，不记录、不报告。前兆是疼痛栏写「可忍」。拦截：疼痛按对象自述记录并报告变化。疼痛的记录一旦按观察者口径写，后续所有镇痛的调整都失去依据，而对象只能反复申诉同一句话。

### 考核项

1. **基线五项**：说出五项基线的具体内容，并各举一个「术前不写、术后误判」的例子。
2. **核查分时**：说出核查的时点与各项内容，说明为什么不能一次核完。
3. **交接复述**：完成一次术后接收交接，接收方复述三项以上。
4. **管路计数**：给一段交接描述，指出其中缺失的管路信息。
5. **首次观察顺序**：说出六项的观察顺序与排序理由。
6. **记录改写**：把「术后一般情况可，管路通畅」改写成合规记录。

## 六、代价与边界

以「术前基线」为核心，第一重代价是**术前环节的时间被拉长**。五项基线要逐项问、逐项记，在手术排程紧张时是明显负担。可行的做法是把基线做成表，术前班一次填完，术后直接引用，避免重复询问。

第二重代价是**「不写一般情况可」会带来更多异常报告**。有了基线，很多过去被一句「可」带过的变化会浮现，报告次数上升。这与观察变细是同一件事的两面，收敛的办法是约定组合判据，而不是回到模糊描述。

第三重代价是**交接的双向复述需要双方同时在场**。手术方赶着下一台、接收方手上还有别的事，复述常被省略。省略之后，出问题时双方各有一套说法。这一条只能靠制度固定交接窗口，靠个人提醒守不住。

三处不写：不写禁食禁饮时长、皮肤准备的用药与操作参数、麻醉与镇痛方案、补液与用药剂量；不写手术部位感染的分类与发生率；不写页码。引用只到「教材·第 12 章·12.1.2」级。
