# 第 14 章 · 质量管理的证据在复核，不在报告数量

> **MOTTO:** 「千丈之堤，以蝼蚁之穴溃」——《韩非子·喻老》
>
> **PROBLEM:** 本章底本 57,391 汉字、387 个实质段；段内含「记录」的 143 段（40.0%）、含「复核」的 89 段（25.6%），而含「评估」的 9 段（2.8%）、含「时限」的只有 1 段（0.2%）。记录与复核写得最厚，而「隔多久回看一次、谁来回看」这一层几乎空着。

## 一、风险来源三类，防范落在三个位置

技能相关的风险按来源分三类，每一类的防范落点不同。把三类混在一起谈，防范就会全落在「加强培训」这一句上。

| 来源 | 典型形态 | 防范落点 |
|---|---|---|
| 技术类 | 无菌区污染、管路接错、体位与约束伤害 | 步骤与判据：把判断做成可复述的动作 |
| 流程类 | 核对走形式、交接断裂、记录倒补 | 时点与留痕：把关键节点固定成时刻 |
| 环境类 | 人力不足、物品摆放不便、照明与空间受限 | 布局与排班：改条件而不是改人 |

第三类最容易被写成「个人责任心不强」。判断依据很简单：**同一个问题在不同班次反复出现，而当事人都不是新手**，那就不是人的问题，是条件的问题。够不到的位置导致跨越，找不全的物品导致中断，人少导致观察滞后——这三件事靠培训解决不了，靠挪一个柜子、加一个班就能解决。

由此得到本章第一条判断：**质量管理的产出是「改了什么」，不是「查了几次」**。查十次而一处不改，比查一次而改一处更接近形式主义。

## 二、社区与居家场景的评估与核对

同一个技能换到居家场景，判据不变，条件全变。差异要写清楚，否则把病房做法直接搬过去就会出问题。

| 项 | 机构内 | 居家与社区 |
|---|---|---|
| 环境 | 可调床、照明、通道、呼叫装置 | 床高固定、照明不足、通道狭窄、无呼叫 |
| 人力 | 当班同事可支援 | 常只有一个照护者，可能是家属 |
| 物品 | 集中供应、可即时补充 | 自行准备、可能缺件、可能重复使用 |
| 退路 | 呼叫、转运、就近处置 | 呼救靠电话，到达有时间差 |
| 知情 | 制度化的告知与同意 | 需向对象与照护者同时说明，含「什么情况必须就医」 |

第四项是居家场景的核心差异。机构内的异常有就近处置的路径，居家没有——从发现到获得帮助之间存在一段无法压缩的时间。所以居家技能的评估必须多问一句：**如果现在出现变化，最近的帮助在哪里、多久能到**。答不上来，就不具备在居家完成这项操作的条件。

由此得到本章第二条判断：**居家护理的门槛不是能不能做，是出了问题能不能接住**。能接住，简单操作可以居家；接不住，再简单的操作也不该居家。

## 三、监测与复核的步骤与判据

以下为课堂演练口径【教学设定】，周期、样本量与复核方式按机构制度确定。

| 段 | 周期档 | 做什么 | 判据 |
|---|---|---|---|
| 定项 | 每轮开始前 | 明确本轮监测哪一项、为什么是这一项 | 有明确的问题指向，不是「全面监测」 |
| 取样 | 按【教学设定】 | 抽取记录或现场观察，含好与坏两类 | 样本含未发生问题的情形 |
| 复核 | 取样后即做 | 回看原始记录与现场一致性：记录说的与做的对不对得上 | 至少一处不一致被发现，或明确写「未发现」 |
| 归因 | 复核后 | 按技术、流程、环境三类归因 | 归因落在可改的条件上 |
| 改动 | 归因后定人定时 | 一条改动，明确责任人与完成时点 | 改动可验证，不写「加强」 |
| 回看 | 按【教学设定】 | 下一轮看这条改动是否生效 | 有效／无效／无法判断，三态之一 |

第三段是整套流程里最容易被跳过的一段。多数监测停在「取样＋统计」，把记录的数量当作质量的证据；而记录与实际是否一致，只有回看现场才能回答。一次回看能发现的问题，往往比十份统计更具体：约束记录写「每两小时复核」，而现场的交班本上没有这两小时的痕迹。

第六段的「无法判断」是一个合法结论。改动之后没有变化，可能是改动无效，也可能是观察期不够、其他因素干扰。写成「有效」会让下一轮失去依据，写成「无法判断」至少保留了继续看的理由。

第三段与第一段要配对使用。定项时选的是「这一轮最想弄清的一个问题」，复核时看的就该是这个问题的原始痕迹，而不是顺手能拿到的报表。选问题、找痕迹、看一致性，这三步走完，一轮监测才算有了内容；只做第一步而跳过第三步的，是把监测做成了统计。

## 四、责任分工与记录字段

| 事项 | 时限口径 | 责任人 | 记录字段 |
|---|---|---|---|
| 监测定项 | 每轮开始前 | 质量负责人 | 项目、依据、本轮关注点 |
| 取样与复核 | 按【教学设定】 | 质量负责人＋当班执行者 | 样本量、复核方式、不一致处 |
| 归因与改动 | 复核后当轮完成 | 质量负责人 | 类别、改动内容、责任人、完成时点 |
| 回看 | 下一轮 | 质量负责人 | 三态结论、依据 |
| 报告保护 | 报告即适用，不因报告受不利对待 | 机构 | 报告人、保护范围 |
| 数据合规 | 采集与使用时 | 数据使用人 | 用途、范围、脱敏方式、留存 |

| 记录列 | 内容 |
|---|---|
| 项目与依据 | 监测什么、依据来自何处 |
| 样本与方式 | 样本量、抽取方式、是否含未发生问题的情形 |
| 不一致处 | 记录与现场不符的具体位置 |
| 归因 | 技术／流程／环境，附一句判断依据 |
| 改动 | 一条改动＋责任人＋完成时点 |
| 回看结论 | 有效／无效／无法判断 |
| 数据合规 | 脱敏方式、使用范围、留存安排 |

第七列在平台化之后变成硬要求。训练数据、操作记录、影像资料一旦进入系统，就同时涉及个人信息与教学用途两个边界；「脱敏」与「去标识化」不是同义词，混用会导致本该去标识的数据只做了表面处理。这一列要写具体做法，不写「已脱敏」。

## 五、失效模式与考核项

- **数量代替质量**：以报告数、检查次数、培训场次作为质量证据。前兆是报表很好看而具体问题一年未变。拦截：每轮必须落一条改动。
- **复核变签字**：复核栏有签名而无回看动作。前兆是签名时刻集中于月末。拦截：复核须写「不一致处」或「未发现」。
- **居家无退路**：在缺乏就近帮助的条件下开展操作。前兆是评估表里没有「多久能到」这一项。拦截：退路作为准入条件。
- **归因指向个人**：问题反复出现而结论总是「责任心不强」。前兆是改进项里全是「加强培训」。拦截：三类归因，指向条件。
- **数据合规缺位**：教学使用真实资料未去标识，或去标识不彻底。前兆是记录里出现可识别信息。拦截：采集前定用途与脱敏方式。
- **改动无回看**：改了但没人看是否生效。前兆是改进清单只增不减。拦截：回看三态入记录。

### 考核项

1. **三类归因**：给三个反复出现的问题，各判断属于哪一类并写出改动方向。
2. **退路评估**：为一个居家场景写准入判断，须含「多久能到」这一项。
3. **复核设计**：为一项目设计一次复核，说明样本为何要含未发生问题的情形。
4. **改动表述**：把「加强核对意识」改写为一条可验证的改动。
5. **三态回看**：给一个改动后的结果，判断属于有效、无效还是无法判断并说明依据。
6. **数据合规**：说明脱敏与去标识的区别，并指出混用的一处具体后果。

## 六、代价与边界

以「改了什么」为质量管理的成品，第一重代价是**成绩不容易被看见**。一条改动的价值要等下一轮才显现，而报表的数量当月就能上报。这个时间差会让做实事的团队在评价上吃亏，只能靠管理者自己认出「慢的价值」。

第二重代价是**复核会暴露自己单位的问题**。回看现场意味着可能发现自己签过的字没有对应的动作。这一层阻力是真实的，处理办法不是降低复核强度，而是把「发现问题」与「追究个人」分开：复核发现的不一致，先按流程与环境归因，个人责任另按制度处理。

第三重代价是**居家场景的准入会拒绝一部分需求**。退路不成立时不做，意味着这个家庭当下得不到这项服务。这是一个艰难的决定，但把没有退路的操作做下去，风险全部由对象与那位唯一的照护者承担。
