# 第 12 章 · 演练的价值不在演得像，在复盘时敢说哪一步没做

> **MOTTO:** 「不闻不若闻之，闻之不若见之，见之不若知之，知之不若行之」——《荀子·儒效》
>
> **PROBLEM:** 本章底本 19,556 汉字、111 个实质段；段内含「记录」的 79 段（74.7%）、含「核对」的 50 段（48.1%）、含「观察」的 29 段（28.6%），而含「评估」的 3 段（2.3%）。演练的记录与核对写得最细，而「这次演练要考什么、演到什么程度算过」这一层几乎没有落点。

**双根因定位:** 环境逼迫——演练是一场有观众的活动，教师、同学、拍摄设备都在场，于是演练天然向「演得好看」倾斜，出错的部分被下意识地抹平；知识积累——教材把演练写成「情境设计—角色分工—实施—复盘」四段，每段都写足了要求，但「允许出错」这件事只作为一句原则存在，没有变成可执行的规则。

**本章引证口径：** 教材·第 13 章·13.1.2（角色分工与流程要求）；段数与关键词命中按 `standards/jichu-huli/units.json` 现算（实质段＝以换行分隔、≥35 汉字者；占比＝命中段汉字／实质段汉字合计）；带【教学设定】的分钟档、人数与轮次为课堂演练口径；全章不写任何操作的临床参数、药物与剂量，不写结局比例，不引页码。

**引用粒度：** 只到「第 13 章·第 1 节」（13.1.2）级，不引页码、不引版次；节号为底本单元编号的中段，目号为该节内的条目序号。

## 一、情境设计的四个要素

一个能练出东西的情境，必须同时具备四个要素。缺一个，演练就会退化成表演。

| 要素 | 内容 | 缺了会怎样 |
|---|---|---|
| 目标 | 本次要考的判断或动作，一条，不超过两条 | 演完不知道考了什么，复盘无从下手 |
| 障碍 | 人为设置的困难：信息不全、家属干扰、物品缺件、对象不配合 | 全程顺畅，学员只练了「顺手时的做法」 |
| 边界 | 学员可以做什么、不可以做什么、什么时候必须求助 | 学员越界或不敢动，两种情况都无法评价 |
| 判据 | 什么算做到、什么算没做到，可观察 | 复盘变成印象交流 |

第三个要素「边界」是设计里最容易被省略的一项。演练中的学员常常卡在一个动作上，不是因为不会，而是因为不确定「这一步该不该我做」。把边界写进情境说明，学员才敢在范围内果断行动，也才能在越界时被明确指出来。

由此得到本章第一条判断：**情境的难度不来自病情复杂，来自信息不全**。病情复杂的场景容易演成流程展示；信息不全的场景才会逼出「先确认再动手」的判断。一个只给了一半信息的情境，比一个病种罕见的情境有用得多。

四个要素里，「判据」要写得像考卷而不是像期望。「做到规范、体现人文关怀」不是判据，因为它无法判定；「在接触对象之前完成身份核对并复述依据」是判据，因为它可以被看到。判据一旦写成期望，复盘就只能凭印象，而印象总向「大家都挺努力」的方向偏。

## 二、演练前的准备与核对

| 项 | 要确认的 | 判据 |
|---|---|---|
| 目标与判据 | 本次考什么、怎么算过 | 学员在开始前知道判据 |
| 角色 | 谁演对象、谁演家属、谁观察、谁记录 | 每人知道自己演什么、不演什么 |
| 物品与装置 | 用物是否齐全、模拟设备状态、缺件是否为刻意设置 | 缺件有清单，不靠临场发现 |
| 安全 | 模拟操作不进入真实对象；锐器、用药、电源的替代方案 | 危险环节有明确替代，无真实接触 |
| 知情 | 参与者的知情与同意、拍摄与使用的范围 | 同意留痕，使用范围写明 |
| 复盘安排 | 何时复盘、谁主持、按什么顺序说 | 复盘的时段与主持人在开始前定 |

第四项「安全」在演练里是硬门槛。演练中「假做」的动作如果不设替代，学员会在真实器材上做出真实动作：锐器可能真的刺入，药物可能真的被抽取。替代方案要在准备阶段定好——用替代物、用空操作、用明确口令代替。

第六项常被省略，结果演练结束时大家都累了，复盘草草收场。复盘的时段必须与演练时段一样被预先占住。

## 三、实施步骤与引导判据

以下为课堂训练口径【教学设定】，时长、人数与轮次按教学需要设定。

| 段 | 时间档 | 做什么 | 通过判据 |
|---|---|---|---|
| 说明 | 3 分钟 | 交代情境、角色、边界、判据 | 学员能复述「我负责什么、不能做什么」 |
| 进场 | 1 分钟 | 就位、报角色、确认通讯 | 每人报出角色，通讯有回应 |
| 实施 | 8–15 分钟 | 按情境推进，观察者只记不提示 | 观察者记录的是行为与时刻，不是评价 |
| 插障 | 按设计 | 按预设时点插入障碍，不临场加码 | 障碍在开始前已定，插入时刻可查 |
| 收束 | 2 分钟 | 宣布结束、停止角色、回到本人 | 学员明确退出角色，情绪有回落时间 |
| 复盘 | 10–15 分钟 | 按「事实—判断—改进」三段进行 | 事实先于评价，改进落到一条 |

第五段「收束」在教材里几乎不写，但它是演练独有的伦理要求。扮演对象的学员在演练中可能被搬动、被约束、被大声指令，结束时不明确退出角色，这些体验会带到角色之外。收束的三个动作——宣布结束、脱去角色、给一句话的空间——是演练区别于真实操作的唯一缓冲。

第六段的三段式复盘有一条硬规则：**先说事实，再说判断，最后说改进**。跳过事实直接评价（「你这里做得不好」），学员无法把评价对应到具体动作；只有事实（「第 4 分钟你离开了按压位置去取物，离开约 20 秒」）才能支撑后面的讨论。

三段式里最容易跳过的是「判断」这一段。事实摆出来之后，大家往往直接跳到改进：「下次别离开就是了。」但离开的原因是判断问题——当时以为取物只要几秒、以为旁边有人接手。不把这个判断说出来，改进就只是一个禁令，换个情境仍然会发生。复盘的真正产出是让当事人自己说出当时的判断，再由全组看这个判断在什么条件下会出错。

## 四、记录、责任人与复盘产物

| 事项 | 时限口径 | 责任人 | 记录字段 |
|---|---|---|---|
| 观察记录 | 实施中同步记，不事后追记 | 观察者 | 时刻、行为、口令、缺项 |
| 复盘记录 | 复盘当次完成 | 记录者 | 事实、判断、改进、责任人 |
| 改进跟踪 | 按【教学设定】在下次演练前回看 | 教学负责人 | 改进项、完成情况、复验方式 |
| 案例归档 | 脱敏后归档 | 教学负责人 | 情境、判据、暴露的问题、改进 |
| 安全事件 | 演练中发生的真实损伤即报 | 发现者 | 时刻、经过、处置、接收人 |

| 记录列 | 内容 |
|---|---|
| 时刻 | 关键动作的时刻，用于算间隔 |
| 行为 | 做了什么、没做什么，只写可见动作 |
| 口令 | 说了什么、谁回应、有无复述 |
| 缺项 | 该做而未做的动作 |
| 越界 | 超出边界的动作与当时的说明 |
| 事实与判断 | 复盘时分列，不混写 |
| 改进项 | 一条可执行的改动＋责任人＋复验方式 |

第七列要求「一条」。复盘最容易产出的是一张长长的改进清单，而长清单的结果是一条也改不动。每次演练只锁定一条，下次演练专门验这一条。

## 五、失效模式与考核项

- **演成表演**：学员按预演过的流程走一遍，障碍被绕开或忽略。前兆是全程无停顿、无求助。拦截：障碍插入时刻固定，观察者记录是否被绕过。
- **复盘变成表扬会**：只说做得好的地方，问题用「下次注意」带过。前兆是复盘记录里没有具体事实。拦截：事实先行，缺项必须点出。
- **安全失守**：演练中使用真实锐器、真实药物，或扮演对象被真实搬动受伤。前兆是替代方案未定。拦截：替代方案前置，危险环节空做。
- **案例未脱敏**：用真实病例细节编写情境，可被识别。前兆是情境里出现具体日期、地名、职业。拦截：脱敏与合成要求写进编写规范。
- **角色不清**：学员不知道自己能做什么，全程等待指令。前兆是频繁看向教师。拦截：边界在说明段说清。
- **改进不闭环**：复盘产出清单，下次演练无人回看。前兆是改进项无责任人、无复验。拦截：一条改进＋复验方式。

### 考核项

1. **四要素**：给一个情境草案，指出缺失的要素并补全。
2. **边界复述**：进入情境前，用自己的话说出「我负责什么、不能做什么、何时求助」。
3. **障碍设计**：为一个基础操作设计三个信息不全的障碍，各写一句插入时点。
4. **观察记录**：观察一次演练，写出五条只含行为与时刻的记录，不得含评价词。
5. **复盘三段**：主持一次 10 分钟复盘，须做到事实先于判断【教学设定】。
6. **收束动作**：说出收束的三个动作，并解释为什么需要「退出角色」这一步。

## 六、代价与边界

以「允许出错」为核心，第一重代价是**演练会变得不好看**。学员在情境里犹豫、求助、做错，观感远不如流畅的流程展示。带教者要承受这种观感，否则会在不知不觉中把障碍撤掉。

第二重代价是**复盘需要时间与技巧**。事实先行的复盘比「大家说说感受」慢得多，也需要主持人有把评价翻译成事实的能力。这门技巧不是天生的，需要在教学团队内部专门练。

第三重代价是**「只改一条」会显得保守**。一次演练暴露六个问题，只锁定一条改进，看起来像不作为。这一条的理由是执行：能落地的一条，胜过写在纸上没人执行的六条。

三处不写：不写任何临床操作参数、药物与剂量；不写演练中「典型错误率」这类比例；不写真实机构与个人的可识别信息。引用只到「教材·第 13 章·13.1.2」级。
