# 核对不是问一句，是给患者一次纠正你的资格 · 提示词

## 用途

给「核对不是问一句，是给患者一次纠正你的资格」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「识别的四种方式与其选用次序 → 关键环节的再核对：四个时点 → 告知同意：四要素与留痕 → 拒绝、中止与尊严保护」这条链。

## 提示词

```
我在学《基础护理学》第 2 章「核对不是问一句，是给患者一次纠正你的资格」，本章 6 节 / 3,090 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 本章引证口径
   - 自述是唯一能让对象参与纠错的环节
   - 对象获得了一次说「不是我」的机会
   - 只要执行者变了、位置变了、容器变了，就当作第一次做
   - 写谁说的、写对方怎么回应的、写有没有提问
   - 告知时谁在场
4. 指出本章写到类别就止步、不再给参数的地方。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，不构成医学意见、诊断或护理指导；具体操作以现行规范与所在机构制度为准。
