# 第 7 章 · 排泄观察的价值在记录，不在处置

> **MOTTO:** 「膀胱者，州都之官，津液藏焉，气化则能出矣」——《黄帝内经·素问·灵兰秘典论》
>
> **PROBLEM:** 本章底本 19,816 汉字、94 个实质段；段内含「记录」的 82 段（88.6%）、含「观察」的 42 段（49.5%）、含「交接」的 31 段（37.0%），而含「导尿」二字的 0 段。章题写着排泄与导尿，正文一次也没有使用这个词，全部写成「协助方式类别」与「留置期间的观察」。

**双根因定位:** 环境逼迫——排泄是最私密、最容易被快速处理掉的一类照护，对象不愿多说、护理人员不便多问，于是处置被保留、描述被压缩；知识积累——教材按「排尿—排便—标本」三条线并列展开，每条线都写足了「怎么协助」，而把「记录到什么程度才算记录了」写成一句要求，没有给出字段。

## 一、六个维度：观察先于处置

排泄的观察不是「有没有解」，是六个可以写下来的维度。六个维度里缺任何一个，一次记录就只能当作「解过了」。

| 维度 | 看什么 | 记不下来会漏掉什么 |
|---|---|---|
| 量 | 量级描述（多、中、少）与容器刻度 | 少尿与无尿的区别，往往只差一个「少」字 |
| 色 | 深浅、有无血色、有无浑浊 | 颜色改变是最早的可观察信号之一 |
| 性状 | 成形、稀、水样、有无黏液或异物 | 性状决定是否需要报告，量不决定 |
| 频次 | 本次与上次的间隔、一日次数 | 频次突增往往比单次异常更值得报 |
| 伴随 | 疼痛、费力、坠胀、恶心、发热感 | 伴随表现决定要不要立即报告 |
| 通路 | 自主、协助、留置；留置的固定与通畅 | 通路状态决定后续所有判断的前提 |

第六维「通路」是本章的结构性一维。留置状态下，观察的对象不只是排出物，还包括管路本身：固定是否牢、有无牵拉、引流是否通畅、接口是否密闭。管路问题不会自己表现出来，只会在记录里留下线索——比如「量突然减少」而对象并无不适。

由此得到本章第一条判断：**排泄护理的成品是一份能复现的记录，不是一次完成的协助**。同一个对象、同一班、两次记录，如果读不出「变化」，这份记录在临床上的作用接近于零。

六个维度里最难落实的是「性状」，因为它要求的词汇比日常用语细：成形、软、稀、水样、带黏液、带未消化物，这几个词之间没有绝对边界，但一旦选定并在同一对象身上持续使用，就能读出趋势。同一班三个人各用一套词，记录就退化成三次互不相关的描述。解决它的办法不是统一到某个标准术语表，而是在同一对象的记录里保持用词一致，并允许附一句具体描述。

## 二、操作前的评估与核对

| 项 | 要确认的 | 判据 |
|---|---|---|
| 自理能力 | 能否自行如厕、能否表达需求、移动能力 | 能说出本次为何用这种方式协助 |
| 现况 | 上次排泄的时刻与情况、有无腹胀或尿意、有无疼痛 | 能复述上次记录的关键维度 |
| 通路 | 有无留置、固定与通畅情况、引流袋位置 | 管路状态当场看过，不凭交班 |
| 标本 | 本次是否需留取、留取目的、容器是否备好 | 目的明确，容器在手 |
| 环境 | 遮挡、私密、温度、地面是否湿滑 | 遮挡先于暴露，地面干燥 |
| 退路 | 协助中对象不适或跌倒风险升高时的处置 | 呼叫方式与人力安排已定 |

第五项的两个动作——遮挡与防滑——在教材里都属「环境准备」，实际是两个不同性质的风险：遮挡是尊严，防滑是安全。两者都不能在上手之后再补，所以都放在准备项里。

第一项「自理能力」在实操里常被简化成一个固定的标签：能走、不能走。这个标签一旦贴上，后续所有协助方式都按它执行，而能力是会变的——一次发热、一次用药后的头晕、一次夜间起身，都会让「能走」变成「当次不能走」。所以评估要按当次做，评估的产物是一句话：「今天能在人扶下走到洗手间，昨天可以独立去。」这句比较，比任何标签都有用。

## 三、协助与导尿配合的步骤与判据

以下为课堂训练口径【教学设定】，时长按教学需要设定，操作参数以现行规范与机构制度为准。

| 段 | 时间档 | 做什么 | 通过判据 |
|---|---|---|---|
| 告知 | 1 分钟 | 说明协助方式、需要对方配合什么、如何叫停 | 对象能复述「怎么叫停」 |
| 准备 | 2 分钟 | 遮挡、物品、手卫生、体位 | 遮挡完成后再进入暴露步骤 |
| 协助 | 按方式计 | 按方式完成协助，全程保持遮挡与呼叫可达 | 对象无跌倒、无牵拉、无暴露 |
| 观察 | 即时 | 六维观察，当场记下关键项 | 六维中至少五维有内容 |
| 处置 | 即时 | 清洁、复位、管路固定、标本留取 | 管路固定牢，标本标识完整 |
| 交代 | 1 分钟 | 下次协助时间、饮水与活动安排、异常如何报告 | 对象能说出「什么情况要叫人」 |

第四段「观察」的判据定在「至少五维有内容」，是有意的：六维全填在实际工作里很难，但只填「已解」等于没填。留一维的余量，是为了让记录在真实节奏下仍能成立。

第五段的「标本留取」有两条硬要求：**标识在离开对象之前完成**，**留取后不放置**。前者防混标，后者防延误——标本的可靠性随时间下降，而延误往往不是没人送，是「等下一趟顺便带过去」。

## 四、时限、责任人与记录字段

| 事项 | 时限口径 | 责任人 | 记录字段 |
|---|---|---|---|
| 协助后记录 | 当次完成，不跨班补写 | 执行者 | 六维＋时刻 |
| 留置管路观察 | 每班至少一次，交接时复核 | 当班执行者 | 固定、通畅、引流性状、接口 |
| 标本送检 | 留取后按机构规定的时限送检 | 留取者 | 留取时刻、送检时刻、接收人 |
| 异常报告 | 发现即报 | 发现者 | 表现、基线、接收人 |
| 交接 | 每班交接，含未完成项 | 交班者 | 上次时刻、量级、异常、待办 |

| 记录列 | 内容 |
|---|---|
| 时刻 | 本次与上次的时:分，间隔可算 |
| 方式 | 自主、协助、留置；协助的具体方式类别 |
| 六维 | 量级、色、性状、频次、伴随、通路 |
| 管路 | 固定、通畅、接口、引流袋位置与更换 |
| 标本 | 是否留取、目的、留取与送检时刻 |
| 对象反应 | 疼痛、费力、情绪、耐受 |
| 报告与交接 | 报告对象、交接要点、待观察项 |

第一列的两个时刻要一起写，因为**间隔本身是一个观察项**。只写「本次 14:00」而上次时刻靠翻页找，等于让读记录的人做一次检索；而检索失败时，间隔就被默认为「正常」。

## 五、失效模式与考核项

- **量级靠估**：尿量按「大概半袋」写，便量按「一些」写。前兆是同一对象的记录量级长期不变。拦截：有刻度的容器与固定描述词。
- **只记结果不记过程**：写「已解小便」，不写色、性状、伴随。前兆是记录列大量留白。拦截：六维至少五维为必填。
- **标本混标与延误**：留取后未即时标识，或放置等待集中送检。前兆是标识与留取时刻不一致。拦截：标识前置、送检时刻入记录。
- **管路牵拉**：翻身、搬运、如厕时未先处理管路。前兆是固定处皮肤发红、引流袋位置高于必要高度。拦截：任何移动前先处理管路，作为独立步骤。
- **协助中跌倒**：独自协助移动能力下降的对象，未呼叫第二人。前兆是「他平时能走」。拦截：移动能力按当次评估，不按印象。
- **便秘处置越界**：自行采用超出职责范围的措施。前兆是记录里出现无依据的处置。拦截：处置边界写进职责，越界即回报。

### 考核项

1. **六维复述**：说出六个维度，并各举一个「缺这一维会漏掉什么」的例子。
2. **记录改写**：把「已解小便一次，量中」改写成含五维以上的记录。
3. **间隔计算**：给两条记录，算出差值并判断是否需要报告。
4. **管路优先**：在协助移动前，说出必须先完成的三件管路相关动作。
5. **标本流程**：按顺序说出留取、标识、送检三个动作的时点要求。
6. **边界判断**：给三个情境，判断哪些处置属于职责内、哪些必须回报。

## 六、代价与边界

以「六维记录」为标准，第一重代价是**时间**。一次协助后的记录从一行变成五行，高频的班次里这是明显的负担。可行的减负是模板化：六维做成勾选，量级用固定词，只有变化项需要写句子。

第二重代价是**它要求问一些难以启齿的问题**。性状、伴随、疼痛，这些都要问，而对象往往不愿答。处理办法不是回避，是把问题变成常规项——「我们每次都要记这几项，您照实说就行」——把私密问题放回流程里，减少个体的尴尬。

第三重代价是**报告线会变敏感**。六维齐全之后，很多过去被忽略的变化会浮现出来，报告次数随之上升。这会带来「是不是报太多」的质疑。本章的立场是：报得多可以收敛，漏报无法追回；收敛的办法是约定哪些组合必须报，而不是减少观察。
