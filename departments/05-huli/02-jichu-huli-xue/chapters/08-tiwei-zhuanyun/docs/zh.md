# 第 8 章 · 翻身的意义不在翻，在翻完之后看了什么

> **MOTTO:** 「久视伤血，久卧伤气，久坐伤肉，久立伤骨，久行伤筋」——《黄帝内经·素问·宣明五气》
>
> **PROBLEM:** 本章底本 20,261 汉字、131 个实质段；段内含「记录」的 81 段（62.5%）、含「交接」的 56 段（43.7%）、含「体位」的 41 段（32.8%），含「约束」的只有 9 段（8.0%）。约束是本章唯一涉及限制人身的一类技术，篇幅不到十二分之一。

**双根因定位:** 环境逼迫——体位与转运是「人力最容易短缺」的环节，两个人搬一个人是标准配置，而实际常常只有一个；人少了，动作就会退化成「先完成再说」，观察与记录随之被挤掉；知识积累——教材把体位、活动、转运、约束写成四组并列的要求类别，每组各自完整，但四组之间的共同前提（同一次移动既要护住身体，也要护住管路与尊严）只写了一句。

**本章引证口径：** 教材·第 9 章·9.1.2（变换频次与观察要求类别）；段数与关键词命中按 `standards/jichu-huli/units.json` 现算（实质段＝以换行分隔、≥35 汉字者；占比＝命中段汉字／实质段汉字合计）；带【教学设定】的分钟档与频次为课堂演练口径；全章不写压力、角度、承重等操作参数，不写发生率，不引页码。

## 一、四要素：压力、剪切、潮湿、时间

受压部位的损伤不是「压坏了」，是四个因素共同作用的结果。四个因素里，护理能改变的是后三个。

| 要素 | 来源 | 护理能改变的部分 |
|---|---|---|
| 压力 | 体重与支撑面之间 | 通过变换体位改变受力点，不试图消除压力 |
| 剪切 | 拖、拽、滑：皮肤与深层组织错位移动 | 抬举代替拖拽，减少错位 |
| 潮湿 | 汗、渗液、失禁、冲洗残留 | 保持干燥、及时更换、避免摩擦叠加 |
| 时间 | 同一受力点持续受压的时长 | 按时变换，并在变换时看皮肤 |

第三要素与第四要素合起来解释了一个常见现象：同一个对象，某个部位在两次翻身之间出了问题，而两次翻身都「按时做了」。原因是潮湿让皮肤耐受下降，同样的时长变成了不同的结果。所以「按时翻身」只是一个必要条件，另一个条件是每次翻身时把皮肤看一遍。

由此得到本章第一条判断：**翻身的成品是一次皮肤检查，不是一次位置改变**。位置改变了而没有人看过皮肤，这次翻身在预防上的作用只有一半。

约束与技术并列，理由在同一个词上：翻身、转运、约束三者都是对身体的直接移动或限制。约束改变的是对象能自主移动的范围，它的收益是防止管路被拔、防止跌落，它的代价是活动受限、皮肤受压时间延长、情绪与尊严受损。把约束放进这一章，是为了让它与翻身、转运共用同一套判据——先看能不能用别的方式解决，再决定是否限制，并且限制之后仍要按时看皮肤。把约束当成一条独立规则去记，容易只记住「要签同意」，记不住「它同时是一次加压」。

## 二、操作前的评估与核对

| 项 | 要确认的 | 判据 |
|---|---|---|
| 耐受 | 能否配合、有无疼痛、有无呼吸费力、有无头晕 | 能说出本次为何用这个体位与角度 |
| 管路 | 有几条、各在哪里、哪些不能压、哪些不能牵 | 逐条说出位置与固定方式 |
| 皮肤 | 现况：发红部位、有无破损、有无潮湿 | 上次记录的部位当场复核 |
| 人力与器具 | 需要几人、器具是否在位、床高是否合适 | 人力与器具在开始前到位 |
| 环境 | 空间是否够、地面是否湿滑、遮挡是否完成 | 通道畅通，遮挡先于移动 |
| 退路 | 移动中出现不适或滑落的处置 | 呼叫方式与接手人已定 |

第四项是一条硬门槛。**人力不足时不做，不等同于不搬**——正确做法是先把能做的做完（调床高、清通道、备器具、告知对象），再等人。抱着「先挪一点」的心态开始，是搬动伤害最常见的起点。

第三项「皮肤」的现况要来自上次的记录，不能来自记忆。受压部位的变化是缓慢的，今天看到的一小片发红，与三天前同一位置的那一小片，是不是同一片，只有记录能回答。所以本项判据写的是「当场复核上次记录的部位」，而不是「看一下皮肤」。

## 三、步骤与判据

以下为课堂训练口径【教学设定】，时长按教学需要设定，操作参数以现行规范与机构制度为准。

| 段 | 时间档 | 做什么 | 通过判据 |
|---|---|---|---|
| 告知 | 1 分钟 | 说明要做什么、需要对方怎么配合、何时可以叫停 | 对象能复述配合要点与叫停方式 |
| 就位 | 1 分钟 | 床高、器具、人力、管路预安置、遮挡 | 六项各自确认，管路无牵拉 |
| 移动 | 按人数与方式计 | 抬举代替拖拽，同步口令，动作一次完成 | 皮肤无摩擦音，管路无张力 |
| 复位 | 1 分钟 | 体位摆放、支撑物放置、管路复位、床档 | 支撑到位，管路回到无张力位置 |
| 观察 | 即时 | 皮肤（原发红处与新受力点）、呼吸、疼痛、意识 | 与上次记录成对比较 |
| 记录 | 即时 | 体位、时刻、皮肤、管路、对象反应 | 记录能复现本次动作 |

第三段「移动」的判据定在「皮肤无摩擦音」上，是一条可听的判据：拖拽时床单与皮肤之间会有摩擦声，抬举时没有。这条判据比「动作轻柔」可执行，也比「注意剪切」好教。

第五段「观察」要求同时看两处：上次发红的部位有没有变化，本次新受力点有没有开始发红。只看新受力点，会把已经在恢复的部位重新压回去；只看旧部位，会漏掉新的受压点。

## 四、时限、责任人与记录字段

| 事项 | 时限口径 | 责任人 | 记录字段 |
|---|---|---|---|
| 变换体位 | 按【教学设定】的频次执行，受压点与耐受变化时加密 | 当班执行者 | 时刻、体位、皮肤、管路 |
| 皮肤复核 | 每次变换时看，交班时全面看一次 | 当班执行者 | 部位、颜色、完整性、与上次比较 |
| 约束使用 | 仅在替代方式无效时，按依据执行并定时复核 | 执行者＋复核人 | 依据、部位、时间、复核 |
| 转运前评估 | 出发前完成，不途中补 | 转运执行者 | 五项评估结果 |
| 交接 | 到达即交接，双方复述 | 转出与接收双方 | 见下表 |
| 异常报告 | 发现即报 | 发现者 | 表现、时刻、接收人 |

| 记录列 | 内容 |
|---|---|
| 时刻 | 变换与观察的时:分 |
| 体位 | 体位类别、倾斜程度（描述性）、支撑物位置 |
| 皮肤 | 部位、颜色、完整性、范围、与上次比较 |
| 管路 | 条数、位置、固定、有无牵拉 |
| 对象反应 | 疼痛、呼吸、意识、耐受、主诉 |
| 约束 | 是否使用、依据、部位、复核时刻、替代方式尝试 |
| 交接 | 转出方陈述、接收方复述、待观察项 |

第六列要求写「替代方式尝试」，是为了让约束的使用留下一个前置条件：先试过别的，再考虑限制。只写「已约束」的记录，无法区分「试过无效」与「图省事」。

## 五、失效模式与考核项

- **拖拽代替抬举**：人力不足时以拖代抬，皮肤与床面错位。前兆是摩擦声、床单起皱。拦截：人力门槛前置，不足即等。
- **管路牵拉**：移动前未处理管路，移动中拉扯。前兆是固定处皮肤发红、引流袋被带起。拦截：管路预安置列为独立步骤。
- **约束滥用与失察**：以约束替代观察，或约束后不按间隔复核。前兆是约束记录里缺复核时刻、缺替代方式。拦截：约束依据与复核双必填。
- **转运交接断裂**：送到即走，口头一句「都还好」。前兆是交接记录无接收方复述。拦截：双向复述，缺一不算交接。
- **体位与目的不符**：需要减压的体位被摆成舒适体位，或反之。前兆是记录里体位与目的无关联。拦截：记录须写「为何是这一体位」。
- **观察滞后**：翻完即走，皮肤留到下次再看。前兆是皮肤列内容与上次雷同。拦截：观察与变换绑定为同一动作。

### 考核项

1. **四要素复述**：说出四个要素，并各举一个「只改一个要素仍会出问题」的例子。
2. **人力门槛**：给一个只有一人可用的情境，写出正确的六步准备与「不做」的理由。
3. **可听判据**：说出「抬举代替拖拽」的可听判据，并演示一次。
4. **双处观察**：说明为什么变换后要同时看旧发红处与新受力点。
5. **约束记录**：填一份约束记录，替代方式列必须有内容。
6. **交接复述**：两人一组完成一次转运交接，接收方须复述三项以上【教学设定，每组 3 分钟】。

## 六、代价与边界

以「翻身即检查」为标准，第一重代价是**单次耗时上升**。一次翻身从「翻过去垫好」变成「翻、看、垫、记」，夜班高频执行时负担明显。可行的减负是把观察做成一句话：发红部位＋范围变化，其余项目勾选。

第二重代价是**人力门槛会让一些搬动延后**。等第二个人到场的几分钟里，对象可能一直保持在不舒适的体位。这个延后是规则的成本，替代方案（一人硬搬）的成本由对象的皮肤与管路承担。两者不能等价交换。

第三重代价是**约束的严格化会带来冲突**。家属可能要求「绑住别让他拔管」，而规则要求先试替代方式。此时的沟通要点不是解释制度，而是把风险说清：约束本身带来皮肤、循环、情绪三方面的代价，替代方式（陪护、环境调整、管路管理）能解决一部分问题。说清代价，比援引规定更容易被接受。

三处不写：不写翻身角度、支撑物高度、承重与搬动参数；不写约束器具的规格与型号；不写压力性损伤的发生率与分期比例。引用只到「教材·第 9 章·9.1.2」级。
