# 无菌技术的难点不是不碰，是承认自己已经碰了 · 提示词

## 用途

给「无菌技术的难点不是不碰，是承认自己已经碰了」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「无菌区是一个可以说出位置的空间 → 操作前的评估与核对 → 步骤与判据 → 时限、责任人与记录字段」这条链。

本章为教学材料，不构成医学意见、诊断或护理指导；具体操作以现行规范与所在机构制度为准。
