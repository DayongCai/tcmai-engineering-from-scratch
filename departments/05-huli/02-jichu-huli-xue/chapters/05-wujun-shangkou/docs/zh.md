# 第 5 章 · 无菌技术的难点不是不碰，是承认自己已经碰了

> **MOTTO:** 「清净则肉腠闭拒，虽有大风苛毒，弗之能害」——《黄帝内经·素问·生气通天论》
>
> **PROBLEM:** 本章底本 20,107 汉字、260 个实质段；段内含「核对」的 56 段（22.5%）、含「标识」的 42 段（15.2%）、含「污染」的 39 段（15.8%），而含「评估」的只有 3 段（1.2%）。全章的重量在「不碰」，而真正决定成败的那一步——判断「已经碰了」并当场弃用——分量最轻。

**双根因定位:** 环境逼迫——无菌操作的现场是一个随时被打破的空间：门开、人走过、衣袖扫过、敷料渗湿，这些都在动作之外发生，无法靠手法避免；知识积累——教材把无菌技术写成「原则＋操作类别＋污染识别」三层，原则部分写得极清楚（无菌区、无菌物品、有效期），污染识别却只能靠列举，而列举永远列不全现场会出现的形态。

## 一、无菌区是一个可以说出位置的空间

无菌区不是「干净的地方」，是一个由三条边界围出来的空间。三条边界都可以用一句话描述，也都可以当场检查。

| 边界 | 内容 | 检查方式 |
|---|---|---|
| 上界 | 视线上方与腰部以上：低于视线、低于腰面的部分不视为无菌 | 弯腰、低头、蹲下取物后，重新判断 |
| 干界 | 干燥为无菌，潮湿即失守：渗湿、溅湿、凝水都算 | 看到水迹即按污染处理，不论来源 |
| 内界 | 无菌物品只在自己范围内接触彼此；跨越即污染 | 手臂跨越无菌区、器械越界，均记为污染 |

第三条边界最容易被低估。跨越之所以是污染，不是因为碰到了什么，而是因为**跨越的手臂经过了无菌区的上方**——上方的空气、衣袖、掉落物都随之进入。所以这条边界的判据不是「有没有接触」，是「有没有经过」。

由此得到本章第一条判断：**无菌状态的维持，靠的是不断重新判断，而不是一次判断**。铺好盘的那一刻是合格的，之后每一次移动、每一次转身、每一滴水，都可能把它变成不合格。技术上没有「一次做好」，只有「持续成立」。

## 二、操作前的评估与核对

| 项 | 要确认的 | 判据 |
|---|---|---|
| 环境 | 操作台面是否清洁干燥、有无人员走动、门窗与气流 | 台面干燥可见，无人在操作区穿行 |
| 物品 | 包装是否完整、有无潮湿与破损、有效期是否可读 | 包装完好、干燥、标识清晰可读 |
| 器具 | 是否在位、是否可用、是否与本操作匹配 | 状态可查，不凭印象 |
| 人员 | 手卫生是否完成、有无饰物、衣袖是否束起 | 手卫生有时刻，饰物已去除 |
| 对象 | 伤口或置管部位的情况、有无渗液、有无疼痛、是否已告知 | 能说出部位现状与本次目的 |
| 退路 | 若污染发生，备用物品是否已在手边 | 备用物品在位，不需离开现场去取 |

第六项是本章唯一一条「为失败做准备」的要求。无菌操作里最常见的两难是：污染发生时，唯一的备用物品在储物间。此时的选择只有两个——中断操作去取，或者带着已污染的状态继续。把备用物品放在手边，是为了让第一次选择成为可能。

## 三、步骤与判据

以下为课堂训练口径【教学设定】，时长按教学需要设定，具体参数以现行规范与机构制度为准。

| 段 | 时间档 | 做什么 | 通过判据 |
|---|---|---|---|
| 准备 | 3 分钟 | 环境、物品、手卫生、对象告知、备用物品到位 | 六项各自说出「已确认」的依据 |
| 铺盘 | 2 分钟 | 打开外层、内层不触、盘面朝上放置 | 手未触及内层；盘面干燥 |
| 取物 | 按件计 | 持器取物，不跨越、不回头、不吹气 | 每取一件即回位，无跨越动作 |
| 使用 | 按操作计 | 按顺序使用，用后不回盘、不重复取用 | 用过的器械不再进入无菌区 |
| 疑污染判断 | 即时 | 出现渗湿、跨越、掉落、疑触，立即停手判断 | 判断结论说出，不默认为「没事」 |
| 处置 | 即时 | 确认污染即弃用、更换、重铺 | 弃用有记录，不静默替换 |
| 收尾 | 2 分钟 | 分类处置、手卫生、记录与交代 | 记录含污染事件（若有）与处理 |

第五段是整章的核心。它的判据只有一句：**判断的结论要说出声**。心里过一遍「应该没事」和说出来「刚才袖子扫过盘边，按污染处理」，是两种完全不同的动作；前者没有留下任何可被纠正的机会，后者可以让在场的人一起判断。

第六段「处置」有一条硬边界：**弃用不需要请示**。疑污染即弃用，成本是浪费一份物品，收益是避免一次感染风险。这条边界之所以要写死，是因为在成本与风险的权衡里，个人几乎总会偏向成本，而这一次偏向的代价由对象承担。

与弃用配套的是一个常被省略的动作：**把污染当作一次报告，而不是一次悄悄重来**。悄悄重来的问题是它不产生任何可学习的信息——同一间病房、同一批物品、同一套摆放，下一个人会遇到同一个问题。报告不必上升为事件，但至少要让当班的人知道「这里的摆放让人够不到，所以总是跨越」。改动一个位置，比训练十次「别跨越」有效。

## 四、时限、责任人与记录字段

| 事项 | 时限口径 | 责任人 | 记录字段 |
|---|---|---|---|
| 手卫生 | 接触前、操作中、脱手套后各一次 | 执行者 | 时点是否完成，不用「已洗手」概括 |
| 无菌盘/无菌区 | 一经铺设在规定时限内使用，超时重铺 | 执行者 | 铺设时刻、使用时刻 |
| 疑污染判断 | 发现即停，当次判断 | 执行者，必要时请第二人复核 | 现象、判断、处置 |
| 伤口观察 | 每次换药记录四个维度 | 执行者 | 见下表 |
| 报告 | 出现感染相关表现即报 | 发现者 | 表现、时刻、接收人 |

| 记录列 | 内容 |
|---|---|
| 时刻 | 开始与结束的时:分 |
| 部位 | 位置、范围、与上次对比 |
| 伤口四维 | 大小与深度（描述性，不量化到毫米）、渗液性质与量级、周围皮肤、气味 |
| 无菌过程 | 有无污染事件、是否重铺、备用物品是否动用 |
| 对象反应 | 疼痛、主诉、体位耐受 |
| 报告与交代 | 报告对象、接收人、下次换药安排 |

第三列的写法要专门训练。「渗液少」是量级，「渗液约两毫升」是伪精度——敷料上的液体无法称量，写下数字等于制造了不存在的准确。合规的写法是「渗液浸透外层敷料约三分之一，较上次减少」。这种写法既可比，又不假装精确。

## 五、失效模式与考核项

无菌区的污染有四种形态，前兆各不相同：

- **跨越**：手臂或器械从无菌区上方经过。前兆是身体重心前倾、手臂伸展。拦截：取物前先移步，不伸手够。
- **潮湿**：盘面或敷料出现水迹，来源可能是渗液、凝水、溅水。前兆是盘边有水痕。拦截：看到水迹即按污染处理。
- **掉落与疑触**：物品落地、衣袖扫过、呼吸正对盘面。前兆是「好像碰到了」这句自我怀疑。拦截：怀疑即弃用。
- **气流与人员**：门开、人员穿行、扇风。前兆是操作区有人经过。拦截：操作前关门、限人。

伤口侧的失效另有三类：

- **只看伤口不看周围**：记录只写伤口本身，周围皮肤的红、肿、温度、边界全部缺位。前兆是记录里没有「周围」二字。拦截：四维列为必填。
- **敷料渗湿不换**：认为「还没到换药时间」。前兆是敷料外层已湿而记录写「干燥」。拦截：渗湿作为独立换药指征。
- **标识缺位**：换药后未标日期与时间。前兆是敷料上无标记。拦截：标识与记录同时完成。

### 考核项

1. **边界判断**：给出三个动作（弯腰取物、手臂跨越、衣袖扫过），各判断是否构成污染并说明依据。
2. **疑污染处置**：模拟一次「疑似碰到」，要求当场说出判断与处置，不得默认为无事【教学设定，10 秒内表态】。
3. **铺盘复核**：完成一次铺盘，由第二人指出三处边界是否成立。
4. **记录改写**：把「渗液约两毫升」改写成合规表述，并说明原写法的两处问题。
5. **伤口四维**：给一段伤口描述，补齐四维中缺失的两项。
6. **备用物品**：说出为什么备用物品必须在手边，并举一个「不在手边」的具体后果。

## 六、代价与边界

以「疑污染即弃用」为硬规则，第一重代价是**浪费**。教学与实操中，被弃用的物品里有相当一部分其实并未污染。这个浪费是这套规则的成本，不能通过「提高判断准确率」来消除——判断准确率的提升永远赶不上漏判的代价。

第二重代价是**它会打断操作的连贯性**。重铺一次意味着从头再来，对象要多等，带教者要多看一遍。这个打断在观感上像「不熟练」，实际是熟练的标志之一。带教者要能区分这两种「慢」。

第三重代价是**「说出来」需要承担**。承认自己碰了，等于当场承认一次失误。在等级明显、节奏紧张的现场，说这句话的成本很高。本章的处理是把这句话制度化：不是「我错了」，是「按规则这是污染，需要重铺」——把个人失误转化为流程动作，降低说出口的门槛。
