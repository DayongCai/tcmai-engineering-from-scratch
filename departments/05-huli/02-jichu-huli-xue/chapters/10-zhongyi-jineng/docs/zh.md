# 第 10 章 · 中医护理技术的门槛不在手法，在什么情况下不做

> **MOTTO:** 「医之治病也，一病而治各不同，皆愈，何也」——《黄帝内经·素问·异法方宜论》
>
> **PROBLEM:** 本章底本 19,959 汉字、112 个实质段；段内含「报告」的 82 段（75.7%）、含「记录」的 77 段（71.7%）、含「告知」的 23 段（23.3%），而含「评估」的只有 3 段（3.2%）。报告与记录写得极厚，而决定「这次能不能做」的评估不到三十分之一。

**双根因定位:** 环境逼迫——中医护理技术多属「温和、可重复、对象感受直接」的一类，正因为看起来风险低，适应证与禁忌的判断容易被跳过，手法被当作全部；知识积累——教材以技术类别为纲（灸、罐、推拿、贴敷、给药配合、情志），每类各自写适用与观察，读者记住的是「有哪些做法」，不容易形成「同一套判据适用于全部类别」的认识。

**本章引证口径：** 教材·第 11 章·11.1.2（适用依据与要求类别）；段数与关键词命中按 `standards/jichu-huli/units.json` 现算（实质段＝以换行分隔、≥35 汉字者；占比＝命中段汉字／实质段汉字合计）；带【教学设定】的分钟档为课堂演练口径；全章不写穴位定位的度量、灸量、留罐时长、药物与剂量，不写疗效比例，不引页码。

**引用粒度：** 只到「第 11 章·第 1 节」（11.1.2）级，不引页码、不引版次；节号为底本单元编号的中段，目号为该节内的条目序号。

## 一、适用范围：五类技术，一套判据

本章讨论的技术分为五类，类别不同，判据相同。

| 类别 | 做法类别 | 共同的风险来源 |
|---|---|---|
| 灸法类 | 以温热作用于体表 | 温度与时长不可见，损伤滞后出现 |
| 罐法类 | 以负压作用于体表 | 负压与局部条件不匹配，出现水泡或破损 |
| 推拿类 | 以手法作用于体表与关节 | 力度不可见，对象难以准确表达 |
| 贴敷类 | 以药物或介质作用于局部皮肤 | 局部反应与皮肤条件相关 |
| 给药与情志配合 | 按依据完成给药配合、按安排实施情志护理 | 核对与告知环节被简化 |

五类共有的风险来源只有一个词：**不可见**。温度、负压、力度、反应，都不像注射那样有即时可见的反馈，它们的后果往往在操作结束后一段时间才显现。所以判据不能建立在「当时看着没事」上，只能建立在「做之前判断、做之中观察、出现什么就停」上。

由此得到本章第一条判断：**中医护理技术的安全不靠手法精细，靠终止条件明确**。手法再轻，没有终止条件，也会在对象忍痛不说的情形下做过头。

五类技术还有一条共同的起点：**技术类别不由护理人员选定**。选哪一类、做哪个部位、做几次，属专业判断；护理承担的是按依据执行、按判据观察、按条件终止。这条边界在中医护理里格外重要，因为技术本身看起来「可按经验调整」——觉得温度不够就再热一点，觉得没感觉就多做一会儿。每一次「再一点」都是越过依据的调整，而越界的那一次，往往就是出现局部损伤的那一次。

## 二、操作前的评估与告知

| 项 | 要确认的 | 判据 |
|---|---|---|
| 依据 | 技术类别由谁确定、依据是否写明部位与次数 | 依据可查，不由护理自行选定 |
| 局部条件 | 皮肤完整性、有无破损、瘢痕、皮疹、感觉减退 | 部位当场看过，不凭交班描述 |
| 全身条件 | 有无发热、饥饿、疲劳、饮酒、情绪激动 | 这五项各问一句，不合并成「还好吧」 |
| 耐受与表达 | 能否清楚表达不适、能否保持体位 | 能说出「不舒服会怎么告诉你」 |
| 告知与同意 | 做什么、可能的感觉、可能的局部反应、可随时叫停 | 对象能复述「可以随时叫停」 |
| 环境 | 温度、遮挡、通风、有无易燃物（灸法） | 遮挡先于暴露，易燃物已移除 |

第三项的五问是有针对性的：饥饿、疲劳、情绪激动、饮酒、发热，这五种状态下对象对刺激的反应会明显不同，而它们都无法从病历上读到，只能当面问。把五问合成一句「今天还好吧」，得到的回答永远是「还好」。

第五项「告知」的关键句是「可能的局部反应」。灸法与罐法之后出现局部颜色改变属常见，出现水泡则属于需要报告的情形。事先说清「什么算正常、什么要叫我们」，对象才不会把该报的情况当作正常忍耐过去。

## 三、步骤与判据

以下为课堂训练口径【教学设定】，时长与次数按教学需要设定，具体操作参数以现行规范与机构制度为准。

| 段 | 时间档 | 做什么 | 通过判据 |
|---|---|---|---|
| 定位 | 1 分钟 | 按依据确认部位，暴露范围最小化 | 部位与依据一致，暴露有遮挡 |
| 试做 | 首次必做 | 先小范围、短时间试做，观察反应 | 有明确的「观察多久、看什么」 |
| 实施 | 按类别计 | 按依据完成，全程不离人 | 全程在场，不中途离开 |
| 观察 | 持续 | 局部颜色、皮肤完整性、对象主诉、全身反应 | 每项都有一次记录，不合并 |
| 终止 | 出现即停 | 疼痛、灼热难忍、头晕心慌、皮肤异常 | 停手不需要请示 |
| 收尾 | 2 分钟 | 清洁、遮挡复原、交代注意事项、记录 | 交代含「出现什么要报告」 |

第五段是整章的核心。**终止不需要请示**，理由与无菌技术的弃用相同：请示要时间，而损伤在时间里发生。停手之后要做的三件事是：说明为什么停、处理局部、报告。

第二段「试做」在教材里几乎不写，但它是五类技术唯一共有的降险动作。首次在一小块皮肤上做，看反应再决定是否继续，代价是多花几分钟，收益是把「不可见的反应」提前变成可见。

## 四、时限、责任人与记录字段

| 事项 | 时限口径 | 责任人 | 记录字段 |
|---|---|---|---|
| 评估 | 操作前完成，五问逐项 | 执行者 | 五问结果、局部条件 |
| 试做观察 | 首次必做，观察时长按【教学设定】 | 执行者 | 试做部位、时长、反应 |
| 全程在场 | 实施期间不离人 | 执行者 | 是否有中断、中断原因 |
| 终止与报告 | 出现即停，停后即报 | 执行者 | 终止原因、局部表现、接收人 |
| 记录 | 操作结束当次完成 | 执行者 | 见下表 |
| 随访观察 | 按【教学设定】在之后的时间点复核局部 | 执行者或接班人 | 复核时刻、局部变化 |

| 记录列 | 内容 |
|---|---|
| 时刻 | 开始、试做、结束、复核 |
| 依据 | 技术类别、部位、次数，与依据是否一致 |
| 局部 | 部位、颜色、完整性、范围、与试做时比较 |
| 对象感受 | 温热感、疼痛、头晕心慌、耐受 |
| 终止 | 是否终止、原因、停后处理 |
| 交代 | 交代了哪几件事、对象能否复述 |
| 报告 | 报告对象、接收人、接收时刻 |

第一列里的「复核」时刻是本章特有的一列。灸法与罐法的局部反应有延迟，操作结束时看起来正常的部位，过后可能出现水泡或颜色加深。写下复核时刻，等于给自己定了一个必须回来看的时间点。

复核安排在什么时点，取决于技术的类别，而不是取决于班次方便。凡是作用时间较长、局部反应可能延迟的类别，复核要落在本次班内；跨班的情形，复核时点必须写进交接，由接班人完成。只写「已交代接班观察」而不写具体时点，等于把复核变成了一个愿望。

## 五、失效模式与考核项

- **跳过局部条件**：在破损、瘢痕、感觉减退的部位施术。前兆是记录里局部一栏只有「皮肤完好」四个字。拦截：部位当场看，写明具体位置与状态。
- **对象忍痛不说**：把「能忍住」当作「可以继续」。前兆是对象沉默、身体僵硬、回避目光。拦截：主动问「现在是几成不适」，并说明「说了我们就停」。
- **终止条件缺位**：只有「注意观察」，没有「出现什么就停」。前兆是记录里没有终止项。拦截：终止条件在操作前说出来。
- **越界确定技术类别**：护理人员自行决定用哪一类技术、做几次。前兆是记录里依据栏空白或写「按经验」。拦截：依据不明即回报。
- **疗效承诺**：向对象承诺「做完就好」。前兆是交代里出现效果判断。拦截：交代只讲过程与注意，不讲结果。
- **复核缺失**：操作结束即认为结束，不回看局部。前兆是记录无复核时刻。拦截：复核时刻前置写入。

### 考核项

1. **五问演练**：对一名模拟对象完成五问，不得合并提问【教学设定，2 分钟内】。
2. **局部条件**：给三个部位描述（破损、瘢痕、感觉减退），各判断能否施术并说明依据。
3. **终止条件**：为灸法与罐法各写出三条终止条件。
4. **试做设计**：设计一次试做，须含部位、时长、观察项。
5. **记录填写**：按七列填一份记录，复核时刻必须有具体时间。
6. **边界判断**：给四个情境，判断哪些属于护理可执行、哪些必须回报。

## 六、代价与边界

以「终止条件明确」为核心，第一重代价是**操作经常被打断**。对象的感受是主观的，一旦说了不适就必须停，于是不少操作只能做到一半。这在带教与排班上会被视为「效率低」。本章的立场是：做到一半而停下来，比做完而出现局部损伤更接近专业。

第二重代价是**试做会增加单次时长**。首次操作多花几分钟，在门诊与病房的高峰时段都是成本。可行的处理是把试做纳入流程的固定段位，让它成为「本来就要做的一步」，而不是额外的谨慎。

第三重代价是**不做疗效承诺会让对象失望**。很多人来做这类技术，期待的是一个明确的承诺。把话说成「这次做的是这个过程，感觉会有变化，但不保证什么」，在沟通上更费力。这个费力是必须承担的，因为承诺一旦给出，后续所有判断都会被期待牵着走。
