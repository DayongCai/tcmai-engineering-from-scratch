# 核对能防给错人，防不了不该给 · 提示词

## 用途

给「核对能防给错人，防不了不该给」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「核对的三个时点 → 给药前的评估：五个问题 → 三类配合的步骤与判据 → 时限、责任人与记录字段」这条链。

## 提示词

```
我在学《基础护理学》第 4 章「核对能防给错人，防不了不该给」，本章 5 节 / 2,960 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 本章引证口径
   - 第二个时点是唯一由对象参与的核对
   - 核对的成品不是「确认无误」，是「确认这一次与前一次不同在哪里」
   - 途径不自行更改
   - 「确认」必须落在可观察的动作上
   - 巡视看的是局部，不只是滴速
4. 指出本章写到类别就止步、不再给参数的地方。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，不构成医学意见、诊断或护理指导；具体操作以现行规范与所在机构制度为准。
