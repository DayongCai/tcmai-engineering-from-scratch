# 第 6 章 · 给氧是最容易被「顺手打开」的一项技术

> **MOTTO:** 「气者，人之根本也，根绝则茎叶枯矣」——《难经·八难》
>
> **PROBLEM:** 本章底本 19,025 汉字、113 个实质段；段内含「报告」的 70 段（62.6%）、含「观察」的 56 段（50.7%），含「核对」的只有 12 段（13.3%）、含「时限」的 0 段。报告写得最厚，而报告之前那道「给的是谁、用的是哪一种方式、装置对不对」的核对最薄。

**双根因定位:** 环境逼迫——给氧的装置轻便、启动快、对象主观感受改善明显，这三点使它成为最容易被自行启动、也最容易被自行加大的技术；知识积累——教材把给氧写成「方式类别—适用要求—观察与记录」三段，方式类别按器具形态划分，读者容易记住「有哪些方式」，却不容易形成「方式由谁定、变更由谁定」的责任观念。

**本章引证口径：** 教材·第 7 章·7.1.2（给氧前准备与核对要求）；段数与关键词命中按 `standards/jichu-huli/units.json` 现算（实质段＝以换行分隔、≥35 汉字者；占比＝命中段汉字／实质段汉字合计）；带【教学设定】的分钟档与秒档为课堂演练口径；全章不写氧流量、氧浓度、吸痰负压与时间等操作参数，不写药物与剂量，不引页码。

**引用粒度：** 只到「第 7 章·第 1 节」（7.1.2）级，不引页码、不引版次；节号为底本单元编号的中段，目号为该节内的条目序号。

## 一、判断在动手之前：三件事不属于护理决定

给氧看起来是一个动作，实际上是三个判断的落地。三个判断都不由护理人员作出，护理承担的是配合、观察与报告。

| 判断 | 归属 | 护理承担的部分 |
|---|---|---|
| 需不需要 | 具备资质的人员 | 提出观察依据：呼吸费力、口唇颜色、说话断续、活动耐受下降 |
| 用哪一种方式 | 具备资质的人员 | 确认装置与对象匹配、确认对象能耐受、确认管路不影响其他照护 |
| 用多久、何时停 | 具备资质的人员 | 观察效果与不适、按安排复查、报告变化 |

三条归属写清楚，才能理解本章的核心矛盾：**护理能做的最重要的一件事，是把「需不需要」这个问题尽早提出来**。等对象出现明显变化再报，判断的空间已经变小；在变化之初报出「说话变短了、走两步就停」，判断才有余地。

由此得到本章第一条判断：给氧的质量不在「给上了」，在「给的过程中有人一直在看，且看得有可比较的依据」。给上之后无人观察的氧疗，是本章要防的第一种形态。

## 二、操作前的评估与核对

| 项 | 要确认的 | 判据 |
|---|---|---|
| 对象 | 身份、本次与前次的差别、有无既往不耐受 | 能说出前次方式与当时反应 |
| 依据 | 依据来自何处、是否仍然有效、方式是否写明 | 依据可查，方式不含糊 |
| 装置 | 是否完好、管路有无破损与打折、接口是否匹配 | 通气检查通过，接口对接无松动 |
| 湿化 | 湿化部分是否在位、状态是否合适 | 在位且状态可查，不凭印象 |
| 环境 | 有无明火与易燃物、通风情况、装置放置是否稳妥 | 明火与易燃物已移开，装置不悬空 |
| 退路 | 备用装置、断电或断气时的替代方案 | 替代方案已在场，不需离场取用 |

第五项在教材里写得很少，但它是本章唯一涉及现场安全的项：氧不是惰性气体。装置附近的明火、易燃物、油性物质，都属于必须在开机之前处理掉的东西，而不是「注意一下」。

第二项「依据是否写明方式」需要单独强调。依据只写「给氧」而不写方式时，护理人员面对的是一个必须自行补全的空白；补全得对不对无法核实。正确做法是回报确认，而不是按经验选一个最常用的。

第三项与第六项要合起来看。装置状态决定这次给氧能不能开始，退路决定开始之后被打断时能不能接上。两者都属「准备」，但检查的时点不同：装置在接触对象之前检查，退路在启动之前确认。教材把装置检查写得较细，退路几乎不写，而断气、断电、装置故障在病房与转运途中都会发生，没有替代方案的氧疗，等于把对象的状态交给一台没人检查过的设备。

## 三、步骤与判据

以下为课堂训练口径【教学设定】，时长按教学需要设定，操作参数以现行规范与机构制度为准。

| 段 | 时间档 | 做什么 | 通过判据 |
|---|---|---|---|
| 核对 | 60 秒 | 对象、依据、方式、装置四项一次核完 | 四项各自说出依据，不跳项 |
| 检查 | 60 秒 | 装置通气、管路完好、湿化在位、环境安全 | 通气有声有形，管路无打折 |
| 安置 | 2 分钟 | 体位、装置佩戴、松紧与贴合、管路走向 | 对象能耐受，管路不牵拉、不压身 |
| 交代 | 1 分钟 | 说明「这是做什么、可能的不适、不要自行调整、如何叫人」 | 对象能复述「不自己动」这一条 |
| 观察 | 按【教学设定】间隔 | 呼吸状态、口唇颜色、说话能力、装置位置、局部皮肤 | 每次观察与上次成对比较 |
| 记录 | 即时 | 方式、开始时刻、观察结果、交代内容 | 记录能独立复现本次操作 |

第四段「交代」在教材里也薄，但它是防止自行调整的唯一防线。交代要说到三件事：这是做什么的、可能有什么不适、**不要自己动装置，需要调整就叫我们**。第三句必须单独说，因为它对应的是最常见的一种失效——对象觉得不够、自己把装置挪了位置或改了大小。

第五段「观察」的判据是「成对比较」。单次描述「呼吸尚平稳」没有信息量；「与 30 分钟前相比，说话从整句变成半句」才有信息量。观察的产物是一句可比的话，不是一个形容词。

## 四、时限、责任人与记录字段

| 事项 | 时限口径 | 责任人 | 记录字段 |
|---|---|---|---|
| 开始前核对 | 接触前完成 | 执行者 | 四项核对结果、依据来源 |
| 启动后首次观察 | 启动后按【教学设定】的短间隔内完成 | 执行者 | 时刻、呼吸、颜色、耐受 |
| 常规观察 | 按【教学设定】间隔，变更后加密 | 当班执行者 | 每次时刻与成对比较结果 |
| 装置与湿化检查 | 每班至少一次，交接时复核 | 当班执行者 | 检查时刻、状态、更换情况 |
| 异常报告 | 变化即报，先口头后书面 | 发现者 | 变化内容、基线、接收人 |
| 停止或变更 | 仅按依据执行，执行后复核 | 执行者 | 依据来源、变更时刻、复核人 |

| 记录列 | 内容 |
|---|---|
| 方式与装置 | 方式类别、装置类别、佩戴部位 |
| 时刻 | 开始、每次观察、结束 |
| 观察结果 | 呼吸状态、口唇颜色、说话能力、活动耐受 |
| 装置状态 | 位置、松紧、管路走向、湿化状态 |
| 局部情况 | 佩戴部位皮肤、有无压迫与潮湿 |
| 交代 | 交代了哪三件事、对象能否复述 |
| 报告 | 报告对象、接收人、接收时刻 |

第五列的「局部情况」是长时间给氧最容易被忽略的一列。耳后、鼻翼、面颊的压迫与潮湿不会立刻表现，等到对象主诉疼痛时，皮肤已经受损。这一列要写具体位置，不写「皮肤完好」。

## 五、失效模式与考核项

- **自行启动与自行调整**：对象或家属觉得不够，自行改动装置或位置。前兆是装置位置与记录不符。拦截：交代第三句必须说到并复述。
- **管路接错与打折**：多路装置并存时接错接口，或管路压在身下打折叠。前兆是对象无改善而装置「在运行」。拦截：启动前通气检查，安置后复核管路走向。
- **湿化缺位**：湿化部分未在位或状态不合适，长时间后出现黏膜干燥与不适。前兆是对象主诉咽干而记录正常。拦截：湿化状态列为班次检查项。
- **吸引操作超时**：气道清理时负压与时间不加控制，出现缺氧表现。前兆是操作中出现心率变化或颜色改变。拦截：操作前给氧、操作中观察、超时即停（具体参数依规范）。
- **固定移位**：人工气道的固定松脱或位置改变。前兆是固定带松、刻度变化、对象发声异常。拦截：固定与刻度每班核对并记录。
- **观察无基线**：每次记录都是形容词，无法比较。前兆是连续记录内容雷同。拦截：成对比较为必填。

### 考核项

1. **归属判断**：给三个情境，判断哪些属于护理可决定、哪些必须回报，并说明依据。
2. **四项核对**：60 秒内完成对象、依据、方式、装置四项核对并各说出依据【教学设定】。
3. **环境安全**：指出启动前必须处理的三类环境因素，并说明不处理的后果。
4. **交代三句**：完整说出交代的三件事，并设计一句能让对象复述的提问。
5. **成对比较**：把「呼吸尚平稳」改写成含比较的观察记录。
6. **失效拦截**：针对「对象自行调整装置」，写出两条可执行的拦截措施。

## 六、代价与边界

把「观察有基线」作为给氧的核心要求，第一重代价是**记录变重**。按间隔观察并成对比较，比一次描述「尚平稳」要多花时间，夜班尤为明显。减负的方向是把比较做成表格：上一行留空，只填变化。

第二重代价是**「不自行调整」的交代会削弱对象的参与感**。有些对象习惯自己处理，被告知「不要动」会觉得被当成不能自理的人。处理办法是把理由说出来——「这个大小是有人算过的，您动了我们就看不出变化了」——把限制解释成合作，而不是命令。

第三重代价是**回报确认会拉长启动时间**。依据不写明方式时，回报意味着等待，而对象正在费力呼吸。这个等待是必要的，因为按经验补全的那一次，可能把一次可纠正的偏差变成一次已经发生的错误。折中方式不是省略回报，而是把「方式未写明」做成依据开具环节的拦截项，让等待不发生。

三处不写：不写氧流量、氧浓度、吸痰负压、吸引时间等操作参数；不写装置品牌、规格与型号；不写任何疗效比例与并发症发生率。引用只到「教材·第 7 章·7.1.2」级。
