# 第 9 章 · 复苏配合的关键是知道自己的位置，不是抢着做

> **MOTTO:** 「凡事豫则立，不豫则废」——《礼记·中庸》
>
> **PROBLEM:** 本章底本 19,949 汉字、109 个实质段；段内含「报告」的 62 段（60.3%）、含「观察」的 46 段（45.5%）、含「核对」的 20 段（19.4%），而含「评估」的只有 1 段（1.0%）、含「时限」的 2 段（1.2%）。全章写得最厚的是「报什么」，最薄的是「谁在什么时候做什么」。

**双根因定位:** 环境逼迫——急救现场的人数是变量，三人与八人的分工完全不同，而教材只能写「分工类别」，无法写死人数，于是分工在实战中往往靠默契临时形成；知识积累——急救内容天然以「技术动作」为骨架书写（识别、启动、配合、转介），动作写得越细，越容易让人以为关键是「会做」，而不是「在位」。

**本章引证口径：** 教材·第 10 章·10.1.2（意识与呼吸的观察要点类别）；段数与关键词命中按 `standards/jichu-huli/units.json` 现算（实质段＝以换行分隔、≥35 汉字者；占比＝命中段汉字／实质段汉字合计）；带【教学设定】的秒档与分工表为课堂演练口径；全章不写按压深度、频率、通气量等操作参数，不写药物、剂量与疗程，不引页码。

**引用粒度：** 只到「第 10 章·第 1 节」（10.1.2）级，不引页码、不引版次；节号为底本单元编号的中段，目号为该节内的条目序号。

## 一、现场三件事的先后：安全、呼救、评估

急救现场最常见的错误不是技术不对，是顺序不对：先上手，再喊人，最后才看环境。正确的顺序与之相反。

| 序 | 做什么 | 判据 | 顺序颠倒的后果 |
|---|---|---|---|
| 1 | 看现场安全 | 有明确结论：可进入／不可进入 | 施救者成为第二个伤员，处置中断 |
| 2 | 呼救与启动流程 | 呼叫内容含地点、人数、状态；有人去取装置 | 人来了但装置没来，或装置来了但人不够 |
| 3 | 评估意识与呼吸 | 有可复述的观察结论，不是「好像没反应」 | 判断被印象取代，启动与否失去依据 |

第三项的判据要落到「可复述」上：叫名字有无回应、有无睁眼、有无正常呼吸的动作、有无濒死样呼吸。这四项说出来，别人才可能接续判断；说「不行了」，别人只能自己再看一遍。

由此得到本章第一条判断：**急救的质量由「第一个人做了什么、第二个人接手时知道什么」决定，而不是由某一个人的技术上限决定**。交接时说得清，比做得漂亮更重要。

四项观察里最难的一项是「有无正常呼吸」。濒死样呼吸在旁观者眼里像是「还在喘气」，于是判断被推向「有呼吸、不用启动」；而它实际是呼吸停止前的一种无效动作。教材把它写在观察要点里，但纸面描述很难替代现场辨认，所以训练必须做成情景辨认：给一段喘息样呼吸的录像或模拟，让人在几秒内说出「这是无效呼吸」。只在文字上记住这一点的人，在现场多半会把它当成有呼吸。

现场还必须处理一件与医学无关的事：**家属的位置**。家属在场会带来两个后果，一是空间被压缩，二是施救者被反复询问而中断动作。处理方式不是驱赶，是给一个明确的安置动作：指定一人负责把家属带到某处并说明「我们在做什么、什么时候会有人来告诉你」。这件事落在场控位，不落在操作者身上。

## 二、操作前的准备与核对

急救没有准备时间，准备发生在平时。这一节写的是「平时要准备好什么，以及现场怎么快速确认它还成立」。

| 项 | 平时 | 现场快速确认 |
|---|---|---|
| 装置与物品 | 按班次检查并留痕，位置固定、可取即用 | 一眼看到位置，取用不需翻找 |
| 装置状态 | 班次标记、备用状态、电量或气源 | 标记在有效范围内，开机有反应 |
| 人员与分工 | 排班时明确谁负责按压、谁负责通气、谁记录 | 到场即报出自己承担的角色 |
| 通讯 | 呼叫方式与替代方式 | 呼叫有回应，不是单向喊话 |
| 环境 | 通道、照明、空间 | 能容纳所需人数，不互相阻挡 |
| 退路 | 转运路线与接手点 | 路线畅通，接手方已知会 |

第二项「装置状态」的现场确认只做一件事：**看标记、开机、看反应**。不做全面自检，因为时间不允许；但「标记过期」与「开机无反应」这两个状态，必须在十秒内被发现。平时检查的价值就在这十秒。

## 三、分工与站位

以下为课堂演练口径【教学设定】，实际人数与分工按现场条件与机构制度确定。

| 位置 | 职责 | 不做的事 |
|---|---|---|
| 气道位 | 体位、气道开放、通气配合 | 不离开位置去取物 |
| 循环位 | 按压配合、交替、节奏维持 | 不因记录中断按压 |
| 记录位 | 时刻、动作、用药与反应、报告 | 不参与操作，除非人手不足且交接清楚 |
| 联络位 | 呼叫、引导、与接手方对接 | 不进入操作区 |
| 场控位 | 环境、人员进出、家属安置 | 不判断病情 |

五人分工在真实场景里常常凑不齐。人手不足时的合并顺序是固定的：**记录位最后合并**，因为一旦没人记时刻，后面所有复盘都失去依据；最先合并的是场控位与联络位。这一条要写死，否则人手一紧，最先被牺牲的总是记录。

## 四、时限、责任人与记录字段

| 事项 | 时限口径 | 责任人 | 记录字段 |
|---|---|---|---|
| 现场安全判断 | 接触前完成，秒档【教学设定】 | 第一个到场者 | 结论与依据 |
| 呼救 | 判断后立即 | 第一个到场者 | 呼叫时刻、呼救内容、回应 |
| 启动流程 | 判断成立即启动 | 具备资质的人员决定，护理配合 | 启动时刻、决定人 |
| 按压交替 | 按【教学设定】的轮换节奏，交替不中断 | 循环位 | 轮换时刻、每次中断时长 |
| 记录 | 与操作同步，不事后追记 | 记录位 | 见下表 |
| 交接 | 转运前完成，接收方复述 | 记录位与联络位 | 已做、未做、反应、去向 |

| 记录列 | 内容 |
|---|---|
| 时刻 | 发现、呼救、启动、每次轮换、转运，各写时:分 |
| 现场 | 场所、是否安全、在场人数、家属位置 |
| 判断 | 意识与呼吸的观察结论（四项） |
| 已做动作 | 体位、通气、按压、除颤配合（按实际） |
| 反应 | 每次动作后的可观察变化 |
| 报告 | 报告对象、接收人、指示内容 |
| 去向 | 转运时刻、接收方、交接复述要点 |

第一列是整张表的地基。急救记录的时刻必须来自当场，不能事后推算；事后推算的时刻会呈现「整齐的间隔」，而真实操作一定有停顿与重叠。记录位要做的不是写完整句子，是记时刻与动作。

记录位的另一个职责是**替全组记住「还没做什么」**。抢救过程中，所有人都盯着正在做的事，没有人盯缺的那一件：通气做了多久、轮换到第几次、报告给谁而谁还没回话。这些缺口只有记录位看得见，因为它手里有一张按时间排列的清单。所以记录位不是「写字的人」，是「提醒缺口的人」，这一条要在分工时说明白，否则记录位只会低头写字。

## 五、失效模式与考核项

- **分工重叠**：两人同时做同一件事，另一件事没人做。前兆是「我以为你在做」。拦截：到场即报角色。
- **判断越界**：护理人员自行作出「无需启动」或「停止」的决定。前兆是记录里没有决定人。拦截：决定与执行分开记，决定人必须具名。
- **装置未处于备用状态**：标记过期、电量不足、耗材缺件。前兆是取用时才发现。拦截：班次检查留痕，标记可视。
- **按压被记录打断**：记录位人手不足，按压者兼记录，节奏中断。前兆是中断次数无记录。拦截：记录位最后合并。
- **时刻失真**：事后统一补记，所有时刻成整齐间隔。前兆是记录里没有轮换时刻。拦截：轮换即记。
- **交接只说「都做了」**：接收方无法判断哪些没做。前兆是交接无复述。拦截：已做与未做分别陈述，接收方复述。缺项的复述比完整陈述更有价值，它给出下一步的起点。

### 考核项

1. **顺序判断**：给一段现场描述，排出安全、呼救、评估的先后并说明颠倒的后果。
2. **四项观察**：说出意识与呼吸观察的四项内容，并演示一次可复述的表述。
3. **角色报位**：进入模拟现场，十秒内报出自己承担的角色与位置【教学设定】。
4. **合并顺序**：说出人手不足时的合并顺序，并解释为什么记录位最后合并。
5. **交接复述**：完成一次交接，接收方须复述已做、未做、反应三项。
6. **记录填写**：按七列填一份演练记录，时刻列不得出现整齐等间隔。

## 六、代价与边界

以「角色与时刻」为核心，第一重代价是**它要求平时投入**。班次检查、标记可视、角色预排，这些工作在无事发生时看起来是负担，且很难证明它避免了多少问题。质量管理上只能用「检查留痕的完整率」这类可核的指标来维持，而不能靠事故的缺席来证明。

第二重代价是**固定分工在真实场景里会失灵**。现场人数、空间、家属情绪都不受控，五人分工经常只能凑到三人。本章的处理是把合并顺序写死，而不是把分工写成弹性描述——弹性描述在紧张时等于没有描述。

第三重代价是**判断权与执行权分离会让人不适**。有能力判断的人被要求「只配合」，在抢救现场会感到被束缚。这条边界的理由不是能力，是责任：谁作出决定，谁承担决定的后果；把决定权模糊掉，出问题时无人可问。

三处不写：不写按压深度、频率、通气比例、除颤能量等操作参数；不写急救药物、剂量与给药途径；不写存活率与任何结局比例。引用只到「教材·第 10 章·10.1.2」级。
