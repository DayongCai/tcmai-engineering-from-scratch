## 一、学科定位

基础护理学（Fundamental Nursing）是护理系的核心学科，聚焦「中医护理特色技术 + 现代护理全科能力」中的一个完整知识域。

## 二、中医 → AI 桥梁

```text
护理操作→标准作业流程 / 生命体征→异常检测
```

基础护理学 里的每一个传统概念，都被翻译成一个可计算、可验证的工程对象：
中医概念给出**语义与约束**，AI/工程方法给出**表示与算法**。两者必须能互相回指，
否则这个章节就还没有写完。

**口径**

1. **三辨＝操作规范／安全与风险／观察与评价**，实测 **4017 / 892 / 5917**，比值 **6.6×**——**「安全与风险」只有「观察与评价」的 1/6.6**。这与母本性质一致：教材讲「怎么做、怎么判断」，风险留给第 9、14 章集中处理；
2. **四位面取操作环节 3.3×**（准备 2133 / 实施 1560 / 观察处置 5221 / 记录评价 3470）；
3. **技能大类 15.5× 未取**：注射给药只有 31 次、气道氧疗 95 次，「吸氧」全书 0 次——**不是分类轴不成立，是母本压根不按技能逐项写**，取它会把 14 章写成大半空白；**发生场所 229.0× 未取**：门诊急诊只有 1 次，229× 是极端缺项。
