# 第 3 章 · 技术安全的关口不在禁忌表上，在开做前那三个必须核对的动作里

> **MOTTO:** 「战战兢兢，如临深渊，如履薄冰」——《诗经·小雅·小旻》
>
> **PROBLEM:** 本章底本 134 段、17,169 汉字，含「观察」79 段、「报告」67 段、「记录」56 段、「皮肤」20 段、「体位」18 段，含「趋势」0 段、「分级」0 段。教材把每项技术的「适用情形、禁忌、观察、报告」都写到了，却没有一处写「做之前核对哪几件事、做之中出现什么就停」。禁忌被写成了知识，没被写成动作。

**双根因定位:** 环境逼迫——内科的技术多为高频、短时、床边完成，一次操作只占几分钟，核对的时间占比看上去很不划算，于是最容易被压缩掉的恰好是核对；知识积累——教材以「技术」为单位逐项展开，每项都自带评估与禁忌，这种写法保证了单看一项很完整，却让人很难发现所有技术共用同一套闸门，于是每换一项技术就要重新记一遍禁忌，记不住就跳过。

**本章引证口径：** 教材·第 4 章·4.1.2（课程第 3 章）。段数、汉字数与各词段落数由 `standards/neike-huli/units.json` 现算。带【教学设定】标记的分钟档、档位与比例是课堂演练口径，不是机构实测值；本章不写任何操作参数（流量、浓度、速度、负压、规格）的具体数值，此类内容一律以现行规范与机构制度为准。

## 一、六要素是六道闸，不是六个步骤

教材把技术的实施要求归为六要素：评估、告知、禁忌、观察、报告、记录。这六项常被读成流水线上的六道工序，做完一项划一项。这个读法有两个后果：一是把「禁忌」放在第三步，等于开做之后才想禁忌；二是把「记录」放在最后，等于事情结束了才补文字。

按闸门读，六要素的关系是三个「开做前必须过」和三个「做之中与做之后的出口」：

| 要素 | 性质 | 未过闸时的动作 |
|---|---|---|
| 评估 | 开做前 | 条件不具备则改期或改方式，不硬做 |
| 告知 | 开做前 | 未获同意不得实施，不得事后追认 |
| 禁忌核对 | 开做前 | 命中任一条即停，报请具备资质的人员 |
| 观察 | 做之中 | 出现设定信号即停，先停再报 |
| 报告 | 做之中或之后 | 无回执视为未完成 |
| 记录 | 做之后 | 未记录视为未发生 |

第三行要特别说明。禁忌写成清单时是一条条知识，写成动作时只有一句话：**这项技术对这个人，今天能不能做**。同一个问题问三遍都不嫌多——入院时问一遍（有无相关病史）、开做前问一遍（此刻的状态允不允许）、操作中留意一遍（身体的反应是不是在说不）。三遍问的是同一件事，答的可能不一样，因为人是在变的。

第七项是教材没单列但必须补的：**替代路径**。禁忌命中时，「不能做」不是终点，终点是「那做什么」。护士至少要能说出两类替代：改方式（改变体位、改时机、改途径）与改由他人（转给能做的岗位或场所）。只会说「不能做」的人，在病房里会被绕过去——家属会自己想办法，而家属想的办法没有记录。

## 二、这一类技术的共同结构：前、中、后各查什么

教材按技术逐项讲，本章抽出一套共用结构。凡内科床边技术，前中后各查三件事，一共九件：

| 阶段 | 查什么 | 判据形态 |
|---|---|---|
| 前 | 人：双重身份标识 + 本人/代理人的同意 | 两项都对上才开做 |
| 前 | 事：项目、部位、方式与本次目的一致 | 有一项不符即停 |
| 前 | 物：用物完好、包装完整、设备已自检 | 未自检的读数标「未校验」 |
| 中 | 耐受：面色、出汗、呼吸、主诉、体位能否维持 | 任一变化即降级或停 |
| 中 | 位置：管路、接头、体位、暴露范围 | 移位即复位后重新核对 |
| 中 | 沟通：告知进程、回应不适、允许暂停 | 患者喊停即停 |
| 后 | 局部：穿刺点、受压处、黏膜、皮肤颜色与完整性 | 与操作前同一部位对比 |
| 后 | 全身：意识、活动、进食、排泄的即刻反应 | 与操作前状态对比 |
| 后 | 交接：已做、待观察、下次时点 | 接收方复述确认 |

这张表的价值在于它可以跨技术使用。氧疗、雾化、排痰、体位引流、静脉治疗、标本采集、皮肤护理，九件都能套。学生不必为每项技术重背一套流程，只需记住九件，再填每项技术的特有项。

「物」这一行经常被省。「设备已自检」听上去像设备科的事，但读数被谁采信，责任就在谁身上。一台未校验的设备给出的数字，会被写进记录、被用来做判断、被下一个人当成基线——**错误的基线比没有基线更糟**，因为它会被继承。

「中」阶段的三行其实是一件事：耐受性。教材写「观察面色、出汗、呼吸与不适表达」，本章把它收成一个可执行的判断：**患者能不能维持这个姿势、能不能说完一句话**。两个「能不能」都不行了，就是不能耐受，先停。

## 三、判据分档与「叫停权」【教学设定】

分档在这里只有一个用途：决定「停不停」和「停多久再试」。

| 档 | 判据（任一成立） | 动作 | 再评估 |
|---|---|---|---|
| 甲 可继续 | 耐受良好，局部与全身无新变化 | 按计划完成，结束后记录 | 结束后一次 |
| 乙 减量或改法 | 轻度不适但可缓解：体位难维持、局部酸胀、短时气促 | 调整方式或缩短单次时长，不追求做完 | 5 分钟内 |
| 丙 暂停 | 明显不适、局部渗血肿胀、气道分泌物增多难排出 | 立即停止，安置舒适体位，报告 | 15 分钟内 |
| 丁 终止并升级 | 意识改变、呼吸形态改变、面色口唇改变、剧痛 | 终止操作，就地处置，呼叫 | 连续至交接 |

丁档的四条判据都不需要测量设备，全靠看。这一点很重要：**最危险的信号往往出现在最不需要仪器的地方**。等到设备报警才停，已经晚了一步。

「叫停权」要单独写一句：停止操作不需要任何人批准，也不需要先说服谁。这不是给护士额外的权力，是承认一个事实——只有站在床边的人能在几秒内看到变化，而批准要花几分钟。停止之后必须报告，报告不等于请示，报的是「我停了，因为什么，请来看」。

同理，恢复操作需要重新过闸。停了十分钟又接着做，前面那三道闸要重过一遍，因为人和状态都变了。「刚才核对过了」这句话在恢复时不成立。

## 四、记录字段、交接与失效模式

技术类记录比观察类记录多三栏，加起来仍是七栏：

| 栏 | 内容 | 特别要求 |
|---|---|---|
| 时刻 | 开始、暂停/终止、结束三个时刻 | 终止必须写终止时刻 |
| 核对 | 身份、项目、部位、同意四项各核过 | 缺一项写「未核」，不写「已核」 |
| 参数外的事项 | 方式、体位、时长档、用物 | 不写具体数值，写档位与方式 |
| 耐受 | 过程中的反应与患者原话 | 患者说「难受」要引原话 |
| 局部所见 | 与操作前同一部位对比 | 渗血、肿胀、发红、疼痛 |
| 报告与回执 | 报给谁、几点、答复 | 终止情形必写 |
| 交接 | 已做、待观察、下次时点 | 接收方复述 |

「缺一项写未核，不写已核」这一条看着较真，实际是防伪。核对栏最常见的造假形态不是打叉，是全部打勾而实际只核了一项——记录本身成了掩盖。留下「未核」的选项，人才敢如实填。

失效模式五种：

- **把「做过」当「做对」**。流程走完、签字结束，中途的耐受变化没记。拦截：记录必须有「耐受」栏且不得写「无不适」了事。
- **禁忌只背不查**。能背出禁忌清单，开做前不问这个人今天的状态。拦截：开做前三问做成一句话口述（有没有、此刻行不行、上次有没有反应）。
- **双人核对变单人**。忙时自己念两遍就算双人。拦截：核对栏写第二人身份标识，不写「双人核对」四个字。
- **设备未自检即采信**。读数进了记录，基线从此带上误差。拦截：未自检的读数标「未校验」，不得作为基线。
- **告知做成签字**。同意书递过去、指一下、签完开始。拦截：让患者复述一次将要发生什么，复述不出则重新告知。

考核项六条：

1. 就一项指定技术，口述九件核对，指出哪三件最常被省。
2. 给一个禁忌命中的情形，说出两类替代路径各是什么。
3. 判断四个情境各属甲乙丙丁哪档，说出动作与再评估时点。
4. 写出一次终止记录，七栏齐全，含终止时刻与原话。
5. 说明为什么「恢复操作要重新过闸」，举一个不这么做的后果。
6. 抽查一份技术记录，指出哪一栏无法复核，并说明它会如何影响下一次判断。

## 五、代价与边界

第一层代价是**速度**。九个核对项、三个时刻、四栏新增记录，一项床边技术的时间会明显变长，而内科病房的技术量本来就大。这个代价不能靠「提高效率」消化，只能靠取舍：**高频低风险的技术可以把九件压缩成五件（人、事、物、耐受、局部），低频高风险的一件都不能省**。教材不分层，本章必须分层，否则规范会因为太重而被整体绕过——被绕过的规范比没有规范更危险，因为它给了人「我们是有制度的」的错觉。

第二层代价是**叫停权带来的关系成本**。停了操作、报了问题，如果复查发现没事，一线会承受「你太大惊小怪」的压力。这种压力是真实存在的，也正是失效模式里最隐蔽的一种——不是不会停，是不敢停。对抗它的办法不是鼓励勇气，是把标准写死：丁档四条判据命中就停，事后判断对错不影响当时该不该停。**判据命中即停，这一条不因结果而追认对错。**

三处不写：不写流量、浓度、速度、负压、规格等任何参数数值，参数随设备、人群与机构而变，写死即成误导；不写技术操作的详细手法（角度、深度、时长），手法须现场示教与考核，文字替代不了；不写什么情形必须用哪项技术，那是处置决定，由具备资质的人员作出。

本章与第 1、2 章的关系：第 1 章给分档与时限，第 2 章给评估与记录，本章把两者压进几分钟的操作窗口里。第 4 章起进入具体系统，每一章的技术细节都要回到本章的九件核对上。
