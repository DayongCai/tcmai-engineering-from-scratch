# 第 15 章 · 护理文书的效力，取决于它写的是事实还是结论

> **MOTTO:** 「必审问其所始病，与今之所方病，而后各切循其脉」——《素问·三部九候论》
>
> **PROBLEM:** 同一段病情，有两种写法。「患者诉腹痛，已处理，观察中」——时间没有、位置没有、做了什么没有、报告了谁没有；「十四时二十分诉右下腹痛、持续、拒按，十四时二十五分报告值班医师，嘱禁食、密切观察」——每一句都可核。前者占了记录本的篇幅，却在出事时一句也用不上。本章用 6 项要素、5 类不可写与 3 类留痕问题，把记录从「交差」改造成「证据」。
>
> **双根因定位:** 环境逼迫（记录被安排在班末集中补写，写的时候人不在床边，只剩记忆；模板又预填了「无特殊」这类默认值，点一下就算写完）+ 知识积累（文书被教成格式要求，没被教成「事实与结论的区分」，学生知道该写「客观、真实、及时、完整」，说不出什么算事实、什么算结论）

**取材说明：** 本章无参考电子件，不引页码、不引版次、不给剂量与疗程。所写为护理文书与信息管理通例；具体表单、留痕规则与保存要求以现行规范、机构制度与信息系统设定为准。

## 一、记录有三重身份，写作标准由它决定

护理文书同时是三种东西：**临床依据**（下一班靠它接手）、**法律证据**（纠纷时要经得起审阅）、**质量数据**（科室靠它看趋势）。三种身份对写法提出同一个要求：**写的必须是可被第三人复核的事实。**

「可复核」有明确内涵：换一个人来看这条记录，他能知道**什么时候、看到了什么、依据什么做了判断、做了什么、病人怎么反应、谁签的字**。缺任何一项，这条记录就只在写字的人脑子里成立。

由此得出写作的第一原则：**事实与结论分开。** 事实是所见——「皮肤湿冷、脉率增快、血压较前下降」；结论是推断——「休克早期」。前者必须写，后者可以不写，写的时候要标明是谁的判断。护理文书里最危险的句子，是把推断写成事实的样子：「患者出现休克」——如果实际只观察到湿冷与脉快，这句话就是替医师下了诊断。

## 二、写什么：六项要素与中医用语的引用规则

| 要素 | 写什么 | 不合格的样子 |
|---|---|---|
| 时点 | 观察、措施、报告的时点，精确到分 | 只写班次；写「上午」 |
| 所见 | 可观察、可测量的客观内容，含测量条件 | 「精神可」「一般情况尚可」 |
| 判断依据 | 支撑措施的那几条所见，按因果排列 | 直接写措施，不写为什么 |
| 措施 | 做了什么、方式、部位、持续时间 | 「已处理」「已护理」 |
| 反应 | 措施后的即时反应与复评结果 | 只记措施，不记反应 |
| 签名 | 执行人、核对人，实名 | 代签、漏签、打印名 |

中医内容进入记录，有两条引用规则。

**第一，所见用描述，不用证型。** 「舌淡胖、苔白腻、畏寒喜热饮」是所见，可以写；「脾阳虚」是证候，写的时候必须写成「医师辨为脾阳虚」。这条规则的作用不是谦让，是**让责任可追溯**：读者能分辨哪部分是护士看到的，哪部分是医师判断的。

**第二，术语按院内统一词表。** 「水肿」「浮肿」「水气」不能混用；「纳差」「食欲减退」「不思饮食」不能在同一份病历里各写一个。术语不统一，趋势就不可统计，交接就会失真。首次出现异名同义处，标注对应关系一次即可。

四诊内容的客观化，是中医护理文书最容易走形的部分，要单独立三条。

**舌象写条件与所见。** 「舌红苔黄腻」缺条件，读者不知道是晨起未食还是刚喝完热水。「晨起未食，舌红，苔黄腻，舌体不胖」才是可核的记录。条件与所见缺一，这一栏只能当装饰。

**脉象只写可计数的部分。** 脉率、节律是否规整、有无间歇、强弱是否一致，是护理可以记的；浮沉迟数弦滑属于医师的脉诊判断，护理记录里出现即为越界。若医师已在病程中记录脉象，护理可引用并标注来源。

**证候名一律引述。** 「医师辨为肝郁脾虚」是合格写法；「患者肝郁脾虚」是越界。差别不在措辞，在于出了问题时能不能说清这条结论是谁下的。

## 三、五类不能写

| 类别 | 例子 | 问题 |
|---|---|---|
| 结论词 | 「出现休克」「有感染」「病情危重」 | 代替医师下诊断，且无事实支撑 |
| 模糊词 | 「尚可」「一般」「较多」「约」 | 不可比、不可核，等于没写 |
| 复制粘贴 | 连续几日「无特殊不适」「神志清楚」 | 实际未观察，记录失真且留痕可查 |
| 事后补记 | 班末统一补写上午的观察 | 时点失真，一旦有争议即失效 |
| 代签与漏签 | 同事代签、实习记录无带教签名 | 责任主体不明，法律上无效 |

第三类在这几年变得更容易发生，因为电子病历的模板与「引用上一条」功能让复制只需一次点击。对抗办法不是靠自觉，是靠**字段设计**：把「与上一班对比」做成必填项，把「无特殊」从默认选项里删掉，把中医所见做成结构化选项而不是自由文本。模板改一次，能拦住成千上万次复制。

第四类的现实原因要承认：忙。可行的折中是**先记时点与关键所见**（写在纸上或移动端），班末补全叙述，但时点必须真实。事后补记与「先记后补全」的区别就在时点是否真实，这一点必须严守。

## 四、电子病历与信息安全

电子化带来三类新问题，各有对应的做法。

**模板陷阱。** 结构化模板提高效率，也会造成「填满但空洞」：所有项目都有值，读起来却看不出这个病人和别人有什么不同。做法是保留自由文本栏写「本例特点」，并要求护士在交班时口头说明这一栏。

**修改留痕。** 电子记录的每一次修改都有痕迹，这是优点也是约束：修改必须走规范流程并说明理由，不能直接覆盖；纸质记录修改要划线签名并注明时间，不得涂改或使用修正液。任何「先删掉再重写」的做法都会留下可疑痕迹。

**隐私与最小必要。** 病人的健康信息属敏感个人信息。三条落地要求：**只访问与本次照护相关的内容**（不因好奇查看他人病历）；**对外提供时脱敏**（去标识化不等于匿名化，两者不可混称）；**传递走指定渠道**（不通过私人社交软件发送含身份信息的病历照片）。交接班、教学讨论、案例分享都要遵守这三条，教学用的案例一律合成或彻底去标识。

**书面语言还要考虑读的人。** 一份记录至少有三个读者：下一班护士、医师、若干年后可能的审阅者。写给下一班，要写趋势与重点；写给医师，要写所见与变化；写给审阅者，要写清时点与依据。三者并不冲突——能同时满足三者的写法，只有一种：**具体、按时点、分事实与结论。** 含混的写法对三者的价值都是零。

## 五、三种失效与后果

| 失效 | 典型表现 | 后果 | 拦截动作 |
|---|---|---|---|
| 记录与观察脱节 | 班末凭记忆补写，时点笼统 | 争议时无法自证；趋势判断失真 | 关键所见当场记时点，班末只补叙述 |
| 用结论代替事实 | 「病情稳定」「已好转」 | 恶化无据可查；责任边界模糊 | 每条结论后必须跟三条所见，否则删掉结论 |
| 术语与口径不一 | 同一症状多种叫法；中医证型自造词 | 数据不可汇总；交接误解 | 按院内词表写；证型一律标「医师辨为」 |

第一种失效的后果常被低估。护理记录在纠纷里的作用不是「证明我做得对」，而是「证明我看到了什么、做了什么、什么时候做的」。时点一旦笼统，这三件事同时失效。

记录的另一半是交接。交班记录不是病历摘要，而是**下一班的行动提示**，四句话成篇：「昨夜怎样」「今晨怎样」「往哪个方向走」「请接班重点看什么」。前三句是事实与趋势，第四句是判断与请求。中医要素放在第二、三句：舌象与痰或二便的变化方向、口渴与寒热的变化。

写成「生命体征平稳，继续观察」的交接，等于把六个要素砍到剩一句模糊词。病人已经又过了八小时，而下一班手上没有任何基线——这是交班环节最常见、也最难追责的损失。

还有一层常被忽略：**记录是可以被用来学习的材料，前提是它写得足够具体。** 具体到「十四时二十分诉右下腹痛、拒按、报告后禁食」的记录，三个月后回看仍能复盘判断是否正确；「腹痛，已处理」的记录，除了证明有人签过字，什么也教不了。护理经验的积累，很大一部分依赖记录的具体程度。

## 六、代价与边界：四条限制与考核项

1. **不给具体表单与字段规范**：各机构表单不同，本章给的是要素与判据，落地以本机构表单为准。
2. **不替代法律意见**：涉及举证、鉴定、责任认定的问题，以法律程序与机构规定为准。
3. **不鼓励「写得漂亮」**：文书的目的是可核，不是好看。为了通顺而删掉不利所见，是伪造。
4. **信息化规则随系统变化**：留痕、权限、脱敏的具体操作以信息系统设定与信息部门规定为准。

| 考核项 | 合格标准 |
|---|---|
| 要素补齐 | 能把「已处理，观察中」补写成含六要素的记录 |
| 事实与结论 | 能在一段记录中逐句标出事实与结论，并改写结论句 |
| 五类禁写 | 能识别五类不可写并说明各自的问题 |
| 留痕操作 | 能说明纸质与电子记录修改的规范做法 |
| 隐私边界 | 能说出最小必要、脱敏与传递渠道三条要求的具体做法 |
