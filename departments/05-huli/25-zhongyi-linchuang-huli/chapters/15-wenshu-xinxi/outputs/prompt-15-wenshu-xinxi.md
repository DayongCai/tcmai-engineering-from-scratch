# 护理文书的效力，取决于它写的是事实还是结论 · 提示词

## 用途

给「护理文书的效力，取决于它写的是事实还是结论」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「记录有三重身份，写作标准由它决定 → 写什么：六项要素与中医用语的引用规则 → 五类不能写 → 电子病历与信息安全」这条链。

## 提示词

```
我在学《中医临床护理学》第 15 章「护理文书的效力，取决于它写的是事实还是结论」，本章 5 节 / 2,903 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - （下一班靠它接手）、
   - （纠纷时要经得起审阅）、
   - （科室靠它看趋势）。三种身份对写法提出同一个要求
   - 什么时候、看到了什么、依据什么做了判断、做了什么、病人怎么反应、谁签的字
   - 事实与结论分开
   - 第一，所见用描述，不用证型
4. 本章自陈的边界（不得越过）：
   - **不给具体表单与字段规范**：各机构表单不同，本章给的是要素与判据，落地以本机构表单为准。
   - **不替代法律意见**：涉及举证、鉴定、责任认定的问题，以法律程序与机构规定为准。
   - **不鼓励「写得漂亮」**：文书的目的是可核，不是好看。为了通顺而删掉不利所见，是伪造。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，不构成医学意见、诊断或护理指导；具体操作以现行规范与所在机构制度为准。
