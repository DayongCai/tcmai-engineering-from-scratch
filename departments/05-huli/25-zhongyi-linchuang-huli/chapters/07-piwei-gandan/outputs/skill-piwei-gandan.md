# 脾胃肝胆的护理窗口在二便与腹痛，不在胃口好坏

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 受纳（胃）—运化（脾）—疏泄（肝）
- 能定量、能复核
- 病人会主动说胃口，不会主动说大便
- 肝病病人要盯的不是肝，是脾
- 观察的先后顺序
- 痛在排便前还是后、排便后减轻还是加重、痛的位置会不会变

## 边界

- **不给饮食量化方案**：热量、蛋白、盐与水的具体量属营养与医嘱范围，护理给的是性质（温软、清淡、忌生冷油腻）与方式（少量多餐、进食后观察）。
- **不给外治参数**：灸法与按压的时长、强度、频次以规范与机构制度为准，本章只写适应证与禁忌。
- **观察不能替代检查**：黑便、黄疸、持续腹痛都需要检查确认，护理的价值是让该做的检查更早被开出。
- 本章为教学材料，不构成医学意见、诊断或护理指导。
