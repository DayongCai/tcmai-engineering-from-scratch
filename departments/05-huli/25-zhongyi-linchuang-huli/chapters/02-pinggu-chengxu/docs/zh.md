## 一、这一章的问题

评估与程序独立成章：中医的四诊要嵌进护理程序。本章走的是中医临床护理学的固定链：**辨证定位 → 施护落地 → 转归判断 → 调护与随访**。链上每一环都有它的判据：前一环答不上来，后一环就只能照着做而不知道为什么。

## 三、逐单元读

### 2.1.2 2.1.2 资料收集与来源类别

（1）说明临床护理评估在护理程序中的定位与本节学习要求。 （2）归纳望、闻、问、切四诊在护理评估中的应用类别。 （3）区分观察所见与护理判断的边界，明确涉判断内容由具备资质的医务人员作出。 （4）掌握护理资料的来源与内容类别。 （5）理解评估中沟通、家属参与与告知同意的要求类别。 （6）按敏感个人信息的要求理解护理资料的处理与留痕。 （7）能够按护理程序描述评估、辨证、计划、实施与评价之间的先后关系。 临床护理评估是护理程序的起始环节，也是后续辨证要素归纳、护理问题确定、护理计划制定与效果评价的共同基础。本节所称评估，指护理人员按照现行规范与机构制度，通过观察、询问与查阅等方式，系统获得服务对象的健康相关信息，并对信息的来源、完整性与可信度作出记录的过程。评估以全面、客观、动态为基本要求，既服务于当次照护，也服务于照护的连续性与交接环节。 中医护理评估在方法上借鉴望、闻、问、切四诊的思路，以观察与询问为主，并注意其与医学诊断的区别。望诊要点类别包括神色与精神状态的类别、形体与姿态的类别、皮肤黏膜与局部外观的类别、舌象的类别等；护理评估重在对可见表现的类别化记录与动态比较，判断标准与病证结论由具备资质的医务人员作出。闻诊要点类别包括语声、呼吸声、咳嗽声等声音类别，以及口气、体气等气味类别；护理评估以类别化描述与变化趋势记录为主，不写判断数值标准。 问诊要点类别包括寒热感受、汗出、饮食与口渴、睡眠、二便、疼痛与不适的部位与性质类别、情志状态、既往情况与用药情况类别等；护理评估重在对主观感受的如实记录，不将其直接等同于病证结论，也不据此提出处置意见。切诊要点类别包括脉象类别与按诊类别；其中部分内容属医疗行为，由具备资质的医务人员作出，护理人员不作独立判断。各类要点在评估中的应用，均以现行规范与机构制度为准。 本节所述评估方法与内容类别，均以现行规范与机构制度为准；具体评估表单、记录格式与频次由机构制度确定，本章不写判断数值标准。
