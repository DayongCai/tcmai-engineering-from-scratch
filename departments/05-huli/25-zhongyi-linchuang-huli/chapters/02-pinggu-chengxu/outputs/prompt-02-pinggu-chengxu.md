# 护理评估的价值在于把「说不清」变成可复核的记录 · 提示词

## 用途

给「护理评估的价值在于把「说不清」变成可复核的记录」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「程序不是表格，是把判断拆成可交接的段落 → 十二个床边问题：问什么，记什么 → 资料的三个层次：冲突时以谁为准 → 从资料到措施：一句可执行的转换」这条链。
