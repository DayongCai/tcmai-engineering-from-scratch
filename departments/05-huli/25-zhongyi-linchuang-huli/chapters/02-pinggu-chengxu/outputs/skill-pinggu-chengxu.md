# 护理评估的价值在于把「说不清」变成可复核的记录

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 让一个人的判断能被另一个人接手
- （每次问同样的问题，才能纵向比较）、
- （每次在相似条件下测，才能横向比较）、
- ：「你是不是觉得冷？」会得到迎合的答案，要问「加被子暖不暖」
- ：把寒热和二便并成一句「你哪儿不舒服」，得到的只会是主诉
- 冲突本身要记录

## 边界

- **十二问是筛子，不是诊断**：它筛出方向、筛出需要加密观察的人，不产出证候。凡是记录里出现护士自下的证候名称，都是越界。
- **评估的完备性与及时性冲突时，先保及时**：急症状态下不做完整十二问，先取能救命的几项（意识、呼吸、循环、出血），其余在稳定后补记，并注明「急症状态下采集」。
- **不给数值阈值**：什么算发热、什么算少尿，各家标准与人群不同，以本机构制度与临床路径为准。本章只写「同一条件、同一指标、至少两点」的方法。
- 本章为教学材料，不构成医学意见、诊断或护理指导。
