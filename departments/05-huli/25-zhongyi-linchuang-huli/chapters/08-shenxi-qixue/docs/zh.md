# 第 8 章 · 水肿与血证的护理，量的是出量，不是感觉

> **MOTTO:** 「诸有水者，腰以下肿，当利小便；腰以上肿，当发汗乃愈」——《金匮要略·水气病脉证并治》
>
> **PROBLEM:** 「肿好像消了一点」是肾病与心衰病房最常见的一句自我评价，也是最不可靠的一句：水肿的视觉变化滞后于体内水量的变化，同一位病人早晨与傍晚的脚踝可以差出一圈。可靠的只有三个数：**晨起同一条件下的体重、逐班出入量、尿量**。本章用这 3 个必测、4 处必看的水肿部位与 5 列出量记录，把「感觉」换成「账」。
>
> **双根因定位:** 环境逼迫（出入量靠病人与家属回忆，尿壶与便盆的计量在忙时被估，体重秤不在床边）+ 知识积累（水肿被当作一个症状记，没被当成一个需要逐日对账的收支问题，学生知道「阳虚水泛」，却不知道少记一次入量会让整张出入量单失真）

**取材说明：** 本章无参考电子件，不引页码、不引版次、不给剂量与疗程。所写为肾系与气血津液病证护理通例；具体参数、限水限盐与检查准备以现行规范、临床路径与所在机构制度为准。

## 一、感觉会骗人，出量不会

水肿的判断有三个不同的「时钟」。**视觉时钟最慢**：组织间隙的液体要积到一定程度才看得出凹陷，消的时候也一样滞后。**体重时钟最快**：同一天内体重变化几百克就能反映容量变化，条件是同一时间、同一衣着、同一秤。**症状时钟居中**：气短、夜间憋醒、鞋子变紧，往往比水肿明显更早。

护理的对账办法就是三件事同时做：每天固定条件下称重、逐班记出入量、每天看四处水肿。三者互相校正——体重上升而尿量不少，可能是入量超标；体重下降而水肿未退，可能是利尿起效但组织液回吸收滞后；尿量骤减而体重未变，可能是排出不畅（尿管、体位、膀胱充盈）。

这里有个常被忽略的技术点：**出入量单的失真，多半出在「入」而不是「出」。** 出量有容器、有刻度、有交接，入量却散落在饮水杯、汤碗、水果、输液、漱口、冰块里。少记一次，后面所有的判断都建立在错误的底数上。所以记录入量要具体到「喝了什么、多少」，且用带刻度的杯子，而不是「饮水约若干」。

## 二、辨证要点：水肿五看与血证四看

**水肿五看：**

| 看什么 | 具体看什么 | 提示 |
|---|---|---|
| 部位与顺序 | 眼睑、颜面、下肢、腰骶、腹部；先肿哪里、是否上行 | 先面后足多属风；先足后上多属水湿下受；卧者腰骶肿须专门翻身查看 |
| 按之凹陷 | 凹陷是否即起、有无光泽、皮肤是否紧绷发亮 | 凹陷不起多虚；紧绷发亮须防破溃与感染 |
| 尿 | 量、色（清长／短赤／浑浊）、泡沫（是否久不消散） | 泡沫久聚提示蛋白流失可能，须报告并留检 |
| 体重与入量 | 晨起同条件的体重、前一日的入量与出量 | 短期上升提示容量增加 |
| 舌与口渴 | 舌淡胖有齿痕、苔白滑；口渴与否、喜热喜冷 | 阳虚水泛者不渴或喜热饮；湿热者口渴而饮不多、苔黄腻 |

第四处部位要专门说：**卧床病人的水肿先出现在腰骶部**，不在脚踝。只查下肢的观察等于漏掉一半。翻身时按一下骶尾部，看有无凹陷与皮肤发红，这一步同时兼作压疮观察。

**血证四看：**

| 看什么 | 具体看什么 |
|---|---|
| 色 | 鲜红、暗红、紫黑、有血块；咳血是否带泡沫与痰 |
| 量 | 用可估的容器或计量物（如称重、计数），不写「较多」 |
| 伴随 | 冷汗、心慌、头晕、面色苍白、脉率增快——这些比出血量本身更能反映循环状态 |
| 部位与来源 | 鼻衄、咳血、呕血、便血、尿血、崩漏；来源不同，护理动作不同 |

血证的红线不在颜色，在**循环**。一位病人只咳出几口血，但面色苍白、出冷汗、脉率增快，比另一位咳出较多血但面色如常者更危险。所以记录血证时，「量」要与「伴随」并排写，单写量没有意义。

肾系与气血津液范围内还有两类常被漏掉的情形，观察入口要单独写清。

**淋证（排尿不适）**要问五件事：尿时痛不痛、痛在起始还是终末、尿色与有无浑浊、有无腰腹绞痛与放射、有无寒战发热。寒战发热伴腰痛是上行感染的信号，属必转；单纯尿频尿急而无发热者可在观察下护。护理要点是鼓励适量饮水（按医嘱）、不憋尿、注意会阴清洁、观察排尿后的感受变化，而不是简单地「多喝水」。

**消渴（口渴多饮多尿）**的护理有两条容易漏的观察：一是**足部**，每日看足背、足趾间、足跟有无破损、水泡、颜色改变与感觉减退，洗脚前用手试水温，不用热水袋与暖足器；二是**口渴与多尿的匹配**，口渴明显而尿量不增，或尿量骤增而饮水不足，都要报告。消渴病人的皮肤与足部损伤往往起于一次不起眼的烫伤，而愈合极慢，这正是护理能提前拦住的部分。

## 三、护理判据：容量与出血两条线

| 线 | 触发条件 | 允许做 | 不能做 |
|---|---|---|---|
| 容量—可护 | 体重稳定、尿量在基线、水肿不加重、能平卧 | 饮食与饮水指导（按医嘱）、皮肤护理、每日称重与出入量、外治（辨证后） | 自行加饮水或汤水「补一补」 |
| 容量—观察 | 体重短期上升、尿量减少、水肿上行或腰骶出现、需高枕 | 严格记录出入量、每日同条件称重、限制活动、报告 | 静脉补液自行调快；给含钠高的食物 |
| 容量—必转 | 尿量显著减少或无尿、气促不能平卧、全身水肿伴腹胀、意识改变 | 立即报告、配合处置、准备转运 | 继续观察等待；自行利尿相关操作 |
| 出血—必转 | 出血不止、呕血咯血、大量便血、崩漏量多、伴冷汗心慌面色苍白 | 制动、平卧、保暖、建立通路配合、呼叫、留取标本 | 让病人走动、自行给止血药、热敷出血部位 |

两条线可以同时触发。此时先处理出血（循环），再处理容量，因为失血的速度远快于水肿的进展。

## 四、动作与时限：把账记准的六个动作

| 动作 | 怎么做 | 关键点 |
|---|---|---|
| 称重 | 晨起、排空二便后、同一衣着、同一秤、同一位置 | 记录写明「晨起排空后」，否则不可比 |
| 出入量 | 入：饮水、汤、水果、输液、漱口；出：尿、呕吐、腹泻、引流、透析超滤 | 逐班小结，交接时对数；不写「约」 |
| 尿量观察 | 每次排尿记录量与色，看有无泡沫与浑浊；留置尿管者看通畅与尿色 | 尿量骤减先查管路与膀胱充盈，再报告 |
| 皮肤护理 | 水肿部位避免长时间受压，抬高患肢，保持清洁干燥，修剪指甲防抓破 | 水肿皮肤脆弱，禁用热水袋与热敷，防烫伤与破溃 |
| 口腔与饮食 | 少量多餐、清淡；按医嘱限盐限水；口渴明显者用含漱与小块冰缓解 | 限水期间口腔护理是缓解口渴的主要手段 |
| 外治 | 阳虚水泛可灸关元、肾俞（皮肤完整、非热证、非水肿破溃处）；血证急性期不做温热外治 | 血热妄行者忌灸；水肿部位禁针刺与留罐 |

外治在肾系有两条硬规矩：**水肿部位不做针刺、不留罐**（渗液与感染风险），**血证急性期不做任何温热外治**（助热动血）。灸法适用于阳虚水泛的稳定期，且必须避开破溃与感觉迟钝处。

**五列出量记录：**

| 列 | 写什么 |
|---|---|
| 时段 | 逐班或逐时段，起止时点 |
| 入量明细 | 种类与量（饮水、汤、水果、输液），不用「约」 |
| 出量明细 | 尿、呕吐、腹泻、引流，分别记量 |
| 体重 | 当日晨起同条件体重，注明条件 |
| 水肿与症状 | 部位、凹陷程度、能否平卧、气短 |
| 报告与签名 | 异常项报告对象与时间；执行人 |

## 五、四种失效

| 失效 | 典型表现 | 后果 | 拦截动作 |
|---|---|---|---|
| 以「肿消」为好转 | 只看脚踝，未见体重与尿量，报告「水肿减轻」 | 容量实际在增加 | 三个数并看：体重、尿量、水肿部位，缺一不结论 |
| 限水过度 | 为「消肿」自行严格限水，病人口渴难忍、舌干 | 津伤、痰黏、意识改变 | 限水严格按医嘱，口渴用含漱缓解并记录 |
| 血证只看颜色 | 记「痰中带血少许」而不记伴随与循环状态 | 大出血前兆被漏 | 色、量、伴随三项并记 |
| 灸法伤阴 | 舌红少苔、手足心热者施灸「补阳」 | 阴虚更甚，烦躁失眠 | 外治前核五项，热证与阴虚不做温性外治 |

第一种失效有个具体形态：**病人自己觉得消肿了，护士照记。** 视觉滞后是双向的——消的时候也滞后。护理的记录要以数为准，病人的感受作为症状记录另列一栏，两者不可互相替代。

## 六、代价与边界：四条限制与考核项

1. **不给限盐限水的具体量**：这类参数随病种、分期、用药与个体差异变化，属医嘱范围。护理给的是执行方法与观察指标。
2. **不给外治参数**：灸法部位、时长、频次以规范与机构制度为准。
3. **不能以单次数值判断**：体重、尿量都要看趋势，同条件、至少两点，单点不构成结论。
4. **不做透析与管路相关操作判断**：涉及透析、置管、超滤的观察与处置，按专科规范与授权执行。

| 考核项 | 合格标准 |
|---|---|
| 三个数并看 | 给出四组数据（体重、尿量、水肿、症状），能判断容量趋势并说明依据 |
| 出量记录 | 能把「饮水约一杯、尿量正常」改写成可复核的记录 |
| 四部位检查 | 能说出卧床病人水肿的首查部位，并说明为什么 |
| 血证记录 | 能写出色、量、伴随三项并说明哪一项最能反映危险 |
| 外治禁忌 | 能指出水肿部位与血证急性期各自的禁忌及理由 |
