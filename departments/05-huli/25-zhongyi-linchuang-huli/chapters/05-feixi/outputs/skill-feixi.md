# 肺系护理的第一件事不是止咳，是分清痰在哪一头、气还剩多少

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 第一，气是底线
- 第二，痰是矛盾的核心
- 第三，咳是结果，不是原因
- 看气定档，看痰定法，看咳定评价
- 「怕冷」不等于寒证
- 「痰黄」不等于纯热

## 边界

- **不给氧流量与药物参数**：氧疗的流量与方式、雾化用药、镇咳与祛痰的选择都属医嘱范围，护理只做执行、观察与记录。
- **分档不含数值阈值**：四档写的是床边可见的表现，不是血氧或呼吸频率的截断值。截断值随人群与机构标准变化，以本院制度为准。
- **外治只作辅助**：肺系外治的定位是缓解症状、配合排痰，不能替代必要的抗感染与气道管理。
- 本章为教学材料，不构成医学意见、诊断或护理指导。
