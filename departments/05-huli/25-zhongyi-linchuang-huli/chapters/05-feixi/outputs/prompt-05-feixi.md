# 肺系护理的第一件事不是止咳，是分清痰在哪一头、气还剩多少 · 提示词

## 用途

给「肺系护理的第一件事不是止咳，是分清痰在哪一头、气还剩多少」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「顺序：先气，再痰，最后才是咳 → 辨证要点：五看定寒热虚实 → 护理判据：四档气促，四档分护 → 动作与时限：从体位到排痰」这条链。
