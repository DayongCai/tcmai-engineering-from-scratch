# 第 6 章 · 心系护理的分界，在「悸」有没有伴随失代偿的信号

> **MOTTO:** 「心者，君主之官也，神明出焉」——《素问·灵兰秘典论》
>
> **PROBLEM:** 心悸是最容易被「安抚」过去的症状。病人说心慌，护士测一次脉率，八十次，规整，记一句「诉心慌，已安慰」，就算处理完了。可心系的风险恰恰藏在这三个被跳过的问题里：**能不能平卧、有没有出汗、活动耐量掉没掉。** 本章把这三个问题扩成 5 项必看、3 段发作计时与 7 列记录——脉率正常不等于节律正常，更不等于心没有失代偿。
>
> **双根因定位:** 环境逼迫（心电监护普及之后，「看一眼监护仪」替代了「问一句病人」，而监护仪不显示夜间能否平卧、不显示活动后的气短）+ 知识积累（心悸被当作一个独立症状记，没被放进「神—脉—水」三条线上，学生不知道同一个「心慌」在三条线上对应三种完全不同的处置）

**取材说明：** 本章无参考电子件，不引页码、不引版次、不给剂量与疗程。所写为心系病证护理通例；具体参数、监护条件与用药以现行规范、临床路径与所在机构制度为准。

## 一、心上的三件事：神、脉、水

心系病证的护理之所以容易漏，是因为「心慌」这一个词盖住了三条线。

**第一条是神。** 心主神明，悸、烦、失眠、健忘、晕厥前的黑矇，都是神明被扰或被养不足。这条线上的护理是安静、睡眠、情志、减少刺激。

**第二条是脉。** 胸痹心痛的落点在脉：胸闷、憋痛、放射、活动诱发、休息缓解。这条线上的护理是活动分级、诱因回避、发作计时。

**第三条是水。** 心衰的落点在水：下肢水肿、尿量减少、夜间不能平卧、活动后气短。这条线上的护理是出入量、体重、体位、水肿观察。

三条线的护理动作不该混。**神线上的病人需要安静，脉线上的病人需要制动，水线上的病人需要限量与监测。** 一位病人可能同时踩在两条线上，此时优先级固定：水（容量）最急，脉（缺血）次之，神（失调）再次。理由是容量与缺血能在数小时内改变结局，而神明失调多数可以等一个班。

这条优先级不是理论推演，是床边顺序：病人说心慌，先看能不能平卧、下肢肿不肿、尿量多少；再看有没有胸痛与诱因；最后才问睡眠与情绪。

## 二、辨证要点：五项必看

| 看什么 | 具体看什么 | 提示什么 |
|---|---|---|
| 脉率与节律 | 每分钟次数、是否规整、有无间歇、强弱是否一致；手测与监护读数对照 | 有间歇、强弱不一提示节律问题，须报告而非只记次数 |
| 胸闷与诱因 | 诱因（活动、情绪、饱食、寒冷）、性质（闷、压、刺）、放射部位、缓解方式与所需时间 | 活动诱发、休息可缓解，偏向脉线；无诱因、持续不缓，须即刻处理 |
| 平卧与夜醒 | 需要几个枕头、夜间是否憋醒、憋醒后坐起多久缓解 | 枕头越垫越高、夜间憋醒，是水线失代偿的早期信号 |
| 水肿与尿量 | 下肢、腰骶、眼睑；按之凹陷是否即起；尿量色量、夜尿次数 | 水肿上行、尿量减少，提示容量负荷增加 |
| 舌色与面色 | 舌淡紫、舌暗有瘀斑；面色苍白、晦暗、两颧潮红 | 舌紫暗提示瘀；面色苍白伴冷汗提示阳脱先兆 |

五项里，**平卧与夜醒**是最容易被漏掉也最有价值的一项。它不需要设备、不需要病人主动说，只要问一句「晚上睡觉垫几个枕头」「有没有睡着后突然憋醒」。这两个答案的变化，往往比体重和尿量早出现。

**舌象要看得有条件。** 刚喝完热水、刚吃完东西、刚刷过牙，舌色会偏红、苔会变薄。看舌要在自然光下，记录注明「晨起未食」或「食后」。心系病人的舌色紫暗是重要的瘀象，但紫暗也可能是灯光或染色食物所致，条件不写，结论就不成立。

## 三、护理判据：三段，与三条必转线

| 段 | 床边表现 | 允许做 | 不能做 |
|---|---|---|---|
| 一段：稳定 | 静息无不适或仅活动后短暂心悸，能平卧，无水肿加重，脉率节律与基线一致 | 生活起居、饮食、情志、活动指导、按班次观察 | 骤然增加活动量；自行加做温热外治 |
| 二段：活动受限 | 轻微活动即心悸气短，需高枕，下肢水肿较前加重，尿量减少 | 限制活动、半卧位、加密观察、记录出入量与体重 | 下床自由活动；热敷、灸法；饱食 |
| 三段：失代偿 | 不能平卧、端坐呼吸、夜间憋醒频繁、下肢水肿明显、尿量显著减少、烦躁 | 半卧或坐位、吸氧配合、呼叫、准备抢救与转运 | 任何外治；让病人自行如厕；等待观察 |

三条必转线，任何一条出现即即刻报告：

1. **胸痛持续不缓解**，伴大汗、面色苍白、恶心，或疼痛性质与以往不同；
2. **心悸伴黑矇、晕厥、意识改变**，或脉率与节律明显异常伴血压下降、皮肤湿冷；
3. **呼吸窘迫**：不能平卧、端坐呼吸、咳粉红色泡沫样痰、唇甲紫绀。

三条线的共同点是：**它们都不需要等设备确认。** 等到监护仪报警或检查报告出来，窗口已经过去一段。

## 四、动作与时限：发作三段计时与活动分级

心系护理最有价值的记录，是**发作的三段时间**：起始时间、持续时间、缓解时间与方式。这三段能把「心慌」变成一个可比较的事件。

| 段 | 记什么 | 为什么 |
|---|---|---|
| 起始 | 何时开始、当时在做什么、有无诱因 | 诱因决定预防措施 |
| 持续 | 持续多久、期间能否活动、有无伴随（汗、痛、气短、黑矇） | 持续时间与伴随症状决定严重程度 |
| 缓解 | 何时缓解、怎么缓解（休息、体位、用药）、缓解是否完全 | 缓解方式决定后续活动的边界 |

| 动作 | 怎么做 | 何时停 |
|---|---|---|
| 立即制动 | 发作时停止活动，取半卧或坐位，双腿下垂（水线明显者） | 缓解后逐步恢复，不骤然站立 |
| 观察与测量 | 测脉率节律、血压、呼吸，看面色、汗、唇甲 | 每次发作都测，不只测一次 |
| 吸氧配合 | 按医嘱给氧，记录方式与流量 | 不自行调高 |
| 活动分级 | 一段可室内缓行，二段以床旁活动为限，三段绝对卧床并在床上完成清洁 | 活动后观察恢复时间，恢复变慢即降级 |
| 外治 | 稳定段可做宁心安神的耳穴按压、睡前穴位按压；须非热证、皮肤完整 | 胸痛发作期、失代偿期一律不做；温热类外治慎用 |
| 饮食 | 少量多餐、避免饱食、限制浓茶咖啡、按医嘱限盐限水 | 饱食后观察胸闷与气短 |

外治在心系要格外谨慎，原因很直接：**温热的灸法会扩张外周血管、加快心率**，对已经心率偏快或容量负荷重的病人是额外负担。宁心类的外治以按压、耳穴这类无创、无热刺激的方式为主，且必须在稳定段做。

**七列记录：**

| 列 | 写什么 |
|---|---|
| 时点 | 发作起始、持续、缓解的具体时点 |
| 诱因 | 当时活动、情绪、进食、体位 |
| 客观所见 | 脉率与节律、血压、呼吸、面色、汗、唇甲、水肿部位与程度 |
| 伴随症状 | 胸痛性质与放射、气短、黑矇、恶心 |
| 措施 | 制动、体位、吸氧、外治（部位与方式） |
| 反应 | 缓解时间与是否完全缓解 |
| 报告与签名 | 报告对象与时间、执行人 |

「缓解是否完全」这一列常被简化成「已缓解」。不完全缓解是一个独立信号：疼痛减轻但仍有压迫感、心悸减轻但仍气短，都属于不完全，须继续观察并报告。

还要加一段**缓解后的观察**。发作过去不等于风险过去：缓解释放之后的一两个小时内，是再次发作与病情转折最集中的时段。这一段要看成三件事——活动耐量是否回到发作前（走同样的路会不会再发）、体位是否回到发作前（枕头数是否降回来）、出汗是否停止。三件事任何一件没回到原样，就把这一段当作未结束处理：继续限制活动、加密观察、交班时明确写出「已缓解但不完全恢复」。护理记录里只写「已缓解」，等于把最需要盯的一段删掉了。

## 五、四种失效

| 失效 | 典型表现 | 后果 | 拦截动作 |
|---|---|---|---|
| 脉率正常即放心 | 只记次数，不看节律与强弱；有间歇未记录 | 节律问题被漏 | 每次测脉搏都写「规整／不规整／有间歇」，必要时听心率并对照 |
| 把夜间憋醒当失眠 | 病人诉睡不好，记录「睡眠差」，未问憋醒与枕头数 | 心衰早期信号丢失 | 睡眠评估必问「是否憋醒」「垫几个枕头」 |
| 把胸痛当胃痛 | 上腹不适、恶心被按胃病护理，未查胸闷与诱因 | 缺血被延误 | 上腹不适伴出汗、活动诱发者，一律先按心源排查 |
| 温热外治助火 | 失代偿期做灸法「补气」，或热敷胸部 | 心率加快、耗氧增加 | 失代偿期与胸痛发作期不做任何温热外治 |

第二种失效的隐蔽性最高。夜间憋醒的病人白天可能完全正常，问「睡得好吗」得到「还行」，问「半夜有没有突然坐起来喘」才会点头。问句决定答案。

## 六、代价与边界：四条限制与考核项

1. **不给药物与参数**：强心、利尿、扩血管类用药的选择与剂量属医嘱范围；氧流量、活动强度的具体数值以医嘱与康复方案为准。
2. **分段的阈值本地化**：三段写的是床边表现，不是心功能分级的具体数值，机构标准不同，不能互相套用。
3. **护理不能替代监护**：观察再细，也不能替代必要的心电监护与检查。护理的价值是让该做检查的人更早被送去。
4. **不做预后判断**：向病人与家属说明时只讲当下观察到什么、下一步做什么，不讲「还能撑多久」这类判断。
