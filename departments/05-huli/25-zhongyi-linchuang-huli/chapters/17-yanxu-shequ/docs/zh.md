# 第 17 章 · 出院宣教不落地，等于把护理做完又退回原处

> **MOTTO:** 「圣人不治已病治未病，不治已乱治未乱」——《素问·四气调神大论》
>
> **PROBLEM:** 出院那天最常见的场景是：发一张宣教单、说一句「注意饮食、按时复查」、签个字。可出院之后决定结局的，是家里那几周由谁做饭、谁来扶、药谁管、什么时候该回医院。这些事一件都没评估过，宣教就只是纸。本章用 6 项出院评估、4 类家庭调护与 3 个随访节点，把「交接」从签字变成可执行的安排。
>
> **双根因定位:** 环境逼迫（出院办理集中在上午，护理同时要接新病人、做治疗、办手续，宣教被压缩到最后几分钟）+ 知识积累（延续护理被讲成「出院指导的内容清单」，没被讲成「照护主体从护士换成病人与家属」这件事，学生能背出饮食宜忌，说不出这个家里谁能执行）

**取材说明：** 本章无参考电子件，不引页码、不引版次、不给剂量与疗程。所写为延续护理与社区康复护理通例；具体转介流程、随访制度与康复方案以现行规范与所在机构、社区的制度为准。

## 一、出院不是终点，是照护主体的更换

住院期间，护理的主体是护士；出院之后，主体换成病人与家属，护士退到咨询与随访的位置。这个更换意味着三件事必须提前处理。

**第一，能力要交接。** 病人或家属必须会做原来护士做的事：观察什么、什么时候该来医院、药怎么吃、伤口怎么护。会不会，不靠问「听懂了吗」，靠**看他做一遍**。

**第二，条件要核实。** 家庭能不能提供照护条件：有没有人能扶、住几楼、有没有电梯、厕所在室内还是室外、有没有冰箱存药、离最近的医院多远。条件不符，方案再正确也执行不了。

**第三，通道要留下。** 出院后出了情况找谁：随访电话、社区护士、门诊时间、急诊指征。通道不明，病人只能靠忍或靠猜。

三件事都不做，宣教就变成一句「注意身体」。而「注意身体」这四个字，是护理工作在生产无效信息。

## 二、出院前评估：六项能否自护

| 项 | 评估什么 | 不合格时的处置 |
|---|---|---|
| 认知与学习能力 | 能否记住并复述要点；有无认知障碍、视力听力障碍、语言不通 | 改由主要照护者学习；提供图示或语音；安排复述核对 |
| 运动与自理 | 能否独立行走、如厕、洗澡、上下床；有无跌倒风险 | 安排辅具、改造居家环境、申请上门服务 |
| 照护者 | 有无固定照护者、其体力与时间、是否也需被照护 | 明确分工；必要时申请社区或机构支持 |
| 居住与交通 | 楼层与电梯、卫生间位置、取暖与通风、到院的距离与方式 | 调整活动方案；安排就近随访或上门 |
| 经济与保障 | 药费与耗材的承担能力、报销与救助渠道 | 提供可及的替代方案；转介社工 |
| 用药管理 | 能否分辨药物、按时服用、识别不良反应 | 使用分装盒与标识；由照护者管理；简化方案需医师决定 |

六项里，第三与第四项最容易被跳过，也最决定成败。一个独居、住六楼无电梯、卫生间在户外的老人，出院时的「适度活动、保持清洁」几乎是无法执行的指令。评估的意义不是打勾，而是**把方案改成这个家能做到的样子**。

评估结果要写进出院记录，并随转介材料一起交出去。只写在护士脑子里，社区接手时等于从零开始。

## 三、四类家庭调护：把中医的「宜忌」落到具体的家

家庭调护的四个方向，每一个都要配一句「在这个家里怎么做」。

| 方向 | 原则 | 落地成什么 |
|---|---|---|
| 饮食 | 辨证择食：虚寒者温软、忌生冷；湿热者清淡、忌肥甘酒酪；气虚者少食多餐 | 写清「能吃的三样、要避的三样、谁来做」，而不是「饮食清淡」 |
| 起居 | 顺应四时、避风寒、规律作息、适度活动 | 写清起床与睡卧时间、通风与保暖的做法、活动的地点与时长上限 |
| 情志 | 减少忧思、保持交流、家属参与 | 写清「每天谁陪、聊什么、出现什么情绪要联系谁」 |
| 导引与康复 | 八段锦、太极、呼吸训练、关节活动，量力而行、循序渐进 | 写清「做哪几式、什么时间、出现什么感觉即停」 |

第四项要格外谨慎。导引与康复在中医护理里价值明确，但**有明确的不适用情形**：心功能不稳定、骨伤未愈合、术后早期、严重骨质疏松、眩晕发作期，都不适合自行练整套功法。宣教时必须给出「只做哪几式」和「什么情况下停」，而不是「回去练练八段锦对身体好」。

同理，饮食的「宜忌」不能给成一张大表。给三样能吃的、三样要避的，家属才记得住；给二十样，等于一样也没给。

## 四、随访：三个节点与一份交接包

| 节点 | 时间口径 | 随访内容 |
|---|---|---|
| 出院后早期 | 出院后数日内 | 用药与伤口、症状变化、有无跌倒与发热、宣教要点复述 |
| 方案调整期 | 按医嘱与病情 | 康复进度、饮食与活动的执行情况、指标变化、是否需要复诊调整 |
| 长期管理 | 按慢病管理要求 | 指标趋势、并发风险筛查、生活方式维持、社区资源衔接 |

三个节点的作用不同：早期抓的是**执行偏差**（药吃错了、伤口没护好），中期抓的是**方案与实际的匹配**（练不动、吃不下），长期抓的是**趋势**（指标在往哪走）。把三个节点混成「定期复查」，等于三个作用都没了。

随访还要有**触发点清单**，教给病人与家属「出现这些情况不用等随访，直接来」：发热不退、伤口红肿渗液、出血、气促不能平卧、意识改变、跌倒后疼痛加重、剧烈腹痛、尿量明显减少。清单要短，五到八条，用家属的话写。

**交接包**是把护理交给社区或上门服务时的最小信息集，六项：

1. 诊断与当前证候（注明「医师辨为」，附主要所见）；
2. 在用的药物与给药途径（不给剂量调整建议）；
3. 观察要点与触发点（本院随访口径）；
4. 已实施的护理措施与反应；
5. 自理能力与照护者情况、居家条件；
6. 随访安排与联系人。

没有这份包，社区接手只能重新评估一遍，而重新评估的这段时间正是风险最高的时段。

社区康复护理的落点还有两处值得单独说。

**一是家庭病床与上门服务。** 上门护理与病房护理最大的差别是**没有旁人可叫**：一个人、一个家庭、一个不确定的环境。所以上门前要先定三件事——这一趟做什么、出现什么情况就撤、撤了找谁。撤的条件要写在服务记录上，比如「血压明显异常、新发意识改变、伤口大量渗液、家属无法配合」，一律停止操作、报告、转诊。上门护理不带「再试试」的余地。

**二是节气与季节调护。** 中医的「因时调护」在延续护理里很实用：冬季注意保暖与晨练时点、夏季注意暑湿与饮食卫生、季节交替注意旧病复发。这类指导要落到「哪个月做什么、什么天气不出门」，而不是「顺应四时」四个字。对慢病病人，节气的意义在于**给出一个可预期的提醒时点**——每年同一个时候，该复查的复查、该调整的调整。

## 五、四种失效

| 失效 | 典型表现 | 后果 | 拦截动作 |
|---|---|---|---|
| 宣教单替代教会 | 发单子、签字、说「有问题打电话」 | 回家执行错误，很快再入院 | 让病人或家属演示一遍关键动作，演示不出即重教 |
| 复述不核对 | 问「听懂了吗」，对方点头 | 误解被隐藏 | 请对方用自己的话说一遍，或演示一遍 |
| 随访无触发点 | 只说「按时复查」 | 出现危险信号仍在家等 | 给五到八条触发点清单，用家属的话写 |
| 导引不分病情 | 一律推荐练整套功法 | 加重病情或造成损伤 | 按病情限定式数与时长，给出停止条件 |

第一种失效最普遍，因为它看起来完成了工作。判据很简单：**宣教完成的标志不是签了字，是对方做对了一遍。**

四种失效里，前两种与沟通有关，后两种与方案有关。还有一个不属于失效、但常被忽略的问题：**宣教的时间点。** 出院当天上午是信息量最饱和、注意力最分散的时候，这时候讲饮食与用药，效果最差。可行的调整是把宣教拆成两次：住院中期讲「回家后大致怎么做」，出院前一天讲「具体这三件事」，出院当天只做核对与补充。拆分之后，每一次的信息量都在可吸收的范围内。

同样值得拆分的是**宣教的接收者**。病人与家属听到的往往不是同一件事：病人关心「什么时候能好」，家属关心「怎么照顾」。把两者分开讲，各自的问题才问得出来；混在一起讲，通常只回答了其中一个人的问题。

## 六、代价与边界：四条限制与考核项

1. **不给康复参数与运动量**：功法式数、时长、强度按康复方案与个体情况，本章只写限定与停止条件。
2. **不给用药调整建议**：随访中发现的用药问题一律转医师与药师，护理不作调整。
3. **不替代社区与家庭的责任**：延续护理是协作，护理不能替代家庭照护与社区服务。
4. **随访不承诺结果**：向病人说明随访的目的与内容，不承诺「按时随访就不会复发」。
