# 产后出血不是"看出血"，是"算出变化" · 提示词

## 用途

给「产后出血不是"看出血"，是"算出变化"」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「四个原因，四种床边可辨的差异 → 量的三种算法，与各自的偏差 → 判据与危险信号：不是"出了多少"，是"变化有多快" → 动作与时限：五个动作的顺序」这条链。

## 提示词

```
我在学《妇产科护理学》第 7 章「产后出血不是"看出血"，是"算出变化"」，本章 5 节 / 2,872 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 该同时看哪几样东西
   - 只写看得见的
   - 必须在记录里写明用的是哪一种
   - 同样多的血，在半小时内出来与在四小时里出来，是两件完全不同的事
   - 烦躁与心率增快
   - 把这三类主诉与出血量放在同一格里看
4. 本章自陈的边界（不得越过）：
   - **本章不给出血量的判定界值与输血指征。**界值随分娩方式、基础状况与机构规范变化，输血与用药由具备资质的人员决定；本章只给"量＋速率＋趋势"的记录判据。
   - **不给药物与液体方案。**宫缩药物的选择、剂量、给药途径，液体与血制品的种类与速度，均不在护理决定范围内，本章不写、不建议。
   - **四分类不是诊断工具。**它的用途是提示"同时看哪几样"，不是让护理在床边判定原因；原因判定由具备资质的人员作出。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```
