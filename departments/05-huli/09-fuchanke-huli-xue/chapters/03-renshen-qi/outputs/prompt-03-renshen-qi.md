# 孕期随访筛的不是"有没有病"，而是"谁在什么时候必须被叫回来" · 提示词

## 用途

给「孕期随访筛的不是"有没有病"，而是"谁在什么时候必须被叫回来"」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三段，三种判据问题 → 评估项怎么落成记录 → 五类必须"不等预约"的情形 → 胎动：最容易被三种方式读错的自监项」这条链。

## 提示词

```
我在学《妇产科护理学》第 3 章「孕期随访筛的不是"有没有病"，而是"谁在什么时候必须被叫回来"」，本章 5 节 / 2,934 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 每一段问的问题不一样
   - 评估项是每次都要看的，信号是不管是不是预约日都要立刻处理的
   - 同一项目要反复测很多次
   - 方法不写，数字就没有意义
   - 危险信号被排除之后
   - 体位改变时量是否明显增多
4. 本章自陈的边界（不得越过）：
   - **本章不给孕周之外的时间数字。**产检间隔、筛查时点、住院指征，都由现行规范与机构制度确定；本章只保留孕周分段这一层公共定义，其余不给数。
   - **不给"胎动多少次算正常"。**不同规范给的界值不同，且与计数方法绑定；给出一个数而不绑定方法，是这类宣教最常见的错误来源。
   - **"不等预约"不等于"直接住院"。**五类信号要求的是即刻评估，不是即刻住院；评估后可继续门诊观察，也可收治，由具备资质的人员决定。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```
