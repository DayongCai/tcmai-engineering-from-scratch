# 孕期随访筛的不是"有没有病"，而是"谁在什么时候必须被叫回来"

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 每一段问的问题不一样
- 评估项是每次都要看的，信号是不管是不是预约日都要立刻处理的
- 同一项目要反复测很多次
- 方法不写，数字就没有意义
- 危险信号被排除之后
- 体位改变时量是否明显增多

## 边界

- **本章不给孕周之外的时间数字。**产检间隔、筛查时点、住院指征，都由现行规范与机构制度确定；本章只保留孕周分段这一层公共定义，其余不给数。
- **不给"胎动多少次算正常"。**不同规范给的界值不同，且与计数方法绑定；给出一个数而不绑定方法，是这类宣教最常见的错误来源。
- **"不等预约"不等于"直接住院"。**五类信号要求的是即刻评估，不是即刻住院；评估后可继续门诊观察，也可收治，由具备资质的人员决定。
- 本章为教学材料，不构成医学意见、诊断或护理指导。
