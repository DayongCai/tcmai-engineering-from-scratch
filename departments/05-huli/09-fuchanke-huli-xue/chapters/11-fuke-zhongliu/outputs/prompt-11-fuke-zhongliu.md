# 肿瘤护理的目标不是"治愈"，是把治疗变成一段能过下去的日子 · 提示词

## 用途

给「肿瘤护理的目标不是"治愈"，是把治疗变成一段能过下去的日子」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三条治疗线，三个观察面 → 不良反应：危险信号与报告的界 → 生育与身体意象：三个必须提前问的时点 → 动作与时限」这条链。
