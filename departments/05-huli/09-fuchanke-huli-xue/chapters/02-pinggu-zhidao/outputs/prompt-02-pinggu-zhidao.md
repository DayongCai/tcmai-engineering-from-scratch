# 评估的价值不在问了多少项，而在同一件事问第二遍还一致 · 提示词

## 用途

给「评估的价值不在问了多少项，而在同一件事问第二遍还一致」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「先确定"谁在听"，再确定"问什么" → 五个维度：问什么、向谁问、记什么 → 一致性：把"问准"变成三道可执行的动作 → 危险信号与转介：评估的出口」这条链。

## 提示词

```
我在学《妇产科护理学》第 2 章「评估的价值不在问了多少项，而在同一件事问第二遍还一致」，本章 5 节 / 3,034 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 先安置在场者，再开始提问
   - 不承诺保密到无法兑现的程度
   - 来源必须分开标
   - 一致与否必须显式写
   - 写明所用口径
   - 其一，间隔复问
4. 本章自陈的边界（不得越过）：
   - **本章不给筛查项目的频次与阈值。**产检间隔、筛查项目、异常判定的界值，均由现行规范与机构制度确定；本章只给"谁在什么条件下必须被叫回来"这一层判据。
   - **一致性核对有成本。**间隔复问、三相比对都要花时间，全项执行不现实。可行的做法是只对**关键项**执行：末次月经、既往分娩方式、过敏史、出血与疼痛的主诉。关键项之外，靠交接与既有记录兜底。
   - **单独访谈不是万能钥匙。**它提高了隐私类信息的获取率，也提高了误判"被胁迫"的风险；判断仍由具备资质的人员作出，护理的责任到"发现差异并报告"为止。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，不构成医学意见、诊断或护理指导；具体操作以现行规范与所在机构制度为准。
