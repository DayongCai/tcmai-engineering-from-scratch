# 产后的"正常"是一条趋势，不是一句写在出院小结上的话

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 同一个数字，条件不同就不是同一个数字
- 把院内看到的趋势翻译成居家能执行的判断
- 疑似血栓的部位不按摩、不热敷
- 其一，早接触与早吸吮的配合
- 在产妇与新生儿状态允许的那个时点，不因流程性事务推迟
- 其二，会阴与伤口的照护

## 边界

- **本章不给复旧的天数、恶露持续的时长与哺乳频次。**这些界值由现行规范与机构制度确定，且随分娩方式、喂养方式、个体差异变化；本章只给"看方向、看序列、看结果"这三条判据。
- **不给用药与哺乳期用药建议。**任何用药问题转由具备资质的人员按说明书与规范处理，护理不代为判断"能不能喂"。
- **情绪观察不等于心理评估。**本章给的是三条可观察的事实与一个报告出口，不是筛查工具；评估与诊断由具备资质的人员作出。
- 本章为教学材料，不构成医学意见、诊断或护理指导。
