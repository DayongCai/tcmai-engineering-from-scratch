# 妇科手术护理 · 提示词

## 用途

给「妇科手术护理」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「孕期监护 → 分娩配合 → 产褥与新生儿 → 出院与随访」这条链。

## 提示词

```
我在学《妇产科护理学》第 12 章「妇科手术护理」，本章 1 单元 / 17,335 汉字，
取自教材第 13 章。

请按以下顺序带我走：
1. 先给本章要回答的问题，并说明它为什么不能直接套用上一章；
2. 再给三辨（孕期监护／分娩与手术／产后与新生儿）在本章的实测分布，指出主导那一辨；
3. 然后按单元逐条读出「判据」——每条只写类别与要点，不给操作参数；
4. 最后给出三条边界：哪些内容只能写到类别、哪些必须由具备资质的人员作出、哪些情况按现行报告与转介流程及院内制度报告。

要求：不编造教材没有的数字；引文写到《书名·篇名》级并标注是否本章原文篇名；
不确定的地方直接说「教材未展开」。
```

## 边界

本提示词用于教学准备，不构成诊疗或护理意见；具体操作以现行规范与所在机构制度为准。
