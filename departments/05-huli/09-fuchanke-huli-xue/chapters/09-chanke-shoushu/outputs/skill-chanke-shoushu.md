# 产科手术的核对不是走流程，是把"两个人"同时对上台

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 准备时间不够，而准备的内容更多
- 缺一项结果，没人发现，人已经进了手术室
- 其一，输血相关告知
- 其二，紧急情况下的告知简化
- 简化的是流程，不是留痕
- 其一，三方核查

## 边界

- **本章不给麻醉方式、用药与补液方案。**麻醉的选择与实施、术中用药、输液与输血由具备资质的人员决定；护理的职责是配合、观察、核对与记录。
- **不给禁食时长与备皮范围的具体数字。**这些由现行规范与机构制度确定，且随术式与紧急程度变化。
- **核对不能靠"记得"。**本章反复强调的三个时点，是为了把核对从记忆变成结构；机构制度若规定了更多时点，按机构执行。
- 本章为教学材料，不构成医学意见、诊断或护理指导。
