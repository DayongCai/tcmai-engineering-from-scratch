## 一、学科定位

妇产科护理学（OB/GYN Nursing）是护理系的核心学科，聚焦「中医护理特色技术 + 现代护理全科能力」中的一个完整知识域。

## 二、中医 → AI 桥梁

```text
产程→阶段状态机 / 母婴数据→联合建模
```

妇产科护理学 里的每一个传统概念，都被翻译成一个可计算、可验证的工程对象：
中医概念给出**语义与约束**，AI/工程方法给出**表示与算法**。两者必须能互相回指，

**口径**

1. **三辨＝孕期监护／分娩与手术／产后与新生儿**，实测 **689 / 401 / 248**，比值 **2.8×**——**孕期监护是分娩与手术的 1.7 倍、产后与新生儿的 2.8 倍**，与「孕期最长、随访最密」一致；
2. **四位面取孕产阶段（2.1×）**（孕期 236 / 分娩期 115 / 产褥期 117 / 新生儿 112）。这是全课最平的一轴，四段几乎等重；
3. **科别（33.5×）弃**：肿瘤只有 21 次——教材以产科为主体（704），妇科与肿瘤是后半本；取科别会把课写成「产科 + 附赠妇科」；**场所（15.9×）弃**：产房只有 8 次，撑不起一轴。
