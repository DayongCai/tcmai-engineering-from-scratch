# 选题在开题前就定了成败：缺口必须算得出来 · 提示词

## 用途

给「选题在开题前就定了成败：缺口必须算得出来」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「好选题的四个判据 → 缺口怎么算：分子、分母、来源 → 选题过大的四种形态 → 开题评什么：评能不能做，不评想不想做」这条链。


## 边界

本章为教学材料，所述选题判据、缺口算式与节点交付用于训练毕设的立项判断，不构成医学、法律、投资或管理意见；具体操作以现行规范与所在机构制度为准。
