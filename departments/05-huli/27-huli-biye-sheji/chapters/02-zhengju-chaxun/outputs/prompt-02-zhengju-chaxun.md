# 证据检索的目的不是找到支持，是找到边界 · 提示词

## 用途

给「证据检索的目的不是找到支持，是找到边界」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「把问题变成能检索的形态 → 证据的层级：知道它管什么，也知道它不管什么 → 检索与筛选：把漏斗的每一层留下来 → 从证据到方案：适配与「不做什么」」这条链。

## 边界

本章为教学材料，所述检索结构、分级用法与适配三步用于训练循证设计，不构成医学意见、诊断或治疗建议；具体操作以现行规范与所在机构制度为准。
