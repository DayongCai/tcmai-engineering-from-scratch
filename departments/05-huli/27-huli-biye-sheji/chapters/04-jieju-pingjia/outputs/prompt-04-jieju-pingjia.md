# 指标选错，做得再规范也回答不了问题 · 提示词

## 用途

给「指标选错，做得再规范也回答不了问题」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三类指标，各回答一个问题 → 可测量化：分子、分母、时点、比较 → 替代指标：能用，但要说清它替代了什么 → 分析与偏倚：能说什么，不能说什么」这条链。

## 提示词

```
我在学《护理毕业设计与知识移交》第 4 章「指标选错，做得再规范也回答不了问题」，本章 5 节 / 2,806 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 本章无教材参考电子件
   - 说清它替代了什么、替代的合理性在哪、它在什么条件下会失效
   - 与真实结局脱节
   - 其一，先描述再比较
   - 其二，区分「统计学差异」与「实际意义」
   - 其三，把偏倚写在明处
4. 指出本章写到类别就止步、不再给参数的地方。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，所述指标分层、可测量化四要素与偏倚清单用于训练结局评价的设计与解读，不构成医学、统计或投资意见；具体操作以现行规范与所在机构制度为准。
