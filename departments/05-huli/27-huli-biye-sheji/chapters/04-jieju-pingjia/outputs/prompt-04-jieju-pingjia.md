# 指标与结局评价 · 提示词

## 用途

给「指标与结局评价」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「选题 → 证据与方案 → 干预与伦理 → 指标与结局 → 写作答辩 → 移交」这条链。

## 提示词

```
我在学《护理毕业设计》第 4 章「指标与结局评价」，本章 2 单元 / 36,855 汉字，
取自教材第 huli-guanli-xue#10、huli-guanli-xue#12 章。

请按以下顺序带我走：
1. 先给本章要回答的问题，并说明它为什么不能直接套用上一章；
2. 再给三辨（立项与设计／实施与伦理／评价与写作）在本章的实测分布，指出主导那一辨；
3. 然后按单元逐条读出「判据」——每条只写类别与要点，不给操作参数；
4. 最后给出三条边界：哪些内容只能写到类别、哪些必须由具备资质的人员作出、哪些情况按现行毕业设计管理规范与院内伦理审查流程报告。

要求：不编造教材没有的数字；引文写到《书名·篇名》级并标注是否本章原文篇名；
不确定的地方直接说「教材未展开」。
```

## 边界

本提示词用于教学准备，不构成诊疗或护理意见；具体操作以现行规范与所在机构制度为准。
