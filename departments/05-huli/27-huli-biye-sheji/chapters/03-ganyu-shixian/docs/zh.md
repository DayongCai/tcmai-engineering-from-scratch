## 三、逐单元读

### 3.1 3.1 自愿性的要求

学完本章，应当能够： 1. 说出知情同意的要素类别及其相互关系，并说明各要素之间的衔接。 2. 说明自愿性在同意过程中的伦理要求与保障环节。 3. 解释同意与拒绝为何应当获得同等尊重，并说明相应的沟通要求。 4. 归纳告知内容的类别与告知方式与语言要求。 5. 说明告知时机与留痕要求的伦理依据与记录要点。 6. 认识自主表达的类别与决定能力评估的边界。 7. 说明同意前置与不得事后追认与记录留痕的要求。 知情同意是护理伦理实践中的一项基本要求，其核心在于尊重服务对象的自主决定。本章采用统一口径，只写伦理要求与原则与议题的类别，说明各要素类别之间的关系，不作道德评判与个案裁断，也不对具体个人作出评价。 知情同意不是一个孤立的签字动作，而是一个持续的沟通与商定过程。按类别认识，其构成要素包括信息告知、信息理解、决定自愿、决定能力与最终授权等几个方面；各要素类别之间相互关联、彼此支撑，共同构成有效同意的基础条件。 告知是理解的前提。没有充分而适宜的告知，理解便失去基础；理解是自愿的前提，只有在对信息形成理解之后，所作出的决定才具有伦理上的意义；自愿是有效同意的前提，决定须出于服务对象的真实意愿；决定能力则贯穿于同意的全过程。 授权是同意过程的落点，可按类别区分为明确同意、默示同意以及由代理人作出的同意等情形。不同类别的授权在适用条件与记录要求上存在差别，但都应当以充分告知与自愿为前提，并按规定留痕，做到过程可复核、结论可追溯。 从伦理原则看，知情同意体现尊重自主的要求，同时与不伤害与有利的要求构成相互制约的关系。尊重自主不意味着放弃专业责任，不伤害与有利也不意味着可以替服务对象作出选择，三者之间的关系需要在具体情境中加以权衡。 上述几类原则之间的关系，需要结合具体情境，由具备资质的人员在多方沟通的基础上加以权衡，而不是由单一一方单独决定。本书只写要素类别与决策环节，不写具体操作参数与判定数值，也不作个案裁断。 护理人员在同意过程中的角色类别，主要是观察、评估、告知与记录，以及在必要时报告与转介，而不是代替具备资质的人员作出专业判断，也不是替服务对象作出选择。

*单元规模：20,220 汉字；出处 `派生·第3章·3.1`；本单元数值类命中 0。*

### 3.2 3.2 信息隐私类别

1. 说出隐私的主要类别，理解各类别在护理情境中的伦理意义与相互关系。 2. 说明身体隐私的保护要求与在照护操作中落实的方式。 3. 描述信息隐私的构成，理解健康信息按敏感个人信息处理的缘由。 4. 理解保密义务的类别与范围，说明保密例外的判断要求与程序。 5. 明确团队内共享信息的边界，理解目的限定与最小必要的要求。 6. 掌握去标识化与留痕的基本要求，说明脱敏与去标识化不得混称的口径。 7. 形成在信息共享中尊重、告知与同意、报告与改进的伦理意识。 隐私是护理伦理的重要范畴，其类别与关系是本章讨论的起点。就护理情境而言，隐私可大致区分为身体隐私、信息隐私以及空间与场所隐私三类。三者并非彼此孤立，而是相互交织：一次照护操作既可能触及身体隐私，也会生成并被记录为信息隐私，还可能发生在涉及空间隐私的场所之中；理解这些类别与关系，是提出恰当伦理要求的前提。 身体隐私类别，指与个人身体、生理状况及身体形象相关的隐私范畴。在护理工作中，更衣、沐浴、擦洗、导尿、伤口换药、体位变换等操作，都可能使护理对象处于身体暴露的状态。此类情境中的伦理议题，集中在暴露的必要程度、操作的可见范围以及当事人意愿是否得到尊重等方面。 对身体隐私的保护，首先体现为尊重的态度与相应的操作习惯。进入照护前应先作说明并征询意愿；操作时保持专注，不以与照护无关的话题谈论当事人的身体特征与外观。任何与照护无关的观看、议论或传播，都不属于护理工作的范围。 最小暴露是身体隐私保护的基本要求。护理人员在操作中只暴露完成操作所必需的部位，其余部分及时以被服或隔帘遮盖；操作间歇与结束时，尽快为当事人整理衣被。暴露范围的把握以操作需要为限，不以方便或习惯为由加以扩大。 环境准备同样属于身体隐私保护的一部分。条件允许时，宜使用屏风或床帘，关闭门窗，减少与操作无关的人员在场；在多人病房中，避免在公共视野内进行涉及身体暴露的操作。上述做法属于常规伦理要求与操作规范，具体以现行规范与机构制度为准。 告知与同意应前置于涉及身体隐私的操作。

*单元规模：20,334 汉字；出处 `派生·第3章·3.2`；本单元数值类命中 0。*
