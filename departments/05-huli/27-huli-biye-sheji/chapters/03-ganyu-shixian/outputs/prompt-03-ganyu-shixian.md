# 伦理审查不是盖章，是把受试者的代价提前算清 · 提示词

## 用途

给「伦理审查不是盖章，是把受试者的代价提前算清」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「干预落地要写死的四件事 → 伦理送审要交的东西 → 知情同意：五个要素与一个容易漏的动作 → 中途变更与退出：方案是会变的」这条链。

## 边界

本章为教学材料，所述四要素、送审四份与变更分类用于训练研究实施的合规判断，不构成法律、伦理审查或医学意见；具体操作以现行规范与所在机构制度为准。
