# 答辩评的是判断链，不是字数与图表的数量 · 提示词

## 用途

给「答辩评的是判断链，不是字数与图表的数量」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「四段式：每一段只回答一个问题 → 图表的三条规矩 → 陈述：十五分钟怎么分 → 提问：六类问题与应答方式」这条链。

## 提示词

```
我在学《护理毕业设计与知识移交》第 5 章「答辩评的是判断链，不是字数与图表的数量」，本章 5 节 / 2,881 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 本章无教材参考电子件
   - （这个变化可能由什么造成）、
   - （在什么条件下成立、什么条件下不成立）、
   - 第一条，一图一结论
   - 第二条，轴、单位、分母写全
   - 第三条，可比才放进同一张图
4. 指出本章写到类别就止步、不再给参数的地方。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，所述四段结构、图表规矩与应答分类用于训练论文写作与答辩表达，不构成医学、统计或学术评价意见；具体操作以现行规范与所在机构制度为准。
