# 群体伤害的分诊不是选重的，是选能救的 · 提示词

## 用途

给「群体伤害的分诊不是选重的，是选能救的」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「检伤分类与日常分诊的分野：个体最优与群体最优 → 分诊判据与分级：三个动作，三十秒 → 时间窗与站位：分区先于处置 → 记录字段与失效模式」这条链。
