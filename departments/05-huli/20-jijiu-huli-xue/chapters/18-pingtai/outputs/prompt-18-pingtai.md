# 平台的价值是让判断可复核，不是替人判断 · 提示词

## 用途

给「平台的价值是让判断可复核，不是替人判断」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三层：单元、术语、版本 → 分诊判据与分级：平台里的分级只能是索引 → 时间窗与站位：从现场到系统的三段 → 记录字段与失效模式」这条链。

## 提示词

```
我在学《急救护理学》第 18 章「平台的价值是让判断可复核，不是替人判断」，本章 6 节 / 3,357 汉字，习题 7 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 本章引证口径
   - 单元、术语、版本
   - 知识只描述，不判定
   - 平台提供判据清单与去向索引，不提供判定结论
   - 其一，判据要可勾选、可不勾选、可留空
   - 其二，分级要允许「判据不足」
4. 指出本章写到类别就止步、不再给参数的地方。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，不构成医学意见、诊断或护理指导；具体操作以现行规范与所在机构制度为准。
