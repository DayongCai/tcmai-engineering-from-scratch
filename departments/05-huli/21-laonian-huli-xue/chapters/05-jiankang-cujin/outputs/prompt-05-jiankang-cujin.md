# 老年期的预防不是做加法，是保住已有的余量 · 提示词

## 用途

给「老年期的预防不是做加法，是保住已有的余量」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三级预防在老年期要重新排序 → 筛查：不做什么比做什么更需要理由 → 三件最划算的事：活动、营养、口腔 → 依从性：把建议压到三条以内」这条链。
