# 质量不是查出来的，是流程里长出来的 · 提示词

## 用途

给「质量不是查出来的，是流程里长出来的」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「四个维度：结构、过程、结果、体验 → 交接：三分钟里必须交到的三件事 → 团队：谁决定、谁执行、谁记录 → 查检与改进：少而准的指标」这条链。

## 边界

本章为教学文本，所述维度、交接结构与改进方法用于训练流程管理，不构成管理决定或诊疗建议；具体操作以现行规范与所在机构制度为准。
