# 评估不是把项目做全，是把可干预的挑出来 · 提示词

## 用途

给「评估不是把项目做全，是把可干预的挑出来」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「谁该做，谁不必做 → 十二个维度，各用哪一套 → 从结果到「可干预清单」：三条规则 → 组织与时限：72 小时内的一次团队会」这条链。

## 边界

本章为教学文本，所述维度、工具与时限用于训练评估组织与记录，不构成诊疗、用药或分级护理的个别建议；具体操作以现行规范与所在机构制度为准。
