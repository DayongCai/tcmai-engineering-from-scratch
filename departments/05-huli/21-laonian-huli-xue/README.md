## 一、学科定位

老年护理学（Geriatric Nursing）是护理系的核心学科，聚焦「中医护理特色技术 + 现代护理全科能力」中的一个完整知识域。

## 二、中医 → AI 桥梁

```text
衰弱评估→综合评分 / 跌倒风险→分类模型
```

老年护理学 里的每一个传统概念，都被翻译成一个可计算、可验证的工程对象：
中医概念给出**语义与约束**，AI/工程方法给出**表示与算法**。两者必须能互相回指，
否则这个章节就还没有写完。

**口径**

1. **三辨＝功能与评估／慢病与照护／安全与风险**，实测 **2011 / 5484 / 1544**，比值 **3.6×**——照护与慢病一侧最厚，评估与安全各占约三分之一；
2. **四位面（照护落点）取 C（11.1×）**：功能维护／心理社会／综合征预防／长期照护 四类分别是 **1849 / 483 / 167 / 1008**；
3. **另外两个候选轴都有零值，弃用**——这是本课最值得记的一条：
   - A 系统轴（3.0×）：**心血管与呼吸 = 0 次**，神经与认知 69 次；
   - B 场所轴（285.5×）：**养老机构 4 次、医院 10 次**，居家 1142 次 → 285.5× 是「教材只写居家」的极端，不是分类；
   - C 初版含「慢病管理」，用 9 个具体病名（高血压/糖尿病/冠心病/慢阻肺/骨质疏松/痴呆/脑卒中/帕金森/慢阻肺）去数，**全部 0 次**；
4. **零值的解释**：这本母本**不写病种、不写机构**，它写的是「功能—照护—安全」的通用框架。所以把 C 的第四类从「慢病管理」改为「长期照护」后四类无零值，才是可用的轴。

**本课在系里的词面签名：`功能康复`（功能康复 41.2，系内第二）**

| 词类 | 本课 | 系内最高 |
|---|--:|---|
| 辨证 | 0.6 | 中医护理学 17.2 |
| 技术操作 | **0.1** | 外科 7.0 |
| 安全风险 | 21.8 | 基护 40.4 |
| 家属沟通 | **36.4** | 儿科 43.7 |
| 功能康复 | **41.2** | 康复 94.3 |
| 时间急救 | 1.1 | 急救 35.7 |

**「功能康复 41.2 + 家属沟通 36.4，技术操作 0.1」**——老年照护靠功能维持与家庭支持，不靠技术动作。这个组合与儿科（家属沟通 43.7、功能 6.1）形成对照：**两端人群都靠家属，但老年多一条「功能」，儿科多一条「生长」**。

**代价与边界**

- 只写到类别与要点：具体操作参数、药物剂量与病种治疗方案 不在正文；
- 个案不入正文，例子一律为说明性表述；
- 不替代专业判断；发现异常按现行报告与转介流程及院内制度报告与转介；
- **两条人群红线**：老年人表述**中性、不贴标签、不作能力贬抑性推断**；涉老化的健康问题**不作个人责任化归因**（母本自身反复强调这两条）。
