# 价值观不挂在墙上，挂在你如何处理一个难缠的人 · 提示词

## 用途

给「价值观不挂在墙上，挂在你如何处理一个难缠的人」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「价值观的三种可观察形态 → 开口之前：先把自己的排序写出来 → 判据分档：价值冲突时能不能继续 → 话术、动作与时限」这条链。

## 边界

本章为教学材料，所述排序方法、判据档位与话术用于训练职业价值判断，不构成医学意见、伦理裁决或法律建议；具体操作以现行规范与所在机构制度为准。
