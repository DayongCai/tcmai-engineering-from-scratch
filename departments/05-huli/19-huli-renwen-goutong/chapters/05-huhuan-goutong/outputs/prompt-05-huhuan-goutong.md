# 护患沟通的成败，一半在入院那十分钟就定了 · 提示词

## 用途

给「护患沟通的成败，一半在入院那十分钟就定了」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「六个环节，各只有一个任务 → 开口之前：入院前十分钟做什么 → 判据分档：环节能不能往下推进 → 话术、动作与时限」这条链。

## 边界

本章为教学材料，所述环节任务、判据档位与话术用于训练护患沟通过程管理，不构成医学意见或诊疗建议；具体操作以现行规范与所在机构制度为准。
