# 人文修养的底子是「把人当人」的可核对动作 · 提示词

## 用途

给「人文修养的底子是「把人当人」的可核对动作」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「人文的三个层次，只有最外层能被看见 → 开口之前：三样东西必须先知道 → 判据分档：什么时候可以继续，什么时候必须停 → 六个动作与各自的时限」这条链。

## 提示词

```
我在学《护理人文修养与沟通》第 1 章「人文修养的底子是「把人当人」的可核对动作」，本章 6 节 / 3,202 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 参考件状态
   - 一个反例值得记住
   - 其一，他是谁，谁替他做决定
   - 其二，他为什么在这里，最在意什么
   - 其三，他现在处在什么状态
   - 必须停的四种情形要背下来
4. 指出本章写到类别就止步、不再给参数的地方。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，所述准备清单、判据档位、动作与时限用于训练沟通能力，不构成医学意见、心理诊断或治疗建议；具体操作以现行规范与所在机构制度为准。
