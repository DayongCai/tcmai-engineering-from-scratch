# 人文要被评价，先得变成可统计的记录字段 · 提示词

## 用途

给「人文要被评价，先得变成可统计的记录字段」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三层指标与人文的位置 → 开口之前：先定评什么、为什么评 → 判据分档：这份数据能不能用来评价 → 动作与时限」这条链。

## 提示词

```
我在学《护理人文修养与沟通》第 14 章「人文要被评价，先得变成可统计的记录字段」，本章 5 节 / 2,818 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 参考件状态
   - 结构层：有什么
   - 过程层：做了什么
   - 结果层：得到了什么
   - 「百工为方以矩，为圆以规」这句话讲的是标准的作用，不是讲工具本身
   - 因此人文要被评价，必须先补过程层的字段
4. 指出本章写到类别就止步、不再给参数的地方。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，所述指标设计、判据与字段用于训练人文质量的评价思维，不构成医学意见或管理裁决；具体操作以现行规范与所在机构制度为准。
