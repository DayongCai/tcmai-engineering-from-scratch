# 人文修养是长期竞争力，因为它最难被替代 · 提示词

## 用途

给「人文修养是长期竞争力，因为它最难被替代」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三个台阶与六格能力 → 开口之前：先做一次能力盘点 → 判据分档：什么时候该换方向 → 动作与时限」这条链。

## 提示词

```
我在学《护理人文修养与沟通》第 13 章「人文修养是长期竞争力，因为它最难被替代」，本章 5 节 / 2,858 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 参考件状态
   - 胜任台阶：能把事做对
   - 精通台阶：能在复杂情境下做判断
   - 带教台阶：能让别人也做到
   - 「青出于蓝」这句话在这里不是励志，是机制
   - 证据要可核实
4. 指出本章写到类别就止步、不再给参数的地方。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，所述能力框架、盘点方法与判据用于职业发展的自我评估，不构成职业规划、心理或法律建议；具体操作以现行规范与所在机构制度为准。
