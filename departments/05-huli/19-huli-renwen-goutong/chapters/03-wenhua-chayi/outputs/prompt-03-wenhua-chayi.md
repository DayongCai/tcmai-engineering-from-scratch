# 文化差异不在风俗清单，在谁有资格先开口 · 提示词

## 用途

给「文化差异不在风俗清单，在谁有资格先开口」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「文化的三层：习俗、规则、假设 → 开口之前：问禁、问俗、问讳 → 判据分档：是误解、是冲突，还是越界 → 话术、动作与时限」这条链。

## 提示词

```
我在学《护理人文修养与沟通》第 3 章「文化差异不在风俗清单，在谁有资格先开口」，本章 5 节 / 2,839 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 参考件状态
   - 还要防止一种反向错误：把个体当成文化样本
   - 问禁，问的是不能碰的
   - 问俗，问的是这里通常怎么做
   - 问讳，问的是不能提的
   - 不要用患者的未成年子女做口译
4. 指出本章写到类别就止步、不再给参数的地方。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，所述三问、判据档位与话术用于训练跨文化沟通能力，不构成医学意见或文化评判；具体操作以现行规范与所在机构制度为准。
