# 反思不是写感想，是把一次失误拆成可改的动作 · 提示词

## 用途

给「反思不是写感想，是把一次失误拆成可改的动作」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「反思与感想的分界线 → 开口之前：先攒素材 → 判据分档：反思做到什么深度 → 方法、动作与时限」这条链。

## 提示词

```
我在学《护理人文修养与沟通》第 12 章「反思不是写感想，是把一次失误拆成可改的动作」，本章 6 节 / 2,949 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 参考件状态
   - 回答「我感觉怎么样」
   - 其一，有没有具体到一句话
   - 其二，有没有指向自己的动作
   - 其三，有没有只留一个动作
   - 「学而不思则罔，思而不学则殆」在这里有第二个含义
4. 指出本章写到类别就止步、不再给参数的地方。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，所述反思方法、判据与记录字段用于训练人文实践的复盘能力，不构成医学意见或心理督导；具体操作以现行规范与所在机构制度为准。
