# 坏消息先说人话，冲突先降级再说理 · 提示词

## 用途

给「坏消息先说人话，冲突先降级再说理」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「四类情境，各自的第一件事 → 开口之前：场地、在场人、开场句 → 判据分档：能不能继续谈 → 话术、动作与时限」这条链。

## 边界

本章为教学材料，所述分级、话术与时限用于训练危机情境下的沟通次序，不构成医学意见、心理诊断或危机干预方案；具体操作以现行规范与所在机构制度为准。
