# 护理程序不是五步流水线，而是一个能被评价打回的循环 · 提示词

## 用途

给「护理程序不是五步流水线，而是一个能被评价打回的循环」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「五步的关系：前四步向前，第五步向后 → 评估：资料的来源与两级可信度 → 诊断：护理诊断不是医学诊断 → 计划：目标四要素与优先级」这条链。

## 边界

本章为教学材料，不构成医学意见或诊疗建议。涉及具体服务对象的评估、诊断性判断与处理决定，须依现行规范与所在机构制度，由具备相应资质的人员作出；具体操作以现行规范与所在机构制度为准。
