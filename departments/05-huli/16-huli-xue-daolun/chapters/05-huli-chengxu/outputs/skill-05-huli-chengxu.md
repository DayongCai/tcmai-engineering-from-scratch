# 护理程序不是五步流水线，而是一个能被评价打回的循环

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 第五步是唯一向后指的步骤
- 任何一条护理诊断，若只有一类资料支撑，都应当标注这一局限
- 若只采用第一条，整条计划会建立在一个错误的判断上
- 边界：护理诊断不作医学诊断结论
- 服务对象认为最要紧的
- 评价是护理程序里唯一能自我纠错的环节

## 边界

- 只写类别与要点，不写操作参数。
- 本章为教学材料，不构成医学意见或诊疗建议。涉及具体服务对象的评估、诊断性判断与处理决定，须依现行规范与所在机构制度，由具备相应资质的人员作出。
