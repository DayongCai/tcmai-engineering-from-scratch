# 理念不是墙上的标语，而是两种做法都合规时你选哪一个 · 提示词

## 用途

给「理念不是墙上的标语，而是两种做法都合规时你选哪一个」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「理念的三个层次，以及标语为什么一定失效 → 三个阶段：变的不是态度，是关注中心 → 整体护理与以人为本：各有一个可判定的动作 → 价值观：五个要素各自约束一种行为」这条链。
