# 理念不是墙上的标语，而是两种做法都合规时你选哪一个

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 标语失效的机制在于它只有中观层的语言，没有宏观层的依据，也没有微观层的动作
- 整体护理的判定动作：把资料归到三类，并让三类互相解释
- 以人为本的判定动作：方案里能指出一处因服务对象的选择而改变的地方
- 理念不是形容词，是结构约束
- ① 操作化定义
- ③ 场景动作

## 边界

- 只写类别与要点，不写操作参数。
- 本章为教学材料，不构成医学意见、伦理裁定或管理建议。涉及伦理争议、投诉处理与执业责任的具体事项，须依现行法律法规、行业规范与所在机构制度，由具备相应资质的人员或伦理委员会处理。
