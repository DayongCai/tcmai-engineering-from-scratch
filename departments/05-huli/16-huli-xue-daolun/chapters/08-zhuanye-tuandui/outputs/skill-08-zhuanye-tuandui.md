# 团队协作的瓶颈不在人数，在有没有人敢说不

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 专业者对自身判断负责，因此专业者之间有相互质疑的义务
- 「没有发生」无法被计数，因此无法被看见
- 临床判断能力
- 沟通与协作能力
- 专业成长能力
- 责任必须有唯一归属

## 边界

- 只写类别与要点，不写操作参数。
- 本章为教学材料，不构成管理意见或执业指导。涉及岗位职责、执业范围、排班与质量管理的具体事项，应以现行法规、部门规章、行业规范与所在机构制度为准。
