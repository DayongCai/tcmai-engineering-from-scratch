# 四个基本概念不是四个词，是一条断哪一节都塌的链

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 整体大于并不同于各个部分之和
- 先找那个把各层串起来的点
- 这一节的结论：整体性不是把评估表做长，是把评估表做出主次
- 分辨哪些是护理能改的、哪些只能报告、哪些改不了但可以缓冲
- 环境包括人际氛围
- 第一，「正常」是一个区间而不是一个点

## 边界

- 只写类别与要点，不写操作参数。
- 本章为教学材料，不构成医学意见或诊疗建议。涉及具体服务对象的健康判断、治疗与用药决定，由具备资质的医务人员依照现行规范作出。
