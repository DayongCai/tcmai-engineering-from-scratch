# 四个基本概念不是四个词，是一条断哪一节都塌的链 · 提示词

## 用途

给「四个基本概念不是四个词，是一条断哪一节都塌的链」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「人：整体性是不可还原，不是一个清单 → 环境：护理真正能改的只有三段 → 健康：连续谱，不是开关 → 理论：概念、命题、模型，以及四条线索」这条链。

正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

## 边界

本章为教学材料，不构成医学意见或诊疗建议。涉及具体服务对象的健康判断、治疗与用药决定，由具备资质的医务人员依照现行规范作出；具体操作以现行规范与所在机构制度为准。
