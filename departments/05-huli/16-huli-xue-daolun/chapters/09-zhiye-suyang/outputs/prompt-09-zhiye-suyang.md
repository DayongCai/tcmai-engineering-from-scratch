# 人文关怀不是态度好，是看见了这个人的处境并因此改了做法 · 提示词

## 用途

给「人文关怀不是态度好，是看见了这个人的处境并因此改了做法」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「素养的三维：知识、技能、态度，态度不能单独考核 → 养成的三条途径，各自的限度 → 关怀行为的四类与判据 → 关怀不替代专业判断：两种越界」这条链。

## 提示词

```
我在学《护理学导论》第 9 章「人文关怀不是态度好，是看见了这个人的处境并因此改了做法」，本章 5 节 / 2,832 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 可以被考试
   - 可以被观察与回示教
   - 前者是要求，后者是改变条件——复盘的深度就体现为能否落到后者
   - 可以被第三个人观察到的动作
   - 人对自己被如何对待的记忆，比对措施本身的记忆更长、更具体
   - 第一种，以关怀替代判断
4. 指出本章写到类别就止步、不再给参数的地方。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，不构成心理诊断、治疗建议或管理意见。涉及服务对象与从业者的心理健康问题，应转由具备相应资质的专业人员处理；具体操作以现行规范与所在机构制度为准。
