# 人文关怀不是态度好，是看见了这个人的处境并因此改了做法

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 可以被考试
- 可以被观察与回示教
- 前者是要求，后者是改变条件——复盘的深度就体现为能否落到后者
- 可以被第三个人观察到的动作
- 人对自己被如何对待的记忆，比对措施本身的记忆更长、更具体
- 第一种，以关怀替代判断

## 边界

- 只写类别与要点，不写操作参数。
- 本章为教学材料，不构成心理诊断、治疗建议或管理意见。涉及服务对象与从业者的心理健康问题，应转由具备相应资质的专业人员处理。
