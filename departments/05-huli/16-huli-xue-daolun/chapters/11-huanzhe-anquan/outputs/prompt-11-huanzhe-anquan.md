# 安全不是不出事，是出事之前有人敢喊停 · 提示词

## 用途

给「安全不是不出事，是出事之前有人敢喊停」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「风险环节的类别 → 身份识别：两个独立标识 → 交接与升级：两条通道 → 质量指标：维度、口径与分子分母」这条链。

## 边界

本章为教学材料，不构成管理意见、法律意见或操作指引。涉及不良事件报告、责任认定、质量评价与患者安全管理的具体事项，须依现行法律法规、行业规范与所在机构制度办理；具体操作以现行规范与所在机构制度为准。
