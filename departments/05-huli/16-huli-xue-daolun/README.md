## 一、学科定位

护理学导论（Introduction to Nursing）是护理系的核心学科，聚焦「中医护理特色技术 + 现代护理全科能力」中的一个完整知识域。

## 二、中医 → AI 桥梁

```text
护理程序→流程建模 / 健康行为→预测模型
```

护理学导论 里的每一个传统概念，都被翻译成一个可计算、可验证的工程对象：
中医概念给出**语义与约束**，AI/工程方法给出**表示与算法**。两者必须能互相回指，
否则这个章节就还没有写完。

**口径**

1. **三辨＝概念与理论／护理程序／专业与伦理**，实测 **9286 / 3644 / 3461**，比值 **2.7×**。**这个比值有词表通胀**：「护理」「健康」「人」等泛词被计入「概念与理论」，几乎每段都有，所以 2.7× 只能说明方向（导论以概念为主），不能当作比例；
2. **四位面取护理领域 5.9×**（基础护理 837 / 治疗与给药 908 / 专科与特殊人群 155 / 健康管理 324）；
3. **护理对象 7.3× 未取**：个体 2614 vs 家庭 356 的 7.3× 是「护理以个体为主」的事实，取它会把课写成「个体护理 + 附录」；**内容层次 2.0× 虽最小（2.0×）也未取**——对象/场所/方法/专业发展四个维度不同层，混在一个轴上无法比较。

**跨课对账（导论 × 中医护理学）：四类词画出两课分界**

| 词类 | 导论 | 中医护理学 | 比值（专科/导论） |
|---|--:|--:|--:|
| 护理程序 | 63.9 | 85.1 | **1.33** |

**结论**：导论给「程序 + 伦理 + 安全」，专科给「辨证 + 具体操作」。**「导论 → 各科护理学」这条先修边不是排课惯例，而是内容依赖**——跳过导论直接学专科，缺的程序与伦理在专科课里不会被补上。
