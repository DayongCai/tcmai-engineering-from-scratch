## 五、代价与边界

- 不写具体灸量、留罐时间、刮痧力度与药物剂量（母本 31.5 万字里操作参数近乎为零，这是教材写法不是疏漏）
- 不承诺疗效，不写「根治／有效率」
- 涉及针刺、破皮、孕妇与出血倾向等禁忌情形一律先说明不适用
