# 第 11 章 · 记录既是照护的痕迹，也是执业的证据

> **MOTTO:** 「凡大医治病，必当安神定志，无欲无求，先发大慈恻隐之心。」——《备急千金要方·大医精诚》

**双根因定位:** 环境逼迫（照护过程本身是连续的、多人交替的，若不留痕，任何一段过程都无法被还原；而当患者、家属、机构之间出现分歧时，唯一能还原过程的就是记录）+ 知识积累（护理文书形成了相对固定的要素与修改规则——客观、真实、准确、及时、完整、规范，以及不涂改、划改留痕、签名注时——使「写清楚」这件事有了可考核的标准）

## 一、记录的读者不是你

写记录时的默认读者错位，是绝大多数记录问题的源头。你以为读者是自己（所以写「按计划执行」），实际读者至少有三类：**下一班的人**（要能接着做）、**复盘的人**（要能找出哪一步出了问题）、**患者与家属**（依法可以查阅、复制的部分）。

三类读者对同一份记录的要求可以合并成一句话：**读完之后，能说出「何时、看到什么、做了什么、结果如何、谁做的」。**五件事齐了，记录就成立；缺任何一件，它在某一种用途上就失效。

写法上最容易混淆的是观察与判断。观察写「患者自述头晕，坐起时明显，平卧后缓解」；判断写「体位性低血压」。前者护理人员可以写，后者须由具备资质的人员作出，护理记录中若需体现，应写为「已报告，医嘱……」。这不是文字洁癖，而是执业范围的边界在纸面上的体现。

## 二、采集项与记录写法

### 护理记录的基本要素

| 要素 | 内容 | 常见缺失 |
|---|---|---|
| 时间 | 观察时间、实施时间、记录时间（三者可不同） | 只写记录时间 |
| 对象 | 患者身份的双项核对 | 只写床号 |
| 观察 | 客观表现与患者原话（加引号） | 写结论、写形容词 |
| 措施 | 做了什么、依据是什么（评估结论或医嘱） | 写「按计划」 |
| 反应 | 患者的主观感受与客观变化 | 只写「无不适」 |
| 报告 | 向谁报告、何时、报告内容 | 口头报告无记录 |

### 中医护理记录的特有要素

在通用要素之外，中医护理记录要能体现三样东西：**观察到的中医相关项**（寒热喜恶、舌象、二便性状、情志与睡眠）、**据此形成的照护方向**（不写证名，写方向与类别）、**实施的技术与反应**（技术名称、部位、患者即时反应、局部表现）。

示例句式：「诉畏寒，加衣不减，喜热饮，大便偏稀；予病室加温、饮食改温热性状、避生冷，一小时后自述畏寒稍减。」这句话里有观察、有方向、有措施、有反应、有时间，且没有一句越界。

### 文书类型与各自的用途

不同类型的文书回答不同的问题，混用的后果是「写了很多，仍然答不上被问的那一个」。体温单回答「数值与趋势」；护理记录单回答「观察到什么、做了什么、反应如何」；交接记录回答「下一班要知道什么」；知情同意类文书回答「告知了什么、谁同意的」；不良事件报告回答「哪个环节出了问题」。同一件事在几类文书里各有一次落笔，彼此不能互相替代：交接记录里写了「已交代注意事项」，不能免除护理记录里对交代内容与回示结果的记录。

电子记录另有两条纪律。其一，**账号即签名**，不共用、不代登、不让实习生用自己的账号录入；其二，**套用条目不是答案**，勾选式条目须有与之匹配的具体描述，纯勾选而无一句自由描述的记录，在复核时通常被判定为「形式完整、内容不足」。

### 修改与留痕

三条铁律：**不涂改、不刮擦、不覆盖**；**修改用划改**，保留原字迹可辨，旁边写修改内容、签名、注时；**电子记录按系统留痕规则修改**，不共用账号、不代签、不事后补记成当时。

「事后补记」要区分两种：确实当时忙而未写，补记时须注明「补记」及实际观察时间，这是可接受的；把没做的事写成做了，属记录失实，性质完全不同。二者的界线是**有没有发生**，不是**写没写全**。

### 查阅、复制与共享

患者依法可以查阅、复制其病历资料中属于可查阅范围的部分；护理人员不得自行提供、不得私自拍照转发、不得在社交平台讨论个案。向第三方（保险、单位、家属中的非授权人）提供信息须有依据与授权。教学与讨论使用个案须去标识化，且去标识化不等于脱敏：前者是切断与身份的可关联，后者是遮蔽敏感字段，两者不可混称。

## 三、成组判据：一份合格记录的六项同现

判断记录是否合格，不看篇幅，看六项是否同现（教学设定，非实测）：

| 项 | 合格表现 | 不合格表现 |
|---|---|---|
| 可追溯 | 时间、执行人、依据齐全 | 只有结果，无时间与人 |
| 可复核 | 观察项具体到部位、程度、条件 | 「一般情况可」 |
| 可交接 | 下一班读完知道要盯什么 | 只写已完成的动作 |
| 边界清 | 判断性内容标注为报告或医嘱 | 自行写出诊断或证名 |
| 留痕完整 | 修改有划改、签名、时间 | 涂黑、覆盖、重新抄写 |
| 合规 | 无多余个人信息，无外传 | 记录中出现与照护无关的隐私 |

六项中缺两项以上，这份记录在争议场景中基本无法自证。带教时用「六项打勾」的方法审记录，比逐字改更有效。

## 四、动作与边界：知情同意、拒绝与执业范围

**知情同意**要落在四个内容上：做什么、为什么做、可能有什么感觉与风险、可以随时停止。四句话说清并取得同意，才可实施；只签一张纸而没说的，不构成知情。同意要记录：谁告知、告知了什么、谁同意、何时。

**拒绝与撤回**同样是权利。患者拒绝时，记录写「已告知……，患者表示暂不接受，已报告」，并继续提供替代性照护与观察；不写「患者不配合」，不施加压力，不因拒绝而减少必要的观察。撤回同意发生在操作中途时，立即停止。

**执业范围**的三条硬边界：不作诊断；不自行调整治疗与用药；不实施超出本机构授权范围的技术。三条之外还有一条软边界：**不替他人作解释**。家属问「这个是不是没好」，正确的回答是「我把观察到的情况告诉您，具体判断请等医生说明」，不是给一个安慰性的结论。

伦理原则上，尊重、不伤害与有利、公正与诚信四条在护理场景中最常落在具体动作上：遮挡与征得同意（尊重）、核查禁忌与停手（不伤害）、资源与告知的一致（公正）、记录如实与不夸大（诚信）。

有两种情形需要额外的注意。**其一，教学与实习场景。**患者有权知道在场者是谁、有权拒绝学生操作；学生的操作须在有资质人员的指导下进行，记录由实际执行者签名并注明指导者。**其二，患者无法表达意愿时。**意识不清、认知受损、语言不通的情形，同意应由法定或授权的代理人在充分告知后作出，紧急情况下按机构制度处理；护理人员记录的是「谁作出的决定、依据什么、何时」，不自行代替决定。

## 五、失效模式与考核项

**其一，判断混入观察。**记录中出现证名、诊断名、因果推断。

**其二，抄写式记录。**连续多日几乎相同，只改日期；趋势信息消失。

**其三，补记不标。**事后补写却写成当时，一旦发生争议无法自证。

**其四，涂改与覆盖。**用修正液、涂黑、撕页重抄。

**其五，口头报告无痕。**已报告但记录中无「向谁、何时、报告什么」。

**其六，信息外流。**拍照发群、在公共区域讨论、把完整病历发给非授权人。

考核六条：一、给一份记录，用六项打勾法审出不合格项并改写其中三条；二、把三句判断性表述改写为观察性表述，并注明应报告的对象；三、演示一次划改，写出修改内容、签名与时间；四、写出知情同意的四句内容并说明记录方式；五、说明患者拒绝时的三条正确动作；六、说出查阅、复制与共享的三条边界。

## 代价与边界

文书记录的代价，第一是**时间**。写得合格必然费时，而记录时间来自照护时间。可行的办法是**边做边记要点**：口袋本记时间与关键观察，班末整理成文；比事后回忆可靠，也比实时长写省时。第二是**合规要求与临床节奏冲突**，尤其在突发情况下，此时的原则是「先处理，后补记并标注」。第三是**记录越完整，暴露面越大**：写得细，意味着可被审视的细节多；这是必须接受的代价，因为不写不等于没发生。第四是**伦理条款容易悬空**。四条原则若不落到遮挡、告知、停手、如实这些动作上，就只是标语。
