# 技术的第一道关是禁忌，不是手法 · 提示词

## 用途

给「技术的第一道关是禁忌，不是手法」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「六要素闭环：技术不是一次动作 → 实施前评估：五个必查项 → 成组判据：能做的条件也是成组的 → 四类技术的动作与边界」这条链。

## 边界

本章为教学文本，所述评估项、条件组与停止指征用于训练判断顺序，不构成诊疗、用药或技术操作的个别建议；具体操作以现行规范与所在机构制度为准。
