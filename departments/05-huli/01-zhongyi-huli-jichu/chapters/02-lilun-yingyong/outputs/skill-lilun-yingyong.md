# 基础理论给的不是证名，是「哪一头偏了」的方向

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 先定两端（阴阳），再定系统（脏腑）与载体（气血津液）
- 这三步不产出诊断
- 生克关系用来解释「为什么一个系统的失衡会牵动另一个」，从而扩大观察面
- （喜冷喜热、四肢温凉、二便性状、舌色）与
- 这一条比任何一组都重要
- 一是环境与起居的安排

## 边界

- 只写类别与要点，不写操作参数。
- 本章为教学文本，所述分组与方向仅用于训练观察与照护思路，不构成诊疗、用药或照护的个别建议。
