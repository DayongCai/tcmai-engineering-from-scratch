# 第 5 章 · 证候是施护的开关，而开关只能靠观察守住

> **MOTTO:** 「太阳之为病，脉浮，头项强痛而恶寒。」——《伤寒论·辨太阳病脉证并治》
>
> **PROBLEM:** 本章原文 15,959 汉字里，「观察」出现 216 次，「施护」78 次，比例 2.8∶1；「报告」50 次，「记录」134 次。教材在证候章把最多的篇幅给了「看」，而不是「做」。这不是失衡，是这门课最要紧的一个判断：**证候章真正的技能是观察证候的移动，而不是记住某个证候对应的措施清单。** 因为证候会变——表证可以入里，寒证可以化热，实证可以转虚——而措施清单是静态的。学生若只会背「表证宜解表」，遇上入里之后仍在「解表」，就是本章最常见的失效。
>
> **双根因定位:** 环境逼迫（证候的移动往往发生在两次巡视之间，医生不在场，护士是唯一能捕捉到「变了」的人；而捕捉靠的是把观察项固定下来，不是靠经验直觉）+ 知识积累（教材把八纲证候按「表里、寒热、虚实」逐节铺开，每节都给「施护原则与观察要点」，但没有把「证变了怎么办」写成一条独立规则，学生拿到的是七个静态模块）

## 一、六个基本证候：判据是成组的，不是单点的

八纲落到证候层面，常用的六个基本型：表证、里证、寒证、热证、虚证、实证（阴阳作为总纲，见第 2 章）。每一个的判据都必须是**成组出现**，单项不算。

| 证候 | 成组判据（需同时具备） | 一句话护理方向 |
|---|---|---|
| 表证 | 起病急、恶寒与发热并见、头身痛、脉浮、苔薄白 | 解表：护汗、避风、观察汗出与热退 |
| 里证 | 病程较长或起病即无恶寒、但热不寒或但寒不热、苔变化明显、脉不浮 | 定位在脏腑：按脏腑观察线走 |
| 寒证 | 畏寒喜温、口不渴或渴喜热饮、便溏尿清、舌淡、脉迟或紧 | 温：护阳、避寒、忌生冷、慎用寒凉 |
| 热证 | 发热喜凉、口渴喜冷、便干尿黄、舌红、脉数 | 清：护津、通风、清淡饮食、观察津伤 |
| 虚证 | 病程久、声低乏力、喜按、脉无力、舌淡或瘦 | 补：减量、节劳、护脾胃、缓图 |
| 实证 | 病程短、声高气粗、胀满拒按、脉有力、舌苔厚 | 泻：观察排泄、护皮肤、防耗伤 |

三条判据纪律：

**一、表里先分，寒热虚实后分。** 表里定的是「邪在哪一层」，这一步错，后面全错。教材把表证放在最前，是因为它有最清晰的时间特征：起病急、恶寒与发热同现。**「恶寒」是表证的关键字**——里证多但热不寒或但寒不热，唯独表证是「恶寒与发热并见」。

**二、虚实看的是「正气的状态」，不是「病得重不重」。** 高热可以是实证（正盛邪盛），也可以是虚证（正虚邪陷）。判据在脉之有力无力、腹部喜按拒按、病程长短。

**三、兼夹是常态，写清楚比归好类更重要。** 「表寒里热」「虚实夹杂」「寒热错杂」在病房里比单纯证多。记录写「以表寒为主，兼见咽痛口干」，比硬贴一个「表寒证」有用得多。

## 二、施护动作的四个方向：温、清、补、泻的护理化

原则层面的「寒者热之、热者寒之、虚者补之、实者泻之」，到护理手里要变成四组具体动作，每组都有自己的边界。

**温（对寒证）。** 动作：调高室温、加被、热饮热食、避风、局部保暖（腹部、腰、足）。边界：**有热象时立即停**——舌转红、口干、烦躁、体温上升，温法要退。最常见的错是「一贯怕冷」的印象压过当下的热象，持续保暖导致烦躁加重。

**清（对热证）。** 动作：通风降温、衣被勿过厚、清凉饮食、多饮、口腔护理、观察津伤（口干、尿少、皮肤弹性）。边界：**虚寒者与脾胃弱者慎用寒凉饮食**；清热不能以伤脾胃为代价，尤其是老年与久病者。此外，热证出汗多，皮肤与床单的潮湿是压疮与皮炎的直接诱因，清凉的同时必须同步做皮肤护理。

**补（对虚证）。** 动作：减少连续活动、分段休息、饮食宜易消化、护脾胃、观察活动后反应。边界：**虚不受补**——纳差、腹胀、苔厚腻的人，先调脾胃再谈补；滋腻之品在痰湿与湿热未清时是负担。护理层面的「补」主要是**省力与护脾胃**，不是给补品。

**泻（对实证）。** 动作：观察排泄（大便性状与次数、小便量、汗、痰）、保证入量、皮肤清洁、腹部观察。边界：**泻下伤正**——老年、久病、孕产期的人，任何促进排泄的措施都要更谨慎，且必须在医嘱范围内。护士不做泻法，只做观察与配合。

四个方向共有一条时限纪律：**每次施护后必须复看主症方向。** 温法后看寒象退了没有、有没有转热；清法后看热势降了没有、有没有伤津；补法后看乏力改善了没有、有没有腹胀；泻法后看胀满减了没有、有没有乏力加重。**方向反了，立刻停并报告**——这是本章最重要的一条操作规则，比任何一条措施都重要。

## 三、兼夹与错杂：三条处理规则

临床上纯粹的单一证候是少数。教材在证候章末尾提到「兼夹情形的施护思路」，本章把它落成三条：

**规则一：先处理「急」的一端，再处理「本」的一端。** 虚人外感，先解表（急），表解后再调补（本）——但解表要轻，不可大汗。这条与《素问·标本病传论》「知标本者，万举万当」同源。

**规则二：寒热错杂时，看「哪一端在加重」。** 上热下寒的人，若口渴烦躁加重，先顾上热；若便溏肢冷加重，先顾下寒。不是「两方各取一半」的折中，而是**随动态选边**。

**规则三：虚实夹杂时，护虚为先，祛邪为辅。** 护理的动作里，凡耗力的（活动、体位变换、清洁）都要减量加频；凡观察的（汗、二便、精神、进食）都要加密。这条在老年与久病者身上几乎是通则。

三条规则共同的前提是：**护士不重新立法，只在医嘱与规范的框架内调顺序、调轻重、调频次。**

## 四、观察清单与记录字段：把「看什么」固定下来

证候章的核心技能在观察。教材给了大量观察要点，本章按证候收成一张可以挂在床尾的清单：

| 证候 | 必看项（每次巡视） | 变化信号（提示证在移动） |
|---|---|---|
| 表证 | 恶寒与否、汗出、体温、脉浮沉、头身痛 | 恶寒消失而热不退、脉转沉、咳喘加重 → 可能入里 |
| 寒证 | 手足温凉、腹痛喜按、便溏、舌色 | 手足转温、口渴出现、舌转红 → 寒化热 |
| 热证 | 体温、口渴、汗、尿色量、舌苔、精神状态 | 汗多而脉转细弱、精神萎顿、尿少 → 津伤或转虚 |
| 虚证 | 活动后气短、进食量、语声、脉力 | 腹胀、苔转厚腻 → 虚不受补，需调脾胃 |
| 实证 | 胀满、拒按、二便、苔厚薄 | 胀减而乏力明显 → 转虚，措施需减量 |

**记录字段**（每一条都必须能落到纸面）：

1. 观察时点与当时的活动状态（静息／活动后／进食后）；
2. 主症的量化描述（次数、性状、部位、程度用可比较的词，如「较昨日加重」）；
3. 舌与脉（注明光线条件与测量者）；
4. 本次施护的内容与起止时点（做了什么、做了多久的**相对**描述，具体参数依规范）；
5. 施护后复看的结果（方向对／无变化／反向）；
6. 报告对象与回应。

第 5 项最容易被省略，也最关键。**没有复看结果的记录，等于只记了「我做了」，没记「有没有用」。**

## 五、失效模式与考核项

**失效一：证变而护不变。** 表证已入里，仍在避风温覆；寒证已化热，仍在保暖。识别方法：把最近三次记录的主症排成一行，看方向；若主症方向变了而措施没变，即为失效。**这是本章第一号失效模式，也是「同病异护判错」的具体形态。**

**失效二：以病名代替证候。** 「他是感冒，按感冒护」——感冒有风寒、风热、暑湿，护法相反。病名是医生的产出，证候才是护理的开关。

**失效三：观察项写成了形容词。** 「精神可」「一般情况尚可」无法比较，也无法交班。合格写法必须带可比较的参照：「较昨日能自行坐起，语声较前提高」。

**失效四：漏掉「反向信号」。** 只记主症好转，不记新出现的变化。比如热证退热后出现乏力、脉细、汗多——这是转虚的信号，不记就漏。

**考核项：**

| 序号 | 考核项 | 合格线 |
|---|---|---|
| 1 | 给一个案例判定六个基本证候中的主证与兼夹 | 主证判据≥3 项，兼夹写出理由 |
| 2 | 为指定证候写出温/清/补/泻之一的四条动作及各一条边界 | 边界须写「什么情况下停」 |
| 3 | 说出该证候的三个「变化信号」及其对应的措施调整 | 信号与调整一一对应 |
| 4 | 完成一次施护后的复看记录（六字段齐全） | 含复看结果与方向判断 |
| 5 | 复算「观察 216／施护 78」并解释比例含义 | `python scripts/huli_chapter_stats.py 5` |

## 六、代价与边界

**丢掉了什么。** 六个基本证候是八纲的简化版，代价是**无法覆盖复合与传变**。真实病证里，卫气营血、三焦、六经的传变规律更细；本章的表格只能保证「不把方向搞反」，不能保证「跟得上传变」。遇到温病范围的病证，须回到相应课程的分期方法。

**数字的边界。** 「观察」216 次、「施护」78 次、「报告」50 次、「记录」134 次、「舌」18 次均为教材原文的字符串计数，出现即计。比例说明文本重心在观察，不说明临床上观察比施护更费力——恰恰相反，观察之所以被反复写，是因为它最容易做得潦草。

**方法的边界。** 本章的「四个方向」是按治法归的护理动作类别，不是中医治法的完整分类（汗、吐、下、和、温、清、消、补八法各有更细的分工）。护理不执行汗吐下，只在观察与配合层面参与，这一点不能含混。

**责任的边界。** 本章不写证候诊断标准、不写方药与剂量、不写任何操作参数与疗程。证候判断属护理评估范畴，由具备资质的护理人员依现行规范作出；诊断与用药由具备资质的医务人员作出；出现本章「变化信号」中的危急表现，一律立即报告，不自行处置。
