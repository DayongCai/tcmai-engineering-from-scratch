# 第 16 章 · 居家护理把观察权交给了不会写记录的家属

> **MOTTO:** 「医之治病也，一病而治各不同，皆愈，何也？」——《黄帝内经·素问·异法方宜论》
>
> **PROBLEM:** 本章原文 18,513 汉字里，「随访」52 次、「社区」49 次、「居家」46 次，三者构成全章骨架；「评价」61 次、「评估」48 次，而「辨证」只有 1 次、「施护」1 次。这个分布说明一件很具体的事：**社区与居家护理的正文几乎不谈辨证，谈的是「谁来跟、跟什么、什么时候必须回院」。** 教材假定辨证已在院内完成，这一章要解决的是「离开医院之后，判断链怎么不断」。可学生的默认想象仍是「把院内那套搬到家里」，于是最常见的失效是——宣教做完了，家属点头了，回家三天后出了问题，因为没人知道该看什么。
>
> **双根因定位:** 环境逼迫（院内的观察靠护士每班巡视，居家靠家属每天自看；家属没有受过观察训练，也没有记录习惯，而病情不会因为换了场地就变慢）+ 知识积累（教材把社区与居家合成一章，覆盖健康指导、慢病管理、康复、安宁疗护、家庭病床多个场景，共性的东西被写成了原则，落地的接口——「一句话的指令」与「一张红线的清单」——反而不多）

## 一、场景变了，判断链不变

院内到院外，变的是四件事，不变的是那条链。

| 项 | 院内 | 社区／居家 |
|---|---|---|
| 观察者 | 护士（受过训练、每班巡视） | 家属、照护者、患者本人 |
| 观察频次 | 按班次与病情 | 全天候但无结构，容易漏 |
| 信息回流 | 交班、记录、医嘱 | 电话、随访、复诊、微信群一类 |
| 出错后的容错 | 同班或下一班能补 | 常常到复诊才发现，已经晚了 |

**不变的三件事：** 一是**先看后判**——不管谁看，看的项要一样；二是**判断有边界**——家属不做判断，只做观察与报告；三是**留痕**——居家的「记录」可以是一张纸、一个本子、一条消息，但必须有。

所以这一章的核心任务可以一句话概括：**把院内的观察项，翻译成家属能执行的动作，并给出「什么时候必须回院」的清单。**

## 二、家庭评估：五看

第一次上门或第一次随访，评估的落点不是病，是**这个家能不能承接这份照护**。

**一看环境。** 地面是否平整防滑、有无门槛与电线、卫生间有无扶手、照明是否够（尤其夜间通道）、床高与床栏、通风与取暖、厨房与热源位置、有无宠物与过敏原。**改造建议要给具体的、便宜的、当天能做的**（移走地毯、加一个小夜灯、把常用物放到腰部高度），不是「建议适老化改造」。

**二看照护者。** 是谁？年龄与健康状况？是否全职？有没有第二个人可以轮换？会不会测体温、看皮肤、喂药？**照护者本人往往是隐藏的患者**——长期睡眠不足、腰背劳损、情绪耗竭，会直接反映在照护质量上。

**三看经济与交通。** 能否负担耗材与交通？到最近医院要多久、怎么去、夜间有没有车？这一项决定了「回院」这件事在现实中是否可行，也决定了红线清单要不要写得更保守。

**四看用药。** 把家里所有的药（含自购药、保健品、他人给的药）摊在桌上逐一核对：名称、用途、谁在吃、怎么吃、有没有重复。**居家最危险的用药问题不是吃错，是重复与漏服**，而这两项只有把药摊开才看得见。

**五看依从性与习惯。** 不问「能不能坚持」，问「昨天怎么做的」。饮食、活动、测量、服药四项各问一遍具体做法，比任何承诺都可靠。

## 三、把观察权交给家属：三句话与一张清单

家属能执行的只有具体动作。教材在「指导原则」里要求不作个体医学建议，落到操作上就是：**教动作、教判断的边界、不教诊断。**

**三句话的模板（每一项观察都按这个结构交代）：**

> 「**看什么**：每天早上看脚背和脚趾缝，有没有破皮、发红、起泡。
> **怎么算不对**：出现破皮、发红范围变大、有渗液，或者他说这里疼、麻。
> **然后做什么**：不要再泡脚、不要擦药，打电话给我们，我们安排你看医生。」

三句话缺一句就失效：只说「看什么」，家属看到了也不知道算不算问题；只说「不对就来」，家属不知道什么算不对；只说「然后做什么」而不说「不要做什么」，家属往往先自行处理，把问题弄复杂（泡脚、擦药、热敷是最常见的三种自行处理）。

**红线清单（居家版），出现任何一条，不等随访、立即联系：**

| 类别 | 具体表现 |
|---|---|
| 意识与精神 | 叫不醒、答非所问、突然极度烦躁或极度安静 |
| 呼吸 | 喘不上气、不能平躺、口唇发紫、说话断续 |
| 循环 | 冷汗、手脚冰凉、心慌、脉搏极快或极慢 |
| 出血 | 呕血、黑便、伤口渗血不止、咳血 |
| 排泄 | 一天没有小便、腹胀呕吐不排气 |
| 感染 | 发热伴寒战、伤口红肿扩大有异味 |
| 疼痛 | 突发剧痛、痛到出汗、痛的位置变了 |
| 外伤 | 跌倒后不能动、头部撞击后呕吐或嗜睡 |
| 用药 | 吃错药、吃多了、出现皮疹或肿胀 |
| 情志 | 说出不想活、拒绝进食饮水、伤害自己的举动 |

这张表要**写在纸上、贴在冰箱上**，不是口头说一遍。家属在慌乱时不会回忆电话里说过什么。

**居家的记录载体：一个本子加一部手机。** 本子记四项：日期时刻、看了什么、什么变化、做了什么。手机用于拍皮肤（同一部位、同一光线、同一距离，便于前后对比）与发送给随访护士。**照片要避开面部与可识别特征**，只拍局部；存于指定渠道，不留在个人相册与聊天记录里——这是居家场景中最容易被忽略的信息合规问题。

## 四、随访与转介：谁跟、跟什么、什么时候必须回院

**随访的三个层次：**

**第一层，电话或消息随访。** 适合稳定期。内容是四问：这两天怎么样（主症变化）、吃和睡怎么样、药有没有按时、有没有出现清单上的情况。**电话随访的局限要说清**——看不见皮肤、摸不到温度、听不出呼吸音，所以它只能筛，不能替代上门或复诊。

**第二层，上门随访。** 适合新出院、独居、照护者能力不足、有管路或伤口、行动不便者。上门必须做的四件事：看环境、看皮肤（要看到该看的部位）、核用药、演示一遍家属的操作并请其回做。

**第三层，复诊与转介。** 触发条件写在红线清单里；此外还有三类「不紧急但必须安排」的情形：症状持续不缓解、体重或进食量持续下降、照护者已无法承担。

**转介的四个方向：** 医疗（症状变化需诊治）、护理（技术操作与伤口管路）、康复（功能训练）、社会支持（照护资源、经济、心理）。**转介不是「推出去」，是「交到能接的人手上并留痕」**：转给谁、什么时候转的、对方有没有接、结果如何。

**一条纪律：随访要有下一次。** 每次随访结束必须约定下一次的时间与方式，并写入记录。没有下一次的随访，等于把患者放回了无人看管的状态。

## 五、失效模式与考核项

**失效一：宣教变成朗读。** 把院内那份注意事项念一遍，家属点头。识别方法：请家属**回做一遍**或**复述三句话**，做不到就是没教会。

**失效二：只教「做什么」，不教「不能做什么」。** 家属于是自行泡脚、热敷、按摩、加药——居家最常见的伤害都来自这四种「好心」。

**失效三：红线清单没落地。** 说了但没写、写了但没贴、贴了但家属不识字或看不清。**清单要按家属的识字与语言能力调整形式（图、颜色、语音）。**

**失效四：随访只问「还好吗」。** 得到「还好」，记录写「情况稳定」。这是把随访做成了确认仪式。

**失效五：转介断在「已告知」。** 告知了家属「要去医院看看」，但没有安排、没有跟进、没有留痕。

**考核项：**

| 序号 | 考核项 | 合格线 |
|---|---|---|
| 1 | 完成一次家庭评估（五看齐全） | 每看至少两项具体发现 |
| 2 | 把一项观察写成「三句话」并让家属复述 | 看什么、怎么算不对、然后做什么 |
| 3 | 为指定情形写一份不少于八条的红线清单 | 覆盖意识、呼吸、出血、排泄、用药 |
| 4 | 演示一次电话随访的四问 | 四问齐全，能识别出需要上门的信号 |
| 5 | 说出转介的四个方向及留痕要求 | 四方向齐全，含「对方是否接」 |
| 6 | 复算本章「随访 52、社区 49、居家 46」并解释 | `python scripts/huli_chapter_stats.py 16` |

## 六、代价与边界

**丢掉了什么。** 本章不给具体的随访频次、上门次数、电话间隔，也不给居家技术的操作参数。代价是**它不能直接变成一张随访排班表**——频次须依病情、机构制度与人力确定。本章给的是「跟什么」与「什么时候必须回院」，时序留给制度。

**数字的边界。** 「随访」52 次、「社区」49 次、「居家」46 次、「评估」48 次、「评价」61 次、「家属」20 次、「辨证」1 次、「施护」1 次均为教材原文的字符串计数，出现即计。「辨证」只 1 次，说明教材把辨证环节留在院内，本章承接的是执行与监测，不表示居家不需要辨证要素——家属报告的内容，正是院内复评的依据。

**方法的边界。** 「三句话」与「红线清单」是本章为落地所作的归纳，不是教材原文结构；不同病种、不同地区的清单内容应有差异，须由本机构按病种与资源条件制定。远程监测设备的使用、数据归属与隐私要求，依现行规范与机构制度。

**责任的边界。** 本章不写诊断、不写用药与剂量、不写操作参数。居家照护中，家属与照护者只做观察、执行与报告，不做判断与处置；涉及诊断、用药、技术操作的，由具备资质的人员作出或实施。上门服务须在执业范围与机构制度内进行。
