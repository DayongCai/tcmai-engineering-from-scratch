# 四诊的价值不在全，在于每一诊都能落成一个能被复核的字段

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 第一，护理问题
- 问题里必须带原因
- 第二，风险
- 第三，转介指向
- 评估不是把结论攒在自己手里，是把该给出去的信息及时给出去
- 神、色、形、态，再由整体到局部

## 边界

- 只写类别与要点，不写操作参数。
- 本章为教学整理，依据教材第 3 章（教材·第 3 章·第 1 节）编写，不构成诊疗意见或操作指导。四诊采集与记录须在受训并具备资质的人员指导下进行。
