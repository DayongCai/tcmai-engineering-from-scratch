# 四诊的价值不在全，在于每一诊都能落成一个能被复核的字段 · 提示词

## 用途

给「四诊的价值不在全，在于每一诊都能落成一个能被复核的字段」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「评估的产出物不是「资料」，是三条判断 → 望诊与闻诊：先整体，后局部，再对比 → 问诊：十问的顺序是为了不漏，不是为了背 → 切诊与归纳：护士的边界在哪」这条链。

```

正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
```

## 边界

本章为教学整理，依据教材第 3 章（教材·第 3 章·第 1 节）编写，不构成诊疗意见或操作指导。四诊采集与记录须在受训并具备资质的人员指导下进行；具体操作以现行规范与所在机构制度为准。
