# 第 3 章 · 四诊的价值不在全，在于每一诊都能落成一个能被复核的字段

> **MOTTO:** 「望以目察，闻以耳占，问以言审，切以指参。」——《医宗金鉴·四诊心法要诀》
>
> **PROBLEM:** 本章原文 17,267 汉字里，「问」出现 143 次，「记录」131 次，「评估」181 次，而「辨证」只有 25 次、「施护」10 次。三组数字把评估章的真实任务暴露得很清楚：它是**全书唯一以「采集与留痕」为主业的章节**，产出不是一个证名，而是一份别人能照着复核的资料。可学生往往把它学成「四诊知识复习课」——把望闻问切的概念再背一遍，却答不出「这份评估记完之后，下一位护士能据此做出同一个判断吗」。本章按「采集—归纳—记录—复核」四个动作重写这一章。
>
> **双根因定位:** 环境逼迫（评估发生在入院最初那段时间里，问诊是唯一能在几分钟内铺开的信息面，所以教材 143 次「问」压过 27 次「望」；而记录一旦写错，后面所有施护都在错误前提上执行，且无法追溯）+ 知识积累（教材把评估写成了一套流程，但流程的真正产出是「护理问题清单」——这条从要素到问题再到记录的转换，教材写得很细却分散，需要在这里收成一条线）

## 一、评估的产出物不是「资料」，是三条判断

很多人以为评估就是把资料收集齐。收集齐只是过程。一份合格的评估必须交出三样东西：

**第一，护理问题。** 不是疾病诊断，是「这个人的哪一个需要没有被满足」。写法上要具体到可干预：不是「营养失调」，而是「近三日进食量明显减少，因口腔疼痛咀嚼受限」。**问题里必须带原因**，否则措施无从下手。

**第二，风险。** 跌倒、压疮、误吸、烫伤、走失、自伤、用药相关风险。风险项的价值在于它必须触发一条具体措施，不触发措施的风险评估等于填表。

**第三，转介指向。** 哪些发现超出了护理范围，必须报告给谁。教材把这一条写得很克制——「凡涉及诊断的判断由具备资质的医务人员作出」——但它是评估的红线：**评估不是把结论攒在自己手里，是把该给出去的信息及时给出去。**

三条判断之外的一切资料，都只是支撑材料。记不住这个层级关系，评估就会变成抄写。

## 二、望诊与闻诊：先整体，后局部，再对比

望诊的顺序有讲究，顺序错了会漏。教材给的次序是**神、色、形、态，再由整体到局部**，本章把它落成一张采集单：

| 层次 | 看什么 | 常见漏项 |
|---|---|---|
| 神 | 得神、少神、烦躁、淡漠、嗜睡、昏迷倾向；眼神、应答反应 | 只写「神清」，不写反应速度与配合度 |
| 色 | 面色（淡白、萎黄、潮红、晦暗、青紫）、唇色、爪甲色 | 不写光泽（有华/无华），只看颜色 |
| 形 | 胖瘦、浮肿、腹部膨隆、肌肉厚薄、脊柱四肢形态 | 不量不问，凭印象写「消瘦」 |
| 态 | 体位（自主体位/被迫体位/蜷卧）、步态、有无震颤、动作是否受限 | 不写体位与主症的关系 |
| 局部 | 舌（质、色、形、苔、润燥）、皮肤（色泽、完整性、温度、湿度）、头面五官、二便与排出物 | 舌象受光线与饮食影响，不注明条件 |

**望诊的三个技术条件**，缺一个结论就不可靠：自然光或接近自然光的光源（荧光灯下黄苔会失真）；患者处于自然状态（刚活动完、刚进食、刚饮水都会改变面色与舌象）；暴露充分但不失隐私（看皮肤要看到该看的部位，同时遮挡不该暴露的部位——这两件事同时做到才算合格）。

闻诊在护理里被严重低估。它分两半：**听声音**（语声高低强弱、呼吸粗细与节律、咳声、呃逆、肠鸣、呻吟）与**嗅气味**（口气、痰、涕、二便、伤口、呼出气）。嗅气味这一项在记录里几乎消失，但它是极早期的线索：伤口敷料下的甜腥味、尿液的特殊气味、口气的酸腐与氨味，都能在指标变化之前出现。记录要求是**写事实、不写推测**：「伤口敷料揭开后有甜腥气」，而不是「疑感染」。

## 三、问诊：十问的顺序是为了不漏，不是为了背

教材给了十问的经典次序：寒热、汗、头身、饮食、二便、胸腹、耳目、睡眠、情志、既往（女性加经带胎产）。这个次序的价值是**不漏项**，不是仪式。

| 问什么 | 关键追问（决定寒热虚实的分岔） |
|---|---|
| 寒热 | 恶寒与发热是同时还是先后？恶寒加不加衣被能缓解？午后是否潮热？ |
| 汗 | 有汗无汗？自汗盗汗？汗出部位？汗后是否更乏力？ |
| 头身 | 痛的部位与性质（胀、空、刺、重）？与体位、情绪、进食的关系？ |
| 饮食 | 想不想吃（食欲）与能不能吃（咀嚼吞咽）分开问；喜温喜冷；食后腹胀？ |
| 二便 | 次数、性状、颜色、有无费力与不尽感；夜尿几次；有无失禁 |
| 睡眠 | 入睡难、易醒、早醒、多梦；睡前习惯；白天是否补睡 |
| 情志 | 近期有无重大变故；情绪变化的时点与诱因；有无消极言语 |
| 既往与用药 | 基础病、手术史、过敏史、正在服用的药（含自购药与保健品） |

**问诊的三条纪律：**

**一、不许诱导。** 「你是不是觉得冷？」会得到「嗯」。正确问法是「你现在觉得冷、热，还是不觉得？」——开放式提问，选项给全。

**二、先开放后封闭。** 先让患者叙述（「哪里最不舒服？」），再用封闭问题确认细节（「是胀还是刺痛？」）。反过来问，患者只会回答你给的两个选项。

**三、缺项要留痕。** 患者说不清、家属代诉、意识不清无法作答——这些不是空白，是**必须写下来的信息**。记录里写「问诊时嗜睡，仅能点头应答，余由家属代诉」，比留空安全得多。

## 四、切诊与归纳：护士的边界在哪

切诊在护士手里主要是三件事：**脉、肌肤、按诊**。

脉：位（浮沉）、数（快慢）、形（粗细弦滑）、势（有力无力）。护士的记录要求是**写描述、不写自拟脉名**——「脉细而数，按之无力」可以，「脉虚数」要看是否在本院规范允许的表述范围内。脉象判断受操作者经验影响极大，两个人摸出不同结论是常态，所以记录里要写「由谁在何时测得」，必要时双人复核。

肌肤：温凉、润燥、有无水肿与凹陷程度、有无汗。按诊：脘腹的软硬、压痛与反跳痛、包块的有无与活动度。**按诊有一条硬边界：急腹症表现（压痛固定、反跳痛、腹肌紧张）不禁忌按，但按完必须立即报告，不得反复按压。**

归纳这一步，教材的处理是把四诊要素收进八纲与脏腑，再归成护理问题的类别：

| 归类型别 | 由哪些要素触发 |
|---|---|
| 呼吸与气体交换 | 咳、痰、喘、气短、不能平卧、口唇紫 |
| 饮食与营养 | 食欲下降、咀嚼吞咽困难、食后腹胀、体重变化 |
| 排泄 | 便秘、泄泻、尿潴留、尿失禁、失禁性皮炎风险 |
| 活动与休息 | 乏力、活动后气短、失眠、被迫体位 |
| 皮肤完整性 | 水肿、消瘦、潮湿、感觉减退、已有破损 |
| 安全与风险 | 跌倒、误吸、烫伤、管路、走失、自伤 |
| 情志与沟通 | 焦虑、低落、拒绝交流、语言不通 |

一张表的作用不是让你给患者贴类，是让你**检查有没有漏问**：七类里哪一类没有任何资料，就回去补问。

## 五、记录、复核与失效模式

记录的字段，教材要求「真实、客观、及时、完整、规范、可追溯」。落到可操作的层面，一份中医护理评估记录至少要能回答六个问题：

1. **谁**——患者身份核对方式（姓名加另一种标识，不用床号）；
2. **何时**——采集时间，与症状出现时间的先后；
3. **谁采的**——签名，代诉者与代诉关系；
4. **采到什么**——四诊要素，写现象不写结论；
5. **判断是什么**——护理问题与风险，带原因；
6. **给出去没有**——报告给谁、几点、回应是什么。

**失效模式一：把评估做成一次性动作。** 入院评完就锁进病历，之后病情变了不更新。识别方法很简单：对比最近一次评估与最近一次交班记录，若主症已经变了而评估项没动，就是失效。

**失效模式二：记录写成结论的堆叠。** 「患者一般情况可，舌红少苔，脉细数，属阴虚，予相应护理」——一句话里有三个问题：结论先行、要素不全、措施无具体内容。复核者无法据此重建判断。

**失效模式三：把「未查」写成「正常」。** 没问二便，记录里留空；没看皮肤，写「皮肤完好」。这是评估里最危险的失效，因为它把缺口伪装成了阴性结果。

**考核项：**

| 序号 | 考核项 | 合格线 |
|---|---|---|
| 1 | 对标准化病人完成一次完整评估，填满七类归类型别 | 每类都有资料，缺项注明拒答或无法采集 |
| 2 | 按十问顺序问诊，全程不使用诱导性提问 | 由带教现场判定，出现一次即不合格 |
| 3 | 写出三条护理问题，每条带原因与一条具体措施 | 问题、原因、措施一一对应 |
| 4 | 指出案例中必须立即报告的至少两项发现 | 不含「观察后再定」 |
| 5 | 按六要素复述一份记录的完整性 | 六项齐全；复算本章词频 `python scripts/huli_chapter_stats.py 3` |

## 六、代价与边界

**丢掉了什么。** 把四诊压成「字段清单」，代价是**感知训练被压缩**。真正的望诊与脉诊靠大量重复才能形成稳定判断，本章的表格只能保证你不漏项，不能保证你摸得准。教材同样只到「要点类别」，把「摸得准」留给实训与临床带教——这是本课程结构上的一处自觉留白。

**数字的边界。** 「问」143 次、「记录」131 次、「评估」181 次、「辨证」25 次是教材原文的字符串计数，口径为出现即计，含「评估」作为动词与名词的两种用法。它说明本章重心在采集与留痕，不说明问诊在临床上比望诊更重要。

**方法的边界。** 十问是通行次序，不是唯一次序；急症、儿科、老年、意识障碍者的问诊路径都不同，第 8 章会给出儿科与老年的替代路径（代诉、观察替代、家属补充）。本章的表格以能配合的成人为默认对象。

**责任的边界。** 本章不写诊断标准、不写脉象数值判读、不写任何处置。评估结论中的诊断性判断由具备资质的医务人员作出；护理问题的认定由具备资质的护理人员依现行规范作出；超出范围的一律转介并留痕。
本章可直接验证：`node code/main.js` 打印结构清点与判据清单（数字从 `docs/zh.md` 现算），`node --test code/main.test.js` 跑本章单测；两条命令只读正文与代码，不写任何文件。
