## 一、学科定位

中医护理学（TCM Nursing）是护理系的核心学科，聚焦「中医护理特色技术 + 现代护理全科能力」中的一个完整知识域。

## 二、中医 → AI 桥梁

```text
辨证施护→规则+ML / 中医护理技术→操作本体
```

中医护理学 里的每一个传统概念，都被翻译成一个可计算、可验证的工程对象：
中医概念给出**语义与约束**，AI/工程方法给出**表示与算法**。两者必须能互相回指，
否则这个章节就还没有写完。

**口径**

1. **三辨＝辨证／施护／评价与记录**，实测 **1365 / 4432 / 4459**，比值 **3.3×**——**辨证词只有施护词的三分之一**，护理教材的重心在「做」不在「辨」；
2. **四位面取技术类别 5.9×**（灸法与拔罐 149 / 刮痧推拿与穴位 162 / 中药外治与熏洗 162 / 饮食与情志 880）；
3. **施护场所 54.6× 未取**：门诊与急诊只有 7 次，54.6× 是**缺项**不是分类轴——教材几乎不写门诊场景，取它会把这门课写成「病房 + 居家」两极；**病证系统 21.8× 未取**：「基础与技术」1,504 次是篇幅结构（18 章里 9 章是总论），不是病证分布。

**跨课对账（护理 × 中药）——两条几乎不交的线**

| 词类 | 密度（每万字） | 相对药名 |
|---|--:|--:|
| 药名（287 味命中 2） | 0.06 | 1× |
| 技术词 | 10.1 | 约 168× |
| 文书词 | 141.1 | 约 2352× |

**结论**：这门课的文本重心在「观察—记录—核对」，不在药，也不在技术动作本身。**但「不点药名」不等于「不讲药」**——第 12/13 章讲的是「怎么用」，不是「用什么」。

**一处口径**：全册 **操作参数（分钟/壮/次/cm/度）近乎为零**，出现的数字主要是章号、节号与年代。教材讲「做什么、为什么、什么情况不能做」，把「做多久、做几次」留给各院校操作规范——**读这本教材要自觉去别处找参数**。
