## 四、这门课的风险判据

气功课与其他课最不同的地方：**读者会自己练**。所以每章都要求写清三件事：
①这个功法**禁用于什么状态**（急性期、精神疾病、严重心肺疾病等）②出现什么反应必须**立即停**
（头晕、心悸、气促、情绪失控）③找谁处理（第 3 章流程：停功 → 记录 → 就医）。
