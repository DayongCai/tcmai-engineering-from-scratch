## 一、这门课没有教材

本库无《针灸毕设》教材；六环节由《经络腧穴学》《经络学》与护理系《护理研究与循证护理》的对应单元派生；每章再挂一条 `standards/biye` 的**真实台账锚点**，数字逐字可查，**不编校名、不编人名、不编「某届学生」**。

针灸毕设最容易停在「我做了 30 例，效果不错」。要往前走一步，就得把配穴方案写成**可检验的比较**（跟什么比、比哪个结局、多久看结果）。
