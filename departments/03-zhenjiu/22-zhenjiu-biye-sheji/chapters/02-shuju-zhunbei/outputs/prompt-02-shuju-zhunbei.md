# 一份病例表的价值不在字段多，而在换个人能照着扎回同一个位置 · 提示词

## 用途

给「一份病例表的价值不在字段多，而在换个人能照着扎回同一个位置」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三类最容易丢的数据，和十行模板的对照 → 定位写成第二个人能照做：四法各留什么字段 → 刺激量与得气：写可核对的数，不写"良好" → 谁在评、什么时候评、谁没做完」这条链。

## 边界

本章为毕业设计教学材料，不构成医学意见、诊断或治疗指导，也不替代伦理委员会与导师的决定。涉及人的研究须先取得伦理审批并在每一例入组前完成知情同意，未获批准或未签同意书者不得采集数据；具体操作以现行规范与所在机构制度为准。
