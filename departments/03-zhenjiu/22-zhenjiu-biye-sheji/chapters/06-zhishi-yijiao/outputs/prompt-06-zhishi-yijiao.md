# 手册写得再全也移不走手感，移交完成的标志是别人照它做出来 · 提示词

## 用途

给「手册写得再全也移不走手感，移交完成的标志是别人照它做出来」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「来路：254 处书名号为什么属于移交清单 → 逐穴一节：把能量化的写到极致 → 不可写项：标出来，配带教，别假装写清了 → 复现验证：三个人、两次、两版」这条链。

## 边界

本章为毕业设计教学材料，不构成医学意见、诊断或治疗指导。移交涉及的原始记录含个人信息与敏感健康信息：病例表、量表原件、影像与知情同意书须去标识后归档，可还原身份的对照表单独存放并限定访问人，交接与借阅须登记；具体操作以现行规范与所在机构制度为准。
