# 采集工具只做四件事，多做的每一件都要从招募窗口里扣时间 · 提示词

## 用途

给「采集工具只做四件事，多做的每一件都要从招募窗口里扣时间」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「底本七节示范的其实是"口径"，不是"系统" → 功能清单只留四项，其余写进不做 → 字段映射与四项校验：错误在这一步拦下，不然要等到分析 → 兜底、备份与留痕：三种故障，各写一页纸」这条链。
