# 论文的说服力来自十个能复算的数字，不来自十页漂亮的讨论 · 提示词

## 用途

给「论文的说服力来自十个能复算的数字，不来自十页漂亮的讨论」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「一头一尾：引文在底本里，数字在你的表里 → 十个数字：定稿前唯一的硬检查 → 讨论不是复述，是与三篇文献对位置 → 四类质疑与两轮试讲」这条链。

```
我在学《针灸毕业设计与知识移交》第 5 章「论文的说服力来自十个能复算的数字，不来自十页漂亮的讨论」，本章 6 节 / 2,974 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 本课不给歌赋原文
   - 本课不给你的结果
   - 本课不给评分权重之外的细则
   - 不宣称任何疗效

4. 本章自陈的边界（不得越过）：
   - **本课不给歌赋原文**：5,622 字的歌诀在底本单元层里逐字可查，本课不复刻——引文必须回到你所用的版本，韵文差一字就是错引。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为毕业设计教学材料，不构成医学意见、诊断或治疗指导。论文若涉及人的研究，须已取得伦理审批并在文中如实写明批件编号与知情同意的实施方式，未获批准或未完成知情同意的数据不得进入结果；具体操作以现行规范与所在机构制度为准。
