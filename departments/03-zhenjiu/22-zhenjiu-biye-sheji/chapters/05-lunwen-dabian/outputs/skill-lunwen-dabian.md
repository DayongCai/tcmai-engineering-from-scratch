# 论文的说服力来自十个能复算的数字，不来自十页漂亮的讨论

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 本课不给歌赋原文
- 本课不给你的结果
- 本课不给评分权重之外的细则
- 不宣称任何疗效
- 引文规范到篇名为止
- 不替代专业判断

## 边界

- **本课不给歌赋原文**：5,622 字的歌诀在底本单元层里逐字可查，本课不复刻——引文必须回到你所用的版本，韵文差一字就是错引。
- **本课不给你的结果**：正文里没有一个真实病例、组间差、区间或 P 值；那些数只能从你自己的数据表里现算。本课替你先写一个"示例结果"，只会让你在答辩现场被问穿。
- **本课不给评分权重之外的细则**：30／25／20／25 出自底本 H.7，具体扣分项由答辩委员会依所在学院规范执行。
- 本章为毕业设计教学材料，不构成医学意见、诊断或治疗指导。论文若涉及人的研究，须已取得伦理审批并在文中如实写明批件编号与知情同意的实施方式，未获批准或未完成知情同意的数据不得进入结果。
