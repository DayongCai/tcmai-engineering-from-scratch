## 一、学科定位

腧穴学（Acupoint Theory）是针灸系的核心学科，聚焦「经络腧穴—刺法灸法—针灸治疗 与推拿康复的完整链条」中的一个完整知识域。

## 二、中医 → AI 桥梁

```text
腧穴定位→三维坐标 / 取穴→KD-Tree 最近邻
```

腧穴学 里的每一个传统概念，都被翻译成一个可计算、可验证的工程对象：
中医概念给出**语义与约束**，AI/工程方法给出**表示与算法**。两者必须能互相回指，
否则这个章节就还没有写完。

**口径**

1. **一穴一条**，与《经络学》的「一小节一条」并存：前者用于按穴算（穴位表、特定穴统计、安全红线），后者用于词频与规模统计；
2. **教材有四种穴位写法**（`穴名 Pinyin（LU1）`＋【字段】式／`1.穴名（Pinyin，LI1）`＋「字段：」式／带中文序号式／背俞穴叙述式），
   解析统一锚在「**穴名（…编号）**」上——**漏认一种，就只剩第一条经**（首次实测 11 穴→修正后 270 穴）；
3. **部位由【定位】文字判定**（头面颈项/胸腹/背腰/四肢），跨部位的穴取命中最多的一个，是简化，误差已计入正文「数字的边界」；
4. **安全红线**只收教材明写「不可怎样刺/以免伤及…」的原句，共 44 穴；不推断、不补写。

## 八、全经穴库（外源补源：GB/T 12346-2021）

教材只讲重点穴，所以 `穴位库.json` 是 **270 穴**（经穴 253、奇穴 17）。第 9 章要按全经穴统计，缺的 109 穴用国标补齐。

**补源约定（与《伤寒》外源补条同一套规则）**

| 项 | 内容 |
|---|---|
| 来源 | GB/T 12346-2021《经穴名称与定位》，发布页 openstd.samr.gov.cn |
| 官方 PDF | `standards/shuxue/sources/GB-T-12346-2021.pdf`（1.19 MB） |
| sha256 | `777643c116fb3cd543a6a632a3ad36c4bfbedd8880aced0c6979a877694d7692`（与来源页记录一致，已核） |
| 抓取 | 2026-11-03T21:37:13 |
| 范围 | 第 5 章「经穴名称与定位」；第 3.6 节基准穴点为重复条目，不重复计入 |

**三层文件，互不覆盖**

| 文件 | 内容 |
|---|---|
| `穴位库.json` | 教材层，270 穴，**不改** |
| `穴位库-国标.json` | 国标层，**362** 条（361 经穴 ＋ 印堂 GV24+） |
| `穴位库-全经穴.json` | 合并视图 **362** 条：教材 253 ＋ 外源 109，逐条标 `来源` |
| `补源登记.json` | sha256 ＋ URL ＋ 校勘结果 ＋ 条款页码索引 |

**凡外源，locator 必写成「外源·GB/T 12346-2021 第X.X.X条」**，与「教材·第N章·X.X.X」分列，不混入底本统计。

**校勘结果（实测）**

| 项 | 值 |
|---|---|
| 匹配（同编号） | **253** |
| 外源补入 | **109** |
| 教材有、国标无 | 0 |
| 名称不一致 | **2**（ST35 教材「眼即犊鼻」多字；TE11 教材「清冷渊」／国标「清泠渊」） |
| 定位覆盖 ≥0.90 | 67 |
| 定位覆盖 0.75–0.90 | 66 |
| 定位覆盖 <0.75（需人工核） | 53 |

低档多为背俞穴：教材「旁开 1.5 寸」vs 国标「后正中线旁开 1.5 寸」并附注——**措辞长度差，不是定位冲突**。本库不自动改写任何一方，两个定位并列存。

**补完之后仍然缺的：特定穴分类**

362 穴中带特定穴标注的只有 **102** 条（**28.2%**）：井 11／荥 10／输 2／经 8／合 9／原 9／络 8／郄 11／募 7／背俞 10／八会 8／八脉交会 7／下合 2。

国标只规定名称与定位，不标类别。**「补齐 109 穴」补的是条目，不是分类**——所以第 9 章能算「每经几穴」，
不能算「五输穴共 60 穴」这类全量判断（输穴只有 2 条，明显是教材只点了重点穴）。
