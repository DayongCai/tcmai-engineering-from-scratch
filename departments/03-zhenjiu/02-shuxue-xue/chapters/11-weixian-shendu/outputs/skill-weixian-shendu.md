# weixian-shendu

## 何时使用

- 带教时，学生第一次独立处理风池、肺俞、人迎、肩井等危险穴位
- 病例讨论需要把「为什么这个深度不能刺」写成可复述的依据
- 操作记录里需要留一条安全复核痕迹

## 不适用

- 决定治疗方案（本技能不做治疗建议）
- 婴幼儿、极度消瘦或肥胖者的个体化深度（需要影像测量）
- 抗凝、肺大疱、妊娠等特殊人群的最终决定（必须上级医师）

## 步骤

1. **填四要素**：穴位、体型（BMI 或身高体重）、方向、计划深度。
2. **方向闸门**：方向指向颅腔/胸腔/大血管/神经干 → 直接「禁止」，不受深度影响。
3. **深度闸门**：上限 = 教材参考深度 × 体型系数；达到 80% 报「警告」，超过报「禁止」。
4. **特殊人群**：命中任一特殊情况 → 「需上级决定」（一票否决）。
5. **写未知项**：列出模型不知道的东西（解剖变异、呼吸时相、体位、既往并发症）。

## 输出模板

```text
【结论】允许 / 警告 / 禁止 / 需上级决定
【依据】
  方向：<安全 / 命中禁令：…>
  深度：计划 <..> 寸，上限 <..> 寸（来源：教材参考 × 体型系数 <..>）
  特殊：<无 / …>
【未知项】…
【提示】允许不等于安全。
```

## 质量判据

- 「禁止」的理由必须写出可能伤及的结构
- 「允许」必须同时出现「允许不等于安全」的提示
- 上限来源必须标注「教材参考值」或「实测值」，不得含糊

> 本技能输出为教学与复核辅助，不构成操作参数或诊疗建议。
