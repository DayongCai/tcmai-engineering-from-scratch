# 第 11 章 · 危险穴位与针刺安全深度：把「不可深刺」变成一道可算的闸门

> **MOTTO:** 「刺缺盆中内陷，气泄，令人喘咳逆。」——《素问·刺禁论》
>
> **PROBLEM:** 教材上写着「风池向鼻尖方向刺 0.8–1.2 寸，不可向内上方深刺」，你记住了这句话，却说不清「多深算深」、也说不清同一个穴位在胖人和瘦人身上为什么不是同一个数。

> **双根因定位:** 环境逼迫(进针时没人替你算深度，手感也不可靠) + 知识积累(解剖 × 分段线性模型 = 一个按体型给上限、越界就报错的校验器)

## 学习目标

- 说清「安全深度」不是一个固定数字，而是由**穴位局部解剖 + 体型**共同决定的区间上界
- 用分段线性函数把 BMI 映射成软组织厚度系数，并解释为什么不用线性外推
- 实现一个进针前校验器：给定穴位、体型、进针方向与计划深度，返回「允许 / 警告 / 禁止」
- 指出这个模型在哪些情况下**必须由人来否决**

## 核心概念

### 中医：刺禁的位置与方向

《素问·刺禁论》把危险穴位写成后果，而不是写成数字：「刺缺盆中内陷，气泄，令人喘咳逆」「刺脊间中髓，为伛」。后世《针灸甲乙经》把这些部位逐一落到具体穴名。教材于是给出「深度 + 方向 + 禁忌」三件套，但深度给的是**成人中等体型**的参考值。

临床上真正决定风险的是三件事：针尖到重要结构（肺、血管、脊髓、神经干）的距离、进针方向、以及病人当时的体位与呼吸时相。三件事里没有一件是「寸」能单独表达的。

### AI/工程：分段线性 + 方向向量

把安全深度写成

$$d_{\max}(h, \text{BMI}) = d_0 \cdot k(\text{BMI})$$

$k$ 按体型分四档：BMI < 18.5 取 0.8；18.5 ≤ BMI < 24 取 1.0；24 ≤ BMI < 28 取 1.25；BMI ≥ 28 取 1.4。

再乘方向惩罚：向内上方进针（朝颅腔/胸腔）时 $d_{\max}$ 直接置零——这不是「更深」，而是**方向本身禁止**。这一步是本课的重点：把「方向」从注释里提出来，变成可执行的分支。

## 代价与边界

- **系数不是测量出来的**。0.8/1.0/1.25/1.4 是按经验给的分段值，没有影像学标定。换成真实数据，这些数会变，而变的方向未知。
- **BMI 只是体型的粗代理**。同样 BMI 的两个人，颈部皮下脂肪可以差一倍；超声测软组织厚度才是正解，本课没有这个条件。
- **不建模呼吸时相与体位**。肺俞在深吸气时肺膨胀，风险高于呼气末——模型对此一无所知。
- **它只能拦「明显越界」，拦不住「合规但出事」**。允许不等于安全，这个差别必须在界面上写明，否则校验器会制造虚假的安心感。

> **免责声明：** 本章的深度系数为教学示例，不是临床操作参数，不构成针刺操作依据。任何针刺操作须由具备资质的执业医师依据解剖、影像与现场判断执行；出现气胸、血肿等并发症须立即按急症处理。

## 练习

1. 把 BMI 分段改成连续函数（如 logistic），观察在 24 与 28 附近的行为差异，说明分段的好处。
2. 为「肩井」补一条禁忌：为什么孕妇禁针，这个理由能否写进同一个数据结构？
3. 如果让模型输出「建议深度区间」而不是单一上限，界面应该怎么提示，才不会被当成许可？

## 进阶思考

安全校验器的价值不在它拦住了多少次，而在它是否让人**在进针前多看一眼方向**。一个只在深度上报警、却对方向沉默的系统，会把最危险的错误留在外面。
