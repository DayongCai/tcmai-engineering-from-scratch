# 穴名、归经与定位是三套索引，没有一套能单独指认一个穴 · 提示词

## 用途

给「穴名、归经与定位是三套索引，没有一套能单独指认一个穴」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「指认一个穴，需要三条互不推导的记录 → 三类的分界不在「有没有名字」 → 命名的六类取义，是定位信息的压缩包 → 数目的变动说明「穴」是被筛出来的」这条链。
