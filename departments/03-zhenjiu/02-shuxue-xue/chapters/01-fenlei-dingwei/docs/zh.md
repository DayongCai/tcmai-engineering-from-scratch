# 第 1 章 · 穴名、归经与定位是三套索引，没有一套能单独指认一个穴

> **MOTTO:** 「所言节者，神气之所游行出入也」——《灵枢·九针十二原》
>
> **PROBLEM:** 教材一面引《内经》「三百六十五穴」之数，一面把历代定穴写成 349（《针灸甲乙经》）、354（《铜人腧穴针灸图经》）、359（《针灸大成》）、361（GB/T 12346—2006）、362（2008 年印堂归督）。同一种东西，数目先降后升：从 365 降到 349，少了十六；再一路回升到 362，仍未回到原数。若「穴」真是身上一个固定的点，这个数字为什么会变？

**双根因定位:** 环境逼迫（针要落在活人身上，位置必须能被第二个人摸到同一处，穴名与坐标因此被迫归一化，否则无法教学、无法会诊、无法追责）+ 知识积累（从《甲乙经》到国标，每一代做的都是同一件事：把口传的位置写成分寸，把方士的别名收进经脉，把有效的经验点升格为经穴）

**教材出处:** 教材·第2章·2.1.1（腧穴的概念）、2.1.2（腧穴的分类）、2.2.1（命名方法）

## 一、指认一个穴，需要三条互不推导的记录

教材开篇先辨字：「腧」是统称，「输」是五输穴中的第三个，「俞」专指背俞穴。三个字今天分工明确，却同出一源，都取「转输、输注」之义。这一节看似训诂，实际定下了本章的第一条规矩——**穴名、归经、定位是三条独立的记录，任何一条都不能代替另外两条。**

三条记录各自回答一个问题。名回答「叫什么」，经回答「归谁管」，位回答「在哪里」。三者之间没有推导关系。知道名字推不出位置：「伏兔」听起来在腿上，但腿的范围太大；知道归经也推不出位置：一条经从指端走到头面，沿途数十穴，经只给出顺序，不给出坐标；知道位置同样推不出归经：同一个凹陷，可能是本经穴，也可能是别经的交会，还可能是没有归经的奇穴。教材把腧穴定义为「脏腑经络之气输注于体表的特殊部位」，这句话同时给了三个层次——气（功能）、经络（归属）、体表（位置），三者并列，不是递进。

所以"这个穴在哪儿"这个问题，严格说需要三句回答：它在哪条经上，它在体表什么标志的什么方位，它叫什么。少一句，临床上就会出岔子：只报穴名，对方可能记成别经的同名穴；只报位置，对方无法判断该不该用；只报归经，等于什么都没说。

## 二、三类的分界不在「有没有名字」

教材把腧穴分为十四经穴、经外奇穴、阿是穴三类。常见的误读是按「重要程度」排：经穴最重要，奇穴次之，阿是穴最次。这是按临床使用频率排的，不是按定义排的。教材的定义用的是另一把尺子——**归不归经**。

十四经穴：有固定名称、固定位置，且归属于十四经脉系统。经外奇穴：有固定名称、有明确位置，但尚未归入或不便归入十四经脉系统。阿是穴：既无固定名称，也无固定位置，以压痛点或反应点为施术部位。三类的差别集中在两列：名与位，经穴和奇穴都有，阿是穴都没有；归经，只有经穴有。

这条分界是行政性的，不是解剖性的，教材自己给了证据：膏肓、风市「早期曾列于奇穴」，后来因疗效显著、定位明确而归入经穴。同一具身体上的同一个点，昨天是奇穴，今天是经穴，变的不是解剖结构，是它有没有被写进经脉目录。反过来，降压穴、安眠穴这类临床新用的点，是不断被补充进奇穴的。**分类记录的是收录状态，不是身体的属性。**

阿是穴最能说明这一点。教材引《备急千金要方》：「有阿是之法，言人有病痛，即令捏其上，若里当其处，不问孔穴，即得便快成痛处，即云阿是，灸刺皆验。」又引《灵枢·经筋》：「以知为数，以痛为输。」两句话合起来，给的是一套与经穴完全相反的操作：不问穴名，只问按下去的反应。它不是"还没被命名的新穴"，而是刻意不命名的取穴法——因为痛处会移动，命名反而会把它钉死。

## 三、命名的六类取义，是定位信息的压缩包

教材把命名法分为六类：按所在部位（腕骨、乳根、颧髎、大椎、肩髃）、按治疗作用（睛明、光明、水分、水道、牵正、陶道）、按天体地貌（日月、上星、承山、大陵、商丘、丘墟、太溪、合谷、水沟、曲泽、曲池、涌泉、小海、四渎）、按动植物（伏兔、鱼际、犊鼻、鹤顶、攒竹、口禾髎）、按建筑物（天井、印堂、巨阙、屋翳、膺窗、库房、地仓、气户、梁门）、按中医理论（阴陵泉、阳陵泉、心俞、胃俞、三阴交、三阳络、百会、气海、血海）。

六类里只有第一类是坐标，其余五类都是比喻。这个比例值得注意：教材举出的穴名，绝大多数并不告诉你"在哪里"，而告诉你"像什么"或"治什么"。比喻之所以能当记忆钩子，是因为它抓住了一个可辨认的形态特征：伏兔取大腿前外侧肌肉隆起如兔伏之状，犊鼻取膝前外侧凹陷形如牛犊之鼻，印堂取两眉之间形如堂屋匾额。**比喻描述的是形状，不是方位。**

由此得出一条使用规则：穴名可以用来回忆，不能用来定位。把「伏兔」理解成"兔子的位置"、把「犊鼻」理解成"鼻子的位置"，是把喻体当成了坐标，这是初学者最常犯的一类错误，而且错得很自信——因为名字太形象，形象到让人以为已经知道了。

教材还提示，命名与主治常有关联：以脏腑命名的（心俞、肝俞、胃俞），主治多与相应脏腑相关；以治疗作用命名的（睛明、光明、牵正），主治方向一目了然；以气血命名的（气海、血海、气户），多与气血输布有关。这层关联是真知识，但它只是统计倾向，不是承诺：带「俞」字的穴不一定都治该脏，带「海」字的穴也不一定都主气血。把它当提示，可以少背一半；把它当规则，就会在第一个例外上翻车。

## 四、数目的变动说明「穴」是被筛出来的

把教材散见的数字并成一条线，脉络就清楚了。

| 出处 | 定穴数 | 性质 |
|---|---:|---|
| 《黄帝内经》 | 365 | 应周天之数，非实数 |
| 《针灸甲乙经》 | 349 | 现存最早腧穴专书厘定 |
| 《铜人腧穴针灸图经》 | 354 | 铸铜人、创归经规范 |
| 《针灸大成》 | 359 | 明代集大成 |
| 《针灸逢源》 | 361 | 清代 |
| GB/T 12346—2006 | 361 | 国家标准 |
| 2008 年印堂归督 | 362 | 行政增补 |
| 本教材选编 | 362 经穴 + 39 奇穴 | 依国标选编 |

读这张表，最容易得出的结论是"穴越发现越多"，但表格不支持这个结论：从 365 到 349 是减少，从 349 到 362 才是回升。真正的解释是，**这些数字统计的不是身体上的点，而是某一版目录收录了多少条。** 365 是先民对天数的比附，349 与 354 反映的是不同底本的删并与校订，361 到 362 只多了印堂一个，那是标准的修订，不是新发现。教材说经穴"约 1/3 是临床常用穴"，这句更直白：目录的完备程度与临床使用率是两件事，362 条里天天用的不过百余。

因此，遇到「某穴是不是经穴」这类问题，正确的答法是先问版本：哪一版目录？2006 年之前印堂还是奇穴，2008 年之后它是督脉穴。**穴的归属是文本事实，不是解剖事实。** 这不是相对主义，恰恰是更严格的标准——它要求每次说"某穴属某经"时，心里清楚这是哪本书、哪一年的规定。

## 五、代价与边界

1. 本章的数目（365、349、354、359、361、362、39）全部取自教材正文，未核原书；其中 365 是《内经》的成数，不可当实数使用。
2. 本章不给任何一穴的具体定位与操作。定位须回到骨度分寸与体表标志两章，本章只讲"名、经、位是三条记录"，不替代具体分寸。
3. 「分类是行政性的」是本章的判断，依据是膏肓、风市由奇穴归经这一教材自述；本章不据此否认经穴在解剖上多有神经血管伴行。教材明言现代研究"并未改变经典理论"，本章同此口径。
4. 六类命名法的归类有交叉，教材亦承认「足三里」「合谷」兼含多义；本章不把六类当互斥的判据使用。
5. 本章不涉及任何刺灸操作与治疗建议。

## 六、运行与验证

本章的正文与习题契约由脚本现算，可当场复核：

```bash
node code/main.js
```

脚本打印的是本章正文的规模、习题的阶段分布与接地情况；退出码为 0 表示各项契约满足，非 0 表示有不满足的项，输出里会逐条写明。


把本章的标准落到可检验的动作上，只需三问：

- 任取三个穴，各写出名、经、位三行。写不全的，说明还停在"背名字"的阶段。
- 举出一个「曾是奇穴、后归经」的例子，并说明它变的是归属还是位置。
- 指着一个比喻型穴名（伏兔、犊鼻、印堂任选），说出它的喻体与真实定位标志各是什么。

三问都能答，说明已经把三条索引拆开了；只答得出第一问，说明仍把穴名当成了一个整体去记。教材之所以先讲训诂、再讲分类、最后讲命名，顺序就是这三问的顺序。
