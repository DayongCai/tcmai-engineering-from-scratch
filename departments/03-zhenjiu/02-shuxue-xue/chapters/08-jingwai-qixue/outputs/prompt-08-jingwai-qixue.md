# 经外奇穴十八条编号背后是五十多个进针点 · 提示词

## 用途

给「经外奇穴十八条编号背后是五十多个进针点」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「十八条编号，五十多个点 → 奇穴是流动的类别 → 编号按部位分箱 → 深度不按层次排，按「这个穴治什么」排」这条链。
