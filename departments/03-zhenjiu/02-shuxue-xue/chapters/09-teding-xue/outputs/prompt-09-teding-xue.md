# 特定穴是同一批穴上越挂越多的牌子，不是六类并列的穴 · 提示词

## 用途

给「特定穴是同一批穴上越挂越多的牌子，不是六类并列的穴」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「102 块牌子，13 个类别，只有一处满额 → 五输：一条线上的五个刻度 → 原络：一条经上的两个接口 → 俞募：一前一后夹住同一个脏腑」这条链。

## 边界

本章为腧穴学特定穴部分的教学整理，穴数、类别归属、定位、深度与主治均转自课程底本与穴位库字段；具体操作以现行规范与所在机构制度为准。
