# 安全章一个次数都不给，它给的是红线与复核 · 提示词

## 用途

给「安全章一个次数都不给，它给的是红线与复核」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「正文：零数值、六类禁、九条红线、四次重复 → 运行与验证 → 资料来源（主要参考）」这条链。

## 提示词

```
我在学《小儿推拿学》第 12 章「安全章一个次数都不给，它给的是红线与复核」，本章 3 节 / 4,210 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 把安全写成「轻一点、短一点」，等于没有写
   - 但有依据不等于无风险
   - 皮肤及软组织
   - 肿瘤与不明肿块
   - 这份清单的用法是排除，不是记忆
   - 「停止」这个动作写在手法规范里，是本章最实用的一句
4. 本章自陈的边界（不得越过）：
   - **「零数值」不等于「零信息」。** 本章把可数的东西换成了可判的东西：六类禁忌、九条红线、四层边界。这些清单的价值在于可逐条核对；代价是无法像次数那样被量化考核，只能靠复述与情景演练来确认是否掌握。
   - **22 处「禁」是底本原话，本章不扩也不缩。** 本章没有把「慎用」写成「禁用」，也没有把「暂停」写成「永久禁忌」——三者的边界在底本里很清楚，改动会直接改变临床行为。
   - **九条红线不是分诊标准。** 它只回答「要不要立刻走」，不回答「走去哪个科」。底本给的是「就近转诊至有儿科急救条件的医疗机构」，具体科室须由接诊方判断。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```
