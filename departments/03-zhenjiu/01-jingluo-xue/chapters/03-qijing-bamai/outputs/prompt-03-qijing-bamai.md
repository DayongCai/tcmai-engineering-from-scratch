# 奇经八脉不是十二经的备用线，而是气血的蓄水池 · 提示词

## 用途

给「奇经八脉不是十二经的备用线，而是气血的蓄水池」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「「奇」是排除式定义，风险在于只记住否定项 → 八脉各司其职，且同出一源 → 督与任：两条有本经穴的奇经 → 六条无穴之脉，靠八个点接入十二经」这条链。
