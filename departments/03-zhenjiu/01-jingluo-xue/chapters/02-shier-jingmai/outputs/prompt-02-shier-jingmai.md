# 十二经的走向不是路线图，而是十二处交接点上的传递规则 · 提示词

## 用途

给「十二经的走向不是路线图，而是十二处交接点上的传递规则」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「「从胸走手」说的是体表段 → 十二处交接，只有三种场合 → 流注是时间表，走向是方向 → 走向规律能推出的四件事」这条链。
