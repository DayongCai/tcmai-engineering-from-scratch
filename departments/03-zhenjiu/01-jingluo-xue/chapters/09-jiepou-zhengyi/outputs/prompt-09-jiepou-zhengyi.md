# 「找不到对应结构」是一个研究状态，不是一句结论 · 提示词

## 用途

给「「找不到对应结构」是一个研究状态，不是一句结论」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「争议的形状：不是有／无，是两说并存 → 功能调节系统说：把经络当成一套调节网络 → 形态结构说：把经络当成一种待找的结构 → 「有进展，无突破」之后，什么算证据」这条链。

## 边界

本章为针灸学教学文本，所论经络实质假说、经穴特异性与灸法物理研究均据教材综述，不含任何临床结论与治疗建议。文中假说均属未定论的研究假设，读者不得据以推断经络的解剖学存在或不存在；具体操作以现行规范与所在机构制度为准。
