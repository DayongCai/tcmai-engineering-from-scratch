# 病候是一张定位表，不是一份症状清单 · 提示词

## 用途

给「病候是一张定位表，不是一份症状清单」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「病候被切成两半：脏腑那一半，经脉那一半 → 「经脉所过，病候所及」是定位规则，不是套话 → 同症异经：三个必须分开的例子 → 循经感传：一条证据，和它的成色」这条链。

## 边界

本章为针灸学教学文本，所论病候、辨经与循经感传均据教材与经典条文，不含任何刺灸操作参数。文中所列症状与经脉的对应关系用于教学辨识，不构成诊断依据；具体操作以现行规范与所在机构制度为准。
