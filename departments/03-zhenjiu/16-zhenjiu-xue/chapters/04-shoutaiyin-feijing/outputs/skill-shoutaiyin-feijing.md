# 肺经十一穴：一条从胸走到拇指的经，先定属络再定穴

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 5 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 底本对三穴未给国标代号
- 定位寸数全部照录，本章零新增
- 篇名级出处只有一种
- 主治与现代观察混排
- 本课不给留针时间、壮数与电针参数

## 边界

- **底本对三穴未给国标代号。** 云门、天府、侠白在本章只有文字定位，没有 LU2、LU3、LU4 字样；表里因此只列 8 穴的代号。本课不代填——代号须回国家标准核对，凭记忆补写等于造数据。
- **定位寸数全部照录，本章零新增。** 表中六处寸数与「0.1 寸（指寸）」均逐字取自底本 4.2.1；本章不推算、不换算，也不给底本未收的穴。
- **篇名级出处只有一种。** 全章【原文】8 处，去重后只有《灵枢·经脉》一种篇名。这是底本的取材结果：循行与病候引经典，主治与操作则用教材自身的表述（标注为「转引自」）。引用病候条文时须注意它出自教材转述，不是直接引自《灵枢》。
- 本章为针灸学课程的教学材料，循行、病候、腧穴定位与操作口径取自 `standards/zhenjiu-xue/units.json` 第 4 章的教材转述，字数与引文计数由上述命令现算。本章不提供诊断、处方、留针时间、壮数或电针参数，不构成医疗建议。
