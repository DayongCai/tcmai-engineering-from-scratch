# 这一章不给穴位，只给把穴位连成方子的规则 · 提示词

## 用途

给「这一章不给穴位，只给把穴位连成方子的规则」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「零定位：这一章写的是规则，不是坐标 → 五条治则，四个单元：治神守气寄居在别人的小节里 → 四类选穴、六种配穴：48 次「配穴」在教什么 → 十类特定穴：只有五个数字是底本给的」这条链。

## 提示词

```
我在学《针灸学》第 23 章「这一章不给穴位，只给把穴位连成方子的规则」，本章 5 节 / 3,634 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 凡是要立「法则」的地方，就密集引经；凡是描述「方法」的地方，就少引甚至不引
   - 治神守气没有自己的位置，它被放在「补虚泻实」单元的后半段
   - 同一个「本」字，在病因层与经络层指两样东西
   - 选穴原则决定「取哪些穴」，配穴方法决定「这些穴怎么摆」
   - 这里是本章最实在的一处缺口
   - 第一个代价：本章没有一条完整处方
4. 指出本章写到类别就止步、不再给参数的地方。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

本章为针灸学教学文本，不构成医学意见、诊断或处方建议；具体操作以现行规范与所在机构制度为准。
