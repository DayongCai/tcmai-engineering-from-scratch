## 四、这门课的判据：处方要能被别人照做

一张合格的针灸处方至少写全四件：**辨证分型、主穴＋配穴、操作（手法/补泻/留针）、疗程频次**。
缺一项，别人拿着这张单子做不出来。教材未给证据等级的病种，本课一律写「教材未标证据等级」，不替它补。
