# 处方不是穴名清单，而是「辨经—选穴—刺灸法」三列必须自洽 · 提示词

## 用途

给「处方不是穴名清单，而是「辨经—选穴—刺灸法」三列必须自洽」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「辨病的两分：脏腑病与经络肢节病，用穴规律不同 → 辨经：三条进路，一条比一条硬 → 辨证：八纲要落到「针还是灸、深还是浅、补还是泻」 → 选穴四原则：各自的主场与各自的失效」这条链。
