# 第 5 章 · 内科前二十一个病证，先问「病在神还是病在形」

> **MOTTO:** 「不寐者，病在阳不交阴也。」——《类证治裁·卷之四》
>
> **PROBLEM:** 教材·第7章前半从「中风」排到「疟疾」，二十一个病证一节一节平铺，读起来像二十一张互不相干的方。可带教门诊一个上午往往连着来三个人：中风后遗症的、面瘫的、失眠的。若每次都从头翻书，速度与质量同时崩。真正要回答的是：这二十一个中间，先判什么，才知道该从哪一组里找方？

**双根因定位:** 环境逼迫（一个上午三类病人轮着来，背不出分组就只能背方，背不下来的那一个当场掉链子） + 知识积累（把二十一节改读成三组，每组的主穴有自己的基线穴与自己的取穴逻辑，方可以按组推）

**教材出处:** 教材·第7章 7.1–7.21（中风、眩晕、贫血、高血压病、面瘫、痹证、痿证、外伤性截瘫、癫证、狂证、痫证、震颤麻痹、痴呆、郁证、不寐、嗜睡、心悸、感冒、咳嗽、哮喘、疟疾）。本章的分组、计数与检索表为**教学设定**，治法、主穴、证型均取自教材原文。

## 一、二十一个病证的三分：九个治神，四个治形，八个治气血脏腑

分组的依据不是病名，是教材自己写的治法。把二十一条治法逐个读一遍，会发现一个极干净的分界：

- **治法是「醒脑开窍」「调神开窍」「清心开窍」「醒神开窍」「宁神定颤」「醒脑调神」「养心调神」「宁心安神」的，共九个**：中风、癫证、狂证、痫证、震颤麻痹、痴呆、郁证、不寐、嗜睡。这九个的治法里都有「神」或「开窍」。
- **治法是「疏调经筋」「通痹止痛」「濡养筋肉」「益肾充髓」的，共四个**：面瘫、痹证、痿证、外伤性截瘫。它们的病位都在筋、肉、骨。
- **剩下八个，治法是「平肝潜阳」「调养气血」「调和气血」「宁心定悸」「祛风解表」「理肺止咳」「止哮平喘」「和解少阳」**：眩晕、贫血、高血压病、心悸、感冒、咳嗽、哮喘、疟疾。它们治的是气血与脏腑功能。

九加四加八正好二十一。这个分法能复算，也能反证：把任何一个病证的治法拿掉，它只会落进这三组之一，不会两边都像。教材没写这句分组，但治法词表已经把它写出来了。

分组之后，每一组的「基线穴」就浮出来了——不是背方，而是先记住这一组反复出现的那几个穴，再逐病加减。

## 二、治神九证：百会、内关、太冲、丰隆是这一组的骨架

九个治神病证的主穴，教材是这样写的：

| 病证 | 治法 | 主穴 |
|---|---|---|
| 中风 | 醒脑开窍，疏通经络 | 水沟、内关、极泉、尺泽、委中、三阴交 |
| 癫证 | 理气化痰，调神开窍 | 百会、印堂、内关、神门、太冲、丰隆 |
| 狂证 | 涤痰泻火，清心开窍 | 水沟、神门、劳宫、内关、丰隆 |
| 痫证 | 豁痰息风，醒神开窍 | 水沟、百会、内关、太冲、后溪、涌泉 |
| 震颤麻痹 | 柔肝息风，宁神定颤 | 百会、四神聪、风池、太冲、合谷、阳陵泉 |
| 痴呆 | 填精益髓，醒脑调神 | 百会、四神聪、风府、太溪、悬钟、足三里 |
| 郁证 | 疏肝解郁，养心调神 | 百会、印堂、太冲、神门、内关、膻中 |
| 不寐 | 交通阴阳，宁心安神 | 照海、申脉、神门、三阴交、安眠、四神聪 |
| 嗜睡 | 醒脑调神，健脾化湿 | 百会、四神聪、印堂、足三里、丰隆 |

横向数一遍：百会出现在七节（除狂证、不寐），内关五节，太冲五节，丰隆四节，水沟三节。这五个穴的分布不是巧合，它们各自对应一条治神的路径。

百会与四神聪在头顶，是「醒脑」这一路的落点。九节里用四神聪的四个病证（震颤麻痹、痴呆、不寐、嗜睡）都是慢性或功能性神志病，用百会的七个则包含痫证、郁证这类发作性或情绪性病证——头顶的取穴对应「上调」，教材方义里反复用的词是「入络于脑」「安神定志」。

内关与神门是「宁心」这一路。狂证、癫证、郁证、不寐都取神门（心之原穴），中风、癫、狂、痫、郁都取内关。这两穴的区别在教材的方义里：神门为心之原，主宁心安神；内关为心包络穴又通阴维脉，主「畅达三焦气机，理气降逆」。所以一个是安，一个是降。

丰隆与水沟是「豁痰开窍」这一路。癫、狂、痫、嗜睡四节取丰隆，正对教材给这四节写的「涤痰」「豁痰」「化痰」；水沟出现在中风、狂证、痫证三节，三节的共同点是「闭」——中脏腑的闭证、狂证的实、痫证的发作。

太冲则是「平肝息风」这一路，出现在中风、癫、痫、震颤麻痹、郁证五节，与震颤麻痹的「柔肝息风」、郁证的「疏肝解郁」直接对应。

九节合起来，这一组的处方骨架是：**头顶一穴（百会或四神聪）＋心包或心经一穴（内关或神门）＋肝经一穴（太冲）＋化痰一穴（丰隆）＋急救一穴（水沟，仅闭证）**。逐病加减的部分才轮到涌泉、劳宫、风池、太溪、悬钟、照海、申脉、安眠、膻中。不寐是唯一不用百会的一节，它用照海配申脉，教材方义写明理由：跷脉主寤寐、司眼睑开阖，泻申脉补照海以交通阴阳——这一节治的是「阴阳不交」，不是「脑不醒」。

## 三、形病四证：局部穴加夹脊，不治神

面瘫、痹证、痿证、外伤性截瘫四节，主穴的结构完全不同，共同点是**都在病变部位附近取穴，并把夹脊穴当骨架**。

面瘫一节：治法「祛风通络，疏调经筋」，主穴阳白、四白、颧髎、颊车、地仓、翳风、牵正、太阳、合谷。九个穴里八个在面部，只有合谷在手上——这是「面口合谷收」的远端呼应。

痹证一节：治法「疏经活络，通痹止痛」，主穴按部位列，肩部取阿是穴、肩髃、肩髎、肩贞、臑俞；肘部取阿是穴、曲池、天井、尺泽、少海；腕部取阿是穴、阳池、外关、阳溪、腕骨；脊背取阿是穴、大杼、身柱、腰阳关、夹脊。它不发一张通用方，而是给一套「按部位查表」的写法，这是教材唯一这样处理的一节，因为痹证的病位本身在变。

痿证一节：治法「调和气血，濡养筋肉」，上肢取肩髃、曲池、合谷，下肢取髀关、足三里、阳陵泉、三阴交，另加颈、胸夹脊与腰夹脊。教材方义点明依据是「治痿独取阳明」与夹脊「调脏腑阴阳，通行气血」。

外伤性截瘫一节：治法「舒筋通络，益肾充髓」，主穴取损伤脊柱上、下 1～2 个棘突的督脉穴及其夹脊穴，加环跳、委中、阳陵泉、足三里、悬钟、涌泉、三阴交。这一节的取穴在解剖上最具体——按损伤节段定位，是四节里唯一把「取穴」写成「取哪一段」的。

四节的共同结论：形病的处方靠「部位」定位，不靠「神」定位。把治神九证的骨架搬过来会当场失效，反之亦然。

## 四、气血脏腑八证：虚证走背俞，实证走项背头面

剩下八节，主穴分成清楚的两路。

**走背俞的四个**：贫血取脾俞、心俞、肾俞、膈俞、足三里、气海、血海（七穴中四个背俞）；心悸取心俞、厥阴俞、巨阙、膻中、神门、内关（俞募同用）；咳嗽分外感与内伤，外感取肺俞、列缺、合谷，内伤取肺俞、中府、太渊、三阴交；哮喘取肺俞、中府、太渊、定喘、膻中。这四个病证的共同点是「虚」或「脏病」，正对第 3 章讲过的用法：五脏病多取背俞，俞募可同用。

**不走背俞的四个**：眩晕取百会、风池、太冲、内关、丰隆；高血压病取风池、太冲、百会、合谷、曲池、三阴交；感冒取列缺、合谷、风池、大椎、外关；疟疾取大椎、陶道、中渚、间使、后溪。这四个的共同点是「实」或「外邪」：风池、大椎、百会都在头项，合谷、曲池、外关都在上肢阳经，取的是「从上从表解」的路子。

两路的分界与教材的治法一一对应：眩晕「平肝潜阳，和胃化痰」、高血压病「平肝潜阳，调和气血」——潜阳要往上往下同时使力，所以既取头顶的百会、也取足部的太冲；感冒「祛风解表」、疟疾「和解少阳，祛邪截疟」——解表要开门，所以取大椎、风池、外关。虚证那一路则相反，取背俞是把气往下引、往里收。

这一节最值得记住的是一句可直接用的判断：**看主穴里有没有背俞穴，就知道教材把这一节当虚证还是实证处理。** 这条判断在二十一个病证里没有反例——凡取背俞的，治法里都有「补」「益」「调养」；凡不取背俞的，治法里都有「平肝」「祛风」「和解」。

## 五、中风一节的三张方：一病多方的读法

中风是这二十一个里唯一给了三张方的病证，值得单独读，因为它是「一病多方」的模板。

第一张：治法「醒脑开窍，疏通经络」，主穴水沟、内关、极泉、尺泽、委中、三阴交。六个穴，头面一（水沟）、上肢二（内关、极泉、尺泽）、下肢二（委中、三阴交），是全身性的通络方。

第二张：治法「醒脑开窍，启闭固脱」。同一句「醒脑开窍」，后半句换成「启闭固脱」——这是中脏腑闭证与脱证的处理，教材把它与第一张并列，说明同一个病在急性期的两个方向（闭与脱）各有一张。

第三张：治法「通关利窍，豁痰化瘀」，主穴廉泉、风池、完骨、通里、照海、合谷、太冲。七个穴里廉泉、风池、完骨都在颈项咽喉，通里是心经络穴「善治失音之疾」，照海通阴跷。教材方义写明这是对症选穴加局部选穴，针对的是语言不利、吞咽困难这一组症状。

三张方的读法是：**同一病名之下，方随「当前最主要的那件事」而换。** 通络是基础，闭脱是急症，失语吞咽是遗留问题。这也解释了为什么本章其余二十节多数只有一张基本方——它们的「最主要那件事」是单一的；中风不是。

## 六、处方的三层与教材的两项约定

二十一个病证的方，结构都是三层：主穴（骨架）、配穴（按证型加减）、操作（补泻、留针、频次）。配穴这一层的规律很清楚：按辨证分型配。痿证按肺热津伤、湿热浸淫、脾胃虚弱、肝肾亏虚、脉络瘀阻五型配不同穴；不寐按肝火扰心、痰热扰心、心脾两虚、心肾不交、心胆气虚五型配；胃痛那一节（属内科后半）按寒邪犯胃、饮食伤胃、肝气犯胃、瘀血停胃、脾胃虚寒、胃阴不足六型配。

教材另给两条约定，省掉了二十一遍重复：

一是「毫针常规刺」，意为实证用泻法、虚证用补法、虚实夹杂者补泻兼施、气机逆乱或虚实不明显者用平补平泻。这一条覆盖了操作栏的大半。

二是个别病证的特殊操作必须单独记。不寐要「泻申脉，补照海」，且背俞穴要注意针刺的方向、角度和深度；中风取极泉要避开腋动脉；痹证日久入络者可刺络出血。这三条都属于「不写就会做错」的层级。

## 七、代价与边界

三分法的好处是一眼定位，代价有四个：

- **分组会压掉同组内的巨大差别。** 九个治神病证里，中风是器质性损伤、郁证是情志病、不寐是睡眠节律问题，三者的预后与疗程完全不同；同一骨架不等于同一病程。
- **治法词表是教材的写法，不是生物学的分类。** 分组的依据是「治法里有没有某个词」，这可以被复算，但不能被当成病机分类学；换一本教材，词表变了，分组也要重算。
- **背俞的有无只是判据，不是疗效证据。** 本章用它来判断教材的虚实定位，没有、也无法据此推出「取背俞优于不取」。
- **配穴层的证型名目各节不齐。** 有的病证分五型、六型，有的只给主症与分经；同一病名在不同版本教材里型数也会变，引用时须注明版本。

不适用范围：本章覆盖的是教材列出的常见证型，不覆盖危重与变证。中风急性期出现高热、神昏、心衰、颅内压增高、上消化道出血者，教材按语明确要求采取综合治疗措施，针刺只是其中一项；外伤性截瘫的康复须与骨科、康复科协同；癫痫持续状态、重度痴呆等不在门诊针刺处方的范围内。
