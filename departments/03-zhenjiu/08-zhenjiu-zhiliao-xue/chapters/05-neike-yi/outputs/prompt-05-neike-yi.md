# 内科前二十一个病证，先问「病在神还是病在形」 · 提示词

## 用途

给「内科前二十一个病证，先问「病在神还是病在形」」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「二十一个病证的三分：九个治神，四个治形，八个治气血脏腑 → 治神九证：百会、内关、太冲、丰隆是这一组的骨架 → 形病四证：局部穴加夹脊，不治神 → 气血脏腑八证：虚证走背俞，实证走项背头面」这条链。

3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 治法是「疏调经筋」「通痹止痛」「濡养筋肉」「益肾充髓」的，共四个
   - 都在病变部位附近取穴，并把夹脊穴当骨架

   - **背俞的有无只是判据，不是疗效证据。** 本章用它来判断教材的虚实定位，没有、也无法据此推出「取背俞优于不取」。
