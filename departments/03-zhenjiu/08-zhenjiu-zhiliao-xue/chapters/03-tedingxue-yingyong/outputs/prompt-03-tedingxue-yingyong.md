# 特定穴是按条件检索的索引，不是「更重要的穴位」 · 提示词

## 用途

给「特定穴是按条件检索的索引，不是「更重要的穴位」」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「五输穴：先记五行归属，再记三种用法 → 子母补泻：本经与他经两条路，以及「补井当补合」 → 原穴与络穴：一络通两经 → 俞募穴：前后配穴的脏腑落点」这条链。
