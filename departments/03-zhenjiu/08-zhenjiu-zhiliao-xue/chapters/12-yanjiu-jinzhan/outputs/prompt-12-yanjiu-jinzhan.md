# 研究进展给的是地图，不是证据表 · 提示词

## 用途

给「研究进展给的是地图，不是证据表」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「这一章的形状：八个系统、两类数字、零个等级 → 五个能直接读的数字，各自能推到哪一步 → 读一篇针灸 RCT 的四个必问 → 从「有效」到「适应证」：分级只能这样用」这条链。

## 提示词

```
我在学《针灸治疗学》第 12 章「研究进展给的是地图，不是证据表」，本章 6 节 / 3,052 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 它是研究地图，不是证据表
   - 404 例（内关、通里治心绞痛）
   - 504 例与 85.4%（电针中髎、会阳治女性压力性尿失禁）
   - 75 例、总有效率 73.3%、6 个月随访（鼻三针透刺治变应性鼻炎）
   - 2 Hz 与 100 Hz（韩济生）
   - 数字越大，能推的步越短
4. 本章自陈的边界（不得越过）：
   - **密度决定读法。** 2,733 汉字承担八类疾病的「进展」，把它当综述读会失望，当索引读才合适。它给的是入口，不是结论。
   - **数字都是转引。** 教材引的原始论文不在本项目取证范围内，本章不再引原件，凡引用一律标「教材原话」。因此本章无法核对教材与原文之间的偏差——这一层只能回原始文献。
   - **病例数不等于样本量。** 「纳入 404 例」是纳入数，脱落与失访教材没给；把它当分析样本量，会高估精度。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为针灸治疗学的教学演练与文献研读，所列读法与分级粗序为课堂整理，不构成诊疗建议，也不构成证据等级评定；具体操作以现行规范与所在机构制度为准。
