# 皮外骨伤二十二证，先分清病在血分、在局部，还是在经筋 · 提示词

## 用途

给「皮外骨伤二十二证，先分清病在血分、在局部，还是在经筋」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「二十二节的三分：皮肤八、外科十、骨伤四 → 皮肤八节：血分四节、湿热两节、直取两节 → 外科十节：四个被点名的经验效穴，两种共用骨架 → 骨伤四节：局部取穴，但先针远端」这条链。
