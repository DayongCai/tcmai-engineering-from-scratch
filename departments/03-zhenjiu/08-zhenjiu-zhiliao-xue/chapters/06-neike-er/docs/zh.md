# 第 6 章 · 内科后二十一个病证，处方的主干是「募穴＋下合穴」

> **MOTTO:** 「胃病者，腹胀，胃脘当心而痛，上支两胁，膈咽不通，食饮不下，取之三里也。」——《灵枢·邪气脏腑病形》
>
> **PROBLEM:** 内科后半从「胃痛」排到「瘿病」，二十一个病证分布在腹、胁、二阴、颈前，看上去杂乱。可把二十一条治法连起来读会发现一件怪事：这一半**没有一个**治法是「治神」的。前半那九个「醒脑开窍」「宁神定颤」在这里完全不见。那么这一半靠什么立骨架？答案在穴上，而且可以数出来。

**双根因定位:** 环境逼迫（这一半是门诊量最大的部分：胃痛、泄泻、便秘、淋证、遗精，一天里反复出现，若每次现想配穴，节奏撑不住） + 知识积累（把二十一节读成「管道与生殖」两件事，各自有一条固定的穴位主干，方可以按主干加枝节推）

**教材出处:** 教材·第7章 7.22–7.42（胃痛、呕吐、呃逆、腹痛、泄泻、痢疾、便秘、肠易激综合征、胁痛、黄疸、水肿、癃闭、淋证、尿失禁、遗精、阳痿、慢性前列腺炎、早泄、不育症、消渴、瘿病）。本章的分组与频次统计为**教学设定**，按教材主穴逐条检索现算；治法与主穴原文取自教材。

## 一、二十一个病证的五个分组

按病位与治法，这二十一节可以分成五组：

- **受纳传导（八）**：胃痛、呕吐、呃逆、腹痛、泄泻、痢疾、便秘、肠易激综合征。治法词是「和胃」「降逆」「通调腑气」「调肠」「通肠导滞」「调肠通便」「理气通腑」。
- **水液（四）**：水肿、癃闭、淋证、尿失禁。治法词是「利水消肿」「行气通闭」「利尿通淋」「益肾固脬」。
- **生殖（五）**：遗精、阳痿、慢性前列腺炎、早泄、不育症。治法词是「调肾固精」「补益肾气，荣养宗筋」「清利下焦」「清泄相火」「补肾填精」。
- **肝胆（二）**：胁痛、黄疸。治法词是「疏肝利胆」「化湿利胆退黄」。
- **代谢与腺体（二）**：消渴、瘿病。治法词是「清热润燥，养阴生津」「理气化痰，消瘿散结」。

八加四加五加二加二，正好二十一。与前半对照，最刺眼的是治法词表的差别：前半有九个含「神」或「开窍」，这一半一个也没有。这不是教材漏写，而是病位换了——这一半的病位在腑、在管道、在精室，处理的是「通、降、利、固」四件事，不是「醒、安、定」。

## 二、受纳传导八证：中脘—天枢—足三里的三点一线

八节的主穴排在一起看，骨架立刻显形：

| 病证 | 治法 | 主穴 |
|---|---|---|
| 胃痛 | 和胃止痛 | 中脘、足三里、内关、公孙 |
| 呕吐 | 和胃止呕 | 中脘、足三里、内关 |
| 呃逆 | 理气和胃，降逆止呃 | 中脘、足三里、内关、膻中、膈俞 |
| 腹痛 | 通调腑气，缓急止痛 | 中脘、天枢、关元、足三里 |
| 泄泻 | 健脾利湿，调肠止泻 | 大肠俞、天枢、上巨虚、三阴交、神阙 |
| 痢疾 | 通肠导滞，调气和血 | 天枢、上巨虚、合谷、三阴交 |
| 便秘 | 调肠通便 | 天枢、大肠俞、上巨虚、支沟、照海 |
| 肠易激综合征 | 调和肝脾，理气通腑 | 天枢、大肠俞、上巨虚、足三里 |

骨架是三段：**中脘（胃之募、腑之会）管上段，天枢（大肠之募）管中段，足三里与上巨虚（胃与大肠的下合穴）管「合治内腑」的出口。** 上半段四节（胃痛、呕吐、呃逆、腹痛）都用中脘配足三里；下半段四节（泄泻、痢疾、便秘、肠易激）都用天枢配上巨虚。中脘与天枢的切换点正好在「腹痛」——腹痛一节两个都用，因为腹痛的病位横跨胃与肠。

内关与公孙的出现也值得注意。「公孙配内关」是第 3 章讲过的一对八脉交会穴，主治「胃、心、胸疾病」；教材把它放在胃痛一节作主穴，呕吐、呃逆则只留内关。这说明胃痛一节用的是「八脉交会」这套依据，其余两节退回「胃募＋下合穴」。同一组穴位、两套依据，写病历时要说清用的是哪一套。

教材在胃痛一节的方义里把这层关系讲透了：中脘为胃之募、腑之会，穴居胃脘部，可健运中州；足三里为胃的下合穴，两穴远近相配，「凡胃脘疼痛，不论寒热虚实，均可使用」；内关通阴维脉，「阴维为病苦心痛」，畅达三焦气机；公孙为脾经络穴，也为八脉交会穴。四穴四个依据，缺一个都还能用，但依据少一条。

## 三、水液四证：中极配膀胱俞，俞募同用

水肿、癃闭、淋证、尿失禁四节的主穴：

- 水肿：三焦俞、委阳、水分、水道、阴陵泉。治法「利水消肿」。
- 癃闭：中极、膀胱俞、委阳、三阴交、阴陵泉。另有第二方，治「益肾固本，软坚散结」，取气海、中极、秩边、水道、三阴交、列缺。
- 淋证：中极、膀胱俞、三阴交、阴陵泉。治法「利尿通淋」。
- 尿失禁：中极、膀胱俞、肾俞、三阴交。治法「益肾固脬」。

后三节的主穴首两味完全相同：中极、膀胱俞。这正是第 3 章讲过的俞募配穴法——中极为膀胱募穴，膀胱俞为膀胱背俞穴，一前一后，教材方义写「可调理膀胱气化功能，通利小便」。三节的区别只在后面的枝节：癃闭加委阳（三焦下合穴）与阴陵泉，淋证加三阴交与阴陵泉，尿失禁加肾俞。

水肿走的是另一条路：不取膀胱俞，取三焦俞、委阳、水分、水道、阴陵泉。三焦俞与委阳（三焦下合穴）配对，仍是「俞＋下合」的逻辑，只是把脏腑从膀胱换成三焦——因为水液代谢在教材的框架里归三焦。「水分」「水道」两个穴名本身就是定位提示，教材用它们是把「水停何处」直接写进穴名。

四节合起来的判据是：**病在膀胱（小便的排出）取中极配膀胱俞；病在三焦（水液的布散）取三焦俞配委阳。** 癃闭与淋证若涉及三焦气化，教材在癃闭第二方里加秩边、水道，仍在这条线上。

## 四、生殖五证：关元—肾俞—太溪—三阴交的固定组合

五节的主穴近乎同构：

- 遗精：关元、肾俞、太溪、志室、三阴交。治法「调肾固精」。
- 阳痿：关元、肾俞、太溪、三阴交。治法「补益肾气，荣养宗筋」。
- 早泄：关元、肾俞、太溪、志室、三阴交。治法「调肾固精」——与遗精一字不差。
- 不育症：气海、关元、肾俞、太溪、三阴交、足三里。治法「补肾填精，通利精宫」。
- 慢性前列腺炎：关元、会阴、太溪、三阴交。治法「清利下焦，健脾补肾」；另有第二方治「清泄相火，弛缓宗筋」，取大敦、行间、蠡沟、侠溪、三阴交。

四味核心（关元、肾俞、太溪、三阴交）在五节里出现四次以上，构成这一组的骨架：关元为任脉穴又与足三阴经交会，肾俞为肾之背俞，太溪为肾之原穴，三阴交为足三阴交会。四个穴把「任脉—背俞—原穴—交会」四条依据都占住了，教材方义里「调肾固精」「补益肾气」说的就是这套。

两处例外值得记：不育症加气海、足三里，是从「精宫」往「气血生化」上补；慢性前列腺炎两方取向相反——第一方清利，第二方清泄相火且取大敦、行间、蠡沟、侠溪（肝经与胆经），因为教材把这一节的病机分成「湿热下注」与「相火偏旺」两路。同一病名，两套穴，与第 5 章中风的三张方是同一个道理。

## 五、肝胆与代谢四证：背俞、阳陵泉与阿是

- 胁痛：期门、阳陵泉、支沟、丘墟。治法「疏肝利胆，活络止痛」。期门为肝之募，阳陵泉为胆之下合穴与筋会，支沟、丘墟属少阳经。
- 黄疸：胆俞、阳陵泉、阴陵泉、至阳。治法「化湿利胆退黄」。胆俞为胆之背俞，阳陵泉为胆之下合，至阳在督脉、为退黄的经验要穴。
- 消渴：肺俞、胃俞、肾俞、胃脘下俞、三阴交、太溪。治法「清热润燥，养阴生津」。
- 瘿病：阿是穴、天突、膻中、足三里、丰隆。治法「理气化痰，消瘿散结」。

胁痛与黄疸同用阳陵泉，是这一组唯一的交点，也是「合治内腑」在胆腑上的应用。消渴是全书唯一同时取三个背俞（肺、胃、肾）的方，正对上消、中消、下消三证——教材的配穴正是按上消配太渊少府、中消配内庭地机、下消配复溜太冲来分。瘿病则回到局部：阿是穴、天突在颈前，膻中在胸，丰隆化痰，足三里和中，是「局部＋化痰＋和中」的三段。

## 六、高频穴与「零个神」的含义

把二十一节的主穴逐个做字符串检索，得到的频次（**按教材主穴原文现算**）：

| 穴位 | 出现在几节主穴中 | 说明 |
|---|---|---|
| 三阴交 | 11 | 全章最高频，跨泄泻、痢疾、癃闭、淋证、尿失禁、遗精、阳痿、前列腺炎、早泄、不育、消渴 |
| 足三里 | 7 | 胃痛、呕吐、呃逆、腹痛、肠易激、不育、瘿病 |
| 关元 | 6 | 腹痛与生殖四证 |
| 肾俞 | 6 | 尿失禁、遗精、阳痿、早泄、不育、消渴 |
| 太溪 | 6 | 生殖四证与消渴 |
| 天枢 | 5 | 腹痛、泄泻、痢疾、便秘、肠易激 |
| 中脘 | 4 | 胃痛、呕吐、呃逆、腹痛 |
| 阴陵泉 | 4 | 黄疸、水肿、癃闭、淋证 |
| 中极、膀胱俞 | 各 3 | 癃闭、淋证、尿失禁，成对出现 |
| 内关 | 3 | 胃痛、呕吐、呃逆 |

这张表本身就是结论：**三阴交一个穴跨十一节，说明这一半的病位虽分散在胃、肠、膀胱、精室，却共享同一条「足三阴」的证据线。** 教材用它，是因为它同时是脾、肝、肾三经的交会穴——一个穴能同时应答「脾虚湿盛」「肝郁」「肾虚」三种病机，正好覆盖这一半的病因谱。

「零个神」的含义也要说清：不是这一半与神志无关——便秘日久可致心烦，癃闭可致烦躁，遗精常伴失眠——而是教材认为这些病证的主线不在神。若患者以神志症状为主诉，按第 5 章处理；若以腑气不通、水液不利、精关不固为主诉，按本章处理。两章的分界不在病名，在主诉。

## 七、代价与边界

「募穴＋下合穴」这套主干换来的是可复用，代价有四个：

- **同构会掩盖虚实两路。** 癃闭有膀胱湿热与肾气亏虚两型，教材只能另给第二方；一张主干方治不了两端。用的时候必须回到辨证分型去加减，主干只是起点。
- **频次统计说明的是教材的写法，不是疗效排序。** 三阴交出现十一次，只能证明教材偏好它，不能证明它最优；本章不据此主张取舍。
- **俞募同用有操作风险。** 中极、关元都在下腹，教材明确要求针前排空小便、不可深刺，以免刺伤膀胱；孕妇腰骶部与下腹穴为禁忌。这类禁忌不写在主穴表里，写在操作栏里。
- **「零个神」的分界在教材里是隐含的。** 本章把它显式化，代价是遇到「腑病兼神志症状」的病人时，两章的分界要重新判断，不能各照一章取穴相加。

不适用范围：这一半的多数病证在教材按语里都写了「先明确病因」——肠易激综合征须排除器质性病变，慢性前列腺炎须与细菌性、非细菌性区分，消渴病程长而病重者须配合药物，癃闭（尿潴留）原因不明者须先导尿与查因。针刺在这些情形里是辅助，不是替代。
