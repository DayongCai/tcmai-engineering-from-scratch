# 读经典不是背条文，是把一句话还原成一组能做的动作 · 提示词

## 用途

给「读经典不是背条文，是把一句话还原成一组能做的动作」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「同一个「补泻」，两本书给的是两个变量 → 《灵枢》的四类补泻：每一类都能落到一个动作 → 《难经》的贡献：把原则变成设问，再把设问落到穴位 → 三档转译：哪些条文今天能执行，哪些只能读」这条链。

## 提示词

```
我在学《刺法灸法学》第 3 章「读经典不是背条文，是把一句话还原成一组能做的动作」，本章 5 节 / 2,978 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 第一档，可直接执行
   - 第二档，需补判据才能执行
   - 第三档，不可执行，只作文献
   - 本章不做版本校勘
   - 本章不给复式手法的操作步骤
   - 经典条文不构成疗效承诺
4. 本章自陈的边界（不得越过）：
   - **本章不做版本校勘。** 所引条文依教材转录，教材未注版本者，本章不代拟版本；异文与断句之争不在本章处理范围，遇到两读并存的条文，只取教材所采一读并注明。
   - **本章不给复式手法的操作步骤。** 烧山火、透天凉一类属第 4 章，本章只到「四类旋钮」为止；凡涉及次数、层次、呼吸配合的细节，一律留到下一章并注明属《金针赋》与《针灸大成》的表述。
   - **经典条文不构成疗效承诺。** 「气至而有效」是经典判断，「十死不治」是古代的预后表述，两者都不宜直接移作今天的临床结论；本章引用时保留原文，不代为放大或缩小。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为《内经》《难经》针法条文的教学整理，引文依课程底本转录，分档与判据为教学框架；具体操作以现行规范与所在机构制度为准。
