# 三种「让刺激留得久」的技术里，只有一种把东西留在了体内

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 3 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 埋线没有「退针」这个动作
- 磁疗的剂量说不清而效应也弱，激光的剂量说得清而效应仍不确定
- 这三种技术的临床地位，目前仍由研究进展决定，而不是由操作规范决定

## 边界

- 只写类别与要点，不写操作参数。
- 本章为刺法灸法学教学材料，不构成医学意见、诊断或治疗建议。
