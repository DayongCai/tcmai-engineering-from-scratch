# 三套微针各把身体投影一次，投影规则不同，边界也不同 · 提示词

## 用途

给「三套微针各把身体投影一次，投影规则不同，边界也不同」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三种投影：同一句「以局部代整体」，三个不同的原点 → 耳针：坐标最细的一套，难点在「先分区再选穴」 → 头针：坐标最解剖的一套，标准线是它的骨架 → 腕踝针：坐标最粗的一套，全部技术都在「浅」」这条链。
