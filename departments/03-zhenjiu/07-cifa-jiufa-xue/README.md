## 四、这门课的判据是「可复核」，不是「知道」

每种技术都必须写清：**器具（针具/艾炷规格）＋部位（穴位）＋手法（角度、深度、频率）＋时长＋反应**。
五项缺一项，操作就不可复现；教材里没写死的（如灸量），本课一律标「教材未给数，按临床常规区间」，不自行编数。
