# 这一章叫关节与腱鞘，而腱鞘在正文里只以一个检查手法的名字出现 · 提示词

## 用途

给「这一章叫关节与腱鞘，而腱鞘在正文里只以一个检查手法的名字出现」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「正文：三个速度、一套检查、一个肘 → 这四节各答什么 → 运行与验证」这条链。

## 提示词

```
我在学《针刀医学》第 5 章「这一章叫关节与腱鞘，而腱鞘在正文里只以一个检查手法的名字出现」，本章 3 节 / 3,990 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 化脓性关节炎（5.1，4,681 字，全章最长的一节）
   - 髋膝关节结核（5.2，2,740 字）
   - 5.5 按病因分类把这件事收成一张表
   - 第一节答「先看速度」
   - 第二节答「先排除」
   - 第三节答「底本写到哪为止」
4. 本章自陈的边界（不得越过）：
   - **「关节病不能扎」这条硬线是本章立的，不是底本写的。** 底本写了「早期诊断、早期排脓引流是关键」，没有写「针刀不适用」；本章把它推成一条流程禁令，依据是操作性质不同，不是底本原意。
   - **三个速度的排序是本章的组织方式。** 底本按病名排列（化脓性关节炎、结核、按病因分类），本章按「能不能等」重排。重排会丢掉某些病名之间的联系，读者需要细节时回《中医骨病学》原章。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为针刀医学教学材料。底本原文引自《中医骨病学》与《针灸治疗学》的机器可读层，经典引文引自《黄帝内经》全文层并逐字核对；具体操作以现行规范与所在机构制度为准。
