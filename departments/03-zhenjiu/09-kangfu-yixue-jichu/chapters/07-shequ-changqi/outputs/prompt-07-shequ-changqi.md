# 社区与长期照护：断点不在家里，在从机构到家那一次交接 · 提示词

## 用途

给「社区与长期照护：断点不在家里，在从机构到家那一次交接」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三种场所是三个照护密度，不是三个等级 → 交接：六个要素，缺一项等于没交 → 社区护理：任务分三层，家庭是单元 → 多病共存：把「五种病」换成「今天做不到的一件事」」这条链。

## 边界

本章为社区与长期照护的照护类别、衔接要素与观察要点整理，不构成诊断、治疗、用药或照护方案建议，不作为诊疗依据。文中不含访视频次、随访间隔、用药品种与剂量等任何操作参数；具体操作以现行规范与所在机构制度为准。
