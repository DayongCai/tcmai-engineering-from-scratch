# 评定不是打分，是把功能变化变成别人能复核的说法 · 提示词

## 用途

给「评定不是打分，是把功能变化变成别人能复核的说法」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「评定的产物不是分数，是共识 → 口径三件套：定义、分子、分母 → 时机是类别，不是日程表 → 记录与转介：评定的终点是一个动作」这条链。

## 边界

本章为康复医学基础的教学整理，只写评定的口径、时机、记录与转介要求，不含任何量表名称、分值区间与截断值，也不含可照做的评定操作。功能评定与处置须由具备资质的人员按现行规范实施，读者不得据本章自行评定或据以调整照护安排；具体操作以现行规范与所在机构制度为准。
