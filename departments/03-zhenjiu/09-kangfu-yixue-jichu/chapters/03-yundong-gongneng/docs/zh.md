### 3.1 3.1 7.1.2 训练中的护理配合要求

一、说出运动功能康复护理的基本内涵与本章的知识框架。 二、说明运动训练常见适用类别及其护理配合的总要求。 三、辨别平衡训练与步行训练配合中的护理要点类别。 四、说明运动训练中常见不适与风险的识别类别。 五、复述报告、暂停训练与转介的情形类别与要求。 六、说明训练记录要素与功能变化评价的口径要求。 七、在信息处理与沟通中遵循合规与人群中性原则。 运动功能康复护理（motor function rehabilitation nursing）、运动训练（exercise training）、平衡训练（balance training）、步行训练（gait training）、辅助器具（assistive device）。 运动功能康复护理（motor function rehabilitation nursing）是康复护理（rehabilitation nursing）中围绕肢体活动、姿势控制与行走能力等层面展开的护理工作领域，其目标方向是功能维护与自理能力促进，而不对功能恢复的具体水平作出承诺。它通过组织训练类别、落实护理配合、实施动态观察与规范记录，协助服务对象在自身体能与安全条件下参与运动训练。本章只写训练类别、适用情形、配合要求与观察要点；负荷、频次、时长、角度、力度等具体参数由具备资质的人员确定，护理人员不开展运动处方性质的独立处置，涉诊断、治疗与用药事项一律不作疾病诊断，也不替代规范诊疗与用药。凡训练安排与安全边界，均以现行规范与机构制度为准，护理人员不替代康复护理判断与专业责任。 运动训练的适用类别可按其目的与形式加以归纳。按目的划分，常见类别包括：以维持与改善关节活动度为方向的关节活动类训练；以增强肌肉收缩能力为方向的肌力类训练；以改善心肺耐受为方向的耐力类训练；以改善姿势控制与动作协调为方向的平衡与协调类训练；以恢复或改善行走与位移能力为方向的步行与转移类训练；以调节呼吸节律与身心状态为方向的呼吸放松类训练。上述均为类别表述，具体适用情形由具备资质的人员结合个体情况确定。

### 3.2 3.2 摇法

摇法是以一手固定关节近端，另一手握住关节远端，作缓和的环转运动的手法，为运动关节类手法中最基本的手法。《医宗金鉴·正骨心法要旨》所论手法「使患者不知其苦」的轻巧原则，在摇法中体现为「缓、匀、圆、和」四字诀。一、操作。摇颈：受术者取坐位，颈项放松；术者立于其侧后方，一手扶按其头顶，另一手托扶其下颌，双手协同用力，使头颈作缓慢的左右环转摇动，顺、逆时针交替，幅度由小渐大，以受术者无眩晕、无痛为度，每侧摇动3～5圈。摇肩：受术者取坐位，肩臂放松下垂；术者立于其侧方，一手扶按其肩部以固定，另一手握住其腕部或肘部，将上肢作顺、逆时针环转摇动，幅度由小到大，以肩关节功能受限程度为限，每侧摇动5～10圈；对肩关节粘连较重者，可先以揉、拿放松后再摇，亦可配合梳头式、拉弓式、弯腰划圈式等肩部功能锻炼体位进行摇动。摇腰：受术者取坐位，术者立于其侧后方，一手扶其肩部，另一手扶按其腰部，或双手环抱其胸腹，使腰部作左右环转摇动，幅度以腰部能耐受为度；腰部活动受限明显者亦可取俯卧位或侧卧位，由助手固定骨盆后摇动。摇髋：受术者取仰卧位，下肢放松；术者立于其侧方，一手扶按其膝部，另一手握其踝部，将下肢屈髋屈膝后作顺、逆时针环转摇动，幅度由小到大。摇踝、摇腕、摇肘：均以一手固定关节近端，另一手握住关节远端，作环转摇动，幅度以生理活动范围为限。二、要领。固定端稳定，摇动端轨迹圆滑；幅度由小到大、速度由慢到快、力量轻巧缓和，在关节生理活动范围内充分活动；摇动过程中随时观察受术者反应，遇阻力感即止，不可强行加大幅度；摇法重在环转连贯，忌生硬折返；摇动节律均匀，每摇一圈速度一致，不可忽快忽慢。三、作用。滑利关节、松解粘连、理筋整复、增强关节活动度，改善关节周围软组织血液循环。四、适应证。关节僵硬、屈伸不利、肩周炎、颈椎病、腰腿痛恢复期、髋膝踝关节扭挫伤后遗功能障碍等，亦用于运动前热身与养生保健。五、摇法与扳法的区别。摇法以缓和的环转运动为主，幅度由小到大，重在滑利关节、松解粘连；扳法以瞬间、快速、有控制的扳动为主，重在整复错缝，二者一缓一急，常配合运用，先摇后扳或先扳后摇，须按病情与治疗阶段合理选用。

### 3.3 3.3 膝骨关节炎

膝骨关节炎又称膝关节骨性关节炎、退行性膝关节炎，是以膝关节软骨退行性改变、软骨下骨硬化及骨质增生（骨赘）为病理特征，以膝关节疼痛、肿胀、僵硬、活动受限为主要表现的慢性退行性关节疾病。本病属中医「膝痹」「骨痹」「痹证」范畴。《素问·痹论》曰：『风寒湿三气杂至，合而为痹也』，指出痹证为风寒湿邪侵袭所致；《素问·长刺节论》谓：『病在骨，骨重不可举，骨髓酸痛，寒气至，名曰骨痹』，描述了骨痹的证候特点。本病可分为原发性与继发性两类，原发性与年龄、遗传、肥胖有关，继发性多继发于创伤、畸形及代谢性疾病。多见于中老年人，60岁以上人群患病率明显升高，女性多于男性，好发于膝关节负重面及内侧间室，临床以活动后疼痛加重、上下楼梯及下蹲时尤甚、晨僵短暂（一般不超过30分钟）为特点，晚期可出现关节畸形、活动受限。随着人口老龄化，本病发病率呈上升趋势，已成为老年医学与康复医学关注的重点疾病，是影响中老年人生活质量最常见的关节疾病之一，推拿治疗对缓解疼痛、改善关节功能具有较好作用。早期规范治疗与功能锻炼可延缓病情进展，减少关节畸形与功能丧失。本病需与多种膝关节疾病鉴别，明确诊断是合理施治的前提。 本病的发生以肝肾亏虚、筋骨失养为本，风寒湿邪侵袭、慢性劳损、外伤瘀血为标，总属本虚标实之证。肾主骨、生髓，肝主筋、藏血，中年以后肝肾渐衰，精血不足，筋骨失于濡养，关节软骨退变加速，此为发病之根本；长期负重行走、上下楼梯、深蹲起立等慢性劳损，或跌仆扭伤，使膝关节应力失衡，软骨磨损加重；风寒湿邪乘虚侵袭关节，痹阻经络，气血运行不畅；痰浊瘀血留滞关节，痰瘀互结，日久形成骨赘、滑膜增生。现代医学认为，关节软骨磨损、软骨下骨硬化、骨赘形成、滑膜炎症及关节液成分改变相互影响，形成恶性循环，是膝骨关节炎的基本病理过程；半月板损伤、关节内游离体及关节内应力分布异常可加速退变，股四头肌肌力下降则使关节稳定性减弱，进一步加重磨损。此外，内分泌代谢异常、骨质疏松等亦与本病发生相关，女性绝经后雌激素水平下降，发病率明显升高。病机特点为筋骨同病、虚实夹杂，治疗当补益肝肾以治本，祛邪通络以治标。
