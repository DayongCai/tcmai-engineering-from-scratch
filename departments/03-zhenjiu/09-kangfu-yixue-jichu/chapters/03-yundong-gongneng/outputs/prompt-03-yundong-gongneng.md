# 训练不是加量，是在能承受的范围里换回可控的动作 · 提示词

## 用途

给「训练不是加量，是在能承受的范围里换回可控的动作」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「训练的目标是动作质量，不是次数 → 负荷没有数字，只有观察口径 → 平衡与步行：把「扶」分成三档 → 暂停比开始更需要规矩」这条链。

## 边界

本章为康复医学基础的教学整理，只写训练类别、配合要求、观察口径与停止条件，不含训练强度、频次、时长、疗程与任何可照做的动作指令；具体操作以现行规范与所在机构制度为准。
