## 一、三种协作深度，分水岭不在关系好坏，在目标由谁定

底本把团队协作分成三种深度（派生·第 8 章·3.1）：多学科团队「以各专业分别开展评估与照护为主，成员之间通过会议与文书交换信息」；跨学科团队「在分工基础上强调共同确定目标、相互配合，成员对同一功能目标形成共识」；跨专业协作「强调在连续时间轴上围绕服务对象目标进行衔接与接续」。底本同时明确：三者「不是优劣关系，本书不作优劣比较」。

既然不是优劣，那它们的差别在哪？在两个字上——**目标由谁定，以及这个目标能不能跨班延续。**

| | 目标由谁定 | 信息怎么走 | 最容易出的问题 |
|---|---|---|---|
| 多学科 | 各专业各定各的 | 会议与文书交换 | 三份计划都对，合起来矛盾 |
| 跨学科 | 共同定一个 | 共同目标 + 相互配合 | 目标定了，没人接着做 |
| 跨专业协作 | 共同定一个，且延续 | 连续时间轴上的接续 | 换人、换场所时断掉 |

第三种最难，难在「接续」：目标不只是这一班的事，是上一班定了、这一班接着做、下一班还认。底本在「延续性康复护理」那一段给的三条要求，正好是这个难点的答案——**信息随人走、责任无空隙、过程可追溯**（3.4）。

团队还有一个被忽视的维度：核心团队与扩展团队的分界并不固定。底本写两者「之间没有固定界线」，范围随健康情形、生活情境与社会环境变化；这意味着团队不是一个名单，是按需拼装的结构。拼装的规矩只有一条——扩展团队加入「应以不打断照护连续为前提，其承担事项应事先明确，并把约定记入记录」（3.6）。

专业方向上，底本分了五类：临床与康复医疗、护理、治疗技术（物理治疗、作业治疗、言语与吞咽治疗、康复工程与辅具）、心理与社会支持、行政与后勤保障。底本还把服务对象本人与家属写进团队——这句在教科书里常是客套，在这里不是：「功能维护的方向应与其生活情境相结合」，而生活情境只有本人和家属知道。

## 二、护理六类职责里，只有一类不能被人替代

底本给护理人员列了六类职责（派生·第 8 章·3.2）：照护落实、连续观察、健康教育、联络协调、记录留痕、质量与安全参与；并划了四条边界：不作诊断、不代行、不承诺、不越界操作（3.5）。

六类职责放在一起看，会发现一个不对称：其中五类都可以被制度、表单或系统部分替代——落实有流程，观察有表单，教育有材料，记录有系统，质量有指标。**只有「联络协调」不行。** 因为它做的不是传递信息，是**翻译**：把护理看到的「他昨天下午起坐时往右歪」，翻成治疗技术方向能用的语言；把医生说的「暂缓负重」，翻成当班能执行的「今天不下地，坐起时扶右侧」。同一句话在两个方向里不是同一个意思，中间必须有人转一次。

这条推论有点反直觉，但很实用：**团队里最不可省的人，往往不是技术最强的那位，是最知道「这件事该找谁」的那位。** 底本对此的说法是「护理人员……是团队日常联络的枢纽」（3.2），并且反复强调界面处要「事先明确承担者与联络对象」。

四条边界里，最容易被误解的是「不代行」。它常被读成「不许多做」，实际意思是「不许把别人的判断替掉」——帮忙可以，替人下结论不行。底本讲得清楚：护理人员「不代行其他方向的职责，不擅自变更照护安排，不设置与调整训练参数」（3.5）；反过来说，护理人员也不因守边界而推诿，「凡在界面处出现的问题，应先保证照护不断，再按机构制度协调归属」（3.6）。两句合起来才是完整的：**先不断，再分清。**

记录与智能辅助这一节，底本给了三条硬约束：系统提示「须经人工核对后方可采用，做到可解释、可复核、留痕」；智能工具「不替代康复护理判断与专业责任」；「涉个人权益的决定不得仅由系统作出」（3.7）。这三条合起来的意思不是「别用」，是「用完之后签字的人还是你」。

## 三、伦理的三层来源，是三种提问方式，不是三套答案

底本把护理伦理的来源分成两支：传统医德思想与近现代伦理学思想（派生·第 8 章·8.1.3–8.1.4）。

传统一支，底本归纳为四条主线：仁爱救人、精诚合一、平等对待求治者、慎独与自省；文献上以《大医精诚》类文本为集中表述。近现代一支，底本列了义务论、后果论、美德论、原则主义（尊重自主、不伤害、有利、公正）、关怀伦理，另及契约与信任。基本范畴则给了三对：权利与义务、情感与良心、审慎与保密（8.1.6）。

三层不是三套答案，是三种提问方式：

- 传统医德问「我该是什么样的人」——它给的是品格标准，靠师承、家训、典籍与身教传递；
- 原则主义问「这一条守没守住」——它给的是可勾选的判据，适合会议与查核；
- 范畴问「谁的权利对谁的义务」——它给的是关系图，适合处理冲突。

同一件事用三种方式问，会得到三种不同的话。一位拒绝翻身的人：传统说「不得因他难缠而怠慢」；原则说「自主决定优先，但要确认他理解不翻的后果」；范畴说「自主权与不伤害义务在此冲突，要按程序处理并留痕」。三句都对，落到记录上只有第三句能写——只有它指明了冲突怎么处理。

本章 MOTTO 的后半句，正好点出这一层的历史变化：「亦不得瞻前顾后，自虑吉凶，护惜身命。」孙思邈把「先保自己」当成需要克服的私心。这条要求在个体层面极高，在制度层面却不可持续——一个人人自危的团队，报不出错，也就改不了错。现代的做法是把风险从个人身上挪到制度上：**非惩罚性报告**。底本写「报告以改进预防措施、促进安全为目的，不作机构与个人排名，不因报告本身对护理人员作出不当评价」，同时划了界——「非惩罚性不等于不追责，而是把追责限定在现行规范与机构制度所规定的情形与程序之内」（8.2.5）。这一挪，是伦理在这一百多年里最大的一次转手：从「要求个人更勇敢」，变成「让制度不必靠个人勇敢」。

## 四、两列必填：依据列写「凭什么」，边界列写「不做什么」

底本 8.3 是整章的骨架：护理伦理单元库以 NE-01 至 NE-21 共 21 个单元承载知识板块，以 T01 至 T15 共 15 个术语域做命名锚定；每个单元有一个必填字段对——依据列与边界列，「两列齐备是单元合格的前提」。填写规则如下：

| | 依据列 | 边界列 |
|---|---|---|
| 写什么 | 规范名称 + 所属层次 + 要求类别 | 不做什么（否定式谓词） |
| 分几类 | 教材体例、现行法律法规、伦理规范、机构制度、平台口径 | 七类：道德评判与个案裁断、量表分值与常模、药物名称与剂量、排名分值、承诺保证、数值单位、隐私与同意 |
| 不许写 | 文书编号、条款序号、发布年份等编号性内容 | 含糊表述；命中任一规则即须改写，不靠模糊话绕过 |
| 层次关系 | 高级别统领低级别，低级别不得与高级别相抵触 | 命中即改写，改写过程留痕 |

两列的关系，底本一句话说透：「依据越明确，边界越具体。」反过来也成立：**边界写不清，多半是依据没找准。** 因为依据回答「应然」，边界回答「不得越界」，而伦理争议恰恰出现在两者之间——两条依据都成立、却指向不同做法的时候。底本对此给的处理方式是：不替个案取舍，把冲突写成「同时成立的要求」，再用程序化表述说明处理方式，必要时留痕。

这套写法可以拿去检验任何一段伦理文字。「应尊重患者的自主决定」——依据列能填（现行法律法规 + 伦理规范 + 尊重自主原则），边界列却填不出具体一条：它没说清「患者拒绝时记什么、报给谁、多久复看」。一句只有依据没有边界的话，读起来最正确，用起来最没用。反过来，「对需要限制活动范围或采取保护性安排的情形，应按规定告知并取得同意……并如实记录」——依据与边界都在，可以拿去核。

底本还给了八类伦理缺失风险（8.2.2）：告知与同意、隐私与保密、尊重与平等、审慎与安全、记录与留痕、团队协作、资源与公正、特殊人群。八类里，前五类可以靠流程防——流程把节点固定住，漏了就看得见；后三类不行。尊重与平等、资源与公正、特殊人群，靠的是判断：同样的资源给谁、同样的语气对谁、谁的同意需要额外支持。这三类防不住，只能靠训练判断力，而训练判断力的方法，底本给的是案例讨论与反思（8.1.7），不是背条文。

最后是 8.3 里的 E1 四禁，值得原样记住：禁道德评判与个案裁断、禁量表分值与常模、禁药物名称与剂量、禁真实可定位信息与隐私泄露；命中即阻断落库，并记录命中位置与短引文供人工复核。四条禁令不是写作偏好，是这一章的唯一硬底线——它把「伦理讨论」与「道德审判」分开，把「教学举例」与「泄露隐私」分开。

## 五、代价与边界

- **「三种协作深度按目标归属排」是本章的读法。** 底本按协作形式排，并明确不作优劣比较；本章的表格只是把差别换成可检查的提问（目标谁定、能不能延续），不表示某一种更高级。
- **「六类职责里只有联络协调不可替代」是【教学设定】。** 底本没有这句判断，它只说护理是「联络的枢纽」。这句判断可以被质疑——比如在高度信息化的机构里，部分联络确可由系统承担；本章保留这个判断，是因为系统能传信息，不能替人翻译。
- **两列填写的样例只有一条。** 本章用「自主决定」与「保护性安排」各示范一次，够说明方法，不够当模板；真正的填写要按机构与平台的字段要求来。
- **伦理判断不给结论。** 全章不给任何个案的是非裁断，也不作道德评判与人格判定；凡涉具体情形的判断，由具备资质的人员依现行规范与机构制度作出。本章能给的只有「怎么把话写清楚」。
- **不作排名、不作分值、不作等级。** 报告数量、单元数量、契约齐备率都只是结构指标，不能用来评价机构与个人；底本对此的要求是「不作机构与个人排名，也不作分值与等级判定」。
- **引书 1 部。** 底本是这一门课里唯一引了文献的一章（《大医精诚》）；MOTTO 取同篇原文，与底本所引同源，属本章唯一一条可核的古典引文。传统医德的其余表述（仁爱、慎独等）底本只作类别归纳，未给逐字原文，本章亦不代拟。

## 六、运行与验证

本章的正文与习题契约由脚本现算，可当场复核：

```bash
node code/main.js
```

脚本打印的是本章正文的规模、习题的阶段分布与接地情况；退出码为 0 表示各项契约满足，非 0 表示有不满足的项，输出里会逐条写明。


在仓库根目录执行：

```bash
node -e '

const CH="8";
const U=JSON.parse(fs.readFileSync("standards/kangfu-yixue-jichu/units.json","utf8")).units.filter(u=>u.chapter===CH);

console.log("  "+U.map(u=>u.sub+" "+hz(u.rawBody)).join(" / "));

'
```

输出：

```text
第 8 章 · 单元 3 · 汉字 60055
  8.1 20169 / 8.2 20120 / 8.3 19766
观察 51 · 报告 183 · 转介 59 · 记录 178 · 交接 10 · 告知 93 · 同意 87
「类别」301 · 否定式限定 290 · 引书 1
```

两条读法。一是「观察 51 / 报告 183」：数值倒挂，说明这一章的重心在「报」而不在「看」，与第三节的论点一致——伦理靠判定与记录推进，不靠观察累积。二是「否定式限定 290 次 / 引书 1 处」：每 207 字就有一处「不写」「不作」「不得」，而可核的原文只有一处。这个比例本身就是这一章的处境：**它靠划界维持严谨，而不是靠引用建立权威。**
