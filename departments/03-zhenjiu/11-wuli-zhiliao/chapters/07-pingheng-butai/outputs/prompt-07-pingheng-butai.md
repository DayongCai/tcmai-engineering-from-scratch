# 平衡、协调与步态训练 · 提示词

## 用途

给「平衡、协调与步态训练」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「物理治疗概论 → 电疗与电针 → 热疗与光疗 → 冷疗、超声与牵引 → 运动疗法基础 → 关节活动与肌力训练 → 平衡、协调与步态训练 → 运动康复方案与风险控制」这条链。

```
1. 先给本章要回答的问题，并说明它为什么不能直接套用上一章；

```

## 边界

本提示词用于教学准备，不构成诊疗或护理意见；具体操作以现行规范与所在机构制度为准。
