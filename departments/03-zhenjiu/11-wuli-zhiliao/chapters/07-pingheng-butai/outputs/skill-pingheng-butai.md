# 平衡的判据不是站得稳，是晃了还能把身体拉回来

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 一个词的次数不等于它的分量，要看它出现在什么句式里
- 这张清单只能当观察清单用，不能当评分表用
- 作为风险要素
- 作为观察要点
- 作为具体场景
- 防范措施本身会削减活动量，而活动量正是平衡能力的基础

## 边界

- **数值的边界。** 底本带单位数值命中 0 处、引书 0 部 0 次。平衡训练的动作、次数、时长、支撑面缩减顺序、辅助器具的选择界值，本课一概不给——底本没有这些内容，任何具体数字都是编的。
- **七要素不是量表。** 既往经历、步态与平衡、用药相关、感觉与认知、排泄、体位耐受、环境用具与陪伴求助，是逐项过关的清单；无分值、无权重、无界值、无分级阈值。
- **词频含修辞，口径要说明。** 12 处「平衡」中 1 处是修辞用法，已剔除；统计按单元层 `prose` 的字面匹配计数，散文体的比喻会污染词频，引用本章数字时须连带声明这一点。
- 本章为物理治疗与运动康复课程的教学材料，取自派生底本与 `standards/wuli-zhiliao` 机器可读层，不构成诊疗、康复或护理意见。平衡与步态训练须由具备资质的人员评估后安排。
