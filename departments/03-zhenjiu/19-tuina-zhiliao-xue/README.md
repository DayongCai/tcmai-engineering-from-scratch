## 一、学科定位

推拿治疗学（Tuina Therapeutics）是针灸系的核心学科，聚焦「经络腧穴—刺法灸法—针灸治疗 与推拿康复的完整链条」中的一个完整知识域。

**两处必须说明的偏倚**

1. **治疗学的节是合称**（「落枕与急性腰扭伤」「第三腰椎横突综合征与脊柱侧弯」），拆分后的兄弟病证**共用同一段正文**，Jaccard 因此被拉近——这是教材编排造成的，不是两书真同意；
2. **Jaccard 只比「用没用这个手法」，不比顺序与剂量**。同一组合换个顺序，临床差别可以很大。

**本轮修掉的两个错**

1. **㨰法/滚法 是同一手法的两种写法**（手法学用「㨰」、推拿学用「滚」），不归一化会把两书都判成「缺这个手法」；
2. **`set(zm) | set(tm) - set(covered)` 运算优先级错误**，让「手法学收录」一栏把全部手法都报成缺——加括号后归零。**这类错只会往「更严重」的方向报，必须回头看实现。**
