# 第 1 章 · 推拿治疗学不是手法目录，是从辨证到疗效评定的一条链

> **MOTTO:** 「形数惊恐，经络不通，病生于不仁，治之以按摩醪药」——《素问·血气形志》

## 一、三层定位：手法学重「术」，治疗学重「治」

教材把这件事讲得很清楚：推拿学是总学科，统「学」；推拿手法学研究手法的动作结构、操作要领、训练方法与适应证，解决「手法如何做得规范」，重「术」；推拿治疗学研究辨证、立法、选穴、择法、处方与疗效评定的全过程，解决「用什么手法、在什么部位、治疗什么病证」，重「治」。手法学是治疗学的技术基础，治疗学是基础理论与临床之间的桥。

三层定位真正的用处，是给了三把不同的尺子。手法学量「像不像」——着力面、节律、频率是否合规；治疗学量「对不对」——分型是否成立、选穴是否有据、刺激量是否与虚实相称；推拿学量「传不传得下去」——有没有形成可教、可考、可交接的体系。学生常拿第一把尺子量第三层的事：手法考了高分，临证仍开不出一张方，因为「像」与「对」不是同一个判据。

与骨伤科的边界同样要划清。骨伤科学研究骨折、脱位、伤筋的病因病机与诊断治疗，手段包括正骨、固定、药物、功能锻炼；推拿治疗学也治伤筋、关节错缝，但以手法为主要手段，范围还覆盖内、妇、儿、五官。两者在理筋整复上互相渗透，临床常配合使用。教材把这条边界写进学科定义，不是做学问的客气话——它决定了遇到骨折时你该做什么：不是加力，是转诊。

教材还点出本学科的学术落点「筋骨并调」，并把它追到《医宗金鉴》所论正骨八法「摸、接、端、提、按、摩、推、拿」。这句话的信息量在于「并」字：筋伤可致骨错，骨错又牵拉筋急，单治一头会自己把病做回去。

## 二、治则：把辨证结论翻译成刺激量的语法

治则是上承辨证、下启立法处方的枢纽。教材列四条：扶正祛邪、调整阴阳、治病求本、三因制宜。四条都不是口号，各自对应一组可执行的动作。

扶正祛邪落到手上的形态是补泻语法：手法轻柔缓和、频率较慢、时间较长、顺经操作为补，用于虚证，如脾虚泄泻缓摩腹部、按揉足三里；手法较重较快、逆经操作为泻，用于实证，如食积胃脘胀痛以较重按揉与推法消食导滞。教材在此引了两条同义经文互证——《素问·三部九候论》「实则泻之，虚则补之」与《灵枢·经脉》「盛则泻之，虚则补之」。两条并列不是重复，是把「补泻」从哲学词汇锚定到操作方向（顺经／逆经）与三个可调量（力度、频率、时间）上。

调整阴阳处理的是偏向。《素问·生气通天论》说「阴平阳秘，精神乃治，阴阳离决，精气乃绝」，教材据此给出三个可对照的处方：失眠属阳不入阴者，摩腹、按揉神门与涌泉以引阳入阴；阴虚阳亢之高血压，推桥弓、按揉太冲以平肝潜阳；小儿夜啼属心经积热者，清心经、清天河水以泻热安神。三个处方分别落在腹、颈、手三个部位，说明「调整阴阳」在推拿里从来不是全身调理的同义词，而是具体到某条经、某个方向。

治病求本给的是次序。急则治其标：急性腰扭伤疼痛剧烈，先以轻柔手法缓解痉挛止痛，待痛减再理损伤之本；缓则治其本：慢性劳损从脏腑经络、筋骨气血上调理。教材同时警告「头痛医头、脚痛医脚」的片面倾向——这句话在推拿科有现实对应：压痛点在腰，病根可能在髋或骶髂。

三因制宜是四条里唯一直接谈剂量的。因时：春夏腠理疏松，手法宜轻灵；秋冬寒冷，手法可稍重而注意保暖。因地：北方寒湿痹痛多见，可增温通类手法；南方湿热为病多见，宜注重清利与疏泄。因人：小儿皮肤娇嫩、囟门未闭者禁按揉囟门；老人气血渐衰、多兼骨质疏松，整脊类手法尤须慎重；体壮者可稍重，体弱者宜轻。

必须说清这一节的能力边界：四条治则给的是方向与相对刻度（轻／重、顺／逆、长／短），不给绝对数值。教材没有写「按压力多少牛顿」「频率多少赫兹」这类量——本课不给。谁在讲义里替你补上这些数字，谁就在替教材做它没做的实验。

## 三、八法与处方：治法是手法的组合规则

治法是治则之下的具体立法。教材取温、通、补、泻、汗、和、散、清八法，每法都配手法与适应证，这一段是全章最可操作的部分：

| 法 | 主用手法 | 典型部位与适应证 |
|---|---|---|
| 温 | 擦、摩、揉 | 掌擦督脉与膀胱经、摩腹、按揉关元气海；寒性腹痛、寒湿痹痛、虚寒泄泻 |
| 通 | 㨰、推、拿 | 沿经络循行施术；经络痹阻、气血不畅 |
| 补 | 轻柔和缓、顺经 | 缓摩腹部、按揉脾俞胃俞足三里；诸虚证 |
| 泻 | 较重较快、逆经 | 重按揉天枢、中脘；食积、气滞、便秘 |
| 汗 | 拿风池、拿肩井、推揉肺俞 | 外感表证，使腠理开泄 |
| 和 | 摩腹、按揉中脘内关、分推膻中 | 肝胃不和、气机失调 |
| 散 | 摩、揉、推，由轻到重、由周围向中心 | 跌打损伤、瘀血肿痛 |
| 清 | 推、揉、掐，手法轻快 | 清天河水、退六腑；发热、热毒内蕴 |

八法之后是处方。教材给了一张完整的处方应含的七项：治则治法、操作部位与穴位、手法选择与组合、操作顺序、刺激量（力度、频率、时间）、治疗频次与疗程、介质选用。并以颈椎病示范：立「舒筋通络、理筋整复」之法，用㨰法、按揉放松颈肩，配颈椎定位扳法或仰卧拔伸整复，再以拿法、擦法收功，嘱颈部功能锻炼。

这张七项清单的价值，是把「我会做手法」升级成「我能交代方案」。它的软处在第六项：概论只把「频次与疗程」列进要素，具体数值留到各论章逐病给出，且各病之间并不统一。所以概论读得再熟，也开不出一张能执行的方——这是教材的结构性分工，不是疏漏，但学生必须知道自己在哪一层。

## 四、作用原理的两层：可追问的因果，与不可证伪的框架

教材把原理分成两层，并给第二层每一段都加了「属现代认识」的标注。这个标注很关键，它是全章最诚实的一处体例。

中医层讲三件事。疏通经络：引《素问·血气形志》「形数惊恐，经络不通，病生于不仁，治之以按摩醪药」，说明经络不通致麻木不仁时，按摩是主要治法；《医宗金鉴·正骨心法要旨》说得更细——「按其经络，以通郁闭之气；摩其壅聚，以散瘀结之肿，其患可愈」，一句话给了部位（经络）、动作（按、摩）、中介（郁闭之气、瘀结之肿）、结果（其患可愈）四段。行气活血：《素问·举痛论》「按之则热气至，热气至则痛止矣」，这是全章唯一一个完整因果句——按是因，热气至是中介，痛止是果，推拿从此有了可被追问的中间环节。理筋整复：针对筋出槽、骨错缝，以拔伸、扳、摇、旋转纠正位置关系，使「骨正筋柔、气血以流」；《医宗金鉴》「一旦临证，机触于外，巧生于内，手随心转，法从手出」讲的是这类手法的操作状态——判断在手上完成，不在纸上完成。

现代层讲四条通路：生物力学（降低肌张力、松解粘连、调整关节突关节位置、改变突出物与神经根的关系）；神经生理（机械感受器激活、脊髓闸门、内啡肽与脑啡肽释放、自主神经调节）；循环与代谢（毛细血管扩张、血流加快、皮温升高、致痛物质清除）；内分泌与免疫（皮质醇、5-羟色胺、免疫球蛋白）。教材在这些段落反复写「可辅助参考，临床决策以医者为准」。

两层的关系要说准：中医层提供的是组织经验的语言，现代层提供的是可测量的量。教材给出的可测参数只有手法频率一类（㨰法约每分钟 120～160 次、擦法约每分钟 100～120 次），且明确标为现代认识。至于「治疗多少个疗程后有效率多少」这类数字，教材不给——本课不给。把两层混着讲，最容易产出的就是一句谁也无法反驳、也无法使用的「通则不痛」。

## 五、代价与边界

**篇幅证明教材写了什么，不证明学生学会了什么。** 8,585 汉字里，操作要领与原理阐释占大头；但文字能传的只有着力面、方向、顺序和相对轻重，「按下去多深」传不了。同一个按法，两个人做可以差数倍，读不出，也考不出。这是文本的硬边界。

**六节等长是编纂的产物，不是重要性的排序。** 概念 1,431 字、治则 1,335 字、现代机制 1,462 字，三者相差不到 130 字。若按临床权重排，治则与治法应当更厚，现代机制应当更薄且更谨慎。学生若把篇幅当权重，就会把复习时间按字数分配，正好分错。

**原理不具备证伪能力。** 「疏通经络」能解释有效，也能解释无效——无效时说「瘀得太深」。把它当机制，得到的是一套推不翻的说法；把它当组织临床经验的方式，它才有用。教材对现代层加「属现代认识」的做法，实际上就是在替读者守住这条线。

**学科边界既保护病人，也限制本课。** 定义里写明推拿以功能性疾病、慢性劳损与康复期疾病为优势病种，凡皮肤破损、感染、溃疡、肿瘤局部、骨折未愈合、出血性疾病、脊柱不稳、骨结核、严重骨质疏松及孕妇腰腹部，均属禁忌或慎用；脊髓型颈椎病、马尾综合征、脑血管意外急性期须十分慎重。这一串名字不是免责套话，它是本课程能讲多远的实际边界：边界之外的病，本课的正确回答是转诊，不是加手法。
