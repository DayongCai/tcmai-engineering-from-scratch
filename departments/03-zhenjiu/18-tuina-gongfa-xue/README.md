**三调：调身讲得最多，调心讲得最少**

调身 2031 / 调息 1390 / 调心 448，比值 **4.5×**。
可写的动作被写尽了，不可写的意念只能点到——**这不是缺陷判断，是文本事实**，已写进第 3 章与全书各章。

**第五层对账：功力供给 vs 手法需求**

两书体量差 2.7 倍（功法学 94,257 vs 手法学 255,169），故用**每万字密度**而非绝对数：

| 力道 | 功法学（供给，每万字） | 手法学（需求，每万字） | 密度比 |
|---|---:|---:|---:|
| 指力 | 13.7 | 18.0 | **0.76** |
| 腕力 | 34.5 | 31.9 | **1.08** |
| 臂力 | 37.8 | 33.5 | **1.13** |
| 腰腿力 | 80.9 | 45.0 | **1.8** |

**唯一的缺口是指力（0.76）**，其余三类都供过于求。这条缺口值得单说：

- 手法学里最吃指力的正是一指禅推法（单节 14,301 字，全书最大）；
- 功法学里指力专项训练写得比腕、臂、腰腿都稀，重心在桩功（下肢静力）。

**不简单判为「教材遗漏」**：桩功练的是全身整合与耐力，指力靠手法本身反复练出来；但两本书既然分开写，这条错位就该被指出来，而不是在两门课之间消失。

**数值类命中只有 59 处（全书最低）——是写法不是剂量**

功法书用汉字数字（「三十六式」「练三百息」「三十分钟」），按阿拉伯数字统计自然抓不到。**数值少不等于剂量松，是剂量用的是另一套写法。** 这条与儿科第 2 章的发现同源。
