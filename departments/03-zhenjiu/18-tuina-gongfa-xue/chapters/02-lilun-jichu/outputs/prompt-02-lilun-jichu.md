# 理论给的是练功的说法，不是练功的做法 · 提示词

## 用途

给「理论给的是练功的说法，不是练功的做法」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「学习目标 → 正文 → 运行与验证 → 资料来源（主要参考）」这条链。

## 提示词

```
我在学《推拿功法学》第 2 章「理论给的是练功的说法，不是练功的做法」，本章 4 节 / 3,788 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 注意底本在这一段没有一个量化词
   - 整章关于「怎么想」的内容，被压进了一个小节
   - 理论在临床上的用法，是给手法指路线，不是给疗效打保票
   - 五行是一套关于「套路之间怎么配」的语言
   - 丢掉了什么
   - 这一章能让你说清道理，不能让你判断今天练够了没有
4. 本章自陈的边界（不得越过）：
   - **丢掉了什么。** 理论解释的是「为什么可能有效」，不描述「有效是什么样」。全章 0 处带单位数值、0 个阿拉伯数字字符，最接近判据的一句是「练后食量渐增、体力渐旺」及它的反面「食欲减退、倦怠加重」，正反都只是方向，没有阈值，不可交付、不可考核。**这一章能让你说清道理，不能让你判断今天练够了没有。**

   - **模型的边界。** 藏象、经络、阴阳三层并置而不换算：藏象说「脾主肌肉」，经络说「足阳明行于前」，阴阳说「阳虚宜动」；三句可同时成立，指向的动作却不同，底本不裁断。任督周天之说，底本自己限定为「经验性描述」「不作解剖学定位之主张」，本章照录这道限制，不越过它去谈气感。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为推拿功法学教学整理，取自教材表述与 `standards/gongfa` 机器可读层，不构成诊疗建议，也不能替代医师面诊与带教。本章讲的是理论的用法与边界，不含任何功法动作指导；具体操作以现行规范与所在机构制度为准。
