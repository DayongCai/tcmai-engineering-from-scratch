# 中风康复这一站，判据在功能，不在症状轻重 · 提示词

## 用途

给「中风康复这一站，判据在功能，不在症状轻重」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「八节等长，说明这是体例，不是判断 → 先分清是哪侧的脸：一条额纹定方向 → 功能有三层，缺一层就练错方向 → 把症状课翻译成功能课：三个动作」这条链。

```

正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
```

## 边界

本章为教学材料，不构成医学意见、诊断或康复指导。文中病证、界值与判据转述自底本单元层，字数与极差为程序现算；具体操作以现行规范与所在机构制度为准。
