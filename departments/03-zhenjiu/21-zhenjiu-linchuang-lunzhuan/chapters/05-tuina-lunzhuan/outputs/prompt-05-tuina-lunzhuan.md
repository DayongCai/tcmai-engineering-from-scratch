# 推拿这一站考的不是会不会做，是第十次还一样不一样 · 提示词

## 用途

给「推拿这一站考的不是会不会做，是第十次还一样不一样」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「一半篇幅在讲"手法之外" → 四要素不是形容词，是四个失效模式 → 刺激量：力×频率×时间，可以记账 → 程序与红线：一松二整三理」这条链。

## 提示词

```
我在学《针灸临床轮转》第 5 章「推拿这一站考的不是会不会做，是第十次还一样不一样」，本章 5 节 / 3,138 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 这一站真正要练的，是把一个动作在五分钟里保持成同一个动作
   - 发力路径错了，先坏的是自己的手
   - 每次治疗都走"轻—重—轻"
   - 扳法不是"敢不敢"的问题，是"配不配"的问题
   - 本课不给手法参数的标准值
   - 17 节里没有一节能替代练功
4. 本章自陈的边界（不得越过）：
   - **本课不给手法参数的标准值**：120～160 次/分、3～5 分钟这些数字转述自底本，是"同书的表述口径"，不是规范值。真正施术时的力度、频率、时长按现行规范、机构制度与患者耐受确定。
   - **17 节里没有一节能替代练功**：底本反复强调"功到自然成"、沙袋练功、易筋经锻炼，这些是手上的功夫，读多少字都换不来。本章只能帮你把"验收标准"想清楚，不能替你练。
   - **占比只描述写法**：43.9% 的篇幅在讲共同要求，说明底本认为稳定性是难点，不说明单一手法可以少学。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，不构成医学意见、操作指令或治疗指导。文中手法要领、参数与禁忌转述自底本单元层，字数与占比为程序现算；具体操作以现行规范与所在机构制度为准。
