# 面瘫这一站先问窗口，窗口判错，手法方向就是反的 · 提示词

## 用途

给「面瘫这一站先问窗口，窗口判错，手法方向就是反的」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「两节 7,469 字，面瘫不在里面 → 四个病，同一个问题：这一期还能不能回 → 窗口之内与窗口之外：手法方向为什么相反 → 四条红线，都带时限」这条链。

```

正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。
```

## 边界

本章为教学材料，不构成医学意见、诊断或治疗指导。文中病名、分期与时限转述自底本单元层，字数与词频为程序现算；具体操作以现行规范与所在机构制度为准。
