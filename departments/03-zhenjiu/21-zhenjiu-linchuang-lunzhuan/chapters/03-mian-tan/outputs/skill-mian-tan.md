# 面瘫这一站先问窗口，窗口判错，手法方向就是反的

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 面瘫一节在底本属内科病证那一组的 2.7（2,664 字）
- 每一个病都被切成"期"或"型"之后再谈手法
- 这一期还能不能回去
- 面瘫：急性期做减法，恢复期做加法
- 鼻炎：发作期与缓解期的目标不同
- 耳鸣：实证可稍重，虚证只能轻

## 边界

- **底本这一站没有面瘫节，这是本课最需要说明的一处错位。** 面瘫的分期判据取自同书内科病证那一组的 2.7（2,664 字），不是这两节的内容。把两处并起来读，是本课的处理方式，不是底本的原编排；引用时请分别注明 2.7 与 3.1、3.2。
- **本课不给周围神经损伤的评估工具**：神经传导、肌电图、面神经功能分级（如 House-Brackmann 分级）本课一律不给，底本没有，不凭常识补。需要用的，按神经科与康复专业课的规范。
- **本课不给针刺参数与操作量**：进针、留针、电针、每次推拿的时长与次数，底本写作同书的表述，本课不复述成规范。
- 本章为教学材料，不构成医学意见、诊断或治疗指导。文中病名、分期与时限转述自底本单元层，字数与词频为程序现算。
