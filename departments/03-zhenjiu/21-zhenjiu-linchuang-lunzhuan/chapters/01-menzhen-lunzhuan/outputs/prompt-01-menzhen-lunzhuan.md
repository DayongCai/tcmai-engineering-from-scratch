# 门诊这一站，先学会停手，再学会配穴 · 提示词

## 用途

给「门诊这一站，先学会停手，再学会配穴」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「底本把笔墨压在"不能做什么"上 → 三组病种，三把不同的定位刀 → 加穴的理由要落在"受累组织"上，不落在"症状"上 → 几周能带走的一张分诊卡」这条链。

## 提示词

```
我在学《针灸临床轮转》第 1 章「门诊这一站，先学会停手，再学会配穴」，本章 5 节 / 3,141 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 停手条件必须先学，因为代价不对称
   - 脊柱组切的是"责任节段与受累组织"
   - 关节与筋腱组切的是"哪一个动作"
   - 神经卡压组切的是"分布区"
   - 局部越痛，越要先把患者的气血与注意力引到远端去
   - 本课不给针刺参数与疗程
4. 本章自陈的边界（不得越过）：
   - **本课不给针刺参数与疗程**：底本写到"10 次为一疗程、每次 20～30 分钟"一类的话是同书的表述，本课不复述成操作规范；进针深度、角度、留针时间、电针波形一律不在本课范围，按现行规范与所在机构制度执行。
   - **本课不给病例**：正文里没有一例真实患者。凡是"某患者"的写法都是你要在带教面前自己补的功课，不是本课提供的素材。
   - **43 次「转诊」不等于 43 条红线**：同一个意思在不同节里重复出现（如"骨折未排除禁推拿"在颈、腰、踝各写一次）。数字说明底本对停手的重视程度，不能当成红线条数来背。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，不构成医学意见、诊断或治疗指导。文中病名、体征与操作要点转述自底本单元层，字数与占比为程序现算；具体操作以现行规范与所在机构制度为准。
