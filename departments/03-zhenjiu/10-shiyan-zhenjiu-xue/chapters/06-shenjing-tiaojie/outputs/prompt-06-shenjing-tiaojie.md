# 针灸对神经系统的调节 · 提示词

## 用途

给「针灸对神经系统的调节」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「绪论 → 腧穴形态 → 经络现象 → 效应特点 → 镇痛 → 神经 → 内分泌免疫 → 循环呼吸消化 → 泌尿生殖运动 → 方法与模型 → 循证与前沿」这条链。
