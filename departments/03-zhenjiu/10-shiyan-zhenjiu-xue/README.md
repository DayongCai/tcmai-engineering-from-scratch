## 四、这门课最大的教学风险

**把机制当结论**。教材里「针刺可调节 X 系统」的表述后面常跟着动物实验，
**动物有效不等于人体有效，指标变化不等于临床获益**。每章判据都要求区分三件事：
①有证据（人体研究）②有机制解释（动物/离体）③只有推测。
