## 一、这一章的问题

同样一个手法，两本教材给的频率能差一倍，标准该怎么立——教材把答案拆在两处：总论讲分类与要求，各类手法章讲单个手法的动作与要领。本章把两处并读：分类给的是坐标，手法给的是动作。

## 三、同类手法在两本教材里的频率对账

把《推拿手法学》与《推拿学》里同一个手法的频率逐项对，能看出「标准」在哪些地方还没统一：

| 手法 | 手法学（次/分） | 推拿学（次/分） | 判定 |
|---|---|---|---|
| 一指禅推法 | 120–160 | 120–160 | 一致 |
| 滚法 | 120–160、100 | 120–160 | 部分一致 |
| 揉法 | 120–160 | 120–160 | 一致 |
| 摩法 | 120、100–120、100 | 120 | 部分一致 |
| 擦法 | 100–120 | 100–120 | 一致 |
| 推法 | 20–30 | 120–160 | 数值不一致 |
| 搓法 | 120 | 120–160 | 数值不一致 |
| 抖法 | 200、100 | 120–150、200、100–120 | 部分一致 |
| 振法 | 300–600、200 | 300–600 | 部分一致 |
| 捻法 | 120–200 | 120–200 | 一致 |
| 拍法 | 80–120 | 100–150 | 数值不一致 |

22 个共同手法里：**一致 4**、**部分一致 4**、**区间不同 3**、**仅一方给数 4**、**双方都没给数 7**。

两条要单独记的：

1. **搓法**：《手法学》「每分钟 120 次左右」，《推拿学》「120 至 160 次」——区间有包含关系，不是矛盾，是宽窄不同；
2. **拍法**：《手法学》「80～120 次」，《推拿学》「100～150 次」——重叠段 100–120，两端各不同，属**教材分歧**，本库并列保存，不裁定。

还有一条是**方法学教训**：初版按「单元」取数，把《推拿学》里「一指禅推法…摆动频率 120～160 次」算到了「推法」头上，凭空造出「推法 20–30 vs 120–160」的假分歧。改成**按手法名切段取数**后消失——**单元级取数会把 A 手法的数串给 B 手法，这不是教材的问题，是读法的问题。**

### 3.2.1 操作程序

> 一次完整的推拿治疗，应当遵循一定的操作程序进行。历代推拿医家在长期临床实践中总结出「由上而下、先轻后重、由浅入深」的操作顺序，并辅以先健后患、先远后近等原则，这些程序性要求既是疗效的保证，也是安全的保证，推拿操作必须按部就班、有条不紊。操作程序的确立，源于对人体气血运行规律的认识与对患者接受程度的把握，绝非可有可无的形式。由上而下，是指操作部位一般按照头面、颈项、肩背、腰骶、上肢、下肢的顺序依次进行。人体经脉气血自上而下运行，操作自上而下顺应气血流行之势，符合经络学说「顺经为…
>

## 六、代价与边界

**丢掉了什么。** 教材用文字写动作（着力面、摆动频率、移动速度），丢掉的是**手下的功力量感**：同样「沉肩垂肘、每分钟 120 次」，两个人做出来可以是两种东西。文本能证明教材怎么要求，不能证明你做对了。

**数字的边界。** 数值类命中只统计带单位的（次/分、分钟、寸、kg）；「持久、有力、均匀、柔和、深透」这五个核心要求一个都不带单位，因此不计入——**不是教材没写要求，是要求本身不可数**。

**方法的边界。** 本章按小节号从单元层直读；跨教材比数时按**手法名切段**，不按单元——一个单元常同时讲几种手法，按单元取数会串。

**免责声明：** 本章为教学整理，内容不构成诊疗建议，也不能替代带教与规范化培训；运动关节类手法（扳法、拔伸）风险高，须在明确诊断后由受训人员按规范实施，本章不提供任何自行操作指引。
