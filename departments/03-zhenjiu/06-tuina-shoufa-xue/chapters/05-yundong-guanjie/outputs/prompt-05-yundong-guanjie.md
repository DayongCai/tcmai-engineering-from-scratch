# 关节的极限写在解剖里，不写在手感里 · 提示词

## 用途

给「关节的极限写在解剖里，不写在手感里」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「学习目标 → 正文 → 运行与验证 → 资料来源（主要参考）」这条链。

