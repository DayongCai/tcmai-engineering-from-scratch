# 骨伤与慢病康复的底本只收了颈、腰和落枕三个病

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 本课不给骨伤术后康复
- 本课不给慢病管理方案
- 本课不给疗程与频次
- 本课不给影像与分型诊断
- 三类腰痛不按腰痛治
- 阿是穴与放血有前提

## 边界

- **本课不给骨伤术后康复。** 骨折术后、关节置换术后的固定期与负重期管理，底本 0 字。术后何时负重、练什么、练多久，以手术记录与骨科康复规范为准。
- **本课不给慢病管理方案。** 「糖尿病」「高血压」在底本中各 0 次。降糖、降压、运动处方、随访间隔，均以现行慢病管理规范为准。
- **本课不给疗程与频次。** 「疗程」0 次、「训练」0 次。针刺几次、间隔多久、总共几周，本章没有；凡读到这类数字，都不是从本章来的。
- 本章为中医康复学教学材料，内容取自《针灸治疗学》相关单元的机器可读层，不构成医学意见、诊断或操作指导。针刺与放血属医疗行为，须由具备资质的人员实施。
