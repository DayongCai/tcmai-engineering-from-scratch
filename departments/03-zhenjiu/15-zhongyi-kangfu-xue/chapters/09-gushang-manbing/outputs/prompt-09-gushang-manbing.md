# 骨伤与慢病康复 · 提示词

## 用途

给「骨伤与慢病康复」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「中医康复学概论 → 辨证与功能评定 → 中药康复 → 针灸康复 → 推拿康复 → 气功导引康复 → 饮食与情志康复 → 中风康复 → 骨伤与慢病康复 → 社区与家庭康复」这条链。

```
4. 最后给出三条边界：哪些内容只能写到类别、哪些必须由具备资质的人员作出、哪些情况按父课教材与现行规范（须注明出处）报告。

要求：不编造教材没有的数字；引文写到《书名·篇名》级并标注是否本章原文篇名；

```

## 边界

本提示词用于教学准备，不构成诊疗或护理意见；具体操作以现行规范与所在机构制度为准。
