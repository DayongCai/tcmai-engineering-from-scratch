# 宋金元把穴定成标准，把时间算成取穴依据

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 四大家在本章是「提及」级别，不是「立传」级别
- 事故多到必须立标准
- 可以通过一次操作判对错的知识
- 第一件是得气
- 第二件是灸温
- 「影响」段 0 原文，是本章最大的读法风险

## 边界

- **「影响」段 0 原文，是本章最大的读法风险。** 五个 6.x.4 节全部无摘句，讲「影响了谁」时只有评价没有原文。凡引用这类判断，须知道它回不到一手文献。
- **四大家是提及级。** 3,098 字 / 4 人 ≈ 775 字/人，不到其他四家的三分之一。别用本章的篇幅去衡量四大家对针灸的分量。
- **铜人的穴数不等于今天的标准。** 教材说《铜人经》载穴 354 个，其体系多为后世所承；本章不逐一核对它与现行国家标准的对应关系，也不据这个数推断临床结论。
- 本章为教学整理，内容不构成诊疗建议，也不能替代医师面诊与规范化操作培训。所引《铜人腧穴针灸图经序》《标幽赋》《卫生宝鉴》《儒门事亲》文字为文献摘录。
