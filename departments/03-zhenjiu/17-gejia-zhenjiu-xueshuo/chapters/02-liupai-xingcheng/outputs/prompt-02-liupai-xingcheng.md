# 流派的判据是三根柱子，不是一张分类表 · 提示词

## 用途

给「流派的判据是三根柱子，不是一张分类表」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「学习目标 → 正文 → 运行与验证」这条链。

## 提示词

```
我在学《各家针灸学说》第 2 章「流派的判据是三根柱子，不是一张分类表」，本章 3 节 / 3,688 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 第一把刀按学术特色切，切出五类
   - 第二把刀按传承脉络切，切出三类
   - 格子比证据多
   - 源远方能流长，流变亦不失其源
   - 本章 0 处原文，是它最大的边界
   - 分类是两把刀，不是一张网
4. 本章自陈的边界（不得越过）：
   - **本章 0 处原文，是它最大的边界。** 关于流派的全部判断都建立在转述之上。三个可核点是：2.1.1 引《灵枢·官能》的先师之传、2.1.2 引《素问·异法方宜论》的五方异治、2.2.1 引《灵枢·五十营》的营卫昼夜五十周——教材只报篇名，未录原文，读者要自己去核。
   - **分类是两把刀，不是一张网。** 同一个医家可同时落在两格，这不是矛盾而是常态；把某人钉死在一格里，就丢了另一格的证据。
   - **「现代学院流派」是概念的扩张。** 标准化、规范化、科研化讲的是传播与评价方式，不是学理内核。把它与经典学派并列，须保留一分：前者能证明学术被组织起来了，不能证明主张被验证了。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学整理，内容不构成诊疗建议，也不能替代医师面诊与规范化操作培训；具体操作以现行规范与所在机构制度为准。
