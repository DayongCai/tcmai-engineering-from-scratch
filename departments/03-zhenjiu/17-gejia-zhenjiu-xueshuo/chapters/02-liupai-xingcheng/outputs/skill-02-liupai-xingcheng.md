# 流派的判据是三根柱子，不是一张分类表

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 第一把刀按学术特色切，切出五类
- 第二把刀按传承脉络切，切出三类
- 格子比证据多
- 源远方能流长，流变亦不失其源
- 本章 0 处原文，是它最大的边界
- 分类是两把刀，不是一张网

## 边界

- **本章 0 处原文，是它最大的边界。** 关于流派的全部判断都建立在转述之上。三个可核点是：2.1.1 引《灵枢·官能》的先师之传、2.1.2 引《素问·异法方宜论》的五方异治、2.2.1 引《灵枢·五十营》的营卫昼夜五十周——教材只报篇名，未录原文，读者要自己去核。
- **分类是两把刀，不是一张网。** 同一个医家可同时落在两格，这不是矛盾而是常态；把某人钉死在一格里，就丢了另一格的证据。
- **「现代学院流派」是概念的扩张。** 标准化、规范化、科研化讲的是传播与评价方式，不是学理内核。把它与经典学派并列，须保留一分：前者能证明学术被组织起来了，不能证明主张被验证了。
- 本章为教学整理，内容不构成诊疗建议，也不能替代医师面诊与规范化操作培训。
