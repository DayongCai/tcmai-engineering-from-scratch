# 歌赋用押韵换来了记得住，代价是把异文压成一个说法 · 提示词

## 用途

给「歌赋用押韵换来了记得住，代价是把异文压成一个说法」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「八节四十九条：歌赋章的分布本身就是一个论点 → 赋：理论密度高的那几节，正好是能逐字核的那几节 → 歌与诀：压缩到四句，代价是限定条件被压没了 → 一条口诀的四处异文，以及怎么读才不被它骗」这条链。

## 提示词

```
我在学《针灸医籍选》第 6 章「歌赋用押韵换来了记得住，代价是把异文压成一个说法」，本章 6 节 / 3,817 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 四十九条原文按节的分布是：8.2.2《标幽赋》16 条、8.3.2《通玄指要赋》6 条、8.4.2《百症赋》10 条、8.5.2《玉龙赋》1 条（《胜玉歌》1 条待核）、8.6.2《席弘赋》12 条、8.7.2《金针赋》1 条、8.8.2《灵光赋》1 条（《天星十二穴》《四总穴歌》2 条待核）、8.9.2《兰江赋》《流注指微赋》2 条（《回阳九针歌》1 条待核）

   - 得气一段是全赋最见功力处：「先详多少之宜，次察应至之气
   - 这一句还有一处教材内部的分级不一致值得记下：第 1 章讨论得气时，引「气速至而速效」标的是「转述」；本章 8.2.2 把它列入【原文】
   - 《通玄指要赋》的方向相反，它把理论压到最少，把取穴铺到最多
4. 指出本章写到类别就止步、不再给参数的地方。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```
