# 《素问》立治则，《难经》把治则算成补泻公式

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 《宝命全形论》把针刺的前提列成五条，而且给了一个不太客气的开头：「故针有悬布天下者五，黔首共余食，莫知之也
- 「治神」到底治什么，同篇紧接着说：「凡刺之真，必先治神，五脏已定，九候已备，后乃存针，众脉不见，众凶弗闻，外内相得，无以形先，可玩往来，乃施于人
- 操作层面的描写在同篇另一处：「刺虚者须其实，刺实者须其虚，经气已至，慎守勿失，深浅在志，远近若一，如临深渊，手如握虎，神无营于众物
- 《调经论》开头把问题拉回脏腑：「百病之生，皆有虚实，今夫子乃言有余有五，不足亦有五，何以生之乎
- 这段话的推理链值得拆开看：五脏各有所藏（神、气、血、肉、志）→ 五脏之道皆出于经隧 → 经隧行血气 → 血气不和则百病变化 → 所以「守经隧」
- 把这两处并读，本章的第一层判断就成形了：先定病在五脏中的哪一脏（定虚实），再定病在哪一层组织（定深浅与刺法），最后才谈取穴

- 只写类别与要点，不写操作参数。
- 本章为针灸医籍教学文本，所论治神、守经隧、缪刺巨刺、针刺深浅与补泻取穴均据教材与经典条文，不含任何刺灸操作参数。针刺、艾灸与刺络放血须由具备资质的执业人员在诊断明确后施行。
