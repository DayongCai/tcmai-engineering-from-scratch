# 医案留下的是一条决策链，不是一个成功率 · 提示词

## 用途

给「医案留下的是一条决策链，不是一个成功率」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「一条案子的四端，与读案的四步 → 21 比 6：疗效词的分布暴露了体裁，不是暴露了水平 → 三案连读：手法替代、标本次序、急则治标 → 气至：案文里最薄的一环」这条链。
