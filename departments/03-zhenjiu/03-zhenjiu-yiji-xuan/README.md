## 四、这门课的核心判据：三层要分得清

读一段医籍，必须能指着文本说清三件事：**①哪句是原文 ②哪句是注家的话 ③哪句是教材作者的按语**。
分不清这三层，就会把「注家的发挥」当成本经原意，这是医籍课最常见也最难纠正的错。

本课的引文一律标到**书名＋篇名**（如《灵枢·九针十二原》），教材只写书名的，标「教材只写书名」。
