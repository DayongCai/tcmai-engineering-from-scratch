# 第 8 章 · 「有效」与「证据充分」是两列，并成一列就会说谎

> **MOTTO:** 「上工刺其未生者也；其次，刺其未盛者也。」——《灵枢·逆顺》
>
> **PROBLEM:** 本章 5 段共 11,838 汉字，「证据」出现 89 次，全部集中在 3 段里（4,682 + 3,163 + 2,929 = 10,774 字，占 91.0%）；剩下两段是痿证的取穴（394 字）与治神守气（670 字，占 5.7%）。证据讲得很足，安全性几乎没讲——整章对不良事件只有一处清单式列举。本章要做的事就是把这两列接回同一张表。

**双根因定位:** 环境逼迫（同一个病，指南说「可考虑」、教材说「疗效较好」、患者听到的是「能治好」，三句话指向三个不同的证据强度）+ 知识积累（要判断一句话能说多重，得先会读对照类型、效应量与证据分级，这套语言不学就只剩形容词）

**教材出处:** 派生课（无独立教材）；单元层 `standards/zhenjiu-zhentong-mazui/units.json`；本章取数 `standards/zhenjiu-zhentong-mazui/chapter-map.json`；原始出处见各单元 `source` 字段（父课 `shiyan-zhenjiu`、`zhenjiu-zhiliao`）。

## 一、把病种放进两维表里

教材第二段把针灸临床证据的现状分成两类：一类已有相对较好的证据支持，一类证据不足或结论不一。这个二分法是对的，但不够用——它没有把「效应有多大」与「证据有多硬」分开。分开之后，四个格子各自对应的说话方式完全不同：

| | 证据质量较高 | 证据质量低或不足 |
|---|---|---|
| **效应小到中等** | 偏头痛发作预防、紧张型头痛预防、术后恶心呕吐（内关）、膝骨关节炎短期疼痛 | 急性肾绞痛止痛、慢性颈肩痛、癌痛辅助 |
| **效应接近无效或结论不一** | 辅助生殖（以活产率为结局的高质量试验为阴性） | 慢性腰背痛、纤维肌痛、抑郁症、失眠、戒烟、过敏性鼻炎、贝尔面瘫、卒中后康复 |

这张表按教材第二段的表述整理，不是本章自行做的合并分析。它的用处有三个。

第一，左上格是**可以说得比较硬**的地方：有证据、有效应、效应不大。这里的正确说法是「可作为非药物选项之一」「可能减少发作天数」，而不是「针灸治偏头痛有效」。

第二，左下格是**最容易被说错**的地方。高质量试验给出阴性结果，不代表针刺对所有人都无效，但它确实把「有效」这句话的强度压到了最低。教材举辅助生殖为例，说明一项以活产率为结局的高质量试验如何改写了既往小样本的阳性结论——这个例子值得反复讲，因为它演示了证据更新的方式。

第三，右下格是**必须说「不知道」**的地方。教材的原话是「证据不足并不等于证明无效，只说明目前缺乏足够证据支持推荐」。这句话要完整地说，不能只取前半句（那是推销），也不能只取后半句（那是否定）。临床上最常见的两种错误正好各取一半。

慢性腰背痛横跨两格，值得单列：教材明确写到，较早的分析与部分国家指南倾向把它列为非药物选项，而纳入更严格试验、采用假针刺对照的更新分析提示效应缩小或消失，指南推荐也随之变化。同一个病、同一个干预，结论随方法学而变——这不是教材自相矛盾，这是证据的常态。

## 二、证据为什么会缩水

教材第二段列了四条争议，每一条都能翻译成一个读文献时的动作。

**第一条，真针与假针的差异是否显著。** 动作：先看对照是什么。以假针刺为对照，效应量通常明显小于以不治疗或等候治疗为对照；而假针刺本身并非无活性——非穴浅刺与可缩回钝头针仍产生触觉刺激，可能激活部分传入纤维。所以「真针不优于假针」不能直接读成「针刺无效」，它可能只说明对照选得太强。反过来，若对照完全不接触皮肤，受试者容易识别，期望效应被削弱，又可能高估真针。教材的结论写得很克制：现有证据提示针刺可能存在一定的特异效应，但大小仍不确定。

**第二条，安慰效应与非特异效应占多大比重。** 动作：看结局是主观量表还是硬指标，看是否报告了期望的测量。针刺治疗里含有大量与穴位无关的成分：期望、医患交流、环境与仪式感、卧位的放松、针刺带来的触压与酸麻感。这些在以主观感受为主的结局（疼痛、失眠、功能性症状）里作用最大。

这一条与教材第五段「治神守气」正好接得上。那段文字说「凡刺之真，必先治神」（《素问·宝命全形论》）、「粗守形，上守神」（《灵枢·九针十二原》），讲的是医者专一其神、患者安神定志、意守感传。用今天的语言说，这段讲的就是注意力、期望与医患互动对疗效的贡献。古人把它当作技术的一部分认真经营，现代试验把它当作需要被分离的非特异效应——两种态度并不冲突，冲突的是「只承认其中一种」。

**第三条，个体化辨证与标准化设计的矛盾。** 动作：看干预是怎么描述的。固定处方便于重复，但反映的是该处方在特定人群中的平均效应；允许医师自由加减则更接近临床，却难以描述、难以比较。教材说目前没有普遍接受的最优方案，这个「没有」应当如实转述，不要替它补一个答案。

**第四条，发表偏倚与语言偏倚。** 动作：看检索截止日期、看是否注册、看阴性结果有没有被报告。小样本研究的效应量普遍大于大样本研究，这是针灸文献里被反复观察到的现象。教材还提到一个机制性的解释：随着临床试验注册制度推行，事后变更主要结局或只报阳性结果的情形正在受到约束，但历史文献里的偏倚仍需在解读时扣除。

四条合起来给出一句判断：读到「针灸有效」时，先问它对什么、比什么、效应多大、证据几级。四个问题缺一个，这句话就只能当线索。

## 三、第二列：安全性

教材第三段有一份完整的不良事件清单，写得比疗效部分更具体：针刺局部疼痛、出血与血肿、晕针（头晕、心慌、出汗、面色苍白甚至短暂昏厥）、电针电极处皮肤灼伤或过敏、消毒不严造成的局部感染，以及较少见的断针与气胸。同一段还给了预防与识别的方向，以及一份必须转诊的就医提示。

这份清单要按「可预防」与「必须转诊」两栏重排，才有操作价值：

| 可预防 | 靠什么 |
|---|---|
| 局部疼痛、血肿 | 部位选择、操作手法、出针按压、抗凝状态评估 |
| 晕针 | 体位（避免空腹与疲劳状态下施术）、过程中观察、出现前驱症状即停止 |
| 电针灼伤、过敏 | 设备与电极检查、强度由小渐大、贴片位置避开破损皮肤 |
| 局部感染 | 消毒、一次性针具、局部皮肤条件评估 |
| 断针 | 针具检查、进针前排除弯针、操作中避免强拉 |

| 必须停止并转诊 | 识别信号 |
|---|---|
| 气胸 | 针刺后突发胸痛、气促、患侧呼吸音减弱 |
| 晕针不缓解 | 平卧后仍面色苍白、心率血压持续异常 |
| 血肿扩大或感染 | 局部迅速肿胀、皮温升高、红肿热痛加重 |
| 神经损伤表现 | 持续麻木、无力、放射痛加重 |

这张表里没有一个数字：不给针刺深度、不给留针时间、不给晕针的发生率。原因不是回避，而是这类数值随部位、体型与操作者差异极大，写进教材会被当成通用阈值。本课不给。

更值得注意的是两列之间的关系。教材对疗效的措辞极其谨慎（「可能」「小到中等」「证据不足」），对安全性的措辞反而具体（能列出七八类事件、能给出转诊信号）。这个不对称是合理的：疗效需要证据支撑才能说重，风险只要有可能发生就必须说清。教学里如果反过来——疗效说得斩钉截铁、风险一句「注意安全」带过——那就是把两列的轻重颠倒了。

## 四、措辞纪律：把证据等级译成一句话

证据分级（教材第一段讲的五条降级维度：偏倚风险、不一致性、间接性、不精确性、发表偏倚）对本科生来说太抽象，落到嘴上只需要五档：

| 档 | 说法 | 用在哪 |
|---|---|---|
| 较强 | 「可以作为……的选项之一」 | 左上格，且指南已有推荐 |
| 中等 | 「可能有助于……，但效应有限」 | 左上格但证据中等 |
| 弱 | 「部分患者报告……，目前证据不一致」 | 左右两格交界 |
| 不足 | 「目前缺乏足够证据支持，也不等于证明无效」 | 右下格 |
| 不推荐 | 「现有高质量证据未显示获益」 | 左下格（如辅助生殖的活产率） |

另有四条禁语，教材第三段明文列出：不得用「包治」「根治」「一定有效」「无效退款」作疗效承诺；不得宣称已证实或完全治愈；不得虚构病例与疗效数据；不得贬低其它有效疗法以招揽患者。这四条不是文风要求，是责任边界——它们与「不替代药物、手术与规范诊疗」是同一条底线的两种写法。

还有两件与本章直接相关的事。其一，教材第四段（痿证）的按语写着「本病属于慢性疾病，难以速愈，需长期治疗」——这句话是预期管理的范本：承认疗程长，就等于放弃了「几次见效」的承诺。其二，教材第五段（治神守气）说治神守气「既能更好地发挥针灸疗法的作用，又能有效地防止针灸意外事故的发生」。把这两句放在一起看，本章的立场就出来了：针刺的收益与风险都受操作者与患者状态影响，所以判断不能只看「扎了什么穴」，还要看「谁扎、怎么扎、患者处于什么状态」。

## 六、代价与边界

1. **本章不给分级判定的操作细节。** 教材讲的是分级体系与降级维度，本章只用到「哪一档该怎么说」这一层，不展开偏倚风险评估工具的具体条目，也不给任何研究的质量评分。
2. **病种归类是转述，不是重评。** 第一节那张表按教材第二段的表述整理；教材本身注明证据现状是动态的，新研究可能改写结论，读者应回到最新系统评价与指南核对。
3. **不给剂量与穿刺参数。** 与安全性相关的具体深度、角度、时间、频次，一律不写。安全清单给的是「观察什么、什么时候停」，不是「扎多深」。
4. **不对单个研究下结论。** 教材反复强调动物实验与机制研究属间接证据，不得直接推导为人体疗效；本章的措辞纪律同样适用于自己——凡是本课给出的判断，都只到「可能」这一档。
5. **不作诊疗依据。** 本章讨论的是如何表述证据，不是如何治疗某个病。任何具体病例的处置由具备资质的人员依现行规范作出。
