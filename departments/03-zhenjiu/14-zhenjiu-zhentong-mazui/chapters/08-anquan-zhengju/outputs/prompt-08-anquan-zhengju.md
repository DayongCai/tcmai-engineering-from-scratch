# 「有效」与「证据充分」是两列，并成一列就会说谎 · 提示词

## 用途

给「「有效」与「证据充分」是两列，并成一列就会说谎」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「把病种放进两维表里 → 证据为什么会缩水 → 第二列：安全性 → 措辞纪律：把证据等级译成一句话」这条链。

## 提示词

```
我在学《针灸镇痛与麻醉》第 8 章「「有效」与「证据充分」是两列，并成一列就会说谎」，本章 5 节 / 3,304 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 可以说得比较硬
   - 最容易被说错
   - 必须说「不知道」
   - 第一条，真针与假针的差异是否显著
   - 第二条，安慰效应与非特异效应占多大比重
   - 第三条，个体化辨证与标准化设计的矛盾
4. 本章自陈的边界（不得越过）：
   - **本章不给分级判定的操作细节。** 教材讲的是分级体系与降级维度，本章只用到「哪一档该怎么说」这一层，不展开偏倚风险评估工具的具体条目，也不给任何研究的质量评分。
   - **病种归类是转述，不是重评。** 第一节那张表按教材第二段的表述整理；教材本身注明证据现状是动态的，新研究可能改写结论，读者应回到最新系统评价与指南核对。
   - **不给剂量与穿刺参数。** 与安全性相关的具体深度、角度、时间、频次，一律不写。安全清单给的是「观察什么、什么时候停」，不是「扎多深」。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，不构成医学意见、诊断或治疗指导，也不构成对任何疗法疗效的承诺；具体操作以现行规范与所在机构制度为准。
