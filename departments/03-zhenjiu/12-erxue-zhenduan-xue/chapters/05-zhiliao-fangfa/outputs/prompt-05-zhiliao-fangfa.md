# 耳穴治疗的差别不在针，而在把刺激送到耳廓的哪一层 · 提示词

## 用途

给「耳穴治疗的差别不在针，而在把刺激送到耳廓的哪一层」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「五种刺激方式，其实是一条「到达层次」的刻度 → 刺激量：底本给了三种可报的量，唯独没给耳穴自己的 → 把「选方法」变成一条四步链 → 手法这件事，耳穴只继承了一半」这条链。

## 边界

本章为耳穴治疗方法的教材整理，属教学材料，不构成诊疗意见或操作处方。电针、水针的数值为底本所载通用通则；具体操作以现行规范与所在机构制度为准。
