# 第 4 章 · 望、压、电测查的是同一件事的三个通道，没有一条能单独定病名

> **MOTTO:** 「凡将用针，必先诊脉，视气之剧易，乃可以治也」——《灵枢·九针十二原》
>
> **PROBLEM:** 这一章叫"耳穴诊断"，底本给了 5 个单元、7,208 汉字，"耳郭"出现 0 次，"耳穴"出现 2 次——两次都在同一段里，讲的是穴位注射的剂量与深度（"耳穴每穴注射 0.1mL""耳穴注射…不可过深，以免注入软骨膜内"）。5 个单元依次是经络诊断的应用、针灸处方、针灸学与相关学科的关系、临床诊治特点、穴位注射法。真正写耳穴诊查三法的只有一段，而且它被放在 1.1 单元。
>
> **双根因定位:** 环境逼迫（诊断要给结论，结论要担后果，于是一个"看"的动作被拆成看、按、测三条通道，好让彼此校验，任何一条单独成立都不许下结论）+ 知识积累（《灵枢》只给了"诊络脉看颜色"的原则，电测法要等到有仪器才可能出现，两千年里通道是从一增到三，不是一次设计出来的）

**教材出处:** 本课无独立教材，为派生课。单元正文逐字取自父课 `cifa-jiufa`、`jingluo`、`shuxue`、`zhenjiu-xue`、`zhenjiu-zhiliao`，落盘于 `standards/erxue-zhenduan-xue/units.json`（8 章 / 40 单元 / 58,090 汉字）；本章取哪些单元见 `standards/erxue-zhenduan-xue/chapter-map.json`。三法的操作细节引自 1.1 与 5.1 两单元，经络诊法的分类引自 4.1 单元。

## 一、"必先诊脉"：诊断发生在刺激之前

底本 4.1 引了《灵枢·九针十二原》的一句：「凡将用针，必先诊脉，视气之剧易，乃可以治也」。这句话的顺序很硬：先诊，再治；不诊而治，不在讨论范围内。

把它移到耳穴上，结论同样硬：**压丸之前必须先有诊断结论**。没有结论就贴王不留行籽，等于按图撒豆——豆贴对了是运气，贴错了没有痕迹，因为没人知道当初想治什么。

4.1 把经络的临床诊断分成四法：经络辨证、经络望诊、经络腧穴按诊、经络腧穴电测定。耳穴诊断的三法正好压在后三法上：

| 经络诊法 | 耳郭上的对应 | 底本出处 |
|---|---|---|
| 经络望诊 | 望诊法 | 1.1 |
| 经络腧穴按诊 | 压痛法 | 1.1、5.1 |
| 经络腧穴电测定 | 皮肤电阻测定法 | 1.1、5.1 |

这张对应表能说明两件事。第一，耳穴诊断不是另起一套方法论，它是经络诊法在耳郭这个局部上的落地版本，所以它的限度也继承自经络诊法——4.1 明确把电测定放在"辅助参考"的位置上。第二，四法里的**第一法"经络辨证"在耳郭上没有对应物**，因为耳郭不分经。

这个缺口很实在。望、按、测三个通道各自产出的是"某处有反应"，而"这组反应说明什么"要靠辨证整合。耳郭上没有经脉可辨，整合就只能靠别的规则——1.1 给的替代方案是五条选穴原则（按相应部位、按脏腑辨证、按经络辨证、按西医理论、按临床经验）。注意第三条仍是"按经络辨证"，而耳郭本身不分经，这一条是靠"某病属某经、某经的耳穴在某区"间接实现的，中间至少隔了一层，底本没有把这层写明，**本课不给**。

还有一处措辞必须原样保留。1.1 描述病理反应时说的是：人体脏腑或躯体有病变时，**往往**在耳郭的相应部位出现压痛敏感、变形、变色和皮肤电阻特异性改变等反应。这句里的"往往"是概率词，不是"一定"。教材把"往往"改成"必然"，就把一条线索升级成了一条定律，而这个升级在底本里没有任何依据。

## 二、望诊：看的是形态与颜色，必须在自然光下，只描述不判病

1.1 给的望诊法是：在自然光线下用肉眼或放大镜，直接观察耳郭有无变形或变色等征象。三个操作条件都不能省——自然光（色温会影响对"充血"与"色素沉着"的判断）、肉眼或放大镜（放大倍数决定能看见哪一级征象）、直接观察（隔着镜头看颜色会失真）。

要看的征象，底本列了八项：脱屑、丘疹、硬结、水疱、充血、色素沉着，加上血管的形状变异与颜色变异。前六项是"长出了什么"，后两项是"原有的血管变成了什么样"——两类不是一回事，数的时候要分开算：六个独立征象，两个血管征象。

4.1 给了望诊的经典依据：《灵枢·经脉》「凡诊络脉，脉色青则寒且痛，赤则有热」。这句是"看颜色断寒热"的原典，也是整个望诊传统的根。但它能不能直接搬到耳郭上，底本没有说，**本课不给**。

不能直接搬的理由是可以说清的：那条讲的是**络脉**的颜色，络脉是可见的血管；而耳郭望诊的八项里，只有后两项（血管形状、颜色变异）属于血管，前六项（脱屑、丘疹、硬结、水疱、充血、色素沉着）都不是。也就是说，经典依据只覆盖了八项中的两项。剩下六项的依据，底本没有交代。

望诊的限度是本章最需要说清的一条：**底本只列"看到什么"，没有给"什么征象对应什么病"的判据表**。它没有说"脱屑等于什么""丘疹等于什么"。所以望诊在本课里只能做到"记录征象"，做不到"由征象推病名"。要那张表，得另找依据，**本课不给**。

## 三、压痛法：唯一由患者亲口确认的通道

1.1 给的压痛法是：用弹簧探棒、毫针针柄或火柴棒等工具，以均匀的压力，在与疾病相应的耳郭部位从周围逐渐向中心探压；探查到痛点时，患者会出现皱眉、眨眼、呼痛或躲闪等反应。

这一节的关键在于它和另外两法的性质差别：

- 望诊的判断者是医者——看的人说了算；
- 电测的判断者是仪器——读数说了算；
- 压痛法的判断者是患者——**只有这一条要靠当事人当场确认**。

三个工具（弹簧探棒、毫针针柄、火柴棒）的弹性、接触面积、尖端硬度完全不同，但底本对它们只有一个统一要求：均匀的压力。这份"均匀"是全章唯一一条标准化要求，而底本没有给压力数值——多少克、多大面积，都没写，**本课不给**。

这带来一个可以预见的偏差：工具不同、压力不同，同一个人同一个点会得到不同的"最敏感处"。要理解底本那句"均匀"到底管什么——它管的是**同一个操作者在一次探查内部的压力一致**，这样"从周围向中心"的比较才有意义；它不是跨操作者的一致性标准，也不是绝对值。

5.1 把选点规则说得更直白：以探棒均匀按压耳廓各区，比较痛觉差异，选最敏感处为治疗点。注意这里用的是"比较"而不是"阈值"——没有"超过多少算阳性"的标准，只有"这一片里哪个更痛"的相对判断。所以压痛法的结论天然是排序，不是分级。

前两节合起来还有一个操作顺序上的含义：望诊是"从周围向中心"之前的粗筛（先看哪一片有异样），压痛是"从周围向中心"的精查（在那一片里找最痛的一点）。底本没有明写这个顺序，但"与疾病相应的部位"这个前提要求先有部位的判断，而部位的判断只能来自望诊或辨证。

## 四、电测：能测出电阻，测不出病名

1.1 给的皮肤电阻测定法是：用耳穴探测仪测定耳郭皮肤电阻、电位等变化，电阻值降低形成良导点者，一般即为病理反应点。

这句话里最要紧的是"一般"两个字。它承认了例外：良导点不必然是病理反应点，病理反应点也不必然是良导点。下面三条限度都可以从这一句推出来：

1. **良导点只说明该点的电学性质改变，不指向具体病**。电阻降低是一个物理量，它不知道自己对应的是胃还是心。要说出病名，必须回到区与主治的对应表上去查。
2. **读数受多个因素影响**：皮肤湿度、角质层厚薄、探头压力、仪器状态。底本一个校准方法都没给，**本课不给**。这意味着两台仪器、两个操作者之间，读数不可直接比较。
3. **概率词不能升格**。"一般即为"是概率表述，写成"即为"就把一条概率判断变成了判据。

5.1 补了一段现代口径：耳廓上存在一些皮肤电阻明显低于周围的点（低电阻点），这些点与耳穴的分布大体一致，患病时相应耳穴的电阻变化更为明显，可作为辅助诊断与取穴定位的参考，属"现代认识，不改经典原义"。这段里有三个程度词值得逐个看："大体一致"（不是完全一致）、"更为明显"（是比较级，不是阈值）、"辅助参考"（不是诊断依据）。三个词都在往回收，收的方向一致。

4.1 把经络腧穴电测定的位置定得更清楚：测定内容包括经络腧穴皮肤的电阻或电位，对诊断经络脏腑疾病与选取治疗穴位有一定参考价值，属辅助参考内容。耳穴电测就是同一类方法在耳郭上的版本，位置也一样——辅助参考。这也解释了为什么它排在第三：它是三条通道里最依赖设备、也最需要校准的一条。

## 五、三条通道怎么合成：底本只给了一句，而且是禁止式的

5.1 有一句话，是整章的合题：

> 耳穴反应点的出现并非绝对，其临床意义应结合四诊综合判断，不可仅凭耳廓反应点作诊断依据。

这句话是禁止式的，不是指导式的。它不说"该怎么合成"，只说"不许怎么用"。从它至少能推出三条：

1. **三法不能互相替代**。望诊看到脱屑，不能推出压痛一定阳性；压痛阳性，不能推出电阻一定降低。三条通道各查各的，任何一条阴性都不足以否证另外两条。
2. **三法可以互相加重**。三法同时指向同一个区，可信度上升；只有一法有反应，只能当线索。这是"合成"的唯一方向，方向是给定的。
3. **权重没给**。三法各占多少、冲突时听谁的，底本没有交代，**本课不给**。这也是为什么 4.1 把"辨证"单列成一法——它是整合环节，而整合规则在耳郭这一层是空的。

回到本章标题：望、压、电测查的是同一件事——耳郭上有没有与病变相应的反应——的三个通道。三条通道的物理量完全不同（形态颜色、痛觉、电阻），它们能互相印证，是因为假设了"同一个病变在三条通道上都留痕"。这个假设底本是用"往往"表述的，不是用"必然"。假设成立时三法互相加重；假设不成立时，三条通道全阴，也不能反推"没有病"。这一条是本章最容易被忽略、也最容易在临床上出事的地方。

## 六、代价与边界

1. **本章没有判据表**。底本给了三法的操作、给了反应的四类表现（压痛敏感、变形、变色、皮肤电阻特异性改变），但没有给"哪种表现对应哪个病"。所以本章能教"怎么查"，不能教"查出什么就是什么"。要判据表，得另有依据，**本课不给**。
2. **压力、电流、校准一律不给**。压痛法的压力数值、电测仪的校准与判读阈值，底本都没有，本章不补。这类参数一旦凭空写出，下游会当成标准执行，风险比留空大得多。
3. **"往往""一般""大体"三个词不许改写**。它们是这一章全部结论的强度标记。改写这三个词，等于把概率判断偷换成定律判断，而依据并没有跟着变强。
4. **派生课不相加**。7,208 字与父课同源，不与父课相加。本章的增量在"三法各查一个通道、缺辨证这一环""禁止式合题""三个程度词"这三处，不在字数。
