# 知识进机器有四条路，最像捷径的那条最贵 · 提示词

## 用途

给「知识进机器有四条路，最像捷径的那条最贵」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「四条路：表达力越强，维护越贵 → 本体构建：先算人日，再决定范围 → 符号与统计怎么分工：一个可复算的组合 → 评价知识库：三个指标，一个抽检」这条链。

## 边界

本章为知识表示与知识工程的讨论，不构成诊疗建议或技术选型建议；具体操作以现行规范与所在机构制度为准。
