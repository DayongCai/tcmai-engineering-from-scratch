# 系统的形状由写权限决定，不由技术栈决定 · 提示词

## 用途

给「系统的形状由写权限决定，不由技术栈决定」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「四种形状：按写权限排，不按技术含量排 → 三条集成路径：旁路、嵌入、代理 → 延迟预算：480 秒里只留 3 秒 → 上线之后：三类监测指标」这条链。

## 边界

本章为医疗信息系统架构与集成的教学讨论，不构成系统选型、实施或合规建议；具体操作以现行规范与所在机构制度为准。
