# 支持向量机：边界由最难分的那几个人决定

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 8 道题自检，答不上就回到对应小节。

## 核心判据

- 间隔变宽并不等于判别力变强
- 只有正好压在间隔边界上的样本，才在模型里占一份权重
- 占据权重的那几个样本，是「刚好卡在边界上」的样本，也就是标注最犹豫的那几个
- 留一法删点实验
- 同一个 `γ` 在不同维数、不同特征尺度下对应的模型完全不同
- 不能向临床翻译的自由度

## 边界

- 本章不推荐任何核函数与参数取值，也**不给出任何实测的准确率、敏感度、样本量或核参数最优值**；文中所有数字（间隔宽度、`γ` 折算半径、贝叶斯错误率下限）都是按公式对假定分布做的**演算设定**，不对应任何真实数据集或已发表研究。
- 「支持向量即边缘病例、因而最不可靠」是基于 KKT 条件的结构性推断，不等于「支持向量标注一定有误」；实际可靠性须由标注一致性研究确定。
- 软间隔的 C 与分类切点在数学上并不等价（前者作用于训练目标，后者作用于决策输出），本章说它们「是同一件事的两种写法」，指的是两者都在表达「漏与误的代价比」这同一个临床取舍。
- 本章为脉象判别模型的教学讨论，不构成医学意见、诊断或治疗建议。任何模型输出的临床采用，须由具备资质的人员结合四诊合参作出。
