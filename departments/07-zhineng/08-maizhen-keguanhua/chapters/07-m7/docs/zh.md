# 第 7 章 · 支持向量机：边界由最难分的那几个人决定

> **MOTTO:** 「善诊者，察色按脉，先别阴阳。」——《素问·阴阳应象大论》
>
> **PROBLEM:** 60 例样本（浮脉 30 例、非浮 30 例），14 个标准化特征。硬间隔要求 60 例全部判对；只要其中三例的标注有争议——而争议样本几乎必然落在两类交界处——最大间隔解的方向就被这三例决定。把惩罚参数 C 从 0.1 扫到 100，支持向量的个数会在个位数与三四十之间移动，边界跟着翻转，同一批数据的判断从「浮」变成「不浮」。**模型的全部信息压在那几个支持向量上，而它们恰好是整个数据集里最不可靠的那几条标签。**

**双根因定位:** 环境逼迫（样本几十例、标签是人给的，而人最容易在交界处给出分歧；SVM 的机制恰好把决策权交给交界处的那几个样本）+ 知识积累（本章底本 14 单元 16,086 汉字，是机器学习教材的支持向量机一章——间隔与支持向量、对偶问题、核函数、软间隔、SVR、核方法；教材给了「怎么求最大间隔」，没给「间隔在几十例上有多大统计意义」）

## 一、间隔是可以量出来的东西，但它量的不是判别力

划分超平面写成 `wᵀx + b = 0`，`w` 是法向量（方向），`b` 是位移（位置）。任意点到它的距离是 `|wᵀx + b| / ‖w‖`。由于 `w`、`b` 同乘一个正数仍表示同一个超平面，可以缩放使最近的样本恰好满足 `yᵢ(wᵀxᵢ + b) = 1`，于是

```
最大间隔 = 2 / ‖w‖ ,  支持向量满足 yᵢ(wᵀxᵢ + b) = 1
求解：min ½‖w‖²   s.t.  yᵢ(wᵀxᵢ + b) ≥ 1
```

这个式子的几何意义很干净：在所有能把两类分开的超平面里，挑那条两侧「空白带」最宽的一条。宽的理由不是玄学——空白带越宽，测试样本落在带内（因而判错）的机会越小。

但「间隔有多宽」这个数必须换一个单位才有意义。特征标准化之后，间隔宽度的单位是**标准差**。设两类均值相差 `d` 个标准差、类内等方差，最大间隔的宽度近似就是 `d`，最近样本落在两侧各 `d/2` 处：

| 两类均值差（以类内标准差计） | 最大间隔宽度 | 最近样本位于 |
|--:|--:|---|
| 0.8 σ | 0.80 | 两侧 ±0.40 σ |
| 1.2 σ | 1.20 | 两侧 ±0.60 σ |
| 2.0 σ | 2.00 | 两侧 ±1.00 σ |
| 3.0 σ | 3.00 | 两侧 ±1.50 σ |

（**演算设定**：假定标准化后类内方差为 1、两类先验相等、样本量足够大，用上述几何关系直接算出的数。）

这张表最容易被误读的地方是：**间隔变宽并不等于判别力变强**。间隔宽度就是两类均值差本身，它描述的是「两类离得多远」，不是「能不能分开」。真正决定可分性的是重叠程度——那是第五节要算的东西，也是 SVM 无论怎么优化都改不动的那部分。

## 二、对偶与支持向量：模型只由边界上那几个人决定

把上面的约束优化用拉格朗日乘子法转成对偶问题，会得到一个结构上极漂亮的结论：

```
对偶：max Σαᵢ − ½ ΣᵢΣⱼ αᵢαⱼyᵢyⱼ xᵢᵀxⱼ
      s.t. Σαᵢyᵢ = 0 ,  αᵢ ≥ 0
恢复：w = Σαᵢyᵢxᵢ ,  f(x) = Σαᵢyᵢ xᵢᵀx + b
KKT：αᵢ ( yᵢ f(xᵢ) − 1 ) = 0
```

最后那行 KKT 条件是全章最要紧的一句。它说：`αᵢ > 0` 的必要条件是 `yᵢ f(xᵢ) = 1`——**只有正好压在间隔边界上的样本，才在模型里占一份权重**。其余样本的 `αᵢ = 0`，删掉它们，解一点不变。

这个性质在教科书里叫稀疏性，通常被当作优点讲：模型只依赖少数样本，存储省、推理快。但在脉诊数据上，它同时是一句警告：

**占据权重的那几个样本，是「刚好卡在边界上」的样本，也就是标注最犹豫的那几个。** 一个典型的浮脉、一个典型的沉脉，离边界很远，`αᵢ = 0`，对边界没有任何影响；而一个「似浮非浮」的样本，`αᵢ > 0`，它往哪边挪一厘米，边界就往那边偏一截。于是模型的判断不是由典型病例支撑的，是由**边缘病例**支撑的。

由此可以推出一个非常实用的检验，成本比交叉验证还低：**留一法删点实验**。把每个支持向量单独删掉、重训、看决策边界移动多少。若删掉三例就翻转结论，那么这个模型报出的任何准确率都不该被单独引用——它测的不是「浮脉的规律」，是「这三例怎么标」。

稀疏性还有一层代价容易被忽略：它让模型对**新增样本**极不稳定。一个远离边界的新样本进来，`α` 全不变；一个落在边界附近的新样本进来，整组 `α` 要重解。这意味着模型的更新成本是不均匀的，也意味着「样本量从 60 加到 80」这种扩充，若新增的恰好都是边缘病例，模型可能变差而不是变好。

## 三、核函数：把「组合才成立」写进模型

线性核只能表达「各项加权求和」。而脉象判据里大量的话是合取式的：「浮而迟」「沉细而数」——单看浮、单看迟都分不开，两个同时出现才成立。这正是第 5 章讲过的异或型结构，也是线性模型最无力的地方。

核技巧的解法是换一个空间看问题。把样本映射到高维 `φ(x)`，在新空间里线性分类；而计算上不必真的写 `φ`，只要有一个函数满足

```
κ(xᵢ, xⱼ) = φ(xᵢ)ᵀφ(xⱼ)
```

对偶问题里所有内积 `xᵢᵀxⱼ` 换成 `κ(xᵢ, xⱼ)` 即可。多项式核 `κ = (xᵀz + 1)^d` 的展开式里显式含有各阶交叉项，`d = 2` 就自动造出「浮 × 迟」这样的乘积项；高斯核（RBF）`κ = exp(−γ‖x − z‖²)` 对应无穷维映射，能造出任意阶的交互。

三种核在脉诊任务上的取舍，不该按「谁更准」排，而该按「谁的自由度能被翻译」排：

| 核 | 表达力 | 可调参数 | 能否向医师解释 | 典型失效 |
|---|---|---|---|---|
| 线性 | 只有加权和 | 仅 C | 能（权重方向可读，但受相关影响，见第 4 章） | 合取型判据表达不了 |
| 多项式 | 显式交互项，阶数可控 | C、阶数 d、常数项 | 勉强（可说「二阶交互」） | d 稍大就过拟合，系数爆炸 |
| RBF | 任意非线性 | C、γ | 不能（相似半径无生理对应物） | γ 一偏，边界碎成孤岛 |

RBF 那一行是全章最需要说清的一句。`γ` 控制「多远还算相似」，相似度降到 1/e 的距离是 `1/√γ`。按 scikit-learn 的 `gamma='scale'` 约定，`γ = 1 / (特征数 × 特征方差)`：

| 情形 | γ | 折算的相似半径 1/√γ |
|---|--:|--:|
| 14 特征、方差 1.0 | 0.071 | 3.75 σ |
| 14 特征、方差 0.3 | 0.238 | 2.05 σ |
| 3 特征、方差 1.0 | 0.333 | 1.73 σ |

（**演算设定**：按 `gamma='scale'` 的定义直接代入算出的数，不对应任何具体模型。）

表里第一个数值得停一下：3.75 个标准差的相似半径，在 14 维空间里意味着几乎所有样本彼此都算「相似」，RBF 在这组配置下近似退化成一个线性核。这不是说 `gamma='scale'` 不好，而是说：**同一个 `γ` 在不同维数、不同特征尺度下对应的模型完全不同**，而它对应的那个物理量（相似半径）在脉学里没有任何对应物。医师问「你为什么说这条脉是浮的」，可以回答「因为主波幅这一项权重最大」；却没法回答「因为 γ 是 0.071」。

所以核参数是 SVM 里唯一一个**不能向临床翻译的自由度**。它的存在本身不是问题，问题是很多报告只写「用了 RBF 核」，不写 γ 是怎么定的、选核带来了多少增益。补上「线性核与 RBF 核在同一划分下的对照」，这一节才算交代完整。

## 四、软间隔与 C：一例错值多少钱，是临床问题不是调参问题

硬间隔在脉诊数据上一定无解：两类本来就有重叠，不存在一条线把 60 例全判对。于是引入松弛变量 `ξᵢ ≥ 0`：

```
min ½‖w‖² + C Σξᵢ  s.t.  yᵢ(wᵀxᵢ + b) ≥ 1 − ξᵢ ,  ξᵢ ≥ 0
对偶约束变为 0 ≤ αᵢ ≤ C
```

`ξᵢ` 的读数很直观：`ξᵢ = 0` 在间隔外且分对；`0 < ξᵢ < 1` 落在间隔带里但分对；`ξᵢ ≥ 1` 直接分错。而 `C` 就是「一例错值多少钱」的标价：`C` 大，模型宁可把间隔压窄也要把这一例掰对；`C` 小，模型宁可放它过去也要保住宽间隔。

对偶形式里 `αᵢ ≤ C` 这个上限有个直接后果：`C` 越小，越多样本的 `αᵢ` 顶到这个上限，越多的点变成「不可再加权」的支持向量。**所以 C 越小，支持向量越多，模型越依赖数据里的多数样本；C 越大，支持向量越少，模型越依赖那几例硬骨头。**

| C 档位 | 间隔 | 支持向量 | 临床读法 | 失效方式 |
|---|---|---|---|---|
| 大（如 10 ~ 100） | 窄 | 少 | 严格按标准判，不容许偏离 | 把标注噪声当成必须满足的约束，边界被三五个错标样本拖走 |
| 中（如 1） | 适中 | 中 | 常规用 | 无特别优势，也最容易被当成默认值而不加说明 |
| 小（如 0.1） | 宽 | 多 | 倾向「宁可不判」，少下结论 | 判据被稀释，两类几乎不分，输出集中在中间 |

关键在于：**C 与第 4 章的切点是同一件事的两种写法**。切点决定「宁可漏还是宁可误」，C 决定「宁可把谁判错」。既然切点应当按用途分档（筛查 / 复核 / 决策），C 也应当按用途分档，而不是让交叉验证替所有人挑一个。用交叉验证选 C 时，它优化的是「平均错误率最低」，而平均错误率隐含了「漏诊与误诊代价相同」这个临床上前提不成立的假设。

所以一份写清楚的报告应当有三行：C 取了多少、按什么用途定的、若换一档结论会怎么变。缺第三行，读者无法判断这个模型是「稳定」还是「刚好卡在这个参数上」。

## 五、先算错误率下限，再读那个准确率

脉诊论文里最常见的数字是准确率。而准确率有一个与模型无关的上限，可以用算术先算出来，这个算术值得成为读论文的第一个动作。

设两类在标准化空间里均值相差 `d` 个标准差、类内等方差、先验相等，则任何分类器（包括贝叶斯最优分类器）的错误率下限是

```
错误率下限 = Φ( −d / 2 )
```

`Φ` 是标准正态分布函数。代入第一节的四个 `d`：

| 均值差 d | 间隔宽度 | 贝叶斯错误率下限 | 对应准确率上限 |
|--:|--:|--:|--:|
| 0.8 σ | 0.80 | 0.345 | 0.655 |
| 1.2 σ | 1.20 | 0.274 | 0.726 |
| 2.0 σ | 2.00 | 0.159 | 0.841 |
| 3.0 σ | 3.00 | 0.067 | 0.933 |

（**演算设定**：等方差正态、先验相等、特征无冗余这几条假设下的算术结果；真实数据的下限只会更高，不会更低。）

这张表可以直接用来做一次自检。若某份报告说「用 14 个脉图特征、60 例，区分浮脉与非浮脉，准确率 95%」，那么按上表，对应的是 `d ≈ 3.3σ` 的两类分离——在 60 例里，这意味着两类几乎不重叠。而临床上的浮脉与非浮脉，本就存在大量中间状态（体型偏瘦者常带浮象、轻度表证者可浮可不浮）。**要么这份数据的标注把中间状态系统性排除了，要么特征里混进了与标签同源的量（比如采集时的压力档位）。** 这两种情况都不是「模型很好」，而是「任务被简化了」。

这个算术还有一个正面用法：它告诉你该往哪儿投人力。若实测的 `d` 只有 1.2σ，那么无论换成多复杂的核、多大的集成，准确率都封顶在 0.73 附近；想要往上走，唯一的路径是**减小类内方差**——统一采集压力、控制体位与时间、把标注口径写细。也就是说，改进的方向在数据侧，不在模型侧。SVM 在这里的作用不是提升上限，是尽量逼近这个上限。

## 代价与边界

- 本章不推荐任何核函数与参数取值，也**不给出任何实测的准确率、敏感度、样本量或核参数最优值**；文中所有数字（间隔宽度、`γ` 折算半径、贝叶斯错误率下限）都是按公式对假定分布做的**演算设定**，不对应任何真实数据集或已发表研究。
- 「支持向量即边缘病例、因而最不可靠」是基于 KKT 条件的结构性推断，不等于「支持向量标注一定有误」；实际可靠性须由标注一致性研究确定。
- 软间隔的 C 与分类切点在数学上并不等价（前者作用于训练目标，后者作用于决策输出），本章说它们「是同一件事的两种写法」，指的是两者都在表达「漏与误的代价比」这同一个临床取舍。
- 核函数的选择、`γ` 的取法会显著改变结论，报告时须写明核类型、参数及其确定方式，否则结果不可复算。
- 本章的算例均为结构示意，不含任何真实病例；SVM 输出不得作为诊断依据直接使用。
