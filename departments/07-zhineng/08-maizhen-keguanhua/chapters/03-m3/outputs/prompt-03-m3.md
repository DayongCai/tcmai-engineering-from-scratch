# 特征提取：可重复的不是特征，是提取它的那套流程 · 提示词

## 用途

给「特征提取：可重复的不是特征，是提取它的那套流程」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「四个域，各自对什么敏感 → 可重复性：先问重测，再问区分度 → 维数灾难在脉诊上的具体样子 → 降维的两笔账」这条链。


## 边界

本章为脉图特征工程的教学讨论，不构成医学意见或诊断建议。特征与模型的使用须在合规的数据治理与临床流程下进行；具体操作以现行规范与所在机构制度为准。
