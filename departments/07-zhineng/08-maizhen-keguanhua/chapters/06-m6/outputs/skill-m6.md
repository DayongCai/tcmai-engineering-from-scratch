# 端到端学习：省掉特征工程，也省掉了「谁在负责」

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 8 道题自检，答不上就回到对应小节。

## 核心判据

- 负责说「这个任务不值得用网络」的人
- 这个网络的输出只看得到 145 毫秒——不到一个心动周期的五分之一
- 局部波形片段的模板匹配
- 在这个样本量下，我最多能负担多少参数，而这个参数预算允许我看到的时窗有多长
- 信号层的对齐
- 83% 的患者在验证集里「露过脸」

## 边界

- 本章不推荐任何网络结构，也不给出参数量与样本量的具体配比；这些应以本机构数据与验证结果确定。
- 第二节的 43,840 个参数、29 点感受野、145 毫秒、第五节 0.83 的泄漏比例与 3.4 的设计效应，全部是按公开公式与假定配置做的算术（**演算设定**），不来自任何实测模型或数据集。
- 「按人分组划分」「分层抽样」是数据纪律，不构成对任何研究设计的评价。
- 本章为脉图表征学习的教学讨论，不构成医学意见、诊断或器械选型建议。模型输出仅供研究与复核参考，临床决策由具备资质的人员作出。
