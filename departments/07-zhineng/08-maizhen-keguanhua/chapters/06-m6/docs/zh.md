# 第 6 章 · 端到端学习：省掉特征工程，也省掉了「谁在负责」

> **MOTTO:** 「脉乃血脉，气血之先，血之隧道，气息应焉。」——《濒湖脉学·四言举要》
>
> **PROBLEM:** 一段 30 秒的脉图，按 200 Hz 采样是 6,000 个点。把这段原始序列直接送进一个一维卷积网络，参数量很容易上到十万级；而一个单中心的脉诊数据集常常只有几百例、几千段。参数比样本多两个数量级，网络完全有能力把每一段波形都记住——**包括手套摩擦的振动、电源的 50 Hz 嗡鸣、以及那台设备特有的频响**。训练集上的损失可以降到几乎为零，而这恰恰是最坏的消息。

**双根因定位:** 环境逼迫（各医院的设备、滤波器、贴片位置都不一样，手工特征一换设备就失效；端到端看上去能「自动适配」，于是被当成跨设备的解药）+ 知识积累（本章底本 13 单元 14,581 汉字，是神经网络一章——神经元模型、感知机、误差逆传播、局部最小、深度学习；教材把反向传播讲得很清楚，却没讲波形里哪一段是脉、哪一段是设备）

## 一、端到端省掉的三个环节，和随之消失的三个责任人

传统流程里，从波形到结论要经过三道人工关口：特征怎么定义、信号怎么质控、结论怎么归因。端到端把三道关口并成一道，用一句「让网络自己学」带过。省下的工作量是真的，消失的责任也是真的。

| 环节 | 手工流程 | 端到端之后 |
|---|---|---|
| 特征定义 | 有人写下「主波幅＝峰值减基线」，可被质疑、可被修改 | 无人写下；网络内部的表示没有名字 |
| 信号质控 | 明确剔除伪迹段，报告剔除率 | 网络把伪迹当特征学进去，无人知道 |
| 结论归因 | 权重或规则可指向某个特征 | 只有显著性图，而它不稳定（见第五节） |

这三项里，第二项最危险。手工流程里，一段明显的运动伪迹会被剔除，剔除率写进报告，读者知道「这批数据里有多少被扔掉了」。端到端流程里，同样的伪迹会作为「有判别力的模式」被学走——因为伪迹往往与采集场景相关，而采集场景又与人群相关：卧床患者的波形有卧床的伪迹，门诊患者的波形有门诊的伪迹。网络学到的可能是「这是住院病人」，而不是「这是某证」。

还少了一个人：**负责说「这个任务不值得用网络」的人**。手工流程里，这个判断发生在特征工程阶段——列出十几个特征后，谁都能看出「迟数」只用一个特征就够了。端到端把这个判断推迟到了训练之后，而那时已经投了几周的工。

## 二、参数量与感受野：先把容量算出来，再谈能不能学

「深度模型能不能用」在脉诊上不是一个立场问题，是一个可以算的除法。

取一个并不夸张的一维卷积结构：四层卷积，通道数依次 1→16→32→64→64，前三层核长 9，最后一层核长 5。按 `输入通道 × 输出通道 × 核长 + 输出通道` 逐层相加：

| 层 | 配置 | 参数量 |
|---|---|--:|
| 1 | 1 → 16，k=9 | 160 |
| 2 | 16 → 32，k=9 | 4,640 |
| 3 | 32 → 64，k=9 | 18,496 |
| 4 | 64 → 64，k=5 | 20,544 |
| 合计（不含全连接与批归一化） | | 43,840 |

这还只是特征提取部分，加一层 64 维到类别数的全连接、加上批归一化的可学习参数，五万上下。而数据一侧：500 例、每人三段、每段 5 搏，是 1,500 段。**43,840 ÷ 1,500 ≈ 29**——每段波形要养活二十几个参数。

同一组数字还能算出第二个量。感受野逐层累加，四层的总感受野是 `1 + (9−1) + (9−1) + (9−1) + (5−1) = 29` 个采样点；200 Hz 下是 145 毫秒。而一个心动周期在 75 次/分时约 800 毫秒，5 搏约 4.3 秒、860 个点。**这个网络的输出只看得到 145 毫秒——不到一个心动周期的五分之一。**

这说明两件事。其一，要让网络看到完整的搏动形态（主波、重搏波、以及搏与搏之间的节律），层数必须显著加深，参数量跟着涨，第二节那道除法就更难看。其二，浅层网络在脉图上实际做的是**局部波形片段的模板匹配**，它抓的是斜率、锐度、局部振荡——恰好是最容易被设备频响和滤波参数改变的那几个量。这不是网络的缺陷，是任务与容量的错配。

所以正确的问题不是「要不要用深度模型」，而是「**在这个样本量下，我最多能负担多少参数，而这个参数预算允许我看到的时窗有多长**」。这句问法一旦落实，很多方案会自己出局。

## 三、波形表征：从原始点到可迁移向量

用神经网络处理脉图，主流有三条路，各自的失败模式不同。

| 做法 | 学到什么 | 典型失败 |
|---|---|---|
| 一维卷积端到端分类 | 直接从波形到标签 | 学到设备频响与采集批次 |
| 自编码器预训练 | 波形的低维压缩表示 | 压缩的是「能重建」，不是「有判别力」 |
| 对比学习 | 同人不同段靠近、异人远离 | 学到的是身份，不是证候 |

第三条值得单说。对比学习在生理信号上非常好用，因为「同一个人不同时间的两段」天然构成正样本对。但它的目标函数是「把同一个人的段拉近」，这在脉诊任务里恰好是**错的目标**：我们要的是「同一个证的段拉近」，而同一个证可以出现在不同人身上，同一个人在不同时间也可以是不同的证。用身份做正样本对，训出来的表示对「这是谁」极度敏感，对「这是什么证」不敏感。这类模型在身份分层的数据上表现很好，一换人就崩。

自编码器的失败方式更安静。重建损失只奖励「能还原」，不奖励「能区分」。一段波形里信息量最大的部分往往是幅度最大的部分，也就是主波；而判别浮沉靠的是峰值出现的位置、判别滑涩靠的是重搏波的相对高度——这些在重建误差里占比很小。于是自编码器把容量全花在主波形状上，而这恰恰是不同证型之间差别最小的部分。**无监督预训练在脉图上的隐含假设是「重要的东西一定占能量多」，这个假设在脉象上不成立。**

表征的可迁移性还有一个常被夸大的说法：在 A 医院数据上预训练、在 B 医院微调。若两家的设备不同，预训练学到的低层滤波器（对应波形的锐度、振荡频率）本身就带着设备指纹，微调只能改高层分类头，改不掉底层的偏。跨设备迁移要处理的是**信号层的对齐**（重采样、频响校正、压力归一化），这件事在进网络之前做，比在网络里期待它自己学会要可靠。

## 四、三个伪相关，和一个可以算的泄漏

讲「黑箱风险」容易流于抽象。在脉诊数据上，它有三个非常具体的形态。

**设备指纹。** 不同型号的传感器频响不同，同一型号不同批次的一致性也有差异。一款压敏薄膜的迟滞会让波形看起来更「圆」，而圆滑度恰好是滑脉的一个候选特征。若样本里「滑脉组」多用新设备、「非滑脉组」多用旧设备，网络分得再准，分的是设备。

**患者身份。** 腕围、皮下脂肪厚度、皮肤温度都会改变波形。这些量在研究里通常没被记录，却稳定地跟着个体走。一个模型若在训练集里见过某位患者的多段波形，它可能只是记住了这个人。

**采集批次。** 滤波参数、固件版本、甚至操作者的手法，都会随时间变化。若数据是按「先收对照组、后收病例组」的顺序采的，那么批次与标签就完全混淆，任何模型都会「表现优异」。

第二个伪相关的规模可以直接算。假设每人采 8 段，按段随机划分、验证集占 20%，则

```
P(某人的 8 段全在训练集) = 0.8⁸ = 0.168
P(该人至少有 1 段进入验证集) = 1 − 0.168 = 0.832
```

也就是说，**83% 的患者在验证集里「露过脸」**。验证集上的每一段波形，训练集里都躺着同一个人的另外几段——同一个人的腕围、皮下脂肪、血管走行完全相同。模型不需要学会辨证，只要学会认人，就能在这 83% 的样本上拿到高分。

同一件事还有一个更隐蔽的版本：样本量被虚增。若每人 5 段、段内相关系数按 0.6 估，设计效应是 `1 + (5−1) × 0.6 = 3.4`；2,500 段的有效样本量只有 `2,500 ÷ 3.4 ≈ 735`，置信区间的宽度是「当独立样本算」时的 1.84 倍。**论文里那个 ±0.02 的区间，实际应该是 ±0.037**。这不是深度学习独有的问题，但端到端流程更容易犯，因为它的输入单位天然是「段」。

对付这三个伪相关，靠的不是更复杂的网络，而是**记录元数据 + 按人分组划分 + 分层抽样**。这三件事都在建模之前，且都不需要深度学习。

## 五、可解释性的替代品不够用

深度模型的「解释」通常指显著性图：哪些时间点对输出贡献最大。它在论文里很好看，在临床沟通里不够用，原因有三。

**其一，不稳定。** 同一段波形加上极小的噪声，热区可以大幅移动。一个会随噪声改变的解释，不能作为「模型依据什么判断」的证据。

**其二，饱和与掩盖。** 梯度类方法在饱和区给出接近零的归因，容易把重要但饱和的特征标成不重要；而相关的时间点之间又会互相「分摊」贡献，导致每个点看起来都不重要。

**其三，归因不是因果。** 显著性的意思是「改动这里会改变输出」，不是「这里就是病因」。把它读成后者，是把模型的内部机制当成了生理机制。

有一个更实用的替代方案：**在输入端做受控实验**。固定其他条件，只改一个物理量（比如把压力档从浮改到沉），看输出怎么变。这种「干预式检查」给出的结论更接近临床想问的问题，也更难被伪相关骗过——因为设备指纹不会随压力档改变而改变。如果模型对压力档完全不敏感，那它学到的就不是脉位，这一点不需要任何解释图就能看出来。这类检验的成本极低（改一个采集参数、重跑一次推理），信息量却比一张热力图大得多。

顺着这条路还能设计出更有针对性的检查：把同一段波形做时间反演（倒放），若输出仍然稳定，说明模型用的是频谱类特征而非形态类特征；把幅度整体缩放 10%，若输出跟着变，说明它没有做幅度归一化。**每一个这样的干预，都在把「模型看见了什么」从一个叙述问题变成一个可以否证的问题。**

## 六、什么时候值得用

不必否定深度模型，但要给它设一个门槛。三个条件同时满足时，它才值得：

1. **样本量与容量匹配**。按人计的样本量要达到参数量的合理倍数，或通过强正则、预训练、数据增广把有效容量压下来。做不到，就用线性模型或树。第二节那道除法就是这一步的操作化。
2. **任务本身复杂到手工特征表达不了**。若「迟数」这类任务用两个特征就能做到，上网络是浪费且更不可控。真正需要网络的，是波形形态的细微差别（如弦与紧的区分），这类任务手工特征确实吃力。
3. **不可解释度是可接受的**。用于科研探索、用于生成假设，不可解释可以接受；用于临床提示并影响决策，就必须有可审计的中间量。

| 用途 | 可接受的模型 | 必须配套 |
|---|---|---|
| 探索性研究、假设生成 | 任意 | 明确声明不用于决策 |
| 辅助提示（医师复核） | 中等复杂度 | 连续输出、可调档、干预式检查 |
| 影响治疗的判断 | 保守模型 | 外部验证、前瞻研究、责任划分 |

第三行不是技术问题，是制度问题。本章只说到这里：**当模型的影响进入治疗决策，它的可解释性就不再是学术偏好，而是责任归属的前提。**

还有一条与数据增广有关的实务提醒。脉图的时间轴不是可以随意拉伸的：把一段波形在时间上拉长 10%，等于把心率改了 10%，也就把「迟」改成了「数」。所以图像领域常用的随机仿射、裁剪、缩放，在脉图上会直接篡改标签。能安全施加的增广只有几类——幅度缩放（并配合归一化）、基线漂移注入、噪声注入、以及在同一患者的多段之间做时间轴上的微小抖动。写增广策略时，每一条都要回答：**这个变换会不会改变它对应的那个脉象属性？** 会改的，就不能用。
本章可直接验证：`node code/main.js` 打印结构清点与判据清单（数字从 `docs/zh.md` 现算），`node --test code/main.test.js` 跑本章单测；两条命令只读正文与代码，不写任何文件。

## 代价与边界

- 本章不推荐任何网络结构，也不给出参数量与样本量的具体配比；这些应以本机构数据与验证结果确定。
- 第二节的 43,840 个参数、29 点感受野、145 毫秒、第五节 0.83 的泄漏比例与 3.4 的设计效应，全部是按公开公式与假定配置做的算术（**演算设定**），不来自任何实测模型或数据集。
- 「按人分组划分」「分层抽样」是数据纪律，不构成对任何研究设计的评价。
- 本章不引用任何模型的性能数字、数据集规模与设备型号；涉及具体设备特性时只作原理性描述。
- 显著性图的价值限于探索，本章不主张其可作为临床解释的依据；任何对外解释须经干预式检查复核。
- 深度学习模型的训练与部署涉及算力、数据安全与合规，本章不涉及具体实施细节。
