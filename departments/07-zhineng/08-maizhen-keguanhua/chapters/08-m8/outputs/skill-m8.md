# 集成学习：平均能降方差，但降不掉「大家都错在同一处」

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 8 道题自检，答不上就回到对应小节。

## 核心判据

- 无论堆多少个模型，方差都降不到 `ρσ²` 以下
- 十分之一的收益
- 数据侧或假设侧的异质性
- 每份自助样本平均只包含约 63.2% 的不同样本，其余是重复
- 冗余但不同源
- 随机性落在了名字上，没落在信息上

## 边界

- 本章不推荐任何集成方法或超参数，也**不给出任何实测 AUC、样本量与集成规模**。文中所有数字（0.82 ± 0.03 与 0.76 ~ 0.87 的极差、方差倍数表、63.2%、`e¹` 的权重倍数）都是**演算设定**或按公式直接算出的量，不对应任何真实研究。
- 「相关系数 0.8 以上则特征随机化近乎无效」是结构性判断，不是阈值标准；实际影响须由本机构数据的相关矩阵与消融实验确定。
- 三档扰动的划分是一种工程归纳，不是规范条文；哪一档必须报，取决于研究目的与数据可得性。
- 本章为脉诊集成建模的教学讨论，不构成医学意见、诊断或治疗建议。任何模型输出的临床采用，须由具备资质的人员结合四诊合参作出。
