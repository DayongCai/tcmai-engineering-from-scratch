## 三、逐单元读

### 8.97 个体与集成（好而不同）

集成学习（ensemble learning）通过构建并结合多个学习器来完成学习任务，有时也被称为多分类器系统（multi-classifier system）。若集成中只包含同种类型的个体学习器，则称这样的集成是同质的（homogeneous），其中的个体学习器亦称基学习器（base learner），相应的学习算法称为基学习算法；若集成中包含不同类型的个体学习器，则称为异质的（heterogeneous），其中的个体学习器亦称组件学习器（component learner）。异质集成中不同算法的预测输出需先转换成一致的输出形式（如都输出类标记或类概率）方可结合。集成学习研究围绕两个核心问题展开：一是如何生成“好而不同”的个体学习器，二是如何设计合适的结合策略把它们组合成强学习器。 所谓“好而不同”，是指个体学习器一方面要具有一定的准确性——至少应优于随机猜测，即对二分类问题错误率应低于 0.5；另一方面，个体学习器之间还要存在差异，即彼此“不同”。若个体学习器完全一样，集成只是简单重复，无论结合策略如何设计都无法获得增益；若个体学习器准确性过低，则“三个臭皮匠”也难以匹敌“诸葛亮”。因此，个体学习器的准确性与多样性之间存在天然的冲突：追求多样性可能损害个体准确性，追求个体准确性又可能使学习器趋于一致。如何在二者之间取得平衡，是集成学习研究的核心所在。 考虑一个理想化的理论模型来理解集成为何有效。对二分类问题 y∈{-1,+1}，设基学习器的错误率为 ε，且各基学习器的错误相互独立。若用简单投票法结合 T 个基学习器，即超过半数的基学习器预测正确则集成预测正确，那么集成的错误率为 P(集成出错) = Σ_{k>⌈T/2⌉} C(T,k)·(1-ε)^k·ε^(T-k)， 其中 k 为预测正确的基学习器个数，C(T,k) 为组合数。由 Hoeffding 不等式可证 P ≤ exp(-T·(1-2ε)²/2)，即集成错误率随个体学习器数目 T 的增大呈指数级下降。

### 8.98 Boosting（AdaBoost/GBDT）

Boosting 是一族可将弱学习器提升为强学习器的算法。其思想源于 Kearns 与 Valiant 提出的“弱可学习”与“强可学习”概念：弱学习器指正确率仅略高于随机猜测的学习算法，强学习器指正确率很高的学习算法；Schapire 等人证明了弱可学习与强可学习在 PAC 学习框架下是等价的——只要存在弱学习器，就一定能通过集成将其提升为强学习器。Boosting 的工作机制是：先从初始训练集训练一个基学习器，再根据基学习器的表现调整训练样本的分布，使先前被分错的样本在后续训练中得到更多关注，然后基于调整后的分布训练下一个基学习器；如此重复 T 轮，最后将各基学习器加权结合。与 Bagging 的并行式集成不同，Boosting 是串行式的，后一个基学习器的训练依赖前一个的结果，难以并行加速。 AdaBoost（Adaptive Boosting）是最具代表性的 Boosting 算法。对二分类问题 y∈{-1,+1}，其流程如下：初始化样本分布 D₁(i)=1/m（m 为训练样本数）；对 t=1,2,…,T：基于分布 D_t 训练出基学习器 h_t（对能接受样本权重的算法用重赋权法直接加权训练，否则用重采样法按权重重新抽样）；计算 h_t 在分布 D_t 上的加权错误率 ε_t = P_{x~D_t}(h_t(x)≠y) = Σ_{i=1}^m D_t(i)·⟦h_t(x_i)≠y_i⟧；若 ε_t>0.5 则终止（此时该学习器不优于随机猜测，继续已无意义）；令 h_t 的投票权重 α_t = ½ln((1-ε_t)/ε_t)，可见 ε_t 越小 α_t 越大，即越准确的基学习器在最终结合中的权重越高；更新样本分布 D_{t+1}(i) = D_t(i)·exp(-α_t·y_i·h_t(x_i))/Z_t，其中 Z_t 为规范化因子。由更新公式可见：被 h_t 分错的样本（y_i·h_t(x_i)=-1）权重被放大 e^{α_t} 倍，分对的样本权重被缩小 e^{-α_t} 倍，于是后续基学习器将更关注难分的样本。

### 8.99 Bagging与随机森林

Bagging（Bootstrap AGGregatING）是并行式集成方法的代表，由 Breiman 提出，直接基于自助采样法（bootstrap sampling）产生个体学习器的多样性。给定含 m 个样本的训练集 D，每一轮从 D 中有放回地随机采样 m 个样本构成一个采样集，重复 T 轮得到 T 个各含 m 个训练样本的采样集，基于每个采样集训练一个基学习器；预测时，分类任务用简单投票法、回归任务用简单平均法结合各基学习器的输出。由于采样是有放回的，D 中的某些样本会在同一采样集中多次出现，而另一些样本始终未被采到。每个样本在 m 次采样中始终不被采到的概率为 (1-1/m)^m，当 m 较大时约为 0.368，即每个采样集平均只包含约 63.2% 的原始样本；例如 m=1000 时，一个采样集中期望包含约 632 个不同的样本（演示数值）。 未被采到的样本称为该采样集的包外（out-of-bag，简称 OOB）样本，其重要用途是包外估计。对第 t 个基学习器而言，其训练采样集未包含的样本可充当验证集：将样本 x 交给所有未使用 x 训练过的基学习器投票（或平均），得到集成的包外预测 H^oob(x)，则包外误差为 ε^oob = (1/m)·Σ_{(x,y)∈D}⟦H^oob(x)≠y⟧（回归任务用均方误差）。包外估计与留出法、交叉验证的效果相当，却无需额外划分数据或重复训练，在样本稀少时尤其有价值。从偏差-方差分解的角度看，Bagging 主要关注降低方差：多个独立训练的基学习器的期望误差与单个学习器相当，但平均效应压低了方差。因此 Bagging 对不稳定的学习算法（如决策树、神经网络——训练样本的微小变化会引起模型显著改变）增益明显；对稳定的学习器（如线性学习器、k 近邻、朴素贝叶斯——对训练样本变化不敏感）则增益有限，此时需借助属性扰动等手段。Bagging 的时间复杂度与训练单个基学习器同阶，且各基学习器可并行训练，这是它相对 Boosting 的重要优势。

### 8.100 结合策略（平均/投票/Stacking）

为什么将多个学习器结合能获得比单一学习器更好的性能？主要有三方面原因：统计上，学习任务的假设空间往往很大，可能存在多个假设在训练集上表现相同，而单一学习器可能因随机性选到泛化性能较差的假设，结合多个学习器可降低“选错”假设的风险；计算上，学习算法可能陷入局部极小，多次运行并加以结合可降低陷入不良局部极小的风险；表示上，某些任务的真实假设可能不在当前学习算法所能表示的假设空间内，而多个假设的结合可以扩大表示空间。这三方面原因构成集成学习有效的理论动因。结合策略主要分为三大类：平均法、投票法与学习法。 平均法用于数值型输出（回归任务）。简单平均法给出 H(x) = (1/T)·Σ_{i=1}^T h_i(x)；加权平均法给出 H(x) = Σ_{i=1}^T w_i·h_i(x)，其中 w_i≥0 且 Σw_i=1，权重一般从训练数据中学习。加权平均的权重若估计不准，反而可能不如简单平均稳健——在训练数据不充分时尤其如此，此时简单平均往往表现更好；事实上加权平均法可视为“学习法”的特例，其权重 w_i 即通过最小化误差从数据中学得。 投票法用于分类任务。设个体学习器 h_i 对样本 x 的预测为类标记 c_i(x)，绝对多数投票法要求某类标记的票数超过半数才输出该标记，否则拒绝预测（在“宁可不说、不可说错”的场景中有用）；相对多数投票法直接取票数最多的类标记，若出现平票则随机选取一个；加权投票法则按个体学习器的权重计票，各类别得票为 Σ_i w_i·⟦h_i(x)=c_j⟧。若基学习器输出的是类概率（如 softmax 输出），则可将各类别概率先平均再取最大者，即软投票；一般软投票比硬投票（对类标记投票）更可靠，因为概率包含了更多信息，但前提是各类概率经过良好校准（如 Platt 缩放、等渗回归，属现代认识）。

### 8.101 多样性

个体学习器的多样性是集成性能的关键，本节从误差-分歧分解、多样性度量与多样性增强三个层面展开。首先看误差-分歧分解（error-ambiguity decomposition），它揭示了集成误差与个体误差、个体分歧之间的定量关系。考虑回归任务，设个体学习器 f_i 的加权平均为 f(x)=Σ_{i=1}^T w_i·f_i(x)，权重 w_i≥0 且 Σw_i=1。定义个体分歧（ambiguity）Ā(x)=Σ_i w_i·(f_i(x)-f(x))²，刻画各学习器输出偏离集成输出的程度；个体误差的加权平均 Ē(x)=Σ_i w_i·(f_i(x)-y)²，其中 y 为真实标记；集成误差 E(x)=(f(x)-y)²。可以推导： E(x) = Σ_i w_i·(f_i(x)-y)² - Σ_i w_i·(f_i(x)-f(x))² = Ē(x) - Ā(x)。 即集成的平方误差等于个体学习器平方误差的加权平均减去个体分歧的加权平均。数值验证：设 f₁=0.8、f₂=1.2、y=1.0、w₁=w₂=0.5，则 f=1.0，集成误差 E=0；个体平均误差 Ē=½(0.04+0.04)=0.04；个体分歧 Ā=½(0.04+0.04)=0.04，恰有 E=Ē-Ā=0（演示数值）。误差-分歧分解说明：个体学习器越准确（Ē 小）、彼此分歧越大（Ā 大），集成误差越小。但它有重要局限：分解中的 Ē 与 Ā 并非相互独立，不能直接作为优化目标——盲目追求分歧可能同时损害个体准确性，这就是下文将讨论的“多样性-准确性悖论”。 再看多样性度量，它用于刻画个体学习器两两之间的差异。对二分类问题，统计两个学习器 h_i、h_j 在样本集上的预测：a=两者均预测正确的样本数，b=h_i 对而 h_j 错的样本数，c=h_i 错而 h_j 对的样本数，d=两者均预测错误的样本数，a+b+c+d=m。

*单元规模：1,378 汉字；出处 `教材·机器学习·第8章·8.5`；本单元数值类命中 0。*

### 8.102 本章小结

本章围绕“好而不同”这一核心思想系统介绍了集成学习。8.1 节奠定基础：个体学习器既要具有优于随机猜测的准确性，又要彼此存在差异；在独立性假设下，多数投票集成的错误率随个体数目 T 指数下降，但现实中个体学习器同源同数据、彼此相关，因此如何平衡准确性与多样性成为集成学习研究的核心问题。8.2 节的 Boosting 是串行式集成的代表：AdaBoost 通过样本分布加权使后续学习器聚焦难例，其权重公式可由“加性模型+前向分步算法+指数损失”完整推导；GBDT 以负梯度近似残差逐轮拟合，XGBoost、LightGBM 等是其高效工程实现。Boosting 主要降低偏差，且对噪声敏感。8.3 节的 Bagging 是并行式集成的代表：自助采样使每个采样集仅含约 63.2% 的原始样本，包外样本可免额外验证集估计泛化误差；Bagging 主要降低方差，对不稳定学习器增益明显且可并行训练；随机森林在 Bagging 基础上引入随机属性选择（推荐 k=log₂d），样本扰动与属性扰动叠加，泛化性能与训练效率俱佳。8.4 节给出结合策略：平均法（简单/加权）用于回归，投票法（绝对多数/相对多数/加权/软投票）用于分类，学习法（Stacking）以初级学习器输出为新特征训练元学习器，次级训练数据须由交叉验证或留出法产生以防过拟合。8.5 节深入多样性：误差-分歧分解 E=Ē-Ā 表明“个体准确+彼此分歧”决定集成质量；不合度量、相关系数、Q 统计量与 kappa 统计量可用于度量多样性；样本、属性、输出表示与算法参数四类扰动是增强多样性的主要途径，但需警惕多样性-准确性悖论。 集成学习是机器学习最成功的实践方向之一：随机森林与 XGBoost 等已在工业界与各类数据竞赛中成为常用利器，而“好而不同”的思想也启发了深度学习中的多模型融合、快照集成（Snapshot Ensembling）等现代做法（现代认识）。

### 8.105 Boosting=迭代审稿闭环

tcmP 把 Boosting 映射为迭代审稿闭环：AdaBoost 按样本权重聚焦被分错的样本，平台则按条款权重聚焦未通过审稿的条文。初始轮所有章节条款权重相等（D₁(i)=1/m，m 为章节条款总数），author-agent 起草全文；第一轮审稿后，未通过条款（为致命或重要者）被标出，下一轮修订时这些条款的权重放大，正如 AdaBoost 将分错样本权重乘 e^{α_t} 倍；每轮根据条款通过率计算审稿人置信度 α_t=½ln((1-ε_t)/ε_t)，其中 ε_t 为本轮未通过率——通过率越高，本轮审稿意见在最终定稿中的权重越大。分布更新公式对应 D_{t+1}(i)=D_t(i)·exp(-α_t·y_i·h_t(x_i))/Z_t：未通过条款下一轮被 author-agent 重点修订，通过条款维持原状。数值演示：若第一轮未通过率 ε₁=0.3，则 α₁≈0.424，未通过条款修订权重约放大 e^{0.424}≈1.53 倍（演示数值，统计来源，送 tcmreviewer 审稿）。终止条件对应 AdaBoost 的 ε_t>0.5 停止规则：若某轮未通过率超过 0.5，说明审稿口径与初稿质量失配，应暂停迭代、由主编人工介入调整审稿标准，而非继续加码放大权重。该闭环对应平台“初稿→审稿→修订→定稿”的章节流转，每轮迭代在 kanban 看板留下记录，便于追溯审稿历史。GBDT 的负梯度思想则对应“残差式修订”：修订不重写全文，而是逐条定位未通过条款的具体问题（缺文献、证型不符、剂量存疑、术语未对齐 ICD-11 等），一条一条修正，避免大改引入新错误；实践上还可引入“学习率”概念，每轮只按比例（如 0.5 权重）采纳审稿意见，降低单轮大改的振荡风险（工程实践，供平台参考）。 符号对照可归纳为：ε_t=本轮未通过率，α_t=本轮审稿意见置信度，D_t(i)=第 t 轮第 i 条条款的修订权重，H(x)=最终定稿。

*单元规模：640 汉字；出处 `教材·机器学习·第8章·8.9`；本单元数值类命中 0。*

### 8.106 Bagging=专科分工

tcmP 把 Bagging 映射为专科分工并行审阅。自助采样对应各专科 Profile 从同一章节中按专科口径采样条款集：内科 Agent 主审脏腑辨证条款，妇科 Agent 主审经带胎产条款，儿科 Agent 主审小儿病证条款，骨伤 Agent 主审伤科条款，彼此并行、互不阻塞，正如 Bagging 的 T 轮并行训练；每个专科 Profile 只对自身专科条款给出高置信意见，形成“好而不同”的基学习器集合。由于章节条款按病证单元库 BZU 归类，同一章节约有 63.2% 的条款落在某专科主审范围内（对应自助采样率），其余约 36.8% 即为该 Profile 的“包外条款”（演示数值，统计来源，送 tcmreviewer 审稿）。包外估计对应平台的自校验机制：每个专科 Profile 用包外条款检验自身意见的可靠性——若某 Profile 对包外条款的意见与最终定稿系统性不符，说明其专科口径存在偏差，应回修该 Profile 的 SKILL.md；该机制无需额外专家即可完成，对应 8.3 节“包外估计无需额外验证集”。随机属性选择对应审稿视角扰动：同一条款由理论审稿（tcmreviewer 关注病机条理与经典依据）、智能审稿（tcmreviewer_ai 关注现代知识与 ICD-11 术语对齐）与专科审稿（关注临床可用性）从不同属性维度审视，对应随机森林每结点“随机选 k 个属性再择最优”；最终按投票或平均输出该条目的审稿结论。全部结论汇总后送 compatibility-coordinator 做兼容性整合，避免各专科口径冲突。从偏差-方差角度，各专科意见单独波动较大（方差高），并行汇聚后整体更稳，对应 Bagging 主要降低方差；平台用 kanban 泳道并行推进各专科审阅，天然契合 Bagging 的可并行优势。

*单元规模：630 汉字；出处 `教材·机器学习·第8章·8.10`；本单元数值类命中 2。*

### 8.107 Stacking=审稿仲裁

tcmP 把 Stacking 映射为审稿仲裁机制：10 个 Profile（author-agent、tcmreviewer、tcmreviewer_ai、各专科 Agent 等）构成初级学习器，各自独立审阅教材条款并输出结构化意见——原文、、、，这些多源意见构成次级特征向量；compatibility-coordinator 兼容性协调器充当次级学习器（元学习器），将多个初级意见作为新特征输入，结合五大大永久协议（兼容性思维流：不改经典原义、可辅助参考、两说并存等）仲裁出最终落版结论，对应 8.4 节 Stacking“以初级学习器输出为新特征训练次级学习器”。训练数据对应历史审稿记录：以既往“多 Agent 意见→主编定稿”的案例对训练协调器的仲裁权重——若某专科意见在历史案例中常与定稿一致，其仲裁权重提高，对应元学习器从数据中学习特征权重。为避免过拟合，协调器的仲裁规则须在训练集外的审稿案例上验证，正如 Stacking 用交叉验证或留出法产生次级学习器训练样本：平台可把历史案例按时间切分，用前 80% 训练仲裁权重、后 20% 验证（演示数值，统计来源，送 tcmreviewer 审稿）。次级学习器常用多响应线性回归（MLR），对应协调器的线性加权仲裁模型：对同一条款的 N 个等级意见做加权综合，权重可解释为各 Profile 的可信度。实践中若某专科意见与整体结论系统性冲突，仲裁权重自动下调，对应加权结合中 w_i 的调整；若冲突条款数量超过阈值，则触发主编人工介入（对应绝对多数投票中的“拒绝预测”），保证最终教材口径统一且各专科意见得到合理体现。该机制同时复用 FTS5+向量混合检索检索历史相似案例，为仲裁提供可溯源的参考依据。 意见等级量化示例：将映射为数值权重——致命=0、重要=0.3、一般=0.6、建议=0.9，某条款收到 5 个 Profile 的意见等级为 0.3、0.3、0.6、0.9、0.9，协调器以相等 Profile 权重取均值得 0.6，对应“一般”档，可与主编最终判定比对验证（演示数值）。

*单元规模：688 汉字；出处 `教材·机器学习·第8章·8.11`；本单元数值类命中 3。*

### 8.108 多样性管理（兼容性思维流）

tcmP 平台将 8.5 节多样性理论落地为兼容性思维流，对四类扰动逐一映射：样本扰动对应专科分工——各 Profile 按病证单元库 BZU 分工采样，同一章节从不同专科视角审读，对应 Bagging 的自助采样与 AdaBoost 的条款加权；属性扰动对应审稿维度差异——理论审稿关注条文本体与经典依据、智能审稿关注现代知识与 ICD-11 术语、临床审稿关注临床可用性，对应随机森林的随机属性选择；输出表示扰动对应非零和注释——同一条款允许相互矛盾的解读并存（如剂量折算两说、经方与时方之别），以“两说并存、存疑备考”标记呈现而非强行统一，对应翻转类标记与 ECOC 的多样性思想；算法参数扰动对应 Profile 的 SKILL.md 版本差异与记忆库积累差异——同属“智能审稿”的不同版本提示词产生不同视角。多样性-准确性悖论在平台中的体现：专科分工过细会削弱单个 Profile 对整体条文的判断力（个体准确性下降），分工过粗则意见趋同（多样性丧失），由 compatibility-coordinator 动态调节各 Profile 的参与权重。kappa 统计量等多样性度量可用于监控各 Profile 意见的差异程度：对“同意/不同意”的二元意见统计 a、b、c、d 并计算 κ=(p₁-p₂)/(1-p₂)，若某轮审稿 κ>0.8，说明意见高度一致、多样性过低，提示需要引入新视角（如新增专科 Profile 或更换审稿提示词）；若 κ<0.2，说明分歧过大，触发协调器介入仲裁（阈值口径为统计来源，送 tcmreviewer 审稿）。平台定期输出各 Profile 意见的 κ 报表，作为兼容性思维流的量化支撑，确保“好而不同”在实践中可度量、可调节。
