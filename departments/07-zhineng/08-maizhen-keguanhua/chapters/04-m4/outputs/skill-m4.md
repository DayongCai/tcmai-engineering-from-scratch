# 浮沉迟数：把一个形容词切成两类，切点就是全部

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 8 道题自检，答不上就回到对应小节。

## 核心判据

- 搏动幅度峰值出现在低压区还是高压区
- 这套量化只覆盖了「位」，没有覆盖「浮」在临床上的另一半含义
- 脉象客观化的难点，从来不在采集那一步，而在采集之后这一次切割
- 心律不齐时，「数」这个范畴本身失效
- 演算设定，非任何真实研究的分布
- 约登指数相同

## 边界

- 迟、数的具体划界（60、90 一类）在不同教材与规范中并不完全一致，本章取通行说法作为讨论对象，**不作为诊断标准引用**；临床判读以现行规范为准。
- 浮中沉的「峰值一半／两倍」是一种可操作化约定，不是行业标准；跨研究比较前必须核对双方的定义与曲线拟合方法。
- 第三节的敏感度／特异度表、第四节的 `w = (0.9375, −0.0625)` 与 32.9°、第五节的 50 例／105 参数，全部是**演算设定**：用假定分布与假定协方差矩阵做的算术，用来展示切点与相关性的作用方向，不代表任何真实数据集的结果。
- 本章为脉象量化与线性模型的教学讨论，不构成医学意见、诊断或治疗建议。脉率与脉位的临床判读由具备资质的人员依现行规范作出。
