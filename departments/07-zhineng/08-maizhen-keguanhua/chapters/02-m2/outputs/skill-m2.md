# 朴素贝叶斯：先验选错了，后验算得再准也是错的

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 该院该科该时段的号源结构
- 阳性预测值对患病率的固有依赖
- 证型本身的划分方式
- 同一手指摸到的两个脉
- 三个部位同源
- 同一个体的重复测量

## 边界

- 本章的 30% 与 3%、13.9 倍是**示意算式**，用来说明先验对后验的放大效应，不是任何真实研究的患病率。
- 本章不给出任何证型的实际先验、似然或模型性能数字。这类数字必须来自可核查的研究设计，本章不代为估算，也不引用二手转述。
- 「条件独立不成立」是结构性判断，不等于「朴素贝叶斯无用」；判断依据应当是本机构数据的实测校准结果，而不是文献结论。
- 本章为脉诊概率建模的教学讨论，不构成医学意见、诊断或用药建议。临床辨证与任何模型输出的采用，由具备资质的人员依现行规范决定。
