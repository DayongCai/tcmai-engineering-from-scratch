# 聚类：算法一定会给你几个簇，问题是谁来认领它们

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 8 道题自检，答不上就回到对应小节。

## 核心判据

- 任何聚类算法在任意数据上都会返回结果，而且返回的结果一定满足它自己的目标函数
- 距离的 99.99% 由脉率决定，主波幅等于不存在
- 它把"噪声大的特征"放大到与"信号特征"同等权重
- 被报告的选择
- 簇是球形的、大小相近
- 各簇离散程度相同

## 边界

- 本章不推荐任何聚类算法与参数，也**不给出任何真实数据的轮廓系数、ARI 或簇数**。第四节的轮廓系数表是**合成数据的演算结果（演算设定）**：左列由标准正态随机数生成，右列由三个已知均值的等方差簇生成，均经 40 次重复平均，不对应任何真实人群。
- 「轮廓系数峰值须超出零模型 95% 分位」是一条工程建议，不是统计检验的规范表述；正式研究应当按各自的设计选择置换检验或 Bootstrap 的具体形式。
- 第二节的 99.99%、第五节的参数经验值都是量级示意，具体取值取决于特征的实际量纲与样本量。
- 本章为脉象无监督分型的教学讨论，不构成医学意见、诊断或治疗建议。任何分型结论的临床采用，须经独立数据验证并由具备资质的人员判断。
