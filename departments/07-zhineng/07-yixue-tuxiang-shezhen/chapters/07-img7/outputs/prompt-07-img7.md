# 集成降的是方差，不是无知 · 提示词

## 用途

给「集成降的是方差，不是无知」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「方差分解：集成到底省了什么 → 三种集成，对应三种误差来源 → 域偏移：三种，脾气不同 → 怎么测：三种划分与两种压力测试」这条链。
