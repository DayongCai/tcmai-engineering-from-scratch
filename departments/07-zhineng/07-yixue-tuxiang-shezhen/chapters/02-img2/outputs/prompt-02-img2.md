# 采集没定，模型只是在背光 · 提示词

## 用途

给「采集没定，模型只是在背光」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「先承认：颜色是相对的 → 色卡校正与重复性：把光源和人一起管住 → 预处理：哪些是无害的，哪些在抹掉信号 → 增广：先问它是否与标签可交换」这条链。

## 边界

本章为医学图像采集与质量控制的教学讨论，不构成设备选型、诊疗或筛查建议；具体操作以现行规范与所在机构制度为准。
