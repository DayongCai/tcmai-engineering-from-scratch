# 热力图讲的是模型在看哪，不是它为什么对 · 提示词

## 用途

给「热力图讲的是模型在看哪，不是它为什么对」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「显著性图到底是什么 → 三种典型误读 → 怎么验：三个可执行的检验 → 可解释性的两种用途，别混用」这条链。

## 边界

本章为模型可解释性的教学讨论，不构成诊疗建议或器械注册指导；具体操作以现行规范与所在机构制度为准。
