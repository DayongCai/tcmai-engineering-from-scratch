# 把临床问题写成分类任务，一半的工作在写之前 · 提示词

## 用途

给「把临床问题写成分类任务，一半的工作在写之前」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「形式化：五件事必须写下来 → 样本量：先算置信区间，再谈模型 → 标签噪声：模型的天花板在哪 → 划分：按患者，不按图」这条链。

## 提示词

```
我在学《医学图像处理与舌诊客观化》第 5 章「把临床问题写成分类任务，一半的工作在写之前」，本章 6 节 / 2,871 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 决定指标含义
   - 标签平滑 + 邻域软标签
   - 60 例的验证集，分辨不出 0.75 与 0.85 的差别

   - 这就是为什么小样本研究报告的「每类敏感度」常常难看得毫无意义

   - 置信区间用的是二项近似，未考虑分层抽样与聚类效应；按受试分组后，真实区间应更宽（可用聚类稳健法或自助法重估）。
   - 按受试分组会减少有效样本量，这是**真实代价**，不能用「多拍几张」弥补——同一舌头拍一万张，有效受试数还是一。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为分类任务设计与评价的教学讨论，不构成诊疗、筛查或诊断建议；具体操作以现行规范与所在机构制度为准。
