# 把临床问题写成分类任务，一半的工作在写之前

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 决定指标含义
- 标签平滑 + 邻域软标签
- 60 例的验证集，分辨不出 0.75 与 0.85 的差别
- 这就是为什么分类报告必须给每类的敏感度，而不是只给一个总准确率
- 这就是为什么小样本研究报告的「每类敏感度」常常难看得毫无意义
- 模型在干净测试集上的准确率期望上限大致就是这个量级

## 边界

- 本章的一致率 0.78、样本 300/60、受试 200 人等数值均为**演算设定**，用于演示区间宽度与泄漏机制，不代表任何实测研究。
- 置信区间用的是二项近似，未考虑分层抽样与聚类效应；按受试分组后，真实区间应更宽（可用聚类稳健法或自助法重估）。
- 按受试分组会减少有效样本量，这是**真实代价**，不能用「多拍几张」弥补——同一舌头拍一万张，有效受试数还是一。
- 本章为分类任务设计与评价的教学讨论，不构成诊疗、筛查或诊断建议。
