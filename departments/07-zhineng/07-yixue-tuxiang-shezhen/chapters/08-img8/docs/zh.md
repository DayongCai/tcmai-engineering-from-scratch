# 第 8 章 · 一致性不是算出来的，是谈出来的

> **MOTTO:** 「三人占，则从二人之言。」——《尚书·洪范》
>
> **PROBLEM:** 两位高年资医师独立标注 400 张舌象，一致率 78%。这个数字通常被当成「标注质量尚可」写进报告，然后没人再问：剩下 22% 的分歧在哪、为什么、有没有规律。演算设定把这 88 张分歧图挑出来看，会发现它们集中在一处——舌边偏暗、苔薄的那一批。也就是说，分歧不是随机的，是**判据在某个区间没有定义**。随机分歧可以靠加人平均掉，系统性分歧只会被模型学成噪声。**kappa 0.70 这个数不说明标注「还行」，它说明有 30% 的判断空间没被规范覆盖。**

**双根因定位:** 环境逼迫（临床判读本来就有个体差异，教材用「 Typical / 非典型」这样的词描述，不给硬边界；而算法要的是二值决定）+ 知识积累（一致性的度量有三种口径——原始一致率、kappa、以及分割任务的重叠度——它们的含义完全不同，混用会把「判据缺失」误读成「标注员不认真」）

## 一、规范要写到「两个人会做同样决定」

一份可用的标注规范，六件事缺一不可：

| 要素 | 要写什么 | 缺失的后果 |
|---|---|---|
| 定义 | 每个类别的文字定义，用可观察的属性 | 各自按经验理解，分歧不可查 |
| 边界例 | 每类给 3–5 张「典型」与 2–3 张「临界」参照图 | 临界样本成为分歧温床 |
| 排除例 | 明确什么情况不标（模糊、过曝、遮挡） | 坏图被强行标注，制造噪声 |
| 粒度 | 一处／一片／一图；齿痕「几处」怎么数 | 计数类标注无法比较（第 1 章） |
| 工具与流程 | 用什么软件、什么顺序、能否回看 | 流程差异引入系统偏差 |
| 仲裁 | 分歧由谁裁、依据什么、如何留档 | 分歧被随手抹平，无从追溯 |

第二行是重点，也是最费工夫的一项。**参照图例的成本常被低估**：找 5 张公认的典型图、3 张公认的临界图，需要几位医师坐在一起谈，往往要谈两三轮。但它的收益极高——它把「淡红」这个抽象词，变成了「不比这张更淡、不比那张更红」的锚点。没有锚点，规范只是文字；有了锚点，规范才是判据。

规范条文要写成可判定的句子。「舌质偏淡：舌中区域 $L^*$ 中位数高于同批参照图的 75 分位」是可判定的；「舌质淡白，色泽偏淡」不可判定。前者需要参照图与测量口径，后者只表达了一种感觉。这不是要求所有判据都量化——临床上很多判断确实靠经验——而是要求**凡是要进算法的那几条，必须落到可观察量上**；其余部分可以留作参考，但要明确标注「不参与标注」。把可判定与不可判定混在同一份规范里，标注员会默认全部按感觉走。

## 二、一致性的三种口径

**口径一：原始一致率** $P_o$，即两位标注员给出相同标签的比例。直观，但会被类别分布欺骗（见下一节）。

**口径二：Cohen's kappa**，扣除「碰巧一致」：

$$\kappa = \frac{P_o - P_e}{1 - P_e},\qquad P_e = \sum_{k=1}^{K} p_{1k}\,p_{2k}$$

其中 $p_{1k}$、$p_{2k}$ 是两位标注员在类别 $k$ 上的边际比例。演算设定 5 类舌色，400 张：

- 标注员 A 的分布：0.40、0.25、0.20、0.10、0.05
- 标注员 B 的分布：0.38、0.27、0.20、0.10、0.05
- $P_e = 0.40\times0.38 + 0.25\times0.27 + 0.20\times0.20 + 0.10\times0.10 + 0.05\times0.05$
  $= 0.152 + 0.0675 + 0.040 + 0.010 + 0.0025 = 0.272$
- 观测一致率 $P_o = 0.78$
- $\kappa = (0.78-0.272)/(1-0.272) = 0.508/0.728 \approx 0.70$

0.70 落在常用分级里的「中等偏上」区段。但分级只是习惯用语，**真正有用的是看分歧矩阵**：哪两类之间互换最多。若分歧集中在「淡红↔红」，那是判据边界问题；若分散在所有类之间，那是标注员训练问题；若某一位标注员系统性地把一类判成另一类，那是个人偏倚，需要单独校准。

**口径三：分割的重叠度**。分割标注没有「类」可对，用两位标注员掩膜的 Dice：

$$\text{Dice}(A,B) = \frac{2|A\cap B|}{|A|+|B|}$$

演算设定：两位医师对同一批舌体的掩膜 Dice 中位数 0.94，而模型对「金标准」的 Dice 是 0.91。这个比较很有信息量：**模型已经接近人际一致性水平**。此时继续优化模型的边界精度，收益会被「人际边界本身就有 6% 的分歧」这一事实吃掉——该做的是明确「边界以谁为准」，而不是继续调网络。

## 三、kappa 的两个悖论

**悖论一：高一致率，零信息。** 若两类占比 95%／5%，两位标注员都把全部样本判为多数类：

- $P_o = 0.95\times0.95 + 0.05\times0.05 = 0.9025+0.0025 = 0.905$
- $P_e = 0.95\times0.95 + 0.05\times0.05 = 0.905$
- $\kappa = (0.905-0.905)/(1-0.905) = 0$

一致率 90.5%，kappa 0。这说明原始一致率不能单独报——它把一个「什么都没判」的标注行为描述成「高度一致」。

**悖论二：kappa 低，未必是标注差。** kappa 对边际分布极度敏感。若两位标注员的边际分布差异大（一位偏保守、一位偏激进），即使他们按同一套标准判读，kappa 也会被压低。这种情形叫「偏倚」，此时应看 **PABAK**（偏倚校正的 kappa，$=2P_o-1$）或直接看分歧矩阵，而不是盯着 kappa 下结论。

所以报告的写法应该是：**原始一致率 + kappa + 分歧矩阵 + 边际分布**，四项并列。只给一个 kappa，读者无法判断低是因为判据模糊，还是因为两位标注员尺度不同。

## 四、仲裁：金标准是一个可复现的妥协

第三人仲裁是标准做法，但它产生的东西不是「真值」，是一个**可复现的裁定**。这一点必须写在规范里，否则后续会把仲裁结论当成客观事实使用。

三条实践规则：

1. **仲裁者要比标注者更资深，且不看前两人的结论**（盲裁），否则会被锚定。
2. **仲裁必须留理由**，哪怕一句话：「舌边偏暗但主体淡红，按主体判淡红」。这些理由是规范迭代的原料——某一类理由反复出现，就说明规范缺了这一条。
3. **仲裁结论要标注来源**，与「两人一致」的样本区分开。下游做误差分析时，这两类样本的性质不同：一致样本是「共识」，仲裁样本是「裁定」。

一个常见的流程缺陷：把仲裁后的标签当成「干净标签」，直接用交叉熵训练，不做任何区分。更稳的做法是给仲裁样本更低的样本权重，或至少在评价时分层报告「共识子集」与「裁定子集」上的性能——后者往往明显更低，而这个差距恰好度量了「判据模糊区」对模型的伤害。

仲裁比例本身是一个有用的指标。演算设定 400 张里仲裁 88 张，占 22%。若这个比例长期高于 25%，说明规范有系统性缺口，应当停下来补规范，而不是继续标；若低于 5%，反而要警惕——可能是第二标注员看到了第一位的结论而被锚定，「一致」是假一致。检查办法是双盲：两位标注员互相看不到对方的标注，直到提交后才比对。

还有一条制度建议：**标注规范要有版本号，并与数据集版本绑定**。规范改了一版，旧数据不一定还适用；若不记录「哪批数据按哪版规范标」，两年后没人说得清某个标签的确切含义。这听起来像文书工作，实际是数据资产能否长期复用的分水岭——换一个人接手时，它决定了这个数据集是可用的资产还是一堆无主的图片。

## 五、把一致性度量变成一个改进回路

一致性数字本身没有价值，它的价值在于指向下一步动作。一条可执行的回路：

```
标注 → 算 Po/kappa → 看分歧矩阵 → 定位高分歧类别 → 补边界例 → 重标一小批 → 再算一致性
```

演算设定一轮迭代的效果：初次 $\kappa=0.70$，分歧集中在「淡红↔红」；补 6 张临界参照图、明确「以舌中区域为准、边缘不计」后重标 100 张，$\kappa$ 升到 0.78。这不是因为标注员变认真了，是因为**判据补上了一块**。

这条回路也解释了为什么「先做小批试点」比「一次标完五千张」划算：五千张标完才发现判据有洞，返工成本是灾难性的；先标 200 张、算一致性、补规范，再放开，成本低一个数量级。

预算的切法由此也能定下来：大约七成用于正式标注，两成用于重复标注（只为算一致性），一成用于仲裁与规范迭代。多数项目的预算全部押在正式标注上，结果一致性无从计算，出了问题也无法定位。**重复标注那两成不是浪费，它是唯一能让「标签质量」变成可测量量的支出。**

还有一条要写进规范的制度性安排：**标注员不能是模型开发者本人**。开发者标数据时会不自觉地向「模型容易学」的方向偏移（挑清晰的、避开模糊的），这是一种自我实现的偏差，而且无法从数据里看出来。

## 代价与边界

- 本章的 $P_o=0.78$、$\kappa=0.70$、Dice 0.94/0.91 等数值均为**演算设定**，用于演示计算过程，不代表任何实测标注研究。
- kappa 的分级（如 0.61–0.80 为「中等偏上」）是习惯用语，不同领域有不同口径；本章不把它当作质量合格的判定标准。
- 增加标注员、增加仲裁轮次都会显著提高成本（演算设定下每张图的人工时间约翻倍），**这个成本必须写在项目预算里**；用「加人」换一致性，前提是分歧确实来自随机误差。
- 本章不给出任何疾病的判读标准；类别的临床定义须由具备资质的医师与所属学会确认，本章只讨论如何把定义写成可执行的形式。

**免责声明：** 本章为标注规范与判读一致性的教学讨论，不构成诊断标准或临床指南；任何判读规范的制定须由相应专业的医师团体完成。
