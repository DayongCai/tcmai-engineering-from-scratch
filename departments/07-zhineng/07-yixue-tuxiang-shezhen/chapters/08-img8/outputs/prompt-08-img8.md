# 一致性不是算出来的，是谈出来的 · 提示词

## 用途

给「一致性不是算出来的，是谈出来的」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「规范要写到「两个人会做同样决定」 → 一致性的三种口径 → kappa 的两个悖论 → 仲裁：金标准是一个可复现的妥协」这条链。
