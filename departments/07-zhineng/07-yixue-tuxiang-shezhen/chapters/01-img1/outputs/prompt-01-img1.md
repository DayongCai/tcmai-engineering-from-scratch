# 图像从哪来，决定了你能问什么问题 · 提示词

## 用途

给「图像从哪来，决定了你能问什么问题」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三类来源，三种脾气 → 任务形式化：三种标签形状 → 同一张舌象，三个任务三种问法 → 图像能回答什么，不能回答什么」这条链。

## 提示词

```

正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。
```

## 边界

本章为医学图像任务建模的教学讨论，不构成诊疗、筛查或设备选型建议；具体操作以现行规范与所在机构制度为准。
