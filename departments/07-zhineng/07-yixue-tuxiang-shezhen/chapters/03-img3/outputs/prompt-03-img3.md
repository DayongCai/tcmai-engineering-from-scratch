# 特征不是越多越好，是越稳越好 · 提示词

## 用途

给「特征不是越多越好，是越稳越好」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三类特征，三种稳定性 → 颜色特征：主力，也是最大的坑 → 纹理：LBP 便宜，GLCM 可解释 → 降维、维度与那个最贵的错误」这条链。
