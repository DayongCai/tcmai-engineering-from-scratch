# 不平衡不是数据问题，是决策问题 · 提示词

## 用途

给「不平衡不是数据问题，是决策问题」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「不平衡从哪来，三种来源要分开 → 指标：四个格子与两条曲线 → 阈值：把打分与决策分开 → 重采样与代价敏感：能做什么，不能做什么」这条链。

## 提示词

```

正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
```

## 边界

本章为类别不平衡与阈值决策的教学讨论，不构成筛查、诊断或公共卫生建议；具体操作以现行规范与所在机构制度为准。
