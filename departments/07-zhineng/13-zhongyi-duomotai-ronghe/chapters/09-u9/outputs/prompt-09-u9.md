# 说多模态更好之前，先让它可被反驳 · 提示词

## 用途

给「说多模态更好之前，先让它可被反驳」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「增益从哪来：三种来源要分开 → 必报的基线矩阵 → 缺失条件下的评估：一条曲线，不是一个点 → 校准与决策曲线」这条链。

## 边界

本章为多模态模型评估方法的教学讨论，不构成临床效能结论或产品性能评价；具体操作以现行规范与所在机构制度为准。
