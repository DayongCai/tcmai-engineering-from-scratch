# 第 8 章 · 知识不是特征，是约束

> **MOTTO:** 「谨守病机，各司其属。」——《素问·至真要大论》
>
> **PROBLEM:** 把「舌红 + 脉数」这类配伍先验做成知识图谱（演算设定 1,200 个节点、3,400 条边），以 logit 偏置的方式注入模型：在 200 例小样本上，F1 从 0.61 升到 0.68，看着很好。但把测试集按证型拆开看——知识图谱覆盖的 12 类上是 0.71，未覆盖的 40 类上从 0.55 掉到 0.47。**知识注入有一个适用半径：半径之内是增益，半径之外是干扰。**

**双根因定位:** 环境逼迫（临床判读依赖大量先验：症状配伍、舌脉相应、方证对应；这些先验在几百例数据里学不出来，只能从外部引入）+ 知识积累（知识进入模型有三条通道——特征、损失、结构——每条通道的作用机制与副作用都不同；把知识当特征是最弱的一种用法）

## 一、三条通道

| 通道 | 做法 | 机制 | 副作用 |
|---|---|---|---|
| 特征拼接 | 把「是否满足某条规则」作为 0/1 特征 | 模型自行决定用不用 | 小样本下权重估不准，规则被淹没 |
| 约束损失 | 输出违反先验时加惩罚项 | 直接塑造决策边界 | 惩罚权重过大则压制数据证据 |
| 结构注入 | 用图结构连接输出（GNN / 层次分类） | 在标签空间上施加依赖 | 图错一处，下游全错 |

第三条最强也最危险。举例：若知识图谱规定「脾气虚」与「脾阳虚」是上下位关系，用层次分类器建模，那么把「脾阳虚」判成「脾气虚」的代价小于判成「肝郁」——这符合临床直觉。但若这条边本身标错了（不同教材对二者的关系表述不一），错误会沿着结构传播到所有相关样本，而且很难被发现，因为模型在结构内是自洽的。

## 二、本体：先对齐术语，再谈注入

知识注入的第一个坑不在模型，在术语。

同一个症状在不同教材里叫法不同： 「纳差」「食欲不振」「食少」；同一个舌象在图像标注里叫「舌淡胖」、在证候标准里叫「舌体胖嫩」。若不做同义词归并，图谱里的边会有三份，权重各三分之一，实际强度被稀释成三分之一。

一个可操作的本体至少要有四类关系：

| 关系 | 例 | 用途 |
|---|---|---|
| 同义 | 纳差 ≡ 食少 | 归并，避免权重稀释 |
| 上下位 | 脾阳虚 ⊂ 脾虚 | 层次分类、错误代价分级 |
| 配伍 | 舌红 + 脉数 → 热 | 联合模式约束 |
| 互斥 | 寒 ∉ 热（同一维度） | 排除矛盾输出 |

第四类最容易被漏。互斥关系能直接用作解码约束：若模型同时输出「寒」与「热」，说明它内部矛盾，此时应当拒答或降级，而不是取概率大者。

## 三、先验强度：一个必须调的旋钮

约束损失一般写成

$$\mathcal{L}=\mathcal{L}_{\text{CE}}+\lambda\sum_{k}\max\left(0,\ 1-\sum_{c\in C_k}p_c\right)$$

第二项惩罚「本应共现的证候没有被同时激活」。$\lambda$ 决定先验与数据谁说话。

演算设定一组扫描，说明 $\lambda$ 的作用：

| λ | 覆盖类 F1 | 未覆盖类 F1 | 违反先验率 |
|---|---|---|---|
| 0（无先验） | 0.61 | 0.55 | 18.4% |
| 0.1 | 0.66 | 0.55 | 12.1% |
| 0.3 | 0.71 | 0.47 | 6.8% |
| 1.0 | 0.68 | 0.33 | 3.1% |

读法：$\lambda$ 从 0 升到 0.3，覆盖类的收益是 +0.10，未覆盖类的损失是 −0.08；再往上，覆盖类也开始掉（因为过度约束压住了数据里真实的例外），未覆盖类崩得更快。

原因是未覆盖类没有先验可依，惩罚项对它们只是噪声——模型为了降低违反率，会把它们往最近的、有先验的类上推。这就是「知识半径」的机制：**先验越强，越会把地图外的样本拉回地图内**。

所以 $\lambda$ 的选择不能只看总体 F1，必须**分层看覆盖与未覆盖**。若未覆盖类在目标场景占比高（比如门诊的杂证多），$\lambda$ 应取小值甚至 0。

## 四、知识冲突时谁赢

真实场景里，数据与知识经常冲突：模型从数据里学到「舌淡 + 脉数」多见于某类，而教材说舌淡主虚寒、脉数主热。这时有三条处理路线。

**路线一：数据赢。** 适合数据量大、标注可靠、且冲突只出现在少数样本。做法是降低 $\lambda$，让数据主导，同时把这批冲突样本单独列出供专家复核。

**路线二：知识赢。** 适合数据量小、先验来自权威标准。做法是提高 $\lambda$，并对违反先验的输出做硬约束（解码时屏蔽）。风险是把数据里的真实新发现压掉。

**路线三：显式建模冲突。** 把「是否冲突」作为一个输出维度，让模型学会说「此例脉症不符」。这是最有价值的路线，也最难：它要求训练集里有足够的冲突样本，而这类样本恰恰稀少。

第三条路线的临床对应物是「脉症从舍」——当脉与症不符时，医者要判断是从脉还是从症。把这个判断做成可学习的输出，比强行让两者一致更接近真实判读。但要非常小心：模型学到「冲突」之后，必须有机制让它说明冲突在哪，否则它只是学会了含糊。

## 五、知识工程：从条文到可审计输出

### 图谱从哪来：抽取的四类错误

知识不会自己变成边。从教材、标准、病历里抽三元组，四类错误最常见，且每一类都会在模型里被放大。

| 错误 | 例子 | 后果 | 检查方法 |
|---|---|---|---|
| 过度泛化 | 「舌红主热」抽成「舌红 → 热（权重 1.0）」 | 虚证假热也被判为实热 | 补限定条件（兼脉、兼症） |
| 遗漏限定 | 漏掉「但脉虚细者除外」 | 规则在边界病例上系统性错 | 与原条文逐句对照 |
| 关系混淆 | 把「相关」抽成「导致」 | 因果方向错，解释失真 | 边的类型必须显式标注 |
| 粒度不一 | 有的到证型，有的到症状 | 层次分类时上下位断裂 | 建统一的术语表与层级 |

第一类最隐蔽，因为它在大多数病例上都对。教材的表述往往带条件（「舌红苔黄而燥者，热在气分」），抽取时若把条件丢掉，规则就从「条件命题」退化成「倾向性关联」——覆盖面变大，精度下降。这类错误的检测方法很朴素：拿规则去跑一遍历史病例，看假阳性集中在哪些兼症上，再回头把条件补回去。

第四类是多模态特有的麻烦。图像标注习惯到「舌体胖大」，证候标准习惯到「脾虚湿困」，两者不在同一层级。若直接连边，层次分类器会认为「舌体胖大」与「脾虚湿困」同级，从而在推理时跳过中间层。可行做法是建一个显式的层级：症状层 → 病机层 → 证候层，边只在相邻层之间连。

### 可审计：每条输出追到哪条边

知识注入的价值一半在性能，一半在可审计。若一条输出无法追溯到具体规则，知识就等于没进来。

最低要求是**输出附证据链**：

```
结论: 脾阳虚（p = 0.62）
证据:
  - 舌淡胖        ← 规则 R-112（舌淡胖 → 脾虚）
  - 脉沉迟        ← 规则 R-087（脉沉迟 → 阳虚）
  - 畏寒肢冷      ← 问诊项 Q-33
冲突:
  - 无
未覆盖:
  - 无
知识版本: kg@v1.3（2026-03 修订）
```

这份结构有三个作用：医师可逐条核对；研究人员可统计「哪条规则最常被触发、最常被推翻」；质量管理部门可追溯版本变更的影响。

反过来，如果模型只给一个概率，知识注入就无法被审计——你也无法知道它到底用了先验，还是只是把先验当成了又一批参数。

## 六、小样本下的先后顺序

知识注入的四个动作不能并行推进，顺序错了会返工。可行的次序是：

1. **术语对齐**。先把教材、标准、标注表里的名词归并成一张表。这一步不做，后面所有统计都会被同义词稀释。
2. **规则抽取与限定补全**。每条规则都要带条件（兼脉、兼症、排除项），并标注来源条文。
3. **先验强度扫描**。$\lambda$ 从 0 开始，按覆盖类与未覆盖类分别看指标，取两者都不明显变差的区间。
4. **结构注入**。只有在前三步都稳的前提下，才上层次分类或图网络。结构一旦引入，错误会沿边传播，排查成本成倍上升。

这个次序的道理是「先保证不坏，再追求更好」。第三步之前，模型的失败是可归因的（哪条规则太强、哪类样本被拉偏）；第四步之后，失败往往表现为整片区域一起错，且难以定位。

另一个实践中的提醒：**知识注入的收益会随数据量增长而缩小**。500 例以下，先验能补上数据学不出的结构；5,000 例以上，数据本身足以覆盖大部分模式，先验若还有偏差，反而成为上限。所以「要不要注入知识」这个问题，应当随样本量重新回答，而不是一次决定。

## 代价与边界

- 本章所有数值（1,200 节点、3,400 边、200 例、F1 0.61/0.68/0.71/0.47/0.33、λ 扫描、违反率 18.4%/3.1%）均为**演算设定**，用于说明知识半径与先验强度的取舍，不对应任何实测知识图谱或模型。
- 本章不主张任何具体的证候-症状关系表；知识图谱的构建须依据权威标准与专家共识，并记录版本与修订依据。
- 「知识半径」是定性描述，其边界依赖具体图谱的覆盖度与样本分布；不存在通用的 λ 取值。
- 知识注入不能替代数据证据，也不能修正标注错误；若训练标签本身有系统性偏差，先验只会把偏差固化。
