# 融合的难点不在拼，而在对齐 · 提示词

## 用途

给「融合的难点不在拼，而在对齐」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三种融合：信息在哪一层汇合 → 对齐的三层 → 缺失模态：三种策略，三种适用面 → 选择哪条路：一棵决策树」这条链。

## 边界

本章为多模态融合策略与对齐方法的理论讨论，不构成临床决策模型的设计规范；具体操作以现行规范与所在机构制度为准。
