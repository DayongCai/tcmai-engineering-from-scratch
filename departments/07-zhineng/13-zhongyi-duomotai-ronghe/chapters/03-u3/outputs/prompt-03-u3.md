# 预处理不是洗干净，是翻译到同一把尺子上 · 提示词

## 用途

给「预处理不是洗干净，是翻译到同一把尺子上」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「脉图：先去趋势，再滤带外 → 重采样：向下必须抗混叠，向上毫无意义 → 舌象：色卡、白平衡、Lab → 语音：帧化、谱、归一」这条链。

## 提示词

```

正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
```

## 边界

本章为多模态信号与图像预处理的教学讨论，不构成临床判读标准或设备性能评价；具体操作以现行规范与所在机构制度为准。
