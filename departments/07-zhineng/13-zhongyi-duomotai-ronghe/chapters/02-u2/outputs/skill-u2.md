# 采集链上掉一次时钟，融合就少一分可信

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 2 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 元数据不是文档工作，它是模型可用性的前置条件
- 让不同模态的等待时间互相填满

## 边界

- 本章的合格率 95%、整链 73.5%、各质控阈值（20 dB、15%、0.1%、0.25、5%）与误差预算（±5 ms）均为**演算设定**，用于说明链式衰减与阈值设计思路，不对应任何实测设备；真实阈值须按设备与人群重新标定。
- 「95% 合格率」是演示用的乐观值。实际多模态采集的整链合格率常显著更低，且各环节不独立（受试者配合差会同时拉低多个环节），此时链式相乘会高估整体合格率。
- 本章的质控指标只覆盖信号自身质量，不覆盖**语义质量**（如问诊回答是否真实、舌象是否代表当时的证候）；后者需要临床复核，不能由算法判定。
- 本章为多模态采集链路与质量控制的教学讨论，不构成设备操作规范或临床建议。
