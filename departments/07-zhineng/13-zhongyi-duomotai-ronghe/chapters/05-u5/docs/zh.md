## 三、逐单元读

### 5.73 神经元模型

神经网络（neural network）是由具有适应性的简单单元组成的广泛并行互连的网络，它的组织能够模拟生物神经系统对真实世界物体所作出的交互反应（Kohonen，1988）。在生物学中，神经系统的基本单元是神经元：神经元通过树突接收来自其他神经元的信号，在细胞体内完成整合，若总刺激超过一定强度，就沿轴突向其他神经元传递兴奋信号。人工神经网络正是对这一过程的高度简化与抽象——把大量结构简单、具有适应能力的计算单元按一定的层次与连接方式组织起来，让它们通过并行协作完成复杂的模式识别与函数映射任务。机器学习中所说的"神经网络"，通常就是指这种由人工神经元互连而成的计算模型；而"学习"则体现在连接强度（权值）与神经元门槛（阈值）随训练数据的自适应调整上。从历史看，神经网络研究几经起伏：M-P 模型奠定了理论基础，感知机带来第一次热潮，XOR 困境使其陷入低潮，BP 算法掀起第二次热潮，直至 2006 年深度学习兴起迎来第三次浪潮——本章的内容正是这条发展主线上的核心环节。 最基本的组成单元是神经元（neuron）模型，即上述"简单单元"。1943 年，McCulloch 与 Pitts 提出了沿用至今的 M-P 神经元模型。在该模型中，神经元接收来自 n 个其他神经元传递来的输入信号 x₁, x₂, …, xₙ，各输入信号通过带权重的连接（connection）进行传递，神经元接收到的总输入为 Σᵢwᵢxᵢ，其中 wᵢ 为第 i 个输入对应的连接权（weight）。神经元将总输入与自身的阈值（threshold）θ 比较后，经激活函数（activation function）处理产生输出，其数学形式为 y = f(Σᵢwᵢxᵢ − θ) 连接权 wᵢ 刻画了相应输入信号对该神经元的重要程度，阈值 θ 则相当于一个"门槛"：只有当总输入超过门槛时，神经元才被"激活"并产生输出。权值与阈值都是待学习的参数，正是它们决定了神经元的输入—输出行为。

### 5.74 感知机与多层网络

感知机（perceptron）由两层神经元组成：输入层接收外界输入信号后传递给输出层，输出层是 M-P 神经元，亦称"阈值逻辑单元"（threshold logic unit）。感知机是神经网络家族中结构最简单、也是最早被研究的模型之一，其学习规则由 Rosenblatt 于 20 世纪 50 年代末提出，是早期监督学习算法的代表，曾成功应用于模式识别等任务。感知机的学习规则可描述如下：对每个训练样例 (x, y)，其中 x 为 d 维输入向量，y 为真实标记，设感知机当前的输出为 ŷ。若 ŷ 与 y 不符，即当前权向量错分了该样本，则按下式调整连接权： wᵢ ← wᵢ + Δwᵢ，Δwᵢ = η(y − ŷ)xᵢ 其中 η∈(0,1) 称为学习率（learning rate），控制每次更新的步长。该规则的几何含义十分直观：感知机的决策边界是超平面 Σᵢwᵢxᵢ = θ（把阈值并入权向量后即 w^T x = 0 的形式），学习的过程就是不断转动这个超平面使其正确划分训练样本。若 y−ŷ=1，说明真实标记为 1 而当前输出为 0，即权向量把该样本分到了错误一侧，此时 Δwᵢ=η(y−ŷ)xᵢ 使权向量朝样本方向转动，增大该样本的净输入，使下次更可能输出 1；反之，若 y−ŷ=−1，则朝相反方向调整，减小净输入。可见感知机学习是"错误驱动"的：只有被错分的样本才触发参数更新，且更新幅度与错分程度（y−ŷ）及输入大小成正比。 感知机学习逻辑或。设初始权值 w₁=w₂=0、阈值 θ=0（即并入哑结点后初始权向量为 0），学习率 η=1，训练样本为 OR 的四个组合。依次考察样本 (0,0)→0：当前净输入 0，输出 0，与标记一致，不更新；样本 (0,1)→1：净输入 0，输出 0，错分，按 Δwᵢ=η(y−ŷ)xᵢ 更新，仅 w₂ 改变：w₂←w₂+1；样本 (1,0)→1：此时 w₁=0、w₂=1，净输入 0，输出 0，错分，更新 w₁←1；再考察 (1,1)→1：净输入 2，输出 1，正确。继续遍历训练集，全部样本均被正确分类，感知机收敛。

### 5.75 误差逆传播 BP

误差逆传播（BackPropagation，简称 BP）是迄今最成功的神经网络学习算法，由 Rumelhart、Hinton 与 Williams 于 1986 年提出，其经典论文《Learning representations by back-propagating errors》开启了神经网络的第二次热潮。BP 算法不仅可用于多层前馈网络，也可用于训练其他类型的神经网络（如递归网络）；通常所说的"BP 网络"，一般是指用 BP 算法训练的多层前馈网络。其核心思想可概括为两步：前向传播——训练样例从输入层进入，经隐层逐层传递，在输出层产生输出；反向传播——将输出与期望输出之间的误差逐层回传，据此更新各连接权与阈值。整个过程可看作"前向算输出、反向传误差、逐层改参数"的循环迭代。 为给出 BP 算法的严格推导，先约定记号。设训练集 D = {(x₁,y₁), (x₂,y₂), …, (xₘ,yₘ)}，xₖ∈ℝᵈ，yₖ∈ℝˡ，即每个样本有 d 个属性、l 个输出分量。考察一个 d 个输入神经元、q 个隐层神经元、l 个输出神经元的单隐层前馈网络：输出层第 j 个神经元的阈值记为 θⱼ，隐层第 h 个神经元的阈值记为 γₕ；输入层第 i 个神经元与隐层第 h 个神经元之间的连接权为 vᵢₕ，隐层第 h 个神经元与输出层第 j 个神经元之间的连接权为 wₕⱼ。隐层第 h 个神经元接收到的输入为 αₕ = Σᵢ vᵢₕ xᵢ，其输出为 bₕ = f(αₕ − γₕ)；输出层第 j 个神经元接收到的输入为 βⱼ = Σₕ wₕⱼ bₕ，其输出为 ŷⱼᵏ = f(βⱼ − θⱼ)。 对训练样例 (xₖ, yₖ)，网络输出为 ŷₖ = (ŷ₁ᵏ, ŷ₂ᵏ, …, ŷₗᵏ)，则网络在该样本上的均方误差为 Eₖ = ½ Σⱼ (ŷⱼᵏ − yⱼᵏ)² BP 算法基于梯度下降（gradient descent）策略，以目标的负梯度方向对参数进行调整。

### 5.76 全局最小与局部最小

神经网络的训练过程，本质上是在参数空间中搜索使误差 E 最小的参数组合。神经网络的参数空间通常是高维的（连接权与阈值的总数往往成百上千），误差函数在其中呈现"多峰"的复杂地貌：既有许多局部的凹陷，也有全局的最低点，还有起伏的脊线与平坦的高原。若参数空间中某点 P 的邻域内误差最小，则称 P 为局部最小（local minimum）；若在整个参数空间中误差最小，则称该点为全局最小（global minimum）。显然，全局最小一定是局部最小，反之不然——换言之，对局部最小点 P，存在邻域 δ 使区域内所有点的误差都不小于 E(P)；而对全局最小点，该性质在整个参数空间成立；梯度为零的点除了可能是局部最小或全局最小外，还可能是鞍点（saddle point）——在该点某些方向上升、某些方向下降，误差并非最小却同样"卡住"梯度下降。 梯度下降是参数寻优中使用最广泛的方法：设当前参数为 θ，误差函数为 E(θ)，则每一步按 θ ← θ − η·∇E(θ) 迭代——沿误差函数负梯度方向（即最陡下降方向）移动一小步，直至梯度为零或接近零。然而，梯度下降是"贪心"的：一旦落入局部最小点，该点梯度为零，算法便无法继续前进，而全局最小点可能位于参数空间另一个"山谷"中，两者之间隔着误差更高的"山脊"。由于参数空间规模巨大，人们通常无法逐一验证某个极小点是否全局最小，因此"跳出"局部最小是神经网络训练中的现实难题。 一维直观示例。考察单变量函数 E(w) = w⁴ − 2w²：它在 w=±1 处各有一个极小值（E=±… 均为 −1），其中两个极小值相等；若考察 E(w)=w⁴−2w²+… 类不对称函数，则一个为局部最小、另一个为全局最小。无论哪种情形，从某个谷底附近出发的梯度下降都会稳定在该谷底而无法到达另一个谷底。这个例子说明，局部最小与全局最小的分野是梯度类方法的固有难题，与问题维度无关，高维空间中该问题只会更严重。

### 5.77 其他常见神经网络

除前馈神经网络外，研究者还发展出多种结构各异的神经网络模型，分别适用于不同的任务场景，本节介绍其中代表性的一批。 （1）RBF 网络。RBF（Radial Basis Function，径向基函数）网络是一种单隐层前馈神经网络，它使用径向基函数作为隐层神经元的激活函数。最常用的径向基函数是高斯函数：φᵢ(x) = exp(−‖x−cᵢ‖²/(2σᵢ²))，其中 cᵢ 为第 i 个隐层神经元的中心，σᵢ 控制函数的宽度。隐层将输入映射到一个高维空间，输出层则是对隐层神经元输出的线性组合，即网络输出 = Σᵢ wᵢ φᵢ(x)。从函数逼近的角度看，RBF 网络可看作"以隐层基函数展开的线性模型"：基函数在输入空间中局部响应——输入越靠近中心 cᵢ，对应的隐层神经元输出越接近 1（激活越强），离中心越远则输出迅速衰减到 0，宽度 σᵢ 决定了响应的作用范围。其训练通常分两步进行：第一步确定隐层神经元的中心 cᵢ，常用随机采样、聚类（如 k 均值）等方法从训练样本中选取代表性位置；第二步在中心确定后，利用 BP 算法等确定输出权值 wᵢ 与宽度 σᵢ，此时因隐层输出已固定，权值求解退化为线性问题，也可用最小二乘直接求解线性方程组。RBF 网络结构简单、训练较快、局部逼近能力强，常用于函数逼近与插值问题。 （2）ART 网络。ART（Adaptive Resonance Theory，自适应谐振理论）网络是竞争型学习（competitive learning）的代表，由比较层、识别层、识别阈值和重置模块四部分组成：比较层负责接收输入样本，并将其传递给识别层神经元；识别层每个神经元对应一个模式类，通过连接权存储该类别的"原型"；识别阈值 ρ 则控制归类的严格程度。ART 的学习过程是：输入样本到达比较层后，与识别层各神经元的原型计算匹配度，若最匹配的神经元所代表的类别与样本的匹配程度超过识别阈值 ρ，则将该样本归入该类，并调整对应连接权使原型向样本靠拢（学习）；否则，重置模块被触发，为该样本分配一个新的识别层神经元，建立新类别。

### 5.78 深度学习

深度学习（deep learning）指使用多隐层神经网络的学习方法，其核心在于"深"：通过多层非线性变换对数据进行逐层抽象——底层网络学习边缘、纹理等局部低级特征，中层组合成部件，高层则形成对整体对象的抽象表示，从而获得强大的表示能力。与"浅层"模型（如单隐层网络、SVM 等）相比，深层模型的每一层都相当于对上一层表示的一次非线性再变换：浅层模型需要人工设计合适的特征，而深层模型让每一层自动完成一次"特征再加工"，深度越深，能够表达的函数类越复杂、表示越抽象。典型的深度学习模型包括用于图像等网格数据的卷积神经网络（Convolutional Neural Network，CNN）与用于序列数据的循环神经网络（RNN）等。 深层网络训练的困难在于：误差逆传播时，误差信号沿网络逐层回传，需要与每一层的连接权矩阵相乘（链式法则连乘），导致梯度随层数增加而指数级衰减——这就是梯度消失（vanishing gradient）问题：靠近输入层的参数几乎收不到有效的梯度信号，标准 BP 难以奏效（层数过深时还可能发生梯度爆炸）。这一瓶颈长期制约着深层网络的训练。2006 年，Hinton 与 Salakhutdinov 提出了突破性方案——无监督逐层预训练加有监督微调：先采用无监督学习逐层训练网络，将多层受限 Boltzmann 机堆叠成深度信念网络（Deep Belief Network，DBN），或用自编码器（autoencoder）逐层对数据进行重构式学习——每一层都试图在无监督条件下重建上一层的表示，从而把各层参数初始化到距离较优解较近的位置；在此良好初始化的基础上，再用 BP 算法对整个网络进行有监督微调（fine-tuning）。预训练相当于为深层网络提供了好的起点，使原本难以训练的深层结构变得可行；微调则利用监督信号进一步精化参数。深度学习由此重新兴起并迅速成为研究热点，而预训练—微调的思想也深刻影响了当今大模型的训练范式——今天的大语言模型同样遵循"大规模预训练 + 任务微调/对齐"的路线。

### 5.79 本章小结

本章围绕神经网络这一经典机器学习模型展开，核心脉络可概括为"模型—算法—优化—扩展"四个层次。 在模型层面，神经网络由大量具有适应性的简单单元（M-P 神经元）按层次结构互连而成：神经元对输入加权求和后与阈值比较，再经激活函数产生输出；连接权与阈值构成可学习参数，阶跃函数、sigmoid 函数等激活函数赋予网络非线性表示能力。单层感知机只能解决线性可分问题，XOR 反例揭示了其本质局限；引入隐层的多层前馈网络凭借通用近似定理，在理论上能以任意精度逼近任意连续函数，但隐层神经元个数需靠试错法确定。 在算法层面，误差逆传播（BP）是训练多层网络的核心算法：前向传播计算输出，反向传播将误差逐层回传，按 Δw = −η·∂E/∂w 的梯度下降规则与链式法则更新各层连接权与阈值；输出层梯度项 gⱼ = ŷⱼᵏ(1−ŷⱼᵏ)(yⱼᵏ−ŷⱼᵏ) 与隐层梯度项 eₕ = bₕ(1−bₕ)Σⱼ wₕⱼ gⱼ 的递推结构正是"误差逆传播"的本质。训练中需通过早停与正则化（权值衰减）防控过拟合。 在优化层面，误差函数在参数空间中多峰，梯度下降易陷入局部最小；多初始点、模拟退火、随机梯度下降、遗传算法等启发式策略可用于尝试跳出局部最小，但缺乏理论保障，实践中以求得"够好"的近似解为目标。 在扩展层面，RBF、ART、SOM、级联相关、Elman、Boltzmann 等网络各具特色，分别适用于函数逼近、增量聚类、拓扑映射、结构自适应、时序建模与能量模型等场景；深度学习以多层非线性变换逐层抽象特征，CNN 的卷积、池化与权共享设计，以及预训练—微调、ReLU、Dropout、批归一化、残差连接等技术，使深度模型成为当代大模型与智能系统的基础。

### 5.80 辨证神经网络的定位

在 tcmP（岐黄智医）平台中，本章神经网络层级对应"端到端辨证引擎"：输入四诊文本（望闻问切的自然语言描述），直接输出证型与方剂建议，跳过人工特征工程——这与神经网络"输入—隐层抽象—输出"的端到端学习一脉相承。平台将大模型 DeepSeek 作为该层级的底座：它像深度隐层一样自动提取四诊语言中的语义特征，无须人工设计"舌红苔黄→热证"之类的显式规则，体现了本章"表示学习"的思想。但神经网络可解释性弱是客观短板（黑箱问题），因此平台实行双轨制：NN/大模型输出与可解释基线（逻辑回归、决策树、规则引擎）并行计算，两者结果交叉校验，偏差超过阈值时自动转人工辨证或送审。门控逻辑可类比本章"置信度输出"的思想：DeepSeek 给出证型概率分布后，平台取其 argmax 作为候选结论，同时保留完整分布供门控与人工复核使用，避免"只给结论、不给把握"的黑箱式输出。例如输入"咳嗽痰黄、咽痛、舌红苔黄"，DeepSeek 输出"风热犯肺证 置信度 0.83"，基线输出"风热犯肺证"，两者一致则放行；若基线输出"痰热壅肺证"且与 NN 冲突，则触发复核流程。与神经网络黑箱相对，平台要求每次辨证输出附置信度与溯源链（条文/病证单元库编码），形成可审计的端到端链路。审稿口径（0映射2 学术审稿人、0映射3 刘仁权智能审稿人）要求：辨证结论必须可溯源到经典条文或病证单元库（BZU）编码，凡无法溯源的输出一律标注「现代认识，不改经典原义」，确保中医本体红线不被统计模型侵蚀；统计性规律一律标注「统计来源，送 tcmreviewer 审稿」，真实临床仅作辅助参考、不参与决策（AI 边界口径）。

### 5.82 BP/梯度下降在 Agent 调优中的隐喻

把本章 BP/梯度下降的思想搬到 Agent 工程，就得到"行为反向传播"隐喻：Hermes Agent 的"网络"是提示词与 SKILL.md 中定义的规则，每次执行相当于前向传播——按规则处理输入产生输出；审稿反馈（tcmreviewer 审稿卡的项）相当于误差信号；反向传播即对照反馈定位产生偏差的规则条款；修正规则即梯度更新，幅度对应学习率 η：Δ规则 = −η × 偏差 × 责任定位，其中"偏差"可量化为审稿问题条数或严重度加权分，"责任定位"即问题条款的归属。实践要点：其一，学习率控制——修订幅度过大（η 过大）会破坏原本正确的行为，应小步迭代、每次只改最小必要条款，对应 BP 中学习率过大会震荡的教训；其二，早停类比——连续多轮审稿无即停止调优，避免过度优化（过拟合于审稿卡样本），与本章早停策略同构；其三，回滚机制——修订后回归测试变差则回滚，等价于检测到"梯度上升"（误差不降反升），即验证集误差上升即停；其四，累积更新类比——可批量收集多轮审稿问题后统一修订（累积 BP），比逐条即时修订更平稳，对应累积误差最小化；其五，多 Profile 协同——不同 Profile 持有不同 SKILL.md，如同多组随机初始化，择优保留最优行为版本，对应本章跳出局部最小的多初始点策略；其六，正则化类比——对规则条数设置上限、要求最小必要修改，防止行为模型过拟合到单一审稿样例。其七，随机梯度与批量梯度节奏类比——Kanban 队列中的任务逐条驱动 Agent 执行（随机梯度式即时反馈），而定期评审会汇总一批问题统一修订（批量梯度式平稳更新），两种节奏在平台中交替使用。举例：若审稿卡连续指出"方剂剂量表述不规范"（误差信号），则定位到 SKILL.md 方剂输出条款（责任定位），按小步幅补充剂量规范说明（梯度更新），并回归测试确认未影响其他证型输出。

### 5.83 深度学习-大模型+RAG 锚定知识库

平台不重训大模型（成本与算力约束），而是采用 RAG（检索增强生成）让大模型输出锚定权威知识库。具体地，将 ICD-11 术语库（病码/证码统一命名）、病证单元库（BZU，病×证→法→方→药推理链）与教材条文向量化后存入向量库；DeepSeek 生成辨证解释时先检索相关条文与单元，再基于检索结果作答，形成"大模型负责表示、知识库负责溯源"的分工——这正是本章"深度学习=表示学习"的平台化体现：语义表示能力交给深度模型，领域正确性交给可验证的知识库，类比 CNN 中"卷积层提特征、全连接层做决策"的分层协作。检索采用 FTS5 全文检索与向量检索的混合策略：关键词精确命中（如"桂枝汤"）走 FTS5，语义相近表达（如"盗汗""寐差"）走向量检索，两者结果按相关度融合排序，兼顾召回与精度；向量模型选用针对中文优化的 embedding 模型（如 bge 系列，此为现代认识，送 tcmreviewer 审稿），维度与距离度量（余弦相似度）在配置中统一声明。向量化与微调任务由 2 台 A800 GPU 机承载；知识库经 tcmp-icd11-rag 管线定期从 ICD-11 API 同步并做 DSU 矫正（疾病/证候命名统一）。检索结果为空时的处理策略与本章"训练误差不达标不停止"同理：宁可返回"证据不足"也不强行生成，该策略已写入 Agent 提示词边界条款。边界口径：检索不到的证候明确返回"知识库无覆盖"，不臆造条文，宁缺毋滥——对应本章"神经网络不编造、只拟合数据分布"的求真精神，也守住中医知识不越权生成的红线。

### 5.84 落地实践-质检送审

辨证模型上线遵循平台质检流程，与本章训练思想一一对应。其一，置信度门控——模型输出证型概率分布，当最高概率低于阈值（如 0.6）时，视为低质量输出，转人工辨证或回退到可解释基线（规则引擎/决策树），避免低置信度结果直达用户，等价于 BP 训练中"误差不达标不停止"的质量约束；门控阈值在 BZU 基准集上校准：取使"误放行率"与"误转人工率"平衡的分位点，并支持按证型细分阈值（高频证型可放宽、危急证型从严）。其二，低质输出回退机制——大模型输出被 RAG 溯源校验判为"无依据"或与可解释基线显著冲突时，自动降级为基线的输出并附说明，防止黑箱错误扩散，对应本章早停中"验证集误差上升即停"的保守策略。其三，统计来源标注——NN 学到的规律属统计相关而非中医理论，教材与平台输出中一律标注「现代认识/统计来源，送 tcmreviewer 审稿」，真实临床仅作辅助参考、不参与决策（安全红线，AI 边界口径）。其四，回归测试——在 BZU 基准集上每轮迭代评估准确率（证型一致率）与溯源率（结论命中 BZU/条文编码的比例），防止知识库更新或提示词修订造成行为漂移，对应本章用验证集监控过拟合的实践。其五，审稿闭环——辨证结论与条文溯源结果定期抽样送 tcmreviewer 与 aireviewer 双审，问题回灌 Agent 调优循环（见 P2.3 隐喻）。门控与双审即训练质量的约束项（正则化类比），门控与回退的每次触发均记录审计日志（含模型版本、置信度、回退原因与人工处理结果），便于事后复盘与送审取证。上述措施共同形成"训练—质检—送审—再训练"的闭环，确保平台辨证质量随迭代持续提升且始终可审计。
