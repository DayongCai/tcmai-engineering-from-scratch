# 学到的表征，未必是你想要的那个 · 提示词

## 用途

给「学到的表征，未必是你想要的那个」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「编码器该分还是该合 → 对比学习：正对从哪来 → 小样本的正则：三种可用的手段 → 捷径学习：三类最常见的泄漏」这条链。

## 边界

本章为多模态表征学习的教学讨论，不构成诊断模型的设计规范或性能承诺；具体操作以现行规范与所在机构制度为准。
