# 特征是压缩，压缩必须留下判据 · 提示词

## 用途

给「特征是压缩，压缩必须留下判据」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「手工特征有三种语法 → 降维：三种方法回答三个不同问题 → 尺度不齐：三个必须处理的差异 → 特征库：定义、版本、可复算」这条链。

## 提示词

```
我在学《中医多模态数据融合》第 4 章「特征是压缩，压缩必须留下判据」，本章 6 节 / 2,734 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 它可以被审计
   - PCA 问：数据在哪个方向上变化最大？
   - PLS 问：哪个方向同时让 X 的变化与 Y 的变化最大？

4. 本章自陈的边界（不得越过）：

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为多模态特征工程与降维方法的教学讨论，不构成任何疾病的诊断依据；具体操作以现行规范与所在机构制度为准。
