# 第 7 章 · 聚类出来的亚型，先问它稳不稳

> **MOTTO:** 「草木畴生，禽兽群焉，物各从其类也。」——《荀子·劝学》
>
> **PROBLEM:** 300 例、4 模态，k = 3 跑 100 次 bootstrap 重抽样，调整兰德指数（ARI）的中位数是 0.41。换一个随机种子，某一类的规模从 62 例变成 31 例。也就是说：**同一批数据、同一个算法，讲出了两个不同的分型故事。** 而这样的结果写进论文，读者无法判断它描述的是数据的结构，还是初始化时的一次偶然。

**双根因定位:** 环境逼迫（证候没有金标准，无法用准确率验证分型是否正确；样本量小、模态多，距离度量本身就不稳定）+ 知识积累（无监督结果的可用性由三件事决定：稳定性、可重复性、与临床变量的可解释映射；三者缺一，分型就只能当探索性描述，不能当结论）

## 一、为什么要在多模态上做无监督

中医的证候分类本就来自「聚类」：医者观察大量病人，把共现的症状、舌脉归成若干证型。这套体系没有病理金标准，只有共识与疗效反馈。所以从数据里找亚型，在方法论上与中医的传统路径是同构的——这也是它诱人的地方。

但同构不等于同效。医者的归类有理论约束（阴阳、表里、寒热、虚实），数据的聚类没有；没有约束时，任何高维数据都能被切成看似合理的几团。所以多模态聚类的第一件事不是选算法，而是**明确约束从哪来**：

| 约束来源 | 形式 | 作用 |
|---|---|---|
| 理论框架 | 八纲作为主轴，聚类前先投影 | 让亚型落在可解释的维度上 |
| 特征选择 | 只用与判读相关的特征 | 减少噪声维度主导距离 |
| 临床变量 | 年龄、病程、疗效作为外部校验 | 判断亚型是否有意义 |
| 专家标注 | 少量专家分型作为锚点 | 半监督，校准聚类 |

第四条最有效，也最少被做。哪怕只有 30 例专家标注，也能把「聚类是否落在临床可解释的空间里」变成一个可检验的问题。

## 二、多模态聚类：先融合相似度，还是先各自聚类

两种基本路线，差别很大。

**路线 A：先融合特征，再聚类。** 把各模态特征拼接（或经 CCA 投影）成一个向量，跑 K-means / 高斯混合。简单，但受尺度与维度影响大，且要求所有样本模态齐备。

**路线 B：先各自算相似度，再融合相似度。** 每一路单独算样本间距离矩阵，再把这些矩阵融合成一个，最后在融合矩阵上聚类。代表方法是相似度网络融合（SNF）：

$$W^{(m)}_{ij}=\exp\left(-\frac{\|x_i^{(m)}-x_j^{(m)}\|^2}{\mu\,\varepsilon_{ij}}\right)$$

其中 $\varepsilon_{ij}$ 是局部尺度参数，$\mu$ 控制核宽。得到各路 $W^{(m)}$ 后，用「沿最强邻居的随机游走」反复迭代融合，使共同强的边增强、只在单模态强的边衰减。

SNF 的三个好处：不需要对齐维度、天然处理缺失（缺一路就用其余路融合）、对尺度不敏感。代价是它对局部尺度参数敏感，且融合后的矩阵不再对应任何原始特征，解释要靠事后回溯。

演算设定一组对比：

| 方法 | ARI（bootstrap 中位） | 类别规模（3 次运行） | 与专家分型的吻合 |
|---|---|---|---|
| 拼接 + K-means | 0.28 | 41 / 62 / 31 | κ = 0.21 |
| 各路 PCA 后拼接 + 高斯混合 | 0.35 | 55 / 48 / 47 | κ = 0.29 |
| SNF + 谱聚类 | 0.47 | 58 / 61 / 61 | κ = 0.38 |
| SNF + 谱聚类 + 理论轴投影 | 0.52 | 60 / 59 / 61 | κ = 0.44 |

第四行说明：**加约束比换算法有效**。把八纲的两个主轴（寒热、虚实）先投影出来再做聚类，稳定性提升明显——因为约束去掉了一部分与判读无关的变异方向。

## 三、k 选几个：三条互相独立的证据

轮廓系数、肘部法、间隙统计量，三条经常给出不同答案。原因不是算法错，而是它们问的问题不同：

- **轮廓系数**问：簇内紧、簇间远吗？它偏好球状簇，对长条或不规则形状不敏感。
- **肘部法**问：增加一个簇，能解释多少额外方差？它偏好方差结构，对密度不均敏感。
- **间隙统计量**问：比在随机数据上聚类好多少？它回答「有没有结构」，不回答「有几个」。

多模态场景下，还要加第四条证据：**临床可解释性**。若 k = 4 时多出来的那一类，在舌脉上找不到共同特征，只在某个设备的信号上一致，那这一类很可能是设备伪影。

实践做法是**并用 + 报冲突**。若三条数值证据都指向 k = 3，而临床认为 k = 5，报告应同时给出，并说明差异在哪（通常是某些小类被合并）。强行选一个数，等于隐藏了结构的不确定性。

## 四、稳定性：唯一能反驳自己的指标

聚类没有金标准，所以「对不对」无法直接回答；能回答的是「稳不稳」。三条检验：

**重抽样稳定性**。Bootstrap 重采样本，重跑聚类，用 ARI 比较两次分区的相似度。演算设定：ARI 中位数 < 0.5 视为不稳定，< 0.3 视为不可用。100 次重抽样是最低要求，500 次更好。

**扰动稳定性**。对特征加小噪声、删掉一个模态、换一种距离度量，看分区是否保持。多模态尤其要做「删模态」这一项——真实门诊里模态是随机缺的，若删掉一路后分型完全变样，这个分型在门诊就不可用。

**留一稳定性**。逐个删除样本，看每个样本的归属是否改变。归属频繁翻转的样本是「边界样本」，应当被标出来，而不是硬分到某一类。

三项检验的结果应作为分型报告的必备内容。缺了它们，任何「发现三个亚型」的说法都只是描述一次运行的结果。

## 五、与证候的关系：映射，不是验证

一个常见的表述错误：把聚类结果与证候比对，吻合度高就说「验证了证候的客观性」。这句话在方法上站不住。

聚类与证候的关系是**映射**，不是验证：

- 聚类得到的是数据空间的分区，证候是理论空间的分区。
- 两者的吻合度（如 κ 系数）衡量的是两个分区的一致性，不证明任何一方「正确」。
- 吻合度高，可能因为两者都受同一批混杂因素影响（年龄、病程、就诊季节）。

正确写法是：「在 300 例样本上，k = 3 的分型与专家证候判读的 κ 为 0.44，提示二者存在中等程度对应；该结果不构成对证候客观性的验证。」

更进一步，可以做**外部效度检验**：不同亚型在疗效、转归、用药反应上是否有差异。这是唯一能说明「分型有用」的证据，也是分型研究的真正目的。若三个亚型在六个月随访里毫无差异，那么它们只是三种数据形态，不是三种临床状态。

## 六、距离度量：混合数据的麻烦

多模态聚类最技术性的一步是「样本之间怎么算距离」。四路数据的类型不同：图像特征是连续向量，脉图是时序，问诊里既有连续量（病程月数）又有名义量（舌苔颜色类别）。

| 数据类型 | 常用距离 | 陷阱 |
|---|---|---|
| 连续、同尺度 | 欧氏 | 未标准化时被大方差维主导 |
| 连续、不同尺度 | 马氏 / 标准化欧氏 | 协方差需估，小样本估不准 |
| 名义量 | 简单匹配系数 | 类别间的「距离」被当成等距 |
| 混合 | Gower 距离 | 各分量权重默认相等，需人工调 |
| 时序 | DTW | 对噪声敏感，且不满足三角不等式 |

Gower 距离的做法是把每个分量归一化到 [0,1] 后加权平均：连续量用 $|x_i-x_j|/\text{range}$，名义量用 0/1，缺失分量在分母里剔除。它的好处是天然处理混合类型与缺失，坏处是**默认等权**——一个 40 维的图像特征块会压过 3 个问诊项。

所以权重必须显式设定，且要报告。一个可行的设定逻辑是「按模态的判别贡献分配」：先用单模态各自做一个弱监督任务（比如区分寒热），看每种模态能解释多少，再按此比例定权重。这比拍脑袋等权要好，也比从聚类结果反推权重（那是循环论证）要诚实。

还有一个常被忽略的点：**距离度量决定了簇的形状**。欧氏距离假设簇是球状的；若数据在某个方向上被拉长（比如病程与年龄强相关），球状假设会把一个簇切成两个。此时要么先做白化（去除相关性），要么换成密度型方法（DBSCAN 一类）。但密度型方法对参数更敏感，小样本下往往不如 K-means 稳。这个取舍没有普适答案，只能靠稳定性检验说话。

## 代价与边界

- 本章所有数值（300 例、k = 3、ARI 0.41/0.28/0.35/0.47/0.52、类别规模 62/31、κ 0.21–0.44、稳定性阈值 0.5/0.3）均为**演算设定**，用于说明稳定性检验的必要性与方法差异，不对应任何实测聚类实验。
- ARI 与 κ 的阈值是经验性的，不同领域差异很大；本章给的是「需要报告」而非「必须达到」的门槛。
- SNF 等方法对超参数（局部尺度、迭代次数）敏感，本章未给出调参流程；实际使用须做敏感性分析。
- 本章不主张任何具体的证候分型方案，也不评价任何已发表的亚型研究；分型结果不得直接用于临床决策。

**免责声明：** 本章为无监督分型与聚类稳定性的方法学讨论，不构成证候分类标准或临床分型建议；任何分型结论须经独立样本复核与临床效度检验。
