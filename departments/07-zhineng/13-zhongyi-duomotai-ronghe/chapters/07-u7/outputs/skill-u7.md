# 聚类出来的亚型，先问它稳不稳

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 明确约束从哪来
- 路线 A：先融合特征，再聚类
- 路线 B：先各自算相似度，再融合相似度
- 加约束比换算法有效
- 临床可解释性
- 并用 + 报冲突

## 边界

- 本章所有数值（300 例、k = 3、ARI 0.41/0.28/0.35/0.47/0.52、类别规模 62/31、κ 0.21–0.44、稳定性阈值 0.5/0.3）均为**演算设定**，用于说明稳定性检验的必要性与方法差异，不对应任何实测聚类实验。
- ARI 与 κ 的阈值是经验性的，不同领域差异很大；本章给的是「需要报告」而非「必须达到」的门槛。
- SNF 等方法对超参数（局部尺度、迭代次数）敏感，本章未给出调参流程；实际使用须做敏感性分析。
- 本章为无监督分型与聚类稳定性的方法学讨论，不构成证候分类标准或临床分型建议。
