# 第 3 章 · 六类边撑起半张中医图，但两套坐标系不能合并

> **MOTTO:** 「气有余，则制己所胜而侮所不胜；其不足，则己所不胜侮而乘之，己所胜轻而侮之。」——《素问·五运行大论》
>
> **PROBLEM:** 五行只有五个节点，相生相克十条边，图小得可以画在纸上。但《素问》这段话里还藏着乘与侮：气有余则「侮所不胜」，不足则「所不胜侮而乘之」。若把乘侮当成新边型，五个节点要长出四十条边，且每条边的成立条件都不同；若不建，模型就永远只会说「相克」，说不出「反被克」。

**双根因定位:** 环境逼迫（临床要判的是失衡往哪传，而失衡不是一条边，是原有边权的反常） + 知识积累（生克十条边是常量，乘侮是变量——只有把常量与变量分开，图才既有骨架又能推演）

## 一、五行：不是十个箭头，是一张带符号的有向图

先算清常量。五行相生五对（木生火、火生土、土生金、金生水、水生木），相克五对（木克土、土克水、水克火、火克金、金克木），合计十条边，构成一个五节点的有向环套环结构：生是一个外环，克是一个内五角星。

把生写成激励边、克写成抑制边，这张图就有了符号。符号让「传播」可算：任取一个节点受到扰动，沿正边传出增益，沿负边传出衰减，两圈之后回到起点，净效应就是这套模型对该脏器的判断。这就是「五行生克」能算的道理——它是一个**带符号的有向环**，不是修辞。

关键在于乘侮怎么进图。三条备选做法，各有代价：

| 做法 | 边数 | 能表达什么 | 代价 |
|---|--:|---|---|
| 单独立边（`乘`、`侮` 各建一类） | 涨到 40+ | 直接读出「木乘土」 | 边的成立条件（太过/不及）无处安放，且与相克重复 |
| 换成新节点（「太过」「不及」各建节点） | 节点翻倍 | 状态可命名 | 破坏了「五行只有五个」这个前提 |
| 不建新边，改**边权与方向** | 仍 10 条 | 乘 = 克边权重放大；侮 = 克边反向 | 需在图算法里解释「反向」的语义 |

第三种是可用解。理由是：乘侮在中医理论里本来就不是新的关系种类，而是**同一种关系在特定条件下的强度与方向变化**——「气有余则制己所胜」是克得过头，「所不胜侮而乘之」是被克者反过来欺。所以数据里存的仍是十条生克边，另存两件事：这条边当前的强度（正常 / 太过 / 不及），以及传播时允许反向。失衡的路径由算法追踪（随机游走、消息传递），不预先穷举。

这样处理还有一个额外好处：**同一张图既能答「木克土」，也能答「木乘土」与「土侮木」，而节点数不变。** 如果为每个病机都建一条边，图会膨胀到无法维护，且每条边都要单独论证依据。

## 二、经脉与六经：一个环、六对表里，和一条不能合并的平行线

经脉是比五行更「硬」的结构，因为它的次序是经典写定的。十二经按流注次序首尾相接：

```text
手太阴肺经 → 手阳明大肠经 → 足阳明胃经 → 足太阴脾经
→ 手少阴心经 → 手太阳小肠经 → 足太阳膀胱经 → 足少阴肾经
→ 手厥阴心包经 → 手少阳三焦经 → 足少阳胆经 → 足厥阴肝经 →（回手太阴）
```

这条环正好十二条边，闭合。另有一组关系与它正交：互为表里的六对（肺—大肠、脾—胃、心—小肠、肾—膀胱、心包—三焦、肝—胆）。两类边性质不同，必须分型：

| 边型 | 语义 | 条数 | 是否成环 |
|---|---|--:|---|
| `meridian_liuzhu` | 流注：上一经接下一经 | 12 | 成环（闭环） |
| `meridian_biaoli` | 表里：脏与腑相合 | 6 | 不成环（配对） |

这个结构有个直接用途：**任何沿经的推理都必须能区分「顺着流注走」与「跨表里跳」。** 前者是时间性的（病邪循经传），后者是空间性的（脏病及腑）。混成一类边，就再也说不清一次传变是「传进去」还是「表里相连」。

**六经是另一套坐标。** 六经（太阳、阳明、少阳、太阴、少阴、厥阴）既是辨证纲领，也是传变路径。它和十二经名字上有重叠（都有「太阳」「阳明」），很容易被当成同一套东西，实际上两者平行而不相交：

- **经络**是解剖与通路：手太阴肺经有确定的循行路线、穴位、主治。
- **六经**是证候分类与病程阶段：太阳病说的是「表证阶段的一组脉症」，不是「手太阳小肠经这段」。

一旦合并，最先塌掉的是合病与并病。「太阳阳明合病」说的是两经证候同时出现，在合并后的坐标系里无处安放——因为它既不是太阳，也不是阳明，而是「两个阶段并置」。同理，「直中少阴」（不经三阳直入）在单一线性传变链上也无法表示。

所以做法是分层：六经建六个节点，只建传变顺序边；病证单元若标注了六经归属，另建一条 `bridge` 边把它接回六经主线。于是同一个病证单元可以同时挂着「它在哪条经上」与「它在六经的哪个阶段」，两者互不覆盖。教材口径给出的分布是 103 个病证单元中大部分有六经归属，说明这条桥是常用路径，而不是备用路径。

## 三、病证单元：三条边完成双向锚定

这是整个知识图谱里设计得最巧的一处。一个病证单元（DSU）同时装两侧内容，不可拆分：

| 侧 | 装什么 | 边型 |
|---|---|---|
| 病侧 | 西医病名、ICD-11 编码、分子靶点、流行病学 | `disease_is` |
| 证侧 | 证候名、六经八纲归属、主症舌脉 | `manifests_as` |
| 中缝 | 对应类型、生物学基础、证据等级 | `bridge` |
| 树位 | 归属学科枝 | `hierarchy` |

拿 `DSU-00001` 举例，四条边各有明确落点：证侧是**风寒束表证**（WHO 传统医学术语表 2.5.36，书页 111），病侧对应**急性鼻咽炎**（ICD-11 CA00），树位挂在 D01-S13。四条边一起读，才是一个完整的临床知识单元；少任何一条，它要么是孤立的证名，要么是没归处的病名。

这套设计解决了一个长期问题：中医的「证」与西医的「病」不是一一对应，也不是毫无关系，而是多对多的弱对应。把对应关系单独建成边（而不是塞进一个字段），才能给每条对应标上可信度——也就是下一节要说的证据等级。

## 四、证据等级与双通道编码：把「有多可信」写进边里

病证桥接的严格性差别极大，不能一视同仁。可用的分级是六级：

```text
A 多中心 RCT → B 单中心 RCT → C 队列研究
→ D 病例对照 → E 专家共识 → F 经典理论
```

这条链的关键不是「越高越好」，而是**等级决定用途**：A 级可以支撑「该病该证用该方」的推广性结论；F 级只能支撑「经典如此论述」，不能推及疗效。等级写入边的元数据后，「这条对应关系有多可信」就成了可排序、可过滤的字段，而不是靠读者自己掂量。

编码侧同理，但要更谨慎。ICD-11 的接入有两条通道：在线 API 与本地库。在线通道需要 OAuth2 凭据，无凭据一律 401；本地库里存着上万条 MMS 快照，可以离线查。双通道的纪律是**离线降级必须显式**：平台不可达时，凡依赖编码的结论都要标「未能核实」，而不是退回一个猜的码。

冲突也真实存在。同一个病证单元可能对应多个候选码，或一词多码。可执行的消解顺序是「三查一验」：查在线 API、查本地库、查教材标注；三者不一致时以本地库的 Foundation 标识为准，并把分歧记入审核队列而不是就地抹平。

还有一处必须承认的核对限度。两套独立资料都声称有 103 个病证单元，但数量相同不等于同一批：按编号与证名逐条比对，重叠部分为 13 / 104，编号三元组 1 条逐条吻合，矛盾 0 条。由于其中一份只摘录了部分证名，全量无法核对——所以正确的结论是「编号空间同源，已核对部分无矛盾」，而不是「两套数据完全一致」。这类「证据到哪一步就说到哪一步」的写法，比任何覆盖率数字都重要。

## 五、路径发现：一次跨树跨图的多跳查询

有了这些边，就能回答真正的中医问题。以「恶寒发热、无汗、脉浮紧」为起点：

```text
症状（恶寒、无汗、脉浮紧）
  → 证候「风寒束表证」        manifests_as 反向
  → 六经「太阳病」            bridge
  → 主方「麻黄汤」            方证对应边
  → 归经「手太阴肺经」        meridian 边
```

这条链跨了三种结构：症状到证候是证侧聚合，证候到六经是阶段归属，六经到方是治法落点，方到经是归经。任何单一坐标都走不完——树只能给出「这段知识在哪一章」，图只能给出「谁和谁相连」，只有树图叠在一起，路径才既有位置又有依据。

同一条链也暴露了边界：路径的最后一步（方→归经）在经典里是有争议的，麻黄汤归太阳经还是归肺经，不同教材写法不同。所以路径发现的输出不该是「答案」，而该是「一条带出处的候选链」，由人来决定采信哪一段。
本章可直接验证：`node code/main.js` 打印结构清点与判据清单（数字从 `docs/zh.md` 现算），`node --test code/main.test.js` 跑本章单测；两条命令只读正文与代码，不写任何文件。

## 六、代价与边界

- **乘侮靠边权表达，是有损的。** 它保住了节点数，但丢掉了「太过/不及」这个条件的独立性——同一条被加权的边，无法同时表达「木太过乘土」与「土不及致木乘」两种成因。
- **六经的传变被简化成顺序边。** 循经传、越经传、直中、合病并病，只有前两类能落到顺序边上，其余靠 `bridge` 与人工标注兜住。
- **证据等级是编辑判断，不是计算结果。** 等级由编写者依证据类型指定，本章不给出自动定级的方法；等级写错，桥接的可信度排序就跟着错。
- **103 与 104 的差额未裁定。** 两套资料的数量差一条，已核对部分无矛盾，但不能据此宣布一致。
- 本章所有病证举例只用于说明结构，不构成任何诊断或用药建议。
