# 第 5 章 · 「消渴」「糖尿病」「E11」：三个名字都不算错，但系统只认一个

> **MOTTO:** 「名定而实辨，道行而志通。」——《荀子·正名》
>
> **PROBLEM:** 117 个证候概念，对应 251 种写法——简体 137、繁体 61、英文 53，平均每个概念 2.15 种叫法。反过来，31 个英文形态同时指向多个概念。这不是笔误，是中医术语的常态：同一个证在不同教材、不同语种、不同标准里都有合法写法。任何系统若假定「一个概念一个字符串」，第一天就会开始分裂。

**双根因定位:** 环境逼迫（病历、诊断证明、医保结算、国际分类各用一套口径，同一份记录在三个系统里必须都能对上号） + 知识积累（251 种写法不是噪音，是可比对的材料——把它们按关系归类，才知道哪些能等同、哪些只能作旁证）

## 一、标准化要解决的是三件事，不是一件

「标准化」常被理解成「统一名称」，这只对三分之一。真实需求是三件事，缺一件都通不了：

| 层 | 要统一什么 | 不统一的后果 |
|---|---|---|
| 术语 | 同一概念同一名称 | 检索漏，统计分叉，两个人说的不是一回事 |
| 编码 | 同一概念同一代码 | 上报对不上，医保拒付，跨院数据无法合并 |
| 接口 | 同一代码可交换 | 系统间要写一对一适配，N 个系统 N² 条通道 |

三件事的难度递增。术语统一靠人（编表、定正名），编码统一靠标准（ICD-11、国标分类代码），接口统一靠治理（谁能改、改了谁通知）。教材里最常被跳过的是第三层——因为它不产生任何可见的成果物，只产生「以后不会出问题」。

本章只谈前两层能做到什么程度，以及在哪一步必须停手。

## 二、等价类：一个类绑定一个语义点

术语归一的做法不是建同义词表，而是建**等价类**：每个类绑定恰好一个语义点，类内成员是不同语种或写法下的同一个术语。

这个定义有一处很关键：等价不是「相似」，是「同一个」。相似度取近邻的做法在这里不适用——「肝阳上亢」与「肝火上炎」向量很近，临床却是两个证；取近邻会把它们合并，而合并之后的错误无法被下游发现。

现有等价类的规模：

| 项 | 数 |
|---|--:|
| 等价类 | 117 |
| 类内成员合计 | 251 |
| 其中 简体中文 / 繁体中文 / 英文 | 137 / 61 / 53 |
| 平均每类写法 | 2.15 |
| 含英文成员 | 42 |
| 有 WHO 术语条目 | 41 |
| 有 ICD-11 编码 | 19 |
| 有 TM1 章归属 | 15 |
| 未解（无法归属） | 9 |
| 同名多义（一个形态指多个类） | 31 |

两个数字要一起看：**117 类对应 251 写法，说明归一确实在起作用；但 31 个同名多义，说明「归一」不能靠字符串匹配自动完成。** 比如英文形态 `deficiency liver spleen` 同时指向三个类——因为三个证都有「肝脾两虚」的构词，差别在限定部分。机器看到这三个词就合并，是错的；正确做法是把歧义挂起来，按上下文择一。

等价强度也要分级，因为「同一个」的凭据不一样：

| 强度 | 判据 | 条数 |
|---|---|--:|
| A | 术语表同一条目（简繁英对照、代码与书页可回查） | 239 |
| B | 编码同源（同条目的别名位、官方英文标题） | 8 |
| C | 规范化后逐字相等 | 4 |

A 级占 95% 以上，说明大部分归一是硬凭据支撑的，不是推测。剩下 4% 的 B/C 级必须能被单独筛出来复核——**强度分级的意义不是排序好看，而是让「这一条弱在哪」可查。**

覆盖情况则是一个漏斗，必须一层层说清，否则「已对齐国际标准」这句话会被误读：

```text
117 类
 → 41 类有 WHO 传统医学术语表条目   （35.0%）
 → 19 类有 ICD-11 编码              （16.2%）
 → 15 类落在 TM1 章内               （12.8%）
 → 66 类只有内部探针文本            （对照用，不构成国际对齐）
```

这张表的用处是限制措辞。真正「对得上国际标准」的是一小部分；剩下的大多数只能在内部可比、与教材原文可比，不能说「已与国际分类对齐」。凡把 117 类整体说成「已映射 ICD-11」的表述，都会在第一次跨院数据交换时暴露——那时要赔的是整批数据的可信度。

## 三、四种「不同写法」，不能一律等同

这一节是整章最容易被做错的地方。两个名字不同，可能因为四件完全不同的事：

| 关系 | 含义 | 例 | 证据怎么算 |
|---|---|---|---|
| `synonym` | 同义异名，同一个证的两个通行叫法 | 气虚不摄证 / 气不摄血证 | 可直接计入 |
| `composition` | 复合证名的组成部分，只覆盖一半 | 合称证名中的单个构件 | 部分证据 |
| `qualified` | 病名或部位限定的用法 | 高血压病肝热阳亢证 | 可用，但须保留限定语境 |
| `broader` | 上位（更宽的证候名） | 泛指某类证的统称 | 只能作旁证 |

四类混成一类，后果是证据虚高：把 `broader` 当同义词，等于用「气虚证」去证明「肺气虚证」有文献依据，覆盖数会凭空翻倍。所以别名表的门禁写得很硬：**每条别名必须在来源里字面出现，且来源已登记；别名只从真实取回的材料里采集，不凭记忆写同义词。**

效果是可数的。对 97 条证名的文献核对结果是：

```text
specific          75   （证名字面命中；其中 1 条靠同义异名命中）
partial            3   （只命中非同一概念的异名）
variantUnconfirmed 11  （正文出现未登记的近名写法，待人工确认）
generic            8   （连近名都没有，是泛论）
```

这组数的读法比总数重要：75 条是硬命中（其中 1 条靠同义异名命中），占 77.3%；3 条只命中非同一概念的异名，只能作旁证；11 条 `variantUnconfirmed` 是「看起来像但不敢判」的部分，工具不擅自判同义，交人工；8 条 `generic` 说明该证名在语料里根本没有针对性论述——这条信息本身就有价值，它告诉你哪些证在教材层面是「有名字、无内容」的。

**合称还要再切一刀。** 中医证名常是合称：「肺经风热、湿热上蒸证（鼻渊/鼻鼽）」。这样一个名字里其实有两条证、一个病名限定。要往标准表里对齐，必须先切。

规则有四条，都写进了处理口径：

1. 按顿号与斜杠切分，**括注不参与**——括注是解释位，不是术语本体。
2. 切完取**首构件**为主构件。
3. 主构件在国家证名表里有标准证的，取该正名；表里只是别名的，取它对应的正名并写明来源。
4. 合称本身不给正名：`wholeStandardName` 恒为空。

第 4 条不是偷懒，是核对结果。全部合称逐条查国家证名表，**一条都没有整条正名**——也就是说，合称是文献与教材的写法，不是标准的写法。承认这一点，才不会造出一个「看起来像标准」的伪正名。

被丢弃的构件也要逐个标状态：在表内有独立证名的标 `standard`，0 命中的标 `nonstandard`（属「文献无证名」）。代码只在「表内同一行代码与证名相邻」时写，否则留空。**不推测、不补全**——这条纪律比任何补全算法都重要，因为一个猜出来的码会一路传到病历和结算单上。

## 四、双层映射：国际一套，国内一套

对外与对内用的是两套标准，二者不是替代关系：

- **国际**：ICD-11 第 26 章为传统医学单设章节（TM1），使中医病证第一次进入国际分类体系。接入靠双通道——在线 API 需 OAuth2 凭据，无凭据一律 401；本地库存有上万条 MMS 快照，可离线查。
- **国内**：以中医病证分类与代码为代表，与 ICD-11 形成「国内—国际」双层映射。标准编号与版本必须以标委会最新发布为准，不确定的一律标「待核」。

双通道的工程后果必须写进教材：**离线降级是常态，不是异常。** 平台不可达时，凡依赖编码的结论都标「未能核实」，而不是退回上一个缓存值——缓存值看起来能用，但它可能已经过期，而过期的码比没有码更危险。

版本漂移是这条线上最难的部分。分类标准会改版（名称调整、码位细分、条目合并），而已经入过库的数据不会自动跟着改。可执行的策略只有两条：一是记录每条映射所依据的标准版本，二是改版时以版本为单位重跑映射并输出差异清单，而不是逐条手改。前者让「这条码基于哪版」可查，后者让改动有据。

## 五、标准落到代码里才算数

一句话总结这一章的方法论：**标准不是文档，是枚举与校验。**

- 证据等级写成 A–F 六级枚举，越界即报错；六经写成七值枚举，不在枚举内的「合病/过渡」变体必须显式登记，不能被悄悄塞进某个值。
- 数据元的设计同理：名称、定义、类型、值域、示例五项齐全才算一个数据元。中医数据元的特殊处在于**值域常是枚举而非数值**——舌质、舌苔、脉象都不是连续量，硬套数值型只会造出一堆假精度。
- 值域显式化的收益是可以做一致性校验：同一份材料里出现「I 级」与「E 级」混用，枚举一跑就能发现，人工审读几乎必漏。

## 六、代价与边界

- **9 条未解 + 31 条同名多义是已知的洞，不是待修的 bug。** 它们被显式记录而非强行归类；强行归类的代价是把错误固化进下游。
- **117 类不是中医证候的全集。** 它只是当前语料与标准表能支撑的部分；覆盖不到的概念既不能声称「没有」，也不能凭构造补进去。
- **对齐不等于证据。** 把合称对齐到国标正名，只是让「要引用哪个名字」有答案，不构成该证存在或该方有效的证据。
- **编码结论可能随时失效。** 在线通道需凭据、本地库是快照，两者都可能落后于最新版标准。
- 本章讨论术语与编码治理，不构成任何诊疗建议；证名的实际使用以现行标准与执业判断为准。

**免责声明：** 本章为标准与信息治理讨论，不构成诊断、辨证或治疗建议；编码引用须以官方最新发布版本为准。
