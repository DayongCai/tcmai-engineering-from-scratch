# 中医知识图谱 缺口登记

## 一、底本强度不足（最重要）

| 项 | 实测 |
|---|---|
| 教材正文 | **6,693 汉字**（6 章，约 1115 字/章） |
| 课程正文 | 26,103 非空白字 |
| 原文占比 | **约 26%** |

教材是**提纲**：`节` 与 `正文` 行合计只有数千字，另有 `表格`/`代码` 行未入正文。
本课按骨架补判据与边界，**不能当作教材全文替代**。

## 二、无插图

教材无图，本课未加图注层——底本过薄时加图注只是灌水（同批的 05 中医知识图谱即因此撤掉图注层）。

## 三、表格与代码未入正文

教材 `表格` 与 `代码` 行留在底本 `units.json` 的原始行中，可按 locator 回查。

## 四、不做的事

1. 不写真实患者数据与方药剂量；
2. 不写平台版本与语法；
3. 不把设计当成果。

## 六、补源约定：26 个单元来自《中医信息学》（已标注）

本课底本《中医知识树》仅 4,542 字，而课程契约要求章节数 6–60、章门要求每章 ≥1,000 字——两条同时成立需 ≥6,000 字。
缺的约 1,500 字按「同域补源」取自《中医信息学》第 15–22 章（标准化、数据元、数据库、检索、关联规则）：

| 项 | 值 |
|---|---|
| 补入单元 | **26 个 / 1,505 汉字** |
| locator 写法 | `补充·中医信息学·原第N章·M.K`（与底本 `教材·第N章` 明确区分） |
| source 字段 | `中医信息学:原 locator`；单元标题后缀「（补充）」 |
| 统计口径 | **底本 4,542 字与补源 1,505 字分列，不合并** |

补源单元在正文里保留原书表述，**不改字**；本课的三辨/四位面读数含补源部分，已在此声明。
