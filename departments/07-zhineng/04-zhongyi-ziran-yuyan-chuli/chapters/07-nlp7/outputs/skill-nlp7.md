# 抽到「麻黄」，不等于抽到「麻黄汤去麻黄」

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 方与药的嵌套
- 程度与判断的耦合
- 不标语气的关系抽取，在有「反」「若」「不可与」的条文上会给出相反的建议
- 单位换不换算
- 只存原文数值与单位，不做换算入库
- 炮制算不算实体的一部分

## 边界

- 底本第 7 章 1,093 汉字、13 个单元，全部是关系建模而无抽取方法；**本章的抽取判据是按骨架补的，不引教材原文为依据**。
- 语气强度表（主之／宜／可与／属／反）是本章提出的判据，未在语料上做覆盖统计；实际建表须逐条核《伤寒论》《金匮要略》原文，本章只给分类框架。
- 剂量换算的立场（不入库）是本仓的工程约定，不代表学界共识；若下游确需换算，须另立换算表并标所据。
