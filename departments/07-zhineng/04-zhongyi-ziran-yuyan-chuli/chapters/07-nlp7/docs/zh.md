# 第 7 章 · 抽到「麻黄」，不等于抽到「麻黄汤去麻黄」

> **MOTTO:** 「主病之谓君，佐君之谓臣，应臣之谓使。」——《素问·至真要大论》
>
> **PROBLEM:** 底本第 7 章只有 13 个单元、1,093 汉字，是全书字数最少的一章，而这 13 个单元讲的是病证单元（DSU）、五行生克建模、十二经脉流注、方证对应——全部是**关系**的建模，没有一节讲「怎么从文本里把这些关系和实体抽出来」。也就是说，本章要讲的东西，底本一个字都没有。既然如此，本章只能做一件事：把六类实体与五种关系的边界麻烦逐条摊开，说明哪些能抽、抽到什么程度、抽错了会怎样。

**双根因定位:** 环境逼迫（中医实体的构词法本身是嵌套与复合的：方名由药名构成，证名由症名构成，一条文本里同一串字可能属于两层实体） + 知识积累（关系不是二元的：方证之间有「主之」「宜」「可与」三档语气，中医文本用虚词承载证据强度，而标准三元组没有这一维）

## 一、六类实体，六种麻烦

| 类 | 正例 | 麻烦从哪来 |
|---|---|---|
| 药 | 麻黄、炙甘草、麻黄（去节） | 一药多名（薯蓣／山药）、炮制改变药性、生炙之分 |
| 方 | 麻黄汤、桂枝加芍药汤、三拗汤 | 同源异名、加减方、方名含药名 |
| 证 | 太阳伤寒证、风寒表实证 | 同证异名、证与症一字之差 |
| 症 | 恶寒、无汗、但欲寐 | 程度修饰、否定、与体征混称 |
| 脉 | 脉浮、浮脉、寸浮 | 部位与脉象是否分列、单字脉名 |
| 穴 | 足三里、三里、阿是穴 | 简称歧义（手三里／足三里）、经外奇穴无归经 |

六类里最难的是**方与药的嵌套**，最简单的是**穴**——穴名有国家标准，别名有限，边界清楚。这个差别决定了工程投入的分配：穴位抽取可以直接用词典，方剂抽取必须处理构词。

方名的构词规律大致三类：药名加剂型（麻黄汤、桂枝散）、药名加加减（桂枝加芍药汤、麻黄汤去麻黄）、纯比喻命名（青龙、白虎、真武、四君子、三拗）。前两类可以靠「药名表 + 剂型后缀」规则生成候选，第三类只能靠词表——「青龙汤」里的「青龙」不是药，规则推不出来。

这条差别还有一个副作用：用规则生成的方名候选会**过度生成**。「桂枝加葛根汤」是真的，「桂枝加桂汤」也是真的，但「桂枝加大黄汤」是真方而「桂枝加芒硝汤」不是——同一条构词规则生成的两个候选，一个是方，一个不是。所以规则只能产候选，入表必须人核。

## 二、否定、程度、时态：修饰语不是噪声

「恶寒」「微恶寒」「不恶寒」「恶寒已罢」——四个短语，一个实体，四种临床含义。抽取器若只标「恶寒」，四条记录就变成同一条，而这四条在辨证上完全不等价。

最朴素的做法是窗口法：实体前若干字内出现否定词，就标为否定。窗口法在中医文本上有两个明确的失效点。

第一个是作用域越界。「不恶寒，反恶热」——「不」只否定「恶寒」，而「恶热」是肯定的。窗口法会把「恶热」一并否掉，得到「不恶热」这个相反的意思。修法要看并列结构：「反」「而」「但」这类转折连词往往标出否定作用域的右界。

第二个是否定词的歧义。「无汗」里的「无」不是否定「汗」这个症，而是构成「无汗」这个独立的症。判据不在语法，在术语表：「无汗」若在症名表里，就整体标为症；若不在，才走否定规则。这条规则把语言学问题转成了词表问题，是可操作的——但它要求词表先于规则，而不是反过来。

程度修饰相对好办：「微」「甚」「大」「稍」这几个字，标成 `degree` 属性即可。真正麻烦的是**程度与判断的耦合**：「微恶寒」在表虚证里是典型见证，在里热证里可能是假象。抽取器只负责记录「微」，判断留给人。

时态与病程也常被漏掉：「已罢」「未解」「渐退」「复作」。这些词不改变实体，但改变实体在时间轴上的位置。一条「恶寒已罢」被抽成「恶寒」，等于把已消失的症状当成现症——这在自动生成病案摘要时是硬错误。

## 三、五种关系，以及语气承载的强度

关系抽取的常规做法是三元组：`(主语, 谓语, 宾语)`。中医文本里最常见的五种关系：

- **组成**：方—药，带剂量与炮制。「麻黄汤方：麻黄三两（去节）、桂枝二两（去皮）……」
- **主治**：方—证。「太阳病，头痛发热，汗出恶风，桂枝汤主之。」
- **归经**：药—经。「麻黄，入手太阴、足太阳经。」
- **定位**：穴—经。「足三里，足阳明胃经。」
- **传变**：证—证。「太阳病……若发汗已，身灼热者，名风温。」

前四种是静态关系，第五种是动态关系（带方向、带条件）。五种关系都可以写成三元组，但都会丢掉同一样东西：**强度**。

强度写在语气里。「桂枝汤主之」——「主之」是最强的一档，意思是这个方就是本证的主方。「宜桂枝汤」——次一档，合适但不唯一。「可与桂枝汤」——再次一档，可以考虑。「属桂枝汤证」——是归类，不是处方。四句话在文本上都是「方—证」关系，在临床上分量完全不同。

| 语气 | 强度 | 例 | 能否作等价关系 |
|---|---|---|---|
| 主之 | 最强，主方 | 桂枝汤主之 | 可，作「主治」 |
| 宜 | 较强，推荐 | 宜桂枝汤 | 可，需标 `strength=recommend` |
| 可与 | 弱，许可 | 可与桂枝汤 | 否，只能作「候选」 |
| 属 | 归类 | 属桂枝汤证 | 否，是证属而非方治 |
| 反 | 反向 | 反与桂枝汤 | 否，是误治警示 |

这张表是本章最实用的一条：**不标语气的关系抽取，在有「反」「若」「不可与」的条文上会给出相反的建议**。「反与桂枝汤，欲攻其表」是一条警示，抽成「桂枝汤主治」就是把人往错的方向推。所以关系边的属性里必须有 `modality`，且默认值不能是「主治」——没有语气词的，默认是「未知」，不是「主治」。

这带来一个反直觉的推论：语气词的价值在**否定与警示**上比在肯定上更高。「主之」的条文即使抽漏，通常还有别处重复，因为主方在书里会被反复提到；而「不可与」「反与」「若……者，死」这类条文往往只出现一次，抽漏了就永远学不到。所以关系抽取的召回率评估应当按语气分层——只在「主之」上算召回，会系统性高估系统的安全性。

## 四、剂量与炮制：结构化到哪一层为止

「麻黄三两（去节）」这六个字，可以结构化成：

```json
{"herb": "麻黄", "amount": 3, "unit": "两", "proc": "去节", "raw": "麻黄三两（去节）"}
```

三个决定要提前定。

**单位换不换算。** 汉代一两合今多少克，学界有不同折算，且各方书、各朝代不同。本课的立场是：**只存原文数值与单位，不做换算入库**。换算表可以另立，但必须标注「近似」与所据，且不参与任何自动计算。理由很直接——一旦换算值进了库，下游就会拿它做剂量比较，而剂量比较在中医里是最不能自动化的动作之一。

**炮制算不算实体的一部分。** 炙甘草与甘草不是同一味药的功能等价物，生麻黄与炙麻黄的发汗力也不同。所以炮制要进属性 `proc`，且在做「同一药」的归并时，炮制不同的记录不能合并成一条——可以归到同一个药名节点下，但必须是不同的用药记录。

**修治与服法要不要抽。** 「去上沫」「先煮」「后下」「烊化」「冲服」——这些是煎服法，不是组成。它们在文本里紧跟着药名出现（「麻黄三两，去上沫」），用邻近规则很容易被误抽成炮制。判据是词表：煎服法动词单列一表，与炮制词表分开，抽的时候先匹配煎服法再匹配炮制。

## 五、从实体到三元组的失真

把前面几条合起来看，三元组在中医文本上丢三样东西：

其一，**条件**。「桂枝汤主之」前面往往还有「若……者」的限定，条件不满足时这条关系不成立。三元组没有条件位，于是所有条件都被丢掉，方证对应变成了无条件的。

其二，**强度**。上一节的语气表，三元组装不下。

其三，**出处**。「这条关系出自哪本书哪一条」在三元组里不存在。而中医关系的证据等级差别极大：有的是原文写死的，有的是后世注家归纳的，有的是教材转述的，有的是统计关联挖出来的。四者写在同一个谓词位置上，图上等重，临床上不等价。

本仓的处理是把三元组升级成**带属性的边**：每条边至少带 `source`（书名·篇名）、`modality`（语气）、`evidence`（证据等级）。这三样不是装饰，它们决定了这条边能不能被用于推理——只有 `modality=主之` 且 `evidence=原文` 的边，才允许参与「方证对应」的推理；其余只能作为参考。

这条纪律的代价是建图变慢，收益是可复核：任何一条推理结论，都能回溯到「哪本书、哪一条、什么语气」。没有这一层，知识图谱只是一个规模很大的字符串集合。
本章可直接验证：`node code/main.js` 打印结构清点与判据清单（数字从 `docs/zh.md` 现算），`node --test code/main.test.js` 跑本章单测；两条命令只读正文与代码，不写任何文件。
