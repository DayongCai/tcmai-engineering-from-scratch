# 中医语料不是一种文本，是四种文本挤在同一列 · 提示词

## 用途

给「中医语料不是一种文本，是四种文本挤在同一列」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「四种文体，四个说话人 → 噪声分三级，代价差两个数量级 → 一条语料记录该写什么 → 底本的构成，以及它决定了什么」这条链。

## 提示词

```
我在学《中医自然语言处理》第 1 章「中医语料不是一种文本，是四种文本挤在同一列」，本章 5 节 / 2,758 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 标点在古籍里是分析结果，不是观测数据
   - 本章及第 2、6、7 章的很多结论是按骨架补的判据，不是教材原文的转述
   - 任何自动改写都要保留原文 span
   - 具体到某部书的某篇属于哪类，仍需按版本核
4. 本章自陈的边界（不得越过）：
   - 本章的文体四分法依据的是教材侧的类别与关系，**具体到某部书的某篇属于哪类，仍需按版本核**；本章只到篇名，不写页码与藏地。
   - 上表的 148 单元、71,254 汉字与各章字数均从 `standards/zhongyi-ziran-yuyan-chuli/units.json` 现算；该文件记录 36 处数值类命中，无一处可作临床参数，本章不引为论据。
   - 三级噪声按可枚举性排序，不是按危害排序。语义级危害最大而成本最高，工程上常见的选择是先绕开（把语料缩到单一文体），而不是硬解。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为文本工程讨论，不构成诊断、辨证或治疗建议；具体操作以现行规范与所在机构制度为准。
