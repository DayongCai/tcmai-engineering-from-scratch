# 第 9 章 · F1 高不等于抽得对，可能只是学会了标注员的习惯

> **MOTTO:** 「不以文害辞，不以辞害志。」——《孟子·万章上》
>
> **PROBLEM:** 底本第 9 章 13 个单元、12,495 汉字，是全课第二长的一章（仅次于第 4 章的 13,259），讲经验误差与过拟合、评估方法、性能度量、比较检验、偏差—方差分解。它的公式都对，但它默认了一件事：用来比对的那个「标准答案」是可靠的。中医文本评测恰恰在这里有个洞——标准答案由人标，人与人自己就不一致。所以本章真正要回答的是：当标注员之间只有七成一致时，一个报到 0.9 的 F1 在说什么？

**双根因定位:** 环境逼迫（评测的分母是标注，而中医实体的边界与证型的归属都有争议，分母本身带噪声） + 知识积累（指标的计算是确定的，指标的解读需要领域知识：微平均与宏平均的差额、人—人一致与人—机一致的关系，都不是通用评估教材会讲的部分）

## 一、三个数，一个分母

精确率、召回率、F1 的定义人人都背得出：

`P = TP/(TP+FP)`　`R = TP/(TP+FN)`　`F1 = 2PR/(P+R)`

要看清这三个数在测什么，得看分母。精确率的分母是「系统判为正的」，召回率的分母是「标注里为正的」。两个分母都来自同一份标注。所以——

**评测测的是「与标注的一致」，不是「与事实的一致」。**这句话不是修辞上的谨慎，它有直接的算术后果：如果标注漏了一个实体，系统抽对了，这一条会被记为 FP（精确率扣分）；如果系统跟着标注一起漏，反而不扣分。于是模型的最优策略是**模仿标注员**，包括标注员的错误。

一个可执行的写法：

```python
def prf(tp, fp, fn):
    p = tp / (tp + fp) if tp + fp else 0.0
    r = tp / (tp + fn) if tp + fn else 0.0
    f = 2 * p * r / (p + r) if p + r else 0.0
    return p, r, f

rows = {"症": (100, 20, 14), "方": (15, 5, 10), "穴": (2, 3, 4)}
for k, (tp, fp, fn) in rows.items():
    print(k, *[round(x, 3) for x in prf(tp, fp, fn)])
tp = sum(v[0] for v in rows.values())
fp = sum(v[1] for v in rows.values())
fn = sum(v[2] for v in rows.values())
print("micro", *[round(x, 3) for x in prf(tp, fp, fn)])
print("macro-F1", round(sum(prf(*v)[2] for v in rows.values()) / len(rows), 3))
```

这段代码跑出来的结果是：症 0.833／0.877／0.855，方 0.750／0.600／0.667，穴 0.400／0.333／0.364；微平均 0.807，宏平均 F1 0.628。这些数字是演算示例（用于说明平均方式的差额，不是任何系统的实测），但差额本身有意义。

## 二、宏平均与微平均：长尾被吃掉

上例里微平均 0.807、宏平均 0.628，差 0.18。差额来自一处：症有 134 个实例、穴只有 6 个，微平均按实例加权，穴的表现几乎不影响总分；宏平均按类等权，穴的 0.364 摊进去就把总分拉下近两成。

这个差额就是**长尾的可见度**。中医实体分布是极端长尾的：症、药、方是高频类，脉、穴是低频类，而低频类恰恰是词典覆盖最差、最需要关注的地方。只报微平均，等于系统性地掩盖了自己最弱的部分。

所以报告要分三层：

- **每类**：P、R、F1、支持数（缺支持数的 P/R 无法解读）。
- **微平均**：反映整体实例级的水平。
- **宏平均**：反映类间的均衡程度。

三层一起看，才能回答「这个系统能不能用」——如果微平均高而宏平均低，说明系统只能用在多数类上；如果宏平均高而微平均低，说明各类都不错但总量少，可能是测试集太小。

序列标注还要多一层：字符级与实体级。字符级准确率会被大量 O 稀释，一条 300 字的病历里若只有 20 个字属于实体，全标 O 的字符准确率就有 93%。所以字符级只能作诊断用，不能作结论用。

## 三、标注一致性：模型上限的经验估计

人与人一致率是评测的前置指标，通常是 Cohen's kappa 或 Krippendorff's alpha。它的意义在于给模型定一个**经验上限**。

逻辑是这样的：若两位标注员在同一个任务上只有 0.7 的 kappa，那么任何模型与其中一位标注员的一致性，理论上不可能长期稳定地超过 0.7——因为模型要同时对两位都一致，而两位彼此都不一致。这不是定理（模型可以选择性地与某一位对齐），但它是一个很强的经验约束：**报到 0.9 而人—人只有 0.7 的系统，几乎一定是在拟合某位标注员的个人习惯，或者测试集与训练集有重叠。**

因此一份诚实的评测报告至少要有四个数：人—人一致、人—机一致、模型 F1、测试集规模。缺了第一个，后三个无法解读。

还有一层容易忽略：一致性要在**同一个颗粒度**上算。实体级的 kappa（这个 span 是不是实体）与字符级的 kappa（这个字在不在实体内）差别很大，后者通常高得多，因为大量 O 拉高了「碰巧一致」。报字符级 kappa 而不说明，是一种无害但会误导的修饰。

指标的选择也有讲究。两位标注员用 Cohen's kappa 就够；三位以上要用 Fleiss' kappa 或 Krippendorff's alpha。后者的好处是容许缺失——专家不一定每条都标。还有一类情形是「严重偏斜」：若某个标签占九成，kappa 会低得难看，即使标注员其实很准，因为 kappa 的分母接近零。这时改用 Gwet 的 AC1 更稳。本课不指定必须用哪一个，只要求在报告里写清用的是哪个、为什么——因为不同指标算出来的数不可比，而混着报是常见错误。

## 四、小样本的波动与比较

中医标注语料的规模通常在几百到几千条，测试集更小。在这个尺度上，一个 F1 的第三位小数是没有意义的，第二位也未必稳。

两件事必须做。

**给区间。** 比例型指标（精确率、召回率）可以用 Wilson 区间；F1 没有简单的闭式区间，用 bootstrap 重采样更稳：对测试集有放回地抽同样大小的样本若干次，每次算 F1，取分位数。区间宽度直接反映「这个数有多可信」——一个 0.72 的 F1，若 95% 区间是 0.64 到 0.79，那么与另一个 0.75 的系统比较就没有意义。

**别用单次划分比较模型。** 单次训练／测试划分的方差常常大于两个模型的真实差距。正确做法是多次随机划分（或交叉验证）后做配对检验，比较的是「同一批样本上两个模型的差异」而不是两个孤立的分数。教材里讲比较检验（如配对 t 检验、McNemar 检验）就是为这件事准备的，但在课程作业里最常被省略。

还有一条更根本的：**比较的双方必须用同一份测试集、同一份标注、同一套匹配规则。**严格匹配与宽松匹配的差别可以达到十几个点，把两个用不同匹配规则算出来的 F1 放在一张表里比较，是常见的错误。

区间之外还有一个更朴素的判据：**分层的分数比分数的总分有用**。一个系统在症上 0.85、在方上 0.66、在穴上 0.36，整体 0.81；这个「0.81」几乎不携带信息，而「穴只有 0.36」直接指出了下一步该补什么（穴位词典与别名表）。所以在中医场景里，评测报告的主表应当是每类一行，总分行放最后，且标注「仅供参考」。

## 五、测试集怎么切才不骗自己

这一节是本章最中医的部分。

通用 NLP 的切分原则是「随机划分」，前提是样本独立同分布。中医古籍语料严重违反这个前提：同一条条文会在不同注本、不同电子整理版、不同教材引文里重复出现。随机划分会让同一句话同时进训练集和测试集，模型在测试集上的表现就成了背诵能力。

三个切分维度，按严格程度排：

**按条切**：最低要求。同一条的不同版本必须整体落在同一侧。这是底线，做不到就没有资格报分数。

**按书切**：推荐。训练用《伤寒论》，测试用《金匮要略》，考察跨书迁移。中医的方证体系跨书有重叠但不相同，这个切法最接近真实使用场景（用一本教材训练，去读另一本书）。

**按文体与年代切**：最严格。训练用古籍，测试用现代病历，考察跨语体迁移。这个设置下分数通常大幅下降，而下降的幅度本身是最有价值的信息——它告诉你这套方法在真实落地时还差多远。

三个切法给出的分数不能互相比较，报告时必须写明用的是哪一种。本课的建议是：**主线报告用按书切，按条切作为上限参考，按文体切作为落地预期。**

还有一类泄漏不来自切分，来自预处理：如果字符归一化、术语归并是在全量语料上做的（包括测试集），那么测试集的信息已经渗进训练。规范做法是所有拟合型预处理只在训练集上做，再应用到测试集。这条在工程上常被忽略，因为它的影响不像数据泄漏那样立刻显形，而是让分数虚高几个点，且无法从结果上看出来。

最后一条纪律关于测试集的生命周期：**测试集一旦定版就不许动**。实践中常见的退化是「看一眼错例、改一改标注、再跑一次」，改上三五轮，测试集就变成了训练集的延伸，分数不再有任何意义。若确实发现标注错误，正确做法是把这一批整体作废、重新抽一批，并在报告里写明作废原因与规模。这很浪费，但比一个好看而无意义的分数便宜得多。
