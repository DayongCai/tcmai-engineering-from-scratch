# 检索的失败不在召回率，在找回来的那条没有出处 · 提示词

## 用途

给「检索的失败不在召回率，在找回来的那条没有出处」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三种检索，三种失效方式 → 索引单位：字、bigram 还是词 → 多路融合：为什么用排名而不用分数 → 排序之上：出处回链」这条链。
