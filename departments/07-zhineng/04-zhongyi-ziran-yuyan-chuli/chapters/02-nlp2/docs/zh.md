# 第 2 章 · 分词切错的不是词，是概念边界

> **MOTTO:** 「名不正则言不顺。」——《论语·子路》
>
> **PROBLEM:** 底本第 2 章只有 12 个单元、1,126 汉字，而这 12 个单元讲的是本体七步法与知识树分层，没有一节讲中文分词。可本课要处理的对象里，「头项强痛」是一个症、「脉浮」是一个脉象、「麻黄汤」是一个方，三个字符串的切法各不相同，切错一个，后面六类实体全部错位。于是本章的分词不是「把句子切成词」，是「把字符串对齐到术语表的条目上」——判据是术语，不是语言学上的词。

**双根因定位:** 环境逼迫（古汉语以单音节词为主，「词」这个单位在原文里并不成立，硬切必然产生大量伪词与碎词） + 知识积累（术语表的颗粒度本身不统一：症候有的到四字，有的只到单字，分词器只能服从术语表而不能服从统计）

## 一、古汉语里没有「词」这个单位

现代汉语分词的前提是：词是最小的能独立运用的单位，长度二到四字，边界大致可由统计确定。这三个前提在医古文里同时不成立。

「太阳之为病，脉浮，头项强痛而恶寒。」按现代汉语切：太阳/之/为/病/脉/浮/头项/强痛/而/恶寒。按中医术语切：太阳病/脉浮/头项强痛/恶寒。两种切法的差别不是精度，是**对象**：前者切的是语言单位，后者切的是概念条目。

再看「麻黄汤去麻黄」这五个字。语言学上切是麻黄/汤/去/麻黄，四个单位；语义上是一个方名变体（麻黄汤去麻黄）加一个「去」的配伍操作。如果按语言学切，系统会抽出两个「麻黄」，一个是药，一个是方名的构件，然后很可能把它们合成一条「方含药」的关系——而这条关系恰好是错的，因为这个方恰恰去了麻黄。

这就是本章的核心判据：**分词的目标不是还原词，是让每个 span 唯一对应到术语表里的一条**。对不上的，宁可留作未登录候选，也不要硬切。硬切的坏处不是难看，是它凭空造出一个「合法」的实体，而这个实体在医学上不存在。

## 二、句读：标点不是数据，是判断

今本古籍的标点是后人加的。第 1 章把这一点记为语料字段，这里要说它的后果：**断句本身是一次语义决策，而这次决策会被下游当作既成事实**。

《素问·生气通天论》有一句常被拿来作断句练习：「因于湿首如裹湿热不攘大筋緛短小筋弛长緛短为拘弛长为痿」。通行断法是：

> 因于湿，首如裹；湿热不攘，大筋緛短，小筋弛长。緛短为拘，弛长为痿。

若断成「因于湿首，如裹」，湿就从病因变成了「湿首」这个部位，全句的病机解释随之改变。两种断法字面上都读得通，区别在医理——而医理不在字符串里。

工程上能用的判据有三类，都不完备：

- **虚词**：「者」「也」「而」「故」「若」「之」的分布有强规律，「…者，…也」是判断句的框。
- **对文**：上下句结构对称处，断点也在对称位置。「大筋緛短」对「小筋弛长」，「緛短为拘」对「弛长为痿」。
- **句长分布**：同一部书的句子长度有惯性，异常长句多半漏断。

三类判据合起来能给出候选，但**不能给出唯一解**。所以断句的产出必须是「候选 + 置信 + 依据」，而不是一串加了逗号的文本。这与分词是同一条纪律：不确定处要显式留白。

有一条反直觉的事实可以说明为什么不能迷信标点。把《伤寒论》太阳病前三条取出来做字符 bigram 统计，共 71 个字符、55 个不同的 bigram，出现最多的是「太阳」三次；紧跟其后的是「病，」「，脉」「发热」各三次。也就是说，**逗号与「脉」组成的二元组，和「发热」一样高频**。标点是今人加的，却在统计上成了最强的边界信号——模型学到的很可能不是医理，是标点习惯。

## 三、异体、通假与避讳：归一到今字，但保留原形

这一级的处理是纯工程，但方向容易搞反。映射的目标是**让检索与匹配能命中**，不是「改正古人」。所以规则是：归一化用于索引，原字形用于展示与引证，两者都存。

| 原字 | 今字 | 关系 | 例 |
|---|---|---|---|
| 鞕 | 硬 | 异体 | 大便鞕 |
| 欬 | 咳 | 异体 | 欬逆上气 |
| 藏 | 脏 | 通假 | 十一藏 |
| 府 | 腑 | 通假 | 六府 |
| 俞 | 腧 | 通假 | 背俞 |
| 内 | 纳 | 通假 | 内药鼻中 |

映射表要写成可测的形式，而不是散在代码里的条件分支：

```python
NORM = {
    "鞕": "硬", "欬": "咳", "藏": "脏", "府": "腑",
    "俞": "腧", "内": "纳", "齐": "剂", "差": "瘥",
}

def normalize(s, table=NORM):
    """只做单字归一；返回 (归一文本, 改写位置列表)"""
    out, marks = [], []
    for i, ch in enumerate(s):
        if ch in table:
            out.append(table[ch])
            marks.append((i, ch, table[ch]))
        else:
            out.append(ch)
    return "".join(out), marks
```

`marks` 是重点。没有它，归一化就是不可逆的：搜「大便硬」能命中，但原文写的是「鞕」，引证时引不出来。医案场景里「引不出原文」等于不能用。

还有一层是**避讳**。刻本因避讳改字，改出来的字与本字往往同音不同义。这一层不能靠通假表，只能靠版本与校勘记，属于第 1 章的第二级噪声。本章的处理是：遇到可疑字保留原样并标 `variant?`，不自动改。宁可留一个待核标记，也不要制造一个看起来干净的错字——错字会被下游当成事实，待核标记不会。

## 四、三种切法，三种后果

同一个字符串，三种颗粒度：

| 切法 | 「头项强痛而恶寒」 | 好处 | 坏处 |
|---|---|---|---|
| 字级 | 头/项/强/痛/而/恶/寒 | 无需词典，零未登录 | 语义全丢，无法对齐术语 |
| 词级（统计） | 头项/强痛/而/恶寒 | 边界较自然，可泛化 | 术语被切碎，「头项强痛」这个症没了 |
| 术语级 | 头项强痛/恶寒 | 可直接对齐证候要素 | 依赖词表，未登录术语全漏 |

实践中的做法是三段式：

1. **词典优先**：术语表按长度降序做最大匹配，长的先匹配，「头项强痛」优先于「头项」。
2. **统计兜底**：未命中的片段交给统计分词或字级 n-gram，产出候选而非定论。
3. **候选池**：未登录的高频串进候选池，等人确认后入表，而不是就地硬切。

最大匹配的经典失败是「麻黄汤」被切成「麻黄/汤」。原因很简单：如果词典里「麻黄」是药、「汤」是剂型，而「麻黄汤」不在方剂表里，最大匹配就会给出这个错切。于是词表的覆盖面决定分词质量，而词表的覆盖面又依赖分词去发现新词——这是一个循环。

打破循环的办法不是调算法，是**换粒度**：先按药、方、证、症、脉、穴六类分别建表，方剂表里必须有「麻黄汤」「麻黄加术汤」「三拗汤」这类同源方，否则任何分词器都会把它们切碎。第 7 章会展开这六类实体的边界麻烦，本章只需记住一条：分词的词典不是一部，是六部。

未登录词（OOV）的发现有一套可操作的流程，不必靠灵感。第一步，把语料按术语表切分，收集所有「无法归入任何术语的最长连续片段」。第二步，按频次与左右邻接的多样性排序——左右邻接越杂，越可能是一个独立的词；左右邻接越固定，越可能是某个更长术语的一部分。第三步，人工过一遍排在前面的若干条，判定是「新术语」「已有术语的变体」还是「切分残留」。

三步里第三步不可省。前两步只是把候选压到人能看完的规模，判定仍要靠医学知识。一个常见的误判是把切分残留当成新术语：比如「脉阴阳俱紧」被切成「脉／阴阳／俱／紧」，中间的「俱」左右邻接极杂、频次很高，按统计它很像一个词，实际上它只是一个副词。判据是词性：术语表只收名词性成分，虚词与副词一律不进——这条规则能挡掉大部分统计误报。

## 五、规范化的三层，以及不能合并的那一层

规范化有三层，越往下越危险。

**第一层，同形归一**：繁简、异体、全半角、标点统一。纯字符操作，可枚举，可回归测试，风险几乎为零。

**第二层，变体归一**：「桂枝汤」「桂枝汤方」「桂枝湯」是同一方；「足三里」与「三里」在多数语境下同一穴。这一层必须带条件——「三里」在手阳明大肠经叫手三里，在足阳明胃经叫足三里，脱离上下文归并就会错。所以规则是「上下文 + 别名表」，不能是纯字符串替换。

**第三层，同义归并**：把「消渴」与「糖尿病」并成一个概念，把「伤寒」的广义与狭义并成一个。这一层**不该由分词器做，也不该由相似度做**。理由很硬：同义是医学判断，不是字符串判断。「消渴」与「糖尿病」在临床上部分重叠而非等同；「伤寒」的广狭两义在《素问》与《伤寒论》里是不同的所指。用向量相似度把这两个并掉，等于用一个余弦值替换了一次医学定义——而这个替换是不可见的，因为它发生在索引层，用户看到的只是「搜到了」。

所以规范化的边界是：**前两层自动，第三层出「映射建议 + 依据 + 待审」**，由人签字后才入映射表。这条界线划在「字符串是否相同」与「概念是否相同」之间；越线的自动化一定出错，而且错得看不出来。
