# 分词切错的不是词，是概念边界 · 提示词

## 用途

给「分词切错的不是词，是概念边界」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「古汉语里没有「词」这个单位 → 句读：标点不是数据，是判断 → 异体、通假与避讳：归一到今字，但保留原形 → 三种切法，三种后果」这条链。

## 提示词

```
我在学《中医自然语言处理》第 2 章「分词切错的不是词，是概念边界」，本章 5 节 / 2,831 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 分词的目标不是还原词，是让每个 span 唯一对应到术语表里的一条
   - 断句本身是一次语义决策，而这次决策会被下游当作既成事实
   - 不能给出唯一解
   - 逗号与「脉」组成的二元组，和「发热」一样高频
   - 让检索与匹配能命中
   - 第一层，同形归一
4. 本章自陈的边界（不得越过）：
   - 本章的句读判据（虚词、对文、句长）是通用汉语句读方法的移植，**不是中医专有的断句算法**；底本无分词章节，切法示例按骨架补，引文取自《伤寒论》《素问》通行本。
   - 异体字表只列常见数例，不足以覆盖刻本全貌；实际建表须以校本与字书为准。
   - 规范化第三层的「人工签字」不是形式要求：映射表一旦进入索引，错误会以「检索命中」的形式扩散，且不可见。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为文本工程讨论，不构成诊断、辨证或治疗建议；具体操作以现行规范与所在机构制度为准。
