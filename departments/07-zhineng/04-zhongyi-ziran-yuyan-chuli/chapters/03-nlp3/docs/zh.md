# 第 3 章 · n-gram 算得出下一个字，算不出这句话是谁写的

> **MOTTO:** 「夫人之立言，因字而生句，积句而成章，积章而成篇。」——刘勰《文心雕龙·章句》
>
> **PROBLEM:** 底本第 3 章有 14 个单元、11,200 汉字，讲的是隐马尔可夫模型、马尔可夫随机场、条件随机场、精确与近似推断、话题模型——全部取自《机器学习》第 14 章，一个字都没有讲中医文本。而本课真正要问的是：一个在四种文体混合语料上训练出来的语言模型，它的困惑度究竟在度量什么？答案不乐观：它度量的是四种文体的加权平均，而这个平均值不对应任何一种真实的文本。概率模型在这里的第一个任务不是生成，是先说清自己在哪种语体上说话。

**双根因定位:** 环境逼迫（语料是合成的：文本侧 5,264 字、模型侧 58,691 字，两侧语体不同，同一个模型无法同时贴合） + 知识积累（概率模型的假设是「局部依赖」，而中医文本的关键信息恰恰是长程的——一句条文里的方与证隔着十几个字，「主之」的强度又由前文的脉症共同决定）

## 一、链式法则：整句概率被拆成一串条件概率

语言模型要回答的问题是：一个字符序列出现的概率有多大。直接给整句定概率不可能——句子无穷多。链式法则把它拆开：

`P(w₁w₂…wₙ) = Π P(wᵢ | w₁…wᵢ₋₁)`

每一项仍然是长程条件，于是引入马尔可夫假设：第 i 个位置只依赖前 n−1 个位置。取 n=2 就是 bigram。这一步是纯粹的工程妥协，代价写在假设里：**距离超过 n−1 的依赖被当作不存在**。

在中医文本上，n 取多大是个真问题。取 2，则「太阳病，头痛发热，汗出恶风，桂枝汤主之」里「桂枝汤」与「汗出恶风」的关系完全丢失；取 5 以上，参数爆炸而语料不够。这不是调参能解决的，是语料规模与依赖长度的矛盾。

字符级与词级的选择也在这里分岔。词级模型的每一项都要求先分词，而第 2 章已经说明中医分词没有稳定解——分词错一处，词级模型的概率就被污染一次，且污染不可见。字符级模型绕开了分词，代价是序列变长、有效依赖变短。在中医古籍上，字符级通常是更稳的起点：字符集小（常用字数千量级），组合虽稀疏但可平滑，且不受分词错误传导。

把《伤寒论》太阳病前三条取出来做一次字符 bigram 计数，可以直接看到问题的形状：71 个字符，55 个不同的 bigram。前五位是「太阳」3 次、「病，」3 次、「，脉」3 次、「发热」3 次、「恶寒」2 次。也就是说，一半以上的 bigram 只出现一次，而出现最多的几个里有两个含标点。

```python
from collections import Counter

def bigrams(text):
    return Counter(text[i:i + 2] for i in range(len(text) - 1))

def unigram_prob(text, add_one=1.0):
    """加一平滑：V 取字符集大小，避免未见组合概率为 0"""
    uni = Counter(text)
    V = len(uni) + 1
    total = len(text) + add_one * V
    return {ch: (c + add_one) / total for ch, c in uni.items()}, V
```

这段代码里 `add_one` 不是装饰。没有它，任何未见过的字概率为 0，整句概率乘起来就是 0，对数似然变成负无穷——一个异体字就能让整个检索排序崩掉。第 2 章的字符归一在这里拿到了概率上的理由。

## 二、稀疏：字符少，组合更少

古汉语的字符集比现代汉语小，但这不是好消息。字符少意味着单个字的频率高，组合少意味着二元组更稀疏。上面那个 71 字的样本里，55 个 bigram 分摊 70 个位置，绝大多数只出现一次——任何「根据前一个字预测下一个字」的尝试，在这个规模上都接近随机。

解决稀疏的三条路，各有代价：

- **加一平滑**：给所有未见组合分配一个极小概率。简单，但把概率质量平摊给了大量不可能的组合（比如「之」后接「鞕」）。
- **插值**：把 bigram 与 unigram 按权重混合，`P = λ·P_bi + (1−λ)·P_uni`。λ 由留存语料估计，能缓解但不解决。
- **回退**：bigram 没见过的组合回退到 unigram。工程上最常用，代价是长程信息在回退处彻底丢失。

三条路的共同前提是**字符已经归一**。这一条比平滑方法重要得多：语料里同时存在「鞕」与「硬」，模型会把它们当成两个不同的字，各自统计各自的上下文，两个都稀疏。归一之后，样本合流，稀疏立刻缓解。所以在中医语料上，做语言模型之前先做字符表，收益往往大于换平滑算法。

## 三、困惑度为什么在混合语体上没有意义

困惑度（perplexity）是语言模型最常用的指标：`PPL = 2^(−(1/N)·Σ log₂ P(wᵢ | 前文))`，直观含义是「模型在每一步平均要在多少个候选之间犹豫」。数值越低越好。

问题出在「平均」这两个字。如果测试集混了四种文体（经典、教材、病历、标准），困惑度就是四种文体的加权平均。一个在教材上极强的模型，在经典上很差，但混合测试集上的困惑度可能仍然好看——因为教材占了多数。反过来，一个专门为经典训练的模型，在混合集上会显得很差，尽管它在自己的语体上是对的。

所以在中医场景里报困惑度，必须同时报三件事：**在哪种语体上测、测试集是否同源、字符表是否一致**。缺一条，这个数就不可比。尤其不能拿古籍的困惑度去和现代新闻语料横向比较：古籍无标点、单音节为主、虚词密度高，任何模型在这些文本上的困惑度都天然偏高，这是语体的性质，不是模型的能力。

还有一层更隐蔽的偏差：如果测试集里的句子在训练集里出现过，困惑度会低得不真实。古籍的条文数量有限、广为引用，同一句「太阳之为病」可能同时出现在训练集和测试集的注本里。这不是数据泄漏的小概率事件，是古籍语料的常态——第 9 章会把「按出处切分」作为评测的第一条纪律，理由就在这里。

## 四、状态与序列：HMM 的用处与它的假设错在哪

隐马尔可夫模型把序列看成「不可观测的状态序列生成可观测的符号序列」。它有两个假设：一阶马尔可夫性（下一状态只依赖当前状态）、观测独立性（当前观测只依赖当前状态）。

在 NLP 里，这套语法非常合用：状态就是标签（B/I/O 或词性），观测就是字。中文分词、命名实体识别在深度学习之前主要靠它，加上维特比解码就能给出全局最优的标注序列。

教材把 HMM 映射到「六经传变路径」，这个映射有意思，但必须说清它的假设在临床上不成立。一阶马尔可夫性要求「下一阶段只依赖当前阶段」，而六经传变恰恰有合病、并病、直中三阴这些不服从单链的情形：太阳与阳明可以同时病（合病），太阳未罢而阳明已见（并病），也可以不经三阳直入三阴（直中）。用一条链去套，等于把「可以同时发生的两件事」压缩成「先后发生的两件事」。

这不是说不能用，而是说**用完必须标明它是一个简化**：输出的是「在该假设下最可能的阶段序列」，不是「传变规律」。二者的区别在临床上就是一句话的差别——前者是模型输出，后者是医学断言。

条件随机场（CRF）换了个方向：不建模联合分布 `P(x,y)`，直接建模条件分布 `P(y | x)`。好处是观测之间的独立性假设可以不要，特征可以任意设计——这对中医文本极其关键。你可以把「前一字为『脉』且当前字为『浮』」写成特征，把「本句含『主之』」写成特征，领域知识由此直接进入模型，而不是指望它从数据里自己发现。代价是训练慢、特征要人工设计，但在标注数据只有几千条的规模上，这个代价是值得的。

特征模板在中医上有一个特殊性：很多有效特征不是局部的。判断一个「浮」是不是脉象，不只看前一字是不是「脉」，还要看这一句是不是在讲脉——而「这一句」的边界又依赖断句。于是特征之间形成依赖链：断句错则句级特征错，标注跟着错。这是级联错误，在古籍上比在现代汉语上更常见，因为长句多、句读不确定。缓解办法不是加更多特征，而是把级联拆开评估：先单独评估断句的准确率，再在「断句正确」的子集上评估标注。两者混在一起报，出了问题无法定位是哪一环塌的。

## 五、概率能做什么，不能做什么

概率模型在中医文本上能做的，是**排序与候选**：给定前文，哪个字更可能；给定一句残缺的条文，哪种断句更可能；给定一条病历，哪个证型标签的分数更高。这些都是「在文本规律层面」的判断，可检验、可复算。

它不能做的，是**因果与判断**。语言模型学到的是「这个词后面常跟那个词」，不是「这个症导致那个证」。当语料里「舌红苔黄」后面常跟「热证」，模型学到的是书写习惯的共现，不是病机。把共现当因果，就会出现「因为写了舌红苔黄所以是热证」这种倒果为因的推理——而临床上舌红苔黄只是支持热证的证据之一，还要看脉、看病程、看体质。

一条分界线可以写死在这里：**概率给的是「文本里有多常见」，医学给的是「病机上有几分把握」。**两者可以互相校准，但不能互相替代。凡是把前者当后者用的系统，在演示时很好看，在复核时说不出依据。
