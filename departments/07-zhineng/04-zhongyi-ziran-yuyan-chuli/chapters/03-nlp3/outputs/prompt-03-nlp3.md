# n-gram 算得出下一个字，算不出这句话是谁写的 · 提示词

## 用途

给「n-gram 算得出下一个字，算不出这句话是谁写的」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「链式法则：整句概率被拆成一串条件概率 → 稀疏：字符少，组合更少 → 困惑度为什么在混合语体上没有意义 → 状态与序列：HMM 的用处与它的假设错在哪」这条链。

本章为语言模型与概率推断的教学讨论，不构成诊断、辨证或治疗建议；具体操作以现行规范与所在机构制度为准。
