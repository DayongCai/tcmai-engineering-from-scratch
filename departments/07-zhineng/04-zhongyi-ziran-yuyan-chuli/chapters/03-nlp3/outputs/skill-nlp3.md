# n-gram 算得出下一个字，算不出这句话是谁写的

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 5 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 距离超过 n−1 的依赖被当作不存在
- 字符已经归一
- 在哪种语体上测、测试集是否同源、字符表是否一致
- 用完必须标明它是一个简化
- 概率给的是「文本里有多常见」，医学给的是「病机上有几分把握」

## 边界

- 本章的模型叙述取自《机器学习》概率图模型一章，**中医侧的映射（HMM 对传变、CRF 对四诊序列）是按骨架补的对应关系，不是教材原文**；底本第 3 章 11,200 字里没有中医文本的实证结果。
- 上文 71 字符、55 个 bigram 的计数是对《伤寒论》太阳病前三条的实算，只用于说明稀疏形状，不代表任何模型性能。
- 困惑度的可比性有三条前提（同语体、同源、同字符表），本章未给任何具体 PPL 数值——底本没有、本章也不编。
- 本章为语言模型与概率推断的教学讨论，不构成诊断、辨证或治疗建议。
