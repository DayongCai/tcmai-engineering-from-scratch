# 第 5 章 · 标注不是把词圈出来，是把边界争议写下来

> **MOTTO:** 许慎：「分别部居，不相杂厕。」——《说文解字·叙》
>
> **PROBLEM:** 底本第 5 章 14 个单元、10,093 汉字，讲的是半监督学习：未标记样本、生成式方法、半监督 SVM、标签传播、协同训练。它有一个隐含前提——已标注的那一小部分是对的。中医文本标注恰恰在这一点上站不住：同一句「麻黄汤去麻黄」，有人标一个方名，有人标一个方名加一个药名，两人都没错，但标出来的训练数据互相矛盾。所以本章要说的不是「怎么用未标注数据」，是「怎么把标注这件事做成可复核的」。

**双根因定位:** 环境逼迫（标注成本按字符计而非按条计：一条 300 字的病历就是 300 次边界决策，而中医实体的边界规则本身有争议） + 知识积累（六类实体的颗粒度不统一：药含炮制、症含程度、脉含部位，同一套 BIO 标签无法同时容纳这六种颗粒度）

## 一、BIO 的第一条裂缝：嵌套

序列标注的标准表示是 BIO：B 开头、I 延续、O 在外。「头项强痛而恶寒」标成 `B-SYM I-SYM I-SYM I-SYM O B-SYM I-SYM`，一个症一个症，边界清楚。

麻烦从嵌套开始。「麻黄汤去麻黄」里，「麻黄汤」是方名，「麻黄」是药名，而药名嵌在方名里面。单层 BIO 只能表达一种切分：要么把整串标成一个方名，药名丢掉；要么切开标成两个实体，方名被破坏。两种都不对。

同类情形在中医文本里不是边角料，而是常态：「桂枝加芍药汤」里的桂枝、芍药是药，「桂枝汤」里的桂枝是方名构件，「四君子汤」里没有一味的药名是完整的。方名是「药名 + 剂型 + 加减」构成的复合词，而这套构词法本身就与实体边界冲突。

三种解法，各有代价：

- **分层标注**：先标外层最大实体，再在实体内部标内层。表达力够，但标注量翻倍，且两层之间的一致性要单独校验。
- **只标外层，内层交给关系**：方名整串标为一个实体，其组成由关系抽取补齐（第 7 章）。标注便宜，代价是「文本里明明写了药名却没被识别」。
- **指针式标注**：不预设层数，让模型直接输出首尾指针。工程上灵活，标注规范难写——标注员看到的是一个 span，不知道该不该再切。

本课选第二条：**实体层只标最大匹配，嵌套由关系层表达**。理由是标注成本与可复核性：一个标注员判断「这五个字是不是一个方名」比判断「这五个字里有几层实体」稳定得多。

## 二、六类实体，六种颗粒度

颗粒度不统一是标注矛盾的主要来源。同一套标签体系下，六类实体的边界规则完全不同：

| 类 | 例 | 边界争议点 | 本章的处理 |
|---|---|---|---|
| 药 | 麻黄、炙甘草、麻黄（去节） | 炮制算不算实体的一部分 | 药名到本名止，炮制入属性 `proc` |
| 方 | 麻黄汤、桂枝加芍药汤 | 加减算不算方名的一部分 | 整串为方名，加减入属性 `mod` |
| 证 | 太阳伤寒证、风寒表实证 | 同证异名、证与症一字之差 | 以术语表为准，别名入 `alias` |
| 症 | 恶寒、微恶寒、无汗 | 程度、否定是否入实体 | 实体到本症止，程度入 `degree`，否定入 `negated` |
| 脉 | 脉浮、浮脉、寸浮 | 部位与脉象是否分开 | 部位入 `pos`，脉象为实体 |
| 穴 | 足三里、三里 | 简称的归属 | 简称入 `alias`，需上下文消歧 |

这张表本身就是标注指南的第一节。它的写法有一个共同点：**修饰成分一律不进实体，进属性**。这条规则的价值在于它可判定——标注员不需要判断「微恶寒算不算一个症」，只需要判断「恶寒」这两个字在不在，然后把「微」填进 `degree`。把判断题换成填空题，一致性立刻上升。

「无汗」是个反例，值得单列。它不是「汗」的否定，而是一个独立的症——「无汗」在表实证里是正面见证，与「汗出」相对。而「不恶寒」是否定，不是独立的症。语言形式上两者都是「否定词 + 名词」，医学上一个是症、一个是属性。这条只能写进指南的例外清单，靠规则推不出来。

## 三、成本算术：按字符算，不按条算

标注预算的估算常犯一个错：按条报价。「一千条病历，每条多少钱。」这个口径掩盖了真正的成本，因为一条病历里的实体数量差别极大——一份门诊记录可能只有三个症，一份住院记录可能有四十个。

按字符算更接近真相：一条 300 字的病历，标注员要为每个字符判断「是不是某个实体的边界」，即 300 次决策。一千条就是三十万次。加双标（两人独立标，用于算一致性）是六十万次。再加争议仲裁——若 10% 的实体有分歧，就是六万次专家判断，而专家判断的单位成本是普通标注的数倍。

这个算术的用处不在于得出一个总数，而在于指出**该把预算花在哪**。三个结论：

其一，标注指南的质量直接决定成本。指南每含糊一条，争议率就上升一截，而争议要靠专家仲裁，单位成本最高。写好「否定怎么标」「炮制算不算」这两条，能省下的仲裁量超过任何工具优化。

其二，预标注（模型先标、人再改）能降低单位成本，但会把模型的偏差写进数据。若预标注模型在某个实体类上系统性漏标，人工复核也容易漏——因为人倾向于接受看起来合理的标注。缓解办法是抽样盲标：随机抽 5% 的样本，让人从零标注，与预标注比对。

其三，主动学习的价值在中医场景里被高估了一半。它的逻辑是「标模型最不确定的样本」，但模型最不确定的样本往往正是边界争议最大的样本——标了也不能用，因为人自己都定不下来。真正该优先标的是**高频且边界清楚**的实体，把低频争议留给指南逐条裁决。

## 四、一致性：标注噪声有一个下限

双标之后要算一致性。最常用的指标是 Cohen's kappa：

```python
def kappa(a, b):
    """a, b: 两个标注员对同一批单位的标签列表（等长）"""
    n = len(a)
    if n == 0:
        return None
    agree = sum(1 for x, y in zip(a, b) if x == y) / n
    labels = set(a) | set(b)
    pe = sum((a.count(l) / n) * (b.count(l) / n) for l in labels)
    if pe == 1:
        return 1.0
    return (agree - pe) / (1 - pe)
```

kappa 减去的那一项 `pe` 是关键：它扣掉了「碰巧一致」。如果 90% 的字符都是 O（不在任何实体内），两个标注员随便标也能有九成一致，但 kappa 会把这个虚高扣掉。所以在序列标注任务上，报「一致率」而不报 kappa 基本没有意义。

序列标注的噪声比分类更致命。分类错一条，错一条；实体边界错一个字，那个实体的精确率与召回率同时算错，而且错误会沿着 `B/I` 序列扩散到相邻实体。这就是为什么在序列标注上，「95% 的字符标对了」可以与「实体 F1 只有 0.6」同时成立——字符级准确率被大量的 O 稀释了。

因此评测要报三层：字符级、实体级（严格匹配）、实体级（宽松匹配）。宽松匹配（只要类型对、有重叠就算对）看着友好，但它会掩盖边界错误，而边界错误恰恰是下游关系抽取最敏感的东西——「麻黄汤去麻黄」的方名边界错一个字，关系就抽成了「方含麻黄」。本课的立场是：**主报严格匹配，宽松匹配只作辅助，两者之差即边界噪声的规模**。

## 五、未标注数据能救什么，不能救什么

回到章首的问题：半监督学习能缓解标注贵，但它解决不了标注矛盾。

标签传播、协同训练、半监督 SVM 的共同思路是「用少量标注 + 大量未标注，让决策边界落在数据稀疏处」。这套思路成立的前提是：已标注的样本是对的，且未标注样本与已标注同分布。

中医文本上，第一个前提最脆弱。若训练集里「恶寒」被标成症、「恶风」被漏标（因为标注员觉得它不重要），模型会把「恶风」学成 O，然后用这个模型去标未标注数据，错误自我强化——这就是伪标签的典型失效。第二个前提也不稳：古籍与病历不同分布，用古籍种子去传播病历，边界会落在两本文体之间，对哪边都不对。

所以在中医场景里，半监督的正确用法是**同一文体内部**的扩充：用已标的一千条病历去扩未标的十万条病历，而不是用古籍的条文种子去扩病历。跨文体传播需要先做分布对齐，而对齐本身又需要标注——绕回去了。

还有一笔成本常被漏算：**标注的返工**。第一批标完之后，指南往往会修订，因为标注员会遇到指南没写到的情况。修订之后，前面的标注要按新指南回改，这部分成本常常等于初次标注的三到五成。工程上的缓解办法是先做小规模试点：拿一百条标一遍，把争议全部摊出来，改指南，再规模化。试点的一百条会作废，但它省下的返工远超这一百条的成本。

试点还有一个副产品：争议率的初估。若一百条里出现三十处指南未覆盖的情形，说明指南的粒度还不够细，规模化之后的争议率不会低于这个比例。这个数字应当写进项目计划，而不是等到验收时才承认。
