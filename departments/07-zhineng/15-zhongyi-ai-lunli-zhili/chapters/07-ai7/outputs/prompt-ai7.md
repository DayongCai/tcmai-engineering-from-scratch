# 可解释不是画热图：审计要的是「这一次依据了哪几条记录」 · 提示词

## 用途

给「可解释不是画热图：审计要的是「这一次依据了哪几条记录」」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三种追溯，三种材料 → 变更管理：版本号之外的「变更理由」 → 解释的层次与对象 → 审计的抽样与定性」这条链。

## 提示词

```
我在学《中医AI伦理与治理》第 7 章「可解释不是画热图：审计要的是「这一次依据了哪几条记录」」，本章 5 节 / 2,653 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - （参数、数据、代码、接口）、
   - （触发的证据是什么，是漂移告警、是临床反馈、还是新数据到位）、
   - （具名的批准人与其依据）、
   - 数据源的变更
   - 回答「这个模型总体上依赖哪些特征」
   - 回答「这一例为什么这样判」
4. 指出本章写到类别就止步、不再给参数的地方。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，不构成合规意见、医学意见或技术评估结论。模型的审计与追溯安排须依现行规定，由具备相应职责的人员组织实施；具体操作以现行规范与所在机构制度为准。
