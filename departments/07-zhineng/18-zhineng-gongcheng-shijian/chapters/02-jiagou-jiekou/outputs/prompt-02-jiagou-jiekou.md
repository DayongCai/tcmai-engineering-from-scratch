# 接口定不下来，架构就只是画在纸上的分工 · 提示词

## 用途

给「接口定不下来，架构就只是画在纸上的分工」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「架构决策要留痕：一页纸的 ADR → 先把契约写死，再写实现 → 集成模式与失败处理 → 联调：把「碰运气」改成「按清单走」」这条链。

## 边界

本章为系统架构与接口实现的教学材料，所述参数与阈值用于演示工程判断方法，不构成对任何系统的性能承诺或合规结论；具体操作以现行规范与所在机构制度为准。
