## 三、逐单元读

### 5.69 基本形式

线性模型（linear model）是机器学习中最基本、应用最广泛的一类模型。它试图学得一个通过属性的线性组合来进行预测的函数，即 f(x) = w₁x₁ + w₂x₂ + … + w_d·x_d + b，其中 x = (x₁; x₂; …; x_d) 是 d 维属性（特征）向量，w = (w₁; w₂; …; w_d) 是各属性对应的权重（weight）向量，b 为偏置（bias）项。写成向量形式即为 f(x) = wᵀx + b。从几何上看，当 d = 1 时该式是一条直线，当 d = 2 时是一个平面，当 d > 2 时则是一个超平面（hyperplane），线性模型学得的正是特征空间中的一个（超）平面，用它来拟合样本点或划分样本类别。权重向量 w 的每个分量直观地表达了对应属性在预测中的重要性：若 wᵢ > 0，说明属性 xᵢ 取值越大、预测值 f(x) 越大，二者正相关；若 wᵢ < 0 则负相关；而 |wᵢ| 越大，说明该属性对预测结果的贡献越显著；偏置 b 则刻画了属性全部为零时模型的基准输出。正是由于模型参数的物理含义清晰，线性模型具有极好的可解释性（interpretability）——这是它区别于许多"黑箱"模型的最大优势，也是它在金融风控、医疗辅助、司法量刑等对可解释性有刚性要求的领域仍被广泛使用的原因。学习线性模型的过程，就是由训练数据确定 w 与 b 的过程：给定训练集 D = {(x₁,y₁), (x₂,y₂), …, (x_m,y_m)}，学得 w 与 b 后，模型即可对新样本做出预测；由于形式简单，线性模型的训练通常非常高效，且其解往往具有解析（闭式）形式，便于理论分析与工程实现。线性模型看似简单，却蕴含着机器学习中一些重要的基本思想：许多功能更为强大的非线性模型都可以在线性模型的基础上，通过引入层级结构（如神经网络把若干个线性模型按层组织、并施加非线性激活函数）或高维特征映射（如支持向量机的核技巧、多项式回归的基函数展开）而得到。因此，线性模型既是学习机器学习的入门模型，也是构建复杂模型的基本构件。

### 5.70 线性回归

线性回归（linear regression）试图学得一个线性模型以尽可能准确地预测实值输出标记。给定数据集 D = {(x₁,y₁), …, (x_m,y_m)}，其中 yᵢ ∈ ℝ。先考虑输入属性只有一个（d = 1）的最简单情形，此时模型为 f(xᵢ) = wxᵢ + b，目标是确定 w 与 b。回归任务最常用的性能度量是均方误差（mean squared error），因此可试图让均方误差最小化，即求解 (w*, b*) = argmin Σᵢ₌₁ᵐ (yᵢ − wxᵢ − b)²。基于均方误差最小化来进行模型求解的方法称为最小二乘法（least squares method），其名称即"最小化误差的平方和"；从几何上看，它使各样本点到拟合直线的竖直距离平方之和最小。求解时分别对 w 和 b 求偏导：∂E(w,b)/∂w = 2(wΣᵢxᵢ² − Σᵢ(yᵢ − b)xᵢ)，∂E(w,b)/∂b = 2(mb − Σᵢ(yᵢ − wxᵢ))，令两式为零，可得闭式解 w = Σᵢ yᵢ(xᵢ − x̄) / (Σᵢ xᵢ² − (Σᵢ xᵢ)²/m)，b = (1/m)Σᵢ(yᵢ − wxᵢ)，其中 x̄ = (1/m)Σᵢxᵢ 为属性 x 的均值。注意到分母 Σᵢxᵢ² − (Σᵢxᵢ)²/m = Σᵢ(xᵢ − x̄)²，只要属性 x 的取值不全相同，分母即严格大于零，解唯一。例如对三点 (1, 2.1)、(2, 3.9)、(3, 6.2) 用上述闭式解拟合直线：x̄ = 2，分子 Σyᵢ(xᵢ − x̄) = 2.1×(−1) + 3.9×0 + 6.2×1 = 4.1，分母 Σ(xᵢ − x̄)² = 2，故 w = 4.1/2 = 2.05；再由 b = (2.1+3.9+6.2)/3 − 2.05×2 ≈ −0.03，得拟合直线 f(x) = 2.05x − 0.03，该直线使三点处的均方误差达到最小。更一般地考虑多元线性回归：设有 d 个属性，模型为 f(xᵢ) = wᵀxᵢ + b。

### 5.71 对数几率回归

上一节的线性回归用于回归任务。若要处理分类任务，只需找一个单调可微函数将分类任务的真实标记 y 与线性回归模型的预测值联系起来。考虑二分类任务，输出标记 y ∈ {0, 1}，而线性回归模型产生的预测值 z = wᵀx + b 是实值，最理想的情形是"单位阶跃函数"（unit-step function）：z < 0 时判为 0（反例）、z > 0 时判为 1（正例）、z = 0 时任意判别。但单位阶跃函数不连续、不可微，不利于后续的求导优化。于是希望找到一个能在一定程度上近似单位阶跃函数的"替代函数"，并希望它单调可微。对数几率函数（logistic function）正是这样一个常用的替代函数：y = 1 / (1 + e^(−z))，它的图像呈 S 形（sigmoid），当 z → +∞ 时 y → 1，当 z → −∞ 时 y → 0，在 z = 0 附近平滑过渡，且处处连续可导。将对数几率函数作为广义线性模型中联系函数的逆代入，令 z = wᵀx + b，得 y = 1 / (1 + e^(−(wᵀx+b)))。将该式变形可得 ln(y/(1−y)) = wᵀx + b。若把 y 视为样本 x 作为正例的可能性，则 1−y 是其作为反例的可能性，两者的比值 y/(1−y) 称为"几率"（odds），反映了 x 作为正例的相对可能性；对几率取对数则得到"对数几率"（log odds，亦称 logit）。由此可见，上式实际上是在用线性回归模型的预测结果去逼近真实标记的对数几率，因此该模型被称为"对数几率回归"（logistic regression，常被译作"逻辑回归"，但"对数几率回归"更贴合其数学本质）。对数几率回归有三个突出优点：其一，它无需事先假设数据分布，直接对分类可能性建模，避免了假设分布不准确所带来的问题；其二，它不是仅预测出"类别"，而是可得到近似概率预测，这对许多需利用概率辅助决策的任务很有用；其三，对率函数是任意阶可导的凸函数，有很好的数学性质，现有的许多数值优化算法都可直接用于求取最优解。

### 5.72 线性判别分析 LDA

线性判别分析（Linear Discriminant Analysis，简称 LDA）是一种经典的线性学习方法，其思想朴素而优美：给定训练集，设法将样例投影到一条直线上，使得同类样例的投影点尽可能接近（类内距离最小）、异类样例的投影点尽可能远离（类间距离最大）；对新的样本点，将其投影到该直线上，再依据投影点的位置判别其所属类别。LDA 在二分类问题上最早由 Fisher 于 1936 年提出，故亦称"Fisher 判别分析"。先考虑二分类情形。给定数据集 D，令 Xᵢ、μᵢ、Σᵢ 分别表示第 i ∈ {0,1} 类示例的集合、均值向量与协方差矩阵。若将数据投影到直线 w 上，则两类样本投影后的中心分别为 wᵀμ₀ 与 wᵀμ₁，投影后的类内"紧凑程度"可用 wᵀΣ₀w + wᵀΣ₁w 度量。要使同类投影点尽可能接近，即令 wᵀΣ₀w + wᵀΣ₁w 尽可能小；要使异类投影点尽可能远离，即令 ‖wᵀμ₀ − wᵀμ₁‖₂² 尽可能大。两者结合，可得最大化目标 J = ‖wᵀμ₀ − wᵀμ₁‖₂² / (wᵀΣ₀w + wᵀΣ₁w) = wᵀS_b w / (wᵀS_w w)，其中定义类内散度矩阵（within-class scatter matrix）S_w = Σ₀ + Σ₁，类间散度矩阵（between-class scatter matrix）S_b = (μ₀−μ₁)(μ₀−μ₁)ᵀ，J 称为广义瑞利商（generalized Rayleigh quotient）。由于分子分母都是关于 w 的二次型，J 的大小与 w 的幅值无关、只与方向有关，故可令 wᵀS_w w = 1，将最大化 J 转化为在约束 wᵀS_w w = 1 下最大化 wᵀS_b w。用拉格朗日乘子法对 w 求导并令其为零，可得 S_b w = λS_w w，即 S_w⁻¹S_b w = λw，说明 w 是矩阵 S_w⁻¹S_b 的特征向量。

### 5.73 多分类学习与类别不平衡

多分类学习的基本思路是"拆解法"：将多分类任务拆分为若干个二分类任务求解，再对预测结果进行集成。经典拆分策略有三种：一对一（One vs. One，简称 OvO）、一对其余（One vs. Rest，简称 OvR）、多对多（Many vs. Many，简称 MvM），其中 OvO 与 OvR 可视作 MvM 的特例。OvO 将 N 个类别两两配对，产生 N(N−1)/2 个二分类任务，每个任务只用两类样本训练一个分类器；测试时，新样本同时提交给所有分类器，得到 N(N−1)/2 个分类结果，最终通过投票产生被预测得最多的类别作为最终分类结果。OvR 每次将一个类的样例作为正例、其余所有类的样例作为负例，训练 N 个分类器；测试时，若仅有一个分类器预测为正类，则对应的类别标记作为最终分类结果；若有多个分类器预测为正类，则通常考察各分类器的预测置信度，选择置信度最大的类别标记作为分类结果。对比二者：OvO 需训练 N(N−1)/2 个分类器，存储与测试时间开销较大，但每个分类器只用两类样本训练，单个分类器的训练时间较短；OvR 只需训练 N 个分类器，总开销较小，但每个分类器都使用全部样本训练。类别很多时，OvO 的总训练时间通常更小，而预测阶段 OvR 更快；两者中的每个二分类器都可采用任意二分类学习算法（如对数几率回归、支持向量机）。MvM 每次将若干个类作为正类、若干个其他类作为负类，正负类的划分由"纠错输出码"（Error Correcting Output Codes，简称 ECOC）编码矩阵决定。ECOC 将每个类别编码为一个码字（codeword）：对 N 个类别、M 个二分类任务，编码矩阵为 N×M 的矩阵，行对应类别、列对应二分类器；二分类器对某类别的输出用 +1/−1 表示正类/负类，三元码还允许 0 表示"忽略该类"，即该分类器不参与此类别的判别。测试时，将新样本在 M 个二分类器上的预测结果组成一个编码，与各类别的码字比较（常用海明距离），取距离最近（或按某种准则最匹配）的类别作为预测结果。

### 5.74 本章小结／阅读材料与延伸

本章围绕线性模型这一最基础、最可解释的模型族展开，六节内容环环相扣、层层递进。3.1 给出线性模型的基本形式 f(x) = wᵀx + b，说明权重向量 w 的每个分量直观表达对应属性的重要性，线性模型因此具有极好的可解释性，且是神经网络、支持向量机、集成学习等非线性模型的基础构件；从几何上看，线性模型学得的正是特征空间中的一个超平面。3.2 针对回归任务，以均方误差为性能度量、用最小二乘法求解线性回归：一元情形推导出闭式解 w = Σyᵢ(xᵢ−x̄)/(Σxᵢ²−(Σxᵢ)²/m)、b = (1/m)Σ(yᵢ−wxᵢ)，多元情形得到矩阵形式的闭式解 ŵ* = (XᵀX)⁻¹Xᵀy，并指出 XᵀX 不满秩时解不唯一、需引入正则化（L1 的 LASSO、L2 的岭回归）；进而通过联系函数 g(·) 推广出广义线性模型 g(y) = wᵀx + b，其中 g(·) = ln(·) 时即对数线性回归。3.3 用单调可微的对数几率函数（sigmoid）替代不连续不可微的单位阶跃函数，把线性模型用于分类，得到对数几率回归：ln(y/(1−y)) = wᵀx + b，即用线性回归逼近真实标记的对数几率；该模型无需假设数据分布、直接对分类可能性建模、输出为概率；参数以极大似然法估计，最小化 ℓ(β) = Σ(−yᵢβᵀx̂ᵢ + ln(1+e^(βᵀx̂ᵢ)))，可用梯度下降、牛顿法等凸优化算法求解。3.4 的线性判别分析从"类内紧凑、类间疏离"出发，定义类内散度矩阵 S_w 与类间散度矩阵 S_b，以最大化广义瑞利商 J = wᵀS_bw/wᵀS_ww 为目标，用拉格朗日乘子法导出二分类判别方向 w = S_w⁻¹(μ₀−μ₁)，多分类情形转化为 S_w⁻¹S_b 的广义特征值问题，将样本投影到至多 N−1 维，兼具分类与监督降维两种用途。

### 5.77 LogisticRegression 证型概率引擎

用 scikit-learn 落地本章 3.3 的对数几率回归作为证型概率引擎：model = LogisticRegression(multi_class='ovr', max_iter=1000, C=1.0)，以四诊特征矩阵 X 与证型标签 y（对齐 ICD-11 证码）拟合；predict_proba 输出各证型概率，取最大者为判别结果，并保留完整概率向量供下游使用。多分类采用 OvR 拆分，即本章 3.5 拆解策略的工程实现：每个证型一个二分类器（该类为正、其余为负），平台维护 N 个分类器与对应权重表；当证型间存在明显嵌套关系时可改用 multi_class='multinomial' 的多项式对数几率回归作为对照实验，记录两者在评估集上的差异并选择更优者。类别不均衡时配合 P2.5 的 SMOTE 过采样，或直接设置 class_weight='balanced' 实现本章 3.6 的再缩放思想；C 为正则化强度的倒数，取值经交叉验证网格搜索确定（如 C ∈ {0.01, 0.1, 1, 10}），防止高维四诊特征下过拟合；solver 默认 lbfgs 即可覆盖多数场景，样本量极大时可换 saga。特征侧：四诊特征须与 BZU 单元的特征字典一致，量化口径（如舌色红=1.0、淡红=0.5）写入特征编码配置并随模型归档，保证权重表可溯源。评估环节：模型上线前必须跑独立评估集，输出准确率、PR-AUC、混淆矩阵并存档，作为版本变更依据；每次重训触发 Kanban 任务卡，训练日志与评估报告随卡流转，审稿通过后方可发布。临床红线：概率仅供辅助参考，不替代医师决策；训练集为病历统计样本，结论一律标注现代认识、统计来源，送 tcmreviewer 审稿后方可进入教学与辅助流程，真实临床仅辅助不决策。特征侧：四诊特征须与 BZU 单元的特征字典一致，量化口径（如舌色红=1.0、淡红=0.5）写入特征编码配置并随模型归档，保证权重表可溯源；连续型特征（如体温、脉率）在训练前做标准化，使权重大小可直接比较。本部分为 hermes-generating-content。

### 5.78 LDA 鉴别诊断投影

对相近证型（如风寒束表 vs 风热犯卫），症状特征高度重叠、人工鉴别困难，本章 3.4 的线性判别分析为此提供了几何化工具。工程落地：model = LinearDiscriminantAnalysis(n_components=1)，用两类（或经 OvO 拆分的两两证型）四诊特征学习判别投影 w = S_w⁻¹(μ₀−μ₁)，把高维特征投影到一维判别轴，可视化呈现鉴别诊断方向——直观显示哪些特征（如舌色红、脉浮数）把两类证型分开；投影坐标分布图可展示两类样本沿判别轴的分离程度，供教学演示与医师复核。核验流程：投影方向与权重表送 tcmreviewer 对照教材口径核验，若某特征权重与中医理论冲突（如恶寒、无汗等寒证特征反而推高风热证概率），打回重训并排查数据质量（标签错标、特征量化错误、样本混杂等）；审稿意见按平台固定格式记录，重要及以上问题须整改后复审。LDA 同时是降维工具：可将 d 维四诊特征降到 1 维用于图表展示，也可降到 2 维在知识图谱可视化面板中观察证型分布簇，帮助学生理解鉴别诊断的几何意义，实现本章 3.4 的教学目标；判别轴上的投影值还可作为新特征输入下游模型（如与 LogisticRegression 概率拼接），提升相近证型区分度。边界口径：投影方向属统计发现，只作教学演示与辅助参考，不构成诊断依据，标注现代认识/统计来源送 tcmreviewer 审稿。可视化输出形式包括：判别轴投影分布图（两类样本沿 w 方向的一维散点与密度曲线）、特征贡献条形图（|wⱼ| 排序展示区分两类证型的关键四诊特征）、以及二维判别平面上的簇分布图（多类情形取前两个判别方向）。判别轴投影值还可回填至病案库作为衍生特征，供 FTS5+向量混合检索的向量索引使用，使"相似病案"的召回同时兼顾四诊特征的判别方向。本部分为 hermes-generating-content。

### 5.79 类别不平衡处理 SMOTE

平台病历库中常见证型样本多、罕见证型样本少，直接训练会严重偏向多数类，对应本章 3.6 的类别不平衡问题。对策有三：① 过采样——from imblearn.over_sampling import SMOTE，对少数类样本在近邻间插值合成新样本后再训练，注意 k_neighbors 参数（默认 5）与特征空间距离度量需与四诊特征编码一致，特征量纲差异大时先标准化；② 再缩放/阈值移动——用 m⁻/m⁺ 修正决策阈值，即公式 y′/(1−y′) = y/(1−y) × (m⁻/m⁺) 的工程实现，或使用 class_weight='balanced' 让算法自动按类频数加权，也可在 predict_proba 之后按平台预设的敏感度档位移动阈值；③ 评估指标改用 PR-AUC、F1 与召回率而非 Accuracy，避免被多数类掩盖，罕见证型的召回率单独报告并设最低门槛（如 ≥0.7 方可发布）。工程要点：SMOTE 合成必须发生在交叉验证的每一折训练集内部，严禁先全局合成再划分，否则会造成数据泄露、评估结果虚高；推荐用 imblearn.pipeline.Pipeline 将 SMOTE 与分类器封装为整体，配合 GridSearchCV 统一调参，网格搜索同样在折内完成合成。安全红线：合成样本属统计构造，须标注现代认识、统计来源并送 tcmreviewer 审稿；合成数据仅用于模型训练与统计教学演示，严禁以合成数据冒充真实临床证据用于教学结论或任何诊疗表述。具体代码路径示例：X_res, y_res = SMOTE(k_neighbors=5, random_state=42).fit_resample(X_train, y_train)，随后以 X_res/y_res 训练分类器；评估集划分按 8:2 比例分层抽样（stratify=y），保证少数类在训练与评估中都有代表性样本。本部分为 hermes-generating-content。
