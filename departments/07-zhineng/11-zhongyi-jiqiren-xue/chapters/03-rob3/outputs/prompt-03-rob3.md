# 决策的难点不是选最优，是错一步还能回头 · 提示词

## 用途

给「决策的难点不是选最优，是错一步还能回头」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「把辨证-调方写成序贯决策，五元组各是什么 → 奖励设计的三种典型错误 → 约束的正确写法：可行域内优化 → 一个小到能手算的 Q 学习算例」这条链。


## 边界

本章为序贯决策与强化学习的教学讨论，不构成诊疗方案、处方建议或临床路径。任何以本章框架构建的决策系统均不得直接输出治疗指令，须经临床验证、伦理审查与主管部门批准；具体操作以现行规范与所在机构制度为准。
