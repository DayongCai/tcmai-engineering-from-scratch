# 能交给机器的是「可参数化的部分」，不是「手法」

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 8 道题自检，答不上就回到对应小节。

## 核心判据

- 可逆性这一条不成立
- 灸疗机器人的核心指标不是「温度控制精度」，是「距离保持精度」
- 可逆性不成立
- 可测量性不成立
- 可参数化部分成立、整体不成立

## 边界

- 本章数值（20 N 在 $4\ \text{cm}^2$ 与 $1\ \text{cm}^2$ 上的 50 kPa 与 200 kPa、灸距平方反比的温升表 18.0/8.0/4.5/2.9 °C）均为**演算设定**，用于演示敏感度关系，不对应任何实测设备或临床观察。
- 灸疗的平方反比模型是点源近似，实际包含对流、传导、灰烬遮挡与灸材燃烧速率变化，真实温升分布与上表有偏差；表中数值只能用于说明「距离是最敏感变量」这一定性结论。
- 手法分类与「可自动化」判定基于工程判据，不涉及任何手法的临床有效性；某手法是否应当被自动化，还须经临床、伦理与监管三方评估。
- 本章为中医手法与机器人边界的教学讨论，不构成诊疗建议、疗效声明或医疗器械注册意见。文中对手法的可行性判定仅为工程视角的分析，任何设备的适用范围须以注册批准的内容为准，任何治疗须由具备资质的人员实施。
