# 安全不是「不出故障」，是故障之后朝哪个方向倒 · 提示词

## 用途

给「安全不是「不出故障」，是故障之后朝哪个方向倒」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「先把失效模式列全，再谈措施 → 停止类别：三种停法，用在三个地方 → 把延迟预算拆开：安全是毫秒堆出来的 → 冗余的两个陷阱」这条链。

## 边界

本章为功能安全与失效处理的教学讨论，不构成安全标准、设计规范或合规意见。任何医疗机器人系统的安全论证须由具备资质的机构按现行法规完成，不得以本章的示例清单代替正式的风险分析；具体操作以现行规范与所在机构制度为准。
