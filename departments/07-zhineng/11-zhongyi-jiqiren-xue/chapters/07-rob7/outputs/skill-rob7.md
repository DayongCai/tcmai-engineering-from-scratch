# 安全不是「不出故障」，是故障之后朝哪个方向倒

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 执行侧必须假设上游会给错东西
- 能量怎么处理
- 机械臂失去支撑，压在人体上的重量全部由人体承担
- 可能已造成伤害
- 通信或软件异常
- 滤波窗是「信号干净」与「反应快」之间的直接对价

## 边界

- 本章数值（100 ms 延迟预算各项、20 ms 滤波窗、25 Hz 截止、抱闸 35 ms）均为**演算设定**，用于演示延迟的构成与取舍，不对应任何实测设备。
- 停止类别与冗余的讨论只到概念层，不引用具体标准的条款；实际设备的安全等级、验证方法与文件要求须按现行医疗器械法规与相关标准执行。
- FMEA 表中的失效模式是示例性清单，不是完整清单；完整分析须针对具体机构、具体传感器与具体软件架构逐项展开。
- 本章为功能安全与失效处理的教学讨论，不构成安全标准、设计规范或合规意见。任何医疗机器人系统的安全论证须由具备资质的机构按现行法规完成，不得以本章的示例清单代替正式的风险分析。
