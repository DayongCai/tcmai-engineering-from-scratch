# 第 3 章 · 十问筛成六快：一次由「可测性」主导的裁剪

> **MOTTO:** 「一问寒热二问汗，三问头身四问便，五问饮食六问胸，七聋八渴俱当辨，九因脉色察阴阳，十从气味章神见。」——《景岳全书·传忠录·十问篇》（张景岳）
>
> **PROBLEM:** 十问十项，能被设备连续采到的只有两项——饮食与二便。六快六项里，真正接住十问的也就这两项半；另三件（喝、睡、警觉）在十问里没有独立一问，或只有一个主观的「渴」。也就是说，这一行的问诊骨架**四分之三来自新增需求，只有四分之一接住了十问**。接不住的八项里，寒热与汗排在最前面——寒热是八纲里辨阴阳的主要依据，汗是辨表虚表实的关键。

**双根因定位:** 环境逼迫（连续监测只能落在「每天都会发生、有物理痕迹」的事上；寒热汗渴没有稳定的物理痕迹，只能靠人自己说）+ 知识积累（六件里真正能自动采的只有三件，另三件仍以自评为主；「自动评价」这个名字掩盖了这个比例）

## 一、六快是从可穿戴反推出来的，不是从十问剪出来的

先把这件事说清，后面的判断才不会偏。

十问的顺序是临床权重：寒热、汗、头身、二便、饮食、胸、聋、渴，最后落到脉色与气味。它回答的是「一个初诊患者，医生该按什么次序把信息问全」。

六快的顺序是工程可行性：吃、喝、拉、撒、睡、警觉安全。它回答的是「一个人每天都会做、且做的时候会留下物理痕迹的事有哪几件」。

两者只有部分重叠。吃对应饮食，拉撒对应二便，睡在十问里没有独立一问（失眠、多寐散在问诊各处），警觉安全则完全是新增项——它不来自中医问诊，来自跌倒检测这个老年照护的真实需求。反过来，寒热、汗、胸、聋、渴五项在十问里位置靠前，在六快里一个也没有，因为它们没有稳定的物理痕迹：怕冷是感受，出汗量难以连续计量，胸闷是主观位置，耳鸣与口渴更没有可穿戴的对应物。

所以六快的位置要摆正：**它是「可连续采集的问诊最小集」，不是「问诊的现代版」**。把它当成完整问诊来用，丢掉的是八纲里最先要用到的两组信息。承认这一点，六快的评分才有边界——它能反映行为与功能的偏离，不能替代一次真正的问诊。

## 二、六快 × 四元：一半的格子要靠人填

把六件放到第一章的四元里，得到的矩阵有一半是空的，而空的那一半正好说明了「自动」到什么程度。

| 快 | 能自动测的 | 手段 | 测不到的 |
|---|---|---|---|
| 吃 | 餐次、进食时长、咀嚼节律 | 加速度、进食图像 | 吃了什么、多少、寒热属性 |
| 喝 | 摄入容量或重量、饮水动作 | 称重杯、皮电 | 渴与不渴 |
| 拉 | 频次（需人记） | 自评、腹部体动 | 形态、性状（需量表） |
| 撒 | 尿量、频次（部分场景） | 称重、夜尿记录 | 与睡眠分期的混淆 |
| 睡 | 入睡与觉醒时刻、分期 | 加速度 + 心率 + 皮温 | 入睡潜伏期、梦多、睡不解乏 |
| 警觉安全 | 跌倒、步态、体位 | 加速度、定位 | 头晕先兆、站立不稳的主观感 |

一眼能看出：真正不需要人动手的只有吃（部分）、睡、警觉三项；喝要靠称重或自评，拉撒几乎全靠人记。**「健康自动评价」里的「自动」，覆盖的是采集链路，不是信息完整性。**

再看「吃」这一格测不到的第一项：吃了什么。一碗冰粥和一碗热粥，加速度曲线可以完全一致，但对脾胃的意义相反。这一格的空白不是传感器不够好，是「食物的寒热属性」这个变量根本不在物理量空间里。工程上只能退一步——让用户选一次餐型，把标签附在信号上。这就是为什么所有可穿戴健康评价最后都会退化成一个「设备 + 问卷」的混合体：设备的强项是频次与连续性，问卷的强项是属性与主观感受，两者缺一不可。

## 三、评分口径：三条不能破的规矩

一套评分只要破了下面前三条里的任何一条，结果就不能进任何比较。

**第一条，缺数据不猜。** 某一维没有数据，就标为缺失，不计入总分，同时报出覆盖率（六维里采到几维）。用均值填补、用上一日外推、用模型预测，都会让「没测」在报告上看起来像「正常」——这是健康类产品最常见也最危险的错误。覆盖率本身要作为一等指标出现在报告首页，因为它直接决定这个分数有多少解释力。

**第二条，同输入必得同输出。** 评分不能带随机初始化、不能带与时间相关的漂移、不能因为服务器换了版本就变。这一条听起来是工程洁癖，实际是可比性的前提：患者上个月 82 分、这个月 78 分，如果算法中间改过一次，这两个数就不能相减。

**第三条，边界声明与分数同时输出，不能放进附录。** 「本评分用于自我记录与教学，不构成医学诊断」这句话，必须和分数在同一屏。放在使用条款第 8 条里等于没写。

第四条是给阈值定的：每一个区间的来源都要写明——是人群统计的分位、是指南给的界，还是设计者定的示范值。三者效力完全不同。示范值可以用于教学演示，不能用于给一个人下结论。

## 四、从分数到证候：这条链上设备只走到第二步

「象—素—候—证」四阶（智能中医学的框架提法，本课程按教学需要重述），放到设备侧是这样的：

**象**是可观测的原始表现——波形、图像、体动记录。**素**是从象里提出来、可计算的要素——心率变异指标、脉象参数、舌色差、六快计数。**候**是要素的组合模式，即证候单元。**证**是判定结论，必须由医师确认。

设备层的工作在「象」上是全部的，在「素」上是全部的，在「候」上只是一部分——它能给出候选集与支持度，不能给出唯一结论；到了「证」，设备层的工作已经结束。

原因在映射的基数上。「素」到「候」是多对多：同一组要素可以见于多个候（舌淡、脉弱、乏力，可以是气虚，也可以是阳虚的早期，还可以是湿困），同一个候在不同人身上的要素组合又各不相同。多对多的映射没法用一次标注学出来，只能给候选集，让人在候选集上做减法。

这一点对产品设计有直接影响：输出「您的体质偏气虚」是一个结论，输出「气虚方向的支持度 0.62，阳虚方向 0.41，建议结合问诊与舌脉复核」是一个提示。前者越界，后者可用。

## 五、评分工具本身也要被评价

一个给出 0 到 100 分的工具，本身就是一份量表，就要按量表的标准被检验。四件事缺一不可。

**信度**：同一个人、同一状态、隔一天再测，分数应当接近。这件事对可穿戴尤其难，因为数据本身每天在变（今天走了八千步，昨天三千），所以信度检验要区分「状态变化」与「测量噪声」——通常做法是让受试者在标准化的一天里重复测量，或者用同一段已录数据重跑两遍看是否同分。后者只能验证算法确定性，验证不了采集的一致性。

**效度**：内容效度看六维是否覆盖了要评的东西（前面已经说过它不覆盖寒热汗渴）；效标效度看分数与一个公认的外部标准是否同向；结构效度看六维之间是不是真的分成六个维度——如果吃、喝、睡三项高度相关，那它们可能只是在共同反映「这个人有没有规律作息」这一件事，六个维度实际不到六个。

**反应度**：能不能测出变化。一个区分度很好的工具，可能在干预前后给出几乎相同的分数，那就没有随访价值。检验办法是看干预前后的分数变化量是否大于测量噪声，这个比值就是常说的「最小可检测变化」。

**地板与天花板**：分数堆在 100 附近，说明区间设得太宽，人人都满分，分辨力全丢；堆在 0 附近则说明阈值过严。两种情况下这个工具都只能用来「打勾」，不能用来比较。

这四条做不做，决定了一份评分是产品功能还是测量工具。差别在于：产品功能可以靠迭代改善体验，测量工具一旦变了口径，历史上所有分数就作废。

## 六、场景、工作流与那个必须报的终点

四种典型场景，各自的价值点不同。**心律失常筛查**（动态心电、贴片）的价值是捕捉阵发性事件，对应中医「心悸、怔忡」这一类症状的客观化与随访。**慢病管理**（手环加电子问卷）的价值是体质与证候的动态追踪，把一次辨证变成一条曲线。**治未病**的价值是把「未病先防」从一句理念变成可量化的偏离度。**名医经验数字化**的价值是把手法与判读过程留下来，让经验可传。

工作流只有一条，顺序不能改：采集 → 质控 → 特征 → 提示 → 医师复核 → 记录。算法只进入「提示」这一格，「判断」与「签字」两格永远留给人。

评价这一类产品时，最容易犯的错是只报算法指标。AUC 0.9 说明的是模型在给定数据集上的分辨能力，不说明它在真实人群里有用。要报的终点有三类：**临床终点**（例如阵发性房颤的检出率，且必须同时报监测时长分布——七天比二十四小时能多检出，不报时长就没法比较）；**与金标准的一致性**（十二导联心电、医师判读，用 Kappa 或 Bland-Altman，不是相关系数）；**可用性终点**（依从率、有效监测时长占比、脱落原因）。第三类最容易被省略，却决定了前两类在一个真实人群里能不能实现。

## 七、代价与边界

六快是教学用的归并，不是行业标准分类；评分区间是示范口径，不是临床参考值。任何以六快为基础的结论都要服从第一章那条红线：设备给提示，人做判断。

本章对十问的裁剪分析是一次数量的对照，不含对任何问诊流派的价值评判。寒热汗渴在临床上并没有因为「测不到」而降权，恰恰相反——它们仍是八纲辨证里最先要用的一组信息，这一行至今没有好的采集手段，是这一行的缺口，不是中医的缺口。
