# kappa 高不代表系统对，只代表它像那位医生 · 提示词

## 用途

给「kappa 高不代表系统对，只代表它像那位医生」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「先测噪声底：医生之间的一致 → kappa 扣掉了什么 → kappa 悖论与替代指标 → 一致不等于正确」这条链。

## 边界

本章讨论一致性评估的方法与局限，不构成诊断或治疗建议。涉及人的评估须经伦理审查，评估设计应由临床与统计人员共同确定；具体操作以现行规范与所在机构制度为准。
