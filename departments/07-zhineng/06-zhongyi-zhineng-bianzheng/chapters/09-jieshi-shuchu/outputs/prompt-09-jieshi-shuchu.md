# 解释不是附赠的一段话，是可被反驳的证据链 · 提示词

## 用途

给「解释不是附赠的一段话，是可被反驳的证据链」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三种解释，不要混着给 → 证据链的结构：来源、时间、强度、关系 → 归因方法的失真 → 反事实：更接近医生的思维」这条链。

## 提示词

```
我在学《中医智能辨证系统》第 9 章「解释不是附赠的一段话，是可被反驳的证据链」，本章 5 节 / 2,754 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - ：症状、体征、舌脉的具体内容
   - ：患者自述、医生观察、家属代述、检查报告、既往病历
   - ：本次就诊、本次病程内、既往史
   - ：直接观察、转述、推断
   - 只列支持项的解释是宣传，不是解释
   - 注意力不是解释
4. 本章自陈的边界（不得越过）：
   - **解释增加认知负担。** 每条结论配五条证据，医生会跳过。解释需要分层：默认一句判据摘要，展开才看证据链。
   - **解释会助长过度信任。** 一段流畅的理由会让医生高估系统可靠性，这叫解释性幻觉。解释越像人话，越要提示它的来源是模型而非医理。
   - **解释不能替代验证。** 能说清理由的系统仍然可能是错的，理由本身也可能是事后编的。解释是审计工具，不是正确性证明。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章讨论可解释输出的设计方法，不构成诊断或治疗建议。解释字段与证据来源的规范须经所在机构中医专家与信息管理部门审定；具体操作以现行规范与所在机构制度为准。
