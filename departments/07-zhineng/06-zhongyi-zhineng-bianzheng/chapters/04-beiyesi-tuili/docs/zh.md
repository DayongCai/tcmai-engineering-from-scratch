## 三、逐单元读

### 4.57 贝叶斯决策论

在机器学习所面对的许多问题中，决策都必须在不确定条件下做出：面对一个样本 x，它最可能属于哪个类别？不同类别的判断失误造成的后果是否相同？贝叶斯决策论（Bayesian Decision Theory）在概率框架下给出了这类问题的最优答案，是整个第 7 章的理论基石。设样本空间上有 N 个类别 c₁, c₂, …, c_N，对样本 x，我们用后验概率 P(c|x) 刻画"给定 x 时它属于类别 c"的不确定性。贝叶斯决策论的核心思想是：分类错误的代价可能因类别而异，因此决策应当使期望损失——即风险（risk）——最小化，而不是简单追求"猜对的次数最多"。 先引入损失（loss）的概念。设 λᵢⱼ 表示把一个真实类别为 cⱼ 的样本误判为类别 cᵢ 所产生的损失；一般约定 λᵢᵢ = 0，即判断正确不产生损失，而 λᵢⱼ（i ≠ j）为正值。将样本 x 判为 cᵢ 所产生的期望损失称为条件风险（conditional risk），其定义为对各类别真实后验的加权和：R(cᵢ|x) = Σⱼ λᵢⱼ·P(cⱼ|x)，其中求和遍及全部 N 个类别。若记分类器 h 在样本空间上的总体风险为 R(h) = Eₓ[R(h(x)|x)]，即条件风险关于样本分布的期望，那么贝叶斯判定准则（Bayesian decision rule）要求对每个样本选择使条件风险最小的类别：h*(x) = argmin_{c∈Y} R(c|x)，其中 Y 为类别集合。满足该准则的分类器 h* 称为贝叶斯最优分类器（Bayes optimal classifier），其总体风险 R(h*) 称为贝叶斯风险（Bayes risk）。贝叶斯风险对应的分类精度是所有基于同一数据分布的模型都无法超越的理论上限，它为机器学习算法的性能评估提供了"天花板"式的参照。 在分类任务中最常用的损失是 0-1 损失（0/1 loss）：λᵢⱼ = 0（当 i = j，即判断正确）；λᵢⱼ = 1（当 i ≠ j，即判断错误）。

### 4.58 极大似然估计

在 7.1 节我们看到，贝叶斯分类器的关键在于估计类条件概率 P(x|c)。当属性为连续值或取值空间很大时，直接按频率计数不可行，一个自然的思路是假设 P(x|c) 服从某种已知形式的概率分布，把"估计整个分布"转化为"估计分布的一小组参数"，这就是参数估计（parametric estimation）的思想。极大似然估计（Maximum Likelihood Estimation，MLE）是其中最经典的方法，其哲学立场属于频率学派（frequentist）：认为参数 θ 是客观存在但未知的常数，最优的参数应使"观测到当前训练数据"这件事的概率最大。与之相对，贝叶斯学派（Bayesian）把参数本身视为随机变量，并引入先验分布来刻画对其取值的事先信念，其最大后验（MAP）估计可以看作 MLE 加上先验后的推广——两个学派的差异详见后文讨论。 设类别 c 的样本集为 D_c = {x₁, x₂, …, x_m}，并假设样本独立同分布（i.i.d.），且类条件概率 P(x|c) 具有确定的分布形式，其参数向量记为 θ_c，则似然函数（likelihood function）定义为各样本似然之积：L(θ_c) = Π_{i=1}^{m} P(xᵢ|θ_c)。极大似然估计即求使似然最大的参数：θ̂_c = argmax_θ L(θ_c)。由于连乘容易造成数值下溢，且乘积的对数是参数的更易处理的函数，实践中通常最大化对数似然（log-likelihood）：LL(θ_c) = log L(θ_c) = Σ_{i=1}^{m} log P(xᵢ|θ_c)。因为对数函数单调递增，最大化 L 与最大化 LL 等价。标准求解步骤为：第一步，根据对问题的认识选定分布形式（如正态分布、多项式分布）；第二步，写出似然函数并对数化；第三步，对参数求偏导并令导数为零，解方程组得到参数的估计值；当方程无解析解时，可借助梯度上升等数值优化方法。MLE 的直观理解是：在候选参数中，使已观测数据出现概率最大的那个参数，就是最合理的估计。 以最常用的单变量正态分布 N(μ, σ²) 为例给出完整推导。

### 4.59 朴素贝叶斯分类器

7.2 节的参数化方法只解决了"分布形式已知"时的估计问题。当属性维度 d 很高时，即便假设每个属性服从某种分布，要估计的联合分布 P(x|c) 仍然复杂得不可操作：属性取值的组合数随 d 指数增长，训练样本永远不够覆盖所有组合。朴素贝叶斯分类器（Naive Bayes classifier）用一个大胆而有效的假设化解了这一难题——属性条件独立假设（attribute conditional independence assumption）：对已知类别，假设所有属性相互独立，即 P(x|c) = Π_{i=1}^{d} P(xᵢ|c)。这一假设把 d 维联合分布的估计分解为 d 个一维分布的估计，从根本上回避了高维稀疏与组合爆炸问题。基于该假设，结合贝叶斯公式，判定准则为：h_nb(x) = argmax_{c∈Y} P(c)·Π_{i=1}^{d} P(xᵢ|c)。注意分母 P(x) 对各类别相同，可略去；分子中的 P(c) 与各 P(xᵢ|c) 分别用训练数据估计。其中离散属性可直接用样本频数估计 P(xᵢ|c)，连续属性则如 7.2 节所述，假设服从正态分布并用极大似然估计均值与方差。 下面用原书例 7.1 完整演示计算流程。训练数据为感冒证候数据集（40 份病历，18 份风寒证、22 份风热证），待判测试样例"测1"为：恶寒=重，汗出=无，脉象=浮紧，舌象=淡红苔薄白，发热=轻，咽部=不红，体温=37.5℃，脉率=72次/分。先估先验：P(风寒证) = 18/40 = 0.45，P(风热证) = 22/40 = 0.55。

### 4.60 半朴素贝叶斯

朴素贝叶斯的属性条件独立假设虽然有效，但在属性间存在明显依赖时过于"朴素"，会引入系统性偏差。完全放弃独立性假设又回到 7.1 节指出的高维估计困境。半朴素贝叶斯分类器（Semi-Naive Bayes classifiers）在两者之间取折中：允许每个属性最多依赖一个其他属性，称为独依赖估计（One-Dependent Estimator，ODE），其一般形式为 P(c|x) ∝ P(c)·Π_{i=1}^{d} P(xᵢ|c, xⱼ)，即把朴素贝叶斯中的 P(xᵢ|c) 换成给定类别与另一个属性 xⱼ 的条件概率。问题的关键变成"每个属性应该依赖哪个属性"，不同的选择策略产生了不同的代表方法。 SPODE（Super-Parent ODE，超父独依赖估计）是最简单的方案：假设所有属性都依赖同一个"超父"（super-parent）属性 x_p，即 P(c|x) ∝ P(c)·Π_{i=1}^{d} P(xᵢ|c, x_p)。超父的选择可通过交叉验证、模型选择或似然比较来确定，一旦选定，估计 P(xᵢ|c, x_p) 只需在 (类别, 超父取值) 分组的样本上做一维统计，代价依然很低。用一个数字例子说明 SPODE 的计算（演示数值）：仍用感冒证候数据集，测试样例同 7.3 节（恶寒=重，汗出=无，脉象=浮紧，舌象=淡红苔薄白，发热=轻，咽部=不红），选取"脉象"为超父。对风寒证：P(风寒证) = 18/40，P(脉象=浮紧|风寒证) = 12/18；风寒证中脉浮紧的样本共 12 份，其中 P(恶寒=重|风寒证,浮紧) = 8/12，P(汗出=无|风寒证,浮紧) = 9/12，P(舌象=淡红苔薄白|风寒证,浮紧) = 10/12，P(发热=轻|风寒证,浮紧) = 7/12，P(咽部=不红|风寒证,浮紧) = 9/12，乘积得 (18/40)×(12/18)×(8/12)×(9/12)×(10/12)×(7/12)×(9/12) ≈ 0.0128。

### 4.61 贝叶斯网

半朴素贝叶斯只允许每个属性依赖一个其他属性，仍是对真实依赖结构的粗糙近似。贝叶斯网（Bayesian network），又称信念网（belief network），用有向无环图（Directed Acyclic Graph，DAG）与条件概率表（Conditional Probability Table，CPT）的组合，显式地刻画变量之间任意复杂的依赖与独立关系。一个贝叶斯网 B = ⟨G, Θ⟩ 由两部分构成：结构 G 是一个 DAG，节点对应属性或随机变量，有向边表示依赖关系——若存在边 X→Y，则 X 是 Y 的父节点，表示 X 直接影响 Y；参数 Θ 为每个节点附一张条件概率表，记录该节点在其父节点各种取值组合下的条件概率 P(节点|父节点)，量化依赖的强度。贝叶斯网定义了属性集上的联合概率分布：P(x₁, x₂, …, x_d) = Π_{i=1}^{d} P(xᵢ | πᵢ)，其中 πᵢ 为节点 xᵢ 的父节点集合。可见，给定结构后，联合分布被分解为每个节点一个局部条件分布之积，参数总数从指数级降为各节点参数之和，这正是贝叶斯网能处理高维问题的根源。 贝叶斯网的核心价值在于用图的结构直接编码条件独立性。三类基本结构决定了独立性的三种典型模式。其一为同父结构（common parent）：X→Y 且 X→Z，给定父节点 X 后，Y 与 Z 条件独立，即 P(Y, Z|X) = P(Y|X)·P(Z|X)，因为 Y 与 Z 的信息全部经由 X 传递。其二为顺序结构（chain）：X→Y→Z，给定中间变量 Y 后，两端变量 X 与 Z 条件独立，即 P(X, Z|Y) = P(X|Y)·P(Z|Y)。其三为 V 型结构（V-structure），又称冲撞结构（collider）：X→Y←Z，此时 X 与 Z 在边际上独立（两者之间没有通路），但给定冲撞节点 Y 之后，X 与 Z 反而产生依赖——这是因果推断中"解释"（explaining away）效应的来源：例如"下雨"与"洒水器"都会导致"地面湿"，若已知地面湿且没有下雨，则更可能是洒水器所致。

### 4.62 EM算法

前几节的参数估计都假设所有变量可观测，但现实中常存在隐变量（latent variable），即未被观测到的变量：混合高斯模型中每个样本来自哪个高斯分量未知；隐马尔可夫模型中隐状态序列未知；临床数据中部分检查结果缺失。此时直接做极大似然估计会遇到本质困难。以混合高斯模型（GMM）为例，样本由 K 个高斯分量按比例混合生成，每个样本 x 对应的分量标记 z ∈ {1, …, K} 是隐变量，完整数据为 (x, z)。对数似然为 LL(θ) = Σ_{i} log P(xᵢ; θ) = Σ_{i} log Σ_{z} P(xᵢ, z; θ)。问题在于：对隐变量的求和位于对数函数内部，导致对数里是混合分布，无法像 7.2 节那样通过对数把乘积化为求和再求导，直接求导得到的方程通常没有解析解。 EM 算法（Expectation-Maximization algorithm）通过迭代巧妙地绕开这一困难。它维护当前参数 θ^t，每轮迭代包含两步。E 步（Expectation，期望步）：以当前参数 θ^t 计算隐变量 z 的后验分布 P(z|x, θ^t)（即每个样本属于各分量的"责任"），并据此构造 Q 函数——完整数据对数似然在隐变量后验分布下的期望：Q(θ|θ^t) = Σ_{z} P(z|x, θ^t)·log P(x, z; θ) = E_{z|x, θ^t}[log P(x, z; θ)]。M 步（Maximization，最大化步）：最大化 Q 函数得到新参数 θ^{t+1} = argmax_θ Q(θ|θ^t)。两步交替进行，直至参数或似然的变化小于阈值即收敛。直观理解：E 步相当于在"隐变量取值未知"的情况下，用当前模型猜测隐变量的概率分布，把不完全数据"补全"为软划分；M 步则基于补全后的完整数据做一次普通的最大似然更新。由于 Q 函数的结构与完整数据的似然一致，M 步往往有闭式解，例如 GMM 中新的分量均值就是各样本按责任加权的均值。 EM 的收敛性有理论保证。

### 4.63 本章小结

本章围绕"用概率描述与消解不确定性"这一主题展开，给出了从理论到算法的完整贝叶斯分类图景。7.1 节贝叶斯决策论确立了分类的黄金标准：引入损失 λᵢⱼ 与条件风险 R(c|x) = Σⱼλᵢⱼ·P(cⱼ|x)，在 0-1 损失下最小化风险等价于最大化后验概率，得到贝叶斯最优分类器 h*(x) = argmax_c P(c|x)，其贝叶斯误差率是任何分类器不可超越的理论下界，从而把学习的任务归结为估计 P(c|x)。围绕"如何估计类条件概率"这一难点，本章给出了一条层层递进的求解路线：7.2 节极大似然估计假设 P(x|c) 具有确定的分布形式，用对数似然 LL(θ_c) = Σ log P(xᵢ|θ_c) 估计参数，正态分布下得到样本均值与样本方差；7.3 节朴素贝叶斯以属性条件独立假设 P(x|c) = ΠP(xᵢ|c) 把高维联合分布分解为一维统计，配合拉普拉斯修正消除零概率，简单而稳健，四诊辨证例展示了从频数到判决的完整计算；7.4 节半朴素贝叶斯放松完全独立假设，以独依赖估计（SPODE/TAN/AODE）在可行性与表达力之间折中；7.5 节贝叶斯网用 DAG+CPT 显式建模任意依赖结构，D-分离准则在图上直接判定条件独立性，学习分为评分搜索式的结构学习与极大似然式的参数学习，推断有变量消去与吉布斯采样等算法；7.6 节 EM 算法以 E/M 两步迭代求解含隐变量的似然最大化，对数似然单调不减保证收敛，但需警惕局部最优。这六节形成一个自洽的整体：贝叶斯决策论给出目标，极大似然给出参数估计工具，朴素贝叶斯、半朴素贝叶斯、贝叶斯网依次以越来越精细的结构逼近真实的类条件概率，EM 则补齐了隐变量场景。 贝叶斯框架还有两个贯穿全章的优势。其一是天然支持先验知识注入：先验概率 P(c) 可以来自数据频率，也可以来自领域知识或历史经验，7.2 节的 MAP 估计、7.5 节贝叶斯网的 CPT 都是先验发挥作用的载体。

### 4.64 平台映射：贝叶斯辨证推理

tcmP 将中医辨证建模为贝叶斯决策问题，与 7.1 节的框架逐项对应：证型即类别 c（如太阳病、少阳病、脾气虚等，取自病证单元库 BZU 的 BZ-B<病>-Z<证> 编码体系）；四诊信息即属性 x（望诊之舌象、面色，闻诊之声息，问诊之症状，切诊之脉象，以及体温、心率等量化指标）；辨证结论 = 后验 P(证型|四诊) = P(证型)·P(四诊|证型)/P(四诊)，其中 P(证型) 为先验概率，P(四诊|证型) 为类条件概率，P(四诊) 为归一化证据因子（比较各证型时可省略）。在 0-1 损失（辨证结论正确与否）下，最优决策即取后验最大的证型，对应贝叶斯最优分类器。平台落地以 sklearn.naive_bayes 为基线：GaussianNB 处理脉率、体温、血压等连续型四诊特征；MultinomialNB 处理症状频次类特征；BernoulliNB 处理"有无某症状/某舌象"的 0-1 标签，三者分别对应 7.3 节离散属性与连续属性的两种估计方式。训练数据来自病证单元库（BZU）与已由主编/专家标注的医案库，输出为"证型概率分布 + 置信度（最大后验与次大后验的差距或熵）"，供辨证引擎排序候选证型，再交主编口径规则过滤与 tcmreviewer 审稿确认后生成结论。属性条件独立假设在四诊之间近似成立——给定证型后舌象与脉象大体独立（这与 7.3 节"独立性不成立也常表现良好"的经验一致），使朴素贝叶斯计算快、可解释、适合教学与临床辅助基线；但四诊并非完全独立（如舌淡胖与齿痕常同现），故真实临床仅辅助不决策，最终判断权在医师，全部统计结论标注"统计来源，送 tcmreviewer 审稿"。

*单元规模：462 汉字；出处 `教材·第7章·7.8`；本单元数值类命中 0。*

### 4.65 平台配置接口-安装依赖

### 4.66 先验=教材权重，后验=辨证结论（双轨）

tcmP 特色机制：先验概率 P(证型) 双轨注入，把 7.1 节"先验"这一抽象概念变成可操作实验。教学轨：先验 = 教材章节权重——如《伤寒论讲义》太阳病篇学时最多、属辨证教学重点，按主编口径设定 P(太阳病) 偏高，引导教学聚焦重点证型；临床轨：先验 = 医案库证型频率——按真实门诊医案统计各类证型占比，反映临床实际分布（如某地区脾胃系证候占比更高）。同一组四诊输入分别用两轨先验计算后验 P(证型|四诊) = P(证型)·P(四诊|证型)/P(四诊)，输出并排对比视图，直观展示"先验选择如何影响辨证结论"：教学先验下可能偏向太阳病，临床先验下可能偏向少阳病，后验差异即先验影响的量化体现。此设计同时体现非零和原则——教学导向与临床导向并存、互不否定，学生通过对比理解先验与后验的关系、体会贝叶斯公式中"信念更新"的含义。先验注入接口：POST /api/bianzheng/prior?mode=textbook|clinic，参数（各证型权重表）存平台配置库，修改留痕可回滚；与知识图谱层、FTS5+向量混合检索的病案检索联动，支持"取相似医案的证型分布作为动态先验"的扩展实验。所有频率统计一律标注"统计来源，送 tcmreviewer 审稿"，先验只影响排序不直接决策，真实临床仅辅助不决策。进阶实验：在对比视图中叠加量化指标——计算两轨后验分布的差异（如 KL 散度或最大后验差），当差异超过阈值时提示"先验主导了结论"，引导学生反思：若教学先验与临床先验结论相左，应以临床证据与教材条文双重核对（送 tcmreviewer 审稿）后再定夺，这正是贝叶斯框架下"先验可辩驳、数据可更新"的直观体现。

*单元规模：510 汉字；出处 `教材·第7章·7.10`；本单元数值类命中 0。*

### 4.67 贝叶斯网=证候因果知识图谱（pgmpy）

贝叶斯网 DAG 与 tcmP 知识图谱同构：病→证→法→方→药构成因果依赖链，节点 = 证候/治法/方剂，边 = 中医病机因果，CPT 量化"某证型下某症状出现的概率"（对应 7.5 节 P(xᵢ|πᵢ)）。平台实践分四步：1）用 pgmpy 的 HillClimbSearch 从标注医案学习结构，scoring_method 选 bic 防止学出过拟合网络（对应 7.5 节 BIC 评分 s(B|D) = LL(B|D) − (log m/2)·|B|）；2）BayesianEstimator 参数学习填充 CPT，并以拉普拉斯修正避免零概率；3）与 ICD-11 术语库、病证单元库的人工知识图谱对照——一致处验证教材理论，差异处触发审稿：AI 学到的依赖关系必须能溯源教材条文，否则标注"现代认识/统计结果，不改经典原义"，送 tcmreviewer（学术审稿）与 aireviewer（智能审稿）双审通过后方可入库；4）利用 D-分离回答教学问题，如"给定'舌淡胖'后，'脉沉细'与'便溏'是否条件独立"，支撑病机推理演示——这正是 7.5 节 D-分离准则的活学活用。产出证候因果图谱 JSON（节点/边/CPT/审稿状态），登记入平台建设与依赖 sheet，作为病证单元库的概率增强层；图谱新增边必须走审稿流程，与 7.5 节理论一一对应，形成"从数据学到结构、从条文验证结构、从结构回答问题"的闭环。教学辅助：将 CPT 导出为"证-症概率表"（行=证型，列=症状/舌脉象，单元格=条件概率），在辨证实验台上以热力图展示，学生可直接读出"某证型下某症状的出现概率"，把 7.5 节条件概率表的抽象概念可视化。

### 4.68 EM-缺失四诊补全

临床病历常缺四诊记录（未采集舌象、脉象缺项、问诊遗漏等），直接丢弃缺失样本浪费信息且引入选择偏差。tcmP 以 EM 算法处理（对应 7.6 节）：将缺失四诊变量视为隐变量 z，E 步用当前辨证参数 θ^t 推断缺失项的期望分布（责任 γ = P(z|x_obs, θ^t)，即"最可能的舌象分布"），构造 Q 函数；M 步用"补全"后的完整样本重新估计 P(证型) 与 P(四诊|证型)，迭代至似然收敛，输出补全值及"补全置信度"。落地方式：sklearn 的 GaussianMixture 即 EM 实现，可直接拟合含缺失特征的数据；教学演示则按 7.6 节公式自实现 E/M 迭代（E 步计算责任、M 步加权更新），代码随本章实践附出，并演示初值敏感性——多次随机初始化、保留对数似然最大的结果。质检红线：补全置信度低于阈值的病历不进入教材案例库与模型训练集，仅作推理参考；补全结果一律标注"EM 估计"字样，与真实采集四诊严格区分，防止教材案例失真、防止把模型猜测当成临床事实。该实践同时演示了 7.6 节的局部最优风险与缓解手段，并显著提升信息利用率——相比直接丢弃缺失样本，EM 补全后的训练集更完整，辨证模型在低完整度病历上的表现更稳（统计来源，送 tcmreviewer 审稿）。真实临床仅辅助不决策：EM 补全值仅供医师参考，不作为辨证依据单独呈现。教学对照实验：同一份含缺失病历，一组直接丢弃缺失样本建模，另一组 EM 补全后建模，对比两者在留出集上的辨证准确率/AUC——课堂演示通常观察到补全后模型更稳（统计来源，送 tcmreviewer 审稿），同时讨论补全引入的偏差风险（模型可能把自身假设当成事实），引导学生建立"补全可用但必须标注、必须审稿"的工程意识。

*单元规模：522 汉字；出处 `教材·第7章·7.12`；本单元数值类命中 0。*
