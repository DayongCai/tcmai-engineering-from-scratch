# 采集界面决定了证候能算到多细 · 提示词

## 用途

给「采集界面决定了证候能算到多细」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「问诊是排查，不是检索 → 四值字段：阳性、阴性、未问、不适用 → 界面即量表：锚点、顺序、观察者 → 信度：先测可靠，再谈有效」这条链。

## 提示词

```
我在学《中医智能辨证系统》第 2 章「采集界面决定了证候能算到多细」，本章 5 节 / 2,807 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 它能不能记录阴性，并且把阴性记录与未记录区分开
   - 谁问的、通过什么方式问的
   - 评定者间信度
   - 信度低的条目，先改界面与定义，不要先改模型
   - 按医生、按科室统计，异常高的要回看流程
   - 异常同样可疑，某位医生对「畏寒」的阳性率达到九成，多半是提问方式带了引导
4. 本章自陈的边界（不得越过）：
   - **采集越全，门诊越慢。** 完整十问加舌脉分级，在门诊节奏里很难逐项做完。可行的折中是分层：首诊全量、复诊增量，急症只取与危候相关的条目。折中方案要写进流程，否则会被默认为「都可以省」。
   - **结构化会挤压自由叙述。** 医生最有价值的那句「说不清哪里不对，但整个人不对劲」，在勾选界面里没有位置。保留一个自由文本字段并让它可检索，比再加十个选项更有用。
   - **信度不等于效度。** 两位医生一致地按同一套错误定义采集，信度可以很高而效度为零。信度只能排除测量噪声，不能证明条目测对了东西。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章讨论症状采集与信度评估的方法，不构成诊断或治疗建议。采集条目、分级锚点与流程须经所在机构中医专家审定后使用；具体操作以现行规范与所在机构制度为准。
