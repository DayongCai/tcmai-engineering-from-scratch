# 辨证算不出来，多半是「证」先没写清楚 · 提示词

## 用途

给「辨证算不出来，多半是「证」先没写清楚」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「病、证、症不是同一种东西 → 判据有四种句法，不能压成一种 → 四诊变向量，有四处固定丢失 → 从规则到概率：不是升级，是换了一种错法」这条链。

## 提示词

```
我在学《中医智能辨证系统》第 1 章「辨证算不出来，多半是「证」先没写清楚」，本章 5 节 / 2,878 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 有病程与转归，是一个时间跨度较长的单位
   - 是对当前病机的概括，时间跨度短，随治疗与传变而变
   - 要识别的不是「给病案贴哪个证名」，而是一组证素及其主次关系
   - 是加权和，见于后世对兼夹证的权衡
   - 主症与否决项要写成硬约束，不能交给权重去学
   - 其一，程度被二值化
4. 本章自陈的边界（不得越过）：
   - **必须先声明用哪套辨证体系。** 八纲、六经、脏腑、卫气营血、三焦，各自的证型集合与边界不同。混着用会造出一批互不可比的标签，而这种标签一旦进了训练集，模型学到的就是混合口径，谁也解释不了。
   - **形式化会奖励「写得下来的」，惩罚「只可意会的」。** 能被拆成主症次症的证候进入系统，靠医生整体印象判断的证候被挤到边缘。这不是中立的技术选择，它会长久地改变教学与记录习惯。
   - **症状字典是资产，也是负债。** 每加一个症状，要同时定定义、定编码、定它与既有条目的关系。字典越大，维护成本越高，而模型未必用得上。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章讨论辨证信息的形式化方法，不构成诊断或治疗建议。任何证型定义、判据与编码的落地，须经所在机构的中医专家与主管部门审定；具体操作以现行规范与所在机构制度为准。
