# 第 1 章 · 辨证算不出来，多半是「证」先没写清楚

> **MOTTO:** 「谨守病机，各司其属，有者求之，无者求之，盛者责之，虚者责之。」——《素问·至真要大论》
>
> **PROBLEM:** 八纲只有八目，两两组合却能张出上百个证型名；症状条目数以百计，落到一份门诊病历上往往只剩十几条阳性。机器拿到的就是这十几条字符串，其中一条还写作「怕冷」而不是「畏寒」。于是同一个病人，在两个库里可以落进两个证型，而两套代码都「跑通了」——跑通的是程序，不是辨证。

**双根因定位:** 环境逼迫（病历要进系统、系统要出概率、概率要能复核，三道压力同时压在一次判断上）+ 知识积累（证的边界是「主症 + 次症 + 舌脉」的合取结构，而绝大多数模型只接受一张平表）

## 一、病、证、症不是同一种东西

把三者混为一谈，是形式化失败的第一个源头。

**病**有病程与转归，是一个时间跨度较长的单位；**证**是对当前病机的概括，时间跨度短，随治疗与传变而变；**症**是当下可观察到的表现，是证的证据，不是证本身。三者不是层级关系：同病可以异证，异病可以同证。这意味着「证」不能当成「病」的子类去做层级分类——一旦按病建树、把证挂在病下面，异病同证的那部分病人在结构上就没有位置。

更关键的是证的可分解性。一个证型名通常是若干**证候要素**的组合：病位要素（心、肝、脾、肺、肾、胃、胆、大肠……）加病性要素（寒、热、虚、实、气滞、血瘀、痰、湿、水饮……），再加病势（上逆、下陷、内闭、外脱）。「肝郁脾虚」拆开是病位肝与脾、病性气滞与气虚；「脾虚湿困」拆开是病位脾、病性气虚与湿。拆开之后，证型名就成了组合的结果，而不是一个不可分析的原子标签。

还有一层：证素组合与证名不是一一对应。同一组证素，在不同教材里可以叫「肝郁脾虚」，也可以叫「肝气犯脾」「木郁克土」，三个名字指向同一个病机结构；反过来，同一个证名在不同流派里对应的证素集合也可能不同。这意味着形式化必须把「证素组合」当作一等对象，把证名当作它的标签之一，而不是反过来从证名去猜证素。否则词表每改一次版，模型就要重训一次，而两次训练的标签根本不是同一件事。

这个认识直接改变建模对象：**要识别的不是「给病案贴哪个证名」，而是一组证素及其主次关系**。证名可以由证素组合规则生成，也可以由字典映射；但若模型直接输出证名，一旦字典里没有这个组合，它就只能退到最像的那一个。

| 层次 | 时间尺度 | 能否直接观察 | 建模时的角色 |
|---|---|---|---|
| 病 | 周至年 | 否，需病程归纳 | 分层变量、先验来源 |
| 证 | 天至周 | 否，需综合判断 | 预测目标（可分解为证素） |
| 症 | 当下 | 是 | 输入证据 |

## 二、判据有四种句法，不能压成一种

中医讲「辨」，辨的是判据是否成立。判据在古籍里有几种明显不同的句法，混成一种就会失真。

**必具式**是合取。《伤寒论·辨太阳病脉证并治上》太阳病提纲「太阳之为病，脉浮，头项强痛而恶寒」，三症并列，缺一则提纲不成立。**但见式**是单条充分。「伤寒中风，有柴胡证，但见一证便是，不必悉具」，说的是某一条特异表现足以支持判断，不必凑齐。**计分式**是加权和，见于后世对兼夹证的权衡。**排除式**是否定，如某证忌见某脉，见则改判或存疑。

一个成熟的证型判据往往是四者的混合：主症用必具，特异性表现用但见，次要表现计分，危重信号做排除。形式化如果只保留计分式，就等于宣布「主症不成立但次症够多也可以出证」——这正是许多打分系统最容易被医生抓住的错。

| 句法 | 逻辑形式 | 典型来源 | 典型失效 |
|---|---|---|---|
| 必具 | A ∧ B ∧ C | 六经提纲 | 患者少报一条即漏判 |
| 但见 | A → 证 | 方证相应条文 | 特异症被常见病污染 |
| 计分 | Σwᵢxᵢ ≥ θ | 后世证候量化 | 次症堆出主证 |
| 排除 | ¬D | 禁忌、危候 | 排除项未采集，形同虚设 |

工程上的结论很直接：**主症与否决项要写成硬约束，不能交给权重去学**。权重可以被数据推着走，硬约束不会。把「脉浮紧」的权重学到 0.3，模型仍然会在脉不浮紧时给出风寒表实——这不是模型不准，是判据结构被压平了。

## 三、四诊变向量，有四处固定丢失

四诊信息进入模型前要变成数值，这一步的丢失是结构性的，不是实现粗糙。

**其一，程度被二值化。** 「纳差」记成 1、「纳呆、不欲食」也记成 1，轻度与重度同权。**其二，定类被当成无序。** 舌色从淡白到红绛本有顺序，独热编码之后「淡白」与「红绛」的距离和「淡白」与「淡红」一样远。**其三，修饰被截断。** 「不渴」与「渴不欲饮」不是「渴 = 0」，后者是湿阻的典型信号，截断后信号消失。**其四，时序被拍平。** 「先寒战、后壮热」与「寒热往来」在集合表示里都是「寒 + 热」，而前者提示疟或痈脓，后者提示少阳。

| 丢失点 | 例子 | 后果 | 可用的补救 |
|---|---|---|---|
| 程度 | 纳差轻 / 重 | 权重被均值化 | 等级编码 + 行为锚点 |
| 序 | 舌淡白→红绛 | 距离失真 | 有序编码或单调约束 |
| 修饰 | 不渴 / 渴不欲饮 | 病性判反 | 复合概念入字典 |
| 时序 | 先寒后热 / 往来寒热 | 病位判错 | 事件序列字段 |

这四处的共同点是：**丢失发生在建模之前，任何模型都补不回来**。所以第 2 章要专门谈采集，因为采集决定了这里的上限。一个只在集合层面工作的系统，无论换多大的模型，都读不出「先寒后热」。

## 四、从规则到概率：不是升级，是换了一种错法

规则系统的错法很清楚：覆盖不到就沉默，或者落到默认分支。概率系统的错法更隐蔽：它总能给出一个数，这个数看起来像置信度，实际上可能只是 softmax 在几个都不像的选项里挑了一个相对高的。

从规则走到概率，通常有三个动机：症状有轻重、证候会重叠、判据有例外。这三件事规则确实处理得笨，概率模型处理得顺手。但代价是判据结构被压进参数里，可审计性下降。

还有一层常被忽略：**概率需要校准**。模型输出 0.8，只有在「判 0.8 的那些病例里大约八成确实如此」时，这个 0.8 才有意义。未经校准的概率只是排序分数，拿它去和医生沟通「系统有八成把握」，是把排序当成了频率。

| 范式 | 表达力 | 可审计性 | 典型失效 |
|---|---|---|---|
| 纯规则 | 低，只表达显式判据 | 高，逐条可追 | 例外与重叠处理不了 |
| 加权打分 | 中，可表达轻重 | 中，权重可看但来源模糊 | 次症堆出主证 |
| 概率模型 | 高，可表达不确定性 | 低，参数不可逐条读 | 未校准、先验压过后验 |
| 规则 + 概率 | 高 | 中高 | 两层的口径不一致 |

实践中最稳的不是选一边，而是分工：**规则管否决与主症，概率管排序与兼夹**。规则那层输出「不成立」，概率层就不该再有机会翻案。

## 五、形式化的三条硬判据

判断一个「证」有没有被写清楚，可以只用三条检验，每条都能在动手建模前做完。

**可标。** 两位有资质的医师独立看同一批病历，能否标出同一个证（或同一组证素）。如果两人一致率低，问题在判据定义，不在模型。此时上模型，等于把标注噪声学进去，再用手调参数把它盖住。

**可分。** 相邻证型之间是否存在可指认的鉴别点。风寒表实与风热犯卫，鉴别点在恶寒轻重、汗之有无、咽痛、舌色、脉浮紧与浮数；如果两个证型在现有采集项上根本找不到稳定差异，模型只能靠基础率猜，表现会随就诊人群漂移。

**可退。** 系统是否允许输出「证据不足以判」。强制 argmax 的系统在证据缺失时也会给一个证，而这个证会被写进病历、进入统计、成为下一轮训练的数据——错误自我复制。

| 判据 | 检验方法 | 不满足时的处置 |
|---|---|---|
| 可标 | 双人独立标注，算一致性 | 先改判据定义与证型边界 |
| 可分 | 逐对相邻证型列鉴别点 | 补采集项，或合并证型 |
| 可退 | 构造证据缺失样例 | 加「未定」出口与缺失原因 |

把这三条落到一条记录上，最小的结构大致是这样（示意，不是标准）：

```json
{
  "syndrome": "肝郁脾虚",
  "elements": { "location": ["肝", "脾"], "nature": ["气滞", "气虚"] },
  "primary": true,
  "criteria": {
    "required": ["情志抑郁", "脉弦"],
    "scored": [{ "item": "纳差", "weight": 2 }, { "item": "腹胀", "weight": 1 }],
    "excluded_by": ["舌红绛无苔"]
  },
  "evidence_state": "sufficient",
  "note": "若 required 未全满足，输出 insufficient 而非降级取次优"
}
```

这段结构里，`required` 与 `scored` 分开、`excluded_by` 独立成字段、`evidence_state` 允许 `insufficient`——三处都是为了保住判据的句法，不让它被压成一个分数。
本章可直接验证：`node code/main.js` 打印结构清点与判据清单（数字从 `docs/zh.md` 现算），`node --test code/main.test.js` 跑本章单测；两条命令只读正文与代码，不写任何文件。

## 六、代价与边界

- **必须先声明用哪套辨证体系。** 八纲、六经、脏腑、卫气营血、三焦，各自的证型集合与边界不同。混着用会造出一批互不可比的标签，而这种标签一旦进了训练集，模型学到的就是混合口径，谁也解释不了。
- **形式化会奖励「写得下来的」，惩罚「只可意会的」。** 能被拆成主症次症的证候进入系统，靠医生整体印象判断的证候被挤到边缘。这不是中立的技术选择，它会长久地改变教学与记录习惯。
- **症状字典是资产，也是负债。** 每加一个症状，要同时定定义、定编码、定它与既有条目的关系。字典越大，维护成本越高，而模型未必用得上。
- **形式化不等于客观化。** 把判据写成字段，只说明它可计算，不说明它正确。判据本身的正确性要靠临床与文献，代码给不了。

**免责声明：** 本章讨论辨证信息的形式化方法，不构成诊断或治疗建议。任何证型定义、判据与编码的落地，须经所在机构的中医专家与主管部门审定。
