# 向量能算出「像」，算不出「为什么是证」 · 提示词

## 用途

给「向量能算出「像」，算不出「为什么是证」」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三条路线，三种代价 → 语料决定语义，而三种语料各有偏差 → 距离不等于鉴别 → 把结构注入向量」这条链。

## 提示词

```
我在学《中医智能辨证系统》第 5 章「向量能算出「像」，算不出「为什么是证」」，本章 5 节 / 2,789 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 字典映射加独热
   - 共现矩阵分解
   - 相似病例检索
   - 嵌入是有损压缩
   - 不可审计是结构性的，不是实现问题
   - 语料规模与质量，比算法选择更重要
4. 本章自陈的边界（不得越过）：
   - **嵌入是有损压缩。** 几百维装不下四诊的全部结构，被压掉的往往正是罕见的、例外的部分。压缩率越高，检索越顺，鉴别越钝。
   - **不可审计是结构性的，不是实现问题。** 稠密向量没有逐维语义，任何「第 37 维代表什么」的解释都是事后附会。需要审计的场景，就该用可读表示。
   - **语料规模与质量，比算法选择更重要。** 同一算法在病历、教材、古籍上训出的空间差别很大。先问语料代表什么人群，再问模型好不好。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```
