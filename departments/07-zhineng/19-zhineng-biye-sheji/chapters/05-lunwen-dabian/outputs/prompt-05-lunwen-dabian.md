# 论文不是把做过的事写一遍，是把「别人凭什么信你」按顺序摆出来 · 提示词

## 用途

给「论文不是把做过的事写一遍，是把「别人凭什么信你」按顺序摆出来」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「六段结构，与评审表一一对应 → 三张表：主表、消融表、误差表 → 写作顺序：先图表，后文字，最后摘要 → 答辩：20 分钟的分配与五个必答题」这条链。

## 提示词

```
我在学《智能系毕业设计与知识移交》第 5 章「论文不是把做过的事写一遍，是把「别人凭什么信你」按顺序摆出来」，本章 5 节 / 2,691 汉字，习题 7 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 图中的每一个数都要能追溯到实验日志的一行
   - 第一步，把三张表定稿
   - 第二步，按表格写结果与分析
   - 第三步，写数据与方法
   - 第四步，写摘要、引言与结论
   - 说清「这一项我没做，原因是什么，影响是什么」
4. 指出本章写到类别就止步、不再给参数的地方。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章内容用于教学，不构成诊疗或执业意见；具体操作以现行规范与所在机构制度为准。
