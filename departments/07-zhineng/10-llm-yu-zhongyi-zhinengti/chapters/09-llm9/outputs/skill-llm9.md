# 测不出幻觉率的模型，不该进临床流程

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 8 道题自检，答不上就回到对应小节。

## 核心判据

- 错误代价不对称
- 报告的结构决定了讨论的质量
- 任何宣称自己做了幻觉检测的系统，若连这一步都没有，那它测的不是幻觉，是印象
- 其一，题源要分层，且注明是否在训练语料内
- 其二，答案要分级，不搞对错二分
- 其三，多解题要标出所有可接受答案

## 边界

- 本章所有数值（300 题、$p_o=0.80$、边缘分布 0.50/0.30/0.20 与 0.55/0.28/0.17、$p_e=0.393$、$\kappa\approx0.67$、总体 0.85 与长尾 0.4）均为**演算设定**，用于说明指标关系，不对应任何实测模型、评测集或评分结果。
- kappa 的区间解释（0.61–0.80 为「较好」）是通行惯例，不是绝对标准；不同任务的合理阈值不同。
- 本章不评价任何公开基准、模型或产品，也不给出「达到多少分可用」的门槛；门槛须由使用机构结合场景与风险确定。
- 本章为模型评估方法的教学讨论，不构成诊疗、技术选型或产品准入建议。
