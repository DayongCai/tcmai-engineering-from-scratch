# 模型说的每一句话，都是在一个概率分布上抽的一次签 · 提示词

## 用途

给「模型说的每一句话，都是在一个概率分布上抽的一次签」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「链式分解：一句话的概率怎么拆 → 概率图：把「谁依赖谁」先画出来 → 解码策略：四条路，四种脾气 → 温度在中医问答里的实际后果」这条链。

