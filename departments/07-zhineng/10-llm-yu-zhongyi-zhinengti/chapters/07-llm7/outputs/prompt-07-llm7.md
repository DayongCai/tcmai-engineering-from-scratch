# 知识不是喂给模型的背景，是它必须引用的证据 · 提示词

## 用途

给「知识不是喂给模型的背景，是它必须引用的证据」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三条注入路径，六项代价 → 检索的三层：字面、语义、结构 → 知识库怎么建：三种 schema → 切片：长度与边界决定检索质量」这条链。
