# 对齐不是让模型更聪明，是让它在该停的地方停 · 提示词

## 用途

给「对齐不是让模型更聪明，是让它在该停的地方停」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三种信号，三种改法 → 偏好数据：写什么，比怎么训更重要 → 奖励模型学的是什么，以及它怎么会错 → 拒答的边界：过度拒答也是一种失败」这条链。

