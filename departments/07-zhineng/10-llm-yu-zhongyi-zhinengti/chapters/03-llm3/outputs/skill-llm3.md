# 证候要能被检索，先得能被放进一个能算距离的空间

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 8 道题自检，答不上就回到对应小节。

## 核心判据

- 共现的语料是混合的
- 术语的分布极不均衡
- 冷僻术语召不回来
- 嵌入只用来做召回（找出候选），术语表用来做判定（决定是否等价）
- 同义（一词多写）
- 上下位（属种）

## 边界

- 本章所有数值（3 万词表、768 维、0.31／0.94／0.5／0.9 的余弦、30–50 个查询词、100 对同义词）均为**演算设定**，用于说明关系与量级，不对应任何实测模型或公开词表。
- 「消渴」与「糖尿病」、「胸痹」与「冠心病」的对应关系存在口径差异，本章仅用于说明「跨体系对应需带口径」，**不构成任何疾病归属或诊断等价的判定**。
- 章节不提供任何术语表的具体内容，也不评价任何嵌入模型或检索产品；术语规范以现行国家标准与行业规范为准。
- 本章为术语表示与检索工程的教学讨论，不构成诊疗、用药或术语规范解释。
