# 标注不够时，最贵的不是算法，是判断哪些样本值得标 · 提示词

## 用途

给「标注不够时，最贵的不是算法，是判断哪些样本值得标」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三种「没有标签」，处理方式完全不同 → 自训练：伪标签的三条规矩 → 主动学习：不确定性怎么量 → 中医场景的弱监督来源」这条链。
