# 深层网络不是更聪明，是把误差分配得更细

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 输出层怎么定义
- 分类任务的参数量最好不超过样本量的 1/10
- 先用规则或线性模型做基线
- 再用预训练表示 + 浅层分类头
- 最后才考虑微调
- 必须留出按医师分组的验证集

## 边界

- 本章所有数值（768 维输入、10 层 512 单元、370 万参数、600 样本、$w=0.5$ 的更新算例、0.8 上下的基线准确率）均为**演算设定**，用于说明参数与样本的关系，不对应任何实测模型或真实数据。
- 「参数量不超过样本量 1/10」是粗用的经验线，不是定理；实际阈值取决于任务难度、标签噪声与正则强度。
- 本章不给出任何模型结构建议、不评价任何框架或产品；结构选择须结合数据规模、审计要求与算力条件判断。
- 本章为神经网络原理与训练决策的教学讨论，不构成诊疗、技术选型或系统验收建议。
