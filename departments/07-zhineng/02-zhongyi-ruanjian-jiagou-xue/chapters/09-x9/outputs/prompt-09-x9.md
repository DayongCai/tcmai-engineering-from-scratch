# 证候不是一个标签，是一次可以拆开的判断 · 提示词

## 用途

给「证候不是一个标签，是一次可以拆开的判断」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「证候：证素加组合，比证型枚举省得多 → 方剂：方名码与组成码必须分开 → 诊疗路径：是一棵决策树，不是一条直线 → 把三者连起来：一张关系图」这条链。
