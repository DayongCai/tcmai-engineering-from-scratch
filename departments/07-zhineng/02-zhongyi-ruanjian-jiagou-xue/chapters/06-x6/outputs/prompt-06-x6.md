# 没写下来的决策，等于没做过决策 · 提示词

## 用途

给「没写下来的决策，等于没做过决策」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、正文档次与边界摆出来，让使用者自己走一遍。

## 提示词

```
我在学《中医软件架构》第 6 章「没写下来的决策，等于没做过决策」，正文见 docs/zh.md。

请按以下顺序带我走：
1. 先给本章要回答的问题，以及它和上一章的分界；
2. 再按正文各节顺序，逐节读出作者的判据与代价，不只复述结论；
3. 对每个判断追问：它在什么条件下失效，正文写没写这条边界；
4. 最后列出本章的三条边界：结构性判断不替代机构方案、参数以现行规范为准、不构成临床或选型建议。

要求：不编造正文没有的数字；引用正文原句时标明所在节；不确定的地方直接说「正文未展开」。
```

## 边界

本提示词用于教学准备，不构成诊疗、用药或信息化决策建议；具体做法以现行规范与所在机构制度为准。
