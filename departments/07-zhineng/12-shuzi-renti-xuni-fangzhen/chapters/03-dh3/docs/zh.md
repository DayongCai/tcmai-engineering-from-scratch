## 三、逐单元读

### 3.34 知识图谱的成就与局限

知识图谱以「实体—关系—实体」的三元组描述世界，在中医药领域已结出硕果：中药—靶点—疾病关联发现、方剂配伍规律挖掘、智能问答与辅助辨证。tcmP 平台的病证知识图谱以「病证单元（DSU）」为最小编写原子，把西医病侧（病名、ICD-11 编码、分子靶点）与中医证侧（证候、六经八纲、主症舌脉）锚定于同一个节点，目前落地 103 个单元、远期规划六万节点。 然而知识图谱是**扁平**的。它擅长回答「谁和谁有关系」，却难以回答三个教学中反复出现的问题：这个知识**从哪里来**？**该先学谁**？它属于**哪一门课、哪一章**？这正是教材体系必须回答的问题，也是纯图谱结构的天然缺口。

*单元规模：215 汉字；出处 `教材·原第1章·1.1`；本单元数值类命中 0。*

### 3.35 中医药知识的两层结构：层次与关系

中医的知识组织从来是双轨的。**层次**体现在经典与教材：阴阳→五行→藏象→经络→证候→方药，逐级从属、由总到分；**关系**体现在临证：五行生克乘侮、十二经脉流注表里、方证对应、君臣佐使、引经报使、六经传变。层次保证「学得进去」，关系保证「用得出神」。 一门课程若要既教会学生系统地记，又教会学生活用地推，就必须同时把两层结构显式化。中医知识树为此而生。

*单元规模：142 汉字；出处 `教材·原第1章·1.2`；本单元数值类命中 0。*

### 3.36 中医知识树的定义与核心隐喻

中医知识树是一棵**五级骨架**的知识结构，以草木生长为隐喻： 须向根输送养分，根生出主干，干分主枝，枝展叶冠——这与中医「由道及术、由源及流」的认知顺序天然同构。

*单元规模：66 汉字；出处 `教材·原第1章·1.3`；本单元数值类命中 0。*

### 3.37 树图一体：知识图谱如何成为知识树的经脉

中医知识树不是要取代知识图谱，而是把它**收编**为自身的经脉。规则只有一条：**树的叶，就是图的节点**。 - 树的枝干路径 = 图的分层聚类； - 图的关系边只在「同层叶之间」或「叶与概念丛之间」建立； - 于是层级管从属，关系管推理，二者互不干扰，又能互相索引。 在 tcmP 的实现中，`neighbors(DSU-00001)` 会同时返回它的证候（`manifests_as`）、西医病（`disease_is`）、ICD-11 编码（`icd11_map`）与所属学科枝（`hierarchy`）——一棵树与一张图，在同一个节点上汇合。

*单元规模：140 汉字；出处 `教材·原第1章·1.4`；本单元数值类命中 0。*

### 3.39 中医知识树的平台意义与技术挑战

平台意义有三：其一，**教材与图谱不再是两张皮**——教材的每一章叶都挂在同一棵树上；其二，**技能与学科可自动对齐**——教育技能声明其学科即可挂树；其三，**六者 Agent 与医圣成长有了统一的知识坐标**。 技术挑战同样现实：源数据分布在领域规范 Markdown、病证单元 JSON、技能目录 JSON 三类异构文件里，排版格式各异；这要求构建管线具备**容错解析**能力，并以**可复现、可校验**为底线。第八章将给出工程解法。 > 思考题：若把「教材」看作叶子，「知识图谱」看作经脉，那么「考试大纲」应当落在树图的哪一层？

### 3.40 知识表示方法概览（框架/语义网络/本体/属性图）

知识表示的历史是一部「从规则到结构、从结构到向量」的演进史。**框架表示**用槽—值结构描述对象；**语义网络**用节点—弧表达概念关系；**本体**（Ontology）在语义网络之上加形式化公理，使之可推理；**属性图**（LPG）则以「节点带属性、边带属性」的工程形态落地。 中医药知识树并不发明新表示法，而是**组合**它们：树骨架借自本体（is-a / part-of 层级），经脉边借自属性图（带权、带类型的边），叶节点则预留向量表示接口。

*单元规模：150 汉字；出处 `教材·原第2章·2.1`；本单元数值类命中 0。*

### 3.41 RDF/OWL 与属性图（LPG）

RDF 用三元组 `(主语, 谓语, 宾语)` 表述事实，OWL 在此基础上定义类、属性与基数约束。其优点是标准化与可推理，缺点是查询与工程实现较重。属性图以 Neo4j 为代表，节点与边都可挂属性，查询语言（Cypher）直观。 tcmP 采用**双轨**：对外以 OWL 承载中医领域本体（Protégé 建模），对内以 JSON 属性图承载构建与查询。二者的桥接由 `kg/tree/schema.json` 定义。

*单元规模：112 汉字；出处 `教材·原第2章·2.2`；本单元数值类命中 0。*

### 3.42 树结构与图结构的数学基础

树是连通无环图，具有唯一路径、$n$ 节点恰有 $n-1$ 条树边、任意两节点间距离等于深度差等性质。这些性质让树天然适合做**导航与从属**：`path(叶)` 必唯一，`subtree(枝)` 必封闭。 图则可含环、可多路径，适合做**推理与传播**。知识树 = 生成树（树边承担层级） + 附加边集（非树边承担关系）。于是「找一条学习路径」用树算法，「找一条推理链」用图算法。

*单元规模：123 汉字；出处 `教材·原第2章·2.3`；本单元数值类命中 0。*
