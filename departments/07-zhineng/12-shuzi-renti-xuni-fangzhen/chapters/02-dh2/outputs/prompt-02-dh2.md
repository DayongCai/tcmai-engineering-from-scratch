# 数据不是「采得越细越好」，而是「这一层问题配这一层数据」 · 提示词

## 用途

给「数据不是「采得越细越好」，而是「这一层问题配这一层数据」」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「四类数据源，物理上限各不相同 → 各向异性：三维数据被当二维堆叠用时的系统性偏差 → 重采样：能改变什么，不能改变什么 → 配准：误差在这里被放大，也在这里被掩盖」这条链。

## 提示词

```
我在学《数字人体与虚拟仿真》第 2 章「数据不是「采得越细越好」，而是「这一层问题配这一层数据」」，本章 7 节 / 2,858 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 几何量的算法必须显式处理
   - 部分容积效应使边界不可精确定义
   - 这不是分割算法不够聪明，是数据本身没有更细的答案
   - 配准残差不能当作精度指标
   - 降下去的那一半，是过拟合，不是精度
   - 把它当内部结构的替代品，是把"看得见的形状"误当成"看不见的结构"
4. 本章自陈的边界（不得越过）：
   - 本章的 0.5×0.5×1.0 mm 体素、8 倍数据量、12 点配准与 1.8 mm 留出点残差均为**演算设定**，用于演示误差关系，不对应任何具体设备或病例。
   - 各向异性带来的体积偏差量级依赖器官形状与阈值选择，本章只说明其存在与方向，不给通用修正系数。
   - 配准方法的选择（刚体／仿射／非刚性）须由应用场景与可接受的形变假设决定，本章不推荐具体算法或软件。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为医学数据来源与误差特性的教学讨论，不构成医学意见、诊断建议或采集规范；具体操作以现行规范与所在机构制度为准。
