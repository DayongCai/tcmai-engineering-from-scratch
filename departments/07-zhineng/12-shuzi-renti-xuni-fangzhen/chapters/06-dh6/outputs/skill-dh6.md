# 收敛只证明方程被解对了，不证明方程是对的

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 只有前两步都通过，第三步的差异才能归因给模型本身
- 是哪一层假设
- 相关性验证与机制验证是两件事
- 在需要绝对数值的场合（如器械尺寸、安全裕度），只有一致性指标有意义
- 不写归一化方式的 RMSE 无法比较
- 参数远多于可观测

## 边界

- 本章的 3.1%、0.8%、20% 离散度、$r=0.94$ 与 Bland–Altman 界限（+1.8 mm，−2.4 至 +6.0 mm）均为**演算设定**，仅用于说明收敛、相关与一致性的区别，不对应任何实验或模型。
- 不确定度分解的具体权重依赖模型与实验条件，本章不给通用比例；任何分解须基于本项目的实测与敏感性分析。
- 确认容差应由应用场景的责任方设定（教学演示、术前规划、器械注册的容差要求差别很大），本章不提供通用阈值。
- 本章为仿真验证与确认方法的教学讨论，不构成医学意见、诊断或治疗建议。
