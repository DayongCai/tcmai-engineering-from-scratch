# 机器学习 缺口登记

## 一、无插图

教材为文字体，无图。图表本应覆盖：假设空间示意、决策树划分、间隔与核映射、集成示意、偏差—方差曲线。
本课图注 108 条为文字形态，图版 0 张（见 `图示缺口.md`）。

## 二、样例数据为合成

教材用「感冒证候样例」等合成表讲解分类，本课沿用但明确标注：**合成数据不得当作真实病例或诊断依据**。

## 三、不写的内容

| 类型 | 处理 |
|---|---|
| 框架/库的 API 与版本差异 | 不写 |
| 调参的具体取值与搜索空间 | 只写方法，不写取值 |
| 性能承诺（准确率/AUC 的具体数） | 不写 |
| 医学应用结论 | 不写，须另行验证与审批 |

## 四、不做的事

1. 不替代《机器学习》实验课与工程实践；
2. 不把教材的算法讲成临床可用方案；
3. 不引真实患者数据。
