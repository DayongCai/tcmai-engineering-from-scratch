# 一条直线的全部本事，在于你把什么变量交给它

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 残差小不代表模型对
- 线性模型的外推是线性外推，这句话应当刻在每个用它做预测的人桌上
- 梯度只由「预测概率减真实标签」乘以特征决定
- 对数几率回归的输出不是校准良好的概率
- 它的输出可以任意接近 0 或 1，与「模型是否真的确定」无关
- 排序用于决策，置信度用于沟通，两者必须分开校准

## 边界

- 本章所有数值（三点拟合 $w=1.5$、$b=-1/3$、残差平方和 0.167、softmax 概率 $(0.665,0.245,0.090)$、梯度下降一步后的 $p=0.706$）均为**演算设定**，用于演示计算过程，不对应任何真实数据集。
- 正规方程的复杂度是 $O(d^3+d^2m)$，特征数超过一万时直接求逆不现实，实际用梯度法或 SVD 分解；本章不展开数值实现。
- 「系数可解释」有一个前提：特征之间不高度相关。存在共线性时，单个系数的符号与大小都不可信，此时应看系数之和或改用正则化路径。
- 本章为线性模型的教学讨论，不构成医学意见、诊断或治疗建议。
