# 一条直线的全部本事，在于你把什么变量交给它 · 提示词

## 用途

给「一条直线的全部本事，在于你把什么变量交给它」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「最小二乘：闭式解与它的几何含义 → 从回归到分类：对数几率 → 多分类：softmax 与它的过度自信 → 正则化：给 $\mathbf{w}$ 系一根绳子」这条链。

