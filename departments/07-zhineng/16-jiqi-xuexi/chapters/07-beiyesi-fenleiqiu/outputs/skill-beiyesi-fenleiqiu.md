# 先验不是偏见，是还没看到数据时你唯一能拿出的东西

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 先验不是主观偏见
- 在给定类别的条件下，各属性相互独立
- 算例（演算设定）
- 把同一条证据数了三遍
- 朴素贝叶斯的排序通常不错，但它的概率几乎从不校准
- 无论其它证据多强，后验都是 0

## 边界

- 本章所有数值（14 属性 / $3^{14}\approx478$ 万 / 84 个参数、20 条训练样本、条件概率 0.8/0.9/0.9、后验 0.997、平滑后的 $1/12$、EM 的 $\mu_1=0,\mu_2=4$）均为**演算设定**，用于演示计算与失效机制，不对应任何真实病例数据。
- 本章的后验概率数值不可用于任何实际判断；朴素贝叶斯的输出未经校准，个体风险必须以校准后的模型与临床评估为准。
- 拉普拉斯平滑会引入偏差，$\lambda$ 过大时所有条件概率趋近均匀，模型退化为只看先验。$\lambda$ 应通过交叉验证选择，而不是默认取 1。
- 本章为贝叶斯分类器的教学讨论，不构成医学意见、诊断或治疗建议。
