## 三、逐单元读

### 11.1 子集搜索与评价

特征选择（feature selection）是选取对当前学习任务有用的特征子集的过程。现实机器学习任务中，样本往往以高维特征加以描述，而这些特征并非都同等重要：冗余特征（redundant feature）指所起作用可由其他特征替代的特征，其判别信息已被其余特征覆盖；无关特征（irrelevant feature）指与学习任务本身无关、不携带判别信息的特征。二者叠加会引发严重的「维数灾难」（curse of dimensionality）：随着特征维数升高，样本在高维空间中迅速趋于稀疏，任意两点间距离趋于相近，为使学习器达到同样泛化性能所需的训练样本数呈指数级增长，同时无关特征引入的噪声会加剧过拟合。特征选择通过剔除冗余与无关特征、保留关键特征，可缓解维数灾难、降低学习难度、提升模型可解释性，并显著缩短训练与预测时间。典型的特征选择应用包括文本分类中的词项筛选、基因表达数据中的差异基因筛选、医学影像中的纹理特征筛选等——这些场景的共同特点是特征维度远高于样本数（高维小样本），若不先做特征选择，多数学习算法难以直接工作。特征选择与降维有本质区别：降维（如主成分分析 PCA）通过线性或非线性变换产生全新的低维表示，新特征往往失去原始语义；特征选择则直接保留原始特征的一个子集，不改变特征语义，因而在医疗诊断、金融风控等需要向领域专家解释决策依据的场景中更具优势，也符合「奥卡姆剃刀」式的简约原则。 特征选择的完整流程包含四个环节：一是子集产生，按某种搜索策略从特征全集 A 中产生候选特征子集 A′；二是子集评价，依据评价准则衡量 A′ 的好坏；三是停止条件，当评价值满足预设条件时终止搜索——常见停止条件包括达到预设特征个数 k、评价性能不再提升、搜索轮数达到上限等；四是子集验证，在独立测试集上验证最终子集的泛化性能，避免因「选择偏差」高估子集效果。

### 11.2 过滤式选择（Relief）

过滤式选择（filter）是最简单、最直观的特征选择方式：先对数据集做特征选择（过滤），再训练学习器，特征选择过程与后续学习器无关，如同先滤掉杂质再学习。这类方法直接基于数据本身的统计性质评价每个特征，计算效率高，适合特征维度极高的场景。其典型代表是 Relief（Relevant Features）算法。 Relief 针对二分类问题设计，基本思想是：一个特征若是「好」的，则应使同类样本在该特征上取值接近、异类样本在该特征上取值远离。具体地，对每个样本 xᵢ，Relief 先在与其同类的样本中寻找最近邻，称为「猜中近邻」（near-hit），记为 x_{i,nh}；再在与其异类的样本中寻找最近邻，称为「猜错近邻」（near-miss），记为 x_{i,nm}。随后按如下规则更新第 j 个特征的相关统计量：δ^j = δ^j − diff(xᵢ^j, x_{i,nh}^j)² + diff(xᵢ^j, x_{i,nm}^j)²，其中 xᵢ^j 表示样本 xᵢ 在第 j 个特征上的取值，diff 为特征取值差异函数：对离散属性，取值相同则 diff = 0、不同则 diff = 1；对连续属性，diff 取归一化后的绝对差，即 diff(x_a^j, x_b^j) = |x_a^j − x_b^j|（各特征已归一化到同一量纲）。更新式的含义十分直观：若特征 j 使 xᵢ 与猜中近邻接近（diff 小），则 δ^j 的减少量小；若使 xᵢ 与猜错近邻远离（diff 大），则 δ^j 的增加量大——净效果是「同类近、异类远」的特征统计量上升，反之下降。 Relief 的完整过程为：初始化各特征统计量 δ^j = 0（j = 1, 2, ..., d）；对每个样本 xᵢ，找出其猜中近邻 x_{i,nh} 与猜错近邻 x_{i,nm}，按更新式累计各特征的 δ^j；遍历完所有样本后，按 δ^j 从大到小排序，取前 k 个特征构成最终选择子集。

### 11.3 包裹式选择（LVW）

包裹式选择（wrapper）与过滤式选择截然不同：它直接把最终将要使用的学习器的性能作为特征子集的评价准则，即「为学习器量身定制特征子集」。由于评价准则与学习器绑定，包裹式选择选出的子集往往比过滤式更贴合任务、泛化性能更好；代价是每评价一个候选子集都要训练一次学习器，计算开销远高于过滤式，在特征数较多或学习器训练较慢时几乎不可行。 包裹式选择的典型代表是 LVW（Las Vegas Wrapper）算法。LVW 采用拉斯维加斯方法（Las Vegas method）框架——与蒙特卡洛方法不同，拉斯维加斯方法的随机性体现在运行时间上：只要时间充足，总能给出正确结果。LVW 的流程如下：输入数据集 D、特征集 A、学习算法 𝔏 与停止条件控制参数 T；初始化最优误差 E* = ∞、最优子集特征数 d* = |A|；随后循环 T 轮：每轮从特征空间中随机产生一个候选子集 A′（子集规模也随机），用交叉验证估计学习器 𝔏 在 A′ 上的误差 E′；若 E′ < E*，或 E′ = E* 且 |A′| < d*（误差相同时偏好更小的子集），则以 A′、E′ 更新当前最优；循环结束后输出最优子集 A*。整个过程可概括为「随机产生子集 → 交叉验证估计误差 → 保留更优者」的反复迭代。 从理论上说，由于特征子集空间有限，拉斯维加斯方法在运行时间足够长时能以概率 1 收敛到最优特征子集——这正是 LVW「理论完备」的一面；但实际中受限于设定的迭代轮数 T，找到的往往只是近似最优子集。更现实的问题是计算开销：每一轮迭代都要在候选子集上完成一次完整的交叉验证，而交叉验证本身包含多次学习器训练。若数据集规模大、特征维度高，LVW 往往需要数小时乃至数天才能完成，因此它主要适用于特征数较少（如几十个以内）、且对特征子集质量要求较高的场景。 设某数据集有 20 个特征，LVW 设定 T = 100 轮、采用 10 折交叉验证（演示数值，非原书数据）。

### 11.4 嵌入式选择与L1正则

嵌入式选择（embedded）把特征选择过程与学习器训练过程融为一体：特征选择在学习器训练过程中自动完成，无需像包裹式那样反复训练学习器来评价子集，也无需像过滤式那样在训练前单独挑选特征。它兼具过滤式的高效与包裹式对任务的贴合，是实践中极为常用的一类方法。其典型代表是带 L1 范数正则化的线性模型，即 LASSO（Least Absolute Shrinkage and Selection Operator，最小绝对收缩选择算子）。 考虑线性回归模型，以平方误差为损失、L1 范数为正则项，得到 LASSO 的目标函数：min_w ½‖y − Xw‖₂² + λ‖w‖₁，其中 X 为样本矩阵、y 为标记向量、w 为回归系数、λ > 0 控制正则化强度，‖w‖₁ = Σⱼ|wⱼ| 为系数向量的 L1 范数（各分量绝对值之和）。为什么 L1 正则化能产生稀疏解（大量分量为零）？关键在于正则化约束区域的几何形状。在二维参数空间中，L2 范数约束 ‖w‖₂² ≤ t 对应一个圆形区域，而 L1 范数约束 ‖w‖₁ ≤ t 对应一个菱形区域——菱形的四个顶点恰好位于坐标轴上。目标函数（平方误差）的等值线是中心在最小二乘解处的椭圆族；当椭圆与约束区域相切时，切点即为最优解。由于菱形在坐标轴处有「尖角」，椭圆与菱形相切时切点落在坐标轴上的概率远高于落在圆上：切点落在坐标轴上意味着相应系数分量为 0。直观地说，L1 约束把解「推向」坐标轴，从而产生稀疏解、自动完成特征选择；而 L2 约束的圆形边界没有尖角，最优解各分量通常均非零、只是整体收缩变小，不产生稀疏性。λ 越大，约束区域越小，解越稀疏；λ 趋于 0 时退化为普通最小二乘。 由于 ‖w‖₁ 在零点不可导，LASSO 不能直接用梯度下降求解，常用近端梯度下降（Proximal Gradient Descent, PGD）处理。

### 11.5 稀疏表示与字典学习

稀疏表示（sparse representation）指将样本表示为尽量少非零分量组成的稀疏向量。与稠密表示相比，稀疏表示有诸多好处：其一，数据可分性增强——高维空间中的样本经适当稀疏化后，不同类别的样本更容易被超平面分开；其二，可解释性好——非零分量直接指向对样本「起作用」的少数成分；其三，存储与计算开销小——只需记录非零分量及其位置；其四，稀疏性便于数据可视化，是压缩感知（11.6 节）等任务的前提条件。然而，「稀疏」是相对于基（basis）而言的：同一个向量在不同基下的表示稀疏程度截然不同。若直接用样本自身（或标准基）作基，表示通常不稀疏；而傅里叶基、小波基等固定基虽在某些信号上表现良好，却未必能匹配任意数据的结构。这引出字典学习（dictionary learning，亦称稀疏编码 sparse coding）的核心问题：能否针对数据本身学习一组「好」的基，使表示尽可能稀疏？ 字典学习希望学得一个过完备字典（over-complete dictionary）矩阵 D ∈ R^{d×k}（原子数 k 可大于样本维数 d），使样本矩阵 X 满足 X ≈ DZ，且 Z 的各列尽量稀疏。其优化目标为：min_{D,Z} ‖X − DZ‖_F²，约束为 ‖zᵢ‖₀ ≤ L（i = 1, 2, ..., m），其中 ‖·‖_F 为 Frobenius 范数（矩阵各元素平方和再开方），‖zᵢ‖₀ 为第 i 个样本的稀疏系数向量 zᵢ 的非零分量个数，L 控制稀疏度上限。该目标同时涉及字典 D 与系数矩阵 Z 两个变量，且 ‖·‖₀ 约束非凸，难以直接联合优化，因此普遍采用交替优化策略：固定一个变量、优化另一个，如此反复。 交替优化的两个子问题分别是：其一，稀疏编码（sparse coding）：固定字典 D，为每个样本求最稀疏的系数 zᵢ，即 min_{zᵢ} ‖xᵢ − Dzᵢ‖₂² 约束 ‖zᵢ‖₀ ≤ L。

*单元规模：1,209 汉字；出处 `教材·第11章·11.5`；本单元数值类命中 0。*

### 11.6 压缩感知

压缩感知（compressive sensing / compressed sensing）研究如何从远低于奈奎斯特采样定理要求的采样数量中恢复原始信号。经典的奈奎斯特采样定理指出：为无失真地重建带限信号，采样频率不得低于信号最高频率的两倍，否则会发生频谱混叠。然而，许多自然信号（图像、语音、医学影像等）在某个变换域（如小波域、离散余弦域）中具有稀疏性或可压缩性——大量系数接近零，只有少数大系数承载主要信息。压缩感知的核心洞察是：既然信号本身的信息量远低于其表观维度，为何还要先高速采样再丢弃大部分系数？能否直接以远低于奈奎斯特率的速率采样，再借助稀疏性精确重构？答案是肯定的，条件是信号可稀疏表示（或近似稀疏、可压缩）、测量矩阵设计得当、重构算法足够鲁棒。 设原始信号 x ∈ R^n 在变换域中稀疏（至多 s 个非零系数），压缩感知通过线性测量得到观测向量 y = Φx，其中 Φ ∈ R^{m×n} 为测量矩阵，m ≪ n——测量数远小于信号维数，方程组欠定，x 有无穷多个解，仅靠 y 无法唯一确定 x。压缩感知指出：若 x 稀疏且 Φ 满足一定条件，则可通过求解最稀疏解精确恢复 x。测量矩阵需满足的关键性质是受限等距性质（Restricted Isometry Property, RIP）：对任意 s-稀疏向量 x，存在常数 δ ∈ (0,1) 使 (1−δ)‖x‖₂² ≤ ‖Φx‖₂² ≤ (1+δ)‖x‖₂²，即 Φ 在稀疏向量上近似保持欧氏距离（能量），从而保证测量不丢失稀疏信号的信息；δ 称为等距常数，越小越好。可以证明，随机高斯矩阵、随机伯努利矩阵等以极大概率满足 RIP，且所需的测量数 m 与 s·log(n/s) 同阶——这解释了为何「随机测量」是压缩感知的标配。 恢复 x 最自然的目标是最小化非零分量个数，即 min ‖x‖₀ 约束 y = Φx。但 ‖·‖₀ 是非凸、不连续的，该问题是 NP 难的，无法高效求解。

### 11.7 本章小结

本章围绕「如何利用特征与数据的稀疏结构降低学习难度」展开，从特征选择与稀疏学习两条主线系统梳理了相关知识。特征选择的目标是从原始特征中选出对任务最有用的子集，以缓解维数灾难、降低过拟合风险、提升可解释性。按照评价准则与学习器耦合程度的不同，特征选择分为三种范式：过滤式（filter）以与学习器无关的统计准则评价特征（代表算法 Relief/Relief-F），先过滤后学习，计算高效但未考虑特征组合效应；包裹式（wrapper）直接以最终学习器的性能评价子集（代表算法 LVW），效果通常最好，但每评价一个子集都要训练学习器，开销巨大；嵌入式（embedded）将特征选择融入训练过程（代表模型为 L1 正则化的 LASSO），在训练中自动完成选择，是效率与效果的折中。理解三者的关键在于把握 L1 与 L2 正则化的几何差异：L1 约束区域为顶点在坐标轴上的菱形，易把解推向坐标轴而产生稀疏解；L2 约束区域为圆形，各分量趋于均匀收缩而不产生稀疏性。LASSO 目标函数不可导，可用近端梯度下降求解，其近端算子恰为软阈值算子——先沿梯度下降再按阈值收缩置零，迭代收敛后非零系数对应的特征即被选中。 稀疏性思想在表示学习与信号处理层面进一步延伸。稀疏表示用尽量少的非零分量刻画样本，增强可分性与可解释性；字典学习（稀疏编码）通过交替优化（OMP 等稀疏编码 + KSVD 等字典更新）学得过完备字典，使表示尽可能稀疏，字典原子可视为数据的基本模式。压缩感知则利用信号在变换域的稀疏性，以远低于奈奎斯特率的随机测量 y = Φx 重构信号，其理论基础是测量矩阵的受限等距性质（RIP），重构通过把 NP 难的 L0 最小化松弛为 L1 最小化（基追踪）或采用匹配追踪类贪心算法完成；矩阵补全利用低秩性从少量已知元素补全矩阵，是压缩感知的重要推广。 三类特征选择方法与稀疏学习从不同层面回答「哪些信息有用」：过滤式基于统计量、包裹式基于学习器反馈、嵌入式基于正则化诱导的稀疏解；稀疏表示与压缩感知则回答「如何用最少的信息表达并恢复最本质的内容」。

### 11.8 tcmP 平台映射

特征选择与稀疏学习对应 tcmP 辨证论治的「信息筛选」环节：患者四诊信息海量（舌、脉、症等条目可达数百项），而真正决定证型的只是少数关键要素——「抓主症」正是中医辨证的经典方法论，与本章「用最少信息表达最本质内容」的思想高度一致。映射关系如下：过滤式（Relief）→ 问诊优先级排序，先问高权重主症、后问兼症，缩短问诊路径；包裹式（LVW/RFE）→ 以辨证引擎性能为目标定制要素集，为特定辨证模型「量身定做」；嵌入式 L1（LASSO）→ 辨证要点提炼，从全量四诊要素中稀疏选出最小辨证要素集；字典学习 → 证型字典学习，从病案库中学习证候模式基（对应病证单元库 BZU 的证型要素模式）；压缩感知 → 从少数关键症候反推完整证候结构，与「以主症定证、以证统症」的辨证逻辑呼应。要素权重与最小要素集写入 BZU 的要素权重字段，供辨证引擎（API server 8642）、问诊流程与条文检索（FTS5+向量混合检索）调用；该映射在岐黄智医多 Profile 体系中由辨证 Agent 落地执行。

### 11.10 过滤式=问诊优先级（Relief）

用 Relief 思想为问诊问题排序：以历史门诊病历（辨证结果作标签）计算每个问诊项的区分权重 δ^j = −diff(xᵢ^j, x_{i,nh}^j)² + diff(xᵢ^j, x_{i,nm}^j)²——同类（同证型）病案近邻靠拢、异类（异证型）病案近邻远离的问诊项权重高。权重高者优先询问：如「恶寒」「发热」「脉浮紧」等太阳病主症权重通常显著高于「口味偏好」「睡眠时长」等非特异条目，据此实现「主症先行、兼症后问」，缩短问诊路径、提升采集效率；权重低于阈值的条目折叠为按需追问，避免冗长问卷。Relief 逐项独立计算的特性也提示：组合症（如「恶寒+无汗」同见）的交互信息需另行通过共现分析补充，避免遗漏组合证候特征。问诊优先级仅作流程提示，不替代医生判断；权重来自病历统计，属「统计来源，送 tcmreviewer 审稿」，标注「现代认识，不改经典原义」；真实临床仅辅助不决策，辨证结论由医生依据四诊合参作出。此外，权重排序结果可定期随病历库更新重算（如按季度离线重训），并在 BFF 8080 的问诊配置页展示 Top-N 主症与权重曲线，便于医师核对与调整。

*单元规模：327 汉字；出处 `教材·第11章·11.10`；本单元数值类命中 0。*

### 11.11 嵌入式 L1=辨证要点提炼（LASSO）

以辨证标签为 y、四诊要素向量为 X 训练 Lasso：min_w ½‖y − Xw‖₂² + λ‖w‖₁。λ 由 LassoCV 沿正则化路径交叉验证确定；λ 调大后大量要素系数归零，保留下来的即辨证要点——如太阳伤寒证保留「恶寒、无汗、脉浮紧」，桂枝汤证保留「恶风、汗出、脉缓」（示例映射，具体以病案统计为准）。L1 菱形约束使解落在坐标轴上的几何解释（对比 L2 圆形约束）直观说明了为何得到稀疏解：稀疏解即最小辨证要素集，用于构建辨证规则、条文主症索引与教学卡片。落地要点：系数非零但绝对值极小的要素设阈值过滤，避免「弱相关要素」混入要素集；LASSO 对高度相关要素只保留其一，与「同义症不重复计」的中医书写规范天然契合，但也会丢弃「同见方显证」的关联症，需结合共现统计补充。要素集须与《伤寒论》条文主症逐条对照，冲突时以条文为准并记录差异，送 tcmreviewer 审稿；算法输出仅作教学与辅助参考。实践口径：λ 的选择优先保证要素集与条文主症一致（先验约束），其次才追求统计拟合优度；若某证型的要素集与经典条文差异过大，先排查标签与要素编码问题，再考虑调整 λ。

*单元规模：357 汉字；出处 `教材·第11章·11.11`；本单元数值类命中 0。*

### 11.12 字典学习=证型字典

用字典学习从病历库学习「证型字典」：过完备字典 D 的原子对应病机/证候模式（如「卫表不固」「寒凝经脉」「热扰心神」等，示例命名），稀疏系数 zᵢ 表示患者由少数证型模式线性组合而成——与中医「复合证」「兼夹证」的思想吻合：一个患者可以是「风寒束表 + 肺气失宣」两个模式的叠加。优化目标 min_{D,Z} ‖X − DZ‖_F² 且 ‖zᵢ‖₀ ≤ L，交替优化求解（OMP 求稀疏系数 + 最小二乘/SVD 更新字典原子，即 KSVD 思路）。字典原子与 ICD-11 术语库证码（Z01..Z17）及病证单元库 BZU 编码映射，实现证型识别、要素提取与相似病案匹配：病案的稀疏系数向量可直接用于 FTS5+向量混合检索，按「证候模式相似度」召回同类病案供医生参考。证型字典的原子数量（过完备程度）与稀疏度上限 L 需结合病案规模调参；原子命名与参数设置送 tcmreviewer 审稿，确保模式命名符合中医理论，不改经典原义。字典更新后需人工复核原子语义：同一原子不得混杂两种病机，语义漂移的原子重新标注或删除，复核记录随模型版本存档。

*单元规模：321 汉字；出处 `教材·第11章·11.12`；本单元数值类命中 0。*

### 11.13 稀疏表示=最小辨证要素集

将每条条文（或病案）表示为稀疏要素向量，仅保留关键主症非零（如桂枝汤证 ≈ 恶风 + 汗出 + 脉缓三项，示例），与全要素向量相比显著降维，利于条文检索、相似病案匹配与教学展示。稀疏表示下数据可分性增强：两证型仅需比对少量要素即可区分（如太阳伤寒「无汗」与太阳中风「汗出」仅一症之别），与「抓主症」的辨证方法论高度一致；稀疏系数的非零位置即「主症位」，可解释性强，适合向学生展示辨证依据。落地注意：稀疏要素向量不得丢失兼症信息——主症用于检索与分类，兼症另行存于结构化字段，避免「为稀疏而稀疏」；最小辨证要素集须与条文主症对照送审：机器选出的高权重要素不得与条文主症冲突，冲突时以经典条文为准并记录差异；输出经 tcmreviewer（中医理论审稿）与 aireviewer（现代技术审稿）双审，按格式落版。向量化细节：要素采用 ICD-11 术语库标准化编码，稀疏向量以 (index, value) 紧凑格式存储于 BZU，检索时先按 FTS5 关键词过滤候选、再按稀疏向量余弦相似度精排，兼顾速度与语义。

### 11.14 要素集与条文主症对照送审

特征选择产出的要素集须与经典条文主症逐条对照：Relief/LASSO/RFE 选出的高权重要素（如「恶寒」「脉浮紧」）不得与《伤寒论》条文主症冲突——算法学自病历统计，病历标注质量、样本分布偏差都可能引入「统计噪声」，使机器选出与经典辨证不符的要素；冲突时以条文为准、记录差异并排查数据标注问题（如标签错分、要素编码不一致）。送审流程：tcmreviewer 审中医本体（要素是否符合辨证理论、证型命名是否规范）、aireviewer 审现代技术（算法选择是否恰当、λ/稀疏度 L 设置是否合理、样本是否具有代表性），输出固定格式原文摘录 /冲突点 /一句可落版 /致命·重要·润色。统计权重一律标注「统计来源，送 tcmreviewer 审稿」；真实临床仅辅助不决策（安全红线），算法输出仅供教学与辅助参考，辨证结论由临床医生负责。对照结果进入 BZU 的要素-条文映射表，反向约束特征选择参数（如调大 λ 剔除与条文冲突的弱要素），形成「算法选要素 → 条文校验 → 参数修正」的闭环。
