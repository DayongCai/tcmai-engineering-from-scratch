# 稀疏不是省参数，是把「不重要」变成可检验的零

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 逐个评估、忽略组合
- 在训练集上做 RFE，等于用训练集的信息选特征，再在同一训练集上评估，性能会虚高
- 顶点意味着另一个坐标为 0
- 所以高维问题里 $L_1$ 几乎必然产生稀疏解
- 软阈值减一个常数，岭回归除以一个常数——这一个字的差别，就是稀疏与不稀疏的差别
- 算例（演算设定）

## 边界

- 本章所有数值（1,000 特征 / 200 样本、误差 0.02/0.68 与 0.11/0.31、五个 OLS 系数与 $\lambda=40$ 的软阈值结果、Bootstrap 稳定性 0.4/0.6）均为**演算设定**，用于演示机制，不对应任何真实数据集。
- $L_1$ 的稀疏性依赖特征尺度：未标准化的特征会被系统性地惩罚或优待，标准化是前提而非可选步骤。
- 本章不宣称稀疏模型优于稠密模型；在特征少、样本多、且特征间高度相关时，岭回归通常更稳。
- 本章为特征选择与稀疏学习的教学讨论，不构成医学意见、诊断或治疗建议。
