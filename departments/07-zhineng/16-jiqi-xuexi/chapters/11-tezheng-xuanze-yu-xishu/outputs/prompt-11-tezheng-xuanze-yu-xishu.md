# 稀疏不是省参数，是把「不重要」变成可检验的零 · 提示词

## 用途

给「稀疏不是省参数，是把「不重要」变成可检验的零」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三种范式：代价差一个量级 → 为什么 $L_1$ 产生零而 $L_2$ 不产生 → Lasso 的算例与 $\lambda$ 路径 → 稀疏的代价：不稳定性与相关特征组」这条链。
