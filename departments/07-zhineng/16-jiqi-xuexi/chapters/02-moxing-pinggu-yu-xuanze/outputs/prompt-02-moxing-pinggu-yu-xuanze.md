# 你报的那个数字，可能只是抽样噪声的形状 · 提示词

## 用途

给「你报的那个数字，可能只是抽样噪声的形状」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三个集，三条纪律 → 交叉验证：压小切分偏差，压不小方差 → 选择偏差：调参调出来的乐观 → 比较两个模型：别用两个百分点」这条链。

## 提示词

```
我在学《机器学习》第 2 章「你报的那个数字，可能只是抽样噪声的形状」，本章 6 节 / 3,004 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 它和验证集上那个数没有区别，都是被优化过的量
   - 特征工程在全量数据上做完再切分
   - 缺陷一：$k$ 折的训练集比最终模型小
   - 缺陷二：折之间有相关性
   - 嵌套交叉验证
   - 一分钱信息都没有增加，报告的数字却涨了 2.2 个百分点
4. 本章自陈的边界（不得越过）：
   - 本章所有数值（1,000 例、0.86、$\sigma\approx0.011$、40 组超参、$n_{10}=45$/$n_{01}=28$、学习曲线三行）均为**演算设定**，用于演示评估偏差的量级关系，不对应任何实测实验。
   - 标准误公式 $\sqrt{p(1-p)/n}$ 假设样本独立同分布。同一病人多次就诊、同一批次采样的数据不满足该假设，此时真实方差更大，报出的置信区间偏窄。
   - 交叉验证的所有变体都只能估计「在同一数据分布下」的性能。部署环境发生分布漂移时，任何 CV 数字都不再适用——这不是方法缺陷，是评估对象变了。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为模型评估方法的教学讨论，不构成医学意见或诊断建议；具体操作以现行规范与所在机构制度为准。
