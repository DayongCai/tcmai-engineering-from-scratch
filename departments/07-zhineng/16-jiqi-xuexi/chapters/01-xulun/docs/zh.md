## 三、逐单元读

### 1.1 引言／汗出／无汗／有汗／无汗／有汗／无汗

机器学习是人工智能（AI）的核心研究领域之一，也是当代计算机科学中最富活力的分支。周志华教授在《机器学习》一书的开篇即给出经典定义：机器学习是这样一门学科，它致力于研究如何通过计算的手段，利用经验来改善系统自身的性能。这里的"经验"在计算机系统中通常以数据（data）的形式存在，因此机器学习研究的主要内容，就是如何从数据中产生"模型"（model）。所谓模型，可以理解为从数据中学得的、能够对新情况做出判断与预测的规律性描述，例如一棵决策树、一个线性判别式或一个神经网络；在机器学习文献中，模型也被称为"学习器"（learner），而"从数据中产生模型"的算法则称为"学习算法"（learning algorithm）。人工智能的总体目标是为机器赋予智能，而机器学习正是其中最关键的能力来源：知识表示、推理、规划等传统分支依赖人工构造知识，机器学习则让机器自己从数据中获取知识，二者互补而非替代。 机器学习的运作方式可以用一个简洁的框架来刻画：给定训练集 D={(x₁,y₁),(x₂,y₂),…,(x_m,y_m)}，其中 xᵢ 表示第 i 个样本的描述（特征向量），yᵢ 表示对应的监督信息（标记），m 为样本个数；学习算法 A 在训练集 D 上运行，输出一个模型 f。此后，对任意新样本 x，模型给出预测 f(x)。换言之，学习过程并不直接针对任务编写规则，而是"让算法自己从数据里找规律"，这正是机器学习区别于传统软件工程的根本所在：传统程序是"规则→执行"，机器学习是"数据→规则"。模型之所以有价值，是因为它抓住了数据背后的潜在规律，从而能对未见过的情形给出合理判断；而"从数据到模型"的完整流程通常包括数据采集与清洗、特征表示、选择学习算法、训练模型、评估性能、部署应用等环节，本书后续章节将逐一展开其中的关键技术。

### 1.2 基本术语

本节介绍贯穿全书的一组基础术语，它们构成后续所有章节的共同语言。用于学习的数据全体称为数据集（data set），其中每一条记录称为一个样本（sample）或"示例"（instance）。刻画样本某方面性质的信息称为特征（feature）或"属性"（attribute），例如感冒病历的恶寒、发热、汗出、脉象；特征的取值称为属性值（attribute value），如恶寒可取"恶寒重""微恶寒"，脉象可取"浮紧""浮数""浮缓"。由全部特征张成的空间称为属性空间（attribute space），也称为样本空间（sample space）或输入空间（input space）；属性空间中的每个点对应一个样本，该点的坐标即特征向量（feature vector）。若样本 x 有 d 个属性，其特征向量可记为 x=(x₁;x₂;…;x_d)，分号表示列向量，d 称为样本的维数（dimensionality）。就感冒辨证问题而言，恶寒、发热、汗出、脉象四个属性构成一个四维属性空间，每份病历对应其中的一个四维点，其坐标就是该病历的四个属性值；例如"（恶寒重，发热轻，无汗，脉浮紧）"就是属性空间中一个具体的点。 我们关心的、关于样本的结果信息称为标记（label）；拥有标记的样本称为样例（example）。一般而言，用 x=(x₁;x₂;…;x_d) 表示样本，用 y 表示标记，则样例记为 (x,y)；所有标记的集合称为标记空间（label space）或输出空间。若预测的是离散值，如"风寒表实证/风热犯表证"，则称分类（classification）任务；若预测的是连续值，如脉率 72 次/分，则称回归（regression）任务。

### 1.3 假设空间

机器学习的核心问题可以形式化地表述为：在假设空间（hypothesis space）中搜索。所谓"假设"（hypothesis），是指关于学习目标的一种可能规律，例如"风寒表实证↔(恶寒重=是)∧(汗出=无)∧(脉象=浮紧)"；所有可能假设的集合构成假设空间。若以合取式描述假设，则对每个属性，其每种具体取值以及通配符"*"（表示"取任意值"）都可以出现在假设中；例如"风寒表实证↔(恶寒重=*)∧(汗出=无)∧(脉象=浮紧)"表示"不论恶寒轻重如何，只要无汗且脉浮紧就属风寒表实"。此外还需考虑"不存在该证型"这种情形，对应空假设 ∅。更一般地，假设还可以用"或"连接多个合取式以表达更复杂的规律（如"风寒或风热均可出现咳嗽"），本书为叙述方便以合取式为例。归纳学习（inductive learning）正是"从样例中学习"的典型形态，其基本过程就是在假设空间中搜索与训练集一致的假设。 以感冒辨证为例：若只考虑恶寒重、汗出、脉浮紧三个属性，且每个属性仅有2种取值（如恶寒重取是/否，汗出取有/无，脉浮紧取是/否），则每个属性在假设中有3种出现方式（两种具体取值加上通配符*），三个属性组合共 3×3×3=27 种假设；再加上表示"不存在该证型"的空假设 ∅，假设空间的大小即为 28。一般地，若样本有 d 个属性、第 j 个属性有 nⱼ 种取值，则假设空间大小为 ∏(nⱼ+1)+1。这个例子说明：即使属性很少、取值很少，假设空间已包含相当数量的候选规律；真实辨证问题中四诊属性更多、取值更稠密（舌象、脉象、症状、体征数十项），假设空间呈组合爆炸式增长，直接枚举搜索不可行，必须借助有效的学习算法。 学习过程就是在假设空间中搜索并不断删减的过程：每获得一个训练样本，就删除与它不一致的假设。具体而言，对正例（风寒表实证），删除所有不能把它判别为风寒证的假设；对反例（非风寒证），删除所有会把它误判为风寒证的假设。经过训练集"筛选"之后，与训练集一致的所有假设构成的集合称为版本空间（version space）。

### 1.4 归纳偏好与NFL定理

当版本空间中存在多个与训练集一致的假设时，学习算法必须依据某种原则从中选择一个作为最终模型，这一原则称为归纳偏好（inductive bias）。归纳偏好是学习算法的固有组成部分：任何有效的学习算法必然有所偏好，否则它无法在多个一致假设之间做出抉择，也就无法输出确定的模型。可以说，归纳偏好刻画了算法"更相信哪一种规律"的先验倾向，它直接决定了模型在未见样本上的预测行为——这是理解"为什么不同的算法在同样的数据上会得到不同模型"的关键。 机器学习中最著名的偏好原则是"奥卡姆剃刀"（Occam's razor）：若有多个假设与观察一致，则选择最简单的那一个。例如在感冒辨证问题中，若版本空间里同时存在"风寒表实证↔(恶寒重=*)∧(汗出=无)∧(脉象=*)"与"风寒表实证↔(恶寒重=是)∧(汗出=无)∧(脉象=浮紧)"两个一致假设，奥卡姆剃刀倾向于选择前者——它更一般、更简洁。然而"简单"本身并无统一标准：按"尽可能特殊"的偏好会选出具体而窄的假设，按"尽可能一般"的偏好会选出宽泛的假设——两者在训练集上表现相同，却可能在未见样本上表现迥异。例如对上述版本空间的假设，若偏好"尽可能特殊"，算法会倾向选择约束最多、最具体的假设；若偏好"尽可能一般"，则会倾向选择约束较少、覆盖面更广的假设。这说明归纳偏好并非客观真理，而是算法设计者注入的主观倾向；学习算法的"好坏"很大程度上取决于其归纳偏好是否与问题本身的规律相契合。例如，若真实辨证规律恰是"无汗且脉浮紧即风寒表实"，则偏好"尽可能一般"的算法能学得更准；若真实规律更特殊（还须恶寒重），则"尽可能特殊"的偏好更优。 由此引出一个深刻的问题：是否存在一个对任何学习问题都最优的算法？"没有免费的午餐"定理（No Free Lunch Theorem，简称 NFL）给出了否定的回答。NFL 定理断言：若所有可能的"真实目标函数"（即所有可能的数据规律）均匀出现，则无论学习算法 A 多么"聪明"、算法 B 多么"笨拙"，两者的期望性能完全相同。

### 1.5 发展历程

机器学习的发展大致经历了三个时期。第一个时期是推理期，约在20世纪50年代至70年代初：研究者认为，只要给机器赋予逻辑推理能力，机器就能实现智能。这一时期的重要标志性事件包括：1950年图灵提出“图灵测试”的思想，1956年达特茅斯会议正式提出“人工智能”概念；而塞缪尔（A. L. Samuel）于20世纪50年代末开发的跳棋程序，通过自我对弈不断改进棋力，堪称“从经验中学习”的最早实践之一。然而人们很快发现，仅有逻辑推理能力远不足以应对真实世界的复杂问题——机器可以证明定理，却难以理解常识、难以适应环境变化。 第二个时期是知识期，约在20世纪70年代中期至80年代：研究者意识到智能行为还依赖于大量知识，于是出现了以专家系统（expert system）为代表的符号主义热潮。专家系统由知识库与推理机两部分构成，知识库中的知识由人类专家手工构造，代表性系统包括化学领域的 DENDRAL、细菌感染诊断领域的 MYCIN 等；其基本思想是“知识+推理=智能”，这一路线也深刻影响了机器学习中的符号主义分支。但人工构造知识库的成本高昂、难以完备且维护困难——这一“知识获取瓶颈”使专家系统的发展遭遇天花板：专家不愿或难以把隐性知识显式化，知识库规模越大越难保持一致，而现实世界的知识又无穷无尽。研究重心由此转向第三个时期。 第三个时期是学习期，从20世纪80年代起：研究者开始让机器直接从数据中自动学习知识，由此形成多个主流方向。

### 1.6 应用现状

经过数十年发展，机器学习已成为计算机科学中最活跃的研究方向之一，并在众多领域取得广泛应用。在图像识别方面，机器学习（尤其是深度学习）的准确率已超越人类水平，广泛用于人脸识别、光学字符识别（OCR）与医学影像判读——例如在肺结节、视网膜病变等影像筛查任务中，模型可辅助医生定位可疑病灶、提示优先级；在语音识别与自然语言处理方面，语音助手、机器翻译、智能问答、文本分类等产品与功能背后都是机器学习模型；在推荐系统方面，电商与内容平台通过机器学习建模用户偏好，实现个性化商品与内容推荐；在自动驾驶方面，环境感知、路径规划等模块大量依赖机器学习；在生物信息学与医疗健康方面，机器学习被用于基因数据分析、药物研发与辅助诊断；在棋类对弈与游戏方面，机器学习驱动的程序已达到人类顶尖水平。此外，搜索引擎的结果排序、垃圾邮件过滤、信用卡欺诈检测等，早已是机器学习的经典落地场景。 机器学习在工业界的成功，通常取决于三个要素：数据、算力与算法。海量高质量的数据是模型学习的源泉——数据规模与质量在很大程度上决定了模型性能的上限，这也是“数据驱动”一词的由来；强大的计算资源（如 GPU 集群、专用加速芯片）支撑大规模模型的训练，使过去不可行的深层模型变得可行；算法的改进则不断提升学习效率与性能上限，例如卷积神经网络、Transformer 等架构的提出。三者协同进步，共同推动了近年机器学习的繁荣。 值得注意的是，应用上的成功并不意味着机器学习是万能的。数据的质量与代表性、任务的定义方式、领域知识的结合程度，都会显著影响实际效果：数据有偏（训练样本与真实分布不符）会导致模型失效，任务定义不当会让模型“答非所问”，缺乏领域约束的模型可能学到与真实规律相悖的模式。周志华教授亦提醒读者，看待机器学习的应用要保持理性：既看到其巨大潜力，也理解其能力边界，避免盲目夸大或贬低——这一态度对技术从业者尤为重要。此外，随着机器学习深入社会生活的方方面面，数据隐私、算法公平、可解释性等伦理与社会问题也日益受到关注，成为研究与应用中不可回避的议题。

### 1.7 本章小结

本章作为全书的绪论，建立了理解机器学习所需的核心概念框架。首先，机器学习是一门研究如何利用计算手段、从经验（数据）中改善系统自身性能的学科，其本质是从数据中产生模型：学习算法在训练集上运行并输出模型，模型对新样本进行预测。在此基础上，我们引入了数据集、样本、特征、标记、样例等基本术语，区分了分类与回归两类预测任务、监督学习与无监督学习两类学习范式，并反复强调：机器学习的目标是获得对新样本的泛化能力，训练样本通常被假设为独立同分布地采样自某个未知分布。 接着，我们将学习过程形式化为在假设空间中搜索与训练集一致的假设，由此引出版本空间的概念；由于版本空间中通常存在多个一致假设，学习算法必须依靠归纳偏好作出选择。奥卡姆剃刀是最常用的偏好原则，但“简单”并无统一标准；NFL 定理则从理论上说明：在所有目标函数均匀分布的假设下，任何算法的期望性能相同——脱离具体问题，任何算法都没有绝对优势。这提醒我们，在实践中应结合问题领域与数据特点，选择合适的算法与归纳偏好。 最后，通过回顾机器学习从推理期、知识期到学习期的发展历程，以及图像识别、语音识别、推荐系统、医疗健康等领域的广泛应用，我们看到：数据、算力、算法三者的协同进步推动着机器学习的繁荣，而对其能力边界保持理性认识同样重要。 本章的概念（数据、假设空间、学习算法、模型、泛化）与思想（归纳偏好、NFL 定理）是后续各章的基础：第2章将讨论模型评估与选择的方法（留出法、交叉验证、性能度量等），第3章起将逐一学习线性模型、决策树、神经网络、支持向量机、贝叶斯分类器等具体模型与算法。读者若希望进一步深入，可阅读 Tom Mitchell 的《Machine Learning》、Bishop 的《Pattern Recognition and Machine Learning》等经典著作，或查阅国际机器学习大会（ICML）、神经信息处理系统大会（NeurIPS）等会议论文——周志华教授在原书每章末的“阅读材料”中均推荐了相应的延伸文献与经典论文，可作为深入学习的重要指引。理解本章内容，就为掌握全书打下了坚实的概念地基。

### 1.8 tcmP 平台映射

### 1.10 辨证假设空间与版本空间

第1.3节的假设空间在 tcmP 中对应“辨证假设空间”：由病（B）、证（Z）、法、方、药各维度取值组合而成，其规模呈组合爆炸——例如病有数十种、证有数百种、方有上千首，组合数即达数百万量级，这正是辨证论治复杂性的形式化表达，也解释了为何单纯枚举规则（知识期路线）在中医领域不可行。教材与平台用三层机制在这个空间中搜索与收敛：其一，病证单元库（BZU）以 BZ-B<病>-Z<证> 编码预先划定了“合法假设”的范围，将漫无边际的组合空间收敛到教材认可的病证组合，相当于给假设空间加上领域约束；其二，0映射N 人格卡与 SKILL.md/SOUL.md 行为规则向模型注入主编与审稿人的口径，相当于为学习算法设定归纳偏好，使模型在众多一致假设中偏向教材主张的规律；其三，审稿流程（tcmreviewer 按“病脉证并治”决策链剪枝）不断删除与教材口径不一致的假设，等效于第1.3节“用训练样本删减假设”的过程。 三层机制收敛后得到的“版本空间”，即平台当前认可的知识集：其中保留的每个假设都能解释现有教材与医案数据，但彼此仍可能有细微差异——这正对应原书“版本空间中多个一致假设并存”的情形，也解释了为何需要审稿人与主编持续裁定。由此，教材口径的更新（如更换主编、修订条文）等价于改变归纳偏好、重构版本空间——平台知识演进获得了清晰的机制解释，也为知识治理提供了可操作的形式化框架。

### 1.11 归纳偏好与NFL定理的工程启示

NFL 定理（第1.4节）在 tcmP 平台上的工程启示：不追求一个“全科 AI 医生”Profile 包打天下，而是以 10 个专科 Profile 分工协作（六经各篇、方剂、中药等），各 Profile 共享 DeepSeek 统一底座，但以不同的 SKILL.md 注入不同辨证偏好——这正是“脱离具体问题谈算法优劣无意义”的平台化实现：对太阳病篇任务，太阳病 Profile 的偏好最合适；对方剂配伍任务，方剂 Profile 胜出；没有一个 Profile 需要在所有任务上最优，也不必为“全科最优”付出不成比例的复杂度（奥卡姆剃刀的工程化）。 同时，归纳偏好的显式化带来可审计性：每个 Profile 的偏好都写在人格卡与 SKILL.md 中，可被 tcmreviewer 审查、可随教材版本更新——偏好不再是黑箱，而是平台治理的对象。平台按“最小必要复杂度”设计各 Profile 的技能与规则，避免引入与教材无关的冗余偏好；若某 Profile 在审稿中反复出错，问题可定位到其注入的偏好并修正，而非整体推翻。对应第1.4节“领域知识才是算法选择的关键”，专科 Profile 正是把“六经辨证的领域知识”编码为归纳偏好的具体实践。此条为平台架构的顶层设计原则，具体 Profile 分工详见 0分布式体系 与 多智能体协同 sheet；相关统计口径送 tcmreviewer 审稿，不改经典原义。
