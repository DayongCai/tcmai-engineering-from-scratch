# 深度不是层数，是每层都在换一次坐标

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 若数据线性可分，感知机在有限步内收敛
- 这不是训练不充分，是假设空间里根本没有解
- 线性模型的假设空间太小，小到连这么简单的一条规律都装不下
- 先把输入映射到一个新坐标系，再在新坐标系里做线性划分
- 后三个点在新坐标里已经线性可分了
- 用层次化的坐标变换复用中间表示

## 边界

- 本章所有数值（2-2-1 结构、XOR 误差 0.5、$h_1/h_2$ 的权重、$L=0.0713\to0.0637$、$0.25^{10}\approx9.5\times10^{-7}$、0.91 与 0.84）均为**演算设定**，用于演示机制，不对应任何实际训练实验。
- 通用逼近定理承诺的是「存在性」，不是「可学性」：存在一组权重能拟合，不等于梯度下降能找到它。
- 本章不对任何网络结构或框架做推荐；层数、宽度、学习率、批量大小都必须在具体数据上以验证集确定。
- 本章为神经网络原理的教学讨论，不构成医学意见、诊断或治疗建议。
