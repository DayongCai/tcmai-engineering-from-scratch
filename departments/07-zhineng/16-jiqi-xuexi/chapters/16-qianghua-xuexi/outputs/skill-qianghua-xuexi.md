# 回报不是奖励的累加，是折现后的和

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 状态的定义是第一个陷阱
- 奖励的设计是第二个陷阱
- 你奖励什么，就得到什么，而不是你想要的什么
- 与真实目标对齐
- Bellman 期望方程
- 当前状态的价值 = 即时奖励 + 折现后的下一状态价值

## 边界

- 本章所有数值（三状态链、$\gamma=0.9$ 时回报 0.81 与 $\gamma=0.99$ 时 0.9801、两状态值迭代的 $V^*=(5.263,4.737)$、$\max$ 高估约 0.13）均为**演算设定**，用于演示折现、迭代与偏差机制，不对应任何真实环境或训练实验。
- 本章不涉及深度强化学习的实现细节（策略梯度定理、GAE、PPO 的裁剪目标）；这些方法的稳定性高度依赖实现细节，不宜凭本章内容直接复现。
- 强化学习在医疗、教育等高风险场景的在线试错存在伦理与法律限制；本章的方法描述不构成在这些场景部署的许可，离线评估与前瞻性试验是前提。
- 本章为强化学习的教学讨论，不构成医学意见、诊断或治疗建议。
