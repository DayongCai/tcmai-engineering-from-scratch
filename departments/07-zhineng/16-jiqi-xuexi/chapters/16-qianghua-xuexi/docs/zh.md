# 第 16 章 · 回报不是奖励的累加，是折现后的和

> **MOTTO:** 「非知之艰，行之惟艰。」——《尚书·说命》
>
> **PROBLEM:** 演算设定一条三状态链 $A\to B\to C$，每次转移奖励为 0，只有到达 $C$ 才有奖励 1，折现因子 $\gamma=0.9$。从 $A$ 出发需要两步才到 $C$，回报是 $0.9^2=0.81$。把 $\gamma$ 改成 0.99，同一个策略、同一个奖励，回报变成 $0.9801$——**「好」的定义变了，而策略没有变**。$\gamma$ 不是超参数中可有可无的一个，它是建模者的价值判断：它决定了智能体愿意为多远的未来等待。选错了 $\gamma$，再好的算法也只是在优化一个错的目​标。

**双根因定位:** 环境逼迫（序贯决策里没有「正确答案」可学，只有延迟到来的标量奖励；把延迟奖励归因到早先的哪个动作上，是一个无法直接观测的信用分配问题）+ 知识积累（有模型与无模型、在策略与离策略、表格与函数逼近，这三组划分对应三种完全不同的失效模式；把它们混为一谈，会把「Q-learning 不收敛」与「探索不足」这两个诊断混淆）

## 一、MDP：五个元素把问题钉死

强化学习的形式化是马尔可夫决策过程 $(\mathcal{S},\mathcal{A},P,R,\gamma)$：

| 元素 | 含义 | 关键点 |
|---|---|---|
| $\mathcal{S}$ | 状态集 | 必须满足马尔可夫性：给定当前状态，未来与历史无关 |
| $\mathcal{A}$ | 动作集 | 离散或连续，决定算法的选择 |
| $P(s'\mid s,a)$ | 转移概率 | 环境的核心，通常未知 |
| $R(s,a,s')$ | 奖励函数 | 设计奖励是本领域最难的部分 |
| $\gamma\in[0,1)$ | 折现因子 | 决定有效视野长度 |

**状态的定义是第一个陷阱。** 马尔可夫性要求「当前状态包含预测未来所需的全部信息」。若状态里漏了一个关键变量（比如病人的用药史），那么同一个状态在不同历史下会导向不同结果，任何基于它的方法都会有系统性偏差。这不是算法问题，是表示问题——而且它不会在任何指标上显现，只会在部署后表现为「时好时坏」。

**奖励的设计是第二个陷阱。** 奖励是你唯一能告诉智能体「什么算好」的通道。它有三个必须满足的性质：

- **可达**：不能只在最终成功时给奖励，否则在随机探索下几乎永远拿不到信号，学习无法启动。典型修法是加中间奖励或使用内在激励。
- **不可投机**：智能体一定会找奖励的漏洞。演算设定：给「血量高」加奖励，智能体会学会站着不动；给「击杀数」加奖励，它会放弃目标去刷小怪。**你奖励什么，就得到什么，而不是你想要的什么。**
- **与真实目标对齐**：代理指标（proxy）与真实目标的偏差，在优化到极致时会被放大。这是「奖励劫持」（reward hacking）的根源，在医疗、教育、推荐系统里都出现过真实事故。

## 二、值函数与 Bellman 方程

策略 $\pi(a\mid s)$ 的价值定义为折现回报的期望：

$$V^\pi(s)=\mathbb{E}_\pi\Big[\sum_{t=0}^{\infty}\gamma^t R_{t+1}\ \Big|\ S_0=s\Big]$$

把它按第一步展开，就得到 **Bellman 期望方程**：

$$V^\pi(s)=\sum_{a}\pi(a\mid s)\sum_{s'}P(s'\mid s,a)\big[R(s,a,s')+\gamma V^\pi(s')\big]$$

这个方程的形态值得盯住：**当前状态的价值 = 即时奖励 + 折现后的下一状态价值**。它把一个无限求和的问题变成了一个递归，而递归可以用迭代解——这是整个领域能工作的数学基础。

最优值函数满足 **Bellman 最优方程**：

$$V^*(s)=\max_{a}\sum_{s'}P(s'\mid s,a)\big[R(s,a,s')+\gamma V^*(s')\big]$$

注意 $\max$ 的位置：它在策略之外，因为最优策略在每一步都选使「即时 + 未来」最大的动作。这个 $\max$ 是**非线性的**（分段线性凸），所以最优方程不能像线性方程那样直接解，必须迭代或规划。

还有两个量必须区分：

- $V^\pi(s)$：在状态 $s$ 下按 $\pi$ 行动的期望回报；
- $Q^\pi(s,a)$：在状态 $s$ 下**先执行 $a$**，之后按 $\pi$ 行动的期望回报。

$Q$ 比 $V$ 多一维，但它的好处是**不需要模型就能改进策略**：$\pi'(s)=\arg\max_a Q^\pi(s,a)$。这就是为什么几乎所有无模型算法都学 $Q$ 而不是 $V$——有了 $Q$，策略改进是一行 `argmax`。

## 三、值迭代：一个能手算的完整例子

值迭代直接对 Bellman 最优方程做不动点迭代：

$$V_{k+1}(s)\leftarrow\max_{a}\sum_{s'}P(s'\mid s,a)\big[R(s,a,s')+\gamma V_k(s')\big]$$

**算例（演算设定）。** 两个状态，动作确定：状态 1 执行 $a$ 得奖励 1 并转到状态 2；状态 2 执行 $b$ 得奖励 0 并转回状态 1。$\gamma=0.9$。初值 $V_0=(0,0)$。

| 轮次 | $V(1)$ | $V(2)$ |
|---|--:|--:|
| 0 | 0 | 0 |
| 1 | 1.0 | 0 |
| 2 | 1.0 | 0.9 |
| 3 | 1.81 | 0.9 |
| 4 | 1.81 | 1.629 |
| 10 | 3.428 | 3.085 |
| 20 | 4.623 | 4.161 |
| 30 | 5.040 | 4.536 |
| ∞ | **5.263** | **4.737** |

不动点可以直接解：$V(1)=1+0.9V(2)$、$V(2)=0.9V(1)$，代入得 $V(1)=1+0.81V(1)$，$V(1)=1/0.19=5.263$，$V(2)=4.737$。

这个例子说明了三件事。第一，**收敛是几何的**，误差每轮乘以 $\gamma$，所以 $\gamma$ 越接近 1 收敛越慢——$\gamma=0.99$ 时需要约 100 倍于 $\gamma=0.9$ 的迭代次数才能达到同样精度。第二，**$V$ 的数值可以远大于单步奖励**，因为它是无限折现和；把 $V$ 当成「预期奖励」来读会误解量级。第三，**这个例子不需要任何数据**，因为模型 $P$ 与 $R$ 都已知——这是「有模型」的规划，不是「无模型」的学习。

**策略迭代**是另一条路：先评估当前策略（解线性方程或迭代到收敛），再贪婪改进，重复。它的迭代次数通常很少（策略空间有限，每轮严格改进），但每轮代价高。值迭代每轮便宜、轮数多。两者在最坏情况下的复杂度同阶，实践中选择看状态空间大小与模型是否显式可用。

## 四、无模型：TD 与 Q-learning

真实问题里 $P$ 与 $R$ 通常未知，只能从交互中采样。两种估计思路：

**蒙特卡洛（MC）**：跑完一整条轨迹，用实际回报 $G_t$ 更新 $V(s_t)$。无偏，但方差大，且必须等回合结束——不适用于连续任务。

**时序差分（TD）**：用一步的实际奖励加上对下一状态的估计，作为「目标」：

$$V(s_t)\leftarrow V(s_t)+\alpha\big[\underbrace{r_{t+1}+\gamma V(s_{t+1})}_{\text{TD 目标}}-V(s_t)\big]$$

括号里那一项叫 TD 误差。TD 是**有偏**的（用了估计值当目标，叫自举 bootstrap），但方差小得多，且可以每步更新、不需要等回合结束。这个「偏差换方差」的交换是 TD 的核心，也是它与 MC 的全部差别。

**Q-learning** 把同样的思想用在 $Q$ 上，并且对下一状态取 $\max$：

$$Q(s,a)\leftarrow Q(s,a)+\alpha\big[r+\gamma\max_{a'}Q(s',a')-Q(s,a)\big]$$

这个更新有一个极强的性质：**它收敛到 $Q^*$，与行为策略无关**（只要每个状态-动作对被无限次访问）。这叫**离策略**（off-policy）——你可以用探索策略采数据，学的却是最优策略的价值。这是 Q-learning 相对于 SARSA（在策略，学的是当前策略的价值）最重要的优势。

但「与行为策略无关」有一个代价：$\max$ 算子会系统性地**高估**。因为 $\max$ 取的是估计值的最大值，而估计有噪声——噪声的正向部分被反复选中，负向部分被丢弃。演算设定：真实 $Q$ 值都是 0，但每个估计有 $\pm0.1$ 的噪声，10 个动作的 $\max$ 期望约为 $+0.13$。这个偏差会在自举中累积，最终导致价值膨胀。Double Q-learning 用两个独立的估计器交叉更新来消除它，是深度 Q 网络（DQN）的标准配置之一。

## 五、探索：$\varepsilon$-贪心为什么不够

所有无模型算法都面临同一个循环：要评估一个动作，必须先试它；但试它可能损失当前收益。这就是探索与利用的权衡。

$\varepsilon$-贪心是最简单的解：以 $1-\varepsilon$ 选当前最优，以 $\varepsilon$ 随机选。它的缺陷是**探索是均匀的**——它会花同样的力气去试一个明显很差的动作和一个可能更好的动作。

更好的做法是**乐观初始化**（把没试过的动作的初始值设高，让算法主动去试）或 **UCB**：

$$a_t=\arg\max_a\Big[Q_t(a)+c\sqrt{\frac{\ln t}{N_t(a)}}\Big]$$

第二项是「不确定性奖励」：访问次数少的动作，奖励大。这使探索自动集中在「不确定且可能好」的动作上，而不是均匀撒网。$c$ 控制探索强度，理论上 $c$ 取奖励范围的一个常数即可保证对数级的遗憾界。

**但所有这些方法都假设「状态可以被反复访问」。** 在医疗、教育、金融这类场景里，同一个病人不能反复试不同方案，真实反馈延迟数月，且试错的代价由患者承担。这使标准的探索策略在伦理上不可接受——这就是为什么这些领域更依赖离线强化学习（从已有日志学）与因果推断，而不是在线试错。**这个边界不是技术问题，是伦理问题，不能用「算法更聪明」来绕过。**

## 六、函数逼近与「死亡三角」

表格方法要求为每个状态-动作对存一个值。状态连续或高维时（图像、生命体征序列），表存不下，必须用函数逼近：$Q(s,a)\approx Q_\theta(s,a)$。

引入函数逼近后，三个要素会互相冲突：

1. **函数逼近**（用参数化模型泛化）；
2. **自举**（用估计值更新估计值）；
3. **离策略**（用行为策略的数据学目标策略）。

三者同时存在时，**收敛性没有保证**——这就是「致命三角」（deadly triad）。Q-learning 加线性逼近在某些情况下会发散；加神经网络则更不稳定，表现为 Q 值爆炸或塌陷。

DQN 的四项工程手段，全部是为了稳住这个三角：

| 手段 | 解决什么 |
|---|---|
| 经验回放 | 打破样本时序相关，让数据接近独立同分布 |
| 目标网络 | 固定 TD 目标一段时间，避免「追自己的尾巴」 |
| 奖励裁剪 | 限制 TD 误差的量级，防止梯度爆炸 |
| 双重估计 | 抑制 $\max$ 带来的系统性高估 |

这四项都不是「技巧」，是对三角冲突的具体补偿。理解了三角，就理解了为什么 DQN 的训练曲线经常剧烈震荡而最终能收敛——那是逼近误差、自举偏差、分布偏移三者在一个狭窄的平衡点上拉锯。

策略梯度方法（REINFORCE、PPO）绕开了部分问题：它们直接对策略参数求梯度，不需要 $\max$，因此不受高估影响；但仍需自举（用 critic）时，三角依旧存在。**没有一种方法能同时消除三者**——只能按场景选一个角落站住。
