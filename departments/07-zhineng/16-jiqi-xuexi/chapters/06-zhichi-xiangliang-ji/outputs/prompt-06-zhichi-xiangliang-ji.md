# 间隔是几何，不是分数 · 提示词

## 用途

给「间隔是几何，不是分数」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「从「分开」到「分得开」 → 对偶：为什么这个形式这么重要 → 核技巧：把内积换掉 → 软间隔：允许错，但要标价」这条链。
