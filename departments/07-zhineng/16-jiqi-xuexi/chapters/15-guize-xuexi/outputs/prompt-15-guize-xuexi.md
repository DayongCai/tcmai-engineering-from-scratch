# 规则的代价不是条数，是它覆盖了多少不该覆盖的 · 提示词

## 用途

给「规则的代价不是条数，是它覆盖了多少不该覆盖的」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「规则的四个量 → Learn-One-Rule：从一般到特殊 → 序贯覆盖与 RIPPER 的剪枝 → 一阶规则：FOIL 与 ILP」这条链。

## 提示词

```
我在学《机器学习》第 15 章「规则的代价不是条数，是它覆盖了多少不该覆盖的」，本章 6 节 / 2,782 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 加一个合取项，覆盖一定不增、精度一般不降；去掉一个合取项，覆盖增、精度降
   - 用一个对称指标处理不对称代价，是规则学习里最常见的量化错误
   - 在假设空间里找一条「最佳」规则
   - 算例（演算设定）
   - 这就是「精度」与「增益」的分野：前者只看纯度，后者兼顾规模
   - 修剪比生长更重要
4. 本章自陈的边界（不得越过）：
   - 本章所有数值（1,000 条样本、400 阳性、规则甲 120/108、规则乙 300/240、信息增益 46.8 与 82.8）均为**演算设定**，用于演示覆盖与精度的权衡，不对应任何真实病例或规则库。
   - 本章的规则示例（脉浮紧、恶寒重等）仅用于说明计算形式，不构成辨证标准；中医证候判断须依教材与临床规范，不得由算法规则替代。
   - 序贯覆盖是贪心算法，不保证全局最优规则集；规则顺序影响 first-match 预测结果，交付时必须固化并声明。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为规则学习的教学讨论，不构成医学意见、诊断或治疗建议；具体操作以现行规范与所在机构制度为准。
