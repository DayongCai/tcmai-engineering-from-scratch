# 弱学习器不是凑数，是要它们错得不一样 · 提示词

## 用途

给「弱学习器不是凑数，是要它们错得不一样」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「误差相关性的算术 → Bagging 与随机森林：降方差 → Boosting：降偏差 → GBDT：把残差当目标」这条链。
