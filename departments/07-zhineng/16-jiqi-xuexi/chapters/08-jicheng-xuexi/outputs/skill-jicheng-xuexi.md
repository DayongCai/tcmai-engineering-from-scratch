# 弱学习器不是凑数，是要它们错得不一样

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 第二项随 $M$ 趋于 0
- 第一项不随 $M$ 变化
- $\rho$ 由数据与算法决定，不由数量决定
- 方差降到四分之一
- 在保持单个模型不太差的前提下，尽量降低 $\rho$
- 换种子不是集成，是重复

## 边界

- 本章所有数值（21 个 0.65 分类器 → 0.923、$\rho=0.8/0.2$ 的方差对比、3 样本 AdaBoost 一轮的权重 $(0.25,0.50,0.25)$、GBDT 0.87 / RF 0.84 / LR 0.81）均为**演算设定**，用于演示机制与量级关系，不对应任何实测竞赛或临床数据。
- 集成模型的训练与推理成本是单模型的数倍到数百倍；本章不讨论分布式训练与推理优化。
- 特征重要性不等于因果效应。基于不纯度下降的重要性对高基数特征有系统性偏好，应优先使用置换重要性，并注明其局限。
- 本章为集成学习的教学讨论，不构成医学意见、诊断或治疗建议。
