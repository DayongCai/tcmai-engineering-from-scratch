## 四、这门课不写什么

1. **不写可直接运行的患者数据与诊疗结论**——教材的样例表是合成数据，本课不把它当真实病例；
2. **不写平台与框架的操作步骤**（版本随时变），只写算法假设与判据；
3. **不写性能数字承诺**（「准确率可达 X%」这类），只写评估方法。
