# p 值不是有效性的判决书 · 提示词

## 用途

给「p 值不是有效性的判决书」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「抽样框：先问样本能代表谁 → 标准误与区间：把不确定性写在脸上 → 假设检验在做什么 → 非劣效与等效：中医研究真正该问的问题」这条链。
