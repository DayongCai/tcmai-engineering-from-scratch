# p 值不是有效性的判决书

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 抽样框与目标人群不一致
- 名义上 600 例的研究，统计效力只相当于 245 例
- （只招愿意配合、病情稳定、住得近的患者）、
- （问卷靠回忆、疗效由知情的医生评定）、
- 样本量增长只能压缩随机误差那一条腿
- 区间比 $p$ 值信息多

## 边界

- 本章数值（29/40 与 22/40、$SE=10.6$ 个百分点、$DEFF=2.45$、Wilson 区间 $[0.219,0.396]$、每组 63 例、把握度 0.55、非劣效算例）均为**演算设定**，用于演示推断量的相互关系，不对应任何真实试验。
- 样本量公式针对两样本均数比较、双侧检验；率的比较、生存终点、重复测量各有对应公式，不可套用。
- 非劣效界值 $\Delta$ 不能由统计方法产生，只能由临床可接受的最小差异决定，本章不给任何病种的具体界值。
- 本章为医学统计推断的教学讨论，不构成研究设计、样本量审定或 regulatory 提交的建议。
