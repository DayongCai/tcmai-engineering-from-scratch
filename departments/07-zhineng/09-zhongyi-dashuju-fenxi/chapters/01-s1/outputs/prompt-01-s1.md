# 数据不是捡来的，是签过字的 · 提示词

## 用途

给「数据不是捡来的，是签过字的」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「四个源，四种缺法 → 抽取：三层，按顺序上 → 整理：三张表定生死 → 图表：先问它要回答什么」这条链。


## 边界

本章为医学数据治理与统计图表的教学讨论，不构成临床、科研伦理或数据合规的法律意见；具体操作以现行规范与所在机构制度为准。
