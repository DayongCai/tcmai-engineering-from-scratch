# 数据不是捡来的，是签过字的

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 5 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 缺失处理的第一步是分清未测量、未记录、未发生三类，而不是挑一个数填进去
- 规则层求准、模型层求全，词典层夹在中间做归一
- 这个数的分母是患者、是就诊、还是处方明细
- ：两条曲线的相对高低完全由两个轴的缩放决定，作者想让它交叉就交叉
- 数据治理的产出不是干净的表，是可复现的路径

## 边界

- 本章所有数值（118 万条、42 个字段、1.7 万种药名写法、各层 P/R、1 钱 = 3.73 g、各组有效例数）均为**演算设定**，用于演示治理环节的量化关系，不对应任何具体医院的真实数据。
- 三层抽取的精确率与召回率随科室、年代、医生书写习惯剧烈变化，本章数值不可作为验收基线；实际项目须自建金标准集重新测量。
- 编码映射依赖标准版本（ICD-10、GB/T 15657、药典）的现行文本，版本升级会造成历史数据不可比，跨年研究必须声明所用版本。
- 本章为医学数据治理与统计图表的教学讨论，不构成临床、科研伦理或数据合规的法律意见。
