# 单因素显著、多因素消失，那不是数据变了 · 提示词

## 用途

给「单因素显著、多因素消失，那不是数据变了」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「回归系数是一句条件句 → 混杂、中介与碰撞：三种「第三个变量」 → 生存分析：删失不是缺失 → 从关联到因果：倾向评分与目标试验」这条链。
