# 换成秩，你换掉的是「差多少」

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 不再有均值差
- 秩变换丢掉间距
- $p=0.03$ 与 $r=0.31$ 一起读，才是完整的句子
- $r=0.62$ 的精度是 ±0.11，不是 ±0.01
- （只招 20–40 岁患者，$r$ 会被压低，不能外推到全年龄）
- （省级层面的「中医资源」与「人均寿命」相关，不代表个体层面成立）

## 边界

- 本章数值（35/35 例、$U=420$、$r_{rb}=0.31$、$r=0.62$ 与 $n=120$ 的 Fisher 区间、$b=0.35$、$R^2=0.18$、三条规则的 sup／conf／lift）均为**演算设定**，不对应任何真实处方库或临床试验。
- 关联规则只能发现共现，不能推出配伍禁忌或协同作用；药对结论须经药理、剂量与临床验证，本章不作任何药效判断。
- 秩检验在方差不齐时对「位置」的解释受限；Hodges-Lehmann 估计要求分布形状相近。
- 本章为医学相关与回归的教学讨论，不构成方剂配伍、剂量或临床用药建议。
