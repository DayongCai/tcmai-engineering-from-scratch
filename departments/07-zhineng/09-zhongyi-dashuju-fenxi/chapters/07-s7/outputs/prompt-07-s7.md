# 设计决定你能问什么问题 · 提示词

## 用途

给「设计决定你能问什么问题」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「四类设计，四种能回答的问题 → 病例谱偏倚：诊断试验的第一杀手 → 诊断试验的算术 → 真实世界数据：能做什么，不能做什么」这条链。

## 提示词

```
我在学《中医大数据分析》第 7 章「设计决定你能问什么问题」，本章 5 节 / 2,517 汉字，习题 7 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 从横断面直接说「某方有效」，是把第四行的结论安在第一行的数据上
   - 单病例随机对照（N-of-1）
   - 模型 × 病例谱
   - 对照组用健康人
   - 只收确诊的典型病例
   - 连续入组、前瞻采集、纳入鉴别诊断人群
4. 本章自陈的边界（不得越过）：
   - 本章全部数值（Sens 0.85／Spec 0.90、$LR^+=8.5$、三档验后概率、1,200 张舌图、$\kappa=0.35$、RWD 缺失与失访比例）均为**演算设定**，不对应任何真实模型或数据库。
   - 本章不评价任何舌诊、脉诊或辨证系统的性能；诊断准确性结论必须在目标人群、目标设备、目标判读者条件下重新测量。
   - 验前概率须来自目标场景的流行病学数据，不能用试验样本的患病率代替；两者常差一个数量级。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为研究设计与诊断试验评价的教学讨论，不构成诊断标准、筛查建议或医疗器械审批意见；具体操作以现行规范与所在机构制度为准。
