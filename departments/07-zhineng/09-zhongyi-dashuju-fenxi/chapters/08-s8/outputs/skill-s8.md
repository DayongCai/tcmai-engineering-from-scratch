# 聚类给出的是分组，不是证型

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 任何聚类结果都首先是一个分组方案，不是一种自然类别
- 标准化方式一换，簇就换，这一点必须在方法里写清
- 权重是研究者的判断，应当明说，不该交给算法默认值
- 能被别人复现的分组才叫分型，只在自己数据里成立的分组叫拟合
- 降维图不能当证据
- 读者看到的「分型清晰」是参数选出来的

## 边界

- 本章全部数值（2,000 例、8 变量、轮廓系数 0.42、Jaccard 0.61／0.58／0.34、$\kappa=0.35$、t-SNE 两档参数、AUC 0.88／0.74／0.68）均为**演算设定**，不对应任何真实数据集或已发表模型。
- 聚类结果不能作为证候分类标准；本章不主张任何新的证候分型，也不评价既有的证候规范。
- 稳定性阈值（0.60／0.75）是经验界线，随样本量、变量数与距离度量变化，须在具体研究中重新校准。
- 本章为聚类分析、可视化与可重复性的教学讨论，不构成证候诊断标准、智能诊疗建议或产品评价。
