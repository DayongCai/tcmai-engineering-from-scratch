# 聚类给出的是分组，不是证型 · 提示词

## 用途

给「聚类给出的是分组，不是证型」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「聚类在做什么，不做什么 → 稳定性：分型能不能成立的入场券 → 可视化：图在替谁说话 → 可重复性：四层，缺一层就断」这条链。
