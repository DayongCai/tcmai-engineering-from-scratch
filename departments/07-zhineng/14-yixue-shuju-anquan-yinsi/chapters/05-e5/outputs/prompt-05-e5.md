# 风险不是漏洞清单，是可能性乘影响 · 提示词

## 用途

给「风险不是漏洞清单，是可能性乘影响」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「风险 = 可能性 × 影响，以及为什么"漏洞数"不是风险 → 责任体系：三道防线，与一个能停机的权力 → 攻击面地图：人、接口、供应链、模型 → 供应链：风险是从别人那里进来的」这条链。

## 边界

本章为信息安全风险管理的教学讨论，不构成安全评估结论或技术保障承诺；具体操作以现行规范与所在机构制度为准。
