# 第 4 章 · 同意不是一次签字，是一段可撤回的授权

> **MOTTO:** 「凡事豫则立，不豫则废。」——《礼记·中庸》
>
> **PROBLEM:** 一项回顾性研究要用十年的 8 万份病历，方案里写着"取得患者知情同意"。真做起来：联系 8 万人，接通率按 40% 算，接通后愿意签的按 60% 算，最终覆盖 1.92 万人，占 24%。剩下 76% 不是随机缺失——能联系上的是近期就诊、仍在本地、病情相对轻的那批人，失访的恰恰是转诊、死亡、重症与流动人口。**用这样一份样本来回答"十年间的疗效趋势"，结论的偏倚比样本量的问题严重得多。**所以真实的二次利用很少靠逐人同意，而靠伦理审查加去标识；但"免除同意"是有条件的例外，不是默认路径。把例外当默认，是这一章要拦下的第一个错误。

**双根因定位:** 环境逼迫（临床数据的二次利用需求持续增长，而逐一联系的成本随年代跨度和机构规模迅速上升；一项十年跨度、跨机构的研究，联系成本几乎等于研究本身）+ 知识积累（知情同意在教材里被讲成"一份同意书 + 一次签字"，而它实际上是一条跨越采集、使用、共享、撤回、销毁的责任链；链条上每一环的技术要求不同，课程通常只讲第一环）

## 一、伦理审查到底在审什么

伦理审查常被误解为"盖章"，因为它审查的很多内容看起来是形式：方案、同意书、保密措施、利益冲突声明。但审查真正在判的是三件事，这三件事都不在纸面上。

**第一件：风险受益比是否成立。**不是"有没有风险"，而是"风险相对于受益是否可接受"，以及"这个判断是由谁做出的"。研究者自己判断自己的方案，风险受益比永远成立；所以审查要有独立于研究者的成员。医疗数据研究的典型风险不是身体伤害，而是隐私、歧视、群体污名与商业滥用，这些风险的承担者往往不是受益者——这一点必须在审查记录里写明，而不是用一句"风险极小"带过。

**第二件：隐私保护方案是否与风险匹配。**审查要看到具体的技术措施，而不是"我们将严格保密"。可核的表述是：数据以什么形态离开机构、去标识到什么程度、在什么环境里分析、结果以什么粒度输出、保存多久、谁有权接触。**"在受控环境内分析、只导出聚合结果"是一句可核的话；"严格保密"不是。**

**第三件：弱势群体与利益冲突。**患者相对于机构是弱势的，员工相对于雇主是弱势的，学生相对于教师是弱势的。弱势体现在同意的自由上：一个由主治医师在查房时递上的同意书，即使文本完美，自愿性也存疑。利益冲突则要问：研究者是否从数据的使用中获得与研究结论相关的利益（专利、股权、职务晋升）。

## 二、同意的四要素与三个层级

一份有效的同意，四个要素缺一不可。

| 要素 | 具体要求 | 常见失效 |
|---|---|---|
| 告知充分 | 目的、范围、方式、期限、风险、权益、退出途径 | 用"用于医学研究"覆盖一切 |
| 自愿 | 无胁迫、无不当诱导、可拒绝而不影响诊疗 | 与挂号、住院流程捆绑 |
| 能力 | 年龄、意识状态、代签规则明确 | 代签人越界，家属代签患者可自主决定的事项 |
| 可撤回 | 撤回方式明确、撤回后数据处理规则明确 | 写了"可撤回"，但没有撤回入口 |

第四行是最容易空的。撤回权如果在技术上没有入口，它就只是文本上的权利。可执行的撤回至少要有：一个可到达的受理渠道、一个能在系统里定位该患者全部数据的索引（这又回到第 7 章的患者主索引问题）、一个明确的"撤回后既有分析结果如何处理"的规则（通常是从撤回时点起停止使用，已发表的聚合结论不追溯撤回，但应说明）。

**三个层级的选择**决定了同意的颗粒度：

- **具体同意**：一项研究一份同意书。最严格，成本最高，适合干预性研究或高风险数据。
- **广泛同意**：就某一类研究（如"中医药治疗风湿病的疗效研究"）一次授权，配合治理机制。它的合法性完全依赖配套治理——用途白名单、独立监督、定期报告、可撤回。**没有治理的广泛同意等于一张空白授权书。**
- **动态同意**：分层选项 + 可随时调整。技术上要求同意状态是"活的数据"，能被下游系统实时读取（第 2 章的同意状态跟随问题）。

三者不是替代关系，是按风险分层使用。实务里最常见的错误是全机构只用一种：要么全用具体同意（研究推不动），要么全用一揽子授权（同意形同虚设）。

## 三、二次利用：从「同意过」到「同意到哪一步」

"同意过"是一句没有信息量的话。真正要回答的是：同意到哪一步？下面这张矩阵是本章的核心工具。行是用途，列是数据形态，格内写该组合所需的授权与审查级别。

| 用途 | 原文（可识别） | 去标识个体级 | 聚合统计 |
|---|---|---|---|
| 临床诊疗 | 院内在授权范围内直接使用 | 可用于质控分析 | 常规 |
| 质量管理 | 需事由与留痕 | 常规 | 常规 |
| 院内科研 | 需伦理审查 + 具体/广泛同意 | 伦理审查（可申请免除） | 备案 |
| 多中心协作 | 伦理审查 + 单独授权 + 协议 | 伦理审查 + 协议 + 环境约定 | 备案 |
| 教学 | 需去标识，且不得带出 | 可用 | 常规 |
| 对外商业合作 | 原则上不做；确需时单独授权 + 高一级审查 | 单独授权 + 协议 + 审计权 | 单独评估 |

这张表有三处值得强调。

**其一，"院内科研"与"多中心协作"之间有一道明确的台阶。**数据一旦离开本机构，即使去标识，风险也升一级——因为接收方的保护能力、二次转发、与其他数据集的拼接，都不在本机构的控制之内。跨机构时把"协议 + 环境约定 + 审计权"作为必要条件，不是不信任合作方，是承认控制权已经部分转移。

**其二，"对外商业合作"这一行不能空着。**很多机构的制度里没有这一行，于是它按"科研"办理，最终以"技术合作"的名义把数据交给了企业。把这一行明确写出来并给出最严的条件，比假装它不存在要好。

**其三，聚合统计不是无风险。**小样本的聚合会泄漏个体（第 8 章的最小单元阈值），时间序列的聚合可以被差分（同一组在不同时点的两次发布，相减即得个体增量）。"只出统计结果"必须附带"每组不少于 N 例、且不发布可连续比对的时间序列"这样的具体约束。

## 四、免除同意的四个条件，与它的替代物

免除知情同意是例外，四个条件要同时成立：

1. **研究具有重要社会价值，且逐一取得同意在客观上不可行或代价过高。**注意是"不可行或代价过高"，不是"不方便"。
2. **对当事人的权益影响极小。**判据是：如果当事人事后知道，是否会有合理的反对理由。
3. **不涉及可识别信息，或研究过程不接触可识别信息。**这一条要求数据在进入研究环境之前就完成去标识，而不是"研究者承诺不看姓名"。
4. **经伦理审查批准，并有保密承诺与数据安全措施。**审查要看到具体措施，与第一节的要求一致。

四个条件里最容易松的是第 2 条，因为它依赖判断而非事实。可操作的收紧办法是加两条替代性约束：

- **不回溯联系**：研究过程中不得以任何方式重新识别并联系个体（包括通过病历号回查）。
- **结果只出聚合**：发表与共享只能给聚合结果，且满足最小单元阈值；个体级数据不得离开分析环境。

这两条的价值在于，它们把"影响极小"从一句判断变成两个可检查的行为约束。**当"影响极小"无法被证明时，用"不联系 + 只出聚合"把它变成可执行的近似。**

## 五、患者权益、职业行为，以及"人是最弱环"的工程解

患者的权利清单不长：查阅、复制、更正、撤回同意、要求解释。难点不在权利本身，在可行性——如果一名患者的病历散落在门诊、住院、检验、影像、体检五个系统，且患者主索引不完整，那么"查阅全部病历"这个请求在技术上就无法完成。**权利的实现依赖数据治理的水平，这一点在教材里很少被点明。**

更常见的一类风险不在制度，而在人。院内越权查阅的典型情形有四种：查熟人、查同事、查公众人物、查与自己有纠纷的人。这四种情形有一个共同点——查阅者在系统里是**有权限的**，所以权限控制拦不住，只有行为分析能拦。

可行的工程解是三条，成本都很低：

1. **同科室 + 非同诊疗关系告警。**查阅者与被查阅者不在同一诊疗组、且无挂号/住院记录关联时，记录并告警。
2. **敏感人物名单。**对公众人物、职工、家属建立保护名单，访问需二次审批。名单本身是敏感信息，须单独加密、限制可见范围——否则保护名单自己变成一份"名人就医索引"。
3. **批量与异常时段限制。**单账号短时间内连续查阅超过阈值、或在非工作时段批量导出，触发复核。阈值要按科室基线设定，不能用全院一个数。

这三条的共同逻辑是：**把"人是否守规矩"换成"行为是否偏离基线"。**培训仍然要做（人员安全意识是基础），但培训的效果不可测量，而偏离基线的告警可测量、可复核、可追责。安全体系里凡是只能靠"大家注意"的环节，都应当被替换成可测量的机制。

还有一条职业规范值得单独写：**离职与轮岗时的数据交接。**实务中大量数据是在人员流动时带出的——个人网盘、私人邮箱、本地硬盘、微信传输。交接清单里应当包含"本地副本清零"这一项，并且要能被抽查（比如检查工作设备的同步目录）。

## 代价与边界

- 本章的 8 万份、接通率 40%、同意率 60%、覆盖 24% 等数值均为**演算设定**，用于说明逐人同意的可行性与偏倚方向，不对应任何具体研究的实际应答率。
- 免除同意的四个条件是本章的概括性表述，具体适用须依现行规定与伦理委员会的审查结论；本章不给任何"可以直接免除"的结论。
- 广泛同意与动态同意在技术上依赖同意状态的可读取与可撤回，若机构尚未建立统一的同意管理，采用这两种模式会形成"纸面授权、系统不知情"的空转。
- 本章不评价任何具体研究方案，也不构成伦理审查意见；审查结论以伦理委员会正式文件为准。

**免责声明：** 本章为伦理审查与知情同意的教学讨论，不构成伦理审查结论或法律意见；涉及具体研究、数据二次利用与免除同意的判断，须由伦理委员会依现行规定与程序作出。
