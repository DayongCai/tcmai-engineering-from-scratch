# 权限不是发给岗位的，是发给任务的 · 提示词

## 用途

给「权限不是发给岗位的，是发给任务的」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「RBAC 的必然过宽，与 ABAC 的补法 → 最小必要与紧急授权 → 审计日志：六个要素与三条告警规则 → 加密：三个层次，一条密钥链」这条链。

## 边界

本章为访问控制、加密与备份恢复的教学讨论，不构成安全建设方案或技术承诺；具体操作以现行规范与所在机构制度为准。
