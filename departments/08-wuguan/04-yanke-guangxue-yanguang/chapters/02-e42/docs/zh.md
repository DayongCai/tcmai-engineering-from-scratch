# 第 2 章 · 屈光不正的类型：先问「哪条路径」，再问「多少度」

> **MOTTO:** 「久视伤血，久卧伤气，久坐伤肉，久立伤骨，久行伤筋，是谓五劳所伤。」——《素问·宣明五气》
>
> **PROBLEM:** 两个人验光都是 −8.00 D。一位眼轴 25.6 毫米、角膜约 41 D；一位眼轴 23.6 毫米、角膜约 45.5 D。1 毫米眼轴约折 2.3 D，两毫米的轴长差约合 4.6 D，而 4 D 余的角膜屈光力差能把其中大半抵掉，于是两人落在同一个度数上。可前者要查眼底、随访眼轴，后者要查角膜形态、随访地形图。分类表里只有「高度近视」一栏，装不下这个差别；而这一栏背后，是两条完全不同的路径。

**双根因定位:** 环境逼迫（配镜窗口只要一个数，处方笺上也只有一栏度数，写多了没人看）+ 知识积累（「方向—来源—度数」三层分法早已成熟，却在流转中被压成一张按度数排列的表，机制被挤到表外，剩下的只有标签）

**教材出处:** 教材·第3章·3.2.1

## 一、四个词不在同一层

近视、远视、散光、屈光参差，四个词常被并排放进一张表，像是同一层级的四种东西。它们不是。

近视与远视说的是**焦点相对视网膜的位置**：焦点在前为近视，在后为远视。散光说的是**两条子午线上的焦点不重合**，与前后无关，是「一个点被拉成两条线」。屈光参差说的是**两眼之间的差异**，是双眼关系，不是单眼状态。前两个是方向，第三个是形态，第四个是关系。把它们并列，等于把「向左」「向上」「斜着」「两个人不一样」放进同一张分类表。

这一层错位有实际后果。一个人 −3.00 D 的近视合并 −1.50 D 的散光，处方上写成「−3.00 / −1.50×180」，读的人容易把它当成「近视 3 度加散光 1.5 度」两个独立的量，而实际上球镜与柱镜在同一只眼上共同决定像的位置与形状，不能拆开单独理解。等效球镜的算法是球镜加柱镜的一半，−3.00 与 −1.50 合起来相当于 −3.75 的球面离焦；这个数在比较两眼、判断进展时才用得上，处方上不写，因为它不产生可戴的镜片。

所以正确的顺序是三层：先问方向（焦点在前还是在后），再问来源（是轴长、是屈光力、还是角膜形态），最后才问度数（多少 D）。跳过前两层直接报度数，得到的是一张标签，不是一份诊断。

## 二、路径一：眼轴

轴性屈光不正是最常见的一条路。眼球前后径超过该屈光力对应的焦距，焦点落在视网膜前，是为轴性近视；眼轴短于焦距，焦点落在视网膜后，是为轴性远视。按简化眼估算，每 1 毫米轴长约合 2.3 D，这个系数是本章所有算例的骨架。

轴性近视的风险不在度数，在眼轴本身。眼轴持续延长的眼，巩膜被牵拉变薄，视网膜、脉络膜随之变薄，周边部容易出现格子样变性、裂孔，黄斑区容易出现后巩膜葡萄肿、脉络膜新生血管。这些并发症与度数相关，但更直接地与眼轴长度和增长速度相关：两个同为 −6.00 D 的人，眼轴 26 毫米与 28 毫米，眼底风险不是一个量级。这就是现代近视管理把眼轴测量放进常规随访、而不只记度数的理由。

轴性远视则相反。眼轴偏短的眼，眼前段相对拥挤，前房偏浅，是闭角型青光眼的解剖基础之一；同时因为常年动用调节，容易较早出现视疲劳，儿童则容易因调节与集合的联动而出现内斜。同样是「远视」，一个轴偏短的成年人要查前房深度与眼压，一个远视儿童要查眼位与弱视，方向相同，路径相同，要查的东西完全不同——差别来自年龄，这一点留到第六章。

判断是不是轴性，靠的是把三个量放在一起看：眼轴、角膜屈光力、晶状体屈光力。眼轴长而角膜平，是典型的轴性；眼轴正常而角膜陡，是曲率性；两者都正常而度数仍在，要考虑晶状体屈光力异常，比如晶状体核硬化导致的屈光指数性近视。单看眼轴一项，只能得到「偏长」这个描述，得不到「轴性」这个结论。

## 三、路径二：屈光力，以及散光的两个来源

屈光力这条路，又可以拆成角膜与晶状体两段。

角膜提供全眼约三分之二的屈光力，它的曲率稍有变化，度数就明显移动。角膜偏陡，屈光力偏强，焦点前移，是为曲率性近视；角膜偏平，屈光力偏弱，是为曲率性远视。角膜形态的改变有些是先天的，有些是后天获得的：圆锥角膜使局部变陡，屈光手术使中央变平，长期配戴不合适的接触镜也可能改变角膜形态。这些情况下，度数是结果，形态才是原因，所以必须做地形图，不能只做验光。

晶状体那一段更隐蔽。晶状体屈光力随年龄与代谢状态变化：核硬化使折射率升高、屈光力增强，表现为近视漂移；糖尿病血糖波动使晶状体渗透压改变，屈光力可在数日内明显移动，表现为「血糖一高就变近视、控制后又退回去」。这一类屈光不正的特点是「可逆」与「波动」，验光单上只是一个时点的快照，若不做病史询问，很容易被当成真性近视去配镜。

散光的来源同样是两段。角膜散光占全眼散光的四分之三以上，可用地形图直接读出；晶状体散光较小，多见逆规，方向常与角膜的顺规散光相反，起部分抵消作用。所以地形图读出 1.50 D、主觉只测出 0.75 D，不一定是哪一方测错，而是两个来源在互相抵消。临床判断「矫多少」，看的是两者之差是否落在晶状体散光的合理范围内；差值离谱，先怀疑标注错误——轴向镜像、左右眼错位，这两种在转抄中最常见。

散光还有一个方向问题：顺规、逆规、斜向。方向不同，对视力的影响不同，对镜片设计的要求也不同。同样 1.00 D 的散光，逆规往往比顺规更影响阅读，因为阅读时的笔画方向与模糊方向叠加。但方向不改变「散光」这个分类，只改变矫正的优先级，这一点要分清。

## 四、接口：能近怯远是症状名，不是机制名

中医眼科典籍里没有「轴性近视」这个词，但有对应的症状名。《审视瑶函》载「能近怯远」「能远怯近」，前者指视近清晰、视远模糊，后者相反。这是**症状命名**：它记录的是患者的主观体验，不含屈光机制，也不分轴性与屈光性。用「能近怯远」替代现代分类，会把「眼轴 26 毫米」与「角膜 45 D」这两个完全不同的问题压成同一个词；反过来，用现代分类去否定症状名，也丢掉了它对主诉的准确描述。

病因上，旧籍多归「久视伤血」与肝肾不足。《素问·宣明五气》把「久视伤血」列为五劳之一，讲的是持续近距离用眼耗伤精血；《素问·五脏生成》说「肝受血而能视」，把视觉与肝血联系起来。这套解释的落点在整体状态——为什么这个孩子一放学就眼酸、为什么这个成年人一加班就视物昏花——而不在「角膜曲率 7.9 毫米为什么会折 48 D」。两者可以并列写进同一份病历：一记主诉与证候，一记眼轴与角膜屈光力。

界限要划在「翻译」这一步上：能近怯远不能翻译成 −3.00 D，肝血不足也不能解释眼轴为什么长了 0.4 毫米。但「久视伤血」对随访节奏有实际提示——它提醒你问用眼时长、问阅读距离、问户外活动，这些都是现代近视管理里被反复验证的因素。两套语言在这里不是互相解释，而是各自提供一半的观察清单。

## 代价与边界

分类的终点不该是度数。度数是一个结果，轴性与屈光性是产生这个结果的路径；路径决定随访什么、警惕什么，结果只决定配多少。任何以度数为唯一标准的分类，都会把高风险者与低风险者混在一栏。

分类还丢掉四样东西。**时间**：分类是横断面的，两个同为 −3.00 D 的十岁儿童，一个去年 −1.00 D、一个去年就 −3.00 D，前者在进展、后者已稳定，而表里没有「速度」这一栏。**调节状态**：分类默认调节松弛，而活人几乎从不松弛，同一只眼散瞳前后可以差出明显度数，两个数都「真实」，取决于测量条件。**双眼关系**：近视、远视、散光三节都是单眼叙述，而实际主诉常来自不等像、抑制、融合困难。**眼底与角膜形态**：度数相同、眼底不同的人，风险判若两人。

本章的分级只作分类边界，不构成对任何个体的诊断标准。屈光参差的阈值不裁定唯一解，只要求注明用的是哪一个，并以「是否已出现抑制或立体视下降」为更硬的判据。本章不给处方模板，不给镜片参数。

脚本打印的是本章正文的规模、习题的阶段分布与接地情况；退出码为 0 表示各项契约满足，非 0 表示有不满足的项，输出里会逐条写明。


分类是否用对，可以用三个算例自查。

第一个算例，两条路径同一个度数。甲：眼轴 25.6 毫米，角膜 41 D，晶状体 19 D，合计屈光力约 60 D；按简化眼的收束力算，1.3333 / 0.0256 ≈ 52.1 D，与 60 D 相差约 −7.9 D。乙：眼轴 23.6 毫米，角膜 45.5 D，晶状体 19 D，合计约 64.5 D；1.3333 / 0.0236 ≈ 56.5 D，与 64.5 D 相差约 −8.0 D。两人都落在 −8.00 D 附近，但一个靠长度、一个靠屈光力。复算的核对点是：把三行分别写出来，看哪一行偏离基准最多——这一项决定随访查什么。

第二个算例，等效球镜。处方 −3.00 / −1.50×180，等效球镜 = −3.00 + (−1.50 / 2) = −3.75 D。若另一眼为 −3.50 / −0.50×10，等效球镜 = −3.75 D。两眼等效球镜相同，但柱镜量差 1.00 D，视觉质量不会相同。这一步说明：比较两眼、判断进展用等效球镜，评价视觉质量必须看柱镜。

第三个算例，散光抵消。地形图 1.50 D 顺规，主觉 0.75 D，差 0.75 D；若角膜散光轴位在 180 度、主觉轴位也在 180 度附近，说明晶状体提供了约 0.75 D 的逆规散光。核对方法是：轴位方向相反、量值可解释，才算抵消；轴位相同而量值差一半，更可能是测量或转抄问题。

三个算例都做完，再问一句：这个分类是否同时说清了方向、路径与度数？只说清了度数，分类就没做完。
