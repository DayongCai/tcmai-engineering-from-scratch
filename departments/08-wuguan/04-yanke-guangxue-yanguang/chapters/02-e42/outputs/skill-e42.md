# 屈光不正的类型：先问「哪条路径」，再问「多少度」

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 4 条核心判断见下）；
4. 用 `quiz.json` 的 8 道题自检，答不上就回到对应小节。

## 核心判据

- 焦点相对视网膜的位置
- 两条子午线上的焦点不重合
- 两眼之间的差异
- ：近视、远视、散光三节都是单眼叙述，而实际主诉常来自不等像、抑制、融合困难

## 边界

- 只写类别与要点，不写操作参数。
- 本章为教学材料，不构成医学意见、诊断或治疗建议。文中屈光度与眼轴数值为教学设定的示例，不用于任何个体的诊断分级。
