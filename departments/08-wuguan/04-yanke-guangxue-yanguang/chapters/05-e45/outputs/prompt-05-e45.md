# 镜片与矫正：改的是入射光，不是眼 · 提示词

## 用途

给「镜片与矫正：改的是入射光，不是眼」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「镜片只做一件事：改入射光的聚散度 → 球柱镜：一个面，两条子午线 → 顶点距离、放大率与棱镜效应 → 接口：外治诸法，治的是「外」」这条链。

## 边界

本章为教学材料，不构成医学意见、诊断或治疗建议。文中镜片屈光力、顶点距离与棱镜数值均为教学设定的示例，不构成配镜处方；具体操作以现行规范与所在机构制度为准。
