# 第 8 章 · 记录：把「看到」写成可以被别人核对的东西

> **MOTTO:** 「四诊分观，则各有所当；四诊合论，亦皆有可凭。」——《望诊遵经·气色声音合参》
>
> **PROBLEM:** 把一张脸的可描述空间摊开：二十四个部位、五色、十法五对——名义上的格子是 24×5×32＝3840 个。而一份门诊病历上的望诊记录，通常是一句话，四到八个字：「面色萎黄」。这句话里，部位只到「面」（二十四分之一），色是「黄」，气是「萎」（大致对应十法里的「夭」），程度没有，采集条件没有。**三千八百四十个格子里，实际被填写的是三个，且其中两个没有量。** 复核的人拿到这句话，无法判断是哪个部位、黄到什么程度、在什么光线下看的。于是「复核」只能退化为「再去看一眼」，而再看一眼的结论，取决于第二位医师那天的心情与诊室的灯。
>
> **双根因定位:** 环境逼迫（门诊时间以分钟计，记录必须快；写得越细越写不完，医师自然会压缩成一句话。这句话在同行之间是可读的——因为大家共享同一套省略法，不需要写清部位与条件）+ 知识积累（本章 3 单元 7,506 汉字，是全课单元最少的一章，讲病历书写与望诊复核；外源《望诊遵经》有「推广望色大意」「主病条目附识」「气色声音合参」「气色脉象合参」「气色病症合参」五篇，把「合参」写成了一套关系规则，而不是一句口号）

## 一、最小可记录单位：四段，缺一段就不可复核

一句话要能被别人核对，至少要带四段信息：

| 段 | 内容 | 「面色萎黄」里有没有 |
|---|---|---|
| 部位 | 哪个区，边界依哪套分区 | 只有「面」，未细分 |
| 征象 | 哪个名目（色／气／形） | 有：黄、萎 |
| 程度 | 相对什么基线的多少 | 无 |
| 条件 | 光线、化妆、时间、设备 | 无 |

四段齐了，才是可复核的。举例：

> 左颊—黄—较上次深约一个可察觉级（ΔE≈2）—自然光，未化妆，上午，同一设备

这句话比「面色萎黄」长六倍，但它可以被第二个人在另一个时间点核对：部位对得上、基线有定义、条件可重复。**复核的前提是可重复，而可重复的前提是把条件写下来。**

工程上，这四段正好对应四个字段：`site`、`sign`、`grade`、`condition`。前两个是名目层，后两个是测量层。缺了后两个，记录就只是一句形容。

## 二、三层分离：名目层、特征层、判据层

这是全课的方法论收口。把望诊拆成三层，各层各管各的，谁变了都不牵连别人。

| 层 | 内容 | 变更成本 | 谁定 |
|---|---|---|---|
| 名目层 | 五色、十法、五轮、脏腑分属、部位表 | 高（涉及学术传统） | 学术共同体 |
| 特征层 | Lab 值、面积比、纹理、光泽、时序参数 | 中（涉及工程实现） | 工程与数据规范 |
| 判据层 | 阈值、分类器、规则 | 低（换个任务就换） | 具体应用 |

三层分离的第一个好处：**名目变了不影响测量。** 某本教材把「疾」并入「数」，或把五轮换成四纲，测量层的 Lab 值与面积比一个字都不用改，只需改映射表。

第二个好处：**测量换了不影响名目。** 从 RGB 换成高光谱，名目层照样是那五个色名；变的只是特征层的分辨率与解释力。

第三个好处：**映射是显式的、可讨论的。** 名目与测量之间那张对照表，可以公开、可以被质疑、可以被修订。这正是「客观化」应有的形态——**不是用仪器重新发明一套名目，而是把命名与测量分成两件事，再用一张公开的表连起来。**

反过来，把三层搅在一起，就会出现本课反复批评的那些错误：把胆红素叫「脾病」（名目与测量错配）、把口红写进「深赤」（条件缺失）、用测试集选特征（判据层偷看特征层）。

## 三、复核：双人盲法，和 Kappa 的正确用法

复核不是「请上级医师再看一眼」，那只是第二次判读。真正的复核要满足三条：两位判读者互相不知道对方的结论、样本顺序随机、判读条件一致（同一批图像、同一套名目、同一份说明）。

一致性指标通常报 Kappa。它校正了「偶然一致」，这一点比原始一致率强。但它的用法有两个必须说明的坑。

**坑一：Kappa 的绝对值依赖类别分布。** 这就是所谓 Kappa 悖论。给一个演算设定：100 例样本，其中 90 例为「有泽」、10 例为「无泽」；判读者 A 判出 88 有泽／12 无泽，判读者 B 判出 87 有泽／13 无泽，两人原始一致 85 例，一致率 85%。期望一致率约为 0.78，于是 Kappa 只有 0.31。**85% 的原始一致，换来一个「中等偏下」的 Kappa**——原因不是两人不一致，而是这个任务里「有泽」太多，随机猜也能猜对大半。

**坑二：Kappa 高不等于临床可用。** 两位医师可以在一套含混的名目上高度一致（比如都按同一本教材的字面判），但这套名目本身可能与病理无关。一致性是必要条件，不是充分条件。

所以复核报告至少要有四项：类别分布、原始一致率、Kappa（或 PABAK 等对偏斜稳健的指标）、以及判读说明的版本。少任何一项，这个数都不能被解释。

还有一层复核常被忽略：**复核的对象不只是标签，还包括采集条件。** 两位医师对同一张照片判得不一致，可能不是判断不同，而是这张照片本身在边界上（高光、阴影、模糊）。所以复核要同时记录「图像质量是否足以判读」，并把「不可判读」作为独立的一类，而不是强行二选一。

## 四、四诊合参不是投票

这是本章最容易被工程实现带偏的一处。

现代系统常见的做法，是把望、闻、问、切各做成一个特征向量，拼接起来送进模型，权重由数据学。这在形式上叫「多模态融合」，但它丢掉了原文的核心结构。

原文给的不是加权求和，是**关系规则**：

> 「色青者其脉弦……见其色而不得其脉，反得其相胜之脉，则死矣；得其相生之脉，则病已矣。」

这里的关键不是「色」和「脉」各自的值，而是**两者之间的关系**：相应、相生、相胜。而且原文明确说，不一致本身携带信息——「应者其常，不应者其变，知其所以变，则知其所以病矣」。

一个忠实于这个结构的接口，应该输出三样东西：

1. 四组断言，各带置信度与出处（望：某部位某征象；闻：某声音；问：某主诉；切：某脉象）；
2. 一个关系层：两两之间是「相应」「相生」「相胜」还是「缺失」；
3. 一个处置：一致且无明显太过不及 → 倾向于平；出现相胜或明显矛盾 → 输出「待复核」，并指出矛盾在哪两诊之间。

第三条尤其重要。**矛盾时取平均，是把信息抹掉；矛盾时输出「待复核」，是把信息交回给人。** 前者在数据上更好看（总能给出一个答案），后者在临床上更安全。

## 五、伦理：人脸是生物识别信息

这一节不是免责声明的前置，而是方法的一部分。因为采集方式一旦不合规，数据本身就不能用。

**面部图像可复原身份。** 打码、裁切到只剩颊部、模糊处理，都不等于匿名——人脸识别在低分辨率下仍有相当能力，且与其他数据关联后几乎必然可复原。所以「去标识」这个词要慎用，准确的说法是「降低可识别性」。

**知情同意要覆盖用途。** 采集时说明：用于什么研究、保存多久、是否出境、是否用于训练模型、是否可能被二次使用。二次使用（科研转商业、训练转发布）通常需要重新同意，不能用第一次的同意书覆盖。

**数据最小化。** 不需要存原图就存特征；不需要整脸就存 ROI；不需要长期保存就设定期限并到期删除。这不是保守，是让数据在被泄露时损失最小。

**器械属性。** 若产品声称用于诊断或辅助诊断，通常按医疗器械管理，须履行相应的注册或备案程序；「只是教学演示」不构成豁免。这一条在把 demo 变成产品的转折点上最容易被忽略。

**群体公平。** 面色的判据本身是群体相对的（第 2 章的基线、第 5 章的齿色与年龄、第 4 章的鼻准与族群）。数据集的人种、性别、年龄分布必须报告，且要报告分层的性能，而不是只报总体。

## 六、一份可执行的记录模板

把前面几节压成字段，得到一张可以直接用的表：

| 字段 | 取值 | 必填 |
|---|---|:--:|
| 时间 | 日期、时段 | ✓ |
| 部位 | 分区名＋分区版本 | ✓ |
| 征象 | 名目层取值（如「黄」「夭」） | ✓ |
| 程度 | 相对基线的 ΔE 或等级 | ✓ |
| 条件 | 光线、色温、是否化妆、是否进食 | ✓ |
| 设备 | 型号、是否偏振、是否标准光源 | ✓ |
| 图像 | 编号、质量评级（可判／边界／不可判） | ✓ |
| 判读者 | 姓名、名目版本 | ✓ |
| 复核者 | 姓名、是否盲法 | 视用途 |

一条原则：**宁可少记，不可混记。** 字段空着，读者知道这里没有信息；字段填了含混的值（「色偏暗」），读者会以为这里有信息。前者可以补，后者会误导。

## 代价与边界

- 本章所述字段与协议是工程建议，不是行业标准；实际病历书写以所在机构规范与现行法规为准。
- 3840 个格子的计数为「24 部位 × 5 色 × 32 种十法组合」的算术结果，属名义组合数，不代表实际可用的判读空间。
- Kappa 的示例为演算设定，用于说明偏斜分布下的解释陷阱，不是实测数据；一致性阈值的通行解释（0.41–0.60 中等、0.61–0.80 高度、0.81 以上几乎完全）为文献惯例，具体判断须结合任务与类别分布。
- 「相胜」「相生」的合参结构是传统理论框架，本章只作接口设计上的对照，不主张其临床效力。
- 涉及医疗器械属性、个人信息保护、伦理审查的具体要求，以现行法规与所在机构伦理委员会的意见为准；本章不构成合规意见。
