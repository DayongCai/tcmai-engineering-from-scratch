# 第 6 章 · 咽喉：一百零一篇里，唯一没有专章的部位

> **MOTTO:** 「庭者，首面也；阙上者，咽喉也；阙中者，肺也。」——《灵枢·五色》（《望诊遵经·明堂周身部位》引）
>
> **PROBLEM:** 本课的外源底本《望诊遵经》共一百零一篇。目部七篇，舌部五篇，口部两篇，唇部三篇（另有四白一篇），齿部两篇，鼻部两篇，耳部一篇，眉、髭须、发各一篇。**咽喉，零篇。** 它在整部书里只出现过一次，就是《灵枢·五色》那张部位表上的五个字：「阙上者，咽喉也」——两眉之间稍上的一块皮肤。一个每天要看几十个咽痛患者、能分辨乳蛾与喉痹、知道白喉要命的学科，在通身望诊的体系里只留下一个坐标，没有提纲，没有条目。这不是遗漏，是**可达性**在划定学科边界：咽喉不是「望」不到，是「望」要先有一块压舌板。
>
> **双根因定位:** 环境逼迫（望诊的组织逻辑是「浅表可见」，能在一间屋子里、不借器械、就着自然光看的，才进通身望法；咽喉需要张口、压舌、强光，天然被划到喉科专书去——《重楼玉钥》《喉科指掌》那一系）+ 知识积累（本章 30 单元 25,985 汉字，覆盖咽喉望诊、咽喉病辨证与证治，是全课第二大章；教材把咽喉当独立器官讲，古籍把它当一个坐标讲，两种讲法各有各的完整性，合起来才看得出缺口在哪）

## 一、五个字的坐标，与一整章的空缺

「阙上者，咽喉也」这句话，在部位表里的位置很特别：它排在「首面」之后、「肺」之前，是整张表里第二个脏腑对应。按这张表的空间逻辑，咽喉在面部的位置比肺还高——这符合解剖直觉（气道在上），也符合临床直觉（咽为肺之门户）。

但这句话之后再无展开。对比一下同一部书对别的部位做了什么：

| 部位 | 篇数 | 有无「形容提纲」 | 有无「气色条目」 |
|---|--:|:--:|:--:|
| 目 | 7 | ✓ | ✓ |
| 舌 | 5 | ✓ | ✓ |
| 唇 | 3（＋四白 1） | ✓ | ✓ |
| 齿 | 2 | ✓ | ✓ |
| 鼻 | 2 | ✓ | ✓ |
| 耳 | 1 | ✓ | — |
| **咽喉** | **0** | **—** | **—** |

「形容提纲」加「条目」是这部书的标准结构：先立观察维度，再堆具体证候。一个部位只有进入这个结构，才算被真正处理过。咽喉没有进入。

这个空缺本身很有信息量。它说明：**在传统望诊的自我理解里，「望」是一种不需要器械的看。** 一旦需要压舌板，它就不再是望诊的一部分，而属于另一门手艺。学科的分工不是按器官分的，是按**可达性**分的。

## 二、直视之下，判据其实是齐的

如果越过那道器械的门槛，咽喉的判据相当完整，而且比面部的判据更「硬」。

**红肿。** 咽黏膜充血的程度、范围、是否累及腭弓与软腭。这是可以分级的：局限、弥漫、伴渗出。

**喉核（扁桃体）肿大。** 临床上有通行的分度：不超过腭咽弓为Ⅰ度，超过腭咽弓为Ⅱ度，接近中线为Ⅲ度，两侧几乎相接为Ⅳ度。这是一套真正可操作的量化，比「深赤为太过」具体得多。

**伪膜。** 灰白色、附着于黏膜、不易擦去、强行擦去易出血——这四个特征合起来，是白喉的典型描述，也是必须立刻升级处理的信号。

**滤泡。** 咽后壁淋巴滤泡增生，颗粒状隆起。慢性咽炎的常见描述，但主观性强，不同观察者的计数差异很大。

**形态。** 悬雍垂的水肿、 elongated、分叉；会厌的红肿与抬举；咽腔的狭窄。

这一组判据有一个共同点：它们几乎都是**结构性的**（肿大、附着、隆起、狭窄），而不是颜色的。颜色在这里退居次要——因为黏膜的颜色受光照、血红蛋白、炎症期相影响太大，而结构的改变更稳定、更容易达成观察者一致。

这与面部望诊恰好相反。面部靠色，咽喉靠形。原因也简单：面部的形（骨相）与病无关，咽喉的形（肿大、伪膜）与病直接相关。

## 三、白喉、会厌炎：两条不能越过的线

咽喉望诊的特殊性在于，它的漏诊代价极高，而且高得不均匀。

**白喉。** 伪膜是关键体征。这是一种需要隔离与抗毒素治疗的急性传染病，延误可有生命危险。任何图像系统只要看到「灰白色、附着、不易擦去」的形态描述，唯一正确的输出就是升级，不是分类。

**急性会厌炎。** 起病急、咽痛剧烈、吞咽困难、流涎、发音含糊，进展可致气道梗阻。这个病的体征在会厌，而会厌在普通张口检查中往往看不见——需要间接喉镜。也就是说，**最危险的咽部急症，恰恰是最难「望」到的**。

这两条决定了咽喉部位的输出设计：不是一个分类器，而是一个**分诊器**。它的任务不是「判断这是风热还是阴虚」，而是「这个要不要现在就叫人来」。

## 四、图像的可能性与不可能

先说可能的部分。咽部图像在技术上是可以采的：压舌板压住舌前三分之二，患者发「啊」音抬高软腭，光源从口外斜前方射入，手机微距或耳鼻喉内镜成像。获得的图像能看清咽后壁、腭弓、扁桃体、悬雍垂。

再说不可能的部分，有四条。

**咽反射。** 压舌板一碰舌根就恶心，图像糊掉。这是生理性的，不是技术问题；反复尝试只会加重反射。

**儿童。** 几乎无法配合。而儿童恰是扁桃体与咽部疾病的高发人群。这个偏倚在数据集里会直接体现为「模型只在成人上有效」。

**照度与噪声。** 口腔是一个暗腔，光源在口外，进入的光很有限。演算设定：若咽部照度为 100 勒克斯（约为室内照明的三分之一），手机在 f/2 光圈下的曝光时间会拉到 1/30 秒以上，手持必然模糊；提高 ISO 则噪声主导，黏膜的细微色差被噪声淹没。

**视角改变解剖。** 手机伸入口腔，舌根被推开、软腭位置改变、咽腔形态随体位变化。同一患者在不同拍摄姿势下的咽部图像，解剖关系可能已经不同。

还有一个更根本的限制：**颜色在这里几乎不可用。** 黏膜湿润、镜面反射强、光源近、白平衡难定。想在咽部做「色」的量化，难度比面部高一个量级，收益却低——因为这里的判据主要是形。

## 五、「阙上」与「直视」：两条同名的测量线

现在回到那五个字。它给出的是面部的一个位置，而现代咽喉检查给的是器官本身。这两条线都叫「咽喉望诊」，但测的完全不是同一个量：

- **阙上**：两眉之间稍上的一块皮肤，测的是皮肤色与形态；
- **直视**：咽腔黏膜，测的是充血、肿大、伪膜、滤泡。

任何标注「咽喉望诊」的数据集，第一件事就是标明属于哪一条。混在一起，等于把「眉间的皮肤色」和「扁桃体Ⅱ度肿大」当成同一个特征空间。

但也正因为这两条线并存，有一个值得做的实验：**取同一批受试者，同时记录阙上的皮肤色与咽部的直视分级，看二者是否相关。** 这是「阙上者，咽喉也」这句话唯一可以被检验的形式——不是去证明它对，而是去看它在什么条件下成立、效应有多大。如果相关很弱，那这五个字就是一个历史坐标，不必强行赋予测量意义；如果相关存在，那它就是一个可用的低成本代理指标。两种结果都有价值，前提是先把两条线分开。

## 六、把「不能望」的部分交出去

咽喉是四诊分工最紧的一个部位：能望的很少，能闻的很多。

**声音。** 嘶哑、语音含糊、鼻音重、气息声——这些都是闻诊的判据，而且与咽部结构改变高度相关。声带与咽腔的形态变化，最先表现在音色上，而不是颜色上。原文讲「气色声音合参」，在咽喉这里不是可选项，是主路径。

**主诉。** 咽干、咽痛的性质（灼痛、刺痛、异物感）、吞咽时是否加重、有无反流、有无夜间加重——这些决定判据的方向，而它们全部来自问诊。同一个「咽后壁滤泡增生」，胃食管反流者与慢性咽炎者的处理路径不同。

**触诊与器械。** 颈部淋巴结、扁桃体周围有无波动感（脓肿）、会厌的间接喉镜所见——这些超出望诊，但在咽喉部位，省略它们的代价远高于省略颜色。

所以咽喉望诊的完整输出，应当明确分成三栏：**看到的**（咽部形态与伪膜）、**听到的**（音色与气息）、**问到的**（主诉与病程）。三栏分开写，读者才知道哪一条是证据、哪一条是转述。混成一句「咽部充血，咽痛三天，声音嘶哑」，看起来完整，实际上把三种可靠度不同的信息压成了同一层。

这也解释了为什么古籍把咽喉推给「各门」：不是不重要，而是它必须由多门共同完成，单靠望法写不出一篇提纲。一个部位能不能立提纲，取决于它能不能被一种感官独立地、稳定地读完。咽喉读不完——这是它的结构，不是它的缺陷。

## 代价与边界

- 本章所引部位表依《灵枢·五色》及《望诊遵经·明堂周身部位》，篇数统计依外源底本的文件结构（101 篇），属文献事实，不含价值判断。
- 「咽喉零篇」是就本课外源底本《望诊遵经》而言；中医喉科另有专著传统（如《重楼玉钥》一系），本章不否认其存在，只是指出它不在通身望法的体系内。
- 扁桃体分度、伪膜特征等属现代临床检查内容，本章只作判据形态的描述，不提供诊断标准或处置方案。
- 本章不给出任何咽喉图像模型的准确率、灵敏度数据；照度与噪声的数值为演算设定。
- 咽痛伴呼吸困难、流涎、不能吞咽、声音改变者属急症，须立即就医，不得依赖任何图像判读；怀疑白喉者须按传染病规定处置。

**免责声明：** 本章为咽喉望诊的教学与工程讨论，不构成医学意见、诊断或治疗建议。任何咽喉征象的临床解释与处置，须由具备资质的人员依规范作出。
