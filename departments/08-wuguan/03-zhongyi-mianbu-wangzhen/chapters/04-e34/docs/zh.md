# 第 4 章 · 明堂之鼻：一张正面照，只拿得到四成的判据

> **MOTTO:** 「五色独决于明堂，四诊先观其天牝。」——《望诊遵经·诊鼻望法提纲》
>
> **PROBLEM:** 鼻部那一篇一共给了二十二条判据。十七条讲形与证：鼻大、鼻小、肿起、陷下、鼻煽张、鼻仰息、鼻枯槁、鼻蚀烂、鼻窍干燥、鼻柱崩坏、鼻下红肿如疮、流浊涕、流清涕、鼻渊、鼻衄、生瘜肉、生粉刺。五条讲色：青、微黑、黄、白、微赤。**其中只有九条能在一张正面静态照片上判**——五条色，加上四条形（大小、肿陷、枯槁、蚀烂）。剩下十三条要侧面、要视频、要问。四成。而公开的鼻部图像研究，几乎全部集中在那四成里的「色」。这不是研究者的疏忽，是采集成本的必然：色最好拿，形要换视角，动态要拍视频，涕要开口问。
>
> **双根因定位:** 环境逼迫（鼻居中、无遮挡、随手可指，于是成为「望色」的默认取样点；但它同时是皮脂腺最密的地方，采样条件最不稳定——选它是因为方便，不是因为它好测）+ 知识积累（本章 35 单元 27,724 汉字，是全课单元最多的一章，覆盖鼻部望诊、鼻科辨证与鼻病证治；外源《望诊遵经》诊鼻两篇，提纲加条目，条目里大量转引《金匮要略》《千金》，正好把「色、形、涕」三条线分开）

## 一、明堂的地位，来自「居中」而不是「信息量大」

> 「五官先生鼻，五脏先成精……鼻者，形之始也，气之门户也。」

古人把望色的最终判读点定在鼻，理由不是鼻上的信息最多，而是四个稳定性：位置居中（左右可比）、面积适中（够大但有边界）、不被表情肌大幅牵动（哭笑的形变最小）、无遮挡（不似眼被睑遮、口被唇闭）。

这是选择取样点的经典逻辑：**稳定优先于丰富**。一个信息量更大但随表情变形的区域，不如一个信息量一般但每次都在同一位置的区域。第 1 章讲的「明堂犹气口」也是这个道理——脉诊取寸口而非全身动脉，理由是同一个。

理解这一点，就能理解为什么现代面色研究几乎都以鼻或额为基准白：不是这两个地方最能反映病，而是它们最容易对齐。

## 二、色：最小的区域，最油的地方，最容易被读成「脾」

鼻部的色判据，源头是《金匮要略》那一段，汪宏原样引来：

> 「鼻头色青，腹中痛，若冷者死。鼻头色微黑者，有水气。色黄者，胸上有寒。色白者，亡血也。设微赤非时者死。」

这段话值得逐条看清楚：**四条判据，没有一条是「鼻头黄＝脾病」**。每一条都是「色＋兼症」的合取——青要配腹痛且冷，黑要配有水气，黄要配胸上有寒，白要配失血，赤要配「非时」（不在当令之时）。后世把它简化成一句「鼻头色黄属脾」，简化掉的是条件，剩下的只是一个色名。

这个简化在临床上或许无害（医师心里还留着条件），但在数据上致命：如果一个模型只在「色→脏腑」这一层训练，它学到的条件从来不存在，而原始判据的全部信息都在条件里。

再看测量条件，鼻部有三个天然的麻烦：

**皮脂。** 鼻部皮脂腺密度在面部最高，镜面反射最强。第 2 章说过，润泽与油光在物理上是同向的；到了鼻头，这个混淆被放大到极致——很多人的鼻头在照片上就是一块高光。

**毛孔与黑头。** 局部暗点会把区域平均亮度拉低，被读成「色沉」或「浊」。而黑头的多少与皮脂分泌、清洁习惯相关，与任何脏腑都不相关。

**区域小。** 归一化到 1000 像素的人脸上，鼻头有效区域大约 120×90 像素。这个尺度上，一个高光斑就能占掉一成半的像素。

## 三、形：一半要侧面，一半要视频

把十七条形与证按「需要什么」重排，得到一张很不一样的表（十二行，覆盖其中十六项）：

| 判据 | 正面静态 | 侧面 | 视频 | 微距 |
|---|:--:|:--:|:--:|:--:|
| 鼻大／鼻小 | ✓ | | | |
| 肿起／陷下 | ✓（需侧光） | | | |
| 鼻枯槁 | ✓ | | | |
| 鼻蚀烂 | ✓ | | | ✓ |
| 鼻煽张 | | | ✓ | |
| 鼻仰息 | | ✓ | | |
| 鼻窍干燥 | ✓（近距） | | | ✓ |
| 鼻柱崩坏 | ✓ | | | |
| 流清涕／浊涕 | | | ✓ | |
| 鼻渊（浊涕下不止） | | | ✓ | |
| 鼻衄 | | | ✓ | |
| 生瘜肉／粉刺 | ✓ | | | ✓ |

其中最有意思的一条是**鼻煽张**。它要求观察呼吸周期——成人静息呼吸大约三到五秒一次——也就是至少十秒的视频。而这十秒的视频，顺带给出了呼吸频率这个硬指标，比任何颜色特征都更接近「可测量的生理量」。换句话说，鼻部望诊里最「客观」的一项，恰恰是最没人做的视频项。

还有一条要单独拎出来：**「骨部起者寿，骨部陷者夭，故鼻准贵乎丰隆。」** 这是骨相与软组织厚度，与疾病无关，与年龄、种族、性别强相关。把它做进特征，模型学到的会是人群构成，而不是病理。这类特征在中医面部研究里出现得不少（面型、颧高、下颌宽），必须显式排除或显式校正。

## 四、涕：望诊到不了的地方，古人自己划了界

《诊鼻望法提纲》的结尾很诚实：

> 「他如气之粗细，息之疾徐，嚏之有无，窍之通塞，当详各门，容后续述。」

气息的粗细、呼吸的快慢、喷嚏的有无、鼻窍的通塞——这四项全是动态或主观的，作者直接推到别的门类去了。这是一个值得学习的边界意识：**能望的望，不能望的转给问与闻，不硬凑。**

工程上的对应很清楚：清涕与浊涕的区分，靠一张照片判不了（涕在鼻腔内，正面照看不到；流到鼻孔外的部分，颜色受光照与干燥影响极大）。鼻塞更判不了。这些必须由问诊获得，或者用其他模态（鼻阻力、声学鼻测量）。

所以鼻部望诊的完整输出，应该明确标注哪些项来自图像、哪些项来自问诊。混在一起写「鼻部望诊：流清涕，鼻塞」，会让复核者以为都是看到的。

## 五、采集：鼻部是「高光地狱」

四条实操建议，按性价比排序。

**双光源 45° 交叉。** 正面直打必然在鼻尖留一个饱和高光斑；两盏 45° 侧前方打光，能把高光推到鼻翼两侧，让鼻准保持漫反射。

**偏振。** 交叉偏振消掉表面反射，得到血色；平行偏振保留表面反射，得到润泽与油光。这在鼻部比在任何部位都更有价值，因为这里的表面反射最强。

**侧光拍形。** 肿起与陷下靠阴影揭示，正面平光会把它们抹平。一盏低角度侧光，能让鼻梁的起伏显形。

**微距拍糜烂与粉刺。** 这两类判据的尺度在毫米级，普通手机的主摄在最近对焦距离上拍不到细节。

一个演算设定说明「区域小」的代价：鼻头 ROI 约 120×90 像素，若高光斑覆盖 15%，这些像素的色度不可用；再剔除毛孔暗点与鼻毛阴影约 10%，有效像素降到七成半以下。区域越小，剔除的代价越大——同样剔 25%，在面颊（面积大十倍）上几乎无损，在鼻头就已经影响均值的稳定性。

## 六、疠风：一条必须写死的转诊规则

「鼻柱崩坏者，疠风之败症」——鼻柱塌陷是麻风晚期的体征，「疠风鼻柱坏者，骨先死也」。

这一条在任何自动系统里的处理方式，不能是分类，只能是**升级**：一旦检出鼻部结构缺损（鼻梁塌陷、鼻翼缺损、鼻中隔穿孔的影像学表现），唯一正确的输出是「建议立即就医」，并附上「本结果不构成诊断」。理由很简单：这类体征的后果严重、进展不可逆、且现代医学有明确的诊断与治疗方案，任何延迟都是伤害。

这条规则的优先级高于所有分类准确率。换句话说，**在这个部位，漏掉一个结构缺损的代价，远大于把一百张正常照片判成可疑。** 系统的阈值设计必须体现这个不对称，而不是追求总体准确率。

## 七、最小输出：把二十二条压成六个字段

判据多不等于输出多。真要做成一张可复核的记录，二十二条最终要落到六个字段上：

| 字段 | 取值 | 来源 | 覆盖判据 |
|---|---|---|---|
| 部位 | 鼻准／鼻根／鼻翼／鼻下 | 分区 | 全部 |
| 色 | 青／赤／黄／白／黑＋相对基线 ΔE | 图像（偏振） | 5 条 |
| 泽 | 泽／夭（高光统计，须排除油光） | 图像 | 泽夭一法 |
| 形态 | 大／小／肿／陷／枯／蚀／缺损 | 正面＋侧光＋微距 | 9 条 |
| 动态 | 煽张有无、呼吸频率 | 视频 | 1 条 |
| 分泌物 | 清／浊／无／血 | 问诊或视频 | 4 条 |

六个字段里，只有「色」与「泽」完全来自静态图像；「形态」要额外视角，「动态」要视频，「分泌物」多数情况要问。这就是本章开头那个四成的具体形状——它不是一句估计，而是逐条清点之后落在字段上的分布。

把这张表写进记录模板，还有一个附带的好处：填表的人会立刻发现哪些项其实没采到。空着的字段是诚实的；一句话的记录，把所有空都藏在形容词里。

## 代价与边界

- 本章所引鼻部判据依《望诊遵经·诊鼻望法提纲》及所转引的《金匮要略》条文，不同版本用字有异（如「天牝」亦作「天牝」指鼻），本章照录不作校勘。
- 二十二条判据的计数、九条可在正面静态照判读的划分，是本章依原文逐条清点的结果，属教学分类，不是公认标准。
- 鼻准丰隆、鼻之大小属骨相与软组织特征，与年龄、性别、族群强相关；本章明确不作为病理特征使用。
- 本章不给出任何鼻部图像模型的准确率或一致性数据；「四成」（九条／二十二条）是判据可得性的比例，不是性能。
- 鼻出血、鼻部结构缺损、持续单侧鼻塞伴血性涕等情况须即时就医，不得依赖任何图像判读。
