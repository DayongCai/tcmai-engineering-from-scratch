# 出科考的判据不是背得出辨证，是三分钟内说出该转还是该治 · 提示词

## 用途

给「出科考的判据不是背得出辨证，是三分钟内说出该转还是该治」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「出科考的三道题 → 九个病压成三张表 → 四个时限与就地处置参数 → 复盘的写法：时间轴与决策点」这条链。

## 边界

本章为教学材料，所述三题结构、时限表、复盘四段与 AI 边界用于训练出科考核与病例复盘，不构成医学意见、诊断或治疗建议；具体操作以现行规范与所在机构制度为准。
