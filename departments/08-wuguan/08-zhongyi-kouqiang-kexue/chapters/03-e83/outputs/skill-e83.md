# 口镜看得见红肿，看不见该不该清

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 定位 → 定性 → 辨火 → 辨脓血 → 辨舌脉 → 落记录
- 其一，定位决定取证范围
- 其二，定性决定要不要辨火
- 其三，舌脉放在最后，是为了让它纠偏
- 暴痛、剧痛、骤肿者多实；隐痛、久痛、渐萎者多虚
- 痛而拒按、痛引头面、夜不能寐者实；痛而喜按、咬物无力、时作时止者虚

## 边界

- **不留病种。** 本章讲的是「辨证」，不给病名。牙痛、牙宣、口疮、茧唇、喉痹各有辨证要点，其详在各病章。用六步去套一个具体病，会漏掉该病特有的证据——牙宣必看齿之松动度与牙周袋，茧唇必看唇肿的形态与病程。
- **不留阈值。**「量多」「色鲜」「黄稠」都是分级词，不是测量值。出血几毫升算多，脓的稠度怎么分三级——本章不给，古书也不给。给了就是编。
- **不留影像与探诊。** 龋洞的深度、根尖的情况、牙槽骨的高度，本章一概不答。牙体缺损之修复，终须专科处理，这条界线在辨证一章就要划清。
- 本章为教学材料，不构成诊断或治疗建议。文中辨证要点、证候名称与所举方名，只用于建立判断框架。
