# 口镜看得见红肿，看不见该不该清 · 提示词

## 用途

给「口镜看得见红肿，看不见该不该清」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「六步次序 → 定位：先分齿、龈、舌、唇、咽 → 定性：虚实以急缓分 → 辨火与辨脓血」这条链。
