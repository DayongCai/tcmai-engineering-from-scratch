# 出血多不等于病重，不出血也不等于好了 · 提示词

## 用途

给「出血多不等于病重，不出血也不等于好了」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三个词，三段病程 → 齿衄：三型，血色只作参考 → 牙宣：从出血到根露 → 齿动：分级，以及两种完全不同的松动」这条链。
