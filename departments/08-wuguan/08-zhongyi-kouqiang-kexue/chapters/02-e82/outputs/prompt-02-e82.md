# 「火」是口齿科最省力的答案，也是最容易错的那一个 · 提示词

## 用途

给「「火」是口齿科最省力的答案，也是最容易错的那一个」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「一张四条路的病因表 → 外因：同一阵风，两条路 → 虫：一个被改了名的病因 → 内因三路：胃火、肾虚、脾虚」这条链。
