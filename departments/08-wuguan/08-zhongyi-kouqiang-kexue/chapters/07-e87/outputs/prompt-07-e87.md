# 口疮是自限的病，两周不愈就不再是口疮 · 提示词

## 用途

给「口疮是自限的病，两周不愈就不再是口疮」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「口疮与口糜：先把这条界划回来 → 三型，加一个没有名字的第四态 → 四个观察项：把「溃疡」拆成可记录的东西 → 两周红线：必须排查的七条」这条链。

4. 本章自陈的边界（不得越过）：
