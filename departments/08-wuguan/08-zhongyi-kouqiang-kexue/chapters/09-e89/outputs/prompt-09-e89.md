# 急症章的一半功夫，是教人少做五件事 · 提示词

## 用途

给「急症章的一半功夫，是教人少做五件事」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三类急症与一个不能改的顺序 → 牙外伤：分型决定现场做什么 → 全脱位牙：拿、洗、泡、送 → 出血：先分源，再谈止」这条链。

## 提示词

```
我在学《中医口腔科学》第 9 章「急症章的一半功夫，是教人少做五件事」，本章 5 节 / 2,637 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 第一类是外伤
   - 第二类是出血
   - 第三类是感染
   - 先气道，再出血，再保牙，最后辨证
   - 摇一颗，看邻牙动不动
   - 第一步，拿
4. 本章自陈的边界（不得越过）：
   - **丢掉了手法与器械。** 复位方向、固定方式与维持时长、缝合层次、引流口位置、清创范围——全在操作层，本章一项不给。文字描述的手术，比没有描述更危险。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

本章为教学材料，不构成急救指令、医学意见或诊断依据；具体操作以现行规范与所在机构制度为准。
