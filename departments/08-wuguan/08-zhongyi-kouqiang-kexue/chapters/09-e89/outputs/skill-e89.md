# 急症章的一半功夫，是教人少做五件事

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 第一类是外伤
- 第二类是出血
- 第三类是感染
- 先气道，再出血，再保牙，最后辨证
- 摇一颗，看邻牙动不动
- 第一步，拿

## 边界

- **丢掉了手法与器械。** 复位方向、固定方式与维持时长、缝合层次、引流口位置、清创范围——全在操作层，本章一项不给。文字描述的手术，比没有描述更危险。
- **丢掉了时间窗的精度。**「三十分钟」「两小时」来自观察性证据与共识，不是实验阈值。牙根未发育完成者的窗口更宽；泡在牛奶里两小时可能比干藏二十分钟更好。本章给的是量纲（以分钟计、越快越好），不是保证。
- **丢掉了影像与活力测试。** 根折位置、牙槽突与颌骨是否骨折、异物在哪一层，要靠 X 线与锥形束 CT；牙髓是否坏死，要靠温度测验与电活力测验随访。本章一条影像判据也没有。
- 本章为教学材料，不构成急救指令、医学意见或诊断依据。
