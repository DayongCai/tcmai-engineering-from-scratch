# 治法不是一张方剂清单，是五道闸门 · 提示词

## 用途

给「治法不是一张方剂清单，是五道闸门」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「内治：四条路加一条岔路 → 外治：四法各有其位 → 刺血与针灸：一处显效，一处禁区 → 五道闸门：次序不能倒」这条链。

## 边界

本章为教学材料，不构成治疗建议。文中治法分类、方名与禁忌，只用于建立判断框架；具体操作以现行规范与所在机构制度为准。
