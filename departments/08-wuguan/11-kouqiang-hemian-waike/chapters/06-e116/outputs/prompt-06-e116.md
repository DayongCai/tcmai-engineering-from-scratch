# 十个病名是一条深度轴：从疖到走黄，差的是「脓有没有出路」 · 提示词

## 用途

给「十个病名是一条深度轴：从疖到走黄，差的是「脓有没有出路」」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「十个病名，其实是三个变量的组合 → 深度的读数：脓头、边界、推之移不移 → 丹毒是另一条线：不化脓的感染 → 走黄与内陷：两种失败方式，一条解剖通路」这条链。
