# 火毒是结论，不是原因 · 提示词

## 用途

给「火毒是结论，不是原因」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「命名：三层叠起来的一个词 → 六个病因，其实只有两个入口 → 气血凝滞：四个可观察的征 → 邪正盛衰：宿主是可分层的变量」这条链。

## 边界

本章为教学材料，不构成医学意见、诊断或治疗建议。颌面部感染属可能危及生命的疾病，任何疑似病例都应由具备资质的医师当面评估，不得依据本章自行判断或处理；具体操作以现行规范与所在机构制度为准。
