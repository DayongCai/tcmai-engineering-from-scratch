# 层次是防线，间隙是走廊 · 提示词

## 用途

给「层次是防线，间隙是走廊」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「五层：每一层都在回答「感染走到第几层」 → 一张脸，两套线：运动与感觉必须分开记 → 腮腺区：唯一必须记住的「例外」 → 间隙：不是房间，是走廊」这条链。
