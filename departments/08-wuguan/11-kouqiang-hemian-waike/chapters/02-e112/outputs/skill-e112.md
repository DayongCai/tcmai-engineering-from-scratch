# 层次是防线，间隙是走廊

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 筋膜是一道有方向的闸门
- "肿"这个字，在不同层次上是不同的病
- 头皮上一个不起眼的肿胀，可以是颅内感染的入口
- 面神经在腮腺内分叉，腮腺因此被分为浅叶与深叶
- 感觉减退或缺失的区域，能反推是哪一支、哪一段受侵
- 面神经的颞支与下颌缘支最易受损

## 边界

- 本章的层次划分与间隙名称依《局部解剖学》头部章与现行教材，**不同版本对间隙的数目与合并方式不一致**；本章不裁定哪一版正确，临床与教学用名以所在机构采用的教材与规范为准。
- 本章**不给**手术入路、切口设计、翻瓣层次、分离平面与器械选择。解剖知识可以用来说明"为什么危险"，不能用来说明"怎么做"——后者属执业范围，须在带教下、在具备条件的机构内完成。
- 本章**不给发生率，也不给"某间隙感染多见/少见"的频率判断**。表中"最常见""易被低估"一类表述是定性的临床印象，不是流行病学数据。
- 本章为解剖学教学材料，不构成医学意见、诊断或治疗建议，也不构成任何操作指导。颌面部的一切有创处置，须由具备资质的医师依现行规范与所在机构制度实施。
