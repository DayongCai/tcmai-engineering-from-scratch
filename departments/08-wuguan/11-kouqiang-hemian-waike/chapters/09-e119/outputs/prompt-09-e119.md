# 识别并发症靠的不是经验，是术前就写好的那张「如果」清单 · 提示词

## 用途

给「识别并发症靠的不是经验，是术前就写好的那张「如果」清单」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「按时段排队，比按系统分类有用 → 每条并发症要能答三句话 → 风险沟通的失败多在时间点，不在措辞 → 坏消息的四段式，与三个不许」这条链。

## 提示词

```
我在学《口腔颌面外科学》第 9 章「识别并发症靠的不是经验，是术前就写好的那张「如果」清单」，本章 6 节 / 3,880 汉字，习题 7 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - "数小时内"这一行的每一项，恶化都以小时计；"数周"这一行的每一项，恶化以周计
   - 术前就知道它在哪儿
   - 最早的信号是什么、观察窗口有多长、谁有权做决定
   - 数值是确认，信号是触发
   - 判断"要不要越级"的标准不是病情轻重，是时间

4. 本章自陈的边界（不得越过）：
   - 本章的治理框架借自底本《医学数据安全与隐私》第 8 章（风险识别、分级、责任、留痕、复盘），属方法移植；并发症的条目、信号与恶化方向是按颌面外科的一般特点组织的教学归纳，不是任何一部教材的原文，也不是行业标准。
   - 本章**不给**并发症的发生率、死亡率与再手术率。"常见""少见"都是定性词；表中"最早的信号"是触发用的观察项，不是诊断标准。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，不构成医学意见、诊断或治疗建议，也不构成法律意见。颌面部手术后出现呼吸困难、大量出血、意识改变、持续高热等情况，须立即就近急诊处置；具体操作以现行规范与所在机构制度为准。
