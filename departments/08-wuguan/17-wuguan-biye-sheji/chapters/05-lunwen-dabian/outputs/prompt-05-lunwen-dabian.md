# 综述里每一句「历代认为」，都要能落到一本具体的书 · 提示词

## 用途

给「综述里每一句「历代认为」，都要能落到一本具体的书」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「四段式：每一段只回答一个问题 → 源流综述的引证规矩 → 指标与单位：论文里唯一不用换算的数字 → 图表三条规矩」这条链。

## 提示词

```
我在学《五官口腔毕业设计与知识移交》第 5 章「综述里每一句「历代认为」，都要能落到一本具体的书」，本章 6 节 / 3,030 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 史实必须可核，观点必须归人，数据必须给单位
   - 第一，视力有两套记录法
   - 第二，功能指标有生理基础，解释不能越界
   - 第三，眼与全身的关系决定了混杂因素
   - 一图一结论
   - 表不重复图，图不重复表
4. 指出本章写到类别就止步、不再给参数的地方。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，所述四段结构、引证规矩、图表规矩与答辩分配用于训练论文写作与答辩表达，不构成学术评价、医学或统计意见；具体操作以现行规范与所在机构制度为准。
