# 选题不是挑一个病名，是把一句主诉压到可测的指标上 · 提示词

## 用途

给「选题不是挑一个病名，是把一句主诉压到可测的指标上」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「四步压缩：从一句话到一个可验证命题 → 从诊法文本里捞指标 → 三种规格：描述、关联、干预 → 可行性：三关」这条链。

## 提示词

```
我在学《五官口腔毕业设计与知识移交》第 1 章「选题不是挑一个病名，是把一句主诉压到可测的指标上」，本章 6 节 / 2,950 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 第一关：样本
   - 第二关：时限
   - 第三关：伦理
   - 你要回答的那一句话是什么？
   - 这个量怎么测？谁测？测几次？
   - 对照是什么？
4. 指出本章写到类别就止步、不再给参数的地方。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，所述四步压缩、指标表与可行性三关用于训练毕设的选题判断，不构成医学、统计、法律或伦理意见；具体操作以现行规范与所在机构制度为准。
