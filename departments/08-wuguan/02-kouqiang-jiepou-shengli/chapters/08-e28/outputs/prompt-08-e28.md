# 检查不是看一遍，是五个动作各答一问 · 提示词

## 用途

给「检查不是看一遍，是五个动作各答一问」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「五个动作，各答一问 → 张口度与关节：三个动作代替一堆描述 → 记录：从「一句话」到「可复现」 → 三种口径的差异」这条链。

## 提示词

```
我在学《口腔解剖生理学》第 8 章「检查不是看一遍，是五个动作各答一问」，本章 7 节 / 3,208 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 视诊答「形与色」
   - 视诊的纪律是「先整体后局部」
   - 触诊答「质与温」
   - 触诊的纪律是「由轻到重、由外到内」
   - 叩诊答「根尖周」
   - ：以邻牙为对照，垂直叩查根尖、水平叩查牙周
4. 本章自陈的边界（不得越过）：
   - **不给数值与分度阈值。** 张口度的毫米数、动度的毫米阈值、探诊力量的克数，一律不给；通行以「几横指」「三度」作定性描述，本书沿用定性口径，具体阈值以现行规范与机构文件为准。
   - **不给诊疗方案。** 本章只给「查什么、怎么记」，不给「查出来怎么治」；处置属各专科范围。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，不构成诊断或治疗建议。文中检查次序、记录口径与影像用法用于建立判断框架；具体操作以现行规范与所在机构制度为准。
