# 腮腺是面神经的床，不是它的邻居 · 提示词

## 用途

给「腮腺是面神经的床，不是它的邻居」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三对大腺与四个开口 → 腮腺与面神经：五支与五个区 → 涎石为什么偏爱下颌下腺 → 三叉神经的三支与口内边界」这条链。

## 边界

本章为教学材料，不构成诊断或治疗建议。文中腺体位置、导管开口与神经分布用于建立判断框架；具体操作以现行规范与所在机构制度为准。
