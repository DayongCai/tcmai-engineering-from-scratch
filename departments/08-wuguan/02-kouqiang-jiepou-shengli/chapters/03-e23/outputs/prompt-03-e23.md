# 上颌是一层薄壳，下颌是一条管子 · 提示词

## 用途

给「上颌是一层薄壳，下颌是一条管子」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「上颌骨：一体四突，每一突都通着一个腔 → 窦底与后牙根：一层薄壁，三种结局 → 下颌骨：体、升支与一条管子 → 断在四处：力走向与肌牵引」这条链。
