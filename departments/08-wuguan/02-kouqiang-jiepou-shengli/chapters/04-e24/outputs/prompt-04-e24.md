# 下颌不是挂在关节窝里，是挂在盘上 · 提示词

## 用途

给「下颌不是挂在关节窝里，是挂在盘上」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「四件套与上下两腔 → 盘髁三种关系：正常、可复、不可复 → 两个「咬到底」：正中关系与正中𬌗 → 运动与引导：谁在前，谁让路」这条链。

## 边界

本章为教学材料，不构成诊断或治疗建议。关节与咬合的判断须结合完整检查与影像，由具备资质的执业人员依现行规范作出。凡遇开口进行性受限、关节区持续疼痛、下颌偏斜伴咬合错乱者，须经口腔科检查；具体操作以现行规范与所在机构制度为准。
