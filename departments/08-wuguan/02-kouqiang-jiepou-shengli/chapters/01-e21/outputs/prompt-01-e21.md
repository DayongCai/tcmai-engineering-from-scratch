# 口腔不是一个腔，是两间房加一道门 · 提示词

## 用途

给「口腔不是一个腔，是两间房加一道门」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「先划界：四壁、一道门、两间房 → 两间房的意义在引流方向，不在名称 → 四区各留一个定位点 → 两处「危险」与三路入口」这条链。
