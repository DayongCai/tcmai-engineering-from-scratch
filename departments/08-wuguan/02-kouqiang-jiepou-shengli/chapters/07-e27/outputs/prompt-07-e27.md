# 牙痛说不准位置，不是患者不会说 · 提示词

## 用途

给「牙痛说不准位置，不是患者不会说」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「四种感觉在口腔里分布不均 → 牙痛为什么定不准 → 味蕾分布与四条通路 → 味觉异常的四类与一处陷阱」这条链。

## 边界

本章为教学材料，不构成诊断或治疗建议。文中分区、通路与检查口径用于建立判断框架；具体操作以现行规范与所在机构制度为准。
