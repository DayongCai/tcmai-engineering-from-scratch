# 第 9 章 · 复查不是看一眼，三条线各自抓到不同的失败

> **MOTTO:** 「用探针探触贴面边缘检查贴面边缘完整性，用牙线测试患牙与邻牙的邻接关系」——《瓷贴面粘接技术操作规范·9.1》
>
> **PROBLEM:** 条文把复查拆成三条评价线，每条都给了具体动作，而不是「观察」；又把并发症列为四类，每类的处置各不相同。四类里只有一类写着处置后成功率较高，另一类明确写「存在较高失败风险」。这意味着复查的真正难点不是发现异常，而是判断**这次的异常值不值得动它**——四条线四条处置逻辑，判断错一次，可能把一次可抛光的染色变成一次拆除重做。

**双根因定位:** 环境逼迫（复查被安排成「顺带看一眼」，三五分钟里只够看患者指的那一颗；患者能指出的问题几乎都是美学问题，功能与生物学问题由医师自己找） + 知识积累（把三条线读成三套独立的检查手段与三套独立的失败机制，而不是「好不好看」的三种说法）

**教材出处:** 外源·T/CHSA 001—2019《瓷贴面粘接技术操作规范》第 9.1—9.3 条与第 10.1—10.4 条；本课无教材底本，条文逐字录自 `standards/kouqiang-xiufu/sources/`，中文为转述。

## 一、三条线：每条线有各自的工具

条文对三条线的写法高度具体，每一句都是一个可执行的动作。

**功能评价**：用探针探触贴面边缘检查边缘完整性；用牙线测试患牙与邻牙的邻接关系；使用咬合纸或咬合记录仪测试咬合接触情况；肉眼观察贴面磨损情况；探诊修复体是否存在松动；用透照法检测是否存在贴面隐裂或折裂；询问患者满意度。

**美学评价**：肉眼观察修复体表面光洁度、表面或边缘是否存在染色、颜色匹配性、透光性，以及美学解剖外形。

**生物学评价**：探针探触结合压缩空气吹拂检查贴面边缘处是否存在术后敏感；牙髓活力仪测试牙髓活力是否正常；视诊观察基牙是否完整、有无隐裂或折裂、是否存在继发龋；牙周基础检查检测牙周组织是否健康。

三条线并排，会看到一个设计上的用心：**功能线几乎全部靠器械与动作，美学线几乎全部靠眼睛，生物学线则器械、仪器、视诊三者混用。** 这不是随意的分类，而是因为三类失败的显形方式不同——功能失败会在咬合纸和牙线上留下客观痕迹，美学失败只能靠比较（今天与术前像比较、与邻牙比较），生物学失败早期没有外观，必须靠探诊、吹气、活力测试去「激」出来。

由此得到一条实操判据：**只做美学线，等于只查了患者已经能看见的那部分。** 一个复查若全程只用眼睛，三条线里实际只走了一条。

## 二、四类并发症：四种不同的处置逻辑

条文把并发症分成四类，每类的处置逻辑都不一样。

**碎裂（10.1）。** 先做咬合检查，排除不良咬合因素；存在不良咬合因素必须先排除。无异常咬合者，向患者讲解正常使用方法，避免偶然异常外力再次发生。处理分级很清楚：存在隐裂纹但对美观无影响，可暂不处理；严重影响美观（如深部严重染色），经患者同意才可重新更换修复体；碎裂影响不大，可仅调磨抛光，或口内树脂修补、重粘断裂部分（再粘接失败风险较高，且存在美学风险）；影响大则拆除剩余贴面后重做；基牙折裂者，按基牙缺损情况更改修复设计。

**脱落（10.2）。** 若基牙与贴面完整无破损、可顺利完全复位，可尝试清理组织面与基牙粘接面后重新粘接，条文同时注明「存在较高失败风险」。清除组织面残留水门汀的办法包括车针磨除、超声器械清除、喷砂去除，但都很难保证恰好、完全清除；若材料允许进烤瓷炉烧结且修复体有足够厚度与强度，建议再做一次上釉，通过热处理完全去除残留粘接材料；基牙粘接面可用车针微量磨除或口内喷砂去除残留树脂，同时暴露新鲜牙体组织。

**边缘染色与龈缘红肿（10.3）。** 若边缘密合性尚好、仅轻度外源性染色，可口内精细抛光。龈缘红肿时先查牙周情况与边缘是否残留树脂，清除残余树脂后精细抛光颈缘，必要时联合牙周治疗。若边缘密合性差，拆除后重新修复。

**继发龋（10.4）。** 优先考虑在不破坏原有贴面的前提下处理：从贴面非覆盖处入路，去净龋坏组织，用复合树脂充填。龋坏范围过大则拆除后重新修复，或更改修复方案。

四类的处置强度可以排成一个梯度：抛光 → 修补 → 重粘 → 拆除重做。**每一次升级都要有依据，而依据几乎总在「密合性」这一项上。**

## 三、把并发症追溯到上游

条文本身没有写「病因链」，但四类的处置文字里反复出现同一个前置判断：咬合（碎裂）、污染与残留（脱落）、边缘密合（染色与红肿）、边缘渗漏与清洁（继发龋）。

把这三处前置判断并排，会看到一条共同的汇流：**边缘不密合是四类并发症的共同上游。** 边缘不密合会滞留菌斑（染色与红肿）、会成为渗漏通道（继发龋）、会让水门汀层暴露于唾液与咬合（脱落与碎裂的初始条件）。这也是为什么条文在生物学评价里把「探针探触结合压缩空气吹拂」放在第一位——它一次检查同时服务三条线。

于是在处置前必须先做归因，归因有四问：

1. **边缘密合吗？** 探针能否探入、吹气有无敏感、边缘有无可见缝隙。
2. **咬合有干扰吗？** 咬合纸在正中与非正中分别看，找早接触与侧方干扰。
3. **有污染史吗？** 回顾粘接记录：隔离方式、就位间隔、是否排龈。
4. **清洁谁在做？** 患者或照护者的实际执行能力，决定复发概率。

四问中任一问答「是」，处置方案就要先处理那一项；不处理就直接修表面，第二次失败几乎是必然的——条文对重粘写的「存在较高失败风险」，说的正是这种情况。

## 四、复查时点与记录

条文给了检查内容，没有给复查间隔。间隔要按失败出现的时间分布来定（教学设定，供课堂排程）：初戴后短期内看的是粘接与咬合（就位不全、早接触）；数月内看的是边缘与牙龈（染色、红肿）；更长期看的是基牙与牙周（继发龋、牙周健康）。所以复查不是「半年一次」这一个点，而是至少两个时点：早期一个、稳定期一个。

记录要能支撑下一次判断，因此必须包含四类字段：**发现**（哪条线上、什么部位、什么程度）、**归因**（四问的答案）、**处置**（抛光／修补／重粘／拆除，及其理由）、**下次观察点**（哪个部位、看什么变化）。术前像在这时发挥作用：没有基线，美学线的「变化」无从判断。

还有一条容易被省略的记录：**患者满意度要单独写。** 条文在功能评价的最后一句是「询问患者满意度」，它不是客套——美学线的很多问题只有患者能提出，而满意度是唯一能把患者感知纳入记录的字段。

## 代价与边界

三条线的方法换来的是「失败可归因」，代价与边界有五处：

- **三条线抓不到「检查正常但患者不满意」。** 所有指标都在范围内而患者仍不接受，这一类不属于本章范围，属于术前沟通与期望值管理的问题。
- **重粘的成功率有限且不可预测。** 条文写明「存在较高失败风险」，但没有给成功率数字。这意味着重粘在方案上应被当作「尝试」，而不是「处置」；尝试前要说清失败后的下一步。
- **抛光与拆除的界线依赖密合性判断。** 「密合性尚好」与「密合性差」之间没有数值界值，条文不给，本章也不给。判断靠探针与吹气的经验，靠两人复核。
- **再染色次数受限。** 外染色超过 2 次美观性下降（第 7 章条文），因此「重新上釉修色」这条退路不是无限的。
- **继发龋的入路受贴面覆盖范围限制。** 非覆盖处入路可行，覆盖区龋坏只能拆除。这一点在术前设计时（贴面覆盖到哪里）就已决定。

> **免责声明：** 本章为口腔修复学的教学讨论，不给出复查间隔的强制标准与再粘接成功率，也不提供任何材料参数；并发症的处置须由执业医师在检查后决定，并以病历记录为依据。；本材料为教学用途，不构成诊疗、用药或检验结论的依据。

## 运行与验证

本章的正文与习题契约由脚本现算，可当场复核：

```bash
node code/main.js
```

脚本打印的是本章正文的规模、习题的阶段分布与接地情况；退出码为 0 表示各项契约满足，非 0 表示有不满足的项，输出里会逐条写明。

把一次复查跑成一张三行表，每行必须有器械动作，不能只有描述。

| 线 | 必做动作 | 记录什么 | 典型漏项 |
|---|---|---|---|
| 功能 | 探针探边缘、牙线过邻接、咬合纸看正中与非正中、透照查隐裂 | 干扰位点、邻接松紧、有无松动 | 只做正中咬合 |
| 美学 | 与术前像、与邻牙对比；看光洁度、染色、透光性、外形 | 变色部位与程度、是否影响美观 | 无术前像可比 |
| 生物学 | 探诊＋吹气查边缘敏感、牙髓活力、视诊基牙、牙周检查 | 敏感位点、活力结果、龋与牙周状态 | 只视诊不探诊 |

验收标准三条：一是三行里至少两行必须有器械动作的记录（探针、牙线、咬合纸、活力仪、吹气），纯描述的复查判为不合格；二是每一条发现必须写出归因四问中对应的那一问；三是每条处置必须写出「下次观察点」。

再加一道判断练习：给同一颗贴面同时出现「边缘轻度染色」与「探针可探入 1mm」，按条文该走抛光还是拆除？答「看密合性」还不够，要能说出密合性差时抛光为什么无效——因为染色来自边缘通道，抛光只处理表面，通道还在。
