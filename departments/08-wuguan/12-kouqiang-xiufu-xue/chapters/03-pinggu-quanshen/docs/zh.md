# 第 3 章 · 修复的第一道门不在口内，在病史里

> **MOTTO:** 「对正在服用此类药物或近期内服用过的患者应严禁进行颌骨手术，例如拔牙或种植牙。」——《老年患者口腔修复指南·5.1.2》
>
> **PROBLEM:** 条文把要问的东西列成了 15 项：7 类系统疾病、4 类常用药、4 项全身治疗史，另加过敏史。若初诊只给 10 分钟问诊（教学设定），每项平均 40 秒。漏掉其中任何一项都可能不算错，漏掉双膦酸盐那一项，一次常规拔牙就可能变成颌骨坏死——15 项里只有这一项，条文用的是「严禁」而不是「注意」。

**双根因定位:** 环境逼迫（门诊的问诊时间按主诉分配，患者说「牙疼」，时间就流向那颗牙；全身病史在病历上往往只剩一行「否认高血压」） + 知识积累（把 15 项读成三组不同性质的约束——改时机、改方式、改禁忌——才知道问诊不是填空，是在给今天的手术划边界）

**教材出处:** 外源·T/CHSA 001—2021《老年患者口腔修复指南》第 5.1.1 条、第 5.1.2 条、第 5.1.3 条与第 3.6 条；本课无教材底本，条文逐字录自 `standards/kouqiang-xiufu/sources/`，中文为转述。

## 一、患者评估是五项，不是一项

条文对患者评估的定义很克制：通过病史询问、体格检查、辅助检查等手段，对患者的心理、生理、社会、经济条件、疾病严重程度等做综合评价。五个维度里只有一个属于生理。这一句决定了本章的写法——全身评估不是「查有没有禁忌证」，而是「判断这个人能不能承受这个方案」。

由此，15 项不该被当成一张勾选表。按它们改变的东西，可以分成三组：

| 组别 | 改变了什么 | 典型项 |
|---|---|---|
| 改时机 | 今天能不能动手 | 血压波动、急性感染期、传染期、放化疗期间 |
| 改方式 | 做什么形式的修复 | 认知障碍、震颤、前列腺增生、免疫抑制 |
| 改禁忌 | 哪些操作根本不能做 | 双膦酸盐用药史、起搏器、抗凝未控 |

同一份病史，落在这三组里的处置完全不同：改时机是「推迟」，改方式是「换方案」，改禁忌是「换路径或转诊」。把三者混成一句「注意全身情况」，等于什么都没写。

## 二、七类疾病：七类各有各的卡点

条文逐条给了理由，理由比病名重要。

**心血管系统**（高血压、冠心病等）：治疗中可因局麻药影响或疼痛刺激发生血压变化、心律失常。卡点在刺激，不在牙——所以处置是控制刺激量、必要时心电监护，而不是「心血管病人不能拔牙」。

**内分泌系统**（糖尿病、骨质疏松、甲状腺疾病等）：可能导致种植治疗失败，尤其是血糖控制不良、严重骨质疏松者。卡点在选择种植这条路径的资格，而不是在糖化血红蛋白的具体数值——数值要问内科。

**呼吸系统**（肺炎、支气管炎、哮喘等）：修复时容易受到水气影响发生呛咳，应注意体位、避免误吸。卡点在体位与水量，属于操作设计，不属于禁忌。

**消化系统**（肝炎、肝硬化等）：可能影响凝血功能，有创操作应注意；病毒性肝炎按常规传染病程序处理；急性期、传染期应暂缓口腔治疗。卡点一半在凝血、一半在感染控制。

**神经系统**（阿尔茨海默病、帕金森病等）：认知障碍者应对家属或监护人做好知情同意；肢体不自主震颤可能影响临床操作。卡点同时在同意主体与操作精度。

**泌尿系统**（前列腺增生、肾功能不全等）：前列腺疾病患者修复过程应简短，避免长时间操作；肾功能不全可能影响种植手术。卡点回到时间——这一条几乎是「微创」原则在病史里的回声。

**免疫系统**（系统性红斑狼疮等）：需长期服用免疫抑制剂，影响机体功能，如需种植等操作需慎重。卡点在有创操作的愈合能力。

七条并排看，会发现**只有两条真正关涉「能不能做」，另外五条关涉「怎么做」**。这个比例很重要：全身评估的产出，多数时候不是一个否决，而是一个修改后的方案。

还有一处容易被读反：内分泌系统一条把风险落在「种植治疗的失败」上，而不是「种植的禁忌」上。失败与禁忌是两个不同层级的判断——前者说这事成功率低，后者说这事不能做。条文用的是前者，所以处置也应当是前者：把种植从首选降为备选、把预期讲清楚、把替代方案摆出来，而不是一刀切地拒绝。区别在于，前者留了患者选择的空间，后者替你做了选择。

## 三、四类用药：四种不同的禁忌动作

用药史比疾病史更容易被漏，因为患者常不把「每天吃的药」当成病史。

**抗凝药物**：应检测凝血功能，避免有创修复操作引起术后持续性出血。动作是「先测，再决定创口大小」。

**激素类与免疫调节类药物**：药物及原发疾病可影响免疫力与机体功能，应避免为此类患者选择创伤较大的修复方式。动作是「降级方式」，不是「取消治疗」。

**镇静安眠药物**：最好选择固位力相对可靠的修复体，并强调勿戴可摘义齿睡觉，避免误吞。动作是「改设计 + 改医嘱」，两条都要做；只做前一条，患者照样会戴着义齿睡。

**双膦酸盐药物**：对正在服用或近期内服用过的患者应**严禁**进行颌骨手术，例如拔牙或种植牙。动作是「停手」。这一条是本课全部条文里语气最硬的一处，没有「慎重」「注意」的余地。

四种药对应四个不同动词：测、降、改、停。背药名没用，要背的是动词。

## 四、四项全身治疗史与既往修复评价

**放化疗**：口腔有创操作（修复前拔牙、种植等）可能导致伤口不愈合、骨坏死。**心脏支架**：常规服用抗血小板或抗凝药物，有创操作前应检测凝血功能，必要时专科会诊。**心脏起搏器**：不建议超声波洁牙、根测仪测量根长，必要时咨询心内科；高速涡轮机的噪音也可能有影响。**助听器**：超声波洁牙对部分助听器有影响，听力受损者的家属也要做好知情同意。

这四项有一个共同点：它们都不在「疾病」栏里，而在「治疗史」栏里。患者说「我没病」，往往是真的——病已经治完了，留下的是支架、起搏器、放疗野和助听器。

第四组是口腔治疗史。条文要求了解既往口腔治疗史，尤其修复相关病史，并**着重了解患者对既往治疗或修复方式的感受与评价**，明确期望值。这一条的操作价值极高：问「上次那副义齿哪里不舒服」比问「你想要什么样的牙」有用得多——前者给的是失败模式，后者给的是想象。

## 代价与边界

这套三组分类换来的是可执行的判断，代价与边界有四处：

- **条文给方向，不给阈值。** 「血糖控制不良」「严重骨质疏松」「凝血功能」都要求具体数值，而条文没有给。这些数值必须来自内科会诊、检验报告与所在机构制度，本章不代填。
- **会诊不是免责。** 请了专科会诊，不等于责任转移；修复方案仍要由本人在会诊结论的范围内作出，并把范围写进病历。
- **时效性。** 条文提示必要时可查看患者 3 个月内相关检查报告。三个月前的凝血结果不能支撑今天的拔牙——这一点常被「病历里有」掩盖。
- **15 项不是穷尽。** 条文列的是「常见」疾病与「常见」药物，罕见病、新药、保健品不在列。分类框架能用，清单不能当封闭集。

还要说清一处语气差别，它决定记录怎么写。同一份条文里，「应检测凝血功能」「应避免创伤较大的修复方式」「最好选择固位可靠的修复体」「应严禁颌骨手术」是四个不同强度的要求：前两个是必须执行的动作，第三个是倾向性建议，第四个是禁止。病历里一律写成「已注意」，就把四种强度压成了一种——日后回看，谁也分不清当时到底做到了哪一步。

> **免责声明：** 本章为口腔修复学的教学讨论，不给出疾病控制阈值、药物停用时间与任何材料参数；全身状况的判断与用药调整须由执业医师及相关专科作出。；本材料为教学用途，不构成诊疗、用药或检验结论的依据。

## 运行与验证

本章的正文与习题契约由脚本现算，可当场复核：

```bash
node code/main.js
```

脚本打印的是本章正文的规模、习题的阶段分布与接地情况；退出码为 0 表示各项契约满足，非 0 表示有不满足的项，输出里会逐条写明。

把一个真实初诊跑成一张评估表，字段固定，缺项写「未采集」，不许写「无异常」。

| 栏目 | 必须落到的颗粒度 | 判定 |
|---|---|---|
| 系统疾病 | 七类逐类过，阳性者写下卡点属于改时机／改方式／改禁忌 | 只写「否认」为不合格 |
| 用药 | 四类逐一问，双膦酸盐必须问到「在服／近期服过／未服」三态 | 只写「无特殊用药」为不合格 |
| 全身治疗史 | 放化疗、支架、起搏器、助听器四项逐一问 | 缺项须注明未采集 |
| 过敏史 | 尤其既往口腔治疗相关过敏 | 空白为不合格 |
| 既往修复评价 | 一句患者原话 + 你的解读 | 写「不满意」为不合格 |
| 今日结论 | 能做／能做但限量／须推迟／须转诊，四选一 | 无结论为不合格 |

验收标准三条：一是「今日结论」必须四选一，不能写「待定」；二是若结论为「能做但限量」，必须写出限量（单次时长、是否含拔牙、是否需监护）；三是双膦酸盐一栏必须是三态之一，不能留空。

最后做一次压力测试：把表里任意一行改成最坏情况（例如双膦酸盐「在服」），问自己方案还剩多少——剩不下来的部分，就是这份方案原本依赖的运气。
