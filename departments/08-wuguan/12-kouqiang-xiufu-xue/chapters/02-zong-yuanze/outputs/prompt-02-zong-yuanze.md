# 六条原则不是口号，每一条都在削减一种具体的失败 · 提示词

## 用途

给「六条原则不是口号，每一条都在削减一种具体的失败」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「六条原则各自削减哪一种失败 → 冲突时谁让位：一条不可交换的前置条件 → 姑息不是降级，是准入制的减法 → 知情同意的对象是理解，不是签名」这条链。

## 提示词

```
我在学《口腔修复学》第 2 章「六条原则不是口号，每一条都在削减一种具体的失败」，本章 5 节 / 2,708 汉字，习题 7 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 安全是前置条件，不是可交换项
   - 安全 ＞ 一切
   - 有效 ＞ 美观
   - 微创 ＞ 疗程完整
   - 健康 ＞ 设计精巧
   - 说不出牺牲了什么的方案，通常是没想过风险的方案
4. 本章自陈的边界（不得越过）：
   - **它给顺序，不给权重。** 「安全优先」在极端情形下清楚，在边缘情形下含糊：血压控制到多少算「可以动手」，条文不给数字，本章也不给。这类判断必须回到专科会诊与机构制度。
   - **它会诱导「凑原则」。** 一旦要求逐条标注，方案就会倾向于把六条都写成「满足」。防这个的办法是强制写「牺牲了哪一条」——写不出牺牲项，说明权衡没发生。
   - **姑息的边界依赖复评。** 没有复评时点的姑息，会在半年后变成默认方案，患者失去转回一般修复的机会。这是本章最需要盯住的一处漏洞。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为口腔修复学的教学讨论，正文不写适应证阈值，也不给材料与药物参数；具体操作以现行规范与所在机构制度为准。
