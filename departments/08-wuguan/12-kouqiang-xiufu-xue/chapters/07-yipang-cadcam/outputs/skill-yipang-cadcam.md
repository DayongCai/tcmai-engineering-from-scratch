# 椅旁修复把加工厂搬进诊室，也把全部误差留在同一天

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 不宜采用贴面等更微创修复技术
- 预备 → 扫描 → 设计 → 参数 → 切削 → 后处理 → 粘接
- 预备的输出是扫描的输入
- 扫描的输出是设计的输入
- 设计的输出是参数的输入
- 切削的输出是后处理的输入

## 边界

- **误差没有缓冲。** 技工所那一段的价值不只是加工，还包括中途复核。椅旁模式把复核压缩到扫描后的几十秒，扫描不合格而未被发现，是这条链上最贵的错误。
- **强度表是推荐，不是许可。** 条文用（-）（+）（++）（+++）四档表达推荐度，并注明固定桥单位数限制。超出推荐档使用，责任在使用者，不在表格。
- **参数必须按设备微调。** 条文原文即写「建议按照每套设备制作的修复体实际情况进行微调」。抄别人的参数表，等于把别人的设备误差搬到自己这里。
- 本章为口腔修复学的教学讨论，所引厚度与参数为条文推荐值，具体数值以材料说明书与设备厂家说明为准。
