# 第 4 章 · 老年的「正常」和年轻人不是同一套标准

> **MOTTO:** 「对于老年患者，推荐优先使用曲面断层片、CBCT。」——《老年患者口腔修复指南·5.2.2》
>
> **PROBLEM:** 条文列了 7 项增龄性变化，其中 4 项会直接改写修复设计；可这 7 项在口内看起来都像「年纪大了就这样」——牙龈退缩被读成正常、垂直距离降低被读成自然老化、唾液减少被读成无关。更麻烦的是拍片：咽反射明显者拍不成根尖片，检查手段反过来被患者条件决定，而不是被病变决定。

**双根因定位:** 环境逼迫（口内检查的时间被主诉占满，剩下几十秒只够看那一颗牙；片子按惯例开根尖片，因为「一直都这么开」） + 知识积累（把 7 项分成「改设计的 4 项」与「改风险的 3 项」，并接受影像选择的第一约束是患者的可配合性）

**教材出处:** 外源·T/CHSA 001—2021《老年患者口腔修复指南》第 5.2.1—5.2.4 条；本课无教材底本，条文逐字录自 `standards/kouqiang-xiufu/sources/`，中文为转述。

## 一、七项增龄变化，分成「改设计」与「改风险」两组

条文对临床口腔检查的要求是：修复开始前对口腔做全面检查与评估，除常规检查外，还要注意老年患者口腔的增龄性变化。七项原文如下。

**牙体**：余留牙常有重度磨耗、松动或楔状缺损。**牙周**：牙龈退缩明显，临床牙冠增长；牙槽骨吸收明显。**牙列**：缺牙数目较多，甚至是无牙颌。**咬合关系**：垂直距离降低、面下 1/3 高度降低、咬合紊乱。**腺体**：唾液分泌减少，口腔自洁能力有限。**黏膜**：可能伴有口腔黏膜病变、黏膜感觉异常。**颞下颌关节**：可能存在退行性改变。

七项平铺没有用，必须分组（本课的分组为教学设定）：**前四项改设计**——牙体决定预备量与固位形，牙周决定基牙能否承担、边缘放在龈上还是龈下，牙列决定形式选择，咬合决定垂直距离要不要重建。**后三项改风险**——腺体决定龋易感与义齿的湿润环境，黏膜决定可否承托与是否有病变需先处理，关节决定能否长时间张口、能否承受咬合改变。

分组的意义在于**检查的时间分配**：改设计的四项必须看清、看全、写进记录；改风险的三项必须问到（口干不干、黏膜有没有不舒服、张口受不受限），因为它们的异常往往先由患者感知到，而不是先由医师看到。

条文还加了两条容易漏的：治疗前仔细询问有无不良口腔习惯，如夜磨牙；口内尚有固定修复体者，要对其做全面检查与评估。夜磨牙会毁掉一切精密设计，而旧修复体常被当成「不用管的部分」——它恰恰是判断患者耐受度与失败模式的最好样本。

旧修复体的检查有一个具体做法（教学设定）：逐单位看边缘、看邻接、看咬合接触，再看患者主诉与这些发现对不对得上。对不上，说明患者感知不到的地方可能已经出问题，这类问题在新修复体上会原样重演。

## 二、影像：按患者条件选片子，而不是按病变选

条文的选择取向很明确：修复前应做必要的放射线检查，对老年患者**推荐优先使用曲面断层片、CBCT**。理由不是清晰度，是操作现实——老年患者多数存在咽反射明显、各种原因导致的肢体震颤，常规根尖片可能引起恶心、呕吐，不能被接受，或不能良好成像。

这一句值得逐字读。「不能被接受」与「不能良好成像」是两种不同的失败：前者是拍不成，后者是拍出来没用。两种失败的结果相同——判断失去依据。

对需要种植的老年患者，条文建议常规 CBCT：颌骨吸收严重，术区解剖结构可能发生变化，CBCT 可明确术区解剖、有无病变，避免损伤重要神经与血管。

由此得到一条判据：**选片子的第一约束是这位患者能不能配合，第二约束才是病变需要什么分辨率。** 反过来做，会得到一张漂亮但拍不成第二次的片子，或者一次失败后患者拒绝再拍。

## 三、模型与照相：为设计留依据，为争议留基线

条文对模型的要求是有条件的：老年修复患者口腔情况复杂，部分合并咬合及颞下颌关节问题，必要时取研究模型，以了解咬合、邻牙以及正中关系，进行有效的评估与设计。关键词是「必要时」与「正中关系」——研究模型不是常规取，是在咬合与关节存疑时才取，且取它是为了在口外看清正中关系。

对相片的要求同样有条件：有条件的情况下，尤其是种植治疗时，应做好照相工作，保留相关资料。多数人把照相理解成「给患者看效果」，条文给的理由是**保留资料**。术前像的真正用途在术后：出现争议时，没有术前像就没有基线，任何讨论都变成各说各话。

照相还有两个技术细节常被忽略：一是同一病例的前后像要用同一套光线与角度，否则比较无意义；二是照片属于患者资料，留档与使用都要有知情同意，用于教学或发表时须另行授权。这两点不属于条文，属于职业规范，但在老年患者身上尤其重要——他们复诊周期长、家属参与多，资料往往要跨人交接。

## 四、检查的出口是两个选项，不是一堆描述

条文的落点很短：在对患者情况评估后，医师可以根据情况选择一般修复治疗还是姑息治疗。

这句话把整章收束成一个二元判断。七项异常、一张片子、一副模型、一组照片，最终要收敛为「一般修复」或「姑息」两个选项之一。收敛不出来，说明前面的检查只是罗列，没有形成判断。

判断的依据是两类：一类是**可修复性**——余留牙、牙槽嵴、咬合与关节能不能支撑完整重建；另一类是**可承受性**——患者能否耐受相应疗程与操作量。两类都过，走一般修复；任何一类不过，走姑息，并写清姑息的范围与复评条件。

两个选项不等于一刀切。一般修复内部仍有量的差别（全牙列重建与分段修复），姑息内部也有量的差别（只恢复前牙区美观与只恢复一侧咀嚼）。条文的二元只是**决策的第一步**，第二步才是在所选支路里定范围。把二元当成结论，会让「一般修复」变成一句空承诺。

## 代价与边界

这一章的方法换来的是「看得见的异常都进了记录」，代价有四处：

- **7 项是观察项，不是诊断标准。** 「牙龈退缩明显」「垂直距离降低」都没有分级界值，条文不给，本章也不给。写记录时可以描述程度（例如「临床牙冠明显增长，邻面暴露至根分叉」），但不能自造分级当作诊断。
- **影像替代不了口内。** 曲面断层片对细微的边缘、隐裂、邻接的显示有限；选它是因为患者配合度，不是因为信息更全。用了它，就要在记录里注明「根尖区细节未获取」。
- **照相有条件。** 条文写的是「有条件的情况下」，意味着设备与流程不支持时可以不做——但不能既不做也不写，那样等于假装没有基线。
- **模型是「必要时」。** 把它做成常规，会拖长流程、增加成本，也不符合条文措辞；把它一律省略，咬合与关节的问题就永远停留在猜测。

> **免责声明：** 本章为口腔修复学的教学讨论，不给出影像学判读标准、投照参数与任何检查阈值；检查项目的取舍与结果解释须由执业医师结合临床作出。；本材料为教学用途，不构成诊疗、用药或检验结论的依据。

## 运行与验证

本章的正文与习题契约由脚本现算，可当场复核：

```bash
node code/main.js
```

脚本打印的是本章正文的规模、习题的阶段分布与接地情况；退出码为 0 表示各项契约满足，非 0 表示有不满足的项，输出里会逐条写明。

把检查跑成一张 7+4 的单子：7 项口内，4 项辅助（片子、模型、照相、习惯询问）。每一项只允许三种状态——正常、异常（写明部位与程度）、未查（写明原因）。

| 项 | 记录什么 | 它改变什么 |
|---|---|---|
| 牙体 | 磨耗部位、松动度、楔状缺损牙位 | 预备量与固位形 |
| 牙周 | 退缩范围、临床牙冠长度、骨吸收 | 基牙能否承担、边缘位置 |
| 牙列 | 缺失段、是否无牙颌 | 修复形式 |
| 咬合 | 垂直距离、面下 1/3、有无紊乱 | 是否重建颌位 |
| 腺体 | 口干主诉、自洁情况 | 龋易感与维护强度 |
| 黏膜 | 病变部位、感觉异常 | 可否承托、是否先治疗 |
| 关节 | 张口度、弹响、疼痛 | 能否长时间操作 |
| 影像 | 片种与选择理由 | 判断有无依据 |
| 模型 | 是否取、用于什么 | 正中关系 |
| 照相 | 有无术前像 | 争议时的基线 |

验收标准三条：一是「影像」一栏必须写出**为什么选这个片种**，写「常规」为不合格；二是 7 项里不得出现「未查」超过两项而无原因；三是检查结束时必须给出「一般修复／姑息」之一，并附一句依据。

再做一次交叉验证：把「咬合」与「关节」两行同时标为异常，问自己方案要不要改——如果答案是「不用改」，那说明这两行原本就没被真正检查过。
