# 修复学的第一个动作是分类，不是选材料 · 提示词

## 用途

给「修复学的第一个动作是分类，不是选材料」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三个层级：病变停在牙上、到了牙列、还是到了颌位 → 60 周岁是证据边界，不是礼貌用语 → 「参照」二字：指南不是操作规范 → 运行与验证」这条链。

## 提示词

```
我在学《口腔修复学》第 1 章「修复学的第一个动作是分类，不是选材料」，本章 5 节 / 2,800 汉字，习题 7 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 它们的失败模式不同
   - ；牙列缺损的条文里，邻接是缺失之后需要
   - 证据覆盖范围
   - 为什么先做全身评估
   - 为什么允许姑息治疗
   - 为什么体位、单次时长、张口度都要约束
4. 本章自陈的边界（不得越过）：
   - **它不回答该不该修。** 三类缺损之下仍有大量病例属于「可修可不修」，分类只说明病变在哪一层，不说明干预的收益大于风险。该不该修要回到第 2 章的六条原则。
   - **它是静态快照。** 多类缺损并存时，本章只给「以哪类为主」，不给处理先后。先后顺序属于修复前处理的问题，见第 5 章。
   - **它不覆盖 60 岁以下。** 人群边界是硬边界，不能靠「病理生理相同」类推。条文没有写 60 岁以下，就是不覆盖。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为口腔修复学的教学讨论，正文不给出适应证阈值与材料参数，也不替代任何临床判断；具体操作以现行规范与所在机构制度为准。
