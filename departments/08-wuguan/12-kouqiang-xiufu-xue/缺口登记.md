# 缺口登记：口腔修复学（0/10 章，暂不建）

## 一、为什么这次没照前几门的办法合成

前几门（09 口腔内科、10 眼科影像、11 颌面外科）之所以能合成，是因为底本里**确实存在**该学科的核心术语与章节
——口齿科有「牙痛、牙周、口疮」，眼科有「内障、眼底、瞳神」，外科有「疮疡、成脓、走黄」。

口腔修复学不一样。我把全库 178 个单元层（**34,247,094 汉字**）扫了一遍，修复与正畸的核心术语命中是：

| 术语 | 全库命中 | 判读 |
|---|---|---|
| 固位 | **2** | 只有一个别处提到 |
| 基牙 | **0** | 无 |
| 牙列 | **6** | 无系统论述 |
| 咬合 | **29** | 仅解剖章顺带 |
| 嵌体 | **0** | 无 |
| 冠桥 | **0** | 无 |
| 印模 | **1** | 无 |
| 义齿 | 52 | 多为「义齿性口炎」类顺带提及 |
| 修复体 | 14 | 同上 |
| 支抗 | **0** | 无 |

也就是说，能凑出来的只有「牙体解剖 + 口腔检查 + 口齿科调护」，那是 02 口腔解剖生理与 08 中医口腔科学**已经写过的内容**；
按修复学章名再讲一遍，就是同一批字的第三次阅读，还会把「基牙预备」「固位设计」这类核心判据彻底写空。

按「不注水、不mislabel」的口径，**这门课不建**。
