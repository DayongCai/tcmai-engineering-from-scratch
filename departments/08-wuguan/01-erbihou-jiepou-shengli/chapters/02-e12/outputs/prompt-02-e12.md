# 耳：三段两层膜，看得见的边界在鼓膜就断了 · 提示词

## 用途

给「耳：三段两层膜，看得见的边界在鼓膜就断了」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「总纲：三段各做一件事，两个界面各是一层膜 → 外耳：两段、一个弯、两处血供薄弱 → 中耳：六壁是一张并发症的路由表 → 中耳不是一台变压器，它是一个有进有出的腔」这条链。
