# 生理：功能拆得开，症状才反推得回去 · 提示词

## 用途

给「生理：功能拆得开，症状才反推得回去」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「七个词换成七条通路 → 声传导与感音：骨导是一次对照实验 → 平衡：三路输入，三路输出，一份比对 → 鼻：三个动作，一条周期」这条链。

```

请按以下顺序带我走：

2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
```

## 边界

本章为教学材料，不构成医学意见、诊断或处置指导。文中的功能描述只到通路与环节，不含生理常数、听力级与判读界限；具体操作以现行规范与所在机构制度为准。
