# 耳鸣不是耳朵在响：鸣为聋之渐，治的是通与养

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 「堵，还是响？」
- 反例一：暴起而属虚
- 与劳累的耦合
- 反例二：渐起而属实
- 睡眠与情绪要写进辨证，不要当成陪衬
- 用物理办法恢复压力平衡

## 边界

- 本章的患病率数字（成人 10%～15%，其中 1%～3% 严重影响生活；约 90% 学龄前儿童有过急性中耳积液）取自教材所述，为概略量级，不同调查口径差异较大，引用时须注明来源，不可当作本机构数据。
- 本章不写方剂剂量、煎服法、疗程与针刺深度。教材中的具体克数、日数、寸数一律不转抄；凡涉及处置，以所在机构规范与执业者判断为准。
- 耳鸣的机制尚未完全阐明，教材所述「听觉通路异常放电、边缘系统参与」属现代研究层面的假说，本章只作背景，不据此推论中医疗效。
- 本章为中医耳鼻喉科学耳病辨治的教学材料，不构成医学意见、诊断或治疗建议。耳鸣耳聋的病因复杂，须由具备资质的人员结合耳内镜、听力学检查与全身情况作出判断。
