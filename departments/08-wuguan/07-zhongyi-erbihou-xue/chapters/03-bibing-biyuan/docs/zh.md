# 第 3 章 · 鼻塞三个月：一个症状，三条完全不同的路

> **MOTTO:** 「肺气通于鼻，肺和则鼻能知臭香矣。」——《灵枢·脉度》
>
> **PROBLEM:** 教材在鼻科一章里列了七个病：鼻疔、鼻疳、伤风鼻塞、鼻窒、鼻鼽、鼻渊、鼻衄。而门诊最常听到的主诉只有四个字——「鼻子不通」。这四个字在七个病里至少能落到三个：鼻窒（黏膜与鼻甲）、鼻渊（窦口与窦腔）、鼻鼽（发作性黏膜反应）。三者治法不同，疗程不同，预后也不同：鼻窒要通，鼻渊要引流，鼻鼽要避开诱因加扶正。用治感冒的思路去治三个月的鼻塞，最常见的结局是病人自己买了半年的滴鼻剂，把黏膜性问题拖成药物性鼻炎。教材把这一条写进鼻窒的病因里，是整章最该先读的一句。
>
> **双根因定位:** 环境逼迫（鼻塞的判据全在「什么时候重、哪一侧重、鼻涕什么样」这三句问话里，而这三句问话要在病人坐下的头两分钟问完；问不出来，后面的检查就只是验证偏见）+ 知识积累（本课单元层 205 单元 184,607 汉字；教材第 6 章鼻科疾病约 10.3 万字节，七病各按概述、病因病机、辨证论治、预防调护、按语五栏写满，证型与代表方齐备，可作逐条对读；本章只取其中能落到「部位—引流—反应性」三层上的句子）

## 一、七病一症：先把「鼻塞」拆成三条路

鼻塞不是一个病，是一个位置。教材用「窒」字定义鼻窒——「窒，塞也」，说明古人看的也是这个位置感。位置分三段：鼻前庭与外鼻（入口）、鼻腔（通道）、鼻窦（挂在通道边的房间）。三段各有一条典型的病：

**黏膜段——鼻窒。** 鼻甲肿胀或肥厚，通道变窄。特点是交替性、间歇性，遇冷、夜间、静坐加重，活动后减轻。教材把「交替」单列为主症，因为它是黏膜性鼻塞的指纹：下鼻甲的静脉丛在昼夜之间有涨落。

**窦腔段——鼻渊。** 鼻腔可能通，但窦口堵了。特点是涕多而难出、头闷胀、嗅觉减退，痛位随窦而定。教材写「涕浊下流，源源不断，状如渊泉」，说的是引流不止，不是鼻道不通。

**反应段——鼻鼽。** 发作性：鼻痒、喷嚏连作、清涕如水，发作过后如常人。特点是「来去」，不是「持续」。

三条路可以重叠，也可以互相转化：鼻鼽反复发作可以长出鼻息肉、堵住窦口而成鼻渊；鼻渊的脓涕长期刺激可以让鼻甲肥厚而成鼻窒。所以问诊要问「最先出现的是哪一条」。

## 二、「堵在哪儿」：三个动作，四个判据

教材讲鼻病辨证，第一步是局部辨证，第二步才是脏腑辨证。局部辨证落在四个判据上，都能在两分钟内拿到。

| 判据 | 看到什么 | 指向 |
|---|---|---|
| 侧别 | 交替、左右轮换 | 黏膜（鼻窒） |
| | 固定单侧、进行性加重 | 结构或占位，须查 |
| 涕 | 清水样、量多、发作性 | 鼻鼽 |
| | 黏白、量多、遇寒加重 | 脾肺气虚 |
| | 黄稠、有味、难出 | 鼻渊（窦腔） |
| 时辰 | 晨起加重、午后减轻 | 额窦引流（鼻渊） |
| | 夜间与静坐加重 | 鼻甲黏膜（鼻窒） |
| 反应 | 对减充血剂敏感、能通 | 黏膜层 |
| | 不敏感、桑椹样 | 黏膜下与骨（肥厚） |

四个判据里最有分量的是最后一条：**对减充血剂有没有反应，等于问病变在黏膜还是在黏膜下。** 教材写鼻窒的气滞血瘀证用「鼻甲肥大暗红、表面凹凸不平、桑椹样」来描述这一层，理由就在这里——黏膜可以收缩，肥厚的组织不能。

三个动作：前鼻镜看鼻甲色泽与中鼻道有无脓；鼻内镜看中鼻道、嗅裂、有无息肉；必要时影像看窦腔与窦口。**只报「上颌窦积液」而不报「中鼻道是否闭塞」，等于只说了结果没说原因。**

## 三、鼻窒：不是炎症不退，是通气的调节器坏了

鼻窒的三证，教材排得很整齐，本质是三种「调节器失灵」。

**肺经蕴热**——鼻塞时轻时重、涕黄黏量少、鼻内干燥灼热、舌红苔薄黄。治法清热宣肺、通利鼻窍，教材用黄芩汤。这一证多见于嗜辛辣、久处干燥环境者。要提醒一句：这一型最容易误用温散，越散越干。

**肺脾气虚**——鼻塞遇寒加重、涕清稀或黏白量多、气短自汗、纳呆便溏。治法补益肺脾、宣肺通窍，教材用补中益气汤。这一证的判据是「遇寒加重＋倦怠」，不是「鼻涕清」。教材引李杲「脾胃虚则九窍不通」为此法立论，落到操作上就是一句话：补气升清比通窍喷剂管得久。

**气滞血瘀**——鼻塞持续不减、涕黏滞、鼻甲暗红桑椹样、舌暗有瘀点。治法活血化瘀、通络开窍，教材用通窍活血汤。到了这一证，单靠内服见效慢，教材明说可配合鼻甲局部治疗，但须专科评估。

这一节真正的重点是病因里那句容易被跳读的话：**长期使用血管收缩滴鼻剂可致药物性鼻炎。** 教材在预防调护里给了明确边界——连续使用不宜超过一周。这个「一周」不是本章给的参数，是教材原文的警示线；实际使用以药品说明书与所在机构规范为准。

用药性鼻炎的典型病史是这样的：一开始喷一次能通六小时，两个月后两小时就堵，越喷越频，停药就完全不通。此时黏膜的反跳性充血已经盖住了原本的病变，任何辨证都失真。处理的第一步不是开方，是**停药并告知反跳期**，否则病人会以为药没用。

## 四、鼻渊：脓涕要有出口，而出口只有一个

鼻渊的病机，教材用一句话点透：「总以通窍排脓为要。」这句话的结构含义是：窦腔是个瓶子，瓶口在中鼻道。所以鼻渊的治疗靶点是**通道**，不是窦腔。反复穿刺抽脓而不通窦口，脓会再来。

教材的证型按「热—湿—虚」排：

- **肺经风热**（初起，涕黄、发热恶风）：疏风清热、宣肺通窍，银翘散。
- **胆腑郁热**（涕黄稠如脓、臭味、头痛剧烈、口苦）：清泄胆热、利湿通窍，龙胆泻肝汤。此证的经典出处是《素问·气厥论》「胆移热于脑，则辛頞鼻渊」。
- **脾胃湿热**（涕黄浊量多、口黏、苔黄腻）：清热利湿、化浊通窍，甘露消毒丹。
- **肺脾气虚**（涕白黏、缠绵不愈、倦怠）：补益肺脾、托毒排脓，温肺止流丹。

有两个临床事实，教材写得很实，值得单独立住。

**第一，头痛的定时性比头痛的位置值钱。** 额窦引流道细长曲折，卧位一夜窦内积液最多，故晨起最痛，活动半日引流渐畅，午后减轻。教材在鼻渊的发病特点里写了「前额痛多属额窦炎」，本章补一句可操作的判据：**问「早上重还是下午重」，比问「哪儿痛」更能定窦。**

**第二，单侧、反复、治不好的上颌窦炎要查牙。** 上颌窦底与后牙牙根只隔一层薄骨，牙源性感染可以直接上来。教材把龋齿、牙周病列为鼻渊的成因之一。凡是「一轮一轮治、总在同一侧」的，先看牙，再看窦。

儿童鼻渊还有一条独立线索：腺样体。腺样体堵在鼻咽，既是鼻塞的原因，也是鼻窦引流的下游障碍。教材在耳胀耳闭与鼻窒两处都提到腺样体，理由一致——它一个人能同时造成鼻塞、中耳积液与张口呼吸。所以儿童「鼻塞＋打鼾＋听力下降」三联，检查顺序是先鼻咽。

## 五、鼻鼽只讲一句，红线要讲三条

鼻鼽留给第 6 章展开，本章只立一个字：**发**。发作性、来去、遇诱因即起、发作后如常——有这个「发」字，才叫鼻鼽；没有它，只是鼻塞。

三条红线，教材写在鼻衄与鼻渊两处，本章合并：

**一、单侧涕中带血，尤其是中老年、持续两周以上。** 教材原文把它写成警示：反复鼻衄或涕中带血，特别是中老年患者单侧涕中带血，应警惕鼻腔及鼻咽部肿瘤，须及时检查。这一条不能靠「先吃点清热止血的药看看」。

**二、脓涕伴臭味、伴眶周肿胀、眼球突出或视力改变。** 提示窦壁受累，已超出鼻科门诊范围，须立即转诊。

**三、鼻塞伴剧烈头痛、发热、颈部抵抗。** 提示颅内并发症可能，按急症处理。

判据收束成一句：**鼻塞可以慢慢辨，出血、臭味、眼球与神志不能等。**

## 代价与边界

- 本章的证型名称与代表方依教材第 6 章；方剂在本章只作「治法—方名」的对应，不给剂量、煎服法、疗程。教材中的具体克数与日数一律不转抄，实际使用以药典、药品说明书与所在机构规范为准。
- 「连续使用减充血滴鼻剂不宜超过一周」为教材的警示表述，本章照录其意，具体时限以药品说明书与所在机构规定为准。
- 「约 90% 学龄前儿童有过急性中耳积液」等流行病学数字取自教材，为概略量级，不同口径差异较大，不得当作本机构统计。
- 局部检查（前鼻镜、鼻内镜、影像）的操作与判读须由具备资质者完成；本章对影像的描述只到「报告什么才有用」，不涉及诊断标准。
- 本章不讨论鼻疔、鼻疳、鼻息肉与鼻腔鼻窦肿瘤的系统辨治，只在与鼻塞鉴别相关处提及；凡疑及占位者，按转介处理。

**免责声明：** 本章为中医耳鼻喉科学鼻病辨治的教学材料，不构成医学意见、诊断或治疗建议。鼻塞、脓涕、鼻出血的病因须由具备资质的人员结合局部检查与影像作出判断；单侧涕中带血、脓涕伴臭味或视力改变、鼻塞伴剧烈头痛者，应立即转诊。
