# 对接不是「古方治今病」，是判据到判据的翻译 · 提示词

## 用途

给「对接不是「古方治今病」，是判据到判据的翻译」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三层对接，先分开 → 病名对接：只到检索为止 → 证候对接：对判据组，不对病名 → 方证对接：读方先读「证的边界」」这条链。

```
我在学《中医五官科经典选读》第 6 章「对接不是「古方治今病」，是判据到判据的翻译」，本章 8 节 / 3,029 汉字，习题 7 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 变应性鼻炎与鼻鼽
   - 干眼与白涩症
   - 不给剂量与疗程

   - 版本责任在引用者
4. 本章自陈的边界（不得越过）：
   - **不给剂量与疗程。** 方名只标方向。古方的分量按当时度量与体质定，直接折成今天的克数，是把一个历史数据当成处方参数。

   - **红旗优先于辨证。** 视力骤降、突发单侧听力下降、单侧鼻衄或涕血、呼吸困难、张口困难、咽痛伴单侧肿胀，这几类先转诊。对接做得再细，也不该在这一步继续观察。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

本章为教学材料，不构成医学意见、诊断或治疗指导；具体操作以现行规范与所在机构制度为准。
