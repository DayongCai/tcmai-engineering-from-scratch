# 五官科的「经典」不是一个书架，而是五条各有源流的谱系

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 5 条核心判断见下）；
4. 用 `quiz.json` 的 8 道题自检，答不上就回到对应小节。

## 核心判据

- 谱系意识会让人变慢
- 托名书的处理只有两种，没有第三种
- 篇幅不等于分量
- 不给页码，就要求读者自备底本
- 不把「经典有此说」当作疗效证据

## 边界

- **谱系意识会让人变慢。** 每引一句都要先定位，写作与讲课都会磕绊。这是成本，不是缺陷。快的那条路是把所有眼科书当成一本，代价是引谁都不准。
- **托名书的处理只有两种，没有第三种。** 要么标明「题某撰，一般认为成书于某代」，要么不用它作断代证据。把它当信史用，再补一句「传说」,并不算处理。
- **篇幅不等于分量。**《口齒類要》十三篇，比《审视瑶函》六卷短得多，但它是口齿一系现存较早的专书，缺了它，口齿谱系就断了。反过来，长篇方书里的五官内容多是转引，不能因其卷帙浩繁就当作专科成就。
- 本章为教学材料，不构成医学意见、诊断或治疗指导。
