# 「肾开窍于耳」是起点，不是答案

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 5 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 「肾虚」不是耳鸣的默认解释
- 不把「肾开窍于耳」当解剖通路
- 暴聋不给时限数字
- 补益之品有代价
- 情志与睡眠要进辨证

## 边界

- **「肾虚」不是耳鸣的默认解释。** 默认解释的代价是漏诊：突发性聋、听神经瘤、耳硬化、噪声性聋、药物性耳聋，都可能以「耳鸣」进门。凡单侧、进行性、伴眩晕或伴神经症状者，先做听力学与影像评估。
- **不把「肾开窍于耳」当解剖通路。** 它讲的是精气灌注的关系，不是神经走向。用现代解剖去证它「对」，或用它去否定解剖，都是错位。
- **暴聋不给时限数字。** 处置窗口按现行规范与专科判断，教材里写死小时数，就成了过期参数。能写的是：属急症，越早转诊越好。
- 本章为教学材料，不构成医学意见、诊断或治疗指导。
