# 第 3 章 · 「肾开窍于耳」是起点，不是答案

> **MOTTO:** 「南方赤色，入通于心，开窍于耳，藏精于心。」——《素问·金匮真言论》
>
> **PROBLEM:** 「耳鸣是肾虚」这句话在门诊出现的频率，远高于它在经典里的分量。《内经》确实说过「肾气通于耳，肾和则耳能闻五音矣」，但同一部书里还写着「开窍于耳」的是心，写着「耳者，宗脉之所聚也」，写着「髓海不足，则脑转耳鸣」，写着「精脱者，耳聋」，写着「上气不足，脑为之不满，耳为之苦鸣」。这些条文指向的病因并不相同——肾精、心血、宗脉、髓海、上气、肠胃。后世把其中一条抽出来当通例，其余降为注脚，于是耳鸣只剩一个解释，治法也只剩一个方向。真正要问的不是「肾开窍于耳」对不对，而是它到底能解释多少。

**双根因定位:** 环境逼迫（耳鸣病人多、检查常阴性、见效慢；一句「肾虚」既解释得通，又不必继续追问，何况补益之品平和不担风险） + 知识积累（耳病诸条文的原文指向 × 心肾两说的并存理由 × 三条入耳经脉 × 暴聋与渐聋的分层 × 虚证实证的判据组）

## 一、八条条文，六个方向

把《内经》里直接谈耳的条文并排摆开，比读任何注家都清楚。

| 条文 | 出处 | 它说的是什么 |
|---|---|---|
| 「肾主耳……在窍为耳」 | 《素问·阴阳应象大论》 | 归属：耳为肾之外窍 |
| 「肾气通于耳，肾和则耳能闻五音矣」 | 《灵枢·脉度》 | 功能条件：肾气和则听觉成 |
| 「南方赤色，入通于心，开窍于耳，藏精于心」 | 《素问·金匮真言论》 | 另一归属：耳亦通于心 |
| 「耳者，宗脉之所聚也」 | 《灵枢·口问》 | 结构：诸脉汇聚于耳 |
| 「髓海不足，则脑转耳鸣」 | 《灵枢·海论》 | 病机：髓海虚 |
| 「精脱者，耳聋」 | 《灵枢·决气》 | 病机：精脱 |
| 「上气不足，脑为之不满，耳为之苦鸣」 | 《灵枢·口问》 | 病机：上气不足 |
| 「头痛耳鸣，九窍不利，肠胃之所生也」 | 《素问·通评虚实论》 | 病机：肠胃升降失常 |

八条里明说肾的只有两条，而且都是归属与功能条件，不是病因分类。剩下六条给了五个不同方向。这不是经典自相矛盾，是经典在描述一个多入口的系统：耳要听到，需要精足、血充、气升、脉通、髓满，任何一环断了都聋。肾主精，是其中一环，且是最不容易替代的一环——所以它被记住；但它不是唯一一环。

读法上的差别就在这里。把八条读成一个系统，遇到耳鸣你会去问：是精不足，还是气不升，还是脉不通，还是有痰火在上？把八条读成一条，你只会问：补阴还是补阳。

隋代《诸病源候论》把这八条落成了「候」。其耳病诸候论耳聋，一面说肾气通于耳，一面说风邪乘虚入于耳经则聋——脏虚与外邪并重，不是二选一。这个写法很值得注意：它没有把耳聋归给肾，也没有归给风，而是把「虚」写成「邪得以入」的条件。后世所谓「肾虚夹风」，原型就在这里。读唐宋以前的耳病条文，要习惯这种双层写法：一层说本，一层说因，两层合起来才是一个候。

## 二、心与肾：两条线为什么能并存

《素问·金匮真言论》把耳接到心上，后世并没有删掉它，而是另造一句来调和：肾开窍于耳，心寄窍于耳。

「寄」这个字用得很准。肾主耳之「本」——精生髓，髓通于脑，耳居头面而与脑相通，精足则听觉敏；心主耳之「用」——心主血脉，耳赖血养，心神安则听觉不乱。一本一用，两说各管一段，不必互相取消。

临床上这一点很实用。耳鸣而伴失眠、心悸、烦燥、多梦者，从心治——安神定志、养血宁心，耳鸣常随睡眠改善而减；耳鸣而伴腰膝酸软、发脱齿摇、夜尿频多者，从肾治。同一个人可以两者兼有：老年肾虚之人兼有心悸失眠，单补肾无效，单安神也不持久，要两端同调。

更要紧的是那句「寄」所承认的事：耳不属于一个脏。归属可以有好几个，只要各自说清自己管哪一段。反过来，凡宣称「耳只属于某脏」的说法，都要追问它把另外几条怎么办。

## 三、经络：耳为宗脉所聚

《灵枢·口问》说「耳者，宗脉之所聚也」，这不是修辞。《灵枢·经脉》里入耳的经脉至少三条：手太阳小肠脉的支者「至目锐眦，却入耳中」；手少阳三焦脉的支者「从耳后入耳中，出走耳前」；足少阳胆脉的支者「从耳后入耳中，出走耳前，至目锐眦后」。此外足阳明之筋「从颊结于耳前」，耳周为经筋所结。

手足少阳都绕耳一周，这一条对临床最有分量。少阳主枢，枢机不利则耳内胀闷、听力下降、耳鸣时轻时重，常伴口苦、咽干、脉弦。感冒后耳闷、乘机后耳堵、情绪波动后耳鸣加重，多可从此处想。取穴用中渚、外关、翳风、听会，也是循这条线。

但要守住一条界线：经络给的是通路与取穴依据，不是病因。知道少阳绕耳，只说明「少阳的病可以到耳」，不说明「耳病都是少阳」。把通路当病因，与把归属当病因，是同一种错。

## 四、病名的分层：先分暴与渐，再分鸣与聋

五官科古籍里与耳有关的病名不少：耳鸣、耳聋、耳胀、耳闭、聤耳、脓耳、耳眩晕、耳疔、耳疮。这些名字看似并列，其实分属几条不同的线。

**暴与渐。** 暴聋是数日之内听力骤降，常单侧，可伴耳鸣、耳闷、眩晕；渐聋是数月数年逐渐下降，常双侧。这两类的处置完全不同：前者是急症，有处置时限，须立即转耳鼻咽喉科评估，中医药只能在规范治疗的前提下参与；后者才是「肾虚耳鸣」的典型场景。把暴聋当渐聋补，是本篇最要避免的一种错。

**鸣与聋。** 耳鸣与耳聋常并见，但可以单独出现。暴聋之后遗留耳鸣者，与久鸣渐聋者，病机不同：前者多属气滞血瘀或脉络受阻，后者多属精血不足。同是耳鸣，一个要通，一个要补。

**胀、闭、脓。** 耳胀耳闭指耳内胀闷、听力下降而鼓膜未穿孔者，多与肺失宣降、少阳枢机不利有关，感冒后最常见，与肾无关。聤耳、脓耳指耳内流脓，多责肝胆湿热或脾虚湿困，也不在肾虚一路。耳眩晕以旋转性眩晕为主，痰湿中阻者最多，半夏白术天麻汤一类；肾精不足者亦有，但须有精亏之据。

**鸣与脑鸣。** 病人说「脑子里响」，与「耳朵里响」不是一回事。脑鸣多属髓海不足或上气不足，位置在头而不在耳，取穴与用药也不同。问诊时这一句要分清。

## 五、把「肾虚」放回它该在的位置

肾虚不是不能用，是要有据。可用的判据组大致是：听力渐降而非骤降；双侧为主；鸣声细如蝉、入夜尤甚；伴腰膝酸软、头晕、发脱齿摇、健忘、夜尿频多；舌淡或红少苔，脉细弱或沉细。这五六项里凑得起四项以上，从肾论治才站得住。

只有「耳鸣」一项，不足以定为肾虚。理由很简单：痰火、气滞、血瘀、上气不足都能鸣，且这几种在青壮年更多见。年老肾虚之人也可以夹痰夹瘀——耳鸣如潮、胸闷痰多、口苦、舌苔黄腻，此时先清化痰火，补药留到后面。虚实兼夹时，先治其实、后顾其虚，是古书里反复讲的次序。

方向上，肾精不足者用耳聋左慈丸一类滋肾填精；脾虚清阳不升、耳鸣而倦怠食少便溏者用益气聪明汤一类升清；痰湿中阻、眩晕耳鸣者用半夏白术天麻汤一类；肝火上扰、耳鸣暴作而口苦胁痛者用龙胆泻肝汤一类。方名只标方向，不标剂量。

还有一条常被忽略：听力康复不因辨证而排除。助听器、人工耳蜗、听觉训练，与中药针灸并不冲突。辨证论治管的是「为什么鸣」，康复管的是「怎么听得见」，两件事都要做。

## 六、代价与边界

- **「肾虚」不是耳鸣的默认解释。** 默认解释的代价是漏诊：突发性聋、听神经瘤、耳硬化、噪声性聋、药物性耳聋，都可能以「耳鸣」进门。凡单侧、进行性、伴眩晕或伴神经症状者，先做听力学与影像评估。
- **不把「肾开窍于耳」当解剖通路。** 它讲的是精气灌注的关系，不是神经走向。用现代解剖去证它「对」，或用它去否定解剖，都是错位。
- **暴聋不给时限数字。** 处置窗口按现行规范与专科判断，教材里写死小时数，就成了过期参数。能写的是：属急症，越早转诊越好。
- **补益之品有代价。** 滋腻碍脾，久服纳减腹胀；矿物类重镇药须遵规范，不可自行久服。虚证也要定期复评，不能一张方守一年。
- **情志与睡眠要进辨证。** 耳鸣与失眠、焦虑互相加重，这是临床事实。只治耳不治神，效果常停在半路；只治神不辨虚实，也难持久。
