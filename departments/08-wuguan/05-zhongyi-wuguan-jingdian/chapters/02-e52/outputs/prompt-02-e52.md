# 五轮回答的是「病在哪一轮」，不是「病因为何」 · 提示词

## 用途

给「五轮回答的是「病在哪一轮」，不是「病因为何」」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「原文只说到「精」，还没说到「轮」 → 定位的逻辑：轮位给的是「先看哪里」 → 八廓：知道它为什么存在，也知道为什么不必用它 → 经络：三条主线，一条环路」这条链。
