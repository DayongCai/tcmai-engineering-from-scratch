# 病名是「当时看得见的东西」的名字，改名时丢的是判据 · 提示词

## 用途

给「病名是「当时看得见的东西」的名字，改名时丢的是判据」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三个断代：候、证、症 → 一名多病：一个名字底下藏着几种病 → 一病多名：同一种病在不同书里有几个名字 → 名变则判据变：三次转移」这条链。

## 提示词

```
我在学《中医五官科经典选读》第 5 章「病名是「当时看得见的东西」的名字，改名时丢的是判据」，本章 7 节 / 2,985 汉字，习题 7 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 隋代以「候」为纲
   - 宋元以「证」统方
   - 明清以「症」为目
   - 聤耳、脓耳、耳疳、耳底
   - 喉风三十六症
   - 白缠喉、白喉
4. 本章自陈的边界（不得越过）：
   - **不拿今病名回填古籍。** 「《审视瑶函》治过敏性结膜炎」这类说法，是把现代分类塞进古书。可以说「该书所论某症，其判据与今之某类病部分重合」，不能说「该书已认识某病」。
   - **不因名同而用方。** 名同而判据不同，用方就是碰运气。用方之前先核三条：病位、形态、病程，与古书所记是否对得上。
   - **断代数字要留余地。** 千七百余候、七十二证、三十六症，都是通行统计，不同版本与不同计法会有出入。引的时候标明「通行统计」，比给一个精确数字更诚实。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，不构成医学意见、诊断或治疗指导。所论病名对应关系仅为文献与教学对照，不用于临床诊断；具体操作以现行规范与所在机构制度为准。
