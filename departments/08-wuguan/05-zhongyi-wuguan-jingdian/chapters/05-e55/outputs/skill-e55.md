# 病名是「当时看得见的东西」的名字，改名时丢的是判据

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 隋代以「候」为纲
- 宋元以「证」统方
- 明清以「症」为目
- 聤耳、脓耳、耳疳、耳底
- 喉风三十六症
- 白缠喉、白喉

## 边界

- **不拿今病名回填古籍。** 「《审视瑶函》治过敏性结膜炎」这类说法，是把现代分类塞进古书。可以说「该书所论某症，其判据与今之某类病部分重合」，不能说「该书已认识某病」。
- **不因名同而用方。** 名同而判据不同，用方就是碰运气。用方之前先核三条：病位、形态、病程，与古书所记是否对得上。
- **断代数字要留余地。** 千七百余候、七十二证、三十六症，都是通行统计，不同版本与不同计法会有出入。引的时候标明「通行统计」，比给一个精确数字更诚实。
- 本章为教学材料，不构成医学意见、诊断或治疗指导。所论病名对应关系仅为文献与教学对照，不用于临床诊断。
