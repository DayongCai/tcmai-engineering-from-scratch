# 咽喉病的病因病机：火在末梢，水在源头 · 提示词

## 用途

给「咽喉病的病因病机：火在末梢，水在源头」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三层因：每一层回答一个不同的问题 → 外因四条路：风寒、风热、燥、疫毒 → 内因四条：热、虚、痰瘀、郁 → 病机三字：壅、损、结」这条链。

## 边界

本章为教学材料，不构成诊断或治疗建议。文中病因分类、病机表述与所举方名，只用于建立判断框架；具体操作以现行规范与所在机构制度为准。
