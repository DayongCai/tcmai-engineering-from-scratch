# wulun-bakuo

## 何时使用

- 眼科门诊记录需要把体征结构化到五轮
- 教学：演示「白睛属肺」这类配属的边界
- 知识库校对：检查已有规则的出处与争议标记是否齐全

## 不适用

- 下证型结论或开方（本技能只做归轮）
- 八廓的单值判定（历代配属不一，不给单值）
- 急症：视力骤降、剧痛、外伤、化学伤（立即转急诊）

## 步骤

1. **摘体征**：逐字取自原文，标明部位。
2. **查五轮**：胞睑肉轮脾 / 两眦血轮心 / 白睛气轮肺 / 黑睛风轮肝 / 瞳神水轮肾。
3. **处理跨区**：命中两个部位 → 输出两候选 + 提示。
4. **标出处**：每条给《书名·篇名》；涉及八廓写「须指明版本」。
5. **列缺口**：原文未描述的部位，逐一列出。

## 输出模板

```text
【体征 → 轮位 → 脏腑】<体征> → <轮> → <脏>（出处：…）
【跨区提示】…
【缺口】未描述：…
【边界】仅归轮，不含证型/治法；急症转诊优先。
```

## 质量判据

- 每条映射都有出处
- 跨区体征不止一个候选
- 输出里没有证型、治法、方药

> 本技能输出为教学与结构化辅助，不构成诊断依据。
