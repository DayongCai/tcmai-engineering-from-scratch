# 证名是结论，不是起点 · 提示词

## 用途

给「证名是结论，不是起点」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「第一步：定病位 → 第二步：定病性 → 第三步：归脏腑 → 第四步：落记录」这条链。

## 提示词

```
我在学《口腔内科学》第 4 章「证名是结论，不是起点」，本章 7 节 / 3,323 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 把「牙痛」这个主诉拆开
   - 痛在齿，还是在龈，还是在这两者之外？
   - 当下主要是邪盛，还是正虚？
   - 先辨虚实，再辨何邪
   - 兼夹不必求全，但不可漏湿
   - 其一，多脏并见是常态
4. 本章自陈的边界（不得越过）：
   - **三要素命名不如四字证型顺口，这是取舍。** 「病位＋病性＋脏腑」的组合便于统计（三要素可编码），也不失个体差异；代价是证名较长。若三步之后仍不能归一，宁肯写「病位在龈，病性属湿热夹虚，脏腑涉胃与脾，未定」，也不要硬套一个漂亮的证名。
   - **虚实二分不够用。** 口齿科最常见的兼夹是湿与瘀，二者都不在虚实两极之内。但虚实仍是第一刀，因为攻补的大方向由它决定；湿与瘀是在这个方向之内的调整，次序不能倒。
   - **脉诊不可废，也不可神化。** 删掉脉，虚实难辨时就少最后一票；夸大脉，则把一个可复核的字段变成不可复核的权威。折中的写法是记录里写清「诊了没有」。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，不构成诊断或治疗建议。文中的辨证路径、字段表与病名对照只用于说明思路，不构成诊疗规范；具体操作以现行规范与所在机构制度为准。
