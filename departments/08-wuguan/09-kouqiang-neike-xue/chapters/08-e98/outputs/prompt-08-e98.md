# 黏膜病先分三层，再谈病名 · 提示词

## 用途

给「黏膜病先分三层，再谈病名」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三个落点：菌层、上皮、上皮下 → 「擦得掉吗」：三个动作 → 三问：哪一层、能不能自限、有没有硬结 → 火有虚实：口疮不都是实火」这条链。

## 提示词

```
我在学《口腔内科学》第 8 章「黏膜病先分三层，再谈病名」，本章 5 节 / 3,604 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - （附着在表面、可以擦掉）、
   - （角化增厚或萎缩，擦不掉）、
   - 别人也能重复的判据
   - 最容易误判的那一个
   - 口疮不都是实火
   - 「白屑可以擦掉」
4. 本章自陈的边界（不得越过）：
   - **分三层能定方向，不能定诊断。** 三个动作把「菌层／上皮／上皮下」分开，但扁平苔藓与白斑的最终性质、异型增生的有无，靠病理。本章只写「什么时候该转」，取哪一块、送什么染色，由黏膜科与病理科定。把「会看」当成「会治」，是这一章最想挡的错觉。
   - **丢了全身背景，是这套分层的固有代价。** 复发性口疮与免疫状态、营养（维生素 B12、叶酸、铁）、内分泌周期、睡眠与压力、消化道疾病都有关联；念珠菌病几乎总有一个诱因——长期用抗菌药或吸入性糖皮质激素、血糖控制不佳、口干、戴义齿、免疫抑制。局部处理反复无效时，最该做的是回头查一遍用药清单与血糖，而不是再加一种含漱液。
   - **顽固定型病例属专科处理，本章不写药名组合。** 重型、频繁复发的口疮，专科会用糖皮质激素、免疫调节剂一类；这类药收益与风险都大，教材给一个模糊的「可用」，落到学生手里就会变成一个具体处方。本章只写「属专科处理」，不给剂量与疗程，也不承诺「根治不复发」。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，不构成医学意见、诊断或治疗建议。黏膜病的确诊依赖视诊、必要的实验室检查与病理；具体操作以现行规范与所在机构制度为准。
