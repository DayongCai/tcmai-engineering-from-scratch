# 口气与口干都要先定位，再谈清热与滋阴 · 提示词

## 用途

给「口气与口干都要先定位，再谈清热与滋阴」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「口气四层 → 时相比气味更有信息 → 口干三路：先把药数清 → 四个自查与一条下游链」这条链。

## 边界

本章为教学材料，不构成医学意见、诊断或治疗建议。持续口臭、进行性口干、单侧腺体肿大或伴全身症状者，须由具备资质的人员检查；具体操作以现行规范与所在机构制度为准。
