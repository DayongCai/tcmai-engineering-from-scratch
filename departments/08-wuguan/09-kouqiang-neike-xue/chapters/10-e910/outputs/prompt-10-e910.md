# 「认真刷牙」不是一个方案 · 提示词

## 用途

给「「认真刷牙」不是一个方案」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「四件事：菌斑、氟、糖、唾液 → 方案必须写四栏 → 三个数字与两条最易省的嘱咐 → 古人三件事的位置」这条链。

## 提示词


## 边界

本章为教学材料，不构成医学意见、诊断或护理指导。刷牙、含氟产品、洁治与特殊人群的口腔护理方案，须由具备资质的人员依现行规范、临床路径与所在机构制度决定。本章给出的量、频次与合格标准用于教学示范，不构成个体化处方；具体操作以现行规范与所在机构制度为准。
