# 适应证不是一个名单，是三级可预测性 · 提示词

## 用途

给「适应证不是一个名单，是三级可预测性」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「名单式适应证为什么必然失效 → 第一道门在隐形之前：能不能接受正畸治疗 → 三级可预测性：判据是「能不能精确实现模拟目标」 → 分级怎么用：它同时决定三件事」这条链。

## 边界

本章为口腔正畸教学材料，只解释适应证分级结构与判据，不写具体矫治方案、附件设计与矫治力值，也不对任何具体病例定级；具体操作以现行规范与所在机构制度为准。
