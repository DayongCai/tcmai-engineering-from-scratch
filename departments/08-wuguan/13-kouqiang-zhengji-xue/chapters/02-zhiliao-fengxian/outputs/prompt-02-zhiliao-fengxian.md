# 疗效的一半握在患者手里，医师只能设计另一半 · 提示词

## 用途

给「疗效的一半握在患者手里，医师只能设计另一半」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「四条风险里，三条不在诊室里发生 → 依从性不是态度问题，是设计问题 → 脱轨不是意外，是系统性偏差 → 并发症与制度风险：一张熟悉的清单，一套不同的触发点」这条链。

## 边界

本章为口腔正畸教学材料，只讨论风险结构与观察要点，不写具体矫治方案、附件设计与矫治力值，也不给佩戴时长与复诊间隔；具体操作以现行规范与所在机构制度为准。
