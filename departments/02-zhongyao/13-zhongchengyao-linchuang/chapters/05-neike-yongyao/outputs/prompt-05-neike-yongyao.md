# 选药的入口是证候，不是药名里的那两个字 · 提示词

## 用途

给「选药的入口是证候，不是药名里的那两个字」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「功效与主治是一条单向链 → 四气五味：把寒热读成方向 → 清与下：两个最容易走反的方向 → 配伍已经写死在处方里」这条链。

## 边界

本章为中成药与临床用药课程的教学材料，只讨论按证候选药的方法与药性判据，不构成诊断、处方或用药建议，也不提供任何品种的用法用量。中成药的使用须由执业中医师在四诊合参、辨证明确之后决定；具体操作以现行规范与所在机构制度为准。
