# 人群一变，剂量、疗程、禁忌三样一起变 · 提示词

## 用途

给「人群一变，剂量、疗程、禁忌三样一起变」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「妊娠禁忌：禁用与慎用的依据不同 → 活血调经：一个「瘀」字下的寒热虚实 → 收涩：用错的代价是闭门留寇 → 小儿不是缩小版的成人」这条链。

## 边界

本章为中成药与临床用药课程的教学材料，只讨论妇科与儿科用药的人群判据，不构成诊断、处方或用药建议，也不提供任何品种的剂量与疗程。妊娠期、哺乳期、儿童与老年患者的用药，必须由执业医师在明确诊断后决定；具体操作以现行规范与所在机构制度为准。
