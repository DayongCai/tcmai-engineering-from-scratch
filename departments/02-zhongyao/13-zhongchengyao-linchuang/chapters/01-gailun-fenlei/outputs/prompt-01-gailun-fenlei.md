# 剂型是把用法固定在药里的那一步 · 提示词

## 用途

给「剂型是把用法固定在药里的那一步」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三个固定：成药与汤剂的分界 → 四条分类轴，各答一个问题 → 散剂与片剂：两个极端样本 → 把剂型选择写成一条链」这条链。

```
我在学《中成药与临床用药》第 1 章「剂型是把用法固定在药里的那一步」，本章 5 节 / 2,763 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 汤剂的风险在医师笔下，成药的风险在选用与疗程上
   - 剂型是形式，制剂是品种
   - 同一味药做成溶液、混悬、固体，起效时间是三个量级
   - 制法轴是唯一一条直接连到生产与检验的轴
   - 要看一个成药「快不快」，看它的分散状态；要看它「准不准」，看它的成型与检验

4. 本章自陈的边界（不得越过）：
   - **本章的数字是结构数，不是疗效数。** 5 个单元、四条分类轴、两个样本剂型，都是编排与分类的计数；本章不给任何有效率、治愈率或血药浓度数据——这类数据不在单元层里，也不该由教学材料代拟。

   - **剂型优劣是相对的。** 散剂快但难贮，片剂准但需辅料，丸剂缓但占体积。没有「最好的剂型」，只有对这个证、这个人、这个场景最合适的剂型。
```

## 边界

本章为中成药与临床用药课程的教学材料，只讨论剂型分类与选择的判断框架，不构成诊断、处方或用药建议，也不提供任何品种的用法用量。实际用药须以药品说明书、现行《中国药典》与执业医师、药师的意见为准；具体操作以现行规范与所在机构制度为准。
