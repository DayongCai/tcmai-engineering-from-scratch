# 不良反应与监测 · 提示词

## 用途

给「不良反应与监测」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「中成药概论与分类 → 剂型与制备工艺 → 质量标准与检验 → 中药注射剂与特殊剂型 → 内科常用中成药 → 妇科与儿科用药 → 骨伤与皮肤科用药 → 联合用药与相互作用 → 不良反应与监测 → 合理使用与处方审核」这条链。

## 提示词

```
我在学《中成药与临床用药》第 9 章「不良反应与监测」，本章 9 单元 / 1,290 汉字，
取自教材第 派生#9 章。

请按以下顺序带我走：
1. 先给本章要回答的问题，并说明它为什么不能直接套用上一章；
2. 再给三辨（剂型与工艺／质量与标准／临床与安全）在本章的实测分布，指出主导那一辨；
3. 然后按单元逐条读出「判据」——每条只写类别与要点，不给操作参数；
4. 最后给出三条边界：哪些内容只能写到类别、哪些必须由具备资质的人员作出、哪些情况按父课教材与《中国药典》相关项报告。

要求：不编造教材没有的数字；引文写到《书名·篇名》级并标注是否本章原文篇名；
不确定的地方直接说「教材未展开」。
```

## 边界

本提示词用于教学准备，不构成诊疗或护理意见；具体操作以现行规范与所在机构制度为准。
