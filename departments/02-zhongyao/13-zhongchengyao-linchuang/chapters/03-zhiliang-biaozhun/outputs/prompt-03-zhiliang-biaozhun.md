# 标准不替好药背书，它只替不合格的药划线 · 提示词

## 用途

给「标准不替好药背书，它只替不合格的药划线」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「四段式：每一段回答一个不同的问题 → 点与面：含量测定与指纹图谱 → 鉴别：专属性的代价 → 稳定性：把「有效期」做成一次实验」这条链。

## 边界

本章为中成药与临床用药课程的教学材料，只讨论质量标准与检验的方法学逻辑，不构成诊断、处方或用药建议，也不提供任何品种的限度值与用法用量。实际检验与判定须以现行《中国药典》、品种标准与药品检验机构的方法为准；具体操作以现行规范与所在机构制度为准。
