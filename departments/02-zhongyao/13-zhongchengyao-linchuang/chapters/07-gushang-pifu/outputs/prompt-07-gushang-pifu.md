# 外用不是内服的降级版，它换了一条吸收路径 · 提示词

## 用途

给「外用不是内服的降级版，它换了一条吸收路径」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「外治之理同，但计量单位换了 → 拔毒与生肌：一个疮面的两个阶段 → 矿物药与虫类药：毒性与疗效同源 → 途径决定剂型，剂型决定时间」这条链。

## 边界

本章为中成药与临床用药课程的教学材料，只讨论外用制剂的判据、阶段与途径，不构成诊断、处方或用药建议，也不提供任何品种的浓度、剂量与疗程。疮疡、湿疹、癣疾与骨伤的处理须由执业医师在查看病灶后决定；具体操作以现行规范与所在机构制度为准。
