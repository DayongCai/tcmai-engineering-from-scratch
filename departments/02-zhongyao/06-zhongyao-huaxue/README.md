## 一、学科定位

中药化学（Phytochemistry of TCM）是中药系的核心学科，聚焦「本草、方剂与中药全产业链：资源—鉴定—化学—药理—制剂」中的一个完整知识域。

## 二、中医 → AI 桥梁

```text
成分结构→分子指纹 / 活性预测→QSAR 回归
```

中药化学 里的每一个传统概念，都被翻译成一个可计算、可验证的工程对象：
中医概念给出**语义与约束**，AI/工程方法给出**表示与算法**。两者必须能互相回指，
否则这个章节就还没有写完。

**口径**

1. **三辨＝结构特征／理化性质／提分与检识**：教材每类化合物都按这条链写（结构决定性质，性质决定方法），不另造分类；
2. **四位数取生源途径**（乙酸-丙二酸 742 / 莽草酸 757 / 甲戊二羟酸 1656 / 氨基酸 542，比值 **3.1×**），这是教材分类的底层依据；
3. **三辨在全库极平（1.5×）**：结构 3105、性质 2104、方法 2791——教材对「长什么样」「什么性质」「怎么拿到」写得一样重；
4. **横切章（1、2、10、11、12）的生源词频只是背景**，不作类别判断依据，正文逐章写明。

**引文口径**：中药化学是现代学科，正文只引书名（《中国药典》《神农本草经》等），无篇名级引文。
凡门要求《书名·篇名》级者，统一按**真实分卷**补足并就地注明：
《中国药典·一部》（中药品种与标准）、《中国药典·四部》（方法学通则与指导原则）、《神农本草经·序录》——
**补足一律标「非本章原文篇名」，不冒充教材原文**。
