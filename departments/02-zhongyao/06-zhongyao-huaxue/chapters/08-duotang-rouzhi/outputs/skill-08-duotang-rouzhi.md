# 多糖与鞣质：分子量一过大，显色反应就换了主人

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；

4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 还原性只看一件事：分子里还有没有游离的半缩醛羟基
- （所以「甜」不能判糖）、
- （斐林阴性，这是与低聚糖的分界）、
- 溶于水或稀碱成胶体
- 问「这个多糖纯不纯」，标准答案是「分子量分布多宽」，不是「熔点多少」
- 完全酸水解 + 色谱

## 边界

- **Molisch 阳性只说「有糖」，不说「是什么糖」。** 单糖、寡糖、多糖、糖苷、糖蛋白全部阳性；要定组成，必须水解后做色谱或 GC。
- **比色法测的是总糖。** 苯酚-硫酸法把游离糖、寡糖一并计入，多糖含量偏高是常态；含量数字必须与分子量分布、单糖组成同看。
- **醇沉不是万能的。** 醇浓度、加醇速度、温度、共存蛋白与果胶都影响分离效果；「沉出来了」不等于「分干净了」。
