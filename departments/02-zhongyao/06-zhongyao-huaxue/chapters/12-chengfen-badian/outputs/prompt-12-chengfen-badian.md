# 网络图上的「核心靶点」是算出来的假说 · 提示词

## 用途

给「网络图上的「核心靶点」是算出来的假说」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「五步流水线：每一步的输入与它的失效点 → 假阳性从哪里来：三个来源 → CADD 的三件工具，与打分函数的硬边界 → 要多少实验才算数」这条链。

```

3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
```

## 边界

本章为中药化学教学材料，内容取自教材《中药化学》第 12 章与 `standards/zhongyao-huaxue` 的机器可读层。**本章不构成靶点结论、功效结论或新药研发方案，也不构成用药建议。** 网络药理学与分子对接的结果属计算假说，须经体外、体内实验验证方可采信；具体操作以现行规范与所在机构制度为准。
