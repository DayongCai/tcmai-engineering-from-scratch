# 含量测定的数字，先由方法定义，再由样品证明 · 提示词

## 用途

给「含量测定的数字，先由方法定义，再由样品证明」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「先把「含量」定义清楚 → 前处理决定数字的上限 → 色谱条件是可复现的前提 → 方法学验证：八项指标各自防一种错」这条链。

## 提示词

```
我在学《中药化学》第 11 章「含量测定的数字，先由方法定义，再由样品证明」，本章 6 节 / 3,919 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 测的是哪个成分
   - 「以某某计」是一句换算声明，不是成分清单
   - 用什么做基准
   - 归一化法的前提是「全部成分都被检出」，而这个前提在中药提取物上几乎不成立
   - 对照品是什么级别
   - 限度是多少、判合格还是判优劣
4. 本章自陈的边界（不得越过）：
   - **方法学验证保证的是「这个方法在这个范围内可信」，不是「这个成分是有效的」。** 两件事分属分析化学与药理学，不能互推。含量做得再准，指标选错了，结论仍然是错的。
   - **限度不是最优值。** 「符合规定」只说明落在可接受区间内。同一品种含量相差数倍而都判合格，是常态而非漏洞。
   - **口径不可混用。** 以某某计、外标与内标、归一化与对照品法、皮粉法与总酚法，四组口径任意混用都会产出不可比的数字。**读文献里的百分比，先找方法学那一段。**

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为中药化学教学材料，内容取自教材《中药化学》第 2、11 章与 `standards/zhongyao-huaxue` 的机器可读层。**本章不构成检验操作规程，不构成质量标准或含量限度，也不构成用药建议。** 文中的方法学项目与接受标准为教学归纳，实际执行须以现行《中国药典》通则及各品种项下规定为准；具体操作以现行规范与所在机构制度为准。
