# 解表药考的是一句话：这个热在表还是在里 · 提示词

## 用途

给「解表药考的是一句话：这个热在表还是在里」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「表证的判据，以及「汗而发之」的四个前提 → 辛温与辛凉：一条以寒热为轴的分类 → 同类的分化：麻黄与桂枝，薄荷与桑叶菊花 → 六条配伍与发汗法度」这条链。
