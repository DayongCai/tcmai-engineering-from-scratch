# 解表药考的是一句话：这个热在表还是在里

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 无汗或汗出不畅
- 以遍身微汗为度
- 麻黄与桂枝
- 薄荷、牛蒡子、蝉蜕
- 桑叶与菊花
- 柴胡与升麻

## 边界

- **表证的判据是症状组合，不是单一指标。** 恶寒与发热的轻重对比靠病人自述，脉象靠指下感觉，两者都有主观性。教材给的是一组项目，不是一个阈值；项目齐了能判，缺项时只能记为不确定。
- **「表热」与「里热」的边界会移动。** 温病卫分证与气分证之间没有硬边界，邪由表入里的过程中，解表与清热的配比只能凭证候变化调整。教材用「渐入」「未罢」这类词，正说明它是一条渐变带。
- **同类分化靠兼长，兼长即兼短。** 牛蒡子滑肠、麻黄升压、桂枝助热，这些短处在教材里写在「使用注意」项下，不在功效项下。只读功效不读注意，选药就会选中短处。
- 本章为临床中药学的解表药教学，所列方名、药名与用法为教材转述，不构成诊疗建议。
