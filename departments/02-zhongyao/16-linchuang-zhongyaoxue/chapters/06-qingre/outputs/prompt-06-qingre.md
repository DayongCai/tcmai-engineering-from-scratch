# 清热药分五类，分的不是五种热而是五个位置 · 提示词

## 用途

给「清热药分五类，分的不是五种热而是五个位置」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「五个位置，五组可观察的判据 → 苦寒是一条共用的边界，不是五条 → 配伍：药量比例决定性质 → 现代研究能说什么，不能说什么」这条链。

## 边界

本章为临床中药学的清热药教学，所列剂量区间引自教材与《中国药典》的教学转述，不构成用药建议；具体操作以现行规范与所在机构制度为准。
