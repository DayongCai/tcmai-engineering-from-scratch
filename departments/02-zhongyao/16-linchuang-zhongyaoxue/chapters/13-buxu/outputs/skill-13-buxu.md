# 补虚药最容易用错：补有方向，补更有时机

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；

## 核心判据

- 补药不是保健品
- 何首乌必须监测肝功能
- 甘草的「调和」不等于安全
- 本章不给剂量
- 肿瘤与慢病患者不要自行「进补」
- 本章不涉及方剂学与膏方制作

## 边界

- **补药不是保健品。** 人参、黄芪、枸杞、阿胶被大量做成日常食品与礼盒，而它们的定位是治疗量级下的药物。无虚而补，轻则上火、腹胀、失眠，重则助邪、升高血压、加重代谢负担。
- **何首乌必须监测肝功能。** 无论生制，长期或大剂量使用都有肝损伤风险；出现乏力、食欲减退、尿黄、皮肤黄染，须立即停药并查肝功能。
- **甘草的「调和」不等于安全。** 长期大量服用可致水肿、高血压、低血钾；高血压、心脏病、肾功能不全者与正在使用利尿剂、糖皮质激素者尤须注意。
- 本章为临床中药学的补虚药教学，所列功效、配伍与禁忌引自教材与《中国药典》的教学转述，不含具体剂量，不构成用药建议。人参、甘草、何首乌、鹿茸等涉及十八反、水钠潴留、肝损伤与温燥伤阴的风险，须由执业医师与药师审核。
