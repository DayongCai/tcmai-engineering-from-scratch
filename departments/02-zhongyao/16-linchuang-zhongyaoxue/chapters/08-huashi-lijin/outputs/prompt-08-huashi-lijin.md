# 湿与水的分界不在病名，而在小便通不通、肿不肿 · 提示词

## 用途

给「湿与水的分界不在病名，而在小便通不通、肿不肿」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「化湿：把弥散的湿散开，判据在中焦 → 利水：把聚集的水导出去，判据在下焦 → 两条通道的交汇点：脾 → 这一类药最容易「越用越虚」」这条链。

## 边界

本章为临床中药学的化湿药与利水渗湿药教学，所列剂量、煎法与品种说明引自教材与《中国药典》的教学转述，不构成用药建议。含马兜铃酸的药材已禁止药用，购药与处方须认准法定品种；具体操作以现行规范与所在机构制度为准。
