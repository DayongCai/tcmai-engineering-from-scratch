# 临床中药学不是中药学的缩写，而是换了一道题

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 3 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 定义不产生疗效判断
- 历史叙述必然取舍
- 术语纪律会牺牲表达效率

## 边界

- **定义不产生疗效判断。** 三层实物的划分能告诉你「这是饮片还是成药」，不能告诉你「这个证该不该用」。定义是坐标，不是方法；把坐标当方法，最常见的结果是处方写得规范而辨证是空的。
- **历史叙述必然取舍。** 教材 1.2.1 用 3,439 字走完两千年，被略去的恰恰是失败的经验与存疑的记载。读史得到的是一条被整理过的成功路径，容易高估古人的一致性。凡涉及具体数值（载药数、成书年代），教材多处标注「转述，据某某研究」，这个标注本身就是证据等级的提示，不宜当成定论引用。
- **术语纪律会牺牲表达效率。** 不许把功效写成适应症，意味着很多现代读者熟悉的说法不能用。代价是叙述变慢，收益是结论不会被悄悄放大——「清热解毒」不能被读成「抗感染」，这条底线只有靠术语纪律守住。
- 本章为临床中药学的概念与学科边界教学，所列数字均由仓库内单元层现算，不构成诊疗建议，也不能替代执业医师的辨证论治与药师的审方。
