# 临床中药学不是中药学的缩写，而是换了一道题 · 提示词

## 用途

给「临床中药学不是中药学的缩写，而是换了一道题」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「先分三层实物，再谈一味药的功效 → 「本草」与「中药」：一次术语更替，两种使用场合 → 中药与天然药物的界线：青蒿与青蒿素 → 课程边界：四门相邻学科各管一段」这条链。

## 提示词

```
我在学《临床中药学》第 1 章「临床中药学不是中药学的缩写，而是换了一道题」，本章 5 节 / 3,184 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 定义不产生疗效判断
   - 历史叙述必然取舍
   - 术语纪律会牺牲表达效率
4. 本章自陈的边界（不得越过）：
   - **定义不产生疗效判断。** 三层实物的划分能告诉你「这是饮片还是成药」，不能告诉你「这个证该不该用」。定义是坐标，不是方法；把坐标当方法，最常见的结果是处方写得规范而辨证是空的。
   - **历史叙述必然取舍。** 教材 1.2.1 用 3,439 字走完两千年，被略去的恰恰是失败的经验与存疑的记载。读史得到的是一条被整理过的成功路径，容易高估古人的一致性。凡涉及具体数值（载药数、成书年代），教材多处标注「转述，据某某研究」，这个标注本身就是证据等级的提示，不宜当成定论引用。
   - **术语纪律会牺牲表达效率。** 不许把功效写成适应症，意味着很多现代读者熟悉的说法不能用。代价是叙述变慢，收益是结论不会被悄悄放大——「清热解毒」不能被读成「抗感染」，这条底线只有靠术语纪律守住。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为临床中药学的概念与学科边界教学，所列数字均由仓库内单元层现算，不构成诊疗建议，也不能替代执业医师的辨证论治与药师的审方；具体操作以现行规范与所在机构制度为准。
