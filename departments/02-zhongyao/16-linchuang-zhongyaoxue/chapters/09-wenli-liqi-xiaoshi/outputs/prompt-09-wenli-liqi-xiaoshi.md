# 温、行、消三法并立，是因为中焦的寒、滞、积常同时到场 · 提示词

## 用途

给「温、行、消三法并立，是因为中焦的寒、滞、积常同时到场」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三法各治一种「不通」，力度却不在一个量级 → 温里：寒在哪个脏腑，就选哪一味 → 理气：四端与「破气」的分寸 → 消食：积从哪来，决定用哪一味」这条链。
