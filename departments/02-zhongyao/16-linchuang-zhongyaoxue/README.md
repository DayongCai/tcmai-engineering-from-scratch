## 一、学科定位

临床中药学（Clinical Chinese Materia Medica）是中药系的核心学科，聚焦「本草、方剂与中药全产业链：资源—鉴定—化学—药理—制剂」中的一个完整知识域。

## 二、中医 → AI 桥梁

```text
证—药对应→关联规则 / 配伍禁忌→约束求解
```

临床中药学 里的每一个传统概念，都被翻译成一个可计算、可验证的工程对象：
中医概念给出**语义与约束**，AI/工程方法给出**表示与算法**。两者必须能互相回指，
否则这个章节就还没有写完。

**口径**

1. **三辨＝性能与功效／临床应用／用法与禁忌**，实测 **2989 / 6434 / 3640**，比值 **2.2×**——**临床应用是性能的 2.2 倍**，这一门确实以「治什么、和谁配」为主轴；
2. **四位面取病位系统**（肺系 3585 / 脾胃 4975 / 心肝 7806 / 肾与杂证 4243，**2.2×**）。它与临床「辨证选药」的落点一致；
3. **药类四分 3.7× 未取**：它其实是教材章名的复述（解表清热/泻下祛湿…），与章节结构循环；**内容层次 2.5× 未取**：药类编排、临床环节、基础理论三者不是同一层的东西。

**跨课对账（与《中药学》）——一个否定结果**

- **药名覆盖**：287 味药名，本课提及 **283**（**0.986**），未提及 4 味（南瓜子、珍珠母、贯众、首乌藤），属各论长尾；
- **讲法侧重**：用同一组词量两套语料，**本课的性能词密度反而高 ×1.35、临床词 ×0.92、安全词 ×0.63** —— 与「临床课更重临床」的直觉不符；
- **原因写在正文**：颗粒度差 31 倍（141 vs 4369 字/单元），词表是粗代理。**这一层对账没量出预期差异，故不作结论**。
