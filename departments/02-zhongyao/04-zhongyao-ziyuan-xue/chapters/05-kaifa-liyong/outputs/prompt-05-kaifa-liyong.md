# 开发不是把药材换成产品，而是把年允收量换算成产品线的上限 · 提示词

## 用途

给「开发不是把药材换成产品，而是把年允收量换算成产品线的上限」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「可持续利用是一句可算的话，不是一句口号 → 综合利用提高的是效率，不是总量 → 传统产品深度开发的三条路，各有各的证据要求 → 新资源是增量，但增量必须先量资源量」这条链。

## 边界

本章为教学整理，不构成产品开发、注册申报或产业投资建议；具体操作以现行规范与所在机构制度为准。
