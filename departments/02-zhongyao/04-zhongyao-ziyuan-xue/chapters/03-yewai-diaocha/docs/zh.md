# 第 3 章 · 蕴藏量不是一个数，而是一条由四步误差叠出来的区间

> **MOTTO:** 「不登高山，不知天之高也；不临深溪，不知地之厚也。」——《荀子·劝学》
>
> **PROBLEM:** 教材第 3 章 5 个单元讲调查方法（12,477 汉字），第 5 章 4 个单元讲生态学基础（11,724 汉字），合计 9 单元 24,201 汉字。两处都给了蕴藏量的算法，却没给这个算法能承受多大误差：四步相乘，每步各差两成，最后的区间就跨到五倍以上。既然报「五倍」也算结论，那么调查的价值就不在算出那个数，而在说清这个区间是被哪几步撑开的。

**双根因定位:** 环境逼迫（药用植物散生在异质山地，一处可采、三处不可采，任何一处实测都只能代表它自己，而资源管理要的偏偏是全域总量） + 知识积累（蕴藏量测算的公式来自林业与草原的抽样清查，移植到药材上时多了「药用部位比例」与「折干率」两个本不属于林学的环节，误差因此又多了一级）

**教材出处:** 教材第 3 章 3.1.1–3.2.2（调查类型、样方法、访问与遥感、调查内容、成果与档案）与第 5 章 5.1.1–5.2.2（群落、演替、光温水与土壤因子）；单元层 `standards/zhongyao-ziyuan/units.json`。

## 一、四步相乘：误差是被乘出来的，不是被加出来的

教材给出的关系极简：蕴藏量 ＝ 单位面积蕴藏量 × 分布面积，而单位面积蕴藏量 ＝ 样方平均产量 ÷ 样方面积。写成一个式子就是四步：

| 步骤 | 这一步要回答的问题 | 常见取法 | 系统性偏差的方向 |
|---|---|---|---|
| S1 样方面积 | 一个样方代表多大地面 | 草本 1 m×1 m，灌木 2 m×2 m 或 4 m×4 m，乔木 10 m×10 m 或 20 m×20 m | 样方偏小则把小丛误当大丛，偏大则把空地摊进产量 |
| S2 样方均值 | 若干样方的平均产量是多少 | 各样方实测产量的算术平均 | 只取「长得好」的地段，均值必然偏高 |
| S3 药用部位比例 | 一株里有多少是入药部分 | 挖取部分植株称鲜重，干燥后称干重 | 省略折干率，鲜重当干重，虚高数倍 |
| S4 分布面积 | 该种在调查区内占多大面积 | 植被图、遥感判读、踏查勾绘 | 把「有记录」当「有分布」，面积虚增 |

**这四步是乘法关系，误差因此是乘性的。** 若每一步都在真值上下浮动两成（0.8 至 1.2 倍），四次相乘得到 0.41 至 2.07 倍，最高与最低相差 5.1 倍；若每步浮动三成，区间变成 0.24 至 2.86 倍，相差 11.9 倍。**（演算设定，非实测：浮动幅度是为了说明乘性误差的量级，不代表任何品种的真实误差。）**

这个算术结论比任何单一品种的数字都重要：**只要四步各自不确定，最后那个数就不可能精确，只能以区间形式呈现。** 教材要求统计时「计算误差范围，客观说明数据的可靠程度」，说的正是这件事。凡是把蕴藏量报成一个精确到个位的千克数、却不附误差与参数的报告，读者无法判断它是实测还是拍的。

反过来，这个式子也给了改进的次序：**先把乘数最少的环节钉死。** 分布面积一项往往偏差最大（S4 常在数倍量级），而它恰恰最容易被一句「以遥感判读为准」带过。所以一份合格的调查方案，应当先写清面积的来源与判读精度，再谈样方。

## 二、样方怎么设：三原则与四种布设方式

样方法的前提是抽样推断——用少量样方的实测代表总体。教材列了四种布设方式，各自的失效方式互不相同：

- **典型选择法**：凭经验挑「有代表性」的地段。省事、针对性强，但代表性由调查者自己担保，两个人可能挑出两块完全不同的地。
- **随机取样法**：抽签或随机数定位置。免除了主观倾向，却可能把样方落进裸岩、道路或农地，代表性反而更差。
- **系统取样法**：按固定间隔布点。分布均匀、便于复算，但间隔若与资源本身的斑块尺度重合（例如沿等高线每 50 m 一点，而药带正好 50 m 一条），会系统性地采到或采不到。
- **分层取样法**：先按植被类型、海拔、坡向、土壤分层，再在各层内布点。它把「代表性」交给分层依据，把「均匀性」交给层内布点，是目前资源调查较常用的方式——代价是分层依据本身必须先被证明与资源分布相关。

三种布设原则要同时守住：**代表性**（布在能代表该类植被与资源总体状况的地段，避开火烧迹地、新采伐地、路边、村舍旁）、**随机性**（位置不由调查者的偏好决定）、**重复性**（同一生境类型设多个样方，不以个别样方代替总体）。三者互相拉扯：越随机越可能不典型，越典型越可能不随机，分层取样就是在这个张力里找平衡。

地形复杂时，方形样方会跨群落边界。教材因此补充了样带法与样线法：沿海拔或水分梯度设长条样带，逐段统计；或沿直线设样线，记录与样线相交的个体。**样带的价值在于「把梯度变成可读的序列」**——垂直带被压进平面图时最容易失真，而样带正好把它重新展开。

还有一条常被忽略：**固定样方**。样方一经设置就统一编号、记录地理位置与设置时间，必要时立固定标志。一次调查只是快照，资源是增是减只能靠同一批样方前后对比才知道；不复位的调查，两次数据之间没有可比性。

## 三、记录：让下一个人能复核

样方调查的内容分两块：群落特征（植被类型、层次结构、优势种与伴生种、总盖度与分层盖度、郁闭度、平均高度）与资源数量（株数或丛数、多度、频度、盖度，以及株高、基径、冠幅等生长性状）。两块都要落到同一张表上，否则「产量高」无法归因到「群落合适」还是「样方选得好」。

最小字段集如下，少一项这个样方就不能进汇总：

| 字段 | 要求 |
|---|---|
| 样方编号 | 与固定标志、照片、标本三者同号 |
| 位置与生境 | 省、市、县、乡、村及小地名；经纬度、海拔；坡向、坡度、坡位 |
| 样方面积与形状 | 实测值，注明方形、长方形或带状 |
| 群落特征 | 植被类型、优势种、总盖度、分层盖度、郁闭度 |
| 物种记录 | 中文名＋拉丁学名＋地方名，凭证标本编号 |
| 数量指标 | 株数或丛数、多度、频度、盖度 |
| 产量 | 药用部位鲜重与干重，注明折干率与折算方法 |
| 物候期与株龄结构 | 幼株、成株、衰老株各占多少 |
| 调查人与日期 | 当场填写，更正须划线注改并签名 |

两条纪律：**记录当场完成，不得事后凭记忆追记**；**挖取样方要留够繁殖更新的个体，凭证标本只采一份**。前者决定数据是不是观测，后者决定这个点明年还在不在。对多年生药材还要记株龄结构：同一片林子，幼株占多数和成株占多数，指向的是「在恢复」与「在消耗」两种相反的判断，两者的可采结论不能相同。

## 四、四种失效模式与考核项

**其一，用访问估产代替实测。** 访问调查是重要的辅助方法，但农户报的是「收了多少」，不是「地里还有多少」；把历年收购量当蕴藏量，等于把已采出的部分反复计入。

**其二，以点代面。** 一个典型样方乘上全域面积，是调查里最常见的省事写法。它把 S2 与 S4 两步的误差同时放大，而且无法估计。

**其三，鲜重干重混用。** 根及根茎类药材鲜干比差异很大，不注折干率的产量数字无法与他人的数据比较，也无法进入任何汇总。

**其四，把「有记录」当「有分布」。** 标本采集点、文献记载点、市场货源点都不是分布面积；面积要靠植被图、遥感判读加实地勾绘，且必须说明判读精度。

考核项四道，都只考一件事——结论能不能被同一份记录重算：

1. 给定四个样方的产量与面积，算出单位面积蕴藏量与全域蕴藏量，并列出你需要的、但题目没给的参数。
2. 给定一份「某县蕴藏量 800 吨」的报告，指出它缺哪几步的参数，估计它的区间最可能被哪一步撑开。
3. 设计一个分层取样方案：分层依据选什么，每层几个样方，为什么这样分层能减少 S4 的偏差。
4. 判断「某药三年收购量合计 120 吨，故蕴藏量约 120 吨」这句话错在哪一步。

## 五、代价与边界

**丢掉了什么。** 丢掉的是「一个确定的数」。教材的叙述读起来是「算出蕴藏量」，本章把它改写成「报出区间与参数」，读起来啰嗦，却让结论可复核。**整体感换可复核性，这笔交易在资源管理上是划算的。**

**区间宽不是失败，是方法性质。** 乘性误差决定了四步各自不确定时区间必然宽；把区间压窄的办法只有一条——把某几步实测掉，而不是把区间写得漂亮。本章给出的 0.41 至 2.07 是演算设定，用来标定量级，不能当作任何品种的误差估计。

**本章不含产区面积与蕴藏量数据。** 全国与省级的资源数字以官方普查成果发布为准，本章不引用、不推算、不举例填充；教材原文中出现的具体数值，须回到原书与发布文件核对后方可引用。

**遥感与访问调查只作辅助。** 遥感能圈定范围、监测变化，但中低分辨率影像分不开形态相近的草本，山区与林下还受上层植被干扰；判读结果必须经地面样方验证。访问调查提供线索，不提供定量结论。

```bash
# 复算乘性误差区间（浮动幅度可改）
python -c "p=0.2;lo,hi=(1-p)**4,(1+p)**4;print(round(lo,2),round(hi,2),round(hi/lo,1))"
```

改任何一个参数（例如把浮动幅度由 0.2 改成 0.3），区间立刻变宽——这正是本章主张的检验方式：**结论随参数变化的方式，比结论本身更能说明方法是否被理解。**
