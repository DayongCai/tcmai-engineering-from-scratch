## 四、这门课不教什么

1. **不替代实验切片**：显微结构只讲判据，不给镜下图谱（缺口见 `缺口登记.md`）。
2. **不列全科属检索表**：只到代表科与药典常见基原。
3. **不写栽培技术**：那是《中药资源学》的范围（本系已建，第 4 章规范化种植）。
