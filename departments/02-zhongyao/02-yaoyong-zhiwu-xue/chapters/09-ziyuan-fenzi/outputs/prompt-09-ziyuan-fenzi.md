# 药用植物资源、保护与分子鉴定 · 提示词

## 用途

给「药用植物资源、保护与分子鉴定」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「绪论 → 细胞组织 → 根茎 → 叶 → 花果种子 → 分类与低等植物 → 苔藓蕨类裸子 → 被子植物 → 资源与分子鉴定」这条链。

## 提示词

```
我在学《药用植物学》第 9 章「药用植物资源、保护与分子鉴定」，本章 7 单元 / 19,146 汉字，
取自教材第 12 章。

请按以下顺序带我走：
1. 先给本章要回答的问题，并说明它为什么不能直接套用上一章；
2. 再给三辨（形态描述／显微结构／分类与鉴定）在本章的实测分布，指出主导那一辨；
3. 然后按单元逐条读出「判据」——每条只写类别与要点，不给操作参数；
4. 最后给出三条边界：哪些内容只能写到类别、哪些必须由具备资质的人员作出、哪些情况按《中国药典·一部》基原项与《中国植物志》科属检索表报告。

要求：不编造教材没有的数字；引文写到《书名·篇名》级并标注是否本章原文篇名；
不确定的地方直接说「教材未展开」。
```

## 边界

本提示词用于教学准备，不构成诊疗或护理意见；具体操作以现行规范与所在机构制度为准。
