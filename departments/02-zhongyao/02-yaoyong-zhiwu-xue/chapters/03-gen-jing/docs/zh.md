# 第 3 章 · 根与茎的分界只有一条：节、叶与芽长在谁身上

> **MOTTO:** 「人参，味甘，微寒。主补五脏，安精神，定魂魄，止惊悸，除邪气，明目，开心益智。」——《神农本草经·上品》
>
> **PROBLEM:** 教材把根与茎的区别压成三条：有无节与节间、生不生叶、具不具芽。可药典里常被笼统称作「根类」的八味药材，有四味的法定部位根本不是根——川芎、白术是根茎，天麻、半夏是块茎（见表 2）。名词的错位不是小事：部位错一位，切面层序、显微判据、采收季节全都跟着错。
>
> **双根因定位:** 环境逼迫（植株一离土，地上部分被剪掉，剩下的块状物只能靠断面与芽眼判断；此时若按「名字」而不按「结构」认，必然出错）+ 知识积累（根的初生构造、次生构造与茎的环状维管束是两套坐标，混用一套就无法解释何首乌的云锦花纹为何长在根上）

**底本定位:** 教材第 3 章（根与茎）六节；本章只标「第X章·X.Y.Z」，不引页码。

## 一、这一章要立的判据

根与茎的分界，教材给得很干脆：茎有节与节间、生叶、具芽，分枝由表面或近表面的侧芽发生，属外起源；根无节无叶、通常无芽，分枝由母根内部组织发生，属内起源，根尖之外还有根冠（第3章·3.1.1、3.2.1）。这一组对比之所以可靠，是因为它指向的是「谁长在谁身上」——叶与芽是茎的附属物，根上没有它们的位置。

麻烦出在变态器官上。根状茎横走地下、形似根，却有节、有鳞叶或叶痕、有顶芽；块茎膨大如薯，表面有芽眼；块根同样膨大，却只在根头生不定芽，全身没有芽眼。三者的外形可以极像，判据却分属两个器官。本章要立的判据因此不是「记住三条定义」，而是：**先找芽与节，找不到再找断面。** 芽眼与节是茎的铁证；断面只能作辅证。

第二层错位来自命名。药典的部位名是按入药习惯定的，不按植物学器官分：甘草写作「根及根茎」，人参也写作「根及根茎」，川芎只写「根茎」，天麻写「块茎」，半夏也写「块茎」（第10章·10.2.1、10.2.2、10.3.1、11.2.2）。表 2 把这八味常见药材的部位列开，四味不是根。

| 药材 | 法定药用部位 | 植物学器官 |
|---|---|---|
| 甘草 | 根及根茎 | 根＋根状茎 |
| 黄芪 | 根 | 根 |
| 当归 | 根 | 根 |
| 柴胡 | 根 | 根 |
| 川芎 | 根茎 | 根状茎 |
| 白术 | 根茎 | 根状茎 |
| 天麻 | 块茎 | 块茎 |
| 半夏 | 块茎 | 块茎 |

## 二、根与茎各看什么

表 3 把两个器官的观察项并排，共十项。并排的好处是：同一项在两栏里的答案不同，差异本身就是判据。

| 序 | 观察项 | 根 | 茎 |
|---|---|---|---|
| 1 | 节与节间 | 无 | 有，节上着叶 |
| 2 | 芽 | 通常无，仅根头可生不定芽 | 有顶芽与腋芽，木本多有芽鳞 |
| 3 | 分枝来源 | 内起源，自中柱鞘发生 | 外起源，自叶腋的侧芽发生 |
| 4 | 根冠或生长点 | 有根冠 | 无根冠，仅生长点 |
| 5 | 根系或株形 | 直根系或须根系 | 直立、缠绕、攀援、匍匐 |
| 6 | 初生构造 | 表皮、皮层、中柱；木质部与韧皮部相间成辐射状 | 表皮、皮层、维管束环状排列、髓 |
| 7 | 次生构造 | 周皮、次生韧皮部、次生木质部；常见异常维管束 | 年轮、导管与木纤维、木射线 |
| 8 | 断面特征 | 菊花心、云锦花纹、罗盘纹、星点 | 环纹、髓心、放射状纹理 |
| 9 | 变态类型 | 贮藏根、块根、气生根 | 根状茎、块茎、鳞茎、茎刺、茎卷须 |
| 10 | 采收季节 | 秋末冬初或早春萌前 | 根茎同根；茎木类多在生长停止后 |

第 6、7 两项是显微层面的判据。根的初生木质部与初生韧皮部相间排列成辐射状，木质部辐射角的数目（二至六原型）是常规鉴别指标；茎的维管束则排成一环，每束外为韧皮部、内为木质部，中央有髓（第3章·3.1.2、3.2.2）。这一条在横切面上几乎一眼可分，比外形可靠。

异常维管束是根类药材的特色判据。正常次生构造之外，由中柱鞘或韧皮部薄壁细胞产生新的形成层，形成位置与方向都不规则的额外维管束，称三生生长。三种形态各有专名：何首乌的云锦花纹、牛膝与商陆的罗盘纹、大黄根茎髓部的星点（第3章·3.1.3）。凡见这三者之一，基本可判为根或根茎类，且能进一步指向具体药材。

## 三、判据与「不成立」条件

【教学设定】本章采用的判定顺序：第一步找芽眼、节、鳞叶或叶痕，三者任一存在即判为茎（含根状茎、块茎、鳞茎）；第二步看断面维管束是辐射状还是环状，辐射状判根，环状判茎；第三步才用外形与气味。三步中前两步任一成立即可定论，第三步只作旁证。

不成立的条件有六条。

其一，「长在地下」不是根的证据。根状茎、块茎、鳞茎都在地下，都是茎。教材讲茎的变态时专门点了这一层（第3章·3.2.1）。

其二，「膨大」不是块根的专利。块茎、鳞茎、球茎都膨大。区分靠芽眼与鳞叶：块茎有凹陷的芽眼，块根没有。

其三，「须根系」可能是人为造成的。移栽或断根后，主根受损失，侧根与不定根代偿性增生，一条直根系的植株也能长成须状。判断须根系必须在未受扰动的植株上做，或看根与茎的连接处有无明显的主根残基。

其四，「有节」不等于茎。少数植物的根在受伤后可形成横缢，状似节，但无叶痕、无芽。

其五，单看断面纹理不作定论。菊花心是同心环状纹理的俗称，多种根类药材都有；星点则专指髓部异常维管束的横断面。纹理须与层序、后含物合看。

其六，药名不作判据。「根类药材」是商品分类的习惯说法，不等于植物学上的根。凡引用药名推断器官，都会在川芎、天麻这类药材上出错。

## 四、挖掘、切面与记录

挖掘的动作决定后续所有判断。三条要领：下铲距主根十厘米以外，避免切断侧根；挖出后带土团轻轻抖散，不用水猛冲，以免冲掉根毛与表皮；根茎类必须连带一段地上茎或叶痕，否则无法确认它是茎。木本植物取带花或带果的枝条，不挖孤立个体（第12章·12.1.1）。

切面的动作分三种。横切看层序与维管束排列，是首选；纵切看导管的纹式与穿孔板，用于区分导管与管胞；木类药材按三切面观察——横切面看生长轮与导管分布，径向切面看木射线与纹孔，切向切面看射线的宽度与高度（第3章·3.2.3）。三切面缺一，木材类药材的鉴定就不完整。

断面记录用表 4 的八栏。这八栏与标本标签分开填，因为断面是采后立刻观察的，标签是事后整理的。

| 栏 | 记录内容 |
|---|---|
| 1 形状 | 圆柱形、圆锥形、纺锤形、结节状、拳形团块 |
| 2 表面 | 颜色、纵皱纹、横长皮孔、环状轮节、茎痕 |
| 3 皮部与木部比例 | 以断面半径估，写明大致比例 |
| 4 断面颜色与质地 | 粉性、纤维性、角质样、平坦或颗粒状 |
| 5 纹理 | 菊花心、云锦花纹、罗盘纹、星点、放射状纹理 |
| 6 形成层环 | 环的形状，平整或波状 |
| 7 气味 | 香气强弱、特异气味、味感（尝后漱口） |
| 8 芽眼与节 | 有无、位置、数目；此项决定器官归属 |

第 8 栏是本章特意加的。多数断面记录表不设这一栏，于是「块茎还是块根」这个最基本的问题在记录里无从回答。

## 五、四种失效模式与考核项

一是把根茎当根。这是最高频的一种。川芎、白术、黄精、玉竹、知母都是根茎，外形圆块状，学生常直接写作「根」。纠法：凡断面见髓、见环状维管束、见节与叶痕，一律改判为茎。

二是把须根系当直根系。移栽苗、断根苗、沙地生长的植株都容易误判。纠法：看根头有无主根残基，或直接查该种的根系类型记载，不以单株为据。

三是把茎刺当叶刺。山楂、皂荚的枝刺生于叶腋、有维管束与茎相连、位置固定；小檗的刺为叶变态，刺槐的刺为托叶变态（第4章·4.1.2）。纠法：看刺的基部有无腋芽，有芽者为茎刺。

四是把块茎当块根。天麻、半夏、马铃薯都是块茎，有芽眼；何首乌、甘薯是块根，无芽眼。纠法：在表面找凹陷的芽眼，找不到再切看有无髓。

考核项五条：

1. 给六份去掉了地上部分的材料，按「芽眼—断面—外形」三步判器官，写出每一步的观察结果；
2. 说出根与茎在初生构造上的三处差异，并在横切面上逐处指认；
3. 解释云锦花纹、罗盘纹、星点各在哪一层、由什么造成；
4. 交一份填满八栏的断面记录，其中第 8 栏不得空缺；
5. 从药典中查出五味「根类」药材的法定部位，指出其中哪几味不是根。

## 六、代价与边界

第一，本章的判据解决的是器官归属，不解决物种定名。知道手里是根茎，离「这是川芎还是白术」还有很远；后者要靠花、果与显微特征。

第二，异常维管束的三个俗名（云锦花纹、罗盘纹、星点）是经验形态术语，其在药典中的对应表述以性状与显微鉴别正文为准。用俗名描述可以，用俗名下结论不行（第3章·3.1.3）。

第三，本章不涉及剂量、炮制与用法。人参、甘草、川芎这些名字在本章只作器官示例出现，其功效与使用不在本章范围；凡涉及用药，须由医师依规范决定。

第四，野生药用植物的采挖受法律约束。本章讲「怎么挖」是教学动作，不构成采集许可；受保护物种的采集须依法审批，保护区内的采集一律禁止。
