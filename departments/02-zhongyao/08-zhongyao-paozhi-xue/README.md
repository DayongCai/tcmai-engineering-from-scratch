**口径**

1. **三辨＝工艺操作／成品性状／减毒增效**，实测 **4354 / 3290 / 2122**，比值 **2.1×**——教材重「怎么做」与「做成什么样」，轻「为什么做」；
2. **四位面取制法大类**（火制 2260 / 水火共制 499 / 水制 714 / 其他制法 217，**10.4×**）。这是炮制学的第一层分类，与教材 8–11 章同构；比值高是因为**教材 3 章讲火制、1 章讲水火共制**，属篇章结构而非词根通胀，故选它；
3. **辅料与规格 8.5×、炮制目的 13.1× 留痕不取**：前者混了「切制规格」与「质量贮藏」两类不相干内容，后者把目的当分类、与三辨的「减毒增效」重叠。

**最值得记的一条**：全书「减毒」类词只出现 **267 次**，「便于制剂与贮藏」出现 **928 次**。
**炮制的第一目的不是减毒**——这与「炮制＝减毒」的直觉相反，也是第 8 章跨课对账的出发点。

**跨课对账（与《中药毒理学》）**：44 味毒性药里，**工艺可查 26（59.1%）**、仅提名 2、**未覆盖 16**。
反向看，炮制课出现的药多数在《中药学》里没有毒性标注（183 味）——再次说明炮制不等于减毒。

**数值口径**：全书数值类命中仅 **5 处**。炮制的火候与时间多以「文火」「炒至表面焦黄色」表述，**可数的值少，不代表工艺不可控**——第 9 章写的就是怎么把这类表述拆成参数。
