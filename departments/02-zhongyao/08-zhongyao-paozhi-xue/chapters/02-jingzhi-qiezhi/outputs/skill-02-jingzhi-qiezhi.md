# 净制的难点不是去杂，而是判断哪一部分才算药

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 5 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 「药」的单位不是植物，是部位
- 净制的每一种「去除」，都要能回答「去除物去了哪里」
- 少泡多润、药透水尽
- 切制软化不得用硫黄熏蒸
- 切得越薄，煎出越快，但未必越好

## 边界

- 只写类别与要点，不写操作参数。
- 本章为中药炮制学教学材料，不构成工艺参数与生产规范。
