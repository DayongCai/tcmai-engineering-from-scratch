# 煅法的全部难点，是把看不见的变化写成看得见的终点

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 明煅、煅淬、闷煅都以武火为主，火力一项上没有差别
- 这个划分不是分类癖，它决定了三种方法各自失败的样子
- 还有一条容易被略过的安全约束：贝壳类药煅制时爆裂，飞溅伤人，须先把药材敲碎，或置耐火容器内加盖但不密封
- 矿物药与贝壳类药结构致密，高温下发生三件事：失水、分解、晶型转变
- 于是终点被翻译成三种感官
- 石膏是最好的例子，因为它把生熟异治压缩在一种药上

## 边界

- 只写类别与要点，不写操作参数。
- 本章为中药炮制学教学材料，不构成工艺参数与生产规范。
