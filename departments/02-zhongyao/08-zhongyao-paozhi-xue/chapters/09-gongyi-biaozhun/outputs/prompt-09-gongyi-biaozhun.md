# 标准化的上限是参数，下限是性状 · 提示词

## 用途

给「标准化的上限是参数，下限是性状」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三层标准：通则、规范、内控 → 参数化：把「文火」翻译成温度，翻译中丢掉了什么 → 性状与限度：为什么「存性」还是判据 → 工程化：设备把参数固定下来，检测把判断提前」这条链。

2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；

   - 第一层是《中国药典》炮制通则
   - 第二层是部颁标准与省级中药饮片炮制规范
   - 第三层是企业内控标准

## 边界

本章为中药炮制学教学材料，内容取自教材《中药炮制学》第 5、12 章与 `standards/zhongyao-paozhi` 的机器可读层。**本章不构成炮制工艺规程、不构成饮片质量标准、不构成生产或检验方案，也不构成用药建议。** 文中的温度区间、辅料比例、检查项目与限度为教学用通行表述，实际执行一律以现行《中国药典》炮制通则、各品种项下规定及省级中药饮片炮制规范为准。炮制生产涉及高温、明火、粉尘、压力容器与毒性药材，须在合规场所由受训持证人员按安全规程操作；具体操作以现行规范与所在机构制度为准。
