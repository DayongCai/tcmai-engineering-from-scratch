## 一、学科定位

中药药理学（TCM Pharmacology）是中药系的核心学科，聚焦「本草、方剂与中药全产业链：资源—鉴定—化学—药理—制剂」中的一个完整知识域。

## 二、中医 → AI 桥梁

```text
药效实验→剂量-反应拟合 / 网络药理→图算法
```

中药药理学 里的每一个传统概念，都被翻译成一个可计算、可验证的工程对象：
中医概念给出**语义与约束**，AI/工程方法给出**表示与算法**。两者必须能互相回指，

**口径**

1. **三辨＝药理作用／作用机制／实验证据**，实测 **4875 / 717 / 1926**，比值 **6.8×**——**「机制」写得最少，只有「作用」的 1/7**。这是本课最值得记的一条：中药药理学教材写「做什么」远多于「凭什么」，写「机制」时又大量停留在「可能与…有关」；
2. **四位面取药物类别**（解表清热 868 / 活血止血 590 / 补虚免疫 506 / 化痰安神平肝 458，**1.9×**）。它与教材章序同构，也与本课「按类别讲」的组织方式一致；
3. **靶系统 3.8× 未取**：消化与代谢一词命中 2,082，是因为「肝」「代谢」「血脂」在各类药里都出现，属词根通胀；**研究环节 4.1× 未取**：药效/药动/毒理/方法是内容切面，不是药理作用的分类。

**数值口径（本课最特殊的一处）**：全书数值类命中仅 **5 处**，全库最低之一。
药理学的剂量与效应多以「剂量依赖」「高剂量组」这类相对表述出现，**绝对数值在实验论文里、不在教材里**——
这正是第 9 章「动物实验有效能不能推到人」要追问的：教材没有可换算的数，转化就无从谈起。

**引文口径**：教材只引书名（《神农本草经》《素问》《本草纲目》等）。
凡门要求《书名·篇名》级者，按**真实篇目**补足并就地注明「非本章原文篇名」：
《素问·至真要大论》（病机十九条、大毒治病）、《素问·阴阳应象大论》（其在皮者汗而发之）、《素问·调经论》（血气不和）、《素问·通评虚实论》（邪气盛则实）、《神农本草经·序录》（三品与七情）。
