# 一条药理证据的等级，先由药材能不能复现决定 · 提示词

## 用途

给「一条药理证据的等级，先由药材能不能复现决定」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「证据链的第一环是「受试物是什么」 → 产地、采收、炮制：同一物种，不同物质体系 → 剂型与剂量：暴露量决定证据的强度轴 → 数据库与人工智能：检索更快，证据没变多」这条链。

## 边界

本章为中药药理学教学材料，讨论药理证据的方法学前提与数字化工具的使用边界，不构成诊断、处方或用药建议。文中基原差异、产地与采收差异、炮制减毒、剂型与剂量要求均取自教材与药典表述，实验结论为文献口径，不是本章的实测数据。附子、川乌、草乌、马钱子、细辛、朱砂、雄黄、斑蝥等有毒中药，以及妊娠禁忌药，任何使用必须由执业中医师或执业药师依《中国药典》决定。数据库检索结果与人工智能生成内容仅作线索，剂量、毒性、配伍禁忌须与药典正文及药品说明书逐项核对，并经专业人员复核后方可采用；具体操作以现行规范与所在机构制度为准。
