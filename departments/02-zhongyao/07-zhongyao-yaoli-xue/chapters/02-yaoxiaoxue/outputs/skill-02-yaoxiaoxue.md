# 中药的量效曲线不是一条线，是一个开关带

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 双向调节是可以观察的事实，不是已经完成的解释
- 第一个断点：起效阈值
- 第二个断点：平台
- 第三个断点：反向点
- 第四个断点：毒性拐点
- 整体动物实验

## 边界

- **剂量只作教材引用，不作推荐。** 文中 0.05～0.3 g、1～2 g、「细辛不过钱」均为教材·第3章·3.1.2 的表述，用于说明量效段的存在，不是可执行的处方；任何实际用量须由执业中医师依《中国药典》与患者情况决定。
- **双向调节不等于安全。** 方向可变恰恰意味着剂量与状态判断错误时，效应会朝反方向走。教材在讲双向调节的临床意义时，落点是「必须重视剂量与机体状态」，不是「因此更安全」。
- **模型结论只在模型内成立。** 离体、细胞、整体、网络四类证据不可互相顶替；本章不引用任何具体的动物实验数值，凡涉及效应量的问题一律回到原始文献。
- 本章为中药药理学教学材料，讨论量效关系与模型选择的方法问题。文中剂量与古籍引文均取自教材所载，实验数据仅为文献口径，不构成临床用药建议。
