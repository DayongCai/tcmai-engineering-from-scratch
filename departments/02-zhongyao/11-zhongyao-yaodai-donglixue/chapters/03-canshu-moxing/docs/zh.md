## 一、模型无关的量，与模型依赖的量

参数可以先按「要不要先假定一个结构」分成两堆，这一刀切下去，后面所有争论都清楚了。

**模型无关的量**，只要有一条浓度—时间曲线就能算出来，不需要假定几个房室：

- 曲线下面积 AUC，用线性梯形法逐段累加，AUC(0→∞) = AUC(0→t) + Ct/λz，Ct 是最后一个实测点，λz 是末端消除速率常数。
- 一阶矩曲线下面积 AUMC，把 t×C 逐段累加，算法与 AUC 完全相同，只是被积函数多乘一个时间。
- 平均驻留时间 MRT = AUMC/AUC，单位是时间，含义是分子在体内平均待了多久。
- 清除率 CL = D/AUC（静脉给药），暴露越大清除越慢，这个关系与房室数无关。
- 稳态表观分布容积 Vss = CL × MRT，同样只用上面三个量拼出来。

**模型依赖的量**，必须先假定结构：一室模型里的消除速率常数 k、吸收速率常数 ka，二室模型里的分布速率常数 α、β 与室间转运常数 k12、k21。它们不是从数据里「读」出来的，是拟合出来的。换一个模型，数就变，而且没有哪一个更「真」。

这一刀的现实意义在于：**跨研究比较，优先比模型无关的量**。AUC、CL、MRT 换个实验室、换套软件，只要采样窗一致，大体能对上；k、α、β 换个模型就对不上。可惜中药药代文献里最常被拿来做比较的，恰恰是模型依赖最深的半衰期。

## 二、房室模型：一个比喻，两种代价

房室模型的表述很漂亮。一室模型把身体看成一个均匀的池子，静脉推注后浓度按指数衰减：

**C = C0 · e^(−k t)，t½ = 0.693 / k**

半衰期与消除速率常数互为倒数关系，0.693 是 2 的自然对数，不是经验值。二室模型把身体分成中央室与周边室，浓度是两条指数之和：

**C = A · e^(−α t) + B · e^(−β t)**

α 相是分布相，药物从中央室往组织里跑；β 相是消除相，跑完之后靠消除往下掉。曲线早期陡、后期平，就是两相叠加的外观。

代价有两条，都容易被忽略。

**代价一：室是数学隔间，不是解剖器官。** 中央室不等于血浆，周边室不等于脂肪或肌肉。所谓「分布到周边室」，只是曲线需要第二条指数，不代表任何具体的组织。把房室当器官讲，是教学里最常见的偷换。

**代价二：室数由采样与选模规则决定，不由生理决定。** 只有三个采样点，二室模型永远拟合不出来——不是没有分布相，是数据支撑不了。反过来，采样密、噪声大时，多拟合一个室往往能让残差平方和降下来，此时要靠赤池信息准则之类的惩罚项把多余的室挡回去。**模型选择的自由度，就是结论的自由度。**

还有一组常被混淆的量：Vd 的三种算法给出三个数。外推法（Vd,extrap）用 C0 除剂量，分布未完成时偏小；稳态法（Vd,ss）用 CL×MRT，最稳；β 相法（Vd,β）用 CL/β，对末端相极其敏感。三个都叫「表观分布容积」，报的时候必须标是哪一个。三室以上在中药多成分研究里几乎不可辨识，硬拟合只会得到一堆无法解释的速率常数。

## 三、末端相：半衰期最容易出问题的地方

半衰期全靠末端相。末端相选错，后面一切白算。所以行业里有一条不成文但被广泛执行的规矩，写出来是四条：

1. **末端至少三个点**，且这三个点要落在同一条对数线性段上。只有两个点，直线必然穿过它们，拟合优度永远是一，毫无检验意义。
2. **不跨过峰。** 末端相只能取峰后。把峰前的点混进回归，这些点高于末端直线，回归线被拉陡，λz 被算大，半衰期随之被低估。
3. **报告拟合优度与点数。** 只说「半衰期若干小时」而不说几点、R² 多少，等于没有报告。
4. **外推比例受限。** AUC(0→∞) 中外推部分（Ct/λz）占总面积的比例通常要求不超过两成。超过两成，说明采样窗没覆盖住末端，此时半衰期不可信，能报的只有 AUC(0→t)。这一条是各国审评通行的口径，也是判断一篇中药药代研究是否严肃的最快切口。

中药的曲线还多一层麻烦：肝肠循环造成第二峰，第二峰之后的「末端」其实是被重吸收拖出来的假末端。此时算出的半衰期描述的是「重吸收—再消除」的循环周期，不是消除半衰期。把它和静脉给药的半衰期并列，是把两个不同机制的数摆进同一列。

## 四、参数可比性的五条契约

参数只有在一组共同条件下才谈得上比较。本章把条件写成五条契约，缺一条，两个数就不能并列：

| 契约 | 内容 | 缺了会怎样 |
|---|---|---|
| 剂量口径 | 标称投料量还是实测含量；是否按体重归一 | 清除率与分布容积整体平移 |
| 给药途径 | 静脉、灌胃、外用不可混比 | 生物利用度被混进清除率 |
| 采样窗与点数 | 末点是否覆盖三个半衰期以上 | 半衰期系统性偏低或偏高 |
| 算法 | 非房室、房室、群体模型三者不互比 | 同一数据得出不同参数 |
| 归一方式 | 体重、体表面积、种属换算 | 动物与人被当成同一尺度 |

五条之外还有一条软约束：**个体差异要报分布，不只报均值**。中药的暴露量受菌群、证候、合并用药影响，均值加减标准差常常掩盖了双峰分布——一部分人是快代谢型，一部分人是慢代谢型，均值落在中间，谁都不代表。群体药代模型的价值就在这里：它把个体间变异与残差变异分开估计，让「这个方对谁有效」这个问题有了量的入口。当然，样本量不足时群体模型给出的个体参数只是收缩后的估计，不能当个体的真值用。

判据收束成一句：**一个参数能不能用，看它有没有交出条件；一组参数能不能比，看它们有没有共享条件。**

## 五、多成分曲线怎么报：三种格式，一种禁忌

中药药代的报告格式只有三种，各有各的适用面，混用就会出伪参数。

**其一，逐成分全参数。** 对每个指标成分单独算 AUC、Cmax、Tmax、t½、CL。最诚实，也最啰嗦；成分多于五个时，表格会失去可读性，读者抓不住重点。

**其二，成分组伪参数。** 把同一母核、同一苷元衍生的几个成分浓度相加，当一条「总浓度」曲线处理。这种做法在黄酮苷类、人参皂苷类里常见，前提是几个成分的分子量相近、活性方向一致、单位统一。它给的是「母核总暴露」，能把分散的曲线收成一条，代价是丢掉了成分间的比例信息。

**其三，暴露比矩阵。** 不算绝对量，只报成分间的 AUC 比值及其在配伍前后的变化。它最适合回答「配伍改没改成分结构」这一类问题，也最适合跨剂量比较，因为比值把剂量口径约掉了。

禁忌只有一条：**不同结构、不同分子量、不同响应因子的成分，浓度不能相加。** 把黄芩苷的纳克数与人参皂苷的纳克数加起来叫「总成分浓度」，得到的数没有物理意义，响应因子差异还会让它随检测方法漂移。这不是保守，是量纲问题。

三种格式的选择判据也简单：要回答「这个成分进没进去」，用第一种；要回答「这一类成分整体变没变」，用第二种并写明归并规则；要回答「配伍改动了什么」，用第三种。**报告格式先定，结论才不会被格式反向塑造。**

## 代价与边界

- **参数是条件量。** 本章不给任何具体成分的参数值；凡引用参数，必须同时引用剂量、途径、采样窗与算法。
- **房室数不是生理事实。** 一室、二室是拟合结构的名字，不是器官清单；室数由数据密度与选模规则决定，不由病机或解剖决定。
- **半衰期最脆弱。** 末端相三点、不跨峰、外推不超两成，这三条不满足时，半衰期只能当描述性数字，不能进比较表。
- **模型无关不等于无假设。** 梯形法假定两点之间浓度线性变化，采样过疏时同样失真；AUC 的「无关」只是不依赖房室结构，不是不依赖采样设计。
- **群体模型不能救小样本。** 个体参数是收缩估计，样本量小的时候向群体均值收缩得厉害，不能当个体真值。
- **本课为派生课。** 母题正文取自父课单元，两课汉字不可相加。
