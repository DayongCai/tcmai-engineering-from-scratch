# 参数不是数据，是可比较性的契约 · 提示词

## 用途

给「参数不是数据，是可比较性的契约」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「模型无关的量，与模型依赖的量 → 房室模型：一个比喻，两种代价 → 末端相：半衰期最容易出问题的地方 → 参数可比性的五条契约」这条链。

## 边界

本章为中药药代动力学教学材料。文中公式、选模规则与外推比例均为教材与审评通行口径的复述，不涉及任何具体药物的参数值，也不构成给药方案。临床剂量调整、治疗药物监测的判读须由医师与临床药师依据患者具体情况决定；具体操作以现行规范与所在机构制度为准。
