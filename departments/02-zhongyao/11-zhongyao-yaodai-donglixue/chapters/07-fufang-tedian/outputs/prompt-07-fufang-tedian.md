# 复方的暴露是一条谱，不是一个点 · 提示词

## 用途

给「复方的暴露是一条谱，不是一个点」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「复方给药的三道难题 → 选标志物：三个层次，三种诚实 → 暴露谱：把「一个点」摊成一张图 → 配伍改写暴露的四条路径」这条链。


## 边界

本章为中药药代动力学教学材料，讨论复方研究的设计与结论边界，不构成方剂推荐、剂量建议或疗效判断。涉及具体方剂的使用、加减与联用，须由执业中医师依辨证结果与现行规范决定；具体操作以现行规范与所在机构制度为准。
