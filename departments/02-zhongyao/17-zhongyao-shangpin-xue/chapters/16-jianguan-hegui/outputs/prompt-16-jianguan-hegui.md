# 监管划的是底线，合规做的是把底线变成流程 · 提示词

## 用途

给「监管划的是底线，合规做的是把底线变成流程」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「先找对门，再找对版本 → 中药为什么要另作安排 → 抽检与公告：公告是事实公开，不是终局结论 → 检查、查封扣押与召回」这条链。

## 边界

本章所涉监管体制、法律依据与合规方法，仅作教学讨论之用；具体操作以现行规范与所在机构制度为准。
