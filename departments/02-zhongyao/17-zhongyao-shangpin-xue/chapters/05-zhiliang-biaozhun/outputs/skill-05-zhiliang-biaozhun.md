# 标准不是一张合格证，是一串「谁说了算、说到哪一步」的效力排序

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 注意它包含两类东西
- 四个层次不是并列，是有主有从
- 《中国药典》
- 药品注册标准
- 再加一条常被忽略的分岔：标准对象不同，依据文件也不同
- 明确某一具体商品应执行哪一层级、哪一类标准，是质量把关的起点

## 边界

- 只写类别与要点，不写操作参数。
- 本章为中药商品学课程的教学材料，讨论质量标准体系的层级、效力与处理原则，不构成质量判定结论或合规意见。具体品种的合格判定依现行版《中国药典》及相应国家药品标准执行。
