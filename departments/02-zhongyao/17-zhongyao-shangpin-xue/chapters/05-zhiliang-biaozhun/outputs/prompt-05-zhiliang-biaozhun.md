# 标准不是一张合格证，是一串「谁说了算、说到哪一步」的效力排序 · 提示词

## 用途

给「标准不是一张合格证，是一串「谁说了算、说到哪一步」的效力排序」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「四层标准：谁定、管到哪、不能越过谁 → 强制与推荐：药典是底线，规格等级标准不是 → 药典一部正文的十项，各管什么 → 层级打架时怎么办：从严、从新、从专门规定」这条链。

## 边界

本章为中药商品学课程的教学材料，讨论质量标准体系的层级、效力与处理原则，不构成质量判定结论或合规意见。具体品种的合格判定依现行版《中国药典》及相应国家药品标准执行；具体操作以现行规范与所在机构制度为准。
