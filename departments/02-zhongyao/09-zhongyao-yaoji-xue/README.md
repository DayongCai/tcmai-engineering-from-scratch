## 一、学科定位

中药药剂学（TCM Pharmaceutics）是中药系的核心学科，聚焦「本草、方剂与中药全产业链：资源—鉴定—化学—药理—制剂」中的一个完整知识域。

```text
剂型设计→多目标优化 / 释放曲线→动力学拟合
```

**口径**

1. **三辨＝处方／工艺／质量**：药剂学每一剂型都按这条链写（有什么、怎么做、怎么放行），不另造分类；实测 处方 1673 · 工艺 2944 · 质量 4117，比值 **2.5×**——**「质量」写得比「处方」多一倍半**，因为教材的篇幅大量落在检查项与限度上；
2. **四位面取给药途径**（口服 1616 / 注射 790 / 外用 393 / 黏膜 206，**7.8×**）；
3. **分散体系 10.2× 未取**：不是数字不好，是「混悬与固体」一格把散剂、颗粒、片剂、胶囊、丸剂五类都算进去，属**词根通胀**，比出来的不是体系偏好；
4. **物态 6.9× 未取**：数字最小（液体/半固体/固体/气体），但物态是包装状态、不是设计决策，教材从未按物态编章——**数字最小不等于轴最好**（同「各家针灸」取时代轴不取主题轴）。

**数值口径**：全书数值类命中仅 **61 处**。药剂学的参数（加水量、火候、压力、转速）多以「适量」「以手握成团」「文火」表述，**可数的值少不等于工艺不量化**——真正的量化在《中国药典》四部的制剂通则里，本库未收，标缺口。

**引文口径**：教材只引书名（《中国药典》《伤寒论》《神农本草经》等）。
凡门要求《书名·篇名》级者按**真实分卷**补足并就地注明「非本章原文篇名」：
《中国药典·四部》（制剂通则与指导原则）、《伤寒论·辨太阳病脉证并治上》（方后注煎服法）、《神农本草经·序录》。
