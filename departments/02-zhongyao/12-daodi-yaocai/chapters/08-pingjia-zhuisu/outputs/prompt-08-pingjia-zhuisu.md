# 合格是最低线，评价是另一件事 · 提示词

## 用途

给「合格是最低线，评价是另一件事」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「评价的三个层次：从看得见到测得出 → 指标成分的困境：测的那个，是不是该测的那个 → 生物活性测定：什么时候非用不可 → 追溯：一条不能断的记录链」这条链。

## 边界

本章为道地药材与产地加工课程的教学材料，讨论品质评价的方法层次与追溯体系的记录结构，不构成质量检验结论、合格判定或采购依据。任何用于交易、投料、调剂或监管的检验与判定，须由具备资质的检验机构依现行版《中国药典》及相关标准执行；具体操作以现行规范与所在机构制度为准。
