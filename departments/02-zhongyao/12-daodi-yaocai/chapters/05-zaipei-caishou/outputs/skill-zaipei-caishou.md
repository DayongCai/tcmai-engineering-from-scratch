# 栽培把「找到好药」换成了「每年都做出好药」

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 农艺的目标常常是产量，而质量的目标是成分
- 每一味药的具体高峰位置不同，必须靠本品种的成分积累曲线去定，不能靠通用口诀
- （外观上可辨识的发育阶段）与
- 「单位面积有效成分总量」才是这两者的正确合成指标
- 人工繁育（半野生）
- 家种（农田栽培）

## 边界

- **栽培品不等于劣质品。** 判断依据是性状、成分与药效三项比较，不是「野生」这个标签。反之，野生品也不自动等于优质，过度采挖地区的野生品同样可能未成熟。
- **道地性不可完全复制。** 种苗可以搬走，产区的微气候、土壤微生物群落与长期选择形成的品种体系搬不走；引种成功通常意味着「可用」，不意味着「等同」。
- **产量与质量存在真实权衡。** 增产措施可能降低次生代谢产物积累，报数据时应当同时给出单位面积有效成分总量，而不是只报亩产或只报含量。
- 本章为道地药材与产地加工课程的教学材料，讨论栽培与采收的一般规律与判据，不构成种植技术方案、品种推荐或投资建议。涉及农药使用、产地环境检测与规范化基地建设，须依现行《中药材生产质量管理规范》与农业投入品管理规定执行。
