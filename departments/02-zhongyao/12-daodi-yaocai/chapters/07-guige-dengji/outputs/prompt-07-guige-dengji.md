# 等级是商品的语言，不是药效的刻度 · 提示词

## 用途

给「等级是商品的语言，不是药效的刻度」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「规格与等级是两个轴，不是一个轴 → 分等的六项依据：都可数，都可查 → 等级与药效：两条不同的刻度 → 价格：等级差价、周期与投机」这条链。

## 边界

本章为道地药材与产地加工课程的教学材料，讨论商品规格、等级与价格的形成逻辑，不构成采购建议、投资建议或质量判定结论。具体药材的规格等级依现行版《中国药典》、相关商品规格等级标准与购销合同约定执行；具体操作以现行规范与所在机构制度为准。
