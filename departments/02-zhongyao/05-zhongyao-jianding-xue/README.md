## 一、学科定位

中药鉴定学（Identification of Chinese Materia Medica）是中药系的核心学科，聚焦「本草、方剂与中药全产业链：资源—鉴定—化学—药理—制剂」中的一个完整知识域。

## 二、中医 → AI 桥梁

```text
性状鉴别→图像分类 / 显微鉴别→纹理特征
```

中药鉴定学 里的每一个传统概念，都被翻译成一个可计算、可验证的工程对象：
中医概念给出**语义与约束**，AI/工程方法给出**表示与算法**。两者必须能互相回指，
否则这个章节就还没有写完。

**口径**

1. **三辨＝特征描述／检查方法／质量限度**，实测 特征 3078 · 方法 3314 · 限度 2760，比值 **1.2×**——**全库最平的一套**。「看什么、怎么查、怎么判」在教材里几乎等重，缺一环鉴定就不成立；
2. **四位面取鉴定四法**（基原 805 / 性状 1841 / 显微 1408 / 理化 1138，**2.3×**）。它与教材 04–07 章的顺序同构，也是「基原→性状→显微→理化」这四层漏斗本身；
3. **药用部位 12.1× 未取**：「茎木皮叶花果实种子」一格把七类都算进去，属词根通胀；**判定类型 3.8× 未取**：真伪/优劣/掺伪是结论分类，不是鉴定的观察维度。

**数值口径（本课最特殊的一处）**：全书数值类命中仅 **7 处**，全库最低。
药材的尺寸多写成「直径约 1 厘米」「长 3～15 厘米」的汉字形式，且**大量判据是不可数的**（气香、味苦、断面有菊花心）。
**这不是缺陷，是鉴定学的性质**：能数字化的部分已交给仪器（含量、水分、灰分），留给人的是比例、组合与相对比较。正文在第 3 章专门写了「写不成数字的部分怎么写成可复核的判据」。

**引文口径**：教材只引书名（《中国药典》《本草纲目》《神农本草经》等）。
凡门要求《书名·篇名》级者按**真实分卷**补足并就地注明「非本章原文篇名」：
《中国药典·一部》（品种、性状与检查项）、《中国药典·四部》（检定通则与分子生物学检查法）、《本草纲目·草部》、《神农本草经·序录》。
