# 报告的效力，藏在取样件数与留样倍数的算术里

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 件数不是线性增长的，跳到 1000 件那一档时斜率突然变缓
- 平均样品一般不得少于检验用量的 3 倍
- 防止以单一项目的偶然现象作结论
- 由复核人对原始记录与结果核对，重大结论尚须审核人审核签发
- 程序的作用就是把这条链改成一条可回溯的链
- 单项合格不等于整体合格

## 边界

- **本章不给判定结论，只讲判定的结构。** 文中所有的人参 12.0%、甘草 7.0% 与 2.0%、丹参 35.0%、黄连 5.0%、马钱子 1.20%～2.20%、朱砂 96.0%、雄黄 90.0% 均为药典口径的举例，用于说明「限度怎么读」，不构成对任何具体检品的判定。现行版药典与品种正文为准。
- **抽样结论天生带着范围。** 任何抽样检验都不能证明「整批无伪」，只能证明「所抽样品符合规定」。报告若不写总件数与取样件数，等于隐藏了这个范围；这是本章认为最需要纠正的书写习惯。
- **留样是复议的物证，不是库存。** 三分之一留样的规定常被当作余量处理，实际上它是复检与仲裁的唯一基础。留样不足或保存条件不当，争议一旦发生即无法复议。
- 本章为中药鉴定学教学材料，讲述样规则、鉴定程序、常规检查项目与质量标准栏目的结构，不构成任何药材或饮片的检验结论、质量等级判定或用药建议。文中的件数规则、取样量、检查方法与限度举例均取自教材与药典表述，实验数据为文献口径，不是本章的实测数据。实际检验必须依据现行版《中国药典》及法定标准，由具备资质的检验机构与人员按标准操作程序完成。
