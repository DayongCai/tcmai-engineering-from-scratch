# 伪品不是长得像，是把正品的判据一条条做掉 · 提示词

## 用途

给「伪品不是长得像，是把正品的判据一条条做掉」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三条路线：伪品是怎么被做出来的 → 成组判据：四味药的正面清单【教学设定】 → 取样与制样：伪品鉴定的一半在取样 → 记录字段、四种失效与考核项」这条链。

## 提示词

```
我在学《中药鉴定学》第 6 章「伪品不是长得像，是把正品的判据一条条做掉」，本章 5 节 / 3,008 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 第一条：同科属近似种
   - 第二条：异科异属形似物
   - 第三条：正品再加工掺伪
   - （星点、树脂道、晶鞘纤维），第二条查
   - （鹦哥嘴、肚脐眼、狮子头），第三条查
   - 每条判据要能指认
4. 本章自陈的边界（不得越过）：
   - **判据清单是闭合的，药材不是。** 表里列的是高频伪品，不等于全部；遇到清单外的近似种，正确动作是加做显微、理化或分子鉴定，而不是套用最像的那一条。
   - **「缺项」也有边界。** 加工方式会消掉特征：蒸煮过的天麻断面同样角质样，提取过的药渣气味变淡。缺项判据只在加工条件可比时成立。
   - **有毒伪品是安全问题，不是质量问题。** 商陆、华山参、紫茉莉根、大叶柴胡、菊三七都曾有中毒或肝损伤报告；判定为伪品后应按不合格品处置，不能「降级使用」。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为中药鉴定学教学材料，讲伪品与混淆品的判据结构、取样与记录要求，不构成任何药材的真伪结论或用药建议。文中点名的伪品多有毒性（商陆、华山参、紫茉莉根、大叶柴胡、菊三七、生半夏等），误用可致中毒或肝损伤，严禁入口尝试，亦不得「降级使用」。实际判定以现行版《中国药典》该品种项下规定与法定检验机构结论为准；具体操作以现行规范与所在机构制度为准。
