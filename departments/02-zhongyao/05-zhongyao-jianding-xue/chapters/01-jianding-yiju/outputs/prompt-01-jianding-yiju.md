# 药典给的是最低线，经验给的是典型样 · 提示词

## 用途

给「药典给的是最低线，经验给的是典型样」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「依据分三层，位阶不能倒着用 → 取样：代表性是可以算出来的 → 成组判据，与「不成立」的条件【教学设定】 → 报告要写哪几栏，以及四种典型失效」这条链。

## 边界

本章为中药鉴定学教学材料，讲的是依据体系、取样规则与报告字段的组织方式，不构成任何品种的检验操作规程或质量判定结论。文中不含具体限度值，实际检验须以现行版《中国药典》该品种正文与四部通则为准，并服从所在机构的质量管理制度与资质要求。涉及毒性药材、麻醉药品与濒危物种药材的取样与检验，须由受训人员在合规条件下按专门规定办理；具体操作以现行规范与所在机构制度为准。
