# 显微报告里没有标定值，就等于没有数字 · 提示词

## 用途

给「显微报告里没有标定值，就等于没有数字」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「制片：横切为主，纵切为辅，部位必须写 → 粉末：六大类特征与四种装片 → 化学定位与测量：成组判据与「不成立」条件【教学设定】 → 记录字段、四种失效与考核项」这条链。

## 边界

本章为中药鉴定学教学材料，讲显微制片、特征辨识与测量记录的方法，不构成任何药材的检验结论。文中的试剂（水合氯醛、间苯三酚、盐酸、硫酸、氯化锌碘、苏丹Ⅲ等）具腐蚀性或毒性，操作须在通风条件下由受训人员按实验室安全规范进行，本章不提供操作步骤。实际检验以现行版《中国药典》该品种显微鉴别项与四部通则为准；具体操作以现行规范与所在机构制度为准。
