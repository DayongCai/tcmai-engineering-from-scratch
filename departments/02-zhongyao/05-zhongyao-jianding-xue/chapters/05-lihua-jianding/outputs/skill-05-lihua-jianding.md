# 同一块板上的对照，比任何绝对数值都硬

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 多项联测、交叉验证
- 供试液的制备
- 同时设空白对照与阳性对照，试剂现配，显色在规定时间内观察并记录
- 同板、同法、同显色，斑点位置相当、颜色与荧光一致
- 在出数据之前先证明这套系统今天能用
- 只看单一指标

## 边界

- **理化强在成分，弱在身份。** 成分相同不等于基原相同，不同种可能含同一成分；理化结论必须与基原、性状、显微互证，不能单点定案。
- **方法参数比限度更容易过时。** 通则编号、色谱柱型号、展开剂配比随版本与耗材变化；本章只写方法结构，具体参数以现行版药典通则与该方法验证报告为准。
- **本章不抄任何含量限度。** 含量测定的限度随品种与版本调整，抄进教学稿就会过期，也会被误当成判定依据；需要数值时查现行版药典该品种正文。
- 本章为中药鉴定学教学材料，讲理化鉴定的常数、反应、色谱与记录结构，不构成任何药材的检验结论或用药建议。文中所述试剂（碘化铋钾、三氯化铁、浓硫酸、茚三酮等）与有机溶剂具腐蚀性、毒性与挥发性，操作须在通风条件下由受训人员按实验室安全规范进行，废液集中处理。
