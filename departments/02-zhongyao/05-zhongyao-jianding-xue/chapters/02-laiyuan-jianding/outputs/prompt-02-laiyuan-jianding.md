# 学名错一个属，整批性状描述跟着作废 · 提示词

## 用途

给「学名错一个属，整批性状描述跟着作废」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「为什么它必须排在第一道 → 野外与标本：把一次观察变成可复查的证据 → 检索与学名：成组判据与「不成立」的条件【教学设定】 → 记录字段、四种失效与考核项」这条链。

## 提示词

```
我在学《中药鉴定学》第 2 章「学名错一个属，整批性状描述跟着作废」，本章 5 节 / 3,115 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 它错了，后面全部失效
   - ，隔夜萎蔫变形，花冠形状与颜色就没了；压制初期
   - 从第 1 条起，不跳条

   - 学名要写到命名人
   - 命名法规的三条原则
4. 本章自陈的边界（不得越过）：
   - **分类学在动，学名就会动。** 本章以药典来源项为锚，是因为它是法定的；但药典本身也随版本修订。凡引学名，须同时给出所依版本，否则「学名对了」这句话没有确定含义。
   - **形态定名有天花板。** 近缘种、碎片、粉末、以及只经过初加工的样品，形态证据不足以定种；此时应转入显微或分子方法，而不是把形态结论说得更肯定。
   - **本章不含药用部位之外的采收加工判据。** 采收时节、干燥方式影响质量，但那属于栽培与加工章节的范围；本章只把「基原、部位、加工三者一致」作为来源项的完整性要求提出。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为中药鉴定学教学材料，讲基原鉴定的观察、检索、命名与记录方法，不构成任何物种的鉴定结论或用药建议。文中所举药材与学名仅用于说明判据，实际鉴定须以现行版《中国药典》来源项为准，并依《国际藻类、真菌、植物命名法规》核对学名。野外采集须遵守野生植物保护与濒危物种管理的规定，不得滥采；具体操作以现行规范与所在机构制度为准。
