# 资料不是把证据摞高，是让陌生人半小时内看懂证据到哪一步 · 提示词

## 用途

给「资料不是把证据摞高，是让陌生人半小时内看懂证据到哪一步」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「学习目标 → 正文 → 考核与自检 → 运行与验证」这条链。

## 提示词

```
我在学《中药新药研发》第 7 章「资料不是把证据摞高，是让陌生人半小时内看懂证据到哪一步」，本章 4 节 / 3,067 汉字，习题 8 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 不引页码、不引版次
   - 你做了什么、依据什么标准判断、结论的适用范围到哪里
   - 规则一：每个结论后面跟一个数据或一条依据
   - 规则二：任何"不得检出""符合规定"都要写明方法、检出限与取样量
   - 未做的研究
   - 只写结果不写变更，读者无法判断前后数据是否在同一体系下产生
4. 本章自陈的边界（不得越过）：
   - **WHO 文件不是申报格式。** 本章的结构与写法是通用逻辑；中国的注册分类、申报资料项目与格式、受理与审评程序另有规定，据本章内容直接组卷属于误用。
   - **不给模板条款。** 本章不写任何具体的资料章节编号、字数要求与格式规范——这些以现行申报要求为准。
   - **数字与情形是教学设定。** 文中"三大本""半小时""三批"等只用于说明判据方向，不是实测数据，也不对应任何真实受理案例。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，不构成医学意见、诊断或用药指导，也不构成注册申报建议。任何在研品种的申报策略、资料组织与变更评估，须由具备资质的专业人员依现行法规、技术指导原则与机构制度决定；具体操作以现行规范与所在机构制度为准。
