## 一、这一章的问题

先立框架：中药新药不是「做一个药」，而是「把一条质量—安全证据链做实」。本章走的是中药新药研发的固定链：**源头 → 生产 → 质量 → 安全 → 上市后监测 → 注册资料 → 产业化移交**。链上每一环都有它的判据：前一环答不上来，后一环就只能照着做而不知道为什么。

## 三、逐单元读

### 1.1 1.1 研发路径与证据链：从药材到上市

1. 说明研发路径与证据链：从药材到上市这一段在证据链上的位置与它负责回答的问题。 2. 写出本段的最小可交付（一张表、一份记录或一组参数）。 3. 指出本段最常见的三类错误。 4. 说明本段的证据来源与适用边界。 中药新药研发的起点是一个容易说错的问题：它到底在研什么。是把一个方子做成制剂，还是把一味药材的质量讲清楚？ 正确的答案是：**两者是同一条证据链的两端**——源头讲不清，制剂再好也只能证明「这批做得好」；制剂不放大，源头再规范也进不了临床。 **这条链有五段**：源头（药材）→ 生产（工艺）→ 质量（标准）→ 安全（毒理与临床）→ 上市后（监测）。 五段的分工很清楚：前两段决定「能不能稳定做出来」，第三段决定「凭什么说这批和那批一样」， 第四段决定「能不能用在人身上」，第五段决定「用久了会不会出事」。 **中药的特殊困难在于「质量」这一段的定义。** 化学药可以指着单一成分说「就是这个」； 中药是多成分体系，同一味药不同产地、不同采收期、不同炮制法的成分谱都不同。 所以中药质量控制不能用「一个含量」解决，必须用**一组指标 + 一个可比的图谱**。 **研发最容易犯的错，是把顺序做反**：先做工艺、再想标准，最后补安全性。 正确的顺序反过来——**先定质量指标，再定工艺参数，最后用安全性数据回头验证**。 顺序反了，前面所有数据在新标准下都要重做。 **本章要建立的判断力**：看到一份中药新药资料，能立刻定位它缺的是哪一段证据。 这比记住任何一条技术指导原则都重要，因为指导原则会改版，证据链的结构不会。 **三类常见错误与自查** ① **把「做成制剂」当研发**：只报工艺与成型结果，不回答质量与安全性问题。自查：你的资料能不能独立支撑「质量可控、安全可用」两句话？ ② **顺序做反**：先做小试、再补标准、最后补毒理，结果每次补证都要回头改工艺。自查：质量标准是不是在工艺定型前就已经写好？ ③ **证据链断在中间**：源头有记录、生产有验证，但两者之间没有衔接（比如药材批号与投料批号对不上）。
