# 中西药联用禁忌 · 提示词

## 用途

给「中西药联用禁忌」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「七情与配伍理论 → 君臣佐使与组方 → 十八反与十九畏 → 妊娠与哺乳期禁忌 → 证候禁忌 → 中西药联用禁忌 → 毒性药的配伍 → 配伍研究的证据方法」这条链。
