# 中西药联用的风险多半不在成分，而在同一套代谢通道

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 第一层，胃肠道里的结合
- 这一层的处置最干净——错开时间即可，不必停任何一方
- 第二层，代谢酶上的相遇
- 剂量与时长决定一切
- 第三层，效应上的叠加
- 这一层的判据是「方向是否同向」，与性味寒热无关

## 边界

- **本章只到机制层面，不给风险数值。** 底本对相互作用的表述限于「可能影响」「可增加风险」「有报道」；本章不提供发生率、倍数、血药浓度阈值一类数字。凡需定量判断，以药品说明书、药物警戒通报与治疗药物监测结果为准。
- **本章不替代说明书与处方权。** 四层通道是核对框架，不是处置授权；具体取舍由执业医师与药师决定，涉及抗凝、降糖、降压、免疫抑制等治疗时尤须如此。
- **「未查」与「无」必须分开记录。** 这是本章在记录层面唯一的硬要求，也是全章判据能否被复核的前提。
- 本章讨论中西药联用的相互作用层次与核对方法，不构成用药建议，不含任何药物组合的推荐或否定结论。
