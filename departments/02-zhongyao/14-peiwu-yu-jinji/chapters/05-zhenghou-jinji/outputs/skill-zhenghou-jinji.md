# 证候禁忌的错法只有一种：把药性当成了药理作用

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 禁忌就是这两个变量取同号时的情形
- 证的寒热是可观察的
- 药的寒热是有出处的
- 把药性当作可质疑的条目去查，而不是当口头常识用，是这一章的第一个动作
- 病名不等于证名
- 病名给的是范围，证候给的才是用法

## 边界

- **本章给的是对撞判据，不是证的诊断标准。** 观察项来自教材条目，本章不替代四诊合参与辨证结论；证的属性由执业中医师判定。
- **药性取值以药典与教材为准。** 文中所引性味归经出自底本单元，未作改动；凡遇版本差异，以现行《中国药典》与所用教材为准。
- **排查项不是诊断清单。** 收涩药一节列出的排查方向只说明「治标先辨因」的必要性，不是诊断建议；相关检查由临床医师决定。
- 本章讨论证候禁忌的判据结构，不构成诊断或用药建议，不含任何适应证下的处方与剂量。
