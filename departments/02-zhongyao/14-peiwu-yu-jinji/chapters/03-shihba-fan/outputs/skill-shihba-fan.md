# 十八反十九畏是两张不同性质的清单，不能合并背诵

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 名同实异，是这两张清单最容易合错的接口
- 两个方向都不轻，所以两张清单必须分开记、分开处置
- 以歌诀所列为准，不以数字为据
- 九对与「十九」之间也没有算术关系
- 结构不同，记忆单位就该不同——这是「不能合并背诵」的技术理由，不是修辞
- 甘草与甘遂

## 边界

- **本章不裁断数字之争。** 「十八反」的名与十五对药之间的差数历代解释不一；本章只给用法，不给史料结论。
- **本章不引毒理数值。** 底本对现代研究的表述是「认识不一」「结果不一」，本章照此转述，不给半数致死量、不给含量限度、不给「增毒几倍」一类数字。凡需要定量判断的，以现行药典与法定检验报告为准。
- **清单不是安全边界，只是被记载过的边界。** 表外组合没有「反」这个名分，只说明没被这张表管到——第八章讨论这句话在证据层面意味着什么。
- 本章讨论十八反、十九畏两张清单的性质、数目与处置差异，不构成用药建议。
