# 君臣佐使分的是责任，不是药味的等级

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 7 道题自检，答不上就回到对应小节。

## 核心判据

- 这两处都不是给药味评等级，而是给一张方定编制
- 以分量定位次
- 以价格定位次
- 以药味数定位次
- 位次齐不齐，看的是职责有没有落空，不是看数字对不对
- 第一问，这一次的主目标能不能一句话说完

## 边界

- **本章给的是位次的判据，不是组方模板。** 具体方剂的君臣佐使，历代注家互有出入；本章只用四逆汤、左金丸、白虎汤一类结构公认清楚的方作例，不替任何一方下唯一结论。
- **剂量只给红线，不给治疗量。** 马钱子 0.3–0.6g、制川乌 1.5–3g 是限度值：前者底本与药典同数，后者以药典的制川乌条目为准（底本作「川乌 3–9g 先煎」，未分生制）。两条都用来说明「位次不能豁免剂量红线」；本章不提供任何适应证下的具体处方量。
- **清单只到接口，不到条目。** 十八反、十九畏的条目、数目与处置差异，下一章逐条对；本章引用它们，只为说明清单是最后一道闸。
- 本章讨论君臣佐使的判定方法与剂量红线的位置，不构成处方建议，不含任何适应证下的用药方案。
