# 眼睛先看，显微镜只回答眼睛答不了的那一问 · 提示词

## 用途

给「眼睛先看，显微镜只回答眼睛答不了的那一问」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「入岗三问：上实验台之前先答 → 操作判据：性状成立与显微成立，各要什么【教学设定】 → 交接与复核：四道关，一道都不能省 → 记录字段：让复核人只凭纸就能重做」这条链。

## 提示词

```
我在学《中药专业实践》第 2 章「眼睛先看，显微镜只回答眼睛答不了的那一问」，本章 6 节 / 3,122 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 底本与引法
   - 第一问：我鉴的是哪一批、哪一层
   - 第二问：我先用哪一路，为什么
   - 第三问：这一次，什么结果会让我改判
   - 性状判据是「七项齐全 + 一项排他」
   - 显微判据是「层次 + 后含物 + 排他」三层，缺一层不算成片
4. 本章自陈的边界（不得越过）：
   - **本章给的是判据与动作，不是判定权限。** 课堂判据用于训练一致性，真实检验以法定标准、检验方法与机构资质为准。
   - **感官与形态的结论有其不确定度。** 性状受干燥度、产地加工、贮存时间影响，显微受切片质量与取材部位影响；本章不承诺「一眼定真伪」，只要求「每条结论有可比对的依据」。
   - **数值缺位是事实，不是缺陷。** 本章八节无数值命中，说明这部分知识以形态与相对比较为主；需要量化时（水分、灰分、浸出物、含量），方法学归入检验与分析的专门章节，不在本章补写。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，不构成药品检验结论、质量判定或诊疗意见；具体操作以现行规范与所在机构制度为准。
