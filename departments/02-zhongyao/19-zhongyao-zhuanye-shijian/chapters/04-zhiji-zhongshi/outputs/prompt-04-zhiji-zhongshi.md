# 中试不是把小试放大十倍，是证明同一处方在两套设备上做出同一个产品 · 提示词

## 用途

给「中试不是把小试放大十倍，是证明同一处方在两套设备上做出同一个产品」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「中试要回答三个"一致"，设备不同不是理由 → 浸出这一段：四个阶段，一个关键变量 → 成型这一段：辅料不是填充物，四个关口逐个过 → 放大的算术：三处必重算，一张对照表」这条链。

```

正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。
```

## 边界

本章为教学材料，不构成药品生产工艺指令、质量判定或用药建议。任何品种的中试放大、工艺验证与放行，须由具备资质的专业人员依现行药典、技术指导原则与机构制度执行；具体操作以现行规范与所在机构制度为准。
