# 车间里没有「炒熟了」，只有炒到哪一步必须停 · 提示词

## 用途

给「车间里没有「炒熟了」，只有炒到哪一步必须停」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「进车间先认三张纸，认不全就不要动手 → 一个工序的质控点只有三类 → 清炒：停点靠断面判，不靠表面 → 加辅料炒：辅料既是传热介质，也是剂量」这条链。

## 边界

本章为教学材料，不构成药品质量判定、工艺放行或诊疗意见；具体操作以现行规范与所在机构制度为准。
