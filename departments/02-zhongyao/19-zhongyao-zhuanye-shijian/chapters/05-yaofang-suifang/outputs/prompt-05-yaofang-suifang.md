# 随访问不出"怎么煎的、怎么吃的"，疗效与不良反应都无从归因 · 提示词

## 用途

给「随访问不出"怎么煎的、怎么吃的"，疗效与不良反应都无从归因」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「发药窗口的三问：谁吃、怎么吃、吃到哪一天 → 煎服法是疗效的一部分：器具、火候、六类特殊煎法 → 随访记录：五个字段，缺一个就无法归因 → 边界：药师能给什么，不能给什么」这条链。

## 边界

本章为中药专业实践教学材料，不构成医学意见、诊断或用药指导。文中所有剂量、煎法与时限仅用于说明判据方向；具体操作以现行规范与所在机构制度为准。
