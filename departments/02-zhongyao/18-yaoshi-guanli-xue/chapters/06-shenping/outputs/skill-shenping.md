# 审评结论要能被换一组人复核，做不到多半是推理链没写出来

需要把本章的判断讲清、或检验自己是否讲清时。

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 没有任何一个专业能单独判断一个药品该不该上市
- 单线审评最容易犯的错不是不专业，而是专业地看漏了另一条线
- 证书不是一张纸，而是一组被核准的参数
- 四条通道都只是把时间挪后，没有一条把证据要求降低
- 标准不因时限而变，时限不因程序而变
- 结论可复现

## 边界

- **本章讲审评的组织与结论结构，不涉及具体品种的技术审评。** 各专业的技术要求以现行指导原则为准，本章不引其编号。
- **四条通道的适用条件严格且会调整。** 本章只给通道之间的结构差异，不给资格判断；能否适用，须依现行文件与沟通结果确定。
- **「二元结论」是对综合审评结论的描述，不覆盖所有程序形态。** 附条件批准、优先审评等属于不同程序，其结论形态以现行规定为准。
- 药事管理专用：不构成法规解读与合规结论。本章为教学材料，条文转述仅供理解审评组织与结论形成的结构。
