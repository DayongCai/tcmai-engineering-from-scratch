# 加快通道换的是证据的时间表，不是证据的门槛 · 提示词

## 用途

给「加快通道换的是证据的时间表，不是证据的门槛」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「四种通道的同一个结构：把证据挪到上市之后 → 附条件批准：门槛写在情形里，不在期待里 → 第六十六条：那张欠条的条款 → 判断树：多数品种的答案在「否」的分支上」这条链。

## 边界

药事管理专用：不构成法规解读与合规结论。本章为教学材料，条文转述仅供理解加快通道的制度结构；具体操作以现行规范与所在机构制度为准。
