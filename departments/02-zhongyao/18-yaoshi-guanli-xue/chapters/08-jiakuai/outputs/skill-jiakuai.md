# 加快通道换的是证据的时间表，不是证据的门槛

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 只做第一个动作，是放水；只做第二个动作，是空话
- 四条通道没有一条降低证据要求，它们降低的是「什么时候交」
- 没有可用的治疗手段
- 紧急性可以触发程序，但不能替代评估
- 附条件不是「没有数据也能批」，而是「数据够预测、不够确证」
- 什么时候做

## 边界

- **本章讲通道的结构与判断顺序，不给资格认定的操作口径。** 各通道的具体技术要求、申报资料与沟通程序，以现行文件与技术指导原则为准，本章不引其编号。
- **期限不列数值。** 附条件批准的研究期限写在具体批准条件中，随品种而异，本章不作统一表述。
- **三种以上情形并存时如何取舍，本章不给答案。** 一个品种可能同时符合多项情形的部分要素，最终走哪条路径，取决于与审评机构的沟通结果与证据的实际成熟度。
- 药事管理专用：不构成法规解读与合规结论。本章为教学材料，条文转述仅供理解加快通道的制度结构。
