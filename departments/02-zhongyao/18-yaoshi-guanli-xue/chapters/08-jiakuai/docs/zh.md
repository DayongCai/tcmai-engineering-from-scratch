# 第 8 章 · 加快通道换的是证据的时间表，不是证据的门槛

> **MOTTO:** 「其进锐者，其退速。」——《孟子·尽心上》
>
> **PROBLEM:** 同一条审评线，常规程序与加快通道的差别常被说成「快慢」，于是被理解成「排队靠前」。但第六十三条把附条件批准的适用情形限死在三种，第六十六条又给批准加上期限与注销风险——一条能加速的通道，同时也是一条能被撤回的通道。企业争的是前一半，制度写的是后一半。这两半为什么必须绑在一起？
>
> **双根因定位:** 环境逼迫（严重危及生命的疾病等不起完整的三期确证，等待本身就是一种损害，制度必须在「证据完整」与「可及性」之间作一次有时间限制的交换）＋ 知识积累（把「加快」理解成行政效率而非证据安排，于是把通道当成一种资格去争取，而不是把剩余证据当成一笔有期限的债去偿还）

**教材出处:** 外源课（无教材）。条文原文逐字校录自 `standards/yaoshi-guanli/sources/`（六份规范原件）；单元底本为 `standards/yaoshi-guanli/units.json` 第 8 章（1 单元，1,112 汉字）。本章不引教材页码，条文含义以现行法规原文为准。

## 一、四种通道的同一个结构：把证据挪到上市之后

加快通道有四种常见形态：突破性治疗药物程序、附条件批准、优先审评审批、特别审批。名字不同，机制其实只有一句话——

> **对未满足的临床需求，允许用更少的前期证据换取更早的可及性，但把剩余证据变成上市后的强制义务。**

这句话里有两个动作，缺一不可。第一个动作是「减」：上市前不要求证据齐备。第二个动作是「加」：把没交的那部分变成上市后必须完成的义务，并且是可追责的义务。**只做第一个动作，是放水；只做第二个动作，是空话。** 制度的分量全在两个动作的绑定上。

四种通道各自挪动的位置不同，但都不改变一个事实：证据的总量没有减少。

| 通道 | 挪动的是 | 留下的义务 |
|---|---|---|
| 突破性治疗药物 | 沟通与数据提交的时点 | 更早、更频繁地交出阶段性数据 |
| 附条件批准 | 确证性研究的位置（上市前 → 上市后） | 期限内完成承诺的研究，并采取风险管理措施 |
| 优先审评审批 | 排队与审评资源配置 | 资格须持续满足，否则退出该通道 |
| 特别审批 | 特定情形下的程序顺序 | 适用范围严格，情形消失后回归常规 |

读这张表要读最后一列。**四条通道没有一条降低证据要求，它们降低的是「什么时候交」。** 把加快理解成「要求变松」，是本章要拆掉的第一个误解。

## 二、附条件批准：门槛写在情形里，不在期待里

第六十三条把可以申请附条件批准的情形写成三项：

1. 治疗严重危及生命且尚无有效治疗手段的疾病的药品，药物临床试验已有数据证实疗效并能预测其临床价值；
2. 公共卫生方面急需的药品，药物临床试验已有数据显示疗效并能预测其临床价值；
3. 应对重大突发公共卫生事件急需的疫苗，或者国家卫生健康委员会认定急需的其他疫苗，经评估获益大于风险的。

三项情形各有一组限定词，而这些限定词是并联的，不是可以任选其一的加分项。以第一项为例：「严重危及生命」与「尚无有效治疗手段」必须同时成立，并且还要加上「已有数据证实疗效并能预测其临床价值」。

「尚无有效治疗手段」这半句最容易被读松。它的意思不是「现有治疗效果不够好」，而是**没有可用的治疗手段**。如果某个疾病已有标准治疗，只是疗效有限、副作用明显，那属于「未满足的临床需求」，可以争取别的通道，但不构成附条件批准的情形。把「现有治疗不理想」讲成「无有效手段」，在审评中会被直接问回来，因为这句话是可以被核对的事实主张，不是价值判断。

第三项还多了一道程序性限定：疫苗要「经评估获益大于风险」。这一句把判断权明确交给了评估，而不是交给紧急性本身。**紧急性可以触发程序，但不能替代评估。**

三項情形之外还有一层共同要求，写在「已有数据」「数据显示」这类措辞里：申请附条件批准的时点，必须在临床试验已经产出可用数据之后。**附条件不是「没有数据也能批」，而是「数据够预测、不够确证」。** 这一条区分了两种完全不同的申请：手里有早期疗效信号、想提前上市；和手里只有机制假说、想先拿批件再补数据。后者不属于附条件批准。

## 三、第六十六条：那张欠条的条款

如果只有第六十三条，附条件批准就是一次单向的松绑。第六十六条把它变成一笔债。

条文规定：对附条件批准的药品，持有人应当在药品上市后采取相应的风险管理措施，并在规定期限内按照要求完成药物临床试验等相关研究，以补充申请方式申报；对批准疫苗注册申请时提出进一步研究要求的，疫苗持有人应当在规定期限内完成研究。

这一句里有四个可执行的点，每一个都能被检查：

- **谁来做。** 持有人，不是研究者，不是受托生产企业。义务主体与批准主体是同一个法律人格。
- **做什么。** 两件事并列：采取风险管理措施，完成承诺的研究。只做研究不做风险管理，不算履行。
- **什么时候做。** 规定期限内。期限写在批准条件里，不写在企业的计划里。
- **怎么交。** 以补充申请方式申报。这一条最技术，也最容易被忽略：研究做完了不等于义务完成，**结果必须以补充申请的形式进入注册档案，才构成履行**。做完不报，在制度上等于没做。

违反的后果，单元的表述很克制但方向明确：逾期未完成，或者不能证明获益大于风险的，注册证书可能被注销。

「不能证明获益大于风险」这一句值得单独看。它说的不是「研究没做完」，而是「做完了却证不出来」。附条件批准的前提是一个预测——预测这个药最终会被证明有效。预测错了，制度给的出路不是继续挂着，而是退出。**这是附条件批准与常规批准最本质的差别：常规批准的证据是既成的，附条件批准的证据是待兑现的。**

所以「附条件批准 = 胜利」是想反了。它更接近**一份带期限的欠条**：欠的是证据，逾期要还，还不上要收回。企业真正该算的账不是「拿到了没有」，而是「期限内做不做得完、做完了证不证得出」。

## 四、判断树：多数品种的答案在「否」的分支上

通道选择不该凭感觉，可以走成一棵判断树。

**第一问：疾病是否严重危及生命、且尚无有效治疗手段？** 是 → 附条件批准与突破性治疗可能同时适用；否 → 进入第二问。

**第二问：是否属于未满足的临床需求、且疗效有显著改善？** 是 → 优先审评审批；否 → 常规程序。

**第三问：是否属于特别情形（如突发公共卫生事件急需）？** 是 → 特别审批；否 → 常规程序。

这棵树的关键不在「是」的分支，在「否」的分支——**绝大多数品种走的是常规程序**。这不是坏消息。常规程序一样能获批，只是按常规时限走；而加快通道的资格门槛，本身就要求证据成熟到某个程度。一个证据还不成熟的品种，即便挤进通道，也会在审评中被要求补回缺的那部分，时间并不会省下来。

树还有一条隐含规则：三问是串联的，不是并列的。疾病是否严重，决定了能不能谈附条件；临床需求是否未满足、疗效是否有显著改善，决定了能不能谈优先；特别情形是外部事件触发的，与品种自身的证据水平无关。**把三问当成三个可叠加的加分项，是通道选择里最常见的结构性错误。**

企业最容易犯的错，是先想拿通道、再找理由：把「我们觉得这个药很有价值」讲成「未满足的临床需求」，把「竞品疗效一般」讲成「尚无有效治疗手段」。这类说法在申报材料里站不住，因为它们都是可以被核对的事实主张。**通道给的是证据方向的优惠，不是给期望值的优惠。**

反过来的错误也存在：明明符合情形却不敢申请。附条件批准不是「降格批准」，它是一条正式路径，第六十三条给了它明确的入口，第六十六条给了它明确的出口。符合情形而不申请，只是把可及性推迟了几年；这在一个没有替代手段的疾病里，是一个实质性的代价。

## 五、把通道读成三句话

看到任何一条加快通道，能立刻说出三件事，才算理解它：

1. **它换掉了哪部分证据。** 是确证性研究的位置，还是沟通的时点，还是排队顺序。
2. **它要求补什么。** 补的是研究、是数据、是风险管理措施，还是持续的资格证明。
3. **补不上会怎样。** 这一问最容易被跳过，而它恰恰是通道之所以成立的根据。

**答不出第三问，就不算理解这条通道。** 因为第三问决定了这条通道是「优惠」还是「交换」——而制度设计的是交换。一个只知道自己拿到了什么、不知道自己要付什么的团队，通常会在上市后第一年就把欠条拖成逾期。

判断树与三句话合起来，构成本章的判据：**通道不是身份，是一组附条件的安排。** 身份可以一直挂着，安排必须按期结清。

## 代价与边界

- **本章讲通道的结构与判断顺序，不给资格认定的操作口径。** 各通道的具体技术要求、申报资料与沟通程序，以现行文件与技术指导原则为准，本章不引其编号。
- **期限不列数值。** 附条件批准的研究期限写在具体批准条件中，随品种而异，本章不作统一表述。
- **三种以上情形并存时如何取舍，本章不给答案。** 一个品种可能同时符合多项情形的部分要素，最终走哪条路径，取决于与审评机构的沟通结果与证据的实际成熟度。
- **不评价任何具体品种的通道适用。** 本章的例子都是结构性的，不含可定位的真实品种。
- **条文引自 2020 年版注册管理办法。** 本章只引用第六十三条与第六十六条两条；注销等后果的完整规定在办法其他条款与《药品管理法》中，本章不展开。
