# 追溯的判据不是上了系统，是能从患者倒走回投料批 · 提示词

## 用途

给「追溯的判据不是上了系统，是能从患者倒走回投料批」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「追溯要回答的是四个问题 → 三件事合起来才叫追溯 → 「互通互享」针对的是各自为政 → 追溯的精度决定召回的范围」这条链。

## 边界

药事管理专用：不构成法规解读与合规结论。本章为教学材料，条文转述仅供理解追溯制度的判据结构；具体操作以现行规范与所在机构制度为准。
