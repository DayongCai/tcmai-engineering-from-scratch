# 条例的增量写在三处：不能做、可以不罚、做了有奖 · 提示词

## 用途

给「条例的增量写在三处：不能做、可以不罚、做了有奖」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「判据先立：什么叫「增量」 → 委托：红线画在「风险集中、追溯困难」处 → 网络销售：不靠解释，靠名单 → 免责：免责于处罚，不免责于损害」这条链。

## 边界

本章为教学材料，不构成法规解读与合规结论。条文转述仅供理解《实施条例》相对法律的增量；具体操作以现行规范与所在机构制度为准。
