# 管辖判断在合规动作之前，定错管辖则后面全部白做 · 提示词

## 用途

给「管辖判断在合规动作之前，定错管辖则后面全部白做」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「三个要件：用途、作用、形式，缺一不成立 → 「人的疾病」这条限定有多硬 → 宣称决定管辖：为什么改包装文案不是小事 → 适用范围管的是「活动」，不是「物」」这条链。

## 边界

药事管理专用：不构成法规解读与合规结论。本章为教学材料，条文转述仅供理解药品定义与适用范围的判断结构；具体操作以现行规范与所在机构制度为准。
