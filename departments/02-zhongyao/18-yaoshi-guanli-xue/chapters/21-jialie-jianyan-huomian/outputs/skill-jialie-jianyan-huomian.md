# 假劣药的认定靠证据链，检验只是链上的一环

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 回答「属于哪一类」
- 可操作的入口
- 每一项都是「标示」与「实际」的比对
- 举证成本下降，认定标准上移
- 细化不等于扩大
- 标注是承诺，成份是履行

## 边界

- **本章讲认定路径，不给个案定性结论。** 某一批药品属于假药还是劣药，须依其标示、实物与记录综合判断；本章只提供条文之间的分工关系，不替代执法判断。
- **条文引自 2019 年《药品管理法》与 2026 年《实施条例》。** 本章只展开第六十七条、第六十九条、第七十一条、第七十二条与第九十八条的关系；处罚幅度、刑事责任与程序规则分布在其他条款，本章不涉及。
- **补充检验方法的批准目录不在本章展开。** 具体哪些品种已有补充方法，以监管部门公布的目录为准，本章不列举。
- 本章为教学材料，不构成法规解读与合规结论。条文转述仅供理解假劣药认定中的举证分工。
