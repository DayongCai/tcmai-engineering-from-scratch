# 核查与检验的价值不在补充材料，而在让纸面证据可被推翻 · 提示词

## 用途

给「核查与检验的价值不在补充材料，而在让纸面证据可被推翻」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「审评听的是陈述，核查与检验要的是举证 → 核查查四件事，第四件最容易被低估 → 检验的两段：先评尺子，再量样品 → 启动权与实施权分开：一个容易被忽略的制度设计」这条链。

## 边界

药事管理专用：不构成法规解读与合规结论。本章为教学材料，条文转述仅供理解核查与检验的制度位置；具体操作以现行规范与所在机构制度为准。
