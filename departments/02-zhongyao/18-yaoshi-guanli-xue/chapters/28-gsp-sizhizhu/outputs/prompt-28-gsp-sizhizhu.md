# 经营环节的质量不是造出来的，是四个支点各防一种错 · 提示词

## 用途

给「经营环节的质量不是造出来的，是四个支点各防一种错」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「四个支点，各防一种错 → 支点一：逐批验收，「逐批」二字排除了抽批的侥幸 → 支点二：储存定条件，养护定持续 → 支点三：记录的价值是让倒查成为可能」这条链。
