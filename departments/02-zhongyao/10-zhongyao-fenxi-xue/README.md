## 一、学科定位

中药分析学（TCM Analysis）是中药系的核心学科，聚焦「本草、方剂与中药全产业链：资源—鉴定—化学—药理—制剂」中的一个完整知识域。

## 二、中医 → AI 桥梁

```text
指纹图谱→降维与相似度 / 光谱数据→PLS 回归
```

中药分析学 里的每一个传统概念，都被翻译成一个可计算、可验证的工程对象：
中医概念给出**语义与约束**，AI/工程方法给出**表示与算法**。两者必须能互相回指，
否则这个章节就还没有写完。

**口径**

1. **三辨＝样品处理／测定条件／数据与限度**，实测 **1556 / 460 / 2560**，比值 **5.6×**——**「测定条件」只有「数据与限度」的 1/5**。教材大篇幅写「测什么、怎么算、限在哪」，仪器参数则留给药典通则；
2. **四位面取分析目的**（鉴别 838 / 检查 915 / 含量测定 1213 / 指纹图谱 554，**2.2×**）。它与教材 04–07 章顺序同构，也是分析工作的四种目的；
3. **方法类别 5.0× 未取**：色谱一词贯穿全书（薄层、液相、气相都算），属词根通胀；**样品类型 23.6× 未取**：「过程与标准」一格吞下标准、验证、规范、数据全部内容，是分类错误而非偏好。

**数值命中 45 处**（较前几门高）：分析课天然带数——流速、柱温、波长、限度值、RSD。这与《中药鉴定学》（7 处）形成对照：**能不能写成数，取决于学科对象**。

**跨课对账（与《中药化学》）**：9 类成分 → 方法可查 **8（0.889）**、仅提名 1（萜类，分析课里以「挥发油」形态出现）、未覆盖 0。
**首版曾得 100%，因方法词用了「测定/检测」这类泛词，改严后降到 0.889** —— 这个下降过程写进了第 8 章正文。
