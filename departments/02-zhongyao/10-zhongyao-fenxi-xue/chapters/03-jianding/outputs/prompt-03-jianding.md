# 四类鉴别不是替代关系，是四种不同的覆盖面 · 提示词

## 用途

给「四类鉴别不是替代关系，是四种不同的覆盖面」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「性状：最快、最便宜，也最不经加工 → 显微：加工之后唯一还认得出的结构 → 理化：一类成分一个反应，专属性有限 → 色谱、光谱与分子：从「有没有」到「是不是这个种」」这条链。

4. 本章自陈的边界（不得越过）：

## 边界

本章为中药分析学教学材料，讲的是中药鉴别方法的分层、判据与边界。文中的显色反应、光谱波长、色谱条件与分子标记，均取自教材《中药分析学》第4章与《中国药典》相关通则的表述；具体操作以现行规范与所在机构制度为准。
