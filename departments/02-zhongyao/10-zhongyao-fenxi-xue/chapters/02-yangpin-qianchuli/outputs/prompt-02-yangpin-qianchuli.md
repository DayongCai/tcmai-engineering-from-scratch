# 取样定上限，前处理定下限，两者都不能靠事后补 · 提示词

## 用途

给「取样定上限，前处理定下限，两者都不能靠事后补」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「六个环节，两处不可逆 → 取样：三条原则，一道算术 → 粉碎、过筛与称量：粒度会进入结果 → 提取与净化：一笔回收率的账」这条链。

## 提示词

```
我在学《中药分析学》第 2 章「取样定上限，前处理定下限，两者都不能靠事后补」，本章 5 节 / 4,049 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 取样错，后面全错，而且看不出来
   - 前处理错，回收率会告诉你
   - 抽样件数按件计，不按重量计
   - 代表性是概率问题，不是「取中间那包」
   - 粒度对结果有方向性影响
   - 本章的 105℃、5 h、5 mg、六等粉末与筛孔数值
4. 本章自陈的边界（不得越过）：
   - **抽样件数按件计，不按重量计。** 一件 50 kg 与一件 5 kg 在规则里是同一个「件」，所以大批量、机械化包装的样品要结合生产批号与包装顺序分层随机，规则本身不替你解决分层。
   - **代表性是概率问题，不是「取中间那包」。** 抽样方案要写成文件：批的定义、抽样点数、每点取样量、混合与分样方法、不合格时的扩样规则。没有这份文件，换一个人取，结论可能不同，而差异会被记在仪器误差上。
   - **粒度对结果有方向性影响。** 偏粗则提取不完全、含量偏低；偏细则挥发损失、过滤困难；同一批样品前后两次用不同筛号，数据不可比。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为中药分析学教学材料，讲的是分析程序、取样与前处理的技术口径。文中的抽样件数规则、药筛号与粉末分等、干燥与称量的具体条件，均取自教材《中药分析学》第2、3章与《中国药典》通则的表述，属一般规定，具体品种以品种项下为准。本章不构成检验方法与限度标准，不替代法定标准与实验室质量体系文件；具体操作以现行规范与所在机构制度为准。
