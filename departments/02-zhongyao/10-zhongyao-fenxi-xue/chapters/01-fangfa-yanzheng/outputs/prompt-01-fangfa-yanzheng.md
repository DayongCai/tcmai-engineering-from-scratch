# 方法验证不是打勾表，是八个各自会失败的边界 · 提示词

## 用途

给「方法验证不是打勾表，是八个各自会失败的边界」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「精密度好，准确度不一定好 → 八个参数，各自对应一种失败 → 回收率：3×3＝9 份，加多少也有讲究 → 修约与报告：先修约，后比较」这条链。

## 提示词

```
我在学《中药分析学》第 1 章「方法验证不是打勾表，是八个各自会失败的边界」，本章 6 节 / 3,321 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 精密度好是准确度高的前提，精密度好不一定准确度高
   - 故意制造的扰动
   - 修约一次完成，不得连续修约
   - 验证证明的是「在受验范围内可用」
   - 98%～102% 是通则的一般要求，不是所有品种的通用门槛
   - 参数齐不等于方法对
4. 本章自陈的边界（不得越过）：
   - **验证证明的是「在受验范围内可用」**，不外推到别的基质、别的浓度、别的仪器。换一根不同品牌的色谱柱，耐用性数据要重做，不能引用原来的结论。
   - **98%～102% 是通则的一般要求，不是所有品种的通用门槛。** 基质复杂样品可放宽至 95%～105%，个别品种另有规定，引用时须同时说明依据。
   - **参数齐不等于方法对。** 八个参数各自回答一个问题，凑齐只说明问题都被问过，不说明答案都合格；把「项目齐全」当成「方法可靠」，是验证报告最常见的空转。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为中药分析学教学材料，讲的是方法学验证与数据处理的判定口径。文中的限度、回收率区间、修约规则与仪器参数，均取自教材《中药分析学》第11章与《中国药典》通则 9101 的表述；具体操作以现行规范与所在机构制度为准。
