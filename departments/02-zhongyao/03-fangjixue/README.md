## 一、学科定位

方剂学（TCM Formulary）是中药系的核心学科，聚焦「本草、方剂与中药全产业链：资源—鉴定—化学—药理—制剂」中的一个完整知识域。

## 二、中医 → AI 桥梁

```text
君臣佐使→缩放点积注意力 / 类方鉴别→对比学习
```

方剂学 里的每一个传统概念，都被翻译成一个可计算、可验证的工程对象：
中医概念给出**语义与约束**，AI/工程方法给出**表示与算法**。两者必须能互相回指，
否则这个章节就还没有写完。
