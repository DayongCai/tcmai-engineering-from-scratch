# guse-anshen

## 何时使用

- 要把「固涩 / 安神 / 开窍」三类方放在一条线上对照「收」与「开」的适应证
- 需要引用教材第13、14章的规模数字（27,100 字、7 节、54 段、9 方）
- 要判断 `formulas.json` 的组成与君臣佐使字段在固涩安神九方上是否可信

## 不适用

- 给具体方剂定量、定煎服法、定疗程
- 判断患者该收敛还是该开窍（须辨证）
- 统计全部固涩剂或全部安神剂（教材只收 4 + 5 首）
- 朱砂、雄黄、罂粟壳的安全性评价与替代建议

## 数据边界

```text
章：教材·第13章 固涩剂（12,028 字 / 3 节 / 4 方）+ 教材·第14章 安神剂与开窍剂（15,072 字 / 4 节 / 5 方）
合计：7 节 / 9 小节 / 54 段 / 27,100 字 / 9 方 · 占全书 358,800 字的 7.55%
每方：六段 · 2,981–3,125 字 · 每段 448–521 字
药位：75 / 去重 57 味 / 方均 8.3；高频 当归3 朱砂3 白术2
共用药：7 味（五味子、诃子、人参、白术、当归、木香、甘草）
回查：66/75 可在方解段逐字找到（88.0%）
角色：有君 9/9 · 三角色以上 3/9 · 四角色齐 0/9
引用：教材·第13章·13.1.1
```

## 步骤

1. **先报规模**：27,100 字 = 12,028 + 15,072；九方；占全书 7.55%。章节长短由方数决定，别当难度指标。
2. **再报结构**：九方是否都是六段（是）；每段字数 448–521，两章每段均字只差 1.2 字 → 编辑模板恒定。
3. **报组成与共用药**：75 药位 / 57 味 / 方均 8.3；两章共用药仅 7 味 → 「收」与「开」各成一套药。
4. **报回查率**：66/75；失配 9 个要分类——切分噪声（牡蛎散 2、金锁固精丸 1、朱砂安神丸 2）、异名或旧名（麦冬/麦门冬、真珠/珍珠、犀角/水牛角、熏陆香/乳香）。
5. **报角色并复核**：有君 9/9 但四角色齐 0/9；朱砂安神丸君臣同判，讲君药必回方解段。
6. **画边界**：要剂量、要辨证、要安全性评价的，一律转出本技能。

## 输出模板

```text
规模：2 章 / 7 节 / 9 小节 / 54 段 / 27,100 字 / 9 方（占全书 7.55%）
结构：六段/方，2,981–3,125 字/方，每段 448–521 字
组成：75 药位 / 57 味 / 方均 8.3；高频 当归3 朱砂3 白术2；共用药 7 味
回查：66/75（88.0%）；失配 9 个按性质分类
角色：有君 9/9 · 四角色齐 0/9；一处重判须复核
边界：不给剂量、不辨证、不评毒性；急救中成药按急诊规范
出处：教材·第13章·13.1–13.3、教材·第14章·14.1–14.4
```

## 质量判据

- 每个数字都能由 `node code/main.js` 现算复现，不手打
- 报「六段」时给出段名与字数区间，否则读者无法判断模板是否真的恒定
- 报「四角色齐 0/9」时必须同时说明这是抽取口径，不是教材缺失
- 报「共用药 7 味」时列出七味药名，别只说数字
- 引文只写「教材·第N章·N.M.K」，不写「底本」「原文」式标签

> 本技能只做教材结构清点，不构成诊断或用药依据。
