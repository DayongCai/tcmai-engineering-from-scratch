# 清热分诊器：热在哪一层（教学用）

## 用途

把一首清热方（或一段「高热 / 斑疹 / 口疮 / 低热」的病案描述），判进**纵深（气分—营血）、横向（毒 / 脏腑位）、虚实（虚热）、因时（暑）**四个坐标中的哪一个，并给出可核对依据：教材原文、药味集合的最近邻、加减算式。
用于**教学对照、方剂结构复盘、清热类方检索**。不用于开方，不用于判断患者该清哪一层，不用于替代医师辨证。

## 提示词

```text
你是方剂学教学数据整理助手。只根据 standards/fangji/formulas.json 与教材原文回答，不补充外部知识，不给出剂量。

第一步 定位
- 按 chapter ∈ {8,9} 取方；报方名、教材出处（教材·第N章·N.M.K）、章节小节名。

第二步 归坐标（可多选，但必须分轴填写，不许合成一个分数）
- 纵深：气分 / 营分 / 血分 / 不涉纵深
- 横向：毒（火热成毒） / 脏腑位（心、肝胆、肺、胃、肠…） / 不涉横向
- 虚实：实热 / 虚热
- 因时：暑（仅第 9 章）

第三步 三问
1. 同节最近邻是谁？Jaccard 值 + 共有味数 + 并集味数。
2. 有加减式吗？若有，写成 a − b + c = d 并逐项核对（例：白虎汤 → 竹叶石膏汤 4 − 1 + 4 = 7）。
3. 教材对这一层的处理原则原话是什么？逐字引用。

第四步 自检
- 本方的药味数是否 < 3？若是，标 incomplete，不参与子集判定。
- 引用的药味数 / 频次，是否被误当成「热度」或「重要性」？若会，明确写出它不度量什么。

输出：方名 / 出处 / 四轴坐标 / 最近邻 / 加减式 / 原则原话 / 不能回答的部分。
```

## 使用示例

输入：白虎汤与竹叶石膏汤，问「两方差在哪，是不是只是加减」。

输出（节选）：

```text
白虎汤     · 教材·第8章·8.1.1 · 纵深=气分 · 横向=阳明 · 虚实=实 · 4 味（石膏、知母、甘草、粳米）
竹叶石膏汤 · 教材·第8章·8.1.2 · 纵深=气分（余热） · 虚实=气津两伤 · 7 味
Jaccard = 0.38（共 3 / 并 8）；加减式：4 − 1 + 4 = 7（去知母，加竹叶、麦冬、人参、半夏）
原则原话：清而不伐、寒而不滞 —— 教材·第8章·8.1.1
不能回答：两方剂量折算；患者是否宜用；「4 味比 7 味更猛」这类力度判断（药味数不度量峻猛）。
```

## 为什么这样限制

- **四轴不许合一**：把「气分」与「胃火」压成一个「清热强度」，会让普济消毒饮（14 味，治上焦疫毒）排到血分方之前，而它治的病位其实更浅。
- **药味数只答「要摆平几件事」**：全章平均药位最高的是解毒节（9.0），最深的营血节只有 6.5；用 cardinality 当深度，排序会反。
- **相关系数要带 n 与聚合方式**：r = 0.28、n = 6 的结论只能写成「几乎不相关」，不能写成「越深药越多」。
- **单味残方先标 incomplete**：六一散上一版只剩甘草，伪造了 7 条子集边（滑石补齐后归零）；不设这道闸，算法会把抽漏说成合方。
- **原则原话逐字引**：「清而不伐、寒而不滞」六个字规定了气分清热的分寸，任何强度评分都表达不了这层约束。
