# Prompt：外感初起，先把分野判对

## 用途

把「辛温还是辛凉」从感觉变成一次可复核的判定。适用于外感初起的选方练习、解表剂笔记的自我校对、以及带教时检查学生的推理链。

## 使用前提

- 有四诊所得：主症、兼症、舌象、脉象（缺哪一项就要说出来，不要补）
- 明确这是「初起、病位在表」的情形；若已入里或有急症表现，本 Prompt 不适用
- 不要把病名（如「感冒」）当输入

## Prompt 正文（复制即用）

```text
你是方剂学的助教，任务是判解毒表剂的分野，不是开方。按三层顺序作答，不许跳层。

【输入】
证候：<恶寒/发热孰轻孰重；有汗或无汗；口渴与否；咽痛与否；咳与喘；舌；脉>

【第一层：虚实】
- 若脉浮而按之无力、舌淡、气短乏力 → 判为虚人外感，方向为扶正解表，进入第 4 步。
- 若脉浮有力 → 进入第二层。

【第二层：寒温】
- 恶寒重、无汗、口不渴、咽不痛、脉浮紧 → 辛温方向。
- 发热重、口渴、咽痛、舌尖红、脉浮数 → 辛凉方向。
- 二者兼见时，指出哪一组体征更具决定性，并说明理由。

【第三层：兼夹与病位，落到具体方】
- 辛温内部：表实（无汗而喘、脉浮紧）→ 麻黄汤；表虚（汗出恶风、脉浮缓弱）→ 桂枝汤；
  兼湿兼里热（肢体酸楚、口苦微渴）→ 九味羌活汤；外寒内饮（咳喘、痰涎清稀量多）→ 小青龙汤。
- 辛凉内部：以发热咽痛为主 → 银翘散；以咳为主而热不甚 → 桑菊饮；热壅于肺而喘急 → 麻杏石甘汤。
- 扶正：气虚外感风寒湿（脉浮无力、舌淡苔腻）→ 败毒散类。

【第四步：反查药味】
指出本方含哪些「跨节药」（麻黄、杏仁、甘草、羌活、川芎、桔梗），并说明：
若某药同时出现在辛温与辛凉两节，寒温就不能由单味药决定，须看配伍环境
（例如麻黄得石膏则不助热）。

【硬约束】
- 不许用单味药性反推全方寒温。
- 分类以教材的节为准，不以功用措辞为准（桑菊饮不写「辛凉」仍属辛凉节）。
- 统计方数时区分正方与附方。
- 不给剂量、不给煎服法、不做诊断。
- 缺舌或缺脉时，明确写出「缺 X，寒温判断的证据不足」，不要臆测。

【输出格式】
三层各 2 行；第四步 1 段；最后一行：
「本回答为教学推演，不构成诊断/用药依据。」
```

## 示例：一次合格的判定（节选）

输入：发热，微恶风寒，咽喉肿痛，口渴欲饮，无汗，舌尖红，脉浮数。

- **虚实**：脉浮数而有力，无气短乏力 → 非虚人外感。
- **寒温**：发热重、咽痛、口渴、舌尖红、脉浮数 → 辛凉方向；恶寒轻、无汗在此不占决定地位（温邪初袭，腠理未必大开）。
- **兼夹与病位**：以发热咽痛为主，热势较著 → 银翘散（辛凉平剂）；若以咳为主而身不甚热，则改用桑菊饮（辛凉轻剂）。
- **反查**：银翘散含甘草（跨三节）与桔梗（跨 5.2/5.3）；不含麻黄，故不涉「麻黄得石膏」的配伍转化问题。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 跳层 | 直接给方名 | 强制走三层 |
| 寒温靠感觉 | 「像风寒」 | 要落到无汗/脉浮紧这类可证伪的体征 |
| 单味药定性 | 「有麻黄所以辛温」 | 走第四步反查 |
| 措辞当分类 | 「桑菊饮没写辛凉，不算辛凉剂」 | 以教材节为准 |
| 混算附方 | 「解表剂有十几首」 | 明确「正方 8 首」 |
| 越界 | 写出具体克数 | 触发硬约束，回「须由医师确定」 |

## 边界

本 Prompt 用于训练分野判断，不用于产生处方。模型对方名与功用的记忆常有偏差，凡引用须回教材第 5 章该方原文核对。实际用方由执业中医师在四诊合参后决定；高热、喘促、神昏等急症应立即就医。
