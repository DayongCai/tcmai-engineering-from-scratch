# Skill：解表剂：辛温与辛凉的分野

## 何时用

- 遇到外感初起，需要在辛温、辛凉、扶正三类之间选方向（不是选方）
- 要在麻黄汤／桂枝汤、银翘散／桑菊饮／麻杏石甘汤之间做鉴别
- 要回答「为什么麻黄能出现在辛凉方里」这类问题
- 要审一份解表剂的笔记，看它是不是只背了标签

## 判据（先分层，再落方）

**第一层：虚实（决定是否扶正）**

- 脉浮而按之无力、舌淡苔腻、气短乏力 → 扶正解表（败毒散类）
- 脉浮有力、舌淡红苔薄白 → 进入第二层

**第二层：寒温（决定辛温还是辛凉）**

- 恶寒重、无汗、口不渴、咽不痛、脉浮紧 → 辛温
- 发热重、口渴、咽痛、舌尖红、脉浮数 → 辛凉

**第三层：兼夹与病位（决定选哪一首）**

| 情形 | 落方 |
|---|---|
| 无汗而喘、脉浮紧（表实） | 麻黄汤 |
| 汗出恶风、脉浮缓弱（表虚） | 桂枝汤 |
| 肢体酸楚、口苦微渴（风寒湿兼里热） | 九味羌活汤 |
| 咳喘、痰涎清稀量多（外寒内饮） | 小青龙汤 |
| 发热、咽痛、口渴（卫分，热势著） | 银翘散（辛凉平剂） |
| 但咳、身不甚热、微渴（肺络，热势轻） | 桑菊饮（辛凉轻剂） |
| 汗出而喘、身热不解（热壅于肺） | 麻杏石甘汤（辛凉重剂） |

## 执行步骤

```text
1. 抄体征：有汗/无汗、口渴/不渴、咽痛/不痛、舌、脉
2. 分层判：虚实 → 寒温 → 兼夹/病位（三层不许跳）
3. 落方，并说出「为何不是同层的另一首」
4. 反查药味：这首方里有没有跨节药（麻黄、杏仁、甘草、羌活、川芎、桔梗）？
   若有，说明它不是靠单味药定性，而是靠配伍环境
5. 声明边界：正方与附方分开算；剂量与煎服不在本判断内
```

## 硬约束

- **不许用单味药性反推全方寒温。** 麻黄在麻黄汤为辛温之君，在麻杏石甘汤得石膏之制而为辛凉之用。
- **分类看节，不看措辞。** 桑菊饮功用作「疏风清热，宣肺止咳」，仍归辛凉节；按关键词匹配会漏掉它。
- **常数不是变量。** 甘草在 8 首正方里全部出现（8/8），它是解表剂的常数，不能用来分类。
- **正方不等于全部。** 教材第5章另有附方（麻黄加术汤、大青龙汤、小青龙加石膏汤等），统计时须说明只算正方。
- **数据瑕疵要说明。** 九味羌活汤的组成抽取含 1 个非药名（「故以为名」），故 37 个药名里真实药味名为 36 个。

## 交付物

1. 一张三行判断表：虚实 / 寒温 / 兼夹与病位，每行给出体征依据
2. 一首方 + 一句「为何不是同层另一首」
3. 一处药味证据：本方含哪些跨节药，说明寒温来自配伍
4. 一句边界：8 首为正方数，不含附方；本章不涉及剂量

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 跳层 | 直接说「风热，用银翘散」 | 先判虚实，再看寒温 |
| 靠感觉 | 「恶寒重，像风寒」 | 换成可证伪的体征：无汗、脉浮紧 |
| 单味药定性 | 「有麻黄，所以辛温」 | 看石膏、看节归属 |
| 混算正方附方 | 说「解表剂有十几首」 | 明确「正方 8 首」 |
| 用措辞代替分类 | 因桑菊饮不写辛凉而误判 | 以教材节为准 |
| 越界给量 | 直接写麻黄 9g | 一律回「须由医师确定」 |

## 边界

本 Skill 只处理解表剂的分野判断，不涉及剂量、煎服法与临床决策。所有体征判断与选方须由执业中医师在四诊合参后作出；麻黄等发汗峻药的使用尤须遵守禁忌与药典用量。
