# zhifeng-zhizao

## 何时使用

- 要分清「外风/内风」「凉燥/温燥」四类方，需要一套可核对的结构表
- 需要引用教材第17、18章的规模数字（27,766 字、4 节、66 段、11 方）
- 要给「某方的组成到底是哪几味」做核对，尤其是同名异方（消风散）

## 不适用

- 给具体方剂定量、定煎服法、定疗程
- 判断患者属外风还是内风、凉燥还是温燥（须辨证）
- 平肝潜阳药的降压风险、虫类药与矿物药的用量安全评估
- 统计全部治风剂或治燥剂（教材只收 6 + 5 首）

## 数据边界

```text
章：教材·第17章 治风剂（14,861 字 / 2 节 / 6 方）+ 教材·第18章 治燥剂（12,905 字 / 2 节 / 5 方）
合计：4 节 / 11 小节 / 66 段 / 27,766 字 / 11 方 · 占全书 358,800 字的 7.74%
每方：六段 · 2,470–2,610 字 · 每段 411.7–434.9 字
药位：99 / 去重 75 味 / 方均 9.0；高频 甘草8 麦冬3 桑叶3 杏仁3 白芍2
共用药：6 味（薄荷、甘草、石膏、桑叶、白芍、玄参）
回查：92/99（92.9%）；最差 牵正散 3/4
自报味数：治风六方都有「凡N味」，五首相符，只牵正散多 1 条（「并生用」）
角色：有君 8/11 · 四角色齐 2/11（镇肝息风汤、杏苏散）
引用：教材·第18章·18.1.1
```

## 步骤

1. **先报规模**：27,766 字 = 14,861 + 12,905；11 方；占全书 7.74%。
2. **报四节**：疏散外风 3 方 / 平息内风 3 方 / 轻宣外燥 3 方 / 滋阴润燥 2 方；17.1 与 17.2 各 3 方 18 段，严格对称。
3. **报章长规律**：每方 2,477 与 2,581 字；治风多 1,956 字 ≈ 多一首方，不是难度。
4. **报自报味数对账**：六首治风方自报 8/13/3/10/12/11 味，组成字段 8/13/4/10/12/11 条；五首相符，只有牵正散把「并生用」切成了第四味。
5. **报消风散的同名方**：方源段先写「须加辨明者」辨《局方》同名方，再写「原方组成为：……凡十三味」；按后者取 13 味，与自报数一致，13/13 可回查。
6. **报君臣**：有君 8/11、四角色齐 2/11；杏苏散甘草同判佐使，桑杏汤桑叶同判君臣，清燥救肺汤石膏同判臣佐——讲君臣必回方解段。
7. **画边界**：要剂量、要辨证、要安全评估的，一律转出本技能。

回查：92/99（92.9%）；角色：有君 8/11、四角色齐 2/11
边界：不给剂量、不辨内外风；平肝药与虫类药的安全性须医师把关
出处：教材·第17章·17.1–17.2、教材·第18章·18.1–18.2

## 质量判据

- 报「消风散 13 味」时必须说明它曾经被切成 19 条（3 条正方 + 7 条《局方》同名方 + 9 条非药串），现在按「原方组成为：」定位才对上自报数
- 报「五首相符」时给出每首的自报数与字段数，并点明唯一失配是牵正散的「并生用」
- 报「回查 92/99」时说明失配多为全称/简称错位（羚角片、鲜生地、大生地、浙贝母、山栀、橘皮），不是错药
- 报「四角色齐 2/11」时必须说明杏苏散是甘草重复计数凑出的齐全
- 引文只写「教材·第N章·N.M.K」，不写「底本」「原文」式标签

> 本技能只做教材结构清点，不构成诊断或用药依据。
