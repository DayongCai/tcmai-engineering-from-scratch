# Skill：方剂与治法：方从法出

## 何时用

- 拿到一首方（教材方、老师给的方、医案里的方），要说明「它落实的是哪一条法」
- 要判断一首方「能不能加减」以及「加减的尺度在哪」
- 需要把一批方按治法分组，并对「分不进去的」给出解释而不是含糊带过

## 核心判据（三问）

1. **法在哪一层？** 治则 / 治疗大法（八法）/ 具体治法（辛温解表等）/ 方药。说「解表」是第二层，说「辛温解表」是第三层，说「麻黄汤」是第四层。
2. **证 → 法的这一步凭什么？** 病位、病性、病势、体质四项里，哪一项决定了这条法。说不出来，说明法是从方倒推的，不是从证立起来的。
3. **法 → 方的这一步凭什么？** 同一法之下为何选此方不选彼方：有无汗、有无里热、有无伏饮、体质强弱。四问里有几问答不出，就有几处是背下来的。

## 执行步骤

```text
1. 抄下证候（主症/兼症/舌/脉），不抄病名
2. 写出病机一句（病位+病性+病势）
3. 由病机立法，写到「具体治法」这一层，不停在「八法」
4. 由法选方，说明为何是此方而非同法的另一方（举出对照方）
5. 反查：此方若去掉君药，法还在不在？不在，则此药即君
6. 若兼证出现，说明加什么、减什么，以及尺度（不得夺君药之位）
```

## 硬约束

- **一方只归一法**：分组时强制单选。兼数法的方要在备注里写清「教材归 X，临床兼 Y」，不许两头都算。
- **判据取最粗粒度**：按教材章名判法，不按节名。节名含「清热」的祛湿、祛痰剂会被误算进清法。
- **分不进去的单列**：不属八法的方不进「其他」黑箱，按教材章再分一次，让它们显形。
- **数字必须能对账**：各法方数之和 + 法外方数 = 总方数。对不上就报错，不写「约」。

## 交付物

1. 一张表：法 / 教材章 / 方数 / 代表方
2. 一句对账：`sum(各法) + 法外 = 总数`
3. 一段说明：法外的方为何法外（规则原因，不是「教材遗漏」）
4. 一处边界：本章数字描述的是教材目录结构，不是临床功用全集

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 把八法当八个方类 | 遇祛湿、理血无处置放 | 八法是治法大类，方类是它的目录投影 |
| 按节名判法 | 清法 13 → 18，全表偏移 | 按章名判 |
| 用病名代替证候 | 同病异治时无法解释 | 抄证候，不抄病名 |
| 把「不属八法」读成「无法」 | 62 首变成黑箱 | 按章再分一次，逐章命名 |
| 用单味药性反推全方寒温 | 麻杏石甘汤被误判为辛温 | 看配伍环境：麻黄得石膏则不助热 |

## 边界

本 Skill 只处理「法与方的对应关系」，不涉及剂量、煎服法与临床决策。任何实际用方须由执业中医师辨证后决定。
