# 方剂与治法：方从法出

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 看一首方，先问它落实的是哪一条法
- 为什么按章判、不按节名判
- 判据要选最粗粒度的那个
- 「不属八法」不等于「无法」
- 方剂学的目录重心其实在八法之外
- 分组的意义不在于分类，而在于让「归不进去的东西」显形

## 边界

- **八法归属是教材编排的产物，不是病机演绎。** 一首方在临床上可能兼数法（和解兼泻下、解表兼清里），但数据层强制「一方只归一法」。所以本章的 52 与 62 描述的是**教材的目录结构**，不是这些方在临床上的全部功用。
- **「法外」是判定规则的边界，不是教材的判断。** 若换一条规则（例如按功用关键词判），62 这个数字会变。凡引用本章数字，须同时引用规则：按教材章名判，一方归一法。
- **字数只说明规模，不说明难度。** 第2章 14,569 字 + 第1章 8,759 字 = 23,328 字，这是教材正文的汉字数，与理解难度无关；第2章的概念密度远高于第1章的史料密度。
- 本章为方剂学教学材料。文中所有方剂名称、功用、主治与分类，均取自教材《方剂学》的表述与 `standards/fangji` 的机器可读层。
