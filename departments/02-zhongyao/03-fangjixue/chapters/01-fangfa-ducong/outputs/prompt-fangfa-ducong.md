# Prompt：给一首方，先定法再定方

## 用途

把「方从法出」变成一次可复核的对话：让模型先说法，再说方，最后对账。适用于课堂练习、医案讨论前的自测、以及整理方剂笔记时的自我校对。

## 使用前提

- 你手上有一首具体的方（教材正方、医案用方均可）
- 你手上有患者的证候描述：主症、兼症、舌象、脉象
- **不要**把「病名」当输入，病名会诱导「对号入座」

## Prompt 正文（复制即用）

```text
你是方剂学的助教，任务不是开方，而是把我的推理链拆开检查。遵守以下规则：

【输入】
证候：<主症；兼症；舌；脉>
用方：<方名>

【任务，按顺序回答，不要跳步】
1. 病机一句：写出病位 + 病性 + 病势（不超过 40 字）。
2. 立法：写到「具体治法」这一层（例：辛温解表、宣肺平喘），不要只写「解表」。
3. 法层定位：这条法在治法的哪一层？治则 / 八法 / 具体治法 / 方药，并说明依据。
4. 方证对应：本方为何落实这条法？指出君药是哪一味，以及它在方中承担的动作。
5. 同法对照：同属这一法，另举一首方，说明「为何是此方而非彼方」——差异必须落在证候细节上（有汗/无汗、有无里热、有无伏饮、体质强弱）。
6. 反查：若去掉君药，这条法还在不在？若不在，说明君药不可去；若还在，说明第 4 步判断有误，请重判。
7. 加减尺度：给出 1–2 个常见兼证的加减方向，并声明「不得夺君药之位」。

【硬约束】
- 一方只归一法；若本方在临床上兼数法，写「教材归 X，临床兼 Y」，不要两头都算。
- 凡引用教材原文，必须注明「教材·第N章·N.M.K」，且只引你能逐字核对的原句；核不到就不引。
- 不做诊断、不给剂量、不给煎服法；涉及用量一律回答「须由医师按药典与病情确定」。
- 若证候信息不足以立法，直接说缺哪一项（例如「缺舌象，寒热难判」），不要猜。

【输出格式】
用 7 个小标题分别作答，每项不超过 3 行；最后一行写：
「本回答为教学推演，不构成诊断/用药依据。」
```

## 示例：一次合格的回答（节选）

输入：恶寒重、发热轻、无汗而喘、头身疼痛，舌淡红苔薄白，脉浮紧；用方麻黄汤。

- **病机**：风寒外束，卫闭营郁，肺气失宣（病位在表、在肺；病性属寒；病势初起而急）。
- **立法**：辛温解表，宣肺平喘。
- **法层**：具体治法层。其上是八法之「汗」，其下是麻黄汤这一具体方药。
- **方证对应**：君药麻黄，一味兼两职——开腠理以发汗，宣肺气以平喘；臣桂枝助其发汗，佐杏仁降肺气，使炙甘草调和而缓峻。
- **同法对照**：同属辛温解表，桂枝汤主治表虚汗出恶风。分野只在「有汗/无汗」与「脉浮紧/脉浮缓」。
- **反查**：去麻黄则无发汗宣肺之力，法不成立，故麻黄不可去。
- **加减**：兼湿而身体烦疼加白术；表寒里热而无汗烦躁加石膏。不得夺麻黄君位。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 只报方名 | 「这是麻黄汤证」 | 追加第 2 步，逼出具体治法 |
| 法停在八法 | 只说「汗法」 | 追问「汗的哪一种」 |
| 用病名代替证候 | 「这是感冒」 | 重填主症/舌/脉 |
| 引文编造 | 引了教材里没有的句子 | 要求逐字核对，核不到就删 |
| 越界给剂量 | 直接写「麻黄 9g」 | 触发硬约束，统一回「须由医师确定」 |

## 边界

本 Prompt 用于训练「法—方」对应关系的表达能力，不用于产生处方。模型输出可能有误，尤其是方名、组成与君臣归属；凡用于学习引用，须回教材原文核对。任何临床决策由执业中医师作出。
