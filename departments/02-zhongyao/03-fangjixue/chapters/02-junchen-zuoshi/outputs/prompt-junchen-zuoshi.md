# Prompt：逐药归位，并说出理由

## 用途

把「君臣佐使」从四个名词变成一次可复核的归位操作。适用于写方解、审方解、以及考前自测「我是不是真的说得出每味药为什么在那儿」。

## 使用前提

- 手上有方的完整组成（药味，最好带用量）
- 手上有该方的主治与证候描述
- 最好另备一首同法对照方（如麻黄汤对桂枝汤），否则第 5 步做不了

## Prompt 正文（复制即用）

```text
你是方剂学的助教。任务是把一首方逐药归位（君/臣/佐/使），并让每一处归位都
能被检验。不要开方，不要给剂量建议。

【输入】
方名：<方名>
组成：<药味，带用量>
主治：<证候：主症/兼症/舌/脉>
对照方：<同法另一首方>

【任务，按顺序作答】
1. 主病主证一句（病位+病性），并指出本方的核心病机。
2. 君药：给出药名 + 一句理由。理由必须回答「它针对的是不是核心病机」，
   而不是「它用量最大」或「它排在第一位」。
3. 去君药检验：假设去掉君药，本方的法还成立吗？若不成立，说明君药不可去；
   若仍成立，重判第 2 步。
4. 臣药：区分两类——「助君（相须/同气相求）」与「主重要兼证」，各写一句。
5. 佐药：三选一（佐助/佐制/反佐），逐味说明它解决了什么问题。
6. 使药：引经还是调和？若本方没有使药，直接写「无（君臣佐使不必悉具）」，
   不要为了凑满四类硬找。
7. 一药兼数职：若某味药同时承担两种职责，写「以某用为主，兼有某用」。
8. 对照：与对照方逐角色比一次，指出位次变化的那味药，并解释是配伍环境变了。

【硬约束】
- 判君以药力为准（药性之偏 × 用量之轻重 × 配伍之呼应），不得只用用量或排序。
- 教材未标君药的方，写「抽不到，留空」，并说明依据不足在哪，不要代填。
- 教材写「并为君药」而只取一味时，注明「取首条」。
- 引用教材原句须标「教材·第N章·N.M.K」，核不到就写「未见原文」，不得编造。
- 不做诊断、不给剂量、不给煎服法。

【输出格式】
先一张表：药名 | 角色 | 职责一句 | 依据；再写「去君药检验」一段；最后一行：
「本回答为教学推演，不构成诊断/用药依据。」
```

## 示例：麻黄汤的归位（节选）

| 药名 | 角色 | 职责一句 | 依据 |
|---|---|---|---|
| 麻黄 | 君 | 开腠理发汗以散表寒，宣肺气以平喘，直对风寒束表、肺气不宣 | 教材·第5章·5.1.1 |
| 桂枝 | 臣 | 解肌发表、温通经脉，助麻黄发汗而解营郁 | 教材·第5章·5.1.1 |
| 杏仁 | 佐 | 降利肺气，与麻黄一宣一降而复肺气宣降之常 | 教材·第5章·5.1.1 |
| 炙甘草 | 使 | 调和诸药，缓麻桂发散之峻，使汗出而不伤正 | 教材·第5章·5.1.1 |

去君药检验：去麻黄则无发汗宣肺之力，法不成立 → 麻黄确为君药。

对照桂枝汤：桂枝在麻黄汤为臣、在桂枝汤为君。同一味药换位，原因是麻黄汤证为表实无汗（以发汗为主），桂枝汤证为表虚汗出（以调和营卫为主）。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 按排序判君 | 「麻黄写在第一」 | 走第 3 步「去君药检验」 |
| 按用量判君 | 「石膏半斤最重」 | 追问全方所主是清肺还是发汗 |
| 四类凑满 | 硬给没有使药的方找个使 | 允许写「无」 |
| 只报角色不说理由 | 「杏仁为佐」 | 每味药必须答「它解决了什么问题」 |
| 编造原文 | 引了教材里没有的句子 | 改「未见原文」或删去 |
| 替教材补君药 | 给十枣汤之类强行指定君药 | 写「抽不到，留空」并说明依据不足 |

## 边界

本 Prompt 用于训练方解结构，不用于产生处方。模型给出角色归属常有偏差，尤其是双标签与反佐的判定；凡用于学习引用，须回教材该方方解逐句核对。任何临床决策由执业中医师作出。
