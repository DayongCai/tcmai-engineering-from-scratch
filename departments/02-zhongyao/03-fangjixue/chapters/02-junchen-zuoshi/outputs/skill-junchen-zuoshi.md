# Skill：君臣佐使：组方的角色结构

## 何时用

- 要写或审一篇方解，需要把每味药「归位」并给出理由
- 读教材方解时发现「某药到底算臣还是佐」说不清
- 要把一批方按角色齐备度分组，或统计某味药在多少方里当君药
- 遇到「这首方有没有君药、能不能说没有」的判断

## 核心判据（四问）

1. **君**：这味药主管的是不是本方的核心病机？去掉它，这条法还在不在？
2. **臣**：它是助君（与君相须、同气相求），还是主治一个重要兼证？
3. **佐**：它是佐助（助君臣或治次要兼证）、佐制（制毒制峻），还是反佐（防格拒）？
4. **使**：引经报使，还是调和诸药？两者常由一味兼任。

四问里答不出「去之则法不成立」的，就不是君药；答不出「它解决了什么问题」的，就先别给它封位。

## 执行步骤

```text
1. 抄证候与病机（不抄病名）
2. 找君：用「去君药」检验，不用「用量最大」检验
3. 找臣：区分「助君」与「治兼证」两类
4. 找佐：三选一（佐助/佐制/反佐），必要时标双标签
5. 找使：引经 / 调和，允许缺席
6. 交叉检验：同一味药在对照方中是什么位次？若位次变了，说明是配伍环境在起作用
7. 写方解：先说主病主证，再逐药归位，最后写配伍特点（不超过三条）
```

## 硬约束

- **不用用量判君。** 大承气汤厚朴半斤而位在佐使；四逆汤用生附子取其力峻。用量只是三个变量之一。
- **抽不到就留空。** 教材未写「君药」二字的方，不许按用量最大者代填；「留空」与「没有」不同。
- **并列君药要标口径。** 教材写「麻黄、桂枝并为君药」时，若数据只记第一味，引用时必须说明「取首条」。
- **一药兼数职要写主次。** 写「以某用为主，兼有某用」，不做二选一。
- **遇到总论与各论冲突，留账。** 例如麻杏石甘汤的君药，第3章与第5章口径不同，须标明你引用的是哪一个。

## 交付物

1. 一张归位表：药名 / 角色 / 职责一句 / 教材依据（教材·第N章·N.M.K）
2. 一句「去君药」检验结论
3. 一处兼数职说明（若有）
4. 一处边界声明：本章角色系抽取，覆盖 105/114（君）、40/114（使）

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 按排序判君 | 「麻黄写在第一，所以是君」 | 用「去君药」检验 |
| 按用量判君 | 「石膏半斤最重，必是君」 | 看全方所主：清肺还是发汗 |
| 四角色凑满 | 硬给每方找使药 | 接受「君臣佐使不必悉具」 |
| 一药一职 | 芍药只能算臣 | 允许双标签并写主次 |
| 把覆盖率当医学结论 | 「多数方无使药」 | 区分写法缺失与结构缺失 |
| 混用总论与各论口径 | 半句第3章、半句第5章 | 标明出处，冲突处留账 |

## 与相邻章节的接缝

- 上一章（方从法出）：君药是法的直接体现者——先有法，才有君。
- 下一章（解表剂）：辛温与辛凉的分野，本质是「同一味药在不同配伍环境中的角色不同」（麻黄在麻黄汤为君发汗，在麻杏石甘汤为君但得石膏之制）。

## 边界

本 Skill 只处理角色归属与方解结构，不涉及剂量、煎服法与临床决策。角色判断以教材方解为据，遇到教材未标注的情形一律留空并注明。任何实际用方须由执业中医师辨证后决定。
