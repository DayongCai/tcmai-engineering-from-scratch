# 君臣佐使：组方的角色结构

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 「去君药」是一个可执行的检验动作
- 记住有两个口径，并说明你引用的是哪一个
- 使药最少，只有 35.1%
- 一首七味药的方，通常不到三种角色在岗
- 双标签是一个提示，不是一个结论
- 代填会污染下游

## 边界

- **君臣佐使是抽取，不是教材标注。** 有君 105/114、三角色以上 80/114、四角色齐 18/114；其余不是「没有君臣佐使」，是本层抽不出。引用这四个数时必须带上这句限定。
- **并列君药只留首位（23 首受影响）。** 小青龙汤、败毒散、银翘散等方的方解都写了「并为君药」，数据层只记第一味。这不是教材的判断，是抽取的规则。
- **使药覆盖偏低（40/114）源于写法，不源于方。** 教材多以「调和诸药」描述而不标「使药」，故使药数偏少；据此推断「多数方无使药」是错的。
- 本章为方剂学教学材料，角色归属取自教材方解的表述，并经程序抽取。
