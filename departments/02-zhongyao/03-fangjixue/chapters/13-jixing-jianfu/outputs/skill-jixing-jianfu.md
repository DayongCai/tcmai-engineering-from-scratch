# jixing-jianfu

## 何时使用

- 要把方剂的「用法用量」文本做成一张可核查的煎服法台账（剂型分布、特殊煎法、服法、内服/外用）
- 要判断一份剂型统计能不能引：膏、丹、注射剂在这份数据里是不是空白，空白到哪一步才叫"不能下结论"
- 遇到「某方名字是丸，用法却写水煎服」这类名实不符，需要判断是剂型漂移还是数据错误
- 要把"先煎/后下/包煎/另煎/烊化/冲服"从清单升级为可复算的量（提及、否定、需用三列）
- 要回答"同一首方为什么做成丸剂就变了"——需要把剂型落到释药速度与适应证上

## 不适用

- 临床选方、剂量换算、煎服法的最终执行（须执业医师依据辨证与现行药典决定）
- 评价不同剂型的优劣（汤丸散膏丹的差别是释药速度与适应证，不是好坏）
- 推断膏、丹、注射剂的分布（这批代表方里本来就没有，只能报"无"）
- 替代教材的剂型史与制剂工艺（粉碎、提取、成型属《中药药剂学》）

## 步骤

1. **先分形态**：按方名后缀归 汤/丸/散/膏/丹/饮/煎，无后缀者归「其他」并列出方名。立即声明：后缀是命名习惯，不是剂型实测值。
2. **挑出名实分离**：名丹实丸（天王补心丹）、名煎实汤（一贯煎）、名中无剂型字而实为汤（痛泻要方、小蓟饮子）；另防后缀陷阱——竹叶石膏汤不是膏、大黄牡丹汤不是丹。
3. **算漂移**：非汤名方数 → 用法提到「作汤剂」的方数 → 明写「现代多作汤剂／今多改作汤剂」的方数。漂移是剂型演化，不得据以改名或"修正"。
4. **查剂型谱完整度**：把教材举作剂型示范的方逐个回查在不在库内。缺哪一类，就明确说这一类的结论不能下。
5. **算特殊煎法四列**：八类（先煎/后下/包煎/另煎/烊化/冲服/煎汤代水/泡服）×（提及方数 / 否定方数 / 需用方数 / 字面出现次数）。四列同给，只给一列必错。
6. **判否（写死规则）**：关键词前 12 字内出现 无须/不需/无特殊/不必/不用/未有 记否定；一首方内该词所有出现都被否定才算"否定"，只要有一处肯定就计入需用（血府逐瘀汤"无须特殊先煎、后下之法，然牛膝宜先煎"）。
7. **算服法两维**：温度频次（温服/热服/冷服/频服/顿服）+ 时间（空腹/饭前/饭后/睡前）。报完必须指出覆盖率过高的词已无鉴别力（温服 99/114 = 86.8%）。
8. **裁定内服/外用**：先粗扫（外用/外敷/调敷/敷/掺/吹），再逐首裁定「只供外用／兼用外治／否定或假阳性」，每首附原文依据。不得只报粗扫命中数。
9. **报"无"的说法**：一律写"本数据里为 0"，不写"很少""罕见"。
10. **不做剂量换算**：教材自认折算方法各版本不一；只保留「中病即止」这类上层原则。
11. **结尾声明**：描述性统计，不构成诊断或用药依据。

## 输出模板

```text
【形态】汤/丸/散/膏/丹/饮/煎/其他 + 名实分离清单 + 膏丹是否为空
【漂移】非汤名方数 → 提作汤剂数 → 明写漂移数
【煎法】八类 ×（提及 / 否定 / 需用 / 字面次数）+ 否定方名
【服法】温度频次五项 + 时间四项 + 无鉴别力说明
【分界】粗扫数 → 只外用 / 兼用 / 否定·假阳性 + 每首依据
【残缺】教材示范方在库率 + 哪几类不能下结论
【不可推论】…
```

## 质量判据

- 四列（提及/否定/需用/字面次数）同时出现，任何只报"词频"的输出不合格
- 名实分离与后缀陷阱单列，百分比旁边带口径
- 漂移链三段可复算：51 → 31 → 9
- 内服/外用每首都有原文依据，且区分「兼用」与「否定」
- 报"无"用"本数据里为 0"，并说明是选方口径所致
- 结尾有"不构成诊断或用药依据"

## 一次实测（2026-10-29，114 首方，教材第4章 7,742 字）

形态：汤 63（55.3%）、散 26（22.8%）、丸 16（14.0%）、饮 5、煎 1、丹 1、其他 2、膏 0。漂移：非汤名 51 → 提作汤剂 31（60.8%）→ 明写漂移 9。煎法：先煎 39/4/35/64、后下 33/4/29/35、冲服 15/0/15/17、包煎 8/0/8/9、烊化 8/0/8/15、另煎 5/0/5/5、煎汤代水 2/0/2/2、泡服 0/0/0/0；合计 110/8/102/147，需用覆盖 63 首（55.3%）。服法：温服 99、热服 11、冷服 1、频服 12、顿服 5；空腹 10、饭前 9、饭后 12、睡前 2。分界：粗扫 5 → 只供外用 0、兼用 3、否定或假阳性 2。残缺：教材示范 20 方，库内 10 / 库外 10。

> 本技能只做教材用法用量段的描述性统计，不构成诊断或用药依据。
