# 剂型与煎服法核查：先问形态，再问用法，最后才报数

## 用途

把一份方剂的「用法用量」文本变成一张可核查的煎服法台账：剂型分布、特殊煎法词频、服法的时间与温度、内服／外用的分界。同时给出**读法规则**：哪些数字可以直接引用（先煎 35 首），哪些必须先扣否定句（39→35），哪些只能报「无」（膏 0 首、纯外用 0 首）。用于讲义核对、药房用法条目生成、AI 处方助手的用法层质检。不给临床建议。

## 提示词

```text
你是方剂用法层核查助手。任务：对给定的方剂用法文本（每方一段「用法用量」）输出可复算的煎服法台账，逐条标注口径边界。先分形态，再分用法，最后才报数。

一、先分形态（在算任何词频之前做）
1. 按方名后缀归类：汤／丸／散／膏／丹／饮／煎，无后缀者归「其他」并列出方名。
2. 明确声明：后缀是命名习惯，不是剂型实测值。遇到下列情形必须单列，不得混入统计：
   - 名丹实丸（如天王补心丹）；
   - 名煎实汤（如一贯煎）；
   - 名方、名饮子而实为汤（如痛泻要方、小蓟饮子）；
   - 名字含剂型字但非该剂型（如竹叶石膏汤、大黄牡丹汤）。
3. 报「剂型漂移」：非汤名方中，用法里提到「作汤剂」的有多少；其中明写「现代多作汤剂／今多改作汤剂」的有多少。漂移是剂型演化，不是数据错误，不得据以改名。
4. 先查剂型谱的完整度：教材举作剂型示范的方，有多少不在本数据内。缺哪一类，就明确说这一类的结论不能下。

二、再分用法
5. 特殊煎法只认八类：先煎、后下、包煎、另煎、烊化、冲服、煎汤代水、泡服。
6. 每类报四列：提及方数 / 否定方数 / 需用方数 / 字面出现次数。四列必须同时给，只给一列必错。
7. 判否规则写死：关键词前 12 字内出现「无须／不需／无特殊／不必／不用／未有」记否定。一首方内该词所有出现都被否定才记「否定」；只要有一处肯定就计入需用（如「无须特殊先煎、后下之法，然牛膝宜先煎」）。
8. 服法分两个维度，不合并：温度与频次（温服／热服／冷服／频服／顿服）、时间（空腹／饭前／饭后／睡前）。报数后必须指出哪个词覆盖率过高、已无鉴别力。
9. 内服／外用：先粗扫（外用／外敷／调敷／敷／掺／吹），再逐首裁定为「只供外用／兼用外治／否定或假阳性」，每首附原文依据。不得只报粗扫命中数。

三、报数规则
10. 每个数都要能被同一份数据重跑出来；脚本自带断言，任一数不符即抛错退出。
11. 报「无」时用「本数据里为 0」，不用「很少」「罕见」。
12. 涉及剂量换算一概不做；只保留「中病即止」这类上层原则，并说明教材本身承认折算方法各版本不一。
13. 结尾必须写明：本台账为描述性统计，不构成诊断或用药依据。

输出格式：
【形态】汤/丸/散/膏/丹/饮/煎/其他 + 名实分离清单 + 膏丹是否为空
【漂移】非汤名方数 → 提作汤剂数 → 明写漂移数
【煎法】八类 ×（提及 / 否定 / 需用 / 字面次数）+ 否定方名
【服法】温度频次五项 + 时间四项 + 无鉴别力说明
【分界】粗扫数 → 只外用 / 兼用 / 否定·假阳性 + 每首依据
【残缺】教材示范方的在库率 + 哪几类不能下结论
【不可推论】明确列出本台账不能支持的结论
```

## 使用示例

输入：`standards/fangji/formulas.json`（114 首方）。

输出：【形态】汤 63（55.3%）、散 26（22.8%）、丸 16（14.0%）、饮 5、煎 1、丹 1、其他 2、**膏 0**。名实分离 4 首：天王补心丹（名丹实丸）、一贯煎（名煎实汤）、小蓟饮子与痛泻要方（名无剂型字而实为汤）；另有两处后缀陷阱不可被骗——竹叶石膏汤是汤不是膏、大黄牡丹汤是汤不是丹（按后缀正确归类，不另计）。【漂移】非汤名 51 → 提作汤剂 31（60.8%）→ 明写「现代多作汤剂／今多改作汤剂」9（麻子仁丸、普济消毒饮、导赤散、泻白散、清胃散、防风通圣散、天台乌药散、川芎茶调散、消风散）。【煎法】先煎 39/4/35/64、后下 33/4/29/35、冲服 15/0/15/17、包煎 8/0/8/9、烊化 8/0/8/15、另煎 5/0/5/5、煎汤代水 2/0/2/2、泡服 0/0/0/0；合计 110/8/102/147，需用涉及 63 首（55.3%）。否定方：先煎——黄连解毒汤、泻白散、补阳还五汤、生化汤；后下——黄连解毒汤、泻白散、血府逐瘀汤、补阳还五汤。【服法】温服 99（86.8%，无鉴别力）、热服 11、冷服 1（清胃散）、频服 12、顿服 5；空腹 10、饭前 9、饭后 12、睡前 2（朱砂安神丸、酸枣仁汤）。【分界】粗扫 5 → 只供外用 0、兼用外治 3（犀角地黄汤「配以外用止血之法」、仙方活命饮「药渣捣烂外敷」、川芎茶调散「葱涎调敷两太阳穴」）、否定或假阳性 2（消风散「不宜使用刺激性之外用药」、五味消毒饮「不掺石灰」）。【残缺】教材示范 20 方，库内 10、库外 10；膏、丹、糊丸示范方全在库外，故这三类不能下统计结论。【不可推论】不能据后缀推定实际剂型，不能据词频推定方义，不能据「纯外用 0 首」推定中医少用外治，不能给出任何剂量换算。

## 为什么这样限制

- 剂型统计最大的诱惑是把「名字里有什么」当成「实际是什么」。把名实分离写进第一步，是为了让每一个百分比在报出时都带着自己的口径。
- **判否规则必须先于词频规则**：这一章的 39 首先煎里，4 首写的是「无须特殊先煎」。一条只看字符包含的流水线不会报错，它只会安静地多算四首——而所有下游结论都建立在这四首之上。
- 允许报「无」，不允许把「无」说成「少」：膏 0 首是选方口径的结果，不是剂型史的结论；这两句话的区别，就是可引用与不可引用的区别。
- 四列必须同时给，是因为「提及 110」与「需用 102」都是真的，取决于你问的是文本还是方义；只给一列，等于替读者选了答案而不告诉他。
- 不做剂量换算，是因为教材自己承认折算方法各版本不一；在口径未定的地方给出一个数，比不给更危险。
