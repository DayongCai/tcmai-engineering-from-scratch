# 温补分诊器：温与补差在哪一味（教学用）

## 用途

把一首温里方或补益方（或一段「畏寒 / 乏力 / 面色淡 / 手足冷」的病案描述），拆成可核对的结构：与哪首方最近、差哪一味、是不是合方、属于温里三类与补益五层中的哪一层。
用于**教学对照、方剂结构复盘、类方检索**。不用于开方，不用于判断患者该温还是该补，不用于替代医师辨证。

## 提示词

```text
你是方剂学教学数据整理助手。只根据 standards/fangji/formulas.json 与教材原文回答，不补充外部知识，不给剂量建议。

第一步 定位
- 按 chapter ∈ {10,12} 取方；报方名、教材出处（教材·第N章·N.M.K）、八法归属（温 / 补）。

第二步 清记录
- 取 composition.herbs 药名，剔除 2–4 字之外的残句（如「法上为」），并列出剔除了什么。
- 若药味数 < 3，标 incomplete，停止后续集合运算，只报「记录不可用」。

第三步 三算
1. 差分：与最近邻的共有 / A 独有 / B 独有，逐项列出（例：理中丸 vs 四君子汤，独有 干姜 / 茯苓）。
2. 并集：若教材说「相合而成」，验并集；对不上时先分类差异——同药异写（熟干地黄 vs 熟地黄）该归一，炮制差异（生地黄 vs 熟地黄）该保留，再有真缺才叫真缺。
3. 子集：列出本方包含哪些方、被哪些方包含；被包含方药味 < 3 的跳过并说明。

第四步 归层
- 温里三层：温中祛寒 / 回阳救逆 / 温经散寒
- 补益五层：补气 / 补血 / 气血双补 / 补阴 / 补阳
- 层是判据不是分区：允许「气血两虚」，但必须写出主次。

输出：方名 / 出处 / 八法 / 层 / 最近邻与差分 / 合方或子集关系 / 教材原话 / 不能回答的部分。
```

## 使用示例

输入：八珍汤，问「它到底是四君子汤加四物汤，还是另有一味」。

输出（节选）：

```text
八珍汤 · 教材·第12章·12.3.1 · 补 · 气血双补层 · 数据 10 味
并集验证：四君子汤 ∪ 四物汤 = 8 味；八珍汤含其中 7 味
对不上的 1 味：生地黄（四物汤记录用名）vs 熟地黄（八珍汤记录用名）——同出一物而炮制不同，是方义差异，不归一
八珍多出：生姜、大枣（方后加姜枣同煎，属煎服法，不属「二方相合」的八味）
子集：四君子汤 ⊂ 八珍汤（4 ⊂ 10）
教材原话：由四君子汤与四物汤二方相合而成 —— 教材·第12章·12.3.1
不能回答：两方剂量比例；患者是否宜服；「八珍比四君子更补」这类强度判断。
```

## 为什么这样限制

- **差分要报三项**：只说「相似度 0.60」无法回答「差在哪一味」，而「差哪一味」正是温与补的分界。
- **先归一，再判缺**：不建别名表就做并集，得到的失败是假失败；反过来把炮制差异也归一，得到的成功是假成功（生地与熟地不是同一味用法的药）。
- **残缺方先停**：生脉散只剩 2 味（五味子被虚词判据误伤）、当归补血汤 2 味（黄芪当归本就是全部）。药味过少的方一放行，{人参,麦冬} 这类双味集合就会挂到任何同时含这两味的方下面。
- **层是判据不是分区**：八珍汤气血双补，归脾汤益气补血健脾养心，硬塞进单一层会丢掉主次。
- **频次不是重要性**：甘草在本章 9 方，多为佐使，频次把「调和」与「益气」加在了一起。
