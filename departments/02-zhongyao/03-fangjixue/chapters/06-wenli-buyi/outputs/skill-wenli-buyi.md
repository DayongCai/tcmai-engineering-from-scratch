# 温里剂与补益剂：温与补，只差一味

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 把茯苓换成干姜，补气之方就成了温中之方
- 同一组三味药（人参、白术、甘草），加茯苓则守中焦之气，加干姜则温中焦之阳
- 在集合上这是等量的替换，在方义上这是方向的改变
- 7/8 不是教材写错，是炮制差异被集合运算读成了缺药
- 它报出的不是错误，而是方义差异
- 多出的生姜、大枣是煎服法的一部分

## 边界

- **别名表仍未进代码**。上一版的书写差异（熟干地黄/熟地黄、干山药/山药）已由上游归一，但本章代码里依旧没有别名表——再出现新的异写时，仍要人工判断「该归一还是该保留」。生地黄与熟地黄的差异必须保留：炮制改变方义，归一即失真。
- **一首小方被跳过**。当归补血汤（2 味，黄芪当归本就是它的全部）。跳过使本章的子集边只有 3 条，实际是少了这 1 首方的参与；任何「补益剂合方关系只有 3 条」的说法都必须带这句限定。（生脉散原被误跳，判据修正后已回到计算里。）
- **药位不等于剂量**。四物汤熟地黄 12g、当归 9g、白芍 9g、川芎 6g，比例本身就是方义（熟地独重为君）；集合里四味同权。
- 本章数据为教材结构化整理，仅用于教学演示与检索，不构成诊断或用药依据。温里剂多辛热，阴虚火旺者忌用。
