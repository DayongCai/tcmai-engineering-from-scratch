# wenli-buyi

## 何时使用

- 教学复盘：要讲清理中丸与四君子汤只差一味、八珍汤为何「二方相合」，而不是让学员背两张组成表
- 建库：要给「相合而成」「去某味加某味」这类教材句子建可判定的写法，并处理同药异写
- 做类方检索：想知道一首补益方在教材同一治法里的最近邻，以及哪首方是多方共有的底方

## 不适用

- 决定患者该温还是该补（本技能不含四诊、剂量与禁忌判定）
- 实证、湿热、食积而妄补的任何实际场景；温里剂的辛热药亦不在此列
- 需要剂量比例判断的场合——四物汤熟地独重为君，集合表示抹掉了比例
- 残缺方参与的集合运算（生脉散只剩 2 味、当归补血汤 2 味，均 < 3），必须先标 incomplete

## 步骤

1. **取子集**：按 `chapter ∈ {'10','12'}` 从 `formulas.json` 过滤，得 16 方（温 5 / 补 11）。
2. **清残句**：药名按「2–4 字且不含虚词」判；本章 96 → 93 药位（「法上为」「白扁豆姜汁浸去」「五味子」3 条剔除，末一条是误伤，也要留账）。
3. **建别名表**：同药异写先归一（熟干地黄 → 熟地黄、干山药 → 山药）；**炮制差异不归一**（生地黄 ≠ 熟地黄，这是方义差异）。
4. **做三算**：
   - 差分：A−B / B−A，看「温」与「补」的距离（本章最小：理中丸 vs 四君子汤，各独有一味）。
   - 并集：验「相合而成」（八珍汤 = 四君子 ∪ 四物 + 姜枣，归一后 8/8）。
   - 子集：找公共子结构（三条边全以四君子汤为子集方）。
5. **加前置**：子集方药味 < 3 时跳过并记入 skipped，不许静默产出假边。
6. **写护栏**：任何频次结论后补一句「频次不区分角色与剂量」。

## 输出模板

```text
批次：教材·第10章 + 第12章（16 方 / 93 药位 / 去重 40 味 / 每方 5.8 味）
分法：温 5（24 药位，4.8 味）/ 补 11（69 药位，6.3 味）
最小差分：理中丸 vs 四君子汤 共有 人参、白术、甘草；独有 干姜 / 茯苓（J=0.60）
合方验证：四君子 ∪ 四物 → 八珍汤 对上 7/8（缺 生地黄，与八珍的熟地黄是炮制差异，不归一）；八珍多出 生姜、大枣
同源差分：六味 vs 肾气 共有 5；六味独有 熟地黄；肾气独有 生地黄、桂枝、附子
子集边：四君子汤 ⊂ 八珍汤 / 参苓白术散 / 归脾汤
跳过：生脉散（2 味）、当归补血汤（2 味）
护栏：本表未含剂量比例、君臣佐使位次、煎服法与患者个体情况。
```

## 质量判据

- 差分结果三项齐全：共有、只在 A、只在 B。只报 Jaccard 一个数的结果不可复核
- 同药异写与炮制差异分列处理，没有把生地/熟地一并归一
- 子集判定前有完整性前置，跳过项在输出中可见（不是静默丢弃）
- 每个数字都能由 `node code/main.js` 重现；文档不手打「16 方」「93 药位」
- 引教材原句写成「…」——教材·第N章·N.M.K，且为底本某段正文的连续子串

> 本技能输出为教学与检索辅助，不构成诊断或用药依据。
