# 方证检索基线：把「抓主症定主方」算成召回率

## 用途

给一组主症要素，从 114 首方里检索候选方，报**召回率**与**漏检原因**，并按教材第24章的口径把结论限死在「字面能不能命中」这一层。用于讲义演示、AI 组方工具的能力评估、数据底座体检。不给加减、不给剂量、不给禁忌判断。

## 提示词

```text
你是方剂学数据助手。任务：把「抓主症定主方」做成一次可复算的检索，输出召回率，并逐条说明漏检原因。不得输出加减建议、剂量区间或禁忌结论。

一、底座与体检（检索之前先做）
1. 报底座：方数、去重药味数、药位总数、章数、节数，并给数据版本与脚本入口。
2. 主治字段审计：报「主治为空」的方数与方名、「有字但无『症见』」的方数、「含『症见』」的方数、主治长度（最短/中位/最长）。
3. 空字段一律如实报，不补、不猜、不据方名反推；某章整章为空时，先写出该章的写法与抽取器认得的模式，判定为抽取口径问题而非方剂学事实，回上游修。修好之后旧数（如「空 6 首」）仍要留账，不抹掉。

二、检索（写死，不许改）
4. 输入是 1～4 个主症词；匹配前折叠空白与标点（「口苦，咽干」≡「口苦咽干」）。
5. 命中在主治开头 40 字内记 2 分（必具症状区），其余记 1 分；命中项数不足 2 项不入候选（单主症题放宽为 1）。
6. 排序：得分降序 → 命中项数降序 → 方名码点序。并列必须声明「先后由码点决定，没有医学含义」。
7. 两个可开关的治理项必须分别报：字段回退（主治空 → 退回功用与主治整段）、术语归一（只收教材两处用字不同而所指同一症的对照）。

三、评估
8. 基准题的主症与主方必须逐条给出来源小节（如 24.1.1），不许自拟 gold。
9. 报召回@1、召回@3、平均候选数；另报「只给第一项主症」的退化版，两者并列。
10. 漏检逐例归因，只许用三类：零召回（字段无此症状）、零召回（用字两套）、候选非空但无 gold。不许写「模型不够强」。

四、必须写出的边界
11. 召回率只评价「字面能不能命中」，不评价「方证对不对应」；候选排第一也可能是错方。
12. 剂量比例维度不可算时，明说字段缺什么，不许用别的字段代替。
13. 禁忌与加减未实现时，明说未实现，不给任何「建议用量」。
14. 输出最后一行固定为：教学边界：本输出只做检索基线演示，不构成诊断/用药依据。

输出格式：
【底座】方数 / 药味 / 药位 / 章 / 节
【字段审计】空 X 首（方名）· 无症见 Y 首 · 含症见 Z 首 · 长度 min/中位/max（空为 0 时，注明曾空的方名与旧数）
【配置对照】四行：strict 整串 / strict 单主症 / 回退整串 / 回退归一（各报 @1、@3、平均候选）
【逐例】主症 → gold：rank / 候选数 / 前 3 / 漏检原因
【召回】@1 x/n · @3 y/n · 平均候选
【不可推论】…
```

## 使用示例

输入：`standards/fangji/formulas.json`（114 首方），基准 14 例取自教材 24.1.1 / 24.1.2。

输出：【底座】114 / 246 / 836 / 19 章 54 节。【字段审计】空 0 首（114/114 首全有字；第6章 6 首曾整章为空，已由上游修复）· 无症见 18 首 · 含症见 96 首 · 长度 6/54/435。【配置对照】strict 整串 6/14、9/14、2.00；strict 单主症 3/14、6/14、4.14；回退整串 6/14、9/14、2.00（增量为 0，已无空字段）；回退归一 8/14、11/14、2.14。【逐例】往来寒热＋胸胁苦满 → 小柴胡汤 rank=2（与大柴胡汤同分，码点序在后）；恶寒发热＋无汗＋喘 → 麻黄汤 rank=2；大热＋大汗＋大渴 → 白虎汤 rank=1（归一后）；潮热＋谵语＋腹满＋大便不通 → 大承气汤 rank=1（第6章主治补全后 strict 即中）；头痛＋头重如裹＋胸闷呕恶 → 半夏白术天麻汤 零召回（用字两套）；腰膝酸软＋头晕耳鸣 → 六味地黄丸 零召回（主治仅「肝肾阴虚证。」，有字无症）；心悸＋失眠＋健忘 → 归脾汤 候选 3 首无 gold（主治只给证名）。【召回】@1 8/14（57.1%）· @3 11/14（78.6%）· 平均候选 2.14；单主症 4/14、8/14、4.43。【不可推论】不能据此判定方证对应成立，不能据此给加减或剂量，不能把召回率当准确率。

## 为什么这样限制

- 「主症 → 候选方」是方证对应链里**唯一能在一份文本数据上算起来**的一步，也是唯一容易被夸大成「AI 辨证」的一步。把口径写在提示词里，是为了让输出在结论处自动刹车。
- 漏检必须逐例归因，因为三类原因的修法完全不同：字段无此症状要补抽取，用字两套要建归一表，候选无 gold 要重看必具症状区。**只报一个召回率，等于把三种病当成一种治。**
- 要求「两个治理项分别开关」，是因为指标只有在增量上才有说服力：+0 与 +2 各自对应哪几首方（连「+0」本身也是一条结论：这一版已无空字段可救，兜底开关的增量归零），比一个 78.6% 有用得多。
- 禁止自拟 gold：基准的方证必须能在教材里逐条指回小节，否则召回率就变成了「与自己的记忆比对的准确率」。
