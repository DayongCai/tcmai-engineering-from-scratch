# qushi-qutan

## 何时使用

- 见到苔腻、身重、痰多，需要在祛湿五节与祛痰四节之间定位
- 讲义要把 16 首方（9 祛湿 + 7 祛痰）排成一张可核对的类表
- 复核某一首方是否被放错了节
- 需要说清"湿聚成痰"这句话的适用边界

## 不适用

- 具体处方与剂量、煎服法
- 疗效判断与预后
- 教材节划分之外的另立分类（本章一律照教材）
- 把君臣佐使覆盖率当成方义证据

## 步骤

1. **定坐标**：先判这一步走"湿"还是"痰"。湿按病位与寒热，痰按性质（湿、热、燥、风）。
2. **归节**：祛湿五节 19.1–19.5，祛痰四节 20.1–20.4；只归一节。
3. **找鉴别点**：写出与相邻节的分界症状（如燥痰的苔白而干、咽干哽痛）。
4. **核共享药**：陈皮、甘草、茯苓、半夏、白术、桔梗、生姜、杏仁 8 味跨两类，说明底盘相同、方向不同。
5. **验数据**：跑 `node code/main.js`，确认 16 首 / 9 节 / 107 药位 / 36,217 字对得上。
6. **声明边界**：抽不到的角色不是没有的角色；不给诊疗建议。

## 输出模板

```text
【坐标】湿 / 痰
【依据】症状 → 坐标（逐条）
【归入】第 N 节 节名
【鉴别点】与相邻节的分界
【代表方】方名（教材·第N章·N.M.K）
【共享药提示】本方落在哪一侧、与另一侧的共同底盘
【边界】…
```

## 质量判据

- 一次只归一节，且给出鉴别点
- 燥痰不入辛温燥湿之路
- 引文可逐字回查，定位到 N.M.K
- 君臣佐使的空缺被识别为抽取留白
- 规模数字（16 / 9 / 107 / 36,217）与 `code/main.js` 输出一致

> 本技能只做类归属与配伍统计，不构成诊断或用药依据。
