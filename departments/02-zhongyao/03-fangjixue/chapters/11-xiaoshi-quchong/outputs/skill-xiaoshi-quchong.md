# xiaoshi-quchong

## 何时使用

- 需要把"吃撑了/腹胀/不想吃"落到五首方中的一首
- 需要判断某方属消法、驱虫法还是涌吐法（如枳实导滞丸是否算泻下）
- 讲义要把 21、22 两章排成一张三法对照表
- 做涌吐剂的风险教育：让人认出"不能用"

## 不适用

- 具体处方、剂量、煎服法
- 催吐的操作步骤（任何催吐都须医疗监护）
- 教材节划分之外的另立分类
- 把君臣佐使抽取结果当方义结论

## 步骤

1. **判峻缓**：可久服（保和丸）/ 中病即止（枳实导滞丸、健脾丸）/ 不可轻投（瓜蒂散）。
2. **定归属**：消（21.1 消食化滞、21.2 健脾消食）、驱虫（22.1）、涌吐（22.2）。
3. **辨脾虚**：食少难消、便溏、倦怠乏力 → 健脾丸；无脾虚 → 保和丸；湿热食积、苔黄腻脉沉有力 → 枳实导滞丸。
4. **辨寒热错杂**：腹痛时作、手足厥冷、吐蛔 → 乌梅丸；注意脏寒为本、蛔动为标。
5. **过禁忌**：涌吐先查孕妇、体弱、失血、心脑血管病、腐蚀性毒物、神志不清。
6. **验数据**：跑 `node code/main.js`，核 5 首 / 4 节 / 40 药位 / 13,358 字 / 八法 3+1。

## 输出模板

```text
【峻缓】可久服 / 中病即止 / 不可轻投
【归属】法 · 节
【选方】方名（教材·第N章·N.M.K）
【理由】君臣配置 → 病机
【禁忌风险】…
【数据提示】药味数、八法归属、抽取留白（如使 0/5）
```

## 质量判据

- 峻缓在选方之前给出
- 消食两型按"脾虚有无"判，不按药味多少判
- 涌吐命中任一禁忌即输出"禁用催吐，即刻送医"
- 健脾丸的"君"写成四君子汤四味共为君，不写成甘草
- 引文可逐字回查并定位到 N.M.K

> 本技能只做归类与风险提示，不构成诊断或用药依据。
