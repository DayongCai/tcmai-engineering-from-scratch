# anshen-pinggan

## 何时使用

- 把教材·第22、23、24 章的 26 味药建成一张带分章口径的表
- 需要说明「心神」与「肝风」是两条轴、不是同义词时
- 遇到字段缺失（如龙骨）要给出「为什么不补」的书面理由时

## 不适用

- 直接开方、按「同归心/同归肝」推替代药（归经只说明作用部位）
- 有毒药材（朱砂、全蝎、蜈蚣、刺蒺藜）的剂量与安全判断
- 判断某味药「能不能用于抽搐」——本技能只整理教材写了什么

## 步骤

1. **分章定靶**：22 章心 8/9、23 章肝 13/13、24 章心 4/4；先给分章，再给合并。
2. **抽字段**：name / chapter / sec / qi / wei / guijing / toxicity / pregnancy / badges / source。
3. **标缺口**：味或归经为空即入缺口清单（本章为龙骨，教材段在「性平」处截断），明确不补。
4. **算毒性与禁忌**：有毒 3（朱砂、全蝎、蜈蚣）、小毒 1（刺蒺藜）；妊娠禁用 4、慎用 7、未标注 15。
5. **校验规模**：1601 + 2565 + 757 = 4923；5 节 / 26 小节 / 78 段，对不上先查漏段。
6. **加护栏**：每条附「本节未含：剂量、炮制、配伍、辨证；平性 ≠ 温和」。

## 质量判据

- 分章数字与合并数字同时出现，且相加相等
- 缺口清单能指到具体段落与断句位置
- 毒性、妊娠档位与原文措辞一致（含「孕妇及肝肾功能不全者禁用」这类插入语）
- 定位语保留原文（如麝香的开窍醒神第一要药），不改写成结论

> 本技能输出为教学与检索辅助，不构成用药建议。
