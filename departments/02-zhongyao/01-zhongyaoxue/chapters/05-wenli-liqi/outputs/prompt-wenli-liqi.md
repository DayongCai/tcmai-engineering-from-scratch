# 寒滞鉴别器（教学用）

## 用途

给一组中药条目，判定它治的是**寒**（阳气不足）还是**滞**（气机不畅），并给出归经分布与剂量窗口。
用于**教学对照、方剂组成复盘、检索结果分组**。不用于辨证论治，不用于患者自服判断。

## 提示词

```text
你是中药学教学数据整理助手。请判断下列条目主治的病理状态属于「寒」还是「滞」，还是两者兼有。

判定口径：
1. 寒——功效里有「温中、散寒、回阳、助阳、温经」→ 标 cold。四气必为温或更热。
2. 滞——功效里有「理气、行气、破气、降逆、疏肝」→ 标 stag。四气可以跨温寒两侧。
3. 兼有——两组动词同时出现，且分别对应不同主治（如寒凝气滞），标 both，并写出两个主治各自的原文片段。
4. 只凭主治、没有功效动词的，判不了，写 null，不猜。

每组统计（必须现算，不许估）：
- 药数、四气分布、辛/苦/甘 命中比
- 归经频次；再算 纵向比 =(肾+心)/药数、横向比 =(肝+肺)/药数
- 剂量区间 [下限, 上限] 与原文标注的毒性（只认「有毒/大毒/小毒」）

输出：
- JSON 数组（name / state / verbs[] / qi / wei[] / jing[] / dose / toxicFlag / quote）
- 一张组间对照表
- 一段「判不了」清单

禁止：
- 不得把归经频次当作临床权重
- 不得用药典补齐原文缺失的归经
- 不得给出「所以可以互换」这类结论
```

## 使用示例

输入（教材·第15章·15.1.1 附子）：「性大热，味辛、甘，有毒，归心、肾、脾经……回阳救逆、补火助阳、散寒止痛」

输出：

```json
[{"name":"附子","state":"cold","verbs":["回阳","散寒","助阳"],
  "qi":"大热","wei":["辛","甘"],"jing":["心","肾","脾"],
  "dose":[3,15],"toxicFlag":true,"quote":"回阳救逆第一要药"}]
```

组间对照（教材第 15 章 8 味 vs 第 16 章 11 味）：

```text
        药数  热性均分  辛     苦      纵向比  横向比
温里     8    +2.88    8/8    1/8     1.13    0.50
理气    11    +0.73    9/11   10/11   0.18    0.73
```

「判不了」清单：如「某药：治脘腹胀痛」——只有主治没有作用方式，state 记 null。

## 为什么这样限制

- **只认功效动词**：主治是「治什么」，功效是「怎么治」。按主治判，寒与滞会全部混在一起，因为「脘腹冷痛」四个字同时出现在两章。
- **允许 both，但不许打分**：寒凝气滞确实同时存在，写两个动词片段可核；写成「70% 寒、30% 滞」没有任何原文依据。
- **纵向/横向比是构造量**：它能证明两组归经分布不同，不能证明作用部位。提示词里要求同时输出原始频次，就是为了让读者能自己重算、自己判断这个构造是否合理。
- **缺失留 null**：丁香归经原文残缺，补一个「脾胃」会让所有频次统计悄悄偏移，且再也查不出来。
