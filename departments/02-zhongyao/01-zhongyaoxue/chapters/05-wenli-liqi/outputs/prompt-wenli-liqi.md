# 温里往下走、理气横着走，十九条记录里有一条自相矛盾 · 提示词

## 用途

给「温里往下走、理气横着走，十九条记录里有一条自相矛盾」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「两章的结构：8 + 11 → 气：温里在热侧，理气横跨温平寒 → 归经：一条向下，一条横着走 → 一条自相矛盾的记录，和四味空栏」这条链。
