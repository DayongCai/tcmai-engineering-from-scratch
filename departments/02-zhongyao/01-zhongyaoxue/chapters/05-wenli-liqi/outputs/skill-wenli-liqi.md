# wenli-liqi

## 何时使用

- 建库时要把「温里」与「理气」分开，而两章的归经首项都是脾，标签容易撞车
- 教学：证明「暖胃顺气」这句话为什么把两种不同的力混成了一种
- 复核一组药的剂量窗口与毒性标注，找出安全窗最窄的那几味

## 不适用

- 辨证（寒证、气滞证的判断需要四诊信息，本技能只有药性数据）
- 任何实际处方与剂量决定
- 归经原文残缺的条目（如丁香）——留空，不补
- 把「纵/横比」当作用部位的医学证据（它只是分布差异的度量）

## 步骤

1. **判状态**：按功效动词判 cold（温中/散寒/回阳/助阳）、stag（理气/行气/破气/降逆）、both；只有主治的判 null。
2. **抽四气**：按有序标度折分（大寒 −4 … 大热 +4），组内求均值；**不要**用众数，众数会丢掉「一组药有多热」这个信息。
3. **数归经**：逐经计频次；再算 纵向比 =(肾+心)/药数、横向比 =(肝+肺)/药数。
4. **比符号而非比大小**：温里的「纵−横」应为正、理气应为负；符号翻转才是证据，差值大小依赖分组方式。
5. **抽剂量与毒性**：区间取 `[下限, 上限]`，抓不到写 null；毒性只认「有毒/大毒/小毒」。
6. **写护栏**：声明「轴是临时构造；归经频次不含权重；剂量不含炮制与配伍」。

## 质量判据

- 「温里全部 ≥ 温」这类结论能被 `QI_SCORE` 直接验证，不靠叙述
- 纵/横差的**符号**在两组间相反；若同号，说明分组方式不适配，应换分组而不是改结论
- 每条判定附原文片段（quote），改一个字应判定失败
- 归经缺失项在输出里可见（null / []），没有被补齐
- 组间对照表里的每个数都能由原始 JSON 复算

> 本技能输出为教学与检索辅助，不构成用药依据。
