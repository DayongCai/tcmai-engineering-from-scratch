# 水湿通道分诊器（教学用）

## 用途

把一段中药条目，判成「水湿的哪一条出口」：**攻（大肠）/ 燥（脾胃）/ 渗（小便）/ 祛风湿（经络）**，并同时抽出剂量区间与原文标注的毒性。
用于**建库、教学对照、方剂组方思路复盘**。不用于开方，不用于替代药选择，不用于患者自服判断。

## 提示词

```text
你是中药学教学数据整理助手。请把下面的药材条目，判成水湿通道，并只抽原文写到的信息。

判定口径（按顺序，命中即停，不叠加）：
1. 攻——功效里有「泻下、攻积、逐水、峻下」→ 出口是大肠；再分攻下 / 润下 / 峻下逐水三档。
2. 燥——功效里有「燥湿、化湿、芳香化浊」→ 出口是脾胃；注意「化」不是「排」。
3. 渗——功效里有「利水、渗湿、通淋、退黄」→ 出口是小便。
4. 祛风湿——功效里有「祛风、除湿、通痹、通络」→ 出口是经络。
5. 一条药同时命中两档（如大黄既泻下又利湿退黄），主档取功效**第一个**动词所在的档，其余记进 also[]，不合并、不平均。

字段规则：
- qi / wei[] / jing[] 逐字取自原文；原文没有的写 null，禁止用「一般认为」补齐。
- dose: 从用法段抓区间，输出 [下限, 上限]（单位 g）；抓不到写 null，不写 0。
- toxicFlag: 原文写了「有毒 / 大毒 / 小毒」才为 true；只写「慎用」不算。
- 每条附 quote：判定所依据的那一句原文，逐字复制，不改写。

输出 JSON 数组；最后单列「判不了」清单：哪一条因为功效描述里没有动词性表述而无法归通道，为什么。
```

## 使用示例

输入（教材·第11章·11.1.1 大黄）：「大黄功效泻下攻积、清热泻火、凉血解毒、逐瘀通经、利湿退黄……大黄煎服3-15g」

输出：

```json
[{"name":"大黄","channel":"攻","sub":"攻下","also":["渗"],
  "qi":"寒","wei":["苦"],"jing":["脾","胃","大肠","肝","心包"],
  "dose":[3,15],"toxicFlag":false,
  "quote":"大黄功效泻下攻积、清热泻火、凉血解毒、逐瘀通经、利湿退黄"}]
```

「判不了」清单：本条无。若功效只写「治水肿」而没有动词（泻下/利水/燥湿），则 channel 为 null 并列出，理由写「只有主治，没有作用方式」。

## 为什么这样限制

- **只认动词**：主治是「治什么病」，功效是「怎么治」。按主治分类会把大黄与茯苓放进同一堆，因为都治水肿。
- **主档 + also 而不是打分**：给一条药算「60% 攻、40% 渗」看起来精细，其实没有任何原文依据，是伪精度。
- **保留 quote**：判定一旦被质疑，能立刻回到原句复核；没有 quote 的分类结果无法审计。
- **null 而不是 0**：剂量抓不到就留空，缺失必须可见。把缺失填成 0，后面所有均值都会被悄悄拉低。
