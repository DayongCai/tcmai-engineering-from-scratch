# xiexia-qushi

## 何时使用

- 建中药数据库，需要给每味药一个稳定的「通道」标签，而不是自由文本功效
- 教学复盘：一张方子里同时有大黄、苍术、茯苓，要讲清各自解决哪一段
- 需要一份「安全窗最窄的药」清单去**人工核对**，而不是直接照单抓药

## 不适用

- 决定患者用哪一类药、用多少（本技能不含辨证、配伍、个体差异）
- 峻下逐水药的任何实际使用（甘遂、京大戟、芫花、商陆、牵牛子、巴豆霜有毒，孕妇忌用，反甘草）
- 只有主治、没有功效动词的条目（如只写「治水肿」）——这类留空，不硬判
- 炮制差异显著的比较（生大黄与大黄炭在本技能里是两条记录，不自动合并）

## 步骤

1. **读原文**：取「来源与性味归经 / 功效与主治 / 用法用量与使用注意」三段，逐字不改。
2. **判主档**：按功效里**第一个**动词判 攻 / 燥 / 渗 / 祛风湿；其余命中的档写进 `also[]`，不合并、不加权。
3. **抽字段**：qi / wei[] / jing[] 逐字；`dose` 抓区间取 `[下限, 上限]`，抓不到写 `null`；`toxicFlag` 只认「有毒 / 大毒 / 小毒」。
4. **算强度**：同一批药按教材章分组，算热性均分（大寒 −4 … 大热 +4）与剂量上限均值；解析失败的不进均值，也不补 0。
5. **附护栏**：每条结论后面写清「本表未含：炮制、配伍、辨证、个体差异」。
6. **人工复核**：把清单交给药师/医师，由人决定可用性。

## 输出模板

```text
批次：教材·第11–14章（<章数>章 / <节数>节 / <小节数>小节 / <字数>字 / <药数>味）
通道  药数  热性均分  剂量上限均值  毒性词  归经前三
攻    …     …        …           …      …
燥    …     …        …           …      …
渗    …     …        …           …      …
祛风湿 …     …        …           …      …

最窄安全窗（剂量上限升序）：<药名> <上限>g（原文毒性：是/否）…
护栏：本表未含炮制/配伍/辨证/个体差异；剂量不能线性相加（十枣汤三药同用）。
```

## 质量判据

- 每条判定都能指回一句原文（`quote` 字段），改一个字就应判定失败
- 主档与 `also[]` 分列，没有出现「0.6 攻 / 0.4 渗」这类无依据的分数
- 解析失败的条目在清单里可见（`null`），没有被静默填成 0
- 同一批药的分组统计能与教材 `counts` 逐章对上（节 / 小节 / 段 / 字）

> 本技能输出为教学与检索辅助，不构成用药依据。
