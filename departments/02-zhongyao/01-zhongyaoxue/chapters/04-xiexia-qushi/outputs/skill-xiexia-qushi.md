# 泻下与祛湿共用「出口」二字，剂量却差六百倍

## 什么时候用

需要把本章的判断讲清、或检验自己是否讲清时。

## 怎么用

1. 先读 `docs/zh.md` 的 MOTTO 与 PROBLEM 段，确认这一章要回答的问题是什么；
2. 跑 `node code/main.js`，看本章的结构清点与判据词频（数字全部从 `docs/zh.md` 现算）；
3. 按正文小节顺序，逐节说出判据（本章 6 条核心判断见下）；
4. 用 `quiz.json` 的 6 道题自检，答不上就回到对应小节。

## 核心判据

- 6/6 全部标毒
- 毒性栏与剂量上界是同一件事的两面
- 节名以动作为主词时，功效首词命中率极高
- 节名带结果词时，结果词在功效首词里 0 命中
- 「祛湿」不是一组药，是四条通道
- 标毒 9/45 是大类的统计倾向

## 边界

- **「祛湿」不是一组药，是四条通道。** 泻下走大肠、利水走膀胱、化湿走中焦、祛风湿走筋骨。四条通道的剂量与毒性差两个数量级，合并记忆会在选药时第一次就出错。
- **标毒 9/45 是大类的统计倾向。** 峻下 6/6 全标、化湿与利水 0 标，用来做筛查可以，用来替代逐条读禁忌不行。
- **剂量数字必须带剂型。** 巴豆霜 0.1–0.3g 是「入丸散」的上限，甘遂 0.5–1.5g 也是「入丸散」；同一个数字若按煎服理解，结论全错。
- 本章为中药学教学内容的字段统计与结构讨论，数据取自教材第 11–14 章拆分出的 45 味药条目，不是处方，也不构成用药建议。泻下药与祛风湿药多含毒性品种，剂量、炮制、煎法与禁忌须以现行药典、教材与执业中医师的辨证判断为准。
