# caiyao-zhijian

## 何时使用

- 教学：讲清「功效」背后的 5 层前提，让学生知道该问哪 5 个问题
- 处方复核：把一张方子逐味展开成条件清单，标出「依据未载」的项
- 药材入库：产地、采收、贮藏、炮制规格四项的验收提问模板

## 不适用

- 直接给出剂量或替代药（本技能不含法定上限、工艺参数、临床判断）
- 只有功效描述、没有性味归经与用法用量记载的条目
- 孕妇、儿童、肝肾功能不全等人群的特殊用药决策
- 毒性药材的安全操作（另见 gongdu-badu 章）

## 步骤

1. **定闸**：五道闸固定顺序——产地 → 采集与贮藏 → 炮制 → 配伍 → 禁忌与剂量。不合并、不调序。
2. **逐闸取证**：每闸只填依据里明确写到的内容，出处写到「教材·第N章·N.M」级。
3. **标缺口**：依据没写的项写「依据未载」，不许用常识补齐；缺口要写明「缺了会影响什么判断」。
4. **拆剂量**：只抄写成克数的区间，旧制（钱/两/枚）原样保留并标未换算。
5. **分三档禁忌**：禁用 / 慎用 / 依据未载，三档不许合并。
6. **交付复核**：把规格卡交给药师或医师，由人决定是否可用。

## 输出模板

```text
药：<药名>（依据：教材·第N章·N.M）
① 产地        ：<基原 + 产地>            出处：<…>  缺口：<…>
② 采集与贮藏  ：<采收期 + 干燥贮存>      出处：<…>  缺口：<…>
③ 炮制        ：<饮片规格名>             出处：<…>  缺口：工艺参数未载
④ 配伍        ：<七情关系 / 禁忌药对>    出处：<…>  缺口：<…>
⑤ 禁忌与剂量  ：<禁用/慎用 + 克数区间 + 煎法> 出处：<…>  缺口：<…>
依据未载清单：<逐项 + 影响>
护栏：规格卡不是处方，剂量区间不是限量标准。
```

## 质量判据

- 五道闸齐全且顺序正确；任何一闸写「无」都必须有出处说明为什么无
- 每条依据能指到具体章·节，不出现「底本」「原文」这类不可核对的标签
- 「依据未载」清单非空时不算失败，但**隐去缺口**算失败
- 剂量项要么是克数区间，要么明确标「未换算」，不允许出现无来源的单一数值

> 本技能输出为教学与复核辅助，不构成用药建议。
