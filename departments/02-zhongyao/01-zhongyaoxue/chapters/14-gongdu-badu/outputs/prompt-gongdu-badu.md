# 毒性与用法边界分级卡

## 用途

把一组毒性药材的条目，整理成**可核对的分级卡**：毒性等级、用法开关（是否许内服）、
内服微量区间、孕妇与特殊人群禁忌、配伍禁忌。
用于教学、药材管理与处方前置检查的**提问模板**。不用于决定是否使用，不用于中毒处理。

## 提示词

```text
你是中药学数据整理助手。下面是一组药材条目，请为每一味输出一张「毒性与用法边界分级卡」。

规则：
1. 毒性等级只从原文的性味句里取，四档：大毒 / 有毒 / 小毒 / 未标。
   原文没有毒性字样的，一律写「未标」，禁止据常识补成「无毒」或「有毒」。
2. 用法开关单列一档，且是一票否决：原文写「只供外用」「不作内服」的，开关标 OFF，并说明原文措辞；
   其余标 ON，并抄出内服的量（若原文没有内服量，写「未载」）。
3. 毒性等级与用法开关必须是两个字段，不许合并成一个「安全性」分数。
4. 内服量只抄原文写成克数的区间，保留「入丸散」「先煎」「冲服」等剂型与煎法限定，不得省略。
5. 禁忌分三栏：孕妇（禁用 / 忌用 / 未载）、配伍（十九畏十八反中与本药相关的条目）、其他人群。
6. 每条都要带出处，写「教材·第N章·N.M」。原文没有的项写「未载」，并在末尾汇总。

输出：每味一张表（药 / 毒性 / 用法开关 / 内服区间 / 剂型限定 / 禁忌 / 出处 / 缺口）。
末尾汇总「未载」清单，并单独标出「开关 OFF」的药名。
```

## 使用示例

输入：升药（教材·第29章·29.1.1）

输出：

| 项 | 内容 |
|---|---|
| 毒性 | 大毒（原文：有大毒） |
| 用法开关 | OFF —— 只供外用，不可内服；不可久用 |
| 内服区间 | 未载（原文明确禁止内服） |
| 剂型限定 | 研末撒敷或制成药捻 |
| 禁忌 | 头面部位慎用；汞过敏者禁用 |
| 缺口 | 无工艺参数、无中毒处理 |

汇总：开关 OFF 的药名 —— 升药（以及同组的土荆皮、炉甘石）。

## 为什么这样限制

- **未标不补**：补一个「无毒」会让整张卡在最关键的一栏上撒谎。
- **开关与等级分离**：把「禁止内服」压成一个很小的剂量数字，看起来只差一点，实际是两条路。
- **剂型限定不省略**：微量毒药的「入丸散」是分剂量可行性的前提，删掉它，区间就失去意义。
- **禁止合并成安全分**：任何把毒性、剂量、禁忌揉成一个数的做法，都会让最危险的药拿到中间分。

> 本模板输出为教学与风险认知辅助，不构成用药建议，也不构成中毒处理建议。
