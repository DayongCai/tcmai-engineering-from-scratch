# gongdu-badu

## 何时使用

- 教学：讲清「以毒攻毒」的适用边界，以及为什么毒性不能只当一个等级数字
- 药材管理：毒性药材的分级台账（是否许内服、内服限量、特殊人群）
- 处方前置检查：把一张方里出现的毒性药材逐味展开成边界卡，标出越线与缺口

## 不适用

- 决定是否使用某味毒性药材（本技能不含适应证判断、临床权衡与法规许可）
- 中毒表现识别、解救与监测（教材未系统展开，本技能不编）
- 炮制工艺参数（教材只有「忌火煅」「炮制后入丸散」这类结论，没有温度与时间）
- 普通药材的常规剂量建议（那属于 caiyao-zhijian 章的 5 道闸流程）

## 步骤

1. **取毒性**：只读原文性味句，分四档 大毒 / 有毒 / 小毒 / 未标。未标就是未标，不补。
2. **设开关**：原文写「只供外用」「不作内服」→ 开关 OFF；否则 ON。开关是一票否决，不与毒性等级合并。
3. **抄剂量**：只抄原文写成克数的内服区间，保留「入丸散 / 先煎 / 冲服」等限定；无则写「未载」。
4. **列禁忌**：孕妇（禁用 / 忌用 / 未载）、十九畏十八反中相关条目、其他人群（如汞过敏、体虚胃弱）。
5. **标缺口**：工艺参数、中毒处理、监测指标一律写「未载」，并说明缺了会影响什么。
6. **交付复核**：分级卡交药师或医师复核；开关 OFF 的药必须单独列出，不混进剂量表。

## 输出模板

```text
药：<药名>（出处：教材·第N章·N.M）
毒性      ：<大毒/有毒/小毒/未标>  原文措辞：<…>
用法开关  ：<ON/OFF>              原文措辞：<…>
内服区间  ：<x-yg / 未载>          剂型与煎法：<入丸散 / 先煎 / …>
禁忌      ：孕妇<禁用/忌用/未载> · 配伍<…> · 其他<…>
缺口      ：<工艺参数未载 / 中毒处理未载 / …>
护栏：分级卡不是用药许可；开关 OFF 的药不存在「小剂量内服」这回事。
```

## 质量判据

- 毒性等级与用法开关是两个独立字段，任何「安全分」都是不合格输出
- 开关 OFF 的药名单独成表，且不与剂量区间同列
- 「未标」不得改写成「无毒」；缺口清单为空要说明为什么
- 内服区间必须带剂型或煎法限定，否则视为不完整

> 本技能输出为教学与风险认知辅助，不构成用药建议，也不构成中毒处理建议。
