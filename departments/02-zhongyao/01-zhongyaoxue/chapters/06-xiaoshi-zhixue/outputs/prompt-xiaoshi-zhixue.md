# 炮制双用法抽取器（教学用）

## 用途

从一段中药条目里抽出**炮制版本**（生用 / 炒 / 炒炭 / 醋制 / 酒制 / 盐制），把「一味药」拆成「(药名, 炮制)」若干条记录，并标出哪一味存在**方向相反的两种用法**。
用于**建库、教学对照、剂量复核**。不用于开方，不用于判断该用哪个炮制品。

## 提示词

```text
你是中药学教学数据整理助手。请把下列条目拆成「药名 + 炮制」记录。

抽取规则：
1. 检索范围必须包含三段全文：来源与性味归经、功效与主治、用法用量与使用注意。
   —— 很多炮制说明只写在来源段末尾（例如「炒炭止血」），只查用法段会漏。
2. 炮制词元：生用 / 炒 / 炒焦 / 炒炭 / 炭 / 醋制 / 酒制 / 盐制 / 姜制 / 蜜炙。
   原文写「炒炭」时同时保留「炒」与「炭」两个命中，便于上层按需组合，不要合并成一个标签。
3. 每个炮制版本单独一条记录，字段：name, proc（原文用词，逐字）, effect（该版本对应的功效片段，逐字）, quote（原句）。
4. 若同一味药同时出现「生用」与「炒/炭」，标 dualUse: true，并写出两段的原文，顺序按原文出现顺序。
5. 只有炮制词、找不到对应功效片段时，effect 写 null，并在「判不了」清单里列出。

输出：
- JSON 数组（每行一个炮制版本）
- 一张 dualUse 表：药名 | 生用片段 | 炒/炭片段
- 「判不了」清单

禁止：
- 不得把「炒」与「炒炭」视为同一版本
- 不得用药典补写原文没有的功效
- 不得在输出里出现「所以可以互换」类结论
```

## 使用示例

输入（教材·第19章·19.1.3 地榆）：「以条粗、质坚、断面红棕色者为佳。炒炭止血。」

输出：

```json
[{"name":"地榆","proc":"炒炭","effect":"止血","dualUse":false,
  "quote":"以条粗、质坚、断面红棕色者为佳。炒炭止血。"}]
```

对照：艾叶原文「生用散寒、炒炭止血」→ 两条记录，`dualUse: true`，两条 effect 分别是「散寒」与「止血」。

「判不了」清单：若某条只写「炒用」而未说明炒后偏于何用，effect 记 null，理由写「只有炮制词，无对应功效片段」。

## 为什么这样限制

- **范围定死在三段全文**：漏掉来源段会静默少计（地榆就是活例），而少计不会报错，只会让后面的统计悄悄偏移。
- **不合并「炒」与「炒炭」**：一个是缓和（炒用护胃），一个是收敛（炒炭止血），方向不同。合并之后，上层再也分不开。
- **dualUse 要双向**：「含炭」不等于「有两条相反的力」。地榆只有炒炭一个方向，把它算成双用法，会让「双向药占比」这个数字失去意义。
- **effect 逐字引用**：功效片段一旦被改写，就无法回到原文复核，所有下游结论都变成无源之水。
