# xiaoshi-zhixue

## 何时使用

- 建库时发现同一味药出现「生用散瘀 / 炒炭止血」两种相反说法，需要拆成两条记录
- 教学：说明消食、驱虫、止血三章为什么可以放在一起讲（去留失序）
- 复核剂量窗口，尤其是「研末冲服」与「煎服」混在同一张表里的情况

## 不适用

- 判断患者该用生品还是炮制品（这需要辨证与处方意图）
- 任何实际剂量决定；跨给药形式的剂量不可直接比较
- 毒性与疗程评估（本章只统计原文标注，不补药理数据）
- 只有炮制词、没有对应功效片段的条目——effect 留 null，不推断

## 步骤

1. **定范围**：来源与性味归经 / 功效与主治 / 用法用量与使用注意，三段全文一起检索。漏掉来源段会静默少计。
2. **抽炮制词**：生用 / 炒 / 炒焦 / 炒炭 / 炭 / 醋制 / 酒制 / 盐制 / 姜制 / 蜜炙；「炒炭」同时保留「炒」与「炭」，不合并。
3. **拆记录**：每个炮制版本一条 `(name, proc, effect, quote)`；`effect` 逐字取自原文。
4. **判双用法**：`dualUse = 生用 AND (炒 OR 炭)`，两个方向都在才为真；只有「炒炭」的（如地榆）不算。
5. **核剂量**：区间取 `[下限, 上限]`，同时记录给药形式（煎服 / 研末冲服 / 入丸散 / 外用）；缺形式则标 unknown。
6. **出表 + 清单**：版本表、双用法表、「判不了」清单，三样缺一不可。

## 质量判据

- 双用法表里每一条都能指回两句原文，且顺序与原句一致
- 地榆这类「只有炒炭」的药不在双用法表内
- 剂量表旁边必须写出给药形式；缺失写 unknown，不默认煎服
- 分章统计（药数 / 字数 / 苦 / 甘 / 涩 / 生用 / 炒 / 炭）可由原始 JSON 复算
- 「判不了」清单非空时，不为了凑数而补值

> 本技能输出为教学与检索辅助，不构成用药依据。
