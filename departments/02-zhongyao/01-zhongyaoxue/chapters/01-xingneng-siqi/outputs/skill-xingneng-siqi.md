# xingneng-siqi

## 何时使用

- 要给「四气 / 五味 / 升降浮沉 / 归经 / 毒性」定一套字段口径，先看教材怎么定义
- 有人拿总论当数据源要「某味药的性味」，需要指回各论
- 教学：演示「定义章」与「数据章」的差别（本章 94 处举药、0 条药目）

## 不适用

- 取单味药的性味归经 / 功效 / 用量（总论没有逐药字段，见各论第 9 章起）
- 统计全书四气、五味、归经分布（须换药物层数据）
- 逐药毒性筛查（毒性未结构化，只散见于「使用注意」文字）
- 辨证、处方、剂量推算、替代药建议

## 数据边界

```text
章：教材·第5章 中药的性能（5 节 10 小节 20 段 2,126 字，占全书 3.33%）
五节字数：四气 399 / 五味 442 / 升降浮沉 457 / 归经 403 / 毒性 425（极差 58 字）
词频：五味 12 / 毒性 7 / 归经 6 / 升降浮沉 4 / 四气 3
举药：54 味去重 / 94 处点名 / 立目 0 条（全书 287 味）
引用：教材·第5章·5.1.1 这种三级写法
```

## 步骤

1. **先报规模**：节/小节/段/字数，并算出占全书比例——防止把总论当全书。
2. **再报同构性**：五节是否每节 2 小节 × 2 段；极差多少字。同构说明是编辑模板，不是内容权重。
3. **抽口径句**：每个要素摘一句可逐字回查的判据句，标到 5.1–5.5 的小节号上。
4. **清点举药与立目**：点名味数与处数（下界，含方名噪声） vs 立目条数（0）。
5. **画边界**：凡是要「逐药数据 / 分布统计 / 毒性标签」的需求，一律转出本章。

## 输出模板

```text
规模：5 节 / 10 小节 / 20 段 / 2,126 字（占全书 3.33%）
结构：五节同构（2 小节 × 2 段），字数 399/442/457/403/425，极差 58
口径：四气 <…>；五味 <…>；升降浮沉 <…>；归经 <…>；毒性 <…>
举药：54 味 / 94 处；立目 0 条 → 总论是词表
边界：逐药数据请下到教材·第9章起；本章不做辨证与处方
出处：教材·第5章·5.1–5.5
```

## 质量判据

- 每个口径句都能在指定小节里逐字回查到，不拼句、不改写
- 报「举药」时说明它是下界（方名含药名会虚增、别名会漏）
- 报「立目 0」时同时给出全书药目数与各论起始章，否则读者无法判断该去哪
- 词频只作写法指纹，不用来排「重点」

> 本技能只做教材结构清点，不构成用药依据。
