# buxuyao-fenlei

## 何时使用

- 编写或校对《中药学》补虚药部分的教案、复习题、章节导图
- 把一批药材记录导入系统前，检查"补气/补阳/补血/补阴"是否归错节
- 需要向人解释"为什么补气药里会有凉性的药"（西洋参），手边要有数据
- 核对某一节的真实构成：几味药、四气几档、归经落在哪些脏腑

## 不适用

- 判断具体某人该补气还是补阴（那是辨证，不是分类）
- 由四气或归经反推节名后当结论使用（补气/补血两节四气交错，反推必错一部分）
- 剂量、炮制、配伍禁忌查询（本章 195 字/味，这些信息未结构化）
- 替代药推荐：分类相同不等于可互换

## 步骤

1. **取数**：从 `standards/zhongyao/底本.json`（章节结构 + 段原文）与 `drugs.json`（药味 + 性味归经）读，不另建副本。
2. **核规模**：4 节 / 39 小节 / 117 段 / 7608 字 / 39 味；段数应等于药味数 × 3，不等就说明解析错位。
3. **建交叉表**：节 × 四气（寒/微寒/凉/平/温/微温/热），缺项写 `-` 不写 `0`。
4. **读表**：补阳无寒凉、补阴无温热 → 阴/阳这一刀与四气同向；补气、补血都跨温与寒凉 → 气/血这一刀与四气正交。
5. **归位单味药**：只依「功效与主治」判节；四气与功效冲突时以功效为准，并写下冲突。
6. **标口径**：遇到双炮制双性味（制首乌/生首乌），拆两条并注明主条目。
7. **复核**：分节合计须等于 39；每条结论能指到 `教材·第25章·25.x.y`。

## 命令

```bash
cd departments/02-zhongyao/01-zhongyaoxue/chapters/10-buxuyao-fenlei
node code/main.js                # 规模 + 四节×四气交叉表 + 归经前三 + 单味药查询
node --test code/main.test.js    # 11 项：规模/结构/原文核对/口径/教学边界
```

```text

25.2 补阳药 11 味：平3 温6 微温2｜全部归肾
25.3 补血药 6 味：微寒1 平1 温2 微温2｜归经前三 肝5 脾3 肾3
25.4 补阴药 13 味：寒2 微寒8 凉1 平2｜归经前三 肾8 肺7 肝5
结论：四气只在 25.2 / 25.4 上可分节；25.1 与 25.3 不可分。
护栏：分类依据为功效，非药性；不含剂量/炮制/配伍/禁忌。
```

## 质量判据

- 交叉表与 `node code/main.js` 输出逐格一致
- 四气保留六档，「微」字未丢
- 归经分项之和不小于药味数（多值字段），且说明分母是什么
- 双炮制双性味的药（何首乌）单独列出，不静默取一个
- 结论里写明"在哪两节失效"，而不是只报整体准确率

> 本技能输出为分类校对与教案辅助，不构成诊断或用药建议。
