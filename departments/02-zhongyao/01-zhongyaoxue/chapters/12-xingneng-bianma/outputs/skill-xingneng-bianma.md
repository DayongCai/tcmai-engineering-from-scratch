# xingneng-bianma

## 何时使用

- 建药材性能库，需要统一的结构化字段
- 教学：演示「性能接近」到底是按什么算的
- 药源短缺时，需要一份候选清单去**人工核对**，而不是直接替换

## 不适用

- 直接决定替代药（本技能不含剂量、炮制、毒性、禁忌、配伍）
- 孕妇、儿童、肝肾功能不全等人群的特殊用药判断
- 只有功效描述、没有性味归经记载的条目

## 步骤

1. **抽字段**：name / qi / wei / jing / raw / source，逐字取自原文。
2. **归一**：气 → 整数（寒 -2 … 热 +2），味与经 → 0/1 多位向量；程度词存 raw。
3. **查询**：给定一味药，算与其余药材的余弦相似度，降序输出。
4. **加护栏**：每条结果后面附「本向量未含：剂量、炮制、毒性、配伍、禁忌」。
5. **人工复核**：把候选清单交给药师/医师，由人决定是否可用。

## 输出模板

```text
查询：<药名>（气：<…>；味：<…>；经：<…>）
近邻：
  1. <药名>  cos=<0.xx>  差异：气 <同/异>；味差 <…>；经差 <…>
  2. …
护栏：相似 ≠ 可替换；未含剂量/炮制/毒性/配伍/禁忌。
```

## 质量判据

- 每条记录的 source 能指到具体书名与篇名
- 程度词（微温、微苦）在 raw 里可查
- 近邻列表里必须写出「差异在哪」，只给分数不算完成

> 本技能输出为教学与检索辅助，不构成用药建议。
