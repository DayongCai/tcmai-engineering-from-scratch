# jiebiaoyao-fengh

## 何时使用

- 要给「发散风寒 / 发散风热」定判据，需要证据而不是印象
- 教学：演示「共性字段」与「差异字段」的区别（辛是共性，四气是差异）
- 建解表药数据表，需要知道哪些字段能用来分组、哪些只能用来描述

## 不适用

- 临床选药（风寒风热的判断须四诊合参，本技能不含证候数据）
- 剂量折算与煎服方案（只抄教材区间，不做儿童/孕妇/肝肾功能调整）
- 补写教材未写的字段（升降浮沉、毒性强度在药物层没有结构化）
- 跨教材、跨药典的性味比对

## 数据边界

```text
章：教材·第9章 解表药（2 节 21 小节 63 段 3,965 字，占全书 6.21%）
分节：9.1 发散风寒药 12 味 2,234 字 / 9.2 发散风热药 9 味 1,731 字
四气：温 9 / 微温 3 / 凉 2 / 寒 3 / 微寒 4；9.1 ⊂ {温,微温}、9.2 ⊂ {凉,寒,微寒}，错分 0
五味：辛 19（9.1 12/12、9.2 7/9）· 苦 7 · 甘 6 · 微苦 1 → 辛不可作分节判据
归经：肺 17 · 肝 8（9.1 2 / 9.2 6）· 胃 7 · 膀胱 6 · 脾 5，共 50 条标注、2.38 经/味
用量：21/21 有煎服区间；细辛 1-3g 最窄、麻黄 2-10g 最宽、葛根上限 15g
特殊煎法：辛夷包煎 · 薄荷后下 · 蝉蜕冲服
引用：教材·第9章·9.1.1
```

## 步骤

1. **摊平**：把 21 味药的 qi / wei / guijing / 用量区间抽成一张表，缺值留空不推断。
2. **算分布**：每个字段在两节的计数与占比，写成两列对照。
3. **判区分力**：字段若在两节都过半（如辛），判「不可分节」；若两节取值集合不相交（如四气），判「可分节」。
4. **报错分**：给出错分味数与药名，不隐去。
5. **报共性 vs 差异**：肺 17/21 是共性（表证属肺卫），四气是差异；两者不能混用。
6. **抄用量**：只抄「煎服 a-b g」与特殊煎法标签，不做任何换算。

## 输出模板

```text
规模：2 节 / 21 味 / 63 段 / 3,965 字
四气：温9 微温3 | 凉2 寒3 微寒4 → 错分 0（可分节）
五味：辛 19/21（9.1 12/12、9.2 7/9）→ 不可分节
归经：肺 17/21（共性）· 肝 8（9.2 占 6，弱指纹）
用量：细辛 1-3g / 麻黄 2-10g / 葛根 10-15g；包煎·后下·冲服各 1 味
结论：分节判据只有四气；五味只解释「都能发散」这一共性
出处：教材·第9章·9.1–9.2
```

## 质量判据

- 每个字段都给出两节各自的分母（12 与 9），不只给全章合计
- 判「不可分节」时必须给出反例味数，而不是只说「都有」
- 四气的「微温 / 微寒」按独立档位统计，压平要显式声明
- 用量只报教材区间，遇到缺量如实写「未给」

> 本技能只做教材字段统计，不构成用药依据。
