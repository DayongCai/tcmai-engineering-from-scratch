# huoxue-huayu

## 何时使用

- 需要把教材·第20章「活血化瘀药」的 23 味药建成可核对的多轴索引
- 写综述/讲义时要给出「这句话出自哪一节哪一味药」
- 教学：演示子串抽取与语义抽取的差值为 3 味，以及漏项为何是静默的

## 不适用

- 直接开方、决定替代药（本技能不含剂量、炮制、配伍、辨证）
- 孕妇、哺乳期、儿童等特殊人群的用药判断（只输出教材写没写，不输出能不能用）
- 只有功效描述、没有性味归经条目的药材

## 步骤

1. **定轴**：先把节号（20.1–20.4）与药名对齐，确认 4 节 / 23 小节 / 69 段 / 4184 字。
2. **抽字段**：name / sec / qi / wei / guijing / toxicity / pregnancy / badges / source。
3. **判禁忌**：按语义判四值（禁用 / 忌用 / 慎用 / 未标注）；用容错模式 `孕妇[^。；]*?(禁用|忌用|慎用)`，不要用连写的子串。
4. **算差值**：同一批数据跑一遍朴素子串，列出不一致的药名与原因（本章为乳香、莪术、三棱）。
5. **列缺口**：把「未标注」单列，注明这是教材缺口、不是阴性结论。
6. **加护栏**：每条结果附「本节未含：剂量、炮制、配伍、辨证」。

## 输出模板

```text
第20章 活血化瘀药：4 节 / 23 小节 / 69 段 / 4184 字
节×规模：20.1 7味 21段 1248字 | 20.2 7/21/1384 | 20.3 5/15/821 | 20.4 4/12/731
四气：温10 平7 寒2 微寒2 微温1 热1
归经：肝23 脾9 心7 肾4 …（23 味全归肝）
毒性：无毒19 小毒2 大毒2（马钱子、斑蝥）
妊娠：忌用15 / 慎用7 / 未标注1（骨碎补）
口径差异：子串法忌用12 味，容错法15 味，差 3 味（乳香、莪术、三棱）
护栏：同归肝 ≠ 可互换；未标注 ≠ 可用。
```

## 质量判据

- 逐节字数相加等于章字数 4184，不等就是聚合漏了段
- 每条 pregnancy 都能指到具体句子，且插入语写法不被漏
- 「未标注」条目数与实际缺口一致，且被显式标注
- 四气保留「微寒」「微温」，不回写成「寒」「温」

> 本技能输出为教学与检索辅助，不构成用药建议。
