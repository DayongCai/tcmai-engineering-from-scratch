# 活血化瘀药禁忌抽取器

## 用途

把活血化瘀药（教材·第20章，23 味）的教材条目转成**可核对的多轴记录**：节 / 性味归经 / 毒性 / 妊娠禁忌三档 / 教材定位语。
用于建库、教学演示、写文献综述时的「出处定位」。不用于开方、不用于替代药决策。

## 提示词

```text
你是中药学文本结构化助手。输入是教材·第20章「活血化瘀药」的 23 个小节，每节三段：
来源与性味归经 / 功效与主治 / 用法用量与使用注意。

请逐味输出一条 JSON：
{"name","sec","qi","wei":[],"guijing":[],"toxicity","pregnancy","badges":[],"source"}

规则：
1. 只抽原文写到的内容。原文没写妊娠禁忌的，pregnancy 必须是 "未标注"，
   不要写 "可用"，也不要按同类药推定。
2. pregnancy 取四值之一：禁用 / 忌用 / 慎用 / 未标注。
   注意教材会写「孕妇及月经过多者忌用」这类插入语，须按语义判档，不能只做子串匹配。
3. toxicity 取四值：大毒 / 小毒 / 有毒 / 无毒，判据是原文「有大毒」「有小毒」「有毒」。
4. qi 原样保留「微寒」「微温」，不要压平成「寒」「温」。
5. badges 抽原文中带「要药」的定位短语，逐条保留，不合并、不改写。
6. sec 写节号（20.1–20.4），source 写「教材·第20章·20.x.y 药名」。

最后单独输出两段：
A. 「抽取口径差异」：用子串法与你自己的语义法各跑一遍 pregnancy，列出不一致的药名与原因。
B. 「缺口清单」：哪些药在本章没有妊娠条目，为什么不能当作阴性结论。
```

## 使用示例

输入（节选）：「莪术煎服6-9g。使用注意：孕妇及月经过多者忌用；气血两虚者慎用。」

输出：

```json
[{"name":"莪术","sec":"20.4","qi":"温","wei":["辛","苦"],"guijing":["肝","脾"],
  "toxicity":"无毒","pregnancy":"忌用","badges":[],
  "source":"教材·第20章·20.4.1 莪术"}]
```

「抽取口径差异」：莪术——子串「孕妇忌用」不命中（插入「及月经过多者」），语义法命中「忌用」。
「缺口清单」：骨碎补——本章无妊娠条目，标为缺失，不推定。

## 为什么这样限制

- 四值禁忌而不是布尔值：禁用/忌用/慎用对应三种不同的临床动作，压平就是把判断权藏进代码。
- 原样保留「微寒」：一旦压平成「寒」，就再也回不到教材的表述，后续统计无法复核。
- 单列「口径差异」：子串法与语义法的差值，正是漏项发生的地方；不写出来，漏项就永远沉默。
- 单列「缺口清单」：未标注必须显性，否则会被下游当成「安全」。
