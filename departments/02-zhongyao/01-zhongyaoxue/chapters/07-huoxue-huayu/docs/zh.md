# 第 7 章 · 活血化瘀药：节分类、归经轴与禁忌的可计算化

> **MOTTO:** 「川芎功效活血行气、祛风止痛。」——《中药学·第20章·20.1》
>
> **PROBLEM:** 病人说「痛」，你能背出二十三味活血药的名字，却说不清为什么川芎在 20.1、丹参在 20.2、土鳖虫在 20.3——更说不清一个孕 12 周的患者，这二十三味里到底有几味要先划掉。要回答这两个问题，光靠记忆不够，得让教材的**分类轴**和**禁忌表述**都变成可以逐条核对的数据。

## 核心概念

### 中医：四节的分法是一条「场景轴」

教材·第20章把活血化瘀药分成四节：20.1 活血止痛药（7 味）、20.2 活血调经药（7 味）、20.3 活血疗伤药（5 味）、20.4 破血消癥药（4 味）。这四节的名字里没有一条经络，全是**用在哪**：止痛、调经、疗伤、消癥。所以分类轴是场景轴，归经轴是另一根轴。

两根轴一交叉，第一个反直觉的结论就出来了：二十三味药**全部**归肝经。教材·第20章·20.2.6 牛膝讲「性善下行，引血引火下行」，说的是方向；20.4.2 三棱讲「破血之力峻于莪术」，说的是力度。方向、力度、场景都在变，归经不变——归经在这里是**入门门槛**，不是区分依据。

第二个反直觉结论来自力度词。「破血」这个词在教材里出现于六味药，却横跨三节：20.1 的姜黄、20.3 的土鳖虫、20.4 的莪术三棱水蛭斑蝥。也就是说，节标题给的力度暗示（20.4 才叫破血消癥）与正文的力度词并不严格对齐。这不是教材写错，而是提示我们：**标题是纲，正文是目，做检索要落到正文**。

### AI/工程：把「禁忌」抽成三档，而不是抽成一个布尔值

妊娠禁忌在教材里写成三种强度：禁用（绝对不用）、忌用（一般不用）、慎用（可用但慎）。三者混成一个 true/false，临床上就是把「慎用」当成「禁用」，或者把「禁用」悄悄放过去。

真正的工程细节在抽取那一步。朴素写法是查子串「孕妇忌用」，在这一章只能捞到 12 味；因为教材把三味的禁忌写成了插入语式——教材·第20章·20.4.1 莪术写的是「孕妇及月经过多者忌用」。中间插了「及月经过多者」，子串就断了。换成 `/孕妇[^。；]*?(禁用|忌用|慎用)/` 能捞到 15 味，补回乳香、莪术、三棱。

漏 3 味不会报错、不会抛异常、不会让任何一行变红。它只是让一份本该 15 行的清单变成 12 行，然后有人照着 12 行开方。这是本章最值得记住的一课：**静默失真是抽取任务里最贵的 bug**。

## BUILD IT：从零实现

```js
const CHAPTER = '20';
const units = () => chapter().secs.flatMap((s) =>
  s.subs.map((u) => ({ sec: s.no, name: u.title, paras: u.paras })));

// 禁忌：三档 + 容错正则（插入语「孕妇及月经过多者忌用」也要命中）
const pregTolerant = (name) =>
  (bodyOf(name).match(/孕妇[^。；]*?(禁用|忌用|慎用)/) || [null, '未标注'])[1];

// 力度词与节标题的交叉表
const breakBlood = () => units().filter((u) => u.paras.join('').includes('破血'));
```

三个函数都不含任何写死的统计结果：四气、归经、禁忌全部从 `drugs.json` 与 `底本.json` 现算，改一个字，输出就跟着变。

## 代价与边界

- **归经 100% 归肝，不代表 23 味可以互换。** 归经一致只说明「作用部位同属肝」，力度、毒性、禁忌、剂量差异极大：马钱子内服 0.3–0.6g 且有大毒，丹参 10–15g 且可用于久服。把「同归肝」当成「同类」，是本章最容易犯的错。
- **节标题不是严格划分。** 「破血」6 味横跨 3 节，说明标题是纲、正文是目。任何按标题聚合的统计都会把姜黄归到「止痛」而漏掉它的破血力度——**聚合必有损**，只是要写明损在哪。
- **关键词抽取有天花板。** 本章靠「孕妇…禁用/忌用/慎用」抽禁忌，遇到「妊娠期不宜」「胎前慎服」这类写法就抽不到。本章的 15 味是**教材这一种写法**下的结果，不是全部事实。
- **「要药」是教材立场，不是疗效排名。** 9 条定位语只说明「教材在这个病位上重点提了它」，不含对照试验、不含剂量效应，不能拿来排序。
- **未标注不等于安全。** 骨碎补没有妊娠条目，这是教材的缺口，不是「孕妇可用」的证据。缺口应当被看见并被标为缺失，而不是被当成阴性结论。

> **免责声明：** 本章的统计只针对教材文本本身，用于教学与检索练习；数据不含剂量、炮制、配伍与辨证信息，不构成用药建议。临床用药须由执业中医师依据药典与患者具体情况决定。

## 进阶思考

统计做得越顺，越容易忘掉统计的前提是「文本怎么写的」。这一章给出的三个数字——23 味全归肝、15 味忌用、6 味破血——都可以在十分钟内复算出来，也都可能在换一份教材后全部变掉。可复算，是它比背诵强的地方；依赖写法，是它比背诵脆的地方。
