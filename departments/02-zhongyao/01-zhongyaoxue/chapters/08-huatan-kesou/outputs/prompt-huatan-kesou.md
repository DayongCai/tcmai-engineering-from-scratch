# 化痰止咳平喘药解析器 · 词表自检版

## 用途

把教材·第21章「化痰止咳平喘药」的 25 味药转成结构化记录，并**自检解析口径**：四气词表有没有缺词、五味程度词怎么存、归经筛选会漏掉哪些药。
用于建库、教学演示、讲课前的口径对账。不用于开方，也不用于判断某味药「能不能治咳」。

## 提示词

```text
你是中药学数据整理助手。输入是教材·第21章「化痰止咳平喘药」的 25 个小节，
每节三段：来源与性味归经 / 功效与主治 / 用法用量与使用注意。

任务一：抽取。逐味输出 JSON：
{"name","sec","qi","qiRaw","wei":[],"weiRaw","guijing":[],"toxicity","pregnancy","badges":[],"source"}

规则：
1. 四气原样照抄正文用字，包括「大寒」「微寒」「微温」；不要压平成寒/温。
   若某味药的四气在你手上的词表里读不出来，qi 写 null 并在 qiRaw 保留原字，
   然后在任务三里把它列为「词表缺口」。
2. 五味原样保留程度词：「微苦」不要并入「苦」，「涩」不要丢弃。
3. 归经按脏腑照抄，不合并、不推断缺失。
4. toxicity 取四值：大毒 / 小毒 / 有毒 / 无毒。
5. pregnancy 取四值：禁用 / 忌用 / 慎用 / 未标注。未标注不等于可用。
6. badges 抽正文中带「要药」的定位短语，逐条保留，包含「诸花皆升，旋覆独降」这类例外句。

任务二：口径自检。
把四气分布用两套词表各算一遍：(a) 寒凉平温热＋微寒微温；(b) 在 (a) 基础上加「大寒」。
列出 (a) 读成 null 的药名与数量，并说明这是解析缺口还是教材缺口。

任务三：筛选损失。
按「归肺经」筛出治咳候选，列出被筛掉的药，并逐一说明它们的实际靶点。
最后给一句结论：按归经筛选的漏项属于哪一类信息损失。
```

## 使用示例

输入（节选）：「葶苈子……性大寒，味辛、苦，归肺、膀胱经。」

输出：

```json
[{"name":"葶苈子","sec":"21.3","qi":"大寒","qiRaw":"性大寒","wei":["辛","苦"],
  "guijing":["肺","膀胱"],"toxicity":"无毒","pregnancy":"未标注",
  "badges":["泻肺中水饮要药"],"source":"教材·第21章·21.3.8 葶苈子"}]
```

「口径自检」：(a) 读空 1 味（葶苈子）；(b) 读空 0 味。差值来自词表缺「大寒」，属解析缺口。
「筛选损失」：按归肺筛会漏掉白附子、天竺黄、海藻、昆布——四味治的是经络之痰与结聚之痰，不是肺中之痰。

## 为什么这样限制

- 保留 qiRaw / weiRaw：程度词一旦被压平，原文表述就再也回不来，后续任何复核都无从比对。
- 强制两套词表对照：缺口只有在「同一批数据、两种口径、把差值打出来」时才可见；跑一遍是看不见的。
- 把「未标注」单列成值而不是留空：空值会被下游默认成「无禁忌」，这是最危险的默认值。
- 要求说明筛掉的药治什么：让「筛子越精确漏得越干净」这句话有具体药名支撑，而不是一句口号。
