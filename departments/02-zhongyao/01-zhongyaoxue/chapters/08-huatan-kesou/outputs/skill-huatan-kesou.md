# huatan-kesou

## 何时使用

- 把教材·第21章「化痰止咳平喘药」的 25 味药建成结构化库
- 讲课或写稿前要对一遍口径：四气词表全不全、五味程度词怎么存
- 需要说明「为什么按归经筛选会漏药」时，要一份带药名的清单

## 不适用

- 直接开方或选替代药（本技能不含剂量、炮制、配伍、辨证）
- 判断某味化痰药「能不能治咳」——归经只说明作用部位，不说明适应证
- 含毒性药材的安全剂量判断（本技能只标毒性档位，不给剂量）

## 步骤

1. **对齐规模**：3 节 / 25 小节 / 75 段 / 4306 字，逐节字数相加必须等于章字数。
2. **抽字段**：name / sec / qi / qiRaw / wei / weiRaw / guijing / toxicity / pregnancy / badges / source。
3. **词表自检**：四气用「含大寒」与「不含大寒」两套词表各跑一遍，列出读空项（本章为葶苈子）。
4. **程度词保留**：微苦（瓜蒌、款冬花）与涩（白果）不并档，原字存 raw。
5. **筛选损失**：按归肺筛一遍，列出被筛掉的四味（白附子、天竺黄、海藻、昆布）并写明靶点。
6. **加护栏**：每条结果附「本节未含：剂量、炮制、配伍、辨证；未标注 ≠ 可用」。

## 质量判据

- 四气分布合计 = 25，且「大寒」独立成档
- 读空项数量与词表缺口一一对应，能被复现
- 归肺筛选的漏项列出药名与靶点，不只给数字
- badges 条目保留原文措辞（含「诸花皆升，旋覆独降」这类例外句）

> 本技能输出为教学与检索辅助，不构成用药建议。
