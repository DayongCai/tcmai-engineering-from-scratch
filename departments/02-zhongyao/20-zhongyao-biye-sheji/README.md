## 一、这门课没有教材

本库无《中药毕业设计》教材；六环节由《中药分析学》《中药化学》《中药药剂学》三门的对应单元派生；每章再挂一条 `standards/biye` 的**真实台账锚点**，数字逐字可查，**不编校名、不编人名、不编「某届学生」**。

中药毕设的对象几乎都是「一批样品的质量一致性」：指标选得对，一年才有产出；指标选错，做得再规范也只是自证。
