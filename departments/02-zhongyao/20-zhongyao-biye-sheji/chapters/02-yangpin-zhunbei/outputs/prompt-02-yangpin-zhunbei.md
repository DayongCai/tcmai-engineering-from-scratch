# 样品不代表性，图谱再精密也只是自证 · 提示词

## 用途

给「样品不代表性，图谱再精密也只是自证」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「代表性是取样问题，不是统计问题 → 批次矩阵：用哪几个维度切开「批」 → 样品登记与留样：台账十字段 → 中期节点：数据可用性判定」这条链。

## 边界

本章为教学材料，用于毕业设计与实验训练，不构成药品检验结论、质量判定或合规意见；具体操作以现行规范与所在机构制度为准。
