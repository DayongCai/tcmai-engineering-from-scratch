# 论文的说服力在绪论就定了，答辩只是把它念一遍 · 提示词

## 用途

给「论文的说服力在绪论就定了，答辩只是把它念一遍」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「绪论不是学科介绍，是把判据摆到桌面上 → 证据链的四层：每层对应论文的一个部位 → 答辩：四类必被问到的问题与应答结构 → 评分维度与失效模式」这条链。

## 提示词

```
我在学《中药毕业设计与知识移交》第 5 章「论文的说服力在绪论就定了，答辩只是把它念一遍」，本章 6 节 / 3,060 汉字，习题 6 道。
正文见本章 `docs/zh.md`，关键数字由 `node code/main.js` 从正文现算。

请按以下顺序带我走：
1. 先用一句话说清本章要回答的问题，以及它为什么不能直接套用上一章；
2. 按正文小节顺序，逐节给出该节的判据，并指出这一节最容易被误判的那一处；
3. 本章的判据包括（请逐条解释它在什么条件下成立、什么条件下失效）：
   - 为什么必须用你选的这个指标、这个判据，来判断这批样品的质量一致
   - 把问题定位到一个具体缺口
   - 把判据摆出来
   - 把边界说清
   - 绪论与结果必须能互相索引
   - 把结论句里的每一个名词，回到数据里找它的支撑
4. 指出本章写到类别就止步、不再给参数的地方。

要求：不编造正文没有的数字；引文写到《书名·篇名》级；不确定的地方直接说「正文未展开」。
```

## 边界

本章为教学材料，用于毕业设计与学术写作训练，不构成学术评价、成果认定或合规意见；具体操作以现行规范与所在机构制度为准。
