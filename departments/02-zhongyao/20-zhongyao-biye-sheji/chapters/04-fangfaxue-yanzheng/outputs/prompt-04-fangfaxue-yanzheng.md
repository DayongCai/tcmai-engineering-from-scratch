# 方法学验证是结论的准生证，不是附录里的形式 · 提示词

## 用途

给「方法学验证是结论的准生证，不是附录里的形式」这一章备课或自学时用的提示词。它不生成结论，只把本章的判据、规模和边界摆出来，
让使用者自己走一遍「八个参数各自回答一个问题 → 失效模式、评分与考核 → 运行与验证 → 资料来源（主要参考）」这条链。

## 边界

本章为教学材料，用于毕业设计与实验训练，不构成药品检验结论、质量标准判定或合规意见；具体操作以现行规范与所在机构制度为准。
