## H.1 本章要解决的问题

筋伤（扭伤、劳损、肌腱病）看起来「不要紧」，但两类错误很常见：把骨折或韧带断裂当扭伤，以及急性期就上重手法与热敷。轮转要练判断：先排除骨折与重要韧带损伤，再按急性期/恢复期分期处理，最后给出可量化的功能目标。

## H.2 本章目标（可检验）

- 完成筋伤的鉴别：骨折、韧带断裂、肌腱撕裂、神经卡压的排除依据
- 按分期（急性 0–72 小时 / 亚急性 / 慢性）给出不同处理与手法强度
- 设定可量化的功能目标（活动度、力量、疼痛评分）并复评

## H.3 操作流程

1. 排除骨折：局部压痛、纵向叩击痛、负重能力、畸形与异常活动；符合 Ottawa 类指征者拍片，不凭「能走」排除
2. 韧带与肌腱评估：稳定性试验（如踝内翻应力、膝侧方应力）、抗阻试验、局部凹陷或空虚感、肿胀与瘀斑位置
3. 神经与血管：远端感觉与运动、搏动；卡压部位做诱发试验并记录
4. 分期判断：受伤时间、肿胀与瘀斑演变、疼痛性质（静息痛/活动痛）、皮温
5. 急性期处理（0–72 小时）：保护、适度负荷、冰敷（每次 15–20 分钟，间隔 ≥2 小时）、加压、抬高；**此期不做重手法与热敷**
6. 亚急性期（3 天–3 周）：逐步加入关节活动度训练与轻手法（㨰、揉、点按），强度以不加重肿胀为度
7. 慢性期：手法松解、牵伸、离心力量训练、本体感觉训练；肌腱病以渐进负荷为主
8. 中医辨证与选穴（如配合）：气滞血瘀、寒湿痹阻、气血不足；外治与针刺方案各写依据
9. 功能目标设定：关节活动度（具体角度）、力量（如单腿提踵次数）、疼痛（0–10 分），写基线值
10. 训练处方：动作、组数、次数、频次、进阶条件——写清「达到什么才进阶」
11. 复评：3 次或 1 周复评，比较活动度、力量与疼痛分值；无改善需重新评估诊断
12. 记录与交代：按 H.5 模板填「筋伤评估与治疗记录表」；交代急性期禁忌（热敷、按摩、酒精）与返诊信号

## H.5 模板：筋伤评估与治疗记录表

| 字段 | 填写要求 |
|------|----------|
| 受伤经过 | 时间、机制、当时能否继续活动 |
| 骨折排除 | 压痛、叩击痛、负重、畸形；是否拍片 |
| 韧带/肌腱 | 稳定性试验、抗阻试验、肿胀瘀斑位置 |
| 神经血管 | 远端感觉运动、搏动、诱发试验 |
| 分期 | 急性/亚急性/慢性，判断依据 |
| 治疗 | 冰敷/加压/抬高、手法种类与强度、外治或针刺 |
| 功能目标 | 活动度角度、力量指标、疼痛分值（基线） |
| 训练处方 | 动作、组数、次数、频次、进阶条件 |
| 复评 | 分值对比、是否调整诊断 |
| 交代 | 急性期禁忌、返诊信号 |

> 本表是本章的交付物：首诊填全；每次治疗记手法与训练，复评时填分值对比。

## H.6 常见失效与处置

- **把骨折当扭伤** → 「能走路」不能排除骨折；叩击痛与负重能力必须查
- **急性期热敷与重手法** → 加重肿胀与出血；72 小时内以保护与冰敷为主
- **只做被动手法不做力量训练** → 慢性期难愈；肌腱与韧带需要渐进负荷
- **功能目标写「恢复活动」** → 无角度无分值，无法判断进展
- **忽略不稳与麻木** → 提示韧带断裂或神经卡压，需转诊评估
- **复评缺失** → 同一方案反复做而不评估，是最常见的时间浪费

## H.7 出科考核

- 鉴别与分期判断（35%）
- 分期对应处理与手法强度（25%）
- 功能目标与训练处方（25%）
- 复评与交代（15%）
