## H.1 本章要解决的问题

复位最容易出的事是「复了位但没评估血运与神经」，几小时后才发现手指发凉。

## H.2 本章目标（可检验）

- 能在复位前后各完成一次血运与神经评估
- 能写出复位方法与固定方式及依据
- 能识别需要手术的指征

## H.3 操作流程

1. 读片：确认部位、类型、移位方向与关节面
2. 查体：皮温、毛细血管充盈、动脉搏动、感觉与肌力
3. 复位：写手法、牵引方向、复位次数
4. 固定：夹板或石膏的位置、长度、松紧
5. 复评：复位后再查血运神经并记录

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 影像已读并写出类型与移位
- [ ] 复位前血运神经已查
- [ ] 复位手法与次数已记录
- [ ] 固定方式与范围已记录
- [ ] 复位后血运神经已复查
- [ ] 末梢循环宣教已交代
- [ ] 复查时间与影像计划已定

## H.5 模板：骨折复位记录表

| 字段 | 填写要求 |
|------|----------|
| 影像 | 部位、类型、移位 |
| 血运神经（前） | 皮温、充盈、搏动、感觉 |
| 复位 | 手法、牵引、次数 |
| 固定 | 方式、范围、松紧 |
| 血运神经（后） | 复查结果 |
| 随访 | 复查时间与影像 |

> 本表是本章的交付物：每次复位一张，含复位前中后三次评估。

## H.6 常见失效与处置

- **只复位不评估血运** → 骨筋膜室综合征不可逆；复位前后都必须查
- **固定过紧** → 压迫神经血管；交代末梢观察要点
- **不写复位次数** → 多次复位提示不稳定，需重新考虑方案

## H.7 出科考核

- 影像与分型（30%）
- 血运神经评估（一票否决项）
- 固定与随访计划（30%）
- 记录完整（20%）
