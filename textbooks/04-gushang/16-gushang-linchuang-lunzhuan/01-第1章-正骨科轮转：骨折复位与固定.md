## H.1 本章要解决的问题

闭合复位最容易出事的环节不是手法，而是「没拍片就动手」和「复位完不看末梢」。骨折端可能压迫血管神经，固定过紧会造成缺血，过松会再移位——两头都要靠可核对的数据判断。轮转要把顺序固定死：影像—查体—复位—对位核对—末梢与固定检查—复查时点。

## H.2 本章目标（可检验）

- 独立完成复位前评估：影像结论、神经血管查体、软组织条件与皮肤情况
- 在带教监督下完成一次闭合复位与夹板/石膏固定，并写下参数
- 复位后完成对位核对与末梢循环检查，写出复查时点与警示症状

## H.3 操作流程

1. 影像先行：正侧位片（必要时加特殊位），记录骨折部位、类型、移位方向与程度；**未看片不动手**
2. 神经血管查体：远端动脉搏动、毛细血管充盈、皮温与颜色、感觉（皮节）、运动（关键肌群）——逐项记左右对比
3. 软组织与皮肤：肿胀程度、张力性水泡、开放伤口、皮肤完整性；开放骨折按急诊流程处理，不在此例
4. 复位方案：麻醉/镇痛方式、体位、牵引方向与力量、手法步骤；写清「先纠正什么、再纠正什么」
5. 复位操作：在带教监督下进行，力度渐进，避免暴力反复；每次尝试记次数，超过 2–3 次无效即请示
6. 对位核对：复位后即刻拍片，记录成角、移位、长度与旋转的残余量；与复位前对比
7. 固定：夹板/石膏选择、衬垫位置、固定范围（跨关节与否）、松紧度（能插入一指）、塑形要点
8. 末梢复查：固定后再查一次动脉搏动、颜色、皮温、感觉、运动与被动牵拉痛；异常立即松解并上报
9. 抬高与冷敷：患肢抬高位置、冷敷时长与间隔；写清观察频次（如前 24 小时每 2 小时看一次）
10. 交代警示：剧痛进行性加重、麻木、苍白、活动不能、被动牵拉痛 —— 出现任一条立即返院
11. 复查计划：首次复查时间（如 3–7 天）、拍片时点、拆固定与开始功能锻炼的参考时点
12. 记录与复盘：按 H.5 模板填「骨折复位与固定记录表」，把复位前后对位数据并列

## H.5 模板：骨折复位与固定记录表

| 字段 | 填写要求 |
|------|----------|
| 骨折描述 | 部位、类型、移位方向与程度（复位前） |
| 神经血管查体 | 搏动、充盈、皮温颜色、感觉、运动，左右对比 |
| 软组织与皮肤 | 肿胀、水泡、伤口、皮肤完整性 |
| 复位方案 | 镇痛/麻醉、体位、牵引方向、手法顺序 |
| 复位过程 | 尝试次数、力度、患者反应 |
| 复位后对位 | 残余成角/移位/长度/旋转（附片号） |
| 固定 | 方式、范围、衬垫、松紧度、塑形 |
| 末梢复查 | 固定后五项，异常处置 |
| 交代 | 抬高冷敷、观察频次、五条警示症状 |
| 复查计划 | 首查时间、拍片时点、拆固定与锻炼时点 |

> 本表是本章的交付物：每次复位一张；复位前后影像与查体并列填写，随病历归档并作为复查依据。

## H.6 常见失效与处置

- **未拍片先复位** → 可能加重移位或漏掉合并损伤；影像先行是硬规矩
- **复位后不查末梢** → 骨筋膜室综合征的黄金处理窗口很短，靠的就是固定后复查
- **固定过紧** → 以「能插入一指」为下限判据；过紧需立即松解
- **反复暴力复位** → 加重软组织损伤与肿胀；超过 2–3 次无效应请示
- **只写「对位良好」** → 没有成角/移位数值，复查时无法判断是否再移位
- **警示症状不交代** → 患者不知道何时返院，是延误的常见原因

## H.7 出科考核

- 复位前评估与影像依据（25%）
- 复位操作规范与权限（25%）
- 固定参数与末梢复查（一票否决：固定后未查末梢即不通过）
- 交代与复查计划（25%）
