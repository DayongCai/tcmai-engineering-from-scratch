## H.1 本章要解决的问题

急诊骨伤的顺序与门诊完全相反：先保命（出血、气道、休克），再保肢（血管神经、骨筋膜室），最后才是骨折本身。学生最容易犯的错是「一进门就看骨折」，而漏掉正在发生的失血与压迫。这一章练的是固定顺序与时间窗。

## H.2 本章目标（可检验）

- 按「保命—保肢—保骨」顺序完成创伤初评并记录时间点
- 完成开放性骨折的止血、覆盖、制动与破伤风/抗生素流程记录
- 识别骨筋膜室综合征的早期征象并在 30 分钟内上报

## H.3 操作流程

1. 初评（ABCDE）：气道、呼吸、循环（脉搏、血压、毛细血管充盈）、意识、暴露与保温；异常立即呼叫带教并启动抢救
2. 大出血控制：直接压迫、加压包扎、必要时止血带（记录上带时间，每 30–60 分钟评估一次）
3. 保肢评估：远端动脉搏动、皮温颜色、毛细血管充盈、感觉与运动、被动牵拉痛——六项（5P 类）逐项记录
4. 开放伤处理：无菌敷料覆盖、不要在现场还纳外露骨端、记录伤口大小与污染程度、拍照（在不延误前提下）
5. 制动：夹板或临时固定，固定范围跨上下关节；记录固定前后末梢情况
6. 时间轴：受伤时间、到院时间、首次评估时间、固定时间、离室/手术时间——五个时间点全部记录
7. 骨筋膜室综合征监测：与损伤程度不相称的剧痛、被动牵拉痛、感觉异常、患区张力高；**不以动脉搏动消失作为判断依据**
8. 用药与预防：破伤风评估（免疫史、伤口性质）、抗生素按院内规范、镇痛；记录执行时间
9. 影像与检查：在生命体征稳定后拍片；危重患者床旁片，避免因检查延误抢救
10. 交接与转运：向接收科室口头+书面交接（受伤机制、时间轴、已用药物、末梢情况、过敏史）
11. 家属沟通：病情、下一步、可能的风险，留痕
12. 复盘：按 H.5 模板填「急诊创伤处置记录表」，24 小时内完成复盘并写明「哪一步若延误会导致什么」

## H.5 模板：急诊创伤处置记录表

| 字段 | 填写要求 |
|------|----------|
| 时间轴 | 受伤、到院、首评、固定、离室/手术 |
| ABCDE 初评 | 各项结论与异常处置 |
| 出血控制 | 方式、止血带时间与复评 |
| 保肢六项 | 搏动、皮温、颜色、充盈、感觉运动、牵拉痛 |
| 伤口 | 部位、大小、污染、是否开放、覆盖方式 |
| 制动 | 方式、范围、固定前后末梢对比 |
| 骨筋膜室监测 | 疼痛程度、牵拉痛、张力、感觉异常 |
| 用药与预防 | 破伤风、抗生素、镇痛，执行时间 |
| 交接 | 接收科室、交接内容、接收人签名 |
| 复盘 | 延误点、后果假设、改进措施 |

> 本表是本章的交付物：每位创伤患者一张；随抢救记录归档，交接时随患者同行。

## H.6 常见失效与处置

- **一进门就看骨折** → 漏掉失血与气道问题，是最致命的顺序错误
- **止血带不记时间** → 超时会导致肢体坏死；上带时间必须写在醒目位置
- **现场还纳外露骨端** → 把污染带入深部组织；只能覆盖，不还纳
- **等搏动消失才怀疑骨筋膜室综合征** → 那时已晚；以剧痛与被动牵拉痛为主判据
- **因拍片延误抢救** → 生命体征不稳时先稳定，影像可床旁或后补
- **交接只口头** → 遗漏用药与末梢情况，下一班需要重新摸一遍

## H.7 出科考核

- 初评顺序与时间轴（一票否决：未按 ABCDE 顺序即不通过）
- 出血控制与保肢评估（30%）
- 制动与骨筋膜室监测（25%）
- 交接与复盘（15%）
