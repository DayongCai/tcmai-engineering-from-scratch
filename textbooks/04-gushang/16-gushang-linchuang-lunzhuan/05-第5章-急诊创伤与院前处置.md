## H.1 本章要解决的问题

创伤的第一小时决定预后。骨伤学生最需要练的是：在不能确诊的情况下，先做对不会错的事。

## H.2 本章目标（可检验）

- 能按 ABCDE 顺序完成初步评估
- 能正确实施止血、包扎、固定、搬运
- 能记录时间节点与处置顺序

## H.3 操作流程

1. 初评：气道、呼吸、循环、意识、暴露与保温
2. 止血：直接压迫为主，记录止血带时间
3. 固定：就地取材，固定上下两个关节
4. 搬运：脊柱损伤按轴线翻身与硬板转运
5. 记录：每个处置的时间点与执行人

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] ABCDE 五项均已评估
- [ ] 止血方式与时间已记录
- [ ] 固定范围含上下关节
- [ ] 脊柱损伤按轴线处理
- [ ] 转运方式已记录
- [ ] 生命体征时间序列已记
- [ ] 交接内容已口头复述确认

## H.5 模板：创伤初评与处置记录表

| 字段 | 填写要求 |
|------|----------|
| 时间轴 | 受伤、到场、处置、离场 |
| ABCDE | 逐项发现 |
| 止血固定 | 方式、范围、止血带时间 |
| 搬运 | 方式与体位 |
| 交接 | 接收方与复述确认 |

> 本表是本章的交付物：急诊每例一张，随交接班传递。

## H.6 常见失效与处置

- **先查骨折后查气道** → 顺序错误会致命；严格 ABCDE
- **止血带不记时间** → 超时致肢体坏死；必须记录
- **固定只固定骨折端** → 未固定上下关节等于没固定

## H.7 出科考核

- ABCDE 顺序（一票否决项）
- 固定与搬运规范（40%）
- 时间与交接记录（30%）
