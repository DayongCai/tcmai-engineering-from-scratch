## H.1 本章要解决的问题

关节病的中医处置与手术指征常被混谈。轮转要能把「现在该保守」与「已经该手术」分开。

## H.2 本章目标（可检验）

- 能按影像分期与功能评分判断所处阶段
- 能列出手术指征并识别其中任一条
- 能写出保守治疗方案与复评时点

## H.3 操作流程

1. 读片：关节间隙、软骨、骨赘、力线
2. 评分：WOMAC 或 HSS 等，记录基线
3. 判指征：静息痛、夜间痛、明显畸形、保守无效
4. 方案：保守（中药、针灸、手法、训练）与时限
5. 复评：约定复评时点与升级条件

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 影像分期已写
- [ ] 功能评分基线已记
- [ ] 手术指征逐条判断
- [ ] 保守方案含时限
- [ ] 升级条件已写
- [ ] 体重与活动方式宣教已做
- [ ] 复评时点已定

## H.5 模板：关节病分期与方案表

| 字段 | 填写要求 |
|------|----------|
| 影像 | 间隙、软骨、骨赘、力线 |
| 功能评分 | 量表与分值 |
| 手术指征 | 逐条结论 |
| 保守方案 | 内容、疗程、复评 |
| 升级条件 | 什么情况下转手术 |

> 本表是本章的交付物：首诊与复评各一张。

## H.6 常见失效与处置

- **只看影像不看功能** → 影像重但功能好可继续保守
- **保守无时限** → 无限期保守会错过手术窗口
- **不写升级条件** → 复诊时无法判断是否该转

## H.7 出科考核

- 分期与评分（40%）
- 指征判断（30%）
- 方案与升级条件（30%）
