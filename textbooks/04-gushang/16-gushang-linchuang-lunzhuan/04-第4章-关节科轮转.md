## H.1 本章要解决的问题

关节病以膝、肩最常见，最容易被「按一按、热一热」糊过去。真正要练的是分层：是退变、炎症、损伤还是感染？能不能负重？该练还是该静？以及中医外治与功能训练怎么配合，才能让患者三个月后还能自己走路。

## H.2 本章目标（可检验）

- 完成关节的结构化评估：疼痛与负重关系、活动度、稳定性、肿胀与积液、力线
- 区分退变性、炎症性、损伤性与感染性四类，写出鉴别依据
- 制定含负荷管理、功能训练、外治与复评的三个月方案

## H.3 操作流程

1. 危险排除：关节红肿热痛伴发热（感染/痛风）、外伤后不能负重、明显畸形与不稳、夜间静息痛进行性加重 —— 命中即转诊或进一步检查
2. 疼痛与负荷关系：起步痛、活动后痛、静息痛、夜间痛；步行距离与上下楼能力（记具体层数/米数）
3. 查体：活动度（屈伸角度）、肌力（股四头肌、臀中肌、肩袖）、稳定性（内外翻、前后抽屉）、肿胀与积液（浮髌试验）、力线（膝内翻/外翻）
4. 影像与化验：X 线分级（如 Kellgren-Lawrence）、必要时 MRI；炎症指标与尿酸按需
5. 分类判断：退变性（负重痛、骨性膨大、活动后加重）、炎症性（晨僵 >30 分钟、多关节、肿胀）、损伤性（明确外伤、不稳、交锁）、感染性（红肿热痛+发热）
6. 辨证：痹证分风寒湿、风湿热、痰瘀阻络、肝肾亏虚；写两行结论与证据
7. 负荷管理：体重管理建议、步行与登楼限量、辅助器具（手杖/护具）使用要点
8. 功能训练：股四头肌等长收缩、直腿抬高、臀中肌训练、肩袖等长与弹力带训练；组数次数写清，注明疼痛不超过 3/10 的规则
9. 外治与手法：针灸选穴、推拿松解、中药外敷的适应证与皮肤注意；感染与急性炎症期不做热敷与重手法
10. 复评：4 周、12 周各一次，指标为疼痛（0–10）、活动度角度、步行距离、肌力
11. 手术指征提示：保守 3 个月无效、明显力线异常、反复交锁或积液、影响基本生活 —— 建议转诊评估
12. 记录与复盘：按 H.5 模板填「关节评估与治疗记录表」；复盘一例「影像重但症状轻」的处理

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 活动度有角度值，肌力有分级或次数
- [ ] 稳定性与积液检查有结果
- [ ] 影像分级或化验结论已记录

- [ ] 负荷管理建议已给（体重、步行限量、辅具）

## H.5 模板：关节评估与治疗记录表

| 字段 | 填写要求 |
|------|----------|
| 危险排除 | 感染、不能负重、畸形不稳、夜间痛，逐项结论 |
| 疼痛与负荷 | 起步痛/活动痛/静息痛、步行距离、上下楼层数 |
| 查体 | 活动度角度、肌力、稳定性、浮髌、力线 |
| 影像与化验 | 分级、结论、炎症指标或尿酸 |
| 分类判断 | 退变/炎症/损伤/感染，附依据 |
| 辨证 | 证候与两行结论 |
| 负荷管理 | 体重目标、步行限量、辅具使用 |
| 训练处方 | 动作、组数、次数、频次、疼痛阈值规则 |
| 外治 | 针灸/推拿/外敷，适应证与皮肤注意 |
| 复评与转诊 | 4/12 周指标、手术指征提示 |

> 本表是本章的交付物：首诊填全；每次治疗记录训练与外治，4/12 周填复评。

## H.6 常见失效与处置

- **红肿热痛仍做热敷与推拿** → 感染或急性炎症期热敷会加重；先排除再处理
- **只练不控负荷** → 边练边走一万步，训练效果被抵消
- **疼痛阈值不设** → 训练中出现 >3/10 疼痛应减量；不设规则患者会硬扛
- **影像分级代替症状评估** → 退变分级与疼痛常不匹配；以功能指标为主
- **不提示手术指征** → 保守无效者被无限期留在理疗，错过时机
- **复评只看「好点没」** → 无角度、距离、分值，三个月后无法判断是否有效

## H.7 出科考核

- 危险排除与分类判断（一票否决）
- 查体与影像解读（25%）
- 负荷管理与训练处方（30%）
- 复评与转诊提示（25%）
