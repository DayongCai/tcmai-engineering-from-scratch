## H.1 本章要解决的问题

脊柱是「看起来最常见、实际最危险」的部位：颈腰痛患者里绝大多数不需要影像，但少数红旗病例延误一天后果就不同。轮转要掌握两件事：什么时候必须拍片/转诊（红旗与影像指征），以及手法与牵引的安全边界（谁不能做、做到什么程度停）。

## H.2 本章目标（可检验）

- 按红旗清单判断是否需要影像与转诊，并写出判断依据
- 完成脊柱查体：活动度、压痛点、神经查体、特殊试验
- 制定含手法/牵引/训练与复评的方案，明确禁忌与停止条件

## H.3 操作流程

1. 红旗筛查：年龄 >50 岁新发痛、夜间痛醒、体重下降、肿瘤史、发热、外伤史、进行性神经功能缺失、鞍区麻木与大小便障碍、静脉吸毒或免疫抑制 —— 命中即转诊并记录
2. 影像指征：红旗阳性、神经功能缺失进行性加重、保守治疗 4–6 周无效、拟行介入或手术；无指征者不常规拍片，但要在病历写明「未拍片理由」
3. 查体：颈椎/腰椎活动度（前屈后伸侧屈旋转，记角度或范围）、压痛点与肌痉挛、肌力分级、感觉皮节、反射、病理征
4. 特殊试验：颈椎椎动脉试验、臂丛牵拉试验、腰椎直腿抬高与股神经牵拉、骶髂关节激发试验 —— 逐项记录阳性/阴性
5. 辨证与分期：经络与病位（督脉、太阳、少阳）、病性（风寒湿、瘀血、肝肾亏虚）；急性期与慢性期处理不同
6. 方案制定：手法（放松类为主）、牵引（重量、时间、体位）、训练（核心稳定、麦肯基方向偏好）、宣教（姿势与负荷）
7. 安全边界：颈部整复类手法学生不独立操作；骨质疏松、椎动脉供血不足、脊髓压迫、术后患者禁用或慎用牵引与旋转手法
8. 牵引参数：重量（一般不超过体重的一定比例，按院内规范）、时间（15–20 分钟）、体位、过程中询问与观察
9. 训练处方：动作、组数、次数、频次、进阶条件；方向偏好训练需说明依据
10. 复评：2 周复评一次，比较疼痛（0–10）、活动度、功能（如 ODI/NDI 或简版问卷）
11. 停止条件：出现眩晕、视物模糊、下肢无力加重、大小便异常，立即停止一切手法并上报
12. 记录与复盘：按 H.5 模板填「脊柱评估与治疗记录表」；复盘一例「影像有突出但症状不符」的处理逻辑

## H.5 模板：脊柱评估与治疗记录表

| 字段 | 填写要求 |
|------|----------|
| 红旗筛查 | 九项逐条有/无与依据 |
| 影像 | 是否拍片、结论、未拍片理由 |
| 查体 | 活动度、压痛、肌力分级、感觉、反射、病理征 |
| 特殊试验 | 椎动脉试验、臂丛牵拉、直腿抬高、骶髂试验 |
| 辨证 | 经络、病位、病性 |
| 治疗方案 | 手法、牵引、训练、宣教，逐项写目的 |
| 参数 | 手法强度、牵引重量/时间/体位、训练组数次数 |
| 禁忌核对 | 骨质疏松、椎动脉、脊髓压迫、术后、妊娠 |
| 复评 | 疼痛分值、活动度、功能问卷，2 周对比 |
| 停止条件 | 眩晕、视物模糊、无力加重、大小便异常 |

> 本表是本章的交付物：首诊填全；每次治疗记参数，2 周填一次复评对比。

## H.6 常见失效与处置

- **不做红旗筛查就做手法** → 肿瘤、感染、骨折被当作劳损处理，是最严重的事故路径
- **所有人常规拍片** → 无指征影像既增加负担也延误处理；应写清判断依据
- **牵引重量凭经验** → 重量与时间必须按规范记录，否则风险不可控
- **把「突出」等同「疼痛原因」** → 影像与症状常不符，需以查体与症状定位为主
- **复评只看疼痛** → 活动度与功能问卷同样重要，尤其慢性病例
- **停止条件不交代** → 患者出现眩晕仍继续训练，风险显著上升

## H.7 出科考核

- 红旗与影像指征判断（一票否决：漏筛红旗即不通过）
- 查体与特殊试验（25%）
- 方案与参数合理性（25%）
- 复评与停止条件交代（25%）
