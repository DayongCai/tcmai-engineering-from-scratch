## H.1 本章要解决的问题

腰痛患者里，真正需要干预的是少数。轮转要能识别红旗征，其余按分层处理。

## H.2 本章目标（可检验）

- 能完成腰背痛红旗征筛查
- 能按神经体征判断是否需要影像
- 能写出分层处理方案

## H.3 操作流程

1. 问红旗：年龄、体重下降、夜间痛、肿瘤史、发热、外伤、激素使用
2. 查神经：直腿抬高、肌力、感觉、反射、鞍区
3. 判影像：有红旗或神经缺损才开 MRI/CT
4. 分层：单纯腰痛、根性痛、警示性腰痛三类
5. 方案：按分层给出处理与转诊

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 七项红旗征已逐条问
- [ ] 神经查体四项已做
- [ ] 鞍区感觉已查
- [ ] 影像指征判断已写
- [ ] 分层结论已写
- [ ] 转诊或会诊理由已写
- [ ] 宣教（避免负重）已交代

## H.5 模板：腰痛分层筛查表

| 字段 | 填写要求 |
|------|----------|
| 红旗征 | 七项逐条结论 |
| 神经查体 | 直腿抬高、肌力、感觉、反射 |
| 鞍区 | 感觉与括约肌 |
| 影像指征 | 开或不开，理由 |
| 分层与方案 | 单纯/根性/警示 + 处理 |

> 本表是本章的交付物：首诊必填，作为是否开影像的依据。

## H.6 常见失效与处置

- **腰痛一律开 MRI** → 无指征影像增加过度诊疗；先筛红旗
- **不查鞍区感觉** → 马尾综合征需急诊；漏查后果严重
- **把根性痛当单纯腰痛** → 处理与预后不同；按神经体征分层

## H.7 出科考核

- 红旗征筛查（一票否决项）
- 神经查体（30%）
- 分层与方案（40%）
