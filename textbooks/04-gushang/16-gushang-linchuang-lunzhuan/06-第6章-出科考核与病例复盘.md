## H.1 本章要解决的问题

骨伤出科要证明的不是「手法会几套」，而是三条可核能力：影像会读、末梢会查、固定参数会写。考核用一份完整病例 + 一次现场操作 + 一次影像判读，把这三条钉住。

## H.2 本章目标（可检验）

- 独立完成一份骨折或筋伤病例的完整记录（影像、查体、处置、复查计划）
- 现场完成一次固定操作并说清松紧度与末梢复查判据
- 独立判读 5 张 X 线片，指出部位、类型、移位与需要警惕的合并损伤

## H.3 操作流程

1. 材料准备：1 份主病例 + 5 份治疗或复查记录，缺项补齐
2. 影像判读训练：按「部位—类型—移位—关节面—软组织」五步读片，每片写五句话
3. 查体复核：神经血管五项与稳定性试验，找同学互查并记录差异
4. 固定操作演练：夹板/石膏的衬垫、范围、塑形、松紧度（一指）与末梢复查顺序
5. 病例自检：影像依据、末梢记录、固定参数、复查时点四项是否齐全
6. 警示症状清单：为本科室常见损伤各写三条必须返院的信号
7. 现场考核：抽一例完成查体+固定+交代，边做边说判据
8. 影像答辩：随机 5 张片，说出最需要警惕的合并损伤及理由
9. 评分与反馈：按 H.7 五项打分，记录扣分点
10. 材料归档：病例、操作评分、影像判读记录三件一并交
11. 经验提炼：三条可迁移规则（如「固定后必查末梢」「未看片不动手」）
12. 补强计划：针对最低分项的两周改进动作

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 主病例含影像、查体、处置、复查计划四部分
- [ ] 读片五步法完整（部位/类型/移位/关节面/软组织）
- [ ] 神经血管五项与稳定性试验可独立完成
- [ ] 固定操作含衬垫、范围、塑形、松紧度
- [ ] 固定后末梢复查顺序正确
- [ ] 常见损伤各写了三条返院信号
- [ ] 现场操作边做边说出判据
- [ ] 5 张片判读完成并说明合并损伤风险
- [ ] 评分表五项已打分并记录扣分点
- [ ] 三件材料归档签收
- [ ] 三条可迁移规则已写
- [ ] 最低分项有改进计划

## H.5 模板：骨伤出科考核评分表

| 字段 | 填写要求 |
|------|----------|
| 病例完整度（30%） | 影像、查体、处置、复查计划齐全 |
| 影像判读（25%） | 5 张片，五步法完整，合并损伤判断 |
| 现场操作（25%） | 查体、固定、末梢复查、交代 |
| 安全问答（一票否决） | 禁忌、松紧度判据、返院信号 |
| 可迁移规则（15%） | 三条规则具体可执行 |
| 扣分记录 | 逐项写明扣分点与改进建议 |
| 签名与日期 | 评分人、复核人、日期 |

> 本表是本章的交付物：现场逐项打分；影像判读与操作分开计分，一票否决项先判。

## H.6 常见失效与处置

- **读片只报「有骨折」** → 类型、移位、关节面与软组织同样决定处理
- **固定做完不查末梢** → 最容易被抓的失分点，也是真实风险点
- **松紧度说不清判据** → 「差不多」不算判据；应以能插入一指为下限
- **返院信号说不出** → 患者安全直接受影响，属必答项
- **材料临时补写** → 复查记录的真实性经不起追问
- **规则空泛** → 「注意安全」不可执行；应写「做什么前先查什么」

## H.7 出科考核

- 病例完整度（30%）
- 影像判读（25%）
- 现场操作（25%）
- 安全问答（一票否决）
- 可迁移规则（15%）
