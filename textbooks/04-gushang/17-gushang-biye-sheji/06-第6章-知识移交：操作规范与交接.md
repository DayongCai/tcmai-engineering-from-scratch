# 第 6 章 · 知识移交：操作规范与交接

## H.1 本章要解决的问题

骨伤的手艺性在毕业设计里最重：手法靠手感，支具靠试戴。这类知识一旦只留在个人身上，下一届就要从头摸一遍，摸出来的未必是同一件东西。移交要交的不是论文一本，而是四样东西：含参数的规范、带尺寸的图纸、标明须带教的部分、一次他人复现的验证记录。四项缺一，下一届仍要从零开始。

## H.2 本章目标（可检验）

- 交出含手法参数、支具图纸、佩戴调整的操作规范
- 标注不可文字化的手感部分与带教安排、带教次数
- 由一名未参与的同学按规范独立复现一件支具并评价
- 完成归档命名与三方签收，接手人可独立起步

## H.3 操作流程

1. 列清单：规范、图纸、照片、测量表、随访记录、并发症登记，逐项写存放路径与格式，接手人按清单能一次找齐，缺件写明原因
2. 写规范：手法五参数、支具规格、制作流程、佩戴与调整，一节一事，不把结论混进操作，判断标准另立一节，术语用科室通行说法
3. 配图：复位步骤照片按顺序编号，支具出三视图并标关键尺寸与公差，图上标方向与体位，照片含标尺与日期，尺寸用毫米
4. 标不可写：牵引手感、复位过手感、支具压痛的判断，写明须带教几次、由谁带、何时算过关，未过关不得独立操作，过关由带教签字
5. 写判断规则：什么情况停止加重量、什么情况改支具、什么情况转手术，写成如果则的形式，每条给可观察征象与一个禁忌情形
6. 做复现验证：找一名未参与的同学，只给规范与图纸，独立做一件并填评价表，卡住时只记录不代为完成，也不许口头提示
7. 收验证意见：记录他在哪一步卡住、哪些尺寸看不懂，据此改规范而不是改人，改完请其再读一遍确认，改不动处标为待定
8. 写材料来源：支具材料、衬垫、耗材的规格与采购渠道，注明替代方案与不可替代处，替代后须重做试戴并记录差异
9. 写接手建议：先练哪一步、练几次算过关、第一个月该跟几台、遇到什么情况找谁，联系人写姓名、科室与可联系时段
10. 归档命名：按项目约定命名目录与文件，版本号与日期进文件名，旧版留归档区不覆盖，索引一页放首层，注明哪些文件已过时
11. 签收：规范、图纸、复现记录、未完成项四张清单，移交人、接手人、带教三方签字，缺一方不算交接完成，签收后扫描存档
12. 附一页复盘：如果重来，哪一步开始就该边做边记，写清当时的代价与改进动作，供下一届直接采用，并写明省下的时间

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 四类材料清单含路径与格式，按清单一次找齐
- [ ] 规范一节一事，未混入结论
- [ ] 步骤照片按顺序编号并标方向与标尺
- [ ] 支具三视图含尺寸与公差
- [ ] 不可写部分已标注含带教次数与过关标准
- [ ] 如果则形式的判断规则已写
- [ ] 复现由未参与同学独立完成，全程无口头提示
- [ ] 复现卡点已记录并回改规范
- [ ] 材料来源与替代方案已注明
- [ ] 接手建议含练习次数、跟台数与联系人
- [ ] 归档命名与版本号符合约定
- [ ] 三方签收完成，日期齐全

## H.5 模板：操作规范移交清单

| 字段 | 填写要求 |
|------|----------|
| 规范 | 手法参数、支具规格、流程、调整 |
| 图纸 | 三视图、关键尺寸、公差、方向 |
| 图示 | 步骤照片编号与图注 |
| 不可写部分 | 手感判断、带教次数与带教人 |
| 判断规则 | 如果则：加重量、改支具、转手术 |
| 复现验证 | 验证人、卡点、评价、修改 |
| 材料 | 规格、来源、替代方案 |
| 未完成项 | 项目、优先级、前置条件 |
| 签收 | 移交人、接手人、带教、日期 |

> 本表是本章的交付物：结题提交，教学秘书签收；接手人按此起步。

## H.6 常见失效与处置

- **只交论文** → 手艺部分无法传递，下一届重做一遍
- **图纸无尺寸** → 做不出来；三视图必须标数与公差
- **不标不可写部分** → 接手人以为照做就行，出事无人可问
- **不做复现验证** → 未验证的规范只是自述，不算移交
- **旧版覆盖新版** → 改过什么查不到，问题无法回溯
- **只口头交接** → 人一走信息全失，签字才留痕

## H.7 中期检查与答辩要点

- 规范可复现（35%）
- 图纸与图示（25%）
- 不可写标注与带教（20%）
- 复现验证与签收（20%）
