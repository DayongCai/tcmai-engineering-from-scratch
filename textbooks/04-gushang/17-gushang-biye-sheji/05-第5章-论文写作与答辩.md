## H.1 本章要解决的问题

骨伤答辩最常被问「你这个角度是怎么量的」「随访怎么保证」。两问都指向方法学细节。

## H.2 本章目标（可检验）

- 论文数据与测量表、台账一致
- 15 分钟讲清方案、测量、结局、边界
- 准备三个方法学质疑

## H.3 操作流程

1. 对表：所有数值回到测量表
2. 写结构：方案、测量、结局、并发症、边界
3. 配图：测量画线图必放
4. 预设质疑：测量一致性、随访、对照可比性
5. 试讲并修改

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 数值与测量表一致
- [ ] 测量画线图已放
- [ ] 五段结构齐全
- [ ] 三个质疑有答案
- [ ] 并发症如实报告
- [ ] 引用写到篇名
- [ ] 免责与致谢已写

## H.5 模板：答辩准备表（骨伤）

| 字段 | 填写要求 |
|------|----------|
| 核心结论 | ≤40 字 |
| 证据链 | 方案→测量→结局 |
| 三个质疑 | 测量/随访/对照 |
| 边界 | 不能推广到什么 |
| 试讲反馈 | 修改点 |

> 本表是本章的交付物：答辩前一天自查。

## H.6 常见失效与处置

- **测量图缺失** → 评审无法判断数据可信度
- **回避并发症** → 如实报告反而加分
- **超时** → 15 分钟须取舍

## H.7 中期检查与答辩要点

- 数据一致（40%）
- 方法学表述（40%）
- 质疑回答（20%）
