## H.1 本章要解决的问题

骨伤答辩的提问高度集中：这个角度是谁量的、怎么量的；随访怎么保证没漏；对照组凭什么可比。三问都指向方法学，而不是结果好不好看。论文写作的任务因此不是把日志誊清，而是让每个数字都能指回测量表，每个判断都能指回判据，每个边界都能指回例数。方法章写不透，结果再好看也只是一组孤证。

## H.2 本章目标（可检验）

- 论文每个数值可回溯到测量表或登记表的具体行
- 十五分钟讲清方案、测量、结局、并发症与边界
- 准备三类方法学质疑的答案，以及被追问后的退让表述
- 完成一次预答辩并按意见修改，保留修改对照

## H.3 操作流程

1. 定主线：一句话写清本研究支持或否证了什么，全文按这句话取舍，与之无关的图表删掉，不留凑数章节，也不为凑篇幅加综述
2. 对表：正文每个数值回到测量表行号，对不上的一律回查原始影像，不许估着填，也不许取整凑整，图上数字须与表一致
3. 写方法：采集条件、画线定义、信度结果、支具规格，写到他人能照做，含失败时的处理与判断由谁做，耗材写型号
4. 写结果：按开题顺序报，主要结局在前；每张图只回答一个问题，图注含例数、时点与误差线含义，坐标轴写单位
5. 配测量图：画线定义图与典型病例片必须放，图注写谁测、用什么工具、取整到多少，缺图则数据无从判断，画线处指到标志点
6. 写并发症：正面成段写，含例数、分级、处置与转归，不藏在讨论里一句带过，末次随访仍在观察的也要写转归
7. 写讨论：与既往报告比对，一致处与不一致处各给原因假设，不空泛说与文献相符，比对至少三条并说明病例构成差异
8. 写边界：例数、随访时长、单中心、量表版本，逐条写越界会得出什么错结论，边界写足反而显专业，写具体才不易被追问
9. 预设三问：测量一致性、随访完整性、对照可比性，各备一组数字与一句退让表述，退让不等于认错，是把不确定性说清
10. 控时间：十五分钟按背景三、方法与结果七、并发症三、边界二分配，超时先砍背景，测量图一秒不能省，压缩背景不压方法
11. 预答辩：录音回放，记下被打断的位置，那里就是论证最薄的地方，先补那一页再改讲稿，补不了的就从结论里删掉
12. 定稿归档：论文、测量表、登记表、答辩稿四件一并交，版本号一致，旧稿不覆盖，电子与纸本各一份，交教学秘书登记

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 主线一句话能说清支持或否证什么，全文未跑题
- [ ] 正文数值可指到测量表行号
- [ ] 方法章可被他人照做，含失败处理与责任人
- [ ] 每张图只回答一个问题，图注含例数与时点
- [ ] 画线定义图与图注齐全
- [ ] 并发症成段报告含例数、分级与转归
- [ ] 讨论有文献比对与原因假设，至少三条
- [ ] 边界逐条写并说明越界后果
- [ ] 三类质疑各有一组数字支撑
- [ ] 十五分钟试讲未超时
- [ ] 预答辩意见逐条回应并改稿
- [ ] 四件材料版本号一致，旧稿未覆盖

## H.5 模板：答辩准备表（骨伤）

| 字段 | 填写要求 |
|------|----------|
| 主线 | 一句话结论，四十字内 |
| 证据链 | 方案、测量、结局、并发症 |
| 测量图 | 画线定义、谁测、什么工具、取整 |
| 结果表 | 图表号、例数、时点、判据 |
| 并发症 | 例数、分级、处置、转归 |
| 三类质疑 | 问题、数字支撑、退让表述 |
| 边界 | 不能推广到什么，越界会错在哪 |
| 试讲 | 时长、被打断处、修改点 |
| 归档 | 四件材料路径与版本 |

> 本表是本章的交付物：答辩前一天逐行自查；右栏留现场记录，答辩后归档。

## H.6 常见失效与处置

- **测量图缺失** → 评审无法判断数据可信度，追问必崩
- **数字与表不符** → 一处对不上，全篇可信度归零
- **并发症回避** → 如实报告加分，遮掩被追问更难看
- **讨论只复述结果** → 没有比对，看不出学术位置，也答不出差异在哪
- **超时** → 十五分钟讲不完，说明主线不清
- **图表堆砌** → 一图多结论，评审抓不到主次，重点反被淹没

## H.7 中期检查与答辩要点

- 数据可溯源（35%）
- 方法学表述（30%）
- 质疑应对（20%）
- 时间与表达（15%）
