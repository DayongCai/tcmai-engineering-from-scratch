## H.1 本章要解决的问题

「手法复位效果好」不是命题：好是指角度恢复、功能恢复还是并发症少，三者不等价。

## H.2 本章目标（可检验）

- 把方案改写成含量化结局的命题
- 确定影像测量指标与功能评分
- 评估十周内可完成的病例量

## H.3 操作流程

1. 写方案：复位手法、固定方式、康复安排
2. 定结局：一个主要（如复位角度丢失）+ 一个功能评分 + 并发症
3. 定对照：与另一种固定或与历史队列比较
4. 估病例：门诊量、入组标准、随访可及性
5. 砍范围：单部位单类型骨折

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 方案要素齐备
- [ ] 主要结局可量化（角度/评分）
- [ ] 对照选择有理由
- [ ] 入组与排除标准已写
- [ ] 随访周期已定
- [ ] 病例量可行性已估
- [ ] 伦理需求已判断

## H.5 模板：开题命题表（骨伤）

| 字段 | 填写要求 |
|------|----------|
| 方案 | 复位手法、固定、康复 |
| 结局 | 主要角度 + 功能评分 + 并发症 |
| 对照 | 类型与理由 |
| 病例方案 | 入组、例数、随访 |
| 范围 | 部位与骨折类型限定 |

> 本表是本章的交付物：开题首页，答辩对照。

## H.6 常见失效与处置

- **只报角度不报功能** → 角度好但功能差很常见；两者都要报
- **用历史队列不说明** → 历史对照偏倚大；须写明可比性
- **不限骨折类型** → 异质性过大，结论无法归因

## H.7 中期检查与答辩要点

- 结局可量化（40%）
- 对照与病例方案（30%）
- 可行性（30%）
