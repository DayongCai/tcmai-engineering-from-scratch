## H.1 本章要解决的问题

「手法复位效果好」不是命题。好可以指角度恢复，可以指功能恢复，也可以指并发症少，三者不等价，有时方向相反：复位漂亮而关节僵硬的病例并不少见，为求早期活动的代价又常是角度丢失。开题要交的不是一段意义论述，而是一条能判真假的比较：跟谁比、在哪个指标上比、差多少算有差异。三项写不出，十周后必然写不出结论。

## H.2 本章目标（可检验）

- 把「效果好」拆成影像、功能、并发症三类结局，每类定一个可测指标与测量时点
- 写出含对照、指标、预期方向与判读阈值的命题句，能被外人判真假
- 按门诊量与随访可及性算清十周内可完成的病例数，并留出脱落余量
- 写明不做什么：部位、骨折类型、年龄段的取舍与理由

## H.3 操作流程

1. 写方案一页：复位手法名称与分步动作、固定方式与时长、康复安排、复查节点与责任人，四项缺一不算方案，并注明由谁执行
2. 拆「好」：把带教口中的好拆成角度、功能、并发症三类，每类写一句能被外人核对的话，明显改善一类说法要改成角度差几度
3. 定主要结局：只留一个，取与方案最直接相关的影像指标，如复位后即刻角度或随访期角度丢失，并写明为什么不是另一个
4. 定次要结局：一个功能量表加一份并发症登记表；量表须有中文版本、信度报道与原始出处，扫描件存入资料夹
5. 定阈值：角度差多少度、量表差多少分算有差异，开题时写定并由导师签字，测完不许再改，改动须记理由
6. 选对照：另一种固定、保守治疗或历史队列，三者偏倚来源不同，选哪个都要写理由与已知代价，不得只写与文献一致
7. 写命题句：A 方案在 X 指标上优于 B 方案，差值不低于 d；缺对照或缺阈值，命题都不成立，阈值须与第 5 步同数
8. 定入排标准：骨折分型、年龄、伤后时间、合并伤四项；分型用通用分型并注明版本与出处，入组后不得因分型模糊放宽
9. 估病例：查近一年同类病例的实际接诊数，按七成可入组、八成可随访折算，再留两成脱落余量，缺口超过三成即缩范围
10. 排十周：开题、伦理、入组、随访、数据、写作六段，逐周写产出，标出随访期末这条关键路径；随访末超出学期的，改以拆除固定时点为终点并写明理由
11. 砍范围：把还想做的列成不做清单，逐条写舍弃理由与舍弃后结论会弱在哪里，防止中途改题，改题一次即须重新开题
12. 预答辩：请导师与一位外专业老师各提一条反对意见，当场记录、逐条回应，改完再定稿，两人问题各留一页答复备查

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 方案含手法、固定、康复、复查与责任人
- [ ] 三类结局各有可测指标与测量时点
- [ ] 主要结局只有一个，未与其他并列
- [ ] 命题句含对照、指标、方向、阈值
- [ ] 阈值由导师签字，未事后调整
- [ ] 入排标准含分型、年龄、伤后时间
- [ ] 病例量由近一年实际接诊数折算
- [ ] 随访周期、方式与责任人已定
- [ ] 十周里程碑逐周有产出
- [ ] 不做清单已写并说明代价
- [ ] 伦理需求已判断，留痕可查
- [ ] 预答辩反对意见已记录并回应

## H.5 模板：开题命题表（骨伤）

| 字段 | 填写要求 |
|------|----------|
| 命题句 | 对照、指标、预期方向、判读阈值 |
| 主要结局 | 指标、测量时点、判读标准、判读者 |
| 次要结局 | 功能量表、版本、并发症登记项 |
| 对照 | 类型、来源、偏倚与选择理由 |
| 入排标准 | 分型、年龄段、伤后时间、合并伤 |
| 病例方案 | 可入组数、随访率、预计完成数 |
| 十周里程碑 | 周次、任务、产出、关键路径 |
| 不做清单 | 舍弃项与舍弃后的代价 |
| 签字 | 学生、导师、日期 |

## H.6 常见失效与处置

- **只报角度不报功能** → 角度好而功能差很常见，两者不等价，结论必被追问
- **阈值事后才定** → 先看结果再定差多少算有效，属事后调参，答辩站不住
- **用历史队列不说明** → 历史对照偏倚大，须写可比性、年代差异与设备变化
- **不限骨折类型** → 异质性过大，疗效无法归因到方案本身
- **病例量凭感觉** → 开题时不算，入组三周才发现凑不齐，只能改题
- **命题句没有对照** → 单组前后比较无法排除自然愈合与康复的作用

## H.7 中期检查与答辩要点

- 命题可判真假（35%）
- 结局与阈值设定（25%）
- 病例与随访可行性（25%）
- 范围裁剪（15%）
