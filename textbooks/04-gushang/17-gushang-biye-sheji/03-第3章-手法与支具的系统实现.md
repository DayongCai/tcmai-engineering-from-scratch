## H.1 本章要解决的问题

手法难以标准化，支具可以。本章要求把手法拆成可记录参数，把支具拆成可复制的规格。

## H.2 本章目标（可检验）

- 把手法拆成 5 个可记录参数
- 给出支具规格与制作流程
- 他人能按记录复现一次操作

## H.3 操作流程

1. 拆手法：体位、牵引方向与重量、复位步骤、固定时相、复查节点
2. 画支具：材料、尺寸、固定点、衬垫位置
3. 写流程：从取模到佩戴调整
4. 试做：做一件并请带教评价贴合度
5. 记录：参数表 + 照片

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 手法五参数已写
- [ ] 支具规格图已完成
- [ ] 制作流程含材料与工具
- [ ] 试做件已由带教评价
- [ ] 佩戴与调整说明已写
- [ ] 并发症（压疮、松动）已列
- [ ] 照片与参数对应

## H.5 模板：手法参数与支具规格表

| 字段 | 填写要求 |
|------|----------|
| 手法参数 | 体位、牵引、步骤、时相、复查 |
| 支具规格 | 材料、尺寸、固定点、衬垫 |
| 制作流程 | 取模到调整 |
| 试做评价 | 贴合度与修改 |
| 风险 | 压疮、松动及处置 |

> 本表是本章的交付物：作为论文方法章的核心表。

## H.6 常见失效与处置

- **手法只写名称** → 无法复现；必须拆参数
- **支具不写衬垫** → 压疮多来自衬垫缺失
- **不做试做评价** → 纸面规格不等于能戴

## H.7 中期检查与答辩要点

- 参数可复现（40%）
- 支具规格（30%）
- 试做与风险（30%）
