## H.1 本章要解决的问题

手法最难交接的部分是手感。手感不能直接写进论文，但可以拆成可记录参数：体位、牵引方向与重量、复位步骤的顺序与时相、固定角度、复查节点。支具相反，它本来就可复制，问题常出在规格写得不细——衬垫位置一省，压疮就来了。本章要求两者都落到他人能照做的程度，否则疗效差异分不清是方案还是操作。

## H.2 本章目标（可检验）

- 把手法定为五个可记录参数，写成他人能照做的分步动作
- 给出支具规格图与制作流程，含材料、尺寸、固定点与衬垫
- 完成一件试做，由带教按贴合度、压痛、稳定性三项评价
- 写明佩戴时长、减量依据与依从性记录方式

## H.3 操作流程

1. 拆手法：体位、牵引方向与重量、复位步骤、固定时相、复查节点，五项逐项写，缺项即为不可复现，写完请带教逐项核
2. 写牵引：方向用解剖方位描述，重量写范围与增减规则，注明由谁判断加量、加到什么征象停，停止征象要可观察
3. 写步骤：复位动作按顺序编号，每步写手放哪里、往哪个方向用力、出现什么征象才进下一步，一步不写两件事
4. 写时相：从牵引到固定维持多久、何时拍片确认、确认后如何维持体位、由谁扶住，超时未复位如何处理
5. 标不可写：过手感、落空感这类判断写明须带教在场，不假装能写成文字，也不省略不提，写明由谁带、带几次
6. 画支具：材料、厚度、长度与周径、固定点数与位置、衬垫位置与厚度，出三视图并标公差，尺寸以实测为准
7. 写制作流程：测量、下料、成型、修边、试戴、调整，每步写工具、耗时与常见失误，失误处附一张错例照片
8. 试做一件：由学生独立完成，请带教按贴合度、压痛、稳定性三项评分并写具体修改意见，改后重做一次再评
9. 定佩戴方案：每日时长、是否夜间佩戴、何时可减量，减量依据写到角度与症状两项，减量由复查者决定
10. 做依从记录：佩戴日志记日期、时长、是否取下、原因，复查时回收，不要只问一句戴得怎么样，缺戴超三成须记处理
11. 列器械风险：压疮、松动、皮肤过敏、关节僵硬，各写观察时点、判据与处置动作，压疮须记部位与分期
12. 成表：参数表配照片，照片与参数一一对应，编号写进图注，改动后重拍，不许留旧图，图注写拍摄日期

## H.5 模板：手法参数与支具规格表

| 字段 | 填写要求 |
|------|----------|
| 手法参数 | 体位、牵引方向与重量、步骤、时相、复查 |
| 不可写部分 | 过手感等判断、带教次数与带教人 |
| 支具规格 | 材料、厚度、周径、固定点、衬垫 |
| 三视图 | 主视、侧视、俯视与关键尺寸公差 |

| 试做评价 | 贴合度、压痛、稳定性、修改意见 |
| 佩戴方案 | 每日时长、夜间佩戴、减量依据 |
| 依从记录 | 日志字段、回收节点、缺戴处理 |
| 风险 | 压疮、松动、过敏的观察与处置 |

## H.6 常见失效与处置

- **手法只写名称** → 「提按复位法」四个字无法复现，必须拆参数
- **不写牵引重量** → 重量全靠手感，换人做效果就变，无法比较
- **支具不标衬垫** → 压疮多来自衬垫缺失或移位，事后无法追责
- **不做试做** → 纸面规格不等于能戴住，试戴才发现压痛
- **不问依从** → 佩戴不足时长，疗效差被误判为方案无效
- **照片与参数不对应** → 照图做出来的件，与论文所述不是同一件
