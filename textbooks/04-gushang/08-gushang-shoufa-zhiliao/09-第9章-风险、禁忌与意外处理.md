## N.1 概念与出处

《医宗金鉴·正骨心法要旨·手法总论》给手法下的定义是【原文】「夫手法者，谓以两手安置所伤之筋骨，使仍复于旧也」，紧接着却写【原文】「但伤有重轻，而手法各有所宜」。再往下有一段常被略过、对本章最要紧的话：伤处「多有关于性命者」，元气素壮者「手法亦不可乱施」，元气素弱者「设手法再误，则万难挽回矣」，故「此所以尤当审慎者也」。

目标（使仍复于旧）、前提（伤有重轻、各有所宜）、代价（再误则万难挽回）三层在这一段里已经齐了。本章不新增第四层，只把这三层落成判断。

| 概念 | 出处 | 在本章的位置 | 说明 |
|---|---|---|---|
| 手法有宜有不宜 | 《医宗金鉴·正骨心法要旨·手法总论》 | 全章前提 | 先辨伤，再谈法 |
| 手法禁忌与注意事项 | 第四章·第二节 | 禁忌体系来源 | 绝对禁忌、相对禁忌、体质与部位注意点 |
| 筋膜间隔区综合征 | 第五章 | 时间窗急症 | 进行性剧痛、被动牵拉痛、间隔区张力增高 |
| 周围血管损伤 | 第五章 | 血管红旗 | 远端缺血，动脉损伤与血栓 |
| 马尾综合征与脊髓压迫 | 课程稿 `9.1`、`9.3` | 神经红旗 | 鞍区麻木、二便障碍、下肢无力 |

**禁忌要分三层，不分层就没法用。**

**绝对禁忌**：做了就必然或极可能造成不可逆损害，没有「调小一点、换个姿势」可以挽救。

| 类别 | 具体情形 | 误做的后果 |
|---|---|---|
| 骨折与脱位未处理 | 疑有或已证实的骨折端、未复位脱位、内固定不稳 | 移位、骨不连、内固定失效 |
| 感染 | 化脓性骨髓炎、化脓性关节炎、脊柱结核、椎间隙感染 | 感染扩散、脓毒症 |
| 肿瘤 | 原发骨肿瘤、骨转移、破坏性病变 | 病理骨折、脊髓压迫 |
| 脊髓与马尾受压 | 脊髓型颈椎病、胸椎管狭窄、马尾综合征 | 瘫痪、二便不可逆损害 |
| 进行性神经损害 | 肌力逐次下降、垂足、感觉平面上升 | 神经功能永久缺失 |
| 血管病变 | 动脉瘤、动脉闭塞、深静脉血栓、血管术后 | 破裂、栓塞、血栓脱落 |
| 出血倾向 | 凝血功能障碍、血小板减少、治疗量抗凝 | 深部血肿、硬膜外血肿 |
| 严重骨质疏松 | 长期激素、影像示骨小梁稀疏 | 医源性骨折、椎体压缩 |
| 妊娠 | 腰骶部与腹部手法、强力旋转类 | 流产、早产 |

**相对禁忌**：风险真实存在，但可被条件改变。它不是「不能做」，是「不能照原方案做」。

| 情形 | 要改哪一格 | 改完还能做什么 |
|---|---|---|
| 急性期肿胀剧痛 | 时机 | 只做远端轻柔理筋与体位摆放，患处不动 |
| 高龄、体质虚弱、长期激素 | 力度与时长 | 以轻柔软组织手法为主，整复类不做 |
| 高血压未控制、心律失常 | 体位与强度 | 避免头低位与憋气发力，缩短单次时长 |
| 糖尿病 | 皮肤与力度 | 避开易损皮肤，力度减轻，事后查皮肤 |
| 月经期、饮酒后、空腹、疲劳 | 部位与时机 | 腰骶与下腹不做强刺激；改期 |

**一票否决红旗**不是「手法禁忌」，而是「必须先诊断」。禁忌问「我能不能做」，红旗问「我知不知道我在做什么」。

| 红旗 | 最快能问出它的那句话 | 指向 | 当次处置 |
|---|---|---|---|
| 夜间静息痛、体重下降、肿瘤史 | 「晚上不动时疼不疼？最近瘦了吗？」 | 骨肿瘤、转移瘤 | 不做手法，转影像与专科 |
| 发热、局部红肿热、脊柱叩击痛 | 「有没有发烧？最近打过针吗？」 | 感染 | 不做手法，急诊或专科 |
| 鞍区麻木、二便无力或失禁 | 「大小便有没有变化？骑车麻不麻？」 | 马尾综合征 | 立即急诊，不等待 |
| 精细动作变差、走路踩棉感 | 「扣扣子、拿筷子还行吗？走路发飘吗？」 | 脊髓型颈椎病 | 不做颈部手法，转专科 |
| 眩晕、复视、构音不清、猝倒 | 「转头时晕不晕？看东西重影吗？」 | 椎动脉供血不足 | 不做颈部旋转类，转专科 |
| 远端苍白发凉、脉搏摸不到 | 「手（脚）比另一边凉吗？」 | 血管损伤、栓塞 | 立即急诊 |
| 进行性剧痛、被动牵拉痛 | 「越来越疼，还是好一点了？」 | 筋膜间隔区综合征 | 立即急诊，禁热敷禁按摩 |
| 外伤后畸形、异常活动 | 「受伤时听见响了吗？现在能自己动吗？」 | 骨折 | 制动、影像，不做手法 |

这张表要背的不是病名，是**问法**：红旗的价值全在患者自述之前先问出来。

四类常见意外另立一层：它们不是禁忌，是**做了以后发生的事**，因此有流程。

## N.2 为什么可以这样翻译

### 一、从「审慎」到一条有先后的筛子

「尤当审慎」是态度，态度不能执行。要执行，必须变成顺序：**红旗 → 绝对禁忌 → 相对禁忌 → 可做**。顺序由两个量决定：后果的不可逆程度，与判错的代价。

红旗放最前，因为红旗对应的病（肿瘤、感染、马尾受压、血管损伤）漏诊代价不可逆，筛出的成本却只是一句问话与一次转诊。这是「低概率、高代价」情形，其中**敏感度必须优先于特异度**：宁可把十个不是肿瘤的人转去拍片，也不能漏掉一个——假阳性花的是钱，假阴性丢的是功能。

绝对禁忌放第二，因为它只需判断有没有，不需判断程度；凡需要「掂量着来」的，都归相对禁忌。

相对禁忌放第三，因为它要求把方案拆开逐格改。最容易犯的错是**整体降级**：因患者高龄，把所有手法都做轻。正确做法是只改与风险相关的那一格——高龄改力度不改部位，皮肤病改部位不改力度，抗凝改深度不改时长。整体降级看似安全，实际把有效手段一起丢掉了。

### 二、从「不知其苦」到剂量的尺

【原文】「法之所施，使患者不知其苦，方称为手法也」常被读成「手法要轻柔」，这只对了一半。原文语境是「拽之离而复合，推之就而复位，正其斜，完其阙」——说的是整复类手法：要把错位骨端复位，还要让患者不觉得痛苦。力学上这意味着**力要够，但加载方式要避开痛觉敏感的路径**。「不知其苦」讲的是力的质量，不是力的大小。

它可翻成三条判据：表情与肌肉张力是即时反馈，一有抵抗就说明方向或力度不对，不是「再使点劲」；痛在施术中被诱发，说明加载路径错误，应换方向而非加力；术后酸痛应可预期、可回落，不可预期的疼痛是剂量过量的信号。

这也解释了暴力整复为什么必然出事：**痛觉是保护性反射的入口**，痛则痉挛，痉挛则所需力量更大，力量更大则更易骨折——一条正反馈。医源性骨折几乎都发生在这条正反馈里。

### 三、从「万难挽回」到四类意外的现场流程

「再误则万难挽回」的现代含义是：**处置有一个以分钟计的时间窗，过了这个窗，后面的努力都是补救。** 四类意外因此共用同一模板：识别 → 立即停止 → 现场处置 → 不改做什么 → 记录 → 转介 → 告知。最容易被忽略、最常出事的是「不改做什么」。

**晕厥。** 面色苍白、出汗、眼前发黑、恶心、脉搏细速，多在首次治疗、空腹、紧张、疼痛刺激或体位骤变时发生。立即停止，平卧抬腿，松衣领、通风，测脉搏血压，多数数分钟内缓解。**不改做什么**：不继续操作、不喂水、不扶起站立、不掐按颈部。意识不清、抽搐、脉搏摸不到或数分钟不缓解者呼叫急救。记录发生时间、体位、生命体征与缓解时间；反复发作者须查明原因后再定。

**骨折。** 施术中突闻或触到闷响、剧痛、迅速肿胀、异常活动或畸形；老年人骨质疏松者风险最高，肋骨、椎体、肱骨近端与桡骨远端最常见。立即停止，制动患处。**不改做什么**：不试图把医源性骨折用手法「复回去」、不揉、不热敷、不贴膏药。处置为固定、影像、按骨折流程转介，如实记录，并说明由谁接手。

**神经血管损伤。** 神经侧见某一支配区麻木、刺痛、肌力下降（腕下垂、足下垂、拇指对掌无力），多在强力旋转、牵拉或长时间压迫后出现；血管侧见远端苍白发凉、脉搏减弱或消失、被动牵拉痛，或迅速增大的搏动性肿物。立即停止，摆中立位，松开束缚，复测双侧脉搏与感觉肌力并记录。**不改做什么**：不热敷、不按摩、不抬高患肢（动脉供血不足时抬高加重缺血）、不观察等待。血管征象按急诊处理；神经损害数小时不缓解者转专科。部分神经损害数小时至数日后才完全显现，故当日与次日须有复查口径。

**皮肤损伤。** 局部发红、灼热、表皮剥脱、瘀斑、水疱，多见于皮肤薄、糖尿病、长期激素、消瘦者，以及摩擦时间过长、介质不足、骨突处直接按压时。立即停止局部操作，清洁、保护。**不改做什么**：不在破损处继续做、不涂刺激性外用药、不覆盖不透气敷料。记录部位与范围，告知患者观察感染征象。多数可自愈，但**感染风险在糖尿病与免疫抑制者身上不成比例地高**。

### 四、告知：把「可能发生」说在发生之前

告知不是免责声明，它有三项实质内容。其一，**说清预期反应与异常反应的界线**：治疗后一两日内的酸胀、轻度疲惫属常见反应；剧痛、麻木加重、发热、二便变化不属于，须立即联系。界线不说，患者会把异常当正常。其二，**说清替代方案与不做的后果**：休息、药物、练功各有其位，把「不做也可以」说出来，选择才是真的选择。其三，**说清复诊条件**：直接列出——进行性麻木、肌力下降、夜间痛加重、发热。清单比叮嘱有效，因为它能被记住，也能被转述给家属。

本章不给意外的发生率，也不接受「告知后签字即免责」。前者因为没有可对读的分母；后者因为**告知改变的是决策质量，不是责任归属**。

## N.3 这个翻译丢掉了什么

**一、丢掉了概率。** 三层筛子能告诉你「该不该做」，不能告诉你「风险有多大」。椎动脉损伤、硬膜外血肿、医源性骨折各自的发生率，在不同人群、不同手法、不同操作者之间差着一个量级以上，本章一个数都不给。代价明确：**读者拿到的是「能不能做」，不是「值不值得做」**。而临床决策恰在后者——七十八岁、骨质疏松、腰痛十年、保守治疗无效者，做与不做都不是零风险，这个权衡本章交不出去。

**二、丢掉了剂量的刻度。** 「不知其苦」是质量判据，不是数量判据。力用多少、幅度多少度、单次多少秒、一疗程几次，本章一概不给。这是刻意的取舍，代价要写明白：**没有刻度的安全只能靠手感，而手感不可传递、不可核查、不可追责**。同一个「轻柔」在不同人手里差别极大，原因就在这里。

**三、丢掉了门诊的抢救条件。** 流程写得再清楚，也要现场有血压计、氧气、呼叫通道与第二个人。多数手法治疗发生在门诊与诊室，条件比急诊科差一个层级——本章写流程不写配置，而流程能否执行，取决于配置。

**四、丢掉了告知的留痕。** 该说什么本章给了三项；怎么留下痕迹（告知单、病程记录、录音录像的合规边界）不给。真实纠纷里，**「说过了」与「能证明说过了」是两件事**。

**五、丢掉了延迟性损害、随访与心理。** 硬膜外血肿可在数小时后加重，神经损害可次日才显现，本章要求「当日与次日复查」，却没给随访频次与责任人。此外，怕痛者会隐瞒症状，急于见效者会要求加力，这些都会改变意外的呈现方式。

## N.4 与相邻学科的接口

| 学科 | 用到本章的什么 | 界线画在哪里 |
|---|---|---|
| 急诊医学 | 血管损伤、休克、筋膜间隔区综合征的识别与转运 | 本章只到「识别与立即停止」，处置归急诊 |
| 骨科与脊柱外科 | 手术指征、内固定术后状态、病理性骨折 | 不给手术指征，只给「不做手法」的条件 |
| 神经内科与电生理 | 神经损害的定位、肌电图与传导速度 | 只要求查、记、转，不解读电生理 |
| 影像科 | 排除骨折、感染、肿瘤、脊髓压迫 | 不给影像选择与阅片标准 |
| 麻醉与疼痛科 | 镇痛、肌松条件下的整复 | 用药与剂量归麻醉与疼痛专业 |
| 康复医学 | 意外之后的功能恢复与训练 | 康复方案由康复科制定 |
| 护理学 | 生命体征观察、皮肤与肢端评估、报告 | 观察与报告归护理，判断与处置归医师 |
| 医疗风险管理 | 不良事件报告、根因分析、告知留痕 | 给原则，不给机构的流程文本 |

接口的共同逻辑是**责任的切割点**：把「不该做的」拦下来，把「已经出事的」停下来，把「停下来之后的」交出去。三段里最容易被跳过的是第三段——停手之后没有交接，患者带着未定性的损害回家，再来时时间窗已经关了。

## N.5 争议与本项目立场

**争议一：脊柱手法与椎动脉损伤，是因果还是时间关联。** 一派认为存在因果关系，另一派认为多数事件源于自发性椎动脉夹层，手法只是时间上的巧合。本项目立场：**不否认时间关联，也不据此给发生率。** 双方证据都不足以定论，任何一方给出的百分比都缺少可靠分母。可执行的只有三条：术前问清眩晕、复视、猝倒史；术中不做颈椎强力旋转与过伸；术后查神经与血管体征并记录。

**争议二：骨质疏松是不是绝对禁忌。** 一派主张凡骨质疏松即禁手法，一派主张按程度分级。本项目立场：**分级，不一刀切。** 强力的旋转、拔伸、整复类属绝对禁忌；轻柔的软组织手法与关节松动在轻中度者可限量施行。分级依据不只是骨密度数值，还包括脆性骨折史、激素使用史与影像上的骨小梁形态。**骨密度正常不等于骨质量正常**，长期激素使用者可在数值尚可时发生骨折。

**争议三：「一票否决」是否过度保守。** 有观点认为红旗筛查会把大量非特异性腰痛患者推去做不必要的影像，增加成本与焦虑。本项目立场：**门诊非急诊场景，敏感度优先。** 也接受其代价——**转诊率上升、部分患者流失**，这属于可接受的成本，不是需要优化的指标。

**争议四：治疗后加重，是正常反应还是意外。** 本项目给一条可操作的界线：**加重在二十四至四十八小时内回到基线，属可接受反应；超出这个窗口，或伴随新的神经血管体征，按意外处理。** 同时列三种失效情形——止痛药掩盖了反应、患者因工期或赔付隐瞒症状、感觉减退者主诉不可靠；此时改用客观体征（肌力、脉搏、皮肤、活动度）判断。
