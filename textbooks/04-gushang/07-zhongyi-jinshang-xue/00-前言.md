## 参考教材怎么用（以及不做什么）

参考书是 **全国中医药行业高等教育「十三五」规划教材《中医筋伤学》（黄桂成主编，239 页扫描本）**，
登记在 `standards/gushang-jinshang/reference-modern.json`：书名、主编、版次、页数、PDF sha256、目录结构、
课程章 ↔ 参考章节的对应表都在那里。

约定三条：

1. **只对读，不搬运。** 参考书用于校对章节结构（概论 → 上肢 → 下肢 → 躯干 → 其他）、术语口径与分型框架；
   正文表述与例子由本项目重写，不逐字复制。
2. **引用只标章·节，不标页码。** 章首「覆盖」行写「参考《中医筋伤学》（黄桂成主编）第一章·第四节」，
   打开书按目录即可核对；页码依赖扫描版页码，换印次就失效。
3. **不存原文。** 该书非公有领域：仓库只存元数据与目录结构，OCR 文本留在本机临时目录，不随仓库分发。

## 与课程正文的关系

教材章 = 课程章（同号同名同主题），区别在写法：课程章讲「怎么做」（可执行、可判分），
教材章讲「为什么这样做、这个说法丢掉了什么、与相邻学科怎么接口」（N.1–N.5 判断层）。
两边数字同源，任何一边改动都要重跑：

```bash
node textbooks/build_book.js --check        # 字数与章数对账
npm run textbooks:board                     # 教材看板（逐门对账）
node scripts/build_textbook_chain.py        # 底本→单元→正文→成片 四层链条
```
