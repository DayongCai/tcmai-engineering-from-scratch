## H.1 本章要解决的问题

没有评测流水线的模型只是一次实验：改一行代码就不知道是变好还是变坏。

## H.2 本章目标（可检验）

- 建立可一键重跑的评测流水线
- 定义主指标与基线
- 输出每次实验的可比记录

## H.3 操作流程

1. 定数据划分：训练/验证/测试，固定随机种子
2. 定指标：主指标一个 + 两个辅助
3. 建基线：最简单方法（规则或多数类）
4. 流水线：一条命令完成训练+评测+报告
5. 留档：每次实验记录参数、数据版本、指标

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 划分与种子固定
- [ ] 主指标唯一
- [ ] 基线已跑
- [ ] 一条命令可重跑
- [ ] 实验记录含数据版本
- [ ] 错误分析已做≥10 例
- [ ] 模型卡已写

## H.5 模板：训练评测记录表

| 字段 | 填写要求 |
|------|----------|
| 数据 | 版本、划分、种子 |
| 指标 | 主指标 + 辅助 |
| 基线 | 方法与结果 |
| 实验 | 参数、结果 |
| 错误分析 | 十例归因 |

> 本表是本章的交付物：每次实验一行，随项目归档。

## H.6 常见失效与处置

- **测试集反复调参** → 等于把测试集变训练集；须留最终测试
- **只报主指标** → 辅助指标能暴露失衡与偏差
- **实验不留档** → 无法复现，也无法解释进步

## H.7 出科考核

- 流水线可重跑（40%）
- 基线与指标（30%）
- 错误分析（30%）
