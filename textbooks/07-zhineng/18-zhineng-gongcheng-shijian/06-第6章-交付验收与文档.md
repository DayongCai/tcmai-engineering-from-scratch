## H.1 本章要解决的问题

验收时最尴尬的是「演示能跑，但没人会部署」。交付文档的读者是运维和下一届学生，不是评委。

## H.2 本章目标（可检验）

- 交付可部署包与运维手册
- 完成验收测试并留记录
- 移交源代码与数据字典

## H.3 操作流程

1. 打包：镜像或安装包、配置样例、启动脚本
2. 写手册：部署、备份、回滚、常见故障
3. 验收测试：按需求逐条测并记录结果
4. 交数据字典：表与字段含义
5. 签收：验收方逐项签字

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 部署包可在干净环境启动
- [ ] 配置项与密钥管理已说明
- [ ] 备份与回滚步骤已写
- [ ] 验收测试逐条有结果
- [ ] 数据字典完整
- [ ] 源代码与许可已交
- [ ] 签收单已归档

## H.5 模板：交付验收清单

| 字段 | 填写要求 |
|------|----------|
| 部署包 | 镜像/安装包/配置 |
| 运维手册 | 备份、回滚、故障 |
| 验收项 | 需求逐条与结果 |
| 数据字典 | 表与字段 |
| 签收 | 双方签字与日期 |

> 本表是本章的交付物：验收会现场逐项打勾。

## H.6 常见失效与处置

- **只在开发机演示** → 换环境起不来；必须干净环境验证
- **密钥写进代码** → 安全事件高发；须走配置
- **验收无逐条记录** → 后续争议无从判断

## H.7 出科考核

- 干净环境可部署（40%）
- 运维手册（30%）
- 验收记录（30%）
