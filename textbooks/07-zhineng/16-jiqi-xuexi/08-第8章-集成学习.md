## 8.1 个体与集成（好而不同）

集成学习（ensemble learning）通过构建并结合多个学习器来完成学习任务，有时也被称为多分类器系统（multi-classifier system）。若集成中只包含同种类型的个体学习器，则称这样的集成是同质的（homogeneous），其中的个体学习器亦称基学习器（base learner），相应的学习算法称为基学习算法；若集成中包含不同类型的个体学习器，则称为异质的（heterogeneous），其中的个体学习器亦称组件学习器（component learner）。异质集成中不同算法的预测输出需先转换成一致的输出形式（如都输出类标记或类概率）方可结合。集成学习研究围绕两个核心问题展开：一是如何生成“好而不同”的个体学习器，二是如何设计合适的结合策略把它们组合成强学习器。 所谓“好而不同”，是指个体学习器一方面要具有一定的准确性——至少应优于随机猜测，即对二分类问题错误率应低于 0.5；另一方面，个体学习器之间还要存在差异，即彼此“不同”。若个体学习器完全一样，集成只是简单重复，无论结合策略如何设计都无法获得增益；若个体学习器准确性过低，则“三个臭皮匠”也难以匹敌“诸葛亮”。因此，个体学习器的准确性与多样性之间存在天然的冲突：追求多样性可能损害个体准确性，追求个体准确性又可能使学习器趋于一致。如何在二者之间取得平衡，是集成学习研究的核心所在。 考虑一个理想化的理论模型来理解集成为何有效。对二分类问题 y∈{-1,+1}，设基学习器的错误率为 ε，且各基学习器的错误相互独立。若用简单投票法结合 T 个基学习器，即超过半数的基学习器预测正确则集成预测正确，那么集成的错误率为 P(集成出错) = Σ_{k>⌈T/2⌉} C(T,k)·(1-ε)^k·ε^(T-k)， 其中 k 为预测正确的基学习器个数，C(T,k) 为组合数。由 Hoeffding 不等式可证 P ≤ exp(-T·(1-2ε)²/2)，即集成错误率随个体学习器数目 T 的增大呈指数级下降。例如当 ε=0.3、T=11 时，集成错误率约为 0.078，远低于单个学习器的 0.3；T 增至 21 时降至约 0.026；T=101 时已不足 0.00001（演示数值）。这正是“三个臭皮匠，赛过诸葛亮”的数学依据：只要每个学习器略强于随机猜测，多数投票就能把错误率压到极低。 然而该结论建立在“个体学习器相互独立”这一强假设之上。现实中的个体学习器由同一学习算法在相近的训练数据上产生，彼此高度相关，并不满足独立性假设，因此集成的错误率并不会随 T 无限下降，而是趋于某个与个体相关性有关的正数——增加基学习器数目到一定程度后，集成性能将不再明显改善。这说明仅靠堆砌学习器数目并不能保证集成性能，关键在于让个体学习器“好而不同”。本章后续将看到：Boosting 通过样本加权让后续学习器聚焦难例，Bagging 通过自助采样改变样本构成，随机森林进一步叠加随机属性选择，这些手段本质上都是在独立性与多样性之间做文章。 从发展脉络看，集成学习的思想在 20 世纪 90 年代随着弱可学习与强可学习等价性的证明而受到广泛重视，此后 Boosting 与 Bagging 两大流派并行发展：Boosting 族算法（AdaBoost、GBDT 等）串行生成个体学习器，后一个学习器聚焦前一个的错误；Bagging 族算法（Bagging、随机森林等）并行生成个体学习器，通过采样与属性扰动制造差异。两者殊途同归，都在回答“如何让集成比个体更准”。另一个直观理解是：若每个个体学习器在样本空间的不同子区域上各有所长（有的擅长近邻式判断、有的擅长把握全局规律），多数投票或加权结合便能取长补短，使集成在绝大多数区域都表现良好；这正对应“好而不同”——每个学习器有独到之处，且彼此不重复。对异质集成，还需注意把不同算法的输出统一为可比较的形式（如都转换为类概率再结合），否则投票计票将失去意义。实践中还观察到，集成规模 T 增大到一定程度后，性能曲线趋于平缓甚至轻微下降——这是因为个体学习器之间的相关性限制了多样性的进一步增长，与理论分析中“错误率随 T 无限下降”的结论形成对照；这一现象提醒读者，调参时应把 T 与个体学习器的复杂度放在一起考虑。从偏差-方差分解的视角看，Boosting 与 Bagging 走了两条互补的路径：Boosting 通过串行聚焦难例主要降低偏差，Bagging 通过平均化主要降低方差，二者分别适用于欠拟合与过拟合倾向的场景（详见 8.2、8.3 节）。这两条路径也共同说明：集成学习不是简单的“多训练几个模型”，而是对学习器之间的互补结构进行设计。归纳起来，集成学习要解决两个子问题：其一，如何生成一组既准确又多样的个体学习器；其二，如何选择与输出类型、任务性质匹配的结合策略——前者是 8.2、8.3、8.5 节的主题，后者是 8.4 节的主题。 本节要点：集成学习的性能增益来自个体学习器的“好而不同”；在独立假设下，多数投票集成的错误率随 T 指数下降，但现实中个体学习器并不独立，准确性与多样性的权衡才是决定集成质量的关键。

## 8.2 Boosting（AdaBoost/GBDT）

Boosting 是一族可将弱学习器提升为强学习器的算法。其思想源于 Kearns 与 Valiant 提出的“弱可学习”与“强可学习”概念：弱学习器指正确率仅略高于随机猜测的学习算法，强学习器指正确率很高的学习算法；Schapire 等人证明了弱可学习与强可学习在 PAC 学习框架下是等价的——只要存在弱学习器，就一定能通过集成将其提升为强学习器。Boosting 的工作机制是：先从初始训练集训练一个基学习器，再根据基学习器的表现调整训练样本的分布，使先前被分错的样本在后续训练中得到更多关注，然后基于调整后的分布训练下一个基学习器；如此重复 T 轮，最后将各基学习器加权结合。与 Bagging 的并行式集成不同，Boosting 是串行式的，后一个基学习器的训练依赖前一个的结果，难以并行加速。 AdaBoost（Adaptive Boosting）是最具代表性的 Boosting 算法。对二分类问题 y∈{-1,+1}，其流程如下：初始化样本分布 D₁(i)=1/m（m 为训练样本数）；对 t=1,2,…,T：基于分布 D_t 训练出基学习器 h_t（对能接受样本权重的算法用重赋权法直接加权训练，否则用重采样法按权重重新抽样）；计算 h_t 在分布 D_t 上的加权错误率 ε_t = P_{x~D_t}(h_t(x)≠y) = Σ_{i=1}^m D_t(i)·⟦h_t(x_i)≠y_i⟧；若 ε_t>0.5 则终止（此时该学习器不优于随机猜测，继续已无意义）；令 h_t 的投票权重 α_t = ½ln((1-ε_t)/ε_t)，可见 ε_t 越小 α_t 越大，即越准确的基学习器在最终结合中的权重越高；更新样本分布 D_{t+1}(i) = D_t(i)·exp(-α_t·y_i·h_t(x_i))/Z_t，其中 Z_t 为规范化因子。由更新公式可见：被 h_t 分错的样本（y_i·h_t(x_i)=-1）权重被放大 e^{α_t} 倍，分对的样本权重被缩小 e^{-α_t} 倍，于是后续基学习器将更关注难分的样本。最终输出 H(x) = sign(Σ_{t=1}^T α_t·h_t(x))。 AdaBoost 的权重公式并非凭空而来，可从加性模型的角度严格推导。把基学习器的线性组合 f(x)=Σ_{t=1}^T α_t·h_t(x) 视为加性模型，AdaBoost 采用前向分步算法：每一轮只优化当前基学习器 h_t 及其权重 α_t，并以指数损失 ℓ_exp(y,f(x)) = exp(-y·f(x)) 为最小化目标。第 t 轮时前 t-1 个基学习器已固定，记 w_i = exp(-y_i·f_{t-1}(x_i))，则本轮需最小化 Σ_{i=1}^m w_i·exp(-α_t·y_i·h_t(x_i))。由于 h_t(x_i) 只取 ±1，该目标可拆为“分对样本”与“分错样本”两部分；先固定 α_t>0 求解 h_t，可知使目标最小的 h_t 恰是使加权错误率 ε_t = Σ_i w_i·⟦h_t(x_i)≠y_i⟧ 最小的学习器——这正是 AdaBoost 每轮依据分布训练基学习器的原因；再把 h_t 代回并对 α_t 求导令其为零，即得 α_t = ½ln((1-ε_t)/ε_t)，同时样本权重更新式与 D_{t+1}(i)=D_t(i)·exp(-α_t·y_i·h_t(x_i))/Z_t 一致。此外，指数损失是 0/1 损失的光滑单调替代，最小化指数损失等价于逼近贝叶斯最优分类器，这保证了 AdaBoost 的优化目标与分类准确率的一致性。 数值演示：设 m=10、D₁(i)=0.1。第一轮 h₁ 分错 3 个样本，ε₁=0.3，α₁=½ln(0.7/0.3)≈0.424；分错样本权重变为 0.1×e^{0.424}≈0.153，分对样本权重变为 0.1×e^{-0.424}≈0.065，规范化后 D₂ 中分错样本权重约为 0.167、分对样本约为 0.071——难例权重明显抬升（演示数值）。第二轮若 h₂ 的 ε₂=0.4，则 α₂≈0.203；第三轮若 ε₃=0.2，则 α₃≈0.693，最终集成 H=sign(0.424h₁+0.203h₂+0.693h₃)，最准的 h₃ 权重最大。 标准 AdaBoost 仅适用于二分类，多分类可用 SAMME 等变体，回归可用 AdaBoost.R2 等算法。Boosting 训练中分错样本的权重不断增大，因此对噪声样本与异常值较敏感，数据含较多噪声时需谨慎使用或配合剪枝。从偏差-方差分解的角度看，Boosting 主要关注降低偏差，故常以泛化能力较弱但方差较小的学习器（如浅层决策树桩）为基学习器。GBDT（梯度提升树）是 Boosting 的另一重要分支：以回归树为基学习器，每轮用损失函数的负梯度近似残差来拟合新树，从而把 Boosting 推广到任意可微损失；XGBoost、LightGBM 等是其高效工程实现，加入了二阶导数、正则化与直方图近似等优化（现代认识）。AdaBoost 的完整算法可概括为以下步骤：输入训练集 D={(x₁,y₁),…,(x_m,y_m)}、基学习算法 L 与训练轮数 T；①初始化样本分布 D₁(i)=1/m；②对 t=1,2,…,T，基于分布 D_t 用 L 训练基学习器 h_t；③计算加权错误率 ε_t=Σ_i D_t(i)·⟦h_t(x_i)≠y_i⟧；④若 ε_t>0.5 则终止；⑤令 α_t=½ln((1-ε_t)/ε_t)；⑥更新分布 D_{t+1}(i)=D_t(i)·exp(-α_t·y_i·h_t(x_i))/Z_t；⑦输出 H(x)=sign(Σ_t α_t·h_t(x))。值得注意的是，AdaBoost 的训练误差随轮数增加通常持续下降甚至趋于零，但泛化性能并不随训练误差的消失而必然恶化——指数损失在分类边界附近的过度加权可能放大噪声影响，实践中常通过限制基学习器复杂度（如控制树桩深度）、提前停止或设置学习率来正则化（现代认识）。指数损失也并非唯一选择：在加性模型框架下可自由替换损失函数，如对数损失对应 LogitBoost，任意可微损失配合负梯度拟合即得 GBDT 一族，这正是 8.2 节公式推导的普适价值所在。 本节要点：AdaBoost 通过样本分布加权实现“聚焦难例”，其权重 α_t 与分布更新可由加性模型+前向分步+指数损失统一推导；Boosting 串行训练、主要降低偏差、对噪声敏感。

## 8.3 Bagging与随机森林

Bagging（Bootstrap AGGregatING）是并行式集成方法的代表，由 Breiman 提出，直接基于自助采样法（bootstrap sampling）产生个体学习器的多样性。给定含 m 个样本的训练集 D，每一轮从 D 中有放回地随机采样 m 个样本构成一个采样集，重复 T 轮得到 T 个各含 m 个训练样本的采样集，基于每个采样集训练一个基学习器；预测时，分类任务用简单投票法、回归任务用简单平均法结合各基学习器的输出。由于采样是有放回的，D 中的某些样本会在同一采样集中多次出现，而另一些样本始终未被采到。每个样本在 m 次采样中始终不被采到的概率为 (1-1/m)^m，当 m 较大时约为 0.368，即每个采样集平均只包含约 63.2% 的原始样本；例如 m=1000 时，一个采样集中期望包含约 632 个不同的样本（演示数值）。 未被采到的样本称为该采样集的包外（out-of-bag，简称 OOB）样本，其重要用途是包外估计。对第 t 个基学习器而言，其训练采样集未包含的样本可充当验证集：将样本 x 交给所有未使用 x 训练过的基学习器投票（或平均），得到集成的包外预测 H^oob(x)，则包外误差为 ε^oob = (1/m)·Σ_{(x,y)∈D}⟦H^oob(x)≠y⟧（回归任务用均方误差）。包外估计与留出法、交叉验证的效果相当，却无需额外划分数据或重复训练，在样本稀少时尤其有价值。从偏差-方差分解的角度看，Bagging 主要关注降低方差：多个独立训练的基学习器的期望误差与单个学习器相当，但平均效应压低了方差。因此 Bagging 对不稳定的学习算法（如决策树、神经网络——训练样本的微小变化会引起模型显著改变）增益明显；对稳定的学习器（如线性学习器、k 近邻、朴素贝叶斯——对训练样本变化不敏感）则增益有限，此时需借助属性扰动等手段。Bagging 的时间复杂度与训练单个基学习器同阶，且各基学习器可并行训练，这是它相对 Boosting 的重要优势。 随机森林（Random Forest，简称 RF）是 Bagging 的著名变体，在以决策树为基学习器构建 Bagging 集成的基础上，进一步在决策树训练过程中引入随机属性选择。传统决策树在划分结点时，从该结点的候选属性集合（设共 d 个属性）中选出最优划分属性；随机森林则在每个结点处，先从候选属性集合中随机挑选一个包含 k 个属性的子集，再从这个子集中选出最优划分属性。参数 k 控制随机性的引入程度：k=d 时退化为传统 Bagging 的决策树；k=1 时随机选一个属性用于划分；一般推荐 k=log₂d，例如 d=16 时取 k=4（演示数值）。随机森林的完整流程为：①对 t=1,2,…,T，对训练集 D 做自助采样得到采样集 D_t；②基于 D_t 训练一棵决策树，结点划分时先随机选 k 个属性再从子集中择最优，且不剪枝、让树充分生长；③对 T 棵树的预测结果投票（分类）或平均（回归）。随机森林的多样性同时来自样本扰动（自助采样）与属性扰动（随机属性选择），基学习器之间的差异显著，因此其泛化性能通常优于 Bagging；同时由于每棵树的每个结点只需考察 k 个属性的子集，随机森林使用的“随机型”决策树比 Bagging 的“确定型”决策树更省时，训练效率常高于 Bagging，且易于并行化。随机森林实现简单、超参数少、在很多现实任务中表现出强大性能，被誉为“代表集成学习技术水平的方法”；实践中还常利用其基学习器为决策树的特点输出特征重要性（如按 OOB 误差增量或基尼系数统计），用于特征选择与数据理解（属实践中的通行做法，现代认识）。Bagging 的完整算法可概括为：输入训练集 D、基学习算法 L 与轮数 T；对 t=1,2,…,T，从 D 中做自助采样得到采样集 D_t，基于 D_t 训练基学习器 h_t；分类任务对 h_1,…,h_T 做简单投票 H(x)=argmax_y Σ_t ⟦h_t(x)=y⟧，回归任务做简单平均 H(x)=(1/T)Σ_t h_t(x)。Bagging 的基学习器通常使用未剪枝的决策树等强学习器（与 Boosting 常用弱学习器不同），因为 Bagging 的增益来自方差降低而非偏差修正。与 Boosting 相比，Bagging 的另一个优势是天然支持并行与增量：各基学习器互不依赖，可部署在多机或 GPU 上并发训练；当训练数据规模很大时，还可对每个采样集独立建模，计算开销与训练单个学习器同阶。随机森林在应用上的突出特点是：对高维数据（如基因表达、文本特征）友好，因其每个结点只需考察 k 个属性；对噪声与缺失值相对稳健，多数投票天然具有容错性；并可输出特征重要性——按特征在 OOB 误差中的贡献或结点分裂的纯度增益累计排序，帮助研究者筛选关键特征（实践中常用做法，现代认识）。数值演示：设训练集 m=1000、T=100，某个样本 x 平均出现在约 63 棵树的训练集中，其余约 37 棵树对 x 是“未见过的”，可用它们的投票产生包外预测 H^oob(x)（演示数值）。包外估计因此几乎不浪费任何训练数据，在医学、金融等样本昂贵的场景中尤为实用。 本节要点：Bagging 用自助采样引入样本扰动、以投票/平均结合，主要降低方差且可并行；随机森林叠加随机属性选择（推荐 k=log₂d），样本与属性双重扰动使其泛化更好、训练更快；包外样本可免额外验证集估计泛化误差。

## 8.4 结合策略（平均/投票/Stacking）

为什么将多个学习器结合能获得比单一学习器更好的性能？主要有三方面原因：统计上，学习任务的假设空间往往很大，可能存在多个假设在训练集上表现相同，而单一学习器可能因随机性选到泛化性能较差的假设，结合多个学习器可降低“选错”假设的风险；计算上，学习算法可能陷入局部极小，多次运行并加以结合可降低陷入不良局部极小的风险；表示上，某些任务的真实假设可能不在当前学习算法所能表示的假设空间内，而多个假设的结合可以扩大表示空间。这三方面原因构成集成学习有效的理论动因。结合策略主要分为三大类：平均法、投票法与学习法。 平均法用于数值型输出（回归任务）。简单平均法给出 H(x) = (1/T)·Σ_{i=1}^T h_i(x)；加权平均法给出 H(x) = Σ_{i=1}^T w_i·h_i(x)，其中 w_i≥0 且 Σw_i=1，权重一般从训练数据中学习。加权平均的权重若估计不准，反而可能不如简单平均稳健——在训练数据不充分时尤其如此，此时简单平均往往表现更好；事实上加权平均法可视为“学习法”的特例，其权重 w_i 即通过最小化误差从数据中学得。 投票法用于分类任务。设个体学习器 h_i 对样本 x 的预测为类标记 c_i(x)，绝对多数投票法要求某类标记的票数超过半数才输出该标记，否则拒绝预测（在“宁可不说、不可说错”的场景中有用）；相对多数投票法直接取票数最多的类标记，若出现平票则随机选取一个；加权投票法则按个体学习器的权重计票，各类别得票为 Σ_i w_i·⟦h_i(x)=c_j⟧。若基学习器输出的是类概率（如 softmax 输出），则可将各类别概率先平均再取最大者，即软投票；一般软投票比硬投票（对类标记投票）更可靠，因为概率包含了更多信息，但前提是各类概率经过良好校准（如 Platt 缩放、等渗回归，属现代认识）。数值演示：设 4 个基学习器对某三分类样本的预测分别为 A、A、B、C，相对多数投票输出 A；若要求绝对多数（票数过半，即至少 3 票），则没有任何类达到要求而拒绝预测；若权重为 0.4、0.3、0.2、0.1，加权投票中 A 得 0.7、B 得 0.2、C 得 0.1，仍输出 A（演示数值）。 学习法的代表是 Stacking（stacked generalization）。Stacking 先用训练集训练 T 个初级学习器（primary learner），再以初级学习器的输出作为新特征，训练一个次级学习器（secondary learner，亦称元学习器 meta-learner）来完成结合。关键问题在于次级学习器的训练数据如何产生：若直接用初级学习器在自身训练集上的预测输出作为次级训练集，过拟合风险很大——初级学习器对训练样本的预测过于“自信”，次级学习器学到的将是对训练集的记忆而非泛化规律。标准做法是交叉验证或留出法：把训练集划分成若干份，用部分数据训练初级学习器、在其余数据上产生预测，把“未见过的”预测输出收集起来构造次级训练集。次级学习器的基学习算法常选用多响应线性回归（multi-response linear regression，MLR），因其不易过拟合，且对初级学习器输出的线性组合足够灵活。数值示意：设 5 折交叉验证，每折用 4/5 数据训练 3 个初级学习器并对剩余 1/5 预测，把 5 折的预测拼接成与训练集同规模的次级训练集，再训练次级学习器；预测新样本时，先由初级学习器产生输出，再交给次级学习器给出最终结果（演示流程）。结合策略的选择应与个体学习器的输出类型匹配：若个体学习器输出类标记，适合用投票法；若输出类概率或置信度，适合用平均法（软投票）或学习法；若输出为排序或序关系，则需专门的结合方式（如 Borda 计数，现代认识）。平均法中权重 w_i 的估计通常以最小化集成在验证集上的误差为目标，也可用交叉验证或对权重做简单搜索；但当训练数据不充分时，学得的权重往往不稳定，简单平均反而更稳健——“简单往往胜过复杂”的现象在集成学习中反复出现。投票法还需注意平局处理：绝对多数投票在平局时拒绝预测，相对多数投票随机选择或按先验选择；实践中若频繁出现平局，可考虑增加学习器数目或改用软投票。Stacking 的次级特征维度等于初级学习器的个数（若初级学习器输出类概率，则特征为各类别概率拼接），因此次级学习器一般不宜过于复杂，MLR 等线性模型是常见选择；初级学习器则鼓励使用异质算法（如决策树、神经网络、k 近邻混合），以提供互补的新特征。工程上常用 5 折或 10 折交叉验证生成次级训练集，但需注意 Stacking 的计算开销约为“交叉验证折数×初级学习器训练开销”的量级，部署时要在性能与代价之间权衡（现代认识）。数值演示：设三个回归学习器在验证集上的误差分别为 0.1、0.2、0.3，以误差倒数归一化得权重 w=(0.545,0.273,0.182)，加权集成误差约为 0.1×0.545+0.2×0.273+0.3×0.182≈0.164，低于简单平均的 (0.1+0.2+0.3)/3≈0.2（演示数值）；但若权重由含噪声的小样本估计，简单平均往往更稳。 本节要点：结合可从统计、计算、表示三方面带来增益；平均法与投票法简单直接，软投票一般优于硬投票；Stacking 以初级学习器输出为新特征训练元学习器，其训练数据须由交叉验证或留出法产生以防过拟合。

## 8.5 多样性

个体学习器的多样性是集成性能的关键，本节从误差-分歧分解、多样性度量与多样性增强三个层面展开。首先看误差-分歧分解（error-ambiguity decomposition），它揭示了集成误差与个体误差、个体分歧之间的定量关系。考虑回归任务，设个体学习器 f_i 的加权平均为 f(x)=Σ_{i=1}^T w_i·f_i(x)，权重 w_i≥0 且 Σw_i=1。定义个体分歧（ambiguity）Ā(x)=Σ_i w_i·(f_i(x)-f(x))²，刻画各学习器输出偏离集成输出的程度；个体误差的加权平均 Ē(x)=Σ_i w_i·(f_i(x)-y)²，其中 y 为真实标记；集成误差 E(x)=(f(x)-y)²。可以推导： E(x) = Σ_i w_i·(f_i(x)-y)² - Σ_i w_i·(f_i(x)-f(x))² = Ē(x) - Ā(x)。 即集成的平方误差等于个体学习器平方误差的加权平均减去个体分歧的加权平均。数值验证：设 f₁=0.8、f₂=1.2、y=1.0、w₁=w₂=0.5，则 f=1.0，集成误差 E=0；个体平均误差 Ē=½(0.04+0.04)=0.04；个体分歧 Ā=½(0.04+0.04)=0.04，恰有 E=Ē-Ā=0（演示数值）。误差-分歧分解说明：个体学习器越准确（Ē 小）、彼此分歧越大（Ā 大），集成误差越小。但它有重要局限：分解中的 Ē 与 Ā 并非相互独立，不能直接作为优化目标——盲目追求分歧可能同时损害个体准确性，这就是下文将讨论的“多样性-准确性悖论”。 再看多样性度量，它用于刻画个体学习器两两之间的差异。对二分类问题，统计两个学习器 h_i、h_j 在样本集上的预测：a=两者均预测正确的样本数，b=h_i 对而 h_j 错的样本数，c=h_i 错而 h_j 对的样本数，d=两者均预测错误的样本数，a+b+c+d=m。常用度量包括：不合度量（disagreement measure）dis_ij=(b+c)/m，即两学习器预测不一致的样本比例，取值越大多样性越高；相关系数 ρ_ij=(ad-bc)/√((a+b)(a+c)(c+d)(b+d))；Q 统计量 Q_ij=(ad-bc)/(ad+bc)；kappa 统计量（Cohen 一致性系数）κ=(p₁-p₂)/(1-p₂)，其中 p₁=(a+d)/m 是两学习器预测一致的样本比例，p₂=((a+b)(a+c)+(c+d)(b+d))/m² 是两学习器偶然一致的期望比例。κ 剔除了偶然一致的部分，κ=0 表示一致性完全来自偶然、κ=1 表示完全一致，κ 越大多样性越小。数值演示：设 m=1000、a=700、b=50、c=100、d=150，则 dis=0.15，Q≈0.909，ρ≈0.577，p₁=0.85，p₂=0.65，κ≈0.571（演示数值）。 最后看多样性增强的途径，主要有四类：①数据样本扰动，通过改变训练样本的分布或构成产生差异，如 Bagging 的自助采样、AdaBoost 的样本加权；样本扰动对不稳定的学习器（决策树、神经网络）有效，对稳定的学习器（线性学习器、k 近邻、朴素贝叶斯）几乎无效，因为后者对训练样本的变化不敏感，此时需借助其他扰动。②输入属性扰动，如随机子空间算法（random subspace）随机选取属性子集训练各基学习器，随机森林的随机属性选择即属此类；属性扰动在属性冗余度高的任务上效果较好。③输出表示扰动，如翻转部分样本的类标记、ECOC（纠错输出码）将类别编码为码字、以多个二分类器分别判别并借助海明距离解码，后者还具备纠错能力。④算法参数扰动，如随机初始化网络权重、设置不同的隐层结点数、负相关法（negative correlation）在训练中显式惩罚个体间的相关性。现实中常组合使用多种扰动，随机森林即同时使用了样本扰动与属性扰动。几个多样性度量之间存在内在联系：Q 统计量与相关系数 ρ 的符号保持一致（正相关时同为正值），但取值不同；kappa 统计量对偶然一致的校正使其比简单一致率 p₁ 更能反映“真实”一致性——两个完全独立的学习器仅凭偶然也会有一定比例的预测一致，κ 接近 0 正说明二者没有超出偶然的同步。实际监控多样性时，通常同时报告不合度量与 kappa：不合度量直观、kappa 严谨。误差-分歧分解是针对回归任务导出的，对分类任务虽无完全对应的恒等式，但“个体准确且彼此分歧的集成更好”已被广泛接受为一般原则；分解中的 Ē 与 Ā 相互耦合，不能直接作为优化目标，这正是多样性-准确性悖论的根源：例如在随机森林中调小 k 可增大属性扰动带来的多样性，但 k 过小时每个结点的属性选择过于随意，个体树准确性下降，集成性能反而变差；在 Bagging 中，若基学习器本身高度稳定（如线性模型），无论采样多少次，个体之间几乎无差异，集成增益趋近于零。因此，增强多样性的正确姿势是“在保证个体准确性的前提下制造差异”：对不稳定学习器用样本扰动，对稳定学习器用属性扰动或输出扰动，对深层网络用参数扰动，必要时组合多种扰动（如随机森林同时使用样本扰动与属性扰动）。ECOC 还提供了一个有趣视角：输出表示扰动不仅能增强多样性，还能利用码字间的海明距离对基学习器的错误进行纠错，体现了“以冗余换鲁棒”的思想。 本节要点：误差-分歧分解给出 E=Ē-Ā，说明“个体准确+彼此分歧”决定集成质量；kappa 等度量可定量监控多样性；样本、属性、输出表示、算法参数四类扰动是增强多样性的主要手段，但须警惕多样性-准确性悖论。

## 8.6 本章小结

本章围绕“好而不同”这一核心思想系统介绍了集成学习。8.1 节奠定基础：个体学习器既要具有优于随机猜测的准确性，又要彼此存在差异；在独立性假设下，多数投票集成的错误率随个体数目 T 指数下降，但现实中个体学习器同源同数据、彼此相关，因此如何平衡准确性与多样性成为集成学习研究的核心问题。8.2 节的 Boosting 是串行式集成的代表：AdaBoost 通过样本分布加权使后续学习器聚焦难例，其权重公式可由“加性模型+前向分步算法+指数损失”完整推导；GBDT 以负梯度近似残差逐轮拟合，XGBoost、LightGBM 等是其高效工程实现。Boosting 主要降低偏差，且对噪声敏感。8.3 节的 Bagging 是并行式集成的代表：自助采样使每个采样集仅含约 63.2% 的原始样本，包外样本可免额外验证集估计泛化误差；Bagging 主要降低方差，对不稳定学习器增益明显且可并行训练；随机森林在 Bagging 基础上引入随机属性选择（推荐 k=log₂d），样本扰动与属性扰动叠加，泛化性能与训练效率俱佳。8.4 节给出结合策略：平均法（简单/加权）用于回归，投票法（绝对多数/相对多数/加权/软投票）用于分类，学习法（Stacking）以初级学习器输出为新特征训练元学习器，次级训练数据须由交叉验证或留出法产生以防过拟合。8.5 节深入多样性：误差-分歧分解 E=Ē-Ā 表明“个体准确+彼此分歧”决定集成质量；不合度量、相关系数、Q 统计量与 kappa 统计量可用于度量多样性；样本、属性、输出表示与算法参数四类扰动是增强多样性的主要途径，但需警惕多样性-准确性悖论。 集成学习是机器学习最成功的实践方向之一：随机森林与 XGBoost 等已在工业界与各类数据竞赛中成为常用利器，而“好而不同”的思想也启发了深度学习中的多模型融合、快照集成（Snapshot Ensembling）等现代做法（现代认识）。理解本章的关键公式推导（AdaBoost 权重、误差-分歧分解、kappa 统计量）有助于掌握集成方法的适用条件与调参方向：基学习器应“好而不同”，结合策略应与输出类型匹配，多样性扰动应与学习器的稳定性匹配。集成思想还与偏差-方差分解、贝叶斯模型平均、迁移学习等内容相互呼应，建议读者结合实验反复体会“三个臭皮匠，赛过诸葛亮”背后的数学机理。学习本章建议抓住三条线索：一是“为什么集成有效”——独立假设下的指数级错误率下降、结合策略的统计/计算/表示三动机、误差-分歧分解 E=Ē-Ā；二是“怎样让个体好而不同”——样本扰动、属性扰动、输出表示扰动、算法参数扰动，以及它们与学习器稳定性的匹配；三是“怎样结合”——平均法、投票法、Stacking 各自的适用场景与防过拟合要点。延伸阅读方面，Breiman 的 Bagging 与随机森林论文、Friedman 的梯度提升系列是经典文献，XGBoost 与 LightGBM 的工程文档展示了 Boosting 在大规模数据上的实践细节（现代认识）。集成思想贯穿全书：第 2 章的偏差-方差分解是理解 Boosting/Bagging 分工的理论基础，指数损失与贝叶斯最优分类器的一致性呼应第 7 章的内容，后续章节的深度模型也可借助集成思路提升稳健性。建议读者动手实现 AdaBoost 与随机森林的小型实验，观察训练误差、OOB 误差与 T、k 的关系，把本章公式变成直观经验。 本章要点：Boosting 主要降偏差、Bagging 主要降方差；集成增益来自个体学习器的准确性与多样性；结合策略与多样性管理是应用集成学习的两大抓手。

| part2 | P2.3 | Boosting=迭代审稿闭环 | 23 | tcmP 把 Boosting 映射为迭代审稿闭环：AdaBoost 按样本权重聚焦被分错的样本，平台则按条款权重聚焦未通过审稿的条文。初始轮所有章节条款权重相等（D₁(i)=1/m，m 为章节条款总数），author-agent 起草全文；第一轮审稿后，未通过条款（【等级】为致命或重要者）被标出，下一轮修订时这些条款的权重放大，正如 AdaBoost 将分错样本权重乘 e^{α_t} 倍；每轮根据条款通过率计算审稿人置信度 α_t=½ln((1-ε_t)/ε_t)，其中 ε_t 为本轮未通过率——通过率越高，本轮审稿意见在最终定稿中的权重越大。分布更新公式对应 D_{t+1}(i)=D_t(i)·exp(-α_t·y_i·h_t(x_i))/Z_t：未通过条款下一轮被 author-agent 重点修订，通过条款维持原状。数值演示：若第一轮未通过率 ε₁=0.3，则 α₁≈0.424，未通过条款修订权重约放大 e^{0.424}≈1.53 倍（演示数值，统计来源，送 tcmreviewer 审稿）。终止条件对应 AdaBoost 的 ε_t>0.5 停止规则：若某轮未通过率超过 0.5，说明审稿口径与初稿质量失配，应暂停迭代、由主编人工介入调整审稿标准，而非继续加码放大权重。该闭环对应平台“初稿→审稿→修订→定稿”的章节流转，每轮迭代在 kanban 看板留下记录，便于追溯审稿历史。GBDT 的负梯度思想则对应“残差式修订”：修订不重写全文，而是逐条定位未通过条款的具体问题（缺文献、证型不符、剂量存疑、术语未对齐 ICD-11 等），一条一条修正，避免大改引入新错误；实践上还可引入“学习率”概念，每轮只按比例（如 0.5 权重）采纳审稿意见，降低单轮大改的振荡风险（工程实践，供平台参考）。
符号对照可归纳为：ε_t=本轮未通过率，α_t=本轮审稿意见置信度，D_t(i)=第 t 轮第 i 条条款的修订权重，H(x)=最终定稿。数值演示：若第一轮未通过率 ε₁=0.3（α₁≈0.424），经重点修订后第二轮未通过率降至 ε₂=0.15，则 α₂≈0.902，第二轮意见置信度更高，定稿更可信（演示数值，统计来源，送 tcmreviewer 审稿）。多分类任务对应多审稿人并行：不同章节可视为不同“类别”，各章节分别跑各自的迭代闭环，kanban 看板按章节泳道展示进度。实践建议：为控制迭代轮次，可设最大轮数 T_max（如 3 轮）与通过率达标线（如未通过率≤0.05），先达标先定稿，避免无限循环消耗算力（工程实践，供平台参考）。 |
| part2 | P2.4 | Bagging=专科分工 | 24 | tcmP 把 Bagging 映射为专科分工并行审阅。自助采样对应各专科 Profile 从同一章节中按专科口径采样条款集：内科 Agent 主审脏腑辨证条款，妇科 Agent 主审经带胎产条款，儿科 Agent 主审小儿病证条款，骨伤 Agent 主审伤科条款，彼此并行、互不阻塞，正如 Bagging 的 T 轮并行训练；每个专科 Profile 只对自身专科条款给出高置信意见，形成“好而不同”的基学习器集合。由于章节条款按病证单元库 BZU 归类，同一章节约有 63.2% 的条款落在某专科主审范围内（对应自助采样率），其余约 36.8% 即为该 Profile 的“包外条款”（演示数值，统计来源，送 tcmreviewer 审稿）。包外估计对应平台的自校验机制：每个专科 Profile 用包外条款检验自身意见的可靠性——若某 Profile 对包外条款的意见与最终定稿系统性不符，说明其专科口径存在偏差，应回修该 Profile 的 SKILL.md；该机制无需额外专家即可完成，对应 8.3 节“包外估计无需额外验证集”。随机属性选择对应审稿视角扰动：同一条款由理论审稿（tcmreviewer 关注病机条理与经典依据）、智能审稿（tcmreviewer_ai 关注现代知识与 ICD-11 术语对齐）与专科审稿（关注临床可用性）从不同属性维度审视，对应随机森林每结点“随机选 k 个属性再择最优”；最终按投票或平均输出该条目的审稿结论。全部结论汇总后送 compatibility-coordinator 做兼容性整合，避免各专科口径冲突。从偏差-方差角度，各专科意见单独波动较大（方差高），并行汇聚后整体更稳，对应 Bagging 主要降低方差；平台用 kanban 泳道并行推进各专科审阅，天然契合 Bagging 的可并行优势。
审稿维度数 d 与随机子集大小 k 的映射：平台审稿维度通常包括病机条理、经典依据、现代知识、ICD-11 术语对齐、临床可用性等约 d=5 维，对应 k=log₂5≈2.3，取 k=2 或 3，即每条条款随机抽取 2~3 个维度重点审视，兼顾深度与视角多样性（演示数值，统计来源，送 tcmreviewer 审稿）。另外，Bagging 对噪声的稳健性对应平台容错：某专科 Profile 或节点临时不可用时，其余 Profile 的结论仍可汇聚成稿，整体质量不因单点故障而崩溃，符合 0 分布式体系拓扑下的高可用要求。 |
