## 3.1 基本形式

线性模型（linear model）是机器学习中最基本、应用最广泛的一类模型。它试图学得一个通过属性的线性组合来进行预测的函数，即 f(x) = w₁x₁ + w₂x₂ + … + w_d·x_d + b，其中 x = (x₁; x₂; …; x_d) 是 d 维属性（特征）向量，w = (w₁; w₂; …; w_d) 是各属性对应的权重（weight）向量，b 为偏置（bias）项。写成向量形式即为 f(x) = wᵀx + b。从几何上看，当 d = 1 时该式是一条直线，当 d = 2 时是一个平面，当 d > 2 时则是一个超平面（hyperplane），线性模型学得的正是特征空间中的一个（超）平面，用它来拟合样本点或划分样本类别。权重向量 w 的每个分量直观地表达了对应属性在预测中的重要性：若 wᵢ > 0，说明属性 xᵢ 取值越大、预测值 f(x) 越大，二者正相关；若 wᵢ < 0 则负相关；而 |wᵢ| 越大，说明该属性对预测结果的贡献越显著；偏置 b 则刻画了属性全部为零时模型的基准输出。正是由于模型参数的物理含义清晰，线性模型具有极好的可解释性（interpretability）——这是它区别于许多"黑箱"模型的最大优势，也是它在金融风控、医疗辅助、司法量刑等对可解释性有刚性要求的领域仍被广泛使用的原因。学习线性模型的过程，就是由训练数据确定 w 与 b 的过程：给定训练集 D = {(x₁,y₁), (x₂,y₂), …, (x_m,y_m)}，学得 w 与 b 后，模型即可对新样本做出预测；由于形式简单，线性模型的训练通常非常高效，且其解往往具有解析（闭式）形式，便于理论分析与工程实现。线性模型看似简单，却蕴含着机器学习中一些重要的基本思想：许多功能更为强大的非线性模型都可以在线性模型的基础上，通过引入层级结构（如神经网络把若干个线性模型按层组织、并施加非线性激活函数）或高维特征映射（如支持向量机的核技巧、多项式回归的基函数展开）而得到。因此，线性模型既是学习机器学习的入门模型，也是构建复杂模型的基本构件。以感冒证候数据集为例，判别一份病历是否属风寒表实证，可把恶寒重、无汗、脉浮紧等四诊属性适当量化后做加权求和，权重越大说明该特征对风寒证判断越关键；在 tcmP 辨证场景中，f(x) 可理解为各症状、舌象、脉象特征对证型判别的加权投票，每个权重对应一个四诊特征对证型的贡献度，这一可解释性质与平台"结论可核查、可审稿"的口径天然契合。从学习任务的视角看，线性模型的训练目标就是使 f(x) 在训练集上尽可能逼近真实标记 y：对回归任务 y 是实值，对分类任务 y 是类别标记，不同任务通过选择不同的损失函数（如平方损失、对率损失）统一在"最小化经验风险"的框架之下。由于模型容量有限，线性模型在训练集上的拟合能力弱于复杂模型，但相应的过拟合风险也更低，其误差主要来自欠拟合——这一"简单模型偏差大、方差小"的特性，正是第 2 章偏差-方差分解所刻画的模型选择规律的直观体现。求解参数 w 与 b 有两条途径：当目标函数关于参数可导且能令导数解析为零时，可得到闭式解（如下一节的最小二乘）；当闭式解不存在或代价过高时，则采用梯度下降、牛顿法等迭代优化算法。线性模型的历史可追溯至统计学中的经典回归分析，广义线性模型、岭回归、LASSO 等均是其直系后裔，在计量经济学、生物统计、工业质检等领域积累了数十年的应用经验，是理论与工程结合最成熟的模型族。仍以 tcmP 辨证为例，若把"风寒束表"证型的判别写为 f(x) = w₁·恶寒 + w₂·发热 + w₃·脉浮紧 + … + b，则训练得到的权重即为各症状在辨证中的相对贡献，这一形式既便于专家逐项核验，也便于向学生解释辨证依据。线性模型的参数学习还可从几何与优化的双重视角理解：从几何视角，学习即寻找一个与样本分布最契合的超平面；从优化视角，学习即在参数空间中最小化经验风险，闭式解对应目标函数驻点的解析位置，迭代法对应沿负梯度方向的逐步逼近，两种视角贯穿全书，线性模型是体会这两种视角最直观的载体。从假设空间的角度看，参数 (w, b) 的每一组取值对应一个具体假设，全部取值构成线性模型的假设空间，学习过程即在该假设空间中按经验风险最小化原则做搜索——这正是第 1 章"假设空间与版本空间"概念在本章的具体化。此外，线性模型的表达能力可通过特征变换灵活增强：对属性做多项式展开（如把 x 映射为 (x, x²)）可拟合曲线关系，对类别属性做 one-hot 展开可捕捉类别效应，这类"先变换、后线性"的范式在后续章节（如支持向量机的核方法）中被推广为更一般的高维映射。在工程实践中，线性模型还常扮演强基线的角色：任何复杂模型上线前都应先用线性模型建立基线性能，若非线性模型的提升不足以抵消其可解释性损失，则保留线性方案——这一"简单优先"原则在平台建设中被固化为默认策略，也与"可辅助参考、不改经典原义"的审稿口径一致。何时选择线性模型、何时必须升级为非线性模型，可从数据分布与任务需求两方面判断：若样本量有限、特征与标记的关系大体单调，或业务要求每个预测都能给出可解释的依据，线性模型往往是稳妥选择；若数据量充足且存在明显的非线性交互（如条件依赖、阈值效应），则需借助特征工程或非线性模型。这一判断贯穿全书，也是后续各应用章节反复出现的模型选择主线。本节要点：线性模型通过属性加权求和进行预测，形式简单、训练高效、权重可解释，是后续众多非线性模型的基础构件。

## 3.2 线性回归

线性回归（linear regression）试图学得一个线性模型以尽可能准确地预测实值输出标记。给定数据集 D = {(x₁,y₁), …, (x_m,y_m)}，其中 yᵢ ∈ ℝ。先考虑输入属性只有一个（d = 1）的最简单情形，此时模型为 f(xᵢ) = wxᵢ + b，目标是确定 w 与 b。回归任务最常用的性能度量是均方误差（mean squared error），因此可试图让均方误差最小化，即求解 (w*, b*) = argmin Σᵢ₌₁ᵐ (yᵢ − wxᵢ − b)²。基于均方误差最小化来进行模型求解的方法称为最小二乘法（least squares method），其名称即"最小化误差的平方和"；从几何上看，它使各样本点到拟合直线的竖直距离平方之和最小。求解时分别对 w 和 b 求偏导：∂E(w,b)/∂w = 2(wΣᵢxᵢ² − Σᵢ(yᵢ − b)xᵢ)，∂E(w,b)/∂b = 2(mb − Σᵢ(yᵢ − wxᵢ))，令两式为零，可得闭式解 w = Σᵢ yᵢ(xᵢ − x̄) / (Σᵢ xᵢ² − (Σᵢ xᵢ)²/m)，b = (1/m)Σᵢ(yᵢ − wxᵢ)，其中 x̄ = (1/m)Σᵢxᵢ 为属性 x 的均值。注意到分母 Σᵢxᵢ² − (Σᵢxᵢ)²/m = Σᵢ(xᵢ − x̄)²，只要属性 x 的取值不全相同，分母即严格大于零，解唯一。例如对三点 (1, 2.1)、(2, 3.9)、(3, 6.2) 用上述闭式解拟合直线：x̄ = 2，分子 Σyᵢ(xᵢ − x̄) = 2.1×(−1) + 3.9×0 + 6.2×1 = 4.1，分母 Σ(xᵢ − x̄)² = 2，故 w = 4.1/2 = 2.05；再由 b = (2.1+3.9+6.2)/3 − 2.05×2 ≈ −0.03，得拟合直线 f(x) = 2.05x − 0.03，该直线使三点处的均方误差达到最小。更一般地考虑多元线性回归：设有 d 个属性，模型为 f(xᵢ) = wᵀxᵢ + b。为便于矩阵表达，把 b 并入权重向量，令 ŵ = (w; b)，相应地把数据集表示为一个 m×(d+1) 大小的矩阵 X（每行对应一个样本，最后一列元素恒为 1），标记写成向量 y，则目标为 ŵ* = argmin ‖y − Xŵ‖²。对 ŵ 求导得 2Xᵀ(Xŵ − y)，令其为零，可得闭式解 ŵ* = (XᵀX)⁻¹Xᵀy。式中 (XᵀX)⁻¹ 要求 XᵀX 为满秩矩阵；当 XᵀX 不满秩（例如变量数目多于样本数目）时，可解出多个 ŵ，此时需引入正则化项（如 L1 正则的 LASSO、L2 正则的岭回归），或由归纳偏好决定选择哪一个解。对离散属性需先作数值化处理：若属性值之间存在"序"关系（如"高、中、低"），可将其连续化为 1.0、0.5、0.0 之类的数值；若属性值之间不存在序关系（如舌色取"淡白、淡红、红、绛"——淡白与绛之间并无数值大小关系），通常转化为 k 维向量（每个分量对应一个属性值，样本在对应分量为 1、其余为 0，即 one-hot 编码），因为若直接赋予 0、1、2 之类的序数值，会不当引入属性值之间的距离关系。线性回归还可向广义方向推广：若认为输出标记是在指数尺度上变化（如房价、人口等呈指数增长的量），可令 ln y = wᵀx + b，即 y = e^(wᵀx+b)，此时模型用 e^(wᵀx+b) 去逼近 y，称为对数线性回归。更一般地，考虑单调可微函数 g(·)，令 g(y) = wᵀx + b，这样得到的模型称为广义线性模型（generalized linear model），g 称为联系函数（link function）；通过对 g 的不同选取即可适配指数分布、泊松分布等多种输出分布，对数线性回归是 g(·) = ln(·) 的特例。从统计视角看，均方误差最小化与"误差服从高斯分布时的极大似然估计"在数学上等价（通行统计结论，非原书论断），这赋予了最小二乘法概率解释；实践中还可辅以决定系数 R²、残差图等工具诊断拟合质量。多元线性回归的完整应用流程通常包括：数据预处理（缺失值处理、离群点剔除、离散属性编码、特征标准化）→ 用训练集求解闭式解 → 在验证集上评估泛化性能 → 必要时引入正则化或特征选择。当特征数目 p 大于样本数目 m 时，XᵀX 必然不满秩，此时岭回归在目标中加入 λ‖w‖² 项、其闭式解变为 ŵ = (XᵀX + λI)⁻¹Xᵀy（λ 为大于零的正则化系数，经交叉验证确定），LASSO 则以 L1 范数 ‖w‖₁ 诱导稀疏解、自动实现特征选择；正则化不仅解决秩亏问题，也通过收缩参数幅度抑制过拟合。对数线性回归的典型应用是房价预测：房价随面积、地段等因子大体呈指数增长，直接拟合 y 效果不佳，而对 ln y 做线性拟合通常能得到更合理的模型。广义线性模型族还包括以泊松回归（联系函数取对数、输出服从泊松分布）处理计数型标记、以 probit 回归（联系函数取标准正态分布函数的逆）处理二分类等变体，它们共同构成了从线性回归通向各类输出分布的统一框架。此外，特征标准化（使各属性均值为零、方差为一）虽不改变线性模型的拟合能力，但能显著改善迭代优化的收敛速度，并使正则化对各特征公平施加，是工程中的推荐预处理步骤。在感冒证候数据集上，若用"体温"与"恶寒程度评分"两个连续属性拟合风寒证倾向，二者量纲不同（体温约 36~39、恶寒评分约 0~50%），标准化后求解与解释都更规范。模型评估方面，闭式解直接给出训练误差最小的参数，但训练误差小不代表泛化性能好，仍需用留出法或交叉验证（第 2 章）在未参与训练的数据上评估；当训练误差与验证误差差距过大时，说明发生了过拟合，应优先考虑增加样本或引入正则化。从计算复杂度看，多元最小二乘的主要开销在 XᵀX 的求逆（约 O(p³)，p 为特征数），特征维度很高时可改用梯度下降等迭代法或稀疏求解器，这是工程上在大规模高维数据上的通行做法。本节要点：线性回归以均方误差为度量、用最小二乘法求解，一元与多元情形均有闭式解，秩亏时引入正则化；通过联系函数可推广为广义线性模型，为下一节把线性模型用于分类埋下伏笔。

## 3.3 对数几率回归

上一节的线性回归用于回归任务。若要处理分类任务，只需找一个单调可微函数将分类任务的真实标记 y 与线性回归模型的预测值联系起来。考虑二分类任务，输出标记 y ∈ {0, 1}，而线性回归模型产生的预测值 z = wᵀx + b 是实值，最理想的情形是"单位阶跃函数"（unit-step function）：z < 0 时判为 0（反例）、z > 0 时判为 1（正例）、z = 0 时任意判别。但单位阶跃函数不连续、不可微，不利于后续的求导优化。于是希望找到一个能在一定程度上近似单位阶跃函数的"替代函数"，并希望它单调可微。对数几率函数（logistic function）正是这样一个常用的替代函数：y = 1 / (1 + e^(−z))，它的图像呈 S 形（sigmoid），当 z → +∞ 时 y → 1，当 z → −∞ 时 y → 0，在 z = 0 附近平滑过渡，且处处连续可导。将对数几率函数作为广义线性模型中联系函数的逆代入，令 z = wᵀx + b，得 y = 1 / (1 + e^(−(wᵀx+b)))。将该式变形可得 ln(y/(1−y)) = wᵀx + b。若把 y 视为样本 x 作为正例的可能性，则 1−y 是其作为反例的可能性，两者的比值 y/(1−y) 称为"几率"（odds），反映了 x 作为正例的相对可能性；对几率取对数则得到"对数几率"（log odds，亦称 logit）。由此可见，上式实际上是在用线性回归模型的预测结果去逼近真实标记的对数几率，因此该模型被称为"对数几率回归"（logistic regression，常被译作"逻辑回归"，但"对数几率回归"更贴合其数学本质）。对数几率回归有三个突出优点：其一，它无需事先假设数据分布，直接对分类可能性建模，避免了假设分布不准确所带来的问题；其二，它不是仅预测出"类别"，而是可得到近似概率预测，这对许多需利用概率辅助决策的任务很有用；其三，对率函数是任意阶可导的凸函数，有很好的数学性质，现有的许多数值优化算法都可直接用于求取最优解。参数估计采用极大似然法（maximum likelihood method）：将 y 视为类后验概率估计 p(y=1|x)，令 β = (w; b)、x̂ = (x; 1)，则 wᵀx + b 可写成 βᵀx̂，且有 p(y=1|x) = e^(βᵀx̂)/(1 + e^(βᵀx̂))、p(y=0|x) = 1/(1 + e^(βᵀx̂))。通过极大似然法估计 β，即最大化对数似然 ℓ(w,b) = Σᵢ ln p(yᵢ|xᵢ; w,b)，等价地可重写为最小化 ℓ(β) = Σᵢ (−yᵢβᵀx̂ᵢ + ln(1 + e^(βᵀx̂ᵢ)))。ℓ(β) 是关于 β 的高阶连续可导凸函数，可用梯度下降法、牛顿法等数值优化算法求解。以牛顿法为例，其迭代式为 β^(t+1) = β^(t) − (∂²ℓ/∂β∂βᵀ)⁻¹ ∂ℓ/∂β，其中一阶导数 ∂ℓ/∂β = −Σᵢ x̂ᵢ(yᵢ − p₁(x̂ᵢ; β))，二阶导数（Hessian 矩阵）∂²ℓ/∂β∂βᵀ = Σᵢ x̂ᵢx̂ᵢᵀ·p₁(x̂ᵢ; β)·(1 − p₁(x̂ᵢ; β))，Hessian 矩阵正定保证了目标函数的凸性，牛顿法每次迭代沿二阶近似的最优方向更新参数，通常收敛较快。经典应用实例：在感冒证候数据集上以"恶寒程度"与"体温"为属性，用对数几率回归学得判别模型后，可对任意新病历给出其属风寒证的概率，概率大于 0.5 判为风寒证；教材图 3.3 展示了学得的 sigmoid 形状的对数几率函数曲线，风寒证与风热证样本点大多分居曲线两侧。对数几率函数的导数具有简洁形式 σ′(z) = σ(z)(1 − σ(z))，这一性质使梯度与 Hessian 矩阵的计算非常方便，也是对率回归广泛用于工程实践的原因之一。从决策角度看，对率回归的决策边界由 wᵀx + b = 0 给出，是特征空间中的一个线性超平面：落在边界一侧的样本被判为正类、另一侧判为反类，而样本距边界的远近则通过 sigmoid 映射为 0 到 1 之间的概率，越远则置信度越高。这一"线性边界 + 概率输出"的组合，使对率回归既保持了线性模型的简洁与可解释，又为后续决策提供了概率依据——例如在医疗场景中可设定保守阈值（如概率大于 0.7 才判为某证型，否则建议进一步检查），这正是平台"概率仅供辅助参考"工程口径的模型侧来源。求解时需注意：ℓ(β) 虽为凸函数，但通常不存在解析解，需迭代优化；牛顿法利用二阶信息收敛较快，梯度下降则实现简单、适合大规模数据，实践中还常加入 L2 正则项（工程实践，非原书内容）以抑制高维特征下的过拟合。若将二分类对率回归按 OvR 方式组合，即可得到多分类的概率输出方案（详见 3.5 与 part2 的工程实现）。感冒证候例子中，学得的决策边界大致沿"恶寒程度-体温"平面的一条直线，风寒证样本集中分布在边界一侧，体现了模型对数据几何结构的刻画能力。对率回归与线性回归的另一重要联系在于损失函数：线性回归用平方损失，对率回归用对率损失（log loss），二者都是凸损失；对率损失对"置信度过高但判错"的样本施加更大惩罚，这使对率回归天然更关注分类边界附近的样本。在特征共线性较强的场景，对率回归的系数估计可能不稳定，工程上可先做相关性筛查或依赖正则化缓解。由于对率回归输出的是后验概率估计，它还可与贝叶斯决策框架衔接：把 p(y=1|x) 与先验概率、误分类代价结合，得到使期望损失最小的决策（统计通行结论，非原书论断），这为医疗等代价不对称场景提供了规范化的决策路径。从数值稳定性看，直接计算 e^(−z) 在 z 很大时可能下溢，工程实现中通常对 z 做截断或使用 log-sum-exp 技巧（工程实践），保证概率输出稳定。本节要点：对数几率回归用对数几率函数把线性输出映射到 (0,1) 区间，等价于用线性模型逼近对数几率；参数以极大似然法结合牛顿法等数值优化求解，输出为概率且无需分布假设，是二分类任务的经典基线模型。

## 3.4 线性判别分析 LDA

线性判别分析（Linear Discriminant Analysis，简称 LDA）是一种经典的线性学习方法，其思想朴素而优美：给定训练集，设法将样例投影到一条直线上，使得同类样例的投影点尽可能接近（类内距离最小）、异类样例的投影点尽可能远离（类间距离最大）；对新的样本点，将其投影到该直线上，再依据投影点的位置判别其所属类别。LDA 在二分类问题上最早由 Fisher 于 1936 年提出，故亦称"Fisher 判别分析"。先考虑二分类情形。给定数据集 D，令 Xᵢ、μᵢ、Σᵢ 分别表示第 i ∈ {0,1} 类示例的集合、均值向量与协方差矩阵。若将数据投影到直线 w 上，则两类样本投影后的中心分别为 wᵀμ₀ 与 wᵀμ₁，投影后的类内"紧凑程度"可用 wᵀΣ₀w + wᵀΣ₁w 度量。要使同类投影点尽可能接近，即令 wᵀΣ₀w + wᵀΣ₁w 尽可能小；要使异类投影点尽可能远离，即令 ‖wᵀμ₀ − wᵀμ₁‖₂² 尽可能大。两者结合，可得最大化目标 J = ‖wᵀμ₀ − wᵀμ₁‖₂² / (wᵀΣ₀w + wᵀΣ₁w) = wᵀS_b w / (wᵀS_w w)，其中定义类内散度矩阵（within-class scatter matrix）S_w = Σ₀ + Σ₁，类间散度矩阵（between-class scatter matrix）S_b = (μ₀−μ₁)(μ₀−μ₁)ᵀ，J 称为广义瑞利商（generalized Rayleigh quotient）。由于分子分母都是关于 w 的二次型，J 的大小与 w 的幅值无关、只与方向有关，故可令 wᵀS_w w = 1，将最大化 J 转化为在约束 wᵀS_w w = 1 下最大化 wᵀS_b w。用拉格朗日乘子法对 w 求导并令其为零，可得 S_b w = λS_w w，即 S_w⁻¹S_b w = λw，说明 w 是矩阵 S_w⁻¹S_b 的特征向量。又因为 S_b w = (μ₀−μ₁)(μ₀−μ₁)ᵀw 恒与向量 (μ₀−μ₁) 同向，最终可得判别投影方向 w = S_w⁻¹(μ₀−μ₁)，即把两类均值差用类内散度的逆矩阵"白化"后得到的方向：先按类内散布对各向异性做校正，再沿校正后的均值差方向投影。LDA 还可看作一种监督降维方法：它将 d 维样本投影到至多 N−1 维（N 为类别数），既可用于分类，也可用于降维与可视化。多分类情形下，定义全局散度矩阵 S_t = S_b + S_w = Σᵢ(xᵢ − μ)(xᵢ − μ)ᵀ（μ 为所有样本的均值向量），类内散度矩阵 S_w = Σᵢ₌₁ᴺ S_wᵢ，其中 S_wᵢ = Σ_{x∈Xᵢ}(x − μᵢ)(x − μᵢ)ᵀ，则类间散度矩阵 S_b = S_t − S_w = Σᵢ₌₁ᴺ mᵢ(μᵢ − μ)(μᵢ − μ)ᵀ（mᵢ 为第 i 类样本数）。多分类 LDA 的优化目标为 max tr(WᵀS_bW) / tr(WᵀS_wW)，其中 W ∈ ℝ^(d×(N−1))，其解为 S_w⁻¹S_b 的 d′（d′ ≤ N−1）个最大非零广义特征值对应的特征向量组成的矩阵；由于 N 个类均值向量至多张成 N−1 维子空间，故投影维数至多 N−1。应用实例：在感冒证候数据集上，将"恶寒程度"与"咽红程度"构成的二维样本投影到 LDA 学得的判别直线上，风寒证与风热证的投影点被明显分开，两类样本在直线上的投影分布清晰可分；在 tcmP 平台中，可将症状、舌象、脉象等高维特征投影到鉴别诊断方向，辅助"风寒束表"与"风热犯卫"等相近证型的鉴别（该应用为平台适配内容，统计结论送 tcmreviewer 审稿）。投影的几何意义值得强调：LDA 所求的 w 定义了一条过原点的直线方向，所有样本点沿该方向做正交投影，一维投影轴上两类样本的分布被拉开、重叠减少，判别即在一维轴上完成——这比在高维空间中直接划分边界更直观，也解释了 LDA 常被用作可视化工具的原因。Fisher 于 1936 年提出该方法时，正是用鸢尾花（Iris）数据集的三个类别、四个属性做演示，将四维数据投影到一维/二维后三类样本清晰可分，该数据集至今仍是判别分析的经典案例。LDA 与无监督降维方法主成分分析（PCA，见第 10 章）的差异在于：PCA 仅最大化投影后方差、不利用类别标记，而 LDA 显式利用类别信息最大化类间散度与类内散度之比，因此在分类任务上 LDA 的投影方向通常更有判别力。数值实现上，当样本数少于特征维数时 S_w 可能奇异，工程中常先对 S_w 做对角加噪（加 λI）或使用其伪逆（工程实践，非原书内容）。多类 LDA 还可直接作为分类器使用：把样本投影到低维判别空间后，按最近类均值（或最近中心）准则判别，这与"投影→判类"的两段式思想一致。在 tcmP 中，多类 LDA 可将多个相近证型的四诊特征投影到二维平面，在图上直接观察各证型的簇分布与重叠程度，为证型体系的结构化梳理提供数据视角。LDA 的推导还揭示了它与线性回归、对率回归的深层联系：三者学得的都是一组线性系数，区别仅在目标函数——LDA 以散度比为目标，对率回归以对率损失为目标，线性回归以平方损失为目标；在二分类且两类协方差相等的高斯假设下，LDA 与对率回归的决策边界具有一致的渐近形式（统计结论，非原书论断），这从侧面说明"线性判别"这一几何框架与"概率建模"这一统计框架在二分类问题上的殊途同归。多类情形下，若各类样本数相差悬殊，S_w 中样本数少的类贡献小，投影方向可能被多数类主导，工程上可结合 3.6 的类别不平衡处理（如按类加权散度）加以缓解（工程实践，送 tcmreviewer 审稿）。本节要点：LDA 通过最大化广义瑞利商寻找使类内紧凑、类间疏离的投影方向，二分类解为 w = S_w⁻¹(μ₀−μ₁)，多分类转化为广义特征值问题，兼具分类与监督降维两种用途。

## 3.5 多分类学习与类别不平衡

多分类学习的基本思路是"拆解法"：将多分类任务拆分为若干个二分类任务求解，再对预测结果进行集成。经典拆分策略有三种：一对一（One vs. One，简称 OvO）、一对其余（One vs. Rest，简称 OvR）、多对多（Many vs. Many，简称 MvM），其中 OvO 与 OvR 可视作 MvM 的特例。OvO 将 N 个类别两两配对，产生 N(N−1)/2 个二分类任务，每个任务只用两类样本训练一个分类器；测试时，新样本同时提交给所有分类器，得到 N(N−1)/2 个分类结果，最终通过投票产生被预测得最多的类别作为最终分类结果。OvR 每次将一个类的样例作为正例、其余所有类的样例作为负例，训练 N 个分类器；测试时，若仅有一个分类器预测为正类，则对应的类别标记作为最终分类结果；若有多个分类器预测为正类，则通常考察各分类器的预测置信度，选择置信度最大的类别标记作为分类结果。对比二者：OvO 需训练 N(N−1)/2 个分类器，存储与测试时间开销较大，但每个分类器只用两类样本训练，单个分类器的训练时间较短；OvR 只需训练 N 个分类器，总开销较小，但每个分类器都使用全部样本训练。类别很多时，OvO 的总训练时间通常更小，而预测阶段 OvR 更快；两者中的每个二分类器都可采用任意二分类学习算法（如对数几率回归、支持向量机）。MvM 每次将若干个类作为正类、若干个其他类作为负类，正负类的划分由"纠错输出码"（Error Correcting Output Codes，简称 ECOC）编码矩阵决定。ECOC 将每个类别编码为一个码字（codeword）：对 N 个类别、M 个二分类任务，编码矩阵为 N×M 的矩阵，行对应类别、列对应二分类器；二分类器对某类别的输出用 +1/−1 表示正类/负类，三元码还允许 0 表示"忽略该类"，即该分类器不参与此类别的判别。测试时，将新样本在 M 个二分类器上的预测结果组成一个编码，与各类别的码字比较（常用海明距离），取距离最近（或按某种准则最匹配）的类别作为预测结果。ECOC 的纠错性质在于：编码越长，对测试阶段个别分类器出错的容忍能力越强，泛化能力往往越好，但计算与存储开销也随之增大；对 N 个类别，理论上至少需要 ⌈log₂N⌉ 位编码，实际中常采用更长的编码以换取纠错能力。类别不平衡（class-imbalance）指分类任务中不同类别的训练样本数目差别很大的情况，例如临床数据集中某罕见证型（如寒凝胞宫）的病历极少而常见证型极多。若直接学习，学得的模型会严重偏向多数类——因为它只需"把样本全判为多数类"即可获得很高的精度，但对少数类毫无判别力。基本策略是"再缩放"（rescaling）：令 y′/(1−y′) = y/(1−y) × (m⁻/m⁺)，其中 m⁺ 为正例数目、m⁻ 为反例数目，即用训练集中正反例的数目比例去修正预测几率；再缩放是"基本"策略，其前提是训练集是真实样本总体的无偏采样，否则还需考虑"代价敏感学习"。实现再缩放有三类手段：① 欠采样（undersampling）：直接丢弃一些多数类样本使正反例数目接近，代表方法如 EasyEnsemble（利用集成学习机制多次欠采样）；② 过采样（oversampling）：增加一些少数类样本使正反例数目接近，代表方法如 SMOTE（在少数类样本的近邻间插值合成新样本）；③ 阈值移动（threshold moving）：直接基于原始训练集学习，但在决策时利用再缩放后的阈值——例如令 y′/(1−y′) > 1 时判为正类，等价于把默认阈值 0.5 调整为 m⁺/(m⁺+m⁻)。三类手段各有取舍：欠采样时间开销小但丢弃样本可能丢失重要信息；过采样时间开销大但保留全部信息；阈值移动无需改动训练数据，实现最简洁。应用实例：某临床数据集中罕见证型样本远少于常见证型，若不处理，模型倾向于把所有病历判为常见证型；采用再缩放（或阈值移动）后，模型对罕见证型的判别能力显著改善。在 tcmP 平台中，罕见证型样本稀少，可结合 SMOTE 过采样与阈值移动处理（现代认识/统计来源，送 tcmreviewer 审稿）。以 N = 10 类任务为例：OvO 需训练 10×9/2 = 45 个二分类器，OvR 仅需 10 个，存储与预测开销差异明显；而 OvO 每个分类器的训练样本只含两类，单个分类器训练时间反而更短，故类别较多时 OvO 常为更优选择。ECOC 的编码与解码过程可这样理解：对三类任务设计五个二分类器，每个类别对应一个五位码字（如类 A 的码字为 (+1,+1,−1,−1,+1)），测试时把新样本在五个分类器上的输出拼成五位编码，逐一与各类码字计算海明距离——即两个等长码字对应位置取值不同的个数——取距离最小的码字对应类别作为预测；若个别分类器出错，只要错误位数小于码字间最小海明距离的一半，仍能正确解码，这正是"纠错输出码"名称的由来。类别不平衡在现实任务中普遍存在：癌症筛查中阳性病例远少于阴性、信用卡欺诈检测中欺诈交易占比极低，若不处理，模型会把所有样本判为多数类，对少数类的召回率趋近于零。SMOTE 的工作原理是：对每个少数类样本，在其 k 个近邻中随机选取一个，沿连线方向随机插值生成新样本，从而在不丢失信息的前提下扩充少数类；与之相对，随机过采样只是简单复制少数类样本，易造成过拟合。再缩放思想还可推广为代价敏感学习：当不同类别误分类代价不同（如漏诊癌症的代价远高于误报）时，以代价比替代样本数比修正预测，使模型偏向代价更高的类别。平台病案库中，若某证型样本占比不足 5%，即触发类别不平衡处理流程，并优先采用阈值移动与 SMOTE 的组合方案。ECOC 编码还可由领域知识驱动设计：将中医理论中证型间的亲疏关系（如风寒与风热相近、与阴虚较远）反映到码字间距上，使编码距离与证型差异度对齐，从而让误判倾向于发生在"相似"证型之间而非完全无关的证型之间（平台适配设想，送 tcmreviewer 审稿）。本节要点：多分类通过 OvO、OvR、MvM 拆解为二分类并集成，ECOC 以编码与海明距离实现纠错；类别不平衡用再缩放修正预测，欠采样、过采样、阈值移动是三种典型实现。

## 3.6 本章小结

本章围绕线性模型这一最基础、最可解释的模型族展开，六节内容环环相扣、层层递进。3.1 给出线性模型的基本形式 f(x) = wᵀx + b，说明权重向量 w 的每个分量直观表达对应属性的重要性，线性模型因此具有极好的可解释性，且是神经网络、支持向量机、集成学习等非线性模型的基础构件；从几何上看，线性模型学得的正是特征空间中的一个超平面。3.2 针对回归任务，以均方误差为性能度量、用最小二乘法求解线性回归：一元情形推导出闭式解 w = Σyᵢ(xᵢ−x̄)/(Σxᵢ²−(Σxᵢ)²/m)、b = (1/m)Σ(yᵢ−wxᵢ)，多元情形得到矩阵形式的闭式解 ŵ* = (XᵀX)⁻¹Xᵀy，并指出 XᵀX 不满秩时解不唯一、需引入正则化（L1 的 LASSO、L2 的岭回归）；进而通过联系函数 g(·) 推广出广义线性模型 g(y) = wᵀx + b，其中 g(·) = ln(·) 时即对数线性回归。3.3 用单调可微的对数几率函数（sigmoid）替代不连续不可微的单位阶跃函数，把线性模型用于分类，得到对数几率回归：ln(y/(1−y)) = wᵀx + b，即用线性回归逼近真实标记的对数几率；该模型无需假设数据分布、直接对分类可能性建模、输出为概率；参数以极大似然法估计，最小化 ℓ(β) = Σ(−yᵢβᵀx̂ᵢ + ln(1+e^(βᵀx̂ᵢ)))，可用梯度下降、牛顿法等凸优化算法求解。3.4 的线性判别分析从"类内紧凑、类间疏离"出发，定义类内散度矩阵 S_w 与类间散度矩阵 S_b，以最大化广义瑞利商 J = wᵀS_bw/wᵀS_ww 为目标，用拉格朗日乘子法导出二分类判别方向 w = S_w⁻¹(μ₀−μ₁)，多分类情形转化为 S_w⁻¹S_b 的广义特征值问题，将样本投影到至多 N−1 维，兼具分类与监督降维两种用途。3.5 讨论多分类学习的拆解策略：OvO 两两配对投票、OvR 一对其余取置信度最大者、MvM 借助纠错输出码 ECOC 以海明距离判类并利用编码纠错提升泛化；同时讨论类别不平衡问题，给出再缩放 y′/(1−y′) = y/(1−y) × (m⁻/m⁺) 这一基本策略及其欠采样、过采样、阈值移动三种实现手段。整体来看，本章的三条主线——最小二乘（3.2）、极大似然（3.3）、广义瑞利商（3.4）——分别对应回归、分类、降维三类任务的代表性优化视角，而 3.5 的拆解与再缩放则解决了多分类与数据偏斜这两个实践中的普遍难题。线性模型结构简单、训练高效、权重可解释，其局限在于表达能力有限，对强非线性关系需借助特征工程（多项式展开、基函数映射）或升级为非线性模型，这正是后续章节（神经网络、支持向量机、集成学习等）发展的动因。在 tcmP 平台中，线性模型可作为证型概率引擎与鉴别诊断投影的基础组件，其权重可解释性契合审稿人可核查的教材口径：每个特征的贡献一目了然，统计结论一律送 tcmreviewer 审稿后方可用于教学与辅助流程（现代认识/统计来源，可辅助参考，不改经典原义）。从模型选择的视角看：输出为实值且关系近似线性时首选线性回归；输出为类别且需要概率与可解释性时首选对数几率回归；需要降维可视化或判别相近类别时首选 LDA；类别多或样本偏斜时再叠加 3.5 的拆解与再缩放策略。三者统一于线性假设，区别在于目标函数与输出形式，这一"同一模型族、不同任务适配"的脉络在后续章节中反复出现。线性模型的工程优势还包括：训练与预测的计算开销低、可处理高维稀疏特征、权重可直接导出用于报告与审计；其局限则是无法刻画特征间的非线性交互（如"舌红且脉数同时出现才指向热证"这类合取关系），对此可先做特征工程（构造交叉项、多项式特征、核映射），或直接采用后续章节的非线性模型。在整本教材的体系位置中，本章是承上启下的枢纽：承上，它把第 1、2 章的学习范式（假设空间、经验风险最小化、泛化误差）落实到第一个具体可解的模型；启下，神经网络可视作多层线性模型叠加以非线性激活，支持向量机可视作带最大间隔约束的线性分类器经核技巧推广，集成学习则常以线性模型为基学习器——理解本章的优化与几何思想，是掌握后续复杂模型的必要前提。本章还为后续章节储备了三个关键数学工具：其一，矩阵形式的闭式解与广义特征值问题（3.2、3.4），是第 10 章降维与第 6 章支持向量机推导的基础；其二，凸函数与迭代优化（3.3），是第 5 章神经网络反向传播、第 11 章稀疏表示优化的共同语言；其三，散度矩阵与投影思想（3.4），在第 10 章核化线性判别分析中直接复用。教学建议上，本章宜配合三个动手实验：用最小二乘拟合真实数据并绘制残差图、用对率回归输出概率并观察阈值移动的效果、用 LDA 对两类数据投影并目视判别轴——三者分别对应教材 3.2、3.3、3.4 的核心结论，可在 tcmP 平台教学沙箱中直接运行；平台侧还可将本章模型输出的权重表与后续各章模型（SVM、神经网络）的特征重要性对照，让学生体会"可解释性"在模型复杂度上升过程中的取舍。学习本章还应注意几个常见误区：其一，把对率回归的输出直接当作校准概率用于高风险决策，实际中概率值可能有偏差（工程上可做 Platt 缩放等概率校准，属工程实践）；其二，忽视特征量纲与编码方式对权重可解释性的影响，权重比较必须在同一量化口径下进行；其三，把 LDA 与 PCA 混为一谈，二者目标不同、适用场景不同。建议读者在掌握公式推导的同时，动手用真实数据复现三节核心实验，并对照教材图示检验自己对几何图像的理解。本节要点：线性模型家族以最小二乘、极大似然、广义瑞利商三大优化视角统一了回归、分类与降维三类任务，是可解释机器学习的地基。

| part2 | P2.5 | 类别不平衡处理 SMOTE | 25 | 平台病历库中常见证型样本多、罕见证型样本少，直接训练会严重偏向多数类，对应本章 3.6 的类别不平衡问题。对策有三：① 过采样——from imblearn.over_sampling import SMOTE，对少数类样本在近邻间插值合成新样本后再训练，注意 k_neighbors 参数（默认 5）与特征空间距离度量需与四诊特征编码一致，特征量纲差异大时先标准化；② 再缩放/阈值移动——用 m⁻/m⁺ 修正决策阈值，即公式 y′/(1−y′) = y/(1−y) × (m⁻/m⁺) 的工程实现，或使用 class_weight='balanced' 让算法自动按类频数加权，也可在 predict_proba 之后按平台预设的敏感度档位移动阈值；③ 评估指标改用 PR-AUC、F1 与召回率而非 Accuracy，避免被多数类掩盖，罕见证型的召回率单独报告并设最低门槛（如 ≥0.7 方可发布）。工程要点：SMOTE 合成必须发生在交叉验证的每一折训练集内部，严禁先全局合成再划分，否则会造成数据泄露、评估结果虚高；推荐用 imblearn.pipeline.Pipeline 将 SMOTE 与分类器封装为整体，配合 GridSearchCV 统一调参，网格搜索同样在折内完成合成。安全红线：合成样本属统计构造，须标注现代认识、统计来源并送 tcmreviewer 审稿；合成数据仅用于模型训练与统计教学演示，严禁以合成数据冒充真实临床证据用于教学结论或任何诊疗表述。具体代码路径示例：X_res, y_res = SMOTE(k_neighbors=5, random_state=42).fit_resample(X_train, y_train)，随后以 X_res/y_res 训练分类器；评估集划分按 8:2 比例分层抽样（stratify=y），保证少数类在训练与评估中都有代表性样本。本部分为 hermes-generating-content。 |
