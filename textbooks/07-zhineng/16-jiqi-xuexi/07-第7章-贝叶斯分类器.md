## 7.1 贝叶斯决策论

在机器学习所面对的许多问题中，决策都必须在不确定条件下做出：面对一个样本 x，它最可能属于哪个类别？不同类别的判断失误造成的后果是否相同？贝叶斯决策论（Bayesian Decision Theory）在概率框架下给出了这类问题的最优答案，是整个第 7 章的理论基石。设样本空间上有 N 个类别 c₁, c₂, …, c_N，对样本 x，我们用后验概率 P(c|x) 刻画"给定 x 时它属于类别 c"的不确定性。贝叶斯决策论的核心思想是：分类错误的代价可能因类别而异，因此决策应当使期望损失——即风险（risk）——最小化，而不是简单追求"猜对的次数最多"。 先引入损失（loss）的概念。设 λᵢⱼ 表示把一个真实类别为 cⱼ 的样本误判为类别 cᵢ 所产生的损失；一般约定 λᵢᵢ = 0，即判断正确不产生损失，而 λᵢⱼ（i ≠ j）为正值。将样本 x 判为 cᵢ 所产生的期望损失称为条件风险（conditional risk），其定义为对各类别真实后验的加权和：R(cᵢ|x) = Σⱼ λᵢⱼ·P(cⱼ|x)，其中求和遍及全部 N 个类别。若记分类器 h 在样本空间上的总体风险为 R(h) = Eₓ[R(h(x)|x)]，即条件风险关于样本分布的期望，那么贝叶斯判定准则（Bayesian decision rule）要求对每个样本选择使条件风险最小的类别：h*(x) = argmin_{c∈Y} R(c|x)，其中 Y 为类别集合。满足该准则的分类器 h* 称为贝叶斯最优分类器（Bayes optimal classifier），其总体风险 R(h*) 称为贝叶斯风险（Bayes risk）。贝叶斯风险对应的分类精度是所有基于同一数据分布的模型都无法超越的理论上限，它为机器学习算法的性能评估提供了"天花板"式的参照。 在分类任务中最常用的损失是 0-1 损失（0/1 loss）：λᵢⱼ = 0（当 i = j，即判断正确）；λᵢⱼ = 1（当 i ≠ j，即判断错误）。把它代入条件风险的定义，得 R(c|x) = Σⱼ λ(c, cⱼ)·P(cⱼ|x) = Σ_{j ≠ c} P(cⱼ|x) = 1 − P(c|x)。于是最小化条件风险等价于最大化后验概率，即 h*(x) = argmax_{c∈Y} P(c|x)。换言之，在 0-1 损失下，贝叶斯最优分类器把样本判给后验概率最大的类别，这正是一种最大后验估计（MAP，Maximum A Posteriori）。此时分类器的错误率称为贝叶斯误差率（Bayes error rate），对单个样本而言是 1 − max_c P(c|x)，其期望 1 − Eₓ[max_c P(c|x)] 构成任何分类器都不可逾越的理论下界：学习算法无论多么精巧，都只能逼近而不能突破它。这一结论把"学习"的根本任务清晰地归结为——尽可能准确地估计后验概率 P(c|x)，估计得越准，模型就越接近最优。 为直观理解风险与后验的关系，看一个带不对称损失的例子（演示数值）。设二分类问题中 c₁ 为"垃圾邮件"、c₂ 为"正常邮件"，损失矩阵取 λ₁₁ = λ₂₂ = 0，λ₁₂ = 1（把正常邮件误判为垃圾，损失为 1），λ₂₁ = 5（把垃圾邮件误判为正常，损失为 5，因为漏掉一封垃圾邮件的代价更高）。若某样本 x 的后验为 P(c₁|x) = 0.7、P(c₂|x) = 0.3，按 0-1 损失会判为 c₁；但按上述非对称损失：R(c₁|x) = λ₁₁·P(c₁|x) + λ₁₂·P(c₂|x) = 0×0.7 + 1×0.3 = 0.3，R(c₂|x) = λ₂₁·P(c₁|x) + λ₂₂·P(c₂|x) = 5×0.7 + 0×0.3 = 3.5。最小风险对应判为 c₁（0.3 < 3.5）。若把后验反过来，P(c₁|x) = 0.3、P(c₂|x) = 0.7，则 R(c₁|x) = 0.7，R(c₂|x) = 1.5，仍然判为 c₁——尽管正常邮件的后验更高，但"漏判垃圾"的代价太大，风险最小的决策依然是当作垃圾处理。这个例子说明：当损失不对称时，最优决策由"后验与损失共同加权"决定，不能只比较后验大小。 中医药场景：设二分类问题中 c₁ 为"风寒表实证"、c₂ 为"风热犯表证"，损失矩阵取 λ₁₁ = λ₂₂ = 0，λ₁₂ = 1（把风寒误判为风热，损失为 1），λ₂₁ = 5（把风热误判为风寒，损失为 5，因为误用辛温解表法于风热证会加重病情，代价更高）。若某病历 x 的后验为 P(c₁|x) = 0.7、P(c₂|x) = 0.3，按 0-1 损失会判为 c₁；但按上述非对称损失：R(c₁|x) = 0×0.7 + 1×0.3 = 0.3，R(c₂|x) = 5×0.7 + 0×0.3 = 3.5，最小风险对应判为 c₁。若后验反过来，P(c₁|x) = 0.3、P(c₂|x) = 0.7，则 R(c₁|x) = 0.7，R(c₂|x) = 1.5，仍然判为 c₁——尽管风热证的后验更高，但"误用辛温药"的代价太大（该应用为平台适配内容）。 那么后验概率 P(c|x) 如何得到？由贝叶斯公式：P(c|x) = P(c)·P(x|c) / P(x)。其中 P(c) 是先验概率（prior），表示观测到样本之前类别 c 出现的概率，通常直接用训练集中各类样本所占频率估计，即 P(c) = |D_c|/|D|；P(x|c) 是类条件概率（class-conditional probability），又称似然（likelihood），表示类别 c 中样本 x 出现的概率；P(x) 是证据因子（evidence），对所有类别取相同值，只起归一化作用，因此在比较各类别后验大小时可以略去，只需比较分子 P(c)·P(x|c)。从建模路线上看，贝叶斯分类器属于生成式模型（generative model）：先对联合概率分布 P(x, c) 建模，再由贝叶斯公式导出 P(c|x)；与之相对，逻辑回归、支持向量机等判别式模型（discriminative model）则直接对 P(c|x) 建模。生成式路线的关键难点在于估计类条件概率 P(x|c)：当属性维度 d 较高时，若按属性取值的组合直接计数，需要统计的取值组合数随 d 指数增长，而训练样本有限，绝大多数组合在训练集中从未出现，直接频率估计将遭遇严重的组合爆炸与样本稀疏问题。因此必须引入假设来简化估计——这正是本章后续各节的推进逻辑：7.2 节假设类条件概率服从某种参数化分布，用极大似然估计分布参数；7.3 节假设属性条件独立，把高维联合分布拆成 d 个一维分布分别统计；7.4 节与 7.5 节以更精细的结构（独依赖估计、贝叶斯网）逐步放松独立性假设，在估计可行性与表达力之间取得平衡；7.6 节的 EM 算法则解决存在隐变量时的参数估计问题。把握住"如何估计 P(c|x)"这条主线，就理解了贝叶斯分类器的全貌，也理解了为什么说本章是全书概率思想最集中的一章。 本节要点：贝叶斯决策论把分类问题转化为期望风险最小化问题，条件风险 R(c|x) = Σⱼλᵢⱼ·P(cⱼ|x) 是最优决策的依据；0-1 损失下最小化风险等价于最大化后验概率，得到贝叶斯最优分类器 h*(x) = argmax P(c|x)，其贝叶斯误差率是任何分类器不可超越的理论下界；估计类条件概率 P(x|c) 是贝叶斯分类器的主要难点，也是本章后续各节展开的动机。

## 7.2 极大似然估计

在 7.1 节我们看到，贝叶斯分类器的关键在于估计类条件概率 P(x|c)。当属性为连续值或取值空间很大时，直接按频率计数不可行，一个自然的思路是假设 P(x|c) 服从某种已知形式的概率分布，把"估计整个分布"转化为"估计分布的一小组参数"，这就是参数估计（parametric estimation）的思想。极大似然估计（Maximum Likelihood Estimation，MLE）是其中最经典的方法，其哲学立场属于频率学派（frequentist）：认为参数 θ 是客观存在但未知的常数，最优的参数应使"观测到当前训练数据"这件事的概率最大。与之相对，贝叶斯学派（Bayesian）把参数本身视为随机变量，并引入先验分布来刻画对其取值的事先信念，其最大后验（MAP）估计可以看作 MLE 加上先验后的推广——两个学派的差异详见后文讨论。 设类别 c 的样本集为 D_c = {x₁, x₂, …, x_m}，并假设样本独立同分布（i.i.d.），且类条件概率 P(x|c) 具有确定的分布形式，其参数向量记为 θ_c，则似然函数（likelihood function）定义为各样本似然之积：L(θ_c) = Π_{i=1}^{m} P(xᵢ|θ_c)。极大似然估计即求使似然最大的参数：θ̂_c = argmax_θ L(θ_c)。由于连乘容易造成数值下溢，且乘积的对数是参数的更易处理的函数，实践中通常最大化对数似然（log-likelihood）：LL(θ_c) = log L(θ_c) = Σ_{i=1}^{m} log P(xᵢ|θ_c)。因为对数函数单调递增，最大化 L 与最大化 LL 等价。标准求解步骤为：第一步，根据对问题的认识选定分布形式（如正态分布、多项式分布）；第二步，写出似然函数并对数化；第三步，对参数求偏导并令导数为零，解方程组得到参数的估计值；当方程无解析解时，可借助梯度上升等数值优化方法。MLE 的直观理解是：在候选参数中，使已观测数据出现概率最大的那个参数，就是最合理的估计。 以最常用的单变量正态分布 N(μ, σ²) 为例给出完整推导。此时 P(x|θ) = (1/√(2πσ²))·exp(−(x−μ)²/(2σ²))，参数 θ = (μ, σ²)。对数似然为 LL(θ) = Σᵢ [−½log(2πσ²) − (xᵢ−μ)²/(2σ²)]。对 μ 求偏导并置零：∂LL/∂μ = Σᵢ (xᵢ−μ)/σ² = 0，解得 μ̂ = (1/m)·Σᵢ xᵢ，即样本均值。对 σ² 求偏导并置零：∂LL/∂σ² = −m/(2σ²) + Σᵢ (xᵢ−μ)²/(2σ⁴) = 0，解得 σ̂² = (1/m)·Σᵢ (xᵢ−μ̂)²，即样本方差（注意分母为样本数 m，这是 MLE 的自然结果；若希望无偏，则除以 m−1）。可见正态分布下的 MLE 估计就是简单的样本均值与样本方差，计算十分轻量。 用一个带数字的例子巩固上述公式（演示数值）。取感冒证候数据集中 8 份风寒证病历的"脉率"属性：72, 68, 75, 70, 66, 78, 69, 74（单位 次/分）。假设 P(脉率|风寒证) 服从正态分布，则由 MLE 得 μ̂ = (72+68+75+70+66+78+69+74)/8 = 572/8 = 71.5；各样本与均值之差的平方和约为 96，故 σ̂² ≈ 96/8 = 12，σ̂ ≈ 3.46。同理可估计"体温"的 μ̂ ≈ 37.2℃、σ̂ ≈ 0.42。有了这两个参数，就能用正态密度公式计算任意脉率值在风寒证类下的似然，这正为 7.3 节朴素贝叶斯处理连续属性提供了手段。 使用 MLE 必须注意两点。其一，结果强烈依赖所假设的分布形式是否符合真实数据：若真实分布与假设相去甚远（例如数据本身是双峰的，却假设了单峰正态），估计出的参数会导致很大的模型误差。因此实践中应先通过直方图、Q-Q 图等可视化手段或统计检验辅助选型，而不是盲目套用正态假设。其二，MLE 在小样本下估计的方差较大、易过拟合，样本越少，极端参数出现的概率越高。此外值得强调的是频率学派与贝叶斯学派的立场差异：MLE 把参数视为确定但未知的常数；贝叶斯学派则把参数视为随机变量，先验 P(θ) 反映了学习前的信念，后验 P(θ|D) = P(θ)P(D|θ)/P(D)，其最大后验估计 θ̂ = argmax_θ P(θ)P(D|θ) 在形式上就是给对数似然加上先验的对数项。当先验取均匀分布时 MAP 退化为 MLE。MLE 既是 7.3 节朴素贝叶斯估计类条件概率的默认工具，也是 7.6 节 EM 算法在"无隐变量"情形下的特例，是本章的方法论基石。 再看离散情形。若属性取值于有限集合（如舌色取淡白、淡红、红、绛），可假设 P(x|c) 服从多项式分布（multinomial distribution）。对类别 c，设属性各取值的概率为 p₁, …, p_K（Σp_k = 1），样本中取值 k 的频数为 n_k（Σn_k = |D_c|），则对数似然为 LL(p) = Σ_k n_k·log p_k，在约束 Σp_k = 1 下用拉格朗日乘子法求极大，得 p̂_k = n_k/|D_c|——即频率估计。这说明 7.3 节朴素贝叶斯中离散属性"直接用频数估计 P(xᵢ|c)"的做法，正是多项式分布下的极大似然估计，两种口径完全自洽，也再次印证 MLE 的普适性：无论连续分布还是离散分布，只要写出似然并最大化，就能得到一致的参数估计框架。本节要点：极大似然估计假设类条件概率具有确定的分布形式，通过最大化对数似然 LL(θ_c) = Σ log P(xᵢ|θ_c) 求解参数；正态分布下 MLE 给出 μ̂ = 样本均值、σ̂² = 样本方差；MLE 依赖分布假设的正确性，且与贝叶斯学派的 MAP 估计在"参数是否为随机变量"上立场不同。

## 7.3 朴素贝叶斯分类器

7.2 节的参数化方法只解决了"分布形式已知"时的估计问题。当属性维度 d 很高时，即便假设每个属性服从某种分布，要估计的联合分布 P(x|c) 仍然复杂得不可操作：属性取值的组合数随 d 指数增长，训练样本永远不够覆盖所有组合。朴素贝叶斯分类器（Naive Bayes classifier）用一个大胆而有效的假设化解了这一难题——属性条件独立假设（attribute conditional independence assumption）：对已知类别，假设所有属性相互独立，即 P(x|c) = Π_{i=1}^{d} P(xᵢ|c)。这一假设把 d 维联合分布的估计分解为 d 个一维分布的估计，从根本上回避了高维稀疏与组合爆炸问题。基于该假设，结合贝叶斯公式，判定准则为：h_nb(x) = argmax_{c∈Y} P(c)·Π_{i=1}^{d} P(xᵢ|c)。注意分母 P(x) 对各类别相同，可略去；分子中的 P(c) 与各 P(xᵢ|c) 分别用训练数据估计。其中离散属性可直接用样本频数估计 P(xᵢ|c)，连续属性则如 7.2 节所述，假设服从正态分布并用极大似然估计均值与方差。 下面用原书例 7.1 完整演示计算流程。训练数据为感冒证候数据集（40 份病历，18 份风寒证、22 份风热证），待判测试样例"测1"为：恶寒=重，汗出=无，脉象=浮紧，舌象=淡红苔薄白，发热=轻，咽部=不红，体温=37.5℃，脉率=72次/分。先估先验：P(风寒证) = 18/40 = 0.45，P(风热证) = 22/40 = 0.55。再按频数估计离散属性的类条件概率（括号内为计数依据，演示计算）：对风寒证，P(恶寒重|风寒证) = 12/18 ≈ 0.667，P(无汗|风寒证) = 15/18 ≈ 0.833，P(脉浮紧|风寒证) = 12/18 ≈ 0.667，P(淡红苔薄白|风寒证) = 14/18 ≈ 0.778，P(发热轻|风寒证) = 11/18 ≈ 0.611，P(咽不红|风寒证) = 13/18 ≈ 0.722；对风热证，P(恶寒重|风热证) = 3/22 ≈ 0.136，P(无汗|风热证) = 4/22 ≈ 0.182，P(脉浮紧|风热证) = 2/22 ≈ 0.091，P(淡红苔薄白|风热证) = 5/22 ≈ 0.227，P(发热轻|风热证) = 4/22 ≈ 0.182，P(咽不红|风热证) = 3/22 ≈ 0.136。于是 P(风寒证)·ΠP(xᵢ|风寒证) ≈ 0.45×0.667×0.833×0.667×0.778×0.611×0.722 ≈ 0.0714，P(风热证)·ΠP(xᵢ|风热证) ≈ 0.55×0.136×0.182×0.091×0.227×0.182×0.136 ≈ 0.0000067，风寒证已经胜出。再计入体温与脉率两个连续属性的高斯密度值后得到：P(风寒证)P(x|风寒证) ≈ 0.063，P(风热证)P(x|风热证) ≈ 0.00057，前者约为后者的 110 倍，故判定"测1"为风寒证。整个计算只涉及一维统计，无需在高维空间计数，这正是属性条件独立假设的价值所在。 实践中朴素贝叶斯必须处理零概率问题：若某个属性值在训练集中从未与类别 c 同现，例如"脉浮紧"在全部 22 份风热证病历中从未出现，则 P(脉浮紧|风热证) = 0/22 = 0，而连乘式中任何一个因子为零都会使整个后验概率归零，其他属性提供的信息全部被抹掉。拉普拉斯修正（Laplace correction/smoothing）是标准的对策：令 N 表示训练集中类别数、Nᵢ 表示第 i 个属性可能的取值数，则修正后的估计为 P(c) = (|D_c| + 1)/(|D| + N)，P(xᵢ|c) = (|D_{c,xᵢ}| + 1)/(|D_c| + Nᵢ)，其中 D_{c,xᵢ} 表示类别 c 中第 i 个属性取值为 xᵢ 的样本集合。分子分母同时加 1（更一般地加常数 λ，称为 Lidstone 平滑），既避免了零概率，又保持了概率和为 1 的归一化性质：对类别 c 的某个属性，修正后各取值概率之和仍为 1。代入本例（演示计算）：舌象有 4 种取值，P(风寒证) 修正为 (18+1)/(40+2) = 19/42 ≈ 0.452；"脉浮紧"在风热证中从未出现，修正为 (0+1)/(22+4) = 1/26 ≈ 0.038，而不是 0。训练样本越少，拉普拉斯修正的影响越显著；样本充足时，修正项趋于可忽略。 一个常被讨论的现象是：属性条件独立假设在现实中几乎从不成立——例如舌象与脉象、恶寒与发热等四诊属性之间明明存在相关性——但朴素贝叶斯依然稳健高效，在许多任务上性能出人意料地好。其解释大致有三：其一，分类只关心各类别后验的相对大小，独立性假设造成的估计偏差在各类别间常常相互抵消，排序关系得以保持；其二，朴素贝叶斯需要估计的参数极少（每个属性每个类别一两个统计量），方差小，不易过拟合，在样本量有限时往往优于更"正确"但方差更大的复杂模型；其三，许多任务中属性间确实近似独立。朴素贝叶斯因此成为文本分类（词袋模型下每个词的出现与否作为属性）、垃圾邮件过滤、情感分析等场景的经典基线，配合 TF-IDF 等特征工程可以取得相当好的效果，且训练只需一遍扫描数据，代价极低。 计算层面还有一个工程细节：当属性维数 d 很大时，连乘 ΠP(xᵢ|c) 的值会指数级缩小，极易下溢为浮点零。标准做法是把判定准则取对数：h_nb(x) = argmax_c [log P(c) + Σᵢ log P(xᵢ|c)]，把乘法变为加法，数值稳定且不改变 argmax 的结果，这也是 sklearn 等库内部的实际实现方式。朴素贝叶斯在文本分类中的典型用法是词袋模型：把每篇文档表示为一个高维稀疏向量，第 i 维指示或计数词典中第 i 个词的出现情况，类别为文档主题；此时属性维数常达数万，但每篇文档只含其中极少词，稀疏性让频数统计依然廉价，而"每个词在给定主题下独立"的假设虽在词义层面不成立，在判别层面却足够好用，配合 TF-IDF 加权与加一平滑（拉普拉斯修正 α=1）即可构成高效的多分类文本基线。值得一提的是，朴素贝叶斯是生成式模型的代表：它显式建模了 P(x|c)，因此还支持生成任务（按类条件分布采样合成样本）与缺失属性推理，这是判别式模型不具备的能力。本节要点：朴素贝叶斯以属性条件独立假设 P(x|c) = ΠP(xᵢ|c) 将高维联合分布估计分解为一维统计，判定准则为 h_nb(x) = argmax P(c)·ΠP(xᵢ|c)；离散属性用频数、连续属性用高斯密度估计；拉普拉斯修正 (|D_{c,xᵢ}|+1)/(|D_c|+Nᵢ) 消除零概率并保持归一化；尽管假设常不成立，朴素贝叶斯仍以低方差、高效率成为文本分类等任务的经典基线。

## 7.4 半朴素贝叶斯

朴素贝叶斯的属性条件独立假设虽然有效，但在属性间存在明显依赖时过于"朴素"，会引入系统性偏差。完全放弃独立性假设又回到 7.1 节指出的高维估计困境。半朴素贝叶斯分类器（Semi-Naive Bayes classifiers）在两者之间取折中：允许每个属性最多依赖一个其他属性，称为独依赖估计（One-Dependent Estimator，ODE），其一般形式为 P(c|x) ∝ P(c)·Π_{i=1}^{d} P(xᵢ|c, xⱼ)，即把朴素贝叶斯中的 P(xᵢ|c) 换成给定类别与另一个属性 xⱼ 的条件概率。问题的关键变成"每个属性应该依赖哪个属性"，不同的选择策略产生了不同的代表方法。 SPODE（Super-Parent ODE，超父独依赖估计）是最简单的方案：假设所有属性都依赖同一个"超父"（super-parent）属性 x_p，即 P(c|x) ∝ P(c)·Π_{i=1}^{d} P(xᵢ|c, x_p)。超父的选择可通过交叉验证、模型选择或似然比较来确定，一旦选定，估计 P(xᵢ|c, x_p) 只需在 (类别, 超父取值) 分组的样本上做一维统计，代价依然很低。用一个数字例子说明 SPODE 的计算（演示数值）：仍用感冒证候数据集，测试样例同 7.3 节（恶寒=重，汗出=无，脉象=浮紧，舌象=淡红苔薄白，发热=轻，咽部=不红），选取"脉象"为超父。对风寒证：P(风寒证) = 18/40，P(脉象=浮紧|风寒证) = 12/18；风寒证中脉浮紧的样本共 12 份，其中 P(恶寒=重|风寒证,浮紧) = 8/12，P(汗出=无|风寒证,浮紧) = 9/12，P(舌象=淡红苔薄白|风寒证,浮紧) = 10/12，P(发热=轻|风寒证,浮紧) = 7/12，P(咽部=不红|风寒证,浮紧) = 9/12，乘积得 (18/40)×(12/18)×(8/12)×(9/12)×(10/12)×(7/12)×(9/12) ≈ 0.0128。对风热证：P(风热证) = 22/40，P(脉象=浮紧|风热证) = 2/22；风热证中脉浮紧的样本仅 2 份，其中恶寒=重、汗出=无、舌象=淡红苔薄白、发热=轻、咽部=不红各占比例很小，乘积远小于风寒证得分。风寒证得分明显更高，仍判为风寒证，与朴素贝叶斯结论一致。注意此处若某个 (类别, 超父取值, 属性值) 组合在训练集中缺失，同样会产生零概率，需像 7.3 节那样施加拉普拉斯修正。 TAN（Tree Augmented Naive Bayes，树增强朴素贝叶斯）进一步利用数据自动确定依赖结构：它以属性为节点，用条件互信息 I(xᵢ, xⱼ|c) = Σ_{xᵢ, xⱼ, c} P(xᵢ, xⱼ, c)·log[P(xᵢ, xⱼ|c) / (P(xᵢ|c)·P(xⱼ|c))] 度量给定类别下两个属性的依赖强度，然后以条件互信息为边权，用最大带权生成树算法（Maximum Weight Spanning Tree，如 Prim 算法）在属性图上构造一棵树，每个属性只依赖其树中的父节点，类别节点则与所有属性相连。TAN 的结构由数据驱动，比固定超父的 SPODE 更贴合真实依赖关系，同时保证任意两属性间最多存在一条依赖路径，参数规模仍在可控范围。 AODE（Averaged One-Dependent Estimator，平均独依赖估计）走的是"模型平均"路线：它不挑一个超父，而是对每个满足条件的属性 xᵢ 都建立一个以它为超父的 SPODE，再对所有这样的模型取平均：P(c|x) ∝ Σ_{i=1, |D_{xᵢ}| ≥ m′}^{d} P(c, xᵢ)·Π_{j=1}^{d} P(xⱼ|c, xᵢ)，其中求和只对训练集中取值 xᵢ 的样本数不少于阈值 m′（通常取 30）的属性进行，以保证估计可靠；联合概率 P(c, xᵢ) 与条件概率 P(xⱼ|c, xᵢ) 同样施加拉普拉斯修正：P(c, xᵢ) = (|D_{c,xᵢ}| + 1)/(|D| + N·Nᵢ)，P(xⱼ|c, xᵢ) = (|D_{c,xᵢ,xⱼ}| + 1)/(|D_{c,xᵢ}| + Nⱼ)。AODE 以集成平均的方式降低单个超父选择不当的风险，无需模型选择即可直接使用，训练开销仍然可控，经验性能常优于朴素贝叶斯与 SPODE。三种方法构成一条递进的谱系：SPODE 结构最简单、计算最省；TAN 用条件互信息做结构搜索，更贴合数据；AODE 不做选择而做平均，以集成换取稳健。选择哪一档，取决于样本量、属性维度与对可解释性的要求——样本越少越应倾向简单模型，属性依赖越强越值得引入结构。 半朴素贝叶斯并非免费午餐：把 P(xᵢ|c) 换成 P(xᵢ|c, xⱼ) 后，每个条件概率需要在（类别, 依赖属性取值）的分组样本上统计，分组数成倍增加，对样本量的需求也随之上升——这正是 AODE 设置 m′ 阈值、各方法普遍施加拉普拉斯修正的原因。实践中选择哪一档模型可遵循如下经验：样本量小（数百级）时优先朴素贝叶斯，其低方差优势明显；样本量中等且属性间存在可辨识的强依赖时，SPODE 或 AODE 以极小的额外代价带来稳健提升；样本量充足且依赖结构复杂时，TAN 的结构搜索更有价值；而更一般化的依赖结构则超出"独依赖"的范畴，应交由 7.5 节贝叶斯网处理。此外，半朴素贝叶斯与贝叶斯网都以"条件独立性的局部放宽"为出发点，区别仅在于结构是手工假定（SPODE/AODE）还是从数据中学习（TAN/贝叶斯网），理解这一谱系有助于把握整个贝叶斯分类器的设计空间。本节要点：半朴素贝叶斯放松完全独立假设，允许每个属性最多依赖一个其他属性（独依赖估计 ODE），在估计可行性与表达力之间折中；SPODE 让所有属性共享一个超父，TAN 用条件互信息与最大带权生成树构造依赖树，AODE 对所有候选超父的 SPODE 取平均并施加拉普拉斯修正，三者递进，各有适用场景。

## 7.5 贝叶斯网

半朴素贝叶斯只允许每个属性依赖一个其他属性，仍是对真实依赖结构的粗糙近似。贝叶斯网（Bayesian network），又称信念网（belief network），用有向无环图（Directed Acyclic Graph，DAG）与条件概率表（Conditional Probability Table，CPT）的组合，显式地刻画变量之间任意复杂的依赖与独立关系。一个贝叶斯网 B = ⟨G, Θ⟩ 由两部分构成：结构 G 是一个 DAG，节点对应属性或随机变量，有向边表示依赖关系——若存在边 X→Y，则 X 是 Y 的父节点，表示 X 直接影响 Y；参数 Θ 为每个节点附一张条件概率表，记录该节点在其父节点各种取值组合下的条件概率 P(节点|父节点)，量化依赖的强度。贝叶斯网定义了属性集上的联合概率分布：P(x₁, x₂, …, x_d) = Π_{i=1}^{d} P(xᵢ | πᵢ)，其中 πᵢ 为节点 xᵢ 的父节点集合。可见，给定结构后，联合分布被分解为每个节点一个局部条件分布之积，参数总数从指数级降为各节点参数之和，这正是贝叶斯网能处理高维问题的根源。 贝叶斯网的核心价值在于用图的结构直接编码条件独立性。三类基本结构决定了独立性的三种典型模式。其一为同父结构（common parent）：X→Y 且 X→Z，给定父节点 X 后，Y 与 Z 条件独立，即 P(Y, Z|X) = P(Y|X)·P(Z|X)，因为 Y 与 Z 的信息全部经由 X 传递。其二为顺序结构（chain）：X→Y→Z，给定中间变量 Y 后，两端变量 X 与 Z 条件独立，即 P(X, Z|Y) = P(X|Y)·P(Z|Y)。其三为 V 型结构（V-structure），又称冲撞结构（collider）：X→Y←Z，此时 X 与 Z 在边际上独立（两者之间没有通路），但给定冲撞节点 Y 之后，X 与 Z 反而产生依赖——这是因果推断中"解释"（explaining away）效应的来源：例如"下雨"与"洒水器"都会导致"地面湿"，若已知地面湿且没有下雨，则更可能是洒水器所致。可见"给定某变量"在三种结构中的效果截然不同，这正是 D-分离（D-separation）准则要系统回答的问题。 D-分离给出了从有向图上读出条件独立性的判读准则：给定变量集 Z，若变量 X 与 Y 之间的所有路径都被 Z 阻断，则称 X 与 Y 被 Z D-分离，此时在 Z 条件下 X 与 Y 条件独立。一条路径被 Z 阻断的条件是：路径上存在一个中间节点被 Z 观测到（对应同父或顺序结构中被给定的节点），或者路径上存在一个冲撞节点未被 Z 观测且其所有后代也均未被 Z 观测。例如在"下雨→地面湿→路滑"这一顺序结构上，给定"地面湿"后，"下雨"与"路滑"之间的唯一路径被阻断，二者条件独立；而在"下雨→地面湿←洒水"的 V 型结构上，若"地面湿"未被观测，"下雨"与"洒水"边际独立，一旦观测到"地面湿"（或其下游变量，如某人滑倒），二者就变得相关。D-分离把概率论的独立性检验转化为图上的路径检查，是贝叶斯网推断与分析的基础工具；把 DAG 中每条有向边替换为无向边并对 V 型结构两两连边得到道德图（moral graph）后，D-分离还可转化为无向图上的分离性来判定。 贝叶斯网的学习分为结构学习与参数学习两步。结构学习的目标是从数据中确定 DAG，常用方法是"评分+搜索"：定义评分函数衡量网络结构与训练数据的匹配程度，典型的有 AIC（Akaike Information Criterion）、BIC（Bayesian Information Criterion）与 MDL（Minimum Description Length，最小描述长度）。评分函数的一般形式为 s(B|D) = LL(B|D) − κ·|B|，其中 LL(B|D) 是网络的对数似然（反映拟合程度），|B| 是网络的参数个数（反映复杂度），κ 是惩罚系数：κ = 1 对应 AIC，κ = (log m)/2（m 为样本数）对应 BIC，MDL 则把"编码长度"作为复杂度度量。评分函数在"拟合得好"与"结构简单"之间权衡，防止学出过度复杂的网络；随后用贪婪搜索、爬山法（hill climbing）等启发式策略在结构空间中逐步增删边、调整方向，寻找评分最高的结构。需要注意，不同的 DAG 可能编码相同的条件独立关系（如 X→Y→Z 与 X←Y←Z），它们构成等价类，评分无法区分等价类内的结构，因果方向还需领域知识或干预实验确定。参数学习在结构确定后进行：对每个节点，用训练数据按极大似然估计其条件概率表，即统计各类父节点取值组合下的频数；与朴素贝叶斯类似，样本不足时同样施加拉普拉斯修正以保证 CPT 中不出现零概率。 推断（inference）是根据已观测证据计算目标变量的后验概率，是贝叶斯网的最终用途。精确推断的代表是变量消去（variable elimination）算法：按一定顺序逐个求和消去非目标变量，把复杂的联合分布求值化为一系列局部乘积求和，其计算代价随网络结构（树宽）指数增长，在最坏情况下是 NP 难题；对树形网络可用信念传播（belief propagation）在节点间传递消息，只需线性时间。当网络规模大、结构复杂时，常改用近似推断，其中吉布斯采样（Gibbs sampling）是代表性方法：从一个初始赋值出发，每次只按条件分布重采样一个变量的取值，迭代足够多轮后，样本的统计频率近似等于目标后验分布，这是一种马尔可夫链蒙特卡罗（MCMC）方法。贝叶斯网可表达因果关系、支持先验知识注入、天然处理缺失数据，是医疗诊断、故障排查、基因调控网络分析等领域的核心概率图模型。值得一提的是，朴素贝叶斯本身就是一个特殊的贝叶斯网：类别节点指向所有属性节点、属性之间无边，即"星形"结构。 贝叶斯网在现实中的应用可追溯到专家系统时代：如著名的病理学诊断系统 PATHFINDER 曾用贝叶斯网在数百种疾病之间做概率推理，帮助病理医生在显微镜观察的基础上给出鉴别诊断建议。医疗场景尤其契合贝叶斯网，因为疾病、症状、检查结果之间的因果关系天然是有向的，且临床知识（如"心肌梗死可导致胸痛"）可以直接编码为网络结构与先验参数，有效缓解小样本问题；当证据不完整或相互矛盾时，贝叶斯网还能在保持概率一致性的前提下给出所有候选诊断的后验排名。在 tcmP 中，这一思想被移植为证候因果知识图谱（见 part2 P2.4）：病→证→法→方→药的因果链、ICD-11 术语对齐与 D-分离教学推断，正是贝叶斯网方法论在中医学情境下的具体化。工程上还需注意：当变量多、证据复杂时精确推断代价高，需借助吉布斯采样等近似推断或对图结构做稀疏化来保证响应时间，这正是 7.5 节推断部分讨论的现实意义。本节要点：贝叶斯网用 DAG+CPT 显式建模变量依赖，联合分布分解为 P(x₁,…,x_d) = ΠP(xᵢ|πᵢ)；同父、顺序、V 型三种基本结构决定了条件独立性的三种模式，D-分离准则据此在图上直接判定独立性；结构学习用评分函数（AIC/BIC/MDL）配合贪婪搜索，参数学习用极大似然加拉普拉斯修正；推断可用变量消去等精确算法或吉布斯采样等近似算法。

## 7.6 EM算法

前几节的参数估计都假设所有变量可观测，但现实中常存在隐变量（latent variable），即未被观测到的变量：混合高斯模型中每个样本来自哪个高斯分量未知；隐马尔可夫模型中隐状态序列未知；临床数据中部分检查结果缺失。此时直接做极大似然估计会遇到本质困难。以混合高斯模型（GMM）为例，样本由 K 个高斯分量按比例混合生成，每个样本 x 对应的分量标记 z ∈ {1, …, K} 是隐变量，完整数据为 (x, z)。对数似然为 LL(θ) = Σ_{i} log P(xᵢ; θ) = Σ_{i} log Σ_{z} P(xᵢ, z; θ)。问题在于：对隐变量的求和位于对数函数内部，导致对数里是混合分布，无法像 7.2 节那样通过对数把乘积化为求和再求导，直接求导得到的方程通常没有解析解。 EM 算法（Expectation-Maximization algorithm）通过迭代巧妙地绕开这一困难。它维护当前参数 θ^t，每轮迭代包含两步。E 步（Expectation，期望步）：以当前参数 θ^t 计算隐变量 z 的后验分布 P(z|x, θ^t)（即每个样本属于各分量的"责任"），并据此构造 Q 函数——完整数据对数似然在隐变量后验分布下的期望：Q(θ|θ^t) = Σ_{z} P(z|x, θ^t)·log P(x, z; θ) = E_{z|x, θ^t}[log P(x, z; θ)]。M 步（Maximization，最大化步）：最大化 Q 函数得到新参数 θ^{t+1} = argmax_θ Q(θ|θ^t)。两步交替进行，直至参数或似然的变化小于阈值即收敛。直观理解：E 步相当于在"隐变量取值未知"的情况下，用当前模型猜测隐变量的概率分布，把不完全数据"补全"为软划分；M 步则基于补全后的完整数据做一次普通的最大似然更新。由于 Q 函数的结构与完整数据的似然一致，M 步往往有闭式解，例如 GMM 中新的分量均值就是各样本按责任加权的均值。 EM 的收敛性有理论保证。利用琴生不等式（Jensen's inequality）对对数函数的凹性做放缩，可以证明每一轮迭代后对数似然单调不减：LL(θ^{t+1}) ≥ LL(θ^t)。因此 EM 必定收敛。但要注意两点：其一，单调性只能保证收敛到似然函数的局部最优（stationary point），无法保证全局最优；其二，收敛结果对初值 θ⁰ 敏感，不同的初值可能收敛到不同的局部最优。实践中通常采用多次随机初始化、分别运行 EM、保留对数似然最大（或验证集上表现最好）的结果；也可用 k-means 聚类结果作为 GMM 初值，既加速收敛又减少陷入差局部最优的可能。 用一个小规模数字例子演示一轮 E/M 迭代（演示数值）。设一维混合高斯模型，两个分量方差均为 σ² = 1，初始参数 α₁ = α₂ = 0.5，μ₁ = 0，μ₂ = 4；观测数据为 x = (1, 2, 5) 三个点。E 步：计算每个点属于分量 1 的责任 γᵢ = α₁·N(xᵢ; μ₁, 1) / [α₁·N(xᵢ; μ₁, 1) + α₂·N(xᵢ; μ₂, 1)]。正态密度 N(1; 0, 1) ≈ 0.2420、N(1; 4, 1) ≈ 0.0044，得 γ₁ ≈ 0.982；N(2; 0, 1) = N(2; 4, 1) ≈ 0.0540，得 γ₂ = 0.5；N(5; 0, 1) ≈ 1.49×10⁻⁶、N(5; 4, 1) ≈ 0.2420，得 γ₃ ≈ 0.000006。M 步：α₁′ = Σγᵢ/3 ≈ 0.494（α₂′ ≈ 0.506）；μ₁′ = Σγᵢxᵢ/Σγᵢ ≈ (0.982×1 + 0.5×2 + 0.000006×5)/1.482 ≈ 1.337；μ₂′ = Σ(1−γᵢ)xᵢ/Σ(1−γᵢ) ≈ 6.018/1.518 ≈ 3.964；σ₁²′ = Σγᵢ(xᵢ−μ₁′)²/Σγᵢ ≈ 0.331/1.482 ≈ 0.224，σ₂²′ ≈ 3.159/1.518 ≈ 2.081。一轮迭代后，分量 1 向观测点靠拢（μ 从 0 移到 1.337），对数似然从初始的约 −7.13 提升到约 −4.86，直观印证了"每轮似然单调上升"。继续迭代，参数与似然将趋于稳定，最终收敛到（局部）最优。 EM 算法的应用远不止混合高斯。它是隐马尔可夫模型（HMM）参数估计（Baum-Welch 算法）的核心，也是处理缺失数据（missing data）的标准工具：把缺失变量视为隐变量，E 步用当前模型推断缺失值的期望分布，M 步用"补全"后的完整数据重估参数。EM 的思想还被推广为广义 EM（GEM，M 步只要求似然不下降）与变分推断（variational inference，当后验难以精确计算时用近似分布逼近），后者是大规模概率图模型学习的常用手段。从方法谱系看：无隐变量时 EM 退化为普通 MLE；有隐变量时，EM 通过"E 步补隐变量、M 步更新参数"的交替，把难解的最大化问题转化为一串易解的更新，是含隐变量统计推断最经典的算法。 工程实践中使用 EM 还有几个要点。其一，收敛判据通常取参数变化量或对数似然增量小于阈值 ε（如 10⁻⁶），而非运行固定轮数；对似然增量设阈值这一做法正源于"对数似然单调不减"的理论保证。其二，混合模型的分量数 K 不是 EM 直接给出的，需通过模型选择确定：常用 BIC 评分在不同 K 下比较（K 越大拟合越好但参数越多，BIC 的惩罚项 (log m)/2·|B| 平衡两者），也可结合领域知识设定。其三，初始化策略对结果影响显著：除多次随机初始化外，先用 k-means 把样本粗划分、以各簇均值为初始 μ 是常见做法，能大幅减少 EM 迭代次数并降低陷入差局部最优的概率。其四，当隐变量的后验难以解析计算时（如复杂图模型），EM 的 E 步本身需要近似，此时"E 步近似 + M 步精确"的变体与变分推断（用可分解的近似分布 q(z) 逼近真实后验）成为更通用的工具，它们与 EM 一脉相承，都是"以迭代方式处理隐变量"这一思想的延伸。本节要点：EM 算法求解含隐变量的极大似然问题，E 步以当前参数计算隐变量后验并构造 Q 函数 Q(θ|θ^t) = E_{z|x,θ^t}[log P(x, z; θ)]，M 步最大化 Q 函数更新参数；由琴生不等式保证对数似然单调不减，但只收敛到局部最优，需多次随机初始化；EM 是 GMM、HMM 与缺失数据处理的标准工具。

## 7.7 本章小结

本章围绕"用概率描述与消解不确定性"这一主题展开，给出了从理论到算法的完整贝叶斯分类图景。7.1 节贝叶斯决策论确立了分类的黄金标准：引入损失 λᵢⱼ 与条件风险 R(c|x) = Σⱼλᵢⱼ·P(cⱼ|x)，在 0-1 损失下最小化风险等价于最大化后验概率，得到贝叶斯最优分类器 h*(x) = argmax_c P(c|x)，其贝叶斯误差率是任何分类器不可超越的理论下界，从而把学习的任务归结为估计 P(c|x)。围绕"如何估计类条件概率"这一难点，本章给出了一条层层递进的求解路线：7.2 节极大似然估计假设 P(x|c) 具有确定的分布形式，用对数似然 LL(θ_c) = Σ log P(xᵢ|θ_c) 估计参数，正态分布下得到样本均值与样本方差；7.3 节朴素贝叶斯以属性条件独立假设 P(x|c) = ΠP(xᵢ|c) 把高维联合分布分解为一维统计，配合拉普拉斯修正消除零概率，简单而稳健，四诊辨证例展示了从频数到判决的完整计算；7.4 节半朴素贝叶斯放松完全独立假设，以独依赖估计（SPODE/TAN/AODE）在可行性与表达力之间折中；7.5 节贝叶斯网用 DAG+CPT 显式建模任意依赖结构，D-分离准则在图上直接判定条件独立性，学习分为评分搜索式的结构学习与极大似然式的参数学习，推断有变量消去与吉布斯采样等算法；7.6 节 EM 算法以 E/M 两步迭代求解含隐变量的似然最大化，对数似然单调不减保证收敛，但需警惕局部最优。这六节形成一个自洽的整体：贝叶斯决策论给出目标，极大似然给出参数估计工具，朴素贝叶斯、半朴素贝叶斯、贝叶斯网依次以越来越精细的结构逼近真实的类条件概率，EM 则补齐了隐变量场景。 贝叶斯框架还有两个贯穿全章的优势。其一是天然支持先验知识注入：先验概率 P(c) 可以来自数据频率，也可以来自领域知识或历史经验，7.2 节的 MAP 估计、7.5 节贝叶斯网的 CPT 都是先验发挥作用的载体。其二是天然支持增量学习：贝叶斯公式把学习过程视为信念的更新——新样本到来后，把当前后验 P(c|x) 作为下一次推断的新先验，即可在无需重训全部数据的情况下持续吸收新信息，这与人类"经验越丰富判断越准"的认知过程高度一致。理解了这一点，就理解了贝叶斯方法"以概率衡量不确定性、以数据更新信念"的方法论精髓。下一章起将进入集成学习，通过组合多个学习器进一步提升性能；而本章的概率分类思想将在 part2 落地为 tcmP 平台的贝叶斯辨证推理、先验双轨注入与证候因果知识图谱，构成"从概率基础到平台应用"的完整闭环。把本章的关键公式串成一条线便于复习：贝叶斯公式 P(c|x) = P(c)P(x|c)/P(x) 是总纲；0-1 损失下最优决策 h*(x) = argmax_c P(c|x)；为估计 P(x|c)，7.2 节用对数似然 LL(θ_c) = Σ log P(xᵢ|θ_c) 求参数（正态假设下即样本均值与样本方差）；7.3 节在独立性假设下 h_nb(x) = argmax_c P(c)·ΠP(xᵢ|c)，配拉普拉斯修正 P(xᵢ|c) = (|D_{c,xᵢ}|+1)/(|D_c|+Nᵢ)；7.4 节给出独依赖形式 P(c|x) ∝ P(c)·ΠP(xᵢ|c, xⱼ) 与 AODE 的集成平均；7.5 节以联合分布分解 P(x₁,…,x_d) = ΠP(xᵢ|πᵢ) 与评分函数 s(B|D) = LL(B|D) − κ|B| 支撑贝叶斯网的学习；7.6 节以 Q 函数 Q(θ|θ^t) = E_{z|x,θ^t}[log P(x, z; θ)] 完成隐变量情形下的参数估计。建议学习路径：先吃透 7.1-7.3（决策准则、参数估计、独立性假设三件套），再做 7.4-7.6（结构放松、显式建模、隐变量推断）的进阶，最后回到 7.1 体会"估计 P(c|x)"这一主线如何贯穿始终——每一节的模型与方法，都是对这条主线某一环节的补全。
