## H.1 本章要解决的问题

中医文本标注的难点不在标不标得动，而在两个人能不能标得一样。同一段「乏力、纳差、舌淡」，有人标脾气虚，有人标气血两虚，第三个人干脆两个都标；边界不清，模型学到的就是标注者的个人偏好，而不是医学规律。这一章要交付的不是一个表格文件，而是规范、一致性证据、按患者划分的清单与数据卡四件套。

## H.2 本章目标（可检验）

- 写出可执行的标注规范：定义、正例、负例、边界例、仲裁规则
- 用双人盲标算一致性系数并处理分歧，把裁定写回规范
- 产出带版本号、数据卡与按患者划分清单的数据快照

## H.3 操作流程

1. 定标注单元：一条记录标一个标签还是标若干片段，单元边界写清（整段、句、实体跨度），跨句症状是否合并成一条要有规则
2. 定标签体系：标签数控制在三到八个，每个给定义、纳入标准、排除标准，并注明教材或指南出处
3. 写正例负例：每个标签至少两正两负，取自真实文本并脱敏；负例要包含「字面相似但语义不同」的那类
4. 写边界例：专门收集「像但不算」的样本，逐条说明为何排除；这一节决定一致性的上限，比定义更重要
5. 写规范版本：从 v0.1 起，每次修订记改动条目、影响范围与生效日期；旧标签不覆盖，另存
6. 预标：两名标注者独立盲标同一批三十到五十条，互不可见对方结果，工具上关闭对方标注的显示
7. 算一致性：两分类用 Cohen's κ，多标注者或用多标签时用 Fleiss' κ 或 Krippendorff'α，同时报点估计与置信区间
8. 定门槛：κ 低于 0.6 视为规范不可用，回到边界例重写；0.6 到 0.8 可接受但须在数据卡里写明，不得只报百分比一致率
9. 裁分歧：逐条讨论，由仲裁人裁定，裁定理由写回规范而不是只改那一条标签；同一类分歧出现三次以上必须改定义
10. 全标与抽检：按定稿规范标注，抽检不低于百分之十，由未参与标注者执行；抽检不一致率超过阈值整批返工
11. 做划分：按患者号或就诊号分组切分，同一患者不得跨集；时间跨度大的数据按时间切，固定随机种子并记入划分清单
12. 出卡与快照：数据卡写来源、时间跨度、规模、标签分布、已知偏差、许可；数据文件冻结为只读快照并记哈希

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 标注单元边界已定义，跨句规则已写
- [ ] 标签三到八个，各有纳入排除标准与出处
- [ ] 每标签至少两正例、两负例
- [ ] 边界例已收集并说明排除理由
- [ ] 规范有版本号与修订记录
- [ ] 双人盲标三十到五十条，互不可见
- [ ] 一致性系数与置信区间均已报
- [ ] 门槛与处置规则事先写定
- [ ] 分歧经仲裁并写回规范
- [ ] 全标抽检不低于一成，返工规则明确
- [ ] 按患者分组切分，无跨集样本
- [ ] 数据卡与快照哈希已完成

## H.5 模板：标注规范与数据卡

| 字段 | 填写要求 |
|------|----------|
| 标注单元 | 整段/句/实体跨度，起止如何界定，跨句如何合并 |
| 标签体系 | 名称、定义、纳入、排除、出处 |
| 示例 | 每标签正例二、负例二、边界例一，附编号 |
| 仲裁 | 仲裁人、裁定流程、写回规范的方式 |
| 一致性 | 系数类型、样本量、点估计、置信区间、门槛 |
| 抽检 | 比例、抽检人、不合格处置 |
| 划分 | 按患者或时间切分、随机种子、各集规模 |
| 数据卡 | 来源、时间跨度、标签分布、已知偏差、许可 |
| 版本 | 规范版本、快照版本、哈希、日期 |

> 本表是本章的交付物：规范随标注工具下发，数据卡随数据集发布；两者版本号必须一一对应。

## H.6 常见失效与处置

- **只写定义不写边界** → 边界例才是一致性的关键；没有边界例，κ 上不去也解释不了
- **先标后定规范** → 标注者各自形成习惯，后期无法统一，只能整批重标
- **用一致率代替一致性** → 两人都标「无」也能九成一致；类别不平衡须用 κ
- **不报置信区间** → 小样本 κ 波动很大，单点数值撑不起「标注可靠」的结论
- **按样本随机切分** → 同一患者多次就诊跨集，指标虚高，是最常见的致命伤
- **数据卡不写偏差** → 标签分布倾斜、科室单一被隐藏，使用者误判适用范围
