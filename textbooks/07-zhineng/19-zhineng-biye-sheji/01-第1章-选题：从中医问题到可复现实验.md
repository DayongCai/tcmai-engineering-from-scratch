## H.1 本章要解决的问题

「用大模型做中医问答」是方向不是命题：答什么、怎么判对错、跟谁比，都没有定义，十周之后只能交出一批截图和一段观感。开题要交的是四件东西：一条能被否证的命题、一套算得出分数的评测集、一个必须打败的基线、一份写明不做什么的清单。四件缺一件，答辩问的第一句就是「你凭什么说它变好了，又凭什么说这个数能重复」。

## H.2 本章目标（可检验）

- 把中医业务问题收敛成单一任务，并把输入输出格式写死
- 定出金标准来源、标注人资质与规模，说明判定规则
- 选定可复现基线并对齐对照，把算力与标注工时折算成十周排期

## H.3 操作流程

1. 定任务：在分类（证型、方剂归类）、信息抽取（症状—证—方—药）、生成（按证候出方解）、检索（条文溯源）四类中只选一类，写清选它的理由与放弃其余的理由
2. 定输入输出：一段门诊记录对应一个结构化输出，字段名、类型、缺省值、允许取值全部写死；格式不合规直接判错，不参与打分
3. 定判定：分类用宏平均 F1，抽取用字段级精确匹配，生成用「关键要素覆盖率 + 人工可接受度」双评，检索用命中率@k；口径写进开题表
4. 定金标准：说明来自真实病历、教材条文还是专家共识，写清出处、脱敏方式与使用许可；三者缺一，数据不能用
5. 定规模：每类至少五十条、总量不少于三百条，先用小样本试标确认可行性，再定正式标注量
6. 定标注人：至少两名具备中医执业或规培背景者，写清培训方式、标注工具与仲裁人；学生本人不得既当标注者又当评测者
7. 定基线：规则或关键词法、公开模型零样本、小样本微调三档中至少选两档，同数据、同指标、同评测脚本
8. 定对照：找一篇同类任务的公开工作，记下它的数据规模与切分方式；不可直接比较时说明差异，不许把自己的数直接塞进别人的表
9. 核资源：GPU 型号与可用时长、API 预算、标注人力工时，折算成每周任务量，标出关键路径
10. 砍范围：单任务、单科室、单数据源；把「还想做」的逐条列进不做清单并写理由
11. 写风险：数据拿不到、标注不一致、算力不足各写一条替代方案，注明触发条件
12. 成稿：填开题命题表，请导师与一位临床老师各提一条反对意见，逐条写下回应与修改

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 任务类型唯一，且有取舍理由
- [ ] 输入输出字段、类型、取值域已写死
- [ ] 判错规则明确，格式不合规即判错
- [ ] 指标与任务匹配，口径已写清
- [ ] 金标准出处、脱敏、许可三项齐全
- [ ] 测试集规模与每类下限已定
- [ ] 标注人资质与仲裁人已定
- [ ] 基线至少两档，同数据同指标
- [ ] 对照工作及其切分差异已记
- [ ] 算力、预算、工时已折算成排期
- [ ] 不做清单已写并说明理由
- [ ] 两条反对意见及回应已记录

## H.5 模板：开题命题表（智能）

| 字段 | 填写要求 |
|------|----------|
| 任务 | 类别（分类/抽取/生成/检索）、输入形态、输出结构与字段取值域 |
| 判定 | 何谓正确、何谓部分正确、格式错误如何处理 |
| 指标 | 主指标一个、辅助指标两三个，各自计算口径与阈值 |
| 金标准 | 来源、脱敏方式、使用许可、标注人资质与仲裁人 |
| 规模 | 总量、每类下限、训练/验证/测试比例 |
| 基线 | 规则法、零样本、微调；同数据同脚本 |
| 对照 | 文献公开结果及其数据与切分差异 |
| 资源 | GPU 型号与时长、API 预算、标注工时 |
| 边界与风险 | 不做清单、三条风险与替代方案 |
| 签字 | 学生、导师、日期 |

## H.6 常见失效与处置

- **把方向当命题** → 「做一个中医大模型」无法判分；必须落到任务与输出格式
- **金标准由模型生成** → 自评自测，分数没有意义；金标准须人工标注并留仲裁记录
- **指标与任务错配** → 生成任务报准确率等于没评；口径要在开题时写死
- **测试集混入训练** → 同患者、同模板样本跨集会虚高；切分规则开题就定
- **标注量拍脑袋** → 每类不足五十条，置信区间宽到无法比较两个方法
- **范围不裁** → 多任务并行，十周里每个都做一半，涨点无法归因

## H.7 中期检查与答辩要点

- 命题可评测性（30%）
- 金标准可靠性（25%）
- 基线与对照设置（20%）
- 资源与排期可行性（15%）
- 预答辩回应质量（10%）
