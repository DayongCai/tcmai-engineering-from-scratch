## H.1 本章要解决的问题

AI 毕设最容易被问倒的两句是「你的测试集和训练集有没有重叠」和「这个涨点是不是调出来的」。论文不是把实验日志誊清，而是把任务、数据、方法、证据、边界串成一条外人可复核的链；答辩考的不是你做了多少组实验，而是能不能在一刻钟内说清这条链的每一环，以及哪一环最薄、薄到什么程度、你打算怎么补。

## H.2 本章目标（可检验）

- 写出五段结构完整、数值与归档运行逐一对得上的论文
- 准备一刻钟汇报与五类必答质疑的答案及证据位置
- 完成预答辩并按意见修改，保留修改对照

## H.3 操作流程

1. 定主线：一句话写清「在什么任务上、用什么方法、相对什么基线、提升了多少、付了什么代价」；全文围绕这句取舍
2. 对表：正文每个数字回溯到归档运行的指标文件，逐条打勾；不一致时以归档为准，不许反向改记录；某个数只存在于临时文件里的，先补归档再动笔
3. 定结构：摘要四句、引言（缺口与命题）、相关工作（定位而非罗列）、数据、方法、实验、误差与可解释、边界与局限、结论
4. 写数据章：金标准怎么来、一致性多少、怎么切分、有无泄漏，这章决定评委信不信后面的所有数；这一章写虚了，后面全部白写
5. 写方法章：模型、损失、超参、训练细节、评测脚本位置，写到他人可照做的程度；关键实现细节不许以「详见代码」带过
6. 写结果章：一表一结论；主表给均值加减标准差与运行次数，不挑最好那次；显著性用同一判据判定，不逐项挑口径
7. 写消融章：每个部件一行，掉分幅度与是否超过种子波动；并解释这个部件在中医语义上为什么该有用
8. 写误差章：挑两三个高发切片讲，附原文与输出，说明错在哪一类、能否通过规则补救
9. 写边界章：适用人群、病种、文本类型、语言风格逐条写，并写清越界后果；每条边界配一个可能被误用的例子，边界不是免责声明
10. 预设质疑：泄漏、调参、标注噪声、样本量、临床有效性五问，各写三句答案并标注证据位置
11. 试讲：至少两次，一次给同组、一次给非本方向老师；记录被问住的地方，回去补证据而不是回去改话术
12. 定稿归档：论文、代码、数据快照、模型卡四件同版本归档；预答辩意见与修改对照一并保存，目录命名与仓库约定一致

## H.5 模板：论文自检与答辩准备表

| 字段 | 填写要求 |
|------|----------|
| 主线 | 任务、方法、基线、增量、代价，一句话 |
| 数字对表 | 表号、数值、归档运行编号、是否一致 |
| 数据章 | 来源、一致性、切分方式、泄漏结论 |
| 方法章 | 模型、损失、超参、脚本位置 |
| 结果主表 | 指标、均值加减标准差、运行次数 |
| 消融 | 部件、掉分幅度、显著性、语义解释 |
| 误差 | 高发切片、典型例、归因 |
| 边界 | 适用人群与场景、越界后果 |
| 质疑与证据 | 五问的答案与证据位置 |

> 本表是本章的交付物：定稿前逐条自查，答辩前一天再核一遍；右栏现场记录追问。

## H.6 常见失效与处置

- **数值与记录不一致** → 评委抽一个数问出处，答不上即失信
- **回避失败实验** → 被问「试过什么没成」时如实说更可信；隐瞒会被追问出来
- **只报最好一次** → 种子敏感的方法不可用；须给波动
- **边界写成套话** → 「仅供参考」等于没写；要写人群、病种、文本类型
- **超时** → 一刻钟讲完主线与证据，细节留附录
- **不附数据卡与消融表** → 数据来源与增量归因都说不清

## H.7 中期检查与答辩要点

- 证据链与数值一致（30%）
- 数据与方法表述（25%）
- 消融与误差呈现（20%）
- 边界分寸（15%）
- 答辩表现（10%）
