## H.1 本章要解决的问题

模型错了不可怕，说不出为什么错才可怕。临床上要的不是一个总体分数，而是「这类病人它会不会错、错了医生能不能看出来」。误差分析要交付三样东西：错误的分层分布、典型失败案例的原文与模型输出、一句能写进说明书的可用边界；缺第三样，模型就只能停在实验里，谁也说不清它能在哪张桌子上用。

## H.2 本章目标（可检验）

- 对测试集全部错误（不少于三十例）逐例归因并分层
- 给出错误类型分布与高发人群、场景特征
- 用可解释性方法定位证据，并明确其不等于因果

## H.3 操作流程

1. 取错：测试集全部错误入表；错误过多时按类分层抽样，保证每个证型与科室都有案例，不许只挑好讲的；错误清单与模型原始输出一并冻结，后续修正不得覆盖
2. 设分层维度：证型、科室、文本长度、是否含方言或错别字、是否多病共存，至少四个维度，维度在取错前定
3. 归因四类：数据问题（缺失、噪声、伪影）、标注问题（错标、歧义）、模型问题（能力不足、过拟合）、任务定义问题（本就不该这么问）
4. 双人归因：两名标注者对同一批错误独立归因，算一致性；分歧条目交仲裁，归因表里保留两方原始判断
5. 统计分布：每类占比、每个维度的错误率，绝对数与比例同时报；只报比例会让小切片看起来比实际严重
6. 找高发切片：挑出错误率最高的两三个切片，写清其特征、样本量与对应的医学解释
7. 看置信度：比较错误与正确样本的置信度分布是否可分；不可分就说明置信度不能用于拒识，别在论文里许这个诺
8. 做解释：对典型例给出注意力权重、显著性图或检索证据片段，标明方法、参数与可视化范围，缺一项读者无法复核
9. 警惕误读：注意力高只说明模型看了那里，不说明因为那里；显著性图对输入扰动敏感；文中须写明「仅供核对，不作依据」
10. 反事实验证：改动一个关键要素（换一味药、去掉一个症状、颠倒主次症），看输出是否按预期变化；不变化说明模型没学到该学的
11. 写可用边界：医生可据此做什么（复核提示、候选排序、术语提醒）、不可做什么（直接下诊断、替代辨证），逐条写
12. 成文：填误差分析表，每个典型例附原文、模型输出、归因类别与证据位置；脱敏后再入附录，原件留在本地不随论文提交

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 错误样本不少于三十例且来源可溯
- [ ] 分层维度至少四个，取错前已定
- [ ] 四类归因均已使用
- [ ] 双人归因一致性已算并处理分歧
- [ ] 分布含绝对数与比例两栏
- [ ] 高发切片已识别并给出医学解释
- [ ] 置信度可分性已检验
- [ ] 解释方法与参数已写明
- [ ] 已声明解释不等于因果
- [ ] 反事实改动实验已做
- [ ] 可用与不可用边界已逐条写
- [ ] 典型例已脱敏后入附录

## H.5 模板：误差分析表

| 字段 | 填写要求 |
|------|----------|
| 样本 | 编号、输入摘要、金标准、模型输出 |
| 分层 | 证型、科室、长度、文本质量、合并症 |
| 归因 | 数据/标注/模型/定义，附判断依据 |
| 一致性 | 双人归因系数、分歧条目与裁定 |
| 分布 | 各类占比、各维度错误率 |
| 高发切片 | 切片定义、错误率、样本量、医学解释 |
| 置信度 | 错误与正确的分布、是否可分、能否拒识 |
| 解释 | 方法、参数、证据位置、局限声明 |
| 边界 | 可用于何处、不可用于何处 |

## H.6 常见失效与处置

- **只报总体准确率** → 掩盖某个证型的系统性失败；必须分层看
- **把标注错误算成模型错误** → 优化方向被带偏，越改越差
- **注意力图当因果** → 注意力高只说明看了那里，不说明因果
- **置信度未检验就用于拒识** → 错的时候也很自信，阈值形同虚设
- **可用性写成宣传语** → 「辅助医生决策」没有信息量；要写具体动作
- **典型例未脱敏** → 真实病历直接进论文，属合规问题

## H.7 中期检查与答辩要点

- 归因质量与一致性（30%）
- 分层与分布统计（25%）
- 可解释性使用规范（20%）
- 可用边界表述（15%）
- 案例呈现与合规（10%）
