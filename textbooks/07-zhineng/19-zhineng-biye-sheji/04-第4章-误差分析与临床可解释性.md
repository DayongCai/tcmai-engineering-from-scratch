## H.1 本章要解决的问题

模型错了不可怕，说不出为什么错才可怕。临床场景要求错误可归类、可解释。

## H.2 本章目标（可检验）

- 对≥20 例错误逐例归因
- 给出错误类型分布
- 说明模型输出对医生的可用性

## H.3 操作流程

1. 抽错：从测试集取全部错误或随机 20 例
2. 归类：数据、标注、模型、任务定义四类
3. 看分布：哪类占多数
4. 做解释：对典型例给出证据片段或置信度
5. 写可用性：医生能据此做什么、不能做什么

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 错误样本≥20 例
- [ ] 四类归因已用
- [ ] 分布已统计
- [ ] 典型例有原始文本与输出
- [ ] 解释方式已说明
- [ ] 可用与不可用边界已写
- [ ] 敏感信息已脱敏

## H.5 模板：误差分析表

| 字段 | 填写要求 |
|------|----------|
| 错误样本 | 编号与输入摘要 |
| 归因 | 数据/标注/模型/定义 |
| 分布 | 各类占比 |
| 典型例 | 原文与模型输出 |
| 可用边界 | 医生可用与不可用 |

## H.6 常见失效与处置

- **只写「准确率不够」** → 不归类无法改进
- **把标注错误算模型错** → 会误导后续优化方向
- **不谈可用性** → 临床落地时无人敢用

## H.7 中期检查与答辩要点

- 归因质量（40%）
- 分布统计（30%）
- 可用性表述（30%）
