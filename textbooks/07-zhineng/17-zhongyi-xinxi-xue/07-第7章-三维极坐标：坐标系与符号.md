## 7.1 坐标系定义

球 → 笛卡尔：**X = r·cosθ·cosφ，Y = r·cosθ·sinφ，Z = r·sinθ** 笛卡尔 → 球：**r = |v|，θ = arcsin(Z/r)，φ = atan2(Y, X)**

| 量 | 区间 | 含义 |
| --- | --- | --- |
| r | (0, 1] | 径向距离 = 语义张量尺度 |
| θ | [−90°, +90°] | 仰角（赤道 0，天顶 +90°，天底 −90°） |
| φ | [0°, 360°) | 方位角（自 +X 轴起算，绕 +Z 逆时针） |

## 7.2 两段三点 I / O / T

每个轴分两段：负值段 **I(−1) → O(0)**、正值段 **O(0) → T(+1)**；三点为 I 端点、O 原点、T 端点。**O 点三轴共有，基准色 = 绿 `#00B050`**。

## 7.3 球面基准线与母语下沉

赤道 = θ = 0（细虚线）；方位基准经线 φ = 0°/180°；阴阳界大圆 φ = 90°/270°。 **画布内不出现汉字**：球面只标 X/Y/Z、θ/φ 数字与圈号 ①②③，所有汉字母语下沉到图注。
