## H.1 本章要解决的问题

针灸方案最难交接的是手感：同一组穴位，深一分浅一分、捻转快慢不同，刺激量就不同。移交要把可写的写到极致——定位、角度、深度、频次、判据；把不可写的明确标出来并配带教，而不是假装都写清了。手册写完不算完，要有人按它做出来、偏差被记下来，才算完成一次移交；别人做出来的偏差能被你预先想到，手册才算合格。

## H.2 本章目标（可检验）

- 交出含定位图、进针参数与刺激量区间的方案手册
- 标出无法文字化的部分，给出带教时长与方式
- 由未参与研究者按手册复现三例，记录并修订偏差

## H.3 操作流程

1. 写手册主体：每穴的定位方法、参照点、进针角度与深度、得气标志、留针、疗程与频次，逐穴一节
2. 配图：每穴一张定位示意（体表标志加骨度分寸），标图号并与手册条目对应，不引用来源不明的图
3. 写刺激量：手法频率与幅度、电针波形频率电流、灸量，写成可核对的数值区间，不写「适度」「酌情」
4. 标不可写项：得气判断、手法力度、按体质调整的分寸，逐条标「须带教」，写明带教几例、由谁带、在哪几诊完成
5. 写合格判据：什么算操作合格（深度在标定区间、得气在三诊内出现、留针时长达标），供带教逐例打分并留记录
6. 做复现验证：请一位未参与本研究的同学按手册独立操作三例，记录穴位偏移、深度、留针时长与得气判断偏差
7. 按偏差修订：偏差集中的条目改写描述或补图，修订后做第二次验证，两版手册都留档
8. 交数据：原始 CRF、数据表、分析脚本、量表原件，一页写清路径、命名规则与复算入口
9. 交实物：剩余针具与灸材、量表纸质件、知情同意书归档位置、随访未完成名单
10. 列未完成项：没做完的随访、没验证的假设、没分析的亚组，按优先级排成下一步清单
11. 写结论摘要：三句话——已确认什么、不能确认什么、建议下一步先做什么
12. 签收：手册、数据、实物、未完成项四张清单由接手人与导师签字，归入教研室档案

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 手册逐穴一节，含定位、角度、深度、留针、频次
- [ ] 每穴有定位示意图，图号与条目对应
- [ ] 刺激量写成数值区间，无「适度」类表述
- [ ] 不可文字化部分逐条标注并附带教安排
- [ ] 操作合格判据可打分
- [ ] 复现验证三例，偏差逐项记录
- [ ] 按偏差修订并二次验证，两版留档
- [ ] 数据清单含路径、命名规则与复算入口
- [ ] 实物清单含针具、灸材、量表、知情同意书位置
- [ ] 未完成项按优先级排序，写清前置条件
- [ ] 结论摘要三句话写完
- [ ] 四张清单已签字归档

## H.5 模板：方案移交清单（针灸）

| 字段 | 填写要求 |
|------|----------|
| 方案手册 | 穴位、定位、角度、深度、留针、疗程、版本号 |
| 定位图 | 图号、对应穴位、绘制或拍摄来源 |
| 刺激量 | 手法、电针参数、灸量的数值区间 |
| 不可写部分 | 内容、带教例数与负责人 |
| 合格判据 | 深度、得气、留针的判定标准 |
| 复现验证 | 验证人、例数、偏差项与修订 |
| 数据资产 | CRF、数据表、脚本、量表；路径与命名规则 |
| 实物 | 针具灸材余量、归档位置、有效期 |
| 未完成项 | 待办事项、优先级、前置条件 |
| 签收 | 移交人、接手人、导师、日期 |

> 本表是本章的交付物：答辩后两周内完成；四张清单签字后归入教研室档案。

## H.6 常见失效与处置

- **只写穴位不写深度** → 复现时刺激量不可控，疗效差说不清是方案还是手法；逐穴写参数
- **用「适度」描述手法** → 无法核对也无法培训；改成频率、幅度、时长的区间
- **假装一切可文字化** → 得气与力度必须靠带教；标明更负责，也更容易被接手
- **手册不做复现验证** → 未验证的手册只是草稿；至少三例、两个人
- **只交论文不交数据** → 下一届无法复算，同一件事每年重做一次；数据清单要能让人从原始值算出你的表格
- **交接只在口头** → 人一走信息全失，连方案版本都说不清；四张清单必须签字，签完归教研室档案

## H.7 中期检查与答辩要点

- 手册完整性与参数可核（30%）
- 不可写部分标注与带教安排（25%）
- 复现验证与修订（25%）
- 数据实物交接与签收（20%）
