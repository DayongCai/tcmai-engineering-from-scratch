## H.1 本章要解决的问题

针刺很难盲，但不等于不能盲：受试者盲（假针刺或安慰针）、评价者盲、统计分析盲，能做到几层就写几层。把单盲写成双盲，是答辩最先被抓的一处。疗效评价这一章要交四样东西：盲法层级、分析集、效应量与区间、偏倚清单。分析计划须在揭盲前定稿，否则每条统计选择都会被质疑是看过结果才定的。

## H.2 本章目标（可检验）

- 写清本研究的盲法层级、实施方式与做不到的部分
- 按意向性原则完成组间比较，报告效应量与置信区间
- 给出脱落敏感性分析与五类偏倚来源

## H.3 操作流程

1. 定层级：受试者盲、评价者盲、统计分析盲逐条写做得到与做不到，做不到的写原因，不写「基本双盲」
2. 设假针刺：非经非穴点、钝头针、浅刺不破皮、安慰针具，选一并写清它与真针刺在位置、深度、刺激上的差异
3. 查盲法可信度：首次治疗后询问受试者「你估计接受的是哪种」，记录猜测分布与正确率，高于随机水平即部分失效
4. 分离评价者：量表由不参与操作的第三人评；无法分离时，注明并由同一人评全部时点，且不知分组
5. 测基线：入组时测全部结局，基线不均衡的变量在分析中作为协变量，不靠随机化自动解决
6. 定分析集：意向性分析为主（全部随机例），符合方案集为辅，两套结果都报，差异大时以意向性为主并解释
7. 选统计：连续变量按分布用 t 检验或秩和检验，分类用卡方或精确检验；重复测量用混合效应模型并写协方差结构
8. 报效应：组间差、95% 置信区间、标准化效应量（如 Cohen d），绝对差与相对差各报一次；只报 P 值等于没报
9. 处理脱落：记录原因与时点，做最差情形与末次观测结转两种敏感性分析，结论随分析集改变要如实写
10. 控多重性：次要结局与亚组分析事先声明为探索性，或做校正并写明方法；亚组每组少于二十例不做推断
11. 写偏倚：选择、实施、测量、失访、报告五类各写一条来源与影响方向，能缓解的写缓解措施
12. 对开题：逐条核对命题句中的时点、量表、最小差值是否按原计划执行，偏离处写清原因与影响

## H.5 模板：疗效与偏倚表

| 字段 | 填写要求 |
|------|----------|
| 盲法 | 层级、实施方式、做不到的部分与原因 |
| 假针刺 | 位置、针具、深度、与真针刺的差异 |
| 盲法可信度 | 询问时点、猜测分布、正确率 |
| 分析集 | 意向性例数、符合方案例数、排除原因 |
| 主要结局 | 各组均值或中位数、组间差、效应量、95% CI |
| 次要结局 | 同上，注明探索性 |
| 脱落与敏感性 | 脱落例数与时点、两种分析结果 |
| 多重性 | 校正方法或探索性声明、亚组门槛 |
| 偏倚 | 五类来源、影响方向、缓解措施 |

> 本表是本章的交付物：结果章首页一页；答辩按行追问，每行须能指到分析输出。

## H.6 常见失效与处置

- **宣称双盲** → 针刺研究多数做不到受试者盲；如实写层级反而加分，虚报是硬伤
- **只报 P 值** → 缺效应量与区间，读者无法判断临床意义；三项都要报
- **假针刺只写「假穴」** → 位置、深度、刺激都不同，效应差无法解释；操作定义写全
- **脱落直接剔除** → 脱落非随机时系统性偏倚；按意向性原则并做敏感性分析
- **事后挑亚组** → 属数据挖掘，结论不可信；亚组须事先声明或做校正
- **盲法可信度不查** → 受试者猜对率过半时盲法实际已破，结论要降级表述

## H.7 中期检查与答辩要点

- 盲法设计与诚实度（30%）
- 统计报告完整性（30%）
- 脱落与敏感性分析（20%）
- 偏倚分析与命题对照（20%）
