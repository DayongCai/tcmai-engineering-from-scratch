## H.1 本章要解决的问题

答辩最常被问的一句是「你怎么知道是穴位起作用，而不是随便扎一下」。这个问题躲不过：要么有非穴对照或剂量对照的证据，要么坦白本研究只能说明这套操作有效，不能说明穴位特异性。论文要做的，是把这条边界写在明面上，并在讨论里给出下一步验证的设计。写得再漂亮，答不上穴位特异性、盲法、样本量这三问，仍然过不了。

## H.2 本章目标（可检验）

- 写出问题、方法、结果、讨论、局限五段齐全且数字可溯源的论文
- 完成十五分钟汇报与四类必答问题的答案，答案里带数字
- 按预答辩意见修改并保留修改对照

## H.3 操作流程

1. 定主线：一句话写清本研究支持什么、不能支持什么，全文取舍以这句为准，摘要与结论都从这句改出来
2. 对表：正文每个数字回到 CRF 与导出表核对，抽查十个数字能复算才写进结果
3. 搭结构：摘要（背景、方法、结果、结论四句）、引言（缺口与命题）、方法、结果、讨论、局限、结论，每部分先列小标题再填内容
4. 写方法：诊断标准、纳入排除、随机与分配隐藏、盲法、干预细节（穴位、参数、疗程）、结局与统计，含软件版本与随机化方法
5. 按 STRICTA 自检干预描述：每穴针数、留针、得气、刺激方式、操作者资质与年限、合并治疗
6. 排结果：先主要结局，再次要，再安全性（不良事件例数、类型、与针刺的关系判定），顺序与命题一致
7. 配图：入组到分析的流程图、主要结局随时间变化图；图注含 n、时点与误差线含义，一图只答一个问题
8. 写讨论：与至少三篇同类研究比对，一致与不一致各给原因假设（方案、疗程、人群、对照差异），并说明本研究处在哪一侧
9. 写局限：穴位特异性未验证、盲法层级有限、样本量与随访时长不足，三条必写，各附对结论的影响方向
10. 备质疑：非穴对照、评价者偏倚、疗程是否足够、合并用药干扰，各写三句答案并背下来，答案里要有数字
11. 试讲：十五分钟讲一遍，请两人记录听不懂处，按记录删掉三分之一内容再讲一遍，第二轮控制在十四分钟内
12. 归档：论文、CRF、数据表、分析脚本、答辩 PPT 五件一并提交，路径写进移交清单，缺一件不算完成

- [ ] 方法章含随机、分配隐藏、盲法与干预细节，可被他人照做

## H.5 模板：答辩准备表（针灸）

| 字段 | 填写要求 |
|------|----------|
| 核心结论 | 四十字以内，含边界 |
| 证据链 | 命题 → 对照 → 结局 → 统计 → 效应量 |
| 干预描述 | 穴位、参数、疗程、操作者资质与年限 |
| 主要结果 | 组间差、效应量、95% CI、P 值 |
| 安全性 | 不良事件例数、类型、判定 |
| 四个质疑 | 问题与三句答案，含数字 |
| 局限 | 穴位特异性、盲法、样本量与随访 |
| 试讲反馈 | 听不懂处与删改记录 |
| 评分 | 证据链 30%、统计 25%、局限 20%、答辩 25% |

> 本表是本章的交付物：答辩前三天自查一遍，前一天再走一遍；当场按行作答。

## H.6 常见失效与处置

- **回避穴位特异性** → 这是最核心的质疑；正面写出边界比绕开可信，讨论里给下一步设计
- **把相关当因果** → 单臂前后对照只能提示关联，措辞要降级，结论写「本方案可能」
- **数字对不上 CRF** → 答辩被追问即崩；写前逐个复算并标表号，抽查十个数字全部可复算才定稿
- **讨论只复述结果** → 没有文献比对，看不出学术位置，也说不清与既往研究不一致的原因；至少三篇
- **结论拔高** → 单中心小样本写成普适规律，评审必打回；限定人群与疗程
- **超时** → 十五分钟讲不完说明没取舍；先删次要结局细节与文献综述

## H.7 中期检查与答辩要点

- 证据链完整性（30%）
- 统计与效应量呈现（25%）
- 局限与结论分寸（20%）
- 答辩表现与质疑回应（25%）
