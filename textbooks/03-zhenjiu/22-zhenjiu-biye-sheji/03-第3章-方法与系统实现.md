## H.1 本章要解决的问题

针灸毕设的「系统」通常是数据采集与随访工具。工具要为评价服务，不是为演示服务。

## H.2 本章目标（可检验）

- 实现能支撑随访与评分的最小工具
- 所有评分可追溯到原始记录
- 工具故障时有纸质兜底

## H.3 操作流程

1. 定功能：入组登记、随访提醒、量表录入、导出
2. 定字段：与数据表一一对应，不多不少
3. 实现：先跑通一例全流程
4. 校验：随机抽三条与原表核对
5. 兜底：断网或故障时的纸质流程

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 功能与字段清单已写
- [ ] 字段与数据表一一对应
- [ ] 一例全流程已跑通
- [ ] 抽查三条核对一致
- [ ] 导出格式可直接分析
- [ ] 纸质兜底流程已写
- [ ] 依赖与版本已记录

## H.5 模板：工具与数据一致性说明

| 字段 | 填写要求 |
|------|----------|
| 功能清单 | 登记/提醒/录入/导出 |
| 字段映射 | 工具字段 ↔ 数据表列 |
| 全流程验证 | 病例号与结果 |
| 兜底 | 故障时的纸质流程 |

> 本表是本章的交付物：论文附录，评审可照此抽查。

## H.6 常见失效与处置

- **功能越做越多** → 评价才是目的；先跑通一条链路
- **字段与数据表不一致** → 导出后还要手工改，易错
- **无兜底方案** → 一次故障就丢随访数据

## H.7 中期检查与答辩要点

- 字段一致性（40%）
- 全流程验证（30%）
- 兜底与可维护（30%）
