## H.1 本章要解决的问题

针灸数据有三类最容易丢：穴位扎在哪（定位与坐标）、刺激量多大（手法与电参数）、谁在评（评价者）。三者缺一，组间差异就无法归因——到底是不对症、没扎准、量不够，还是评分漂移。数据准备要交的不是一本病历，而是一条能复算的链：换一个人拿着你的表，能把位置扎回去、把量做出来，也能看出哪一例没做全。

## H.2 本章目标（可检验）

- 建立含定位方法、进针参数、刺激量与评价者的病例表
- 把穴位定位写成可被第二个人照做的描述，并统一坐标口径
- 固定评价者与时点，完成一次评分一致性检验，低于阈值即重训

## H.3 操作流程

1. 建表头：病例号、入组日期、西医诊断、中医证型、病程、基线量表分、合并用药，字段名一经确定不再改，改名须记变更
2. 定编号：中心码-组别-序号（如 A-01-07），知情同意书、CRF、随访表、数据文件共用同一编号
3. 写定位：每穴写定位方法（骨度分寸、体表标志、同身寸）、参照点、示意图编号；禁止只写穴名或「经验取穴」
4. 定坐标口径：需跨操作者比对时，按骨度分寸折算的相对坐标记录（以骨性标志为原点），写明折算规则与容差
5. 记进针：深度（寸或毫米，全项目统一单位）、角度（直刺、斜刺、平刺及度数）、方向、单侧或双侧，逐穴一行
6. 记得气：有无、性质（酸麻胀重）、是否循经感传，用固定描述词，不写「得气良好」这类无判据的话
7. 记刺激量：捻转频率与幅度、电针波形（连续或疏密）、频率（Hz）、电流（mA）、留针时长，逐次记录
8. 记辅助：艾灸壮数与壮量、温针灸、拔罐留罐时长；同一例中途不得改方案，改动一律记方案偏离并注明诊次
9. 定评价者：固定一至两名，先培训一次再上岗；同一患者由两人各评一次，算 ICC 或 Kappa 并留存
10. 定时点：基线、疗程中（第几诊）、疗程末、随访（第几周），写进 CRF 表头，不临时决定，也不事后追补
11. 记脱落与偏离：脱落原因、时间点、已完成诊次、是否愿接受末次评估；违背方案例数单列，不删不并
12. 管版本：CRF 表头标版本号与生效日期，字段增删留变更记录，旧版表与旧数据一并归档，导出文件注明版本

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 病例表含诊断、证型、病程、基线分、合并用药
- [ ] 编号规则统一，四类文件共用同一编号
- [ ] 每穴写明定位方法与参照点，附示意图编号
- [ ] 坐标口径与折算规则已写，含容差
- [ ] 进针深度、角度、方向逐穴记录，单位统一

- [ ] 辅助理疗（灸、罐）剂量已记录

## H.5 模板：针灸病例数据表（CRF）

| 字段 | 填写要求 |
|------|----------|
| 病例标识 | 编号、组别、入组日期、完成诊次 |
| 诊断与证型 | 西医病名、中医证型、病程、合并用药 |
| 穴位与定位 | 穴名、定位方法、参照点、示意图号、单双侧 |
| 坐标 | 骨度折算值、原点标志、容差 |
| 进针参数 | 深度、角度、方向 |
| 得气 | 有无、性质、感传、出现诊次 |
| 刺激量 | 手法频率幅度、电针波形频率电流、留针时长、累计次数 |
| 辅助理疗 | 灸法壮数、留罐时长 |
| 评价 | 评价者、量表、时点、一致性结果 |
| 脱落与偏离 | 原因、时间点、已完成诊次、末次评估 |

> 本表是本章的交付物：每例一份，随论文提交；表头版本号与导出文件一一对应。

## H.6 常见失效与处置

- **定位只写穴名** → 不同人扎的位置差一两寸，刺激的组织不同，效应差无从解释；须写方法与图号
- **坐标口径不统一** → 一人用同身寸一人用骨度分寸，跨操作者比对全部作废；开题前定死
- **漏记电针参数** → 频率与电流直接改变刺激量，组间差异说不清来源；逐次记波形、频率、电流
- **得气写「良好」** → 无法复核也无法培训；改成固定描述词并记出现诊次
- **评价者中途换人** → 评分漂移被当成疗效变化；换人须重做一致性检验并在局限中说明
- **删掉违背方案病例** → 属选择性报告，答辩必被追问；单列并做敏感性分析，注明例数

## H.7 中期检查与答辩要点

- 定位与坐标可复现（30%）
- 刺激参数完整度（25%）
- 评价一致性（25%）
- 脱落、偏离与版本管理（20%）
