## H.1 本章要解决的问题

针灸数据有三类容易丢：穴位有没有扎准（坐标）、刺激量有多大（参数）、谁在评（评价者）。

## H.2 本章目标（可检验）

- 建立含穴位定位与刺激参数的病例表
- 固定评价者与评价时点
- 记录脱落与违背方案

## H.3 操作流程

1. 定表：病例号、证型、穴位、定位方法、刺激参数、评价者
2. 定位：按骨度分寸记录，附示意图编号
3. 参数：进针深度、得气描述、留针时间、电针频率
4. 评价：评价者固定，必要时用第三方
5. 记录脱落：原因与时间点

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 穴位定位方法已写（骨度分寸/体表标志）
- [ ] 每穴深度与角度已记录
- [ ] 得气描述与留针时间已记
- [ ] 电针参数（波形/频率/强度）已记
- [ ] 评价者身份与时点已固定
- [ ] 脱落与违背方案已记录
- [ ] 数据表版本号已标

## H.5 模板：针灸病例数据表

| 字段 | 填写要求 |
|------|----------|
| 病例与证型 | 编号、证型、入组时间 |
| 穴位与定位 | 穴名、定位法、示意图号 |
| 刺激参数 | 深度、得气、留针、电针 |
| 评价 | 评价者、量表、时点 |
| 脱落 | 原因与时间 |

> 本表是本章的交付物：每例一行，随论文提交。

## H.6 常见失效与处置

- **定位只写穴名** → 不同人扎的位置不同；须写定位方法与图号
- **刺激参数缺失** → 电针频率与强度直接影响效应，必须记
- **评价者不固定** → 评分漂移会被误当成疗效

## H.7 中期检查与答辩要点

- 定位与参数记录（40%）
- 评价一致性（30%）
- 脱落记录完整（30%）
