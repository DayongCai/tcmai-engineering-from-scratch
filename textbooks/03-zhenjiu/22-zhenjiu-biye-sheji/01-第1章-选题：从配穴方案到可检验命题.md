## H.1 本章要解决的问题

「某配穴方案治疗某病有效」不是命题：有效没定义、跟谁比没写、招多少例没算、扎几周没说、谁来评没定。开题要交的是一条能被否证的假设——哪组穴位、相对什么对照、在哪个时点、用哪个量表、差多少才算差。这六项缺一项，后面十周都在补定义，招募一开始就卡在纳排标准上；与其写十页意义，不如把这一句写死。

## H.2 本章目标（可检验）

- 把配穴方案写成含人群、对照、结局、时点、最小差值的可否证命题
- 为命题配一套能算的样本量与十周招募测算，说明依据
- 划定单病种单证型的边界，并写出不做清单

## H.3 操作流程

1. 查依据：抄下该病现行指南或规划教材的推荐方案与常用配穴，标出处与年份，判断本方案属常规应用还是改良
2. 写方案要素：主穴与配穴、单侧或双侧、进针顺序、刺激方式（手针或电针）、单次留针、每周频次、总次数
3. 选对照：假针刺（非经非穴点、钝头针、浅刺不破皮）、常规治疗、等待名单，只选一个，并用一句话写清它能排除哪种解释
4. 写命题句：在 X 病患者中，A 方案相对 B 对照，在 Y 时点使 Z 量表评分下降不少于 d 分；句式不许留「有效」这类空词
5. 定主要结局：只留一个，优先选该病公认量表（疼痛用 NRS 或 VAS，失眠用 PSQI），写明测量时点与随访长度
6. 定次要结局：不超过两个，其中一个用盲法评价或客观指标（如睡眠监测、关节活动度），避免全部依赖患者自报
7. 取效应量：从同病种针刺研究取，注明是否同方案同疗程；无同方案者按该量表的最小临床重要差异定 d，并说明来源
8. 算样本量：按主要结局、α 取 0.05、把握度 0.80、脱落率 20% 计算，公式与每个参数抄进开题表，不写「大约几十例」
9. 测招募：用近三个月周均门诊量与可用治疗床位、时段相乘，算十周可入组例数；不足则缩窄证型或延长招募窗口
10. 限范围：单病种、单证型、单中心、单方案；把想加的第二方案与亚组分析列入不做清单，写理由
11. 判伦理：按院内与学院规范确认是否需伦理审批与试验注册，把审批周期排进里程碑，不放在开题之后补办
12. 找反对：请导师与一位非针灸专业老师各提一条反对意见，抄在附页并逐条写回应，回应不成立就改命题

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 命题句含人群、方案、对照、时点、量表、最小差值六项
- [ ] 主要结局唯一，且是该病公认量表
- [ ] 次要结局不超过两个，含一项非自报指标
- [ ] 对照组写明能排除的解释，未只写「不治疗」
- [ ] 效应量来源已注明，非同方案者已说明理由
- [ ] 样本量含 α、把握度、脱落率与计算公式
- [ ] 十周招募测算按真实门诊量与床位时段做过
- [ ] 病种、证型、中心三项均已限定
- [ ] 不做清单已写并附理由
- [ ] 伦理与注册需求已判定，周期已排进里程碑
- [ ] 方案要素七项（穴、侧、序、刺激、留针、频次、总次数）齐备
- [ ] 两条以上反对意见有书面回应

## H.5 模板：开题命题表（针灸）

| 字段 | 填写要求 |
|------|----------|
| 病种与证型 | 西医病名、中医证型、诊断标准出处与年份 |
| 方案要素 | 主配穴、单双侧、进针顺序、刺激方式、留针、频次、总次数 |
| 对照 | 类型、操作定义、可排除的解释 |
| 命题句 | 人群 + 方案 + 对照 + 时点 + 量表 + 最小差值 |
| 主要结局 | 量表全名、测量时点、随访长度 |
| 次要结局 | 至多两项，注明哪项非自报 |
| 样本量 | 效应量来源、α、把握度、脱落率、公式、每组例数 |
| 招募测算 | 周门诊量、可用时段、十周可入组数 |
| 伦理与注册 | 是否需审批、受理时间、批件归档位置 |
| 不做清单 | 舍弃项与理由 |

> 本表是本章的交付物：开题报告首页一页纸；答辩时与最终结论逐项对照，缺项不予开题。

## H.6 常见失效与处置

- **把方向当命题** → 「针刺治疗失眠疗效观察」判不了真假；补对照、时点与最小差值才能开题
- **主要结局留三个** → 三个都做不透，统计还要多重比较校正；只留一个
- **对照写成不治疗** → 自然病程与安慰效应混在一起，效应无法归因；至少加假针刺或常规治疗
- **样本量凭感觉** → 「招六十例差不多」经不起追问，也无法解释阴性结果；按公式算并写参数
- **不限证型** → 入组异质性大，效应被稀释，样本量永远不够；先限一个证型
- **伦理开题后才办** → 审批常以周计，直接吃掉招募窗口；排进第一里程碑

## H.7 中期检查与答辩要点

- 命题可检验性（35%）
- 对照与结局设计（30%）
- 样本量与招募测算（20%）
- 范围裁剪与反对意见回应（15%）
