## H.1 本章要解决的问题

「某配穴方案治疗某病有效」不是可检验命题：有效指什么、跟谁比、多少例，都没定义。

## H.2 本章目标（可检验）

- 把配穴方案写成含对照的命题
- 定义主要结局与测量时点
- 判断十周内能否完成

## H.3 操作流程

1. 写方案：穴位、刺激方式、疗程、频次
2. 写对照：假针刺、常规治疗或不治疗，选一并说明理由
3. 定结局：一个主要结局 + 两个次要结局，含量表与测量时点
4. 估样本：按既往效应量估算，写清依据
5. 砍范围：单病种、单证型、单方案

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 方案要素（穴位/刺激/疗程/频次）齐备
- [ ] 对照组选择有理由
- [ ] 主要结局唯一且可测
- [ ] 测量时点已定
- [ ] 样本量估算有依据
- [ ] 证型与病种已限定
- [ ] 伦理审批需求已判断

## H.5 模板：开题命题表（针灸）

| 字段 | 填写要求 |
|------|----------|
| 方案 | 穴位、刺激、疗程、频次 |
| 对照 | 类型与理由 |
| 结局 | 主要/次要 + 量表 + 时点 |
| 样本量 | 估算依据 |
| 范围 | 病种与证型限定 |

> 本表是本章的交付物：开题首页，答辩须与最终结论对照。

## H.6 常见失效与处置

- **无对照** → 无法判断效应来自针刺还是自然病程
- **主要结局多个** → 多重比较会稀释结论；只留一个
- **不限证型** → 异质性过大，样本量永远不够

## H.7 中期检查与答辩要点

- 命题可检验性（40%）
- 对照与结局设计（30%）
- 可行性（30%）
