## H.1 本章要解决的问题

灸法与拔罐是「看起来最安全」的两项技术，也是门诊烫伤与晕厥的主要来源：艾灰掉落、留罐过久起水泡、空腹或疲劳状态下晕灸。轮转要建立的是「先判适应证与禁忌，再谈操作」的顺序，以及四类意外的标准处置动作。

## H.2 本章目标（可检验）

- 独立判断适应证与禁忌证（含糖尿病足、感觉障碍、凝血异常、皮肤破损、妊娠腰骶部）
- 完成艾条灸与留罐的规范操作，全程有距离/时间/皮肤反应记录
- 能按标准步骤处置烫伤、水泡、晕灸、晕罐四类意外并留痕

## H.3 操作流程

1. 适应证判断：虚寒证、寒湿痹痛、脾胃虚寒、阳气不足等；记录支持该判断的症状与舌脉
2. 禁忌筛查：皮肤破损与感染、感觉障碍（糖尿病周围神经病变）、凝血功能障碍或抗凝用药、严重心肺疾病、妊娠腰骶腹部、发热与出血倾向、瘢痕体质（禁瘢痕灸）
3. 环境与器材：排烟通风、灭火器具、艾条质量（无杂质硬结）、火源管理、罐具完整性检查（无裂纹）
4. 体位与暴露：体位稳定、只暴露操作区、注意保暖与隐私
5. 艾条灸操作：距离皮肤 3 cm 左右（温和灸），以温热不灼痛为度；每穴 10–15 分钟；随时弹灰、观察皮肤潮红程度
6. 艾炷灸（如用）：炷大小、壮数、是否隔物（隔姜/隔盐）；非化脓灸以皮肤潮红为度，瘢痕灸须单独知情同意
7. 拔罐操作：选罐（大小与部位匹配）、投火或抽气、吸附力度（以患者耐受为度）、留罐 5–10 分钟（不宜超过 15 分钟）、观察罐内皮肤颜色与有无水泡
8. 起罐与善后：一手压罐口皮肤、一手扶罐倾斜起罐；起罐后观察皮肤颜色、有无破损；交代避免受凉、当日不洗冷水
9. 意外处置——烫伤：立即移除热源、冷水冲洗 15–20 分钟、覆盖清洁敷料、按面积与深度决定是否转诊；记录时间与处置
10. 意外处置——水泡：小水泡不刺破、保护防摩擦；大水泡无菌抽液、保留表皮、覆盖敷料；糖尿病与抗凝患者一律上报
11. 意外处置——晕灸/晕罐：立即停止、去罐或移开艾条、平卧抬高下肢、通风、测血压脉搏、给温糖水；不缓解即呼叫带教
12. 记录与复盘：按 H.5 模板填「灸法/拔罐操作与意外记录表」；每例意外写「诱因—处置—转归—改进」

## H.5 模板：灸法/拔罐操作与意外记录表

| 字段 | 填写要求 |
|------|----------|
| 适应证与依据 | 证候、症状、舌脉 |
| 禁忌筛查 | 七项逐条有/无 |
| 环境与器材 | 通风、火源管理、罐具检查、艾条质量 |
| 操作参数 | 穴位、距离/吸附力度、时长、壮数或罐数 |
| 皮肤反应 | 潮红程度、颜色、有无水泡或破损 |
| 起罐/收灸 | 手法、时间、善后交代 |
| 意外处置 | 类型、诱因、处置步骤、生命体征、转归 |

| 复盘 | 诱因、处置、转归、改进措施 |
| 签名 | 操作人、带教、时间 |

## H.6 常见失效与处置

- **不筛感觉障碍与抗凝** → 糖尿病足与抗凝患者最易烫伤且难愈；漏筛是主要事故来源
- **留罐超时** → 超过 15 分钟水泡率显著升高；时间必须记
- **艾条不弹灰** → 艾灰掉落造成点状烫伤，是最常见的低级错误
- **空腹或疲劳状态施灸** → 晕灸高发；操作前应询问进食与睡眠
- **水泡一律刺破** → 增加感染风险；小水泡应保护不刺破
- **意外不记录** → 无法复盘改进，也可能在纠纷中失去自证材料

## H.7 出科考核

- 适应证与禁忌判断（一票否决：漏筛禁忌即不通过）
- 操作参数与过程记录（30%）
- 四类意外处置的规范性（30%）
- 善后与交代（20%）
- 复盘质量（20%）
