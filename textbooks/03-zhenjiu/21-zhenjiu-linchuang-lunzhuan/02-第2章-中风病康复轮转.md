## H.1 本章要解决的问题

中风康复的关键不是多扎几针，而是「当前处于哪一期、这一期能练什么」。分期错了，强刺激反而有害。

## H.2 本章目标（可检验）

- 能用 Brunnstrom 或简化分期判断当前阶段
- 能按分期选择刺激强度与康复动作
- 能记录痉挛与误吸风险

## H.3 操作流程

1. 评估：意识、肌张力、Brunnstrom 分期、坐站平衡、吞咽
2. 定阶段：软瘫期、痉挛期、恢复期各写一句依据
3. 配穴与手法：按分期调整刺激量与留针
4. 康复配合：写出当日可完成的主动训练动作
5. 记录：量表分值与不良反应

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 肌张力与分期已评
- [ ] 坐站平衡与转移能力已记
- [ ] 吞咽筛查已做
- [ ] 刺激量按分期调整并记录
- [ ] 当日训练动作已写三条
- [ ] 痉挛加重或不适已记录
- [ ] 家属宣教内容已记

## H.5 模板：中风康复分期记录表

| 字段 | 填写要求 |
|------|----------|
| 分期 | Brunnstrom 分期与依据 |
| 肌张力与平衡 | 改良 Ashworth、坐站 |
| 吞咽 | 筛查结果与饮食建议 |
| 针刺方案 | 穴位、刺激量、留针 |
| 训练动作 | 当日三条主动训练 |

> 本表是本章的交付物：每周一张，随康复计划更新。

## H.6 常见失效与处置

- **软瘫期用强刺激** → 可能加重痉挛；按分期调整
- **不做吞咽筛查** → 误吸风险直接威胁生命；必须筛
- **只记针刺不记训练** → 康复效果主要来自训练，针刺是配合

## H.7 出科考核

- 分期准确性（40%）
- 吞咽筛查（一票否决项）
- 方案与分期匹配（30%）
- 记录完整度（30%）
