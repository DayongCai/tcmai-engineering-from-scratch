## H.1 本章要解决的问题

中风康复的针灸最容易被做成「每天扎一遍，扎完就结束」。真正决定结局的是三件事：介入时机与病情稳定性判断、与康复训练的配合（扎完就练还是练完再扎）、以及可量化的功能评定。不会评定的针灸，无法回答「这个病人这周到底进步了没有」。

## H.2 本章目标（可检验）

- 判断当前是否处于可针灸的稳定期，并写出判断依据（生命体征、病情进展、抗凝用药）
- 完成一次痉挛与运动功能的量化评定（如肌张力分级、Brunnstrom 分期或简式 Fugl-Meyer，按院内条件）
- 制定含穴位、参数、训练配合与复评时点的康复计划

## H.3 操作流程

1. 病历与稳定期判断：发病时间、影像结论、生命体征是否平稳 48 小时以上、有无进展性加重、有无发热与感染
2. 用药核对：抗凝/抗血小板药物（影响出血风险）、降压药、降糖药；记录最后一次用药时间
3. 功能评定：意识与配合度、肌张力（改良 Ashworth）、运动分期（Brunnstrom）、平衡与步行能力、日常生活能力（如 Barthel）——每项记分值
4. 并发症筛查：吞咽困难（误吸风险）、肩手综合征、肩关节半脱位、深静脉血栓、压疮；命中即调整方案
5. 体位与安全：良肢位摆放、患侧保护、进针体位是否能维持、有无坠床风险
6. 辨证与选穴：病位（脑络、心、肝、肾）+ 病性（气虚血瘀、风痰阻络、阴虚风动）；选穴以头针（如运动区）、体针（肩髃、曲池、合谷、环跳、阳陵泉、足三里、太冲等）与辨证配穴组合，逐穴写依据
7. 刺激参数：进针深度与角度、手法、得气要求、电针频率与波型（如用）、留针时长；痉挛明显者避免强刺激
8. 训练配合：明确「针灸—训练」的先后与间隔（如针后即练、练后休息再针），写进计划
9. 操作与观察：进针过程观察面色、出汗、心慌；抗凝患者拔针后延长按压时间并观察血肿
10. 当日记录：按 H.5 模板填「中风康复针灸记录表」，含评定分值、穴位参数、训练内容与反应
11. 复评时点：设定每周复评一次，比较运动分期、肌张力与 Barthel 分值
12. 阶段小结：4 周做一次小结，写清「有效/平台/退步」及依据，退步需查原因（痉挛加重、感染、抑郁）

## H.5 模板：中风康复针灸记录表

| 字段 | 填写要求 |
|------|----------|
| 病程与稳定期 | 发病日期、影像、生命体征、是否稳定 |
| 用药 | 抗凝/抗血小板、降压、降糖，最后用药时间 |
| 功能评定 | 肌张力分级、运动分期、平衡、Barthel 分值 |
| 并发症筛查 | 吞咽、肩手、半脱位、血栓、压疮，逐项结论 |
| 辨证 | 病位、病性两行写 |
| 选穴 | 头针/体针/辨证配穴，逐穴依据 |
| 刺激参数 | 深度、角度、手法、电针频率波型、留针时长 |
| 训练配合 | 训练内容、先后顺序、间隔 |
| 反应与处置 | 得气、面色出汗、血肿、晕针等 |
| 复评与小结 | 每周分值对比、4 周小结结论 |

> 本表是本章的交付物：每次治疗一栏，评定栏每周填一次；阶段小结附在表后。

## H.6 常见失效与处置

- **病情未稳定就扎** → 进展期针刺可能加重负担；稳定期判断必须留痕
- **不查抗凝用药** → 拔针后血肿与出血风险显著升高；需延长按压并观察
- **评定只写「较前好转」** → 没有分值就没有疗效证据，也无法调整方案
- **痉挛期用强刺激** → 可能加重痉挛；参数应随肌张力调整
- **忽略吞咽与误吸** → 康复期最常见的致命并发症，必须在筛查项内
- **针灸与训练脱节** → 扎完就散步、或训练后疲劳再扎，都会削弱效果；顺序要写死

## H.7 出科考核

- 稳定期判断与用药核对（一票否决：未判断稳定期即不通过）
- 功能评定的规范执行（30%）
- 选穴依据与参数记录（25%）
- 并发症筛查与训练配合（25%）
- 复评与阶段小结（20%）
