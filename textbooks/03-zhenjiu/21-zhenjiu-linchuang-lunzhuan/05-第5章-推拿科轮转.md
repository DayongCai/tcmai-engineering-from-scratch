## H.1 本章要解决的问题

推拿的风险集中在颈椎：扳法用错、力度失控、未先排除椎动脉与脊髓问题，后果可能是不可逆的。轮转的核心不是学更多手法，而是学会「什么时候不推」——把禁忌证筛干净，把手法参数写清楚，把患者的即时反应记下来。

## H.2 本章目标（可检验）

- 完成推拿前评估：影像与症状是否匹配、有无手法禁忌、体质与耐受度
- 掌握至少三类基本手法（㨰法、按揉、拔伸或扳法）的规范操作与力度控制
- 对每次治疗记录部位、手法、力度、时长与患者即时反应

## H.3 操作流程

1. 病史与影像：症状分布、病程、既往影像结论；影像与症状不符时以症状与查体为主并记录
2. 禁忌筛查：椎动脉供血不足表现（转头眩晕、视物模糊、猝倒史）、脊髓压迫征象（行走不稳、病理征阳性、括约肌障碍）、骨质疏松、肿瘤与感染、骨折与脱位、皮肤感染、妊娠、抗凝用药
3. 体格检查：活动度、压痛点、肌张力与条索、神经查体（肌力、感觉、反射）、特殊试验（椎动脉试验、臂丛牵拉、直腿抬高）
4. 方案制定：部位与手法组合（放松类→整复类→收尾类），每步目的写清；整复类手法须写明「为什么这个节段、为什么这个方向」
5. 力度控制：以患者耐受与组织反应为度，颈部整复类手法原则上不在学生独立操作范围内，须在带教监督下进行
6. 操作过程：体位、接触部位、手法频次与时长；随时询问感受，出现头晕、恶心、视物模糊立即停止
7. 即时反应记录：疼痛变化（减轻/加重/无变化）、局部温度与颜色、有无头晕与不适；加重者需记录并复评
8. 善后交代：当日避免剧烈活动与长时间低头、局部保暖；可能出现的一过性酸胀说明清楚
9. 复评与调整：3 次后复评，无效或加重需重新评估诊断与手法选择
10. 记录：按 H.5 模板填「推拿治疗记录表」，含禁忌筛查结论（必须出现在表内）
11. 意外处置：出现眩晕、晕厥、剧痛或神经症状加重，立即停止、平卧、测生命体征、呼叫带教并记录
12. 复盘：挑一例「症状像颈椎病但实际需要转诊」的病例，写清哪条线索改变了判断

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 影像与症状的匹配性已判断
- [ ] 禁忌九项已筛（椎动脉、脊髓、骨质疏松、肿瘤感染、骨折、皮肤、妊娠、抗凝、体质）
- [ ] 神经查体与特殊试验有实测结果
- [ ] 手法组合与每步目的已写
- [ ] 整复类手法有带教监督记录，学生不独立操作颈部扳法
- [ ] 力度与时长已记录
- [ ] 过程中出现头晕/恶心即停止并记录
- [ ] 即时反应（疼痛变化、局部反应）已记
- [ ] 善后交代（活动、保暖、一过性反应）已复述确认
- [ ] 3 次复评已安排
- [ ] 意外处置流程已掌握并留痕
- [ ] 复盘病例已写清转折线索

## H.5 模板：推拿治疗记录表

| 字段 | 填写要求 |
|------|----------|
| 病史与影像 | 症状分布、病程、影像结论、是否匹配 |
| 禁忌筛查 | 九项逐条有/无与依据 |
| 查体 | 活动度、压痛、肌张力、神经查体、特殊试验 |
| 手法方案 | 部位、手法、顺序、每步目的 |
| 操作参数 | 力度、频次、时长、体位 |
| 监督与权限 | 整复类手法是否带教在场、谁操作 |
| 即时反应 | 疼痛变化、局部反应、头晕恶心等 |
| 善后交代 | 活动限制、保暖、可能出现的一过性反应 |
| 复评 | 3 次后评估结论与调整 |
| 意外与签名 | 意外处置记录、操作人与带教签名 |

> 本表是本章的交付物：每次治疗一行；禁忌筛查栏首诊必填，复诊如有变化须更新。

## H.6 常见失效与处置

- **不查椎动脉与脊髓征象就做颈部手法** → 最严重的安全事故来源，属绝对禁忌筛查项
- **学生独立做颈部扳法** → 超出权限；必须在带教监督下并留痕
- **只记「手法治疗」** → 无法复现，也无法判断是哪种手法起了作用
- **患者说「有点晕」仍继续** → 应立即停止并测生命体征；继续操作风险极高
- **3 次无效仍原方案** → 需重新评估诊断与手法，不能靠加次数
- **善后交代省略** → 一过性反应被误认为加重，患者依从性下降

## H.7 出科考核

- 禁忌筛查与查体（一票否决：漏筛即不通过）
- 手法选择与参数记录（30%）
- 即时反应观察与处置（25%）
- 复评与方案调整（20%）
- 记录与复盘（25%）
