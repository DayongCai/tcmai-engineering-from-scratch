## H.1 本章要解决的问题

颈肩腰腿痛最容易「来了就扎」，但同样的腰痛可能是劳损、可能是椎间盘、也可能要转诊。轮转第一天要能先分诊再配穴。

## H.2 本章目标（可检验）

- 能完成疼痛的部位、性质、诱因与神经体征采集
- 能识别需要转诊的危险信号
- 能写出配穴思路（循经 + 局部 + 辨证）

## H.3 操作流程

1. 问痛：部位、性质、诱因、昼夜变化、有无放射
2. 查体：压痛点、活动度、直腿抬高或臂丛牵拉、肌力与感觉
3. 排危险：进行性肌力下降、鞍区麻木、大小便障碍、发热 → 转诊
4. 配穴：写循经取穴、局部取穴、辨证配穴三行
5. 操作：记录穴位、角度、深度、得气、留针时间

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 疼痛五要素（部位/性质/诱因/昼夜/放射）已问
- [ ] 压痛点与活动度已查
- [ ] 神经体征（肌力、感觉、牵拉试验）已查
- [ ] 危险信号逐条排查
- [ ] 配穴三行分开写
- [ ] 进针参数（角度/深度/得气）已记录
- [ ] 留针时间与不良反应已记

## H.5 模板：痛证针灸接诊表

| 字段 | 填写要求 |
|------|----------|
| 疼痛五要素 | 部位、性质、诱因、昼夜、放射 |
| 查体 | 压痛点、活动度、神经体征 |
| 危险信号 | 排查结论 |
| 配穴 | 循经/局部/辨证三行 |
| 操作参数 | 穴位、角度、深度、得气、留针 |

> 本表是本章的交付物：每位初诊患者一张，复诊对照。

## H.6 常见失效与处置

- **直接按「腰痛」配肾俞** → 未排除神经受压与危险信号；先查体再配穴
- **配穴只写穴名** → 不写循经与辨证依据，无法复盘与教学
- **不记进针参数** → 同一穴位不同角度效果不同，参数是疗效的一部分

## H.7 出科考核

- 查体与危险信号（一票否决项）
- 配穴三行完整度（40%）
- 操作参数记录（30%）
