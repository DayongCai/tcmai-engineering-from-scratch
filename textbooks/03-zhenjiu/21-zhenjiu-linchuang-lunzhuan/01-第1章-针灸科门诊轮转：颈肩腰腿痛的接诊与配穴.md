## H.1 本章要解决的问题

颈肩腰腿痛是针灸门诊量最大的群体，也最容易「一套穴位通用」。真正要练的是三件事：先用查体把「该不该扎」判断出来（红旗征象、神经受压、需要影像的情形），再按经络与病位选穴并说明依据，最后把刺激参数写清楚——否则「有效」无法归因，也无法被别人重复。

## H.2 本章目标（可检验）

- 完成颈肩腰腿痛的结构化接诊：疼痛部位与放射、诱发与缓解因素、神经查体要点、红旗筛查
- 给出配穴方案并逐穴说明依据（经脉循行、局部与远端、经验穴的来源）
- 记录可复现的刺激参数：穴位、深度、角度、手法、得气描述、留针时间、疗程

## H.3 操作流程

1. 接诊与分诊（5 分钟）：先筛红旗——外伤后剧痛、进行性肌力下降、马尾综合征表现（鞍区麻木、大小便障碍）、发热伴腰痛、夜间痛醒、体重下降，命中即建议转诊并记录
2. 疼痛画像：部位（颈/肩/腰/腿）、性质（酸痛/刺痛/放射）、放射路径与皮节对应、诱发（久坐/弯腰/翻身）与缓解（平卧/活动）
3. 体格检查：颈椎与腰椎活动度、压痛点、肌力（关键肌群分级）、感觉（皮节）、反射、特殊试验（如臂丛牵拉、直腿抬高）——每项写实测结果
4. 影像与既往：是否已有影像及结论；既往治疗（针灸、推拿、药物、手术）与反应
5. 辨证定位：经络（如太阳、少阳、督脉）+ 病位（经筋、脏腑）+ 病性（风寒湿、瘀、虚），写两行结论
6. 配穴方案：局部取穴（阿是、夹脊）+ 远端取穴（循经）+ 辨证配穴，每穴写选穴理由；总穴位数与主次分明
7. 刺激参数预设：进针角度与深度（按部位与体型给范围）、手法（提插捻转频次与幅度）、得气标准、留针时长、电针参数（如用）
8. 体位与安全：体位稳定、暴露适度、避开血管与重要脏器投影区；胸背部取穴需写明安全深度依据
9. 操作与观察：进针后逐穴记录得气（酸麻胀重、传导方向）、患者反应；出现头晕、恶心、心慌立即停针并按晕针处置
10. 出针与善后：按压止血、观察有无血肿、交代当日注意事项（避免受凉、剧烈运动）
11. 记录与疗程：按 H.5 模板填「颈肩腰腿痛针灸接诊表」，写明疗程安排与复评指标（疼痛评分、活动度、功能量表）
12. 复评与调整：下次就诊对比三项指标，有效则守方，无效则改穴或改参数并写调整理由

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 红旗六项已筛（外伤剧痛、肌力进行性下降、鞍区症状、发热腰痛、夜间痛醒、消瘦）
- [ ] 疼痛画像四项齐全（部位、性质、放射、诱因/缓解）
- [ ] 神经查体有实测值（肌力分级、感觉、反射、特殊试验）
- [ ] 既往影像与治疗反应已记录
- [ ] 经络与病位病性两行结论已写
- [ ] 每穴有选穴依据，主次分明
- [ ] 进针角度、深度、手法、得气标准、留针时间全部记录
- [ ] 胸背腹部取穴写明安全深度依据
- [ ] 得气描述逐穴记录（含传导方向）
- [ ] 出针后观察出血/血肿并交代注意事项
- [ ] 复评指标（疼痛/活动度/功能）已设定基线
- [ ] 无改善时有调整理由记录

## H.5 模板：颈肩腰腿痛针灸接诊表

| 字段 | 填写要求 |
|------|----------|
| 红旗筛查 | 六项逐条有/无与依据 |
| 疼痛画像 | 部位、性质、放射、诱发、缓解 |
| 查体 | 活动度、压痛点、肌力分级、感觉、反射、特殊试验 |
| 影像与既往治疗 | 检查结论、既往治疗与反应 |
| 辨证结论 | 经络 / 病位 / 病性，两行写 |
| 配穴方案 | 穴位、局部或远端、依据、主次 |
| 刺激参数 | 角度、深度、手法、得气标准、留针时间、电针参数 |
| 操作记录 | 逐穴得气与患者反应、异常处置 |
| 复评 | 疼痛评分、活动度、功能量表，基线 vs 本次 |
| 疗程与调整 | 疗程安排、调整理由、下次计划 |

> 本表是本章的交付物：首诊填全，复诊只填变化栏；疗程结束时按复评指标出具小结。

## H.6 常见失效与处置

- **不做神经查体就扎** → 肌力下降与感觉障碍提示神经受压，先扎针会延误
- **一套穴位通用** → 无选穴依据，疗效无法归因；复诊也就无从调整
- **深度凭感觉** → 胸背部与颈前部深度必须有解剖依据，是安全底线
- **只写「得气」两字** → 得气的性质与传导是参数的一部分，必须具体描述
- **疗效只看患者说「好些了」** → 缺基线评分，无法判断是治疗作用还是自然病程
- **出现晕针仍继续操作** → 应立即停针、平卧、观察，并记录处置过程

## H.7 出科考核

- 红旗筛查与神经查体（一票否决：漏筛红旗即不通过）
- 配穴依据与辨证一致性（30%）
- 刺激参数记录的可复现性（25%）
- 复评与调整逻辑（20%）
- 意外处置规范（15%）
