## H.1 本章要解决的问题

面瘫的处置分歧集中在两点：急性期该不该马上扎、扎多深多强；以及「是不是面瘫」这个前提——中枢性面瘫（额纹保留、伴肢体症状）与周围性面瘫的处理完全不同。轮转要养成两个动作：先做定位鉴别，再按分期定刺激量。

## H.2 本章目标（可检验）

- 完成周围性与中枢性面瘫的定位鉴别，并写出鉴别依据
- 按急性期/恢复期/后遗症期给出不同的取穴与刺激强度
- 记录 House-Brackmann 分级（或院内等效量表）作为基线与复评依据

## H.3 操作流程

1. 定位鉴别：额纹与皱眉（周围性受累、中枢性多保留）、眼睑闭合不全、口角歪斜方向、有无肢体无力/言语不清/视野缺损——伴后者按卒中流程处理
2. 病程分期：急性期（≤7 天）、恢复期（8 天–3 个月）、后遗症期（>3 个月）；记录发病确切日期
3. 病因线索：受凉吹风史、耳部疱疹与疼痛（提示带状疱疹）、耳闷耳鸣、糖尿病与免疫状态、近期病毒感染
4. 程度评定：House-Brackmann 分级（I–VI）或院内量表，记录基线；同时记眼睑闭合程度与流泪
5. 眼部保护：闭合不全者是否已用眼罩/人工泪液；角膜刺激症状是否出现——这是最需要立即处理的并发症
6. 辨证与选穴：风寒袭络、风热犯络、气血不足兼瘀；取穴（阳白、攒竹、四白、地仓、颊车、翳风、合谷、太冲等），逐穴依据
7. 分期定刺激量：急性期浅刺、轻刺激、留针短；恢复期可加电针（低频、弱强）与透刺；后遗症期可用滞针/透刺配合康复训练，避免长时间强刺激
8. 操作与观察：面部血管丰富，出针按压充分；观察有无血肿、面肌抽搐（提示刺激过强）
9. 自我训练交代：对着镜子做抬眉、闭眼、鼓腮、示齿，每日次数与组数写清
10. 记录：按 H.5 模板填「面瘫针灸接诊表」，含分期、分级、参数与训练
11. 复评：每 2 周复评一次分级；3 个月未恢复需评估是否转诊（神经科/耳鼻喉）
12. 后遗症期策略：联动征与面肌痉挛出现时，调整穴位与强度，不以「加量」作为唯一手段

## H.5 模板：面瘫针灸接诊表

| 字段 | 填写要求 |
|------|----------|
| 定位鉴别 | 额纹、闭眼、口角、肢体/言语/视野 |
| 分期 | 发病日期、急性/恢复/后遗症 |
| 病因线索 | 受凉、疱疹、耳部症状、糖尿病、免疫 |
| 程度分级 | House-Brackmann 或等效量表，基线值 |
| 眼部保护 | 闭合程度、眼罩/人工泪液、角膜刺激 |
| 辨证与选穴 | 证候、穴位、逐穴依据 |
| 刺激参数 | 深度、手法、电针频率强度、留针时间 |
| 反应与处置 | 血肿、面肌抽搐、晕针 |
| 自我训练 | 项目、次数、组数、复述确认 |
| 复评 | 分级变化、下一步（继续/调整/转诊） |

> 本表是本章的交付物：首诊填全；每次治疗记参数与反应，每 2 周填一次分级复评。

## H.6 常见失效与处置

- **未区分中枢与周围性** → 漏掉卒中信号是最大风险；额纹与肢体症状必查
- **急性期强刺激** → 可能加重神经水肿；分期定强度是基本纪律
- **不评分级只写「好转」** → 无量化就无法判断恢复程度与是否需要转诊
- **忽略眼部保护** → 暴露性角膜炎可致视力损害，必须当班处理
- **漏问耳部疱疹** → 带状疱疹面瘫需抗病毒，单靠针刺会延误
- **恢复期无限加量** → 面肌痉挛与联动征常因刺激过量；出现即减量调整

## H.7 出科考核

- 定位鉴别与红旗识别（一票否决）
- 分期与分级记录（30%）
- 选穴与刺激量匹配（25%）
- 眼部保护与自我训练交代（25%）
- 复评与转诊判断（20%）
