## H.1 本章要解决的问题

面瘫要先分清中枢性与周围性，再谈针灸时机。分期与选穴强度直接关系到后遗症。

## H.2 本章目标（可检验）

- 能用额纹、闭目、口角三项区分中枢与周围
- 能按急性期与恢复期调整取穴与刺激
- 能记录 House-Brackmann 分级

## H.3 操作流程

1. 查体：额纹、闭目力、鼻唇沟、鼓腮、示齿
2. 定性：额纹消失多为周围性；伴肢体症状须排查中枢
3. 分级：记录 House-Brackmann 级别
4. 选穴与时机：急性期轻刺激、恢复期可加电针
5. 记录：分级、方案、患者自评

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 五项面肌查体已完成
- [ ] 中枢/周围判断已写依据
- [ ] House-Brackmann 分级已记
- [ ] 急性期与恢复期方案已区分
- [ ] 眼部保护（眼罩/滴眼液）已交代
- [ ] 刺激量已记录
- [ ] 复诊间隔已定

## H.5 模板：面瘫接诊与分级表

| 字段 | 填写要求 |
|------|----------|
| 面肌查体 | 额纹、闭目、鼻唇沟、鼓腮、示齿 |
| 定性 | 中枢/周围 + 依据 |
| 分级 | House-Brackmann |
| 方案 | 穴位、刺激量、电针参数 |
| 眼部保护 | 交代内容 |

> 本表是本章的交付物：首诊与每次复诊各一张。

## H.6 常见失效与处置

- **不查额纹** → 中枢与周围分不开，可能漏掉卒中
- **急性期即用电针强刺激** → 可能加重神经水肿；按分期
- **不做眼部保护交代** → 角膜暴露可致损伤

## H.7 出科考核

- 定性判断（40%）
- 分级记录（30%）
- 方案分期匹配与宣教（30%）
