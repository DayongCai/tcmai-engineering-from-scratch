## H.1 本章要解决的问题

中医五官的外治法（薰眼、滴鼻、含漱、吹药）在门诊很常用，但适应证与操作规范常被含糊带过。

## H.2 本章目标（可检验）

- 能按证型选择一项五官外治技术
- 能完成操作前评估与禁忌筛查
- 能记录处方、操作与反应

## H.3 操作流程

1. 辨证：局部所见 + 全身症状，写出证型
2. 选法：薰、滴、含漱、吹药、穴位贴敷中选一
3. 筛禁忌：角膜损伤、鼓膜穿孔、过敏史、妊娠
4. 操作：温度、浓度、时长、频次逐项记录
5. 观察：局部刺激与全身反应，异常即停

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 证型判断有依据
- [ ] 外治法与证型对应
- [ ] 禁忌四项已筛
- [ ] 处方与操作参数已记
- [ ] 反应观察已写
- [ ] 患者宣教已复述
- [ ] 不良事件上报路径已知

## H.5 模板：五官外治操作记录

| 字段 | 填写要求 |
|------|----------|
| 证型 | 局部与全身依据 |
| 技术 | 薰/滴/含漱/吹药/贴敷 |
| 禁忌 | 角膜、鼓膜、过敏、妊娠 |
| 参数 | 温度、浓度、时长、频次 |
| 反应 | 局部与全身，处置 |

> 本表是本章的交付物：每次操作一张。

## H.6 常见失效与处置

- **鼓膜穿孔仍滴耳** → 可致中耳感染；须先查鼓膜
- **薰眼温度过高** → 角膜损伤不可逆；须控温
- **参数不记录** → 疗效与不良反应无法归因

## H.7 出科考核

- 辨证与技术匹配（40%）
- 禁忌筛查（一票否决项）
- 记录完整（30%）
