## H.1 本章要解决的问题

中医五官特色治疗（眼部熏洗、鼻部雾化与吹药、耳穴压豆、穴位贴敷、咽喉含漱与烙治）疗效依赖操作细节：药液温度、浓度、时间、体位，任何一项偏差都会影响效果甚至造成损伤。轮转要练的是「把经验变成参数」，并守住禁忌与安全边界。

## H.2 本章目标（可检验）

- 按辨证选择特色治疗并说明依据（证—法—部位—参数）
- 独立完成三项常见操作，全程记录药液参数与患者反应
- 识别并处置四类不良反应（烫伤、过敏、角膜刺激、晕厥）

## H.3 操作流程

1. 医嘱与辨证核对：诊断、证候、治疗项目；证与法不匹配时先与医师沟通并留痕
2. 禁忌筛查：眼部急性炎症与角膜损伤、皮肤破损、过敏史、妊娠、严重心肺疾病、空腹与疲劳、儿童配合度
3. 药液制备：组成、浓度、温度（眼部熏洗以温热不烫为度，一般不超过 40℃）、现配现用与保存时限
4. 眼部熏洗：体位（仰卧或坐位头略后仰）、距离与时间（10–15 分钟）、避免药液入眼、结束后擦干
5. 鼻部治疗：鼻腔清洁、雾化装置与药液量、吹药器具一人一用、避免深吸气时吹药
6. 耳穴压豆：选穴依据、按压方法与频次（每日 3–5 次，每次 1–2 分钟）、留豆 3–5 天、脱落与皮肤反应处理
7. 穴位贴敷：药物组成、贴敷时长（一般 2–6 小时，儿童更短）、皮肤反应观察（发红、水泡、瘙痒）
8. 咽喉含漱与局部处理：含漱液浓度与温度、含漱时长与频次、吞咽注意（儿童与老人防误吸）
9. 过程观察：面色、主诉、局部皮肤与黏膜反应；出现灼痛、流泪不止、皮疹立即停止
10. 不良反应处置：烫伤（冷水冲、覆盖）、过敏（停药清洗、上报）、角膜刺激（生理盐水冲洗、眼科会诊）、晕厥（平卧、测生命体征、呼叫）
11. 记录：按 H.5 模板填「中医五官特色治疗记录表」，药液参数与反应必填
12. 交代与复诊：居家操作方法、注意事项、复诊时点；请患者复述两项

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 鼻部器具一人一用，吹药时机已交代
- [ ] 耳穴选穴依据、按压频次、留豆天数已记
- [ ] 贴敷时长与皮肤反应已记
- [ ] 含漱浓度温度与防误吸措施已交代

## H.5 模板：中医五官特色治疗记录表

| 字段 | 填写要求 |
|------|----------|
| 医嘱与辨证 | 诊断、证候、治疗项目 |
| 禁忌筛查 | 七项逐条有/无与依据 |
| 药液参数 | 组成、浓度、温度、配制时间、保存时限 |
| 操作参数 | 部位、距离、时长、器具、频次 |
| 过程观察 | 面色、主诉、局部黏膜与皮肤反应 |
| 不良反应处置 | 类型、处置步骤、是否上报与会诊 |
| 交代 | 居家操作、注意事项、复述确认、复诊时点 |
| 签名 | 操作人、复核人、时间 |

> 本表是本章的交付物：每次操作一张；药液参数栏不得留空，皮肤黏膜反应每次必填。

## H.6 常见失效与处置

- **药液温度凭手感** → 眼部与黏膜对温度敏感；应控温并记录
- **不筛禁忌** → 急性炎症期熏洗可加重；过敏体质贴敷风险高
- **吹药时让患者深吸气** → 药粉误入气道，属操作错误
- **贴敷超时** → 水泡与色素沉着风险升高；时长必须记
- **含漱不防误吸** → 儿童与老人吞咽功能差，需坐位并少量
- **反应只写「无不适」** → 缺具体描述，异常无法追溯

## H.7 出科考核

- 辨证核对与禁忌筛查（一票否决）
- 药液与操作参数记录（30%）
- 不良反应处置（25%）
- 交代与复述（20%）
- 记录规范（15%）
