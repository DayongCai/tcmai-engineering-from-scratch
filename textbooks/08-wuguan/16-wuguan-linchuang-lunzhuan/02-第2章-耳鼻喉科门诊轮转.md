## H.1 本章要解决的问题

耳鼻喉的检查靠「看得见」：耳内镜看不到鼓膜就说「未见异常」，鼻内镜不收敛黏膜就下结论，是这一科最普遍的漏诊来源。另有几类红旗必须张口就问：单侧鼻塞带血、颈部包块、吞咽痛伴呼吸困难、突发性耳聋——它们都不是「按鼻炎治治看」的问题。

## H.2 本章目标（可检验）

- 完成耳、鼻、咽喉三部位的标准检查并记录可见结构
- 识别五类红旗征象并说明处置时限
- 完成一次纯音测听或声导抗的判读（按院内条件）

## H.3 操作流程

1. 红旗筛查：单侧鼻塞伴血性分泌物、颈部无痛性包块、吞咽痛伴呼吸困难或流涎、突发性听力下降、耳漏伴眩晕面瘫、外伤后鼻出血不止
2. 耳部：耳廓与耳周、外耳道（皮肤、分泌物、异物）、鼓膜（色泽、标志、有无穿孔与积液）；耳内镜记录可见范围
3. 听力：音叉试验（Rinne/Weber）左右对比；必要时纯音测听与声导抗，记录气骨导差
4. 鼻部：外鼻、鼻前庭、鼻腔（黏膜色泽、鼻甲大小、鼻中隔偏曲、分泌物性状、有无息肉与出血点）；必要时鼻内镜
5. 咽喉：口咽（扁桃体大小与渗出、咽后壁）、间接喉镜或电子喉镜（声带活动、有无新生物）、吞咽功能询问
6. 颈部：触诊分区（颌下、颈前、颈侧）、包块大小活动度质地、有无压痛、与吞咽的关系
7. 过敏与诱因：季节性、接触史、用药史（滴鼻剂滥用可致药物性鼻炎）
8. 记录：按 H.5 模板填「耳鼻喉检查记录表」，每部位写「可见结构 + 异常 + 未查原因」
9. 处置与交代：鼻腔冲洗与喷剂用法、耳道滴药方法、避免用力擤鼻；复诊时点
10. 转诊：突发性耳聋（时限以天计）、颈部包块、可疑新生物、外伤，写明转诊理由与时限
11. 器械与感染控制：内镜消毒记录、一人一用一消毒
12. 复盘：挑一例「单侧鼻塞按过敏性鼻炎治了两周」的案例，写清红旗与转诊时点

## H.5 模板：耳鼻喉检查记录表

| 字段 | 填写要求 |
|------|----------|
| 红旗筛查 | 六项逐条有/无与依据 |
| 耳部 | 耳廓、外耳道、鼓膜（色泽/标志/穿孔/积液） |
| 听力 | 音叉试验左右对比；测听与声导抗结果 |
| 鼻部 | 黏膜、鼻甲、鼻中隔、分泌物、息肉、出血点 |
| 咽喉 | 扁桃体、咽后壁、声带活动、检查方式 |
| 颈部 | 分区触诊、包块特征、与吞咽关系 |
| 用药史 | 滴鼻剂、抗生素、抗过敏药 |
| 处置与交代 | 冲洗/喷剂/滴药方法、复诊时点 |
| 转诊 | 理由、时限、接收科室 |
| 院感 | 内镜消毒记录编号 |

> 本表是本章的交付物：每部位一栏；未查项目须写原因（如患者不耐受、设备不可用）。

## H.6 常见失效与处置

- **看不到鼓膜就写「未见异常」** → 应写可见范围与未查原因；否则等于伪造阴性
- **不查颈部** → 颈部包块常由患者自己发现，医生不问就漏
- **突发性耳聋按「上火」处理** → 治疗窗以天计，延误影响恢复
- **长期用滴鼻剂不问** → 药物性鼻炎被当慢性鼻炎，越治越重
- **不记检查方式** → 间接喉镜与电子喉镜所见范围不同，结论可靠性不同
- **内镜消毒不核** → 院感风险，属底线问题

## H.7 出科考核

- 红旗筛查与转诊时限（一票否决）
- 三部位检查完整性（30%）
- 未查原因与所见范围记录（25%）
- 交代与院感（15%）
