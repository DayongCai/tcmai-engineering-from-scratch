## H.1 本章要解决的问题

耳鼻喉的难点在「看不见的地方」：鼻咽、喉部需要内镜，声嘶超过两周必须看到声带。

## H.2 本章目标（可检验）

- 能完成耳、鼻、咽、喉四部位基础检查
- 能判断何时必须做内镜
- 能记录听力与声嘶的客观描述

## H.3 操作流程

1. 耳：耳道、鼓膜、音叉试验（Rinne/Weber）
2. 鼻：鼻甲、鼻中隔、分泌物性质、嗅觉
3. 咽：扁桃体大小、咽后壁、有无脓性分泌物
4. 喉：间接喉镜或内镜，观察声带活动与形态
5. 记录：部位、所见、建议检查

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 耳道与鼓膜已查
- [ ] 音叉试验双侧已做
- [ ] 鼻甲与鼻中隔已描述
- [ ] 咽部与扁桃体已记录
- [ ] 声嘶超过两周已安排内镜
- [ ] 颈部淋巴结已触诊
- [ ] 检查建议与理由已写

## H.5 模板：耳鼻喉四部位检查表

| 字段 | 填写要求 |
|------|----------|
| 耳 | 耳道、鼓膜、音叉结果 |
| 鼻 | 鼻甲、中隔、分泌物 |
| 咽 | 扁桃体、咽后壁 |
| 喉 | 声带形态与活动 |
| 淋巴结 | 颈部触诊 |
| 建议 | 内镜/听力学检查及理由 |

> 本表是本章的交付物：每例一张，内镜建议须写理由。

## H.6 常见失效与处置

- **声嘶只开药不做内镜** → 超过两周必须看声带，排除器质性病变
- **音叉只做一侧** → 需双侧对比才能判断传导与感音
- **不问鼻出血的诱因** → 抗凝药与高血压决定处置方式

## H.7 出科考核

- 四部位检查（40%）
- 内镜指征（一票否决项）
- 记录与建议（30%）
