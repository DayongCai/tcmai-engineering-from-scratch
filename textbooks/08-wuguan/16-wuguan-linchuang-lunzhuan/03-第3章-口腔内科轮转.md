## H.1 本章要解决的问题

口腔内科最常见的是「牙痛就说牙髓炎」。定位、牙周与黏膜三条线不分，处置就会错。

## H.2 本章目标（可检验）

- 能完成牙位、龋、牙髓、牙周三部分评估
- 能区分牙髓炎与牙周炎的主诉差异
- 能记录探诊深度与松动度

## H.3 操作流程

1. 定位：问痛的性质、诱因、能否指明患牙
2. 查龋：视诊 + 探诊，记录牙位与面
3. 查牙髓：冷热诊、叩诊、电活力
4. 查牙周：探诊深度、出血、松动度、附着丧失
5. 查黏膜：部位、形态、边界、有无可疑病损

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 牙位按 FDI 记录
- [ ] 龋的部位与深度已记
- [ ] 冷热诊与叩诊结果已记
- [ ] 探诊深度记六个位点
- [ ] 松动度已分级
- [ ] 黏膜病损已描述并判断是否需活检
- [ ] 影像申请已写理由

## H.5 模板：口腔内科检查表

| 字段 | 填写要求 |
|------|----------|
| 牙位与主诉 | FDI 牙位、痛性特点 |
| 龋 | 部位、深度、探诊 |
| 牙髓 | 冷热诊、叩诊、活力 |
| 牙周 | 六个位点探诊、松动度 |
| 黏膜 | 部位、形态、处理 |
| 影像 | 申请与理由 |

> 本表是本章的交付物：每位患者一张，取模前必备。

## H.6 常见失效与处置

- **不记探诊深度** → 牙周治疗无从谈起；六位点必须记
- **黏膜病损只写「溃疡」** → 边界与病程决定是否活检
- **叩诊缺失** → 无法区分牙髓炎与根尖周炎

## H.7 出科考核

- 三线评估（40%）
- 牙周记录（30%）
- 黏膜与活检判断（30%）
