## H.1 本章要解决的问题

口腔内科的检查靠「四查」：视、探、叩、扪，落一项就可能把深龋当敏感、把根尖周炎当牙髓炎。实习生最常见的错误是直接看主诉牙，而漏掉邻牙、对颌牙与全口状况——口腔是整体，一颗牙的问题常常不是孤立的。

## H.2 本章目标（可检验）

- 完成四查（视诊、探诊、叩诊、扪诊）并记录牙位、牙周与黏膜情况
- 用牙位表示法准确记录病变，能区分龋、牙髓炎、根尖周炎、牙周炎的表现
- 给出治疗计划与口腔卫生指导，并说明复诊时点

## H.3 操作流程

1. 主诉与病史：疼痛性质（自发/激发、夜间加重、定位与否）、持续时间、诱因（冷热酸甜、咬合）、既往治疗
2. 视诊：全口牙列、龋坏部位与深度、充填体边缘、牙石与色素、黏膜色泽与形态
3. 探诊：探针查龋洞深度与是否露髓、牙周袋深度（六个位点/牙）、附着丧失、探诊出血
4. 叩诊：垂直与水平叩诊，记录疼痛程度（-/+ /++）；与邻牙对照
5. 扪诊：根尖区黏膜压痛、波动感、肿胀范围
6. 动度与咬合：牙松动度（I–III 度）、咬合关系、有无早接触与创伤
7. 影像：根尖片或全景片指征（深龋、根尖病变、牙周骨吸收、阻生牙）；记录片号与所见
8. 诊断与鉴别：龋（冷热一过性敏感）、牙髓炎（自发痛、夜间痛、定位不清）、根尖周炎（叩痛、咬合痛、定位明确）、牙周炎（牙周袋、松动、出血）
9. 治疗计划：本次处置（充填/开髓引流/洁治）、后续计划、需转诊（拔牙、正畸、修复）
10. 口腔卫生指导：刷牙方法（巴氏）、牙线/间隙刷使用、含氟制剂；请患者复述要点
11. 记录：按 H.5 模板填「口腔检查与治疗记录表」，牙位用标准表示法
12. 复盘：挑一例「主诉牙治疗后仍痛，实为邻牙根尖周炎」的案例，写清四查中哪一步纠正了判断

## H.5 模板：口腔检查与治疗记录表

| 字段 | 填写要求 |
|------|----------|
| 主诉与病史 | 疼痛性质、诱因、时程、既往治疗 |
| 视诊 | 龋坏、充填体、牙石、黏膜 |
| 探诊 | 龋洞深度、牙周袋深度与出血 |
| 叩诊 | 垂直/水平，与邻牙对照，程度分级 |
| 扪诊 | 根尖区压痛、波动、肿胀范围 |
| 动度与咬合 | 松动度、咬合关系、早接触 |
| 影像 | 片号、指征、所见 |
| 诊断与鉴别 | 龋/牙髓炎/根尖周炎/牙周炎的依据 |
| 治疗计划 | 本次处置、后续计划、转诊项 |
| 指导与复诊 | 刷牙与牙线方法、复述确认、复诊时点 |

> 本表是本章的交付物：每次就诊一张；牙位图可在表上勾画，治疗前后对照。

## H.6 常见失效与处置

- **只看主诉牙** → 邻牙与对颌牙常是真正病因，必须全口视诊
- **不探牙周袋** → 牙周炎被当牙龈炎，治疗方向错
- **叩诊不与邻牙对照** → 无法判断是患牙还是邻牙敏感
- **影像无指征滥拍** → 增加负担；指征要写清
- **诊断靠「像」** → 四类疾病靠具体表现区分，不能凭印象
- **不做口腔卫生指导** → 治疗后复发率高，等于治标不治本

## H.7 出科考核

- 四查执行与记录（35%）
- 诊断与鉴别依据（30%）
- 治疗计划与转诊判断（20%）
- 指导与复述（15%）
