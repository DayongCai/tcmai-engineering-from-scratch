## H.1 本章要解决的问题

眼科的急症窗口以小时计：急性闭角型青光眼、视网膜中央动脉阻塞，误判一次就是永久视力损伤。

## H.2 本章目标（可检验）

- 能按顺序完成基础眼科检查
- 能识别需要急诊处理的四种情况
- 能记录视力、眼压、眼底所见

## H.3 操作流程

1. 问诊：视力下降的速度、单眼双眼、伴眼痛头痛恶心
2. 查视力：裸眼与矫正，分别记录
3. 查眼前段：结膜、角膜、前房、瞳孔
4. 测眼压：记录数值与测量方式
5. 查眼底：视盘、血管、黄斑，必要时散瞳并交代风险

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 视力下降速度与伴随症已问
- [ ] 裸眼与矫正视力已分别记录
- [ ] 眼前段四项已查
- [ ] 眼压数值与方式已记
- [ ] 瞳孔对光反射已查
- [ ] 眼底三区已描述
- [ ] 急诊指征已逐条判断

## H.5 模板：眼科接诊记录表

| 字段 | 填写要求 |
|------|----------|
| 主诉与速度 | 下降速度、单双眼、伴随症 |
| 视力 | 裸眼 / 矫正 |
| 眼前段 | 结膜、角膜、前房、瞳孔 |
| 眼压 | 数值、方式、时间 |
| 眼底 | 视盘、血管、黄斑 |
| 急诊判断 | 是否需即刻处理及依据 |

> 本表是本章的交付物：每位初诊患者一张。

## H.6 常见失效与处置

- **不测眼压** → 青光眼漏诊；眼压是常规项
- **只记裸眼视力** → 矫正视力才反映视功能
- **散瞳不问禁忌** → 浅前房者散瞳可诱发急性发作

## H.7 出科考核

- 检查顺序完整（40%）
- 急诊识别（一票否决项）
- 记录规范（30%）
