## H.1 本章要解决的问题

眼科的急症窗口极短：急性闭角型青光眼、视网膜动脉阻塞、化学伤，处置延迟以小时计。而门诊最常见的错误是「先查视力再做其他」这个顺序被颠倒，或眼压没测就按结膜炎处理。轮转要把检查顺序与红旗筛查变成不可省略的动作。

## H.2 本章目标（可检验）

- 按标准顺序完成眼科基础检查：视力（裸眼/矫正）、眼压、裂隙灯前后节、眼底
- 识别五类眼科急症并说出处置时限
- 记录「看到了什么/没看到什么」，包括阴性所见

## H.3 操作流程

1. 红旗筛查：突发视力下降、眼痛伴头痛恶心呕吐、化学伤、眼球穿通伤、视野缺损、闪光感伴飞蚊骤增 —— 命中即优先处理并呼叫带教
2. 视力：裸眼与针孔/矫正视力，分别记左右眼；记录检查距离与是否戴镜
3. 眼压：测量方式（非接触/压平）、左右眼数值与测量时间；高眼压伴角膜水肿需警惕
4. 外眼与眼睑：红肿、分泌物、倒睫、睑内外翻、眼球突出与运动
5. 裂隙灯：结膜（充血类型）、角膜（透明度、染色）、前房（深度、细胞闪光）、虹膜、晶状体（混浊程度）
6. 瞳孔与对光反射：大小、形态、直接与间接反射、有无相对性传入障碍
7. 眼底（散瞳前评估前房深度）：视盘边界与杯盘比、视网膜血管、黄斑、有无出血渗出
8. 化学伤处置：立即大量生理盐水冲洗（至少 15–30 分钟），记录冲洗开始时间与 pH 复测结果
9. 记录：按 H.5 模板填「眼科检查记录表」，左右眼分栏，阴性所见必写
10. 用药与交代：滴眼液使用方法（间隔、顺序、按压泪囊）、复诊时点、需立即返院的症状
11. 转诊判断：需专科处理的情形（视网膜脱离、眼内炎、视神经病变）写明转诊理由与时限
12. 复盘：挑一例「先按结膜炎处理、后发现眼压高」的案例，写清哪一步可以更早识别

## H.5 模板：眼科检查记录表（左右眼分栏）

| 字段 | 填写要求 |
|------|----------|
| 红旗筛查 | 六项逐条有/无与依据 |
| 视力 | 裸眼、针孔/矫正，左右眼分列 |
| 眼压 | 数值、测量方式、时间 |
| 外眼 | 眼睑、结膜充血类型、分泌物、眼球运动 |
| 裂隙灯 | 角膜、前房深度与细胞闪光、虹膜、晶状体 |
| 瞳孔 | 大小、形态、直接/间接反射 |
| 眼底 | 视盘杯盘比、血管、黄斑、出血渗出 |
| 急症处置 | 化学伤冲洗时间与 pH；穿通伤保护 |
| 交代 | 用药方法、复诊时点、返院症状 |
| 转诊 | 理由、时限、接收科室 |

> 本表是本章的交付物：每位患者一张；急症病例在表头标注时间点，随病历归档。

## H.6 常见失效与处置

- **不测眼压** → 急性闭角型青光眼被当结膜炎处理，可致不可逆视力损害
- **化学伤先查视力再冲洗** → 冲洗优先级最高；延迟冲洗加重损伤
- **只查患眼** → 眼科必须双眼对照，健侧是重要参照
- **裂隙灯只看角膜** → 前房深度与细胞闪光是青光眼与葡萄膜炎的关键
- **眼底不散瞳也写「未见异常」** → 未散瞳的所见有限，应写清检查条件
- **阴性所见不写** → 无法判断是否漏查，也无法在随访中对比

## H.7 出科考核

- 红旗筛查与急症处置（一票否决：漏筛红旗或化学伤未冲洗即不通过）
- 检查顺序与完整性（30%）
- 双眼对照与阴性所见记录（25%）
- 交代与转诊（15%）
