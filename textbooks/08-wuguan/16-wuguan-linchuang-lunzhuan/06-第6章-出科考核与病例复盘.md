## H.1 本章要解决的问题

五官科出科的关键不是「看过多少病人」，而是「检查做全了没有、异常认出来了没有」。考核用一份完整检查记录 + 一次现场操作 + 一次影像/图像判读，把这三条钉死：顺序不能乱、阴性要写、红旗要认。

## H.2 本章目标（可检验）

- 提交一份含完整检查顺序与阴性所见的病例记录
- 现场完成一次专科检查（眼科或耳鼻喉抽签）并说出每一步的目的
- 判读 5 份图像/影像，指出主要所见与需警惕的问题

## H.3 操作流程

1. 材料准备：1 份主病例（优先选有红旗或转折的）+ 5 份检查记录
2. 记录自检：检查顺序、左右对照、阴性所见、未查原因四项是否齐全
3. 红旗清单：为本科室各部位写出「必须立即处理」的征象各三条
4. 现场操作：抽签完成一套检查，边做边说出每一步目的与正常所见
5. 图像判读：裂隙灯照片/眼底照/耳内镜/全景片各若干，说出主要所见、可疑处、下一步
6. 病例汇报：10 分钟讲病例——主诉、检查顺序与所见、判断依据、处置与转诊
7. 反证准备：为诊断准备一条反证，说明「若反证成立会怎样」
8. 安全问答：急症处置（化学伤、突发性耳聋、口底肿胀、术后出血）步骤与时限
9. 评分与反馈：按 H.7 五项打分，记录扣分点
10. 材料归档：病例、检查记录、操作评分、判读记录四件一并交
11. 经验提炼：三条可迁移规则（如「化学伤先冲洗后检查」）
12. 补强计划：针对最低分项的两周改进动作

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 主病例含检查顺序、左右对照、阴性所见、未查原因
- [ ] 各部位红旗各三条已写出
- [ ] 现场操作步骤完整并说出目的
- [ ] 图像判读 5 份，含主要所见与下一步
- [ ] 病例汇报 10 分钟，四段结构完整
- [ ] 每个诊断备有一条反证
- [ ] 安全问答覆盖四类急症与时限
- [ ] 评分表五项已打分并记录扣分点
- [ ] 四件材料归档签收
- [ ] 三条可迁移规则已写
- [ ] 最低分项有改进计划
- [ ] 记录中无「未见异常」而无检查条件

## H.5 模板：五官科出科考核评分表

| 字段 | 填写要求 |
|------|----------|
| 病例完整度（30%） | 顺序、左右对照、阴性所见、未查原因 |
| 现场操作（25%） | 步骤完整、目的清楚、手法规范 |
| 图像判读（20%） | 5 份，所见准确，下一步合理 |
| 安全问答（一票否决） | 四类急症处置与时限 |
| 汇报与反证（15%） | 10 分钟结构、反证回答 |
| 可迁移规则（10%） | 三条具体可执行 |
| 扣分记录 | 逐项扣分点与改进建议 |
| 签名与日期 | 评分人、复核人、日期 |

> 本表是本章的交付物：现场逐项打分；操作与判读分开计分，一票否决项先判。

## H.6 常见失效与处置

- **检查顺序颠倒** → 化学伤未先冲洗、眼压未测先散瞳，都是顺序错误
- **阴性所见不写** → 无法证明查过，也无法在随访中对比
- **判读只说「正常」** → 需说出主要结构与可疑处，否则无法评估能力
- **红旗说不出** → 安全问答是一票否决项
- **汇报只讲处置** → 没有检查所见与判断依据，等于没讲
- **材料临时补** → 检查记录的真实性经不起追问

## H.7 出科考核

- 病例完整度（30%）
- 现场操作（25%）
- 图像判读（20%）
- 安全问答（一票否决）
- 汇报与规则（25%）
