## H.1 本章要解决的问题

颌面外科的门槛是「出血与气道」：拔牙也可能出大问题，术前评估比手术本身更重要。

## H.2 本章目标（可检验）

- 能完成拔牙或小手术的术前评估
- 能识别需要转诊的全身风险
- 能按流程完成术后观察与交代

## H.3 操作流程

1. 问病：高血压、糖尿病、抗凝药、心脏病史、妊娠
2. 查局部：牙位、松动度、冠周炎症、张口度
3. 看影像：牙根形态、与上颌窦或下颌管关系
4. 评风险：出血、感染、神经损伤、上颌窦交通
5. 交代：术后止血、饮食、冷热敷、复诊指征

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 五项全身病史已问
- [ ] 抗凝与抗血小板用药已记录
- [ ] 张口度与局部炎症已评估
- [ ] 影像与解剖关系已看
- [ ] 四项风险已逐条判断
- [ ] 术后交代要点已复述
- [ ] 急诊返院指征已写

## H.5 模板：颌面外科术前评估表

| 字段 | 填写要求 |
|------|----------|
| 全身病史 | 血压、血糖、心脏、妊娠 |
| 用药 | 抗凝/抗血小板 |
| 局部 | 牙位、炎症、张口度 |
| 影像 | 牙根与邻近结构 |
| 风险 | 出血/感染/神经/窦交通 |
| 交代 | 术后要点与返院指征 |

> 本表是本章的交付物：每例拔牙或小手术前填写。

## H.6 常见失效与处置

- **不问抗凝药** → 术后出血风险高；须记录并会诊
- **不看影像** → 牙根入窦或近下颌管会出并发症
- **术后交代只给纸条** → 须让患者复述关键两条

## H.7 出科考核

- 术前评估（一票否决项）
- 风险判断（40%）
- 术后交代（30%）
