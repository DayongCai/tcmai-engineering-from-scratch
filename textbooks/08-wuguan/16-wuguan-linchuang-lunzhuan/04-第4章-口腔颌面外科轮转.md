## H.1 本章要解决的问题

颌面外科的风险点集中在两处：气道与出血。颌面部肿胀、外伤、术后血肿都可能迅速影响通气；而颌面部血供丰富，出血不易自止。轮转要把「先保气道」变成条件反射，并在每次操作前说清解剖风险（神经、血管、唾液腺导管）。

## H.2 本章目标（可检验）

- 完成颌面外科术前评估：气道、肿胀范围、张口度、神经功能、出血风险
- 掌握拔牙与常见小手术的适应证、禁忌与并发症识别
- 能按流程处置四类常见并发症（出血、肿胀、感染、神经损伤）

## H.3 操作流程

1. 气道评估：张口度（指宽）、舌体与口底肿胀、咽部视野、有无呼吸费力与发音改变；口底蜂窝织炎属急症
2. 局部检查：肿胀部位与范围（画界或拍照）、皮温、波动感、瘘管、唾液腺导管开口分泌
3. 神经功能：三叉神经分布区感觉、面神经各支运动（抬眉、闭眼、鼓腮、示齿）
4. 影像与化验：全景片/CT 指征、凝血功能、血糖与感染指标
5. 既往与用药：抗凝/抗血小板、双膦酸盐用药史（颌骨坏死风险）、糖尿病、放疗史
6. 拔牙适应证与禁忌：适应证写明；禁忌含未控制高血压、凝血异常、急性感染期、放疗后风险区、双膦酸盐长期用药
7. 操作前准备：器械与吸引、体位、消毒、麻醉方式与剂量（记麻药名称、浓度、剂量）
8. 操作与观察：术中出血量、患者面色与主诉；出现晕厥或过度换气立即停止
9. 术后交代：咬棉时间、冷敷、饮食、口腔清洁、禁忌（吸吮、漱口过猛、吸烟）；请患者复述
10. 并发症识别与处置：出血（压迫、明胶海绵、必要时缝合与转诊）、肿胀（冷敷与抬高）、感染（引流与抗生素）、神经损伤（记录并随访）
11. 记录：按 H.5 模板填「颌面外科操作记录表」，含麻醉剂量与术中出血
12. 复盘：挑一例「术后出血因未停抗凝」的案例，写清术前该问什么

## H.5 模板：颌面外科操作记录表

| 字段 | 填写要求 |
|------|----------|
| 气道评估 | 张口度、肿胀范围、发音与呼吸、咽部视野 |
| 局部检查 | 肿胀范围、皮温、波动感、瘘管、导管分泌 |
| 神经功能 | 三叉感觉、面神经各支运动 |
| 影像与化验 | 片号/CT、凝血、血糖、感染指标 |
| 用药史 | 抗凝/抗血小板、双膦酸盐、糖尿病、放疗 |
| 适应证与禁忌 | 逐条核对结果 |
| 麻醉 | 方式、药名、浓度、剂量 |
| 术中 | 出血量、患者反应、异常处置 |
| 术后交代 | 咬棉、冷敷、饮食、清洁、禁忌 + 复述 |
| 并发症与随访 | 类型、处置、随访时点 |

> 本表是本章的交付物：每次操作一张；术前评估栏必须在操作前完成，术后栏当场填写。

## H.6 常见失效与处置

- **不评估气道** → 口底肿胀可在数小时内窒息，是最致命的漏项
- **不问抗凝与双膦酸盐** → 术中术后出血与颌骨坏死风险显著升高
- **麻药剂量不记** → 过量反应无法追溯，也无法复盘
- **术后交代只说「注意点」** → 必须具体到咬棉时长、冷敷方式与禁忌动作
- **把肿胀当正常反应** → 持续加重伴发热需考虑感染并引流
- **神经损伤不记录** → 术后出现麻木无基线对比，纠纷时无法自证

## H.7 出科考核

- 气道与出血风险评估（一票否决：未评估气道即不通过）
- 适应证禁忌与用药史（25%）
- 操作记录完整性（25%）
- 术后交代与并发症处置（25%）
