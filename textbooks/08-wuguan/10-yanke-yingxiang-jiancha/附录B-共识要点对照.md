## 二、共识给出、本教材此前留白的数值（现在有出处了）

本教材第一版按「无底本」定位，凡数值一律写「按所在机构规范」。拿到本共识后，下列各项**改为引用共识值**，
并在正文标「共识·第X节」；引用时保留「设备刻度」「多数机构」这类限定语，不把共识值升级为强制标准。

| 项 | 共识值 | 出处 |
|---|---|---|
| 眼底照相视野角 | 45° 或 35°，至少含视盘·黄斑·颞侧上下血管弓 | 共识·第二节 |
| 散瞳后不适时长 | 约 4–6 小时；瞳孔 <3mm 或需拍周边时散瞳，先排闭角型青光眼 | 共识·第二节 |
| DR 拍摄范围 | ETDRS 7 个标准视野 | 共识·第二节 |
| OCT 黄斑扫描 | 放射状 6mm×6mm、格栅、中心凹单线 | 共识·第三节 |
| OCT 信号强度 | ≥40dB（设备刻度值） | 共识·第三节 |
| OCTA 扫描范围 | 3mm×3mm 或 6mm×6mm | 共识·第三节 |
| FFA 注射 | 荧光素钠 3–5ml（10%–20%），3–5 秒推注；注射与计时同步 | 共识·第四节 |
| FFA 时相 | 动脉期 0–10s、静脉期 10–20s、晚期 5–15min | 共识·第四节 |
| ICGA 时相 | 早期 10–30s 看脉络膜循环，晚期看强/弱荧光 | 共识·第四节 |
| B 超探头频率 | 7.5–10MHz；TGC 调至玻璃体无回声、球壁强回声 | 共识·第五节 |
| UBM 频率 | 35–50MHz；水浴法避免压迫角膜；关注 AOD500 与 TIA | 共识·第五节 |

## 三、三块覆盖不到的（如实登记，不硬塞进 8 章）

1. **CT / MRI（共识第六节）**：本课 8 章按课程章 1:1，没有影像科章；这部分只能在本附录与第 4 章 N.6 的接口段提一句，
   不新增章。若后续课程增设「眼科影像科轮转」，再单列成章。
2. **远程医疗影像（第十三节）**：涉及筛查网络与阅片资质，属卫生管理范畴，本课不展开；第 8 章 N.6 只写数据合规交集。
3. **检查室消毒与院感防控（第十四节）**：属机构感控规程，本课只引用「高频接触面每人次消毒」这一条判据，
   不给消毒剂配比与作用时间（那是感控科的文件，不是本课的范围）。
