## 参考教材怎么用（以及不做什么）

参考书是 **《嗓音医学》第 2 版（韩德民、Robert T. Sataloff、徐文主编，人民卫生出版社 2017，541 页，826 千字）**，
登记在 `standards/zhongyi-sangyin-yixue/reference-modern.json`：书名、版次、主编、页数、ISBN、
PDF sha256 `55962b37…`（160 MB 扫描本，无文本层）、篇章节结构、课程章 ↔ 参考篇章对应表。

**它是西医耳鼻咽喉科学著作，本书是中医学教材**，所以边界比结构更重要：

1. **只借解剖、生理、评估方法与疾病分类**（喉的应用解剖、嗓音的听感知与声学评估、声带病变分类）；
   中医的病因病机、辨证分型、治法治则与方药，全部来自课程正文与中医文献。
2. **不互换结论。** 不能用「声带小结」替代「喉喑」的辨证，也不能用 GRBAS 评分替代中医证候判断——
   两套体系各有各的问题意识，接口写在每章 N.4，不在正文里混写。
3. **引用只标篇·章**（「参考《嗓音医学》第 2 版 第三篇·第一章」），不标页码：扫描本无页码锚点，
   换印次即失效；PDF 与 OCR 全文不入库（版权）。

## 与课程正文的关系

教材章 = 课程章（同号同名同主题）。课程章讲「临床怎么做」（可执行、可判分），
教材章讲「为什么这样做、这个说法丢掉了什么、与相邻学科怎么接口」（N.1–N.5 判断层）。
两边数字同源，任何一边改动都要重跑：

```bash
node textbooks/build_book.js --check        # 字数与章数对账
npm run textbooks:board                     # 教材看板（逐门对账）
```
