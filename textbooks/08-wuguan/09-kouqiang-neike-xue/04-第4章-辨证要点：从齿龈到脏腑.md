## N.1 概念与出处

辨证不是从证型表里挑一个最像的，而是按次序把证据收拢：先定病位，再定病性，然后归脏腑，最后落成记录。四步走完，证名自然浮出来；跳过任何一步，证名就是猜的。

| 概念 | 出处 | 一句定义 |
|---|---|---|
| 病位 | 《口齿类要·齿痛三》分经之说 | 病在齿、在龈、在黏膜、在涎唾、在口气，抑或波及颌面 |
| 病性 | 后世八纲与气血津液辨证通义 | 属火（实火、虚火）、属虚（气、血、阴、阳）、属湿、属风、属瘀、属虫 |
| 脏腑归属 | 《灵枢·经脉》手足阳明入上下齿；《素问》肾主骨、脾开窍于口 | 把病位与病性挂到肾、胃、大肠、脾、心、肝上，作为治法落点 |
| 主症 | 课程正文牙宣、牙痛两节 | 最能定性的那一两个症状，如「龈肿溢脓」「齿动龈萎」「溃点反复」 |
| 舌脉 | 同上 | 虚实难辨时的最后一票，尤以脉之有力无力为要 |
| 证名 | 本项目体例 | 以「病位＋病性＋脏腑」三要素组合命名，如「胃火龈肿」「肾虚齿动」 |
| 记录字段 | 本章 4.1.4 | 辨证所需的最小信息集，缺一项则虚实可能判反 |
| 红旗 | 现行口腔科与内科通例（此为现代认识） | 提示需立即转诊或排除恶性、感染扩散、全身疾病的征象 |

**先立一条纪律：证名是结论，不是起点。** 初学最常见的错，是先想好一个证型，再去凑症状。正确的次序相反：先把病位定死，再把病性定死，脏腑归属是前两步的必然结果，而不是另一次猜测。若三步之后仍不能归一，宁肯写「病位在龈，病性属湿热夹虚，脏腑涉胃与脾，未定」，也不要硬套一个漂亮的证名。

### 4.1.1 第一步：定病位

病位不是「哪里痛」，而是「哪一层组织在变」。同一处疼痛，病位可以在齿、在龈、在黏膜，甚至不在口内。

| 病位 | 主要表现 | 首问 |
|---|---|---|
| 齿（质） | 龋洞、变色、磨耗、裂纹、遇冷热酸甜而痛、齿脆、齿动 | 肾精与阳明 |
| 龈（肉） | 红肿、出血、溢脓、萎缩、根露、口臭 | 胃火、脾虚、湿热 |
| 黏膜 | 溃疡、糜烂、斑纹、假膜、灼痛 | 心脾、三焦、阴虚 |
| 涎唾 | 涎多口黏、口干唾少、口甜、口苦 | 脾、肾 |
| 口气 | 臭秽、酸腐、腥臭 | 胃、湿热、龋坏 |
| 颌面关节 | 面肿、张口受限、弹响、咀嚼痛 | 转诊指征优先于辨证 |

这一步的用处，是**把「牙痛」这个主诉拆开**。牙痛可以是齿质之病（龋深及髓），可以是龈肉之病（牙周脓肿），可以是黏膜之病（溃疡波及龈），也可以是颌面之病（上颌窦炎、关节紊乱、神经痛）。四种病位，四条思路，治法互不相通。所以第一问永远是：**痛在齿，还是在龈，还是在这两者之外？**

病位还有一个常被忽略的情形：**重叠**。龈袋溢脓而根面有龋，齿动而黏膜有斑，这不是两个病位，而是一条链上的两段。此时定病位要问一句「哪一处是先起的」，先起者为原发，后起者为波及；治法随原发处定，波及处随证加减。把重叠当并列，处方就会左右为难。

### 4.1.2 第二步：定病性

病性只需回答一个问题：**当下主要是邪盛，还是正虚？** 这是第一刀，切完再细分。

**属火者**，看三条：起病急、痛而拒按、局部红肿高起色鲜。再分虚实：实火者兼口臭、便秘、渴喜冷饮、脉洪数；虚火者兼口干夜甚、齿动、舌红少苔、脉细数。

**属虚者**，看四条：病程久、隐痛喜按、色淡质软、劳则加重。再分气血阴阳：气虚则倦怠无力、纳少便溏；血虚则色淡白、心悸、渗血色淡；阴虚则干（口干、唾少、舌燥）而动摇；阳虚则冷（畏寒、肢冷）而水肿。

**属湿者**，看黏与腻：口黏、苔腻、溢脓黄稠或白腐、大便黏滞。湿常与热合，故多称湿热；亦常与虚并存，故有脾虚湿困。

**属风者**，看动与急：痛处游走、遇风触发、痒、肿而忽起忽消。

**属瘀者**，看色与痛：痛有定处如刺、色暗、久痛不愈、舌有瘀点。口腔科的瘀多见于久病、外伤、术后。

**属虫者**，看洞：牙体有洞而痛随刺激，即龋；「虫」是过程之喻，不指实体。

六性之中，火与虚是主干，湿、风、瘀、虫是兼夹。

还有一层次序要说清：**先辨虚实，再辨何邪。** 虚实定的是攻补的大方向，何邪定的是具体用药的落点。次序若倒，先想「是火还是湿」，再想「该清还是该补」，就会出现「湿热而用温补」「脾虚而用苦寒」这类方向性错误。方向错了，剂量再准也无用。**兼夹不必求全，但不可漏湿**——口齿科的脓、黏、腻，十之七八与湿有关，漏了湿，清热往往去而复来。

### 4.1.3 第三步：归脏腑

病位与病性定了，脏腑归属是推出来的。下表给的是「定位线索」，不是「确诊依据」。

| 脏腑 | 定位线索 | 常见证 | 代表方（只举方名） |
|---|---|---|---|
| 肾 | 齿动、齿脆、齿槁、根露、腰膝酸软、夜尿、脉沉细 | 肾阴虚、肾气不足 | 六味地黄丸（《小儿药证直诀》） |
| 胃 | 上龈肿、口臭、渴喜冷饮、便秘、脉洪数 | 胃火炽盛 | 清胃散（《兰室秘藏》） |
| 大肠 | 下龈肿、便结、腹胀 | 大肠积热 | 凉膈散（《太平惠民和剂局方》）一类 |
| 脾 | 龈色淡、萎缩、渗血淡红、倦怠、便溏、涎多 | 脾气虚、脾虚湿困 | 补中益气汤（《脾胃论》） |
| 心 | 口疮生于舌、舌尖红、心烦、失眠 | 心脾积热 | 导赤散（《小儿药证直诀》）一类 |
| 肝 | 随怒而发、经前加重、口苦、脉弦 | 肝郁化火 | 丹栀逍遥散（《内科摘要》）一类 |

三件事要说清。

**其一，多脏并见是常态。** 牙宣就是胃、肾、脾三脏同病：胃火为标，肾虚为本，脾虚为兼。若强行归于一脏，必有一半症状无处安放。

**其二，归脏腑的目的是定治法，不是贴标签。** 归到肾，意味着要考虑补；归到胃，意味着要考虑清；归到脾，意味着要考虑运。若归了脏腑而治法不变，这一步就白做了。

**其三，脏腑归属要与病性交叉验证。** 同样「齿动」，若脉洪数、龈红肿，是胃火熏灼而齿浮，清之则安；若脉细数、龈萎缩，是肾虚不固，补之乃坚。同一位，两性，两脏，两法——这就是为什么不能跳过病性直接归脏腑。

### 4.1.4 第四步：落记录

辨证的最后一关是记录。记录不是抄病历格式，而是**把判断所依赖的证据固定下来**，以便复诊时对照、以便他人复核。下面这张表是本课的最小字段集。

| 字段 | 记什么 | 漏了会怎样 |
|---|---|---|
| 主诉与病程 | 主症＋时长（几日／几年），起病缓急 | 虚实的第一判据丢失 |
| 疼痛五问 | 性质（胀、跳、隐、刺）、诱因（冷热酸甜、咬合、风吹）、昼夜、能否定位、是否放射 | 齿病与龈病、可复与不可复分不清 |
| 龈之色形质 | 色（鲜红／暗红／淡白）、形（肿／萎／增生）、质（软／硬）、有无点彩 | 胃火与脾虚分不清 |
| 出血与溢脓 | 出血量与色、自发出血还是刺激后出血；脓之稀稠、色、臭 | 实与虚、湿热与正虚邪恋分不清 |
| 牙齿 | 松动度、牙位、龋洞、变色、磨耗、楔状缺损、有无隐裂 | 「能否保留」无据，转诊无凭 |
| 黏膜 | 部位、数目、大小、边缘、基底、有无假膜、复发频率与诱因 | 反复性这一关键证据丢失 |
| 口气与口味 | 臭秽／酸腐／腥臭；口苦／口甜／口黏／口淡 | 胃、脾、湿的线索丢失 |
| 舌脉 | 舌质、舌苔、脉之有力无力 | 虚实难辨时无最后一票 |
| 二便与饮食 | 便结／便溏；嗜辛辣、醇酒、甜食 | 胃火与脾虚的佐证丢失 |
| 全身与用药 | 糖尿病、血液病、妊娠、经期、抗凝药、免疫抑制药 | 处置风险与全身关联被忽略 |
| 口腔卫生行为 | 刷牙次数与方法、是否用牙线、洁治史 | 复发原因无从判断 |
| 红旗 | 面肿硬、张口受限、发热、出血不止、溃破逾两周不愈 | 延误转诊 |

**十二项里，最易漏而后果最重的三项是：病程、出血之色量、全身与用药。** 病程决定虚实的第一刀；出血之色量区分实热与正虚；全身与用药决定能不能动手、要不要转诊。这三项漏了，前面的辨证再细也可能判反。

## N.2 为什么可以这样翻译

把「定病位—定病性—归脏腑—落记录」译成现代的「主诉—现病史—检查—诊断—治疗计划」，是可以成立的，理由有三。

**一、次序同构。** 两套流程都要求先收证据、后下结论，且都要求先排除危险。中医的「先辨虚实」与现代的「先排除恶性与感染扩散」，位置都在最前；差别只在排除的手段（脉证 vs 影像与活检）。

**二、结构同构。** 定病位相当于定位诊断（哪一颗牙、哪一层组织）；定病性相当于定性（炎症、变性、肿瘤、功能）；归脏腑相当于病因与系统关联（糖尿病、免疫、营养）；落记录相当于病历。四步对四步，一一可挂。

**三、目的同构。** 两者都要回答「现在做什么」。辨证的终点是治法，诊断的终点是治疗计划；都不以「说清是什么」为满足。

但翻译在关键处断开：**现代诊断给的是「病的名称」，辨证给的是「当下的状态」。** 一个人可以终身带着「慢性牙周炎」这个诊断，而他的证在一个月内可以从「胃火」变成「脾虚」；反过来，同一种证可以出现在龋病、牙周病、黏膜病三个诊断之下。这就是「一病多证、一证多病」，翻译到这里必须停：不能用一个诊断去对应一个证，也不能用一个证去覆盖一个诊断。

## N.3 这个翻译丢掉了什么

**一、丢了证的动态。** 流程化的记录是一次快照，写完就归档；辨证要求的是每次复诊重新辨一次。清热之后脉由数转缓、龈由鲜红转淡，证已变而方未变，是最常见的失误。译成流程之后，「复诊再辨」这条纪律极易被「按原方案续用」替代。

**二、丢了体质与从化。** 同一邪气，阳虚之人从寒化，阴虚之人从热化，这就是「从化」。现代流程里没有「体质」这一栏，只有「基础疾病」。丢掉从化，就会把「同病异治」看成经验，而不是理据。

**三、丢了传变。** 辨证不只回答「现在是什么」，还要回答「将要往哪里去」：胃火失治则伤阴，阴伤则火愈浮；龈病日久则及骨，骨损则齿摇。这是「治未病」在口齿科的落点。流程只处理当下，不预测走向。

**四、丢了脉。** 流程化记录里最先被删的就是脉——它没有客观刻度，无法复核。可在虚实难辨时，脉之有力无力常常是最后一票：龈红肿而脉洪数者清之，龈红肿而脉数无力者补之。删掉脉，这一票就没了。

**五、丢了可解释性。** 「胃火龈肿」对患者毫无意义，「牙龈发炎，与刷牙不到位和胃火上炎都有关」才有意义。译成流程之后，医患沟通成了必须另补的一课，而不是辨证自带的副产品。

## N.4 与相邻学科的接口

**与病历书写规范。** 本章的十二字段可与规范的「主诉、现病史、既往史、检查、诊断、计划」一一挂靠：病程入现病史，龈与牙入检查，全身与用药入既往史，红旗入注意事项。挂靠之后，中医记录不必另立格式，只需在规范之内增补几栏。

**与牙周检查表。** 牙位、探诊深度、探诊出血、松动度、根分叉，是现代牙周记录的骨架。中医的龈之色形质与出血色量可附于其后，形成「一张表两种读法」：同一行数据，既看袋深，也看虚实。

**与黏膜病诊断。** 黏膜病的性质判定依赖视诊、涂片、必要时活检，辨证不能替代病理。接口的次序是：先定性（是不是念珠菌、是不是苔藓、是不是恶性），再辨证（属哪一层、该清该温该滋）。次序颠倒，就是把可治的病拖成难治的病。

**与中医内科。** 内科的「十问」是本章问诊的母本：寒热、汗、头身、饮食、二便、睡眠、情志，问全了，虚实自明。口齿科只是把十问收窄到口腔，再加几项专科字段。

**与针灸科。** 归脏腑之后，取穴才有依据：归胃取内庭、归大肠取合谷、归肾取太溪、局部取颊车与下关。穴位是归经的兑现，不是对症的堆叠。

## N.5 争议与本项目立场

**争议一：证型要不要标准化。** 一派主张统一证型表（胃火、虚火、脾虚、湿热……），便于教学与统计；一派主张个体化，反对削足适履。本项目取中间：**用「病位＋病性＋脏腑」三要素组合命名，不强求固定证型表。** 好处是既可统计（三要素可编码），又不失个体差异；代价是证名较长，不如四个字的证型顺口。

**争议二：虚实二分够不够用。** 不够。口齿科最常见的兼夹是湿与瘀，二者都不在虚实两极之内。但虚实仍是第一刀，因为治法的大方向由它决定：虚则补，实则泻；湿与瘀是在这个方向之内的调整。次序不能倒——先分虚实，再辨兼夹。

**争议三：中西医双重诊断该怎么写。** 一派写「牙宣（相当于慢性牙周炎）」；一派主张两栏并列。本项目取后者：**中医诊断栏写「牙宣（胃火炽盛，兼肾虚）」，现代诊断栏写「慢性牙周炎」**，两栏并列，互不翻译。理由：等号会掩盖「同症异源」。反例很现成——龈肿出血而血常规异常者，写作「牙宣相当于慢性牙周炎」就会把血液病漏掉；写作两栏并列，则会逼着人去看那个「异常」。

**争议四：什么时候停止辨证、直接转诊。** 红旗出现时。面肿而硬、张口受限、吞咽困难、发热（感染扩散）；出血不止而全身有瘀斑（血液病）；溃破逾两周不愈、白斑粗糙或红斑、不明肿块（需活检）；齿动而全身骨痛（需查全身）。**红旗之前不谈辨证，红旗之后才谈。** 这一条不是保守，是承认本课的边界。

**争议五：脉诊在口腔科的现实性。** 一派认为口腔科不必诊脉，问诊与望诊已足；一派认为脉不可废。本项目取折中：**脉当诊，但不夸大。** 条件不允许时，以舌象、色形、劳逸关系补，并在记录中写明「脉未诊」，不臆造脉象。诊脉的价值在虚实难辨时最显，而非每案必备。

> **免责声明：** 本章为教学材料，不构成诊断或治疗建议。文中的辨证路径、字段表与方名只用于说明思路，不构成诊疗规范或处方；一切诊断、检查、用药与处置，须由具备资质的执业人员依现行规范与所在机构制度作出，方药须随证加减并注意禁忌。凡见面肿而硬、张口受限、发热、出血不止、溃破逾两周不愈或不明肿块者，先转诊。本章不给剂量、不给疗程，不含任何研究数据与疗效结论。

## 延伸阅读

- 《口齿类要》，明·薛己撰，「齿痛三」「口疮二」。——分经归属（上齿胃、下齿大肠、动摇属少阴）与三焦分层（上焦实热、中焦虚寒、下焦阴火），是本章归脏腑一步的直接依据。
- 《景岳全书》，明·张介宾撰，齿痛诸条。——以急缓辨虚实：「凡火病者其病必骤」，虫蚀日久者其病必缓；本章 4.1.2 的第一刀取意于此。
- 《医宗金鉴·外科心法要诀》，清·吴谦等编，牙齿部。——牙宣、牙痈、齿衄各条辨虚实先后与脓成未成，可与本章的字段表对照读，看古人记录哪些、省略哪些。
