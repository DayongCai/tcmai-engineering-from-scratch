## N.1 概念与出处

中医看口腔，看的不是「一个腔里装着牙和肉」，而是「几条通路在此交汇」。齿、龈、口、唇、舌、涎、唾，各自挂着不同的脏腑，挂着的方式也不同：有的挂「形质」（这东西由什么生成），有的挂「通路」（气血从哪条经上来），有的挂「外候」（内脏的状态从这里露出来）。三种挂法混在一起讲，就会觉得古人自相矛盾；分开讲，每一句都站得住。

| 概念 | 出处 | 一句定义 |
|---|---|---|
| 齿 | 《素问·上古天真论》「齿更发长」「真牙生而长极」「发堕齿槁」；《口齿类要》「齿者肾之标」 | 骨之余，外露于口，其生成、坚固与脱落皆随肾气盛衰 |
| 龈（牙床） | 后世「龈为胃之络」；《医宗金鉴·外科心法要诀》「龈为肉之余属胃」 | 包绕牙颈之肉，上龈属足阳明胃，下龈属手阳明大肠 |
| 口 | 《素问·金匮真言论》「开窍于口」；《灵枢·脉度》「脾气通于口，脾和则口能知五谷矣」 | 脾之外窍，纳谷与知味之门 |
| 唇 | 《素问·五脏生成篇》「脾之合肉也，其荣唇也」；《灵枢·五阅五使》「口唇者，脾之官也」 | 脾荣之外候，其色之华枯应脾之盛衰 |
| 舌 | 《素问·阴阳应象大论》「心主舌」；后世「舌为心之苗」 | 心之外候，又为脾胃之气所蒸而成苔 |
| 涎 | 《素问·宣明五气篇》「脾为涎」 | 脾之液，清稀而溢于口，助纳谷、润口腔 |
| 唾 | 《素问·宣明五气篇》「肾为唾」 | 肾之液，稠厚而生于舌下，咽之养精 |
| 真牙 | 《素问·上古天真论》「真牙生而长极」 | 最后萌出之牙，其生以肾气平均为期，俗称智齿 |

**先立一个总纲：来源与通路，是两件事。** 齿的「来源」在肾（肾主骨生髓，齿为骨之余），齿的「通路」在阳明（手阳明入下齿，足阳明入上齿）。所以问齿病，既要问肾（这个人的精足不足、发育顺不顺、老没老），也要问阳明（有没有火、有没有积热、大便通不通）。只问一端，判断必偏：只见火而清，则年老齿动者愈清愈虚；只见虚而补，则胃火龈肿者愈补愈肿。

### 2.1.1 齿为骨之余：一条生命节律

《素问·上古天真论》讲人的生长衰老，用的是一串牙齿的事：女子七岁「齿更发长」，三七「真牙生而长极」；丈夫八岁「发长齿更」，三八「筋骨劲强，故真牙生而长极」，五八「肾气衰，发堕齿槁」，八八「齿发去」。这一段不是零散的描述，是一条以肾气为轴的曲线：**肾气盛则齿更、则真牙生，肾气衰则齿槁、则齿去。**

这条曲线给出三层认识。

**其一，齿的生成与更替由肾气驱动。** 换牙、智齿萌出这两个节点，古人都挂在肾气上，而不是挂在「年龄」上。年龄只是刻度，肾气才是动力；所以同样的年龄，有人齿坚，有人齿脆，古人归之于禀赋与保养。

**其二，齿的坚固程度是肾气的外显。** 「齿槁」二字很准：不是痛，不是肿，是枯槁——失其润泽、失其坚固。这与「肾主骨、其华在发」是同一套观察：骨、发、齿三处，都是肾精在体表的账本。

**其三，齿的脱落有其常与变。** 八八齿发去，是常；四十岁而齿大动，是变。常者不必治，变者当求其因。这一条最实用：见到牙齿松动，先问年龄与全身，再问局部，不要一见松动就开补肾方。

但齿不只属肾。薛己在《口齿类要》开篇引徐用诚语，把这件事分得极清楚：**「齿恶寒热等症，本手足阳明经；其动摇脱落，本足少阴经；其虫疳龈肿，出血痛秽，皆湿热胃火。」** 一句话三层：怕冷怕热、遇刺激而痛，责阳明（通路）；动摇脱落，责少阴（来源）；虫蚀、龈肿、出血、口臭，责湿热胃火（邪）。这是本章能给出的最有用的一个分句法，第 3、4 章都从它长出来。

### 2.1.2 龈为胃之络：上与下，胃与大肠

「龈为胃之络」的依据在经络。《灵枢·经脉》说手阳明大肠之脉「入下齿中」，足阳明胃之脉「入上齿中」。一上一下，分得很齐。于是有了一个沿用了千年的默认归属：**上齿、上龈多责胃，下齿、下龈多责大肠。**

这个默认值在临床上很好用。上牙痛而口臭、渴喜冷饮、大便干，多从胃火想；下牙痛而便秘、腹胀，多从大肠积热想。反过来，治上牙常取内庭（胃经），治下牙常配合谷（大肠经），也是照这条线走的。

但默认值不是定律，薛己自己就留了余地：「诸经多有会于口者，齿牙是也。」意思是口齿乃多经交汇之地，不可执一。所以正确的用法是：**先按上下分经取一个初步方向，再用全身脉证校正。** 上牙痛而脉细数、舌红少苔、腰酸者，病不在胃而在肾，此时若执「上牙属胃」而用清胃，就错了。

还有一层常被忽略：龈不只属胃，也属脾。《医宗金鉴》说「龈为肉之余属胃」，而肉为脾所主；故龈之病有两副面孔——**属胃者多实（红肿、出血、溢脓、口臭），属脾者多虚（色淡、萎缩、渗血、乏力）。** 这与「来源与通路」是同一个结构：胃给龈以气血的通路，脾给龈以形质的来源。通路有火则肿，来源不足则萎。

**这一节要记住的不是「上胃下大肠」五个字，而是「龈有两个归属，一实一虚」。** 第 3 章讲火与虚，讲的就是这两副面孔。

### 2.1.3 脾开窍于口，涎为脾液

「脾开窍于口」见于《素问·金匮真言论》。《灵枢·脉度》又补一句：「脾气通于口，脾和则口能知五谷矣。」这句话的分量在「知五谷」三字：口不只是进出的门，还是**辨味的器官**，而辨味的能力取决于脾之和否。所以口味异常——口淡、口甜、口黏、口苦——不是小事，是脾（及肝胆）状态最直接的报告。

唇是口的外框。《素问·五脏生成篇》说「脾之合肉也，其荣唇也」，《灵枢·五阅五使》说「口唇者，脾之官也」。唇之色泽润枯，古人当作脾之华来看：唇淡而白，多属血虚；唇干而裂，多属津伤；唇肿而痒，多属风湿热。

液的部分更细。《素问·宣明五气篇》列五脏化液：心为汗、肺为涕、肝为泪、脾为涎、肾为唾。涎与唾分了家，分得不只是名字，是**质地与归属**：

- **涎**，清稀，溢于口，随进食而增，属脾。它的作用是润与助纳，故「脾虚不摄」则涎多自流（小儿流涎不止多责此），「脾不散精」则涎少而口黏。
- **唾**，稠厚，生于舌下，咽下以养肾精，属肾。故「肾阴不足」则唾少而口干，夜卧尤甚；古人又有「咽唾养生」之说，正是把它当作可咽之精。

这个二分在看病时很有用：**口黏、涎多、口甜，从脾与湿上想；口干、唾少、舌燥，从肾与阴上想。** 二者可以并存——口黏而口干，是湿与阴虚同见，多见于久病、年老、嗜辛辣者。

### 2.1.4 经络与口齿：一张简表

口齿虽小，过的经不少。下表只列与本章相关的几条，够用即可。

| 经 | 所过 | 临床落点 |
|---|---|---|
| 手阳明大肠 | 入下齿中 | 下齿痛、下龈肿、便秘而痛甚 |
| 足阳明胃 | 入上齿中 | 上齿痛、上龈肿、口臭、渴喜冷饮 |
| 足少阴肾 | 主骨生髓，齿为骨之余 | 齿动、齿脆、齿槁、齿根宣露 |
| 足太阴脾 | 开窍于口，其荣在唇 | 龈萎色淡、口疮、唇病、涎多 |
| 手少阴心 | 舌为心之苗 | 舌痛、口疮、舌尖红赤 |
| 足厥阴肝 | 其支者循喉咙之后；情志化火 | 口疮随怒而发、经前龈肿 |
| 督脉 | 上唇系带处有龈交 | 口齿与督脉相通，龈交为局部取穴之一 |

这张表要会用，不要会背：**见一处病，先问它在哪条经上，再问这条经连着什么脏，最后回到那个人身上验证。** 表只是提示，脉证才是裁决。

## N.2 为什么可以这样翻译

「齿为骨之余」与「牙与骨同为矿化组织」可以对读，但这是本章最容易被用错的一句。先看它成立的部分。

牙釉质、牙本质、牙骨质与骨，确实同属以羟基磷灰石为主的矿化组织。钙磷代谢、维生素 D、甲状旁腺素这一套调节，同时作用于骨与牙：佝偻病与骨软化可见釉质发育不全与萌出延迟，牙槽骨在牙周炎中的吸收与全身骨代谢同受一套因子支配。这就是「齿为骨之余」最硬的现代回声——**在矿化这件事上，牙与骨共用一套调节系统。** 而中医的「肾」包含生长、发育、生殖与衰老这一条功能轴，现代的肾脏又参与钙磷平衡与活性维生素 D 的生成。两条语言在这一层上对得相当准。

「龈为胃之络」也能译。牙龈是消化道入口的黏膜，血供丰富、更新快，对全身状态极敏感：维生素 C 缺乏则龈出血，糖尿病则牙周破坏加重，白血病可致龈肿出血，妊娠可致妊娠性龈炎，某些药物可致龈增生。中医把这些归到「胃」——受纳腐熟、气血生化之源；现代归到消化、代谢与免疫。两套词不同，指的却是同一件事：**全身状态在龈上留痕。**

「脾开窍于口、涎为脾液」同样可译。唾液分泌受自主神经调节，进食时增加，参与湿润、缓冲、初步消化与抗菌；「脾主运化」「涎助纳谷」说的是这条功能线的两端。故脾虚者口淡、涎多而纳呆，与「消化功能低下」在临床画面上高度重合。

但翻译必须画出边界，两条：

**一、矿化同源，不等于胚胎同源。** 牙釉质来自外胚层上皮，牙本质与骨来自神经嵴间充质，成骨方式也与牙体形成不同。所以「齿为骨之余」只能讲成「同一套矿化调节下的两种组织」，不能讲成「牙是骨长出来的」。

**二、脏腑是功能轴，不是器官。** 「肾主骨」的肾，不是腰后那两个器官；但现代肾脏又确实参与钙磷与维生素 D 活化。这个巧合极容易诱人越界——由「齿动」直接推出「肾有病」，由「补肾」直接推出「改善肾功能」。这是本章要挡住的第一个错误。

两套语言在「矿化调节」与「全身状态在龈上留痕」这两处合得上；越出这两处，就不是翻译，是比附。

## N.3 这个翻译丢掉了什么

**一、丢了禀赋与节律。** 矿化代谢模型讲的是当下的平衡：摄入多少钙、吸收多少、沉积多少。它没有「先天禀赋」这一栏，也没有「七岁齿更、三八真牙生、五八齿槁」这种以肾气为轴的节律。于是「此人齿脆易龋，是先天不足」这类判断无处落笔；而临床上，同一年龄、同一口腔卫生水平，两个人的龋易感性可以差得很远。这一层，翻译之后只能靠「遗传」二字含糊带过。

**二、丢了经络的纵向联系。** 译本保留了「牙与骨同治」，却保不住「上齿属胃、下齿属大肠」这条横向分经，更保不住合谷、内庭、太溪这些远道取穴的依据。远道取穴的理据是「经气相通」，不是「神经节段」；译成神经学，取穴就成了经验凑数。

**三、丢了津的输布。** 涎与唾被译成「唾液分泌」，看似妥帖，实则丢了三层：津随气升降输布，故腺体流量正常而口干者大有人在（多见于阴虚、气虚、湿热）；津停则为湿，故涎多不必是分泌过多，也可以是输布失常；津的盈亏要看全身（舌、便、肤、夜卧），局部流量计测不出。凡以流量替代津液，就会把「查到不干」当作「津液不亏」。

**四、丢了「知味」。** 「脾和则口能知五谷」把口味列为脾之外候，口淡、口甜、口黏、口苦各有归属。现代唾液检查里没有这一项。丢掉这一层，问诊里就少了一整块最灵敏的信息。

## N.4 与相邻学科的接口

**与口腔组织胚胎学。** 它给出牙的发育序列：牙板、蕾状期、钟状期、釉质器、牙乳头、牙囊，以及釉质与牙本质各自的来源。这套序列能解释「为什么釉质坏了不能再生」——成釉细胞在萌出后即退去。中医没有这套序列，但有「肾气盛则齿更」的时间轴，两者在「发育有时间窗」这一点上可对读；在细胞来源上不可通融。

**与唾液腺生理。** 它给出流率、成分与调节：静止与刺激状态不同，缓冲能力、溶菌酶、免疫球蛋白各有其用。这正好解释「涎为脾液」的一半：涎不是水，是有功能之液。接口处要小心的是把「涎」等同于全部唾液——中医的涎还带着「津之输布」的意思，比腺体分泌大一圈。

**与经络腧穴学。** 本章的经络表直接供它使用：合谷（大肠）、内庭（胃）、颊车与下关（局部）、太溪与照海（肾）、龈交（督脉）。取穴的理据在经络所过，不在病灶远近；这一点若丢，针灸在口齿科就成了「哪里痛扎哪里」。

**与中医内科。** 肾、脾、胃三脏的虚实，是本章的落点，也是内科的起点。口齿科从内科借的是「辨虚实」的方法，还给内科的是「一个容易观察的窗口」：龈之色形质、齿之动与不动、涎之多寡，都是内科问诊里常常漏掉、却极易获得的信息。

## N.5 争议与本项目立场

**争议一：「齿为骨之余」是不是解剖学命题。** 一派认为它讲的是牙齿的解剖归属，故可与「牙是骨的一种」等同；一派认为它是功能命题。本项目取后者：它讲的是「齿与骨共用一套由肾所主的充养与调节」，不是「牙由骨生成」。理由已见 N.2：胚胎来源不同，成骨方式不同。代价是这个说法不能再用来解释牙齿的发生学，好处是它保住了临床用途——见齿之枯槁，知肾精之盛衰。

**争议二：上龈属胃、下龈属大肠是否可靠。** 临床上不难找到反例：上牙痛而病在大肠，下牙痛而病在胃。一派据此认为分经无意义；一派坚持经典不移。本项目取中间：**分经作为默认方向，脉证作为最终裁决。** 薛己自己就说「诸经多有会于口者」，可见古人也不把它当定律。用它的正确方式是省力，而不是代替思考。

**争议三：涎与唾的二分在今天还能不能用。** 一派认为现代只讲唾液，二分是臆造；一派坚持脾涎肾唾。本项目保留二分，但不宣称它对应两套腺体。理由是临床价值：口黏涎多与口干唾少，指向两个不同的方向（湿与阴虚），处置相反；若合并为「唾液异常」，这条线索就断了。名称可留，腺体不等。

**争议四：由「肾主骨」能不能推出查肾功能、查骨密度。** 不能，这是本章最需要挡住的一条越界。齿动可见于牙周炎、咬合创伤、糖尿病、骨质疏松、药物影响，也可见于年老。**「肾虚齿动」是一个证候判断，不是一个器官诊断。** 正确的做法是：由证候提示「应查全身」，而不是由证候直接断定「肾有病」；查与不查，依现行规范与具体情形定。

> **免责声明：** 本章为教学材料，不构成诊断或治疗建议。文中的脏腑归属、经络循行与涎唾之分，只用于建立判断框架；一切检查、用药与处置，须由具备资质的执业人员依现行规范与所在机构制度作出。牙齿松动、牙龈出血、口腔黏膜久溃不愈者，须先经口腔科检查排除局部与全身病变，不在此框架内自行判断。本章不给剂量、不给疗程，不含任何研究数据与疗效结论。

## 思考题

1. 「齿属肾」与「齿络属阳明」看似矛盾。请用「来源与通路」解释这两句为何可以并存，并举一个必须同时问两端的临床情形（不必是真实病例）。
2. 「龈为胃之络」与「龈为肉之余（属脾）」并存。请用「通路与形质」区分二者，并说明龈色淡白而萎缩者，当从脾论还是从胃论，为什么。
3. 「涎为脾液、唾为肾液」的二分，在现代唾液生理里找不到一一对应的腺体。请说明这个二分在问诊上还能提供什么信息，以及它在什么情况下会失效。

## 延伸阅读

- 《黄帝内经·素问》《灵枢》——《上古天真论》给出以肾气为轴的齿更齿槁节律，《金匮真言论》《宣明五气篇》立「开窍于口」「脾为涎、肾为唾」，《经脉》提供手足阳明入上下齿的经络依据；本章引文皆出此。
- 《口齿类要》，明·薛己撰，「齿痛三」。——「齿者肾之标，口者肾之窍」与转引徐用诚「齿恶寒热本手足阳明、动摇脱落本足少阴、虫疳龈肿皆湿热胃火」一段，是本章分经三层说的直接来源。
- 《医宗金鉴·外科心法要诀》，清·吴谦等编，牙齿部。——「龈为肉之余属胃」一语及牙齿各条的辨证次序，可与本章的龈之两属对照读；只标篇目，不引原文。
