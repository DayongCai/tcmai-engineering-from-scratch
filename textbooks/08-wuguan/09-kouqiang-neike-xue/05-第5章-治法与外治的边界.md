# 第 5 章 · 治法与外治的边界

## N.1 概念与出处

先立一组词，分三层：**从里面治**（内治三法）、**从外面治**（含漱、吹药、涂敷、冲洗）、**用器械治**（洁治、刮治）。这三层的区别不在「中药还是西药」，而在**它能把作用送到哪一层组织**。第三层常被中医院校的教材略过，却是本章真正的分水岭：龈上龈下的钙化牙石，任何汤药与含漱液都化不掉。

| 概念 | 出处 | 一句定义 |
|---|---|---|
| 内治 | 《素问·至真要大论》「谨守病机，各司其属」；教材总论·治法 | 以汤、丸、散内服调整脏腑功能，针对的是「生火、生湿、耗气」这些上游环节，不是病灶本身 |
| 外治 | 《理瀹骈文》「外治之理，即内治之理；外治之药，即内治之药」；教材·外治法 | 以药物或器械直接作用于口腔局部，追求局部浓度与局部清洁，不经过胃肠吸收 |
| 含漱 | 《医宗金鉴》漱口诸方；教材·外治法 | 药液在口内鼓漱并停留，作用限于黏膜表面、龈缘与龈沟浅部，进不到袋底 |
| 吹药 | 教材·外治法（冰硼散、锡类散一类） | 药粉直接覆盖溃疡面或龈缘，靠局部高浓度与物理吸附起效 |
| 涂敷／噙化 | 同上 | 药膏、药膜贴敷于患处，延长局部停留时间，适合孤立病灶 |
| 牙周冲洗 | 现代牙周治疗常规 | 以钝针插入龈袋或牙周袋，用冲洗液带走袋内菌斑、食物残渣与脓液，能到袋的中上部 |
| 洁治与刮治 | 现代牙周治疗常规（龈上洁治、龈下刮治与根面平整） | 以器械从牙面与根面机械去除牙石与菌斑，是去除局部病因的唯一手段 |
| 局部刺激物 | 现代口腔科通称 | 牙石、菌斑、悬突、不良修复体边缘、食物嵌塞、解剖沟裂——一切能持续供养炎症的局部因素 |

这张表里最容易被误读的是「内治」那一行。教材说内治「治病求本」，学者常顺手把它读成「治根」，于是把「本」理解为「比症状更深的那个东西」。但在口腔科，「本」有两项，一项是**菌斑牙石**，一项是**宿主易感性**；内治只能动第二项，第一项必须交给器械。把两项都叫「本」，就会出现「明明在吃清胃散、龈炎还在出血」这种局面——不是方子错，是有一项「本」根本没被处理。

### N.1.1 内治三法：一条轴上的三个位置

口腔内科的内治，通行归纳为三法。三法不是三个病，是一条轴上的三个位置：**火在气分**（清）、**火在阴分**（滋）、**气不摄血**（补）。三者的鉴别不靠单一症状，靠一组同时出现的体征。

**一、清胃泻火。** 适用于龈肉红肿、出血色鲜量多、溢脓、口臭、口渴喜冷、大便干结、舌红苔黄厚、脉洪数者。代表方清胃散；若胃热而兼阴伤（口干而舌红少苔、龈肿不甚而痛甚），可用玉女煎，清胃与滋水同施。这一法的靶点是「阳明有余」：足阳明胃经循行于上龈，火沿经上炎，所以龈先肿、先出血，牙本身未必痛。判断是否对证，看三个「下游」：口臭、便秘、舌苔厚黄。三者同在，清之有效；只有龈红而三者皆无，多半不是纯实证。

**二、滋阴降火。** 适用于龈肉微红微肿、齿根宣露、牙齿松动、渗血色淡、午后颧红、五心烦热、腰膝酸软、舌红少苔、脉细数者。代表方知柏地黄丸；若兼湿热熏蒸、口黏而苔黄腻，用甘露饮一类清滋并行。这一法的靶点是「少阴不足」：齿为骨之余，肾主骨生髓，肾阴亏则齿失所养，虚火上浮则龈络受损。它的特征性表现不是「痛得厉害」，而是「反复、缠绵、白天轻夜间重」。

**三、补气摄血。** 适用于龈色淡白、渗血绵绵不止、齿浮无力、倦怠乏力、面色萎黄、纳少便溏、舌淡苔白、脉细弱者。代表方补中益气汤；若气血两亏、兼见面色无华与心悸，用八珍汤。这一法针对的不是「火」，是「统摄无权」：脾气虚则血不循经，溢于龈络。它的鉴别点是**出血的性质**——实证出血色鲜、量多、来势急；气虚出血色淡、量少、淋漓不尽，且刷牙、进食即渗。

三法之间不是互斥关系。临床最常见的是「清中兼补」或「补中兼清」：胃火炽盛日久灼伤肾阴，转为虚实夹杂，此时单清则伤正、单补则助火；久病气虚而余火未清，亦同此理。教材讲牙宣「常虚实夹杂」，讲的就是这个渐变过程。判断虚实的「多少」，看的是**同一组体征的权重**：龈红肿与舌红苔黄占优则偏实，齿摇、腰酸、脉细占优则偏虚，两者并重则两法合用，但用药有主次。

### N.1.2 外治四类：它能到哪一层

外治的分类若按「剂型」分（散、膏、液、膜），学者记住的是剂型，用的时候仍不知道能治什么。按「能到达的组织层次」分才有操作意义。

| 方法 | 能到达 | 能解决 | 不能解决 |
|---|---|---|---|
| 含漱 | 黏膜表面、龈缘、龈沟浅部（数毫米） | 减少龈缘菌斑的成熟度、冲掉食物残渣、局部消肿止痛、溃疡面清洁 | 龈下牙石、深袋内的菌斑、根面病变 |
| 吹药／涂敷 | 病灶表面，靠局部高浓度 | 孤立溃疡的止痛与促愈、龈缘渗血的局部收敛 | 大面积炎症、袋内感染 |
| 牙周冲洗 | 龈袋与牙周袋的中上部 | 袋内脓液、食物残渣、松动菌斑的机械清除；上药后的局部给药 | 附着于根面的牙石（冲洗冲不掉） |
| 洁治／刮治 | 牙面与根面（龈上、龈下） | 去除钙化牙石与根面菌斑，消除炎症的直接病因 | 已丧失的牙槽骨与附着（不可逆） |

这张表要读出的结论只有一句：**外治的边界，就是器械与药液能触到的边界；触不到的地方，药再好也无效。** 龈下五毫米的牙石，含漱液泡十年也不会变软；反过来，已形成的牙周袋，单靠刷牙也永远清不干净。中医院校的教材在「外治法」一节常以含漱、吹药、涂敷为主，这是历史条件所限（洁治器不属于传统中医器械），今天读这一节，应当把「器械」补进外治的范畴，而不是把「器械」当成另一门学问。

### N.1.3 分工与先后：四条排序规则

内治与外治不是「两条路可选」，而是「一条流水线上的两道工序」。排序有四条规则，前两条是硬的。

**第一，有局部刺激物，先去除，再谈内治。** 牙石、菌斑、悬突、边缘不密合的修复体、食物嵌塞，这些是炎症的持续供养源。不拆掉供养源而内治，等于一边放水一边舀水：药力能压住一时，停药即复。这条规则在龈炎上几乎是绝对成立的——龈炎的全部病因在龈缘，去除菌斑牙石后炎症可完全消退，此时内治的意义只是缩短病程、减轻症状。

**第二，急性症状（剧痛、大量出血、脓肿）先处理局部，再辨证。** 牙髓炎的夜间剧痛、牙周脓肿的跳痛、牙龈的持续渗血，这些不因服汤药而在数小时内缓解，患者也不会等。此时外治与器械是「一线」，内治是「二线」：先开髓减压、先切开引流、先局部压迫止血，痛止之后再从容辨证。反过来做——先开七剂清胃散、嘱其「吃完再看」——是本章最需要防的一种处置。

**第三，局部处理后仍反复，或全身证候明显者，内治为主。** 典型情形有三类：洁治后龈炎消退而数月即复、且伴口臭便秘舌苔厚黄者（胃火未清，宿主易感性强）；龈退缩、齿摇、腰酸耳鸣而局部清洁良好者（肾虚为主，器械无能为力）；渗血绵绵、倦怠面黄者（气不摄血）。这三类里，内治不是辅助，是主要手段。

**第四，二者可以并行，但并行不等于无序。** 同一天可以既做洁治又开方，但交代要分先后：当日以局部处置为主，汤药自当日起服；复诊间隔按局部处置的需要定，不按方剂吃完的时间定。这一条常被忽略，结果是患者把「药吃完了」当成「疗程结束了」。

「先后」还有第二层含义，是**疗程内的先后**：急性期（止痛、止血、引流）→ 缓解期（去除病因、辨证调本）→ 维持期（口腔卫生、定期洁治、间断服药）。三个阶段的治疗目标不同，用同一张方子贯穿全程，是把三个阶段混成一个。

### N.1.4 闸门：哪些必须交给牙科

以下情形不属于「内治可以观察」的范围，须转口腔科（牙体牙髓、牙周或颌面外科）。每一条后面写的是「为什么不能等」。

| 情形 | 判据 | 为什么不能等 |
|---|---|---|
| 深龋、牙髓炎、根尖周炎 | 自发痛、夜间痛、温度刺激后痛持续、叩痛、龈瘘管 | 牙髓一旦不可逆坏死，唯一出路是根管治疗；止痛药与汤药只掩盖症状，感染继续向根尖扩散 |
| 牙周袋形成 | 探诊深度持续增大、探诊出血、附着丧失 | 附着丧失不可逆；等待期内牙槽骨持续吸收，最终松动脱落 |
| 牙周脓肿 | 局部半球形隆起、波动感、跳痛、溢脓 | 需切开引流，脓液自行破溃的方向与时机不可控 |
| 牙齿松动 II 度以上 | 颊舌向动度超过一毫米或伴垂直向动度 | 提示支持组织丧失已达相当程度，需牙周系统治疗甚至夹板固定 |
| 牙龈出血不止 | 自发出血、量多、压迫难止，或伴皮下瘀斑、发热、淋巴结肿大 | 需排除血液系统疾病，此类出血不是「火」能解释的 |
| 口腔溃疡超过两周不愈 | 基底硬结、边缘隆起、菜花状、疼痛由痛转不痛 | 需排除恶变；「久溃不敛属虚」的判断在此会让位于活检 |
| 面颊肿胀、张口受限、发热 | 局部红肿热痛、开口度减小、吞咽困难 | 间隙感染可迅速扩散至颌下、口底，属急症 |
| 牙外伤、牙脱位 | 外伤史、牙体移位、松动、牙髓暴露 | 再植与复位有时间窗，以分钟计 |
| 药物性龈增生、妊娠期龈炎 | 服药史（苯妥英钠、硝苯地平、环孢素）、妊娠 | 需专科评估是否调整用药或行牙周治疗，单靠含漱无效 |

这张表的作用不是让中医「退出」，而是划定「谁能先动手」。表内九条，前六条与中医辨证可以并存——患者可以在根管治疗的同时服清胃散，但顺序是「先做根管，再服药」，不是反过来。

### N.1.5 记录与复评

口腔内科的病历与内科不同，它要求「可复查的局部指标」与「可复查的证候」并列。一份能复评的记录至少五栏：

**部位**（牙位或龈区，用牙位编号而非「右上」这类模糊描述）、**局部指标**（探诊深度、出血、松动度、龋损深度、溃疡大小）、**证候**（舌象、脉象、二便、口渴与寒热）、**已施处置**（含漱方、外用药、洁治范围）、**复诊间隔与判据**（下次看什么）。

复评的「有效」有各自的判据：局部看出血是否减少、龈色是否由暗红转粉、探诊深度是否减少、疼痛是否消失；全身看舌苔是否转薄、便秘是否解除、倦怠是否减轻。**两者不一致时以局部为准**——龈色转粉而舌苔仍厚，说明病因已去而体质未调，可继续内治；舌苔转薄而出血不减，说明诊断有误或局部刺激物未除净，须回查。复评间隔一般以二至四周为一档，急性期更短；不以「一剂吃完」为单位。

## N.2 为什么可以这样翻译

把「标本兼治」译成「清除病因物 + 调整宿主反应」，把「内外合治」译成「两条时间常数不同的通道」，这个译法站得住，理由在三层。

**尺度层：三种作用的时间常数不同。** 器械的作用是「一次事件」——洁治当天，牙石从有到无；外治的作用以「日」计——含漱每日数次，压的是龈缘菌斑的成熟速度；内治的作用以「周」计——调气、养阴、健脾，靠的是体质层面的缓慢改变。三种时间常数放在一条时间轴上，先后就自然浮现：一次性的先做，按日计的并行，按周计的打底。这不是谁高谁低，是三种节律必须对齐。反过来说，把按周计的放在最前，患者在前三天看不到任何变化，依从性就在这三天里流失了。

**因果层：「本」在口腔科可以拆成两项。** 中医讲「治病求本」，本是一个哲学概念；落到口腔，它可以被拆成两个可指认的对象：菌斑牙石（外源、可移除）与宿主易感性（内源、需调整）。拆开之后，「求本」就有了操作含义：先清外源，再调内源。不拆的后果是把两项混为一谈，于是「本」成了万能词——牙龈出血可以叫「胃火之本」，也可以叫「牙石之本」，说起来都对，做起来互相推诿。拆开还有一个好处：它让「治不好」有了可追问的原因。出血不减，是外源没清干净，还是内源没调到位？两者可以分别验证。

**验收层：两个通道各有各的核对物。** 外治与器械的疗效，可以被探诊深度、出血指数、龈色、疼痛这些可重复观察的量核对；内治的疗效，可以被舌象、脉象、二便、倦怠这些证候核对。有了各自的核对物，「有效」才不是一句自我评价。这也是本章把「记录与复评」放在最后一节的缘故——没有复评的分工，只是一次性的动作分配，不是一套可迭代的方案。

可译性有条件：**它只在「病因以局部为主、全身仅为易感背景」这一档里成立。** 换成白血病性龈出血、药物性龈增生、妊娠期龈炎、糖尿病未控的牙周炎，这套翻译立刻要改：此时全身因素不是背景，是主因，处置顺序要倒过来——先控全身，再谈局部。

## N.3 这个翻译丢掉了什么

**丢掉了「龈为胃之络、齿为骨之余」的定位。** 译成「胃火」与「肾虚」，剩下的是两个证型标签；丢掉的是「为什么胃火先犯上龈、肾虚先见齿摇」这一层经络与藏象的对应。这层对应不是装饰，它决定了问诊的方向：见上龈红肿，要问饮食与便秘；见齿根宣露，要问腰膝与夜尿。标签可以背，问诊的方向背不出来。

**丢掉了「火」的层次。** 实火、虚火、郁火，三者的舌脉不同，病程不同，治法也不同。译成「炎症」，三者被压成一个词，于是「清热」成了唯一动作。临床上的后果是：郁火者用大剂苦寒，火未清而气先伤；虚火者用苦寒，火愈浮而阴愈损。这一层若不在翻译时标出，学者会把「清热」当成万能钥匙。

**丢掉了性味与煎服法。** 同一味药，先煎后下、文火武火、含漱液的温度与停留时间，都影响局部浓度。「含漱」二字在译文中只剩「漱口」，丢掉了「药液停留片刻、鼓漱使药力遍及龈沟」这个动作要领——它常写在括号里，却是外治有效与无效的分界。

**丢掉了医患之间的调护契约。** 忌口、刷牙方法、复诊时间、戒烟——这些不写在方剂里，却决定了疗效的下限。口腔科的特殊性在于：患者每天有两次机会（刷牙）自己做治疗，也每天有两次机会自己破坏治疗。译成「内外合治」，就把这部分悄悄划到了「护理」名下，好像它与治法的逻辑无关。

**丢掉了「治未病」的公共卫生层。** 半年至一年一次洁治、窝沟封闭、含氟牙膏——这些在个体层面是「预防」，在人群层面是「减少患病率」。本章讲的是个体的治法边界，但边界的另一侧是「本来可以不发生」。

## N.4 与相邻学科的接口

- **牙体牙髓**：龋病的分层处置、根管治疗的适应证与时机在彼；本章只取「什么情况下内治必须让位」这一条判据。两者的接缝在「牙髓是否可逆」。
- **牙周**：洁治、刮治、翻瓣、夹板固定、维护期管理在彼。本章的「外治边界」在牙周科就是「袋深与根面」这条线；中医内治在牙周的位置，是宿主易感性的长期调整，不是替代刮治。
- **口腔颌面外科**：脓肿切开、拔牙、间隙感染处理在彼。本章的闸门表里有四条直接指向它。
- **血液科与内分泌科**：出血不止查血象与凝血，糖尿病与牙周炎的双向影响，在彼。这两科是「局部治疗无效」时最常被想起、也最常被想起得太晚的两个方向。
- **中药学与药剂学**：含漱液的制备、稳定性与口感在彼。含漱方若苦到患者不愿用，等于没有方。
- **护理与健康教育**：刷牙方法（Bass 法一类）、牙线使用、戒烟辅导在彼。这一环的落地质量，往往比方剂的选择更影响一年后的复查结果。

## N.5 争议与本项目立场

**争议一：中药含漱能否替代洁治。** 有「坚持含漱可免洗牙」的说法，理由是「西医治标、中医治本」。本项目立场：**不能替代**。含漱能改变龈缘菌斑的成熟速度，不能移除已钙化的牙石；把可逆的龈炎拖成不可逆的附着丧失，是这一说法最实际的代价。含漱的位置是「洁治之后锦上添花」，不是「洁治之前另辟蹊径」。

**争议二：牙龈出血时该停刷还是照刷。** 患者普遍的做法是停刷，怕「越刷越出血」。本项目立场：**照刷，用软毛、轻力**。出血是炎症的表现，菌斑是炎症的原因，停刷等于停掉唯一的病因治疗，出血只会更久。唯一的例外是有全身出血倾向者——此时不是「照刷」，是「压迫止血 + 查血 + 转诊」。

**争议三：长期服清热泻火药「预防复发」。** 有把清胃散、牛黄解毒一类当作长期保健方的做法。本项目立场：**不成立**。苦寒久服败胃伤阳，而牙周病复发的首要原因是菌斑再积累，不是「火未清尽」。缓解期的正确做法是口腔卫生 + 定期洁治 + 按体质间断调理，不是常服苦寒。

**争议四：外治在口腔科是「辅助」还是「主力」。** 内科教材的习惯表述是「内治为主，外治为辅」。本项目立场：**在口腔科要倒过来**。龈炎、龋病、牙周病这三类主体疾病，去除局部病因的处置是主力，内治调整体质是辅助与善后。这不是贬低内治，而是承认病位在「齿与龈」这个可直接触及的局部——凡能直接触及的病位，局部处置的权重必然上升。这一条是本学科与内科最大的口径差异，也是学者最容易带着内科习惯读错的地方。

**争议五：辨证分型是否必须「对号入座」。** 有把三法当成三个互斥证型、要求「一证一方」的读法。本项目立场：**允许并常见虚实夹杂**。清中兼补、补中兼清，是按权重配比，不是和稀泥；判断权重的依据是同一组体征的占比，不是「主要症状是哪一条」。

> **免责声明：** 本章为教学材料，不构成诊疗建议。文中方名仅为证治对应的举例，不给剂量、煎服法与疗程；一切处方与处置须由具备资质的执业人员依现行规范、临床路径与所在机构制度作出。凡遇自发出血、脓肿、张口受限、溃疡久不愈者，先转专科排查，再谈辨证。本章的「闸门表」用于建立转诊意识，不用于替代专科检查；实际转诊时机依患者全身状况与当地医疗条件判断。

## 思考题

1. 本章说「外治的边界就是器械能触到的边界」。请以龈下牙石与牙周袋为例，说明为什么含漱与冲洗都无法替代刮治，并从「药物需要接触才起效」这一条药理常识给出解释。
2. 「本」在口腔科被拆成「菌斑牙石」与「宿主易感性」两项。请说明这一拆分如何改变你对「治病求本」的理解，并指出它在什么情况下会失效。
3. 一位患者洁治后龈炎消退，三个月后出血复现，伴口臭、便秘、舌苔黄厚。请按本章的四条排序规则，写出你的处置顺序与复评判据，并说明为什么不建议「再洁一次就算了」。
