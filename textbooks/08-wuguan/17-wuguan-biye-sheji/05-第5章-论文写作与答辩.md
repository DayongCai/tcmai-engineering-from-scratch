## H.1 本章要解决的问题

五官科答辩最常被追问的一句是「这个改善超过测量误差了吗」。答不上来，前面所有数字都作废。论文要做的不是把台账誊成表格，而是把「问题—测量—结果—边界」串成一条外人能复查的链：每个数字能回到某次访视、某台设备、某个操作者；每句结论能说清在什么人群、什么参数下成立。写作的次序也是这个顺序，先定这句话，再决定摆哪些图表。

## H.2 本章目标（可检验）

- 写出含问题、方法、结果、讨论、边界五部分的论文，数字可溯源到台账
- 把测量误差写进结果与讨论，明确改善量与误差的关系
- 准备三类必答质疑的回答：测量误差、自然波动、对照可比
- 完成一次预答辩并按意见修改，保留修改对照

## H.3 操作流程

1. 定主线：一句话写清「本研究在什么人群、什么参数下，证明了什么、没证明什么」，全文据此取舍，写不出这句话说明分析还没做完
2. 搭结构：摘要四句（背景、方法、结果、结论）→引言（专科问题与证据缺口）→对象与方法→结果→讨论→边界与局限→结论
3. 方法章写足：设备型号与参数、操作流程、一致性检验、结局定义与阈值、统计方法，写到他人可照做的程度，不写「常规操作」
4. 结果章按结局排序：先主要结局（含效应量与区间），再次要结局，再安全性；每图只回答一个问题，不堆图
5. 图注写全：样本量、单位、误差线含义、判据线与阈值位置；轨迹图注明一线一例，缩写首次出现须展开
6. 把误差摆出来：在结果或讨论中明写测量误差数值，并说明改善量是它的几倍；小于一倍就要正面讨论，不能回避
7. 讨论与文献比：至少三篇同类研究，一致处与不一致处各给原因假设（人群、参数、测量方法），不做笼统评价
8. 边界逐条：病种与证型范围、参数范围、样本量与随访时长、单中心与操作者依赖，每条写越界后果
9. 结论分档：确定结论与提示性结论分开写，提示性的明确标注仍需验证，不与确定结论混在一段
10. 数字溯源：正文每个数字标注表号或附录编号，附录放台账摘要与代表性原始图像，抽查哪一条都能对上
11. 规范格式：引用格式统一，标准注明版本与年份，图像自制或注明来源与使用许可，转引须回查原文
12. 预答辩与归档：十五分钟试讲，记录三条意见逐条回应；定稿后论文、台账、原始图像、汇报四件一并归档

## H.5 模板：论文自检与答辩准备表

| 字段 | 填写要求 |
|------|----------|
| 主线 | 一句话：人群、参数、证明与未证明 |
| 摘要 | 背景、方法、结果、结论四句 |
| 方法 | 设备、参数、流程、一致性、阈值 |
| 结果 | 主要、次要、安全三段的图表编号 |
| 误差 | 测量误差数值与改善量的倍数关系 |
| 讨论 | 三篇文献、一致与不一致的原因假设 |
| 边界 | 范围逐条与越界后果 |
| 结论 | 确定与提示两档 |
| 溯源 | 数字到表号或附录的对应 |
| 答辩 | 三类质疑的回答与追问预案 |

## H.6 常见失效与处置

- **改善不敌误差** → 报出的差异落在测量误差内，结论不成立却未讨论
- **方法章缺参数** → 他人无法照做，一致性检验也无从评价
- **只报完成者** → 脱落与失访被略去，疗效被系统性高估
- **讨论复述结果** → 不与文献比对，看不出本研究在学术上的位置
- **结论拔高** → 单中心小样本写成普适规律，越界即错
- **数字无出处** → 答辩追问一次即崩，且当场无法补救

## H.7 中期检查与答辩要点

- 证据链与溯源（35%）
- 测量严谨与误差讨论（25%）
- 边界与结论分寸（20%）
- 答辩表现（20%）
