## H.1 本章要解决的问题

五官科答辩最常被问「这个改善超过了测量误差吗」。答不上，疗效就无法成立。

## H.2 本章目标（可检验）

- 论文数据与台账一致
- 15 分钟讲清干预、测量、结果、安全
- 准备三个测量类质疑

## H.3 操作流程

1. 对表：数值回到台账
2. 写结构：问题、干预、测量、结果、安全
3. 附证据：一致性检验与原始图像
4. 预设质疑：测量误差、自然波动、对照可比
5. 试讲

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 数值与台账一致
- [ ] 五段结构齐全
- [ ] 一致性与原始数据已附
- [ ] 三个质疑有答案
- [ ] 引用写到篇名
- [ ] 安全结论已写
- [ ] 免责与致谢已写

## H.5 模板：答辩准备表（五官）

| 字段 | 填写要求 |
|------|----------|
| 核心结论 | ≤40 字 |
| 证据链 | 干预→测量→结果→安全 |
| 三个质疑 | 误差/波动/对照 |
| 边界 | 适用人群 |
| 试讲反馈 | 修改点 |

> 本表是本章的交付物：答辩前一天自查。

## H.6 常见失效与处置

- **不报测量误差** → 改善可能小于误差
- **把主观改善当客观疗效** → 须有量表或检查支撑
- **超时** → 15 分钟须取舍

## H.7 中期检查与答辩要点

- 数据一致（40%）
- 测量严谨（30%）
- 质疑回答（30%）
