## H.1 本章要解决的问题

「中医外治对干眼有效」是方向不是命题：用哪项指标判有效、与什么对照、疗程多长、改善多少才算有效，一句都没定。五官科毕设的开题要交的不是一段意义论述，而是一条能被证伪的假设、一套测得准的结局、一个十周内招得满的样本。三者缺一，开题表填得再漂亮，答辩时第一个问题就能把题目问倒。

## H.2 本章目标（可检验）

- 把轮转中反复出现的判断困难写成含人群、干预、对照、结局与时限的命题
- 确定唯一的主要结局，并为每个结局指定测量时点、测量方法与判效阈值
- 算出十周内可入组的例数与脱落余量，判断这个题目做不做得完

## H.3 操作流程

1. 选问题：从门诊记录或轮转笔记里挑一个「同一病人两位医生判断不一致」的情形，写下分歧具体在哪一项、一年出现几次
2. 查证据：检索该问题近五年的系统评价与对照研究，记下别人用过哪些结局、结论停在哪一步、为什么停在那里
3. 定位缺口：把缺口写成一句「已有研究多关注 A，未回答 B」，B 必须是你的样本量与随访时长能回答的；需要三年随访才能答的，直接划掉
4. 写命题：格式为「在 X 人群中，干预 A 相较对照 B，在疗程 T 后指标 M 的改善不小于 D」，句子里六个位置都要有具体值
5. 定主要结局：只留一个，优先选客观可重复测量的（如泪膜破裂时间、纯音听阈），症状量表降为次要，避免主结局被主观评分带偏
6. 定判效阈值：写明「改善多少算有效」的出处——文献报告的临床最小重要差异或本科室既往数据，不得事后定；阈值一旦写进方案，统计时不得改
7. 定测量时点：基线、疗程中点、疗程结束、结束后随访，各时点允许的窗口（如±3 天）逐条写清；超窗的访视标为超窗，不补做、不外推
8. 定对照：常规治疗、假操作或等待观察，逐项说明为什么可比、哪些混杂因素已被平衡、哪些仍无法排除
9. 估例数：门诊量×符合条件比例×愿意入组比例，再留两成脱落余量；不足则改设计或缩窄问题，可入组例数低于二十时应考虑改做病例系列
10. 定证型与纳入排除：中医证型用哪个标准、由谁判定、两人不一致时如何裁决，全部写进方案，不留口头约定
11. 判伦理：是否涉及侵入性操作、是否设对照、知情同意与伦理审查何时启动；批件未到不得先入组，也不得先做预试验
12. 砍范围与排期：列出「不做清单」，按周排里程碑，标出依赖伦理批件与设备档期的关键路径，每周留一天缓冲

## H.5 模板：开题命题表（五官）

| 字段 | 填写要求 |
|------|----------|
| 专科问题 | 轮转中的判断分歧、发生在哪类病人身上、出现频率 |
| 证据缺口 | 已研究的结局与尚未回答的问题 |
| 命题 | 人群、干预、对照、结局、时限、阈值 |
| 主要结局 | 指标、测量方法、判效阈值及其出处 |
| 次要结局 | 症状量表与客观检查各一项 |
| 对照 | 类型、可比性说明、无法平衡的因素 |
| 样本 | 来源、估算过程、脱落余量 |
| 证型与判定 | 所用标准、判定人、分歧裁决规则 |
| 测量时点 | 基线、中点、终点、随访与允许窗口 |
| 不做清单与排期 | 舍弃项、周次里程碑、关键路径 |

## H.6 常见失效与处置

- **把方向当命题** → 「外治对干眼有效」无法判真假，必须落到人群、对照与阈值
- **主要结局设两个** → 统计与结论都会打架；次要结局再多，主要结局也只能有一个
- **阈值事后定** → 看完数据再定「改善半秒算有效」，属事后调参，结论不可信
- **例数不算就开题** → 第八周才发现只入组十几例，只能临时改题或改设计
- **证型判定无人负责** → 两人判型不一致却无裁决规则，分组本身就已失真
- **不判伦理** → 涉及对照或侵入操作而未启动审查，数据一律不能用

## H.7 中期检查与答辩要点

- 命题可检验性与阈值出处（35%）
- 结局与测量设计（25%）
- 样本可及与伦理安排（25%）
- 范围裁剪与排期（15%）
