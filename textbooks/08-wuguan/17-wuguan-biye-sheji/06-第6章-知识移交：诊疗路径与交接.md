## H.1 本章要解决的问题

五官外治最难移交的不是处方，是手上的分寸：药液温度到多少病人会喊烫、熏蒸头距眼多远、留观多久算安全。这些写不进处方笺，却决定安全。移交要做的是把可写的写足——参数、路径、判定节点、停止规则；把不可写的标明并配带教；再用一次他人复现来验证这份规范是否真的能用。三者齐了，才算把个人经验变成了科室资产。

## H.2 本章目标（可检验）

- 画出一条可执行的诊疗路径：纳入、评估、干预、复评、转归与退出
- 交出含全部操作参数的规范，体位与器具配有图示
- 标出须带教的部分，并安排带教次数与考核方式
- 由他人按规范完整操作一次，记录偏差并回改规范

## H.3 操作流程

1. 画路径主干：从接诊到转归五个节点——纳入判定、基线评估、干预实施、复评、转归或退出，每节点写清由谁做、做什么、依据什么、留下什么记录
2. 写纳入与排除：病种、证型、年龄与合并症、禁忌情形；把「不适合做」的写在最前，避免先做后判、做完才发现不该做
3. 写评估节点：每节点用哪项检查、什么阈值触发下一步；阈值须与论文所用口径一致，不得另立一套，也不得凭经验放宽
4. 写干预参数：处方组成与剂量、药液浓度与配制方法、温度范围与控温方式、单次时长、频次、疗程总次数、头距与体位
5. 写留观与停止：留观时长、观察哪些表现（疼痛、畏光、流泪、眩晕等）、出现哪类反应立即停止并如何处理
6. 写复评与转归：复评时点、判效阈值、有效与无效各自的下一步；无效者何时转诊、转哪一科、带哪些资料过去
7. 配图示：体位、器具相对位置、头距、遮挡与保护（护眼罩、护耳等），一图一事，标出尺寸与方位
8. 标不可文字化：温度手感、病人耐受的即时判断、手法力度，逐条注明须带教、不可仅凭文字掌握
9. 写带教安排：谁带、几次、每次练什么、如何考核，例如独立完成三例并由带教逐例复核签字
10. 做复现验证：找一位未参与研究的同学，只给规范与图示完整操作一次，记录每处停顿、询问与偏差
11. 回改规范：把验证中暴露的歧义逐条改写，标注版本号与修改日期，改后再验一次关键步骤
12. 归档与签收：规范、图示、路径图、带教记录、验证记录一并归档，教学秘书与接手人签收

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 纳入排除与禁忌写在最前
- [ ] 评估阈值与论文口径一致
- [ ] 干预参数含浓度、温度、时长、频次、疗程
- [ ] 留观时长与停止指征已写
- [ ] 复评时点与转归分支已写
- [ ] 图示含体位、头距、保护措施与尺寸
- [ ] 不可文字化部分已逐条标注
- [ ] 带教次数、内容与考核方式已定
- [ ] 他人复现验证已完成并留记录

## H.5 模板：诊疗路径与交接单

| 字段 | 填写要求 |
|------|----------|
| 路径 | 五节点、责任人、动作、依据 |
| 纳入与禁忌 | 病种、证型、年龄、禁忌情形 |
| 评估节点 | 检查项、阈值、触发的下一步 |
| 干预参数 | 处方、浓度、温度、时长、频次、疗程 |
| 安全控制 | 留观时长、停止指征、处置方式 |
| 转归分支 | 有效、无效、转诊的判定与去向 |
| 图示 | 体位、头距、器具位置、保护措施 |
| 不可文字化 | 手感、耐受判断、力度与带教要求 |
| 复现验证 | 验证人、偏差条目、回改内容 |
| 签收 | 版本号、移交人、接手人、日期 |

> 本表是本章的交付物：结题时提交，教学秘书签收；接手人凭此单可独立走完一例。

## H.6 常见失效与处置

- **只写处方不写温度** → 温度是安全边界，缺这一项规范就不能用
- **写区间不写控温方式** → 只写「若干度」而无控温手段与测温位置，等于没写
- **无图示** → 体位、头距、保护位置难以复现，安全风险直接转给接手人
- **不标不可文字化** → 接手人以为照文即可，实际靠手感的部分无人带教
- **不做复现验证** → 未经验证的规范只是作者的自述，不能算移交
- **口头交接不签收** → 人一走信息全失，路径与参数一并归零

## H.7 中期检查与答辩要点

- 路径与参数完整（35%）
- 安全控制与转归分支（25%）
- 图示与不可文字化标注（20%）
- 复现验证与签收（20%）
