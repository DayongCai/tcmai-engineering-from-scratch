## H.1 本章要解决的问题

外治的疗效评价有两个陷阱：一是把「病人说舒服些」当成疗效，二是把不良事件写成「轻微，未处理」。前者无法与测量误差和自然波动区分，后者让安全性结论变成一句空话。这一章要交的是双终点：疗效侧给出主要结局的效应量与应答人数，安全侧给出逐例登记的事件、处置与转归，两侧都不许含糊，也不许用一侧的漂亮数字遮住另一侧的空白。

## H.2 本章目标（可检验）

- 按开题定的主要结局报告效应量、置信区间与应答率
- 逐例登记不良事件，含类型、程度、处置、转归与关联判断
- 给出安全边界：禁忌人群、停止规则与操作参数的安全区间
- 疗效与安全并列表述，不让任何一侧被另一侧掩盖

## H.3 操作流程

1. 复核阈值：把开题时写下的判效阈值再抄一遍，确认统计时没有改；改过须写明改在何时、为什么改、改前改后结论差多少
2. 算主要结局：组内前后差与组间差同时报，给均数差或率差及置信区间，不能只报 P 值
3. 报应答率：按预设阈值把每例判为应答或未应答，报两组人数与比例；失访者按未应答处理并注明，不另设一套算法
4. 报次要结局：症状量表与一项客观检查各一，量表须说明是总分还是分维度，缺失如何处理，分值方向（越高越好还是越差）写清
5. 画个体轨迹：主要结局按病人画前后连线，一眼看出改善是普遍发生还是集中在少数人身上，避免均值掩盖分布
6. 做敏感性分析：把失访、超窗、方案偏离的病例按不同规则再算一次，看结论会不会翻转；翻转了就要在讨论里直说
7. 定安全登记口径：事先定义何为不良事件、何为严重不良事件，谁负责登记、多久内上报、由谁判定关联
8. 逐例登记：事件名称、发生时间、持续时长、程度分级、与干预的时间关系、处置、转归，一例一行，不做汇总后再报
9. 判关联：按肯定、可能、可能无关、无关、无法判断五档给判断与依据，不拿病人主诉替代判断，也不把时间巧合当因果
10. 查参数关联：把事件与操作参数对照——药液浓度、温度、单次时长与头距、留观时间，找出可改的边界与安全余量
11. 定停止规则：出现哪类事件、达到几例即暂停该操作；规则必须在开始前写好，不在事后补
12. 写安全边界：列出禁忌人群、慎用情形、参数安全区间与超限后果，与疗效结论并列陈述，单独成段

## H.5 模板：疗效与安全双终点表

| 字段 | 填写要求 |
|------|----------|
| 主要结局 | 指标、组内差、组间差、置信区间 |
| 应答率 | 阈值、两组人数与比例、失访处理 |
| 次要结局 | 量表口径、客观检查、缺失处理 |
| 个体轨迹 | 图号、改善在人群中的分布特征 |
| 敏感性分析 | 规则、重算结果、结论是否翻转 |
| 事件定义 | 不良事件与严重事件的判定口径 |
| 逐例登记 | 名称、时间、程度、处置、转归 |
| 关联判断 | 五档判断与依据 |
| 参数对照 | 浓度、温度、时长、头距与事件 |
| 安全边界 | 禁忌、慎用、停止规则与超限后果 |

## H.6 常见失效与处置

- **只报 P 值** → 不给效应量与区间，读者判断不了改善有没有临床意义
- **改善小于测量误差** → 把误差当疗效，是五官科外治评价最常见的硬伤
- **失访者被剔除** → 只算完成者，等于只报有效者，结论系统性偏乐观
- **不良事件只写轻微** → 无类型、例数、处置，安全结论无法成立，也无法追责
- **事后补停止规则** → 事件发生后才定规则，属事后合理化，评审必问
- **疗效与安全分开写** → 读者只记住有效、忘了边界；两栏必须并排

## H.7 中期检查与答辩要点

- 主要结局与效应量（30%）
- 应答率与敏感性分析（20%）
- 不良事件登记质量（30%）
- 安全边界与结论克制（20%）
