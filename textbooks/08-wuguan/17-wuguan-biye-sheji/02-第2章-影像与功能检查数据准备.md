## H.1 本章要解决的问题

专科检查的数值，一半来自病人，一半来自操作者与设备。同一只眼，两位医生测的泪膜破裂时间可以差两秒；同一副耳，两台听力计给出的听阈可以差十分贝。这些差异与疗效无关，却会被当成疗效。数据准备要交的不是一张数值表，而是一条能说明「谁、用什么设备、按什么参数、测了几次、取值规则是什么」的测量链；链断了，后面所有统计都白做。

## H.2 本章目标（可检验）

- 固定设备型号、校准状态与检查室条件，并留下可查的记录
- 把每项检查写成可照做的操作流程，含体位、指令与重复次数
- 完成操作者一致性检验，给出测量误差数值与可接受判据
- 建立含原始图像或曲线的检查台账，编号与病例一一对应

## H.3 操作流程

1. 分指标类：把命题涉及的检查分成三类——主观量表、操作者依赖的定量检查（眼压、破裂时间、听阈）、设备自动输出（相干光断层扫描、视野、声导抗），三类误差来源不同
2. 定设备：每项检查只指定一台设备，记型号、序列号、末次校准日期与校准单位；中途换机须视为方法变更并重做一致性
3. 定参数：同一设备同一参数，把扫描模式、视野程序、刺激声频率与强度步进、气导骨导顺序逐项写死，不许用默认值
4. 定环境：检查室照度、背景噪声、屏幕亮度、病人与屏幕的距离；听力检查须记环境噪声是否符合所用耳机的隔声要求
5. 定流程：体位、头位固定方式、注视指令、睁眼闭眼时机、每项重复次数，以及取值规则（三次均值还是最佳值）；规则写在流程里，不许操作者临场决定
6. 统一口径：视力记对数视力还是小数记录、眼压单位与所用眼压计类型、听阈为听力级且注明气导或骨导、破裂时间的计时起点
7. 训练操作者：两名操作者各自按流程练至熟练，练习数据单独存放，不得混入研究数据
8. 做一致性：两名操作者各测同一批受试者，同日完成，互盲对方的读数，先后顺序随机
9. 算误差：用配对差值均数与一致性界限，或组内相关系数表达，不能只报一个平均值
10. 定判据：测量误差必须明显小于命题所设的判效阈值；否则该指标不能作主要结局，只能降为次要或换指标
11. 留原始：图像、曲线、打印报告按「病例号-检查项-日期」存档，保留设备原始格式，不只留截图
12. 建台账与预试：台账含编号、检查项、数值、单位、操作者、设备、时间；先跑三例预试，确认流程无歧义再正式入组

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 每项检查已指定唯一设备与参数
- [ ] 设备型号、序列号、校准日期已记
- [ ] 检查室照度、噪声、距离已记
- [ ] 操作流程含体位、指令、重复次数
- [ ] 取值规则（均值或最佳值）已定
- [ ] 指标口径与单位统一，无混用
- [ ] 操作者已训练，练习数据未混入
- [ ] 一致性检验含互盲与同日测量
- [ ] 误差以一致性界限或相关系数表达
- [ ] 误差小于判效阈值，否则已调整结局
- [ ] 原始图像或曲线按规则命名存档
- [ ] 台账含操作者与设备字段，预试已完成

## H.5 模板：检查台账与测量条件表

| 字段 | 填写要求 |
|------|----------|
| 设备 | 检查项、型号、序列号、校准日期与校准单位 |
| 参数 | 扫描模式、视野程序、刺激声、频率与步进 |
| 环境 | 照度、背景噪声、距离、屏幕亮度 |
| 流程 | 体位、指令、重复次数、取值规则 |
| 口径 | 单位、记录方式、计时起点 |
| 一致性 | 操作者、例数、差值均数、一致性界限 |
| 判据 | 测量误差与判效阈值的比较 |
| 原始文件 | 命名规则、格式、存放路径 |
| 台账 | 编号、数值、操作者、设备、时间 |

> 本表是本章的交付物：条件表贴在设备旁，换机、换参数、换人都要更新版本；台账随论文提交供抽查。

## H.6 常见失效与处置

- **两台设备混用** → 数值不可比，前后差值里混进了设备差，疗效方向都可能反
- **参数被默认值带走** → 换了扫描模式或视野程序，结果不可比却无人察觉
- **只报均值不报误差** → 组间差异落在测量误差内时，结论必然站不住
- **一致性不互盲** → 后测者看着前一个读数测，误差被系统性低估
- **只留截图** → 无法回读原始曲线，复核与重算都做不了
- **口径混用** → 一只眼记小数视力、一只记对数视力，合并即错

## H.7 中期检查与答辩要点

- 设备与参数固定（30%）
- 流程与口径统一（25%）
- 一致性检验与判据（30%）
- 原始数据与台账（15%）
