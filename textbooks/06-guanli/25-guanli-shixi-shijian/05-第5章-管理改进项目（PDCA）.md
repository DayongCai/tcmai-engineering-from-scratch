## H.1 本章要解决的问题

改进项目最常见的失败是「有计划、无验证」：改完没人量，最后只能说「感觉好多了」。

## H.2 本章目标（可检验）

- 完成一个 PDCA 闭环（含基线数据）
- 定义可量化的改进指标
- 给出是否有效的判断

## H.3 操作流程

1. P：选一个问题，取基线数据（至少两周）
2. D：实施一条具体改动（只改一条，便于归因）
3. C：用同一指标再测两周，比较变化
4. A：判断有效与否，无效则改假设
5. 固化：有效则写进制度或流程

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 基线数据≥2 周
- [ ] 改进措施唯一且具体
- [ ] 指标定义与取数方式不变
- [ ] 改进后数据≥2 周
- [ ] 前后对比已做
- [ ] 有效性判断已写
- [ ] 固化方式已写

## H.5 模板：PDCA 一页纸

| 字段 | 填写要求 |
|------|----------|
| 问题与基线 | 现象、指标、基线值 |
| 措施 | 一条，含责任人与时间 |
| 复测 | 同指标、改进后值 |
| 判断 | 有效/无效及依据 |
| 固化 | 写进哪个制度或流程 |

> 本表是本章的交付物：实习报告首页，答辩看这一页。

## H.6 常见失效与处置

- **同时改多项** → 无法归因；一次只改一条
- **基线没取** → 没有基线就没有改进，只有变化
- **指标中途换口径** → 前后不可比，等于没测

## H.7 出科考核

- 基线完整性（40%）
- 措施单一性（20%）
- 判断与固化（40%）
