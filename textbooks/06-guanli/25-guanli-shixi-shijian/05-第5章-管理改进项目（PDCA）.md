# 第 5 章 · 管理改进项目（PDCA）

> **课程**：管理实习与实践（📊 管理系 · 第 9 学期 · 108 学时 · 轮转/实践）
> **契约**：**操作型章（handbook-v1）** —— 本文件是工作手册，不是学术教材：给的是当场能执行的流程、清单与模板。
> **前置**：医院管理学、医疗保险与卫生经济、医院信息化与病案管理
> **本章产出物**：PDCA 项目记录表
> 学术型教材的 N.1–N.5 契约（含 N.3「这个翻译丢掉了什么」）**不适用**本课程，理由见 `textbooks/README.md`「操作型章契约」。

## H.1 本章要解决的问题

改进项目最常见的失败不是「想不到办法」，而是「说不清改了什么」：措施一堆、指标没动、或者指标动了但没人知道是哪条措施起的作用。PDCA 的价值在于把「改动」变成可验证的实验：一条主措施、一个主指标、一个明确的对照期。

## H.2 本章目标（可检验）

- 完成一个改进项目的完整闭环：问题定义、基线测量、措施实施、效果验证、标准化
- 用一张图说清「措施—指标」的因果链与验证方式
- 产出可移交的标准化文件（SOP 或检查表）与复测计划

## H.3 操作流程

1. 问题定义：用数据描述问题（发生率、时长、返工率），避免形容词；写清影响对象与量级
2. 基线测量：同口径连续测 2–4 周，记录样本量与波动范围；基线不稳的项目先稳测量
3. 目标设定：给出可测目标（如「3 个月内从 62% 提升到 85%」），并说明依据
4. 原因分析：鱼骨图或 5Why，落到可改的环节；每条原因配一条验证证据
5. 措施排序：按「影响大小 × 实施难度」排序，选 1–2 条主措施，其余列为后续
6. 措施设计：写清动作、责任人、频次、所需资源、开始时间；避免一次性运动式措施
7. 实施与记录：每周记执行率（措施做了几次/应做几次），执行率不达标先修执行再谈效果
8. 过程监测：主指标 + 平衡指标（防止按下葫芦浮起瓢，如效率提升但差错上升）
9. 效果验证：与基线同口径对比，给出变化幅度与统计不确定性的说明（样本小时不夸大）
10. 标准化：把有效动作写进 SOP/检查表/系统校验，明确谁维护、何时复审
11. 复测与移交：设定 1 个月与 3 个月复测点，移交责任人与数据来源
12. 报告：按 H.5 模板成文，附执行率曲线与主指标曲线

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 问题用数据描述，含量级与影响对象
- [ ] 基线连续测量≥2 周且口径固定
- [ ] 目标可测且写明依据
- [ ] 原因分析落到可改环节，每条有验证证据
- [ ] 主措施≤2 条，附排序理由
- [ ] 措施含责任人、频次、资源、开始时间
- [ ] 每周执行率有记录，未达标先修执行
- [ ] 主指标与平衡指标同时监测
- [ ] 效果对比同口径，未夸大统计意义
- [ ] 有效动作已写入 SOP/检查表/系统校验
- [ ] 复测点与责任人已定
- [ ] 报告含执行率与主指标两条曲线

## H.5 模板：PDCA 项目记录表

| 字段 | 填写要求 |
|------|----------|
| 问题定义 | 指标、现值、影响对象、量级 |
| 基线 | 测量周期、样本量、波动范围 |
| 目标 | 目标值、期限、依据 |
| 原因 | 分析工具、原因清单、验证证据 |
| 措施 | 主措施、责任人、频次、资源、开始时间 |
| 执行率 | 每周应做/实做/执行率 |
| 指标 | 主指标与平衡指标曲线 |
| 效果 | 同口径对比、变化幅度、不确定性说明 |
| 标准化 | SOP/检查表/系统校验、维护人、复审周期 |
| 复测与移交 | 1/3 个月复测点、数据来源、责任人 |

> 本表是本章的交付物：每周更新一页；项目结束装订成册，作为标准化依据。

## H.6 常见失效与处置

- **问题用形容词描述** → 「效率低」无法测量，也就无法验证改进
- **基线不稳就上措施** → 效果无法归因，白做一轮
- **措施一次上五条** → 分不清哪条有效；主措施应≤2 条
- **不看执行率只看结果** → 措施没做就谈无效，是常见误判
- **只测主指标** → 副作用无人发现；平衡指标必须有
- **有效但不标准化** → 人一走就回弹，项目等于没做

## H.7 出科考核

- 问题定义与基线（30%）
- 措施设计与执行率（30%）
- 效果验证与指标设计（25%）
- 标准化与移交（15%）
