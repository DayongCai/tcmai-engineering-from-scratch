## H.1 本章要解决的问题

管理实习报告的读者是「要做决定的人」：他们没有时间看你走了几个科室，只想知道三件事——问题有多大、你建议做什么、做了会怎样。报告写成一页纸能说清，比二十页的过程记录更有用。

## H.2 本章目标（可检验）

- 写出一份含数据、判断、建议、可验证性四要素的实践报告
- 报告中每个数字可溯源（表号/系统/时间），每个建议有责任岗位与测法
- 在 15 分钟答辩中回答「你的建议需要多少钱、多久见效、谁来负责」

## H.3 操作流程

1. 收口选题：从五个现场中选一个有数据支撑的问题，写成一句可检验的命题
2. 材料清点：核对表、抽样清单、访谈记录、费用表、PDCA 记录逐份编号，缺失如实标注
3. 数据口径：统一分母与时间窗，写清取数时间与版本
4. 结论分层：确定结论/提示性结论/无法结论三档，各附证据编号
5. 建议设计：每条含「做什么—谁负责—多久—怎么测—需要什么资源」
6. 成本与收益：能给量级就给（人力小时、返工次数、费用占比），不能给就写「需进一步测算」
7. 风险与边界：合规、资源、执行阻力三类风险各写一条；写明本报告的适用边界
8. 图表：每张图一个结论，图注含样本量与口径
9. 格式：按学院模板；引用制度与政策写编号与条款
10. 自查：逐条核对「每个数字有来源、每条建议有责任岗位」
11. 答辩准备：三个必答题——数据可信吗、建议可行吗、怎么知道有效
12. 归档：报告、原始材料、答辩记录三件一并交

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 全部原始材料编号，缺失如实标注
- [ ] 分母与时间窗统一，取数版本已记
- [ ] 结论分三档，各附证据编号
- [ ] 每条建议含责任岗位、时限、测法、资源
- [ ] 成本与收益给量级或注明需测算
- [ ] 三类风险各一条，边界已写

- [ ] 引用写编号与条款

## H.5 模板：管理实践报告结构与答辩评分表

| 字段 | 填写要求 |
|------|----------|
| 命题与背景 | 一句话命题、为什么现在做 |
| 数据与口径 | 分母、时间窗、取数版本、样本量 |
| 发现 | 确定/提示/无法结论三档 + 证据编号 |
| 建议 | 做什么、谁负责、多久、怎么测、资源 |
| 成本收益 | 量级或需测算说明 |
| 风险与边界 | 合规、资源、阻力；适用边界 |
| 可验证性 | 复测时点、口径、责任人 |
| 答辩记录 | 三个必答题与追问 |
| 评分 | 数据可溯源 35%、建议可行性 30%、结论分寸 20%、答辩 15% |
| 归档 | 报告、原始材料、答辩记录，签收人 |

> 本表是本章的交付物：按左栏结构写作；答辩用右栏评分，两份一并归档。

## H.6 常见失效与处置

- **写成走马观花** → 没有命题与数据，读者无法据此决策
- **数字无来源** → 被追问即崩；每个数字要能指到表号或系统
- **建议没有负责人** → 「建议加强协同」无人认领，等于没建议
- **结论拔高** → 单科室三个月的数据不能推全院规律
- **忽略成本** → 不问钱与人的建议在管理场景里不可执行
- **不写边界** → 读者把实习报告当决策依据，风险转嫁给了报告

## H.7 出科考核

- 数据可溯源（35%）
- 建议可行性与责任落实（30%）
- 结论分寸与边界（20%）
- 答辩（15%）
