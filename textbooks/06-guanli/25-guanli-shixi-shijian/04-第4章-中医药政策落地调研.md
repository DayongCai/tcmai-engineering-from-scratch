# 第 4 章 · 中医药政策落地调研

> **课程**：管理实习与实践（📊 管理系 · 第 9 学期 · 108 学时 · 轮转/实践）
> **契约**：**操作型章（handbook-v1）** —— 本文件是工作手册，不是学术教材：给的是当场能执行的流程、清单与模板。
> **前置**：医院管理学、医疗保险与卫生经济、医院信息化与病案管理
> **本章产出物**：政策落地对照表
> 学术型教材的 N.1–N.5 契约（含 N.3「这个翻译丢掉了什么」）**不适用**本课程，理由见 `textbooks/README.md`「操作型章契约」。

## H.1 本章要解决的问题

政策调研最容易写成「文件摘抄 + 表态」。有用的调研要回答三个问题：这条政策要求的具体动作是什么、本院现在做到什么程度、差距卡在哪个条件上（人、钱、系统、资质）。答不出第三个，报告就没有价值。

## H.2 本章目标（可检验）

- 把一条政策拆成可核对的动作清单（谁做、做什么、什么时限、什么凭证）
- 完成一次现状对照：做到/部分做到/未做到，各附证据
- 写出差距的约束条件与可行的推进路径（含前置条件）

## H.3 操作流程

1. 选政策：优先选与本院业务直接相关的条款（如中医诊疗模式创新、基层中医药服务、院内制剂、师承教育）
2. 拆条文：逐条拆成「主体—动作—时限—凭证」四要素；不愿拆的条文说明它不可执行
3. 建清单：把可核对的动作列成表，每项写判定标准（什么算做到）
4. 定证据：每项明确要什么证据（制度文件、台账、系统截图、现场查看、访谈）
5. 现状核查：按证据逐项判定三态（做到/部分/未做到），部分做到要写清缺哪一部分
6. 访谈：与责任科室、临床一线各访谈，问「这条为什么没做到」，记录约束条件
7. 约束归类：人（编制与能力）、钱（预算与收费）、系统（信息化支持）、资质（许可与备案）、协同（跨部门）
8. 差距量化：做到率、缺口项数、关键缺口（阻塞性 vs 改善性）
9. 路径设计：按「前置条件 → 第一步 → 里程碑 → 验收证据」写，标注需谁批
10. 风险提示：合规风险（如资质未批先做）、资源风险（人力不足）、舆情风险
11. 报告：按 H.5 模板成文，条文原文与判定分栏，避免把解释写成结论
12. 答辩：回答「如果只给你三个月和一个兼职人员，你先做哪一项」

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 政策条文逐条拆成四要素（主体/动作/时限/凭证）
- [ ] 每条动作有判定标准与证据类型
- [ ] 现状判定为三态，部分做到写清缺哪部分
- [ ] 访谈覆盖责任科室与一线，原话记录
- [ ] 约束条件按五类归因
- [ ] 做到率与缺口项数已量化
- [ ] 关键缺口标注阻塞性/改善性
- [ ] 路径含前置条件、里程碑与验收证据
- [ ] 三类风险已提示
- [ ] 条文原文与判定分栏呈现
- [ ] 报告未把解释写成结论
- [ ] 答辩能给出三个月最小可行动作

## H.5 模板：政策落地对照表

| 字段 | 填写要求 |
|------|----------|
| 条文 | 文件名称、条款号、原文 |
| 四要素 | 主体、动作、时限、凭证 |
| 判定标准 | 什么算做到 |
| 证据 | 类型与编号（制度/台账/截图/访谈） |
| 现状 | 做到/部分/未做到 + 缺口描述 |
| 约束 | 人/钱/系统/资质/协同 |
| 量化 | 做到率、缺口项数、阻塞性判定 |
| 路径 | 前置条件、第一步、里程碑、验收证据 |
| 风险 | 合规、资源、舆情 |
| 结论 | 可执行动作与需上级决策事项 |

> 本表是本章的交付物：一条政策一张表；逐条判定，附证据编号，报告正文引用表号。

## H.6 常见失效与处置

- **写成文件摘抄** → 没有现状与差距，报告无法支撑任何决策
- **判定标准含糊** → 「基本落实」无法核对；要写什么算做到
- **只访谈管理层** → 一线才知道卡在哪；两层都要问
- **把约束写成「重视不够」** → 这不是约束条件，改不动；要落到人钱系统资质
- **路径无前置条件** → 资质未批就开展，属合规风险
- **结论与条文混写** → 读者分不清哪是政策原文、哪是你的判断

## H.7 出科考核

- 条文拆解与判定标准（30%）
- 证据与现状核查（30%）
- 约束归因与路径设计（25%）
- 报告与答辩（15%）
