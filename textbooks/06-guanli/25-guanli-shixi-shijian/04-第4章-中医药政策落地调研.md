## H.1 本章要解决的问题

政策文件写得清楚，落到科室常常变形。调研要能说清「文件要求什么、实际做到什么、差在哪」。

## H.2 本章目标（可检验）

- 能把一条政策要求拆成可核查条款
- 能通过访谈与现场核实执行情况
- 能写出差距与原因

## H.3 操作流程

1. 选条款：挑一条与本院直接相关的政策要求
2. 拆解：把要求拆成三条以上可核查项
3. 核实：查台账、看现场、访谈两个岗位
4. 比对：逐条判断已落实、部分落实、未落实
5. 归因：人力、信息系统、激励、认知四类归因

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 政策条款出处写到文号
- [ ] 拆解为≥3 条可核查项
- [ ] 台账与现场证据均有
- [ ] 访谈两个以上岗位
- [ ] 逐条判定已写
- [ ] 原因归入四类
- [ ] 建议与责任部门已写

## H.5 模板：政策落地核查表

| 字段 | 填写要求 |
|------|----------|
| 政策 | 文号与条款原文 |
| 核查项 | ≥3 条 |
| 证据 | 台账、现场、访谈 |
| 判定 | 落实/部分/未落实 |
| 归因 | 人力/系统/激励/认知 |

> 本表是本章的交付物：调研报告核心表。

## H.6 常见失效与处置

- **只读文件不下现场** → 落地差异只有现场能看见
- **条款不写文号** → 无法核验；引用必须到条款
- **归因笼统写「重视不够」** → 要落到人力或系统等可改因素

## H.7 出科考核

- 条款拆解（30%）
- 证据充分性（40%）
- 归因与建议（30%）
