## H.1 本章要解决的问题

医务科的工作是「把个案变成制度」。实习生最常见的产出是一份描述性报告：「发现病历书写不规范」——但医务科要的是：不规范发生在哪些科室、哪几个字段、占比多少、按什么规则判、改哪一条流程能降下来。没有口径与基线的报告，进不了质控会议。

## H.2 本章目标（可检验）

- 独立完成一次质控抽样：定义抽样框、抽样量、判定标准与记录方式
- 把发现的问题归到「流程环节」而不是「个人态度」
- 产出一份能在质控会上使用的简报（含基线、问题分布、改进建议与复测方法）

## H.3 操作流程

1. 接题：与带教确认本次质控主题（如病历时限、知情同意、危急值处置），写清范围与时间窗
2. 找判据：把判定标准落到条文（院内制度编号、条款原句），逐条抄成核对表；无判据的项不纳入统计
3. 定口径：明确分母（纳入哪些病历、排除哪些）、分子（什么算不合格）、时间窗；口径写进报告首页
4. 抽样：按科室分层随机抽样，样本量写清（如每科室 20 份），记录抽样方法与随机方式
5. 核查：逐份对照核对表打勾，不合格项写「字段—实际内容—判据条款」，不做主观评价
6. 归类：把不合格项归到流程环节（模板缺失、培训不足、系统无强制校验、人力不足），每类给占比
7. 基线：算出本次合格率与各类问题占比，作为后续复测的比较基准
8. 访谈：选 3–5 位一线人员，问「为什么这一项容易漏」，记录原话（不加工）
9. 改进建议：每条建议指向一个环节与一个责任岗位，写清「改什么、谁改、多久见效、怎么测」
10. 复测设计：确定复测时点、样本量与同口径；写明若无效的下一步
11. 汇报：按 H.5 模板做 1 页简报（问题—数据—原因—建议—复测），准备被追问「分母是多少」
12. 归档：核对表、抽样清单、访谈记录、简报四件一并归档

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 质控主题、范围、时间窗已书面确认
- [ ] 每条判据能指到制度编号与条款原句
- [ ] 分母、分子、排除项口径写在报告首页
- [ ] 抽样方法与样本量写清，分科室分层
- [ ] 不合格项按「字段—实际—条款」三段记录
- [ ] 问题已归类到流程环节并给占比
- [ ] 基线合格率已算出
- [ ] 访谈≥3 人，原话记录未加工
- [ ] 每条建议含环节、责任岗位、见效期、测法
- [ ] 复测时点与同口径已写
- [ ] 简报 1 页可读，能答「分母是多少」
- [ ] 四件材料归档

## H.5 模板：质控抽样与简报模板

| 字段 | 填写要求 |
|------|----------|
| 主题与范围 | 质控主题、科室范围、时间窗 |
| 判据 | 制度编号、条款原句、核对项 |
| 口径 | 分母、分子、排除项 |
| 抽样 | 方法、样本量、随机方式 |
| 结果 | 合格率、问题分布、分类占比 |
| 归因 | 流程环节分类与占比 |
| 访谈 | 对象、原话、共性原因 |
| 建议 | 环节、责任岗位、见效期、测法 |
| 复测 | 时点、样本量、同口径说明 |
| 附件 | 核对表、抽样清单、访谈记录 |

> 本表是本章的交付物：核对表现场用；简报用于质控会汇报，一页纸，附抽样清单备查。

## H.6 常见失效与处置

- **没有判据就统计** → 「不规范」无标准，结论无法在会议上站住
- **口径不清** → 分母变了合格率就没法比较，复测也失效
- **只抽样不随机** → 抽自己方便的 10 份，结论不可推广
- **归因到「态度不认真」** → 不可改的问题不该写进建议；要归到流程与系统
- **建议没有责任岗位** → 「加强培训」无人认领，等于没建议
- **不设计复测** → 无法证明改进有效，项目停在报告阶段

## H.7 出科考核

- 判据与口径的严谨性（30%）
- 抽样与记录规范（25%）
- 归因与建议的可执行性（25%）
- 简报表达与答辩（20%）
