## H.1 本章要解决的问题

医务科的工作看起来是发文与检查，实际是「把风险变成流程」。实习生要能读懂一个流程卡点，而不是抄制度目录。

## H.2 本章目标（可检验）

- 能画出一个真实业务流程并标出卡点
- 能读懂质控指标的定义与取数口径
- 能提出一条可执行的改进建议

## H.3 操作流程

1. 选流程：挑一个高频流程（会诊、危急值、转科）
2. 跟单：跟三例真实单据走完全程，记录每步耗时
3. 找卡点：标出等待、返工、信息断点
4. 读指标：查该流程对应的质控指标定义与口径
5. 提建议：一条，写清改什么、谁执行、怎么验证

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 流程图画到岗位级
- [ ] 三例跟单记录齐全
- [ ] 卡点标注≥3 处
- [ ] 质控指标定义已抄录
- [ ] 取数口径已问清
- [ ] 改进建议含验证方式
- [ ] 涉患者信息已脱敏

## H.5 模板：流程卡点分析表

| 字段 | 填写要求 |
|------|----------|
| 流程 | 名称、起止、涉及岗位 |
| 跟单记录 | 三例，各步耗时 |
| 卡点 | 位置、类型、影响 |
| 对应指标 | 定义与口径 |
| 改进建议 | 动作、责任人、验证方式 |

> 本表是本章的交付物：实习第一周提交，作为改进项目选题依据。

## H.6 常见失效与处置

- **抄制度当成果** → 制度目录不反映实际流程；必须跟单
- **只看平均耗时** → 卡点常在中位数之外的长尾；要看分布
- **建议无责任人** → 无人执行等于没建议

## H.7 出科考核

- 流程图与跟单（40%）
- 卡点识别（30%）
- 建议可执行性（30%）
