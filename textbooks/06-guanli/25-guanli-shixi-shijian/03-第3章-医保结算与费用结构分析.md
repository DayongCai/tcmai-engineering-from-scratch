## H.1 本章要解决的问题

同样一个病种，不同科室的费用结构差别很大。实习生要能从数据里看出「贵在哪」。

## H.2 本章目标（可检验）

- 能取一个病种的费用明细并分类
- 能计算费用结构占比
- 能指出一项可优化的费用项

## H.3 操作流程

1. 定病种：选一个出院量足够且诊断明确的病种
2. 取数：按病种取费用明细，含项目分类
3. 分类：药、耗材、检查、治疗、床位、护理
4. 算结构：各类占比与人均费用
5. 找差异：与院均值或同级医院比较，指出最大偏离项

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 病种与诊断口径已写死
- [ ] 取数范围与时间已记
- [ ] 费用分类规则已写
- [ ] 占比与人均已算
- [ ] 比较对象已说明
- [ ] 最大偏离项已定位
- [ ] 数据脱敏

## H.5 模板：费用结构分析表

| 字段 | 填写要求 |
|------|----------|
| 病种口径 | 诊断、入排、时间 |
| 费用分类 | 六类规则 |
| 结构 | 占比与人均 |
| 比较 | 对照对象与差异 |
| 偏离项 | 最大项与可能原因 |

> 本表是本章的交付物：实习报告核心表。

## H.6 常见失效与处置

- **口径不写死** → 同一病种不同口径无法比较
- **只看总费用** → 结构差异才是管理抓手
- **把差异当浪费** → 可能是病情更重；须做病例组合校正

## H.7 出科考核

- 口径与取数（40%）
- 结构计算（30%）
- 偏离项解释（30%）
