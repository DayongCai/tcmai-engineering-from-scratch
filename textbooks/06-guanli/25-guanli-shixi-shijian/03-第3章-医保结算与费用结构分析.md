## H.1 本章要解决的问题

医保数据分析最容易犯的错是「拿总额说事」：总额涨了就说费用控制不好，却没看是病例组合变了、还是单价变了、还是自费比例变了。实习要练的是拆解——把费用变化拆成量、价、结构三个因子，并说清每个因子的可控性。

## H.2 本章目标（可检验）

- 独立完成一次科室或病种费用结构分析（收入构成、药占比、耗材占比、自费比例）
- 把费用变化拆分为量、价、结构三因子，并给出各自贡献度
- 识别结算中的合规风险点（分解住院、低标入院、串换项目）并说明判据

## H.3 操作流程

1. 确定分析对象：科室/病种/时间段；先对齐口径（出院人次、入组规则、结算方式）
2. 取数：从结算清单与病案首页取字段，记录取数时间与口径版本（数据会变）
3. 总量与结构：总费用、药费、耗材费、检查检验费、治疗费、床位护理费；算各项占比
4. 人次与次均：出院人次、次均费用、次均药费；区分「人次增长」与「次均增长」
5. 三因子分解：费用变化 = 量（人次）× 价（次均）× 结构（病种/术式构成），逐项算贡献
6. 病种结构：按病种或 DRG/DIP 组分层，看高费用组占比是否上升
7. 自费与自付：自费比例、目录内外构成；高自费项目集中在哪里
8. 合规风险筛查：分解住院（短期再入院同病种）、低标入院（住院日与资源消耗异常低）、串换项目（收费与医嘱不符）、超限用药
9. 原因访谈：与临床、医保办各访谈 1–2 人，记录解释（不采信单一来源）
10. 结论分层：确定结论（数据支持）、待验证（需更多数据）、无法判断（口径不明）
11. 建议：分「可立即改」（收费与医嘱一致性、路径管理）与「需协同」（病种结构、采购）
12. 报告与复算：按 H.5 模板成文；给出复算方法，使他人用同口径能得到同样数字

## H.5 模板：费用结构分析表与合规风险清单

| 字段 | 填写要求 |
|------|----------|
| 对象与口径 | 科室/病种、时间段、人次口径、结算方式 |
| 取数说明 | 系统、时间、口径版本 |
| 费用构成 | 六类费用金额与占比 |
| 人次与次均 | 出院人次、次均费用、次均药费 |
| 三因子分解 | 量、价、结构，各贡献度 |
| 病种结构 | 组别分布与高费用组占比变化 |
| 自费分析 | 自费比例、目录内外构成、集中项目 |
| 合规风险 | 类型、判据、证据、初步结论 |
| 访谈 | 对象、原话、一致性判断 |
| 建议与复算 | 可立即改/需协同、复算方法 |

> 本表是本章的交付物：结构表按月更新；风险清单逐条附判据与证据，供医保办核查。

## H.6 常见失效与处置

- **只看总费用不看结构** → 总额变化可能来自病例组合，不是浪费
- **人次与次均混算** → 无法判断是量的问题还是效率问题
- **口径不写清** → 换个人算就得出不同数字，分析失去可信度
- **把相关当因果** → 费用上升与某政策同期出现，不等于政策导致
- **合规风险只列现象** → 必须给判据与证据，否则无法核查
- **建议脱离权限** → 实习生提「调整支付方式」没有意义，要提能落地的动作
