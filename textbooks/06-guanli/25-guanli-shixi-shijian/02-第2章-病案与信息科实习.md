## H.1 本章要解决的问题

病案质量决定的不是文书好看，而是能不能用于结算、评价与科研。实习生要看懂一份病案在三处怎么被用。

## H.2 本章目标（可检验）

- 能按病案质量评分标准抽查五份病历
- 能说明主要诊断选择对入组与结算的影响
- 能写出一个数据质量问题清单

## H.3 操作流程

1. 读标准：病案质量评分表逐项读一遍
2. 抽查：随机五份，逐项打分并记录扣分点
3. 看编码：主要诊断与手术操作编码是否与病程一致
4. 看流向：病案数据如何进入上报与结算
5. 列问题：按频次排出前三条数据质量问题

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 评分表逐项理解并记录
- [ ] 五份抽查评分完成
- [ ] 扣分点具体到段落
- [ ] 主要诊断选择已核查
- [ ] 编码与病程一致性已核
- [ ] 数据流向已画清
- [ ] 问题清单按频次排序

## H.5 模板：病案质量抽查表

| 字段 | 填写要求 |
|------|----------|
| 评分表 | 项目与分值 |
| 抽查结果 | 五份得分与扣分点 |
| 主要诊断 | 是否恰当、依据 |
| 编码一致性 | 与病程是否相符 |
| 问题清单 | 前三条及频次 |

> 本表是本章的交付物：五份一页，随实习报告提交。

## H.6 常见失效与处置

- **只看得分不看扣分点** → 得分相同问题不同；扣分点才有信息
- **忽略主要诊断选择** → 直接影响入组与结算金额
- **把编码错误当录入错误** → 编码错多源于病程描述不清

## H.7 出科考核

- 抽查规范性（40%）
- 诊断与编码核查（30%）
- 问题排序合理性（30%）
