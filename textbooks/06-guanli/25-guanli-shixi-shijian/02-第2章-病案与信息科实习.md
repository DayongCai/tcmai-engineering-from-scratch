## H.1 本章要解决的问题

病案首页的数据质量问题有个特点：错在末端、因在上游。编码员改得再仔细，如果临床写的诊断名称不规范、手术操作漏填，首页数据仍然不可用。实习要练的是「顺着一个字段往上追」——这个数字是从哪张单子、哪个环节来的，谁改得动它。

## H.2 本章目标（可检验）

- 独立完成一次首页字段核查：抽取样本、比对原始病历、记录差异类型
- 能画出某个关键指标（如平均住院日、CMI）的数据链路：来源表—计算规则—口径
- 产出一份数据质量报告，区分「录入错误」「口径差异」「源头缺失」三类

## H.3 操作流程

1. 选字段：从主要诊断、其他诊断、手术操作、入院病情、离院方式中选 3–5 个高影响字段
2. 定判据：对照病案填写规范与编码规则，写清「什么算错」（如主诊断选择错误、编码与名称不符、漏填）
3. 抽样：按科室分层抽取 30–50 份，记录病历号、科室、出院日期
4. 比对：首页 vs 病历原文（入院记录、病程、手术记录、出院小结），逐份记录差异
5. 差异分类：录入错误（笔误/漏填）、口径差异（同一概念不同定义）、源头缺失（病历未写导致无法编码）、编码规则理解差异
6. 数据链路：选一个指标，写出「原始记录 → 首页字段 → 数据库表 → 计算公式 → 报表」五步，标出每步的责任岗位
7. 口径核对：把院内口径与外部上报口径（如公立医院绩效考核、医保结算清单）并列，标出差异项
8. 影响评估：估算该字段错误对指标的影响（如主诊断错误对 CMI 与入组的影响方向）
9. 改进建议：分「系统层」（必填校验、下拉限定）、「流程层」（出院前自查、编码前置）、「培训层」三类
10. 复测设计：同口径复测时点与样本量
11. 报告：按 H.5 模板成文，附差异清单（可脱敏）
12. 归档与答辩：材料归档，答辩须回答「这个错误是谁造成的」——答案应是环节，不是个人

## H.5 模板：病案首页数据质量核查表

| 字段 | 填写要求 |
|------|----------|
| 样本信息 | 病历号（脱敏）、科室、出院日期 |
| 核查字段 | 字段名、判据、规范条款 |
| 比对结果 | 首页值 vs 病历原文 vs 判定 |
| 差异类型 | 录入/口径/源头缺失/编码理解 |
| 数据链路 | 原始记录→字段→表→公式→报表，责任岗位 |
| 口径差异 | 院内 vs 外部，差异项与影响 |
| 影响评估 | 对指标的方向与量级 |
| 建议 | 系统层 / 流程层 / 培训层，各附责任岗位 |
| 复测 | 时点、样本量、口径 |
| 附件 | 脱敏差异清单 |

> 本表是本章的交付物：逐份填写；汇总页用于报告，差异清单脱敏后可作为培训素材。

## H.6 常见失效与处置

- **只改首页不看原文** → 编码员改得再细，源头缺失仍无法解决
- **判据含糊** → 「填写不规范」无法统计；必须写清什么算错
- **不区分口径差异与错误** → 把口径问题当错误统计，会得出错误的改进方向
- **归因到编码员个人** → 首页错误的多数成因在临床书写与系统设计
- **忽略外部口径** → 院内合格但上报不合格，是常见返工来源
- **不估影响** → 不知道错 5% 会造成什么后果，改进就排不上优先级

## H.7 出科考核

- 判据与差异分类（30%）
- 比对与原文溯源（25%）
- 数据链路与口径核对（25%）
- 建议与影响评估（20%）
