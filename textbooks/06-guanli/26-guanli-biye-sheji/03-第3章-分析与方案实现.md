## H.1 本章要解决的问题

管理方案最常见的死法是「方案写了三十页，没人执行」。本章要求方案落到岗位、动作与时限。

## H.2 本章目标（可检验）

- 把方案拆成岗位动作与时限
- 指出方案实施的两个前提条件
- 完成一次小范围试运行

## H.3 操作流程

1. 拆动作：每条措施对应谁、什么时候做、做多久
2. 定前提：人力、系统、授权三项逐一确认
3. 试运行：选一个班组试一周
4. 收反馈：执行者说清哪里做不到
5. 修订：按反馈改一版并记录改动

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 措施与岗位一一对应
- [ ] 每项有时限
- [ ] 三项前提已确认
- [ ] 小范围试运行已完成
- [ ] 执行者反馈已记录
- [ ] 修订记录已写
- [ ] 与指标口径对齐

## H.5 模板：方案落地表

| 字段 | 填写要求 |
|------|----------|
| 措施 | 逐条 |
| 岗位与时限 | 谁、何时、多久 |
| 前提 | 人力/系统/授权 |
| 试运行 | 范围、结果 |
| 修订 | 改了什么、为什么 |

> 本表是本章的交付物：答辩时展示执行链。

## H.6 常见失效与处置

- **方案没有责任人** → 无人执行；措施必须落到岗位
- **跳过试运行** → 纸面可行不等于现场可行
- **修订不留痕** → 无法说明最终方案从哪来

## H.7 中期检查与答辩要点

- 动作与岗位（40%）
- 试运行（30%）
- 修订留痕（30%）
