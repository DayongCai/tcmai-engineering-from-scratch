## H.1 本章要解决的问题

管理答辩最容易被追问「数据从哪来、谁给你授权、口径谁定的」。三问答不上，结论就无法成立。

## H.2 本章目标（可检验）

- 论文数据与核查表一致
- 15 分钟讲清问题、指标、方案、效果、成本
- 准备三个数据治理类质疑

## H.3 操作流程

1. 对表：数值回溯核查表
2. 写结构：问题、指标、方案、效果、成本五段
3. 附证据：指标定义、取数说明、授权文件
4. 预设质疑：数据授权、口径、可比性
5. 试讲

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 数值与核查表一致
- [ ] 五段结构齐全
- [ ] 指标定义与取数说明已附
- [ ] 授权与脱敏证明已附
- [ ] 三个质疑有答案
- [ ] 引用政策写到文号
- [ ] 免责与致谢已写

## H.5 模板：答辩准备表（管理）

| 字段 | 填写要求 |
|------|----------|
| 核心结论 | ≤40 字 |
| 证据链 | 指标→数据→方案→效果 |
| 三个质疑 | 授权/口径/可比性 |
| 边界 | 单科室与时段限制 |
| 试讲反馈 | 修改点 |

> 本表是本章的交付物：答辩前一天自查。

## H.6 常见失效与处置

- **数据来源说不清** → 无授权数据不能用于论文
- **口径被问倒** → 定义表必须随身带
- **只讲效果不讲成本** → 管理评价必须算账

## H.7 中期检查与答辩要点

- 数据合规（一票否决项）
- 结论链条（40%）
- 质疑回答（30%）
