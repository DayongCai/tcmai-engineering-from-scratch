## H.1 本章要解决的问题

管理答辩最容易被追问三句：数据从哪来、谁给你授权、口径是谁定的。三问答不上，效果再好也无法成立。论文的任务不是把过程记录誊清，而是把「问题—指标—方案—效果—成本」串成一条外人可复核的链，并说清结论在什么范围内成立。链断在任何一环，全文都只是描述；三份材料——定义表、授权、成本表——答辩时应随手可翻。

## H.2 本章目标（可检验）

- 论文数据与核查表逐项对得上，每个数字可指到表号或系统
- 15 分钟讲清问题、指标、方案、效果与成本五段
- 准备数据治理三类质疑（授权、口径、可比性）的书面答复
- 结论分档并写明适用边界

## H.3 操作流程

1. 定主线：一句话写清「本研究证明了什么、在什么条件下」，全文取舍围绕它，与主线无关的图表移入附录
2. 结构：摘要（背景、方法、结果、结论四句）、引言（现象与缺口）、方法与数据（口径、取数、核查）、方案与实施（岗位、时限、执行率）、结果（效果与成本）、讨论、边界、结论
3. 方法章写口径：指标定义表原样附入，含分子分母、时窗、排除、版本与取数日期，不写「按医院统计口径」这种空话，口径表述以定义表原文为准
4. 附证据：数据使用授权或审批记录、脱敏说明、取数脚本或筛选条件说明，证据单独编页并把页码写进答辩提纲
5. 结果章：一图一结论，图注含样本量、时段、口径版本与判据线；副图不超过两张，避免堆砌，也不必为每张图配一段文字复述
6. 成本章：投入与效益分列，单位统一，注明哪些是估算、估算依据是什么，估算与实测分开标注，不得把估算写成实测值
7. 讨论章：与至少 3 项同类研究或院内既往改进比对，一致与不一致处各给原因假设，不只复述结果；不一致处至少给两种可能原因
8. 边界章：单科室、单时段、样本量、执行率水平、同期举措影响，逐条写并说明越界后果，边界越具体越可信
9. 结论分档：确定结论（数据直接支持）、提示性结论（方向一致但样本不足）、无法判断（口径不明或数据缺失），三档不混写，各附一条例子
10. 引用规范：制度与政策写文件名称、条款与年份，文号不确定就留位待核，不臆造编号；条款号不确定时同样留位，数据写系统与取数日期
11. 查重与规范：引用标注完整，图表自制或注明来源；患者与员工信息一律脱敏，个案不写可识别细节
12. 预答辩与修改：试讲一次，记录三条意见（多为口径、成本、可比性），逐条回应并留修改对照，未采纳的意见也要写明理由

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 每图一结论，图注含样本量与口径版本
- [ ] 成本与效益单位统一，估算有依据且已标注

## H.5 模板：论文自检与答辩表

| 字段 | 填写要求 |
|------|----------|
| 主线 | 一句话结论与成立条件 |
| 摘要 | 背景、方法、结果、结论四句 |
| 口径 | 指标定义表、版本、取数日期 |
| 证据 | 授权或审批、脱敏说明、筛选条件 |
| 结果 | 图表编号、样本量、判据、对应命题 |
| 成本效益 | 投入与效益、单位、估算依据 |
| 讨论 | 比对对象、一致与不一致的原因假设 |
| 边界 | 范围限制、越界后果 |
| 结论 | 确定 / 提示 / 无法判断三档 |
| 答辩 | 三类质疑的答复与追问记录 |

> 本表是本章的交付物：定稿前逐条自查；答辩用左栏讲、右栏备问，两份一并归档。

## H.6 常见失效与处置

- **数据来源说不清** → 未授权数据不能进论文，属合规问题
- **口径被问倒** → 定义表必须随身带，口头解释不算数
- **只讲效果不讲成本** → 管理评价必须算账，否则无法判断是否值得推广
- **结论拔高** → 单科室三个月的数据写成全院规律
- **引用臆造文号** → 编造文件编号是硬伤，宁可留位待核
- **预答辩意见不回应** → 正式答辩会被同一问题再问一次

## H.7 中期检查与答辩要点

- 数据合规与脱敏（一票否决项）
- 结论链条与口径一致（35%）
- 成本效益与边界分寸（30%）
- 答辩表达与质疑回应（20%）
- 材料归档完整（15%）
