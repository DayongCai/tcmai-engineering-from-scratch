## H.1 本章要解决的问题

管理改进常报「指标改善」，但不报成本与副作用：为了缩短候诊增加人手，人力成本可能翻倍。

## H.2 本章目标（可检验）

- 完成前后对比并做统计检验
- 列出投入成本与节省项
- 写出未预期的副作用

## H.3 操作流程

1. 对比：同口径前后各两周数据
2. 检验：选合适方法并说明假设
3. 算成本：人力、系统、耗材投入
4. 算效益：节省时间、减少爽约、提升周转
5. 写副作用：加班、其他流程受影响等

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 前后口径一致
- [ ] 统计方法已说明
- [ ] 投入成本逐项列
- [ ] 效益逐项列
- [ ] 副作用≥1 条
- [ ] 净效益结论已写
- [ ] 数据可复核

## H.5 模板：效果与成本表

| 字段 | 填写要求 |
|------|----------|
| 前后对比 | 指标值与差异 |
| 统计 | 方法、P 或效应量 |
| 投入 | 人力/系统/耗材 |
| 效益 | 时间/爽约/周转 |
| 副作用 | 至少一条 |

> 本表是本章的交付物：结果章核心表。

## H.6 常见失效与处置

- **只报改善不报成本** → 可能整体不划算；必须算投入
- **口径前后不同** → 数据不可比，等于没评价
- **不报副作用** → 副作用常在别的环节爆发

## H.7 中期检查与答辩要点

- 对比规范性（30%）
- 成本效益完整（40%）
- 副作用诚实度（30%）
