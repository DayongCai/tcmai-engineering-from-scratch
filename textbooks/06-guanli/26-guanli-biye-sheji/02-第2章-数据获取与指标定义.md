## H.1 本章要解决的问题

同一指标在三个科室有三种算法，是管理数据最常见的坑：门诊量算挂号还是算就诊、平均住院日算入院到出院还是算占用床日、爽约率的分母是预约数还是应到数。定义不写死，后期无法合并，前后也无法比较；等到写论文才发现口径不一，只能重算。本章交付一张指标定义表，加一次能被别人复算的取数，以及取数所必需的权限与脱敏手续。

## H.2 本章目标（可检验）

- 写出主指标与 2–3 个辅助指标的完整定义（分子、分母、时窗、排除、数据源）
- 完成一次从系统导出原始明细的取数，留下取数时间与口径版本
- 完成质量核查：抽查记录回查原始凭证，量化差错率
- 明确数据权限、脱敏方式与保存期限

## H.3 操作流程

1. 列指标清单：主指标一个，辅助指标 2–3 个；每个写一句用途，不服务于命题的指标删掉，不要「顺便也算算」，指标越多核查成本越高
2. 写分子：什么记录计入（状态、类型、金额或时长条件），是否含撤销、作废、退费记录
3. 写分母：纳入哪些对象（就诊、住院、处方、床位），排除哪些（体检、复诊、当日取消、跨期结算），排除情形要能一句话说清，否则核查时无法判定
4. 定时窗：按就诊日、开单日还是结算日归属；跨月跨年记录如何切分；节假日与夜班是否单独统计
5. 标数据源：系统名称、表名或报表名、字段名、更新频率与滞后天数（如次日更新），并注明字段由谁维护
6. 取原始明细：导出到行级记录，不只取汇总报表；汇总数只用于交叉验证，不能替代明细，导出保留原始字段名不改列名
7. 留取数痕迹：记录取数时间、操作人、筛选条件与导出文件名；数据会随补录变化，隔周重取结果可能不同
8. 核查：随机抽 20–30 条回查原始记录（病历、医嘱、收费明细、叫号日志），判定一致与否并计差错率
9. 双人复核：关键指标由第二人按同一定义独立算一遍，差异超过 1% 要查原因并记录是哪一环不一致，复算差异要在表里留数，不能只写「已核」
10. 清洗规则：缺失值（空字段、未结算）与异常值（时长为负、超长滞留）的处理方式事先写定，删除须留痕，异常值要区分录错与真异常，后者不能删
11. 口径版本：任何定义变更升版本号，写变更日、变更内容与影响范围；旧版本数据保留不覆盖，便于回溯
12. 权限与脱敏：按最小必要取字段，姓名、证件号、住址等直接标识不外带；导出文件加密存放，用毕按约定归档或销毁

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 指标清单含用途，无冗余指标
- [ ] 分子含与不含情形已写
- [ ] 分母纳入与排除已写
- [ ] 时窗归属日、跨期与夜班规则已定
- [ ] 数据源含表名、字段、更新频率与维护人，院内与上报口径差异已并列
- [ ] 已取行级明细，非仅汇总
- [ ] 取数时间与筛选条件已留痕
- [ ] 抽查 20 条以上并算出差错率
- [ ] 关键指标经第二人复算
- [ ] 缺失与异常规则事先写定
- [ ] 口径版本号与变更日已标
- [ ] 脱敏方式与保存期限已落实

## H.5 模板：指标定义与取数核查表

| 字段 | 填写要求 |
|------|----------|
| 指标 | 名称、用途、方向、层级（院/科/班次） |
| 分子 | 计入条件、含与不含情形 |
| 分母 | 纳入对象、排除情形 |
| 时窗 | 归属日、跨期切分、节假日与夜班处理 |
| 数据源 | 系统、表或报表、字段、更新频率、维护岗位 |
| 取数 | 时间、操作人、筛选条件、文件名 |
| 核查 | 抽查数、一致数、差错率、差异类型 |
| 复算 | 第二人结果、差异率、原因 |
| 清洗 | 缺失与异常规则、删除留痕 |
| 版本与权限 | 口径版本、变更日；脱敏方式与保存期限 |

> 本表是本章的交付物：论文方法章首页；换人接手先看这张表，能照着重算出同一个数才算合格。

## H.6 常见失效与处置

- **只取汇总报表** → 无法核查也无法重算，答辩追问数字来源即崩
- **分子分母混装** → 把复诊计入门诊量，指标虚高且与别处不可比
- **口径中途变更** → 前后不可比；变更须升版本并重算基线
- **异常值直接删** → 未写规则与影响，属选择性处理数据
- **不留取数时间** → 数据随补录变化，复核时对不上，结论无法复核
- **超范围取字段** → 违反最小必要；姓名与证件号不该出现在分析表里

## H.7 中期检查与答辩要点

- 定义完整性（35%）
- 取数与溯源（25%）
- 核查与清洗（25%）
- 权限与脱敏合规（15%）
