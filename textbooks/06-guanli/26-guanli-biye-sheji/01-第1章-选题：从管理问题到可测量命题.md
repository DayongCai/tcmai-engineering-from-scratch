## H.1 本章要解决的问题

「提升门诊效率」不是命题：效率用什么指标、基线多少、提升多少算成功，都没定。

## H.2 本章目标（可检验）

- 把管理问题改写成含指标的命题
- 确认数据可取且有基线
- 判断十周内可完成

## H.3 操作流程

1. 写问题：用一句话描述现象（如平均候诊 48 分钟）
2. 定指标：候诊时长、爽约率、周转率中选一个主指标
3. 写命题：干预后该指标相对基线变化 ≥X%
4. 核数据：确认系统能导出、口径稳定
5. 估范围：单科室、单流程

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 现象有具体数值
- [ ] 主指标唯一且可导出
- [ ] 命题含方向与幅度
- [ ] 基线期与口径已定
- [ ] 数据授权已获得
- [ ] 范围限定在单流程
- [ ] 十周可行性已评估

## H.5 模板：开题命题表（管理）

| 字段 | 填写要求 |
|------|----------|
| 现象 | 一句话 + 数值 |
| 主指标 | 定义、口径、来源系统 |
| 命题 | 干预 + 方向 + 幅度 |
| 基线 | 时段与取值 |
| 范围 | 科室与流程 |

> 本表是本章的交付物：开题首页。

## H.6 常见失效与处置

- **指标不可导出** → 系统没有该字段，十周内做不出来
- **命题无幅度** → 无法判断成功与否
- **范围跨科室** → 干扰因素太多，无法归因

## H.7 中期检查与答辩要点

- 指标可测（40%）
- 命题含幅度（30%）
- 范围可行（30%）
