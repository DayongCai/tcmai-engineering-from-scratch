## H.1 本章要解决的问题

「提升门诊效率」是方向不是命题：效率落到哪个指标、分子分母怎么算、基线是多少、改到多少算有效，这四件全都没定。管理类毕设开题要交的不是一段意义论述，而是一条能被数据判真假的命题，加一份取得到数、拿得到授权、十周内跑得完的证据方案。三者缺一件，答辩的第一个问题就答不上；三者齐了，题目才算立住。

## H.2 本章目标（可检验）

- 把现象写成带数值与影响对象的一句话，并归到可改的流程环节
- 选定唯一主指标，写明分子、分母、统计时窗与排除情形
- 给出基线与目标幅度，并说明幅度依据而非凭感觉定数
- 确认数据可导出、授权可获、范围在十周内可控

## H.3 操作流程

1. 抓现象：用数据描述，如「内科门诊从挂号到就诊的平均等待时长偏高」，附一个近期实测值；不用「患者不满意」这类形容词
2. 归环节：把现象拆到流程节点（挂号、分诊、候诊、就诊、检查、取药），指出哪一段占用时间最长、移交次数最多
3. 选主指标：候诊时长、爽约率、平均住院日、床位周转次数、处方合格率中只选一个，其余列为观察指标
4. 写定义：分子（满足什么条件的记录计入）、分母（纳入哪些就诊或病例、排除哪些）、时窗（自然日还是工作日、按就诊日还是结算日）
5. 查基线：回看 2–4 周或 3 个月历史数据，算均值、中位数与波动范围；波动大过预期效应时先修测量，不急于上措施
6. 核字段：确认系统里有没有该字段、是否必填、空值比例多少、能否按科室与时段筛选；没有字段就换指标，不要指望手工补录
7. 查授权：向信息科与医务或质控部门提出数据使用申请，写明用途、字段范围、保存期限与销毁方式；未获批不动数据
8. 定幅度：参照基线波动区间与同类改进的经验值定目标，写清依据与「不确定时下调」的口径，不承诺未经测算的收益
9. 定判定：明确比较方式（前后对照、同期未干预科室对照、分段比较）与判定时点，避免边做边看、看到好看就停
10. 砍范围：限定单科室、单流程、单班次；跨科室的干扰因素无法在十周内分离，逐条写进「不做清单」并说明理由
11. 排十周：按周列里程碑（授权到位—取数—基线—试运行—正式实施—评价—写作），标出关键路径与最可能卡住的一环
12. 风险预案：数据拿不到、科室不配合、同期有其它举措落地，各写一条替代方案与降级目标，注明触发条件

## H.5 模板：开题命题表（管理）

| 字段 | 填写要求 |
|------|----------|
| 现象与环节 | 一句话 + 实测值；落在哪个流程节点 |
| 主指标 | 名称、方向（升高或下降）、为何选它而不选别的 |
| 口径 | 分子、分母、统计时窗、排除情形 |
| 数据来源 | 系统、表或报表、字段、更新频率与滞后 |
| 基线 | 时段、样本量、均值与中位数、波动范围 |
| 命题 | 干预 + 指标 + 方向 + 幅度 + 判定时点 |
| 比较方式 | 前后对照 / 同期对照 / 分段比较 |
| 范围与授权 | 科室、流程、班次；授权状态与批件位置 |
| 里程碑与风险 | 周次、产出、关键路径；三条风险与替代方案 |

## H.6 常见失效与处置

- **指标不可导出** → 系统无该字段或空值过半，十周内做不出来
- **命题无幅度** → 只说「提升效率」，做完也无法判断成功与否
- **分母不清** → 纳入范围一变，前后数据不可比，等于没评价
- **基线不稳就上措施** → 波动大于预期效应，效果无法归因
- **范围跨科室** → 同期举措、人员与病种结构干扰，结论站不住
- **未获批先用数** → 属数据合规问题，一票否决，事后无法补救

## H.7 中期检查与答辩要点

- 命题可判真假（30%）
- 口径与数据可得性（30%）
- 基线与判定设计（25%）
- 范围裁剪与里程碑（15%）
