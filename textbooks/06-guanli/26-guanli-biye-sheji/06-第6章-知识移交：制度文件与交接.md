## H.1 本章要解决的问题

管理成果的最终形态是「一条能留在制度里的做法」。交接不到位，人走制度废。

## H.2 本章目标（可检验）

- 交出一份可发布的管理办法或流程文件
- 含指标与复核方式
- 科室确认可执行

## H.3 操作流程

1. 成文：按公文格式写办法或流程（目的、范围、职责、流程、考核）
2. 嵌指标：把主指标与复核方式写进考核条款
3. 征求：科室负责人签注意见
4. 修订：按意见改一版
5. 归档：编号入库

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 文件含五要素
- [ ] 职责到岗位
- [ ] 指标与复核方式已写
- [ ] 科室意见已签注
- [ ] 修订记录已附
- [ ] 文号与生效日已留位
- [ ] 敏感数据已脱敏

## H.5 模板：制度移交清单

| 字段 | 填写要求 |
|------|----------|
| 文件 | 名称、目的、范围 |
| 职责 | 岗位分工 |
| 流程 | 步骤与时限 |
| 考核 | 指标与复核 |
| 意见与修订 | 科室签注与改动 |

> 本表是本章的交付物：结题提交，科室与教学秘书各存一份。

## H.6 常见失效与处置

- **写成论文摘要** → 制度要能执行，不是论证
- **无考核条款** → 没有复核就没有落地
- **科室未签注** → 发布即空转

## H.7 中期检查与答辩要点

- 文件可执行（40%）
- 指标条款（30%）
- 科室确认（30%）
