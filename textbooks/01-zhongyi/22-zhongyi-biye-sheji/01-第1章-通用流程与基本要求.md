# 第 1 章 · 通用流程与基本要求

> **课程**：中医毕业设计与知识移交（☯️ 中医系 · 第 10 学期 · 72 学时 · 毕业设计）
> **契约**：**操作型章（handbook-v1）** —— 本文件是工作手册，不是学术教材：给的是当场能执行的流程、清单与模板。
> **前置**：中医临床轮转、中医证候学
> **本章产出物**：毕设总表
> 学术型教材的 N.1–N.5 契约（含 N.3「这个翻译丢掉了什么」）**不适用**本课程，理由见 `textbooks/README.md`「操作型章契约」。

---

## H.1 本章要解决的问题

毕设最常见的失败不是做得不好，而是没人能重跑：题太大、数据来源没落实、口径边做边改、只报平均数不报失效案例。四段流程与三件必报，就是把这四类塌方在开题前堵住。

## H.2 本章目标（可检验）

- 把疑问改写成可证伪命题（人群＋暴露或干预＋结局）
- 说清数据从哪来、多大、能否核
- 实现一条能跑的管线且参数外置
- 给出基线、消融与至少两个失效案例
- 交出数据、脚本、门禁、文档四件

## H.3 操作流程

1. 定题：把疑问写成「在 X 人群中，Y 与 Z 是否相关」，并写出反例长什么样
2. 定证：条文底本、病例区间、量表口径各写死，并做十例试提取
3. 定法：画链路图，先跑通一条样本，记录依赖版本与随机种子
4. 定评：设基线、做一次消融、挑两个失效案例逐例归因
5. 定交：打包四件并请另一位同学在干净环境复现一次

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 命题可证伪且含三要素
- [ ] 数据来源已落实（不是「以后再说」）
- [ ] 口径版本号与日期已写
- [ ] 管线可跑且参数外置
- [ ] 基线方法与选它的理由已写
- [ ] 消融是去掉模块而非调参
- [ ] 两个失效案例有原始记录与归因
- [ ] 移交四件齐（数据／脚本／门禁／文档）
- [ ] 缺口一行已写进研究边界

## H.5 模板：毕设总表

| 字段 | 填写要求 |
|------|----------|
| 命题 | 人群＋暴露/干预＋结局，附反例 |
| 数据 | 路径、规模、取数许可 |
| 口径 | 版本号与变更记录 |
| 评价 | 基线、消融、两个失效案例 |
| 移交 | 数据／脚本／门禁／文档四件 |
| 缺口 | 缺什么、缺多少、哪条结论不能下 |

> 本表是本章的交付物：开题、中期、答辩三处通用，逐项打勾后不得留空。

## H.6 常见失效与处置

- **题太大** → 「中医治疗失眠的疗效」十周做不完；收窄到单一证型与单一结局
- **把综述当毕设** → 只汇总他人结论，没有可核查的数据环节
- **口径边做边改** → 改过三次口径的数据无法复算；每次改须升版本并重跑

## H.7 中期检查与答辩要点

- 命题可证伪性（30%）
- 数据可核性与口径稳定性（30%）
- 评价三件完整性（25%）
- 移交四件完整性（15%）

> **边界声明**：本章为教学与毕设管理材料，交付物不构成诊疗建议，不得用于真实患者决策。
