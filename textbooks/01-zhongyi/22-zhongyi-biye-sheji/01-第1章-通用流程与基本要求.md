# 第 1 章 · 通用流程与基本要求

> **课程**：中医毕业设计与知识移交（☯️ 中医系 · 第 10 学期 · 72 学时 · 毕业设计）

## H.1 本章要解决的问题

毕设最常见的塌方不是做得不好，而是没人能重跑：题太大，十周做不完；数据来源没落实，开题后才发现拿不到；口径边做边改，改到第三次已经算不回去；只报平均数，不报失效案例，边界看不见。四段流程与三件必报，就是把这四类问题在开题前堵住。评审其实只问一句：换一个人拿着你的交付物，能否在半天内复算出主结果。答不上来的命题不算立项，靠文笔和态度补不回来。

## H.2 本章目标（可检验）

- 把疑问改写成可证伪命题：人群、干预、结局三要素齐全，并写出反例
- 说清数据从哪来、多大、能否逐条核到源文件与页码
- 跑通一条管线，参数外置，随机种子与依赖版本写进文档
- 给出基线、消融与两个失效案例，并把缺口写进研究边界

## H.3 操作流程

1. 定题：写成「在 X 人群中，Y 与 Z 是否相关」，并写出什么样的数据会推翻它
2. 定证：底本、病例区间、量表口径各写死版本，先做十例试提取并留档
3. 定源：每个文件登记路径、体积、来源与日期，缺许可的写补源计划
4. 定法：画链路图，先跑通一条样本，记依赖版本、种子与单次时长
5. 定评：设最笨的基线，做一次去掉模块的消融，不许用调参冒充
6. 定败：挑两个失效案例，逐例写输入、预期、实际、归因四栏
7. 定交：打包数据、脚本、门禁、文档四件，命名与目录按仓库约定
8. 定验：请另一位同学在干净环境按文档复现，记卡点与耗时
9. 定界：写清缺什么、缺多少、哪条结论不能下，禁写「数据有限」

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 命题含人群、暴露或干预、结局三要素
- [ ] 反例条件已写明，能判真假
- [ ] 数据来源已落实，不是一个「以后再说」
- [ ] 口径版本号与变更日期已写
- [ ] 管线可跑，参数外置，种子已固定
- [ ] 基线方法与选它的理由各一句
- [ ] 消融是去掉模块，不是调参
- [ ] 两个失效案例有原始记录与归因
- [ ] 移交四件齐：数据、脚本、门禁、文档
- [ ] 缺口一行写清缺什么、缺多少

## H.5 模板：毕设总表

| 字段 | 填写要求 |
|------|----------|
| 命题 | 人群、干预、结局，附反例条件 |
| 数据 | 路径、规模、来源、取数日期 |
| 口径 | 版本号与变更记录 |
| 方法 | 链路图、基线选择、消融设定 |
| 评价 | 基线值、消融差值、两个失效案例 |
| 移交 | 数据、脚本、门禁、文档四件位置 |
| 缺口 | 缺什么、缺多少、哪条结论不能下 |

> 本表是本章的交付物：开题、中期、答辩三处通用，逐项打勾，缺项不得留空。

## H.6 常见失效与处置

- **题太大** → 「中医治疗失眠的疗效」十周做不完；收窄到单一证型与单一结局
- **把综述当毕设** → 只汇总他人结论，没有一个可核查的数据环节
- **口径边做边改** → 改过三次口径的数据无法复算；每次改须升版本并重跑全链
- **只报均值** → 均值掩盖最差样例，评审一问边界就露底
- **口头移交** → 脚本在个人电脑、参数在脑子里，人一走全部作废

## H.7 中期检查与答辩要点

- 命题可证伪性（30%）
- 数据可核性与口径稳定性（30%）
- 评价三件完整性（25%）
- 移交完整性与他人复现（15%）
