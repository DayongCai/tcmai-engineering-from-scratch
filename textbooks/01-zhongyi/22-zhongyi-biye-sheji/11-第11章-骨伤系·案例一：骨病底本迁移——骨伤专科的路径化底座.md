## H.1 本章要解决的问题

中医系的骨病课已有底本，骨伤系能不能直接用？底本与章轴，能否直接为骨伤系所用？哪一部分必须改？数据锚点：gubing 60 单元 / 149,316 汉字 / 数值 0；四候选章轴的不均衡度为 17.5 倍、5.9 倍、5.6 倍、2.2 倍，采用病性四分。缺口：骨伤系培养方案本库未收，「是否仍最均」只能按教材分布判断，不能替代培养方案评审，结论不得写成「已适配培养方案」。章轴不均衡意味着有的章十几节、有的章只一节，排课时长短悬殊，学生会以为不重要的章可以略过。

## H.2 本章目标（可检验）

- 自己复算 60 单元与 149,316 字，与文件对齐
- 复算四个候选轴的倍数，说明为何选病性四分
- 换科室口径重算章轴，比对是否仍最均
- 把必须改的章名与理由逐条列出

## H.3 操作流程

1. 读源：锁定骨病底本与轴探测文件，抄下 60 单元与字数
2. 复算：自己算一遍单元数与字数，对上再谈迁移
3. 看轴：四个倍数逐个验算，公式为最大章单元数除最小章
4. 定轴：按最小倍数选病性四分，写下选它的理由
5. 换科：按骨伤系病种重命名章，单元内容不动
6. 重算：换轴后重算不均衡度，看是否仍最小
7. 查冲突：列出与培养方案可能冲突的章名，标须改或可留
8. 记界：写清培养方案未收，结论只在教材分布层面成立
9. 交付：迁移后 units.json、轴对照表、差异说明

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 60 单元与 149,316 字自己复算过
- [ ] 四个倍数逐个验算，公式写明
- [ ] 采用病性四分的理由可读
- [ ] 换轴后不均衡度重算并列表
- [ ] 章名改动逐条登记，未静默改名
- [ ] 单元内容未随章名改写
- [ ] 数值为 0 已注明，不据此谈密度
- [ ] 冲突项逐条标须改或可留
- [ ] 缺口写明培养方案未收
- [ ] 移交件齐：units.json、轴表、差异说明

## H.5 模板：底本迁移对照表

| 字段 | 填写要求 |
|------|----------|
| 原底本 | 单元数、字数、数值个数 |
| 候选轴 | 四个轴的名称与不均衡倍数 |
| 选定轴 | 采用理由与倍数 |
| 换轴结果 | 重算倍数、是否仍最小 |
| 章名改动 | 原名、新名、须改理由 |
| 冲突 | 与培养方案冲突项与处置 |
| 缺口 | 未收材料与不能下的结论 |

> 本表是本章的交付物：开题与答辩共用；迁移成功与否看轴对照，不看章节数。

## H.6 常见失效与处置

- **照抄章名** → 中医系章名直接搬，与骨伤系培养方案对不上
- **倍数算法不写** → 17.5 倍从哪来没人知道，等于给结论不给公式
- **换轴不重算** → 改完章名仍报旧倍数
- **拿分布代替方案** → 分布最均不等于课程目标最合
- **数值为 0 硬谈难度** → 无量化内容却做难度排序，属越界
