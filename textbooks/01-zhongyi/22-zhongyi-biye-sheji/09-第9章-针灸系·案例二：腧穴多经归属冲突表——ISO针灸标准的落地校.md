## H.1 本章要解决的问题

同一个穴名，在几部教材里归经不一致的有多少？冲突能否收敛到一张表？这不是学术争论，而是排课与考核的现实问题：学生按甲教材答，按乙教材判卷就错。数据锚点：本库无现成数据；可用口径为每穴一行（穴名、归经、出处），冲突定义为同穴多经。缺口：多教材文本未入库，本案例第一步是补源而不是计算；没有两本以上来源就报冲突率，属于自欺。冲突表的价值是让人看见分歧在哪，而不强行统一成答案。

## H.2 本章目标（可检验）

- 补齐至少两部教材的穴位表，逐部登记版次与页码
- 把每穴的归经与出处落成一行，冲突可查
- 把冲突分成四类并给出建议值，原值保留
- 用单教材重跑，证明冲突来自合并而非抄错

## H.3 操作流程

1. 补源：先收两部以上教材穴位表，登记版次、页码、录入人
2. 建表：每穴一行，字段为穴名、归经、部位、出处、版次
3. 规名：穴名统一为简体正名，别名单列一列不并入正名
4. 分组：按穴名分组，统计归经个数，两个及以上即为冲突
5. 出单：冲突穴逐条列出各家归经与页码，允许并排对照
6. 判因：分异体字、同名异穴、标准改版、录入错四类
7. 消融：只用单部教材重算，冲突应为零，以此证明来源
8. 收敛：给建议归经与依据，与原值分列不覆盖
9. 交付：穴经表、冲突清单、出处列，任一行可翻到页码

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 至少两部教材入库，版次页码齐全
- [ ] 每穴一行，六个字段不缺
- [ ] 穴名规范化规则写成对照表
- [ ] 冲突判据为同穴多经，阈值写明
- [ ] 冲突穴逐条附各家归经与页码
- [ ] 冲突四类归因，无「其他」兜底
- [ ] 单教材重跑冲突为零
- [ ] 建议归经与原值分列，原值未覆盖
- [ ] 同名异穴已人工确认，未误合并
- [ ] 移交件齐：穴经表、冲突清单、出处

## H.5 模板：腧穴归属对账表

| 字段 | 填写要求 |
|------|----------|
| 穴名 | 简正名、别名分列 |
| 归经 | 各家归经并列，标明出处 |
| 出处 | 教材名、版次、页码 |
| 冲突 | 冲突标记与冲突类型 |
| 建议 | 建议归经与依据 |
| 复核 | 是否翻页核对、核对人 |
| 缺口 | 未收教材与未判定的穴 |

> 本表是本章的交付物：一穴一行，答辩时按行追问，能翻到页码才算数。

## H.6 常见失效与处置

- **无源先算** → 教材没入库就报冲突率，数字无处可核
- **同名异穴合并** → 两个不同部位的穴被当成一个，冲突虚增
- **覆盖原值** → 直接改成建议归经，出处丢失，无法回溯
- **只报冲突数** → 不列各家归经，评审无法判断谁对
- **把标准当教材** → 拿一份标准代替多教材比对，冲突自然为零

## H.7 中期检查与答辩要点

- 补源与登记（30%）
- 冲突判据与归因（35%）
- 可回溯性（25%）
- 边界（10%）
