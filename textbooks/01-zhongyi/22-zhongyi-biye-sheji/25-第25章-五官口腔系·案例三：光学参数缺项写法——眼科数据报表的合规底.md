## H.1 本章要解决的问题

报表里一格空白，下游可能当成零，也可能当成缺失，两种读法结论相反。参数报表里「本项无数据」与「留空」混用会带来什么后果？数据锚点：本库无现成光学数据；口径为缺项必须显式写「无」，不允许留空。缺口：真实验光数据属院内数据，本案例只有模板与口径，不能据此评价某家机构的验光质量，也不能当作设备比对依据。缺项写法是数据契约的一部分：写「无」是信息，留空是沉默，二者在下游被读成完全不同的东西。契约要写进表头，而不是靠口头约定。

## H.2 本章目标（可检验）

- 定表结构：球镜、柱镜、轴位、瞳距逐项给单位与精度
- 造两种填法各 20 行，缺项比例相同
- 写下游计算，量化两版均值差与受影响行数
- 定位空串转零发生在哪一行代码，并加门禁

## H.3 操作流程

1. 定表：逐项给单位、精度、允许范围
2. 两版：A 版缺项留空，B 版缺项写「无」
3. 造例：每版 20 行，缺项比例保持一致
4. 下算：写一段读表求均值的下游计算
5. 比对：两版均值差与受影响行数逐项记
6. 查歧义：看下游是否把空串转零，定位到代码行
7. 定则：缺项写「无」且为字符串，数值列不收空值，规则写进表头不用口头交代
8. 门禁：加一条检查，空值直接报错，报错信息须指出行号与列名
9. 回归：把门禁接进日常出表流程，连跑一周看是否有人绕过，每处绕过都记下原因
10. 交付：参数表、两种填法对照、影响行数

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 每项有单位与精度
- [ ] A、B 两版缺项比例相同
- [ ] 两版各 20 行，逐行可对照
- [ ] 下游计算代码可读
- [ ] 两版均值差有数值
- [ ] 受影响行数逐项列出
- [ ] 空串转零的位置定位到代码行
- [ ] 缺项类型规则写死
- [ ] 门禁能拦住空值
- [ ] 缺口写明无真实数据

## H.5 模板：参数报表与缺项规则

| 字段 | 填写要求 |
|------|----------|
| 参数 | 项目、单位、精度 |
| A 版 | 缺项留空的填法 |
| B 版 | 缺项写「无」的填法 |
| 下游 | 计算方式与读取路径 |
| 影响 | 均值差与受影响行数 |
| 定位 | 空串转零的代码位置 |
| 门禁 | 空值检查规则 |

> 本表是本章的交付物：一表两版对照；规则贴在报表页脚，改版须升版本。

## H.6 常见失效与处置

- **留空当零** → 缺项被算成零，均值被拉低
- **两版缺项比例不同** → 差异来自样本而非填法
- **只改模板不改下游** → 表里写「无」，计算仍按零处理
- **门禁只查列数** → 空值照样过
- **拿模板当真实数据** → 无实测数据却报统计结果，属越界
