## H.1 本章要解决的问题

交接班留空是最常见的信息丢失：没写不等于没有，下一班只能靠猜，猜错就是风险。把交接班改成结构化五栏后，「缺项显式化」能否取代「留空」？数据锚点：lunzhuan 口径 38 病 / 190 动作，缺项须写「无」。缺口：真实交接班记录属院内数据，本库只有模板与口径，不含真实记录；因此本案例只能证明「表能降低留空率」，不能证明「交接质量提高」，也不能据此评价某个病区。五栏的作用是让「没有」也留下痕迹，而不是让记录更漂亮。

## H.2 本章目标（可检验）

- 把交班内容拆成现状、风险、措施、待办、缺项五栏
- 用同一病例双人填写，量化栏内信息差
- 统计留空率、写「无」率、具体缺项率三个数
- 用自由文本对照，说明结构化多提取了多少条

## H.3 操作流程

1. 定栏：五栏名称与每栏一句话写法写死，不许跨栏混写
2. 定空则：缺项栏必须写「无」或写缺什么，留空即判不合格
3. 填样：按 38 病 / 190 动作口径填 10 份样例，覆盖急诊与病房
4. 双填：两人对同一病例各填一份，逐栏比对信息差
5. 算率：留空率、写「无」率、写具体缺项率三个数同时报
6. 消融：同一病例改自由文本写，统计可提取条目数
7. 查弊：找出把「无」也省略的样例，标为失效并附原表
8. 定检：写一条交班前自检句，逐栏念一遍再下班
9. 交付：五栏模板、填表说明、统计脚本

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 五栏名称与写法固定，栏内未混写
- [ ] 缺项规则写明：写「无」或写缺什么
- [ ] 10 份样例按 38 病 / 190 动作口径填
- [ ] 双填比对完成，信息差逐条记
- [ ] 三个率同时报出，缺一不算完成
- [ ] 自由文本对照的可提取条目数已算
- [ ] 省略「无」的失效样例至少两例
- [ ] 自检句可执行，不是口号
- [ ] 统计脚本可复跑，口径写死
- [ ] 缺口写明无真实院内记录

## H.5 模板：交接班五栏表

| 字段 | 填写要求 |
|------|----------|
| 现状 | 病人、诊断、当前主症 |
| 风险 | 可能恶化方向与触发条件 |
| 措施 | 已做与在做的处置 |
| 待办 | 下一班须完成的事与时限 |
| 缺项 | 写「无」或写明缺什么 |
| 三个率 | 留空、写无、具体缺项 |
| 对照 | 自由文本可提取条目数 |

> 本表是本章的交付物：一例一页，交班前逐栏念完再签，缺项栏不得空白。

## H.6 常见失效与处置

- **把「无」省掉** → 填表人以为空着更省事，缺项重新变成隐形
- **五栏写成五段话** → 结构化退化成小作文，仍然不可提取
- **只查留空率** → 写「无」率高也可能是敷衍，须三项合看
- **拿样例当真实记录** → 对外称基于真实交接班，属越界
- **自检句写成口号** → 「认真核对」无法执行，等于没写

- 栏位设计与规则（30%）
- 缺项显式化的执行（35%）
- 对照与失效分析（25%）
- 边界（10%）
