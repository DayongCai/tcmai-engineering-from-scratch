## H.1 本章要解决的问题

正常值表最容易出的错不是数值错，是单位错：三十是毫摩尔每升还是毫克每分升，差一个字，判读全反。正常值表移交时，单位与参考区间必须写到什么程度才算可复现？数据锚点：shengli 132 单元 / 228,672 汉字 / 数值 0。缺口：参考区间的实验室差异本库未收，表中只反映教材口径，不能直接给患者看，也不能替代检验科报告。参考区间是判读的尺子，尺子刻度不清，量出来的数就没有意义。表要能被程序直接读，也要能被护士一眼看懂，两者并不冲突。

## H.2 本章目标（可检验）

- 抽出所有带数值的正常值条目，一条一行
- 每条补指标名、数值、单位、区间与出处章
- 统一跨章单位，换算系数写进表并可复算
- 报跨章不一致清单，不静默合并

## H.3 操作流程

1. 取源：锁定单元表，核 132 单元与 228,672 字
2. 抽条：抽出带数值的正常值条目，一条一行，重复条目去重后保留出处
3. 补全：每条补指标名、数值、单位、区间、出处章，缺一项即标为不完整
4. 统一：同一指标跨章单位统一，换算系数入表
5. 查歧义：找出摩尔与毫克并存项，逐条标
6. 核区：区间上下限与单位对齐，开闭符号写清，缺上限的条目单列
7. 复算：抽 10 条按系数复算，结果须一致
8. 试读：请一位非检验专业读者只看表说出三个指标的区间，说错即说明列名或单位不清
9. 写界：声明只反映教材口径，不替代实验室区间
10. 交付：正常值表、换算说明、不一致清单

## H.5 模板：正常值表

| 字段 | 填写要求 |
|------|----------|
| 指标 | 中文名与常用缩写 |
| 数值 | 参考值与单位 |
| 区间 | 上下限与开闭符号 |
| 出处 | 教材名、章、节 |
| 换算 | 并存单位与系数 |
| 不一致 | 跨章差异与处置 |
| 声明 | 教材口径、非实验室区间 |

> 本表是本章的交付物：一指标一行；列名固定不改，换版须写明版本与日期。

## H.6 常见失效与处置

- **单位不写** → 三十是摩尔还是毫克，读者自行猜
- **区间只写下限** → 上限缺失，判读只能做一半
- **换算两次四舍五入** → 复算对不上，误差累积
- **拿教材值当实验室区间** → 患者按此判读会误判
- **跨章不查** → 同一指标两章两个区间，无人发现

## H.7 中期检查与答辩要点

- 条目完整性（35%）
- 单位与换算（30%）
- 复算与不一致（25%）
- 边界（10%）
