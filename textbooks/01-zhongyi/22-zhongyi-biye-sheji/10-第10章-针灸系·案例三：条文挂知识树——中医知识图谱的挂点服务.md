## H.1 本章要解决的问题

中医知识图谱最难的不是画树，是把条文挂上去。按五级骨架给针灸条文挂点，覆盖率能到多少？哪些条文挂不上？数据锚点：知识树五级骨架的 schema 已入库；条文规模待建。缺口：条文层未建，覆盖率暂不可算，这一点必须写进开题，不能先报一个数；而挂了但错级，比不挂更糟，因为下游会当真。五级骨架的好处是每级只答一个问题：病在哪、属何证、怎么治、用何方、忌什么；条文挂错级，检索就会串味。

## H.2 本章目标（可检验）

- 抄清五级骨架的层级名与允许的子节点类型
- 建条文层，一条一行，出处与节号可回溯
- 人工挂 50 条做金标，再跑自动挂点并比对
- 把未挂与错挂分开报，给出各自原因

## H.3 操作流程

1. 读骨架：打开 schema，抄五级层级名与每级允许的子节点
2. 建条文：按章节逐条录入，一条一行，含原文、出处、节号
3. 定挂点：每条只挂一个主节点，允许一个次节点，须写依据词
4. 人工挂：先挂 50 条做金标，两人独立挂并算一致率
5. 自动挂：按关键词规则挂全量，规则可读可改
6. 比对：自动与金标逐条比，算覆盖率与错挂率
7. 查错挂：挑同义不同级的错例，如治则挂到病证下
8. 出未挂：按无对应节点、表述过泛、跨级三类归因
9. 交付：挂点表、未挂清单、规则，规则带版本号

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 五级层级名与子节点类型已抄录
- [ ] 条文一条一行，出处与节号齐全
- [ ] 每条只挂一个主节点，依据词非空
- [ ] 金标 50 条，两人独立挂并算一致率
- [ ] 自动挂规则可读，关键词可查
- [ ] 覆盖率分子分母定义写死
- [ ] 错挂率单独报，不只报覆盖率
- [ ] 未挂条文按三类归因
- [ ] 同义不同级错例至少两例
- [ ] 条文层建成前未预先报数

## H.5 模板：条文挂点表

| 字段 | 填写要求 |
|------|----------|
| 条文 | 原文、出处、节号 |
| 主节点 | 五级路径与依据词 |
| 次节点 | 可空，须写理由 |
| 金标 | 两人独立挂点与一致率 |
| 错挂 | 错例、错在哪一级 |
| 未挂 | 原因分类与建议 |
| 版本 | 规则版本号与生效日期 |

> 本表是本章的交付物：一条一行，覆盖率与错挂率同页呈现，缺一项不交。

## H.6 常见失效与处置

- **先报覆盖率** → 条文没建完就报八成挂上，等于编数
- **只挂主节点不看层级** → 治则挂进病证，树结构被污染
- **关键词一把梭** → 「补」字挂遍补益类，错挂率无人统计
- **未挂条文不列** → 挂不上的被悄悄丢掉，覆盖率虚高
- **规则无版本** → 改了关键词不记录，前后结果无法比较

## H.7 中期检查与答辩要点

- 骨架遵循度（30%）
- 金标与一致率（30%）
- 错挂与未挂分析（30%）
- 边界（10%）
