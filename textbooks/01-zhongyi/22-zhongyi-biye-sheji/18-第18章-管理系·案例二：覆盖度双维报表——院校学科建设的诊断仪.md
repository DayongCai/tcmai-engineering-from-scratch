## H.1 本章要解决的问题

覆盖率报表只报「已建章节／目标章节」，会把章节多的系报成先进，而它的底本一门没有。一个指标够不够？哪一维会误导？数据锚点：全库已建 405 章 / 目标 2,115（取 audit 输出）；中医系 208 章、基础医学院 134 章。缺口：目标章节数本身是排课期估算，不是评估标准，报表不得用于院系排名，也不得写成「完成率达标」。覆盖率回答的是「写了多少」，底本维回答的是「写的东西有没有依据」。两个问题不能互相替代，一个高一个低时，恰恰是最需要被看见的系。

## H.2 本章目标（可检验）

- 按院系拆开算覆盖率，不只报全库一个数
- 加入底本维，两条排序并列呈现
- 挑出章节多而底本为零的系做误读案例
- 在报表首页写清读法，单看一维视为误读

## H.3 操作流程

1. 取数：跑课程审计脚本，记 405 与 2,115 并按院系拆开
2. 单维：算各系已建除目标，排一版序
3. 加维：第二维取有底本的学科数除学科总数
4. 双排：两维各排一版，标出位次差最大的系
5. 找误读：挑章节多但底本为零的系，写成案例
6. 定读法：报表首页写明两维必须同看，并附一句「只看覆盖率，底本空白就被藏起来了」
7. 复算：208 与 134 两数逐系核过
8. 压测：把一个系的已建章数人为加十，看两维是否同时变动，只动一维即为口径错
9. 记界：目标数是估算，报表不作排名
10. 交付：报表模板、双维排序表、误读案例

## H.5 模板：覆盖度双维报表

| 字段 | 填写要求 |
|------|----------|
| 院系 | 院系名与学科数 |
| 已建 | 已建章数与目标章数 |
| 覆盖率 | 已建除目标的百分比 |
| 底本维 | 有底本学科数除学科总数 |
| 位次 | 两维各自排名与差 |
| 误读 | 单看一维会得出什么错结论 |
| 声明 | 目标数为估算，不作排名 |

> 本表是本章的交付物：一系一行，两维同页；只写一维的报表视为不合格。

## H.6 常见失效与处置

- **单维排序** → 章节多的系排第一，底本空白被掩盖
- **只报全库** → 一个百分比，院内差异全无
- **目标数当标准** → 拿估算值做考核，越用越偏
- **第二维不定义** → 说「质量」却不说怎么算
- **报表无读法** → 读者各取一维，结论互相打架
