## H.1 本章要解决的问题

养生建议里「忌」比「宜」重要，但「忌」最容易被写成模糊劝告：少食生冷、注意保暖，说了等于没说，执行与不执行看不出来。能否用检查单把这条落成可核项？数据锚点：口径来源为体质学第 7 章「以平为期，忌比宜重要」；证候 132 证可作对象池。缺口：养生效果的长期随访数据本库没有，只能做方案可执行性，不做疗效结论，也不能说某方案「有效」。养生方案要能被家属读懂并照做，读不懂就等于没给。检查单的价值在「可判」，不在「好看」；判不了执行与否的条目，一律退回重写。

## H.2 本章目标（可检验）

- 选 5 个证作对象池，说明为什么选它们
- 每条忌写成含对象、量、频次或情形的可核句
- 把模糊劝告逐条改写，原文保留作对照
- 请他人按单核查 3 份方案，判读结果一致

## H.3 操作流程

1. 选池：从 132 证里选 5 证作对象，写明选取理由
2. 列栏：每证列忌、宜两栏，忌在前，宜在后
3. 写判据：每条忌须含对象、量、频次、情形之一
4. 改模糊：把少食生冷一类改写为可观察句，并留原文
5. 建单：检查单勾「已执行／未执行／不适用」三态
6. 抽检：请一位同事按单核查 3 份方案，看能否判出执行
7. 算率：统计可核条数占比，模糊条数单列
8. 消融：只写宜不写忌，比对方案完整度
9. 复听：请一位家属按单复述其中一条忌，复述不出就说明该条仍不可执行，退回改写
10. 交付：检查单、判据列、改写前后对照

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 对象池 5 证与选取理由已写
- [ ] 每证忌栏在前，宜栏在后
- [ ] 每条忌至少含一个可核要素
- [ ] 模糊条已改写并保留原文
- [ ] 检查单三态勾选，无空白项
- [ ] 3 份方案经他人核查，判读一致
- [ ] 可核条数占比有具体数值
- [ ] 只写宜的对照版已做
- [ ] 结论只谈可执行性，不谈疗效
- [ ] 移交件齐：检查单、判据列、对照

## H.5 模板：养生忌宜检查单

| 字段 | 填写要求 |
|------|----------|
| 对象 | 证名与体质类型 |
| 忌 | 对象、量、频次、情形 |
| 宜 | 同样写到可核程度 |
| 判据 | 怎样算执行、怎样算未执行 |
| 三态 | 已执行、未执行、不适用 |
| 核查 | 核查人与一致情况 |
| 改写 | 模糊原文与改写后对照 |

> 本表是本章的交付物：一证一页；忌在前，条条可判，判不了的写进改判清单。

## H.6 常见失效与处置

- **忌写成劝告** → 「注意保暖」无法判执行，等于没写
- **宜多忌少** → 方案看着丰富，真正要戒的一条没有
- **判据无量** → 「适量」既不能核也不能教
- **拿随访说疗效** → 没有随访数据却称有效，属越界
- **检查单无三态** → 只有打勾，不适用与未执行混在一起

## H.7 中期检查与答辩要点

- 判据可核性（40%）
- 忌宜结构与改写（30%）
- 他人核查（20%）
- 边界（10%）
