# 第 1 章 · 阴阳：从对立范畴到二分类

> **本章要回答的问题:** 「阴阳」这个概念，写成什么数学形式才算没丢它的意思？

---

## 1.1 概念与出处

### 原文

《素问·阴阳应象大论》开篇：

> 「阴阳者，天地之道也，万物之纲纪，变化之父母，生杀之本始，神明之府也。治病必求于本。」

这段话里，阴阳不是两种东西，而是**一切事物的两个基本面向**。「纲纪」「父母」「本始」
这些词都在说明它的地位：它是一套**分类与解释的总框架**，不是一对标签。

### 具体化：从范畴到属性

抽象的「阴阳」在具体事物上如何落地？请看《素问·阴阳应象大论》接下来的配属：

| 属性 | 阳 | 阴 |
|------|----|----|
| 天/地 | 天 | 地 |
| 日/月 | 日 | 月 |
| 火/水 | 火 | 水 |
| 动/静 | 动 | 静 |
| 升/降 | 升 | 降 |
| 昼/夜 | 昼 | 夜 |
| 春夏/秋冬 | 春夏 | 秋冬 |

**注意这张表的读法**：它不是七个互不相干的属性，而是**同一对立在七个不同层面上的投影**。
天/地、日/月、火/水…… 这些对立之间有内在关联 —— 属阳的那一列彼此相关，属阴的那一列也彼此相关。

这一点至关重要。如果阴阳只是七个独立属性，那就没必要叫同一个名字了。

### 八纲中的阴阳

《医学心悟》（清·程钟龄）确立的八纲为「寒热虚实表里阴阳」，其中阴阳是**总纲**：

> 「至于……阴阳，尤为纲领之纲领。」

八纲里的阴证与阳证，是**综合判断**，不是单项测量：

- **阳证**：热、实、表，或表现为亢盛、躁动、口渴、面红、脉数
- **阴证**：寒、虚、里，或表现为沉静、畏寒、不渴、面白、脉迟

临床上的表现往往混杂，且程度不同。

## 1.2 为什么可以这样翻译

### 二分类：第一步

阴阳的对立性最直接的数学形式是**二分类**：

$$\hat{y} = \begin{cases} 1 & (\text{阳}) \\ 0 & (\text{阴}) \end{cases}$$

这一步看起来平凡但必须说清：它只用了「对立」这一条性质。

### sigmoid：第二步，也是关键的一步

把输出写成硬标签（0 或 1）会立刻损失一个东西：**程度**。

临床上「偏阴」与「极阴」完全不同 —— 前者可能只是畏寒喜暖，后者可能已经是四肢厥冷、
脉微欲绝。硬标签把这两者压成同一个符号，这在临床上是不可以接受的。

于是改用概率输出：

$$p = \sigma(z) = \frac{1}{1+e^{-z}}, \qquad z = \mathbf{w}^\top\mathbf{x} + b$$

其中 $\mathbf{x}$ 是体征向量，$z$ 是「阳证倾向的线性打分」。

这样处理带来三个好处：

**(1) 保留了强度。** $p = 0.55$ 与 $p = 0.95$ 在临床上对应完全不同的处置思路。

**(2) 强制了两类的互补关系。** 阴阳互根互用，在「对立统一」的意义上，
「非此即彼」的二分法有一层天然结构：

$$p + (1 - p) = 1$$

这个等式不是人为加上的约束，它是 sigmoid 的数学性质。**它恰好对应「阴阳互根」在
对立统一层面上的含义** —— 这是本章最值得注意的一点对应。

**(3) 最不确定的地方被显式暴露出来。** $p \approx 0.5$ 的病例，就是这个模型没有把握的病例。
在硬标签体系里，这种病例会被悄悄分到某一侧；在概率输出下，它是可见的。
**临床安全的第一条：不知道要说不知道。**

### 权重的可解释性

以交叉熵为损失时：

$$L = -[y\log p + (1-y)\log(1-p)], \qquad \frac{\partial L}{\partial \mathbf{w}} = (p - y)\mathbf{x}$$

权重的更新方向由「预测偏差 × 特征取值」决定。训练完成后，每个权重的符号与大小
直接对应「该体征偏向阴还是阳、偏向多少」。

本教材配套的课程代码在 8 例八纲典型证候上训练，得到：

```text
w = [ 畏寒: -7.60,  口渴: +5.19,  脉数: +5.85 ]
b = -2.10
```

符号是符合中医常识的：畏寒为负（偏阴），口渴与脉数为正（偏阳）。

**但权重绝对值不能当重要度读。** 理由见 1.3。

## 1.3 这个翻译丢掉了什么

这是本章最重要的一节。

### 丢掉的第一件：互化

sigmoid 描述的是**某一时刻**的状态。而阴阳最核心的动态性质是**相互转化**：

《素问·阴阳应象大论》：

> 「重阴必阳，重阳必阴。」

《素问·六微旨大论》：

> 「阴胜则阳病，阳胜则阴病。」

这些都在讲**过程**：阴发展到极点会转向阳，反之亦然。

单次二分类模型**拿不到这一层**。它只有当前状态，没有轨迹，也没有相变机制。
要表达「重阴必阳」，至少需要：

- 一个随时间演化的状态（时序模型或状态机）
- 一个在临界点触发翻转的机制

这属于后续章节的范围（六经传变、卫气营血传变都涉及这一层）。

**结论：单次二分类丢掉了阴阳的动态性，这是结构性丢失，不是精度问题。**
用再多的数据训练一个单次分类器，也拿不到互化。

### 丢掉的第二件：绝对的强度信息

前面已经提到：本例数据是**线性可分**的，因此交叉熵损失没有有限的最优解，
权重会一直增大。训练 4000 步得到 $|\mathbf{w}|$ 在 7 左右；训练 40000 步会更大。

这意味着 **$w_1 = -7.60$ 并不比 $w_1 = -3.00$「更重要」**，它只是训练得更久。
可以稳定读出的只有**符号**。

要拿到有界的、可比较的权重，需要引入正则（L2）或提前停止。这是第四章的内容。
在此之前，任何"某体征权重是另一个的两倍，所以它重要两倍"的说法都是错的。

### 丢掉的第三件：语义层次

阴阳在各个层面上的表现（天/地、日/月、火/水……）是**同一对立的多层投影**。
sigmoid 把它们压成一个标量 $z$，层与层之间的关系消失了。

要在模型中保留层次，需要结构化的表示（例如分层的特征组、或带约束的多任务模型）。
本教材在后续章节讨论体质学说时会回到这个问题。

### 一项必须显式排除的误用

**「阴阳就是二进制的 0 和 1」—— 这是错的。**

| | 二进制位 | 阴阳 |
|---|---|---|
| 关系 | 互斥、可交换 | 互根互用，不可交换 |
| 转化 | 无 | 有（重阴必阳） |
| 强度 | 无 | 有（偏阴 / 极阴） |
| 层级 | 无 | 有（多层次投影） |

二进制位是**互换对称**的：把 0 与 1 对调，系统行为不变。阴阳不是 —— 「阴胜则阳病」
与「阳胜则阴病」是不同的命题，不能对调。

用位运算处理阴阳，会丢掉上面全部四条。这是本项目在
[glossary/bridge-map.md](../../../glossary/bridge-map.md) 中列为 **D 级（误导）** 的典型。

## 1.4 与相邻学科的接口

| 学科 | 用到本章的什么 | 以什么形式用 |
|------|--------------|------------|
| 中医诊断学 | 八纲中的阴阳总纲 | 多标签分类的输出层 |
| 中医证候学 | 证候的阴阳属性 | 本体中的一个维度 |
| 中药学 | 药性的寒热温凉（属阴阳的具体化） | 有序变量编码，不用 one-hot |
| 医学人工智能导论 | sigmoid、交叉熵、梯度下降 | 第一个可运行模型 |
| 中医体质学 | 九种体质的阴阳偏向 | 多分类 + 连续倾向分量 |

一个具体的接口例子：中医诊断学里要把八纲的六个维度（表里、寒热、虚实）
与阴阳总纲对接。数理上，阴阳不是第七个维度，而是**其余六维的聚合**。
这可以用一个额外的聚合层实现，而不是再多加一个独立分类头。

## 1.5 争议与本项目立场

### 争议一：阴阳是「分类」还是「连续谱」

一派认为阴阳是范畴（阴证 / 阳证），临床上要落到具体的证型；另一派认为阴阳是连续谱，
重点在"偏向程度"。

**本项目立场：两者都要，且必须分开表达。**

- 连续分量（sigmoid 输出）回答「偏哪一侧、偏多少」
- 分类（阈值判定）回答「此刻归入哪一侧，以便后续立法处方」

把两者混成一个硬标签，就丢掉了程度；只给连续值不给判定，临床上没法用。
本项目的做法是**同时输出**，并在判定时显式带上阈值与置信度。

### 争议二：阴阳能否量化

有观点认为阴阳是定性范畴，量化本身就是曲解。

**本项目立场：可以量化其「表现」，不可以量化其「本体」。**

我们能量化的是**可观测的体征**（畏寒程度、口渴程度、脉率）与它们与阴阳判断的关联强度。
我们说「口渴越重，越偏阳」时，量化的是这个关联，不是阴阳本身。
本教材的所有量化表述都限定在「体征 → 判断」这个层面。

这个区分不是文字游戏。如果把它模糊掉，很快就会滑向「阴阳指数 0.73」这类
既无临床依据也无理论依据的数字。

### 争议三：教学样例数据的地位

本教材用构造的 8 例数据讲解方法。有读者会问：这有什么临床意义？

**本项目立场：教学中数据的作用是让机制可见，不是产生临床结论。**

8 例数据能让你看清 sigmoid 的形状、权重的符号、线性可分带来的无界性 ——
这些都是**机制**。它不能让你得出任何关于真实病人的结论。本教材在每处数值结果后
都标注了这一点。

## 本章小结

1. 阴阳的对立性 → 二分类；阴阳的程度性 → sigmoid 的连续输出。
2. $p + (1-p) = 1$ 这一数学性质恰好对应「阴阳互根」在对立统一层面的含义。
3. 单次二分类**丢掉了**：互化（重阴必阳）、有界权重、语义层次。这是结构性丢失。
4. 「阴阳 = 二进制」是 D 级误用：二进制位可交换，阴阳不可。
5. 临床安全的做法是同时输出连续倾向与带阈值的判定，并把 $p \approx 0.5$ 的情况显式标为不确定。
