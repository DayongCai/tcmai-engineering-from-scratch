## 讲义正文

### 一、判定的四个域

| 域 | 观察项 |
|---|---|
| 形态 | 形体胖瘦、腹部松紧、面色、皮肤、舌象 |
| 功能 | 气短、乏力、畏寒、口干、二便、汗、睡眠、脉 |
| 心理 | 性格、情绪基调、是否善太息 |
| 易感 | 易感冒、易过敏、易生疮疡 |

**四域的好处是可复核**：两个人看同一个记录，能得出相近结论。

### 二、八质的判定要点（平和质为基准）

| 质 | 一句话抓手 | 四域中最关键的一域 |
|---|---|---|
| 气虚 | 疲、短、汗、感 | 功能 |
| 阳虚 | 寒（畏寒肢冷、便溏、夜尿清长） | 功能 |
| 阴虚 | 干、热（口燥、手足心热、盗汗） | 功能 |
| 痰湿 | 肥、黏、腻（腹松、口黏、苔白腻） | 形态 |
| 湿热 | 油、苦、疮（面垢、口苦、苔黄腻） | 形态 |
| 血瘀 | 暗、斑、涩（肤色晦暗、瘀斑、脉涩） | 形态 |
| 气郁 | 郁、胀、息（情绪低落、胁胀、太息） | 心理 |
| 特禀 | 敏、感（易过敏、易感外邪） | 易感 |

**表里第三列是本课程的核心设计**：每个质都有「最关键的域」，判定时先查这一域，再用其余三域佐证。

### 三、兼夹与复合

老年体质以兼夹为主（气虚兼痰湿、阳虚兼血瘀、阴虚兼气郁）。量表设计必须支持**多标签**而非单选：

- 允许 2–3 个质同时成立；
- 但须给出「主质」——判定后仍要定主次，否则调养无下手处。

### 四、量表的四条设计原则

1. **条目单维**：一个条目只测一个域；
2. **量纲统一**：统一 1–5 级，避免「是／否」与「频次」混用；
3. **缺失不等于最低分**：缺失是「未测」，不是「无症状」；
4. **可解释**：每一分的来源要能回溯到条目。

### 五、本章数值 7 处

本章的数值集中在阈值与条目数（如「同时满足 2 项以上」）。**体质判定不宜给过多硬阈值**，因为体质的边界本身就是模糊的——这一点与第 8 章的测量误差直接相关。

### 六、判定表的写法（可复述的模板）

| 行 | 填什么 |
|---|---|
| 形态 | 形体胖瘦／腹部松紧／面色／舌象（各一条） |
| 功能 | 气短／乏力／畏寒／口干／二便／睡眠（择要） |
| 心理 | 情绪基调／是否善太息 |
| 易感 | 易感冒／易过敏／易生疮疡 |
| 主质 | 关键域支持的那一个 |
| 兼夹 | 其余支持项，排主次 |

六行写完，判定即可复核。**模板的价值不在完整，而在「每一行都必须有内容或明确写「无」」**——空行是判定失败的标志。

### 七、九质判定的五个易混对

| 易混对 | 分界 |
|---|---|
| 气虚 vs 阳虚 | 有无寒象 |
| 阴虚 vs 湿热 | 舌苔：少苔 vs 黄腻 |
| 痰湿 vs 湿热 | 苔色与气味：白腻无臭 vs 黄腻臭秽 |
| 血瘀 vs 气郁 | 有形之块与定处痛 vs 情绪与走窜胀 |
| 气郁 vs 特禀 | 情志诱因 vs 过敏原诱因 |

五对分界都是「一票否决」式的：只要有一条明确指向另一侧，就不能判当前质。

## N.2 为什么可以这样翻译

把「我是什么体质」翻译成「八个维度各打一分，按阈值与转化分判型」，要解决三件事：测什么、怎么算、算到哪一步停。

测什么：每个维度对应一组条目，条目要能区分「素来如此」与「最近如此」，否则测出来的是证候不是体质。怎么算：原始分转成转化分（使不同条目数的维度可比），再按判定标准分档——是、倾向是、否。算到哪一步停：单一维度达标判该质，多维度同时达标判兼夹质，都不达标判平和质。

量表的价值不在分数本身，而在**可复现**：换一个人、换一个时间，用同一套条目应得到同一档结论。因此量表设计的第一原则是条目与维度一一对应，第二原则是阈值预先设定，第三原则是不允许为凑结论调阈值。

## N.5 争议与本项目立场

争议一：自评量表与医生判定谁为准。自评可大规模施测但受主观与情绪影响，医生判定更准但不可规模化。本项目立场：筛查用自评，判定用「自评 + 四域复核」；两者不一致时以复核为准并记录分歧。

争议二：兼夹质怎么算。有做法把兼夹质拆成多个单质分别报告，也有做法合并为一个复合型。本项目立场：分别报告各质得分与是否达标，兼夹作为**组合描述**而非新类型，避免类型数无限膨胀。

争议三：阈值能不能按人群调整。按人群调阈值可以提高地区筛查效率，但会破坏跨地区可比。本项目立场：阈值用通行标准，地区差异另行报告，不在正文私自调整。
