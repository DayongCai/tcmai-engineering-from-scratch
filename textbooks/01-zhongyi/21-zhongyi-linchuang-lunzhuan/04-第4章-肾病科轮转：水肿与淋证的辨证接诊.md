# 第 4 章 · 肾病科轮转：水肿与淋证的辨证接诊

## H.1 本章要解决的问题

水肿与淋证（尿频尿急尿痛）这两类主诉，最危险的不是辨错证，而是漏掉「需要马上处理的西医问题」：急性肾损伤、严重感染、电解质紊乱、心衰导致的凹陷性水肿。轮转要练的是双轨判断——一条轨是客观指标（尿量、尿常规、肌酐、血压、体温），一条轨是中医病位病性；两条结论都写出来，再谈证候。

## H.2 本章目标（可检验）

- 完成水肿/淋证的结构化采集：起病部位与顺序、尿量与尿色、伴随症状、既往病史与用药
- 识别急性肾损伤、严重感染、心源性水肿等需要立即上报的情形
- 给出病位（肾/脾/肺/膀胱）+ 病性（风水、湿热、寒湿、阳虚、气虚、瘀）两行结论并附证据

## H.3 操作流程

1. 交接班（5 分钟）：先看夜班尿量、体重变化、发热与血压记录，把「尿量骤减」「血压骤升」「新发发热」列为优先
2. 红旗筛查（3 分钟）：24 小时尿量 <400 ml、肉眼血尿、寒战高热伴腰痛、血压 ≥180/110 mmHg、呼吸困难不能平卧、意识改变、抽搐 —— 命中即上报
3. 客观数据：体重（每日同条件）、血压、体温、尿量（若在院）、尿常规（蛋白、红细胞、白细胞、管型）、肌酐与电解质（如已查）
4. 水肿问诊：起始部位（眼睑/下肢/全身）、发展顺序（上行/下行）、凹陷性与晨轻暮重、伴随（泡沫尿、尿量变化、气短）
5. 淋证问诊：尿频次数、尿急程度、尿痛性质（灼痛/刺痛/酸胀）、尿色与有无血块、腰痛与放射、发热与寒战
6. 既往与用药：糖尿病、高血压、近期感染（咽部/皮肤）、肾毒性药物（NSAIDs、氨基糖苷、含马兜铃酸中药）、造影剂暴露
7. 望闻切：面色（㿠白/晦暗）、舌（淡胖/红/暗、苔白滑/黄腻）、脉（沉细/濡/弦）、下肢按压凹陷程度与皮温
8. 病位病性两行结论：病位（肾、脾、肺、膀胱），病性（风水相搏、湿毒浸淫、水湿浸渍、湿热壅盛、脾阳虚衰、肾阳衰微；淋证分热淋、石淋、气淋、血淋、膏淋、劳淋）
9. 证候与反证：主证候 + 三条支持证据 + 一条反证；水肿与淋证并存时，写清以何者为主、为什么
10. 处置边界：利尿、抗感染、降压、补液由带教决定；学生负责记录出入量、体重曲线与症状日记，并核对肾毒性用药
11. 记录与交班：按 H.5 模板填「水肿/淋证接诊复盘表」，附 24 小时出入量与体重记录
12. 复盘：挑一例「水肿但心、肝、肾三种解释都说得通」的病例，写清鉴别所用证据与最终依据

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 红旗七项已筛（少尿、肉眼血尿、寒战高热腰痛、重度高血压、端坐呼吸、意识改变、抽搐）
- [ ] 体重与血压已测，尿量（若在院）已记录
- [ ] 水肿：起始部位、顺序、凹陷性、晨轻暮重四项齐全
- [ ] 淋证：频次、尿急、尿痛性质、尿色、腰痛五项齐全
- [ ] 尿常规结果已核（蛋白、红白细胞、管型）
- [ ] 既往史与肾毒性用药已逐条核（含中药）
- [ ] 舌象脉象各≥2 项描述，下肢皮温与凹陷程度已记
- [ ] 病位病性分两行写
- [ ] 主证候附三条支持证据与一条反证
- [ ] 24 小时出入量与体重曲线已建立
- [ ] 需急查项目（肌酐、电解质、尿培养）已写清指征与回报时间
- [ ] 带教修正与不确定点已记录

## H.5 模板：水肿/淋证接诊复盘表

| 字段 | 填写要求 |
|------|----------|
| 主诉与病程 | 起病时间、部位、发展顺序 |
| 红旗筛查结论 | 七项逐条写有/无与依据 |
| 客观数据 | 体重、血压、体温、尿量、尿常规、肌酐与电解质 |
| 水肿四要素 | 起始部位、顺序、凹陷性、晨轻暮重 |
| 淋证五要素 | 频次、尿急、尿痛性质、尿色、腰痛 |
| 既往与用药 | 糖尿病/高血压/近期感染；肾毒性药物与中药清单 |
| 病位·病性 | 两行分开写 |
| 证候名与证据 | 主证候 + 三条支持 + 一条反证 |
| 出入量与体重 | 24 小时出入量、体重曲线、变化趋势 |
| 不确定点与带教修正 | 自己没把握的点与修正结论 |

> 本表是本章的交付物：每位水肿或淋证患者一张；在院患者按日续填体重与出入量，出科抽 5 张评分。

## H.6 常见失效与处置

- **见水肿就利水** → 未分心源性、肝源性、肾源性、营养不良性；方向错则越利越坏
- **不问肾毒性用药** → 含马兜铃酸中药、NSAIDs、造影剂是常见可避免病因
- **尿量不记却判断脱水或水潴留** → 没有出入量就没有依据；在院患者每日必须记
- **把「尿频尿急尿痛」直接等同尿路感染** → 需尿常规支撑；老年人与儿童表现常不典型
- **血压不测双上肢与体位** → 漏掉肾性高血压与体位性低血压，处理会反
- **只写证候不写鉴别证据** → 水肿的三源鉴别未写，等于把风险留给下一班

## H.7 出科考核

- 红旗筛查与客观数据完整度（一票否决：漏筛即不通过）
- 水肿/淋证要素采集质量（30%）
- 病位病性分离与证候证据链（30%）
- 出入量与体重记录的执行（20%）
- 鉴别诊断与复盘质量（20%）
