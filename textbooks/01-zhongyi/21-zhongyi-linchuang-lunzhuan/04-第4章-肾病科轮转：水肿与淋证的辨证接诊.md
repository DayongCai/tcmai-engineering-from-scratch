## H.1 本章要解决的问题

水肿与淋证都要先回答一个非中医问题：肾功能与感染状态如何。轮转要能在辨证之前把这个底线摸清，再决定是走中医路径还是立即转诊。

## H.2 本章目标（可检验）

- 能按凹陷性、体位分布、伴随症把水肿分成肾性、心性、肝性三条线
- 能在接诊时完成尿常规与肾功能的开单判断
- 能写出含寒热虚实与是否夹湿热的淋证记录

## H.3 操作流程

1. 问水肿分布：晨起眼睑、午后下肢、全身，以及是否凹陷性
2. 问小便：量、色、频次、有无尿痛尿急、有无泡沫久不散
3. 查底线：血压、尿常规、血肌酐、白蛋白，四项缺一不可
4. 辨寒热虚实：淋证先分石、气、血、膏、劳五类再论寒热
5. 记录：按 H.5 模板写，注明尿蛋白与肌酐值（无值则写未查）
6. 交带教：说明是否需要肾内科会诊或转诊，理由写具体

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 水肿分布与凹陷性已记录
- [ ] 小便五项（量色频痛泡）已问
- [ ] 血压与体重已测
- [ ] 尿常规已开或已记录未查原因
- [ ] 肾功能（肌酐）已记录
- [ ] 淋证五类归属已判断
- [ ] 会诊或转诊理由已写明
- [ ] 带教修正已记录

## H.5 模板：水肿/淋证接诊复盘表

| 字段 | 填写要求 |
|------|----------|
| 水肿分布 | 部位、时间规律、是否凹陷 |
| 小便情况 | 量、色、频次、尿痛、泡沫 |
| 生命体征与体重 | 血压、体重变化、24 小时出入量 |
| 实验室底线 | 尿常规、肌酐、白蛋白 |
| 淋证分类 | 石 / 气 / 血 / 膏 / 劳 |
| 辨证结论 | 病位 + 病性 + 证候名 |
| 处置与去向 | 门诊治疗 / 会诊 / 转诊，及理由 |
| 带教修正 | 判断差在哪里 |

> 本表是本章的交付物：当班填写，涉及转诊时必须附本表。

## H.6 常见失效与处置

- **先辨证再等化验** → 肾性水肿的判断依赖尿与肾功能；化验未回不得下确定性结论
- **把泡沫尿直接当蛋白尿** → 需查尿常规确认；主诉不能替代检验
- **淋证不分五类** → 石淋与劳淋的处置完全不同；先分类再论寒热

## H.7 出科考核

- 四项底线完成度（40%）
- 水肿或淋证分类判断（30%）
- 转诊与会诊理由（30%）
- 漏做尿常规或肌酐（一票否决项）
