## H.1 本章要解决的问题

咳嗽是最容易被当成「小毛病」的主诉，但它同时可能是感染、哮喘、慢阻肺急性加重、结核、肿瘤或药物副作用（如 ACEI 类）。轮转要建立的是两条纪律：先用客观指标把「必须马上处理」的挑出来，再用咳嗽的时相、痰的性状与诱因把证候分清楚，而不是听病人说「上火」就清热。

## H.2 本章目标（可检验）

- 完成咳嗽/喘证的结构化问诊：病程分期（急性 <3 周 / 亚急性 3–8 周 / 慢性 >8 周）、时相、痰的色质量、诱因与缓解因素
- 能识别需要立即上报或转诊的红旗征象，并说清依据
- 把「咳嗽」拆成病位（肺、涉脾/肾）+ 病性（风寒、风热、燥、痰湿、痰热、气火、阴虚）两行结论

## H.3 操作流程

1. 交接班与分级（5 分钟）：先看是否有新入的呼吸困难、咯血、发热患者，把待办按「今日必须处理 / 需随访 / 可观察」分栏
2. 红旗筛查（2 分钟）：静息呼吸困难或说话不成句、指脉氧 <92%、咯血、单侧胸痛伴呼吸加重、意识改变、高热不退 —— 命中即呼叫带教并启动相应流程
3. 客观数据（3 分钟）：体温、呼吸频率、指脉氧、心率、肺部听诊（干湿啰音、哮鸣音、呼吸音减弱部位），有条件加峰流速
4. 病程分期与时相：急性/亚急性/慢性；夜间加重、晨起加重、体位相关、进食呛咳 —— 分别指向不同病因
5. 痰的性状：色（白/黄/黄绿/带血）、量、质（稀/稠/泡沫/块状）、气味，各记具体值，不写「有痰」
6. 诱因与既往：吸烟史（包年）、职业粉尘、过敏原、近期用药（ACEI、β受体阻滞剂）、既往哮喘/慢阻肺/结核史
7. 望闻切：面色（苍白/晦暗）、舌（淡红/红/暗、苔白/黄/腻/少苔）、脉（浮/滑/细/数），并记桶状胸、杵状指等体征
8. 病位病性两行结论：病位（肺、涉脾/肾/肝），病性（风寒袭肺、风热犯肺、燥邪伤肺、痰湿蕴肺、痰热郁肺、肝火犯肺、肺阴亏虚）
9. 证候与反证：给出主证候并写三条支持证据 + 一条不支持证据（例如「痰黄但无口渴、无咽痛，不支持纯热证」）
10. 处置与边界：需要雾化、吸氧、抗感染等由带教决定；学生负责把「用药前后症状变化」量化记录（如咳嗽频次/夜醒次数）
11. 记录与交班：按 H.5 模板填「咳嗽/喘证接诊复盘表」，把红旗筛查结论写在最上方
12. 复盘（下班前）：把当日「我原先以为是 X，实际是 Y」的病例写一条，累计到出科考核材料

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 已记录病程分期（急性/亚急性/慢性）与具体时长
- [ ] 红旗六项已筛（静息呼吸困难 / SpO₂<92% / 咯血 / 单侧胸痛 / 意识改变 / 高热不退）
- [ ] 客观数据齐全：体温、呼吸频率、指脉氧、心率、肺部听诊
- [ ] 痰的色、量、质、气味分别有描述
- [ ] 吸烟史按包年记，职业暴露与过敏原已问
- [ ] 近期用药已核（尤其 ACEI 与 β受体阻滞剂）
- [ ] 舌象与脉象各≥2 项描述
- [ ] 病位、病性分两行写
- [ ] 主证候附三条支持证据 + 一条反证
- [ ] 用药前后症状变化有量化记录（频次/夜醒/活动耐量）
- [ ] 红旗筛查结论写在记录最上方
- [ ] 交班时能说清「哪些是今日必须处理」

## H.5 模板：咳嗽/喘证接诊复盘表

| 字段 | 填写要求 |
|------|----------|
| 主诉与病程分期 | 时长 + 急性/亚急性/慢性 |
| 红旗筛查结论 | 六项逐条写有/无与依据 |
| 客观数据 | 体温、呼吸频率、指脉氧、心率、肺部听诊 |
| 痰的性状 | 色 / 量 / 质 / 气味，各写具体 |
| 诱因与时相 | 夜间/晨起/体位/进食；吸烟包年、职业与过敏原 |
| 用药史 | 近期抗生素、ACEI、β受体阻滞剂、吸入制剂 |
| 病位·病性 | 两行分开写 |
| 证候名与证据 | 主证候 + 三条支持 + 一条反证 |
| 疗效量化 | 咳嗽频次/夜醒次数/活动耐量，用药前后对比 |
| 不确定点与带教修正 | 自己没把握的点与修正结论 |

> 本表是本章的交付物：每位咳嗽或喘证患者一张；慢性咳嗽随访时与上一张对照，看症状与用药是否真的在变。

## H.6 常见失效与处置

- **把慢性咳嗽当急性感染反复开抗生素** → 病程分期没做；>8 周要按慢性咳嗽路径查（鼻后滴漏、咳嗽变异性哮喘、胃食管反流）
- **只问「有没有痰」** → 痰的色质量决定寒热燥湿，写「有痰」等于没问
- **漏问用药史** → ACEI 引起的干咳很常见；不停药，怎么治都不好
- **SpO₂ 没测就写「无呼吸困难」** → 主观描述不能替代客观指标；呼吸频率与指脉氧必须测
- **证候写「肺热」但无支持证据** → 证候名必须能与三条证据对上，否则属于贴标签
- **随访只看「好些了吗」** → 没有量化指标就无法判断疗效；频次、夜醒、活动耐量三项至少记一项

## H.7 出科考核

- 结构化采集完整度（模板十项，35%）
- 红旗筛查与留痕（一票否决）
- 病位病性分离与证候证据链（30%）
- 疗效量化的执行（20%）
- 交班表达与不确定点（15%）
