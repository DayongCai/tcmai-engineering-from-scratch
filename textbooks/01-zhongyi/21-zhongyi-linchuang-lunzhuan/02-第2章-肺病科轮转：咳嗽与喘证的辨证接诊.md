## H.1 本章要解决的问题

咳嗽是最容易被写成「感冒后咳嗽」的主诉。轮转要能分清外感与内伤、分清喘与不喘的边界，并识别需要立刻处理的气促。

## H.2 本章目标（可检验）

- 能按病程与诱因把咳嗽分成外感、内伤两线，并写出判断依据
- 能识别喘证的危险信号（不能平卧、说话断续、唇甲发绀）并立即上报
- 能写出含痰色、痰量与寒热属性的接诊记录

## H.3 操作流程

1. 问病程：起病时间、是否反复发作、有无明确诱因（受寒、异味、运动）
2. 问痰：色、质、量、是否易咯出，痰的变化往往比咳嗽本身更能定寒热
3. 查喘：能否平卧、语声是否连续、有无三凹征与发绀
4. 辨病位：咳在肺、痰在脾、根在肾，先写病位再论证候
5. 记录：按 H.5 模板填写，注明是否已用抗菌药与激素
6. 交带教：提出「这例是否需要胸片/血常规」的具体理由

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 病程与诱因已问清
- [ ] 痰的色质量三项齐备
- [ ] 喘的危险信号已逐项排查
- [ ] 既往用药（抗菌药 / 激素 / 吸入剂）已记录
- [ ] 寒热属性有明确结论
- [ ] 阴性症不少于三条
- [ ] 需要做的检查已写明理由
- [ ] 带教意见已记录

## H.5 模板：咳嗽/喘证接诊复盘表

| 字段 | 填写要求 |
|------|----------|
| 病程与诱因 | 起病时间、诱因、复发次数 |
| 痰的性状 | 色 / 质 / 量 / 是否易咯 |
| 喘的评估 | 平卧、语声、三凹征、发绀 |
| 病位判断 | 肺 / 脾 / 肾，以及依据 |
| 寒热属性 | 痰与舌脉支持哪一侧 |
| 既往用药 | 药名、剂量、疗程、效果 |
| 拟做检查及理由 | 胸片 / 血常规 / 肺功能 |
| 带教修正 | 与自己的判断差在哪 |

> 本表是本章的交付物：当班填写，用于出科病例汇报。

## H.6 常见失效与处置

- **把慢性咳嗽一律归为外感** → 反复发作超过八周要考虑内伤与鼻后滴漏；先问复发史
- **漏看语声与三凹征** → 喘的危重程度靠这几项，不能只凭患者主诉
- **痰的描述只写「有痰」** → 色质量缺失等于没问；模板三项必须写全

## H.7 出科考核

- 痰与喘的描述完整度（40%）
- 病位判断与依据是否对应（30%）
- 危险信号识别（一票否决项）
- 检查理由是否成立（30%）
