## H.1 本章要解决的问题

眩晕与中风的共同点是「可能是急症」。轮转要把时间窗意识放在辨证之前：先判断是不是卒中，再谈风火痰虚。

## H.2 本章目标（可检验）

- 能用起病方式、伴随症与神经系统查体把中枢性眩晕与周围性眩晕分开
- 能识别卒中时间窗并完成急诊上报流程
- 能写出含风火痰虚依据的眩晕记录，且不与卒中混淆

## H.3 操作流程

1. 问起病：突发还是渐进，是否伴复视、构音障碍、行走不稳、单侧无力
2. 查体征：眼球震颤方向、指鼻试验、跟膝胫试验、病理反射、双侧血压
3. 判时间窗：最后正常时间点到接诊时刻，超过窗口也要记录并上报
4. 辨证定位：风、火、痰、虚各写依据，肝阳上亢与痰湿中阻的鉴别要写在记录里
5. 记录：按 H.5 模板填写，用 NIHSS 或简化神经查体结果
6. 交带教：明确本次是「按卒中流程处理」还是「按眩晕门诊处理」

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 起病方式与最后正常时间已记录
- [ ] 复视、构音、行走不稳、单侧无力四项已问
- [ ] 眼球震颤方向与性质已查
- [ ] 共济与病理反射已查
- [ ] 双侧血压已测
- [ ] 风火痰虚依据至少各一条或写明排除
- [ ] 卒中流程判断已写明
- [ ] 带教修正已记录

## H.5 模板：眩晕/卒中筛查复盘表

| 字段 | 填写要求 |
|------|----------|
| 起病与时间窗 | 起病方式、最后正常时间、接诊时间 |
| 神经症状清单 | 复视、构音、吞咽、单侧无力、共济 |
| 查体结果 | 眼震、指鼻、跟膝胫、病理反射、血压双侧 |
| 中枢/周围判断 | 依据与结论 |
| 中医辨证 | 风、火、痰、虚各自依据 |
| 处置路径 | 卒中流程 / 眩晕门诊，及理由 |
| 上报与会诊 | 对象、时间、回复 |
| 复盘 | 判断与最终诊断的差异 |

> 本表是本章的交付物：每例眩晕患者必填，卒中疑诊须在 30 分钟内完成上报。

## H.6 常见失效与处置

- **见眩晕先辨肝阳上亢** → 漏掉卒中筛查是最大的风险；顺序必须反过来
- **不记最后正常时间** → 时间窗决定能否溶栓；没有这个数字后续全部作废
- **眼震方向不写** → 中枢与周围的判断靠眼震性质；只写「有眼震」等于没查

## H.7 出科考核

- 卒中筛查完成度与时间记录（一票否决项）
- 神经查体描述规范度（30%）
- 中枢/周围判断依据（30%）
- 辨证与处置路径是否匹配（40%）
