# 第 5 章 · 脑病科轮转：眩晕与中风的辨证接诊

> **课程**：中医临床轮转（☯️ 中医系 · 第 9 学期 · 108 学时 · 轮转/实践）
> **契约**：**操作型章（handbook-v1）** —— 本文件是工作手册，不是学术教材：给的是当场能执行的流程、清单与模板。
> **前置**：中医内科学、中医外科学、金匮要略
> **本章产出物**：眩晕/卒中接诊复盘表

## H.1 本章要解决的问题

眩晕与中风共用一套主诉词汇（头晕、站不稳、说话不清），但前者多为外周或功能性，后者是分秒必争的急症。轮转最该建立的是「时间轴意识」：最后正常时间是什么时候、症状几分钟内到高峰、有没有伴随的言语/肢体/视野症状——这三问答不清，后面的辨证再漂亮也没用。

## H.2 本章目标（可检验）

- 在 5 分钟内完成卒中识别（面部、上肢、言语、时间）并记录「最后正常时间」
- 把眩晕分成外周性/中枢性/全身性三类，各写出支持与反对证据
- 给出病位（肝/肾/脾/脑络）+ 病性（风、火、痰、瘀、虚）两行结论，并说明与西医判断的关系

## H.3 操作流程

1. 交接班（5 分钟）：先看新发的言语不清、肢体无力、意识改变，把「最后正常时间」写在白板最上方
2. 卒中识别（2 分钟）：面部不对称、上肢下垂、言语含糊、视野缺损、共济失调 —— 任一阳性立即启动卒中流程并记录时间点，**不等待辨证**
3. 生命体征与血糖：血压、心率与节律（房颤）、指脉氧、指尖血糖（低血糖可模拟卒中）
4. 时间轴：症状起始时间、是否在睡眠中发生、是否波动、是否在 4.5 小时内（溶栓时间窗由医生判断，学生负责提供准确时间）
5. 眩晕分型：外周性（旋转感明显、伴耳鸣耳闷、水平眼震、走路偏斜但能走）、中枢性（复视、构音障碍、共济失调、垂直眼震、不能站立）、全身性（血压、贫血、低血糖、药物）
6. 伴随症与既往：头痛、呕吐、意识障碍、吞咽困难、肢体麻木；高血压、糖尿病、房颤、既往卒中史与抗凝用药
7. 望闻切：面色、舌（红/暗/胖、苔黄腻/白腻/少苔）、脉（弦/滑/细/涩）、以及构音、面瘫、肢体肌力与病理征（如已查）
8. 病位病性两行结论：病位（肝、肾、脾、脑络），病性（肝阳上亢、痰湿中阻、瘀血阻窍、气血亏虚、肾精不足；中风分风痰阻络、痰热腑实、气虚血瘀、阴虚风动）
9. 证候与反证：主证候 + 三条支持证据 + 一条反证；明确写出「本判断不替代影像与卒中评估」
10. 处置边界：溶栓、抗血小板、抗凝、降压目标均由医生决定；学生负责时间轴记录、量表填写（如 NIHSS 由培训合格者执行）与家属沟通记录
11. 记录与交班：按 H.5 模板填「眩晕/卒中接诊复盘表」，把最后正常时间、到院时间、评估时间三个时间点写清
12. 复盘：选一例「看起来像眩晕、实际是后循环缺血」的病例，写清哪一条证据纠正了判断

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 卒中识别四项已完成并记录时间（面部/上肢/言语/时间）
- [ ] 「最后正常时间」与「到院时间」均已记录到分钟
- [ ] 生命体征 + 指尖血糖已测（排除低血糖）
- [ ] 心率与节律已记（房颤线索）
- [ ] 眩晕三型（外周/中枢/全身）各写了支持与反对证据
- [ ] 伴随症（复视、构音、吞咽、共济）已逐项问
- [ ] 既往史与抗凝/抗血小板用药已核
- [ ] 舌象脉象各≥2 项描述
- [ ] 病位病性分两行写，且注明不替代影像评估
- [ ] 证候名附三条支持 + 一条反证
- [ ] 量表与评分由培训合格者完成并签名
- [ ] 家属沟通与知情记录已留痕

## H.5 模板：眩晕/卒中接诊复盘表

| 字段 | 填写要求 |
|------|----------|
| 最后正常时间 / 到院时间 | 精确到分钟；睡眠中发病写「醒后发现」 |
| 卒中识别四项 | 面部、上肢、言语、时间，逐项有/无 |
| 生命体征与血糖 | 血压、心率节律、指脉氧、指尖血糖 |
| 眩晕分型证据 | 外周/中枢/全身各写支持与反对证据 |
| 伴随神经症状 | 复视、构音、吞咽、共济、感觉异常 |
| 既往与用药 | 高血压/糖尿病/房颤；抗凝与抗血小板清单 |
| 病位·病性 | 两行分开写，注明不替代影像 |
| 证候名与证据 | 主证候 + 三条支持 + 一条反证 |
| 量表与评分 | 量表名、分值、执行人与时间 |
| 不确定点与带教修正 | 自己没把握的点与修正结论 |

> 本表是本章的交付物：每位急性眩晕或疑似卒中患者一张；卒中流程病例须在 24 小时内完成复盘。

## H.6 常见失效与处置

- **把卒中当眩晕治** → 未做卒中识别；任何急性眩晕都要先过一遍四项识别
- **只写「上午发病」** → 卒中判断以分钟计；最后正常时间必须精确并留痕
- **漏测血糖** → 低血糖可完全模拟卒中，漏测会导致方向性错误
- **不查房颤与抗凝用药** → 直接影响后续抗栓决策与出血风险
- **用「肝阳上亢」解释一切头晕** → 缺舌脉与诱因支撑；中枢性眩晕被贴上肝阳标签最危险
- **家属沟通只口头进行** → 无记录等于没沟通；关键告知必须留痕

## H.7 出科考核

- 卒中识别与时间轴记录（一票否决：未记录最后正常时间即不通过）
- 眩晕分型的证据质量（30%）
- 病位病性与证候证据链（25%）
- 量表执行与沟通留痕（20%）
- 复盘质量（15%）
