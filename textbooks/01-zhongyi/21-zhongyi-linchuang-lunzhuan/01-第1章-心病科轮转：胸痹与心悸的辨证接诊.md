# 第 1 章 · 心病科轮转：胸痹与心悸的辨证接诊

## H.1 本章要解决的问题

同一位胸闷病人，前一位医生写「胸痹」，后一位写「心悸」——两个名字背后的处置路径不同。轮转第一天要能判断这次接诊该走哪条路径，并在十分钟内留下能复盘的记录。

## H.2 本章目标（可检验）

- 10 分钟内完成胸痹/心悸的主诉采集与四诊要点记录（含舌脉）
- 按「先排危重、再辨证」的顺序判断，能说清排除依据
- 写出含病位、病性、证候名与不确定点的接诊记录，交带教复核

## H.3 操作流程

1. 交接班：读上一班病历、待办与未回报检查，标出三类待办（结果未回 / 需复诊 / 需上报）
2. 危重筛查：胸痛伴汗出、放射痛、血压不对称或静息呼吸困难 → 立即呼叫带教并启动急诊流程，此处不辨证
3. 四诊采集：问诱因与缓解方式、望面色唇甲、闻语声喘息、切脉位脉率脉势并看舌质舌苔
4. 辨证定位：先写「病位」与「病性」两行结论，再给证候名，避免直接跳到方名
5. 记录：按 H.5 模板写结构化病历，阴性症与鉴别要点必须写
6. 交带教：60 秒口述摘要 + 主动提出一个不确定点，并记下带教的修正

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 主诉一句话含时间与诱因
- [ ] 危重筛查三问已问（出汗 / 放射 / 静息呼吸困难）
- [ ] 舌象与脉象各至少两项描述
- [ ] 阴性症记录不少于三条
- [ ] 病位与病性分开写，未混为一句
- [ ] 证候名与治法一一对应
- [ ] 带教修正点已写入复盘表
- [ ] 病历有时间戳与签名

## H.5 模板：胸痹/心悸接诊复盘表

| 字段 | 填写要求 |
|------|----------|
| 主诉与病程 | 一句话，含时间、诱因、缓解方式 |
| 危重筛查结论 | 已排除哪些、依据是什么 |
| 四诊要点 | 舌 / 脉 / 伴随症各写具体描述 |
| 阴性症 | 至少三条，写清问过但没有的 |
| 病位·病性 | 两行分开写 |
| 证候名与治法 | 证候名 + 对应治法 |
| 不确定点与带教修正 | 自己没把握的点，以及带教怎么说 |
| 下一步 | 检查 / 复诊 / 转诊，写清由谁执行 |

> 本表是本章的交付物：当班每接一位胸痹或心悸患者填一张，出科时随机抽 5 张评分。

## H.6 常见失效与处置

- **见心悸即安神** → 未辨痰火与水饮，方向就错了；先定病位病性再选方
- **只写阳性症** → 复盘时无法判断是否漏问；阴性症必须逐条写
- **把危重筛查放到辨证之后** → 顺序颠倒会导致延误；一律先排危重

## H.7 出科考核

- 接诊记录完整度（模板八项齐全，40%）
- 辨证依据与证候名的一致性（30%）
- 危重筛查执行情况（一票否决：漏做即本次不通过）
- 口述摘要与不确定点表述（30%）
