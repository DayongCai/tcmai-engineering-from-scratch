# 第 3 章 · 脾胃病科轮转：胃痞与泄泻的辨证接诊

## H.1 本章要解决的问题

胃痞（上腹痞满）与泄泻（大便性状改变）是门诊量最大的两类主诉，也是最容易被「经验性开药」糊过去的两类：一开就开抑酸药或止泻药，症状缓解了但病因没查。轮转要立两条底线：先排消化道出血、消瘦、吞咽困难等红旗；再把「吃了什么、拉了什么、什么时候疼」这三件事问成可复核的数据。

## H.2 本章目标（可检验）

- 用结构化问诊把「胃痞/泄泻」拆成可判断的要素：部位、时间关系、诱因、大便性状与频次
- 识别并上报需要立即处理的情况（出血、脱水、疑似急腹症）
- 给出病位（脾/胃/肝/肾）+ 病性（寒、热、虚、实、气滞、湿）两行结论，并写出支持与反证

## H.3 操作流程

1. 交接班与分诊（5 分钟）：先看有无黑便、呕血、剧烈腹痛、频繁水样便伴口干尿少的患者，优先处理
2. 红旗筛查（3 分钟）：呕血或黑便、6 小时内反复呕吐、剧烈持续腹痛、腹部板硬拒按、明显消瘦（近 3 个月下降 >5%）、吞咽困难、发热伴黄疸 —— 命中即上报
3. 脱水评估：口干、尿量减少、皮肤弹性、体位性头晕、心率增快；儿童与老人门槛更低，需更早干预
4. 胃痞问诊四件事：部位（上腹/剑突下）、与进食关系（餐前/餐后/夜间）、性质（胀/痛/灼/堵）、伴随（反酸、嗳气、恶心）
5. 泄泻问诊四件事：频次（次/日）、性状（水样/糊状/黏液/脓血/脂肪样）、时间（晨起/餐后/夜间）、伴随（腹痛—便后缓解？里急后重？）
6. 饮食与用药：近期不洁饮食、乳制品、酒精、抗生素与 PPI 使用、泻药与保健品；旅行史与集体发病线索
7. 望闻切：面色、舌（淡/红/胖有齿痕、苔白腻/黄腻/少苔）、脉（濡/滑/细/弦）、腹部触诊（压痛部位、有无包块、肠鸣音）
8. 病位病性两行结论：病位（胃/脾，涉肝/肾/大肠），病性（寒邪客胃、饮食伤胃、肝气犯胃、湿热阻胃、瘀血停胃、胃阴亏虚、脾胃虚寒；泄泻分寒湿、湿热、食滞、肝郁、脾虚、肾虚）
9. 证候与反证：主证候 + 三条支持证据 + 一条反证；对「寒热错杂」的病例，明确写以何者为主、依据是什么
10. 处置边界：补液、止泻、抑酸、抗感染由带教决定；学生负责记录出入量、排便记录单与症状日记
11. 记录与交班：按 H.5 模板填「胃痞/泄泻接诊复盘表」，把排便记录单复印件附后
12. 复盘：总结一例「症状缓解但病因未明」的病例，写清后续该查什么（幽门螺杆菌、粪便常规+潜血、内镜指征）

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 红旗七项已筛（呕血/黑便、反复呕吐、剧烈腹痛、板状腹、消瘦、吞咽困难、发热黄疸）
- [ ] 脱水五项已评（口干、尿量、皮肤弹性、体位性头晕、心率）
- [ ] 胃痞：部位、与进食关系、性质、伴随症四项齐全
- [ ] 泄泻：频次、性状、时间、伴随四项齐全，性状写到「水样/黏液/脓血」级别
- [ ] 饮食、用药（含抗生素与 PPI）、旅行史已问
- [ ] 腹部触诊记录压痛部位与肠鸣音
- [ ] 舌象脉象各≥2 项描述
- [ ] 病位病性分两行写
- [ ] 主证候有三条支持证据与一条反证
- [ ] 出入量或排便记录单已建立并当日更新
- [ ] 内镜/化验指征已写清（该查什么、为什么查）
- [ ] 带教修正与不确定点已记录

## H.5 模板：胃痞/泄泻接诊复盘表

| 字段 | 填写要求 |
|------|----------|
| 主诉与病程 | 时长、频次、与进食关系 |
| 红旗与脱水评估 | 七项红旗 + 五项脱水逐条写结论 |
| 大便记录 | 次数/性状/量/颜色/有无黏液脓血 |
| 饮食与用药 | 可疑食物、抗生素、PPI、泻药、保健品 |
| 腹部体征 | 压痛部位、包块、肠鸣音、有无肌紧张 |
| 舌脉 | 舌质舌苔、脉象各两项以上 |
| 病位·病性 | 两行分开写 |
| 证候名与证据 | 主证候 + 三条支持 + 一条反证 |
| 化验与检查指征 | 该查什么、指征是什么、结果回报时间 |
| 不确定点与带教修正 | 自己没把握的点与修正结论 |

> 本表是本章的交付物：每位胃痞或泄泻患者一张；连续腹泻者按日续填排便记录，出科时抽 5 张评分。

## H.6 常见失效与处置

- **上腹不适一律按「胃炎」处理** → 未做红旗筛查；消瘦、吞咽困难、黑便的病例必须先排器质性病变
- **把「大便稀」当泄泻全部** → 性状、频次、时间是分型依据，缺一项就无法辨寒热虚实
- **不记出入量** → 脱水程度无法判断，补液也就没有依据
- **只问饮食不问用药** → 抗生素相关性腹泻、PPI 相关腹泻常被漏掉
- **证候写「脾虚湿盛」当万能答案** → 必须有舌脉与诱因支撑；否则属于套模板
- **症状好转即结案** → 未写后续检查与随访计划，等于把病因留给了下一位医生

## H.7 出科考核

- 红旗与脱水的评估完整度（一票否决：漏筛红旗即不通过）
- 四要素问诊与大便记录质量（30%）
- 病位病性分离与证候证据（30%）
- 检查指征与随访计划（20%）
- 交班与复盘质量（20%）
