## H.1 本章要解决的问题

胃痞与泄泻最容易在问诊阶段被合并成「脾胃虚弱」。轮转要能把虚、实、寒、热、湿拆开，并问出真正影响处置的两件事：大便性状与饮食关系。

## H.2 本章目标（可检验）

- 能用大便性状与餐后反应把胃痞与泄泻分开定位
- 能写出虚实寒热的判断依据，不只给「脾虚」一个结论
- 能识别需要警惕的报警症状（消瘦、黑便、吞咽困难）

## H.3 操作流程

1. 问进食关系：餐前痛、餐后胀、食后即泻，三者指向不同病位
2. 问大便：次数、性状（成形/溏/水样/夹黏液）、有无未消化食物
3. 查报警症状：体重下降、黑便、呕血、进行性吞咽困难、贫血貌
4. 辨虚实：病程长短、按之喜拒、舌苔厚薄三项交叉判断
5. 记录：按 H.5 模板写，注明既往胃肠镜检查结果
6. 交带教：说明本次是否需要复查胃镜或便常规

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 进食与症状的关系已问清
- [ ] 大便次数与性状已具体记录
- [ ] 报警症状逐条排查
- [ ] 虚实判断有三项以上依据
- [ ] 舌苔厚薄与腻腐已描述
- [ ] 既往胃肠镜与用药已记录
- [ ] 是否需要复查检查已给出结论
- [ ] 带教修正已记录

## H.5 模板：胃痞/泄泻接诊复盘表

| 字段 | 填写要求 |
|------|----------|
| 进食关系 | 餐前 / 餐后 / 食后即泻 |
| 大便性状 | 次数、性状、黏液或未消化物 |
| 报警症状 | 体重、黑便、呕血、吞咽困难 |
| 虚实依据 | 病程、按诊、舌苔 |
| 寒热依据 | 口苦口淡、喜温喜凉、小便黄赤 |
| 既往检查 | 胃肠镜、幽门螺杆菌、用药 |
| 结论与治法 | 病位 + 病性 + 证候名 + 治法 |
| 待办 | 复查项目与时间 |

> 本表是本章的交付物：当班填写，出科时与带教共同复核三例。

## H.6 常见失效与处置

- **一律写「脾虚湿盛」** → 虚实未分时用药方向相反；先做三项交叉判断
- **不问大便性状** → 泄泻的寒热虚实主要靠大便与舌苔，缺了就无法下结论
- **漏查报警症状** → 消瘦与黑便提示需优先排查器质病变，不能只按功能性疾病处理

## H.7 出科考核

- 进食关系与大便记录（40%）
- 虚实寒热依据链（30%）
- 报警症状排查（一票否决项）
- 待办事项是否可执行（30%）
