# 第 8 章 · 评估偏差、过度检查与质量治理

> **层次**：本文件是**本库撰写层**（无底本表，不是源正文层）。依据是 USPSTF 筛查建议、GDS 解释条件、Hendrich II 复评规则，条文登记于 `standards/jiankang-pinggu/外源条文.json`（25 条，逐字可核）。
> **依据**：`standards/jiankang-pinggu/补源登记.json`（6 份来源 / 25 条，逐字可核 25/25）。
> **免责**：本章为评估质量的教学整理，不构成诊断或治疗建议；质量治理须依机构制度。

## 本章要回答的问题

评估的质量问题有两种相反的方向：**做得太少**（用「年纪大了」一句话带过）和**做得太多**（人人都筛、项目越加越多）。本章用三条条文把两个方向都钉住：抑郁不是自然老化（E05）、不推荐无症状常规认知筛查（E08）、每年复评与状态变化时复评提高可靠性（E11）。剩下的问题是：怎么把这三条变成可执行的质量治理。

> 「the U.S. Preventative Services Task Force (USPSTF) does not recommend routine cognitive screening in asymptomatic community-dwelling older adults」（外源·Mental Status Assessment of Older Adults 第2条）

## N.1 概念与出处

| 条 | 内容 | 对应的偏差类型 |
|---|---|---|
| 外源·The Geriatric Depression Scale 第5条 | 抑郁不是老化的自然组成部分 | **归因偏差**：把可治的当不可逆 |
| 同 第3条 | 0–4 正常；分数解释受年龄、教育、主诉影响 | **解释偏差**：一刀切阈值 |
| 外源·Mental Status Assessment of Older Adults 第2条 | USPSTF **不推荐**对无症状者常规认知筛查 | **过度检查** |
| 同 第3条 | 分诊工具，识别需进一步评估者 | **越界偏差**：筛查当诊断 |
| 外源·Fall Risk Assessment for Older Adults 第2条 | 每年 + 状态变化时复评，可提高可靠性 | **一次性评估**（缺复评） |
| 同 第1条 | 跌倒为多因素病因 | **单因归因**：只怪腿脚 |

六条覆盖了四类偏差（归因、解释、过度检查、缺复评），正好可以做成治理清单。

## N.2 为什么可以这样翻译：四类偏差与一张治理表

**四类偏差的表现与纠正**：

| 偏差 | 表现 | 纠正 |
|---|---|---|
| 归因偏差 | 「这个年纪都这样」「老来寂寞正常」 | 凡「年龄相关」结论必须同时列出已排除的可逆因素（抑郁、贫血、甲状腺、疼痛、药物） |
| 解释偏差 | 把 GDS 7 分直接写成「抑郁」 | 记录带三项背景（年龄、教育、躯体主诉），结论落到「需关注 + 下一步」 |
| 过度检查 | 给所有老人做认知筛查 | 按指征做（第2条：无主诉、无功能下降不做）；做了要写理由 |
| 越界偏差 | 把 Mini-Cog 结果写成「痴呆」 | 写「提示需进一步评估」，转诊而非定论（第3条） |
| 缺复评 | 评估只在入院做一次 | 每年 + 状态变化时复评（E11）；复评结果与上次对照写 |

**质量治理三件**（把上面的纠正变成制度）：

1. **必做最小集 + 按指征追加**：四域各 1–2 项为必做；其余项目按指征，且必须在记录里写指征。
2. **复评台账**：以「上次评估日期 + 状态变化事件」为触发条件，而不是「每年体检时顺手做」。
3. **抽查四问**（质控用）：这个分数解释了没有？这次的指征是什么？上次复评是什么时候？老人自己的目标写了没有？

**为什么「加项目」不是治理**：第2条明确不推荐无症状常规筛查——加项目会增加假阳性、增加后续检查、增加老人焦虑，而不提高结局。质量治理的目标是**每一分投入都对应一个可改变的动作**，不是「项目齐全」。

**抽查四问的操作细则**：四问要能一次抽 10 份记录、10 分钟内出结果：**① 分数解释了没有**（看解释段是否含年龄/教育/主诉三项）；**② 指征写了没有**（做得对不对，先看为什么做）；**③ 复评时间写了没有**（下一次何时、触发条件是什么）；**④ 老人目标写了没有**（④ 段是否为空）。四问里任一项缺失即判「记录不合格」，按不合格率做月度趋势——这比「评估完成率」更能反映质量，因为完成率只说明做了什么，不说明做得对不对。

## N.3 这个翻译丢掉了什么

- **不给质量指标的计算口径**：评估完成率、复评率、阳性预测值的统计方法属质量管理。
- **不给不良事件的定义与上报流程**：漏评、误判的定级与上报依机构制度。
- **不给知情同意的具体文本**：筛查前告知的内容与形式依规范。
- **不给培训与认证要求**：量表施测的培训学时与考核属机构培训体系。
- **不给伦理学论证的完整框架**：过度检查的伦理分析（受益/伤害/自主）属医学伦理学。

**一个常见误判：评估完成率高就是质量好**：完成率只证明「做了」，不证明「做对」。一份分数写错、解释缺失、复评无着落的记录，在完成率里是满分。因此治理指标至少要两条并列：**完成率**（做没做）+ **不合格率**（抽查四问的缺失比例）。只报前者，等于给形式主义发奖。

## N.4 与相邻学科的接口

| 相邻学科 | 接口 |
|---|---|
| 质量管理 | 指标设定、抽查、持续改进（PDCA） |
| 医学伦理学 | 过度检查与筛查的受益-伤害权衡 |
| 卫生经济学 | 筛查成本与后续检查成本 |
| 临床流行病学 | 灵敏度、特异度、阳性预测值 |

## N.5 争议与本项目立场

**争议一：不推荐常规筛查，是否等于「不筛查」？** 不等于。是不推荐**无症状者的常规**筛查；有主诉、有功能下降、有家属疑问时应当做（第3条的分诊价值正在此）。教材若写成「不必筛查」，就是把限定条件删了。

**争议二：项目少会不会漏？** 会，但漏的概率与「做了却不解释、不复评」相比更可控。本项目立场：**必做最小集 + 指征追加 + 复评** 三件同时成立时，漏检率与过度检查率都能压低；只做「项目齐全」而没复评，是最差组合。

**争议三：质量治理由谁负责？** 不是某个人，而是**记录 + 复评 + 抽查**三件构成的闭环。本项目立场：教材应把治理写成可执行动作（谁在什么时点做什么），而不是写「应加强质量管理」这类空话。

> **免责**：本章所列条文与判据不构成诊断或治疗建议；质量治理措施须依所在机构制度与规范。

## 小结

1. 四类偏差：归因（年龄万能）、解释（一刀切阈值）、过度检查（无症状普筛）、越界（筛查当诊断）。
2. 第5条否掉「老来抑郁正常」；第2条否掉无症状常规认知筛查；第3条把工具定在分诊位。
3. 缺复评本身是偏差：每年 + 状态变化时复评（第2条）。
4. 治理三件：必做最小集 + 指征追加、复评台账、抽查四问。
5. 「加项目」不是治理；每一分投入都要对应一个可改变的动作。
