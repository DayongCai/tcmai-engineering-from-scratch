## H.1 本章要解决的问题

「加强健康教育能提高依从性」是方向不是命题：教育讲什么、讲几次、谁来讲、讲到什么程度算完成、依从性用什么测，全都没定，做出来无法归因。护理毕设要交的是一条能被证伪的命题：人群说得清、干预拆得开、结局测得准、样本够得着，四者缺一，答辩时都会被追问到答不上来。选题阶段真正要完成的是把「我觉得这个问题重要」换成「我能用十周、在本科室、用可及的人力把它证实或否证」。

## H.2 本章目标（可检验）

- 把轮转中反复出现的护理问题写成含人群、干预、对照、结局的可评价命题
- 选定一个护理敏感结局（如跌倒、压疮、非计划拔管发生率或自护能力得分）并确认量表可用
- 确定设计与对照，说明可比性威胁与组间污染风险
- 按科室出院量反推可及样本，判断十周内能否完成

## H.3 操作流程

1. 找问题：翻轮转记录与交班本，记下反复出现、有具体场景与频次的事件，不写「患者教育不足」这类泛语
2. 三问筛：这事有后果吗、护理措施能改变吗、十周内能观察到变化吗，三问皆过才留下
3. 写 PICO：人群与病种、干预、对照、结局、观察时长，逐项写到别人能照你的话复述
4. 拆干预五要素：内容、频次、执行者、单次时长、场所与工具，缺一项就算没写清
5. 定结局：主要结局只留一个，次要一至两个，主次写在开题表第一行，后文不再增补
6. 核可测：结局有无现成量表、量表来源与使用授权、计分口径与分级界值，三样都要落到纸质材料
7. 选设计：能做随机就随机；做不到用类实验（前后对照或历史对照），并把可比性威胁逐条写明
8. 算可及：科室月出院量乘可纳入比例乘十周，减去不符合与拒签者，得预期例数并留失访余地
9. 反推效应：按可及例数算最小可检出差异，若差异大到临床不现实，缩小结局范围或改设计
10. 判伦理：是否涉及弱势人群、是否需知情同意、是否只用常规护理数据，先问清再定题
11. 写不做清单：不做的病种、不做的随访时长、不做的亚组，逐条写理由，防止范围持续膨胀
12. 排十周：伦理送审、培训、入组、随访、分析、写作各占几周，标出关键路径与最可能卡住的一环

## H.4 现场清单（逐项打勾，缺一项不算完成）

## H.5 模板：开题命题表（护理）

| 字段 | 填写要求 |
|------|----------|
| 护理问题 | 场景、频次、后果，一句话说清 |
| PICO | 人群病种、干预、对照、结局、观察时长 |
| 干预五要素 | 内容、频次、执行者、单次时长、场所与工具 |
| 主要结局 | 护理敏感指标、量表、计分与界值 |
| 次要结局 | 一至两项及测量方式 |
| 设计 | 随机、类实验或前后对照，含可比性威胁 |
| 样本 | 月出院量、纳入比例、预期例数、失访预留 |
| 最小可检出效应 | 按可及例数推算的差异下限 |
| 不做清单与排期 | 舍弃项、十周里程碑、关键路径 |

> 本表是本章的交付物：开题首页一页纸，导师签字后不再改动；答辩时逐行对照，任何改动须写版本与日期。

## H.6 常见失效与处置

- **干预写成口号** → 「加强宣教」无法执行与比较，必须拆到动作与频次
- **结局用医生指标** → 治愈率、住院日不反映护理贡献，归因会被直接质疑
- **主要结局铺开** → 三四个结局都报，多重比较把结论稀释到没有一个站得住
- **不限人群** → 病种混杂，两组基线差异大，结果无法解释也无法推广
- **样本靠估** → 不按出院量核算，入组两周就发现凑不齐，只能改题
- **伦理后补** → 先入组再送审属重大违规，已收集的数据可能整体作废

## H.7 中期检查与答辩要点

- 命题可证伪与干预可执行（35%）
- 结局敏感度与可测性（30%）
- 样本与设计可行性（25%）
- 伦理预判与十周排期（10%）
