## H.1 本章要解决的问题

「加强健康教育能提高依从性」这类命题太宽：教育内容、次数、评价方式都没定，做出来无法归因。

## H.2 本章目标（可检验）

- 把护理问题写成可评价命题
- 选定护理敏感结局指标
- 判断十周内可完成的样本量

## H.3 操作流程

1. 定问题：从轮转中挑一个反复出现的护理问题
2. 写干预：内容、频次、执行者、时长逐项写死
3. 定结局：一个护理敏感指标（如自护能力、压疮发生率、依从性量表）
4. 定对照：常规护理或历史对照，说明可比性
5. 估样本：按科室出院量估算可及例数

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 干预五要素（内容/频次/执行者/时长/场所）已写
- [ ] 结局指标护理敏感且可测
- [ ] 对照选择有理由
- [ ] 入排标准已写
- [ ] 样本可及性已估
- [ ] 伦理需求已判断
- [ ] 十周可行性已评估

## H.5 模板：开题命题表（护理）

| 字段 | 填写要求 |
|------|----------|
| 护理问题 | 轮转中观察到的具体问题 |
| 干预方案 | 五要素逐项 |
| 结局 | 护理敏感指标与量表 |
| 对照 | 常规/历史，及可比性 |
| 样本 | 可及例数与来源 |

> 本表是本章的交付物：开题首页，答辩对照。

## H.6 常见失效与处置

- **干预写得像口号** → 「加强宣教」无法执行与比较；须拆五要素
- **结局用医生指标** → 护理毕设应选护理敏感指标，否则归因不清
- **不限人群** → 病种混杂导致结论无意义

## H.7 中期检查与答辩要点

- 干预可执行（40%）
- 结局敏感度（30%）
- 样本可行性（30%）
