## H.1 本章要解决的问题

护理结局评价最怕「指标一大堆，每个都只做一次」。本章要求一个主要指标、两个次要指标，并说明测量时点。

## H.2 本章目标（可检验）

- 确定主要与次要结局及测量时点
- 完成组间比较并报告效应量
- 分析失访与依从性对结论的影响

## H.3 操作流程

1. 定指标：主要一个、次要两个，各含量表与计分
2. 定时点：基线、干预结束、随访一个月
3. 统计：组间比较、效应量、置信区间
4. 敏感性：对失访与低依从做分析
5. 解释：与开题命题逐条对照

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 主要结局唯一
- [ ] 量表与计分口径已写
- [ ] 三个时点齐全
- [ ] 效应量与区间已报
- [ ] 失访做敏感性分析
- [ ] 依从性分层分析已做
- [ ] 边界与推广限制已写

## H.5 模板：结局评价表

| 字段 | 填写要求 |
|------|----------|
| 主要结局 | 指标、量表、时点 |
| 次要结局 | 两项 |
| 统计 | 组间差、效应量、95%CI |
| 敏感性 | 失访与低依从 |
| 边界 | 可推广与不可推广 |

> 本表是本章的交付物：结果章首页。

## H.6 常见失效与处置

- **主要结局多个** → 多重比较稀释结论
- **只报均数与 P 值** → 缺效应量无法判断临床意义
- **忽略依从性** → 干预没做够却报告无效，会错杀有效方案

## H.7 中期检查与答辩要点

- 指标设计（40%）
- 统计报告（30%）
- 敏感性分析（30%）
