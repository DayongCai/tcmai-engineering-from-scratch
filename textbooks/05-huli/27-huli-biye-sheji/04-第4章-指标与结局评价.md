## H.1 本章要解决的问题

护理结局评价最怕「指标一大堆，每个只测一次」：跌倒率、满意度、自护能力、住院日全报一遍，结果每个都说不清。结局评价要先把一个主要指标定义到分子分母：谁算跌倒、观察窗口多长、数据从哪里取、由谁判定；再定测量时点与测量人，最后报效应量与置信区间，而不是只报一个 P 值。护理敏感指标的价值正在这里：它测量的是护理措施能改变的部分，定义清楚了，干预与结局之间才接得上。

## H.2 本章目标（可检验）

- 把主要结局定义到分子、分母、观察窗口、数据来源与判定人
- 确定基线与随访时点，明确测量者与盲法安排
- 完成组间比较，报告效应量与置信区间而非只有 P 值
- 分析失访、依从性与基线差异对结论的影响，写出结论分寸

## H.3 操作流程

1. 定主要结局：只留一个，与开题命题的主语一致，写在结果章第一段，全文不换，也不因结果不好而加
2. 写定义：分子（发生例数或得分变化）、分母（纳入分析人数）、观察窗口、判定人，逐项写死到可照抄
3. 定数据源：护理记录、不良事件上报、量表测评，写明具体字段与提取方式，不用口头补充，缺失要记原因
4. 核量表：来源、中文版信效度、使用授权、计分与分级界值，全文附在附录，缺授权不得使用
5. 定时点：基线、干预结束、随访一个月；每个时点允许的窗口误差要写明，超出即记偏离并说明处理
6. 排测量：谁测、何时测、如何避免知道分组；做不到盲法就说明原因，并评估偏倚可能的方向与大小
7. 控质量：测量者统一培训一次，双人录入并抽查一成，量表当场回收不代填，字迹与漏项当日记
8. 算样本：按主要结局的预期率差或均数差估算，写清参数来源、检验水准、把握度与失访预留比例
9. 描述基线：两组年龄、病情、基线得分并列，差异大的变量纳入调整分析并说明选择理由
10. 组间比较：连续变量先看分布再选检验，分类变量算率差；同时给效应量与置信区间，不只给 P 值
11. 处理失访：报失访人数与原因，做完成者分析与保守填补两种，看结论是否翻转，翻转就照实写
12. 分层解释：按依从率分层看结局，低依从组单独描述，避免把没做够当成干预无效，也避免只报高依从组

## H.5 模板：结局评价表

| 字段 | 填写要求 |
|------|----------|
| 主要结局 | 定义、分子分母、观察窗口、数据源 |
| 次要结局 | 一至两项及各自测量方式 |
| 时点 | 基线、干预结束、随访及允许窗口 |
| 测量 | 测量者、培训、盲法或替代安排 |
| 样本量 | 预期效应、参数来源、失访预留 |
| 基线 | 两组关键变量与差异 |
| 组间比较 | 检验方法、效应量、置信区间 |
| 失访 | 人数、原因、两种处理结果 |
| 依从性分层 | 分层依据与各层结局 |

> 本表是本章的交付物：结果章首页一张表定口径；写作与答辩均以此表为准，改口径须回改全表并记版本。

## H.6 常见失效与处置

- **主要结局多个** → 多重比较下没有一个站得住，结论只能写「有改善趋势」
- **只报均数与 P 值** → 缺效应量，看不出差异在临床上有多大，也无法与文献比
- **定义含糊** → 把跌倒风险事件算进跌倒，发生率被高估，口径无法复核
- **测量者知道分组** → 测得偏倚，干预组被无意识放宽，量表分虚高
- **失访当缺失丢掉** → 完成者分析高估效果，失访越多结论偏得越乐观
- **忽略依从性** → 干预没做够就报无效，会把可行方案错杀，也误导后人

## H.7 中期检查与答辩要点

- 结局定义与测量（35%）
- 统计报告完整（30%）
- 失访与依从性分析（20%）
- 结论分寸与边界（15%）
