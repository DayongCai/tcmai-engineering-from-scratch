## H.1 本章要解决的问题

护理答辩最常见的问题是「你说干预有效，可病人自护能力真的提高了吗，还是只是答问卷答得好」。

## H.2 本章目标（可检验）

- 论文数据与核查表、结局表一致
- 15 分钟讲清问题、干预、结局、边界
- 准备三个质疑（测量、污染、依从性）

## H.3 操作流程

1. 对表：数值回溯到结局表
2. 写结构：问题、干预、结局、边界、推广
3. 写局限：测量偏倚、组间污染、单中心
4. 预设质疑并准备答案
5. 试讲并修改

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 数值与结局表一致
- [ ] 五段结构齐全
- [ ] 局限三条已写
- [ ] 三个质疑有答案
- [ ] 量表来源已注明
- [ ] 引用写到篇名
- [ ] 免责与致谢已写

## H.5 模板：答辩准备表（护理）

| 字段 | 填写要求 |
|------|----------|
| 核心结论 | ≤40 字 |
| 证据链 | 干预→依从性→结局 |
| 三个质疑 | 测量/污染/依从性 |
| 边界 | 单中心与外推 |
| 试讲反馈 | 修改点 |

> 本表是本章的交付物：答辩前一天自查。

## H.6 常见失效与处置

- **把问卷分数等同能力** → 需结合行为指标；单靠自评会被质疑
- **回避组间污染** → 同病房易交叉；须说明隔离措施
- **超时** → 15 分钟须取舍

## H.7 中期检查与答辩要点

- 数据一致（40%）
- 局限意识（30%）
- 质疑回答（30%）
