## H.1 本章要解决的问题

护理答辩最常被问的一句是「病人自护能力真提高了，还是只是问卷答得好」。论文要把干预、执行、结局三段接上：谁做的、做了几次、依从多少、结局怎么测、测得准不准。写作不是把核查表誊清，而是让评审沿着一条链往前走，每一步都能指回原始记录。凡是正文里出现的人数、率、得分，都要能说出它来自哪张表哪一页；说不出来，答辩现场就会被追问到崩。

## H.2 本章目标（可检验）

- 论文里每个数字都能回溯到核查表或结局表的对应页
- 按对象与方法、结果、讨论、局限四段写清干预与测量，他人可照做
- 准备三类质疑的答法：测量偏倚、组间污染、依从性不足
- 完成一次试讲并按反馈修改，稳定控制在十五分钟

## H.3 操作流程

1. 定主线：一句话写清干预对主要结局的影响方向与大小，全文围绕它取舍材料，写不出来说明结果没算清
2. 搭结构：摘要四句，引言写问题与证据缺口，方法写设计与对象，结果按主次，讨论比对文献，局限单列不混写
3. 写对象：场所、时间、纳入与排除、样本量依据、分组方式、失访人数，逐项交代到别人能判断可比性
4. 写干预：手册版本、执行者、培训与考核、依从率，写到别人拿你的方法章就能在本科室照着做一遍
5. 写结局：主要与次要、量表来源与授权、测量时点、测量者、盲法或替代安排，与结局评价表逐行对齐
6. 写统计：软件与版本、检验方法选择理由、效应量与区间、失访处理方式，避免只写「P 小于零点零五」
7. 做图表：入组到分析的流程图一张，基线表一张，主要结局一张，图注写 n、误差线含义与判据线
8. 写讨论：与至少三篇文献比对，一致处与不一致处各给原因假设，不只复述自己的结果
9. 写局限：单中心、非盲、自评量表、依从率不足、随访短，逐条写清会把结论带偏到哪个方向
10. 备质疑：测量偏倚、组间污染、依从性不足各写一问一答，答案指向具体表号与页码，不背套话
11. 试讲：掐表十五分钟，请一位带教与一位同学各提两条意见，逐条记录并改稿，改完再讲一遍
12. 归档：论文、核查表、结局表、分析文件四件同目录，命名统一，便于复核与下一届接手

## H.5 模板：答辩准备表（护理）

| 字段 | 填写要求 |
|------|----------|
| 核心结论 | 一句话，含方向与效应量 |
| 证据链 | 干预动作到依从率到结局的对应 |
| 执行证据 | 手册版本、培训、核查表抽查结果 |
| 测量证据 | 量表来源、时点、测量者、盲法 |
| 三个质疑 | 测量偏倚、组间污染、依从不足 |
| 答法要点 | 每条答法指向的表号与页码 |
| 局限 | 单中心、非盲、随访短及影响 |
| 推广边界 | 可推广人群与不可推广情形 |
| 试讲反馈 | 意见、修改点、是否已改 |

> 本表是本章的交付物：答辩前一天自查一页；左栏列结论与证据链，右栏列可能追问与答法，现场按行应答。

## H.6 常见失效与处置

- **把问卷分数等同能力** → 自评受社会赞许影响，须配行为指标一起报，答不出行为变化
- **回避组间污染** → 同病房交叉不说明，效果被高估，且无法自证清白
- **方法与结果不对应** → 结局表有四个指标，方法章只写两个，等于事后补设计
- **数字对不上** → 正文与表格差一人，追问一句即崩，全篇可信度归零
- **局限写套话** → 只写样本量小，不写对结论的具体影响，等于没写
- **超时** → 十五分钟讲完设计已无时间讲结果，重点与取舍全丢

## H.7 中期检查与答辩要点

- 数据一致与可溯源（35%）
- 方法与干预呈现（25%）
- 局限与边界（20%）
- 答辩应对（20%）
