## H.1 本章要解决的问题

护理方案的价值在于下一班、下一届能直接执行。交接若只给论文，接手人拿到的是结论不是做法：手册在哪、核查表怎么填、培训讲什么、人力不足时先砍哪一步，全都没有。移交要把个人经验变成可打印、可培训、可核查的方案包，并由一位没参与研究的护士按包独立跑通一例。跑不通的地方就是方案包的缺口，回改之后再签收，才算真正交出去。

## H.2 本章目标（可检验）

- 交出可执行的方案包：方案文本、动作表与核查表、培训材料、评价工具四件齐全
- 写明适用范围、禁忌情形与常见偏差的处理办法
- 由未参与研究的护士按包独立执行一例，记录卡点与偏差
- 写清人力、耗材、场地、信息系统前提，以及数据归属与使用许可

## H.3 操作流程

1. 清点：把手头材料按方案、动作表、培训、评价工具四类摆开，缺哪类先补哪类，别急着排版
2. 写方案文本：适用人群、纳入排除、干预流程、时点、结局与测量，一页能读完，不写研究背景
3. 整理动作表：逐动作标准、用时、判定合格的方式，排版成可直接打印上墙的样式，字号要能在走廊看清
4. 整理核查表：与动作表一一对应，字段留空可手写，附一页填写示例，含填错与漏填的对照样例
5. 做培训材料：讲义提纲、示范要点、常见错误、五道考核题与参考答案，一堂课能讲完
6. 附评价工具：量表全文、计分说明、授权证明、数据提取字段表，缺授权就换工具
7. 写禁忌与红线：哪些患者不能用、出现什么情况必须停、向谁报告、如何记录，写到值班护士敢照做
8. 写偏差处理：漏做一次怎么补、家属代做怎么记、代班时如何交接，逐条给做法而不是原则
9. 写前提：每班人力配比、耗材清单与单例用量、场地与设备、信息系统需新增的字段，逐项给数字
10. 执行验证：找一位未参与研究的护士，按包独立执行一例，全程不提示、不代做、不现场解释
11. 记偏差：验证者卡在哪、理解错哪、多花了多少时间，逐条记下并回改方案包，改完记版本
12. 签收归档：护士长签收，方案包与论文、原始数据同目录，命名按科室约定，换版保留旧版与修订说明

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 四类材料齐全，缺项已补齐
- [ ] 方案文本含适用人群与排除标准
- [ ] 动作表可直接打印上墙
- [ ] 核查表附填写示例与错填对照
- [ ] 培训材料含讲义、示范与五道考核题
- [ ] 评价工具含量表、计分与授权证明
- [ ] 禁忌、停用指征与报告路径已写
- [ ] 漏做、代做、代班的处理均有做法
- [ ] 人力、耗材、场地、信息字段已给数字
- [ ] 未参与研究的护士独立执行一例
- [ ] 验证偏差逐条记下并回改方案包
- [ ] 护士长签收，换版保留旧版与说明

## H.5 模板：护理方案移交清单

| 字段 | 填写要求 |
|------|----------|
| 包内容 | 方案文本、动作表、核查表、培训材料 |
| 适用与禁忌 | 人群、病情、停用指征 |
| 执行流程 | 班次、时点、每步用时 |
| 培训与考核 | 讲义、示范、五道题、合格线 |
| 评价工具 | 量表、计分、授权、提取字段 |
| 偏差处理 | 漏做、代做、代班的处理办法与报告对象 |
| 前提条件 | 人力配比、耗材、场地、信息字段及缺口 |
| 执行验证 | 执行人、完成情况、偏差清单 |
| 签收 | 移交人、护士长、日期、版本 |

> 本表是本章的交付物：结题时随论文提交，护士长签收后入科室文档库；换版须保留旧版与修订说明，接手人执行前先读这一页。

## H.6 常见失效与处置

- **只交论文** → 接手人只有结论没有做法，方案停在纸上，下一届重做一遍
- **缺培训材料** → 换人执行就走样，效果无法复制，也说不清差在哪一步
- **核查表没示例** → 各人填法不同，数据无法汇总，等于白收一叠纸
- **不写前提** → 人力不足时方案不可行，却无人知晓，执行到一半崩
- **验证找熟人** → 不好意思挑错，偏差一条也记不出来，验证成了走过场
- **不写数据归属** → 后续使用与发表易起争议，交接在法律上不算完成

## H.7 中期检查与答辩要点

- 方案包完整可打印（35%）
- 培训与考核可用（20%）
- 执行验证与偏差回改（25%）
- 前提与签收（20%）
