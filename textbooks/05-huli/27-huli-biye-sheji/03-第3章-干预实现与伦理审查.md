## H.1 本章要解决的问题

护理干预的实施者是人，最容易出现「同一个人对两组做法不同」。本章要求把干预做成可核查的动作表。

## H.2 本章目标（可检验）

- 把干预拆成可核查动作并培训执行者
- 完成伦理审批与知情同意
- 记录干预依从性与偏离

## H.3 操作流程

1. 拆动作：每次干预包含哪几个动作、每个动作的标准
2. 培训：执行者培训并考核一次
3. 伦理：提交审查，取得批件号
4. 同意：知情同意签署并留档
5. 记录：每次干预的完成情况与偏离原因

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 干预动作表已完成
- [ ] 执行者培训与考核已做
- [ ] 伦理批件号已记
- [ ] 知情同意已签署留档
- [ ] 每次干预有完成记录
- [ ] 偏离原因已记录
- [ ] 隐私与数据保存已说明

## H.5 模板：干预实施核查表

| 字段 | 填写要求 |
|------|----------|
| 动作表 | 逐动作标准 |
| 培训 | 人员、考核结果 |
| 伦理 | 批件号与日期 |
| 同意 | 签署与留档位置 |
| 偏离 | 次数与原因 |

> 本表是本章的交付物：每次干预一张，随机抽查 10%。

## H.6 常见失效与处置

- **干预靠口头传达** → 执行不一致会导致两组污染
- **伦理后补** → 属重大违规；必须批准后再入组
- **不记偏离** → 依从性无法报告

## H.7 中期检查与答辩要点

- 动作表可核查（40%）
- 伦理与同意（一票否决项）
- 依从性记录（30%）
