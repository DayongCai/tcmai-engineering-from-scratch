## H.1 本章要解决的问题

护理干预的执行者是人，最容易出现「同一个人对两组做法不同」：白班做得细、夜班图省事，家属代做、代班顶替，最后两组互相学到对方的做法，效果说不清。本章要求把干预做成可核查的动作表：每个动作有标准与用时，每个执行者有培训与考核，每次干预有完成记录，每次偏离有原因与影响。伦理不是最后补的一张纸，批件与知情同意必须在第一例入组之前完成，顺序颠倒，数据再好也不能用。

## H.2 本章目标（可检验）

- 把干预拆成逐条动作与判定标准，写成可打印、可上墙的操作手册
- 完成执行者培训与考核，未通过者不参与入组
- 取得伦理批件与逐例知情同意后再启动入组
- 建立依从性监测与偏离记录，能按人按周算出实际执行率

## H.3 操作流程

1. 写手册：按时间顺序列每次干预的动作、标准、预计用时、常见错误与纠正办法，一页写一个动作，不写抽象原则
2. 配工具：图示、示范视频、患者版说明，工具上标手册版本号，改手册必同步改工具，旧版收回
3. 定人选：固定执行者名单，写明资质与排班要求，避免一人多岗频繁换手，换人须重新考核
4. 做培训：一次集中讲手册，一次床旁示范，两次都签到留档，缺席者单独补训后才可参与
5. 考核：情景演练加口头提问，逐人判定合格与否，记录不合格项与补考结果，未过者不进组
6. 预试验：在 3 至 5 例非入组患者身上完整跑一遍，记录卡壳、超时与理解偏差，据此改第二版手册
7. 备伦理材料：研究方案、知情同意书、病例报告表、执行者资质、量表授权证明，缺件会被退回重排
8. 送审与批件：按机构流程提交，取得批件号与批准日期后再启动入组，修正案同样先批后做
9. 知情同意：讲清目的、分组方式、可能的收益与不便、可随时退出、隐私如何保护，逐例签署并留一份给患者
10. 逐例核查：每次干预后填核查表，记动作完成情况、实际用时、患者反应与拒绝，当日填完不隔夜
11. 算依从：实际完成次数除以计划次数，按人、按周、按动作三个维度算，低于阈值当周查原因并补救
12. 控污染：同病房分组须说明隔离措施；发现交叉、代做、家属替代，当日记录并评估对结论的影响方向

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 操作手册逐动作写清标准、用时与纠正办法
- [ ] 手册与图示、视频标注同一版本号
- [ ] 执行者名单写明资质与排班要求
- [ ] 两次培训均有签到，缺席者已补训
- [ ] 考核逐人判定，未过者不进组
- [ ] 预试验 3 至 5 例完成并据此改版
- [ ] 伦理批件号、批准日期与修正案已记
- [ ] 知情同意逐例签署，患者留存一份
- [ ] 每次干预有核查表且当日填完
- [ ] 依从率按人、按周、按动作计算
- [ ] 偏离与污染当日记录并评估影响
- [ ] 低依从当周查原因并补救

## H.5 模板：干预实施核查表

| 字段 | 填写要求 |
|------|----------|
| 手册版本 | 版本号、生效日期、本次修订要点 |
| 动作清单 | 动作、标准、预计用时 |
| 执行者 | 姓名、资质、培训日期、考核结果 |
| 伦理 | 批件号、批准日期、修正案记录 |
| 知情同意 | 签署日期、留档位置、退出情况 |
| 单次记录 | 日期、班次、动作完成情况、实际用时 |
| 患者反应 | 耐受、拒绝、不适及处理 |
| 偏离 | 类型、原因、是否影响分组 |
| 依从率 | 实际次数、计划次数、按周汇总 |

> 本表是本章的交付物：每次干预一张，随病历车取用随填；每周由护士长抽查一成，签名后归入研究档案。

## H.6 常见失效与处置

- **干预靠口头交接** → 每人理解不同，两组做法各异，效果无法归因，也无法复现
- **先入组后送审** → 属重大违规，已收集数据可能整体作废，答辩前无法补救
- **培训不做考核** → 听过不等于会做，执行走样无人察觉，依从率虚高
- **同病房不隔离** → 对照组学到干预内容，组间差异被抹平，等于白做
- **核查表事后补填** → 记录变成回忆，依从率与偏离都不可信，抽查即穿
- **偏离不记录** → 低执行率被当成干预无效，可行方案被错杀，结论反向

## H.7 中期检查与答辩要点

- 动作表可核查（35%）
- 伦理与知情同意（15%，一票否决项）
- 培训与考核（20%）
- 依从性与偏离记录（30%）
