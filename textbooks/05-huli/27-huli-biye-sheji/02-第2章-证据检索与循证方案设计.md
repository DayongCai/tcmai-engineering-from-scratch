## H.1 本章要解决的问题

循证设计最容易被跳过的一步是「查过什么」。没有检索日志，方案就成了拍脑袋：为什么选这个频次、为什么不加那个环节、为什么用这个量表，答辩时只能答「文献都这么做」。可复现的检索要留下库名、完整检索式、检索日期与每一条排除理由。检索记录同时是方案取舍的依据：哪条措施证据强、哪条只是习惯做法，写清楚了，后面干预做不走样才有底气。

## H.2 本章目标（可检验）

- 完成一次可复现的检索：库名、检索式、日期、命中数全部留痕
- 用证据分级说明每条关键措施的依据强弱，而不是笼统说「有文献支持」
- 写出方案的取舍：采用了什么、改动了什么、舍弃了什么、各自理由
- 说明方案与本科室人力、耗材、场地、信息系统的匹配程度

## H.3 操作流程

1. 定问题：把开题命题改写成 PICO，P 写到病种与病情程度，O 写到量表与分级界值，T 写观察时长，不停在「患者」
2. 拆词：每个要素列主题词、自由词、同义词与英文对应词，护理措施先拆到具体动作再逐动作找词
3. 选库：中文用知网、万方、维普，外文用 PubMed、CINAHL、Cochrane Library，指南与学会共识另行检索
4. 组式：同要素内用 OR 并联，要素之间用 AND，按需加字段限定、语种与时间范围，每次改动都记下来
5. 预检索：先用两三组式试跑，看命中量级是否可人工筛，过宽加限定、过窄去限定，试跑式同样留档
6. 留痕：建检索日志，逐条记库名、完整检索式、检索日期、命中数、限定条件，一行写定不再改写
7. 去重与初筛：按题录筛，读标题摘要，逐条记排除理由（人群不符、非干预性、无目标结局），不写「不相关」
8. 读全文：按事先写定的纳排标准定稿，记纳入篇数与排除原因，画一张从识别到纳入的筛选流程图
9. 评质量：原始研究按对应工具评（随机对照、类实验、质性研究各有清单），综述只作线索不作证据
10. 汇总：做证据表，列结论、证据等级、适用人群、与本研究人群的差异，差异大者降级使用并在方案里说明
11. 对条件：逐条比对本科室人力配比、耗材供应、场地与信息系统能否支撑该措施，撑不住就换成能落地的做法
12. 定方案：写明采用哪几条、改动哪几条、舍弃哪几条，每条给理由与本地替代，交导师过一遍再定稿

## H.5 模板：循证检索与方案表

| 字段 | 填写要求 |
|------|----------|
| PICO | 人群病种、干预动作、对照、结局量表、时长 |
| 检索词 | 主题词、自由词、同义词、英文对应 |
| 检索式 | 完整布尔式，可原样复制重跑 |
| 库与日期 | 库名、检索日期、限定条件、命中数 |
| 筛选 | 题录筛与全文筛的纳入数、排除理由 |
| 质量评价 | 研究类型、评价工具、主要偏倚 |
| 证据汇总 | 结论、证据等级、适用人群、人群差异 |
| 方案取舍 | 采用、改动、舍弃及各自理由 |
| 条件匹配 | 人力、耗材、场地、信息系统 |

> 本表是本章的交付物：论文方法章首页附检索日志，方案表与日志同页编号；换检索式须新增一行，不覆盖旧记录。

## H.6 常见失效与处置

- **只搜中文库** → 漏掉关键外文证据，方案依据单薄，也说不清与已有研究的差别
- **检索式不写全** → 只留关键词没有布尔式，别人无法复现，等于没有检索
- **把综述当原始研究** → 结论经二次转述，证据等级虚高，原始研究的对象与剂量全丢
- **证据等级随手标** → 不按工具逐条评，等级与结论不匹配，被问到评价条目就露
- **方案超出科室能力** → 要两人一组的措施排不出班，入组一周即停摆，只能中途缩方案
- **忽略患者接受度** → 措施依从性低，效果被稀释，却被归因于干预本身无效

## H.7 中期检查与答辩要点

- 检索可复现（35%）
- 证据质量与分级（30%）
- 方案取舍理由（20%）
- 与本院条件匹配（15%）
