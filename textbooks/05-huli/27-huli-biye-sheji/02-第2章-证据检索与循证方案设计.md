## H.1 本章要解决的问题

循证设计最常被跳过的一步是「查过什么、为什么选这个方案」。没有检索记录，方案就是拍脑袋。

## H.2 本章目标（可检验）

- 完成一次可复现的检索并留痕
- 用证据等级说明方案依据
- 写出方案的取舍理由

## H.3 操作流程

1. 定问题：按 PICO 写清人群、干预、对照、结局
2. 检索：数据库、检索式、时间范围、命中数全部记录
3. 筛读：按纳排筛选并记录排除理由
4. 评级：对纳入证据标注等级
5. 定方案：写明采用了什么、舍弃了什么及理由

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] PICO 四要素已写
- [ ] 检索式与命中数已记录
- [ ] 筛选过程与排除理由已记
- [ ] 证据等级已标
- [ ] 方案取舍理由已写
- [ ] 与本院条件匹配性已说明
- [ ] 参考文献写到篇名

## H.5 模板：循证检索与方案表

| 字段 | 填写要求 |
|------|----------|
| PICO | 人群、干预、对照、结局 |
| 检索 | 库、式、时间、命中 |
| 筛选 | 纳入与排除理由 |
| 证据等级 | 逐条标注 |
| 方案取舍 | 采用与舍弃 |

> 本表是本章的交付物：论文方法章首页。

## H.6 常见失效与处置

- **不记检索式** → 无法复现；检索式必须写
- **只引结论不看等级** → 低等级证据支撑强结论是常见错误
- **方案与本院条件脱节** → 人手与设备不支持则做不下去

## H.7 中期检查与答辩要点

- 检索可复现（40%）
- 证据分级（30%）
- 方案匹配（30%）
