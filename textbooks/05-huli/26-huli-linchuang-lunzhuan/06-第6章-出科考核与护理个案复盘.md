## H.1 本章要解决的问题

护理出科看的是「你能不能独立带一个病人」，不是做了多少项操作。

## H.2 本章目标（可检验）

- 提交一份完整的护理个案（含评估、措施、结局）
- 完成一次交接班演练
- 对一例护理不良事件写出复盘

## H.3 操作流程

1. 选例：挑一位全程跟护的患者
2. 写个案：评估、风险、措施、结局、反思
3. 演练：向带教做一次 SBAR 交接并接受追问
4. 复盘：挑一例不良事件或险情
5. 自评与改进计划

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 个案含评估—措施—结局三段
- [ ] 风险措施一一对应
- [ ] SBAR 交接演练完成
- [ ] 不良事件复盘四段完整
- [ ] 自评与带教分差异已说明
- [ ] 改进计划三条可执行
- [ ] 隐私已脱敏

## H.5 模板：护理个案与复盘表

| 字段 | 填写要求 |
|------|----------|
| 个案概况 | 诊断、病程、护理问题 |
| 评估与风险 | 六项评估 + 五类风险 |
| 措施与结局 | 逐条对应 |
| 不良事件复盘 | 发生—识别—处置—改进 |
| 改进计划 | 三条，含时间 |

> 本表是本章的交付物：出科提交，教学秘书归档。

## H.6 常见失效与处置

- **个案写成操作清单** → 要写判断与结局，不是做了什么
- **复盘回避自身环节** → 只写客观原因等于没复盘
- **交接演练不准备** → SBAR 四段说不全会被当场退回

## H.7 出科考核

- 个案完整性（40%）
- 复盘深度（30%）
- 交接演练（30%）
