# 第 6 章 · 出科考核与护理个案复盘

> **课程**：护理临床轮转（🩺 护理系 · 第 9 学期 · 108 学时 · 轮转/实践）
> **契约**：**操作型章（handbook-v1）** —— 本文件是工作手册，不是学术教材：给的是当场能执行的流程、清单与模板。
> **前置**：内科护理学、急危重症护理学、中医临床护理学

## H.1 本章要解决的问题

护理出科的证明不是「做过多少操作」，而是一个能讲完整的护理个案：你评估了什么、发现了什么风险、做了什么、结果如何、下一班接手需要知道什么。个案讲不清，说明评估是抄的、判断是别人的。

## H.2 本章目标（可检验）

- 完成一份护理个案报告（评估—问题—措施—结果—交接）
- 现场完成一项操作考核并通过安全问答
- 能说清自己在个案中「最早发现的那条异常」及其意义

## H.3 操作流程

1. 选例：优先选有风险转折的病例（趋势恶化、并发症早期、交接差点遗漏）
2. 资料整理：护理记录、评估分值、生命体征趋势、用药与操作记录，按时间排序
3. 护理问题提炼：按优先级列 3–5 条（生理安全优先），每条附证据（数值/评分）
4. 措施与依据：每条问题对应措施与依据（指南/院内规范/医嘱），写明执行时间
5. 结果评价：用同一指标对比（评分、数值、天数），无改善需分析原因
6. 交接设计：如果要把这个患者交给下一班，写 SBAR 四段，重点是三个待办与两个风险
7. 最早异常：找出自己最早注意到的一条异常，说明当时依据与后续验证
8. 现场操作：抽一项（如无菌操作/导管护理/艾灸）完成全流程，边做边说要点
9. 安全问答：本科五类风险（跌倒、压疮、给药、管路、感染）与处置步骤
10. 答辩：10 分钟讲个案，回答「如果重来一次你会先做什么」
11. 评分与反馈：按 H.7 五项打分，记录扣分点
12. 归档与提炼：个案、操作评分、答辩记录归档；写出三条可迁移规则带入下一科室

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 个案含评估、问题、措施、结果、交接五部分
- [ ] 每条护理问题附数值或评分证据
- [ ] 措施有依据并记执行时间
- [ ] 结果用同一指标对比
- [ ] SBAR 四段完整且含三个待办两个风险
- [ ] 最早异常及其意义已写清
- [ ] 现场操作全流程规范并说出要点
- [ ] 安全问答覆盖五类风险
- [ ] 答辩 10 分钟完成并回答「重来先做什么」
- [ ] 评分表五项已打分并记录扣分点
- [ ] 材料归档签收
- [ ] 三条可迁移规则已写

## H.5 模板：护理个案报告与出科评分表

| 字段 | 填写要求 |
|------|----------|
| 个案概况 | 诊断、入院时间、主要治疗 |
| 评估与证据 | 风险评分、生命体征趋势、关键检验 |
| 护理问题 | 3–5 条，按优先级排序，附证据 |
| 措施与依据 | 措施、依据来源、执行时间 |
| 结果评价 | 同一指标前后对比、无改善的原因分析 |
| 交接设计 | SBAR 四段、三个待办、两个风险 |
| 最早异常 | 发现时点、依据、后续验证 |
| 现场操作评分 | 流程规范、无菌观念、沟通、要点陈述 |
| 安全问答（一票否决） | 五类风险与处置，答错关键项即不通过 |
| 答辩与规则 | 10 分钟陈述、追问回答、三条可迁移规则 |

> 本表是本章的交付物：个案按左栏结构成文；答辩现场用右栏评分，两份一并归档。

## H.6 常见失效与处置

- **个案写成操作流水** → 没有评估与判断，无法体现护理思维
- **护理问题无证据** → 「有跌倒风险」不给分值，属空话
- **结果评价换指标** → 前后指标不一致，等于没有评价
- **交接只说现状** → 下一班不知道要做什么，个案不完整
- **说不出最早异常** → 说明观察是被动的，靠别人提醒
- **操作快而漏核对** → 安全问答与核对环节是一票否决项

## H.7 出科考核

- 个案完整度与证据链（30%）
- 护理问题与措施匹配（25%）
- 交接设计与最早异常（20%）
- 现场操作（25%）
- 安全问答（一票否决）
