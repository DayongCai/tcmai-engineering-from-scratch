## H.1 本章要解决的问题

妇儿的风险判断依赖「与成人不同」的正常值：产妇出血量、新生儿黄疸、儿童液体量，任何按成人标准都会错。

## H.2 本章目标（可检验）

- 能使用妇儿专用评估标准
- 能识别产后出血与新生儿异常
- 能与家属完成安全宣教

## H.3 操作流程

1. 产科：宫缩、出血量、会阴伤口、乳房、子宫复旧
2. 新生儿：体温、黄疸、喂养、排泄、反应
3. 儿科：体重折算液体量、脱水评估、体温管理
4. 宣教：母乳喂养、安全睡眠、复诊指征
5. 记录：用专用表格而非成人表

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 产后出血量已估算并记录
- [ ] 子宫复旧与会阴伤口已查
- [ ] 新生儿黄疸与喂养已记
- [ ] 儿科液体量按体重计算
- [ ] 脱水评估已做
- [ ] 家属宣教要点已复述
- [ ] 复诊指征已交代

## H.5 模板：妇儿护理记录表

| 字段 | 填写要求 |
|------|----------|
| 母亲/患儿基本情况 | 分娩方式或年龄体重 |
| 关键指标 | 出血量/黄疸/体温/体重 |
| 喂养与排泄 | 次数、量、性状 |
| 宣教 | 要点与复述 |
| 复诊指征 | 何时必须返院 |

> 本表是本章的交付物：产科与儿科各一版，字段不同。

## H.6 常见失效与处置

- **出血量凭印象** → 须用称重法或容积法估算
- **新生儿黄疸靠肉眼** → 须经皮或血清胆红素
- **儿科按成人量补液** → 按体重折算，否则过量或不足

## H.7 出科考核

- 专用标准使用（40%）
- 关键指标记录（30%）
- 家属宣教（30%）
