## H.1 本章要解决的问题

妇儿护理的难点在于「两个病人」：孕产妇要同时评估母亲与胎儿，儿童则要用年龄对应的正常值与沟通方式。用成人标准衡量儿童、用「看着还行」判断胎心，是这一科最常见的两类错误。轮转要把年龄分层与双人评估变成习惯动作。

## H.2 本章目标（可检验）

- 按年龄分层使用儿童生命体征正常值与评估工具（含疼痛与脱水评估）
- 完成孕产妇的母婴双评估：血压、水肿、蛋白尿、胎心/胎动、宫缩与出血
- 能识别产科与儿科急症征象并按流程上报（含时限）

## H.3 操作流程

1. 对象确认与年龄分层：婴幼儿/学龄前/学龄期/青春期；孕妇记孕周与产次
2. 儿童生命体征：按年龄对照正常范围（心率、呼吸、血压），记录实测值与参考区间；体温测量方式写明（腋温/耳温/口温）
3. 儿童评估工具：疼痛（面部表情量表/数字量表按年龄选）、脱水（精神、眼泪、口唇、尿量、皮肤弹性）、意识（AVPU 或儿科格拉斯哥）
4. 用药安全：按体重计算剂量并双人核对；输液速度与微量泵参数记录；高危药标识
5. 孕产妇评估：血压（与基础值对比）、水肿（部位与程度）、尿蛋白、体重增长、胎心（110–160 次/分，记录听诊时间与位置）、胎动计数
6. 产科警示：头痛视物模糊、上腹不适、血压 ≥140/90、阴道流血、破水、胎动减少、规律宫缩（记间隔与持续）
7. 新生儿与婴儿护理：保暖、喂养（量/次/方式）、黄疸观察（部位与范围）、脐部、大小便次数与性状
8. 家长沟通与宣教：喂养、体温测量、危险征象（不吃、不动、体温异常、呼吸急促、抽搐）——请家长复述三条
9. 心理与隐私：孕产妇隐私保护、儿童配合技巧（游戏化、告知—同意—操作）、家长在场安排
10. 记录：按 H.5 模板填「妇儿护理评估表」，母婴双栏分开写，儿童数值附年龄对应区间
11. 上报与转运：出现产科或儿科急症征象，按流程呼叫并记录时间（发现—呼叫—到场—处置）
12. 复盘：挑一例「成人标准差点误判儿童指标」的案例，写清正确阈值与依据

## H.5 模板：妇儿护理评估表（母婴双栏）

| 字段 | 填写要求 |
|------|----------|
| 对象与分层 | 年龄/孕周/产次、体重 |
| 生命体征 | 实测值 + 年龄对应区间 + 测量方式 |
| 评估工具 | 疼痛、脱水、意识所用工具与分值 |
| 用药 | 按体重计算过程、双人核对签名、泵参数 |
| 产科观察 | 血压、水肿、尿蛋白、胎心、胎动、宫缩、出血 |
| 新生儿观察 | 喂养量、黄疸部位、脐部、大小便次数与性状 |
| 警示筛查 | 产科六项 / 儿科危险征象，逐条有/无 |
| 沟通与宣教 | 家长复述的三条内容 |
| 上报 | 发现—呼叫—到场—处置四个时间点 |
| 签名 | 责任护士、复核人、时间 |

> 本表是本章的交付物：孕产妇与新生儿各一栏，同时填写；儿科患者单栏填，数值旁标年龄区间。

## H.6 常见失效与处置

- **用成人正常值判断儿童** → 心率 130 在婴儿可为正常，在学龄儿即为异常；必须按年龄对照
- **胎心只听不记时间** → 胎心异常需结合宫缩与时间判断，缺时间无法复盘
- **儿童用药按成人剂量减半** → 必须按体重计算，且双人核对
- **脱水只看口唇** → 需五项综合（精神、眼泪、口唇、尿量、皮肤弹性）
- **家长宣教只发材料** → 不复述等于没宣教；危险征象必须听到家长说出来
- **隐私保护不到位** → 孕产妇与青春期患者尤需注意，属基本职业要求

## H.7 出科考核

- 年龄分层与正常值使用（一票否决：用成人标准判断儿童即不通过）
- 母婴双评估完整度（30%）
- 用药安全与计算（20%）
- 警示筛查与上报（20%）
- 沟通宣教与复盘（15%）
