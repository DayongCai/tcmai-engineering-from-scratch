## H.1 本章要解决的问题

内科护理最常见的失守是「记录齐全但风险没传下去」：接班护士不知道该先看谁。

## H.2 本章目标（可检验）

- 能完成入院护理评估并分级
- 能识别本班三类高风险患者
- 能写出一份可执行的交接班记录

## H.3 操作流程

1. 评估：生命体征、意识、活动能力、皮肤、进食与排泄、管路
2. 分级：按自理能力与风险分为三级
3. 列风险：跌倒、压疮、误吸、管路滑脱、用药风险各评一次
4. 定措施：每条风险对应一条具体措施
5. 交接：按 SBAR 写清现状、背景、评估、建议

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 六项评估已完成
- [ ] 护理分级已给出
- [ ] 五类风险各评一次
- [ ] 每条风险有对应措施
- [ ] SBAR 四段齐全
- [ ] 高危患者已口头交接
- [ ] 患者与家属宣教已记录

## H.5 模板：内科护理评估与交接表

| 字段 | 填写要求 |
|------|----------|
| 六项评估 | 生命体征、意识、活动、皮肤、进食排泄、管路 |
| 分级 | 三级之一 + 依据 |
| 风险 | 跌倒/压疮/误吸/滑脱/用药 |
| 措施 | 逐条对应 |
| SBAR 交接 | 现状、背景、评估、建议 |

> 本表是本章的交付物：每班一张，危重患者加页。

## H.6 常见失效与处置

- **记录全但无优先级** → 接班者不知道先看谁；须标高危
- **风险只打勾不写措施** → 打勾不等于落实
- **交接只报数值** → 缺背景与建议，等于把判断留给下一班

## H.7 出科考核

- 评估完整度（40%）
- 风险与措施对应（30%）
- SBAR 交接质量（30%）
