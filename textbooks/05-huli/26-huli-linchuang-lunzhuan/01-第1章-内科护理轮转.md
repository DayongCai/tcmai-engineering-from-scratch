## H.1 本章要解决的问题

内科病房的护理风险是「慢慢变坏」：血压一点点下降、尿量一点点减少、意识一点点淡漠，每一班都觉得「还行」，等到下一班发现时往往已经晚了。轮转要建立的是趋势意识——把数值按时间排成一条线，而不是只看当次是否在参考范围内。

## H.2 本章目标（可检验）

- 独立完成一次系统护理评估：生命体征、意识、出入量、皮肤、活动能力、跌倒与压疮风险评分
- 能识别「趋势性恶化」并按要求上报（含上报对象与时限）
- 用 SBAR 完成一次交接，使接班护士能复述三个待办

## H.3 操作流程

1. 接班与核对：核对患者身份（双标识）、诊断、过敏史、管路与用药；与上一班共同查看重点患者
2. 生命体征与趋势：记录体温、脉搏、呼吸、血压、指脉氧；与前三班对比，标出变化幅度（如收缩压较前下降 >20 mmHg）
3. 出入量与体重：精确记录 24 小时出入量；水肿或心衰患者记每日体重（同条件同时刻）
4. 风险评估：跌倒（Morse 类）、压疮（Braden 类）、营养、吞咽、静脉血栓、疼痛（0–10 分）——每项记分值并采取对应措施
5. 用药核对：口服药、静脉药、高危药（胰岛素、抗凝、高浓度电解质）双人核对并签名
6. 专科观察：按病种写观察要点（如心衰看夜间能否平卧、慢阻肺看痰色与呼吸做功、糖尿病看足部与血糖曲线）
7. 管路与皮肤：管路名称、置入日期、固定与通畅、引流液性质量；皮肤受压部位逐处查看并记录
8. 异常处置：出现趋势性恶化（意识改变、尿量 <0.5 ml/kg/h 持续 2 小时、SpO₂ 下降、血压下降）立即上报并按流程处理
9. 记录：按 H.5 模板填「内科护理评估与交接表」，数值写实数，不写「正常」「尚可」
10. SBAR 交接：现状（Situation）—背景（Background）—评估（Assessment）—建议（Recommendation），每项不超过三句
11. 交接确认：请接班护士复述三个待办与两个风险点，确认后签名
12. 班后复盘：挑一个「我原本以为稳定、实际在恶化」的病例，写清哪条趋势线最早提示了变化

- [ ] 六项风险评估均有分值

## H.5 模板：内科护理评估与交接表（SBAR）

| 字段 | 填写要求 |
|------|----------|
| S 现状 | 床号、诊断、当前主诉与关键数值 |
| B 背景 | 入院时间、主要治疗、管路与用药 |
| A 评估 | 六项风险分值、趋势变化、当前最担心的问题 |
| R 建议 | 本班已做、下一班必须做的三件事 |
| 生命体征趋势 | 前三班数值与变化幅度 |
| 出入量与体重 | 24 小时出入量、体重曲线 |
| 风险评分 | 跌倒、压疮、营养、吞咽、血栓、疼痛 |
| 管路与皮肤 | 管路清单、置入日期、皮肤受压部位 |
| 上报记录 | 上报对象、时间、内容、回复 |
| 复述确认 | 接班护士复述要点、双方签名 |

> 本表是本章的交付物：每班一张，交接前填完；接班护士复述确认后双方签名。

## H.6 常见失效与处置

- **只看当次数值是否在范围内** → 趋势比单点更重要；下降幅度必须算出来
- **记录写「生命体征平稳」** → 无实数无法比较，也无法在纠纷中自证
- **风险评分只打分不落实措施** → 评分是起点，措施才是护理行为
- **交接只讲现状不讲建议** → 接班护士不知道要做什么，等于没交接
- **高危药单人核对** → 胰岛素与抗凝药差错代价高，必须双人
- **趋势恶化等交班再说** → 应在发现时立即上报，交班不是上报渠道

## H.7 出科考核

- 评估完整度与数值化（30%）
- 风险识别与上报（一票否决：漏报趋势性恶化即不通过）
- SBAR 交接质量（25%）
- 记录规范（20%）
- 复盘质量（15%）
