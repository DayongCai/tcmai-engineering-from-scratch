## H.1 本章要解决的问题

外科护理的时间轴很清楚：术前准备做没做到位，决定手术能不能按时开；术后 24 小时观察做没做到位，决定并发症能不能早发现。两类问题都不靠「经验感觉」，靠的是清单与数值：禁食时间、备皮范围、管路标识、引流量、疼痛评分、首次下床时间。

## H.2 本章目标（可检验）

- 独立完成术前准备清单核对，确保八项无遗漏
- 术后按时间点完成观察（0–2h、2–6h、6–24h），记录引流量、尿量、疼痛与活动
- 识别术后四类常见并发症的早期征象并上报

## H.3 操作流程

1. 术前核对：身份、手术部位与侧别标记、术式、麻醉方式、过敏史、知情同意、备血、禁食禁饮时间（清饮与固体分别记）
2. 术前准备：备皮范围与皮肤完整性、肠道准备（如需要）、预防性用药执行时间、义齿与饰品摘除、管路与标识
3. 术前宣教：呼吸训练、咳嗽排痰方法、早期活动意义、疼痛报告方式；请患者复述两项
4. 接手术交接：与手术室核对身份、部位、带药带片、管路；记录交接时间与双方签名
5. 术后返室即刻（0–2 小时）：意识与气道、生命体征每 15–30 分钟一次、伤口敷料渗血、引流管通畅与量色、尿量、疼痛评分
6. 术后 2–6 小时：体位与翻身、早期活动（按医嘱）、肺部听诊与咳痰、恶心呕吐、首次饮水或进食
7. 术后 6–24 小时：引流量趋势、体温、切口周围红肿、下肢肿胀与疼痛（血栓线索）、首次下床活动与跌倒防护
8. 四类并发症监测：出血（引流量骤增、血压下降、心率增快）、感染（体温、切口红肿热痛、脓性分泌物）、深静脉血栓（单侧肿胀、疼痛、皮温）、肺不张与肺部感染（呼吸浅快、痰不易咳出、SpO₂ 下降）
9. 疼痛管理：评分（0–10）、给药时间与效果复评（给药后 30–60 分钟）、非药物措施
10. 管路护理：标识、固定、通畅、引流液性质与量、更换时点；拔管条件按医嘱
11. 记录：按 H.5 模板填「外科围手术期护理记录表」，引流量与尿量写实数并成趋势
12. 复盘：挑一例「引流量变化最早提示出血」的病例，写清观察时点与判断依据

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 术前八项核对无遗漏（身份、部位侧别、术式、过敏、同意书、备血、禁食、用药）
- [ ] 禁食禁饮时间分别记录（清饮/固体）
- [ ] 备皮范围与皮肤完整性已记录
- [ ] 术前宣教请患者复述两项
- [ ] 手术室交接双方签名并记时间
- [ ] 术后 0–2 小时生命体征按频次记录
- [ ] 引流量、尿量、疼痛评分均写实数

## H.5 模板：外科围手术期护理记录表

| 字段 | 填写要求 |
|------|----------|
| 术前核对 | 八项逐项打勾，禁食时间为清饮/固体分别记 |
| 备皮与皮肤 | 范围、皮肤完整性、异常 |
| 宣教与复述 | 训练项目、患者复述内容 |
| 手术室交接 | 时间、带药带片、管路、双方签名 |
| 0–2h 观察 | 意识气道、生命体征频次、敷料、引流、尿量、疼痛 |
| 2–6h 观察 | 体位、活动、肺部、恶心呕吐、进食 |
| 6–24h 观察 | 引流量趋势、体温、切口、下肢、首次下床 |
| 并发症监测 | 出血/感染/血栓/肺不张，逐项结论 |
| 疼痛管理 | 评分、给药时间、复评结果 |
| 管路 | 名称、标识、固定、引流量与性质、拔管条件 |

> 本表是本章的交付物：术前一张、术后按时间点续填；随病历归档，交接时对照使用。

## H.6 常见失效与处置

- **禁食时间记成「已禁食」** → 清饮与固体要求不同；时间未记等于没核对
- **术后只看单次引流量** → 出血看趋势；骤增或持续增多都要立即上报
- **疼痛评分记了不复评** → 给药后无复评，无法判断是否有效
- **早期活动无防护** → 首次下床是跌倒高发点，须有人陪护与评估
- **切口只看敷料外面** → 渗血可能积在敷料下；需按医嘱查看与记录
- **交接不带管路清单** → 管路遗漏是外科交接最常见的事故来源

## H.7 出科考核

- 术前核对与准备（30%）
- 术后观察的时间点与数值（一票否决：漏观察时间点即不通过）
- 并发症识别与上报（25%）
- 疼痛与管路管理（20%）
- 记录与复盘（15%）
