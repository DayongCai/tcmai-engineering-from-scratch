## H.1 本章要解决的问题

外科护理的窗口期很短：术前准备漏一项、术后观察慢一步，都会变成并发症。

## H.2 本章目标（可检验）

- 能完成术前准备核对
- 能按时间点完成术后观察
- 能识别切口与引流的异常

## H.3 操作流程

1. 术前：核对身份、禁食、皮肤准备、备血、宣教、知情同意
2. 术后：按 15/30/60 分钟节点记录生命体征
3. 看切口：渗血、渗液、红肿、裂开
4. 看引流：量、色、性状、通畅
5. 报告：异常即刻报告并记录时间

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 术前六项核对完成
- [ ] 禁食与用药停用已确认
- [ ] 术后生命体征按节点记录
- [ ] 切口情况每班描述
- [ ] 引流量色性状已记
- [ ] 异常上报时间已记
- [ ] 镇痛与活动宣教已做

## H.5 模板：围手术期护理核对表

| 字段 | 填写要求 |
|------|----------|
| 术前核对 | 身份、禁食、皮肤、备血、宣教、同意 |
| 术后观察 | 时间点与生命体征 |
| 切口 | 渗血渗液红肿裂开 |
| 引流 | 量、色、性状、通畅 |
| 异常与上报 | 内容、时间、接收人 |

> 本表是本章的交付物：每例手术患者一张。

## H.6 常见失效与处置

- **术前核对凭记忆** → 漏项高发；按表逐项签
- **术后只看血压** → 切口与引流异常常先于生命体征变化
- **异常不记时间** → 责任与处置链说不清

## H.7 出科考核

- 术前核对（一票否决项）
- 术后观察记录（40%）
- 异常上报（30%）
