## H.1 本章要解决的问题

中医护理技术（艾灸、拔罐、耳穴压豆、穴位贴敷、中药熏洗、刮痧）在病房里最容易变成「医嘱写了就做」，而适应证、禁忌与皮肤反应没人核。轮转要建立三道关：辨证对不对、禁忌筛没筛、反应记没记。三道关任何一道缺失，都不应执行。

## H.2 本章目标（可检验）

- 按辨证结果选择技术并说明依据（证—法—穴/部位—参数）
- 独立完成五项常见技术的禁忌筛查与操作，全程记录皮肤反应
- 能识别并处置四类不良反应（烫伤、水泡、过敏、晕厥）

## H.3 操作流程

1. 医嘱与辨证核对：医嘱技术名称、部位、频次；核对护理记录中的证候描述，证与技术不匹配时先与医师沟通并留痕
2. 禁忌筛查：皮肤破损与感染、感觉障碍（糖尿病足）、凝血异常与抗凝、严重心肺疾病、妊娠腰骶腹部、发热与出血倾向、空腹或极度疲劳、瘢痕体质
3. 环境与器材：通风排烟、灭火器具、罐具完整性、艾条质量、贴敷药物有效期
4. 体位与暴露：体位稳定、暴露适度、保暖与隐私、床档保护
5. 艾灸：距离 3 cm 左右温和灸，每穴 10–15 分钟，随时弹灰，以温热不灼痛为度
6. 拔罐：罐具与部位匹配、吸附力度以耐受为度、留罐 5–10 分钟（不超 15 分钟）、观察罐内皮肤
7. 耳穴压豆：选穴依据、按压方法与频次、留豆天数、脱落与皮肤反应处理
8. 穴位贴敷与熏洗：药物组成与浓度、时间（一般 ≤30 分钟）、温度（熏洗不超过 40℃ 或以患者耐受为度）、皮肤反应观察
9. 刮痧：介质、方向与力度、出痧程度、间隔时间（待痧退再行）
10. 反应记录：皮肤颜色、温度、有无水泡破损、患者主观感受；出现异常立即停止并按流程处置
11. 不良反应处置：烫伤（移除热源、冷水冲 15–20 分钟、覆盖、按需转诊）、水泡（小不刺破、大无菌抽液）、过敏（停药、清洗、上报）、晕厥（平卧、抬高下肢、测生命体征、呼叫）
12. 记录与交代：按 H.5 模板填「中医护理技术操作记录表」；交代当日注意事项（不洗冷水、避免受凉、皮肤保护）

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 医嘱与证候描述已核对，不一致已沟通留痕
- [ ] 禁忌九项已逐条筛
- [ ] 通风与灭火器具、罐具与艾条质量已检查
- [ ] 体位、暴露、保暖与隐私已落实
- [ ] 艾灸距离与每穴时长已记录
- [ ] 拔罐留罐时长未超 15 分钟
- [ ] 耳穴选穴依据、按压频次、留豆天数已记
- [ ] 贴敷/熏洗的时间与温度已记
- [ ] 皮肤反应（颜色/温度/水泡）已记录
- [ ] 四类不良反应处置流程已掌握
- [ ] 当日注意事项已交代并复述
- [ ] 操作人与时间签名齐全

## H.5 模板：中医护理技术操作记录表

| 字段 | 填写要求 |
|------|----------|
| 医嘱与辨证 | 技术名称、部位、频次；护理记录中的证候 |
| 禁忌筛查 | 九项逐条有/无与依据 |
| 环境器材 | 通风、灭火器具、罐具/艾条/药物检查 |
| 操作参数 | 距离或吸附力度、时长、温度、选穴与依据 |
| 皮肤反应 | 颜色、温度、水泡、破损、患者感受 |
| 不良反应处置 | 类型、处置步骤、是否上报与转诊 |
| 交代 | 当日注意事项、复述确认 |
| 签名 | 操作人、复核人、时间 |

> 本表是本章的交付物：每次操作一张；同一患者连续操作可续页，皮肤反应栏每次必填。

## H.6 常见失效与处置

- **医嘱写了就做，不核辨证** → 证与技术不符会加重症状；核对是护理的第一道关
- **不筛感觉障碍与抗凝** → 糖尿病足与抗凝患者烫伤、出血风险高
- **留罐超 15 分钟** → 水泡率显著升高；时间必须记在表上
- **熏洗温度凭手感** → 应以温度计或明确判据控制，避免烫伤
- **反应只写「无不适」** → 缺具体皮肤描述，异常无法追溯
- **交代省略** → 患者洗冷水或抓挠导致皮肤破损，责任难辨

## H.7 出科考核

- 辨证核对与禁忌筛查（一票否决：漏筛禁忌即不通过）
- 操作参数与皮肤反应记录（30%）
- 不良反应处置（25%）
- 交代与复述（20%）
- 记录规范（15%）
