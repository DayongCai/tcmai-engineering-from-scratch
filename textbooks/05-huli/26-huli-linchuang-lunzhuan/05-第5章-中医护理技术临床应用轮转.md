## H.1 本章要解决的问题

中医护理技术（艾灸、拔罐、耳穴、穴位贴敷）在病房落地时，最大的问题是「谁都能做，但没人管适应证」。

## H.2 本章目标（可检验）

- 能按证型选择一项中医护理技术
- 能完成操作前评估与禁忌筛查
- 能记录操作参数与反应

## H.3 操作流程

1. 辨证：按四诊要点写出证型
2. 选术：技术—证型对应表里选一项
3. 筛禁忌：皮肤、感觉、凝血、妊娠、糖尿病
4. 操作：记录穴位/部位、时长、强度
5. 观察：局部与全身反应，异常即停

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 证型判断有依据
- [ ] 技术与证型对应
- [ ] 禁忌五项已筛
- [ ] 操作参数已记录
- [ ] 反应观察已写
- [ ] 患者宣教已复述
- [ ] 不良事件已上报

## H.5 模板：中医护理技术操作记录

| 字段 | 填写要求 |
|------|----------|
| 证型 | 四诊依据 |
| 技术 | 名称与选穴/部位 |
| 禁忌筛查 | 五项结论 |
| 参数 | 时长、强度、频次 |
| 反应 | 局部与全身，处置 |

> 本表是本章的交付物：每次操作一张，随护理记录归档。

## H.6 常见失效与处置

- **不辨证就选技术** → 同是失眠，虚实不同选术不同
- **糖尿病足部艾灸** → 感觉减退易烫伤；须筛禁忌
- **参数不记** → 疗效与不良反应都无法归因

## H.7 出科考核

- 辨证与技术匹配（40%）
- 禁忌筛查（一票否决项）
- 记录与观察（30%）
