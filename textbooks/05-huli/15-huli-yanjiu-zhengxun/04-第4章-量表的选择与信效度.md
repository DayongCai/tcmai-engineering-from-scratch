## 本章要回答的问题

「这个量表信效度好不好？」——这个问题问错了。正确的问题是：**你要用它做什么，它对你的用途是否可靠？**

同一份量表，用于**区分人群**（筛查）与用于**评估个体变化**（疗效评价），需要的测量属性不同。COSMIN 的做法是把「信效度」拆成**九项独立的测量属性**，逐项评级，而不是给一个总分。

## N.1 概念与出处

| 测量属性 | 依据 | 它在问什么 |
|---|---|---|
| 内容效度 | 外源·COSMIN 偏倚风险清单 第1条 | 条目是否覆盖了构念的全部方面（含专家与患者参与） |
| 结构效度 | 外源·COSMIN 偏倚风险清单 第2条 | 量表内部的维度结构是否成立（因子分析） |
| 内部一致性 | 外源·COSMIN 偏倚风险清单 第3条 | 同一维度内条目是否同向（α / ω） |
| 信度 | 外源·COSMIN 偏倚风险清单 第4条 | 重复测量的稳定性（ICC 等） |
| 测量误差 | 外源·COSMIN 偏倚风险清单 第5条 | 单次测量偏离真值多少（SEM、最小可检测变化） |
| 结构效度（假设检验） | 外源·COSMIN 偏倚风险清单 第6条 | 与其他量表的预期关系是否被证实 |
| 反应度 | 外源·COSMIN 偏倚风险清单 第7条 | 变化时能否测出变化（干预前后） |
| 暴露/结局测量的前提 | 外源·JBI 横断面研究核查表 第2条 | 测量是否 **valid and reliable** —— 两者都要 |
| 分析要匹配 | 外源·JBI 横断面研究核查表 第3条 | 统计分析是否恰当（含量表计分类型） |

**关键区别**：**内容效度与结构效度是「效度」**（测得对不对），**内部一致性、信度、测量误差是「可靠性」**（测得稳不稳）。一份量表可以很稳但测错（信度高、效度低），这正是两者必须分列的原因。

## N.2 为什么可以这样翻译：按用途选属性

```mermaid
flowchart TD
  A[要测量什么构念] --> B{用途}
  B -- 筛查/区分人群 --> C[重点看：内容效度 + 结构效度 + 灵敏度/特异度]
  B -- 评估个体变化 --> D[重点看：测量误差(SEM/MDC) + 反应度]
  B -- 群体均值比较 --> E[重点看：内部一致性 + 结构效度]
  C --> F{属性评级够不够}
  D --> F
  E --> F
  F -- 否 --> G[换量表 或 加测同一构念的另一量表]
  F -- 是 --> H[检查计分与统计匹配（第2章 C03）]
```

| 用途 | 该看的属性 | 依据 |
|---|---|---|
| 筛查 / 区分 | 内容效度、结构效度（含与他人量表的关系） | 第1条、第2条、第6条 |
| 个体变化 | 测量误差、反应度 | 第5条、第7条 |
| 群体均值 | 内部一致性、结构效度 | 第3条、第2条 |
| 任何用途 | valid **and** reliable 必须同时成立 | 外源·JBI 横断面研究核查表 第2条 |

**为什么「人群均值」不必苛求测量误差**：群体均值里个体误差会相互抵消；但个体评估不能抵消——同一个人的 SEM 会直接变成「他到底好转了没有」的判断误差。这就是同一量表在两种用途下「够用 / 不够用」的根源。

## N.3 这个翻译丢掉了什么

1. **不给阈值**。α 多少算够、ICC 多少算好、MDC 怎么算，COSMIN 清单只给评分档（very good / adequate / doubtful / inadequate），不给通用数值门槛。
2. **不给翻译与文化调适的流程**。跨文化效度（Box 5）在本库未取条文，量表汉化通常要先做翻译—回译与认知访谈。
3. **不给版权与授权规则**。多数量表需授权使用、按份计费，清单不涉及。
4. **不给「自编量表」的构建路径**。COSMIN 评的是已有量表的测量学研究，自编量表的条目生成、预调查、认知访谈要靠方法学专著。
5. **不给计分与统计的对应表**。李克特量表按序数还是等距处理，直接影响检验选择（第3条只要求「恰当」，不指定）。
6. **只评研究质量，不评量表优劣**。一份测量学研究做得很好、评级很高，也只说明「这项属性被可靠地研究过」，不等于该属性本身达标。

## N.5 争议与本项目立场

**争议一：α 能不能代表信度。** α 只反映内部一致性，不反映时间稳定性；高 α 也可能是条目重复（冗余）。本项目立场：**内部一致性与重测信度分列报告**，不合并成一句「信度良好」。

**争议二：一份量表通用到底可不可以。** 同一个构念（如「自我效能」）在不同人群常需要不同量表。本项目立场：**先看内容效度是否覆盖目标人群的构念边界**，再看数值属性；覆盖不足时，数值再好也不适配。

**争议三：自编量表能不能用。** 可以，但必须交底：条目来源、专家评审、预调查样本、认知访谈记录。本项目立场：**自编量表在论文里必须附带完整构建过程**，否则读者无法判断测的是不是它声称的东西。

**本项目立场**：量表章的产出不是「用了某某量表」，而是**一张属性—用途对照表**：这份量表测什么构念、本次用途是什么、该看哪几项属性、每项的评级与出处各是什么。四项齐，量表选择才算有据。

> **免责**：本章所列条文与判据不构成诊断或治疗建议；量表使用须遵守版权授权与计分规则，测量结果不构成个体诊断结论。

## 小结

1. 「信效度好不好」是错问题；正确问法是「对我的用途是否可靠」。
2. COSMIN 把测量属性拆成九项，逐项评级，不给总分。
3. 效度（内容、结构）与可靠性（内部一致性、信度、测量误差）必须分列。
4. 筛查看内容与结构效度；个体变化看测量误差与反应度；群体均值看内部一致性。
5. 「valid and reliable」是两条要求（JBI 第2条），缺一不可。
6. 清单评的是「研究做得如何」，不是「量表本身好不好」。

## 思考题

1. 你要用一份量表评估「出院后 30 天内的自理能力变化」，会重点看哪两项属性？为什么不是 α？
2. 一份量表 α=0.93、ICC=0.88，但你发现条目只覆盖「躯体」不覆盖「社会」。这属于哪一项属性不足？会影响什么结论？
3. 汉化量表未经跨文化调适直接使用，最可能在哪项属性上出问题？
4. 自编量表要交底的四件事，你会怎么写进论文的方法部分？
