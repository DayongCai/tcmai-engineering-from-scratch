## H.1 本章要解决的问题

毕设的最后一道题不是答辩，而是移交：下一届学生能不能接着你的数据做下去？实验室里最常见的浪费是「上一个人的原始数据找不到、方法参数没记、样品没留」，于是同一件事每年重做一遍。移交要做的是把个人记忆变成实验室资产。

## H.2 本章目标（可检验）

- 整理可移交的四类资产：数据、方法、样品、结论
- 写出一页「接手须知」：从哪开始、坑在哪、下一步做什么
- 完成实验室登记与实物交接签收

## H.3 操作流程

1. 数据清单：原始色谱文件、处理后表格、脚本、图像，逐一列路径与命名规则
2. 数据完整性检查：抽查 5 个数字能否从原始文件复算出来；不能复算的标「不可用」
3. 方法文档：把最终条件写成 SOP（样品制备、色谱条件、系统适用性、数据处理），含版本号
4. 踩坑记录：列出至少 5 条「我遇到过但文档里没有」的问题与解决办法
5. 样品移交：剩余样品、留样、对照品清单与位置，注明有效期
6. 未完成项：把没做完的实验、没验证的假设列成「下一步清单」，按优先级排序
7. 结论摘要：三句话写清「已确认什么、未确认什么、建议下一步验证什么」
8. 接手须知一页：从哪读起（文件顺序）、跑通一次需要什么、坑在哪
9. 实验室登记：仪器使用记录、耗材余量、试剂有效期更新
10. 交接演示：向接手人演示一次完整流程（样品→采集→处理），对方复述关键三步
11. 签收：数据、方法、样品、未完成项四张清单逐项签字
12. 复盘：写一条「如果重来，我会在哪一步开始就归档」

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 四类资产清单齐全且路径明确
- [ ] 抽查 5 个数字可从原始文件复算
- [ ] SOP 含版本号与最终条件
- [ ] 踩坑记录≥5 条且可操作
- [ ] 样品与对照品清单含位置与有效期
- [ ] 未完成项按优先级排序
- [ ] 结论摘要三句话写完
- [ ] 接手须知一页可独立阅读
- [ ] 仪器与耗材、试剂效期已更新
- [ ] 交接演示完成，对方复述三步
- [ ] 四张清单签字
- [ ] 复盘一条已写

## H.5 模板：毕设移交清单

| 字段 | 填写要求 |
|------|----------|
| 数据资产 | 原始文件、表格、脚本、图像；路径与命名规则 |
| 复算抽查 | 抽查的 5 个数字与复算结果 |
| 方法 SOP | 版本号、样品制备、采集条件、系统适用性、处理规则 |
| 踩坑记录 | 问题、表现、解决办法 |
| 样品与耗材 | 剩余样品、留样、对照品、位置、有效期 |
| 未完成项 | 项目、优先级、前置条件 |
| 结论摘要 | 已确认/未确认/建议下一步 |
| 接手须知 | 阅读顺序、跑通一次的条件、注意事项 |
| 签收 | 移交人、接手人、导师、日期 |

> 本表是本章的交付物：答辩后一周内完成；四张清单签字后归入实验室档案。

## H.6 常见失效与处置

- **只交论文不交数据** → 下一届无法复用，重做一遍
- **SOP 无版本号** → 条件改过也看不出，复现失败无从追
- **踩坑记录不写** → 同样的坑每年有人踩
- **样品不留样** → 关键批次用完即绝版，复核无从谈起
- **未完成项不列** → 接手人不知道从哪继续，先从零开始
- **交接只在口头** → 人一走信息全失；必须签字

## H.7 中期检查与答辩要点

- 数据可复算与清单完整（30%）
- SOP 与踩坑记录质量（30%）
- 未完成项与接手须知（25%）
- 交接演示与签收（15%）
