## H.1 本章要解决的问题

有了差异还要证明差异不是方法波动。方法学验证（精密度、重复性、稳定性、加样回收）是中药分析的硬门槛。

## H.2 本章目标（可检验）

- 完成四项方法学验证并给出数据
- 说明批内与批间一致性的判定标准
- 对不合格项给出归因

## H.3 操作流程

1. 精密度：同一样品连续进样六次
2. 重复性：同批取样六份独立前处理
3. 稳定性：不同时间点进样比较
4. 回收率：加标三水平各三份
5. 判定：按可接受标准逐项判断并写结论

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 四项验证各有原始数据
- [ ] RSD 或回收率数值已列
- [ ] 判定标准事先写明
- [ ] 不合格项已归因
- [ ] 仪器状态与柱效已记录
- [ ] 对照品批号与纯度已记
- [ ] 结论与开题假设呼应

## H.5 模板：方法学验证表

| 字段 | 填写要求 |
|------|----------|
| 精密度 | 六次进样 RSD |
| 重复性 | 六份 RSD |
| 稳定性 | 时间点与变化 |
| 回收率 | 三水平九份 |
| 判定 | 逐项结论与归因 |

> 本表是本章的交付物：质量一致性结论的唯一依据。

## H.6 常见失效与处置

- **标准事后定** → 看到数据再定阈值等于自证；须事先写明
- **只做精密度** → 缺重复性与回收率不足以支撑一致性结论
- **不合格项隐去** → 验证的意义就在于暴露波动；须列出并归因

## H.7 中期检查与答辩要点

- 四项完成度（40%）
- 判定标准前置（30%）
- 不合格归因（30%）
