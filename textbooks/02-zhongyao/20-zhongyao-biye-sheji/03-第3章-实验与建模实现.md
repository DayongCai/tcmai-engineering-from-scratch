## H.1 本章要解决的问题

把图谱变成结论，中间要么靠相似度计算、要么靠统计检验。两种做法都要写清假设与参数，否则结论不可复现。

## H.2 本章目标（可检验）

- 实现一条从原始图谱到结论的可复现链路
- 说明所选算法与参数及其理由
- 保存全部中间结果

## H.3 操作流程

1. 预处理：对齐、基线校正、归一化各写参数
2. 特征：选共有峰或整段信号，说明理由
3. 分析：相似度或分组检验，写假设与显著性水平
4. 复算：用同一脚本重跑一次验证结果一致
5. 存档：原始数据、脚本、参数三者同目录

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 预处理参数已写
- [ ] 特征选择有理由
- [ ] 统计假设与检验方法已写
- [ ] 显著性水平与多重比较处理已写
- [ ] 脚本可重跑且结果一致
- [ ] 原始数据未修改
- [ ] 第三方工具版本已记

## H.5 模板：分析实现说明

| 字段 | 填写要求 |
|------|----------|
| 预处理 | 对齐/基线/归一化参数 |
| 特征 | 共有峰或区段 |
| 方法 | 相似度或检验，假设与 α |
| 结果 | 关键数值 |
| 复算 | 命令与一致性检查 |

> 本表是本章的交付物：论文附录，评审可按此复算。

## H.6 常见失效与处置

- **预处理不写参数** → 结果无法复现；参数即方法
- **多重比较多不做校正** → 假阳性率高；须说明校正方式
- **只留结果不留原始** → 无法判断是否预处理过度

## H.7 中期检查与答辩要点

- 链路可复现（40%）
- 方法选择理由（30%）
- 原始数据完整性（30%）
