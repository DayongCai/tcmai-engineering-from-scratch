## H.1 本章要解决的问题

毕设最容易失控的阶段是「做实验」：平行样做到一半发现对照品不够、数据处理时才想起没记柱温。这一阶段的目标不是「做出漂亮数据」，而是让每一步都能被复现：谁在什么条件下、得到什么、异常怎么处理。

## H.2 本章目标（可检验）

- 按预试确认的条件完成全样检测，逐日记录实验日志
- 完成数据处理（峰面积归一、相似度、聚类或统计检验）并保留脚本
- 对异常值、失败批次给出处理规则与留痕

## H.3 操作流程

1. 排产：按仪器可用时段排检测顺序，避免样品放置过久；记录每批开始与结束时间
2. 每日日志：日期、样品编号、检测项、条件偏差（温度/流动相批号）、异常现象、处理动作
3. 平行样：每批 ≥2 份平行，RSD 超限（如 >3%）需重测并记原因
4. 质控样：每 10 针插一针对照品，监控系统漂移；漂移超限则整段重测
5. 原始记录：打印图谱需签名与日期，电子文件同步归档
6. 数据导出：峰面积、保留时间导出为表格，保留原始导出文件不覆盖
7. 数据处理规则：峰识别阈值、基线处理、归一化方式必须事先写定，不得看完结果再定
8. 相似度与聚类：相似度用夹角余弦或相关系数，说明软件与版本；聚类方法（层次/ K-means）与距离度量写清
9. 统计检验：分组比较用方差分析或非参数方法，前提检查与多重比较按教材第 4 章口径
10. 异常值处理：按预设规则（如 Grubbs 或 >3SD）判定，剔除须写「值、判据、影响」
11. 失败批次：记录失败原因（样品、仪器、操作），重测后保留两次记录
12. 阶段小结：每完成一个分组写半页小结（数据完整率、异常项、下一步），交导师签字

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 排产表含仪器时段与样品顺序
- [ ] 每日日志有日期、编号、条件偏差与异常
- [ ] 每批≥2 份平行，RSD 超限有重测记录
- [ ] 每 10 针插对照品监控漂移
- [ ] 打印图谱有签名与日期
- [ ] 导出文件保留原始版本未被覆盖
- [ ] 数据处理规则在看结果前写定
- [ ] 相似度/聚类方法与软件版本已记
- [ ] 统计检验含前提检查与多重比较
- [ ] 异常值处理有判据与影响说明
- [ ] 失败批次两次记录均保留
- [ ] 每个分组有阶段小结并经导师签字

## H.5 模板：实验日志与数据处理记录表

| 字段 | 填写要求 |
|------|----------|
| 排产 | 日期、仪器、样品顺序、预计时长 |
| 当日操作 | 样品编号、检测项、条件偏差 |
| 质控 | 对照品针次、漂移幅度、是否重测 |
| 平行与 RSD | 份数、结果、RSD、是否超限 |
| 异常 | 现象、判断、处理、是否影响结论 |
| 处理规则 | 峰识别、基线、归一化；版本与生效日期 |
| 建模/统计 | 方法、软件版本、参数、前提检查 |
| 异常值 | 值、判据、剔除与否、影响 |
| 小结 | 完整率、异常项、下一步、导师签字 |

> 本表是本章的交付物：每日一页；数据处理规则单独一页贴在工作台，改动须写版本。

## H.6 常见失效与处置

- **不插质控针** → 仪器漂移被当作样品差异，整组数据不可用
- **看完结果才定处理规则** → 属事后调参，结论不可信
- **平行样 RSD 超限不重测** → 把操作误差当样品差异报出
- **只存图片不存原始文件** → 复核时无法重算峰面积
- **异常值悄悄剔除** → 未写判据与影响，评审必问
- **失败批次只留成功那次** → 属选择性报告，是学术规范问题

## H.7 中期检查与答辩要点

- 实验日志完整性（30%）
- 质控与平行样执行（25%）
- 处理规则预设与可复现（25%）
- 异常与失败记录（20%）
