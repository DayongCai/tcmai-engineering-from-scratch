## H.1 本章要解决的问题

「研究某药材的质量标志物」是方向不是命题。毕设要把它收窄成能判真假的假设，并说明现有标准为何不够。

## H.2 本章目标（可检验）

- 指出一条现行标准的具体缺口
- 把缺口改写成可验证假设
- 明确所需批次与检测能力

## H.3 操作流程

1. 查标准：找药典项下已有指标，指出缺少哪一类（如产地或炮制差异）
2. 定假设：写成「A 产地与 B 产地在指标 X 上存在系统差异」
3. 估批次：三点以上产地、每点三批
4. 核能力：确认仪器与方法可及
5. 砍范围：只做一个指标族，不铺开

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 标准缺口写到具体条款
- [ ] 假设含产地/炮制/年份等分组变量
- [ ] 每点三批以上样品可得
- [ ] 检测方法已确认可做
- [ ] 指标族不超过两个
- [ ] 伦理与委托协议已确认
- [ ] 十周可行性已评估

## H.5 模板：开题假设表

| 字段 | 填写要求 |
|------|----------|
| 标准缺口 | 药典条款与缺项 |
| 假设 | 分组变量 + 指标 + 预期方向 |
| 样品方案 | 产地/批次/数量 |
| 检测能力 | 仪器、方法、委托方 |
| 范围裁剪 | 舍弃了哪些指标 |

> 本表是本章的交付物：开题报告首页。

## H.6 常见失效与处置

- **把方向当命题** → 「研究质量标志物」无法判真假；必须落到分组比较
- **批次不足** → 每点一批无法排除批间差；至少三批
- **指标铺开** → 十周做不完；一个指标族做透

## H.7 中期检查与答辩要点

- 缺口与假设对应（40%）
- 样品方案可行性（30%）
- 检测能力确认（30%）
