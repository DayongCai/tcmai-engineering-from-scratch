## H.1 本章要解决的问题

「研究某药材的质量标志物」是方向不是命题。方向可以无限做，命题必须在十周内被证实或否证。毕设开题要交的不是一段意义论述，而是一条能被打假的假设 + 支撑它的样品与方法能力 + 明确说不做什么。

## H.2 本章目标（可检验）

- 指出一条现行标准（药典/部颁/地方标准）的具体缺口，落到条款与缺项
- 把缺口改写成含分组变量、指标与预期方向的可验证假设
- 给出样品方案（产地/批次/数量）与检测能力清单，说明十周可行性

## H.3 操作流程

1. 查标准：抄下目标药材药典项下的全部检测项（性状、鉴别、检查、浸出物、含量测定），标出各自限量
2. 找缺口：对照真实问题选一类缺口——产地差异未纳入、炮制前后未区分、多成分比例未控制、批间波动无判据
3. 写缺口句：格式为「现行标准 X 条款只控制 A，未控制 B，导致 C 情形无法判别」，缺 C 就不是缺口
4. 定假设：格式为「A 组与 B 组在指标 X 上存在系统差异（方向：A>B）」，必须能判真假
5. 选分组变量：产地（≥3 点）、炮制方法（生/制）、采收年份、规格等级，只选一个主变量
6. 定指标族：一个主指标 + 一个辅助指标（如指标成分含量 + 指纹图谱相似度），不超过两个
7. 估样品量：每点 ≥3 批、每批 ≥3 份平行；算清总检测次数与仪器占用时长
8. 核能力：仪器（HPLC/UV/TLC）、对照品（有无、是否需采购）、方法（药典法是否可直接用）
9. 砍范围：把「还想做」的列出并明确舍弃，写进开题报告的「不做清单」
10. 排十周：按周列里程碑（样品到位/方法建立/全样检测/数据处理/写作），标出关键路径
11. 风险预案：样品不到位、对照品缺货、仪器故障各写一条替代方案
12. 成稿与预答辩：按 H.5 模板填「开题假设表」，请导师与一位外专业老师各提一条反对意见并记录回应

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 标准条款与缺项已抄录，非泛泛而谈
- [ ] 缺口句含「只控制 A、未控制 B、导致 C 无法判别」三段
- [ ] 假设含分组变量、指标与预期方向
- [ ] 分组变量只选一个主变量，取样点≥3
- [ ] 指标族≤2 个，主辅分明
- [ ] 样品量与总检测次数已算清
- [ ] 仪器、对照品、方法三项能力已确认
- [ ] 「不做清单」已写并说明理由
- [ ] 十周里程碑含关键路径
- [ ] 三条风险各有替代方案
- [ ] 开题表经导师签字
- [ ] 记录了至少两条反对意见及回应

## H.5 模板：开题假设表

| 字段 | 填写要求 |
|------|----------|
| 标准缺口 | 标准名称、条款号、现控项目、未控项目、导致的问题 |
| 假设 | 分组变量 + 指标 + 预期方向 |
| 样品方案 | 取样点、每点批次、每批份数、总量 |
| 检测能力 | 仪器、对照品、方法来源、委托方 |
| 指标族 | 主指标、辅助指标、各自判据 |
| 不做清单 | 舍弃项与理由 |
| 十周里程碑 | 周次、任务、产出、关键路径标记 |
| 风险与替代 | 风险项、触发条件、替代方案 |
| 签字 | 学生、导师、日期 |

## H.6 常见失效与处置

- **把方向当命题** → 「研究质量标志物」无法判真假；必须落到分组比较
- **缺口没有后果** → 只说「标准未涉及产地」，不说因此会导致什么误判，缺口不成立
- **批次不足** → 每点一批无法排除批间差；至少三批
- **指标铺开** → 十周做不完；一个指标族做透胜过五个半途
- **能力未核就定题** → 开题后才发现对照品买不到，是最常见的返工
- **没有不做清单** → 范围会持续膨胀，最后每周都在换方向

## H.7 中期检查与答辩要点

- 缺口与假设的对应性（35%）
- 样品与检测能力可行性（30%）
- 范围裁剪与里程碑（20%）
- 预答辩回应质量（15%）
