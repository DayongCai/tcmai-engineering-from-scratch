## H.1 本章要解决的问题

中药类论文最易被质疑的是「样品够不够、方法靠不靠谱」，答辩要能当场指出台账与验证表的位置。

## H.2 本章目标（可检验）

- 论文数字与台账、验证表逐条一致
- 15 分钟讲清缺口—假设—方法—结论—边界
- 准备三个预设质疑

## H.3 操作流程

1. 对表：把论文每个数值回到台账与验证表
2. 写结构：缺口、假设、方法、结果、边界五段
3. 做图：每图标注样品编号与条件
4. 预设质疑：样品代表性、方法选择、统计处理
5. 试讲：找非本专业同学听一遍

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 数值与台账一致
- [ ] 五段结构齐全
- [ ] 每图有编号、条件与样品来源
- [ ] 三个预设质疑有答案
- [ ] 已做跨专业试讲
- [ ] 引用标准写到版本年
- [ ] 免责与致谢已写

## H.5 模板：答辩准备表

| 字段 | 填写要求 |
|------|----------|
| 核心结论 | 一句话，不超过 40 字 |
| 证据链 | 结论→样品→方法→验证 |
| 三个质疑 | 问题与答案要点 |
| 边界 | 不能推广到什么 |
| 试讲反馈 | 听不懂处与修改 |

> 本表是本章的交付物：答辩前一天自查。

## H.6 常见失效与处置

- **论文与台账不一致** → 答辩必被抽问；交稿前逐条核
- **只讲结果不讲边界** → 缺边界等于缺判断
- **图不标样品来源** → 无法判断代表性

## H.7 中期检查与答辩要点

- 一致性（40%）
- 表达与边界（40%）
- 质疑回答（20%）
