## H.1 本章要解决的问题

论文不是把日志誊清，而是把「问题—方法—证据—边界」串成一条能被外人检验的链。答辩考的不是你做了多少实验，而是你能不能在三分钟内说清「你的结论凭什么成立、在什么条件下不成立」。

## H.2 本章目标（可检验）

- 写出含问题、方法、结果、讨论、边界五部分的论文，每个数字可溯源
- 准备 10 分钟汇报与三类必答问题（数据可信、结论分寸、能否推广）
- 完成一次预答辩并按意见修改，保留修改对照

## H.3 操作流程

1. 定主线：一句话写清「本研究证明/否证了什么」，全文围绕它取舍
2. 结构：摘要（背景-方法-结果-结论四句）→ 引言（缺口与假设）→ 材料与方法（可复现）→ 结果（按假设顺序）→ 讨论（与文献比对）→ 边界与局限 → 结论
3. 方法章：样品、仪器、色谱条件、验证项，写到「他人可照做」的程度
4. 结果章：每个图表只回答一个子问题；图注含 n、误差线含义、判据线
5. 讨论章：与至少 3 篇文献比对，一致处与不一致处各写原因假设
6. 边界章：品种、产地范围、样本量、方法前提，逐条写并说明越界后果
7. 结论章：分「确定结论/提示性结论」两档，不与讨论混写
8. 数据溯源：正文每个数字标注表号或附录编号；附录放原始数据摘要与色谱图
9. 格式：按学院模板；引用格式统一，标准与药典注明版本与年份
10. 查重与规范：引用标注完整，图片自制或注明来源
11. 预答辩：10 分钟汇报 + 记录三条意见，逐条回应并修改
12. 定稿归档：论文、原始数据、脚本、答辩 PPT 四件一并归档

## H.5 模板：论文自检表与答辩评分表

| 字段 | 填写要求 |
|------|----------|
| 主线 | 一句话结论 |
| 摘要 | 背景、方法、结果、结论四句 |
| 方法可复现 | 样品、仪器、条件、验证项 |
| 结果 | 图表编号、n、判据、对应假设 |
| 讨论 | 文献比对条目与原因假设 |
| 边界与局限 | 逐条 + 越界后果 |
| 结论 | 确定/提示两档 |
| 溯源 | 数字到表号/附录的对应 |
| 答辩记录 | 三类必答问题的回答与追问 |
| 评分 | 证据链 35%、验证完整性 25%、边界分寸 20%、答辩 20% |

> 本表是本章的交付物：定稿前逐条自查；答辩现场用右栏评分，两份一并归档。

## H.6 常见失效与处置

- **方法与结果不对应** → 验证项缺项却下「方法可靠」结论
- **图表堆砌** → 一图多结论，读者抓不到主次
- **讨论只复述结果** → 没有与文献比对，看不出学术位置
- **结论拔高** → 单一产地数据写成普适规律
- **数字无出处** → 答辩被追问即崩
- **预答辩意见不回应** → 正式答辩会被同一问题再问一次

## H.7 中期检查与答辩要点

- 证据链完整性（35%）
- 方法学验证呈现（25%）
- 边界与结论分寸（20%）
- 答辩表现（20%）
