## H.1 本章要解决的问题

中药研究的结论强度，一半取决于样品是否「说得出出处」。同一批药材分三次粉碎、放在不同湿度下，指纹图谱就能出现肉眼可见的差异。样品准备要交付的不是一堆袋子，而是一条可追溯链：谁采的、什么时候、怎么干燥、怎么粉碎、留样在哪。

## H.2 本章目标（可检验）

- 建立样品台账：编号、产地、采收期、加工方式、入库时间、留样位置
- 完成取样与粉碎的标准化操作并记录（四分法、粒度、含水量）
- 建立指纹图谱采集的固定条件与原始数据归档规则

## H.3 操作流程

1. 样品来源确认：供应商资质、产地证明、采收期；无证明的样品单列为「来源不明」，不混入分组
2. 编号规则：产地码-批次号-份号（如 YN-03-02），全项目统一，标签与台账一致
3. 到样检查：外观、气味、含水量（快测）、杂质与霉变；不合格批单独标记不用
4. 留样：每批留 200 g 原样（不粉碎），4℃ 或阴凉干燥保存，记录留样位置
5. 取样：四分法缩分至检测量，记录缩分次数与最终量
6. 粉碎与过筛：统一粒度（如过三号筛），记录粉碎设备、时间、损耗率
7. 含水量测定：烘干法或快测仪，记录方法与结果；不同含水量会影响称样量
8. 对照品与试剂：来源、批号、纯度、配制日期；对照品不足时提前采购并记录到货时间
9. 指纹图谱条件固定：色谱柱型号与批号、流动相配制方法、梯度程序、柱温、检测波长、进样量
10. 系统适用性：理论板数、分离度、重复性（连续 6 针 RSD）达标后才测样品
11. 原始数据归档：色谱文件命名「编号-日期-序号」，与台账对应；导出 PDF 与原始格式双备份
12. 预试：先测 3 批确认方法稳定，再做全样；预试数据单独保存不混入正式结果

- [ ] 来源不明样品已单列，未混入分组
- [ ] 编号规则全项目统一，标签与台账一致
- [ ] 到样检查含含水量、杂质、霉变
- [ ] 每批留样≥200 g 且未粉碎
- [ ] 取样用四分法并记录缩分次数
- [ ] 粉碎粒度统一并有设备与损耗记录

## H.5 模板：样品台账与采集条件表

| 字段 | 填写要求 |
|------|----------|
| 样品信息 | 编号、名称、产地、采收期、加工方式、供应商 |
| 到样检查 | 外观、含水量、杂质、霉变、判定 |
| 取样与粉碎 | 四分法次数、粒度、设备、损耗率 |
| 留样 | 数量、位置、保存条件 |
| 对照品与试剂 | 名称、批号、纯度、配制日期、有效期 |
| 采集条件 | 色谱柱、流动相、梯度、柱温、波长、进样量 |
| 系统适用性 | 板数、分离度、6 针 RSD |
| 原始数据 | 文件命名规则、存放路径、备份位置 |

> 本表是本章的交付物：一张台账管全部样品；采集条件表贴在仪器旁，换柱或换流动相必须更新版本。

## H.6 常见失效与处置

- **来源不明样品混入分组** → 结论无法归因，答辩时整组数据作废
- **不记含水量** → 称样量偏差直接进入含量结果，误差被当成产地差异
- **粉碎粒度不一致** → 提取效率不同，指纹图谱差异来自操作而非样品
- **换柱不更新条件** → 柱批号变了，保留时间漂移，相似度计算失真
- **原始文件重命名** → 与台账脱钩，复核时无法定位
- **预试数据混入正式结果** → 属选择性使用数据，评审会直接质疑

## H.7 中期检查与答辩要点

- 台账可追溯性（30%）
- 取样与粉碎规范（25%）
- 采集条件固定与系统适用性（30%）
- 原始数据管理（15%）
