## H.1 本章要解决的问题

样品是中药毕设的地基：来源不清、混批、储存条件不一，后面的数据全部作废。

## H.2 本章目标（可检验）

- 建立可追溯的样品台账
- 固定取样与储存条件
- 完成指纹图谱的前处理与进样记录

## H.3 操作流程

1. 收样：每批留样两份，一份检测一份备查
2. 编号：产地-批次-年份三段编码
3. 储存：温湿度、避光、留样期限写死
4. 前处理：按方法记录称量、提取、定容
5. 进样：记录柱号、流速、梯度、进样量

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 每批两份留样已封存
- [ ] 三段编码规则已写
- [ ] 储存条件与期限已记录
- [ ] 前处理参数逐项记录
- [ ] 色谱条件完整（柱/流速/梯度/温度）
- [ ] 进样序列与样品编号对应
- [ ] 异常峰已标注未删

## H.5 模板：样品与进样台账

| 字段 | 填写要求 |
|------|----------|
| 样品编号 | 产地-批次-年份 |
| 留样 | 两份位置与期限 |
| 储存 | 温湿度、避光 |
| 前处理 | 称量、提取、定容 |
| 色谱条件 | 柱号、流速、梯度 |

> 本表是本章的交付物：随论文附，答辩抽查任一编号。

## H.6 常见失效与处置

- **编号无规则** → 样品与数据对不上；编码规则先定后收样
- **删掉「异常」峰** → 异常本身就是数据；标注而不删除
- **储存条件不记录** → 后续差异无法归因

## H.7 中期检查与答辩要点

- 台账可追溯性（40%）
- 条件记录完整度（30%）
- 异常处理诚实度（30%）
