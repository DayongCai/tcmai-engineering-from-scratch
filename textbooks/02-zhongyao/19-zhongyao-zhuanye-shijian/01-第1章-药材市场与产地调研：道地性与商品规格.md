## H.1 本章要解决的问题

同一味药在市场上能见到三四个「规格」，价格差一倍。调研要能说清规格差异对应哪些性状与产地，而不是只抄报价。

## H.2 本章目标（可检验）

- 能按药典性状项记录一个品种的市场规格
- 能区分道地产区与集散地，不把集散当产地
- 能写出价格与规格的对应关系

## H.3 操作流程

1. 定品种：选一个有明确道地记载的品种
2. 访三家：产地收购点、集散市场、零售药房各一家
3. 记性状：按药典性状项逐条记录并拍照留档
4. 问来源：问清收购地、加工方式、仓储年限
5. 做对照：把三处样品并列比对，写出差异

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 品种与药典标准已确定
- [ ] 三处样本各有来源记录
- [ ] 性状项逐条比对完成
- [ ] 产地与集散地已区分
- [ ] 加工与仓储信息已问
- [ ] 照片与样品编号对应
- [ ] 价格区间与规格对应已写

## H.5 模板：商品规格调研表

| 字段 | 填写要求 |
|------|----------|
| 品种与药典标准 | 药名、标准出处 |
| 三处来源 | 产地/集散/零售，各写地址与联系人 |
| 性状比对 | 按药典项逐条写差异 |
| 加工与仓储 | 方法、年限 |
| 价格与规格 | 区间、对应规格 |
| 结论 | 道地性判断与依据 |

> 本表是本章的交付物：每个品种一张，附照片编号。

## H.6 常见失效与处置

- **把集散地当产地** → 价格与质量判断都会错；必须问到收购地
- **只抄报价不记规格** → 价格差来自规格差，不记规格等于没调研
- **性状只写「色佳」** → 药典有具体项，须逐条对应

## H.7 出科考核

- 调研表完整度（40%）
- 道地性判断依据（30%）
- 样品与记录对应（30%）
