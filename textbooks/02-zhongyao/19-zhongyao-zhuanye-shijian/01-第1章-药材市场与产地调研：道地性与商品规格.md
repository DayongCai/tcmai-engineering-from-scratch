## H.1 本章要解决的问题

同一味药，市场报价能差三倍：产地不同、规格不同、加工方式不同，甚至只是「熏没熏硫」。调研不是记价格，而是把「这批货凭什么值这个价」拆成可核的六项：产地、采收期、加工法、规格等级、含水量、杂质与霉变情况。写不出这六项的调研表，等于只抄了一张价目单。

## H.2 本章目标（可检验）

- 独立完成一次不少于 10 个批次的抽样调研，逐批记录产地、规格、加工法与外观缺陷
- 能用《中国药典》性状项与规格等级标准判断「这批货属于哪一档」，并说明判据
- 写出一份含取样照片、原始记录与结论的调研报告，结论部分区分「观察到的事实」与「推断」

## H.3 操作流程

1. 调研前准备：明确调研品种（建议 3–5 味）、对照药典性状项抄成一张现场核对表、备好取样袋/标签/电子秤/水分速测仪/放大镜/相机
2. 确定抽样框：同一市场内不同摊位、不同产地标签各取一批；每批不少于 500 g，分装两份（一份留样、一份检测），标签写品种、产地、摊位、日期、抽样人
3. 外观六项逐批记：形状与大小、表面颜色与纹理、断面特征、气味、杂质比例（目测估）、有无霉变虫蛀与硫熏痕迹
4. 规格判级：按药典或行业规格（如头数、条粗、片厚、色泽等级）给出档位，并把「判为该档的三条依据」写下来
5. 水分与杂质：现场速测水分（如具备），杂质按目测+筛分粗估；超标批次单独标记，不进入后续比较
6. 加工方式追问：是否硫熏、是否染色、是否提取过（「提过油的」药材气味淡、质轻）、干燥方式（晒干/烘干/阴干）
7. 价格与来源链：报价、批量、供货周期、是否有产地证明或检测报告；同一品种不同摊位价差原因逐条写
8. 拍照留证：每批拍整体、断面、缺陷特写三张，编号与标签一致
9. 当日整理：把记录录入表格，标注异常值（价格离群、性状不符、水分超标），异常项写「待复核」而非直接下结论
10. 复核与送检：对争议批次送实验室做性状+显微或薄层鉴别，把结果回填调研表
11. 结论分栏：事实栏（观察到的）、推断栏（据此判断的道地性与档位）、待查栏（证据不足的）
12. 报告与答辩：按 H.5 模板成文，附抽样照片与原始记录；答辩时需说明「你最不确定的一批是哪批、为什么」

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 调研品种与批次数量达标（≥3 味、≥10 批）
- [ ] 每批有标签（品种/产地/摊位/日期/抽样人）与两份分装
- [ ] 外观六项（形色气味断面杂质霉变）逐批有记录
- [ ] 规格档位判断附三条依据
- [ ] 水分与杂质有实测或粗估数值，超标批次已单列
- [ ] 加工方式（硫熏/染色/提取过）已追问并记录
- [ ] 价格差异原因逐条写，未用「行情如此」敷衍
- [ ] 每批三张照片，编号与标签一致
- [ ] 争议批次已送检并回填结果
- [ ] 结论分事实/推断/待查三栏，未混写
- [ ] 原始记录可追溯到摊位与时间
- [ ] 报告含不确定批次说明

## H.5 模板：药材市场抽样调研表（逐批）

| 字段 | 填写要求 |
|------|----------|
| 品种 / 批次号 | 品种名 + 现场编号 |
| 产地与摊位 | 标称产地、摊位号、供货商 |
| 外观六项 | 形状大小、表面、断面、气味、杂质、霉变虫蛀 |
| 规格判级与依据 | 档位 + 三条判据 |
| 水分 / 杂质 | 实测或粗估值，注明方法 |
| 加工方式 | 硫熏/染色/提取过/干燥方式，依据是什么 |
| 价格与批量 | 报价、起订量、供货周期、有无检测报告 |
| 照片编号 | 整体/断面/缺陷三张，与标签一致 |
| 送检与回填 | 送检项目、结果、回填日期 |
| 结论分栏 | 事实 / 推断 / 待查 |

> 本表是本章的交付物：每批一张，现场手写；回实验室后录入电子表，纸质原件随报告归档。

## H.6 常见失效与处置

- **只抄价格不记性状** → 价差原因无法解释，调研退化为价目单
- **同一摊位取多批当多样本** → 抽样框失真，结论不能推广
- **硫熏与提取过药材未识别** → 气味淡、质轻、断面异常是线索；漏判会得出错误的质量结论
- **把推断写进事实栏** → 答辩时无法区分「你看到的」与「你以为的」，整份报告可信度下降
- **留样与检测样混放** → 复核时无法追溯；两份分装、标签一致是底线
- **异常值直接删除** → 离群数据往往是最有价值的线索；应标「待复核」并说明处理

## H.7 出科考核

- 抽样规范性（标签、分装、批次覆盖，25%）
- 外观与规格判据的准确性（30%）
- 原始记录完整与可追溯（20%）
- 结论三栏分离与不确定说明（15%）
- 报告与答辩（10%）
