## H.1 本章要解决的问题

炮制的关键不是「炒了什么」，而是「哪几个参数决定成败」。车间实践要能指出本工艺的三个质控点并说明超限后果。

## H.2 本章目标（可检验）

- 能写出本工艺的完整参数与质控点
- 能识别常见偏差（太过/不及）及其指标
- 能完成一次批记录并复核

## H.3 操作流程

1. 读规程：抄下温度、时间、辅料比、投料量
2. 跟批：全程跟随一批，记录实际值与规程值
3. 取质控点：指出三个关键点及判定标准
4. 查偏差：找出本批与规程的差异并提出处置
5. 复核：与班组长共同签字确认

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 工艺参数已完整抄录
- [ ] 实际值与规程值并列记录
- [ ] 三个质控点及标准已写
- [ ] 偏差项与处置已写
- [ ] 批记录签字齐全
- [ ] 成品性状与水分检测已做
- [ ] 异常已上报并留痕

## H.5 模板：炮制批记录复核表

| 字段 | 填写要求 |
|------|----------|
| 工艺参数 | 温度/时间/辅料比/投料量 |
| 实测量 | 逐项实际值 |
| 质控点 | 三处及判定标准 |
| 偏差 | 差异、原因、处置 |
| 签字 | 操作人、复核人、日期 |

> 本表是本章的交付物：每批一张，与车间原始记录一并归档。

## H.6 常见失效与处置

- **只记「已按规程操作」** → 无法判断是否太过或不及；须记实测值
- **质控点选成非关键项** → 选温度与时间之外的外观项会导致漏判
- **偏差不写处置** → 留痕不完整，等于没有纠正

## H.7 出科考核

- 参数与实测记录（40%）
- 质控点选择合理性（30%）
- 偏差处置闭环（30%）
