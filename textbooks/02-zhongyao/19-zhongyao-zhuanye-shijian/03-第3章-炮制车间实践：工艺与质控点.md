## H.1 本章要解决的问题

炮制的目标只有两条：减毒增效、改变药性走向。但车间里最容易发生的是「凭经验做到差不多」——火候看颜色、辅料凭手感、时间靠师傅喊。实践要做的，是把「差不多」换成可记录的参数：温度、时间、辅料比例、投料量、终点判据，并且每批留样。

## H.2 本章目标（可检验）

- 独立完成一种炮制方法（炒/炙/煅/蒸煮之一）的批记录，参数完整可复现
- 能说清该方法的三个关键质控点与终点判据（外观、气味、水分、指标成分）
- 识别并记录至少两类常见偏差（火候过度、辅料不匀、干燥不足）及其处置

## H.3 操作流程

1. 班前确认：核对炮制品种、批量、辅料（酒/醋/蜜/盐/姜汁）规格与用量、设备状态与清洁记录
2. 参数设定：按工艺规程写清温度（或火力档）、投料量、辅料比例、时间；**未写参数不开机**
3. 投料与预热：设备预热到设定温度并稳定，投料均匀，记录投料时间与实测温度
4. 过程观察：按固定间隔（如每 2 分钟）观察颜色、气味、形态变化并记录；不凭记忆事后描述
5. 终点判据：以外观（色泽均匀、无焦斑）、气味（该品种特有香气出现且不焦）、水分（实测）、必要时指标成分含量综合判定；判据写在批记录上
6. 出料与摊晾：出料时间、摊晾厚度与环境、摊晾时长；避免堆积导致回潮或过度干燥
7. 辅料均匀性检查：炙法需抽查不同位置样品，比较色泽与气味是否一致
8. 质量快检：水分、浸出物或指标成分（按品种规程），记录方法与结果
9. 留样：每批留样不少于三次检验量，标签写品种、批号、辅料、日期、操作人
10. 偏差记录：出现焦斑、辅料结块、干燥不足等，写「偏差描述—可能原因—处置—是否影响放行」
11. 清场与交接：设备清洁、剩余辅料退库、批记录交车间复核
12. 复盘：挑一批「颜色合格但气味偏焦」的样品，讨论单一判据为何不够

## H.5 模板：炮制批记录（单批）

| 字段 | 填写要求 |
|------|----------|
| 品种与批号 | 品名、批号、批量、生产日期 |
| 辅料 | 种类、规格、用量、比例、来源 |
| 设备与清洁状态 | 设备编号、清洁记录编号、预热温度 |
| 关键参数 | 温度/火力、投料量、时间、翻动频次 |
| 过程观察 | 时间点 → 颜色/气味/形态 |
| 终点判据 | 外观、气味、水分、成分，逐项写实测值 |
| 出料与摊晾 | 出料时间、厚度、环境、时长 |
| 快检结果 | 项目、方法、结果、判定 |
| 偏差 | 描述、原因、处置、是否影响放行 |
| 留样与签名 | 留样量、位置、操作人、复核人 |

> 本表是本章的交付物：每批一张，随批流转；放行前须有车间复核与 QA 签字。

## H.6 常见失效与处置

- **凭颜色判断终点** → 单一判据不可靠；颜色合格但气味偏焦的批次很常见
- **辅料凭手感加** → 比例无法复现，批间差异大；必须称量并记录
- **过程观察事后补写** → 批记录失去证据价值，偏差也无从追溯
- **摊晾堆积过厚** → 回潮与霉变风险；厚度与环境要记
- **偏差不记录直接放行** → 质量问题被掩盖，后续投诉无法追因
- **留样量不足** → 复检与稳定性考察无法开展

## H.7 出科考核

- 批记录参数完整性与可复现性（35%）
- 终点判据的多指标使用（25%）
- 偏差识别与处置（20%）
- 留样与清场规范（10%）
- 复盘质量（10%）
