## H.1 本章要解决的问题

中试是实验室处方走向生产的分水岭：小试做得出的东西，放大十倍常常做不出来——提取率变了、干燥后粉体性质变了、成型时黏冲了。中试要交付的不是「一批样品」，而是「一套能重复做出合格样品的工艺参数与判据」。

## H.2 本章目标（可检验）

- 完成一次中试的工艺参数记录（提取、浓缩、干燥、成型四段），标明关键工艺参数
- 为每个关键质量属性（CQA）给出检测方法与可接受范围
- 写出一份中试报告，说明放大前后差异、原因假设与验证计划

## H.3 操作流程

1. 处方与目标确认：处方组成、日剂量、拟用剂型、目标质量属性（含量、溶出、水分、微生物）
2. 物料核对：药材/饮片批号与检验报告、辅料规格、包材；一批中试原则上用同一批药材，否则无法归因
3. 提取段：溶媒与倍量、温度、时间、次数、提取罐编号；记录提取液体积与相对密度
4. 浓缩与干燥：真空度、温度、终点（相对密度/含水量）、干燥方式（真空/喷雾）与进风/出风温度
5. 成型段：辅料配比、制粒（润湿剂种类与用量、制粒时间）、压片/装囊参数（压力、转速、装量差异）
6. 关键工艺参数（CPP）标注：从四段中挑出对 CQA 影响最大的 3–5 个参数，写清「为什么是它」
7. 过程取样：提取液、浸膏、干膏粉、半成品、成品各取样，编号与批号对应
8. 质量检测：含量/指标成分、水分、溶出度或崩解时限、装量差异、微生物限度；每项写方法与限度
9. 放大差异分析：与小试数据对比，列出差异项（如提取率下降 8%、干燥后流动性变差），提出原因假设
10. 偏差与处置：黏冲、含量偏低、溶出不合格等，写「现象—假设—验证动作—结论」
11. 稳定性起点：留样并设计加速试验条件（温度/湿度/时间点）
12. 报告与移交：按 H.5 模板成文，附批记录、检测报告、留样清单；移交生产前需列出「未解决项」

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 处方与目标 CQA 已书面确认
- [ ] 药材/辅料批号与检验报告齐全，同批原则已说明
- [ ] 提取四要素（溶媒倍量、温度、时间、次数）完整
- [ ] 浓缩干燥终点有实测值（相对密度或含水量）
- [ ] 成型参数（配比、润湿剂、压力/转速）完整
- [ ] 已标注 3–5 个 CPP 并说明理由
- [ ] 五段取样（提取液/浸膏/干膏/半成品/成品）编号可对应
- [ ] 每项 CQA 有方法与限度
- [ ] 放大前后差异已列表并给原因假设
- [ ] 偏差按「现象—假设—验证—结论」记录
- [ ] 留样与加速试验条件已设计
- [ ] 报告列出未解决项与移交前置条件

## H.5 模板：中试批记录与质量汇总表

| 字段 | 填写要求 |
|------|----------|
| 处方与剂型 | 组成、日剂量、目标 CQA |
| 物料 | 药材批号、辅料规格、包材，是否同批 |
| 提取参数 | 溶媒、倍量、温度、时间、次数、罐号 |
| 浓缩干燥 | 真空度、温度、终点密度/含水量、方式 |
| 成型参数 | 配比、润湿剂、制粒时间、压力/转速、装量 |
| CPP 清单 | 参数名、目标值、允许范围、影响哪个 CQA |
| 检测结果 | 项目、方法、限度、实测值、判定 |
| 放大差异 | 差异项、幅度、原因假设 |
| 偏差 | 现象、假设、验证动作、结论 |
| 留样与稳定性 | 留样量、加速条件、时间点 |

> 本表是本章的交付物：每批中试一套；随批记录归档，质量汇总页供移交评审使用。

## H.6 常见失效与处置

- **中试用多批药材混投** → 放大差异无法归因，等于白做一次中试
- **只记「按规程操作」** → 没有实测参数就没有可复现性，工艺无法移交
- **CQA 只测含量** → 溶出/崩解、水分、装量差异同样决定成败
- **放大差异不分析** → 下一批仍会重复同样的问题
- **偏差当偶然事件** → 不写假设与验证，偏差会反复出现
- **未列未解决项就移交** → 生产端接手即爆雷；移交前必须列清单

## H.7 出科考核

- 工艺参数完整与 CPP 识别（35%）
- CQA 方法与限度设置（25%）
- 放大差异分析与偏差处置（25%）
- 留样与移交清单（15%）
