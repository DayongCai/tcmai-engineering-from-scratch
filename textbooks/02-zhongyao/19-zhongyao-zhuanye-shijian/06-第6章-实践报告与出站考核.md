# 第 6 章 · 实践报告与出站考核

> **课程**：中药专业实践（🌾 中药系 · 第 9 学期 · 108 学时 · 轮转/实践）
> **契约**：**操作型章（handbook-v1）** —— 本文件是工作手册，不是学术教材：给的是当场能执行的流程、清单与模板。
> **前置**：中成药与临床用药、中药鉴定学、中药炮制学
> **本章产出物**：实践报告结构表与考核评分表
> 学术型教材的 N.1–N.5 契约（含 N.3「这个翻译丢掉了什么」）**不适用**本课程，理由见 `textbooks/README.md`「操作型章契约」。

---

## H.1 本章要解决的问题

五周实践结束时，多数人交上来的是一份「我做了什么」的流水账。出站考核要的是另一种东西：一个可复核的结论——你用什么样本、什么方法、得到什么数据、能支持到什么程度、哪些还解释不了。报告的价值不在于长，而在于每条结论后面都能指到原始记录。

## H.2 本章目标（可检验）

- 写出一份含样本、方法、数据、结论、局限五部分的实践报告
- 报告中的每条数据都能追溯到原始记录（表号/照片号/批记录号）
- 在 15 分钟答辩中回答「你的结论能不能推广到别的产地/别的批次」

## H.3 操作流程

1. 选题收口：从五个现场中选一个有数据支撑的问题（如「某产地三七规格与水分的关系」），写成一句可检验的命题
2. 材料清点：调研表、鉴定记录、批记录、审方与随访记录逐份编号，缺失的标注而非编造
3. 方法描述：写清样本量、抽样方法、检测方法与判据；他人照此应能复现
4. 数据整理：把原始数据录入统一表格，保留异常值并注明处理方式（保留/剔除及理由）
5. 图表：每张图表只有一个结论，图注写清样本量与单位
6. 结论分层：确定结论（证据充分）、提示性结论（证据有限）、无法结论（数据不足）三档
7. 局限与偏倚：样本代表性、时间跨度、检测手段限制、单一操作者偏倚，逐条写
8. 改进建议：面向现场（流程/记录/判据）而非空泛的「加强管理」
9. 格式与引用：按学院模板排版，引用药典/标准写明版本与条款号
10. 自查：逐条核对「每个数字都有来源」，标不出来的删掉或降级为提示性结论
11. 答辩准备：准备三个必答题——样本够不够、方法可靠吗、结论能推广吗
12. 归档与移交：报告、原始记录、留样清单三件一并交，签字确认

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 命题一句话可检验，含对象与判据
- [ ] 样本量、抽样方法、检测方法、判据四项写清
- [ ] 全部原始记录已编号，缺失项如实标注
- [ ] 数据表保留异常值并说明处理理由
- [ ] 每张图表只有一个结论，图注含样本量与单位
- [ ] 结论分确定/提示/无法结论三档
- [ ] 局限与偏倚逐条写，未用「时间有限」搪塞
- [ ] 改进建议面向现场流程与判据
- [ ] 引用写明版本与条款号
- [ ] 自查过「每个数字都有来源」
- [ ] 三个必答题已准备
- [ ] 三件材料归档并签收

## H.5 模板：实践报告结构表与考核评分表

| 字段 | 填写要求 |
|------|----------|
| 命题与背景 | 一句话命题 + 为什么值得做 |
| 样本与方法 | 样本量、抽样、检测方法、判据 |
| 数据与图表 | 表号/图号、样本量、单位、异常值处理 |
| 结论三档 | 确定 / 提示 / 无法结论，各附证据编号 |
| 局限与偏倚 | 代表性、时间、手段、操作者 |
| 改进建议 | 面向流程与判据的具体动作 |
| 引用 | 药典/标准版本与条款号 |
| 答辩记录 | 三个必答题的回答与追问 |
| 评分 | 数据可溯源 40%、方法可靠性 25%、结论分寸 20%、答辩 15% |
| 归档 | 报告、原始记录、留样清单，签收人 |

> 本表是本章的交付物：写作时按结构表逐节填；答辩现场用评分表打分，两项分数一并归档。

## H.6 常见失效与处置

- **写成流水账** → 没有命题就没有结论，报告无法评分
- **数字没有来源** → 答辩时被追问即崩；每个数字都要能指到表号
- **结论拔高** → 样本 10 批却写成普遍规律，属过度推断
- **异常值悄悄剔除** → 未说明处理理由，数据可信度归零
- **局限写成套话** → 「时间有限、经验不足」不算局限分析
- **建议空泛** → 「加强质量管理」不可执行；要写清谁在什么环节改什么判据

## H.7 出科考核

- 数据可溯源（40%）
- 方法描述与可复现性（25%）
- 结论分寸与局限分析（20%）
- 答辩（15%）
