## H.1 本章要解决的问题

鉴定最常见的错误不是「不会看」，而是「看得太快」：拿到样品先想结论，再找支持结论的特征，于是把混伪品看成正品。实验室实践要建立的是相反的顺序——先按药典性状项逐条比对并记录不符合项，再决定是否上显微与理化；每一步都留原始记录，包括「不符合」的那些。

## H.2 本章目标（可检验）

- 按药典性状项完成 5 个品种的独立鉴定，逐项写「符合/不符合/无法判断」及依据
- 独立完成显微制片与特征描述（组织构造、后含物、晶体），能区分正品与常见混伪品
- 写出一份鉴定记录：样品来源、方法、观察结果、结论与置信度

## H.3 操作流程

1. 收样与登记：样品编号、来源、数量、外观照片；核对送检目的（真伪/优劣/掺杂）
2. 性状鉴定：按药典「性状」项逐条比对——形状、大小（实测若干粒并记范围）、表面、断面、气味、味感（有毒品种不尝）
3. 不符合项登记：任何一条不符即记「不符合 + 具体差异」，不得用「大致相符」笼统带过
4. 取样粉碎：按四分法取样，留足复检量；粉碎粒度按检测项目要求，记录设备与时间
5. 显微制片：粉末制片（水合氯醛透化、稀甘油装片）、必要时做切片；记录试剂、透化时间、放大倍数
6. 显微特征描述：逐项写组织构造（如导管类型、石细胞、纤维）、后含物（淀粉粒、草酸钙结晶、菊糖）、分泌组织；每项标数量与尺寸范围
7. 混伪品比对：对疑似混伪品，列出「正品有而样品无」「样品有而正品无」两栏特征
8. 理化鉴别（按需）：薄层色谱（对照药材/对照品、展开剂、检视条件）、水分、灰分、浸出物；记录色谱图与 Rf 值
9. 结果汇总：每个检测项写「符合/不符合/无法判断」，无法判断的写明原因（样品量不足、特征不典型）
10. 结论与置信度：给出「符合规定/疑似混伪/不符合规定」三档之一，并注明支撑证据与反证
11. 复核：由第二人独立复看关键特征并签名；有分歧时保留双方记录，交带教裁定
12. 归档：原始记录、照片、色谱图、复检样品一并归档，编号与送检单一致

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 样品登记信息齐全（编号、来源、数量、送检目的）
- [ ] 性状项逐条比对，未用「大致相符」
- [ ] 大小做了实测（若干粒，记范围而非单值）
- [ ] 不符合项已单独登记并写明差异
- [ ] 取样按四分法，留足复检量
- [ ] 显微制片记录试剂、透化时间、放大倍数
- [ ] 显微特征写数量与尺寸范围，不写「可见」
- [ ] 混伪品比对写成「正品有/样品无」两栏
- [ ] 理化项目记录了对照、展开剂与检视条件
- [ ] 每项结论为「符合/不符合/无法判断」三态之一
- [ ] 结论附支撑证据与反证，并标置信度
- [ ] 第二人复核签名，分歧记录保留

## H.5 模板：药材鉴定原始记录表

| 字段 | 填写要求 |
|------|----------|
| 样品信息 | 编号、名称、来源、数量、送检目的 |
| 性状逐项比对 | 药典项 → 观察值 → 符合/不符合/无法判断 |
| 实测数据 | 大小、色泽、断面、气味；粒数与范围 |
| 显微制片 | 方法、试剂、透化时间、放大倍数 |
| 显微特征 | 组织构造、后含物、晶体，附数量与尺寸 |
| 混伪品比对 | 正品有而样品无 / 样品有而正品无 |
| 理化鉴别 | 方法、对照、条件、结果（图号） |
| 结论与置信度 | 三档结论 + 支撑证据 + 反证 |
| 复核 | 第二人签名、分歧与裁定 |
| 附件 | 照片编号、色谱图编号、留样位置 |

> 本表是本章的交付物：每个样品一张，边做边填；不得事后补写，改动须划改并签名。

## H.6 常见失效与处置

- **先有结论再找证据** → 只记支持项、不记不符合项，混伪品会被放过
- **显微只看「有没有」** → 特征必须写数量与尺寸范围，否则无法与标准比对
- **取样不按四分法** → 样品不具代表性，结论不能代表整批
- **用「大致符合」代替逐项判断** → 无法复核，也无法在争议时自证
- **尝味鉴定有毒品种** → 安全底线：有毒药材一律不尝，用其他特征判断
- **复核走过场** → 第二人未独立复看即签名，等于没有复核

## H.7 出科考核

- 性状逐项比对与不符合项登记（30%）
- 显微操作与特征描述质量（30%）
- 结论三态与证据/反证（20%）
- 原始记录规范与可追溯（10%）
- 复核与归档（10%）
