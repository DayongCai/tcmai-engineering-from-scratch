## H.1 本章要解决的问题

显微鉴定最容易出的问题是「照着图谱找特征」而不是「按标准逐项排除伪品」。本章要求给出排除路径，而非一句「符合规定」。

## H.2 本章目标（可检验）

- 能按药典完成性状与显微两项鉴定记录
- 能对易混淆品列出鉴别点
- 能写出判定与不确定项

## H.3 操作流程

1. 取样：按四分法取样并编号
2. 性状：逐项对照药典并记录
3. 制片：按标准制片，记录试剂与倍数
4. 显微：记录组织特征与细胞内含物
5. 判定：写出符合/不符合与依据，列出未检项

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 取样方法与样本编号已记录
- [ ] 性状项逐条有结论
- [ ] 制片方法与试剂已记录
- [ ] 显微特征有图像或文字描述
- [ ] 易混淆品鉴别点已列
- [ ] 判定依据与未检项已写
- [ ] 仪器编号与日期已记

## H.5 模板：鉴定记录表

| 字段 | 填写要求 |
|------|----------|
| 样本信息 | 编号、来源、批次 |
| 性状记录 | 逐项对照结果 |
| 显微记录 | 制片、试剂、特征 |
| 易混淆品 | 鉴别点与差异 |
| 判定 | 符合/不符合 + 未检项 |

> 本表是本章的交付物：每个样本一张，随检验报告归档。

## H.6 常见失效与处置

- **只写「符合规定」** → 无逐项记录无法复核；每项都要有结论
- **显微只看一张片** → 取样不均会漏检；按标准制片并记录位置
- **不记试剂与倍数** → 他人无法复现；制片条件必须写

## H.7 出科考核

- 记录可复现性（40%）
- 鉴别点准确性（30%）
- 判定与未检项诚实度（30%）
