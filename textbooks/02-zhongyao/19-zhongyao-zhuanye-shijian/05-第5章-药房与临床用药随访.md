## H.1 本章要解决的问题

药房实践的价值在于看到真实用药：同一张方在门诊被反复加减，配伍禁忌与剂量问题往往出现在这里而不是处方集里。

## H.2 本章目标（可检验）

- 能审核一张处方的配伍与用量
- 能完成十例用药随访并记录不良反应
- 能识别需要反馈给医师的问题

## H.3 操作流程

1. 审方：查配伍禁忌、妊娠禁忌、超量、重复用药
2. 发药交代：煎法、服法、饮食禁忌各说清
3. 随访：一周后电话或复诊随访十例
4. 记反应：记录胃肠道反应、过敏、疗效自评
5. 反馈：把共性问题整理成一条改进建议

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 审方四项已逐张完成
- [ ] 煎服法与禁忌已交代并记录
- [ ] 随访十例且有联系方式
- [ ] 不良反应逐例记录
- [ ] 疗效自评有口径
- [ ] 反馈建议已提交药师
- [ ] 隐私信息已脱敏

## H.5 模板：用药随访记录表

| 字段 | 填写要求 |
|------|----------|
| 处方审核 | 禁忌、超量、重复 |
| 交代内容 | 煎法、服法、忌口 |
| 随访结果 | 依从性、疗效自评 |
| 不良反应 | 症状、时间、处置 |
| 改进建议 | 一条，可执行 |

> 本表是本章的交付物：十例汇总一页，匿名化后归档。

## H.6 常见失效与处置

- **随访只问「有没有效」** → 缺依从性与不良反应，无法判断因果
- **把不良反应当疗效不佳** → 两者处置不同；须分开记录
- **反馈建议写成抱怨** → 要给可执行动作，不是评价

## H.7 出科考核

- 审方记录（30%）
- 随访完整性（40%）
- 改进建议可执行性（30%）
