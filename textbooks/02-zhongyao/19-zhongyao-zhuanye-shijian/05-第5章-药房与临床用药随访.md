## H.1 本章要解决的问题

药房是中药风险的最后一道闸：配伍禁忌、妊娠禁忌、超剂量、煎服法交代不清，任何一项漏掉都可能变成不良事件。实践要练的是「审方—交代—随访」三件套：审方要能说清每一条干预的依据，交代要病人能复述，随访要有可记录的结果。

## H.2 本章目标（可检验）

- 独立完成每日不少于 20 张处方的审核，记录干预项与依据
- 用 3 分钟完成煎服法与注意事项交代，并让患者复述关键三条
- 对不少于 10 位患者完成用药随访，记录依从性、疗效与不良反应

## H.3 操作流程

1. 审方前准备：熟悉本院中药房审方规则（配伍禁忌、妊娠禁忌、毒性饮片剂量上限、特殊煎法）
2. 处方合法性：医师签名、科室、日期、诊断与证候；缺诊断或诊断与用药明显不符的退方并记录
3. 剂量与配伍：逐味核对剂量是否超药典上限；核对十八反、十九畏与妊娠禁忌；毒性饮片是否双签名
4. 特殊煎法：先煎（矿石、贝壳、有毒）、后下（薄荷、砂仁）、包煎（车前子、旋覆花）、另煎（人参）、烊化（阿胶）、冲服（三七粉）
5. 用法用量：剂数、每日次数、每次量、饭前饭后、忌口；儿童与老人剂量是否调整
6. 干预记录：每一条干预写「问题—依据（药典条款/院内规则）—处理（退方/联系医师/加注说明）」
7. 发药交代（3 分钟）：煎法（器具、水量、火候、时间）、服法（温度、时间、与西药间隔）、忌口与可能出现的变化；请患者复述三条关键
8. 高危提示：妊娠、肝肾功能不全、儿童、老年多病共存患者，额外标注并留联系方式
9. 随访设计：确定随访时点（如第 3 天、第 7 天）、随访内容（依从性、症状变化、不良反应）与记录方式
10. 随访执行：电话或门诊随访，逐项记录；出现不良反应立即上报并留痕
11. 数据汇总：统计干预类型分布、依从性比例、不良反应例数；区分「患者报告」与「临床判断」
12. 复盘：选一例「审方未拦、随访才发现」的案例，写清漏点与改法

## H.5 模板：中药处方审核与随访记录表

| 字段 | 填写要求 |
|------|----------|
| 处方标识 | 处方号、医师、日期、诊断与证候 |
| 剂量核对 | 超标饮片、实测剂量、上限、处理 |
| 配伍与禁忌 | 十八反/十九畏/妊娠禁忌核查结论 |
| 毒性饮片 | 品种、剂量、双签名 |
| 特殊煎法 | 逐味标注与交代方式 |
| 发药交代 | 煎法、服法、忌口、复述确认 |
| 干预记录 | 问题、依据、处理、结果 |
| 随访 | 时点、依从性、症状变化、不良反应 |
| 上报 | 不良反应上报编号与时间 |
| 统计 | 干预类型、依从性、不良反应计数 |

> 本表是本章的交付物：每日一张汇总；干预项与随访逐条登记，月末统计。

## H.6 常见失效与处置

- **审方只看剂量不看配伍** → 十八反与妊娠禁忌更常被漏，且后果更重
- **交代只说「按说明吃」** → 未复述即未交代；关键三条必须听到患者说出来
- **特殊煎法漏标** → 包煎、先煎、后下漏掉会直接影响疗效与安全
- **随访只问「有没有效」** → 没有依从性与不良反应记录，等于没随访
- **不良反应不报** → 漏报会被视为隐瞒，且失去改进依据
- **统计把患者主观感受当临床结论** → 两者必须分栏，否则数据不可用

## H.7 出科考核

- 审方准确率与干预依据（35%）
- 交代与复述确认（20%）
- 随访完整性与不良反应处理（25%）
- 记录与统计规范（10%）
- 复盘质量（10%）
