# 第 6 章 · 生殖与遗传毒性：妊娠禁忌的分级

> **层次**：本文件是**本库撰写层**（无底本表，不是源正文层）。依据是 OECD 遗传毒性试验指南（TG 471 / 473 / 474 / 487 / 470）与遗传毒性总览文件，条文登记于 `standards/zhongyao-du-li/外源条文.json`（27 条，逐字可核）。
> **依据**：`standards/zhongyao-du-li/补源登记.json`（16 份来源 / 27 条，逐字可核 27/27）。
> **免责**：本章为遗传与生殖毒性的教学整理，不构成诊断或治疗建议；妊娠用药判断须由临床医师依说明书作出。

## 本章要回答的问题

为什么「做了 Ames 试验阴性」不能说明没有遗传毒性？因为**没有一项试验能覆盖所有遗传学终点**——这是 OECD 总览文件的明确结论。本章讲清三件事：遗传毒性为什么要用「组合」而不是「单项」、体内与体外各自不可替代的理由、以及这套数据如何支撑「妊娠禁忌」的分级。

> 「To adequately cover all the genetic endpoints, one must use multiple tests (i.e. a test battery), because no individual test can provide information on all endpoints.」（外源·Overview of the set of OECD Genetic Toxicology 第14条）

## N.1 概念与出处

七条条文，按「组合逻辑 → 各方法定位」排列：

| 条 | 方法 | 定位 |
|---|---|---|
| 外源·Overview of the set of OECD Genetic Toxicology 第14条 | 试验组合（battery） | **立论**：单项覆盖不了全部终点 |
| 外源·OECD Test Guideline 471 第1条 | 细菌回复突变（Ames） | 基因突变，最敏感、最便宜的初筛 |
| 外源·OECD Test Guideline 473 第2条 | 体外哺乳动物染色体畸变 | 结构畸变，补 Ames 的盲区 |
| 外源·OECD Test Guideline 487 第7条 | 体外微核（MNvit） | 结构与数目畸变，可替代 473 |
| 外源·OECD Test Guideline 474 第2条 | 体内哺乳动物微核 | 考虑代谢、药动、DNA 修复的真实结果 |
| 外源·OECD Test Guideline 474 第3条 | 体内微核的检测对象 | 对染色体结构或数目损伤的检测 |
| 外源·OECD Test Guideline 470 第2条 | 体内 Pig-a 基因突变 | 内源基因突变，可反复取样 |

关键对照在第 474 条第2条：**「factors of in vivo metabolism, pharmacokinetics and DNA repair processes are active」**——这正是体外试验的短板。体外系统没有完整的代谢活化、没有组织分布、没有修复动力学，所以体外阳性需要体内确认，体外阴性也不能替代体内。

## N.2 为什么可以这样翻译：三步组合与妊娠禁忌的三级

**第一步：初筛（基因突变）**。Ames（TG 471）用组氨酸/色氨酸缺陷株检测回复突变，成本低、通量高，是组合的第一块。

**第二步：体外染色体（结构/数目）**。TG 473 或 TG 487 二选一：前者看中期染色体结构畸变，后者看微核（结构 + 数目）。两者都能在加与不加代谢活化（S9）两种条件下做，覆盖「需代谢活化才致突变」的情形。

**第三步：体内确认**。TG 474（骨髓微核）或 TG 470（Pig-a）——体内试验回答的是「在活体里、经过吸收分布代谢后，是否仍然造成遗传物质损伤」。第 474 条第2条给的理由是三条真实变量：代谢、药动、修复。

**妊娠禁忌怎么分级**（这是中医学与现代毒理的接点，教材必须把两套语言对齐）：

| 传统表述 | 现代对应 | 数据来源 |
|---|---|---|
| 妊娠禁用（绝对禁忌） | 有生殖毒性阳性证据，风险明确大于获益 | 生殖毒性试验（Ⅰ/Ⅱ/Ⅲ段）+ 人用经验 |
| 妊娠慎用 | 无充分数据，或动物试验提示风险但人体证据不足 | 动物试验 + 临床监测 |
| 哺乳期慎用 | 乳汁分泌数据缺失或提示可分泌 | 药动学 + 上市后信号 |

教材不应把「十八反」「妊娠禁忌药」直接写成现代结论，也不应因其「未做现代试验」就删除：正确写法是**传统标注作为风险提示的来源，现代试验作为分级的依据**，两者分栏呈现。

**取样时间窗为什么是硬约束**：骨髓微核（TG 474）反映的是**近期**的染色体损伤，取样要落在受试物峰浓度之后的 24–48 小时内；Pig-a 试验（TG 470）靠外周血成熟红细胞累积突变，需要**数周**的观察窗才能读出上升。两者的时间尺度差一个数量级，混用会得出「同一个药一个阳性一个阴性」的假矛盾。教材必须把「终点 → 时间窗」写成对，否则学生只会记方法名，不会排实验。

## N.3 这个翻译丢掉了什么

- **不给生殖毒性三段试验的设计细节**：Ⅰ段（生育力与早期胚胎）、Ⅱ段（胚胎-胎仔发育）、Ⅲ段（围产期）的给药窗口、动物数与观察指标不在本课条文内（现有 27 条无生殖毒性专条，这是**本课明确缺口**）。
- **不给妊娠禁忌药物名单**：药典与各版教材有名单，且名单随证据更新。
- **不给阳性结果的判定标准**：统计学显著 ≠ 生物学相关，需结合剂量-反应、历史对照、重现性。
- **不给 Pig-a 的取样与流式方案**：方法学细节在 TG 470 正文。
- **不给遗传毒性杂质的限度**：ICH M7 那套（致突变杂质分类与限度）针对化学药杂质，中药复方的适用性需另行论证。

## N.4 与相邻学科的接口

| 相邻学科 | 接口 |
|---|---|
| 中药化学 | 成分的致突变性预测（构效关系），决定做哪些试验与如何解释阳性 |
| 中药炮制学 | 炮制对毒性成分的转化，可能同时改变遗传毒性结果 |
| 临床中药学 | 妊娠期用药的实际判断与替代方案 |
| 药事管理 | 说明书「孕妇及哺乳期妇女用药」项的写法与依据 |

## N.5 争议与本项目立场

**争议一：中药复方一定要做全套遗传毒性吗？** 按暴露与人群定：拟用于育龄人群、长期给药、或含有已知致突变结构类成分的，应做组合；经典名方类可依指导原则简化，但**简化不等于不做**（第 8 章条文要求一般包括单次与重复给药毒性，遗传毒性按情形）。

**争议二：体外阳性、体内阴性怎么判？** 这是最常见的结果组合。本项目立场：以体内结果为主，但必须解释体外阳性的原因（代谢活化差异、体外浓度超出暴露量、试验系统假阳性），并把解释写进报告——**不能只写「体内阴性，判为无遗传毒性」**。

**争议三：Ames 阴性就够了吗？** 不够。Ames 只测基因突变，对染色体结构/数目畸变不敏感；第 14 条的「组合」要求正是为此。教材若把 Ames 当作唯一指标，学生就会误以为「阴性 = 安全」。

> **免责**：本章所列条文与判据不构成诊断或治疗建议；妊娠与哺乳期用药须由临床医师依说明书与患者情况判断。

## 小结

1. 遗传毒性必须用试验组合，单项覆盖不了全部终点（总览 第14条）。
2. Ames 测基因突变，473/487 测染色体，474/470 做体内确认。
3. 体内不可替代的理由是代谢、药动、DNA 修复三者在活体内同时成立（TG 474 第2条）。
4. 妊娠禁忌分级要「传统标注」与「现代证据」分栏，不许互相顶替。
5. 本课现无生殖毒性专条，三段试验细节是**明确缺口**。
