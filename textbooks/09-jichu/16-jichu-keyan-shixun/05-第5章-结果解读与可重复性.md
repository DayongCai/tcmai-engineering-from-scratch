## H.1 本章要解决的问题

一次实验有差异就下结论，是实训里最常见的过度解读。可重复性要求独立重复至少两次。

## H.2 本章目标（可检验）

- 完成一次独立重复并比较
- 写出结果的可信区间与不确定处
- 列出至少两条替代解释

## H.3 操作流程

1. 重复：换一天、换一批试剂独立再做一次
2. 比较：两次结果是否同向、幅度是否接近
3. 找替代解释：批次、操作者、环境、测量
4. 定结论强度：肯定、提示、不能判断
5. 写记录：把两次原始数据都留下

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 独立重复已完成
- [ ] 两次结果同向性已写
- [ ] 幅度差异已说明
- [ ] 替代解释≥2 条
- [ ] 结论强度已分级
- [ ] 原始数据两份都在
- [ ] 与假设对照

## H.5 模板：重复与解读表

| 字段 | 填写要求 |
|------|----------|
| 重复 | 时间、批次、操作者 |
| 结果比较 | 同向性与幅度 |
| 替代解释 | ≥2 条 |
| 结论强度 | 肯定/提示/不能判断 |
| 不确定处 | 具体写 |

> 本表是本章的交付物：结果章讨论部分的基础。

## H.6 常见失效与处置

- **一次实验定结论** → 须独立重复
- **把「没差异」当「无效」** → 可能是检验效能不足
- **不写替代解释** → 评审第一问就是它

## H.7 出科考核

- 重复执行（40%）
- 解读克制（30%）
- 替代解释（30%）
