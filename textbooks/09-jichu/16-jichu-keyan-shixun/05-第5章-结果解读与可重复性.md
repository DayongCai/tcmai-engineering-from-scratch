## H.1 本章要解决的问题

「有统计学差异」与「有生物学意义」是两件事。样本足够大时，任何微小差异都能显著；样本太小时，真实效应也可能测不出。结果解读要回答的是三层问题：差异有多大、是否可信、能否推广——三层都不是 p 值能单独回答的。

## H.2 本章目标（可检验）

- 按「效应量—不确定性—边界」三层解读结果，区分统计显著与生物学意义
- 识别并说明本研究的局限（样本、模型、测量、偏倚）
- 完成一次可重复性自查：他人按记录能否得到同样结果

## H.3 操作流程

1. 先看设计与对照是否成立：对照是否如预期、质控是否通过；不成立则先修实验而不是解读
2. 效应量：差异的绝对大小与相对大小（倍数、百分比、标准化效应量），结合临床或生物学阈值判断意义
3. 不确定性：置信区间宽度、样本量、变异来源；区间跨过无效值时不下「有效」结论
4. 一致性与剂量关系：多个指标是否同向、是否存在剂量或时间梯度（支持因果的间接证据）
5. 替代解释：列出三种可能的替代解释（批次、操作者、测量偏倚、样本选择），逐条给排除依据
6. 外推边界：模型（细胞/动物/人）、样本特征（年龄、性别、病程）、实验条件（浓度、时长）对推广的限制
7. 阴性结果解读：区分「确无效应」与「检验效能不足」——后者需要给出最小可检测效应
8. 可重复性自查：按记录让同组同学复跑一个关键步骤；不一致时定位是记录缺失还是操作差异
9. 结论分层：确定结论/提示性结论/无法结论三档，各附证据
10. 记录：按 H.5 模板填「结果解读记录表」，三层结论分开写
11. 汇报准备：一页纸讲清「发现了什么、有多可信、能用在哪、不能用在哪」
12. 复盘：挑一个「显著但无生物学意义」的例子，说明为何不能写进结论

## H.5 模板：结果解读记录表

| 字段 | 填写要求 |
|------|----------|
| 对照与质控 | 是否如预期，不成立时的处置 |
| 效应量 | 绝对差、相对差、标准化效应量 |
| 不确定性 | 95% CI、样本量、变异来源 |
| 一致性与梯度 | 多指标同向性、剂量/时间关系 |
| 替代解释 | 三条及排除依据 |
| 外推边界 | 模型、人群、条件限制 |
| 阴性结果 | 最小可检测效应或效能说明 |
| 可重复性 | 复跑步骤、差异、定位 |
| 结论 | 确定/提示/无法结论 + 证据编号 |
| 汇报要点 | 能用在哪、不能用在哪 |

> 本表是本章的交付物：分析完成后填写；三档结论与替代解释是汇报的必答项。

## H.6 常见失效与处置

- **p<0.05 即下结论** → 缺效应量与区间，读者无法判断实际意义
- **忽略样本量** → 大样本的微小差异常无生物学意义
- **不列替代解释** → 无法排除批次与操作者效应
- **阴性结果写成「无效」** → 可能是效能不足，需给最小可检测效应
- **外推无边界** → 细胞结果直接推到临床，是最常见过度解读
- **不做可重复性自查** → 记录缺失在别人复跑时才暴露

## H.7 出科考核

- 三层解读的完整性（35%）
- 替代解释与边界（30%）
- 阴性结果处理（15%）
- 可重复性自查（20%）
