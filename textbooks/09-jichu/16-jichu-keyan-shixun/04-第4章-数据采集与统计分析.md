## H.1 本章要解决的问题

统计错误里最常见的一类不是算错，而是「检验方法用错」：把配对数据当独立样本、把多组两两 t 检验当方差分析、把重复测量当单点比较。另一类是「先看图再选检验」，让数据去迁就方法。这一章要把分析计划写在看数据之前。

## H.2 本章目标（可检验）

- 建立规范的原始数据表（一行一个观测、一列一个变量、含分组与批次）
- 按数据类型与设计选择检验方法，并在分析前写下分析计划
- 报告结果时给出效应量、置信区间与样本量，而不只是 p 值

## H.3 操作流程

1. 数据表规范：一行一个观测；列名英文短名 + 数据字典（含义、单位、允许值）；缺失值用统一编码而非空格
2. 数据清洗：记录清洗规则（剔除标准、异常值处理），清洗前后各留一份数据，不覆盖原始文件
3. 变量类型确认：连续/分类/有序；分组变量与配对变量分开（配对关系必须显式记录）
4. 分析计划：在看主要结果前写清——主要终点、检验方法、显著性水平、亚组分析、缺失值处理
5. 方法选择：两组独立连续→独立样本 t 或秩和；两组配对→配对 t 或符号秩；多组→方差分析或 Kruskal-Wallis + 事后检验；分类→卡方或 Fisher；相关→Pearson/Spearman
6. 前提检查：正态性（Shapiro-Wilk 或 QQ 图）、方差齐性；不满足时用非参数方法并说明
7. 多重比较：多组或多终点时做校正（Bonferroni/Holm/FDR），写出校正方法
8. 效应量与区间：报告均值差或 OR/HR 与 95% 置信区间；p 值单独不构成结论
9. 图表：散点/箱线展示分布，避免只用柱状图掩盖分布；误差线注明是 SD 还是 SEM
10. 结果核对：由第二人用脚本或独立复算核对主要数字；脚本与数据一并保存
11. 记录：按 H.5 模板填「数据分析记录表」，含分析计划与偏离说明
12. 复盘：挑一个「换检验方法后结论变化」的例子，说明为何要预设分析计划

## H.5 模板：数据分析记录表

| 字段 | 填写要求 |
|------|----------|
| 数据来源 | 文件路径、版本、行数、变量数 |
| 数据字典 | 变量名、含义、单位、允许值 |
| 清洗规则 | 剔除标准、异常值处理、缺失值处理 |
| 分析计划 | 主要终点、检验方法、显著性水平、亚组 |
| 方法选择依据 | 变量类型、设计（配对/独立）、前提检查结果 |
| 多重比较 | 方法、校正后阈值 |
| 结果 | 效应量、95% CI、p 值、样本量 |
| 图表 | 类型、误差线含义 |
| 复算 | 复算人、脚本路径、差异说明 |
| 偏离 | 与计划的差异及原因 |

> 本表是本章的交付物：分析前写计划栏，分析后写结果与偏离；随报告归档，供复算。

## H.6 常见失效与处置

- **配对数据当独立样本** → 统计效能与 p 值都会被高估，是常见的致命错误
- **多组反复做 t 检验** → I 类错误膨胀；应做方差分析 + 事后检验
- **先看图再选检验** → 选择性报告，结论不可信
- **只报 p 值** → 不报效应量与区间，读者无法判断实际意义
- **柱状图掩盖分布** → 小样本时尤为重要；应展示散点
- **覆盖原始数据** → 清洗错误无法回溯，数据不可复核

## H.7 出科考核

- 数据表与清洗规范（25%）
- 方法与前提检查（30%）
- 报告完整性（效应量/CI/校正，25%）
- 复算与可复现（20%）
