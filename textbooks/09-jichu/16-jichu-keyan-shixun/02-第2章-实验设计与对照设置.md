## H.1 本章要解决的问题

「做了三组，结果不一样」不是结论，除非你知道差异来自处理还是来自批次、操作者或时间。实验设计要解决的就是把「变量」隔离出来：谁是对照、什么是重复、分组怎么随机、盲法可不可行。设计没想清就动手，通常的结果是重复三次也说不清为什么。

## H.2 本章目标（可检验）

- 写出可执行的实验方案：假设、分组、样本量、随机化、盲法、主要终点
- 正确设置阴性对照、阳性对照与空白对照，并说明各自作用
- 识别方案中的混杂因素并给出控制措施

## H.3 操作流程

1. 假设表述：写成可检验的形式（处理 X 相对对照 Y 使指标 Z 变化 Δ），避免「探索一下」
2. 确定主要终点：一个主要指标 + 若干次要指标；主要指标决定样本量
3. 分组设计：对照组（阴性/阳性/空白）、剂量组、时间点组；组数与每组例数写清
4. 样本量估算：给出依据（预实验标准差、文献效应量、检验水准与把握度），无法估算时说明先用预实验
5. 随机化：随机分组方法（抽签、随机数表、软件），记录种子；避免「按到达顺序交替」
6. 盲法：可实施程度（样本编码、第三方揭盲）；不能盲时说明可能偏倚方向
7. 混杂控制：批次、操作者、时间、温度、试剂批号、动物周龄与性别；能配对的配对，能分层的分层
8. 重复与独立：生物学重复与技术重复分开记；技术重复不能代替生物学重复
9. 方案文档：一页纸写清上述要素 + 试剂与设备清单 + 时间表，经带教签字后执行
10. 预实验：小样本验证流程可跑通、效应量可估、变异可知，再做正式实验
11. 变更记录：执行中任何变更写「原方案—变更—原因—对结论的影响」
12. 复盘：挑一个「没设阳性对照导致无法解释阴性结果」的例子，说明代价

## H.5 模板：实验方案与分组表

| 字段 | 填写要求 |
|------|----------|
| 假设 | 处理、对照、指标、预期方向 |
| 终点 | 主要指标、次要指标、测量方法 |
| 分组 | 组名、处理内容、每组例数、对照类型 |
| 样本量 | 估算依据或预实验说明 |
| 随机与盲法 | 方法、种子、编码方式、揭盲规则 |
| 混杂控制 | 批次、操作者、时间、试剂批号、个体特征 |
| 重复 | 生物学重复数、技术重复数 |
| 材料与时间表 | 试剂、设备、关键时间点 |
| 变更记录 | 原方案、变更、原因、影响 |
| 签字 | 设计人、带教、日期 |

> 本表是本章的交付物：实验前定稿并签字；分组表按实际编号填写，作为数据录入的对照依据。

## H.6 常见失效与处置

- **无阳性对照** → 阴性结果无法解释：是没效应还是实验失败
- **技术重复当生物学重复** → 统计上会严重高估把握度
- **按到达顺序分组** → 引入系统性偏倚；必须随机化
- **样本量凭感觉** → 例数不足会导致「有效应也测不出」
- **不控批次与操作者** → 差异可能全来自批次，处理效应被掩盖
- **变更不记录** → 结果与方案不符，数据不可用
