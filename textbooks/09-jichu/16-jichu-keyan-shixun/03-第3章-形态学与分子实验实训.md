## H.1 本章要解决的问题

形态学与分子实验的失败大多是「没记录关键步骤」：切片厚度、抗体稀释、循环数，一项缺失就无法排查。

## H.2 本章目标（可检验）

- 能按标准完成一类形态学与一类分子操作
- 逐步记录关键参数
- 能对失败结果给出排查路径

## H.3 操作流程

1. 选项目：形态学（切片/染色）或分子（PCR/WB）各一
2. 照规程：抄下关键参数与时限
3. 操作：每步记录实际值
4. 留样：保留中间产物与图像
5. 排查：失败时按试剂—操作—设备三线排查

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 关键参数已逐步记录
- [ ] 试剂批号与配制日期已记
- [ ] 设备编号与设置已记
- [ ] 中间产物已留样
- [ ] 图像含标尺或分子量标记
- [ ] 失败排查三线已用过
- [ ] 结果判读标准已写

## H.5 模板：实验操作记录表

| 字段 | 填写要求 |
|------|----------|
| 参数 | 关键步骤实际值 |
| 试剂 | 批号、配制日期 |
| 设备 | 编号、设置 |
| 留样 | 中间产物与位置 |
| 判读 | 标准与结果 |
| 排查 | 失败时的三线检查 |

> 本表是本章的交付物：每次实验一张，原始记录不得誊抄。

## H.6 常见失效与处置

- **事后誊抄记录** → 原始记录才有证据力
- **不记批号** → 批次差异无法追溯
- **图像无标尺** → 形态学结论不可复核

## H.7 出科考核

- 记录原始性（40%）
- 参数完整（30%）
- 排查能力（30%）
