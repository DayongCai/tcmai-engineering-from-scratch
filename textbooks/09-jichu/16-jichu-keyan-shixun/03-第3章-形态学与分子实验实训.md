## H.1 本章要解决的问题

形态学与分子实验的共同点是：结果高度依赖操作细节，而细节常常没被记录。同一切片不同批次染色，颜色差异可能来自抗体批号而不是处理；同一批 PCR 的 CT 值偏差可能来自加样误差。实训要证明的是「操作可复现」，而不是「这次做出来了」。

## H.2 本章目标（可检验）

- 独立完成一套形态学流程（固定、包埋、切片、染色）并记录关键参数
- 独立完成一次核酸提取与扩增，记录试剂批号、循环参数与质控结果
- 识别并记录三类常见失败（染色背景高、无扩增、条带异常）及排查顺序

## H.3 操作流程

1. 样本与登记：样本编号、取材部位、固定液与固定时间（形态学）；保存条件与冻融次数（分子）
2. 试剂与批号：抗体/引物/酶/试剂的厂家、货号、批号、配制日期；不同批号不得混用而不记录
3. 形态学流程：脱水透明、包埋、切片厚度、烤片温度与时间、脱蜡、抗原修复方式与时间、封闭、一抗浓度与孵育条件、二抗、显色时间、复染
4. 质量控制（形态学）：阳性对照组织与阴性对照（省略一抗），确认染色特异性
5. 核酸提取：裂解、结合、洗涤、洗脱体积；测浓度与纯度（A260/280、A260/230）
6. 扩增：反应体系（体积、引物浓度、模板量）、循环参数（退火温度、循环数）、熔解曲线或电泳验证
7. 质控：阴性对照（无模板）无菌生长/无扩增，阳性对照有预期信号
8. 数据记录：图像采集参数（曝光、放大倍数）、CT 值、电泳图；原始文件命名与编号一致
9. 失败排查顺序：先查对照（是否成立）→ 查试剂（批号/有效期/冻融）→ 查操作（加样、温度、时间）→ 查样本（降解/浓度）
10. 重复与验证：关键结果至少两次独立重复；不一致时保留两次记录而非择一
11. 记录：按 H.5 模板填「形态学/分子实验记录表」，参数栏不得写「按常规」
12. 复盘：挑一次失败实验，写清排查路径与最终原因

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 样本编号、取材、固定/保存条件已记录
- [ ] 试剂厂家、货号、批号、配制日期齐全
- [ ] 形态学全流程关键参数已记（厚度、修复、抗体浓度、孵育、显色）
- [ ] 形态学含阳性对照与省略一抗的阴性对照
- [ ] 核酸浓度与纯度已测并记录
- [ ] 扩增体系与循环参数已记录
- [ ] 无模板阴性对照与阳性对照结果已记录
- [ ] 图像/CT/电泳原始文件命名与编号一致

## H.5 模板：形态学/分子实验记录表

| 字段 | 填写要求 |
|------|----------|
| 样本 | 编号、部位、固定/保存条件、冻融次数 |
| 试剂 | 厂家、货号、批号、配制日期 |
| 流程参数 | 厚度、修复方式与时间、抗体浓度、孵育、显色 |
| 对照 | 阳性对照、阴性对照（省略一抗/无模板）结果 |
| 分子质控 | 浓度、纯度、CT 值、熔解或电泳结果 |
| 原始数据 | 图像参数、文件命名与路径 |
| 失败排查 | 现象、排查步骤、结论 |
| 重复 | 重复次数、结果一致性 |
| 签名 | 操作人、带教、日期 |

> 本表是本章的交付物：每次实验一张；参数与批号当场填，原始文件路径写在表尾。

## H.6 常见失效与处置

- **不记抗体批号** → 批间差异被误判为处理效应
- **省略阴性对照** → 背景高时无法判断是特异性还是非特异
- **固定时间随意** → 形态与抗原性都受影响，且无法追溯
- **无模板对照省略** → 污染导致的假阳性无法识别
- **重复不一致只报一次** → 属选择性报告，数据不可信
- **参数写「按常规」** → 他人无法复现，等于没有方法

## H.7 出科考核

- 参数与批号记录完整性（30%）
- 对照设置与质控（30%）
- 失败排查与重复（25%）
- 原始数据管理（15%）
