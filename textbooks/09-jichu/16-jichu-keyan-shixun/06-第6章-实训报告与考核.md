# 第 6 章 · 实训报告与考核

> **课程**：科研实训与实验设计（🧬 基础医学院 · 第 9 学期 · 108 学时 · 轮转/实践）
> **契约**：**操作型章（handbook-v1）** —— 本文件是工作手册，不是学术教材：给的是当场能执行的流程、清单与模板。

## H.1 本章要解决的问题

实训报告最常见的写法是「按时间顺序记流水」：先做了什么、再做了什么、结果是图 1 到图 5。读者要的是另一套结构：问题是什么、怎么做的、数据支持什么、哪里还说不清。报告是给人判断用的，不是给自己留纪念的。

## H.2 本章目标（可检验）

- 写出一份含问题、方法、结果、讨论、局限五部分的实训报告
- 报告中每个数字都能追溯到原始记录与脚本
- 通过一次操作考核与答辩，能回答「如果结果不成立，最可能是哪一步错了」

## H.3 操作流程

1. 确定主线：一句话说清「本实训验证了什么」，全文围绕它取舍材料
2. 方法：写清样本、试剂批号、参数、仪器型号与软件版本，使他人可复现
3. 结果：按「主要终点—次要指标—质控结果」顺序呈现；图表一图一结论，图注含 n 与误差线含义
4. 质控呈现：对照结果必须出现在结果部分，而不是附录
5. 讨论：把结果放回问题——支持了什么、与文献是否一致、不一致的可能原因
6. 局限：样本量、模型、测量方法、单一操作者、时间跨度，逐条写并说影响方向
7. 结论分层：确定/提示/无法结论，各附图表编号
8. 引用：原始文献，写明方法来源的出处
9. 自查：逐条核对「每个数字有来源、每张图有 n、每个结论有图表支撑」
10. 操作考核：抽一项核心操作完成全流程，边做边说关键参数与质控点
11. 答辩：10 分钟陈述 + 追问（含「结果不成立最可能是哪一步」）
12. 归档：报告、原始记录、数据与脚本、操作评分四件一并交

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 主线一句话明确，全文围绕它
- [ ] 方法与参数含试剂批号、仪器型号、软件版本
- [ ] 结果按主要终点—次要指标—质控顺序呈现
- [ ] 对照结果出现在结果部分
- [ ] 讨论回答与文献一致/不一致的原因
- [ ] 局限逐条写并说明影响方向
- [ ] 结论分三档并附图表编号
- [ ] 引用标明方法出处
- [ ] 自查过数字来源、图注 n、结论支撑

- [ ] 答辩能回答「最可能哪一步错」

## H.5 模板：实训报告结构与考核评分表

| 字段 | 填写要求 |
|------|----------|
| 主线 | 一句话：验证了什么 |
| 方法 | 样本、试剂批号、参数、仪器、软件版本 |
| 结果 | 主要终点、次要指标、质控结果；图表编号与 n |
| 讨论 | 支持了什么、与文献一致性、原因 |
| 局限 | 逐条 + 影响方向 |
| 结论 | 确定/提示/无法结论 + 图表编号 |
| 引用 | 方法与结论来源 |
| 操作考核 | 流程、参数、质控点、规范 |
| 评分 | 数据可溯源 30%、方法可复现 25%、解读分寸 25%、操作与答辩 20% |
| 归档 | 报告、原始记录、数据脚本、评分表 |

> 本表是本章的交付物：按左栏写作，右栏现场评分；报告与评分一并归档。

## H.6 常见失效与处置

- **写成实验流水账** → 没有主线，读者无法判断价值
- **方法缺批号与版本** → 他人无法复现，等于没有方法
- **对照放附录** → 质控是结果的一部分，藏起来等于回避
- **图注无 n 与误差线含义** → 读者无法判断可靠性
- **局限写套话** → 「时间有限」不算局限分析
- **结论超出数据** → 小样本探索性结果写成确定结论，属过度解读

## H.7 出科考核

- 数据可溯源（30%）
- 方法可复现（25%）
- 解读分寸与局限（25%）
- 操作与答辩（20%）
