## H.1 本章要解决的问题

实验室事故多半不是操作难度造成的，而是「以为知道」：试剂混放、废液乱倒、离心机不平衡。

## H.2 本章目标（可检验）

- 能说清本实验室五类风险与对应防护
- 能正确分类处置废液与锐器
- 能在事故发生时按流程处置并上报

## H.3 操作流程

1. 读守则：找出本实验室的高危试剂与设备清单
2. 走流程：按标识走一遍危化品柜、废液桶、洗眼器、灭火器位置
3. 穿防护：手套、护目镜、白大衣缺一不进
4. 做分类：有机废液、含重金属废液、生物废弃物分桶
5. 演练：小面积泼溅与锐器伤的处置步骤口述一遍

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 高危试剂与设备清单已记
- [ ] 洗眼器与灭火器位置已知
- [ ] 防护三件齐备
- [ ] 废液分类规则已记
- [ ] 锐器处置方式已知
- [ ] 泼溅与刺伤处置流程能口述
- [ ] 紧急联系人与电话已记

## H.5 模板：实验室安全自查表

| 字段 | 填写要求 |
|------|----------|
| 高危清单 | 试剂与设备 |
| 应急位置 | 洗眼器、灭火器、急救箱 |
| 防护 | 三件是否齐备 |
| 废弃物 | 分类与投放点 |
| 处置流程 | 泼溅/刺伤步骤 |
| 联系人 | 电话与位置 |

> 本表是本章的交付物：进实验室第一周提交，之后每学期复核。

## H.6 常见失效与处置

- **戴手套代替洗手** → 手套破损不自知；离开前必须洗手
- **废液混倒** → 可能产生反应或污染整桶
- **离心机目视平衡** → 须对称配平到克级

## H.7 出科考核

- 自查表完整（40%）
- 处置流程口述（30%）
- 实操规范（30%）
