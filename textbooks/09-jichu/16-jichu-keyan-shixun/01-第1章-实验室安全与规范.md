# 第 1 章 · 实验室安全与规范

> **课程**：科研实训与实验设计（🧬 基础医学院 · 第 9 学期 · 108 学时 · 轮转/实践）
> **契约**：**操作型章（handbook-v1）** —— 本文件是工作手册，不是学术教材：给的是当场能执行的流程、清单与模板。
> **前置**：药理学、病理生理学、流行病学
> **本章产出物**：实验室安全核查与处置记录表
> 学术型教材的 N.1–N.5 契约（含 N.3「这个翻译丢掉了什么」）**不适用**本课程，理由见 `textbooks/README.md`「操作型章契约」。

## H.1 本章要解决的问题

实验室事故的绝大多数不是「不会操作」，而是「以为没事」：不戴手套配试剂、废液倒进水槽、高压锅没等压力降就开盖。安全规范之所以要写成动作而不是原则，是因为出事那一刻没人会去回忆原则。这一章的目标是：把每一次进实验室前的检查做成固定动作。

## H.2 本章目标（可检验）

- 独立完成一次实验前安全核查并填写核查表
- 掌握四类风险（化学、生物、电气、压力容器）的防护与应急处置
- 正确完成三类废物（化学废液、生物废弃物、锐器）的分类处置

## H.3 操作流程

1. 准入确认：培训与考核记录、门禁权限、实验区与生活区分离
2. 个人防护：实验服、护目镜、手套（材质与试剂匹配）、长发束起、禁穿露趾鞋
3. 通风与设施：通风橱风速检查、洗眼器与淋浴器位置、灭火器与沙箱位置与有效期
4. 化学品管理：危险化学品清单、存放（酸碱分开、氧化剂隔离）、标签完整（名称、浓度、日期、责任人）
5. 配制与操作：在通风橱内进行挥发性操作、禁止口吸移液、加热密闭容器禁止
6. 生物安全：生物安全柜使用（气流与操作规范）、样本标识、锐器处理、溢出处置流程
7. 电气与设备：插座与线缆检查、设备接地、离心机配平与盖锁、高压灭菌锅操作与压力确认
8. 实验前核查：按核查表逐项打勾（防护、通风、试剂标签、设备状态、应急设施），未打勾不得开始
9. 实验后整理：台面消毒、试剂归位、废物分类、设备关闭与登记
10. 应急处置演练：化学溅入眼（立即洗眼 ≥15 分钟并就医）、皮肤接触（冲洗并查 SDS）、小火（灭火器或沙）、大面积泄漏（疏散并报告）
11. 记录：按 H.5 模板填「实验室安全核查与处置记录表」；事故与近失事件（未造成伤害的险情）同样记录
12. 复盘：写出一条自己曾忽视的风险点与改进动作

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 准入培训与门禁确认
- [ ] 个人防护四项齐全（实验服、护目镜、手套、鞋）
- [ ] 通风橱、洗眼器、灭火器位置与状态已确认
- [ ] 危险化学品清单与存放合规，标签完整
- [ ] 挥发性操作在通风橱内，未口吸移液
- [ ] 生物安全柜与锐器处置规范已执行
- [ ] 设备接地、离心配平、灭菌锅压力确认
- [ ] 实验前核查表逐项打勾
- [ ] 实验后台面消毒、试剂归位、设备登记
- [ ] 三类废物分类正确
- [ ] 应急处置流程能口述并演练
- [ ] 近失事件已记录

## H.5 模板：实验室安全核查与处置记录表

| 字段 | 填写要求 |
|------|----------|
| 准入与防护 | 培训记录、门禁、防护装备检查 |
| 设施 | 通风橱风速、洗眼器、灭火器、沙箱 |
| 化学品 | 清单、存放分区、标签、SDS 可及 |
| 生物安全 | 安全柜状态、样本标识、锐器处置 |
| 设备 | 接地、配平、灭菌锅压力与温度 |
| 核查打勾 | 逐项确认与未通过项处置 |
| 废物 | 化学废液、生物废弃物、锐器等分类 |
| 事故/近失 | 时间、类型、处置、报告对象 |
| 演练 | 应急处置项目与用时 |
| 签名 | 核查人、带教、日期 |

> 本表是本章的交付物：每次实验前填一次核查；事故与近失事件另起一页写处置过程。

## H.6 常见失效与处置

- **凭记忆不填核查表** → 漏项无记录，事故后无法复盘
- **手套材质与试剂不匹配** → 乳胶手套挡不住有机溶剂，属常见误区
- **废液混倒** → 化学反应与污染风险；必须分类并标注
- **高压锅未降压开盖** → 蒸汽烫伤是实验室高发事故
- **只记事故不记近失** → 近失事件才是最便宜的学习材料
- **应急设施位置不知** → 洗眼器找不到时，每多一秒都影响预后

## H.7 出科考核

- 核查表执行与防护（一票否决：未完成核查即禁止实验）
- 四类风险处置（30%）
- 废物分类与记录（25%）
- 近失事件复盘（15%）
