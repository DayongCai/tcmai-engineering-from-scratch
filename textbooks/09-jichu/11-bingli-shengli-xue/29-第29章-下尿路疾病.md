## 29.1 上尿路与下尿路：一条功能分界线

尿路以膀胱为界分为两部分：

| | 上尿路 | 下尿路 |
|---|---|---|
| 组成 | 肾盂、肾盏、输尿管 | 膀胱、膀胱颈、尿道、盆底与括约肌 |
| 功能 | 生成并输送尿液 | 储存尿液、按意愿排出 |
| 动力 | 输尿管蠕动（自主、不受意识控制） | 逼尿肌收缩 + 括约肌松弛（受神经调控） |
| 梗阻后果 | 压力逆传至肾实质 → 肾积水、肾功能损害 | 排尿困难、尿潴留、反复感染、上尿路继发积水 |
| 典型症状 | 腰痛、肾绞痛、血尿 | 尿频、尿急、排尿踌躇、尿流细弱、尿失禁 |

**这条分界是本单元最重要的一句判断**：**上尿路的问题伤肾，下尿路的问题伤「排尿」**。看到腰痛伴血尿，先想上尿路（结石、感染、梗阻）；看到尿频尿急、排尿费力、尿失禁，先想下尿路（前列腺、膀胱、尿道、神经调控）。两者并非隔绝——下尿路长期梗阻会通过双侧上尿路积水反过来损害肾功能，这是「下病上及」的唯一通路，也是必须早期处理下尿路梗阻的理由。

## 29.2 储尿与排尿的神经调控

排尿是「储尿」与「排尿」两个相反过程的切换，依赖三级神经结构的协调：

**（1）外周神经**

- **副交感神经**（盆神经，S2–S4）：支配逼尿肌，兴奋时逼尿肌收缩、尿道内括约肌舒张 → **排尿**；
- **交感神经**（腹下神经，T10–L2）：作用于膀胱体 β₃ 受体使逼尿肌舒张，作用于膀胱颈 α₁ 受体使内括约肌收缩 → **储尿**；
- **躯体神经**（阴部神经，S2–S4）：支配尿道外括约肌与盆底肌，维持随意控制 → **控尿**。

**（2）脊髓反射**：骶髓存在基本的排尿反射弧（膀胱充盈 → 牵张感受器 → 骶髓 → 逼尿肌收缩）。婴幼儿此反射占主导，故排尿不受意识控制。

**（3）中枢调控**：脑桥存在**储尿中枢**与**排尿中枢**；大脑皮层（尤其额叶）对脑桥与骶髓施加抑制性控制，使排尿可在适当时间与地点进行。**皮层或传导通路受损（卒中、痴呆、脊髓损伤）→ 抑制丧失 → 尿急、尿频、尿失禁**，这是神经源性膀胱的常见机制。

储尿期的正常状态可概括为「**膀胱松弛、出口关闭**」；排尿期为「**膀胱收缩、出口开放**」。任何导致二者不协调的病变，都会产生相应的症状组合——这是分析下尿路症状的基本框架。

## 29.3 下尿路症状的分类

国际上把下尿路症状（lower urinary tract symptoms, LUTS）分为三组，这个分类直接对应功能异常：

**（1）储尿期症状**：尿频、尿急、夜尿、尿失禁。机制是膀胱容量减小、逼尿肌过度活动（不自主收缩）或感觉过敏。常见于膀胱炎、膀胱过度活动症、神经源性膀胱、前列腺增生早期。

**（2）排尿期症状**：排尿踌躇（等待）、尿流细弱、排尿费力、间断排尿、需腹压辅助。机制是**出口阻力增加**（前列腺增生、尿道狭窄、括约肌不松弛）或**逼尿肌收缩力下降**。

**（3）排尿后症状**：排尿不尽感、尿后滴沥、残余尿增多。机制是膀胱排空不全。

**症状组合的意义**：单纯储尿期症状多见于膀胱本身或神经调控问题；储尿期 + 排尿期症状并存多见于前列腺增生（出口梗阻引起逼尿肌继发改变）；排尿后症状突出提示**残余尿**，是感染与上尿路损害的风险标志。

需要强调的是：**症状的严重度与梗阻程度并不平行**。有的患者症状明显而梗阻轻，有的患者症状轻微却已有大量残余尿与上尿路积水（「沉默的梗阻」）。因此客观评估（残余尿、尿流率、影像）不可省略。

## 29.4 尿路梗阻：上、下尿路后果的比较

梗阻是下尿路疾病的核心机制之一，但同样是梗阻，位置不同后果迥异：

**上尿路梗阻（输尿管、肾盂输尿管连接部）**：压力直接作用于肾单位 → 肾积水 → 肾实质受压变薄 → 肾功能不可逆丧失。单侧者可无症状，双侧者迅速肾衰竭。

**下尿路梗阻（膀胱出口、尿道）**：膀胱先作为「缓冲」承受压力，通过**逼尿肌肥厚**代偿；代偿期可维持排尿，但膀胱内压升高 → **膀胱小梁形成、假性憩室**；失代偿后出现残余尿 → 反复感染、结石；压力继续逆传 → **双侧上尿路积水 → 肾功能损害**。

这条路径解释了一个临床现象：**长期前列腺增生的患者，首发就诊原因可能是「尿不出来」，也可能是「肾功能不全」**——后者说明梗阻已存在很久而未被察觉。

梗阻的常见原因按年龄与性别分布不同：儿童以先天性狭窄、后尿道瓣膜为主；青年男性以结石、尿道狭窄为主；老年男性以良性前列腺增生与前列腺癌为主；女性以盆底器官脱垂、术后粘连为主。

## 29.5 良性前列腺增生

**良性前列腺增生（benign prostatic hyperplasia, BPH）**是老年男性下尿路症状最常见的原因。其发生依赖两个条件：**年龄增长**与**有功能的睾丸**（双氢睾酮驱动）。

机制分两部分，必须分开理解：

**（1）静态因素（解剖性梗阻）**：前列腺移行带腺体与间质增生 → 压迫尿道 → 出口阻力增加。增生的程度与症状不完全相关，因为**梗阻还取决于前列腺的形态与包膜张力**（中叶突出者梗阻更明显）。

**（2）动态因素（张力性梗阻）**：前列腺与膀胱颈富含**α₁ 肾上腺素受体**，交感张力升高时平滑肌收缩，梗阻加重。这解释了为什么**受凉、饮酒、抗胆碱能药物、拟交感药物、憋尿**可诱发急性尿潴留——它们或增加交感张力，或削弱逼尿肌收缩。

**膀胱的继发改变**是决定预后的关键：

1. **代偿期**：逼尿肌肥厚、收缩力增强以克服阻力，患者可维持排尿但尿流变细、排尿费力；
2. **失代偿期**：逼尿肌纤维化、收缩力下降 → 残余尿增多 → 充盈性尿失禁（溢出性）；
3. **并发症**：反复尿路感染、膀胱结石、双侧肾积水与肾功能损害、急性尿潴留。

**护理与观察要点**：排尿日记（次数、量、夜尿）、残余尿评估、饮水与用药史（尤其抗胆碱能药与感冒药）、感染征象、以及**突然出现尿潴留或肾功能恶化时的应急评估**。具体药物与手术选择属临床决策，本讲义不涉及。

## 29.6 尿潴留与尿失禁

**尿潴留（urinary retention）**指膀胱内有尿而不能排出：

- **急性尿潴留**：突发、膀胱胀痛、无法排尿，属急症；常见诱因是梗阻基础上叠加交感兴奋（受凉、饮酒、手术、药物）；
- **慢性尿潴留**：逐渐发生，膀胱容量增大而感觉迟钝，患者可能仅有「排尿不尽」或「尿频」，最终以**充盈性（溢出性）尿失禁**表现——膀胱过度充盈后少量尿液不断溢出。**这种「尿失禁」实质是梗阻，不是控尿能力丧失**，导尿可引出大量尿液，是重要的鉴别点。

**尿失禁（urinary incontinence）**分四型，机制各不相同：

| 类型 | 机制 | 典型情形 |
|---|---|---|
| 压力性 | 盆底与尿道括约肌支持力下降，腹压升高时漏尿 | 咳嗽、喷嚏、大笑、跳跃时漏尿；经产妇、老年女性、前列腺术后 |
| 急迫性 | 逼尿肌不自主收缩（过度活动） | 突然强烈尿意后不能控制；膀胱炎、神经源性膀胱、特发性膀胱过度活动 |
| 充盈性（溢出性） | 膀胱排空不全、过度充盈 | 前列腺增生、糖尿病神经病变、药物性逼尿肌无力 |
| 功能性 | 排尿通路与环境、认知、行动能力不匹配 | 痴呆、行动不便、环境不便、镇静药物 |

**四型的处理方向完全不同**：压力性靠盆底肌训练与减重，急迫性靠膀胱训练与病因处理，充盈性必须解决梗阻或排空问题，功能性靠环境改造与照护协助。**误判类型会导致完全无效甚至有害的干预**（如把充盈性尿失禁当作急迫性而用抑制逼尿肌的药物，可能加重尿潴留）。

## 29.7 尿路感染

尿路感染（urinary tract infection, UTI）是最常见的下尿路疾病，按部位分**下尿路感染（膀胱炎）**与**上尿路感染（肾盂肾炎）**，后者属肾内疾病范畴（见第27章），但两者常连续发生。

**发病机制的核心是「上行感染」**：肠道菌群（以大肠埃希菌为主）定植于尿道口 → 上行至膀胱 → 黏附于尿路上皮（菌毛与受体结合）→ 增殖 → 炎症。少数经血行或淋巴播散。

**易感因素**可归纳为四类：

1. **尿液滞留**：梗阻、残余尿、憋尿、神经源性膀胱——尿液是良好的培养基，滞留即「培养」；
2. **黏膜屏障受损**：导尿、器械操作、性活动、绝经后雌激素下降致黏膜萎缩；
3. **病原体毒力**：菌毛黏附素、尿素酶、生物膜形成（导管相关感染的关键）；
4. **宿主防御下降**：糖尿病、免疫抑制、尿路结构异常（反流、结石）。

**为什么女性更易患**：尿道短而直、尿道口邻近肛门与阴道，上行距离短。**为什么妊娠期易患**：激素致输尿管蠕动减弱与肾盂扩张、子宫压迫致尿液滞留。

**临床表现的方向性**：膀胱炎以尿频、尿急、尿痛、下腹不适为主，可有血尿，**一般无高热**；肾盂肾炎则出现**高热、寒战、腰痛、肋脊角叩击痛**，可伴恶心呕吐——**发热与腰痛是「感染已上行」的信号**，必须区别对待。

**反复感染与复杂性感染**要寻找结构性原因：梗阻、结石、反流、糖尿病、导管。**不解决结构问题，单纯反复用药只会筛选出耐药菌**。

## 29.8 尿路结石

结石是上、下尿路都可见的疾病，其形成遵循一个物理化学框架：**过饱和 → 成核 → 结晶生长与聚集 → 滞留**。

**促进因素**：尿量少（浓缩）、高钙尿、高草酸尿、高尿酸尿、高胱氨酸尿、尿 pH 异常（酸性易形成尿酸与胱氨酸结石，碱性易形成磷酸铵镁与磷酸钙结石）、以及**抑制物缺乏**（枸橼酸、镁、焦磷酸抑制结晶）。

**感染性结石**是机制上的特例：产尿素酶的细菌（变形杆菌等）分解尿素 → 尿氨升高 → pH 升高 → 磷酸铵镁与碳酸磷灰石析出 → **鹿角形结石**。这类结石与感染互为因果：结石藏菌 → 感染持续 → 结石增大，形成闭环，**不彻底清除结石则感染无法根治**。

**临床表现**：结石在肾盂或输尿管移动时引起**肾绞痛**（腰部剧痛向腹股沟放射）、镜下或肉眼血尿、恶心呕吐；结石停留致梗阻 → 肾积水 → 感染 → 肾功能损害。

**护理与预防的方向**（不给具体方案）：增加尿量是最基础的措施；按结石成分调整饮食（如草酸钙结石限制高草酸食物与过量钠，尿酸结石减少嘌呤并碱化尿液）；监测复发（结石复发率高，需长期随访）。

## 29.9 神经源性膀胱

当支配膀胱的神经通路受损，储尿与排尿的协调被破坏，形成**神经源性膀胱（neurogenic bladder）**。其表现取决于**损伤平面**：

- **上运动神经元病变**（骶髓以上，如脊髓损伤、卒中、多发性硬化）：骶髓反射弧完整但失去上位抑制 → **逼尿肌过度活动、膀胱容量小、尿急尿失禁**，同时**逼尿肌-括约肌协同失调**（逼尿肌收缩时括约肌不松弛甚至收缩）→ 膀胱内高压 → **上尿路损害风险高**；
- **下运动神经元病变**（骶髓及以下，如马尾损伤、糖尿病神经病变、盆腔手术损伤）：反射弧中断 → **逼尿肌无反射、膀胱容量大而不收缩 → 充溢性尿失禁与大量残余尿**，感染与结石风险高。

**为什么这类患者必须长期随访上尿路**：膀胱内高压（尤其协同失调时）会逆传至肾，造成积水与肾功能损害——**这是神经源性膀胱最主要的致残与致死原因**，而患者往往只关注「尿失禁」这一表面问题。

**护理核心**：规律排空（定时排尿、间歇导尿）、控制膀胱内压、监测残余尿与感染、保护上尿路（影像随访）、皮肤与心理照护。具体导尿频次与方案属临床决策。

## 29.10 下尿路疾病的评估与感染预防

**评估框架**（从症状到机制）：

1. **症状归类**：储尿期 / 排尿期 / 排尿后，判断是「储不住」还是「排不出」；
2. **排尿日记**：记录时间、尿量、饮水、漏尿事件，是最廉价而信息量最大的工具；
3. **残余尿**：区分排空不全与单纯储尿问题；
4. **尿分析 + 尿培养**：判断有无感染、血尿、结晶；
5. **影像与内镜**：评估梗阻部位、结石、积水、前列腺形态；
6. **神经评估**：会阴感觉、肛门括约肌张力、球海绵体反射，判断有无神经源性成分。

**感染预防的机制性措施**（不给处方）：

- **减少滞留**：避免不必要的导尿，尽早拔除导管；必需时采用闭合引流系统并保持通畅（打折、逆流是感染的重要途径）；
- **保持尿量**：充足饮水稀释尿液、冲刷尿路；
- **会阴清洁与排便管理**：减少肠道菌群在尿道口的定植（女性便后从前向后擦拭）；
- **避免滥用抗生素**：防止菌群失调与耐药；
- **特殊人群**：绝经后女性关注黏膜萎缩、糖尿病患者控制血糖、梗阻者解除梗阻。

**一条必须记住的原则**：**无症状菌尿通常不需要处理，而导管相关感染的关键是「尽早拔管」而不是「换更高级的抗生素」**。这既符合机制（生物膜在导管表面形成，药物难以穿透），也符合抗菌药物合理使用的要求。

## 29.11 生命周期考量

**儿童**：排尿控制是发育过程，夜间遗尿在学龄前属常见现象；但**反复尿路感染、排尿异常、日间尿失禁**需警惕先天性结构异常（后尿道瓣膜、膀胱输尿管反流），因为反流可致肾瘢痕与高血压，损害在多年后才显现。

**孕妇**：子宫压迫与激素作用致输尿管扩张、蠕动减弱，尿液滞留 → 感染与结石风险升高；感染可诱发早产，故产前检查中的尿检不可省略。

**老年男性**：前列腺增生与前列腺癌是两大原因，二者可并存；症状相似而性质不同，需通过指检、影像与必要时的活检区分。

**老年女性**：绝经后雌激素下降致尿道黏膜萎缩、盆底支持减弱 → 压力性尿失禁与反复感染增多；同时合并用药（利尿剂、镇静剂、抗胆碱能药）常是症状加重的原因，**「先查用药清单」往往比「先加一种药」更有效**。

## 本章小结（Key Points）

- 尿路以膀胱为界：上尿路伤肾（积水、实质萎缩），下尿路伤排尿（梗阻、潴留、失禁）；下尿路长期梗阻可经双侧积水反过来伤肾；
- 储尿期「膀胱松弛、出口关闭」，排尿期「膀胱收缩、出口开放」，二者不协调即产生症状；下尿路症状分储尿期、排尿期、排尿后三组，分别对应储不住、排不出、排不尽；
- 良性前列腺增生由静态（腺体压迫）与动态（α 受体介导张力）两类因素构成，膀胱经历代偿肥厚到失代偿；
- 充盈性尿失禁实质是梗阻而非控尿丧失，误判会导致有害干预；
- 尿路感染以肠道菌群上行为主，滞留、黏膜损伤、毒力、防御下降是四类易感因素；发热与腰痛提示感染已上行；
- 结石形成遵循过饱和—成核—生长—滞留框架，感染性结石与感染互为因果；
- 神经源性膀胱按损伤平面分上、下运动神经元两型，前者上尿路损害风险更高。

## 单元临床案例（HPP-U08-CASE-01）

> 本案例中所有实验室与尿量参数均为**示意**，仅用于说明变化方向与机制，不代表任何诊断界值或分期标准。

**病例**：陈先生，68 岁。近半年夜尿增多、排尿等待、尿流变细，未就诊。三天前受凉后出现发热、下腹坠胀，自行服用非甾体抗炎药与复方感冒药（含抗胆碱能成分）。昨日至今晨几乎不能排尿，下腹膨隆、胀痛，伴恶心、乏力。查体：体温升高（示意），下腹可触及充盈膀胱，耻骨上叩诊浊音；双下肢轻度水肿。实验室：血肌酐较其既往记录明显升高（示意），血钾偏高（示意），尿分析见大量白细胞与细菌，尿比重偏低（示意）；泌尿系超声示双侧肾盂轻度扩张、前列腺体积增大、膀胱残余尿明显增多（示意）。

**问题**：

1. 请按「肾前性 / 肾性 / 肾后性」分析该患者急性肾功能恶化的原因，指出哪一项是主导因素，哪些是叠加因素。
2. 患者为何在受凉与服用感冒药后发生急性尿潴留？请从良性前列腺增生的静态与动态因素解释。
3. 尿比重偏低、夜尿增多提示什么？与本次急性事件是什么关系？
4. 若梗阻持续不解除，肾功能将沿什么路径恶化？请按第27、28章的机制说明。
5. 作为护士，你会在哪些环节设置观察点以防止进一步损害？

**要点参考**：

1. 主导因素为**肾后性**：前列腺增生致膀胱出口梗阻，残余尿增多、膀胱内压升高，压力逆传致双侧肾盂扩张，滤过压下降。叠加因素有二：**肾前性**成分——发热、进食减少与呕吐致容量不足，加之非甾体抗炎药抑制前列腺素使入球小动脉收缩、滤过压进一步下降；**肾性**风险——感染（肾盂肾炎）与药物毒性可造成小管间质损伤。三者共存，符合临床常见的「混合型」情形。
2. **静态因素**：增生腺体压迫尿道，出口阻力本已升高；**动态因素**：前列腺与膀胱颈 α₁ 受体在受凉、交感兴奋时张力升高，梗阻骤然加重；复方感冒药中的抗胆碱能成分削弱逼尿肌收缩，形成「出口更紧 + 动力更弱」的组合，遂致急性尿潴留。
3. 尿比重偏低与夜尿增多提示**浓缩能力下降**，符合慢性肾小管间质受累（长期梗阻致间质纤维化）的方向，说明梗阻并非三日之事，而是已存在数月；本次事件是在慢性损害基础上的**急性加重（急性-on-慢性）**。
4. 路径为：持续梗阻 → 肾盂与肾小管压力升高、囊内压上升 → 净滤过压下降 → 管周血管受压致局部缺血 → 小管上皮损伤与间质炎症 → 间质纤维化、肾实质变薄 → 肾单位不可逆丧失 → 残余肾单位高滤过代偿 → 肾小球硬化 → 慢性肾脏病进展；同时感染与结石风险升高，进一步加重损害。
5. 观察点：① **排尿与尿量**——是否真正排空、残余尿趋势、尿流特点；② **容量状态**——每日体重、出入量、水肿与肺部体征，警惕容量过负荷与脱水两个方向的偏差；③ **电解质与心律**——少尿伴酸中毒与组织损伤者警惕高钾，关注心电图方向性改变；④ **感染**——体温、尿液性状、腰痛与肋脊角叩击痛（提示感染上行）；⑤ **用药核对**——非处方止痛药、含抗胆碱能成分的感冒药、造影检查等肾毒性或影响排尿的因素；⑥ **梗阻解除后的多尿期**——尿量骤增时警惕容量不足与低钾，此时监测重点需从「少尿」转为「多尿」。

## N.2 为什么可以这样翻译

本章可译成**一台两态机加两个力**：

```
两个态：储尿＝膀胱松弛、出口关闭；排尿＝膀胱收缩、出口开放
两个力：P＝逼尿肌压，R＝出口阻力
储尿失败：P 在错误时刻升高（顺应性下降，或上位抑制丧失）
排尿失败：R 过高，或 P 过低
排空不全：P 与 R 失衡的积分 → 残余尿
四个观测量：排尿日记、残余尿、尿流率、尿分析与影像
```

这样译有三处对得上讲义：29.2 把储尿与排尿写成两套相反的神经支配，所以「两个态」不是修辞，是解剖事实；29.3 的三组症状正好落在「储不住」「排不出」「排不净」三个位置；29.5 的静态与动态因素，就是 R 的两个分量——一个来自腺体体积，一个来自平滑肌张力，后者解释了为什么受凉与憋尿能在一夜之间把 R 推上去。

最要紧的是这句话：**症状的严重度与 R 并不平行**（`第29章·29.3`）。所以模型里必须有一个**积分量**，把「一时的不顺」与「持续的排空不全」分开——这个量就是残余尿。它同时也是 29.4 那条「下病上及」的起点：残余尿 → 膀胱内压升高 → 压力逆传 → 双侧上尿路积水 → 肾功能损害。这条路径跨了本章与上一章，是本单元唯一必须连着读的一条线。

## N.3 这个翻译丢掉了什么

1. **三级神经结构被压成一个 P。** 骶髓反射弧、脑桥的储尿与排尿中枢、皮层的抑制（`第29章·29.2`）在模型里只剩一个压力。逼尿肌-括约肌协同失调就是「P 升而 R 不降」，两变量能表示它，却预测不出它——因为失调是时序问题，不是幅度问题。
2. **时间尺度跨了好几个数量级。** 急性尿潴留以小时计，前列腺增生的代偿以年计（`第29章·29.5`、`29.6`），同一个 R 的升高配两种节奏。静态的力平衡没有「多久」这一维。
3. **感染是活的东西。** 生物膜、耐药筛选、感染性结石的闭环（`第29章·29.7`、`29.8`）都需要「繁殖」这一维；P 与 R 都是力学量，装不进生长。
4. **功能性尿失禁整型落在模型外。** 四型里唯一「器官没问题」的一型，机制在通路、环境与认知（`第29章·29.6`），恰是最需要照护介入的一型。
5. **「沉默的梗阻」不可见。** 症状轻而残余尿多的人（`第29章·29.3`），在只靠问诊的模型里永远是轻症；要看见他，必须主动测量，模型本身不提供这个动作。

## N.4 与相邻学科的接口

- **生理学**：排尿反射、膀胱顺应性、括约肌的神经支配是零件说明书；本章只讲零件不协调时症状朝哪边偏。
- **第 26 章**：上尿路的输送靠蠕动，与下尿路的按意愿排出是两种动力，这是 29.1 那张表最容易被忽略的一行。
- **第 27、28 章**：梗阻性肾病与肾后性损伤是「下病上及」的落点，本章给入口，那两章给后果。
- **第 8、9 章**：上行感染在炎症一侧的写法（渗出、增生）与本章的「滞留即培养」是同一件事的两种语言。
- **第 43、45 章**：损伤平面决定膀胱表现，神经科的定位恰好是本章 29.9 二分的前提。
- **中医学**：淋证、癃闭是现象层的词，与「出口阻力升高」「逼尿肌无力」不是一一对应，只能并列，不能对译。
- **tcmP 平台**：桥接句是「两态机加两个力→状态机」，残余尿作积分判据。平台刻意不把两态合成一个严重度，否则「储不住」与「排不出」会被算成一回事。

## N.5 争议与本项目立场

**争议一：下尿路疾病按科室分，还是按功能分。** 按科室分符合就诊路径，按功能分符合机制。**本项目立场：按功能分。** 依据是 29.1 的分界表——它按「伤肾」还是「伤排尿」划线，而不是按谁来做手术划线；底本压根没有下尿路一节，也说明科室式划分在这本合并本里没有位置。

**争议二：无症状菌尿要不要处理。** **本项目立场：以不处理为原则，但本项目只写到「不滥用抗菌药物」这一层，不出方案。** 依据是 29.10 给出的机制理由（生物膜在导管表面形成，药物难以穿透），与底本 `教材·疾病学基础·第14章·14.4.2` 对耐药表述的边界要求；具体判断交回具备资质的人员。

**争议三：增生程度与症状不平行，说明什么。** **本项目立场：把「形态不等于功能」写成一条通则，而不是本章的例外。** 依据在底本自己手里：`教材·疾病学基础·第11章·11.2.3` 把结构与功能的关系分成同步、不同步、先行、滞后四类。本章只是把这四类用到膀胱上——增生是形态，残余尿是功能，两者不同步是常态。

> 本章改写层是教学解读，不构成诊断、治疗或用药依据。
