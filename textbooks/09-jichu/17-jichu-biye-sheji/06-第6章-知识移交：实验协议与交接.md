## H.1 本章要解决的问题

基础实验的可重复性死在细节上：细胞代次、抗体批号、诱导条件、门控策略。这些东西多数只存在于上一届学生的记忆里。移交不是交一个 U 盘，而是让下一位在不问你的情况下跑通一次关键实验。判断标准很硬：他按协议做，结果落在你记录的范围内移交的质量要用「下一位能否独立复现」验收，而不是用交了多少文件验收。

## H.2 本章目标（可检验）

- 交出可执行的实验协议，含试剂批号、细胞代次与仪器设置
- 交出可复算的数据与可复苏的样本，路径与命名一一对应
- 由他人按协议复现一次关键步骤，并留下验证记录

## H.3 操作流程

1. 列资产：协议、试剂与细胞、原始数据、未完成项四类，逐项写存放位置与责任人
2. 写协议并把关键参数写死：目的、材料、步骤、时限、判读标准，每一步用实测值；抗体货号与稀释比、封闭与孵育条件、曝光时长、流式门控策略与电压、诱导浓度与时长、传代比例与代次上限逐项落地
3. 建试剂清单：名称、厂家、货号、批号、收到与开封日期、分装量、有效期、存放位置；批号变更须重做一次对照
4. 盘细胞与动物：细胞写来源、鉴定与支原体检测结果、冻存管数与位置、复苏记录；动物写品系、周龄、笼位与福利观察表
5. 列数据清单：原始文件、处理中间件、脚本、图像源文件，逐一列路径与命名规则；不合并、不压成图片
6. 复算抽查：随机抽五个数字，从原始文件重算一遍，能对上才标「可用」，对不上的标「不可复算」并写原因
7. 记踩坑：至少五条「文档里没有、我踩过」的问题与绕法，例如某抗体换批后背景升高、某代次之后表型衰减
8. 列未完成项：没做完的实验、没验证的假设、被否掉的方向，按优先级排成下一步清单并写清前置条件
9. 写结论摘要：三句话——已确认什么、未确认什么、建议下一步先验证什么
10. 他人验证：请一位同学只读协议、不看你的操作，独立完成一次关键步骤；记录他卡住的地方，据此改协议
11. 实物与登记：剩余试剂、细胞、样本、危化品、仪器使用记录、耗材余量逐项签收；动物房笼位与在养动物一并交接
12. 接手须知一页：从哪份文件读起、跑通一次需要什么、最容易错的三处，独立可读

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 四类资产有清单、路径与责任人
- [ ] 协议每步为实测参数，无「适量」「适当」
- [ ] 抗体、流式、诱导、传代关键参数已记
- [ ] 试剂清单含货号批号与开封日期，换批有对照
- [ ] 细胞代次、鉴定与支原体结果、冻存位置已记
- [ ] 动物品系、笼位与福利观察已交接
- [ ] 数据含原始文件与脚本，未压成图片
- [ ] 五个数字可复算，不可复算项已标注
- [ ] 踩坑记录≥5 条且可操作
- [ ] 未完成项按优先级与前置条件排序
- [ ] 他人按协议独立复现一次并留记录
- [ ] 实物签收与接手须知一页完成

## H.5 模板：实验协议移交清单

| 字段 | 填写要求 |
|------|----------|
| 协议 | 目的、材料、步骤、实测参数、判读标准 |
| 关键参数 | 抗体稀释、曝光、门控电压、诱导条件、代次上限 |
| 试剂 | 厂家、货号、批号、开封日期、分装、效期 |
| 细胞与动物 | 来源、鉴定、支原体、冻存位置、品系与笼位 |
| 数据 | 原始文件、脚本、图像源、命名规则、路径 |
| 复算抽查 | 抽查数字、重算结果、可用与否 |
| 踩坑 | 问题、表现、绕法 |
| 未完成与建议 | 项目、优先级、前置条件、结论三句 |
| 验证与签收 | 验证人、卡点、协议修改、签收人与日期 |

> 本表是本章的交付物：答辩后一周内完成；四类资产签字后归入实验室档案，教学秘书签收。

## H.6 常见失效与处置

- **只交论文** → 协议与数据不留，下一届从零摸起
- **不记代次与批号** → 细胞传代衰减、抗体换批背景升高，结果不可复现
- **协议写「适量」「适当」** → 读者无法执行，等于没写
- **数据只剩图片** → 无法复算，也无法重做统计
- **无他人验证** → 自己能跑通不等于写得清；卡点只有外人能暴露
- **交接只在口头** → 人一走信息全失；四类资产须签字

## H.7 中期检查与答辩要点

- 协议可执行性（30%）
- 关键参数与清单完整（25%）
- 数据可复算（20%）
- 他人验证结果（15%）
- 签收与接手须知（10%）
