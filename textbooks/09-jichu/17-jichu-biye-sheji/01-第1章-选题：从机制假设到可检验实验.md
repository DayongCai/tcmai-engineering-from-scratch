## H.1 本章要解决的问题

「某方通过某通路改善某表型」听上去像命题，其实是几句没落地的话：在哪个模型上、干预到哪一步、测什么指标、多久看结果、差异朝哪个方向，全没定。开题要交的不是一段意义论证，而是一条能被打假的假设，外加撑得住它的样本量、模型与对照。命题定不死，后面十周就一直在换方向；把假设压成一句能判真假的话，是本章唯一的产出。

## H.2 本章目标（可检验）

- 把现象改写成含模型、干预、对照、指标、方向与时间窗的机制假设
- 按效应量、检验水准与把握度估算每组例数，并写清依据
- 说明模型与临床问题的距离，划定十周内能做到的机制层级

## H.3 操作流程

1. 定现象并查证据：从文献复现失败、实训反常或带教观察里挑一个具体现象，写成「在 A 条件下观察到 B，现有解释说不通」，再找到支持它的原始研究，核对其模型、剂量与时间窗能否在自己条件里重演
2. 写假设：格式为「在 M 模型中，干预 I 相对对照 C，使指标 Y 在 T 时间窗内朝 D 方向变化」，六个位置缺一个就不算命题
3. 判可检验：自问「什么样的结果会让我认输」；答不出否证条件，说明指标不可测或假设太宽
4. 定机制层级：相关（表达随表型变）、必要（敲低或抑制剂后表型消失）、充分（过表达或激动剂可复制）、回补（敲低再加回补后恢复），开题就写明本次做到哪一层
5. 选模型：细胞系写来源、代次上限、支原体与身份鉴定；原代细胞写取材与培养条件；动物写品系、周龄、性别与饲养等级；逐层说明能回答什么、不能回答什么
6. 设对照：阴性对照（溶剂、空载、同型抗体）、阳性对照（已知有效处理）、假手术或假处理，逐一写清，不留给「到时候再说」
7. 定样本量：取文献或预实验的效应量，设定检验水准与把握度算出每组例数，再按操作损耗上浮；同时写清这个 n 能测出多大的差异、测不出更小的
8. 设随机与盲法：区组随机或按体重、代次分层，给药与检测分离，分组编码由第三人保管，揭盲时点写进计划
9. 砍范围：一条通路、一个表型、一个时间窗；把「顺便看看」的项目列成不做清单
10. 排十周：伦理审批、细胞复苏与适应、预实验、正式实验、检测与统计逐周列里程碑，标出关键路径
11. 风险预案：细胞污染或代次过高、抗体不识别、动物审批延期、仪器排队，各写一条替代方案
12. 成稿：填开题命题表，请导师与一位不做本方向的同学各提一条反对意见，书面回应并留档

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 证据来自原始研究，模型与剂量已核
- [ ] 假设六要素（模型、干预、对照、指标、方向、时间窗）齐全
- [ ] 能说出否证条件
- [ ] 机制层级（相关/必要/充分/回补）已声明
- [ ] 模型来源、代次、品系与饲养条件已写
- [ ] 三类对照（阴性、阳性、假处理）已列
- [ ] 样本量有效应量、检验水准、把握度三项依据

## H.5 模板：开题命题表（基础）

| 字段 | 填写要求 |
|------|----------|
| 现象与证据 | 观察到的现象、原始研究出处、现有解释的缺口 |
| 假设 | 模型 + 干预 + 对照 + 指标 + 方向 + 时间窗 |
| 否证条件 | 出现何种结果即判假设不成立 |
| 机制层级 | 相关/必要/充分/回补，本次做到哪一层 |
| 模型 | 细胞系与代次上限、原代来源、动物品系周龄性别 |
| 对照 | 阴性、阳性、假处理，各自要排除什么 |
| 样本量 | 效应量来源、检验水准、把握度、每组 n、损耗上浮 |
| 随机与盲法 | 随机方法、分层因素、编码保管人、揭盲时点 |
| 范围与排期 | 不做清单、十周里程碑、关键路径、风险替代 |

## H.6 常见失效与处置

- **假设没有方向** → 「影响」「调节」无法判真假；必须写升或降、在哪个时间窗
- **层级吹高** → 只做了表达变化就写成「通过某通路调控」，一问敲低实验就露底
- **样本量拍脑袋** → 每组三只算不出效应，p 值随换一批动物翻覆；n 必须有依据
- **没有阳性对照** → 指标做不出来时分不清是干预无效还是实验失败
- **模型与问题错位** → 细胞系结果直接推人体，中间缺在体与临床样本两层桥
- **范围不收** → 十周同时开三条通路，最后每条都只剩半张图

## H.7 中期检查与答辩要点

- 假设可检验性与否证条件（30%）
- 样本量依据与统计计划（25%）
- 模型与对照设计（25%）
- 范围裁剪与排期（15%）
- 预答辩回应（5%）
