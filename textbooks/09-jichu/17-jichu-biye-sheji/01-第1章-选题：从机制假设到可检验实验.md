## H.1 本章要解决的问题

「研究某方对某通路的影响」不是命题：在什么模型、测什么指标、预期方向是什么，都没定。

## H.2 本章目标（可检验）

- 写出含模型、指标、方向的机制假设
- 说明所用模型与人体的距离
- 判断十周内可完成的实验量

## H.3 操作流程

1. 定现象：从文献或实训中挑一个未解释的现象
2. 写假设：模型 + 干预 + 指标 + 预期方向
3. 选模型：细胞或动物，说明与临床问题的距离
4. 估实验量：每组例数、重复次数、周期
5. 砍范围：单一通路、单一指标族

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 假设四要素齐全
- [ ] 模型选择理由已写
- [ ] 模型与人体差距已说明
- [ ] 每组例数与重复已估
- [ ] 周期与设备可及
- [ ] 伦理需求已判断
- [ ] 十周可行性已评估

## H.5 模板：开题命题表（基础）

| 字段 | 填写要求 |
|------|----------|
| 现象 | 文献或实训中的未解处 |
| 假设 | 模型+干预+指标+方向 |
| 模型 | 细胞/动物及理由 |
| 实验量 | 组数、例数、周期 |
| 范围 | 通路与指标限定 |

> 本表是本章的交付物：开题首页。

## H.6 常见失效与处置

- **假设无方向** → 无法判真假；必须写预期变化方向
- **模型与问题不匹配** → 细胞结果直接推临床会被质疑
- **实验量估少** → 十周做不完，最后只能报半截

## H.7 中期检查与答辩要点

- 假设可检验（40%）
- 模型适当性（30%）
- 实验量可行（30%）
