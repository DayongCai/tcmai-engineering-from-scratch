## H.1 本章要解决的问题

原始记录是实验唯一的证据。它要回答的不是「结果是多少」，而是「这个数在什么条件下、由谁、第几次做出来的」。事后补记、只记结果不记过程、图像调完对比度再覆盖原件，都会让结论在复核时失去支点。这一章把记录做成动作：当时写、页码连续、划改签名、原件不动记录的价值不在完整好看，而在别人拿去能核对、能重算。

## H.2 本章目标（可检验）

- 建立受控的原始记录本与数据目录，页码连续、可追溯到人
- 按实测参数、批号与仪器编号记录每一步，异常与偏离单独留痕
- 落实随机化、盲法与批次安排，使组间比较不被操作顺序污染

## H.3 操作流程

1. 建本并写页首：装订本或受控电子记录系统，封面写项目名、批件号、起止日期与保管人，页码预先连续编号；每页页首写日期时间、操作者、复核人、当次目的与方案版本号
2. 记材料：试剂名称、厂家、货号、批号、配制日期与浓度、溶剂；细胞写来源与代次，动物写个体编号与笼号
3. 记仪器：设备名称与编号、关键设置（离心转速与时间、曝光时长、门控电压、退火温度）；设置改过要写改前改后
4. 记实测值：写仪器读出的数，不写「按方案」；温湿度、pH、细胞计数与活率这类环境量同样要有
5. 划改规范：写错时单线划去、保留原字可读、旁写正确值、签名并注明日期；禁止涂黑、覆盖、使用修正液，禁止撕页重抄
6. 记异常与偏离：污染、凝血、麻醉意外、仪器报警、加样失误逐条写现象、判断、处置与是否影响该批数据；与方案不一致的操作另立偏离日志并评估影响
7. 排批次：一次实验内包含全部组别，避免「今天做对照、明天做给药」；同批试剂、同批细胞，减少批次效应
8. 随机与盲法落地：随机数字表或软件生成分组，区组长度固定；给药者与检测者分离，切片与图像按编码命名，揭盲时点写进计划
9. 存原始数据：仪器导出文件原名保存，另建只读备份与异地副本并记录校验值；图像保留原始格式，裁剪与调亮度对比度须声明并留原件
10. 日签与周核：当天记录当天签名；每周由复核人抽查三处，核对记录与原始文件能否对上
11. 阶段小结：每完成一个实验组写半页（完成率、异常项、下一步），交导师签字
12. 复盘一次：挑一个自己曾想「先记个大概、回头再补」的环节，说明补记会丢掉哪条信息

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 记录本装订受控、页码连续、无撕页
- [ ] 页首日期、操作者、目的、方案版本齐全
- [ ] 试剂批号、细胞代次、动物编号与笼号已记
- [ ] 仪器编号与关键设置已记，改动有前后值
- [ ] 参数为实测值，非「按方案」
- [ ] 划改单线保留原字并签名注明日期
- [ ] 无涂改、覆盖、修正液、重抄
- [ ] 异常与方案偏离逐条留痕并评估影响
- [ ] 同一次实验含全部组别，试剂与细胞同批
- [ ] 随机区组与盲法编码已执行，揭盲时点已定
- [ ] 原始文件原名保存、只读备份、校验值已记
- [ ] 当天签名，每周复核抽查有记录

## H.5 模板：原始记录页

| 字段 | 填写要求 |
|------|----------|
| 页首 | 日期时间、操作者、复核人、目的、方案版本 |
| 材料 | 试剂厂家货号批号、配制浓度、细胞代次、动物编号 |
| 仪器与设置 | 设备编号、转速、温度、曝光、门控电压 |
| 实测参数 | 读数、温湿度、pH、计数与活率 |
| 操作步骤 | 实际执行顺序与用时 |
| 异常与偏离 | 现象、判断、处置、是否影响数据 |
| 随机与盲法 | 分组方式、编码、保管人、揭盲时点 |
| 原始文件 | 文件名、路径、校验值、备份位置 |
| 签名 | 操作者、复核人、日期 |

> 本表是本章的交付物：实验本每页格式，禁止誊抄；补记须在旁注明补记时间与原因。

## H.6 常见失效与处置

- **事后补记不注明** → 补记可以，但须写明补记时间与原因；整本重抄等同伪造
- **只记结果不记过程** → 出问题时无法判断是干预无效还是操作失败
- **图像处理后覆盖原件** → 等于销毁证据；原件与处理版必须分开存
- **划改涂黑** → 原值不可读，复核时分不清改了什么、谁改的
- **分组不随机、检测不盲** → 差异可能来自操作顺序与判读偏好，机制结论站不住
- **批次分开做** → 对照与给药不同天，批次效应被当成处理效应

## H.7 中期检查与答辩要点

- 记录原始性与规范性（一票否决：涂改、重抄、无签名）
- 可追溯性：材料、仪器、参数齐全（30%）
- 随机、盲法与批次安排（25%）
- 异常与偏离记录（15%）
- 原始数据保存与备份（15%）
