## H.1 本章要解决的问题

基础实验的原始记录是唯一证据。事后补记、只记结果不记过程，都无法支撑结论。

## H.2 本章目标（可检验）

- 按天记录实验过程与异常
- 保留原始图像与数据文件
- 做到他人可据记录复算

## H.3 操作流程

1. 建本：编号、日期、操作者、当次目的
2. 记过程：每步实际参数与偏差
3. 记异常：动物状态、污染、失败
4. 存原始：图像、原始导出文件不加工
5. 日签：当天记录当天签字

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 记录本编号与日期连续
- [ ] 每步参数为实测值
- [ ] 异常逐条记录
- [ ] 原始文件未修改
- [ ] 图像含标尺与组别
- [ ] 当天签字完成
- [ ] 数据与记录本可对应

## H.5 模板：原始记录页

| 字段 | 填写要求 |
|------|----------|
| 日期与目的 | 编号、操作者 |
| 步骤与参数 | 实测值 |
| 异常 | 现象与处置 |
| 原始文件 | 路径与命名 |
| 签字 | 操作者与复核 |

> 本表是本章的交付物：实验本每页格式，禁止誊抄。

## H.6 常见失效与处置

- **只记结果** → 过程缺失无法排查与复现
- **原始图加工后覆盖** → 等于销毁证据；须保留原件
- **补记不注明** → 补记须写明补记时间与原因

## H.7 中期检查与答辩要点

- 记录原始性（40%）
- 异常记录（30%）
- 数据可对应（30%）
