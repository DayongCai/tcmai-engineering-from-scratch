## H.1 本章要解决的问题

基础实验数据量小、变异大，最容易「挑一个好看的指标作为主要结果」。预设指标是唯一防线。

## H.2 本章目标（可检验）

- 按预设主要指标分析
- 报告效应量与变异
- 如实呈现阴性结果

## H.3 操作流程

1. 回看预设：主要指标与检验方法写在开题里
2. 分析：按预设执行，不临时换指标
3. 呈现：散点或均值±SD，标出每组 n
4. 报阴性：未达显著的指标一并列
5. 附原始：关键图对应原始数据文件

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 主要指标与开题一致
- [ ] 检验方法未事后更改
- [ ] 每组 n 已标注
- [ ] 误差线定义已写
- [ ] 阴性结果已列
- [ ] 图表与原始文件对应
- [ ] 统计软件与版本已记

## H.5 模板：结果呈现表

| 字段 | 填写要求 |
|------|----------|
| 预设指标 | 主要与次要 |
| 分析 | 方法、n、误差 |
| 阳性结果 | 值、效应量 |
| 阴性结果 | 指标与值 |
| 原始对应 | 文件路径 |

> 本表是本章的交付物：结果章配套，评审可对照原始数据。

## H.6 常见失效与处置

- **临时换主要指标** → 属选择性报告；预设不可改
- **只画柱状不标 n** → 无法判断变异与效能
- **删掉阴性结果** → 会误导后续研究

## H.7 中期检查与答辩要点

- 预设遵守（一票否决项）
- 呈现规范（40%）
- 阴性结果诚实（30%）
