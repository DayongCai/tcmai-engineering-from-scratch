## H.1 本章要解决的问题

小样本基础实验最常见的失真不是算错，而是「看完数据再决定怎么算」：换个指标当主要结果、挑一个出显著的检验方法、把没差异的一组悄悄去掉。这条路的终点是结论无法复现。防线只有一条：分析计划在揭盲前写定，之后照做，改动留痕并说明理由预设分析计划挡的正是「结果好看就换一种算法」这种最容易被自己合理化的操作。

## H.2 本章目标（可检验）

- 揭盲前写定分析计划：主要终点、检验方法、缺失与异常值规则
- 按效应量与置信区间报告，p 值只作辅助
- 如实呈现阴性、无效与不一致的结果，并给出替代解释

## H.3 操作流程

1. 锁计划：主要终点、次要终点、检验方法、多重比较策略、缺失值处理、异常值判据，在揭盲前签字定稿；事后新增的分析一律标注为探索性
2. 分清重复：技术重复（同一份样本测三次）不能当生物学重复（三只动物、三批细胞）；把技术重复当 n，误差会被算小一个量级
3. 描述并查前提：每组先给个体散点、集中趋势、离散度与 n，再看分布；正态性、方差齐性按惯例检验，不满足改用非参数方法或变换并写明
4. 选检验：两组用 t 或秩和，多组用方差分析或 Kruskal-Wallis 加事后比较；配对设计用配对检验，不当独立样本处理
5. 控多重：三组以上两两比较，或多个指标同时检验，用 Holm、Bonferroni 或 FDR 校正；校正前后 p 都报，不只报小的那个
6. 报效应量：均值差、标准化差值、比值比或风险比，按指标类型选；效应量回答「有多大」，p 值只能回答「像不像偶然」
7. 报区间：给出效应量的置信区间；区间跨过无效值就写「不能排除无差异」，不写「有趋势」
8. 处理异常值：按预设判据判定，剔除须写值、判据与剔除前后结果；再做一个敏感性分析，看结论是否翻转
9. 图像定量：显微镜与免疫印迹的定量，阈值与选区规则事先定，测量者对分组设盲；同一张膜不跨实验拼接
10. 图表：散点加均值与离散度，不用柱状图掩盖分布；误差线写明是 SD、SEM 还是 CI；纵轴不从非零点截断（除非声明）；每组标 n
11. 存流程：从原始文件到图的每一步写成脚本或步骤清单，记软件与版本、随机种子，他人拿到数据能重跑出同一张图
12. 报阴性：所有预设终点都报，包括没做出差异的；阴性结果要写清「在多大样本下、能排除多大的效应」

## H.5 模板：分析计划与结果对照表

| 字段 | 填写要求 |
|------|----------|
| 主要终点 | 指标、时点、判定方向 |
| 次要终点 | 指标与用途（支持或探索） |
| 样本与 n | 生物学重复口径、技术重复、缺失情况 |
| 前提检查 | 正态性、方差齐性、是否变换 |
| 检验方法 | 组间方法、配对与否、事后比较 |
| 多重比较 | 校正方法与校正前后 p |
| 效应量与区间 | 效应量类型、数值、置信区间 |
| 异常值与敏感性 | 判据、剔除项、结论是否翻转 |
| 可复现 | 脚本路径、软件版本、随机种子、图与数据对应 |

> 本表是本章的交付物：揭盲前填左半并签字，出结果后填右半；两栏不一致处须写明原因。

## H.6 常见失效与处置

- **揭盲后改主要终点** → 属选择性报告；预设终点不能换，换了就写明是探索
- **技术重复当 n** → 伪重复把误差算小，p 值虚低，结论放大
- **只报 p 不报效应量** → 统计显著不等于差异有意义，读者无法判断大小
- **多重比较不校正** → 十几个指标里总有一个「显著」，这是概率不是发现
- **异常值随手剔除** → 不写判据就是挑数据；须报剔除前后结果
- **阴性结果不写** → 后续研究者会重复你已经排除过的路径
