## H.1 本章要解决的问题

动物与人源样本实验的第一道门不是技术，是审批；细胞实验也常被误当成「不用审」。批件没下来就动手，数据在答辩与投稿时一律不可用，且属违规。这一章要交的是一份能一次过审的方案：分组与样本量有依据、终点与处死方式写死、3R 落到具体动作、批件号与批准范围登记在册审得过的方案，共性是把变量、数量与处置都写成可核对的条目。

## H.2 本章目标（可检验）

- 判断研究属细胞、动物还是人源样本，各对应哪类审查与备案
- 把 3R 写成可核查的具体做法，而非口号
- 写清分组、样本量依据、终点、麻醉镇痛与处死方式
- 完成批件号、有效期与批准范围的登记，变更走修订

## H.3 操作流程

1. 判类型：细胞系实验一般走机构生物安全与实验室备案；人源样本（含细胞、组织、血液）走伦理审查并签知情同意；活体动物走实验动物福利伦理审查。三类可能同时涉及，须逐项判断
2. 查前置：细胞来源与使用授权、样本库出库单、动物房笼位与人员资质是否可排；前置缺一项，审批表就填不成
3. 写分组：组别、每组例数、对照种类、随机与盲法，与开题命题表一致；审查第一眼看的就是这部分
4. 给样本量依据：效应量来源、检验水准、把握度、计算结果与损耗上浮，写成一两句可核查的话，不用「参考同类研究」搪塞
5. 定终点：主要终点一个，次要终点不超过两个，写明观察时点与判定标准；终点必须可测，不能是「状态改善」
6. 定人道终点：动物出现何种体重下降幅度、何种姿态或进食异常即提前终止，并写处置方式；不写人道终点的方案多数会被退回
7. 落 3R：替代（能否先用细胞、类器官或已发表数据回答）、减少（共用对照、纵向取材、预实验定效应量）、优化（麻醉镇痛、环境丰富、操作者培训），每条写成一个动作
8. 写麻醉与镇痛：药物、剂量按机构 SOP、给药途径、术中监测指标、术后镇痛时长与观察频次
9. 写处死与尸体处置：方法须符合机构规定（如过量麻醉后确认死亡），注明由谁执行、如何确认死亡、组织与遗体如何处置
10. 人源样本：知情同意的范围要写全，是否允许二次使用、是否允许基因组或组学数据、是否可共享、保存年限与销毁方式
11. 登记批件与变更：批件号、批准日期、有效期、批准范围（品系、数量、实验内容、场所）抄进项目台账；改分组、加动物、换品系须提交修订并取得新批件，到期前续审
12. 归档与年度报告：批件、方案、知情同意模板、培训证书、变更记录放同一目录，年度报告按时提交

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 研究类型判断完整（细胞、动物、人源样本逐项）
- [ ] 细胞来源、样本出库、动物笼位三项前置已确认
- [ ] 分组、例数、对照、随机盲法与开题一致
- [ ] 样本量依据含效应量、检验水准、把握度
- [ ] 主要终点唯一，判定标准可测
- [ ] 人道终点与处置已写
- [ ] 3R 三条各有具体动作，非口号
- [ ] 麻醉、镇痛、术中监测已写
- [ ] 处死方法与死亡确认方式符合机构规定
- [ ] 知情同意覆盖二次使用与数据共享
- [ ] 批件号、有效期、批准范围已入台账
- [ ] 变更走修订、到期续审、年度报告已排期

## H.5 模板：伦理与方案备案表

| 字段 | 填写要求 |
|------|----------|
| 研究类型 | 细胞 / 动物 / 人源样本，对应审查与备案类型 |
| 分组与例数 | 组别、每组 n、对照种类、随机与盲法 |
| 样本量依据 | 效应量来源、检验水准、把握度、损耗上浮 |
| 终点 | 主要终点、次要终点、观察时点、判定标准 |
| 人道终点 | 触发条件与处置方式 |
| 3R | 替代、减少、优化各一条具体动作 |
| 麻醉与处死 | 药物、途径、监测指标、处死方法与死亡确认 |
| 批件 | 编号、批准日期、有效期、批准范围 |
| 归档与变更 | 存放位置、修订记录、年度报告责任人 |

> 本表是本章的交付物：实验开始前必须完成并归档；批件到期或方案变更时更新同一张表。

## H.6 常见失效与处置

- **先做后批** → 数据不可用于答辩与投稿，且属违规；审批是前置不是补办
- **借用他人批件** → 批准范围含品系、数量、场所，跨项目使用等同无批件
- **3R 写成口号** → 「尽量减少动物使用」不算落实；要写共用对照这类具体做法
- **样本量无依据** → 审查与答辩都会追问；「参考同类研究」不是依据
- **不写人道终点** → 动物痛苦超出预期仍继续，属福利问题，方案多被退回
- **知情同意范围不全** → 只签「同意本次研究」，二次使用组学数据即越界

## H.7 中期检查与答辩要点

- 审批完备性（一票否决：无有效批件不得开始）
- 3R 落实的具体性（30%）
- 分组、样本量与终点设计（30%）
- 麻醉镇痛与处死规范（20%）
- 备案、变更与归档（15%）
