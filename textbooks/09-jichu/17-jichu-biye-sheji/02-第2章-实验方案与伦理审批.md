## H.1 本章要解决的问题

动物与人体实验的前置不是技术，是审批：没有批件就不能开始，补批属重大违规。

## H.2 本章目标（可检验）

- 完成伦理或动物福利审批
- 写清 3R 原则的落实
- 把批件号写进方案首页

## H.3 操作流程

1. 判类型：细胞、动物、人体样本各对应哪类审批
2. 备材料：方案、分组、终点、处死方式（动物）
3. 交审批：取得批件号与有效期
4. 落 3R：替代、减少、优化各写一条
5. 归档：批件与方案同目录保存

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 审批类型判断正确
- [ ] 方案含分组与终点
- [ ] 动物处死方式已写
- [ ] 批件号与有效期已记
- [ ] 3R 三条已落实并说明
- [ ] 知情同意（人体样本）已备
- [ ] 批件与方案已归档

## H.5 模板：伦理与方案备案表

| 字段 | 填写要求 |
|------|----------|
| 类型 | 细胞/动物/人体样本 |
| 方案要点 | 分组、终点、处置 |
| 批件 | 编号与有效期 |
| 3R | 替代/减少/优化 |
| 归档 | 位置与责任人 |

> 本表是本章的交付物：实验开始前必须完成。

## H.6 常见失效与处置

- **先做后批** → 数据不可用且违规；审批是前置
- **3R 写在纸上** → 要写具体做法，如共用对照组
- **批件过期未续** → 有效期须记入台账

## H.7 中期检查与答辩要点

- 审批完备（一票否决项）
- 3R 落实（40%）
- 备案归档（20%）
