## H.1 本章要解决的问题

答辩真正考的不是做了多少实验，而是「你的结论凭什么成立、什么情况下不成立」。失分多数不在数据，而在三处：把相关说成机制、把细胞结果说成临床结论、答不出「还可能是别的什么原因」。论文要做的，是把问题、模型、证据、替代解释与结论强度串成一条别人能检验的链论文的分寸感，体现在每一句结论都能指回某一张图。

## H.2 本章目标（可检验）

- 写出主线唯一、数字可溯源的论文，方法章到他人可照做的程度
- 主动列出替代解释，逐条排除或明确承认未排除
- 按「特异性、剂量与时间窗、外推」三类问题准备答辩

## H.3 操作流程

1. 定主线：一句话写清「本研究在什么模型上证明了哪一层级的机制」，全文围绕它取舍，枝节数据进附录
2. 写摘要：背景一句、方法两句、结果三句（含效应量与 n）、结论一句并标强度，不写「具有重要意义」
3. 写引言：从现象与缺口写起，落到本研究的假设与否证条件，不写成综述
4. 写方法：按报告规范逐项写——细胞来源与代次、动物品系周龄性别与饲养、随机化与盲法、样本量依据、伦理批件号、抗体货号与稀释比、统计方法，写到别人能照做
5. 写结果：按假设顺序组织，一图一结论；图注写 n、误差线含义、检验方法与区间；结果里不作讨论
6. 写讨论：开头两三句复述主要发现并对应开题假设，指出哪条被支持、哪条没有；再与至少三篇原始研究比对，一致处与不一致处各给原因（模型、剂量、时点、检测方法），不回避相反结果
7. 列替代解释：脱靶或非特异结合、溶剂与载体效应、毒性导致的选择性、批次与代次差异、观察者偏倚；逐条说明已有的排除证据，或承认未排除
8. 标机制链缺口：明确哪一步是相关、哪一步有干预证据、哪一步缺在体或回补，不把链条说得比数据长
9. 划边界：模型与人体距离、样本量与可检出的最小效应、单次实验与重复次数、指标替代性，逐条写并说明越界后果
10. 分级结论：分「确定」「提示」「待验证」三档，与讨论分开写，不用「首次」「填补空白」这类话
11. 备答辩：三类必答题——怎么排除脱靶与非特异、剂量与时间窗为何这样选、结果能否外推到在体与人；每题备一条数据与一句退让说法
12. 预答辩与归档：十五分钟讲完，记录三条意见逐条回应并留修改对照；定稿时论文、原始数据、脚本、图源一并归档

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 主线一句话含模型与机制层级
- [ ] 摘要含效应量与 n，无空话
- [ ] 引言落到假设与否证条件
- [ ] 方法含来源、代次、品系、随机盲法、样本量、批件号
- [ ] 图注含 n、误差线、检验与区间
- [ ] 结果与讨论未混写
- [ ] 与≥3 篇原始研究比对，相反结果未回避
- [ ] 替代解释≥4 条，逐条有排除证据或承认
- [ ] 机制链缺口已标明
- [ ] 边界逐条写并说明越界后果
- [ ] 结论分三档，未用「首次」「填补空白」
- [ ] 三类答辩题各有数据与退让说法，预答辩意见已回应

## H.5 模板：论文自检与答辩表

| 字段 | 填写要求 |
|------|----------|
| 主线与强度 | 一句话结论、机制层级 |
| 摘要 | 背景、方法、结果（含效应量与 n）、结论 |
| 方法可复现 | 来源、代次、品系、随机盲法、样本量、批件号 |
| 结果 | 图表编号、n、误差线、检验、对应假设 |
| 文献比对 | 一致与不一致条目、各自原因 |
| 替代解释 | 条目、排除证据或承认未排除 |
| 边界 | 模型距离、最小可检出效应、重复次数 |
| 结论分级 | 确定 / 提示 / 待验证 |
| 答辩 | 三类问题、数据支撑、退让说法、修改对照 |

> 本表是本章的交付物：定稿前逐条自查，答辩前用右栏预演；答辩后与本表一并归档。

## H.6 常见失效与处置

- **把相关当机制** → 只看到表达随表型变化就写「通过某通路调控」，缺干预证据
- **方法写不到可复现** → 缺代次、批号、稀释比，别人重复不出来
- **讨论只复述结果** → 没有文献比对与替代解释，看不出学术位置
- **回避相反文献** → 评审一眼看出选择性引用，可信度全失
- **结论拔高** → 细胞系单一处理写成临床建议，属越界
- **答辩硬扛** → 答不出就说「文献如此」，不如承认未排除并给出验证方案

## H.7 中期检查与答辩要点

- 证据链与主线（30%）
- 方法与可复现（25%）
- 替代解释与边界（25%）
- 结论分寸（10%）
- 答辩表现（10%）
