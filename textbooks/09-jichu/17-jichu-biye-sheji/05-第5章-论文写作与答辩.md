## H.1 本章要解决的问题

基础医学答辩的关键问题永远是「你怎么排除其他解释」。答不上，机制结论就不成立。

## H.2 本章目标（可检验）

- 论文数据与原始记录一致
- 15 分钟讲清假设、模型、结果、替代解释
- 准备三个机制类质疑

## H.3 操作流程

1. 对表：数值回到原始记录与结果表
2. 写结构：假设、模型、结果、替代解释、结论强度
3. 写局限：模型距离、样本量、单次重复
4. 预设质疑：特异性、剂量、模型外推
5. 试讲

## H.4 现场清单（逐项打勾，缺一项不算完成）

- [ ] 数值与原始记录一致
- [ ] 五段结构齐全
- [ ] 替代解释≥2 条
- [ ] 结论强度已分级
- [ ] 三个质疑有答案
- [ ] 引用写到篇名
- [ ] 伦理批件号已注明

## H.5 模板：答辩准备表（基础）

| 字段 | 填写要求 |
|------|----------|
| 核心结论 | ≤40 字，含强度 |
| 证据链 | 假设→模型→结果 |
| 三个质疑 | 特异性/剂量/外推 |
| 替代解释 | ≥2 条 |
| 试讲反馈 | 修改点 |

> 本表是本章的交付物：答辩前一天自查。

## H.6 常见失效与处置

- **把相关当机制** → 需干预实验支撑因果
- **不提模型外推限制** → 细胞结果直接推人体会被当场质疑
- **结论强于数据** → 用「提示」「相关」而非「证明」

## H.7 中期检查与答辩要点

- 数据一致（40%）
- 机制论证强度（30%）
- 质疑回答（30%）
