# 中医 ↔ AI 概念桥梁对照表

> **这不是类比表，是工程接口表。**
>
> 中医概念给出**语义与约束**，AI/工程概念给出**表示与算法**。
> 一行桥梁只有同时满足两个条件才成立：
> 1. **左 → 右**：能给出可计算的形式化表示；
> 2. **右 → 左**：从算法输出能回指到具体的中医命题（而不是停在"相似度 0.87"）。

## 桥梁的四种强度

| 级别 | 含义 | 可否进入 `outputs/` |
|------|------|-------------------|
| **A 同构** | 结构与约束都能一一对应 | ✅ 可以直接产品化 |
| **B 约束可用** | 中医侧提供先验约束，AI 侧提供求解方法 | ✅ 需标注约束来源 |
| **C 类比** | 只在直觉层相似，形式化会丢语义 | ⚠️ 只可出现在教学讲解，不得用于临床输出 |
| **D 误导** | 流行但错误，必须显式排除 | ❌ 在 glossary 里作为「常见误用」记录 |

## 一、基础理论

| 中医概念 | AI / 工程概念 | 桥梁 | 级别 | 丢失了什么 |
|---------|--------------|------|------|-----------|
| 阴阳 | 二分类 / logistic 回归 | 对立属性 → sigmoid 后验概率；输出连续值保留「偏阴偏阳」的强度 | **B** | 互根互用、相互转化（需额外建模转移） |
| 阴阳转化 | 状态转移 / 阈值翻转 | 「重阴必阳」→ 状态机在临界点的相变 | **B** | 转化的时间尺度 |
| 五行 | 五分类 + 关系图 | 类别为 5，生克为有向边，构成带约束的多分类 | **B** | 生克的量化强度 |
| 五行生克 | 图上的有向传播 | 相生=正向加权边，相克=负向加权边 | **A** | — |
| 藏象 | 知识图谱 | 脏腑/官窍/情志为节点，功能联系为边 | **A** | 功能联系的程度差异 |
| 精气血津液 | 多维状态向量 | 四类物质为连续状态分量，化生关系为守恒/流向约束 | **B** | 定量单位 |
| 经络 | 图结构（节点+路径） | 腧穴为节点，循行为边 | **A** | 循行的空间几何 |
| 三焦 | 分层架构 / 限界上下文 | 上中下三焦 → 三层职责划分 | **C** | 三焦是功能划分，不是部署划分 |
| 标本缓急 | 多目标优化 + 优先级调度 | 「急则治标」→ 加权目标函数在约束下切换权重 | **B** | 缓急的临床判据 |
| 正治反治 | 策略空间 / 反事实推理 | 「热因热用」→ 反直觉策略，需在反事实框架下评估 | **B** | 适用条件 |

## 被明确排除的误用（D 级）

| 流行说法 | 为什么错 |
|---------|---------|
| 「阴阳就是二进制的 0 和 1」 | 二进制位互斥且可交换；阴阳互根互用、可转化、带强度。用位运算处理阴阳会丢掉全部动态语义。 |
| 「五行就是五行分类器」 | 纯 softmax 丢掉生克约束。「五行」最有价值的部分恰恰是关系，不是类别数。 |
| 「藏象就是器官知识图谱」 | 藏象之「肝」是功能系统，与解剖肝脏非一对一。直接映射会造成系统性错误。 |
| 「脉象就是一段波形」 | 取脉压力不同，同一人波形可以完全不同。不做压力标准化就谈识别，学到的是设备不是脉象。 |
| 「四诊合参 = 舌象 + 脉象两个模态」 | 缺了望（面色）、闻、问三通道。两模态不能称为「合参」。 |
| 「用大模型读医案就能替代辨证」 | 辨证是可追责的临床判断。模型可以辅助，但责任主体不能是模型。 |
| 「师承可以靠微调复现」 | 师承的核心是长期临床反馈与隐性判断。微调复现的是语言风格，不是判断力。 |

## 使用方式

1. 写新章节时，先在本表找到对应的桥梁行；没有就先补一行。
2. `docs/zh.md` 的「对应关系」表必须引用本表的级别（A/B/C/D）。
3. **C 级桥梁不得出现在任何 `outputs/` 的临床输出路径上**，只能作为教学讲解。
4. 发现新的 D 级误用，直接加进上表，并在相关章节把它显式排除。
