PROBLEM

本章底本 7 个单元、14,036 汉字，正文出现《……》书名 99 种、标为【原文】的引文块 41 处，而 41 处引文没有一处附版本与页码。这 41 块引文要落地成可核的句子，只能经过字书、辞书、目录书这一层中转；中转错一步，后面所有训释都建在错字上。本章要回答的是：一次合格的查检，必须留下哪几样可复核的东西。

双根因定位

环境逼迫（手上常常只是一部无标点、无注释的白文本或影印本，遇到生字僻义没有第二个人可问，只能自己把字书翻对，翻错也无从校验）+ 知识积累（字书体系自东汉至现代层层累积，形、音、义、源流分属不同层级的工具，混用一层就会把本义当成通义）

4 / 18roots
一、三种字书不在同一层：形、义、音各有其司

初学者最容易把工具书当成一排同质的柜子，以为「查一下」就算取证。其实《说文》《尔雅》《康熙字典》回答的是三个不同的问题，答案彼此不能替换。

《说文解字》以形为主。许慎收正篆九千三百五十三、重文一千一百六十三，按五百四十部编排，部首「始一终亥」，每字先列小篆，次释字义，再析字形，末注读音。它给的是本义与字形理据。底本引其释「疾」「病」两条：「疾，病也。从疒，矢声」「病，疾加也。从疒，丙声」。两条互训，却分轻重——疾轻病重，后世「疾病」连言，这个分别就磨平了。同书训「走」为「趋也」，即疾行；这正说明《说文》的释义停在汉代通义上，与今语「行走」并不同指。

一、三种字书不在同一层：形、义、音各有其司

《尔雅》以义为主，按义类编排，前三篇《释诂》《释言》《释训》释一般词语，后十六篇释名物制度。它给的是同义聚合与名物对应。《释诂》开篇「初、哉、首、基、肇、祖、元、胎、俶、落、权舆，始也」，是用当时通语去解释一串古语、方言与雅言；《释草》《释木》《释虫》《释鱼》《释鸟》《释兽》诸篇与本草名物互相发明，读本草书时，哪一个字对哪一种物，答案在这里而不在《说文》。

《广雅》沿《尔雅》体例而增广之，收字一万八千余；王念孙《广雅疏证》以声音通训诂，把「因声求义」做成了一套可复核的方法。它给的是通假与语源的线索。

一、三种字书不在同一层：形、义、音各有其司

《康熙字典》是合编体。底本载其收字四万七千零三十五，按二百十四部首、依子丑寅卯十二集分卷；每字先注音（反切与直音并用），次释义（本义、引申、通假依次排列），每义引书证。它给的是义项的全景与读音，代价是成于众手、引书多误——王引之奉敕撰《字典考证》，改正引书讹误二千五百八十八条。这个数字本身就是一条方法论提示：字典的书证是转引，转引必须回原书。

于是有了第一条判据。动手查之前先问一句：我要的是本义、是同义聚合、是读音、还是名物对应？问错了层级，查到的东西再准确也用不上——拿《康熙字典》里的引申义去充当《说文》的本义，是医古文里最常见的一种「引对了书、用错了层」。

一、三种字书不在同一层：形、义、音各有其司

还有并列的第四层：专科辞书。它不释字而释词，回答的是「这个词在医学语境里指什么」。《中国医学大辞典》收词七万余条，包医经、本草、方书、病名、证候、诊法、药物、方剂、医家、医籍、脏腑、经络、腧穴诸类，每条先释名义、再述源流；《中医大辞典》合订本收词目四万余条，释义注明出处，卷末附引用书目；《中药大辞典》收药五千七百六十七味，每味列基原、性味、归经、功用主治、宜忌诸项。三者分工也不同：考词目取前者与中者，考单味药取后者。此层的价值在于它把「字之常训」与「词之专义」分开——「气」字常训为云气、气息，而专科辞典所列则是元气、宗气、营气、卫气，两者不可互代。此层的风险则在于它是现代人的整理：释义多本旧说，出处须回原书，否则引用的是编纂者的概括，不是古人的话。

二、部首数从 540 到 214 再到 201：查检法本身就是一部学术史

同一个「部」字，在三套体系里数出三个数：五百四十、二百十四、二百零一。这不是谁算错了，而是三部书对「部首」的理解不同。

五百四十部是依形系联，同一个意义范畴的字排在同一个部首之下，字形理据优先，检寻效率靠后。明代梅膺祚《字汇》把它简化为二百十四部，按笔画排列，检字方便了，代价是部分字的形义关系被切断。《康熙字典》沿用二百十四部，遂成此后三百年的通例。二〇〇九年发布的《汉字部首表》归并为二百零一部，服务于现代通用字典。

二、部首数从 540 到 214 再到 201：查检法本身就是一部学术史

这条演化史对读古籍有直接后果：一个字在 214 部体系里归某部，在 201 部体系里可能归另一部。查不到，第一反应不该是「字书未收此字」，而该是「部定错了」。底本举的例子很实在：查「病」，部首是疒（五画），再数「丙」五画，于疒部五画内检得；查「炙」，可不走部首而走音节 zhì。部首位置也不固定，或在左（治之氵）、或在右（颈之页）、或在上（药之艹）、或在下（炙之火）——位置不定，说明部首不是「偏旁的固定位置」，而是「表意偏旁的认定」，认定本身需要判断。

多音字则是另一道坎。底本点出「数」三读：读 shù 为数目，读 shǔ 为计算，读 shuò 为屡次；「数脉」之「数」取 shuò。又「和」读 hé 为调和、读 huò 为拌和、读 hè 为唱和，《素问》「阴阳和」取 hé。读音定错，义项必然跟着错，且错得不显眼——句子照样读得通，只是意思偏了。

三、一次查检要留下六个字段

把查检当动作而不是当印象，就要有记录格式。本课程要求一字一条，六项齐全才算查过：

text
查检记录（一字一条）
① 字头：
② 所在句：（照录原文，附书名·篇名）
③ 所求层级：本义 / 同义聚合 / 读音 / 名物对应
④ 检得工具书：书名 + 部（或音节）+ 义项序号
⑤ 用字关系：本字 / 借字 / 古字 / 今字 / 异体 / 避讳改字
⑥ 复核结论：采 / 不采，附一句理由（可否代回原句）

六项各有其不可省的理由。缺②，训释就脱离了上下文，同一个字在两句里会被压成一个义；缺③，本义与通义混用而不自知；缺④里的「义项序号」，则同一字条下的几个义项会被合并引用——底本讲「瘥」字最清楚：一义为「痛」，一义为「病除」，读医籍见「病瘥」「瘥后」，当取后起义。若记录只写「瘥，病也」，痊愈就被读成了疼痛，而这处错误在任何一本字书里都查不出毛病，因为字书没错，是记录漏了义项序号。

三、一次查检要留下六个字段

⑤是医籍特有的负担。同一个概念，古书常换字写：藏／脏、府／腑、蚤／早、亡／无。这些关系不写进记录，同一段文字换个版本就接不上了。

⑥是最容易被跳过、也最要紧的一项。判据只有一句：把训释代回原句，句意是否通，是否与全篇一致。 通不过这一句，前面五项做得再漂亮也只是资料。

四、三种失效模式与一条共同的判据

以今律古。 底本反复申说的「古今异义」，在查检环节表现为：用今天的常用义去读字书里的第一个义项。「走」今为行走，《说文》训「趋」为疾行；「涕」古指眼泪；「汤」在医籍里指汤剂。判据：这个义项能否在汉代以前的用例中找到？找不到，它就是今义，不是古义。

孤证立说。 一条书证足以提出假设，不足以定训。判据：换一部书、换一个作者，还能不能找到同义的用例？只能找到一条，就只能写「一例作某义」，不能写「其义为某」。

训释脱离上下文。 复词不可拆。「治未病」的「治」训「治理」而非「治疗」，若按今义拆开，「未病」就成了治理的对象，整句立刻荒谬。判据与⑥同：代回原句。

四、三种失效模式与一条共同的判据

三种失效之上还有一条总判据，底本讲得比任何一条细则都重：辞书是二手，典籍是一手。 凡引用辞书释义，必须能报出该辞书所引的原书与篇名；报不出，说明这一条还停在转述层。这不是苛求——王引之改正《康熙字典》引书讹误二千五百八十八条这件事，恰好证明转述层本身就带误差，误差还会被后一层转述继承。

14 / 18body
四、三种失效模式与一条共同的判据

与之配套的是目录书这一层。查到一个词、一条引文，还要问它在哪个本子里。底本举《医籍考》为例：仿朱彝尊《经义考》体例，著录历代医籍三千余种，按医经、本草、食治、藏象、诊法、明堂经脉、方论、史传、运气九类编排，每种详列存佚、撰者、序跋、提要，并辑录历代书目著录与诸家评论。它的用处不是替代原书，而是回答三个前置问题：这部书还在不在（存佚）、现在通行的本子从哪来（源流）、后人给它写过什么（序跋与评论）。跳过这三个问题直接引文，引到的可能是晚出的重编本、删节本或改字本，字面上通顺，却不是原文。因此本章的顺序是：先定层级，再定版本，最后才落训释；三步倒过来，前面的功夫都会白费。

五、考核项
  1. 给出「瘥」的两个义项各一句原文，并说明「病瘥」当取哪一义、依据是句中哪个词。
  2. 说明《说文》训「走」为「趋」、《康熙字典》列「走」有「趋」「趋向」「走漏」诸义，二者的差别属于哪一层（本义／引申／通义），并指出混用会造成什么误读。
  3. 举出一例说明二百十四部与二百零一部归并后部首不同的字，并写出该字在两套体系中的部。
  4. 取一段无注白文，任选三字完成六字段记录，其中⑥必须写出代回原句后的判断。
  5. 指出下列哪一条属于孤证立说，并给出补证的方向：某字仅见于一书一处的某义。
  6. 说明「辞书是二手」这条判据如何解释王引之所正二千五百八十八条这一事实。

评分只看「能不能复核」：结论朴素但每一步可回查的记录为合格；结论漂亮而报不出篇名与义项序号的，作未查处理。

代价与边界
  1. 本章不教认篆文。《说文》的字形分析以通行今本与底本所述为准，未核对拓本与影印本；凡涉字形理据的具体判断，须回原书影像。
  2. 底本 41 处【原文】块均无页码，本章所引字书条目（如「疾，病也」「走，趋也」）系转自底本，尚未逐条核原书，属转述层材料。
  3. 部首 201 部与 214 部不是一一对应，归并规则须查《汉字部首表》原表；本章只说明「会出现不对应」，不给逐字对照。
  4. 电子古籍与在线字书可辅助检索，但各库底本不同、录入与标点均有讹误，版本不明者不作引用依据；检索所得必须回纸质善本或权威整理本。
  5. 本章不给任何病证判断与用药建议。字词训释只解决「这句话在说什么」，不解决「这个病人该怎么治」。
