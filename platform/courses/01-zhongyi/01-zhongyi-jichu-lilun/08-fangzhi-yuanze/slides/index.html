PROBLEM

你能一口气说出「汗吐下和温清补消」。但让你给「和法」下个定义、说清它与「下法」的边界，教材里找不到——八法只写了两个法的释义。

治则层里，「治病求本」再分正治与反治：

  • 正治（逆其证候性质而治）：寒证用温热药，热证用寒凉药，虚证用补益药，实证用攻伐药；
  • 反治（顺从假象而治）：教材只给了两法——「热因热用」（内真寒而外假热）、「寒因寒用」（内真热而外假寒）。

反治缺两法：塞因塞用 与 通因通用 在整章出现 0 次。这两个是反治的另外半壁，缺了之后「反治」只剩「真假寒热」一种情形，学生容易以为反治就是治假热假寒。

二、八法：八个名字，两个释义

小节标题写得很齐：「汗、吐、下、和、温、清、补、消」。正文里能被认成「释义」的只有两处：

text
汗法：通过发汗，使邪从汗解，适用于外感表证
补法：针对各种虚损证候，通过补益气血阴阳，恢复脏腑功能

吐、下、和、温、清、消 六法连一句定义都没有。 这不是本章读漏——10.3.1 只有两段，一段讲汗、一段讲补，中间没有其余六法的任何文字。

后果很具体：教材要求学生「灵活运用八法」（10.3.2），却只给了两法的语义。这相当于给了一张八按钮的控制台，只解释了两个按钮——所以本章的产物里，六法只能标「教材未释义」，不能按通行教材补写。补写就是替教材编内容，与伪造原文同性质。

三、八法组合：三组，都有方名可查

10.3.2 给了三个组合，每组都带方：

组合方覆盖的两法
汗下并用大柴胡汤汗 + 下
温清并用半夏泻心汤温 + 清
攻补兼施黄龙汤攻（下）+ 补

三组覆盖了「汗下、温清、攻补」三对——八法里最常冲突的三对。这是本章唯一「有方、有法、有适应证」齐全的地方（「少阳阳明合病」用大柴胡汤法）。要讲八法怎么配，只能从这三个例子讲，讲不出第四条规律。

四、三因制宜给的是方向，不是权重

教材 10.2.4 的两条约束写得很清楚：

text
夏季炎热，腠理开泄 → 慎用辛温发散
冬季寒冷，腠理致密 → 慎用寒凉伤阳

这是方向性约束（某季禁用某类），不是权重（该用多少）。于是「策略选择」只能写成代价函数，而代价函数的系数全部自设：

策略耗气伤津伤正总分（等权）
温阳益气+0.7−0.2−0.1+0.4
甘寒养阴−0.2+0.5−0.1+0.2
苦寒直折−0.1−0.4−0.3−0.8
辛温发汗−0.6−0.5−0.2−1.3

这张表唯一的用处是演示「换个权重排序就变」。 把伤津的权重调高，甘寒养阴立刻掉到末位；把耗气的权重调高，温阳益气也会跌。教材没有给任何系数，所以这张表不能用来选治法——它只能用来向学生证明「治法比较在没有权重时是伪比较」。

五、代价与边界
  • 本章的四个数字（3/4/8/3）都是结构数，不是疗效数。教材 27 段里没有任何一组疗效统计。
  • 反治只覆盖真假寒热，缺塞因塞用、通因通用；标本 二字全章 0 次，同病异治/异病同治 也 0 次——教材第 10 章没有讲这几个常被考的概念，本章不替它补。
  • 代价函数的三维（耗气/伤津/伤正）是自选的；换成「疗效/成本/依从性」结论全变。它的价值在于暴露缺权重，不在于给答案。
  • 10.3.2 第二段以「如血」结尾（截断），「急则治其标，缓则治其本」只写了一半——这是第 5 章报过的同一类母本截断。
