PROBLEM

咀嚼一个周期分五相，吞咽分三期，咽期里又叠着四道保护；五相加三期加四道，一共十二个环节，而其中只有口腔期这一段能随意志开始或暂停。咽期一旦启动，就不能中途叫停——这意味着所有「防误吸」的工作，必须在咽期之前做完。本章要回答的正是这个时序问题：为什么牙缺一颗会改变咀嚼效率，而咽期少一道保护就会改变一个人的结局。

3 / 17problem
双根因定位

环境逼迫（口腔同时是消化道与呼吸道的交叉口：食物要走的路与空气要走的路在咽部共用一段，机体只能在共用段前后各设闸门，靠时序错开两条通路。凡是时序被打乱的情形——进食过快、意识下降、结构缺损——都会把「吃」变成风险）+ 知识积累（五相与三期的分界、每一相的肌与关节分工、四道保护的解剖对应，三层必须串起来；只会背「吞咽分三期」，遇到具体患者仍说不出「他卡在哪一期、缺哪一道」）。

一、咀嚼周期的五相

咀嚼不是「上下牙碰几下」，是一个有固定结构的周期。通行把它分成五相，各书措辞不同，内容一致：

  1. 静止相：上下牙分离，下颌处于姿势位，舌与颊把食物维持在牙列上。
  2. 摄食相：食物被送到牙列，下颌下降到开口位，准备咬入。
  3. 粉碎相：牙接触、食物被压碎，这是全周期最长的一段，也是唯一产生咬合力的阶段。
  4. 食团形成与排出相：舌把碎屑聚成食团，送到咽峡前待吞。
  5. 清扫相：舌与颊清除牙间隙与前庭沟内的残渣，下颌回到姿势位。

五相的意义在「哪一相出事，症状就长在哪」。 摄食相出问题，食物送不到位，患者靠前牙咬、后牙用不上；粉碎相出问题，多是牙列缺失或咬合干扰，表现为「嚼不烂」「只在一侧嚼」；食团形成相出问题，是舌的运动障碍，表现为「含饭」、食物堆在颊沟里不咽；清扫相出问题，是残渣滞留，与龋、牙周炎、口臭直接相关。五个问题五种归因，写成「咀嚼功能差」一句，等于五种都没说。

一、咀嚼周期的五相

单侧咀嚼（偏侧咀嚼）值得单列。它的直接原因是患侧有痛、有缺失、有干扰；它的后果是双侧负荷长期不对称：工作侧牙磨耗快、牙周负担重，非工作侧的牙因为缺少自洁与对𬌗接触而堆积菌斑、伸长；两侧关节的负荷也随之不同。「只用一边嚼」是一个可以问出来的习惯，也是一个可以推回病因的线索。

二、咀嚼力与咀嚼效率：三个上限，不是一条曲线

「咬合力有多大」这个问题，临床上问错了方向。真正要区分的是三个量：

  • 肌能发出的最大力：由咀嚼肌的体积与协调决定，是理论上限。
  • 实际咬合力：作用在牙面上的力，随食物性质、牙接触面积、咬合方向变化。
  • 牙周膜能耐受的阈限：超过它，牙周组织开始出现可观察的反应。

三者的大小关系是本章最重要的一句：日常咀嚼用力低于牙周耐受阈，牙周耐受阈低于肌的最大力。 中间那段差额，就是「牙周储备」。它解释了两件事：正常咀嚼为什么不会伤牙；以及咬合创伤为什么发生在「力没变大、但承受面积变小」的时候——牙周储备被消耗掉了，而不是力超过了极限。

二、咀嚼力与咀嚼效率：三个上限，不是一条曲线

咀嚼效率则是另一件事：它是单位时间内把食物嚼碎的能力，通行以筛分法或比色法测定。影响因素有五处，正好对应前五章：牙接触面积（第 2 章）、牙列完整性（第 2 章）、咀嚼肌力（第 3 章）、关节运动是否顺畅（第 4 章）、唾液对食团的润湿（第 5 章）。所以咀嚼效率下降从来不是单一原因，也不是单一科室能解决的：修复科恢复接触面积，外科处理缺失，内科看唾液，关节科看运动。先分清是哪一处掉了，再决定补哪一处——这一条是本章对临床最直接的贡献。

三、吞咽三期与口腔期的交接

吞咽分三期，分界的判据是「能不能自主控制」。

口腔期（随意期）：舌把食团从牙列上收拢，向硬腭压送，向后推到咽峡。这一段完全受意志支配，可以开始、可以暂停、可以把食团退回。它是唯一可以训练、可以代偿、可以在检查中观察的一段。

咽期（不随意期）：食团越过咽峡、触发吞咽反射，此后一连串动作按固定顺序发生，中途不能停止。这一期短，靠的是时序而不是力量：软腭先上提，舌根后缩，喉上提，声带闭合，会厌翻转，咽缩肌依次收缩，食管上括约肌开放。任何一步慢半拍，食物就可能走错路。

食管期：食团进入食管，靠蠕动与重力下行，由食管上括约肌的开放与关闭控制。这一期已不属口腔解剖生理的范围，但它与本课有一处接口：食管入口的位置与咽部结构的关系，决定了「咽期结束得干不干净」。

三、吞咽三期与口腔期的交接

交接点是本章的关键结构：咽峡。 食团越过咽峡，就从「可以反悔」进入「不可反悔」。所以临床上评估吞咽，最有价值的一问是「有没有呛、呛在什么时候」：如果呛在刚要咽的瞬间，问题在口腔期（食团没聚好、送不到位）；如果呛在咽下去的过程中，问题在咽期（保护没到位或时序错乱）。同一个「呛」，时间点不同，定位完全不同。

四、误吸与四道保护

误吸是食物或液体进入声门以下。机体靠四道保护拦住它，四道各有各的解剖基础，也各有各的失效方式。

第一道，软腭上提封闭鼻咽。 靠腭帆提肌与腭帆张肌。失效时食物从鼻腔反流——这是软腭麻痹最典型的体征，也是腭裂修复要解决的第一件事。判据很干净：喝水时鼻腔流出，说话带鼻音。

第二道，舌根后缩与咽缩肌收缩。 舌根向后贴住咽后壁，把食团往下推，同时形成压力。失效时食物残留在咽部（吞咽后咽部有存留感、声音「有水泡音」），下一次呼吸就可能吸进去。

第三道，喉上提、声带闭合与会厌翻转。 三者是同时发生的：喉被向前上提，声带内收关闭，会厌被舌根与喉的上提推倒，盖住喉口。这是四道里最「机械」的一道，也是最容易被结构改变破坏的一道——会厌的翻转依赖喉的上提，喉的上提依赖舌骨上肌群与舌骨的稳定（第 3 章已讲：固定哪一端，就动哪一端）。

四、误吸与四道保护

第四道，声门下的咳嗽反射。 前三道是「不让进」，第四道是「进了要出来」。它的存在意味着：没有咳嗽反射的人，误吸可以是无声的——没有呛咳、没有明显症状，只有反复的低热或肺部影像改变。这一条最要紧，因为它推翻了「不呛就没事」的常识。

四道保护合起来有一个时序判据：保护必须在食团到达喉口之前完成。 所以咽期不是「力量够不够」的问题，是「快慢对不对」的问题。老年人、卒中后、意识下降者、长期留置管者，四道保护往往没有「坏掉」，而是「慢了一拍」——这一拍之差，就是误吸与安全的全部距离。

五、结构缺一段之后：三类代偿

咀嚼与吞咽的解剖一旦缺一段，机体不会坐等，会走代偿。三类代偿最常见，也最能说明结构与功能的关系。

牙列缺失的代偿。 后牙缺失后，患者会自动把食团移到前牙区，用前牙的切缘去「切」本该由后牙「磨」的食物；同时咀嚼周期缩短、次数增加。代偿的表现是「还能吃」，代价是前牙承受了它没被设计来承受的力：前牙单根、冠薄，长期如此出现磨耗、松动、甚至移位。这也是「缺一颗后牙不修，几年后前牙出问题」的解剖解释。

腭裂修复后的代偿。 软腭的封闭功能靠肌的悬吊与腭腱膜的张力；修复后，瘢痕与肌的重排使上提不完全，患者会用舌根与咽后壁的接触来「补」这道封闭（通行称咽部代偿）。代偿有效时鼻音减轻，无效时需二次手术。这一条说明：解剖结构可以补，功能重建要靠训练。

五、结构缺一段之后：三类代偿

舌切除后的代偿。 舌是口腔期的主力：收拢食团、压送、后推，三件事都靠它。部分切除后，剩余舌体通过加大运动幅度、借助重力与头位改变来完成推送；全舌切除者则几乎完全依赖重力与头位。「进食要低头」这个体位建议，解剖依据就在这里——它把口腔期从「主动推送」改成「顺势滑落」。

三类代偿有一个共同点：它们都改变了力的分布，而不是恢复了原结构。 所以代偿期的患者需要的是「监测哪一处被过度使用」，而不是「能吃就没事」。牙的磨耗面、修复体的松动、咽部的残留感，都是代偿过载的早期信号。

代价与边界
  1. 不给数值与时程。 咀嚼周期的时长、各相占比、咀嚼次数、吞咽频率、咽期持续时间，一律不给；这些量随食物性质、个体与年龄变化极大，写成常数会误导。本章只给分相与时序。
  2. 不给康复方案与饮食处方。 吞咽训练的具体手法、食物性状的分级、代偿体位的选择，属言语治疗与康复专业范围；本章只解释「为什么要在这个时点防」。
  3. 五相的分法不是唯一的。 通行教材对咀嚼周期的划相有差异（三相、四相、五相都有），本章取五相以便与关节、肌的分工对应；具体划法不同不影响「哪一相出事、症状在哪」这一层判断。
  4. 不把误吸当口腔问题。 本章只说明四道保护的解剖基础与失效表现；误吸的评估与处理属多学科范围（含影像吞咽评估），不在本课。
