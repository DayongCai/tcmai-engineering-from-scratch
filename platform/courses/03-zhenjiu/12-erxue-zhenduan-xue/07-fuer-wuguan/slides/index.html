PROBLEM

底本第 7 章五节 2,636 汉字，按病种分：鼻病两节 1,479 字（鼻渊 807、鼻鼽 672），耳病两节 700 字（耳鸣耳聋 371、聤耳 329），妇科一节 457 字（月经不调）。章名写的是「妇儿与五官」，现算下来五官占 2,179 字（82.7%）、妇科占 457 字（17.3%）、儿科占 0 字。更要紧的是结构：只有鼻病两节带治疗段与耳针方（各 1 处），耳病两节与妇科一节全部止于「辨证要点」，一个字的主穴都没有。也就是说，这门课里最有资格谈耳穴的地方——耳病——恰好是最薄的地方：700 字，占全章 26.6%，且不给方。这不是巧合，是底本按父课《针灸治疗学》的病证表选材时留下的缺口。

双根因定位

环境逼迫（妇、儿、五官三类人群的差别不在经穴图上，而在耐受与禁忌上：孕妇的腰骶与合谷三阴交至阴要避开，小儿的刺激量要减，耳廓本身正在发炎时不宜再刺——这些都不是「多背几个穴」能解决的，必须换一套准入条件）+ 知识积累（父课按病证平铺，每个病证写成一节，篇幅由该病证在教材里的地位决定，与它在耳穴这门技术里的风险高低无关；于是鼻渊写得最厚、聤耳写得最薄，而聤耳（化脓性中耳炎）恰恰是耳穴施术部位正在感染的那一种）

一、字数倒挂：最薄的两节，是最该厚的地方

先看一组可核的对照：

病证节汉字有无治疗段有无耳针方
鼻渊7.1807有有
鼻鼽7.2672有有
月经不调7.3457无无
耳鸣耳聋7.4371无无
聤耳7.5329无无

最长的鼻渊是最短的聤耳的 2.45 倍。按「耳穴诊治学」这门课的立场，这个比例是反的：鼻渊的耳针方（内鼻、外鼻、肾上腺、额、肺、胆、脾、胃）只是众多治法里的一项，患者不必靠耳穴；而聤耳是耳内流脓，耳廓与外耳道正在炎症之中，耳穴施术的第一问题不是「取哪些穴」，而是「这时候能不能碰这只耳朵」。

底本在这里给不出答案，因为它连治疗段都没写。本章的处理办法是把缺口写明，不替它补方：耳病两节的耳穴处方，本课不给。 给的是缺口清单——缺治法、缺主穴、缺操作、缺禁忌；这四项恰好是任何一种疗法进入临床前必须齐备的四项。

二、鼻病两方对照：同一个部位穴，配穴随病机反转

两节都给了耳针方，而且可以逐穴对照，这是本章最有教学价值的一段。

鼻渊（鼻流腥臭浊涕、鼻塞、嗅觉减退；病位在鼻，与肺、脾、胃、胆关系密切，基本病机是邪壅鼻窍）的耳针方：「取内鼻、外鼻、肾上腺、额、肺、胆、脾、胃。每次选 3～5 穴，毫针刺法，或埋针法、压丸法。」八个穴，取三到五个。

鼻鼽（鼻痒、打喷嚏、流清涕、鼻塞，呈季节性阵发性；病位在鼻，与肺、脾、肾三脏关系密切，基本病机是脾肾亏虚、肺气不固、邪聚鼻窍）的耳针方：「取内分泌、内鼻、肺、脾、肾穴。毫针刺法，或埋针法、压丸法。」五个穴。

对照三处：

共有的两个：内鼻、肺。 病位都在鼻，肺开窍于鼻，所以这两个穴不动。这一条把「相应部位穴 + 脏腑对应穴」这个骨架立住了。

二、鼻病两方对照：同一个部位穴，配穴随病机反转

换掉的两个：胆、胃 → 内分泌、肾。 鼻渊的分型是肺经风热、胆腑郁热、脾胃湿热，三型都在「邪」，所以配穴取胆、胃以清郁热与湿热；鼻鼽的分型是肺气虚寒、脾气虚弱、肾阳亏虚、肺肾阴虚，四型都在「虚」，所以配穴取肾与内分泌以调补。同一只耳朵，同样的鼻病，配穴的方向相反——这是「辨证选穴」四个字在耳穴上唯一能落的实处。

加减的两个：外鼻、额、肾上腺。 这三个只在鼻渊方里出现。外鼻是局部加强，额与鼻窦的解剖位置相近，肾上腺在耳穴临床上多用于抗炎抗过敏一类的作用。底本没有解释为什么鼻渊用而鼻鼽不用，本章不替它解释，只把差别标出来：八个穴不是一张固定处方，而是「每次选 3～5 穴」的一个池子，池子大是因为证型多（三型），池子小是因为证型同属虚（四型却只用五个穴，说明选穴数不随证型数增加）。

二、鼻病两方对照：同一个部位穴，配穴随病机反转

两节的体针部分还提供了一个可比的旁证：鼻渊主穴是迎香、印堂、上迎香、通天、列缺、合谷，方义自称「三部配穴法」（局部三穴 + 远端表里经）；鼻鼽主穴是上迎香、印堂、风门、足三里，方义强调「足三里为强壮要穴，可益气固表」。连体针都在同一处分岔：一个清，一个补。

三、耳病两节：缺口是可以点清的

耳鸣耳聋（371 字）给了主症、病位（肾开窍于耳，少阳经入于耳中，与肝胆肾关系密切）、病机（邪扰耳窍或耳窍失养）、三个证型（外感风邪、肝胆火盛、肾精亏虚）与各自的舌脉，然后结束。

聤耳（329 字）给了主症（耳内疼痛、流脓、耳胀闷或耳鸣、听力下降）、病位（手足少阳经皆入于耳，属少阳经病变）、病机、四个证型（风热上壅、肝胆火盛、脾虚湿滞、肾阴亏虚）与舌脉，然后结束。

两节的结构完全一样：病名 → 病因病位 → 基本病机 → 西医对应病 → 辨证要点（主症 + 分型舌脉）。缺的那一段，是底本在其他三节都写了的「治疗」。

三、耳病两节：缺口是可以点清的

这个缺口为什么不能靠类推补上？因为耳穴治耳病与体针治耳病不是同一件事。体针取听宫、翳风、中渚、侠溪一类，针尖落在耳周与远端；耳穴的施术部位就是耳廓本身，而聤耳的病位也在耳——患病部位与施术部位重合。重合带来两个体针没有的问题：一是局部皮肤可能已有炎症、破损或渗液，消毒与准入的判断要先于取穴；二是耳廓血运差、抗感染力弱（这一点在第 5 章的解剖段里说得很清楚：除耳垂外均有软骨，皮肤与软骨膜紧贴，皮下组织少），一旦感染波及软骨，处理起来比别处麻烦。

所以本章对耳病给出的不是方，是三条准入判断：耳廓及耳周皮肤是否完整（有破损、渗液、明显红肿则不在患处施术）；有无流脓及脓液性质（聤耳主症即为流脓，这本身就是局部存在感染灶的证据）；是否需要先转专科（底本在鼻渊按语里立过一条规矩：「对慢性鼻渊反复发作者，应做专科检查，及时排除肿瘤」——同一个道理，慢性化脓性中耳炎、胆脂瘤型中耳炎应先由专科处理，不是耳穴能替代的）。

四、妇与儿：底本给了一个病证，儿科是零

妇科只有月经不调一节（457 字），而且只到辨证：先期三型（实热、虚热、气虚）、后期四型（血寒、血虚、肾虚、气滞）、先后无定期二型（肝郁、肾虚），共九型，各有经量、经色、经质与舌脉。治法、主穴、耳针方一概没有。

儿科是零。章名里有「儿」，底本第 7 章五节没有一节讲小儿病证。

这两个空白合起来说明一件事：本章真正能教的是人群带来的准入变化，不是病证清单。底本在别处恰好留了可用的材料——第 8 章讲穴位埋线的禁忌时写得极具体：「孕妇尤其是妊娠 3 个月以内者，禁止在腹部、腰骶部及合谷、三阴交、至阴等通经活络作用较强的穴位埋线，以免扰动胎气引起流产；月经期妇女下腹部及腰骶部穴位亦宜慎用。」这条讲的是埋线，但它的判断方式可以搬到耳穴上：先看人群状态，再看穴位。妊娠期、经期、哺乳期各自对应不同的禁区，这与「取哪几个穴」无关，与「现在能不能做」有关。

四、妇与儿：底本给了一个病证，儿科是零

小儿这一头，底本一个字没有，本章也不编。能说的只有一条结构性的：小儿的耳廓更小、软骨更软、配合度更低，取穴精度与固定（压丸、埋针）都更难；凡涉及小儿的刺激量、留针时间与操作方式，须另据儿科针灸的规范与教材，本章不给数，也不给方。

五、代价与边界
  1. 耳病（耳鸣耳聋、聤耳）的耳穴处方，本课不给。 底本两节止于辨证，缺治法、主穴、操作、禁忌四项；本章只给准入判断，不补方。
  2. 妇科只到辨证。 月经不调九型的舌脉可背，但底本没有给任何治疗段落；本章不臆造主穴与疗程。
  3. 儿科为零，本章明说为零。 不从成人病证类推小儿剂量，也不从埋线禁忌类推耳穴禁忌的具体数值——只继承「先看人群状态」这个判断顺序。
  4. 鼻病两方是底本原文，不是本章的优化。 八穴与五穴的差别、为什么鼻渊用肾上腺而鼻鼽不用，底本未解释，本章只标差别、不补解释。
  5. 本章不替代专科。 鼻渊按语已要求慢性反复发作者做专科检查排除肿瘤；聤耳涉及化脓性中耳炎、胆脂瘤型中耳炎，须先由耳科处理。耳穴在这些病证里是辅助位置，本章不把它写成主治疗。
