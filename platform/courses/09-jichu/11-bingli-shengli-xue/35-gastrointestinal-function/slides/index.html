这一章讲的全是正常功能，看起来像生理学的复述：慢波、胃酸、胰液、胆盐、刷状缘酶、屏障四层。可它的用处不在记住这些名词，而在得到一个反推法——胃肠病的症状是一组极不特异的词：腹胀、腹痛、腹泻、便秘、体重下降、贫血。同一组词既能由推进太慢引起，也能由推进太快引起；既能由分泌不足引起，也能由分泌过多引起。若不先立起四类功能的链条，这些词就只是六张互不相干的标签，症状再重也读不出环节。本章真正要交的是一句话：症状指向环节，而不是指向病名。

一、四类功能不是四个器官，而是一条链

35.1 先把消化道写成一条从口腔到肛管的肌性管道，管壁由内向外分黏膜层、黏膜下层、肌层与外膜，三层各担一事：黏膜承担分泌、吸收与屏障，黏膜下层承载血管、淋巴与神经，肌层负责运动。随后是本章的骨架句——功能被拆成运动、分泌、消化与吸收、屏障与免疫四条主线，而这四条不是并列的器官功能：

「四条主线不是并列的器官功能，而是同一条链上的四个环节」——补充·hermes-病理生理学讲义·第35章·35.1

链的写法决定了读法。运动负责位置与速度，分泌提供化学环境与酶，消化吸收把大分子拆成可转运的小分子，屏障决定「什么能进来、什么必须挡在外面」。四段首尾相接，任一环失衡，症状都落在同一小组表现上。

这条链最实用的地方在下半句：

「从症状反推环节，是本章的基本方法」——补充·hermes-病理生理学讲义·第35章·35.1

一、四类功能不是四个器官，而是一条链

反推要问三个问题：推进太慢还是太快、分泌不足还是过多、面积不够还是酶不够。三个问题各自对应一组不同的追查方向，也各自对应不同的处理重心——这三问就是本章后面九节的索引。

6 / 27body
二、运动：两个变量，四种收缩

35.2 把平滑肌收缩拆成电活动与机械活动两层。起搏细胞是 Cajal 间质细胞，它产生慢波，即基本电节律：

「慢波本身通常不引起收缩，但它设定收缩的节律与最大频率」——补充·hermes-病理生理学讲义·第35章·35.2

慢波定节律与上限，叠加其上的动作电位（钙内流）定强度。两个变量一分开，运动障碍就自动分成两类：起搏与节律异常（ICC 丢失、电活动紊乱），以及兴奋-收缩耦联异常（离子通道、受体与信号通路）。分类不是背出来的，是从两个变量里长出来的。

收缩形式有四种，各管一件事：蠕动由腔内容物扩张触发，口侧收缩、肛侧舒张，把内容物向前推；分节运动是局限的环形收缩，只混合不推进；紧张性收缩见于括约肌与胃底，维持基础张力；禁食期间还有移行性复合运动，以周期性清扫把残余内容物与细菌推向结肠。第四种形式常被低估——它一减弱，小肠细菌过度生长就有了条件，而这条线索在只问排便习惯的框架里根本看不见。

二、运动：两个变量，四种收缩

「推进力弱不一定表现为便秘」——补充·hermes-病理生理学讲义·第35章·35.2

推进弱而括约肌协同正常，表现是腹胀与排空延迟；括约肌在排便时反常收缩，表现才是排出困难。两者机制不同，处理方向也不同——同一句「便秘」，底下可能是两种病。

8 / 27body
三、括约肌：同一类结构，两个方向的病

35.3 把传输写成一道分段控制的闸门：上、下食管括约肌，幽门，回盲瓣，肛门内、外括约肌。下食管括约肌的张力由肌源性特性、抑制性神经递质与激素共同决定，餐后的一过性松弛是生理性反流的主要机制；松弛过频或基础张力过低，反流才由生理转为病理。

胃排空遵循液体先于固体、可消化先于不可消化的顺序，并受十二指肠反馈调节：腔内脂肪、酸度升高与高渗都会减慢排空。这是一种保护性的刹车，使小肠有时间处理负荷——把它读成「胃动力差」，方向就反了。传输时间测定把便秘分成慢传输型与排出障碍型，前者推进力不足，后者括约肌协同失调。

这一节给了一条可以复用到全章的对照：

「同一类结构，两个方向的病变，症状完全相反」——补充·hermes-病理生理学讲义·第35章·35.3

张力过低则内容物逆行，张力过高或不松弛则内容物淤滞。记住这一条，动力性疾病就不再需要逐个记：先问这个括约肌该开还是该关，再问它开得过头还是关得太死。

四、胃的分泌：三步换位与三促三抑

35.4 从腺体的细胞构成讲起：壁细胞、主细胞、黏液颈细胞，加上散在的内分泌细胞——G 细胞分泌胃泌素，D 细胞分泌生长抑素，ECL 细胞分泌组胺。

盐酸分泌的机制被压成「三步换位」：壁细胞内碳酸酐酶把二氧化碳与水合成碳酸，解离出的氢离子由质子泵泵入腺腔换取钾离子；碳酸氢根则经基底侧与氯离子交换进入血液，形成餐后短暂出现的碱潮。这一步的副产品值得记住——胃在泌酸的同时向血里送碱，两件事是同一个动作的两面。

同一条通路还带出两件必需品。胃蛋白酶原由主细胞分泌，需在酸性环境中自我激活，所以胃酸是蛋白消化的前提；内因子也由壁细胞分泌，它与维生素 B12 结合后在回肠末端被识别吸收。于是「酸少」不只是消化问题，还是吸收问题——这一句把 35.4 与 35.7 提前接上了。

调节是「三促三抑」：乙酰胆碱、胃泌素与组胺三者协同放大分泌，组胺是共同的最后通路；生长抑素、前列腺素与腔内酸度升高构成的负反馈抑制分泌。讲义由此推出两个现象：

四、胃的分泌：三步换位与三促三抑

「抑酸治疗会抬高胃泌素水平，停药时可能出现酸分泌的反跳」——补充·hermes-病理生理学讲义·第35章·35.4

第二个现象是长期强效抑酸使胃内酸度偏低，影响铁与维生素 B12 的吸收并改变腔内菌群。两个现象合起来说明一件事：抑酸不是把一条通路关掉，而是把整个负反馈环整体平移——环一动，远处的指标跟着动。

五、胰液与胆汁：酶量与溶媒体积必须匹配

35.5 把外分泌分成两半：腺泡细胞合成酶与酶原，导管细胞分泌富含碳酸氢盐的液体。促胰液素由十二指肠腔内酸度升高触发，作用于导管细胞；胆囊收缩素由脂肪与蛋白分解产物触发，作用于腺泡细胞。二者分工的要点是：

「只有酶没有液体，酶无法被送达并发挥作用」——补充·hermes-病理生理学讲义·第35章·35.5

这句话解释了一类容易被误读的情形：酶本身不缺，缺的是把酶送到的介质。查「酶」查不出问题，不等于分泌功能完好。

胆汁这一半讲得极省，却埋伏了一个高频记错点。胆盐是胆汁酸与甘氨酸或牛磺酸的结合物，具两亲性，能把脂肪乳化为微胶粒：

「它是物理乳化剂，不是酶」——补充·hermes-病理生理学讲义·第35章·35.5

乳化与水解是两件事。把胆盐当酶，就会在脂肪泻的推理里找错环节。胆盐在回肠末端被主动重吸收，经门静脉回肝，构成肠肝循环，使有限的胆盐池反复使用；胆囊在消化间期浓缩并储存胆汁，进食后收缩排空。

五、胰液与胆汁：酶量与溶媒体积必须匹配

小肠的分泌与吸收则同时进行：隐窝细胞分泌氯离子与水，绒毛上皮吸收，净流向决定粪便含水量。分泌侧被持续激活而超出结肠回收能力时，就是分泌性腹泻的原型——这一句是 36.10 分型的前身。

六、消化两期与吸收地图

35.6 把消化分两期。腔内消化靠酸、胃蛋白酶与胰酶，把大分子切成寡聚体；膜性消化靠刷状缘酶完成最后一步，并且酶与转运体紧邻，使水解产物就地吸收。讲义对这一设计的评价只有一句：

「水解与转运耦联」——补充·hermes-病理生理学讲义·第35章·35.6

耦联的用处是避免产物在腔内被细菌利用或稀释——效率不是靠酶更强，而是靠位置更近。

六、消化两期与吸收地图

三条营养通路的写法各有侧重。碳水化合物：淀粉经唾液与胰淀粉酶切成麦芽糖与极限糊精，刷状缘的麦芽糖酶、蔗糖酶、乳糖酶再水解为单糖；膳食纤维不被人体酶分解，在结肠被菌群发酵为短链脂肪酸，为结肠上皮供能。蛋白质：胃内酸与胃蛋白酶初步水解，小肠内胰蛋白酶、糜蛋白酶与羧肽酶继续切割，刷状缘肽酶切成氨基酸；小肽还可经 PepT1 直接吸收，在氨基酸转运体缺陷时这条通路仍是重要补偿。脂肪走一条最长的链：胆盐乳化 → 胰脂肪酶与共脂肪酶作用 → 单酰甘油与游离脂肪酸 → 与胆盐形成混合微胶粒 → 在上皮表面释放并扩散入胞 → 在内质网重新酯化 → 组装乳糜微粒 → 经淋巴入血。

脂肪这一链的用处在于它把脂肪泻拆成四类原因，且四类各有不同的伴随表现：

「胰酶不足、胆盐缺乏、黏膜面积减少或淋巴回流受阻」——补充·hermes-病理生理学讲义·第35章·35.6

四类原因对应四种伴随表现，这句话是全章最省力的鉴别框架之一：不看粪便看伴随，伴随指向环节。

六、消化两期与吸收地图

35.7 补上部位地图，这张图是解释局限病变症状的钥匙。十二指肠与近端空肠吸收铁与钙，铁以二价形式经转运体进入细胞，胃酸有助于铁的还原与释放；钙的吸收依赖维生素 D 诱导的钙结合蛋白。回肠末端专司维生素 B12-内因子复合物与胆盐的重吸收。结肠主要回收钠与水，受醛固酮调节，并吸收短链脂肪酸。

地图一立，三条推论自动出现：

「回肠末端切除或病变，同时造成维生素 B12 缺乏（巨幼细胞性贫血）与胆盐丢失」——补充·hermes-病理生理学讲义·第35章·35.7

一处于病变，两个系统受累：B12 缺乏走贫血方向，胆盐丢失走腹泻方向（胆盐进入结肠刺激分泌）。胃大部切除则使铁与维生素 B12 的吸收双重受损；广泛小肠切除导致短肠综合征，剩余黏膜面积不足以维持吸收。讲义还给了一句诊断学上的提醒：吸收障碍的表现是选择性的，因为各营养素依赖的环节不同——脂肪与脂溶性维生素最先受累，随后是蛋白质与矿物质。评估时按营养素逐个核对，而不是只看体重。

七、屏障四层与前列腺素

35.8 把黏膜屏障写成四层：黏液-碳酸氢盐层构成物理化学屏障，使上皮表面维持近中性；上皮层靠紧密连接封闭细胞间隙；黏膜免疫层以分泌型 IgA、黏膜相关淋巴组织与派尔集合淋巴结识别并清除抗原；黏膜下血流与修复机制提供能量与细胞更新。

四层里最容易被低估的是最后一层。血流不是背景条件，而是修复的物质前提——这一点在下一句里被点成机制：

「促进黏液与碳酸氢盐分泌、增加黏膜血流、加速上皮修复」——补充·hermes-病理生理学讲义·第35章·35.8

这是前列腺素的三条保护通路。非甾体抗炎药抑制环氧化酶，三条同时被削弱，这就是药物性溃疡的机制核心，也解释了为什么这类药物在没有酸相关症状的人身上同样能造成黏膜损伤——损伤的门槛不在症状，而在屏障的余量。

屏障受损后，腔内细菌与抗原易位，激活黏膜免疫，炎症介质又进一步破坏紧密连接，形成通透性升高、炎症、更通透的正反馈。讲义在这里加了一句分寸很紧的限定：

八、肠神经与脑-肠轴：为什么同一刺激有两种症状负荷

35.9 讲肠神经系统：肌间神经丛与黏膜下神经丛，神经元数量庞大，

「能在脱离中枢的情况下独立完成局部反射」——补充·hermes-病理生理学讲义·第35章·35.9

腔内扩张引起口侧收缩、肛侧舒张，就是最典型的一例。但它并非独立王国，持续被交感与副交感通路调制。

脑-肠轴是双向的：迷走神经以传入为主，把内脏机械与化学信号送往上位中枢；下行通路通过自主神经与 HPA 轴调节动力、分泌与通透性。第三类感受器是肠内分泌细胞：肠嗜铬细胞产生体内大部分的血清素，参与蠕动与分泌反射；L 细胞分泌 GLP-1，I 细胞分泌 CCK。

由此得到功能性胃肠病的整合模型，讲义把它写成一条箭头链：

「心理社会应激 → 中枢放大与自主神经失衡 → 内脏高敏感 + 动力异常 + 黏膜低度炎症 + 菌群改变 → 症状」——补充·hermes-病理生理学讲义·第35章·35.9

八、肠神经与脑-肠轴：为什么同一刺激有两种症状负荷

这条链解答了一个常被问偏的问题：决定症状负荷的不是刺激强度单一变量，而是刺激强度与放大增益的乘积。同一个刺激在不同人身上引起完全不同的负荷，不是谁在夸大，而是增益不同。

九、生命周期与餐后整合

35.10 只有两段，讲的是把前面八节放回时间轴。新生儿与婴儿的乳糖酶活性相对不足，屏障与免疫尚不完善，下食管括约肌张力偏低，因此溢乳与喂养不耐受常见。讲义对这类情形给了一句很克制的判断：

「这些多为发育性问题，随年龄改善，不宜一律按疾病处理」——补充·hermes-病理生理学讲义·第35章·35.10

老年人则是另一组变化：味觉与嗅觉减退、咀嚼与吞咽协调下降、胃酸偏低、传输减慢与菌群构成改变；同时多种合并用药通过抗胆碱能、抑酸、泻药等机制叠加影响动力与屏障。注意最后一项——药物不是背景，而是机制的一部分。

整合的落点是餐后反应：进食后胃肠血流增加、动力与分泌被协调激活，胃结肠反射是其一。讲义对此的判断是：

「任何一环失效都以同一组非特异症状出现」——补充·hermes-病理生理学讲义·第35章·35.10
