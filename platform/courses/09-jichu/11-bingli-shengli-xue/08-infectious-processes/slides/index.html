PROBLEM

感染这一块最常见的两种讲法都不够用。一种是病名式：说出病原体的名字，仿佛名字就是解释；另一种是结果式：体温上去了就叫感染，血压掉了就叫脓毒症。两种讲法都跳过同一段东西——中间那条过程。病原体怎么从「住在表面」变成「进了组织」，怎么从「一处」变成「全身」，怎么从「宿主在打」变成「宿主打失控」。这一章要交的是一条连续谱：谱上有六个可打断的环节、三道分层的防线、一条可完整复述的发热链条，以及一个必须记住的不等式——感染不等于脓毒症。

三道防线：把「平时为什么不生病」讲成机制（8.1）

8.1 的第一句就换了一个提问方式：

「健康不是没有病原体接触，而是接触被限制在屏障之外或被迅速清除」——补充·hermes-病理生理学讲义·第8章·8.1

这句话把「健康」从「干净」改成「处理得掉」。区别很重要：前者要求环境无菌（不可能），后者要求三道防线各就各位（可评估、可干预）。

三道防线各有一个可记忆的差别。第一道是屏障，讲义给的性质是：

「这层防线即时、广谱、无记忆」——补充·hermes-病理生理学讲义·第8章·8.1

第二道固有免疫，讲义写的是「在数分钟至数小时内启动」，识别危险信号而非特定病原体，也不产生记忆。第三道适应性免疫相反：有特异性、有记忆，首次应答要数天，再次应答迅速而强烈。

三道的接续关系才是本节的重点：

「屏障破损后，固有免疫负责」——补充·hermes-病理生理学讲义·第8章·8.1

后半句接的是拖延与局限，适应性免疫接的是精准清除与记住。四个动词对应四种功能：挡、拖、清、记。这四格一旦立住，后面讲防御缺损就有位置可放：

「大面积烧伤、留置导管、气管插管破坏第一道」——补充·hermes-病理生理学讲义·第8章·8.1

粒细胞缺乏与补体缺陷削弱第二道；脾切除后对荚膜菌的清除能力下降，讲义把它归在第二道与第三道之间的接口缺损。这个归类很讲究——脾既是吞噬细胞的场所，也是抗体应答的场所，缺了它，两道的衔接处先断。

由此得出本节最实用的一句结论：保持屏障完整、减少不必要的侵入性装置，是「成本最低、证据最稳的感染预防」。这句话在 8.9 会以另一副面孔再出现一次。

定植与感染：一条界线由两件事共同决定（8.2）

8.2 是全章最长的一节（427 字），也是本章的枢轴——锚点定植与侵入组织只在这一节齐备。

两个定义的差别写得极干净。定植是：

「指病原体在皮肤或黏膜表面繁殖，未侵入组织、未引起宿主反应」——补充·hermes-病理生理学讲义·第8章·8.2

感染是：

「指病原体侵入组织并引起宿主反应，可伴或不伴明显临床表现」——补充·hermes-病理生理学讲义·第8章·8.2

两个定义各含两个否定或条件：位置（表面 / 组织）与宿主反应（无 / 有）。所以界线不由一个因素决定：

「而不是由病原体种类单独决定」——补充·hermes-病理生理学讲义·第8章·8.2

讲义紧接着给的例子是全章最值得记的一句：

「同一株菌在皮肤上是常驻菌，进入血流就是致病菌」——补充·hermes-病理生理学讲义·第8章·8.2

同一株、两个身份，唯一的变量是位置。这句话废掉了某种菌等于致病菌的清单式思维。

致病力的几组因素按三问排——能不能进去、进去后能不能活、活下来造成什么：侵袭力（黏附、降解基质、跨越上皮）、免疫逃避（荚膜抗吞噬、表面抗原不断变异、降解黏膜抗体、寄居细胞内、抑制补体沉积）、毒力因子（外毒素有明确靶点、内毒素经模式识别受体触发炎症、超抗原绕过常规提呈大量激活 T 细胞）、接种量与门户深浅。最后补一类位置性概念：

「在屏障完整、免疫正常时通常不致病，在免疫受损时成为主力」——补充·hermes-病理生理学讲义·第8章·8.2

机会性病原体。它的存在说明「致病力」不是病原体单方面的属性，而是病原体与宿主状态的一个乘积。

本节末尾落到那句常见临床困惑：

「培养出某种微生物，不等于该微生物就是当前感染的病因」——补充·hermes-病理生理学讲义·第8章·8.2

判断要结合部位、数量、炎性细胞与宿主状态——四个条件，缺一个就可能把定植或污染读成病因。这与 8.7 的三条原则是同一件事的两种说法。

传播链六环与宿主因素（8.3）

从防线到传播：定植、感染与六环（8.1–8.3）

8.3 给的是本章的结构图：六个环节，任一环被打断，传播即终止。六环是病原体、储存宿主、排出门户、传播途径、进入门户、易感宿主。这张表的价值不在记名字，而在每一环都对应一组具体动作：灭菌消毒与手卫生、隔离与环境清洁、分泌物与敷料管理、手套口罩与通风、无菌技术与导管维护、疫苗与营养支持。

把六环与自己熟悉的场景对一遍，会发现院内感染几乎都落在第四、五环的接缝上：器械越过了进入门户，而操作者成了传播途径的载体。这就是 8.9 那一节要展开的内容。

六环之后是宿主因素。讲义列了七项：屏障完整性、粒细胞数量与功能、抗体与补体水平、营养状态、共生菌群构成、合并症、年龄。这一串的共同点在于可评估：

「这些因素多数可在护理评估中被识别」——补充·hermes-病理生理学讲义·第8章·8.3

这句话解释了「高危患者」这个说法为什么在病理生理学里成立——它不是标签，而是一组可点名的机制位置。同一病原体，有人清除有人重症，差的就是这七项里的某几项。

临床类型：同一病原体的多种面貌（8.4）

8.4 按四个轴切分：范围（局部 / 全身）、病程（急性 / 亚急性 / 慢性）、表现（显性 / 隐性 / 潜伏 / 携带）、来源（社区获得 / 医疗相关 / 机会性）。四轴并列，不是四选一——同一个患者可以同时落在局部、急性、显性、社区获得这四格上。

开篇一句是全节的纲领：

「同一病原体可呈现完全不同的临床类型，取决于宿主免疫与接种量」——补充·hermes-病理生理学讲义·第8章·8.4

表现那一轴的四格最容易被混。隐性感染是「无明显表现，但产生免疫应答，是人群免疫的重要来源」；潜伏感染是「病原体长期存留于细胞内、可无复制」，在免疫下降时再激活；携带状态是「持续排出病原体而无明显症状，是重要的传播源」。

10 / 28body
表现与升级：临床类型、发热与脓毒症（8.4–8.6）

三者的差别不在「有没有症状」，而在病原体还在不在、排不排、能不能被再激活：隐性感染是打完了、人没事；潜伏是没打完、被围住；携带是还在、在排。搞混的后果很实际——把携带者当隐性感染者，就会漏掉传播源；把潜伏当隐性，就会漏掉再激活的风险。

本节末句是一条流行病学规律：

「隐性感染多、显性感染少」——补充·hermes-病理生理学讲义·第8章·8.4

由它推出防控的重心：着眼群体而非只盯确诊者。因为能被确诊的只是冰山露出水面的那一角。

发热链条与急性期反应（8.5）

8.5 是本章唯一一条可以「完整复述」的机制链，讲义自己也这么定性：

「其机制是一条可完整复述的链条」——补充·hermes-病理生理学讲义·第8章·8.5

链条六步：外源性致热原 → 单核巨噬细胞释放内源性致热原 → 下丘脑局部合成前列腺素 → 调定点上移 → 产热增加散热减少 → 体温升高。六步之中，最该抓住的是调定点这个中间变量，因为它解释了两组现象：

表现与升级：临床类型、发热与脓毒症（8.4–8.6）

「调定点上移阶段患者畏寒、寒战（产热），随后才出汗退热」——补充·hermes-病理生理学讲义·第8章·8.5

畏寒不是因为冷，而是调定点被抬高了：身体把当前温度判为不够；出汗退热也不是治疗起效，而是调定点回落。由此得到一句很硬的推论：

「单纯物理降温只能缓解不适，不能改变调定点」——补充·hermes-病理生理学讲义·第8章·8.5

急性期反应是链条的下游。讲义列了四项：C 反应蛋白与血清淀粉样蛋白升高；铁调素升高导致血清铁下降；纤维蛋白原升高使红细胞沉降加快；白细胞总数升高并出现核左移。四项里面，铁那一条最值得停一下——它是主动把铁藏起来：

「通过剥夺病原体必需的铁来抑制其增殖」——补充·hermes-病理生理学讲义·第8章·8.5

这叫营养免疫。它解释了一个反直觉的现象：感染时的低铁不是「缺」，是「藏」；也因此，见低就补的思路在机制上并不自然。这一层只作机制说明，不作为任何处置依据。

急性期反应还有行为面：乏力、食欲下降、嗜睡、注意力下降，由细胞因子作用于中枢。讲义的评价很平衡——有防御价值，但「持续过久会造成肌肉分解、负氮平衡与功能衰退」。

本节末尾那处临床联系是本章最该记的例外：老年、免疫抑制、严重营养不良者的感染可以不发热，标志物也可不显著升高。所以以没有发烧排除感染是危险推理。讲义给的替代路径是看功能状态（谵妄、跌倒、进食减少）与局部线索——也就是 8.10 要展开的那三个群体。

脓毒症：连续谱的末端（8.6）

8.6 把「局部 → 入血 → 全身炎症 → 器官功能障碍」这四级写成一条线，末端是脓毒症。定义值得逐字读：

「宿主对感染的反应失调所致的、危及生命的器官功能障碍」——补充·hermes-病理生理学讲义·第8章·8.6

三个成分：宿主反应失调（不是病原体凶猛）、危及生命、器官功能障碍（不是血压一项）。定义里没有「感染」作为等号的一边，只有「由感染引起」。这就带出本节的核心不等式：

表现与升级：临床类型、发热与脓毒症（8.4–8.6）

「存在感染不等于存在脓毒症，而脓毒症也不总有血培养阳性」——补充·hermes-病理生理学讲义·第8章·8.6

机制主线五步：模式识别受体识别病原体分子 → 促炎与抗炎同时启动并失衡 → 内皮活化与损伤致毛细血管渗漏与微血管血栓 → 血管扩张与心肌抑制致有效循环血量相对不足 → 细胞氧利用障碍、乳酸升高、多器官功能障碍。五步读下来，可以看到「失调」二字落在第二步：不是没有反应，而是反应与抗反应同时过强。

由此推出两个临床要点。第一：

「决定预后的往往不是病原体数量」——补充·hermes-病理生理学讲义·第8章·8.6

后半句是宿主反应失调的程度。第二是观察重心：护理观察落在灌注与器官功能的动态变化——意识、尿量、皮肤温度与花斑、毛细血管再充盈——「而非单一体温数值」。这与 8.5 末尾那处例外严丝合缝：体温既可能不高，也可能不高却已经很重。

诊断与转归：四问与五种结局（8.7–8.8）

诊断四问与三条原则（8.7）

8.7 把诊断拆成四个依次回答的问题：

「有没有感染、在哪里、由什么引起、到什么程度」——补充·hermes-病理生理学讲义·第8章·8.7

四问的次序不能颠倒。「有没有」是定性，「在哪里」定部位，「由什么引起」定病原，「到什么程度」定范围与严重度。跳过前两问直接追病原，就是 8.2 那个困惑的来源。

标本那一栏有一句判断价值最高：无菌部位标本（血液、脑脊液、胸腔积液、关节液）「临床意义最大，因不易被常驻菌污染」。这句话是取样位置决定解释力的一个例子——同一份报告，来自无菌部位与来自有菌部位，能承载的结论完全不同。

诊断与转归：四问与五种结局（8.7–8.8）

三条原则是本节收口：先取样后用药，否则培养阳性率大幅下降；培养阴性不能排除感染（已用药、标本量不足、苛养菌、深部病灶、生物膜）；「结果须结合临床解释」，避免把定植当感染、把污染当病原。三条合起来是一句方法纪律：任何单一结果都不能独立支撑结论。炎症标志物那一栏也写了同一句——「不能单独作为诊断依据」。

五种转归与一个对比（8.8）

8.8 用一张表列五种转归：清除与修复、携带状态、潜伏与再激活、慢性化、并发症。五格之间不是程度差别，而是方向差别：前两格是病原体走了或还在但不闹，后三格是没走干净、且留下东西。

表下那句是全节的机制核心：

「之间的对比，而非单一因素」——补充·hermes-病理生理学讲义·第8章·8.8

诊断与转归：四问与五种结局（8.7–8.8）

对比的两端是病原体毒力与数量、宿主防御。这句话的价值在于它能解释清除动力学的差异：为什么有的感染几天就清、有的要几个月、有的清了还会回来。讲义给了三个机制层面的理由：胞内寄生病原体需要细胞免疫参与（抗体进不去细胞）；生物膜内的病原体难以被药物与吞噬细胞触及；无血管区域（如瘢痕、死腔）则两者都难以到达。

三个理由其实是同一件事的三个版本：到达。药要到得了、细胞要到得了，清除才可能发生。这条思路把 8.8 与 8.1 接上了——第一道防线是不让它进，转归这一节是进了之后能不能被够到。

特殊场景：医疗相关感染与三个群体（8.9–8.10）

医疗相关感染：防控的两层与一个集体责任（8.9）

8.9 先给定义：「指在医疗活动中获得的感染」，再列四类常见（导管相关血流感染、呼吸机相关肺炎、导尿管相关尿路感染、手术部位感染），然后把它们的共同机制压成一句：

「屏障被器械突破 + 器械表面生物膜形成 + 宿主防御下降」——补充·hermes-病理生理学讲义·第8章·8.9

三个加号对应 8.1 的三道防线：第一道被器械破、第二道在生物膜面前够不着、第三道被基础病削弱。院内感染不是新机制，而是三道防线同时被削的那一类情形。

防控分两层。标准预防的原则是一句视角转换：

「视所有血液与体液为潜在传染源」——补充·hermes-病理生理学讲义·第8章·8.9

特殊场景：医疗相关感染与三个群体（8.9–8.10）

这句话的意思不是人人都有病，而是不靠判断来决定防不防。额外预防按传播途径加接触、飞沫或空气隔离，并附一条时序要求：病原体未明确时，按最可能的途径先行处置，不等待结果。这条与 8.7 的先取样后用药是同一类判断——在信息不全时先做不会错的那一半。

本节末尾有一段关于耐药的表述，值得单独记：耐药不是某种药对某个人不管用，而是群体层面的选择结果，因此防控带有集体责任的性质。这句话把个体用药与群体后果连起来，也解释了为什么多用一次没关系的想法在机制上站不住。

生命周期：三个群体的不同首发（8.10）

8.10 把前面九节按人群重排一遍，三个群体的差别可以压成三句话。

儿童：免疫系统尚在成熟过程中，表现常不典型——「婴儿可仅表现为喂养差、反应弱、体温不稳」。皮疹性疾病的形态也与年龄相关。

老年：免疫衰老「使应答减弱，皮肤黏膜屏障变薄」，咳嗽与吞咽功能下降，于是首发常不是发热，而是谵妄、跌倒、进食减少。这与 8.5 末尾那处例外是同一件事的人群版。

免疫抑制者：炎症反应弱，局部红肿热痛不显著，标志物可不升高，因此需要更低的检查门槛与更密的观察。这句话反过来读，就是同样的表现在这个群体里意味着更多。

四组护理动作——评估、监测、控制、支持——按顺序排，正好对应本章的四段：评估对 8.3 的宿主因素，监测对 8.6 的灌注与器官功能，控制对 8.9 的两层预防，支持对 8.5 的全身反应。
