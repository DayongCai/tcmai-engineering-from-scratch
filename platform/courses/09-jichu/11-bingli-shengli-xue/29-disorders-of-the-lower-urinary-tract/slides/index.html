PROBLEM

下尿路疾病的主诉是几句话：尿频、尿急、排尿费力、漏尿、尿不尽。这些话都很响，却都不指向一个病名——同一句「尿频」可以是感染、可以是膀胱过度活动、可以是前列腺增生的早期、也可以是神经调控出了问题。而本章最反直觉的一条判断是：症状的响度与梗阻的程度并不平行，有的人症状很轻却已有大量残余尿与上尿路积水。本章要交的是一条分界线（上尿路伤肾、下尿路伤排尿）加三组症状（储不住、排不出、排不尽），再把每一组挂到神经、出口与膀胱三个环节上。

一、一条功能分界线（29.1）

讲义用膀胱把尿路切成两段，两段的组成、功能、动力、梗阻后果、典型症状各不相同。上尿路是肾盂、肾盏、输尿管，功能是生成并输送尿液，动力是输尿管蠕动（自主、不受意识控制），梗阻的后果是压力逆传至肾实质、肾积水与肾功能损害，典型症状是腰痛、肾绞痛、血尿。下尿路是膀胱、膀胱颈、尿道、盆底与括约肌，功能是储存与按意愿排出，动力是逼尿肌收缩加括约肌松弛（受神经调控），梗阻的后果是排尿困难、尿潴留、反复感染，典型症状是尿频、尿急、排尿踌躇、尿流细弱、尿失禁。

这条分界的用处是一句判断：

「上尿路的问题伤肾，下尿路的问题伤「排尿」」——补充·hermes-病理生理学讲义·第29章·29.1

5 / 28body
一、一条功能分界线（29.1）

它给了两组主诉两个方向：腰痛伴血尿先想上尿路（结石、感染、梗阻），尿频尿急、排尿费力、尿失禁先想下尿路（前列腺、膀胱、尿道、神经调控）。但两段不是隔绝的，讲义另给了一条通路——下尿路长期梗阻会通过双侧上尿路积水反过来损害肾功能。这条通路被称为下病上及，它是本章唯一一处上下相连的地方，也是必须早期处理下尿路梗阻的理由。写本章任何一段时，只要出现下尿路的问题不会伤肾这类推断，就是漏掉了这条通路。

二、储尿与排尿的两套开关（29.2）

排尿是两个相反过程的切换，依赖三级结构。

外周神经三支：副交感（盆神经）支配逼尿肌，兴奋时逼尿肌收缩、尿道内括约肌舒张，管排尿；交感（腹下神经）作用于膀胱体使逼尿肌舒张，作用于膀胱颈使内括约肌收缩，管储尿；躯体神经（阴部神经）支配尿道外括约肌与盆底肌，维持随意控制，管控尿。三支里两支管开关，一支管刹车。

脊髓反射：骶髓存在基本的排尿反射弧（膀胱充盈、牵张感受器、骶髓、逼尿肌收缩）。婴幼儿此反射占主导，故排尿不受意识控制。中枢调控：脑桥有储尿中枢与排尿中枢，大脑皮层（尤其额叶）对脑桥与骶髓施加抑制性控制，使排尿可在适当时间与地点进行。皮层或传导通路受损（卒中、痴呆、脊髓损伤）→ 抑制丧失 → 尿急、尿频、尿失禁，这是神经源性膀胱最常见的机制。

两级状态可以压成两句：

「膀胱松弛、出口关闭」——补充·hermes-病理生理学讲义·第29章·29.2

「膀胱收缩、出口开放」——补充·hermes-病理生理学讲义·第29章·29.2

二、储尿与排尿的两套开关（29.2）

前一句是储尿期，后一句是排尿期。本章后面所有症状都可以用这两句反推：出不了尿，是收缩不够还是出口不开；留不住尿，是膀胱太紧还是刹车失灵。

三、症状三组：储不住、排不出、排不尽（29.3）

下尿路症状分三组，分类直接对应功能异常。

储尿期症状：尿频、尿急、夜尿、尿失禁。机制是膀胱容量减小、逼尿肌过度活动（不自主收缩）或感觉过敏。常见于膀胱炎、膀胱过度活动症、神经源性膀胱、前列腺增生早期。排尿期症状：排尿踌躇、尿流细弱、排尿费力、间断排尿、需腹压辅助。机制是出口阻力增加（前列腺增生、尿道狭窄、括约肌不松弛）或逼尿肌收缩力下降。排尿后症状：排尿不尽感、尿后滴沥、残余尿增多。机制是膀胱排空不全。

三组组合起来有诊断方向：单纯储尿期症状多见于膀胱本身或神经调控问题；储尿期加排尿期并存多见于前列腺增生（出口梗阻引起逼尿肌继发改变）；排尿后症状突出提示残余尿，是感染与上尿路损害的风险标志。

然后是全章最该记住的一句限定：

「症状的严重度与梗阻程度并不平行」——补充·hermes-病理生理学讲义·第29章·29.3

9 / 28body
三、症状三组：储不住、排不出、排不尽（29.3）

理由是两个方向的错配：有的患者症状明显而梗阻轻，有的患者症状轻微却已有大量残余尿与上尿路积水。后者被称为沉默的梗阻。这一句直接否掉了「问症状就够」的做法——它要求客观评估（残余尿、尿流率、影像）不可省略。讲义用的是不可省略，不是建议；区别在于前者是流程的必要条件。

四、梗阻的位置决定后果（29.4）

同样叫梗阻，位置不同，后果迥异。

上尿路梗阻（输尿管、肾盂输尿管连接部）：压力直接作用于肾单位 → 肾积水 → 肾实质受压变薄 → 肾功能不可逆丧失。单侧者可无症状，双侧者迅速肾衰竭。

下尿路梗阻（膀胱出口、尿道）：膀胱先作为缓冲承受压力，通过逼尿肌肥厚代偿；代偿期可维持排尿，但膀胱内压升高 → 膀胱小梁形成、假性憩室；失代偿后出现残余尿 → 反复感染、结石；压力继续逆传 → 双侧上尿路积水 → 肾功能损害。

这条路径解释了一个临床现象：长期前列腺增生的患者，首发就诊原因可能是尿不出来，也可能是肾功能不全——后者说明梗阻已存在很久而未被察觉。同一个病，两种首发，差别只在有没有人量过残余尿。

梗阻的常见原因按年龄与性别分布不同：儿童以先天性狭窄、后尿道瓣膜为主；青年男性以结石、尿道狭窄为主；老年男性以良性前列腺增生与前列腺癌为主；女性以盆底器官脱垂、术后粘连为主。这条分布表的作用不是让人背，而是提示同一个症状在不同人群里指向不同结构。

五、良性前列腺增生：静态、动态与膀胱的三期（29.5）

良性前列腺增生是老年男性下尿路症状最常见的原因。它的发生依赖两个条件：年龄增长与有功能的睾丸（双氢睾酮驱动）——两个条件缺一不可，这也解释了为什么它不出现在儿童与去势者身上。

机制分两部分，必须分开理解。静态因素（解剖性梗阻）：前列腺移行带腺体与间质增生，压迫尿道，出口阻力增加。增生的程度与症状不完全相关，因为梗阻还取决于前列腺的形态与包膜张力（中叶突出者梗阻更明显）。动态因素（张力性梗阻）：前列腺与膀胱颈富含 α₁ 肾上腺素受体，交感张力升高时平滑肌收缩，梗阻加重。动态因素解释了为什么受凉、饮酒、抗胆碱能药物、拟交感药物、憋尿可诱发急性尿潴留——它们或增加交感张力，或削弱逼尿肌收缩。

五、良性前列腺增生：静态、动态与膀胱的三期（29.5）

膀胱的继发改变决定预后，分三段：代偿期（逼尿肌肥厚、收缩力增强以克服阻力，可维持排尿但尿流变细、排尿费力）；失代偿期（逼尿肌纤维化、收缩力下降，残余尿增多，出现充盈性尿失禁）；并发症期（反复尿路感染、膀胱结石、双侧肾积水与肾功能损害、急性尿潴留）。三段其实就是 29.4 那条下尿路梗阻路径的分期版本——先缓冲，再失代偿，最后累及上尿路。

六、尿潴留与四种尿失禁（29.6）

尿潴留指膀胱内有尿而不能排出。急性尿潴留突发、膀胱胀痛、无法排尿，属急症，常见诱因是梗阻基础上叠加交感兴奋（受凉、饮酒、手术、药物）。慢性尿潴留逐渐发生，膀胱容量增大而感觉迟钝，患者可能只有排尿不尽或尿频，最终以充盈性尿失禁表现——膀胱过度充盈后少量尿液不断溢出。讲义对这一型的判断很硬：

「这种「尿失禁」实质是梗阻，不是控尿能力丧失」——补充·hermes-病理生理学讲义·第29章·29.6

导尿可引出大量尿液，是重要的鉴别点。这句话的教学价值在于它把「漏」与「堵」这两个看似相反的表现接到同一个机制上：漏是堵的结果。凡是把充盈性尿失禁当成控尿能力问题来处理，方向就反了。

六、尿潴留与四种尿失禁（29.6）

尿失禁分四型，机制各不相同：压力性（盆底与尿道括约肌支持力下降，腹压升高时漏尿，见于咳嗽、喷嚏、大笑、跳跃，经产妇、老年女性、前列腺术后）；急迫性（逼尿肌不自主收缩，突然强烈尿意后不能控制，见于膀胱炎、神经源性膀胱、特发性膀胱过度活动）；充盈性（膀胱排空不全、过度充盈，见于前列腺增生、糖尿病神经病变、药物性逼尿肌无力）；功能性（排尿通路与环境、认知、行动能力不匹配，见于痴呆、行动不便、环境不便、镇静药物）。

四型的处理方向完全不同，讲义的原话是误判类型会导致完全无效甚至有害的干预。它举的例子是反向的：把充盈性当急迫性而用抑制逼尿肌的药，可能加重尿潴留。这个例子值得记住，因为它是四型分辨的「代价说明书」——分错型的后果不是无效，而是更糟。

七、尿路感染：上行与四个易感因素（29.7）

尿路感染按部位分下尿路（膀胱炎）与上尿路（肾盂肾炎），后者属肾内疾病范畴（见第 27 章），但两者常连续发生。

发病机制的核心是上行感染：肠道菌群（以大肠埃希菌为主）定植于尿道口 → 上行至膀胱 → 黏附于尿路上皮（菌毛与受体结合）→ 增殖 → 炎症。少数经血行或淋巴播散。易感因素四类：尿液滞留（梗阻、残余尿、憋尿、神经源性膀胱——尿液是良好的培养基，滞留即培养）；黏膜屏障受损（导尿、器械操作、性活动、绝经后黏膜萎缩）；病原体毒力（菌毛黏附素、尿素酶、生物膜形成，后者是导管相关感染的关键）；宿主防御下降（糖尿病、免疫抑制、尿路结构异常如反流、结石）。

两个「为什么」值得单列：女性更易患，因为尿道短而直、尿道口邻近肛门与阴道，上行距离短；妊娠期易患，因为激素致输尿管蠕动减弱与肾盂扩张、子宫压迫致尿液滞留。

七、尿路感染：上行与四个易感因素（29.7）

临床表现的方向性：膀胱炎以尿频、尿急、尿痛、下腹不适为主，可有血尿，一般无高热；肾盂肾炎则出现高热、寒战、腰痛、肋脊角叩击痛，可伴恶心呕吐。讲义把这一组差别命名为一个信号——发热与腰痛是感染已上行的信号，必须区别对待。这一句与 29.1 的分界线同轴：同一个感染，位置一换，处理与观察方向就换。

反复感染与复杂性感染要寻找结构性原因：梗阻、结石、反流、糖尿病、导管。讲义给了一句因果判断：不解决结构问题，单纯反复用药只会筛选出耐药菌。这句话把「反复感染」从一个用药问题改写成结构问题，是本章最实用的一处转向。

八、结石：一个物理化学框架（29.8）

结石的形成遵循一个四步框架：

「过饱和 → 成核 → 结晶生长与聚集 → 滞留」——补充·hermes-病理生理学讲义·第29章·29.8

四步里前三步是物理化学，第四步是解剖——滞留才让前二步的结果留得下来。促进因素包括尿量少（浓缩）、高钙尿、高草酸尿、高尿酸尿、高胱氨酸尿、尿 pH 异常（酸性易形成尿酸与胱氨酸结石，碱性易形成磷酸铵镁与磷酸钙结石），以及抑制物缺乏（枸橼酸、镁、焦磷酸抑制结晶）。

感染性结石是机制上的特例，也是本章唯一一个闭环：产尿素酶的细菌分解尿素 → 尿氨升高 → pH 升高 → 磷酸铵镁与碳酸磷灰石析出 → 鹿角形结石。这类结石与感染互为因果，结石藏菌、感染持续、结石增大，形成闭环。讲义给的结论是：

「不彻底清除结石则感染无法根治」——补充·hermes-病理生理学讲义·第29章·29.8

这句话与 29.7 的不解决结构、只反复用药这一句是同构的两句：都把「反复」归到结构上，而不是归到用药上。

八、结石：一个物理化学框架（29.8）

临床表现：结石在肾盂或输尿管移动时引起肾绞痛（腰部剧痛向腹股沟放射）、镜下或肉眼血尿、恶心呕吐；结石停留致梗阻 → 肾积水 → 感染 → 肾功能损害。这条链把 27.9 的梗阻、29.7 的感染与本章的结石接成一条，也是「下病上及」的另一种实现方式。

九、神经源性膀胱：损伤平面决定表现（29.9）

支配膀胱的神经通路受损，储尿与排尿的协调被破坏，形成神经源性膀胱。表现取决于损伤平面。

上运动神经元病变（骶髓以上，如脊髓损伤、卒中、多发性硬化）：骶髓反射弧完整但失去上位抑制 → 逼尿肌过度活动、膀胱容量小、尿急尿失禁，同时逼尿肌与括约肌协同失调（逼尿肌收缩时括约肌不松弛甚至收缩）→ 膀胱内高压 → 上尿路损害风险高。

下运动神经元病变（骶髓及以下，如马尾损伤、糖尿病神经病变、盆腔手术损伤）：反射弧中断 → 逼尿肌无反射、膀胱容量大而不收缩 → 充溢性尿失禁与大量残余尿，感染与结石风险高。

两类对照起来看，差别不在有没有尿失禁——两类都有——而在膀胱内压的方向：上运动神经元病变是高容量的高压，下运动神经元病变是大容量的低压。高压那一支的风险写在一句话里：

「这是神经源性膀胱最主要的致残与致死原因」——补充·hermes-病理生理学讲义·第29章·29.9

20 / 28body
九、神经源性膀胱：损伤平面决定表现（29.9）

指的就是膀胱内高压逆传至肾，造成积水与肾功能损害。而患者往往只关注尿失禁这一表面问题——这是本章第三次出现的注意力错位：最响的表现不是最危险的那一项。护理核心因此落在规律排空、控制膀胱内压、监测残余尿与感染、保护上尿路、皮肤与心理照护上；具体频次与方案属临床决策。

十、评估框架与预防的机制性措施（29.10）

评估从症状到机制，六步：症状归类（储尿期、排尿期、排尿后，判断是储不住还是排不出）；排尿日记（时间、尿量、饮水、漏尿事件，最廉价而信息量最大）；残余尿（区分排空不全与单纯储尿问题）；尿分析加尿培养（有无感染、血尿、结晶）；影像与内镜（梗阻部位、结石、积水、前列腺形态）；神经评估（会阴感觉、肛门括约肌张力、球海绵体反射，判断有无神经源性成分）。

预防的机制性措施五条：减少滞留（避免不必要的导尿，尽早拔除导管，必需时用闭合引流并保持通畅——打折与逆流是感染的重要途径）；保持尿量（充足饮水稀释并冲刷）；会阴清洁与排便管理（减少肠道菌群在尿道口定植）；避免滥用抗生素（防菌群失调与耐药）；特殊人群（绝经后关注黏膜萎缩、糖尿病控制血糖、梗阻者解除梗阻）。

最后一条原则把全节收口：

「无症状菌尿通常不需要处理，而导管相关感染的关键是「尽早拔管」而不是「换更高级的抗生素」」——补充·hermes-病理生理学讲义·第29章·29.10

十、评估框架与预防的机制性措施（29.10）

理由有两层：机制上，生物膜在导管表面形成，药物难以穿透；管理上，它符合抗菌药物合理使用的要求。这句是本章唯一一处直接给出取舍原则的地方，而它给的仍是方向——该做什么类别的事，不是具体方案。

十一、生命周期（29.11）

儿童：排尿控制是发育过程，夜间遗尿在学龄前属常见现象；但反复尿路感染、排尿异常、日间尿失禁需警惕先天性结构异常（后尿道瓣膜、膀胱输尿管反流），因为反流可致肾瘢痕与高血压，损害在多年后才显现。

孕妇：子宫压迫与激素作用致输尿管扩张、蠕动减弱，尿液滞留，感染与结石风险升高；感染可诱发早产，故产前检查中的尿检不可省略。

老年男性：前列腺增生与前列腺癌是两大原因，二者可并存；症状相似而性质不同，需通过指检、影像与必要时的活检区分。

老年女性：绝经后雌激素下降致尿道黏膜萎缩、盆底支持减弱，压力性尿失禁与反复感染增多；同时合并用药（利尿剂、镇静剂、抗胆碱能药）常是症状加重的原因。讲义给了一句顺序建议：

「先查用药清单」——补充·hermes-病理生理学讲义·第29章·29.11

它说这句话往往比先加一种药更有效。这句与 28.10 的避免叠加同轴：在老年下尿路症状里，最常见的可逆因素不是新病，而是已有的药。
