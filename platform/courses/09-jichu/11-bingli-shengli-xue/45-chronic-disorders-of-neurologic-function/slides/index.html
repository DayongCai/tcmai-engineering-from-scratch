PROBLEM

慢性神经病最省力的学法是按病名背症状清单：阿尔茨海默病记记忆，帕金森病记震颤，多发性硬化记复发缓解，癫痫记抽搐。四张清单背下来能答题，却答不了长期照护里天天出现的那个问题——这一位现在的表现，是病程在走，还是可治的并发症在拖。讲义把继发后果单列成一节不是凑数，而是因为慢性病的关键变量与急性病不同：急性病看时间与压力，慢性病看部位与储备。这一章要交的不是四张清单，是一条把变性、脱髓鞘、癫痫三条主线接进来的判断框架。

先把变量换掉（45.1）

急性病那一章问的是“此刻走到哪一步”，慢性病这一章问的是“哪一处环路在退、还剩多少储备”。两个问法对应两套变量：前者是时间与压力，后者是部位与储备。

讲义把慢性神经功能障碍的共同点概括为四条：神经元不可逆丢失或功能持续受损；病程以年计；代偿储备被逐步消耗；症状由可代偿走向失代偿。四条合起来推出一句很有分量的话：

「同一疾病在不同阶段的表现差异，往往大于不同疾病之间的差异」——补充·hermes-病理生理学讲义·第45章·45.1

这句话改变了分类的意义。按病名分类，是把同一阶段的不同病放在一起；按阶段分类，是把同一病的不同阶段分开看。后者更接近床边，因为床边的困难从来不是“这是什么病”，而是“现在处在哪一段”。

三条主线由此展开：变性（神经元选择性死亡）、脱髓鞘（髓鞘与少突胶质细胞受损而轴突相对保留）、癫痫（兴奋—抑制网络失衡）。三者并非互斥：多发性硬化患者可出现癫痫，阿尔茨海默病可有肌阵挛，卒中后既可有变性样退变也可有癫痫。讲义特意点明这一点，是为了防止读者把三条线读成三个抽屉。

变性：一条共同的机制，五处不同的落点（45.2–45.5）

45.2 五条共同机制

讲义列了五条：蛋白错误折叠与聚集、选择性易损性、能量与清除系统衰竭、神经炎症、朊蛋白病作为极端范例。

第一条最值得展开。β-淀粉样蛋白、tau、α-突触核蛋白、TDP-43、突变亨廷顿蛋白——构象异常使它们抵抗降解：

「构象异常使其抵抗降解」——补充·hermes-病理生理学讲义·第45章·45.2

抵抗降解只是第一步，第二步才是关键：

「把病理从一个区域传到另一个区域」——补充·hermes-病理生理学讲义·第45章·45.2

这就是“类朊蛋白式播散”。它解释了两件事：为什么变性病往往从一个局限的区域起病，然后按解剖联系扩散；为什么病程以年计而不是以天计——传播靠的是细胞间的接触，速度慢，但方向稳定。帕金森病的“由下而上、逐级播散”假说，用的就是这条机制。

第二条（选择性易损性）解释了症状的特异性来源：不同疾病累及不同环路（海马与默认网络、黑质多巴胺神经元、运动神经元、纹状体）。同一个病理蛋白，沉积在不同环路，就是不同的病。

第三、四条（能量与清除系统衰竭、神经炎症）把变性从“蛋白问题”扩展成“系统问题”：线粒体功能障碍、氧化应激、轴突运输障碍、泛素-蛋白酶体与自噬功能下降，而小胶质细胞的持续激活既清除病理蛋白又释放毒性因子，作用双向。

第五条是理论上的收口：朊蛋白病证明错误折叠本身即可致病与传播，不需要病原体、不需要基因突变。变性病的“传染性”在这个意义上是一个机制类比，不是一个公共卫生问题。

45.3 阿尔茨海默病：三联征与三种被误读

病理三联征写得清楚：细胞外 β-淀粉样蛋白斑块、细胞内 tau 神经原纤维缠结、突触与神经元丢失伴脑萎缩（以内侧颞叶与海马最先）。机制要点四条：Aβ 生成与清除失衡（散发型中清除障碍更关键）、tau 过度磷酸化使微管失稳与轴突运输中断、基底前脑胆碱能神经元受累、默认网络连接下降。

四条里最值得注意的是括号里那句“散发型中清除障碍更关键”。它把 Aβ 从“生产过多”改写成“清理不足”——同一个堆积结果，两种机制，对应两个不同的干预思路。讲义没有展开哪个更好，但把它标出来，读者就知道这里存在分歧。

临床以情景记忆受损起病：重复提问、丢物、迷路、记不住约定；逐渐累及语言（找词困难）、视空间（穿衣、认路）与执行功能；中晚期出现行为心理症状。讲义补了一句临床上极其重要的话：病程中保留的领域（如社交礼节）常掩盖缺损的严重程度。这句话解释了一个常见的误判——会客时得体的人，可能已经不能独自管钱。

本节最硬的一句是诊断上的：

「痴呆不等于阿尔茨海默病」——补充·hermes-病理生理学讲义·第45章·45.3

血管性、路易体、额颞叶变性各有特征。更重要的是必须排除可逆原因：甲状腺功能减退、维生素缺乏、抑郁（假性痴呆）、药物不良反应、硬膜下血肿、正常压力脑积水。讲义把这件事收成一句判断——

「把可逆当不可逆，是这一类疾病最常见的判断错误」——补充·hermes-病理生理学讲义·第45章·45.3

这句话的力度在于它指的不是知识缺口，而是方向性错误：一旦把可逆的当成不可逆的，后面所有的努力都会被取消。

45.4 帕金森病：环路失衡，不是“多巴胺少了”

病理是黑质致密部多巴胺神经元进行性丢失，残存神经元内出现路易小体（α-突触核蛋白）。功能后果讲义写成一个环路账本：直接通路活动下降、间接通路活动增强 → 丘脑-皮层运动输出受抑 → 运动启动困难与动作减少。

这个写法比“多巴胺不足所以动不了”精确得多。多巴胺在直接通路上是“开门”的，在间接通路上是“关门”的；同一个递质减少，两条通路的净效应相反，合起来才是运动减少。理解这一层，才能理解为什么单纯补充递质在不同阶段效果不同。

临床四主征：静止性震颤（搓丸样、情绪紧张时加重、随意运动时减轻）、肌强直（铅管样或齿轮样）、运动迟缓（起步困难、写字变小、面具脸、语音低平）、姿势步态障碍（前倾、慌张步态、冻结）。起病常不对称，自一侧上肢开始——不对称这一条在鉴别上很有用，因为它指向局灶的退变而不是全身性的代谢问题。

非运动症状的位置值得单独说：

「非运动症状常早于运动症状多年出现」——补充·hermes-病理生理学讲义·第45章·45.4

嗅觉减退、便秘、快速眼动期睡眠行为障碍、抑郁与焦虑。这组症状提示病变并不局限于黑质，支持由下而上、逐级播散的假说。它同时给了临床一个可用的窗口：嗅觉与睡眠问诊可以比运动症状更早提供线索。

治疗那一段讲的是“剂末现象”与异动症，机制落在一句话上：

「药物效应取决于受体与储备状态」——补充·hermes-病理生理学讲义·第45章·45.4

突触前多巴胺储存能力下降，血药浓度的波动被直接放大为症状波动。这是药理学上一条很通用的原则：药物的效应不只看剂量，还看靶点还剩多少缓冲。

肌萎缩侧索硬化：上、下运动神经元同时变性，累及皮层、脑干与脊髓前角。表现为肌萎缩与无力（下运动神经元体征）叠加腱反射亢进与病理反射（上运动神经元体征）——这种矛盾组合是其标志；感觉、眼球运动与括约肌多保留。呼吸肌受累是主要死因，吞咽障碍致误吸与营养衰竭是常见并发症。部分患者伴额颞叶谱系的认知与行为改变。

亨廷顿病：常染色体显性遗传，CAG 三核苷酸重复扩增；纹状体（尾状核）GABA 能神经元丢失 → 舞蹈样不自主运动、执行功能障碍与精神症状。遗传早现（后代发病更早、更重）与重复长度相关，是遗传咨询的核心议题。

两病放在一起，是为了收一句：

「同样的病理蛋白，在不同环路沉积就产生完全不同的疾病」——补充·hermes-病理生理学讲义·第45章·45.5

同样的病理蛋白，在不同环路沉积就产生完全不同的疾病。这句是本章的第二个轴：部位。

脱髓鞘：轴突没死，功能却能全失（45.6–45.7）

45.6 多发性硬化：时间多发 + 空间多发

12 / 27body
换掉变量：变性五处与脱髓鞘（45.1–45.7）

多发性硬化是免疫介导的中枢神经系统白质脱髓鞘，好发于视神经、脑室周围、脊髓、脑干与小脑。

「轴突相对保留，但随病程逐渐丢失，后者决定长期残疾」——补充·hermes-病理生理学讲义·第45章·45.6

这一句把“复发缓解”与“长期残疾”分成两件事：前者由脱髓鞘与炎症决定，后者由轴突的慢性丢失决定。所以“这次发作好了”不等于“病在好转”——两本账，两种趋势。

机制写得像一条流水线：自身反应性 T 细胞在外周被激活 → 穿越血脑屏障 → 局部炎症、髓鞘破坏与传导阻滞；炎症消退后部分髓鞘可修复，故临床呈复发-缓解。脱髓鞘轴突对温度敏感：体温升高（发热、热水浴、运动）使传导阻滞加重，出现 Uhthoff 现象——症状一过性加重而非新病灶。这与 43.3 的物理约束是同一件事，两章共用同一条机制。

诊断骨架是时间多发加空间多发。常见表现：视神经炎（单眼视力下降、眼球转动痛、色觉减退）、核间性眼肌麻痹、肢体感觉异常与无力、共济失调、膀胱功能障碍、疲劳（最常见也最易被忽视）。

讲义在这一节末尾给了一个纯临床的判断：

「症状波动不等于复发」——补充·hermes-病理生理学讲义·第45章·45.6

感染、发热、疲劳、热环境、睡眠不足都可致一过性加重；判断真复发须看持续时间与客观体征，并排除感染与代谢原因。这句话的价值在于它把“波动”与“进展”分开，而这两者对应的处理完全不同。

45.7 吉兰-巴雷：同一机制，相反体征

吉兰-巴雷综合征是急性免疫介导的周围神经脱髓鞘（部分为轴索型），多在感染后一段时间发生，机制是病原抗原与周围神经成分的分子模拟。表现为对称性、上行性弛缓性瘫痪，腱反射消失，可伴感觉异常与自主神经不稳。

四个危险点：呼吸肌麻痹（观察呼吸费力、说话断续、肺活量下降趋势）、吞咽障碍致误吸、自主神经不稳致血压与心率剧烈波动、深静脉血栓与疼痛。

讲义把这一节写成了一次对照实验：

「部位决定表现」——补充·hermes-病理生理学讲义·第45章·45.7

同一“脱髓鞘”机制，在中枢表现为反射亢进与病理反射阳性，在周围神经则表现为反射消失与肌萎缩。机制相同、部位不同、体征相反——这是全章反复强调的推理原则，也是 43.10 那张上下运动神经元对照表在慢性病里的第二次兑现。

癫痫：兴奋与抑制的账（45.8–45.9）

45.8 四个环节

癫痫是兴奋与抑制失衡导致的神经元异常同步放电。形成包含四个环节：

  • 致痫灶：局部神经元膜兴奋性增高（离子通道改变、抑制性中间神经元丢失、细胞外钾缓冲障碍、谷氨酸能活动增强、胶质细胞功能异常）；
  • 同步化与募集：通过突触传递与电场效应使邻近神经元同步放电；
  • 泛化：经丘脑-皮层环路与胼胝体扩散为全面性发作；
  • 发作后状态：抑制机制启动（GABA、腺苷、离子梯度恢复）与代谢耗竭，表现为嗜睡、意识模糊或局灶无力（Todd 麻痹）。

四个环节里，第一个是“为什么会有灶”，第二、三个是“灶怎么变成一个发作”，第四个是“发作为什么自己会停”。很多教材只讲前三个，把第四个当作余波；讲义把它单独列出，是因为它解释了发作的自限性与发作后的局灶无力——后者常被误认为新的卒中。

账与分界：癫痫的兴奋抑制账与继发因素（45.8–45.11）

阈值受多种因素调节：发热、睡眠剥夺、酒精戒断、低血糖、电解质紊乱、闪光刺激、药物相互作用。于是有一句很重要的澄清：

「有致痫灶不等于总有发作」——补充·hermes-病理生理学讲义·第45章·45.8

灶是结构条件，发作是条件被满足时的事件。这解释了为什么癫痫管理必须同时处理诱因——不是把灶去掉（多数做不到），而是把条件按住。

45.9 分类与持续状态

按起源分局灶性（可伴意识保留或受损，常有先兆，如嗅幻觉、上腹上升感、Déjà vu）与全面性（失神、肌阵挛、强直-阵挛、失张力）；按病因分结构性、遗传性、感染性、代谢性、免疫性与未知。讲义提醒分类的用途：选药方向与预后判断，而非贴标签。

癫痫持续状态的定义不按分钟数，而按机制：

「发作持续到机体自身终止机制失败」——补充·hermes-病理生理学讲义·第45章·45.9

账与分界：癫痫的兴奋抑制账与继发因素（45.8–45.11）

这一定义把 45.8 的第四个环节接了上来：正常发作会自己停，持续状态是“停不下来”。机制上是时间依赖性恶化——GABA_A 受体下调与内化、NMDA 受体上调，使同一干预随时间推移效果下降，即越晚越难治。后果包括兴奋毒性损伤、脑水肿、高热、酸中毒、横纹肌溶解、心律失常与吸入性肺炎。

处理逻辑固定：先稳定气道、呼吸与循环，尽快终止发作，再查找病因。讲义不涉及具体药物与剂量，本书照此执行。

讲义列出七类继发性、可干预的后果：运动（痉挛、腱反射亢进、阵挛、挛缩、废用性肌萎缩、骨质疏松）、吞咽与营养（误吸、脱水、营养不良、体重下降）、呼吸（通气不足、分泌物清除障碍、睡眠呼吸障碍）、自主神经（体位性低血压、膀胱直肠功能障碍、体温与出汗调节异常）、感觉与疼痛（中枢性疼痛、感觉丧失导致外伤与烫伤）、认知与情绪（注意与执行功能下降、抑郁与焦虑）、社会心理（病耻感、失业、照护者负担与耗竭）。

这七类没有一类是“神经变性”本身，却都决定生活质量。讲义把它们单列，是为了让读者养成一个分拣动作：看到一个坏转，先问它是原发缺损的延伸，还是可干预的继发后果。

讲义把这一组称为继发性、可干预的后果，与原发性缺损分栏并列（补充·hermes-病理生理学讲义·第45章·45.10）。这个并列是本章最有实操价值的一处安排，也是护理工作最具价值的着力点：它把“没办法”重新拆成两部分——一部分真的没办法，一部分只是没人管。

45.11 可塑性与康复的机制

可塑性的机制包括：突触效能改变（LTP/LTD）、轴突发芽与侧支形成、皮层代表区重组、网络代偿（对侧半球募集）、髓鞘重塑。可塑性终身存在，但随年龄与抑制性环境（胶质瘢痕、抑制性分子、慢性炎症）而受限。

康复的机制基础是任务特异性的重复训练：

「训练哪种任务，就重组哪个代表区」——补充·hermes-病理生理学讲义·第45章·45.11

强度、主动性与任务的意义性决定效果，被动维持的效果有限。早期、适量、渐进优于晚期、过量；过度训练可诱发疲劳与疼痛，反而削弱参与。这几句合起来是一条不常见的克制：康复不是越多越好，是越对越好。

安全照护要点：跌倒与外伤预防（癫痫、痉挛、体位性低血压、视力与视野缺损叠加）、误吸预防（体位、食团性状、进食速度）、皮肤与关节保护、发作时的环境安全与记录（时间、形式、意识、诱因）、用药依从性与相互作用、驾驶与职业限制的告知、照护者培训与 respite 支持。
