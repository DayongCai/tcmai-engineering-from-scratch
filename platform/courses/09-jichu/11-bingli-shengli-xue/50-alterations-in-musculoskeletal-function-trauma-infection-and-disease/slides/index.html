PROBLEM

这一章最容易被读成一串并列的病：骨折、骨筋膜室综合征、骨髓炎、骨肿瘤、废用。并列读法会漏掉一条主线——它们问的是同一件事，只是打断了维护机制的不同位置。骨折问的是力学环境与修复能力，骨筋膜室问的是封闭腔隙里的压力循环，骨髓炎问的是无血供的异物表面，废用问的是「不用就拆」这条方向一致的规则。抓住这条主线，全章就从十几种病变成一个判断：哪一层被打断、打断之后是局部闭环还是全身路径、可逆性还剩多少。

损伤分类：两条轴线交叉才定位

50.1 用两条轴线给损伤分类，两条交叉才定得住临床问题。按组织层次分五类：挫伤累及皮肤、皮下与肌肉，直接暴力致微血管破裂与组织内出血，肌肉内血肿可机化；拉伤累及肌-腱单位，过度牵伸或强烈离心收缩，最常发生于肌腱交界处；扭伤累及韧带，关节超出生理范围的应力使韧带纤维部分或完全断裂；脱位与半脱位是关节面失去正常对合，常伴关节囊、韧带与软骨损伤；骨折是应力超过骨强度，可为创伤性、疲劳性或病理性。

按受力方式分五类：直接暴力（打击、碾压，软组织损伤重，多为粉碎或横形）、间接暴力（力经杠杆传导，骨折位于受力点之外）、扭转暴力（螺旋形骨折）、牵拉暴力（撕脱骨折，韧带或肌腱附着处的骨块被拉脱）、重复应力。重复应力这一类值得单列：

「骨在修复不足时累积微损伤」——补充·hermes-病理生理学讲义·第50章·50.1

这正是疲劳骨折的机制，见于长跑与行军，也解释了为什么它的起病是隐袭的、影像早期常不显。骨折还可按是否与外界相通分闭合性与开放性（后者感染风险显著升高，是 50.7 的直接入口），按稳定程度分稳定型与不稳定型——后者决定固定方式与愈合模式，这条线在 50.4 会展开。

临床价值在于预测看不见的损伤：高能量直接暴力造成皮肤完整而深层肌肉广泛挫灭时，表面的轻伤会掩盖深部的骨筋膜室高压；而间接暴力造成的骨折，其软组织损伤相对轻、愈合条件较好。评估时必须同时问力从哪来、多大、作用多久。

骨折后的局部与全身反应

「骨折不只是骨皮质断裂，而是一次涉及局部与全身的创伤反应」——补充·hermes-病理生理学讲义·第50章·50.2

局部反应按时间推进四步。血管破裂与血肿形成：断端及骨膜、髓腔血管撕裂，血液在骨折周围聚积，骨膜撕裂的范围决定血供破坏的程度，也决定愈合潜力。炎症期：血小板脱颗粒释放趋化与生长因子，肥大细胞与中性粒细胞涌入，巨噬细胞清理坏死组织与碎屑，局部出现红、肿、热、痛与功能障碍。血管新生与细胞募集：缺氧与酸性环境稳定缺氧诱导因子，促血管内皮生长因子释放，骨膜生骨层、骨髓与周围软组织的间充质干细胞被招募。软组织修复：肌肉、筋膜与皮肤各自启动修复，血肿机化形成纤维连接。

全身反应包括创伤性应激（交感兴奋、皮质醇与儿茶酚胺升高、分解代谢占优、负氮平衡）、疼痛与睡眠障碍、发热（吸收热或感染）、失血与贫血、活动受限带来的并发症。两类特殊并发症方向必须记住：脂肪栓塞（长骨骨折后骨髓脂肪进入静脉系统，引起肺血管阻塞与全身炎症反应，表现为低氧、意识改变与皮肤瘀点）与静脉血栓栓塞（制动、血流淤滞、创伤致高凝）。

讲义在此给出一条容易被当成安慰的机制判断：局部处理永远伴随全身管理。疼痛控制不足会限制早期活动，早期活动不足又加重制动后果——这一环在本章末会以废用的形式完整呈现。换句话说，50.2 与 50.11 是同一件事的两端。

愈合三期：清理、桥接、重塑

50.3 把愈合写成再生过程，三期按主导事件命名，彼此重叠而非截然分开。

第一期是炎症与血肿期：断端血肿形成纤维蛋白网，作为细胞迁移的临时支架；中性粒细胞与巨噬细胞清除坏死组织与细小骨屑；炎症介质招募并激活间充质干细胞。此期的关键词是清理与招募。临床含义有两面，讲义写得很平衡：

「适度的炎症是愈合的必要条件」——补充·hermes-病理生理学讲义·第50章·50.3

过度抑制炎症（大剂量糖皮质激素、长期非甾体抗炎药）可能延缓骨痂形成；而反复移动断端、反复复位则不断破坏刚建立的血管与支架，使愈合在原地打转。这一句把「抗炎」与「制动」两件事同时放进了机制里，也预告了 50.4 的核心。

第二期是修复期，软骨痂转为硬骨痂，两种成骨方式并行。软骨内成骨：骨折周围的间充质细胞分化为软骨细胞，形成软骨痂，随后血管长入、软骨细胞肥大凋亡、基质钙化，被编织骨替代。膜内成骨：骨膜生骨层的骨祖细胞直接分化为成骨细胞，在骨膜下形成新骨，构成硬骨痂的外壳。软骨痂提供早期的软固定，硬骨痂提供骨性连接。第三个节点是临床愈合与骨性愈合的分离：断端被桥接、负重时不再有异常活动即临床愈合，而骨性愈合要求骨痂桥接与髓腔封闭——两者常不同步，这就是「不痛了」不等于「可以随意负重」的机制根据。

第三期是重塑期：编织骨力学性能差、结构杂乱，须被板层骨替代；破骨细胞沿应力线开凿通道，成骨细胞随后填充，形成新的骨单位；多余骨痂被吸收，髓腔重新贯通，骨逐步恢复原有形态与强度。此期完全由力学需求驱动，时程远长于前两期，且在儿童与成人、不同部位之间差异很大。重塑未完成即承受超常负荷，是再骨折的典型场景——这一句在 50.12 的康复原则里会变成一条纪律。

一期与二期愈合：力学环境决定模式

50.4 只有一节，却完成了本章最重要的一次视角转换：愈合模式不是由骨折类型单独决定，而是由断端间的力学环境决定。二期愈合（间接愈合）的条件是相对稳定、允许微小活动，典型场景是保守治疗、夹板或石膏、髓内固定、松质骨区，中间组织经过血肿、软骨痂、硬骨痂到编织骨，影像上可见外骨痂，时程特点是早期快、后期需长期重塑。一期愈合（直接愈合）的条件是绝对稳定、断端间几乎无活动，典型场景是解剖复位加坚固内固定、断端紧密对合，中间没有软骨痂、哈弗斯系统直接穿越断端，影像上无明显外骨痂、靠断端逐渐消失的透亮线判断，时程特点是早期慢、无骨痂期易被误判为不愈合。

理解这一对照的要点是：

「微动是双刃剑」——补充·hermes-病理生理学讲义·第50章·50.4

适量的微动刺激骨痂形成（机械信号促间充质细胞向成骨或成软骨方向分化），过度活动则使断端被纤维组织填充、无法桥接；绝对稳定虽能实现一期愈合，却牺牲了骨痂的生物性加固，且内固定物承受全部负荷，可能产生应力遮挡——被保护的骨因缺乏负荷而局部骨量下降，取出内固定后需重新适应。

这一节的临床结论是要背的：固定得越牢越好并不成立；康复计划必须与固定方式匹配——坚固内固定者可早期活动关节与部分负重，保守治疗者则需在保护期内限制负重。护理宣教的重点不是多动或少动，而是按这种方式允许的范围动。

50.5 按结果分三形态，机制各不相同。延迟愈合是愈合进程慢于该部位与类型的预期，但仍在推进，去除不利因素后仍可愈合。不愈合是超过合理时程仍无骨性连接，断端硬化、髓腔封闭，形成假关节；又分肥大性（血供尚可但稳定不足，断端膨大，提示生物学活跃而力学失败）与萎缩性（血供差、断端吸收变细，提示生物学失败）。畸形愈合是已愈合但对位、对线或长度不良，遗留力线异常与关节负荷分布改变。三者的区分在机制上就是一句话：进程慢、连接失败、连接但错位。

影响因素分两组。局部因素：血供（部分部位的滋养血管分布特殊，愈合困难）、感染（持续的炎症与死骨使愈合无法启动）、稳定性（过度活动）、骨缺损（超过临界尺寸的缺损无法自行桥接）、软组织嵌入（肌肉或筋膜夹在断端之间）、关节内骨折（滑液中的纤维蛋白溶解酶可溶解血肿支架）。全身因素：年龄、营养（蛋白质、钙、维生素 D、维生素 C 缺乏均不利胶原合成与矿化）、吸烟（尼古丁致血管收缩、一氧化碳降低氧输送、抑制成骨细胞）、糖尿病（微血管病变与糖基化终产物）、糖皮质激素与免疫抑制剂、放疗、慢性消耗性疾病。

讲义在这里给护理一句很实在的判断：

「上述清单中有一半是可干预的行为与营养因素」——补充·hermes-病理生理学讲义·第50章·50.5

把吸烟、蛋白摄入、血糖控制写进护理计划，其证据强度不亚于任何技术操作。这句话的分量在于它把「护理」从执行医嘱挪到了机制干预的位置上。

50.6 是全章篇幅第二长的一节，因为它给的是本章唯一一条完整的正反馈。骨筋膜室由骨、骨间膜、肌间隔与深筋膜围成，内含肌肉、神经与血管；四壁缺乏弹性，腔内内容物体积增加或外部压迫都会使室内压力升高，而压力升高又压迫薄壁静脉与小动脉，使灌注进一步下降。链条是这样闭合的：创伤、出血或水肿使室内压力升高，静脉回流受阻，渗出增加、水肿加重，压力更高，毛细血管灌注压不足，肌肉与神经缺血，细胞膜泵失效、细胞内水肿，压力再升高。

缺血最先受损的是神经（对缺氧最敏感）与肌肉（代谢需求高），因此早期表现是感觉异常与被动牵拉痛，而不是脉搏消失。讲义在这里下了一句全章最硬的判断：

「脉搏消失是晚期征象，等待它出现等于等待不可逆损伤」——补充·hermes-病理生理学讲义·第50章·50.6

沿这条线读那组经典征象，顺序立刻变得有意义：疼痛（尤其与损伤程度不相称的剧痛）、被动牵拉痛、感觉异常出现早，苍白、麻痹、无脉出现晚。护理上最重要的一句判断是：越来越痛、越来越紧、越来越麻是需要立即上报的信号，而不是等待观察的信号。

后果是缺血性肌挛缩：坏死肌肉被纤维组织替代，肌腱固定于瘢痕中，形成腕与手指的屈曲畸形伴感觉障碍。这是不可逆的结构后果，也是本章时间就是组织的最强例证。

挤压伤是另一条全身路径。大量横纹肌细胞坏死，内容物涌入循环：肌红蛋白经肾滤过，在酸性尿中形成管型、阻塞肾小管，并对肾小管上皮产生直接毒性，造成急性肾损伤；钾从坏死细胞释放，可致致命性心律失常；钙沉积于坏死肌肉造成低钙血症，加重心律失常与凝血异常；乳酸与酸性代谢产物造成代谢性酸中毒；血浆渗入受损肌肉使有效循环血量下降，引起低血容量性休克。因此处理逻辑是三条并行：容量复苏（把尿量维持住以冲刷肌红蛋白）、纠正电解质与酸碱紊乱、处理创面与坏死组织。这条线与水电解质、肾脏两个单元直接相连，是本单元最重要的跨单元接口。

骨髓炎：三条途径与三个机制难点

16 / 35body
愈合的模式与偏离：力学环境、三种形态与两个循环（50.4–50.7）

50.7 讲骨与骨髓的感染，其难治程度由骨的特殊解剖决定。感染途径有三。血源性：菌血症时细菌在血流缓慢处停留，儿童长骨干骺端的毛细血管襻血流缓慢且缺乏吞噬细胞，是典型起点；成人则多见于椎体与骨盆。邻近蔓延：从邻近软组织感染直接侵入，如糖尿病足溃疡、压疮、牙源性感染至下颌骨。直接植入：开放性骨折、手术内固定物、关节假体。致病菌以金黄色葡萄球菌最常见，其表面黏附素可结合骨基质蛋白，使细菌在骨面锚定；革兰阴性菌与厌氧菌在糖尿病足与咬伤中更常见；结核分枝杆菌则走慢性肉芽肿路径。

三个机制难点构成本病的核心。

其一是生物膜：细菌在骨面或内固定物表面分泌胞外多糖基质，形成结构化群落。膜内细菌代谢率低、表型改变，对多数抗菌手段的敏感性大幅下降，且胞外基质阻碍抗体与吞噬细胞进入；更棘手的是，生物膜可持续释放浮游菌，造成治疗后复发的循环。这正是内固定物相关感染往往需要移除植入物的原因：

其二是死骨：炎症引起骨内血管血栓形成与骨膜血管破坏，局部骨组织缺血坏死。死骨无血供，药物无法到达，又成为细菌的庇护所；同时炎症刺激骨膜形成新生骨壳（包壳），把感染包裹在内部。慢性骨髓炎的经典三联是死骨、包壳与窦道——窦道反复排脓、时闭时开，可迁延多年。其三是缺血与硬化：慢性炎症使骨硬化、髓腔纤维化，血供进一步恶化，形成越慢性越缺血、越缺血越难治的循环。

临床联系：急性期以全身中毒症状、局部剧痛、压痛与活动受限为主；慢性期则以反复窦道排脓、局部肿痛、全身症状轻微为特点，容易被误认为皮肤问题。评估时须问清有无开放性损伤史、手术史、糖尿病与免疫抑制状态——这三项决定了途径与难治程度。

感染性关节炎与骨关节结核：两种时间尺度

50.8 用一个对照把关节感染的两种面貌分开。感染性（化脓性）关节炎是关节腔的细菌感染，多经血行播散；滑膜血管丰富、衬里层缺乏基底膜屏障（49.7 给的结构），使细菌极易在此种植并迅速引起滑膜中性粒细胞浸润。关节腔是一个相对封闭的空间，缺少补体与调理素的持续补充，细菌得以快速增殖；中性粒细胞释放的蛋白酶、活性氧与炎症因子在杀灭细菌的同时直接降解软骨基质。因此软骨破坏可在很短时间内发生，属骨科急症——引流加抗菌必须尽早，任何延迟都以永久性关节损伤为代价。

骨关节结核走另一条路径：结核分枝杆菌引起肉芽肿性炎症，起病隐匿，全身中毒症状轻（低热、盗汗、消瘦、乏力），局部以疼痛、肌肉痉挛与活动受限为主。病理上以骨破坏为特征，可形成冷脓肿（无红热的脓肿）与窦道；脊柱结核累及椎体，可致椎体塌陷与后凸畸形，若压迫脊髓则出现神经症状。与化脓性感染相比，结核的炎症反应温和而破坏持久，因此：

这是它最危险的地方——不是炎症猛烈，而是慢得让人放松警惕。

鉴别方向由六项组成：起病速度（急骤对隐匿）、全身中毒症状的轻重、局部红热是否明显、有无窦道与冷脓肿、既往结核接触史与免疫状态。六项里前四项由时间与局部表现给，后两项要问出来——这一节因此也是问诊结构的示范。

骨肿瘤：三条轴线交叉定位

50.9 说骨肿瘤相对少见，但分类逻辑清晰，按三条轴线交叉定位。按组织来源：成骨性、成软骨性、纤维性与纤维组织细胞性、骨髓来源、血管性与神经性、来源不明的巨细胞瘤等。按生物学行为：良性（生长局限、有包膜或边界清楚、不转移，但因占位可致病理性骨折或压迫神经）、恶性（浸润性生长、破坏皮质、可转移）、交界性（局部侵袭但转移潜能低）。按对骨的影响：溶骨性（骨破坏、透亮区、皮质变薄）、成骨性（骨硬化、密度增高）、混合性。

第三条轴线在影像与临床判断中最实用，因为它直接对应症状机制：溶骨使骨强度下降，于是疼痛与病理性骨折；成骨使骨结构紊乱但强度未必下降。这一区分把 49.5 的强度三要素直接接到了肿瘤上。

年龄与部位提供方向线索：青少年多见于生长活跃的部位（长骨干骺端），老年人则需优先考虑转移瘤与骨髓瘤。这里有一条流行病学判断必须记住：

「骨转移瘤的发生率远高于原发骨肿瘤」——补充·hermes-病理生理学讲义·第50章·50.9

因此成人发现骨破坏性病变时，从哪里转移来的是第一个要问的问题，常见原发部位为乳腺、肺、前列腺、肾与甲状腺。

疼痛的机制也值得区分：肿瘤性疼痛常为夜间痛、静息痛，与力学负荷无关；而力学性疼痛多在活动时加重、休息后缓解。这一方向性差异是最实用的床边鉴别线索之一——它与第 47 章的机制分类同轴，只是把靶点换成了有无负荷依赖。

骨转移的恶性循环：双向塑造与两条全身路径

21 / 35body

50.10 先纠正一个直觉：骨转移不是肿瘤细胞被动停留，而是肿瘤与骨微环境之间的双向塑造。链条闭合的方式是：肿瘤细胞进入骨髓，分泌甲状旁腺激素相关蛋白、白细胞介素-6、白细胞介素-11 等，成骨细胞与基质细胞上调 RANKL，破骨细胞活化，骨吸收，基质释放转化生长因子-β与胰岛素样生长因子，反过来促进肿瘤细胞增殖，更多溶骨因子释放。这条环与 49.4 的 RANKL/OPG 轴共用同一个开关，区别只在驱动者从力学与激素换成了肿瘤。

这一循环解释了三个临床现象：溶骨灶呈进行性扩大而非静止；抑制破骨细胞活性的治疗能减轻骨痛与骨相关事件，即使肿瘤本身未被消灭；不同原发肿瘤偏好不同表型（前列腺癌多成骨性，乳腺与肺多溶骨或混合性），

「因为分泌的因子谱不同」——补充·hermes-病理生理学讲义·第50章·50.10

第三点把表型差异归到了分子层，而不是归到「哪种癌更凶」这种印象上。

病理性骨折指在骨本身已有病变（肿瘤、感染、囊肿、严重骨量丢失）的基础上，轻微外力即发生骨折。其机制是强度已被削弱加上正常外力，因此预防的关键不是避免外力（无法完全避免），而是识别高危病灶并提前处理——这与 49.5 的乘法关系完全一致。

肿瘤相关高钙血症是另一条全身路径：溶骨释放的钙超过肾脏排泄与骨再矿化的能力，血钙升高，多尿与脱水（肾浓缩功能受损），进一步减少钙排泄，形成第二个恶性循环；随后出现消化道症状（恶心、便秘、食欲下降）、神经症状（乏力、意识改变、嗜睡）与心律失常。护理上，多尿、脱水、意识改变这条链一旦出现，必须同时想到高钙，而不是只补液。本节因此有两个环：一个是肿瘤与骨的环，一个是钙与肾的环，两者互相加速。

废用与制动：一条方向一致的规则

50.11 用一张表把制动的影响摊开，方向一致——不用的就拆掉，但时程与可逆性各不相同。骨：力学信号减少，硬化素升高、Wnt 下调，形成下降而吸收上升，承重部位松质骨丢失最著，部分可逆，微结构连接损失难以完全恢复。关节软骨：缺乏周期性负荷使滑液扩散营养减少、蛋白聚糖合成下降，软骨变薄、软化，早期可逆，长期退变不可逆。肌肉：蛋白合成下降，泛素-蛋白酶体与自噬介导的降解增强，肌萎缩，抗重力肌最著，可逆但恢复慢于丢失。肌腱与韧带：胶原交联与排列改变，刚度下降，可逆但需渐进负荷。关节囊与结缔组织：胶原重塑、疏松结缔组织变为致密，挛缩与活动范围受限，部分可逆，越久越难。全身：静脉淤滞、肺通气不足、负氮平衡、胰岛素抵抗、体位性低血压、便秘、情绪低落，依赖活动恢复。

「肌力下降快于肌量下降」——补充·hermes-病理生理学讲义·第50章·50.11

制动早期力量损失中相当部分来自神经因素（募集能力下降、运动单位放电频率降低），因此早期介入的等长收缩与想象性训练也能保留部分力量——这对不能负重的患者很有意义，也与 49.9 的大小原则呼应。其二，骨丢失有部位选择性：承重骨丢失最明显，非承重骨相对轻，这再次印证力学信号的主导作用。其三，儿童与老年的差异：儿童骨塑形能力强、恢复快，但长期制动可影响生长与肢体长度；老年人肌少症与骨量丢失叠加，制动数周即可造成功能状态的阶梯式下降，且常无法回到制动前水平。

对老年人而言，卧床本身是一种治疗风险，必须与收益权衡。这一句把 50.2 的全身反应与 50.12 的康复原则接在一起：制动是治疗手段，也是病理刺激，两者同时成立。

四条生理学原则支撑全部方案：超负荷原则（刺激必须超过日常负荷阈值才能引发适应——骨需要承重与冲击，肌肉需要抗阻，软骨需要周期性压缩）；特异性原则（适应的方向与刺激的形式对应——耐力训练改善氧化能力，抗阻训练增加肌量与力量，平衡训练改善姿势控制，彼此不能完全替代）；可逆性原则（去除刺激即退化，因此维持需要持续投入）；渐进原则（负荷增长须在组织耐受范围内，过快则引发再损伤）。

护理要点按时间推进。急性期：疼痛与肿胀控制、体位与支具管理、观察神经血管状态（尤其骨筋膜室综合征的早期信号）、预防深静脉血栓与压疮。早期活动期：未受累关节的全范围活动、患肢的等长收缩、呼吸训练与体位变换、尽早离床。功能恢复期：渐进负重、肌力与耐力训练、本体感觉与平衡训练、日常生活活动训练。长期：营养（足量蛋白质、钙与维生素 D）、戒烟、跌倒预防（居家环境、视力、用药复核）、体重管理。
