这一章一打开就是一堆名字：急性髓系、急性淋系、慢性髓系、慢性淋系、霍奇金、非霍奇金、多发性骨髓瘤、骨髓增殖性肿瘤。十个节，每节都在加名字。按名字记的学生，考完就忘，遇到新亚型也认不出来。可如果把十个节读成一张表，会发现临床表现只有四条来源：骨髓被占、组织被浸润、细胞因子、免疫功能异常。名字在变，四条机制不动。这一章要交的不是病名表，而是一套把名字还原到机制的读法——先问哪一系、什么成熟度、占了哪儿，再问哪一条机制在起作用，名字只是这两问的登记结果。

从造血到命名：分层放大、克隆性与三个坐标轴（11.1–11.3）

造血是分层放大的过程，阻滞就发生在层与层之间（讲义 11.1）

讲义把造血写成一条从干细胞往下的梯子：多能造血干细胞在骨髓，向下分成共同髓系祖细胞与共同淋系祖细胞，再经定向祖细胞、前体细胞逐步成熟，最后释放入血。这条梯子每一级都由转录因子程序把关，讲义把失效的后果写成一句可检验的话：

「某一转录因子缺失或异常，细胞就会停在某个幼稚阶段」——补充·hermes-病理生理学讲义·第11章·11.1

紧接着给出这个现象的名字：

「分化阻滞（maturation arrest）」——补充·hermes-病理生理学讲义·第11章·11.1

把这两句连起来读，会看到一件事：阻滞不是「长得快」，是「停在那儿」。细胞确实在增殖，只是不再往下一步走，于是骨髓里堆起来的不是成熟细胞，而是本该继续分化的幼稚细胞。这就是后面 11.4 那条主线的胚胎——骨髓被幼稚细胞占满，不是因为它们生得多，而是因为它们的出口被堵了。

从造血到命名：分层放大、克隆性与三个坐标轴（11.1–11.3）

讲义接着讲寿命差异，这一段决定了骨髓先掉谁：

「中性粒细胞数量最多、寿命短（血中数小时至数天），是急性抗感染的主力」——补充·hermes-病理生理学讲义·第11章·11.1

寿命短意味着更新快，更新快意味着对骨髓停产最敏感。淋巴细胞能再循环、在淋巴组织里长期存留，单核细胞进组织后变成巨噬细胞——它们的库存深，掉得慢。这一句解释了一个临床上很常见的次序：骨髓受抑时先出现粒细胞减少与血小板减少，贫血来得相对晚。讲义把这条次序当推论给出，不当口诀，这是它的写法：先给寿命，再让读者自己得出先后。

克隆性：从一个细胞到一群子代（讲义 11.2）

本章的根概念是克隆性。讲义的定义只有一句：

「单个细胞获得增殖与生存优势，其子代占据骨髓或淋巴组织」——补充·hermes-病理生理学讲义·第11章·11.2

从造血到命名：分层放大、克隆性与三个坐标轴（11.1–11.3）

这句里有两个词要留住：获得与占据。获得说的是优势从哪来——不是外界给的，是细胞自己改的；占据说的是结果——不是「多了一点」，是占据了别人的位置。后者直接连到第一节的梯子：占据的方式就是把出口堵住。

讲义把多步骤演进拆成四类改变：基因结构改变、原癌基因激活与抑癌基因失活、分化阻滞、微环境与免疫监视逃逸。四类不是并列的四种病，而是一条链上的四个环节——结构改变提供起点，癌基因与抑癌基因决定增殖与存活的偏向，分化阻滞决定细胞停在哪儿，微环境与免疫逃逸决定这群细胞能不能待下去。

其中第三类与第一节直接接上：

「细胞获得无限增殖能力却无法成熟」——补充·hermes-病理生理学讲义·第11章·11.2

讲义对这句的补充说明是骨髓中充满「有用功能不足」的幼稚细胞——注意它不是「没有功能」，是「功能不足」。这个措辞很紧：幼稚细胞并非完全不干活，它干得不够，而数量上又挤掉了干得够的那些。临床表现的两条主线，从这一个词上分叉。

从造血到命名：分层放大、克隆性与三个坐标轴（11.1–11.3）

多步骤这一点讲义讲得很克制，只用一句话交代：

「单一基因改变通常不足以致病，需多环节协同」——补充·hermes-病理生理学讲义·第11章·11.2

这句话有两个可用的推论：发病随年龄增长而上升（累积需要时间），以及损伤 DNA 的治疗本身会增加继发肿瘤风险（它也在制造改变）。两个推论都是机制推出来的，不是统计出来的——本章不给任何发生率，也不给任何年龄界值。

三个坐标轴：为什么名字多而类别少（讲义 11.3）

讲义面对命名混乱的办法不是列表，而是立轴：谱系（髓系 / 淋系）、成熟度（急性 / 慢性）、主要部位（骨髓为主 / 淋巴组织为主 / 浆细胞）。三轴一定，名字就成了坐标的组合。

成熟度这一轴的定义写得最实：

「急性以原始细胞为主、进展快；慢性以较成熟细胞增多为主、病程惰性」——补充·hermes-病理生理学讲义·第11章·11.3

从造血到命名：分层放大、克隆性与三个坐标轴（11.1–11.3）

把这条与第一节的阻滞对起来看：急性是阻滞发生在很早的层级（原始细胞），慢性是阻滞发生在较晚的层级（较成熟细胞仍能生成，只是数量失控）。所以「急性 / 慢性」在病理生理上不是快慢形容词，是阻滞位置的标记。这一句一旦读通，11.4 与 11.5 的差别就不用背了。

由此得到四个基本类别：急性白血病、慢性白血病、淋巴瘤、浆细胞病，另加骨髓增殖性肿瘤。讲义随即把边界写死：

「具体亚型繁多，本章只到类别层面」——补充·hermes-病理生理学讲义·第11章·11.3

这句是本课程的分工声明：精确分型依赖形态学、免疫表型、细胞遗传与分子检测的综合，那是诊断学与血液学的地盘。本章只负责类别到机制这一段。

四类疾病：急慢白血病、淋巴瘤与浆细胞病（11.4–11.7）

急性白血病：两条主线，别的一概是推论（讲义 11.4）

11.4 的写法是全章最经济的：两条主线，其余全是派生。

第一条主线是：

「骨髓被原始细胞占据 → 正常造血受抑」——补充·hermes-病理生理学讲义·第11章·11.4

三系各自掉，表现各自成组：红细胞生成减少是贫血（乏力、苍白、活动后心悸气短）；中性粒细胞减少且功能异常是感染，且因炎症反应弱而表现不典型；巨核细胞生成减少是血小板减少（瘀点瘀斑、黏膜出血、鼻衄、牙龈出血）。三组表现同源，这就是 11.8 那张表的左半边。

第二条主线是髓外浸润：淋巴结、肝、脾肿大；牙龈增生与皮肤浸润；骨与关节疼痛（骨髓腔压力升高）；中枢神经系统受累。中枢那一条讲义多给了一句机制：

「因血脑屏障使部分药物难以到达」——补充·hermes-病理生理学讲义·第11章·11.4

这句把「庇护所」这个词从比喻变成了结构说明：不是病灶顽固，是药到不了。凡是遇到某处反复不好的描述，先问屏障，再问耐药。

四类疾病：急慢白血病、淋巴瘤与浆细胞病（11.4–11.7）

起病与实验室特点那一段里，有一句是全章最该划线的：

「白细胞不升高不等于不是白血病」——补充·hermes-病理生理学讲义·第11章·11.4

为什么这句重要？因为直觉把白血病读成「白细胞太多」，而机制说的是骨髓被幼稚细胞占满。占满之后，成熟细胞出不来，总数可以升高、可以正常、可以降低——三种都成立。抓住机制的人不会被计数带着走，抓不住的人会拿一个数字去否掉一个诊断方向。讲义接着把确诊的落点写在骨髓：

「确诊依赖骨髓检查显示原始细胞比例显著增高」——补充·hermes-病理生理学讲义·第11章·11.4

注意它只说「比例显著增高」，不给任何阈值。这是本课程的一贯做法：方向可以写，取值不写；阈值属诊断标准，另立来源。

慢性白血病与骨髓增殖性肿瘤：惰性不等于良性（讲义 11.5）

慢性白血病的定义句与第三节那一轴对齐：

「分化相对保留、以较成熟细胞增多为主，病程惰性」——补充·hermes-病理生理学讲义·第11章·11.5

四类疾病：急慢白血病、淋巴瘤与浆细胞病（11.4–11.7）

但讲义立刻补了一个转折，这个转折是本章第二个反直觉点：

「原始细胞突然增多，临床转为急性白血病的表现」——补充·hermes-病理生理学讲义·第11章·11.5

名字叫「急变」。它的机制读法很清楚：慢性期的阻滞在较晚层级，细胞还留着一部分分化能力；一旦又出现一次改变把阻滞推前，同一群细胞就退回急性期的那种状态。所以「慢性」描述的是当前阻滞位置，不是承诺。把「慢性」听成「不会变急」，是把一个时点的描述读成了对未来的判断——这也是本章最容易被误用的地方。

两个代表各有一句要点。慢性髓系白血病：粒细胞系显著增生并伴特征性染色体易位，早期线索是乏力、体重下降、脾大与腹胀；讲义把它称作「分子机制转化为治疗」的经典范例，并明确注明不涉及方案参数。慢性淋巴细胞白血病：克隆性成熟小淋巴细胞在血、骨髓、淋巴结与脾中蓄积，多见于老年，早期可无症状；因正常免疫球蛋白减少而反复感染，并可并发自身免疫性血细胞减少。

四类疾病：急慢白血病、淋巴瘤与浆细胞病（11.4–11.7）

骨髓增殖性肿瘤的共同特征讲义写成一句话的三个并列：一系或多系成熟细胞过度产生；脾大；血栓与出血风险并存，以及向急性白血病转化的可能。最后补的一句很关键——症状常源于血容量增加或脾大压迫，而非白细胞高本身。这与第四节那句「白细胞不升高不等于不是白血病」是同一类提醒：别把计数当病情。

淋巴瘤：惰性与侵袭性是行为轴，不是良恶轴（讲义 11.6）

淋巴瘤起于淋巴细胞，主要累及淋巴结与结外淋巴组织。分类先按类别分霍奇金与非霍奇金，非霍奇金再按起源细胞分 B、T、NK，按生物学行为分惰性与侵袭性。讲义在这里明确：只列类别，不作分期编号。

「不明原因发热、夜间盗汗、体重下降」——补充·hermes-病理生理学讲义·第11章·11.6

讲义给的机制是肿瘤细胞与反应性细胞释放细胞因子——这与 11.8 表的第三行（细胞因子释放）是同一个来源。第三、四条是结外受累与压迫症状：纵隔淋巴结肿大可致咳嗽、气促、上腔静脉受压；腹膜后病变可致腹痛与肾积水。第五条是免疫异常：部分惰性淋巴瘤可伴自身免疫性血细胞减少或免疫球蛋白异常。

这一节真正的落点在这句：

「长得慢」不等于「良性」，「长得快」也不等于「无望」——补充·hermes-病理生理学讲义·第11章·11.6

讲义把它称作向患者解释时常需澄清的误解。从机制上说，惰性与侵袭性描述的是增殖速率与凋亡速率之比，而良性与恶性描述的是有没有侵袭与转移的能力——两个轴，不能互换。一段话里只用一个轴，混用就会得出「慢就是好」这种既不真也不假的结论。

「克隆性浆细胞在骨髓聚集 + 单克隆免疫球蛋白大量产生」——补充·hermes-病理生理学讲义·第11章·11.7

骨病变那一条机制写得最细：

「浆细胞激活破骨细胞、抑制成骨细胞」——补充·hermes-病理生理学讲义·第11章·11.7

破骨与成骨是一对平衡，浆细胞同时推一侧、压另一侧，于是溶骨性损害成立，连带骨痛、病理性骨折与高钙血症（多尿、便秘、意识改变、心律失常）。贫血来自骨髓被占据与促红细胞生成素相对不足。肾损害来自单克隆轻链经肾小球滤过造成小管损伤，加上高钙、脱水与感染共同作用——注意这是四个因素叠加，不是一个原因。反复感染来自正常多克隆免疫球蛋白被单克隆成分取代：总量不低，功能不全，这与第二节那个「功能不足」是同一种结构。高黏滞与淀粉样变来自蛋白太多：黏度升高带来头痛、视物模糊、黏膜出血，异常蛋白沉积带来器官功能障碍。

机制、诊断与治疗代价：一元论的落点（11.8–11.10）

四机制表：一元论的落点（讲义 11.8）

11.8 把 11.4 到 11.7 的现象收进一张四行表：骨髓正常造血受抑 → 贫血、感染、出血；髓外浸润与占位 → 淋巴结与肝脾肿大、骨痛、中枢症状、压迫症状；细胞因子释放 → 发热、盗汗、体重下降、乏力、食欲减退；免疫功能异常 → 反复感染、自身免疫性血细胞减少。

表的用法讲义写得很直：

「不需要四个诊断，而可能是一个疾病的四种表现」——补充·hermes-病理生理学讲义·第11章·11.8

这就是一元论在病理生理里的具体形状：四条机制共用一个克隆起点。反过来也成立——四条机制可以分别被别的病借用（感染、自身免疫、实体瘤浸润），所以四条同时出现比任何一条单独出现更有指向性。这一句是本课程少数可以直接拿去做推理的地方，但它指向的是「往一处想」，不是「就是那一个」。

机制、诊断与治疗代价：一元论的落点（11.8–11.10）

讲义把诊断写成四类信息的拼合：血液学（全血细胞计数与涂片）、骨髓（穿刺与活检）、免疫表型（流式）、细胞遗传与分子检测，另加影像与特殊部位检查。

涂片那一条给了理由：

「观察细胞形态与有无原始细胞，是最快获得线索的检查」——补充·hermes-病理生理学讲义·第11章·11.9

流式那一条也给了理由：

「确定细胞谱系与分化阶段，是分型的核心手段」——补充·hermes-病理生理学讲义·第11章·11.9

两条理由正好对应第三节那三个轴：涂片看成熟度，流式看谱系，影像看部位。三类检查不是替代关系，是各自回答一个坐标。

机制、诊断与治疗代价：一元论的落点（11.8–11.10）

监测的重点随病而异：急性白血病看缓解与微小残留病，淋巴瘤看影像与代谢活性，骨髓瘤看单克隆免疫球蛋白水平、游离轻链与骨病变。讲义在护理上补了一句很实用的话：理解为什么反复抽血、反复骨穿——这些是判断疗效与调整策略的依据，事先解释可显著减少患者的抵触与恐惧。这句话把「检查」从流程还原成了机制：没有基线就没有变化，没有变化就没有判断。

治疗相关病理生理：把并发症读成机制的推论（讲义 11.10）

治疗手段的类别有化学治疗、靶向治疗、免疫治疗、放射治疗与造血干细胞移植，讲义明确不涉及方案与参数。它要讲的是并发症的机制，因为只有机制能预判。

骨髓抑制期的次序与第一节的寿命差直接对应：粒细胞与血小板先掉，最低点出现在治疗后的一到两周。讲义在这里下了一句最硬的判断：

「粒细胞缺乏伴发热是急症」——补充·hermes-病理生理学讲义·第11章·11.10

「急症」两个字不是修辞，它意味着处置的时限性——不能等待观察。这是全章唯一一处时间敏感的表述，而它仍然不给任何数值。

肿瘤溶解综合征的机制是细胞死得太快：

「大量肿瘤细胞快速死亡，细胞内钾、磷与核酸代谢产物释放入血」——补充·hermes-病理生理学讲义·第11章·11.10

四个方向的高（钾、磷、尿酸）与一个方向的低（继发低钙）都从这一句推出来，急性肾损伤与心律失常是它们的合并结果。讲义把预防的核心归到两件事：水化与监测；部分患者需用药降低尿酸。这一句的顺序也值得注意——水化在前，因为它处理的是「冲走」，不是「减少生成」。
