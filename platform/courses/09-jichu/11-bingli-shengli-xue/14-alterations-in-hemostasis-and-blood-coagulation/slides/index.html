PROBLEM

凝血不好是临床上最省事也最没用的一句话。它把三件不同的事压成一个词：血小板栓子建不起来（出血在黏膜、即刻、压之易止）、凝血因子网织不牢（出血在深部、迟发、压之难止）、以及纤溶把已经建好的网拆掉。三种情形的观察重点与处理方向都不同，混成一句，就只剩开一张化验单。这一章的十一个节按三条线排：先给三条线（14.1），再各自讲正常生理（14.2 到 14.4），然后讲两端的失衡——出血（14.5 到 14.7）与血栓（14.8 到 14.9），最后是三条线同时失控的弥散性血管内凝血（14.10）与床旁观察（14.11）。读完之后该能做到一件事：看到出血，先问是哪一条线，再问形态对不对得上。

一、止血是三条同时开动的线（讲义 14.1）

讲义开篇就把口语里的「止血」拆成三条线。一期止血是血管收缩加血小板黏附、活化、聚集，形成血小板栓子——起效以秒计，先把口子堵住。二期止血是凝血因子级联激活、纤维蛋白网形成，把松软的血小板栓子加固成牢固的血栓。纤溶是纤溶酶原被激活为纤溶酶、降解纤维蛋白、血管再通，修复后把脚手架拆掉。

三条线的正常关系，讲义只给三个词：

「限局、适度、可撤」——补充·hermes-病理生理学讲义·第14章·14.1

三个词各有各的对应：限局说栓子只长在破损处，适度说只长到够用，可撤说修复完成后能被溶解。疾病就是某一条线过强或过弱，并且失去了限局性。讲义由此给出本章的两端：

一端是该堵的没堵住（出血），一端是不该堵的堵了（血栓），而三条线同时失控就是弥散性血管内凝血。这个三角就是全章的地图：14.5 到 14.7 走左端，14.8 到 14.9 走右端，14.10 走中间那个交汇点。

为什么要分开三条线？讲义的理由落在实用性上：

5 / 31body
一、止血是三条同时开动的线（讲义 14.1）

「就只能开一张化验单，开不出一个判断」——补充·hermes-病理生理学讲义·第14章·14.1

出血可以是一期止血不足，也可以是二期凝血不足，两者的出血形态、观察重点与处理方向都不同。把三条线分开，才有「判断」可言。

6 / 31body
二、内皮不是被动的衬里（讲义 14.2）

「血管内皮不是被动的衬里，而是一层主动的抗血栓表面」——补充·hermes-病理生理学讲义·第14章·14.2

讲义列了内皮的三种主动行为：释放一氧化氮与前列环素抑制血小板；表达血栓调节蛋白与硫酸类肝素样物质激活抗凝；分泌组织型纤溶酶原激活物启动纤溶。三件事分别压住三条线——抑制血小板对应一期，激活抗凝对应二期，启动纤溶对应第三条。所以内皮是三条线共同的闸门。

「内皮完整时，血小板不会黏上去」——补充·hermes-病理生理学讲义·第14章·14.2

讲义补了一句很有分量的话：不黏本身就是一种需要持续消耗能量的状态。这句话解释了一个看似矛盾的现象——内皮功能障碍会同时带来血栓与出血两种风险。因为它不是一个开关，是一组需要维护的功能；维护失败时，某些功能亢进、某些功能缺失，两端可以同时出现。

7 / 31body
二、内皮不是被动的衬里（讲义 14.2）

内皮损伤后的四步，讲义写得像工序：血管收缩（反射性收缩加内皮素释放）；黏附（内皮下胶原暴露，vWF 结合胶原并发生构象改变，血小板经 GP Ib 受体黏附于 vWF）；活化（形态改变、释放颗粒内容物，招募并激活更多血小板）；聚集（GP IIb/IIIa 与纤维蛋白原桥接，把血小板彼此连起来）。

临床联系把每一步都对应到一种缺损：vWF 缺乏 → 黏附失败；GP Ib 或 GP IIb/IIIa 异常 → 黏附或聚集失败；阿司匹林抑制血栓烷生成、P2Y12 抑制剂阻断 ADP 通路 → 药物性一期止血减弱。这一路的出血形态讲义写得很具体：

「皮肤瘀点、黏膜出血、刷牙出血、月经过多、即刻渗血、压之易止」——补充·hermes-病理生理学讲义·第14章·14.2

六个特征里，即刻与压之易止是两个时间性特征——它们指向第一层没建起来，而凝血与纤溶是好的。记住这两个词，比记住六个词更有用。

三、凝血级联：三条通路与三个要点（讲义 14.3）

外源性通路：组织因子暴露，与因子 VII 结合并激活，进而激活因子 X。这是启动通路，讲义明写「是生理止血真正的第一步」。内源性通路：接触激活（因子 XII、XI），因子 IX 被激活，与因子 VIII 形成复合物，激活因子 X。这是放大通路。共同通路：因子 X 激活 → 凝血酶原变为凝血酶 → 纤维蛋白原变为纤维蛋白 → 因子 XIII 交联加固，形成耐纤溶的网。

三个要点，讲义按重要性排。第一是维生素 K 依赖因子：II、VII、IX、X，以及抗凝的蛋白 C、蛋白 S。

「维生素 K 缺乏、肝功能不全、华法林类药物的作用都集中在这一组上」——补充·hermes-病理生理学讲义·第14章·14.3

这一句解释了一个临床上很容易混的现象：缺维生素 K 与吃抗凝药的实验室表现相似，因为两者动的是同一组因子。相似的表现不等于相同的病因，判断要靠用药史与吸收情况，不能只看化验方向。

9 / 31body
三、凝血级联：三条通路与三个要点（讲义 14.3）

第二是钙离子（曾称因子 IV）作为多个步骤的辅因子。讲义给了一个可验证的推论：枸橼酸抗凝正是通过螯合钙实现，所以采血管里必须加枸橼酸。这一条把「机制」与「操作」连起来了——采血管的选择不是习惯，是化学。

第三是组织因子是生理启动的关键。讲义对命名的提醒很值得记：

「它其实是体内最重要的启动途径」——补充·hermes-病理生理学讲义·第14章·14.3

名字里的「外源性」容易误导。内源性通路更像一台放大器。理解这一点，才能解释为什么严重创伤、产科意外、恶性肿瘤（组织因子大量释放）会迅速触发全身凝血——它们动的都是启动环节。

临床联系给出两组形态差异极大的出血：血友病 A 缺因子 VIII、血友病 B 缺因子 IX，都在内源性通路，表现为深部出血、关节腔与肌肉血肿、迟发性出血、压之难止；外源性通路受损（肝病、维生素 K 缺乏、华法林）则表现为多部位、黏膜与消化道出血。同一句凝血不好，落在这两条通路上，出血的样子完全不同。

四、抗凝与纤溶：四道闸与一个不定位的指标（讲义 14.4）

凝血一旦启动必须能被限局与终止，否则就是全身凝血。四道闸是：抗凝血酶（灭活凝血酶以及因子 Xa 等，肝素类物质使其活性大幅增强）；蛋白 C／蛋白 S 系统（凝血酶与内皮上的血栓调节蛋白结合后激活蛋白 C，蛋白 C 在蛋白 S 辅助下灭活因子 Va 与 VIIIa，即拆掉放大器）；组织因子途径抑制物（抑制 TF-VIIa 复合物，管住启动环节）；纤溶系统（t-PA 与 u-PA 使纤溶酶原变为纤溶酶，降解纤维蛋白，产生 D-二聚体与 FDP）。

四道闸的位置很整齐：一道管已经生成的凝血酶，一道管放大器，一道管启动，一道管清场。四道闸对应四类遗传性易栓症的机制——抗凝血酶缺乏、蛋白 C／S 缺乏、因子 V Leiden（对活化蛋白 C 抵抗），讲义把这组机制概括为闸门关不紧。

D-二聚体那一段是本章第一个指标容易被过度解读的例子：

「升高提示凝血与纤溶同时活跃」——补充·hermes-病理生理学讲义·第14章·14.4

11 / 31body
四、抗凝与纤溶：四道闸与一个不定位的指标（讲义 14.4）

关键在于它反映的是「纤维蛋白形成之后又被降解」这一事件，不是「哪里有血栓」。所以讲义写明它不定位、不定量：

「不能单独用来诊断血栓」——补充·hermes-病理生理学讲义·第14章·14.4

并补了一句极实用的提醒：术后 D-二聚体几乎都会升高。这一句把「指标升高」与「病」之间的距离量出来了——距离就是定位与定量这两件事，而这两件事它都做不到。

五、出血的四层：按三条线的解剖逐层排查（讲义 14.5）

四层是：血管壁异常（遗传性毛细血管扩张症、过敏性紫癜、老年性紫癜、维生素 C 缺乏致胶原合成障碍、感染性血管损伤）；血小板数量减少（生成减少、破坏增加、消耗、分布异常）；血小板功能异常（遗传性或获得性）；凝血因子缺乏或被抑制（遗传性或获得性）。

四层与三条线不是一一对应，讲义做了交叉：血管壁与血小板数量、功能三层都属一期止血，凝血因子那一层属二期。所以「四层」是排查清单，「三条线」是机制分类——清单用来不漏，分类用来解释。

鉴别靠出血形态，讲义给了两句对照：

「血小板与血管问题 → 皮肤黏膜、瘀点瘀斑、即刻出血、压之易止」——补充·hermes-病理生理学讲义·第14章·14.5

「凝血因子问题 → 深部血肿、关节腔、迟发出血、压之难止」——补充·hermes-病理生理学讲义·第14章·14.5

13 / 31body
五、出血的四层：按三条线的解剖逐层排查（讲义 14.5）

这句经验规则的生理基础讲义也给了：血小板栓子负责先堵住小口，凝血因子负责把大口子焊牢。小血管靠前者，大血管与深部组织靠后者。于是形态不是「症状描述」，它是定位证据——问诊时问压一会儿能不能止，比问「出了多少」更有定位价值。

14 / 31body
六、血小板：数量与功能要分开问（讲义 14.6）

数量减少的三大机制在临床上要分开推理，因为处理方向相反。生成减少且伴其他血细胞减少 → 想到骨髓问题，需查骨髓而非单纯输注；单纯血小板减少而骨髓巨核细胞增多 → 想到破坏增加（免疫性），处理方向是抑制免疫破坏；血小板减少伴溶血与器官损害 → 想到血栓性微血管病。

第三条最容易判反，讲义专门点破：此时血小板低不是因为没造，而是在微血管里被血栓消耗掉了——低血小板恰恰是血栓正在发生的证据。这一句的结构值得留意：同一个指标（低），在两层机制里指向相反的两件事（造得少 vs 耗得多）。所以「低」本身不是信息，低 + 什么才是信息。

功能异常那一段是本章第二个指标正常但人有病的例子：尿毒症时毒素抑制血小板功能；肝病时纤维蛋白原与 vWF 的质与量都异常；阿司匹林、氯吡格雷类阻断活化通路。这类患者血小板计数正常，但出血时间延长、临床有出血倾向。

15 / 31body
六、血小板：数量与功能要分开问（讲义 14.6）

「血小板计数正常，但出血时间延长、临床有出血倾向」——补充·hermes-病理生理学讲义·第14章·14.6

结论讲义写得很直接：问诊要问用药史，观察要看黏膜。计数是数量，黏膜是功能——两个不同的证据来源。

七、凝血因子的三个获得性原因：同一句「凝血不好」，三种方向（讲义 14.7）

维生素 K 缺乏：新生儿（肠道菌群未建立、母乳中含量低）、长期禁食或吸收不良、广谱抗菌药抑制肠道菌群，导致 II、VII、IX、X 与蛋白 C／S 合成不足。讲义给了一条可推演的细节：

「因子 VII 半衰期最短，故外源性通路最先受影响」——补充·hermes-病理生理学讲义·第14章·14.7

半衰期最短 → 最先掉 → 外源性通路最先受损 → 凝血酶原时间最先延长。这是一条从半衰期推到实验室表现的链条，记住链条就不必记结论。

肝病：几乎全部凝血因子（除因子 VIII 与 vWF）在肝合成。肝功能受损时因子减少、抗凝物质减少、血小板减少、纤溶亢进同时存在。方向是出血与血栓风险并存。

「出血与血栓风险并存」——补充·hermes-病理生理学讲义·第14章·14.7

七、凝血因子的三个获得性原因：同一句「凝血不好」，三种方向（讲义 14.7）

讲义对这一条的提醒很硬：不能因为凝血酶原时间延长就认定只会出血。这是本章最容易被忽略的一处，因为它违反直觉——化验提示出血倾向，临床上却要防血栓。原因在四条同时改变：促凝的少了，抗凝的也少了，清场的还更积极，血小板也不够。

消耗性：DIC 时因子被大量消耗，同时纤溶亢进，形成越凝越缺、越缺越出的循环。

治疗方向的差别，讲义分得很清：维生素 K 缺乏可补充维生素 K；肝病需综合支持；DIC 的关键是去除病因。

「补进去的因子会立刻成为微血栓的原料」——补充·hermes-病理生理学讲义·第14章·14.7

这一句把「补」这个动作的相对性说透了：在消耗性路径上，补充可能加速消耗。同一类处置在不同机制下方向相反，这是本章第三次出现同一结构（前两次是低血小板的两层含义、肝病的两端风险）。

八、血栓三要素：叠加，而不是三选一（讲义 14.8）

Virchow 三联是内皮损伤、血流异常、高凝状态。内皮损伤是动脉血栓的主因（粥样硬化斑块破裂、高血压剪切力、吸烟、感染、导管与支架）；血流异常是淤滞与涡流（长期制动、卧床、心房颤动、静脉曲张、动脉瘤、红细胞增多导致的高黏滞）；高凝状态分遗传性与获得性。

三要素的关系讲义写得很明确：

「长时间卧床 + 手术创伤 + 高龄」——补充·hermes-病理生理学讲义·第14章·14.8

三条同时具备，静脉血栓的风险骤升。所以预防措施总是成组出现（活动、机械预防、药物预防），

「因为单独一条措施只能对付一个要素」——补充·hermes-病理生理学讲义·第14章·14.8

这一句是本章最实用的一句：它把为什么预防要成组从经验变成了结构。三要素是乘法关系，不是加法关系——一条措施把某个要素降到很低，另外两个仍在，风险仍高。

19 / 31body
八、血栓三要素：叠加，而不是三选一（讲义 14.8）

部位与成分也有规律：动脉血栓在高剪切力下形成，以血小板为主（白色血栓），后果是缺血与梗死；静脉血栓在低剪切力与淤滞下形成，以纤维蛋白与红细胞为主（红色血栓），后果是脱落栓塞。这一对差别直接解释了为什么两端的用药方向不同——成分不同，靶点就不同。

20 / 31body
九、高凝状态：遗传性与获得性，两张不同的名单（讲义 14.9）

遗传性那一组：因子 V Leiden（活化蛋白 C 抵抗，最常见的遗传性易栓因素）、凝血酶原基因变异、抗凝血酶缺乏、蛋白 C／S 缺乏。讲义给了五个特征：

「年轻、反复、诱因轻微或无诱因即血栓、有家族史、静脉多于动脉」——补充·hermes-病理生理学讲义·第14章·14.9

五个特征里有三个是时间性的（年轻、反复、无诱因），两个是分布性的（家族史、静脉多于动脉）。它们共同指向一件事：机制在闸门那一侧，而不是在诱因那一侧。

获得性那一组更长：恶性肿瘤（肿瘤细胞释放组织因子与促凝微粒）、妊娠与产褥期、口服避孕药与激素替代治疗、抗磷脂综合征（动静脉均可受累、可致反复流产）、肾病综合征（抗凝血酶随尿丢失）、真性红细胞增多与血小板增多、肥胖、高龄、制动、创伤与手术、脓毒症、重大感染。

21 / 31body
九、高凝状态：遗传性与获得性，两张不同的名单（讲义 14.9）

注意这一组的机制并不相同：恶性肿瘤与脓毒症动的是启动环节（组织因子），肾病综合征动的是抗凝血酶（丢掉了），真性红细胞增多动的是血流（黏度），抗磷脂综合征动的是膜表面（抗体）。同一张名单里有四种不同的机制——这提醒读者：分类按来源，机制按环节，两套坐标不能混用。

评估那一段讲义给了四问：既往血栓史、家族史、当前诱因（制动、手术、肿瘤、妊娠、感染）、用药史（激素、抗凝、抗血小板）。并给了一句评价：

「这四问不需要任何化验就能把风险分层」——补充·hermes-病理生理学讲义·第14章·14.9

这是本章唯一的「零成本工具」，也是最能体现病理生理学用处的地方：机制清楚了，问诊就能替代一部分检查。

十、弥散性血管内凝血：三条线同时失控（讲义 14.10）

「DIC 不是一种独立的病，而是多种危重症的共同终末通路」——补充·hermes-病理生理学讲义·第14章·14.10

三步机制：第一步，促凝物质大量入血（严重感染的内毒素、大面积创伤与烧伤、产科意外、恶性肿瘤尤其急性早幼粒细胞白血病、严重溶血）；第二步，微血管内皮广泛损伤加抗凝系统被抑制（抗凝血酶被消耗、蛋白 C 系统受损、TFPI 不足），微血栓在全身微血管内广泛形成；第三步，消耗与纤溶——凝血因子与血小板被大量消耗导致出血，同时纤溶被继发性激活，已形成的纤维蛋白被降解，出血进一步加重。

临床表现的矛盾正是三条线的表现：微血栓 → 器官缺血与功能障碍（肾、肺、脑、皮肤），可表现为少尿、呼吸困难、意识改变、肢端发凉；消耗性减少 → 广泛出血（穿刺点渗血、皮肤瘀斑、黏膜出血）；微血管病性溶血 → 红细胞在纤维蛋白网中被切割，出现碎片、贫血与黄疸。

十、弥散性血管内凝血：三条线同时失控（讲义 14.10）

三条并列就是本章的收口：同一时刻，三条线可以各自朝不同方向失控。这就是为什么 DIC 的患者可以同时「出血」与「血栓」，而这两件事并不矛盾——它们是不同血管、不同环节上的结果。

实验室的方向性改变，讲义要求只记方向、不记数值：血小板降低、纤维蛋白原降低、凝血酶原时间与活化部分凝血活酶时间延长、D-二聚体与 FDP 升高。判读要动态、成组、结合临床。

「单项异常不能定论」——补充·hermes-病理生理学讲义·第14章·14.10

理由是肝病、大量输血、原发性纤溶都能造成部分相似的结果。这一句与 14.4 那句D-二聚体不能单独诊断血栓是同一原则的两次应用：单一指标不构成判断，组合与变化才构成判断。

护理重点讲义写成一句话的两半：看出血也看血栓——穿刺点渗血与肢端发凉、尿量减少、意识改变同等重要；避免不必要的侵入性操作，采血后充分压迫，注射部位轮换并记录。这四件事都不需要数值，全部是行为与观察。

十一、评估与观察：五项同看，写变化不写绝对值（讲义 14.11）

病史四问：出血的部位与形态（黏膜还是深部）、起病时间（先天还是后天）、诱因（外伤、手术、药物、感染）、家族史与肝病史、饮酒史、饮食与吸收情况。用药要问五类：抗血小板药、抗凝药、糖皮质激素、广谱抗菌药、部分中草药。体检看五处：皮肤黏膜瘀点瘀斑、关节肿胀与活动度、肝脾大小、生命体征、有无黄疸。

实验室那一条把本章的方法收成一句：

「五项同看，才能把病变定位到三条线的哪一条」——补充·hermes-病理生理学讲义·第14章·14.11

五项是血小板计数、凝血酶原时间、活化部分凝血活酶时间、纤维蛋白原、D-二聚体。五项的组合方式对应三条线：血小板计数管一期止血的数量，凝血酶原时间管外源性通路，活化部分凝血活酶时间管内源性通路，纤维蛋白原管底物，D-二聚体管纤溶活性。五项不是五个分数，是一张定位图。

十一、评估与观察：五项同看，写变化不写绝对值（讲义 14.11）

护理观察要点：新发瘀斑的位置与范围变化、穿刺点压迫所需时间、牙龈与鼻出血、黑便与血尿、月经量变化、意识与尿量。记录要写部位加大小加时间加是否新发，因为出血倾向的判断靠的是变化，不是单次的绝对值。

「不是单次的绝对值」——补充·hermes-病理生理学讲义·第14章·14.11

这一句可以作为全章的收尾判据：三条线是动态平衡，一次测量只是快照；判断靠的是趋势，而趋势需要同一套记录口径。
