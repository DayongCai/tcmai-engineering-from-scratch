PROBLEM

休克这一章最容易被记成「血压掉下来」：血压低就是休克，血压回来就是救回来了。可临床上有两种情形专门打这个记法——血压还撑得住而组织已经缺血，血压偏低而灌注尚可。前者是代偿期与分布性休克的常态，后者是慢性低血压的常态。把血压当判据，就会在代偿期放过它，在低血压时误判它；更麻烦的是，一旦把「升压」当成目标，整个环节链后段的细胞损伤与器官衰竭就都被挡在视野之外。这一章要交的不是一个数字，而是一条从血量到细胞、从细胞到器官的链，以及链上每一段的可观察位置。

一、概念：这是灌注问题，不是压力问题

讲义的定义把四个词串成一串：休克是各种原因引起的有效循环血量急剧减少，导致组织器官灌注不足、细胞代谢障碍与器官功能受损的临床综合征。（补充·hermes-病理生理学讲义·第20章·20.1）

定义之后紧接着一句划线的话：「休克是灌注问题，不是压力问题」。这句话的分量在于它同时否掉了两种误判。血压是灌注的驱动力之一，但灌注还取决于血管阻力与血流分布——所以血压正常不等于灌注正常，血压偏低也不等于灌注不足。

于是讲义给出两类容易被误判的情形：血压尚可维持而组织已灌注不足（代偿期或分布性休克，靠血管收缩撑住血压）；血压偏低而组织灌注尚可（慢性低血压状态）。两种情形方向相反，错法是同一个——拿一个数字替代一条链。

一、概念：这是灌注问题，不是压力问题

判断的依据因此被挪到「灌注不足的证据」上：意识、皮肤温度与色泽、尿量、毛细血管再充盈、乳酸倾向。请注意这份清单的性质：它们都不是压力读数，而是末端表现。这也解释了为什么本章要从环节链讲起——不知道链，就不知道为什么要看这些末端。

二、三要素：一条链的三个入口

有效循环血量指「有效参与循环、真正完成组织灌注的血量」。它取决于三个要素，讲义明确说：「任一要素失衡都可启动休克」。（补充·hermes-病理生理学讲义·第20章·20.2）

容量要素：失血、脱水、烧伤渗液、第三间隙丢失使绝对容量不足。动力要素（有效的心泵功能）：心肌收缩力下降、严重心律失常、瓣膜急性损坏、心脏压塞使泵出的血量不足。阻力与分布要素（适当的血管床容积与张力）：血管扩张使容量相对不足——容量未变而容器变大；血管阻塞使血流无法到达组织，这一支被单列为梗阻要素。

三要素的框架价值不在「三」这个数字，而在于它把「血压下降」这一共同表现拆成三条不同的起始路径，从而决定了完全不同的干预方向：补容量、强泵、调张力、解除梗阻。四个动词对应四条路，用错一条不但无效，还可能加重——心源性休克过量补液会加重肺淤血，就是这个框架最直接的一次兑现。

三、环节链：本章的主线

讲义的写法是把休克的病理生理直接排成一条链：

text
有效循环血量下降
  → 组织灌注下降（血流减少、分布不均）
  → 氧与底物输送不足
  → 细胞缺氧与有氧代谢受限
  → 无氧酵解增强、乳酸堆积、ATP 生成下降
  → 离子泵失效、细胞水肿与酸中毒
  → 细胞结构与功能损伤
  → 器官功能受损（单一器官 → 多器官）
  → 全身代谢与内环境紊乱
  → 循环进一步恶化

链的关键特征是「因果交替、自我强化」：灌注下降引起酸中毒与血管舒缩障碍，后者又使灌注进一步下降；细胞损伤释放的炎症介质与活性物质损害远隔器官，使局部灌注不足演变为全身炎症与多器官功能障碍。首尾相接，链条变成环——这是本章与第一章「因果交替」那条规律最直接的一次对账。（补充·hermes-病理生理学讲义·第20章·20.3）

8 / 31body
三、环节链：本章的主线

链条的第二层含义是干预的时点。讲义写得很清楚：一旦进入链条的后段，即使恢复血压也难以逆转细胞与器官损伤。所以「早」不是态度问题，而是链的位置问题：越靠前，可逆性越高。把这句话记住，第七、八节的分期就有了判据——分期不是按时间分的，是按链走到了哪一段分的。

四、灌注下降在组织层的三个后果

灌注下降在组织层面表现为三件事，讲义一件一件说。

氧输送不足：氧输送取决于血流量与动脉血氧含量。流量下降是休克的主要问题，但血氧含量下降（贫血、低氧）也可在流量尚可时造成同样的组织缺氧——这解释了为何严重贫血可出现休克样表现。这句话是「三要素」框架的一次扩展：氧输送有两个乘数，任何一个是零，积就是零。

血流分布不均：休克时交感兴奋使血流重新分布，皮肤、内脏、肾脏的血管强烈收缩以保证心、脑灌注。这种「中心化」短期是保护，长期却使内脏与肾脏缺血，成为器官功能障碍的源头。分布性休克时问题更复杂：微循环中部分毛细血管灌注过度、部分完全无灌注，出现「流量不少而氧利用障碍」的现象。这句描述值得单独记：总流量够，不等于每个毛细血管都够。（补充·hermes-病理生理学讲义·第20章·20.4）

10 / 31body
四、灌注下降在组织层的三个后果

微循环障碍：微循环是氧交换的最终场所。休克时它经历从痉挛到扩张淤滞再到微血栓形成的过程，使「大血管通畅」而「毛细血管不灌注」。这一句是第六节的引子，也是本章最容易被跳过的一段——因为它讲的不是肉眼可见的血管，而是氧真正交接的那一层。

五、细胞层：能量危机与结构损伤

细胞层面的改变是休克不可逆化的核心。讲义按三步讲。

能量代谢转向：缺氧使氧化磷酸化受限，细胞依赖无氧酵解，ATP 产量大幅下降而乳酸生成增加，形成乳酸酸中毒。酸中毒又反过来抑制心肌收缩力、降低血管对儿茶酚胺的反应性、削弱凝血功能——它不只是结果，还是新的恶化因素。这就是链的自强化在细胞层的落点。（补充·hermes-病理生理学讲义·第20章·20.5）

离子泵失效：ATP 不足使钠钾泵无法维持跨膜梯度，细胞内钠与钙蓄积、细胞外钾升高。细胞水肿、线粒体肿胀、溶酶体酶释放，进一步破坏细胞结构；钙超载激活蛋白酶与磷脂酶，直接损伤膜结构。这一段的写法值得注意——讲义没有把它写成「细胞坏了」，而是写成泵停了、梯度没了、水与钙进来了这三步。因果顺序清楚，才有可干预的位置。

12 / 31body
五、细胞层：能量危机与结构损伤

细胞死亡与炎症放大：坏死细胞释放内容物（损伤相关分子模式），激活炎症反应；炎症介质进入循环后损害远隔器官，形成全身炎症反应与多器官功能障碍的共同通路。这也是「休克复苏后仍可出现器官衰竭」的原因：损伤在缺血期已埋下，再灌注又带来氧化应激与炎症放大。

最后这半句是本章对「救回来」这个词最重要的修正：压力回来不等于损伤停止。再灌注本身是一次新的打击，这一层在后面的缺血-再灌注话题里还会展开，本章只把它记作链条末端的加速项。

六、微循环：三段与一个转折点

微循环的改变是休克从可逆走向不可逆的关键转折点，讲义分三段。

痉挛期：交感兴奋与儿茶酚胺释放使微动脉、毛细血管前括约肌强烈收缩，微循环灌流急剧减少。此时血压可能尚可维持（通过增加外周阻力），但组织已缺血——这正是代偿期「血压正常而灌注不足」的机制。请把这一句和第一节的两类误判对上：不是巧合，是同一个机制在概念层与微循环层的两次出现。

扩张淤滞期：缺血与酸中毒使局部血管对儿茶酚胺反应性下降，毛细血管前括约肌松弛而微静脉仍收缩，形成「灌入多、流出少」的淤滞状态。血液在毛细血管内滞留，流体静压升高，液体外渗，有效循环血量进一步减少——休克由此自我加重。这一段的机制值得反复看：入口松了、出口还紧着，于是血在床里泡着，水往组织里漏。容量要素的第二次损失不是在外周丢的，是在毛细血管里丢的。（补充·hermes-病理生理学讲义·第20章·20.6）

14 / 31body
六、微循环：三段与一个转折点

微血栓期：血流淤滞、内皮损伤与凝血激活共同促成微血栓形成，毛细血管床被机械性阻断，出现「无复流」现象。此时即使大循环恢复，微循环仍不灌注，细胞持续缺氧，器官功能难以恢复。这是复苏后器官仍会衰竭的第二个解释，也是分期的物质基础。

三段合起来是一条可背的短句：先关小门，再关不上出口，最后把门堵死。

15 / 31body
七、代偿期：最佳窗口

休克按进程分三期，讲义提醒分期的意义在于识别各期在环节上的差别，而不是记数值。

代偿期（微循环痉挛期）：有效循环血量下降被压力感受器感知，交感-肾上腺髓质系统强烈兴奋，心率增快、收缩力增强、外周血管收缩、静脉收缩提高回心血量；RAAS 与抗利尿激素激活，水钠潴留、尿量减少以保住容量。

此期的特点是「代偿机制活跃、组织已缺血」：血压可维持甚至略高，而皮肤苍白发凉、脉搏细速、尿量减少、意识清醒但烦躁或淡漠。这是干预的最佳窗口——去除病因、恢复容量或泵功能，可完全逆转。

讲义在这里下了一句最实用的判词：若把「血压正常」当作「没有休克」，就会错过这一窗口。这句话的用法不是让你去猜谁在休克，而是让你在看到一个正常读数时仍然去核对末端证据。窗口之所以叫窗口，是因为它长得不像窗口。（补充·hermes-病理生理学讲义·第20章·20.7）

八、进展期与难治期：代价到期

进展期（微循环淤滞期）：代偿机制不再足以维持灌注，血压开始下降，组织缺氧加重、乳酸堆积、酸中毒形成。微循环进入扩张淤滞状态，液体外渗使有效循环血量进一步减少。临床表现加重：皮肤出现花斑、四肢湿冷、尿量进一步减少、意识由烦躁转为淡漠、心率进一步增快而脉搏更弱。

此期已出现细胞与器官的功能性损伤，但若及时纠正灌注，仍可能逆转。讲义补了一句干预上的要点：需同时处理容量、泵功能、血管张力与病因，单靠一种手段往往不足。这句是「三要素」框架的第二次兑现——三条入口同时开着，只关一扇门不够。

难治期（微血栓期／不可逆期）：微血栓广泛形成、细胞大面积死亡、多器官功能衰竭，对常规复苏反应差。此期血压难以维持、无尿、意识障碍加深、出现出血倾向（凝血因子消耗）与代谢性酸中毒加重。即使恢复大循环压力，微循环「无复流」与细胞损伤仍使器官功能无法恢复。

八、进展期与难治期：代价到期

三期的差别，讲义用一句话收口：代偿期是「灌注不足而压力尚可」，进展期是「压力与灌注同时下降」，难治期是「压力可被支撑而细胞已不能利用」。这一句值得抄在笔记本第一页——它把三个期变成三种组合，而不是三个数字区间。（补充·hermes-病理生理学讲义·第20章·20.8）

九、分类：四类休克的起始环节

按起始环节把休克分为四类，是临床思维的核心工具。四类的共同点是有效循环血量不足，不同点在于哪一要素先失效。

低血容量性休克：全血或血浆丢失（出血、烧伤）、体液丢失（呕吐、腹泻、脱水）、第三间隙隔离（肠梗阻、胰腺炎）。起始环节是容量绝对不足 → 回心血量下降 → 前负荷下降 → 每搏量下降。特点：外周血管收缩、脉压减小、中心静脉压偏低。

心源性休克：大面积心肌梗死、严重心肌病、急性瓣膜损坏、严重心律失常。起始环节是泵功能衰竭 → 每搏量下降。特点：外周灌注不足伴肺淤血，中心静脉压偏高。

分布性休克：感染性（脓毒症）、过敏性、神经源性。起始环节是血管床扩张与血流分布异常 → 外周阻力下降、有效循环血量相对不足。特点：早期外周温暖、脉压增宽、心输出量可正常或偏高，而氧利用障碍。这一类的特殊之处在于它长得不像休克：手脚是暖的，血压可能还宽着，只有氧利用出了问题。

九、分类：四类休克的起始环节

梗阻性休克：心脏压塞、张力性气胸、肺栓塞、主动脉夹层。起始环节是血流通道被机械性阻断 → 充盈或射血受阻。特点：起病急、对液体复苏反应差，必须解除梗阻。这一类的机制最直白——管子堵了，补液补不进去。

四类并列排开，可以看出分类的用处：它不是给病人贴标签，而是先定位哪一要素先失效，再决定动哪一只手。也正因如此，四类可以并存：一个创伤患者可以同时低容量与梗阻，一个脓毒症患者可以在分布性基础上叠加心源性。（补充·hermes-病理生理学讲义·第20章·20.9）

十、器官与多器官功能障碍

休克时器官损伤的顺序与机制值得逐一提及。讲义按器官列了一遍，每一句都能回指到链条上的某一环。

肺：早期因过度通气出现呼吸性碱中毒，随后肺泡-毛细血管膜损伤、通透性升高，出现急性肺损伤与低氧血症。肾：肾灌注下降加交感与 RAAS 激活使肾血管强烈收缩，出现少尿与急性肾损伤；若持续缺血则转为肾小管坏死。脑：脑灌注下降引起意识改变，从烦躁到淡漠到昏迷，是判断灌注的敏感窗口。肝：肝缺血使合成与解毒功能下降，转氨酶升高、凝血因子合成减少。肠：肠黏膜屏障在缺血时最早受损，细菌与内毒素移位，成为炎症放大的来源——「肠是休克的发动机」这一说法即源于此。心：休克时心肌自身也缺血、酸中毒与炎症介质抑制收缩力，形成「休克加重心衰、心衰加重休克」的循环。凝血：组织因子释放与微血栓形成消耗凝血因子，可演变为弥散性血管内凝血，表现为出血与栓塞并存。

十、器官与多器官功能障碍

多器官功能障碍是休克晚期的共同结局，讲义对它的定性是：本质是「炎症-缺血-再灌注」三重损伤的叠加，而非单一器官的原发故障。这句话对写作有直接约束——写任何一个器官的受损，都要能说出它经由哪一条（缺血、炎症、再灌注）进来的；说不出来的，就是把合并症写成了后果。（补充·hermes-病理生理学讲义·第20章·20.10）

十一、临床表现：一副拼图，不是一个读数

休克的临床表现可以按「灌注」这一主线归为几组方向性线索。

皮肤与末梢：苍白、湿冷、花斑、毛细血管再充盈延迟——反映外周血管收缩与微循环灌注不足；分布性休克早期可反而温暖干燥，这是重要的鉴别方向。脉搏与心率：细速、脉搏减弱、节律不齐；脉压减小提示每搏量下降。尿量：减少是最实用的灌注指标之一。意识：烦躁、淡漠、定向力下降，反映脑灌注。呼吸：初期深快（代偿性），后期可出现呼吸窘迫。颈静脉与中心静脉压方向：低血容量时塌陷，心源性与梗阻性时充盈——这一条是区分类型的关键体征。

讲义用一句话把这些线索收起来：休克的床旁判断是「灌注的拼图」，而不是单一读数；本讲义只给方向，不列阈值。

十二、监测与干预：每一步都要能回指某一环

干预的每一步都应能对应到环节链上的某一环，这就是机制化干预的含义。讲义按要素列了五组。

针对容量要素：评估容量状态后补充容量，目标是恢复前负荷与每搏量；但心源性休克时过量补液会加重肺淤血，因此必须先判断类型。针对泵功能要素：改善收缩力、纠正严重心律失常、解除机械性梗阻（压塞、张力性气胸）。针对血管张力要素：在容量已纠正而灌注仍不足时调节血管张力，维持必要的灌注压；分布性休克需同时处理感染源与炎症。针对细胞与代谢：纠正缺氧、酸中毒与电解质紊乱，保护器官功能。针对病因：止血、抗感染、解除梗阻、再灌注——病因不除，任何支持手段都只是拖延。

最后一组的分量最重：前四组是「撑住」，第五组才是「解决」。撑住能买时间，买不到结果。（补充·hermes-病理生理学讲义·第20章·20.12）
