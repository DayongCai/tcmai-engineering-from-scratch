PROBLEM

特殊感觉最省力的学法是背通路：光路、听路、前庭三输出、嗅味两条投射。五张图背下来能答题，却答不了门诊里最常被问的那句——这个看不清、听不清、晕得厉害，问题出在哪一段。讲义把五种感觉放进同一章，不是因为它们相似，而是因为它们共用一条推理规则：缺损的形状（视野缺损的位置、听力损失的频率分布、眼震的方向、眩晕的伴随体征）指向通路的某一段。这一章要交的不是五张通路图，是“形状即定位”这条规则，再加上一件常被忽略的事——感觉障碍从来不只是输入减少，而是整个系统在重组。

五种感觉共用的骨架（46.1）

特殊感觉的骨架只有三段：感受器把特定形式的能量转换为电信号，传入通路（多级神经元、多有交叉），皮层代表区。五种的感受器不同，骨架相同。

骨架上挂着三条共同规律，讲义写得很省，但每一条都能直接用在床边：

  • 适应：持续不变的刺激引起反应减弱，因此“持续存在的异常可能被忽略”，而变化最容易被察觉；
  • 对侧投射：视、听与躯体感觉均为对侧代表，故单侧皮层病变产生对侧障碍；
  • 可定位：通路任一环节受损都造成功能丧失，但缺损的形态（视野缺损的形状、听力损失的频率分布、眼震的方向）可指向具体环节。

第一条解释了一个反直觉的现象：慢性的感觉下降往往被本人忽略，直到某个场景把它暴露（夜里看不清台阶、饭桌上听不清对话）。第二条把“单侧皮层病变”与“对侧障碍”锁在一起，是后面所有视野与听力定位的底座。第三条是本章的方法论：形状比强度更有信息量。

骨架之外还有一层，是这一章真正的深水区：

「感觉剥夺还会引起中枢重组」——补充·hermes-病理生理学讲义·第46章·46.1

听觉剥夺后听觉皮层增益上调（耳鸣）、视觉剥夺后视觉皮层被触觉与听觉占用、单侧前庭丧失后依赖视觉与本体感觉代偿。于是感觉障碍的后果不止是信号变少，还有系统重新分配资源。这一句在 46.9 会完整展开，但它必须在这里先出现——否则读者会把“耳鸣”“代偿”“不耐受”当成三件互不相关的事。

视觉：一条链与一张定位表（46.2–46.3）

46.2 通路与视野的对应

光线经角膜、房水、瞳孔、晶状体、玻璃体到达视网膜；视网膜内三级神经元接力（视杆与视锥 → 双极细胞 → 神经节细胞），再经视神经 → 视交叉（鼻侧纤维交叉）→ 视束 → 外侧膝状体 → 视辐射（经颞叶与顶叶）→ 枕叶距状裂皮层。

这条链的特点是在视交叉处做了一次部分交叉。部分交叉产生了一个很好用的性质：不同位置的病变产生不同形状的缺损。

这张表的价值不在背，在于它是一条反推路径：给出缺损形状，就能排除大半通路。单眼 → 交叉前；双颞侧 → 正中；同向性 → 交叉后；象限性 → 视辐射的某一片；伴黄斑回避 → 枕叶（因为黄斑区有双重血供，枕叶病灶常常保留中心视力）。

最后一行值得单独留一格：黄斑回避不是例外，是解剖的必然——同一个病灶，血供特殊的区域活下来，于是中心视力保留而周边全失。结构决定缺损的形状，这里是最干净的一例。

本节末尾写视网膜的双重血供：

「视网膜血供是双重的」——补充·hermes-病理生理学讲义·第46章·46.2

内层由视网膜中央动脉供应，外层由脉络膜供应。于是中央动脉阻塞造成单眼突发无痛性失明，而眼动脉的侧支可保留部分视功能。“无痛、单眼、突发”是动脉阻塞的三要素——又一个形状定位的例子，只不过这次形状是时间与疼痛的组合。

46.3 五个环节，一条判断顺序

讲义把视觉失衡分五层：屈光不正、白内障、青光眼、视网膜病变、视神经病变。五层的性质不同：

8 / 29body
共用的骨架与两种距离觉：视觉与听觉（46.1–46.5）
  • 屈光不正是光学问题——矫正即可，眼轴长度与屈光力不匹配；
  • 白内障是晶状体蛋白变性混浊，透光下降，是可逆性致盲的首位原因，手术可恢复；
  • 青光眼是房水生成与流出失衡致眼压升高，视神经乳头凹陷与进行性视野缺损（周边先受累、中心视力晚期才丧失）。开角型隐匿进展，闭角型急性发作伴眼痛、虹视、头痛与恶心；
  • 视网膜病变是微血管病变（糖尿病与高血压性）→ 渗出、出血、黄斑水肿；增殖期新生血管 → 玻璃体出血与牵拉性视网膜脱离；
  • 视神经病变分炎症（伴眼球转动痛）、缺血（突发、象限性缺损）、压迫（肿瘤、甲状腺相关眼病）。

青光眼那一条留了一句重要的保留：

「眼压升高并非唯一机制」——补充·hermes-病理生理学讲义·第46章·46.3

正常眼压性青光眼提示血管因素与轴突运输障碍同样重要。这句话防止了一个常见的推理错误：把一个“通常相关”的指标当成“必要原因”。相关不等于因果，这一条在全书里反复出现，这里是最直白的一处。

本节末尾给出判断顺序：看四项——起病速度、单眼还是双眼、有无疼痛、视野缺损的形态。这四项比视力表上的数字更有定位价值，也决定了后续走哪条路（配镜、手术、降眼压还是急诊影像）。注意这里的取舍：讲义把“形态”排在“数值”之前，与本书不给值的原则是同一套逻辑。

听觉：阻抗匹配、频率地图与不可再生的毛细胞（46.4–46.5）

46.4 通路里的两个要点

声波经外耳、鼓膜、中耳听骨链（阻抗匹配：

「把空气的低阻抗振动高效传入内耳液体」——补充·hermes-病理生理学讲义·第46章·46.4

这个设计的效率损失被大幅补偿，镫骨肌反射提供一定保护），再经卵圆窗进入耳蜗。耳蜗内基底膜行波呈频率—位置编码：

「高频近底、低频近顶」——补充·hermes-病理生理学讲义·第46章·46.4

八个字，解释了整个听力图的形状逻辑：不同频率在不同部位受损，所以听力图上的曲线形态可以提示病因。此后是毛细胞（机械转导，钾内流去极化）→ 螺旋神经节 → 听神经 → 耳蜗核 → 上橄榄复合体（比较双耳时间与强度差，实现声源定位）→ 下丘 → 内侧膝状体 → 颞横回。

第二个要点是：

「毛细胞不可再生」——补充·hermes-病理生理学讲义·第46章·46.4

哺乳类的毛细胞一旦损失就不再补充，所以感音神经性损失多为永久性。这一句是听觉章与视觉章最重要的不对称：晶状体混浊可以换，毛细胞死了不能长。同为感觉器官，可修复性差了一个量级。

此外，听神经以上的通路为双侧投射，单侧中枢病变很少造成全聋，但会影响声源定位与言语识别。这一条与 46.1 的对侧投射并不矛盾：对侧投射讲的是皮层代表，双侧投射讲的是通路冗余——两个层面，两句话。

三型的判别逻辑很清楚：传导性只挡气导，骨导绕过了外耳与中耳，所以保留；感音神经性两路都下降。中枢性的特点是“不成比例”——纯音阈值可能正常，言语识别却很差。这三个特征各自对应一处解剖，是形状定位在听觉上的版本。

重振（小声听不见、大声嫌太响）提示耳蜗病变，机制是毛细胞受损后动态范围变窄。讲义点出它在助听器验配时是关键技术问题——这不是理论兴趣，它直接决定设备能不能用。

耳鸣的机制写得很克制，但很准：外周输入减少后中枢增益上调，属听觉剥夺的中枢代偿。由此推出两个可观察的结论——耳鸣的响度与听力损失程度不必平行；情绪与睡眠状态显著影响其困扰度。第二句解释了为什么同一种耳鸣，有人不在意，有人睡不着。

本节还有一条不能漏的提醒：单侧听力下降伴耳鸣须警惕听神经瘤，因其常先影响高频与言语识别。以及老年性聋的形状：高频先受累，表现为听得见但听不清，在噪声环境中尤其明显。讲义把它后面的社会后果写全了——社交退缩、误解与猜疑（被误认为多疑）、认知负荷加重。听力干预因此不只是听的问题。

前庭：推挽、代偿与一张鉴别表（46.6–46.7）

46.6 两个器官，三条输出

半规管三个互相垂直的平面感受角加速度（转头）；椭圆囊与球囊内含耳石，感受直线加速度与头位相对重力的方向。这个分工是纯力学的：转与不转、往哪边倾，是两件不同的事。

通路是前庭神经 → 前庭核 → 三条输出：

  1. 前庭眼反射：经动眼、滑车、外展神经核，头动时眼球反向转动以稳定注视——这是睁开眼走路不晕的基础；
  2. 前庭脊髓反射：维持姿势张力与平衡；
  3. 前庭-自主与皮层投射：恶心、呕吐、出汗、眩晕感与空间定向。

关键特性是双侧推挽：

「两侧静息放电对称」——补充·hermes-病理生理学讲义·第46章·46.6

中枢把“对称”解读为“静止”。一侧受损造成不对称，被感知为“自己在旋转”（眩晕），并出现眼震（慢相向患侧、快相向健侧）与向患侧倾倒。这里有一个很漂亮的推理：没有真正的运动，却有运动的感觉——因为系统读的是差值，不是绝对值。

平衡、化学觉与补偿：前庭、嗅味、剥夺与沟通（46.6–46.10）

中枢可以代偿：对侧前庭核兴奋性上调、小脑参与再校准、视觉与本体感觉被重新加权。这是前庭康复训练的机制基础，也解释了急性前庭病变为何在数周内逐步减轻。讲义补了一句极实用的判断：

「而代偿依赖活动，卧床不动反而延迟恢复」——补充·hermes-病理生理学讲义·第46章·46.6

安静休息在多数急性病里是对的，在这里是错的。机制决定方向，方向可能反直觉——这一句是全章最值得记住的“反常识”。

「而非眩晕的剧烈程度」——补充·hermes-病理生理学讲义·第46章·46.7

鉴别靠的是伴随体征，不是眩晕有多剧烈。这句话纠正了一个非常常见的直觉：越晕越严重。事实相反——中枢性眩晕可以很轻，却提示后循环缺血这类急症。

三种外周病因的形状也各不相同：良性阵发性位置性眩晕由耳石脱落进入半管，与头位变化密切相关，发作短暂；前庭神经炎为病毒感染后单侧前庭功能丧失，持续数日、无听力障碍；梅尼埃病为膜迷路积水，表现波动性听力下降加耳鸣、耳闷与眩晕发作。三者都晕，但一个有头位诱因、一个没有听力症状、一个有波动性听力下降。

讲义给的安全底线很明确：凡眩晕伴新发的神经体征（复视、构音障碍、吞咽困难、偏身感觉异常、共济失调），应按中枢性处理并紧急评估；反之，纯旋转性眩晕伴耳症状而神经体征阴性，多属外周性。

嗅与味：不经丘脑的一条路（46.8）

平衡、化学觉与补偿：前庭、嗅味、剥夺与沟通（46.6–46.10）

嗅觉的特别之处有两个。第一，嗅上皮的受体神经元是唯一直接暴露于外环境的神经元，也是少数终身更新的神经元。第二，它的轴突穿过筛板进入嗅球，形成肾小球，再经嗅束投射到梨状皮层、杏仁核与内嗅皮层——不经丘脑。

不经丘脑这件事解释了一个日常经验：

「气味与情绪、记忆的联系格外紧密」——补充·hermes-病理生理学讲义·第46章·46.8

其它感觉都要在丘脑换一次站，嗅觉直接进了边缘系统。所以气味能突然唤起一段完整的往事，而其它感觉很少这样。

味觉的通路走常规路线：味蕾分布于舌、腭与咽；前部经面神经、后部经舌咽神经、咽部经迷走神经传入孤束核 → 丘脑 → 岛叶皮层。基本味为甜、咸、酸、苦、鲜。所谓味道大部分来自嗅觉，故嗅觉丧失者常主诉吃东西没味道——这句话在门诊里能省掉很多弯路：主诉是味觉，病变可能在嗅觉。

平衡、化学觉与补偿：前庭、嗅味、剥夺与沟通（46.6–46.10）

失衡原因分四层：传导性（鼻塞、鼻息肉）、感受器损伤（病毒感染后、药物、放疗）、神经损伤（头部外伤致嗅丝撕裂、颅底骨折、手术）、中枢病变（帕金森病与阿尔茨海默病早期常受累，可作为前驱标志）。第四层把感觉章与 45 章接了起来——嗅觉减退可以是变性病的前驱标志，这也是 45.4 说非运动症状更早出现的一个具体例子。

安全意义单独成段：

「嗅觉减退使患者难以察觉煤气泄漏」——补充·hermes-病理生理学讲义·第46章·46.8

烟雾与变质食物同理。这是居家安全中常被忽视的风险，应在出院教育中明确告知并建议安装报警装置。一句话把感觉缺损翻译成了可执行的照护动作。

剥夺之后：代偿与老年性改变（46.9）

感觉剥夺会触发中枢重组：听觉剥夺 → 听觉皮层增益上调（耳鸣、对噪声不耐受）；视觉剥夺 → 视觉皮层被触觉与听觉任务占用（跨模态可塑性）；单侧前庭丧失 → 平衡依赖视觉与本体感觉，在暗处或软地面上不稳。

平衡、化学觉与补偿：前庭、嗅味、剥夺与沟通（46.6–46.10）

三种代偿的形式不同，共同点是：中枢不承认“没有输入”，它会重新分配资源。这解释了三件看似无关的事——耳鸣为什么在安静时更响、盲人为什么听觉更敏锐、前庭损伤的人为什么怕黑。它们都是同一机制的不同表现。

老年性改变是多重叠加：晶状体弹性下降（老视）、瞳孔缩小致夜间视物差、对比敏感度下降、眩光敏感；高频听力损失与言语识别下降；前庭毛细胞与神经元减少、姿势控制变慢；嗅觉与味觉阈值升高。共同后果是一句话：

「跌倒风险上升、社交退缩、认知负荷增加」——补充·hermes-病理生理学讲义·第46章·46.9

三者互相拖累：看不清就不敢走，不敢走就肌力下降，肌力下降就更怕跌倒；听不清就不参与对话，不参与就社交退缩，社交退缩又加重认知负荷。讲义把这种关系概括为感觉—认知—运动三者互为因果，任一环恶化都会带动其余两环。

干预方向多为低成本高收益：矫正屈光、白内障手术、助听设备、环境照明与对比度提升、去除地面障碍与增加扶手、前庭与平衡训练、营养与口腔照护。讲义给了一句判断：这些措施对功能与生活质量的影响，常大于针对病因的无效努力。这句话在本章是收口，也是全书价值观的又一次出现——能改善功能的事，优先于听起来更“根本”却做不了的事。

最后一节全是可执行的动作，但每一条背后都有一条机制：

平衡、化学觉与补偿：前庭、嗅味、剥夺与沟通（46.6–46.10）
  • 与听力障碍者沟通：面对光源、让对方看到口型，清晰发音而非大声喊叫（喊叫会扭曲辅音），减少背景噪声，备好纸笔或辅助设备，必要时安排手语翻译；确认理解用复述而非点头。机制在 46.4：言语识别依赖高频成分，喊叫放大的是低频与音量，反而破坏辅音。
  • 与视力障碍者沟通：进房间先自我介绍、离开时告知；操作前说明位置与动作；引导时让对方扶你的臂而非被推着走；物品固定位置，不随意移动。机制在 46.1：视觉剥夺后空间定向依赖记忆与触觉，物品移位等于把地图撕掉。
  • 安全：跌倒与烫伤预防（热水温度、餐具位置）、药物标签可辨识（大字体、触觉标记）、居家环境改造、驾驶能力评估与告知。
  • 心理：感觉丧失常伴孤立、抑郁与猜疑，需主动询问情绪与社交状况，必要时转介。
  • 记录：功能状态（能否读药瓶、能否听懂电话、能否独自出门）应作为评估与随访的基线，而不是只记录检查结果。
