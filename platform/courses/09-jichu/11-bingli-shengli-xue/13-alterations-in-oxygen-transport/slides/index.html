PROBLEM

缺氧是临床语言里最含糊的一个词。它可以是高原上吸不到氧，可以是贫血时血里装不下氧，可以是心衰时送不到，也可以是氰化物让细胞用不上——四种情形的处置方向完全不同，甚至相反：一种要加氧，一种加氧没用，一种越加越糟。这一章的全部工作，就是把缺氧这个笼统状态换成一条位置固定的链条，再问断在哪一段。十二个节里，前三个讲链条与量（分压、容量、含量、饱和度、曲线），中间五个讲四型失衡与鉴别，最后四个讲代偿、器官损伤、发绀与氧疗边界。读完之后该能做到一件事：给一组指标，指到某一段，并说清为什么不是另外三段。

链条与曲线：四个位置、四个概念与一条 S 形（13.1–13.3）

一条位置固定的链条，四个位置固定的名称（讲义 13.1）

讲义开篇不定义缺氧，先画链条：

「外界空气 → 肺泡 → 肺泡毛细血管膜 → 血浆 → 红细胞内的血红蛋白 → 循环输送 → 组织毛细血管 → 细胞 → 线粒体」——补充·hermes-病理生理学讲义·第13章·13.1

这条链有九个位置。任何一段断掉，临床上都被叫作缺氧，但讲义立刻给出区分：

「断在哪一段，指标的变化方向不同」——补充·hermes-病理生理学讲义·第13章·13.1

这就是本章的方法论：不是先分类，是先定位。分类的名称只是位置的代号：

「四段对应四个名称」——补充·hermes-病理生理学讲义·第13章·13.1

链条与曲线：四个位置、四个概念与一条 S 形（13.1–13.3）

四段是：摄取与交换段（外呼吸：吸入气氧分压、肺泡通气、弥散面积与厚度、通气/血流匹配）、携带与释放段（血红蛋白的数量、结构，以及氧向组织释放的难易）、输送段（心输出量、局部血流量、血管通畅性）、利用段（线粒体氧化磷酸化、呼吸链酶系、细胞对氧的利用能力）。对应的四个名称是乏氧性、血液性、循环性、组织性。

讲义为什么要强调先定位置？它给了两句理由，正好是一对：

「现象是多样的，同一类可以表现得很不一样，不同类又可以表现得很像」——补充·hermes-病理生理学讲义·第13章·13.1

「环节是有限的，只有四段」——补充·hermes-病理生理学讲义·第13章·13.1

这是本课程最经济的一次论证：现象无穷、环节有限，所以定位优于枚举。凡是试图按表现反推类别的做法，都会在「表现很像」的地方翻车。

四个被当成同义词的概念（讲义 13.2）

氧分压、氧容量、氧含量、氧饱和度，在日常语言里几乎可以互换，而鉴别四型缺氧全靠把它们分开。

链条与曲线：四个位置、四个概念与一条 S 形（13.1–13.3）

氧分压是溶解在血浆中的氧所产生的张力。它反映压力——推动氧从气相进血液、从血液进组织的力，不反映血液里装了多少氧。氧容量是单位容积血液中血红蛋白所能结合的最大氧量，取决于血红蛋白的数量与性质，与当前吸入多少氧无关：

「与当前吸入多少氧无关」——补充·hermes-病理生理学讲义·第13章·13.2

这一句是血液性缺氧的判据来源：吸入多少都不影响容量，容量只由血红蛋白定。氧含量是实际结合的氧量，等于血红蛋白结合氧与物理溶解氧之和；生理条件下溶解部分占比很小。氧饱和度是氧含量占氧容量的百分比，反映装满的程度，不反映总量。

四个概念的分工，讲义压缩得极省：分压管推动，容量管装得下多少，含量管实际装了多少，饱和度管装了几成。由此可以直接推出判读骨架，讲义给了四条：

「分压与饱和度同时下降 → 问题在交换段（乏氧性）」——补充·hermes-病理生理学讲义·第13章·13.2

链条与曲线：四个位置、四个概念与一条 S 形（13.1–13.3）

「分压、容量、饱和度都正常，而动静脉氧差增大 → 问题在输送段（循环性）」——补充·hermes-病理生理学讲义·第13章·13.2

「动静脉氧差减小、静脉端氧分压偏高 → 问题在利用段（组织性）」——补充·hermes-病理生理学讲义·第13章·13.2

第四条（分压正常而容量下降 → 血液性）讲义写在同一组的开头。四条合起来就是 13.8 那张表的雏形——注意它们的共同结构：每一条都以哪些指标正常开头。正常值在这里不是背景，是排除条件；排除法比确认法更稳，因为它不依赖某个指标有多异常。

S 形曲线：形状本身就是设计（讲义 13.3）

氧解离曲线描述氧分压与氧饱和度之间的关系，呈 S 形。讲义对这一形状的解读值得整段抄下来：上段平坦，肺泡氧分压小幅下降时饱和度掉得不多，保证装载不因轻微的通气波动而大幅损失；下段陡峭，组织氧分压降低时血红蛋白迅速卸载，保证释放跟得上组织的消耗。

链条与曲线：四个位置、四个概念与一条 S 形（13.1–13.3）

「在肺里抓得牢，在组织里放得开」——补充·hermes-病理生理学讲义·第13章·13.3

曲线的位置用左移与右移描述，讲义明确不用具体数值。右移（释放增强）有四个因素：酸中毒（氢离子升高）、二氧化碳升高、温度升高、2,3-二磷酸甘油酸增多。讲义对这四件事有一句很漂亮的总结——它们恰好都是组织代谢旺盛处的局部特征，所以右移可以理解为就地卸货。左移（释放减弱）也有四项：碱中毒、低温、2,3-DPG 减少、胎儿血红蛋白、一氧化碳血红蛋白、高铁血红蛋白。

把右移那一组读成代谢旺盛的地方自动多放氧，会得到一个可用的推论：曲线位置不是固定属性，是随局部环境变化的调节。这一条在 13.10 会反过来用——缺氧致酸中毒，酸中毒又使曲线右移，短期有利、长期有害。

乏氧性缺氧：交换段，氧疗有效但分流例外（讲义 13.4）

成因三种：吸入气氧分压降低（高原、密闭空间、通风不良的作业环境、供气异常）；外呼吸功能障碍（通气不足、弥散障碍、通气/血流比例失调）；静脉血分流入动脉（先天性心脏缺损、肺内动静脉短路）。

指标方向是五项的联合：动脉氧分压降低、氧容量正常、氧饱和度降低、氧含量降低、动静脉氧差可正常或偏小。发绀常见，因为毛细血管内还原血红蛋白的绝对量增多——注意这一句把发绀的机制提前交代了，13.11 只是把它展开成三个边界。

氧疗有效的道理很直接：提高吸入气氧分压可抬高肺泡氧分压，进而抬高饱和度。但讲义立刻划出一个例外：

「提高吸入氧浓度后缺氧不改善，要想到分流」——补充·hermes-病理生理学讲义·第13章·13.4

四种缺氧与鉴别：每一型断在哪一段（13.4–13.8）

理由是分流的血液根本没有接触肺泡气。这一条在临床上极实用：加氧无效时的第一反应不该是加大流量，而该是问有没有分流。同一个名称（乏氧性）里，藏着一个对治疗反应完全相反的亚类——这是本章第一次提醒：类别不是终点，位置才是。

血液性缺氧：交换正常、输送通畅，问题在血本身（讲义 13.5）

「交换正常、输送通畅，问题出在血液本身」——补充·hermes-病理生理学讲义·第13章·13.5

三种情形，机理各不相同，但都落在装与放上。

贫血：血红蛋白数量减少 → 容量降低、含量降低；但动脉氧分压正常、饱和度也正常——剩下的每一个血红蛋白分子仍然是装满的。动静脉氧差偏小，因为组织能从每毫升血里拿到的氧总量本来就少。讲义把这一型的标志写成一句对照：饱和度正常而含量低。这是最容易误判的一型：

「脉搏血氧读数可以完全正常，患者却已经明显缺氧」——补充·hermes-病理生理学讲义·第13章·13.5

四种缺氧与鉴别：每一型断在哪一段（13.4–13.8）

贫血患者的缺氧表现更多来自心输出量的代偿（心率增快、心慌、活动后气促），而不是发绀。这一句把「表现」与「指标」两条线分开：表现来自代偿，指标来自血红蛋白，两者不必同步。

一氧化碳中毒：亲和力远高于氧，占据结合位点 → 容量降低；同时使剩余位点释放氧更困难（曲线左移），形成双重打击。分压正常、含量显著降低；皮肤黏膜呈樱桃红、不发绀。最关键的一句是仪器层面的：

「脉搏血氧仪无法区分一氧化碳血红蛋白与氧合血红蛋白，读数假性正常」——补充·hermes-病理生理学讲义·第13章·13.5

处理方向是脱离接触与高压氧，而不是单纯提高吸入氧浓度。这里有一个可以推广的读法：当仪器读的是「饱和度」而病变在「含量」时，读数会替你撒谎。贫血、一氧化碳、高铁血红蛋白三种情形都是这个结构的实例。

四种缺氧与鉴别：每一型断在哪一段（13.4–13.8）

高铁血红蛋白血症：二价铁被氧化为三价铁，失去携氧能力，且使曲线左移。可为先天（还原酶系统缺陷）或后天（亚硝酸盐、某些局麻药与抗菌药、含苯化合物）。表现为发绀而动脉氧分压正常，血液呈暗褐色，氧疗无效。讲义用一句话把两种中毒的差别钉住：一个红得不对（樱桃红），一个暗得不对（暗褐），但两者都让血氧读数失去意义。

循环性缺氧：装得满、送不到（讲义 13.6）

输送段的两类：缺血性（动脉受阻——粥样硬化、血栓、栓塞、痉挛、外部压迫）与淤血性（静脉回流受阻——心力衰竭、静脉血栓、静脉受压）。讲义对淤血性那一类的解释值得细读：

「动脉仍在供血，但血流太慢，单位时间内送到的氧仍然不够」——补充·hermes-病理生理学讲义·第13章·13.6

四种缺氧与鉴别：每一型断在哪一段（13.4–13.8）

关键词是单位时间。输送段的问题从来不是「血里没有氧」，而是每分钟送到的量不够；代谢产物也带不走，所以淤血性缺氧常伴局部酸中毒——而酸中毒又让曲线右移，短期多放一点氧，长期抑制心肌（13.10 会再提一次）。

指标方向：分压、容量、饱和度均正常，动静脉氧差增大。理由是血流慢、停留久，组织从每单位血液中摄取的份额增加，血回到静脉端时被拿得更干净。发绀可出现于淤血部位（如心衰时的口唇、肢端）——注意这个限定：是部位性的，不是全身性的。

氧疗效果有限，因为是送不到而不是装不满；关键处理是恢复灌注（扩容、强心、解除梗阻、改善体位与活动）。这一型的教学价值在于它逼人把「氧」与「血流」分开想：同一条链条上，携带段与输送段是两个可以独立失效的环节。

组织性缺氧：氧到了，用不上（讲义 13.7）

四种缺氧与鉴别：每一型断在哪一段（13.4–13.8）

三类成因：呼吸链抑制（氰化物抑制细胞色素氧化酶，电子传递中断，组织无法利用氧）；氧化磷酸化解偶联（某些毒物使电子传递与 ATP 合成脱钩，氧照常被消耗，ATP 却产不出来，能量以热的形式散失）；细胞损伤或酶系不足（严重感染、休克晚期、某些维生素缺乏）。

指标方向：分压、容量、饱和度全部正常，动静脉氧差减小，静脉端氧分压偏高——血带着氧回来了。讲义把这一型与循环性缺氧的分野写成一句对照：

「两者都表现为组织缺氧而动脉指标正常，但一个动静脉氧差增大，一个减小，方向相反」——补充·hermes-病理生理学讲义·第13章·13.7

这一句是全章最值得记的一句，因为它是唯一一个方向相反的鉴别点。其余鉴别靠有没有某一项下降，这一对靠差值往哪边走。抓到这一点，就不必背表。

氧疗无效，甚至可能因加重氧化应激而不利；处理必须针对毒物或病因而非给氧。讲义在这里给了一个反直觉的判断：在这种情形下，「给氧」是一种看起来正确、方向上错误的处置。这也是本章反复强调定位的理由——不定位，处置就会跟着名称走。

四型鉴别：一张表与三条规则（讲义 13.8）

表格把五类六行的指标方向排开：乏氧性（分压降、容量正常、饱和度降、氧差正常或偏小、常有发绀、氧疗有效但分流者差）；血液性贫血（分压正常、容量降、饱和度正常、氧差偏小、无发绀、氧疗无效）；血液性一氧化碳（分压正常、容量降、饱和度降、氧差偏小、无发绀呈樱桃红、需高压氧）；血液性高铁血红蛋白（分压正常、容量降、饱和度降、氧差偏小、有发绀、氧疗无效）；循环性（三项正常、氧差增大、可有发绀、氧疗有限）；组织性（三项正常、氧差减小、无发绀呈玫瑰红、氧疗无效）。

四种缺氧与鉴别：每一型断在哪一段（13.4–13.8）

「先看动脉氧分压」——补充·hermes-病理生理学讲义·第13章·13.8

降低 → 乏氧性；正常 → 其余三型。第二步看氧容量或血红蛋白：降低 → 血液性。第三步在分压与容量都正常时看动静脉氧差：增大 → 循环性，减小 → 组织性。

三步的顺序不是随意的：第一步排掉一整类，第二步排掉三种亚型，第三步只剩一对方向相反的情形。每一步都在缩小候选集，这就是「按顺序问」的含义。跳过第一步直接看氧差，会把乏氧性误判成循环性——因为乏氧性合并代偿时氧差也可能偏大。

讲义随即提醒：

「在临床上比单一型更常见」——补充·hermes-病理生理学讲义·第13章·13.8

四种缺氧与鉴别：每一型断在哪一段（13.4–13.8）

指的是混合型：休克合并贫血、肺炎合并心力衰竭、一氧化碳中毒合并心肌损伤。两条段同时受损时，指标互相掩盖——贫血把循环性缺氧的氧差增大削弱，心衰又把乏氧性缺氧的分压降低放大。讲义给的处理办法很务实：不是找一个完美符合的类别，而是按最可能的一段逐段排查，并承认可能同时存在两段。这一句是对整章方法论的收口：定位是分段的，不是分类的。

代偿、损伤与边界：四个层面与一条提示（13.9–13.12）

代偿：四个层面同时应答，每一项都有代价（讲义 13.9）

「代偿有效，患者可以长期维持；代偿有成本，成本累积就是失代偿」——补充·hermes-病理生理学讲义·第13章·13.9

四个层面各有一组反应与一组代价。呼吸：缺氧刺激外周化学感受器 → 通气增加 → 肺泡氧分压上升；代价是呼吸功增加、二氧化碳排出过多致碱中毒、呼吸肌疲劳。循环：交感兴奋 → 心率增快、收缩力增强、血流重分布（心脑优先）；代价是心肌耗氧增加、心律失常、肾与内脏灌注下降。血液：促红细胞生成素增加 → 红细胞增多 → 携氧能力上升；代价是黏度升高、血流阻力增加、血栓风险上升。组织与细胞：毛细血管增生、肌红蛋白增加、无氧酵解增强、低氧诱导因子通路激活；代价是乳酸堆积、酸中毒、细胞水肿。

代偿、损伤与边界：四个层面与一条提示（13.9–13.12）

这张表的设计是「一进一出」：每一层的收益都可以用链条上的一段来表述，每一项代价都可以用另一段来表述。红细胞增多提高了携带段的容量，却提高了输送段的阻力——这是同一条链上的内部交易。理解了这一层，就不会把代偿当成纯收益。

讲义给了一个观察窗口：

「看到后者要想到已经越过了代偿的边界」——补充·hermes-病理生理学讲义·第13章·13.9

前者是长期代偿的痕迹（红细胞增多、右心肥厚、杵状指），后者是代偿耗竭的信号（活动耐量下降、夜间阵发性呼吸困难、意识改变）。两类表现同时存在，往往意味着病程已长且余量将尽。

器官损伤：从一个环节推到一组器官（讲义 13.10）

脑对缺氧最敏感：早期兴奋、烦躁、判断力下降，继而嗜睡、昏迷；缺氧使脑血管扩张、血脑屏障通透性升高 → 脑水肿 → 颅内压升高 → 灌注进一步下降，形成恶性循环。这个环与本章的因果交替主题一致：缺血造成水肿，水肿加重缺血。

代偿、损伤与边界：四个层面与一条提示（13.9–13.12）

心：心肌缺氧 → 收缩力下降、心律失常；酸中毒降低心肌对儿茶酚胺的反应性，使强心手段变得不灵。这一句是机制制约处置的好例子——不是药不管用，是受体端不响应。

肺：缺氧性肺血管收缩本意是减少无通气区域的灌注、保住通气/血流匹配；但广泛而持久的收缩 → 肺动脉高压 → 右心负荷增加 → 肺源性心脏病。这一条值得单独记，因为它是代偿转为致病的典型：局部合理的反应，在全身尺度上成了负担。

肝与肾：缺氧 → 细胞膜泵功能障碍 → 细胞水肿；肾血流减少 → 肾前性功能下降，严重时发展为肾小管损伤。

代谢：无氧酵解增强 → 乳酸升高 → 代谢性酸中毒；钠钾泵失效 → 细胞内钠、钙超载 → 细胞死亡。讲义把这一条与因果交替接了起来：

「缺氧致酸中毒，酸中毒又使曲线右移（短期有利）并抑制心肌（长期有害）」——补充·hermes-病理生理学讲义·第13章·13.10

一句话里装了三个环节与两个时间尺度，是本章密度最高的一句。

发绀：是提示，不是分级（讲义 13.11）

22 / 31boundary
代偿、损伤与边界：四个层面与一条提示（13.9–13.12）

发绀是皮肤黏膜呈青紫色，机制是毛细血管内还原血红蛋白的绝对量增多——注意是绝对量，不是饱和度。这个限定推出三个边界：贫血者即使严重缺氧也可以不发绀（还原血红蛋白总量不够显色）；红细胞增多者轻度缺氧即可发绀（同样的饱和度下降，绝对量更大）；一氧化碳中毒与组织性缺氧可以发绀不明显，甚至呈樱桃红或玫瑰红。

结论讲义写得很干脆：

「没有发绀不等于没有缺氧」——补充·hermes-病理生理学讲义·第13章·13.11

讲义把两个最常见的误判并列：把发绀当作唯一的缺氧体征，以及把血氧读数当作氧含量。两者结构相同——都是把一个指标当成整体。本章反复在做的事，就是拆掉这类一个指标代表一切的读法。

氧疗的边界与监测的陷阱（讲义 13.12）

讲义按四型给出反应：乏氧性最有效；循环性仅部分有效（须同时改善灌注）；血液性（贫血、一氧化碳、高铁血红蛋白）与组织性基本无效，须针对病因处理——输血、高压氧、解毒、支持治疗。

23 / 31boundary
代偿、损伤与边界：四个层面与一条提示（13.9–13.12）

三个监测陷阱：一氧化碳血红蛋白与高铁血红蛋白造成读数假性正常；末梢冷、低灌注、指甲油、深色皮肤可致读数偏差；读数反映的是饱和度，不反映氧含量，也不反映输送。

「读数反映的是饱和度，不反映氧含量，也不反映输送」——补充·hermes-病理生理学讲义·第13章·13.12

这一句其实是全章的压缩：链条有四段，而读数只覆盖其中一段的一半。用一个指标去代表四段，是把定位问题当成了测量问题。

观察顺序讲义给了三步：先定哪一段，再看代偿是否足够（呼吸功、心率、意识），最后看器官是否已受损（意识、尿量、乳酸、心律）。顺序颠倒的后果它也说清了：会在饱和度还行的安慰里错过休克。这一句可以作为本章的收尾判据——顺序错了，信息越多越危险。
