PROBLEM

这一章最容易被读成一个数字的事：血糖高了，降下来就好。可讲义从头到尾没把重心放在那个数字上，而是放在一个结构上——升糖有四路以上，降糖只有一路。这个不对称解释了本章几乎所有的难题：为什么感染、创伤、情绪应激会让血糖迅速失控，为什么同一诊断名称下的患者治疗反应差得很远，为什么并发症的预防不能只盯血糖，为什么低血糖反而是治疗中最常见的急性并发症。把不对称记住，后面三节急性紊乱、四节慢性并发症才有共同的语言。

一、三个变量与「四促四抑」

41.1 先把血糖写成三个变量的平衡：

「肠道吸收、肝脏输出（糖原分解与糖异生）、外周组织摄取与利用」——补充·hermes-病理生理学讲义·第41章·41.1

三个变量各有一个主管方向：肠道吸收由进食决定，肝脏输出由胰高血糖素与胰岛素的比例决定，外周摄取由胰岛素驱动。临床上任何一个“血糖为什么高”的问题，最后都能落到这三个变量中的某一个上——吃得多了、肝输出没被压住、外周不进糖。这个三分法比背并发症有用得多。

胰岛素的作用被压成四促四抑。促进一栏四条：肌肉与脂肪组织摄取葡萄糖、肝与肌肉合成糖原、脂肪合成与储存、蛋白质合成与氨基酸转运，另加一条常被忽略的——促进钾向细胞内转移。抑制一栏四条：肝糖异生、肝糖原分解、脂肪分解、酮体生成。

5 / 32body
一、三个变量与「四促四抑」

四促四抑的排法本身有信息量：四条“促进”里有三条是储存，四条“抑制”里有两条是分解。胰岛素的角色因此不是“降糖”，而是“把燃料收进仓库并关上分解的阀门”。这个读法在 41.7 会直接用上：胰岛素一旦缺位，被打开的第一道阀门是脂肪分解，而不是血糖本身。

6 / 32body
二、不对称结构：一个降糖对四个升糖

升糖一侧讲义列了四个：胰高血糖素（促进糖原分解与糖异生、促进酮体生成）、肾上腺素（应激时快速动员）、皮质醇（促进糖异生、诱导胰岛素抵抗）、生长激素（拮抗胰岛素、促进脂解）。随后是本章的题眼：

「一个降糖激素对抗四个以上升糖激素」——补充·hermes-病理生理学讲义·第41章·41.1

这个不对称有两个后果。第一个是量上的：胰岛素分泌或作用一旦不足，

「升糖方向几乎不受约束」——补充·hermes-病理生理学讲义·第41章·41.1

第二个是时序上的：四个升糖激素里有三个是应激激素（肾上腺素、皮质醇、生长激素），它们的共同点是应激时一起升高。所以血糖失控从来不是渐进的，而是“平时勉强平衡，应激时同时被四路推开”。这一句是 41.7 全部急性紊乱的机制前提，也是 42.6 应激代谢的接口。

7 / 32body
二、不对称结构：一个降糖对四个升糖

讲义顺手把肾糖阈接在这条链上：血糖超过肾小管重吸收能力时出现尿糖，尿糖的渗透效应带走水分，引起渗透性利尿，形成多尿、脱水、烦渴的连锁。这条连锁是 DKA 与 HHS 共同的起手式——两个急症的第一段完全一样，分岔在后面。

三、β 细胞是葡萄糖感受器

41.2 把分泌机制写成一条链：葡萄糖经转运体进入细胞，代谢产生 ATP，ATP 与 ADP 的比值升高，ATP 敏感性钾通道关闭，细胞膜去极化，电压依赖性钙通道开放，钙内流，分泌颗粒与膜融合、释放胰岛素。

这条链的价值在于它能解释三类现象。第一类是通道本身出问题：钾通道活性改变可致新生儿糖尿病或低血糖。第二类是药物借助同一个通道：磺脲类通过关闭同一通道促分泌，因此其低血糖风险与进食状态密切相关——药在推，饭没进来，落差就出现了。第三类是信号放大：葡萄糖以外的信号（氨基酸、脂肪酸、肠促胰素、迷走神经）作为放大器调节同一分泌装置的输出，这解释了为什么同样一餐，进食顺序与肠道激素状态会影响餐后曲线。

讲义随后把 C 肽单列一段，落点是一个判断：

「C 肽是评估内源 β 细胞功能的可靠指标」——补充·hermes-病理生理学讲义·第41章·41.2

9 / 32body
三、β 细胞是葡萄糖感受器

根据在两处：C 肽与胰岛素由同一前体等量裂解产生，但 C 肽不经肝首过代谢、半衰期更长；而外源注射的胰岛素不含 C 肽。两条合起来给出一个工具：测 C 肽可以区分分泌不足与外源补充。在判断类型与病程阶段时，这个区分比血糖本身更有信息量。

10 / 32body
四、肠促胰素：被削弱的一环

肠促胰素效应写在 41.2 末段：进食后肠道 L 细胞分泌 GLP-1、K 细胞分泌 GIP，以葡萄糖依赖性方式放大胰岛素分泌并抑制胰高血糖素。两个要点值得记住：一是“葡萄糖依赖性”——放大只在血糖上升时发生，这解释了为什么以这条通路为靶点的治疗低血糖风险相对低；二是 2 型糖尿病中该效应显著减弱，而它恰好是药物治疗的重要靶点。

把这一节与 41.3 的第三环节并读，会看到一处结构：肠促胰素不是“另一个降糖激素”，而是把降糖信号放大的装置。装置失灵与激素不足是两件事，处理方向也不同。这种区分在 41.5 讲 2 型糖尿病的多重机制时会被再次用到。

五、三环节模型：为什么不能只说“激素不够”

41.3 开篇就否掉一种简化读法：把糖尿病理解为一个激素不够，

「会漏掉大半机制」——补充·hermes-病理生理学讲义·第41章·41.3

更完整的模型是三环节。

环节一，β 细胞分泌缺陷。 包括数量减少（1 型的自身免疫破坏、2 型的进行性凋亡）与功能缺陷（葡萄糖敏感性下降、脉冲分泌丧失、胰岛素原与胰岛素比例升高）。它决定“能不能分泌足够的胰岛素”。

环节二，靶组织胰岛素抵抗。 按层次分受体前（胰岛素抗体、拮抗激素过多）、受体（数量或亲和力下降、受体突变）、受体后（信号转导缺陷、葡萄糖转运体表达下降、脂毒性）。后果有三：肌肉摄取减少、肝糖输出不被抑制、脂肪分解增加使游离脂肪酸涌入肝与肌肉，进一步加重抵抗——形成恶性循环。第三条后果是本章与第 42 章的接缝：脂毒性既是抵抗的原因，也是抵抗的结果。

12 / 32body
五、三环节模型：为什么不能只说“激素不够”

环节三，其他器官环节。 肾小管葡萄糖重吸收增加（使血糖进一步升高）、肠促胰素效应减弱、脂肪组织慢性炎症与脂肪因子失衡、中枢食欲与肝糖调节异常。

三环节的组合决定临床表型，讲义把这句话写得很清楚：分泌缺陷为主者起病较急、酮症倾向明显；抵抗为主而分泌尚可者长期无症状；二者并存且分泌进行性下降者，表现为静默进展直至失代偿。同一诊断名称下的患者治疗反应差异巨大，原因就在这里——他们缺的不是同一个环节。

六、1 型与 2 型：两种自然史

41.4 讲 1 型的机制起点：

「自身免疫介导的 β 细胞选择性破坏」——补充·hermes-病理生理学讲义·第41章·41.4

遗传易感（HLA 区域）个体在环境因素触发下产生针对胰岛细胞的自身抗体，T 细胞介导的炎症逐步摧毁 β 细胞。五个特点各有机制根据：绝对胰岛素缺乏（C 肽极低或测不出，必须依赖外源胰岛素维持生命）；酮症倾向（缺乏胰岛素时脂肪分解不受抑制，酮体大量生成，易发生酮症酸中毒，甚至以急症起病）；起病较急，三多一少明显，儿童青少年多见但任何年龄均可发生；伴随其他腺体的自身免疫病；以及蜜月期——起病治疗后部分 β 细胞功能短暂恢复，胰岛素需求下降，易被误认为痊愈。

蜜月期这一条在护理上最实用：功能短暂回升不是病好了，而是残余细胞在应激解除后的短暂喘息。把它读成痊愈，就会在需求再次上升时误判为“治疗失败”。

「胰岛素抵抗为背景、β 细胞分泌缺陷为进展动力」——补充·hermes-病理生理学讲义·第41章·41.5

五个要点：遗传易感与环境的交互（内脏脂肪增多、体力活动减少、能量摄入结构改变、睡眠不足、心理应激、增龄）；起病隐匿，可多年无典型症状，常在体检、并发症出现或应激时被发现，所以诊断之时已有并发症并不罕见；进展性——β 细胞功能随时间下降，治疗需求逐步升级，这并非没管好，而是疾病自然史的一部分；多重机制并存（肝糖输出增高、肠促胰素效应减弱、肾糖阈上调、脂肪组织炎症、肌肉摄取减少）；以及共享代谢综合征的土壤。

“这并非没管好”这五个字值得单独标出。它把一个常被读成依从性问题的现象，还原成疾病自然史——这一句改变的是沟通方式，不是治疗方案。

七、特殊类型与妊娠糖尿病

41.6 篇幅不长，但两类都要记。其他特殊类型包括：单基因糖尿病（青年发病的成人型糖尿病、新生儿糖尿病，常被误诊为 1 型或 2 型，家族史与病程特点提供线索）、胰腺外分泌疾病（慢性胰腺炎、胰腺切除、囊性纤维化、血色病）、内分泌病（皮质醇增多、肢端肥大、甲亢、嗜铬细胞瘤）、药物或化学物所致、感染。

这一串的用处是提醒：不是所有糖尿病都落在 1 型与 2 型两格里。单基因糖尿病被误诊的代价尤其大——诊断名称一错，整条管理思路就跟着错。

妊娠糖尿病的机制有一条清晰的生理逻辑：妊娠中晚期胎盘分泌的激素（胎盘生乳素、孕激素、皮质醇）造成

「生理性胰岛素抵抗加深」——补充·hermes-病理生理学讲义·第41章·41.6

若 β 细胞储备不足以代偿，即出现糖代谢异常。这正好是 39.10 那一节“妊娠期生理性胰岛素抵抗”的病理延伸，也是三环节模型的一个干净用例：抵抗加深是生理的，出问题的是代偿能力。

七、特殊类型与妊娠糖尿病

三个意义各有落点：对母亲，增加妊娠期高血压与远期 2 型糖尿病风险；对胎儿，母体高血糖经胎盘传输刺激胎儿胰岛素分泌，导致巨大儿、新生儿低血糖、呼吸窘迫与远期代谢风险；对管理，产后多数恢复，但需长期随访。“产后恢复”不等于“事情结束”，这一句是随访的依据。

八、DKA 与 HHS：同一失代偿的两种侧重

41.7 是本章最长的一节，两个急症必须分开读。两者的共同前提是胰岛素不足加升糖激素过多，但侧重不同。

糖尿病酮症酸中毒（DKA）：胰岛素绝对或近乎绝对缺乏，脂肪分解失控，游离脂肪酸在肝内转化为酮体，酮体为酸性物质，导致代谢性酸中毒。临床方向：多尿烦渴加重、恶心呕吐、腹痛（可被误为急腹症）、深大呼吸、呼气烂苹果味、脱水、意识由淡漠至昏迷。实验室方向：血糖显著升高、血酮与尿酮阳性、代谢性酸中毒、阴离子间隙增大、总体钾缺失而血钾可高可低——酸中毒与胰岛素缺乏使钾外移，血钾“看似正常”实则总体缺钾。

这一条是本节最该记住的陷阱：血钾可以看起来正常，而总体已经缺钾。它解释了为什么补钾要等尿量恢复后再审慎补充——补得太早、太快，风险在心脏。

八、DKA 与 HHS：同一失代偿的两种侧重

高渗高血糖状态（HHS）：胰岛素相对不足，足以抑制酮体生成，却不足以控制血糖。于是血糖极度升高而无明显酮症，渗透性利尿导致严重脱水与高渗，血液浓缩、黏度升高，血栓风险上升。临床方向：起病较缓、老年多见、脱水征明显、意识障碍突出、可有局灶神经体征或抽搐（易被误为脑卒中）。实验室方向：血糖与血浆渗透压显著升高、酮体阴性或微量、血钠因脱水而升高。

两者的分界可以压成一句话：酮体生成需要“绝对缺”，血糖失控只需要“相对缺”。这一句把 41.1 的四促四抑与本节接上——脂肪分解这道阀门对胰岛素的敏感度，高于葡萄糖摄取那道。

共同诱因：感染（最常见）、胰岛素中断或用量不足、新发糖尿病、急性心脑血管事件、创伤手术、妊娠、严重情绪应激、某些药物。护理识别的关键是感染、脱水、意识改变、呼吸模式改变四者的组合，而不是等待化验结果——这一句把识别时点提前到了化验之前。

八、DKA 与 HHS：同一失代偿的两种侧重

处理原则只有方向性表述：补液纠正脱水、静脉胰岛素抑制脂解与糖异生、纠正电解质（尤其钾，须在尿量恢复后审慎补充）、寻找并处理诱因、监测意识与循环。讲义特意强调两件事必须同步，并把不同步的后果写死：

「单用胰岛素而不补液会加重循环衰竭，单补液而不给胰岛素无法关闭酮体生成」——补充·hermes-病理生理学讲义·第41章·41.7

具体剂量与速率属个体化医疗决策，讲义不予列举，本页同样不写。

九、四条通路与两类血管

41.8 把慢性并发症从“血糖高久了自然出现”的模糊说法，改写成四条可归纳的细胞机制。

非酶糖基化：葡萄糖与蛋白质氨基共价结合，形成糖基化终末产物，交联胶原使血管壁僵硬、基底膜增厚，并通过受体激活炎症与氧化应激。多元醇通路：葡萄糖经醛糖还原酶转为山梨醇，细胞内渗透压升高、NADPH 消耗，见于神经、晶体、视网膜。蛋白激酶 C 激活：由二酰甘油增多触发，改变血管通透性、内皮素与 VEGF 表达，促进新生血管与渗漏。氧化应激与炎症：线粒体超氧化物增多，激活炎症因子与黏附分子，造成内皮功能障碍。

四条通路汇聚于同一结果：

「微血管基底膜增厚、内皮功能障碍、血流与神经灌注异常」——补充·hermes-病理生理学讲义·第41章·41.8

这个“汇聚”是本节的方法要点：四条通路不是四个独立的病，而是同一批损伤的四条来路；因此针对单一通路的干预，效果总被其余三条稀释。

九、四条通路与两类血管

受累表按血管分两类。微血管三类：视网膜（微动脉瘤、出血、渗出、黄斑水肿、增殖性病变）、肾（蛋白尿、滤过率下降、血压升高）、神经（远端对称性感觉异常、自主神经受累如体位性低血压、胃轻瘫、排尿与性功能异常）。大血管一类：冠脉、脑、外周动脉，表现为冠心病（常无痛）、脑卒中、间歇性跛行。

讲义特意指出大血管的机制不同：它以动脉粥样硬化为核心，糖尿病通过血脂异常、炎症、内皮损伤、血小板功能改变加速这一过程，并与高血压、吸烟、肥胖协同。因此糖尿病被视为冠心病的等危状态，而这个概念的意义在于：

「并发症的预防不能只盯血糖」——补充·hermes-病理生理学讲义·第41章·41.8

十、足与感染：三类因素叠加

41.9 把糖尿病足写成三类因素的叠加，缺一不可。神经病变：感觉丧失使患者察觉不到外伤与压力，运动神经病变致足趾畸形、压力分布异常，自主神经病变致皮肤干燥、皲裂。缺血：外周动脉病变使组织灌注不足，伤口难以愈合。感染：高血糖环境下免疫细胞功能受损（趋化、吞噬、细胞内杀菌能力下降），感染一旦发生便迅速扩散。

三者的关系不是并列而是串联：感觉丧失让伤口不被发现，缺血让伤口不愈合，感染让伤口迅速扩散。任何一项被忽略，伤口都可能从小破皮演变为深部感染、骨髓炎甚至截肢。这条串联解释了为什么足部护理的每一条动作都对着其中一环：每日检查对着感觉丧失，合适鞋袜对着压力分布，保持皮肤湿润而趾间干燥对着皲裂，发现伤口立即就医对着缺血与感染。

讲义对预防的评价很直接：

「预防的价值远高于治疗」——补充·hermes-病理生理学讲义·第41章·41.9

感染与糖尿病的关系是双向的：感染通过升糖激素与胰岛素抵抗加重高血糖，高血糖又削弱免疫防御，形成感染与高血糖之间的正反馈，是 DKA 与 HHS 最常见的诱因。这一条把本节与 41.7 接成闭环：感染的入口在足，出口在酮症。

十一、低血糖：预警与感知受损

41.10 讲治疗中最常见的急性并发症，起点是一句解剖事实：

「脑依赖葡萄糖供能」——补充·hermes-病理生理学讲义·第41章·41.10

而脑组织几乎无糖原储备——所以低血糖的危害不在“饿”，在“断供”。

表现分两组。交感肾上腺样症状（心悸、出汗、震颤、饥饿感、焦虑、面色苍白）由儿茶酚胺释放引起，是早期预警；神经低糖症状（注意力涣散、反应迟钝、言语含糊、行为异常、视物模糊、抽搐、昏迷）提示脑功能受损。两组的关系是时序的：预警在前，脑功能受损在后。于是本节最重的一句是：

「病情越重，预警症状可能越不明显」——补充·hermes-病理生理学讲义·第41章·41.10

机制在同一节：长期糖尿病致低血糖感知受损，反复低血糖使交感反应阈值下移，患者在血糖已很低时仍无预警，直接进入神经低糖阶段。这条机制把“预警”从一个可靠信号变成了一个会失效的信号——风险最高的，恰恰是那些“从来没有低血糖症状”的人。

十一、低血糖：预警与感知受损

高危人群与情形讲义列了六类：使用胰岛素或促泌剂者；进食不足、延迟进餐、饮酒（抑制糖异生）；运动后未调整；肾功能不全（胰岛素清除减慢，接 39.6 的清除机制）；老年与认知障碍者；以及上述感知受损者。

处理原则只有方向：意识清醒者立即口服快速吸收的糖类，随后补充较持久的主食以防复发；意识障碍者不可经口喂食（误吸风险），须由他人协助并紧急就医。处理后须查找原因（用药、进食、运动、肾功能、饮酒）并调整方案，而不是简单补上就好。“补上就好”是本节最想否掉的直觉：一次低血糖是一次信号，不是一次事故。

十二、管理与生命周期

41.11 先给目标。管理的落点不是把一个数字压到某个点：

「降低并发症风险、维持功能与生活质量」——补充·hermes-病理生理学讲义·第41章·41.11

随后是五组内容。

监测的局限：自我血糖监测反映时点值，糖化血红蛋白反映一段时间内的平均水平，二者都不能反映波动幅度；而波动本身与氧化应激和并发症相关。理解平均值正常而波动剧烈同样有风险，是解读监测结果的关键。

教育四件事：足部护理、饮食结构与进餐规律、运动的安全原则（避免在低血糖高风险时段运动、随身携带糖类）、生病日管理（感染时监测加密、不擅自停药、及时就医）。

并发症筛查：眼底、尿蛋白与肾功能、足部感觉与血管评估、血脂与血压管理、口腔与皮肤护理。

心理与社会支持：疾病负担、饮食限制、注射恐惧、低血糖焦虑、治疗疲劳显著影响依从性，需主动评估而非视为不配合。这一条与 40.11 的心理社会支持是同一条原则在两章里的两次出现。

十二、管理与生命周期

41.12 把管理放回生命周期。儿童与青少年：生长发育、学业、同伴关系与自我管理能力的建立并重；青春期胰岛素抵抗生理性升高，需求波动大；家庭支持与逐步过渡到自我管理是关键。老年：低血糖风险高、感知受损、认知与视听功能下降、多重用药、共病多，管理目标应个体化，

「避免以严格达标换取低血糖与跌倒风险」——补充·hermes-病理生理学讲义·第41章·41.12

妊娠：孕前评估与准备、孕期密切监测、产后随访。围手术期与重症：应激性高血糖常见，需与原有糖尿病区分；管理重点是避免剧烈波动与低血糖。

十二节的排法本身就是一条链：41.1 与 41.2 给生理，41.3 给模型，41.4 到 41.6 给类型，41.7 到 41.10 给四类急性与慢性后果，41.11 与 41.12 给管理与时间。若从 41.7 开始读，两个急症会变成两张对照表——而它们其实是同一个不对称结构在两种缺胰岛素程度下的两种表现。
