导论是最容易被读成客套的一章：定义、分类、规律、方法，四样都在，却一样也不治病。急着背病名的人翻过去，等到第三章讲细胞损伤时才发现，手里没有一套问法——不知道该先问「这是什么」，还是先问「为什么会这样」，于是每个病名都变成一段孤立的记忆。这一章真正要交的不是知识点，是一条问法与三处口径：四个问题定顺序，病因与条件定位置，健康与疾病定连续谱，五类错误定纠错线。缺了这条问法，后面每一章都会退化成名词表。

一、四个问题：把学科定义拧成一条推理链（1.1）

1.1 什么是病理生理学

讲义的第一句就是学科定义，落点在「规律」与「机制」两个词上：

「是研究疾病发生、发展与转归的规律及其机制的科学」——补充·hermes-病理生理学讲义·第1章·1.1

定义之后立刻划截面。讲义把本课程与病理解剖学的分工写成一句话：一个问结构与形态，一个问功能与代谢。这个分工值得记住的原因不在礼貌，而在它决定了后面每一章怎么写——凡涉及「长什么样」的问题，本章一律转交病理学；凡涉及「为什么变了」的问题，才在本课程范围内。

研究对象那一句更具体：

「疾病状态下机体的功能代谢变化及其发生机制」——补充·hermes-病理生理学讲义·第1章·1.1

学科定位被写成桥梁，服务对象被写成依据：

「为诊断、治疗、护理与预防提供机制依据」——补充·hermes-病理生理学讲义·第1章·1.1

「依据」两个字是本章最要紧的边界。依据在课程手里，处置在临床手里；课程越界的那一刻，正是它把依据写成了处置。

一、四个问题：把学科定义拧成一条推理链（1.1）

四个问题的次序是定义题不是修辞题：先辨认是什么，再追问为什么，再展开如何，最后落到怎样。讲义在同一节里给了一句提醒，解释为什么两个截面必须同读：有些病结构改变轻微而功能紊乱显著，有些病结构改变显著而功能长期代偿，只看一面就会漏判。

二、病因、条件、诱因：三个位置与一句话记法（1.2）

1.2 病因学

这一节是全章最厚的一节（node code/main.js 现算：346 字），厚在它要把三个常被混用的词分开。定义只有两个限定：

「引起疾病必不可少的、决定疾病特异性的因素」——补充·hermes-病理生理学讲义·第1章·1.2

「必不可少」管必要性，「决定特异性」管身份。两个限定合起来说明一件事：不是所有在场的因素都叫病因，同时满足这两条的才算。

条件的定义落在影不影响上：

「能影响疾病发生发展的内外环境因素，如年龄、性别、营养状态、免疫水平、气候等」——补充·hermes-病理生理学讲义·第1章·1.2

诱因是条件的一个子集，判定落在时点上：

「促使疾病在病因作用下发生的条件称」——补充·hermes-病理生理学讲义·第1章·1.2

讲义给的两个例子都是日常情境，只作类别示例，不作个案判断——这是本书对一切举例的用法：受凉诱发肺炎、情绪波动诱发心绞痛。

二、病因、条件、诱因：三个位置与一句话记法（1.2）

「病因决定「会不会得、得什么病」，条件决定「何时得、得多重」」——补充·hermes-病理生理学讲义·第1章·1.2

一句话里三个位置各占一格：病因管得不得、得哪一种，条件管何时起、多重，诱因管此刻是否被促成。混读的典型症状是把年龄写成病因——年龄能影响发生发展，却不是必不可少的，也不是决定特异性的。

讲义另外补了两处更硬的区分：必要病因无之则必不得该病，充分病因有之则必得，而后者罕见；多数慢性病是多因素网络，单一因素既不必要也不充分，只提高概率，这类因素叫危险因素。还有一条常被忽略的：条件不是被动背景，它经三条途径起作用——增加暴露、削弱防御、改变反应性。

三、发病机制：四段环节、两种类型、一条环（1.3）

1.3 发病机制

讲义对机制的定义同时交代了跨层次：

「是病因作用于机体后，疾病发生、发展的具体过程与原理，涉及分子、细胞、组织器官与整体多个层次」——补充·hermes-病理生理学讲义·第1章·1.3

四段基本环节被写成一条可以照抄的句式：

「病因 → 与机体相互作用（损伤与抗损伤）→ 功能代谢紊乱 → 临床表现」——补充·hermes-病理生理学讲义·第1章·1.3

四段各占一个位置：起点是因素，第二段是力量对比，第三段是机能与代谢的偏离，第四段是可观察的表现。第二段之所以要单列，是因为它解释了同一病因为何结局不同——力量对比不同，走向就不同。

机制类型分两支：直接损伤与间接机制。间接那一支列了四条路径：

「免疫损伤、炎症介质、神经-体液调节紊乱、代谢障碍」——补充·hermes-病理生理学讲义·第1章·1.3

三、发病机制：四段环节、两种类型、一条环（1.3）

「缺氧 → 无氧代谢增强 → 乳酸堆积 → 酸中毒 → 血管舒缩障碍 → 血压下降 → 组织灌注进一步减少 → 缺氧加重」——补充·hermes-病理生理学讲义·第1章·1.3

链的起点是缺氧，末端落在缺氧加重——首尾同名。写成链时按箭头读，写成环时要指出哪一段是回返。这条例子在第 25 章（酸碱平衡）会以完整形态再出现一次，本章只把它当作「环」的样板。

讲义还给了两条写作纪律。一条是先分层再谈机制：同一过程在分子、细胞、器官、系统与整体五个尺度上有不同读法，层次之间有涌现，单个心肌细胞的代谢改变推不出患者的活动耐力，却是其必要条件。另一条是机制不总单向恶化：代偿与失代偿的转折正是讨论转归的基础，这一句把 1.3 与 1.7 接了起来。

最后是共同通路：

「不同病因常汇入少数几条损伤通路——能量不足、氧化应激、钙超载、炎症」——补充·hermes-病理生理学讲义·第1章·1.3

正因为存在共同通路，才可能有基本病理过程这一层概念，也才可能有一门课把几十种病放在一起讲。

四、基本病理过程与四种临床用语（1.4）

1.4 基本病理过程与临床表现

这一节补的是用词层。基本病理过程的定义只有两个限定：

「多种疾病中共有的、成套的功能代谢变化」——补充·hermes-病理生理学讲义·第1章·1.4

「多种疾病中共有」说明它不属任何一种病，「成套」说明它不指一项改变。讲义举的例是一串熟悉的词：

「发热、炎症、缺氧、水肿、脱水、酸碱失衡、休克、弥散性血管内凝血（DIC）等」——补充·hermes-病理生理学讲义·第1章·1.4

这份清单解释了本课程为什么有一半章节在讲这些词：它们不是病，是跨病的类。一个病可以同时走上其中几个，几个病也可以共用同一个。

临床表现按可观察性分三栏，症状与体征的差别写在括号里，不另立定义：症状是患者主观感受，体征是体格检查可发现的客观表现，第三栏是实验室与影像学改变。三栏并排的用处是把主观陈述与客观观察分开记，不合并成一句主观加客观的混写。

四、基本病理过程与四种临床用语（1.4）

「疾病过程中继发的另一种疾病或病理过程（如肺炎并发脓胸）」——补充·hermes-病理生理学讲义·第1章·1.4

「疾病恢复期遗留的持久性功能障碍或结构异常」——补充·hermes-病理生理学讲义·第1章·1.4

前者是并发症，后者是后遗症。差别在时序与归属：并发症发生在过程之中，属另一段过程；后遗症发生在过程之后，属这一段留下的东西。讲义把这一组词连同综合征一起收在一句里：归类其实是在判断它在时间轴与因果链上的位置。

本节末尾还有一条实用提醒，针对不典型表现：老年、婴幼儿与免疫抑制者常偏离教科书，感染可以不发热，休克可以血压尚可而灌注已差。纠正办法不是加一条症状清单，而是回到机制问这条机制还有没有别的出口。这一句是本章把「机制」当纠偏工具用的第一次，第 1.11 节会把它写成通用纪律。

五、四条一般规律与代偿的三个层次（1.5）

1.5 疾病发生发展的一般规律

四条规律各占一段，讲义在末尾把它们收成四种视角。第一条是力量的对比：

「贯穿疾病全程的两股力量，其对比决定转归方向」——补充·hermes-病理生理学讲义·第1章·1.5

例子是一组对峙：感染时细菌毒素是损伤一方，发热、白细胞吞噬与抗体产生是抗损伤一方。紧接着一句提醒，是初学者最容易漏的：

「抗损伤过度也会造成损害（如炎症风暴）」——补充·hermes-病理生理学讲义·第1章·1.5

第二条是因果交替：某一过程的结果成为新过程的原因，形成连锁（见 1.3 缺氧链条）。第三条是局部与整体，讲义给了两个方向各一个例子：

「局部病变可引起全身反应（如龋齿→败血症→休克）」——补充·hermes-病理生理学讲义·第1章·1.5

「全身状态也影响局部病变（如营养不良者伤口愈合差）」——补充·hermes-病理生理学讲义·第1章·1.5

五、四条一般规律与代偿的三个层次（1.5）

「疾病本质上可看作内环境稳态的破坏与机体修复能力不足的表现」——补充·hermes-病理生理学讲义·第1章·1.5

这一条不是第四组并列规律，而是前三组的合账：稳态的破坏说的是偏离，修复能力不足说的是抗损伤不够。它在章末被明确交给第 2 章，所以本章不追问它的机制细节。

四条之后是代偿的三个层次，这一段是全章密度最高的部分：功能代偿（心率加快维持输出）、结构代偿（心肌肥厚、单侧肾切除后对侧肥大）、代谢代偿（慢性缺氧时红细胞生成增加）。三层的共同点是都在正常值上看不出差别，只在负荷时才显现。代价也写在同一段：

「代偿有代价——肥厚心肌耗氧更高、储备更少」——补充·hermes-病理生理学讲义·第1章·1.5

这句话的作用是拆掉一个常见等式：代偿不等于无害。肥厚的心肌能维持输出，却同时把耗氧与储备两笔账都推向了不利的一边——这正是 1.3 那句「代偿—失代偿」的具体内容。

六、健康、疾病与疾病连续谱（1.6）

1.6 健康、疾病与疾病连续谱

讲义的健康定义用的是正面描述，不是检查的阴性结果：

「身体、心理和社会适应三方面均处于完好状态，而不仅仅是没有疾病或虚弱」——补充·hermes-病理生理学讲义·第1章·1.6

疾病的定义则含三个要素——病因的作用、自稳调节的紊乱、异常的生命活动过程：

「机体在病因作用下，因自稳调节紊乱而发生的异常生命活动过程」——补充·hermes-病理生理学讲义·第1章·1.6

三要素缺一不可，讲义给了两个方向的例子：有病因作用而无调节紊乱（如带菌状态）通常不称疾病；有调节紊乱而病因难寻（部分功能性疾患）仍按疾病处理，但机制解释须留余地。这两个例子合起来否掉了两种朴素读法——查出病原体不等于患病，查不出原因也不等于没病。

亚健康的定义落在未达诊断标准上：

「介于健康与疾病之间的过渡状态，功能代谢轻度偏离但未达疾病诊断标准（如疲劳、睡眠障碍、反复感冒）」——补充·hermes-病理生理学讲义·第1章·1.6

六、健康、疾病与疾病连续谱（1.6）

这一句是本页最该收紧的地方。它描述的是状态的位置，不是个体的结论：说某人处在亚健康那一格，等于用一条描述性排列给他定位，而下这个判断需要标准、检查与资质，三样都不在本课程手里。讲义自己也留了一句——亚健康缺乏统一判定标准，宜作风险提示而非诊断标签。

连续谱的形状是四段的：

「健康 → 亚健康 → 疾病（轻→重）→ 慢性化 / 康复 / 恶化」——补充·hermes-病理生理学讲义·第1章·1.6

讲义把这条线接到预防的三个层次：减少暴露、早发现早处理、防并发症与防残。三层里第二层最能体现评估的价值，而评估的对象是状态与风险，不是给谁贴一张标签。

七、转归四格与两条界线（1.7）

1.7 疾病的转归

转归被排成一张四格表，每格一句含义，四句都可以逐字引用：完全康复是病因清除、功能代谢完全恢复；不完全康复是损伤留有代偿性改变或后遗症；慢性化是病程迁延、反复发作；恶化与死亡是疾病进行性加重至死亡。四格的次序不是严重度排序，而是过程走到哪一段的位置。

决定转归的三要素讲义写在一段里：

「损伤与抗损伤的力量对比、代偿储备的多少、干预的时机与恰当性」——补充·hermes-病理生理学讲义·第1章·1.7

前两者由病情与个体条件决定，第三者部分可由照护者影响——这正是护理在转归中的位置，也是本章与 1.8 的接缝。

两条界线要单独记。第一条是完全与不完全的分界：

「心肌梗死后瘢痕永久存在，若泵功能与活动能力恢复，仍归不完全康复但功能良好」——补充·hermes-病理生理学讲义·第1章·1.7

17 / 31body
七、转归四格与两条界线（1.7）

这句话说明分界落在功能而不在结构：瘢痕不会消失，功能可以恢复；反过来，结构愈合而功能长期受限，也不算完全康复。第二条界线是脑死亡与植物状态的分界，落在脑干：

「前者全脑（含脑干）功能不可逆丧失，后者保留脑干功能而意识丧失」——补充·hermes-病理生理学讲义·第1章·1.7

这两句都是概念层的说明：讲的是类别怎么分，不是判定怎么做。判定依现行规范、由具备资质的人员作出；本章只把死亡记作转归的终点类别，不写任何程序，也不对任何个体作预测。这是全章边界最紧的一格。

八、从机制到床边：临床判断与护理实践（1.8）

1.8 病理生理学与临床护理实践

这一节是全章的落地点，讲义用五个条目把机制接到具体工作上：临床判断、护理诊断、循证实践、用药与干预，以及一条总提醒。

临床判断那一条写的是推理过程：

「护士依据症状、体征与机制推理形成护理假设」——补充·hermes-病理生理学讲义·第1章·1.8

护理诊断那一条给了落点，说明诊断条目不是凭经验编的，而是直接建立在病理生理机制之上。循证实践那一条把三样东西并列：

「将最佳研究证据、病理生理机制理解与患者偏好结合，做出个体化决策」——补充·hermes-病理生理学讲义·第1章·1.8

三样缺一不可：只有证据会忽略个体，只有机制会忽略证据强度，只有偏好会失去依据。

本节最实用的一条是同一症状、不同机制、相反处理：

「术后少尿若源于低血容量，方向是补充容量」——补充·hermes-病理生理学讲义·第1章·1.8

八、从机制到床边：临床判断与护理实践（1.8）

「若源于肾实质损伤，方向是限制进一步损伤并监测，仅凭「尿少」无法决定方向」——补充·hermes-病理生理学讲义·第1章·1.8

这两句说明机制在本课程里的用途不是解释得漂亮，而是决定方向：同一个表现，机制不同，方向可能相反。讲义另有一句关于判断方式的说明——临床判断由模式识别与分析推理共同完成，熟练者多靠前者，但遇到不典型表现而认不出来时，机制是唯一的纠偏工具。

九、方法三支与四条实验逻辑（1.9）

1.9 主要研究方法

讲义按在哪儿做把方法分三支，每支列一串具体做法：实验研究（动物实验、离体器官与细胞实验、分子生物学实验）、临床研究（临床试验、观察性研究）、流行病学研究（横断面调查、队列研究、病例对照研究、系统评价与 Meta 分析）。

三支各答一个问题，讲义把边界写在同一段里：实验研究可控可干预但脱离整体；临床研究直接可用但受混杂与伦理限制；流行病学研究规模大却难定个体因果。三句并列的意义是取消排序——三者是分工，不是优劣。

实验的基本逻辑有四条，讲义写得极省：对照排除自然病程与安慰剂效应，随机平衡已知与未知混杂，盲法减少测量与期待偏倚，可重复排除偶然。

「缺一条，结论强度就打折」——补充·hermes-病理生理学讲义·第1章·1.9

这一句后面没有例外条款。它对本课程自身也成立：本章所有统计都由脚本现算，但脚本只说明讲义怎么用词，不说明讲义的结论对不对。

十、限度与证据层级：结论只能用在覆盖范围内（1.10）

1.10 研究方法的限度与证据层级

这一节的第一句就是全节的总纲：

「方法的结论只能用在它覆盖的范围内」——补充·hermes-病理生理学讲义·第1章·1.10

随后逐支点名限度。动物模型的强项与弱项分得很清：种属差异明显，诱导方式模拟的多是某个环节被突然打断，而人类疾病多为长期、缓慢、多因素累积；因此它擅长回答这条通路是否成立，不擅长回答这个患者会不会受益。离体与细胞实验的限度在权重：去除整体调节与灌注条件，能把机制拆到分子层，却说不出它在完整机体中占多大权重。

观察性研究的两个威胁被并列写出：

「混杂与反向因果是两个基本威胁」——补充·hermes-病理生理学讲义·第1章·1.10

后一句解释了为什么难分：可能是暴露致病，也可能是疾病本身改变了暴露。随机对照试验的限度在外部效度——内部效度最好，但严格入组使受试者与真实患者有差距。

十、限度与证据层级：结论只能用在覆盖范围内（1.10）

证据层级被写成一条连续谱：从机制研究、病例报告、横断面、队列与病例对照、随机对照，到系统评价；谱的一端是解释力强、可推广性弱，另一端相反。讲义特意说明这条谱描述的是证据强度而非真理性，正确用法是各司其职——基础研究解释机制，人群研究判断效果。这一条与 1.9 的三支分工是同一件事的两种写法：一个说方法在哪做，一个说结论能走多远。

十一、五类常见错误与可复用的四问（1.11）

1.11 病理生理学推理的常见错误

末节把前十一节收成一份纠错清单：

「以下五类错误出现频率最高，且都有明确的纠正办法」——补充·hermes-病理生理学讲义·第1章·1.11

五类各有表现与修法。以症代病：把症状当诊断，修法是先列机制假设，再找区分线索。以偏概全：用单个指标定论，修法是要求至少两条独立线索同向。把相关当因果：两个变化同时出现即断定因果，修法是问时间先后、问有无共同原因、问有无剂量与反应的关系。把机制当疗效：因机制上应该有效就认定有效，或因机制上说不通就否定观察到的效果，修法是机制提出假设、证据判定效果。第五类是忽视时间与个体：把代偿期与失代偿期混为一谈，把典型表现套到老年、婴幼儿或共病患者身上，修法是标注哪个阶段、哪类人。
