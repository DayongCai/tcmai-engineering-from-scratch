PROBLEM

女性生殖功能异常的难点不在病种多，而在同一个表现可以从五个层次来：同是闭经，可以是流出道堵了、子宫坏了、卵巢耗竭了、垂体受压了，也可以是下丘脑的脉冲停了。五层的方向完全不同，而表面症状一模一样。这一章给的正是这套分层——先把表现按层排开，再从最下游往最上游走，用最简单的检查排除最大的类别。没有它，闭经只能背成一份病因清单；有了它，闭经就变成一道可以逐层排除的题。第二件要交的是识别机制环：雄激素过多不是一串并列症状，而是一个每一环都强化其他环的循环。

一、六类：分类是评估的起点

33.1 把异常分成六类：轴与出血异常、激素失衡、结构异常、盆底支持结构异常、肿瘤性病变、妊娠相关异常。切法不是按器官，而是按评估路径——每一类对应一套不同的检查思路，因此讲义给了一句用法上的限定：

「分类的目的是建立评估的起点，而非终点」——补充·hermes-病理生理学讲义·第33章·33.1

六类之间大量交叉：子宫内膜异位症既属结构异常又致疼痛与不孕，多囊卵巢样改变既属激素失衡又致出血异常与代谢问题。交叉的处理与前章一致——一格作起点，其余写传导关系，不并列。这一节最容易被略读，其实它决定了后面十节的读法：分类若不落在评估路径上，就只是六个标签。

二、闭经的五层：从下游往上排查

33.2 把闭经写成一道分层题。流出道：处女膜闭锁、阴道横隔、宫腔粘连、宫颈狭窄——卵巢与激素周期正常，但经血不能排出，表现为周期性腹痛而无经血。子宫：内膜被破坏致不能再生，激素正常而月经不来。卵巢：卵泡耗竭或功能衰退，雌激素低下、促性腺激素升高。垂体：肿瘤、缺血、高催乳素状态抑制脉冲。下丘脑：过度运动、体重过低、严重应激、进食障碍抑制脉冲发生器，表现为低促性腺激素性低性腺功能。

顺序的价值是效率——「从「最下游」往「最上游」排查，可以用最简单的检查排除最大类的病因」——补充·hermes-病理生理学讲义·第33章·33.2。讲义把每层对应的工具也说清了：流出道与子宫靠影像与病史，卵巢靠激素方向，中枢靠促性腺激素与影像。注意方向二字的用法与前一章一致：不是看某个值高不高，而是看促性腺激素朝哪个方向动。

二、闭经的五层：从下游往上排查

同一节还给了异常子宫出血的四组机制：排卵障碍性（无排卵则无黄体、无孕酮，雌激素持续作用使内膜过度增殖，脱落不规律且量大——这是无孕酮对抗的直接后果）、结构病变性、凝血性（全身性凝血异常可表现为经量过多，常被忽略）、医源性。四组里只有第一组直接落在轴上，另三组提醒：出血不一定来自轴。末句是一条不可省的情形：绝经后出血无论量多少都属于需要评估的情形，因为其机制指向内膜病变而非周期波动。

三、雄激素三源与一条因果交替环

33.3 先把来源拆成三处：卵巢源（卵泡膜细胞过度活跃，黄体生成素驱动增强）、肾上腺源（肾上腺雄激素合成增加）、外周转化（脂肪组织把雄激素芳香化为雌激素，同时胰岛素抵抗降低性激素结合球蛋白，使游离雄激素升高）。三源之分决定往哪里找——三处对应三种不同的入口。

随后讲义把多囊卵巢样改变写成一整条环：胰岛素抵抗导致代偿性高胰岛素，高胰岛素使卵泡膜细胞对黄体生成素的反应增强，雄激素产生增加，雄激素抑制优势卵泡选择使卵泡发育停滞，于是无排卵、孕酮缺乏、内膜持续受雌激素刺激；同时高胰岛素降低性激素结合球蛋白，进一步提高游离雄激素的活性。讲义对这一结构的判断是「这是一个典型的因果交替环：每一环都强化其他环」——补充·hermes-病理生理学讲义·第33章·33.3。

8 / 30body
三、雄激素三源与一条因果交替环

这一句同时定了临床表现的读法：月经稀发或闭经、多毛与痤疮、不孕、内膜增生风险上升、代谢异常，不是并列清单，而是同一机制环的不同输出。清单只能逐条罗列，环可以指出从哪一环切入。讲义还给了实践含义：干预可以从环上任何一点切入，体重管理之所以有效，是因为它同时作用于胰岛素抵抗与脂肪组织芳香化两个环节——仍停在类别层，只指出可切入的环节，不给方案。

四、内异症：三步与三个输出

33.4 把子宫内膜异位症的机制写成三步组合——「经血逆流 + 免疫清除失败 + 在位内膜决定论」，讲义称之为最具解释力的说法（补充·hermes-病理生理学讲义·第33章·33.4）。第一步是经血逆流；但逆流是常见现象，多数人并不发病，因此仅有逆流不足以成病。第二步是免疫清除失败——腹腔内的自然杀伤细胞与巨噬细胞未能有效清除逆流的内膜细胞，反而分泌炎症因子促进其黏附与增殖。第三步是在位内膜的生物学差异——患者自身的子宫内膜在黏附、侵袭与血管生成能力上更强，使其在异位存活。

四、内异症：三步与三个输出

三步分量不均：前提、闸门、个体差异。这个结构解释了为什么同一现象在不同人身上结局不同。三个核心表现全部由同一机制推出：疼痛（异位病灶随周期出血，局部炎症与前列腺素释放刺激神经末梢；炎症反复致盆腔粘连，形成慢性盆腔痛）；粘连与不孕（反复出血与炎症修复导致纤维化与粘连，改变输卵管与卵巢的解剖关系，影响拾卵与运输，炎症环境也不利于受精与着床）；卵巢囊肿（异位内膜在卵巢内反复出血，形成陈旧性积血的囊肿）。

子宫腺肌病单列：内膜侵入肌层，机制涉及内膜与肌层交界带的结构破坏；表现为子宫增大、经量增多与痛经，疼痛机制与异位症相似，但病灶在肌层内，故子宫呈对称性增大。两者的共同点是激素依赖性——病灶随雌激素刺激而活动，随绝经或激素抑制而萎缩；这一句既解释症状的周期性，也构成治疗思路的基础。

五、结构异常：位置决定症状

33.5 讲了四种结构问题，主线是位置。子宫肌瘤起源于肌层平滑肌细胞，发生依赖雌孕激素与局部生长因子，故育龄期增大、绝经后萎缩；症状取决于位置而非体积——黏膜下肌瘤突向宫腔，即使很小也可造成经量增多与不孕；肌壁间肌瘤增大到一定程度才产生压迫症状；浆膜下肌瘤向外生长，早期常无症状。讲义把这条规律与前列腺增生并列，称之为「位置决定症状」（补充·hermes-病理生理学讲义·第33章·33.5）——同一规律在两章出现，说明它不是某一器官的特性，而是腔道器官的共性：靠近通道的小病灶比远离通道的大病灶更能说话。

五、结构异常：位置决定症状

子宫内膜息肉是内膜局部的过度生长，机制涉及雌激素受体的局部高表达与凋亡减少，表现为不规则出血且有恶变潜能，因此需要病理评估。先天性畸形源于苗勒管的发育、融合或腔化失败：一侧发育不全致单角子宫，融合失败致双角或纵隔子宫，腔化失败致阴道横隔；可无症状，也可致反复流产、早产或经血潴留，机制是宫腔形态与容积异常影响着床与生长。宫腔粘连是基底层损伤后的纤维化修复结果，常见于产后刮宫或反复宫腔操作后，表现为经量减少、闭经与不孕——讲义称之为一次损伤造成终身功能丧失的典型例子，并由此提出一条判断：宫腔操作的指征应当严格。

六、盆底支持与两种漏尿

33.6 先把盆底写成一套悬吊与支撑系统：肛提肌构成主要力量层，耻骨宫颈筋膜与直肠阴道筋膜提供局部支撑，韧带把器官悬吊于骨盆壁。三类结构、三种失效方式，这个三分法决定了后面所有推理。

盆腔器官脱垂的机制是支持组织的力学失败，可归为三类原因：产伤（分娩过程中肌肉、筋膜与神经的牵拉损伤，是最主要的风险因素）；慢性腹压增高（长期咳嗽、便秘、体力负荷、肥胖，持续增加盆底负荷）；组织质量下降（绝经后雌激素低下使胶原含量与弹性下降，筋膜变薄，支撑力减弱）。三类原因可以叠加，也可以单独成立——这就是同一个脱垂在不同人身上原因不同的机制解释。

六、盆底支持与两种漏尿

压力性尿失禁被写成组合机制——「支撑不足 + 括约功能减弱」（补充·hermes-病理生理学讲义·第33章·33.6）：腹压骤增时尿道不能获得足够的支撑性压迫，或括约肌本身闭合能力下降，于是漏尿。其特点是腹压增高时发生，与膀胱过度活动症的尿急时发生机制不同。讲义由此给出一条问诊判据：「漏尿的触发情境」比「漏尿量」更有诊断价值——触发情境是机制层的材料，漏尿量是数据层的材料。护理层面收在预防性干预：盆底肌训练、体重管理、慢性咳嗽与便秘的控制、避免长期负重；这些措施针对机制而非症状，因此在症状出现前即有位置。

七、四类肿瘤：一个共式与四种机制

33.7 先给共式，四类常见肿瘤的机制各异，但都可归纳为「持续刺激 + 修复增殖 + 调控失效」（补充·hermes-病理生理学讲义·第33章·33.7）。共式让四种具体机制有同一个落点，也让慢性刺激与肿瘤相关这件事有了统一说法。

宫颈癌的核心是高危型人乳头瘤病毒的持续感染：病毒基因整合入宿主基因组，编码的蛋白干扰抑癌蛋白功能，使细胞周期失控。讲义特意标出关键的修饰词是持续——多数感染可被免疫清除，只有持续感染才推进至癌前病变乃至浸润癌。这一机制直接决定筛查逻辑：筛查的目标不是发现癌，而是发现癌前病变并阻断其进展，因此间隔与起始时间的设计都围绕持续感染到癌变需要时间这一前提。

七、四类肿瘤：一个共式与四种机制

子宫内膜癌的核心是无孕酮对抗的雌激素暴露：雌激素驱动增殖，孕酮在正常周期中限制增殖并促分化；当孕酮缺失（无排卵、多囊卵巢样改变、雌激素替代而无孕酮对抗、肥胖致外周芳香化增加）时，增殖失去制衡，逐步累积基因损伤。这解释了肥胖、糖尿病、无排卵与内膜癌风险的关联——它们共享雌激素相对过剩这一环节。讲义另点一类发生在萎缩内膜基础上的内膜癌，机制不同、预后也不同，提醒不要把两类混成一类。

卵巢癌以上皮性来源为主，机制涉及排卵导致的表面上皮反复损伤与修复、遗传易感基因的胚系变异、以及输卵管上皮的参与；后一点最值得注意——相当部分高级别浆液性癌被认为起源于输卵管上皮而非卵巢表面，这改变了预防策略的思路。乳腺癌的机制围绕激素暴露与受体状态：长期雌激素暴露提高风险，受体状态决定生物学行为与治疗方向；乳腺并非生殖器官，但其功能与激素轴紧密耦合，放在本单元讨论是合理的。

八、妊娠相关异常：四个断点

33.8 是本章最长的一节，四个病各给一个机制起点。异位妊娠是输卵管运输障碍：炎症后粘连、纤毛损伤、手术后狭窄、先天畸形，都可使受精卵滞留于输卵管；危险在于滋养细胞侵袭输卵管壁血管，一旦破裂造成腹腔内大出血。讲义由此给出一条临床规则：育龄期女性腹痛伴阴道流血必须先排除异位妊娠——规则的根据在机制，不在经验。

流产分三类原因：胚胎因素（染色体异常最常见，属减数分裂或受精过程的错误）、母体因素（子宫畸形、宫腔粘连、内分泌异常、免疫因素、感染）、环境因素（毒物、放射、药物）。讲义给出一条分布规律：早期流产以胚胎染色体异常为主，晚期流产以母体因素为主——这条差异把往哪一侧找定了下来。

八、妊娠相关异常：四个断点

妊娠期高血压疾病的起点在胎盘形成：正常妊娠早期，滋养细胞重塑子宫螺旋动脉，使其成为低阻力、高流量的血管；若重塑不足，胎盘灌注下降，产生氧化应激与抗血管生成因子，进入母体循环后造成全身血管内皮损伤。内皮损伤的表现是全身性的：高血压、蛋白尿、水肿、凝血激活以及肝、脑受累。讲义由此给出判断：该病不是子宫的病，而是「全身内皮疾病」（补充·hermes-病理生理学讲义·第33章·33.8），因此终止妊娠是根本性的处理，因为源头是胎盘。妊娠期糖代谢异常则是生理性胰岛素抵抗叠加胰岛储备不足：妊娠中期起胎盘激素造成抵抗上升，代偿不足者出现糖代谢异常——由此推出筛查时点应设在抵抗最明显的阶段，而非妊娠早期。

九、不孕：双方三要素与顺序

33.9 给评估原则——「双方、三要素」（补充·hermes-病理生理学讲义·第33章·33.9）。三要素是配子（精子与卵子）、通路（输卵管与宫颈）、土壤（子宫内膜与着床）；再加一方，就是四个入口。这个结构的好处是它逼着评估同时看两侧，而不是默认指向一方。

机制类别逐条：排卵障碍（轴功能异常、卵巢储备下降、多囊卵巢样改变、甲状腺与催乳素异常）；输卵管因素（炎症后粘连、手术史、内异症造成的解剖改变——输卵管是配子相遇与胚胎运输的双重通道，任一处受阻都可使受精不能发生或胚胎不能到达宫腔）；子宫因素（黏膜下肌瘤、息肉、粘连、畸形、内膜容受性异常）；男方因素（前一章已展开，占相当比例，且可与女方因素并存）；以及不明原因——讲义对这一格的处理很克制：现有检查未能发现明确机制，但这不等于没有原因，而是超出当前检测能力，处理逻辑是经验性干预与时间管理，而非无限期等待。

九、不孕：双方三要素与顺序

评估顺序的原则是创伤小、成本低、信息量大：病史与周期评估、精液分析（男方优先，因其简便且阳性率高）、排卵确认、输卵管通畅性、宫腔评估。把男方检查放在前面是基于概率与成本的双重考虑——这是本章唯一一处把顺序写成功率论证的地方，也最容易被跳过。

十、围绝经期：波动而非单向下降

33.10 先纠正一个常见读法：围绝经期的本质是卵泡池耗竭的过程，「而非一个突然的事件」（补充·hermes-病理生理学讲义·第33章·33.10）。链条是：卵泡数量减少、抑制素下降、促性腺激素升高、剩余卵泡被过度刺激、周期缩短或不规律、排卵减少、最终卵泡功能停止。

链上最容易被误读的是激素特征——它是波动，而不是单向下降：雌激素可一时升高（残余卵泡受高强度刺激），随后下降，造成潮热、情绪波动与不规则出血。因此不能仅凭单次激素测定判断阶段，需结合月经史与临床表现。这一句把一次化验定性的做法挡在门外。潮热的机制被写成体温调节中枢的窄化：雌激素撤退使下丘脑的体温调节带变窄，核心体温的微小上升即触发散热反应——这同时说明为什么它以上半身突然发热出汗的形式出现，为什么发生在中枢而不是外周。

十、围绝经期：波动而非单向下降

长期后果集中在三处：骨骼（雌激素抑制破骨细胞，撤退后骨吸收加速，骨量流失）、心血管（血脂谱向不利方向改变、内皮功能下降）、泌尿生殖道（上皮萎缩、润滑减少、酸度上升，致干涩、性交痛与感染易感）。讲义对绝经的立场写得最平衡：绝经是生理过程而非疾病——过度医学化的风险是过度干预，完全正常化的风险是忽视可预防的骨与心血管后果；恰当的立场是把它视为一个需要风险管理的生命阶段。阶段可以描述，风险可以分类，个体的判断不在此侧。

十一、护理与判断：五个主题

33.11 收了五个反复出现的主题。第一，把症状翻译成机制：异常出血要问何时、多少、与周期关系，因为不同答案指向不同层次；痛经要问是否随周期、是否影响日常，因为周期性提示激素依赖的病灶；漏尿要问触发情境，因为压力性与急迫性机制不同。第二，识别必须立即评估的信号：育龄期腹痛伴阴道流血、绝经后出血、急性下腹痛伴发热、妊娠期头痛视力改变，四类都属不可等待的情形。

十一、护理与判断：五个主题

第三，尊重信息的敏感性：月经史、性史、生育史与避孕史都是必要信息，但采集方式决定其真实性；使用中性术语、说明用途、提供隐私，「比反复追问更有效」（补充·hermes-病理生理学讲义·第33章·33.11）。第四，把生殖健康放回整体：多囊卵巢样改变需要评估代谢，绝经需要评估骨与心血管，不孕需要评估双方——生殖系统的表现常是全身状态的投影。第五，教育要给出可判断的依据：周期记录的方法、异常出血的识别标准（类别而非数值）、盆底肌训练的原理、绝经后骨健康的维护方向、筛查的意义。五个主题的次序也有意：先翻译、再识别、再采集、再整体、最后教育。
