4 / 39roots
一、定义句里有三个限定，少了哪一个都不成立

教材给炎症下的定义只有一句话，但这句话里有三道闸门：

「炎症是具有血管系统的活体组织对损伤因子所发生的防御性反应」——教材·第5章·5.1.1（《病理学·第5章·5.1》）

拆开来看：具有血管系统的活体组织——无血管的组织（角膜、软骨表层、表皮）不发生这类反应；损伤因子——必须有一个造成损伤的起因；防御性反应——反应的方向是保护，不是破坏。三个限定合起来，炎症就不是「组织坏了」的同义词，而是「有血管的活组织对损伤作出的、方向为保护的一套应答」。

这一句紧接着还有一层，教材自己就点破了：

「炎症的本质是机体在长期进化过程中形成的防御适应反应」——教材·第5章·5.1.1（《病理学·第5章·5.1》）

5 / 39body
一、定义句里有三个限定，少了哪一个都不成立

「进化过程中形成」这六个字，把炎症从「病理现象」挪到了「生理能力」的位置上：它是机体本来就有的一套本领，只是在特定条件下被启动、被放大、被延长。所以本章所有关于「不利影响」的叙述，都不是在否定炎症，而是在说这套本领用过了头或用得不够。教材把这个判断写成了两重性：适度有利，过度或持续则带来进一步的形态改变与功能影响。这句判断贯穿全章，也是本章唯一允许下的价值判断——而且它是对「反应强度」的判断，不是对某个人的判断。

6 / 39body
二、原因：打掉「单一原因」的幻想

5.1.2 把致炎因子按类别铺开：生物性、物理性、化学性、异常免疫反应、组织坏死本身、异物。六类并列，看起来像一份清单，其实每一类都在做同一件事——说明「损伤」可以有完全不同的来路。教材对这个共性的表述很干脆：

「凡能造成组织损伤的因素，在特定条件下均可成为致炎因子」——教材·第5章·5.1.2（《病理学·第5章·5.1》）

「在特定条件下」这五个字是这一节的真正难点。同一类因子作用于不同组织，后果不同；同一个体在不同状态下遇到同一因子，反应也不同。教材在 5.1.2 里把「机体反应性」单列一段，说的就是这件事：遗传背景、营养状态、免疫状态、局部组织结构，四项都能改写结果。于是「找到致炎因子」并不等于「解释了这个炎症」——中间还差一层「这个机体此刻为什么这样反应」。

10 / 39body
三、四节的分布，与局部三变化

三句话各自对应一个方向：变质是组织受损（伤），渗出是血管与血液成分出动（援），增生是细胞数目增多以修（补）。三者不是三个阶段，而是同一时间窗内三种并存的过程，只是配比随经过而变。教材在 5.2.1 与 5.2.3 里都写了这层关系：变质产物可成为新的致炎因子、吸引炎症细胞；渗出物可稀释中和致炎因子，也可压迫组织加重损伤；增生在后期逐渐明显，并可能留下结构改变。

code/main.js 复算了一个有意思的数：本章 12 个单元里，把「变质、渗出、增生」三个词都写到的有 8 个。剩下的 4 个不是漏写，而是各有分工——5.1.1 是概述，三要素在那里只作铺陈后的收束；5.1.3 讲表现，用「血管反应、渗出、组织变化」另一套措辞；5.4.1 与 5.4.2 讲临床表现与结局，直接调用三要素的结论而不重复定义。同一套概念在不同单元里换措辞，是教材的常态；读者要抓的是所指，不是字面。

三、四节的分布，与局部三变化

渗出一节还多给了一层可操作的结构：血管反应（细动脉扩张→血流加快→细静脉扩张→血流减慢→白细胞附壁）→ 通透性升高（内皮收缩、内皮损伤、穿胞增强）→ 液体渗出（渗出液，与漏出液按机制与性状区分）→ 细胞渗出（附壁、游出、趋化）。这条链上每一环都能被指认，所以它是全章最像「机制」的一段。教材在这里明确划了线：渗出液与漏出液只按性状类别归纳，不写比重与蛋白质含量的数值——这是本书口径的直接来源。

细胞渗出那一段还有一个判读用的对应关系，教材写得很实用：中性粒细胞多见于急性渗出性炎，单核细胞与淋巴细胞多见于慢性炎症与病毒感染，嗜酸性粒细胞常见于寄生虫感染与变态反应。这不是「看到某细胞就等于某病」，而是「细胞类别提示反应的侧重」——方向对了才谈得上后面的话。

12 / 39body
四、类型：两套划分，不许混着用

5.3 开头一句话把两套坐标摆在一起：按局部变化分为变质性炎、渗出性炎、增生性炎；按病程分为急性炎症与慢性炎症。教材随后反复提醒这两套坐标的着眼点不同——一套看「三要素谁最突出」，一套看「经过有多长」。学生最常犯的错，是把「变质性炎」和「急性炎症」当成同义或对立：其实前者是配比问题，后者是时程问题，同一个炎症完全可以既是渗出性炎又是慢性炎症（慢性炎症以增生为主、浸润以单核与淋巴为主，但急性发作时又会出现渗出表现）。

三个定义句并列，差别只在「谁最突出」：

「变质性炎是以组织细胞的变性与坏死为主要表现的炎症类别」——教材·第5章·5.3.1（《病理学·第5章·5.3》）

「渗出性炎是以渗出为主要表现的炎症类别」——教材·第5章·5.3.2（《病理学·第5章·5.3》）

「增生性炎是以组织增生为主要表现的炎症类别」——教材·第5章·5.3.3（《病理学·第5章·5.3》）

13 / 39body
四、类型：两套划分，不许混着用

三句话是同一个句式的三次填空，这本身就是教材在暗示：分类的依据是相对突出程度，不是有无。任何炎症都有三样，只是配比不同。所以「这是渗出性炎」这句话完整的意思是「这三样里渗出最突出，其余两样相对轻微」，而不是「这个炎症只有渗出」。

渗出性炎内部还要再分一层：浆液性、纤维素性、化脓性（蜂窝织炎、脓肿、表面化脓与积脓）、出血性、卡他性。这一层的划分依据是渗出物的性状类别，而性状又跟通透性升高的程度与致炎因子的类别相关——链条是通的：因子 → 通透性 → 渗出物性状 → 类型名称。增生性炎内部同样再分一层：非特异性（纤维母细胞、内皮细胞、巨噬细胞增生为主）与特异性（肉芽肿，以上皮样细胞与多核巨细胞为特征）。教材在 5.2.3 就把肉芽肿的形态特点写全了，5.3.3 再把它放到类型体系里——这是同一个概念在两节里的两次落位，读的时候应当并起来看。

五、临床表现与结局：两重性不是套话

5.1.3 与 5.4.1 讲的是同一件事的两种写法：前者在概述里先给框架，后者在临床一节里再展开。五个局部表现的对应关系是本章最实用的一张对照表：

「炎症的局部表现以红、肿、热、痛与功能障碍为主要类别」——教材·第5章·5.1.3（《病理学·第5章·5.1》）

  • 红与热：动脉性充血使血流加快，继之静脉性充血使血流减慢——所以颜色与温度的表现随阶段变，描述时必须标明处在哪个阶段。
  • 肿：通透性升高，液体与细胞成分进入组织间隙；肿胀的程度与组织的疏松程度相关。
  • 痛：局部压力变化 + 介质作用于感觉神经末梢 + 组织损伤，三条来路。
  • 功能障碍：形态改变影响了器官活动，描述时要指明受累的结构与功能环节。

局部与全身的关系，教材写成双向：局部经介质入血引起全身表现，全身状态又反过来调节局部的强度与经过。这一条把「炎症是局部的事」这个直觉推翻了：一个局部脓肿可以让整个人发热、乏力、血象改变，而一个人的营养与免疫状态又会改写局部反应的强度。分析时把两边割裂，就必然得出片面的结论。

五、临床表现与结局：两重性不是套话

修复愈合的路径是肉芽组织填充 → 纤维瘢痕；转为慢性对应「致炎因子持续存在」；蔓延扩散对应「局部防御失守」。四条路的分岔条件，教材都归到同一组变量上：致炎因子的类别、局部组织的特点、机体的反应状态。同一组变量既解释结局，也解释表现，这就是本章的内在一致性。

5.4.3 讲防御作用，四件事：局限并清除致炎因子、消除坏死组织、修复组织缺损、参与免疫反应。然后立刻补上一句：

「炎症的防御作用有其限度」——教材·第5章·5.4.3（《病理学·第5章·5.4》）

限度的两侧都要说：反应过度，组织损伤与功能影响加重；反应不足，致炎因子清不掉。教材还列了炎症不利的一面——渗出物压迫、纤维增生改变结构、某些反应损伤自身组织。到这里，「防御性反应」这句定义才算被读完：它描述的是一种有方向的能力，不是一种必然有益的结果。

5.1.1 炎症的概念

这一节问的是炎症凭什么被当作一个独立的病理过程。答案落在定义的三重限定与一句本质判断这一层：定义把「活体」「有血管系统」「防御方向」捆在一起，说明无血管的组织不会出现这套反应；本质判断把它放回进化的位置，写成一套既有的防御适应本领，目的是局限并清除损伤因子、消除坏死组织、为修复创造条件。由此推出两点：反应适度时有利，过度或持续存在时本身又造成形态改变与功能影响。局部反应被归结为变质、渗出与增生的组合，以血管反应为中心，常伴不同程度的全身反应；分类依据也在此交代，即局部基本变化的相对突出程度与渗出物的性状类别。与本章后三节的关系是总纲与分论。

十二个小节：逐条落位

这一节问的是哪些因素可以点燃炎症，答案落在致炎因子的类别这一层。生物性因子包括病原微生物与寄生虫，通过在组织内繁殖、释放毒性产物或诱发免疫反应造成损伤；物理性因子包括高温、低温、紫外线、放射线与机械性损伤，主要靠直接作用造成破坏；化学性因子分外源性与内源性，前者如强酸强碱与毒物，后者如坏死组织的分解产物与代谢产物的蓄积；此外还有异常免疫反应、组织坏死本身与异物。归类的共同点用一句话收束：凡能造成组织损伤者，在特定条件下均可成为致炎因子。教材同时点出机体反应性与局部全身的相互作用，并在末尾提前提到炎症介质，为讲渗出的那一节留下接口。本节因此是原因层，与讲概念的上一节构成「是什么」与「由什么引起」的先后关系，与讲表现的下节则是原因到结果。

5.1.3 炎症的局部表现与全身反应

20 / 39body
十二个小节：逐条落位

这一节问的是炎症在体表与全身各留下什么可观察的痕迹。答案落在表现类别与形态基础的对应这一层：局部以红、肿、热、痛与功能障碍为主，红与热对应血管扩张与血流状态的改变，由动脉性充血转为静脉性充血；肿对应渗出物在组织间隙的积聚与局部组织的变化；痛对应局部压力变化、炎症介质对感觉神经末梢的作用与组织损伤三条来路；功能障碍对应受累器官的结构改变。全身反应以发热、外周血细胞类别的变化、急性期反应与全身不适为类别。教材强调这些表现彼此关联、不宜孤立看待，并规定不写体温数值与时间频次参数。与前一节的关系是由原因转入表现，与讲临床表现的那一节是同一内容的两次落位。

5.2.1 变质

21 / 39body
十二个小节：逐条落位

这一节问的是炎症局部「伤」的一面长什么样。答案落在变质这一层：变质指局部组织发生的变性与坏死，须把实质细胞与间质分开描述。实质一侧表现为细胞水肿、脂肪变与细胞坏死，胞质内出现异常物质、细胞形态改变与结构崩解，反映代谢与膜结构的损伤；间质一侧表现为胶原纤维肿胀、溶解与断裂，基质液化与性状改变，结构完整性因此受损，且常与实质损伤并存。机制三条：致炎因子的直接作用、局部血液循环障碍导致的缺血缺氧、炎症介质的作用，三者互相加重。教材特别说明变质、渗出与增生之间的相互影响——变质产物本身又成为致炎因子，所以三者是连续过程而非孤立条目。与后两节的关系是损伤与应答相对。

5.2.2 渗出

22 / 39body
十二个小节：逐条落位

这一节问的是血管内的成分怎样到血管外去。答案落在渗出的环节这一层，四段相接：血管反应先使细动脉扩张、血流加快，继而细静脉扩张、血流减慢，细胞成分向血管壁靠拢并附壁；通透性升高由内皮细胞收缩、内皮细胞损伤与穿胞作用增强几种环节引起，结果是富含蛋白质的液体进入组织间隙；液体渗出形成渗出液，与漏出液按形成机制与性状类别相区分；细胞渗出经附壁、游出与趋化完成。白细胞的类别与炎症类别相对应，中性粒细胞多见于急性渗出性炎，单核与淋巴细胞多见于慢性炎症与病毒感染，嗜酸性粒细胞多见于寄生虫感染与变态反应。渗出有两重性：稀释中和致炎因子为利，压迫组织加重形态改变为弊。与前后两节的关系是应答的主体。

5.2.3 增生

23 / 39body
十二个小节：逐条落位

这一节问的是炎症局部「补」的一面如何体现。答案落在增生这一层：增生指实质细胞与间质细胞数目增多的过程，参与者有巨噬细胞、纤维母细胞、血管内皮细胞与上皮细胞，淋巴细胞与浆细胞也常加入。增生的细胞类别、排列方式与所在组织层次是描述的重点，其出现与炎症的类别、经过以及致炎因子的作用环节相关，多见于炎症的后期与慢性炎症，是机体限制损伤范围并修复组织缺损的环节。类别上分非特异性增生与特异性增生，后者以肉芽肿形成为特征，由巨噬细胞及其演变的细胞构成，可见上皮样细胞与多核巨细胞，周围常有淋巴细胞与纤维组织的反应。意义有两条：肉芽组织形成以修复缺损，纤维组织持续增生则改变结构、影响器官功能。与前一节的关系是损伤与修复相对。

5.3.1 变质性炎

24 / 39body
十二个小节：逐条落位

这一节问的是炎症按什么坐标分类、第一型落在哪里。答案落在两套划分依据这一层：按局部基本变化的侧重分为变质性炎、渗出性炎与增生性炎，按病程分为急性炎症与慢性炎症，角度不同、服务不同的分析需要，不可互相替代。变质性炎以实质细胞的变性与坏死为突出表现，渗出与增生相对轻微，多发生于实质器官，间质改变常继发于实质损伤；原因类别以生物性因子的毒性产物与化学毒物为主，损害程度与组织的代谢特点及实质细胞对缺氧和毒性物质的敏感程度相关。教材把变质性炎与急性炎症并置对照，正是为了说明两套坐标的区别——前者依变化侧重，后者依病程。与本章讲另外两型的小节是并列三分。

5.3.2 渗出性炎

25 / 39body
十二个小节：逐条落位

这一节问的是渗出为主时，渗出物的性状又能分出几类。答案落在渗出物的类别这一层：浆液性以液体成分为主、细胞成分相对较少，可在组织间隙、体腔或黏膜表面积聚；纤维素性以纤维素为主要成分，多见于黏膜、浆膜与肺，呈膜状或网状，与周围组织的附着关系是描述要点；化脓性以中性粒细胞渗出伴组织坏死为特征，按范围与部位又可分蜂窝织炎、脓肿、表面化脓与积脓；出血性以渗出物中含红细胞为特点，多与其他类别并存；卡他性指黏膜表面的渗出，可为浆液性、黏液性或脓性。蜂窝织炎在疏松结缔组织内弥漫扩散，脓肿则较为局限并常有肉芽组织构成的壁。与本章前一型的关系是同一坐标的另一格。

5.3.3 增生性炎

26 / 39body
十二个小节：逐条落位

这一节问的是增生为主时，形态上怎样再分。答案落在增生性炎的类别这一层：非特异性增生性炎以纤维母细胞、血管内皮细胞与巨噬细胞的增生为主，常伴淋巴细胞与浆细胞浸润，形态因部位与经过不同而有差别，观察时应按类别归纳；特异性增生性炎以肉芽肿形成为特征，肉芽肿由巨噬细胞及其演变的细胞构成，可见上皮样细胞与多核巨细胞，周围常有淋巴细胞与纤维组织的反应，识别依据是特征性的细胞类别与排列方式。教材把「增生为主加单核淋巴浸润」与「慢性经过」的对应关系写实，并说明慢性炎症的形态包括实质细胞萎缩变性、间质增生与纤维组织增多。与本章前两型的关系是三分中的第三格。

5.4.1 炎症的临床表现

27 / 39body
十二个小节：逐条落位

这一节问的是炎症在临床一侧留下哪些可记录的内容。答案落在表现与形态的对应这一层，是概述里那份表现的展开版：局部五个表现逐条接回形态基础，发红与温度变化接血管扩张与血流状态，肿胀接渗出物的积聚，疼痛接介质的作用与局部压力的变化，功能障碍接受累器官的结构改变。全身反应以发热、外周血细胞类别的变化、急性期反应与全身不适为类别。本节新增的是记录与转介两条流程要求：观察所见、检查过程与判断依据如实记录，重要环节留痕；需进一步处理的情形按规定报告与转介，流程以现行规范与机构制度为准。口径上重申不写体温数值、时间频次与参考值。与前一节的关系是概述到临床。

5.4.2 炎症的结局

28 / 39body
十二个小节：逐条落位

这一节问的是一场炎症可能走到哪几个方向。答案落在结局类别这一层：吸收消散是渗出物被吸收、坏死组织被清除、局部结构逐步恢复；修复愈合是组织缺损由肉芽组织填充、随后形成纤维瘢痕；转为慢性是致炎因子持续存在或机体反应状态改变，形态以增生与单核淋巴浸润为主；蔓延扩散分局部蔓延、淋巴道播散与血道播散三条路，分别沿组织间隙与管道、经淋巴管到局部淋巴结、经血液到远处组织。四条走向归到同一组变量：致炎因子的类别、局部组织的特点与机体的反应状态。教材明确不作预后判定、不作生存期与转归判定，也不作疗效断言。与前一节是表现到走向，与后一节是走向到意义。

5.4.3 炎症的防御作用

29 / 39body
十二个小节：逐条落位

这一节问的是炎症对机体究竟意味着什么。答案落在防御作用与限度这一层：防御作用有四项——血管反应与渗出把致炎因子限制在局部，液体成分稀释毒性物质、细胞成分吞噬清除；坏死组织的分解产物被吞噬与运走，为修复创造条件；纤维母细胞与内皮细胞形成肉芽组织，进而修复组织缺损；抗原的处理与提呈参与免疫反应，局部淋巴结出现相应反应。限度同样要写清：反应过度会加重损伤，反应不足则清不掉因子，平衡取决于机体的反应状态；不利面包括渗出物压迫、纤维增生改变结构、某些反应损伤自身组织。与全章的关系是收口：把前面各节的形态与关系折成一句价值判断。
