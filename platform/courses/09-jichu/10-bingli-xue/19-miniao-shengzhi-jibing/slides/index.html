PROBLEM

「肾小球肾炎是变态反应性疾病」这句话，考试能写，病人听不懂，自己也说不下去。换一个问法——为什么同一个肾小球，有时尿里全是蛋白、有时尿里全是红细胞、有时尿里只剩管型——三问答不出两问，这句话就还是标签。真正要回答的是：病变落在哪一个部位、由哪一类成分构成、沿着哪条管道扩散。本章的全部内容，就是把这三个问题在泌尿与生殖两个系统里各问一遍。

一、第一句话不是病名，是一条结构描述

教材开篇没有从「肾炎」讲起，而是先交代管道：

「泌尿系统由肾脏与输尿管与膀胱与尿道组成」——教材·第19章·19.1.1

这句话看着像解剖复习，其实是本章的坐标系。它把后面所有病变都放进一条有方向的管道里：肾在内、尿道在外，任何炎症都可以问一句「它从哪一端开始、往哪一端走」。本章真正难的地方不在记病名，而在把病变钉回这条管道上的某一段。

紧接在这句之后，教材给出的不是定义，而是一条对应关系：肾单位是本章唯一被写全的「结构—功能」配对——肾小体负责滤过，肾小管负责重吸收与分泌。于是本章出现了一个反复使用的推理句式——肾小球坏了，尿里出现的是「不该漏的」；肾小管坏了，尿里出现的是「不该留的」。前者是蛋白与红细胞，后者是管型。教材在 19.1.2 里把这条对应关系写成了三行，本章把它当成读尿常规形态的第一把尺子（只读形态类别，不读数值）。

三、肾小球肾炎与肾盂肾炎：类型的聚类与途径决定的分布

19.1.1 先把「为什么是免疫」讲清：免疫复合物沉在哪里（内皮细胞下、基底膜内、上皮细胞下、系膜区），形态就长成什么样；形态长成什么样，类型就被命名成什么。教材把这条对应关系写成一句判断——沉积部位与形态改变之间存在对应关系——并且从不说哪个类型「更重」。因果链是「部位 → 形态 → 名称」，不是「名称 → 病情」。

到了 19.1.3，七种类型被逐一摊开，其中膜性那一段最能说明「形态命名」的分寸：

「膜性类型以基底膜弥漫性增厚为特点，上皮侧可见沉积物，钉状突起是该类的特征性形态」——教材·第19章·19.1.3

「钉状突起」四个字是本章少见的、带画面感的术语。它的价值在于可核对：说「基底膜增厚」是笼统的，说「上皮侧有钉状突起」就把观察位置与观察手段一起钉住了。本章要求学生在描述时做到这一点——术语必须能指认到位置。

三、肾小球肾炎与肾盂肾炎：类型的聚类与途径决定的分布

这一句之后，教材立刻给出对应关系：上行性感染者病变分布不均匀，肾盂与肾盏黏膜以及肾实质的炎症明显；血源性感染者病变多呈双侧弥漫分布，皮质小脓肿突出。途径是自变量，分布是因变量——这是本章唯一一处把「病因 → 分布」写成函数关系的地方。

肉眼形态那一段写得很具体：

「急性肾盂肾炎的肾脏外观可见充血与水肿，表面与切面可见散在的黄色化脓病灶」——教材·第19章·19.2.2

「散在」与「黄色化脓」两个词合起来就是上行性感染的签名：病灶之间还留着相对完整的肾组织。到了慢性阶段，同一句话变成「表面可见瘢痕凹陷呈不规则分布」——同一个器官，两种分布，两种经过。

19.2.3 把两种肾炎的差别压成一句最省力的判断：肾盂肾炎由黏膜向间质延伸，肾小球肾炎由肾小球向肾小管与间质延伸，两者的扩展方向相反。 记住方向，比记住两串病名有用得多。

四、肾功能衰竭：从一段小管到一个系统

19.3.1 的形态落点极窄：

「肾小管上皮坏死多累及近曲小管的直部与髓袢升支的粗段等对缺血较为敏感的部位」——教材·第19章·19.3.1

「对缺血较为敏感」是本节所有推理的前提。急性肾衰的形态学故事只有三段：上皮变性 → 上皮坏死与管型阻塞 → 上皮再生与管腔重建。教材把这三段写成「起始、维持、恢复」，并明确说上皮再生是形态上的重要变化——这是本章唯一一处以「修复」为主角的叙述。

慢性那一节换了主角。教材把慢性肾功能衰竭写成「各种肾脏疾病发展的后期阶段」，核心是肾单位进行性丧失与肾功能持续减退；「各种」两个字很关键——慢性肾衰是共同归宿，不是一种独立的病。所以它的形态特征是「趋同」：不管原来是什么病，最后都长成一颗缩小、变硬、表面细颗粒状的肾。教材用「类别不同而形态趋同」八个字概括这件事，本章把它当作全章的收束句之一。

四、肾功能衰竭：从一段小管到一个系统

尿毒症则是把局部推到全身：教材把它定义为急性与慢性肾功能衰竭发展到严重阶段时出现的全身性病理过程。至此，本章的推理链闭合了：一个肾小球的沉积 → 一段小管的坏死 → 一颗肾的硬化 → 全身多系统的纤维素性炎。四级台阶，每一级都有形态证据。

五、生殖系统：两个「热点」与一条中性表述的底线

19.4 的第一句就是定位：

「子宫颈由黏膜与纤维肌组织构成，其黏膜上皮在宫颈外口附近由鳞状上皮移行为柱状上皮，移行部位称为鳞柱交界」——教材·第19章·19.4.1

鳞柱交界是本章第二个「热点」，与前列腺的移行区配对出现：一个在宫颈外口，一个在前列腺的移行区。教材把这两处写成病变的常见起始部位，理由都是同一个——两种上皮或两种组织在这里相接，结构关系最复杂。这是形态学里最朴素也最可靠的一条经验：交界处先坏。

19.4 还有一条容易被忽略的写作纪律。全节反复出现「保持中性」「不作污名化与标签化表述」「不作道德评判」——这不是套话，是本章对生殖系统病变的硬约束。教材把「疾病的发生与不同因素相关，不作归因与评价」写进正文，本章照录其立场：形态描述只以病变为对象，不指向具体个体。

19.1.1 肾小球组织结构与病因机制

本节问的是肾小球的病变从哪一层结构开始，以及免疫机制如何落到这一层上。答案落在结构与机制的交界。滤过屏障可分内皮细胞、基底膜与脏层上皮三层，任何一层的改变都会改变滤过的选择性。病因机制以免疫为主，途径有两条：循环免疫复合物在肾小球内沉积，或抗体先与肾小球固有成分结合、再形成原位免疫复合物。要害是沉积位置决定病变表现：沉积在基底膜的不同侧，引起的细胞反应与形态改变不同，随之出现的滤过改变类别也不同。这一条是后面分型的机制前提。与下一节的关系是机制与形态，与类型一节的关系是本节给位置这一维度。位置这一维度因此同时是机制条件与形态条件，两项在此重合。不写蛋白定量数值。

19.1.2 病理变化与临床表现

本节问的是肾小球的病变在镜下以哪几类改变表现，以及这些形态改变如何对应到滤过功能的改变。答案落在形态与功能的对应这一层。病变以肾小球为核心，也可累及肾小管、间质与血管：光镜下可见细胞成分增多，包括内皮与系膜细胞增生以及中性粒细胞与单核细胞浸润；也可见基底膜增厚、系膜基质增多与毛细血管腔受压变窄。要害是把形态接到表现上：滤过屏障受损则出现蛋白与红细胞的漏出，滤过面积减少则滤过功能下降，形态与滤过改变是同一件事的两面。与上一节的关系是结构与形态，与类型一节的关系是本节给改变类别、下节按组合归类。把形态与滤过改变并置，才使这一节的描述不止于镜下所见。不写定量与分级。

19.1.3 常见病理学类型

20 / 40body
十二个小节：逐条落位

本节问的是形态相似的肾小球病变凭什么被分成不同类型，分类要用几个维度。答案落在分类这一层。类型依据三个维度划分：病变累及的范围，即弥漫或局灶；细胞增生的成分，即内皮、系膜或上皮；沉积物的部位，即基底膜内、上皮下或内皮下。类型划分的意义在于把形态相似的病变归为一类，便于认识与交流，而不是给出个体判断。要害是三个维度要同时报：只说增生性而不说成分与部位，等于没有分类，因为同样的增生落在不同成分上，功能后果不同。维度齐备之后，类型名称才具备可交流的含义。与前面两节的关系是本节把结构、机制与形态收束为可命名的类别，与肾盂肾炎一节的关系是本类以肾小球为主、后者以间质与肾小管为主。

19.2.1 病因、感染途径与发病机制

21 / 40body
十二个小节：逐条落位

本节问的是一种以间质与肾小管为主的化脓性炎症，病原从哪条路径到达肾，以及这条路径如何决定病变的分布。答案落在病因与途径这一层。肾盂肾炎是病原微生物引起的肾盂与肾实质的炎症性病变，以间质与肾小管的化脓性炎症为主要特点，肾小球受累相对轻微。感染途径以逆行即上行途径为主，另有血行途径。发生与尿路解剖、排尿功能与机体防御状态相关。要害是上行这条路径解释了病变为何呈不规则的灶性分布：病原沿管道逐段推进，累及的范围随推进路径而定，而不是经血流均匀播散。与上一节的关系是落点由肾小球转为间质，与类型一节的关系是本节讲入口、下节讲形态分类。不写菌落计数。

19.2.2 类型

22 / 40body
十二个小节：逐条落位

本节问的是同一疾病为何要分两类，分类依据是经过还是形态。答案落在形态与经过这一层。急性者以化脓性炎症为特点：肾盂黏膜充血、脓性渗出，间质中性粒细胞浸润并形成微脓肿；慢性者以纤维化与瘢痕形成为特点：间质纤维增生、表面瘢痕凹陷、肾盏变形。类别划分以形态与经过为依据，不涉及分级与分期数值。要害是两类的形态方向不同：一类以渗出与破坏为主，结构上有恢复的基础；另一类以纤维与变形为主，结构已发生改建，形态上的痕迹长期保留。这一差别决定了描述时该看渗出还是该看纤维。与上一节的关系是途径与结果，与肾功能衰竭一节的关系是慢性类的结构改建为其病因之一。

19.2.3 肾盂肾炎的类别联系

十二个小节：逐条落位

本节问的是这一疾病应当从哪几个方向与本章其他内容建立联系，才不至于把它当成孤立的一条。答案落在关系这一层。联系可从几个角度展开：部位上，肾盂、肾盏、间质与肾小管相继受累，呈由管道向间质推进的次序；病因上，病原类别与尿路结构与功能状态以及机体防御相互作用；经过上，急性与慢性之间存在演变关系，形态由渗出转向纤维；全身方面，与全身感染状态相联系。要害是相继受累这条线索：它说明扩散是顺着管道与间质推进的，因此早期形态局限、后期才弥散。四条线合起来，构成本病在章节中的位置而不是孤立的一条。与前后各节的关系是由此把部位、病因、经过与全身几条线接起来，为下一节的功能后果铺垫。

19.3.1 急性肾功能衰竭

24 / 40body
十二个小节：逐条落位

本节问的是肾功能在短时间内严重下降时，形态上最常见的落点在哪里，以及凭什么说某些改变有恢复的结构基础。答案落在形态与机制这一层。急性肾功能衰竭指各种病因引起肾功能严重障碍的过程，表现为代谢终产物蓄积以及水、电解质与酸碱平衡的紊乱。常见的形态基础是肾小管上皮的损伤：上皮细胞变性坏死、管腔内有管型形成。要害是基底膜是否完整：基底膜完整则上皮有沿骨架再生的条件，基底膜破坏则结构失去依附，两类改变的形态方向不同。这一条是判别可逆与不可逆的形态依据，也是本节与慢性节的分界。与上一节的关系是由间质炎症转入肾单位损伤，与下一节的关系是急性与慢性的经过对照。

19.3.2 慢性肾功能衰竭

25 / 40body
十二个小节：逐条落位

本节问的是肾功能为何在长期中持续减退而不是损伤后停在一个固定水平。答案落在形态与代偿的关系这一层。慢性肾功能衰竭是各种肾脏疾病发展的后期阶段，表现为肾单位的进行性丧失与肾功能的持续减退。形态基础是肾实质的广泛破坏与纤维化：肾体积缩小、表面呈颗粒状、皮质变薄、间质纤维增生。要害是代偿与累积的关系：残存肾单位承担更多滤过，长期代偿本身加速硬化，于是丧失继续推进。这一机制解释了病程的渐进性，也解释了形态上为何以纤维与萎缩为主。与上一节的关系是急性与慢性的经过对照，与尿毒症一节的关系是本节所述广泛破坏为全身性改变提供基础。渐进性因此不是时间描述，而是形态累积的结果。不写滤过数值。

19.3.3 尿毒症

26 / 40body
十二个小节：逐条落位

本节问的是肾功能严重下降之后，为何表现是一组分散于多系统的改变，而不是单一症状。答案落在物质蓄积与系统表现的关系这一层。尿毒症是急、慢性肾功能衰竭发展到严重阶段出现的全身性病理过程，与代谢产物在体内蓄积有关。参与致病的物质可按类别归纳：尿素类、胍类、胺类、中分子物质与激素类物质；各类物质蓄积的方向不同，作用的主要靶器官也不同，因而引起多器官多系统的病变。要害是把物质类别与系统表现对上：不同类别对应不同的受累侧重，理解这一点才不会把尿毒症的表现当成一串互不相关的现象。与上一节的关系是基础与后果，与本章开头的关系是由局部病变回到全身。

19.4.1 慢性子宫颈炎及子宫颈癌

27 / 40body
十二个小节：逐条落位

本节问的是同一部位从炎症到癌的形态序列如何排列，中间那一层为何重要。答案落在形态与层次这一层。慢性子宫颈炎以宫颈黏膜的慢性炎症为特点：柱状上皮增生并向宫颈阴道部延伸，形成糜烂样改变的形态基础；腺体囊性扩张形成纳氏囊肿；间质有炎细胞浸润。子宫颈癌起于宫颈上皮，形态可分鳞状细胞癌与腺癌，发展经过为上皮内病变到浸润癌。要害是上皮内病变这一层：它把可逆改变与浸润癌分开，是判断病变位于哪一层、是否突破基底膜的形态依据。与上一节的关系是由肾转入生殖器官，与下一节的关系是同类层次划分在子宫内膜上的再现。层次判读是本节与炎症节之间的连接点，也是形态序列的中段。不写分级数值。

19.4.2 子宫内膜增生症及子宫内膜癌与乳腺病变

28 / 40body
十二个小节：逐条落位

本节问的是子宫内膜的增生性改变凭什么被判为增生症，判据是一项还是两项。答案落在形态与比例这一层。子宫内膜增生症是腺体与间质比例关系改变的病变，与激素类物质作用失衡有关：腺体密集、腺腔形态改变、间质相对减少，腺上皮层次增多并出现排列紊乱。子宫内膜癌起于内膜腺上皮，形态上以腺体结构的异型与间质浸润为特点。乳腺常见病变包括炎症性、增生性与肿瘤性类别，各自的形态落点不同。要害是增生症的判据是腺体与间质的比例加上腺上皮的排列，两项合看而不看单项：只看腺体多会误判，只看排列会漏掉比例。与上一节的关系是同一判据思路的移用。比例与排列两项，构成了这一组病变判读的共同尺度。不写分级数值。

19.4.3 前列腺增生症及前列腺癌

十二个小节：逐条落位

本节问的是同一器官上两种增生性病变凭什么分开，以及这一判断落在哪一层。答案落在部位与形态这一层。前列腺增生症是腺体与间质的增生性病变，多起始于移行区，形成结节状增生，腺体与间质的比例因情形而异；增生的组织压迫尿道，引起排尿过程的改变。前列腺癌多起于外周区，与增生症的起始部位不同，形态上以腺体结构的异型与浸润为特点。要害是起始部位的差别很有用：增生在内、癌在外，位置不同则早期的形态所见与取材所得都不同，判读时先定部位再谈性质。与上一节的关系是同类部位与形态的双重判据，与本章开头的关系是由炎症与增生回到肿瘤类别。不写分级数值。
