一、本章其实只讲三层结构

消化系统的形态学比呼吸系统多一层，但也就三层：

  • 黏膜层（胃与肠）：上皮、固有层、黏膜肌层。胃炎与糜烂、溃疡都在这一层里分深浅。
  • 胃壁与肠壁全层：黏膜、黏膜下层、肌层、浆膜。溃疡穿透黏膜肌层，肿瘤向深层浸润，讲的都是这一层。
  • 肝小叶：肝细胞索、肝窦、门管区、中央静脉。肝炎、肝硬化、肝功能衰竭，讲的都是这一层的改建。

三层结构的用处是定深度。同样是「缺损」，缺损停在黏膜层叫糜烂，穿透黏膜肌层叫溃疡；同样是「纤维化」，沿肝窦延伸与沿坏死区延伸，长出来的结节形态不一样；同样是「炎症」，停在黏膜浅层叫浅表，累及腺体叫萎缩。教材开篇就把这个道理写在定位句里：胃炎是胃黏膜以炎症性病变为主要表现的一类疾病。

「胃黏膜」三个字就是深度限定。记住这个限定，后面「浅表与萎缩」的区分才有落脚点。

二、四节的排法，与三个词频数字

值得注意的不是形态又一次占绝对多数（这本教材的常态），而是细胞层的比例明显高于第 16、17 章（本章细胞层占四层级的近五分之一）。原因很直接：病毒性肝炎那一节的基本病变几乎全部落在细胞上——胞质疏松、气球样变、嗜酸性小体、溶解性坏死、点状与碎片状与桥接状坏死。这些术语没有一个是器官层的，所以本章的形态描述必须能在细胞层站住。

另一条信息是病因：62 次，比第 17 章高，但仍不到形态的十分之一。教材提到幽门螺杆菌、病毒、胆汁反流、药物、代谢异常，都只作类别，不展开成流行病学推演。类别是分类用的，不是解释用的——这条在第 16 章已经说过，本章同样适用。

三、浅表与萎缩、消化性溃疡：同一层里的两种改变与四层底

18.1.1 与 18.1.2 是一对，差别只有一条：腺体在不在。

  • 浅表性：病变在黏膜浅层，小凹与固有层有炎性细胞浸润（淋巴细胞与浆细胞为主，可有中性粒细胞散在），腺体结构相对完整，一般不向深层扩展。
  • 萎缩性：固有腺体减少、腺体变小、腺腔不规则、固有层结缔组织增生，黏膜变薄、小凹缩短或变形，可伴肠上皮化生与淋巴滤泡样聚集。

萎缩性那一段的定义句把「腺体」直接写进特征里：

「慢性萎缩性胃炎是以胃黏膜固有腺体萎缩与减少为主要特征的慢性炎症性病变」——教材·第18章·18.1.2（《病理学·第18章·18.1》）

教材还专门处理了「名字」这件事：浅表性胃炎的名称「取其病变范围表浅之意」，与病变深达腺体的萎缩性改变相对而言，名称反映形态特点，不直接表明病程长短。这句话是防误读的：浅表不等于早期，萎缩不等于晚期，二者是形态类别，不是时间序列。

三、浅表与萎缩、消化性溃疡：同一层里的两种改变与四层底

肠上皮化生那一段也值得单独记：胃黏膜上皮被含杯状细胞的肠型上皮替代，属于适应性改变，「其本身不等同于炎症」，也「并非恶性病变」。学生最容易在这里越界，把化生直接读成癌前；教材的写法是只描述形态转化，不作性质判定。

18.1.3 的定义句把深度写在最前面：

「消化性溃疡是指胃或十二指肠黏膜在胃酸与胃蛋白酶的作用下形成的慢性溃疡性病变」——教材·第18章·18.1.3（《病理学·第18章·18.1》）

紧接着的一句更重要：缺损「可穿透黏膜肌层，达到黏膜下层乃至更深部位」。这就是与糜烂的分水岭，也是「愈合后留不留瘢痕」的结构原因——糜烂限于黏膜层，愈合一般不留瘢痕；溃疡穿透黏膜肌层，愈合常留瘢痕，瘢痕收缩还能改变周围黏膜形态甚至引起管腔变形。

三、浅表与萎缩、消化性溃疡：同一层里的两种改变与四层底

溃疡底部由内向外四层：渗出物 → 坏死组织 → 肉芽组织 → 瘢痕组织。这四层不是四种病，是一个病变的四个深度；code/main.js 现算的结果是：12 个单元里只有 18.1.3 把这四层写全。换句话说，教材把「分层」这件事一次讲透，其余小节只引用。

四层还可以按阶段读：活动期以渗出与坏死为主（上面两层活跃），愈合期以肉芽与瘢痕为主（下面两层活跃）。同一张切片上四层同时存在，是「动态过程被冻结在一瞬间」的结果——这句话是理解溃疡的关键，也是考试里「为什么底部是分层结构」的标准答法。

并发症也按形态分类：侵蚀血管→出血；穿透管壁→穿孔；瘢痕收缩→梗阻；长期存在→上皮恶变。四类的形态基础各不相同，不能一句「并发症」带过。

四、病毒性肝炎与肝硬化：五件基本病变，一个关键词

18.2.1 讲病因与机制，核心是一句话：损伤有两条路——病毒在肝细胞内复制引起的直接损伤，与机体针对病毒抗原的免疫反应引起的间接损伤。教材进一步给出一个可用的推论：免疫反应充分时肝细胞损伤明显、病变较重；免疫反应较弱时病毒长期存在、病变趋于慢性。这条推论把「机制」与「类型」接上了。

四、病毒性肝炎与肝硬化：五件基本病变，一个关键词
  1. 变性：胞质疏松、水分增加、细胞肿胀（气球样变）；胞质浓缩、核浓缩形成嗜酸性小体。
  2. 坏死：溶解性坏死（细胞结构消失、形成坏死灶）与单个细胞坏死；按分布有点状、碎片状、桥接状三种名称——这三个词描述的是空间分布，不是严重程度分级。
  3. 炎性细胞浸润：淋巴细胞与单核细胞为主，分布于坏死区与门管区，程度反映活动性。
  4. 再生：坏死的肝细胞由周围肝细胞分裂补充，损伤轻时再生充分。
  5. 纤维化：炎症与坏死刺激下纤维组织增生，沿肝窦与门管区延伸，是向肝硬化发展的基础。

五件的关系统一是「损伤与修复同时进行」：变性坏死与炎性浸润是损伤侧，再生与纤维化是修复侧；修复侧占优势时结构恢复，纤维化占优势时结构改建。code/main.js 核过：五件同时写全的也只有 18.2.2 一个单元。

四、病毒性肝炎与肝硬化：五件基本病变，一个关键词

18.2.3 讲类型，四类：急性（变性坏死为主、散在分布、纤维化不明显；按黄疸有无再分，形态上无本质差别）、慢性（损伤反复、炎性浸润持续、纤维化累积）、重型（大片坏死、肝细胞索解离、网状支架塌陷；亚重型坏死区与再生结节并存）、淤胆型（肝细胞与毛细胞管内胆汁淤积，门管区炎性浸润，坏死相对轻）。教材强调类型之间可以相互转化，是一个连续过程而不是四个孤立的盒子。

18.3.1 的定义句：

「门脉性肝硬化是以肝组织弥漫性纤维化与假小叶形成为特征的慢性肝脏病变」——教材·第18章·18.3.1（《病理学·第18章·18.3》）

假小叶是什么？肝细胞反复坏死后，纤维组织增生并分割肝实质，把肝细胞团包裹成结节；结节内肝细胞排列紊乱、缺乏正常肝小叶结构，故称假小叶。定义里两个词都不能省：弥漫性纤维化说明范围，假小叶说明结构改建的性质。

四、病毒性肝炎与肝硬化：五件基本病变，一个关键词

形态上有一条时间线：早期肝可因脂肪变性而肿大；纤维化进展后质地变硬、体积缩小、表面呈弥漫细小结节；结节较均一，间隔宽窄大致一致。这条线与「坏死后性肝硬化」正好对照——后者结节不均、间隔较宽。

功能后果一侧，教材只给一条因果链：纤维组织压迫肝内血管 → 血液回流受阻 → 门静脉压力改变 → 脾大、腹水、侧支循环建立。三样后果都有形态基础：脾被膜增厚与脾内纤维增生、腹水来自门脉高压与血浆胶体渗透压下降的组合、侧支循环是血管改建（食管与胃底静脉扩张）。

code/main.js 核过：「假小叶 + 纤维间隔 + 门脉高压」三者同时出现的单元只有 18.3.1。这三个词就是本章肝部分的全部骨架。

五、其他类型肝硬化与消化道肿瘤：看纤维化从哪里起步
  • 部位与上皮来源：食管以鳞状上皮为衬，癌变多与鳞状上皮相关；胃与大肠起于黏膜上皮；肝癌起于肝细胞或肝内胆管上皮。
  • 生长方式：食管癌可呈蕈伞状向腔内突出，也可沿管壁浸润使管腔狭窄；胃癌早期可平坦、隆起或凹陷，进展期可息肉状、溃疡状或弥漫浸润（弥漫浸润使胃壁增厚变硬）；大肠癌可隆起、溃疡或浸润，可伴黏液分泌；肝癌分巨块型、结节型、弥漫型。
  • 扩散途径：淋巴道、血道、种植。不同部位的主要途径不同，教材只作类别说明，不给分期。

教材还给了形态与器官结构的对应：

「食管癌以食管黏膜上皮的恶性增生为特点」——教材·第18章·18.3.3（《病理学·第18章·18.3》）

这句看似平淡，实际是方法论：先看这个器官被什么上皮覆盖、管腔是什么形状，再推肿瘤会长成什么样、往哪里扩散。管腔器官的肿瘤容易造成狭窄，实质器官的肿瘤容易形成肿块——这条规律比背四个病名有用。

六、肝功能衰竭：从肝小叶走到全身

18.4.1 给分类与病因：

「肝功能衰竭的核心在于肝脏功能的严重障碍」——教材·第18章·18.4.1（《病理学·第18章·18.4》）

分类按病程与病变基础：急性（大片坏死）、慢性（纤维化与结构改建）、慢性基础上的急性加重（两者兼具）。病因按类别：病毒、药物性、毒性物质、循环障碍、代谢异常。教材特别声明「病因与病变的关系并非单一对应」——同一病因可引起不同病变，不同病因也可引起相似病变。

18.4.2 讲对机体的影响，按系统摊开：物质代谢紊乱、黄疸（胆红素处理能力下降）、凝血功能改变（凝血因子合成减少）、感染风险（肠源性物质进入体循环、防御减弱）、肾功能改变（以功能性为主）、循环改变、神经系统改变（物质蓄积影响中枢）、内分泌改变、消化道黏膜充血水肿。这一节的写法仍是「一个基本环节，对一组表现」。

18.1.1 慢性浅表性胃炎

本节问的是胃黏膜的慢性炎症在最轻的一端是什么形态，以及浅这个字说明了什么。答案落在形态与层次这一层。病变限于黏膜的浅层，表现为上皮的变性、间质的炎细胞浸润与黏液分泌的改变，腺体结构基本保留。要害是浅既指深度也指后果：腺体不动，分泌功能受损有限，结构骨架尚在，因而这一类的形态改变以可逆方向为主。与下一节的关系是层次上的递进：炎症向深层推进、累及固有腺体，就进入萎缩性类别。这一对照说明胃炎的分类不是按症状而按累及层次。与消化性溃疡一节的关系是本节讲黏膜的炎症，后者讲黏膜缺损的深度。层次是本节唯一的分类轴，也是最稳的一条。表述只写层次与形态类别，不写程度分级与检出数值。

18.1.2 慢性萎缩性胃炎

21 / 42body
十二个小节：逐条落位

本节问的是炎症累及腺体之后，形态上出现什么不可逆的改变，以及这些改变带来哪些后果方向。答案落在形态这一层。特征为胃黏膜固有腺体的萎缩与减少：腺体数目减少、黏膜变薄，常伴肠上皮化生，即上皮的形态向另一类上皮转变。与浅表性相比，差别不在炎症的强弱而在累及的结构层次：前者腺体保留，后者腺体减少。后果有两个方向：分泌功能下降，以及化生上皮成为病变易发处的结构基础。要害是腺体减少在形态上属结构丧失，与单纯炎症的层次不同，这是两类分开的依据。与上一节的关系是层次递进，与消化性溃疡一节的关系是本节的黏膜状态改变为其背景条件之一。两类胃炎的分野因此落在结构是否保存，而不落在炎症的强弱。不写分级数值。

18.1.3 消化性溃疡

22 / 42body
十二个小节：逐条落位

本节问的是黏膜的缺损深到什么程度才称为溃疡，以及它的断面由哪几层构成。答案落在形态这一层。病变为胃或十二指肠黏膜在胃酸与胃蛋白酶作用下形成的慢性缺损，可穿透黏膜肌层、达黏膜下层乃至更深。断面可分渗出层、坏死层、肉芽组织层与瘢痕层，由内向外依次排列。要害是与糜烂的对照：糜烂不穿透黏膜肌层，溃疡穿透，这条深度差别是本节最实用的判据，也是出血与穿孔等并发症的形态基础，因为深度的不同决定了缺损能触及哪一类血管与哪一层管壁。与前面两节的关系是由黏膜炎症转入黏膜缺损，与肝硬化一节的关系是本节属局部病变而后者属弥漫性改建。断面各层的排列顺序，本身即说明病变处于慢性经过之中。不写大小数值。

18.2.1 病因及发病机制

23 / 42body
十二个小节：逐条落位

本节问的是肝细胞的损伤由病毒直接造成还是由机体反应造成，以及这一区分为何重要。答案落在病因与机制这一层。病毒性肝炎由多种嗜肝病毒引起，以肝细胞损伤为主要表现，属弥漫性肝损伤的范畴。要害是把病毒因素与免疫反应分开：病毒提供靶点并在细胞内复制，免疫反应针对带靶点的细胞造成损伤，因此损伤程度与病毒量的多少并不总成正比。这一区分解释了同一型别在不同情形下表现不同的原因，也为后面基本病变与临床类型的划分提供机制前提。与下一节的关系是机制与形态，与肝硬化一节的关系是本节所述反复损伤为纤维化的起点。机制上的这一分工，也决定了形态描述要区分细胞损伤与炎细胞浸润。不写病毒载量与酶学数值。

18.2.2 基本病变

24 / 42body
十二个小节：逐条落位

本节问的是肝细胞受损时，切片上可以看到哪几类改变，它们之间是什么关系。答案落在形态这一层。改变以肝细胞的变性、坏死为主，伴炎细胞浸润与肝细胞再生。变性可分胞质疏松与气球样变等类别；坏死按范围可分点状、碎片状与桥接、大块状等类别，范围的差别对应损伤的分布方式；再生表现为肝细胞体积增大与核分裂增多。要害是变性、坏死与再生三种改变同时存在，读片时须分别描述，不能只报最显眼的那一种，否则分布与范围的信息就丢了。与上一节的关系是机制与形态，与下一节的关系是本节给共同单位、下节按单位组合归入类型。三类改变的空间关系，比各自的轻重更能说明损伤的分布。表述不写分级数值。

18.2.3 临床病理类型

25 / 42body
十二个小节：逐条落位

本节问的是一组形态相似的肝炎，凭什么被分成不同类型，分类依据是形态还是时间。答案落在分类这一层。按病变的性质与分布、经过的长短以及机体反应状态归纳类别，主要分急性与慢性，慢性再按程度与活动性分层。差别体现在肝细胞损伤的程度、坏死分布的方式与纤维化的有无。要害是分类依据是形态而不是时间标签：同样被称为慢性，坏死分布与纤维化程度不同，归入的类别也不同；反之，经过相近而形态不同，也不应合并。这一条把分类从命名问题变成了形态判读问题。分类因此是一个形态判断问题，而不是按病程贴标签。与上一节的关系是单位与组合，与肝硬化一节的关系是纤维化累积到结构改建即为下一节的起点。

18.3.1 门脉性肝硬化

26 / 42body
十二个小节：逐条落位

本节问的是一种以结构改建为特征的慢性肝病，其核心形态单位是什么，以及它为何能解释门静脉高压。答案落在形态这一层。病变以肝组织弥漫性纤维化与假小叶形成为特征，是多种慢性肝病的共同结局。正常肝小叶被假小叶取代，肝内血管的走行随之改变，血流阻力增加，形成门静脉高压的结构原因。要害是假小叶这个核心：它不是正常小叶的变形，而是纤维分隔包围再生结节之后形成的新结构单位，其内部结构与血管关系都已重排。这一认识把形态改变与功能后果连成一条线。与上一节的关系是纤维化在此完成结构改建，与下一节的关系是本节讲共同结局、下节讲不同类型的差别。不写结节大小数值。

18.3.2 其他类型肝硬化

27 / 42body
十二个小节：逐条落位

本节问的是同为肝硬化，不同类型的差别应当从哪里看。答案落在形态链条这一层。除门脉性之外，还有坏死后性、胆汁性、淤血性等类别。理解差别要看三件事：纤维化的起点、分布与结节形态；起点不同则分布不同，分布不同则结节形态不同，三者构成一条可推演的链条。要害是分类依据是形态学链条而不是病因名单：先说纤维从哪起，再说结节什么样，类别自然确定。此外还要交代纤维化的程度类别，因为程度决定结构改建的范围，也就决定门静脉高压能否仅凭形态说明。与上一节的关系是共同结局与类型差异的对照，与下一节的关系是本节的分类方法同样适用于肿瘤的形态归类。掌握了这条链条，遇到新的类型也能按起点与分布推断其形态。不写程度数值。

18.3.3 食管癌与胃癌与大肠癌与原发性肝癌

本节问的是消化系统几个部位的恶性肿瘤，形态类别与扩散途径如何分别表述而不互相串。答案落在形态与扩散这一层。各部位的形态类别不同：食管癌按形态可分髓质型、蕈伞型、溃疡型与缩窄型；胃癌可分息肉型、溃疡型与浸润型；大肠癌多呈环状或隆起状生长；肝癌多为结节型或巨块型。扩散途径也各有偏重，淋巴道、血道、种植与直接蔓延的次序与部位相关。要害是把形态类别与扩散途径两栏分开记：混在一起就会串，尤其溃疡型这一名称在多个部位出现，含义随部位而异。部位、形态与扩散三项依次写完，一节的描述才算完整。与前面两节的关系是由弥漫性改建转入局部增生性病变，观察口径仍按部位、分布、性质依次进行。

18.4.1 肝功能衰竭的分类及病因

29 / 42body
十二个小节：逐条落位

本节问的是肝功能在什么意义上称为衰竭，以及分类要同时回答哪几个问题。答案落在分类与病因这一层。肝功能衰竭指肝脏功能发生严重障碍的一类状态，表现为合成、代谢与解毒功能的明显改变。分类按经过可分急性与慢性，慢性者多以肝硬化为形态基础。病因按类别可分感染性、毒物与药物性、缺血性与代谢性等。要害是分类要同时回答两个问题：损的是哪一层功能，以及损得多快；前者决定表现落在合成、代谢还是解毒，后者决定形态上以细胞损伤为主还是以结构改建为主。与前面各节的关系是本节把各类肝病收束为同一后果，与下一节的关系是分类之后讲影响。两层问题的答案合起来，才构成一个完整的类别名称。不写酶学与蛋白数值。

18.4.2 肝功能衰竭对机体的影响

30 / 42body
十二个小节：逐条落位

本节问的是肝功能下降之后，机体哪些环节随之改变，以及这些环节之间如何牵连。答案落在功能与代谢这一层。影响涉及四个方面：物质代谢的改变，包括糖、脂肪与蛋白质的代谢；物质合成的减少，包括血浆蛋白与凝血相关蛋白；解毒能力的下降，使体内毒性物质蓄积；凝血功能的障碍。四个方面相互牵连，不是并列的四条。要害是牵一发动全身有具体路径：合成减少影响胶体渗透压与凝血，解毒下降影响中枢，代谢改变影响能量供给，这些路径才是本节要写的东西。与上一节的关系是分类与影响，与下一节的关系是本节所述中枢与肾的受累正是下一节的两个落点。四个方面的牵连方式不同，描述时须指明以哪一条路径为主。不写检验数值。

18.4.3 肝性脑病与肝性肾功能衰竭

十二个小节：逐条落位

本节问的是肝功能衰竭为何会在中枢与肾这两个器官上表现出专门的类别，两者是同一逻辑还是两条独立线索。答案落在器官受累这一层。肝性脑病是肝功能衰竭时出现的中枢神经系统功能改变，表现为意识、行为与神经功能的异常，与肝对多种物质的清除能力下降相关；按发生基础可分与肝细胞严重损伤相关者与门体分流相关者两类。肝性肾功能衰竭指肝功能衰竭时出现的肾功能障碍，形态上以肾小管的改变为主而肾小球改变轻微。要害是两者的共同逻辑：都是肝的清除与调节能力下降在下游器官上的投影，因此表现分散却同源。与上一节的关系是影响的具体落点，与本章开头的关系是由器官病变回到全身。不作诊断与预后判定。
