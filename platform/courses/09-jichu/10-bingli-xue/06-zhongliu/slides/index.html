PROBLEM

「肿瘤是异常增生」这句话人人会说，考卷上也写得出。可换一个问法——炎症时的上皮增生、创伤修复时的纤维增生、代偿性的腺体增生，凭什么说它们不是肿瘤——「异常增生」四个字一个也挡不住。定义句里真正管用的只有两个字：克隆。抓住它，增生就能分成两类；抓不住它，这一章剩下的内容都只能靠背。

一、定义句里只有一个词在干活：克隆

教材的定义句长，但真正承担区分功能的只有一处：

「肿瘤性增生则具有克隆性」——教材·第6章·6.1.1（《病理学·第6章·6.1》）

克隆性的意思是：增生的细胞来自同一个发生了改变的细胞及其子代，它们共享那次改变。这一条把肿瘤性增生与另外两种增生彻底分开——反应性增生（炎症时的上皮或淋巴组织增生）与代偿性增生（切除一侧器官后另一侧的增大），二者的细胞来源是多元的，刺激一去，增生就退。教材把这条对照写得非常具体：反应性与代偿性增生「在刺激去除后趋于缓解，结构安排大体保持原有的层次与极向，细胞的形态与起源组织相近」；肿瘤性增生则「由发生改变的细胞及其子代持续增殖而来，其增生过程与机体的需要之间不再保持协调」。

5 / 42body
一、定义句里只有一个词在干活：克隆

注意最后半句：与机体的需要不再协调。这是克隆性带来的第二个后果——增生不再服务于机体的需要，而服务于自身。于是「肿瘤与机体之间是相互作用的关系」这句看似平淡的话就有了分量：肿瘤不是机体的一部分在正常工作，而是机体里长出了一套按自己的逻辑走的东西，机体同时对它作出反应（炎症、纤维化、免疫清除）。这一层关系在第 6 章的多个单元里反复出现，是理解「为什么肿瘤既能被限制又能进展」的钥匙。

定义句还有一处限定常被漏读：在基因水平上失去对其生长的调控。这句话把「原因」定在了细胞自身的调控环节，而不是外部刺激的强弱。外部刺激（致瘤因素）提供改变的契机，能不能累积成肿瘤，取决于机体自身的调控与修复能力——教材紧接着就写了这层：「致瘤因素提供改变的契机，机体自身的调控与修复能力决定改变能否累积。」这一句同时否掉了两种简化：把肿瘤归因于单一因素，以及把某一因素当成决定性条件。

二、实质与间质，与一把叫异型性的尺

6.1.2 讲肉眼与镜下两套观察。肉眼六项：数目、形状、颜色、质地、表面、边界——教材明确说这些「具体数值与尺寸参数不属于本章的记述范围」，只写类别。镜下则只有两个成分：

「实质是肿瘤细胞的总称，是肿瘤的主要成分」——教材·第6章·6.1.2（《病理学·第6章·6.1》）

实质决定生物学行为与命名类别；间质由结缔组织与血管构成，起支持与营养作用，通常不参与命名。这一分工极其重要，因为后面三件事都挂在它上面：

  1. 命名：名字跟实质走。「纤维瘤」说的是实质是纤维成分，「腺瘤」说的是实质呈腺样——不是「长在纤维里」或「长在腺体旁」。
  2. 质地与颜色：实质细胞密集则质地偏实、颜色偏深；间质纤维多则质地偏韧、颜色偏灰白。教材用「实质与间质的比例关系」来解释一般形态的差异。
  3. 生长所需的支持：间质里的血管决定营养供给，也决定肿瘤细胞有没有机会进入血管——这一点在 6.2.3 讲血管生成时会回来。

二、实质与间质，与一把叫异型性的尺

继发改变单列一类：出血、坏死、囊性变、感染、钙化。教材要求「区分原发表现与继发表现，分别描述并注明依据」——这条要求不是形式主义：一块切面上看到的暗红色区域可能是出血（继发），也可能是肿瘤本身含血窦丰富（原发），混淆了就会把继发改变当成肿瘤的特点，进而影响对生长方式的判断。

异型性的定义是「与其起源的正常组织之间的差异」，教材把它拆成两个面：

「异型性是指肿瘤组织在形态与结构上与其起源的正常组织之间的差异」——教材·第6章·6.1.3（《病理学·第6章·6.1》）

  • 组织结构异型性：细胞排列的层次与极向改变，腺体或上皮与间质的关系紊乱，实质与间质的正常排布被打乱。
  • 细胞异型性：细胞形态与核的形态改变，细胞的单一性消失；恶性者可见大小形状不一、核浆比例变化、染色质分布改变、核仁改变、核分裂象类别改变与病理性核分裂。

二、实质与间质，与一把叫异型性的尺

两个面必须分列记录——教材特意提醒，混着写会让「组织排列紊乱」与「单个细胞幼稚」两件事互相污染，复核时无法逐项核对。

异型性与分化的关系，教材给了一个非常干净的判断：

「分化与异型性存在反变关系」——教材·第6章·6.1.3（《病理学·第6章·6.1》）

分化高 → 接近起源组织 → 异型性不明显；分化低 → 偏离明显 → 异型性显著；未分化 → 难以辨认起源，须借助其他方法。反变关系是一把双向可用的尺：看到异型性明显，可以推分化低；看到分化好，可以预期异型性轻。但教材同时给了一句刹车：常见的问题是把异型性与恶性程度直接等同——异型性只是形态比较的结果，解释时要结合起源组织、部位与继发改变。这句话在第 6.3.1 讲良恶性区别时会再被用到。

代谢特点是本节唯一偏机制的内容，三句话：核酸与蛋白质合成活跃（对应持续增殖）、有氧条件下仍以糖酵解为主且乳酸生成增多、酶谱活性类别改变。教材没有给任何数值，也没有给「活跃多少倍」这类表述——这正是本书口径的来源。

三、四节的分布，与生长方式与扩散

注意两句都是「多见于」，不是「就是」。教材在 6.3.1 里把这层保留写实了：良恶性的表现并非处处截然分开，部分肿瘤形态特殊，生物学行为要综合理解；「良性也不等于没有影响」，局部压迫与阻塞同样引起功能改变，部分部位的良性肿瘤也可以复发。「多见于」这三个字是本章最该被学生抄下来的措辞——它把一个个案判断从「查表」变成了「权衡」。

膨胀性生长的形态标志是包膜：完整包膜、边界清楚、周围组织呈受压改变。浸润性生长的形态后果是结构被破坏：沿组织间隙、淋巴管、血管、神经束衣延伸，无完整包膜，边界不清，是「难以彻底清除的形态基础」。外生性生长讲的是方向（向体表或腔内向腔内突起），它可以与向深部浸润并存——所以教材提醒「表面所见只是形态的一个方面，判断生长方式需要结合基底部的表现」。

扩散是另一套描述：

「转移的途径包括淋巴道转移、血道转移与种植性转移」——教材·第6章·6.2.2（《病理学·第6章·6.2》）

三、四节的分布，与生长方式与扩散

直接蔓延与转移的区别在于连续性：直接蔓延是连续的（与原发部位无明确界限），转移是离散的（离开原发部位，经淋巴、血道或体腔到达他处，形成与原发同类的肿瘤）。教材给了一条按来源分类的经验归纳：上皮来源的肿瘤以淋巴道转移较为常见，间叶来源以血道较为常见——这条对应关系在 6.3.3 讲癌与肉瘤的区别时会第二次出现，两处必须合起来看。

血道转移的形态特点被写成「集落式」：转移灶在器官内呈相对独立的结节，周围多呈受压改变，分布与血流走向相关。这一句把「转移灶为什么长这样」和「它怎么来的」接上了。

6.2.3 讲机制，四个环节：细胞黏附改变（脱离原位）、细胞外基质降解（开路）、运动能力增强（前移）、血管生成（进入循环的支持）。教材对这个链条有一句方法论提示：环节之间「不是简单的先后关系，而是相互配合的过程」，在表现上可以重叠。同一节还有一句把形态与行为缝在一起的话：

四、良恶性区别：一张交叉表，不是一条及格线

6.3.1 给了六个比较面：分化程度、异型性表现、生长方式、生长活跃程度、复发与转移、对机体的影响。教材的行文方式值得注意：它不是给一条线（「超过这条线就是恶性」），而是给一组彼此印证的类别，并明确「上述方面并非彼此独立」——分化影响异型性，异型性关联生长方式，生长方式影响扩散可能。

于是判断的正确姿势是交叉印证：分化低 + 异型性明显 + 浸润性生长 + 有转移 → 四项同向，结论稳；分化较好但边界不清、有复发 → 项间不一致，只能说「表现特殊，需综合理解」，不能硬塞进格位。教材在 6.3.1 末尾专门写了这句提醒，也在 6.1.3 用「异型性 ≠ 恶性程度」提前打过预防针。同一个刹车装在两处，说明这是本章最容易被踩错的地方。

四、良恶性区别：一张交叉表，不是一条及格线

对机体的影响（6.3.2）分局部与全身两层。局部：压迫、阻塞、出血、感染、疼痛、溃疡、积液；全身：营养与代谢状态改变、乏力消瘦、发热与血液成分变化，以及部分肿瘤产生激素样物质引起与原发部位无关的表现。最后这一类（异位激素样表现）是「肿瘤与机体关系」的极端例子——病灶在一个地方，表现出现在另一个地方，靠的是活性物质经血行播散。教材把它归到「关系类别」而不是「孤立名称」来记，这个处理很关键：记名称只能应付选择题，记关系才能解释「为什么这个表现和那个病灶有关」。

五、命名跟实质走，关联不是因果

6.3.3 的规则可以用一句话概括：名字反映起源组织与生物学行为，不反映部位，也不反映形态特点。

「良性肿瘤的命名一般在起源组织名称之后加瘤字」——教材·第6章·6.3.3（《病理学·第6章·6.3》）

「起源于上皮组织的恶性肿瘤称为癌」——教材·第6章·6.3.3（《病理学·第6章·6.3》）

「起源于间叶组织的恶性肿瘤称为肉瘤」——教材·第6章·6.3.3（《病理学·第6章·6.3》）

三句合起来是一个矩阵：良性 = 起源 + 瘤；恶性上皮 = 起源 + 癌；恶性间叶 = 起源 + 肉瘤。于是「腺瘤 / 腺癌」「纤维瘤 / 纤维肉瘤」「骨瘤 / 骨肉瘤」三对名称的差别只在生物学行为，起源相同。这一矩阵还能推出一个常被忽略的结论：同一个名称可以出现在不同部位（不同部位的纤维瘤都叫纤维瘤），同一个部位可以有不同名称（同一个器官里上皮来源与间叶来源的肿瘤名字完全不同）。所以「部位名 + 瘤」这种说法在规范命名里是不成立的。

五、命名跟实质走，关联不是因果

特殊命名要单独记：幼稚组织来源加「母细胞瘤」；沿用习惯名称的（淋巴瘤、白血病、黑素瘤、精原细胞瘤）；多胚层成分的称畸胎瘤。教材对这几类的处理是明确的：按约定类别记，说明其在分类框架中的位置，「不宜由名称推断分化程度与来源」——黑素瘤听起来像良性（带「瘤」字），实际是恶性；淋巴瘤同理。这是名称与行为脱钩的唯一一批例外，也是最容易被名称骗到的地方。

分类框架按起源组织分：上皮、间叶、淋巴造血、神经、其他。6.4.1 的举例正是按这个框架铺开的：上皮（乳头状瘤、腺瘤 / 鳞状细胞癌、腺癌）、间叶（纤维瘤、脂肪瘤、骨瘤 / 纤维肉瘤、骨肉瘤）、神经（神经纤维瘤、胶质瘤）、其他（黑素瘤、畸胎瘤）。举例那一节的落点是「以形态为据理解名称，以名称规范记录形态」——名称是约定，形态是所见，两者互相印证而不是互相替代。

五、命名跟实质走，关联不是因果

6.4.2 把病因分外界与机体两类，并给了一句必须记住的限定：许多因素与肿瘤的关系「表现为概率层面的关联，而不是确定不移的因果关系」。这句话的分量在于它挡住了两种过度推论：看到一个致癌因素就断定「必然得病」，或者看到一个病例就反推「必然是某个因素所致」。教材还把「慢性炎症与长期刺激」单列——它属于「可以持续存在的条件」，其作用是长期的、累积的，这一条与第 5 章炎症的慢性经过直接接续。

6.4.3 讲发病学，四类环节：生长调控改变（促进与抑制的平衡偏移）、修复能力改变（损伤反应减弱、改变累积）、凋亡相关环节改变（异常细胞被保留）、克隆性演变（形成表现不同的细胞群体）。落点仍是那句「发病过程通常涉及多个环节的先后累积，而不是单一事件的结果」。形态上的对应物是「肿瘤不同区域的表现存在差异」——这句话把克隆性演变从抽象概念变成了可以在切片上看到的现象。

6.1.1 肿瘤的概念

这一节问的是肿瘤与其它增生凭什么分开，答案落在增生的类别这一层：肿瘤是机体在致瘤因素长期作用下，局部组织的细胞在基因水平上失去对其生长的调控、出现克隆性异常增生所形成的新生物。分辨的关键有三条：与反应性增生、代偿性增生不同，后两者在刺激去除后趋于缓解，结构安排大体保持原有的层次与极向，细胞形态与起源组织相近；肿瘤性增生具有克隆性，由发生改变的细胞及其子代持续增殖而来；其增生与机体需要之间不再保持协调。形成与致瘤因素的持续作用和机体自身防御能力的改变相关，不能归因于单一环节。与本章后三节的关系是概念先行：先定类别，才谈形态、生长与良恶。

6.1.2 肿瘤的一般形态与组织结构

这一节问的是肿瘤在肉眼上可以记哪几项，答案落在形态要素这一层：数目、形状、颜色、质地、表面与边界构成描述肿瘤形态的基本项，尺寸与具体数值不在记述范围。形状与生长方式及发生部位相关——体表或空腔器官的肿瘤可呈结节状、息肉状、乳头状或菜花状，实质器官的多呈结节状或分叶状，浸润性生长者边界不清，膨胀性生长者常有包膜；颜色与起源组织的类别及是否含色素、出血、坏死相关，含脂质者偏黄，含色素者偏深，出血区暗红，坏死区灰白；质地与实质和间质的构成比例相关。组织结构则看实质与间质的排布及细胞的排列方式。与前一节是概念到外观，与后一节是外观到异型性。

6.1.3 肿瘤的异型性与代谢特点

十二个小节：逐条落位

这一节问的是「像不像原来的组织」这件事怎样变成可描述的内容。答案落在异型性这一层，分组织结构与细胞形态两面：组织结构异型性表现为细胞排列的层次与极向发生改变，腺体或上皮与间质的相互关系紊乱，实质与间质的正常排布被打乱；细胞异型性表现为细胞形态与核的形态改变、细胞的单一性消失，可见大小与形状的差异、核浆比例的变化、染色质分布与核仁表现的改变，以及核分裂象的类别改变与病理性核分裂。程度按类别表述，不采用分级与分期的数值口径。分化与异型性呈反变关系：分化高者接近起源组织、异型性不明显，分化低者偏离明显、异型性显著，未分化者难以辨认起源。代谢特点表现为合成与分解代谢关系的偏移，与生长活跃程度相关。与前后两节的关系是同一条线索的展开：概念定类别，本节定「像不像」，后一节谈生长行为。

6.2.1 肿瘤的生长方式

十二个小节：逐条落位

这一节问的是肿瘤与周围组织之间形成什么样的空间关系。答案落在生长方式这一层：膨胀性生长、浸润性生长与外生性生长，方式与良恶类别及发生部位相关，也是理解扩散途径的基础。膨胀性生长多见于良性肿瘤，生长时推开周围组织，常形成完整包膜，与周围组织分界清楚，周围组织多呈受压改变而非破坏性改变；包膜由纤维组织构成，其完整程度与生长的活跃程度以及周围组织的反应相关。浸润性生长多见于恶性肿瘤，细胞侵入并破坏周围组织，沿组织间隙与淋巴管血管延伸，通常不形成完整包膜，分界不清，是难以彻底清除的形态基础。外生性生长者须结合基底部的表现综合判断。与前一节是形态到行为，与后一节是行为到扩散。

6.2.2 肿瘤的扩散途径

25 / 42body
十二个小节：逐条落位

这一节问的是肿瘤离开原发部位有哪几条路。答案落在扩散途径这一层：直接蔓延与转移。直接蔓延指肿瘤细胞沿组织间隙、神经束衣与血管淋巴管周围间隙连续生长，侵入邻近组织与器官，形态特点是连续性——与原发部位之间没有明显界限，受累组织的结构与排列被逐步取代，与浸润性生长的表现相互衔接。转移指细胞离开原发部位、经特定途径到达他处并继续生长，形成与原发肿瘤同类的肿瘤，途径分淋巴道、血道与种植性三类。途径与肿瘤类别相关：上皮来源者以淋巴道转移较常见，间叶来源者以血道转移较常见；淋巴结的引流区域与部位相关，转移可沿引流顺序出现。与前一节是生长到扩散，与后一节是表现到机制。

6.2.3 恶性肿瘤浸润转移的机制

这一节问的是浸润与转移在机制上有哪些环节。答案落在环节类别这一层，且各环节不是简单先后，而是相互配合：黏附改变提供脱离的条件——正常组织中细胞借黏附结构相互连接，肿瘤细胞之间的黏附减弱，容易脱离原有位置；细胞外基质降解开辟通路——细胞分泌降解基质的酶类，使基质屏障受损；运动能力使细胞前移，与降解过程配合形成连续浸润；血管生成提供进入循环的支持；进入循环后的存活依赖机体防御反应与细胞自身特点的共同作用。教材强调以类别为据解释，不涉及分子操作参数，也不把过程简化为单一因素。与前一节的关系是途径到机制，与后一节是机制到良恶比较。

6.3.1 良性肿瘤与恶性肿瘤的区别

这一节问的是良性与恶性凭什么分开。答案落在比较的类别框架这一层，几个方面相互联系：分化程度、异型性表现、生长方式、生长的活跃程度、复发与转移、对机体的影响。良性者多与起源组织相近，异型性不明显，组织排列多保留原有的层次与极向，细胞形态较一致，多呈膨胀性生长、常有完整包膜、边界清楚；恶性者多偏离起源组织，异型性较显著，排列紊乱，细胞与核的形态出现差异并可见核分裂象的类别改变，多呈浸润性生长、多无完整包膜、边界不清。教材要求按类别比较而不是按级别名称记忆，外生性生长者还须结合基底部表现综合判断。与前后两节的关系是承上启下：上承形态与生长，下接对机体的影响。

6.3.2 肿瘤对机体的影响

6.4.3 肿瘤的发病学

这一节问的是从因素作用到肿瘤形成之间经过哪些环节。答案落在发病环节这一层：生长调控的改变是基础——调控依靠促进生长的因素与抑制生长的因素之间的平衡，相关基因的类别发生改变时平衡偏移，细胞获得持续增殖的能力；损伤修复能力的改变参与其中——相关基因改变时细胞对损伤的反应减弱，改变可以在细胞群体中累积；凋亡相关环节的改变同样参与——程序性死亡是维持组织稳定的方式，环节改变时异常细胞被保留并继续增殖。克隆性演变是进展的表现，持续增殖中出现具有不同表现的细胞群体。各环节以类别为据解释，不用具体指标代替机制说明。与前一节是因素到环节，本节收束全章。
