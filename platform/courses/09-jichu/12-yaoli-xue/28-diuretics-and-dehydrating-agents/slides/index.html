2 / 25motto
PROBLEM

学生很容易把「利尿」与「脱水」当成同一件事的强弱两档——都是把水弄出去，只是力度不同。教材把两类药并列在一章里，给的却是两条不同路线：利尿药从血液侧进入肾小管细胞、作用于管腔膜上的转运体，脱水药不进细胞，只在管腔里靠渗透压把水带出来。分不清这两条，后面每一个不良反应都解释不了——前者丢的是电解质，后者多出的是一过性血容量。更少被注意到的是，本章十二个小节里有六个不讲药，只讲「这些话该怎么写」（28.3）与「药在体内怎么走」（28.4）。

一、两套药物，一条路线：排出与转移

教材的切口是肾脏的三个环节：滤过、重吸收、分泌。滤过是被动的，重吸收是主动与被动并存的，而尿量的多少最终由重吸收的比例决定。由此给出利尿药的定义式：

「凡能减少肾小管对钠离子与水重吸收的药物，都可能增加尿量」——教材·药理学·第28章·28.1.1

注意这句话的落点：它说的是「减少重吸收」，不是「增加滤过」，也不是「把水挤出去」。利尿药动的是一条已经被滤出来的液体的处理方式。

脱水药动的是另一件事。教材的定义很干脆：

「脱水药又称渗透性利尿药」——教材·药理学·第28章·28.2.1

同一句里既叫「脱水」又叫「利尿」，最容易把人绕进去。教材紧接着把两者的分工写开：

「利尿药主要作用于肾小管上皮的转运体或酶，减少钠离子与水的重吸收」——教材·药理学·第28章·28.2.1

5 / 25body
一、两套药物，一条路线：排出与转移

这一句的后半段才是关键：脱水药主要提高血浆渗透压，使水在血管与组织之间重新分布，其利尿作用是继发的。于是两类药的分工可以压成两个词——利尿药管「排出」，脱水药管「转移」；前者的效应在肾小管腔里发生，后者的效应先在毛细血管壁两侧发生，然后才轮到肾。

这一分工决定了两件事：给药途径（脱水药以静脉给药为前提，口服只产生肠道内的局部效应）与观察重点（利尿药看尿量与电解质，脱水药看容量负荷与屏障两侧的梯度）。把两类混为一谈，会把渗透压效应误当作转运体抑制，也会把利尿药的组织脱水作用估计过高——这正是教材自己点明的第一处边界。

二、四节十二小节：一半篇幅在讲「怎么写」

其一，28.3 不是免责声明，而是一份写作规范：它把「可写项」与九类「不写项」逐一列出，还给了两段改写案例（把「效果良好、可作常规处理」改成「尿量较给药前增多，属偏多一级」）。这一节解决的问题是「同一段观察，为什么这样写可以复核、那样写就是结论」。

其二，28.4 不是体内过程的重复，而是把它拆成三个小节各写一节：28.4.1 吸收、28.4.2 分布、28.4.3 生物转化与排泄。体内过程在别的章里通常只占半个小节，这里给了三节——因为在利尿药身上，这三个环节各自都能解释一个临床现象（口服与静脉的起效差别、管腔侧作用面与血中水平不平行、肾功能减退时的蓄积）。

所以本章的读法可以是：前六节讲药，后六节讲「这些药的话该怎么说、路该怎么走」。两半的分量相等，正好说明底本不认为「机制讲完就完了」。

三、28.1：四个部位与四个类别

28.1 的骨架是解剖。教材按肾单位走一遍：

  • 近曲小管：重吸收滤过液中大部分的钠离子，方式以钠氢交换为主；氢离子来自碳酸酐酶催化的反应，抑制该酶则钠氢交换减弱，钠离子与碳酸氢根随尿排出，尿的酸度下降。
  • 髓袢升支粗段：以钠钾氯同向转运的方式重吸收氯化钠；进入细胞的钾离子经管腔侧钾通道返回管腔，形成钾再循环，使管腔侧呈正电位，这一正电位推动钙与镁经细胞旁路重吸收。此段对水几乎不通透，溶质被移走而水留下，管腔液被稀释，髓质间渗透压梯度随之建立。
  • 远曲小管前段：以钠氯同向转运重吸收钠离子，对水的通透性仍低，是稀释过程的延续。
  • 集合管：水重吸收的调节部位，抗利尿激素使水通道蛋白插入管腔膜；醛固酮作用于远曲小管后段与集合管，促进钠重吸收与钾分泌。

四、28.2：脱水药靠的是屏障

28.2 的机制叙述有一个物理学的开头：半透膜两侧，水由溶质颗粒较少的一侧向较多的一侧移动，单位体积内溶质颗粒的数量决定渗透压的高低，而与颗粒的种类关系较小。脱水药利用的正是这一点——用停留在血管内的溶质颗粒造成两侧差异。

差异能不能维持，取决于溶质会不会跑掉：

「凡能迅速跨过膜而进入组织的溶质，其造成的差异很快消失，效应也随之减弱」——教材·药理学·第28章·28.2.2

这一句解释了甘露醇为什么能作用于脑与眼：血脑屏障与血眼屏障对它的通透性低，药物停在血管内，屏障两侧才有有效的梯度；对通透性高的组织，药物迅速进入组织间隙，梯度随之消失。教材把这条写成一句判断：

「渗透性脱水的作用以屏障的存在为前提」——教材·药理学·第28章·28.2.2

「以屏障的存在为前提」——这句话把脱水药从「强效利尿」的位置上挪开了：它不是更强，而是要求一个结构条件。屏障受损时，效应与风险同时改变。这一层在别处少见，本章给了整整一段。

四、28.2：脱水药靠的是屏障

随之而来的是本章最值得琢磨的一个现象：

「反跳现象是渗透性脱水药共有的一类过程性问题」——教材·药理学·第28章·28.2.2

机制不难：给药期间血管内渗透压高于组织，水外移；停药后血管内药物被排泄而组织内药物仍在，渗透压关系反转，水回流入组织。教材的处理方式是把它写成「过程特点与观察要点」，而不写成必然发生的结局——给药速度与总量影响回升的程度，因此它是一个与操作相关的现象，不是一个药物的固有属性。

分类上，脱水药按结构分三组：多元醇类（甘露醇、山梨醇）、糖类（高渗葡萄糖）、酰胺类（尿素）。三组的差别在跨膜与代谢，不在作用性质：山梨醇有一部分在肝内转化为糖原，渗透效应随时间衰减；尿素分子小、跨膜快，脱水出现迅速，但进入细胞后使细胞内渗透压升高，回升现象更突出；高渗葡萄糖被迅速代谢，渗透压梯度消失得更快。这一组对照正好说明：同一机制下，过程参数决定效应时程。

  1. 商品名、生产厂家、规格、价格、批准文号；
  2. 含量、浓度、滴度、效价的量值；
  3. 检验数值与参考区间（包括尿量、体重、出入量的量化指标）；
  4. 诊断与病情与预后判定；

五、28.3：可写项与不写项——这一节在教写作

「教材提供知识与方法，规范提供当下的要求，两者不能互相代替」——教材·药理学·第28章·28.3.1

这句话的作用是给教材定位：教材的时效长、规范的时效短，两者冲突时以规范与现行药品说明书为准。教材自己写明这一点，等于承认自己会过期——这是一种很少见的诚实。

28.3.2 把观察的对象定死了：

「观察的对象是药物作用在个体身上表现出的类别，而不是检验数值」——教材·药理学·第28章·28.3.2

于是记录采用三级描述：尿量记「偏多 / 如常 / 偏少」，体重记「上升 / 持平 / 下降」，口渴记「无 / 轻度 / 明显」，穿刺部位记「无异常 / 轻度肿胀 / 明显肿胀」。四级以上的精细分级不写——因为细分需要测量，而教材的观察练习只训练类别识别与描述规范。

五、28.3：可写项与不写项——这一节在教写作

复核分四组内容（药名剂量途径时间的一致性、观察记录与给药记录的对应、类别用语的规范性、签署的完整性）、三类方法（逐项核对、抽样核对、交接班核对）、三种结论（相符、不符、待补）。留痕六项要素（时间、环节、内容、依据、结论类别、人员）。这一节的落点是一句边界：

「复核不替代专业判断」——教材·药理学·第28章·28.3.3

复核能确认的是「记录与记录是否一致」，不能确认「这个表现意味着什么」。把复核写成判断，复核者就越出了职责；把判断写成复核，判断就失去了依据。

六、28.4：把体内过程拆成三节

体内过程在多数章里是半个小节，这里给了三节。理由写在每一节的开头。

28.4.1 吸收：「吸收是药物进入体循环的第一道环节」。对利尿药而言，它决定起效快慢与口服能否替代注射。教材在这里写了一处很实用的差别：呋塞米口服吸收迅速但个体之间差别较大，胃肠道黏膜水肿或肠道淤血可使吸收明显减少，故需要迅速起效时改用静脉给药；氢氯噻嗪吸收较快但完整程度有限；螺内酯首过效应明显，部分效应来自活性代谢产物。脱水药则相反——口服几乎不吸收，只在肠腔形成渗透压梯度产生导泻，属局部效应。

28.4.2 分布：这一节的关键是「作用部位在管腔侧」这一解剖事实：

「利尿药的作用部位在肾小管上皮的管腔侧」——教材·药理学·第28章·28.4.2

17 / 25body
六、28.4：把体内过程拆成三节

由此推出一条容易被忽略的结论：血中水平高而分泌受阻时，管腔内的药量仍然不足，效应与血中水平并不平行。噻嗪类与髓袢类经近曲小管的有机酸转运系统主动分泌进入管腔，同一系统上的其他有机酸可与之竞争；螺内酯则相反，亲脂性强，进入细胞后与胞质内的醛固酮受体结合，作用面在细胞内。脱水药的分布范围最窄：甘露醇与山梨醇不进入细胞内，主要停留在细胞外液，故其分布容积接近细胞外液体积。

28.4.3 生物转化与排泄：消除方式决定了蓄积的可能。氢氯噻嗪几乎不被代谢，以原形经肾排出；呋塞米兼有肝内结合与肾排出两途，故受肝肾功能两方面影响；螺内酯在肝内转化为坎利酮等活性产物，肝功能减退时活性产物生成减少，效应随之改变。尿的酸碱状态也影响排泄——弱酸性药物在碱性尿中解离增多、重吸收减少、排出加快，乙酰唑胺使尿趋向碱性，故可加快某些弱酸性药物的排出。

七、分类不是等级：高效、中效、低效的正确用法

本章有一处极容易被误读的表述。教材说利尿药习惯上分为高效、中效、低效三类，紧接着立刻补了一句：

「这一分法只描述排钠幅度所在的区间，不构成药物之间的等级评定」——教材·药理学·第28章·28.1.2

这句话是本章的口径样本。它承认「高效 / 中效 / 低效」这套说法存在（教材不能假装它不存在，因为临床与教学中都在用），同时把它的含义锁死为「排钠幅度的区间」。区间是描述，等级是评价；同一句话可以读成前者，也可以读成后者，教材选择了前者并明说了。

再往下看，还有一层：高效类作用于髓袢升支粗段，中效类作用于远曲小管前段，低效类作用于近曲小管或集合管——但「分类名称与实际药物之间并非一一对应，同一类别内的药物在起效快慢与维持时间上仍有差别」。这句「并非一一对应」是教材常见的自限：它给出分类，同时告诉你分类的边界在哪里。

由此可以提炼出本章的一条判断规则：凡是带「效」字的词，先问它描述的是什么区间，再问它能不能用来排序。排钠幅度是一个区间，起效快慢是另一个区间，作用维持时间是第三个区间；三个区间不能互相换算，更不能合成一个总分。

  • 引文是教材正文，不是指南。 本章引用格式为「教材·药理学·第N章·N.M.K」。教材写「临床应用类别」而不写「适应证」，写「剂量与用法照底本」而不给个体方案；要引指南推荐，须回指南原文核对。
