PROBLEM

腰背痛是国内门诊量最大的症状之一，而「腰肌劳损」常被当成筐：凡腰疼查不出原因都装进去。四个病——急性腰扭伤、腰肌劳损、腰椎小关节紊乱、第三腰椎横突综合征——症状都写「腰痛、活动受限」，鉴别却只靠四项：起病方式、压痛的位置与范围、对负荷与休息的反应、有没有神经症状。四项都靠一双手和几句问话，为什么还会混？

双根因定位

环境逼迫（腰背是承重与劳损的双重集中区：搬运、久坐、久站、肥胖、妊娠都把负荷压在同一个节段上；而腰背痛里混着马尾综合征、腹主动脉瘤、椎体骨折、脊柱感染与转移瘤——误治的代价不可逆，所以「能不能动手」必须排在「怎么动手」之前）+ 知识积累（本章 5 单元 / 10,879 汉字，是全课最薄的一章，却要装四个病与一张红旗清单；其中 7.1 与 7.3 同写腰肌劳损、7.3 与 7.5 同写急性腰扭伤，重复的单元正是本章合并的对象）

一、急性腰扭伤：先分清伤了哪一组

急性腰扭伤俗称闪腰、岔气，指腰部肌肉、筋膜、韧带、关节囊因骤然用力、姿势不当或扭转牵拉发生的急性损伤，可伴小关节滑膜嵌顿与骶髂关节轻微错缝。机制多为间接暴力：搬抬重物时腰前屈加旋转，力臂最长而稳定肌群来不及保护性收缩。

「伤了哪一组」决定压痛在哪、要不要固定、能不能扳：肌肉筋膜伤压痛弥散在骶棘肌外缘与髂嵴后缘，肌肉痉挛呈板状腰；韧带伤压痛深而局限，骨盆挤压分离试验可阳性；小关节伤压痛在棘突旁，棘突可偏歪，后伸与旋转受限最明显。

三条阴性体征比阳性体征更有用：直腿抬高阴性或轻度受限，无神经根支配区的感觉减退与肌力下降，腱反射对称。这三条在，可先按筋伤处理；出现下肢放射性麻木、踝反射减弱、足背伸无力，改按腰椎间盘突出症急性发作评估。

一、急性腰扭伤：先分清伤了哪一组

处理分两段。头一两天减负：卧硬板床、腰围短期保护、局部冷敷，避免弯腰负重，但不必绝对卧床。三日后肿痛趋稳，改用轻柔手法，取肾俞、大肠俞、气海俞、腰阳关、委中、承山与阿是穴；扳法只在明确小关节错缝、且已排除骨折与骨质疏松时使用。内治按气滞血瘀，用复元活血汤或血府逐瘀汤加减，外敷消瘀止痛类药膏。

同一个手法，用在闪腰上是疗效，用在压缩骨折上是一次事故。这句话不是修辞：两者都表现为「搬东西时突然腰痛、不敢动」，区别只在叩击痛与影像——而影像往往要等到第二天才拍。

二、腰肌劳损：一个「没有体征的病」

腰肌劳损又称慢性腰肌劳损、功能性腰痛，指腰部肌肉、筋膜、韧带因长期慢性损伤产生的无菌性炎症，以反复酸胀疼痛、劳累后加重、休息后减轻为主要表现。多因长期弯腰久坐、姿势不良使筋肉持续牵拉而失养，或急性扭伤失治迁延，或肾气亏虚、气血不足，复感风寒湿邪而痹阻经络；职业、肥胖、妊娠与腹部手术是常见的加重条件。

其特点是症状多、体征少：酸胀隐痛，时轻时重，久坐久站与劳累后加重，晨起僵硬而活动后减轻，捶击腰部反觉舒适；压痛广泛，以骶棘肌、髂腰肌附着点及腰骶部为著，可触及条索；腰椎活动多正常或轻度受限。

「捶击后舒适」是它最省事的一条分界。 骨折、感染、肿瘤叩之更痛，不会想让人再捶；劳损的组织在叩击与按压后反而松快。这条体征不精确，但它筛掉的方向很关键。

二、腰肌劳损：一个「没有体征的病」

辨证三型。寒湿型：腰部冷痛重着，阴雨受凉加重，得温则减，苔白腻，治以散寒除湿，甘姜苓术汤或羌活胜湿汤加减。肾虚型：酸软隐痛，喜按喜揉，遇劳加重、休息减轻，伴头晕耳鸣、膝软乏力，偏阳虚者温补肾阳，偏阴虚者滋养肾阴。瘀血型：痛有定处，拒按，腰部板硬，舌紫暗或有瘀点，治以活血化瘀、行气止痛。

须分出去的是根性痛、炎性腰痛、骨病与内脏牵涉，逐条见第五节的清单。

治疗的主力不是手法，是负荷管理加练功。手法松解骶棘肌、腰方肌、髂腰韧带，点按肾俞、大肠俞、气海俞、关元俞、委中、承山；固定只用腰围短期保护，长期佩戴使腰肌进一步萎缩；练功以核心稳定与髋部柔韧为主，五点支撑、三点支撑、飞燕式、桥式；生活上每三十至四十分钟变换体位，减少单侧负重。这个病治的是负荷，不是疼痛；只止痛不改负荷，一定复发。

三、小关节紊乱：一次「错缝」

腰椎小关节紊乱又称腰椎后关节紊乱、腰椎骨错缝、腰椎滑膜嵌顿，指关节突关节因急慢性损伤发生错位或滑膜嵌顿，引起腰部剧痛与活动受限。多见于青壮年，是脊柱手法的优势病种，也最易被手法做出事故。关节突关节是滑膜关节，椎间隙变窄后关节囊松弛，弯腰转身时滑膜易被嵌夹；腰肌疲劳则更易失稳。

表现辨识度很高：常于弯腰、转身或晨起时突发剧痛，呈强迫体位，腰僵直不能挺直，翻身、咳嗽、深呼吸时加重；压痛点在棘突旁，可有棘突偏歪与局部叩击痛；无明显下肢放射痛，直腿抬高多阴性；后伸与旋转受限最明显。整复后症状多即刻缓解，这一条几乎可以反证诊断。

处理的关键是「一手准、一手轻」。放松之后作旋转扳法，幅度小、速度慢，到终末感即止；一次不成，改日再来，不叠加发力。此前必须排除骨质疏松、椎体骨折、脊柱感染与肿瘤、腰椎滑脱、腹主动脉瘤。

三、小关节紊乱：一次「错缝」

弹响来自关节内气体与关节面滑动，不等于复位；把弹响当成功指标，手法就会越来越大。 这一条与第 4 章的「不追求弹响」是同一条纪律：弹响与位置恢复之间没有稳定对应，而为了听到那一声所加的幅度，正是医源性损伤的常见起因。

四、第三腰椎横突综合征：一个「点」的病

第三腰椎横突综合征，指因第三腰椎横突过长或发育异常，其附着的肌肉、筋膜发生慢性劳损与无菌性炎症，引起腰臀部疼痛。属「腰痛」「筋痹」范畴，好发于青壮年体力劳动者与长期久坐者。

解剖是全部理由：第三腰椎位于生理前凸顶点，横突最长，所受杠杆应力最大，腰方肌、横突间肌与腰背筋膜深层附着于此，长期弯腰久坐即在此反复微伤，迁延则筋膜增厚粘连，卡压臀上皮神经，疼痛向臀腿放散。

体征是一个点，不是一个面：患侧第三腰椎横突尖部（髂嵴上方、竖脊肌外缘处）有明显压痛，可触及条索或结节，按压时诱发同侧臀腿部放射样酸胀；放射多不过膝，这是它与根性痛最省事的分界。此外须与肾脏疾病（肾区叩击痛、尿检异常）分开。

治疗以松解横突尖部粘连为关键：拇指或肘尖在条索上作与肌纤维垂直的弹拨，由轻渐重，配合点按肾俞、气海俞、志室、环跳、委中、阿是穴；术后温热敷，当日避免弯腰负重。练功以腰方肌牵伸与核心稳定为主；病程长者易反复，须同时改姿势与负荷。

四病之外，还有一组必须先想的东西。它们不是鉴别诊断的候选，而是「手能不能下」的闸门：

五、四病鉴别、八条红旗、一条主线
  1. 马尾综合征：双下肢无力、鞍区麻木、大小便功能障碍。急诊，禁手法。
  2. 腹主动脉瘤：老年突发腰腹剧痛，可伴搏动性包块、血压下降。急诊，禁推拿与复位。
  3. 椎体骨折：外伤后剧痛不能站立，或老年、骨质疏松、长期用激素者轻微外力即剧痛；叩击痛显著，X 线早期可阴性。
  4. 脊柱感染：发热寒战、持续剧痛、叩击痛剧；化脓者起病急，结核者缓而伴低热、盗汗、消瘦。
  5. 肿瘤与转移瘤：夜间静息痛、休息不减、进行性加重、体重下降、肿瘤史；五十岁以上新发腰痛属高危。
  6. 泌尿系结石：突发腰腹绞痛、向腹股沟放射、血尿。
  7. 炎性腰痛：四十岁以下、晨僵超过半小时、活动后改善、夜间痛醒。
  8. 内脏牵涉：与体位和负重无关的腰背痛，先查内脏。

问诊次序即这八条的次序：怎么起病、夜里痛不痛、有无发热消瘦、有无下肢麻木与二便变化、有无肿瘤与激素史、多大年纪。

五、四病鉴别、八条红旗、一条主线

手法按病与期给，不按「腰疼」给。松解类（揉、㨰、推、按、弹拨）通用于四病，以局部温热为度；点按取肾俞、大肠俞、委中、承山与阿是穴，「腰背委中求」说的是远端取穴的道理；运动类（斜扳、旋转复位、抖腰）只用于小关节错缝与扭伤后期。

固定以腰围短期减负为限，症状缓解即撤；久戴使腰肌与腹肌萎缩，把急性痛养成慢性不稳。练功是四病共同的长线：五点支撑、三点支撑练腰背肌，飞燕式练竖脊肌与多裂肌，桥式练臀与核心。原则是少量多次、每日数回、在疼痛可耐受范围内进行，急性期只做等长收缩，慢性期加渐进负荷。腰的稳定靠肌肉按时上班，不是靠腰围替它上班。

代价与边界
  1. 「腰肌劳损」是排除性诊断。 本章保留这个病名，但要求写它的时候写清排除了什么；诊断名词的收紧，本身就是一次治疗决定。
  2. 不把弹响当指标。 斜扳的弹响来自关节内气体逸出与关节面滑动，与错位是否纠正没有必然关系；本章不追求、不以次数计疗效、一次不成不叠加发力。
  3. 不给固定天数与练功组数。 腰围佩戴时长、训练的次数、阻力与进阶标准，本章不给；具体依现行规范与所在机构制度。
  4. 影像与症状不符时不按影像治。 无症状人群中椎间盘膨出与突出的影像并不少见；影像解释不了症状时，不按影像治疗；症状体征指向危险而影像阴性时，也不能放心。
  5. 母本重复未消。 底稿五单元里 7.1 与 7.3 同写腰肌劳损、7.3 与 7.5 同写急性腰扭伤，本章合并处理；合并后的篇幅因此比单元数看起来更紧。
  6. 个案不进入正文。 文中例子是合成的说明性情形，不含可定位的机构、人名与时间地点。
