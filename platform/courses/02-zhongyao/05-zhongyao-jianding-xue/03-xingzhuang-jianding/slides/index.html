第 3 章 · 性状鉴定没有仪器，八项描述就是它的仪器

「药有酸、咸、甘、苦、辛五味，又有寒、热、温、凉四气，及有毒无毒，阴干曝干，采造时月、生熟、土地所出、真伪陈新，并各有法」——《神农本草经·序录》。两千年前把「真伪陈新」与气味形色并列，说的正是同一件事：辨药先辨形色气味，且各有其法。
2 / 16motto
PROBLEM

药典性状项固定八项描述——形状、大小、色泽、表面、质地、断面、气、味。缺一项，结论只覆盖八分之七；而现场最常被省掉的恰恰是大小、表面、质地、断面这四项，它们也正是最难伪造的四项。剩下形、色、气、味四项，染色、增重、硫熏都能做得像。

双根因定位

环境逼迫（收购、入库、调剂、抽检都在现场完成，没有显微与色谱的条件，只能靠感官在几分钟内给判断）+ 知识积累（八项逐条对标准 × 术语指向可观察特征 × 水试火试设对照 = 一个能被第二个人重做一遍的观察，而不是一句「像正品」）

一、八项不是并列的，观察有固定顺序

性状鉴定的第一步不是看，是辨部位。根、根茎、茎木、皮、叶、花、果实、种子、全草、动物、矿物，部位不同，形态语汇整套不同：根类多圆柱形、圆锥形、纺锤形，根茎类多结节状、类球形，皮类多卷筒状、板片状，花类分花蕾与花朵。辨错部位，后面的形容全错位。

顺序是四句话：由表及里、先整后碎、先干后湿、先共性后个性。先看整体形状、大小、色泽，把握总体印象；再看表面——皱纹、皮孔、环节、毛茸、疤痕；然后折断或切开看断面，注意是否平坦、有无粉性、纤维性、角质样与特殊纹理；最后才是气与味，必要时辅以水试、火试。

「先干后湿」这一条常被忽略：干燥品与吸潮回软的同一批货，色泽、质地、断面表现明显不同。回软的白芍断面发暗，看着像陈旧品；判之前应让样品恢复干燥状态。观察要在自然光下，颜色用双色调描述（黄白色、红棕色、灰褐色），避免单说「白」「红」——单色词无法复核。

二、四种手段，各有各的边界

眼看为主，手摸、鼻闻、口尝为辅。四种手段的可靠性并不相同，边界要说在明处。

眼看能覆盖六项（形状、大小、色泽、表面、断面，以及花叶的完整形态），是最主要的手段；细小特征如种子表面网纹、花冠毛茸，用放大镜；破碎或粉末状样品先用清水润湿展平再看。断面颜色要折断后立即观察，久置氧化会变。

手摸管质地与轻重：坚实与松泡、粉性与纤维性、油润与角质样、黏滑。手摸还能估干湿，这是仪器不方便做的现场判断。

鼻闻要配合动作：有的药材直接嗅即可，有的须折断（当归、白芷），有的须揉搓（薄荷、鱼腥草），有的须热水浸润。

口尝是四种里唯一有安全门槛的。规矩是三条：少量、浅尝即吐、立即漱口。毒性药材禁尝——马钱子、生川乌、生草乌、半夏、天南星、白附子、斑蝥、巴豆、蟾酥、细辛等，只可观察不可入口。半夏嚼之麻舌刺喉，这个麻感既是鉴别特征，也是毒性警示，不能因为它「好用」就放松规矩。

二、四种手段，各有各的边界

手段的边界也要承认：感官结果受个人差异、经验水平与当时状态影响；术语难以量化。电子鼻、电子舌、色差仪能把感官特征转成数据，但转出来的仍是辅助数据，判定要回到法定标准的描述上。

三、成组判据与水试火试的「不成立」条件【教学设定】

单项特征永远不足以定真伪，因为伪品可以针对单项做得很像。性状鉴定必须成组看，一组同向才成立。

判据组组内要有哪几项成立的条件不成立（任一出现即退回）
形态组形状 + 大小 + 表面三项与药典描述同向，特异术语能在样品上指出来只有一个特异外形对得上，大小明显越界
断面组断面纹理 + 质地 + 断面色纹理、粉性／纤维性、色泽三者一致纹理对而质地不符（写角质样，实际粉性）
气味组气 + 味，且与成分类型相符气味同向且强度相当气味微弱或异常；先尝后嗅，味干扰嗅觉
水火组水试或火试现象 + 正品平行对照在同等水质、水温、样品量下与正品同现象无平行对照；只凭一次现象（如「水变红」）就判真

【教学设定】本表为课堂判定口径，不是法定判定规则；法定判定以现行版药典该品种性状项为准，并服从所在机构的验收制度。

三、成组判据与水试火试的「不成立」条件【教学设定】

水试与火试之所以好用，是因为它们检的是行为而不是外观，仿制外观容易，仿制行为难。水试看沉浮、颜色变化、膨胀、溶解、乳化、旋转、起泡：苏木投热水染成鲜红，加酸变浅、加碱复深；红花浸水成金黄而花本身不褪色；西红花浸水成金黄，柱头膨胀呈喇叭状，橙色成分自柱头呈直线下降扩散；秦皮水浸液在日光下显碧蓝色荧光；熊胆粉末入水在水面旋转并呈黄线下沉不扩散（挂线）；蟾酥遇水泛白起泡；胖大海膨胀成海绵状；青黛撒于水面漂浮不沉。

火试看火焰、烟雾、气味、灰烬与爆鸣：海金沙置火焰中爆鸣闪光、几无灰烬；血竭火烧熔化、有呛鼻气味而无松香气、灰烬暗红；沉香、降香燃之浓烟浓香；麝香仁灼烧初则迸裂、随即熔化膨胀起泡似珠、香气浓烈、灰烬白色或灰白色。

三、成组判据与水试火试的「不成立」条件【教学设定】

这些现象的反面才是判据的价值所在：红花水色深红浑浊、花迅速褪色，多系染色；海金沙爆鸣声弱、灰烬多，提示掺沙；血竭冒浓黑烟、有松香气，提示掺松香；熊胆水试无挂线或扩散过快，提示以猪牛羊胆充。没有正品平行对照的现象，一律不作结论——同一现象在不同水温、不同样品量下可以完全相反。

性状鉴定的天花板也在这里写明：近缘种、破碎不完整的药材、粉末、掺伪细微者，单凭性状难以定论，须转显微、理化乃至分子方法复核；干燥程度、产地加工、贮存时间都会改变性状表现。性状是先导，不是终局。

四、记录字段、四种失效与考核项

记录的质量决定结论能不能被复核。字段按药典性状项的顺序排，术语用药典与教材的通行表述，忌方言俚语与含混之词。

字段要求
品名与部位中文名 + 药用部位 + 商品规格（统货／选货）
八项描述形状、大小、色泽、表面、质地、断面、气、味，逐项写，不合并
特异术语芦碗、过桥、怀中抱月、金井玉栏、菊花心、云锦纹、星点、朱砂点等，须旁注在样品上的观察部位与形态
试验记录水试的水质、水温、样品量、观察时间；火试的器具、样品量、现象；是否设正品对照
观察条件光源（自然光／其他）、样品状态（干燥／回软）、放大倍数
结论与签署与药典性状项逐条对照的结果；观察人、复核人、日期

四、记录字段、四种失效与考核项
  • 只看单一指标：颜色像就放行，或气味对就认定。伪品专攻单项，硫熏能让色泽统一变白，染色能让断面颜色一致。
  • 名词与实物不对应：报告写「具菊花心」，样品断面却无放射状纹理；写「过桥」，指的是黄连根茎的平滑节间，不是任意一段光滑面。术语一旦脱离所指特征，就退化成了形容词。
  • 取样不具代表性：只挑好看的几支观察。药材批内差异常在大小与干湿上，挑样等于自造结论。
  • 口尝不合规：尝了毒性药材，或尝后不漱口就接着尝第二味。这是安全问题，不只是记录问题。

考核项（本章）：① 给一份只写了「形、色、气、味」四项的验收单，指出缺的四项各自会漏掉什么风险；② 用八项描述一种根类药材，其中至少三项须落到教材术语并说明观察部位；③ 设计一组水试对照，说明为什么必须设正品平行样；④ 指出「颜色变白」这一现象在判真伪时的两种相反解释，以及如何用其他项排除其中一种。

代价与边界
  • 易学难精，且难在言传。 「一摸一掂」的干湿判断、滑腻与细腻的手感差别，文字只能指路，须在实物上反复对照才能建立。本章给的是判据结构，不是手感的替代品。
  • 术语是压缩，也是风险。 「狮子头」「鹦哥嘴」这类词便于记忆，但它压缩掉的是「在哪个部位、什么条件下可见」。背词不认物，是性状鉴定最常见的塌陷方式。
  • 本章不含具体规格等级标准。 三七按每 500 g 含头数分档、枸杞按单位重量粒数分级，这类商品分级属行业与团体标准，与药典的质量判定各司其职；本章只指出「大小是数量化判据」，不替商品标准下结论。
  • 感官数据不可外推。 本章描述的现象都是「在该条件下」的观察；换水温、换样品量、换观察人，结论可能不同。凡进报告的观察，必须连条件一起记录。
