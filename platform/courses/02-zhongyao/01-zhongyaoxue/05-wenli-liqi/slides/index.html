2 / 8motto
PROBLEM

「寒」和「滞」在门诊描述里几乎是同一句话——「肚子胀、发凉、吃不下」。于是你很容易把温里药与理气药当成同一堆「暖胃顺气」的药，谁在场就用谁。可这两组药一味往下走（肾、心），一味往外走（肝、肺）；用错方向，胀不会消，人会更虚。

3 / 8problem
双根因定位

环境逼迫(脘腹冷痛、胀满、呕吐、疝痛在一个诊室里连着出现，患者自述分不清「冷」还是「堵」，医生必须在几分钟内决定温还是行) + 知识积累(把 19 味药的「气—味—归经」拉成两条可以互相比较的轴，才看得见温里与理气各占哪一段)

5 / 8objectives
核心概念

中医：寒与滞是两件事，虽然常同时出现

教材把这两章分开写，因为它们治的是两种不同的病理状态：

教材章组病机代表功效动词代表药
第 15 章温里寒——阳气不足，温煦失职温中、散寒、回阳、助阳附子、干姜、肉桂、吴茱萸
第 16 章理气滞——气机不畅，升降失常理气、行气、破气、降逆陈皮、枳实、木香、香附

教材·第15章·15.1 的附子被写作「回阳救逆第一要药」，干姜是「温中散寒要药」——这两个词都在讲把温度推回来。教材·第16章·16.1 的香附是「气病之总司，女科之主帅」，陈皮讲「治痰先治气，气顺痰自消」——这两个词都在讲把通路打开。

关键差别在方向。温热之力的靶点偏下、偏内：肾阳、心阳、脾胃之阳，是一条纵线。行气之力的靶点偏外、偏上：肝的疏泄、肺的宣降，是一条横线。临床上两者常并用（寒凝则气滞，气滞则寒生），但并用的前提是知道自己在补哪一段，而不是「都暖都顺」。

AI/工程：把归经频次变成两个比值

归经是类别，不能相加，但可以数。数完除以药数，就得到「平均每味药命中几条某类经络」。本章把 12 条归经折成两组：

text
纵向轴 = (归肾 + 归心) / 药数     ← 下焦与心，温阳的去处
横向轴 = (归肝 + 归肺) / 药数     ← 肝胆与肺，行气的去处

这不是临床权重，只是把「药力落在哪」换了个分母看。它的价值在于可比：两组药数不同（8 vs 11），频次直接比会失真，除以药数之后才能放在一张表里。

四气则用有序标度折成分数（大寒 −4 … 平 0 … 大热 +4），再求组内均值。这样「温里整体比理气热多少」从一句形容词变成一个数。

四行数字读出四件事：

  1. 热性均分差 3.9 倍（2.88 vs 0.73）。温里是「加温」，理气只是「疏通」，后者不需要热。
  2. 辛味几乎全覆盖（8/8 与 9/11）。辛能散能行，是两组唯一的公共语言——这解释了为什么临床上「辛香」二字能把两组混为一谈。
  3. 苦味是分水岭（1/8 vs 10/11）。理气药靠苦泄、苦降把气往下推；温里药一旦苦，就变成「辛开苦降」，重心从温阳滑向调气（吴茱萸正是那一味）。
  4. 归经第一都是脾（7 与 7）。这是本章最容易被误读的一格：同一个首经，不同的第二、第三经。温里第二是肾（6）、第三是心（3）；理气第二是胃（7）、肺（4）、肝（4）。首经相同，走向相反。

四气分布（19 味）

味数2391211

跨度：温里 2 → 4（小茴香/丁香/花椒 → 附子/肉桂），理气 −3 → 2（川楝子 → 陈皮/青皮/木香/乌药/佛手/薤白）。

温里 8 味无一味低于「温」，这不是编排上的巧合，而是定义使然：低于温就不叫温里药了。理气药则必须跨到寒侧——川楝子「疏肝泄热止痛，兼能杀虫」，取的是苦寒泄肝火，与温热毫无关系；枳实微寒、破气消积要药，破的是实积而不是寒凝。如果一组药的属性可以由组名推出，那这组药就不需要单独学；理气需要，因为它跨了温寒两侧。
