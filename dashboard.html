阻塞项 · 与解除条件

103 个 DSU 缺属性字段

为什么：源平台 kg/ 下那 7 个病证单元文件未随资料来；disease 12/103、icd 7/103、dsym/ssym/formula/zf/six 全 0/103
影响：嵌入层的 /diag 与 /bianzheng 端点命中率 1/3；这是「没有描述可嵌入」，不是模型问题
解除：给 103 个 DSU 写真正的描述（病因/病机/主症/舌脉/治法）—— [textbooks] 线的产出物

ICD-11 中文通道未验证

为什么：WHO API 需 client_id/secret（无凭据一律 HTTP 401）；本地库是英文 MMS
影响：规格里「中文搜索 → Foundation ID」这条路一次都没跑通过
解除：https://icd.who.int/icdapi 注册 → 设 ICD11_CLIENT_ID / ICD11_CLIENT_SECRET

PDF/EPUB 不可用

为什么：本机无 pandoc
影响：[textbooks] 只能到 Markdown + 单文件书 HTML
解除：装 pandoc（或确认 HTML 已够用）

4 个旧二进制 .xls 读不了

为什么：OLE2/BIFF8 需复合文档 + BIFF 记录 + SST 解析
影响：《黄帝内经全文》《素问灵枢》等 4 份源资料在库外（是能力缺口，不是资料不存在）
解除：补 BIFF8 读取器（独立工作量）

源数据三处内部不一致待裁定

为什么：颜色公理未定义 c_i；源实现 comp() 与 Python hex 互不相符；类经图翼方位色已实测排除
影响：语义张量的颜色无法从源复现（已用同规模随机调色板对照排除该路径）
解除：需源实现 kg/semtensor/axioms.py + encoder.py（F:\tcm\tcmP 已查不存在）
