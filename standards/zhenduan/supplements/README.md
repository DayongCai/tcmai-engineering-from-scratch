# standards/zhenduan/supplements —— 教材缺口的外源补录层

## 0. 一句话

**底本一个字不改。** 教材（`standards/zhenduan/底本.json`，14 章 / 46 节 / 105 小节 / 196 段 / 22,215 字，sha256 `051d830a…`）
缺什么就如实留账；缺的部分在**本层**补录，两笔账分开算。

引用本层任何一条，一律写「**外源·笈成·<书名> <篇卷>**」，
不得写「底本」「原文」，也不得把补录条目并进 `底本.json`。

## 1. 立约（先有约定，再落条文）

| 项 | 约定 |
|---|---|
| 提供方 | 中醫笈成（漢リポ 文字化本）`https://jicheng.tw/tcm/book/<书名>/index.html` |
| 留档 | `supplements/sources/<书名>.html`，逐份记字节数与 sha256 |
| 改写 | 只做繁→简的**引用层**显示（`opencc t2s`），留档文件不改；比对名称时两边都转简 |
| 引用格式 | `外源·笈成·脈經 卷一·脈形狀指下秘決第一（二十四種）第N条` / `外源·笈成·景岳全書 卷之一·傳忠錄·十問篇（九）` / `外源·笈成·黃帝內經素問 金匱真言論篇第四` |
| 记账 | 每条补录都带 `textbookLocator`（教材缺在哪）+ `locator`（外源在哪），缺一不可 |
| 拒补 | 古籍里**不存在**的（如误差率），明确标 `refused` 并写理由，不许拿古籍充数 |

## 4. 三条必须记住的结论

1. **「缓」是唯一一个「正文有、标题无」的脉名。**《脈經》二十四種里它在第十九位左右有定形描述；
   但**不许**拿二十四種去改教材的 28 脉体系——教材多出长、短、疾、牢四名（《脈經》无）。
2. **十问变八节不是教材漏抄。** 景岳原书十問篇也只写到「八問渴」；第九、第十问只有歌诀一句
   「九因脈色察陰陽，十從氣味章神見」，两书都没有这两问的问答段。
3. **误差率必须拒补。** 拿《素問》《脈經》去「补」误差率是伪造证据。教材 0 个百分号是实测，
   补录层不许假装补上了。

## 5. 边界

- 三份源都是笈成的**文字化本**，未与宋本/人卫校注本逐字校勘；引用只能声称「笈成本如此」。
- 脈經/景岳全書两份留档是**部分下载**（见上表「完整性」），所取篇卷完整，但不代表全书。
- 本层只补「教材没展开/没分级/标题漏收」的项，不补教材没有的章节体系。
- 与 `standards/jichu/supplements/` 同一套立约方式，但两门课的外源层**各自独立记账**。
