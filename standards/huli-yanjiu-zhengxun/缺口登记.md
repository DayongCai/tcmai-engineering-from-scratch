**两处取件说明**：

1. **COSMIN** 是表单体清单，条文取「Box 2/3/4/6/7/9/10」处的**九项测量属性标题**（内容效度、结构效度、内部一致性、信度、测量误差、结构效度假设检验、反应度）。Box 内的评分格用于评价单个研究，不作条文引用。
2. **伦理审查办法**：`nhc.gov.cn` 原页对本机 IP 返回 **412（反爬）**，正文改取自**北京大学医学部伦理委员会转载页**（同文），由脚本去标签落盘为 `ethics-review-measures-2023.txt`，只保留第一章至第五十四条正文。builder 为此新增 `.txt/.md` 文本快照分支（`kind: text-snapshot`，pages 为 null）。

**仍未入库**：赫尔辛基宣言（WMA）、CIOMS 指南、知情同意书模板、跨文化效度与自编量表的构建方法——这四项是第 8 章与第 4 章的剩余缺口，写章时已在 N.3 逐条标注。

**JBI 手册为什么条文 0 条**：整本 21.5 MB / 481 页，若进逐字校勘语料，builder 每次要对每页做三等分栏提取，`npm run check` 会从 ~3 分钟涨到 5 分钟以上；收益（5–6 条与核查表覆盖度相近的条文）不划算。故按 `referenceOnly` 登记（sha256 / 字节 / 页数照算，`kind: reference-only`），保持「标准源镜像在本机」这条约定，同时不让每次 check 变慢。将来若要为「循证实践」章补条，去掉 `referenceOnly` 再挂锚点即可。

**Cochrane Handbook 的取件方式要写明**：官方只提供在线章节页（无 PDF 下载），本库用浏览器 headless 打印成 PDF 快照，`url` 记官方章节地址、`issuer` 记「官方在线版，headless 打印快照」。这不是转载，是**同一页面的可核快照**；页面若改版，`--check` 会因 sha256 变化被重跑发现。
