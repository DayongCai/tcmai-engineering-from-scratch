# ICD-11 嵌入评测（复现上游论文的指标口径）

由 `node scripts/icd11_embeddings.js` 生成，数据 = 本仓库 `data/icd11/`。

## 参照

- 仓库：`marcolomele/vectorization-ICD11`
- 论文：Descriptions are all you need: Semantic Vectorization of Hierarchical Medical Knowledge (ICD-11) via Large Language Models (Bocconi, 2025)
- 数据：13,960 ICD-11 entities —— 与本仓库 data/icd11/ 同一份（definition 为空 7,066 条与论文数字吻合）
- 聚类目标：**ICD-11 章节（chapter）**（不是自选的类别）
- TF-IDF 配置：3,000 features（论文 "3,000 features with SVD reduction"）

## 本次对照：只改一个变量 —— 输入文本

分层抽样 **1171** 条 / 26 个章节 · TF-IDF 3000 特征（两条件同一套词表参数）。

| 指标 | 仅标题 | 标题 + full_text | 论文（供参照） |
|---|---|---|---|
| 轮廓系数 silhouette（越大越好） | 0.0225 | 0.0391 | — |
| CH 指数（越大越好） | 3.0539 | 4.2408 | — |
| DB 指数（**越小越好**） | 3.3109 | 3.8715 | — |
| 簇内平均距离 | 0.9435 | 0.9085 | — |
| 簇间平均距离 | 0.9922 | 0.9771 | — |
| 簇分离比（越大越好） | 1.0516 | 1.0755 | — |
| 章节熵 (bit) | 4.6903 | 4.6903 | — |
| 有效章节数 | 25.817 | 25.817 | 26 |
| 层级一致性 1-符号 | 32.79% | 42.37% | 论文 PubMedBERT 92.33% |
| 层级一致性 4-符号 | 4.75% | 5.71% | 论文 PubMedBERT 75.13% |
| 　└ 1-符号随机基线 | 3.72% | 3.72% | — |
| 　└ 1-符号相对基线倍数 | 8.81× | 11.38× | — |

## 结论

**"描述才是关键"在本机可复现**：只把输入从「仅标题」换成「标题 + full_text」，
轮廓 +0.0166、
CH +1.1869、
簇分离比 +0.0239、
1-符号 +0.0958（相对基线 8.81× → 11.38×）
—— 六项里五项变好，**DB 指数变差 0.5606**（这一项不跟着走，如实记下，不挑好看的报）。

## 不要误读这些数字

- 距离用余弦（论文用欧氏）→ 轮廓/CH/DB 的绝对值与论文不可直接比，只可看**方向与相对变化**。
- 不做 SVD 降维（纯 Node 截断 SVD 需迭代特征分解）→ 直接在 3000 维稀疏 TF-IDF 上算余弦。口径差，不是等价实现。
- 按章节分层抽样，不是 13,960 全量（全量两两距离 2e8 对，纯 JS 跑不完）；样本量见各条件的 sample 字段。
- 只做 TF-IDF 一支（论文做了 7 个模型）。论文自己的结论是 TF-IDF 在层级保持上弱于 PubMedBERT，故此处复现的是**下限**。
- **不报 trustworthiness / continuity**：这两项衡量降维保真度，而本脚本不做 t-SNE/UMAP/SVD，没有低维坐标可比。硬填一个假坐标会得出无意义的数，所以不填 —— 该指标在 lib_metrics.js 里实现并单测，留给真正做降维的调用方。

**绝对水平不可比**：绝对水平**不可与论文比**：论文是 PubMedBERT 级模型 + 800 字符描述 + 13,960 全量（1-符号 92.33%）；本处是 TF-IDF + 标题（或 407 字符 full_text）+ 分层抽样。**可比的是"只改输入文本这一件事"的方向与幅度**，以及相对随机基线的倍数（symbol*LiftVsChance）。

（DB 指数**越小越好**，其余越大越好；正号＝加了描述之后变好。）
