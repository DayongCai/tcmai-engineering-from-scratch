## 3. 数据形状

```jsonc
{
  "meta":   { "policy": "值不冒充教材……", "citeFormat": "正文写 [[nv:<id>]]" },
  "mooc":   { "status": "unreachable", "blocker": "...", "consequence": "..." },
  "sources":{ "S1": { "file": "...", "bytes": 3719222, "sha256": "...", "number": "WS/T 405—2012", "locator": "表1", "evidence": "行业标准" } },
  "entries":[ { "id": "S1-WBC", "item": "白细胞计数（WBC）", "value": "3.5~9.5", "unit": "×10⁹/L",
                "group": "男/女", "chapters": [3], "source": "S1", "locator": "表1 p1", "quote": "白细胞计数(WBC)" } ],
  "pending":[ { "item": "体温（口腔/腋下）", "chapters": [7], "why": "...", "need": "..." } ]

```

- `value` 保持原文写法（`<120`、`120~139`、`≥6.1，<7.0`），不转成数字，避免「区间被压成一个点」。
- `chapters` 是挂靠关系，可多章（钙磷镁同时挂第 8、9 章）。
- `quote` 是该行在原文中的项目名，供回查；`locator` 精确到表号/页码。

### 「体温 / 心率 / 呼吸频率」这三项的实际情况（2026-10-30 复查）

我先前笼统说过「中国没有对应行业标准」，**这句话对一半、错一半**，查清后改成分条结论：

| 项 | 查到了什么 | 怎么入库 |
|---|---|---|
| **静息心率** | 《中国高血压患者心率管理多学科专家共识（2021年版）》原文：「传统上正常窦性心律的定义为 60~100 次/min。**但这一定义只是早年专家们的一种共识，没有经过任何科学验证**」；该共识把干预切点定为静息心率 >80 次/min | **入库 2 条**（S14）：传统定义 60~100、干预切点 >80。入库时把「出处本身在质疑它」写进 `note`——这比单纯给一个 60~100 更有教学价值 |
| **体温** | 卫生行业标准里没有「正常体温区间」；但**国家/省级防控文件**把「发热」定为腋温 ≥37.3℃（湖北卫健委手册两处原文） | **入库 1 条界值**（S15）：发热判定界值 37.3℃；**「正常区间」仍 pending**，因为口温 36.3~37.2 一类数字只出现在科普站与百科 |
| **呼吸频率** | 只有科普站、百科与维基给 12~20 次/分；中国无参考区间标准或共识（急诊预检分诊类文件给的是分诊阈值） | **仍 pending**，`why` 里写明「查过什么、剩下的在哪」 |

**这条经验要记住**：说「没有标准」之前，得区分三种东西——① **参考区间标准**（WS/T 404 那类）、② **指南/共识里引述的定义**、③ **政府文件里的判定界值**。三项缺的是①，不是全都没有；把②③当成①用会误导，但把它们当「根本没有」也会漏掉真能用的数。

两条必须写在明面上：

1. **404.5 的四组值不是啰嗦，是事实**——尿素与肌酐都随年龄上移（肌酐上限 97→111 / 73→81）。只给一个「正常值」就等于抹掉年龄差，所以这一层宁可 8 条也不压成 2 条。
2. **404.10 按 8 种分析系统分列**（罗氏/贝克曼/雅培/西门子/迈瑞/安图/迈克/新产业），区间随系统而异。本层只取**罗氏**列，并在 `group` 里写明「成人 ≥18 岁·罗氏分析系统」，**不跨系统混用**；标准注 6 还写明不适用于 <18 岁与妊娠女性。

**尿酸没补到**：WS/T 404 系列只覆盖尿素与肌酐，不含尿酸；尿酸的在《中国高尿酸血症与痛风诊疗指南》里，本次未取到可核验原文，继续 pending。

### 第 8 章肾功组的最后一次闭合（尿酸 + eGFR）

| 项 | 值 | 来源 |
|---|---|---|
| 高尿酸血症判定切点 | 血尿酸 **>420 μmol/L**（不分男女，非同日 2 次空腹） | 高尿酸血症多学科共识 2023（S16） |
| eGFR 分期 | G1 ≥90 / G2 60~89 / G3a 45~59 / G3b 30~44 / G4 15~29 / G5 <15 | 中国 CKD 早期评价与管理指南 表2（S17） |
| CKD 判定（肾功能腿） | eGFR **<60** 持续 >3 个月 | 同上 |

**一个必须写明的口径分歧**：2019 版《中国高尿酸血症与痛风诊疗指南》用的是**性别分层**（男 >420、女 >360 μmol/L），2023 版多学科共识改成**不分男女 >420**。本层取 2023 口径（有原文 PDF），并在 `S16.note` 里保留 2019 的性别分层说法——两个都写出来，读者才知道「420」不是唯一说法。

**eGFR 分期不是「正常值」而是「分级界值」**：G1 与 G2 在缺乏肾损伤证据时都不诊断为 CKD；CKD 的判定腿是 <60 且持续 3 个月。这三件事分开写，是为了不让「G2 就正常」这种误读发生。

这三条是**教科书级通行值，没有标准号、没有原文页**。所以本层的处理比对待标准还严：

- 来源标 `provenance: "oral"` + `attestedBy` + `attestedAt`，**`file`/`sha256`/`url` 一律为 null**——不许拿一个空字段假装有原文。

- CLI 输出会带「（口授·无原文）」后缀，查 `--source S18` 会打印升级路径。

**为什么留着这个口子**：教材层一个字不给值（`valueLike = 0`），这三项又找不到中国标准。要么永远空着，要么承认「这是人给的、可追溯但不可引原文」。选择后者，但把不可引这件事写在数据里，而不是留给读者猜。

### 「缺」与「不给」是两件事：pending vs byDesign

| | 含义 | 例子 | 处理 |
|---|---|---|---|
| `pending` | **本层没找到**可核验来源，值本该有 | 动脉血气、正常体温区间 | 写明「查过什么、还缺什么」，不许写数值 |
| `byDesign` | **来源本身刻意不给值**（这里是教材） | 细胞电生理（静息电位/阈电位/动作电位幅度） | 写明依据（`valueLike = 0`）与后果，不进 pending、不算缺口 |

把这两类混在一张清单里，会让「教材的取舍」看起来像「我们的失职」——第 2、10 章因此被误读成没做完。现在门第 12 项强制两者互斥。

### 正文怎么用起来：`[[nv:ID]]` 引用段

每章 `docs/zh.md` 在「代价与边界」之前有一节 **「本章的界值在哪里（不在本章正文里）」**，由 `scripts/wire_normal_values_refs.js` 生成，列 3–9 条「说法 → `[[nv:ID]]`」。

7 章有值，共 **59 个引用**（第 3 章 9、第 4 章 6、第 5 章 8、第 6 章 8、第 7 章 9、第 8 章 11、第 9 章 8）；4 章没有挂载值，那一节换成「为什么没有值」（第 1 章：绪论不吃数值；第 2、10 章：细胞电生理属 byDesign；第 11 章：教材每节都用边界句替代数字）。

**为什么不是把数字塞进句子**：教材原文一处数值都不给，正文的任务是把「关系」讲清；数值一进句子，读者会记数而忘关系。所以正文只出现 token（不带数字），值仍在文末 NV 块里——**两笔账分开，但正文真的用起来了**。

门第 13 项守三件事：11 章都有这一节且与脚本现算一致；有值的章 ≥3 个引用且每个 token 都存在并属于本章；无值的章必须写明为什么没有值；全仓引用合计 ≥40。

## 6. 三道边界
