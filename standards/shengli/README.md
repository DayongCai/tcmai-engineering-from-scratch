# standards/shengli —— 生理学底本与单元层

## 1. 这是什么

《生理学》（72 学时·QHZY 版）工作簿的**机器可读化**：底本三级结构 + 逐小节单元层（学习目标、正文、三视角与四层级的词频、数值核验）。

**底本一个字不改。** 它自己声明「不写数值与单位与正常值」——本层把这个声明**当成可核验的断言**来检查（见 §4）。

| 项 | 值 |
|---|---|
| 文件 | `E:\textbooks\qhzy-生理学.xlsx` |
| 字节 | 411,687 |
| sha256 | `283daac82059…`（全值见 `底本.json` 的 `source.sha256`） |
| 工作表 | **27 表 = 11 内容章（01–11）+ 16 前置/平台表** |
| 规模 | **11 章 / 44 节 / 132 小节 / 132 有正文 / 228,672 汉字** |
| 单元 | **132 个**（一小节 = 一个知识单元） |

前置 7 表（0封面 / 0历史 / 0改写说明 / 0映射1-3 / 0目录）与平台 9 表（0分布式体系 / 平台建设与依赖 / ICD11统一命名 / 病证单元库 / 多智能体协同 / 兼容性思维流 / 可复用Skills / 平台支撑完整性 / 平台度量）不进底本，行数在 `METHOD.json` 留档。

## 2. 产物

| 文件 | 内容 |
|---|---|

## 3. 这本书的结构特点（与中药学、方剂学都不同）

**没有段标题。** 每个小节恰好两行：

| 段号 | 内容 | 本层落点 |
|---|---|---|
| `段=1` | **口径句**：小节名 + 括注约束，例「生理学的研究对象和任务（只写结构与功能与机制的类别与关系，不写数值与单位与正常值，不作诊断与正常与异常判定）」 | `brief` |
| `段=11` | **正文**：以 `【学习目标】` 开头，后接正文、`【本节要点】`、`思考题` | `body` + `goals` |

四种括注变体，覆盖全部 132 小节：

| 括注 | 小节数 |
|---|--:|
| 只写**过程与调节与机制**的类别与关系 | 60 |
| 只写**结构与功能与机制**的类别与关系 | 36 |
| 只写**调节与整合**的类别与关系 | 24 |
| 只写**感受与转换**的类别与关系 | 12 |
| **合计** | **132** |

四者的后半句完全一致：「不写数值与单位与正常值，不作诊断与正常与异常判定」。

## 4. 口径核验：这本书真的一个数值都没写

底本自己说「不写数值与单位与正常值」。本层逐字核了一遍：

| 证据 | 值 | 说明 |
|---|--:|---|
| 阿拉伯数字字符 | 304 | 全部是**列表序号**（296）与**交叉引用/编号**（8，如「第2章」「SL-01」「T01」「E1」） |
| **数值型（数字＋计量单位）** | **0** | 无 mmHg / kPa / % / mmol / mV / 次每分 之类 |
| 「正常值 / 参考值 / 正常范围」出现 | 156 次 | **全部是边界声明**（「凡涉及生理常数与参考值与正常值…由现行规范与机构制度为准」），没有一处给出数值 |
| 学习目标 | 11 处（每章一处）/ **77 条** | 章级目标，落在每章第一个小节 |

所以这本教材是**纯类别与关系**的写法：它讲「压力差决定血流方向」，不给「正常血压 120/80」。这不是缺陷，是本书的取舍——但**任何需要正常值的场景都要另立数据层**，不能从这本书推。

## 5. 三视角与四层级（用户口径：代谢/机能/形态 × 细胞/组织/器官/系统）

对 132 个单元正文做词频统计（词表见 `scripts/build_shengli_text.py` 的 `VIEWS` / `LEVELS`）：

| 三视角 | 命中 | | 四层级 | 命中 |
|---|--:|---|---|--:|
| 机能 | **3,922** | | 细胞 | **1,453** |
| 形态 | 1,709 | | 器官 | 1,445 |
| 代谢 | 854 | | 系统 | 963 |
| | | | 组织 | 353 |

读出两件事：① 本书以**机能**为主轴（是方剂、中药那几门课没有的）；② 层级落在**细胞与器官**上（各 1,400+），**组织**最弱（353）——「组织」在这一版里是过渡层，讲得最薄。

## 6. 解析踩到的坑

1. **章名只在表名里**：`04 血液循环` 才是章名，首行数据是节标题（`4.1 心脏的泵血功能`）。
2. **段=1 不是标题**：它是口径句，与小节名重复但带约束；当成标题存会把「不写数值…」这句丢掉，而那正是本书最重要的元信息。
3. **数字要先分类再断言**：直接数 `\d` 得 304，看起来像「写了一堆数值」；按「列表序号 / 编号 / 数值型」分开后才是 **0 个数值**。不分类就下结论，会得出与事实相反的判断。
4. **学习目标是章级的**：11 处 / 77 条，落在每章第一个小节；按「每小节都有目标」去断言会失败。

## 7. 引用口径

正文引教材：`教材·第N章·N.M.K`，例 `教材·第4章·4.1.1`。**不许写「底本」「原文」**——有教材底本的学科，引文就是教材正文。

## 8. quiz 引证（语义门的可核部分）

11 章 66 题，每道题的解析末尾都标了引证，形如 `（依据教材·第4章·4.1.1）`。三类分工与判据见 `scripts/lib_quiz_semantics.js`：

| 类型 | 含义 | 门是否核 |
|---|---|---|
| `依据` | 这一节正文就是答案来源 | 核：正文须覆盖正确答案内容词 ≥15% |
| `口径见` | 这一节规定的是本题口径/边界（「本书不给值」类） | 不核 |
| `前提` | 前置题（pre）问「进本章之前要具备什么」 | 不核 |

实测：**66 / 66 题有引证 · 硬错 0**，`依据 43 · 口径见 14 · 前提 9`。另有软警 21 题「解析更贴近某个干扰项」——抽读过多为解析在解释「别人为什么错」，属字面法的固有假阳性，列清单供人看，不判红。

补证流程（可复用）：`node scripts/quiz_cite_helper.js shengli <章号>` 列出每题 3 个候选节与覆盖率 → 人判类型与节号 → `node scripts/apply_quiz_cites.js shengli <assign.json>` 幂等写入。**覆盖率只是排序线索，不是判据**：口径类题在任何一节正文里都覆盖不到答案。

## 9. 运行

## 10. 三轴标签层（`triaxis.json` + 每个单元的 `tri`）

教材按「**代谢 / 机能 / 形态**」三线组织内容，又按「**细胞 → 组织 → 器官 → 系统**」四层递进。这两条不是我们的解读，是书自己的骨架；把它们压成**每个单元一个主标签**，才能回答「全书的重心在哪」「哪一层是空的」。

规则只有三条，全部可复算：

1. 同一单元内按词表逐词 `count` 相加（词表见 `scripts/build_shengli_text.py` 的 `VIEWS` / `LEVELS`）；
2. 主标签取词频最大者，**并列时按词表顺序**取第一个；
3. 全零记 `None`（本次 132 个单元**一个都没有**，说明每个单元都能落位）。

### 10.1 主视角 × 主层级（单元数）

| | 细胞 | 组织 | 器官 | 系统 | 合计 |
|---|--:|--:|--:|--:|--:|
| **代谢** | 1 | 5 | 2 | 6 | **14** |
| **机能** | 24 | 0 | 39 | 27 | **90** |
| **形态** | 22 | 0 | 3 | 3 | **28** |
| **合计** | **47** | **5** | **44** | **36** | **132** |

四句话读这张表：

- **机能主导 90/132（68.2%）**——这是一本讲「怎么运转」的书，不是解剖书。
- **组织层只有 5 个单元（3.8%）**——全书的层级重心在细胞（47）与器官（44），组织只作过渡。这解释了词频里「组织 353 次」为什么垫底：不是词少，是**它几乎不作为单元主旨出现**。
- **形态×细胞 22、形态×器官只有 3**——讲结构时基本停在细胞水平（膜、通道、受体），不上到器官形态。
- **代谢×组织 5 就是那 5 个组织层单元的全部**：代谢这条线在本教材里只以「组织换气/能量代谢」形态出现。

### 7.3 用法

```bash
node scripts/shengli_axis.js              # 3×4 矩阵 + 章级表
node scripts/shengli_axis.js --view 代谢   # 该主视角的全部单元
node scripts/shengli_axis.js --level 组织  # 该主层级的 5 个单元
node scripts/shengli_axis.js --ch 2       # 单章剖面
node scripts/shengli_axis.js 2.4.2        # 单单元两轴坐标与原始词频
```

门 `test_shengli_text` 第 11–14 项守四件事：标签的原始计数与 `measure` 一字不差；主标签必须是 argmax（不许手填）；3×4 矩阵行列和都等于 132；章级主标签与章内词频一致。**手填的标签一旦与词频脱钩，改词表时就会静默失效**——这层最怕的不是算错，是「看起来对」。
