# standards/zhongyao/supplements —— 中药学教材缺口的补录层

## 0. 一句话

**底本一个字不改。** 教材（`standards/zhongyao/底本.json`，30 章 / 74 节 / 342 小节 / 971 段 / 63,865 字）缺什么就如实留账；
缺的部分在**本层**补录或**拒补**，两笔账分开算。

引用本层任何一条，一律写「**外源·笈成·醫學衷中參西錄 <篇名>**」，
不得写「底本」「原文」，也不得把补录条目并进 `底本.json`。

## 1. 立约

| 项 | 约定 |
|---|---|
| 提供方 | 中醫笈成（漢リポ 文字化本）`https://jicheng.tw/tcm/book/<书名>/index.html` |
| 留档 | `supplements/sources/醫學衷中參西錄.html`，记字节数与 sha256 |
| 引用格式 | `外源·笈成·醫學衷中參西錄 <h2 篇名>`；教材侧写 `教材·第5章·5.3` |
| **三档证据强度** | ① **教材示例**：教材原句点名药与趋向（逐字可查）→ 可当条目用 ② **外源线索**：该书某篇同句出现药名与升降浮沉词 → 只当线索 ③ **拒补**：两者都没有 → 不写 |
| 不做的事 | 不按「辛甘温热→升浮」这类规则给 287 味药硬推标注——那是推断，不是数据 |

## 3. 三档证据的差别（最容易被混用的地方）

```text
教材示例 17 味   「升——上升提陷（升麻升阳举陷）」        ← 教材原句，逐字可查，可引用
外源线索 28 味   「某篇里同时出现『升麻』与『升提』」      ← 只是同句，句意在讲什么要人读
无源     249 味   什么都没有                              ← 拒补；不许按性味规则推
```

**为什么线索不能当标注**：一本书里出现「升麻……升提」的句子，可能在讲方剂配伍、在讲误治、也可能在否定某说。
本层只保证「这句话里同时有药名与升降词」，不保证「这句话在给该药定性」。

## 4. 边界

- 《醫學衷中參西錄》是**一家之言**（张锡纯），不是通行药典口径；与教材 5.3 的说法冲突时不作裁决，两条并列。
- 该书写于清末民初，药名与今本教材时有出入（如「䗪虫／地鳖虫」），本层按字面匹配，不做异名归并。
- 教材示例只覆盖 17 味；**任何「287 味的升降浮沉分布」的说法都是错的**——本层没有那个数据。
- `g2`/`g3` 是**课程口径**的缺口，不是教材缺口：教材写得好好的，只是课程 12 章没排进去。
