# 毕设口径通用检查表（v1）

> 提炼自 `01-zhongyi/22-zhongyi-biye-sheji` 第 1 章的九节实践：四类数字、两组敏感性、欠账与台账、合并账与成本口径。
> 适用对象：九个院系的毕设／实践课（`*-biye-sheji`、`*-shijian`、`*-lunzhuan`）。
> 用法：逐项判定「齐备／部分／待补」，每一项都必须能被一条命令或一个文件指认。**答不出「在哪」的，一律按待补计。**

## 〇、这张表解决什么问题

毕设最常见的四种塌方：

| 塌方 | 表现 | 本表对应项 |
|---|---|---|
| 数字来路不明 | 「预计市场 100 亿」「我们的份额 1%」 | 第 1 项 |
| 客户数拍脑袋 | 「三年 500 家客户」，问 SAM 与渗透率答不出 | 第 2 项 |
| 假设冒充实测 | 工时、客单、转化率都不标来源 | 第 3、6 项 |
| 只有结论没有边界 | 报均值不报失效、报回本不报敏感性 | 第 4、5 项 |

## 一、七项检查

### 1. 数字四分类（每张表都要标）

| 类别 | 定义 | 例子 |
|---|---|---|
| 公开数字 | 有发布主体、有年份 | 中医类机构 112,032（2025 公报）；基层中医馆 4.2 万（卫健委 2025-03） |
| 法规条款 | 有条款号 | 广告法第十六条；个保法第二十八条；器械分类界定（2021 年第 47 号） |
| 客群锚 | 用公开量除出来的单位值 | 中医类医院均收入 ≈ 9,100 万/家（5,910.5 亿 ÷ 6,498） |
| 本库假设 | 自己设的参数 | 客单、渗透率、人月单价、转化率、工时比例 |

**判据**：报告里每个数字都能回指到上表某一类，并附来源或「假设」标签。
**不合格**：出现无来源的绝对值（尤其市场规模、客户数、收入预测）。

### 2. 客户数与客群（SAM × 渗透带）

```text
客群 SAM  ← 公开机构数（或明确标注为估计）
渗透带     ← 该客群的合理区间（馆所 0.1%–3%；医院 1%–10%；院校 5%–40%）
客户数     ← min(手设值, SAM × 带中位)，并报隐含渗透率
```

**判据**：能报出 SAM、来源、渗透带、隐含渗透率、以及是否被上限修正。
**不合格**：客户数只写一个数，问「占多少份额」答不出。
**不适用**：纯方法／纯工具类课题（不面向机构销售）须写「不适用—理由」，而不是留空。

### 3. 客单与占比校验

```text
客单 ÷ 客户年营收 ∈ [0.1%, 5%]      或     客单 ≤ 客户 IT 预算上限
```

锚：医院 IT 预算占总预算 1%–2%（CHIMA 2023-2024 调查）；中医类医院均收入 ≈ 9,100 万/家。

**判据**：给出客单、锚来源、占比，并判定是否在带内。
**不合格**：「参考同行定价」——同行是谁、多少，答不出。

### 4. 两组敏感性（成本侧 + 收入侧）

| 侧 | 变量 | 必答 |
|---|---|---|
| 成本 | 人月单价（至少三档，如 1.5／2／4 万） | 投入倍数、毛利倍数、回本中位、排序是否变 |
| 收入 | 客户数（至少三档，如 ×0.5／×1／×0.05） | 毛利倍数、回本中位、**几案转亏** |

**判据**：给出「模型何时开始出现亏损案」这一句。
**不合格**：只说「结果稳健」而没有任何一档缩放。

### 5. 欠账登记（不可计的资产）

| 字段 | 必填 |
|---|---|
| 缺什么 | 具体到文件或表 |
| 依赖什么 | 哪门课／哪份教材／哪次审批 |
| 可计条件 | 满足什么才可以算成本 |

**判据**：不可计项显式列出，且**不按目标体量估**。
**不合格**：把待建资产的成本按「目标章节数 × 单价」估算后混进合计。

### 6. 工时台账（设计／校验／返工）

```text
每案三行：设计 / 校验 / 返工，字段 = 人月、记录人、日期、来源（假设|实测）
```

**判据**：来源字段存在；「假设」不得去掉标签；填 0 或负数视为未填。
**不合格**：只填一个总数，或把经验比例直接当实测。

### 7. 复算入口

```text
一条命令能重跑；参数外置；输出可 diff
```

**判据**：`README` 或 `outputs/prompt-*.md` 里有一条可复制执行的命令，且跑出来的数等于报告里的数。
**不合格**：数字只在截图里，或参数写死在代码里。

## 四、怎么用（三步）

1. 复制 `biye-checklist.json` 模板到本院系毕设课根目录，填「现状」与「七项状态」；
2. 跑 `python scripts/build_biye_checklist.py --check`，看哪几项停在「待补」；
3. 每补一项，把「说明」里写成一条可执行命令或一个文件路径——**写不出路径的，就还没补**。
