## 二、14 章怎么来的

| 章 | 来源 | 依据 |
|---|---|---|
| 1–12 | 底本 1:1（章号章名照底本） | `scripts/plan_neike_14.py` |
| 13 | 本仓综合章：证候—方剂—疗效的因果推断 | 底本无对应章，跨章引 |
| 14 | 本仓综合章：内科分型与 ICD-11 的映射 | 底本无对应章，跨章引 |

旧 14 章是病证式切分（咳嗽与喘证、肺痈肺痿……），把底本一章拆两章、又把两章并一章，
引文章号会来回跳，门没法核；所以按底本重切，另保留两个 AI 桥梁章。

## 三、引文格式

```
「逐字引语，≥6 字，必须能在所引那一章的底本原文里 find 到」——教材·中医内科学·第4章·4.1.1
```

- 三级 locator = **章.节.小节**；
- 底本 12 章：章号必须等于本章（门会逐条核，引到别章即红）；
- 综合章 13/14：**≥5 个不同章号**，每条仍要能逐字回查；
- 每章 ≥10 条。

## 四、数值口径：B 支（底本含 41 处量值）

与药理学同一支：引文行（带 `教材·中医内科学·第N章·M.K`）放行，**正文裸写剂量一律判红**；
要谈剂量只写「剂量与用法照底本」，并保证该章出现一次边界声明（`剂量照底本` / `不构成诊断` 之一）。

## 五、章级契约（6 文件）

| 文件 | 要求 |
|---|---|
| `docs/zh.md` | 8,000–20,000 非空白字；**本章全部节号与小节号逐个出现**（40–55 个也要，用「逐条落位」表）；≥10 条逐字引语；含「代价与边界」「运行与验证」与免责句 |
| `quiz.json` | 6 题：pre / check×3 / post×2；题干键 `question`；每题带 `cite` |
| `code/main.js` | 读 `底本.json` 现算，末行「教学边界：……不构成诊断与用药依据」 |
| `code/main.test.js` | `node --test code/main.test.js` 全过，断言落在可复算结构上 |
| `outputs/prompt-<slug>.md` | ≥300 非空白字 |
| `outputs/skill-<slug>.md` | frontmatter：`name`（= slug 去章号前缀）/ `description` / `version` |

## 六、门与工具

| 命令 | 作用 |
|---|---|
| `npm run neike:check` | 全量门 9 项（14 章） |

| `npm run neike:brief -- <章号>` | 打印该章素材包（全部节/小节号 + 正文开头） |

## 七、不要做的事

- **不要把 40 个小节号当装饰**：门核的是「每个小节号都在正文里出现」，凑号而无内容会在
  「逐条落位」表里露馅——那一列要写本仓的一句理解，不是复制小节标题。
- **不要写疗效断言**（「某方治某病有效」）、不要作诊断与预后判定；底本自己也不这么写。
- **不要用病名代替辨证**：这一门的正文要写「凭什么这么辨」，而不是「某病用某方」。
