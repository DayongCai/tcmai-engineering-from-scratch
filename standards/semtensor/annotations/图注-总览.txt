一、口径（v1.0 仰角口径）
  r  ∈ (0, 1]        径向距离 = 语义张量尺度
  θ  ∈ [-90°, +90°]  仰角 elevation（赤道 0，天顶 +90°，天底 -90°）
  φ  ∈ [0°, 360°)    方位角 azimuth（自 +X 轴起算，绕 +Z 轴逆时针）
  球 → 笛：X = r·cosθ·cosφ ; Y = r·cosθ·sinφ ; Z = r·sinθ

三、轴语义
  X 阴阳轴（左右）   I=阴   O=中（阴阳平和）  T=阳
  Y 表里轴（前后）   I=表   O=半表半里        T=里
  Z 精气神轴（足→首）I=精（形质）O=气（能量）T=神（神志情志）

四、颜色公理
  ramp(t, 轴)：在 [-1, 0, +1] 三色间逐通道线性插值
  w_i = clip(|v_i|, 0, 1) ； k = max(w_i)
  C = (1 - k)·绿 + k·( Σ w_i·c_i / Σ w_i )
  性质：O 点任意轴都回到基准绿；三轴同强趋向三端色加权混合；镜像不变色。
