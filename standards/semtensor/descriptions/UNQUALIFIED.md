# 不合格 2 条：拆构件第二遍定向检索与处理记录

> 2026-10-19。对象是 `external.json` 里 `scope=partial` 的两条。
> 口径不变（见 `EVIDENCE-STANDARD.md`）：不合并两级、不同义改写、证据边界 = 入库 title+snippet。
> 本次的产出不是"把它们救成合格"，而是**查清为什么不合格**，并把查证过程留在数据里。

## 0 做法（与队列批次的区别）

- 不是整串重查，而是**按缺失构件逐条检索**（`、` 拆开后每侧单独查），每次把括注病种带进查询串。
- 取回的来源一律先过"对题"：必须与括注病种（失荣/上石疽、石瘿）同题才入库；
  只与构件字面相同、病种无关的，**不入库**（那是充数，不是证据）。
- 不用 `--requery`：它会把条目整条删掉（原有 4 条溯源来源随之消失），而这两条的来源有描述价值；
  且条目一旦退回队列，再取一批也只能取回同样的"病名类"来源 —— 缺的构件不会因为再查一次而出现。
  改为**在原条目上追加来源**，再用 `--audit` 按唯一口径重算（手改后必须 audit，见标准第 4 节）。
- 追加来源不改变 scope 判定，除非真的补上了缺失构件；本次两条的 scope 未变。

## 1 热毒犯肺、痰瘀阻络证(失荣/上石疽)

| 项 | 值 |
|---|---|
| 构件 | 热毒犯肺 / 痰瘀阻络证 |
| 缺失 | **两侧都缺**（追加 2 条来源后仍缺） |
| 括注 | 失荣、上石疽 = 颈部岩肿（恶性淋巴瘤、颈部淋巴转移癌） |
| 来源数 | 6（原 4 + 本次 2） |
| 判定 | `partial`，不计入任何覆盖数 |

**检索记录**（`web_search`，limit 3–5）

1. `失荣 热毒犯肺 痰瘀阻络证 辨证分型 中医外科学` → 无关（肺结节、脱髓鞘）
2. `上石疽 热毒犯肺 痰瘀阻络证 石疽 治法` → 无关（肿瘤十法、医保代码表）
3. `"热毒犯肺" "痰瘀阻络" 失荣 石疽` → 医保/国标代码表、外感热病、慢阻肺，无失荣页
4. `"热毒犯肺" "痰瘀阻络" 证` → 胸腔积液/支扩考题、香港传染病手册（肺炎类）
5. `淋巴瘤 中医辨证分型 "热毒犯肺" 痰瘀` → 肺癌、乳腺癌放疗后放射性肺损伤、肺痈（全是肺系）
6. `"失荣" "痰瘀阻络" 证` → 经络肢体病证、颈椎病医案（"筋脉失荣"≠失荣病名）
7. `肺癌 中医证型 "热毒犯肺" 痰瘀阻络 辨证` → 放射性肺损伤专论（"热毒犯肺"确为肺系证候）

**教材给出的失荣实际分型**（《中医外科学》总表 2018，已入库为来源 [4]）：

> 03 失荣　气郁痰结 / 阴毒结聚 / 瘀毒化热 / 气血两亏

**最接近的实文**（潘敏求工作室·非霍奇金淋巴瘤医案，已入库为来源 [5]）：

> 恶性淋巴瘤属于中医的恶核、石疽、失荣、痰核等范畴……导致气滞血瘀，痰湿内生，痰、瘀、毒互结而致病……且久病致瘀毒凝结不散。

**为什么不能升级**：失荣的证型表里没有"热毒犯肺"，也没有"痰瘀阻络"；
"热毒犯肺"在本语料里稳定地出现在**肺系**（放射性肺损伤、肺炎喘嗽、肺癌、乳腺癌放疗并发症），
与颈部岩肿不同题。按"特指证据"规则，拿肺系来源去覆盖颈部岩肿的构件就是充数，不做。

**判断**：这更像**证名与病名拼接**的问题 —— "热毒犯肺、痰瘀阻络"的语境是肺系肿瘤/放射性肺损伤，
被挂在了"失荣/上石疽"（颈部岩肿）上。属 DSU 命名层的核查项，不在证据层改写。

## 2 痰气交阻、瘀毒凝结证(石瘿)

| 项 | 值 |
|---|---|
| 构件 | 痰气交阻 / 瘀毒凝结证 |
| 缺失 | **仅剩「瘀毒凝结证」**（「痰气交阻」本次已补上） |
| 括注 | 石瘿 = 甲状腺癌 |
| 来源数 | 7（原 4 + 本次 3） |
| 判定 | `partial`（缺 1 个构件，仍不计覆盖） |

**检索记录**

1. `"痰气交阻" "瘀毒凝结" 石瘿` → 只有石瘿病名页，无该证名
2. `"石瘿" "瘀毒凝结" 证 甲状腺癌 辨证` → 甲状腺癌术后综述、验案（痰瘀阻络证）
3. `"石瘿" "痰气交阻" 证 辨证论治` → **cancer361 甲状腺癌分型综述命中「痰气交阻，血行瘀滞」**（已入库 [5]）
4. `甲状腺癌 中医辨证分型 痰气交阻证 瘀毒凝结证 石瘿` → 同上 + 齐元富经验
5. `"痰气交阻" "瘀毒" 甲状腺癌 证型 四海舒郁丸 海藻玉壶汤` → 中医外科学总表、执医考点
6. `甲状腺癌 中医诊疗方案 证型 "痰气交阻" 瘀毒 瘿瘤 分证论治` → 石瘿病名页、从肾论治经验（已入库 [6]）
7. `石瘿 甲状腺癌 中医 证型 "瘀毒" 凝结 颈部肿块` → **中医外科石瘿证型表**（已入库 [4]）
8. `"瘀毒凝结" 证` → 命中潘敏求淋巴瘤医案「久病致瘀毒凝结不散」（**病种是淋巴瘤，不是石瘿**，故不用于本条）

**教材/文献给出的石瘿实际分型**

- 《中医外科学》体例（中医启疾光，已入库 [4]）：痰凝毒聚 / 痰郁气结 / 毒热蕴结 / 瘀热伤阴
- 人卫《中医外科学》总表（同批入库的失荣来源同书，第 8 章）：痰瘀内结 / 瘀热伤阴
- 综述（cancer361，已入库 [5]）：痰瘀互结 / 肝郁气滞 / 瘀热伤阴 / 气血两虚 / 气阴两虚 / 脾肾阳虚

**为什么不能升级**：三套分型里都没有"瘀毒凝结"。
最接近的实文是"瘀毒内结"（蔡小平，已入库 [6]）与"瘀毒凝结不散"（潘敏求·淋巴瘤），
前者是**同义近形但不是原词**，后者**病种不对**。按口径第 2 节，同义关系只在 `aliases.json` 处理，
判定里不做替换 —— 所以本条停在缺 1 个构件。

**判断**：这条更像"痰凝毒聚 / 痰郁气结"两个教材证型名被合并转写（"痰气交阻"+"瘀毒凝结"），
而不是文献里真实存在的双构件证名。属 DSU 命名层核查项。
