# 第39章 内分泌生理与下丘脑-垂体调控机制（Endocrine Physiology and Mechanisms of Hypothalamic-Pituitary Regulation）

## 学习目标

完成本章学习后，你应当能够：

1. 说出内分泌、旁分泌、自分泌与神经内分泌四种分泌方式的区别，并按化学结构归类激素；
2. 比较水溶性激素与脂溶性激素在受体定位、信号转导与起效速度上的差异；
3. 描述下丘脑-垂体门脉系统与神经垂体直接释放这两条通路的结构基础；
4. 阐释「下丘脑释放激素—垂体促激素—靶腺激素」三级轴及长、短、超短反馈回路；
5. 说明结合蛋白、脉冲分泌与昼夜节律如何影响激素测定的解释；
6. 用至少四种情形解释「激素水平不等于功能状态」，并据此设计评估思路。

## 39.1 内分泌系统的组成与激素的作用方式

**内分泌系统**由分散于全身的腺体与具有分泌功能的细胞构成，包括下丘脑、垂体、甲状腺、甲状旁腺、肾上腺、胰岛、性腺，以及分散在心、肾、胃肠、脂肪组织中的内分泌细胞。它与神经系统共同构成机体的**两大整合调节系统**：神经以电信号与短程递质实现快速、定位明确的调控，内分泌以血液为通道实现较慢、广泛、持久的调控。

按激素到达靶细胞的路径，可区分四种作用方式：

| 方式 | 路径 | 举例 |
|---|---|---|
| 内分泌（endocrine） | 激素入血，经循环作用于远隔靶细胞 | 胰岛素、甲状腺激素、皮质醇 |
| 旁分泌（paracrine） | 作用于邻近细胞，不经循环稀释 | 胰岛内生长抑素抑制邻近细胞、内皮素 |
| 自分泌（autocrine） | 作用于分泌细胞自身 | 胰岛素对 β 细胞的自我调节、生长因子 |
| 神经内分泌（neuroendocrine） | 神经元合成激素并释放入血 | 下丘脑释放激素、神经垂体激素 |

按化学结构，激素分为**肽与蛋白质类**（胰岛素、胰高血糖素、PTH、垂体激素、下丘脑释放激素）、**胺类**（儿茶酚胺、甲状腺激素的酪氨酸衍生物）、**类固醇类**（皮质醇、醛固酮、性激素）与**固醇类/脂肪酸衍生物**（维生素 D 活性形式、前列腺素）。结构决定溶解性，溶解性决定受体位置与信号方式——这是理解全部内分泌药理与病理的起点。

## 39.2 激素作用的细胞机制

**水溶性激素**（肽类、儿茶酚胺）不能自由穿越细胞膜，作用于**膜受体**，通过第二信使把信号放大并转导至胞内：

- 腺苷酸环化酶—cAMP—蛋白激酶 A 通路：多见于促激素类，如 ACTH、TSH、FSH、LH、ADH 的某些效应；
- 磷脂酶 C—IP₃/DAG—钙与蛋白激酶 C 通路：如 GnRH、血管紧张素Ⅱ、儿茶酚胺的 α 受体效应；
- 酪氨酸激酶级联：胰岛素与生长因子类受体自身具有激酶活性，通过磷酸化级联启动代谢与生长效应；
- 鸟苷酸环化酶—cGMP：如心房利钠肽。

这类激素**起效快、时程短**，效应依赖既有蛋白的活性改变，不依赖新蛋白合成。

**脂溶性激素**（类固醇、甲状腺激素、维生素 D）可穿过细胞膜，与**胞质或核受体**结合，形成激素-受体复合物后作为转录因子调控基因表达，改变靶细胞合成的蛋白种类与数量。其特点是**起效慢（以小时计）、时程长（以天计）**，且效应不易迅速撤除——这解释了为什么甲状腺功能减退的临床表现出现缓慢、纠正也需要数周才显现。

**受体的可调节性**是本章的关键伏笔：持续高水平的激素使受体数量减少或敏感性下降，称**下调（down-regulation）**；长期低激素水平或去神经支配使受体数量增加，称**上调（up-regulation）**。受体调节使「激素浓度—生物效应」不再是简单的线性关系，为 39.8 的讨论奠定基础。

## 39.3 下丘脑-垂体单元的结构基础

垂体位于蝶鞍内，借垂体柄与下丘脑相连，分**腺垂体（前叶）**与**神经垂体（后叶）**两部分，二者的调控逻辑完全不同。

**腺垂体**分泌六种激素：生长激素（GH）、促肾上腺皮质激素（ACTH）、促甲状腺激素（TSH）、卵泡刺激素（FSH）、黄体生成素（LH）、催乳素（PRL）。其分泌受下丘脑释放激素与抑制激素的双重控制。关键在于，下丘脑的释放激素并不经体循环到达垂体，而是由正中隆起处的神经末梢释放入**垂体门脉系统**，以很高的局部浓度直接送达腺垂体——这一解剖设计使下丘脑能以极微量激素实现对垂体的精确调控，也使垂体局部微环境成为独立调节单元。

**神经垂体**不合成激素，只储存与释放由下丘脑视上核、室旁核合成的**抗利尿激素（ADH，又称血管加压素）**与**催产素**。因此神经垂体病变表现为「释放障碍」而非「合成障碍」，其功能状态须结合下丘脑与渗透压刺激综合判断。

**临床联系**：垂体位于蝶鞍，其上方紧邻视交叉。垂体占位向上扩展可压迫视交叉，产生**双颞侧视野缺损**；向侧方侵入海绵窦可累及动眼神经与三叉神经分支。头痛伴视野改变是垂体占位的经典组合，提示内分泌病变可以首先以神经科症状出现。

## 39.4 三级轴与反馈回路

绝大多数内分泌功能以**三级轴**的形式组织：

**下丘脑释放激素 → 腺垂体促激素 → 靶腺激素 → 靶组织效应**

以甲状腺轴为例：促甲状腺激素释放激素（TRH）→ TSH → 甲状腺激素（T₄、T₃）→ 全身代谢效应；肾上腺轴为 CRH → ACTH → 皮质醇；性腺轴为 GnRH → LH/FSH → 性激素；生长轴为 GHRH/生长抑素 → GH → IGF-1（主要由肝产生，介导大部分生长效应）。

反馈是这一结构维持稳定的核心机制，按作用距离分三层：

1. **长反馈（long-loop feedback）**：靶腺激素反向抑制下丘脑与垂体。皮质醇抑制 CRH 与 ACTH、甲状腺激素抑制 TRH 与 TSH、性激素抑制 GnRH 与促性腺激素，都是长负反馈。
2. **短反馈（short-loop feedback）**：垂体促激素反向抑制下丘脑释放激素的分泌，如 ACTH 对 CRH 神经元的抑制。
3. **超短反馈（ultrashort-loop feedback）**：释放激素或促激素抑制自身分泌细胞，见于 GnRH 与 GH 系统，使分泌呈脉冲而非持续状态。

负反馈并非唯一模式。**正反馈**在生殖周期中具有决定性意义：排卵前雌激素水平持续升高到一定阶段后，由抑制转为增强 GnRH 与 LH 的释放，形成 LH 峰并触发排卵。这是生理性正反馈的少数范例，也解释了为何生殖轴的调控不能简单套用「升高就抑制」的直觉。

反馈原理的两条临床推论值得牢记：其一，**长期外源激素会抑制整条轴**——长期使用糖皮质激素者，其肾上腺皮质萎缩、内源 CRH/ACTH 受抑，突然停药可诱发肾上腺皮质功能不全；其二，**反馈关系是定位诊断的工具**——同时测定靶腺激素与其促激素，观察二者是否「相称」，即可判断病变位于靶腺、垂体还是下丘脑（详见 40.5）。

## 39.5 反馈之外的调控维度

若只按反馈回路理解内分泌，会把一个多输入系统简化成恒温器。真实调控还包括：

- **脉冲式分泌**：GnRH 以脉冲方式释放，脉冲频率决定 LH 与 FSH 的相对比例——高频偏向 LH，低频偏向 FSH。持续而非脉冲的刺激反而使垂体受体下调、促性腺激素分泌受抑，这正是某些 GnRH 类似物用于抑制性腺轴的机制基础。
- **昼夜节律**：皮质醇呈晨高暮低的节律，GH 主要在深睡眠期分泌，PRL 在睡眠中升高。节律由视交叉上核驱动，与光照、睡眠-觉醒周期耦合。**单点采血若忽略时点，结论可能完全错误**。
- **神经调节**：应激、疼痛、情绪、运动经交感与下丘脑通路改变轴的活动；吸吮刺激经神经反射引起催产素与 PRL 释放，是神经内分泌反射的典型。
- **代谢信号**：血糖、氨基酸、游离脂肪酸、酮体直接作用于胰岛细胞；进食后肠道激素（肠促胰素）放大胰岛素分泌。代谢产物本身就是内分泌信号，构成「代谢—内分泌」闭环。
- **旁分泌与局部网络**：胰岛内 β、α、δ 细胞互相制约；脂肪组织分泌瘦素、脂联素；血管内皮参与激素的活化与灭活。

这些维度共同说明：内分泌系统的输出是**多输入整合的结果**，任何单一测定都只是这个整合过程的一个截面。

## 39.6 激素的转运、代谢与清除

多数激素在血中并非全部游离。甲状腺激素主要与**甲状腺结合球蛋白**及白蛋白结合，皮质醇与**皮质醇结合球蛋白**结合，性激素与**性激素结合球蛋白**结合。只有**游离部分**能进入细胞产生效应，也只有游离部分参与反馈调节。

由此产生一类常见的解释陷阱：**总浓度测定受结合蛋白影响，可能严重偏离功能状态**。妊娠、雌激素治疗、慢性肝病使结合蛋白升高，总激素浓度随之升高而游离部分正常，患者并无功能亢进；肾病综合征大量蛋白丢失、严重肝病合成减少则使结合蛋白下降，总浓度偏低而游离部分正常，患者并无功能减退。反之，若结合蛋白显著下降而总浓度「看起来正常」，游离部分可能已经升高。

激素的**半衰期**差异极大：肽类激素多以分钟计，需持续分泌或频繁给药；甲状腺激素以天计，故替代治疗起效与调整都以周为尺度；皮质醇以小时计但受体后效应更持久。激素主要在肝降解、肾排泄，肝肾功能不全时激素清除减慢，既影响测定值解释，也影响外源激素的作用强度与持续时间。

## 39.7 靶细胞反应性：允许、协同与拮抗

同样浓度的激素在不同个体、不同状态下产生的效应可以相差很大，原因在于靶细胞反应性：

- **受体数量与亲和力**：受体上调使低浓度激素产生足够效应，受体下调则相反；
- **受体后信号效率**：信号分子的表达、磷酸化状态、负反馈调节蛋白的水平决定信号能否有效传递；
- **允许作用（permissive action）**：皮质醇本身不直接收缩血管，但它是儿茶酚胺维持血管张力所必需的条件；缺乏皮质醇时，儿茶酚胺的升压效应显著减弱。这解释了肾上腺皮质功能不全者为何出现难以用补液纠正的低血压；
- **协同与拮抗**：胰高血糖素、肾上腺素、皮质醇、生长激素在升高血糖上相互协同；胰岛素与它们构成方向相反的抗衡系统，形成「一组升糖、一个降糖」的不对称结构——这也是糖尿病在应激下容易失控的原因；
- **竞争与耐受**：结构相似的激素或药物可竞争同一受体；长期刺激导致反应性下降。

## 39.8 「激素水平不等于功能状态」

这是本单元最重要的认识论命题，值得单列一节。以下五类情形足以说明，为什么不能把化验单上的箭头直接等同于功能诊断。

**第一，激素高而功能低下（抵抗）。** 受体或受体后缺陷时，激素水平代偿性升高，而终末效应不足。甲状腺激素抵抗者甲状腺激素升高却表现为甲减倾向；胰岛素抵抗者胰岛素升高而血糖仍高。此时若只看激素水平，会得出与事实相反的结论。

**第二，激素「在范围内」而轴已失衡。** 反馈系统可在相当宽的范围内把激素维持在看似正常的水平，直到储备耗竭才跌破界限：肾上腺轴受损早期，皮质醇仍在范围内，只有在应激时才暴露不足；GH 缺乏者 IGF-1 可能仅处于低限。**正常范围内的低值在高应激需求下等于功能不足。**

**第三，总浓度受结合蛋白干扰。** 如 39.6 所述，妊娠、肝病、肾病可制造「假性亢进」或「假性减退」。

**第四，节律与脉冲的丧失先于水平异常。** 皮质醇节律消失、GH 脉冲减少、LH 脉冲频率改变，往往出现在平均水平仍正常时；而节律本身承载信息——皮质醇的晨峰对觉醒、代谢与免疫的时序安排具有意义。

**第五，终末效应物比激素更能反映功能。** 甲状腺激素的外周转化效率、IGF-1 对 GH 的反映、骨转换标志物对 PTH 与性激素的反映，都比单一上位激素更接近「功能状态」。

**结论**：评估内分泌功能必须把**激素测定、动态试验、靶器官效应与临床表现**四者结合；单点、单指标的判断在逻辑上不成立（如何组织这四者，见 39.9）。

## 39.9 内分泌功能的评估思路

| 层次 | 手段 | 回答的问题 |
|---|---|---|
| 基线测定 | 按时点、按体位、按进食状态采血 | 该时点的激素水平处于什么方向 |
| 动态试验 | 兴奋试验（刺激后反应）、抑制试验（能否被抑制） | 储备能力如何、分泌是否自主 |
| 节律与脉冲 | 多次或连续采样 | 调控模式是否完整 |
| 靶器官效应 | 代谢指标、骨密度、生长速度、生殖功能 | 激素是否真正起效 |
| 定位与病因 | 影像、自身抗体、基因检测 | 病变部位与性质 |

**兴奋试验**用于怀疑功能减退：给予促激素或生理性刺激（如 ACTH 兴奋试验、TRH 兴奋试验、胰岛素低血糖试验、禁水试验的反向逻辑），观察靶腺能否相应升高。有反应提示靶腺储备尚可、病变可能在上位；无反应提示靶腺本身衰竭。**抑制试验**用于怀疑功能亢进：给予外源激素，观察自主分泌能否被抑制；不能被抑制提示分泌自主，常见于腺瘤。

**护理配合要点**：严格按医嘱时点采血，避免在采血前剧烈活动、吸烟、情绪激动；了解患者正在使用的激素类药物（可干扰测定与反馈）；记录采血时的进食、睡眠与应激状态；动态试验过程中密切观察低血糖、脱水、心悸等反应，备好急救条件。

## 39.10 生命周期与内分泌

- **胎儿与新生儿**：甲状腺激素对脑发育具有时限性作用，先天性甲减若未在早期识别，损害不可逆；新生儿筛查是这一原理的公共卫生体现。
- **儿童与青春期**：生长轴与性腺轴依次激活，GH 脉冲幅度在青春期升高，性激素启动第二性征。青春期启动的时间受营养、体脂、睡眠与遗传共同影响，是「代谢信号调控内分泌」的典型例证。
- **妊娠**：胎盘分泌大量激素（hCG、胎盘生乳素、雌激素、孕激素），结合蛋白升高使总激素浓度上升；肾小球滤过率增加与肾糖阈变化使孕期糖代谢呈现特殊模式；胎盘生乳素与皮质醇升高造成生理性胰岛素抵抗。
- **老年**：激素分泌率与清除率同时下降，血中水平可能变化不大而生物学效应减弱；受体敏感性、靶器官反应与储备能力下降；临床表现不典型（甲亢可不发热、不激动，而表现为房颤、消瘦、意识改变），使识别难度上升。
- **应激状态**：急性疾病可重设整个轴的调定点，出现「病态下的内分泌模式」（如重症时甲状腺激素外周转化改变），此时测定的解释必须结合病情而非套用健康人参考。

## 39.11 内分泌、神经与免疫的整合

内分泌系统从不孤立工作：

- **神经对内分泌**：下丘脑是二者的接口，交感与副交感神经直接支配胰岛、肾上腺髓质与甲状腺；
- **内分泌对免疫**：皮质醇抑制炎症与淋巴细胞增殖，性激素调节免疫反应强度，甲状腺激素影响免疫细胞代谢；这也是自身免疫病在性别与年龄上分布差异的部分解释；
- **免疫对内分泌**：自身免疫性腺体炎（桥本甲状腺炎、1 型糖尿病、自身免疫性肾上腺炎）是内分泌功能减退的主要病因之一；细胞因子在重症时抑制下丘脑-垂体轴，造成「非甲状腺疾病综合征」式的激素改变；
- **代谢对三者**：能量供给状态改变激素分泌、神经递质合成与免疫应答，营养因此成为内分泌调节的底层变量。

理解这个网络，才能理解为什么一个腺体的病变会在多个系统留下痕迹，也才能理解第 40–42 章反复出现的「多系统共病」现象。

## 本章小结（Key Points）

- 内分泌以血液为通道实现较慢、广泛、持久的调控；激素按结构分为肽类、胺类、类固醇与固醇类，结构决定受体位置与信号方式。
- 水溶性激素经膜受体与第二信使快速起效；脂溶性激素经核受体调控基因表达，起效慢、时程长。
- 腺垂体经垂体门脉接受下丘脑释放激素；神经垂体只储存与释放下丘脑合成的 ADH 与催产素。
- 三级轴（释放激素—促激素—靶腺激素）以长、短、超短负反馈维持稳定；排卵前雌激素的正反馈是重要例外。
- 脉冲分泌、昼夜节律、神经与代谢信号共同塑造内分泌输出，单点采血可能得出错误结论。
- 结合蛋白决定游离激素比例，总浓度可因妊娠、肝病、肾病而失真。
- 「激素水平不等于功能状态」：抵抗、储备耗竭、结合蛋白干扰、节律丧失与终末效应物差异，都会使化验值与功能脱节；评估须四者结合。

# 第40章 内分泌功能紊乱（Disorders of Endocrine Function）

## 学习目标

完成本章学习后，你应当能够：

1. 按功能亢进、功能减退、激素抵抗与结构/异位分泌四类归纳内分泌紊乱；
2. 说明功能亢进与功能减退各自的常见机制，并各举两例；
3. 用「靶腺激素—促激素」的对应关系判断原发、继发与三发性病变；
4. 描述甲状腺、肾上腺皮质、甲状旁腺功能紊乱的主要表现方向与急症形态；
5. 解释应激与内分泌之间的双向影响，识别易发生危象的高危患者；
6. 制定内分泌紊乱患者的评估与护理干预要点。

## 40.1 内分泌紊乱的分类框架

内分泌疾病的表现看似繁杂，但按机制归类只有少数几种基本型态。掌握框架，才能把零散症状还原为可推理的结构：

| 类型 | 核心特征 | 典型举例 |
|---|---|---|
| 功能亢进（hyperfunction） | 激素效应过强，分泌常为自主性 | Graves 病、皮质醇增多、原发性甲旁亢 |
| 功能减退（hypofunction） | 激素效应不足，可原发或继发 | 桥本甲状腺炎、Addison 病、垂体功能减退 |
| 激素抵抗（resistance） | 激素水平不低甚至升高，效应不足 | 胰岛素抵抗、甲状腺激素抵抗、雄激素抵抗 |
| 结构与异位分泌 | 占位效应、异位激素、多腺体综合征 | 垂体腺瘤、异位 ACTH 综合征、多内分泌腺自身免疫综合征 |

另有两个交叉维度：**按层级**分为原发（靶腺）、继发（垂体）、三发（下丘脑）；**按范围**分为单腺体、多腺体与综合征性。同一患者可同时具备多个维度，如「原发甲状腺功能减退合并自身免疫性肾上腺炎」属多腺体自身免疫。

## 40.2 功能亢进的机制

功能亢进的共同结果是激素效应超过机体需要，其产生路径有五条：

1. **腺体增生或肿瘤的自主分泌**：细胞获得不经反馈抑制的分泌能力，靶腺激素升高而促激素被抑制。垂体腺瘤、甲状腺自主功能性结节、肾上腺腺瘤均属此类。**「自主」是关键词**——它意味着分泌脱离了对机体需求的响应。
2. **自身抗体模拟促激素**：Graves 病中促甲状腺激素受体刺激性抗体持续激活受体，产生与 TSH 相同的效应，而垂体 TSH 因负反馈而降低。此时「促激素低、靶腺激素高」的组合极易被误读为「垂体没问题」。
3. **异位激素分泌**：非内分泌组织的肿瘤合成并分泌激素或激素前体，如某些肺癌分泌 ACTH 样物质引起皮质醇增多。其特点是**不能被常规抑制试验抑制**，且原发灶不在内分泌器官。
4. **外源性激素摄入**：患者因治疗或非正规途径摄入激素，表现为功能亢进而内源激素被抑制。识别要点是病史与内源激素水平的分离。
5. **底物或信号过度**：碘摄入骤增可诱发易感者甲状腺功能亢进；组成性激活的基因突变使信号通路持续开启。

## 40.3 功能减退的机制

功能减退的机制同样可归为几条主线：

- **腺体破坏**：自身免疫性破坏（桥本甲状腺炎、1 型糖尿病、自身免疫性肾上腺炎）最常见；此外有缺血、出血、感染、手术切除、放射性损伤。破坏通常是**渐进且不可逆**的，储备耗竭到一定程度才出现临床与生化改变。
- **先天性发育或合成障碍**：腺体发育不全、激素合成酶的基因缺陷（如先天性肾上腺增生中的酶缺陷）、受体缺陷。
- **上位病变**：垂体或下丘脑的肿瘤、缺血（产后大出血致垂体坏死）、创伤、放疗引起继发性或三发性减退。此类患者的**促激素不升高**，是与原发减退的关键区别。
- **医源性**：长期外源激素抑制轴后骤停；药物干扰激素合成或释放；颈部手术或放射损伤甲状旁腺。
- **受体后缺陷**：激素水平正常而信号传递失败，表现类似减退。

**临床提示**：功能减退的症状多为「代谢与兴奋性普遍下降」的非特异组合（乏力、畏寒、体重变化、便秘、心率减慢、反应迟钝、情绪低落），极易被归因于衰老、抑郁或疲劳。**症状越不特异，越需要靠机制线索（合并的自身免疫病、手术史、用药史、家族史）主动筛查。**

## 40.4 激素抵抗综合征

抵抗是指激素浓度足以产生效应而靶组织反应不足。机制分三层：

- **受体缺陷**：受体基因突变使结合能力或信号能力下降，如甲状腺激素抵抗、雄激素抵抗、部分皮质醇抵抗；
- **受体后缺陷**：信号转导分子异常、转运体缺陷、代谢酶异常；
- **抗体阻断**：抗受体抗体占据受体而不激活，如胰岛素受体抗体所致严重胰岛素抵抗。

抵抗的识别难点在于：**激素水平升高，容易被判为功能亢进**。鉴别要点是**看终末效应**——若终末效应物（如代谢率、IGF-1、血糖、性征发育）显示功能不足，而激素水平升高，则抵抗的可能性大于亢进。抵抗综合征常呈家族性，部分伴特征性体型或发育改变，识别后对家系筛查有意义。

## 40.5 定位诊断的逻辑：原发、继发与三发

定位的核心不是记住疾病名称，而是**读出一对激素之间的关系**：

| 靶腺激素 | 促激素 | 推断 |
|---|---|---|
| 降低 | 升高 | 原发性减退（靶腺本身衰竭，反馈减弱） |
| 降低 | 降低或不相称地低 | 继发（垂体）或三发（下丘脑）性减退 |
| 升高 | 降低 | 原发性亢进（靶腺自主分泌，反馈增强） |
| 升高 | 升高或不相称地高 | 继发性亢进、异位分泌或抵抗 |

关键在于「**不相称**」这三个字：正常时二者应呈反向关系，一旦同向变动或比例失衡，就说明反馈环路某处被打破。临床实践中还需结合动态试验——抑制试验能否抑制、兴奋试验能否反应，往往比基础值更能定位。

**护理意义**：理解定位逻辑可以解释治疗为何不同。原发减退补充靶腺激素即可；继发减退若只补靶腺激素，可能掩盖垂体病变的进展，且需同时评估其他垂体激素轴（多轴受累常见，且有一定次序性）。

## 40.6 垂体疾病

- **垂体腺瘤**：按功能分为功能性（分泌 PRL、GH、ACTH、TSH）与无功能性。表现由两部分构成：**占位效应**（头痛、视野缺损、垂体柄受压致轻度高 PRL、正常组织受压致多轴减退）与**激素效应**（闭经泌乳、肢端肥大、皮质醇增多）。无功能性腺瘤常在体积较大时才被发现。
- **垂体功能减退**：多轴激素依次丢失，临床以性腺轴、甲状腺轴、肾上腺轴受累为常见顺序；起病隐匿，常在应激时暴露。产后大出血所致者常伴泌乳失败、闭经、乏力、低血压。
- **垂体卒中**：腺瘤内出血或梗死，表现为突发剧烈头痛、视力急剧下降、眼肌麻痹与急性肾上腺皮质功能不全，属内分泌急症，需立即识别。
- **尿崩症**：ADH 缺乏（中枢性）或肾对 ADH 反应不足（肾性），表现为多尿、烦渴、尿比重与渗透压降低。禁水试验用于鉴别：中枢性者在禁水后仍不能浓缩尿，补充 ADH 后改善；肾性者对 ADH 无反应。
- **抗利尿激素分泌不当综合征（SIADH）**：ADH 不适当分泌致水潴留、稀释性低钠，表现为低钠相关的意识改变、恶心、抽搐，尿渗透压不适当升高。

## 40.7 甲状腺功能紊乱

**甲状腺功能亢进**是甲状腺激素合成与释放增多所致的高代谢状态：代谢率升高（怕热、多汗、体重下降而食欲增加）、交感样表现（心悸、手抖、焦虑、失眠）、肠蠕动增快（大便次数增多）、月经紊乱、肌无力，可有甲状腺肿大与突眼。**甲状腺危象**是其在应激下的极端形态，常由感染、手术、分娩、停药或碘负荷诱发，表现为高热、心动过速与心律失常、烦躁甚至谵妄、呕吐腹泻、脱水与循环衰竭，属危重症。

**甲状腺功能减退**是代谢率下降状态：畏寒、乏力、体重增加、便秘、皮肤干燥、声音低沉、心率减慢、反应与记忆减退、抑郁倾向、月经异常；严重者出现黏液性水肿（非凹陷性水肿、面部虚肿、舌体增大），进而发展为**黏液性水肿昏迷**——低体温、意识障碍、通气不足、低钠、低血糖，常由感染、寒冷、镇静药物或停药诱发。

**病因谱**：自身免疫（Graves 病、桥本甲状腺炎）、碘缺乏或过量、药物（抗甲状腺药、胺碘酮、锂盐）、手术与放射性碘、亚急性甲状腺炎的释放期与恢复期。**注意方向可以翻转**：亚急性甲状腺炎早期因滤泡破坏而激素释放增多，表现为一过性亢进，随后可进入一过性减退期——同一疾病在不同阶段方向相反，是「按机制而非按病名」判断的典型例证。

## 40.8 肾上腺皮质功能紊乱

**皮质醇增多（Cushing 综合征）**：向心性肥胖、满月脸、水牛背、紫纹、皮肤变薄、肌萎缩与近端肌无力、骨质疏松、血糖升高、血压升高、免疫抑制致感染易感、伤口愈合差、情绪改变与睡眠障碍。按病因分 ACTH 依赖性（垂体腺瘤即 Cushing 病、异位 ACTH）与非 ACTH 依赖性（肾上腺腺瘤或癌、外源激素）。**外源性糖皮质激素所致者最常见**，其内源皮质醇与 ACTH 均被抑制。

**醛固酮增多**：醛固酮促进肾远曲小管保钠排钾，过多则出现高血压伴低钾倾向、代谢性碱中毒、肌无力与多尿。原发性者肾素受抑，继发性者（如肾动脉狭窄、有效循环血量不足）肾素升高——肾素与醛固酮的配对关系同样是定位工具。

**肾上腺皮质功能不全**：皮质醇与（或）醛固酮不足，表现为乏力、食欲下降、体重减轻、低血压与体位性头晕、低钠、高钾、低血糖、色素沉着（ACTH 前体增多所致，见于原发性）。**肾上腺危象**是其急症形态：诱因为感染、创伤、手术、呕吐腹泻、骤停激素；表现为休克、脱水、低钠、低血糖、腹痛与意识障碍，可被误诊为急腹症或感染性休克。

**先天性肾上腺增生**：皮质醇合成通路中的酶缺陷使皮质醇不足，ACTH 代偿性升高，前体物质转向雄激素合成，导致女性男性化或男性性早熟，并可伴失盐型危象。

## 40.9 甲状旁腺与钙磷调节紊乱

PTH 的作用可概括为「**升钙降磷**」：促进骨吸收释放钙磷、增加肾小管钙重吸收、减少磷重吸收、促进活性维生素 D 生成从而增加肠钙吸收。

- **甲状旁腺功能亢进**：高钙引起神经肌肉兴奋性下降（乏力、便秘、腹胀、情绪淡漠）、肾结石与肾钙化、骨痛与骨量减少（骨吸收增强）、心电图改变。原发性者多为腺瘤，继发性者见于慢性肾病（低钙、高磷刺激 PTH 分泌）。
- **甲状旁腺功能减退**：低钙使神经肌肉兴奋性升高，出现口周与肢端麻木、手足搐搦、肌肉痉挛，严重者喉痉挛与抽搐；颈部手术是最常见医源性原因。低钙还延长心肌复极，需心电监护。
- **维生素 D 缺乏**：肠钙吸收减少，PTH 代偿性升高，导致骨软化与骨量下降；长期室内生活、防晒过度、肝肾功能不全、吸收不良者高危。

钙磷紊乱的共同点是**神经肌肉兴奋性与血钙方向相反**，且症状跨神经、消化、泌尿、骨骼多个系统——这是「一个离子影响全身」的典型例证。

## 40.10 应激与内分泌的双向影响

应激与内分泌的关系是双向且互相放大的：

**应激 → 内分泌**：交感-肾上腺髓质轴与下丘脑-垂体-肾上腺轴被激活，儿茶酚胺与皮质醇升高，血糖上升、血压上升、心率增快、炎症与免疫受抑、蛋白与脂肪分解加速。短期内这是适应性动员；持续激活则造成代谢紊乱、免疫抑制与组织损伤。

**内分泌疾病 → 应激耐受力下降**：肾上腺皮质功能不全者缺乏皮质醇的允许作用，在感染或手术时迅速陷入休克；未控制的甲亢者在应激下易发危象；糖尿病患者在感染时胰岛素抵抗加重、酮症风险上升；垂体功能减退者在创伤时暴露多轴不足。**这些患者平时可能「看起来稳定」，其脆弱性只在应激时显现**——这与 39.8 所述「激素水平不等于功能状态」是同一命题的临床版本。

**医源性风险**：长期外源糖皮质激素抑制 HPA 轴，减量过快或骤停可诱发危象；应激状态下机体需求上升，此时通常需要在医生指导下调整剂量而非维持原方案（具体剂量属个体化医疗决策，不在本讲义讨论范围）。

**护理要点**：识别高危人群并主动宣教（随身携带疾病标识、生病时及时就医、不自行停药）；在感染、手术、呕吐腹泻等应激事件中加强监测（血压、意识、尿量、血糖方向性变化）；对长期激素治疗者执行**逐步减量**原则并记录减量过程。

## 40.11 内分泌紊乱的评估与护理原则

- **不依赖单次化验**：结合时点、症状、体征、动态试验与靶器官效应；对「化验正常但症状典型」者保持警惕，必要时重复或做动态试验。
- **建立机制假设而非贴标签**：从「激素效应过强还是不足」「病变在哪一层」「是否存在抵抗」三个问题入手，可将复杂病例结构化。
- **识别急症形态**：甲状腺危象、黏液性水肿昏迷、肾上腺危象、垂体卒中、严重低钙抽搐——这些情况的共同特征是**意识改变 + 循环或呼吸不稳定**，识别速度决定结局。
- **激素替代的教育**：不可自行停药、不可骤减；发热、手术、呕吐等应激时联系医生；了解过量与不足的早期信号（心悸、失眠、体重下降提示过量；乏力、低血压、食欲下降提示不足）。
- **多腺体筛查意识**：一种自身免疫性内分泌病存在时，应关注其他腺体（甲状腺、肾上腺、胰岛、性腺）的受累可能。
- **长期风险管理**：糖皮质激素过量状态下的骨质疏松、感染、血糖与血压问题；甲亢的心律失常与骨量丢失；甲减的血脂异常与心血管风险。
- **心理与社会支持**：体型改变（满月脸、体重增加、突眼、瘢痕）对自我形象影响显著，需主动评估情绪与生活质量。

## 本章小结（Key Points）

- 内分泌紊乱按机制分为功能亢进、功能减退、激素抵抗与结构/异位分泌四类，另按层级（原发/继发/三发）与范围（单腺体/多腺体）交叉定位。
- 亢进的核心是「自主分泌」：腺瘤、刺激性抗体、异位分泌、外源摄入、底物过量。
- 减退的核心是「腺体破坏或上位调控失败」：自身免疫最常见，继发者促激素不升高。
- 抵抗的特征是激素高而效应低，鉴别靠终末效应物而非激素水平本身。
- 定位诊断读的是「靶腺激素—促激素」的对应关系，关键是识别「不相称」。
- 应激与内分泌双向放大：应激激活两轴，内分泌病降低应激耐受力，危象多由应激诱发。
- 护理核心：识别危象形态、坚持动态与联合评估、落实激素替代的用药教育与应激时就医指导。

# 第41章 糖尿病（Diabetes Mellitus）

## 学习目标

1. 说明胰岛素在糖、脂、蛋白代谢中的作用及其与升糖激素的抗衡关系；

4. 区分 1 型、2 型、其他特殊类型与妊娠糖尿病的机制特点；
5. 分别阐述糖尿病酮症酸中毒与高渗高血糖状态的机制，并说明低血糖的表现、高危人群与处理原则；
6. 说明慢性并发症的共同机制，区分微血管与大血管病变，并制定综合管理与足部护理要点。

## 41.1 糖代谢的调节与胰岛素的作用

血糖的稳定取决于三个变量的平衡：**肠道吸收、肝脏输出（糖原分解与糖异生）、外周组织摄取与利用**。胰岛素是唯一显著降低血糖的激素，其作用可归纳为「四促四抑」：

- **促进**：肌肉与脂肪组织摄取葡萄糖；肝与肌肉合成糖原；脂肪合成与储存（激活脂蛋白脂酶）；蛋白质合成与氨基酸转运；同时促进钾向细胞内转移。
- **抑制**：肝糖异生；肝糖原分解；脂肪分解（抑制脂肪酶）；酮体生成。

与胰岛素方向相反的**升糖激素**包括胰高血糖素（促进糖原分解与糖异生、促进酮体生成）、肾上腺素（应激时快速动员）、皮质醇（促进糖异生、诱导胰岛素抵抗）、生长激素（拮抗胰岛素、促进脂解）。注意这个结构的不对称：**一个降糖激素对抗四个以上升糖激素**，因此胰岛素分泌或作用一旦不足，升糖方向几乎不受约束——这是糖尿病在感染、创伤、情绪应激下迅速恶化的机制根源。

当血糖超过肾小管重吸收能力（**肾糖阈**）时出现尿糖；尿糖的渗透效应带走水分，引起渗透性利尿，形成「多尿—脱水—烦渴」的连锁。这为 41.7 的急性代谢紊乱埋下伏笔。

## 41.2 胰岛素的分泌机制

β 细胞是**葡萄糖感受器**：葡萄糖经转运体进入细胞 → 代谢产生 ATP → ATP/ADP 比值升高 → ATP 敏感性钾通道关闭 → 细胞膜去极化 → 电压依赖性钙通道开放 → 钙内流 → 分泌颗粒与膜融合、释放胰岛素。

这一链条解释了若干临床现象：钾通道活性改变可致新生儿糖尿病或低血糖；磺脲类药物通过关闭同一通道促分泌（故其低血糖风险与进食状态密切相关）；而葡萄糖以外的信号（氨基酸、脂肪酸、肠促胰素、迷走神经）作为**放大器**调节同一分泌装置的输出。

**C 肽**与胰岛素由同一前体（胰岛素原）等量裂解产生，但 C 肽不经肝首过代谢、半衰期更长，因此**C 肽是评估内源 β 细胞功能的可靠指标**；外源注射的胰岛素不含 C 肽，故测定 C 肽可区分「分泌不足」与「外源补充」。这一点在判断糖尿病类型与病程阶段时具有实际价值。

**肠促胰素效应**：进食后肠道 L 细胞分泌 GLP-1、K 细胞分泌 GIP，以葡萄糖依赖性方式放大胰岛素分泌并抑制胰高血糖素。2 型糖尿病中该效应显著减弱，是药物治疗的重要靶点。

## 41.3 糖尿病发生的三环节模型

把糖尿病理解为「一个激素不够」，会漏掉大半机制。更完整的模型包含三个环节：

**环节一：β 细胞分泌缺陷。** 包括 β 细胞数量减少（1 型的自身免疫破坏、2 型的进行性凋亡）与功能缺陷（葡萄糖敏感性下降、脉冲分泌丧失、胰岛素原/胰岛素比例升高）。分泌缺陷决定「能不能分泌足够的胰岛素」。

**环节二：靶组织胰岛素抵抗。** 按层次分为受体前（胰岛素抗体、拮抗激素过多）、受体（数量或亲和力下降、受体突变）、受体后（信号转导缺陷、葡萄糖转运体表达下降、脂毒性）。抵抗的后果有三：肌肉摄取葡萄糖减少、肝糖输出不被抑制、脂肪分解增加使游离脂肪酸涌入肝与肌肉，进一步加重抵抗——形成**恶性循环**。

**环节三：其他器官环节。** 肾小管葡萄糖重吸收增加（使血糖进一步升高）、肠促胰素效应减弱、脂肪组织慢性炎症与脂肪因子失衡、中枢食欲与肝糖调节异常。

三环节的组合决定临床表型：分泌缺陷为主者起病较急、酮症倾向明显；抵抗为主而分泌尚可者长期无症状；二者并存且分泌进行性下降者，表现为「静默进展直至失代偿」。这也解释了为何同一诊断名称下的患者，治疗反应差异巨大。

## 41.4 1 型糖尿病

1 型糖尿病是**自身免疫介导的 β 细胞选择性破坏**：遗传易感（HLA 区域）个体在环境因素触发下，产生针对胰岛细胞的自身抗体，T 细胞介导的炎症逐步摧毁 β 细胞。其特点：

- **绝对胰岛素缺乏**：C 肽极低或测不出，必须依赖外源胰岛素维持生命；
- **酮症倾向**：缺乏胰岛素时脂肪分解不受抑制，酮体大量生成，易发生酮症酸中毒，甚至以急症起病；
- **起病较急**：多饮、多尿、多食、体重下降的「三多一少」明显，儿童青少年多见，但任何年龄均可发生；
- **伴随自身免疫**：可合并甲状腺、肾上腺等其他腺体的自身免疫病（与 40.4 的多腺体概念呼应）；
- **蜜月期**：起病治疗后部分 β 细胞功能短暂恢复，胰岛素需求下降，易被误认为「痊愈」。

## 41.5 2 型糖尿病

2 型糖尿病以**胰岛素抵抗为背景、β 细胞分泌缺陷为进展动力**：

- 遗传易感与环境的交互：内脏脂肪增多、体力活动减少、能量摄入结构改变、睡眠不足、心理应激、增龄；
- 起病隐匿：可多年无典型症状，常在体检、并发症出现或应激时被发现——「诊断之时已有并发症」并不罕见；
- **进展性**：β 细胞功能随时间下降，治疗需求逐步升级，这并非「没管好」，而是疾病自然史的一部分；
- 多重机制并存：肝糖输出增高、肠促胰素效应减弱、肾糖阈上调、脂肪组织炎症、肌肉摄取减少；
- 与代谢综合征共享土壤（见 42.4）：腹型肥胖、血脂异常、高血压、脂肪肝常同时存在，干预需面向共同环节。

## 41.6 其他特殊类型与妊娠糖尿病

**其他特殊类型**包括：单基因糖尿病（如青年发病的成人型糖尿病、新生儿糖尿病，常被误诊为 1 型或 2 型，家族史与病程特点提供线索）、胰腺外分泌疾病（慢性胰腺炎、胰腺切除、囊性纤维化、血色病）、内分泌病（皮质醇增多、肢端肥大、甲亢、嗜铬细胞瘤）、药物或化学物所致（糖皮质激素、某些抗病毒药、免疫抑制剂）、感染。

**妊娠糖尿病**的机制具有清晰的生理逻辑：妊娠中晚期胎盘分泌的激素（胎盘生乳素、孕激素、皮质醇）造成**生理性胰岛素抵抗加深**，若 β 细胞储备不足以代偿，即出现糖代谢异常。其意义有三：对母亲，增加妊娠期高血压与远期 2 型糖尿病风险；对胎儿，母体高血糖经胎盘传输刺激胎儿胰岛素分泌，导致巨大儿、新生儿低血糖、呼吸窘迫与远期代谢风险；对管理，产后多数恢复，但需长期随访。

## 41.7 急性代谢紊乱：DKA 与 HHS

两者都是「胰岛素不足 + 升糖激素过多」的急性失代偿，但侧重不同，必须分开理解。

**糖尿病酮症酸中毒（DKA）**：胰岛素**绝对或近乎绝对**缺乏，脂肪分解失控，游离脂肪酸在肝内转化为酮体，酮体为酸性物质 → **代谢性酸中毒**。临床方向：多尿烦渴加重、恶心呕吐、腹痛（可被误为急腹症）、深大呼吸（Kussmaul 呼吸，机体以过度通气代偿酸中毒）、呼气烂苹果味、脱水、意识由淡漠至昏迷。实验室方向：血糖显著升高、血酮与尿酮阳性、代谢性酸中毒、阴离子间隙增大、总体钾缺失而血钾可高可低（酸中毒与胰岛素缺乏使钾外移，血钾「看似正常」实则总体缺钾）。

**高渗高血糖状态（HHS）**：胰岛素相对不足——足以抑制酮体生成，却不足以控制血糖。于是血糖极度升高而无明显酮症，渗透性利尿导致**严重脱水与高渗**，血液浓缩、黏度升高，血栓风险上升。临床方向：起病较缓、老年多见、脱水征明显、意识障碍突出（可由嗜睡至昏迷）、可有局灶神经体征或抽搐（易被误为脑卒中）。实验室方向：血糖与血浆渗透压显著升高、酮体阴性或微量、血钠因脱水而升高。

| 对比项 | DKA | HHS |
|---|---|---|
| 胰岛素缺乏程度 | 绝对/近绝对 | 相对 |
| 酮体 | 明显阳性 | 阴性或微量 |
| 酸碱状态 | 代谢性酸中毒 | 无明显酸中毒 |
| 脱水程度 | 中度 | 重度 |
| 主要死因方向 | 酸中毒、电解质紊乱、脑水肿（儿童） | 休克、血栓、意识障碍 |
| 常见人群 | 1 型、也可发生于 2 型应激时 | 老年 2 型 |

**共同诱因**：感染（最常见）、胰岛素中断或用量不足、新发糖尿病、急性心脑血管事件、创伤手术、妊娠、严重情绪应激、某些药物。**护理识别的关键是「感染 + 脱水 + 意识改变 + 呼吸模式改变」的组合**，而不是等待化验结果。

**处理原则的方向性表述**：补液纠正脱水、静脉胰岛素抑制脂解与糖异生、纠正电解质（尤其钾，须在尿量恢复后审慎补充）、寻找并处理诱因、监测意识与循环。补液与胰岛素必须同步推进——单用胰岛素而不补液会加重循环衰竭，单补液而不给胰岛素无法关闭酮体生成。具体剂量与速率属个体化医疗决策，本讲义不予列举。

## 41.8 慢性并发症的共同机制

慢性并发症并非「血糖高久了自然出现」的模糊说法，而有可归纳的细胞机制。持续高血糖通过四条通路造成损伤：

1. **非酶糖基化**：葡萄糖与蛋白质氨基共价结合，形成糖基化终末产物（AGEs），交联胶原使血管壁僵硬、基底膜增厚，并通过受体激活炎症与氧化应激；
2. **多元醇通路**：葡萄糖经醛糖还原酶转为山梨醇，细胞内渗透压升高、NADPH 消耗，见于神经、晶体、视网膜；
3. **蛋白激酶 C 激活**：由二酰甘油增多触发，改变血管通透性、内皮素与 VEGF 表达，促进新生血管与渗漏；
4. **氧化应激与炎症**：线粒体超氧化物增多，激活炎症因子与黏附分子，造成内皮功能障碍。

四条通路汇聚于同一结果：**微血管基底膜增厚、内皮功能障碍、血流与神经灌注异常**。

| 类别 | 受累 | 主要表现方向 |
|---|---|---|
| 微血管 | 视网膜 | 微动脉瘤、出血、渗出、黄斑水肿、增殖性病变 → 视力下降 |
| 微血管 | 肾 | 蛋白尿、滤过率下降、血压升高 → 慢性肾病 |
| 微血管 | 神经 | 远端对称性感觉异常（麻木、烧灼、针刺感）、自主神经（体位性低血压、胃轻瘫、排尿与性功能异常） |
| 大血管 | 冠脉、脑、外周动脉 | 冠心病（常无痛）、脑卒中、间歇性跛行 |

**大血管病变的机制不同于微血管**：它以动脉粥样硬化为核心，糖尿病通过血脂异常、炎症、内皮损伤、血小板功能改变加速这一过程，并与高血压、吸烟、肥胖协同。因此糖尿病被视为**冠心病的等危状态**——这一概念的意义在于：并发症的预防不能只盯血糖。

## 41.9 糖尿病足与感染

糖尿病足是三类因素叠加的结果，缺一不可：

- **神经病变**：感觉丧失使患者察觉不到外伤与压力；运动神经病变致足趾畸形、压力分布异常；自主神经病变致皮肤干燥、皲裂；
- **缺血**：外周动脉病变使组织灌注不足，伤口难以愈合；
- **感染**：高血糖环境下免疫细胞功能受损（趋化、吞噬、细胞内杀菌能力下降），感染一旦发生便迅速扩散。

**临床意义**：三者中任何一项被忽略，伤口都可能从「小破皮」演变为深部感染、骨髓炎甚至截肢。**预防的价值远高于治疗**——每日检查足部、选择合适鞋袜、避免赤足行走、正确修剪趾甲、保持皮肤湿润但趾间干燥、发现伤口立即就医。这些措施不需要任何数值标准，却构成糖尿病护理中最有效的干预之一。

感染与糖尿病的关系是双向的：感染通过升糖激素与胰岛素抵抗加重高血糖，高血糖又削弱免疫防御，形成「感染—高血糖」的正反馈，是 DKA 与 HHS 最常见的诱因。

## 41.10 低血糖

低血糖是糖尿病治疗中最常见的急性并发症，其危害在于**脑依赖葡萄糖供能**，而脑组织几乎无糖原储备。

**表现分两组**：交感肾上腺样症状（心悸、出汗、震颤、饥饿感、焦虑、面色苍白）——由儿茶酚胺释放引起，是早期预警；神经低糖症状（注意力涣散、反应迟钝、言语含糊、行为异常、视物模糊、抽搐、昏迷）——提示脑功能受损。**病情越重，预警症状可能越不明显**。

**高危人群与情形**：使用胰岛素或促泌剂者；进食不足、延迟进餐、饮酒（抑制糖异生）；运动后未调整；肾功能不全（胰岛素清除减慢）；老年与认知障碍者；长期糖尿病致**低血糖感知受损**——反复低血糖使交感反应阈值下移，患者在血糖已很低时仍无预警，直接进入神经低糖阶段，风险最高。

**处理原则的方向性表述**：意识清醒者立即口服快速吸收的糖类，随后补充较持久的主食以防复发；意识障碍者不可经口喂食（误吸风险），须由他人协助并紧急就医，院内可经静脉补充葡萄糖或使用胰高血糖素。**具体用量属个体化医疗决策，本讲义不列举。** 处理后须查找原因（用药、进食、运动、肾功能、饮酒）并调整方案，而不是简单「补上就好」。

## 41.11 综合管理与护理

糖尿病管理的目标不是把一个数字压到某个点，而是**降低并发症风险、维持功能与生活质量**。这需要多维度并进：

- **监测的局限**：自我血糖监测反映时点值，糖化血红蛋白反映一段时间内的平均水平，二者都不能反映**波动幅度**；波动本身与氧化应激和并发症相关。理解「平均值正常而波动剧烈」同样有风险，是解读监测结果的关键。
- **教育**：足部护理、饮食结构与进餐规律（本讲义不提供热量方案）、运动的安全原则（避免在低血糖高风险时段运动、随身携带糖类）、生病日管理（感染时监测加密、不擅自停药、及时就医）、旅行与驾驶的安全事项。
- **并发症筛查**：眼底检查、尿蛋白与肾功能、足部感觉与血管评估、血脂与血压管理、口腔与皮肤护理。
- **心理与社会支持**：疾病负担、饮食限制、注射恐惧、低血糖焦虑、治疗疲劳（diabetes distress）显著影响依从性，需主动评估而非视为「不配合」。
- **特殊情境**：围手术期、妊娠、老年、合并心肾疾病时的管理重点各不相同，需个体化。

## 41.12 生命周期考量

- **儿童与青少年**：生长发育、学业、同伴关系与自我管理能力的建立并重；青春期胰岛素抵抗生理性升高，需求波动大；家庭支持与逐步过渡到自我管理是关键；低血糖与酮症风险在学龄期尤需关注。
- **老年**：低血糖风险高、感知受损、认知与视听功能下降、多重用药、共病多；管理目标应个体化，**避免以严格达标换取低血糖与跌倒风险**；照护者参与与简化方案有助于安全。
- **妊娠**：孕前评估与准备、孕期密切监测、产后随访；妊娠糖尿病的女性产后需长期筛查 2 型糖尿病。
- **围手术期与重症**：应激性高血糖常见，需与原有糖尿病区分；管理重点是避免剧烈波动与低血糖。

## 本章小结（Key Points）

- 胰岛素促摄取、促合成、抑分解，是唯一显著降糖的激素；升糖激素众多，结构不对称使胰岛素不足时升糖方向几乎不受约束。
- β 细胞以 ATP 敏感性钾通道—钙内流为分泌核心；C 肽与胰岛素等量分泌，是评估内源功能的指标。
- 三环节模型：β 细胞分泌缺陷、靶组织胰岛素抵抗、肾脏/肠道/脂肪等附加环节，组合决定表型与进展速度。
- 1 型为自身免疫性绝对缺乏、酮症倾向明显；2 型以抵抗为背景、分泌缺陷驱动进展，起病隐匿。
- DKA 以酮症酸中毒为特征，HHS 以重度脱水高渗为特征；二者共同诱因是感染与胰岛素中断，处理须补液与胰岛素并重。
- 慢性并发症经糖基化、多元醇通路、PKC 与氧化应激四条通路损伤血管；微血管与大血管病变机制与防治重点不同。
- 低血糖的预警症状可因感知受损而消失；足部护理与患者教育是不依赖数值标准的高价值干预。

## 42.1 能量平衡与体重调节

体重是**能量摄入与能量消耗长期平衡**的结果。能量消耗由三部分构成：基础代谢（静息状态下维持生命活动的消耗，占主要部分）、食物热效应（消化吸收与代谢转化消耗的能量）、体力活动消耗。三者中基础代谢受体重、肌肉量、甲状腺激素、体温与年龄影响最大。

当摄入持续超过消耗，多余能量以脂肪形式储存，**能量正平衡**导致体重上升；反之则为负平衡。但机体并非被动记账，而是通过一套调节系统**defend**一个「调定点」：体重下降时，能量消耗下降（代谢适应）、饥饿感增强、食物奖赏敏感性升高；体重上升时，理论上应出现相反变化，但这一方向的调节力量明显较弱——这解释了为什么减重后容易反弹，而增重后难以自动回落。

**临床意义**：把肥胖归因于「意志力不足」既不符合生理事实，也会破坏护患关系。有效的干预必须同时处理环境、行为与生物学三个层面，并预期到代谢适应的存在。

## 42.2 能量稳态的神经内分泌调控

能量稳态的中枢在**下丘脑弓状核**，其中两类神经元构成「促食—抑食」的对抗系统：

- **POMC/CART 神经元**（抑食）：被瘦素与胰岛素激活，投射至室旁核，促进饱腹、增加能量消耗；
- **NPY/AgRP 神经元**（促食）：被饥饿信号激活、被瘦素抑制，促进摄食、降低消耗。

外周信号构成这个中枢的输入：

| 信号 | 来源 | 作用方向 |
|---|---|---|
| 瘦素（leptin） | 脂肪组织 | 反映脂肪储备，抑食、增加消耗；肥胖时常见「瘦素抵抗」 |
| 胰岛素 | 胰岛 β 细胞 | 中枢抑食信号，与瘦素协同 |
| ghrelin | 胃（空腹时升高） | 促食，进餐后下降 |
| GLP-1、PYY | 肠道（进食后释放） | 增强饱腹、延缓胃排空 |
| 甲状腺激素、交感神经 | 甲状腺、中枢 | 调节产热与基础代谢率 |

此外，**棕色脂肪**通过解偶联产热消耗能量，其活性受交感神经与寒冷刺激调节，是能量消耗侧的重要变量。这套系统的意义在于：体重不是单一器官的功能，而是**脂肪、胃肠、胰岛、甲状腺与中枢共同协商的结果**——因此任何单点干预都可能被其他环节代偿。

## 42.3 肥胖的机制与后果

肥胖是遗传易感与环境因素长期交互的结果，涉及多条通路：

- **遗传易感**：能量利用效率、脂肪分布、食欲调控的个体差异有明确的遗传基础；
- **环境与行为**：能量密度高的饮食结构、久坐、睡眠不足（改变瘦素与 ghrelin 的分泌模式）、慢性应激（皮质醇促进内脏脂肪沉积）、某些药物（糖皮质激素、部分抗精神病药）、肠道菌群构成；
- **脂肪组织的内分泌功能**：脂肪不是惰性仓库，它分泌瘦素、脂联素、炎症因子（TNF-α、IL-6）与游离脂肪酸。脂肪堆积时脂联素下降、炎症因子上升，形成**慢性低度炎症**；
- **异位脂肪与脂毒性**：当皮下储存能力饱和，脂肪沉积于肝、肌肉、心包、胰腺，这些「不该存脂的地方」出现脂毒性，直接干扰胰岛素信号与器官功能。

**后果**覆盖多系统：胰岛素抵抗与糖代谢异常、血脂异常、高血压、脂肪肝、睡眠呼吸暂停、骨关节负荷增加、静脉血栓风险、某些肿瘤风险上升，以及抑郁、病耻感与社会功能受损。**肥胖本身即是病理状态，而非单纯的危险因素。**

## 42.4 代谢综合征：共同的代谢土壤

代谢综合征不是单一疾病，而是一组**聚集出现**的代谢异常：腹型肥胖、胰岛素抵抗与糖代谢异常、血脂异常（甘油三酯升高、高密度脂蛋白降低的方向性改变）、血压升高，常伴高尿酸与脂肪肝。

其共同机制可归纳为一条链：**内脏脂肪堆积 → 游离脂肪酸释放增多 → 肝脏与肌肉脂质沉积 → 胰岛素信号受损 → 代偿性高胰岛素血症 → 进一步促进脂肪合成与钠潴留 → 血压升高、血脂异常、尿酸排泄减少**。加上脂肪组织炎症与内皮功能障碍，各异常互相强化。

**意义有三**：其一，风险是**聚集且相乘**的，而非简单相加；其二，干预应指向**共同环节**（减少内脏脂肪、改善胰岛素敏感性、增加活动），而非逐个指标分别处理；其三，它解释了为何同一患者常同时存在糖尿病、高血压、脂肪肝与高尿酸——这不是巧合，而是同一土壤的不同表现。

## 42.5 饥饿与禁食的代谢适应

饥饿状态下机体按顺序切换燃料，这一顺序体现了极强的适应性：

1. **餐后阶段**：葡萄糖为主要燃料，胰岛素高、胰高血糖素低，肝糖原合成与储存；
2. **早期禁食**：肝糖原分解维持血糖，糖原储备有限，随后**糖异生**启动（主要底物为氨基酸，来自肌肉蛋白分解），此阶段蛋白丢失较快；
3. **延长禁食**：脂肪分解成为主要能量来源，肝生成酮体供脑、心、肌肉使用，**减少对葡萄糖与蛋白质的依赖**——这是「蛋白节省」机制，使生存时间显著延长；
4. **激素模式**：胰岛素降低、胰高血糖素升高、皮质醇与生长激素升高（促进脂解与糖异生）、甲状腺激素外周转化下调（降低基础代谢率）、性腺轴受抑。

**水与电解质**同样发生变化：钠钾丢失、细胞内液外移，体重下降中相当一部分是水分而非脂肪。**饥饿性水肿**则是蛋白缺乏致胶体渗透压下降的结果，与心肾性水肿的机制不同。

**关键认识**：饥饿是一种**主动降低消耗、节约蛋白**的适应，其代谢方向是「以脂肪替代葡萄糖、以酮体替代葡萄糖」。

## 42.6 应激代谢

创伤、感染、烧伤与大手术引发的是完全不同的代谢模式——**高代谢与分解代谢为主**：

- 儿茶酚胺、皮质醇、胰高血糖素、生长激素升高，胰岛素相对不足并伴抵抗；
- 肝糖异生显著增强，出现**应激性高血糖**（即使既往无糖尿病）；
- 蛋白质分解加速，氮从尿中大量丢失，出现**负氮平衡**与肌肉消耗，且补充营养难以完全逆转；
- 脂肪动员增强，游离脂肪酸成为重要燃料；
- 水钠潴留、血管通透性增加、体温升高使消耗进一步上升。

| 对比项 | 饥饿 | 应激 |
|---|---|---|
| 代谢率 | 下降（适应） | 升高（强制） |
| 主要燃料 | 脂肪、酮体 | 混合，糖异生显著 |
| 蛋白 | 先丢失后节省 | 持续大量分解 |
| 血糖 | 偏低或正常 | 升高（应激性高血糖） |
| 营养支持效果 | 有效 | 部分有效，须先控制原发病 |

**护理意义**：两者的混淆会导致错误干预——对饥饿者应循序渐进补充；对应激者则需优先处理感染、疼痛、容量不足等原发问题，营养支持是辅助而非主导，且过量喂养反而增加代谢负担与并发症。

## 42.7 再喂养综合征

长期严重营养不良者突然获得充足能量供应时，可能发生**再喂养综合征（refeeding syndrome）**，其机制清晰而凶险：

长期饥饿时胰岛素低、细胞处于分解状态，细胞内磷、钾、镁外流并经尿丢失，总体储备耗竭（血浓度可能尚在范围内）。重新摄入能量后**胰岛素分泌迅速回升**，驱动葡萄糖与这些电解质**向细胞内转移**，血磷、血钾、血镁急剧下降。

**低磷血症是核心**：磷是 ATP 与 2,3-DPG 的组成成分，缺乏使细胞能量代谢与组织氧供受损，临床表现包括：

- 心血管：心律失常、心力衰竭、低血压；
- 呼吸：呼吸肌无力、呼吸衰竭、脱机困难；
- 神经：意识改变、谵妄、抽搐、周围神经病变；
- 血液：红细胞与血小板功能异常；
- 代谢：钠水潴留、容量负荷过重。

**高危人群**：长期摄入不足者、体重显著下降者、酒精使用障碍、神经性厌食、长期禁食或仅静脉输液的术后患者、老年、肿瘤与慢性消耗性疾病、严重吸收不良。

**预防原则**（方向性）：① 识别高危并在补充前评估电解质与容量状态；② **缓慢启动、逐步增加**能量供给，避免「一次补足」；③ 补充硫胺素等维生素（尤其酒精使用障碍者），防止诱发 Wernicke 脑病；④ 密切监测磷、钾、镁与心率、呼吸、容量状态；⑤ 多学科协作，营养方案个体化。**具体能量与补充剂量属个体化医疗决策，本讲义不列举。**

## 42.8 营养不良

**蛋白质-能量营养不良**分两型，机制与表现不同：

| 类型 | 主要缺乏 | 表现方向 |
|---|---|---|
| 消瘦型（marasmus） | 能量与蛋白均长期不足 | 明显消瘦、皮下脂肪与肌肉流失、体重显著下降、无水肿，儿童生长迟缓 |
| 水肿型（kwashiorkor） | 蛋白缺乏为主，能量相对尚可 | 低蛋白血症致水肿（下肢、颜面）、腹部膨隆、皮肤脱屑与色素改变、毛发稀疏易断、肝脂肪浸润、免疫力低下、情绪淡漠 |

两型可并存。**微量营养素缺乏**常被忽略：铁（贫血、乏力）、维生素 D 与钙（骨软化、骨量下降）、B 族维生素（周围神经病变、舌炎、Wernicke 脑病）、锌（伤口愈合差、味觉减退、免疫低下）、维生素 C（牙龈出血、伤口愈合障碍）。

**医院获得性营养不良**是一个被低估的问题：疾病本身增加分解代谢、症状（厌食、恶心、吞咽困难、味觉改变）减少摄入、检查前禁食与治疗副作用进一步削减供给。其后果是免疫力下降、伤口愈合延迟、肌少症、跌倒风险、住院时间延长与预后恶化。**营养状态不是「住院的附属问题」，而是结局的独立决定因素。**

## 42.9 营养过剩与其他代谢异常

能量过剩不仅表现为体脂增加，还通过脂毒性与胰岛素抵抗牵动多条代谢通路：

- **血脂异常**：以甘油三酯升高、高密度脂蛋白降低、低密度脂蛋白增高或颗粒变小为方向性改变，是动脉粥样硬化的直接推手；
- **高尿酸血症与痛风**：尿酸生成过多或肾排泄减少，胰岛素抵抗与内脏脂肪可减少尿酸排泄；尿酸盐结晶沉积于关节与肾，引发急性关节炎与肾损害；
- **非酒精性脂肪性肝病**：异位脂肪在肝沉积 → 脂毒性、炎症 → 部分进展为纤维化与肝硬化，是「代谢因素直接造成器官结构损伤」的范例；
- **胆石症**：肥胖、快速减重、胆汁成分改变促进结石形成；
- **睡眠呼吸暂停**：咽部脂肪沉积与中枢调节改变，夜间低氧又进一步加重胰岛素抵抗，形成环路。

共同背景仍是**能量过剩 + 胰岛素抵抗 + 慢性炎症**三者的叠加。

## 42.10 营养与体重状态的评估

单一指标无法描述营养状态。合理的评估是多维的：

- **人体测量**：体重及其**变化的速度与幅度**（比单次绝对值更有意义）、身高、腰围（反映腹型脂肪）、上臂围与皮褶厚度、肌肉量评估；
- **生化指标**：白蛋白、前白蛋白、转铁蛋白（受炎症影响，须结合病情解读）、血红蛋白、电解质、维生素与微量元素；
- **功能指标**：握力、行走能力、呼吸肌力量——功能下降往往早于体重变化；
- **摄入与消化**：膳食调查、进食能力（咀嚼、吞咽、食欲）、吸收不良线索（腹泻、脂肪泻）；
- **筛查工具**：入院筛查量表用于快速识别风险，阳性者进入详细评估；
- **社会心理**：经济状况、独居、抑郁、酒精使用、认知障碍、饮食文化。

**关于体质指数的局限**：它不区分脂肪与肌肉、不反映脂肪分布、对水肿与肌肉发达者失真。同等体质指数者，肌肉量高与脂肪量高的代谢风险截然不同。因此评估必须结合腰围、肌肉功能与临床背景，而非依赖单一比值。

## 42.11 护理与营养干预原则

- **先筛查，后干预**：所有住院与慢病随访患者应接受营养风险筛查，阳性者进一步评估；
- **优先处理原发病**：感染、疼痛、容量不足、抑郁、口腔问题时，单纯增加供给无效；
- **循序渐进**：长期营养不良者的补充必须缓慢启动（见 42.7），「越多越快」是危险的直觉；
- **途径选择的原则**：能口服则口服，不能口服而胃肠功能可用则管饲，胃肠不可用才考虑静脉；这一阶梯原则兼顾生理性与安全性；
- **监测与记录**：摄入量、体重变化、电解质（尤其磷钾镁）、容量状态、伤口愈合、肌力与活动能力；
- **教育与随访**：解释「为什么不能一次补足」、识别再喂养的早期信号（乏力、心悸、水肿、意识改变）、建立可执行的饮食结构而非抽象建议（本讲义不提供热量方案）；
- **多学科协作**：医师、营养师、护士、康复与心理支持共同参与；
- **避免两个极端**：既不应「饿着养」，也不应「过度喂养」——后者增加代谢负担、血糖波动与呼吸负荷。

## 42.12 生命周期考量

- **儿童**：生长曲线是营养状态最敏感的指标；长期营养不良造成生长迟缓与认知发育受损，追赶生长需在专业指导下进行，过快追赶同样有代谢风险；
- **妊娠与哺乳**：能量、蛋白、铁、叶酸、钙与碘需求增加；孕期营养影响胎儿编程与远期代谢疾病风险；
- **老年**：食欲下降、味觉减退、牙齿与吞咽问题、消化吸收功能下降、社会隔离与抑郁共同导致摄入不足；肌少症使跌倒与失能风险上升，蛋白质摄入与抗阻运动是核心干预；
- **慢性病与术后**：分解代谢占优，营养支持须与疾病治疗同步，且预期效果有限——这不意味着放弃，而意味着设定现实目标。

## 本章小结（Key Points）

- 体重由能量摄入与消耗的长期平衡决定；机体以调定点防御体重，减重后出现代谢适应与饥饿感增强，故易反弹。
- 下丘脑弓状核的 POMC/CART 与 NPY/AgRP 神经元构成促食—抑食对抗系统，接受瘦素、胰岛素、ghrelin 与肠道激素的输入。
- 肥胖涉及遗传、环境、睡眠、应激与药物，脂肪组织作为内分泌器官通过脂肪因子与炎症参与全身代谢；异位脂肪与脂毒性是器官损伤的关键。
- 代谢综合征是内脏脂肪与胰岛素抵抗驱动的异常聚集，各成分互相强化，干预应指向共同环节。
- 饥饿是降低消耗、节省蛋白的适应；应激是高代谢、持续分解的强制状态，二者方向相反，处理逻辑不同。
- 再喂养综合征以胰岛素回升致磷钾镁细胞内移、低磷血症为核心，高危者须缓慢启动并监测电解质。
- 营养不良分消瘦型与水肿型，医院获得性营养不良影响结局；评估须多维，体质指数不能单独使用。

## 单元临床案例（HPP-U11-CASE-01）

> 本案例中出现的检验与体征描述均为**示意性表述**，用于训练机制推理，不代表任何诊断切点或参考范围。

**病例**：李先生，58 岁，长期久坐、腹型肥胖，诊断为 2 型糖尿病多年，用药不规律，平时很少监测。近一周发热、咳嗽、食欲明显下降，自认为「吃得少就不用吃药」，遂自行停用了部分药物。两天来口干加重、尿量明显增多，家属发现其嗜睡、答话迟缓而送医。

入院查体（示意）：明显脱水貌，皮肤弹性差，呼吸深快，呼气有烂苹果味，意识模糊，血压偏低，心率增快。实验室（示意）：血糖显著升高，血酮与尿酮阳性，代谢性酸中毒，血浆渗透压升高，血钾处于「看似正常」的范围，血钠偏高；胸片提示肺部感染。追问病史：近半年体重下降，但腰围未减。

入院后给予补液、静脉胰岛素与抗感染治疗，酸中毒逐步纠正，意识转清。第 3 天恢复经口进食后，出现心悸、乏力加重、心率增快，复查血磷明显下降（示意）。

**问题**：

1. 用第39章的三级轴与反馈概念，说明感染期间其血糖为何迅速失控。
2. 该患者同时存在酮症、酸中毒与高渗脱水，应如何用第41章的三环节模型与 DKA/HHS 对比框架解释？
3. 第 3 天出现的新问题属于哪一类代谢紊乱？机制是什么？与第42章的哪一概念直接对应？
4. 出院前应完成哪些评估与教育（不涉及具体药物剂量与热量方案）？

**要点参考**：

1. 感染为强应激源，激活交感-肾上腺髓质轴与 HPA 轴，儿茶酚胺、皮质醇、胰高血糖素、生长激素升高，共同拮抗胰岛素并促进糖异生；同时感染本身加重胰岛素抵抗。患者原有 β 细胞储备不足（第41章三环节中的「分泌缺陷」），无法以增加分泌来代偿抵抗的上升，负反馈调节失效，血糖迅速升高。停药进一步移除了外源胰岛素作用，使「升糖方向几乎不受约束」的结构性缺陷完全暴露（41.1）。
2. 三环节同时失衡：分泌缺陷（β 细胞储备不足 + 停药）、抵抗加重（感染、皮质醇、儿茶酚胺）、附加环节（脱水致肾灌注下降、渗透性利尿）。胰岛素缺乏接近绝对，脂肪分解失控、酮体大量生成，故有酮症与代谢性酸中毒（DKA 侧）；同时严重脱水使血浆渗透压升高、意识障碍突出（HHS 侧）。该患者处于二者重叠的谱系上，提示「DKA 与 HHS 并非互斥，而是同一失代偿过程的不同侧重」。血钾「看似正常」而总体缺钾，是补钾决策中最易出错之处（41.7）。
3. 再喂养综合征（42.7）。长期摄入不足加感染的高分解代谢使磷、钾、镁总体储备耗竭；恢复进食后胰岛素回升，驱动葡萄糖与这些电解质向细胞内转移，血磷骤降。低磷使 ATP 与 2,3-DPG 生成不足，出现心肌与呼吸肌功能受损、意识改变。护理要点：识别高危、缓慢逐步增加供给、监测磷钾镁与心率呼吸容量状态、补充硫胺素、避免「一次补足」的直觉。
4. 评估：血糖波动模式与监测能力、并发症筛查（眼底、尿蛋白与肾功能、足部感觉与血管、血脂血压）、营养状态（体重变化速度、腰围、肌肉功能、摄入史）、心理状态与治疗负担、自我管理知识与家庭支持。教育：生病日管理（感染时不擅自停药、加密监测、及时就医）、低血糖的识别与处理原则、每日足部检查与鞋袜选择、胰岛素或口服药的规范使用与不骤停原则、出院后随访安排。**不涉及具体剂量与热量方案**——这些属个体化医疗决策。
