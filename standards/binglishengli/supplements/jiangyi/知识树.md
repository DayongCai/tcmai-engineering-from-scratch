## 3. 知识树构建约定

### 3.1 节点 ID
| 层级 | 格式 | 示例 |
|---|---|---|
| 根 | `HPP` | hermes 病理生理学（教材） |
| 单元 | `HPP-U01` … `HPP-U15` | HPP-U02 |
| 章 | `HPP-U01-C01`（章号沿用教材原章号） | HPP-U04-C14 |
| 节 | `HPP-U01-C01-S01` | HPP-U01-C02-S05 |
| 知识点（叶） | `HPP-U01-C01-K01` | HPP-U02-C05-K03 |
| 案例 | `HPP-U01-CASE-01` | HPP-U01-CASE-01 |

### 3.2 节点类型与语义标签
- 类型：`ROOT` / `UNIT` / `CH` / `SEC` / `KP` / `CASE`
- 语义标签（写入节点元数据）：`[概念]`、`[机制]`、`[疾病]`、`[系统]`、`[临床]`、`[案例]`

### 3.3 边类型
- `depends_on`：前置依赖（先学 A 再学 B）
- `refines`：细分（父 → 子）
- `related`：同域关联
- `clinical_map`：临床映射（机制 → 疾病 / 护理措施）

### 3.4 阶段化交付规范
- 15 个阶段 = 15 个单元；每阶段交付一个单元的简体中文讲义正文。
- 每章内部固定结构：**学习目标 → 知识要点 → 关键术语表（中英对照）→ 临床联系 → 本章小结 → 自测题**；每单元末尾附**临床案例 1 则**。

## 6. 学习路径与依赖建议

**主线**：U01 → U02 → U03 → U04 → U05 → U06 → U07 → U08 → U10 → U11 → U12 → U13 → U14 → U15；U09（生殖）、U13（神经心理）可相对独立并行。

**交叉依赖示例**：

| 目标章节 | 前置依赖 | 原因 |
|---|---|---|
| U04（氧运输/凝血/血流/血压） | U03（炎症与免疫） | 血管反应、止血与炎症共享介质与通路 |
| U05（心衰/心律失常/休克） | U04 | 心输出量 = 血压与血流调节的核心变量 |
| U08（AKI/CKD） | U04 + U07 | 肾血流依赖灌注压，容量与电解质影响肾负荷 |
| U11（糖尿病） | U07 + U10 | 代谢失衡与胰腺内分泌功能 |
| U15（烧伤） | U07 + U03 | 大面积烧伤的水电解质失衡与炎症/感染 |
| U12（神经） | U01 + U04 | 脑灌注依赖血压/血流稳态 |
