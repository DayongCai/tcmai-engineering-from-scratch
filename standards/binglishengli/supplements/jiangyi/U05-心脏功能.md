# 第17章 心脏功能（Cardiac Function）

## 学习目标

完成本章学习后，你应当能够：

1. 说明心脏作为「双重泵」的结构基础，指出结构如何决定功能；
2. 描述心肌兴奋-收缩耦联的基本环节，并指出任一环节受损对收缩力的影响；
3. 用压力-容积关系解释收缩期与舒张期的时相划分；
4. 阐明心输出量的四个决定因素，并说明每一因素的作用方向与限度；
5. 用 Frank-Starling 机制与 Laplace 定律解释前负荷、后负荷改变对每搏量的影响；
6. 说明冠脉循环「舒张期灌注为主」与「供-需平衡」对心肌缺血的意义。

## 17.1 心脏的功能定位与结构基础

心脏是串联在循环系统中的**双重泵**：右心接纳体循环回流的静脉血并泵入肺循环，左心接纳肺静脉回流的氧合血并泵入体循环。结构上包括四个腔室（右房、右室、左房、左室）、四组瓣膜（三尖瓣、肺动脉瓣、二尖瓣、主动脉瓣），以及由特殊心肌构成的传导系统（窦房结、房室结、希氏束、左右束支、浦肯野纤维）。

结构决定功能，可以概括为三条对应关系：房室顺序收缩保证心室在舒张期获得充分充盈；瓣膜的单向开放保证血流只能沿「房→室→动脉」方向前进，关闭不全或狭窄都会破坏这一单向性；传导系统保证心房与心室兴奋的顺序性与心室肌收缩的同步性，同步性丧失会使同一心室的不同部位不同时收缩，泵血效率下降。心脏的功能可归为「泵血」与「节律」两件事：前者依赖心肌的收缩与舒张，后者依赖电活动的产生与传导。病理生理学讨论心脏功能，始终围绕这两件事展开。

## 17.2 心肌细胞与兴奋-收缩耦联

心肌分两类：**工作心肌**（收缩细胞，负责产生力）与**特殊心肌**（起搏与传导细胞，负责产生与传递电兴奋）。工作心肌呈分支状，细胞间以闰盘连接，闰盘中的缝隙连接使电兴奋在细胞间低阻传导，整个心室因此近似一个「功能合胞体」——这是心室同步收缩的结构基础。

收缩装置是**肌节**：粗肌丝（肌球蛋白）与细肌丝（肌动蛋白）在钙离子与 ATP 参与下反复形成与解离横桥，肌节缩短产生张力。**兴奋-收缩耦联**是一条可以逐步追溯的链条：动作电位沿肌膜与横管传入 → 电压门控钙通道开放 → 少量外钙内流触发肌浆网释放大量钙（钙致钙释放）→ 胞质钙浓度升高 → 钙与肌钙蛋白结合，原肌球蛋白移位，暴露出肌动蛋白上的结合位点 → 横桥形成并摆动 → 心肌收缩。舒张则依赖钙的清除：肌浆网钙泵把钙回摄入网内，钠-钙交换体与肌膜钙泵把钙排出细胞外，胞质钙下降，横桥解离，心肌舒张。

这条链条上任何一环受限都会削弱收缩力：钙内流减少（钙通道阻滞、交感支持不足）、肌浆网摄取或释放障碍（能量依赖的钙泵受损）、ATP 不足（缺血）、收缩蛋白或调节蛋白改变（心肌病、慢性负荷过重）、细胞外基质与相邻细胞的力学耦联破坏（纤维化）。因此「收缩力下降」从来不是单一原因，而应沿链条逐环排查。

## 17.3 心动周期与压力-容积关系

一次心搏分收缩期与舒张期，各含两个时相。**等容收缩期**：房室瓣与半月瓣均关闭，室内压快速上升而容积不变，是「压力上升最快、容积不变」的阶段。室内压超过动脉压时半月瓣开放，进入**射血期**，容积快速下降。射血末心室开始舒张，室内压低于动脉压时半月瓣关闭，进入**等容舒张期**，室内压快速下降而容积不变。室内压低于房内压时房室瓣开放，进入**充盈期**，容积回升；其后的房性收缩为心室补充最后一部分充盈量。

把一次心搏的容积与压力画成环，即**压力-容积环**：环的宽度对应每搏量，环的面积对应每搏做功，环的位置与形状随负荷与收缩力改变而移动。前负荷增加使环向右扩展（舒张末期容积增大）；后负荷增加使环向上、向右移位（射血末残余容积增多）；收缩力增强使环向左上移位（在相同充盈下射血更完全）。理解这张图，就能把四个决定因素的作用「可视化」，而不必依赖任何具体数值。

## 17.4 心输出量及其构成

**心输出量（cardiac output）**是单位时间内心室泵出的血量，等于**心率**与**每搏量**的乘积。每搏量取决于三个因素：前负荷、后负荷、收缩力。因此心输出量的四个决定因素是**前负荷、后负荷、收缩力与心率**——这是本单元的总纲，后续所有关于心衰与休克的讨论都可以回到这四个词上定位。

**心指数**是把心输出量按体表面积标准化后的指标，用于个体间比较；本讲义只记其概念与变化方向，不记数值。心输出量的意义在于它是**组织灌注的总源头**：心输出量不足，各器官灌注随之下降；心输出量长期过高（发热、甲状腺功能亢进、贫血、动静脉分流）则持续增加心脏做功负荷，最终可致心功能耗竭。需要注意，心输出量正常并不等于灌注充分——分布性休克时心输出量可以正常甚至偏高，而组织仍处于灌注不足与氧利用障碍之中。

## 17.5 前负荷（Preload）

**前负荷**指心室舒张末期心肌纤维的初长度，临床上以心室舒张末期容积或充盈压来代表。它回答的问题是：**心室在射血前被「装」了多少血**。

决定前负荷的因素包括：静脉回流量（受血容量、体循环平均充盈压、体位、骨骼肌泵、呼吸泵、静脉瓣功能与静脉张力影响）、心室顺应性（舒张期「容不容易被撑开」，顺应性下降时同样压力只能容纳更少血量）、心率（心率过快使舒张期缩短，充盈时间不足）、房性收缩的贡献（心房颤动时丧失，前负荷下降）、心包腔内压（心包积液或正压通气时升高，阻碍充盈）。

**Frank-Starling 机制**是前负荷的核心规律：在一定范围内，心肌初长度增加使肌节内粗细肌丝重叠更充分、对钙的敏感性提高，收缩力增强、每搏量增加。用一句话概括就是「回心血量增加 → 舒张末期容积增加 → 每搏量增加」。它的生理意义在于让左右心的输出量自动匹配：右心多泵一点，左心也随之多泵一点，避免血液在肺循环或体循环淤积。

临床联系有两面：低血容量时提高前负荷可以改善每搏量，这是补液的机制依据；但过度充盈会使室壁张力与心肌耗氧升高、肺淤血加重，而收缩力不再上升甚至下降（Starling 曲线的平台段与下降段），此时继续扩容只会加重淤血而不增加输出。

## 17.6 后负荷（Afterload）

**后负荷**指心室射血时必须克服的阻力，回答的问题是：**心室把血推出去要费多大力**。它主要由动脉压、动脉血管阻力、大动脉顺应性与瓣膜阻力构成；对左室而言还包括血液本身的惯性阻抗。

**Laplace 定律**给出室壁张力的关系：室壁张力与腔内压和腔半径的乘积成正比，与室壁厚度成反比。这条定律解释了两个常见现象：心室扩大（半径增大）时，为产生同样的腔内压必须付出更高的壁张力与耗氧，因此扩大的心脏「效率更低」；室壁增厚（向心性肥厚）可以在一定程度上把张力拉回，但肥厚本身又增加耗氧、降低顺应性。

后负荷升高的直接后果是每搏量下降：等容收缩期延长、射血期缩短、射血速度减慢，射血末残余血量增多，舒张末期容积被动增加，再通过 Frank-Starling 部分代偿。长期高后负荷则引起向心性肥厚，最终走向收缩功能耗竭。临床联系：高血压、主动脉瓣狭窄、肺动脉高压、使用血管收缩药都会提高后负荷；降低后负荷（扩血管）可提高每搏量，但必须以足够的灌注压为前提，否则器官灌注反而下降。

## 17.7 收缩力（Contractility）

**收缩力**（心肌变力状态）指在给定前负荷与后负荷的条件下，心肌产生张力与缩短速度的能力，是**独立于负荷的心肌内在性质**。这是它与前、后负荷最根本的区别：前负荷与后负荷是「外部条件」，收缩力是「内在能力」。

决定收缩力的因素：胞质钙瞬变的幅度与持续时间、肌丝对钙的敏感性、肌节的长度与排列、能量供应（氧与底物）、收缩蛋白与调节蛋白的完整性、细胞外基质与相邻细胞的力学耦联。

增强收缩力的因素：交感神经兴奋（β 受体介导，钙内流增加、肌浆网摄取与释放增强）、循环儿茶酚胺、甲状腺激素、洋地黄类（抑制钠泵，间接提高胞内钙）。减弱收缩力的因素：心肌缺血与梗死、长期压力或容量负荷过重、酸中毒、低氧、感染与炎症介质、酒精与心肌毒性药物、心肌病。收缩力下降时，压力-容积环变窄并向右下移位：相同的充盈压下每搏量减少，射血末残余血量增多。

## 17.8 心率（Heart Rate）

心率是单位时间的心搏次数，作为心输出量的**乘数因子**起作用，但它的作用受「充盈」与「供氧」两方面的双向限制。

心率增快在一定范围内提高心输出量；但心率过快时，舒张期显著缩短，一方面心室充盈时间不足使每搏量下降，另一方面冠脉灌注主要发生在舒张期，灌注时间缩短使心肌供氧减少，而心肌耗氧又随心率增快而上升——供需同时恶化，心输出量可能不升反降，缺血风险上升。心率过慢时，每搏量可因充盈充分而增加，但心输出量仍可能不足；舒张期过长还会使低压腔过度充盈。

影响心率的因素：窦房结自律性（交感 β 受体兴奋、迷走 M 受体抑制）、循环儿茶酚胺、体温、甲状腺激素、电解质、药物，以及压力感受器反射、化学感受器反射与容量相关的反射。临床联系：发热时心率随体温上升而增快，是代谢需求上升的表现；心动过速与心动过缓都可能通过「充盈不足、供氧减少、耗氧增加」三条途径损害心功能，方向不同而终点相似。

## 17.9 四因素的整合与相互制约

四个决定因素不是四个互不干扰的旋钮，而是通过压力-容积关系彼此耦合、彼此制约。

前负荷增加 → 每搏量增加，但室壁张力与耗氧同时上升，淤血风险上升；后负荷降低 → 每搏量增加，但器官灌注压下降；收缩力增强 → 每搏量增加，但耗氧上升、能量储备消耗加快；心率增快 → 单位时间心搏数增加，但充盈时间与冠脉灌注时间被压缩。任何单一因素的极端改变，都会被其他因素的连带效应抵消一部分，因此「把某一个指标推到极限」往往得不到预期的心输出量收益。

机体在运动、失血、发热、体位改变时，靠自主神经与体液因素**同时对四个因素做协调调整**。以运动为例：交感兴奋提高心率与收缩力；骨骼肌泵与静脉收缩提高回心血量，即提高前负荷；骨骼肌小动脉扩张降低外周阻力，即降低后负荷。三者同向发力，心输出量成倍上升而血压仅轻度升高。理解这种「同时调整、彼此制约」的整体观，是理解代偿与失代偿的分水岭。

## 17.10 心输出量的整体调节

心输出量受「心脏自身能力」与「外周需求」双向调节，可归为四组因素。

外周因素：静脉回流量（决定前负荷）、动脉阻力（决定后负荷）、组织代谢需求（局部代谢产物扩张血管并促进回流）、血容量、体位与胸腔内压。神经因素：交感与副交感对心率、收缩力、传导速度与静脉张力的作用。体液因素：儿茶酚胺、血管紧张素Ⅱ、醛固酮、抗利尿激素、甲状腺激素、利钠肽。局部因素：冠脉血流的内皮调节，如一氧化氮与腺苷参与的舒缩平衡。

调节的本质是**需求与供给的匹配**：组织需氧上升 → 局部血管扩张、代谢产物堆积 → 静脉回流增加 → 前负荷上升 → 每搏量上升（Starling 机制）；同时交感兴奋 → 心率与收缩力上升。两条通路叠加，心输出量随需求上调；需求回落后，迷走张力恢复、前负荷下降，心输出量回落。这一「上调-回落」的弹性，就是心脏的功能储备。

## 17.11 冠脉循环与心肌供氧

心肌几乎完全依赖有氧代谢，氧储备很小，对血流中断极为敏感——这是心肌与骨骼肌最重要的差别之一。

冠脉循环有两个特点。其一，**舒张期灌注为主**：左室收缩期壁内血管被挤压，血流明显减少，冠脉血流主要在舒张期完成，因此心率过快、舒张压过低都会直接削减供氧。其二，**自主调节能力强**：在灌注压的一定范围内，冠脉小动脉通过自身舒缩维持血流相对恒定，使供氧不随血压波动而同步波动。

心肌供氧取决于冠脉血流量与血氧含量；冠脉血流取决于灌注压（主动脉压与右房压之差）与冠脉阻力。心肌耗氧的主要决定因素是心率、收缩力与室壁张力（由前负荷与后负荷共同决定）。因此「**供-需平衡**」是理解心肌缺血的钥匙：需求上升（运动、发热、甲状腺功能亢进、心肌肥厚）或供给下降（冠脉狭窄或痉挛、贫血、低氧、舒张压过低、舒张期过短）都能造成缺血，而临床上常见的缺血往往是供需两端同时恶化的结果。

## 17.12 心脏功能的评估方向

评估心脏功能时，应把收集到的信息归入几个**方向**，而不是去背数值。可用的方向有六个：

症状方向——活动耐量下降、呼吸困难、乏力、心悸、水肿；体征方向——颈静脉充盈、肺部啰音、心音改变、杂音、外周水肿、脉搏性质与节律；结构方向——心腔大小、室壁厚度、瓣膜形态与运动、心包情况；功能方向——收缩功能与舒张功能、每搏量、充盈压的估计；电活动方向——节律、频率、传导与复极；生化与体液方向——利钠肽升高提示室壁张力增高，心肌损伤标志物升高提示心肌坏死。

把「症状-体征-结构-功能-电-生化」六个方向串起来，才能形成机制化的临床判断：例如「活动后气促 + 肺部啰音 + 心腔扩大 + 收缩功能减弱」指向泵功能失衡导致的肺淤血；而「心悸 + 脉搏短绌 + 节律绝对不齐」指向节律失衡。此处只强调方向与类别，具体分级阈值属于各专科标准，不在本讲义范围。

## 本章小结（Key Points）

- 心脏是双重泵，结构决定功能：房室顺序收缩保证充盈，瓣膜保证单向血流，传导系统保证顺序与同步；
- 收缩力来自兴奋-收缩耦联链条，钙的进入、释放、回收与能量供应任一环受损都削弱收缩；
- 心输出量 = 心率 × 每搏量；每搏量由前负荷、后负荷、收缩力决定，故四个决定因素是总纲；
- Frank-Starling 机制让前后负荷与输出量自动匹配，但有平台与下降段；
- Laplace 定律说明心脏扩大时代价更高：同样压力需要更大壁张力与耗氧；
- 心率是乘数因子，受充盈时间与冠脉灌注的双向限制；
- 冠脉以舒张期灌注为主，心肌缺血本质是供-需失衡。

# 第18章 心脏功能异常（Alterations in Cardiac Function）

## 学习目标

完成本章学习后，你应当能够：

1. 用「泵、节律、瓣膜、冠脉」四类框架对心脏功能异常作出归类；
2. 区分收缩功能障碍与舒张功能障碍的机制与表现方向；
3. 说明冲动形成异常与传导异常分别如何改变心脏的泵血效率；
4. 比较瓣膜狭窄与关闭不全的力学后果差异；
5. 用供-需失衡解释心肌缺血，并说明梗死后的结构改变；
6. 说明四类失衡如何相互转化并走向共同终点。

## 18.1 分类框架：四类失衡

心脏功能异常的表现千变万化，但机制上可以归入四类**失衡**，这是本章的总纲：

**泵功能失衡**——心肌的收缩或舒张能力受损，心脏作为泵的做功能力下降，包括收缩力下降与舒张充盈受限两种方向。**节律失衡**——电活动的产生或传导异常，使心搏的频率、顺序或同步性改变。**瓣膜失衡**——瓣膜狭窄（开放不全）或关闭不全（关闭不严），使血流的方向与阻力异常。**冠脉失衡**——心肌的供氧与耗氧失去平衡，导致缺血、损伤乃至坏死。

四类失衡的划分不是为了贴标签，而是为了**定位**：同一患者可以同时存在多类失衡，且四类之间通过负荷、氧耗与结构重塑互相转化。临床上见到的「心衰」，往往是四类失衡长期作用后的共同终点。

## 18.2 泵功能失衡之一：收缩力下降

收缩力下降是最直观的泵功能失衡，机制可沿兴奋-收缩耦联链条逐环追溯：钙内流或肌浆网释放不足、肌丝对钙的敏感性下降、收缩蛋白改变、能量供应不足、细胞外基质纤维化使力学耦联失效、心肌细胞丢失（坏死或凋亡）使收缩单位减少。

后果是每搏量下降、射血末残余血量增多、舒张末期容积被动上升。机体先靠 Frank-Starling 与交感兴奋代偿，因此在相当长的时间内患者可以「没有症状」——这就是收缩功能已受损而临床仍稳定的原因。当代偿耗尽，前负荷的被动升高转为淤血，交感长期兴奋转为耗氧增加与心律失常，才出现气促、乏力、水肿等表现。这一「损伤先行、症状后至」的时序，是理解心衰自然史的关键。

还要区分「绝对不足」与「相对不足」：前者静息时输出即偏低，后者只在活动、感染抬高需求时才显露。同样程度的收缩受损落在不同需求背景上，表现可以相差很远。

## 18.3 泵功能失衡之二：舒张功能障碍与充盈受限

舒张功能障碍指心室**舒张期不能充分松弛或不能充分容纳血液**，其核心是充盈受阻而非射血无力。机制包括：心肌主动松弛需要 ATP 依赖的钙回收，缺血或能量不足时松弛延迟；心肌肥厚与纤维化使心室僵硬度升高、顺应性下降；心包病变（心包积液、缩窄性心包炎）从外部限制充盈。

后果是：在同样充盈压下舒张末期容积偏小，每搏量下降；而为了维持充盈，房内压与静脉压被动升高，因此肺淤血与体循环淤血的症状可以出现在收缩功能尚可的患者身上。这类患者的典型矛盾是「射血能力不差，却一动就气促」——因为心率增快时舒张期缩短，充盈进一步受限，每搏量无法随需求上调。识别这一方向，对解释「症状与收缩功能不平行」的病例十分重要。

另一条线索是容量与压力关系的斜率：僵硬度升高后，同样幅度的容量增加会引起更大幅度的充盈压上升。故这类患者对输液速度与钠水负荷格外敏感——容量稍多即转肺淤血，稍少又充盈不足。

## 18.4 节律失衡：冲动形成与传导

节律失衡分两个机制方向。

**冲动形成异常**：窦房结自律性过高或过低，或窦房结以外的异位起搏点（心房、房室交界、心室）抢先发放冲动。异位冲动若频率过快，心室充盈时间不足；若起源在心室，因不经过正常传导系统，心室除极不同步，收缩效率下降。

**传导异常**：冲动在传导系统中被阻滞（房室阻滞、束支阻滞），使心房与心室失去顺序，或使心室失去同步；也可因存在异常通路而形成折返，产生快速而规则或不规则的节律。

后果方向可以统一表述为三条：**频率**改变影响充盈与冠脉灌注时间；**顺序**丧失使房性收缩对充盈的贡献消失；**同步性**丧失使心室各部分不同时收缩，泵血效率下降。这三条不需要任何数值就能解释为什么同样「跳得快」，有的患者尚能维持，有的迅速失代偿。

## 18.5 瓣膜失衡之一：狭窄

瓣膜狭窄指瓣膜开放不全，血流通过受阻，其力学后果是**阻力负荷（压力负荷）增加**。

以左心瓣膜狭窄为例：狭窄使心室射血必须产生更高的腔内压，即**后负荷升高**；为克服长期高压，心室发生**向心性肥厚**（室壁增厚、心腔不扩大），按 Laplace 定律可暂时把室壁张力拉回，但代价是心肌耗氧增加、顺应性下降（舒张功能受损）、冠脉灌注相对不足。因此狭窄性病变的典型演变是：后负荷升高 → 向心性肥厚 → 舒张功能障碍与心肌缺血 → 收缩功能耗竭。

狭窄的另一后果是狭窄前后的压力差与血流湍流，产生杂音；跨瓣压差越大，杂音与血流动力学意义越显著（具体分级属专科标准，本讲义不记数值）。

## 18.6 瓣膜失衡之二：关闭不全

瓣膜关闭不全指瓣膜关闭不严，血液在收缩期或舒张期反向流动，其力学后果是**容量负荷（前负荷）增加**。

机制上分两类：瓣叶病变（增厚、脱垂、穿孔）与瓣环/腱索/乳头肌病变（扩张、断裂、功能不全）。后果是：反流使有效前向血流减少，同时使心室在舒张期接纳「正常回流 + 反流量」的额外容量，即**前负荷升高**。长期容量负荷引起**离心性肥厚**（心腔扩大、室壁相对变薄），按 Laplace 定律腔半径增大使壁张力升高，形成「扩大 → 张力升高 → 进一步扩大」的循环。

比较两类瓣膜失衡是有价值的思维训练：狭窄以**压力负荷**为主、导致向心性肥厚、以舒张功能受损为早期表现；关闭不全以**容量负荷**为主、导致离心性肥厚、以收缩功能受损与心腔扩大为特征。两者最终都可以走到心衰，但路径不同，这决定了临床关注点的不同。

起病速度同样重要：慢性反流有时间扩大心腔、以离心性肥厚拉回壁张力，故可长期无症状；急性反流（如腱索断裂）来不及扩大，容量骤压入未扩张的心室，充盈压急升、前向输出骤减，可迅速致肺水肿。

## 18.7 冠脉失衡之一：供需失衡与心绞痛

冠脉失衡的本质是**心肌供氧与耗氧之间的失衡**，而非单纯的「血管堵了」。

供给侧的下降因素：冠脉固定狭窄（粥样斑块）、冠脉痉挛、微血管功能障碍、贫血或低氧使血氧含量下降、舒张压过低或舒张期过短使灌注时间不足。需求侧的上升因素：心率增快、收缩力增强、室壁张力升高（前负荷或后负荷增加）、心肌肥厚使单位心肌耗氧上升。

当需求超过供给，心肌局部代谢产物堆积（腺苷等）引起疼痛与不适，即**心绞痛**；此时心肌尚未发生不可逆损伤，属于「可逆的供需失衡」。典型的稳定型心绞痛有固定的诱因（劳力、情绪、寒冷、饱餐），休息或去除诱因后缓解——这正说明其机制是可逆的供需失衡。不稳定型的特征是诱因阈值下降或在静息时发作，提示供需平衡被进一步打破。

慢性缺血还有一种主动的功能下调：心肌在持续低灌注下降低收缩强度以减少耗氧，细胞得以存活但做功下降。故收缩减弱在恢复灌注后可部分回升——「功能差」与「已坏死」是两件事。

## 18.8 冠脉失衡之二：梗死与重构

当缺血持续且严重到一定程度，心肌由可逆的缺血转为**不可逆的坏死**（梗死）。坏死的顺序性值得记住：心内膜下心肌对缺血最敏感，故坏死常自内向外扩展；坏死区失去收缩能力，该区域在收缩期不但不缩短，反而被腔内压顶出（矛盾运动），使每搏量进一步下降。

梗死后进入**重构**过程：坏死区被纤维瘢痕替代（无收缩力、无电活动，成为折返的解剖基础）；非坏死区承受更高的壁张力而发生代偿性肥厚；心腔几何形状改变（趋向球形），按 Laplace 定律壁张力进一步升高。重构的后果是三重叠加：收缩单位减少、壁张力升高、电活动不均一（易发心律失常）。

因此「梗死 → 重构 → 心衰与心律失常」是一条典型的因果链，而重构是可以被干预的环节，这也是梗死后长期治疗的理论基础。

恢复血流本身也可造成二次损伤：氧自由基、钙超载与炎症在再灌注时加重细胞伤害，微血管阻塞又使部分区域「通了血仍不灌注」。故梗死范围不只由缺血时间决定，也由再灌注是否及时充分决定。

## 18.9 心内分流与先天性结构异常

先天性结构异常可以简化为「分流」与「梗阻」两类机制。

**左向右分流**（如房间隔缺损、室间隔缺损、动脉导管未闭）：氧合血回流至右心与肺循环，使肺循环血流量增多、右心容量负荷增加；长期肺血流增多引起肺血管收缩与重构、肺动脉压升高，最终可逆转为**右向左分流**，出现发绀——这解释了某些先天性心脏病患者「先不紫、后发紫」的演变。

**梗阻性病变**（如肺动脉瓣狭窄、主动脉缩窄）：机制与瓣膜狭窄相同，为压力负荷增加与向心性肥厚。

先天性异常的病理生理意义在于：**异常的负荷分配从生命早期就开始**，因此结构重塑与功能储备的消耗都发生得更早，代偿期的「无症状窗口」也更短。

## 18.10 心包与心外因素

心脏功能不只取决于心肌本身，还受心包与心外因素制约。

**心包因素**：心包积液使心包腔内压升高，外部压迫限制心室充盈（舒张功能受限）；积液快速积聚时，因心包扩张能力有限，少量液体即可显著阻碍充盈，形成**心脏压塞**的机制基础——其关键不是液量多少，而是「积聚速度与心包顺应性」。缩窄性心包炎则因心包增厚钙化，使舒张期充盈在早期即被「硬性」限制。

**心外因素**：胸腔内压升高（正压通气、张力性气胸）减少静脉回流；腹腔内压升高同样压迫下腔静脉；甲状腺功能亢进提高代谢率与心率；贫血降低血氧含量、迫使心输出量上升；感染与炎症介质直接抑制心肌收缩力。把心外因素纳入考虑，能避免把「心脏表现」一律归因于心脏本身。

## 18.11 四类失衡的相互转化

四类失衡并非彼此孤立，而是通过负荷、氧耗与结构重塑互相转化，这是本章最重要的整合观点。

泵功能下降 → 每搏量减少 → 肾灌注下降与交感兴奋 → 血容量与前负荷上升 → 室壁张力升高 → 心肌耗氧上升 → 冠脉失衡（缺血）；长期容量与压力负荷 → 心腔扩大与心肌肥厚 → 传导路径改变与纤维化 → 节律失衡；节律失衡 → 充盈时间不足与同步性丧失 → 泵功能进一步下降。瓣膜失衡则同时提供压力或容量负荷，从起点推动上述循环。

这就是为什么临床上很难见到「单纯一种失衡」的患者：四类失衡构成一个正反馈网络，任何一类持续存在都会牵动其余三类。理解这张网络，才能理解为何治疗常常需要同时针对多个环节，也才能理解为何「去除初始病因」并不总能逆转病情——网络一旦启动，便有了自身的惯性。

网络的惯性也说明时机有价值：负荷刚升高、结构未变时打断循环，代价最小；几何与电活动都已重塑后，干预只能延缓而难以回退。判断患者处在网络哪一段，比判断属于哪一类更能指导决策。

## 18.12 临床识别的方向性线索

把四类失衡与临床表现对应起来，可以形成一套方向性线索，用于初步定位。

泵功能失衡：活动耐量下降、乏力、端坐呼吸、肺部啰音、外周水肿、颈静脉充盈、心音低钝。节律失衡：心悸、脉搏短绌、节律不齐、突发突止的晕厥或黑蒙。瓣膜失衡：特征性杂音、震颤、脉搏性质改变（细迟脉或水冲脉）、心腔扩大或肥厚。冠脉失衡：与劳力相关的不适、放射痛、出汗、活动后气促。

需要强调三点：其一，线索只指示方向，确诊依赖结构与功能的客观评估；其二，多类失衡并存时表现会互相掩盖（如严重瓣膜狭窄合并心房颤动，杂音与节律都可被误读）；其三，老年人与糖尿病患者的表现常不典型，缺血可以仅表现为气促或乏力而无疼痛。本讲义只给方向与类别，不列诊断阈值。

| dysrhythmia | 心律失常 | ectopic focus | 异位起搏点 |
| reentry | 折返 | conduction block | 传导阻滞 |
| myocardial ischemia | 心肌缺血 | angina pectoris | 心绞痛 |
| infarction | 梗死 | remodeling | 重构 |
| fibrous scar | 纤维瘢痕 | paradoxical motion | 矛盾运动 |
| shunt | 分流 | cyanosis | 发绀 |
| cardiac tamponade | 心脏压塞 | constrictive pericarditis | 缩窄性心包炎 |
| reperfusion injury | 再灌注损伤 | hibernating myocardium | 冬眠心肌 |
| afterload mismatch | 后负荷失配 | functional reserve | 功能储备 |

## 本章小结（Key Points）

- 心脏功能异常归为四类失衡：泵、节律、瓣膜、冠脉，用于定位而非贴标签；
- 泵功能失衡有两条方向：收缩力下降（射血无力）与舒张充盈受限（充盈受阻），后者可解释「症状与收缩功能不平行」；
- 节律失衡的后果统一为三条：频率、顺序、同步性改变；
- 瓣膜狭窄是压力负荷 → 向心性肥厚 → 舒张功能受损；关闭不全是容量负荷 → 离心性肥厚 → 心腔扩大；
- 心肌缺血是供-需失衡，可逆阶段为心绞痛，不可逆阶段为梗死；
- 梗死后重构带来三重后果：收缩单位减少、壁张力升高、电活动不均一；
- 四类失衡通过负荷、氧耗与重构构成正反馈网络，故临床多为混合型；
- 起病速度会改写同一机制的后果：急性反流与急性缺血没有代偿与重构的时间，故表现比慢性病变更凶险；缺血损伤的范围既由缺血时间决定，也由再灌注是否及时充分决定。

# 第19章 心力衰竭与心律失常（Heart Failure and Dysrhythmias）

## 学习目标

完成本章学习后，你应当能够：

1. 说明心力衰竭的本质是泵功能不能满足代谢需要，而非单一指标异常；
2. 按「代偿—重构—失代偿」三段描述心衰的演进；
3. 列举神经-体液代偿的主要系统及其短期益处与长期代价；
4. 说明重构在心肌、间质、几何与电活动四个层次的表现；
5. 归类心律失常的发生机制并说明其后果方向；
6. 解释心衰与心律失常如何互为因果。

## 19.1 心力衰竭的概念与分类方向

**心力衰竭**的本质是：心脏的泵血能力不足以满足机体代谢需要，或仅在充盈压升高的代价下才能满足。这个定义包含两个要点：一是**相对不足**——需求上升时供不上也算心衰；二是**代价**——靠提高充盈压维持输出，就会带来淤血。

分类只记方向，不记数值。按发生速度分**急性**与**慢性**；按受累部位分**左心衰、右心衰与全心衰**；按泵功能失衡的方向分**收缩性（射血无力）** 与**舒张性（充盈受阻）**；按心输出量分**低输出量型**（多数）与**高输出量型**（甲状腺功能亢进、贫血、动静脉分流等需求过高所致）。高输出量型容易被忽略，因为「输出量不低」并不等于「需求被满足」。

急与慢的差别值得记住：慢性心衰有时间完成代偿与重构，症状多由淤血逐步显现；急性者来不及重构，只能立即动用 Starling 与交感，故低输出与淤血并存，表现更凶险。

## 19.2 代偿一：Frank-Starling 与心率

心衰的演进可以写成三段：**代偿 → 重构 → 失代偿**。第一段是代偿，最先启动的是两个「即时」机制。

**Frank-Starling 代偿**：每搏量下降使射血末残余血量增多，舒张末期容积被动上升，初长度增加使收缩力增强，每搏量回升。这一机制不需要神经体液参与，几秒内即可生效，因此被称为「第一道防线」。但它的代价是充盈压升高——淤血由此开始。

**心率代偿**：心输出量下降触发交感兴奋，心率增快以维持单位时间输出量。代价是舒张期缩短，冠脉灌注时间减少、心室充盈时间不足，同时耗氧上升。因此心率代偿是「借未来的供氧换眼前的输出」。

回到 Starling 机制：它的代偿有上限——容积超过一定程度后，肌节过度牵拉使有效重叠减少，收缩力反降，曲线进入平台乃至下降段。心衰的心脏正被推在这段区间，继续扩容换不来输出，只换来充盈压。

## 19.3 代偿二：神经-体液系统

第二层代偿是神经-体液系统，启动稍慢但作用更强、持续更久。

**交感神经系统**：心输出量下降被压力感受器感知，交感张力升高，心率与收缩力上升、静脉收缩提高回心血量、外周血管收缩维持血压并重新分配血流（心、脑优先）。短期益处明确：维持灌注压与输出量。长期代价同样明确：心肌耗氧上升、心律失常易感性升高、心肌细胞凋亡增加、外周阻力升高使后负荷上升。

**肾素-血管紧张素-醛固酮系统（RAAS）**：肾灌注下降与交感兴奋触发肾素释放，血管紧张素Ⅱ收缩血管、促进醛固酮分泌；醛固酮促进钠水重吸收，提高血容量与前负荷。短期益处是维持血压与充盈；长期代价是水钠潴留加重淤血、血管与心肌纤维化、重构加速。

**其他**：抗利尿激素释放增加（水潴留、低钠倾向）；利钠肽系统被激活（利钠利尿、抑制 RAAS），是机体**对抗**过度代偿的内源性负调节——但在心衰中其效应常被更强的 RAAS 与交感所压倒。

## 19.4 代偿三：心肌肥厚

第三层代偿是**结构代偿**，需数周至数月形成，是「把心脏改造得更能承重」。

压力负荷引起**向心性肥厚**：肌节并联增加，室壁增厚、心腔不扩大，按 Laplace 定律可降低室壁张力。容量负荷引起**离心性肥厚**：肌节串联增加，心腔扩大、室壁相对变薄。

肥厚的短期益处是降低壁张力、维持射血；长期代价有四条：肥厚心肌的**毛细血管密度相对不足**，供需失衡倾向加重；肥厚心肌**顺应性下降**，舒张功能受损；肥厚心肌**电活动不均一**，心律失常易感；肥厚是**有限度的**，且伴随纤维化与细胞凋亡，最终从「代偿性肥厚」转为「病理性重构」。

所谓「限度」由供血决定：毛细血管不随心肌同步增生，室壁越厚，心内膜下越易缺血；而肥厚心肌又需要更长的舒张期来灌注，恰与心率增快相冲突。两者叠加，肥厚便从「增强承重」转为「加重供需矛盾」。

## 19.5 代偿的代价：为什么代偿会走向反面

把三层代偿放在一起看，会发现一个共同的困境：**每一种代偿都以消耗储备或加重负荷为代价**。

Starling 代偿以充盈压升高为代价 → 肺淤血与体循环淤血；心率代偿以舒张期缩短与耗氧上升为代价 → 缺血与充盈不足；交感代偿以后负荷上升与心律失常为代价；RAAS 代偿以水钠潴留与纤维化为代价；肥厚代偿以顺应性下降、毛细血管相对不足与电不均一为代价。

因此「代偿期」并不是安全的稳态，而是**以持续透支换取表面稳定**的阶段。这也解释了一个临床上反复出现的现象：患者在代偿期可以长期无明显症状，一旦某个诱因（感染、心律失常、贫血、停药、过量输液、妊娠）叠加，就从「稳定」直接坠入「失代偿」——因为储备已被透支干净，没有余量应对新增负荷。

三层代偿的时间尺度并不相同：Starling 以秒计，心率与交感以分计，RAAS 以小时计，肥厚以周月计。越晚启动的机制越耐用，也越难撤除；当每一层都已上线，心脏便没有可再动员的层次，失代偿只差一个诱因。

## 19.6 重构：结构重塑的四个层次

**重构（remodeling）**指心衰进程中心脏的结构性改变，它使心衰从「功能问题」变为「结构问题」，是病情不可逆化的关键环节。可分四个层次记忆。

**心肌层次**：心肌细胞肥大、部分细胞凋亡与坏死、收缩蛋白表型改变（趋向胎儿型，收缩效率下降）。**间质层次**：成纤维细胞活化、胶原沉积、纤维化，使心室僵硬度升高、细胞间力学耦联失效。**几何层次**：心腔由椭球趋向球形，腔半径增大使壁张力升高（Laplace 定律），形成「扩大—张力升高—再扩大」的正反馈；乳头肌移位加重房室瓣反流。**电活动层次**：纤维化与肥厚造成传导速度不均、复极离散，形成折返的解剖与功能基础，即「电重构」。

重构的意义在于：即使初始病因被去除（如血压控制、瓣膜置换），已形成的重构仍可自行推进。这就是「病因治疗不等于病情逆转」的机制解释，也是为何干预越早越有利。

## 19.7 失代偿的发生

**失代偿**指代偿机制不再足以维持足够的输出量，或必须以不可接受的充盈压为代价。发生机制可以归为三条路径。

其一，**储备耗尽**：肥厚已达极限、心率已无法再快、Starling 曲线已进入平台或下降段，任何新增需求都无法被吸收。其二，**代偿机制自身致病**：长期交感与 RAAS 激活直接损害心肌（凋亡、纤维化）、升高后负荷、潴留水钠，使「救急的手段」成为「加重的推手」。其三，**诱因叠加**：感染（代谢需求上升、炎症抑制心肌）、心律失常（充盈与同步性丧失）、贫血（血氧含量下降）、甲状腺功能亢进、停药、过量输液、妊娠分娩，都在已耗尽的储备上再加负荷。

三条路径常同时存在。理解这一点，就能理解为何失代偿往往「来得突然」而实际上是长期积累的结果。

诱因还可按作用方式归类：**抬高需求**（感染发热、妊娠、甲状腺功能亢进）、**削减供给**（贫血、低氧、心肌缺血）、**骤增负荷**（过量输液、钠摄入骤增、停药后反跳）。三类都能在储备耗尽的心脏上一击致失代偿，故识别与规避诱因本身就是治疗的一环。

## 19.8 临床表现的机制来源

心衰的临床表现可以按「淤血」与「灌注不足」两条主线解释，再按左右心区分。

**左心衰以肺淤血为主**：左室充盈压升高 → 肺静脉与肺毛细血管压升高 → 肺淤血、肺水肿 → 劳力性呼吸困难、端坐呼吸、夜间阵发性呼吸困难、咳嗽、肺部啰音。同时因输出量下降出现乏力、活动耐量下降、尿量减少。

**右心衰以体循环淤血为主**：右室充盈压升高 → 体循环静脉压升高 → 颈静脉充盈、肝大与肝区胀痛、下肢水肿、腹水、胃肠淤血致食欲下降与腹胀。

**全心衰**时两套表现并存，且肺淤血可因右心输出下降而「看似减轻」——这是临床容易被误读的现象：呼吸困难好转不代表病情好转，可能只是右心也衰竭了。

## 19.9 心衰的全身性后果

心衰不是心脏的孤立疾病，而是全身性综合征，其后果可归为几组。

**呼吸系统**：肺淤血降低肺顺应性、增加呼吸做功；肺水肿影响气体交换。**肾脏**：肾灌注下降 + 静脉压升高 + RAAS 激活 → 水钠潴留、肾功能受损（心肾相互作用），形成「淤血加重—肾灌注更差」的循环。**肝脏与消化系统**：肝淤血致肝功能异常与合成能力下降；胃肠淤血致吸收不良、食欲下降。**骨骼肌**：长期低灌注与炎症状态导致肌萎缩、乏力、活动耐量进一步下降（「运动不足—去适应」恶性循环）。**代谢与营养**：慢性炎症与代谢重编程导致体重下降、肌肉消耗（心源性恶病质）。**电解质与内环境**：RAAS 与利尿治疗共同造成低钠、低钾或高钾倾向。

把这些后果并列，可以看到心衰的「综合征」性质：它是多器官相互拖累的网络，而非单器官故障。

## 19.10 心律失常的机制类别

心律失常的机制只记**类别**，不记具体诊断标准。

**冲动形成异常**：一是**自律性改变**——窦房结或异位起搏点的自动除极斜率改变，使发放频率升高或降低；二是**触发活动**——在动作电位复极过程中出现异常的后除极（早期或延迟后除极），达到阈值即触发新的兴奋，常与钙超载、复极延长、洋地黄毒性、低钾低镁相关。

**冲动传导异常**：一是**传导阻滞**——冲动在传导系统某处传导减慢或中断，造成房室顺序丧失或心室不同步；二是**折返**——冲动在存在「一条慢通道、一条快通道」且两者首尾相连的环路中反复循环，是快速性心律失常最常见的机制，其解剖基础常为瘢痕、纤维化或先天性异常通路。

**混合机制**：同一患者可同时存在触发与折返，且心衰的电重构（纤维化、复极离散、传导不均）为两者同时提供土壤。

## 19.11 心律失常的后果方向

后果只看**方向**，可以归为四条。

**血流动力学方向**：频率过快使充盈时间不足、耗氧上升；频率过慢使单位时间输出不足；顺序丧失使房性收缩的充盈贡献消失；同步性丧失使心室各部分不同时收缩，泵血效率下降。四条叠加，可致低血压、晕厥、黑蒙乃至休克。

**缺血方向**：心率增快与舒张期缩短同时削减冠脉灌注并提高耗氧，可诱发或加重心肌缺血。

**血栓方向**：心房失去有效收缩时血流淤滞，易在心房内形成血栓，脱落后造成体循环栓塞——这是「节律失衡」转化为「血管事件」的典型路径。

**结构方向**：长期快速节律可导致心肌功能下降与心腔扩大（节律相关性心肌病），而控制节律后可以部分逆转——这说明节律与结构之间是双向关系。

四条并非各自独立：低输出致脑灌注不足，表现为晕厥与黑蒙；灌注压下降又加重冠脉缺血；心房淤滞促成血栓；快速节律长期作用于结构，反过来加深心衰。故同一心律失常，有人只觉心悸，有人直接休克。

## 19.12 互为因果与干预逻辑

心衰与心律失常构成**双向正反馈**：心衰的电重构（纤维化、肥厚、复极离散、交感兴奋、电解质紊乱）为心律失常提供土壤；心律失常（快速、不规则、不同步）又削减输出、加重缺血、激活神经体液，反过来推进心衰。这一循环是「心衰患者猝死风险高」的主要机制解释。

干预逻辑因此可以按环节归纳，而不涉及具体药物与参数。**去除或减轻初始负荷**：控制血压、纠正瓣膜病变、改善缺血。**阻断过度代偿**：抑制交感与 RAAS 的长期有害效应（这是心衰长期治疗的核心思路）。**逆转或延缓重构**：早期干预、控制负荷、改善供氧。**纠正节律与同步性**：控制频率、恢复顺序、重建同步。**管理诱因与容量**：防治感染、纠正贫血与电解质紊乱、合理管理液体出入量。

对护理而言，这套逻辑对应的是可观察的抓手：体重与出入量、呼吸与啰音、心率与节律、水肿与颈静脉、活动耐量与疲劳、用药依从性与诱因识别。

## 本章小结（Key Points）

- 心衰的本质是泵功能不能满足代谢需要，或只能以升高充盈压为代价满足；
- 演进三段：代偿（Starling、心率、神经体液、肥厚）→ 重构（心肌、间质、几何、电）→ 失代偿；
- 每一种代偿都以消耗储备或加重负荷为代价，故代偿期是「透支换稳定」，储备耗尽后诱因一叠加即失代偿；
- 重构使心衰从功能问题变为结构问题，是「病因去除而病情仍进展」的机制；
- 临床表现按「淤血」与「灌注不足」两线解释，左心以肺淤血为主、右心以体循环淤血为主；
- 心律失常机制只记类别：自律性改变、触发活动、传导阻滞、折返；后果方向为血流动力学、缺血、血栓、结构四条；
- 心衰与心律失常互为因果，干预按「减负荷—阻断过度代偿—延缓重构—纠正节律—管理诱因」的环节逻辑展开；
- 代偿有层次也有时间尺度（秒、分、小时、周月），越晚启动者越耐用也越难撤除；各层尽数上线后，失代偿只差一个诱因。

# 第20章 休克（Shock）

## 学习目标

完成本章学习后，你应当能够：

1. 说明休克的本质是有效循环血量不足导致组织灌注下降与细胞代谢障碍；
2. 用「有效循环血量三要素」分析不同休克的起始环节；
3. 描述休克的环节链：灌注下降 → 细胞缺氧 → 代谢障碍 → 器官功能受损；
4. 说明微循环改变在休克进程中的意义；
5. 比较代偿期、进展期与难治期在环节上的差别；
6. 比较四类休克的起始环节与血流动力学方向。

## 20.1 休克的概念与本质

**休克**是各种原因引起的**有效循环血量急剧减少**，导致**组织器官灌注不足**、**细胞代谢障碍**与**器官功能受损**的临床综合征。

这个定义把休克与「低血压」明确区分开：休克是**灌注**问题，不是**压力**问题。血压是灌注的驱动力之一，但灌注还取决于血管阻力与血流分布。因此存在两类容易被误判的情形：血压尚可维持而组织已灌注不足（代偿期或分布性休克，靠血管收缩「撑住」血压）；血压偏低而组织灌注尚可（慢性低血压状态）。判断休克要看**灌注不足的证据**——意识、皮肤温度与色泽、尿量、毛细血管再充盈、乳酸倾向——而不只看血压。

休克的共同终点是**细胞能量危机**：氧供不足使有氧代谢受限，ATP 生成下降，离子泵失效，细胞水肿、酸中毒，最终坏死与器官功能衰竭。

## 20.2 有效循环血量的三要素

**有效循环血量**指单位时间内有效参与循环、真正完成组织灌注的血量。它取决于三个要素，任一要素失衡都可启动休克。

**足够的血容量**（容量要素）：失血、脱水、烧伤渗液、第三间隙丢失使绝对容量不足。**有效的心泵功能**（动力要素）：心肌收缩力下降、严重心律失常、瓣膜急性损坏、心脏压塞使泵出的血量不足。**适当的血管床容积与张力**（阻力与分布要素）：血管扩张使容量相对不足（容量未变而「容器」变大）；血管阻塞使血流无法到达组织（梗阻要素）。

三要素的框架价值在于：它把「血压下降」这一共同表现拆解为三条不同的起始路径，从而决定了完全不同的干预方向——补容量、强泵、调张力、解除梗阻。

## 20.3 环节链总览

休克的病理生理可以写成一条**环节链**，这是本章的主线：

有效循环血量下降 → 组织灌注下降（血流减少、分布不均）→ 氧与底物输送不足 → 细胞缺氧与有氧代谢受限 → 无氧酵解增强、乳酸堆积、ATP 生成下降 → 离子泵失效、细胞水肿与酸中毒 → 细胞结构与功能损伤 → 器官功能受损（单一器官 → 多器官）→ 全身代谢与内环境紊乱 → 循环进一步恶化。

链条的关键特征是**因果交替、自我强化**：灌注下降引起酸中毒与血管舒缩障碍，后者又使灌注进一步下降；细胞损伤释放的炎症介质与活性物质损害远隔器官，使「局部灌注不足」演变为「全身炎症与多器官功能障碍」。理解这条链条，就能理解为何休克必须早期干预——一旦进入链条的后段，即使恢复血压也难以逆转细胞与器官损伤。

## 20.4 组织灌注下降的直接后果

灌注下降在组织层面表现为三件事。

**氧输送不足**：氧输送取决于血流量与动脉血氧含量。流量下降是休克的主要问题，但血氧含量下降（贫血、低氧）也可在流量尚可时造成同样的组织缺氧，这解释了为何严重贫血可出现休克样表现。

**血流分布不均**：休克时交感兴奋使血流重新分布，皮肤、内脏、肾脏的血管强烈收缩以保证心、脑灌注。这种「中心化」短期是保护，长期却使内脏与肾脏缺血，成为器官功能障碍的源头。分布性休克时问题更复杂：微循环中部分毛细血管灌注过度、部分完全无灌注，出现「流量不少而氧利用障碍」的现象。

**微循环障碍**：微循环是氧交换的最终场所。休克时微循环经历从痉挛到扩张淤滞再到微血栓形成的过程，使「大血管通畅」而「毛细血管不灌注」。

## 20.5 细胞代谢障碍与结构损伤

细胞层面的改变是休克不可逆化的核心。

**能量代谢转向**：缺氧使氧化磷酸化受限，细胞依赖无氧酵解，ATP 产量大幅下降而乳酸生成增加，形成**乳酸酸中毒**。酸中毒抑制心肌收缩力、降低血管对儿茶酚胺的反应性、削弱凝血功能，构成新的恶化因素。

**离子泵失效**：ATP 不足使钠钾泵无法维持跨膜梯度，细胞内钠与钙蓄积、细胞外钾升高。细胞水肿、线粒体肿胀、溶酶体酶释放，进一步破坏细胞结构。钙超载激活蛋白酶与磷脂酶，直接损伤膜结构。

**细胞死亡与炎症放大**：坏死细胞释放内容物（损伤相关分子模式），激活炎症反应，炎症介质进入循环后损害远隔器官，形成**全身炎症反应**与多器官功能障碍的共同通路。这也是「休克复苏后仍可出现器官衰竭」的原因：损伤在缺血期已埋下，再灌注又带来氧化应激与炎症放大。

## 20.6 微循环的改变

微循环的改变是休克从可逆走向不可逆的**关键转折点**，可分三个阶段理解。

**痉挛期**：交感兴奋与儿茶酚胺释放使微动脉、毛细血管前括约肌强烈收缩，微循环灌流急剧减少。此时血压可能尚可维持（通过增加外周阻力），但组织已缺血——这正是代偿期「血压正常而灌注不足」的机制。

**扩张淤滞期**：缺血与酸中毒使局部血管对儿茶酚胺反应性下降，毛细血管前括约肌松弛而微静脉仍收缩，形成「灌入多、流出少」的淤滞状态。血液在毛细血管内滞留，流体静压升高，液体外渗，有效循环血量进一步减少——休克由此自我加重。

**微血栓期**：血流淤滞、内皮损伤与凝血激活共同促成微血栓形成，毛细血管床被「机械性」阻断，出现「无复流」现象。此时即使大循环恢复，微循环仍不灌注，细胞持续缺氧，器官功能难以恢复。

## 20.7 分期：代偿期

休克按进程分三期，分期的意义在于**识别各期在环节上的差别**，而不是记数值。以下三节只描述环节。

**代偿期（微循环痉挛期）**：有效循环血量下降被压力感受器感知，交感-肾上腺髓质系统强烈兴奋，心率增快、收缩力增强、外周血管收缩、静脉收缩提高回心血量；RAAS 与抗利尿激素激活，水钠潴留、尿量减少以保住容量。

此期的特点是**代偿机制活跃、组织已缺血**：血压可维持甚至略高，而皮肤苍白发凉、脉搏细速、尿量减少、意识清醒但烦躁或淡漠。这是干预的**最佳窗口**——去除病因、恢复容量或泵功能，可完全逆转。若把「血压正常」当作「没有休克」，就会错过这一窗口。

## 20.8 分期：进展期与难治期

**进展期（微循环淤滞期）**：代偿机制不再足以维持灌注，血压开始下降，组织缺氧加重、乳酸堆积、酸中毒形成。微循环进入扩张淤滞状态，液体外渗使有效循环血量进一步减少。临床表现加重：皮肤出现花斑、四肢湿冷、尿量进一步减少、意识由烦躁转为淡漠、心率进一步增快而脉搏更弱。

此期已出现**细胞与器官的功能性损伤**，但若及时纠正灌注，仍可能逆转。干预需同时处理容量、泵功能、血管张力与病因，单靠一种手段往往不足。

**难治期（微血栓期／不可逆期）**：微血栓广泛形成、细胞大面积死亡、多器官功能衰竭，对常规复苏反应差。此期血压难以维持、无尿、意识障碍加深、出现出血倾向（凝血因子消耗）与代谢性酸中毒加重。即使恢复大循环压力，微循环「无复流」与细胞损伤仍使器官功能无法恢复。

三期的差别可以概括为一句话：**代偿期是「灌注不足而压力尚可」，进展期是「压力与灌注同时下降」，难治期是「压力可被支撑而细胞已不能利用」**。

## 20.9 分类：四类休克的起始环节

按起始环节把休克分为四类，是临床思维的核心工具。

**低血容量性休克**：全血或血浆丢失（出血、烧伤）、体液丢失（呕吐、腹泻、脱水）、第三间隙隔离（肠梗阻、胰腺炎）。起始环节是**容量绝对不足** → 回心血量下降 → 前负荷下降 → 每搏量下降。特点：外周血管收缩、脉压减小、中心静脉压偏低。

**心源性休克**：大面积心肌梗死、严重心肌病、急性瓣膜损坏、严重心律失常。起始环节是**泵功能衰竭** → 每搏量下降。特点：外周灌注不足伴肺淤血，中心静脉压偏高。

**分布性休克**：感染性（脓毒症）、过敏性、神经源性。起始环节是**血管床扩张与血流分布异常** → 外周阻力下降、有效循环血量相对不足。特点：早期外周温暖、脉压增宽、心输出量可正常或偏高，而氧利用障碍；过敏性与神经源性以血管扩张与相对容量不足为主。

**梗阻性休克**：心脏压塞、张力性气胸、肺栓塞、主动脉夹层。起始环节是**血流通道被机械性阻断** → 充盈或射血受阻。特点：起病急、对液体复苏反应差，必须解除梗阻。

四类的共同点是「有效循环血量不足」，不同点在**哪一要素先失效**——这就是分类的机制意义。

## 20.10 器官功能受损与多器官功能障碍

休克时器官损伤的顺序与机制值得逐一提及。

**肺**：早期因过度通气出现呼吸性碱中毒，随后肺泡-毛细血管膜损伤、通透性升高，出现急性肺损伤与低氧血症。**肾**：肾灌注下降 + 交感与 RAAS 激活使肾血管强烈收缩，出现少尿与急性肾损伤；若持续缺血则转为肾小管坏死。**脑**：脑灌注下降引起意识改变，从烦躁到淡漠到昏迷，是判断灌注的敏感窗口。**肝**：肝缺血使合成与解毒功能下降，转氨酶升高、凝血因子合成减少。**肠**：肠黏膜屏障在缺血时最早受损，细菌与内毒素移位，成为炎症放大的来源——「肠是休克的发动机」这一说法即源于此。**心**：休克时心肌自身也缺血、酸中毒与炎症介质抑制收缩力，形成「休克加重心衰、心衰加重休克」的循环。**凝血**：组织因子释放与微血栓形成消耗凝血因子，可演变为弥散性血管内凝血，表现为出血与栓塞并存。

多器官功能障碍（MODS）是休克晚期的共同结局，其本质是「炎症-缺血-再灌注」三重损伤的叠加，而非单一器官的原发故障。

## 20.11 临床表现的方向性

休克的临床表现可以按「灌注」这一主线归为几组方向性线索。

**皮肤与末梢**：苍白、湿冷、花斑、毛细血管再充盈延迟——反映外周血管收缩与微循环灌注不足；分布性休克早期可反而温暖干燥，这是重要的鉴别方向。**脉搏与心率**：细速、脉搏减弱、节律不齐；脉压减小提示每搏量下降。**尿量**：减少是最实用的灌注指标之一。**意识**：烦躁、淡漠、定向力下降，反映脑灌注。**呼吸**：初期深快（代偿性），后期可出现呼吸窘迫。**颈静脉与中心静脉压方向**：低血容量时塌陷，心源性与梗阻性时充盈——这一条是区分类型的关键体征。

把这些线索串成一句话：**休克的床旁判断是「灌注的拼图」，而不是单一读数**。本讲义只给方向，不列阈值。

## 20.12 监测与干预的机制依据

干预的每一步都应能对应到环节链上的某一环，这就是「机制化干预」的含义。

**针对容量要素**：评估容量状态后补充容量，目标是恢复前负荷与每搏量；但心源性休克时过量补液会加重肺淤血，因此必须先判断类型。**针对泵功能要素**：改善收缩力、纠正严重心律失常、解除机械性梗阻（压塞、张力性气胸）。**针对血管张力要素**：在容量已纠正而灌注仍不足时调节血管张力，维持必要的灌注压；分布性休克需同时处理感染源与炎症。**针对细胞与代谢**：纠正缺氧、酸中毒与电解质紊乱，保护器官功能。**针对病因**：止血、抗感染、解除梗阻、再灌注——病因不除，任何支持手段都只是拖延。

护理层面的抓手是把机制转成可观察、可报告的指标：意识、皮肤温度与色泽、尿量、脉搏性质、呼吸形态、颈静脉充盈、出入量与体重、以及实验室反映的组织灌注与代谢状态。核心原则是**早识别、早报告、连续评估**——因为休克的时间窗就是器官的命运。

## 本章小结（Key Points）

- 休克是有效循环血量急剧减少导致组织灌注不足、细胞代谢障碍与器官功能受损的综合征；本质是灌注问题而非压力问题；
- 有效循环血量取决于三要素：血容量、心泵功能、血管床容积与张力；任一失效即启动休克；
- 环节链：灌注下降 → 缺氧 → 无氧酵解与 ATP 下降 → 离子泵失效、酸中毒 → 细胞损伤 → 器官功能受损 → 循环进一步恶化，自我强化；
- 微循环经历痉挛、淤滞、微血栓三阶段，是「可逆转不可逆」的转折点；
- 三期差别：代偿期灌注不足而压力尚可；进展期压力与灌注同降；难治期压力可支撑而细胞不能利用；
- 四类休克按起始环节区分：容量不足、泵衰竭、血管扩张与分布异常、机械梗阻；
- 干预必须对应环节链：容量、泵、张力、细胞代谢、病因五条线并行，早识别是器官保护的前提。

## 单元临床案例（HPP-U05-CASE-01）

> 本例所有参数均为**示意**，用于说明机制与环节，不代表任何诊断标准或治疗阈值。

**病例（示意）**：李先生，老年男性，有长期高血压与陈旧性心肌梗死史。近两周活动后气促加重，夜间需垫高枕头方能入睡，双下肢出现凹陷性水肿。某日因受凉发热、咳嗽，气促骤然加重，家属发现其反应迟钝、四肢湿冷，遂送医。

入院时（示意）：神志淡漠，呼吸浅快，口唇轻度发绀；皮肤湿冷、可见花斑，毛细血管再充盈明显延迟；脉搏细速、节律不齐；颈静脉充盈；双肺可闻及湿性啰音；双下肢中度水肿。生命体征与实验室参数从略（示意），仅记录方向：血压偏低、脉压减小，尿量显著减少，动脉血乳酸倾向升高。

**问题**：

1. 请用第17章的四个决定因素，分析李先生「活动后气促加重」的机制。
2. 本次急性加重涉及第18章四类失衡中的哪几类？请说明各自的证据与机制。
3. 用第19章「代偿—重构—失代偿」三段，解释他为何在受凉发热后骤然恶化。
4. 他当前是否处于休克？属于哪一类？请用第20章的环节链说明从「感染」到「四肢湿冷、尿量减少、意识淡漠」的过程。
5. 作为护士，你会优先连续监测哪些方向性指标？各自的机制依据是什么？

**要点参考**：

1. 陈旧梗死使收缩单位减少、收缩力下降（收缩力因素）；左室充盈压升高使肺淤血，活动时心率增快、舒张期缩短，充盈进一步受限（前负荷与心率因素）；长期高血压使后负荷升高、心肌肥厚、顺应性下降（后负荷因素）。四因素叠加，活动耐量下降。
2. 泵功能失衡（陈旧梗死 + 收缩力下降 + 舒张功能受损，证据为气促、啰音、水肿、颈静脉充盈）；节律失衡（脉搏细速且不齐，机制可能为纤维化瘢痕导致的折返或触发活动）；冠脉失衡（高血压与肥厚使耗氧上升、供氧相对不足，发热进一步加剧供需失衡）；瓣膜方向可能有功能性二尖瓣反流（心腔扩大致瓣环扩张），但需客观评估确认。四类失衡并存，符合第18章「正反馈网络」的描述。
3. 代偿期：Starling 机制、心率增快、交感与 RAAS 激活、心肌肥厚共同维持表面稳定；重构期：梗死区瘢痕、非梗死区肥厚、心腔球形化、纤维化致电活动不均一，储备被持续透支；失代偿：受凉发热使代谢需求上升、炎症抑制心肌、心率增快使充盈与冠脉灌注时间缩短、不齐的节律削减输出，多重诱因叠加在已耗尽的储备上，故骤然恶化。
4. 是休克。以心源性成分为主（泵衰竭 + 肺淤血 + 颈静脉充盈），同时因发热感染存在分布性成分（血管扩张、氧利用障碍），属混合型。环节链：感染与发热 → 代谢需求上升、炎症介质抑制心肌 → 每搏量进一步下降 → 有效循环血量不足 → 交感强烈兴奋使皮肤与内脏血管收缩（四肢湿冷、花斑、尿少）→ 组织缺氧、无氧酵解、乳酸升高 → 脑灌注下降（意识淡漠）→ 细胞离子泵失效与器官功能受损。若持续，将进入微循环淤滞与微血栓期。
5. 意识状态（脑灌注）；皮肤温度、色泽与毛细血管再充盈（外周灌注与血管张力）；尿量（肾灌注，最实用的连续指标）；脉搏性质与节律（每搏量与节律）；呼吸形态与肺部啰音（肺淤血与气体交换）；颈静脉充盈度（容量与右心充盈压方向）；出入量与体重（容量平衡）；体温与感染征象（诱因）；以及反映组织灌注与代谢的实验室方向（乳酸倾向、电解质、肾功能）。监测原则是连续、趋势化、早报告。
