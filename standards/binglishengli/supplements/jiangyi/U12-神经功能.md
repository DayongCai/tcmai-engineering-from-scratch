# 第43章 神经系统结构与功能（Structure and Function of the Nervous System）

## 学习目标

完成本章学习后，你应当能够：

1. 按解剖与功能两条轴划分神经系统，并说明中枢各层级结构的主要职责；
2. 描述神经元的结构分区、轴突运输与损伤后的变性方式；
3. 解释静息电位、动作电位的离子基础，以及髓鞘如何影响传导速度；
4. 复述化学突触传递的步骤，区分兴奋性突触后电位与抑制性突触后电位；
5. 归类主要神经递质与受体，说明离子型与代谢型受体的差异；
6. 说明脑血流供应、自动调节、脑脊液循环与血脑屏障如何共同维持脑内稳态。

## 43.1 神经系统的层级组织与功能分区

神经系统按解剖分为**中枢神经系统（central nervous system, CNS）**——脑与脊髓，与**周围神经系统（peripheral nervous system, PNS）**——脑神经、脊神经及其神经节；按功能分为**躯体部分**（支配骨骼肌、传导躯体感觉）与**自主部分**（交感、副交感与肠神经系统，调控内脏、血管与腺体）。这两条分类轴构成解读症状的坐标系：同一种「无力」，病灶在皮层、内囊、脑干、脊髓前角、周围神经或神经肌肉接头，伴随体征完全不同。

CNS 内部呈**层级组织**：

- 脊髓：完成节段反射，并为上行感觉与下行运动纤维提供通道；
- 脑干：承载呼吸、循环等生命中枢与多数脑神经核，是上行网状激活系统的所在；
- 小脑：协调运动的时序、幅度与平衡；
- 基底节：参与运动程序的启动与抑制；
- 丘脑：除嗅觉外全部感觉通往皮层的中转站；
- 大脑皮层：完成感知、运动执行、语言与认知的最高整合。

层级不等于「高层独裁」：运动是皮层、基底节、小脑环路反复迭代的结果，任一环节受损都表现为运动异常，只是形式不同。灰白质布局在脊髓与大脑恰好相反——脊髓灰质在内、白质在外，大脑皮层灰质在外、白质在内；因此髓内病变常呈髓节性、分离性感觉障碍，而皮层下病变（如内囊）常呈对侧偏瘫、偏身感觉障碍与偏盲的组合。

自主部分的第三条支线——**肠神经系统**：它嵌在胃肠壁内，能独立完成局部反射，又接受交感与副交感的调制，因而被称为「腹脑」。交感与副交感对多数器官呈拮抗支配，但拮抗并不对称：交感以去甲肾上腺素为主，按需动员、作用广泛；副交感以乙酰胆碱为主，定位精确、以恢复与储备为务。两者的张力同时存在，器官的实际状态是双方与局部调质叠加的结果，而不是某一方「开」或「关」。这解释了自主神经功能紊乱为何总以组合形式出现——心率、血压、出汗、瞳孔与胃肠同时偏向一侧。

## 43.2 神经元的结构与轴突运输

神经元由**胞体**（代谢中心，含核与粗面内质网）、**树突**（主要输入面，扩大接收面积）、**轴突**（唯一可长距离传导的输出结构）与**突触终末**构成。轴突起始段（轴丘）膜上电压门控钠通道密集，是动作电位的**触发区**；轴突末梢则把电信号转换为化学信号。

轴突内没有核糖体，蛋白与细胞器全靠**轴突运输**获得：顺行快速运输运送囊泡与膜成分，顺行慢速运输运送细胞骨架与可溶性蛋白，逆行运输回收物质并把神经营养信号送回胞体——某些病毒与毒素也借逆行运输入脑。

**临床联系**：轴突运输依赖能量与微管完整性，缺血、中毒或代谢障碍时最先受累的是轴突远端，表现为**远端对称性多神经病**（袜套-手套样感觉障碍、腱反射减弱）。轴突中断后其远端发生沃勒变性（Wallerian degeneration），这是损伤后功能丧失与肌萎缩的结构基础；而胞体的逆行反应决定神经元是存活、萎缩还是凋亡。

## 43.3 静息电位、动作电位与传导

**静息膜电位**主要由钾离子顺浓度外流形成，钠钾泵持续维持跨膜梯度。动作电位的序列是：刺激使膜去极化达**阈值** → 电压门控钠通道开放、钠内流（正反馈式再生）→ 钠通道失活、钾外流复极 → 超极化后电位。动作电位遵循**全或无**规律，刺激强度以**发放频率**而非幅度编码，绝对不应期限制最高频率。

**传导速度**由纤维直径与髓鞘共同决定。有髓纤维的髓鞘使局部电容减小、电流只在郎飞结处交换，形成**跳跃传导**，速度与能量效率同时提高。脱髓鞘改变这两个参数，使传导减慢甚至**阻滞**——这解释了脱髓鞘病变为何出现症状波动，也解释了体温升高时传导阻滞加重（Uhthoff 现象）：温度对钠通道动力学的影响在失去髓鞘的轴突上被放大。

动作电位的产生是有代价的：每恢复一次离子梯度都要耗能，钠钾泵的持续工作占脑能量消耗的相当份额。因此凡使供能受限的状态——低氧、低血糖、缺血——都会先表现为膜电位不稳、传导效率下降与兴奋性改变，而不是立刻的结构破坏。这正是代谢性脑病症状弥漫而波动的原因：没有局灶结构损伤，只有一大群神经元同时「供电不足」。

## 43.4 化学突触传递

化学突触的传递步骤可概括为：动作电位到达终末 → 电压门控钙通道开放、钙内流 → 突触囊泡与前膜融合 → 递质释放入间隙 → 与突触后受体结合 → 离子通道开放或第二信使启动 → 产生**兴奋性突触后电位（EPSP）**或**抑制性突触后电位（IPSP）** → 在触发区做空间与时间**总和**，决定是否发放。

突触传递具有单向性、**突触延搁**与可调制性（突触前抑制与易化）。**神经肌肉接头**是特化的化学突触：乙酰胆碱作用于终板受体，乙酰胆碱酯酶迅速清除递质；受体被自身抗体破坏或递质释放受阻，都会造成神经肌肉传递障碍，表现为易疲劳性无力。

突触并非固定不变的开关。高频刺激引起**长时程增强（LTP）**，低频刺激引起**长时程抑制（LTD）**，二者通过受体数量与敏感性的改变实现——这是学习与记忆的细胞基础，也是慢性疼痛中枢敏化所使用的同一套机制（见 47.6）。

## 43.5 神经递质系统与受体

主要递质可按作用性质归类：

- **谷氨酸**：CNS 主要兴奋性递质；AMPA/Kainate 受体快速开放钠通道，NMDA 受体需去极化解除镁阻滞且允许钙内流——后者是兴奋毒性与突触可塑性的共同入口；
- **GABA**：主要抑制性递质，GABA_A 受体为氯通道，GABA_B 受体经 G 蛋白起作用；
- **甘氨酸**：脊髓与脑干的抑制性递质；
- **乙酰胆碱**：神经肌肉接头、自主神经节、副交感末梢与中枢的觉醒与记忆环路；
- **儿茶酚胺**：多巴胺（运动、动机、奖赏）、去甲肾上腺素（觉醒、警觉、血压）；
- **5-羟色胺**：情绪、睡眠与痛调制；
- **组胺**：觉醒与警觉；
- **神经肽**（P 物质、降钙素基因相关肽、内阿片肽）：多为调质，起效慢、时程长；一氧化氮作为逆行信使从突触后影响突触前。

受体分**离子型**（配体门控通道，毫秒级、快而短暂）与**代谢型**（G 蛋白偶联，经第二信使放大，慢而持久）。同一递质可经不同受体产生相反效应，这解释了为何作用于同一系统的药物效应复杂——理解「增强还是削弱、作用在哪类受体」，比记住药名更有迁移价值。

递质与功能并非一一对应。同一神经元可共存多种递质与神经肽，按发放模式决定释放比例；同一分子在不同脑区可因受体亚型与下游耦联不同而兴奋或抑制。受体本身也是可调的：长期阻断使受体上调（敏感性升高，撤药时反跳），长期激动使其下调（耐受）。这条规则把「起效—耐受—撤药」的现象从经验上升为机制，也是理解依赖与戒断的起点。

## 43.6 神经胶质细胞与髓鞘

胶质细胞的数量超过神经元，功能远不止「支持」：

| 细胞 | 主要功能 | 受累后的后果 |
|---|---|---|
| 星形胶质细胞 | 诱导并维持血脑屏障、缓冲细胞外钾与谷氨酸、参与「三部分突触」、构成胶质瘢痕 | 稳态缓冲失效 → 兴奋毒性、水肿加重；瘢痕阻碍轴突再生 |
| 少突胶质细胞 | 形成 CNS 髓鞘，一个细胞包绕多段轴突 | 脱髓鞘 → 传导减慢或阻滞 |
| 施万细胞 | 形成 PNS 髓鞘，分泌促再生因子、形成引导带 | 周围神经再生能力优于中枢 |
| 小胶质细胞 | 固有免疫、吞噬、突触修剪 | 慢性激活 → 神经炎症，既清除病理蛋白又加重损伤 |
| 室管膜细胞 | 衬覆脑室、参与脑脊液生成与流动 | 脑室壁完整性破坏 → 间质性水肿 |

髓鞘使传导速度提高并节省空间，但把轴突的命运交给了胶质细胞。CNS 再生受限的原因包括胶质瘢痕中的抑制性分子、缺乏许可生长的环境与神经元自身生长能力下降；PNS 因施万细胞形成引导带而能部分再生——这就是为什么周围神经损伤的恢复通常优于脊髓损伤。

## 43.7 脑的血液供应与神经血管单元

脑血供分**前循环**（颈内动脉 → 大脑前、中动脉）与**后循环**（椎-基底动脉 → 大脑后动脉、脑干与小脑分支）；**Willis 环**连接两侧与前后循环，是侧支代偿的解剖基础。皮层支与穿通支受累的后果不同：穿通支（如豆纹动脉）病变常造成基底节与内囊的小灶梗死，表现为纯运动或纯感觉缺损。

灰质的血流与代谢率高于白质，且局部神经元活动经**神经血管单元**（血管内皮、周细胞、星形胶质终足、神经元）耦联为局部血流增加——功能充血是功能成像的生理基础。

**自动调节**指在一定脑灌注压范围内，通过肌源性收缩与代谢性舒缩维持血流相对恒定：压力升高时小动脉收缩，压力下降时舒张。超出上限，血流随压力被动增加（突破性灌注、水肿与出血）；低于下限，血流随压力下降（缺血）。慢性高血压使这条曲线**右移**——患者耐受较高压力，却对血压骤降格外敏感。理解曲线的移动方向，比记住曲线上的点位更重要。

## 43.8 脑脊液循环与颅内腔室

**脑脊液（cerebrospinal fluid, CSF）**主要由脉络丛**主动分泌**，而非单纯超滤。循环路径为：侧脑室 → 室间孔 → 第三脑室 → 中脑水管 → 第四脑室 → 蛛网膜下腔 → 蛛网膜颗粒吸收入静脉窦，少量经神经根鞘与淋巴清除。颅腔内 CSF 总量相对恒定而更新迅速，近年认识的**类淋巴通路**在睡眠时清除效率提高，负责运走代谢废物。

CSF 的三项功能决定了它的病理意义：**浮力**（使脑的实际重量大幅减轻，避免自重压迫颅底）、**机械缓冲**（吸收冲击）、**运输与清除**（供给营养、带走代谢产物）。

分泌与吸收失衡、或通路阻塞，即形成**脑积水**：阻塞位于脑室系统内称**非交通性**（脑室扩大、颅内压升高），阻塞位于蛛网膜颗粒称**交通性**（吸收障碍）。脑室液还可经室管膜渗入室周白质，形成**间质性水肿**（见 44.5）。

## 43.9 血脑屏障与脑内稳态

**血脑屏障（blood-brain barrier, BBB）**由四层构成：脑毛细血管内皮（紧密连接、无窗孔）、基膜、周细胞与星形胶质终足。它是一道**选择性**屏障而非绝对屏障：脂溶性小分子可被动通过，水与离子经特定通道，葡萄糖经 GLUT1、氨基酸经专用转运体进入；内皮还表达**外排泵**，把许多药物泵回血液。

**室周器官**（最后区、穹窿下器、正中隆起、松果体等）缺乏完整屏障，用于感受血源性信号：渗透压升高触发抗利尿激素释放与口渴，血中毒素触发恶心与发热。它们也是药物与毒素引起中枢反应的入口之一。

屏障在缺血、炎症、创伤与高渗状态下被破坏，后果是三重：富含蛋白的液体外漏形成**血管源性水肿**、免疫细胞与病原体入脑、循环中原本难以入脑的药物中枢作用增强。这解释了为何中枢感染需选用能透过屏障的抗菌药，也解释了为何系统性炎症能引起意识改变（不涉及具体药物与剂量）。

## 43.10 神经功能评估的机制基础

神经系统评估不是体征的罗列，而是**由缺损反推部位**的推理过程，其骨架如下：

- **意识**：觉醒依赖脑干上行网状激活系统，内容依赖大脑皮层；两者可分离（清醒但无内容、或睡眠样状态而有反应）；
- **瞳孔**：交感扩瞳、副交感（动眼神经）缩瞳，通路走行于脑干，对占位压迫极敏感；
- **眼球运动**：动眼、滑车、外展神经及其脑干核团联系，可定位脑干平面；
- **运动**：上运动神经元损害表现为肌张力增高、腱反射亢进、病理反射阳性、轻度废用性萎缩；下运动神经元损害表现为弛缓、反射消失、明显肌萎缩与肌束颤动；
- **感觉**：按分布形态定位（皮层型、髓节型、周围神经型、分离性）；
- **脑膜刺激征**：提示蛛网膜下腔受激惹。

定位之后再看**起病方式**：突发提示血管事件，数小时至数天进展提示感染、炎症或代谢，数月以上缓慢进展提示变性或肿瘤。部位与时间两条线索交叉，才形成病因假设——这是后续四章共用的推理框架。

## 本章小结（Key Points）

- 神经系统可按解剖（中枢/周围）与功能（躯体/自主）两条轴划分，CNS 内部呈层级组织，运动依赖多环路的迭代而非单向指令；自主部分除交感与副交感外还有肠神经系统，器官状态由两者张力与局部调质叠加决定。
- 神经元以轴丘为触发区、以轴突运输维持远端存活；轴突中断后远端发生沃勒变性，远端最先受累是代谢性多神经病的特点。
- 动作电位遵循全或无，强度以频率编码；髓鞘通过跳跃传导提高速度，脱髓鞘则使传导减慢或阻滞，并对温度敏感。
- 化学突触传递经历钙内流—囊泡释放—受体激活—突触后电位总和；LTP 与 LTD 是学习记忆与中枢敏化共用的机制。
- 脑血流由前后循环与 Willis 环保障，局部活动经神经血管单元耦联血流；自动调节有一定范围，慢性高血压使其右移。
- 脑脊液由脉络丛主动分泌、经蛛网膜颗粒吸收，承担浮力、缓冲与清除；通路或吸收障碍即脑积水。血脑屏障是选择性屏障，室周器官为例外；屏障破坏导致血管源性水肿、感染入脑与药物中枢作用增强。
- 神经评估的核心是「缺损 → 部位 → 起病方式 → 病因类别」的推理，而非体征清单。

# 第44章 脑功能急性疾病（Acute Disorders of Brain Function）

## 学习目标

完成本章学习后，你应当能够：

1. 复述急性脑损伤从能量衰竭到细胞死亡的共同通路；
2. 按机制区分血栓性、栓塞性与低灌注性缺血，并说明腔隙性梗死的来源；
3. 解释缺血半暗带的时间依赖性与再灌注损伤的双向性；
4. 区分脑实质出血与蛛网膜下腔出血的来源、表现与共同后果；
5. 鉴别细胞毒性、血管源性与间质性脑水肿；
6. 用 Monro-Kellie 学说解释颅内压的代偿与失代偿，并复述「占位 → 移位 → 脑疝」链及各型脑疝的体征。

## 44.1 急性脑功能障碍的共同通路

脑组织几乎没有氧与底物储备，全部依赖持续血流供氧供糖，因此对缺血极为脆弱。能量衰竭引发一条连锁反应：钠钾泵失灵 → 细胞肿胀（细胞毒性水肿）→ 膜去极化 → 谷氨酸大量释放 → NMDA 受体介导**钙超载** → 蛋白酶、脂酶与自由基激活、线粒体通透性转换 → 膜、蛋白与 DNA 损伤 → 坏死与凋亡并存。

同时，损伤触发炎症：小胶质细胞与浸润的白细胞释放细胞因子，血脑屏障被破坏，血管源性水肿叠加于细胞毒性水肿之上。**能量衰竭—兴奋毒性—钙超载—氧化应激—炎症—水肿**这条链是缺血、创伤、感染与癫痫持续状态共有的终末通路，也是各类治疗共同指向的环节。理解这条链的意义在于：急性脑损伤的可干预部分，几乎都在「链」上而非「起点」上。

这条链还解释了一个临床现象：不同病因的急性脑病在早期可以表现得极为相似——意识模糊、瞳孔改变、呼吸模式异常——因为终点相同；而同一病因在不同患者身上轻重悬殊，差别常在于**侧支循环、体温、血糖与是否发生癫痫**这些调节因子，而不是病因本身。所以急性期的评估应当先确定「处在链的哪一段」，再追问「起点是什么」。

## 44.2 缺血性卒中：血栓、栓塞与低灌注

缺血性卒中的机制可分三类，起病方式是最重要的鉴别线索：

| 机制 | 来源 | 起病特点 | 常见受累 |
|---|---|---|---|
| 血栓性 | 动脉粥样硬化斑块破裂处原位血栓 | 相对渐进、可波动进展 | 颈动脉分叉、大脑中动脉主干 |
| 栓塞性 | 心源性（房颤、瓣膜病）或动脉-动脉栓塞 | 突然起病、迅速达高峰 | 皮层区，易出血性转化 |
| 低灌注性 | 严重狭窄或全身低血压 | 与体位、血压波动相关 | 分水岭区（边缘带） |

**腔隙性梗死**源于穿通支的小血管病变（长期高血压、糖尿病），病灶小、位于深部白质、基底节、丘脑与脑桥，表现为纯运动性轻偏瘫、纯感觉性障碍或构音-手笨拙等「腔隙综合征」。其预后相对较好，但复发提示小血管病变已广泛，是认知下降与步态障碍的底层原因。

## 44.3 缺血半暗带、再灌注损伤与时间依赖

梗死**核心**是已发生不可逆坏死的组织；其周围为**缺血半暗带（penumbra）**——电活动已停止、膜结构尚存、血流处于「功能衰竭但结构可救」的区间。半暗带的转归取决于三件事：侧支循环能否供应、灌注压能否维持、以及时间。

这构成「时间就是大脑」的机制基础：核心随时间扩大，半暗带随时间缩小，可挽救组织的比例随之下降。影响这一进程的因素还包括体温（高热加速损伤）、血糖（高血糖加重酸中毒与氧化应激）与癫痫发作（增加代谢需求）。

**再灌注损伤**是另一面：血流恢复后氧自由基爆发、钙超载持续、炎症细胞浸润与微血管「无复流」，可加重水肿并诱发出血性转化。因此再通并非无条件有益，须权衡缺血范围与出血风险；恢复灌注的同时必须控制血压波动、体温与血糖。

## 44.4 颅内出血：脑实质出血与蛛网膜下腔出血

**脑实质出血（intracerebral hemorrhage, ICH）**最常见的来源是高血压性小动脉（基底节、丘脑、脑桥、小脑）与脑淀粉样血管病（老年人、脑叶分布）。其病理生理包括四个相互叠加的成分：血肿的机械压迫、占位效应、血肿继续扩大、周围水肿；血液分解产物（凝血酶、铁、血红素）进一步加重水肿与炎症。因此 ICH 的恶化常在起病后数小时内发生，而非「一次性事件」。

**蛛网膜下腔出血（subarachnoid hemorrhage, SAH）**多为颅内动脉瘤破裂，典型表现为突发剧烈头痛（患者常描述为「一生中最剧烈」）、脑膜刺激征、可有短暂意识丧失。其并发症构成独立的风险链：再出血、脑血管痉挛致迟发性缺血、脑积水与低钠血症。

两类出血的共同后果都是**占位与颅内压升高**，也都可能破入脑室。处理方向因此一致：控制压力、防止扩大、维持灌注、防治继发损伤（不涉及具体药物与剂量）。

## 44.5 脑水肿的三种类型

| 类型 | 机制 | 屏障状态 | 分布特点 | 常见情形 |
|---|---|---|---|---|
| 细胞毒性 | 能量不足、泵失灵，水进入细胞内 | 相对完整 | 灰质为主，早期出现 | 缺血早期、缺氧、中毒 |
| 血管源性 | 屏障破坏，含蛋白液体进入细胞外间隙 | 破坏 | 白质为主（髓鞘疏松） | 肿瘤、脓肿、创伤、晚期缺血 |
| 间质性 | 脑室液经室管膜渗入室周白质 | 完整 | 脑室周围 | 梗阻性脑积水 |

三型常并存并相互转化：缺血先有细胞毒性水肿，随后屏障破坏叠加血管源性水肿；占位引起的水肿又压迫静脉、加重淤血与间质液蓄积。类型判断决定干预方向——细胞毒性水肿对脱水治疗反应有限，血管源性水肿对糖皮质激素敏感，间质性水肿的根本处理是解除梗阻、引流脑室。方向判断错误，干预即无效甚至有害。

需要留意的是，影像上的低密度或占位并不能区分水在细胞内还是细胞外——这正是必须结合起病时间与病灶性质推断类型的原因。缺血早期以细胞毒性为主，数日后屏障破坏、血管源性成分上升；肿瘤与脓肿则从一开始就以血管源性为主。时间轴与病因共同决定类型，而不是单张影像。

## 44.6 颅内压升高的代偿与失代偿

颅腔由脑实质、血液与脑脊液三部分组成，成人颅骨闭合、总容积固定，这就是 **Monro-Kellie 学说**。任一成分增加，机体先以两种方式代偿：把脑脊液挤向椎管蛛网膜下腔、减少颅内静脉血容量。此阶段容积增加而压力上升缓慢，称为**代偿期**。

当代偿储备耗尽，压力—容积曲线进入陡峭段：再增加极少容积即引起压力**骤升**，脑灌注压随之下降 → 缺血 → 水肿加重 → 压力更高，形成恶性循环。此时出现 **Cushing 反应**：血压升高（交感代偿以维持灌注）、心率减慢、呼吸不规则——它是脑干受压的**晚期**信号，出现即意味代偿已近极限。

代偿能力的个体差异极大：脑萎缩的老年人颅内容积缓冲更大，同等血肿的压力表现更晚；儿童颅腔顺应性小、代偿空间有限，失代偿更快。这解释了为何「同样大小的病灶」在不同患者身上后果悬殊。

## 44.7 占位 → 移位 → 脑疝

本章的主链是：**占位 → 移位 → 脑疝**。

1. **占位**：血肿、水肿、肿瘤或脓肿在有限颅腔内产生压力梯度；
2. **移位**：脑组织由高压区向低压区移动，室间孔或中脑水管受压 → 梗阻性脑积水 → 压力进一步升高（正反馈）；
3. **脑疝**：移位超过解剖耐受，脑组织被挤入生理孔道。

各型脑疝的体征指向不同结构：

- **扣带回疝（大脑镰下疝）**：大脑前动脉受压 → 对侧下肢为主的缺血性无力；
- **小脑幕切迹疝（钩回疝）**：同侧动眼神经受压 → 瞳孔散大、对光反应迟钝、眼睑下垂、眼位外斜；中脑受压 → 意识障碍加深、对侧（或同侧）偏瘫、去大脑强直；
- **枕骨大孔疝（小脑扁桃体疝）**：延髓受压 → 呼吸骤停；可先有颈痛、强迫头位、呕吐。

链条的价值在于**每一步都是干预点**：减小占位（清除血肿）、控制水肿、解除梗阻（引流）、维持灌注与氧合。识别患者处在「哪一步」，决定选择哪种干预——这正是临床判断的核心。

## 44.8 脑灌注压与自动调节失效

**脑灌注压**约等于平均动脉压减去颅内压（此处只作方向性理解）。因此颅内压升高或全身血压下降，都会使灌注压下降。

在完整状态下，自动调节可在一定范围内维持血流恒定；但**严重脑损伤后自动调节常丧失**，血流随压力被动变化：血压下降直接造成缺血，血压过高则加重水肿与出血扩大（突破性灌注）。这就是急性脑损伤血压管理必须「双向」的原因——既不能低，也不能高，且须参照患者平时的血压水平（慢性高血压者曲线右移，其「可耐受的低值」高于常人）。

临床监测手段各有局限：颅内压反映压力而非血流，影像反映结构而非功能，临床体征反映的是已经发生的功能损害。因此**趋势比单点值更重要**，多项指标交叉比任何单项「正常值」更有意义。

## 44.9 中枢神经系统感染

病原可经血行播散、由邻近结构（鼻窦、中耳、牙源性感染）直接蔓延，或经开放性损伤入颅。

**脑膜炎**：病原在蛛网膜下腔繁殖，引起脑膜炎症与渗出 → 脑脊液循环受阻、吸收障碍 → 脑积水与颅内压升高；炎症累及脑神经（听神经、面神经）→ 听力下降与面瘫；累及皮层血管 → 梗死与癫痫。脑膜刺激征是标志，但婴幼儿与老年人可缺如。

**脑炎**：病原或免疫反应直接损伤脑实质，以意识改变、癫痫与局灶体征为主，脑膜刺激征可不明显——「脑膜刺激征阴性」不能排除中枢感染。

**脑脓肿**：局灶占位叠加明显水肿，颅内压升高突出；破入脑室则迅速恶化。

血脑屏障在感染中被炎症破坏，既让免疫细胞进入，也让药物更易入脑。脑脊液检查的分类价值在于**方向性**：细胞数升高、以何种细胞为主、蛋白升高的程度、糖相对血糖的水平——方向组合比单一数值更能区分细菌性、病毒性、结核性与真菌性（不给出具体阈值）。

## 44.10 创伤性脑损伤：原发与继发

**原发性损伤**在撞击瞬间决定，不可逆：脑挫裂伤、**弥漫性轴索损伤**（剪切力作用于灰白质交界、胼胝体与脑干，临床严重程度与影像可不成比例）、硬膜外/硬膜下/脑内血肿。

**继发性损伤**在伤后数小时至数天演进，是可干预的部分：缺血、水肿、兴奋毒性、炎症、氧化应激、癫痫、发热与高血糖。护理与监护的重心几乎全在这一段。

硬膜外血肿多为动脉来源（常伴颅骨骨折），典型病程为「短暂意识丧失 → 清醒间期 → 再度恶化」，反映的是持续动脉性出血造成的占位；硬膜下血肿多为静脉来源、进展较缓，在老年人、酗酒者与抗凝使用者中更常见，且症状易被误认为「衰老」或「痴呆」。

处理的核心不是「治愈原发损伤」，而是**阻断继发链**：维持氧合与灌注、控制颅内压、防治癫痫与发热、避免低血压与低氧这两项最确定的恶化因素。

## 44.11 急性意识障碍的评估与监测

评估应结构化，并强调**动态比较**：

- **意识**：按睁眼、语言、运动三方面分别描述与记录，比单一总分更能反映变化的方向（例如「语言变差而运动不变」提示皮层或语言区受累）；
- **瞳孔**：大小、对称性、对光反应——一侧散大固定提示同侧动眼神经受压；
- **眼位与眼动**：脑干功能与脑神经完整性；
- **运动**：有无不对称；**去皮质强直**（上肢屈曲、下肢伸直）提示病变在脑干以上，**去大脑强直**（四肢伸直）提示脑干受累；
- **生命体征与呼吸模式**：Cushing 反应、Cheyne-Stokes 呼吸、中枢性过度通气、共济失调性呼吸分别指向不同平面；
- **其他**：脑膜刺激征、癫痫发作、体温、有无外伤证据。

评估的真正价值在**趋势**：恶化几乎总是先于不可逆损伤出现。连续、规范、可比较的床旁观察，是最早也最廉价的监测手段。

另一个常被忽略的维度是**基线**：意识水平必须与患者病前状态比较。认知障碍、听力下降、语言不通、镇静残留都会使评分偏低，被误读为病情恶化；反之，一个平时嗜睡的患者在「正常」评分下可能已明显恶化。因此交接班时应同时传递「当前状态」与「与基线的差距」。

## 44.12 生命周期与照护原则

**儿童**：颅骨可塑、脑含水量高，颅内压升高的早期表现不典型（呕吐、嗜睡、前囟膨隆、头围增长、落日眼）；代偿空间小、失代偿快；病因谱中缺氧缺血性脑病、先天性畸形与代谢性疾病占比更高。

**老年**：脑萎缩提供额外缓冲，颅内压升高出现较晚，可能直到脑疝前期才被察觉；抗凝与抗血小板药物使用率高，出血风险与血肿扩大风险上升；合并症多、认知基线差异大，评估须以家属提供的基线为准。

共同原则：把**起病方式 + 局灶体征 + 意识演变**三者合起来判断，而非依赖任何单一检查。急性脑病的处理始终围绕三个目标——保住灌注、控制压力、防止继发损伤。

## 本章小结（Key Points）

- 急性脑损伤共享一条终末通路：能量衰竭 → 兴奋毒性 → 钙超载 → 氧化应激 → 炎症 → 水肿；可干预点几乎都在链上。
- 缺血性卒中的三类机制以起病方式区分：血栓性相对渐进、栓塞性骤然达峰、低灌注性与血压体位相关；腔隙性梗死源于穿通支小血管病。
- 半暗带是「结构尚存、功能已停」的可救组织，其存活时间依赖且受侧支、灌注压、体温与血糖影响；再灌注同时带来获益与出血风险。
- 脑出血的恶化来自占位、血肿扩大与水肿的叠加；SAH 的风险链包括再出血、血管痉挛、脑积水与低钠血症。
- 脑水肿分细胞毒性（细胞内、灰质）、血管源性（细胞外、白质）、间质性（脑室周）；类型决定干预方向。
- Monro-Kellie 学说解释代偿期的「压力缓升」与失代偿期的「陡升」；Cushing 反应是晚期信号。「占位 → 移位 → 脑疝」链中每一步都可干预；钩回疝的瞳孔改变与枕骨大孔疝的呼吸骤停是最需识别的两个节点。
- 严重脑损伤后自动调节常丧失，血压管理必须双向；监测看趋势而非单点。

# 第45章 慢性神经功能障碍（Chronic Disorders of Neurologic Function）

## 学习目标

完成本章学习后，你应当能够：

1. 概括慢性神经功能障碍的共同特征，并区分变性、脱髓鞘与癫痫三类机制；
2. 列举神经变性的共同细胞机制，解释「选择性易损性」的含义；
3. 说明阿尔茨海默病与帕金森病的核心病理与临床推理要点；
4. 比较多发性硬化与吉兰-巴雷综合征的受累部位与体征差异；
5. 描述癫痫灶的形成、同步化、泛化与发作后状态；
6. 说明慢性神经功能障碍的继发后果与可塑性、康复的机制基础。

## 45.1 慢性神经功能障碍的一般特征

慢性神经功能障碍的共同点可以概括为四条：神经元不可逆丢失或功能持续受损；病程以年计；代偿储备被逐步消耗；症状由「可代偿」走向「失代偿」。因此同一疾病在不同阶段的表现差异，往往大于不同疾病之间的差异。

本章沿三条主线展开：**变性**（神经元选择性死亡，如阿尔茨海默病、帕金森病）、**脱髓鞘**（髓鞘与少突胶质细胞受损而轴突相对保留，如多发性硬化）、**癫痫**（兴奋—抑制网络失衡导致的发作性放电）。三者并非互斥：多发性硬化患者可出现癫痫，阿尔茨海默病可有肌阵挛，卒中后既可有变性样退变也可有癫痫。

与急性病的根本区别在于关键变量：急性病看**时间与压力**，慢性病看**部位与储备**。

还有一层区别值得强调：急性病的时间轴由病理过程决定，慢性病的时间轴由**代偿储备**决定。同样程度的神经元丢失，在储备充足者可多年无症状，在储备已被年龄、血管病或其他变性病消耗者则很快显形。这就是为何慢性神经病的起病年龄、进展速度与最终表型差异极大，也为何「同病不同命」在这一类疾病中格外常见。评估时应同时记录功能状态与储备条件（年龄、血管危险因素、合并用药、认知基线），而不只是疾病名称与病程长短。

## 45.2 神经变性的共同机制

- **蛋白错误折叠与聚集**：β-淀粉样蛋白、tau、α-突触核蛋白、TDP-43、突变亨廷顿蛋白——构象异常使其抵抗降解，并能以「类朊蛋白」方式在细胞间播散，把病理从一个区域传到另一个区域；
- **选择性易损性**：不同疾病累及不同环路（海马与默认网络、黑质多巴胺神经元、运动神经元、纹状体），这正是症状特异性的来源；
- **能量与清除系统衰竭**：线粒体功能障碍、氧化应激、轴突运输障碍、泛素-蛋白酶体与自噬功能下降；
- **神经炎症**：小胶质细胞持续激活，既清除病理蛋白又释放毒性因子，作用双向；
- **朊蛋白病**是纯「蛋白构象病」的极端范例，证明错误折叠本身即可致病与传播。

理解这组机制的现实意义：变性病目前多无法逆转病因，治疗与照护的重心在**延缓功能丧失、补偿缺损、处理继发问题**。

## 45.3 阿尔茨海默病

病理三联征：细胞外 **β-淀粉样蛋白（Aβ）斑块**、细胞内 **tau 神经原纤维缠结**、突触与神经元丢失伴脑萎缩（以内侧颞叶与海马最先）。机制要点：Aβ 生成与清除失衡（散发型中清除障碍更关键）；tau 过度磷酸化使微管失稳、轴突运输中断；基底前脑**胆碱能神经元**受累导致记忆与注意障碍；默认网络连接下降。

临床以**情景记忆**受损起病：重复提问、丢物、迷路、记不住约定；逐渐累及语言（找词困难）、视空间（穿衣、认路）与执行功能；中晚期出现行为心理症状（淡漠、妄想、激越、日落综合征）以及吞咽与运动障碍。病程中**保留的领域**（如社交礼节）常掩盖缺损的严重程度。

**临床联系**：阿尔茨海默病是最常见的痴呆原因，但痴呆不等于阿尔茨海默病——血管性、路易体、额颞叶变性各有特征。更重要的是，诊断时必须排除**可逆原因**：甲状腺功能减退、维生素缺乏、抑郁（假性痴呆）、药物不良反应、硬膜下血肿、正常压力脑积水。把可逆当不可逆，是这一类疾病最常见的判断错误。

照护上还有一个易被忽略的环节：**能力与安全感的错配**。患者对自身缺损的觉察可能低于实际损害，家属的过度保护又可能加速功能废用。较好的做法是把环境改造、日常节律与提示系统前置，让患者在仍有能力时继续完成熟悉任务，而不是等出错后再全面接管——维持参与本身就是一种治疗。

## 45.4 帕金森病

病理：**黑质致密部多巴胺神经元**进行性丢失，残存神经元内出现**路易小体**（α-突触核蛋白）。功能后果是基底节环路失衡：直接通路活动下降、间接通路活动增强 → 丘脑-皮层运动输出受抑 → 运动启动困难与动作减少。

临床四主征：**静止性震颤**（搓丸样、情绪紧张时加重、随意运动时减轻）、**肌强直**（铅管样或齿轮样）、**运动迟缓**（起步困难、写字变小、面具脸、语音低平）、**姿势步态障碍**（前倾、慌张步态、冻结）。起病常不对称，自一侧上肢开始。

非运动症状常早于运动症状多年出现：嗅觉减退、便秘、快速眼动期睡眠行为障碍、抑郁与焦虑。这提示病变并不局限于黑质，支持「由下而上、逐级播散」的假说，也使嗅觉与睡眠问诊成为早期识别线索。

**临床联系**：多巴胺替代治疗初期效果显著，随病程出现「剂末现象」（药效在下一次给药前消退）与异动症。机制在于**突触前多巴胺储存能力下降**，使血药浓度的波动被直接放大为症状波动——这是「药物效应取决于受体与储备状态」的经典范例（不涉及剂量）。

## 45.5 其他变性病：肌萎缩侧索硬化与亨廷顿病

**肌萎缩侧索硬化（amyotrophic lateral sclerosis, ALS）**：上、下运动神经元同时变性，累及皮层、脑干与脊髓前角。表现为肌萎缩与无力（下运动神经元体征）叠加腱反射亢进与病理反射（上运动神经元体征）——这种「矛盾组合」是其标志；感觉、眼球运动与括约肌多保留。呼吸肌受累是主要死因，吞咽障碍致误吸与营养衰竭是常见并发症。部分患者伴额颞叶谱系的认知与行为改变。

**亨廷顿病（Huntington disease）**：常染色体显性遗传，CAG 三核苷酸重复扩增；**纹状体（尾状核）GABA 能神经元**丢失 → 舞蹈样不自主运动、执行功能障碍与精神症状。遗传早现（后代发病更早、更重）与重复长度相关，是遗传咨询的核心议题。

共同启示：变性病的症状图谱由**受累环路**决定，而不是由「变性」这一共同机制决定。同样的病理蛋白，在不同环路沉积就产生完全不同的疾病。

## 45.6 脱髓鞘疾病：多发性硬化

多发性硬化（multiple sclerosis, MS）是免疫介导的中枢神经系统白质脱髓鞘，好发于视神经、脑室周围、脊髓、脑干与小脑。轴突相对保留，但随病程逐渐丢失，后者决定长期残疾。

机制：自身反应性 T 细胞在外周被激活 → 穿越血脑屏障 → 局部炎症、髓鞘破坏与传导阻滞；炎症消退后部分髓鞘可修复，故临床呈**复发-缓解**。脱髓鞘轴突对温度敏感：体温升高（发热、热水浴、运动）使传导阻滞加重，出现 **Uhthoff 现象**——症状一过性加重而非新病灶。

临床以「**时间多发 + 空间多发**」为诊断骨架。常见表现：视神经炎（单眼视力下降、眼球转动痛、色觉减退）、核间性眼肌麻痹（双眼同向运动时患侧内收不能伴对侧眼震）、肢体感觉异常与无力、共济失调、膀胱功能障碍、疲劳（最常见也最易被忽视的症状）。

**临床联系**：症状波动不等于复发。感染、发热、疲劳、热环境、睡眠不足均可致一过性加重，判断真复发须看持续时间与客观体征，并排除感染与代谢原因。

## 45.7 急性炎症性脱髓鞘性多神经病

吉兰-巴雷综合征（Guillain-Barré syndrome, GBS）是急性免疫介导的**周围神经**脱髓鞘（部分为轴索型），多在感染后一段时间发生，机制为病原抗原与周围神经成分的**分子模拟**。表现为对称性、上行性弛缓性瘫痪，腱反射消失，可伴感觉异常与自主神经不稳。

需要盯住的四个危险点：**呼吸肌麻痹**（观察呼吸费力、说话断续、肺活量下降趋势）、吞咽障碍致误吸、自主神经不稳致血压与心率剧烈波动、深静脉血栓与疼痛（神经病理性）。

与 MS 的对照最有教学价值：同一「脱髓鞘」机制，在中枢表现为反射亢进与病理反射阳性，在周围神经则表现为反射消失与肌萎缩——**部位决定表现**。这正是全章反复强调的推理原则。

## 45.8 癫痫的发生机制

癫痫是**兴奋与抑制失衡**导致的神经元异常同步放电，其形成包含几个环节：

- **致痫灶**：局部神经元膜兴奋性增高（离子通道改变、抑制性中间神经元丢失、细胞外钾缓冲障碍、谷氨酸能活动增强、胶质细胞功能异常）；
- **同步化与募集**：通过突触传递与电场效应使邻近神经元同步放电；
- **泛化**：经丘脑-皮层环路与胼胝体扩散为全面性发作；
- **发作后状态**：抑制机制启动（GABA、腺苷、离子梯度恢复）与代谢耗竭，表现为嗜睡、意识模糊或局灶无力（Todd 麻痹）。

阈值受多种因素调节：发热、睡眠剥夺、酒精戒断、低血糖、电解质紊乱、闪光刺激、药物相互作用。这解释了一个常见误解——**有致痫灶不等于总有发作**；也解释了为何癫痫管理必须同时处理诱因。

## 45.9 癫痫的临床类型与持续状态

按起源分**局灶性**（可伴意识保留或受损，常有先兆，如嗅幻觉、上腹上升感、 Déjà vu）与**全面性**（失神、肌阵挛、强直-阵挛、失张力）；按病因分结构性、遗传性、感染性、代谢性、免疫性与未知。分类的临床意义在于选药方向与预后判断，而非贴标签。

**癫痫持续状态（status epilepticus）**指发作持续到机体自身终止机制失败，或反复发作而发作间期意识未恢复——属神经科急症。机制上存在**时间依赖性恶化**：GABA_A 受体下调与内化、NMDA 受体上调，使同一干预随时间推移效果下降，即「越晚越难治」。后果包括兴奋毒性损伤、脑水肿、高热、酸中毒、横纹肌溶解、心律失常与吸入性肺炎。

处理逻辑固定：先稳定气道、呼吸与循环，尽快终止发作，再查找病因（不涉及具体药物与剂量）。

分类的另一实用价值在于**发作日记**：记录时间、形式、意识状态、诱因、持续时间与恢复过程，比任何单次检查更能反映疾病的真实负荷。发作形式的改变——局灶转为全面、出现新的先兆、发作后状态延长——常提示病灶演进或干预不当，是需要重新评估的信号，而不只是「又犯了一次」。

## 45.10 慢性神经功能障碍的继发后果

原发性神经缺损之外，还有一组**继发性、可干预**的后果，常被误当作「病程本身」：

- 运动：上运动神经元综合征（痉挛、腱反射亢进、阵挛）、挛缩、废用性肌萎缩、骨质疏松；
- 吞咽与营养：误吸、脱水、营养不良、体重下降；
- 呼吸：通气不足、分泌物清除障碍、睡眠呼吸障碍；
- 自主神经：体位性低血压、膀胱直肠功能障碍、体温与出汗调节异常；
- 感觉与疼痛：中枢性疼痛、感觉丧失导致外伤与烫伤；
- 认知与情绪：注意与执行功能下降、抑郁与焦虑（在卒中后、MS、帕金森病中均常见）；
- 社会心理：病耻感、失业、照护者负担与耗竭。

把这些与原发性缺损分开评估，才不会把「可治的并发症」当成「不可治的病程」。这也是护理工作最具价值的着力点。

## 45.11 可塑性、康复与安全照护

**可塑性**的机制包括：突触效能改变（LTP/LTD）、轴突发芽与侧支形成、皮层代表区重组、网络代偿（对侧半球募集）、髓鞘重塑。可塑性终身存在，但随年龄与抑制性环境（胶质瘢痕、抑制性分子、慢性炎症）而受限。

**康复的机制基础**是任务特异性的重复训练：训练哪种任务，就重组哪个代表区；强度、主动性与任务的意义性决定效果，被动维持的效果有限。早期、适量、渐进优于晚期、过量；过度训练可诱发疲劳与疼痛，反而削弱参与。

照护者的能力同样是可干预变量：把观察要点、给药时间、发作应对与求助路径写成可执行的清单，比反复口头叮嘱更可靠。清单还应写明「什么情况下必须联系医护人员」，让判断权不必每次从零开始。

**安全照护要点**：跌倒与外伤预防（癫痫、痉挛、体位性低血压、视力与视野缺损叠加）、误吸预防（体位、食团性状、进食速度）、皮肤与关节保护、发作时的环境安全与记录（时间、形式、意识、诱因）、用药依从性与相互作用、驾驶与职业限制的告知、照护者培训与 respite 支持。

## 本章小结（Key Points）

- 慢性神经功能障碍看「部位与储备」：变性、脱髓鞘、癫痫三条主线可重叠。
- 神经变性的共同机制是蛋白错误折叠与聚集、选择性易损、能量与清除系统衰竭、神经炎症；症状图谱由受累环路决定。
- 阿尔茨海默病以情景记忆起病，Aβ 与 tau 为核心病理；诊断须排除可逆原因。
- 帕金森病源于黑质多巴胺神经元丢失与基底节环路失衡，非运动症状可早于运动症状多年出现。
- 多发性硬化是中枢脱髓鞘、呈时间与空间多发，症状可因体温升高而一过性加重（Uhthoff 现象）；GBS 是周围神经脱髓鞘，表现为弛缓性瘫痪与反射消失——部位决定表现。
- 癫痫是兴奋-抑制失衡的异常同步放电，有灶不等于总有发作；持续状态存在时间依赖性恶化，越晚越难治。
- 痉挛、吞咽障碍、自主神经不稳、抑郁等继发后果多可干预，须与原发性缺损分开评估。康复依靠任务特异性的重复训练驱动皮层重组；安全照护的重点是跌倒、误吸与发作管理。

# 第46章 特殊感觉功能异常（Alterations in Special Sensory Function）

## 学习目标

完成本章学习后，你应当能够：

1. 概括视、听、前庭、味、嗅五种特殊感觉的共同传导结构；
2. 复述视觉通路的关键节点，并由视野缺损形态推断病变部位；
3. 区分传导性、感音神经性与中枢性听力损失；
4. 说明前庭器官如何感受角加速度与直线加速度，以及前庭眼反射的作用；
5. 比较外周性与中枢性眩晕的鉴别要点；
6. 说明嗅觉与味觉障碍的常见环节及其安全意义。

## 46.1 特殊感觉的一般传导结构

特殊感觉的共同骨架是：**感受器**把特定形式的能量转换为电信号 → 传入通路（多级神经元、多有交叉）→ 皮层代表区。视、听、前庭、味、嗅各自的感受器不同，但共享三条规律：

- **适应**：持续不变的刺激引起反应减弱，因此「持续存在的异常可能被忽略」，而**变化**最容易被察觉；
- **对侧投射**：视、听与躯体感觉均为对侧代表，故单侧皮层病变产生对侧障碍；
- **可定位**：通路任一环节受损都造成功能丧失，但**缺损的形态**（视野缺损的形状、听力损失的频率分布、眼震的方向）可指向具体环节。

感觉剥夺还会引起中枢重组：听觉剥夺后听觉皮层增益上调（耳鸣）、视觉剥夺后视觉皮层被触觉与听觉占用、单侧前庭丧失后依赖视觉与本体感觉代偿。因此感觉障碍从来不只是「输入减少」，而是整个系统的重新组织。

这套骨架还决定了「检查为何要成组做」：单一指标只反映一个环节，只有成组且可比较的结果才能把缺损锁定在通路的某一段。视力下降需结合视野、色觉、瞳孔反应与眼底；听力下降需结合纯音、言语识别与声导抗；眩晕需结合眼震、头脉冲与站位平衡。指标之间是一致还是矛盾，比单项是否「正常」信息量更大。

## 46.2 视觉通路

光线经角膜、房水、瞳孔（调节光量）、晶状体（调节焦距）、玻璃体到达视网膜；视网膜内完成三级神经元接力（视杆/视锥 → 双极细胞 → 神经节细胞），再经视神经 → **视交叉**（鼻侧纤维交叉）→ 视束 → 外侧膝状体 → 视辐射（经颞叶与顶叶）→ 枕叶距状裂皮层。

视野缺损的形态是定位工具：

| 病变部位 | 视野缺损 |
|---|---|
| 视交叉前（视神经） | 单眼视野缺损 |
| 视交叉正中 | 双颞侧偏盲（压迫来自下方，如垂体占位） |
| 视交叉后（视束、视辐射、枕叶） | 对侧同向性偏盲 |
| 颞叶视辐射 | 对侧上象限盲 |
| 顶叶视辐射 | 对侧下象限盲 |
| 枕叶（黄斑区有双重血供） | 同向性偏盲伴黄斑回避 |

视网膜血供是双重的：内层由视网膜中央动脉供应，外层由脉络膜供应。因此**视网膜中央动脉阻塞**造成单眼突发无痛性失明，而眼动脉的侧支可保留部分视功能——「无痛、单眼、突发」是动脉阻塞的三要素。

## 46.3 视觉失衡的常见环节

- **屈光不正**：眼轴长度与屈光力不匹配，成像焦点不在视网膜（近视、远视、散光）——矫正即可，属光学问题；
- **白内障**：晶状体蛋白变性混浊，透光下降；是可逆性致盲的首位原因，手术可恢复；
- **青光眼**：房水生成与流出失衡致眼压升高，视神经乳头凹陷与**进行性视野缺损**（周边先受累、中心视力晚期才丧失）；开角型隐匿进展，闭角型急性发作伴眼痛、虹视、头痛与恶心。眼压升高并非唯一机制——正常眼压性青光眼提示血管因素与轴突运输障碍同样重要；
- **视网膜病变**：糖尿病与高血压性微血管病变 → 渗出、出血、黄斑水肿；增殖期新生血管 → 玻璃体出血与牵拉性视网膜脱离；
- **视神经病变**：炎症（视神经炎，伴眼球转动痛）、缺血（前部缺血性视神经病变，突发、象限性缺损）、压迫（肿瘤、甲状腺相关眼病）。

**临床联系**：判断视力下降，看四项——**起病速度、单眼还是双眼、有无疼痛、视野缺损的形态**。这四项比视力表上的数字更有定位价值，也决定了是「配镜、手术、降压眼压还是急诊影像」。

另一个常被忽略的维度是**双眼协同**：屈光参差、斜视与融合失败会造成复视、视疲劳与空间判断错误，而单眼视力可以完全正常。因此「视力表正常」不等于视觉功能正常——阅读耐受、深度觉与驾驶安全取决于双眼能否协同，而非单眼分辨力。

## 46.4 听觉通路

声波 → 外耳（集音与共振）→ 鼓膜 → 中耳听骨链（**阻抗匹配**：把空气的低阻抗振动高效传入内耳液体，效率损失被大幅补偿；镫骨肌反射提供一定保护）→ 卵圆窗 → 耳蜗（基底膜行波，**高频近底、低频近顶**，即频率—位置编码）→ **毛细胞**（机械转导，钾内流去极化）→ 螺旋神经节 → 听神经 → 耳蜗核 → 上橄榄复合体（比较双耳时间与强度差，实现声源定位）→ 下丘 → 内侧膝状体 → 颞横回。

两个要点决定了临床特征：其一，耳蜗是**频率分析器**，不同频率在不同部位受损，故听力图上的形态可提示病因；其二，哺乳类**毛细胞不可再生**，故感音神经性损失多为永久性。此外，听神经以上的通路为双侧投射，单侧中枢病变很少造成全聋，但会影响声源定位与言语识别。

## 46.5 听力损失与耳鸣

| 类型 | 病变部位 | 听力学特点 | 常见原因 |
|---|---|---|---|
| 传导性 | 外耳、中耳 | 气导下降、骨导相对保留 | 耵聍、鼓膜穿孔、中耳积液、听骨链固定 |
| 感音神经性 | 耳蜗毛细胞或听神经 | 气骨导同时下降，常伴耳鸣与重振 | 噪声、耳毒性药物、老年性、感染、突发性 |
| 中枢性 | 脑干、皮层 | 言语识别差与纯音听力不成比例 | 肿瘤、卒中、脱髓鞘 |

**重振**（小声听不见、大声嫌太响）提示耳蜗病变，是因毛细胞受损后动态范围变窄；这在助听器验配时是关键技术问题。

**耳鸣**多因外周输入减少后中枢增益上调，属听觉剥夺的中枢代偿，因此耳鸣的响度与听力损失程度不必平行，情绪与睡眠状态显著影响其困扰度。**单侧听力下降伴耳鸣**须警惕听神经瘤，因其常先影响高频与言语识别。

老年性聋以高频先受累，表现为「听得见但听不清」，在噪声环境中尤其明显。这直接导致社交退缩、误解与猜疑（被误认为「多疑」）、以及认知负荷加重——听力干预因此不只是「听的问题」。

## 46.6 前庭系统与平衡

前庭器官分两部分：**半规管**（三个互相垂直的平面，感受**角加速度**，即转头）与**椭圆囊、球囊**（内含耳石，感受**直线加速度**与头位相对重力的方向）。

通路为：前庭神经 → 前庭核（脑干）→ 三条输出：

1. **前庭眼反射**：经动眼、滑车、外展神经核，头动时眼球反向转动以稳定注视——这是睁开眼走路不晕的基础；
2. **前庭脊髓反射**：维持姿势张力与平衡；
3. **前庭-自主与皮层投射**：恶心、呕吐、出汗、眩晕感与空间定向。

关键特性是**双侧推挽**：两侧静息放电对称，中枢把「对称」解读为「静止」。一侧受损造成不对称，被感知为「自己在旋转」（眩晕），并出现眼震（慢相向患侧、快相向健侧）与向患侧倾倒。

中枢可**代偿**：对侧前庭核兴奋性上调、小脑参与再校准、视觉与本体感觉被重新加权。这是前庭康复训练的机制基础，也解释了急性前庭病变为何在数周内逐步减轻——而代偿依赖活动，卧床不动反而延迟恢复。

推挽结构的临床含义是：症状的**方向**比症状的**有无**更有定位价值。单侧功能丧失时，「环境在转」与「自己在转」的区分、眼震快慢相的方向、跌倒偏向哪一侧，共同指向受损侧。若两侧同时受损（如耳毒性损害），推挽仍对称，眩晕反而不明显，取而代之的是行走时视物晃动与平衡不稳——这解释了双侧前庭病的表现为何与单侧截然不同。

## 46.7 眩晕与眼震

鉴别外周性与中枢性眩晕，靠的是**伴随体征**而非眩晕的剧烈程度：

| 鉴别点 | 外周性 | 中枢性 |
|---|---|---|
| 眩晕性质 | 旋转性、剧烈，伴恶心呕吐出汗 | 可为不稳感或旋转，程度不一 |
| 眼震 | 水平-旋转性、方向固定、**不被固视抑制** | 可为垂直性或方向改变，**固视可抑制** |
| 伴随症状 | 耳鸣、耳闷、听力下降 | 复视、构音障碍、吞咽困难、面部或肢体感觉异常、共济失调 |
| 常见病因 | 良性阵发性位置性眩晕、前庭神经炎、梅尼埃病 | 后循环缺血、脑干或小脑病变、脱髓鞘 |

良性阵发性位置性眩晕由耳石脱落进入半规管，与头位变化密切相关，发作短暂；前庭神经炎为病毒感染后单侧前庭功能丧失，持续数日、无听力障碍；梅尼埃病为膜迷路积水，表现波动性听力下降 + 耳鸣 + 耳闷 + 眩晕发作。

**临床联系**：中枢性眩晕可无剧烈眩晕，却提示后循环缺血这类急症。因此凡眩晕伴**新发的神经体征**（复视、构音障碍、吞咽困难、偏身感觉异常、共济失调），应按中枢性处理并紧急评估；反之，纯旋转性眩晕伴耳症状而神经体征阴性，多属外周性（不涉及具体检查操作细节）。

## 46.8 嗅觉与味觉

**嗅觉**：气味分子与嗅上皮受体神经元结合，后者是**唯一直接暴露于外环境的神经元**（也是少数终身更新的神经元）；轴突穿过筛板进入嗅球，形成肾小球，再经嗅束投射到梨状皮层、杏仁核与内嗅皮层——**不经丘脑**，故气味与情绪、记忆的联系格外紧密（「气味唤起往事」）。

**味觉**：味蕾分布于舌、腭与咽；前部经面神经、后部经舌咽神经、咽部经迷走神经传入孤束核 → 丘脑 → 岛叶皮层。基本味为甜、咸、酸、苦、鲜。所谓「味道」大部分来自嗅觉，故嗅觉丧失者常主诉「吃东西没味道」。

失衡的原因可分四层：传导性（鼻塞、鼻息肉）、感受器损伤（病毒感染后、药物、放疗）、神经损伤（头部外伤致嗅丝撕裂、颅底骨折、手术）与中枢病变（**帕金森病与阿尔茨海默病早期常受累**，可作为前驱标志）。味觉障碍还需考虑锌缺乏、药物、面神经病变与口腔疾病。

**安全意义**：嗅觉减退使患者难以察觉煤气泄漏、烟雾与变质食物，是居家安全中常被忽视的风险，应在出院教育中明确告知并建议安装报警装置。

沟通策略的核心也不是「说得更大声」，而是**降低对受损通道的依赖**：把信息转移到仍可用的通道（触觉提示、文字、示范、书面步骤），并给对方足够的处理时间。感觉障碍者的疲劳多来自持续的高认知负荷，而不是不配合；把这一点讲清楚，家属的误解与责备会明显减少。

## 46.9 感觉剥夺、代偿与老年性改变

感觉剥夺会触发中枢重组：听觉剥夺 → 听觉皮层增益上调（耳鸣、对噪声不耐受）；视觉剥夺 → 视觉皮层被触觉与听觉任务占用（跨模态可塑性）；单侧前庭丧失 → 平衡依赖视觉与本体感觉，在暗处或软地面上不稳。

老年性改变是多重叠加：晶状体弹性下降（老视）、瞳孔缩小致夜间视物差、对比敏感度下降、眩光敏感；高频听力损失与言语识别下降；前庭毛细胞与神经元减少、姿势控制变慢；嗅觉与味觉阈值升高。共同后果是**跌倒风险上升、社交退缩、认知负荷增加**——「感觉—认知—运动」三者互相拖累，任一环恶化都会带动其余两环。

干预方向多为低成本高收益：矫正屈光、白内障手术、助听设备、环境照明与对比度提升、去除地面障碍与增加扶手、前庭与平衡训练、营养与口腔照护。这些措施对功能与生活质量的影响，常大于针对「病因」的无效努力。

## 46.10 沟通与安全照护

- **与听力障碍者沟通**：面对光源、让对方看到口型，清晰发音而非大声喊叫（喊叫会扭曲辅音），减少背景噪声，备好纸笔或辅助设备，必要时安排手语翻译；确认理解用复述而非点头；
- **与视力障碍者沟通**：进房间先自我介绍、离开时告知；操作前说明位置与动作；引导时让对方扶你的臂而非被推着走；物品固定位置，不随意移动；
- **安全**：跌倒与烫伤预防（热水温度、餐具位置）、药物标签可辨识（大字体、触觉标记）、居家环境改造、驾驶能力评估与告知；
- **心理**：感觉丧失常伴孤立、抑郁与猜疑，需主动询问情绪与社交状况，必要时转介；
- **记录**：功能状态（能否读药瓶、能否听懂电话、能否独自出门）应作为评估与随访的基线，而不是只记录检查结果。

## 本章小结（Key Points）

- 特殊感觉共享「感受器—多级通路—皮层代表区」骨架，具有适应、对侧投射与可定位三条规律。
- 视觉通路的关键节点是视交叉、外侧膝状体与视辐射；视野缺损的形态可精确定位，黄斑回避提示枕叶。
- 视力下降的判断看起病速度、单双眼、有无疼痛与视野形态；青光眼以进行性周边视野缺损为特征。
- 中耳的阻抗匹配使声音高效传入内耳；耳蜗按频率定位，毛细胞不可再生，故感音神经性损失多为永久性。听力损失分传导性、感音神经性与中枢性；重振提示耳蜗病变，单侧耳鸣须警惕听神经瘤。
- 前庭系统双侧推挽、编码角加速度与直线加速度，经前庭眼反射与前庭脊髓反射维持稳定，并可由中枢代偿。
- 外周性与中枢性眩晕的鉴别靠伴随神经体征与眼震能否被固视抑制；眩晕伴新发神经体征须按急症处理。
- 嗅觉不经丘脑而直连边缘系统，其减退可为神经变性病的前驱标志，并有明确的居家安全意义。

# 第47章 疼痛（Pain）

## 学习目标

完成本章学习后，你应当能够：

1. 说明疼痛的多维性及其为何不能简化为「强度」；
2. 描述伤害感受器的转导过程与外周敏化的机制；
3. 复述痛觉的传导路径与脊髓背角的整合作用；
4. 说明「疼痛矩阵」各成分的功能分工；
5. 解释内源性镇痛系统与闸门控制学说；
6. 区分急性与慢性疼痛的机制类别，并据此选择评估与处理方向。

## 47.1 疼痛的定义与多维性

疼痛是「与实际或潜在组织损伤相关的不愉快感觉与情绪体验」。定义中的「或潜在」与「不愉快」两个词都至关重要：前者承认疼痛可以在无明显损伤时存在，后者承认情绪成分不可分割。

疼痛至少包含四个维度：**感觉-辨别**（位置、性质、强度）、**情绪-动机**（不愉快、回避冲动）、**认知**（意义、预期、注意力）、**社会**（角色、文化、工作与赔偿）。这解释了为什么单纯提高镇痛强度常不足以改善疼痛相关失能——若恐惧、失眠与角色丧失未被处理，疼痛体验仍会持续。

疼痛是有保护价值的防御系统：先天性无痛症患者因缺乏保护而反复骨折、关节破坏、烧伤无察觉。**疼痛的缺失比疼痛更危险**，这一事实提醒我们，治疗目标是「恢复功能」而非「彻底消除信号」。

「多维」还有一层实践含义：四个维度并非各自独立，而是相互放大或相互缓冲。睡眠剥夺降低痛阈、放大不愉快成分；恐惧与灾难化把注意力锁定在身体感受上；社会支持、对病情的理解与可控感则提高耐受。因此强度评分必须放在这四维背景中读——单看一个数字，既不能预测失能，也不能指导分层。

## 47.2 转导：伤害感受器与外周敏化

**伤害感受器**是分布于皮肤、肌肉、关节、内脏与血管壁的游离神经末梢，把机械、温度与化学刺激转换为电信号（**转导**）。关键分子包括温度敏感的 TRP 通道、机械敏感通道与酸敏感离子通道。

组织损伤后释放的「炎症汤」——缓激肽、前列腺素、组胺、5-羟色胺、ATP、氢离子与神经生长因子——降低伤害感受器阈值、增加自发放电，即**外周敏化**。其临床表现是静息痛与局部压痛（原本不痛的刺激开始引起疼痛）。

**沉默伤害感受器**平时不响应，炎症时被招募，这解释了「平时不痛的组织在炎症后一碰就痛」。**神经源性炎症**（C 纤维末梢释放 P 物质与降钙素基因相关肽引起血管扩张与水肿）则说明疼痛系统本身也能制造炎症。

内脏痛的定位问题是转导之后的第一道陷阱：内脏伤害感受器密度低、感受野大，其传入纤维与躯体纤维在脊髓**汇聚**于同一投射神经元（汇聚-投射），大脑无法区分来源，形成**牵涉痛**——心肌缺血表现为左肩、左臂与下颌痛，胆囊病表现为右肩痛。这是定位诊断中最容易误导的现象。

## 47.3 传导与上行通路

初级传入分两类：**Aδ 纤维**（有髓、传导快，产生尖锐定位明确的「第一痛」）与 **C 纤维**（无髓、传导慢，产生钝而弥散的「第二痛」，并携带情绪色彩）。Aβ 纤维传导触觉与振动，正常情况下不引起疼痛——但在中枢敏化后，它被「招募」进痛通路（见 47.6）。

**脊髓背角**是第一整合站：C/Aδ 传入释放谷氨酸与 P 物质、降钙素基因相关肽 → 投射神经元上行，同时激活局部中间神经元形成环路。持续输入还会激活**胶质细胞**（小胶质、星形胶质），释放细胞因子与脑源性神经营养因子增强痛传递——「胶质痛」是理解慢性疼痛的重要新视角。

上行通路各有分工：

| 通路 | 投射 | 功能 |
|---|---|---|
| 脊髓丘脑束 | 丘脑腹后外侧核 → 躯体感觉皮层 | 定位、性质与强度辨别 |
| 脊髓网状束 | 脑干网状结构 | 觉醒、注意力、自主反应 |
| 脊髓中脑束 | 导水管周围灰质、臂旁核 | 情绪、自主与下行调控的输入 |
| 脊髓颈束、后索 | 颈髓、延髓 | 内脏与深部痛、双侧传递 |

痛温觉纤维在脊髓内交叉后上行，故**脊髓半切**产生「对侧痛温觉丧失、同侧本体感觉与运动障碍」的分离性感觉障碍——这是传导路径解剖的直接推论。

上行通路也不是被动的电缆。脊髓以上每一站都接受下行系统与其他感觉通道的调制：触觉、温度与本体感觉的输入会改变痛信号的传递效率，这正是冷热敷、按摩与经皮电刺激能起效的解剖基础。理解「通路 + 调制」两层结构，才不会把镇痛理解为「堵住某一条线」。

## 47.4 中枢整合：疼痛矩阵

丘脑是主要中继，但疼痛体验由一组结构共同构建：

- **躯体感觉皮层**：定位、强度与性质辨别；
- **岛叶**：内感受、自主反应与「身体状态」的整合；
- **前扣带皮层**：不愉快感与回避动机；
- **前额叶**：评价、意义赋予、注意调控与抑制；
- **杏仁核**：恐惧、警觉与情绪记忆。

关键结论是：**强度与不愉快由不同成分编码**。前额叶或扣带区受损的患者仍能准确报告疼痛的位置与强度，却诉「不再为此痛苦」；反之，焦虑与灾难化思维会放大不愉快成分，使同等强度的疼痛造成更大失能。

皮层与下行系统之间是**双向**的：预期、注意力、情绪状态直接改变上行信号的增益。这意味着「分心」「解释」「重建意义」不是安慰性的空话，而是有生理基础的调制手段。

## 47.5 内源性调控与闸门控制

**内源性镇痛系统**：中脑导水管周围灰质（PAG）→ 延髓头端腹内侧区 → 脊髓背角，经去甲肾上腺素与 5-羟色胺下行纤维抑制传入；内阿片肽（内啡肽、脑啡肽、强啡肽）及其受体遍布这条通路。

**闸门控制学说**（Melzack 与 Wall）提出，脊髓背角存在一个「闸门」：Aβ 触觉传入的激活可抑制 C 纤维的传递，下行纤维亦可关闭闸门。这解释了三类日常经验：揉一揉、热敷、按摩能减轻疼痛；注意力集中于他事时疼痛减轻；而焦虑、失眠与孤立时疼痛加重——因为下行抑制被削弱。

**应激性镇痛**（战斗或受伤当下不觉痛）与**安慰剂效应**（预期触发内阿片与多巴胺系统，可被相应拮抗剂部分逆转）都是这套系统的临床证据。它们的实践含义是：疼痛管理的环境、沟通与预期，本身即为有效成分。

## 47.6 外周与中枢敏化

- **外周敏化**：炎症介质降低伤害感受器阈值、增加自发放电 → 静息痛、压痛、对刺激反应增强；
- **中枢敏化**：持续 C 纤维输入使背角神经元反应增强、感受野扩大、阈值下降（wind-up 与 LTP 样改变）→ **痛觉过敏**（对伤害性刺激反应过强）与**异常性疼痛**（轻触、穿衣、微风即引起疼痛）；
- **去抑制**：抑制性中间神经元丢失或 GABA 能功能下降（神经损伤后常见），使「刹车」失灵；
- **结构重塑**：慢性疼痛可致皮层代表区重组、下行调制失衡、HPA 轴与免疫改变、睡眠结构破坏。

这组机制的核心含义是：疼痛可以从**症状**转变为**疾病状态**。此时疼痛强度与原始损伤的程度脱钩，检查可能找不到对应病灶——这不等于疼痛不存在，而是提示机制已从外周转移到中枢。理解这一点，是避免「反复检查、反复加量、反复失望」这一医源性循环的前提（不涉及具体药物与剂量）。

## 47.7 疼痛的机制分类

| 类别 | 机制 | 临床特征 | 处理方向 |
|---|---|---|---|
| 伤害性（躯体） | 持续伤害性刺激激活完整通路 | 定位清晰、与损伤程度相称、活动时加重 | 减少伤害性输入、抗炎、制动 |
| 伤害性（内脏） | 内脏感受器激活、汇聚-投射 | 定位模糊、伴恶心出汗、可牵涉 | 针对原发病，辅以调制 |
| 神经病理性 | 躯体感觉系统病变或疾病 | 烧灼、电击、针刺样，伴麻木、异常性疼痛、痛觉过敏 | 针对神经机制，常规镇痛药反应差 |
| 混合性 | 两类机制并存 | 癌痛、腰背痛常见 | 分层处理各成分 |
| 可塑性/中枢性 | 中枢敏化为核心，无明确外周损伤 | 广泛痛、疲劳、睡眠障碍、多部位压痛 | 功能恢复、运动、认知行为治疗 |

另需识别两类易被忽略的情形：**心因性放大**（真实存在，非「装病」，是中枢调制异常的结果）与**药物相关性疼痛**（反跳痛、阿片诱导的痛觉过敏）。分类的价值在于**选对靶点**——同等强度的疼痛，机制不同，方向就不同。

## 47.8 急性与慢性疼痛

**急性疼痛**有明确损伤、有保护价值、随组织愈合而消退。机制以外周伤害感受器激活与外周敏化为主；伴交感激活（心率增快、血压升高、出汗、瞳孔扩大）与焦虑；处理目标是缓解疼痛、支持愈合、预防并发症（如术后因疼痛不敢咳嗽导致肺不张）。

**慢性疼痛**在组织愈合所需时间之外仍持续（通常以月计，不给具体界值），已失去保护价值。机制以中枢敏化、去抑制、皮层重组与神经免疫改变为主；常伴睡眠障碍、抑郁、疲劳、活动回避与失能。处理目标转向**功能恢复与自我管理**，而非「完全无痛」——把「无痛」作为唯一目标，往往导致过度用药与功能进一步退化。

两者的根本差别在于「伤害性输入—疼痛强度」的关系是否仍然成立。急性期这条关系紧密，慢性期被削弱。因此慢性疼痛的评估必须包含功能（睡眠、行走、工作、社交）与心理社会因素，而不只是强度评分。

## 47.9 疼痛评估

- **自述是金标准**：部位、性质、强度、时间模式、诱发与缓解因素、对功能的影响；常用工具包括数字评分、视觉模拟与面部表情量表，各有适用人群与局限；
- **无法自述者**（婴幼儿、痴呆、镇静、语言障碍、危重患者）：依靠行为观察（面部表情、保护性动作、呻吟、僵硬）、生理指标（心率、血压、出汗）与照护者报告，使用结构化工具并建立个体基线——单次生理指标不能作为疼痛证据；
- **神经病理性筛查**：烧灼/电击样痛、麻木、异常性疼痛、痛觉过敏；可用筛查问卷辅助；
- **功能与风险**：睡眠、活动能力、情绪、工作与社交、抑郁与自杀风险、物质使用与用药风险；
- **记录闭环**：「疼痛—干预—再评估」构成一个完整记录单元，孤立的强度数字没有临床意义。

评估还有时间维度：同一患者不同时点的评分不可直接比较，除非同时记录当时的活动量、用药与情绪背景。趋势要结合情境读，否则容易把「今天多走了路所以更痛」误读为「病情加重」，也可能把「卧床休息所以不痛」误读为「好转」。

## 47.10 疼痛管理的机制基础

按机制分层是本章的落点：

- 伤害性成分：减少伤害性输入（制动、冷热敷、抗炎、局部麻醉）、非阿片类镇痛；
- 神经病理性成分：作用于钙通道 α2δ 亚基、5-羟色胺与去甲肾上腺素再摄取、钠通道等靶点的药物，以及局部外用制剂（不涉及剂量）；
- 中枢敏化成分：以功能恢复为核心——分级运动与活动、睡眠管理、认知行为治疗、患者教育与信念重建；
- 非药物手段：经皮电刺激、按摩、针灸、放松与正念训练、物理治疗、多学科疼痛门诊。

五条原则：**多模式**（不同机制靶点联合，降低单一手段的剂量与副作用）、**按时而非按痛**（针对持续疼痛，避免疼痛反复升级）、**以功能为目标**、**定期再评估**、**避免单一手段长期依赖**。

安全方面需注意：阿片类的呼吸抑制、便秘、耐受与依赖风险；非甾体类的胃肠与肾损害；老年与肝肾功能不全者的代谢差异；以及「疼痛缓解后活动量骤增」造成的二次损伤。所有用药决策均属个体化医疗，本讲义不提供剂量与方案。

## 47.11 生命周期与特殊人群

- **儿童**：痛觉通路在发育早期即功能完整，新生儿甚至更敏感；表达能力有限，须依行为与家长报告；反复的疼痛性操作应做程序性镇痛（安抚、哺乳、甜味液、分散注意力），并注意疼痛的远期影响（针头恐惧、痛觉敏化）；
- **老年**：疾病负荷大而常**少报**疼痛（认为「老了就该痛」、怕被视为抱怨、担心药物副作用）；认知障碍者评估困难；多种合并用药增加相互作用与跌倒风险；
- **妊娠与哺乳**：用药须权衡母婴双方风险，非药物手段优先；
- **文化与语言**：表达方式、忍耐规范与求助行为差异大；以「表情平静」判断无痛是最常见的评估错误之一；
- **临终与重症**：舒适为优先目标，镇痛与镇静的边界、以及「可能缩短生命」的伦理顾虑，需团队与家属充分沟通——未被控制的疼痛本身就是痛苦的主要来源。

## 本章小结（Key Points）

- 疼痛是多维体验（感觉、情绪、认知、社会），强度与不愉快由不同通路编码，故单纯镇痛常不足以恢复功能。
- 伤害感受器把机械、温度与化学刺激转换为电信号；炎症介质引起外周敏化，沉默感受器被招募。内脏传入与躯体传入在脊髓汇聚，形成牵涉痛，是定位诊断最常见的陷阱。
- Aδ 与 C 纤维分别传递「第一痛」与「第二痛」；背角整合后经脊髓丘脑、脊髓网状、脊髓中脑等通路上行。
- 疼痛矩阵（感觉皮层、岛叶、前扣带、前额叶、杏仁核）共同构建体验；皮层与下行系统双向调制。
- 内源性镇痛系统（PAG—RVM—背角）与闸门控制解释了按摩、分心、应激性镇痛与安慰剂效应。
- 外周与中枢敏化、去抑制与结构重塑使疼痛由症状转为疾病状态；此时疼痛强度与损伤程度脱钩。
- 急性疼痛有保护价值、机制在外周；慢性疼痛以中枢机制为主，目标是功能恢复与自我管理，而非完全无痛。

## 单元临床案例（HPP-U12-CASE-01）

> 本案例中的体征、影像与检验描述均为**示意性表述**，用于训练机制推理，不代表任何诊断切点、分级标准或参考范围。

**病例**：周女士，67 岁，高血压病史多年，服药不规律，未规律监测。某日晨起洗碗时突感右手无力，碗落地，随后说话含糊、听不懂家人问话。家属以为「累了」，让其卧床休息。数小时后发现她嗜睡、呼之能应但答话错乱，右侧肢体完全不能活动，遂送医。

入院查体（示意）：嗜睡，双眼向左侧凝视，右侧中枢性面舌瘫，右侧上下肢肌力明显下降，右侧巴氏征阳性，右侧偏身痛温觉减退；左侧瞳孔较右侧大、对光反应迟钝；血压明显高于平时水平，心率偏慢，呼吸不规则。影像（示意）：左侧大脑中动脉供血区大片低密度影，伴占位效应与中线向对侧移位，左侧侧脑室受压。

住院期间出现一次全面性强直-阵挛发作。病情稳定后遗留右侧肢体痉挛性瘫痪、右侧同向性偏盲与言语理解困难。数月后她诉右侧肢体「火烧样、电击样」疼痛，轻触床单即痛，夜间加重，伴失眠与情绪低落，逐渐不愿活动右手。

**问题**：

1. 用第43章的脑血供与第44章的缺血机制，解释她的症状组合为何指向左侧大脑中动脉供血区。
2. 从「占位 → 移位 → 脑疝」链，说明入院时瞳孔不等大、血压升高与呼吸不规则分别意味着什么。
3. 稳定后出现的癫痫发作与痉挛性瘫痪，分别对应第45章的哪一类机制？
4. 数月后的疼痛属于哪一类？用第47章的敏化与调控概念解释「轻触即痛」，并说明评估与处理方向（不涉及药物剂量）。

**要点参考**：

1. 左侧大脑中动脉供应额、顶、颞叶外侧面及部分基底节（穿通支）。其供血区受损产生**对侧（右侧）偏瘫与偏身感觉障碍**、**双眼向病灶侧凝视**（额叶眼区及其下行纤维受损，眼球偏向病灶侧）、**失语**（优势半球）——「对侧偏瘫 + 同向凝视 + 失语」是左侧大脑中动脉区的经典组合。晨起起病、数小时内进展，符合大血管闭塞后缺血扩展与水肿加重的过程；高血压多年提示小血管病变与动脉粥样硬化基础，也可能是心源性栓塞（需评估心律）。
2. 左侧瞳孔散大、对光反应迟钝提示**同侧动眼神经受压**——小脑幕切迹疝的早期信号，其后方是钩回移位压迫中脑。血压升高伴心率减慢、呼吸不规则构成 **Cushing 反应**，提示颅内压失代偿、脑干受压，属晚期而非早期表现。中线移位与侧脑室受压是占位的直接证据。整条链为：梗死区细胞毒性水肿 + 屏障破坏后的血管源性水肿 → 占位 → 中线移位 → 钩回疝 → 脑干受压；可干预节点包括减小水肿、维持脑灌注压与氧合、防治癫痫与发热、避免低血压与高血糖。
3. **癫痫**：皮层梗死灶形成致痫灶，叠加急性期的兴奋毒性、离子梯度破坏与代谢紊乱，导致兴奋—抑制失衡与异常同步放电；属第45章「癫痫」类别，卒中后癫痫多为局灶起源、可继发全面化。**痉挛性瘫痪**：属上运动神经元综合征——皮层对下运动神经元的抑制作用解除、网状脊髓束失衡，表现为肌张力增高、腱反射亢进、病理反射阳性，与周围神经损伤的弛缓性瘫痪、反射消失形成对照；同时要注意痉挛本身可致挛缩与疼痛，是独立的干预目标。
4. 属**中枢性（卒中后）神经病理性疼痛**：丘脑—皮层感觉通路受损后出现中枢去抑制与中枢敏化，背角与丘脑神经元阈值下降、感受野扩大，Aβ 触觉传入被招募进痛通路，故**轻触即痛（异常性疼痛）**并伴痛觉过敏；下行抑制（PAG—RVM）减弱，加上失眠与情绪低落，进一步放大疼痛体验。评估：疼痛性质（烧灼、电击）、分布与诱发因素、异常性疼痛范围、睡眠与情绪、右上肢功能与活动回避、跌倒风险（偏盲 + 痉挛 + 感觉减退叠加）。处理方向：按神经病理性机制选药（不涉剂量）、分级功能训练与患肢保护、睡眠与情绪管理、患者教育与家属参与，目标设为「恢复活动与睡眠」而非「完全无痛」。
