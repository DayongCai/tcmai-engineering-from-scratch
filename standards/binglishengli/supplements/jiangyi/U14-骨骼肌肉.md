# 第49章 骨骼肌肉系统结构与功能（Structure and Function of the Musculoskeletal System）

## 学习目标

完成本章学习后，你应当能够：

1. 按层次说出骨骼肌肉系统的组成，并说明其在支撑与运动之外的代谢、内分泌与产热功能；
2. 比较皮质骨与松质骨的结构差异，说明骨基质的有机相与无机相如何共同决定强度与韧性；
3. 列举四类骨细胞的来源与功能，解释骨细胞作为力学感受器的角色；
4. 阐释骨重建的基本多细胞单位过程，用 RANKL/OPG 轴与 Wnt 通路说明成骨—破骨耦联；
5. 说明关节软骨的分层结构与无血管特性为何使其修复能力低下；
6. 描述骨骼肌从兴奋到收缩的耦联步骤，并区分三类供能系统与肌纤维类型的功能定位。

## 49.1 系统的组成与功能定位

**骨骼肌肉系统（musculoskeletal system）**由骨、关节、骨骼肌，以及把力在它们之间传递的肌腱、韧带、筋膜与滑囊构成。它在教科书里常被当作「支架与杠杆」，但这一系统承担的功能远不止于此：

- **支撑与保护**：骨构成体腔的骨性壁，保护脑、脊髓、心、肺；
- **运动与姿势**：骨为被动杠杆，关节为支点，骨骼肌为主动力源，三者构成运动链；
- **矿物储库**：体内绝大部分钙、磷以矿物形式储存于骨，骨是血钙调节的缓冲池；
- **造血**：红骨髓是血细胞生成场所；
- **产热与代谢**：骨骼肌战栗与非战栗产热参与体温调节，肌肉是全身最大的葡萄糖处置器官之一，也是静息能量消耗的主要来源；
- **内分泌**：骨细胞分泌骨钙素与成纤维细胞生长因子 23（FGF23），后者调控肾排磷；肌肉分泌多种肌肉因子（myokine），与脂肪、肝、脑相互通讯。

把这六项并列记忆的价值在于：**骨骼肌肉的病变从来不只是「动不了」**。骨折后长期卧床可致高钙尿与肾结石，肌少症可加重胰岛素抵抗，慢性炎症性关节病可加速动脉粥样硬化——这些都是系统功能的连带损失，也是护理评估必须覆盖的范围。

## 49.2 骨的组织层次与两类骨

骨在肉眼、镜下与超微结构三个层次都能观察。**皮质骨（cortical bone，密质骨）**位于骨表面，致密、孔隙率低，以**骨单位（osteon，哈弗斯系统）**为结构单元：中央为纵向走行的哈弗斯管，内含血管与神经，周围是同心圆排列的骨板，相邻骨单位由黏合线分隔，横向的穿通管把相邻哈弗斯管连通。**松质骨（cancellous bone，海绵骨、骨小梁骨）**位于骨的内部与干骺端，由相互连接的骨小梁构成三维网格，表面/体积比大，代谢周转快。

两种骨的分工不同：皮质骨承担抗弯与抗扭，松质骨以轻量结构承担压应力并把负荷分散到皮质壳。骨表面覆盖**骨膜**（外层纤维层含血管与神经，内层为生骨层，是骨横径生长与骨折愈合细胞的重要来源）与**骨内膜**（衬于髓腔与骨小梁表面）。

骨基质是**复合材料**，这一点决定全部力学行为：

| 相 | 主要成分 | 提供的性质 | 缺失时的后果 |
|---|---|---|---|
| 有机相（约占干重一半上下） | Ⅰ型胶原为主，另有骨钙素、骨桥蛋白、骨涎蛋白等非胶原蛋白 | 抗张强度、韧性、可变形而不碎 | 胶原合成缺陷 → 骨脆、反复骨折（成骨不全的方向） |
| 无机相（矿物） | 羟基磷灰石类钙磷晶体，沿胶原纤维沉积 | 抗压强度、刚度 | 矿化不足 → 骨软、变形（骨软化/佝偻病的方向） |

**临床联系**：把骨想成钢筋混凝土——胶原是钢筋，矿物是水泥。只有水泥没有钢筋会脆裂，只有钢筋没有水泥会弯软。临床上「骨量正常却反复骨折」与「骨量低但形态尚可」是两类不同的问题，前者提示材料质量或微结构缺陷，后者提示量不足，处理方向完全不同。

## 49.3 四类骨细胞

骨是有活跃细胞代谢的组织，四类细胞分工明确：

| 细胞 | 来源 | 主要功能 |
|---|---|---|
| 成骨细胞（osteoblast） | 间充质干细胞／骨祖细胞 | 合成并分泌类骨质（Ⅰ型胶原为主），表达碱性磷酸酶，促进矿化；分泌 RANKL 与 OPG 调控破骨细胞；一部分转为骨细胞或衬里细胞 |
| 骨细胞（osteocyte） | 分化终末的成骨细胞，被埋入自身分泌的基质 | 通过骨小管网络感受流体剪切力与微损伤，是**力学感受器**；分泌硬化素（sclerostin）与 FGF23；调控局部重建的启动位点 |
| 破骨细胞（osteoclast） | 单核-巨噬细胞系前体融合而成的多核巨细胞 | 贴附骨面形成封闭区，以质子泵酸化溶解矿物，以组织蛋白酶 K 降解胶原，形成吸收陷窝（Howship 陷窝） |
| 骨衬里细胞（bone lining cell） | 静止期覆盖骨面的成骨细胞样细胞 | 隔离骨面与细胞外液、参与钙流交换、在需要时被激活 |

骨细胞的网络结构值得强调：骨细胞伸出大量树突状突起，在骨小管内相互连接并与骨表面细胞相通，形成一个遍布全骨的**力学传感网络**。负荷引起的组织液流动被这一网络感知，转化为生化信号（一氧化氮、前列腺素、Wnt 通路变化），决定「哪里该加骨、哪里该拆骨」。因此骨不是被动承受外力的材料，而是持续自检、按需改建的活组织，这就是**Wolff 定律**（骨的结构随所承受的力学负荷而调整）的细胞学基础。

## 49.4 骨重建：基本多细胞单位与成骨—破骨耦联

骨在一生中不断被拆除与重建，这一过程称**骨重建（bone remodeling）**，其执行单元是**基本多细胞单位（basic multicellular unit, BMU）**。在皮质骨内，BMU 呈锥形推进，前端破骨细胞开凿隧道，后方成骨细胞填充；在松质骨内，BMU 沿骨小梁表面推进，形成吸收陷窝后再填平。一个重建周期分五相：

1. **激活**：骨细胞感知微损伤或负荷改变，招募破骨前体至特定位点；
2. **吸收**：破骨细胞附着、酸化、酶解，形成吸收陷窝，持续数日到数周；
3. **反转**：巨噬样细胞清理残渣，释放耦联信号，为成骨细胞铺路；
4. **形成**：成骨细胞分泌类骨质并使其逐步矿化，时程远长于吸收；
5. **静止**：骨面被衬里细胞覆盖，等待下一轮激活。

**「耦联（coupling）」是全部骨代谢病理的枢纽**：吸收之后必有形成，两者在时程与量上匹配，骨量才守恒。调控这一匹配的主控通路有三条：

**（1）RANKL/RANK/OPG 轴**——破骨细胞的开关。成骨细胞与骨细胞表达**核因子 κB 受体活化因子配体（RANKL）**，与破骨前体表面的 RANK 结合，促其分化、融合、活化并抑制凋亡；成骨细胞同时分泌**骨保护素（OPG）**，作为可溶性诱饵受体竞争结合 RANKL。因此决定骨吸收倾向的不是 RANKL 的绝对量，而是 **RANKL/OPG 比值**的升降方向。几乎所有促吸收的因素——炎症因子、糖皮质激素、雌激素缺乏、甲状旁腺激素持续升高——最终都通过抬高这一比值实现。

**（2）Wnt/β-catenin 通路**——成骨细胞的数量开关。Wnt 信号促骨祖细胞向成骨方向分化并延长成骨细胞寿命；骨细胞分泌的**硬化素（sclerostin）**与 DKK1 是这条路通路的抑制物。关键在力学：**负荷抑制硬化素分泌**，于是负荷→Wnt 增强→骨形成增加。这条链条解释了卧床、制动、失重为何在很短时间內就出现骨丢失，也解释了承重运动对骨的正向作用。

**（3）甲状旁腺激素的双相性**。同一激素，给法不同、方向相反：**间歇性**升高促骨形成（主要经成骨细胞），**持续性**升高促骨吸收（经成骨细胞上调 RANKL）。这是骨代谢调节中最容易被误解的一点——血钙正常不代表骨代谢正常，PTH 的时程特征比单点浓度更能说明问题。

在此之上还有三类修饰因素：

- **性激素**：雌激素抑制 RANKL 表达、促进破骨细胞凋亡、促进成骨细胞存活；雌激素水平下降 → 吸收大于形成，且以松质骨表面为著，因为松质骨表面/体积比大、重建位点多。
- **糖皮质激素**：抑制成骨细胞分化与功能、促骨细胞与成骨细胞凋亡、减少肠钙吸收并增加尿钙，形成「形成下降 + 吸收上升」的双重打击；这是长期激素治疗者骨丢失迅速的原因。
- **炎症因子**：白细胞介素-1、白细胞介素-6、肿瘤坏死因子-α 上调 RANKL，把免疫激活直接翻译为骨破坏——这条线在第51章会以「滑膜炎→骨侵蚀」的形式再次出现。

耦联失衡共有四种方向，用方向记忆比记病名更稳：**形成下降+吸收上升**（绝经后、激素治疗）、**形成与吸收同时下降但吸收相对占优**（老年性慢丢失）、**局部吸收剧增**（溶骨性转移、感染、制动、炎症性关节病）、**局部形成剧增**（反应性骨形成、骨赘、Paget 样病变）。判断一个骨病变，第一步就是问：它落在哪一个方向。

## 49.5 骨量与骨强度的生命周期

骨量在一生中呈可预测的轨迹：生长期随身高与负荷增长，青春期后期达到**峰值骨量**，其后进入平台期，中年之后随年龄缓慢下降。女性在绝经后可出现一段快速丢失期，男性则表现为持续的缓慢丢失。

决定峰值骨量的因素中，**遗传**贡献最大，营养（钙、维生素 D、蛋白质）、力学负荷（承重与抗阻活动）、激素状态（性激素、生长激素、甲状腺激素）与生活方式（吸烟、饮酒、咖啡因过量）共同修饰。峰值骨量是「银行本金」，成年后的丢失是「支出」——本金越少、支出越快，越早进入骨折风险区。

但骨强度不等于骨量。骨强度由三项共同决定：

- **骨量**（材料多少）；
- **微结构**（骨小梁的厚度、数目与**连接性**；皮质骨的厚度与孔隙率）；
- **材料质量**（矿化程度、胶原交联状态、微损伤累积）。

其中微结构的不可逆性最值得警惕：骨小梁一旦穿孔、连接中断，即便后续骨量回升，力学骨架也难以完全复原。这解释了一个临床悖论——治疗后的骨量改善幅度有限，骨折风险下降却更明显，因为干预同时改善了重建平衡与结构完整性。

最后，**骨折风险 = 骨强度 × 外力**。所以防跌倒与增骨量在逻辑上等价：一位骨量中等但反复跌倒的老人，其风险可能高于骨量偏低而步态稳健者。护理评估必须两条线并行，只盯一项会漏掉一半风险。

## 49.6 关节的结构与关节软骨

可动关节（滑膜关节）的基本构件是：**关节软骨**覆盖骨端、**关节囊**包绕关节、内衬**滑膜**、腔内有少量**滑液**，软骨深面为**软骨下骨**，关节外可有滑囊与脂肪垫。

**关节软骨**为透明软骨，其分层结构决定了它的力学行为：

| 层次 | 结构特征 | 功能 |
|---|---|---|
| 表层（切线层） | 胶原纤维平行于表面，软骨细胞扁平 | 抗剪切，最先承受摩擦 |
| 中间层 | 胶原斜行交叉，蛋白聚糖较多 | 分散压力 |
| 深层 | 胶原垂直于表面，细胞柱状排列 | 把压力传向软骨下骨 |
| 钙化层 | 软骨钙化，以**潮线**与深层分界 | 与骨牢固锚定，缓冲界面应力 |

软骨的基质由**Ⅱ型胶原网络**与**蛋白聚糖（aggrecan）**构成。蛋白聚糖带大量负电荷，形成高渗透压，把水吸入基质；受压时水被挤出、卸载时回吸，这种「流动阻力 + 渗透压」机制使软骨具有惊人的抗压与减震能力。胶原网则像约束袋，限制蛋白聚糖过度膨胀并抵抗张应力。

软骨最重要的生物学特征是**无血管、无神经、无淋巴**。这带来三个后果：营养靠滑液经基质扩散（因此**周期性负荷是软骨的"呼吸"**，完全制动反而使软骨营养不良）；代谢率低、细胞密度低、增殖能力有限；损伤后无血凝块支架、无炎症细胞涌入，修复几乎不发生，缺损常被纤维软骨或瘢痕替代，力学性能远逊于原组织。

**临床联系**：软骨的「三无」既是保护（不发生免疫反应、不产生疼痛）也是诅咒（损伤不报警、修复不启动）。这解释了为何骨关节炎在出现症状时往往已有可观的结构改变，也解释了为何关节内骨折必须追求解剖复位——软骨不能靠自身再生来弥补对合不良。

## 49.7 滑膜与滑液

**滑膜（synovium）**衬于关节囊内面，衬里层由两类细胞构成：**巨噬样 A 型细胞**负责吞噬清除关节腔内的碎屑，**成纤维样 B 型细胞**合成透明质酸与润滑素。滑膜下层的血管极为丰富，且衬里层**缺乏连续的基底膜**——血浆成分可以较自由地渗入关节腔，这使滑膜成为血浆与滑液之间的高效交换界面，也使循环中的免疫细胞与免疫复合物容易进入关节。

**滑液**是血浆的超滤液加上滑膜 B 型细胞分泌的**透明质酸**，因此具有独特的**黏弹性**：慢速运动时黏稠（润滑），快速运动时变稀（吸收冲击）。它的功能有三：润滑关节面、为软骨提供营养并带走代谢废物、以巨噬细胞与免疫球蛋白构成关节腔的局部防御。

这种解剖布置埋下了一个伏笔：**滑膜是关节的免疫前哨**。病原体经血流到达关节时首先接触滑膜；自身免疫反应也最易在此点燃；滑膜增生形成的侵袭性肉芽组织（血管翳）则是类风湿关节炎骨破坏的直接执行者。第51章的全部关节病理，几乎都可以回溯到 49.7 这一节的三个事实：血管丰富、无基底膜屏障、免疫细胞易于聚集。

## 49.8 骨骼肌的结构与收缩机制

骨骼肌由**肌束**（bundle）→**肌纤维**（肌细胞）→**肌原纤维**→**肌节（sarcomere）**逐级组成。肌节是收缩的功能单元，两端以 **Z 线**为界，其中：

- **粗肌丝**由肌球蛋白（myosin）构成，头部具有 ATP 酶活性与 actin 结合位点；
- **细肌丝**由肌动蛋白（actin）构成，附有**肌钙蛋白（troponin）**与**原肌球蛋白（tropomyosin）**；
- 明带（I 带）只含细肌丝，暗带（A 带）含粗肌丝全长，H 区为粗肌丝中段无横桥重叠的部分。

**兴奋-收缩耦联（excitation-contraction coupling）**的步骤必须能默写：

1. 运动神经元动作电位到达**神经肌肉接头**，释放乙酰胆碱；
2. 乙酰胆碱结合终板膜受体，产生终板电位，触发肌膜动作电位；
3. 动作电位沿肌膜与 **T 管**内传，激活肌浆网上的**兰尼碱受体（RyR）**；
4. 肌浆网释放钙离子，胞质钙浓度骤升；
5. 钙与肌钙蛋白 C 结合，原肌球蛋白移位，暴露肌动蛋白上的结合位点；
6. 肌球蛋白头部与肌动蛋白结合形成**横桥**，头部摆动产生**滑行**，肌节缩短；
7. 钙被肌浆网钙泵主动回摄（**耗能过程**），胞质钙下降，肌肉舒张。

两个推论极重要。**其一，舒张也是主动的**：钙泵依赖 ATP，因此 ATP 耗竭时横桥无法解离、钙无法回摄，肌肉持续紧张——这就是**尸僵**的机制，也是缺血性肌挛缩的病理生理基础。**其二，力量取决于初始长度与募集**：肌节在中等长度时粗细肌丝重叠最充分、张力最大（长度-张力关系）；超过重叠极限则张力下降。

按长度变化区分收缩形式：**等长收缩**（张力增、长度不变，如维持姿势）、**等张收缩**（张力恒定、长度缩短，如举物）、**离心收缩**（肌肉被拉长而同时产生张力，如下坡、落地缓冲）。离心收缩能以较小代谢代价产生较大力量，但对肌纤维的机械应力也最大，是延迟性肌肉酸痛与肌肉拉伤的主要机制——这为第50章的软组织损伤提供了力学解释。

## 49.9 肌纤维类型与运动单位

骨骼肌并非同质组织。按收缩速度与代谢特征可分为：

| 类型 | 收缩特性 | 代谢特征 | 抗疲劳性 | 功能定位 |
|---|---|---|---|---|
| Ⅰ 型（慢肌） | 收缩慢、张力低 | 氧化代谢为主，毛细血管与线粒体丰富，肌红蛋白多 | 高 | 姿势维持、耐力活动 |
| Ⅱa 型（快氧化糖酵解型） | 收缩快、张力较高 | 氧化与糖酵解兼有 | 中等 | 日常快速动作、中等强度运动 |
| Ⅱx 型（快糖酵解型） | 收缩最快、张力最高 | 糖酵解为主，易堆积代谢产物 | 低 | 爆发性用力、短时高强度 |

一个运动神经元及其支配的全部肌纤维构成**运动单位（motor unit）**。中枢按**大小原则**募集：先动员小运动单位（慢肌、精细控制），需要更大力量时再募集大运动单位。这一原则使日常动作省力平滑，也解释了为何力竭前的最后几次重复总是「动作变形」——快肌单位被大量动员，控制精度下降。

肌纤维类型受遗传与训练共同塑造，且具有可塑性：耐力训练增加线粒体与毛细血管密度、提高氧化能力；抗阻训练增加肌纤维横截面积与收缩蛋白含量。**失神经支配**则引起特征性改变：肌纤维失去神经营养 → 萎缩、纤维类型趋同、接头处乙酰胆碱受体扩散至全肌膜（去神经超敏），临床上表现为自发性颤动与电生理异常。这条线索在评估「肌无力是肌肉病还是神经病」时非常有用。

## 49.10 肌肉的能量代谢与疲劳

肌肉收缩直接消耗 ATP，但胞内 ATP 储备只能支持极短时间，必须由三条系统按强度与时长接力供能：

| 供能系统 | 时程特征 | 底物 | 特点 |
|---|---|---|---|
| 磷酸原系统（ATP-CP） | 最初数秒 | 肌酸磷酸 | 无需氧、不产乳酸、功率最高、储备有限 |
| 无氧糖酵解 | 数十秒至数分钟 | 肌糖原 | 不需氧、产 ATP 较快、伴随乳酸与氢离子生成 |
| 氧化磷酸化 | 持续数分钟至数小时 | 糖、脂肪酸、酮体 | 需氧、功率低但容量近乎无限 |

三系统是**并行叠加**而非依次切换：任何时刻都以氧化供能为主，高强度时另两系统叠加其上。

关于**乳酸**，需要纠正一个流传甚广的错误：乳酸不是「疲劳毒素」，而是重要的**燃料与信号分子**——它可被氧化、可在肌纤维间与器官间穿梭（乳酸穿梭），并参与线粒体功能与肌肉适应的信号传导。运动后血乳酸升高反映的是糖酵解通量增大，而不是肌肉被「毒害」。运动后过量氧耗（俗称「氧债」）则反映恢复期的磷酸原再合成、乳酸清除、体温回落与激素恢复。

**疲劳**是多因素现象，没有单一元凶：胞内无机磷酸与氢离子堆积干扰横桥循环、钙处理能力下降使兴奋-收缩耦联效率降低、活性氧损伤收缩蛋白、糖原耗竭使供能受限、中枢驱动下降（中枢性疲劳）降低募集能力。这一多因素图景有实践含义：改善疲劳不能只靠「补充能量」，睡眠、训练负荷安排、心理动机与疾病状态（贫血、甲状腺功能减退、慢性炎症）都要同时评估。

**临床联系**：肌酸激酶升高提示肌细胞膜通透性增加或肌纤维损伤，可见于剧烈运动、肌肉挫伤、他汀类药物的肌毒性、横纹肌溶解。评估时须同时看尿色与肾功能方向——肌红蛋白大量释放可致急性肾损伤（详见 50.6）。

## 49.11 神经肌肉控制与本体感觉

运动不是肌肉的孤立行为，而是「感觉—整合—执行」的闭环。三类感受器提供关键输入：

- **肌梭（muscle spindle）**：位于肌腹内，与肌纤维平行排列，感受肌肉**长度及其变化速度**；其传入纤维与支配同一肌肉的 α 运动神经元形成单突触的**牵张反射**环路，γ 运动神经元调节肌梭敏感性（γ 环路）；
- **高尔基腱器官（Golgi tendon organ）**：位于肌腱内，与肌纤维串联，感受**张力**，经抑制性中间神经元反馈性降低肌张力，起保护作用；
- **关节与皮肤感受器**：提供位置觉、运动觉与触压信息。

**本体感觉（proprioception）**是位置与运动觉的总称，其输入与视觉、前庭信息在脊髓、小脑与皮质整合，共同维持平衡与姿势。三者构成**平衡三联**：任一路径受损（视力下降、前庭病变、周围神经病致本体感觉减退），平衡能力即下降，跌倒风险上升。老年人常为三重轻度减退叠加，这也是为什么跌倒预防要同时评估视力、前庭与足部感觉，而不能只练肌力。

**临床联系**：本体感觉训练（闭眼单腿站立、不稳定平面训练、太极）之所以有效，机制在于促进感觉输入的整合与运动程序的重新校准，而不仅是增强肌力。对骨折术后、关节置换后与周围神经病患者，这是康复处方中不可省略的一环。

## 49.12 生命周期变化与临床评估维度

**儿童与青少年**：骨在生长板（骺板）处纵向生长，生长板是力学薄弱点，儿童骨折常表现为青枝骨折或骨骺损伤；骨的塑形能力极强，轻度成角可在生长中自行矫正，但生长板损伤可致肢体不等长或成角畸形。肌肉力量与协调性随神经系统成熟而提高，训练应以动作质量与趣味性为主。

**成年期**：骨量达峰值后进入维持期，肌肉量与力量在中年后开始缓慢下降；此期的核心任务是「把峰值抬高、把下降推迟」——承重与抗阻活动、足量蛋白与钙、避免吸烟。

**老年期**：骨量下降、微结构破坏、肌肉量减少（**肌少症，sarcopenia**）、软骨退变、本体感觉与平衡能力减退同时出现，构成「跌倒—骨折—制动—进一步失能」的恶性循环。评估必须覆盖营养、用药（镇静药、降压药致体位性低血压）、居家环境与视听力。

**临床评估的维度**（本讲义一律用方向性描述，不给度数或分级）：

- 视诊：肿胀、红斑、畸形、肌萎缩、步态异常；
- 触诊：压痛部位、皮温、捻发感、波动感；
- 主动与被动活动：记录「主动小于被动」（提示肌腱或疼痛限制）还是「两者同样受限」（提示关节本身或挛缩）；
- 肌力：以能否抗重力、能否抗阻力、是否对称描述，而非套用数字分级；
- 功能任务：起立、行走、上下楼梯、穿脱衣物——功能比关节单项指标更能反映生活影响；
- 系统关联：疼痛对睡眠的影响、活动减少带来的心肺与代谢后果、跌倒史与居家环境。

## 本章小结（Key Points）

- 骨骼肌肉系统承担支撑、运动、矿物储库、造血、产热与内分泌六类功能，病变后果远超「活动受限」；
- 骨是胶原与矿物构成的复合材料：胶原给韧性、矿物给刚度，任一方缺陷都改变骨折模式；
- 骨细胞网络是力学感受器，Wolff 定律的分子实现是「负荷抑制硬化素 → Wnt 通路增强 → 成骨增加」；
- 骨重建以 BMU 为单位，成骨—破骨耦联由 RANKL/OPG 比值与 Wnt 通路主控，PTH 的效应取决于给药时程；
- 耦联失衡有四种方向，识别方向比背病名更有用；
- 关节软骨无血管无神经、靠滑液扩散营养，因此周期性负荷是必需的、损伤后几乎不修复；
- 骨骼肌收缩依赖钙与 ATP，舒张同样耗能；疲劳是多因素现象，乳酸是燃料而非毒素。

# 第50章 骨骼肌肉功能异常：创伤、感染与疾病（Alterations in Musculoskeletal Function: Trauma, Infection, and Disease）

## 学习目标

完成本章学习后，你应当能够：

1. 按受力方式与组织受累层次分类骨骼肌肉损伤，并说明各类损伤的力学机制；
2. 描述骨折愈合三期的细胞与基质事件，比较一期愈合与二期愈合的力学条件；
3. 分析影响骨折愈合的局部与全身因素，区分延迟愈合、不愈合与畸形愈合的机制差异；
4. 解释骨筋膜室综合征的恶性循环与挤压伤的全身后果；
5. 说明骨髓炎的感染途径、生物膜与死骨在慢性化中的作用，并按三条轴线归类骨肿瘤、解释骨转移的「恶性循环」；
6. 描述废用与制动对骨、软骨、肌肉、肌腱及全身的影响，并据此设计康复方向。

## 50.1 损伤的分类与力学基础

骨骼肌肉损伤可按「组织层次」与「受力方式」两条轴线分类，两条轴线交叉才能定位临床问题。

**按组织层次**：

| 损伤 | 受累结构 | 机制要点 |
|---|---|---|
| 挫伤（contusion） | 皮肤、皮下、肌肉 | 直接暴力致微血管破裂与组织内出血，肌肉内血肿可机化 |
| 拉伤（strain） | 肌-腱单位 | 过度牵伸或强烈离心收缩，最常发生于肌腱交界处 |
| 扭伤（sprain） | 韧带 | 关节超出生理范围的应力，韧带纤维部分或完全断裂 |
| 脱位／半脱位（dislocation/subluxation） | 关节 | 关节面失去正常对合；常伴关节囊、韧带与软骨损伤 |
| 骨折（fracture） | 骨 | 应力超过骨强度；可为创伤性、疲劳性（应力性）或病理性 |

**按受力方式**：**直接暴力**（打击、碾压，软组织损伤重，多为粉碎或横形）、**间接暴力**（力经杠杆传导，如跌倒时手掌撑地致桡骨远端骨折，骨折位于受力点之外）、**扭转暴力**（螺旋形骨折）、**牵拉暴力**（撕脱骨折，韧带或肌腱附着处骨块被拉脱）、**重复应力**（疲劳骨折，见于长跑、行军，骨在修复不足时累积微损伤）。

骨折还可按是否与外界相通分**闭合性**与**开放性**（后者感染风险显著升高，是 50.7 的直接入口），按稳定程度分稳定型与不稳定型（决定固定方式与愈合模式）。

**临床联系**：损伤分类的临床价值在于预测「看不见的损伤」。高能量直接暴力造成皮肤完整而深层肌肉广泛挫灭时，表面的轻伤会掩盖深部的骨筋膜室高压；而间接暴力造成的骨折，其软组织损伤相对轻、愈合条件较好。评估时必须同时问「力从哪来、多大、作用多久」。

## 50.2 骨折后的局部与全身反应

骨折不只是骨皮质断裂，而是一次涉及局部与全身的创伤反应。

**局部反应**按时间推进：

1. **血管破裂与血肿形成**：断端及骨膜、髓腔血管撕裂，血液在骨折周围聚积形成血肿；骨膜撕裂的范围决定血供破坏的程度，也决定愈合潜力；
2. **炎症期**：血小板脱颗粒释放趋化与生长因子，肥大细胞与中性粒细胞涌入，巨噬细胞清理坏死组织与碎屑；局部出现红、肿、热、痛与功能障碍；
3. **血管新生与细胞募集**：缺氧与酸性环境稳定缺氧诱导因子，促血管内皮生长因子释放；骨膜生骨层、骨髓与周围软组织的间充质干细胞被招募至骨折处；
4. **软组织修复**：肌肉、筋膜与皮肤各自启动修复，血肿机化形成纤维连接。

**全身反应**包括：创伤性应激（交感兴奋、皮质醇与儿茶酚胺升高、分解代谢占优、负氮平衡）、疼痛与睡眠障碍、发热（吸收热或感染）、失血与贫血、活动受限带来的并发症。需警惕两类特殊全身并发症的方向：**脂肪栓塞**（长骨骨折后骨髓脂肪进入静脉系统，引起肺血管阻塞与全身炎症反应，表现为低氧、意识改变与皮肤瘀点）；**静脉血栓栓塞**（制动、血流淤滞、创伤致高凝）。

**临床联系**：骨折后的「局部处理」永远伴随「全身管理」。疼痛控制不足会限制早期活动，早期活动不足又加重制动后果——这一环在第50章末会以「废用」的形式完整呈现。

## 50.3 骨折愈合三期

骨折愈合是再生过程，其分期按主导事件命名，三期之间相互重叠而非截然分开。

**第一期：炎症与血肿期**。断端血肿形成纤维蛋白网，作为细胞迁移的临时支架；中性粒细胞与巨噬细胞清除坏死组织与细小骨屑；炎症介质（白细胞介素-1、白细胞介素-6、肿瘤坏死因子-α、转化生长因子-β）招募并激活间充质干细胞。此期的关键词是**清理与招募**。临床含义有两面：适度的炎症是愈合的必要条件，过度抑制炎症（如大剂量糖皮质激素、长期非甾体抗炎药）可能延缓骨痂形成；而反复移动断端、反复复位则不断破坏刚刚建立的血管与支架，使愈合在原地打转。

**第二期：修复期（软骨痂 → 硬骨痂）**。两种成骨方式并行：

- **软骨内成骨**：骨折周围的间充质细胞分化为软骨细胞，形成**软骨痂**（以Ⅱ型胶原与蛋白聚糖为主），随后血管长入、软骨细胞肥大凋亡、基质钙化，被**编织骨**替代；
- **膜内成骨**：骨膜生骨层的骨祖细胞直接分化为成骨细胞，在骨膜下形成新骨，构成**硬骨痂**的外壳。

软骨痂提供早期的「软固定」，硬骨痂提供「骨性连接」。当断端被桥接、负重时不再有异常活动，临床上称为**临床愈合**；而**骨性愈合**要求X线上骨痂桥接与髓腔封闭——两者常不同步，这也是为什么「不痛了」不等于「可以随意负重」。

**第三期：重塑期**。编织骨力学性能差、结构杂乱，须被**板层骨**替代：破骨细胞沿应力线开凿通道，成骨细胞随后填充，形成新的骨单位；多余骨痂被吸收，髓腔重新贯通，骨逐步恢复原有形态与强度。此期完全由力学需求驱动（Wolff 定律），时程远长于前两期，可达数月乃至更久，且在儿童与成人、不同部位之间差异很大。**重塑未完成即承受超常负荷，是再骨折的典型场景**。

## 50.4 一期愈合与二期愈合：力学环境决定模式

骨折愈合的模式不是由骨折类型单独决定，而是由**断端间的力学环境**决定：

| 项目 | 二期愈合（间接愈合） | 一期愈合（直接愈合） |
|---|---|---|
| 力学条件 | 相对稳定，允许微小活动 | 绝对稳定，断端间几乎无活动 |
| 典型场景 | 保守治疗、夹板/石膏、髓内固定、松质骨区 | 解剖复位加坚固内固定，断端紧密对合 |
| 中间组织 | 血肿 → 软骨痂 → 硬骨痂 → 编织骨 | 无软骨痂，哈弗斯系统直接穿越断端 |
| 影像特征 | 可见外骨痂 | 无明显外骨痂，靠断端逐渐消失的透亮线判断 |
| 时程特点 | 早期快、后期需长期重塑 | 早期慢、无骨痂期易被误判为「不愈合」 |

理解这一对照的要点是：**微动是双刃剑**。适量的微动刺激骨痂形成（机械信号促间充质细胞向成骨/成软骨方向分化），过度活动则使断端被纤维组织填充、无法桥接；绝对稳定虽能实现一期愈合，却牺牲了骨痂的「生物性加固」，且内固定物承受全部负荷，可能产生应力遮挡——被保护的骨因缺乏负荷而局部骨量下降，取出内固定后需重新适应。

**临床联系**：这解释了为何「固定得越牢越好」并不成立，也解释了为何康复计划必须与固定方式匹配——坚固内固定者可早期活动关节与部分负重，保守治疗者则需在保护期内限制负重。护士的宣教要点不是「多动」或「少动」，而是**「按这种方式允许的范围动」**。

## 50.5 骨折愈合不良的机制

按结果分类，愈合不良有三种形态，机制各不相同：

- **延迟愈合（delayed union）**：愈合进程慢于该部位与类型的预期，但仍在推进；去除不利因素后仍可愈合；
- **不愈合（nonunion）**：超过合理时程仍无骨性连接，断端硬化、髓腔封闭，形成假关节；又分**肥大性**（血供尚可、但稳定不足，断端膨大如「象足」，提示生物学活跃而力学失败）与**萎缩性**（血供差、断端吸收变细，提示生物学失败）；
- **畸形愈合（malunion）**：已愈合但对位、对线或长度不良，遗留力线异常与关节负荷分布改变。

影响愈合的因素可分两组：

**局部因素**——血供（胫骨中下段、股骨颈、腕舟骨、距骨等部位因滋养血管分布特殊而愈合困难）、感染（持续的炎症与死骨使愈合无法启动）、稳定性（过度活动）、骨缺损（超过临界尺寸的缺损无法自行桥接）、软组织嵌入（肌肉或筋膜夹在断端之间）、关节内骨折（滑液中的纤维蛋白溶解酶可溶解血肿支架）。

**全身因素**——年龄（儿童愈合快于老年）、营养（蛋白质、钙、维生素 D、维生素 C 缺乏均不利胶原合成与矿化）、吸烟（尼古丁致血管收缩、一氧化碳降低氧输送、抑制成骨细胞）、糖尿病（微血管病变与糖基化终产物）、糖皮质激素与免疫抑制剂、放疗、慢性消耗性疾病。

**护理含义**：上述清单中有一半是可干预的行为与营养因素。把「吸烟」「蛋白摄入」「血糖控制」写进护理计划，其证据强度不亚于任何技术操作。

## 50.6 骨筋膜室综合征与挤压伤

**骨筋膜室**是由骨、骨间膜、肌间隔与深筋膜围成的封闭腔隙，内含肌肉、神经与血管。由于四壁缺乏弹性，腔内内容物体积增加或外部压迫都会使**室内压力升高**，而压力升高又压迫薄壁静脉与小动脉，使灌注进一步下降——这就构成了一个**自我强化的恶性循环**：

> 创伤/出血/水肿 → 室内压力升高 → 静脉回流受阻 → 渗出增加、水肿加重 → 压力更高 → 毛细血管灌注压不足 → 肌肉与神经缺血 → 细胞膜泵失效、细胞内水肿 → 压力再升高

缺血最先受损的是**神经**（对缺氧最敏感）与**肌肉**（代谢需求高），因此早期表现是**感觉异常与被动牵拉痛**，而不是脉搏消失——**脉搏消失是晚期征象，等待它出现等于等待不可逆损伤**。经典的「5P」中，疼痛（pain，尤其与损伤程度不相称的剧痛）、被动牵拉痛（pain with passive stretch）、感觉异常（paresthesia）出现早，苍白（pallor）、麻痹（paralysis）、无脉（pulselessness）出现晚。护理上最重要的一句判断是：**「越来越痛、越来越紧、越来越麻」是需要立即上报的信号，而不是等待观察的信号**。

后果是**缺血性肌挛缩（Volkmann 挛缩）**：坏死肌肉被纤维组织替代，肌腱固定于瘢痕中，形成腕与手指的屈曲畸形伴感觉障碍。这是不可逆的结构后果，也是本章「时间就是组织」的最强例证。

**挤压伤（crush injury）**是另一条全身路径。大量横纹肌细胞坏死，内容物涌入循环：

- **肌红蛋白**经肾滤过，在酸性尿中形成管型、阻塞肾小管，并对肾小管上皮产生直接毒性 → **急性肾损伤**；
- **钾**从坏死细胞释放 → 高钾血症，可致致命性心律失常；
- **钙**沉积于坏死肌肉 → 低钙血症，加重心律失常与凝血异常；
- **乳酸与酸性代谢产物** → 代谢性酸中毒；
- 血浆渗入受损肌肉 → 有效循环血量下降 → 低血容量性休克。

因此挤压伤的处理逻辑是三条并行：**容量复苏（把尿量维持住以冲刷肌红蛋白）、纠正电解质与酸碱紊乱、处理创面与坏死组织**。这条线与水电解质（U07）、肾脏（U08）两单元直接相连，是本单元最重要的跨单元接口。

## 50.7 骨髓炎：感染途径、生物膜与死骨

**骨髓炎（osteomyelitis）**是骨与骨髓的感染，其难治程度由骨的特殊解剖决定。感染途径有三：

1. **血源性（hematogenous）**：菌血症时细菌在血流缓慢处停留。儿童长骨干骺端的毛细血管襻血流缓慢且缺乏吞噬细胞，是典型起点；成人则多见于椎体（Batson 静脉丛）与骨盆；
2. **邻近蔓延（contiguous）**：从邻近软组织感染直接侵入，如糖尿病足溃疡、压疮、牙源性感染至下颌骨；
3. **直接植入（direct inoculation）**：开放性骨折、手术内固定物、关节置换假体。

致病菌以金黄色葡萄球菌最常见，其表面黏附素可结合骨基质蛋白（纤连蛋白、胶原），使细菌在骨面「锚定」；革兰阴性菌、厌氧菌在糖尿病足与咬伤中更常见；结核分枝杆菌则走慢性肉芽肿路径。

**三个机制性难点**构成本病的核心：

**（1）生物膜（biofilm）**。细菌在骨面或内固定物表面分泌胞外多糖基质，形成结构化群落。生物膜内的细菌代谢率低、表型改变，对多数抗生素的敏感性大幅下降，且胞外基质阻碍抗体与吞噬细胞进入。更棘手的是，生物膜可持续释放浮游菌，造成「治疗后复发」的循环。这是内固定物相关感染往往需要移除植入物的原因——**在无血管的异物表面，药物与免疫都到不了**。

**（2）死骨（sequestrum）**。炎症引起骨内血管血栓形成与骨膜血管破坏，局部骨组织缺血坏死。死骨无血供，抗生素无法到达，又成为细菌的庇护所；同时炎症刺激骨膜形成新生骨壳（**包壳，involucrum**），把感染包裹在内部。慢性骨髓炎的经典三联是**死骨、包壳与窦道**——窦道反复排脓、时闭时开，可迁延多年。

**（3）缺血与硬化**。慢性炎症使骨硬化、髓腔纤维化，血供进一步恶化，形成「越慢性越缺血、越缺血越难治」的循环。

**临床联系**：急性期以全身中毒症状（高热、寒战）、局部剧痛、压痛与活动受限为主；慢性期则以反复窦道排脓、局部肿痛、全身症状轻微为特点，容易被误认为「皮肤问题」。评估时须问清有无开放性损伤史、手术史、糖尿病与免疫抑制状态。

## 50.8 感染性关节炎与骨关节结核

**感染性（化脓性）关节炎**是关节腔的细菌感染，多经血行播散。滑膜血管丰富、衬里层缺乏基底膜屏障（见 49.7），使细菌极易在此种植并迅速引起滑膜中性粒细胞浸润。关节腔是一个相对封闭的空间，缺少补体与调理素的持续补充，细菌得以快速增殖；中性粒细胞释放的蛋白酶、活性氧与炎症因子在杀灭细菌的同时**直接降解软骨基质**。因此化脓性关节炎的软骨破坏可在很短时间内发生，属于骨科急症——「引流 + 抗菌」必须尽早，任何延迟都以永久性关节损伤为代价。

**骨关节结核**走另一条路径：结核分枝杆菌引起**肉芽肿性炎症**，起病隐匿，全身中毒症状轻（低热、盗汗、消瘦、乏力），局部以疼痛、肌肉痉挛与活动受限为主。病理上以**骨破坏**为特征，可形成冷脓肿（无红热的脓肿）与窦道；脊柱结核（Pott 病）累及椎体，可致椎体塌陷与后凸畸形，若压迫脊髓则出现神经症状。与化脓性感染相比，结核的炎症反应「温和」而破坏「持久」，因此**诊断延迟远比急性感染更长**，这是它最危险的地方。

**鉴别方向**：起病速度（急骤 vs 隐匿）、全身中毒症状的轻重、局部红热是否明显、有无窦道与冷脓肿、既往结核接触史与免疫状态。

## 50.9 骨肿瘤的机制类别

骨肿瘤相对少见，但分类逻辑清晰，按三条轴线交叉定位：

**按组织来源**：成骨性（骨肉瘤）、成软骨性（软骨肉瘤、骨软骨瘤）、纤维性与纤维组织细胞性、骨髓来源（多发性骨髓瘤、淋巴瘤）、血管性与神经性、来源不明的巨细胞瘤等。

**按生物学行为**：良性（生长局限、有包膜或边界清楚、不转移，但因占位可致病理性骨折或压迫神经）、恶性（浸润性生长、破坏皮质、可转移）、交界性（局部侵袭但转移潜能低）。

**按对骨的影响**：**溶骨性**（骨破坏、透亮区、皮质变薄）、**成骨性**（骨硬化、密度增高）、**混合性**。这一轴线在影像与临床判断中最实用，因为它直接对应症状机制：溶骨 → 骨强度下降 → 疼痛与病理性骨折；成骨 → 骨结构紊乱但强度未必下降。

年龄与部位提供重要线索方向：青少年多见于生长活跃的部位（长骨干骺端，如股骨远端、胫骨近端、桡骨远端）；老年人则需优先考虑转移瘤与骨髓瘤。**骨转移瘤的发生率远高于原发骨肿瘤**，因此成人发现骨破坏性病变时，「从哪里转移来的」是第一个要问的问题，常见原发部位为乳腺、肺、前列腺、肾与甲状腺。

**疼痛的机制**也值得区分：肿瘤性疼痛常为**夜间痛、静息痛**，与力学负荷无关；而力学性疼痛（如骨关节炎）多在活动时加重、休息后缓解。这一方向性差异是最实用的床边鉴别线索之一。

## 50.10 骨转移的「恶性循环」与病理性骨折

骨转移不是肿瘤细胞「被动停留」，而是肿瘤与骨微环境之间的双向塑造，形成**恶性循环**：

> 肿瘤细胞进入骨髓 → 分泌甲状旁腺激素相关蛋白（PTHrP）、白细胞介素-6、白细胞介素-11 等 → 成骨细胞/基质细胞上调 RANKL → 破骨细胞活化 → 骨吸收 → 基质释放转化生长因子-β、胰岛素样生长因子 → 反过来促进肿瘤细胞增殖 → 更多溶骨因子释放

这一循环解释了三个临床现象：溶骨灶呈「进行性扩大」而非静止；抑制破骨细胞活性的治疗能减轻骨痛与骨相关事件（即使肿瘤本身未被消灭）；不同原发肿瘤偏好不同表型（前列腺癌多成骨性、乳腺与肺多溶骨或混合性），因为分泌的因子谱不同。

**病理性骨折**指在骨本身已有病变（肿瘤、感染、囊肿、严重骨量丢失）的基础上，轻微外力即发生骨折。其机制是「强度已被削弱 + 正常外力」，因此预防的关键不是避免外力（无法完全避免），而是识别高危病灶并提前处理。

**肿瘤相关高钙血症**是另一条全身路径：溶骨释放的钙超过肾脏排泄与骨再矿化的能力 → 血钙升高 → 多尿与脱水（肾浓缩功能受损）→ 进一步减少钙排泄（恶性循环）→ 消化道症状（恶心、便秘、食欲下降）→ 神经症状（乏力、意识改变、嗜睡）→ 心律失常。护理上，「多尿 → 脱水 → 意识改变」这条链一旦出现，必须同时想到高钙，而不是只补液。

## 50.11 废用与制动的影响

制动是治疗手段，也是病理刺激。它对各组织的影响方向一致——**「不用的就拆掉」**，但时程与可逆性各不相同：

| 组织 | 主要变化 | 方向 | 可逆性 |
|---|---|---|---|
| 骨 | 力学信号减少 → 硬化素升高、Wnt 下调 → 形成下降、吸收上升 | 承重部位松质骨丢失最著 | 部分可逆，微结构连接损失难以完全恢复 |
| 关节软骨 | 缺乏周期性负荷 → 滑液扩散营养减少、蛋白聚糖合成下降 | 软骨变薄、软化 | 早期可逆，长期退变不可逆 |
| 肌肉 | 蛋白合成下降、泛素-蛋白酶体与自噬介导的降解增强 | 肌萎缩，抗重力肌最著 | 可逆，但恢复慢于丢失 |
| 肌腱与韧带 | 胶原交联与排列改变 | 刚度下降、力学性能减弱 | 可逆，需渐进负荷 |
| 关节囊与结缔组织 | 胶原重塑、疏松结缔组织变为致密 | 挛缩、活动范围受限 | 部分可逆，越久越难 |
| 全身 | 静脉淤滞、肺通气不足、负氮平衡、胰岛素抵抗、体位性低血压、便秘、情绪低落 | 多系统退化 | 依赖活动恢复 |

三个细节值得强调：

**其一，肌力下降快于肌量下降**。制动早期力量损失中相当部分来自神经因素（募集能力下降、运动单位放电频率降低），因此早期介入的等长收缩与想象性训练也能保留部分力量——这对不能负重的患者很有意义。

**其二，骨丢失有部位选择性**。承重骨（跟骨、股骨颈、椎体）丢失最明显，非承重骨相对轻，这再次印证力学信号的主导作用。

**其三，儿童与老年的差异**。儿童骨塑形能力强、恢复快，但长期制动可影响生长与肢体长度；老年人肌少症与骨量丢失叠加，制动数周即可造成功能状态的阶梯式下降，且常无法回到制动前水平。对老年人而言，**「卧床」本身是一种治疗风险**，必须与收益权衡。

## 50.12 康复的生理学基础与护理要点

康复不是「养好了再练」，而是从损伤即刻开始的、以力学信号为工具的治疗。四条生理学原则支撑全部方案：

1. **超负荷原则**：刺激必须超过日常负荷阈值才能引发适应——骨需要承重与冲击，肌肉需要抗阻，软骨需要周期性压缩；
2. **特异性原则**：适应的方向与刺激的形式对应——耐力训练改善氧化能力，抗阻训练增加肌量与力量，平衡训练改善姿势控制，彼此不能完全替代；
3. **可逆性原则**：去除刺激即退化，因此「维持」需要持续投入，中断训练的代价是部分或全部丧失；
4. **渐进原则**：负荷增长须在组织耐受范围内，过快则引发再损伤（应力性骨折、肌腱病、软骨损伤）。

**护理要点**（按时间推进）：

- **急性期**：疼痛与肿胀控制、体位与支具管理、观察神经血管状态（尤其骨筋膜室综合征的早期信号）、预防深静脉血栓与压疮；
- **早期活动期**：未受累关节的全范围活动、患肢的等长收缩、呼吸训练与体位变换、尽早离床（在允许范围内）；
- **功能恢复期**：渐进负重、肌力与耐力训练、本体感觉与平衡训练、日常生活活动训练；
- **长期**：营养（足量蛋白质、钙与维生素 D）、戒烟、跌倒预防（居家环境、视力、用药复核）、体重管理（减轻关节负荷）。

**评估与记录的方向**：疼痛（性质、时间、诱因、对睡眠的影响）、肿胀与皮温、主动与被动活动范围的差异、肌力（能否抗重力/抗阻、左右是否对称）、步态与转移能力、日常生活活动的独立性、以及患者对疾病与康复的理解程度。所有指标以**变化方向**记录，而非绝对数值。

## 本章小结（Key Points）

- 损伤须按组织层次与受力方式双轴定位，高能量直接暴力可造成「表面轻、深层重」的假象；
- 骨折愈合三期：炎症与血肿（清理与招募）→ 修复（软骨痂与硬骨痂）→ 重塑（编织骨变板层骨，力学驱动）；临床愈合与骨性愈合不同步；愈合模式由断端力学环境决定，相对稳定走二期愈合、绝对稳定走一期愈合，微动是双刃剑；
- 愈合不良分延迟、不愈合（肥大性/萎缩性）与畸形愈合，局部因素以血供、感染、稳定性为主，全身因素中吸烟与营养最可干预；
- 骨筋膜室综合征是压力—缺血恶性循环，被动牵拉痛早于无脉，等待脉搏消失等于等待不可逆损伤；
- 骨髓炎之难治源于生物膜、死骨与缺血三者叠加；
- 骨转移的溶骨灶由肿瘤—破骨细胞恶性循环驱动；病理性骨折与高钙血症是其两条主要后果；
- 制动对骨、软骨、肌肉、肌腱与全身均产生方向一致的退化，康复以超负荷、特异性、可逆与渐进四原则对抗。

## 51.1 风湿性疾病的范围与两种范式

**风湿性疾病（rheumatic diseases）**是一组累及关节、肌腱、韧带、肌肉与结缔组织的疾病总称，包括：

- **自身免疫性炎症性关节病**：类风湿关节炎、系统性红斑狼疮、脊柱关节病（强直性脊柱炎、银屑病关节炎、反应性关节炎、肠病相关关节炎）、系统性硬化、干燥综合征、血管炎；
- **退行性关节病**：骨关节炎；
- **晶体性关节病**：痛风、焦磷酸钙沉积病；
- **感染相关**：化脓性关节炎、莱姆病关节炎、风湿热；
- **软组织风湿症**：纤维肌痛、肌腱病、滑囊炎、肌筋膜疼痛。

病种虽多，机制上可归为两种**范式（paradigm）**，鉴别这两者是本章的组织主线：

| 维度 | 炎症主导型 | 力学-代谢主导型 |
|---|---|---|
| 代表疾病 | 类风湿关节炎、脊柱关节病、痛风发作 | 骨关节炎、肌腱病 |
| 启动机制 | 免疫耐受破坏、自身抗体、炎症介质 | 负荷异常、软骨细胞代谢失衡、低度炎症 |
| 主要靶组织 | 滑膜（及附着点） | 关节软骨、软骨下骨 |
| 破坏方式 | 侵蚀性（骨与软骨同时破坏） | 磨损与修复失衡（软骨丢失、骨赘形成） |
| 全身表现 | 明显（疲乏、发热、贫血、多器官） | 通常缺如 |
| 晨僵特点 | 长，活动后改善 | 短，活动后加重 |
| 病程 | 发作与缓解交替、持续进展 | 缓慢进展、与负荷相关 |

这张表的价值不在背病名，而在**建立第一判断**：一位多关节肿痛的患者，先问「这是炎症还是力学问题」——答案决定后续检查方向、治疗逻辑与护理重点。判断错误（把炎症当劳损、或把退变当炎症）是风湿领域最常见的认知错误。

## 51.2 免疫耐受的破坏与自身抗体

自身免疫病的起点是**免疫耐受（immune tolerance）**的失效。正常情况下，中枢耐受（胸腺与骨髓中对自身反应性淋巴细胞的清除）与外周耐受（调节性 T 细胞、无能状态、抑制性受体）共同阻止免疫系统攻击自身组织。风湿性疾病中，这一多层防线在遗传易感背景下被环境因素突破。

**遗传易感**最典型的例子是 HLA 区域的关联：某些 HLA-DR 等位基因编码的抗原结合槽可高效呈递特定的自身肽段（「共享表位」假说），使 T 细胞易于被激活。但遗传只是「易感」，不是「决定」——同卵双生的患病一致性远低于完全一致，说明环境因素必不可少。

**环境触发**有三条被广泛讨论的路径：

- **黏膜起点假说**：吸烟在肺内诱导蛋白瓜氨酸化（由肽酰精氨酸脱亚氨酶催化），产生的瓜氨酸化蛋白被呈递后激发抗体反应，随后针对关节内相似修饰蛋白发生交叉反应。这解释了吸烟与类风湿关节炎的强关联，也解释了为何抗体可在关节症状出现前很久就被检出；
- **分子模拟**：病原体抗原与自身抗原结构相似，抗病原免疫反应误伤自身组织；
- **表位扩展（epitope spreading）**：初始反应针对一个表位，组织损伤释放更多自身蛋白，反应范围逐步扩大，疾病由局限走向系统。

**自身抗体**的意义须精确理解：它是**标志物**，说明免疫系统已对自身成分发生反应，但不必然等同于致病因子。类风湿因子（针对 IgG Fc 段的抗体）与抗瓜氨酸化蛋白抗体（ACPA）都可出现在症状之前，ACPA 与侵蚀性病程的关联更强；抗核抗体是结缔组织病的筛查线索，抗双链 DNA 与抗 Sm 抗体对系统性红斑狼疮更具特异性。临床上「抗体阳性 + 无症状」不等于疾病，「抗体阴性 + 典型表现」也不能排除疾病——血清学是拼图的一块，不是判决书。

## 51.3 滑膜炎的细胞与介质机制

关节的炎症几乎都从滑膜开始，理由在 49.7 已经埋下：滑膜血管丰富、衬里层缺乏基底膜屏障、免疫细胞易于聚集。

**类风湿关节炎的滑膜炎**具有几个特征性改变：

1. **衬里层增生**：A 型（巨噬样）与 B 型（成纤维样）滑膜细胞大量增殖，衬里层由原本的薄层变为多层，B 型细胞的表型发生转变——获得侵袭性、分泌基质降解酶、抵抗凋亡，行为上近似「局部侵袭性肿瘤」；
2. **新生血管形成**：缺氧与血管内皮生长因子驱动血管增生，为不断增厚的滑膜供氧，也为更多炎症细胞提供入口；
3. **炎性浸润**：T 细胞（尤其辅助性 T 细胞亚群）、B 细胞、浆细胞、巨噬细胞聚集，可形成类似淋巴滤泡的结构；B 细胞分化为浆细胞产生自身抗体（类风湿因子、ACPA），形成「自身抗体—免疫复合物—补体激活」的正反馈；
4. **介质网络**：肿瘤坏死因子-α、白细胞介素-6、白细胞介素-1、粒细胞-巨噬细胞集落刺激因子构成核心网络，彼此上调、互为放大；趋化因子把循环白细胞持续招募入关节；
5. **基质降解**：**基质金属蛋白酶（MMP）**与 **ADAMTS** 家族分别降解胶原与蛋白聚糖，是软骨基质丢失的直接执行者；其活性受组织金属蛋白酶抑制物调控，炎症状态下抑制物相对不足；
6. **骨侵蚀的启动**：滑膜成纤维细胞与活化 T 细胞表达 RANKL（见 49.4），在关节边缘的「裸区」（软骨与骨交界、无软骨覆盖处）激活破骨细胞，形成特征性的边缘性骨侵蚀。

**临床联系**：上述每一步都对应一个可干预的靶点——阻断细胞因子、耗竭 B 细胞、抑制 T 细胞共刺激、抑制破骨细胞。理解机制不是为了记药名，而是为了理解「为什么越早干预，结构损伤越少」：滑膜一旦完成表型转变并建立血管翳，破坏就具有了自我维持的动力。

## 51.4 从滑膜炎到畸形：损伤链

类风湿关节炎的关节破坏是一条环环相扣的链条，每一环都有明确的细胞事件：

> **滑膜炎**（衬里增生、炎性浸润）→ **血管翳（pannus）**：由增生的滑膜、新生血管与炎症细胞构成的侵袭性肉芽组织，覆盖并侵入软骨表面 → **软骨降解**：MMP 与 ADAMTS 分解胶原与蛋白聚糖，软骨细胞在炎症介质与一氧化氮作用下凋亡，软骨变薄、表面溃疡 → **骨侵蚀**：RANKL 驱动的破骨细胞在关节边缘侵蚀，X线上呈边缘性骨破坏 → **关节间隙狭窄**：软骨丢失的直接后果 → **力学失衡**：关节囊与韧带被炎症拉伸松弛，肌腱滑动受限或断裂，肌力下降 → **畸形**：关节周围软组织失衡使关节偏离正常对线（尺偏、天鹅颈、纽扣花、拇指 Z 形畸形等）→ **功能丧失与残疾**

这条链的关键性质是**不可逆性递进**：滑膜炎是可逆的（治疗后可以消退），软骨降解部分可逆（早期），骨侵蚀与畸形不可逆。因此「治疗窗口」的概念在此有严格的生物学含义——**在结构损伤发生前阻断炎症，是唯一能改变远期结局的策略**。

**临床线索的方向性**（不给数值）：

- 晨僵时间**长**、活动后**改善** → 指向炎症；
- 对称性、小关节（掌指、近端指间关节、腕）为主的肿胀 → 指向类风湿关节炎；
- 远端指间关节、第一掌指关节受累、骨性膨大 → 指向骨关节炎；
- 非对称、下肢大关节、附着点压痛 → 指向脊柱关节病；
- 单关节、起病极快、红肿热痛剧烈 → 指向晶体性或感染性。

评估时还要注意**关节外的沉默损伤**：颈椎寰枢关节受累可致不稳（插管与体位管理时的风险），环杓关节受累可致声音嘶哑与气道风险，这些在术前评估中至关重要。

## 51.5 关节外表现与全身炎症的代价

类风湿关节炎不是「关节病」，而是**系统性疾病**。炎症介质溢出关节进入循环，产生全身效应：

- **类风湿结节**：见于皮下与内脏，中心为纤维素样坏死，周围为栅栏状排列的组织细胞与单核细胞，与疾病活动度和抗体阳性相关；
- **血管炎**：累及小到中等血管，可致皮肤溃疡、周围神经病变、指端缺血；
- **呼吸系统**：间质性肺病、胸膜炎与胸腔积液、结节性病变；
- **眼**：巩膜炎、表层巩膜炎（可致视力威胁，需与普通结膜炎鉴别）；
- **心血管**：心包炎、加速的动脉粥样硬化——慢性炎症是独立的心血管危险因素，这一点常被患者与部分医务人员低估；
- **血液**：慢性病性贫血（炎症致铁调素升高、铁利用障碍，铁剂单纯补充效果有限）、血小板增多；
- **骨**：炎症性骨丢失（RANKL 上调）叠加活动减少，骨折风险升高；
- **长期并发症**：淀粉样变（血清淀粉样蛋白 A 沉积）、继发性干燥综合征。

**疲乏（fatigue）**应被当作一个独立的、可测量的症状维度，而不是「意志薄弱」。其机制包括炎症介质对中枢的作用、睡眠障碍、贫血、疼痛与心理负担的叠加。

**护理含义**：风湿病的护理评估必须覆盖关节外器官，尤其是心血管风险、肺部症状、眼部症状与感染风险（免疫抑制治疗下）。宣教要点是让患者理解「这是全身病」，从而提高对全身症状的警觉与治疗依从性。

## 51.6 脊柱关节病与附着点炎

**脊柱关节病（spondyloarthropathies）**是一组共享临床与遗传特征的疾病：强直性脊柱炎、银屑病关节炎、反应性关节炎、炎症性肠病相关关节炎、未分化脊柱关节病。其共同点与类风湿关节炎形成鲜明对照：

| 特征 | 类风湿关节炎 | 脊柱关节病 |
|---|---|---|
| 原发部位 | 滑膜 | **附着点（enthesis）**——肌腱、韧带、关节囊附着于骨处 |
| 遗传关联 | HLA-DR 共享表位 | HLA-B27 |
| 分布 | 对称、外周小关节 | 非对称、下肢为主、中轴受累 |
| 起病部位 | 手足小关节 | 骶髂关节、脊柱 |
| 骨的反应 | 以破坏为主 | **破坏与反应性骨形成并存** |
| 核心细胞因子轴 | 肿瘤坏死因子、白细胞介素-6 | 白细胞介素-23/白细胞介素-17 |

**附着点炎**是本组疾病的机制核心。附着点是力学应力集中处，也是血管化程度较低、纤维软骨过渡的组织——免疫细胞在此聚集后，炎症既造成局部骨侵蚀（因此可见「侵蚀性附着点炎」），又通过修复反应引起**反应性骨形成**：韧带骨赘沿脊柱纵向生长，最终使相邻椎体「桥接」，脊柱活动度丧失、后凸畸形（影像上称「竹节样脊柱」）。这一「破坏 + 成骨」并存的特征，是脊柱关节病与类风湿关节炎最本质的机制差异，也解释了为何强直性脊柱炎患者既有骨折风险（骨质量差、脊柱僵硬如长骨）又有骨赘形成。

**力学-免疫耦联**在此体现得最清楚：附着点炎好发于跟腱、足底筋膜、髌腱等承受高应力的部位，说明机械应力本身可放大局部炎症反应——「哪里受力，哪里发炎」是这组疾病的空间规律。**临床线索**：青年男性、慢性腰背痛（夜间与晨起为重、活动后改善、休息不缓解）、足跟痛、葡萄膜炎、银屑病皮疹、家族史。

## 51.7 骨关节炎：力学-代谢范式

**骨关节炎（osteoarthritis, OA）**长期被描述为「磨损」，这一比喻既对又错：机械负荷确实是核心因素，但软骨不是被动磨损的材料，而是**主动重塑而失衡的组织**。现代理解是：软骨细胞在异常力学与炎症微环境中发生表型改变（趋向肥大样分化）、合成与降解失衡（MMP 与 ADAMTS 升高、蛋白聚糖合成相对不足）、软骨基质逐步丢失；软骨下骨同步发生重塑——硬化、囊性变、骨赘形成；滑膜出现**低度炎症**（不如类风湿剧烈，但确实参与疼痛与进展）。

**危险因素**按其作用方式分类：

- **力学**：肥胖（负荷增加）、既往关节损伤（半月板、韧带、关节内骨折破坏力学分布）、力线异常（膝内翻/外翻使负荷集中于一侧）、肌力不足（肌肉是关节的减震器）、职业性重复负荷；
- **代谢**：脂肪组织分泌的脂肪因子与低度全身炎症、代谢综合征；
- **生物学**：年龄（软骨细胞修复能力下降、基质累积损伤）、遗传、性别；
- **其他**：关节发育异常、神经性关节病（感觉丧失致反复微创伤）。

**骨赘（osteophyte）**的机制值得单独说明：它是关节边缘的反应性骨形成，本质是机体试图**扩大关节面以分散负荷**的代偿行为。因此骨赘大小与疼痛程度并不平行——它是一个「力学代偿的标记」，而非「病情严重度的量表」。

**疼痛来源的多元性**是 OA 管理的核心难点：疼痛可来自滑膜（炎症）、骨膜（骨赘牵张）、软骨下骨（骨髓水肿、微骨折）、关节囊与韧带（牵张）、以及周围肌肉（痉挛与疲劳），还可叠加中枢敏化。这就是为什么影像上的结构改变与症状严重度常常不一致——**治疗的是人，不是片子**。

**与类风湿关节炎的鉴别方向**：晨僵短、活动后加重、休息缓解；受累以负重与远端指间关节为主；骨性膨大（Heberden 与 Bouchard 结节）；无全身炎症表现；急性期反应物通常不高。

## 51.8 晶体性关节病：痛风与假性痛风

晶体性关节病的共同逻辑是：**代谢异常提供背景，晶体提供触发器，炎症体放大反应**。

**痛风（gout）**的机制分三段：

1. **高尿酸血症的形成**：尿酸是嘌呤代谢终产物。生成过多（高嘌呤饮食、酒精尤其啤酒、细胞更新加速如肿瘤溶解、酶缺陷）或排泄减少（肾功能下降、某些药物抑制肾小管分泌、脱水、乳酸与酮体竞争排泄）都可致血尿酸升高。**绝大多数患者属排泄减少型**；
2. **晶体沉积**：尿酸盐在温度较低、pH 较低、脱水与局部创伤的条件下析出针状单钠尿酸盐晶体。这解释了为何痛风好发于第一跖趾关节（体温最低、承受机械应力）、耳廓与远端关节；
3. **炎症爆发与自限**：晶体被巨噬细胞与中性粒细胞吞噬后激活 **NLRP3 炎症体** → 白细胞介素-1β 释放 → 中性粒细胞大量涌入 → 剧烈红肿热痛，在很短时间内达峰。随后炎症自发消退（吞噬细胞清除晶体、抗炎介质与脂质介质转换、晶体被蛋白包被），这一**自限性**是痛风发作的标志性特征。

慢性阶段：反复发作 → 痛风石（tophus，尿酸盐在软组织与骨内沉积）→ 侵蚀性骨破坏、关节畸形；肾脏受累包括尿酸性结石与尿酸盐肾病。痛风与代谢综合征、高血压、慢性肾病互为因果，评估时必须看全身。

**焦磷酸钙沉积病（CPPD，假性痛风）**：焦磷酸钙晶体沉积于关节软骨与半月板（软骨钙化），急性发作时症状酷似痛风，但机制不同——晶体类型不同、好发于老年、常累及膝等大关节、影像上可见软骨钙化。其代谢背景与甲状旁腺功能异常、血色病、低镁血症等相关。

**鉴别方向**：发作达峰速度（痛风极快）、部位（第一跖趾 vs 膝）、晶体类型（针状、负双折射 vs 菱形、正双折射）、背景代谢状态。**「晶体是触发器，代谢是背景」**——只处理发作不管理代谢，发作必然复发。

## 51.9 系统性红斑狼疮的关节与多系统表现

**系统性红斑狼疮（SLE）**是自身抗体介导的多系统疾病，其核心机制是**免疫复合物沉积与补体激活**：抗核抗体（尤其抗双链 DNA 与抗 Sm 抗体）与相应抗原形成循环免疫复合物，沉积于肾小球、皮肤、关节、浆膜与血管壁，激活补体、招募中性粒细胞，造成组织损伤；同时存在细胞免疫异常与凋亡细胞清除障碍。

**关节表现**具有鉴别价值：

- 多为对称性多关节痛与关节炎，累及手部小关节与腕、膝；
- **非侵蚀性**——与类风湿关节炎最关键的差异：炎症可反复发生，但软骨与骨破坏不明显；
- 可出现**可复性畸形**（Jaccoud 关节病）：关节囊与韧带松弛导致尺偏、手指畸形，但无骨侵蚀，矫正后可以复位——这是「软组织失衡」而非「结构破坏」的例证；
- 部分患者合并肌腱炎、肌腱断裂。

**多系统表现**：皮肤（光敏、蝶形红斑、盘状红斑、口腔溃疡）、肾（狼疮肾炎，是预后关键）、血液（溶血性贫血、白细胞减少、血小板减少）、浆膜（胸膜炎、心包炎）、神经精神（癫痫、精神症状、认知障碍）、肺（间质性病变、肺动脉高压）、心血管（Libman-Sacks 心内膜炎、加速动脉粥样硬化）。**药物性狼疮**（如某些抗心律失常药、降压药、抗结核药）表现类似但很少累及肾与中枢，停药后可缓解。

**护理含义**：狼疮患者的教育重点是**紫外线防护、感染预防、治疗依从性与妊娠计划**。疾病活动与缓解交替，评估须覆盖多系统而非仅关节；疲乏与认知症状常被低估，却是影响生活质量的主要因素。

## 51.10 无结构损伤的疼痛：中枢敏化与纤维肌痛

临床上有一类患者：广泛疼痛、疲乏、睡眠障碍，但关节无肿胀、影像与实验室无结构或炎症证据。**纤维肌痛（fibromyalgia）**是这一类的代表，其机制不是「心理作用」，而是可测量的**中枢敏化（central sensitization）**：

- **脊髓背角易化增强**：伤害性传入反复激活使背角神经元阈值下降、感受野扩大（「上发条」现象），轻刺激即可引发疼痛；
- **下行抑制减弱**：脑干的下行疼痛调控通路（去甲肾上腺素与 5-羟色胺能）功能下降，疼痛信号失去「刹车」；
- **中枢处理改变**：功能影像显示疼痛矩阵对同等刺激的反应增强，且与预期、注意、情绪相关；
- **睡眠与自主神经**：慢波睡眠减少、交感张力异常，与疼痛形成双向恶化；
- **心理社会因素**：童年逆境、焦虑抑郁、灾难化思维放大疼痛体验，但它们是**调节因素**而非「病因的全部」。

**临床要点**：纤维肌痛可与炎症性关节病、骨关节炎共存——「有明确诊断」不等于「疼痛全部来自该诊断」。评估时应区分**伤害性疼痛**（组织损伤，定位清楚、与负荷相关）与**中枢性疼痛**（广泛、波动、伴随疲乏与睡眠障碍、对常规镇痛反应差）。

这一节与第47章（疼痛）直接相连，也提醒整个单元的读者：骨骼肌肉系统的「功能异常」有时并不在骨、关节或肌肉本身，而在处理疼痛信号的神经系统。

## 51.11 评估维度与护理要点

风湿病的评估必须多维并行，任何单一指标都不足以反映疾病状态：

| 维度 | 评估内容 | 关注方向 |
|---|---|---|
| 症状 | 疼痛性质与分布、晨僵时程、肿胀、活动后变化 | 炎症模式 vs 力学模式 |
| 关节 | 肿胀关节计数、压痛、畸形、活动范围 | 变化方向与对称性 |
| 功能 | 握力、行走、起立、穿衣、进食 | 日常生活活动独立性 |
| 全身 | 疲乏、发热、体重、眼部与呼吸道症状 | 关节外受累 |
| 心理社会 | 情绪、睡眠、疾病认知、经济与照护负担 | 影响依从性与结局 |
| 治疗安全 | 感染征象、血象与肝肾功能方向、骨健康 | 免疫抑制与激素的代价 |

**护理干预的四个支柱**：

1. **炎症控制的支持**：按医嘱给药、观察疗效与不良反应方向（感染、骨髓抑制、肝肾功能、胃肠道）、疫苗接种与感染预防教育；
2. **关节保护与能量节约**：大关节代劳、避免长时间同一姿势、使用辅助器具、把活动分散到一天中并安排休息——目的是把有限的功能储备用在最重要的活动上；
3. **运动与体能**：在炎症控制的前提下进行关节活动度、肌力与有氧训练；炎症活跃期以等长收缩与被动活动为主，缓解期渐进增加负荷；
4. **自我管理与教育**：疾病性质（慢性、波动、需长期管理）、药物依从性、戒烟（对炎症性关节病有直接益处）、体重管理、骨健康（钙、维生素 D、承重运动）、妊娠计划与避孕咨询。

**沟通要点**：风湿病的「不可预测性」本身就是负担来源。帮助患者建立「以功能为目标、以症状为信号」的自我管理框架，比承诺「治好」更有价值。

## 51.12 生命周期考量

**儿童**：幼年特发性关节炎是最常见的儿童风湿病，表现为持续关节肿胀、晨僵、跛行；生长板受累可致肢体不等长或小颌畸形；**慢性葡萄膜炎**可无症状而致盲，须规律眼科筛查；长期激素治疗影响生长与骨量，需监测身高速度与营养状态。儿童的心理与社会适应（就学、同伴关系）是护理的重点之一。

**育龄期**：多数炎症性关节病在妊娠期活动度下降（激素与免疫调节改变），产后复发风险升高；部分药物具致畸性或影响生育，须在孕前规划。狼疮患者妊娠属高危，需多学科管理。**男性痛风与代谢综合征**的生育与心血管风险同样值得关注。

**老年**：多病共存（骨关节炎 + 骨质疏松 + 肌少症 + 心血管病）、多重用药与药物相互作用、跌倒与骨折风险、认知与依从性问题叠加。评估须把「功能」放在「指标」之前——对一位高龄患者，能安全行走与自理，其价值高于某项化验的小幅改善。

**全生命周期的共同点**：风湿病是**慢性、波动、需长期自我管理**的疾病。护理的长期价值不在单次干预，而在帮助患者建立可持续的管理模式。

## 本章小结（Key Points）

- 风湿性疾病可按「炎症主导」与「力学-代谢主导」两种范式归类，第一判断决定后续全部逻辑；
- 自身免疫的起点是遗传易感（HLA）叠加环境触发（吸烟致瓜氨酸化、分子模拟、表位扩展），自身抗体是标志而非判决；
- 滑膜炎的核心是衬里增生、新生血管、炎性浸润与介质网络，滑膜成纤维细胞获得侵袭性表型；
- 损伤链为「滑膜炎 → 血管翳 → 软骨降解 → 骨侵蚀 → 间隙狭窄 → 软组织失衡 → 畸形」，前段可逆、后段不可逆，故有治疗窗口；
- 脊柱关节病以附着点为原发部位，表现为「破坏 + 反应性骨形成」并存，与类风湿的纯破坏模式相反；
- 骨关节炎是主动重塑失衡而非被动磨损，骨赘是力学代偿标记，疼痛来源多元；晶体性关节病的逻辑则是「代谢背景 + 晶体触发 + 炎症体放大」，痛风发作具自限性；
- 狼疮关节表现非侵蚀、可复性畸形；纤维肌痛的本质是中枢敏化，与炎症性关节病可共存。

## 单元临床案例（HPP-U14-CASE-01）

**病例 A（参数均示意）**：李先生，68 岁，独居，吸烟多年，日常活动以室内为主。雨天在浴室滑倒，右髋部着地，当即剧痛不能站立。急诊影像示右股骨颈骨折，行手术治疗。术后早期因疼痛不愿翻身与活动，卧床时间较长；第 3 天出现右小腿肿胀、压痛，被动牵拉踝部时疼痛明显加重，肢端感觉较对侧迟钝。既往有高血压，长期服用降压药。

**病例 B（参数均示意）**：张女士，46 岁，双手近端指间关节与腕关节对称性肿痛半年，晨起僵硬明显、活动后减轻，伴疲乏与食欲下降。查体见掌指关节与腕关节肿胀压痛，握力下降，无骨性膨大。实验室提示炎症性改变，类风湿因子与抗瓜氨酸化蛋白抗体阳性。

**问题**：

1. 李先生骨折后长期卧床，其骨、肌肉与关节将发生哪些方向性改变？为什么这些改变在老年患者身上后果更重？
2. 李先生第 3 天出现的小腿表现应首先考虑什么？其机制是什么？为什么不能等待「脉搏消失」再处理？
3. 张女士的关节表现属于哪一类机制范式？请用「滑膜炎—血管翳—骨侵蚀—畸形」的链条解释其症状与体征，并指出最关键的干预时点。
4. 张女士若同时诉说全身多处疼痛与睡眠障碍，护理评估应如何区分炎症性疼痛与其他类型的疼痛？

**要点参考**：

1. 骨：力学信号减少使硬化素升高、成骨信号减弱，形成下降而吸收上升，承重部位松质骨丢失最著；肌肉：蛋白合成下降、降解增强，抗重力肌萎缩，且肌力下降早于肌量下降（神经因素）；关节：缺乏周期性负荷致滑液扩散营养减少、蛋白聚糖合成下降，软骨软化，关节囊胶原重塑致挛缩。老年患者峰值骨量低、肌量已减少、修复能力下降，数周制动即可造成功能阶梯式下降且难以完全恢复，故「卧床」本身即治疗风险。
2. 首先考虑骨筋膜室综合征（并需评估深静脉血栓）。机制为室内压力升高→静脉回流受阻→渗出与水肿加重→压力更高→毛细血管灌注不足→肌肉神经缺血→细胞水肿→压力再升的恶性循环。脉搏消失属晚期征象，此时常已发生不可逆肌坏死与缺血性肌挛缩，故判断依据应是「疼痛与损伤程度不相称、被动牵拉痛、感觉异常、肢体张力增高」。
3. 属炎症主导型（自身免疫性炎症性关节病，符合类风湿关节炎的方向）。滑膜衬里增生与炎性浸润产生肿胀与晨僵；血管翳侵入软骨，MMP 与 ADAMTS 降解基质；RANKL 驱动破骨细胞在关节边缘形成侵蚀；关节囊韧带松弛与肌腱失衡最终导致畸形。关键干预时点在滑膜炎阶段——软骨降解部分可逆，骨侵蚀与畸形不可逆，因此早期控制炎症是唯一能改变远期结构结局的策略。
4. 炎症性疼痛多与关节肿胀、晨僵、活动后改善相关，定位明确、与疾病活动度同步；力学性疼痛与负荷相关、休息缓解；中枢性疼痛广泛、波动、伴疲乏与睡眠障碍、对常规镇痛反应差，且可与炎症性疾病共存。评估应记录疼痛性质、分布、时间模式、对活动的反应，并结合肿胀体征、睡眠、情绪与功能状态综合判断，避免把全部疼痛归因于单一诊断。
