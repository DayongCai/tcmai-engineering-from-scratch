## 为什么单独立一层，而不当底本

课程现在的**底本**是代用底本《疾病学基础》（见 `standards/binglishengli/README.md`）。讲义是另一套体系：

| | 代用底本《疾病学基础》 | 讲义（本层） |
|---|---|---|
| 章目 | 18 章（病理学 + 病理生理学合并） | 15 单元 53 章（按 Banasik *Pathophysiology* 8th ed. 目录结构） |
| 已写内容 | 全本 360,945 字 | **15 单元 53 章全写完**：599 节 / 214,666 字正文（2026-10-30；扩写后每章 ≥3,300 汉字） |
| 性质 | 外部教材工作簿 | **本仓库原创简体中文讲义**，非译本、非扫描件 |

两套章目对不上，所以分层：

- **底本**继续管「教材级」引文：`教材·疾病学基础·第N章·N.M.K`。
- **本层**管「补充级」引文：`补充·hermes-病理生理学讲义·第N章·N.M`，**不得标「教材」**。

## 补的是什么

代用底本缺三样东西，讲义第 2 章正好有：

1. **异稳态（allostasis）与异稳态负荷（allostatic load）**——「稳态靠调定点维持」之外的另一套调节观：靠改变调定点来适应，代价是长期负荷。
2. **全身适应综合征（GAS）三期**——警戒期 / 抵抗期 / 衰竭期，是应激章的结构骨架。
3. **心理神经免疫（PNI）与生命周期考量**——把应激接到免疫与年龄阶段上。

第 1 章另有代用底本没有的四条规律链条、症状/体征/并发症/后遗症的区分、研究方法，用于加深课程第 1、2 章。

## 门（第 15 项）

`tests/test_binglishengli_chapters.js` 第 15 项核四件事：

1. 标了 `补充·hermes-病理生理学讲义·第N章·N.M` 的行，该章该节必须真的存在于 `jiangyi.json`；
2. 同一行里的「」引语必须能在**该节**正文里逐字找到（去空白与标点后比对）；
3. 不许出现 `教材·hermes` 或 `教材·…讲义` 这类把补充层当教材的写法；
4. 至少 3 章（第 1、2、7 章）真的引用了补充层——写了层却没人用，等于没建。

## 边界

- 讲义是**原创讲义**，不是 Elsevier 教材的译文；引用它不等于引用 Banasik 原文。
- 讲义只覆盖第 1–2 章；其余 51 章仍是「待写」（见 `知识树.md` §5 路线图），本层不假装覆盖。
- 不把讲义内容回抄进底本《疾病学基础》：底本一个字不改。
