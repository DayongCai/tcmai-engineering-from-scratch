# Skill：肾功能不全——经过、功能与判定三层

## 何时用

- 有人（包括你自己）用「急性肾衰」「慢性肾衰」把一段描述糊过去了，需要拆开
- 要判断一句话越了层：把经过类别（急与慢）当成轻重，或把类别名当成个体结论
- 要把功能变化按组成摊开：滤过、重吸收、分泌、内分泌，各写各的依据
- 遇到「肾功能几期、指标多少」这类追问，需要一套一致的拒答口径

## 核心判据（四问）

1. **哪一层？** 经过（时间上怎么展开）、功能（哪一类功能在变）、判定（谁有权下结论）。三层不许互相代替。
2. **急还是慢，是什么关系？** 独立、转化、叠加——区别在是否保留原有类别特征。
3. **哪一类功能？** 滤过、重吸收、分泌、内分泌；再分方向（增强、减弱、紊乱）与时点（即时、持续）。
4. **四维度齐不齐？** 结构、功能、经过、关系；哪一维缺材料，就写缺项，不用推测填补。

## 执行步骤

```text
1. 抄材料，不抄病名：写「起病隐匿、夜尿增多」，不写「慢性肾衰」
2. 定经过：急性经过类 / 慢性经过类（只写时间展开方式，不写轻重）
3. 看储备：短期内改变，还是逐步减少
4. 定关系：独立 / 转化 / 叠加（叠加＝两类并存，各自保留）
5. 摊功能：滤过、重吸收、分泌、内分泌，逐类标「有依据 / 未定」
6. 定方向与时点：增强 / 减弱 / 紊乱；即时 / 持续
7. 写蓄积：酸性 / 碱性倾向；电解质单一 / 并存（并存逐项列）
8. 写全身影响：消化、循环、血液与矿物质、神经四组，按双向关系写两句
9. 四维度自查：缺项写明，不以推测填补
10. 划边界：类别描述 / 判断主体 / 信息与资料三层，判断交回具备资质的人员
```

## 硬约束

- **不给数值、单位、参考值、分期、分级、分度。** 肾功能分期只写类别名称，不写期别与刻度；需要数值时统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不判正常与异常。** 类别能说明「落在哪一层哪一类」，不能说明「这个人现在是否异常」。
- **急与慢不作轻重。** 名称不表示轻重顺序，也不表示优劣顺序。
- **引文逐字。** 标「教材·疾病学基础·第N章·N.M.K」，核不到就不引。
- **用药只写类别。** 不写名称、剂量与疗程；检查只写项目类别。

## 交付物

1. 一条经过结论：急性 / 慢性 + 时间线索依据
2. 一条储备判断：短期改变 / 逐步减少
3. 一条关系结论：独立 / 转化 / 叠加
4. 一张功能表：四类功能 × 方向 × 时点，缺材料的标「未定」
5. 一条蓄积与全身：酸性或碱性倾向 + 四组影响的类别
6. 一句四维度自查：哪一维缺项
7. 一句边界：本章不给值，判断交回具备资质的人员

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 急慢当轻重 | 「慢性的更重」 | 改为经过类别 |
| 叠加写成转化 | 「慢性转急性」 | 看是否保留原有类别特征 |
| 功能只写滤过 | 描述不完整 | 摊开四类，缺项标「未定」 |
| 蓄积写成单向链 | 系统性被写成被动 | 补反向一句，写成双向 |
| 只答分期 | 「肾功能几期」 | 改为类别描述，分期交数据层 |
| 拿类别当结论 | 「就是慢性肾衰」 | 写明类别名不回答个体情形 |

## 边界

本 Skill 只处理「材料 → 经过与功能类别」的结构化表达，不涉及数值、判定与临床决策。任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。本 Skill 不写数值，不构成诊断或用药依据。
