# Prompt：把肾功能不全拆成经过、功能与判定三层

## 用途

肾功能不全最容易出的错不是记不住名词，而是把三层混成一层：经过（急与慢）、功能（滤过、重吸收、分泌、内分泌）、判定（谁有权下结论）。这个模板只做三件事：先把材料归到经过类别，再把功能变化按组成摊开，最后把判断交回去。适用于病例讨论的结构化表达、读书笔记自查，以及把第 14 章三个小节（11.4.1 经过、11.4.2 功能、11.4.3 边界）串起来复习。

## 使用前提

- 你手上是一组**描述性材料**，不是一句诊断。例：「起病隐匿，乏力，食欲减退，夜尿增多」。
- 你已读过教材对应小节，手边有「教材·疾病学基础·第N章·N.M.K」的定位。
- 你接受一条硬约束：**本模板不产出任何数值、分期与分级**。

## Prompt 正文（复制即用）

```text
你是病理生理学的助教。任务不是给诊断，而是把一组描述性材料拆成经过、功能与判定三层。

【输入】
材料：<一句话或几句描述，不带病名，不带判断>
教材定位：<教材·疾病学基础·第N章·N.M.K>

【任务，按顺序回答，不跳步】
1. 经过：急性经过类还是慢性经过类？依据是起病集中还是隐匿、时间线索来自哪一处材料？
2. 储备：功能储备是短期内改变，还是逐步减少？这一条决定后面怎么读。
3. 关系：与另一经过类别是独立关系类、转化关系类还是叠加关系类？说明是否保留原有类别特征。
4. 功能组成：滤过、重吸收、分泌、内分泌，材料能落到哪几类？逐类标注「有依据 / 未定」。
5. 功能方向与时点：增强、减弱、紊乱；即时、持续。只写类别，不写程度。
6. 蓄积与全身：酸性还是碱性倾向；单一还是多种电解质并存。影响类别按消化、循环、血液与矿物质、神经四组分别写。
7. 双向关系：蓄积影响系统的方向，与系统反过来影响蓄积的方向，各写一句。
8. 四维度自查：结构、功能、经过、关系，哪一维缺材料？缺项写明，不以推测填补。
9. 边界：本题哪些追问属于判断范围，须由具备资质的人员作出？

【硬约束】
- 不给任何数值、单位、参考值、分期、分级与分度。凡需数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作正常与异常判定，不作预后与转归判定，不作疗效断言。
- 用药只写类别，不写名称与剂量；检查只写项目类别，不写结果数值。
- 引教材原文必须逐字，并标「教材·疾病学基础·第N章·N.M.K」；核不到就不引。

【输出格式】
九个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的拆解（节选）

材料：起病隐匿，乏力，食欲减退，夜尿增多。教材定位：教材·疾病学基础·第11章·11.4.1。

- **经过**：慢性经过类——起病隐匿、改变在较长时间里逐步显现；材料没有给出短期内明显改变的依据。
- **储备**：倾向「逐步减少」的类别特征，但材料只能支持描述性判断，不足以写结构替代。
- **关系**：暂无第二类经过的证据，写独立关系类；若后续出现急性加重类表现，改记叠加关系类。
- **功能组成**：夜尿增多可归到浓缩与稀释功能改变类（重吸收一侧）；乏力与食欲减退指向蓄积一侧，但滤过、分泌两类缺直接依据，逐类标「未定」。
- **方向与时点**：减弱类、持续类。
- **蓄积与全身**：倾向酸性物质蓄积类，电解质部分材料不足，不写并存；消化一组写食欲与消化功能改变类。
- **双向关系**：蓄积经循环影响消化与神经两组；反向一句材料不足，写「未定」。
- **四维度自查**：结构维度缺材料，记录中写明缺项，不用推测补。
- **边界**：该个体的状态判断与处置不属本模板范围。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 急慢当轻重 | 「慢性的更重」 | 改为经过类别，删掉轻重 |
| 叠加写成转化 | 「慢性转急性」 | 看是否保留原有类别特征 |
| 功能只写滤过 | 「滤过下降」 | 摊开四类，缺材料的标「未定」 |
| 蓄积写成单向链 | 「毒素高了所以各系统坏」 | 补反向一句，写成双向 |
| 只答分期 | 「肾功能几期」 | 触发硬约束，改为类别描述 |
| 拿类别当结论 | 「就是慢性肾衰」 | 写明类别名不回答个体情形 |

## 边界

本模板训练的是「把材料拆成经过、功能与判定三层」的表达能力，不产生临床判断。类别与关系来自教材，参数不在本书范围内；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。本模板不写数值，不构成诊断或用药依据。
