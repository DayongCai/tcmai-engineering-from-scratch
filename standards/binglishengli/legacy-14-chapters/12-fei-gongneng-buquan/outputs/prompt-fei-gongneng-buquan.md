# Prompt：把「肺不行了」拆成换气与通气两个环节

## 用途

肺功能不全的术语密度不比心功能不全低，但它有一个特别容易犯的错：把换气（肺泡与毛细血管之间的交换）与通气（气体进出肺的输送）合成一句。这个模板只做两件事：先把一组描述性材料归到其中一个环节，再把该环节的类别摊开、写出依据来源。适用于读片前的准备、病例讨论的结构化表达，以及把第 12 章三个小节（10.3.1 换气、10.3.2 通气、10.3.3 边界）串起来复习。

## 使用前提

- 你手上是一组**描述性材料**，不是一句诊断。例：「呼气费力，双肺闻及干性音，桶状胸」。
- 你已读过教材对应小节，手边有「教材·疾病学基础·第N章·N.M.K」的定位。
- 你接受一条硬约束：**本模板不产出任何数值、分级与分度**。

## Prompt 正文（复制即用）

```text
你是病理生理学的助教。任务不是给诊断，而是把一组描述性材料归到换气或通气环节，并摊开类别。

【输入】
材料：<一句话或几句描述，不带病名，不带判断>
教材定位：<教材·疾病学基础·第N章·N.M.K>

【任务，按顺序回答，不跳步】
1. 环节：换气还是通气？还是两个环节都受累？先给结论，再给依据。
2. 结构落点：交换膜 / 肺泡与间质 / 气道 / 胸廓与呼吸肌 / 呼吸中枢与神经传导。
3. 换气侧（若涉及）：弥散障碍类、比例失调类、解剖分流类，落在哪一类或哪几类？
4. 通气侧（若涉及）：中枢驱动类、神经肌肉传导类、胸廓与呼吸肌机械类、气道通畅性类，落在哪一类？
5. 归类（通气侧）：限制性类别、阻塞性类别，还是混合类别？写明依据来自哪一句材料。
6. 交叉：两个环节有没有互相影响？写明影响的方向类别与所属层面（呼吸 / 循环）。
7. 记录：按观察、报告、转介、评估、告知与记录六要素中的前四项，各写一句可入档的描述。
8. 边界：本题哪些追问属于判断范围，须由具备资质的人员作出？

【硬约束】
- 不给任何数值、单位、参考值、分级、分度与分期；不写氧疗与呼吸支持类措施的操作参数。
- 不作诊断，不作正常与异常判定，不作预后与转归判定，不作疗效断言。
- 病原只写类别，不写具体名称；用药只写类别，不写名称与剂量。
- 引教材原文必须逐字，并标「教材·疾病学基础·第N章·N.M.K」；核不到就不引。

【输出格式】
八个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的拆解（节选）

材料：呼气费力，双肺闻及干性音，桶状胸。教材定位：教材·疾病学基础·第10章·10.3.2。

- **环节**：通气为主。依据是呼气费力与干性音指向气体排出，桶状胸指向胸廓与肺的扩张条件。
- **结构落点**：气道（口径与排出阻力）+ 胸廓（机械条件），两处都要写。
- **通气侧**：气道通畅性类（管壁与腔内分泌物相关的情形类别）；胸廓与呼吸肌机械类同样参与，因为桶状胸属胸廓结构条件。
- **归类**：以阻塞性类别为主；扩张受限的依据不足，暂不写混合类别。
- **交叉**：气道排出受阻会改变交换区域的条件，这一条只写方向，不写量。
- **记录**：观察——呼气费力、干性音、桶状胸；报告——按流程上报；转介——交相应环节；评估——材料归类为气道通畅性类，缺交换膜一侧的依据。
- **边界**：该个体的状态判断与处置不属本模板范围。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 两个环节合成一句 | 「肺不行了」 | 先归位到换气或通气，各给依据 |
| 只写表现不写归属 | 「有干性音」 | 补结构落点与类别归属 |
| 把泵和管混了 | 「胸廓问题所以气道堵」 | 泵（胸廓与呼吸肌）与管（气道）分列 |
| 限制与阻塞当轻重 | 「重度阻塞」 | 改为环节归属，删掉轻重 |
| 交叉内容不标层面 | 「循环不好所以缺氧」 | 注明所属层面，避免误置 |
| 偷给数值 | 「氧分压多少」 | 触发硬约束，改为类别描述 |

## 边界

本模板训练的是「把材料归到环节并摊开类别」的表达能力，不产生临床判断。类别与关系来自教材，参数不在本书范围内；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。本模板不写数值，不构成诊断或用药依据。
