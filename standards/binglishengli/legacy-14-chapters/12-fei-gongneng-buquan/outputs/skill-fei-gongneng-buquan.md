# Skill：肺功能不全——换气、通气与两个环节的接缝

## 何时用

- 有人（包括你自己）用「肺不行了」「呼吸衰竭」把一段描述糊过去了，需要拆开
- 要在换气三类（弥散、比例失调、解剖分流）与通气四类（驱动、传导、执行、气道通畅性）之间迁移同一套语言
- 要把限制性、阻塞性与混合类别这三组归类用对，而不是当成严重程度
- 遇到「氧分压多少、几度呼吸衰竭」这类追问，需要一套一致的拒答口径

## 核心判据（四问）

1. **哪一环节？** 换气（肺泡与毛细血管之间的交换）还是通气（气体进出肺的输送）。两套依据不能混。
2. **哪一结构落点？** 交换膜、肺泡与间质、气道、胸廓与呼吸肌、呼吸中枢与神经传导——落点错了，类别一定错。
3. **归入哪一类？** 换气看弥散、比例与分流；通气看驱动、传导、执行与通畅性；通气侧再分限制性、阻塞性、混合。
4. **依据来自哪里？** 每一句类别归属都要能指回一句描述性材料；材料不足就写「未定」，不抢先归位。

## 执行步骤

```text
1. 抄材料，不抄病名：写「呼气费力、干性音」，不写「慢阻肺」
2. 归环节：换气 / 通气 / 两者并存
3. 定落点：交换膜、间质、气道、胸廓与呼吸肌、中枢与传导
4. 摊类别：换气三类、通气四类，逐条对照，缺依据的写「未定」
5. 归类（通气侧）：限制性 / 阻塞性 / 混合，只写环节归属，不作轻重比较
6. 看交叉：两个环节有没有互相影响；涉肺循环时注明所属层面
7. 走六要素：观察 → 报告 → 转介 → 评估（→ 告知 → 记录），记录留痕
8. 划边界：凡属个体判断的追问，一律交回具备资质的人员
```

## 硬约束

- **不给数值、单位、参考值、分级、分度、分期。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不判正常与异常。** 类别能说明「落在哪一环节」，不能说明「这个人现在是否异常」。
- **引文逐字。** 标「教材·疾病学基础·第N章·N.M.K」，核不到就不引。
- **操作只写类别。** 不写呼吸支持类措施的操作参数、调节要求与器械型号。
- **泵与管分列。** 胸廓与呼吸肌是泵，气道是管；两者在表现上可以相似，结构落点不同，不能互换。

## 交付物

1. 一条环节结论：换气 / 通气 / 并存 + 依据
2. 一条结构落点：交换膜 · 间质 · 气道 · 胸廓与呼吸肌 · 中枢与传导
3. 一张类别表：换气三类或通气四类，逐条标注「有依据 / 未定」
4. 一条归类：限制性 / 阻塞性 / 混合（只写环节归属）
5. 一句交叉方向：哪个环节影响哪个环节，属哪一层
6. 一句边界：本章不给值，判断交回具备资质的人员

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 两环节合成一句 | 依据无法核对 | 先归位，再摊类别 |
| 泵管混答 | 「胸廓问题所以气道堵」 | 泵与管分列，各给落点 |
| 限制与阻塞当轻重 | 「重度阻塞」 | 改为环节归属 |
| 用表现代替归属 | 「有干性音」 | 补结构落点与类别 |
| 交叉内容不标层面 | 把循环问题写成呼吸问题 | 注明所属层面 |
| 只答分级 | 「呼吸衰竭几度」 | 改为类别描述，分级交数据层 |

## 边界

本 Skill 只处理「材料 → 环节与类别」的结构化表达，不涉及数值、判定与临床决策。任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。本 Skill 不写数值，不构成诊断或用药依据。
