# Prompt：把「酸碱失衡」拆成起因端与代偿端

## 用途

酸碱这一段最容易糊过去的一句话是「这是酸中毒」。这个模板把这句话逼到两条轴上：起因端定方向，代偿端定表现。四个基本类别只是起因端的四个位置，真正决定「看起来像什么」的是代偿环节走到了哪一步。适用于病例讨论前的机制梳理、读记录时把程度词换成方向词、以及回答「到底代偿够不够」这类追问。

## 使用前提

- 你手上是**一组类别化的描述**，不是一个判断。例：「通气功能受限一段时间后出现嗜睡」「反复呕吐后乏力」。
- 你已经读过对应小节，手边有「教材·疾病学基础·第5章·5.3.1」这一级的定位。
- 你接受一条硬约束：**本模板不产出任何数值**，也不给出代偿幅度的量化。

## Prompt 正文（复制即用）

```text
你是病理生理学的助教。任务不是给这组情形下结论，而是把它拆到起因端与代偿端两条轴上。

【输入】
情形：<一句话描述可观察的类别信息：通气、丢失途径、意识或肌力等，不带诊断与程度>
教材定位：<教材·疾病学基础·第5章·N.M.K>

【任务，按顺序回答，不跳步】
1. 定端：偏移落在酸的生成、酸的排出、碱的生成、碱的排出这四条通路中的哪一条或哪几条？
2. 定方向：由端推方向（偏酸或偏碱），只写方向，不写程度。
3. 归类别：把方向与端合成一个基本类别（代谢性 / 呼吸性 × 酸 / 碱），可并列，不可强行归一。
4. 找伴随：若涉及代谢性酸中毒，说明伴随离子的差异属于哪一类（间隙增宽 / 间隙相对正常），只作类别名使用。
5. 看代偿：三级调节中哪一层先应答、哪一层是末端？给出先后，不给幅度。
6. 判病程：同一方向在急性与慢性下由谁承担代偿？两类的差别来自时间尺度，不来自轻重。
7. 功能方向：只写兴奋性或节律朝哪个方向变，分神经肌肉与循环两面，不写程度。
8. 边界：这组信息不能推出什么？说清「描述」与「判断」的分界。

【硬约束】
- 不给任何数值、单位、参考值与参考范围；不给分级、分期与分度；不给代偿幅度的量化。
- 不作正常与异常的判定，不作诊断，不作病情与预后判定，不作疗效断言。
- 引教材原文必须逐字，并标「教材·疾病学基础·第5章·N.M.K」；核不到就不引。
- 信息不足以定端时，直接说缺哪一条（通气 / 丢失途径 / 代偿线索），不要猜。

【输出格式】
八个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不作诊断与判定，不构成诊断/治疗/用药依据。」
```

## 示例：一次合格的拆解（节选）

情形：通气功能受限持续一段时间后出现嗜睡。教材定位：教材·疾病学基础·第5章·5.3.2。

- **定端**：酸的排出减少——落在通气环节。
- **定方向**：偏酸。
- **归类别**：呼吸性酸中毒（起因端在通气，不在代谢）。
- **找伴随**：不涉间隙类别，此处不写。
- **看代偿**：缓冲与细胞内外交换先行，肾环节随后展开，是末端。
- **判病程**：持续一段时间后肾环节的调节逐渐展开，故按慢性一类理解；差别在时间尺度，不在轻重。
- **功能方向**：可兴奋组织的电活动朝抑制方向变，写方向不写程度。
- **边界**：只说明类别与环节的组合，不说明严重程度，也不构成诊断。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 用诊断代替情形 | 「这是呼酸」 | 先写端与方向，再给类别名 |
| 两条轴并成一条 | 「酸中毒就是代偿不够」 | 起因写一栏、代偿写一栏，分开写 |
| 把间隙当判据 | 「间隙大了就是某类」 | 只作类别名，不给界线 |
| 用程度代替方向 | 「酸中毒很重」 | 只写方向与缓和与否 |
| 偷给数值 | 「分压多少」 | 触发硬约束，改为方向语汇 |

## 边界

本模板训练的是「把情形拆到两条轴上」的表达能力，不产生临床判断。类别与环节的对应来自教材，浓度、分压、间隙大小等参数不在本书范围内；任何涉及个体的评估须由具备资质的人员依现行规范作出。
