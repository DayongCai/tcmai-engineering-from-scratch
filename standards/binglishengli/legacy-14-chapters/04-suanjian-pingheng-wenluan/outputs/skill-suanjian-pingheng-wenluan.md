# Skill：酸碱平衡紊乱——起因定方向，代偿定表现

## 何时用

- 有人（包括你自己）用「这是酸中毒」把一段观察糊过去了，需要拆开
- 要回答「代偿够不够」，却只有方向、没有幅度可用
- 要在代谢性与呼吸性之间归类，且两类同时在场、说不清以谁为主
- 要把记录里的程度词（明显、较重、轻度）换成方向词
- 需要一套一致的拒答口径来应对「间隙多大 / 分压多少」的追问

## 核心判据（四问）

1. **哪一端？** 酸的生成、酸的排出、碱的生成、碱的排出，四条通路里偏移落在哪一条。答成「酸碱失衡」，说明端还没定。
2. **哪个方向？** 由端推方向。只写方向，不写程度；同一方向可以有多个来源。
3. **哪一类？** 代谢端还是呼吸端。两类可以并存；并存时写清以谁为主，不许强行归一。
4. **代偿到哪一步？** 三级调节里谁先应答、谁是末端。快的一层先应答，慢的一层决定能否收住——这是「代偿够不够」在本章唯一可写的内容。

## 执行步骤

```text
1. 抄情形，不抄诊断：写「通气受限持续一段时间后嗜睡」，不写「呼酸」
2. 定端：四条通路中逐条判断是否偏移
3. 定方向：偏酸或偏碱，只写方向
4. 归类别：代谢性 / 呼吸性 × 酸 / 碱，可并列
5. 找伴随：涉及代谢性酸中毒时，写出间隙增宽或间隙相对正常（类别名，非数值）
6. 看代偿：缓冲 → 呼吸 → 肾，写先后与末端，不写幅度
7. 判病程：急性与慢性由谁承担代偿，差别在时间尺度不在轻重
8. 功能方向：兴奋性或节律朝哪个方向变，分神经肌肉与循环两面
9. 反查：抽掉代偿这一栏，结论会怎样变（给可观察差别，不给数值）
```

## 硬约束

- **不给数值、单位、参考值、参考范围、分级分期分度。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **只写方向。** 「升高」「降低」「代偿」「失代偿」是本书唯一允许的表述层次。
- **间隙是类别名。** 增宽与相对正常是两个方向，不是两个数值区间。
- **代偿充分不是没问题。** 它是「能否把方向性偏移控制在可调范围之内」的定性说法，教材不给界线。
- **不判正常与异常，不作诊断与预后判定。** 描述属认识层面，判断属专业层面。
- **引文逐字。** 标「教材·疾病学基础·第5章·N.M.K」，核不到就不引。

## 交付物

1. 一张端与方向的对照：四条通路逐条判断
2. 一个基本类别（可并列），并写明以谁为主
3. 一条代偿说明：谁先应答、谁是末端
4. 一条病程说明：急性与慢性的调节承担者不同
5. 一处边界：本章不给值，间隙与分压须另立数据层

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 用诊断代替情形 | 拆解无从下手 | 先写端与方向 |
| 两条轴并成一条 | 「酸中毒就是代偿不够」 | 起因写一栏、代偿写一栏 |
| 把间隙当判据 | 越出本书口径 | 只作类别名使用 |
| 用程度代替方向 | 「酸中毒很重」 | 只写方向与缓和与否 |
| 用代偿解释类别 | 四类混成两类 | 类别归起因轴，表现归代偿轴 |
| 被追问就报数值 | 越出本书口径，且数值无来源 | 统一回「本书不给值，另立数据层」 |

## 与相邻章节的接缝

- 课程第 3 章（水、电解质代谢紊乱）：钾的跨膜转移与酸碱状态互相牵连，两章共用「一条环节改动会带动另一条」的读法。
- 课程第 12 章（肺功能不全）：通气环节的类别是两章共同的语言，呼吸性紊乱的起因端落在那里。
- 课程第 14 章（肾功能不全）：肾环节是三级调节的末端，也是排酸与保碱的共同通道。

## 边界

本 Skill 只处理「情形 → 端 → 方向 → 代偿」的结构化表达，不涉及数值、判定与临床决策。任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
