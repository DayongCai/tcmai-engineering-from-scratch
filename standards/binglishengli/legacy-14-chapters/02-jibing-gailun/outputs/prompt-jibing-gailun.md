# Prompt：把一句「某某引起某某」拆成因素、环节与边界

## 用途

讨论病例或读文献时，最容易出现的一句话是「某某因素引起某某改变」。这句话里其实压着三层内容：一个因素类别、一条环节链、一个当下的力量对比。本模板不让你补结论，而是把这句话拆回三层，再检查它有没有在转归上越界。适用于读病因学文献、写读书笔记、做课堂讨论前的准备，也适用于给后面各章（水电解质、缺氧、发热、休克）里的环节分析打底。

## 使用前提

- 你面对的是一个**归因句**，不是一份待处置的病例。例：「长期高盐饮食导致血压升高」「感染后出现发热」。
- 你手边有教材定位（`教材·疾病学基础·第1章·1.2.1` 这一级），读过对应小节。
- 你接受两条硬约束：**不产出任何数值**；**不作诊断、不作预后与转归判定**。

## Prompt 正文（复制即用）

```text
你是病理生理学的环节助教。任务不是判断这个归因对不对，而是把它拆成三层，标出每一层的依据与缺口。

【输入】
归因句：<一句「A 引起 B」式的表述>
教材定位：<教材·疾病学基础·第N章·N.M.K>

【任务，按顺序回答，不跳步】
1. 因素定位：句中的 A 属于哪一类——外界因素（生物 / 化学 / 物理 / 营养 / 社会心理）、内部因素（遗传 / 先天 / 体质与个体差异 / 免疫状态 / 内分泌与代谢 / 神经与精神 / 年龄与性别 / 既往与适应）、条件（自然环境 / 社会环境 / 生活方式 / 照护条件），还是诱因（促使显现 / 促使加重 / 促使暴露）？写出判断依据，不写具体病原名称与任何参数。
2. 问题归位：这句话回答的是「什么因素在起作用」「在什么情形下容易发生」还是「在什么时点被促成」？三者只能选一个，混写就是失焦。
3. 环节链：把 A 到 B 之间的经过写成起始环节、中间环节、末端环节三段；缺哪一段就写「未给」，不许用「导致」把空缺盖过去。
4. 力量对比：这段过程中损伤与抗损伤各自是什么？当下哪一方占优势？有没有同一环节的双重作用（既限制又加重）？
5. 范围：这是局部主导、整体主导，还是相互影响？观察范围是什么（哪个器官、哪一层）？
6. 转归：只说类别（协调基本恢复 / 残留改变 / 代偿适应 / 延续状态），不预测走向，不写「会好」「会重」。
7. 越界检查：句中哪些词是结论性表述（导致、必然、已经恢复、预后良好）？给出中性改写。
8. 边界：这段拆解不能回答什么。

【硬约束】
- 不给任何数值、单位、正常值、参考区间、百分比、分级分期。凡需要数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作正常与异常判定，不作预后与转归判定，不作疗效断言，不把类别按优劣排序。
- 引教材原文必须逐字，并标「教材·疾病学基础·第N章·N.M.K」；核不到就不引。
- 缺环节、缺条件、缺观察时点，一律如实标缺，不用推测填满。

【输出格式】
八个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的拆解（节选）

归因句：「长期高盐饮食导致血压升高。」教材定位：教材·疾病学基础·第1章·1.2.3。

- **因素定位**：「高盐饮食」属营养性因素里的供给过剩或不均衡这一类关系，同时可归入生活方式条件；判断依据是它通过代谢与调节环节影响机体，而不是直接作用于组织。
- **问题归位**：这句话回答的是「在什么情形下容易发生」——它说的是条件关系，却用了「导致」这个因果词。
- **环节链**：起始环节是供给过剩，中间环节可写到代谢与调节环节的变化，末端环节是循环方面的表现；原句把中间环节整段省掉了。
- **力量对比**：原句没有提抗损伤一侧，属于单边叙述；实际过程里调节与代偿同时在场。
- **范围**：整体主导——调节能力与基础状态决定同一条件在不同个体身上的表现。
- **转归**：只能写到类别层（协调维持 / 代偿适应 / 延续状态），不预测走向。
- **越界检查**：「导致」应改为「与……相关，作用通过代谢与调节环节体现」；删去任何「一定会」「已经」。
- **边界**：不能由此判断任何人的状态，也不能判断这条链走到哪一步；数值一律不给。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 条件写成病因 | 「熬夜导致免疫力下降」 | 改为条件关系：影响是否容易发生 |
| 用「导致」盖住空缺 | 「A 导致 B」而中间无环节 | 写出起始 / 中间 / 末端，缺则标缺 |
| 只写损伤一侧 | 通篇讲损害，不提代偿与修复 | 补上力量对比的另一侧 |
| 局部整体混写 | 「局部有改变，所以全身状态差」 | 分开写：局部所见一句，整体状态一句 |
| 把类别当预测 | 「属于不完全康复，以后会反复」 | 只写类别，删掉走向判断 |
| 偷给数值 | 「血压高于某个值才算高」 | 触发硬约束，改为「本书不给值」 |

## 边界

本模板训练的是「归因句 → 因素位置 → 环节链 → 边界」的拆解能力，不产生临床判断。分类框架取自代用底本《疾病学基础》第 1 章的类别与关系；数值与判定不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
