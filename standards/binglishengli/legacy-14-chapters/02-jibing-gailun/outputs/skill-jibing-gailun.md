# Skill：疾病概论——三层位置、三组规律与转归边界

## 何时用

- 有人用「某某导致某某」把一段过程说完了，需要拆出中间环节
- 要判断一句话说的是病因、条件还是诱因；三者混用会让讨论失去层次
- 要在「局部」与「整体」之间迁移同一套语言，先确认观察范围
- 要谈转归又不想越界：只到类别为止，不写走向
- 遇到「到什么程度算重」「会不会好」这类追问，需要一套一致的拒答口径

## 核心判据（四问）

1. **这是三个位置里的哪一个？** 病因（直接作用）／条件（影响是否容易发生）／诱因（影响是否在此刻发生）。三者回答的问题不同，方向也不一样。
2. **力量对比如何？** 损伤与抗损伤同时在场，走向取决于哪一方在当下占优势；同一环节常常双重作用，别只写一侧。
3. **环节在哪一段？** 起始、中间、末端。三个位置缺一个，链条就断；时间先后不等于环节先后。
4. **范围是什么？** 局部主导、整体主导，还是相互影响？观察范围一变，同一个词指的就不是同一件事。

## 执行步骤

```text
1. 抄原话，不改写：把归因句原样放在第一行
2. 定位置：病因 / 条件 / 诱因，选一个，写出依据
3. 补环节：起始 → 中间 → 末端；缺的写「未给」，不用「导致」盖住
4. 记对比：损伤一侧、抗损伤一侧各写一句，再说当下哪方占优势
5. 标范围：局部 / 整体，并写明观察范围（器官、层次）
6. 落转归：只写类别——协调基本恢复 / 残留改变 / 代偿适应 / 延续状态
7. 查边界：删掉结论性措辞（导致、必然、已经恢复、预后良好），改中性表述
8. 报边界：不给值、不判预后、不把类别排序
```

## 硬约束

- **不给数值、单位、正常值、参考区间、百分比、分级分期。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不判转归。** 两类转归是结果类别，不是预测；三条边界是不判定、不承诺、不比较。
- **引文逐字。** 标「教材·疾病学基础·第N章·N.M.K」；章号取小节号首段，本课程第 2 章的九个小节章号全是 1。
- **位置不混。** 条件不写成病因，诱因不写成决定因素，伴随现象不写成原因。
- **范围必标。** 局部所见与整体状态分别记载，跨层面的推断不在记录中作出。

## 交付物

1. 一句位置判定：这一段说的是病因、条件还是诱因，依据是什么
2. 一条环节链：起始 → 中间 → 末端，缺段如实标缺
3. 一句力量对比：损伤与抗损伤各是什么，当下哪方占优势
4. 一句范围声明：局部主导 / 整体主导 / 相互影响，附观察范围
5. 一句转归类别：只到类别层，不写走向
6. 一处边界：不给值、不作预后判断，数值须另立数据层

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 条件当病因 | 讨论失去层次 | 改成影响关系：影响是否容易发生 |
| 伴随当原因 | 把时间先后写成环节先后 | 标出观察时点，环节关系另作论证 |
| 只写损伤一侧 | 把过程写成单边加重 | 补上代偿、修复、适应、应激反应 |
| 代偿当康复 | 掩盖环节上的关系 | 代偿是协调在另一方式下维持，过程未停 |
| 局部整体混写 | 一句话里装着两个层面 | 分开记载，跨层面推断不入记录 |
| 谈转归就预测 | 越出三条边界 | 只写类别，删掉「会好」「会重」 |
| 被追问就报数值 | 越出本书口径且无来源 | 统一回「本书不给值，另立数据层」 |

## 边界

本 Skill 只处理「归因句 → 位置 → 环节 → 边界」的结构化拆解，不涉及数值、判定与临床决策。分类框架取自代用底本《疾病学基础》第 1 章的类别与关系；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
