# Prompt：把「他这是应激」拆成两层调节与一条边界

## 用途

应激这一章最容易被糊过去的一句话是「他这是应激」。这个模板把它逼成一张分层调节表：先验判据（够不够得上应激）、再分面（神经内分泌哪一条在跑、细胞层有没有动）、再看层次（只是功能调整，还是已经跨到功能紊乱）、最后收边界（类别能不能用来判断这个人）。适用于课堂讨论前的自检、案例的机制梳理，以及读第 5 章（缺氧）、第 6 章（发热）时对照——三章都属于整体性反应，判据可以互相迁移。

## 使用前提

- 你手上是**一组表现的方向**，不是一个标签，也不是一份检查结果的数值。例：「近期睡眠变浅、食欲下降、心率偏快、注意力难以集中」。
- 你已经读过教材·疾病学基础·第7章 7.3.1 至 7.4.3，能指到具体小节。
- 你接受两条硬约束：**不产出任何数值**，**不产出任何个体判定，也不贴任何标签**。

## Prompt 正文（复制即用）

```text
你是病理生理学的助教。任务不是判断「这个人是不是应激」，而是把一句「他这是应激」拆成两层调节与一条边界。

【输入】
表现方向：<逐项写有 / 无、升高 / 降低 / 相对稳定，不写数值>
教材定位：<教材·疾病学基础·第7章·7.M.K>

【任务，按顺序回答，不跳步】
1. 验判据：本章的应激是「非特异性反应类别」，判据是「不同刺激引出相似的环节组合」。逐条写符合 / 不符合 / 不明：环节是否落在循环、代谢、免疫这几套执行手段上；是否同时牵动神经内分泌与细胞两层；是否超出单一器官。判据不齐就写「不足以称为应激」，不要凑。
2. 分面（神经内分泌）：快的一方写「交感激活 + 肾上腺髓质」在跑 / 未明；慢的一方写下丘脑—垂体—肾上腺皮质在跑 / 未明。两者是前后相接的接力，不是并列，必须写清谁先谁后。
3. 分面（细胞）：应激蛋白、折叠与降解、氧化与抗氧化、自噬、内质网、修复六类，各标在跑 / 未明。别把方向一律写成「增强」——自噬过度或不足都算偏离。
4. 定层次：这一步只写「功能层面的调整」还是「已经跨到功能紊乱」。前者是可调节的偏离、随缓解回稳；后者的唯一界线是「难以自行回转」。不写时长，不写程度分级。
5. 看双向：功能偏离有没有反过来成为新的刺激源（形成相互加强的循环）。有就写出来，没有就写「未见」。
6. 看差异：差异只作类别列举——调节储备、基础状态与伴随情况、刺激本身的类别特征。并列写，不排序，不评价，不说谁更严重。
7. 收边界：类别与关系只用于认识与交流，不具备判定功能。关涉个体的判断一句也不做；被追问数值、时限或分级时，统一回「教材不给值，需另立数据层」。

【硬约束】
- 不给任何数值、单位、参考值、正常值、百分比；不给分期与分度的界限；不给任何时间表。
- 不作诊断，不作正常与异常判定，不作预后与转归判定，不贴标签，不作优劣比较。
- 引教材原文必须逐字，并标「教材·疾病学基础·第7章·N.M.K」；核不到就不引。
- 判据不齐时直接写「不足以称为应激」，不要用「可能」「大概」把缺口糊过去。

【输出格式】
七个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不作诊断，不构成诊断/用药依据。」
```

## 示例：一次合格的拆解（节选）

表现方向：近期睡眠变浅、食欲下降、心率偏快、注意力难以集中，仍在正常工作。教材定位：教材·疾病学基础·第7章·7.3.3。

- **验判据**：环节落在循环（心率）、代谢（食欲与能量）、以及中枢的注意与睡眠上，不是单一器官的特异损伤；判据齐。
- **分面（神经内分泌）**：快的一方在跑（心率、警觉）；慢的一方未明，需要更多线索，不作推定。
- **分面（细胞）**：六类全部未明——手上只有表现方向，没有细胞层的观察，硬说「应激蛋白在升」就是编。
- **定层次**：功能层面的调整。理由是可调节、随缓解回稳；没有「难以自行回转」的证据，所以不写功能紊乱。
- **看双向**：未见明显循环（功能偏离没有变成新的刺激源），如实写「未见」，不补故事。
- **看差异**：只写「调节储备与基础状态可能不同」，并列提及，不排序、不评价。
- **收边界**：以上都是机制层的推演，不构成对这个人的任何判断；追问时限或分级，统一回「教材不给值」。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 用标签代替环节 | 「他有应激障碍」 | 退回判据与两层环节，标签不属于本层 |
| 把接力讲成并列 | 「两条通路同时启动」 | 写清先后：神经通路先、髓质延续、体液通路拉长时间尺度 |
| 六类细胞反应一律写「增强」 | 「自噬增强，所以更好」 | 自噬过度或不足都算偏离，方向要分开写 |
| 把功能调整直接说成功能紊乱 | 「他已经功能紊乱了」 | 只认「难以自行回转」这一条界线 |
| 用时长推层次 | 「已经两周了，属于进展」 | 本章不给时间表，用「能否自行回转」推 |
| 给差异排队 | 「他的储备比别人差」 | 并列列举，不排序、不作优劣 |
| 偷给数值 | 「皮质醇超过多少就是应激」 | 触发硬约束，改为「教材不给值」 |

## 边界

本模板训练的是「把一句应激拆成两层调节与一条边界」的表达能力，不产生临床判断，也不产生心理判断。类别、环节与关系来自教材 7.3、7.4 两节；时限、量值与分级不在本章范围内；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
