# Skill：应激——类别、两层的环节、由调到变与边界

## 何时用

- 有人（包括你自己）用「压力大」「他应激了」把环节糊过去了，需要拆开
- 要判断某个情形够不够得上本章意义上的应激（判据是「不同刺激、相似环节组合」）
- 要解释「为什么两条通路不是同时启动，而是接力」
- 要解释细胞层那六类保护动作之间的关系（维持 → 恢复）
- 要区分功能层面的调整与功能紊乱（界线是「难以自行回转」）
- 要处理「把个体差异说成结局差异」这类越界表述

## 核心判据（五问）

1. **判据齐不齐？** 不同刺激是否引出相似的环节组合；是否牵动神经内分泌与细胞两层；是否超出单一器官。不齐就不是本章的应激。
2. **神经内分泌哪一方在跑？** 快：交感激活 + 肾上腺髓质（略延后而延续）；慢：下丘脑—垂体—肾上腺皮质。二者前后相接，不是并列。
3. **细胞层有没有动？** 应激蛋白、折叠与降解、氧化与抗氧化、自噬、内质网、修复。方向要分开写，别一律「增强」。
4. **哪一层？** 功能层面的调整（可调节、随缓解回稳）还是功能紊乱（偏离稳态且难以自行回转）。不写时长、不写程度分级。
5. **边界在哪？** 类别与关系只用于认识与交流，不具备判定功能；关涉个体的判断归具备资质的人员。

## 执行步骤

```text
1. 验判据：三条逐条标符合 / 不符合 / 不明
2. 分面一：神经内分泌的快与慢，各标在跑 / 未明，写清先后
3. 分面二：细胞六类，各标在跑 / 未明，方向分开写
4. 定层次：功能调整 / 功能紊乱（只认「能否自行回转」）
5. 看双向：功能偏离是否成为新的刺激源
6. 看差异：三类来源并列列举，不排序、不评价
7. 收边界：不作判定；追问数值一律回「教材不给值」
```

## 硬约束

- **不给数值、单位、参考值、正常值、百分比；不给分期与分度的界限；不给时间表。** 追问统一回「教材不给值，需另立数据层（另立来源与校验）」。
- **不作诊断，不作正常与异常判定，不作预后与转归判定，不贴标签，不作优劣比较。**
- **不把接力讲成并列。** 神经通路先动员，髓质环节略为延后而延续，体液通路把动员拉到较长时间尺度。
- **不把「增强」当成好。** 自噬过度或不足都可能带来偏离；氧化与抗氧化看的是平衡，不是单向。
- **不把差异当结局。** 差异只说明倾向，不说明走向；教材明确把「差异 → 更差结果」判为不适当的推论。
- **引文逐字。** 标「教材·疾病学基础·第7章·N.M.K」，核不到就不引。

## 交付物

1. 一句判据结论（够不够得上应激）
2. 一张两层环节表（神经内分泌的快与慢 + 细胞六类，各标在跑 / 未明）
3. 一个层次判定（功能调整 / 功能紊乱，附「能否自行回转」的依据）
4. 一处双向检查（功能偏离是否成为新的刺激源）
5. 一段边界说明（类别无判定功能 + 不给值 + 不贴标签）

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 把日常「压力大」当应激 | 概念被稀释，判据失效 | 按「不同刺激、相似环节组合」逐条验 |
| 两条通路讲成同时启动 | 漏掉糖皮质激素维持血管应答这一环 | 写成前后相接的接力 |
| 细胞六类一律写「增强」 | 把双向环节读成单向好处 | 方向分开写，看平衡 |
| 用时长推层次 | 时间表替代了机制 | 只认「能否自行回转」 |
| 给个体差异排队 | 越出资质边界，且不可检验 | 并列列举，不排序、不评价 |
| 拿引文当判定依据 | 把类别升级成结论 | 引文只证明教材怎么写，不证明个体怎么样 |

## 边界

本 Skill 只处理「表现方向 → 判据、两层环节、层次与边界」的结构化表达，不涉及数值、判定与临床决策。任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出；涉及心理状态的内容不作诊断、不作标签化表述。
