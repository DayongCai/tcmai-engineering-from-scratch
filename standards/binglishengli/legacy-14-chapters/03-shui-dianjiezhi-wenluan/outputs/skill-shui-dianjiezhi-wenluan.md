# Skill：水、电解质代谢紊乱——三条维度、三端环节与一道边界

## 何时用

- 有人（包括你自己）用「这是脱水」或「血钾低」把一段观察糊过去了，需要拆开
- 要在高渗性 / 低渗性 / 等渗性之间归类，却说不清水与钠谁丢得多
- 遇到「血钾低了，是不是缺钾」这类追问，需要区分总量路径与分布路径
- 要把一段记录里的程度词（严重、明显、轻度）换成可比较的类别词
- 需要一套一致的拒答口径来应对「具体是多少」的追问

## 核心判据（四问）

1. **哪几条维度？** 容量状态、渗透状态、钠水平各是什么方向。只答一条，说明另外两条被默认成了「正常」。
2. **谁丢得多？** 水与钠哪一边相对丢失更多。这一条定渗透方向；丢失总量定容量方向。两个自变量不许合并。
3. **水往哪边走？** 渗透方向决定跨膜方向：细胞内→细胞外（细胞皱缩），或细胞外→细胞内（细胞肿胀）。
4. **哪一端先动？** 摄入、排出、跨膜转移三端里，指出先动的一端与跟着动的一端。钾尤其如此：总量变化与分布变化两条路不许混谈。

## 执行步骤

```text
1. 抄情形，不抄诊断：写「经消化道丢失后只补了不含钠的液体」，不写「低渗性脱水」
2. 三条维度各写一句方向，并注明依据
3. 定相对量：水与钠谁丢得（增得）更多 → 渗透方向
4. 定再分布：按渗透方向写水往哪一侧移、细胞形态朝哪边变
5. 追三端：摄入 / 排出 / 跨膜转移，标出先动与后动
6. 钾的特判：先判总量路径还是分布路径，再落到三端
7. 因素归组：摄入 / 排出 / 分布 / 调节四组，说明各作用于哪一端
8. 功能方向：只写兴奋性升高或降低，分神经肌肉与心脏两面，不写程度
9. 反查：抽掉某一条维度，结论会怎样变（给可观察差别，不给数值）
```

## 硬约束

- **不给数值、单位、参考值、参考范围、分级分期分度。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不判正常与异常，不作诊断与预后判定。** 机制能说明「方向为什么朝这边」，不能说明某个体现在处于什么状态。
- **血钾 ≠ 总量。** 任何关于钾的表述都必须先说明改变来自总量还是分布。
- **因素存在 ≠ 方向确定。** 多个因素并存时，教材明确不据单一因素推方向。
- **引文逐字。** 标「教材·疾病学基础·第5章·N.M.K」，核不到就不引。

## 交付物

1. 一份三维度表：容量 / 渗透 / 钠量各一句方向
2. 一条相对量判断：水与钠谁相对多丢（或多增）
3. 一条再分布说明：水往哪边移、细胞形态朝哪边变
4. 一条三端定位：先动端与后动端
5. 一处边界：本章不给值，浓度与容量须另立数据层

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 用诊断代替情形 | 拆解无从下手 | 先写三条维度的方向 |
| 三维度压成一条 | 「缺水就是容量不足」 | 容量与渗透分开写，各注依据 |
| 把补液写成建议 | 越出教学口径 | 改为「补入液体的类别改写相对量这一条」 |
| 血钾与总量混谈 | 「血钾低就是缺钾」 | 先判总量还是分布 |
| 用程度代替类别 | 「乏力明显」 | 只写兴奋性方向与所涉方面 |
| 被追问就报数值 | 越出本书口径，且数值无来源 | 统一回「本书不给值，另立数据层」 |

## 与相邻章节的接缝

- 课程第 4 章（酸碱平衡紊乱）：钾的跨膜转移与酸碱状态互相牵连，两章共用「一条环节改动会带动另一条」的读法。
- 课程第 11、12、14 章（心、肺、肾功能不全）：容量与渗透的改变常与器官功能状态并存，复用本章的三维度与三端读法。
- 病理学的水肿一章：那里讲液体分布，这里讲维度与环节，两处不重复但接口在「渗透状态对细胞体积的影响」。

## 边界

本 Skill 只处理「情形 → 三维度 → 三端」的结构化表达，不涉及数值、判定与临床决策。任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
