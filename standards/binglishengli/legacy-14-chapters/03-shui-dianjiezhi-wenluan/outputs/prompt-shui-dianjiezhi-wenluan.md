# Prompt：把「脱水」拆成三条维度与三端环节

## 用途

水电解质这一段最容易糊过去的一句话是「这是脱水」。这个模板把这句话逼到三条维度上：容量、渗透、钠量分别是什么方向，再由方向追到丢失的那一端。钾的部分同样适用：先问血钾的改变来自总量还是来自分布，再问它落在摄入、排出、跨膜转移的哪一端。适用于病例讨论前的自检、读记录时的机制梳理，以及写护理记录前把「程度词」换成「类别词」。

## 使用前提

- 你手上是**一组可观察的类别信息**，不是一个诊断。例：「经消化道丢失后只补了不含钠的液体，乏力明显」「饮水量较日常显著增多，伴头胀」。
- 你已经读过对应小节，手边有「教材·疾病学基础·第5章·5.1.1」这一级的定位。
- 你接受一条硬约束：**本模板不产出任何数值**，也不产出分级分期。

## Prompt 正文（复制即用）

```text
你是病理生理学的助教。任务不是给这组情形下结论，而是把它拆到三条维度与三端环节上。

【输入】
情形：<一句话描述丢失或蓄积的途径类别、补入液体的类别、以及可观察的类别化表现>
教材定位：<教材·疾病学基础·第5章·N.M.K>

【任务，按顺序回答，不跳步】
1. 分维度：容量状态、渗透状态、钠水平各写一句方向（不足/过多、偏低/偏高/接近不变）。
2. 定构成：水与钠哪一边丢得（或增得）相对更多？这一条决定的是渗透方向，不是容量方向。
3. 再分布：按渗透方向说清水往哪一侧移（细胞内→细胞外，或细胞外→细胞内），以及细胞形态朝哪个方向变。
4. 追环节：把方向落到端上——摄入、排出、跨膜转移，指出哪一端是先动的，哪一端是跟着动的。
5. 钾的特判：血钾的改变来自总量变化还是分布变化？两条不许混着写。
6. 因素定位：若涉及血钾，把因素归入摄入、排出、分布、调节四组，并说明它作用于哪一端。
7. 功能方向：只写兴奋性是升高还是降低，分神经肌肉与心脏两面；不写程度。
8. 边界：这组信息不能推出什么？说清类别说明与专业判断之间的界线。

【硬约束】
- 不给任何数值、单位、参考值与参考范围；不给分级、分期与分度。
- 不作正常与异常的判定，不作诊断，不作病情与预后判定，不作疗效断言。
- 引教材原文必须逐字，并标「教材·疾病学基础·第5章·N.M.K」；核不到就不引。
- 信息不足以定维度时，直接说缺哪一条（容量 / 渗透 / 钠量 / 端），不要猜。

【输出格式】
八个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不作诊断与判定，不构成诊断/治疗/用药依据。」
```

## 示例：一次合格的拆解（节选）

情形：经消化道丢失后只补了不含钠的液体，出现乏力。教材定位：教材·疾病学基础·第5章·5.1.2。

- **分维度**：容量不足（总量减少）；渗透状态偏低；钠水平偏低。
- **定构成**：钠的丢失相对居多——补进去的液体不含钠，把「相对量」这一条进一步推低了。
- **再分布**：水由细胞外移向细胞内，细胞趋于肿胀；细胞外液容量进一步减少。
- **追环节**：先动的是排出端（经消化道丢失），跟着动的是摄入端（补入液体不含钠）。
- **钾的特判**：此处不涉血钾；若涉，必须先分清总量与分布两条路径。
- **因素定位**：排出类别在先，摄入类别在后；分布类别因渗透方向改变而可能被牵动。
- **功能方向**：可兴奋组织的电活动可能受影响，写方向不写程度。
- **边界**：只说明类别与环节的组合，不说明严重程度，也不构成诊断。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 用诊断代替情形 | 「这是低渗性脱水」 | 先写三条维度各自的方向，再谈类别名 |
| 三条维度压成一条 | 「缺水就是容量不足」 | 容量与渗透分开写，注明各自依据 |
| 把补液当治疗建议 | 「应该补钠」 | 改为「补入液体的类别会改写相对量这一条」 |
| 血钾与总量混谈 | 「血钾低就是缺钾」 | 先判总量路径还是分布路径 |
| 偷给数值 | 「补多少毫升」 | 触发硬约束，改为类别语汇 |

## 边界

本模板训练的是「把情形拆到维度与端上」的表达能力，不产生临床判断。类别与环节的对应来自教材，容量、浓度、程度等参数不在本书范围内；任何涉及个体的评估须由具备资质的人员依现行规范作出。
