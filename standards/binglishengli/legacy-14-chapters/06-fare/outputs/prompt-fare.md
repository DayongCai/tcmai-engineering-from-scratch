# Prompt：把「他在发热」拆成调定点与体温的位置关系

## 用途

「发热了」这句话在讨论里往往同时承担三件事：说明状态、暗示程度、预告走向。本章的底本三件都不给，只给位置关系。这个模板把这句话逼到两条线上：先定位机制环节（致热原 → 中枢 → 效应），再定位分期（调定点与体温谁高谁低）。适用于课堂讨论前的自检、病例讨论的机制梳理，以及读第 5 章（缺氧）、第 7 章（应激）时对照使用——缺氧讲供氧链，应激讲全身反应，发热讲设定值，三者常在同一个情形里同时出现。

注意：底本是《疾病学基础》第 6 章 6.3–6.4，它给的是**类别、环节与关系**，不给任何体温数值与分级。本模板因此不产出「多少度算什么」这类内容。

## 使用前提

- 你手上的是一段关于**变化与感受的描述**（起于什么、往哪个方向、处在什么阶段），而不是一个体温读数。
- 你已读过教材·疾病学基础·第6章 6.3.1 至 6.4.3，手边能指出每一小节的定位。
- 你接受两条硬约束：**不产出任何数值与分级，不产出诊断**。

## Prompt 正文（复制即用）

```text
你是病理生理学的助教。任务不是给出判断，而是把一个「发热」的说法拆成两条线：机制环节，与调定点—体温的位置关系。

【输入】
变化描述：<写清起于什么、往哪个方向、处在什么阶段；不写数值，不写病名>
教材定位：<教材·疾病学基础·第N章·N.M.K>

【任务，按顺序回答，不跳步】
1. 分概念：先明确区分「调定点的变化」与「体温的变化」——前者是调节环节本身的变化，后者是调节产生的结果。只写这两句，不写数值。
2. 定位链条：把致热原按类别排成前后相接的链（外源性 → 内源性 → 中枢环节），并说明输入里的变化落在哪一段；若属于不经过这条链条、直接作用于中枢的因素，单独标出。
3. 定环节：说明发热的关键变化落在感受、中枢、效应三个环节中的哪一个，依据是哪一句原文（引原文须逐字）。
4. 判分期：按调定点与体温的相对位置判断属于三个分期中的哪一个——调定点高于体温 / 两者大体相当 / 调定点低于体温；并写出产热与散热的净效果。
5. 做辨析：指出本期最容易混淆的「另一类变化」（如调节环节未改变时的体温升高或体温下降），并说明凭哪一条区分。
6. 边界：说明这次定位在环节层面成立，但不足以判定任何个体的正常与异常；被追问数值、分级或时限时，统一回答「教材不给值，需另立数据层」。
7. 反查：如果拿掉「调定点」这条尺度，三个分期还分得开吗？给出会剩下的歧义。

【硬约束】
- 不给任何数值、单位、正常值、参考范围、百分比、分级与时限。
- 只写环节，不写比值：产热与散热的相对比例只用方向表述。
- 不作诊断，不作正常与异常判定，不作预后与转归判定，不作疗效断言。
- 引底本原文必须逐字，并标「教材·疾病学基础·第N章·N.M.K」；核不到就不引。

【输出格式】
七个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的拆分（节选）

变化描述：调定点已上移，体温尚未升到新的调定点，产热增多而散热减少。教材定位：教材·疾病学基础·第6章·6.4.1。

- **分概念**：动的是调定点，体温是被动跟随的结果。两句分开写，不写数值。
- **定位链条**：落在内源性一类作用于中枢环节之后，外源性一类在更前段，本段不再展开。
- **定环节**：中枢环节。依据是底本那句「发热的关键变化就落在这一环节」。
- **判分期**：体温上升期——调定点高于体温，产热多于散热，体温持续上升。
- **做辨析**：与「调节环节未改变时的体温升高」区分，凭的是有无调定点的上移。
- **边界**：这是环节定位，不是诊断。追问数值统一回「教材不给值，需另立数据层」。
- **反查**：拿掉调定点，三个分期只剩「冷、热、出汗」三种感受，感受可以重叠，分期就分不开——这正说明调定点是唯一尺度。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 用感受代替位置 | 「他觉得冷，所以是上升期」 | 感受只作类别提及，判据是调定点与体温的位置 |
| 把稳定当调节停止 | 「体温稳住了，说明调节停了」 | 相对稳定是产热与散热在新水平上的平衡 |
| 用分期当时间表 | 「这一期大概持续多久」 | 时限属个体情形，本章不给 |
| 把两类混称 | 把调节环节未改变的体温升高说成发热 | 有无调定点的上移，是区分两类变化的根本 |
| 偷给数值 | 「超过某个读数就是发热」 | 触发硬约束，改为「教材不给值」 |

## 边界

本模板训练的是「把发热写成位置关系」的表达能力，不产生临床判断。链条、环节与分期来自代用底本《疾病学基础》第 6 章 6.3–6.4 的表述；数值、分级与时限不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
