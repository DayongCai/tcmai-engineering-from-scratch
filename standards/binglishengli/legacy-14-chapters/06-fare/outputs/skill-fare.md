# Skill：发热——三个分期是调定点的三种位置

## 何时用

- 有人（包括你自己）用一句「他发热了」把判断糊过去了，需要拆到环节上
- 分不清眼下是上升、持续还是退热，只能凭「感觉冷还是热」猜
- 要解释「为什么发热不等于体温升高」「为什么体温稳住了不等于调节停止」
- 要说明致热原两类的前后顺序与中枢环节的位置
- 遇到「到多少度算发热」的追问，需要一套一致的拒答口径

## 核心判据（五问）

1. **动的是调定点还是体温？** 前者是调节环节本身的变化，后者是调节产生的结果。混了两者，分期一定讲乱。
2. **落在链条哪一段？** 外源性 → 内源性 → 中枢环节；直接作用于中枢的因素不在这条链上，须单列。
3. **关键变化在哪个环节？** 感受、中枢、效应三者中，发热落在中枢（设定值），不在感受与效应。
4. **调定点与体温谁高？** 调定点高于体温 = 上升期；大体相当 = 持续期；低于体温 = 退热期。
5. **这次定位能承担什么？** 只能承担环节与分期，不能承担正常与异常的判定，也不能给时限。

## 执行步骤

```text
1. 分概念：调定点 / 体温，两句分开写
2. 排链条：外源性 → 内源性 → 中枢环节（直击中枢的因素另列）
3. 定环节：落到中枢，引一句原文作依据
4. 判分期：按调定点与体温的相对位置定三期，写产热与散热的净效果
5. 做辨析：指出本期最易混的另一类变化，并说明凭哪一条区分
6. 边界：只到环节层；追问数值统一回「教材不给值，另立数据层」
7. 反查：抽掉调定点这条尺度，看三个分期还能不能分开
```

## 硬约束

- **不给数值、单位、正常值、参考范围、百分比；不给分级、分度与时限。** 需要数值才能回答的追问，统一回「教材不给值，需另立数据层（另立来源与校验）」。
- **只写环节，不写比值。** 产热与散热的相对比例只用方向表述。
- **不作诊断、不作正常与异常判定、不作预后与转归判定。**
- **不把感受当判据。** 主观感受只作类别提及，不写强度与判断标准。
- **引文逐字。** 标「教材·疾病学基础·第N章·N.M.K」，核不到就不引。

## 交付物

1. 一句分概念（调定点 vs 体温）
2. 一个链条位置（外源性 / 内源性 / 直击中枢）
3. 一个环节落点（中枢）+ 一句原文依据
4. 一个分期判断（位置关系 + 产热与散热的净效果）
5. 一处边界（不给值，须另立数据层）

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 用感受定分期 | 冷热可以重叠，分错期 | 回到调定点与体温的位置 |
| 把稳定当调节停止 | 误解持续期 | 相对稳定是新的平衡，调节仍在进行 |
| 分期当时间表 | 追问「持续多久」答不上来 | 时限属个体情形，本章不给 |
| 把体温升高都说成发热 | 混掉两类不同变化 | 有无调定点的上移 |
| 被追问就报阈值 | 越出本书口径，且阈值无来源 | 统一回「教材不给值」 |

## 与相邻章节的接缝

- 上一章（缺氧）：发热使代谢率升高、耗氧需求增加，供与需的关系随之改变。
- 下一章（应激）：应激的神经内分泌反应与发热的调节环节在中枢层面交汇，但两者的起点不同。
- 全书：本章的「设定值—效应」结构，在心功能不全（前负荷与代偿）、肾功能不全（调节阈值）两处反复复用。

## 边界

本 Skill 只处理「变化描述 → 环节与分期定位」的结构化表达，不涉及数值、判定与临床决策。任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
