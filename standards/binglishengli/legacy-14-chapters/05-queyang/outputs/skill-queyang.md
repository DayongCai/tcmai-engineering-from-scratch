# Skill：缺氧——四类缺氧是链条上的四段

## 何时用

- 有人（包括你自己）用一句「他缺氧」把判断糊过去了，需要拆到链条上
- 手上有关于变化的描述，却分不清落在摄取与交换、携带与释放、输送还是利用
- 要解释「为什么摄取与交换正常也会缺氧」「为什么血液成分增多不等于血液性缺氧」
- 要判断某类代偿大概往哪个方向走、会付出什么代价
- 遇到「到什么程度算缺氧」的追问，需要一套一致的拒答口径

## 核心判据（五问）

1. **落在哪一段？** 摄取与交换、携带与释放、输送、利用——四段，答不出段就还在讲现象。
2. **起点靠哪边？** 靠近外界与交换面 = 乏氧性；在血液本身 = 血液性；在推送与灌注 = 循环性；在细胞末端 = 组织性。
3. **送到之前还是之后？** 循环性在送达之前，组织性在送达之后。这是后两段唯一可靠的分界。
4. **两类同时成立时以谁为主？** 以主导环节为准；底本把这条写成了归类的基本原则。
5. **这次定位能承担什么？** 只能承担环节与类别，不能承担正常与异常的判定。

## 执行步骤

```text
1. 立链：摄取与交换 → 携带与释放 → 输送 → 利用
2. 归位：把变化描述挂到它所在的那一段，并引一句底本原文作依据
3. 定类：给出类别，并为另外三类各写一句排除理由
4. 主导：两类并见时定主导环节，说明依据
5. 代偿：细胞侧（能量生成 / 酸碱 / 膜功能 / 细胞结构）+ 系统侧（呼吸 / 循环 / 血液 / 神经），只写方向
6. 边界：说明只到环节层；追问数值统一回「教材不给值，另立数据层」
7. 反查：抽掉主导环节或抽掉一段，看会剩下什么歧义
```

## 硬约束

- **不给数值、单位、正常值、参考范围、百分比；不给分级、分期、分度与时限。** 需要数值才能回答的追问，统一回「教材不给值，需另立数据层（另立来源与校验）」。
- **不作诊断、不作正常与异常判定、不作预后与转归判定。** 环节定位能说明「断在哪」，不能说明「某人现在算不算异常」。
- **不用现象替代环节。** 底本明说表面现象往往可以在多个类别中出现，不能仅凭某一现象作出类别归属。
- **名称相近的类别不得混称。** 血液系统的适应性增多与血液性缺氧是两件事。
- **引文逐字。** 标「教材·疾病学基础·第N章·N.M.K」，核不到就不引。

## 交付物

1. 链条上的一个位置（四段之一，附三条排除理由）
2. 一个类别名（含主导环节判断）
3. 一组代偿方向（细胞侧 + 系统侧，不含程度）
4. 一处边界（不给值，须另立数据层）

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 四类当四个病名背 | 换一段描述就套不上 | 记住四个位置，类别名只是标签 |
| 只看表面现象 | 同一现象在多个类别出现，归错类 | 回到环节，以主导环节为准 |
| 混淆名称 | 把携氧成分增多说成血液性缺氧 | 名称相近而环节不同，须分述 |
| 把代偿当无代价 | 忽略心脏氧需上升、呼吸做功增加 | 代偿本身可以是新的负担 |
| 被追问就报阈值 | 越出本书口径，且阈值无来源 | 统一回「教材不给值」 |

## 与相邻章节的接缝

- 上一章（酸碱平衡紊乱）：缺氧时的不依赖氧途径增强会把酸性产物推上来，两章的代谢侧在这里相交。
- 下一章（发热）：发热使代谢率升高、耗氧需求增加，供与需的关系随之改变。
- 再下一章（应激）：应激的血流重新分布改写「输送」这一段。
- 全书：本章的链条在休克（输送）、缺血-再灌注（利用与再损伤）、呼吸功能不全（摄取与交换）三处反复复用。

## 边界

本 Skill 只处理「变化描述 → 环节定位」的结构化表达，不涉及数值、判定与临床决策。任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
