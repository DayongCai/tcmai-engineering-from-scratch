# Prompt：把「他缺氧」落到氧代谢链条的哪一段

## 用途

病理生理学里最容易被糊过去的判断是「他缺氧了」。这句话既不说清变化落在哪一环，也不说清机体在往哪个方向代偿。这个模板把这句话逼到链条上：先说清环节位置，再说类别，最后说这次定位能承担什么、不能承担什么。适用于课堂讨论前的自检、病例讨论的机制梳理，以及读第 6 章（发热）、第 7 章（应激）时反复套用——发热使耗氧需求上升，应激改写血流分布，两者都会牵动供氧这一条链。

注意：本章的底本是《疾病学基础》第 6 章 6.1–6.2，它给的是**类别、环节与关系**，不给任何指标与数值。所以本模板不产出「某指标多少」这类内容，只产出位置与方向。

## 使用前提

- 你手上的是**一段关于变化的描述**（变化起于何处、往哪个方向、涉及哪些情形），而不是一个病名，也不是一个数值。
- 你已读过教材·疾病学基础·第6章 6.1.1 至 6.2.3，手边能指出每一小节的定位。
- 你接受两条硬约束：**本模板不产出任何数值，也不产出诊断**。

## Prompt 正文（复制即用）

```text
你是病理生理学的助教。任务不是给出判断，而是把一个「缺氧」的说法落到氧代谢链条上的某一段。

【输入】
变化描述：<写清起于何处、往哪个方向、涉及哪些情形；不写数值，不写病名>
教材定位：<教材·疾病学基础·第N章·N.M.K>

【任务，按顺序回答，不跳步】
1. 立链：把氧的行程写成四段——摄取与交换、携带与释放、输送、利用。只写段名，不写任何数值。
2. 归位：把输入里的变化挂到它所在的那一段，并说明依据落在哪句话上（引原文须逐字）。
3. 定类：按归类原则给出类别（乏氧性 / 血液性 / 循环性 / 组织性），并说明「为什么不是另外三类」。三类各给一句排除理由。
4. 定主导环节：若有两类同时成立，指出以哪一环为主导，依据是什么；不要用「都很重要」糊过去。
5. 代偿方向：分别写出该类别在细胞代谢与各系统两个层面的变化方向（能量生成、酸碱状态、膜功能、细胞结构；呼吸、循环、血液、神经），只写方向，不写程度。
6. 边界：说明这次定位在环节层面成立，但不足以判定任何个体的正常与异常；若被追问具体数值、分级或时限，统一回答「教材不给值，需另立数据层」。
7. 反查：如果拿掉「主导环节」这一条，会剩下什么歧义？给出歧义，不要用数值弥补。

【硬约束】
- 不给任何数值、单位、正常值、参考范围、百分比、分级与时限。
- 不作诊断，不作正常与异常判定，不作预后与转归判定，不作疗效断言。
- 引底本原文必须逐字，并标「教材·疾病学基础·第N章·N.M.K」；核不到就不引。
- 描述不足以定位时，直接说缺哪几项，不要猜。

【输出格式】
七个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的落位（节选）

变化描述：起于所处环境氧相对不足，经交换之后血液携带的氧不及常态，呼吸通路与交换面未见原发变化。教材定位：教材·疾病学基础·第6章·6.1.1。

- **立链**：摄取与交换 → 携带与释放 → 输送 → 利用。
- **归位**：落在第一段。底本的原话是「乏氧性缺氧类别的特点，在于其环节位于氧的摄取与交换一侧」。
- **定类**：乏氧性。排除血液性——携氧成分的数量与状态未见改变；排除循环性——推送与灌注不是起点；排除组织性——利用一侧在链条末端，与「经交换之后携带的氧不及常态」对不上。
- **定主导环节**：环境一侧为主，呼吸通路与交换面只作为可能被加重的方向列出，按底本要求「以主导环节为准」。
- **代偿方向**：细胞层面能量生成方式偏向不依赖氧的途径、酸性产物方向上升；系统层面呼吸与循环先动，血液与神经随后。只写方向，不写程度。
- **边界**：这是环节定位，不是诊断。追问数值统一回「教材不给值，需另立数据层」。
- **反查**：拿掉「主导环节」，环境、通路、交换面三种情形会并列，四类之间就分不开——这正是底本把「以主导环节为准」写进正文的理由。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 用病名代替环节 | 「这是贫血性缺氧」 | 改成环节：「落在携带与释放这一段」 |
| 用现象代替位置 | 「口唇发绀，属于乏氧性」 | 现象可在多个类别中出现，回到环节 |
| 名称相近就混称 | 把血液系统的适应性增多说成血液性缺氧 | 底本明说「两者名称相近而环节不同，叙述时不得混称」 |
| 把代偿当无代价 | 「已经代偿了，所以没问题」 | 追问代价：心脏氧需上升、呼吸做功增加 |
| 偷给数值 | 「低于某个值就是缺氧」 | 触发硬约束，改为「教材不给值」 |

## 边界

本模板训练的是「把缺氧写成环节定位」的表达能力，不产生临床判断。链条与类别来自代用底本《疾病学基础》第 6 章 6.1–6.2 的表述；数值、分级与时限不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
