# Prompt：把「他休克了」拆成一条环节链

## 用途

「休克」这个词在课堂上常被当成一个标签用：贴上它，似乎就不用再说环节了。这个模板把它逼成一条链：先认概念（一类过程 + 一个中心环节）、再定起点（四类之一，允许叠加）、再判阶段（代偿还在不在覆盖）、再走微循环（三个部位、四类环节），最后收口径（类别不是判定，不给阈值）。适用于课堂讨论前的自检、案例的机制梳理，以及读第 7 章（应激）时对照——两章共用「环节—代偿—失代偿」这套语言。

## 使用前提

- 你手上是**一组表现的方向与环节线索**，不是一个数值，也不是一份检查结论。例：「四肢发凉、尿量减少、意识由清转淡」。
- 你已经读过教材·疾病学基础·第7章 7.1.1 至 7.2.3，能指到具体小节。
- 你接受三条硬约束：**不产出任何数值**、**不产出任何个体判定**、**不产出任何处置方案**。

## Prompt 正文（复制即用）

```text
你是病理生理学的助教。任务不是判断「这个人是不是休克」，而是把一句「他休克了」拆成一条环节链。

【输入】
表现方向：<逐项写有 / 无、升高 / 降低 / 相对稳定，不写数值，不写任何测量值>
教材定位：<教材·疾病学基础·第7章·7.M.K>

【任务，按顺序回答，不跳步】
1. 认概念：写出本章的中心环节——有效循环血量相对不足与组织灌注的持续性下降。说明「相对」把容量、泵、分布、通路四类起点都收进来，「持续」说明它是一段过程而不是一个时点。
2. 定起点：四类起始环节是哪一类或哪几类（血容量丢失 / 心脏泵血减退 / 血管舒缩与分布异常 / 循环通路受阻）。允许叠加，写成「以某类为主，另有某类参与」；不要凑成唯一一类。
3. 判阶段：代偿 / 进展 / 难治。判据只有一个——代偿还在不在覆盖。写清依据是「调节尚能覆盖」「代偿与失代偿并存」「对常规调节缺乏应答」中的哪一条；不写「多久了」，不写任何时限。
4. 走微循环：微动脉（动脉端阻力）、毛细血管（灌流量与流速）、微静脉（容纳与回流）、物质交换（这一层的目标）四栏各写一句。代偿期要写出「调的是前后阻力的比值，不是绝对值」；进展期要写出「应答减弱 → 流速减慢 → 静脉端积聚 → 环境恶化」这条相互加强的链。
5. 看接缝：与应激的关系（彼此影响、彼此强化）写一句；若涉及凝血与纤溶，只标「这是难治期的一类环节」，并说明底本没有展开、本章不替它展开。
6. 收口径：这一步只写类别与关系。阶段名称是类别标签，不用来推断个体状况；「难治」描述的是环节性质与调节应答状态，不是结局。
7. 划边界：被追问阈值、分级、时限或处置时，统一回「教材不给值，需另立数据层」，并说明处置须由具备资质的人员依现行规范作出。

【硬约束】
- 不给任何数值、单位、参考值、正常值、百分比；不给血压阈值；不给分期与分度界限；不给时限。
- 不作诊断，不作正常与异常判定，不作预后与转归判定，不给处置方案与用药建议。
- 引教材原文必须逐字，并标「教材·疾病学基础·第7章·N.M.K」；核不到就不引。
- 四类起点不要写成互斥项；三阶段不要写成时间表。

【输出格式】
七个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不作诊断，不构成诊断/用药依据。」
```

## 示例：一次合格的拆解（节选）

表现方向：四肢发凉、尿量减少、意识由清转淡。教材定位：教材·疾病学基础·第7章·7.1.2。

- **认概念**：中心环节是有效循环血量相对不足与组织灌注的持续性下降；「持续」说明这是过程，不能凭一次所见定阶段。
- **定起点**：以血容量丢失为主（需核对是否有丢失的线索），另可能有分布异常参与——两类可以并存，不写成唯一一类。
- **判阶段**：倾向进展期。依据是「代偿与失代偿并存」：还有调节在生效（四肢发凉提示外周调节仍在），但已有失代偿成分（尿量减少、意识改变）。不给时长。
- **走微循环**：动脉端应答减弱（推动力不足）→ 毛细血管流速减慢（停留延长、聚集倾向增强）→ 静脉端容纳超过回流（交换平衡被打破）→ 代谢环境恶化（缺氧与酸性产物积聚）。四步是一条相互加强的链，不是四个并列现象。
- **看接缝**：与应激彼此强化——应激环节改变血管对调节信号的应答能力，这正是本章微循环调节的前提之一。
- **收口径**：以上是环节层的梳理；阶段名称不用于推断这个人的具体状况。
- **划边界**：追问血压界值或分级，回「教材不给值」；处置不由本章给。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 把分期当时长 | 「已经几个小时了，属进展期」 | 用「代偿还在不在覆盖」判，不用时间判 |
| 四类起点写成抽屉 | 「他属于分布异常型」 | 允许叠加，写成「以某类为主、另有参与」 |
| 微循环三段各自为政 | 三个名字下面各写一堆现象 | 用「同一套环节的三种状态」串起来 |
| 把「难治」读成结局 | 「难治期就是没救了」 | 类别只描述环节与应答状态 |
| 偷给阈值 | 「血压低于多少就是休克」 | 触发硬约束，改为「教材不给值」 |
| 越到处置 | 「应该先快速补液」 | 本章不给处置方案，交具备资质的人员 |
| 替缺稿章展开 | 「再灌注损伤会……」 | 第 8、10 章在底本中无内容，只标位置不展开 |

## 边界

本模板训练的是「把一句休克拆成一条环节链」的表达能力，不产生临床判断。类别、环节与关系来自教材 7.1、7.2 两节；阈值、分级、时限与处置均不在本章范围内；任何涉及个体的评估与处置须由具备资质的人员依现行规范与机构制度作出。
