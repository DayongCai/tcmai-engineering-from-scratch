# Skill：休克——概念、四类起点、三段分期与微循环环节

## 何时用

- 有人（包括你自己）用「他休克了」把环节糊过去了，需要拆开
- 要判断某情形以哪一类起始环节为主（允许叠加，不要求唯一）
- 要解释「分期为什么不是时间表」、「为什么代偿期还能维持」
- 要解释进展期那条「应答减弱 → 流速减慢 → 静脉端积聚 → 环境恶化」的相互加强链
- 要把「难治」从结局判定里救回来，写成环节描述
- 要处理「补液/升压」这类被塞进机制章的处置提问

## 核心判据（五问）

1. **中心环节在不在？** 有效循环血量相对不足 + 组织灌注持续性下降。「相对」管起点多样，「持续」管它是一段过程。
2. **起点是哪一类（可多类）？** 血容量丢失 / 心脏泵血减退 / 血管舒缩与分布异常 / 循环通路受阻。前两类是量与泵，后两类是分布与通路。
3. **代偿还在不在覆盖？** 在覆盖 → 代偿期；并存且失代偿成分增加 → 进展期；对常规调节缺乏应答 → 难治期。不写时长。
4. **微循环哪一栏在动？** 微动脉（动脉端阻力）、毛细血管（灌流量与流速）、微静脉（容纳与回流）、物质交换（目标函数）。调的是前后阻力的比值，不是绝对值。
5. **口径守住了吗？** 阶段名称是类别标签，不推断个体状况；「难治」描述环节性质与应答状态，不是结局；不给阈值、分级、时限与处置。

## 执行步骤

```text
1. 认概念：写出中心环节，标明「相对」与「持续」各管什么
2. 定起点：四类中选主次，允许叠加
3. 判阶段：只按「代偿还在不在覆盖」，附依据，不写时长
4. 走微循环：四栏各一句；进展期要串成相互加强的链
5. 看接缝：与应激的相互强化；凝血/纤溶只标位置（第 10 章缺稿）
6. 收口径：类别标签不用于推断个体；难治不是结局
7. 划边界：追问阈值/分级/时限/处置，统一回「教材不给值」并转介
```

## 硬约束

- **不给数值、单位、参考值、正常值、百分比；不给血压阈值；不给分期与分度界限；不给时限。** 追问统一回「教材不给值，需另立数据层（另立来源与校验）」。
- **不作诊断，不作正常与异常判定，不作预后与转归判定；不给处置方案与用药建议。**
- **不把分期当时间表。** 相邻阶段有重叠区域，推进非匀速；归属须结合连续观察。
- **不把四类起点写成互斥抽屉。** 它们相互转化、相互叠加。
- **不把「难治」读成结局。** 它只描述环节性质与调节应答状态。
- **不替缺稿章展开。** 第 8 章（缺血-再灌注）、第 10 章（凝血）在代用底本中无内容，本章只标接缝位置。
- **引文逐字。** 标「教材·疾病学基础·第7章·N.M.K」，核不到就不引。

## 交付物

1. 一句概念定位（中心环节 + 两个限定词各管什么）
2. 一张起点表（主类 + 参与类，不要求唯一）
3. 一个阶段判定（附「代偿还在不在覆盖」的依据，不写时长）
4. 一组微循环四栏（动脉端 / 毛细血管 / 静脉端 / 交换），进展期附相互加强链
5. 一段边界说明（类别不是判定 + 不给阈值 + 处置转介）

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 用时长判阶段 | 遇干预或波动就判不出期 | 只按「代偿还在不在覆盖」判 |
| 把四类起点当互斥项 | 混合情形卡住，且掩盖叠加 | 写「以某类为主、另有参与」 |
| 微循环三段各写一堆现象 | 记不住、说不清推进关系 | 用「同一套环节的三种状态」串 |
| 把「难治」当结局 | 把类别读成判定，越过边界 | 只写环节性质与应答状态 |
| 在机制章里给处置 | 越出资质与章节边界 | 处置交具备资质的人员，本章只给认识框架 |
| 替第 8/10 章补内容 | 造出底本没有的内容 | 只标接缝位置，缺口留账 |

## 与相邻章节的接缝

- 第 7 章（应激）：应激的糖皮质激素环节「维持血管对调节信号的应答能力」，是本章微循环调节的前提；两章共用「环节—代偿—失代偿」的语言，可互相迁移。
- 第 10 章（凝血与抗凝平衡紊乱）：难治期有凝血与纤溶一类环节，但底本无内容，故本课缺稿，本章不展开。
- 第 14 章（肾功能不全）：灌注下降与泌尿系统表现的关系，在第 14 章按器官层展开，本章只在「物质交换」这一栏点到为止。

## 边界

本 Skill 只处理「表现方向 → 概念、起点、阶段与微循环环节」的结构化表达，不涉及数值、判定、处置与临床决策。任何涉及个体的评估与处置须由具备资质的人员依现行规范与机构制度作出。
