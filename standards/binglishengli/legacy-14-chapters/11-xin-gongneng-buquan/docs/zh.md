# 第 11 章 · 心功能不全：泵、代偿与失代偿的类别链

> **MOTTO:** 「心功能不全指心脏泵血功能与循环需求之间的关系发生改变的情形类别」——教材·疾病学基础·第9章·9.3.1（《疾病学基础·第9章·9.3》）
>
> **PROBLEM:** 「心衰」两个字谁都会说，可把它拆开问三句就卡住：是收缩环节还是舒张环节出了问题？是左心还是右心？前向排血不足与后向淤血是两种病还是一个过程的两个面？再问一句「代偿是怎么把心脏自己拖下水的」，多数人只能背出「心肌肥厚」四个字，说不出肥厚为什么最终反而有害——**泵、代偿、失代偿三段，背到第二段就断了**。
>
> **双根因定位:** 环境逼迫（带教查房只问「哪一心、哪一环节、代偿到哪一步」，学生张口就是「心衰」，接不下去；换成问「这个病人的颈静脉与肺部体征分别指向哪一侧」，链条又断在部位与方向之间）+ 知识积累（本章 3 个小节、5403 字的词频结构显示：机能 90 次、机制 51 次、病因 0 次——教材把力气全花在「泵在什么条件下工作」上，病因只给类别；这是分工不是缺陷，但它意味着「环节→代偿→失代偿」这条链必须由学习者自己接上）

## 一、第一句话给的是关系，不是数值

教材讲心功能不全，第一句没有给定义式，而是先把两样东西摆在一起：一边是心脏泵血功能，一边是循环需求。这一句是本章口径的样本——它把「写什么」限定在**关系的类别**上，既不给射血分数，也不给压力与容量，更不给分级。

> 「心功能不全指心脏泵血功能与循环需求之间的关系发生改变的情形类别」——教材·疾病学基础·第9章·9.3.1

这句话里真正要抓的是三个词：

- **关系**：不是「心脏弱」，是「泵的能力」与「需求」之间的匹配状态。同一颗心脏，需求一变，关系就变；所以描述必须带条件。
- **情形类别**：不是某个人的状态，是归类用的格子。类别名回答「属于哪一类环节」，不回答「这个人现在怎么样」。
- **改变**：是过程，不是标签。改变有方向、有起病方式、有受累范围，三样都要交代。

教材随即把这条边界写进正文，而不是写在脚注里：

> 「划分只用于归类，只写类别与关系，不写分级与量化数值」——教材·疾病学基础·第9章·9.3.1

所以本章的每一张表都只能是**类别表**，不能升级成**分级表**。心功能分级那套说法（几级、几度）在本章一次都不出现，只写「急性起病类 / 慢性起病类」这样的类别名。这不是省略，是分工：数值与分级属于数据层，要有来源、有校验、有适用范围，不能由教材顺手给。

## 二、五条划分线索：一张可交叉的坐标

9.3.1 把同一个对象按五条线索各切一遍。五条线索不是五个知识点，是五个提问方向：

| 线索 | 类别 | 用来回答什么 |
|---|---|---|
| 发生环节 | 收缩功能改变类 / 舒张功能改变类 / 两类并存类 | 泵的哪一段出了问题 |
| 起病方式 | 急性起病类 / 慢性起病类 | 改变是在多长时间里显出来的 |
| 受累部位 | 左心受累类 / 右心受累类 / 全心受累类 | 哪一侧心室在承担 |
| 血流方向 | 前向排血不足类 / 后向淤血类 | 表现落在动脉侧还是静脉侧 |
| 诱发类别 | 负荷增加类 / 心肌受损类 / 节律改变类 / 瓣膜功能改变类 | 是什么把泵推到这一步 |

教材对这五条线索加了一句极重要的限定：线索之间可以交叉，同一情形可同时按多条线索归类。这句话的用法是**先分后合**——描述时逐条交代（环节、起病、部位、方向、诱因各一句），分析时再说明它们怎么扣在一起。反过来做（上来就一句「全心衰、慢性、收缩性」）看似完整，其实把五条线索压成了一个标签，后面每一条都追问不下去。

`code/main.js` 会现算：五条线索**同时**出现的小节只有 9.3.1 一个（1 / 3）。这说明底本的写法是「一处写全、其余承接」，读到 9.3.2 与 9.3.3 时，那些线索并没有消失，只是不再重复列举。

## 三、部位与方向：左与右、前与后

五条线索里，最容易混的是部位与方向。教材把它们分开写，并在同一段里给出对应关系：

> 「左心受累类多与肺循环淤血的类别相关，右心受累类多与体循环静脉回流受阻的类别相关」——教材·疾病学基础·第9章·9.3.1

这句话是本章最实用的工具之一。它的方向是**从部位推表现**：左心在后向淤血上落在肺循环，右心落在体循环。反过来也成立——看到肺循环淤血的类别，先想到左心；看到体循环静脉回流受阻的类别，先想到右心。但要注意教材用的是「多与……相关」，是关联类别的表述，不是充分条件。

方向这一条线索则给出另一组格子：前向排血不足类与后向淤血类。教材明确说二者常并存：

> 「二者常在同一情形中并存，其关系可表述为同一功能改变的两个方面」——教材·疾病学基础·第9章·9.3.1

「两个方面」这个说法值得停下来看：它不是「两种病同时存在」，是同一件事的两个观察面。前向看的是组织灌注，后向看的是静脉系统的压力与容量。**同一个人身上，两面同时成立**，描述时不必二选一，但必须分别写清依据来自哪一面。

## 四、代偿的两条时间轴与四个作用部位

9.3.2 换了一个提问方式：泵的能力下降之后，机体靠什么把循环维持在相对稳定的状态。教材给了两套划分，并且说二者互为补充。

> 「代偿环节可按作用途径划分为快速代偿类与长期代偿类」——教材·疾病学基础·第9章·9.3.2

- **快速代偿类**：心率调节类与心脏自身调节类。前者改频率，后者改心肌纤维的初长度与收缩条件。特点是反应快、作用有限。
- **长期代偿类**：心肌肥厚类与心室重构类。前者改心肌细胞体积与结构成分，后者改心室的整体结构（心肌细胞、基质成分、血管成分一起变）。

另一套划分按作用部位给四个格子：心脏自身调节类、神经调节类、体液调节类、组织适应类。两套划分交叉起来看，才看得出本章的骨架：

| 作用部位 | 快速一侧 | 长期一侧 | 代价落在哪 |
|---|---|---|---|
| 心脏自身 | 初长度与收缩条件 | 心肌肥厚、心室重构 | 顺应性与耗氧条件 |
| 神经 | 交感活动增强 | 长期活跃后影响类别改变 | 心肌与血管的负担 |
| 体液 | 血管张力调整 | 肾素—血管紧张素—醛固酮相关类别 | 容量与压力条件 |
| 组织 | 摄氧比例调整 | 代谢方式调整 | 作用慢、效果依组织而定 |

这张表的价值不在记住四行，而在看出**每一行都有代价**。教材在长期代偿那一段直接写明了：

> 「两类改变可提高心脏的工作能力，同时也改变心肌的顺应性与耗氧条件，因而具有代价的性质」——教材·疾病学基础·第9章·9.3.2

## 五、代偿的代价：为什么代偿是失代偿的入口

把 9.3.2 从头读到尾，会发现它的写法是「先给能力、再给代价」，一段一段成对出现。四类代价可以并排看：

> 「快速代偿类以增加心肌耗氧条件为代价，长期代偿类以改变心肌结构与顺应性为代价」——教材·疾病学基础·第9章·9.3.2

血管相关的代偿（血管收缩类、血流重分布类）以改变组织灌注分布为代价；容量相关的代偿（钠水潴留类）以增加心脏负荷为代价。四条代价指向同一件事：**代偿不是免费的修复，是把负担挪到另一个格子里**。

于是代偿与失代偿之间不是两个阶段，而是一条路的两个方向：

> 「代偿改变可转变为新的结构改变类别，进而影响功能状态，形成代偿与失衡之间的相互转化关系」——教材·疾病学基础·第9章·9.3.2

这句话是本章的转折点。它说的是：代偿环节本身会变成新的结构改变（肥厚、重构、间质成分改变），而结构改变又反过来改变功能状态。所以「代偿到哪一步」这个问题，答案不是某个刻度，而是「代偿改变有没有已经变成结构改变类别」。

教材还提醒，代偿环节之间是网络关系而不是链条关系：多个环节常同时参与，方向可能一致也可能互相制约。描述时宜用网络的方式写（哪几个环节在动、彼此怎么影响），不宜写成一条单线因果。

## 六、边界：9.3.3 把「不写什么」写成正文

多数教材把边界放在前言，这一本把它单列一个小节，而且写得比内容还硬。

> 「教材只写类别、环节与关系，不写分级与量化数值，不写指标名称与判定界限」——教材·疾病学基础·第9章·9.3.3

9.3.3 的七条要求可以归成三组：

1. **判断权限**：不作疾病诊断，不作病情与预后的判定，不作疗效的断言；某种活动类别或饮食类别是否属于禁忌范围，同样由具备资质的人员判断。
2. **内容范围**：不替代规范诊疗与用药，不涉药物名称与用药安排，不涉具体处置方式。
3. **表述方式**：中性表述，不贴标签，不对人群作整体评价，不以类别名称暗示轻重次序。

其中判断权限那一条写得很直白：

> 「凡涉及判断的内容，均应由具备资质的人员作出」——教材·疾病学基础·第9章·9.3.3

这一句不是免责套话，它决定了本章的写法：凡是要落到「这个人现在处于什么状态」的问题，本章一律停在类别层面。9.3.3 还补了一句方法上的提醒——不要把边界读成对知识的否定。它写「不写分级与数值」是为了保持类别化叙述的严谨，不是说不存在分级；分级在，只是不在本书里。

```text

   │  五条线索：环节 / 起病 / 部位 / 方向 / 诱因

   │

   │
   ▼
```

## 教材小节：逐条落位

代用底本《疾病学基础》第 9 章对应本章的 3 个小节。这一节把它们逐一落位：每个小节一段，说清这一节在问什么、答案落在哪一层（环节 / 机制 / 代偿）、与相邻小节是什么关系。**没有被主题叙述点到的小节，在这里也必须有位置。**

#### 9.3.1 心功能不全的类别

本节问的是心功能不全按什么线索归类，以及归类之后能说什么、不能说什么。答案落在环节这一层：先按发生环节分出收缩功能改变类、舒张功能改变类与两类并存类，再按起病方式、受累部位、血流方向与诱发类别各切一遍，五条线索可以交叉，同一情形能同时按多条归类。要害是类别名与判断分开：类别名只说明功能改变的环节与范围，与个体处于何种情形并无对应关系，所以叙述时逐条交代线索，不把五条压成一个标签。与下一节的关系是本节给格子、下一节填代偿；与末尾边界一节的关系是本节已写明不写分级与量化数值，那一节把同一条要求写成全章统一口径。词频上本节机能远多于机制与病因，说明底本谈的是工作条件，不是病因归因。

#### 9.3.2 代偿环节的类别

本节问的是泵的能力改变之后，机体靠哪些环节把循环维持在相对稳定的状态，以及这些环节为什么最终会反噬。答案落在代偿与代价这一层：按作用途径分快速代偿类与长期代偿类，按作用部位分心脏自身调节、神经调节、体液调节与组织适应四类，两套划分互为补充。要害是代偿必须连代价一起写：快速一侧增加耗氧条件，长期一侧改变结构与顺应性，血管一侧改变灌注分布，容量一侧增加心脏负荷；四条代价指向同一件事，代偿不是修复，是把负担挪到另一个格子。代偿与失代偿之间因此不是两个阶段，而是同一条路上的两个方向，代偿改变转为结构改变类别，失代偿的条件才成立。与上一节的关系是由类别转入环节，与边界一节的关系是本节的代价表述同样只写关系类别，不写程度与量化内容。

#### 9.3.3 叙述边界要求

本节问的是同一内容在教材里允许写到哪一步，以及为什么边界要单列一节而不是写在前言。答案落在表述规则这一层，可归成三组：判断权限、内容范围与表述方式。判断权限写的是不作疾病诊断、不作病情与预后判定、不作疗效断言，凡涉及判断的内容由具备资质的人员作出；内容范围写的是不替代规范诊疗与用药，不涉药物名称与用药安排；表述方式写的是中性表述、不贴标签、不以类别名称暗示轻重次序。要害是边界属于叙述口径，不是对知识的否定：不写分级与量化数值，是因为数值与分级属于数据层，要有来源与校验，不能由教材顺手给出。与上一节的关系是本节的规则正好扣住代偿的代价表述，与全章的关系是它把前面两节各自写过的「不写数值」收成一套可逐项核对的检查项。
