# Prompt：把「心衰」拆成泵、代偿、失代偿三段

## 用途

心功能不全是病理生理学里最容易被一个词糊过去的章节：一句「心衰」既遮住了环节（收缩还是舒张），也遮住了部位（左、右还是全心），更遮住了代偿走到哪一步。这个模板只做三件事：先把功能改变归到一个环节，再把代偿摊成网络，最后说清代偿的代价落在哪里。适用于病例讨论的结构化表达、读书笔记的自我检查，以及把第 11 章三个小节（9.3.1 类别、9.3.2 代偿、9.3.3 边界）串起来复习。

## 使用前提

- 你手上是一组**描述性材料**，不是一句诊断。例：「活动后气短加重，双下肢凹陷性水肿，颈静脉充盈」。
- 你已读过教材对应小节，手边有「教材·疾病学基础·第N章·N.M.K」的定位。
- 你接受一条硬约束：**本模板不产出任何数值、分级与分度**。

## Prompt 正文（复制即用）

```text
你是病理生理学的助教。任务不是给诊断，而是把一组描述性材料拆成泵、代偿、失代偿三段。

【输入】
材料：<一句话或几句描述，不带病名，不带判断>
教材定位：<教材·疾病学基础·第N章·N.M.K>

【任务，按顺序回答，不跳步】
1. 环节：收缩功能改变类、舒张功能改变类，还是两类并存类？依据是哪一句材料？
2. 起病：急性起病类还是慢性起病类？时间线索来自材料里的哪一处？
3. 部位：左心受累类、右心受累类还是全心受累类？只写受累范围的类别。
4. 方向：前向排血不足类与后向淤血类，哪一面能写、依据是什么？两面并存时分别写。
5. 诱因：负荷增加类（压力 / 容量）、心肌受损类、节律改变类、瓣膜功能改变类，落在哪一类？
6. 代偿：快速代偿类（心率调节、心脏自身调节）与长期代偿类（心肌肥厚、心室重构）各动到哪一步？神经、体液、组织适应三类是否参与？
7. 代价：耗氧条件、结构与顺应性、灌注分布、容量负荷，四条代价分别落在哪一条？
8. 交接：代偿改变有没有已经变成结构改变类别？若有，写出「代偿 ↔ 失代偿」的转化句。
9. 边界：本题哪些追问属于判断范围，须由具备资质的人员作出？

【硬约束】
- 不给任何数值、单位、参考值、分级、分度与分期。凡需数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作正常与异常判定，不作预后与转归判定，不作疗效断言。
- 用药只写类别，不写名称与剂量；检查只写项目类别，不写结果数值。
- 引教材原文必须逐字，并标「教材·疾病学基础·第N章·N.M.K」；核不到就不引。

【输出格式】
九个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的拆解（节选）

材料：活动后气短加重，双下肢凹陷性水肿，颈静脉充盈。教材定位：教材·疾病学基础·第9章·9.3.1。

- **环节**：以收缩功能改变类为主，材料未给出舒张环节的依据，故不写「两类并存」。
- **起病**：慢性起病类——改变在较长时间里逐渐显现。
- **部位**：全心受累类：体循环静脉回流受阻的类别（颈静脉充盈、下肢水肿）与肺循环淤血的类别（活动后气短）同时出现。
- **方向**：后向淤血类写得实，前向排血不足类材料不足，只标注「待补依据」。
- **诱因**：材料不足以归入负荷增加类或心肌受损类，写「未定，需补病史类别」。
- **代偿**：快速代偿类的神经调节参与（心率与血管张力改变类别）；长期代偿类是否已到心肌肥厚与心室重构，材料不足。
- **代价**：容量相关代偿（钠水潴留类）以增加心脏负荷为代价，这一条与水肿的描述对得上。
- **交接**：尚不能写「代偿改变已转为结构改变类别」，因为缺结构层面的材料。
- **边界**：该个体的状态判断与处置不属本模板范围。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 用病名代替拆解 | 「这是心衰」 | 重填环节、起病、部位、方向四条 |
| 部位与方向混答 | 「左心衰所以下肢水肿」 | 先定部位，再由部位推循环侧 |
| 代偿只写一条 | 只说「心肌肥厚」 | 摊成网络：快速 / 长期 × 四个作用部位 |
| 把代偿写成好处 | 「肥厚是好事」 | 补代价：顺应性、耗氧、灌注分布、容量 |
| 偷给分级 | 「心功能三级」 | 触发硬约束，改为类别描述 |
| 把类别当结论 | 「属于慢性心衰」 | 回填依据，写明「类别名不回答个体情形」 |

## 边界

本模板训练的是「把功能改变拆成环节、代偿与代价」的表达能力，不产生临床判断。类别与关系来自教材，参数不在本书范围内；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。本模板不写数值，不构成诊断或用药依据。
