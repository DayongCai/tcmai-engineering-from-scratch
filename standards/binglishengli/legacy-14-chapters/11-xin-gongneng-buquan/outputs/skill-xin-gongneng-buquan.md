# Skill：心功能不全——泵、代偿与失代偿

## 何时用

- 有人（包括你自己）用「心衰」两个字把一段描述糊过去了，需要拆开
- 要在收缩 / 舒张、左 / 右 / 全心、前向 / 后向这几组类别之间来回迁移同一套语言
- 要判断一段描述「越了几层」：把心肌肥厚直接说成失代偿，中间的结构改变被跳过
- 遇到「心功能几级、射血分数多少」这类追问，需要一套一致的拒答口径

## 核心判据（四问）

1. **哪一环节？** 收缩功能改变类、舒张功能改变类，还是两类并存类。环节不明，后面每一条都追问不下去。
2. **哪一部位、哪一方向？** 部位给左 / 右 / 全心，方向给前向排血不足 / 后向淤血。两侧与两面可以并存，必须分别写。
3. **代偿走到哪一步？** 快速代偿类（心率调节、心脏自身调节）还是长期代偿类（心肌肥厚、心室重构）；四个作用部位（心脏自身、神经、体液、组织适应）各自有没有参与。
4. **代价落在哪里？** 耗氧条件、结构与顺应性、灌注分布、容量负荷，四条代价要能指出至少一条。

## 执行步骤

```text
1. 抄材料，不抄病名：写「双下肢凹陷性水肿」，不写「右心衰」
2. 定环节：收缩 / 舒张 / 并存
3. 定起病：急性起病类 / 慢性起病类（只写类别，不写时间数值）
4. 定部位：左 / 右 / 全心
5. 定方向：前向 / 后向 / 两面并存（写明依据来自哪一面）
6. 定诱因：负荷增加类（压力 / 容量）/ 心肌受损类 / 节律改变类 / 瓣膜功能改变类
7. 摊代偿：快速与长期各动到哪一步；神经、体液、组织适应是否参与；按网络写，不写单线因果
8. 指代价：四条代价逐条对照，缺依据的写「未定」
9. 判交接：代偿改变是否已转为结构改变类别——转为结构改变，才谈得上失代偿
10. 划边界：凡属个体判断的追问，一律交回具备资质的人员
```

## 硬约束

- **不给数值、单位、参考值、分级、分度、分期。** 心功能分级只写类别名称，不写等级与刻度；需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不判正常与异常。** 类别能说明「属于哪一类环节」，不能说明「这个人现在是否异常」。
- **引文逐字。** 标「教材·疾病学基础·第N章·N.M.K」，核不到就不引。
- **用药只写类别。** 不写药物名称、剂量与疗程。
- **代偿必须带代价。** 只写「代偿有效」而不写代价，等于把代偿写成了修复。

## 交付物

1. 一条环节结论：收缩 / 舒张 / 并存 + 依据
2. 一条部位与方向结论：左·右·全心 × 前向·后向
3. 一张代偿网络：快速 / 长期 × 四个作用部位
4. 一条代价落点：耗氧 / 顺应性 / 灌注分布 / 容量负荷
5. 一句交接：代偿改变是否已转为结构改变类别
6. 一句边界：本章不给值，判断交回具备资质的人员

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 病名代替拆解 | 描述无法复核 | 重填环节、起病、部位、方向 |
| 部位与方向混答 | 「左心衰所以下肢肿」 | 先定部位，再推循环侧 |
| 代偿只写「肥厚」 | 代偿被写成单线因果 | 摊成网络，写相互影响 |
| 把代偿当好事 | 漏掉失代偿的入口 | 补四条代价 |
| 只答分级 | 「心功能三级」 | 改为类别描述，分级交数据层 |
| 把类别当结论 | 「就是慢性心衰」 | 写明类别名不回答个体情形 |

## 边界

本 Skill 只处理「功能改变 → 环节与代偿」的结构化表达，不涉及数值、判定与临床决策。任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。本 Skill 不写数值，不构成诊断或用药依据。
