# Skill：绪论——四层拆解、六要素与不判定的底线

## 何时用

- 有人（包括你自己）用「他病了」「亚健康」「体质差」这类说法把一段状态糊过去了，需要拆开
- 要在病理生理学（病因 / 机制 / 机能）与病理学（病因 / 机制 / 形态）之间迁移同一套语言时，先确认自己在用哪一套
- 要判断一段叙述有没有把「条件」写成「病因」、把「提示」写成「结论」
- 遇到「这算不算异常」「要不要紧」这类追问，需要一套一致的拒答口径

## 核心判据（四问）

1. **这是哪一层？** 状态（协调能否维持）／因素（外界、内部、条件与诱因）／环节（起始、中间、末端）／判定（诊断、正常与异常、预后与转归、疗效）。四层的语言不同，混写就是越界。
2. **六要素齐了几项？** 病因与条件、机体反应、结构与功能改变、时间与空间分布、功能影响、转归去向。缺哪项写缺哪项，不用形容词补。
3. **任务走到哪一步？** 描述、归类、解释、提示——前三类课程可以承担，第四类只给方向，不作判定。
4. **学科位置对不对？** 前置（解剖、生理、生化）给语言，并列（免疫、病原生物）给类别，分工（临床）给处置。本课程不越到分工那一侧。

## 执行步骤

```text
1. 抄原话，不改写：把要拆的那句话原样放在第一行
2. 定层：状态 / 因素 / 环节 / 判定，四层各写一句，缺的写「未给」
3. 补维度：六要素逐项对，缺项如实标缺，不补猜
4. 归任务：这句话停在描述、归类、解释还是提示？越到提示之后就是判定
5. 查位置：涉及的因素属外界 / 内部 / 条件与诱因，三者不互换
6. 中性改写：删掉判定成分，只留状态与关系，保留观察时点
7. 报边界：不写数值，不作诊断，不给转归判断
```

## 硬约束

- **不给数值、单位、正常值、参考区间、百分比。** 需要数值才能回答的追问，统一回「本书不给值，需另立数据层（另立来源与校验）」。
- **不作诊断，不作正常与异常判定。** 「健康」与「疾病」在本课程里只作状态类别，不用于给任何个体定性。
- **引文逐字。** 标「教材·疾病学基础·第N章·N.M.K」；核不到就不引。底本是代用底本，不许写成「教材·病理生理学」。
- **不贴标签。** 状态可以写，评价不写；不因某一状态对个体作贬抑性描述。
- **层次必标。** 同一句话里不许同时装两个层面的内容（个体状态与人群分布、局部环节与整体状态）。

## 交付物

1. 一段四层拆解（状态 → 因素 → 环节 → 判定），缺层如实标缺
2. 一张六要素对照：齐了哪几项、缺哪几项
3. 一句任务定位：这句话停在描述、归类、解释还是提示
4. 一段中性改写：删掉判定成分后的版本，保留观察时点
5. 一处边界：本章不给值、不作诊断，数值须另立数据层

## 典型误用

| 误用 | 后果 | 纠正 |
|---|---|---|
| 用病名替代状态 | 「这是某某病」当成描述 | 回到「协调能否维持」，只写状态类别 |
| 条件写成病因 | 「熬夜导致他生病」 | 条件写影响关系：影响是否容易发生 |
| 提示写成结论 | 「基本可以确定」 | 提示只给方向，删掉确定语气 |
| 六要素当清单 | 六项逐条打勾就算描述完整 | 六项是勾连的关系，前项为后项的条件 |
| 学科位置错位 | 在基础课里给处置建议 | 处置属分工一侧，交回临床与规范 |
| 被追问就报数值 | 越出本书口径，且数值无来源 | 统一回「本书不给值，另立数据层」 |

## 与相邻章节的接缝

- 下一章（疾病概论）：本章的「因素」在那里展开成外界因素、内部因素、条件与诱因三节；本章的「环节」在那里展开成损伤与抗损伤、因果交替、局部与整体三组规律。
- 与病理学的分工：病理学（`10-bingli-xue`）讲形态，本课程讲机制与机能。同一份材料，前者问「长成什么样」，后者问「哪一环失调」。
- 再往后（水电解质、酸碱、缺氧、发热、休克）：那些章讲的都是「环节」，本章的分层若不先立住，环节会被写进结论的位置上。

## 边界

本 Skill 只处理「一句话 → 四层 → 中性表述」的结构化拆解，不涉及数值、判定与临床决策。分类框架取自代用底本《疾病学基础》第 1 章的类别与关系；任何涉及个体的评估须由具备资质的人员依现行规范与机构制度作出。
