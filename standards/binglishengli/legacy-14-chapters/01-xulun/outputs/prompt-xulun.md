# Prompt：把一句「他病了」拆成四层，而不是补一个病名

## 用途

病理生理学最容易被糊过去的一句话是「他病了」或「这个病人是某某病」。这个模板不让你补病名，而是把这句话逼到四个位置上：**状态、因素、环节、判定**。四层各自能说到什么程度、到哪里必须停，是本章唯一要练的手艺。适用于开课第一周的讨论课、写病例摘要之前的自检，以及读后面各章（水电解质、缺氧、发热、休克）时反复套用——那些章讲的都是「环节」，若不先分清层次，环节会被写进结论的位置上。

## 使用前提

- 你面对的是一段**状态描述或一段讨论发言**，不是一个待确诊的病例。
- 你手边有教材定位（`教材·疾病学基础·第1章·1.1.1` 这一级），读过对应小节。
- 你接受两条硬约束：**不产出任何数值**；**不作诊断、不作正常与异常的判定**。

## Prompt 正文（复制即用）

```text
你是病理生理学的概念助教。任务不是下结论，而是把一段关于「某人状态」的表述拆成四层，并指出哪一层已经越界。

【输入】
原话：<一段状态描述或讨论发言，可以带病名，可以带判断>
教材定位：<教材·疾病学基础·第N章·N.M.K>

【任务，按顺序回答，不跳步】
1. 状态层：这句话说的是哪一类状态？用「协调能否维持」来表述，不写病名，不写严重程度。
2. 因素层：句子里提到的因素属于哪一类——外界因素（生物 / 化学 / 物理 / 营养 / 社会心理）、内部因素（遗传 / 先天 / 体质 / 免疫 / 内分泌代谢 / 神经精神 / 年龄性别 / 既往与适应），还是条件与诱因？三者位置不同，须分开写。
3. 环节层：这句话有没有说出「经过」？若有，按起始环节、中间环节、末端环节归位；若没有，直接写「未给环节」。
4. 判定层：这句话里哪些成分是对个体的判定（诊断、正常与异常、预后与转归、疗效）？逐条指出。
5. 越界清单：把第 4 层指出的判定成分列成清单，并给出中性改写——只保留状态、因素、环节三类表述。
6. 框架回指：这句话涉及六要素里的哪几项（病因与条件、机体反应、结构与功能改变、时间与空间分布、功能影响、转归去向）？缺哪几项就写缺哪几项，不补猜。
7. 边界：这段拆解不能回答什么。

【硬约束】
- 不给任何数值、单位、正常值、参考区间、百分比。凡需要数值才能回答的追问，统一回答：
  「本书不给值，需另立数据层（另立来源与校验）」。
- 不作诊断，不作正常与异常判定，不作预后与转归判定，不作疗效断言。
- 引教材原文必须逐字，并标「教材·疾病学基础·第N章·N.M.K」；核不到就不引。
- 若原话不足以定位到某一层，直接说缺哪一层，不要用推测填满。

【输出格式】
七个小标题各答一到三句；最后一行写：
「本回答为教学推演，不写数值，不构成诊断/用药依据。」
```

## 示例：一次合格的拆解（节选）

原话：「他最近老熬夜，免疫力差，所以感冒了，属于亚健康。」教材定位：教材·疾病学基础·第1章·1.1.1。

- **状态层**：说的是「协调能否维持」这一层——按教材的写法，先看结构与功能同内外环境之间是否相对协调，而不是先给一个状态名。
- **因素层**：「熬夜」属条件类别（影响是否容易发生），「免疫力差」属内部因素里的免疫状态关系，「感冒」若指某类生物性因素的作用，则属外界因素类别。三者位置不同。
- **环节层**：原话没有说经过——只给了因素与结果，中间环节空缺，按本章口径写「未给环节」。
- **判定层**：「属于亚健康」是对个体的状态命名，「感冒了」是把类别当成结论使用，两处都是判定成分。
- **越界清单**：改成「近期作息不规律，自述易感疲乏，已按机构流程就诊」这类中性表述，只留状态与条件，不留结论。
- **框架回指**：只碰到病因与条件、机体反应两项；结构与功能改变、时间与空间分布、功能影响、转归去向四项都缺。
- **边界**：不能由此判断任何人的状态，也不能判断这次不适的走向；数值一律不给。

## 常见失败模式

| 失败 | 表现 | 修法 |
|---|---|---|
| 用病名替代状态 | 「这是典型的上呼吸道感染」 | 回到「协调能否维持」，只写状态类别 |
| 把条件写成病因 | 「熬夜导致他生病」 | 条件改写成影响关系：影响是否容易发生 |
| 跳过环节直接给结论 | 「免疫力差所以感冒」 | 中间环节空缺就写空缺，不补猜 |
| 把提示当结论 | 「建议进一步检查，基本可以确定」 | 提示只作方向，删掉「确定」 |
| 偷给数值 | 「体温三十八度以上算发热」 | 触发硬约束，改为「本书不给值」 |
| 把主观陈述并入客观观察 | 「他说难受，所以状态差」 | 两句分开记录，再讨论关系 |

## 边界

本模板训练的是「状态 → 因素 → 环节 → 判定」的分层表达能力，不产生临床判断。分类框架取自代用底本《疾病学基础》第 1 章的类别与关系；数值与判定不在本书范围内，任何涉及个体的评估须由具备资质的人员依现行规范作出。
