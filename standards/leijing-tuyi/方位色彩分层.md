## 五、配色判定：这套调色板能不能解释源实现的 DSU 配色

把 116 个 DSU 色当作点，量它们到本调色板（14 个实色 + 91 条两两插值线段）的距离。

**对照必须用「同规模随机调色板」，不能用随机点**：本调色板的插值线段覆盖了很大一片 RGB 空间，
拿孤立的随机点当基线，任何调色板都会显得「更近」—— 那是流形大，不是信号。

| 指标 | 数值 |
| --- | :-: |
| DSU 色数 | 116 |
| 调色板 | 14 实色 + 91 条插值线段 |
| DSU 色到本调色板 · 均值 | 16.31 |
| DSU 色到本调色板 · 中位 | 14.46 |
| DSU 色到本调色板 · 最小 | 0 |
| 同规模随机调色板（2000 个）· 均值 | 19.49 |
| 本调色板优于多少随机调色板 | **63%** |
| 精确命中调色板实色的 DSU 色 | 0 / 116 |

结论：**不能解释**：DSU 色到本调色板的距离并未显著优于同规模随机调色板（优于 63%），「类经图翼方位色就是源配色」不成立。

### 这条结论否定了什么、没有否定什么

**否定**：「类经图翼的方位色可以用来复现源实现的 DSU 配色」。
本调色板只优于 63% 的同规模随机调色板 —— 与随机无异。
因此**它解不开** `standards/semtensor/` §14.1 的颜色公理悬案。

**没有否定**：这套规范本身的价值。它是一份独立、自洽、有出处的
「语义范畴 → 方位 → 传统色 → 球面层」规定，可用于本仓库自己的三球呈现。
它只是**不能**被当作源配色的解释。

### 第一版为什么得出相反结论（留档）

第一版拿「随机点」当基线，得出 DSU 色均值 16.31 对随机点均值 43.71，
比值 0.369，看起来是「显著更近」。**那是假信号**：14 实色 + 91 条插值线段的流形本身
就覆盖了大片 RGB 空间，任何点离它都不会太远。换成同规模随机调色板对照后，差异消失。

> 教训：**对照要选对**。选错对照，会得到一个看起来很漂亮、但完全不成立的结论 ——
> 而且它和真结论一样带着小数点和百分比，光看数字分辨不出来。
