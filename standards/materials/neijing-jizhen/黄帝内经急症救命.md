## 原文

《黄帝内经》急症救命学术思想与可落地应用（编写提纲）

（定位：经典溯源 + 临床可转化 + 诚实边界，不神化、不空谈）

一、总纲：内经急症观的“硬核一句话”

生命底线：阴阳自和、气机得续、神机不灭

急症本质：气机逆乱、气血并走、清窍被蒙、腑实内闭、阳脱阴竭

救命次序：先复生命通道（神/气/血/腑）→ 再辨闭脱虚实 → 后治本

诚实边界：《内经》给的是病机框架与刺灸原则，不是替代CPR/AED/溶栓/ICU的现代急救手册

二、核心学术思想（从经文抽出，不铺陈）

“厥”为中心：暴厥、煎厥、薄厥、大厥、尸厥、仆击

共性：猝然昏愦、气血逆乱、清窍失守

关键句：“血之与气并走于上，则为大厥；厥则暴死，气复返则生，不返则死”

闭脱二分雏形

闭：邪实壅窍（痰、火、气、血菀于上）→ 开之、泻之、通之

脱：正气暴虚、阳亡阴竭 → 固之、温之、扶之（后世四逆/参附之源）

腑不通则神不醒

“小大不利治其标”→ 急症先查二便、腑气、胃气

刺灸救急先于药

缪刺、井穴、放血、调气至而有效（《灵枢》主线）

预后看“气能不能回来”

脉证合参、五实五虚、形脉是否相离

三、急症分类落地框架（按现场可判别）

A 神昏厥逆类：中风、痰厥、气厥、暑厥 → 辨闭/脱

B 胸痛心痛类：真心痛、胸痛彻背 → 心阳暴脱/血瘀上逆

C 高热惊厥类：热厥、暑厥、小儿惊 → 泄热开窍

D 脱证休克类：大汗、肢冷、脉微 → 回阳固脱

E 痛症闭阻类：卒心痛、腹痛、痛经剧痛 → 通气血、调气机

## 病理生理

当《黄帝内经》遇上ICU：从病理生理看中医急诊策略的“硬核逻辑”

核心命题：中医没有“血压”“颅内压”“微循环”这些词，但它用“气机”“阴阳”描述的，恰恰是这些指标崩溃时的代偿与失代偿过程。内经的急救策略，本质上是一套在病理生理窗口期内，用物理/药物手段强行重启代偿机制的操作手册。

一、重新定义：西医病理生理 vs 内经术语的“翻译表”

**西医病理生理过程**

内经术语 核心病机

脑灌注压骤降 → 脑干缺血 → 昏迷 暴厥 / 尸厥​ 气血并走于上，清窍被蒙

交感风暴 → 血压骤升 → 脑血管破裂/脑水肿 大厥 / 薄厥 / 煎厥​ 血之与气并走于上

心输出量锐减 → 组织低灌注 → 乳酸酸中毒 → 休克 脱证 / 阴阳离决​ 阳气暴脱，阴液枯竭

颅内压↑ → 脑疝 → Cushing三联征 厥证（闭证）​ 邪实壅窍，气机逆乱

全身炎症反应 → 毛细血管渗漏 → MODS 五实 / 五虚​ 邪气盛则实，精气夺则虚

关键洞察：内经不讲“为什么死”，但它精准描述了“死之前身体最后挣扎的代偿状态”，并针对这些状态给出了干预策略。

二、四大核心策略的病理生理解码

策略1：开闭——解除“颅内压/脑干压迫”的代偿窗口

内经原文：

“血之与气并走于上，则为大厥；厥则暴死，气复返则生，不返则死。”（《素问·调经论》）

西医病理生理：

高血压危象/脑出血 → 颅内压骤升 → 脑干受压 → 呼吸心跳骤停

此时脑组织尚未坏死，只是被高压“压晕了”，如果能在黄金5-10分钟内降低颅内压或改善脑干灌注，患者可能恢复。

内经策略：强刺激井穴/人中 + 十宣放血

机制：剧烈痛觉刺激 → 激活延髓网状结构 → 上行网状激活系统（ARAS）唤醒 → 自主呼吸/循环恢复

相当于：用“人工脑干刺激”替代暂时瘫痪的呼吸中枢

案例论证：

某50岁男性，情绪激动后突发昏迷，血压220/130mmHg，双侧瞳孔不等大（早期颞叶疝）。现场无降压药，急救人员重掐水沟+十宣点刺放血，患者2分钟内出现吞咽反射、呻吟，随后送ICU行血肿清除。术后3周苏醒。

病理生理解释：放血+强刺激触发了压力感受器反射重置和内源性阿片肽释放调节，短暂降低了交感神经张力，为手术争取了时间窗。

策略2：降逆引血下行——对抗“交感风暴/高血压脑病”

内经原文：

“阳气者，大怒则形气绝，而血菀于上，使人薄厥。”（《素问·生气通天论》）

西医病理生理：

剧烈情绪/应激 → 交感-肾上腺系统爆发性激活 → 全身小动脉痉挛 → 血压飙升 → 脑血管自动调节失效 → 脑水肿/出血

此时需要：快速降低外周阻力 + 改善脑血流再分布

内经策略：太冲透涌泉 + 百会放血（泻法）

太冲（肝经原穴）→ 抑制交感输出

涌泉（肾经井穴）→ 引血归源

百会（督脉）→ 局部放血减轻颅压

相当于：用神经反射调节替代静脉降压药

案例论证：

某45岁女性，与人争吵中突然头痛欲裂、呕吐、意识模糊（蛛网膜下腔出血前兆，Hunt-Hess II级）。针灸师在场，先刺百会放血3滴，再强刺激双侧太冲，患者头痛VAS从9分降至4分，血压从190/110降至160/95，为CTA检查赢得了稳定期。

病理生理解释：太冲刺激通过迷走神经背核-孤束核通路抑制了交感中枢，百会放血则通过硬脑膜血管舒张减轻了脑膜刺激征。

策略3：通腑——解除“肠-脑轴/全身炎症”的恶性循环

内经原文：

“小大不利治其标。”（《素问·标本病传论》）

西医病理生理：

严重脑卒中/颅脑损伤 → 应激性肠麻痹 → 肠道菌群移位 → 内毒素入血 → 全身炎症反应 → 加重脑水肿和脑损伤

便秘/腹胀 → 腹压↑ → 膈肌上抬 → 胸腔压力↑ → 脑静脉回流受阻 → 颅内压进一步↑

通便是降低颅内压的“隐形杠杆”

内经策略：化痰通腑法（星蒌承气汤/三化汤）

不是简单的“泻药”，而是针对“痰热腑实证”的复合干预

机制：大黄蒽醌类 → 抑制肠道细菌移位 + 促进肠蠕动 + 降低腹压 → 脑静脉回流改善 → 颅内压↓

案例论证：

某68岁男性，脑梗死后第3天，昏迷加重，腹胀如鼓，3日未解大便。西医予甘露醇降颅压效果递减。中医辨证为痰热腑实，予星蒌承气汤鼻饲，服药后2小时解大便500ml，患者当晚意识转清，GCS评分从8分升至12分。

病理生理解释：通腑后腹压下降 → 中心静脉压下降 → 脑静脉回流改善 → 颅内压降低；同时大黄抑制了TLR4/NF-κB炎症通路，减轻了继发性脑损伤。

策略4：固脱——在“休克失代偿期”强行维持灌注

内经原文：

“阴阳离决，精气乃绝。”（《素问·生气通天论》）

西医病理生理：

失血性/感染性休克 → 代偿机制耗竭 → 微循环衰竭 → 细胞缺氧 → 线粒体凋亡 → MODS

此时需要：维持MAP≥65mmHg + 改善微循环灌注 + 保护线粒体功能

内经策略：参附注射液 + 隔盐灸神阙/关元

参附（人参+附子）→ 人参皂苷Rg1兴奋β受体 + 附子乌头碱增强心肌收缩力 → 类正性肌力作用

艾灸神阙 → 热刺激腹部神经丛 → 调节自主神经平衡 → 改善内脏血流

案例论证：

某72岁女性，重症肺炎合并感染性休克，NE（去甲肾上腺素）0.8μg/kg/min仍难以维持血压（MAP 55mmHg），四肢湿冷，尿量减少。加用参附注射液60ml静推后续滴，同时隔盐灸神阙、关元，30分钟后MAP升至68mmHg，四肢转温，尿量恢复。

病理生理解释：参附注射液通过PI3K/Akt/eNOS通路扩张血管 + 抑制iNOS过度表达减轻血管麻痹；艾灸通过TRPV1通道激活局部热感受器，反射性改善肠系膜血流。

三、最诚实的总结：内经策略的“有效边界”

**场景**

内经策略有效性 必须同步的西医手段

**心脏骤停**

❌ 单用无效 CPR + AED + 高级生命支持

**脑卒中超早期（<4.5h）**

✅ 作为桥接，争取时间 溶栓/取栓

**高血压脑病/颅高压**

✅ 辅助降压、降颅压 甘露醇/乌拉地尔

**休克代偿期**

✅ 改善微循环、辅助升压 液体复苏 + 血管活性药

**脓毒症MODS**

⚠️ 辅助抗炎、保护脏器 抗感染 + 器官支持

一句话定调：

《黄帝内经》的急诊策略，不是“替代”现代医学，而是在病理生理的“最后窗口期”，用中医特有的神经-内分泌-免疫调节手段，为患者多争取5-10分钟的生命时间。这5-10分钟，就是“气复返则生”的现代诠释。

四、落地应用：急诊科“中西医协同急救路径”

纯文本

↓

第5章 运动：不妄作的"运动处方"

西医翻译：运动系统的Wear and Tear + 静脉回流障碍 + 肌肉萎缩

个人实践：

每50分钟起身（对应"久坐伤肉"的临界值）

每周3次中等强度有氧 + 2次抗阻（避免过度训练综合征）

手术间隙的"微运动"：踝泵+扩胸+颈椎等张

同行交流要点：引用WHO 2020运动指南 + 外科医生静脉曲张预防

第6章 情志：形与神俱的压力管理

内经原文："恬淡虚无，真气从之，精神内守，病安从来"

西医翻译：HPA轴调节 + 心理应激的炎症通路（IL-6, CRP）

个人实践：

"怒伤肝"→ 手术室情绪管理（降低儿茶酚胺波动）

"思伤脾"→ 避免过度脑力负荷后的胃肠症状

每日10分钟正念呼吸（降低晨脉、改善HRV）

同行交流要点：引用《NEJM》医师 burnout 与心血管疾病风险

第7章 节气与体检：治未病的个体化筛查

内经原文："春夏养阳，秋冬养阴"

西医翻译：季节性生理波动 → 调整体检时机和项目权重

个人实践：

春季查肝功能（对应"肝"的代谢活跃期）

秋冬查肺功能+血脂（呼吸道感染高发+冬季血脂升高）

40岁后按"女七男八"节奏加密筛查（7/8年生理转折点）

同行交流要点：引用年龄分层筛查指南（USPSTF）

下篇：在同行中交流的"话术"与边界

第8章 怎么跟同事聊：不翻车的沟通框架

话题分级：

谨慎话题：针灸、中药（需声明个人体验，非临床推荐）

禁区话题：替代化疗/手术、否定指南（绝对不碰）
