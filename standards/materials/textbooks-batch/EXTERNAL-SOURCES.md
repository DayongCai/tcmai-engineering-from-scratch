# [textbooks] 外源补录约定与 25 门缺口分级

> 本文件是**约定**，不是素材。先立规则，再落正文；每条外源都必须能回到一份留档 + 一个 sha256。
> 生成物：`external-registry.json`（出处账本）、`external/<id>/source.{html,txt,simplified.txt}`（留档）、
> `textbooks/<dept>/<subject>/`（外源正文层，`layer: external-source`）。
> 复核：`node scripts/fetch_external_textbooks.js --check` ·
> `node scripts/import_external_textbooks.js --check` ·
> `node scripts/build_textbook_board.js --check`

## 一、为什么需要外源

底本 = 桌面 `textbooks/qhzy-*.xlsx` 共 100 份（27.7 M 字），抽取成 99 门学科 + 1 门手工整理层。
`08-wuguan`（五官口腔系）与 `04-gushang`（骨伤系）合计 25 门学科**在底本里根本没有源件** ——
不是抽取失败、不是漏扫，是源里没有。实测：registry 100 份工作簿 ↔ 学科映射 101 条，两者都不含这 25 门。

补源不是「把缺的填满」。判断标准只有一条：**有没有可核验的源**。

## 二、硬规则（与底本同一套，另加四条）

1. **只收公有领域古籍的文字化本**（清代及以前刊本 / 四庫全書本）。现代教材、论文、商业题库一律不收。
2. **留档不可变**：原始页面按字节存 `source.html`，登记 `sha256` + 字节数 + 抓取时间；网页改版即 `--check` 报错，不静默漂移。
3. **外源单独成库**：不进 `registry.json`（底本的出处账本），看板里「底本 / 外源」两列分账；
   任何汇总数字若把外源并进底本，视为口径错误。
4. **引用标注**：引外源须标「**外源·笈成·&lt;书名&gt; 第N条**」，**不得**标「底本」。章首块自带 sha256 前 16 位。
5. **繁→简只做字形**：用 `opencc t2s`（`scripts/convert_t2s.py`），不做地区词替换、不改字词、不改病名；
   繁體原文同时留档，任何人可复算。
6. **覆盖边界写在教材里**：外源章只覆盖「古籍能对上的部分」，不含现代检查、手术、评定量表、器械参数；
   这一点写进每门学科的 `00-前言.md`，不是写在台账里就算完。

## 四、口径与现状（可复算）

| 指标 | 底本 | 外源 | 合计 |

> 补完 A 层（7 门）只把覆盖率从 58.6% 推到 62.9%（+4.3 pt）。
> **25 门全补满也只有 74.0%** —— 因为还有 62 门缺口在别的院系（智能 13、管理 10、针灸 6、中药 5、护理 4…）。
> 任何「补完 A 就是 88%」的说法都是算错的，本表按学时逐项相加。

## 五、已知限制（写在明处）

1. **外源不是现代教材体例**：没有 N.1–N.5 五节契约，改写层（尤其 N.3「这个翻译丢掉了什么」）仍是空的。
2. **章数多于课时**：古籍按「证/部位」分篇（如《外科心法要诀》381 篇），教学计划 10 章，
   教材章数与教学章数不是一回事，看板分两列（`外 381/10`），不要互相替代。
3. **页面会变**：笈成站点改版会改变字节，`--check` 会报 sha256 漂移；重抓须同时更新 `external-registry.json` 并记 CHANGELOG。
4. **底本缺口的统计不变**：`textbooks/README.md` 与看板的「底本」列仍是 100 门 / 1,622 章，外源不参与。
5. **异体字**：古籍原字（如「痎」「痄」「齶」）保留，检索层需要另行归一（同底本的处理方式）。

## 六、复核

```bash
node scripts/fetch_external_textbooks.js --list     # 7 部书的抓取状态
node scripts/fetch_external_textbooks.js --check    # 留档 sha256 与账本一致
node scripts/import_external_textbooks.js --check   # 章文件 ↔ 留档逐章对账（章数/标题/指纹）
python scripts/convert_t2s.py --check               # 繁→简依赖与三探针自检
node scripts/build_textbook_board.js --check        # 看板 / SCHEDULE.md / JSON 不漂移
```
