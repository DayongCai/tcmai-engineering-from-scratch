Chapter 1 — Introduction to Artificial Intelligence in Medicine

总学时：14 学时

1.1 What is Artificial Intelligence

学时：6 学时

1.1.1 Definition, History, and Core Concepts

学时：3 学时

正文内容：

Artificial Intelligence (AI) is broadly defined as the capability of a machine to imitate intelligent human behavior. In medicine, AI refers to computational systems that perform clinical tasks requiring reasoning, pattern recognition, and decision-making traditionally executed by physicians, nurses, and allied health professionals.

Historical milestones​ critical to medical AI include:

1959: Ledley and Lusted publish "Reasoning Foundations of Medical Diagnosis" in Science, establishing the first formal framework for applying Boolean logic and probability theory to differential diagnosis.

1976: The MYCIN rule-based expert system at Stanford demonstrates automated antibiotic selection with performance matching infectious disease fellows.

2012: AlexNet breakthrough in ImageNet competition catalyzes deep learning adoption in medical imaging.

2018–2024: Transformer architecture and foundation models (GPT, Med-PaLM, Llama-Med) enable zero-shot clinical reasoning and multimodal medical understanding.

Core concepts​ every medical AI student must master:

**Concept**

Definition Medical Example

**Algorithm**

Step-by-step procedure for calculation Apgar score calculation

**Model**

Mathematical representation of a process Logistic regression for readmission risk

**Training**

Parameter optimization on labeled data Tuning CNN weights on chest X-rays

**Inference**

Applying trained model to new cases Real-time ECG arrhythmia detection

**Generalization**

Performance on unseen patient populations Model trained at Hospital A working at Hospital B

Key distinction: AI ≠ Machine Learning ≠ Deep Learning. AI is the umbrella; ML is a subset using data-driven pattern learning; DL is a subset of ML using multi-layer neural networks. In 2026, most deployed medical AI systems are ML-based, with DL dominating imaging and NLP domains.

1.1.2 Brief History of AI in Healthcare

学时：3 学时

正文内容：

The history of medical AI divides into five distinct eras:

Era I — Symbolic AI (1950s–1980s): Rule-based systems (MYCIN, INTERNIST-1, DXplain) encoded physician knowledge as IF-THEN rules. Strengths: interpretable, auditable. Weaknesses: brittle, unable to handle uncertainty, knowledge acquisition bottleneck.

Era II — Machine Learning Emergence (1990s–2000s): Statistical methods (naive Bayes, SVM, random forest) replace hand-crafted rules. The UCI Machine Learning Repository and early EHR datasets enable data-driven modeling. Key paper: Kononenko (2001) "Machine Learning for Medical Diagnosis" reviews 20 years of progress.

Era III — Deep Learning Revolution (2012–2018): Convolutional neural networks achieve radiologist-level performance in diabetic retinopathy screening (Gulshan et al., 2016, JAMA), skin cancer classification (Esteva et al., 2017, Nature), and pathology slide analysis. FDA clears first deep learning device (Arterys Cardio DL, 2017).

Era IV — Foundation Models (2019–2023): Transformer-based architectures (BERT, GPT) pretrained on massive corpora enable transfer learning. BioBERT, ClinicalBERT, and PubMedBERT specialize in biomedical NLP. Multimodal models begin fusing imaging, text, and genomics.

Era V — Agentic & Embodied AI (2024–2026): LLM-powered clinical agents (Hermes, OpenMAIC) orchestrate multi-step reasoning, tool use, and human-AI collaboration. Embodied AI enters surgical robotics and rehabilitation. Regulatory frameworks (FDA AI/ML SaMD Action Plan, EU AI Act) mature.

Critical lesson: Each era overpromised and underdelivered initially, then found narrow, high-value niches. Current era's challenge is safe, equitable, generalizable deployment​ — not algorithmic novelty.

1.2 Why Medicine Needs AI

学时：5 学时

1.2.1 Clinical Burden, Data Explosion, and Precision Medicine

学时：3 学时

正文内容：

The clinical burden crisis: Global physician shortage projected at 10 million by 2030 (WHO). In China alone, the physician-to-population ratio lags high-income country averages by 40%. Workload: radiologists interpret one image every 3–5 seconds during an 8-hour shift; primary care physicians manage 20+ patients daily with 11.4 minutes per encounter on average.

Data explosion: A single patient generates approximately 80 MB of EHR data annually (imaging excluded). A 1,000-bed hospital produces 50 PB over 5 years. Data modalities include:

Structured: lab values, vital signs, billing codes

Semi-structured: clinical notes, discharge summaries

Unstructured: free-text radiology reports, pathology descriptions

Imaging: X-ray (≈20 MB), CT (≈500 MB), whole-slide pathology (≈5 GB)

Genomic: whole-genome sequencing (≈200 GB per patient)

Human cognition cannot scale to this volume. AI excels at pattern extraction from high-dimensional, multimodal data​ — the defining challenge of 21st-century medicine.

Precision medicine imperative: The "one-size-fits-all" paradigm fails for heterogeneous diseases. Oncology exemplifies this: two patients with "lung adenocarcinoma" may have entirely different driver mutations (EGFR, ALK, KRAS, PD-L1), requiring distinct targeted therapies. AI enables:

Genomic subtype discovery from transcriptomic data

Pharmacogenomic dosing optimization

Radiomics: extracting quantitative features from medical images invisible to the naked eye

Digital pathology: cellular-level tumor microenvironment characterization

Case study: DeepMind's AlphaFold2 (2021) predicts protein structures with atomic accuracy, accelerating drug discovery from years to days. This exemplifies AI's role in precision medicine infrastructure, not just diagnosis.

1.2.2 Opportunities and Limitations

学时：2 学时

正文内容：

Opportunities across the care continuum:

**Domain**

AI Application Impact

**Screening**

Automated diabetic retinopathy detection 10× throughput increase

**Diagnosis**

Chest X-ray triage 30% reduction in time-to-treatment

**Prognosis**

Sepsis prediction (4-hour lead time) 20% mortality reduction

**Treatment**

Radiation therapy planning 60% time savings for dosimetrists

**Monitoring**

Continuous ECG arrhythmia detection 95% sensitivity for AFib

Population health Risk stratification for intervention 15% reduction in preventable admissions

Fundamental limitations​ (must be understood, not dismissed):

1. Data quality dependency: "Garbage in, garbage out" applies doubly in medicine. Label noise, selection bias, and missingness plague medical datasets.

2. Black-box interpretability: Deep neural networks offer limited insight into decision rationale — unacceptable for high-stakes clinical decisions without explainability layers.

3. Generalization failure: Models trained on one demographic (e.g., U.S. academic centers) often fail on others (e.g., rural Chinese hospitals, pediatric populations).

4. Regulatory lag: FDA clearance cycles (12–24 months) lag AI development velocity.

5. Ethical hazards: Algorithmic bias can amplify health disparities; privacy breaches expose sensitive patient data.

The "AI will replace doctors" myth: AI augments, not replaces. The physician's role evolves from information processor to AI supervisor, contextual interpreter, and empathetic communicator. The stethoscope analogy: invented in 1816, never replaced the physician — transformed the practice.

2.1 Linear Algebra and Calculus

学时：5 学时

2.1.1 Vectors, Matrices, and Gradients

学时：3 学时

正文内容：

Linear algebra​ is the language of medical AI data representation.

Vectors: A patient's clinical state is a vector x​ ∈ ℝⁿ:

x​ = [age, BMI, systolic BP, glucose, WBC count, ...]

Distance metrics (Euclidean, Manhattan, cosine) quantify patient similarity → clustering, k-NN diagnosis.

Matrices: Medical datasets are matrices X​ ∈ ℝ^{m×n}:

m patients (rows), n features (columns)

Image data: a 224×224 grayscale image is a matrix; RGB adds a channel dimension → tensor X​ ∈ ℝ^{224×224×3}

EHR time-series: each admission is a matrix of time steps × variables

Key operations:

**Operation**

Medical Relevance

Matrix multiplication Feature transformation, layer output in neural networks

Eigenvalue decomposition Principal Component Analysis (PCA) for dimensionality reduction of genomic data

Singular Value Decomposition (SVD) Denoising medical images, collaborative filtering for treatment recommendation

Tensor operations Multimodal fusion (imaging + text + genomics)

Calculus — gradients and optimization:

Gradient​ ∇f(x) points in the direction of steepest increase of loss function

Gradient descent: θ_{t+1} = θ_t − η∇L(θ_t) — the universal learning algorithm

Chain rule​ (backpropagation): enables training deep networks by decomposing complex derivatives

Partial derivatives: each model parameter's contribution to prediction error

Medical example: In radiation therapy optimization, gradient descent adjusts beam angles and intensities to minimize dose to healthy tissue while maximizing tumor coverage.

2.1.2 Optimization Basics

学时：2 学时

正文内容：

Optimization​ is the engine of machine learning: find parameters θ​ that minimize a loss function L(θ).

Loss functions in medical AI:

Binary cross-entropy: for disease presence/absence (pneumonia on X-ray: yes/no)

Categorical cross-entropy: for multi-class diagnosis (10 skin lesion types)

Mean squared error: for continuous prediction (length-of-stay, lab value forecasting)

Dice loss: for medical image segmentation (overlap between predicted and ground-truth tumor boundary)

Focal loss: addresses class imbalance (rare diseases vs. common findings)

Optimization algorithms:

**Algorithm**

Key Idea When to Use

**Gradient Descent**

Full-batch update Small datasets

**Stochastic GD**

Single-sample update Large datasets, online learning

**Mini-batch SGD**

Batch of 32–256 Standard for deep learning

**Adam**

Adaptive learning rates per parameter Default for most medical AI

**AdamW**

Adam + weight decay Prevents overfitting on small medical datasets

**L-BFGS**

Quasi-Newton, no hyperparameter tuning Small-data classical ML

Challenges in medical optimization:

Class imbalance: 95% negative / 5% positive → model learns to always predict negative. Solutions: class weighting, focal loss, SMOTE oversampling.

Non-convex landscapes: deep networks have many local minima; modern theory shows "good enough" minima generalize well.

Constrained optimization: clinical constraints (e.g., maximum radiation dose) require Lagrangian methods or projected gradient descent.

2.2 Probability and Statistics

学时：4 学时

2.2.1 Bayes Theorem, Distributions, Hypothesis Testing

学时：2 学时

正文内容：

Probability​ is the foundation of medical reasoning and AI uncertainty quantification.

Bayes' Theorem: P(Disease|Test) = P(Test|Disease)·P(Disease) / P(Test)

Prior​ P(Disease): prevalence in population

Likelihood​ P(Test|Disease): sensitivity

Evidence​ P(Test): total probability of positive test

Posterior​ P(Disease|Test): updated belief after seeing test result

Clinical example: Mammography screening

Prevalence: 1% → prior = 0.01

Sensitivity: 90% → P(+|cancer) = 0.90

False positive: 9% → P(+|no cancer) = 0.09

Posterior P(cancer|+) = 0.09 / (0.09 + 0.0891) ≈ 9.2%​ — not 90% as intuition suggests.

This illustrates why AI systems must output calibrated probabilities, not binary predictions.

Key distributions in medical data:

**Distribution**

Use Case Example

**Binomial**

Binary outcomes Treatment success/failure

**Poisson**

Count data Hospital admissions per day

**Normal**

2.2.2 Bias-Variance Tradeoff

学时：2 学时

正文内容：

The bias-variance decomposition​ is the central theoretical framework for understanding model generalization.

Total error = Bias² + Variance + Irreducible noise

**Component**

Meaning Medical Example

**Bias**

Error from wrong assumptions Linear model trying to fit nonlinear gene-disease relationship

**Variance**

Sensitivity to training data fluctuations Model memorizes 50 training cases, fails on 51st

Irreducible noise Inherent uncertainty Patient with identical presentation has different outcomes

Underfitting​ (high bias): Model too simple → fails on training AND test data.

Example: Linear regression for pneumonia severity (ignores nonlinear interactions between age, comorbidity, labs).

Overfitting​ (high variance): Model too complex → perfect on training, poor on test.

Example: Deep CNN trained on 200 chest X-rays from one hospital → 99% training accuracy, 55% on external validation.

Remedies:

**Technique**

Reduces Mechanism

**More data**

Variance Model sees more patterns

Regularization (L1/L2) Variance Penalizes large weights

**Dropout**

Variance Randomly disables neurons during training

**Early stopping**

Variance Stops before overfitting

Feature selection Variance Removes noisy inputs

**Ensemble methods**

Variance Averages multiple models

Domain adaptation Both Transfers knowledge across hospitals

Medical AI implication: Overfitting is the #1 cause of AI model failure in clinical deployment. A model with 98% AUC on internal validation that drops to 72% on external test is not ready for clinical use.

2.3 Information Theory and Entropy

学时：3 学时

2.3.1 Entropy, KL Divergence, Mutual Information

学时：1.5 学时

正文内容：

Entropy​ H(X) = −Σ p(x) log p(x) measures uncertainty in a random variable.

High entropy → more uncertain → more information gained by observing outcome

In medical diagnosis: a symptom with high entropy (equally likely across diseases) is less informative than one with low entropy (strongly associated with one disease)

Cross-entropy​ H(p, q) = −Σ p(x) log q(x) measures difference between true distribution p and predicted distribution q. Used as loss function in classification.

Kullback-Leibler (KL) Divergence​ D_KL(p||q) = Σ p(x) log(p(x)/q(x)) measures how one probability distribution diverges from another.

Medical use: Quantify dataset shift between training hospital (p) and deployment hospital (q). High KL → model likely to fail.

Application: Detect when a patient's physiology drifts from training distribution → trigger human review.

Mutual Information​ I(X;Y) = H(X) − H(X|Y) measures information shared between variables.

Feature selection: Choose variables with high MI to diagnosis outcome

Example: "Cough" has low MI with myocardial infarction; "chest pain" has high MI → select chest pain as feature

2.3.2 Decision Trees and Information Gain

学时：1.5 学时

正文内容：

Decision trees​ are interpretable ML models that split data based on feature thresholds, forming a tree structure. Each internal node tests a feature; each leaf predicts an outcome.

Information gain​ = Entropy(parent) − weighted average Entropy(children)

Algorithm selects split that maximizes information gain at each node

Medical example: Diagnosing chest pain

Root: Is pain substernal? (yes → high probability CAD)

Left child: Is pain exertional? (yes → very high probability CAD)

Right child: Is pain positional? (yes → likely musculoskeletal)

Advantages in medicine:

Interpretable: physicians can trace decision path ("why did the model say heart attack?")

Handles mixed data types: continuous (age), categorical (sex), ordinal (NYHA class)

No feature scaling required

Limitations:

Unstable: small data changes → completely different tree

Greedy splits: locally optimal, not globally optimal

Prone to overfitting: deep trees memorize training data

Ensemble solutions:

Random Forest: 100–1000 trees, each on random bootstrap sample + random feature subset → vote majority

Gradient Boosted Trees (XGBoost, LightGBM): sequential trees correct errors of previous → state-of-the-art for tabular medical data (EHR, lab panels)

Clinical deployment note: Random forests and XGBoost are the most commonly deployed ML models in hospital operational systems (readmission prediction, sepsis alert) because they balance accuracy with interpretability (feature importance) and run on CPU in milliseconds.

4.1.1 Linear/Logistic Regression, SVM, Decision Trees

学时：4 学时

正文内容：

Supervised Learning​ is the dominant paradigm in medical AI: learn a mapping f: X → Y from labeled examples (xᵢ, yᵢ). The model optimizes parameters to minimize prediction error on training data, then generalizes to unseen patients.

Linear Regression​ — foundation of continuous prediction:

Model: ŷ = β₀ + β₁x₁ + β₂x₂ + ... + βₙxₙ

Loss: Mean Squared Error (MSE) = (1/m) Σ(yᵢ − ŷᵢ)²

Closed-form solution: β = (XᵀX)⁻¹Xᵀy (normal equation)

Medical example: Predicting hospital length-of-stay from age, comorbidity count, admission severity score

Assumptions: linearity, homoscedasticity, independence, normality of residuals

Limitation: Cannot capture nonlinear relationships (e.g., age-risk curve for many diseases is J-shaped, not linear)

Logistic Regression​ — workhorse of medical binary classification:

Model: P(y=1|x) = σ(β₀ + Σβⱼxⱼ), where σ(z) = 1/(1+e⁻ᶻ)

Output: calibrated probability between 0 and 1

Odds ratio: e^βⱼ quantifies how each feature multiplies odds of outcome

Medical example: 30-day readmission risk (yes/no) from discharge summary features

Strengths: interpretable (clinicians understand odds ratios), outputs calibrated probabilities, fast training

Limitation: assumes linear decision boundary in feature space

Support Vector Machine (SVM)​ — maximum-margin classifier:

Objective: find hyperplane that maximizes margin between classes

Kernel trick: maps features to higher-dimensional space for nonlinear boundaries (RBF kernel most common)

Medical example: Distinguishing benign vs. malignant skin lesions from dermoscopic features

Strengths: effective in high-dimensional spaces (genomics: 20,000 genes, 200 samples), memory-efficient

Limitations: no probability output (requires Platt scaling), sensitive to class imbalance, poor on very large datasets (>10K samples)

Decision Trees​ (reviewed from Ch2, now with medical focus):

CART algorithm: Gini impurity or entropy-based splits

Medical example: Sepsis screening tool — sequential thresholds on heart rate, lactate, blood pressure

Clinical Decision Rules​ (e.g., Wells Criteria for DVT, CHA₂DS₂-VASc for stroke risk) are essentially hand-crafted decision trees

4.1.2 Model Evaluation: Accuracy, AUC, F1, Calibration

学时：4 学时

正文内容：

Why accuracy is often misleading in medicine:

Imbalanced datasets: 95% patients are disease-negative → a model predicting "always negative" gets 95% accuracy but detects ZERO cases

Better metrics:

**Metric**

Definition When to Use

Sensitivity (Recall) TP / (TP + FN) Screening tests — minimize false negatives

**Specificity**

TN / (TN + FP) Confirmatory tests — minimize false positives

**PPV (Precision)**

TP / (TP + FP) When false alarm cost is high

**NPV**

TN / (TN + FN) When missing disease is catastrophic

**F1-Score**

2·(Precision·Recall)/(Precision+Recall) Imbalanced data, need balance

**AUC-ROC**

Area under Receiver Operating Characteristic Overall discrimination ability

**AUPRC**

Area under Precision-Recall Curve Highly imbalanced data (better than AUC)

ROC Curve: plots TPR vs. FPR at varying thresholds. AUC = 0.5 is random guessing; AUC = 1.0 is perfect. Clinical interpretation: AUC 0.70–0.80 = acceptable; 0.80–0.90 = excellent; >0.90 = outstanding.

Precision-Recall Curve: more informative than ROC when positive class is rare (<10%). AUPRC considers only positive predictions.

Calibration: Do predicted probabilities match observed frequencies?

Calibration plot: predicted probability bins (0–0.1, 0.1–0.2, ...) vs. observed fraction of positives

Hosmer-Lemeshow test: statistical test for calibration

Why it matters: A model with AUC 0.85 but poor calibration may predict "70% risk" when actual risk is 30% → dangerous for clinical decision-making

Fixes: Platt scaling, isotonic regression

Confusion Matrix deep dive:

纯文本

Predicted

Positive Negative

Actual Positive TP FN → missed diagnoses

Negative FP TN → false alarms

Clinical threshold selection: Different applications demand different operating points:

Cancer screening: prioritize sensitivity (accept more FP for fewer FN) → lower threshold

ICU alarm system: prioritize specificity (reduce alarm fatigue) → higher threshold

Youden's J: threshold maximizing (sensitivity + specificity − 1)

Cost-based threshold: incorporate cost of FN vs. FP explicitly

学时：3 学时

正文内容：

Ensemble learning​ combines multiple models to produce a stronger predictor. Core principle: wisdom of crowds​ — diverse models make different errors; averaging reduces variance.

Random Forest​ — bagging (bootstrap aggregating):

Train B trees on bootstrap samples (random ~63.2% of data each)

At each split, consider √p random features (not all p)

Prediction: regression → average; classification → majority vote

Feature importance: mean decrease in impurity (Gini/entropy) across all trees

Out-of-bag (OOB) error: estimate generalization without held-out validation set

Medical example: MIMIC-III mortality prediction (AUC 0.85–0.88 in published benchmarks)

Strengths: handles mixed data types, robust to outliers, no scaling needed, built-in feature importance

Limitation: less accurate than gradient boosting on structured/tabular data

Sequential training: each tree corrects residuals of previous ensemble

Leaf-wise growth​ (vs. XGBoost's level-wise) → faster, sometimes more accurate

Exclusive Feature Bundling: reduces feature dimensionality for high-cardinality categorical data

Level-0 models: diverse base learners (LR, RF, XGBoost, SVM)

Clinical prediction models​ bridge statistical ML and bedside practice. They must be interpretable, calibrated, and validated in independent cohorts.

Risk Scores​ — simplified prediction tools:

Principle: assign integer points to key predictors; sum yields risk estimate

Examples: Framingham Risk Score (10-year cardiovascular disease), CHA₂DS₂-VASc (stroke risk in atrial fibrillation), CURB-65 (pneumonia severity)

Derivation: logistic regression coefficients → round to integer weights

Validation: internal (bootstrap) + external (different hospital/region)

Nomograms​ — graphical risk calculators:

Each predictor has a point scale; total points map to probability

Example: Memorial Sloan Kettering prostate cancer nomogram

Modern variant: Web-based calculators (e.g., MDCalc.com hosts 600+ clinical calculators)

Clinical Decision Rules (CDRs)​ — evidence-based diagnostic tools:

**Rule**

Purpose Key Variables

Wells Criteria for DVT Pre-test probability of deep vein thrombosis Active cancer, paralysis, recent surgery, tenderness, swelling

Wells Criteria for PE Pre-test probability of pulmonary embolism Clinical signs of DVT, HR>100, immobilization, previous DVT/PE

**HEART Score**

Chest pain risk stratification History, ECG, Age, Risk factors, Troponin

**qSOFA**

Rapid sepsis screening RR≥22, altered mentation, SBP≤100 mmHg

Machine learning enhancement of CDRs:

Traditional CDRs use ≤6 variables (simplicity constraint)

ML can incorporate 50+ variables (labs, vitals, demographics)

Hybrid approach: ML identifies important features → simplified scoring system derived → validated in prospective study

Validation framework​ (TRIPOD statement):

Development: model derivation on training set

Internal validation: bootstrap, cross-validation

External validation: different time period, different hospital, different country

Temporal validation: future patients at same institution

Impact study: does using the model improve patient outcomes? (gold standard, rarely done)

4.3.2 Handling Imbalanced Medical Data

学时：3 学时

正文内容：

The class imbalance problem​ is ubiquitous in medicine:

Rare diseases: prevalence 0.1% (e.g., certain genetic disorders)

Adverse events: 2% in-hospital mortality

Screening: 5% disease prevalence

Consequences: Standard algorithms optimize accuracy → predict majority class → useless for clinical decision support.

Solution 1: Data-level methods

Oversampling minority class: SMOTE (Synthetic Minority Oversampling Technique) — creates synthetic examples by interpolating between minority class neighbors

Undersampling majority class: Random undersampling, Tomek links, Edited Nearest Neighbors

Combination: SMOTE + Tomek links (oversample minority, clean majority boundaries)

python

from imblearn.over_sampling import SMOTE

from imblearn.combine import SMOTETomek

smote = SMOTE(sampling_strategy=0.3, random_state=42) # upsample to 30% of majority

X_res, y_res = smote.fit_resample(X_train, y_train)

print(f"Before: {sum(y_train==1)} positive, {sum(y_train==0)} negative")

print(f"After: {sum(y_res==1)} positive, {sum(y_res==0)} negative")

Solution 2: Algorithm-level methods

Class weighting: assign higher penalty to misclassifying minority class

python

from sklearn.linear_model import LogisticRegression

model = LogisticRegression(class_weight='balanced', max_iter=1000)

# or manual: class_weight={0: 1, 1: 20}

Cost-sensitive learning: incorporate FN cost (missed diagnosis) >> FP cost (false alarm)

Anomaly detection: treat rare events as outliers (One-Class SVM, Isolation Forest)

Solution 3: Evaluation strategy

Always report AUPRC (not just AUC) for imbalanced data

Report sensitivity at clinically acceptable specificity threshold

Use precision-recall gain curves​ for extreme imbalance (<1% prevalence)

Solution 4: Ensemble for imbalance

Balanced Random Forest: each tree trained on balanced bootstrap (equal samples from each class)

EasyEnsemble: multiple AdaBoost classifiers on balanced subsamples

RUSBoost: Random undersampling + AdaBoost

Critical warning: Oversampling test set is data leakage. Only resample training data. Validation and test sets must reflect true class distribution.

学时：6 学时

5.1.1 K-Means, Hierarchical, DBSCAN

学时：3 学时

正文内容：

Unsupervised Learning​ discovers patterns in unlabeled data. In medicine, it's used for patient subtyping, biomarker discovery, and anomaly detection — where ground truth labels are unavailable or expensive.

K-Means Clustering:

Algorithm: Initialize k centroids → assign each point to nearest centroid → recompute centroids → repeat until convergence

Objective: minimize within-cluster sum of squares (WCSS)

Medical example: Subtyping diabetes patients from glucose trajectory, BMI, age, insulin resistance markers → identifies distinct phenotypes (e.g., severe insulin-deficient, severe insulin-resistant, mild obesity-related)

Choosing k: Elbow method (plot WCSS vs. k), Silhouette score, Gap statistic

Limitations: assumes spherical clusters, sensitive to initialization, requires k specification, struggles with non-convex shapes

python

from sklearn.cluster import KMeans

from sklearn.metrics import silhouette_score

kmeans = KMeans(n_clusters=4, random_state=42, n_init=10)

clusters = kmeans.fit_predict(X_scaled)

sil_score = silhouette_score(X_scaled, clusters)

print(f"Silhouette score: {sil_score:.3f}")

print(f"Cluster sizes: {np.bincount(clusters)}")

Hierarchical Clustering:

Agglomerative (bottom-up): each point starts as its own cluster; merge closest pairs iteratively

Linkage criteria: single (minimum distance), complete (maximum), average (mean), Ward (minimize variance)

Output: dendrogram (tree diagram) showing merge hierarchy

Medical example: Gene expression profiling — cluster genes by co-expression pattern → identify biological pathways; cluster patients by expression profile → discover disease subtypes

Advantage: no need to specify k in advance; dendrogram reveals natural hierarchy

Limitation: O(n³) or O(n²) complexity → infeasible for >10,000 samples

python

plt.show()

# Cut tree at height → get clusters

hc = AgglomerativeClustering(n_clusters=3, linkage='ward')

clusters_hc = hc.fit_predict(X_scaled)

DBSCAN​ (Density-Based Spatial Clustering of Applications with Noise):

Core idea: clusters are dense regions separated by low-density regions

Parameters: ε (neighborhood radius), MinPts (minimum points to form dense region)

Medical example: Detecting disease outbreaks (geographic clustering of cases), identifying anomalous patient profiles (outliers = rare disease presentations)

Advantage: finds arbitrary-shaped clusters; automatically identifies outliers (noise points); no need to specify k

Limitation: struggles with varying density regions; sensitive to ε parameter

python

Dimensionality reduction​ compresses high-dimensional data into lower dimensions while preserving structure. Essential for visualization, noise reduction, and computational efficiency.

PCA​ (Principal Component Analysis):

Concept: Find orthogonal directions of maximum variance

Mathematical: eigenvalue decomposition of covariance matrix Σ = (1/(m-1))XᵀX

Medical example: Gene expression (20,000 genes → 50 PCs capture 80% variance) → downstream clustering/classification on PCs

Strengths: linear, interpretable (loadings show which variables drive each PC), fast

Limitations: linear only; may not capture nonlinear manifold structure

Concept: Preserves local neighborhood structure; converts high-dimensional distances to probability distributions

6.1 Neural Networks

学时：8 学时

6.1.1 Perceptron, Backpropagation, Activation Functions

学时：4 学时

正文内容：

Artificial Neural Networks (ANNs)​ are layered computational graphs inspired by biological neurons. They are the foundation of deep learning and the dominant architecture for medical imaging, NLP, and multimodal AI.

Perceptron​ — the simplest neural unit:

Input: x₁, x₂, ..., xₙ

Weights: w₁, w₂, ..., wₙ

Bias: b

Output: ŷ = f(Σ wᵢxᵢ + b), where f is activation function

Limitation: can only learn linearly separable patterns (Minsky & Papert, 1969)

Multi-Layer Perceptron (MLP)​ — stacks perceptrons in layers:

Input layer: features (e.g., 20 lab values)

Hidden layers: 1 to many; each neuron computes weighted sum + activation

Output layer: prediction (single value for regression; softmax for multi-class)

Universal Approximation Theorem: a single hidden layer with sufficient neurons can approximate any continuous function (Cybenko, 1989)

Activation Functions​ — introduce nonlinearity (essential for learning complex patterns):

**Function**

Formula Range Use Case

**Sigmoid**

1/(1+e⁻ˣ) (0, 1) Output layer for binary classification (legacy)

**Tanh**

(eˣ−e⁻ˣ)/(eˣ+e⁻ˣ) (−1, 1) Hidden layers (centered, zero-mean)

**ReLU**

max(0, x) [0, ∞) Default for hidden layers (fast, sparse)

**Leaky ReLU**

max(αx, x) (−∞, ∞) Fixes "dying ReLU" problem

**GELU**

x·Φ(x) (−∞, ∞) Transformer models (GPT, BERT)

**Softmax**

eˣⁱ/Σeˣʲ (0, 1), sums to 1 Multi-class output

Backpropagation​ — the learning algorithm:

1. Forward pass: compute predictions layer by layer

2. Compute loss: L(y, ŷ)

3. Backward pass: compute ∂L/∂w for every weight using chain rule

4. Update: w ← w − η·∂L/∂w

python

import torch

import torch.nn as nn

import torch.optim as optim

# Simple MLP for medical diagnosis

class MedicalMLP(nn.Module):

def __init__(self, input_dim, hidden_dim, output_dim):

super(MedicalMLP, self).__init__()

self.net = nn.Sequential(

nn.Linear(input_dim, hidden_dim),

nn.ReLU(),

nn.Dropout(0.3),

nn.Linear(hidden_dim, hidden_dim // 2),

nn.ReLU(),

nn.Dropout(0.3),

nn.Linear(hidden_dim // 2, output_dim),

nn.Sigmoid()

)

def forward(self, x):

return self.net(x)

# Training loop

model = MedicalMLP(input_dim=20, hidden_dim=64, output_dim=1)

criterion = nn.BCELoss()

optimizer = optim.Adam(model.parameters(), lr=0.001)

for epoch in range(100):

model.train()

optimizer.zero_grad()

outputs = model(X_train_tensor)

loss = criterion(outputs, y_train_tensor)

loss.backward()

optimizer.step()

if epoch % 20 == 0:

print(f"Epoch {epoch}, Loss: {loss.item():.4f}")

Gradient descent variants:

SGD with momentum: accelerates convergence in ravines

Adam: adaptive learning rates per parameter (default for most medical DL)

AdamW: decoupled weight decay (prevents overfitting)

Common pitfalls:

Vanishing gradient: deep networks → gradients approach zero → no learning (solved by ReLU, residual connections)

Exploding gradient: gradients become huge → unstable training (solved by gradient clipping)

Overfitting: model memorizes training data (solved by dropout, weight decay, early stopping, data augmentation)

6.2.1 Convolutional and Recurrent Architectures

学时：4 学时

正文内容：

Convolutional Neural Networks (CNNs)​ — specialized for grid-structured data (images, time-series as 1D signals).

Convolution operation: slide a filter (kernel) across input, computing element-wise product + sum at each position → feature map

Local connectivity: each neuron connects only to local region (receptive field)

Weight sharing: same filter applied across all spatial positions → translation invariance

Hierarchical features: early layers detect edges → mid layers detect textures/shapes → deep layers detect objects/semantic concepts

Key building blocks:

Convolutional layer: Conv2d(in_channels, out_channels, kernel_size, stride, padding)

Pooling layer: MaxPool2d(kernel_size=2) → downsampling, translation invariance

Batch normalization: stabilizes training, accelerates convergence

Skip connections​ (ResNet): bypass layers → train very deep networks

python

import torch.nn as nn

class MedicalCNN(nn.Module):

def __init__(self, num_classes=2):

super(MedicalCNN, self).__init__()

self.features = nn.Sequential(

nn.Conv2d(1, 32, kernel_size=3, padding=1),

nn.BatchNorm2d(32),

nn.ReLU(),

nn.MaxPool2d(2),

nn.Conv2d(32, 64, kernel_size=3, padding=1),

nn.BatchNorm2d(64),

nn.ReLU(),

nn.MaxPool2d(2),

nn.Conv2d(64, 128, kernel_size=3, padding=1),

nn.BatchNorm2d(128),

nn.ReLU(),

nn.MaxPool2d(2),

nn.Conv2d(128, 256, kernel_size=3, padding=1),

nn.BatchNorm2d(256),

nn.ReLU(),

nn.AdaptiveAvgPool2d((1, 1))

)

self.classifier = nn.Sequential(

nn.Flatten(),

nn.Linear(256, 128),

nn.ReLU(),

nn.Dropout(0.5),

nn.Linear(128, num_classes)

)

def forward(self, x):

x = self.features(x)

x = self.classifier(x)

return x

Recurrent Neural Networks (RNNs)​ — for sequential data (time-series, text):

Core idea: hidden state hₜ = f(Wₓxₜ + Whhₜ₋₁ + b)

Limitation: vanishing gradient → cannot capture long-range dependencies

LSTM​ (Long Short-Term Memory):

Gates: forget gate (what to discard), input gate (what to store), output gate (what to output)

Medical example: ICU time-series prediction (vital signs every 5 min → predict deterioration in next 4 hours)

Bidirectional LSTM: processes sequence forward and backward → captures past and future context

python

class MedicalLSTM(nn.Module):

def __init__(self, input_dim, hidden_dim, num_layers, output_dim):

super(MedicalLSTM, self).__init__()

self.lstm = nn.LSTM(input_dim, hidden_dim, num_layers,

batch_first=True, bidirectional=True)

self.fc = nn.Linear(hidden_dim * 2, output_dim)

def forward(self, x):

# x shape: (batch, seq_len, input_dim)

lstm_out, _ = self.lstm(x)

# Use last time step

out = self.fc(lstm_out[:, -1, :])

return out

GRU​ (Gated Recurrent Unit): simplified LSTM (fewer parameters, comparable performance)

When to use CNN vs. RNN:

CNN: spatial data (images), fixed-length sequences with local patterns

RNN/LSTM: variable-length sequences (EHR time-series, clinical notes)

Hybrid: CNN extracts features from each time step → LSTM processes sequence of features

学时：6 学时

7.1.1 X-ray, CT, MRI, Ultrasound, Pathology Slides

学时：3 学时

正文内容：

Medical imaging is the single largest application domain of AI in medicine. Understanding physics, acquisition, and data characteristics​ of each modality is prerequisite to building effective models.

X-ray (Radiography)

Physics: Ionizing electromagnetic radiation (0.01–10 nm wavelength); differential absorption by tissue density creates contrast

Clinical use: Chest (pneumonia, COVID-19, heart failure, tuberculosis), bone fracture, abdominal free air

Data characteristics: 2D grayscale; 8–12 bit depth; typical size 1024×1024 to 2048×2048; single view or paired PA/lateral

AI challenge: High class imbalance (normal >> abnormal); subtle findings; overlapping anatomy

Landmark dataset: ChestX-ray14 (NIH, 2017) — 112,120 frontal CXR with 14 disease labels; CheXpert (Stanford, 2019) — 224,316 CXR

Computed Tomography (CT)

Physics: X-ray tube rotates around patient; computer reconstructs cross-sectional slices via filtered back-projection or iterative reconstruction

Data: 3D volume of axial slices; typical 512×512×Z (Z = 50–500+); voxel size ~0.5×0.5×1–5 mm; Hounsfield Units (HU) standardized scale (air = −1000, water = 0, bone = +1000)

Clinical use: Lung nodule detection, stroke (CT perfusion), trauma, oncology staging

AI preprocessing: Windowing (lung window: −1000 to −300 HU; soft tissue: 40–80 HU; bone: 250–1000 HU) → map to [0,1]

Key difference from X-ray: 3D spatial information; much larger data volume; requires 3D CNN or slice-by-slice + aggregation

Magnetic Resonance Imaging (MRI)

Physics: Strong magnetic field + radiofrequency pulses; hydrogen nuclei realign and emit signals; no ionizing radiation

Sequences: T1-weighted (anatomy, fat bright), T2-weighted (fluid bright, pathology), FLAIR (suppresses CSF), DWI (diffusion, stroke), T1-Gd (contrast enhancement)

Data: 3D or 4D (including time/contrast); variable voxel size (0.5–1.5 mm isotropic); multiple sequences per exam

Clinical use: Brain (tumor, stroke, dementia), spine, joints, liver, cardiac

AI challenge: Multiple sequences per patient → multimodal input; longer acquisition → motion artifacts; smaller datasets than CT/X-ray

Ultrasound (US)

Physics: High-frequency sound waves (2–18 MHz); piezoelectric transducer emits/receives echoes

Data: Real-time 2D video (30 fps) or 3D/4D; speckle noise; operator-dependent

Clinical use: Obstetrics, cardiac (echocardiography), abdominal organs, vascular, point-of-care (POCUS)

AI challenge: Low SNR; video not image → temporal modeling; operator variability; no standardized DICOM metadata

Digital Pathology (Whole Slide Imaging, WSI)

Physics: Brightfield/fluorescence microscopy; tissue slides scanned at 20× or 40× magnification

Data: Gigapixel images (100,000 × 100,000 pixels, ~5–10 GB per slide); stored as multi-resolution pyramids (SVS, NDPI formats)

Clinical use: Cancer diagnosis (biopsy, resection margins), grading, biomarker quantification

AI approach: Patch-based (extract 224×224 patches → predict per-patch → aggregate to slide-level); or multiple instance learning (MIL)

Landmark: CAMELYON16/17 (lymph node metastasis detection); PANDA (prostate cancer grading, Kaggle 2020)

Modality comparison for AI:

**Modality**

Volume (per study) Annotation Cost AI Maturity Key Challenge

**X-ray**

Low (1–2 MB) Low Highest Subtle findings, overlap

**CT**

Medium (50–500 MB) Medium High 3D, radiation dose

**MRI**

High (10–100 MB) High Medium Multiple sequences, artifacts

**US**

Medium (video) Medium Emerging Operator-dependent, speckle

**Pathology**

Very High (5–10 GB) Very High High (patch-based) Gigapixel, WSI formats

8.2.1 ViT, Swin Transformer in Radiology

学时：3 学时

正文内容：

Vision Transformer (ViT, Dosovitskiy et al., 2020)​ — applies Transformer architecture to images:

Core idea: Split image into patches (e.g., 16×16 pixels) → flatten each patch → linear embedding → add position embedding → feed to standard Transformer encoder

Architecture:

Patch embedding: image (224×224×3) → 196 patches of 16×16 → each patch → 768-dim vector

Position embedding: learnable 1D or 2D positional encoding

Transformer encoder: multi-head self-attention (MSA) + MLP + LayerNorm (pre-norm variant)

Classification head: CLS token or global average pooling → linear classifier

python

import torch

from torch import nn

from einops import rearrange

class PatchEmbedding(nn.Module):

def __init__(self, img_size=224, patch_size=16, in_channels=3, embed_dim=768):

super().__init__()

self.num_patches = (img_size // patch_size) ** 2

self.proj = nn.Conv2d(in_channels, embed_dim, kernel_size=patch_size, stride=patch_size)

def forward(self, x):

x = self.proj(x) # (B, embed_dim, H/patch, W/patch)

x = rearrange(x, 'b c h w -> b (h w) c')

return x

class ViT(nn.Module):

def __init__(self, img_size=224, patch_size=16, num_classes=14, embed_dim=768, depth=12, num_heads=12):

super().__init__()

self.patch_embed = PatchEmbedding(img_size, patch_size, 1, embed_dim)

self.cls_token = nn.Parameter(torch.zeros(1, 1, embed_dim))

self.pos_embed = nn.Parameter(torch.zeros(1, 196 + 1, embed_dim))

self.transformer = nn.TransformerEncoder(

nn.TransformerEncoderLayer(d_model=embed_dim, nhead=num_heads, batch_first=True),

num_layers=depth

)

self.head = nn.Linear(embed_dim, num_classes)

def forward(self, x):

B = x.shape[0]

x = self.patch_embed(x)

cls_tokens = self.cls_token.expand(B, -1, -1)

x = torch.cat([cls_tokens, x], dim=1)

x = x + self.pos_embed

x = self.transformer(x)

cls_output = x[:, 0] # CLS token

return self.head(cls_output)

Limitation: requires large datasets; struggles with small medical datasets (<10K images)

Key innovation: Shifted Window (Swin) attention → linear complexity O(N) instead of O(N²)

Hierarchical feature maps: like CNNs, produces multi-scale features → suitable for dense prediction (segmentation, detection)

# Conceptual contrastive loss (InfoNCE)

def contrastive_loss(z_i, z_j, temperature=0.5):

"""z_i, z_j: embeddings of two augmented views of same image"""

z = torch.cat([z_i, z_j], dim=0)

sim = torch.mm(z, z.T) / temperature

labels = torch.arange(z.shape[0], device=z.device)

labels = torch.cat([labels + 1, labels - 1], dim=0)

loss = nn.CrossEntropyLoss()(sim, labels)

return loss

BiLSTM-CRF​ (2015–2018 standard):

Bidirectional LSTM captures contextual embeddings → CRF layer enforces label consistency (BIO scheme)

BIO tagging: B-Disease (beginning), I-Disease (inside), O (outside)

import torch

import torch.nn as nn

class BiLSTM_CRF(nn.Module):

def __init__(self, vocab_size, tagset_size, embedding_dim=100, hidden_dim=256):

super().__init__()

self.embedding = nn.Embedding(vocab_size, embedding_dim)

self.bilstm = nn.LSTM(embedding_dim, hidden_dim // 2,

num_layers=2, bidirectional=True, batch_first=True)

self.hidden2tag = nn.Linear(hidden_dim, tagset_size)

self.crf = CRF(tagset_size, batch_first=True)

def forward(self, x, labels=None):

embeds = self.embedding(x)

lstm_out, _ = self.bilstm(embeds)

emissions = self.hidden2tag(lstm_out)

if labels is not None:

loss = -self.crf(emissions, labels, reduction='mean')

return loss

else:

return self.crf.decode(emissions)

Algorithmic Bias in Medical AI​ — documented cases:

**Study**

Finding

Obermeyer et al. (Science 2019) Commercial risk-prediction algorithm had 50% lower Black patient identification at same risk score due to using healthcare cost as proxy for need

Larrazabal et al. (PNAS 2020) Dermatology AI performs worse on dark skin tones (training data skewed toward light skin)

Seyyed-Kalantari et al. (Nature Med 2021) Chest X-ray models systematically underestimate disease severity in underrepresented groups

Chen et al. (JAMA 2023) Sepsis prediction model calibration degraded in safety-net hospitals vs. academic centers

Sources of bias:

1. Data bias: training data not representative of target population

2. Label bias: ground truth labels reflect historical disparities (e.g., underdiagnosis in minorities)

3. Algorithmic bias: optimization objective doesn't account for fairness

4. Evaluation bias: validation only on majority population

Fairness definitions​ (mathematical):

**Definition**

Formula Meaning

Demographic parity P(ŷ=1|A=0) = P(ŷ=1|A=1) Equal positive rate across groups

**Equalized odds**

P(ŷ=1|Y=1, A=0) = P(ŷ=1|Y=1, A=1) Equal TPR across groups

Equal opportunity Same as equalized odds (focus on TPR) Disadvantaged group gets equal chance

**Calibration**

P(Y=1|ŷ=p, A=0) = P(Y=1|ŷ=p, A=1) Predicted risk means same thing across groups

Mitigation strategies:

Pre-processing:

Reweight training samples: increase weight of underrepresented group

Resample to balance demographic distribution

In-processing:

Add fairness constraint to loss function

Adversarial debiasing: train predictor to predict outcome while adversary tries to predict protected attribute from predictions → predictor learns to be independent of protected attribute

python

# Conceptual: adversarial debiasing

class AdversarialDebiasing(nn.Module):

def __init__(self):

super().__init__()

self.predictor = MedicalMLP() # predicts outcome

self.adversary = nn.Sequential( # predicts protected attribute

nn.Linear(1, 32), # outcome probability

nn.ReLU(),

nn.Linear(32, 2) # protected attribute (e.g., race)

)

def forward(self, x, protected_attr):

outcome_logits = self.predictor(x)

# Adversary tries to predict protected_attr from outcome

adv_logits = self.adversary(torch.sigmoid(outcome_logits))

return outcome_logits, adv_logits

# Loss = outcome_loss - λ * adversary_loss

Generalizability — the "external validation gap":

Problem: Model trained at Hospital A (academic, urban, affluent) fails at Hospital B (rural, safety-net)

Causes:

Population shift: different demographics, disease prevalence

Practice pattern shift: different ordering patterns, diagnostic thresholds

Equipment shift: different lab equipment, imaging protocols

Temporal shift: model trained on 2015–2018 data applied to 2024 patients

Solutions:

1. Multi-center training: include diverse hospitals in training set

2. Domain adaptation: transfer learning from source to target domain

3. Federated learning: train across hospitals without sharing data

4. Continuous monitoring: track performance drift in production

|  |  |  |  |  |  |  | Why Medical AI Ethics Is Different from General AI Ethics |  |  |  |  |
|  |  |  |  |  |  |  | Medical data is uniquely sensitive: it reveals not only current health status but also genetic predispositions, mental health history, substance use, sexual behavior, and reproductive choices. A single medical record can be used to discriminate in employment, insurance, housing, and social relationships. Therefore, medical AI ethics is not an afterthought—it is the foundation upon which all clinical AI systems must be built. |  |  |  |  |
|  |  |  |  |  |  |  | The Four Classical Biomedical Ethics Principles (Beauchamp & Childress, 1979): |  |  |  |  |
|  |  |  |  |  |  |  | Principle | Core Meaning | Medical AI Implication |  |  |
|  |  |  |  |  |  |  | Autonomy | Patients have the right to make informed decisions | AI must not override patient choice; patients must understand when AI is involved |  |  |
|  |  |  |  |  |  |  | Beneficence | Act in the patient's best interest | AI must demonstrably improve outcomes, not just efficiency |  |  |
|  |  |  |  |  |  |  | Non-maleficence | "First, do no harm" | AI errors, bias, and over-reliance must be minimized |  |  |
|  |  |  |  |  |  |  | Justice | Fair distribution of benefits and burdens | AI must not exacerbate health disparities |  |  |

|  |  |  |  |  |  |  | Legal frameworks worldwide: |  |  |  |  |
|  |  |  |  |  |  |  | Region | Law | Key Provision for AI |  |  |
|  |  |  |  |  |  |  | USA | HIPAA (1996) | Prohibits re-identification of de-identified data; limits sharing |  |  |
|  |  |  |  |  |  |  | EU | GDPR (2018) | Right to explanation, right to be forgotten, data minimization |  |  |
|  |  |  |  |  |  |  | China | PIPL (2021) | Personal Information Protection Law; strict cross-border transfer rules |  |  |
|  |  |  |  |  |  |  | California | CCPA/CPRA | Consumer right to know and delete; opt-out of data sale |  |  |
|  |  |  |  |  |  |  | De-identification standards: |  |  |  |  |
|  |  |  |  |  |  |  | Safe Harbor method​ (HIPAA): remove 18 identifiers (names, dates, locations, phone numbers, etc.) |  |  |  |  |

|  |  |  |  |  |  |  | Technical privacy-preserving methods: |  |  |  |  |
|  |  |  |  |  |  |  | 1. Differential Privacy (Dwork, 2006): |  |  |  |  |
|  |  |  |  |  |  |  | python |  |  |  |  |
|  |  |  |  |  |  |  | import numpy as np |  |  |  |  |
|  |  |  |  |  |  |  | def add_laplace_noise(data, epsilon=1.0, sensitivity=1.0): |  |  |  |  |
|  |  |  |  |  |  |  | """Add Laplace noise for ε-differential privacy""" |  |  |  |  |
|  |  |  |  |  |  |  | scale = sensitivity / epsilon |  |  |  |  |
|  |  |  |  |  |  |  | noise = np.random.laplace(0, scale, size=data.shape) |  |  |  |  |
|  |  |  |  |  |  |  | return data + noise |  |  |  |  |
|  |  |  |  |  |  |  | # Example: release average HbA1c without revealing individual values |  |  |  |  |
|  |  |  |  |  |  |  | true_mean = np.mean(hba1c_values) # 7.2 |  |  |  |  |
|  |  |  |  |  |  |  | dp_mean = add_laplace_noise(np.array([true_mean]), epsilon=0.5) |  |  |  |  |
|  |  |  |  |  |  |  | print(f"DP mean HbA1c: {dp_mean[0]:.2f}") |  |  |  |  |
|  |  |  |  |  |  |  | Guarantee: removing or adding any single patient changes output probability by at most e^ε |  |  |  |  |
|  |  |  |  |  |  |  | Trade-off: stronger privacy (smaller ε) → more noise → lower utility |  |  |  |  |
|  |  |  |  |  |  |  | Medical use: Apple Health uses DP for fitness trend aggregation; FDA exploring DP for device surveillance |  |  |  |  |
|  |  |  |  |  |  |  | 2. Federated Learning (reviewed in Part 4, here with privacy focus): |  |  |  |  |
|  |  |  |  |  |  |  | python |  |  |  |  |
|  |  |  |  |  |  |  | # Differential Privacy + Federated Learning |  |  |  |  |
|  |  |  |  |  |  |  | # Each hospital adds noise to gradients before sending to server |  |  |  |  |
|  |  |  |  |  |  |  | def dp_federated_update(local_gradients, epsilon=1.0): |  |  |  |  |
|  |  |  |  |  |  |  | sensitivity = 2 * 1.0 / batch_size # L2 clipping bound / batch_size |  |  |  |  |
|  |  |  |  |  |  |  | noise = np.random.laplace(0, sensitivity / epsilon, size=local_gradients.shape) |  |  |  |  |
|  |  |  |  |  |  |  | clipped = clip_gradients(local_gradients, max_norm=1.0) |  |  |  |  |
|  |  |  |  |  |  |  | return clipped + noise |  |  |  |  |
|  |  |  |  |  |  |  | Advantage: data never leaves hospital; only model updates transmitted |  |  |  |  |
|  |  |  |  |  |  |  | Challenge: gradient inversion attacks can reconstruct training data from gradients |  |  |  |  |
|  |  |  |  |  |  |  | 3. Homomorphic Encryption: |  |  |  |  |
|  |  |  |  |  |  |  | Compute on encrypted data without decrypting |  |  |  |  |
|  |  |  |  |  |  |  | Current state: computationally expensive (1000× slower); research stage for medical AI |  |  |  |  |

|  |  |  |  |  |  |  | Fairness Metrics (reviewed in Part 4, expanded here): |  |  |  |  |
|  |  |  |  |  |  |  | Metric | Formula | Interpretation |  |  |
|  |  |  |  |  |  |  | Demographic Parity | P(ŷ=1\|A=0) = P(ŷ=1\|A=1) | Equal positive prediction rate |  |  |
|  |  |  |  |  |  |  | Equalized Odds | P(ŷ=1\|Y=1,A=0) = P(ŷ=1\|Y=1,A=1) | Equal TPR across groups |  |  |
|  |  |  |  |  |  |  | Predictive Parity | P(Y=1\|ŷ=1,A=0) = P(Y=1\|ŷ=1,A=1) | Equal PPV across groups |  |  |
|  |  |  |  |  |  |  | Counterfactual Fairness | P(ŷ{A←a}=1) = P(ŷ{A←a'}=1) | Prediction unchanged if protected attribute changed |  |  |
|  |  |  |  |  |  |  | Impossibility theorem (Chouldechova, 2017; Kleinberg, 2017): |  |  |  |  |
|  |  |  |  |  |  |  | In general, Demographic Parity, Equalized Odds, and Predictive Parity cannot all be satisfied simultaneously​ unless base rates are equal across groups or the classifier is perfect. |  |  |  |  |
|  |  |  |  |  |  |  | → Must choose which fairness criterion aligns with clinical values. |  |  |  |  |
|  |  |  |  |  |  |  | Mitigation at each stage: |  |  |  |  |
|  |  |  |  |  |  |  | Stage | Strategy | Example |  |  |
|  |  |  |  |  |  |  | Data collection | Oversample underrepresented groups | Actively recruit minority patients for imaging studies |  |  |
|  |  |  |  |  |  |  | Labeling | Audit labels for systematic errors | Re-review chest X-rays with known racial disparities |  |  |
|  |  |  |  |  |  |  | Feature selection | Remove proxies for protected attributes | Don't use zip code if it proxies race |  |  |
|  |  |  |  |  |  |  | Algorithm | Adversarial debiasing, fairness constraints | Add fairness loss term |  |  |
|  |  |  |  |  |  |  | Deployment | Subgroup monitoring, stratified thresholds | Track performance by race/ethnicity/age |  |  |
|  |  |  |  |  |  |  | Feedback | Correct errors, retrain | Active learning from minority group errors |  |  |
|  |  |  |  |  |  |  | Health Equity Framework for Medical AI: |  |  |  |  |
|  |  |  |  |  |  |  | 1. Representation: Training data reflects target population demographics |  |  |  |  |
|  |  |  |  |  |  |  | 2. Performance: Model accuracy within acceptable range for all subgroups |  |  |  |  |
|  |  |  |  |  |  |  | 3. Access: AI tools deployed in safety-net hospitals, not just academic centers |  |  |  |  |
|  |  |  |  |  |  |  | 4. Participation: Diverse stakeholders (patients, community advocates) in AI design |  |  |  |  |
|  |  |  |  |  |  |  | 5. Accountability: Clear responsibility when AI causes harm to vulnerable groups |  |  |  |  |

|  |  |  |  |  |  |  | TCM diagnosis relies on tongue/pulse examination — subjective, culturally embedded |  |  |  |  |
|  |  |  |  |  |  |  | Risk: TCM AI trained on one lineage (e.g., Beijing school) may not generalize to other traditions (e.g., Shanghai, Sichuan schools) |  |  |  |  |
|  |  |  |  |  |  |  | Mitigation: multi-center TCM data collection; explicit documentation of TCM lineage in metadata |  |  |  |  |

|  |  |  |  |  |  |  | Taxonomy of Explainability: |  |  |  |  |
|  |  |  |  |  |  |  | Type | Description | Example |  |  |
|  |  |  |  |  |  |  | Intrinsic | Simple model inherently interpretable | Logistic regression, decision tree |  |  |
|  |  |  |  |  |  |  | Post-hoc | Explain complex model after training | SHAP, LIME, saliency maps |  |  |
|  |  |  |  |  |  |  | Local | Explain single prediction | "This patient was flagged because creatinine=3.2" |  |  |

|  |  |  |  |  |  |  | Level | Description | Example |  |  |

两份文档已生成：《Hermes Agent 与医学人工智能导论课程对接指南》（PDF 技术文档，含架构图与伪代码）和《TCM_AI_Hermes_Skills 包》（Word 版 SKILL.md 全集，可直接写回 zhongweiv/hermes-edu-skills 仓库）。

一、对接总原则

双通道解耦、意图为界、六面架构、三阶段落地。

Agent 只产意图，不碰驱动：Hermes Agent 负责 TCM 辨证推理、方剂推导、舌脉诊演示意图，具体渲染交给下层——这是与"医疗敏感信息不出域"和"换机器人不返工"两个要求同时兼容的唯一架构

六个面：课件面（Lesson）、讲义面（Notes）、板书面（Board）、助手面（Assistant）、实验面（Lab）、评测面（Eval）。A-Swarm 管学与练，B-Swarm 管教与评，双群经 Redis Stream 意图总线通信

三阶段：先数字人课堂（G1 EDU 离线）、再人形机器人进实训室（真机 + 仿真）、最后多机协作（讲台上 G1 + 实验室 H1）

三、Part 6 新增一章内容

第 17 章 中医药 AI 的伦理、监管与部署——这是整个对接里最硬的一块：

监管层

关键要求

数据安全

饮片/舌象/脉象纳入敏感个人信息；本地化存储；知情同意需明确 AI 用途

诊疗红线

AI 只"辅助"不"替代"；方剂/针刺方案需医师复核；毒性药（附子、乌头）强制提示

算法合规

辨证一致性测试、舌脉标注一致性检验、漂移监测（季节/地域/师承流派）

具身安全

机器人教学属近距离接触，跌倒/夹伤/碰倒煎药设备责任主体为学校，安全验收 6 万不可省

TCM 特性

师承流派差异不可强制归一；伪品鉴别只做辅助不替代法定检验
