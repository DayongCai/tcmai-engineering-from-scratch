## 工作簿结构（与生理学同形）

每小节恰好两行，四列编号：

| 列 | 含义 |
|---|---|
| A | 章序号（只在章首行与每行重复） |
| B | 节序号（`1`…`4`） |
| C | 小节序号（`1`…`3`） |
| D | 段号：`1` = 口径句，`11` = 正文 |
| E | 文本 |

所以 **段=1 不是标题**，是一句口径声明；真标题在小节行的 E 列。解析时把 `段=1` 存进 `brief`，`段=11` 存进 `body`（`rawBody`），去掉【学习目标】后的视图存 `prose`。

## 数值口径：这次和上次一样，`valueLike = 0`

上一轮我说过一句预判：「病理学教材大概不会 `valueLike=0`，正好把『教材带数值时怎么写』跑通。」

**实测把这个预判否掉了。** 21 章全量统计：

| 项 | 计数 | 说明 |
|---|--:|---|
| 数字字符 | 603 | 出现在编号与列表里 |
| 数值型（数字＋计量单位） | **0** | 一个都没有 |
| 列表序号 | 563 | 行首 `1.` `2、` |
| 「正常值」类词（正常值/参考值/正常范围） | 193 | 其中 **157** 处在否定语境（「不写正常值」这类声明），余 36 处是在讲「正常与异常的判定不在本书」 |
| 每小节的 `brief` | — | 全部写着「不写数值与单位，不作诊断与病情与预后判定」 |

也就是说：**病理学与生理学是同一种取舍**——教材只写类别与关系，不给值。差别只在声明措辞（这里是「不写数值与单位，不作诊断与病情与预后判定」，生理学是「不写数值与单位与正常值」）。

所以「带数值怎么写」不能靠这份教材演示，只能把规则**写成可执行的门**，等哪天真出现带数值的教材时自动生效。规则分两支：

### 分支 A：教材 `valueLike = 0`（本书就是这一支）

课程正文 **零数值**。凡涉及数额、区间、分级阈值、参考范围的地方：

- 只写**类别与关系**（「升高/降低」「按程度分轻中重」），不写数值与单位；
- 若读者确实需要值，另立**数据层**（形如 `standards/shengli/normal-values/`：来源号 + locator + 本机留档 + sha256），不从本书推；
- 正文里出现「数字＋计量单位」即判红。

### 分支 B：教材带数值（本层预留，暂未触发）

门按 `底本.counts.valueLike` 自动换档。一旦 `> 0`：

| 允许 | 禁止 |
|---|---|
| 在**带 `教材·第N章·N.M.K` 的行**里逐字引用教材的值（原单位原写法） | 正文其他任何位置裸写数值 |
| 引用时写明计量单位与测量条件（若教材写了） | 把教材的观察值改写成「正常值/参考区间」 |
| 同一参数教材给多套值时**原样分条**，不取平均、不择优 | 换算成别的单位、四舍五入、补齐精度 |
| 教材未给条件时，注明「教材未交代条件」 | 用教材的数值对个体作判定 |

一句话：**分支 B 里数值必须「可回到原文某一行」，分支 A 里数值一个都不许有。** 门 `scripts/check_bingli_chapter.js` 与 `tests/test_bingli_chapters.js` 都实现了这个分支判断，不是写在文档里的君子协定。

视角词表按病理学的经典三问：**病因 / 机制 / 形态**；层级沿用「细胞 / 组织 / 器官 / 系统」。

3×4 交叉（主标签组合的单元数）：

| | 细胞 | 组织 | 器官 | 系统 |

| 病因 | 2 | 0 | 2 | 0 |

**这张分布本身就是一条结论**：病理学是形态主导的学科（178 / 252 = 70.6%），而「病因」作为主视角只有 4 个单元——教材把病因写成类别（感染/理化/遗传/免疫），不展开成机制推演，病因学的分量落在「分类」而不是「分析」。读的时候要知道这一点，否则会误以为教材漏讲病因。

标签规则与生理学同一套：每单元按词表逐词计数，取最大者为 `primary`，并列时按词表顺序（不用字典序，否则并列单元会跳到「系统」），全零记 `None`（本书 1 个：`8.4.2 记录与复核的类别`——该节讲字段与流程，四层级词频全零，故不进矩阵；3×4 交叉合计 251 + 无标签 1 = 252）。

## quiz 语义门（第 13 项）

结构门管不到「答案对不上解析」这类错：6 题、阶段序列、4 选项、`correct∈0..3`、解析 ≥10 字全都能过，而 `correct` 指到错项时整题作废。第 13 项补这一段，判据分硬软两层（`scripts/lib_quiz_semantics.js`）：

**硬（判红）**

| 判据 | 说明 |
|---|---|
| 解析点名的单元号必须属于本章 | 防止点错章、点出不存在的节（如写 `5.9.9`） |
| 「依据」类引证：该节正文必须覆盖正确答案的内容词 ≥15% | 「引了这一节，答案却不在这一节」是本条要拦的事 |
| 两个选项规范化后不许完全相同 | 防「抄选项漏改」；只认完全一致，**不认字面相似** |

**引证分三类，作者自己标**（写进解析末尾，形如 `（依据教材·第5章·5.1.1）`）：

| 类型 | 含义 | 是否核正文覆盖 |
|---|---|---|
| `依据` | 这一节的正文就是答案来源 | 核（≥15%） |
| `口径见` | 这一节规定的是本题口径或边界（如「不作判定」） | 不核——口径句不在正文里 |
| `前提` | 前置题（pre）问「进本章之前要具备什么」 | 不核——答案本来就不在本章任何一节 |
| `算见` | 答案由本仓脚本对底本现算（字数、占比、条数、规则阈值），教材正文不含该结论 | 不核——标的是统计所落的节，供回查对象 |

> `算见` 是先给诊断学补引证时加的第四类（那册 72 题里 44 题考的是教材统计与课程规则，不在任何一节正文里）。病理学与生理学两册没有这类题，所以两册只用前三类。

**软（列清单，需人看）**

| 判据 | 现网实测 |
|---|---|
| 解析与「正确项」的贴近度低于某个干扰项 | **22 / 126 题**（多为解析在解释「别人为什么错」） |
| 两个选项用词几乎相同（顺序题？） | **8 处**（顺序本身是考点，属正常设计） |

**现状（2026-10-30 补齐后）**：126 / 126 题都有引证，`依据 94 · 口径见 16 · 前提 16`，硬错 **0**。补证用的是 `scripts/quiz_cite_helper.js`（按「正确项内容词在该节正文里的覆盖率」排候选）+ 人判：覆盖率只是排序线索，**不是判据**——口径类题在任何一节的正文里都覆盖不到答案，那类题要标 `口径见` 而不是硬凑一个 `依据`。

两个踩过的坑写在这里：

1. **「字面越像越可疑」是错的判据**。第一版把「选项字面重合 ≥8 个 bigram」判红，8 处误报全是好题——`渗出物→坏死→肉芽→瘢痕` 与它的倒序项共享全部词，而**顺序本身才是考点**。改成只认「规范化后完全一致」。
2. **判据会静默空转**。`unitIdsIn()` 最初在 `clean()` 之后匹配，而 `clean()` 把句点当标点抹掉，`5.9.9` 被抹成 `5 9 9`，于是这条判据永远 0 命中、也永远不报错。第 13 项因此内置**四个探针**（点错单元号 / 选项重复 / 引对单元 / 同词不同序）——没有探针的门，绿灯只证明它没在干活。

## 单元级正文（第 14 项）：252 段

21 章正文原本是**章级**的：每章 7–11k 字，覆盖 12 个小节，但颗粒度停在「节」。生理学那边每章有一层 `standards/shengli/unit-notes/<章>.json`（132 段、一小节一段、每段 ≥120 字、docs 与源逐字一致），病理学缺这一层——按小节量只能算「提到过」，不能算「写过」。

这一轮把同一层建起来：

| 项 | 值 |
|---|---|
| 段落数 | **252**（21 章 × 12 小节，一个不多一个不少） |
| 总字 / 平均 / 最短 / 最长 | 71,980 / **286** / 261 / 340 |
| docs 非空白字 | 179,221 → **250,705**（+71,484） |
| 教材引文行 | 239 → 239（渲染块里不含引文行，+21 是各章「引用格式说明」行） |
| 每章 12 个 `#### N.M.K` 标题 | 21 / 21 |

**写法与生理学一致**：每段固定说三件事——这一节在问什么、答案落在哪一层、与同章其它小节是什么关系。源文件是 `standards/bingli/unit-notes/<章>.json`，由 `scripts/render_bingli_unit_notes.js` 渲染进 `docs/zh.md` 的「## 十二个小节：逐条落位」（带 `UNITNOTES:BEGIN/END` 标记，幂等）。05/06/07 三章建章时就手写过这一节，这轮先用 `scripts/extract_bingli_unit_notes.js` 抽成源文件再回渲染——**抽取 → 生成 → 一致**，而不是把内容重写一遍。

**第 14 项门**（`tests/test_bingli_chapters.js`）：21 章都得有 unit-notes（缺一章即红）；每章恰好 12 段；小节号与标题对齐 `units.json`；每段非空白字 **≥250**；docs 里那一段必须与现算结果**逐字一致**；每章 12 个 `#### N.M.K` 标题。

第一次跑（阈值 120）就拦下三处：`17.3.1` 117 字、`18.3.2` 116 字（两段都不足 120，是真正的「写短了」），`18.1.1` 标题写成「慢性表浅性胃炎」而教材是「慢性浅表性胃炎」（标题对齐 `units.json` 时抓到）。三处都改了源文件，不是放宽判据。

**第二轮：252 段全部扩写到 260–340 字**（原平均 158 → **286**），门的下限随之从 120 提到 **250**——门跟着内容走，不是内容迁就门。扩写的是「为什么这样归类、与相邻小节什么关系、判读时哪一步最容易被记反」，不增新事实、不写数值（复算：`数值 + 单位` 命中 **0** 处）。

**与生理学的差距已收平**：生理学 132 段平均 332 字，病理学 252 段平均 286 字，都是「一小节一段、每段说清问什么/落在哪层/与谁相关」。

## 边界

- 底本一个字不改：教材缺什么如实留账，缺的部分另立 `supplements/` 层，两笔账分开算。
