## 口径（可复算）

1. **一篇一单元**：素问 81 + 灵枢 81 = 162，与「内经选读」的书名口径一致；篇内 1,728 段原文保留在 `units[i].paras`，不做二次合并。
2. **正文只算原文**：教材的「通读」（篇导读）与「注释」（校勘按语）单列在 `tongdu` / `notes`，不进 `body`——否则 13.6 万字会混进 1.9 万字按语。
3. **不校改**：异体字与 `【网络校准·…】` 批注原样保留，只在统计时单列。
4. **引用格式**：`教材·素问·阴阳应象大论（素问第5篇）`；本书是教材整理本，不得写成「影印本第N页」。

课程逐字引用以**全文**为准；教材本负责注释、篇导读与 31 篇类编排。两本字数比 < 90% 的判为**节选**。

## 边界

- 本底本是**教材整理本**，不是影印善本：篇序依王冰次注/史崧本，文字以工作簿为准；若要校勘异文，需另立影印本来源（本课不做）。
- 「通读」与「注释」是教材编者的话，引用时必须与原文分开标注。
- 篇数与通行本一致（162 篇），但**未逐字核对**通行本异文——这是已知缺口，不掩饰。
- 单元按**教材的 31 篇类 → 162 篇**编排，与课程 06-neijing-xuandu 的 **10 章**不是同一套编号：
  课章是选读路线（阴阳/藏象/脉学…），篇类是全书的检索骨架；两套并存，不得互相冒充。
