## 一、隐形矫治的总路径：从资质门槛到方案落地

> 「本指南从口腔正畸无托槽隐形矫治技术中的从业者要求、治疗风险、适应证、病历资料的采集要求、矫治方案的设计流程和常用治疗策略几个方面给出了口腔正畸无托槽隐形矫治技术的应用标准和指南。」（外源·T/CHSA 003—2021 口腔正畸无托槽隐形矫治技术指南 第1条）

这一条把整套指南的目录念了一遍：**从业者要求 → 治疗风险 → 适应证 → 资料采集 → 方案设计 → 治疗策略**。它同时说明一件事：隐形矫治的失败多数不在「牙移动算法」，而在前三项（资质、风险告知、适应证判断）。

| 环节 | 依据 | 要点 |
|---|---|---|
| 从业者要求 | 外源·T/CHSA 003—2021 口腔正畸无托槽隐形矫治技术指南 第4.2条 | 须具备正畸专业训练与相应资质，能识别并处理并发症 |
| 治疗风险 | 外源·T/CHSA 003—2021 口腔正畸无托槽隐形矫治技术指南 第4.3条 | 依赖患者依从；牙移动与设计存在偏差 |
| 适应证分级 | 外源·T/CHSA 003—2021 口腔正畸无托槽隐形矫治技术指南 第5.1.1条 | 高／中／低三级可预测性，分级决定是否接诊 |
| 影像采集 | 外源·T/CHSA 003—2021 口腔正畸无托槽隐形矫治技术指南 第5.2.2条 | 曲面断层＋头颅侧位，必要时 CBCT |
| 数字化模型 | 外源·T/CHSA 003—2021 口腔正畸无托槽隐形矫治技术指南 第5.2.3条 | 口内扫描或硅橡胶印模 |
| 方案设计 | 外源·T/CHSA 003—2021 口腔正畸无托槽隐形矫治技术指南 第5.3条 | 前瞻设计 → 定目标 → 虚拟排牙 → 移动顺序 |

**操作要点**：把「可预测性分级」当准入判据，而不是事后解释。低可预测病例不是「做慢一点」，而是「换方案或转诊」——这是指南用分级替代经验判断的用意。

## 二、三条常用策略：各自有适应证与禁忌证

| 策略 | 依据 | 要点 |
|---|---|---|
| 推磨牙向远中 | 外源·T/CHSA 003—2021 口腔正畸无托槽隐形矫治技术指南 第6.1.1条 / 第6.1.2条 / 第6.1.3条 | 适应证 → 禁忌证 → 设计要点，三步都必须过 |
| 邻面去釉 | 外源·T/CHSA 003—2021 口腔正畸无托槽隐形矫治技术指南 第6.2.1条 / 第6.2.2条 / 第6.2.3条 | 同上；去釉量是硬约束，不是「看着来」 |
| 分步移动 | 外源·T/CHSA 003—2021 口腔正畸无托槽隐形矫治技术指南 第6.3.1条 / 第6.3.2条 / 第6.3.3条 | 前牙与后牙分步节奏不同 |

**操作要点**：这三条策略是**获取间隙**的三条路，选择顺序应为「先判禁忌 → 再判适应证 → 最后排设计」。倒过来做（先定策略再找理由）是临床上最常见的返工来源。
