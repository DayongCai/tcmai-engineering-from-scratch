# standards/jichu —— 《中医基础理论》教材底本

## 1. 这是什么

中医系「中医基础理论」10 章课程引用的**教材底本**。母本是项目方提供的 Excel 工作簿：

| 项 | 值 |
|---|---|
| 文件 | `E:\textbooks\qhzy-中医基础理论.xlsx` |
| 版本 | 岐黄智医版种子内容 · 分布式体系适配版（v3.0-qhzy，2026-08） |
| 大小 | 见 `底本.json` 的 `source.bytes` |
| sha256 | `870b004ea34b4ec22e00f9903c5b6cea0f6e4e34ab3cff594906477b9da51382` |
| 工作表 | 29（14 内容表 + 15 方法与平台表） |

与金匮、温病不同，**这门学科有教材底本**，所以：

- 引用写 **「教材·第N章·第M.M节」**，不写「原文」「经文」；
- 不走「外源·笈成」那套标注；
- 教材里转引的古籍（如「正气存内，邪不可干」）是**二手引语**，要引经典须回《素问》核对——本仓库对经典的保真门（`test_jingui_chapters` / `test_wenbing_chapters`）管不到教材转引，这是已知缺口。

## 2. 产物

## 3. 解析口径

工作簿的「内容」列逐行取，按编号识别层级：

```text
第N章  →  章
9.1    →  节
9.1.1  →  小节
9.1.1.1 → 段标题（挂在小节下）
其余非空行 → 正文段（挂到最近一层）
【…】开头的行 → 校准批注，单独进 notes[]（全书 5 条）
```

## 4. 已知缺陷（必须在引用时说明）

### 4.1 19 段被单元格截断

327 段里有 19 段以非句末标点收尾，是工作簿转录时被切断的，例如：

```text
4.6.1（48 字）… 气能摄血（固摄血液不溢出脉外）。气虚      ← 后半句丢失
5.2.2（37 字）… 循行于躯干及下肢外侧，终止于              ← 后半句丢失
2.2.2（91 字）… AI系统模拟极端环境下的生理反应（如        ← 括号未闭合
```

影响：第 5 章的关系图因此少了「气虚→出血」一条边；第 8 章「急则治其标」只写了一半。
修法只有回纸本/PDF 补录，**不许推断补字**。

### 4.2 理论句与平台映射句同段

62/327 段（19.0%）在同一段内先讲理论、再讲「AI/平台怎么做」。因此：

- 不能按段落切「原文层」与「注释层」，必须逐句；
- 各章代码只引理论句；映射句一律降级为「教材的工程建议」。

### 4.4 缺口已补：补源层 `supplements/`

上表六处缺口**已按补源约定补录**，但**底本一个字未改**（仍是 13 章 / 327 段 / 45,199 字）。
补录内容在 `standards/jichu/supplements/`（四份源：素問 / 靈樞 / 八十一難經 / 醫學心悟），
共 **74 条**（两轮：六处「说了没展开」+ 两处「提了名没讲」），每条带 `外源·笈成·<书名> <篇>` 与 sha256，可逐条回源核验。
引用补录条目时**必须标「外源·笈成」**，不得写成「教材」或「底本」。
