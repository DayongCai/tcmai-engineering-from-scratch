# standards/jichu/supplements —— 教材缺口的补源层

> 底本 `standards/jichu/底本.json`（13 章 / 327 段 / 45,199 字）**一个字都不改**。
> 它缺什么，就如实记什么；缺的部分另立本层补录，两笔账分开算。

## 一、为什么要有这一层

`README.md`（上层）§4.3 把教材的六处缺口列了出来。这些缺口是**教材自身的**，不是本仓库漏抽：
病机十九条只引 2 条、八法只释 2 法、反治只 2 法、奇经只写 4 脉、十二经全称只 7 个、五行归类只填 4 格。

补法只有两条路：

1. **改底本补齐** —— 否决。底本是母本工作簿的忠实投影，改它等于伪造教材；
2. **另立补源层** —— 采用。底本照旧统计，补录内容单独记账、单独标注、可逐条回源。

### 4.1 第二轮的两个口径问题

- **七篇只报规模、不摘文**：教材用 18 行覆盖 3.4 万字，骨架后面是实体；本章只量「篇序 / 句数 / 字数」，把「讲什么」留给原文，避免用摘要冒充原文。
- **胜复 ≠ 相乘相侮**：教材 2.3.2 讲的相乘相侮是五行**结构**（脏腑间生克），胜复是六气**节律**（一年六步、六年一轮的过度与报复）。两者都叫「制约」，但尺度不同，不能互换引用。

## 五、解析坑

1. **病机十九条的句子有长有短**：多数是「诸…，皆属于X。」一句六到十字，但「诸禁鼓栗，如丧神守，皆属于火」有内部逗号；按「諸…皆屬于…。」整体切，不能按逗号切。
2. **五行归类不在第一句里**：`東方生風…肝主目。` 之后才是「在體為筋，在臟為肝，在色為蒼…」；只截第一句会得到 9 个空格。截到「怒傷肝」这类「X傷Y」句之前才完整。
3. **八法是章题不是正文**：`醫學心悟` 的八法以 `論汗法`/`論和法`/…/`論消法` 八个章题分章；正文里「醫門八法」只是序言里的一句。必须按章题切，且要拿**原始 HTML**（去掉标签后章题就没了）。
4. **opencc 的两个错字**：`蹻` 转成异体 `𫏋`（应作「跷」）、`膹` 转成 `𪱥`（应作「膹」）。已显式纠正，否则简体栏不能引用。
5. **十二经全称不止一种句式**：`肺手太陰之脈`、`心主手厥陰心包絡之脈` 的脏腑名位置不同；按「…手/足+阴阳…之脈」整段抓，再用十二组（手足×三阴三阳）去重，不靠人工名单。

6. **七篇要按篇题切片，不能按字数截**：素問一页里 81 篇连排，`<h2>` 篇题是唯一可靠边界；按字数截会把《六元正纪大论》（11,272 字）截成《五常政大论》的尾巴。
7. **胜复三则必须整句命中**：「有勝則復，無勝則否。」在原文里紧接「復已而勝何如」，按 `勝複` 关键词扫会捞到 49 处噪声；本书改为**整句等值匹配**，命中即原文，不命中即 missing。
