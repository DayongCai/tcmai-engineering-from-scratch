# standards/jingui/gushiwen —— 《金匮要略》古诗文网本（第二见证）

> 用途：与 `../底本.json`（笈成本）逐篇互校，给 `departments/01-zhongyi/08-jingui-yaolue/` 的 24 章提供第二个文本见证。
> 生成：`python scripts/build_jingui_gushiwen.py --fetch` · 重建：`python scripts/build_jingui_gushiwen.py` · 校验：`--check`

## 一、为什么要有第二本

`../底本.json` 是从中醫笈成（漢リポ 文字化本）取的《仲景全書·金匱要畧方論》，**唯一的条文见证**。
单见证有两个具体风险：

1. **分篇**：笈成本是 22 篇 + 序 + 3 附篇（共 26 段），通行本多作 25 篇（序不入篇）。课程要「一篇一章」覆盖 25 篇，
   就必须有一本按 25 篇编排的对照本，否则「第 7 篇」到底指哪一篇无法自证。
2. **字词与分条**：笈成本把双行夹注单列进 `notes`、方文另存 `formulas`；别本把注文留在正文括号里、方文与正文混排。
   若只照一本讲「本篇 1804 字」，读者无从判断差异是版本还是抄错。

所以本目录是**校勘本，不是替代本**：条文引用仍写 `外源·笈成·金匱要略方論 第N篇·第M条`，
古诗文网本只在需要指出差异时出现，写作 `外源·古诗文网·金匮要略 卷X·<篇名>`。

## 四、实测口径（2026-11-11）

| 指标 | 古诗文网本 | 笈成本 |
|---|--:|--:|
| 篇 | **25** | 22 篇 + 序 + 3 附篇 |
| 卷 | 3 | 3（笈成按篇，不标卷） |
| 段落 / 条 | 1,282 段 | 402 条（+ 序 1） |
| 汉字 | **29,929** | 34,462（含方文与注文的计法不同） |
| 方名段 | 157 | 174 方（有方文 165 + 互见 9） |

字数不等是**正常的**：两本对「什么算正文」的口径不同（见 `校勘.md` 读法第 1 条）。
正因为口径不同，本目录只做两件事：**给分篇定位**（25 篇 → 通行本编号）与**给字词差异留证**（差异必须能被指出并复算）。

## 六、已知缺口

1. 古诗文网本无「序」，笈成本的张仲景序/林亿序在本目录无对应——序只以笈成本为见证。
2. 古 25 篇与笈成 22 篇正文的**编号一致**（1-22），但篇名用字有差：如笈成「消渴小便利淋病脉证并治第十三」vs 古诗文网「消渴小便不利淋病脉证并治十三」；「蚘虫」vs「蛔虫」。校勘表已并列，引用时以笈成名称为准。
3. 本章只做文本与结构校勘，**没有任何临床结论**；两本的分条差异不得用于判断「哪种治法更对」。
