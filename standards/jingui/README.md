## 一、为什么走外源

仓库的「底本」是桌面 `textbooks/qhzy-*.xlsx` 共 100 份 —— 那是**教材**工作簿，覆盖 99 门学科；
金匮要略**不在其中**（`D:\textbooks\textbooks\` 100 份里也没有 `qhzy-金匮要略*`）。

所以金匮的原文只能走外源。按 [`EXTERNAL-SOURCES.md`](../materials/textbooks-batch/EXTERNAL-SOURCES.md)
立的规矩办：**先留档、再登记 sha256、然后才落条文**；外源单独成库，不并入底本统计。

## 四、口径（引用前必读）

1. **条号沿用源页，不自编**。金匮各本分条有出入（赵开美本 vs 医统本 vs 通行本），跨版本引用须核对分条。
2. **繁→简只做字形**（`opencc t2s`），不改字词、不改方名、不做地区词替换。
3. **药名/剂量是源页原文，未做规范化**：`附子炮` 里的「炮」、`山茱萸各四兩` 的「各」都照抄；
   要做配伍统计须自行清洗（第 10 章 `code/main.js` 里有清洗规则，且把规则写在注释里）。
4. **附篇三篇无条号**（杂疗方第二十三、禽兽鱼虫禁忌第二十四、果实菜谷禁忌第二十五），
   整篇存为 1 条，`tiao: null` —— 它们不是辨证条文，别混进杂病统计。
5. **序 1 条**（张仲景序 / 林亿序），同样 `tiao: null`。

## 五、已知缺口与校勘登记

| 项 | 情况 |
|---|---|
| 段落标记两套 | 源页老段用 `<div data-sec="p" id="1.1">`、新段用 `<p id="1.3">`；只认后者会丢 1.1/1.2/1.13（首版就丢了两条「上工治未病」，已修） |

| 异体/讹字 | 源内已知异体（如 `𠘧𠘧然`、`齘齒`）照录不改，简体由 opencc 转，不校改 |

### 5.1 药名解析（底本 v2：已修，原文自述 148/148 吻合）

方文里「右N味」是原文自带的复算锚点，用它校验解析器：**148 方自述味数，148 方吻合，0 偏差**。

v1 有 12 处方名/药味错位，原因归四类，v2 逐类修掉：

| 根因 | v1 症状 | v2 修法 |
|---|---|---|
| 一个 `h-formula` 块里并列多个方 | 蒲灰散吞掉滑石白鱼散与茯苓戎盐汤；越婢加术汤的药文读成了甘草麻黄汤；乌头桂枝汤只剩「乌头」 | 按 `<b>X方：</b>` 切块，块内各取方名/药味/煎服法（13.11、14.25、10.19、12.23、12.24、9.5 等共 +10 方） |
| 非贪婪正则截断 | `<span data-rev="注"><small>…</small></span>` 让块在第一个内层 `</span>` 就断，后半段药味/煎服法丢失（9.9、12.23 细辛） | 改成标签配对扫描 `extract_formula_blocks()` |
| 下一味药被排进上一味的剂量夹注 | 「三兩，炙細辛三兩」「三兩，黃柏三兩」「二兩，除目及閉口，去汗黃芩二分」→ 少 1–3 味（6.17、17.8、17.43、18.6、20.5、7.9、5.10、12.18、17.45） | 按「，+ 药名 + 剂量」再切一刀；同时否决煎服法/校注/采集日期片段（以、煎、煮、取、服、一作、强人、月、日…），否则会拆出「以蜜」「以水」「八月」 |
| 纯校注被当成药 / 全角逗号未切 | 「⟨深師有生薑二兩⟩」「一法二分」各算一味；橘皮竹茹汤整行用逗号，被并成 1 味 | 丢弃整 token 为夹注者与 `一法/一方/一作/恐是/深師…`；无夹注时按 `，、` 切分并解析「药名+剂量」 |

口径差（**不要混用**）：

- **方数**：**174 方** = 165 有方文 + **9 互见**（见前/见上/未见，`refOnly`）。v1 的 164 是「每块只读首方」的产物，并列方被吞掉了。
- **2026-11-11 两处解析规则修正（药名数与药味次数随之变动）**：
  1. **洗方／坐药无药味行**：底本原先把「右以百合一升，以水一斗，漬之一宿…」整句当药味行切，
     切出「右以／以水／漬之／以洗身／洗已／食煮饼／勿以盐豉也」7 个伪药名（172 味里有它们）。
     规则改为「段落以『右』起头即视为服法」，并从中提出单味药 → **百合洗方 = 百合一味**。
  2. **服法用药单列 `methodHerbs`**：大建中汤「內膠飴一升」、十枣汤「先煮肥大棗十枚」、乌头煎「蜜二升」
     这类药不在药味行（故不计「右N味」），但又确实是方中用药。新增 `methodHerbs` 字段单列三处，
     方解与门禁据此核对，不再需要豁免名单。
  → 结果：**药名 172 → 165 味、药味行 734 → 728 次**（方数 174、条数 402 不变）。
- **药名数**：未清洗 **165** 味（v1 174 里有「深師有生薑二兩」「去汗黃芩」这类伪药名）。
- **药味出现次数**：**728** 次（v1 685）。
- 清洗后药名数与 Top 频次由第 10 章代码计算，引用时写**哪个口径**（未清洗 / 清洗后）。

`tests/test_jingui_text.js` 把 **148/148** 钉死：以后解析再有偏差，这道门会直接红。

## 七、第二见证：古诗文网本（`gushiwen/`）

| 项 | 古诗文网本 | 笈成本（主见证） |
|---|--:|--:|

**分工**：笈成本继续做条文引用与统计（条号 `第N篇·第M条`、方数 174、药味 728 次都以它为准）；
古诗文网本只做**分篇定位**（把课程要讲的「25 篇」落到具体篇名与卷次）与**字词/分条差异留证**。
两本口径不同（注文是否单列、方文是否另存），字数不等是正常的，见 `gushiwen/校勘.md` 读法第 1 条。

**已知解析缺口（做篇级方数前必须核对）**：笈成本的方数按 `formulas[]` 结构化解析，
源页把主治写进方名行的写法（如「侯氏黑散　治大风…」不带「方」字）会被漏计——
篇 5 因此只解析到 **2 方**（桂枝芍药知母汤、乌头汤），而该篇原文还有侯氏黑散、风引汤、
防己地黄汤、头风摩散、矾石汤等方文。**篇级方数只对解析完整的篇有比较意义**；
全书 174 方这个数是解析口径的结论，不等于「金匮有 174 首方」。

## 九、方族层（`fangzu.*`，本项目自撰分类）

第 10 章把 174 方的配伍算清楚了，但那是**平铺**统计，看不出方与方的关系。方族层补的是这一层：

| 产物 | 内容 |
|---|---|
| `fangzu-map.json` | 族归属（由 `scripts/jingui_fangzu.py` 生成，人工作者层） |
| `fangzu.json` | 逐族统计：方数 / 药味中位与均 / 共见药 / 标志药 / 族内前三 / 代表方 / 逐方组成 |
| `fangzu.md` | 比较表（23 族一行一族 + 逐族成员表） |
| `fangzu.svg` | 全库方族图（离线 SVG，每点 1 方，空心点＝互见方） |
| `leifang-map.json` | 类方鉴别 30 对（`scripts/jingui_leifang.py`，人工作者层） |

口径三条：

1. **一族一归属**：168 个唯一方名全部分配，不重不漏（同方异名的猪膏发煎／膏发煎各归一次）；
2. **族按功用，不按单味药**：含附子的方分属温阳、攻下、利水三族，判据是全方功用；
3. **不硬凑族**：只归 1 方的方不入族；每族 ≥2 方，否则族内统计失去意义。

**共见药**＝全族每一方都有的药（交集）；交集为空时**不冒充**，写「（无共见药）」并给族内前三。
**标志药**＝族内 ≥50% 且族外 <10%；大族的药多在别族出现，因此多数大族没有标志药——
这不是缺数据，是门槛在起作用（甘草、茯苓这类全库高频药本来就不该成为某族标志）。

### 类方鉴别（同族内相邻两方）

族内按**药味数升序**排队，相邻两方成对；两方药味差 > 2 味的不作鉴别（不是同源加减，硬比就是牵强）。
全库得 **30 对**，分三类：**加减味**（多／少一味）、**易味**（一味换一味，如泽泻汤之泽泻 → 枳术汤之枳实）、
**同药异量**（药味全同而分量不同，如半夏泻心汤之甘草三两 → 甘草泻心汤四两）。

与方解层互相校验的办法：鉴别要点必须点到**真正的差异药**，且不得提到两方都没有的药；
差异（加味／去味／剂量）由构建脚本从底本现算，作者的文字不能改变差异事实。
这条门当场抓过我一处：写「白粉少许」时，粉虽在别方入药，却不是蛇床子散与雄黄薰任何一方的药。

复算：`python scripts/jingui_fangzu.py && python scripts/jingui_leifang.py && node scripts/build_jingui_fangzu.js`
校验：`node scripts/build_jingui_fangzu.js --check && node tests/test_jingui_fangzu.js`
