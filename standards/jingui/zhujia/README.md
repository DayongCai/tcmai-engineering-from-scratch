# standards/jingui/zhujia —— 《金匮要略》四家注（外源·笈成）

> 用途：教材线（`textbooks/01-zhongyi/08-jingui-yaolue/`）**逐条注文**的唯一来源。四家 = 醫宗金鑑 + 心典 + 淺註 + 輯義。
> 生成：`fetch_jingui_zhujia.py --fetch` + `fetch_jingui_yizong.py --fetch`（留档）→ `build_jingui_zhujia_align.py`（结构化 + 对齐 + 校勘登记）
> 校验：两个脚本都有 `--check`（sha256 / 篇块 / 块数 / 注文字数 / 对齐数）。

## 一、为什么单独立库

底本 `../底本.json` 只有**条文**。教材要讲「为什么可以这样读」，就必须引注家——但注家不是底本：

1. **不是同一版本**：底本是趙開美本一系的《金匱要略方論》；心典、淺註、輯義各有底本与分卷。
2. **不是同一分条**：心典常两三條并讲，淺註把注文用小字夹进原文句中，輯義逐条校异文。
3. **不是本项目的话**：注家判断必须与原文判词分开，不能混成一句。

所以三家注单独成库，**不并入 402 条统计**，引用一律写「外源·笈成·<书名> <卷>·<篇>」。

## 四、对齐方法（为什么不用条号）

三家注的分条与底本不同，按条号对齐会假精确。做法：

1. 按篇对齐（注本 h2 的出现顺序 = 底本 22 篇 + 序 + 3 附篇的顺序）；
2. 篇内把每个 `<p>` 与本篇各条做**去标点 + 异文归一**后的前缀相似度（difflib，前 60 字），≥0.60 认作同条；
3. 同段里「原文 + 注」的写法（心典、淺註）按底本条的**尾 12 字锚点**切开，锚点后退到 8 字再试；
4. 一条命中多块、一块命中多条都如实记进 `align.json`（带 `ratio`），不强行一对一。

异文归一表在脚本 `VARIANT` 里（臟/藏、準/准、癉/疸、噦/哕、痙/痓、欬/咳、鞕/硬、胷/胸…），
**只用于相似度计算，不改输出文本**。

## 五、口径（引用前必读）

1. **注文不改字**：逐字引用（繁体照录）；教材里做 t2s 字形转换，与底本同一条规则（只动字形，不动字词）。
2. **注家观点≠原文**：凡「按、」「愚按」「〔程〕」「〔尤〕」「〔鉴〕」之后的话都是注家判断。
3. **不并入 402 条统计**：注文是解释层，单独计数。
4. **对齐误差照录**：0.60–0.80 的块保留 `ratio`，供人工复核；本项目不静默丢块。
5. **附篇**：心典不注 23-25 篇（22 篇），淺註与輯義有；差异写进 `校勘登记.md`。

## 六、已知缺口

1. 三家注的**卷次/篇名用字**与底本有异（痓/痙、噦/哕、癉/疸、奔㹠/奔豚），引用时以注本原字为准，另注底本篇号。
2. 淺註 有 18 块判不出注文（原文与夹注同段且句式差异大）——这些块的注文在 `books/qianzhu.json` 里为空，**不补写**。
3. **《醫宗金鑑》另走字段式解析**（见 §七），其余三家仍按 h2/p 结构；两套解析器写同一份 `align.json`，互不干扰。

## 七、《醫宗金鑑·訂正仲景全書金匱要略註》：抓取工程要点

**为什么单立脚本**：笈成的《醫宗金鑑》是**多卷总书**，目录页只有元数据（1 KB），正文在子目录，且两种版式并存：

| 见证 | 路径（笈成 raw） | 字节 | sha256 | 角色 |
|---|---|--:|---|---|
| **條列版**（主） | `醫宗金鑑_條列版/訂正仲景全書金匱要略註/index.html` | 459,086 | `6ddbb8aa247c…` | 每条一个 `<pre>`：篇名／編號／經文／按／註／集註 |
| 原版（第二） | `醫宗金鑑/訂正仲景全書金匱要略註/index.html` | 426,322 | `364fa240d89a…` | 卷—篇—段式，注散在文中，供校字与卷次核对 |

解析要点（每条都是踩过的坑）：

1. **字段切分**用 `(集註|篇名|編號|經文|按|註|方|附)：`，`集註` 必须排在 `註` 前面，否则「集註：」被切成「集」+「註：」。
2. **篇按名字匹配，不按序号**：《醫宗金鑑》的篇序与底本不同——「驚悸吐衄下血」在金鑑是**第十二**，在底本是**第十六**；按序号对齐会整篇错位。
3. **篇名比对前先 t2s**：底本 `nameSimp` 是简体、金鑑是繁体，直接算相似度只有 0.36，22 篇里只认出 4 篇。
4. **附篇（23-25）另计**：底本附篇按整篇 1 条计，金鑑逐方分立（191 个方块），不参与条级对齐，`tiao` 留空、如实单列。
5. **編號作交叉验证**：金鑑每篇自 001 起编号，与底本条号并排记录在 `books/yizong.json` 的 `bianhao` 字段；相似度认不出时按編號兜底。

实测：**25 篇 / 383 块 / 82,710 注文汉字（落在 402 条上 75,350）/ 命中 369 条**；
其中「註」543 段、「集註」414 段、「按」291 段（集註里保留了金鑑转引的徐彬、程林、赵良等旧注，具名照录）。
